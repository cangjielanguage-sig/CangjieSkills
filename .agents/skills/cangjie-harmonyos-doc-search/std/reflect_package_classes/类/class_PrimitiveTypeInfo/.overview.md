# class_PrimitiveTypeInfo

This directory provides comprehensive API documentation for the `PrimitiveTypeInfo` class, a core component of the Cangjie programming language's reflection package. It details how developers can describe and inspect type information for primitive data types, such as integers, floats, and booleans. The documentation covers class definitions, inheritance from `TypeInfo`, and specific methods for retrieving metadata, including handling exceptions for invalid types. It is designed for Cangjie developers who need to implement reflection features, programmatically inspect types, or manage runtime and static type information within their applications.

## Detailed Description

### class_PrimitiveTypeInfo_2more.md class_PrimitiveTypeInfo_2more.md
This API reference document details the PrimitiveTypeInfo class, which describes type information for primitive data types within the Cangjie reflection package. The main sections cover the class definition, a comprehensive list of supported primitives (including integers, floats, and booleans), and the static get method. Key information includes that the class inherits from TypeInfo and the get function retrieves type metadata via a qualified name string, throwing specific exceptions if the type is invalid or not found. Developers should note that the Nothing type is currently unsupported. This documentation targets Cangjie developers utilizing reflection to programmatically inspect primitive types.

### static_func_ofAny_2more.md static_func_ofAny_2more.md
This API documentation details the static `of` functions within the `PrimitiveTypeInfo` class for the Cangjie programming language's reflection capabilities. It covers two overloaded methods: one accepting an instance of type `Any` to retrieve runtime type information, and a generic version accepting a type parameter `T` to retrieve static type information. The document explains the concept of runtime types versus static types, specifically noting that runtime types are determined via dynamic binding. Both functions return a `PrimitiveTypeInfo` object and may throw `InfoNotFoundException` or `IllegalTypeException`. Code examples demonstrate retrieving type information for `Int64`. This reference guide targets Cangjie developers implementing reflection features who need to inspect type metadata programmatically.
