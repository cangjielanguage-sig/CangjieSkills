# cj-image-pixelmap-operation

本目录提供了关于仓颉语言中 PixelMap 对象位图操作的详细技术指南。它旨在帮助开发者掌握获取位图信息、读取及修改像素数据（涵盖整图与指定区域）以及执行深拷贝的核心技能。文档深入剖析了 `readPixelsToBuffer` 和 `writeBufferToPixels` 等 API 的协同工作机制，并强调了保持像素格式一致性的关键作用。该指南特别适合从事图片美化、滤镜开发或局部像素处理的应用开发者，前提是读者已具备基础的图片解码知识。核心关键词包括 PixelMap、位图操作、图像处理、仓颉、像素读写。
