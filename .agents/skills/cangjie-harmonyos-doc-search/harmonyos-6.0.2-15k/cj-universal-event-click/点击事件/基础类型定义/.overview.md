# 基础类型定义

This directory serves as a comprehensive resource for API reference documentation concerning fundamental type definitions within the Cangjie language and the ArkUI framework. It is specifically curated to assist developers in understanding and implementing the core data structures required for effective event handling and user interaction management. The documentation encompasses detailed definitions for classes that manage user inputs, such as click events, by capturing precise coordinate data, event timing, and input device sources. Furthermore, it provides specifications for representing the display areas of UI components that trigger events, enabling accurate spatial logic. These foundational types are indispensable for creating responsive and interactive user interfaces. This directory is highly suitable for ArkUI developers working on API version 12 or later who need to integrate sophisticated input processing, manage event targets, and leverage the specific structural capabilities of Cangjie syntax in their application development workflow.

## Detailed Description

### class_ClickEvent.md class_ClickEvent.md
This API reference document defines the ClickEvent class in the Cangjie language for handling user click interactions within the ArkUI framework. It details the class constructor and nine public properties, including coordinate variables (x, y, windowX, windowY, displayX, displayY), timestamp, source, and target. The class captures precise click locations relative to the element, window, and screen, along with event timing and input device type. All properties are readable and writable. This guide targets ArkUI developers needing to process touch or mouse input events in version 12 or later.

### class_EventTarget.md class_EventTarget.md
This document provides API reference documentation for the EventTarget class in the Cangjie language, designed to represent the display area of an element triggering an event within the ArkUI framework. It details the class constructor and the public area property, which defines the target region using the Area type. Key information includes the read-write capability of the area property, the requirement for an Area parameter during object construction, and specific version availability starting from API 12. This technical reference is intended for developers implementing event handling and spatial logic in ArkUI applications, requiring knowledge of Cangjie syntax and UI component structures.
