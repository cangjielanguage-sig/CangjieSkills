# cj-notification-overview

This directory contains the essential documentation for the Notification Kit, a specialized service enabling developers to publish local notifications directly to user devices. It provides a holistic view of the notification system, covering everything from basic usage scenarios to complex business workflows. Key topics include core capabilities, various notification styles, and critical system constraints such as retention periods and frequency limits. The guide also distinguishes between foreground local notifications and background Push Kit requirements, offering clarity on when to use each. Additionally, it details integration with the BackGroundTask Kit for handling scheduled tasks efficiently. This documentation is intended for application developers seeking to implement robust user alerts, status updates, and time-sensitive notifications, ensuring they adhere to platform limits like the 200KB size cap while optimizing user engagement and system performance.
