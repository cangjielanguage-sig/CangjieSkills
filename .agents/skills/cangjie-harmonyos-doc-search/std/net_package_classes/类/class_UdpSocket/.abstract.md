This directory contains API reference documentation for the `UdpSocket` class within the Cangjie standard library, designed to facilitate User Datagram Protocol (UDP) network communication. It covers essential aspects of socket management, including class constructors, data transmission and reception, configuration of socket options, and lifecycle control. Key topics include binding sockets to local ports, managing buffer sizes, handling operation timeouts, and error handling for platform-specific limitations. This documentation is suitable for developers implementing network protocols in Cangjie who require precise control over low-level datagram operations, socket configuration, and resource management.
