# cj-start-application-development-overview

本目录提供了基于OpenHarmony SDK和仓颉语言的应用开发总体导读，旨在帮助开发者全面掌握应用开发流程。文档内容涵盖入门、开发、工具和API参考四大核心板块，详细介绍了基础构建方法、仓颉语言语法、应用程序包结构及资源文件使用。此外，还深入讲解了应用框架、系统、媒体、图形等领域的Kit开放能力，如Ability Kit、ArkUI和Network Kit。该文档适合OpenHarmony应用开发者，通过推荐DevEco Studio工具及提供全量API参考，助力开发者快速上手并实现高效开发。

## 详细描述

### cj-start-application-development-overview.md

本文档旨在指导开发者利用OpenHarmony SDK的开放能力完成应用开发，是应用开发的总体导读。文档主要包含入门、开发、工具和API参考四个部分。入门部分介绍基础构建方法及仓颉语言语法；开发部分涵盖应用框架、系统、媒体、图形等领域的Kit开放能力；工具部分推荐DevEco Studio；API参考提供全量接口说明。重点信息包括掌握应用程序包结构、资源文件使用及仓颉核心语法，以及如何利用Ability Kit、ArkUI、Network Kit等丰富能力进行高效开发。面向OpenHarmony应用开发者，帮助其快速上手并深入掌握开发技能。
