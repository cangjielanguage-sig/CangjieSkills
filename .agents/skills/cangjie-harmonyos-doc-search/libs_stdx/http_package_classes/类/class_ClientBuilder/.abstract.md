This directory contains API documentation for the `ClientBuilder` class in the Cangjie language, which acts as the exclusive constructor for HTTP Client instances. It covers the builder pattern implementation, including initialization, configuration of redirects, cookies, server push, and custom connectors. The documentation also details HTTP/2 protocol settings, network proxy configuration, and connection management features like timeouts and TLS. It is suitable for software developers and system integrators who need to instantiate and fine-tune HTTP clients with specific behaviors, security settings, and performance constraints in Cangjie applications.
