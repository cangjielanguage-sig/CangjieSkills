This directory serves as a comprehensive resource for the `ohos.ark_interop_helper` module, specifically designed to facilitate interoperability between ArkTS and native code using the Cangjie language. It provides detailed API references for common helper functions that enable developers to handle complex data mapping, type conversions, and context management within the ArkUI framework. Key topics include converting HashMap data to JSValue, managing Stage and FA contexts, and detecting application modes. This documentation is essential for HarmonyOS developers utilizing SystemCapability.ArkUI.ArkUI.Napi who need to bridge the gap between ArkTS UI components and native NAPI logic efficiently, starting from API version 12.
