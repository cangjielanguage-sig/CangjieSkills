This directory contains API documentation for the `SatelliteStatusInfo` class within the Cangjie language framework, specifically designed for GNSS (Global Navigation Satellite System) location services. It provides comprehensive details on encapsulating satellite status data, including satellite count, IDs, altitudes, azimuths, carrier frequencies, and noise density. The documentation covers the class properties and its constructor, specifying data types, valid ranges, and system capabilities. This resource is suitable for developers working on location-based applications, navigation systems, or positioning tools who require access to raw GNSS satellite data structures in the Cangjie environment. It ensures developers understand the necessary system capabilities and version requirements (API 19+) for implementation.
