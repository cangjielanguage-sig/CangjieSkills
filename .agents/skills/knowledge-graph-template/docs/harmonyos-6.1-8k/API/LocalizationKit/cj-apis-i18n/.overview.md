## Detailed Description

### ohosi18n国际化-I18n/

This directory contains Cangjie language API reference documentation regarding Internationalization (I18n) in HarmonyOS application development. Content mainly covers system-level internationalization capabilities, including obtaining application preferred languages, calendar type enumeration definitions, calendar object acquisition, and date-time localization processing. Core functions involve detailed usage methods of the System class, CalendarType enumeration, getCalendar function, and Calendar class. This document integrates LocalizationKit capabilities, aiming to help developers using the Cangjie language implement multi-language support, multi-calendar systems, and precise date-time localization functions, suitable for engineering technicians engaged in HarmonyOS internationalization application development.

**Key components covered in this section include:**
*   **System Class:** For managing system-level I18n settings.
*   **CalendarType Enumeration:** Defining various calendar systems.
*   **getCalendar Function:** Mechanisms for retrieving calendar instances.
*   **Calendar Class:** Handling date and time localization.

This documentation is particularly valuable for engineering technicians engaged in HarmonyOS internationalization application development, providing the technical depth required for enterprise-grade global applications.
