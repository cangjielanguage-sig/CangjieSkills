# UIAbility组件启动模式

This directory focuses on the launch modes of UIAbility components in HarmonyOS development. It comprehensively covers how system instances are managed during startup, specifically detailing singleton, multiton, and specified modes. Key topics include lifecycle callbacks (onNewWant, onCreate), configuration via module.json5, and instance management strategies for different scenarios like document editing. This resource is suitable for HarmonyOS application developers looking to configure component behavior, optimize resource management, and implement precise instance control using the AbilityKit API and Cangjie programming language.

## Detailed Description

The following resources provide in-depth technical guidance on configuring and managing UIAbility launch modes.

### UIAbility组件启动模式_3more.md UIAbility组件启动模式_3more.md
This technical guide explains the launch modes of UIAbility components in HarmonyOS development, detailing how instances are managed during startup. It covers the singleton (default) and multiton modes, explaining their behavior, lifecycle callbacks like onNewWant, and configuration via module.json5. Key takeaways include that singleton reuses existing instances to maintain a single entry in recent tasks, while multiton creates a new instance for every startAbility call. Targeted at application developers configuring component behavior, this document requires knowledge of the AbilityKit API and JSON configuration.
