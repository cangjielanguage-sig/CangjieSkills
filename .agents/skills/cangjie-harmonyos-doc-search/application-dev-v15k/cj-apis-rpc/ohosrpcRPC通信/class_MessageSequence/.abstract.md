This directory contains API reference documentation for the Cangjie `MessageSequence` class, a core component of the IPC Kit designed for data serialization and deserialization in RPC or IPC scenarios. It covers a comprehensive set of methods for managing data buffers, reading and writing various data types (including primitives, arrays, strings, and file descriptors), and handling memory metrics. The documentation is intended for Cangjie developers implementing inter-process communication who need to efficiently transmit and parse data between processes. Key topics include buffer management, file descriptor handling, and error codes like BusinessException.
