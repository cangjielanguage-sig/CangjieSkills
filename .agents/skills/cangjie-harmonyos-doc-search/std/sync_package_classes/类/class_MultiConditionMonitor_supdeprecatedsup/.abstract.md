This directory provides comprehensive API documentation for the deprecated `MultiConditionMonitor` class and its related synchronization functions in the Cangjie programming language. It details advanced concurrency control patterns, specifically focusing on the architecture that allows multiple condition variables to be bound to a single reentrant mutex. The content encompasses class definitions, inheritance hierarchies, and essential methods for thread management, such as waiting, notifying, and handling timeouts. Critical topics include the use of ConditionID instances for identifying wait queues and managing IllegalSynchronizationStateException errors. This documentation is tailored for experienced developers who are maintaining complex legacy synchronization code or seeking to understand the underlying mechanics before migrating to the recommended `Mutex` standard.
