This directory provides API reference documentation for the `LocaleOptions` struct in the Cangjie programming language. It focuses on defining configuration parameters for locale initialization, a fundamental aspect of implementing internationalization (I18n) features. The documentation covers the constructor signature used to build objects and details the public properties available for customization, including calendar types, collation rules, hour cycles, and numbering systems. It is intended for developers working with the SystemCapability.Global.I18n module (version 19+) who need to customize date formatting, sorting behaviors, and numeral systems for global applications. Understanding these options is essential for ensuring applications behave correctly across different locales and cultural contexts.
