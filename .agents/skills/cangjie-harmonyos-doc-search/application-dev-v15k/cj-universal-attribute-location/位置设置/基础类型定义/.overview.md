# 基础类型定义

This directory contains API reference documentation for fundamental layout and alignment types within the Cangjie ArkUI framework. It covers classes and structures essential for defining alignment rules, anchor points, bias offsets, and chain styles in relative containers. Key topics include `AlignRuleOption`, `Bias`, `HorizontalAnchor`, `VerticalAnchor`, and localized alignment parameters for internationalization. These definitions are crucial for developers building responsive and adaptive user interfaces in HarmonyOS applications, providing the necessary tools for precise component positioning and layout management.

## Detailed Description

### class_AlignRuleOption.md class_AlignRuleOption.md
This API reference document details the AlignRuleOption class used to define alignment rules for child components within relative containers in the Cangjie ArkUI framework. The documentation covers the class constructor and seven public properties: left, right, middle, top, bottom, center, and bias. Key information includes the use of HorizontalAnchor, VerticalAnchor, and Bias types to control positioning and offset ratios, with all parameters defaulting to None. Intended for UI developers, this guide facilitates precise layout management using ArkUI system capabilities.

### class_Bias_2more.md class_Bias_2more.md
This API reference document defines the Bias and HorizontalAnchor classes for the Cangjie language within the ArkUI framework. It details the Bias class, which sets component offset parameters as ratios relative to anchor points, and the HorizontalAnchor class, which configures horizontal alignment using specific component IDs. Key information includes the constructors, property types like ?Float32 and HorizontalAlign, and default values for bias parameters. Both classes support SystemCapability.ArkUI.ArkUI.Full starting from version 12. This documentation targets developers implementing complex layout constraints and anchor-based positioning in HarmonyOS applications.

### class_LocalizedHorizontalA_4more.md class_LocalizedHorizontalA_4more.md

This technical reference is intended for developers building user interfaces in HarmonyOS, requiring knowledge of Cangjie syntax and ArkUI layout principles.

### class_LocalizedAlignRuleOptions/
