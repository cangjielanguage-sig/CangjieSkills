## 目标方开发步骤

1. 为了能够支持被其他应用通过mailto协议拉起，目标应用需要在[module.json5配置文件](../cj-start/basic-knowledge/module-configuration-file.md)中声明mailto。

    ```json
    {
      "module": {
        // ...
        "abilities": [
          {
            // ...
            "skills": [
              {
              "actions": [
                  "ohos.want.action.sendToData"
                ],
                "uris": [
                  {
                    "scheme": "mailto",
                    // linkFeature 用于适配垂类面板拉起
                    "linkFeature": "ComposeMail"
                  }
                ]
              }
            ]
          }
        ]
      }
    }
    ```

2. 目标应用在代码中取出uri参数进行解析。

    ```cangjie
    import kit.AbilityKit.{UIAbility, Want, LaunchParam}

    class MainAbility <: UIAbility {
        public override func onCreate(want: Want, launchParam: LaunchParam): Unit {
            // 应用冷启动生命周期回调，其他业务处理...
            parseMailto(want)
        }

        public override func onNewWant(want: Want, launchParam: LaunchParam): Unit {
            // 应用热启动生命周期回调，其他业务处理...
            parseMailto(want)
        }
    ```
