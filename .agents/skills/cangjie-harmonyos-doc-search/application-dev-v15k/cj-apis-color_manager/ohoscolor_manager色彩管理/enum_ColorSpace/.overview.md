# enum_ColorSpace

This directory contains API reference documentation for the `ColorSpace` enum within the ArkGraphics2D framework, specifically designed for the Cangjie language. It comprehensively defines standard color gamut types used in graphics rendering, such as SRGB, DCI-P3, and various BT standards. The documentation details critical attributes including RGB gamut, transfer functions (Linear, HLG, PQ, Gamma), and encoding ranges (Full, Limit). Additionally, it covers utility methods for parsing and string representation. This resource is suitable for graphics developers working on 2D graphics applications who need to manage color space conversions, display configurations, and ensure accurate color management across different system capabilities.
