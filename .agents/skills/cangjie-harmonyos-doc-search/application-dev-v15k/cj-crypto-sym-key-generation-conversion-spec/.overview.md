# cj-crypto-sym-key-generation-conversion-spec

This directory provides the essential technical specification for symmetric key generation and conversion within the system. It comprehensively outlines the supported cryptographic algorithms, including AES, 3DES, SM4, and HMAC, while detailing the precise string parameters required to generate keys of various lengths. It is specifically designed for developers implementing cryptographic functions who need to ensure correct parameter formats for key generators.
