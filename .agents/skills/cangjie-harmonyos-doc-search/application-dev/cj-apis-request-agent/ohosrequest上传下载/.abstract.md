This directory contains comprehensive API documentation for the HarmonyOS `ohos.request` module, specifically designed for the Cangjie programming language. It covers the `SystemCapability.Request.FileTransferAgent` system capability, enabling developers to implement robust file upload and download functionalities. Key topics include task configuration, lifecycle management, progress tracking, event handling, and network constraints. The documentation details essential classes like `Task`, `Config`, and `Progress`, alongside enumerations for states, actions, and error codes. It is suitable for Cangjie developers building HarmonyOS applications that require efficient background and foreground file transfer operations.
