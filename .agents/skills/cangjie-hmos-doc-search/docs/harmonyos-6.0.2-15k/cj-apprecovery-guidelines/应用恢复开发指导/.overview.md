# 应用恢复开发指导

This directory serves as a comprehensive guide for implementing application recovery mechanisms to prevent data loss and enhance user experience during unexpected errors. It covers the fundamental principles of state restoration, the default system behavior upon crashes, and the specific technical implementation using the AbilityStage and onSaveState interfaces. Key topics include Application Recovery, State Restoration, Exception Handling, and the AbilityKit framework. This resource is suitable for application developers, particularly those working within the Cangjie language ecosystem, who aim to build resilient applications with robust error handling and seamless data persistence capabilities.

## Detailed Description

### 场景介绍.md 场景介绍.md
This document introduces the application recovery scenario to prevent data loss and improve user experience when unexpected errors occur. It covers the causes of unexpected application exits, the default system behavior, and the mechanism for restoring application state and data upon restart. Key information includes enabling the application recovery feature in AbilityStage and saving temporary data via the onSaveState interface, which allows the system to restore the page stack and user data after a crash. This guide targets application developers looking to implement robust error handling and state persistence within the framework. Keywords: Application Recovery, AbilityStage, State Restoration, Exception Handling, User Experience, onSaveState.

### 开发示例/
This directory provides a specialized collection of development examples and technical guides dedicated to enhancing application resilience and stability within the Cangjie language ecosystem. It focuses on critical mechanisms for enabling self-recovery features and implementing robust data saving and restoration processes to handle unexpected application behaviors. The content covers the integration of the AbilityKit framework, detailed configuration of `module.json5` manifest files, and the utilization of specific lifecycle methods such as `onCreate` and `onSaveState`. Developers will find instructions on calling `enableAppRecovery`, managing `Want` parameters, and handling restart markers like `ABILITY_RECOVERY_RESTART`. These resources are specifically designed for application developers familiar with Cangjie syntax and lifecycle management who need to ensure data persistence and seamless user experience restoration in their projects.

### 接口说明/
This directory provides comprehensive documentation for application fault management and recovery interfaces. It covers the mechanisms for application recovery, state management during freezes, and specific API references for the `appRecovery` module. Key topics include `APP_RECOVERY`, `onSaveState`, `errorManager`, and fault handling workflows for various crash types. It is suitable for application developers seeking to implement robust error handling, state restoration, and automatic recovery features to ensure application stability and data integrity.
