# 基础播控

This directory provides technical guides for implementing core playback control features in media applications. It covers essential aspects such as displaying media metadata (covers, titles, subtitles), managing playback states (play, pause, progress), and handling advanced controls like favorites and loop modes. The documentation focuses on integrating with the system's playback control center using AVSessionKit and AVMetadata. It is suitable for application developers seeking to ensure a consistent and high-quality user experience across the system interface for music, video, and audiobook apps.

## Detailed Description

### 副标题_7more.md 副标题_7more.md
This technical guide instructs developers on configuring media metadata and playback controls within the system's playback control center. Key topics include displaying subtitles and synchronized lyrics using AVMetadata, identifying special audio sources, and managing playback states like play, pause, and track switching. The document explains how to synchronize application states with the control center, handle unsupported commands by graying out buttons, and implement navigation from the control card to the app's playback page. Intended for application developers integrating AVSessionKit, this guide ensures a consistent user experience by detailing specific API usage and interaction logic for media applications.

### 媒体封面_2more.md 媒体封面_2more.md
This technical guide instructs developers on implementing and optimizing media covers and main titles within an application's playback interface. It details specifications for media covers using AVMetadata.mediaImage and main titles using AVMetadata.title. Key information includes specific aspect ratio requirements: music covers must be 1:1 (recommended 800x800px), while video supports 13:18 and 16:9 ratios. Mismatched images are automatically cropped, and PixelMap is recommended for performance. Titles should be concise, with long text scrolling automatically. This guide targets application developers integrating media playback features who need to ensure visual consistency in the playback control center.

### 收藏_3more.md 收藏_3more.md
This technical guide instructs developers on adapting advanced playback control features—specifically Favorites, Loop Modes, and Fast Forward/Rewind—within the system's playback control center for media applications. The document details three main features: synchronizing "Favorite" states, managing playback loop modes (including mapping custom modes to standard ones), and implementing skip intervals for long-form content. Key takeaways include the necessity of bidirectional state synchronization between the application and the control center via AVSession callbacks, ensuring UI consistency. Custom loop modes must be mapped to system-defined modes like random play. This guide targets developers of music or audiobook applications integrating AVSession to enhance user experience during playback.

### 进度与时间.md 进度与时间.md
This technical guide outlines how to implement and manage media playback progress within a control center. It categorizes progress display into three types: draggable, non-draggable, and unavailable, based on app capabilities. Key sections cover progress control logic, emphasizing state updates via AVPlayBackState rather than real-time setting, and handling specific scenarios like buffering and seeking. The document also details complex logic for VIP trials and advertisements, explaining how to manage duration and timestamps to ensure correct user experience. It targets developers integrating media session APIs.
