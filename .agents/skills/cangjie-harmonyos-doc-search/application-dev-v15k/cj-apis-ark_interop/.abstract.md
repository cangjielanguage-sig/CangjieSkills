This directory serves as the comprehensive documentation hub for the `cj-apis-ark_interop` project, specifically focusing on the `ohos.ark_interop` library. It is an essential resource for developers operating within the HarmonyOS ecosystem, providing the necessary tools and references to achieve seamless interoperability between the Cangjie language and ArkTS (TypeScript/JavaScript). The content covers a wide array of technical functionalities, including type conversion, runtime management, object manipulation, and asynchronous operations powered by the Napi framework. By offering detailed guidance on handling arrays, functions, promises, and modules, this documentation enables Cangjie developers to build sophisticated native modules and cross-language applications. It is particularly suitable for those requiring efficient data exchange and precise execution control between native environments and the ArkTS runtime, ensuring high performance and stability in hybrid development scenarios.
