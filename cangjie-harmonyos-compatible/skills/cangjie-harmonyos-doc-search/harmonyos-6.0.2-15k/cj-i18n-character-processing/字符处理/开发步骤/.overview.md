# 开发步骤

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language, specifically focusing on the LocalizationKit to implement advanced internationalization (i18n) features. The content covers critical text processing tasks, including analyzing character properties (such as identifying digits or ideographs), performing text transliteration (like converting Chinese to Pinyin), and applying character normalization using standard forms like NFC and NFD. Additionally, it addresses text segmentation for locale-specific line breaking. These guides are designed for Cangjie developers seeking to build applications with robust multilingual support, ensuring text data is handled, standardized, and displayed correctly across different languages and regions.

## Detailed Description

Below are the detailed guides covering specific implementation steps and API usage for these text processing features.

### 字符属性_2more.md 字符属性_2more.md
This development guide explains how to utilize the LocalizationKit in the Cangjie programming language to analyze character properties and perform text transliteration. The document covers two main topics: Character Properties and Transliteration. The first section details identifying character types like digits, right-to-left scripts, and ideographs using the Unicode class. The second section covers converting text, specifically Chinese characters to Pinyin, using the Transliterator class with various rules such as tone removal or name pronunciation. Key takeaways include the usage of APIs like isDigit, isIdeograph, getInstance, and transform, along with the limitation that Chinese transliteration cannot handle context-sensitive polyphones. This tutorial targets Cangjie developers implementing internationalization features.

### 字符标准化_2more.md 字符标准化_2more.md
This technical guide provides step-by-step instructions for implementing character normalization and line breaking using the Cangjie LocalizationKit. It covers two primary functionalities: character normalization using the Normalizer class with forms like NFC and NFD, and text segmentation using the BreakIterator class for locale-specific line breaking. Key information includes API usage details such as object instantiation, method calls like normalize and next, and executable Cangjie code examples. Targeted at Cangjie developers working on internationalization, this document explains how to handle text standardization and formatting rules effectively.
