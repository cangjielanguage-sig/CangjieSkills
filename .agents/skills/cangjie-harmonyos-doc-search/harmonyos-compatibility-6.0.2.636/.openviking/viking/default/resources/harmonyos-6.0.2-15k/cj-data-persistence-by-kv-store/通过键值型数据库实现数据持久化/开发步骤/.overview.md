# 开发步骤

This directory provides comprehensive technical tutorials for developing Key-Value (KV) database applications using the Cangjie programming language and the ArkData kit. It covers the full spectrum of data management operations, ranging from initializing the KVManager and configuring SingleKVStore options to executing standard CRUD operations like put, get, and delete. Additionally, it addresses advanced lifecycle management tasks such as closing connections and permanently deleting stores. Key concepts include security level configuration, exception handling via try-catch blocks, and logging mechanisms. These resources are tailored for application developers building on the HarmonyOS framework who require efficient persistent or distributed data storage solutions.

## Detailed Description

### 开发步骤_1.md
This document provides a step-by-step tutorial for implementing a Key-Value (KV) database using the Cangjie programming language and the ArkData kit. The content covers seven distinct development stages: obtaining a KVManager instance, creating a SingleKVStore with specific options, inserting data using put(), retrieving values with get(), deleting specific entries, and managing database lifecycle through closing and deletion operations. Key takeaways include the configuration of security levels, error handling via try-catch blocks, and the behavior of put() in updating existing keys. This guide targets application developers who require persistent or distributed data storage solutions and assumes familiarity with Cangjie syntax and the HarmonyOS or similar application framework.

### 开发步骤_2.md
This document serves as a code tutorial demonstrating how to delete a Key-Value (KV) store using the Cangjie programming language. The content focuses on the implementation of the `deleteKVStore` method, specifically highlighting the syntax for invoking the operation via `kvManager` and handling potential runtime errors. Key information includes the use of a `try-catch` block to manage `BusinessException`, logging success messages with `AppLog.info`, and capturing error codes and messages upon failure. This snippet is intended for Cangjie developers managing application data persistence, requiring prior knowledge of the language's syntax and the KV management API. Keywords: Cangjie, KV store, deleteKVStore, exception handling, data management, AppLog.
