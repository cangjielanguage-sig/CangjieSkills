# ohosaccount_distributedAccount分布式账号管理

This directory contains API reference documentation for the `ohos.account_distributedAccount` module in the Cangjie programming language. It focuses on managing distributed account login states, handling account lifecycle events, and encapsulating account information structures. Key components include the `DistributedAccountAbility` class for state management, the `DistributedInfo` class for data encapsulation, and enumerations for status and events. This documentation is suitable for system application developers working on OpenHarmony or HarmonyOS who need to implement distributed account features, requiring knowledge of Cangjie syntax and the BasicServicesKit.

The content details the class structure, focusing on read-only properties such as account name, ID, event type, nickname, avatar, status, and scalable data. This documentation targets developers implementing distributed account features within the SystemCapability.Account.OsAccount framework, providing the necessary data structures to manage account states and user profiles across devices.
