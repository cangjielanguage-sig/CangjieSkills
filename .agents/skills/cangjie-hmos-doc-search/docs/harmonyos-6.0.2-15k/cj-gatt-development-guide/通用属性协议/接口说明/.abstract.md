This directory provides comprehensive technical documentation for Bluetooth Low Energy (BLE) Generic Attribute Profile (GATT) interfaces, specifically tailored for the Cangjie programming language within the ConnectivityKit framework. It serves as a central hub for developers seeking to implement robust Bluetooth connectivity features, offering detailed API references, instance code examples, and structured overviews of interface specifications. The content covers both client and server roles, addressing connection management, service discovery, and data operations. This resource is primarily suitable for software developers and engineers working on BLE communication protocols who require precise technical guidance to integrate central and peripheral device interactions into their Cangjie applications.
