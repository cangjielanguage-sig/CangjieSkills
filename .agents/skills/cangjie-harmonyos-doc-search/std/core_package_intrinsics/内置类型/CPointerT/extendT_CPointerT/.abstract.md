This directory contains API documentation for the `extend<T> CPointer<T>` extension in the Cangjie language, specifically designed to facilitate robust C interoperability and low-level memory management. It provides a comprehensive guide to essential interfaces for pointer manipulation, including resource management mechanisms like `asResource`, safety checks for null validation, and methods for data reading and writing. The documentation also delves into pointer arithmetic and address conversion, highlighting the necessity of unsafe contexts to prevent undefined behavior. This resource is suitable for systems programmers and developers working on Foreign Function Interface (FFI) tasks who require precise control over memory allocation, automatic resource cleanup, and direct pointer operations similar to those in the C language. By mastering these APIs, developers can safely integrate C libraries and manage memory lifecycles effectively within the Cangjie environment.
