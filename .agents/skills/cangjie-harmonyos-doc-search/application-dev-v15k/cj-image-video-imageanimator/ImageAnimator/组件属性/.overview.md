# 组件属性

This directory serves as a specialized repository for API reference documentation concerning component properties within the ArkUI framework, explicitly designed for the Cangjie programming language. It provides in-depth technical guidance on configuring and manipulating animation behaviors, which are critical for creating engaging user experiences. The documentation encompasses a wide array of functionalities, ranging from the granular control of image frame animations—such as setting duration, defining fill modes, and managing frame sequences—to the broader management of animation playback states. By detailing function signatures, parameter tables, and system capabilities, these documents enable precise control over UI dynamics. This resource is essential for Cangjie developers, UI engineers, and system architects who are tasked with implementing sophisticated animation logic and ensuring smooth state transitions in their applications, particularly those targeting newer versions of the ArkUI system.

### func_durationInt32_7more.md func_durationInt32_7more.md
This document provides API reference documentation for configuring image frame animations within the ArkUI framework using the Cangjie language. It details seven key functions used to control playback behavior, including duration, fill mode, sizing, frame sequences, iterations, pre-decoding, and reverse playback. Key takeaways include the interaction between fillMode and reverse for determining end states, the priority of individual frame durations over global settings, and the static nature of the image array. This reference is intended for developers implementing custom image animation components, requiring knowledge of Cangjie syntax and ArkUI system capabilities.

This technical documentation is intended for Cangjie developers seeking to manage animation states in their applications, specifically targeting version 19 and above.
