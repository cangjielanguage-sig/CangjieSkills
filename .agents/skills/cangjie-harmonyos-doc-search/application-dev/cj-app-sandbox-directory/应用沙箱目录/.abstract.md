This directory provides comprehensive technical documentation on the application sandbox mechanism within the OpenHarmony environment. It covers the core concepts of file isolation, path mapping between virtual sandbox views and physical file systems, and data security protocols. Key topics include encryption levels (EL1-EL5), access permissions, and the distinction between App-level and HAP-level storage. This resource is essential for application developers and system integrators seeking to implement secure data handling, manage file persistence, and understand the architectural nuances of sandboxed file access.
