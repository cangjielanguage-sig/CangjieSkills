# 类

This directory contains API reference documentation for core classes within the Cangjie unittest framework. It primarily focuses on configuration management and text formatting utilities. Key components include classes for handling test configuration data (`Configuration`, `ConfigurationKey`) and tools for generating structured, readable console output (`PrettyText`, `PrettyPrinter`). These resources are designed for Cangjie developers who need to programmatically manage test settings or implement custom reporting and output formatting in their unit testing workflows.

## Detailed Description

### class_Configuration.md class_Configuration.md
This API documentation defines the Cangjie Configuration class, which stores unittest configuration data generated by the @Configure macro. The document details the class structure, constructor, and methods for managing key-value pairs using generic types. Key functionalities include retrieving, setting, and removing values via KeyFor or String keys, cloning instances, and a static merge function that combines configurations with child values overriding parent ones. It also explains the toString implementation. This reference guide targets Cangjie developers working with the unittest framework who need to programmatically handle test configuration data.

### class_ConfigurationKey.md class_ConfigurationKey.md
This document provides API reference documentation for the Cangjie language class ConfigurationKey, which serves as a key object for configuration items. It details the class definition, properties like name, operator overloads for equality and inequality, the hashCode method, and an extension containing a static create function. Key information includes that the class inherits from Equatable and Hashable, enabling comparison and hashing capabilities, while the create function allows instantiation with a specific name and generic type. This reference guide targets Cangjie developers implementing or interacting with configuration management systems.

### class_PrettyText.md class_PrettyText.md
This document provides API reference documentation for the Cangjie PrettyText class, which serves as a storage mechanism for printed output to facilitate intermediate data handling. The content covers the class definition, its inheritance from PrettyPrinter, PrettyPrintable, and ToString, and details its constructors and member functions. Key information includes methods for checking emptiness, printing to other printers, converting to strings, and a static factory method of for creating instances from PrettyPrintable objects. This guide is intended for Cangjie developers utilizing the unit testing framework who require flexible text formatting and output capture capabilities.

### class_PrettyPrinter/
This directory contains comprehensive API reference documentation for the Cangjie `PrettyPrinter` class, a utility designed for generating formatted text output. It covers core functionality including indentation control, text alignment (left, center, right), color application, and line break management. The documentation details the class constructor, properties like `isTopLevel`, and various `append` methods, including support for closures to scope formatting effects. This resource is essential for Cangjie developers, particularly those working on unit testing or building tools that require structured, readable console output.
