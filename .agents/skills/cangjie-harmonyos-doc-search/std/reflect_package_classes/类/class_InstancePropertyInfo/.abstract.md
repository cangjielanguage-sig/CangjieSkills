This directory contains API reference documentation for the `InstancePropertyInfo` class within the Cangjie programming language's reflection package. It provides comprehensive details on metadata for instance member properties, covering class definitions, inheritance hierarchies, and core properties like annotations and modifiers. The content also explains methods for runtime manipulation, including retrieving and setting property values, as well as introspection capabilities. This documentation is suitable for Cangjie developers who need to programmatically inspect program structure and dynamically interact with object properties using reflection.
