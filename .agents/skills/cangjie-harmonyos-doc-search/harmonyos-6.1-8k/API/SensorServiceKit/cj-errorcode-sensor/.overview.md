# cj-errorcode-sensor

本目录专门用于存放传感器模块的错误码定义文档，旨在为开发者提供系统化的故障诊断与处理指南。文档内容聚焦于传感器运行时可能遇到的特定异常情况，详细定义了诸如传感器服务异常及设备硬件不支持等关键错误码。通过阅读本文档，开发者可以了解错误的具体含义、产生的潜在原因以及推荐的解决步骤，例如利用定时重试机制处理HDI服务故障，或通过特定接口检测硬件兼容性。该文档主要面向使用传感器API进行应用开发的工程师，建议读者具备一定的HDI服务及传感器接口基础知识，以便更好地理解和应用这些错误码。

## 详细说明

### cj-errorcode-sensor.md cj-errorcode-sensor.md
本文档定义了传感器模块特有的错误码，旨在帮助开发者诊断和处理运行时问题。文档主要涵盖两个错误码：14500101（传感器服务异常）和14500102（设备不支持该传感器），详细说明了错误信息、描述、可能原因及处理步骤。关键信息包括通过定时重试机制处理HDI服务异常，以及利用GetSingleSensor接口识别硬件不支持的传感器，区分了服务故障与硬件兼容性问题。本文档属于参考手册，面向使用传感器API的开发者，需具备HDI服务及传感器接口的基础知识。
