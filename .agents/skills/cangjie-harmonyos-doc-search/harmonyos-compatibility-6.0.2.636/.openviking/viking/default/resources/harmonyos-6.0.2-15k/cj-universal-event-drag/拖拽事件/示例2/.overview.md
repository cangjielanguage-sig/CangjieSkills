# 示例2

This directory contains code examples focused on implementing drag-and-drop functionality in UI components. It covers essential concepts such as state management, event handling (onDragStart, onDragEnter, onDragMove, onDragLeave, onDrop), and customizing drag visuals using builders or PixelMap generation. The examples demonstrate how to manage drag interactions within general UI components and specifically within List components. Suitable for developers working with the Cangjie language and HarmonyOS ArkUI framework who need to implement complex interactive features and understand event-driven UI logic.

## Detailed Description

### 示例2_1.md
This document provides a Cangjie code example demonstrating the implementation of drag-and-drop functionality within a UI component. Main sections cover state management, event handling using onDragStart, and customizing drag visuals through builders or PixelMap generation. Key takeaways include how to hide source elements during drag, update status text with event coordinates, and construct DragItemInfo using either a custom builder function or a programmatically created PixelMap. The intended audience is developers working with the Cangjie language and HarmonyOS UI framework who need to implement complex interaction features.

### 示例2_2.md
This document serves as a code example demonstrating the implementation of drag-and-drop functionality within a List component using ArkUI syntax. The primary topics covered include configuring the List with edit mode enabled, generating ListItems via ForEach, and attaching specific event handlers like onDragStart, onDragEnter, onDragMove, onDragLeave, and onDrop. Key information includes how to capture and log event parameters such as coordinates and extra data during the drag process. This example is designed for developers seeking to understand interactive UI event handling and state management in application development.
