# enum_ExtensionAbilityType

本目录包含关于 `ExtensionAbilityType` 枚举的 API 参考文档，详细定义了系统中可用的各种扩展能力类型。内容涵盖了后台服务、数据共享、无障碍服务、输入法、壁纸、窗口管理等多种组件的功能描述、系统能力要求及使用限制（如部分能力仅限系统应用）。该文档基于仓颉语言，适用于需要在 BundleFramework 中配置和使用系统扩展能力的应用开发者，旨在帮助开发者实现后台逻辑、设备管理及嵌入式 UI 等功能。

## 详细描述

### Service_8more_a7bd5ddf.md
本文档是一份API参考文档，旨在定义系统中可用的各种扩展能力类型及其功能。主要涵盖了Service、Share、StaticSubscriber、Thumbnail、Unspecified、Wallpaper、Window和WorkScheduler八个部分。关键信息包括每个类型的具体功能描述，例如后台服务、分享业务、静态广播处理及延时任务等，以及它们所属的系统能力BundleFramework.Core和起始版本22。值得注意的是，Thumbnail、Wallpaper和Window等部分能力预留仅系统应用支持。该文档主要面向使用仓颉语言进行应用开发，需要调用特定系统扩展能力或处理后台逻辑的开发者。

### enum_ExtensionAb_15more_607a313f.md
本文档是Cangjie语言中ExtensionAbilityType枚举的API参考，定义了系统中可用的扩展组件类型。文档详细列出了Accessibility、InputMethod、Driver、DataShare和EnterpriseAdmin等枚举成员，解释了它们在无障碍服务、输入法开发、外设驱动及设备管理等方面的功能。关键信息包括系统能力要求、起始版本22以及特定使用限制，例如AdsService仅限系统应用使用。本文档面向需要在BundleFramework中配置和使用各种扩展能力的应用开发者，为实现数据共享、备份恢复及嵌入式UI等功能提供了必要的定义和规范。
