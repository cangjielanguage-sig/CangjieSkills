# API_列表

This directory serves as a comprehensive API reference for a unit testing framework, detailing essential components for test configuration, data management, and output formatting. It covers core functionalities such as option validation, parametrized testing via DataStrategy interfaces, and configuration storage. Additionally, it documents supplementary data structures, exception handling mechanisms, and internal state variables. This documentation is designed for developers looking to extend the framework, customize test execution, or understand the underlying data models and error handling logic. It provides a technical guide for navigating the framework's common package APIs and internal architecture.

## Detailed Description

### 函数_4more.md

This document provides an API reference for common utilities and components within a unit testing framework. It is organized into four main categories: functions, interfaces, classes, and enums. Key topics include option validation and metadata management via functions, parametrized testing support through DataStrategy interfaces like DataProvider and DataShrinker, and configuration storage using the Configuration class. Additionally, it covers output formatting with PrettyPrinter and PrettyText classes. The document targets developers seeking to configure tests, manage test data, or customize output formatting, serving as a technical guide for the framework's common package APIs.

### 结构体_3more.md

This document acts as a reference guide for supplementary data structures, exception classes, and internal variables within a unit testing framework's API. It details specific structures like OptionInfo for help page options and KeyTags for configuration keying, alongside the UnittestOptionValidationException for validation errors. Additionally, it lists internal constants such as optionsInfo and unittestOptionsRegistryClosed, which manage option registries and are restricted to framework-internal use. The content is organized into tables linking to detailed definitions, serving developers who need to understand the framework's data models, error handling mechanisms, and internal state management.
