# cj-camera-overview

This directory provides a comprehensive high-level overview of Camera Kit, designed specifically for developers who need to integrate camera hardware and APIs into their applications. It serves as a foundational guide, explaining the core architecture and workflows necessary for building robust camera features. The content covers essential development scenarios, clearly distinguishing between the complexities of custom camera development and the simplified approach using CameraPicker. It details the camera development model, focusing on the management of inputs, sessions, and outputs. Key topics include the workflow for data capture, session configuration for parameters like focus and exposure, and output handling for previews, photos, and videos. Additionally, it describes the underlying data transmission mechanisms via HDI and BufferQueue. This resource is suitable for developers seeking a conceptual understanding before diving into specific implementation guides.
