This directory provides a comprehensive technical overview of API tagging and management strategies specifically tailored for the Cangjie programming language. It centers on the practical application of the `@IfAvailable` attribute, which serves as a critical tool for achieving fine-grained control over code availability and execution paths. The documentation addresses the significant challenges associated with developing for a fragmented ecosystem of devices by explaining how to implement conditional code execution based on specific API levels and System Capabilities (syscap). By thoroughly covering advanced technical aspects such as macro expressions, lambda usage, compile-time scope restrictions, and runtime behavior—including the logic behind intersection and union rules—it equips developers with the necessary knowledge to build robust, adaptable applications. Furthermore, it provides essential guidance on handling weak symbols and managing implicit package imports. This resource is ideally suited for Cangjie developers working within the DevEco Studio environment who are dedicated to maintaining strict version compatibility, preventing compilation errors, and efficiently managing feature support across a wide array of system configurations.
