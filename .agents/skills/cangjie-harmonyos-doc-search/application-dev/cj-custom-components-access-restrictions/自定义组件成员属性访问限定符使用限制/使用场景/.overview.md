# 使用场景

This directory serves as a technical guide for developers using the Cangjie ArkUI framework, specifically focusing on the constraints and validation rules governing state management. It details the compatibility requirements between various access modifiers (such as `private` and `public`) and state management macros (including `@State`, `@Link`, `@StorageLink`, and others). By providing comparative code examples that highlight common compiler errors versus correct syntax, these documents help developers navigate access control restrictions. This resource is essential for Cangjie developers aiming to implement robust state management in their ArkUI applications while avoiding syntax pitfalls.

## Detailed Description

### 使用场景_1.md

This document outlines validation rules for combining access modifiers with state management macros in the Cangjie ArkUI framework. It details two specific scenarios: the incompatibility of the `private` modifier with `@State`, `@Prop`, `@Provide`, and `@BuilderParam`, and the incompatibility of the `public` modifier with `@StorageLink`, `@StorageProp`, `@LocalStorageLink`, `@LocalStorageProp`, and `@Consume`. The text provides comparative code examples, highlighting incorrect usage that triggers compiler errors versus correct implementation. This guide targets Cangjie developers working on ArkUI applications who need to understand access control restrictions for state variables.

### 使用场景_2.md

This document clarifies a specific compiler constraint in Cangjie ArkUI development regarding the usage of the `@Link` decorator with access modifiers. It covers the conflict between the `@Link` state management macro and the `private` access qualifier within custom components. The key takeaway is that member variables decorated with `@Link` cannot be declared private, as this triggers a compilation error. The document provides a counter-example demonstrating the error and a corrected example showing the proper syntax without the private modifier. This guide targets Cangjie developers using ArkUI who need to understand state management rules and avoid common syntax errors.
