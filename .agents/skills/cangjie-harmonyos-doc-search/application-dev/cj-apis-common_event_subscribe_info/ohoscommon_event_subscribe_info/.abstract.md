This directory contains API reference documentation for the `ohoscommon_event_subscribe_info` module within the HarmonyOS Cangjie development environment. It focuses on the `CommonEventSubscribeInfo` class, which is essential for defining subscriber information for common events. Key topics include event filtering, priority management, and publisher-specific configurations like permissions and bundle names. The documentation covers constructor parameters, property ranges, and usage instructions for integrating these features into application code. This resource is suitable for application developers working with system notifications and event handling in Cangjie who need to configure precise subscription criteria.
