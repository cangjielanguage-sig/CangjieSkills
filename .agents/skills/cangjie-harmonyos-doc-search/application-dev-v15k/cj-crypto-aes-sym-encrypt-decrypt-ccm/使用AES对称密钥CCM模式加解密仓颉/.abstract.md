This directory provides a comprehensive technical collection focused on implementing AES symmetric encryption and decryption using the CCM (Counter with CBC-MAC) mode within the Cangjie programming language. It covers the entire cryptographic lifecycle, from generating 128-bit symmetric keys to initializing Cipher instances with specific parameters like CcmParamsSpec. The documentation highlights critical operational constraints of CCM mode, such as the lack of support for segmented operations and the mandatory extraction of a 12-byte authentication tag for verification. These resources are specifically designed for Cangjie developers who possess a working knowledge of the CryptoArchitectureKit and need precise, code-level instructions for securing data through authenticated encryption mechanisms. By following these guides, developers can effectively manage cryptographic keys and handle the nuances of authenticated encryption in their applications.
