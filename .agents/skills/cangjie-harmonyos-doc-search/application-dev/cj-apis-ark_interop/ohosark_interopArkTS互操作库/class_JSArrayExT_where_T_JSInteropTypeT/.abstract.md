This directory contains API reference documentation for the Cangjie programming language's `JSArrayEx` class, designed for declarative interoperability with ArkTS Array types. It covers essential class definitions, initialization methods, and array manipulation functions such as cloning, merging, and element access. The documentation details syntax, parameters, return types, and specific error handling for thread mismatches and access violations. It is suitable for Cangjie developers implementing cross-language features and type-safe data manipulation between Cangjie and ArkTS environments.
