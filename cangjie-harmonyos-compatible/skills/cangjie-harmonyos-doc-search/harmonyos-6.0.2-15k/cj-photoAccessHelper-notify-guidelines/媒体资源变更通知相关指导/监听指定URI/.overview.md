# 监听指定URI

This directory provides comprehensive technical documentation for HarmonyOS developers focusing on real-time data monitoring within the photo library. It specifically addresses how to register listeners for specific URIs, including user albums and individual PhotoAssets, utilizing the Cangjie programming language. The guides cover essential prerequisites such as obtaining the `photoAccessHelper` instance and managing necessary read/write permissions. By following these tutorials, developers can implement robust callback mechanisms to track state changes like renaming or deletion, ensuring their applications remain synchronized with the user's media data. This resource is ideal for those building dynamic, media-rich applications requiring immediate updates on file system changes.

## Detailed Description

### 对指定Album注册监听.md 对指定Album注册监听.md
This file focuses on album-level monitoring. This tutorial guides developers on registering a listener for a specific album to receive callbacks when changes occur. It covers prerequisites like obtaining the photoAccessHelper instance and requesting necessary permissions. The document details the development steps: fetching a user album, registering the listener, and triggering a change via renaming. Key information includes Cangjie code examples demonstrating the registerChange method, callback implementation using Callback1Argument, and album modification via commitModify. Targeted at HarmonyOS developers using the Cangjie language, this guide explains how to monitor album state changes effectively within applications.

### 监听指定URI_2more.md 监听指定URI_2more.md
This file focuses on asset-level monitoring. This document serves as a development guide explaining how to monitor changes to specific URIs, particularly PhotoAssets, using the registerChange API. It details the necessary prerequisites, such as obtaining the photoAccessHelper instance and requesting specific read and write permissions. The guide provides a step-by-step tutorial with Cangjie code examples demonstrating how to fetch a media resource, register a change listener, and trigger the callback by deleting the asset. Key takeaways include understanding the callback mechanism and handling ChangeData. This content is intended for HarmonyOS developers implementing media asset change tracking in their applications.
