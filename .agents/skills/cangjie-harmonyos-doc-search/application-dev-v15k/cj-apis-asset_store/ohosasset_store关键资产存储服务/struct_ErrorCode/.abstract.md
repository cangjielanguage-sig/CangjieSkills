This directory contains comprehensive documentation for the `ErrorCode` struct and associated error constants within the Cangjie programming environment, specifically tailored for the Security Asset system. It covers a wide range of static integer constants representing various failure scenarios, including invalid arguments, permission denials, and system failures such as database or crypto errors. The documentation details Int32 mappings, specific error meanings, and necessary system capability requirements like SystemCapability.Security.Asset. This resource is essential for developers integrating asset management features who need to effectively handle error states, diagnose application failures, and manage exceptions in their code starting from API version 19.
