This directory contains comprehensive documentation and practical code examples for the ImageSpan component within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers the essential concepts of integrating inline images directly into text flows, providing detailed insights into component initialization via ResourceStr or PixelMap. The content explores universal attributes like size and background, alongside specific properties such as colorFilter, objectFit, and verticalAlign. Additionally, it addresses event handling for loading states and supports both local and network images. This resource is suitable for developers and UI designers aiming to create rich, interactive text layouts with embedded graphical elements in their applications.
