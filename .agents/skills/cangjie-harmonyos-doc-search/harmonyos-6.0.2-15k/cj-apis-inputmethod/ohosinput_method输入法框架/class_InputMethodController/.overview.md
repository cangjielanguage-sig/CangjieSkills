# class_InputMethodController

This directory contains API reference documentation for the Cangjie `InputMethodController` class within the IMEKit framework. It covers the management of input method interactions, including binding self-drawn controls, handling text selection, managing keyboard visibility, and subscribing to input events. Key topics include `attach`, `detach`, cursor updates, and event callbacks like `SelectByRange`. Targeted at Cangjie developers building text editing interfaces or input method extensions, these documents provide function signatures, parameters, error codes, and code examples necessary for implementing robust input functionality in applications.
