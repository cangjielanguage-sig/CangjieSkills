# 创建列表List

This directory provides a comprehensive guide to creating and managing lists using the ArkUI framework and the Cangjie programming language. It covers fundamental concepts like component structure, layout constraints, and data iteration, as well as advanced features such as sticky headers, swipe interactions, and performance optimization. Developers will learn how to implement grouped lists, control scroll positions, and customize styles for better user experience. Suitable for mobile UI developers and Cangjie programmers looking to build efficient, scrollable interfaces for applications like contact lists or file managers.

## Detailed Description

### 响应列表项侧滑_3more.md
This tutorial guides developers on implementing common list interactions in ArkUI using Cangjie. It covers three main features: responding to list item swipes for deletion, adding notification badges, and handling pull-to-refresh and load-more mechanisms. Key takeaways include using the swipeAction attribute to define custom end components like delete buttons, utilizing the Badge component to display unread counts on avatars, and managing touch events or the Refresh component for data loading. The document provides Cangjie code examples for each scenario. It targets mobile developers seeking to enhance user experience with standard UI patterns like swipe-to-delete and visual indicators.

### 布局与约束.md
This technical guide explains the layout mechanisms and size constraints of the List component within a UI framework. It covers component hierarchy, vertical and horizontal layout capabilities, and specific constraints regarding main and cross axes. Key information includes how List arranges ListItem and ListItemGroup, supports adaptive scrolling, and handles sizing logic where the List adapts to either its children's total size or its parent's size when dimensions are undefined. It recommends List over Grid for simple equal-width columns and targets UI developers designing scrollable interfaces.

### 开发布局_2more.md
This document serves as a development guide for configuring the List component in Cangjie UI applications. It details setting the main axis direction for vertical or horizontal scrolling and managing cross-axis layouts using the lanes and alignListItem properties for adaptive multi-column displays. Additionally, it demonstrates how to populate lists with static data, covering simple text items and complex structures that require container components like Row. Key takeaways include understanding the single root node limitation of ListItem and adaptive layout strategies. This tutorial targets Cangjie developers seeking to implement responsive list views.

### 折叠与展开.md
This tutorial guides developers on implementing list item collapse and expand functionality using the Cangjie language. The document covers three main steps: defining data structures with ItemInfo and ItemGroupInfo, constructing the list UI using ListItemGroup and conditional ForEach loops, and implementing animations. Key takeaways include using @State to manage expansion state, controlling visibility based on the state array, and applying animationStart, rotate, and animationEnd to create smooth transition effects. This guide is intended for Cangjie developers building interactive information lists or forms requiring expandable sections.

### 控制滚动位置_2more.md
This technical tutorial explains how to manage and respond to scroll positions within List components using the Cangjie language. It covers two primary functions: programmatically controlling scroll position and reacting to scroll events. The first section details binding a Scroller object to a List to implement features like returning to the top using the scrollToIndex method. The second section demonstrates synchronizing an AlphabetIndexer component with list scrolling via the onScrollIndex event to update UI states dynamically. Key takeaways include the usage of Scroller objects, event listeners, and state management. The document targets application developers building interactive lists, noting that ListItemGroup counts as a single index.

### 支持分组列表.md
This document serves as a technical guide for implementing grouped lists within a UI framework to enhance data display structure and user efficiency. It covers the conceptual benefits of grouping, the usage of the ListItemGroup component within the List component, and practical code examples. Key information includes how to set custom headers using the header parameter and how to dynamically render multiple groups using ForEach with combined data arrays. The content targets UI developers using the Cangjie language, providing syntax examples for building two-dimensional lists like contact applications.

### 概述.md
This document serves as a conceptual overview for the List component within the ArkUI framework, explaining its role as a scrollable container for displaying structured data sets. The text covers the definition and functionality of lists, common application scenarios like contact lists, and the structural composition using List, ListItem, and ListItemGroup components. It highlights that the List component supports vertical and horizontal linear arrangements, mixed rendering of single views and ForEach loops, and advanced features like conditional rendering and lazy loading for efficiency. This guide targets UI developers seeking to implement efficient, scrollable data displays in their applications.

### 添加粘性标题.md
This tutorial guides developers on implementing sticky headers for list components to improve data navigation and readability in applications. It covers the definition and benefits of sticky headers, visual examples, and the technical implementation using the List and ListItemGroup components. The core mechanism involves setting the sticky attribute to StickyStyle.Header for headers or StickyStyle.Footer for footers. The provided Cangjie code demonstrates data modeling and rendering logic. This is intended for UI developers using the Cangjie language and ArkUI framework who need to organize large datasets like contact lists.

### 编辑列表_2more.md
This technical guide explains list editing modes and performance optimization strategies for long lists in UI development. It covers basic data manipulation for adding and deleting items, then focuses on handling large datasets. Key sections discuss replacing standard loop rendering with data lazy loading (LazyForEach) to improve startup times. The document details the cachedCount parameter for the List component, explaining how it caches items to enhance scrolling performance and reduce visual glitches. It also warns about the CPU and memory overhead associated with caching. Intended for developers building data-intensive applications like file managers, this guide provides essential techniques for balancing user experience with system resources.

### 自定义列表样式.md
This technical guide explains how to customize the visual appearance and behavior of List components in the Cangjie programming language. It covers three main styling aspects: setting content spacing between items, adding dividers with customizable margins and colors, and configuring scrollbars. Key takeaways include using the space parameter for gaps, the divider property for visual separation with specific notes on margin behavior and multi-column support, and the scrollBar property with BarState.Auto for interactive scrolling. Intended for UI developers using Cangjie, this tutorial requires basic knowledge of component layout and aims to enhance user interface readability and navigation.

### 迭代列表内容.md
This document serves as a technical tutorial demonstrating how to implement dynamic list rendering in the Cangjie framework using the ForEach component. It covers the concept of loop rendering to reduce code complexity and provides a complete code example for a contact list application. Key takeaways include the structure of the ForEach syntax, specifically the use of itemGeneratorFunc to create ListItems and keyGeneratorFunc for unique identification, alongside the definition of a data model class. The content is intended for Cangjie developers seeking to optimize UI code by iterating over data collections rather than writing repetitive static components.
