This directory provides comprehensive API reference documentation for the Hilog class within the Cangjie programming language, designed as part of the PerformanceAnalysisKit. It is dedicated to enabling applications and system services to output categorized and structured logs. The content covers a wide range of static methods used for printing logs at various severity levels, including DEBUG, INFO, WARN, ERROR, and FATAL. It details specific system capabilities, version requirements, and mandatory parameters such as domain (a 16-bit identifier) and tag (used for class or behavior identification). This documentation is highly suitable for Cangjie developers who need to implement robust logging mechanisms, control log output based on specific domains and tags, and ensure their applications adhere to system logging standards.
