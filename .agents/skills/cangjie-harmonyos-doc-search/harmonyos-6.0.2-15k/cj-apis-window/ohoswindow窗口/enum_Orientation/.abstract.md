This directory contains essential API reference documentation for the `Orientation` enumeration within the WindowManager module, specifically designed for developers using the Cangjie language. It provides a detailed breakdown of constants and types used to control screen rotation and display direction. The content covers a broad spectrum of orientation behaviors, including static portrait and landscape modes, dynamic sensor-based auto-rotation, and restricted axis variants. Additionally, it documents specific user rotation modes that allow applications to temporarily force a specific orientation before reverting to system defaults. This documentation is suitable for software developers and UI engineers who need to implement robust window management logic, handle sensor dependencies, and manage display behaviors responsive to system control center settings and hardware capabilities.
