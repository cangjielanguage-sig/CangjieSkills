# unittest_test_templates

This directory contains the official guide for the `@TestTemplate` feature in the Cangjie unittest framework. It is designed to help developers create reusable test components and hierarchies, significantly reducing code duplication in complex test suites. The content covers the creation of abstract templates, the specific execution order of lifecycle methods, and how configuration is inherited across test classes. It also outlines interaction rules with other features, such as support for `@Bench` and restrictions on `@Parallel` and `@Types`. This documentation is specifically suitable for Cangjie developers who utilize object-oriented inheritance to structure their testing logic efficiently. By mastering these templates, developers can maintain cleaner, more modular test code that is easier to update and extend over time, ultimately improving the maintainability and reliability of large-scale software projects.

### unittest_test_templates.md unittest_test_templates.md

This guide explains how to use the `@TestTemplate` feature in the Cangjie unittest framework to create reusable test components and hierarchies. It covers getting started with abstract templates, lifecycle method execution order, configuration inheritance, and interaction rules with other features. Key takeaways include that templates allow common test code to be defined once and inherited, with lifecycle hooks executing in a specific base-to-derived order. While `@Bench` is supported, `@Parallel` and `@Types` are incompatible with templates. This tutorial targets Cangjie developers seeking to reduce code duplication and structure complex test suites using object-oriented inheritance.
