## 开发步骤

1. 导入[证书算法库框架模块](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md)。

    ```cangjie
    import kit.DeviceCertificateKit.*
    ```

2. 基于已有的证书数据，调用[createX509CertChain](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md#func-createx509certchainencodingblob)创建X509证书链对象，并返回结果。

3. 调用[x509CertChain.getCertList](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md#func-getcertlist)获取证书链中的X509证书列表。

4. 调用[x509CertChain.validate](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md#func-validatecertchaindata)使用校验参数校验证书链并返回结果。

    ```cangjie
    import kit.DeviceCertificateKit.*
    import ohos.base.BusinessException
