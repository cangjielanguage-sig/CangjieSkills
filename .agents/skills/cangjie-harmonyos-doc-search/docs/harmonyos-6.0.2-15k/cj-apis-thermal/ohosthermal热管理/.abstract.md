This directory provides comprehensive API reference documentation for the `ohos.thermal` module within the Cangjie development environment, specifically tailored for HarmonyOS developers. It focuses on device thermal management capabilities, allowing applications to monitor temperature changes and optimize performance dynamically. The documentation covers the `ThermalLevel` enum, which categorizes thermal states, and core functions for retrieving thermal levels and managing event subscriptions. This resource is essential for developers implementing thermal-aware features, enabling them to adjust system resources, reduce background load, and save critical data based on device thermal severity to ensure stable operation and user experience.
