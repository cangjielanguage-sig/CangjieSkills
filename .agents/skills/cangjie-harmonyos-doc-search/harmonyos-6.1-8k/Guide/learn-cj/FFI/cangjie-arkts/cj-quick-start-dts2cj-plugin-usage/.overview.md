# cj-quick-start-dts2cj-plugin-usage

本目录提供了关于使用DevEco Studio仓颉插件实现跨语言调用的详细指南。核心内容聚焦于如何在仓颉（Cangjie）代码中无缝调用ArkTS生态中的三方库。文档通过一个具体的lz4js库集成案例，系统性地讲解了从零开始的开发流程，包括创建[Cangjie] Hybrid Ability工程、配置必要的项目依赖、利用.d.ts类型定义文件自动生成仓颉封装层代码，以及最终在仓颉侧调用接口的完整步骤。此外，文档还深入解析了关键的互操作技术细节，例如如何通过右键菜单快速生成绑定代码，以及如何在ArkTS入口文件中利用globalThis机制手动传入模块对象。这份资料非常适合致力于HarmonyOS应用开发，且需要解决仓颉与ArkTS混合编程及互操作问题的开发者参考。
