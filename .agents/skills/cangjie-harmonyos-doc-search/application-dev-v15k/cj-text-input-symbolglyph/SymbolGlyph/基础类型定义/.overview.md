# 基础类型定义

This directory contains API reference documentation for fundamental type definitions related to symbol effects within the ArkUI framework, specifically using the Cangjie programming language. It covers various symbol effect classes—such as `AppearSymbolEffect`, `ReplaceSymbolEffect`, and `ScaleSymbolEffect`—as well as enumerations like `SymbolEffectStrategy` and `SymbolRenderingStrategy`. These definitions are essential for developers building dynamic UI animations in HarmonyOS applications, providing the necessary syntax, parameters, and configuration options to customize visual behaviors including scaling, direction, color rendering, and automatic animation strategies.

## Detailed Description

### class_AppearSymbolEffect_5more.md class_AppearSymbolEffect_5more.md
This API reference document defines five specific symbol effect classes for the Cangjie language within the ArkUI framework. It details the `AppearSymbolEffect`, `BounceSymbolEffect`, `DisappearSymbolEffect`, `HierarchicalSymbolEffect`, and `PulseSymbolEffect` classes. Key information includes that all classes inherit from `SymbolEffect` and provide constructors with parameters such as `EffectScope`, `EffectDirection`, and `EffectFillStyle` to customize animation behaviors like appearance, bounce, and pulse. The document targets developers implementing visual animations in HarmonyOS applications, requiring knowledge of Cangjie syntax and ArkUI components.

### class_ReplaceSymbolEffect_6more.md class_ReplaceSymbolEffect_6more.md

This technical reference is intended for developers building UI animations in the ArkUI framework.

### enum_SymbolEffectStrategy_2more.md enum_SymbolEffectStrategy_2more.md
