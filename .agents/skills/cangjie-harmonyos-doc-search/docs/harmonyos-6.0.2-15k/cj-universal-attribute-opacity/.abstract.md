This directory contains the essential API reference documentation for the `cj-universal-attribute-opacity` module within the Cangjie ArkUI framework. It is dedicated to explaining the universal attribute responsible for controlling component transparency. The documentation provides a deep dive into the syntax and usage of the opacity property, differentiating between the `Float64` overload for precise alpha blending and the `Int64` overload for simple on-off visibility. Furthermore, it elucidates complex rendering behaviors, such as multiplicative inheritance, which affects how nested components display transparency relative to their containers. It also clarifies layout space preservation when elements are hidden. This resource is tailored for Cangjie developers looking to refine the visual aesthetics of their applications through effective transparency management and layering strategies.
