# class_AudioStreamManager

This directory contains API reference documentation for the `AudioStreamManager` class within the Cangjie AudioKit framework. It covers the management and monitoring of audio streams, including retrieving information about audio capturers, renderers, and effects. The documentation details methods for querying active stream states, managing event subscriptions for stream changes, and handling callbacks for dynamic audio events. Key topics include synchronous data retrieval, event listening (`on`/`off`), and error handling via `BusinessException`. This resource is suitable for software developers and multimedia engineers integrating audio stream management capabilities into Cangjie-based applications.
