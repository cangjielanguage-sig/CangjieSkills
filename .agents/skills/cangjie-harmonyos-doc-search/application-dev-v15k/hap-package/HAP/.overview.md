# HAP

This directory provides an in-depth technical overview of the Harmony Ability Package (HAP), the fundamental building block for HarmonyOS application installation and execution. It covers the complete lifecycle of HAP development, ranging from architectural definitions and Cangjie-based coding standards to configuration constraints and signing protocols. The documentation explores various usage scenarios, including single versus multi-HAP structures, and offers practical tutorials for creating packages within DevEco Studio. Additionally, it addresses the critical operational phase by detailing debugging procedures and deployment strategies using both integrated environments and command-line tools like hdc. This resource is essential for HarmonyOS developers, QA engineers, and system architects seeking to optimize application structure, ensure compliance with signing standards, and streamline the debugging and deployment process for robust application delivery.

## Detailed Description

### HAP_5more.md
This technical guide defines the Harmony Ability Package (HAP), the fundamental unit for HarmonyOS application installation and execution, specifically focusing on Cangjie-based development. The document covers HAP definitions (entry vs. feature), usage scenarios (single vs. multi-HAP), strict constraints regarding configuration and signing, and a step-by-step creation tutorial using DevEco Studio. Key takeaways include the recommendation for single HAP structures to avoid resource loading, the requirement for consistent signing certificates across all HAPs, and the support for HAR references. Targeted at HarmonyOS developers, this guide provides essential architectural knowledge and practical steps for building and packaging applications.

### 调试.md
This technical guide outlines the procedures for debugging HarmonyOS applications (HAPs) compiled via DevEco Studio. It primarily focuses on two debugging approaches: using the integrated DevEco Studio environment and employing the hdc command-line tool. Key sections provide detailed instructions for installing, updating, and uninstalling HAP files, specifically contrasting direct hdc commands with the bm tool used within an hdc shell session. The document serves as a reference for developers needing to manage application deployment and perform debugging operations on target devices.
