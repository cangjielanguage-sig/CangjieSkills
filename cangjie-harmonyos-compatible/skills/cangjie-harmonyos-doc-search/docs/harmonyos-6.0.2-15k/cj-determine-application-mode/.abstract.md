This directory serves as an essential technical resource for application developers, providing a detailed guide on how to determine the correct method for applying for application permissions based on specific criteria. It thoroughly covers the decision-making flowchart necessary to choose between `system_grant` and `user_grant` authorization modes and explains the implementation of ACL for restricted permissions. The guide includes a specific four-step process for handling `user_grant` permissions and provides a reference table that maps permission types—such as open versus restricted—to their respective operational paths, including declaration and user authorization requests. This resource is specifically designed for developers implementing permission management who require a solid understanding of basic concepts like APL (Ability Privilege Level). By utilizing this guide, developers can ensure their applications adhere to correct permission protocols and security standards.
