This directory provides API reference documentation for database-related classes in the Cangjie language. It encompasses runtime driver management, connection pooling mechanisms, and a wide array of SQL data type wrappers. While the type wrappers are largely deprecated in favor of native Cangjie types, they are documented here for legacy support and migration purposes. The content is essential for developers building database-driven applications, managing connection lifecycles, or updating legacy codebases to use modern native types.
