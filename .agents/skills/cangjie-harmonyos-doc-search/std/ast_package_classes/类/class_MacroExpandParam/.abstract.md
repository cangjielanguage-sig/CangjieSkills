This directory provides comprehensive API references for the Cangjie programming language, specifically focusing on components related to Abstract Syntax Tree (AST) manipulation and traversal. It includes detailed documentation for the `MacroExpandParam` class, which is essential for handling macro call nodes within function parameters, as well as the `traverse` function, which enables systematic navigation of syntax trees using the Visitor pattern. Key topics covered include macro syntax handling, token conversion, inheritance structures, and custom traversal logic. This documentation is primarily suitable for compiler engineers, language tool developers, and advanced users working on code analysis or transformation within the Cangjie ecosystem who require a deep understanding of AST internals.
