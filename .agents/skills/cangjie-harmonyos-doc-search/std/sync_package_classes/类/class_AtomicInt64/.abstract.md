This directory contains API reference documentation for the `AtomicInt64` class in the Cangjie programming language, focusing on thread-safe operations for 64-bit integers. It covers essential concurrency mechanisms such as compare-and-swap, atomic arithmetic (add, subtract), bitwise operations, and value swapping. The documentation highlights the distinction between standard implementations using default memory ordering and deprecated versions that allowed explicit memory order specifications. This resource is suitable for systems programmers and experienced developers implementing synchronization and concurrent algorithms in multi-threaded applications.
