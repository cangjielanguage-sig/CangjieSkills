This directory provides comprehensive technical guidance for developers on managing audio focus changes within applications. It covers the system's audio focus strategy, which automatically handles stream conflicts, and details how to use the InterruptEvent API to respond to these changes. Key topics include monitoring audio focus events across different development methods like AVPlayer, AudioRenderer, and AudioCapturer, as well as understanding critical parameters such as InterruptForceType and InterruptHint. This resource is suitable for audio application developers who need to ensure state consistency and a seamless user experience when integrating audio playback or recording features.
