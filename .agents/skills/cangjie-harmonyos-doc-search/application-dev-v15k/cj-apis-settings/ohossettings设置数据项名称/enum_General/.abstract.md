This directory provides essential API reference documentation for the Cangjie programming language, focusing specifically on system settings and configuration constants. It encompasses the `General` enum and associated utility functions designed to manage a wide array of device states, such as airplane mode activation, accessibility service status, geolocation permissions, and hardware connectivity options. All documented components fall under the `SystemCapability.Applications.Settings.Core` capability, effective from API version 19. This resource is tailored for system developers and software engineers tasked with creating applications that need to interact directly with low-level device configurations and system settings management. It serves as a critical technical guide for understanding the data structures and constants required to programmatically manipulate core device behaviors.
