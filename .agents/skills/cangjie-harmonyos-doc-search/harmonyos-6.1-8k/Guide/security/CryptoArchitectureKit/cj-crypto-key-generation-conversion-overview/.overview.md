# cj-crypto-key-generation-conversion-overview

本目录提供了加密模块中密钥生成与转换的全面概述文档。它详细介绍了密钥管理的核心概念，包括随机生成、基于指定数据生成以及获取密钥二进制数据的三种主要场景。文档明确界定了对称密钥、非对称密钥及密钥对等术语，并特别指出当前系统仅支持对称密钥。此外，它还阐述了密钥对象在加解密操作中的具体用途及数据转换流程。这份概念性指南专为需要实施加解密功能的开发者设计，旨在帮助他们掌握密钥管理的完整生命周期。

## Detailed Description

### cj-crypto-key-generation-conversion-overview.md cj-crypto-key-generation-conversion-overview.md
本文档旨在介绍加密模块中密钥生成与转换的基本概念、应用场景及当前支持范围。主要涵盖随机生成密钥、基于指定数据生成密钥以及获取密钥二进制数据三种场景，并定义了对称密钥、非对称密钥及密钥对等核心概念。关键信息在于当前系统仅支持对称密钥，文档明确了密钥对象在加解密操作中的用途及数据转换流程。该文档属于概念性概述指南，面向需要使用密钥进行加解密操作的开发者，帮助其理解密钥管理的生命周期。
