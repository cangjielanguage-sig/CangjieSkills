# README_zh

本目录是仓颉语言基础服务套件的核心API索引文档，专为使用仓颉语言进行HarmonyOS或OpenHarmony系统开发的开发者设计。它提供了一个系统级的导航入口，全面涵盖了设备管理（如电量监控、设备信息获取）、数据文件处理（包括文件上传与下载）、进程线程通信（如公共事件机制）以及系统工具（如系统设置、时间管理）等关键API模块。此外，文档还详细列出了各类服务的错误码定义，帮助开发者进行异常处理。目前，文档中引用的大部分功能仍处于Beta特性阶段，主要集中在ohos命名空间下。通过本文档，开发者可以快速定位基础服务接口，规范开发流程，是进行仓颉系统级应用开发不可或缺的参考指南。
