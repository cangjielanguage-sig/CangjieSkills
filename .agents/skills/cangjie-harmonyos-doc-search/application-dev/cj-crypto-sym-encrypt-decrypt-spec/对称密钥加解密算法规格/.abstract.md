This directory contains technical specifications for symmetric key encryption algorithms within the CryptoArchitectureKit. It covers implementation details, supported encryption modes (ECB, CBC, GCM, etc.), padding mechanisms, and string parameter formatting for algorithms like 3DES, SM4, and AES. The documents guide developers on how to construct algorithm specifications and handle key lengths. It is suitable for developers integrating cryptographic functions who need a reference for configuring encryption parameters and understanding block cipher constraints.
