This directory contains API reference documentation for the core classes within the Cangjie programming language's `encoding_json` package. It covers the fundamental data structures used to represent and manipulate JSON data, including primitive types like integers, strings, and booleans, as well as complex structures like arrays and objects. The documentation details class definitions, constructors, and methods for parsing, serialization, and type inspection. It is suitable for Cangjie developers who need to programmatically handle JSON data, ensuring robust data interchange and type safety in their applications.
