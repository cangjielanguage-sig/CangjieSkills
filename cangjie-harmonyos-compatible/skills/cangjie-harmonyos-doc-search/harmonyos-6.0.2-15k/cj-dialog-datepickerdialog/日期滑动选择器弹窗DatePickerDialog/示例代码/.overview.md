# 示例代码

This directory contains practical code examples for implementing and customizing the `DatePickerDialog` component using the Cangjie programming language within the HarmonyOS ecosystem. It covers essential features such as configuring time display, customizing visual styles, setting popup positions, and handling calendar types (Gregorian and Lunar). These examples demonstrate the use of `DatePickerDialogOptions` for various UI configurations and event handling. Suitable for HarmonyOS developers and Cangjie programmers looking to integrate advanced date and time selection functionalities into their applications.

## Detailed Description

### 示例1设置显示时间.md 示例1设置显示时间.md
This document provides a code example demonstrating how to configure a DatePickerDialog to display time using the Cangjie programming language. It covers the implementation of a UI component with a button that triggers a dialog, specifically focusing on the showTime, useMilitaryTime, and dateTimeOptions parameters within DatePickerDialogOptions. The example illustrates setting a date range, enabling time display, formatting the time (12-hour vs 24-hour), and handling various lifecycle and selection callbacks like onDateAccept and onDateChange. This tutorial is intended for HarmonyOS developers using Cangjie who need to implement date and time selection features in their applications.

### 示例2自定义样式.md 示例2自定义样式.md
This document serves as a practical code example demonstrating how to customize the visual appearance of a DatePickerDialog in the Cangjie programming language. The primary focus is on configuring specific style properties, including disappearTextStyle, textStyle, selectedTextStyle, acceptButtonStyle, and cancelButtonStyle. Key takeaways include the implementation of PickerTextStyle and PickerDialogButtonStyle to modify fonts, colors, weights, and border radii within the DatePickerDialog configuration. This tutorial is designed for Cangjie developers seeking to implement custom UI styling and event handling for date selection components in HarmonyOS applications.

### 示例3设置弹窗位置_3more.md 示例3设置弹窗位置_3more.md
This document provides code examples demonstrating how to customize the appearance and layout of a DatePickerDialog in Cangjie. It covers three specific scenarios: setting the popup position using alignment and offset, defining a mask area using maskRect, and styling the dialog backboard with background color, blur effects, and shadows. The examples utilize DatePickerDialogOptions to configure properties like DialogAlignment, Offset, Rectangle, and ShadowOptions, allowing developers to control visual presentation and user interaction zones. This tutorial targets HarmonyOS developers using the Cangjie language who need to implement advanced UI customizations for date selection dialogs.

### 示例6设置公历农历.md 示例6设置公历农历.md
This document provides a code example demonstrating how to configure a DatePickerDialog to display either Gregorian or Lunar calendars in a Cangjie application. It covers the usage of the DatePickerDialogOptions class, specifically focusing on the lunar and lunarSwitch boolean parameters to control calendar type and switching capabilities. The example includes two implementations: a standard Gregorian picker and a Lunar picker with a switch option, utilizing the DatePickerDialog.show method and state management for the selected date. This tutorial is intended for developers using the Cangjie language and HarmonyOS UIKit who need to implement date selection with calendar type support.
