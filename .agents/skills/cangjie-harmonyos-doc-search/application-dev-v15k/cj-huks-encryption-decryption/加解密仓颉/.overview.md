# 加解密仓颉

This directory provides a comprehensive technical resource dedicated to implementing encryption and decryption operations using the Cangjie programming language within the HarmonyOS ecosystem. It focuses on leveraging the Universal Keystore Kit (HUKS) to facilitate secure data handling. The content covers a wide range of cryptographic standards, including symmetric algorithms like AES and asymmetric algorithms such as RSA and SM2. It addresses the complete key lifecycle, from generation and usage to deletion. This collection is specifically designed for software developers and security engineers working with Cangjie who require practical guidance and code references to integrate robust security protocols and cryptographic features into their applications effectively.

### 加解密仓颉.md 加解密仓颉.md
This document serves as a technical guide for implementing encryption and decryption operations using the Cangjie language. The main topics cover practical examples utilizing specific cryptographic algorithms, including AES 128, RSA 2048, and SM2. ### 开发步骤.md 开发步骤.md
This document serves as a step-by-step development guide for implementing cryptographic operations using the Universal Keystore Kit. It covers the complete lifecycle of key management, including generating or importing keys, performing encryption and decryption, and deleting obsolete keys. The guide details specific API calls such as generateKeyItem, initSession, and finishSession, while highlighting crucial parameter configurations for various algorithms like AES, RSA, and SM2. It is intended for developers seeking to integrate secure data handling into their applications, emphasizing correct algorithm parameter setup for successful cryptographic sessions.

### 开发案例/
This directory contains Cangjie code examples for cryptographic operations using the Universal Keystore Kit (HUKS) in HarmonyOS. It covers various encryption algorithms including AES (CBC, GCM), RSA (ECB with different paddings), and SM2. The examples demonstrate key lifecycle management (generation, encryption, decryption, deletion) and specific configurations like padding modes and digests. It is suitable for Cangjie developers and software engineers looking to implement secure data storage and cryptographic features within the HarmonyOS ecosystem.
