This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, specifically focusing on the generation of cryptographically secure random numbers. It utilizes the Cangjie CryptoArchitectureKit to provide robust solutions for creating session keys and encryption data, which are critical components in modern security architectures. The content covers fundamental cryptographic concepts, including internal state management and random seeding, with a specific focus on the CTR_DRBG algorithm. Built on an OpenSSL-based implementation, the guide clarifies important behavioral characteristics, such as the non-repeatable nature of seed sequences. It is tailored for developers who possess a foundational understanding of encryption principles and are looking for practical, step-by-step workflows and Cangjie code examples to integrate secure random number generation into their applications effectively and securely.
