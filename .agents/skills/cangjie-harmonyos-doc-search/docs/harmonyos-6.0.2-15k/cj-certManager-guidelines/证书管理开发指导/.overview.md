# 证书管理开发指导

This directory provides comprehensive development guidance for managing application certificates and private credentials within the HarmonyOS ecosystem. It focuses on utilizing the DeviceCertificateKit and Universal Keystore (HUKS) to handle the full lifecycle of credentials, including installation, cryptographic operations (signing/verification), and removal. Key topics include permission configuration, Cangjie programming language implementation, and API version 12+ interfaces. Suitable for HarmonyOS application developers, particularly those using the Stage model and seeking to implement secure digital signatures and credential management in their apps.

## Detailed Description

### 开发步骤.md
This document provides a step-by-step tutorial for developers on managing application private credentials using the DeviceCertificateKit in the Cangjie programming language. It covers three primary steps: configuring the ohos.permission.ACCESS_CERT_MANAGER permission in module.json5, importing necessary modules, and executing a comprehensive code sample. The code example demonstrates the full lifecycle of a credential: installation via installPrivateCertificate, cryptographic operations including signing and verifying data using CMSignatureSpec with PSS padding and SHA256, and removal via uninstallPrivateCertificate. Targeted at HarmonyOS application developers using the Stage model, this guide requires knowledge of Cangjie syntax and application package structure to implement secure certificate management and digital signatures effectively.

### 证书管理开发指导_3more.md
This document serves as a development guide for managing application certificates and private credentials using API version 12 and above. It details typical usage scenarios including installing, retrieving, and uninstalling credentials, as well as performing data signing and verification. The guide specifies that supported algorithms are limited to RSA and ECC, relying on the Universal Keystore (HUKS) capabilities. Key interfaces covered include installPrivateCertificate, getPrivateCertificate, and the multi-step signature process involving init, update, and finish. This resource is intended for developers seeking to implement secure credential management and cryptographic operations within their applications.
