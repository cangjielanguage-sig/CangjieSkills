This directory serves as the definitive resource for API reference documentation regarding global logger management functions within the Cangjie logging package. It provides critical technical details for developers who need to implement or interact with a centralized logging system effectively. The documentation covers the complete lifecycle of logger instances, ranging from the initial configuration steps to the ongoing retrieval of instances during runtime. Key topics include the specific behaviors of `getGlobalLogger` and `setGlobalLogger`, the nuances of shared versus copied instances, and the strict guidelines regarding initialization frequency. This resource is specifically tailored for Cangjie developers and implementation providers who require a deep understanding of how to properly manage global state within their logging infrastructure. By adhering to the guidelines found here, users ensure application stability and maintain consistent logging behavior throughout the entire software lifecycle, avoiding common pitfalls associated with global state management.
