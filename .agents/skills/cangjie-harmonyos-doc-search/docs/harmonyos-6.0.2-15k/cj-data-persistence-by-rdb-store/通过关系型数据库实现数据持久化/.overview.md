# 通过关系型数据库实现数据持久化

This directory provides a comprehensive guide to implementing data persistence using relational databases within the Cangjie framework on HarmonyOS. It focuses on the SQLite-based RdbStore component, designed to help developers manage complex data relationships efficiently. The content covers essential concepts such as predicates, result sets, and system constraints, alongside practical implementation steps for CRUD operations, version management, and database backup. It is specifically tailored for application developers utilizing the ArkData kit who need robust local storage solutions with SQL capabilities. By following these resources, developers can learn to initialize databases, handle data evolution, and optimize performance for large datasets.

### 场景介绍_5more.md 场景介绍_5more.md
This technical guide introduces the relational database component based on SQLite, designed for managing complex data relationships in applications. It covers usage scenarios, basic concepts like predicates and result sets, operational mechanisms, system constraints, and API interfaces. Key information includes performance recommendations for large data queries, supported data types (Int64, String, etc.), and limitations such as a 2MB data size limit and WAL logging mode. The document details essential APIs including getRdbStore, executeSql, insert, update, and query. It is intended for developers using the Cangjie framework who require persistent storage solutions with SQL capabilities.

### 开发步骤/
This directory provides a structured tutorial series for developers implementing data persistence using the relational database (RdbStore) within the Cangjie framework on HarmonyOS. It covers the complete development lifecycle, starting from initial database configuration, schema creation, and version management to performing standard CRUD operations and handling advanced tasks like result set processing, backup, and deletion. Key concepts include StoreConfig initialization, RdbPredicates, and resource management. These guides are essential for application developers utilizing the ArkData kit to build robust local data storage solutions and manage database evolution effectively.
