This directory contains API documentation for the `cj-apis-zlib` project, specifically focusing on the HarmonyOS Cangjie environment's Zlib subsystem. It provides comprehensive resources for data compression, decompression, and integrity verification workflows. The content covers essential classes like ZStream, GZip, and Zip, alongside configuration enumerations and utility functions. Designed for Cangjie developers, this documentation assists in implementing efficient data handling, managing archives, and ensuring data integrity within HarmonyOS applications. It serves as a technical reference for mastering compression-related system capabilities and error handling.
