This directory serves as a specialized technical resource focusing on the `@BuilderParam` macro within the ArkUI framework and the Cangjie language environment. It is designed to assist developers in understanding the mechanisms for dynamically injecting specific UI descriptions or behaviors into custom component instances, effectively functioning as slot placeholders. The documentation covers essential concepts including initialization via global or local `@Builder` functions, strict type consistency requirements, and specific usage limitations. Furthermore, it addresses common compilation errors related to state management. This content is suitable for developers who are already familiar with `@Builder` decorators and aim to achieve flexible component customization and dynamic UI composition in their ArkUI applications.
