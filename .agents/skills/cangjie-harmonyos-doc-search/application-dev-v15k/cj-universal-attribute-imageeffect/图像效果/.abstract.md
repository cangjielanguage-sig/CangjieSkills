This directory contains API reference documentation and resources for implementing visual effects in the Cangjie ArkUI framework. It covers a wide range of image manipulation capabilities, including color adjustments (contrast, saturation, hue), filters (blur, sepia, grayscale), and advanced rendering techniques (spherical effects, pixel stretching). Additionally, it addresses performance optimization strategies like off-screen rendering and shadow batching. Suitable for HarmonyOS developers and UI designers, these documents provide the necessary parameters and type definitions to programmatically enhance component aesthetics and rendering efficiency in Cangjie applications.
