# 类

This directory contains API reference documentation for core classes in the Cangjie programming language. It covers essential components for concurrency management, data iteration, and object manipulation. Key topics include thread handling with `Thread` and `Future`, asynchronous task management, and sequential traversal via `Iterator` and `ArrayIterator`. It also details utility classes like `Box` for reference semantics and `StringBuilder` for efficient string construction. This documentation is suitable for Cangjie developers, software engineers, and library maintainers seeking to implement multithreaded applications, manage object lifecycles, or utilize functional programming patterns.

### class_FutureT.md class_FutureT.md
This document serves as API reference documentation for the Cangjie Future class, which represents a thread task used to manage asynchronous computations and retrieve results. It covers the thread property and essential methods for task control: cancel sends a cancellation request, get blocks indefinitely or with a timeout to retrieve results, and tryGet attempts a non-blocking retrieval. Key concepts include cooperative cancellation, blocking versus non-blocking calls, and exception handling for timeouts. This guide targets Cangjie developers working with concurrency and the spawn expression, providing the necessary interfaces to interact with thread lifecycles and return values.

### class_Thread.md class_Thread.md
This API reference document details the Thread class in the Cangjie language, providing functionality for thread management and exception handling. ### class_ThreadLocalT.md class_ThreadLocalT.md
This document serves as API reference documentation for the Cangjie programming language's ThreadLocal class. It covers the class definition, its semantic behavior regarding thread isolation, and details two primary methods: get and set. The key takeaway is that ThreadLocal variables provide each thread with an independent copy of a value, preventing interference between threads. The get method retrieves the current thread's value or None, while the set method updates the value or deletes it if None is passed. This reference is intended for Cangjie developers implementing multithreaded applications who need to maintain thread-specific state.
