This directory contains API reference documentation for the Cangjie ArkUI framework, focusing on the configuration and customization of component properties, specifically for text input and display controls like TextArea. It covers a wide range of functionalities including custom keyboards, text styling (fonts, spacing, colors), input validation, layout constraints, and user interaction behaviors such as selection and copy options. These documents provide detailed parameter definitions, system capabilities, and version requirements. This resource is suitable for HarmonyOS developers and UI engineers who need granular control over text rendering, input mechanisms, and component appearance within their applications.
