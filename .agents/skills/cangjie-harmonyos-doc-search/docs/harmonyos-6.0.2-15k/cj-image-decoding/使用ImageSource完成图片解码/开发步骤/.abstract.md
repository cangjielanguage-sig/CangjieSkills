This directory provides a comprehensive set of development guides focused on image decoding and processing using the Cangjie language and the ImageKit framework. It details the essential steps required to integrate image handling capabilities into applications, starting from the initial setup and module imports to the actual decoding of image data. The documentation covers critical aspects such as acquiring image data via sandbox paths or resource managers, creating ImageSource instances, and configuring decoding options for various formats including HDR. These resources are specifically tailored for application developers who possess a working knowledge of Cangjie syntax and application context handling, aiming to facilitate efficient image loading and manipulation within their software projects.
