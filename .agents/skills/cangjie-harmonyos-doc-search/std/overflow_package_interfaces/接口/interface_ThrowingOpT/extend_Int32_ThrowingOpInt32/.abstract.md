This directory serves as a comprehensive technical resource for Cangjie language developers, focusing specifically on the implementation of the `ThrowingOp<Int32>` interface for the `Int32` type. It provides detailed API documentation on a wide array of arithmetic and bitwise operations that prioritize safety through rigorous exception-throwing strategies. The covered operations include essential mathematical functions like addition, multiplication, division, and modulo, as well as negation, subtraction, and bit shifting. Each function is designed to throw specific exceptions, such as `OverflowException` or `OvershiftException`, whenever operational boundaries are exceeded. This documentation is ideal for developers building systems where strict error handling and explicit overflow detection are paramount, ensuring numerical stability and reliability in Cangjie applications.
