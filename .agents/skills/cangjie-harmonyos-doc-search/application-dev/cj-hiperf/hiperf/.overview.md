# hiperf

This directory contains documentation for `hiperf`, a cross-platform command-line performance analysis tool similar to Linux perf, designed for the OpenHarmony environment. It covers environment setup, core commands for recording and reporting statistics, and Python scripts for generating visualized flame graphs. The content is tailored for developers and performance engineers to capture, debug, and analyze system or program performance data efficiently.

## Detailed Description

### hiperf_5more.md
This document serves as a usage guide for hiperf, a cross-platform command-line tool designed for developers to capture and debug system or program performance data, similar to the Linux perf tool. The content covers environment prerequisites using hdc, command-line options for logging control, and detailed usage of the list command to identify supported event types. Key information includes parameters for filtering events by hardware, software, tracepoint, cache, and raw types, alongside an overview of core commands like dump, record, report, and stat. Intended for developers performing performance analysis, this reference requires familiarity with the hdc shell environment.

### record命令.md
This document provides a reference guide for the `hiperf record` command, a tool used to sample target programs and save performance data. It features a comprehensive parameter table detailing options for configuring sampling scope, such as CPU selection, process or thread IDs, duration, frequency, and specific events. Key sections cover call stack modes (fp/dwarf), output file settings, and application profiling. The document includes usage syntax and a practical example demonstrating how to sample a specific process ID. Intended for developers and performance engineers, this guide helps users configure granular profiling tasks to analyze system or application behavior efficiently.

### stat命令_3more.md
This reference documentation details the usage of three specific commands within the hiperf performance analysis tool: stat, dump, and report. The document is divided into three main sections, each dedicated to a command, providing parameter descriptions, usage syntax, and practical shell examples. Key information includes how to monitor performance counters in real-time, read raw perf.data files for verification, and generate formatted reports in JSON or ProtoBuf. It highlights parameters for setting collection duration, CPU IDs, and process filtering. This guide is intended for developers and performance engineers who need to profile application performance, verify raw sampling data, and analyze results.

### 脚本.md
This document serves as a usage guide for executing performance sampling operations and generating visualized flame graphs using Python scripts from the hiperf repository. It details three primary workflows: sampling processes or applications using command_script.py, collecting symbol tables via recv_binary_cache.py to resolve function names, and generating HTML flame graphs with make_report.py. Key information includes command-line examples for targeting specific packages, the logic for prioritizing local symbol paths over device files, and the default output filename for reports. Intended for general users and developers, this guide facilitates OpenHarmony system performance analysis through a structured, step-by-step scripting process.
