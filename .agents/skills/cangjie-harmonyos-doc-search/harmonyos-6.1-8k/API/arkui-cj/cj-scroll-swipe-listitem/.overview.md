## 详细描述

### cj-scroll-swipe-listitem.md

本文档是 ArkUI 框架中 ListItem 组件的 API 参考文档，旨在指导开发者使用仓颉语言在 List 容器中创建和配置列表项。主要内容包括模块导入、组件初始化、子组件规则、通用属性与事件，以及 selectable 和 swipeAction 等特定组件属性和 onSelect 事件。关键信息包括该组件支持滑动操作、选择状态管理，且目前处于 Beta 阶段。文档面向使用仓颉语言进行 ArkUI 应用开发的开发者，提供了基础用法示例以帮助实现可滚动的交互式列表。
