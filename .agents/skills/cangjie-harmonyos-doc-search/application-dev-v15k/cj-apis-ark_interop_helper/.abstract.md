This directory hosts the `cj-apis-ark_interop_helper` module, a critical technical repository for developers working within the HarmonyOS ArkUI framework. It focuses on enabling seamless interoperability between ArkTS and native Cangjie code, addressing the complexities of cross-language communication. The module provides essential public auxiliary functions for high-performance applications, specifically targeting data type conversions—such as mapping native HashMap structures to JavaScript values—and managing application contexts across both FA and Stage models. It is tailored for HarmonyOS developers who require robust tools for native-bridge interactions, system capability integration, and optimizing the interface between the ArkTS runtime and native NAPI layers. This documentation is particularly relevant for projects utilizing API version 12 and the SystemCapability.ArkUI.ArkUI.Napi capability, ensuring type safety and data integrity during complex cross-language calls.
