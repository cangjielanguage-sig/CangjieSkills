This directory provides comprehensive API reference documentation for the `ohos.router` module and associated classes within the Cangjie ArkUI framework. It covers essential page routing functionalities, including URL-based navigation, page stack manipulation, and state management. Key topics include the `RouterState` class, `RouterMode` enumeration, and specific lifecycle constraints for routing operations. The documentation highlights strict usage rules, such as the requirement to invoke routing methods only after page rendering. This resource is specifically designed for HarmonyOS developers working in a pure Cangjie environment to implement robust navigation logic and manage page transitions effectively.
