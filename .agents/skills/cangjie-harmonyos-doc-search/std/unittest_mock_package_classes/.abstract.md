This directory serves as a comprehensive and detailed API reference for the core classes within the Cangjie unit testing framework's mock package. It focuses extensively on the essential mechanisms required for effective testing, specifically covering the complex topics of mocking, stubbing, and verification of object interactions. The documentation provides in-depth information on critical components such as ActionSelector, MockFramework, and various specific selectors designed for methods, getters, and setters. It is primarily designed for Cangjie developers and QA engineers who need to implement robust unit tests with precise control over object behavior and dependency isolation. By utilizing these resources, users can effectively manage mock lifecycles, define complex argument matchers, and enforce strict interaction rules to ensure code reliability. This collection of documents is essential for anyone looking to master the intricacies of the Cangjie testing ecosystem and significantly improve the quality of their software through rigorous testing practices. Whether you are building a new feature or maintaining legacy code, understanding these classes is crucial for ensuring that your unit tests are both reliable and maintainable.
