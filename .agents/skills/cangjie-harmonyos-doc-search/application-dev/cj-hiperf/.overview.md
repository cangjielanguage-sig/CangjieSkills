# cj-hiperf

This directory serves as a comprehensive resource for `cj-hiperf`, a specialized performance analysis framework tailored for the OpenHarmony operating system. It centers on the `hiperf` tool, a cross-platform command-line interface that mirrors the functionality of Linux `perf`. The documentation guides users through the entire performance analysis lifecycle, from initial environment setup to executing core commands for data recording and statistical reporting. Additionally, it includes Python utilities for creating visualized flame graphs. This repository is essential for developers and performance engineers aiming to diagnose system bottlenecks, debug complex issues, and optimize the efficiency of applications running within the OpenHarmony ecosystem.

### [1] hiperf/
This directory contains documentation for `hiperf`, a cross-platform command-line performance analysis tool similar to Linux perf, designed for the OpenHarmony environment. It covers environment setup, core commands for recording and reporting statistics, and Python scripts for generating visualized flame graphs. The content is tailored for developers and performance engineers to capture, debug, and analyze system or program performance data efficiently.
