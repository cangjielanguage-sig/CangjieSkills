## 开发步骤

### 生成密钥

1. 指定密钥别名。

2. 初始化密钥属性集。

3. 调用[generateKeyItem](../../cj-apis-security_huks/.overview.md)生成密钥，具体请参见[密钥生成](./cj-huks-key-generation-overview.md)。

除此之外，开发者也可以参考[密钥导入](./cj-huks-key-import-overview.md)，导入已有的密钥。

### 签名

1. 获取密钥别名。

2. 指定待签名的明文数据。

3. 获取属性参数HuksOptions，包括两个字段properties和inData。inData传入明文数据，properties传入[算法参数配置](../../cj-apis-security_huks/.overview.md)。

4. 调用[initSession](../../cj-apis-security_huks/.overview.md)初始化密钥会话，并获取会话的句柄handle。

5. 调用[finishSession](../../cj-apis-security_huks/.overview.md)结束密钥会话，获取签名signature。

### 验签

1. 获取密钥别名。

2. 获取待验证的签名signature。

3. 获取属性参数HuksOptions，包括两个字段properties和inData。inData传入签名signature，properties传入[算法参数配置](../../cj-apis-security_huks/.overview.md)。

4. 调用[initSession](../../cj-apis-security_huks/.overview.md)初始化密钥会话，并获取会话的句柄handle。

5. 调用[updateSession](../../cj-apis-security_huks/.overview.md)更新密钥会话。

6. 调用[finishSession](../../cj-apis-security_huks/.overview.md)结束密钥会话，验证签名。

### 删除密钥

当密钥废弃不用时，需要调用[deleteKeyItem](../../cj-apis-security_huks/.overview.md)删除密钥，具体请参见[密钥删除](./cj-huks-delete-key.md)。
