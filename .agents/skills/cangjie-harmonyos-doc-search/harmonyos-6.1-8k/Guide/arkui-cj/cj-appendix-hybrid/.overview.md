# cj-appendix-hybrid

本目录提供了关于在ArkTS应用中集成仓颉语言开发UI组件的混合开发指南。文档详细介绍了混合开发的背景、与纯仓颉模式的区别（如生命周期和路由限制）、工程配置步骤及代码示例。核心机制涉及利用ArkUI的NodeContainer和互操作能力，通过`@HybridComponentEntry`修饰仓颉组件并在ArkTS中使用`CJHybridComponent`加载。通过本指南，开发者可以掌握如何在保持ArkTS主工程结构的同时，有效复用仓颉编写的UI模块。该资源适合需要在OpenHarmony平台上结合ArkTS与仓颉语言进行应用开发的开发者参考。

## 详细描述

### cj-appendix-hybrid.md cj-appendix-hybrid.md

本文档旨在指导开发者如何在ArkTS应用中集成仓颉语言开发的UI组件，实现混合开发。内容涵盖混合开发背景、与纯仓颉模式的异同（如生命周期和路由限制）、工程配置步骤及代码示例。核心机制是利用ArkUI的NodeContainer和互操作能力，通过`@HybridComponentEntry`修饰仓颉组件，并在ArkTS中使用`CJHybridComponent`进行加载。文档特别强调了当前的技术限制，例如不支持跨语言状态同步及完整页面生命周期，这对于架构设计至关重要。该文档适用于需要在OpenHarmony平台上结合ArkTS与仓颉进行应用开发的开发者，提供了从理论到实践的完整路径。
