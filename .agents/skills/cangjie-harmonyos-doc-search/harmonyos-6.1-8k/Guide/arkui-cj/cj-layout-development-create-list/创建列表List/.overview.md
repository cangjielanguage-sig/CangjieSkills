# 创建列表List

本目录汇集了关于ArkUI框架中List组件的全面开发指南，涵盖了从基础创建到高级交互的各个方面。内容主要包括列表的布局构建、数据迭代渲染、分组显示、样式自定义以及滚动位置控制等核心功能。此外，还深入探讨了侧滑操作、折叠展开、粘性标题及长列表性能优化等高级特性。文档主要面向使用ArkUI和仓颉（Cangjie）语言进行HarmonyOS应用开发的开发者，旨在帮助他们构建高效、交互丰富的滚动列表界面。

## 详细描述

### 创建列表List_2more_c7382ab1.md
本文档介绍如何使用List组件创建可滚动列表容器，涵盖定义、适用场景及构建方法。重点讲解自动滚动、条件渲染、循环渲染及懒加载功能，适用于高效展示结构化数据。

### 响应列表项侧滑_3more_60a53273.md
面向ArkUI/Cangjie开发者的交互指南，涵盖利用swipeAction实现侧滑删除、使用Badge添加未读标记，以及基于触摸事件或Refresh组件实现下拉刷新与上拉加载。

### 布局与约束.md
阐述List组件的布局能力及尺寸约束规则，包括组件关系、垂直/水平布局模式及主轴交叉轴约束机制，帮助开发者理解自适应延伸和自动调整逻辑。

### 开发布局_2more_2ebc9c6c.md
指导使用Cangjie构建List布局，内容包括设置主轴方向、配置交叉轴布局及显示数据。重点介绍ListItem的使用限制及lanes、alignListItem等属性配置。

### 折叠与展开.md
关于使用Cangjie实现列表项折叠与展开的教程，涵盖定义数据结构、构造UI结构及通过状态控制实现rotate属性和onClick事件的平滑动效。

### 控制滚动位置_2more_e6a56bcb.md
指导在ArkUI中使用Cangjie控制List滚动位置，包括通过Scroller对象实现快速定位，以及利用onScrollIndex事件监听实现与AlphabetIndexer的联动。

### 支持分组列表_adcb853b.md
指导利用List组件实现数据分组展示，主要介绍ListItemGroup组件的使用方法，包括header参数设置及结合ForEach进行循环渲染的技巧。

### 添加粘性标题.md
指导为列表组件实现粘性标题效果，涵盖概念定义及利用sticky属性与ListItemGroup配合的具体实现方法，提供基于仓颉语言的代码示例。

### 编辑列表_2more_47baa191.md
介绍列表编辑模式及长列表性能优化，涵盖列表项增删操作，以及利用LazyForEach和cachedCount实现按需加载和减少滑动白块的策略。

### 自定义列表样式.md
针对Cangjie开发者的样式配置指南，讲解如何通过space、divider及scrollBar属性自定义List组件的视觉效果，优化布局细节和用户体验。

### 迭代列表内容_37289b06.md
指导在仓颉ArkUI中使用ForEach实现列表内容的动态循环渲染，涵盖基本概念、应用方法及通过Contact类构建联系人列表的代码示例。
