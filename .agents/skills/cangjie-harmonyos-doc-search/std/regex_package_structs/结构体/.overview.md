### struct_Position.md struct_Position.md
This document provides API reference documentation for the Position struct in the Cangjie programming language, designed to store location information. The main sections detail the struct's definition and its two public properties, start and end. Key information highlights that Position represents a half-open interval using Int64 values, meaning the range includes the start position but excludes the end position. This is essential for developers working with text ranges or data segments. The intended audience consists of Cangjie developers seeking to implement or understand position-based logic. Prerequisites include familiarity with Cangjie syntax and basic data types. Keywords: Cangjie, struct, Position, API reference, Int64, half-open interval, range.
