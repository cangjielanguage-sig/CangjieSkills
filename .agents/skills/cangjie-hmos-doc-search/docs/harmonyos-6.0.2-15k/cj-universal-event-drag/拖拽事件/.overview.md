This directory provides comprehensive documentation for implementing drag-and-drop functionality in the Cangjie ArkUI framework. It covers essential API references for event handling (onDragStart, onDrop, onDragEnter, etc.), configuration attributes, and data structures like DragInfo and DragEvent. The content includes detailed function signatures, version differences (API 12 vs 19), and practical code examples for customizing drag visuals and managing interactions. It is suitable for Cangjie developers and HarmonyOS engineers looking to build interactive UI components with robust drag-and-drop capabilities.

## Detailed Description

### func_onDragEnterDragInfo_-_6more.md func_onDragEnterDragInfo_-_6more.md
This document provides API reference documentation for drag-and-drop event handling functions in the Cangjie ArkUI framework. It details three primary functions: onDragEnter, onDragMove, and onDragLeave, each offering two overloaded versions based on API level 12 or 19. The API 12 versions accept a DragInfo callback, while API 19 versions accept DragEvent and an optional string for extra JSON parameters. Crucially, these events only function when an onDrop event listener is present. This reference is intended for Cangjie developers implementing interactive drag-and-drop UI components.
