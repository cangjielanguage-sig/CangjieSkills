# 常用命令

This directory contains a comprehensive collection of command references for the `hidumper` tool, essential for OpenHarmony and HarmonyOS system diagnostics. It covers a wide range of functionalities including system information retrieval, process monitoring, memory analysis, IPC statistics, and specific service debugging like WindowManager and RenderService. The guides provide syntax for dumping heap snapshots, checking FPS, and managing crash logs. These resources are designed for developers and system administrators who need to inspect system state, debug services, analyze resource usage, or diagnose performance bottlenecks and memory leaks in a production or development environment.

## Detailed Description

### 常用命令_1.md 常用命令_1.md
This document serves as a command reference guide for the hidumper tool used in OpenHarmony system diagnostics and debugging. It covers viewing help text, listing system information clusters and system abilities, and retrieving detailed information for specific clusters like base and system or specific system abilities. Key takeaways include commands for dumping process, memory, network, and CPU statistics, as well as advanced options for heap snapshots and garbage collection. This guide is intended for developers and system administrators who need to inspect system state, debug services, or analyze resource usage within the OpenHarmony environment.

### 常用命令_2.md 常用命令_2.md
This document serves as a technical reference guide for using the hidumper command-line tool to inspect and debug system services in an OpenHarmony environment. It details specific commands for WindowManagerService to dump window data, RenderService to monitor FPS, memory, and surface information, and PowerManagerService to control screen timeout settings. Additionally, it explains how to retrieve crash history via the Faultlog module. Key takeaways include syntax for dumping specific window IDs, checking frame rates, and preventing automatic screen sleep. This guide is intended for developers and system administrators diagnosing system performance or stability issues.

### 常用命令_3.md 常用命令_3.md
This document serves as a command reference guide for using the hidumper tool to monitor system resources and performance metrics. It details specific commands for retrieving network traffic, storage I/O, process and thread lists, CPU usage statistics, CPU core frequencies, and memory information. Key takeaways include the ability to filter most outputs by Process ID (PID) and a critical restriction where process information export is limited to debug applications in release versions. This guide targets developers and system administrators seeking to diagnose system performance or debug application behavior.

### 常用命令_4.md 常用命令_4.md
This reference guide documents the usage of the hidumper command-line tool for system diagnostics, focusing on memory analysis, log archiving, and IPC statistics. The content covers memory inspection commands including general usage, specific PID details, pruned views, and time-interval monitoring. It details command syntax, output field definitions like Pss, Vss, and Graph memory metrics, and provides practical examples for monitoring memory changes. Additionally, it explains output compression to zip files and Inter-Process Communication data collection workflows. Intended for system developers or engineers with knowledge of Linux process management, this guide aids in debugging performance issues and tracking system resource usage.

### 常用命令_5.md 常用命令_5.md
This document serves as a technical reference guide for using the hidumper tool to analyze Inter-Process Communication (IPC) performance and detailed memory usage. It covers IPC statistics commands for specific or all processes, including starting, viewing, and stopping statistics to track time costs and call counts. Additionally, it explains the mem-smaps command for exporting detailed process memory information. Key takeaways include specific command syntaxes, output format examples, and the restriction that memory smaps are only available in debug versions. This guide is intended for system developers and debuggers diagnosing performance bottlenecks or memory issues.

### 常用命令_6.md 常用命令_6.md
This document serves as a technical reference guide for the hidumper command-line tool, focusing on system diagnostics and memory analysis. It covers a comprehensive list of general usage flags for system information, processes, and resources, followed by detailed instructions for JavaScript heap and Cangjie heap memory dumping. Key takeaways include the syntax for triggering garbage collection, exporting heap snapshots, and identifying memory leaks, along with specific output file locations and version compatibility notes for HarmonyOS. Intended for developers and system administrators debugging performance issues or memory leaks in HarmonyOS applications.
