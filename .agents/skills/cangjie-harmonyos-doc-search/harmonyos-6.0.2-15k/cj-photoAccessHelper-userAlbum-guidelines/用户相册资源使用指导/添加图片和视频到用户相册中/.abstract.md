This directory provides comprehensive technical guidance for HarmonyOS developers on how to programmatically add images and videos to specific user albums. It focuses on utilizing the MediaLibraryKit within the Cangjie programming environment. The content covers essential prerequisites, such as permission handling and context initialization, and details the step-by-step development process for media manipulation. It is suitable for developers who need to manage user media libraries and possess prior knowledge of Cangjie, ArkTS, and system lifecycle management. The included files offer both the core logic implementation and the necessary application setup code to ensure a functional development environment.
