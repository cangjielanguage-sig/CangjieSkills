### cj-hiappevent-watcher-freeze-events.md

This document provides a detailed technical reference for the HiAppEvent API, specifically focusing on the mechanisms required to subscribe to system app freeze events. It serves as a structural guide for the `appfreeze` event, meticulously defining its data structure to aid developers in debugging. The core of the documentation lies in its breakdown of the `params` attribute, which is dissected into nested components including general parameters, exception details, thread stack traces, frame information, and memory statistics. By highlighting specific event types like `THREAD_BLOCK_6S`, the document enables precise identification of blocking issues. Additionally, it offers practical warnings regarding external log file size limits, helping developers avoid common pitfalls like write failures. This guide is intended for developers using the Cangjie language framework who are focused on system monitoring and need to interpret freeze event data to ensure application stability and performance. This documentation is crucial for ensuring robust error handling and performance tracking in Cangjie applications.
