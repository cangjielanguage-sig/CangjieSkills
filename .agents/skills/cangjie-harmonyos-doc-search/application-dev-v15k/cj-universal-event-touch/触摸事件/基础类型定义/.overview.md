# 基础类型定义

This directory provides essential API reference documentation for fundamental data structures within the ArkUI framework, specifically designed for the Cangjie programming language. It focuses on the core classes required to handle user input and touch interactions effectively. The documentation covers the `TouchEvent` class, which encapsulates event data and propagation logic, and the `TouchObject` class, which defines the specific attributes of individual touch points, such as coordinates and identification. These resources are critical for developers aiming to build interactive and responsive UI applications, offering detailed insights into event handling mechanisms and coordinate systems.

## Detailed Description

### class_TouchEvent.md class_TouchEvent.md
This document provides API reference documentation for the TouchEvent class in the Cangjie language, detailing the structure and properties of touch events within the ArkUI framework. It covers class properties including eventType, touches, changedTouches, timestamp, target, and source, along with a constructor for object initialization. A crucial distinction is made between touches (device refresh rate) and changedTouches (screen refresh rate/resampled) in non-injection scenarios. The class inherits from BaseEvent and includes a flag isStopPropagation to control event bubbling. This reference is intended for software developers building UI applications using ArkUI, requiring knowledge of Cangjie syntax and event handling mechanisms.

### class_TouchObject.md class_TouchObject.md
This document serves as API reference documentation for the Cangjie language, specifically detailing the TouchObject class used within the ArkUI framework. The primary purpose is to define a data structure representing current finger touch information. The main sections cover the class constructor and its public properties, including touchType, id, screenX, screenY, x, and y. Key information includes the distinction between screen-relative coordinates and element-relative coordinates, along with unique finger identification. This reference is intended for developers building UI applications who need to handle touch interactions. Relevant keywords include TouchObject, Cangjie, ArkUI, touch events, and coordinates.
