This directory contains a specialized technical guide designed for developers working with the Cangjie programming language, focusing specifically on the generation of SHA256 message digests. It addresses the critical need for secure data hashing by exploring two distinct implementation methodologies: single-pass processing and segmented chunk handling. The guide thoroughly documents the utilization of the CryptoArchitectureKit, breaking down the specific roles of essential functions like `createMd`, `update`, `digest`, and `getMdLength`. Designed for Cangjie developers targeting API version 12 or higher, this resource is particularly valuable for those creating software for lightweight wearable devices. It ensures developers can implement efficient, memory-conscious cryptographic operations essential for modern embedded applications, balancing security requirements with the limited processing power available on such hardware. The guide serves as a bridge between high-level cryptographic theory and practical, implementable code for the Cangjie ecosystem.
