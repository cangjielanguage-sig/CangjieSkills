# 请求UI绘制帧率

This directory focuses on the technical implementation of requesting and managing UI drawing frame rates within the Cangjie programming language ecosystem. It provides comprehensive guidance on using the DisplaySync API to achieve variable frame rate animations, allowing developers to optimize rendering performance for specific UI components. Key concepts include configuring ExpectedFrameRateRange, managing animation lifecycles, and handling frame callbacks to update visual elements dynamically. This material is essential for developers building graphical user interfaces on HarmonyOS or OpenHarmony platforms who require precise control over refresh rates to balance performance and visual quality.
