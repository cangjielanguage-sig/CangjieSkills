# Image

## Detailed Description

### Image_6more_8a3a9f86.md Image_6more_8a3a9f86.md
这是一份ArkUI框架中Image组件的API参考文档，旨在指导开发者使用Cangjie语言在应用中显示图片。文档主要涵盖模块导入、网络权限配置及组件初始化方法，详细介绍了通过ResourceStr和PixelMap两种数据源加载图片的构造函数。关键信息包括支持多种图片格式（如SVG、GIF）、动画播放与可见性的关系，以及图片加载失败时的默认布局行为。文档还说明了通用属性的支持情况，特别指出需使用fillColor替代foregroundColor。该文档适合具备ArkUI基础的开发者查阅。

### type_ImageComplet_2more_a56e17e3.md type_ImageComplet_2more_a56e17e3.md
本文档定义了Cangjie编程语言中用于处理图片加载事件的回调函数类型。主要包含两个类型定义：`ImageCompleteCallback`用于处理图片加载完成，`ImageErrorCallback`用于处理加载错误。关键信息在于这两个类型均为函数类型，前者接收`ImageLoadResult`参数，后者接收`ImageError`参数，且均无返回值（Unit）。面向使用图片加载功能的开发者，适用于需要实现异步加载结果处理或错误监听的场景。

### 组件事件_491f3779.md 组件事件_491f3779.md
这份文档是ArkUI框架中图片组件事件处理的API参考手册，主要面向使用仓颉语言的开发者。文档详细定义了三个关键事件处理接口：onComplete用于在图片加载成功时获取尺寸，onError用于捕获加载异常，onFinish则专门用于监听SVG动效播放完成（非无限循环）。所有接口均支持系统能力SystemCapability.ArkUI.ArkUI.Full，起始版本为22。通过这些回调函数，开发者可以精确控制图片加载流程及动效交互，提升应用的用户体验。

### 基础类型定义/
本目录包含ArkUI框架在仓颉语言下的基础类型定义文档，主要涉及图像处理领域的核心数据结构。内容涵盖了用于构建颜色滤镜矩阵的ColorFilter类、处理图片加载异常的ImageError类，以及封装图片加载成功结果的ImageLoadResult类。这些API参考文档适用于ArkUI应用开发者，旨在提供图像色彩处理、错误回调机制及加载状态管理的详细规范，帮助开发者在UI渲染和状态判断中正确使用这些数据结构。

### 示例代码/
本目录包含使用仓颉语言在 ArkUI 框架下进行图片处理的示例代码。内容涵盖了基本图片格式加载、事件处理、图片填充模式设置、动态图片源切换以及 SVG 颜色修改等核心功能。这些示例旨在帮助 HarmonyOS 开发者深入理解 Image 组件的用法及交互逻辑，适合正在使用仓颉语言进行应用开发的用户参考。

### 组件属性/
本目录包含Cangjie语言ArkUI框架中图片组件的API参考文档，主要涵盖组件属性的配置与优化。内容涉及图片显示属性（如占位图、颜色填充、缩放适配）以及样式与加载行为（如重复样式、渲染模式、解码尺寸）。这些文档旨在帮助开发者精细控制图片的渲染效果、内存占用及加载性能，适用于使用Cangjie进行ArkUI应用开发的专业人员。
