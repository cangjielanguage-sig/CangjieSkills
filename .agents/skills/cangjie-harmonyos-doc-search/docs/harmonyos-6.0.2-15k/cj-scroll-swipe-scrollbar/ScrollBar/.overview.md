# ScrollBar

This directory contains comprehensive documentation for the ScrollBar component within the ArkUI framework, specifically utilizing the Cangjie language. It covers the component's layout constraints, initialization APIs, code examples for custom and default styling, and nested scrolling configurations. Key topics include Scroller binding, main axis sizing, direction settings, and event handling. This resource is suitable for UI developers and software engineers looking to implement or customize scrollable interfaces in List, Grid, or WaterFlow components.

## Detailed Description

### ScrollBar_2more.md
This document serves as a reference guide for the ScrollBar component, designed to accompany scrollable elements like List, Grid, Scroll, and WaterFlow. It details the component's description, layout constraints regarding main axis size, and child component rules. Key information includes a critical recommendation to explicitly set the ScrollBar's main axis size when used within scrollable parents to prevent infinite sizing issues, as it otherwise defaults to the parent's maxSize. The document also specifies that the ScrollBar can contain only a single child component. This technical reference is intended for UI developers implementing custom scrollbars who need to understand specific layout behaviors and component constraints.

### 创建组件.md
This document serves as API reference documentation for initializing a ScrollBar component using the Cangjie language within the ArkUI framework. It details four overloaded init constructors that allow developers to instantiate the component with varying levels of configuration. Key parameters include a mandatory Scroller controller for binding to scrollable content and a child lambda for defining sub-components. The constructors optionally accept direction and state parameters to control orientation and visibility, with defaults set to Vertical and Auto respectively. This technical guide is intended for software developers implementing scrollable user interfaces, requiring knowledge of ArkUI system capabilities and component binding.

### 示例代码.md
This document provides Cangjie code examples demonstrating how to implement and customize the ScrollBar component within a UI layout. It covers two distinct scenarios: setting a child node for custom styling and omitting the child node for default system styling. The examples illustrate the relationship between the Scroll and ScrollBar components, which are linked via a shared Scroller object. The first example customizes the bar's appearance using a styled Text component, while the second relies on the default implementation. This guide is intended for UI developers using the Cangjie language, specifically those working with scrollable lists and layout components.

### 通用属性通用事件_2more.md
This document serves as an API reference for configuring nested scrolling behavior within the ArkUI framework. It covers general properties and events, specifically detailing the `enableNestedScroll` function under component attributes. The function accepts a boolean parameter to control whether a scrollbar performs nested scrolling. Key information includes the offset propagation logic, where offsets pass from inner to outer components based on priority. It also notes limitations, such as incompatibility with WaterFlow's SLIDING_WINDOW mode, and requirements for custom logic when using PARALLEL mode. This technical guide is intended for developers implementing complex scrollable interfaces.
