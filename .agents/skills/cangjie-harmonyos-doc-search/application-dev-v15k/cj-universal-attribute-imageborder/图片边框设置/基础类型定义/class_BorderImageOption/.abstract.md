This directory contains comprehensive API reference documentation for the `BorderImageOption` class within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the configuration of image and gradient borders for UI components, detailing essential properties such as source, slice, width, outset, repeat, and fill. The documentation explains how to apply custom image borders to container components like Row and Column, supporting various dimension types and repetition modes. This resource is suitable for Cangjie developers and UI designers seeking to implement complex border styling and enhance visual aesthetics in their applications starting from API version 19. By utilizing these resources, developers can effectively manage border image slicing and repetition to achieve precise visual designs.
