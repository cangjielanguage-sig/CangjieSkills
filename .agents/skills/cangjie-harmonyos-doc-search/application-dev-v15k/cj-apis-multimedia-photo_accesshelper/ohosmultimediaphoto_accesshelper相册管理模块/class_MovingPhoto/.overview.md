# class_MovingPhoto

This directory provides comprehensive API reference documentation for the `MovingPhoto` class in the Cangjie language, tailored for HarmonyOS developers. It focuses on the management of dynamic photo objects, covering essential operations such as retrieving photo URIs and fetching image or video content. The documentation includes detailed information on system capabilities, specific error codes for parameter and system failures, and permission requirements like `ohos.permission.READ_IMAGEVIDEO`. It is designed for developers utilizing the `MediaAssetManager` and `MediaLibraryKit` to handle media assets, offering code examples and implementation guidance for robust media application development.

### class_MovingPhoto_3more.md class_MovingPhoto_3more.md

The main sections cover the class definition and two key functions: `getUri()`, which retrieves the photo's URI string, and `requestContent()`, which fetches image and video content using provided URIs. The document targets developers working with media assets, providing code examples for implementation using the MediaAssetManager.

It covers two primary function signatures: one that writes content to a specified file URI and another that returns data as a byte array. Key information includes the requirement for the `ohos.permission.READ_IMAGEVIDEO` permission, with exceptions for app-owned resources, and specific error codes for permission or parameter failures. This reference guide targets developers using the MediaLibraryKit to manage media assets within HarmonyOS applications, providing syntax, parameters, and usage examples for accessing image and video data.
