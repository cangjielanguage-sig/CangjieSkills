# 指定二进制数据转换非对称密钥对仓颉

This directory provides technical guides for converting external binary data into asymmetric key pairs using the Cangjie programming language and the CryptoArchitectureKit. It covers specific algorithms including ECC, SM2, and RSA, detailing how to handle raw binary data, PKCS#8, and X.509/DER formats. The tutorials demonstrate the use of `AsyKeyGenerator`, `DataBlob`, and the `convertKey` method to import and restore cryptographic keys. These resources are designed for software developers and security engineers who need to integrate existing key material into Cangjie applications for encryption, decryption, or signature operations.

## Detailed Description

### 指定二进制数据转换ECC密钥对_2more.md
This technical guide explains how to convert binary data into Elliptic Curve Cryptography (ECC) key pairs using the CryptoArchitectureKit in the Cangjie programming language. It covers two primary workflows: converting raw public and private key binary data into a KeyPair object, and converting PKCS8 formatted binary data specifically for ECC private keys. Key steps include creating an AsyKeyGenerator with the 'ECC256' parameter, encapsulating binary data into DataBlob objects, and utilizing the convertKey method. The document provides practical code examples demonstrating data encapsulation, encoding retrieval via getEncoded, and error handling. This tutorial targets software developers who need to import or transform existing cryptographic key material within the specified development environment.

### 指定二进制数据转换SM2密钥对.md
This document serves as a technical tutorial explaining how to convert binary data into an SM2 asymmetric key pair. It details the process of encapsulating public and private key data into DataBlob objects, creating an AsyKeyGenerator using the 'SM2_256' algorithm, and calling the convertKey function to generate a KeyPair object. The document provides a complete Cangjie code example demonstrating these steps, including error handling. It is intended for developers using the CryptoArchitectureKit who need to import or restore SM2 keys from raw binary data.

The document details the RSA conversion process, which involves encapsulating binary data into a DataBlob, creating an AsyKeyGenerator instance, and calling the convertKey method. It includes a practical Cangjie code example using the CryptoArchitectureKit.
