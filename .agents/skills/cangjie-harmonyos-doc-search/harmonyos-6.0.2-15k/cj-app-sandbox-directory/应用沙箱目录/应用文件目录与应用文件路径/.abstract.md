This directory provides comprehensive technical documentation on HarmonyOS application file structures and path management. It covers the app sandbox hierarchy, encryption levels (EL1-EL5), and specific directory purposes such as persistent storage, caching, and distributed files. Key topics include Context API usage for path retrieval, security capabilities, and lifecycle behaviors like automatic cleanup. Suitable for HarmonyOS developers, this guide ensures correct implementation of data persistence, resource management, and security within the operating system environment. It distinguishes between global and HAP-level storage and advises on best practices for data encryption and file access. By following these guidelines, developers can effectively manage data lifecycles and ensure application compatibility across different HarmonyOS environments while maintaining high security standards.
