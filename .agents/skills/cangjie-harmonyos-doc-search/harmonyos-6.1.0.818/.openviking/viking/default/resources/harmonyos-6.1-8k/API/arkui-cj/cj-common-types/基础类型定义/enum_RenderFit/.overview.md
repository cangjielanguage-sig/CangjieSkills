# enum_RenderFit

本目录包含ArkUI框架中RenderFit枚举的API参考文档，主要用于定义组件内容的缩放模式、填充样式及对齐方式。文档详细介绍了多种枚举值，如ResizeCover、ResizeContain等，涵盖了保持宽高比缩放、位置对齐以及比较运算符重载等核心功能。这些API适用于使用仓颉语言进行ArkUI界面开发的开发者，旨在帮助其实现精确的UI组件内容布局和显示控制。系统能力要求为ArkUI.Full，起始版本为22。
