# struct_Emitter

This directory contains API reference documentation for the `Emitter` struct in the Cangjie programming language, designed to facilitate event-driven communication within applications. It covers static methods for subscribing to, unsubscribing from, and dispatching events, including support for one-time listeners and priority-based message handling. Key functionalities include managing listener counts, handling `InnerEvent` and string identifiers, and error management for invalid event IDs. This documentation is suitable for Cangjie developers implementing robust event queues and notification systems using the SystemCapability.Notification.Emitter capability.
