This directory contains API reference documentation for extending the `Random` type in the Cangjie programming language to implement the `RandomSource` interface. It covers a comprehensive suite of pseudo-random number generation functions across various data types, including signed and unsigned integers (Int8-64, UInt8-64), floating-point numbers (Float16-64), Booleans, and Runes. The documentation details functions for generating values within default ranges, specific bounds, and Gaussian distributions. It is suitable for Cangjie developers seeking to implement or extend randomization logic in their applications.
