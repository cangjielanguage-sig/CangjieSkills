This directory contains API reference documentation for the `IPPrefix` class within the Cangjie programming language's standard library. It focuses on representing and manipulating IP address subnets, which are defined by a starting address and a prefix length. The documentation covers essential functionality including parsing string representations, handling errors via exceptions or optional types, and calculating broadcast addresses. It includes practical code examples for both IPv4 and IPv6 protocols. This resource is suitable for software developers working with network protocols in Cangjie who need to perform precise network operations and subnet validations.
