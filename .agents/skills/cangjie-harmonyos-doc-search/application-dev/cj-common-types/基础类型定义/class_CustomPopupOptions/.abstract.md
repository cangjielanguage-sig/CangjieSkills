This directory contains API reference documentation for the `CustomPopupOptions` class within the Cangjie ArkUI framework. It covers the configuration and customization of popup windows, including content construction, positioning, styling, and event handling. Key topics include arrow configuration, background masking, shadow effects, transition animations, and state management. The documentation is designed for software developers and UI engineers using the Cangjie language to build interactive user interfaces with ArkUI system capabilities. It provides detailed parameters for implementing overlays, tooltips, and custom popups starting from API version 22.
