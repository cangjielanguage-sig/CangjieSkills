# 固定样式弹出框

This directory focuses on implementing fixed-style popup boxes in the HarmonyOS ArkUI framework using the Cangjie language. It covers various dialog types including ActionSheets, ActionMenus, and AlertDialogs, detailing how to configure options, handle asynchronous callbacks, and apply custom styles and animations. The guides emphasize practical implementation, UIContext usage, and complex transition effects. It is suitable for HarmonyOS developers and application engineers looking to create interactive, styled modal components with pre-defined layouts.

## Detailed Description

### 列表选择弹窗ActionSheet.md 列表选择弹窗ActionSheet.md
This document serves as a practical tutorial for implementing a list selection popup (ActionSheet) within the ArkUI framework using the Cangjie language. It focuses on the UIContext.showActionSheet interface to display multiple operation options. The main topic covers the configuration of ActionSheetOptions, including defining list items via SheetInfo and setting up a confirmation button. Key takeaways include how to customize the popup's appearance using properties like width, height, border radius, and background color, as well as implementing complex asymmetric transition animations for entry and exit effects. The document targets developers familiar with ArkUI and Cangjie who need to create interactive, styled dialog components for their applications. Keywords: ArkUI, Cangjie, ActionSheet, UIContext, showActionSheet, TransitionEffect, Dialog, UI component.

### 固定样式弹出框_4more.md 固定样式弹出框_4more.md
This document provides a guide for implementing fixed-style popup boxes in HarmonyOS ArkUI using the Cangjie language, designed to simplify development by offering pre-defined layouts. The main sections cover usage constraints, the ActionMenu (showActionMenu), and the Dialog (showDialog). Key information includes the requirement to obtain a PromptAction object via UIContext.getPromptAction() before invoking methods, support for non-modal modes, and asynchronous result handling through callbacks. The content targets HarmonyOS developers with knowledge of the Cangjie language and ArkUI framework, offering practical code examples for implementation.

### 警告弹窗AlertDialog.md 警告弹窗AlertDialog.md
This document serves as a technical guide for implementing and styling AlertDialogs within the Cangjie UI framework. It covers design principles regarding user interruption, configuration of dialog parameters, and animation effects. The key takeaway is the practical code example demonstrating the use of AlertDialogParamWithButtons to define titles, messages, button actions, and complex TransitionEffect animations, including asymmetric scaling and opacity changes. This resource is intended for application developers using the Cangjie language who need to create interactive modal dialogs with custom styles and transitions.
