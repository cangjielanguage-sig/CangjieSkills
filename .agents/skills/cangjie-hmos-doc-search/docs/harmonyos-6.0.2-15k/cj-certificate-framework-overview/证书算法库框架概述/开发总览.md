## 开发总览

证书算法库框架为开发者提供了以下相关功能的开发指导，请开发者参照开发。在开发前，请先查阅[证书规格](#证书规格)。

- [证书对象的创建、解析和校验](./cj-create-parse-verify-cert-object.md)
- [证书扩展信息对象的创建、解析和校验](./cj-create-parse-verify-certextension-object.md)
- [证书吊销列表对象的创建、解析和校验](./cj-create-parse-verify-crl-object.md)
- [证书链校验器对象的创建和校验](./cj-create-verify-cerchainvalidator-object.md)
- [证书集合及证书吊销列表集合对象的创建和获取](./cj-create-get-cert-crl-object.md)
- [证书链对象的创建和校验](./cj-create-verify-certchain-object.md)
- [证书链校验时从p12文件构造TrustAnchor对象数组](./cj-create-trustanchor-from-p12.md)

证书算法库框架主要提供了以下类，开发者可以查阅对应API参考，了解以下接口：

| 名称 | 类 | 功能 |
| -------- | -------- | -------- |
| X509证书 | [X509Cert](../../cj-apis-cert/.overview.md) | 提供X509证书的解析、序列化、X509证书签名验证、证书相关的信息查询等功能。 |
| 证书扩展域段 | [CertExtension](../../cj-apis-cert/.overview.md) | 提供X509证书中扩展域段的获取，如是否CA，CRL分发点等字段。 |
| X509证书吊销列表 | [X509CRL](../../cj-apis-cert/.overview.md) | 提供X509证书吊销列表的解析、序列化、信息查询等功能。 |
| 证书链校验器 | [CertChainValidator](../../cj-apis-cert/.overview.md) | 提供证书链校验（不包括证书有效期的校验）、证书链算法名称查询的功能。 |
| 证书和证书吊销列表集合 | [CertCRLCollection](../../cj-apis-cert/.overview.md) | 提供证书和证书吊销列表集合的查询功能。 |
| X509证书链 | [X509CertChain](../../cj-apis-cert/.overview.md) | 提供证书链校验、证书列表获取的功能。 |
