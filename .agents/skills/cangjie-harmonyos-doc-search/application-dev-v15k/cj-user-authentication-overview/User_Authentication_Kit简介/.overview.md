# User_Authentication_Kit简介

This directory provides an introduction to the User Authentication Kit, a system-level service designed to offer unified identity authentication capabilities. It covers the kit's definition, usage scenarios, and key features such as unified interfaces, trust level perception, and credential change detection. The documentation also outlines mandatory constraints for third-party applications, specifically regarding UI implementation and security policies. Additionally, it explores operational mechanisms like Authentication Trust Levels (ATL) and AuthToken generation within a Trusted Execution Environment (TEE). This resource is suitable for developers, security architects, and system integrators looking to integrate secure authentication methods like biometrics and passwords into their applications.

## Detailed Description

### User_Authentication_Kit简介_2more.md User_Authentication_Kit简介_2more.md
This document introduces the User Authentication Kit, a system-level service providing unified identity authentication capabilities using local credentials like passwords, face, and fingerprints. It covers the kit's definition, usage scenarios, and key features including unified interfaces, trust level perception, custom authentication methods, result reuse mechanisms, and credential change detection. Key takeaways include a normalized API for various auth factors, support for specifying trust levels to prevent low-security usage in high-risk scenarios, and the ability to reuse auth results within five minutes. This technical guide targets developers integrating secure authentication for sensitive operations like app logins or payments. Keywords: User Authentication, Biometrics, Security, Unified API, Trust Level.

### 约束与限制.md 约束与限制.md
This document serves as a reference guide outlining mandatory usage constraints for third-party applications accessing system-level local identity authentication features. The content focuses on the "Constraints and Limitations" section, which establishes strict rules regarding the user interface implementation. The key information provided is that third-party applications must exclusively use the system's built-in identity authentication control when invoking local authentication capabilities; custom or external controls are not permitted. The target audience includes third-party developers and system integrators working on identity verification features. Keywords: constraints, limitations, third-party applications, local identity authentication, system control, UI requirements, security policy.

### 运作机制/
This directory covers the operational mechanisms of the Unified User Authentication Framework, focusing on the intersection of user identity verification and secure key access. It provides a comprehensive look at how authentication trust is quantified and technically implemented within a secure environment. Key topics include the definition of Authentication Trust Levels (ATL) based on security metrics like FRR, FAR, and SAR, as well as the architectural details of AuthToken generation within a Trusted Execution Environment (TEE). This documentation is essential for developers, security architects, and system integrators who need to design robust authentication protocols or integrate secure key management services into their applications.
