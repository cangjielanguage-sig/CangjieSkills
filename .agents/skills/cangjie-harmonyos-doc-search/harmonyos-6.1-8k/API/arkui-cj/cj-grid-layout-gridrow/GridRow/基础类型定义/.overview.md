# 基础类型定义

本目录汇集了ArkUI框架中用于构建响应式栅格布局的核心基础类型定义。内容涵盖断点配置、栅格行列数设置、组件间距控制以及布局方向与参照物的枚举定义。这些API文档专为使用仓颉语言开发ArkUI应用的工程师设计，旨在提供精细化的布局控制能力，帮助开发者高效实现跨设备的自适应界面设计。

## 详细描述

### class_BreakPoints_b07f202d.md BreakPoints 类
本文档是Cangjie语言中BreakPoints类的API参考文档，旨在定义栅格容器组件的断点配置。文档详细说明了类的属性，包括用于设置单调递增断点位置数组的value属性（默认值为[320.vp, 600.vp, 840.vp]）和定义断点切换参照物的reference属性（默认为窗口大小），以及构造函数的初始化参数。该类属于ArkUI系统能力，起始版本为22。主要面向使用Cangjie开发ArkUI应用的开发者，适用于需要实现响应式布局的场景。

### class_GridRowOptions.md GridRowOptions 类
本文档是GridRowOptions类的API参考文档，旨在定义栅格布局在不同设备宽度下的列数配置。文档涵盖了类定义、六个断点属性（xs, sm, md, lg, xl, xxl）及两个构造函数。关键信息在于，该类通过可空Int32属性控制栅格组件在各尺寸设备上的占据列数或偏移量，支持分别设置各断点或统一设置。主要面向使用ArkUI和仓颉语言进行响应式界面开发的开发者，关键词包括GridRowOptions、栅格布局、断点和响应式设计。

### class_GutterOption_b7489b85.md GutterOption 类
本文档是Cangjie语言中GutterOption类的API参考文档，用于定义栅格布局子组件在不同方向的间距。文档涵盖了类的基本功能、系统能力及起始版本，重点介绍了两个构造函数重载：一个接受Length类型用于设置固定间距，另一个接受GridRowSizeOption类型用于动态尺寸配置。关键信息包括x和y方向参数的默认值（如0.vp）及其必填性。该文档面向ArkUI开发者，旨在帮助其在栅格系统中精确控制组件间距。关键词：GutterOption, ArkUI, 栅格布局, 间距, Cangjie, API文档。

### enum_BreakpointsR_2more_5e7a7d42.md BreakpointsReference 与 GridRowDirection 枚举
本文档是ArkUI框架下Cangjie语言的API参考文档，主要定义了BreakpointsReference和GridRowDirection两个枚举类型。文档涵盖了断点参照设置（WindowSize或ComponentSize）以及栅格布局方向控制（Row或RowReverse）的具体用法，并详细列出了各枚举成员及其相等性比较操作符。关键信息在于理解如何通过这两个枚举实现基于窗口或容器的响应式布局，以及控制栅格元素的排列方向。该文档面向使用Cangjie语言进行ArkUI应用开发的开发者，适用于需要精细控制布局断点和栅格排列的场景。

### class_GridRowSizeOption/ 子目录
本目录详细记录了ArkUI框架中GridRowSizeOption类的API参考文档，该类是构建响应式栅格布局的核心组件，专门用于配置栅格在不同设备断点下的尺寸选项。文档内容全面覆盖了类的定义、六个关键响应式断点属性（xs, sm, md, lg, xl, xxl）的详细说明以及构造函数的使用方法。这些属性均为可读写的Length类型，支持开发者针对从最小到超大宽度的设备屏幕进行精细化的布局定制。本资料主要面向使用仓颉语言进行ArkUI应用开发的工程师，旨在帮助其深入理解栅格布局机制，从而高效实现跨设备适配。
