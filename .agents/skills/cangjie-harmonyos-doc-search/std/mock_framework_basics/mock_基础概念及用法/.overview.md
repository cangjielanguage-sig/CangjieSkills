# mock_基础概念及用法

This directory serves as a foundational guide for using the Mock framework within the Cangjie programming language. It covers essential concepts such as the distinction between spy and mock objects, instantiation methods, and the necessary compilation configurations like the `--mock=on` flag. Additionally, it provides detailed documentation on the Configuration API for defining stub signatures, parameter matchers, and advanced behaviors. This resource is suitable for Cangjie developers and QA engineers looking to isolate units of code, simulate dependencies, and perform precise unit testing.

## Detailed Description

### 使用_spy_和_mock_对象_2more.md 使用_spy_和_mock_对象_2more.md
This technical guide explains the usage and configuration differences between spy and mock objects in the Cangjie testing framework. It details that spy objects call original implementations when unstubbed, while mock objects throw runtime errors, and highlights that static members behave like spies. The document further covers compilation requirements for mocking dependencies, specifically distinguishing between interfaces and classes. It provides instructions for using the `--mock=on` flag with the cjc compiler and the automatic detection features of cjpm. This guide is intended for developers seeking to isolate units of code and simulate specific test scenarios without relying on real dependencies.

### 创建_mock_对象.md 创建_mock_对象.md
This technical guide explains how to instantiate mock and spy objects for testing purposes in the Cangjie programming language. It details the `mock` and `spy` constructor functions, distinguishing between skeleton mock objects and spy objects that wrap existing instances. Key takeaways include that mocks perform no operations by default, whereas spies delegate calls to the underlying object. The document specifies that only classes and interfaces are supported for mocking, while referencing separate guides for usage and static declarations. Intended for developers writing unit tests, this reference material helps users simulate or monitor class and interface behavior effectively.

### 配置_API/
This directory provides comprehensive technical documentation for the Configuration API within a Cangjie mocking framework. It covers the fundamental aspects of creating and managing mock objects, including defining stub signatures, using parameter matchers, and configuring specific behaviors like return values and exceptions. The guides explain advanced features such as operation chaining and cardinality settings to ensure precise test control. This resource is intended for Cangjie developers and testers who need to isolate dependencies and simulate complex component interactions during unit testing.
