This directory contains API reference documentation for configuring the List component within the ArkUI framework using the Cangjie programming language. It covers a wide range of properties and functions essential for layout customization, performance optimization, and interaction design. Key topics include cross-axis alignment, lazy loading, multi-column structures, scroll behavior, and sticky headers. This documentation is suitable for UI developers and system architects who need to implement dynamic, high-performance list interfaces and require a deep understanding of Cangjie syntax and ArkUI component architecture.
