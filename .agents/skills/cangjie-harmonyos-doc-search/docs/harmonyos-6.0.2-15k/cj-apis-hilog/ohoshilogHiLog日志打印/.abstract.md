This directory contains comprehensive documentation for the HiLog logging system in the Cangjie language, specifically designed for OpenHarmony application development. It covers API references for core classes like `Hilog` and `HilogChannel`, the `LogLevel` enumeration, and practical usage guides for implementing logging functionality. Key topics include log severity levels, formatting, domain tagging, and debugging techniques. This resource is suitable for Cangjie developers and software engineers looking to integrate robust logging, monitor application status, and track errors effectively within the SystemCapability.HiviewDFX.HiLog framework.
