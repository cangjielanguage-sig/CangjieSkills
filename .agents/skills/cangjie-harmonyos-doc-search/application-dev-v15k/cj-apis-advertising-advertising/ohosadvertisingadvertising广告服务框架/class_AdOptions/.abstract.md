This directory provides comprehensive API reference documentation for the `AdOptions` class within the Cangjie AdsKit framework. It serves as a critical resource for developers looking to configure and manage advertising request instances effectively. The documentation covers essential aspects of ad configuration, including regulatory compliance settings such as child protection (COPPA), content classification ratings, and options for non-personalized advertising. Additionally, it details custom attributes that allow fine-tuning of ad behavior, such as duration limits and traffic management. This content is specifically tailored for software developers and engineers working with the Cangjie programming language who need to integrate robust advertising capabilities into their applications while adhering to SDK standards and syntax requirements. By understanding these parameters, developers can ensure their ad implementations are both compliant with regulations and optimized for user engagement.
