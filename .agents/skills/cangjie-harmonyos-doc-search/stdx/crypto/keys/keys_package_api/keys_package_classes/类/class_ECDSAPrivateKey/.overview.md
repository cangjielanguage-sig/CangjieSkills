# class_ECDSAPrivateKey

本目录包含 Cangjie 语言中 ECDSAPrivateKey 类的 API 参考文档，旨在为开发者提供关于椭圆曲线数字签名算法（ECDSA）私钥的全面操作指南。内容涵盖了私钥的生成、基于指定曲线的初始化、以及 DER 和 PEM 格式的编码与解码（支持加密）。文档详细介绍了如何使用私钥进行数据摘要签名，并说明了相关的异常处理机制（CryptoException）。核心关键词包括 ECDSA、私钥管理、DER 编码、PEM 格式、数字签名及 Cangjie 加密开发。这些文档适合需要在 Cangjie 环境下进行密钥安全存储、X.509 证书处理及实现数字签名功能的开发者阅读。
