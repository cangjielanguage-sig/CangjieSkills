This directory provides comprehensive API reference documentation for the `Orientation` enum in the Cangjie language, specifically designed to facilitate screen display management within the WindowManager system. It thoroughly covers various static orientation modes, including Portrait and Landscape, alongside their inverted counterparts. Furthermore, it details sensor-based AutoRotation features that can dynamically adjust the display based on device movement, with options to either respect or bypass system locks. The documentation also includes definitions for a Locked mode and specific operator overloads. Key concepts involve UI layout adaptation, screen rotation logic, and system capability dependencies. This resource is highly suitable for developers working on Cangjie applications who need to implement robust window management features and control screen orientation behaviors programmatically.
