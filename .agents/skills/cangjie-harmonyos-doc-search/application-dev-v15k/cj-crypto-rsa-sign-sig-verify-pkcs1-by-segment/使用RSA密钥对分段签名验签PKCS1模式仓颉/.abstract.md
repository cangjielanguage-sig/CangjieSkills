This directory serves as a comprehensive technical resource for developers utilizing the Cangjie framework, specifically focusing on the implementation of segmented RSA digital signatures and verification using the PKCS1 mode. It addresses the critical requirement of processing large data volumes efficiently by employing the SHA256 algorithm to handle data in discrete segments. The content covers the complete cryptographic lifecycle, including the generation of 1024-bit RSA key pairs, the initialization of Sign and Verify instances with corresponding private and public keys, and the iterative application of the update method for data processing. This collection is ideally suited for Cangjie developers, security engineers, and software architects aiming to implement robust data integrity checks and secure digital signature capabilities while optimizing memory management for large-scale data processing.
