# 基础类型定义

This directory provides fundamental type definitions and API references for implementing drag-and-drop functionality within the ArkUI framework using the Cangjie language. It covers essential classes, structs, and enumerations that manage drag behaviors, event states, and visual configurations. Key components include `DragInfo`, `DragBehavior`, `PreDragStatus`, and `DragEvent`, which collectively handle data transfer, gesture recognition, and animation control. This documentation is suitable for developers and UI engineers building interactive applications requiring precise drag-and-drop mechanics and custom visual feedback.

### class_DragInfo_2more.md class_DragInfo_2more.md

Intended for developers building UI interactions, this guide requires knowledge of Cangjie and ArkUI components, specifically targeting system version 12.

### enum_DragBehavior_2more.md enum_DragBehavior_2more.md
This document serves as API reference documentation for Cangjie language enums within the ArkUI framework, specifically managing drag-and-drop interactions. It covers two primary enumerations: DragBehavior, which defines data handling intent like copy or move for the drag source, and DragResult, which specifies operation outcomes such as success, failure, or drop permissions for the target. Key takeaways include understanding that DragBehavior describes intent without enforcing it, while DragResult controls drop states in events like onDrop and onDragMove. This guide targets developers building interactive UI components requiring drag-and-drop capabilities.

### enum_PreDragStatus.md enum_PreDragStatus.md
This API reference document defines the PreDragStatus enum, which enumerates the various states during the initialization phase of a drag gesture in the ArkUI framework. The document covers six specific enum values: ACTION_DETECTING_STATUS, READY_TO_TRIGGER_DRAG_ACTION, PREVIEW_LIFT_STARTED, PREVIEW_LIFT_FINISHED, PREVIEW_LANDING_STARTED, PREVIEW_LANDING_FINISHED, and ACTION_CANCELED_BEFORE_DRAG. Key information includes the functional description of each stage and specific trigger conditions, such as timing (e.g., 50ms or 500ms after press) or animation completion. This documentation is intended for ArkUI developers using the Cangjie language to implement or handle complex drag-and-drop interactions and animations.
