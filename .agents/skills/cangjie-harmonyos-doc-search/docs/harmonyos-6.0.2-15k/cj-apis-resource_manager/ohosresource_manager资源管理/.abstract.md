This directory contains API reference documentation for the `ohos.resource_manager` module in the Cangjie programming language, designed for HarmonyOS application development. It covers comprehensive resource management functionalities, including accessing strings, media, and configuration files, as well as handling device-specific states like screen density and locale. The documentation details classes for resource representation (`AppResource`), device configuration (`Configuration`), and capability descriptors, alongside enumerations for display modes and device types. It is suitable for Cangjie developers looking to implement resource localization, internationalization, and dynamic asset loading within their applications using SystemCapability.Global.ResourceManager.
