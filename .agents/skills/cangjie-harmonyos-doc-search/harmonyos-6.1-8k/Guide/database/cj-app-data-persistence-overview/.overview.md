# cj-app-data-persistence-overview

本目录专注于OpenHarmony标准系统下的应用数据持久化机制，旨在为开发者提供将内存数据持久化存储到设备的指导。内容涵盖了三种核心数据存储形态：适用于轻量级配置的用户首选项、适合分布式场景及简单业务数据的键值型数据库（KV-Store），以及支持复杂查询和自定义SQL的关系型数据库（RelationalStore）。文档通过对比各形态的特点与适用场景，帮助开发者根据具体业务需求做出最佳选择。这是一份面向OpenHarmony应用开发者的概念性指南，核心关键词包括数据持久化、用户首选项、KV-Store和RelationalStore。
