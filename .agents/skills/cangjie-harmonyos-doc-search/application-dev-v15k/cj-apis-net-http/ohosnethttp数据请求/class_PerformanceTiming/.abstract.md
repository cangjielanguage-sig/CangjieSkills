This directory provides comprehensive documentation for the `PerformanceTiming` class, a critical component within the NetworkKit framework designed for high-precision network performance monitoring. It serves as a complete guide for capturing and analyzing granular timing metrics related to HTTP requests. The documentation covers essential performance indicators, such as DNS resolution latency, TCP connection establishment time, TLS negotiation duration, redirect delays, and server response processing speeds. All metrics are provided as Float64 values in milliseconds, calculated from the moment the initial request is initiated. This resource is specifically tailored for developers and system engineers working with the SystemCapability.Communication.NetStack capability, available from API version 12 onwards. It is an indispensable tool for those seeking to diagnose network inefficiencies, identify bottlenecks, and significantly optimize the latency and responsiveness of their network-dependent applications.
