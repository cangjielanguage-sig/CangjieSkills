# cj-apis-bluetooth-a2dp

This directory serves as a comprehensive repository for the HarmonyOS Bluetooth A2DP (Advanced Audio Distribution Profile) module, specifically tailored for the Cangjie programming language. It provides essential API reference documentation designed to facilitate the development of high-quality wireless audio applications. The content encompasses critical technical areas, including detailed audio encoder configurations—such as sample rates, channel modes, and encoding types—as well as robust playback state management and core interfaces for the A2DP source profile. This resource is primarily intended for software developers and engineers utilizing the Cangjie language to build Bluetooth audio communication solutions. It offers standardized interfaces to effectively configure audio parameters, manage device connections, and control playback streams, ensuring seamless integration of wireless audio features within the HarmonyOS ecosystem.
