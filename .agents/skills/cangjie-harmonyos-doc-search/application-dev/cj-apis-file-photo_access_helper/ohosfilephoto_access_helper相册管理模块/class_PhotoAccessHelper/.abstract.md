This directory contains API documentation for the `PhotoAccessHelper` class in the Cangjie language, designed for HarmonyOS application development. It covers essential functionalities for managing media assets, including retrieving photos and videos, modifying metadata, handling user permissions for saving files, and monitoring media library changes. Key topics include `getAssets`, `applyChanges`, `registerChange`, and resource management. This documentation is suitable for developers using the MediaLibraryKit who need to implement robust file management, access control, and event listening within their applications.
