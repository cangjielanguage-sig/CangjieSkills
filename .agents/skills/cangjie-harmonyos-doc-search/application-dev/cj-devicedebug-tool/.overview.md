# cj-devicedebug-tool

This directory contains the documentation for the `cj-devicedebug-tool`, a Beta utility designed specifically for OpenHarmony developers. It focuses on the management of application processes via the Application Manager Service (AMS). The primary function of this tool is to enable developers to send termination signals to debug application processes. The documentation covers the command list, emphasizing the `help` command for usage instructions and the `kill` command for terminating processes. It details the syntax for sending specific signals (numbered 1-64) to a target Process ID (PID) and includes error handling for non-app or non-debuggable processes. To utilize this tool, developers must have prior access to the hdc shell environment. This guide is suitable for system developers and testers needing to control process lifecycles during the debugging phase.
