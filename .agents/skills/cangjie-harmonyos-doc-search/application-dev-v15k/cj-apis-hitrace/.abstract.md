This directory provides the comprehensive API reference documentation for the `cj-apis-hitrace` module, which is a fundamental tool for enabling process trajectory tracking and performance measurement within Cangjie applications operating on the HarmonyOS platform. The documentation is centered around the `ohos.hitrace` module, offering developers the necessary interfaces to instrument their code for deep analysis. It specifically details the `Hitrace` class, which is marked as deprecated, and explains the usage of its static methods for tracking execution flow. Key functionalities include the ability to mark the beginning and end of tasks using `startTrace` and `finishTrace`—which rely on matching names and IDs—as well as monitoring the real-time value changes of numerical variables through `traceByValue`. This resource is indispensable for Cangjie developers, system architects, and QA engineers who require robust tools for analyzing application performance, debugging complex logic issues, or tracing process lifecycles. It leverages the SystemCapability.HiviewDFX.HiTrace to deliver these system-level tracing capabilities, ensuring that users can effectively diagnose and optimize their applications.
