This directory serves as a comprehensive technical resource for developers working within the Cangjie programming environment, specifically focusing on cryptographic operations involving RSA. It details the implementation of digital signing and signature recovery processes utilizing the PKCS1 padding mode. The content covers essential steps such as RSA key pair generation, data signing with a private key, and signature verification or recovery using a public key. Key technical elements include the use of the CryptoArchitectureKit, specific API functions like `createSign`, `createVerify`, and `recover`, and algorithm configurations like RSA1024|PKCS1|SHA256. This guide is best suited for Cangjie developers who possess a foundational understanding of cryptography and are looking for synchronous code examples to integrate secure signing mechanisms into their applications.
