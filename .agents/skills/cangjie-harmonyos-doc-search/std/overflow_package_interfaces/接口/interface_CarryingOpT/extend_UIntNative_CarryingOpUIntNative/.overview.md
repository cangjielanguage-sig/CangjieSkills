# extend_UIntNative_CarryingOpUIntNative

This directory contains comprehensive API documentation for the implementation of the `CarryingOp` interface specifically tailored for the `UIntNative` type within the Cangjie programming language. It focuses on a specialized set of arithmetic and bitwise operations that are essential for low-level system programming. The documentation explains how these functions utilize a wrapping strategy to handle overflow, ensuring that developers can detect truncation events reliably. By returning tuples that combine the computed result with a Boolean status flag, these APIs provide the necessary tools for managing integer arithmetic safely. This resource is highly suitable for systems programmers, compiler developers, and anyone working on performance-critical code where precise control over numeric behavior is required.
