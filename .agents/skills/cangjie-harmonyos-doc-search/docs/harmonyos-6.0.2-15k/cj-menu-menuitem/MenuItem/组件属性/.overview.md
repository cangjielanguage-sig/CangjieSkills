# 组件属性

This directory contains API reference documentation for configuring component properties within the HarmonyOS ArkUI framework, specifically focusing on menu items using the Cangjie language. It covers essential styling capabilities such as font customization (size, weight, color), icon selection, and state management. Developers can find detailed parameters for `contentFont`, `labelFont`, and `selected` functions to programmatically control the visual appearance and interaction states of UI elements. This documentation is suitable for software developers and UI engineers building applications with ArkUI who require precise control over component aesthetics and behavior.

### func_selectedBool.md func_selectedBool.md
This API documentation defines the selected function in the Cangjie language, designed to control the selection state of menu items within the ArkUI framework. The document details the function signature, system capabilities, version requirements, and a parameter table explaining the input value. Key information includes that the function accepts a required Boolean parameter named value, which defaults to false; setting it to true selects the menu item, while false deselects it. The function returns the current instance to support method chaining. This reference guide targets software developers building UI applications using ArkUI, requiring knowledge of Cangjie syntax and UI component properties.
