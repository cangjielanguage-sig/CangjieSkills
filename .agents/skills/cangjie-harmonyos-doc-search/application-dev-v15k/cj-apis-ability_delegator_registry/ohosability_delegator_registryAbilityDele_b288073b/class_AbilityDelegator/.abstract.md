This directory contains API reference documentation for the Cangjie `AbilityDelegator` class within the HarmonyOS TestKit and AbilityKit frameworks. It covers the management and monitoring of UIAbility and AbilityStage lifecycles, essential for automated testing. Key topics include adding and removing monitors, controlling ability states (foreground/background), executing shell commands, and managing test execution flows. This documentation is suitable for Cangjie developers and QA engineers building automated tests for HarmonyOS applications who need to manipulate and observe application component behaviors programmatically.
