# 自定义组件的删除

This directory provides a comprehensive technical overview of the deletion mechanisms and lifecycle management for custom components within the ArkUI framework. It covers critical internal processes, including the `aboutToDisappear` callback, the destruction sequence of backend and frontend nodes, and the unregistration of synchronized state variables such as `@Link` and `@Prop`. Furthermore, it details the execution order of lifecycles during various application states like page navigation, back presses, and app exit. This resource is specifically designed for ArkTS developers who need to master component state management, optimize memory usage, and prevent memory leaks in their applications. By understanding these concepts, developers can ensure robust application performance and stability while avoiding common pitfalls related to component destruction.

## Detailed Description

### 自定义组件的删除_1.md 自定义组件的删除_1.md

This technical guide explains the deletion mechanism and lifecycle behavior of custom components within the ArkUI framework. It details the `aboutToDisappear` lifecycle function, the process of backend and frontend node destruction, and the unregistration of synchronized state variables like `@Link` and `@Prop`. Key takeaways include a strict warning against using asynchronous operations in `aboutToDisappear`, as this prevents garbage collection by retaining references in closures. The document provides a Cangjie code example demonstrating lifecycle invocation timing during component removal. This resource is intended for developers managing component lifecycles and memory in ArkUI applications.

### 自定义组件的删除_2.md 自定义组件的删除_2.md

Key takeaways include the distinction between page-level methods (onPageShow/Hide) and component-level methods (aboutToAppear/Disappear), specifically how `router.replaceUrl` destroys the current page triggering component destruction, whereas `router.pushUrl` only hides it. The document targets ArkTS developers needing to understand component state management and lifecycle interactions.
