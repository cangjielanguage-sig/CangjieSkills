# PanGesture

This directory contains documentation and resources for the PanGesture component within the ArkUI framework using the Cangjie language. It covers the implementation of sliding gesture events triggered by specific movement distances, including API references, practical code examples, and fundamental type definitions. Key topics include gesture lifecycle management (onActionStart, onActionUpdate, onActionEnd), dynamic configuration via PanGestureOptions, and direction constraints using PanDirection. This content is suitable for application developers and UI engineers working on HarmonyOS applications who need to integrate interactive touch controls and precise gesture recognition into their user interfaces.

## Detailed Description

### PanGesture_3more.md PanGesture_3more.md
This document serves as API reference documentation for the PanGesture component in the Cangjie language, designed to handle sliding gesture events triggered when a specific movement distance is reached. The content is divided into component creation and event handling sections. It details two initialization methods: one using named parameters for finger count, direction, and distance, and another using a PanGestureOptions object for dynamic updates. Key information includes event callbacks such as onActionStart, onActionUpdate, onActionEnd, and onActionCancel, which allow developers to manage the full gesture lifecycle using GestureEvent data. This technical guide targets application developers implementing interactive touch controls and gesture recognition.

Key information includes the logic for calculating real-time translation offsets and persisting the final position after the gesture ends, allowing the component to stay in its new location. This tutorial is intended for application developers using the Cangjie language for HarmonyOS development who need to integrate interactive touch gestures into their user interfaces.

This directory contains fundamental type definitions for the ArkUI framework in the Cangjie language, specifically focusing on gesture recognition and interaction handling. It covers the core configuration options for pan gestures and the enumeration of possible drag directions. Key components include the `PanGestureOptions` class, which allows for the dynamic modification of gesture properties without triggering expensive UI refreshes, and the `PanDirection` enum, which provides a robust way to define movement constraints using cardinal and axis-based directions. These definitions are essential for developers building interactive user interfaces that require precise touch handling, efficient state management, and complex gesture logic.
