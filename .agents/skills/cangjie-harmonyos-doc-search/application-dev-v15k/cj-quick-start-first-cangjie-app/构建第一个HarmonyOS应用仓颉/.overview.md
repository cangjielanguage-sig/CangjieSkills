# 构建第一个HarmonyOS应用仓颉

This directory provides a comprehensive guide for developers starting their journey with HarmonyOS application development using the Cangjie programming language. It covers the entire lifecycle of creating a basic application, from setting up the project environment and understanding the file structure to building user interfaces and implementing page navigation. Key topics include DevEco Studio configuration, UI component implementation, state management, and routing logic. Suitable for beginners and developers transitioning to Cangjie, this resource equips users with the essential skills to build and run their first multi-page HarmonyOS app on emulators or real devices.

## Detailed Description

### 使用真机或模拟器运行应用.md 使用真机或模拟器运行应用.md
This tutorial guides developers on running HarmonyOS applications written in the Cangjie language using DevEco Studio. It covers two primary execution environments: local real devices and the built-in emulator. Key sections include connecting a physical device, configuring automatic signing via a Huawei account, and setting up the emulator. A critical technical takeaway is the requirement to modify the build-profile.json5 file to include x86_64 in abiFilters when running on x86-based emulators, as the default architecture is arm64-v8a. This document targets Cangjie developers who have completed their initial build and need to deploy their first application for testing.

### 创建仓颉工程_2more.md 创建仓颉工程_2more.md
This tutorial guides developers through creating a Cangjie project in DevEco Studio and understanding its directory structure. It covers the step-by-step project creation process using the Empty Ability template and provides a detailed breakdown of the generated file tree. Key takeaways include the location of Cangjie source code within the entry module, the role of cjpm.toml for package management, and the function of configuration files like module.json5 and app.json5. The target audience is HarmonyOS developers using the Cangjie language who need to set up a new application project.

### 构建第一个页面.md 构建第一个页面.md
This tutorial guides developers through building a basic application page using the Cangjie language within a HarmonyOS development environment. It covers the project file structure, the default index.cj code template, and the implementation of layout components like Row, Column, Text, and Button. Key information includes demonstrations of state management using @State and event handling with onClick to modify text or log actions. The document provides step-by-step code examples for structuring a declarative UI. This guide is intended for developers beginning to use Cangjie for mobile app development, focusing on fundamental UI composition and interaction logic.

### 构建第二个页面_2more.md 构建第二个页面_2more.md
This tutorial guides developers through creating a second page and implementing navigation between pages in a Cangjie-based HarmonyOS application. The document covers creating the second.cj file, adding UI components like Text and Button, and utilizing the Router module for page transitions. Key takeaways include using Router.push to navigate to the new page and Router.back to return to the previous view. Intended for developers familiar with basic Cangjie syntax, this guide provides step-by-step instructions for multi-page application development.
