This directory provides a comprehensive technical overview of ExtensionAbility components within the Stage model, serving as a critical resource for understanding system-level extension capabilities. It covers essential concepts such as component classification, permissions, sandboxing rules, and data sharing modes. The documentation explains how these components are managed by system services to ensure process isolation and controlled lifecycles, distinct from standard application components. It is designed for application developers who need to understand the capabilities, constraints, and system interaction mechanisms of ExtensionAbility for scenarios like embedded UI and data sharing. By mastering these concepts, developers can effectively leverage system-managed components to enhance application functionality while adhering to security and isolation protocols. This overview is essential for anyone looking to integrate advanced features that require strict system management and data security protocols.
