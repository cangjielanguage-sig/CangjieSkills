This directory focuses on the `@Reusable` macro within the Cangjie HarmonyOS development framework, designed to optimize UI performance through component reuse and caching mechanisms. It covers technical definitions, specific usage scenarios like list scrolling and dynamic layouts, and critical constraints such as nested usage limitations. The content is tailored for Cangjie developers and UI engineers seeking to reduce resource overhead, minimize initialization time, and ensure smooth rendering in data-heavy or dynamic applications. Key concepts include `@Component`, `@Reusable`, lifecycle management, and view recycling.
