# fake_coverage_usage

本目录包含关于 FakeCoverage 功能的使用指南文档，旨在解决在 DataProvider 模式下因 libfuzzer 初始化检测失败而导致的 Fuzz 异常终止问题。文档深入分析了 libfuzzer 14 及以下版本中初始化输入被提前消耗的根本原因，并提供了通过创建虚假覆盖率信息来规避该问题的解决方案。核心关键词包括：FakeCoverage、libfuzzer、DataProvider、覆盖率初始化、模糊测试。这份指南适用于使用模糊测试工具的开发者，特别是遇到覆盖率初始化障碍的技术人员。

## 详细说明

### fake_coverage_usage.md fake_coverage_usage.md

本文档旨在指导开发者使用 FakeCoverage 功能，解决 DataProvider 模式下因 libfuzzer 初始化检测失败导致的 Fuzz 异常终止问题。文档详细分析了 libfuzzer 14 及以下版本中，初始化输入被提前消耗导致“无有趣输入”错误的根本原因，并介绍了通过 `enableFakeCoverage()` 或调用非关键 API 的解决方案。核心要点是 FakeCoverage 模式通过创建虚假覆盖率信息，让 libfuzzer 误以为已插桩从而避免提前退出，同时指出 libfuzzer 15 已修复此问题。这是一份面向使用模糊测试工具的开发者的技术指南，适用于解决 DataProvider 模式下的覆盖率初始化障碍。
