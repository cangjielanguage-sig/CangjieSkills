This directory contains API reference documentation for the `PhotoOutput` class within the Cangjie programming language's CameraKit framework. It covers the core functionality for managing photo capture sessions, including configuration, event handling, and resource management. Key topics include capturing photos with custom settings, enabling features like mirroring and moving photos, querying system capabilities, and managing camera event listeners for capture lifecycle events. This documentation is suitable for developers integrating advanced multimedia camera features into Cangjie applications, providing detailed syntax, error codes, and code examples for effective implementation.
