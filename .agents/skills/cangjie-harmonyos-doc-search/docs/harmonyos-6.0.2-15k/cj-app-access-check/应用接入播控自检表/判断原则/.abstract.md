This directory contains reference documentation defining the principles and standards for application integration, specifically focusing on AVSession and media playback features. It covers the criteria for determining integration requirements based on app type, distinguishing between mandatory and optional functionalities. The content includes compatibility matrices for playback controls, media information, and navigation behaviors across various categories like Music, Video, and Live apps. It is suitable for developers and quality assurance personnel responsible for ensuring compliance with system integration standards and verifying feature implementation.
