This directory serves as a specialized technical resource for developers working within the ArkUI framework using the Cangjie programming language. It focuses specifically on the universal attributes related to drag control, providing the necessary documentation to implement and customize drag-and-drop interactions. The primary subject is the `dragPreview` function, an API feature that enables the specification of custom preview images for components while they are being dragged by the user. By covering module imports, detailed function signatures, and parameter definitions, the guide ensures developers have all the technical specifications required for successful integration. Furthermore, it addresses practical implementation concerns, such as how the system generates previews via screenshots of components identified by string IDs, and how to manage scenarios involving invalid IDs. It also highlights specific version constraints and visual limitations, such as the handling of shadows. This documentation is best suited for application developers and system architects looking to enhance the interactivity of their ArkUI applications with sophisticated drag behaviors.
