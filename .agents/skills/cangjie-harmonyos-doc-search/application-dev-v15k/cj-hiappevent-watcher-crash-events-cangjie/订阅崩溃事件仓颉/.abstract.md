This directory provides a comprehensive technical resource for implementing crash event subscription capabilities using the Cangjie programming language within the HarmonyOS environment. It details the integration of the Performance Analysis Kit to monitor application stability, specifically distinguishing between CjError and NativeCrash event types. The content covers essential workflows such as configuring event watchers, managing subscription lifecycles, and analyzing stack unwinding data. Designed for Cangjie application developers and QA engineers, this guide offers the necessary tools and API references to track, debug, and resolve system-level crashes, ensuring robust application performance and reliability.
