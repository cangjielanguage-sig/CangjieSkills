# 管理Cookie及数据存储

This directory provides comprehensive technical documentation for managing client-side data within the ArkWeb and ArkUI frameworks. It focuses on two critical aspects of modern web application development: maintaining client-server state through Cookies and optimizing performance via caching and storage mechanisms. The content covers essential security policies like SameSite, resource loading strategies, and persistent data storage using Dom Storage. Designed for developers proficient in Cangjie, these guides offer practical code examples and API references to help integrate robust data management features into web components. By following these guidelines, developers can ensure secure user sessions, efficient resource utilization, and reliable data persistence within their applications.

## Detailed Description

The following files provide in-depth technical specifications and implementation guides for the topics outlined above.

### Cookie管理.md Cookie管理
This document serves as a technical guide for managing cookies within the ArkWeb framework, detailing their role in client-server state identification. It covers cookie definitions, the default SameSite=Lax security behavior, the WebCookieManager class, and storage locations. Key takeaways include the specific sandbox storage path and a Cangjie code example demonstrating the configCookie method to set values for specific domains. Intended for developers integrating web components, this guide requires familiarity with the ArkWeb API and Cangjie syntax.

### 缓存与存储管理.md 缓存与存储管理
This technical guide instructs developers on optimizing web resource performance through caching and storage management within the ArkUI framework using Cangjie. The document is divided into two primary sections: Cache configuration and Dom Storage usage. Key topics include setting resource loading strategies via cacheMode (Default, None, Online, Only), programmatically clearing caches with removeCache, and enabling persistent or session-based Key-Value storage using domStorageAccess. The content provides practical code examples for implementing these features. It targets application developers seeking to enhance loading speeds and manage client-side data persistence effectively.
