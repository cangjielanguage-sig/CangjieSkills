This directory serves as a comprehensive API reference for enumeration types utilized within a unit testing mock framework specifically developed for the Cangjie programming language. It focuses on the critical configuration aspects of verification and stubbing behaviors required for robust testing. The documentation covers three primary enumeration types: `Exhaustiveness`, which dictates the strictness of call verification; `MockSessionKind`, which manages session-level constraints; and `StubMode`, which controls how mocks return values and handle field mutability. This resource is essential for software developers and QA engineers who are writing unit tests in Cangjie and need granular control over mock object interactions to ensure their test logic is both precise and reliable.
