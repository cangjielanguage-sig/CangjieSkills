# dump

This directory contains essential documentation for the `dump` function within the Cangjie AST package, specifically designed to visualize Abstract Syntax Tree (AST) node structures. It addresses the common challenges developers face when trying to understand complex syntax hierarchies and resolve confusion regarding specific node attributes. The documentation thoroughly covers the motivation behind the feature, the technical implementation details, and provides a robust, practical code example that demonstrates the parsing and printing of a variable declaration node. The primary goal is to show that calling `dump()` on an AST node produces a detailed, hierarchical text representation. This output includes critical information such as tokens, kinds, and source positions, which significantly facilitates easier debugging and a deeper understanding of the code structure. This resource is ideally suited for software developers, compiler engineers, and tooling creators working within the Cangjie ecosystem who require the ability to programmatically inspect or debug Abstract Syntax Trees. By utilizing the resources in this directory, users can gain immediate clarity on code structure and node relationships.
