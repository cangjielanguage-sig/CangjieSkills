This directory provides a comprehensive guide for developers implementing device vibration controls using the Cangjie language and SensorServiceKit. It covers the Vibrator module, including API usage, permission acquisition, and various vibration scenarios such as alarms and key presses. The documentation details how to trigger fixed-duration vibrations, validate preset effects, and configure custom vibrations via JSON. It is suitable for application developers and system integrators looking to integrate sophisticated haptic feedback mechanisms into their software projects.
