# acm工具

本目录包含ACM（账号管理工具）的参考文档，主要介绍如何通过命令行接口管理本地账号的生命周期及权限约束。内容涵盖账号的创建、删除、查询、切换、注销以及约束条件的设置。核心功能包括使用 `hdc shell` 进入环境后，利用 `acm` 命令集进行操作，其中大部分操作需要 root 权限。本文档适用于需要调试账号功能或配置系统权限的开发人员和系统管理员，提供了完整的参数说明与使用示例。
