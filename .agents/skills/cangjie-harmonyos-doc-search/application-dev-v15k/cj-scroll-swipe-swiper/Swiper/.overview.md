# Swiper

This directory contains comprehensive documentation and code examples for the Swiper component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the creation of sliding carousel view containers, including API references, type definitions, event handling, and property configurations. Key topics include navigation indicators (dots, arrows, digits), animation effects, and interactive behaviors. The resources range from basic setup to advanced customization like overflow display and group pagination. This collection is suitable for HarmonyOS developers and UI engineers looking to implement dynamic, interactive slider interfaces in their applications.
