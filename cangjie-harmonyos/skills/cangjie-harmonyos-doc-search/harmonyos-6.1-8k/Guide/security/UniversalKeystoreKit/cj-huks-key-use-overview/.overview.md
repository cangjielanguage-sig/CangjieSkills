# cj-huks-key-use-overview

本目录包含HUKS（通用密钥库系统）密钥使用概览文档，旨在为开发者提供全面的密钥操作指导。文档详细阐述了加密解密、签名验签、密钥协商和派生等核心安全场景，并深入解析了基于密钥会话的通用开发流程，涵盖会话初始化、结束以及针对大数据的分段处理机制。此外，内容还涉及关键参数配置、错误处理策略及低内存设备的性能优化建议。该指南适用于需要利用HUKS实现数据安全保护的开发者，目前处于Beta阶段。

## 详细说明

### cj-huks-key-use-overview.md

本文档旨在介绍HUKS密钥的使用场景及通用的开发流程，指导开发者进行密钥操作。主要涵盖密钥使用介绍（包括加密解密、签名验签、密钥协商和派生）以及基于密钥会话的通用开发流程。核心流程包括必选的初始化会话和结束会话，以及针对大数据或特定算法的可选分段操作。文档详细说明了各阶段需传入的参数（如算法、密钥大小等），并强调了错误处理及低内存设备的优化建议。适用于需要利用HUKS进行数据安全保护的开发者，属于Beta阶段的开发指南。
