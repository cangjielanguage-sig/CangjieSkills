# 基础类型定义

This directory contains API reference documentation for fundamental transformation types within the ArkUI framework using the Cangjie language. It covers essential classes for manipulating UI components, including scaling, translation, rotation, and transition effects. Key concepts include 3D transformations, axis configurations, and animation parameters. This documentation is suitable for software developers and UI engineers building dynamic interfaces in HarmonyOS applications who need precise control over component geometry and visual effects.

## Quick Navigation

**What do you want to do?**

## Detailed Description

### class_ScaleOptions.md
This API reference document defines the ScaleOptions class used to configure scaling transformations within the ArkUI framework using the Cangjie language. The documentation details the class structure, specifically covering public properties for axis scaling (x, y, z) and transformation center coordinates (centerX, centerY), alongside the class constructor. Key information includes how scaling factors determine enlargement, reduction, or reflection based on values greater than, less than, or below zero, while the transformation center defaults to 50 percent. This guide targets software developers implementing UI component scaling in ArkUI applications.

### class_TranslateOptions_2more.md
This document serves as API reference documentation for the Cangjie language, detailing the TranslateOptions class and TransitionEdge enum within the ArkUI framework. It covers the TranslateOptions class, which configures 3D translation parameters through x, y, and z properties, and the TransitionEdge enum, which defines window boundaries including Top, Bottom, Start, and End. Key takeaways include the default translation values of 0.0.vp and the layout-dependent behavior of Start and End edges for LTR and RTL directions. This guide is intended for developers implementing UI component transformations and window edge transitions in HarmonyOS applications.

### class_RotateOptions/
This directory provides comprehensive API reference documentation for the `RotateOptions` class within the Cangjie language and ArkUI framework. It focuses on the technical specifications required to implement 3D rotations for UI components. The content covers the class definition, constructor initialization, and detailed property configurations such as rotation angles, axis vectors, center points, and perspective settings. By utilizing these resources, developers can achieve precise control over 3D transformations and depth effects. This documentation is intended for ArkUI developers and system engineers who are building advanced user interfaces requiring complex geometric manipulations and visual depth. It serves as a critical resource for understanding how to manipulate component orientation and perspective in system version 12 and later.

### class_TransitionEffect/
This directory provides comprehensive API reference documentation for the `TransitionEffect` class within the ArkUI framework, tailored for developers using the Cangjie language. It focuses on defining and managing transition effect types for component appearance and disappearance. The content covers class structures, static constants, and methods for combining effects, alongside specific animation parameters like move, rotate, and scale. It addresses complex scenarios such as animation precedence hierarchies, subtree deletion, and asymmetric transitions. This resource is essential for UI developers seeking to implement dynamic, polished entry and exit animations in their applications.
