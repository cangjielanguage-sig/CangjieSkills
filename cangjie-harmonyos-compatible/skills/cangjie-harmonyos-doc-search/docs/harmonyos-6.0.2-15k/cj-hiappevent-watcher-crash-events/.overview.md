# cj-hiappevent-watcher-crash-events

This directory provides a comprehensive reference for Cangjie developers utilizing the HiAppEvent framework to monitor system stability within the HarmonyOS ecosystem. It focuses on the `cj-hiappevent-watcher-crash-events` module, detailing the precise data structures and attributes required to subscribe to and interpret system crash events. The documentation covers essential technical components, including the main params object, nested attributes for exceptions and signals, and specific definitions for crash types such as CjError and NativeCrash. Additionally, it explains how to utilize process IDs, fault IDs, and stack traces for effective debugging. The guide also includes instructions for accessing external log files for deep analysis and managing storage limits. This resource is suitable for HarmonyOS developers and engineers dedicated to improving application reliability and resolving runtime issues through structured event data analysis.
