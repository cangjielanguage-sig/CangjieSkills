# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework, specifically utilizing the Cangjie language. It focuses extensively on the customization and behavior of picker components, enabling developers to manipulate date and time options, visual styles, and user interactions. Key topics include setting leading zeros, defining text styles for various states (selected, disappearing, top, bottom), enabling haptic feedback, implementing infinite scrolling, and toggling between 12-hour and 24-hour time formats. This resource is essential for developers seeking to create polished, highly interactive UI applications with precise control over picker functionality and aesthetics.

## Detailed Description

### func_dateTimeOptionsString_5more.md
This document serves as an API reference for configuring date and time picker components within the ArkUI framework using the Cangjie language. It details five specific functions: dateTimeOptions, disappearTextStyle, enableHapticFeedback, loop, and selectedTextStyle. Key information includes how to control leading zeros for time display, customize text styles for selected and edge items, toggle haptic feedback, and enable infinite scrolling. All functions support nullable parameters that revert to default values. This guide targets developers building UI applications who need to fine-tune the visual and interactive behavior of picker controls.

### func_textStylePickerTextSt_2more.md
This document provides API reference documentation for configuring text styles and time formats within a Cangjie-based picker component. It covers two primary functions: textStyle, which defines the color, font size, and weight for the top and bottom options, and useMilitaryTime, which sets the display to 12-hour or 24-hour format. Key details include parameter types, nullable inputs, default values, and system capability requirements starting from version 20. Intended for developers using the ArkUI framework, this guide assists in customizing the visual presentation and time logic of picker interfaces.
