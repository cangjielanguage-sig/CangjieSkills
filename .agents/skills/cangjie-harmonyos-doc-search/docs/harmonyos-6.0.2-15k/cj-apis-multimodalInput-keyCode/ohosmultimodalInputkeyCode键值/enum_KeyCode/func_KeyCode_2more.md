### func ==(KeyCode)

```cangjie
public operator func ==(other: KeyCode): Bool
```

**功能：** 对键码值进行判等。

**系统能力：** SystemCapability.MultimodalInput.Input.Core

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|other|[KeyCode](#enum-keycode)|是|-|对键码值进行判不等键码值。|

**返回值：**

|类型|说明|
|:----|:----|
|Bool|如果键码值相同返回true，否则返回false。|
