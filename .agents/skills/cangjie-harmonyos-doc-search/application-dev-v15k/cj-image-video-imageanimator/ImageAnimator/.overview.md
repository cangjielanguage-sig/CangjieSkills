# ImageAnimator

The ImageAnimator directory provides comprehensive documentation for the ArkUI framework's frame-by-frame image animation component, specifically designed for the Cangjie programming language. It covers the core component definition, basic type definitions for image frames, event handling mechanisms, and practical implementation examples. Key topics include animation lifecycle management, state control (running, paused, stopped), and configuration of image sequences. This resource is suitable for HarmonyOS developers and UI engineers using Cangjie who need to create dynamic, frame-based animations and manage interactive UI controls within their applications.

## Detailed Description

### ImageAnimator_4more.md ImageAnimator_4more.md
This API reference document details the ImageAnimator component, which enables frame-by-frame image playback within the ArkUI framework. The documentation covers the component's description, the absence of subcomponents, and the initialization process via the init() function. Key information includes the component's support for configurable image lists and durations, full support for universal attributes and events, and system capability requirements starting from version 19. Intended for developers using the Cangjie language, this guide provides the necessary specifications to implement frame animations in user interfaces.

### 基础类型定义.md 基础类型定义.md
This API reference document defines the ImageFrameInfo class used for managing image frame properties in Cangjie-based ArkUI development. It details the class overview and two constructor overloads: one accepting a String path and another accepting an AppResource object. Key parameters include the image source, playback duration in milliseconds, dimensions (width, height), and positioning coordinates (top, left), all supporting default values. This technical documentation targets HarmonyOS developers using the Cangjie language to implement image animation or display logic.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating the implementation and control of the ImageAnimator component using the Cangjie language for HarmonyOS development. The code covers the EntryView class structure, configuration of an ImageFrameInfo array, state management variables, and a UI layout with interactive control buttons. Key information includes managing animation states like Running, Paused, and Stopped, handling reverse playback, setting iteration counts for finite or infinite loops, and logging lifecycle events such as onStart and onFinish. This example targets HarmonyOS developers using Cangjie who need to implement frame-based image animations and interactive UI controls.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling animation lifecycle events within the ArkUI framework using the Cangjie language. It details five specific callback functions: onCancel, onFinish, onPause, onRepeat, and onStart. Each function accepts a callback parameter of type () -> Unit and returns the component instance to allow method chaining. These events trigger at specific animation states such as starting, pausing, repeating, finishing, or canceling. The target audience is software developers utilizing ArkUI for interface development who need to manage animation behaviors programmatically.
