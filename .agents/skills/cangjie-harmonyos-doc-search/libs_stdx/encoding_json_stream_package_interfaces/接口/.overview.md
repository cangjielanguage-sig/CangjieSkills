# 接口

This directory serves as a central hub for API reference documentation regarding interfaces in the Cangjie programming language, with a specific focus on JSON data handling and stream processing. It comprehensively covers the core mechanisms required for converting data between native Cangjie objects and JSON text streams. Key topics include the `JsonSerializable` interface, which facilitates encoding objects into JSON, and the `JsonDeserializable` interface, which handles the reverse process of parsing JSON streams back into native types. The documentation is essential for Cangjie developers who need to implement robust data interchange capabilities, manage I/O streams efficiently, and ensure type safety during serialization and deserialization tasks. By understanding these interfaces, developers can effectively integrate their applications with web services and external data sources, utilizing generic constraints to handle complex data structures seamlessly.

## Detailed Description

### interface_JsonDeserializableT/

This directory contains API reference documentation for the `JsonDeserializable` interface in the Cangjie programming language. It details how various data types implement the `fromJson` method to parse JSON streams into native objects. The content covers core interface definitions, numeric types (integers, floats, Decimal), collections (ArrayList, HashMap, Array), and utility types (String, Option, DateTime). It is suitable for Cangjie developers integrating JSON parsing capabilities, focusing on stream-based reading, generic constraints, and error handling like overflow exceptions.

### interface_JsonSerializable/

This directory contains API documentation for the Cangjie language's `JsonSerializable` interface, which enables the serialization of various data types into JSON data streams. It covers the base interface definition and numerous extensions for fundamental types, including integers, floating-point numbers, strings, and generic collections like `Array` and `HashMap`. The documentation details the `toJson` function implementation for each type, specifying constraints for generic parameters. This resource is suitable for Cangjie developers implementing JSON encoding logic who need to understand how specific types are converted and written to output streams using `JsonWriter`.
