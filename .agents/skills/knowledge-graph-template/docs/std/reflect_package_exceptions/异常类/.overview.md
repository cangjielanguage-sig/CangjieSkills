# 异常类

This directory contains comprehensive API reference documentation for exception classes within the Cangjie reflection package. It covers a range of specific runtime errors, including IllegalSetException, MisMatchException, and their parent class ReflectException. The documents detail class inheritance hierarchies, available constructors, and specific usage scenarios for handling errors during reflective operations. This resource is essential for Cangjie developers implementing reflection mechanisms who need to understand error types, instantiation patterns, and robust exception handling strategies.

### class_IllegalSetException_4more.md class_IllegalSetException_4more.md
This API reference document defines four specific exception classes within the Cangjie reflection package used to handle runtime errors during reflective operations. It details the IllegalSetException, IllegalTypeException, InfoNotFoundException, and InvocationTargetException classes, all inheriting from the parent ReflectException. Key information includes that each class provides two public constructors: a default initializer and one accepting a custom error message string. These exceptions address specific scenarios such as modifying immutable types, type mismatches, missing metadata, and wrapped invocation failures. This documentation targets Cangjie developers implementing reflection mechanisms who need to understand error handling and exception instantiation.
