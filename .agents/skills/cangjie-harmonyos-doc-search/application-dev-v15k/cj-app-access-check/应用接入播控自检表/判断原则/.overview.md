# 判断原则

This directory contains comprehensive guidelines and reference matrices designed to determine integration requirements for various application types, with a specific focus on AVSession and playback control features. It covers the distinction between mandatory and conditional integration items, feature priorities, and compliance standards across media categories such as Music, Video, Live streaming, and VoIP. The documents provide detailed checklists for playback information, control states, and navigation behaviors. Suitable for developers, QA engineers, compliance auditors, and system integrators, these guidelines ensure that media applications meet specific platform standards and deliver optimized user experiences.

## Detailed Description

### 判断原则_1.md 判断原则_1.md
This document outlines the judgment principles for determining which integration items are required for different types of applications. It covers three main categories: mandatory integration based on app type, conditional integration based on actual functionality, and exclusion criteria. The key information specifies that mandatory items must be connected, optional items are required only if the app possesses the corresponding feature, and excluded items should be ignored. This reference guide is intended for developers or compliance auditors ensuring correct SDK or API integration standards. Keywords: integration principles, app classification, mandatory items, optional features, compliance checklist.

### 判断原则_2.md 判断原则_2.md
This document serves as a reference matrix defining AVSession integration requirements and feature priorities for various application categories. It covers Basic Features, specifically AVSession access and Basic Playback Control, which are subdivided into Playback Information (cover, title, progress) and Playback Control (play/pause, navigation, button states). The table differentiates between "Complete Experience Optimization" and "Basic Access Requirements" for Music, Video, Live, Browser, News, and VoIP apps, using checkmarks to indicate mandatory features. It targets developers and system integrators seeking to ensure their media applications meet specific compliance standards or user experience guidelines.

### 判断原则_3.md 判断原则_3.md
This document serves as a reference matrix defining judgment principles for playback control feature support. It categorizes requirements under "Basic Playback Control," specifically detailing "Playback Information" (subtitles, scrolling lyrics, media source IDs) and "Playback Control" (favorites, loop modes, fast forward/rewind). Additionally, it addresses navigation behaviors such as clicking the playback card to jump to a specified app page. The table utilizes specific symbols to indicate mandatory support, optional status, or non-applicability for each feature. This technical guide is intended for developers and QA engineers to verify compliance with platform standards, likely for automotive or media application integration.
