# HKDF

This directory provides technical documentation and code examples for implementing HMAC-based Extract-and-Expand Key Derivation Function (HKDF) within the HarmonyOS Universal Keystore (HUKS) framework. It covers the essential cryptographic processes required to derive secure keys from existing secrets, including configuration of parameter sets, session management, and key lifecycle operations. The examples demonstrate how to generate source keys, initialize derivation sessions, and finalize them to produce derived keys using specific algorithms like AES and SHA-256. This content is suitable for developers proficient in ArkTS or Cangjie who are building secure applications requiring robust key management and cryptographic capabilities.

## Detailed Description

### HKDF_1.md
This document provides a Cangjie code example demonstrating how to perform HKDF key derivation using the UniversalKeystoreKit. It details the configuration of parameter sets for generating a source key, initializing a derivation session, and finalizing the session to produce a derived key. Key information includes the specific HuksParam definitions for AES-128 source keys, SHA-256 digest usage, and the resulting AES-256 derived key attributes. The code also includes helper functions for session management and error handling. This tutorial is intended for developers implementing cryptographic key derivation within the HUKS framework.

### HKDF_2.md
This document provides a code example demonstrating the implementation of HKDF key derivation using the HarmonyOS Universal Keystore (HUKS) SDK. Main sections include wrapper functions for session management and key deletion, specifically publicUpdateFunc, publicFinishFunc, and publicDeleteKeyFunc, followed by a comprehensive testDerive function. Key information highlights the full cryptographic lifecycle: generating a source key, initializing a derivation session, updating with input data, finalizing the session, and securely deleting the key, all utilizing specific error handling patterns. Intended for developers with knowledge of ArkTS and cryptography, this serves as a practical reference for integrating secure key derivation workflows into HarmonyOS applications.
