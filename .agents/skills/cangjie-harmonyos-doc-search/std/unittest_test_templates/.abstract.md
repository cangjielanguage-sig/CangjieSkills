This directory contains essential documentation for the `@TestTemplate` feature in the Cangjie programming language, designed to assist developers in creating reusable test components and significantly reducing code duplication. It thoroughly covers the basics of defining abstract test templates, the precise execution order of lifecycle methods like `@BeforeEach` within inheritance hierarchies, and the rules for configuration merging. Additionally, it details interaction constraints with other testing features. Key takeaways include the capability for templates to be nested, the specific base-to-derived order of lifecycle hook execution, and compatibility notes—specifically that templates support `@Bench` but are incompatible with `@Parallel`. This resource is intended for Cangjie developers who possess a strong understanding of unit testing and object-oriented inheritance and wish to implement robust, shared test infrastructure. Core keywords: Cangjie, @TestTemplate, unit testing, inheritance, lifecycle methods, code duplication, @BeforeEach, @Bench, @Parallel.
