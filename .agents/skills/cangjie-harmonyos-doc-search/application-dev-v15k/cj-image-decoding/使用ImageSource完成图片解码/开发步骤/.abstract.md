This directory provides a comprehensive technical guide for developers focused on implementing image decoding functionality using the Cangjie language and the ImageKit framework. It details the complete development workflow, beginning with the essential step of importing the Image module and covering various methods for obtaining image data. The content explains how to retrieve sandbox paths, acquire file descriptors using CoreFileKit, and fetch resource files as byte arrays or descriptors via LocalizationKit. Furthermore, it guides users through creating ImageSource instances, decoding them into PixelMap objects, and configuring options for standard and HDR formats. This documentation is specifically designed for application developers who possess prerequisite knowledge of Cangjie syntax and HarmonyOS context management.
