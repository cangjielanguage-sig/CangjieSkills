This directory contains comprehensive API reference documentation for the `DefaultHasher` struct within the Cangjie programming language. It focuses on the default implementation used for calculating combined hash values, specifically detailing initialization, result retrieval, and reset functionality. The documentation thoroughly covers various overloaded `write` functions designed to input different data types—such as unsigned integers (UInt8, UInt16, UInt32, UInt64), strings, and floating-point numbers—into hash combination operations. This resource is highly suitable for developers implementing custom hashing logic or utilizing hash-based collections who need to integrate specific data types into their hashing workflows efficiently and accurately.
