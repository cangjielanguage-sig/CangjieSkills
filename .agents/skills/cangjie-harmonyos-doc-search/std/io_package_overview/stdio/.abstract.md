The `stdio` directory provides comprehensive documentation for the Cangjie programming language's I/O package, designed to facilitate efficient data exchange between programs and external devices. It covers the fundamental mechanics of stream-based interfaces, including input and output streams, and offers a structured index of available components. Key topics include stream copying, buffered I/O operations, string conversion, and cursor seeking. This documentation is essential for Cangjie developers who need to implement data handling features, offering both conceptual overviews and detailed references for core abstractions like InputStream and OutputStream, as well as utility classes such as BufferedInputStream.
