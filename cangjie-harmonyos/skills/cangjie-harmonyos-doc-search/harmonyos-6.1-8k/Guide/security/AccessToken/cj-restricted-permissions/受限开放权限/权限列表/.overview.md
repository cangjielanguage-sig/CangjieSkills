# 权限列表

本目录包含OpenHarmony和HarmonyOS系统的权限参考文档，详细定义了各类系统级敏感权限的功能、级别及授权方式。内容涵盖剪贴板访问、硬件信息获取、虚拟屏管控、沙箱配置及内核内存保护等核心权限。所有权限均为system_basic级别，主要面向需要深度系统集成、访问敏感硬件数据或实现高级管理功能的系统开发者及应用工程师。

## 详细描述

### ohospermissionMA_15more_920bfad6.md
本文档是OpenHarmony系统权限的参考指南，详细定义了多个系统级权限的功能、级别及授权方式。涵盖剪贴板与UDMF数据共享、硬盘硬件信息获取、文件预加载、网络代理设置、设备管理策略、诈骗信息获取、蓝牙MAC地址固化、虚拟屏管控、APN设置及内核内存保护等权限。所有权限均为system_basic级别，采用system_grant授权方式，起始版本为12，允许应用执行管理虚拟屏或访问硬件等敏感操作。面向需要深度系统集成或访问敏感硬件数据的OpenHarmony系统开发者及应用工程师。

### ohospermissionSY_15more_67c1ee04.md
本文档是HarmonyOS系统的权限参考文档，旨在定义特定敏感权限的用途、级别及授权方式。主要涵盖悬浮窗、联系人、媒体文件读写、剪贴板、文件持久化、输入监听、Wi-Fi MAC地址及内核内存保护等权限。关键信息包括大部分权限为system_basic级别，起始版本为API 12，授权方式分为系统授权和用户授权。文档特别指出了短时媒体写入的30分钟限制、API 15的权限等级变更及内核权限仅限平板设备。该文档面向需要申请系统能力或访问用户数据的HarmonyOS应用开发者。

### ohospermissionker_4more_77a27049.md
本文档是OpenHarmony系统的权限参考文档，定义了四个特定的系统级权限及其用途。主要内容包括允许安装插件的SUPPORT_PLUGIN、修改沙箱类型的CUSTOM_SANDBOX、管理屏幕时间的MANAGE_SCREEN_TIME_GUARD以及自定义保存控件的CUSTOMIZE_SAVE_BUTTON。关键信息指出这些权限均为system_basic级别，采用system_grant授权方式，起始版本涵盖API 12和20。该文档面向需要实现插件管理、安全沙箱配置或屏幕使用限制等高级功能的系统开发者。关键词：OpenHarmony, 权限定义, system_basic, system_grant, 沙箱, 屏幕时间。
