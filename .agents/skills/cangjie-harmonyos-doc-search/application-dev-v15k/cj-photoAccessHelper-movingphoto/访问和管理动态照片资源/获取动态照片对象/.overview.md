# 获取动态照片对象

This directory provides comprehensive technical documentation for developers working with dynamic photo assets in the HarmonyOS ecosystem using the Cangjie programming language. It specifically addresses the retrieval and instantiation of MovingPhoto objects, which are essential for applications that require playback or advanced resource manipulation of media files. The content covers two distinct approaches: accessing the system media library through the PhotoViewPicker interface and loading assets directly from the application's private sandbox storage. Key technical concepts include URI management, MediaAssetManager integration, PhotoAsset fetching, and robust error handling for resource loading. This guide is primarily suitable for application developers and multimedia engineers seeking to implement rich media features and manage dynamic photo resources efficiently within their software projects. By following these guides, developers can effectively bridge the gap between system media libraries and application-specific storage requirements, ensuring a seamless user experience for dynamic content.

## Detailed Description

### 获取动态照片对象_2more.md
This technical guide instructs developers on retrieving moving photo objects for playback or resource operations. It covers two primary methods: using the Picker to access the media library or constructing objects from local sandbox files. The main section details the step-by-step process of selecting a media URI, fetching the corresponding PhotoAsset via getAssets and getFirstObject, and obtaining the MovingPhoto object using requestMovingPhoto. The document includes Cangjie code examples demonstrating the PhotoViewPicker usage and MediaAssetManager integration. It is intended for application developers working with the MediaLibraryKit to implement dynamic photo features.

### 获取应用沙箱动态照片对象.md
This document serves as a code tutorial for HarmonyOS developers, demonstrating how to load a MovingPhoto object from the application sandbox using the Cangjie language. The content is divided into two main code sections: the primary example function utilizing MediaAssetManager.loadMovingPhoto with specific image and video URIs, and the MainAbility setup required to obtain the application context. Key takeaways include the necessity of providing both image and video file paths and implementing error handling for business exceptions. This guide is intended for developers building multimedia applications who need to handle dynamic photo assets within the app's private storage.
