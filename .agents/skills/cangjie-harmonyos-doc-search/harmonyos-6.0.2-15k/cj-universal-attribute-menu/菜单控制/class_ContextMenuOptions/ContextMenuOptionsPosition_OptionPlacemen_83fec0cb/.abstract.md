This directory contains API reference documentation for the `ContextMenuOptions` constructor within the Cangjie framework. It focuses on the configuration and instantiation of context menu objects, detailing parameters for positioning, visual styling, and animation behaviors. Key topics include offset adjustments, placement logic, arrow display, background blur effects, and lifecycle callbacks like `onAppear` and `onDisappear`. The documentation is designed for UI developers using the Cangjie language who need to build interactive interfaces with customized context menus, offering precise control over layout, transitions, and event handling.
