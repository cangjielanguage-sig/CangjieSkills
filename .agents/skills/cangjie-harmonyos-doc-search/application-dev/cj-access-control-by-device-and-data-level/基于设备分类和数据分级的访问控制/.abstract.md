This directory focuses on implementing robust access control mechanisms based on device classification and data classification within the Cangjie language environment. It comprehensively covers how to configure security levels for both relational and key-value databases to ensure data protection. Key topics include setting specific security grades (S1-S4), understanding device security levels (SL1-SL5), and managing synchronization rules between distributed devices. This resource is suitable for developers using the ArkData framework who need to design secure database environments and strictly control data flow across different device security tiers.
