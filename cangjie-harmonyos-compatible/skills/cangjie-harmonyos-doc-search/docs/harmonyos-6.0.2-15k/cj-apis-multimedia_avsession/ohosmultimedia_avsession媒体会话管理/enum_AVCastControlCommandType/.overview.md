# enum_AVCastControlCommandType

This directory provides a comprehensive API reference for the `AVCastControlCommandType` enum within the Cangjie programming language, specifically designed to facilitate the control of audio and video casting sessions. It thoroughly documents the definition of specific command values such as Play, Pause, Stop, Seek, and Volume control, which are critical for managing remote playback states. Additionally, the content details operator overloads for equality and inequality checks, ensuring robust command validation. Key technical highlights include the enum's inheritance from Equatable, Hashable, and ToString interfaces, and its reliance on the SystemCapability.Multimedia.AVSession.AVCast capability, which is available starting from version 19. This resource is primarily intended for developers and software engineers who are constructing multimedia applications requiring precise and reliable remote casting control features.
