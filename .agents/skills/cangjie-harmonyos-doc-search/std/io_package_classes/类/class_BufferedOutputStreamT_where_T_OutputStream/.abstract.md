This directory contains API documentation for the `BufferedOutputStream` class in the Cangjie programming language. It focuses on a generic output stream wrapper that enhances I/O performance through buffering. The documentation covers class initialization, data writing methods, and extensions for automatic resource management and random access operations. Key topics include buffer capacity configuration, the `Resource` interface for safe disposal, and the `Seekable` interface for cursor manipulation. This resource is suitable for Cangjie developers implementing efficient, safe, and advanced I/O operations in their applications.
