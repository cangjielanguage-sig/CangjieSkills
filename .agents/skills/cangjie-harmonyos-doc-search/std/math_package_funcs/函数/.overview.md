# 函数

This directory contains API reference documentation for mathematical functions within the Cangjie standard library. It covers a comprehensive range of operations including basic arithmetic, trigonometric and hyperbolic functions, exponential and logarithmic calculations, rounding, and bitwise manipulations. The documentation details function signatures, parameters, return types, and exception handling for various numeric types like Float16, Float32, Float64, and integer types. It is suitable for Cangjie developers seeking precise implementation details for mathematical logic, geometric calculations, and low-level bit operations in their applications.
