This directory contains API documentation for the Cangjie programming language, specifically focusing on the `WrappingOp` interface implementation for the `UInt8` type. It covers arithmetic and bitwise operations designed to handle overflow through high-order truncation, ensuring results wrap around within the 8-bit limit. Key topics include addition, subtraction, multiplication, division, negation, and shifting, with specific attention to how shift counts are masked. This documentation is suitable for Cangjie developers working on low-level systems, embedded programming, or performance-critical applications where precise control over numeric overflow behavior is essential to prevent runtime errors and ensure deterministic execution. By utilizing these wrapping operations, developers can avoid unexpected crashes and manage numeric boundaries effectively.
