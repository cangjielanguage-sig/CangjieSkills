This directory contains the comprehensive API documentation for the HarmonyOS Bluetooth Hands-Free Profile (HFP) module, specifically curated for developers working with the Cangjie programming language. It acts as a vital resource for implementing Bluetooth call interfaces, with a primary focus on the Hands-Free Audio Gateway (AG) profile. The documentation covers a wide array of technical requirements, including module imports, system capabilities, and necessary permissions. Furthermore, it provides in-depth guidance on profile instantiation, connection management, and state monitoring. This package is best suited for HarmonyOS developers utilizing the ConnectivityKit who need to integrate advanced HFP AG features into their applications. To maximize the utility of this documentation, users should have a solid understanding of Cangjie syntax and the nuances of application context configuration within the HarmonyOS environment.
