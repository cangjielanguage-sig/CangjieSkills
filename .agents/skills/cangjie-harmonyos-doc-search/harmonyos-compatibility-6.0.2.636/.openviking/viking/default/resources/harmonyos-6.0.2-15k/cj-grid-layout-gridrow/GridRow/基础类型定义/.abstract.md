This directory provides comprehensive API reference documentation for fundamental type definitions essential for configuring responsive grid layouts within the Cangjie ArkUI framework. It details classes for managing breakpoints, grid row sizing options, and gutter configurations, alongside enums for layout direction and reference types. These definitions are critical for building adaptive user interfaces that dynamically adjust to various device screen sizes, ranging from mobile phones to large desktop displays. Suitable for UI developers and system architects working with ArkUI, this documentation provides the necessary structural components to implement flexible, responsive grid systems effectively.
