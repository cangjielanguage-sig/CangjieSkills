This directory contains API reference documentation for the Cangjie language `AccountManager` class within the BasicServicesKit framework. It focuses on operating system account management, providing methods to query account IDs, names, types, and constraints. The documentation covers functionalities like checking multi-account support, retrieving serial numbers, and managing distributed virtual device IDs. Key concepts include `BusinessException` error handling, system capabilities, and specific permissions such as `MANAGE_LOCAL_ACCOUNTS`. This content is intended for system application developers and those working with distributed systems in the HarmonyOS ecosystem who need to programmatically manage or identify OS accounts.
