This directory provides comprehensive API reference documentation for the `WebCustomScheme` class in the Cangjie language, specifically designed to facilitate the configuration and management of custom URL protocols within webview environments. It thoroughly covers the class initialization process and details a wide array of configurable properties that dictate protocol behavior. Key topics include security settings such as `isSecure` and `isLocal`, network capabilities including `isSupportCORS` and `isSupportFetch`, and content policy controls like `isCspBypassing`. Furthermore, the documentation specifies the strict rules for defining `schemeName` and explains how to toggle features like code caching and display isolation. This resource is suitable for developers integrating webviews who require granular control over security and network features when defining custom schemes, applicable from system API version 20.
