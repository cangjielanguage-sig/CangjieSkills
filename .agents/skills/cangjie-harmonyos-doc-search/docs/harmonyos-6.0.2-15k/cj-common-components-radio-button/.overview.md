# cj-common-components-radio-button

This directory hosts the documentation for the Radio component, a fundamental UI element within the Cangjie UI framework designed for single-selection scenarios. It provides a thorough guide for developers on how to implement, configure, and manage Radio buttons effectively. The documentation covers critical aspects such as component initialization via the `init` interface, property configuration (including `checked` and `indicatorType`), and event handling through `onChange`. It also clarifies the behavior of Radio groups, ensuring that only one option remains selected. A practical example of a sound mode switcher is included to demonstrate integration with toast notifications. This resource is ideal for Cangjie developers seeking to enhance user interaction in their applications, provided they have basic knowledge of UI structures. Keywords: Cangjie, Radio component, UI framework, single-selection, onChange event, indicatorType, user interaction.

## Detailed Description

### cj-common-components-radio-button.md

This document serves as the definitive usage guide for the Radio component within the Cangjie UI framework, specifically focusing on the implementation of single-selection controls. It provides a step-by-step approach to creating Radio buttons using the `init` interface, ensuring developers can quickly integrate the component into their projects. The guide details the configuration of various properties, such as `checked` and `indicatorType`, allowing for customization of the selection state and visual style. Additionally, it explains the mechanism for handling selection events via the `onChange` callback, which is crucial for interactive applications. The text reinforces the rule that only one Radio in a group can be selected, preventing conflicting states. To bridge theory with practice, the document includes a practical scenario example: a sound mode switcher that utilizes toast notifications to confirm user actions. This tutorial is targeted at Cangjie developers and requires a basic understanding of UI component structure and event handling. By following this guide, developers can effectively implement robust selection logic in their applications.
