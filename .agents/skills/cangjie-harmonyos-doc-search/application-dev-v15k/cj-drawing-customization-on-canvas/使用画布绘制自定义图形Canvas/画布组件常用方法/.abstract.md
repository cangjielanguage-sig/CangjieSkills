This directory contains documentation and tutorials for the Canvas component in the Cangjie programming language, specifically within the ArkUI framework. It covers essential 2D drawing operations including shape rendering, text manipulation, image processing, and gradient effects. Key topics include `CanvasRenderingContext2D`, drawing primitives like rectangles and circles, pixel data manipulation, and creating linear or radial gradients. These resources are designed for developers using Cangjie to build UI applications requiring advanced graphics rendering capabilities.
