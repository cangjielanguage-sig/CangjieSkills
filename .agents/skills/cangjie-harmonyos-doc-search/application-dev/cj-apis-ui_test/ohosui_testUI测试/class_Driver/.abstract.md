This directory contains API reference documentation for the `Driver` class within the Cangjie UI testing framework (TestKit). It serves as the primary entry point for developers and QA engineers to implement automated UI tests. The documentation covers a comprehensive range of functionalities, including component location and assertion, input simulation (touch, mouse, keyboard), display property management, and system event handling. By providing detailed method signatures, parameters, and code examples, these resources enable users to script complex user interactions and verify interface elements effectively within the HarmonyOS environment.
