This directory contains API reference documentation for stream-based compression and decompression classes within the Cangjie programming language's zlib package. It covers four primary classes designed to handle data transformation: `CompressInputStream`, `CompressOutputStream`, `DecompressInputStream`, and `DecompressOutputStream`. These resources detail constructors, methods for reading and writing data, buffer management, and resource cleanup. Targeted at Cangjie developers, the documentation provides syntax, usage examples, and error handling details for implementing efficient data compression workflows in applications.
