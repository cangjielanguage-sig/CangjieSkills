# cj-photoAccessHelper-savebutton

This directory provides a comprehensive technical tutorial for developers building HarmonyOS applications with the Cangjie programming language, specifically focusing on the implementation of media saving functionality. The guide addresses the common requirement of persisting media resources—such as images and videos—from the application's private sandbox storage to the device's public system gallery. This capability is essential for applications that handle media capture, editing, or downloading, ensuring that users retain access to their content outside of the app's immediate context. The tutorial meticulously covers the security prerequisites, including the declaration and usage of the `ohos.permission.WRITE_IMAGEVIDEO` permission, and explains the modern approach to user authorization through dialog methods. It breaks down the core development workflow into clear steps: identifying the source URI within the app sandbox, configuring the `PhotoCreationConfig` object, invoking the `showAssetsCreationDialog` API to retrieve a valid target URI from the system, and executing the file copy operation using the `FileFs` module. This resource is intended for HarmonyOS developers who possess a working knowledge of Cangjie syntax and file management APIs and need to integrate secure and efficient media saving features into their applications. Keywords: HarmonyOS, Cangjie, PhotoAccessHelper, showAssetsCreationDialog, media library, file saving, permission.
