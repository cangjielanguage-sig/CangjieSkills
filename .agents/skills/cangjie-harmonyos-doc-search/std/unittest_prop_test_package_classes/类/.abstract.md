This directory contains API documentation for core classes in the Cangjie programming language, specifically focusing on property-based testing and functional data structures. It covers random data generation, shrinking strategies, lazy sequences, and generator utilities. Key components include `RandomDataProvider`, `RandomDataShrinker`, `LazySeq`, and `Generators`. This resource is suitable for Cangjie developers and QA engineers looking to implement robust testing frameworks, manage immutable data structures, or create custom data strategies for automated testing.
