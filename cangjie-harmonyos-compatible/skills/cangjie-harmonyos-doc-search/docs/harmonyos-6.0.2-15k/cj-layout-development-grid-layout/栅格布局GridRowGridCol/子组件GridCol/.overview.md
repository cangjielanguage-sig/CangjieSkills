# 子组件GridCol

This directory contains API documentation for the `GridCol` sub-component within the Cangjie UI framework (ArkUI). It focuses on grid layout management, specifically controlling column behavior through attributes like span, offset, and order. The documentation covers responsive design strategies using breakpoints (xs to xxl) and fixed values, enabling developers to create adaptive interfaces. It is suitable for UI developers using the Cangjie programming language who need to implement flexible and responsive grid systems in their applications.

## Detailed Description

### offset.md offset.md
This API documentation explains the offset attribute used to define column spacing for grid child components relative to their predecessors. It covers two data types for the offset parameter: Int32 for fixed offsets and GridColColumnOption for responsive design across six device breakpoints (xs to xxl). The document details how offsets interact with the default 12-column grid system, providing Cangjie code examples and visual references to illustrate layout behavior like spacing and row capacity. It targets UI developers using the ArkUI framework and Cangjie programming language who need to manage grid layouts.

### order.md order.md
This reference documentation explains the order attribute used to control the layout sequence of grid sub-components. It covers two data types: Int32 for consistent ordering across all device sizes and GridColColumnOption for responsive ordering across six breakpoints (xs to xxl). The document defines sorting rules where unset items appear first, followed by items sorted numerically. It provides Cangjie code examples demonstrating how to rearrange grid columns statically and dynamically based on screen width. This guide targets UI developers using the Cangjie language to build adaptive grid layouts.
