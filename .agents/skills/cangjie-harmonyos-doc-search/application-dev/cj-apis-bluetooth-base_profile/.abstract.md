This directory contains the comprehensive API reference documentation for the `ohos.bluetooth.base_profile` module, a critical component of the HarmonyOS Cangjie development framework. It is specifically designed to equip developers with the essential building blocks required for implementing advanced Bluetooth functionality. The documentation covers a wide array of technical topics, including base profile interfaces, state change parameters, and detailed enumerations for disconnect causes and callback types. Furthermore, the module addresses key operational aspects such as connection management, asynchronous event handling, and device state diagnostics. As the module is currently in the Beta stage, developers must be aware of specific permission requirements, notably `ohos.permission.ACCESS_BLUETOOTH`. This resource is highly suitable for Cangjie developers and software engineers who are actively involved in building Bluetooth applications and require precise tools to manage connectivity, handle events, and perform diagnostics within the HarmonyOS ecosystem.
