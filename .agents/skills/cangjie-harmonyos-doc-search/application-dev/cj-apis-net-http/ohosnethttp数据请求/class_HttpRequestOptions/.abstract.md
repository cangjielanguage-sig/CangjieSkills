This directory contains comprehensive API reference documentation for the `HttpRequestOptions` class in the Cangjie programming language. It covers the configuration parameters required to initiate and customize HTTP requests within the SystemCapability.Communication.NetStack. Key topics include SSL security settings, DNS configurations, request headers, data types, timeouts, caching strategies, and proxy management. The documentation is designed for developers and engineers building network applications who need precise control over HTTP/HTTPS client behaviors, ranging from basic request setup to advanced features like resumable downloads and multipart form data handling.
