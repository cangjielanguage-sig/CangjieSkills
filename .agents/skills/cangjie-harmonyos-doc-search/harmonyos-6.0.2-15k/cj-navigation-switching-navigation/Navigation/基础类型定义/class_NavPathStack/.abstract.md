This directory contains API reference documentation for the `NavPathStack` class in the Cangjie language, specifically designed for managing Navigation route stacks within the ArkUI framework. It covers the comprehensive lifecycle and manipulation of page stacks, including methods for pushing, popping, removing, and reordering pages. Key topics include animation control, parameter passing between pages, nested navigation handling, and stack state retrieval. This documentation is suitable for HarmonyOS developers and software engineers who need to implement complex page routing logic, manage application state transitions, and customize navigation behavior programmatically.
