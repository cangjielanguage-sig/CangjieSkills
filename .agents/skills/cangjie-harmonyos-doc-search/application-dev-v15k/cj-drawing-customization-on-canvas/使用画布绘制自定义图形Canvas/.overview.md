# 使用画布绘制自定义图形Canvas

This directory provides comprehensive documentation and tutorials for using the Canvas component to draw custom 2D graphics within the Cangjie UI framework. It covers essential topics such as initializing the canvas, configuring rendering contexts, and implementing both on-screen and high-performance off-screen drawing techniques. Developers will learn to manipulate shapes, text, and images using `CanvasRenderingContext2D` and `Path2D`. These resources are designed for application developers using the Cangjie language who need to integrate advanced graphics rendering into their HarmonyOS applications.
