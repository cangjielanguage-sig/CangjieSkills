## system_grant（系统授权）权限列表

以下权限的授权方式均为 system_grant，申请方式请参考声明权限。

### ohos.permission.USE_BLUETOOTH

允许应用查看蓝牙的配置。

**权限级别**：normal

**授权方式**：system_grant

**ACL使能**：true

### ohos.permission.GET_BUNDLE_INFO

允许查询应用的基本信息。

**权限级别**：normal

**授权方式**：system_grant

**ACL使能**：true

### ohos.permission.PREPARE_APP_TERMINATE

允许应用关闭前执行自定义的预关闭动作。

**授权方式**：system_grant

**ACL使能**：true
