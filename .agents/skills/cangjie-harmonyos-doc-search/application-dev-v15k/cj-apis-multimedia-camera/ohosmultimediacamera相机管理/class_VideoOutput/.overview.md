# class_VideoOutput

This directory contains API reference documentation for the `VideoOutput` class within the Cangjie CameraKit framework. It comprehensively covers the management of video recording sessions, including querying stream configurations, handling video rotation logic, managing event callbacks for errors and lifecycle events, and controlling recording states. Key functionalities include retrieving active frame rates, setting video profiles, registering listeners for recording start and end events, and resource management. This documentation is intended for developers building multimedia camera applications on HarmonyOS who need to implement robust video capture and output handling using the Cangjie programming language.
