This directory contains comprehensive documentation for the Bundle Manager (bm) tool used within the Cangjie and HarmonyOS development environments. It covers command-line operations for the full application lifecycle, including installation, uninstallation, querying, debugging, and patching. Key topics include handling HAR and HAP packages, managing shared libraries and overlays, querying application information, and resolving installation or signature conflicts. This resource is suitable for developers, system administrators, and technical support personnel who need to manage application deployment and troubleshoot issues via the shell.
