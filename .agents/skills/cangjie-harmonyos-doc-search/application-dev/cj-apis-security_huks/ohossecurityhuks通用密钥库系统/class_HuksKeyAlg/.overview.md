# class_HuksKeyAlg

This directory contains API reference documentation for the `HuksKeyAlg` class within the Harmony Universal KeyStore (HUKS) system, specifically designed for the Cangjie programming language. It provides a comprehensive enumeration of cryptographic algorithm constants used for secure key management and operations. The content covers a wide range of algorithms, including international standards like RSA, ECC, AES, and HMAC, key derivation functions such as HKDF and PBKDF2, and Chinese national standard algorithms (SM2, SM3, SM4). Additionally, it details specific constants for modern algorithms like X25519. This documentation is essential for security developers and system integrators building secure applications on the HarmonyOS platform, requiring knowledge of system capabilities and API version 22.
