This directory contains API reference documentation for the `Config` class within the Cangjie programming language's `FileTransferAgent` system capability. It focuses on the configuration and management of file transfer operations, specifically HTTP uploads and downloads. The documentation covers class constructors, properties, and configurable variables related to network constraints, task modes, retry logic, and file handling options such as overwrite permissions and save paths. It is designed for Cangjie developers and software engineers who need to implement robust, flexible, and efficient background file transfer features in their applications, offering granular control over network behaviors and data management protocols.
