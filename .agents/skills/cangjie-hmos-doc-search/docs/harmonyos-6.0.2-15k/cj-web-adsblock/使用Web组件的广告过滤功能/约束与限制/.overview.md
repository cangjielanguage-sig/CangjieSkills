### 约束与限制_2.md 约束与限制_2.md
This document outlines the constraints, logic, and persistence behaviors of the ad-blocking feature for the Web component. It covers the WebviewController instance switch, the global AdsBlockManager singleton, and callback mechanisms. Key information includes that custom rules set via setAdsBlockRules persist across cold starts, while allowlist and disallowlist configurations do not. If ad blocking is enabled without specific lists, it defaults to blocking all sites. Allowlist priority overrides disallowlist matching. This technical reference is intended for developers implementing ad filtering in web applications.

### 约束与限制_3.md 约束与限制_3.md
This document defines the specific matching logic used for allowlist and disallowlist configurations within an application. The primary topic is the domain matching mechanism, specifically focusing on suffix matching behavior. Key information includes the rule that configured domains use suffix matching, meaning a setting for "xxyy.com" will successfully match subdomains like "wwsstt.xxyy.com". This reference material is intended for developers and system administrators who need to understand how domain filtering rules are applied when configuring network access controls or security policies. Keywords: allowlist, disallowlist, suffix matching, domain configuration, network security.
