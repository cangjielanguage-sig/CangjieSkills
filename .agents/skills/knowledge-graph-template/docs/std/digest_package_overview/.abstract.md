This directory contains the essential documentation for the `std.crypto.digest` package, serving as a comprehensive API overview for developers working with cryptographic hash algorithms. It provides a unified interface designed to simplify the implementation of various hashing standards, including MD5, SHA1, SHA256, HMAC, and SM3. The documentation focuses heavily on the generic digest function, which offers flexibility by accepting byte arrays, strings, or input streams, alongside the core Digest interface required for stream processing. This reference material is specifically tailored for developers seeking to integrate secure digest operations into their applications using generic types and efficient stream handling mechanisms. It ensures that users have a clear understanding of the available tools and how to apply them correctly in a standard library context.
