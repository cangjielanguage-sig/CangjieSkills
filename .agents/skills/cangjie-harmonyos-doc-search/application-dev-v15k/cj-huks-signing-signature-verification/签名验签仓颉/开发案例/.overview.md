# 开发案例

This directory serves as a comprehensive collection of development examples for implementing cryptographic operations using the Universal Keystore Kit within the Cangjie programming language. It covers a wide range of algorithms, including ECC, RSA, and SM2, focusing on key generation, digital signing, and signature verification processes. The documentation details essential workflows such as session management, property configuration using HuksParam, and key lifecycle management. These resources are specifically designed for Cangjie developers and security engineers aiming to integrate robust, hardware-backed security features and national cryptographic standards into their applications.

## Detailed Description

### ECC256SHA256.md ECC256SHA256.md
This document demonstrates how to implement ECC 256-bit key generation and SHA-256 digital signing and verification using the Universal Keystore Kit in Cangjie. Key sections include property configuration functions for algorithm parameters, core cryptographic operations for key generation, signing, and verification, and a test function illustrating the complete workflow. The code highlights the use of HuksParam to define cryptographic attributes like algorithm, key size, and digest, and demonstrates session management via initSession, updateSession, and finishSession for secure operations. Intended for Cangjie developers implementing security features, this tutorial requires familiarity with cryptographic concepts and the Universal Keystore API.

### RSASHA256PKCS1_V1_5.md RSASHA256PKCS1_V1_5.md
This document provides a Cangjie code example demonstrating how to perform digital signing and verification using the RSA algorithm with SHA256 digest and PKCS1_V1_5 padding within the Universal Keystore environment. It covers key generation, property configuration for signing and verification, session management, and the complete lifecycle including key deletion. Key takeaways include the specific parameter sets for 2048-bit RSA keys, the use of initSession, updateSession, and finishSession for cryptographic operations, and the separation of concerns between generation, signing, and verification properties. Targeted at developers implementing cryptographic security in Cangjie, this tutorial assumes familiarity with basic cryptography concepts and the Universal Keystore Kit API structure.

### RSASHA256PSS.md RSASHA256PSS.md
This document provides a Cangjie code example demonstrating how to implement RSA digital signatures with SHA256 hashing and PSS padding using the UniversalKeystoreKit. The code covers key generation, signing, verification, and key deletion, detailing specific cryptographic properties like algorithm type, key size, and padding mode. Key takeaways include the configuration of HuksParam objects for RSA operations and the session-based workflow for signing and verifying data. This tutorial is intended for developers working with hardware-backed key stores who need to implement secure cryptographic operations in Cangjie.

### SM2SM3.md SM2SM3.md
This document provides a Cangjie code example demonstrating how to implement SM2 key generation and digital signing with SM3 hashing using the UniversalKeystoreKit. It covers defining cryptographic properties, generating SM2 keys, signing plaintext data, verifying signatures, and managing key lifecycle through deletion. The code illustrates the use of HuksParam to configure algorithms, key sizes, and purposes, detailing a session-based approach for cryptographic operations. Targeted at developers using the Cangjie language, this example serves as a practical guide for integrating Chinese national cryptographic standards into applications requiring secure data authentication.
