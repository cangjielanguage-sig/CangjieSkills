This directory contains documentation for the `ohos.displaySync` module, focusing on variable frame rate support within the HarmonyOS ArkUI framework. It covers the `DisplaySync` class, `IntervalInfo` data structures, and implementation guides for Cangjie developers. The content is designed to help optimize graphics performance by allowing precise control over rendering cycles and frame synchronization in self-drawn UI scenarios. It is suitable for HarmonyOS developers and graphics engineers looking to implement high-performance, variable frame rate applications using the Cangjie language.
