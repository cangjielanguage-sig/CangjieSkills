This directory contains API reference documentation for the `AVScreenCaptureRecorder` class within the Cangjie MediaKit framework. It covers the complete lifecycle of screen recording operations, including initialization, event subscription, recording control (start/stop), resource management, and privacy settings. Key topics include configuration parameters, error handling, callback mechanisms for state changes, and microphone control. This documentation is suitable for Cangjie developers and multimedia engineers looking to implement robust screen capture features, manage recording states, and handle runtime exceptions effectively in their applications.
