This directory contains technical tutorials and practical examples focused on specific usage scenarios for state management in Cangjie, specifically for HarmonyOS application development. It primarily covers the advanced implementation of the `@Watch` decorator to observe state changes, handle complex data structures like dynamic ArrayLists, and manage UI updates within custom components. Key topics include the interaction between `@Link` and `@State`, execution flows for parent-child component updates, and optimizing state observation logic. These resources are suitable for HarmonyOS developers using the Cangjie language who possess prerequisite knowledge of state management and component lifecycles and wish to master reactive programming patterns.
