# class_GattServer

This directory contains API reference documentation for the `GattServer` class in the Cangjie programming language, specifically designed for HarmonyOS Bluetooth Low Energy (BLE) development. It covers server-side operations within the GATT protocol, including service management, connection state monitoring, and handling client read/write requests. Key topics include adding and removing services, subscribing to various BLE events (MTU changes, connection states), and managing server lifecycles. This documentation is suitable for developers using the ConnectivityKit to implement Bluetooth peripheral roles, requiring knowledge of Cangjie syntax and BLE concepts.
