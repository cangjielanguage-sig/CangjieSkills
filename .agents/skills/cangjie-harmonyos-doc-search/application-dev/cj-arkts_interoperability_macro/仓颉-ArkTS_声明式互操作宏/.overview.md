### 类型映射.md 类型映射.md
This reference document outlines the type mapping rules between Cangjie and ArkTS for declarative interoperability macros. It features a comprehensive table mapping primitive and complex types, including numbers, strings, Option, and collections, alongside specific usage notes. Key information includes critical constraints such as the prohibition of syntax sugar like `?T` in Interop contexts and restrictions on generic types within `Option`, `JSArrayEx`, and `JSHashMapEx`. Custom types used in generics must be decorated with the Interop macro. This guide targets developers implementing cross-language features who need to ensure type safety and compatibility between Cangjie and ArkTS.
