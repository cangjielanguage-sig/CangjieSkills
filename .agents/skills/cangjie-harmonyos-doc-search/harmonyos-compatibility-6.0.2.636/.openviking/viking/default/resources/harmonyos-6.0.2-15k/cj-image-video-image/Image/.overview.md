# Image

This directory provides comprehensive documentation and resources for the ArkUI Image component within the HarmonyOS ecosystem, specifically tailored for the Cangjie programming language. It covers the complete lifecycle of image handling, from component initialization and data source configuration to event management and advanced property customization. Key topics include support for various formats like GIF and SVG, network permissions, color filters, and rendering modes. This collection is essential for software developers and UI engineers seeking to implement robust image display, interactive media features, and high-performance visual effects in their applications.

## Detailed Description

### Image_3more.md Image_3more.md
This document serves as a reference guide for the ArkUI Image component, explaining how to display various image formats within applications. It covers supported formats, usage notes regarding focus and animation behavior, and permission requirements for network images. Key information includes the necessity of the INTERNET permission for remote sources and specific focus attributes for interaction. Additionally, it notes that animated GIFs play only when the node is visible. Intended for HarmonyOS developers, this guide ensures proper implementation of image display and interaction features.

### 创建组件.md 创建组件.md
This document provides API reference documentation for initializing the Image component in the Cangjie programming language. It details four overloaded init methods that accept different data sources: String for network or local paths, AppResource for resource management, PixelMap for image editing, and ImageContent. Key information includes the component's default behavior of center cropping, adaptive sizing when dimensions are unset, and zero-size handling on load failure. The document specifies system capabilities and version requirements, targeting developers using ArkUI to render images in their applications.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling image loading events within the ArkUI framework using the Cangjie language. It details three specific callback functions: onComplete, onError, and onFinish. Key information includes that onComplete returns image dimensions upon success, onError handles exceptions, and onFinish specifically triggers for non-looping animated SVGs. All functions require version 12 and return the component instance for chaining. The target audience is software developers implementing image handling logic in ArkUI applications.

### 通用属性通用事件.md 通用属性通用事件.md
This reference document outlines the support status of universal attributes and events for a specific component within the ArkUI framework. It confirms that the component fully supports all standard universal attributes and events. However, a key exception is highlighted regarding the Image component, which does not support the foregroundColor attribute. Instead, developers are instructed to use the fillColor attribute to set fill colors. This information is essential for developers and UI engineers implementing styling and interaction logic, ensuring they use the correct properties for visual customization in their applications.
