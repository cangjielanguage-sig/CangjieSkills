# 对称密钥加解密算法规格

本目录包含对称密钥加解密算法的技术规格文档，详细定义了AES、3DES和SM4等主流算法的实现规范。内容涵盖算法支持的加密模式（如ECB、CBC、GCM）、数据填充规则（如PKCS7、NoPadding）以及通过字符串参数配置算法规格的具体方法。这些文档面向使用CryptoArchitectureKit进行加密功能开发的开发者，旨在提供API参考和集成指导，帮助理解并正确调用加密接口。

## 详细描述

### 3DES.md
本文档详细说明了3DES算法的加解密机制、支持的加密模式、填充规则以及如何通过字符串参数配置算法规格。主要涵盖3DES算法原理、四种加密模式（ECB、CBC、OFB、CFB）、数据填充模式（如PKCS7）以及字符串参数的拼接规范。关键信息包括：3DES分组长度为64位，ECB和CBC模式必须填充；参数字符串由“算法类型|分组模式|填充模式”组成；支持指定密钥长度（如3DES192）或由实际密钥决定。这是一份面向开发者的API参考文档，适用于使用CryptoArchitectureKit进行对称加解密开发的场景。

### SM4_2more_3aaca089.md
1. 本文档介绍SM4分组加密算法的实现规范，涵盖支持的加密模式、填充方式及字符串参数配置格式。
2. 主要内容包括7种加密模式（ECB、CBC、GCM等）、填充模式定义及“算法_密钥长度|分组模式|填充模式”的拼接语法。
3. 关键点在于SM4分组长度为128位，PKCS5/PKCS7均填充至16字节，流模式（如CTR、GCM）强制使用NoPadding。
4. 适用于使用CryptoArchitectureKit进行SM4开发的开发者，属于API参考文档。

### 对称密钥加解密算法规格_2more_eb081824.md
本文档是关于对称密钥加解密算法的技术规格说明，主要定义了AES算法支持的七种加密模式（ECB、CBC、GCM等）及其参数配置。文档详细阐述了分组长度、填充模式规则以及通过字符串参数（如“AES128|ECB|PKCS7”）指定算法规格的方法。关键信息包括API 12及以上版本支持的密钥长度与模式组合表，以及支持省略密钥长度的新特性。这是一份面向开发者的参考文档，旨在帮助其理解并正确调用加密接口，适用于需要集成加密功能的系统开发场景。
