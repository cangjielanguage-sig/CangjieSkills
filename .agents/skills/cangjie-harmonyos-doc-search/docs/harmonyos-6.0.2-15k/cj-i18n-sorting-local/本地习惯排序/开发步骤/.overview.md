# 开发步骤

This directory provides a structured approach to implementing locale-aware string sorting and searching using the Collator class within the LocalizationKit framework. It is designed to assist developers in mastering the complexities of text processing for internationalized applications. The content covers essential steps such as module importation, Collator object instantiation, and the detailed configuration of CollatorOptions. Developers will learn how to manipulate sorting behaviors, including sensitivity levels, numeric ordering, and language-specific rules like Chinese Pinyin or stroke sorting. Through practical Cangjie code examples, the guide demonstrates how to achieve culturally accurate list ordering and perform precise text matching. This resource is ideal for developers using the Cangjie language who need to handle sophisticated text comparison logic across various locales, ensuring their applications behave correctly in different linguistic contexts.

## Detailed Description

### 开发步骤_1.md
This tutorial guides developers on implementing locale-aware string sorting using the Collator class within the LocalizationKit. It covers module importation, Collator object instantiation, string comparison logic, and a detailed breakdown of CollatorOptions parameters. The document explains how to configure sorting behaviors like sensitivity, numeric ordering, and specific collation rules such as pinyin or stroke for Chinese through a comprehensive options table. It provides practical Cangjie code examples demonstrating case-sensitive English sorting and various Chinese sorting methods. Targeted at developers using the Cangjie language, this guide ensures culturally correct list ordering in applications.

### 开发步骤_2.md
This document provides code examples demonstrating how to use the Collator class for locale-aware string sorting and searching. It covers two main scenarios: sorting an array of Chinese strings using stroke order and performing a case-insensitive search within a Turkish string array. Key information includes configuring CollatorOptions for specific locales like 'zh-CN' and 'tr', defining custom comparison functions for sorting, and using sensitivity settings to normalize search matches. This tutorial is designed for developers working on internationalization or text processing who need to handle complex sorting and matching rules across different languages.
