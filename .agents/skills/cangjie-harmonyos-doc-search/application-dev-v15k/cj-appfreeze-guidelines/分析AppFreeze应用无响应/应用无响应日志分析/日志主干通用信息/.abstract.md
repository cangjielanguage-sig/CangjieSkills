This directory contains essential technical reference documentation designed for analyzing system logs, with a specific focus on diagnosing application freezes (appfreeze) and performance debugging within OpenHarmony environments. It comprehensively covers the interpretation of common log fields, main thread task queues, process stack traces, and Inter-Process Communication (IPC) mechanisms. Key topics include BinderCatcher usage, CPU load monitoring, and memory statistics analysis. These guides are primarily intended for system developers and engineers who need to troubleshoot complex application responsiveness issues, identify system bottlenecks, and resolve resource consumption problems effectively.
