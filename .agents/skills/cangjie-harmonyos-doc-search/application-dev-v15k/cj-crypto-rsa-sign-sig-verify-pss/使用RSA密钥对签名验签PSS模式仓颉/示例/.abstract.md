This directory serves as a comprehensive practical resource for developers working with the Cangjie programming language, specifically focusing on cryptographic implementations using the CryptoArchitectureKit. It provides detailed code examples that cover fundamental security operations, including the manual construction of RSA asymmetric key pair specifications and the execution of digital signing and verification processes. The examples illustrate how to handle large integers using BigInt, configure specific algorithm parameters like salt length and mask generation functions, and manage multi-part data updates securely. These tutorials are designed for software engineers and security professionals who require a deep understanding of how to integrate and configure advanced cryptographic primitives, such as RSA PSS with SHA256, within their Cangjie-based applications to ensure data integrity and authenticity. By following these examples, users can gain hands-on experience with the library's API structure and best practices for secure coding, ensuring they can effectively implement robust security features in their software projects.
