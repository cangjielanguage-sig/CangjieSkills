## Detailed Description

### 使用AES对称密钥CCM模式加解密/

This subdirectory acts as a detailed instructional manual for using AES symmetric keys within the CCM mode to perform data encryption and decryption. It is built upon the CryptoArchitectureKit, providing a native approach for Cangjie developers to handle sensitive information. The guide meticulously covers the implementation details required to establish a secure cryptographic environment. This includes the procedures for generating robust symmetric keys and the correct methods for creating and configuring Cipher instances to handle the CCM mode effectively.

Beyond basic setup, the directory delves into the practical execution of the encryption and decryption workflows. It provides critical warnings and technical constraints specific to the CCM algorithm. Notably, it emphasizes that CCM mode is not designed for segmented or chunked processing; therefore, the entire data payload must be available and processed as a single unit, which impacts memory management strategies. Additionally, the documentation highlights the indispensable nature of authentication tag verification. This step is crucial for validating that the encrypted data has not been tampered with, ensuring both the privacy and the integrity of the information. This resource is essential for any developer requiring high-security data encryption capabilities in the Cangjie ecosystem, ensuring that they avoid common pitfalls associated with block cipher modes.
