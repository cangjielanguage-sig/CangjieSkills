This directory contains API reference documentation for the `AlignRuleOption` class within the Cangjie language and ArkUI framework. It covers the structural definition and initialization of alignment rules used to control component positioning in UI layouts. Key topics include horizontal alignment (left, right, middle), vertical alignment (top, bottom, center), and alignment bias. The documentation details properties, constructors, and parameter types like `HorizontalAlignParam` and `VerticalAlignParam`. It is intended for developers using ArkUI to build precise UI layouts starting from version 22, offering full control over alignment constraints and offsets.
