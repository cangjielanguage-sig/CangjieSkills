# cj-distributedservice-kit-intro

This directory serves as the entry point for understanding the Distributed Service Kit, a robust system service designed to empower applications with distributed capabilities. It covers the essential functionalities of distributed device management, hardware management, and cross-device mouse and keyboard control. The documentation details the operational mechanism, explaining how applications must actively initiate requests for device discovery, authentication, information queries, and state monitoring. Crucial concepts such as user permissions and the mandatory nature of device authentication as the gateway for distributed business operations are highlighted. This resource is specifically curated for application developers seeking to integrate multi-device features, offering a foundational overview of the interactions between the application and the system service.
