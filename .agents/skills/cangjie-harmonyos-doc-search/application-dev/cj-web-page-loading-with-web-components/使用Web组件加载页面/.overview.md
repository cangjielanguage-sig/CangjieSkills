# 使用Web组件加载页面

This directory provides comprehensive guides on using the ArkUI Web component to load and display various types of content in HarmonyOS applications. It covers loading network pages, local HTML files, and rich text strings, utilizing both static and dynamic methods. Key topics include configuring internet permissions, using `WebviewController`, managing `rawfile` resources, and handling application lifecycle events. These resources are tailored for HarmonyOS developers working with the Cangjie language and ArkTS who need to integrate web content into their native apps.

## Detailed Description

### 使用Web组件加载页面_2more.md 使用Web组件加载页面_2more.md
This guide explains how to utilize the Web component in ArkUI to load various types of page content. It covers loading network pages, local pages, and HTML rich text, with a specific focus on network page configuration. Key information includes the requirement to configure internet permissions in module.json5 and the distinction between static initialization via the src attribute and dynamic navigation using the WebviewController.loadUrl method. The document provides a Cangjie code example demonstrating these concepts. This tutorial targets HarmonyOS developers using the Cangjie language who need to integrate web content into their applications.

### 加载HTML格式的文本数据.md 加载HTML格式的文本数据.md
This document demonstrates how to load HTML string data directly into a Web component using data URLs within the Cangjie development environment. The content focuses on a practical code example that imports necessary ArkUI and Webview modules to render HTML content. Key information includes the specific syntax for constructing a data URL with the "data:text/html," prefix and assigning it to the Web component's source attribute. This tutorial is intended for ArkUI developers using the Cangjie language who need to display local or dynamic HTML content without external network requests. Keywords: ArkUI, Cangjie, Web component, data URL, HTML string, WebviewController.

### 加载本地页面/
This directory serves as a comprehensive technical guide for loading local pages within HarmonyOS applications, addressing specific development needs for both Cangjie and ArkTS developers. It thoroughly covers the intricacies of rendering local HTML content inside a Web component, including resource loading from `rawfile` directories and managing application sandbox paths. Furthermore, it details the application lifecycle management in ArkTS, specifically focusing on the `onWindowStageCreate` method to programmatically set the initial UI. Key concepts include `WebviewController`, `GlobalContext`, file access permissions, and `WindowStage` functionality. These documents are ideal for developers seeking to implement offline web rendering or control app initialization sequences effectively.
