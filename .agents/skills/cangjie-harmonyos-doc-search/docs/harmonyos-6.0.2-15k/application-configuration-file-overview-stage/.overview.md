# application-configuration-file-overview-stage

This directory serves as a comprehensive resource for developers working with the Stage model, specifically focusing on the mandatory configuration files essential for application development. It provides detailed insights into the structural requirements and content definitions for `app.json5`, which handles global settings such as bundle information and device types, and `module.json5`, which manages module-level configurations. Key topics include defining application components like UIAbility and ExtensionAbility, as well as setting up runtime permissions. This documentation is designed for developers who need to configure their application projects to ensure full compatibility with the operating system and app markets.

## Detailed Description

### application-configuration-file-overview-stage.md

This document provides an overview of the mandatory configuration files required for developing applications based on the Stage model. It details the structure and contents of the app.json5 file for global settings and the module.json5 file for module-level configurations. Key takeaways include that app.json5 holds bundle information and device types, while module.json5 defines module basics, application components like UIAbility and ExtensionAbility, and runtime permissions. This reference guide targets developers configuring their application projects to ensure compatibility with the operating system and app markets.
