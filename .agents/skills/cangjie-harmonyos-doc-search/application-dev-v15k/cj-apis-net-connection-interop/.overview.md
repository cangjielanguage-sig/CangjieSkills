# cj-apis-net-connection-interop

This directory contains the API reference documentation for the `ohos.net.connection.interop` module, a specialized library designed to facilitate interoperability between the Cangjie and ArkTS programming languages within the HarmonyOS ecosystem. The module focuses on network connection management, providing the necessary tools to bridge the gap between Cangjie objects and ArkTS `JSValue` types. It covers critical interfaces such as `JSSystemObjectInteropType` and the extended `NetHandle` class, which are essential for bidirectional data conversion. This documentation is intended for HarmonyOS developers who are working within the `SystemCapability.Communication.NetManager.Core` framework and need to integrate Cangjie logic with ArkTS applications or vice versa. Key topics include data parsing, object exporting, and cross-language type handling.

## Detailed Description

### cj-apis-net-connection-interop.md cj-apis-net-connection-interop.md

This file serves as the comprehensive API reference document for the `ohos.net.connection.interop` module. It is specifically designed to enable interoperability between Cangjie and ArkTS for the purpose of network connection management. The documentation provides a detailed technical overview of the `JSSystemObjectInteropType` interface, which is fundamental for defining how system objects are handled across the language boundary. Furthermore, it covers the extended `NetHandle` class, a crucial component that facilitates the bidirectional conversion between Cangjie objects and ArkTS `JSValue` types.

The document highlights key functions such as `fromJSValue`, which is used to parse ArkTS data into Cangjie objects, and `toJSValue`, which handles the reverse process of exporting Cangjie objects to ArkTS. This reference material is primarily targeted at HarmonyOS developers who require a robust solution to bridge Cangjie and ArkTS code within the `SystemCapability.Communication.NetManager.Core` framework. By utilizing these APIs, developers can ensure seamless data exchange and functionality integration between the two programming environments. Keywords associated with this document include Cangjie, ArkTS, NetHandle, Interop, JSValue, and NetworkManager.
