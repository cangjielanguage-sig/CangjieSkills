This directory provides API reference documentation for the `ResultSet` class in the Cangjie language, used for managing data sets from relational database queries in the ArkData framework. It covers class properties, resource management, data retrieval methods for various types (String, Int, Blob, Asset), and cursor navigation. The documentation includes system capabilities, error handling details, and code examples. It is intended for developers utilizing the RelationalStore core capability in HarmonyOS who need to programmatically access, manipulate, and traverse query results while handling potential database exceptions.
