# cj-nfc-hce-guide

This directory serves as a comprehensive technical resource dedicated to Host Card Emulation (HCE) technology within the Cangjie development framework and HarmonyOS ecosystem. It provides in-depth documentation on simulating NFC cards without relying on secure hardware elements (SE), covering critical implementation scenarios such as foreground and background swiping. The content focuses heavily on Application ID (AID) management, APDU command processing, and system configuration constraints, including screen unlock requirements. This guide is specifically designed for developers proficient in ArkTS or Cangjie who are looking to build secure, interactive applications capable of seamless communication with NFC readers. Whether you are developing payment solutions, access control systems, or identity verification tools, this documentation covers the full development lifecycle, offering the necessary API references and architectural knowledge to succeed. By leveraging this guide, developers can effectively implement HCE features to enhance user interaction and security in their applications.
