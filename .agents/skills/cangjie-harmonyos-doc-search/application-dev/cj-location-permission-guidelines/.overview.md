# cj-location-permission-guidelines

This directory provides a comprehensive development guide focused on the essential protocols for requesting user authorization for device location information before utilizing Location Kit capabilities. It covers the complete scenario overview, defining the various permission types and the step-by-step development procedures for requesting authorization. Key topics include the critical distinction between `ohos.permission.LOCATION` for precise, meter-level accuracy and `ohos.permission.APPROXIMATELY_LOCATION` for 5km accuracy. The guide also clarifies that requesting both permissions simultaneously grants precise location access. This resource is suitable for application developers integrating location services who need to understand permission declaration and request logic to ensure their applications function correctly within the system's privacy framework.

### cj-location-permission-guidelines.md

This document functions as a critical development guide for developers needing to request user authorization for device location information before accessing Location Kit capabilities. It begins with a scenario overview that clearly defines the available permission types, followed by a structured walkthrough of the development steps necessary for requesting authorization. A significant portion of the guide is dedicated to explaining the key differences between `ohos.permission.LOCATION`, which provides precise, meter-level accuracy, and `ohos.permission.APPROXIMATELY_LOCATION`, which offers a lower accuracy of 5km. The guide also elucidates the specific logic where requesting both permissions at the same time will result in the system granting precise location access to the application. This tutorial is essential for application developers integrating location services, as it provides the necessary knowledge to understand permission declaration and the underlying request logic required for a compliant user experience. By following this guide, developers can ensure they are adhering to best practices for privacy and user consent when handling sensitive location data.
