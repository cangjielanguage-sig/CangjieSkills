This directory offers a comprehensive guide for developers looking to implement external subtitle functionality in video playback applications using the AVPlayer instance in the Cangjie language. It covers the complete development lifecycle, from setting subtitle resources via file descriptors or URLs to registering and managing subtitle update callbacks. The documentation highlights critical constraints, such as the necessity of setting subtitles prior to playback initiation. Key technical elements include code examples for `addSubtitleFromFd`, `addSubtitleFromUrl`, and handling `AVPlayerCallbackType.subtitleUpdate` events. This resource is ideal for application developers leveraging the MediaKit API to enhance user experience with multilingual or accessible video content.
