# 开发步骤

This directory serves as a technical resource for developers working with the CryptoArchitectureKit in Cangjie, focusing specifically on the implementation of HMAC (Hash-based Message Authentication Code) using the SHA256 algorithm. It provides detailed instructions on the complete cryptographic workflow, ranging from generating symmetric keys to initializing Mac instances and processing data. The documents included here offer practical insights into handling data efficiently, with a particular emphasis on segmented processing for large data volumes. This content is highly suitable for software developers and security architects looking to integrate robust message authentication capabilities into their systems, ensuring data integrity and security through standardized cryptographic practices.

## Detailed Description

### 分段HMAC_2more.md
This document provides a step-by-step tutorial for performing segmented HMAC (Hash-based Message Authentication Code) operations using the CryptoArchitectureKit in Cangjie. It details the workflow including creating a Mac instance with SHA256, generating a symmetric key, initializing the Mac, and processing data in chunks via the update method. Key information includes a practical code example demonstrating how to split a message into 20-byte segments for processing, highlighting functions like createMac, init, update, and doFinal. This guide targets developers implementing cryptographic security features who need to handle large data inputs efficiently through segmented processing.

### 开发步骤_3more.md
This document serves as a development guide for implementing HMAC (Hash-based Message Authentication Code) using the CryptoArchitectureKit, specifically focusing on the SHA256 algorithm. It outlines the step-by-step process for generating a symmetric key, initializing a Mac instance, and processing data either in a single pass or segments. Key sections include the API workflow involving functions like createMac, convertKey, init, update, and doFinal, followed by a practical Cangjie code example demonstrating synchronous HMAC generation. The guide clarifies that segmentation does not affect calculation results, offering flexibility for large data volumes. Intended for developers integrating cryptographic security, it requires understanding of key generation and message authentication concepts.
