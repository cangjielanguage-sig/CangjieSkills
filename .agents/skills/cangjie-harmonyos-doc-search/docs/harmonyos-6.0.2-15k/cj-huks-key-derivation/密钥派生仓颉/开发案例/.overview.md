# 开发案例

This directory serves as a comprehensive repository of development examples and technical resources specifically designed for the HarmonyOS ecosystem. It focuses heavily on cryptographic security, demonstrating how to effectively utilize the Universal Keystore Kit (HUKS) and the Cangjie programming language. The content covers essential security protocols, including HMAC-based Key Derivation Function (HKDF) and Password-Based Key Derivation Function 2 (PBKDF2). By providing detailed code skeletons and structural descriptions, it guides developers through the complexities of key lifecycle management, parameter configuration, and secure data handling. This collection is ideal for software engineers, security architects, and developers aiming to build secure applications that require robust encryption and standardized key derivation mechanisms to safeguard sensitive user information. The examples provided here bridge the gap between theoretical security concepts and practical implementation within the HarmonyOS framework, ensuring that developers can confidently integrate high-level security features into their projects.

## Detailed Description

### HKDF/
This directory provides technical resources and code examples for implementing HKDF (HMAC-based Key Derivation Function) operations using the Universal Keystore Kit (HUKS) in the Cangjie programming language and HarmonyOS. It covers the complete lifecycle of cryptographic key derivation, including defining parameter sets, session management, initialization, data updates, and finalization. Key topics include configuring HUKS parameters for AES-128 source keys, handling errors, and managing wrapper functions for secure operations. This content is designed for developers building secure applications on HarmonyOS who require practical guidance on integrating robust key derivation logic and managing cryptographic sessions within the HUKS framework.

### PBKDF2/
This directory serves as a comprehensive guide for developers looking to implement PBKDF2 (Password-Based Key Derivation Function 2) within the HarmonyOS environment. It focuses on the practical application of the Universal Keystore Service (HUKS) and UniversalKeystoreKit to securely derive cryptographic keys from passwords or passphrases. The provided materials cover the entire cryptographic lifecycle, from generating base keys and configuring parameters like salt and iteration counts to managing derivation sessions and handling errors. Key technical aspects include the use of HUKS tags for algorithm specification and the storage of derived AES keys. This resource is particularly suitable for software engineers and security architects working with Cangjie or native HarmonyOS APIs who require robust solutions for secure key generation and data encryption. By utilizing these examples, developers can effectively integrate standardized key derivation mechanisms into their applications to enhance security and protect sensitive user data.
