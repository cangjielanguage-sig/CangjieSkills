# 使用场景

This directory provides a comprehensive collection of practical usage scenarios focused on state management within the Cangjie UI framework. It specifically addresses the implementation of the `@Provide` and `@Consume` decorators to facilitate seamless data synchronization between ancestor and descendant components. The content covers a wide spectrum of use cases, ranging from simple two-way data binding mechanisms, such as counters, to more advanced scenarios involving complex data structures like HashMaps and HashSets. Key topics include automatic view refreshes triggered by state changes, event handling for data modification, and the synchronization of collection types with display arrays. These tutorials are essential for HarmonyOS developers using the Cangjie language who aim to create efficient, responsive, and scalable user interfaces by mastering cross-component state management techniques.

## Detailed Description

### 使用场景_2more.md 使用场景_2more.md
This document provides practical code examples demonstrating state synchronization between ancestor and descendant components using the @Provide and @Consume decorators in Cangjie. It covers two primary scenarios: a basic counter implementation for two-way data binding and an advanced example managing a HashMap data structure. Key takeaways include understanding how modifications to @Consume variables in child components automatically update the @Provide variable in the ancestor, triggering view refreshes. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to implement efficient cross-component state management in their UI applications.

### 装饰Set类型变量.md 装饰Set类型变量.md
This tutorial demonstrates how to implement state management for HashSet variables using @Provide and @Consume decorators in Cangjie UI development. The document covers the setup of parent and child components, data synchronization between a HashSet and an Array for display, and event handling for data modification. Key takeaways include observing that modifying the HashSet—through initialization, adding elements, clearing, or removing items—triggers automatic view refreshes in the consuming component. This guide targets HarmonyOS developers using the Cangjie language who need to manage complex collection states across components.
