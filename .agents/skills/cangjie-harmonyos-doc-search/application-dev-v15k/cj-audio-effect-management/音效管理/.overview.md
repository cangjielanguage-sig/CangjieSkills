# 音效管理

This directory provides comprehensive technical documentation for managing audio effects within the Cangjie development environment, specifically utilizing the AudioKit framework. It covers the entire lifecycle of audio effect control, ranging from querying global effect modes for specific stream usage scenarios to managing effects within individual playback instances. Key concepts include AudioStreamManager, AudioRenderer, StreamUsage, and AudioEffectMode (EFFECT_NONE, EFFECT_DEFAULT). These guides are designed for Cangjie developers and audio engineers who need to dynamically configure audio settings, handle exceptions, and ensure optimal sound quality for various playback contexts.

## Detailed Description

### 全局查询音效模式.md 全局查询音效模式.md
This technical guide explains how to query global audio effect modes corresponding to specific stream usage scenarios in a Cangjie development environment. The document covers obtaining the audio stream management interface and querying sound effect modes for specific contexts like music playback. Key information includes the prerequisite step of creating an AudioStreamManager instance via getStreamManager() and using the getAudioEffectInfoArray() function to retrieve effect data based on StreamUsage parameters, with necessary exception handling. This guide targets audio application developers who need to dynamically adapt audio settings to match specific usage scenarios, ensuring optimal playback experiences.

### 播放实例音效管理.md 播放实例音效管理.md
This document serves as a technical guide for managing audio effects within audio playback instances using the Cangjie AudioKit. It details the process of creating an AudioRenderer, querying the current audio effect mode, and setting the mode to either disabled or default. Key information includes the definition of AudioEffectMode, specifically distinguishing between EFFECT_NONE and EFFECT_DEFAULT, where the latter automatically adapts to the StreamUsage scenario. The document provides practical code examples for creating renderers, configuring AudioRendererOptions, and handling exceptions. Intended for Cangjie developers, this guide requires basic knowledge of audio stream configuration and multimedia API usage. Keywords: AudioKit, AudioRenderer, AudioEffectMode, Cangjie, StreamUsage, audio rendering.

### 音效管理.md 音效管理.md
This document serves as a technical reference for managing sound effects within an audio system, focusing on playback instances and global capabilities. It covers two main sections: playback instance sound effect management and global sound effect queries. Key information includes methods to query and set effect modes for current audio playback streams, as well as functionality to determine supported effect modes for specific StreamUsage scenarios. This guide is intended for developers integrating audio features, providing the necessary logic to control and verify audio output configurations effectively.
