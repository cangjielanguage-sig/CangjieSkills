This directory provides comprehensive API reference documentation for the `WebSchemeHandlerResponse` class within the Cangjie language environment. It focuses on the mechanisms required to create and manipulate custom responses for web requests intercepted by a Web component. The documentation encompasses class initialization, various getter methods for retrieving response attributes, and setter functions for modifying metadata such as headers, MIME types, and status codes. Key topics include HTTP response handling, character set management, and network error codes. This resource is intended for developers utilizing the ArkWeb and UIKit frameworks who require precise programmatic control over web request handling and response generation.
