This directory provides essential API references for fundamental data structures and enumerations within the ArkUI framework, specifically tailored for the Cangjie language. It focuses on core navigation components, detailing classes that encapsulate navigation path information, stack states, and display modes, as well as enumerations that define visibility change reasons. These definitions are crucial for developers building complex user interfaces, enabling precise control over navigation logic, component lifecycle management, and state transitions. The documentation targets developers seeking to implement robust navigation behaviors and handle UI events effectively in their applications.
