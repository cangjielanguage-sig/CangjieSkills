This directory contains API reference documentation for the `UIExtensionContentSession` class in the Cangjie programming language, designed for HarmonyOS developers. It covers the management of UI extension content sessions, including loading page content, controlling screen capture privacy, implicitly launching abilities, and terminating sessions. Key topics include lifecycle management, permission handling (such as `ohos.permission.PRIVACY_WINDOW`), and error code management. This documentation is suitable for application developers building secure UI extension capabilities using the AbilityKit framework, specifically within contexts like `PhotoEditorExtensionAbility`.
