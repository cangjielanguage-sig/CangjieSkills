# class_Locale

This directory contains comprehensive API reference documentation for the `Locale` class within the Cangjie LocalizationKit, specifically designed to handle internationalization (I18n) settings. It covers the structural definition of the class, including its constructors, read-only properties like language and region, and methods for locale manipulation such as maximize and minimize. The documentation is intended for software developers implementing localization features who need to programmatically manage and normalize locale identifiers using the SystemCapability.Global.I18n capability. Key topics include locale constructors, attribute access, and string representation methods.
