This directory contains documentation for the `HuksTag` enumeration within the HarmonyOS Universal Keystore Service (HUKS) framework, specifically implemented in the Cangjie language. It covers a comprehensive range of cryptographic parameter tags, including algorithms, key sizes, digests, padding modes, and key management attributes like storage flags and access control. The documents detail system capabilities, API version availability (starting from version 15), and the deprecation status of legacy tags. This resource is suitable for HarmonyOS developers and security engineers who need to configure secure key operations, implement device attestation, or manage cryptographic lifecycles in their applications.
