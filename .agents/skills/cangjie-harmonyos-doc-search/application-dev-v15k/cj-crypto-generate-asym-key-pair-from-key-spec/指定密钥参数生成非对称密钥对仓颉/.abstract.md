This directory focuses on the technical implementation of generating asymmetric key pairs using specified parameters within the Cangjie programming language and the CryptoArchitectureKit framework. It covers essential cryptographic algorithms including RSA, ECC, and SM2, providing detailed guides on constructing key specifications, handling BigInt inputs in big-endian mode, and managing key attributes. The content is designed for software developers and security engineers who need to integrate custom key generation workflows into their applications, ensuring secure encryption, decryption, and key storage capabilities.
