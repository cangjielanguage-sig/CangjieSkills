# sync_package_enums

This directory serves as the definitive API reference for enumeration types within the synchronization package of the Cangjie standard library. It is a critical resource for developers aiming to master timer management and concurrency control in their applications. The documentation details specific enumeration types that dictate how systems handle asynchronous operations, particularly focusing on the `CatchupStyle` enum. This enum is essential for defining strategies—such as Delay, Burst, or Skip—that determine how repetitive tasks behave when their execution times exceed their scheduled intervals. Furthermore, the directory includes documentation for `MemoryOrder` and `ReadWriteMutexMode`, which address sequential consistency and lock fairness, although these are marked as deprecated. This content is intended for software engineers and developers working with the Cangjie standard library who possess a strong understanding of asynchronous programming and multithreading concepts. By leveraging these definitions, developers can ensure their applications maintain high performance and stability under concurrent loads.
