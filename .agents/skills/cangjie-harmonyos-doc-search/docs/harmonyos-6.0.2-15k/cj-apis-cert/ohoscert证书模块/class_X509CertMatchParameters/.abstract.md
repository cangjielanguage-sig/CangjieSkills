This directory contains comprehensive API reference documentation for the `X509CertMatchParameters` class, a fundamental component for handling X.509 digital certificates in the Cangjie programming language. It serves as a structural guide for filtering and matching certificates, detailing the implementation of security validation logic. Key topics include the class definition, optional properties like subjectAlternativeNames and authorityKeyIdentifier, and specific data types such as GeneralName arrays and UInt8. The documentation clarifies that the filter defaults to matching all certificates if no parameters are provided. This resource is suitable for developers and system architects working on cryptographic operations and secure application development using the SystemCapability.Security.Cert framework, specifically for versions 19 and above. It ensures precise control over certificate selection processes in security-sensitive environments.
