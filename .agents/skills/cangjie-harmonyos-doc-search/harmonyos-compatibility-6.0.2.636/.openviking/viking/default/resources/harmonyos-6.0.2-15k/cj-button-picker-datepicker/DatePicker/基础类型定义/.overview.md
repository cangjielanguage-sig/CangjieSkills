# 基础类型定义

This directory serves as a comprehensive repository for API reference documentation regarding fundamental type definitions within the ArkUI framework, specifically written for the Cangjie programming language. It encompasses essential classes used for configuring font styles, including `MyFont` and `PickerTextStyle`, alongside data structures designed to handle UI component results such as `DatePickerResult`. These definitions are indispensable for developers who need to customize text appearance and manage user input data programmatically. The documentation is primarily targeted at Cangjie developers involved in application development who require granular control over UI styling, resource management, and data handling logic. Mastering these base types allows developers to implement consistent, responsive, and visually appealing user interfaces effectively.

## Detailed Description

### class_MyFont.md class_MyFont.md
This document provides API reference documentation for the Cangjie MyFont class, designed to configure font formatting styles within the ArkUI framework. It covers four main properties: family, size, style, and weight, all of which are readable and writable with defined default values. The text explains two constructor overloads that allow specifying the font family using either a String or an AppResource type. Key information includes the system capability requirements and the specific data types used for each attribute. This guide targets Cangjie developers seeking to programmatically control text appearance in their applications.

### class_PickerTextStyle_2more.md class_PickerTextStyle_2more.md
This document serves as an API reference for configuring text styles and handling date selection results within the ArkUI framework using the Cangjie language. It details the PickerTextStyle class for font configuration and the DatePickerResult class for capturing date picker outputs. Key takeaways include the read-only properties for text color and font in PickerTextStyle, and the year, month, and day integers in DatePickerResult, specifically noting that the month value ranges from 0 to 11. Targeted at developers implementing UI components, this documentation requires familiarity with resource types and basic data structures.
