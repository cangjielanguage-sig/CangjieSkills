# 设备输入仓颉

This directory contains documentation for developing camera applications using the Cangjie programming language, focusing on device input capabilities. It covers the essential workflows for interacting with camera hardware, including requesting permissions, initializing streams, and managing outputs like real-time preview, photo capture, and video recording. Key topics include the use of the CameraKit API, environment setup, and error handling. This resource is suitable for software developers and multimedia application engineers who are proficient in Cangjie syntax and seek a foundational guide to building robust camera features within the Cangjie ecosystem.
