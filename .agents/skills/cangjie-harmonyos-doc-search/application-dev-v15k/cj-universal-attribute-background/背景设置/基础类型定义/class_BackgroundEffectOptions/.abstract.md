This directory provides comprehensive API reference documentation for the `BackgroundEffectOptions` class, specifically designed for the Cangjie language within the ArkUI framework. It serves as a technical guide for configuring background visual effects, enabling developers to implement sophisticated UI styling. The content covers essential aspects such as adaptive color modes, blur options, brightness, saturation, and radius settings. Additionally, it details logic for handling inactive window states and activation policies. This documentation is best suited for HarmonyOS developers who possess a solid understanding of Cangjie syntax and ArkUI system capabilities. By utilizing these resources, developers can effectively manage visual adjustments and create dynamic, responsive background effects for their applications.
