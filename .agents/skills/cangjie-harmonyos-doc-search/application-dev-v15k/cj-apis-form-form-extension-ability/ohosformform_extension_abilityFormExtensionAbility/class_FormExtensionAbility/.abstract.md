This directory contains API reference documentation for the `FormExtensionAbility` class in the Cangjie programming language, specifically designed for HarmonyOS application development. It covers the complete lifecycle management of form widgets (cards), including initialization, creation, configuration updates, user interaction, and deletion. Key topics include registering creator functions, handling state queries, and managing dynamic updates. This documentation is suitable for developers building form providers who need to implement robust widget behaviors and state management using Cangjie syntax.
