This directory contains API reference documentation for the `ohos.ability_access_ctrl` module in the Cangjie language, designed for HarmonyOS application security. It covers program access control management, including authentication, authorization, and permission verification. Key components include the `AtManager` class for handling access tokens, enumerations for grant statuses and hardware switches, and result classes for permission requests. Intended for Cangjie developers, these resources facilitate the implementation of secure runtime permission checks, user consent dialogs, and global switch management within the `SystemCapability.Security.AccessToken` framework.
