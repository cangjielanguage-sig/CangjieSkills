This directory provides comprehensive API reference documentation for the `FormInfo` class within the Cangjie programming language, specifically focusing on the configuration properties of system cards. It covers a wide array of read-only properties categorized into identity, display attributes, and behavior settings, including bundleName, colorMode, formType, and supportDimensions. The documentation highlights that these features belong to the SystemCapability.Ability.Form capability starting from version 20, offering essential metadata for managing the card lifecycle and presentation. This resource is primarily intended for developers building or managing form-based applications who require programmatic access to card configuration data to control UI behavior and appearance effectively.
