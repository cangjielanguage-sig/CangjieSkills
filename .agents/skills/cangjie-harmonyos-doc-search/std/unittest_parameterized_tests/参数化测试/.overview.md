# 参数化测试

This directory provides a comprehensive guide to parameterized testing in the Cangjie programming language. It covers essential techniques for automating test input generation, ranging from basic value-driven testing and type parameterization to advanced coverage-guided random testing and custom data strategies. Key topics include the `@Types` macro, `@Strategy` macro, Data DSL, and fuzzing-based coverage guidance. Designed for Cangjie developers, these resources help improve test coverage, reduce code duplication, and ensure robust validation of polymorphic and complex code structures.

## Detailed Description

### 类型参数化测试.md 类型参数化测试
This tutorial explains how to implement type parameterized testing in the Cangjie programming language to avoid code duplication when validating generic functions. It covers transitioning from specific type tests to generic test functions, addressing compilation errors, and utilizing the `@Types` macro. The key takeaway is that generic test functions require the `@Types` macro to specify concrete types like `Int64`, `Float64`, and `String`, ensuring the test logic runs separately for each specified type. This guide is intended for Cangjie developers seeking efficient testing strategies for polymorphic code.

### 覆盖率引导的随机参数化测试.md 覆盖率引导的随机参数化测试
This technical guide introduces coverage-guided random parametric unit testing within the Cangjie framework to overcome the limitations of standard random testing. The document covers the inefficiency of pure random generation, the introduction of fuzzing-based coverage guidance, specific compilation and runtime configuration steps, and a comparative code example. Key information includes the requirement to compile with --sanitizer-coverage-trace-pc-guard and --sanitizer-coverage-trace-compares, and run tests with the --coverage-guided option. This approach significantly increases the likelihood of finding edge cases like specific integer values, though it may require high generation step counts. It targets developers seeking rigorous security and defect detection who are familiar with unit testing concepts.

### 重用组合和映射参数策略.md 重用组合和映射参数策略
This tutorial explains how to use the `@Strategy` macro to create reusable and composable test data generation strategies in the Cangjie testing framework. It covers the limitations of standard random data generation for specific test cases like `HashSet.remove`, manual data generation, and the implementation of custom strategies. Key takeaways include how to annotate a generator function with `@Strategy` to eliminate code duplication and clearly separate test logic from data preparation, a feature also vital for benchmarking. Intended for Cangjie developers, this guide helps users write robust property-based tests requiring specific data constraints.

### 参数化测试入门/
This directory serves as a practical guide to parameterized testing within the Cangjie unittest framework, designed to help developers automate test input insertion using Data DSL. It covers a wide range of topics, from basic value-driven testing with single and multiple parameters to handling complex types and implementing advanced random testing strategies. Key concepts include Cartesian product combinations, avoiding combinatorial explosion, and utilizing `unittest.random()` for edge-case-biased data. Additionally, it addresses the critical aspects of reproducibility and configuration in random testing, such as using random seeds and interpreting failure outputs. Targeted at Cangjie developers, these documents aim to significantly improve test coverage, efficiency, and reliability through automated data generation and shrinking mechanisms.
