# cert_key

This directory serves as a specialized technical resource and tutorial collection for Cangjie developers who are focusing on implementing cryptographic security and Transport Layer Security (TLS) within their applications. It specifically addresses the complex but common task of parsing PEM-encoded files that bundle server certificate chains with private keys. This is a standard practice in HTTPS server deployment, and understanding how to handle these files programmatically is crucial. The content delves deeply into the `stdx.crypto.x509` package, illustrating how to perform file reading operations, decode PEM blocks accurately, and handle exceptions for missing or invalid credentials. By providing a concrete, executable code example, it assists developers in the correct initialization of `TlsServerConfig`. This resource is essential for backend engineers and system programmers working with the Cangjie language who require a robust, programmatic method to manage X.509 certificates and private keys within a single file structure for secure server configurations.

## Detailed Description

### cert_key.md cert_key.md

This document provides a Cangjie code example demonstrating how to parse a single PEM file containing both a server certificate chain and a private key for TLS configuration. It covers file reading operations, PEM decoding logic using the stdx.crypto.x509 package, and the initialization of TlsServerConfig. Key information includes the parsePem function, which filters PEM entries to extract an array of X509Certificate objects and a PrivateKey, while throwing exceptions for missing data. This tutorial targets Cangjie developers implementing secure HTTPS servers who need to handle combined certificate and key files.

**Implementation Details:**
The tutorial focuses on the `parsePem` function, which is central to the operation. This function is responsible for reading the raw file content and filtering the PEM entries. It distinguishes between different block types to correctly extract an array of `X509Certificate` objects representing the chain and a single `PrivateKey` for the server. The document also highlights the importance of error handling, specifically throwing exceptions when the expected data is missing, which is critical for preventing server misconfigurations.
