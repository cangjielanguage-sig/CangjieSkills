# 开发示例

This directory serves as a comprehensive resource for developers working with the Cangjie language within the HarmonyOS ecosystem, specifically focusing on file system operations. It provides practical tutorials and code examples demonstrating how to effectively handle file input/output (I/O), manage data streams, and manipulate directory contents. Key technical concepts covered include stream interfaces for buffered data transfer, file offset management, and the use of `FileFs` methods for robust file handling. Additionally, it explores advanced directory management techniques such as filtering files by attributes like size and modification time. These materials are highly suitable for HarmonyOS application developers seeking to implement efficient local data storage, file persistence, and complex file management features in their projects.

## Detailed Description

### 以流的形式读写文件_2more.md
This technical tutorial demonstrates file manipulation in the Cangjie language for HarmonyOS development. It covers two primary operations: reading and writing files using stream interfaces, and retrieving a filtered list of files. The stream section details creating input/output streams, buffered data transfer, and emphasizes the importance of closing streams and avoiding concurrent operations. The file listing section explains using ListFileOptions to filter by suffix, name, size, and modification time. This guide is intended for developers needing to implement file I/O and directory management within their applications.

### 开发示例_3more.md
This document provides practical code examples for performing file input and output operations using the Cangjie language within the HarmonyOS development environment. It covers prerequisites such as obtaining application file paths via AbilityContext, creating and writing to a new file, and reading content from one file to write to another. The examples utilize FileFs methods for opening, reading, writing, and closing files, highlighting the use of OpenMode and ReadOptions. It also includes a crucial note regarding file offset pointer management during read/write operations. This guide targets HarmonyOS application developers who need to implement local file storage and data manipulation features.
