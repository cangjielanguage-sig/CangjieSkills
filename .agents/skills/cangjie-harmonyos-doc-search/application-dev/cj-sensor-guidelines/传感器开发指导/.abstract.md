This directory provides a comprehensive guide for sensor module development, currently in Beta, focusing on enabling applications to access device sensor data. It covers essential topics such as scenario introductions, API interface descriptions, sensor categorization (periodic vs. instantaneous), and step-by-step development tutorials using the Cangjie language. Key concepts include accelerometer models, data monitoring (`on`, `once`), and listener management. This resource is suitable for application developers looking to integrate hardware sensor capabilities, understand reporting behaviors, and manage system permissions effectively.
