# 示例代码

This directory contains a collection of code examples demonstrating the implementation and configuration of the Swiper component within the ArkUI framework using the Cangjie language. It covers various navigation and pagination features, including dot indicators, digital indicators, group pagination, and handling overflow for navigation points. These examples are designed to help developers understand how to customize carousel behaviors, manage data sources with LazyForEach, and control navigation programmatically using SwiperController. The content is suitable for developers working with ArkUI who need to build interactive and visually appealing carousel interfaces in their applications.

## Detailed Description

### 示例代码1设置导航点交互及翻页动效.md
This document serves as a code example demonstrating how to configure the Swiper component with navigation dots and page turning animations using the Cangjie language in ArkUI. The main topics include implementing a custom data source for LazyForEach, styling the DotIndicator, and setting Swiper properties such as autoPlay, loop, and duration. Key takeaways involve using the SwiperController to programmatically navigate pages via showNext and showPrevious methods. This tutorial targets developers seeking to implement interactive carousel features, requiring basic knowledge of ArkUI component architecture and Cangjie syntax.

### 示例代码2设置数字指示器.md
This document provides a code example demonstrating how to implement and configure a digital indicator for a Swiper component using the ArkUI framework in Cangjie. The content covers the implementation of a custom IDataSource for data management, the setup of the main EntryView, and the specific configuration of the Indicator.digit() interface. Key information includes setting properties such as position, font color, and digit font weight, alongside Swiper features like auto-play and manual navigation via SwiperController. This tutorial is intended for developers seeking to enhance carousel components with numeric navigation indicators.

### 示例代码3设置按组翻页.md
This document provides a Cangjie code example demonstrating how to implement group pagination within a Swiper component using the displayCount property. The content covers the implementation of a custom data source, the configuration of the Swiper component, and the integration of navigation controls. Key takeaways include setting displayCount to 3 with swipeByGroup enabled to show multiple items per page, configuring auto-play and dot indicators, and using a SwiperController for manual navigation. This tutorial is intended for developers working with the ArkUI framework who need to create carousel interfaces with grouped sliding effects.

### 示例代码4设置圆点导航点超长显示.md
This document provides a Cangjie code example demonstrating how to configure a Swiper component's dot indicator to handle overflow display using the maxDisplayCount property. The content covers the implementation of a custom data source, the setup of the Swiper with auto-play functionality, and the specific styling of the DotIndicator. The key takeaway is the application of the .maxDisplayCount(9) attribute to manage visual overflow when navigation points exceed the display limit. This tutorial targets ArkUI developers using the Cangjie language who need to implement carousel navigation with constrained indicator space. Keywords: Swiper, DotIndicator, maxDisplayCount, Cangjie, ArkUI, overflow display.
