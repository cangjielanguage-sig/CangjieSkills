# cj-rendering-control-overview

本目录专注于ArkUI框架中声明式UI构建的渲染控制机制。它详细阐述了开发者如何在自定义组件的`build()`函数及`@Builder`装饰器中，运用条件渲染、循环渲染、数据懒加载以及混合模式组件渲染等关键技术。文档不仅解释了这些控制语句的基本概念，还深入探讨了它们如何根据数据状态的变化动态生成或控制UI界面。特别地，它针对大数据量场景下的性能优化提供了指导，并支持混合开发模式的实现。该文档主要面向使用ArkUI进行声明式UI开发的工程师，要求读者已具备自定义组件和基础UI描述语句的相关背景知识，旨在帮助开发者构建更高效、响应更灵敏的用户界面。

## Detailed Description

### cj-rendering-control-overview.md

本文档旨在概述ArkUI框架中声明式UI构建所使用的渲染控制语句及其基本概念。主要介绍了在自定义组件的build()函数和@Builder宏中，如何利用条件渲染、循环渲染、数据懒加载以及混合模式组件渲染等语句来辅助UI构建。核心要点在于掌握这些控制语句如何基于数据状态动态生成或控制UI组件，特别是针对大数据量场景的优化和混合开发模式的支持。文档面向使用ArkUI进行声明式UI开发的开发者，要求其具备自定义组件和基础UI描述语句的相关知识。
