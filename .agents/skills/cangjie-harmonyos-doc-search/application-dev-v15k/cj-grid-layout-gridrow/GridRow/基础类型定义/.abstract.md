This directory contains API reference documentation for fundamental type definitions used in configuring responsive grid layouts within the Cangjie ArkUI framework. It comprehensively covers essential classes and enums required for managing breakpoints, grid row sizing, gutter spacing, and layout directions. Key concepts include responsive thresholds, column configurations, and spacing options across various device sizes ranging from xs to xxl. This documentation is specifically suitable for UI developers and system architects looking to implement adaptive interfaces using ArkUI components, requiring a solid understanding of grid systems and Cangjie syntax.
