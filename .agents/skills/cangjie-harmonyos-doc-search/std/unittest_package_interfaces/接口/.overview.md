# 接口

This directory contains API reference documentation for core interfaces within the Cangjie programming language, primarily focusing on performance benchmarking and unit testing frameworks. It covers essential components such as input providers, measurement markers, configuration settings, and result reporting mechanisms. Additionally, it includes interfaces for numerical comparisons, specifically approximate equality for floating-point types. This documentation is suitable for Cangjie developers, QA engineers, and performance testers who need to implement custom testing logic, configure benchmarks, or handle precise numerical validations in their applications.

### interface_BenchInputProvider.md interface_BenchInputProvider.md
This API documentation defines the BenchInputProvider interface for managing input data during performance benchmarking in the Cangjie language. The document details the interface structure, its inheritance from BenchmarkInputMarker, and specifications for the get and reset methods. Key information includes that get retrieves elements by index with its execution time excluded from final results, while reset prepares the data range. The interface is typically utilized alongside DataStrategy and the @Strategy macro, meaning users rarely implement it directly. This reference guide targets developers creating performance tests who need to understand data provisioning and measurement overhead.

### interface_NearEquatableCT_D/
This directory provides comprehensive API reference documentation for the `NearEquatable` interface within the Cangjie programming language. It is designed to facilitate approximate equality comparisons between objects, a critical requirement for handling floating-point arithmetic where exact matches are often unreliable due to precision errors. The documentation covers the generic interface definition alongside specific extensions for `Float16`, `Float32`, and `Float64` types, supporting both absolute and relative delta calculations. Key features include the `isNear` function for Boolean results and strict exception handling for invalid inputs like negative or NaN deltas. This resource is essential for developers and engineers involved in numerical computing, scientific simulations, or unit testing who need robust mechanisms for defining and managing equality tolerances.
