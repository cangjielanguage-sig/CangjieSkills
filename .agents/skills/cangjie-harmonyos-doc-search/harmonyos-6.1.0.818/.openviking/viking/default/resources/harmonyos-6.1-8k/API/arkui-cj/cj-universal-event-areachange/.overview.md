# cj-universal-event-areachange

本目录包含ArkUI框架中组件区域变化事件的API参考文档，主要面向使用仓颉语言的开发者。文档详细介绍了如何通过`onAreaChange`接口监听组件尺寸和位置的变化，涵盖了事件定义、模块导入、参数及返回值规范。核心内容包括区分布局变化与绘制属性变化的影响，以及获取变化前后`Area`对象的方法。适用于需要动态获取组件布局信息以实现复杂交互或自适应布局的开发场景。掌握此API有助于开发者精确控制UI响应，提升应用的交互体验。

## 详细说明

### cj-universal-event-areachange.md cj-universal-event-areachange.md
本文档是ArkUI框架中组件区域变化事件的API参考，旨在指导开发者如何监听组件尺寸和位置的变化。内容涵盖事件定义、模块导入及`onAreaChange`函数的详细规范，包括参数和返回值说明。关键信息指出该回调仅响应布局变化导致的区域改变，不响应绘制属性（如translate）引起的变化，且提供变化前后的`Area`对象。面向使用仓颉语言的ArkUI开发者，适用于需要动态获取组件布局信息的场景。
