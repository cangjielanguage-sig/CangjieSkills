# cj-audio-playback-overview

This directory provides a specialized technical overview for developers implementing audio playback features using the Cangjie language. It functions as a strategic guide to navigating the available audio subsystems, ensuring that developers can match technical requirements with the correct API. The scope of the document covers four distinct playback methods: the **AudioRenderer** for advanced, low-level raw PCM processing; **AudioHaptic** for multi-sensory feedback involving synchronized vibration; **AVPlayer** for streamlined playback of standard media formats such as MP3; and **SoundPool** for high-performance, low-latency sound effects. Additionally, the resource outlines critical environmental constraints, specifically noting the current lack of support for background or screen-off playback. This documentation is primarily suitable for application developers and audio engineers who need to evaluate trade-offs between data format support, latency sensitivity, and overall usage scenarios to build robust audio applications.

## Detailed Description

### cj-audio-playback-overview.md cj-audio-playback-overview.md
This document serves as a comprehensive development overview designed to guide developers in selecting the most appropriate audio playback APIs within the Cangjie language ecosystem. It provides a detailed technical breakdown of four primary methods, each catering to specific development needs. First, the **AudioRenderer** is explained as the solution for raw PCM output, which is necessary when developers require granular control over manual data processing. Second, the **AudioHaptic** API is introduced for creating immersive experiences through synchronized audio-vibration feedback. Third, the **AVPlayer** is covered as the standard solution for integrated playback of common media formats like MP3, offering a balance of functionality and ease of use. Finally, the **SoundPool** is detailed as the optimal choice for low-latency short sound effects, often used in gaming interfaces. In addition to these capabilities, the document explicitly addresses system constraints, stating that background or screen-off playback is currently unsupported. This guide targets application developers seeking to implement audio features, helping them choose the right tool based on data format, latency requirements, and usage scenarios.
