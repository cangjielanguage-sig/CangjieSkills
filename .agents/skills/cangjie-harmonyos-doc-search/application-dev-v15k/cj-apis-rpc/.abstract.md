This directory serves as a comprehensive resource for API reference documentation focused on HarmonyOS RPC (Remote Procedure Call) and IPC (Inter-Process Communication) modules, specifically implemented using the Cangjie programming language. It is designed to provide developers with the necessary tools to enable efficient communication between processes and devices. The documentation covers a wide array of essential components, including remote object management, data serialization, shared memory usage, and error handling. Key topics detailed within include `IRemoteObject`, `MessageSequence`, `Ashmem`, and `DeathRecipient`. This resource is highly suitable for Cangjie developers and system engineers who are building distributed applications or services requiring robust, high-performance communication mechanisms within the HarmonyOS ecosystem. It acts as a critical guide for mastering inter-process communication capabilities in this specific development environment.
