This directory serves as a comprehensive guide for Cangjie developers focusing on the Want object within the AbilityKit framework. It provides a detailed conceptual overview of how Want functions as a carrier for passing information between application components, with a specific emphasis on UIAbility. The documentation thoroughly explains the distinction between Explicit Wants, which require specific parameters like bundleName and abilityName for precise internal launches, and Implicit Wants, which utilize actions and URIs to request system-matched capabilities. Furthermore, it covers potential system behaviors, such as user selection dialogs that arise during implicit matches. By including code examples, this resource assists developers in effectively implementing component startup and data transfer. This overview is essential for anyone looking to master inter-component communication and navigation logic in Cangjie applications.
