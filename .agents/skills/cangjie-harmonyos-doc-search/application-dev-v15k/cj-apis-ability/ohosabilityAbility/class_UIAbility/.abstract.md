This directory contains API reference documentation for the `UIAbility` class within the Cangjie framework and HarmonyOS AbilityKit. It focuses on the lifecycle management of applications with user interfaces, covering initialization, state transitions, window management, and inter-process communication. Key topics include core properties, lifecycle callbacks like `onCreate` and `onDestroy`, and window stage events. This documentation is suitable for HarmonyOS application developers using the Cangjie language who need to implement robust UI lifecycle handling, ability migration, and component collaboration.
