# cj-location-kit-intro

本目录提供了Location Kit的入门级介绍文档，旨在帮助开发者深入理解位置服务的核心功能与多样化的定位技术。文档内容详实，不仅涵盖了场景概述，还深入讲解了基础概念，包括坐标系统、全球导航卫星系统（GNSS）、基站定位以及WLAN/蓝牙定位等关键技术。此外，文档重点阐述了在集成过程中必须注意的约束与限制，明确指出应用获取位置信息需要用户开启开关并授权，且定位能力高度依赖设备硬件支持。通过阅读本文档，开发者可以掌握如何利用这些技术覆盖室内外全场景，从而有效提升应用体验。该文档特别适合需要集成位置功能的移动应用开发者，是快速上手Location Kit的必备指南。核心关键词包括Location Kit、定位服务、GNSS、基站定位、权限管理及开发者指南。
