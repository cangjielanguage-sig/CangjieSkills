This directory provides the definitive API reference for exception classes within the unittest mock package, specifically designed to address error scenarios encountered during testing. It details a robust hierarchy of exceptions, including ExpectationFailedException, MockFrameworkException, UnhandledCallException, and VerificationFailedException. Central to this system is the abstract PrettyException base class, which integrates Exception and PrettyPrintable traits to deliver formatted, readable error output via the pprint function. This documentation is crucial for developers writing unit tests in Cangjie, as it equips them with the knowledge to diagnose mock failures, handle unhandled calls, identify unnecessary stubbing, and resolve verification errors efficiently. By understanding these exceptions, developers can ensure their test suites are reliable and their debugging process is streamlined, ultimately leading to more robust software development practices.
