This directory provides comprehensive API reference documentation for the Cangjie class `RichEditorTextSpanResult`, specifically designed for the ArkUI framework. It focuses on encapsulating backend-returned text style information required for rich text editors. The documentation details the class definition, two distinct initializers, and seven public properties, including `spanPosition`, `value`, `textStyle`, `offsetInSpan`, `symbolSpanStyle`, `paragraphStyle`, and `previewText`. Each property is explained with its type, functionality, and read/write permissions. This resource is essential for developers working with Cangjie syntax to implement advanced text editing features, covering system capabilities and API version requirements (support starts at API 12, with specific additions in API 19). It serves as a technical guide for managing text span content, positioning, and styling within UI components.
