This directory provides comprehensive technical documentation for the `distributionFilter` tag within the HarmonyOS development ecosystem. It focuses on the mechanisms required to specify HAP (HarmonyOS Ability Package) distribution strategies, enabling precise cloud matching for application markets. The documentation covers essential configuration rules, usage scenarios for overlapping device types, and file placement requirements. Key topics include filtering attributes such as screenShape, screenWindow, screenDensity, and countryCode, along with include/exclude policies for targeting specific hardware. This resource is specifically designed for HarmonyOS developers and system architects who need to manage multi-module projects and ensure accurate app delivery across diverse device profiles, including lightweight wearables. It serves as a critical reference for ensuring unique HAP identification and optimizing app distribution logic.
