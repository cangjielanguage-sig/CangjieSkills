This directory contains API reference documentation for the `Task` class within the Cangjie language environment, specifically designed for managing file transfer operations. It covers the lifecycle management of upload and download tasks, including initialization, event subscription, and control methods like pause, resume, and stop. Key topics include task configuration, unique task IDs, and asynchronous event handling for progress and response headers. This documentation is intended for developers working with the HarmonyOS ecosystem and the SystemCapability.Request.FileTransferAgent, requiring knowledge of Cangjie syntax and application context management.
