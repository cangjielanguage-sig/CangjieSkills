This directory contains API documentation for implementing saturating arithmetic and bitwise operations on the `Int8` type within the Cangjie programming language. It focuses on safety mechanisms where operations clamp results to maximum or minimum values instead of wrapping around on overflow or underflow. The content covers a wide range of functions including addition, subtraction, shifting, and negation. This resource is suitable for Cangjie developers who require precise, bounded integer arithmetic for low-level programming or applications where data integrity is critical and preventing unexpected wrapping behavior is a priority.
