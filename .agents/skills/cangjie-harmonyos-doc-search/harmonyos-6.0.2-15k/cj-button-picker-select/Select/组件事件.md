### func onSelect((Int32,String) -> Unit)

```cangjie
public func onSelect(callback: (Int32, String) -> Unit): This
```

**功能：** 下拉菜单选中某一项时触发该回调。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|(Int32,String)->Unit|是|-|选中项的索引和值。|
