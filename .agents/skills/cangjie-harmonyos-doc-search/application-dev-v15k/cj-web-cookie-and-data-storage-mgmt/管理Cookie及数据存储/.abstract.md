This directory provides comprehensive technical guidance on managing client-side data persistence and state within the ArkWeb and ArkUI Web components using the Cangjie language. It covers essential mechanisms for handling cookies, including security attributes like SameSite, storage paths, and synchronization interfaces. Furthermore, it details strategies for optimizing web resource loading through various cache configuration modes and managing DOM Storage for temporary and persistent data retention. This documentation is specifically designed for application developers seeking to implement robust data management, enhance web performance, and ensure secure state persistence in their web-based applications.
