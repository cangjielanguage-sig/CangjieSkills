This directory serves as a comprehensive technical guide for HarmonyOS developers aiming to implement local call audio recording using the AudioCapturer module within the Cangjie language environment. It details the end-to-end process, starting from obtaining the UIAbility context and initializing the AudioCapturer with critical configurations, specifically setting the source type to `SOURCE_TYPE_VOICE_COMMUNICATION`. The content covers essential steps such as setting up audio stream parameters, registering callbacks for data reading and event monitoring, and writing captured data to a file. Furthermore, it addresses the management of the recording lifecycle, including starting, stopping, and releasing resources, with a strong emphasis on state validation and error handling. This resource is ideal for developers seeking to build robust call recording features that require microphone permissions and precise audio state management. By following these tutorials, developers can ensure their applications handle audio streams efficiently while adhering to system state requirements and business exception protocols.
