This directory serves as a comprehensive technical reference for universal attributes and events within a UI development framework. It covers essential aspects of component design, including layout constraints (width, height), visual styling (background, borders), interaction handling (gestures, focus), and animation effects. Additionally, it details lifecycle events, drag-and-drop functionality, and input handling for mouse, touch, and keyboard interactions. This resource is suitable for developers looking to quickly locate specific properties to define component appearance or implement interactive behaviors and state tracking in their UI applications. It acts as a central index for styling and functional logic, providing direct links to detailed definitions for efficient development workflows. By categorizing properties and events, it enables rapid application of styling and functional logic to components, making it an essential tool for building responsive and interactive user interfaces.
