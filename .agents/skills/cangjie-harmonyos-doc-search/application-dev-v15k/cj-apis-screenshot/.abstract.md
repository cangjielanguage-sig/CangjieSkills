The `cj-apis-screenshot` directory is a comprehensive technical repository dedicated to the `ohos.screenshot` module within the HarmonyOS Cangjie language ecosystem. It serves as an essential guide for developers aiming to implement robust screen capture functionalities in their applications. The directory covers a wide array of scenarios, including the retrieval of full-screen images on tablet devices and the handling of selective capture data on 2-in-1 devices. Beyond basic capture logic, it provides in-depth documentation on API references for core classes such as `PickInfo` and `Rect`, alongside critical information on configuration options, required system permissions, and error handling protocols. This resource is specifically curated for software engineers and developers who are actively utilizing ArkUI and ImageKit to build advanced window management features or integrate seamless screen capture capabilities into their software projects.
