This directory contains API reference documentation for the WebSocket class within the Cangjie programming language's HTTP package. It covers the implementation of WebSocket connections, adhering to RFC 6455 standards. Key topics include connection management, frame reading and writing, automatic fragmentation, and protocol upgrades for both client and server sides. Developers will find details on properties like subprotocols, logger configuration, and error handling for exceptions such as SocketException. This documentation is suitable for backend developers and network engineers building real-time communication applications who need to manage low-level WebSocket operations and protocol compliance in Cangjie.
