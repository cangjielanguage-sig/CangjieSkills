This directory contains API reference documentation for the `HuksTag` class and related static constant definitions within the HarmonyOS Universal Keystore (HUKS) framework. It covers a comprehensive set of tags used to specify key attributes, cryptographic algorithms, operational parameters, and security access controls in the Cangjie programming language. Key topics include AEAD data, key agreement, block modes, authentication mechanisms, and RSA configurations. This documentation is suitable for security developers, system engineers, and application developers implementing secure hardware-backed key management and cryptographic functions in OpenHarmony or HarmonyOS environments.
