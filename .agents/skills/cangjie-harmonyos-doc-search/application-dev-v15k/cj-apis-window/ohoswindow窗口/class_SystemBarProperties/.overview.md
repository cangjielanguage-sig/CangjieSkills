# class_SystemBarProperties

This directory contains comprehensive API documentation for the `SystemBarProperties` class within the Cangjie language framework. It is dedicated to the configuration and customization of system-level UI elements, specifically the status bar and navigation bar. The documentation covers essential aspects such as setting background and content colors, managing icon highlight states, and toggling animations. It also explains the precedence rules where content colors override light icon settings. This resource is primarily suitable for application developers and system integrators involved in window management who require precise control over the visual presentation and behavior of system interface components.
