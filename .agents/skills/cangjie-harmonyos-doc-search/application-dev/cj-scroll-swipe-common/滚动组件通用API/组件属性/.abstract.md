This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework. It primarily focuses on scroll-related behaviors and visual styling, including edge fading effects, physics parameters like friction and fling speed, nested scrolling mechanisms, and scroll bar customization. Additionally, it covers content clipping and scroll interaction management. These documents are designed for developers using ArkUI Full capabilities who need to implement complex scrolling interactions and fine-tune UI component aesthetics in their applications.
