# 基础类型定义

This directory provides fundamental type definitions and API references for the ArkUI framework's Navigation components, specifically designed for the Cangjie language. It covers essential classes and enumerations for managing routing stacks, configuring navigation bars, handling page transitions, and customizing toolbars and menus. Key topics include `NavPathStack` management, `NavigationOptions` for launch modes, and styling for titles and toolbars. This documentation is suitable for HarmonyOS developers and software engineers implementing complex navigation logic and UI layouts in ArkUI applications.

## Quick Navigation

**What do you want to learn or configure?**

*   Manage the navigation route stack and page lifecycle → `class_NavPathStack/`
*   Configure how navigation starts (animations, launch modes) → class_NavigationOptions.md
*   Handle page return information and callbacks → class_NavPathInfo.md, class_PopInfo.md
*   Customize the title bar appearance and layout → `class_NavigationTitleOptions/`, class_NavigationCommonTitl_5more.md, enum_NavigationTitleMode_2more.md
*   Configure toolbar items and menus → class_NavigationToolbarOptions.md, class_NavigationMenuItem.md, class_ToolBarItem.md

## Detailed Description

### class_NavPathInfo.md class_NavPathInfo.md
This document provides API reference documentation for the Cangjie class `NavPathInfo`, used to store routing page information within the ArkUI framework. It covers the class definition, including public properties for page name, parameters, and a pop callback, as well as two initialization constructors. Key information highlights the `onPop` callback, which executes when a `NavDestination` page is popped with a result. This reference is intended for developers implementing navigation logic in ArkUI applications using Cangjie.

### class_NavigationCommonTitl_5more.md class_NavigationCommonTitl_5more.md
This document provides API reference documentation for ArkUI Navigation components in Cangjie. It details the `NavigationCommonTitle` class for managing titles and defines enumerations: `NavigationMode`, `ToolbarItemStatus`, `NavBarPosition`, and `LaunchMode`. Key information includes specific behaviors for Split and Stack modes, toolbar state styles, and routing logic like SingleTon patterns. It facilitates the implementation of navigation bars, toolbar controls, and complex page routing.

### class_NavigationMenuItem.md class_NavigationMenuItem.md
This API reference defines the `NavigationMenuItem` class, representing menu options within the ArkUI framework for Cangjie developers. It details properties such as text value, icon path, enable state, and selection action callbacks. The document explains two constructor overloads: one accepting standard Strings and another supporting `AppResource` types for localization. All properties are read-write.

### class_NavigationOptions.md class_NavigationOptions.md
This document serves as an API reference for the Cangjie class `NavigationOptions`, defining configuration settings for initiating navigation within the ArkUI framework. It details the class structure, focusing on two primary properties: `launchMode` for page stack operations and `animated` for transition animation control. Key takeaways include the read-only nature of these properties and their default values (`LaunchMode.Standard` and `true`).

### class_NavigationToolbarOptions.md class_NavigationToolbarOptions.md
This API reference details the `NavigationToolbarOptions` class used to configure the appearance and layout of a Navigation toolbar in the Cangjie ArkUI framework. It covers the class definition, three configurable properties including `backgroundColor`, `backgroundBlurStyle`, and `barStyle`, along with the class constructor. All properties are optional, defaulting to system settings or None, allowing developers to customize visual elements.

### class_PopInfo.md class_PopInfo.md
This document serves as API reference documentation for the Cangjie `PopInfo` class, designed to act as a carrier for callback information when a page returns. It covers the class definition, its two primary properties, and the initialization constructor. Key information includes the `info` property, holding system-populated `NavPathInfo`, and the `result` property, a String for developer-defined return outcomes. Both properties are readable and writable.

### class_ToolBarItem.md class_ToolBarItem.md
This API reference details the `ToolBarItem` class used to configure individual options within a toolbar for ArkUI applications. It covers class properties including value, icon, activeIcon, status, and action, alongside two constructor overloads. Key information includes support for both String and `AppResource` types for text and icons, facilitating internationalization. All properties are readable and writable, with status defaulting to `ToolbarItemStatus.NORMAL`.

### enum_NavigationTitleMode_2more.md enum_NavigationTitleMode_2more.md
This document provides API reference documentation defining enums used to configure navigation title behaviors and layout styles in the ArkUI framework. It covers the `NavigationTitleMode` enum (Free, Full, Mini modes) and the `BarStyle` enum (Standard, Stack layouts). Key information includes specific height values, scroll interaction rules, and system capabilities. It is intended for developers implementing dynamic navigation interfaces.

### class_NavPathStack/
This directory contains API reference documentation for the `NavPathStack` class in Cangjie, designed for managing Navigation route stacks within the ArkUI framework. It covers the comprehensive lifecycle and manipulation of page stacks, including methods for pushing, popping, removing, and reordering pages. Key topics include animation control, parameter passing, nested navigation, and stack state retrieval. Suitable for developers implementing complex page routing logic.

### class_NavigationTitleOptions/
This directory provides API reference documentation for the `NavigationTitleOptions` class within the HarmonyOS ArkUI framework for Cangjie. It covers the configuration of navigation title bar styles, detailing properties such as background color, blur effects, bar styles, and padding constraints. It is designed for developers aiming to customize the visual layout and spacing of navigation titles, starting from API version 20.
