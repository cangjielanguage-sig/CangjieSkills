# cj-telephony-call

This directory serves as a comprehensive technical resource for developers aiming to integrate telephony features into applications built with the Cangjie language. It specifically addresses the implementation of phone call functionality within third-party apps, detailing the necessary APIs, system constraints, and logic handling required for a seamless user experience. Key topics include the use of the `makeCall` interface to invoke the system dialer, verifying device capabilities via `hasVoiceCapability`, and managing call states such as Idle, Ringing, and Offhook. The content is tailored for Cangjie developers targeting standard systems equipped with SIM cards, offering practical code examples for UIAbility integration and a structured development workflow to ensure successful implementation of voice calling features.

## Detailed Description

### cj-telephony-call.md
This technical guide explains how to implement phone call functionality in third-party applications using the Cangjie language. It covers scenario introduction, basic concepts like call state codes, system constraints, API descriptions, and a step-by-step development tutorial. The core functionality relies on the makeCall interface to launch the system dialer and hasVoiceCapability to check device support. It defines states such as Idle, Ringing, and Offhook for logic handling. Targeted at Cangjie developers working on standard systems with SIM cards, the document provides code examples for UIAbility integration.
