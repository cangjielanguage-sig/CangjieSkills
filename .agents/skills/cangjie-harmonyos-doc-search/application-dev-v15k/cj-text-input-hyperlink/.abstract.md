This directory serves as a comprehensive repository for technical documentation regarding the `cj-text-input-hyperlink` component, specifically focusing on the Hyperlink functionality within the Cangjie ArkUI framework. It is designed to assist developers in seamlessly integrating web navigation and external URL redirection capabilities into their applications. The documentation encompasses a wide array of critical topics, including component functionality, necessary permission configurations for internet access, and detailed API references for initialization. Furthermore, it provides in-depth guidance on universal properties, event handling mechanisms, and customization options for text and image sub-components. This resource is primarily tailored for Cangjie application developers and UI engineers who require a reliable reference for implementing interactive and user-friendly hyperlink features in their interfaces.
