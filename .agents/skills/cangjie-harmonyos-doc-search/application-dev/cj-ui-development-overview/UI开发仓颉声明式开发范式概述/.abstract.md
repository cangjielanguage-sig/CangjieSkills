This directory provides a comprehensive introduction to the ArkUI framework's declarative development paradigm using the Cangjie programming language. It covers the framework's architecture, core features, development workflow, and general coding rules. Key topics include state management, component usage, layout design, and performance optimization. Designed for application developers and technical architects, this documentation serves as a foundational guide to building high-performance, cross-device user interfaces efficiently using Cangjie's natural syntax and robust backend capabilities.
