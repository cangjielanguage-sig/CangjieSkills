# 使用场景

This directory contains technical tutorials and practical examples focused on specific usage scenarios for state management in Cangjie, specifically for HarmonyOS application development. It primarily covers the advanced implementation of the `@Watch` decorator to observe state changes, handle complex data structures like dynamic ArrayLists, and manage UI updates within custom components. Key topics include the interaction between `@Link` and `@State`, execution flows for parent-child component updates, and optimizing state observation logic. These resources are suitable for HarmonyOS developers using the Cangjie language who possess prerequisite knowledge of state management and component lifecycles and wish to master reactive programming patterns.

## Detailed Description

### Watch和自定义组件更新_2more.md
This technical tutorial demonstrates how to implement the @Watch decorator alongside @Link and @State to manage state changes and UI updates in Cangjie custom components. The document covers two primary scenarios: observing a simple integer counter and observing a dynamic ArrayList within a child component. Key takeaways include the execution flow where parent state changes trigger child @Link updates, invoking @Watch callbacks to modify local state and asynchronously re-render components like Text and ForEach. Targeted at HarmonyOS developers using Cangjie, this guide requires prerequisite knowledge of state management and component lifecycle.

### 使用changedPropertyName进行不同的逻辑处理.md
This tutorial demonstrates how to implement conditional logic within a shared @Watch callback function in Cangjie state management. The document presents a code example using @Entry, @Component, and @State decorators to track changes in multiple variables like apple and cabbage. Key information includes using a tracking variable to identify which property triggered the update, allowing specific actions such as updating a fruit total only when the apple count changes. The step-by-step explanation details the rendering flow and logic branching. Intended for Cangjie developers building HarmonyOS applications, this guide helps optimize state observation by consolidating logic for different properties into a single function.
