# cj-photoAccessHelper-resource-guidelines

This directory serves as a comprehensive resource for developers working within the HarmonyOS ecosystem, specifically focusing on the Cangjie programming language. It provides detailed guidelines for utilizing the MediaLibraryKit and photoAccessHelper interfaces to manage media resources effectively. The documentation covers a wide range of essential operations, including querying, renaming, deleting, and retrieving thumbnails for both images and videos. Furthermore, it outlines critical aspects such as necessary permissions, initialization procedures, and the practical application of specific APIs like `deleteAssets` and `getThumbnail`. This guide is primarily suitable for application developers seeking to implement robust and efficient media access and management features in their applications.
