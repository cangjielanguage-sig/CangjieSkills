This directory contains API reference documentation for the `ohos.labels` package in the Cangjie language, focusing on metadata annotations and permission management systems. It covers classes and structs used to define API attributes, such as API levels, deprecation versions, system capabilities, and permission logic. Key components include the `APILevel` class, permission combination classes (`PermissionAnd`, `PermissionOr`), and extensions to the `String` struct for permission handling. This documentation is intended for system developers, framework engineers, and software developers working on HarmonyOS API definitions who need to implement access control and versioning logic.
