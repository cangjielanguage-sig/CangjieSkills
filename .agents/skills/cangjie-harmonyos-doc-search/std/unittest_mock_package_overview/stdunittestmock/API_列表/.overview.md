# API_列表

This directory serves as a comprehensive API reference for a unit testing mock framework, providing essential documentation for developers and QA engineers. It covers the core components required to implement advanced testing strategies, including functions for creating test doubles, enumeration types for configuring behaviors, and class structures for object-oriented verification. Key topics include mocking, spying, stubbing modes, argument monitoring, and action selectors. By detailing the distinctions between mock and spy objects and outlining verification modes, this documentation enables users to precisely control test environments and ensure code reliability through rigorous unit testing practices.

## Detailed Description

### 函数_2more.md 函数_2more.md
This document serves as a reference guide for core functions and interfaces within a unit testing mock framework. It covers two main categories: Functions and Interfaces. The Functions section details `mock` and `spy` for creating test doubles, while the Interfaces section introduces `ValueListener` for argument monitoring. Key takeaways include the distinction between `mock` objects, which lack default implementation, and `spy` objects, which wrap real instances to preserve default behavior. Additionally, it highlights the configuration of stub modes. This documentation is intended for software developers and QA engineers seeking to implement advanced mocking, spying, and argument verification in their unit tests.

### 枚举.md 枚举.md
This document acts as a reference guide for enumeration types used within a unit testing and mocking framework. It provides a structured overview of three key enums: Exhaustiveness, MockSessionKind, and StubMode. The content explains that Exhaustiveness specifies verification modes for the unordered function, MockSessionKind controls permissible stub types within a MockSession, and StubMode dictates the operational behavior of stubs. This documentation is intended for software developers and QA engineers who are configuring mock objects and defining test behaviors. It serves as a navigation aid pointing to detailed API definitions for advanced test setup.
