This directory focuses on the @Provide and @Consume macros within the Cangjie and ArkUI frameworks, designed to facilitate two-way data synchronization between ancestor and descendant components. It covers the core mechanisms of cross-level state management, eliminating the need for manual parameter passing through intermediate layers. The content includes technical specifications, variable access rules, usage constraints, and practical scenarios for handling complex data structures. It is suitable for developers, software engineers, and technical architects working with HarmonyOS or Cangjie who need to implement efficient, reactive state management in complex component hierarchies.
