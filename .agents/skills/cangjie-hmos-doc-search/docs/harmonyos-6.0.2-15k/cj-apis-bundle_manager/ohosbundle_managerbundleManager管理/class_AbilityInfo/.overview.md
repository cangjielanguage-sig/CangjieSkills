# class_AbilityInfo

This directory provides API reference documentation for the `AbilityInfo` class in the Cangjie programming language, tailored for HarmonyOS application developers. It comprehensively covers the properties that define an Ability's configuration, metadata, and runtime behavior. Key topics include system capabilities, read-only properties such as bundleName, label, icon, launchType, permissions, and module settings, as well as specific versioning requirements for newer attributes. This resource is essential for developers seeking to programmatically query and manipulate Ability component attributes and configurations using the `getBundleInfoForSelf` interface.
