# 短信服务

This directory provides comprehensive technical documentation for integrating SMS services within HarmonyOS applications. It covers core concepts, system constraints, and API interfaces for SMS management, including message creation and SIM slot configuration. Key topics include launching the SMS editing interface via URI protocols or in-app jumps using the Cangjie language, handling permissions, and constructing Want objects. Suitable for mobile developers, these guides facilitate the implementation of features like sending messages, managing service centers, and navigating between third-party apps and the system messaging interface.

### 应用内跳转到短信编辑界面.md 应用内跳转到短信编辑界面.md
This technical guide instructs developers on implementing a jump from a third-party application to the system SMS editing interface using the Cangjie language. The document explains that due to system permission restrictions for direct SMS sending, applications must use the `startAbilityForResult` interface. Key sections include defining the target bundle and ability name, constructing a Want object with parameters for recipient contact objects and message content, and handling the UI context. The provided code snippets demonstrate how to pass a JSON payload containing the phone number and text body to the `com.ohos.mms` module. This resource is designed for HarmonyOS developers seeking to integrate SMS capabilities into their applications.
