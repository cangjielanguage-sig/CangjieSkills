This directory focuses on state management techniques for component-level variables within the Cangjie language and ArkUI framework. It covers reactive data structures like ObservedArray and ObservedArrayList, as well as the generic ObservedProperty class, which facilitate automatic UI synchronization when data changes. Key topics include recursive observation binding, index-based access, and thread-safe state updates. This documentation is suitable for ArkUI developers and HarmonyOS engineers looking to implement dynamic, data-driven user interfaces with efficient state handling and declarative UI patterns.
