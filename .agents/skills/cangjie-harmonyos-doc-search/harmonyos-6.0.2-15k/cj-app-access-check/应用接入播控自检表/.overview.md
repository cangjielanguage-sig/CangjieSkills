# 应用接入播控自检表

This directory serves as a comprehensive resource for developers and quality assurance teams involved in integrating media playback controls within their applications. By utilizing these documents, developers can verify that their applications deliver a consistent and seamless user experience, particularly regarding lock screen and background audio behaviors. This document acts as a self-checklist guide for developers integrating the AVSession framework to manage audio playback control. It primarily distinguishes between applications requiring background or lock screen audio capabilities versus those limited to foreground playback.
