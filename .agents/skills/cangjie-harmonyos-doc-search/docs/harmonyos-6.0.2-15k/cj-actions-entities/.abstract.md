This directory provides essential documentation for HarmonyOS developers regarding the use of Actions and Entities within implicit Want parameters. It serves as a technical reference for defining generic operations (such as viewing data) and categorizing system components (such as browsers). The content covers specific constants like `ACTION_VIEW_DATA` and `ENTITY_HOME`, illustrating how they function to match caller requests with receiver skills. However, a primary focus of this documentation is the security implications of these features; it explicitly warns against their continued use due to risks like malicious traffic hijacking. Consequently, it outlines the system's roadmap for deprecating these features and guides developers toward adopting safer, specific type-based launching methods. This resource is suitable for application developers currently maintaining legacy code or configuring module skills who need to understand the shift away from implicit intents. Understanding these definitions is critical for ensuring application compatibility while adhering to new security protocols.
