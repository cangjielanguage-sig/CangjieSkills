This directory contains a guide for HarmonyOS developers implementing interoperability between ArkTS and Cangjie using a manual library approach, serving as an alternative to declarative macros. The documentation covers the end-to-end process, starting with creating a Cangjie module and defining functions that utilize JSContext and JSCallInfo parameters. Developers will learn to register modules programmatically using JSModule.registerModule and handle type conversions between JSValue and Cangjie types. It also provides instructions for generating TypeScript declarations and importing dynamic libraries into ArkTS projects. Crucially, the guide emphasizes strict naming conventions to prevent symbol overwriting between manually registered functions and those generated by the @Interop decorator. This resource is intended for developers with a strong command of both ArkTS and Cangjie syntax seeking advanced integration techniques. By following this guide, developers can ensure seamless communication between the two environments while maintaining code integrity.
