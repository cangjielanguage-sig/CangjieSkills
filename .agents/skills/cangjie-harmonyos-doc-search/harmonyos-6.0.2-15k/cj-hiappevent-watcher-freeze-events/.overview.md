# cj-hiappevent-watcher-freeze-events

This directory provides a comprehensive technical reference for the `appfreeze` event structure within the HiAppEvent framework, specifically designed for the Cangjie programming language. It focuses on the `params` attribute, which is essential for capturing and analyzing critical system data during application freeze events. The content covers a wide array of diagnostic information, including process identifiers, detailed exception reports, full thread stacks with frame information, and memory usage statistics. Additionally, the documentation outlines specific enhancements introduced in API 12, such as external log paths and storage limits. This resource is highly suitable for developers, system engineers, and performance analysts who are tasked with monitoring application stability, debugging complex performance bottlenecks, and conducting root cause analysis for crashes in Cangjie-based environments.
