This directory functions as a specialized reference library for system permissions within the OpenHarmony and HarmonyOS ecosystems, specifically targeting API version 12. It provides detailed lists of permissions necessary for accessing a diverse range of device capabilities, including hardware interfaces (Bluetooth, NFC, sensors), system utilities (background running, biometric auth), and advanced features (cloud sync, input control). The documentation clarifies that these are generally normal level permissions using system_grant authorization. This resource is primarily designed for application developers who need to accurately declare permissions in their configuration files to unlock specific functionalities and adhere to system security policies.
