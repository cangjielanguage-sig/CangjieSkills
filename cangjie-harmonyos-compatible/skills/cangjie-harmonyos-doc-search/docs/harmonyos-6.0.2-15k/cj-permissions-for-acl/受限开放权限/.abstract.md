This directory serves as a comprehensive guide for managing restricted open permissions within the HarmonyOS and OpenHarmony development environments. It addresses the critical procedures and compliance standards required for applications that need access to sensitive system capabilities. The content covers the end-to-end application process, including eligibility criteria, the necessity for prior approval, and the rigorous audit processes conducted by App Gallery Connect (AGC) during the release phase. Furthermore, it provides detailed reference documentation for API version 12 permissions, outlining specific authorization types, usage scopes, and hardware constraints. This resource is specifically designed for HarmonyOS developers and enterprise engineers who are building advanced applications requiring elevated privileges, such as USB debugging or system-level file management, and must adhere to strict security protocols to ensure successful publication and operation.
