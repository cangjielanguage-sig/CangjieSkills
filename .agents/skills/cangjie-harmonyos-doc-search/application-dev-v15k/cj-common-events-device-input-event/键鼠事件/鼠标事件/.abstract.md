This directory focuses on mouse interaction handling within the Cangjie UI framework (ArkUI). It covers essential APIs for managing mouse events, including hover states, click detection, and cursor tracking. Key topics include the `hoverEffect` function for visual feedback, the `onMouse` callback for detailed event data, and the integration of mouse inputs with touch gesture systems. This documentation is suitable for UI developers looking to implement desktop or mouse-based interactive features in Cangjie applications.
