## 详细描述

### 基于shell命令测试_4more_ce729872.md
本文档是一份技术参考指南，旨在介绍如何通过shell命令利用uitest工具进行快速测试，涵盖截屏、获取控件树、UI录制及模拟操作注入等功能。文档核心部分详细列出了screenCap、dumpLayout、uiRecord、uiInput等命令的参数配置与使用方法，并提供了具体的执行示例。关键信息包括文件存储路径限制、控件树过滤选项以及录制操作数据的JSON字段定义。使用本文档需预先配置hdc环境变量，适用于需要高效进行自动化测试和调试的开发场景。

### 注入UI模拟操作.md
本文档是一份API参考指南，旨在说明如何通过hdc shell uitest uiInput命令注入并模拟各种UI操作。文档详细列出了包括单击、双击、长按、快滑、慢滑、拖拽、指定方向滑动、文本输入及实体按键事件在内的多种命令。每个命令部分均提供了配置参数说明（如坐标点、滑动速度、方向值等）及具体的Shell命令执行示例。该文档主要面向开发人员和测试工程师，用于编写自动化测试脚本或进行设备交互调试。

### 获取版本信息_2more_4b88d787.md
本文档旨在指导用户获取UITest版本信息并拉起测试进程。主要内容包括执行版本查询命令和启动uitest守护进程的操作。关键信息强调设备需开启开发者模式，仅aa test命令拉起的进程具备调用UITest接口的能力，且测试HAP的APL等级必须为system_basic或normal。该技术参考文档面向进行自动化UI测试的开发人员，需具备HDC命令及权限管理的基础知识。
