# cj-universal-attribute-enable

本目录包含关于ArkUI框架中`enabled`通用属性的API参考文档，专为使用仓颉语言进行应用开发的开发者设计。文档详细阐述了如何利用该属性控制UI组件的交互状态，包括组件是否响应点击、触摸及焦点等关键事件。核心内容涵盖了模块导入方式、`enabled`函数的完整定义、参数类型及返回值说明。此外，文档还特别强调了属性更改的生效时机（仅在按下时生效），帮助开发者准确掌握组件可用性的控制逻辑，避免交互过程中的状态冲突。

## 详细描述

### cj-universal-attribute-enable.md cj-universal-attribute-enable.md
这是一份ArkUI框架的API参考文档，旨在说明如何通过`enabled`属性控制组件的交互状态。文档涵盖了导入模块、`enabled`函数的详细定义、参数类型及返回值。核心内容指出，该属性决定组件是否响应点击、触摸及焦点等事件，并特别强调属性更改仅在按下时生效，交互过程中修改无效。文档面向使用仓颉语言的开发者，提供了控制组件可用性的具体方法。
