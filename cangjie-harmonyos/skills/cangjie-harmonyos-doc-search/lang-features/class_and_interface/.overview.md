# class_and_interface

This directory serves as a central hub for object-oriented programming (OOP) concepts within the Cangjie language. It covers the fundamental building blocks of classes, interfaces, and properties, alongside advanced type system features like subtyping, polymorphism, and type casting. Key topics include class definitions, interface implementations, property encapsulation, subtype relationships (covariance/contravariance), and runtime type checking. This resource is suitable for Cangjie developers ranging from beginners learning OOP basics to advanced users looking to master type safety and polymorphism mechanisms.

## Detailed Description

### [1] class/
This directory serves as a comprehensive resource for understanding the object-oriented programming paradigm within the Cangjie language, with a specific focus on the "class" construct. It provides an in-depth look at the fundamental building blocks of OOP, detailing how classes are defined and used to structure code effectively.

### [2] interface/
This directory focuses on the interface system within the Cangjie programming language. It provides comprehensive documentation on core concepts and advanced features, starting from the fundamental `Any` type. The content covers interface declarations, implementation rules, and how interfaces facilitate abstraction and polymorphism.

### [3] prop/
The `prop` directory serves as a specialized repository for documentation concerning "properties" within the Cangjie programming language. As a fundamental aspect of object-oriented programming, properties facilitate data encapsulation and indirect access to object state, ensuring better control over how data is modified and retrieved.

### [4] subtype/
This directory collects core reference documentation regarding subtype relationships and polymorphism features in the Cangjie language. The content comprehensively covers the specific rules for establishing subtype relationships through class inheritance, interface implementation, tuple types, and function types. It focuses on an in-depth analysis of the contravariance of parameters and covariance of return values in function types, which is key to understanding advanced type systems. Additionally, the documentation details mathematical properties such as transitivity and reflexivity of subtypes, as well as the special relationships of basic types like Nothing and Any in the type hierarchy. This document is primarily suitable for Cangjie language developers with basic OOP knowledge, aiming to help them deeply understand type compatibility checks and polymorphism application scenarios to write safer and more flexible code.

### [5] typecast/
This directory serves as a comprehensive technical guide to type conversion and type checking mechanisms within the Cangjie programming language. It thoroughly documents the runtime type judgment and safe casting techniques, with a specific focus on ensuring type safety during dynamic operations.
