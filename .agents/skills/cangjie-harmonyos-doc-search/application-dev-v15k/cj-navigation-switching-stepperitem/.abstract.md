This directory contains the essential API reference documentation for the `StepperItem` component, a fundamental building block within the Cangjie ArkUI framework. Specifically designed to operate as a child page for the `Stepper` component, this resource is indispensable for developers aiming to construct sophisticated, step-based navigation flows in their applications. The documentation provides a deep dive into the component's initialization process and offers detailed guidance on customizing user interface elements, specifically navigation labels such as `nextLabel` and `prevLabel`. Furthermore, it elucidates the mechanisms for status control, which are vital for managing user interaction and accessibility. Key technical concepts covered include the `ItemState` enum, which defines various display states including Normal, Disabled, Waiting, and Skip. The guide also addresses specific layout constraints, noting that the component's width fills the parent container while height is automatically calculated. This documentation is strictly intended for developers who require precise syntax and parameter definitions to effectively implement and manage multi-step navigation controls within the Cangjie ecosystem. By following this guide, developers can ensure their navigation logic is robust and user-friendly.
