# extend_String_UnicodeStringExtension

This directory contains API reference documentation for extending the Cangjie `String` type to implement the `UnicodeStringExtension` interface. It comprehensively covers advanced character set operations, including Unicode-compliant casing conversions (toLower, toTitle, toUpper), whitespace validation (isBlank), and various string trimming methods (trim, trimStart, trimEnd). The documents detail function signatures, locale-specific handling via `CasingOption`, and error handling for invalid UTF-8 encoding. Additionally, it highlights deprecated functions and their modern replacements. This resource is suitable for Cangjie developers seeking to manipulate text casing, sanitize inputs, and ensure proper Unicode compliance in their applications.

## Detailed Description

### extend_String_UnicodeStrin_5more.md extend_String_UnicodeStrin_5more.md
This API reference document details the extension of the Cangjie String type to implement the UnicodeStringExtension interface, enabling advanced character set operations. It covers the extension declaration and specific member functions: isBlank, toLower, and toTitle. Key information includes that isBlank identifies empty or whitespace-only strings using specific Unicode code points, while toLower supports both default and language-specific casing options via CasingOption. The toTitle function handles title case conversion. All functions return String or Bool and may throw IllegalArgumentException for invalid UTF-8 encoding. This technical documentation targets Cangjie developers seeking to manipulate string casing and validate whitespace using Unicode standards.
