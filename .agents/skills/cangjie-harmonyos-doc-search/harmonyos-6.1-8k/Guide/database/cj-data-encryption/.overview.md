# cj-data-encryption

This directory serves as a comprehensive technical resource for the `cj-data-encryption` project, focusing on data security implementations within the ArkData framework using the Cangjie (仓颉) programming language. It addresses the critical requirements for securing persistent storage in modern application development, specifically targeting environments that utilize the HarmonyOS/OpenHarmony ecosystem. The documentation provides a deep dive into the mechanisms required to encrypt both relational and key-value databases, ensuring that sensitive data remains protected against unauthorized access. Key topics include the configuration of encryption attributes using `StoreConfig` and `KVOptions`, the management of security levels such as S3, and the practical implementation of these features through Cangjie code. By offering detailed examples on how to acquire the UIAbility context and invoke essential interfaces like `getRdbStore`, this guide empowers developers to build robust, secure applications. It is highly suitable for application developers and security engineers looking to enhance the confidentiality and integrity of their data storage layers.

## Detailed Description

### 数据库加密/

This directory collects technical documentation regarding database encryption within the ArkData framework. Its primary objective is to guide developers on how to ensure data security through the precise configuration of parameters.

**Scope and Coverage**
The content encompasses encryption implementations for two primary types of databases: relational databases and key-value databases. It highlights the technical methods required to secure these data structures effectively within the ArkData environment.

**Configuration and Management**
A significant portion of the documentation is dedicated to explaining how to utilize `StoreConfig` and `KVOptions` to set encryption attributes. It further details how to manage these settings in conjunction with specific security levels, such as S3, to maintain a high standard of data protection and compliance.

**Code Examples and Implementation**
The directory includes practical code examples based on the Cangjie language. These examples provide step-by-step instructions on obtaining the UIAbility context and calling relevant interfaces, such as `getRdbStore`, to implement the encryption logic in real-world scenarios.

**Target Audience**
This resource is specifically suitable for application developers who wish to improve the security and confidentiality of their application data storage.
