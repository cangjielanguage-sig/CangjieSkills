# 基础类型定义

This directory contains API reference documentation for fundamental data structures and controller classes used within the ArkUI framework for the Cangjie language. It covers definitions for managing graphical rendering surfaces, including display area dimensions, orientation locking, and component control. Key concepts include SurfaceRect, SurfaceRotationOptions, and XComponentController. These documents are essential for HarmonyOS developers who need low-level control over XComponent behavior, layout configurations, and system interactions involving native interfaces like camera management.

## Detailed Description

### class_SurfaceRect.md class_SurfaceRect.md
This API reference document defines the SurfaceRect class used to describe the display area of a Surface held by an XComponent within the ArkUI framework. It details the class structure, covering four public properties (offsetX, offsetY, surfaceWidth, surfaceHeight) and the constructor method. Key information includes that all properties are Float32 types representing pixel coordinates or dimensions relative to the XComponent. Notably, dimensions default to the component size if unspecified and must not exceed 8192px to prevent rendering anomalies. This documentation targets HarmonyOS developers using the Cangjie language to manage graphical rendering surfaces and layout configurations.

### class_SurfaceRotationOptions.md class_SurfaceRotationOptions.md
This API documentation defines the Cangjie class SurfaceRotationOptions, designed to manage orientation locking for an XComponent's Surface during screen rotation. The document details the class structure, focusing on the public property lock and the initializer method. Key information includes that the lock property is a Boolean value determining if the orientation is fixed, defaulting to false to allow rotation. The documentation specifies system capabilities and the starting API version 19. Intended for ArkUI developers, this reference helps configure display behavior for graphical components, ensuring proper handling of device orientation changes within the Cangjie development environment.

### class_XComponentController.md class_XComponentController.md
This document serves as API reference documentation for the XComponentController class in the Cangjie language, designed to control XComponent components. It details the class constructor and methods for managing Surface properties, specifically ID retrieval, display area manipulation, and rotation settings. Key information includes that methods like getXComponentSurfaceId facilitate integration with native interfaces such as camera management, while layout and rotation controls are restricted to SURFACE or TEXTURE types. The documentation notes specific behaviors for rotation locking during screen transitions. This reference is intended for ArkUI developers requiring low-level control over component surfaces and system interactions.
