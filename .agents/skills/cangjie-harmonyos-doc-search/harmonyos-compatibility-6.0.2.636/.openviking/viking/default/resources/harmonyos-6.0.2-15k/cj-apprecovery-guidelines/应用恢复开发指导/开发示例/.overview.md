# 开发示例

This directory provides a specialized collection of development examples and technical guides dedicated to enhancing application resilience and stability within the Cangjie language ecosystem. It focuses on critical mechanisms for enabling self-recovery features and implementing robust data saving and restoration processes to handle unexpected application behaviors. The content covers the integration of the AbilityKit framework, detailed configuration of `module.json5` manifest files, and the utilization of specific lifecycle methods such as `onCreate` and `onSaveState`. Developers will find instructions on calling `enableAppRecovery`, managing `Want` parameters, and handling restart markers like `ABILITY_RECOVERY_RESTART`. These resources are specifically designed for application developers familiar with Cangjie syntax and lifecycle management who need to ensure data persistence and seamless user experience restoration in their projects.

## Detailed Description

### 使能开启自恢复特性_2more.md 使能开启自恢复特性_2more.md

This technical guide instructs developers on how to implement the self-recovery feature for applications using the Cangjie language. It covers enabling the recovery mechanism in the AbilityStage initialization and configuring specific abilities in the module.json5 manifest file. The core steps involve calling the enableAppRecovery function with specific flags for restart and save modes within the onCreate method, and setting the recoverable attribute to true in the JSON configuration. This is intended for application developers familiar with Cangjie syntax and application lifecycle management who need to enhance app stability. Keywords: App recovery, Cangjie, AbilityStage, module.json5, enableAppRecovery, configuration.

### 数据保存和恢复/

This directory serves as a technical resource for implementing robust data saving and recovery mechanisms within the Cangjie application ecosystem. It specifically addresses the AbilityKit framework, providing developers with the knowledge to handle application state resilience during crashes or unexpected terminations. The documentation covers two primary approaches: active recovery using `appRecovery` features and `ErrorObserver` callbacks, and passive recovery via the `onSaveState` interface. Key concepts include managing `Want` parameters, identifying specific launch reasons such as `APP_RECOVERY`, and detecting restart markers like `ABILITY_RECOVERY_RESTART`. This guide is tailored for application developers who need to ensure data persistence and seamless user experience restoration in their Cangjie-based projects.
