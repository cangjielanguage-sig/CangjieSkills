This directory provides comprehensive API reference documentation for the `ohos.preferences` module within the HarmonyOS ArkData framework, specifically designed for the Cangjie language. It focuses on lightweight Key-Value data persistence, enabling efficient management of application settings and small datasets. The documentation covers module imports, configuration structures, supported data types, and the core `Preferences` class for data manipulation. It is suitable for HarmonyOS developers looking to implement local data storage, handle data change subscriptions, and manage persistent application contexts using Cangjie syntax.
