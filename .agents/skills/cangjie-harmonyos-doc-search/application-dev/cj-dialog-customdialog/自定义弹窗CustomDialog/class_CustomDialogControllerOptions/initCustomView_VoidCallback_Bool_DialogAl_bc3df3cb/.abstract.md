This directory contains comprehensive API reference documentation for initializing and configuring custom dialog views within the ArkUI framework, specifically designed for HarmonyOS development. It details the `initCustomView` function, providing developers with the necessary specifications to create `CustomDialogControllerOptions` objects. The content covers a wide range of configuration aspects, including content construction, layout positioning, visual styling, animation settings, and user interaction handling. It is suitable for software developers using the Cangjie language who require granular control over custom popups, enabling them to programmatically define complex UI behaviors and visual effects in their applications.
