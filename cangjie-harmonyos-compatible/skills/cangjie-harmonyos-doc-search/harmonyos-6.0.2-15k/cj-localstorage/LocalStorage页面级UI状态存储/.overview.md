# LocalStorage页面级UI状态存储

This directory provides comprehensive documentation and guides for implementing LocalStorage, a page-level UI state storage mechanism within the Cangjie framework. It covers the core concepts of using LocalStorage as an in-memory database for managing state across component trees. Key topics include the `@LocalStorageLink` and `@LocalStorageProp` decorators for data synchronization, lifecycle management, and specific usage constraints. The content is designed for developers working with HarmonyOS applications who need to handle reactive state management, complex data types, and state sharing between views and UIAbility instances.

## Detailed Description

### LocalStorageLink.md LocalStorageLink.md
This API documentation defines the @LocalStorageLink decorator, which facilitates two-way data synchronization between custom component state variables and LocalStorage. The document outlines macro usage rules, including required string keys, supported data types, and initialization protocols. It details variable transfer restrictions, prohibiting parent initialization while supporting child node initialization. Key sections explain observation behaviors for primitives, objects, and collections like Map and Set, noting that changes trigger both LocalStorage updates and component re-renders. Intended for developers managing application state, this guide ensures proper implementation of bidirectional local storage binding.

### LocalStorageProp.md LocalStorageProp.md
This API documentation explains the @LocalStorageProp macro, which establishes a one-way data synchronization between LocalStorage and custom component variables. It details macro usage rules, variable passing constraints, and observation behaviors for various data types including primitives, classes, and collections like Map and Set. Key takeaways include that the decorator binds variables via a key string, initializing from LocalStorage or a default value, and that LocalStorage changes overwrite local values to trigger component refreshes. Intended for developers building UI components, this guide requires understanding of basic state management concepts.

### LocalStorage页面级UI状态存储_2more.md LocalStorage页面级UI状态存储_2more.md
This document serves as a technical guide for implementing LocalStorage, a page-level UI state storage mechanism in the Cangjie framework. It covers the core concepts of LocalStorage as an in-memory database, its lifecycle management, and how it facilitates state sharing within and across pages via the @Entry decorator. Key takeaways include the distinction between the @LocalStorageProp macro for one-way synchronization and the @LocalStorageLink macro for two-way data binding. Intended for developers with prior knowledge of state management, this guide explains how to manage mutable state properties effectively within a component tree.

### 限制条件.md 限制条件.md
This document outlines the constraints and usage rules for LocalStorage and its associated decorators in the Cangjie framework. It covers parameter type requirements for decorators, unsupported variable types, immutability of property types after creation, and the scope of LocalStorage as page-level storage. Key takeaways include that @LocalStorageProp and @LocalStorageLink require string parameters, cannot decorate functions, and that property types are fixed upon creation. This reference guide targets developers using the Cangjie framework for UI development, specifically those managing state with LocalStorage.
