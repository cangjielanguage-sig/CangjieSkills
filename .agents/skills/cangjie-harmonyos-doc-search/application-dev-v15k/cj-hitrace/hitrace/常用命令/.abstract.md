This directory serves as a comprehensive resource for the `hitrace` command-line tool within the HarmonyOS development environment. It focuses on system performance tracing, offering guidance on capturing, managing, and analyzing trace data via the hdc shell. The documentation covers a wide range of functionalities, from basic command syntax and tag configuration to advanced data management techniques like snapshot mode and compression. Core keywords include system performance, trace recording, buffer configuration, and debugging. These guides are specifically tailored for software developers, QA engineers, and system performance analysts who require precise tools for monitoring application behavior, diagnosing system issues, and optimizing performance using visualization tools like HiSmartPerf.
