### class_RunningLock.md class_RunningLock.md
This API reference document details the RunningLock class, designed to prevent system sleep in the Cangjie programming environment. It covers system capabilities and three primary methods: hold for acquiring the lock with a specific timeout, isHolding for checking status, and unhold for releasing the lock. Key information includes timeout parameter definitions where -1 indicates permanent locking, alongside specific error codes for service failures or permission denial. The documentation targets application developers using the BasicServicesKit who need to manage power states and keep the device awake during critical tasks.
