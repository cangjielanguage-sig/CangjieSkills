# class_Path2D

This directory contains API reference documentation for the Cangjie Path2D class within the ArkUI framework. It covers the creation, manipulation, and rendering of 2D vector paths, including constructors, SVG parsing, and various drawing methods like arcs, Bezier curves, and lines. The documentation details functions for transforming paths and configuring length metrics. It is suitable for developers building graphical user interfaces on HarmonyOS who require precise control over custom 2D vector graphics and rendering capabilities using the Cangjie language.
