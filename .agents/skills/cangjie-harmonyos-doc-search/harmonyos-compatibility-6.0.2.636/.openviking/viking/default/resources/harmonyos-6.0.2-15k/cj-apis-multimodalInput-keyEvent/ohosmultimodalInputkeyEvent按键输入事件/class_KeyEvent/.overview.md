# class_KeyEvent

This directory provides comprehensive API reference documentation for the `KeyEvent` class in the Cangjie language, specifically designed to model keyboard input events. It covers essential components such as class definitions, constructors, and a wide array of properties including key actions, specific key codes, unicode characters, and modifier states like ctrlKey, altKey, and shiftKey. The documentation highlights the class inheritance from InputEvent and outlines system capability requirements. Suitable for software developers, this guide assists in implementing robust multimodal input handling for applications requiring detailed keyboard event tracking.
