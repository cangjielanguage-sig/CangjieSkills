This directory contains comprehensive documentation and resources for the `ListItemGroup` component within the Cangjie ArkUI framework. It covers the API reference for grouping list items, practical code examples for advanced layouts like sticky headers and card styles, and fundamental type definitions for configuration. Key topics include component constraints, styling parameters, and visual presentation control. This content is suitable for Cangjie developers looking to construct complex list layouts and enhance UI aesthetics in HarmonyOS applications.
