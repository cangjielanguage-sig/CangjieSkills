This directory hosts the overview documentation for the Performance Analysis Kit, a comprehensive service suite designed to empower developers with advanced tools for event, log, and trace analysis. It focuses on monitoring application runtime states to significantly improve user experience. The content covers critical usage scenarios such as debugging, online monitoring, and APM system construction. Key components detailed include HiLog, HiTraceMeter, HiAppEvent, FaultLogger, and HiDebug. Additionally, it addresses fault analysis for crashes and freezes, exception handling, and custom APM SDK development. This resource is ideal for developers aiming to debug applications, locate faults, and ensure online performance stability, assuming prior knowledge of programming and operating systems.
