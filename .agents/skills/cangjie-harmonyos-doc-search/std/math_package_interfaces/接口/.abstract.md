This directory contains API reference documentation for core numeric interfaces in the Cangjie programming language. It covers fundamental abstractions for generic programming, including the base `Number` interface, specific `Integer` and `FloatingPoint` implementations, and utility interfaces like `MaxMinValue`. The content details operator overloading, mathematical constants, type properties, and boundary checks for various numeric types (Int8 to Float64). It also includes documentation for deprecated legacy interfaces. This resource is suitable for Cangjie developers, language implementers, and software engineers seeking to understand type hierarchies, implement custom numeric types, or perform precise numerical computations using standardized interfaces.
