# 应用组件级配置

This directory focuses on the configuration of application components and metadata within HarmonyOS and Cangjie development environments. It covers essential setup tasks such as defining application identities (bundle names), managing version information, and configuring visual elements like icons and labels. Key topics include `app.json5` and `module.json5` file settings, permission declarations, and device compatibility. This documentation is suitable for developers using DevEco Studio or working with Cangjie projects who need to establish the foundational attributes and capabilities of their applications.

## Detailed Description

### 图标和标签配置.md
This technical guide details the configuration and display logic for application icons and labels within HarmonyOS development. It covers the mandatory app.json5 and optional module.json5 settings, explaining the priority mechanism where system icons default to the app-level configuration unless specific UIAbility skills are defined. Key sections include generation logic, usage scenarios like desktop display, configuration examples, and security rules preventing icon hiding for non-pre-installed apps. The document targets developers using DevEco Studio to manage application identity and visibility, emphasizing the relationship between configuration files and system behavior.

### 应用版本声明配置_3more.md
This document serves as a configuration guide for defining application metadata and module capabilities in HarmonyOS development. It details three primary configuration areas: application version declaration, module-supported device types, and module permission settings. Key information includes using versionCode and versionName in the app.json5 file for version control, and configuring deviceTypes and requestPermissions within module.json5 to specify supported hardware and declare necessary system access rights, respectively. Intended for developers, this reference ensures proper setup of application manifests to manage versioning, device compatibility, and security permissions.

### 应用组件级配置_2more.md
This document serves as a configuration guide for developers setting up application-level attributes in Cangjie projects. It covers the application package name configuration, specifically focusing on the bundleName tag. Key information includes the requirement to configure the bundleName within the app.json5 file located in the AppScope directory to ensure application uniqueness. The document recommends using a reverse domain naming convention, such as com.example.demo, for standardization. This guide is intended for Cangjie application developers who need to define fundamental identity properties like package names and icons during the initial project setup.
