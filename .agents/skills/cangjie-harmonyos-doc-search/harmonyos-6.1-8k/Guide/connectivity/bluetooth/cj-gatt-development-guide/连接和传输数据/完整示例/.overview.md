# 完整示例

This directory serves as a comprehensive repository for complete examples and documentation regarding Bluetooth Low Energy (BLE) development within the HarmonyOS ecosystem. It encompasses the full spectrum of GATT (Generic Attribute Profile) implementation, covering both Client and Server roles. The examples are primarily written in Cangjie and ArkTS, demonstrating essential workflows such as connection establishment, service discovery, data transmission via characteristics, and notification management. This resource is tailored for developers looking to implement robust Bluetooth communication in their applications, providing structural skeletons and practical guides for creating central or peripheral devices.

## Quick Navigation

- **What do you want to do?**
    - Implement a device that scans for, connects to, and interacts with other BLE devices → Go to [1] 客户端
    - Implement a device that advertises services, handles requests, and acts as a BLE peripheral → Go to [2] 服务端

## Detailed Description

### [1] 客户端
This directory is dedicated to the development of the Bluetooth Low Energy (BLE) GATT Client. It provides a comprehensive set of documentation and code examples that guide developers through the entire lifecycle of a client-side connection. Key topics covered include initiating and establishing connections with remote BLE devices, performing service discovery to identify available capabilities, and executing read and write operations on characteristics and descriptors. Furthermore, it details the management of notifications and indications to receive data updates asynchronously, as well as the proper procedures for disconnecting and cleaning up resources. The content leverages the Cangjie language and HarmonyOS APIs, making it an essential resource for developers aiming to enable their applications to scan for, connect to, and interact with various Bluetooth peripherals effectively.

### [2] 服务端
This directory aggregates core documentation and code examples focused on the Bluetooth Low Energy (BLE) GATT Server. It is designed for developers building peripheral devices or services that need to broadcast data and respond to client requests. The content covers the complete server-side workflow, starting with server initialization and the setup of advertising to be discoverable by clients. It provides in-depth explanations on handling read and write requests for characteristics and descriptors, managing connection states to ensure stability, and implementing data notification mechanisms to push updates to connected clients. Additionally, it covers the service deregistration process. The examples are written using Cangjie and ArkTS, offering detailed insights into constructing a `GattServerManager`, encapsulating callback logic for event handling, and configuring standard GATT profiles. This section is highly suitable for HarmonyOS developers focusing on peripheral logic and server-side business implementation.
