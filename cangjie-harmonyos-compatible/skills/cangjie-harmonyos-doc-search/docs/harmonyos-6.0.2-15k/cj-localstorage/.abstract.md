This directory serves as a comprehensive resource for `cj-localstorage`, a specialized page-level UI state storage solution built for the Cangjie framework. It is designed to assist developers in utilizing LocalStorage as an efficient in-memory database to manage and synchronize state across complex component trees. The documentation covers essential concepts such as reactive state management, the application of `@LocalStorageLink` and `@LocalStorageProp` decorators, and the handling of complex data types. It is particularly suitable for HarmonyOS application developers seeking to implement robust state sharing between views and UIAbility instances while adhering to specific lifecycle constraints and usage best practices. By leveraging these tools, developers can ensure that their applications maintain consistent UI states and respond dynamically to user interactions, ultimately improving the user experience and application reliability. This guide is essential for anyone looking to master state persistence and data flow within the Cangjie ecosystem, providing the necessary theoretical background and practical implementation details to build responsive, high-performance applications.
