### 示例代码.md 示例代码
本文档提供了仓颉语言编写的示例代码，演示了在鸿蒙ArkUI开发中如何使用RichEditor富文本编辑器组件。代码涵盖了RichEditorController的使用方法，包括光标位置控制、文本与图片Span的添加、段落样式更新，以及自定义键盘和选择菜单的配置。关键要点展示了如何通过控制器方法操作编辑器内容，利用Builder构建自定义UI，并处理编辑器的生命周期及选择事件。该文档面向熟悉仓颉语法和ArkUI声明式UI结构的鸿蒙应用开发者，旨在提供RichEditor组件的集成参考。

### 组件属性.md 组件属性
本文档是ArkUI框架的API参考文档，主要定义了组件的交互属性，包括自定义选择菜单、复制粘贴能力及自定义键盘。核心内容涵盖`bindSelectionMenu`、`copyOptions`和`customKeyboard`三个函数，详细说明了其参数配置、默认值及行为逻辑。关键点在于利用`CustomBuilder`实现UI定制，以及自定义键盘的覆盖显示机制。文档适用于使用仓颉语言的开发者，旨在帮助其实现高度定制的文本编辑与输入体验。

### 基础类型定义/
本目录汇集了ArkUI框架下Cangjie（仓颉）语言的基础类型定义，专注于富文本编辑器（RichEditor）的核心组件与数据结构。内容涵盖了文本样式、图像跨度、段落布局、选择范围、光标控制及编辑操作等关键类与接口。这些API旨在帮助开发者实现精细的UI交互与内容管理。适用于使用ArkUI框架和Cangjie语言进行应用开发的工程师，特别是需要构建复杂富文本编辑功能的用户。
