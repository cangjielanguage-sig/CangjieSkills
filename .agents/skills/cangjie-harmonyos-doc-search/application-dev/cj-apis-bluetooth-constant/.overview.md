# cj-apis-bluetooth-constant

This directory serves as a comprehensive resource for API reference documentation regarding the Cangjie language's Bluetooth constant module within the HarmonyOS development environment. It is specifically designed to assist developers in understanding and implementing enumeration values that dictate device connection states. The documentation centers on the `ProfileConnectionState` enum, which is pivotal for tracking the lifecycle of Bluetooth connections, including states such as `StateDisconnected`, `StateConnecting`, `StateConnected`, and `StateDisconnecting`. Beyond the enumerations, it provides insights into associated methods like equality operators and `toString` that facilitate state management and debugging. The content highlights the module's current Beta status, specifies the necessity of importing `ConnectivityKit`, and outlines system capability requirements. This directory is highly suitable for Cangjie developers and system architects building connectivity applications who need to ensure robust handling of Bluetooth profile connections and state transitions in their applications.

## Detailed Description

### cj-apis-bluetooth-constant.md
This document provides API reference documentation for the Cangjie language's Bluetooth constant module, specifically defining enumeration values for device connection states.

The primary focus is the `ProfileConnectionState` enum, which is essential for tracking connection lifecycles. It includes states such as `StateDisconnected`, `StateConnecting`, `StateConnected`, and `StateDisconnecting`.

**Methods and Utilities:**
It also details associated methods like equality operators and `toString` for state management, allowing developers to effectively compare and log connection states.
