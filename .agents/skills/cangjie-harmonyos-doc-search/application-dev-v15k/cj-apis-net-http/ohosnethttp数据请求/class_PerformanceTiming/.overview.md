# class_PerformanceTiming

This directory provides comprehensive documentation for the `PerformanceTiming` class, a critical component within the NetworkKit framework designed for high-precision network performance monitoring. It serves as a complete guide for capturing and analyzing granular timing metrics related to HTTP requests. The documentation covers essential performance indicators, such as DNS resolution latency, TCP connection establishment time, TLS negotiation duration, redirect delays, and server response processing speeds. All metrics are provided as Float64 values in milliseconds, calculated from the moment the initial request is initiated. This resource is specifically tailored for developers and system engineers working with the SystemCapability.Communication.NetStack capability, available from API version 12 onwards. It is an indispensable tool for those seeking to diagnose network inefficiencies, identify bottlenecks, and significantly optimize the latency and responsiveness of their network-dependent applications.

### class_PerformanceTiming_12more.md class_PerformanceTiming_12more.md
This document serves as the official API reference documentation for the PerformanceTiming class, which is engineered to capture detailed network performance metrics in milliseconds. It offers a thorough breakdown of the class's read-only properties, each designed to measure a distinct stage of the HTTP request lifecycle. These stages include DNS resolution, TCP and TLS connection times, the duration of redirects, and various aspects of response processing. In addition to the metrics, the documentation explains the `toString` method, facilitating the conversion of the performance object into a human-readable string representation. A critical technical detail provided is that all metrics are Float64 values, calculated from the initial request call. The class is part of the SystemCapability.Communication.NetStack capability, starting from version 12. This guide is intended for developers utilizing the NetworkKit to perform deep analysis and optimization of network request latency.
