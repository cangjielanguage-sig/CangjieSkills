This directory provides a comprehensive technical overview of the implicit Want matching mechanism used in system application component routing. It covers the core logic for resolving intents based on parameters such as action, entities, URI, type, and linkFeature. The documents detail specific matching rules, priority handling, and configuration requirements within `module.json5`. Key topics include URI expression types, wildcard handling, and the interaction between caller parameters and target skills. This resource is suitable for system developers and application engineers looking to implement or debug cross-component invocation and intent filtering.
