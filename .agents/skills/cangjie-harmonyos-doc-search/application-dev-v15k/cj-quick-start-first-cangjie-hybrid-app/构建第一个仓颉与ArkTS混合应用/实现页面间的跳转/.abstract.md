This directory provides a comprehensive technical overview of implementing page navigation within HarmonyOS applications that utilize a hybrid architecture combining ArkTS and Cangjie. It addresses the specific challenges developers face when routing between these two distinct language environments, which do not share a direct router connection. The documentation covers critical scenarios including standard forward navigation using the native router module and the complex interoperability required for backward navigation. Key topics include the utilization of `router.pushUrl`, the application of Cangjie-ArkTS interop macros for function registration, and the management of cross-language callbacks. This guide is specifically tailored for developers working on mixed-language applications who need to bridge routing capabilities and ensure seamless user flow between ArkTS and Cangjie components.
