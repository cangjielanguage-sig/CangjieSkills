# 基础类型定义

本目录包含Cangjie语言中用于ArkUI应用开发的基础类型定义文档，主要涵盖了侧边栏控制按钮的图标配置、样式布局以及分割线样式的定义。这些API参考文档详细说明了类的属性、构造函数及参数，旨在帮助开发者自定义侧边栏的交互按钮外观和分割线效果。核心关键词包括ButtonIconOptions、ButtonStyle、DividerStyle、侧边栏、图标配置及样式定制。该文档适用于使用Cangjie和ArkUI框架进行HarmonyOS应用开发的开发者，提供了精细化的UI定制能力。

## 详细描述

### class_ButtonIconOptions.md class_ButtonIconOptions.md
本文档是Cangjie语言中ButtonIconOptions类的API参考文档，用于定义侧边栏控制按钮在不同状态下的图标配置。主要内容包括类的属性定义（shown、hidden、switching）及其类型说明，以及构造函数的参数详解。关键信息在于该类通过三个可空ResourceStr类型的属性分别管理侧边栏显示、隐藏及切换状态时的按钮图标，其中switching参数在构造时可选。面向使用Cangjie开发ArkUI应用的开发者，适用于需要自定义侧边栏交互按钮图标的场景。

### class_ButtonStyle.md class_ButtonStyle.md
这是一份Cangjie语言的API参考文档，详细定义了用于配置侧边栏控制按钮样式的ButtonStyle类。文档涵盖了位置、尺寸及图标等核心属性，包括left、top、width、height和icons，并说明了各属性的读写能力、单位及默认值。此外，还提供了构造函数的参数详情。该文档面向ArkUI应用开发者，旨在帮助其通过精确设置按钮参数来实现自定义的界面布局和交互效果。

### class_DividerStyle.md class_DividerStyle.md
本文档是Cangjie语言中DividerStyle类的API参考文档，主要用于定义SideBar组件中分割线的样式。文档详细列出了类的属性，包括分割线的线宽、颜色以及起始和结束边距，并提供了构造函数的具体参数说明及默认值。关键信息指出，分割线默认占满SideBarContainer的剩余空间，且各属性均为可读写类型。该文档面向使用ArkUI框架进行HarmonyOS应用开发的开发者，旨在帮助其自定义侧边栏分割线的外观。
