# cj-persiststorage

This directory focuses on the `PersistentStorage` component within the Cangjie (cj) development ecosystem. It is designed to address the need for persisting UI state by storing selected attributes from `AppStorage`, ensuring that critical application data survives app restarts. The documentation covers the core mechanisms of bidirectional synchronization, supported data types, and specific constraints. It also provides performance optimization strategies and practical code examples. This resource is ideal for ArkUI developers and software engineers working on Cangjie applications who require a robust solution for state management and lifecycle preservation.

## Detailed Description

### PersistentStorage持久化存储UI状态/

This subdirectory serves as a detailed technical guide for the `PersistentStorage` component. It begins by explaining the fundamental purpose of the component: to enable the persistent storage of specific properties managed by `AppStorage`. By doing so, it ensures that the UI state is not lost when the application terminates and restarts, which is a crucial requirement for modern mobile applications.

A significant portion of the content is dedicated to the bidirectional synchronization mechanism. It explains how data flows between the runtime `AppStorage` and the persistent storage layer, ensuring consistency. The guide lists the supported data types that developers can safely persist, which is vital for avoiding runtime errors. It also highlights specific constraints and limitations that must be adhered to during implementation.

To assist in building high-performance applications, the documentation includes recommendations for performance optimization. It advises on how to minimize the overhead associated with disk I/O operations during state persistence. Furthermore, the guide discusses the lifecycle of the stored data, explaining when data is written to disk and when it is loaded back into memory. Additionally, the subdirectory provides concrete usage scenarios and code examples specifically written for Cangjie applications. These examples demonstrate how to effectively implement the component in real-world projects. This guide is highly recommended for ArkUI developers who need to deepen their understanding of state synchronization and lifecycle management to create resilient user interfaces.
