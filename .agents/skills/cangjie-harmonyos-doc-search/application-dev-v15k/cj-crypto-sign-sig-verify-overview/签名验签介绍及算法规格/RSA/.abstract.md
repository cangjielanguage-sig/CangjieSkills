This directory contains technical documentation for implementing RSA cryptographic operations, specifically focusing on signing, verification, and parameter configuration within an algorithm library framework. It covers various padding schemes like PKCS1 and PSS, signature recovery modes, and specific parameter settings such as salt lengths and digest algorithms. The documentation addresses compatibility across different RSA key sizes (512 to 8192 bits) and API versions. It is intended for developers, security engineers, and cryptographers integrating asymmetric encryption functions who require detailed specifications for configuration and implementation.
