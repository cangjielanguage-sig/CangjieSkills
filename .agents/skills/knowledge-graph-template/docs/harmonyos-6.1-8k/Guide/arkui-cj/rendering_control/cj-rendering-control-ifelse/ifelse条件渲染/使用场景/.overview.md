## 详细描述

### if_else_语句和子组件状态.md
本文档旨在阐述在ArkUI中使用Cangjie语言时，if...else条件渲染对子组件状态的影响及解决方案。文档主要包含两个代码示例，对比了子组件内部状态管理与父子组件状态同步的差异。关键信息指出，if分支切换会销毁并重建子组件实例，导致其内部@State变量重置；为保留状态，需将状态提升至父组件并通过@Link装饰器引用。该指南适合需要掌握ArkUI状态管理及条件渲染逻辑的开发者参考。

### 使用if进行条件渲染_903772d5.md
本文档旨在介绍在ArkUI框架中使用仓颉语言进行条件渲染的方法，特别是通过if语句控制组件的显示与隐藏。主要内容包括一个包含状态变量count的代码示例，以及关于if语句分支构建函数执行逻辑和状态变量变化时组件更新机制的详细说明。核心要点在于：当状态变量变化导致条件评估结果改变时，ArkUI框架会销毁旧分支的组件并执行新分支的构建函数来添加新组件，从而实现动态更新。这是一份面向使用仓颉语言开发ArkUI应用的开发者的教程文档，要求读者具备基本的组件构建和状态管理知识。
