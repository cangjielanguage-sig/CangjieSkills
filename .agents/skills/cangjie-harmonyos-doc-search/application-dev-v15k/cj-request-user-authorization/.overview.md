# cj-request-user-authorization

This directory serves as an essential technical resource for HarmonyOS application developers utilizing the Cangjie language. It comprehensively addresses the implementation of runtime user authorization, which is vital for applications requiring access to sensitive system data or hardware, such as geolocation or camera feeds. The content focuses on the `user_grant` permission model, providing detailed instructions on triggering dynamic authorization dialogs, validating permissions through `checkAccessToken()`, and gracefully handling user refusals by navigating to system Settings. Furthermore, it outlines critical UI constraints, including the prohibition of obscuring system dialogs and specific timing rules for content loading. This guide is ideal for developers aiming to balance robust functionality with strict privacy compliance and a seamless user experience.

## Detailed Description

### 向用户申请授权/
This directory serves as a comprehensive technical resource for implementing runtime user authorization for sensitive system permissions within HarmonyOS applications. It covers the `user_grant` permission model in depth, detailing how to trigger dynamic dialogs, verify authorization results using `checkAccessToken()`, and handle user denials by guiding users to system Settings. The content addresses specific constraints, such as the prohibition of obscuring system dialogs and the critical timing rules regarding UI content loading. It is suitable for application developers integrating privacy-sensitive features such as location or camera access using the Cangjie language, offering both theoretical guidelines and practical implementation steps to ensure compliance and user privacy. By following these guidelines, developers can ensure their applications adhere to privacy standards while providing a seamless user experience.
