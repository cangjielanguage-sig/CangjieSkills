# class_Cipher

This directory contains comprehensive API documentation for the Cangjie `Cipher` class, a core component of the CryptoArchitectureKit designed to facilitate secure data processing. It covers the implementation of both symmetric and asymmetric cryptographic operations, including encryption and decryption. The documentation details the complete workflow involving initialization, segmented data updates, and finalization, while addressing specific algorithm behaviors for RSA, SM2, GCM, and CCM. It is intended for software developers and security engineers building secure applications in the Cangjie programming language who need to manage keys, algorithm modes, and parameter specifications effectively.

## Detailed Description

### class_Cipher_3more.md class_Cipher_3more.md
This document provides API reference documentation for the Cangjie Cipher class, which facilitates symmetric and asymmetric encryption and decryption operations. Key sections include the class overview, the read-only algName property, and the initialize method definition with parameters and exceptions. The documentation highlights a three-step workflow involving initialize, optional update, and mandatory doFinal calls, distinguishing specific behaviors for symmetric versus asymmetric algorithms like RSA and SM2. It is intended for developers implementing cryptographic security, requiring an understanding of keys, algorithm modes, and parameter specifications.

### func_doFinalDataBlob.md func_doFinalDataBlob.md
This API documentation details the doFinal function used to finalize encryption or decryption operations within the Cangjie CryptoArchitectureKit. It covers functionality for both symmetric and asymmetric algorithms, specific handling for GCM and CCM authentication tags, parameter definitions, return values, and potential exceptions. Key takeaways include that the function processes remaining data to end the cryptographic operation, automatically clearing the Cipher instance state, requiring re-initialization for subsequent use. For GCM and CCM modes, the output includes ciphertext plus an authTag. This reference guide targets software developers implementing cryptographic security features in Cangjie applications.

### func_updateDataBlob.md func_updateDataBlob.md
This API reference document details the update function for performing segmented encryption or decryption operations within the Cipher class. It covers the function signature, prerequisites, behavioral explanations for symmetric algorithms including buffering and padding, usage restrictions for specific algorithms like RSA and CCM, and error handling. Key takeaways include the requirement to initialize the Cipher first and the understanding that output depends on block modes, potentially buffering data until a full block is formed. The document targets Cangjie developers using the CryptoArchitectureKit who need to process large data volumes or implement streaming cryptographic operations.
