This directory serves as a comprehensive technical resource for HarmonyOS developers, particularly those working with the Cangjie language, who need to debug web components within their applications. It provides a structured workflow for enabling and utilizing Chrome DevTools to inspect web pages running in the ArkWeb environment. The content covers the entire setup process, beginning with the programmatic enabling of the debugging switch and the declaration of required system permissions. It further details the necessary hardware configurations, such as enabling USB debugging, and the network setup required to bridge the device with the development machine. Key technical elements include the use of `WebviewController.setWebDebuggingAccess`, `hdc` command-line tools, and domain socket forwarding. By following these guides, developers can establish a reliable connection for real-time debugging and performance analysis. This documentation is essential for any developer aiming to troubleshoot or optimize web-based functionalities in HarmonyOS apps.
