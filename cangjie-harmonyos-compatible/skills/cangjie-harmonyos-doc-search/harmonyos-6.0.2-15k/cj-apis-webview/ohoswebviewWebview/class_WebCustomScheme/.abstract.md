This directory contains comprehensive API reference documentation for the `WebCustomScheme` class within the Cangjie WebView environment. It focuses on the configuration, initialization, and management of custom URL protocols, enabling developers to define specific network behaviors for web views. Key topics include setting protocol names with strict validation rules, managing security properties such as Content Security Policy (CSP) bypassing, and handling Cross-Origin Resource Sharing (CORS) and fetch API support. The documentation details the class constructor, readable and writable properties like `isSecure` and `isLocal`, and system capability requirements. This resource is intended for Cangjie developers who need to integrate custom network protocols and enforce specific security rules in their web applications, ensuring robust and compliant web view implementations.
