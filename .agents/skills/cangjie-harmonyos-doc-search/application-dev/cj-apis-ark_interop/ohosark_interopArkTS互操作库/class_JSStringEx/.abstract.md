This directory provides comprehensive technical documentation for the `JSStringEx` class, a specialized component within the Cangjie programming language designed to significantly extend standard JSString functionality and performance. It focuses on the implementation of declarative interop macros, facilitating seamless and efficient interaction between Cangjie and ArkTS environments. The content covers essential aspects such as class definitions, constructor initialization from String types, and static or instance methods for type conversion, including `fromJSValue`, `toJSValue`, and `toString`. Additionally, it addresses error handling for `BusinessException` regarding thread mismatches and data type incompatibilities, noting which APIs are intended for framework use. This documentation is primarily intended for developers and engineers working on ArkTS interoperability who need efficient, high-performance string handling, type conversion mechanisms, and precise comparison operators in their software projects.
