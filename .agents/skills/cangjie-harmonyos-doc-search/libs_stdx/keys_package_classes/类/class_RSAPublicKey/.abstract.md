This directory provides comprehensive API reference documentation for the `RSAPublicKey` class in the Cangjie programming language. It covers the essential functionalities required for RSA public key operations, including key initialization from private keys, static methods for decoding keys from DER and PEM formats, and instance methods for encoding keys back to these formats. Additionally, it details data encryption capabilities and digital signature verification. Key technical aspects include support for PKCS1, OAEP, and PSS padding modes, with specific recommendations for high-security scenarios. This documentation is designed for software developers and security engineers implementing cryptographic features, offering guidance on exception handling (CryptoException) and secure data practices.
