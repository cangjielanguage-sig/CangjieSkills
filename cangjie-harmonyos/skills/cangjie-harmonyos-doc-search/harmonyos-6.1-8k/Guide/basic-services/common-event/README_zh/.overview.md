# README_zh

本目录是进程线程通信模块的中文导航中心，旨在帮助开发者利用公共事件机制实现高效的进程间通信（IPC）。文档内容全面覆盖了公共事件的基础知识、动态订阅流程、取消订阅机制以及事件发布方法等核心主题。鉴于所有列出的功能目前均为Beta特性，本指南对于希望尝试新特性或进行跨进程交互开发的工程师尤为重要。它不仅提供了清晰的功能索引，还通过详细链接引导开发者完成从订阅到发布的完整开发闭环，是构建解耦、高效跨进程应用的重要参考资料。

## 快速导航

请根据你的开发需求选择以下路径：

*   **概念理解**：想要了解公共事件是什么及其在IPC中的作用 → README_zh.md
*   **建立连接**：想要学习如何动态订阅特定的公共事件 → README_zh.md
*   **断开连接**：想要了解如何安全地取消订阅公共事件 → README_zh.md
*   **触发通信**：想要学习如何发布公共事件以通知其他进程 → README_zh.md
*   **开发指引**：需要查看从订阅到发布的完整流程与详细链接 → README_zh.md

## 详细描述

### README_zh.md

本文档作为进程线程通信模块的导航索引，主要介绍了如何利用公共事件实现进程间通信。主要涵盖公共事件简介、动态订阅、取消订阅以及发布公共事件等核心主题。所有列出的功能目前均为Beta特性，文档提供了从订阅到发布完整流程的详细链接。面向需要进行跨进程交互的开发者，帮助其快速定位相关开发指南。
