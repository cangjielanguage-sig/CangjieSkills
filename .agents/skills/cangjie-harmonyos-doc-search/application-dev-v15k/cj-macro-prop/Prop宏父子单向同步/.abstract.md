This directory provides comprehensive technical documentation on the @Prop decorator within the Cangjie ArkUI framework, focusing on one-way data synchronization between parent and child components. It covers core concepts such as variable initialization, access rules, type constraints, and synchronization mechanisms. The content explains how @Prop variables are mutable locally but overwritten by parent updates, ensuring unidirectional state flow. It also details complex scenarios involving nested objects and arrays using @Observed. Suitable for developers building HarmonyOS applications who need to master state management, data binding, and reactive programming patterns to optimize component performance and architecture.
