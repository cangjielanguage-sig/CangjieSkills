This directory contains API documentation for the `ohos.displaySync` module within the HarmonyOS ArkUI framework, specifically designed for the Cangjie programming language. It focuses on variable frame rate control, enabling developers to synchronize custom UI rendering logic with the display's refresh cycle. Key components include the `DisplaySync` class, `IntervalInfo` class, and `OnOffType` enum, which facilitate precise management of frame drawing timestamps and callback events. This documentation is suitable for HarmonyOS developers and software engineers aiming to optimize application performance and implement self-drawn UI tasks with specific performance demands.
