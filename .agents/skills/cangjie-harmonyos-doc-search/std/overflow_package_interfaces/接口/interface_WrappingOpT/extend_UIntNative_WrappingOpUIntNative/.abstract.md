This directory provides comprehensive API documentation for the `WrappingOp` interface implementation specifically tailored for the `UIntNative` type within the Cangjie programming language. It details a suite of arithmetic and bitwise functions designed to manage integer overflow through a high-bit truncation strategy, ensuring that results wrap around predictably instead of triggering runtime errors. The documentation covers essential operations such as addition, multiplication, division, modulo, and bit shifting. This resource is ideal for Cangjie developers who require precise, low-level control over integer behavior and need to ensure consistent overflow handling in performance-critical or systems-level applications.
