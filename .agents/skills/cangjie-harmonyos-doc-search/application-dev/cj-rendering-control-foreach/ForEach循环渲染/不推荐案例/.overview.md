# 不推荐案例

This directory serves as a repository of anti-patterns and technical warnings specifically designed for ArkUI developers working with the Cangjie language. It focuses on common mistakes made when implementing the `ForEach` component, particularly regarding the `keyGenerator` parameter. The content covers critical issues such as unexpected rendering results caused by incorrect key usage and performance degradation resulting from omitted key generation rules. By analyzing these negative cases, developers can gain a deeper understanding of component lifecycle, state management, and rendering efficiency. This resource is essential for any developer looking to write robust, high-performance ArkUI code and avoid subtle functional bugs.

## Detailed Description

### 不推荐案例_2more.md
This document serves as a technical warning guide for ArkUI developers, illustrating the negative consequences of incorrectly using the index as a key generator within the ForEach component. It covers the specific scenario of "Unexpected Rendering Results," providing a Cangjie code example and a detailed breakdown of how key generation affects component reuse. The key takeaway is that using the index in the key generation rule causes the framework to reuse existing component states incorrectly during data insertion, resulting in duplicate or wrong UI elements; developers must avoid using index for keys. The target audience is ArkUI developers using the Cangjie language who need to understand rendering logic and state management to prevent functional bugs.

### 渲染性能降低.md
This document illustrates a performance degradation issue in ArkUI rendering caused by omitting the keyGenerator parameter in the ForEach component. It covers the default key generation mechanism, the lifecycle method aboutToAppear, and the impact of data insertion on component recreation. The example demonstrates that without a specific key generator, inserting an item shifts indices, forcing the framework to recreate all subsequent components unnecessarily. The solution is to define a keyGenerator using the item's unique value to ensure component reuse and efficiency. This guide is intended for ArkUI developers using Cangjie who need to optimize list rendering performance. Keywords: ArkUI, ForEach, keyGenerator, performance optimization, component lifecycle, Cangjie.
