This directory contains the essential API reference documentation for the `OverflowStrategy` enum, a fundamental component within the Cangjie math package. It is dedicated to defining robust mechanisms for handling numeric overflows that occur during type conversions, particularly when transitioning between high-precision types like BigInt or Decimal and standard integer types. The documentation provides a deep dive into three distinct handling strategies: Saturating, Throwing, and Wrapping, while also detailing the enum's inheritance from standard interfaces such as Equatable and ToString. This resource is specifically curated for Cangjie developers, software engineers, and system architects who demand precise, predictable control over arithmetic operations, error management, and type safety in their software projects.
