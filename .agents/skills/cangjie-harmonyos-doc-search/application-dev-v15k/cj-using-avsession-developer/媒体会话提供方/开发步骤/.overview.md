# 开发步骤

This directory provides a comprehensive development guide for implementing audio and video media sessions using the Cangjie programming language on HarmonyOS. It covers the complete lifecycle of AVSession integration, from creating and activating sessions to configuring metadata, handling playback control events, and managing session destruction. Key topics include AVSessionKit usage, AVMetadata management, playback state synchronization, and event listener registration. Suitable for HarmonyOS developers building media applications that require robust session management and controller interaction capabilities.

## Detailed Description

### 开发步骤_1.md 开发步骤_1.md
This document serves as a development guide for integrating audio and video applications as media session providers using the Cangjie programming language. The content outlines the fundamental steps required to establish a media session, specifically focusing on creating and activating a session via the createAVSession method and subsequently setting media session information. Key topics include managing AVMetadata and AVPlaybackState to reflect real-time media changes, which are then accessed by media controllers. The tutorial provides practical Cangjie code examples utilizing the AVSessionKit. It is intended for developers working on HarmonyOS media applications who need to implement session management and control interfaces.

### 开发步骤_2.md 开发步骤_2.md
This document serves as a code tutorial for configuring media session details in Cangjie applications. It primarily covers the implementation of the setSessionInfo function to manage media metadata, playback states, and queue items. Key takeaways include setting properties like title, artist, and playlist data using AVSessionKit APIs, alongside error handling. Additionally, it explains how to configure an Ability to be launched by media session controllers via the WantAgent interface. This guide is intended for developers integrating media playback controls and session management into their applications.

### 开发步骤_3.md 开发步骤_3.md
This tutorial provides Cangjie code examples for configuring advanced features in an AVSession to facilitate interaction with media controllers. The document covers setting launch abilities via WantAgent, dispatching transient custom events, setting persistent custom data packets (extras), and registering listeners for fixed playback commands like play and pause. Key takeaways include the distinction that dispatchSessionEvent data is not saved, whereas setExtras data persists with the session lifecycle. It also warns against empty listener implementations to ensure valid command recognition. This guide targets HarmonyOS developers using the Cangjie language to implement robust media session control logic.

### 开发步骤_4.md 开发步骤_4.md
This document provides code examples for handling media control events within an AV Session using the Cangjie programming language. It details the definition of callback classes for various actions, including Stop, PlayNext, Seek, and SetSpeed, and demonstrates how to register these listeners to the session instance. Key takeaways include the importance of executing specific logic upon event reception and subsequently synchronizing the playback state using SetAVPlayState and SetAVMetadata. The text also advises on unregistering unsupported events. This technical guide is intended for developers implementing media playback features who require knowledge of the Cangjie syntax and AV Session APIs.

### 开发步骤_5.md 开发步骤_5.md
This technical guide explains how to register and handle playback control events within an AVSession using the Cangjie programming language. It covers basic event listeners like Seek, SetSpeed, SetLoopMode, and ToggleFavorite, alongside advanced events such as SkipToQueueItem, HandleKeyEvent, OutputDeviceChange, and CommonCommand. Key takeaways include Cangjie code examples for defining callback classes and registering them via session.on. The documentation emphasizes updating playback state using SetAVPlayState after handling events and unregistering unsupported commands. Intended for HarmonyOS developers implementing media session controls, this guide requires prerequisite knowledge of Cangjie syntax and the AVSessionKit framework.

### 开发步骤_6.md 开发步骤_6.md
This tutorial step guides developers on controlling media sessions and managing their lifecycle using the Cangjie language. It covers obtaining an AVSessionController to send playback commands and register listeners for state changes, such as speed, position, and volume. The document emphasizes critical cleanup procedures, demonstrating how to unregister specific event listeners and destroy the session to release resources when the application exits. Key code examples include using sendControlCommand, setting state filters, and handling exceptions during session destruction. Intended for audio/video application developers, this guide assumes familiarity with previous steps regarding session creation and focuses on interaction and resource management within the AVSessionKit framework.
