# Router

本目录包含ArkUI框架和Cangjie语言中Router模块的API参考文档，主要涵盖应用内页面导航的实现与管理。内容涉及通过URL进行页面跳转、替换及返回的操作，详细介绍了Router类的方法（如pushUrl、back）、参数传递机制，以及RouterState类和RouterMode枚举用于管理页面栈状态和路由模式（如Standard和Single）。这些文档适用于使用ArkUI和Cangjie进行鸿蒙应用开发的开发者，旨在指导其正确实现页面路由逻辑和数据传输。
