This directory provides comprehensive documentation for the `ImportContent` class, a core component within the Abstract Syntax Tree (AST) of the Cangjie programming language. It details the structural representation of import statements, covering properties for identifiers, import kinds, aliases, and package path components. The documentation explains how to manage syntax tokens for multi-import scenarios, handle validation errors via ASTException, and utilize specific methods for type inspection and tree traversal. This resource is designed for compiler developers, language tool implementers, and static analysis engineers who require a deep understanding of AST structures to build tools for the Cangjie language ecosystem.
