## 设置音频流类型

应用可采用多种方法实现音频播放或录音功能，常见的设置播放音频流类型的方法有：

- **[使用AudioRenderer开发音频播放功能](./cj-using-audiorenderer-for-playback.md)：**

    可以在调用[createAudioRenderer](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#func-createaudiorendereraudiorendereroptions)以获取音频渲染器时，传入对应的[StreamUsage](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#enum-streamusage)。

    createAudioRenderer的参数options类型为AudioRendererOptions，包含AudioRendererInfo渲染器信息，使用AudioRendererInfo.usage可指定StreamUsage音频流类型。

- **[使用AVPlayer开发音频播放功能](../media/cj-media-kit-using-avplayer-for-playback.md)：**

    可以通过设置AVPlayer的[audioRendererInfo](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#prop-audiorendererinfo)属性来实现。该属性类型为AudioRendererInfo，使用AudioRendererInfo的[usage](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#prop-usage)属性可指定[StreamUsage](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#enum-streamusage)音频流类型。

    > **说明：**
    >
    > 在设置AVPlayer的audioRendererInfo属性时，只允许在initialized状态下设置。
    >
    > 如果应用未主动设置该属性，AVPlayer将进行默认处理。当媒体源包含视频时，usage的默认值为STREAM_USAGE_MOVIE；否则，usage的默认值为STREAM_USAGE_MUSIC。

- **[使用SoundPool开发音频播放功能](../media/cj-media-kit-using-soundpool-for-playback.md)：**

    可以在调用[createSoundPool](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#func-createsoundpoolint32-audiorendererinfo)接口时，传入对应的[StreamUsage](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#enum-streamusage)指定音频流类型。

常见的设置录制音频流类型的方法有：

- **[使用AudioCapturer开发音频录制功能](./cj-using-audiocapturer-for-recording.md)：**

    可以在调用[createAudioCapturer](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#func-createaudiocaptureraudiocaptureroptions)接口时，传入对应的[SourceType](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#enum-sourcetype)。

    createAudioCapturer的参数options类型为AudioCapturerOptions，包含AudioCapturerInfo采集器信息，使用AudioCapturerInfo的source成员可指定SourceType音源类型。

- **[使用AVRecorder开发音频录制功能](../media/cj-media-kit-using-avrecorder-for-recording.md)：**

    可以在调用AVRecorder的[prepare](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#func-prepareavrecorderconfig)接口时，传入对应的[AudioSourceType](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#enum-audiosourcetype)。

    AVRecorder的prepare接口的参数config类型为AVRecorderConfig，使用AVRecorderConfig的audioSourceType成员可指定音源类型。
