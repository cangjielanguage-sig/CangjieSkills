This directory contains the API reference documentation for the HarmonyOS Bluetooth Access module, designed for the Cangjie programming language. It covers the essential functionalities required to manage Bluetooth radio states, including enabling, disabling, and querying the current status. The module also provides mechanisms for monitoring state changes through callback subscriptions. Key topics include `BluetoothState`, `BluetoothAccessCallbackType`, and functions like `enableBluetooth` and `getState`. This documentation is intended for HarmonyOS developers using the ConnectivityKit to implement basic Bluetooth control and state monitoring features in their applications, requiring specific permissions and system capabilities.
