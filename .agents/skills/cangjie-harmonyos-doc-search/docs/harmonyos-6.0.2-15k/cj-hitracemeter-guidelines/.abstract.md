This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, focusing specifically on performance tracking using the HiTraceMeter API. It covers fundamental concepts, implementation principles involving kernel ftrace buffers, and system performance marking. The content includes detailed guides on API interfaces like `startTrace`, `finishTrace`, and `traceByValue`, alongside practical tutorials for distributed tracing and log capturing. It is suitable for Cangjie developers aiming to analyze application performance, track process trajectories, and optimize business logic execution through precise data collection and verification.
