# function

This directory contains comprehensive documentation for functions within the Cangjie programming language. It covers a wide range of topics including function definition, calling conventions, overloading, and advanced features like closures, lambdas, and operator overloading. Key concepts include parameter passing, type inference, constant evaluation, and functions as first-class citizens. This resource is suitable for both beginners learning basic syntax and experienced developers looking to master advanced functional programming techniques and type system intricacies in Cangjie.

## Detailed Description

### [1] call_functions
This directory contains core documentation on function calls in the Cangjie programming language. It covers basic syntax rules, parameter passing methods (including unnamed and named parameters), flexibility in parameter order, and default value handling mechanisms. Key points include type matching between actual and formal parameters, specific formats for named parameters, and how to explicitly override default values. Suitable for beginners and developers to master flexible and standardized code writing.

### [2] closure
This directory serves as a comprehensive repository for technical documentation concerning closure features within the Cangjie programming language. It provides an in-depth analysis of closure definitions, the specific criteria for variable capture, and related behaviors.

### [3] const_func_and_eval
This directory serves as a comprehensive resource for understanding `const` functions and constant evaluation mechanisms within the Cangjie programming language. It is designed to provide developers with the necessary knowledge to effectively utilize compile-time computation features.

### [4] define_functions
This directory serves as a comprehensive technical resource dedicated to the intricacies of defining functions within the Cangjie programming language. It provides an in-depth examination of the fundamental syntax required to construct functions, ranging from basic declarations to complex structures.

### [5] first_class_citizen
This directory explores the core feature of "functions as first-class citizens" and related type system designs in the Cangjie programming language. It details the syntax for defining function types using the `->` symbol to connect parameter and return types, and parameter naming rules. Core content covers passing function types as arguments, returning them as values, and storing them as variables. It also explains ambiguity issues in function overloading and their solutions. It is an essential reference for developers to master high-order function programming and complex type deduction.

### [6] function_call_desugar
This directory is dedicated to the `function_call_desugar` functionality within the Cangjie programming language, specifically focusing on the syntactic sugar features designed to simplify function calls and significantly enhance code readability.

### [7] function_overloading
This directory serves as a comprehensive resource for understanding function overloading within the Cangjie programming language. It delves into the intricate mechanisms that allow developers to define multiple functions with the same name but different parameter lists.
