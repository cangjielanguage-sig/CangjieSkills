This directory contains comprehensive API reference documentation for the Cangjie `DebugDataProvider` class, a specialized component within a fuzzing framework designed to extend standard `FuzzDataProvider` functionality with advanced debugging capabilities. The documentation thoroughly covers methods for consuming, retrieving, and converting raw test data into a wide array of primitive types, including integers, floating-point numbers, booleans, characters, and strings, as well as their array counterparts. It details critical implementation aspects such as method signatures, parameter constraints, return types, and specific exception handling protocols like `IllegalArgumentException`. This resource is essential for developers and QA engineers working with the Cangjie fuzzing framework who require precise control over data generation and transformation during the testing and debugging process.
