This directory contains essential API reference documentation for the `ProfileUuids` enum utilized within the Cangjie programming language framework. It is dedicated to defining the Universally Unique Identifiers (UUIDs) that are critical for identifying and interacting with various Bluetooth communication profiles. The scope of this documentation includes detailed specifications for standard profiles such as A2DP (Advanced Audio Distribution Profile), HFP (Hands-Free Profile), HSP (Headset Profile), AVRCP (Audio/Video Remote Control Profile), HID (Human Interface Device), and HOGP (HID over GATT Profile). Furthermore, it explains the enum's architectural features, specifically its inheritance from the `ToString` and `Equatable` interfaces, which facilitate string representation and equality comparisons. This resource is primarily intended for software developers and engineers who are integrating Bluetooth Core capabilities into Cangjie-based applications, providing them with the necessary definitions to ensure accurate profile identification and robust device communication.
