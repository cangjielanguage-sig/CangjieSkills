This directory serves as a comprehensive technical resource for developers working within the Cangjie framework, specifically focusing on the implementation and configuration of dark mode for Web components. It provides detailed instructions on two distinct approaches: the standard `darkMode()` interface, which supports Off, On, and Auto (system-dependent) settings, and the `forceDarkAccess()` method, which overrides page styles to enforce a dark theme. The guide highlights critical technical considerations, such as the requirement for CSS media queries in standard implementations and the potential for color rendering inconsistencies when using forced mode. By including practical Cangjie and HTML code examples, this documentation is tailored for application developers utilizing ArkWeb and UIKit who seek to create visually consistent, adaptive, and user-friendly interfaces that align with modern theming standards. This guide is essential for ensuring that web content integrates seamlessly with the host application's visual environment, providing a cohesive experience for end-users across different lighting conditions and system preferences. It addresses the specific needs of developers looking to bridge the gap between native application themes and web content rendering.
