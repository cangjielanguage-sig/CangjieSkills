This directory provides API reference documentation for the Context class and associated context management functions in the Cangjie language, specifically designed for the HarmonyOS ecosystem. It covers essential runtime capabilities for abilities and applications, including event hub objects, read-only properties, and file directory access such as cache, database, and temp folders. Key topics include resource management interfaces, module-specific context retrieval, global application context access, and shared directory management via Group IDs. This documentation is suitable for Cangjie and HarmonyOS developers who need to manage application runtime environments, interact with system-level file partitions, and handle context-related operations within the SystemCapability.Ability.AbilityRuntime.Core framework.
