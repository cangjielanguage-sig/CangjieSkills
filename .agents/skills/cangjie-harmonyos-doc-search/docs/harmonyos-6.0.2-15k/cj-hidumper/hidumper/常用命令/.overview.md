# 常用命令

This directory contains a comprehensive collection of command references for the `hidumper` tool in HarmonyOS. It covers essential system diagnostics, including inspecting system abilities, monitoring performance metrics like CPU and memory, and debugging specific services such as WindowManager and RenderService. The documentation also details advanced features like JavaScript heap analysis, garbage collection, and Inter-Process Communication (IPC) statistics. These guides are designed for system developers, QA engineers, and administrators who need to perform deep system introspection, diagnose crashes, or optimize resource usage on HarmonyOS devices.

## Detailed Description

### 常用命令_1.md
This document serves as a command reference guide for the hidumper tool, used for debugging and inspecting system status in HarmonyOS. It details how to view help text, list system information clusters and system abilities, and retrieve detailed data for specific components. Key sections explain commands for dumping process, network, storage, memory, and CPU usage, alongside examples for accessing specific system abilities or clusters like "base" and "system." The guide is intended for developers or system administrators requiring deep system diagnostics and performance monitoring.

### 常用命令_2.md
This document serves as a technical reference guide for using the hidumper command-line tool to diagnose and debug system services. It covers WindowManagerService for window details, RenderService for graphics and FPS statistics, PowerManagerService for screen timeout control, and Faultlog for crash history retrieval. Key takeaways include specific command syntaxes for dumping surface frame rates, preventing automatic screen sleep, and accessing system crash logs. The target audience is system developers or QA engineers requiring knowledge of command-line interfaces to monitor system performance and stability.

### 常用命令_3.md
This reference documentation details specific hidumper commands for monitoring system performance and resource usage in HarmonyOS. It covers network traffic statistics, storage I/O data, process and thread listings, CPU usage rates, CPU core frequencies, and memory information. Key takeaways include the ability to target specific Process IDs (PIDs) for granular data and a critical restriction where process information export is limited to debug applications in release builds. This guide targets developers and system administrators performing diagnostics or debugging on HarmonyOS devices.

### 常用命令_4.md
This reference guide documents advanced usage of the hidumper command-line tool for system diagnostics and performance monitoring. It covers three primary functions: detailed memory analysis, exporting command outputs to compressed archives, and tracking Inter-Process Communication (IPC) statistics. Key information includes syntax for retrieving specific PID memory metrics like Pss and Vss, explanations of Graph memory calculations, and procedures for starting, retrieving, and stopping IPC statistics for individual or all processes. Intended for system developers and engineers, this guide facilitates deep system introspection and debugging.

### 常用命令_5.md
This technical reference guide details specific hidumper commands for analyzing system and JavaScript memory usage. It covers the --mem-smaps command for exporting detailed process memory statistics and the --mem-jsheap command for triggering garbage collection, heap snapshots, and leak detection. Key information includes that these features are primarily restricted to debug versions of the system, with specific output paths for heap dump files. The document targets developers and system debuggers who need to diagnose memory leaks or monitor resource consumption in a specific operating system environment.

### 常用命令_6.md
This document serves as a practical reference guide for using the hidumper command-line tool to diagnose JavaScript memory issues. It covers specific commands for dumping JavaScript heap memory, triggering garbage collection, and identifying potential memory leaks. Key information includes the syntax for flags such as --mem-jsheap, --gc, and --leakobj, demonstrating how to target specific process IDs (PID) and thread IDs (TID) to generate diagnostic output files. This technical snippet is intended for developers or system engineers debugging memory performance in a runtime environment, likely HarmonyOS or OpenHarmony. Keywords: hidumper, memory debugging, JS heap, garbage collection, memory leaks, command-line interface.
