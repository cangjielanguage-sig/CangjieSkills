This directory provides a comprehensive technical guide for developers using the Cangjie language to implement performance tracking using the HiTraceMeter API. It covers the fundamental concepts of the HiTraceMeter system, including its implementation principles involving kernel ftrace buffers and system performance marking. The content details specific API interfaces such as `startTrace`, `finishTrace`, and `traceByValue` for monitoring execution flows and variable changes. Additionally, it offers practical tutorials on code implementation for distributed tracing and shell commands for capturing trace logs. This resource is suitable for Cangjie developers aiming to analyze application performance, track process trajectories, and optimize business logic execution through precise data collection and verification. It serves as an essential reference for mastering performance monitoring within the Cangjie ecosystem.
