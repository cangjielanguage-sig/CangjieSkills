# 启动UIAbility的指定页面

This directory focuses on the technical implementation of launching specific pages within a UIAbility component in HarmonyOS development using the Cangjie language. It covers the distinctions between cold starts (initializing new instances) and hot starts (restoring running instances), detailing how to pass parameters via the Want object to control navigation. Key topics include lifecycle callbacks like `onCreate`, `onWindowStageCreate`, and `onNewWant`, as well as routing mechanisms. This resource is suitable for developers using the AbilityKit framework who need to manage inter-page navigation, parameter passing, and application lifecycle states effectively.

### 概述_2more.md 概述_2more.md
This technical guide explains how to launch specific pages within a UIAbility component based on different startup scenarios. It covers the definitions of UIAbility cold start, where instances are fully initialized, and hot start, where running instances are quickly restored. The document details how a calling UIAbility can specify the target page by passing custom parameters through the Want object. It includes a Cangjie code example demonstrating how to configure these parameters to navigate to specific pages like "FuncA". This guide is intended for developers using the AbilityKit framework to manage application navigation and lifecycle states.

### 目标UIAbility冷启动.md 目标UIAbility冷启动.md
This technical guide explains how to handle the cold start process of a target UIAbility in Cangjie development. It covers the lifecycle callbacks onCreate() and onWindowStageCreate(), detailing how to process incoming Want parameters. The key takeaway is that developers must receive parameters in onCreate() and parse the page URL in onWindowStageCreate() to pass it to windowStage.loadContent(). The document includes a code example demonstrating this flow within a class inheriting from UIAbility. This is intended for HarmonyOS developers using the Cangjie language who need to implement inter-page navigation and parameter passing during application startup.

### 目标UIAbility热启动.md 目标UIAbility热启动.md
This guide explains how to handle the hot start scenario for a UIAbility component, ensuring navigation to specific pages when an already running instance is relaunched. It covers the lifecycle behavior difference between cold and hot starts, a practical SMS and Contacts integration example, and step-by-step development instructions using Cangjie code. The core concept is that onNewWant() is triggered instead of initialization methods during a hot start. Developers must parse Want parameters within onNewWant() and use Router.pushUrl() to navigate. It notes that this logic does not apply to the multiton launch mode. This tutorial targets application developers using the Cangjie language and AbilityKit framework who need to manage cross-application navigation and background state restoration.
