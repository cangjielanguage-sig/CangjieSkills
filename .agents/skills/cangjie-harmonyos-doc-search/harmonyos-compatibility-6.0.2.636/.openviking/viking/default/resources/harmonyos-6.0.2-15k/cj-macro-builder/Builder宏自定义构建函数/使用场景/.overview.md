# 使用场景

This directory focuses on practical usage scenarios for the Cangjie ArkUI framework, specifically detailing the implementation of @Builder functions for dynamic UI construction. It covers advanced techniques such as passing global and local builders as parameters, handling nested structures, and managing state with decorators like @State and @Observed. The content is designed for Cangjie developers looking to optimize component reusability and ensure efficient UI refresh propagation in HarmonyOS applications. Key concepts include customBuilder parameters, pass-by-reference mechanisms, and the relationship between macro decorators and UI updates. By exploring these scenarios, developers can better understand how to structure complex UI logic and maintain data consistency across different component levels.

## Detailed Description

### 使用全局和局部的Builder传入customBui_2more.md 使用全局和局部的Builder传入customBui_2more.md
This technical guide explains how to utilize global and local @Builder functions within the Cangjie ArkUI framework, focusing on parameter passing and nested usage. The document covers passing @Builder functions as customBuilder parameters and implementing multi-level @Builder nesting. Key takeaways include the ability to pass @Builder functions as Function types to components like bindSheet, and the critical requirement for pass-by-reference in nested methods to ensure dynamic UI refreshes propagate correctly through all levels. This guide targets Cangjie developers familiar with ArkUI components and state management decorators like @State and @Observed.

### 自定义组件内使用自定义构建函数_3more.md 自定义组件内使用自定义构建函数_3more.md
This tutorial demonstrates how to implement and utilize custom @Builder functions in Cangjie for dynamic UI rendering within HarmonyOS applications. It covers three distinct scenarios: using private @Builder methods with @State variables for local state management, employing global @Builder functions with @Observed object parameters to handle complex data types, and clarifying that UI refresh is driven by macro decorators like @Publish rather than the @Builder mechanism itself. Key takeaways include the syntax for calling builders, passing parameters via object literals, and the relationship between state management macros and UI updates. This guide targets developers familiar with Cangjie seeking to structure reusable UI components and manage state effectively.
