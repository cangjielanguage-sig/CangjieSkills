# class_AbilityInfo

This directory contains API reference documentation for the `AbilityInfo` class in the Cangjie programming language, specifically within the HarmonyOS/OpenHarmony BundleManager framework. It covers the data structure used to store Ability component information, detailing properties defined in `module.json5` such as bundle names, permissions, launch types, and window configurations. The documentation is intended for application developers and system integrators who need to configure, query, and manage Ability component states and capabilities. Key topics include read-only properties, system flags for data retrieval, and component metadata.

### class_AbilityInfo_9more.md class_AbilityInfo_9more.md
This document provides API reference documentation for the Cangjie AbilityInfo class, which defines the data structure for storing Ability component information. It details the class properties including appIndex, applicationInfo, bundleName, description, deviceTypes, enabled, and excludeFromDock, explaining their types, read-only nature, and configuration origins like module.json5. Intended for developers working with the BundleManager framework, this document assumes familiarity with application configuration and system capabilities.

### let_permissions_5more.md let_permissions_5more.md
