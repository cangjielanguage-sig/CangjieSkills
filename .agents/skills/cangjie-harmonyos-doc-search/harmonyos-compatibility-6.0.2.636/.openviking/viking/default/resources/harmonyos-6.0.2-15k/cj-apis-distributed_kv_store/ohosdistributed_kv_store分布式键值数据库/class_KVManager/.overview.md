# class_KVManager

This directory contains API reference documentation for the Cangjie `KVManager` class, a core component of the ArkData kit designed for managing distributed key-value database instances. It covers essential operations including the lifecycle management of KV stores (closing, deleting, listing), creating and retrieving device or single-version databases, and handling distributed data service status subscriptions. Key topics include `closeKVStore`, `getDeviceKVStore`, and service death notifications. This documentation is intended for developers utilizing the Cangjie programming language to implement robust distributed data management and synchronization in their applications.
