## 创建组件

### init(Int64, Int32, () -> Unit)

```cangjie
public init(space!: Int64 = spaceDefault, initialIndex!: Int32 = initialIndexDefault, child!: () -> Unit)
```

**功能：** 创建一个可包含子组件的List容器。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|space|Int64|否|0| **命名参数。** 子组件主轴方向的间隔。<br/>初始值：0。<br/>单位为vp。<br/>**说明：**<br/>设置为负数或者大于等于List内容区长度时，按初始值显示。<br/>space参数值小于List分割线宽度时，子组件主轴方向的间隔取分割线宽度。<br/>List子组件的visibility属性设置为None时不显示，但该子组件上下的space还会生效。|
|initialIndex|Int32|否|0| **命名参数。** 设置当前List初次加载时视口起始位置显示的item，即显示第一个item，如果设置的值超过了当前List最后一个item的索引值，则设置为不生效。<br/>初始值：0。<br/>**说明：**<br/>设置为负数或超过了当前List最后一个item的索引值时视为无效取值，无效取值按初始值显示。|
|child|()->Unit|是|-| **命名参数。** 声明容器内的List子组件。|

### init(Int64, Int32, BaseScroller, () -> Unit)

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

|:---|:---|:---|:---|:---|
|space|Int64|否|spaceDefault| **命名参数。** 子组件主轴方向的间隔。<br/>初始值：0。<br/>单位为vp。<br/>**说明：**<br/>设置为负数或者大于等于List内容区长度时，按初始值显示。<br/>space参数值小于List分割线宽度时，子组件主轴方向的间隔取分割线宽度。<br/>List子组件的visibility属性设置为None时不显示，但该子组件上下的space还会生效。|
|initialIndex|Int32|否|initialIndexDefault| **命名参数。** 设置当前List初次加载时视口起始位置显示的item，即显示第一个item，如果设置的值超过了当前List最后一个item的索引值，则设置为不生效。<br/>初始值：0。<br/>**说明：**<br/>设置为负数或超过了当前List最后一个item的索引值时视为无效取值，无效取值按初始值显示。|

|child|()->Unit|是|-| **命名参数。** 声明容器内的List子组件。|
