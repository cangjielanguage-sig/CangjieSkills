# using_cangjie

This directory serves as an essential resource for developers working within the HarmonyOS ecosystem who wish to leverage the combined power of ArkTS and the Cangjie programming language. It focuses specifically on the technical implementation of cross-language interoperability, a sophisticated feature that allows developers to write high-performance, concurrent code in Cangjie while maintaining the user interface and application logic in ArkTS. The documentation provides a step-by-step tutorial on how to configure the development environment in DevEco Studio to support this hybrid approach effectively. It details the architectural patterns required to define Cangjie modules as self-contained packages, which can include pages, reusable components, and complex state management systems. By integrating these languages, developers can significantly optimize application performance, particularly for tasks requiring heavy computation or efficient threading. This guide is highly suitable for experienced software developers, system architects, and performance engineers looking to push the limits of mobile application capabilities by utilizing the advanced features of the Cangjie language alongside standard ArkTS development practices.
