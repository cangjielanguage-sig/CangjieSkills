This directory is a specialized repository of technical documentation and code examples dedicated to the implementation of SM2 digital signatures within the Cangjie ecosystem. It addresses the specific needs of developers requiring robust security mechanisms, detailing the end-to-end process of creating digital signatures and verifying them using the SM3 hash algorithm. The resources leverage the CryptoArchitectureKit to demonstrate how to handle asymmetric keys and manage cryptographic states. This guide is particularly suitable for Cangjie developers and system architects who are building secure applications and require a practical understanding of how to utilize the `createAsyKeyGenerator`, `createSign`, and `createVerify` APIs to enforce data integrity and non-repudiation in their software solutions. The focus on synchronous implementation ensures that developers can easily follow the logic for real-world application scenarios.
