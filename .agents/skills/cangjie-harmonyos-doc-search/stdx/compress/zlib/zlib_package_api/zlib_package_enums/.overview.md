# zlib_package_enums

本目录专门收录了Cangjie语言标准库中zlib包相关的枚举类型定义文档，旨在为开发者提供精确的压缩参数配置指南。文档详细阐述了用于控制压缩性能与效率的`CompressLevel`枚举，以及用于定义数据流封装方式的`WrapType`枚举。通过这些枚举，开发者可以灵活地在压缩速度、压缩率以及兼容性之间进行权衡。该文档是API参考手册的重要组成部分，特别适合那些正在Cangjie开发环境中集成zlib功能，并需要对压缩行为进行细粒度控制的专业开发者阅读和使用。

## 详细说明

### zlib_package_enums.md zlib_package_enums.md
本文档定义了Cangjie语言中zlib包的枚举类型，用于配置压缩参数和数据格式。主要包含CompressLevel枚举，用于设定压缩等级；以及WrapType枚举，用于指定压缩数据格式。CompressLevel提供BestSpeed、DefaultCompression和BestCompression三个选项，平衡压缩率与速度；WrapType支持DeflateFormat和GzipFormat两种数据封装格式。该文档属于API参考手册，面向需要在Cangjie项目中使用zlib进行数据压缩的开发者。
