This directory serves as a comprehensive repository for reference documentation regarding OpenHarmony and HarmonyOS system permissions, specifically those introduced or updated in API version 12. It covers a wide array of permission definitions ranging from hardware interactions—such as Bluetooth, sensors, and NFC—to system-level capabilities including background running, wallpaper settings, and security detection. The documents detail critical attributes like authorization levels (normal) and grant modes (system_grant), indicating automatic installation grants. This resource is primarily suitable for HarmonyOS application developers who need to accurately declare required capabilities in their configuration files to ensure proper application functionality and compliance.
