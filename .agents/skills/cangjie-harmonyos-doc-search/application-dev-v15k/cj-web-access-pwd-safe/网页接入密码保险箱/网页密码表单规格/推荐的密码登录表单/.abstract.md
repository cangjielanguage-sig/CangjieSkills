This directory provides a comprehensive set of technical guidelines and best practices for implementing password login forms that are optimized for automated algorithms, password managers, and browser autofill features. It covers critical topics including HTML structure requirements, input element attributes, and specific naming conventions for username fields. The content emphasizes the importance of using static HTML forms rather than dynamic JavaScript injection, ensuring inputs are editable, and utilizing specific id or name values to facilitate algorithmic inference. Additionally, it details implementation rules such as applying the correct autocomplete attributes and maintaining field adjacency. This resource is essential for front-end developers and security engineers aiming to create robust, user-friendly authentication interfaces that integrate seamlessly with modern credential management systems.
