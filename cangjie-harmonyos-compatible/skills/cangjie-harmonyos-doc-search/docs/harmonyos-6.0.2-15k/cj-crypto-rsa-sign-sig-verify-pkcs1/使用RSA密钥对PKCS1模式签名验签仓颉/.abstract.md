This directory contains resources for implementing RSA digital signatures and verification using the PKCS1 padding mode within the Cangjie programming environment. It covers the complete cryptographic workflow, including generating RSA KeyPairs, initializing Sign and Verify instances, and handling data updates. The content emphasizes the use of specific algorithm parameters like RSA1024 and SHA256, while also supporting segmented data processing for large payloads. These materials are intended for Cangjie developers utilizing the CryptoArchitectureKit who require a solid understanding of asymmetric cryptography concepts and API integration to ensure data integrity and authenticity.
