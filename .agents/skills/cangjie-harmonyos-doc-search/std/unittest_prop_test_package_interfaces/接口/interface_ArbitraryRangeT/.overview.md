# interface_ArbitraryRangeT

This directory contains API documentation for the `ArbitraryRange` interface in the Cangjie programming language, specifically designed for property-based testing frameworks. It covers the generation of random values within specified numerical ranges. The content details the core interface definition and its implementations across various numeric types, including signed and unsigned integers (Int8, Int16, Int32, Int64, IntNative, UInt8, UInt16, UInt32, UInt64, UIntNative) and floating-point numbers (Float16, Float32, Float64). This documentation is suitable for developers implementing testing logic who need to create constrained random data generators using `RandomSource` and `Generator` types.
