This directory provides comprehensive API documentation for the `CharacteristicWriteRequest` class in the Cangjie language, tailored for Bluetooth Core operations. It details the data structures required to handle characteristic write requests received by a Bluetooth Low Energy (BLE) server. The content covers the class constructor, read-only properties, and specific parameters like remote device address, service and characteristic UUIDs, transaction IDs, data offsets, and execution flags. This resource is intended for Cangjie developers working with Bluetooth Core capabilities (version 19) who need to implement server-side logic for managing and responding to client write operations.
