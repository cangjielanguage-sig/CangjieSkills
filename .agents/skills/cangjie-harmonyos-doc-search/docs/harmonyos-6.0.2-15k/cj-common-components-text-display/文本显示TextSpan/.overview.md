# 文本显示TextSpan

This directory provides a comprehensive guide to text display and manipulation using the Text and Span components within the ArkUI framework and the Cangjie language. It covers fundamental topics such as text creation, layout constraints, overflow handling, and event binding, as well as advanced features like custom styling, text case conversion, and selection menu customization. Suitable for HarmonyOS developers, these resources offer practical code examples for building interactive and visually appealing text interfaces, ranging from simple labels to complex rich text layouts.

## Detailed Description

### 场景示例.md 场景示例.md
This document serves as a practical code example demonstrating how to implement a hot search ranking interface using the Cangjie language and ArkUI components. The primary focus is on text handling properties, specifically maxLines, textOverflow, textAlign, and constraintSize, to manage content display within a list layout. Key takeaways include how to truncate overflowing text with ellipsis and style ranking elements with specific colors and weights. This tutorial is intended for developers building HarmonyOS applications who need to understand text layout constraints and UI component composition in Cangjie.

### 文本显示TextSpan_2more.md 文本显示TextSpan_2more.md
This document serves as a tutorial for using the Text and Span components within the ArkUI framework to display text content. It primarily focuses on the methods for creating Text components, detailing how to initialize them using either direct string values or AppResource references via the @r syntax. Key information includes the Text component's ability to support custom text selection menus for improved user interaction. The content is intended for developers using the Cangjie language who need to implement text display and resource management in their user interfaces.

### 添加事件.md 添加事件.md
This document serves as a technical tutorial demonstrating how to bind universal events to the Text component in the Cangjie framework. The content focuses on event handling capabilities, specifically referencing the onClick and onTouch methods. Key information includes a practical code example that illustrates the syntax for attaching an onClick event handler to a Text element, which executes a logging function upon interaction. This guide is intended for HarmonyOS developers using the Cangjie language who need to implement interactive UI behaviors in their applications.

### 添加子组件.md 添加子组件.md
This document serves as a technical tutorial for developers on how to implement and configure the Span component within the ArkUI Cangjie framework. It explains that Span components must be embedded inside Text or RichEditor components to display content. The guide covers four main topics: creating a basic Span, setting text decorations and colors via the decoration attribute, enforcing uppercase or lowercase text using the textCase attribute, and handling click events. Key takeaways include the limitation that Span components lack size information and thus only support onClick events. This resource is intended for Cangjie developers looking to style specific text segments, such as in product manuals, using code examples.

### 自定义文本样式/
This directory provides a comprehensive guide to customizing text styles in ArkUI applications using the Cangjie language. It covers a wide range of text attributes, from basic layout adjustments like alignment, overflow handling, and line height, to advanced typography features such as baseline offset, character spacing, and adaptive font sizing. Additionally, it addresses text presentation controls like capitalization and user interaction settings such as clipboard options. The tutorials include executable code examples to help developers refine UI text appearance and layout behavior. This resource is suitable for developers building HarmonyOS applications who seek to enhance text presentation, readability, and user interaction capabilities within their interfaces.

### 选中菜单/
This directory focuses on the implementation and customization of selection menus for text components within the HarmonyOS ArkUI development environment. It provides comprehensive guidance on enabling default selection behaviors, binding fully custom menus, and extending standard menus with additional options. The content covers specific technical implementations using both the Cangjie language and ArkTS, detailing the use of `TextController`, `bindSelectionMenu`, `editMenuOptions`, and event handling callbacks like `onCreateMenu` and `onMenuItemClick`. This resource is designed for HarmonyOS application developers who need to create sophisticated text interaction experiences, manage user selections, and implement custom editing behaviors in their mobile applications. By following these guides, developers can learn how to intercept standard actions, append custom items, and control the UI presentation of text selection menus effectively.
