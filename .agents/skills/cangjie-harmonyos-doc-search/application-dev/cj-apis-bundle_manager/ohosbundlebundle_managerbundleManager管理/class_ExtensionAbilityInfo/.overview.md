# class_ExtensionAbilityInfo

This directory provides comprehensive API reference documentation for the `ExtensionAbilityInfo` class within the Cangjie programming language, specifically designed for the HarmonyOS BundleManager framework. It encapsulates metadata regarding extension abilities, covering essential read-only properties such as `bundleName`, `extensionAbilityType`, `permissions`, `exported`, and `appIndex`. The documentation details the necessary flags, like `GET_BUNDLE_INFO_WITH_EXTENSION_ABILITY`, required to retrieve this data via `getBundleInfoForSelf`. It is suitable for system developers and application developers who need to query extension capability configurations, manage component states, and understand system capabilities and permissions required for accessing specific metadata.
