This directory provides API reference documentation for the `IPv4Address` class in the Cangjie programming language, designed for representing Internet Protocol version 4 addresses. It covers core functionalities such as initialization from bytes or integers, static properties for standard addresses, and inheritance from interfaces like `IPAddress` and `Equatable`. The documentation also details utility functions for serialization, type conversion to IPv6, and address classification. This resource is intended for software developers and network engineers who need to implement, manipulate, or validate IP addresses within their network applications.
