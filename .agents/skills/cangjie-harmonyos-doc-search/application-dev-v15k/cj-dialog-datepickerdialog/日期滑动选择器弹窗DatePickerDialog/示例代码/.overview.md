# 示例代码

This directory contains a collection of Cangjie code examples designed to help developers master the `DatePickerDialog` component within the HarmonyOS UIKit. It covers essential functionalities such as configuring time display, customizing visual styles, setting popup positions, and switching between Gregorian and Lunar calendars. These examples provide practical implementations for lifecycle callbacks, text styling, and layout adjustments. Suitable for HarmonyOS developers using the Cangjie language, this resource serves as a comprehensive guide for creating flexible and visually appealing date selection interfaces in applications.

## Detailed Description

### 示例1设置显示时间.md
This document provides a code example demonstrating how to configure a DatePickerDialog to display time in a Cangjie application. It covers the implementation of the EntryView component, specifically focusing on the DatePickerDialog.show method and its configuration options. The example highlights the usage of showTime to enable time display, useMilitaryTime for 12/24-hour format, and dateTimeOptions for formatting. It also includes lifecycle and event callbacks like onDateAccept and onDateChange. This tutorial is intended for developers using the Cangjie language and HarmonyOS UIKit who need to implement date and time selection interfaces.

### 示例2自定义样式.md
This document provides a Cangjie code example demonstrating how to customize the visual appearance of a DatePickerDialog component. It covers the configuration of text styles for various picker states and the styling of action buttons. The code illustrates the use of disappearTextStyle, textStyle, and selectedTextStyle for date text, alongside acceptButtonStyle and cancelButtonStyle for dialog buttons, allowing customization of colors, fonts, and border radii. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to implement custom UI styling for date selection dialogs.

### 示例3设置弹窗位置_3more.md
This document provides Cangjie code examples demonstrating advanced customization options for the DatePickerDialog component. It covers three specific scenarios: setting the popup position using alignment and offset, defining a mask area, and styling the dialog backboard. Key parameters include DialogAlignment, Offset, maskRect, backgroundColor, backgroundBlurStyle, and ShadowOptions. The examples illustrate how to implement these properties within DatePickerDialogOptions to control layout and visual effects. This tutorial targets HarmonyOS developers using the Cangjie language who need to fine-tune the presentation and layout of date picker dialogs in their applications.

### 示例6设置公历农历.md
This document provides a Cangjie code example demonstrating how to configure a DatePickerDialog to display either Gregorian or Lunar calendars. The content illustrates the implementation of two distinct buttons: one triggering a standard Gregorian dialog and another enabling a Lunar calendar view with a toggle switch. Key takeaways include the specific usage of the `lunar` parameter to define the calendar type and the `lunarSwitch` parameter to allow users to switch between formats. This tutorial is designed for HarmonyOS developers using the Cangjie language who require flexible date selection interfaces in their applications.
