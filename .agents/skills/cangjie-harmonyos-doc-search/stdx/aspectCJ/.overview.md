# aspectCJ

The `aspectCJ` directory is a specialized repository designed to facilitate Aspect-Oriented Programming (AOP) within the Cangjie language ecosystem. It functions as a comprehensive knowledge base, encompassing the core API definitions, detailed reference documentation, and practical implementation samples. Key topics include function instrumentation, body replacement, and the utilization of annotations such as `InsertAtEntry` and `InsertAtExit` to handle cross-cutting concerns. This resource is tailored for developers seeking to enhance modularity in their Cangjie applications by separating business logic from auxiliary functionalities. Through the integration of specific compilation plugins and libraries, `aspectCJ` provides the necessary tools and documentation to effectively implement AOP patterns.
