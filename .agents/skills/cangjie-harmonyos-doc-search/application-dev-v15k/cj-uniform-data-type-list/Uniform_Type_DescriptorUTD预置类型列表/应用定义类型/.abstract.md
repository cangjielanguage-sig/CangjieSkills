This directory contains comprehensive reference documentation for Application Defined Types, custom data types maintained by specific applications using reverse domain naming conventions. It covers the theoretical framework of these types and provides extensive technical tables mapping file extensions to MIME types and internal identifiers. The content spans a wide range of software ecosystems, including Microsoft Office, OpenDocument, Adobe products, AutoCAD, and various multimedia formats. This resource is essential for developers, system architects, and administrators who need to configure file associations, implement data parsing logic, or ensure system integration across diverse file formats.
