This directory serves as a comprehensive technical reference for developers building enterprise applications, specifically addressing the granular permission requirements necessary for advanced system integration. It clearly delineates the permission models for standard enterprise applications versus Mobile Device Management (MDM) solutions, ensuring developers understand the distinct privilege tiers required for different use cases. The documentation covers a wide array of critical capabilities, including file guard policies, cross-account interactions, runtime information access, Wi-Fi configuration, and firewall management. It provides essential technical specifications such as permission levels (predominantly system_basic), authorization methods (system_grant), and the API version introduction (starting from API 12). Furthermore, it addresses hardware-specific constraints, notably that firewall permissions are restricted to 2in1 devices. This resource is indispensable for enterprise developers required to declare sensitive privileges in Profile files to enable robust device management and comprehensive system control features.
