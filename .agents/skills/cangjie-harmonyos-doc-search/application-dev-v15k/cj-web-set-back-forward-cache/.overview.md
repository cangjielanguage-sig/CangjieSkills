# cj-web-set-back-forward-cache

This directory contains a technical guide for developers using the ArkWeb engine in the Cangjie environment, focusing on the Back/Forward Cache (BFCache). It details how to enable and configure BFCache to accelerate page navigation speeds and improve responsiveness. The guide covers enabling the cache before kernel initialization and configuring limits like page capacity and retention time, with a default of 600 seconds. By providing Cangjie code examples, it helps developers reduce HTTP requests and ensure rapid page state restoration. This resource is essential for optimizing user experience through efficient state management and performance tuning in web applications.

### cj-web-set-back-forward-cache.md cj-web-set-back-forward-cache.md
This technical guide explains how to enable and configure the Back/Forward Cache (BFCache) for Web components to improve page navigation speed. It covers two main procedures: enabling BFCache before initializing the ArkWeb kernel using `enableBackForwardCache`, and configuring cache limits via `setBackForwardCacheOptions`. Key information includes the default cache duration (600 seconds) and the ability to customize page limits and retention time. The document provides Cangjie code examples for implementation. It targets developers using the ArkWeb engine who need to optimize user experience by reducing HTTP requests and restoring page states quickly.
