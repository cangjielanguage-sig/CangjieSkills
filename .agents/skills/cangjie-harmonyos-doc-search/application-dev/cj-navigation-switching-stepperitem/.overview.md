# cj-navigation-switching-stepperitem

This directory provides the API reference documentation for the StepperItem component within the ArkUI framework, specifically written for developers using the Cangjie language. It focuses on the implementation of step-by-step navigation flows, detailing how StepperItem functions as a child component of the Stepper navigation element. The documentation covers essential technical aspects, including module imports, component initialization, and the configuration of specific attributes such as nextLabel, prevLabel, and status. It also explains layout constraints, highlighting that the component's width fills the parent while height is calculated automatically. This resource is suitable for software engineers and UI developers who need to build structured, sequential user interfaces, offering the necessary guidance to manage single child components and customize navigation buttons effectively in ArkUI applications.
