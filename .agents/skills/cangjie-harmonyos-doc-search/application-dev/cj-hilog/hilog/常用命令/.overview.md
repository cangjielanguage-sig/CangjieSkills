# 常用命令

This directory contains a comprehensive collection of technical reference guides for the `hilog` logging tool, focusing on common command-line operations used in system diagnostics and debugging. It covers essential tasks such as viewing and configuring log levels, filtering logs by tags or process IDs, managing log buffers, and setting display formats. Additionally, it includes instructions for flow control, kernel log management, and disk persistence. These documents are designed for system developers, engineers, and administrators who need to monitor system behavior, analyze performance, or troubleshoot issues within the operating system environment using terminal commands.

## Detailed Description

### 查看和设置日志级别_2more.md
This technical reference guide outlines commands for viewing and configuring log levels within the hilog system. The document details methods to query global settings and adjust log verbosity for global scopes, specific domain IDs, or tags using the -b flag. It explains how to make these settings persistent after reboots and includes a section for toggling the privacy format switch. Key takeaways include the syntax for filtering logs by severity (D/I/W/E/F) and managing privacy controls. This guide is intended for developers or system administrators managing system diagnostics and debugging.

### 查看帮助命令_8more.md
This document serves as a command reference guide for the hilog logging tool, detailing various operational commands for log management and analysis. It covers viewing help information, performing non-blocking log reads, querying and modifying log buffer sizes, clearing buffers, controlling kernel log storage, and querying or clearing statistical data. Key commands include -h for help, -x for non-blocking reads, -g and -G for buffer management, -r for clearing, -k for kernel logs, and -s for detailed statistics including domain tables and frequency metrics. Intended for system developers or engineers needing to monitor, configure, and debug system logs via the command line.

### 查看指定TAG日志_3more.md
This document serves as a technical reference guide for using the hilog command-line tool to filter and retrieve system logs. It covers three primary operations: filtering logs by a specified tag using the -T option, viewing the first n lines of the log buffer using -a, and retrieving the last n lines using -z. Each section provides the specific command syntax followed by practical usage examples with sample output to demonstrate effective log isolation. The content is intended for developers or system administrators who need to debug applications or monitor system behavior through terminal commands, offering quick methods to access specific log streams or buffer segments.

### 查看指定进程日志_3more.md
This technical reference guide explains how to use the hilog command-line tool to filter and manage system logs. It covers three main topics: viewing logs for a specific process ID, filtering logs using regular expressions, and managing disk persistence tasks. Key information includes commands for querying, starting, and stopping log storage, as well as configuring parameters like file size, quantity, and compression methods such as zlib or zstd. The document targets system developers and administrators who need to monitor system performance, debug specific processes, or configure log retention policies within the operating system environment.

### 设置日志显示格式.md
This document serves as a technical reference guide for configuring the timestamp display format within the hilog logging system. It details the command syntax for the -v flag, listing available format options such as time, color, epoch, and nsec. The content includes practical usage examples demonstrating the difference between standard time and high-precision nanosecond outputs. Key takeaways involve understanding how to toggle between various time representations to suit different debugging needs. This guide is intended for developers and system engineers who require precise log analysis and control over terminal output formatting.

### 进程流控开关_5more.md
This document serves as a technical reference guide for managing log flow control and filtering output using the hilog command-line tool. It covers enabling and disabling flow control switches for both processes and domains, as well as methods to view logs filtered by specific severity levels, types, and domain IDs. Key information includes practical shell command examples, such as toggling flow control with hilog -Q pidon or filtering error logs with hilog -L E. Intended for system developers or engineers, this guide assists in debugging and monitoring system behavior by providing precise commands to control log volume and isolate specific events.
