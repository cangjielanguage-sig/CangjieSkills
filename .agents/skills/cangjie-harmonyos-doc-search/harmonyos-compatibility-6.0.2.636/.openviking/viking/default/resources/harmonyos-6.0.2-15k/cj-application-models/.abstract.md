This directory serves as a comprehensive resource for understanding the application model framework, with a specific emphasis on the Stage model as the primary development paradigm. It covers the five core elements essential for application development: application components, process model, thread model, task management, and configuration files. The documentation details the architecture of the Stage model, including UIAbility and ExtensionAbility components, distinct process types, and a task management system where each UIAbility instance creates a separate task. It also explains the reliance on app.json5 and module.json5 for configuration. This content is designed for application developers who need a deep understanding of the fundamental architecture, lifecycle mechanisms, and object-oriented approach required to build robust applications within this ecosystem.
