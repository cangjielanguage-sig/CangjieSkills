# 创建列表List

This directory provides a comprehensive guide to creating and managing List components within the ArkUI framework using the Cangjie language. It covers fundamental implementation, layout configuration, and advanced interactive features such as swipe actions, sticky headers, and scroll control. Developers will learn how to handle dynamic data rendering, optimize performance with lazy loading, and customize visual styles. Suitable for application developers and UI engineers building structured, scrollable interfaces for mobile or cross-platform applications, this collection ensures efficient data display and enhanced user experience.

### 创建列表List_2more.md 创建列表List_2more.md
This document serves as a guide for developers on how to implement and utilize the List component within the ArkUI framework to display scrollable data collections. It covers the component's definition, common use cases like contact or music lists, and structural composition using List, ListItem, and ListItemGroup. ### 响应列表项侧滑_3more.md 响应列表项侧滑_3more.md

It covers three main topics: implementing list item swipe actions for deletion, adding notification badges to avatars, and handling pull-to-refresh and load-more functionalities. Key takeaways include using the ListItem swipeAction attribute with end parameters for custom delete buttons, wrapping images in the Badge component for status indicators, and utilizing touch event logic or the Refresh component for data loading.

### 布局与约束.md 布局与约束.md
This technical guide details the layout mechanisms and size constraints of the List component within a UI framework. It covers the component hierarchy involving List, ListItemGroup, and ListItem, and explores layout capabilities including vertical and horizontal scrolling with single or multi-column arrangements. Key information includes specific sizing rules: the main axis adapts to the total size of children if smaller than the parent, otherwise it fills the parent, while the cross axis defaults to the parent's size.

### 开发布局_2more.md 开发布局_2more.md
This document serves as a development guide for configuring the layout and data display of the List component in ArkUI using the Cangjie language. It covers setting the main axis direction, configuring cross-axis layout using lanes and alignment properties, and displaying static data within list items. Key information includes using listDirection for scrolling orientation, lanes for adaptive column or row counts, and alignListItem for cross-axis alignment. The guide also explains that ListItem requires a single root node, necessitating containers like Row for complex layouts.

### 折叠与展开.md 折叠与展开.md

The document covers three main steps: defining hierarchical data structures with ItemInfo and ItemGroupInfo, constructing the list layout using ListItemGroup and ForEach, and controlling state changes to trigger animations. Key takeaways include using an ObservedArrayList to track expansion states and applying rotate and animation properties to achieve smooth visual transitions.

Key information includes binding a Scroller object to a List to enable methods like scrollToIndex for navigation, and using the onScrollIndex event to synchronize external UI elements, such as an AlphabetIndexer, with the current list view.

### 添加粘性标题.md 添加粘性标题.md
This document serves as a technical tutorial for implementing sticky headers in list components using the ArkUI framework and Cangjie language. It covers the definition and user experience benefits of sticky headers, the specific relationship between the List component and ListItemGroup, and configuration options for both header and footer stickiness. The core implementation involves setting the List component's sticky attribute to StickyStyle.Header to achieve the anchoring effect, or StickyStyle.Footer for footers.

It covers basic data manipulation for list items, the limitations of loop rendering for large datasets, and the implementation of lazy loading. Key information includes the use of the cachedCount parameter within the List component to cache items and prevent visual glitches during scrolling, emphasizing the trade-off between smooth user experience and increased CPU or memory overhead.

### 自定义列表样式.md 自定义列表样式.md

Key takeaways include using the space parameter for gaps, the divider property (with strokeWidth, color, startMargin, endMargin) for visual separation, and the scrollBar property with BarState.Auto for interactive scrolling.

### 迭代列表内容.md 迭代列表内容.md
This document serves as a tutorial for implementing dynamic list rendering in the Cangjie programming language using ArkUI. It focuses on utilizing the ForEach component to iterate over data collections and generate UI elements, thereby reducing code complexity. The main content includes a conceptual overview of loop rendering and a practical code example demonstrating a contact list where data is stored in a Contact class and rendered via nested List and ListItem components. Key takeaways involve understanding how to bind data arrays to UI components and the ability to render both ListItem and ListItemGroup.
