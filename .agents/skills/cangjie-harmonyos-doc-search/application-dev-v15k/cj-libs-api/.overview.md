# cj-libs-api

This directory serves as the central documentation and navigation hub for the Cangjie programming language library API. It provides a comprehensive architectural overview of the language's ecosystem, specifically detailing the structure of the standard library module (std) alongside various common extension modules. These modules collectively contain specific packages of functionality designed to support a wide range of programming tasks, from core operations to extended features. The primary function of this directory is to facilitate efficient development by offering a clear roadmap of the available libraries and directing users to the official, comprehensive external documentation hosted on the Huawei developer site for in-depth API specifications. This resource is suitable for Cangjie developers, software engineers, and technical architects who need to understand the library's modular organization, locate specific functional references, and access authoritative documentation to build robust applications. By bridging the gap between local structure and external detail, it ensures that users can quickly find the tools they need without getting lost in the complexity of the full API specification.
