# RPC错误码

This directory contains technical documentation for Remote Procedure Call (RPC) error codes, specifically focusing on system-level troubleshooting and debugging. It covers a range of issues including memory allocation failures, JavaScript callback errors, system call failures (like mmap, ioctl), shared memory conflicts, and IPC permission issues. The documents provide structured guidance with error messages, descriptions, root causes, and handling steps. This resource is suitable for system developers, software engineers, and system administrators who need to diagnose and resolve runtime errors in inter-process communication environments, particularly those involving shared memory and serialization processes.

## Detailed Description

### 1900011_内存分配失败_3more.md
This document serves as a troubleshooting reference guide for specific system errors, detailing error codes 1900011 through 1900013. It covers three distinct error scenarios: memory allocation failure during serialization, JavaScript callback execution failure, and system call dup failure, each structured with error messages, descriptions, causes, and handling steps. Key takeaways include identifying oversized data as the cause of memory errors, verifying business logic for JS failures, and checking file descriptor limits or validity for system call issues. This reference material targets developers and system administrators debugging runtime issues, requiring knowledge of system resources, JavaScript integration, and serialization processes.

### RPC错误码_11more.md
This document serves as a technical reference guide detailing module-specific RPC error codes to assist developers in troubleshooting inter-process communication and shared memory issues. It covers ten specific error codes (1900001 to 1900010), addressing system call failures like mmap and ioctl, shared memory read/write errors, IPC object permission conflicts, and MessageSequence data handling. Each entry provides the error message, description, potential causes, and specific handling steps, such as verifying memory limits or distinguishing between Proxy and RemoteObject operations. Intended for system developers, this guide requires prerequisite knowledge of IPC mechanisms, Ashmem, and data serialization for effective debugging.
