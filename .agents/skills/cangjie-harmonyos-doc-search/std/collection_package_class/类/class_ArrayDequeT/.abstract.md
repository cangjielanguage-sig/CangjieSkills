This directory provides comprehensive API reference documentation for the `ArrayDeque` class within the Cangjie programming language. It details a high-performance, resizable double-ended queue implementation that utilizes a circular array structure to ensure O(1) operational efficiency for insertions and deletions at both ends. The documentation covers essential class definitions, constructors, properties like capacity and size, and manipulation methods such as `addFirst`, `removeLast`, and `reserve`. Furthermore, it explains conversion utilities like `toArray` and string representation interfaces. This resource is specifically designed for Cangjie developers seeking to implement efficient, dynamic collections in their applications. To effectively utilize this guide, readers should possess a working knowledge of generic types and interfaces. Key topics include memory management, capacity growth strategies, and data structure optimization.
