This directory contains API documentation for the `BufferedInputStream<T>` class in the Cangjie standard library, designed to optimize data reading by wrapping input streams with buffering capabilities. It covers the class definition, initialization methods, and extensions for resource management and seekable operations. Key topics include buffer configuration, automatic cleanup via the `Resource` interface, random access via the `Seekable` interface, and core reading functions. This documentation is suitable for Cangjie developers looking to implement efficient I/O operations, manage stream lifecycles, and handle buffered data streams with generic types.
