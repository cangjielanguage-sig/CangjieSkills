This directory contains API reference documentation for mathematical utility functions within the Cangjie standard library's numeric package. It covers a range of operations for arbitrary-precision integers (`BigInt`) and decimal numbers (`Decimal`), including absolute value calculation, greatest common divisor (GCD), least common multiple (LCM), rounding, square roots, and bit manipulation tasks like counting trailing zeros. These documents provide function signatures, parameter descriptions, return types, and verified code examples. This resource is suitable for Cangjie developers implementing complex mathematical logic or high-precision arithmetic in their applications.
