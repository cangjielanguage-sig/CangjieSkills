# UInt32

This directory serves as a comprehensive repository for API reference documentation regarding the UInt32 type in the Cangjie programming language. It meticulously details the definition, behavior, and extended functionalities of 32-bit unsigned integers, which represent values ranging from 0 to 2^32 - 1. The content encompasses core type definitions, static properties for maximum and minimum values, and critical interface implementations including Comparable, Countable, and Hashable. Furthermore, it documents specific functions for value comparison, wrapping arithmetic, position retrieval, and hash code generation. The directory also includes documentation on extending the type to support string conversion via the ToString interface. This technical resource is intended for Cangjie developers seeking to understand type behaviors, perform mathematical operations, and handle data representation for unsigned integers in their software projects.
