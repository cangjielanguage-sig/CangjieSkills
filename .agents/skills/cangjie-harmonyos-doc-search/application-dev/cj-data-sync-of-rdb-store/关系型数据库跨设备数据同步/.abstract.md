This directory provides comprehensive technical resources for implementing cross-device synchronization for relational databases, specifically designed to ensure data consistency across multiple devices in a distributed environment. It covers essential technical concepts such as distributed tables, encrypted channels, and the underlying operational mechanisms required for seamless data management. The documentation details the complete synchronization process, including local and distributed data change notifications, and outlines specific constraints like database limits and key exclusions. Designed for application developers, particularly those working with the Cangjie language and HarmonyOS architecture, these guides offer both theoretical background and practical coding steps for managing distributed data effectively. Please note that the features described are currently in Beta.
