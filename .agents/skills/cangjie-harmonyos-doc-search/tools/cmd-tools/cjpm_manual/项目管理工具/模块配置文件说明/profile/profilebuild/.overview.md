# profilebuild

本目录包含关于 `cjpm` 构建工具中 `[profile.build]` 配置部分的详细文档。它主要涵盖了编译优化选项（如 LTO）、性能分析功能以及实验性的动态库合并（combined）配置。这些文档旨在帮助开发者通过调整构建配置来优化编译性能、分析资源消耗，并解决因模块合并配置引发的循环依赖问题。适用于需要深入定制构建流程或处理复杂二进制依赖关系的开发者。

## 详细描述

### profilebuild_1.md
本文档详细说明了构建配置文件中 `[profile.build]` 部分的各项配置项，用于控制编译优化、性能分析及模块链接策略。主要涵盖链接时优化（LTO）模式选择、编译性能分析开关，以及实验性的 `combined` 动态库合并编译配置。关键信息包括：`lto` 提供全局优化与编译时间的权衡；`performance_analysis` 生成耗时与内存分析文件；`combined` 配置将模块打包为单一动态库以简化依赖分发，但该特性目前仅限特定平台且存在循环依赖风险。这是一份面向使用 `cjpm` 构建工具的开发者的参考文档，适用于需要优化编译性能或管理复杂二进制依赖的场景。

### profilebuild_2.md
本文档旨在指导开发者解决构建过程中因模块配置为 combined 而引发的循环依赖报错问题。文档主要涵盖两类报错场景：单一 combined 模块内部子包与根包的循环依赖，以及两个 combined 模块之间的相互依赖。核心解决方案包括查找并删除子包中对根包的导入、删除模块间的相互导入，或者直接移除模块的 combined 配置以打破循环依赖。适用于遇到构建报错的开发者，需具备模块依赖和配置管理的基础知识。
