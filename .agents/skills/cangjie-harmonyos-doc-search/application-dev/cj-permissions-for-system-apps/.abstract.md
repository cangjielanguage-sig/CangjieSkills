This directory serves as a specialized technical repository focused on the complex landscape of system-level permissions within the OpenHarmony and HarmonyOS operating environments. It specifically addresses the Access Control List (ACL) enablement process required for sensitive system applications, providing a critical framework for managing high-risk device capabilities. The content provides a detailed inventory of permissions introduced from API version 12 onwards, covering critical functional domains including account management, casting, factory operations, security protocols, and telephony. By outlining the `system_grant` authorization model and restrictions for `system_basic` and `system_core` levels, this guide is an indispensable tool for system application developers, security architects, and device integrators. It is designed to assist professionals in securely implementing privileged functionalities and ensuring compliance with strict platform security standards, ultimately facilitating the development of robust and secure system applications.
