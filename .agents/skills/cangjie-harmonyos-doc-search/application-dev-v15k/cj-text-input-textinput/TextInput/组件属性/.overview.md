# 组件属性

This directory contains API reference documentation for configuring properties of UI components, specifically focusing on the TextInput component within the ArkUI framework using the Cangjie language. It covers a wide range of functionalities including text styling, input validation, cursor management, password handling, and layout behaviors. Developers will find detailed specifications for functions related to decoration, font adaptation, selection, and error states. This documentation is suitable for software engineers and UI developers building HarmonyOS applications who need granular control over text input appearance and interaction logic.

### func_passwordIconAppResour_6more.md

### func_underlineColorColor_C_2more.md
This document serves as API reference material for configuring text styling properties within the Cangjie ArkUI framework.
