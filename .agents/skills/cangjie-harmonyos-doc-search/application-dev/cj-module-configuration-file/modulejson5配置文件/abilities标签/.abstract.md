This directory contains comprehensive documentation for configuring the `abilities` tag within HarmonyOS application manifests (`module.json5`). It covers the definition, structure, and detailed attribute configuration for `UIAbility` components, including launch modes, permissions, background tasks, window dimensions, and multi-window behaviors. The resources range from conceptual overviews to specific attribute references and practical JSON examples. Suitable for HarmonyOS application developers and system engineers looking to define component capabilities, manage lifecycle behaviors, and implement features like cross-device migration and process isolation.
