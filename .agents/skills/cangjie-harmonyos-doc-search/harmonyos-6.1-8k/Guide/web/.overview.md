# web

This directory contains comprehensive documentation and technical guides for developing with the ArkWeb component within the HarmonyOS/OpenHarmony ecosystem. It covers a wide range of topics, including component architecture, page loading mechanisms, scrolling control, security features like Secure Shield Mode, and debugging tools. The content is tailored for developers using the Cangjie language or ArkUI framework who need to integrate web content, manage complex interactions, or ensure application stability and security. Key areas include PDF preview, dark mode adaptation, crash analysis, and safe area management.

## Detailed Description

### [1] README_zh/
This directory contains the index for the ArkWeb component development guide, specifically targeting Beta version features. It comprehensively covers core development areas, including basic property configuration (e.g., User-Agent, dark mode), complex web interaction management (e.g., nested scrolling), strict network security and privacy mechanisms (e.g., Secure Shield Mode), efficient web loading processes, diverse content handling capabilities (e.g., PDF preview, safe area adaptation), and professional debugging tools (e.g., DevTools integration, crash collection). This guide aims to help developers with basic Web knowledge efficiently integrate ArkWeb into HarmonyOS applications.

### [2] cj-web-component-overview/
This directory provides a comprehensive overview of the ArkWeb component, helping developers understand its technical details and value. The content covers the component's definition, applicable scenarios, core capabilities, and usage constraints. It elaborates on application integration, browser building, and mini-program development, while analyzing the Chromium M114 kernel-based page loading mechanism, lifecycle management, interaction logic, security policies, and maintenance capabilities. Key topics include JS interaction, incognito mode, ad blocking, and same-layer rendering. It targets professionals embedding Web content or developing browsers and mini-programs.

### [3] cj-web-content-scrolling/
This directory introduces how to implement Web page content scrolling control using the Cangjie language in the ArkWeb component. It covers calling `WebviewController` interfaces (like `scrollTo` and `scrollBy`), generating smooth scrolling animations, and forcibly interrupting animations. The document provides complete Cangjie code examples and HTML configurations, suitable for developers requiring fine-grained control over Web view scrolling behaviors. Note that these features are currently in the Beta stage.

### [4] cj-web-crashpad/
This directory provides a technical guide on `cj-web-crashpad`, focusing on crash collection and deep analysis for the Web component. It details how to use the Crashpad tool to capture critical data during process crashes, including crash file generation paths and storage mechanisms within the application's main process sandbox directory. Core content covers using `minidump_stackwalk` to parse binary `.dmp` files for detailed stack information and using `llvm-addr2line` to map memory addresses back to specific source code locations. This helps developers quickly locate crash causes and register states.
