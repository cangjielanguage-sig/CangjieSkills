This directory contains API reference documentation for the `ohos.user_auth` module in the Cangjie programming language, designed for the OpenHarmony (OHOS) system. It covers user identity verification features, including biometric authentication (Face, Fingerprint), PIN codes, and device unlocking mechanisms. Key components include authentication parameters, result handling, trust levels, and UI customization. The documentation targets developers building secure applications requiring identity and access management, utilizing the SystemCapability.UserIAM.UserAuth.Core capability. It provides essential classes, enums, and functions to implement robust authentication flows and manage credential states effectively.
