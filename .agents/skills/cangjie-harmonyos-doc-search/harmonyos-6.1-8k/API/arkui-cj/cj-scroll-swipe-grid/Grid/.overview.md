### 示例代码.md 示例代码.md
本文档旨在通过Cangjie代码示例，演示Grid组件中columnsTemplate属性的自适应列数设置方法。文档主要涵盖了auto-fill、auto-fit和auto-stretch三种模式的具体应用场景。关键信息包括：auto-fill根据设定列宽自动计算列数；auto-fit将剩余空间均分至每一列；auto-stretch则将剩余空间均分至列间距。该文档属于代码教程，面向熟悉Cangjie语言及ArkUI框架的开发者，旨在帮助其掌握Grid组件的高级布局技巧。
