# Font

This directory contains documentation and resources for managing fonts within the ArkUI framework using the Cangjie programming language. It covers the essential APIs for registering custom fonts, retrieving system font lists, and querying specific font metadata. Key components include the `Font` class for management operations and the `FontInfo` class for defining font properties. This content is suitable for HarmonyOS application developers who need to implement custom typography or inspect system font capabilities in their projects.

## Detailed Description

### Font_3more.md Font_3more.md
This document provides API reference documentation for the ArkUI Font class, enabling developers to manage and register custom fonts. It details the class structure and three key methods: retrieving specific font information via getFontByName, listing available system fonts, and registering custom font files using registerFont. Crucially, users must first obtain a Font instance through the UIContext.getFont() method. The documentation specifies parameters, return values, and potential exceptions like invalid input errors. Intended for application developers using ArkUI system capabilities, this guide requires familiarity with the Cangjie language and resource management.

### class_FontInfo.md class_FontInfo.md
This document serves as an API reference for the FontInfo class in the Cangjie programming language, detailing the properties used to describe font metadata. It covers the class definition and individual property documentation for attributes such as family name, weight, width, style flags like italic and monospace, and the font file path. Key information includes that all properties are public, readable, and writable, belonging to the SystemCapability.ArkUI.ArkUI.Full system capability starting from version 22. This reference is intended for Cangjie developers working with the ArkUI framework who need to programmatically access or define font characteristics in their applications.

### 示例代码.md 示例代码.md
This document provides practical Cangjie code examples for font management within HarmonyOS ArkUI applications. It covers three distinct scenarios: registering custom fonts from resource files, retrieving the list of available system fonts, and querying detailed metadata for a specific font by name. The examples demonstrate the usage of the getUIContext().getFont() API, including methods like registerFont, getSystemFontList, and getFontByName, alongside pattern matching for handling font attributes. This guide targets HarmonyOS developers using the Cangjie language who need to implement custom typography or inspect system font capabilities.
