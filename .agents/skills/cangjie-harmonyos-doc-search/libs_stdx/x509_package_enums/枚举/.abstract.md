This directory serves as a specialized collection of API reference documentation for enumeration types defined in the Cangjie programming language, specifically targeting cryptographic mechanisms used within digital certificates. It provides in-depth technical specifications for public key algorithms and signature algorithms, detailing their supported variants, functional methods, and interface inheritance structures. Key technical concepts covered include RSA, DSA, ECDSA, SHA256, Equatable interfaces, and X.509 standards. This documentation is essential for developers, security architects, and systems engineers working on secure communication protocols, certificate validation logic, and cryptographic implementations in the Cangjie ecosystem.
