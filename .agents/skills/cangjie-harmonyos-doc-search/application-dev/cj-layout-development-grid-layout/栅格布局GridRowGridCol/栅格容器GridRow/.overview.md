# 栅格容器GridRow

This directory provides comprehensive technical documentation for the GridRow component within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers fundamental aspects of grid layout design, including the configuration of total columns, management of arrangement directions, and implementation of spacing (gutters). Additionally, it details the responsive breakpoint system necessary for building adaptive user interfaces across various devices. This resource is ideal for UI developers and software engineers seeking to master dynamic, multi-device layout strategies using ArkUI and Cangjie.

## Detailed Description

### 布局的总列数.md 布局的总列数.md
This technical guide explains how to configure the total number of columns in the GridRow component within the ArkUI framework using the Cangjie language. It covers three configuration methods: the default 12-column setting, custom integer values for fixed layouts, and responsive configurations using GridRowOptions across various breakpoints (xs, sm, md, lg, xl, xxl). Key takeaways include understanding the fallback logic for unspecified breakpoints and how column counts affect child element distribution. This tutorial targets ArkUI developers seeking to implement adaptive grid layouts for multi-device applications.

### 排列方向_2more.md 排列方向_2more.md
This technical guide explains how to configure the arrangement direction and spacing of child components within the GridRow layout system. It covers two main properties: direction for controlling the flow of child elements and gutter for managing horizontal and vertical spacing. Key takeaways include using GridRowDirection.Row or RowReverse to set layout flow, and utilizing the gutter attribute with either a Length value for uniform spacing or a GutterOption object for distinct x and y axis distances. The document targets UI developers using the Cangjie language who need to customize grid layouts for specific design requirements.

### 栅格系统断点.md 栅格系统断点.md
This document defines the grid system's breakpoint rules for implementing responsive layouts based on device width. It covers the default breakpoint ranges (xs, sm, md, lg) and explains how to customize them using the GridRow component to support up to six sizes (xs to xxl). Key information includes defining breakpoints via a monotonically increasing array of viewport pixel values and setting the reference to window size for dynamic layout switching. The document provides a Cangjie code example demonstrating how to adjust column spans across different breakpoints. This technical guide is intended for developers using the ArkUI framework to build adaptive user interfaces.
