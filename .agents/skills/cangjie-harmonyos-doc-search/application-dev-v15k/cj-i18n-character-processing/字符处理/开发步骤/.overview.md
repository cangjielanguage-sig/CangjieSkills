# 开发步骤

This directory provides comprehensive development guides for implementing advanced text processing features within the LocalizationKit framework using the Cangjie programming language. It focuses on essential internationalization (i18n) tasks, including identifying character attributes, performing text transliteration (such as converting Chinese to Pinyin), normalizing character forms, and managing text segmentation for line breaking. These documents are specifically tailored for software developers and engineers who need to build robust, multilingual applications that adhere to Unicode standards and locale-specific formatting rules. By following these step-by-step tutorials, developers can effectively utilize classes like Unicode, Transliterator, Normalizer, and BreakIterator to handle complex text transformations and ensure proper display across different languages and regions.

## Detailed Description

### 字符属性_2more.md
This document serves as a development guide for utilizing character property checks and text transliteration features within the LocalizationKit framework using the Cangjie language. It covers two primary topics: Character Properties, which involves identifying character categories like digits, letters, right-to-left scripts, and ideographs, and Transliteration, which converts text such as Chinese characters into phonetic representations like Pinyin. Key information includes the usage of the Unicode class for type checking and the Transliterator class for text transformation, with specific attention to methods like isDigit, getType, and transform. The guide also notes limitations regarding polyphone context handling. Intended for developers working on internationalization, this tutorial provides step-by-step instructions and code examples to implement these localization features effectively.

### 字符标准化_2more.md
This document serves as a development guide for implementing character normalization and line breaking using the LocalizationKit in the Cangjie programming language. It covers two primary functionalities: character normalization using the Normalizer class and text segmentation for line breaking using the BreakIterator class. The guide details specific normalization forms like NFC and NFD, alongside methods for navigating text boundaries based on locale settings, complete with executable code examples. It targets software developers working on internationalization who need to handle text processing and formatting rules.
