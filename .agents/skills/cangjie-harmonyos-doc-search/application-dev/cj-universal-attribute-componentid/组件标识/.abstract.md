This directory provides comprehensive documentation for the ArkUI framework's component identification module within the Cangjie language ecosystem. It details the mechanisms for assigning unique identifiers to UI components, facilitating precise targeting and manipulation. The content covers core APIs like `id` and `key`, practical code examples for property retrieval, and advanced extension capabilities designed for automated testing scenarios. These tools allow for component inspection, event simulation, and tree traversal. This resource is specifically tailored for ArkUI developers and QA engineers aiming to implement robust UI testing and component management strategies.
