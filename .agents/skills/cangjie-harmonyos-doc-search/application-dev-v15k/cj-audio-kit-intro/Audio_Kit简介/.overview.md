# Audio_Kit简介

This directory provides a foundational overview of Audio Kit, a robust service engineered to deliver scenario-based audio playback and recording interfaces with a focus on high-definition capture and immersive playback experiences. The content encompasses the complete system architecture, detailing the interaction between the Application layer, FFI, Native Framework, SystemAbility, HAL, and the Kernel.
