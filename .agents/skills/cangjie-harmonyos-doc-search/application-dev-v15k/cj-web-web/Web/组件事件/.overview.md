# 组件事件

This directory contains API reference documentation for event handling within the Cangjie language and HarmonyOS ArkUI framework, specifically focusing on Web components. It covers a wide range of event callbacks including ad blocking, dialog management, page lifecycle tracking, download handling, and system permission requests. Key topics include `WebviewController` binding, JavaScript interaction, and security protocols for accessing hardware like cameras and microphones. This resource is designed for software developers seeking granular control over web interactions, resource loading, and user permissions in their applications.

### func_onAdsBlockedAdsBlocke_5more.md func_onAdsBlockedAdsBlocke_5more.md
This document serves as API reference documentation for Cangjie language event handlers within Web and ArkUI components. It details five specific callback functions: onAdsBlocked, onAlert, onBeforeUnload, onConfirm, and onConsole. Key information includes the throttling logic for ad blocking notifications and the Boolean return mechanism for dialog events, which enables developers to suppress default browser behaviors and implement custom user interfaces. Each function specifies required system capabilities and parameters. The target audience is software developers building HarmonyOS applications who require granular control over web page interactions, JavaScript console messages, and ad filtering events.

### func_onControllerAttached__6more.md func_onControllerAttached__6more.md

### func_onPromptOnPromptEvent_2more.md func_onPromptOnPromptEvent_2more.md
This document serves as API reference documentation for configuring WebView behaviors in the Cangjie programming language. It details two specific functions: onPrompt, which handles JavaScript prompt events, and onlineImageAccess, which manages network image loading permissions. Key takeaways include that onPrompt requires a boolean return value to enable custom dialogs and subsequent WebResult notifications, while onlineImageAccess defaults to allowing HTTP and HTTPS resources. This guide is intended for application developers integrating web components who need to control user interactions and resource access. Keywords: Cangjie, WebView, API, onPrompt, onlineImageAccess, JavaScript, HTTP, HTTPS.

This directory provides a specialized technical overview focused on managing media permissions within the HarmonyOS development environment. This dual perspective makes it a valuable reference for building secure, interactive applications that require seamless integration between native OS controls and web-based multimedia functionalities.
