This directory provides comprehensive API reference documentation for the `FormParam` enum within the Cangjie programming language, tailored for the HarmonyOS ecosystem. It details the structure and usage of enumeration members that serve as keys for accessing various form parameters, such as form identity, dimensions, and bundle names. The documentation also includes utility functions for retrieving these values and defines system capabilities and version requirements. It ensures developers have the necessary mappings to interact correctly with the underlying system. This resource is essential for Cangjie developers involved in form creation and management, specifically those implementing card-based features requiring precise parameter handling and system integration.
