# cj-apis-file_statvfs

This directory serves as a comprehensive repository for API reference documentation regarding the `ohos.file_statvfs` module, a vital component for developers utilizing the Cangjie programming language in the HarmonyOS ecosystem. It is specifically designed to assist developers in retrieving and managing file system storage statistics, a crucial aspect of application performance and resource management. The documentation centers on the `Statfs` class, providing in-depth details on its static methods, `getFreeSize` and `getTotalSize`, which are essential for querying storage metrics. Key topics include method parameters (file path strings), return values (Int64 bytes), and exception handling strategies. Furthermore, the guide outlines necessary technical prerequisites, such as importing `kit.CoreFileKit`, and defines system capabilities like `SystemCapability.FileManagement.File.FileIO` supported from API version 19. This resource is indispensable for Cangjie developers, system architects, and software engineers who need to integrate precise storage monitoring, handle file I/O constraints, and ensure their applications adhere to HarmonyOS system requirements while delivering a seamless user experience.

### cj-apis-file_statvfs.md cj-apis-file_statvfs.md

This document serves as API reference documentation for the ohos.file_statvfs module in the Cangjie programming language, designed to retrieve file system storage statistics. It covers the Statfs class, specifically detailing the static methods getFreeSize and getTotalSize, including their parameters, return values, and exceptions. Both methods accept a file path string and return an Int64 representing free or total bytes. The module requires importing kit.CoreFileKit and supports system capability SystemCapability.FileManagement.File.FileIO starting from version 19. This guide targets Cangjie developers building HarmonyOS applications who need to monitor storage usage.
