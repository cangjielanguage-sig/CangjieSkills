This directory serves as a comprehensive technical resource for the `ohos.cj_leakwatcher` module, a critical component of the PerformanceAnalysisKit tailored for OpenHarmony Cangjie applications. It provides in-depth information on detecting and managing memory leaks, which is a vital aspect of ensuring application stability and performance. The documentation thoroughly covers the `CJLeakWatcher` class, outlining methods to activate detection, monitor specific objects with custom tags, and generate detailed reports on suspected leaks. By utilizing these tools, developers can effectively identify objects that persist beyond their expected lifecycle. This content is specifically designed for Cangjie developers and performance engineers who need to diagnose complex memory issues, optimize resource allocation, and ensure robust performance within the SystemCapability.HiviewDFX.HiChecker framework.
