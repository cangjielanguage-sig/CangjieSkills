This directory contains API reference documentation for the `ohos.multimedia_media` module in the Cangjie programming language, designed for HarmonyOS multimedia application development. It covers comprehensive media functionalities including audio/video playback, recording, transcoding, screen capture, and metadata extraction. Key components include classes for AVPlayer, AVRecorder, and AVImageGenerator, alongside various enums for configuration and state management. This documentation is suitable for software developers and multimedia engineers seeking to integrate robust media capabilities into their Cangjie-based projects.
