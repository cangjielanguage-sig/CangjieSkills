This directory contains API reference documentation for the `FormExtensionAbility` class in the Cangjie programming language, designed for HarmonyOS developers building form widgets (cards). It covers the class definition, initialization via `registerCreator`, and comprehensive lifecycle management methods including creation, updates, visibility changes, and destruction. Key topics include `FormBindingData`, `Want` parameters, and system configuration handling. This resource is suitable for developers implementing dynamic card functionality and managing form states within the HarmonyOS ecosystem using Cangjie.
