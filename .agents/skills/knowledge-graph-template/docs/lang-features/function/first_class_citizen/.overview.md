# first_class_citizen

本目录深入探讨了仓颉编程语言中“函数作为一等公民”这一核心特性及其相关的类型系统设计。文档详细解析了函数类型的定义语法，即如何通过 `->` 符号连接参数类型与返回类型，并阐述了参数名的标记规则。核心内容涵盖了函数类型作为参数传递、作为返回值返回以及作为变量存储的具体应用场景，同时深入讲解了在处理函数重载时可能出现的歧义问题及其解决方案。该文档是仓颉语言开发者的必备技术参考，旨在帮助开发者熟练掌握高阶函数的编程技巧及复杂的类型推导规则，从而编写出更加简洁、高效的代码。
