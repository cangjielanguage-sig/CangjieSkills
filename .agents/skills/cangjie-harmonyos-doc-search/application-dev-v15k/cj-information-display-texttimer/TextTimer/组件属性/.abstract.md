This directory contains API reference documentation for component properties within the Cangjie ArkUI framework, focusing primarily on text styling and visual effects. It covers methods for manipulating font attributes such as color, family, size, and weight, as well as advanced text shadow configurations. These resources are designed for HarmonyOS developers using the Cangjie language to customize UI text appearance and add visual depth to their applications. Key topics include ResourceColor handling, FontStyle, and shadow parameters like blur radius and offsets, supporting API version 19 and above.
