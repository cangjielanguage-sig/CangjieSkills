# 组件事件

This directory serves as a repository for API reference documentation regarding event handling functions within the Cangjie ArkUI framework. It specifically focuses on events associated with UI components, particularly those involving text manipulation, clipboard interactions, and input method management. The documentation covers essential functionalities such as overriding default paste behaviors, tracking text content modifications, and handling complex IME (Input Method Editor) lifecycles. These resources are designed for developers utilizing the Cangjie language who require granular control over component behaviors, such as implementing custom clipboard logic or responding to specific user inputs in text editing scenarios.

## Detailed Description

### func_onPastePasteEventCall_2more.md
This document provides API reference documentation for two event handling functions within the Cangjie ArkUI framework. It details the `onPaste` and `onDidChange` methods, including their syntax, parameters, and system capabilities. The `onPaste` function enables developers to override default system behavior for text and image pasting by intercepting the event before completion. The `onDidChange` function triggers specifically after add or delete operations, providing text ranges before and after changes, but only if actual content modification occurred. Intended for developers implementing custom clipboard logic or monitoring text content changes in UI components, this guide requires knowledge of Cangjie syntax and ArkUI development. Keywords: Cangjie, ArkUI, API, event callback, paste, text range.

### func_onReadyVoidCallback_6more.md
This API reference document outlines event handling functions for the ArkUI RichEditor component in the Cangjie language. It details six key methods: onReady, aboutToImeInput, onImeInputComplete, onDeleteComplete, aboutToDelete, and onSelect. These functions manage component initialization, text selection, and input method (IME) interactions, allowing developers to intercept or respond to content insertion and deletion events. Key takeaways include the specific callback types for each event and the ability to control IME actions via boolean returns. This documentation targets developers implementing advanced text editing capabilities within the ArkUI framework.
