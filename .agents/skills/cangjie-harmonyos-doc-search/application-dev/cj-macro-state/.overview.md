# cj-macro-state

This directory serves as a comprehensive resource for developers working with the ArkUI framework and the Cangjie programming language, specifically focusing on state management mechanisms. It provides in-depth documentation and resources regarding the `@State` decorator, which is essential for managing internal component state. The content covers critical aspects such as API definitions, variable initialization rules, supported data types, and the specific constraints that govern state behavior. Furthermore, it explains how state changes trigger UI updates and details the observation behaviors necessary for reactive programming. This directory is highly suitable for HarmonyOS developers and Cangjie programmers who aim to master state management, optimize rendering performance, and ensure the stability of their applications by understanding the intricacies of component-level state.
