# 运作机制

This directory covers the operational mechanisms of the Unified User Authentication Framework, focusing on the intersection of user identity verification and secure key access. It provides a comprehensive look at how authentication trust is quantified and technically implemented within a secure environment. Key topics include the definition of Authentication Trust Levels (ATL) based on security metrics like FRR, FAR, and SAR, as well as the architectural details of AuthToken generation within a Trusted Execution Environment (TEE). This documentation is essential for developers, security architects, and system integrators who need to design robust authentication protocols or integrate secure key management services into their applications.

## Detailed Description

### 认证可信等级划分原则.md 认证可信等级划分原则.md
This reference document defines the classification principles for Authentication Trust Levels (ATL) used to evaluate system security. It introduces three core metrics: FRR, FAR, and SAR, explaining their relationship to security and convenience. The content details four distinct levels (ATL1 to ATL4), specifying threshold requirements for each metric alongside examples like secure PINs, 3D facial recognition, and voiceprints. It maps these levels to specific scenarios, ranging from high-security small payments (ATL4) to low-risk personalized services (ATL1). This guide is intended for developers and security architects designing authentication mechanisms.

### 运作机制_2more.md 运作机制_2more.md
This document explains the architecture and operating mechanism of the Unified User Authentication Framework, detailing how user identity verification integrates with secure key access. Key sections include the framework architecture comprising four components (API, framework, widgets, capabilities), the authentication flow generating AuthTokens, and the detailed AuthToken data structure specifications. The framework issues AuthTokens within a Trusted Execution Environment (TEE) upon successful authentication via password, face, or fingerprint. These tokens authorize applications to access the Universal Keystore Service. The AuthToken structure comprises plaintext fields for verification, encrypted user and credential IDs, and integrity protection tags. Intended for developers and system architects, this technical reference guides the integration of user authentication for secure key operations, requiring an understanding of Trusted Execution Environments and cryptographic concepts.
