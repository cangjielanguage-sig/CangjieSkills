This directory serves as a centralized repository for technical documentation regarding the application sandbox mechanism specifically designed for the OpenHarmony operating system. It provides an in-depth exploration of the architectural frameworks that govern file isolation, ensuring that applications operate within secure, confined environments. The content covers critical technical areas such as the complex path mapping relationships between virtual sandbox views and the underlying physical file systems, as well as robust data security protocols. Key technical concepts detailed herein include the hierarchy of encryption levels ranging from EL1 to EL5, granular access permissions, and the structural differences between App-level and HAP-level storage. This documentation is primarily intended for application developers and system integrators who require a deep understanding of secure data handling, file persistence management, and the architectural nuances necessary to build secure and compliant applications within the OpenHarmony ecosystem.
