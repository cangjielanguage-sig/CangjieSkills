This directory contains API reference documentation for core data structures within the Cangjie Crypto and X.509 packages. It covers essential structs used for handling cryptographic data, including binary encoding (DER, PEM), certificate extensions (KeyUsage, ExtKeyUsage), and certificate management (SerialNumber, Signature, VerifyOption). Additionally, it details structures for creating certificate signing requests and managing certificate information. These documents are designed for Cangjie developers and security engineers implementing low-level cryptographic operations, SSL/TLS protocols, and identity management systems, providing the necessary definitions and methods to parse, validate, and generate security artifacts.
