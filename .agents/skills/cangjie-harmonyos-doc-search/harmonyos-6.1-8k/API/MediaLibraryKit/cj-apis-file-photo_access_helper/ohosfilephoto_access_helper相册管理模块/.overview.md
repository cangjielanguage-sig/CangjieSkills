# ohosfilephoto_access_helper相册管理模块

本模块是HarmonyOS系统中基于仓颉（Cangjie）语言的相册管理API参考文档，旨在提供完整的媒体库访问与管理能力。内容涵盖相册与资源的增删改查、变更监听、元数据处理及权限配置等核心功能。主要涉及PhotoAccessHelper、Album、PhotoAsset等关键类，适用于使用仓颉语言开发文件管理、相册或多媒体应用的开发者，帮助其高效实现系统媒体数据的交互与操作。

## 详细描述

### class_AbsAlbum.md class_AbsAlbum.md
定义相册管理接口，包含名称、类型、URI及文件数量等属性，以及用于检索相册内资源的getAssets方法。文档说明了属性的读写限制、方法所需的READ_IMAGEVIDEO权限及异常处理机制。

### class_Album.md class_Album.md
表示系统中的实体相册，涵盖类定义及用于统计图片和视频数量的只读属性（imageCount和videoCount）。包含用于将属性修改更新到数据库的commitModify方法，需WRITE_IMAGEVIDEO权限。

### class_ChangeData_2more_afb14251.md class_ChangeData_2more_afb14251.md
定义PhotoAccessHelper核心能力中的ChangeData和CreateOptions类。ChangeData用于返回相册文件变动URI，CreateOptions用于配置媒体创建参数（如标题和subtype），标题长度限制为1至255。

### class_FetchOptions_730dc509.md class_FetchOptions_730dc509.md
定义照片和相册的检索条件。包含用于指定查询列名的fetchColumns和用于设置过滤条件的predicates属性，以及类的构造函数，旨在帮助构建精确的数据查询请求。

### class_FetchResult.md class_FetchResult.md
表示文件检索结果集，介绍了close、getCount以及isAfterLast三个核心方法。文档包含系统能力声明、返回值类型说明及BusinessException错误码处理。

### class_PhotoCreationConfig.md class_PhotoCreationConfig.md
定义保存图片或视频到媒体库的配置参数。涵盖文件扩展名、媒体类型、子类型及标题等核心属性，并说明了标题属性的特定命名规范。

### class_RequestOpti_2more_afd7f67c.md class_RequestOpti_2more_afd7f67c.md
定义RequestOptions类和AlbumKeys枚举。RequestOptions通过deliveryMode属性配置资源请求的分发策略（快速、高质量、均衡），AlbumKeys用于标识相册关键信息。

### enum_AlbumSubtype.md enum_AlbumSubtype.md
定义相册的具体子类型，涵盖UserGeneric、Favorite、Video、Image等枚举成员，以及相等性判断运算符和toString方法。

### enum_AlbumType_8a7080be.md enum_AlbumType_8a7080be.md
定义相册的类型分类，包含User（用户相册）和System（系统预置相册）两个核心枚举值，以及继承的运算符和toString方法。

### enum_DefaultChangeUri.md enum_DefaultChangeUri.md
定义监听相册和照片资源变更的默认URI。详细说明了DefaultAlbumUri和DefaultPhotoUri两个枚举值，它们需配合forChildUris{true}使用。

### enum_DeliveryMode.md enum_DeliveryMode.md
定义PhotoAccessHelper系统的资源分发模式，包括快速模式、高质量模式和均衡模式，同时涵盖了继承的相等性判断运算符和字符串转换方法。

### enum_DynamicRange_2more_44f2ce79.md enum_DynamicRange_2more_44f2ce79.md
定义媒体文件的动态范围类型及PhotoAsset的成员类型。包含DynamicRangeType枚举（Sdr和Hdr）以及MemberType枚举（Int64、String和Bool）。

### enum_NotifyType.md enum_NotifyType.md
定义文件管理和相册访问中的通知事件类型。主要涵盖NotifyAdd、NotifyRemove等成员值及操作符函数，用于处理文件变更监听。

### enum_PhotoSubtype.md enum_PhotoSubtype.md

### enum_PhotoType_c59b97e1.md enum_PhotoType_c59b97e1.md

### enum_PhotoViewMimeTypes.md enum_PhotoViewMimeTypes.md

### enum_ResourceType_6cb9c54b.md enum_ResourceType_6cb9c54b.md
