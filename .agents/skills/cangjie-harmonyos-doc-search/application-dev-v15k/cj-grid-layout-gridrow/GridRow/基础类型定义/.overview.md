# 基础类型定义

This directory contains API reference documentation for fundamental type definitions used in configuring responsive grid layouts within the Cangjie ArkUI framework. It comprehensively covers essential classes and enums required for managing breakpoints, grid row sizing, gutter spacing, and layout directions. Key concepts include responsive thresholds, column configurations, and spacing options across various device sizes ranging from xs to xxl. This documentation is specifically suitable for UI developers and system architects looking to implement adaptive interfaces using ArkUI components, requiring a solid understanding of grid systems and Cangjie syntax.

## Detailed Description

### class_BreakPoints_2more.md class_BreakPoints_2more.md
This API reference documentation defines classes for configuring responsive grid layouts in the Cangjie ArkUI framework. It details the BreakPoints class, which sets breakpoint thresholds and references, and the GridRowColumnOption struct, which defines column counts for various device sizes (xs through xxl). Key information includes the BreakPoints constructor accepting a monotonic array of lengths and a reference type, while GridRowColumnOption defaults to 12 columns. The document explains how input arrays map to specific breakpoint ranges like [0, n0) for xs. Intended for UI developers, this guide facilitates adaptive interface design using system capabilities starting from version 12.

### class_GridRowSizeOption.md class_GridRowSizeOption.md
This API reference document details the GridRowSizeOption class, which configures grid gutter sizes across various device widths in the ArkUI framework. The documentation covers the class definition, six public properties representing device breakpoints (xs, sm, md, lg, xl, xxl), and the class constructor. Key information includes that all properties are of type Length and are read-write. The constructor initializes these values, defaulting to 0.vp, allowing developers to specify spacing for devices ranging from minimum to extra-extra-large widths. This guide targets Cangjie developers building responsive layouts using ArkUI components, requiring knowledge of grid systems and length units.

### class_GutterOption_3more.md class_GutterOption_3more.md
This API reference document defines classes and enums for configuring grid layouts in the Cangjie ArkUI framework. It details the GutterOption class for setting spacing, the BreakpointsReference enum for choosing sizing references, and the GridRowDirection enum for layout orientation. Key information includes GutterOption constructors accepting Length or GridRowSizeOption parameters, and specific rules for GridRowDirection regarding span and offset calculations, such as automatic wrapping when spans exceed column limits. The document is intended for developers utilizing ArkUI system capabilities to implement responsive grid systems, requiring knowledge of grid layout concepts and Cangjie syntax.
