# class_Stream

This directory contains API reference documentation for the Cangjie language's `Stream` class, focusing on file stream management and input/output (I/O) operations. It covers essential functionalities such as reading byte arrays, writing string or byte data, and managing stream lifecycles through methods like `close` and `flush`. The documentation includes detailed parameter definitions, return values, and comprehensive error handling via `BusinessException`. It is suitable for software developers building file management features in HarmonyOS or OpenHarmony applications who need to perform low-level file operations and handle runtime exceptions effectively.
