This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It focuses on navigation and layout customization, including setting back button icons, managing page menus, controlling system bar styles, and configuring navigation titles. Key topics cover layout extension into non-safe areas, menu display limits, and title bar customization. This documentation is suitable for application developers and software engineers working with Cangjie syntax and ArkUI component structures who need to fine-tune the visual and functional behavior of navigation interfaces.
