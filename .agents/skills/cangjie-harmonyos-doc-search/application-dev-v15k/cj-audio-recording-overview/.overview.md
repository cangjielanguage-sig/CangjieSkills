# cj-audio-recording-overview

This directory provides a comprehensive development overview for audio recording functionality, specifically designed to assist developers in navigating the complexities of audio input implementation within the Cangjie and Native environments. It serves as a central guide for selecting the most suitable API based on specific format requirements and usage scenarios. The content covers four distinct primary methods: AudioCapturer, OpenSL ES, and OHAudio for PCM-based professional or native development, alongside AVRecorder for integrated m4a file generation. Key topics include detailed API comparisons and critical development notices regarding permissions and execution contexts. This resource is ideal for developers utilizing Cangjie or Native APIs who need to implement robust audio input functionality, helping them weigh the trade-offs between low-level control and ease of use.
