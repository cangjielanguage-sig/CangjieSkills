This directory serves as a comprehensive technical guide for developers operating within the HarmonyOS/OpenHarmony ecosystem who need to implement email launching capabilities. It focuses specifically on the `mailto` protocol, detailing how to construct valid URIs and configure parameters such as subject, body, cc, and bcc. The documentation covers implementation strategies for both web-based (HTML) and native application environments using the Cangjie language. Furthermore, it explains the `Want` object mechanism for deep linking, enabling apps to both invoke email clients and receive `mailto` requests. This resource is essential for developers seeking to integrate seamless email composition features or handle specific email-related deep links in their applications, ensuring smooth inter-process communication.
