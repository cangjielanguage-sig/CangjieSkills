# cj-common-components-xcomponent

This directory serves as a comprehensive resource for developers working within the HarmonyOS and OpenHarmony ecosystems, focusing on the integration of C++ native libraries with the Cangjie programming language. It specifically addresses the use of the XComponent component to achieve high-performance graphics rendering, such as camera previews and game visuals. The content covers the technical architecture required to bridge Cangjie UI and Native C++ code, utilizing technologies like Foreign Function Interface (FFI), CMake, NativeWindow, EGL, and OpenGLES. It is particularly suitable for graphics engineers and application developers aiming to implement hardware-accelerated visual effects and optimize application performance through native interoperability.

## Detailed Description

### the_minimum_version_of_CMa_2more.md the_minimum_version_of_CMa_2more.md
This technical guide details the integration of a C++ native library with a Cangjie project using CMake and Foreign Function Interface (FFI). The document covers the CMakeLists.txt configuration for building the shared library, the exportffi.cpp glue code that exposes C++ rendering functions to Cangjie, and the necessary build-profile.json5 settings to compile and package the native output. Key information includes linking system libraries like EGL and GLESv3 and defining exported functions for surface management. This guide targets developers building OpenHarmony or HarmonyOS applications that require combining native C++ rendering capabilities with Cangjie code.

### 自定义渲染XComponent/
This directory focuses on the XComponent component within the HarmonyOS ecosystem, specifically tailored for custom rendering scenarios using the Cangjie language. It comprehensively covers the technical architecture required for high-performance graphics, including camera previews and game rendering, by leveraging NativeWindow, EGL, and OpenGLES. Key topics include the self-drawing mechanism, lifecycle management, and the critical bridge between Cangjie UI and Native C++ code via XComponentController and FFI. The content explores how developers can submit buffers to a surface managed by XComponent and handle events efficiently. Furthermore, it details the interaction between the Cangjie framework and native layers, ensuring seamless integration for complex visual tasks. This resource is ideal for developers and graphics engineers seeking to implement hardware-accelerated visual effects and optimize application performance through native interoperability.
