This repository serves as a specialized technical resource for developers utilizing the Cangjie programming language, focusing specifically on the implementation of AES symmetric encryption and decryption using the GCM (Galois/Counter Mode). It provides a thorough examination of the cryptographic workflow, essential for building secure applications. The content covers critical operations such as secure key generation, precise cipher configuration, and the nuances of data processing, including the application of PKCS7 padding. Central to this guide is the usage of the CryptoArchitectureKit, Cangjie's framework for cryptographic operations. By detailing standards like AES128 and the management of authentication tags, this repository is suitable for Cangjie developers ranging from intermediate to expert levels who need to ensure data confidentiality and integrity. It offers a blend of theoretical background and executable code examples to facilitate the secure and efficient handling of sensitive information, making it a vital tool for any security-conscious project in the Cangjie ecosystem.
