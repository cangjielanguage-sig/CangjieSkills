# HAP

This directory serves as a technical resource for HarmonyOS developers, focusing on the HAP (Harmony Ability Package), which is the core unit for application installation and execution. It provides in-depth guidance on the structural aspects of HAPs, including the differences between entry and feature modules, and outlines usage scenarios for single and multi-HAP architectures. The content also covers practical development workflows, such as creating modules in DevEco Studio with the Cangjie template and integrating HAR files. Additionally, it addresses the critical operational phase of debugging and managing HAPs using command-line tools like hdc and bm. This documentation is suitable for developers aiming to master application packaging, resource optimization, and deployment strategies within the HarmonyOS ecosystem.

## Detailed Description

### HAP_5more.md HAP_5more.md
This technical guide defines HAP (Harmony Ability Package) as the fundamental unit for HarmonyOS application installation and execution, detailing its two types: entry and feature modules. It outlines usage scenarios for single and multi-HAP architectures, emphasizing resource optimization and ExtensionAbility support. The document specifies strict constraints regarding configuration consistency, module naming, and signing certificates across HAPs. Additionally, it provides a step-by-step tutorial for creating HAP modules in DevEco Studio using the Cangjie template and mentions HAR integration. Targeted at HarmonyOS developers, this guide serves as a reference for structuring and packaging applications efficiently.

### 调试.md 调试.md
This guide explains how to debug HarmonyOS applications (HAPs) using DevEco Studio or the hdc command-line tool. Key sections include debugging via the IDE and using the hdc tool, specifically focusing on HAP installation and management. The document details two approaches for HAP management: direct installation commands using hdc and using the bm tool after entering hdc shell. It provides specific command examples for installing, updating, and uninstalling HAPs on both local development platforms and remote devices. Intended for HarmonyOS developers, this technical guide assumes familiarity with command-line interfaces and the DevEco Studio environment.
