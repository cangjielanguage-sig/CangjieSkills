## 详细描述

### func_getInspector_5more_328bd783.md
本文档是ArkUI测试相关的API参考文档，旨在提供用于获取组件属性和模拟用户交互的接口。文档详细介绍了五个核心函数：getInspectorByKey（获取指定组件属性）、getInspectorTree（获取组件树）、sendEventByKey（发送点击或长按事件）、sendTouchEvent（发送触摸事件）以及sendKeyEvent（发送按键事件）。关键信息指出所有接口仅用于应用测试且耗时较长，其中getInspectorByKey必须在主线程调用以确保属性完整。这些函数主要面向需要进行UI自动化测试的开发人员，帮助他们验证组件状态和交互逻辑。

关键词：ArkUI, API参考, UI测试, 组件属性, 事件模拟, 自动化测试

### func_sendMouseEventMous_b255c741.md
本文档详细介绍了用于发送鼠标事件的API函数 `sendMouseEvent`，该函数主要用于应用测试场景。文档涵盖了函数签名、系统能力要求、起始版本、必填参数 `event` 的类型说明以及布尔类型的返回值定义。关键信息指出该接口仅用于测试且耗时较长，不建议常规使用；成功发送返回 true，失败返回 false。面向ArkUI应用开发人员，特别是需要进行UI自动化测试的开发者，需具备鼠标事件对象的相关知识。
