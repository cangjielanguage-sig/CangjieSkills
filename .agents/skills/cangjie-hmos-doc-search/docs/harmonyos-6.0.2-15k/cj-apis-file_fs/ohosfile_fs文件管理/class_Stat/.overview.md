# class_Stat

This directory provides comprehensive API reference documentation for the Cangjie Stat class and associated file type inspection utilities. It focuses on encapsulating detailed file metadata, such as access, modification, and status change timestamps, alongside file size, ownership IDs, and permission modes. The content also covers methods for programmatically identifying various file types, including block devices, character devices, directories, named pipes, sockets, and symbolic links. Designed for developers proficient in Cangjie and file I/O concepts, this guide assists in implementing robust file system operations using the CoreFileKit and FileFs.stat.

## Detailed Description

### class_Stat_10more.md
This document serves as API reference documentation for the Cangjie Stat class, which encapsulates detailed file metadata. It covers read-only properties including timestamps for access, modification, and status changes, file size, ownership IDs, and permission modes. A key takeaway is the explanation of the mode property, which defines file permissions using octal values, and the requirement to construct instances via FileFs.stat. Intended for developers working with file system operations, this guide assumes familiarity with the Cangjie language and file I/O concepts.

### func_isBlockDevice_5more.md
This document serves as API reference documentation for the Cangjie programming language, specifically detailing file type inspection methods. It covers five distinct functions: isBlockDevice, isCharacterDevice, isDirectory, isFIFO, and isFile. Each function returns a Boolean value indicating whether a file matches a specific type, such as a block device, character device, directory, named pipe, or regular file. The documentation provides function signatures, functional descriptions, system capabilities, return values, potential exceptions, and usage examples involving FileFs.stat. This reference is intended for software developers implementing file system operations in Cangjie, requiring knowledge of basic file I/O concepts and error handling.

### func_isSocket_2more.md
This API reference document details two specific file type checking functions, isSocket() and isSymbolicLink(), within the Cangjie programming language's file management system. The content is structured into two main sections, each providing the function signature, functionality description, system capabilities, return values, exceptions, and code examples. Key information includes that both functions return a Bool to verify if a file is a socket or a symbolic link, belonging to the SystemCapability.FileManagement.File.FileIO capability starting from version 12. This documentation targets Cangjie developers utilizing the CoreFileKit for file I/O operations who need to programmatically identify specific file attributes.
