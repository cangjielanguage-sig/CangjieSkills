# class_PriKey

This directory contains comprehensive API reference documentation for the `PriKey` class within the Cangjie language's CryptoArchitectureKit. It focuses on the management and manipulation of private keys used in asymmetric cryptographic operations, including encryption, digital signing, and key agreement protocols. The documentation details essential methods for secure memory erasure, key parameter retrieval, and data serialization in both DER and PEM formats. It is designed for developers implementing security features who require a deep understanding of cryptographic frameworks, key generation, error handling, and specific encoding standards like PKCS#8 and PKCS#1.

## Detailed Description

### class_PriKey_3more.md class_PriKey_3more.md
This document provides API reference documentation for the PriKey class in the Cangjie language, designed for handling private keys within the CryptoArchitectureKit. It details the class structure, which inherits from the Key interface, and explains its role in asymmetric cryptographic operations such as encryption, signing, and key agreement. The main sections cover the clearMem() function for securely erasing key content from memory and the getAsyKeySpec() function for retrieving specific key parameters, including parameter types, return values, and potential exceptions like BusinessException. Key information highlights that private keys are generated via AsyKeyGenerator and that calling clearMem() leads to unpredictable behavior in subsequent calls. This technical reference is intended for developers implementing security features, requiring an understanding of cryptographic frameworks and error codes.

### func_getEncodedDerString.md func_getEncodedDerString.md
This API documentation describes the getEncodedDer function in the Cangjie language, which retrieves ASN.1 DER-encoded private key data based on a specified format. The document outlines the function's signature, parameters, return values, and exceptions, specifically noting current support for PKCS8 formatted ECC private keys. It differentiates this method from Key.getEncoded() by its ability to accept a format argument. Key sections include parameter definitions, error codes like 401 and 17630001, and a usage example. This reference material is intended for developers using the CryptoArchitectureKit to manage cryptographic key encoding and requires knowledge of asymmetric key generation.
