# 使用场景

This directory focuses on practical usage scenarios for conditional rendering within the Cangjie ArkUI framework. It comprehensively covers the implementation of `if` statements, nested conditional logic, and the critical impact of conditional branches on component state management and lifecycle. Key topics include state preservation using `@Link` versus `@State`, component destruction and recreation, and handling complex UI updates driven by state variables. Through specific examples like nested statements and state hoisting, it addresses common challenges in dynamic UI development. This resource is suitable for Cangjie developers looking to master dynamic UI layouts, optimize state persistence across view changes, and deeply understand the underlying mechanics of component lifecycle during conditional rendering.

## Detailed Description

### if_else_语句和子组件状态.md
This technical guide illustrates how conditional rendering using if...else statements impacts the state management of child components in Cangjie UI development. It covers two code examples comparing internal @State variables versus parent-owned @Link variables within conditional branches. The document demonstrates that switching if-else branches destroys and recreates child components, resetting internal @State values. To preserve state across these changes, developers must hoist state to the parent component using the @Link decorator. This tutorial targets Cangjie developers needing to manage component lifecycle and state persistence in dynamic UI layouts.

### 使用if进行条件渲染.md
This tutorial guide explains how to implement conditional rendering in Cangjie applications using if statements within the ArkUI framework. It covers the syntax for conditional branches, the execution of build functions, and the lifecycle management of components during state changes. Key takeaways include that each branch creates sub-components, and when state variables change, the framework re-evaluates conditions. If the condition changes, the framework deletes old components and executes the new branch's constructor to add fresh components. This document targets Cangjie developers building dynamic user interfaces who require an understanding of state-driven UI updates and component creation or destruction.

### 嵌套if语句.md
This document serves as a code example demonstrating the implementation of nested conditional statements within the Cangjie UI framework. The primary topic is conditional rendering, specifically showing how nested if statements function without affecting parent component rules. The code snippet illustrates a UI component (EntryView) utilizing two state variables, toggle and toggleColor, to control the display and styling of nested Text elements within a Column. Key takeaways include the syntax for state management and the independence of nested logic scopes. This example is intended for Cangjie developers seeking to understand complex conditional logic in UI development.
