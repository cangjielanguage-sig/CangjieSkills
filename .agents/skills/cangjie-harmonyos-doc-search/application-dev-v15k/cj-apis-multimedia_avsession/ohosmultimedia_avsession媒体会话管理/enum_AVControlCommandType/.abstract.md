This directory contains essential API reference documentation for the `AVControlCommandType` enum within the multimedia AV session framework, specifically designed for developers using the Cangjie language. It details the structure and usage of command types required to manage audio and video sessions effectively. The content covers a wide range of operations, including media playback controls (such as play, pause, seek, and loop mode) and call handling features (like answer, hang up, and mute). Furthermore, it documents utility functions for hash retrieval and string representation. Key technical aspects include inheritance from ToString, Equatable, and Hashable, alongside dependencies on the SystemCapability.Multimedia.AVSession.Core capability starting from API version 19. This documentation is ideal for developers implementing sophisticated multimedia session management and control logic.
