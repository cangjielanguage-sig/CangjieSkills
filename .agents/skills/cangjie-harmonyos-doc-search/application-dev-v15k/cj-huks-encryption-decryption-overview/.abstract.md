This directory serves as a specialized technical resource for developers working with the OpenHarmony HUKS (Harmony Universal KeyStore) framework. It provides a detailed overview of encryption and decryption capabilities, specifically focusing on the algorithm specifications supported across various device categories. The documentation distinguishes between standard and lightweight devices, offering tailored guidance for each environment to optimize performance and security. It covers critical cryptographic algorithms including AES, RSA, SM4, and SM2, outlining their specific block modes, padding schemes, and essential parameters such as IV, Nonce, and TAG. This reference is essential for developers ensuring secure data handling and compliance with API level 15+ requirements in their OpenHarmony applications, helping them navigate the complexities of cryptographic implementation. By utilizing this guide, developers can effectively select the correct algorithm combinations and parameters required for robust security solutions.
