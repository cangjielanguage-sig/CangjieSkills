This directory serves as a comprehensive resource for the `app_check_tool.jar`, a powerful utility specifically engineered to analyze HAP and App installation packages. The documentation provided herein covers a wide range of functionalities, including the detection of duplicate files, the identification of oversized files that may impact performance, and the statistical analysis of file type size distributions. It offers in-depth technical references regarding command-line parameters, the structure of JSON output reports, and necessary system constraints such as the Java 8 environment requirement. This collection is highly suitable for application developers and QA analysts who are focused on optimizing application architecture, troubleshooting package-related issues, and conducting thorough audits of storage distribution to maintain efficient application performance.
