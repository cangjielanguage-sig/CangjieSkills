This directory focuses on the implementation, management, and constraints of keyboard shortcuts within the ArkUI framework using the Cangjie language. It covers the `keyboardShortcut` interface, detailed usage rules, system-level restrictions, and event handling behaviors. Key topics include focus dependencies, conflict resolution, modifier key handling, and prohibited system key combinations. The documentation is designed for HarmonyOS developers who need to enhance user interaction through custom hotkeys while adhering to system constraints and event priorities.
