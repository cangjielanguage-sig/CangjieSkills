# cj-determine-application-mode

本目录提供了关于HarmonyOS应用权限申请模式的决策指南。它详细阐述了如何根据应用权限等级（APL）和授权方式选择正确的申请流程，涵盖了Normal和System_basic等级应用的处理方法，包括权限声明、ACL申请及用户授权等关键步骤。此外，还介绍了调试时提升APL等级的配置方法。本文档适合HarmonyOS应用开发者阅读，旨在帮助开发者准确理解并实施权限管理策略。

## Detailed Description

### cj-determine-application-mode.md
本文档旨在指导开发者根据应用权限等级（APL）和授权方式选择正确的权限申请流程。文档主要涵盖Normal等级和System_basic等级应用的权限申请方式，详细列出了开放权限与受限权限在不同授权模式下的操作路径，包括声明权限、ACL申请及用户授权等步骤。此外，还介绍了如何通过修改配置文件提升应用APL等级以进行调试。本文档面向HarmonyOS应用开发者，提供了权限申请的决策依据和具体操作指南。
