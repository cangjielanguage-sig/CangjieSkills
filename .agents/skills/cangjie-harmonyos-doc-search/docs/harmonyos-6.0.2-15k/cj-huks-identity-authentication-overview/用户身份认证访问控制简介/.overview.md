# 用户身份认证访问控制简介

This directory provides comprehensive documentation on User Identity Authentication and Access Control within the HUKS (HarmonyOS Universal Keystore Subsystem) framework. It covers the mechanisms ensuring secure key storage, including key ownership isolation, user identity verification via passwords or biometrics, and specific usage restrictions for cryptographic algorithms. The content details development workflows, authorization types, and invalidation triggers like password clearing or new biometric enrollment. It is suitable for developers and security engineers implementing high-security features such as passwordless login and secure payments in HarmonyOS applications.

## Detailed Description

### 使用场景及开发流程.md 使用场景及开发流程.md
This technical guide details the usage scenarios and development workflow for user identity authentication and access control within the HUKS system. It covers user authentication prerequisites, three authorization access types defining key invalidation conditions, and challenge value verification for anti-replay security. Additionally, it explains secondary authentication methods, including AuthToken control, batch authorization for multiple keys, and timestamp-based access for high performance. Key takeaways include the binding of keys to device credentials and specific invalidation triggers like password clearing or new biometric enrollment. Intended for developers implementing high-security features such as passwordless login and payments, this document assumes familiarity with secure key management and TEE environments.

### 用户身份认证和授权访问类型详细规格.md 用户身份认证和授权访问类型详细规格.md
This technical reference document specifies the detailed behaviors of user identity authentication and authorization access types for a secure keystore system. It defines abbreviations for authentication methods like PIN, FACE, and FINGERPRINT, alongside access control types such as INVALID_CLEAR_PASSWORD and INVALID_NEW_BIO_ENROLL. The core content is a comprehensive table mapping various single and combined authentication factors to specific key validity rules, explaining how events like clearing passwords or enrolling new biometrics affect key access. This document serves as a configuration guide for developers and security engineers implementing secure access control policies.

### 用户身份认证访问控制简介.md 用户身份认证访问控制简介.md
This document introduces the key access control mechanisms provided by HUKS to ensure secure key storage and usage. It covers three main aspects: key ownership isolation, user identity authentication for high-security keys, and strict usage restrictions for specific algorithms like AES and RSA. Key takeaways include that services can only access their own keys, sensitive operations require immediate user verification via password or biometrics, and key usage is algorithm-specific. The document notes that lightweight devices do not support user identity authentication. This conceptual guide targets developers implementing security features in HarmonyOS applications who need to understand access control policies.
