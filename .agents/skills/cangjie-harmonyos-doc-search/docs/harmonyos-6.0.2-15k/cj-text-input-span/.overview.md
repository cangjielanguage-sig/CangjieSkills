# cj-text-input-span

The `cj-text-input-span` directory serves as a specialized resource hub for developers working with the ArkUI framework in the Cangjie programming language. It focuses specifically on the Span component, which is essential for creating and managing inline text segments within HarmonyOS applications. This documentation provides a deep dive into the API reference, detailing how to define basic data types such as text background styles and shadow effects. It also guides users through configuring component properties to achieve desired visual outcomes. By including practical code examples, the directory illustrates advanced text styling techniques, including decorations, spacing adjustments, and various visual effects. This collection is particularly suitable for UI engineers and developers seeking to enhance the typographic capabilities and user interface richness of their applications through precise inline text control.

### Span/

This directory provides comprehensive documentation for the Span component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the fundamental API reference for creating inline text segments, defining basic data types like text background styles and shadow effects, and configuring component properties. Additionally, it includes practical code examples demonstrating text styling techniques such as decorations, spacing, and visual effects. This resource is suitable for developers and UI engineers looking to implement and customize inline text content in HarmonyOS applications using Cangjie.
