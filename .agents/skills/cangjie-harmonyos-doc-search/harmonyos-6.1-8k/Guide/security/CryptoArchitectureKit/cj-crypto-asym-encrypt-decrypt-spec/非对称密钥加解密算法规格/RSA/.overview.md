# RSA

本目录包含关于仓颉框架中RSA非对称加密算法的技术文档。内容涵盖了RSA的三种主要填充模式（NoPadding、PKCS1、PKCS1_OAEP）的配置规范、输入输出长度限制以及密钥参数设置。特别详细介绍了PKCS1_OAEP模式的参数获取与设置方法，以及不同密钥长度下的兼容性规范。核心关键词包括RSA、填充模式、PKCS1_OAEP、密钥长度和参数配置。这些文档适合需要在仓颉开发环境中实现或配置RSA加解密功能的开发人员参考。

## 详细描述

### RSA_3more_018b35f9.md RSA_3more_018b35f9.md
本文档旨在介绍仓颉框架中RSA非对称加密算法的三种填充模式及其参数配置规范。文档主要涵盖NoPadding、PKCS1和PKCS1_OAEP三种模式的定义、输入输出长度限制及参数设置，并列出了不同密钥长度对应的字符串参数规格表。关键信息包括各模式对输入数据长度的具体限制公式、PKCS1_OAEP模式所需的摘要算法参数，以及通过“密钥类型|填充模式”格式（如RSA2048|PKCS1）创建加解密实例的方法。该文档面向需要在仓颉开发环境中实现RSA加解密功能的开发人员，读者需具备基础的非对称加密知识。

### 获取设置OAEP填充模式的参数_04914ed3.md 获取设置OAEP填充模式的参数_04914ed3.md
本文档旨在说明从API版本12开始，如何在RSA使用PKCS1_OAEP填充模式时获取和设置相关参数。文档核心内容通过表格形式展示了OAEP参数（如md、mgf、mgf1_md及pSource）的枚举值及其读写支持情况。关键信息指出，除pSource参数支持获取和设置外，其余参数仅支持获取操作。这是一份API参考文档，主要面向需要配置RSA加密参数的开发人员，读者需具备基础的加密算法知识。

### 填充模式为PKCS1_OAEP/
本目录包含关于RSA加密中PKCS1_OAEP填充模式的技术文档。内容涵盖了如何构建加密参数字符串、不同RSA密钥长度支持的摘要算法与MGF组合，以及密钥类型的兼容性规范。核心关键词包括RSA、PKCS1_OAEP、摘要算法、MGF1和密钥长度。这些文档适合需要在系统中集成非对称加密功能、配置加密参数或解决密钥兼容性问题的开发人员参考。
