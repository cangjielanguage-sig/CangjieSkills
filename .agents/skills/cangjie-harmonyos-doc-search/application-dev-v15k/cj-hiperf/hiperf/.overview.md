# hiperf

This directory contains documentation for `hiperf`, a cross-platform command-line tool designed for developers to capture and debug performance data, similar to the Linux `perf` tool. It covers essential commands for logging, sampling, and reporting, alongside Python scripts for generating visual flame graphs in OpenHarmony environments. Key topics include hardware/software event monitoring, callstack recording, and data visualization. This resource is suitable for system performance engineers and developers seeking to analyze application behavior, optimize system resources, and debug performance issues on connected devices.

## Detailed Description

### hiperf_5more.md hiperf_5more.md
This document serves as a reference guide for hiperf, a cross-platform command-line tool designed for developers to capture and debug performance data of programs or systems, similar to the Linux perf tool. It covers environment prerequisites involving the hdc tool, general command-line options for logging control, and specific sub-commands like list, record, stat, report, and dump. Key information includes detailed explanations of logging flags and instructions for querying supported event types such as hardware, software, and tracepoint events using the list command. The content is intended for developers familiar with command-line interfaces who need to analyze system performance on connected devices.

### record命令.md record命令.md
This reference documentation details the `hiperf record` command, which samples target programs to capture performance data for analysis. The document primarily features a comprehensive parameter table explaining flags for CPU selection, frequency, duration, callstack modes, and output options, followed by usage syntax and a practical shell example. Key parameters include `-p` for process ID, `-d` for duration, and `-s` for stack unwinding methods like dwarf. It supports filtering by CPU, thread, and application, with options for data compression and symbolization. Intended for system performance engineers and developers needing to profile application behavior.

### stat命令_3more.md stat命令_3more.md
This document provides a command-line reference guide for the hiperf performance analysis tool, specifically detailing the stat, dump, and report commands. The stat section explains how to monitor target programs and print performance counters periodically. The dump section covers raw data extraction from perf.data files for verification, while the report section describes formatting sampling data into readable outputs like JSON or ProtoBuf. Key information includes comprehensive parameter tables for filtering by CPU, thread, or process, along with usage examples for each command. This technical guide is intended for developers and testers seeking to analyze system performance and debug applications using profiling data.

### 脚本.md 脚本.md
This technical guide explains how to use Python scripts within the Hiperf toolset to perform performance sampling and generate visual flame graphs for OpenHarmony systems. The document details three core workflows: executing sampling on specific targets like apps or processes, collecting symbol tables from local directories or devices, and generating HTML reports. It highlights specific scripts, their command-line arguments, and usage examples for tasks like targeting package names or handling build IDs for symbol resolution. Intended for developers or performance analysts familiar with command-line tools and OpenHarmony debugging, this reference facilitates efficient performance analysis.
