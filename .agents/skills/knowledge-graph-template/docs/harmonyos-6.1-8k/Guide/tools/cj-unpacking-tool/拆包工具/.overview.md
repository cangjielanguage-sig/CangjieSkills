## 详细描述

### 包解析接口_d89419a3.md 包解析接口_d89419a3.md
本文档定义了用于解析应用包（HAP、HSP、App）以提取配置信息的Java接口，主要面向应用市场。文档详细介绍了UncompressEntrance类，重点涵盖了parseApp和parseHap方法，这些方法支持文件路径和输入流两种输入方式。关键功能包括针对App包的多种解析模式（ALL、HAP_LIST、HAP_INFO）以及针对HAP包的JSON配置提取，所有接口均返回UncompressResult对象。这是API参考文档，旨在为需要在应用市场系统中集成包分析功能的开发人员提供技术规范。

### 拆包工具_2more_2fc6334d.md 拆包工具_2more_2fc6334d.md
本文档介绍了OpenHarmony提供的拆包工具，这是一种用于通过命令行解压HAP、HSP及App文件，并提供Java接口进行解析的调测工具。文档主要涵盖工具功能说明、SDK中JAR包位置、仓颉语言对HSP包的限制以及运行环境约束。关键信息包括该工具目前处于Beta阶段，需Java 8及以上环境运行，且仓颉程序暂不支持HSP包相关功能。该文档面向需要调试或分析OpenHarmony应用包的开发者，关键词包括OpenHarmony、拆包工具、HAP、HSP、仓颉、Java接口。

### 拆包指令说明.md 拆包指令说明.md
本文档是一份技术参考指南，旨在指导开发者使用app_unpacking_tool.jar工具对应用包进行解压操作。文档详细介绍了HAP包、App包、HSP包及APPQF包四种模式的拆包指令，并特别说明了从HAP包中提取rpcid文件的方法。每个章节均包含具体的命令行示例及参数规范，重点阐述了--mode、路径参数及--force覆盖选项的使用。该文档主要面向需要分析或解压应用包的开发人员，提供了完整的命令行操作参考。

### 拆包工具信息字段/
本目录包含HarmonyOS/OpenHarmony应用拆包工具相关的数据结构定义文档，详细描述了应用包（HAP）解析过程中的核心信息字段。内容涵盖应用元数据、Ability组件配置、权限管理、卡片信息及分发过滤规则等关键结构体。文档重点区分了FA模型与Stage模型的配置差异，适用于应用开发、系统框架集成及包管理工具开发人员，旨在辅助理解应用配置文件的内部结构与解析逻辑。
