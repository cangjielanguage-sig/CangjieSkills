# class_EventBase

This directory contains API reference documentation for the `EventBase` abstract class within the Cangjie AbilityKit, focusing on event handling and type validation mechanisms. It details methods for validating event parameter counts (from 0 to 5 arguments) and returning corresponding Event objects like `Event0` through `Event5`. The documentation includes syntax details, return types, potential `BusinessException` errors, and practical Cangjie code examples for registering callbacks and emitting events via `EventHub`. It is intended for developers building applications using the HarmonyOS AbilityRuntime Core who require knowledge of generic types and event-driven programming.

### class_EventBase_4more.md
This document provides API reference documentation for the abstract class EventBase within the Cangjie AbilityKit, designed for event handling and type validation. It details methods as0, as1, and as2, which validate event parameter counts and return corresponding Event objects like Event0 and Event1. Key information includes system capabilities, return types, and potential BusinessException errors. Practical Cangjie code examples demonstrate how to register callbacks and emit events using EventHub. Targeted at developers building applications using the HarmonyOS AbilityRuntime Core, this guide requires knowledge of generic types and event-driven programming. Keywords: EventBase, Cangjie, EventHub, API, Event handling, generic types.

### func_as3A1_A2_A3_3more.md
This API reference document details generic functions used to validate parameter types for event handling with three or more arguments. It covers the syntax, functionality, return values, and exceptions for as3, as4, and as5, along with Cangjie code examples. Key information includes that these functions return specific event centers (Event3 to Event5) and require system capability SystemCapability.Ability.AbilityRuntime.Core. They may throw a BusinessException if capabilities are unsupported. Targeted at developers using the AbilityKit to manage multi-parameter event callbacks in version 12 or later.
