# 接口

This directory contains comprehensive API reference documentation for core interfaces in the Cangjie programming language. It covers fundamental type system components including interoperability with C (CType), collection management (Collection, Iterable), comparison operations (Comparable, Equatable), hashing (Hashable, Hasher), and utility functions (ToString, Resource). Additionally, it details the root type hierarchy (Any) and specialized interfaces for counting and concurrency. This documentation is essential for Cangjie developers seeking to understand type constraints, implement custom data structures, manage object lifecycles, or utilize standard library features for generic programming and operator overloading.

## Detailed Description

### interface_CType_4more.md interface_CType_4more.md
This document serves as API reference for core interfaces focusing on interoperability and comparison. It details CType for C language interaction, Equal/Equatable for equality checks, and Greater for comparisons. It highlights that CType is a sealed, built-in interface implicitly implemented by C-compatible types, while Equatable combines Equal and NotEqual to provide a default implementation for the inequality operator. It lists standard types like Int64, String, and Array, aiding developers in understanding type constraints and operator overloading.

### interface_CollectionT.md interface_CollectionT.md
This API reference defines the Collection interface for container types, inheriting from Iterable. It details members like the size property and methods such as isEmpty and toArray, establishing a contract for generic data containers. It is intended for developers building or using data structures who need to understand the standard API for collection manipulation.

### interface_ComparableT.md interface_ComparableT.md
This document defines the Comparable interface for standardizing generic type comparisons. It details the compare method and default implementations for operators (<, <=, ==, >, >=) based on Ordering results. It simplifies type implementation for developers needing custom types with total ordering capabilities.

### interface_GreaterOrEqualT_2more.md interface_GreaterOrEqualT_2more.md
This API documentation defines GreaterOrEqual for the >= operator and Hashable for hash calculation. It details the hashCode function and lists built-in types like Int64 and String that implement Hashable. It targets developers implementing custom types or utilizing standard library comparison and hashing features.

### interface_IterableE_6more.md interface_IterableE_6more.md
This reference details six interfaces: Iterable for traversal, Less/LessOrEqual/NotEqual for operators, Resource for lifecycle management, and ThreadContext for concurrency. It explains enabling for-in loops via the iterator function and automatic resource release. It targets developers implementing interfaces or using built-in container and concurrency features.

### interface_ToString.md interface_ToString.md
This document provides API reference for the ToString interface, outlining the `toString()` function. It explains providing string representations for concrete types and the function's String return type. It is designed for developers implementing standard string output for logging or display mechanisms.

### interface_Any/
This directory documents the `interface_Any` module, focusing on the `Any` interface as the root of the type hierarchy. It includes `Byte` extensions for ASCII manipulation. It is suitable for developers understanding type inheritance, polymorphism, and low-level text processing.

### interface_CountableT/
This directory documents the `Countable` interface for mapping instances to Int64 positions and time-based arithmetic extensions. It covers methods like `next` and operator overloading for Duration multiplication. It is suitable for developers implementing countable types or precise time interval calculations.

### interface_Hasher/
This directory provides API reference for the `Hasher` interface, focusing on computing combined hash values. It details overloaded `write` methods for UInt types and state management like `finish` and `reset`. It is essential for developers implementing hashing logic or custom data structures.
