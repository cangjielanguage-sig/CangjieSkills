This directory provides essential type definitions for implementing gesture handling within the ArkUI framework using the Cangjie programming language. It focuses on the core structures required to manage touch interactions, specifically pan gestures. The content includes detailed API references for configuration classes that allow dynamic adjustment of gesture properties without UI refreshes, as well as enumerations that define directional constraints and axis-based movements. These definitions are crucial for developers aiming to create responsive and interactive user interfaces, providing the necessary tools to optimize performance and handle complex event logic. This documentation is specifically suitable for software engineers and ArkUI developers working with Cangjie who need precise control over gesture recognition behaviors, parameter constraints, and system capabilities in their applications.
