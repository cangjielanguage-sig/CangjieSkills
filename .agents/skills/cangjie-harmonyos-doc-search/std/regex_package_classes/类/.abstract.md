This directory contains API reference documentation for classes within the Cangjie programming language, primarily focusing on regular expression (regex) processing. It covers both current implementations and deprecated legacy components. Key topics include the `Regex` class for text processing, the deprecated `Matcher` class for pattern matching, and the obsolete `RegexOption` class for matching modes. This documentation is suitable for Cangjie developers looking to implement robust text validation, parsing logic, or maintain legacy codebases that utilize older regex frameworks.
