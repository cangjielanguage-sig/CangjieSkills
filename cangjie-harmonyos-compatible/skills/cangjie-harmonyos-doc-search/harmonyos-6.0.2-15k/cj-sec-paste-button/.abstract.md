This directory serves as a comprehensive resource for the `cj-sec-paste-button` project, focusing on the implementation of the PasteButton component within the ArkUI framework using the Cangjie language. It addresses the critical need for secure clipboard interactions by providing a specialized control that manages temporary read permissions for users. The documentation encompasses the full API specification, detailing component constructors, the `PasteButtonOnClickResult` enum for tracking authorization states, and immutable style properties. It also outlines supported attributes and specific event exclusions. Tailored for HarmonyOS developers, this collection includes practical Cangjie code examples for UI layout, event handling, and customization, ensuring applications remain system-compliant while handling sensitive user data securely.
