This directory contains API reference documentation for the `ohos.data_share_predicates` module within the Cangjie language ecosystem. It focuses on defining predicates used to filter data during DataShare database operations, such as querying, updating, and deleting records. The documentation covers the `DataSharePredicates` class, supporting both RDB and KVDB databases with methods for logical operations, sorting, and limiting results. It is designed for Cangjie developers building data-driven applications who need to manage distributed data queries effectively and possess a solid understanding of database concepts.
