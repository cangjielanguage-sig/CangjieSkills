## 添加事件

Text组件可以添加通用事件，可以绑定[onClick](../../cj-universal-event-click/.overview.md)、[onTouch](../../cj-universal-event-touch/.overview.md)等事件来响应操作。

<!-- run -->

```cangjie
package ohos_app_cangjie_entry

import kit.UIKit.*
import ohos.state_macro_manage.*

@Entry
@Component
class EntryView {
    func build() {
        Scroll {
            Column {
                Text('点我').onClick {
                    evt => AppLog.info('我是Text的点击响应事件')
                }
            }.height(100.percent).width(100.percent)
        }
    }
}
```
