# cj-arktsapi-in-cangjie

This directory provides a comprehensive technical guide designed for Cangjie developers who require the ability to invoke ArkTS APIs directly within their Cangjie-based applications. It focuses on the critical aspect of cross-language interoperability, enabling the use of ArkTS features and standard libraries that are currently absent from the native Cangjie ecosystem. The documentation covers the complete workflow necessary to bridge these environments, starting from the initialization of a JSRuntime instance to establish a secure execution context. It further details the procedures for importing pre-compiled ArkTS modules, including NAPI .so shared libraries and .abc bytecode files, and subsequently invoking their exported functions. This resource is essential for developers looking to maximize code reuse and functionality by integrating existing ArkTS assets into new Cangjie projects, ensuring a seamless development experience across language boundaries.

## Detailed Description

The directory contains a single primary document that serves as the definitive guide for this integration process.

### cj-arktsapi-in-cangjie.md cj-arktsapi-in-cangjie.md
This guide explains how to enable cross-language interoperability to use ArkTS APIs within Cangjie applications. It targets Cangjie developers who need to access ArkTS features or standard libraries not yet available in the native Cangjie ecosystem. The document outlines a three-step process: creating a JSRuntime instance to establish an execution context, loading pre-compiled ArkTS modules (such as NAPI .so or .abc bytecode files), and invoking exported functions using the call method. Key concepts include the JSRuntime object, mainContext, and module loading constraints. This tutorial serves as a practical reference for bridging the two languages during application development.
