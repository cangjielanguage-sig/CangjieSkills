# cj-huks-key-agreement

This directory functions as a specialized technical repository dedicated to the implementation of cryptographic key agreement protocols, with a specific focus on X25519, within the HarmonyOS Universal Keystore (HUKS) framework using the Cangjie programming language. It provides a thorough examination of the entire development lifecycle, ranging from initial key generation and public key export to the execution of the key agreement process and eventual key deletion. Particular attention is given to the `HUKS_TAG_DERIVED_AGREED_KEY_STORAGE_FLAG` parameter, a critical setting that determines whether the negotiated shared secret remains managed by the HUKS system or is exported to the user application. This documentation is highly suitable for HarmonyOS developers and security architects who need to master HUKS integration and asymmetric cryptography to ensure the security of their applications. By following the guidelines in this directory, developers can effectively manage cryptographic keys and implement secure communication channels in their HarmonyOS applications.

## Detailed Description

### 密钥协商仓颉/

This directory serves as a comprehensive technical repository for implementing cryptographic key agreement protocols, specifically X25519, within the HarmonyOS Universal Keystore (HUKS) framework using the Cangjie programming language. It details the complete development workflow, encompassing key generation, public key export, the key agreement process, and key deletion. A critical aspect covered is the `HUKS_TAG_DERIVED_AGREED_KEY_STORAGE_FLAG` parameter, which controls whether the negotiated shared secret is managed by HUKS or exported to the application. The content includes a matrix of valid storage flag combinations. This resource is specifically designed for HarmonyOS developers working with cryptographic operations who require a solid understanding of HUKS integration and asymmetric cryptography to build secure applications.
