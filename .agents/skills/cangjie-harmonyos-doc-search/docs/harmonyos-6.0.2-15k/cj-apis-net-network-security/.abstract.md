This directory contains the essential API reference documentation for the `ohos.net.networkSecurity` module, a key component of the HarmonyOS NetStack system, specifically adapted for the Cangjie programming language. It provides an in-depth look at network communication security, offering developers the necessary tools to handle certificates, manage data structures, and execute verification processes. The documentation covers a wide array of technical topics, including certificate encoding formats like PEM and DER, various data encapsulation types, and the intricacies of validating certificates against both system and custom Certificate Authorities (CA). This resource is indispensable for Cangjie developers and system engineers who are looking to implement secure network protocols and manage certificate data with precision and reliability in their application development workflows. It ensures that users have access to the critical information needed to build secure, compliant, and high-performance applications on the HarmonyOS platform.
