# 主要场景开发步骤

本目录主要涵盖了使用仓颉语言在HarmonyOS平台上进行蓝牙低功耗（BLE）开发的核心场景。内容重点包括BLE广播的开启与关闭、扫描功能的实现及参数配置、以及原始广播数据的解析。文档详细介绍了如何使用ConnectivityKit进行模块导入、状态回调订阅及生命周期管理。核心关键词包括BLE、广播、扫描、仓颉、ConnectivityKit。本指南适合具备基础蓝牙开发知识，需要在HarmonyOS应用中实现设备发现与连接功能的开发者参考。

## 详细说明

### 开启关闭广播.md 开启关闭广播.md

本文档旨在指导开发者使用仓颉语言实现蓝牙低功耗（BLE）广播的开启与关闭功能。主要涵盖模块导入、系统能力要求、广播参数配置、数据构造及状态回调订阅等核心步骤。关键信息包括通过AdvertiseSetting和AdvertiseData配置广播详情，利用startAdvertising和stopAdvertising管理广播生命周期，并提供了完整的代码示例。文档面向HarmonyOS应用开发者，要求具备基础蓝牙开发知识，适用于需要实现设备发现功能的场景。关键词：BLE、广播、仓颉、ConnectivityKit。

### 开启关闭扫描/

本目录包含关于使用仓颉语言在HarmonyOS平台上实现蓝牙低功耗（BLE）扫描功能的文档。内容涵盖了扫描生命周期的管理（开启与停止）、扫描参数配置、过滤器设置以及原始广播数据包的深度解析。核心知识点包括BleScanManager类的使用、ScanFilter构造、UUID转换、服务数据及厂商数据的提取。该文档适合需要实现设备发现功能及处理底层广播数据的HarmonyOS应用开发者参考。
