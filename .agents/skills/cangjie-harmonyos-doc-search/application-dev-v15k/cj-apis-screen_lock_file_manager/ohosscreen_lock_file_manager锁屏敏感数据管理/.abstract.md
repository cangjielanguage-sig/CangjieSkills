This directory contains documentation for the `ohos.screen_lock_file_manager` module, designed to manage sensitive data access permissions when a device screen is locked. It covers the security mechanism where sensitive data keys are destroyed upon locking and restored only after unlocking. The content includes API references for the `ScreenLockFileManager` class, status enums for access and release operations, and module configuration details. It is suitable for HarmonyOS developers using the Cangjie language who need to implement secure data protection features and handle permission states programmatically.
