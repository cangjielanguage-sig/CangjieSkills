# cj-spring-curve

This directory provides a comprehensive technical reference for utilizing ArkUI's damped spring curve APIs specifically within the Cangjie programming language environment. It is designed to assist developers in creating natural, physics-based animations that feel organic and responsive to user interaction. The documentation covers four distinct interfaces—springMotion, responsiveSpringMotion, interpolatingSpring, and springCurve—offering a deep dive into their parameters, specific use cases, and functional differences. Key topics include the critical distinction between auto-calculated animation durations versus fixed durations, the mechanisms behind velocity inheritance, and the significance of normalized velocity in animation physics. Furthermore, the guide highlights best practices, explicitly advising against the use of the springCurve interface due to its tendency to distort physical laws. This resource is primarily suitable for UI developers and system designers aiming to implement sophisticated, smooth, and non-abrupt motion effects in their applications while maintaining a high standard of physical realism.
