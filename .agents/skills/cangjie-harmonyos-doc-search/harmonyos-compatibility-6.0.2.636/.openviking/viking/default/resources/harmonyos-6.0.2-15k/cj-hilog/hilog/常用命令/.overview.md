# 常用命令

This directory serves as a comprehensive technical resource for the `hilog` logging system within HarmonyOS and OpenHarmony environments. It provides command-line instructions for viewing, filtering, and configuring system logs effectively. Key topics include setting global and domain-specific log levels, managing buffer sizes, and filtering logs by tags or process IDs. Additionally, it covers advanced features such as flow control, log persistence, and customizing output formats. These guides are intended for developers and system administrators seeking to debug issues, monitor system performance, or control log data flow efficiently.

## Detailed Description

### 查看和设置日志级别.md 查看和设置日志级别.md
This technical reference guide provides instructions for viewing and configuring log levels within the hilog system. It covers querying the default global level, setting global, domain-specific, and tag-specific levels, and applying persistent settings that survive restarts. The document details the hilog command syntax, including flags like -b for level, -D for domain, -T for tag, and --persist. It defines valid levels as Debug, Info, Warning, Error, and Fatal. Intended for developers and system administrators needing to control log verbosity for debugging or system monitoring.

### 查看帮助命令_8more.md 查看帮助命令_8more.md
This document serves as a quick reference guide for managing the hilog logging system via command-line interface. It covers viewing help information, performing non-blocking log reads, querying and modifying log buffer sizes, clearing buffers, toggling kernel log storage, and managing log statistics. Key commands include hilog -x for non-blocking reads, hilog -G for resizing buffers, and hilog -s for detailed statistics including log frequency and dropped lines. The document also defines statistical metrics like MAX_FREQ and MAX_TP. Intended for system developers or administrators needing to monitor, configure, and troubleshoot system logging behavior.

### 查看指定TAG日志_3more.md 查看指定TAG日志_3more.md
This document serves as a technical reference guide for using the hilog command-line tool to filter and retrieve system logs efficiently. It covers three distinct log viewing methods: filtering logs by a specific tag using the -T option, displaying the first n lines of the log buffer using the -a option, and showing the last n lines using the -z option. Each section includes the command syntax and a practical usage example with sample output to demonstrate real-world application. This guide is intended for developers and system administrators debugging HarmonyOS or OpenHarmony systems who need to isolate specific events or monitor log buffer limits.

### 查看指定进程日志_3more.md 查看指定进程日志_3more.md
This document serves as a command-line reference guide for using the hilog tool to filter, search, and manage system log persistence. It covers three specific functionalities: filtering logs by process ID using the -P flag, searching logs with regular expressions using the -e flag, and managing disk persistence tasks using the -w flag. Key takeaways include the syntax for targeting specific PIDs, performing regex-based searches, and configuring persistent storage tasks with parameters like file count, size limits, and compression methods such as zlib or zstd. This technical guide is intended for developers or system administrators needing to debug or monitor system behavior through log analysis and storage management.

### 设置日志显示格式.md 设置日志显示格式.md
This document serves as a technical reference guide for configuring the output display format of system logs using the hilog command-line tool. It details the syntax for the -v option, enumerating available format types such as time, color, epoch, monotonic, and nsec. The content includes practical usage examples demonstrating the visual difference between standard time formatting and high-precision nanosecond timestamps. Key takeaways involve understanding how to adjust log verbosity and time precision for effective debugging. The intended audience consists of developers and system administrators working within the HarmonyOS or OpenHarmony environment who need to customize log output for system monitoring and issue diagnosis.

### 进程流控开关_5more.md 进程流控开关_5more.md
This document serves as a technical reference guide for managing log flow control and filtering output using the hilog command-line tool. It covers toggling process and domain flow control switches, viewing logs by specific severity levels, filtering by log type, and querying logs by domain ID. Key information includes specific shell commands such as hilog -Q pidon and hilog -L E, accompanied by usage examples and sample output to demonstrate effective log throttling and data isolation. Intended for system developers or engineers debugging operating system environments, this guide requires basic familiarity with shell commands and system logging concepts.
