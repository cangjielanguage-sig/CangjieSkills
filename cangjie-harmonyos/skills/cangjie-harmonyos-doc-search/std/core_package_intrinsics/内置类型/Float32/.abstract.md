This directory contains comprehensive technical documentation and API references for the Float32 data type within the Cangjie programming language environment. Key topics include the single-precision binary32 format, NaN handling, bitwise conversion methods, and standard interfaces like Comparable and Hashable. This documentation is suitable for developers, engineers, and system architects who need to implement, debug, or integrate precise floating-point operations and understand the underlying data structure specifications.
