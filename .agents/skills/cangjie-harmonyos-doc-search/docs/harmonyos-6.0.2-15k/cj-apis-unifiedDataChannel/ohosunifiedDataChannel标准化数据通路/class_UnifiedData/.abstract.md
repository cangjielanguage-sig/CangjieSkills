This directory contains essential API reference documentation for the `UnifiedData` class within the Unified Data Management Framework (UDMF), specifically tailored for HarmonyOS developers using the Cangjie language. It covers the complete lifecycle of the `UnifiedData` object, including its definition, metadata management (such as timestamps), and initialization processes. The documentation details functional methods for inserting data via `addRecord` and retrieving `UnifiedRecord` objects via `getRecords`. Additionally, it includes references for inspecting data types using `getTypes` and `hasType`. This resource is suitable for developers who need to implement or interact with the UDMF Core system capability, requiring a solid understanding of basic data types and the UDMF architecture to effectively manage unified data objects.
