# cj-asset-store-kit-overview

This directory contains the technical overview for the Asset Store Kit, a specialized solution designed for securely storing and managing short sensitive user data, such as passwords and tokens. It covers essential security concepts including AES256-GCM encryption and the Universal Keystore System, alongside various access control mechanisms like owner-based permissions, lock screen status, password settings, and user authentication. The documentation outlines specific operational constraints, such as data size limits (under 1KB), alias uniqueness, and batch query limits of 40 items. This resource is primarily intended for developers using the Cangjie language who need to implement robust, secure data storage mechanisms within their applications while adhering to strict security standards.
