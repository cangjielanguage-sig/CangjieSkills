This directory serves as a comprehensive API reference for the Abstract Syntax Tree (AST) package, primarily targeting the Cangjie programming language environment. It covers core interfaces for serialization and tokenization, essential data types, error handling mechanisms, and detailed documentation for functions and classes used in compiler operations. The content ranges from basic modular programming concepts to advanced metaprogramming and macro processing. It is suitable for software developers, compiler engineers, and students interested in language design, syntax tree manipulation, and building language extensions.
