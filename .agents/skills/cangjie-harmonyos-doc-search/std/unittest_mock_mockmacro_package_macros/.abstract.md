This directory contains documentation for the `unittest_mock_mockmacro_package_macros`, a specialized component of the `unittest_mock` framework focused on macro-based testing utilities. It serves as a technical reference for developers looking to streamline their unit testing process using specific annotations. The content primarily covers the `@Called` macro for verifying method interactions and the `@On` macro for configuring mock and spy object behaviors. By utilizing these macros, developers can write more concise and readable test code, significantly reducing boilerplate and improving overall test maintainability. This documentation is intended for developers with prior experience in testing frameworks who need to implement advanced mocking, spying, and verification logic within their test suites. It assumes familiarity with the underlying verification and configuration APIs.
