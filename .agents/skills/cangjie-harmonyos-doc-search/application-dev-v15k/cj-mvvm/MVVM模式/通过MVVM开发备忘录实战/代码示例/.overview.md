# 代码示例

This directory contains practical code examples demonstrating the implementation of To-Do List applications using the MVVM architectural pattern in the Cangjie programming language. It covers essential concepts such as project directory structure, entry views, data models, and UI components, with a strong emphasis on state management. The examples specifically illustrate the use of decorators like @Observed, @Publish, @State, and @Link to synchronize data between View and ViewModel layers effectively. Additionally, it explores reactive programming techniques, including the use of ForEach for list rendering and ObservedArrayList for data handling. These resources are suitable for developers familiar with basic programming concepts who are learning Cangjie or HarmonyOS development, offering insights into achieving modular, reusable, and efficient code structures. By studying these examples, developers can gain a deeper understanding of how to build responsive applications that separate business logic from the user interface.
