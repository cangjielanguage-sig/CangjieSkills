## 详细描述

### SM2.md SM2.md
本文档旨在说明仓颉框架中SM2非对称加密算法的实现与使用规范。文档涵盖了SM2密文结构（C1、C2、C3）、字符串参数的拼接方式（如"SM2_256|MD5"）及支持的摘要算法。重点介绍了API 12版本新增的获取摘要参数功能，以及SM2密文与ASN.1格式（C1C3C2）之间的相互转换。作为技术参考文档，它为开发者提供了实现国密SM2加解密及密文格式处理所需的详细参数定义和操作指南。

### 非对称密钥加解密算法规格_6b193d11.md 非对称密钥加解密算法规格_6b193d11.md
本文档旨在介绍仓颉编程语言当前支持的非对称密钥加解密算法及其具体规格。主要内容涵盖仓颉支持的非对称算法列表，并指出各算法所支持的加密模式将在后续具体算法规格章节中详细阐述。文档目前处于Beta阶段，关键信息在于明确算法的适用范围及模式支持情况，为开发者提供权威的技术参考。作为技术参考文档，主要面向使用仓颉语言进行安全加密开发的用户，建议读者具备基础的密码学知识。

### RSA/
本目录包含关于仓颉框架中RSA非对称加密算法的技术文档。内容涵盖了RSA的三种主要填充模式（NoPadding、PKCS1、PKCS1_OAEP）的配置规范、输入输出长度限制以及密钥参数设置。特别详细介绍了PKCS1_OAEP模式的参数获取与设置方法，以及不同密钥长度下的兼容性规范。核心关键词包括RSA、填充模式、PKCS1_OAEP、密钥长度和参数配置。这些文档适合需要在仓颉开发环境中实现或配置RSA加解密功能的开发人员参考。
