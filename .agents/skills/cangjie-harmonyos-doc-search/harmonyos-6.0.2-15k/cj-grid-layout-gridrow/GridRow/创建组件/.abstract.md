This directory contains API reference documentation for initializing the `GridRow` container component within the Cangjie ArkUI framework. It focuses on various constructor overloads that allow developers to configure responsive grid layouts with specific parameters such as gutter spacing, column definitions, breakpoints, and layout direction. The content is designed for software developers and UI engineers building HarmonyOS applications who need to implement flexible grid systems. Key topics include component initialization, responsive design configuration, and structural control using Cangjie language features.
