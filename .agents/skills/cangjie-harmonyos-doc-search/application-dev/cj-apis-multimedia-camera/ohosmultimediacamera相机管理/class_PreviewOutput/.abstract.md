This directory contains API reference documentation for the `PreviewOutput` class within the Cangjie language CameraKit. It focuses on managing camera preview outputs in the multimedia camera core system. Key topics include configuring frame rates, handling preview rotation, managing event listeners (callbacks), and resource lifecycle management. The documentation covers methods for querying active profiles, setting rotation angles, and registering or unregistering camera events. It is intended for developers building camera applications on the HarmonyOS ecosystem who need to implement robust preview functionality and handle asynchronous events.
