# 基于shell命令测试

This directory contains technical documentation for performing automated UI testing and debugging on HarmonyOS/OpenHarmony systems using shell commands. It covers the `uitest` tool, enabling users to execute operations such as screen capturing, layout dumping, and complex UI simulations directly from the command line. Key topics include gesture recording, input simulation (clicks, swipes, text), and environment configuration. These resources are designed for developers and QA engineers seeking efficient workflows for rapid testing and interface validation, assuming prior setup of HDC environment variables and appropriate system permissions.

## Detailed Description

### 基于shell命令测试_4more.md 基于shell命令测试_4more.md
This reference guide provides instructions for using shell commands via the uitest tool to perform quick testing operations like screen capturing, layout dumping, and UI simulation. The document covers a comprehensive command list table, usage examples for screenshots and layout retrieval, and a detailed breakdown of the user recording operation including JSON data structure definitions. Key information includes specific commands such as screenCap, dumpLayout, uiRecord, and uiInput, along with their parameters for file paths and attribute filtering. It also explains the output format for recorded gestures, detailing fields for coordinates, event types, and control hierarchies. Targeted at developers requiring rapid testing workflows, this guide assumes the user has already configured the necessary HDC environment variables.

### 注入UI模拟操作.md 注入UI模拟操作.md
This document serves as a technical reference for using the uiInput command to simulate various user interface interactions via the command line. It details specific sub-commands for touch gestures like click, double-click, long-press, and complex motions such as fling, swipe, and drag. Additionally, it covers text input simulation and hardware key event handling, including combination keys. Key information includes parameter definitions for coordinates, velocity, and direction, accompanied by practical shell command examples. This guide is intended for developers and QA engineers performing automated UI testing or debugging on HarmonyOS/OpenHarmony systems.

### 获取版本信息_2more.md 获取版本信息_2more.md
This technical reference guide provides essential commands for managing the UITest environment on a device. It covers retrieving the current UITest version and launching the UITest daemon process. Key information includes critical prerequisites such as enabling developer mode and ensuring the test HAP possesses an APL level of system_basic or normal. The document explicitly warns that only processes initiated by the aa test command can invoke UITest interfaces, while those started via aa start will fail. This guide targets developers and QA engineers configuring automated UI testing setups.
