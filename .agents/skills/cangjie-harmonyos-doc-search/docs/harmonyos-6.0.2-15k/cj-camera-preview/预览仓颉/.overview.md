# 预览仓颉

This directory serves as a comprehensive technical resource for developers implementing camera preview functionality using the Cangjie (仓颉) programming language. It provides detailed guidance on the essential steps required to establish a live camera feed, including importing interfaces, creating Surface components via XComponent, and generating preview output streams. The documentation highlights critical implementation details, such as the necessity of matching the preview stream's aspect ratio with the XComponent display area to prevent rendering distortion. Beyond basic setup, it covers advanced lifecycle management, instructing developers on how to monitor stream status events—including start, end, and error notifications—using specific callbacks. This content is specifically designed for software engineers and application developers who are building camera applications and require practical, code-oriented solutions to manage preview sessions and handle runtime exceptions effectively.

## Detailed Description

#### 状态监听.md 状态监听.md
This document guides developers on monitoring camera preview output stream status during application development using the Cangjie language. It covers three specific monitoring events: preview stream start, preview stream end, and preview output errors. Key information includes how to register specific callbacks—FrameStartCallBack, FrameEndCallBack, and ErrorCallBack—using the previewOutput.on method to handle events like first exposure, last frame completion, and error code retrieval. This technical guide targets camera application developers who need to manage the preview lifecycle and handle exceptions effectively.

#### 预览仓颉_2more.md 预览仓颉_2more.md
This tutorial guides developers through implementing camera preview functionality using the Cangjie programming language. It covers importing necessary interfaces, creating a Surface via XComponent, generating a preview output stream, and enabling the session to display the feed. Key takeaways include the critical requirement to match the aspect ratio of the preview stream with the XComponent display area to ensure proper rendering. The document provides code examples for creating PreviewOutput and starting the session using Session.start. Intended for developers building camera applications, this guide assumes prior completion of permission application preparations.
