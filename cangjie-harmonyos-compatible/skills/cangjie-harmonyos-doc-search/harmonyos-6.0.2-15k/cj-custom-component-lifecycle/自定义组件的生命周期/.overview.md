# 自定义组件的生命周期

This directory provides comprehensive documentation on the lifecycle management of custom components within the HarmonyOS ArkUI framework, specifically tailored for the Cangjie language. It covers the complete spectrum of component states, from initialization and rendering to destruction and recycling. Key topics include the `@Reusable` decorator, the `ReuseParams` class, and specific lifecycle callbacks like `aboutToAppear` and `onPageShow`. This resource is essential for HarmonyOS developers and UI engineers seeking to master state management, optimize memory usage through component reuse, and ensure proper application behavior during page transitions.

## Detailed Description

### class_ReuseParams.md class_ReuseParams.md
This API reference document details the ReuseParams class, which serves as a parameter carrier for the aboutToReuse lifecycle function in the ArkUI framework. It covers class initialization, the size property, and methods for accessing and managing construction parameters, including get, contains, add, and the aboutToRecycle callback. Key takeaways include the ability to retrieve parameter values by key and check for their existence, while noting that constructors and the add method are generally reserved for system use. This documentation is intended for HarmonyOS developers using the Cangjie language to implement efficient component reuse and recycling logic.

Targeted at developers familiar with Cangjie syntax, this guide provides essential patterns for building responsive and optimized user interfaces.

### 自定义组件的生命周期_9more.md 自定义组件的生命周期_9more.md
This document serves as an API reference for managing the lifecycle of custom components within the Cangjie UIKit framework. It details specific callback functions covering initialization, destruction, reuse, page visibility, and back press handling. Key information includes the execution order relative to the build function, such as aboutToAppear allowing state changes before rendering, and aboutToReuse facilitating component caching. The document also outlines strict restrictions, prohibiting state modifications in aboutToDisappear and noting that page-level callbacks like onPageShow only apply to @Entry decorated components. Intended for UI developers, this guide ensures proper component behavior and state management in ArkUI applications.
