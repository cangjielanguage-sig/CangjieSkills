This directory provides a comprehensive guide for implementing runtime permission requests in HarmonyOS applications using the Cangjie language. It covers the complete development lifecycle, from declaring permissions in configuration files to handling authorization results and UI integration. Key topics include location permission management, the `checkAccessToken` method, and the `requestPermissionsFromUser` API. The tutorials address critical timing constraints and lifecycle methods like `onWindowStageCreate`. This resource is suitable for HarmonyOS developers familiar with Cangjie syntax and the AbilityKit framework who need to integrate privacy permission flows into their applications.
