This directory contains the API reference documentation for the `ohos.ark_interop_advance` library, designed to facilitate interoperability between the Cangjie language and ArkTS within the HarmonyOS ecosystem. It covers a comprehensive range of classes, structs, and interfaces for managing JavaScript contexts, data types, functions, promises, and error handling. Key components include memory management, type conversion, and asynchronous operation support. This documentation is suitable for HarmonyOS developers and system engineers working on native-ArkTS integration, requiring knowledge of Napi capabilities and cross-language runtime mechanics.
