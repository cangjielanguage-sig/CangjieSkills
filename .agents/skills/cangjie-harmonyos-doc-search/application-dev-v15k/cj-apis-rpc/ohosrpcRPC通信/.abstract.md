This directory provides comprehensive API reference documentation for the HarmonyOS RPC (Remote Procedure Call) and IPC (Inter-Process Communication) modules using the Cangjie programming language. It covers essential components for enabling communication between processes and devices, including remote object management, data serialization, shared memory, and error handling. Key topics include `IRemoteObject`, `MessageSequence`, `Ashmem`, and `DeathRecipient`. This documentation is suitable for Cangjie developers and system engineers building distributed applications or services that require robust, high-performance communication mechanisms within the HarmonyOS ecosystem.
