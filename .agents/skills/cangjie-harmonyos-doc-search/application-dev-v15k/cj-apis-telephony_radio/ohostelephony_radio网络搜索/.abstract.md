This directory contains API reference documentation for the HarmonyOS `ohos.telephony_radio` network search module, specifically designed for the Cangjie programming language. It covers essential telephony functionalities including network registration states, signal information, radio technology identification, and 5G NSA configurations. The documentation details classes like `NetworkState` and `SignalInformation`, alongside various enums for network types and registration statuses. It is intended for developers building telephony applications on HarmonyOS who need to access device network capabilities, manage radio configurations, and monitor signal strength with system version 19 support.
