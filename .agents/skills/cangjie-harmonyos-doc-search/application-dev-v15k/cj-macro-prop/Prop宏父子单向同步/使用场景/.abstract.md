This directory contains technical guides and tutorials focused on state management and data synchronization scenarios within the Cangjie ArkUI framework. It covers various implementations of the @Prop decorator, ranging from simple data type synchronization to complex nested object management and array handling. Key topics include unidirectional data flow, the @Observed decorator, and change detection mechanisms. These resources are suitable for developers building HarmonyOS applications who need to understand how to effectively propagate state changes between parent and child components.
