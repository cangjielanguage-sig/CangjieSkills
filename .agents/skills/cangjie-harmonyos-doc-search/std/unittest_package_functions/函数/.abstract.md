This directory contains API reference documentation for core functions within the Cangjie language's unit testing framework. It covers essential utilities for assertion handling, test execution configuration, and failure management. Key topics include standard assertions like `assertEqual` and `assertCaughtUnexpectedE`, expectation-based validation, and mechanisms for invoking custom assertion logic. Additionally, it documents internal functions used for macro expansion regarding approximate equality. This documentation is suitable for Cangjie developers writing automated tests, framework maintainers, and advanced users implementing custom test validation logic.
