This directory contains API reference documentation for the `NavPathStack` class within the HarmonyOS ArkUI framework, written in the Cangjie language. It covers the comprehensive management of navigation routing stacks, including class initialization, stack manipulation (push, pop, remove, replace), and query functions. Key topics include handling page transitions, passing data between pages, managing nested navigation, and configuring launch modes. This documentation is intended for application developers seeking to implement and control complex page navigation logic programmatically in their HarmonyOS applications.
