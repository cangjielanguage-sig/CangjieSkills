This directory provides comprehensive API reference documentation for the Cangjie `InputMethodSetting` class, designed to facilitate the management of input method configurations within the IMEKit framework. It covers essential functionalities such as retrieving all installed input methods, filtering these lists based on enabled or disabled status, and querying specific subtypes of the current input method. Key technical aspects include obtaining instances via `getSetting`, handling return types like `InputMethodProperty`, and implementing robust error handling for exceptions such as `BusinessException` and `IllegalStateException`. Additionally, it details event subscription mechanisms and UI interaction functions. This documentation is specifically tailored for system developers who possess a solid understanding of Cangjie syntax and the InputMethodFramework system capability.
