# class_MediaAssetChangeRequest

This directory contains API reference documentation for the `MediaAssetChangeRequest` class in the Cangjie programming language, part of the MediaLibraryKit for HarmonyOS. It covers the management of media assets, including creating, modifying, deleting, and saving photos and videos. Key functionalities include handling change requests, adding resources via URI or byte arrays, managing write caches, and setting asset titles. The documentation details necessary permissions, error codes, and system capabilities. It is intended for HarmonyOS developers working on file management and photo access applications who need to implement robust media asset manipulation.
