# cangjie_package_compatibility

本目录详细记录了仓颉编程语言中关于包兼容性检查的技术规范与实现细节。自0.59.4版本起，仓颉引入了一套严格的运行时机制，用于在加载包时自动识别潜在的二进制兼容性问题，从而保障系统的稳定性。文档内容涵盖了版本匹配的核心逻辑，特别是针对主版本号为0（需精确匹配）和非0（主版本相同即可）的不同处理策略。此外，还详细说明了当检测到不兼容情况时的系统行为，包括Core包终止运行以及其他包抛出IncompatiblePackageException异常的具体场景。这份技术文档是仓颉开发者进行依赖管理、版本升级及错误排查的重要参考资料，有助于开发者构建更加健壮的应用程序。

### cangjie_package_compatibility.md cangjie_package_compatibility.md
这份文档介绍了仓颉编程语言自0.59.4版本引入的包兼容性检查机制，旨在运行时加载包时识别二进制兼容性问题。文档详细阐述了版本匹配规则及不兼容时的报错场景。核心规则为主版本号为0时需精确匹配，非0时主版本相同即可；不兼容时Core包终止运行，其他包抛出IncompatiblePackageException异常。该技术参考文档面向仓颉开发者，帮助其理解版本兼容逻辑及错误处理方式。
