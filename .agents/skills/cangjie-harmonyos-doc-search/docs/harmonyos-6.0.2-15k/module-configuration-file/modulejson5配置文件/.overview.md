# modulejson5配置文件

This directory contains comprehensive technical documentation for configuring the `module.json5` file in HarmonyOS and OpenHarmony application development. It covers essential configuration tags for defining module properties, permissions, abilities, extension abilities, and device-specific behaviors. Key topics include component lifecycle management, HAP distribution strategies, UI configuration, and system resource permissions. The resources provide detailed attribute tables, JSON examples, and usage scenarios for various tags like `abilities`, `skills`, and `metadata`. This documentation is suitable for application developers, system architects, and engineers who need to configure application manifests, manage module behaviors, and ensure proper packaging and deployment across diverse device profiles.

## Detailed Description

### definePermissions标签.md definePermissions标签.md
This document outlines the `definePermissions` tag for defining system resource permissions in OpenHarmony. It details attributes such as permission name, grant mode (system_grant/user_grant), and available level. Restricted to system HAP definitions, it includes a JSON example and is intended for system developers managing permission definitions.

### deviceTypes标签_2more.md deviceTypes标签_2more.md
This guide defines the `deviceTypes` and `pages` tags. It covers device type enumeration (tablet, default) and page profile configuration for routing paths relative to the source directory. It also details window display settings like `designWidth` for UI scaling, targeting developers configuring application modules.

### fileContextMenu标签.md fileContextMenu标签.md
This guide explains configuring right-click context menus for HAPs on PC and 2-in-1 devices using the `fileContextMenu` tag. It details the JSON structure, `menuContext` for trigger conditions, and the requirement for a `menu.json` file. It is intended for developers integrating file management extensions.

### hnpPackages标签.md hnpPackages标签.md
This document defines the `hnpPackages` tag for specifying Native software package information. It covers mandatory attributes like package name and type (public/private), providing a JSON example to assist developers configuring native modules.

### metadata标签.md metadata标签.md
This reference defines the `metadata` tag for storing custom meta-information in HAP configurations. It details attributes for window geometry and splash screen behavior, with JSON examples for HarmonyOS developers customizing application behaviors.

### shortcuts标签.md shortcuts标签.md
This guide explains configuring application shortcuts using the `shortcuts` tag. It covers attributes like `shortcutId` and `wants`, instructions for `shortcuts_config.json`, and linking via metadata. It helps developers implement quick access features for UIAbility components.

### startWindow标签.md startWindow标签.md
This documentation explains configuring the UIAbility startup page using the `startWindow` tag (API 18+). It details attributes for icons, branding, and background styles, assisting developers in defining custom startup experiences through resource file configuration.

### testRunner标签_4more.md testRunner标签_4more.md
This document defines the schema for `testRunner`, `dependencies`, `proxyData`, and `appEnvironments`. It provides attribute tables and JSON examples for developers configuring module behaviors, testing, dependency management, and environment setup.

### 配置文件示例.md 配置文件示例.md
This document provides a comprehensive `module.json5` example covering module info, device types, abilities, and permissions. It illustrates defining entry modules using the Ark virtual machine, targeting developers needing to configure module properties and system permissions.

### abilities标签
