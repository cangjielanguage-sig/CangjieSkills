# 结构体

This directory contains API reference documentation for various structs used in network programming within the Cangjie programming language. It covers essential components such as socket option levels, address families, protocol types, and socket configurations. Key topics include raw socket addressing, TCP KeepAlive settings, and cross-platform compatibility for socket domains and options. This documentation is suitable for systems programmers, backend developers, and network engineers who need to implement low-level network communication, manage socket behaviors, and ensure protocol compatibility across different operating systems like Windows, macOS, and Linux.

## Detailed Description

### struct_OptionLevel.md struct_OptionLevel.md
API reference for the Cangjie OptionLevel struct, detailing static constants for socket option levels (ICMP, IP, TCP, etc.). It provides integer values for protocol levels, noting OS-specific adaptations for the SOCKET constant. Essential for developers configuring network socket behaviors across platforms.

### struct_RawAddress.md struct_RawAddress.md
API reference for the RawAddress struct in Cangjie, defining address creation and retrieval for RawSocket operations. It covers the struct definition, the `addr` property for byte array access, and the constructor. Targets developers handling low-level network protocols and raw socket addressing.

### struct_SocketKeepAliveConfig.md struct_SocketKeepAliveConfig.md
Details the SocketKeepAliveConfig struct for configuring TCP KeepAlive in Cangjie. It covers properties like count, idle time, and interval, including default settings (45s idle, 5s interval) and exception handling. Intended for developers managing persistent connections and link failure detection.

### struct_SocketType.md struct_SocketType.md
Defines the SocketType struct in Cangjie, encapsulating socket communication types (DATAGRAM, STREAM, etc.). It details static constants, an Int32 initializer, and interfaces like Equatable and Hashable. Helps developers define and compare socket types efficiently in networked applications.

### struct_AddressFamily/
API reference for the AddressFamily struct, assisting in managing network socket addressing schemes. Covers IPv4, IPv6, Unix, and Netlink protocols, plus operator overloads. Suitable for developers configuring socket behavior and understanding platform-specific variations.

### struct_OptionName/
Technical guide for the OptionName struct and socket option constants in Cangjie. Details static integer constants for IP, socket, and TCP layers, highlighting cross-platform hexadecimal values for macOS and Windows. Targets developers needing precise socket configurations.

### struct_ProtocolType/
API reference for the ProtocolType struct, focusing on socket protocol types. Breaks down static properties for TCP, UDP, ICMP, etc., and covers comparison operators. Suitable for systems programmers implementing or comparing network protocols in Cangjie.

### struct_SocketDomain/
Reference for the SocketDomain struct, defining socket communication domains. Includes constants for IPv4, IPv6, Unix, and Netlink, with platform-specific considerations for Windows and macOS. Intended for engineers ensuring compatibility in socket configurations.

### struct_SocketOptions/
Documentation for the SocketOptions struct and constants, covering protocol levels and options like `SO_KEEPALIVE` and `TCP_NODELAY`. Provides platform-specific values and notes on deprecated constants. Suitable for developers needing low-level socket behavior control.
