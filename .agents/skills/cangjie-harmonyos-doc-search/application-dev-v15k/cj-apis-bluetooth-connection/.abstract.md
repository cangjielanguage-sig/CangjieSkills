This directory provides API reference documentation for the `ohos.bluetooth.connection` module within the HarmonyOS Cangjie development environment. It focuses on essential Bluetooth functionalities such as device discovery, pairing, connection management, and state monitoring. The documentation includes detailed descriptions of data structures for battery and device information, enums for transport and bond states, and functions for handling callbacks and remote device interactions. It is designed for developers utilizing the ConnectivityKit to implement robust Bluetooth communication features in Cangjie applications, ensuring proper handling of permissions, system capabilities, and asynchronous events.
