# class_CameraManager

This directory provides API reference documentation for the `CameraManager` class in the Cangjie language, focusing on the CameraKit framework. It covers the complete lifecycle of camera management, including querying supported devices, creating inputs and outputs (photo, video, preview), and managing sessions. The documentation also details event handling for status changes and torch (flashlight) control. Designed for software developers building multimedia applications, these references require knowledge of Cangjie syntax, system capabilities, and exception handling to effectively implement camera features.
