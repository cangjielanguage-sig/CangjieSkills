This directory serves as a comprehensive resource for the `process` package functions within the Cangjie programming language ecosystem. It focuses on system-level operations, specifically the management of subprocesses and external command execution. The content covers essential technical areas such as process creation, lifecycle control, input/output stream redirection, environment variable configuration, and working directory manipulation. Designed for Cangjie developers, this documentation provides the necessary API references to implement robust process handling, manage system resources efficiently, and execute external commands with precise control over timeouts and output capturing. It is an essential guide for anyone looking to integrate system-level capabilities into their Cangjie applications.
