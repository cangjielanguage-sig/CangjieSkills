# arkui-cj

This directory serves as a comprehensive documentation repository for the ArkUI framework implemented using the Cangjie (仓颉) programming language. It covers a wide range of development topics including UI components, layout systems, animation effects, state management, and universal attributes. Designed for HarmonyOS developers, it provides API references, code examples, and technical specifications to facilitate the creation of cross-device applications. The content is structured to support both beginners learning the framework and experienced developers looking for specific implementation details.

## Detailed Description

### Animation and Transition
This section covers property animations, geometry transitions, page transitions, shared transitions, and general transition effects using Cangjie. Key directories include [2] through [6].

### APIs and System Capabilities
Documentation for system modules like display, window, curves, shapes, and UI context controllers. It also includes error codes for animator, display, and window modules. See directories [7] through [19] and [46] through [48].

### Layout Components
Resources for structuring UI using Row, Column, Stack, Flex, Grid, and List components. It covers layout attributes, scrolling, and grid items. Refer to directories [56] through [59], [82] through [86], and [87] through [96].

### UI Components
A vast collection of component references including buttons, pickers, text inputs, images, video, dialogs, menus, and information display elements like gauges and progress bars. These are found in directories [21] through [32], [43] through [45], [60] through [72], [73] through [75], [101] through [108], and [149].

### Canvas and Graphics
Technical guides for 2D drawing, including Canvas, Path2D, ImageBitmap, and shape components (Circle, Rect, Ellipse). See directories [33] through [39] and [49] through [55].

### Universal Attributes and Events
Comprehensive references for styling (background, border, size) and handling interactions (click, touch, focus). These are detailed in directories [110] through [137] and [138] through [148].

### State and Framework
Core framework documentation covering application state, component lifecycle, and rendering logic (ForEach, LazyForEach). See directories [40] through [42], [97] through [100], and [109].
