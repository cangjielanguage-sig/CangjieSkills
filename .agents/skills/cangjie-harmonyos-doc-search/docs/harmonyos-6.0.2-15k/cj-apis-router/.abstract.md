The `cj-apis-router` directory serves as a comprehensive technical resource for developers working with the Cangjie language within the HarmonyOS ecosystem. It specifically houses API documentation for the `ohos.router` module, which is integral to the ArkUI framework. This collection covers the fundamental aspects of application navigation, including page jumping, stack management, and URL-based access. It is tailored for software engineers and mobile application developers who are building robust applications using Cangjie and need to master the intricacies of routing modes, page state tracking, and lifecycle management to ensure a smooth, professional user experience.
