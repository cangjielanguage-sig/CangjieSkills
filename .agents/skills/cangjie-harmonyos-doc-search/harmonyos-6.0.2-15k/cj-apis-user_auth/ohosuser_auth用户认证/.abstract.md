This directory contains API reference documentation for the `ohos.user_auth` module in the Cangjie programming language, designed for HarmonyOS user authentication. It covers essential components for implementing biometric and credential-based security, including authentication parameters, result handling, trust levels, and enrollment states. Developers can find definitions for classes like `AuthParam`, `UserAuthResult`, and `UserAuthInstance`, alongside enums for authentication types and error codes. This documentation is suitable for software engineers and system integrators building secure applications requiring features like device unlocking, payments, and identity verification using the SystemCapability.UserIAM.UserAuth.Core framework.
