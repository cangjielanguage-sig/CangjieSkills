# 创建组件

This directory provides comprehensive API reference documentation for creating and initializing the `GridRow` container component using the Cangjie language in the ArkUI framework. It covers a variety of constructor overloads designed to facilitate the development of responsive grid layouts. Key configuration options detailed here include layout spacing via `GutterOption` or `Length`, column definitions using `Int32` or `GridRowColumnOption`, and optional settings for breakpoints and layout direction. These documents are specifically tailored for ArkUI and HarmonyOS developers who need to implement adaptive grid systems with support for system capabilities starting from API version 12.
