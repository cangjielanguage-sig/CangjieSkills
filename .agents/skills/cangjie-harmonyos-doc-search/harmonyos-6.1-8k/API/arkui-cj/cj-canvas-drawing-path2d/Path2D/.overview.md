# Path2D

本文档目录主要介绍了 ArkUI 框架中的 Path2D 对象及其相关 API，旨在帮助开发者使用仓颉语言在 Canvas 上进行 2D 图形绘制。内容涵盖了 Path2D 的功能概述、开发状态、模块导入方式，以及详细的类接口参考，包括路径创建、基本图形绘制、贝塞尔曲线和路径变换等操作。该目录适合需要进行自定义矢量图形开发的 ArkUI 应用开发人员查阅，提供了构建复杂 2D 路径的完整技术细节。
