# enum_Orientation

This directory provides comprehensive API reference documentation for screen orientation and window management within the Cangjie programming language. It specifically addresses the definitions and behaviors of constants and enumerations used to control window display orientations. The content covers a wide range of modes, including static orientations (portrait and landscape), sensor-based auto-rotations, and user-forced temporary rotations. Key technical details include system capabilities requirements, version availability (starting from API 19), and interactions with system settings like the control center. This documentation is essential for application developers utilizing the WindowManager Core module who require precise control over how their applications respond to device rotation and display changes. By detailing specific constants and the broader `Orientation` enum, this directory equips developers to implement robust and user-friendly display behaviors.

## Detailed Description

### USER_ROTATION_PORTRAIT_5more.md USER_ROTATION_PORTRAIT_5more.md
This document serves as API reference documentation defining screen rotation constants for window management in the Cangjie programming language. It covers five specific rotation modes: standard and inverted portrait and landscape orientations, plus a mode to follow the desktop. Key takeaways include that user rotation modes temporarily force an orientation before reverting to sensor-based auto-rotation, subject to system control center settings. All constants require the WindowManager.Core system capability and are available starting from version 19. The target audience is application developers using the Cangjie language who need to control screen orientation behavior within their apps. Keywords: Cangjie, WindowManager, screen rotation, API, orientation, system capability.

### enum_Orientation_14more.md enum_Orientation_14more.md
This document serves as an API reference for the `Orientation` enum in the Cangjie programming language, defining window display orientation types. It details 17 enumeration values, categorized into static orientations (e.g., PORTRAIT, LANDSCAPE), sensor-based auto-rotations (e.g., AUTO_ROTATION), and system-specific modes (e.g., LOCKED, FOLLOW_DESKTOP). Key information includes specific behaviors for each mode, such as sensor dependency and control center restrictions, alongside system capabilities and version requirements. Intended for developers working on window management, this reference requires familiarity with the WindowManager Core module to implement correct display behaviors.
