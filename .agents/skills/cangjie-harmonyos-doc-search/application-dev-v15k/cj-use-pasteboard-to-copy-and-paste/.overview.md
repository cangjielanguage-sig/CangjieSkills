# cj-use-pasteboard-to-copy-and-paste

This directory serves as a technical resource for developers aiming to implement copy and paste functionality using the system pasteboard within the Cangjie development environment. It thoroughly explores usage scenarios, critical system constraints such as the 128MB data size limit, and necessary privacy permissions. The content covers the manipulation of basic data types, including plain text, HTML, and URIs. By detailing the `setData` and `getData` APIs, the guide provides a clear path for data transfer. It includes a complete Cangjie code example illustrating the creation, writing, and reading of clipboard data. This resource is ideal for application developers who need to integrate seamless data transfer capabilities, with a specific focus on data record management and the correct handling of URI files via the file management interface.
