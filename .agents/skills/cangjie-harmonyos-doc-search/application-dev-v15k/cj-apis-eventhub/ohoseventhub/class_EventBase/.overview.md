# class_EventBase

This directory provides essential API reference documentation for the `EventBase` class and related generic functions within the Cangjie AbilityKit framework. It covers the architecture for validating and managing event parameters, specifically detailing methods for handling events with zero to five generic parameters. Key topics include the abstract `EventBase` class, the `as0` through `as5` validation functions, specific return types like `Event0` through `Event5`, and error handling via `BusinessException`. This documentation is tailored for Cangjie developers implementing event-driven logic in applications requiring the `AbilityRuntime.Core` system capability, offering practical code examples for using `EventHub` to obtain, register, and emit events.
