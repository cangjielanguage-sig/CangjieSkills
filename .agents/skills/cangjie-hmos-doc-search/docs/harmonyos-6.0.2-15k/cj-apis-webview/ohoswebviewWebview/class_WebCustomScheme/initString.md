### init(String)

```cangjie
public init(schemeName: String)
```

**功能：** WebCustomScheme的构造函数。

**系统能力：** SystemCapability.Web.Webview.Core

**起始版本：** 20

**参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :---- | :--- | :--- | :--- | :--- |
| schemeName | String | 是 | - | 自定义协议名称。最大长度为32，其字符仅支持小写字母、数字、'.'、'+'、'-'，同时需要以字母开头。|
