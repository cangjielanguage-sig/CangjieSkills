# class_RandomAccessFile

This directory serves as a comprehensive repository for API reference documentation regarding the `RandomAccessFile` class in the Cangjie programming language. It focuses on enabling developers to perform random read and write access to files, which is essential for tasks requiring direct manipulation of file contents rather than sequential processing. The content covers core class properties like file descriptors and the file pointer, alongside methods for synchronous stream operations. Furthermore, it includes detailed guides on writing data using various buffer types and configuration options. This documentation is specifically tailored for software engineers and system developers working within the Cangjie ecosystem who need robust, low-level file I/O capabilities, precise error handling, and control over data encoding and file positioning. By utilizing these resources, developers can effectively manage file states, handle exceptions, and ensure data integrity during complex read-write operations.

## Detailed Description

The following files provide in-depth technical details for the components listed above:

### class_RandomAccessFile_6more.md
This document serves as API reference documentation for the RandomAccessFile class in the Cangjie language, enabling random read and write access to files. It covers essential properties such as the file descriptor (fd) and the current offset pointer (filePointer), alongside key methods for synchronously closing the stream, reading data into a buffer with configurable options, and manually setting the file pointer position. Key takeaways include the requirement to instantiate the object via createRandomAccessFile and the ability to specify read length and offset. This guide is intended for developers working on system-level file management and I/O operations within the Cangjie ecosystem.

### func_writeString_WriteOpti_2more.md
This API reference documentation details the synchronous write functions used to write data to files in the Cangjie programming language. The document covers two overloaded function signatures that accept either a String or an Array<Byte> as the data buffer. Key information includes the configuration of WriteOptions for specifying write length, file offset, and character encoding, as well as the return of the actual bytes written. It also lists potential exceptions and provides practical code examples. This resource is intended for developers implementing file management features who require precise control over file writing operations and error handling.
