This directory contains API reference documentation for the `PreviewOutput` class within the Cangjie CameraKit. It focuses on managing camera preview outputs, including configuration, frame rate control, rotation handling, and event listener management. Key topics include retrieving active profiles, setting frame rates, calculating display rotation, and registering callbacks for frame lifecycle or error events. The documentation is intended for developers using the Cangjie programming language to build multimedia camera applications on the HarmonyOS ecosystem, providing the necessary interfaces to control preview streams and handle system capabilities.
