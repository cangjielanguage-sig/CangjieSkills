This directory contains API reference documentation for the `CustomPopupOptions` class constructors within the Cangjie programming language and ArkUI framework. It covers the initialization of custom popup objects, detailing how to create empty instances or configure them with specific parameters like placement, colors, and callbacks. The documentation includes system capability requirements and version history, specifically targeting API version 19 and above. This resource is suitable for UI developers and software engineers using Cangjie to build ArkUI applications who need to implement customizable popup dialogs, tooltips, and bubble components with precise control over visual styling and interaction behaviors.
