# class_Location

本目录包含Cangjie语言中位置服务相关的API参考文档，主要涵盖Location类及其相关变量的定义。内容涉及地理位置信息的封装，包括经纬度、海拔、速度、航向等核心属性，以及时间戳和精度指标等关键数据。这些文档详细说明了数据类型、单位、取值范围及读写权限，适用于使用Cangjie语言进行定位服务开发、需要处理精确位置和时间信息的应用开发者。

## Detailed Description

### class_Location_13more_f157b9d6.md
本文档是Cangjie语言中Location类的API参考文档，用于封装和表示地理位置信息。文档详细列出了类的属性定义，涵盖经纬度、海拔、速度、航向等核心数据，以及各类精度指标和附加信息字段。关键信息指出坐标仅支持WGS84坐标系，属性包含单位说明（如米、度）及取值范围，且所有属性均具备读写能力。面向使用Cangjie语言进行位置服务开发的开发者，适用于需要处理定位数据的应用场景。

### var_speedAccuracy_4more_595ae93a.md
本文档定义了Cangjie语言中与定位和时间相关的四个公共变量。主要涵盖速度精度、开机时长、UTC时间戳及其不确定度等属性。这些变量均为可读写属性，属于系统能力SystemCapability.Location.Location.Core，起始版本为22，类型涵盖Float64和Int64。文档面向使用Cangjie进行定位服务开发的开发者，用于获取精确的时间和速度信息。关键词：Cangjie API, 定位服务, 变量定义, 时间戳, 速度精度。
