# cj-universal-event-touch

This directory serves as a comprehensive resource for the `cj-universal-event-touch` module, specifically focusing on the API reference documentation for the `onTouch` event handler within the Cangjie ArkUI framework. It is designed to assist developers in managing complex user interactions, including finger presses, slides, and lifts, across various UI components. The documentation thoroughly defines the `onTouch` function, outlining its required `TouchEvent` callback parameter and generic return values, while also specifying system capabilities and versioning requirements. This content is highly suitable for software developers and engineers who are actively building touch-responsive applications using the Cangjie language and need precise guidance on ArkUI module imports and event handling implementation.
