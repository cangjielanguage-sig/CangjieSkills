This directory serves as a comprehensive resource for the Cangjie HTTP framework, specifically focusing on the core class structures used to build robust web clients and servers. It covers essential networking components such as request and response handling, file transfers, WebSocket communication, and connection management. The documentation details support for HTTP/1.1, HTTP/2, and TLS configurations, alongside the builder pattern for object instantiation. It is designed for backend developers, software engineers, and system integrators utilizing the Cangjie programming language to implement efficient network communication and web services. By providing detailed API references, this directory aims to facilitate the development of scalable, secure, and high-performance applications, ensuring that users have all the necessary tools to master the framework's capabilities.
