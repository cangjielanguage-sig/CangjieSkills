# 自定义事件分发

This directory focuses on customizing touch event distribution within the ArkUI framework using the Cangjie language. It covers the `onChildTouchTest` mechanism, allowing developers to control how touch events are dispatched to child nodes, manage event conflicts, and handle geometric data for touch points. Key topics include touch result strategies, event propagation control, and coordinate system mappings. This documentation is intended for advanced Cangjie and ArkUI developers who need to build sophisticated UI interaction logic, resolve touch event conflicts in complex layouts, and implement granular control over event flows.

### 自定义事件分发_2more.md 自定义事件分发_2more.md
This document serves as API reference material for the ArkUI framework, detailing the `onChildTouchTest` function used to customize touch event distribution. It explains the mechanism where touch tests precede event triggering, allowing developers to influence child node responsiveness. The main sections cover the functional overview, a warning regarding potential unresponsiveness of gestures like `onClick` or rotation due to hot area mismatches, and the detailed API specification including parameters and return types. Key takeaways include the function's signature, which accepts a callback processing an array of `TouchTestInfo` and returning a `TouchResult`. Intended for advanced developers using the Cangjie language, this documentation requires understanding of touch event flows and component hierarchies.
