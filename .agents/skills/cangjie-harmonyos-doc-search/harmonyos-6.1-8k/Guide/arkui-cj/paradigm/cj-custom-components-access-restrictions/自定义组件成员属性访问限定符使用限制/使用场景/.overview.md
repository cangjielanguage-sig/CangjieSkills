# 使用场景

本目录主要介绍仓颉语言中ArkUI组件开发时，状态管理宏与访问限定符的规范使用场景。内容涵盖了禁止private与特定宏（如@State、@Prop）混用，以及禁止public与存储类宏（如@StorageLink）混用的规则。通过正反代码示例，帮助开发者理解编译校验逻辑，避免常见的语法错误。适合具备基础组件状态管理知识的仓颉开发者阅读。

## 详细描述

### 使用场景_1.md

本文档旨在规范仓颉语言中ArkUI组件状态管理宏与访问限定符的使用。文档主要涵盖两个关键场景：一是禁止将private修饰符与@State、@Prop、@Provide或@BuilderParam宏同时修饰成员变量；二是禁止将public修饰符与@StorageLink、@StorageProp、@LocalStorageLink、@LocalStorageProp或@Consume宏同时使用。通过反例与正例的代码对比，文档明确了正确的变量声明方式，帮助开发者避免编译错误。该指南适用于使用仓颉进行ArkUI应用开发的程序员，重点在于理解状态管理变量的访问权限限制。

### 使用场景_2.md

本文档旨在阐述仓颉语言中ArkUI组件开发的一项语法规则，即成员变量不能同时被private访问限定符和@Link宏修饰。文档通过反例展示了该组合导致的编译报错，并通过正例演示了移除private修饰符后的正确代码实现。核心要点在于编译器会对这种冲突进行严格校验。本文档属于开发规范指南，面向使用仓颉语言进行ArkUI应用开发的程序员，要求读者具备基本的组件状态管理知识。关键词包括仓颉、ArkUI、@Link、private修饰符、组件状态、编译校验。
