This directory contains essential API documentation for the Cangjie `Display` class and associated functions within the WindowManager framework. It focuses on providing developers with the tools necessary to query and interact with physical screen properties. The content covers a wide range of static attributes, such as screen dimensions, density metrics, orientation, and refresh rates, alongside specific functions for handling non-rectangular display areas like cutouts and notches. By detailing system capabilities, return types, and exception handling, this documentation serves as a critical resource for Cangjie developers and application engineers aiming to optimize user interfaces and ensure proper hardware interaction for diverse screen configurations.
