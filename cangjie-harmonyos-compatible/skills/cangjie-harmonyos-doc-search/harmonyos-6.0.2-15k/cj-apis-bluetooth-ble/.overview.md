# cj-apis-bluetooth-ble

This directory serves as a comprehensive resource for the Bluetooth Low Energy (BLE) APIs within the Cangjie programming language ecosystem, specifically tailored for HarmonyOS application development. It provides detailed documentation on the `ohos.bluetooth.ble` module, covering a wide array of functionalities such as peripheral advertising, central scanning, and Generic Attribute Profile (GATT) server and client operations. The content includes structural definitions for configuring broadcast packets, managing device connection states, and handling characteristic read/write interactions. This documentation is essential for software developers and system integrators aiming to implement robust, low-power wireless communication features. It targets API version 19 and above, requiring the `SystemCapability.Communication.Bluetooth.Core` system capability to function correctly. By utilizing these tools, developers can effectively manage BLE connections and data exchange in their Cangjie projects.

## Detailed Description

### ohosbluetoothble蓝牙ble模块/
This directory contains API reference documentation for the `ohos.bluetooth.ble` module in the Cangjie programming language, designed for HarmonyOS application development. It covers comprehensive Bluetooth Low Energy (BLE) functionalities, including advertising, scanning, GATT server and client operations, and data management. Key components include classes for configuring broadcast packets, managing connection states, and handling characteristic interactions. Suitable for software developers and system integrators, this module requires the `SystemCapability.Communication.Bluetooth.Core` capability and targets API version 19 and above. It provides the necessary tools to implement robust BLE communication features in Cangjie projects.
