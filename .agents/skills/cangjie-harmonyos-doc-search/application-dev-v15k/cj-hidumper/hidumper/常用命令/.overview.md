# 常用命令

This directory contains a comprehensive set of reference guides for the `hidumper` command-line tool used in HarmonyOS and OpenHarmony systems. It covers essential commands for inspecting system information, debugging system services, monitoring performance metrics like CPU and memory, and analyzing Inter-Process Communication (IPC). Additionally, it provides advanced techniques for JavaScript heap analysis and garbage collection. These documents are designed for system developers, QA engineers, and administrators who need to diagnose system states, troubleshoot crashes, or optimize application performance using command-line interfaces.

## Detailed Description

### 常用命令_1.md 常用命令_1.md
This document serves as a quick reference guide for using the `hidumper` command-line tool to inspect and debug system information in HarmonyOS. It details commands for viewing help, listing system information clusters and system abilities, and retrieving detailed data for specific clusters or individual system abilities. Key takeaways include the syntax for listing resources using `-lc` and `-ls`, and dumping detailed information using `-c` and `-s` flags, accompanied by practical usage examples. This technical reference is designed for system developers or engineers who need to diagnose system states, requiring familiarity with the command-line interface. Keywords: hidumper, HarmonyOS, system abilities, debugging, command reference, system clusters.

### 常用命令_2.md 常用命令_2.md
This document serves as a command reference guide for using the hidumper tool to debug and monitor system services. It covers WindowManagerService for window details, RenderService for graphics performance like FPS and memory, PowerManagerService for screen timeout control, and faultlog for crash history. Key commands include dumping specific window info, monitoring surface FPS, preventing auto-sleep, and retrieving system crash logs. It targets developers and system administrators needing to diagnose system performance or stability issues.

### 常用命令_3.md 常用命令_3.md
This document serves as a technical reference guide for using the hidumper command-line tool in HarmonyOS to retrieve system performance metrics. It details specific commands for monitoring network traffic, storage I/O, process lists, CPU usage and frequency, and memory statistics. Key information includes syntax options for filtering by process ID (PID) and example outputs, alongside a critical note that process information export is restricted to debug applications in release versions. The target audience is system developers or QA engineers requiring low-level system diagnostics and performance analysis.

### 常用命令_4.md 常用命令_4.md
This reference guide documents advanced usage of the hidumper command-line tool for system diagnostics. It covers three primary functions: memory analysis, log archiving, and Inter-Process Communication (IPC) statistics. The memory section explains retrieving global or PID-specific memory metrics, including a specific definition for the Graph field calculation. The IPC section details tracking performance metrics like time cost and call counts for specific or all processes using start, stat, and stop flags. Additionally, the zip command allows users to save command outputs to a compressed file. This guide targets system developers and administrators requiring tools to monitor memory usage and debug IPC performance.

### 常用命令_5.md 常用命令_5.md
This technical reference document details specific hidumper commands for analyzing system and application memory usage. It covers the --mem-smaps command for exporting detailed process memory statistics and the --mem-jsheap command for triggering garbage collection and exporting JavaScript heap snapshots. Key information includes version restrictions, as these features are primarily limited to debug builds, and explanations for optional flags like -v for verbose output, --gc for garbage collection only, and --leakobj for identifying memory leaks. The document is intended for developers and system engineers debugging memory performance or leaks, providing syntax, usage examples, and output file locations.

### 常用命令_6.md 常用命令_6.md
This document serves as a practical reference for using the hidumper tool to analyze JavaScript heap memory, trigger garbage collection, and detect memory leaks in a specific process. It covers command-line usage for dumping JS heap snapshots, specifying thread IDs, forcing garbage collection, and generating leak object lists. Key takeaways include the syntax for targeting a specific process ID and the naming conventions for the resulting dump files, such as hidumper-jsheap and hidumper-leaklist. This guide is intended for developers or system engineers debugging memory performance issues in OpenHarmony or similar environments, requiring familiarity with shell commands and process management.
