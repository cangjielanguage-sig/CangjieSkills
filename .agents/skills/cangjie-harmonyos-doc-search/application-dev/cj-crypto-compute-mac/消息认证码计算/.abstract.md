This directory focuses on the technical implementation of Message Authentication Codes (MAC) and Hash-based MAC (HMAC) to ensure data integrity and authenticity. It covers essential concepts such as shared key usage, tamper detection, and supported hash algorithms like SHA1, SHA256, SM3, and MD5. The content is designed for developers and security engineers working with the CryptoArchitectureKit in the Cangjie programming language. It provides specifications and practical guidance for integrating secure message verification mechanisms into software applications, ensuring compliance with security standards.
