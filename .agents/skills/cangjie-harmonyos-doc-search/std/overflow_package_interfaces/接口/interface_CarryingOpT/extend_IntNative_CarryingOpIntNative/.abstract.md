This directory provides comprehensive API documentation for the implementation of the `CarryingOp` interface as it applies to the `IntNative` type in the Cangjie programming language. It focuses on arithmetic operations that feature explicit overflow detection, utilizing a wrapping strategy to manage calculations safely. The content covers a broad spectrum of methods, including addition, subtraction, multiplication, division, modulo, and bit shifts. Crucially, these functions return a tuple consisting of a boolean flag indicating whether truncation occurred alongside the computed result. This documentation is specifically designed for Cangjie developers and systems programmers who need precise control over low-level arithmetic behavior and integer overflow states.
