# dynamic_feature

This directory serves as a comprehensive guide to the dynamic features of the Cangjie programming language, with a specific focus on the reflection mechanism and its diverse applications. While the root directory contains no direct files, it organizes critical documentation regarding the `TypeInfo` type, runtime type inspection, and member access. The content provides an in-depth look at the fundamental concepts of reflection, weighing its advantages and disadvantages, and demonstrates how to leverage core types to retrieve type information. Furthermore, it clarifies the technical distinctions between runtime and static types, outlines fully qualified name lookup rules, and illustrates how to access and modify public member variables dynamically. This resource is essential for Cangjie developers aiming to maximize program flexibility and extensibility or those requiring dynamic object manipulation capabilities in their software architecture.

## Detailed Description

### 动态特性/

This subdirectory acts as the primary resource for understanding the dynamic features of the Cangjie language, with a strong emphasis on the reflection mechanism. It begins by establishing a solid foundation, covering the basic concepts of reflection and providing a balanced view of its pros and cons. This theoretical background is crucial for developers to understand when and why to employ reflection in their codebases effectively.

Moving into practical application, the content details the usage of the core `TypeInfo` type. It explains how developers can utilize this type to query type information and access class members dynamically. The documentation also clarifies the technical nuances between runtime types and static types, a distinction that is vital for writing robust dynamic code. Furthermore, it outlines the specific rules for fully qualified name lookups, ensuring accurate type resolution during execution.

Finally, the guide covers the manipulation of object states, specifically how to access and modify public member variables using reflection. By mastering these techniques, developers can significantly enhance the flexibility and extensibility of their programs. This section is particularly suitable for Cangjie language developers who are interested in advanced programming patterns, dynamic object operations, or building systems that require high adaptability. These materials are specifically curated for those looking to move beyond static coding patterns and leverage the full power of the language's runtime capabilities.
