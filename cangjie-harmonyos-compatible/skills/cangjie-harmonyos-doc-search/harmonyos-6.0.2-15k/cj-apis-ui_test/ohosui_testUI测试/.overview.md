This directory contains API reference documentation for the HarmonyOS UI testing framework in the Cangjie language. Key components include the Driver, UIComponent, and TestRunner classes, alongside support for multi-touch simulation and event observation. Designed for software developers and QA engineers, these documents facilitate the creation of robust automated test scripts using the TestKit framework, ensuring comprehensive UI behavior verification for HarmonyOS applications.
