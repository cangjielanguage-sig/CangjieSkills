This directory contains comprehensive documentation and practical examples for the `tsv<T>` function within the Cangjie programming language. It focuses on utilizing Tab-Separated Values (TSV) files to generate parameter sources for data-driven unit testing. The content covers the complete API reference, detailing function signatures, configuration parameters like file paths and quote characters, and return types such as `CsvStrategy<T>`. Additionally, it includes code examples demonstrating object deserialization, pattern matching, and assertion-based validation. This resource is essential for Cangjie developers who need to map external data to serializable objects, implement flexible parsing options, or build robust test suites using TSV inputs.
