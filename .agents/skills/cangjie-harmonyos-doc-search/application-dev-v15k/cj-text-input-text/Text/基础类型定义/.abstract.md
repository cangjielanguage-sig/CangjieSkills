This directory provides API reference documentation for fundamental data structures and classes in the Cangjie language, specifically designed for the ArkUI framework. It covers essential UI components including shadow configurations, text controllers, font styling, and menu item definitions. Additionally, it details enumerations for text interaction, data detection, and selection states. These definitions are critical for developers building HarmonyOS applications who need to implement visual effects, manage text behaviors, and customize user interface elements programmatically. The documentation targets software developers working with API versions 12 and above.
