This directory hosts the API documentation for enumerations belonging to the `argopt` package, a core component for command-line argument parsing in the Cangjie programming language. It provides the foundational definitions required to structure and parse command-line inputs effectively. The content focuses on two primary enumerations: `ArgumentMode`, which dictates parameter requirements, and `ArgumentSpec`, which defines the syntax of options. This documentation is highly suitable for systems programmers and developers building CLI tools in Cangjie who require precise control over argument behaviors, validation, and callback handling. By standardizing how arguments are defined, this package helps reduce boilerplate code and minimizes parsing errors. Key search terms include Cangjie, CLI parsing, enumerations, ArgumentMode, and ArgumentSpec.
