This directory contains API reference documentation for the `VideoSession` class within the Cangjie CameraKit framework. It covers the core structure for standard video recording, including session management, event handling, and preconfiguration settings. Key topics include camera capabilities like Flash, AutoExposure, Focus, and Zoom, as well as methods for registering and unregistering callbacks for errors and state changes. The documentation provides Cangjie code examples and details system capabilities. It is intended for developers building camera applications who need to manage video recording sessions, handle asynchronous events, and configure camera parameters programmatically.
