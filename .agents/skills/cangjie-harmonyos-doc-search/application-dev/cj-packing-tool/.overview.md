# cj-packing-tool

The `cj-packing-tool` directory serves as a vital technical resource repository for developers and build engineers working within the HarmonyOS ecosystem. It focuses specifically on the `app_packing_tool.jar`, a command-line utility designed to facilitate the application packaging process without relying on an Integrated Development Environment (IDE). The directory provides extensive documentation on generating various package types, including HAP, HSP, and App packages, while supporting diverse packaging modes such as standard builds, FastApp, and multi-project merging. Beyond basic packaging, it offers guidance on advanced operations like creating hotfixes (HQF) and normalizing version numbers across modules to ensure consistency. These resources are indispensable for teams aiming to automate deployment pipelines, manage complex module dependencies, and maintain high standards of build integrity. By utilizing the guides found here, users can streamline their development workflows and ensure their applications are packaged correctly for distribution.

## Detailed Description

### [1] 打包工具/
This directory provides comprehensive technical documentation for the HarmonyOS application packaging tool (`app_packing_tool.jar`). It covers command-line instructions for generating HAP, HSP, and App packages, supporting various modes such as standard packaging, FastApp, and multi-project merging. Additionally, it includes guides for creating hotfixes (HQF) and normalizing version numbers across modules. These resources are essential for developers and build engineers seeking to automate deployment, manage complex module dependencies, and ensure consistency in application builds outside of the IDE environment.
