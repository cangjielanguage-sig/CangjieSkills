# 使用AES对称密钥GCM模式分段加解密仓颉

This directory contains technical documentation and practical code examples for implementing AES symmetric encryption and decryption using GCM mode in the Cangjie programming language. It focuses specifically on segmented processing techniques designed to handle large data volumes efficiently without loading entire files into memory. Key topics include key generation, initialization vector (IV) management, Additional Authenticated Data (AAD), and authentication tag handling using the CryptoArchitectureKit. The content is suitable for Cangjie developers looking to implement secure data transmission and cryptographic security features in their applications.
