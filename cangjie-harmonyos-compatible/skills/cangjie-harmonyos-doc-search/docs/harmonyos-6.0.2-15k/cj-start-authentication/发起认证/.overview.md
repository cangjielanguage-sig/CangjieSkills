# 发起认证

This directory provides comprehensive resources for initiating user identity authentication to access protected system features and data. It covers the core concepts of the UserAuthenticationKit, detailing API interfaces such as `getUserAuthInstance`, `start`, and result subscription methods. A major focus is placed on the unified user authentication widget, which ensures biometric data security and consistent UI across applications. The content includes guidance on supported authentication types like fingerprint and face recognition. It is suitable for developers seeking to implement secure, high-trust authentication flows, manage permissions, and configure authentication parameters effectively within their applications. The directory bridges the gap between theoretical API definitions and practical implementation strategies.

## Detailed Description

### 发起认证_4more.md 发起认证_4more.md
This document serves as a technical guide for developers on how to initiate user identity authentication requests. It details key API interfaces, including `getUserAuthInstance`, `start`, and methods for subscribing to authentication results. A significant portion of the text is dedicated to the unified user authentication widget, highlighting its advantages for biometric data security and UI consistency, while listing supported types such as fingerprint and face recognition. The guide outlines a clear four-step development process: applying for the `ACCESS_BIOMETRIC` permission, configuring `AuthParam` and `WidgetParam`, subscribing to results, and executing the authentication. It is intended for developers implementing secure authentication flows using the UserAuthenticationKit.

### 示例代码/
This subdirectory contains Cangjie code examples focused on implementing user authentication using the UserAuthenticationKit. It covers various practical scenarios, including basic biometric (Face) and PIN authentication at specific trust levels, as well as advanced features like reusing device unlock states and cross-application authentication. The examples demonstrate how to configure authentication parameters (`AuthParam`), manage UI widgets, handle asynchronous callbacks, and manage exceptions. These resources are suitable for developers integrating secure biometric verification and credential management into their applications, providing practical implementations for handling security workflows, trust level configurations, and the complete authentication lifecycle.
