# 开发步骤

This directory provides a comprehensive tutorial series for implementing data persistence using relational databases in the Cangjie programming language. It covers the full development lifecycle, from initializing the RdbStore and configuring database properties to performing essential data manipulation operations like inserting, updating, and querying records. Additionally, it addresses advanced maintenance tasks such as database backup, restoration, and deletion. Designed for application developers familiar with Cangjie and ArkUI, these guides offer practical code examples for managing local data storage effectively within UIAbility components.

## Quick Navigation

**What do you want to learn?**

*   Initialize the database and insert data → 开发步骤_1.md
*   Update, delete, query, or backup the database → 开发步骤_2.md
*   Delete the database store and handle exceptions → 开发步骤_3.md

## Detailed Description

### 开发步骤_1.md
This tutorial guides developers through implementing data persistence using a relational database in the Cangjie language. It covers the essential steps of obtaining an RdbStore instance, configuring database properties like security levels and paths, and executing SQL commands to create or alter tables within a UIAbility. The document further explains how to insert data using a HashMap with specific value types. Key takeaways include the dependency on application context for database isolation and the handling of temporary database files. Intended for application developers familiar with Cangjie and ArkUI, this guide provides the foundational code needed to set up and populate a local relational database for application development.

### 开发步骤_2.md
This document serves as a development tutorial for managing relational databases using the Cangjie programming language. It covers essential data manipulation and maintenance operations, including updating and deleting records using predicates, querying data with ResultSets, and performing database backup, restoration, and deletion. Key takeaways include the automatic persistence of data upon insertion and the necessity of closing ResultSets to release memory. The guide provides code examples for methods like update, delete, query, backup, and restore. It targets application developers seeking to implement local data storage and lifecycle management within their software projects.

### 开发步骤_3.md
This document serves as a tutorial step demonstrating how to programmatically delete a relational database store using the Cangjie language. The content focuses on the deleteRdbStore function, configuration parameters like StoreConfig and RelationalStoreSecurityLevel, and exception handling mechanisms. Key information includes the implementation of a try-catch block to manage BusinessException and the use of Hilog for tracking success or failure with specific error codes. This snippet is intended for developers familiar with Cangjie syntax and database management, providing a practical example of resource cleanup and error logging in application development.
