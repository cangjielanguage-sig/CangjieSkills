# Stage模型应用程序包结构

This directory provides comprehensive technical documentation on the application package structure for the HarmonyOS Stage model. It covers the project hierarchy during development, including configuration files like `app.json5` and `module.json5`, Cangjie source code, and resource management. Additionally, it details the structural transformation from the development phase to the final release state, explaining HAP generation, resource merging, and distribution packaging. Key topics include DevEco Studio project organization, build artifacts, and the distinction between App Packs and HAPs. This guide is suitable for HarmonyOS developers using the Cangjie language who need to understand project organization, build processes, and packaging logic.

## Detailed Description

### Stage模型应用程序包结构_2more.md Stage模型应用程序包结构_2more.md
This technical guide outlines the application package structure for the Stage model during the development phase within DevEco Studio. It covers the project hierarchy, specifically distinguishing between the global AppScope and individual Module directories. Key information includes detailed descriptions of configuration files like app.json5 and module.json5, Cangjie source code files (.cj), resource directories, and build scripts such as build-profile.json5. The document emphasizes the importance of preserving the AppScope directory name to ensure successful compilation. Targeted at HarmonyOS developers using the Cangjie language, this guide serves as a reference for understanding project organization, file dependencies, and the roles of various configuration and source files in the development environment.

### 编译态包结构_2more.md 编译态包结构_2more.md
This technical guide details the structural transformation of HarmonyOS applications from the development phase through compilation to the final release state. It covers the compile-time package structure, explaining how modules generate HAP files, merge resources and configurations, and handle Cangjie source code. It also details the release-time structure, defining Bundles and App Packs for market distribution. Key takeaways include the precedence of AppScope resources, the generation of the pack.info file, and the distinction that App Packs are for distribution while HAPs are the units for installation and signing. This reference material targets HarmonyOS developers using DevEco Studio who need to understand build artifacts and packaging logic.
