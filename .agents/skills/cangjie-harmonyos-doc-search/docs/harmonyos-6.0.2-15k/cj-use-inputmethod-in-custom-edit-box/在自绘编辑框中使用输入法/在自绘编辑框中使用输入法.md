# 在自绘编辑框中使用输入法

在输入法框架中，可以通过[getController](../../API_Reference/source_zh_cn/apis/IMEKit/cj-apis-inputmethod.md#func-getcontroller)方法获取到[InputMethodController](../../API_Reference/source_zh_cn/apis/IMEKit/cj-apis-inputmethod.md#class-inputmethodcontroller)实例来绑定输入法并监听输入法应用的各种操作，比如插入、删除、选择、光标移动等。这样就可以在自绘编辑框中使用输入法，并实现更加灵活和自由的编辑操作。
