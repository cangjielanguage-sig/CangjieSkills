# 设置锚点

This directory provides comprehensive technical documentation on configuring anchor points within the RelativeContainer component of the ArkUI framework. It covers the fundamental principles of defining position dependencies relative to parents, siblings, guidelines, or barriers, utilizing both Cangjie and ArkTS programming languages. Key topics include the strict requirement for unique component IDs, the specific syntax for referencing the container ID `__container__`, and critical rules for avoiding dependency cycles to ensure stable rendering. These resources are specifically designed for developers working on the HarmonyOS platform who require precise control over component positioning and need to construct complex, interconnected user interface layouts with robust relative positioning capabilities.

## Detailed Description

### 设置锚点_1.md
This technical guide explains how to configure anchor points for child elements within a RelativeContainer in the ArkUI framework using Cangjie syntax. It covers the definition of position dependencies relative to parents, siblings, guidelines, or barriers, emphasizing the requirement for unique component IDs. Key sections include rules for avoiding dependency cycles and code examples demonstrating anchoring to the parent container and sibling elements. The document highlights that the parent container uses the ID `__container__` and warns against circular dependencies to prevent rendering failures. Intended for developers, this guide assumes familiarity with ArkUI layout principles and Cangjie programming.

### 设置锚点_2.md
This document serves as a practical tutorial demonstrating how to configure anchor points and alignment rules within a RelativeContainer using ArkTS. The main topic focuses on relative positioning, specifically utilizing the alignRules property with VerticalAnchor and HorizontalAnchor to define component placement. Key information includes the syntax for referencing the container ID ("__container__") and sibling component IDs (e.g., "row1", "row2") to create a complex, interconnected layout of four rows. This guide is designed for developers building user interfaces on the HarmonyOS platform who require precise control over component positioning and layout dependencies.
