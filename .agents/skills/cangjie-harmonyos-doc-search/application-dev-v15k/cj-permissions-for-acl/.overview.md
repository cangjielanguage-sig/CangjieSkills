# cj-permissions-for-acl

This directory, `cj-permissions-for-acl`, serves as a comprehensive technical resource and definitive guide for managing Access Control Lists (ACL) and restricted open permissions within the HarmonyOS and OpenHarmony development environments. It specifically addresses the complex, multi-layered requirements developers face when seeking access to sensitive system capabilities that are otherwise protected by the operating system's security architecture. The content covers the complete lifecycle of permission management, beginning with the initial application process and eligibility criteria, moving through the rigorous App Gallery Connect (AGC) review, and concluding with the strict compliance audits required for app publication. It emphasizes the critical nature of matching usage scenarios to requested permissions to avoid rejection. Furthermore, the directory provides detailed reference documentation for specific permissions introduced in API version 12, covering areas such as hardware access (HID, USB), file manipulation, data sharing, and advanced system features like virtual screens. This resource is essential for HarmonyOS developers and system engineers who need to securely implement high-risk functionalities while adhering to platform security standards.
