This directory serves as a comprehensive repository for the interoperability guidelines between the Cangjie (CJ) language and ArkTS, specifically tailored for the HarmonyOS development environment. It addresses the complexities of bridging native code with script-based environments, providing rigorous standards for threading models, memory management, exception handling, and object lifecycle management. The content highlights critical operational constraints such as main thread restrictions, proper JSRuntime utilization, and cross-engine context safety. Furthermore, it offers strategies for preventing common issues like memory leaks. This resource is indispensable for HarmonyOS developers and system engineers who require a deep understanding of native-script integration to build robust, high-performance applications.
