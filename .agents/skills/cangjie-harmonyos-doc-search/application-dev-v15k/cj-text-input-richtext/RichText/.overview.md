# RichText

This directory provides essential resources for the RichText component within the Cangjie framework and HarmonyOS ecosystem. It focuses on the functionality of parsing and displaying HTML strings, offering a deep dive into API references, component creation methods, and supported universal attributes. The documentation highlights specific component events like `onStart` and `onComplete`, while also addressing critical performance constraints such as memory usage in Lists and limited attribute support. Additionally, it includes practical implementation examples for layout configuration. This content is tailored for developers using ArkUI who need to integrate web content into their applications, balancing theoretical knowledge with coding best practices.

## Detailed Description

### RichText_5more.md RichText_5more.md
This API reference document details the RichText component, designed to parse and display HTML strings within the Cangjie framework. It covers usage scenarios, component creation via the init method, supported universal attributes, and specific component events like onStart and onComplete. Key information includes the component's reliance on Web capabilities, limited attribute support restricted to size properties, and performance warnings regarding memory usage in repetitive scenarios like Lists. The document advises using the Web component for complex styling or RichEditor for high-frequency rendering. It targets developers seeking to integrate HTML content into their applications using ArkUI.
