# 功能介绍

This directory provides comprehensive documentation for a robust network communication package supporting HTTP/1.1, HTTP/2, and WebSocket protocols. It covers essential setup requirements, specifically OpenSSL 3 integration, and details the implementation of HTTP clients and servers with TLS/ALPN support. Additionally, it explains WebSocket protocol upgrades, frame handling, and connection management across different HTTP versions. Targeted at developers building real-time communication systems or high-performance network applications, these guides ensure proper environment configuration and effective utilization of the library's features.

## Detailed Description

### WebSocket.md WebSocket.md
This document outlines a WebSocket implementation that facilitates protocol upgrades from HTTP/1.1 or HTTP/2, providing essential communication features like frame handling and connection management. It covers core functionalities including sub-protocol negotiation, frame encoding and decoding, ping/pong mechanisms, and connection closure. The text details specific upgrade methods for both client-side (upgradeFromClient) and server-side (upgradeFromServer) contexts. A crucial distinction is made between HTTP/1.1 and HTTP/2 underlying connections: HTTP/1.1 uses TCP/TLS, whereas HTTP/2 utilizes a stream. Consequently, closing a connection in HTTP/2 terminates only the stream, not the entire connection. Targeted at developers integrating real-time communication, this reference requires understanding of HTTP protocols and WebSocket standards.

### http.md http.md
This document serves as a technical guide for an HTTP library supporting both HTTP/1.1 and HTTP/2 protocols. It details protocol configuration, noting that HTTP/2 requires TLS and ALPN negotiation with automatic fallback to HTTP/1.1. Key sections explain the use of ClientBuilder and ServerBuilder for constructing immutable instances, and HttpRequestBuilder or HttpResponseBuilder for handling data transfer. The document highlights that most parameters are fixed after building, though specific server features like certificate hot updates exist. It also mentions utility handlers for redirects and 404 errors. Intended for developers implementing network clients and servers, it requires understanding of thread safety for custom loggers.

### 功能介绍.md 功能介绍.md
This document serves as a functional introduction and setup guide for an HTTP package supporting HTTP/1.1, HTTP/2, and WebSocket protocols. It covers protocol references and provides detailed installation instructions for the mandatory OpenSSL 3 dependency across Linux, Windows, and macOS. Key information includes the requirement for specific dynamic libraries (libssl, libcrypto) and the configuration of environment variables like LD_LIBRARY_PATH and PATH to ensure proper linking. The document warns that missing or outdated OpenSSL versions will cause TLS exceptions. Intended for developers, this guide ensures the correct runtime environment is established before utilizing the package's client and server implementations.
