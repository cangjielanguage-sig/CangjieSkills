# 被拉起应用开发指导

This directory provides a comprehensive guide for HarmonyOS developers on implementing App Linking functionality, allowing applications to be launched directly via web URLs. It covers the end-to-end process from service activation in AppGallery Connect (AGC) to local configuration in DevEco Studio and handling incoming links in Cangjie code. Key topics include domain verification, JSON file hosting, `module.json5` configuration, and URI parsing within lifecycle methods. This resource is suitable for developers seeking to integrate secure deep linking capabilities into their HarmonyOS applications.

## Detailed Description

### 在AGC控制台开通App_Linking服务_3more.md 在AGC控制台开通App_Linking服务_3more.md
This technical tutorial guides HarmonyOS developers through enabling and configuring the App Linking service within the AppGallery Connect console. The document covers three primary steps: activating the service and retrieving the APP ID, creating and hosting a verification JSON file on the developer's website server, and associating the specific domain in the AGC console. Key takeaways include the requirement to place the applinking.json file in the .well-known directory for security validation and the system's automatic intersection verification process that updates every 24 hours. This guide is essential for developers implementing deep linking capabilities to ensure secure redirection from web URLs to HarmonyOS applications.

### 在DevEco_Studio中配置关联的网址域名.md 在DevEco_Studio中配置关联的网址域名.md
This guide instructs developers on configuring associated domain names and enabling domain verification within the DevEco Studio module.json5 file. It details the specific requirements for the skills configuration, including mandatory entities, actions, and URI schemes. Key takeaways include the necessity of creating a separate skill object for App Linking rather than modifying the default entry skill, setting the URI scheme to https, and enabling the domainVerify switch. This technical documentation is intended for HarmonyOS application developers seeking to implement deep linking or domain association capabilities for their applications.

### 处理传入的链接_2more.md 处理传入的链接_2more.md
This technical guide instructs developers on handling incoming links in Cangjie applications by processing URIs within the UIAbility lifecycle methods, specifically onCreate or onNewWant. The document details how to parse query parameters from the want.uri to trigger specific business logic. Additionally, it provides a verification workflow that emphasizes the critical requirement of manual application signing, as auto-signing prevents the app from being launched. The guide targets Cangjie developers implementing App Linking features, offering code examples and testing procedures to ensure successful deep link integration.
