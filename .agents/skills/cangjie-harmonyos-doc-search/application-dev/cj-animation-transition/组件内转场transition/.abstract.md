This directory provides comprehensive documentation for implementing component internal transitions within the ArkUI framework using the Cangjie language. It covers essential configuration classes for scaling, translation, and rotation transformations, alongside the core `TransitionEffect` API for defining entry and exit animations. The content includes detailed API references for options classes, enums for edge definitions, and practical code examples demonstrating bidirectional and asymmetric transitions. Designed for ArkUI developers and UI engineers, these resources facilitate the creation of smooth, state-driven visual changes and dynamic user interface behaviors in HarmonyOS applications.
