This directory focuses on the common properties for graphic drawing components within the ArkUI framework using the Cangjie language. It covers supported components like Circle, Ellipse, Line, Path, Rect, and Shape, detailing shared attributes for fill, stroke, and rendering. Key topics include styling, stroke properties (dash arrays, line caps), and viewport management. Suitable for developers using Cangjie to build user interfaces with ArkUI who need precise control over 2D graphics rendering and aesthetic customization.
