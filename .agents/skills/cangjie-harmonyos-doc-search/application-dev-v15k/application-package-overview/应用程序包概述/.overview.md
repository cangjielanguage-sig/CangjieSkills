## Detailed Description

### 应用程序包概述_4more.md
This technical guide provides a comprehensive overview of application packages specifically for the Stage model. It defines core concepts such as applications and packages, placing a strong emphasis on system management and cross-platform compatibility. The document details the multi-module design mechanism, explaining how modular development facilitates loose coupling and adaptation across multiple devices. It categorizes modules into Ability types, which generate HAP files (including entry and feature modules), and Library types, which generate HAR static shared packages for code reuse. Key takeaways include understanding the structure of HAPs as installation units and the specific compilation characteristics of HARs. This guide is intended for developers who need to grasp the package architecture before developing HarmonyOS applications.

### 选择合适的包类型.md
This guide assists HarmonyOS developers in selecting the appropriate package type, HAP or HAR, by comparing their functions and technical specifications. The document features two detailed comparison tables that outline usage scenarios and supported capabilities. Key information highlights that HAP packages are independent modules installable on devices, supporting both UIAbility and ExtensionAbility components. In contrast, HAR packages are static shared libraries designed for compile-time reuse, making them suitable for internal or third-party SDK distribution via OHPM. However, HARs cannot run independently and may lead to code duplication. The text also notes that HAR does not support circular or transitive dependencies. This reference is intended for HarmonyOS application developers designing module architecture and managing dependencies.
