# socket_option

This directory provides a specialized collection of documentation and practical guides focused on the configuration and customization of socket attributes within the Cangjie programming language. It serves as an essential technical resource for developers who require precise control over network communication behaviors. The content thoroughly covers the configuration of standard TCP socket properties—such as `readTimeout`, `noDelay`, `linger`, and `keepAlive`—using the standard library's built-in capabilities. Furthermore, it addresses advanced scenarios by demonstrating how to extend socket functionality. By leveraging native functions like `getSocketOptionIntNative` and `setSocketOptionIntNative`, developers can interact directly with the underlying operating system to implement custom attributes. This directory is highly suitable for Cangjie developers aiming to optimize network performance, troubleshoot connection issues, or extend the standard library's capabilities to meet specific application requirements. By following these guides, users can gain a deeper understanding of network stack management within the Cangjie ecosystem.

### socket_option.md socket_option.md

This document acts as a comprehensive practical usage guide designed for developers working with socket attributes in the Cangjie programming language. It is structured into two primary sections to address different levels of configuration needs.

The first section focuses on standard property configuration. It provides clear demonstrations on how to set built-in `TcpSocket` options using the standard library. Key properties covered in this section include `readTimeout`, `noDelay`, `linger`, and `keepAlive`, which are essential for controlling connection behavior and performance.

The second section delves into advanced customization by explaining how to extend socket functionality. It details the process of adding custom attributes by extending the `TcpSocket` class. This involves utilizing native functions, specifically `getSocketOptionIntNative` and `setSocketOptionIntNative`, to interact directly with the underlying system. This tutorial is particularly valuable for Cangjie developers who need to customize network behavior beyond standard offerings or extend the capabilities of the standard library. By mastering these techniques, developers can ensure their applications maintain robust and efficient network connections tailored to specific operational needs.
