# 主要场景开发步骤

This directory outlines the essential development steps for primary Bluetooth Low Energy (BLE) scenarios within the HarmonyOS ecosystem. It focuses on the practical implementation of GATT (Generic Attribute Profile) protocols, comprehensively covering both server-side service management and client-side data interaction. Key topics include BLE server initialization, service addition, client notifications, connection establishment, and read/write operations. The documentation provides detailed code examples in both Cangjie and ArkTS to facilitate understanding. It is specifically suitable for software developers and engineers aiming to build robust connectivity features, manage GATT server logic, or implement client communication in HarmonyOS applications, ensuring a thorough grasp of asynchronous callback handling and UUID management.

## Detailed Description

### server端操作services和通知客户端信息
This directory contains technical documentation and code examples for implementing a Bluetooth Low Energy (BLE) GATT Server, focusing on service management and client notifications. It covers the complete server lifecycle, including initialization, service addition, handling client read/write requests, and resource cleanup. The content includes implementations in both Cangjie and ArkTS, detailing specific UUIDs, callback mechanisms, and response handling. It is suitable for software developers working on connectivity features in HarmonyOS applications who need to manage BLE server-side logic and interactions with GATT clients.

### 连接server端读取和写入信息
This directory provides technical guides and code examples for implementing Bluetooth Low Energy (BLE) GATT client functionality, specifically focusing on connecting to a server to read and write data. It covers the complete workflow from establishing connections and discovering services to performing read/write operations and managing disconnections. The content includes implementations in both Cangjie and ArkTS languages within the HarmonyOS ecosystem. It is suitable for developers looking to integrate BLE communication into their applications, offering detailed insights into GATT protocols, UUID management, and asynchronous callback handling.
