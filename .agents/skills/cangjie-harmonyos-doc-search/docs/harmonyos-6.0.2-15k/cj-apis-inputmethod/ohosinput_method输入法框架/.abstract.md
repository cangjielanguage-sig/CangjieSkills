This directory contains the API reference documentation for the HarmonyOS Input Method Framework (IMF) implemented in the Cangjie programming language. It covers essential components for developing and managing input method editors (IMEs), including data structures for text configuration, window management, and event handling. Key topics include input attributes, keyboard status, cursor control, and system settings. Designed for system developers and application engineers working on text entry interfaces, this documentation provides the necessary definitions and utilities to integrate robust input functionalities within the HarmonyOS ecosystem.
