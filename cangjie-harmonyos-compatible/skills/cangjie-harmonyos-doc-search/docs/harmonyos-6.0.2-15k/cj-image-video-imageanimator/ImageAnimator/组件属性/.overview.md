# 组件属性

This directory serves as a comprehensive repository for API reference documentation regarding component properties within the ArkUI framework, specifically tailored for the Cangjie programming language. The content primarily focuses on the intricate configuration of animation-related attributes, providing developers with the necessary tools to implement dynamic visual effects. It covers a wide range of functionalities, from the granular control of image frame animations—such as duration, fill modes, and iteration counts—to the high-level management of animation playback statuses. By detailing specific function signatures, parameters, and system capabilities, this directory acts as a vital technical guide for optimizing user interface interactions. It is highly suitable for developers, UI engineers, and system architects who possess a working knowledge of ArkUI components and Cangjie syntax and are seeking to enhance the interactivity and responsiveness of their applications through precise animation control. The documentation ensures that developers can effectively leverage the framework's capabilities to create smooth and engaging user experiences.

## Detailed Description

### func_durationInt32_7more.md func_durationInt32_7more.md
This document serves as an API reference for configuring image frame animation properties within the ArkUI framework using the Cangjie language. It details seven functions: duration, fillMode, fixedSize, images, iterations, preDecode, and reverse. Key functionalities include setting playback duration in milliseconds, defining animation start and end states via fillMode, managing frame sequences, and controlling loop counts. The documentation highlights that individual frame durations override global settings and notes the preDecode function is deprecated. The content targets developers implementing image animations, requiring knowledge of ArkUI components and Cangjie syntax.

### func_stateAnimationStatus.md func_stateAnimationStatus.md
This API reference document details the state function in the Cangjie language, designed to control the playback status of animations within the ArkUI framework. The content covers the function signature, system capabilities, version requirements, and a detailed parameter table explaining the input value. Key takeaways include that the function accepts a required AnimationStatus enum parameter, defaults to AnimationStatus.Initial, and returns the current object instance for chaining. Intended for developers implementing animation controls, this document requires knowledge of ArkUI and Cangjie syntax.
