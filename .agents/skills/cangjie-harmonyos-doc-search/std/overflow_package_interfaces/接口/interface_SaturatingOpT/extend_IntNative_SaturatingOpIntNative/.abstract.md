This directory serves as a technical reference for the implementation of the `SaturatingOp` interface extension for the `IntNative` type within the Cangjie core package. It details a suite of saturating arithmetic functions that ensure numerical safety by clamping results to maximum or minimum limits upon overflow or underflow, rather than allowing values to wrap around. The documentation covers a wide range of operations, including basic arithmetic like addition and multiplication, as well as bit manipulation and negation. This collection of documents is specifically curated for Cangjie developers who require precise, safe, and boundary-checked integer operations to maintain data integrity and prevent runtime errors in high-performance or safety-critical applications.
