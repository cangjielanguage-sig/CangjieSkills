This repository provides a comprehensive technical implementation of segmented encryption and decryption using the SM4 symmetric key algorithm in GCM mode, specifically tailored for the Cangjie programming language. It addresses the critical need for memory-efficient data processing by demonstrating how to handle large data streams through chunked operations. The content covers the entire cryptographic lifecycle, including secure key generation, initialization vector (IV) management, and the specific usage of `update` and `doFinal` methods for stream processing. Furthermore, it explores essential security standards such as PKCS7 padding and authentication tag verification. This resource is specifically designed for Cangjie developers and security engineers who aim to integrate robust, high-performance cryptographic capabilities into their applications while adhering to modern security best practices.
