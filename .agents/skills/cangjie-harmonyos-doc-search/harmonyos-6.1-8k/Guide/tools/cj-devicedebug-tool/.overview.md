# cj-devicedebug-tool

本目录包含 `cj-devicedebug-tool` 的参考文档，主要介绍如何使用该工具向由 AMS 管理的 debug 类型应用进程发送信号以终止进程。文档涵盖了 `help` 帮助命令和 `kill` 终止进程命令的详细用法，包括信号参数（1-64）、进程 ID（pid）的使用限制及错误返回值。该工具目前处于 Beta 阶段，需通过 `hdc shell` 执行，仅适用于可调试的应用进程。本文档面向 OpenHarmony 开发者，适用于应用调试过程中需要强制终止特定进程的场景。

## 详细说明

### cj-devicedebug-tool.md cj-devicedebug-tool.md
本文档是 devicedebug 工具的参考指南，旨在帮助开发者向 AMS 管理的 debug 类型应用进程发送信号以终止进程。文档主要涵盖了 help 帮助命令和 kill 终止进程命令，详细说明了 kill 命令的语法、参数（signal 信号 1-64 及 pid）、使用限制及错误返回值。关键信息指出该工具目前处于 Beta 阶段，需通过 hdc shell 执行，且仅针对可调试的应用进程有效。文档面向 OpenHarmony 开发者，适用于应用调试过程中需要强制终止特定进程的场景。
