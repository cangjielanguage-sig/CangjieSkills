This directory provides comprehensive API reference documentation for the deprecated `ConsoleWriter` class and related console output functions within the Cangjie programming language. It focuses on thread-safe mechanisms for writing to standard output and error streams, covering a wide array of overloaded methods for data types such as Byte arrays, Booleans, Floats, Integers, and Runes. Additionally, it distinguishes between standard write operations and those that append newlines. This documentation is essential for Cangjie developers maintaining legacy codebases or seeking to understand the migration path to the `env` package for console operations.
