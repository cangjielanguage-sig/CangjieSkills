This directory serves as a comprehensive technical resource hub focused specifically on image decoding operations within the Cangjie programming language. It provides developers with the necessary tools and knowledge to handle a wide variety of image formats, including JPEG, PNG, and WebP, converting them efficiently into PixelMaps for display or further processing. The documentation covers essential development practices such as resource management, the configuration of decoding options, and the implementation of memory cleanup routines to ensure application stability. This content is primarily intended for Cangjie developers, application engineers, and technical architects operating within the HarmonyOS or OpenHarmony ecosystems who require practical, step-by-step guidance to integrate robust image handling capabilities into their software projects.
