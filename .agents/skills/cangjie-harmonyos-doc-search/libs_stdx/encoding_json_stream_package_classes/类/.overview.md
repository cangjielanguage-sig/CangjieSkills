## Detailed Description

The following subsections provide detailed summaries of the specific class documentation available in this directory, outlining their functionalities and intended use cases.

### class_JsonReader/

This directory contains comprehensive API reference documentation for the `JsonReader` class within the Cangjie programming language ecosystem. It focuses specifically on the mechanisms required for deserializing JSON data streams into native Cangjie objects. The documentation covers essential aspects of stream processing, including initialization, token inspection, and structural navigation. It highlights error handling protocols, such as throwing `IllegalStateException` for invalid formats, and details specific behaviors like whitespace skipping and raw byte retrieval. This resource is primarily suitable for Cangjie developers and system architects who are implementing custom JSON parsing logic and require granular control over data stream consumption, validation, and extraction.

### class_JsonWriter/

This directory contains comprehensive documentation for the Cangjie `JsonWriter` class, a specialized utility designed to serialize objects and construct JSON structures directly into an OutputStream. It covers essential aspects of the class, including initialization procedures, configuration settings via `writeConfig`, and methods for manually building complex JSON entities like objects and arrays. Key topics include stream buffering, the insertion of raw JSON strings, and state management. This documentation is intended for developers using the Cangjie language who require efficient JSON stream generation and assumes familiarity with the `JsonSerializable` interface and standard output operations. It is particularly useful for scenarios requiring manual control over the JSON structure or high-performance serialization tasks.
