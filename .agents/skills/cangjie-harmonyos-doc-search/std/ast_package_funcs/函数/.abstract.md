This directory contains API reference documentation for utility functions within the Cangjie programming language, specifically focusing on metaprogramming, macro expansion, and Abstract Syntax Tree (AST) manipulation. It covers a wide range of functionalities including lexical analysis, token comparison, parsing tokens into AST nodes (declarations, expressions, patterns, types), diagnostic reporting, and inter-macro communication mechanisms. These tools are essential for developers working on compiler tools, custom macros, or source code analysis, providing the necessary interfaces to validate contexts, handle errors, and programmatically construct or inspect code structures.
