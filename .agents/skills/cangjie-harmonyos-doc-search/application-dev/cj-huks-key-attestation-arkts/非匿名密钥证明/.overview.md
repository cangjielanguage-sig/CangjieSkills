# 非匿名密钥证明

This directory provides technical documentation and guidelines for implementing Key Attestation features in HarmonyOS, specifically focusing on Non-anonymous Key Attestation. It covers essential security protocols, permission management (such as `ohos.permission.ATTEST_KEY`), and the integration of hardware-backed cryptographic operations using the Universal Keystore Kit (HUKS). The content is tailored for HarmonyOS developers, particularly those working on system applications requiring high-level security verification. It includes detailed guidelines on Access Control Lists (ACL), access tokens, and practical development steps using the Cangjie programming language. This resource is crucial for developers aiming to build secure applications by effectively verifying key properties and managing system-level permissions.

### 开发步骤/
This directory provides a comprehensive technical guide outlining the development steps required for implementing anonymous key attestation using the Universal Keystore Kit (HUKS) within the Cangjie programming language environment. It meticulously details the entire workflow, starting from defining key aliases and initializing mandatory attestation parameters to generating asymmetric keys and invoking specific attestation APIs. The documentation is specifically designed to assist software developers in building secure applications by demonstrating how to verify key properties effectively through hardware-backed security features. Key technical concepts covered include the `HUKS_TAG_ATTESTATION_CHALLENGE` parameter, RSA key generation, and the `huks.anonAttestKeyItem` function. This resource is essential for developers who require a foundational understanding of cryptographic operations and Cangjie syntax to successfully integrate advanced security protocols into their software solutions.
