This directory contains API reference documentation for the Cangjie ResourceManager class, essential for HarmonyOS application development. It provides comprehensive details on accessing and managing system and application resources, including strings, media, booleans, and configuration settings. Key functionalities include resource retrieval by ID or name, cross-package resource access, localization support, and runtime resource overlay. The documentation is tailored for Cangjie developers who need to programmatically handle resources, implement multi-language support, and adapt to device capabilities within the LocalizationKit and AbilityKit frameworks.
