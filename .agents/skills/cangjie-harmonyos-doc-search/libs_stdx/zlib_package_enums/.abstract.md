This directory contains the essential API reference documentation for enumerations utilized within the zlib package, specifically developed for the Cangjie programming language environment. It acts as a technical guide for configuring the core behaviors of the compression library. The documentation covers the structural definitions of `CompressLevel`, which allows developers to fine-tune the balance between processing speed and the resulting compression ratio, and `WrapType`, which is used to specify the exact format of the compressed data stream, such as Gzip or Deflate. By providing clear definitions for values like BestCompression and BestSpeed, this resource ensures that developers can optimize their applications for specific performance requirements. This directory is highly suitable for Cangjie developers, backend engineers, and system programmers who are actively implementing data compression features and need a reliable reference for configuring compression parameters and output formats.
