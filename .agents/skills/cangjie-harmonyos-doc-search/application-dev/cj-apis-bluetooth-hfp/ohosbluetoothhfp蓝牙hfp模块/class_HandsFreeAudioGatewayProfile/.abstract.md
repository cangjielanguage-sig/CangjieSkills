This directory contains API reference documentation for the `HandsFreeAudioGatewayProfile` class in the Cangjie language, designed for managing Bluetooth Hands-Free Audio Gateway connections within HarmonyOS applications. It covers the class structure, device connection management, and event subscription mechanisms for connection state changes. Key topics include retrieving connected devices, checking connection states, and handling Bluetooth events. This documentation is suitable for developers implementing Bluetooth functionality, specifically for hands-free audio scenarios, requiring the `ohos.permission.ACCESS_BLUETOOTH` permission.
