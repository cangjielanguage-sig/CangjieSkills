This directory provides essential API reference documentation for the `WebDataBase` class within the Cangjie programming language, specifically designed for HarmonyOS developers utilizing the ArkWeb kit. It comprehensively covers the management of HTTP authentication credentials, detailing how to programmatically save, delete, verify existence, and retrieve user data. Key topics include static synchronous methods, parameter definitions (host, realm, username, password), return types (Bool, Array<String>), and specific error handling mechanisms (error code 401). The documentation also outlines system capabilities and version requirements, notably version 19. This resource is suitable for developers who need to implement robust web authentication states and handle secure credential data within their applications efficiently.
