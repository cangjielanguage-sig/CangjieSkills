# cj-ipc-rpc-overview

This directory provides a comprehensive technical overview of the IPC Kit, focusing on the essential mechanisms for Inter-Process Communication (IPC) and Remote Procedure Call (RPC). It thoroughly explains the fundamental differences between IPC, which utilizes the Binder driver, and RPC, which relies on the Soft bus driver. The content covers the implementation principles of the Client-Server model, specifically detailing the interaction between Proxy and Stub components. Additionally, it addresses critical system constraints, such as the 1MB data transfer limit and object passing protocols. The documentation also highlights the System Ability Manager (SAMgr) and its role in connection management. This resource is tailored for developers working on cross-process or cross-device communication who need a solid grasp of the underlying architecture, data limitations, and operational boundaries of the IPC Kit to ensure system stability and performance.
