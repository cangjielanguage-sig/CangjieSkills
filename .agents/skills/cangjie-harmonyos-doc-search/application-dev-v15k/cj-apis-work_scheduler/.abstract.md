This directory serves as the central hub for API reference documentation regarding the `cj-apis-work_scheduler` module, specifically curated for the Cangjie programming language within the HarmonyOS development ecosystem. It provides a comprehensive guide to managing delayed tasks, a crucial feature that allows developers to schedule background operations specifically during system idle periods. By deferring non-urgent work, developers can significantly optimize power consumption and enhance overall system performance. The documentation encompasses a wide array of technical components, including enumerations for various system states such as battery level, storage status, and network connectivity. Furthermore, it details the necessary data types for parameter configuration and the core functions required for robust task lifecycle management—specifically starting, stopping, and querying tasks. This resource is vital for HarmonyOS developers aiming to build efficient, resource-friendly applications by utilizing the `SystemCapability.ResourceSchedule.WorkScheduler` capability to its fullest potential.
