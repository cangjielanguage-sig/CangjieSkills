This directory provides comprehensive technical guides for migrating from the legacy Router component to the modern Navigation component in HarmonyOS applications using the Cangjie ArkUI framework. It covers architectural differences, lifecycle management, routing operations, and advanced features like cross-package navigation and shared element transitions. Key topics include NavPathStack management, imperative vs. declarative routing, and stack-based page handling. These resources are designed for Cangjie developers seeking to modernize their app navigation logic, improve animation performance, and implement flexible, cross-platform UI structures.
