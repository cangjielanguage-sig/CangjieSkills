This directory functions as an essential preparatory guide for Cangjie developers intending to implement media access features within their software projects. It comprehensively addresses the technical prerequisites and configuration steps necessary to utilize the photo access helper effectively. The guide focuses on the critical initialization phase, instructing developers on how to obtain the module instance via the application context and how to navigate the system's permission model. Key topics include the correct importation of the MediaLibraryKit, the execution of the getPhotoAccessHelper method, and the specific configuration of READ_IMAGEVIDEO and WRITE_IMAGEVIDEO permissions. Moreover, the directory delves into the security aspects of the user_grant authorization process, providing detailed instructions on ACL whitelisting, modifying the module.json5 configuration file, and conducting runtime verification. This resource is ideally suited for Cangjie developers whose applications require the ability to read, write, or manage user media data, ensuring they establish a secure and compliant foundation before proceeding with core development tasks.
