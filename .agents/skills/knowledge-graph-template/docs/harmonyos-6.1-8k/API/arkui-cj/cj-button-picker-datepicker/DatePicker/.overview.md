## Detailed Description

### DatePicker_5more_c106240e.md DatePicker_5more_c106240e.md
本文档是ArkUI框架中DatePicker组件的API参考文档，旨在指导开发者使用Cangjie语言创建日期滑动选择器。文档主要涵盖了模块导入、组件初始化构造函数以及start、end和selected三个关键参数的详细配置说明。核心信息包括该组件默认日期范围（1970至2100年）、支持所有通用属性与事件，以及当前处于Beta阶段的状态。该文档面向具备ArkUI和DateTime类型基础知识的开发者，适用于需要在应用中实现日期范围选择功能的场景。

### 示例代码_4a670b0f.md 示例代码_4a670b0f.md
本文档提供了一个仓颉语言代码示例，演示如何在ArkUI应用中实现支持公历与农历切换的日期选择器组件。代码涵盖了使用Column、Button和DatePicker组件的UI布局，展示了通过@State进行日历模式和日期选择的状态管理，以及处理按钮点击和日期变更的事件逻辑。关键要点包括通过设置DatePicker的lunar属性切换日历模式，自定义不同状态下的文本样式，以及使用Hilog记录用户选择的日期。这是一个面向使用仓颉语言的HarmonyOS开发者的教程示例，适用于需要实现具有日历转换功能的日期选择界面的场景。

### 组件事件_2more_03344540.md 组件事件_2more_03344540.md
本文档是关于ArkUI框架中日期选择器组件的API参考文档，主要定义了日期变更事件及结果数据类型。文档包含两个核心部分：`onDateChange`函数用于监听并处理日期选择事件，返回包含选中日期和系统时间的`DateTime`对象；`DatePickerResult`类则用于封装具体的年、月、日选择结果，其中月份取值范围为0至11。这些接口均从API版本22开始支持。文档面向使用仓颉语言进行ArkUI开发的开发者，旨在帮助其实现日期选择交互逻辑及数据解析。

### 组件属性.md 组件属性.md
本文档详细介绍了用于配置UI组件外观和行为的API方法，主要涵盖文本样式设置和日历显示模式。文档包含四个核心函数：`disappearTextStyle`、`lunar`、`selectedTextStyle` 和 `textStyle`。关键信息在于，开发者可通过 `PickerTextStyle` 定义选中项、一般项及过渡项的字体样式，并支持控制农历显示。所有方法均支持链式调用，起始版本为22。这是一份面向使用仓颉语言的ArkUI开发者的API参考文档，适用于需要自定义选择器组件视觉效果的场景。
