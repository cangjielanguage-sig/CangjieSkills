This directory provides comprehensive Cangjie code examples focused on generating Elliptic Curve Cryptography (ECC) keys based on specific key parameters within the HarmonyOS ecosystem. It covers the manual construction of `ECCCommonParamsSpec`, defining prime fields, curve coefficients, and generator points, as well as retrieving detailed cryptographic attributes from generated keys. Key topics include secp224r1 curve implementation, key pair generation workflows, and parameter inspection. These resources are suitable for Cangjie developers and security engineers implementing custom cryptographic operations or validating ECC key properties programmatically. The examples demonstrate both the setup of curve parameters and the subsequent extraction of key details for verification.
