This directory provides comprehensive API reference documentation for the `ohos.callback_invoke` module within the Cangjie programming language. It is dedicated to general callback mechanisms essential for handling asynchronous operations and event-driven architectures in HarmonyOS applications. The content covers abstract base classes like `CallbackObject` and specialized subclasses such as `CallbackWithReturn`, detailing their `invoke` methods, generic type support, and exception handling parameters. Currently in Beta status, this resource is suitable for Cangjie and HarmonyOS developers seeking to implement structured, type-safe callback patterns in their projects.
