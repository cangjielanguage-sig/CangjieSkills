This directory contains API documentation for the core classes within the Cangjie logging framework. It covers the essential components required for implementing, extending, or understanding the logging system, including data payloads, serialization mechanisms, and logger interfaces. Key topics include log record structures, no-operation implementations, output serialization, and abstract logging definitions. This documentation is suitable for Cangjie developers who need to integrate logging into their applications, build custom log handlers, or optimize logging performance.
