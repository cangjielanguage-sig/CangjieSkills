This directory contains API reference documentation for the `ClassTypeInfo` class within the Cangjie programming language's reflection library (`std.reflect`). It provides comprehensive details on runtime type inspection, enabling developers to dynamically analyze class structures, retrieve metadata for constructors and variables, and check class modifiers like abstract or sealed. The documentation covers properties for accessing member collections and methods for dynamic object instantiation. It is suitable for Cangjie developers looking to implement advanced reflection features, dynamic programming tasks, or tools that require deep introspection of class hierarchies and behaviors at runtime.
