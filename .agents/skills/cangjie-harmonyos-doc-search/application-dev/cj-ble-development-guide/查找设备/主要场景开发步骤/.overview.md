# 主要场景开发步骤

This directory serves as a comprehensive technical resource for developers implementing core Bluetooth Low Energy (BLE) scenarios within the HarmonyOS and OpenHarmony ecosystems. It focuses on essential connectivity workflows, specifically the management of advertising broadcasts and the execution of device scanning operations. The content covers technical implementation using the Cangjie language and ArkTS, addressing key tasks such as parameter configuration, data construction, lifecycle management, and the parsing of raw advertising packets. Designed for software engineers working with the ConnectivityKit, these guides provide the necessary code examples and architectural guidance to build robust device discovery and communication features. By following these steps, developers can effectively manage device visibility and interpret incoming data signals.

## Detailed Description

### 开启关闭广播.md 开启关闭广播.md
This document provides a tutorial on managing Bluetooth Low Energy (BLE) advertising operations, specifically starting and stopping broadcasts, using the Cangjie language. It covers prerequisites such as system capabilities and module imports, followed by a detailed code example demonstrating parameter configuration, data construction, and lifecycle management. Key information includes setting AdvertiseSetting, building AdvertiseData with manufacturer and service data, handling state change callbacks, and resource cleanup via stopAdvertising. Targeted at developers building connectivity features for HarmonyOS or OpenHarmony systems, this guide requires knowledge of the ConnectivityKit and basic BLE concepts.

### 开启关闭扫描/
This directory focuses on the implementation of Bluetooth Low Energy (BLE) scanning functionalities, specifically initiating and terminating scan processes, and parsing the resulting advertising data. It covers technical guides using the Cangjie programming language and ArkTS, detailing how to configure scan filters, manage scan options, and handle callbacks. Additionally, it provides code examples for decoding raw byte arrays into structured information like service UUIDs and device names. This content is suitable for software developers building connectivity features for HarmonyOS/OpenHarmony systems who need to implement device discovery and data interpretation logic.
