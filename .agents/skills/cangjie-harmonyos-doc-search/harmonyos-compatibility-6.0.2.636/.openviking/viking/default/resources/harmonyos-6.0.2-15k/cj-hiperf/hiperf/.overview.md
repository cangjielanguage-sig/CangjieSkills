# hiperf

This directory contains documentation for `hiperf`, a cross-platform command-line performance analysis tool designed for developers working with OpenHarmony and Linux-like environments. It functions similarly to the Linux `perf` utility, enabling the capture of system and program performance data. The content covers essential commands for recording samples, monitoring statistics, generating reports, and utilizing Python scripts for visualized flame graphs. It is suitable for performance analysts, developers, and testers aiming to diagnose system issues, optimize application behavior, and profile performance bottlenecks through precise data collection and visualization.

## Detailed Description

### hiperf_5more.md
This document provides a technical reference for hiperf, a cross-platform command-line tool designed for developers to capture system and program performance data, similar to the Linux perf utility. It details environment prerequisites, global logging options, and specific sub-commands. Key sections explain the usage of the help command for syntax and the list command for querying supported event types like hardware, software, and tracepoint events. The guide includes parameter definitions and usage examples, serving as a manual for debugging and performance profiling on connected devices via hdc shell.

### record命令.md
This document serves as a reference guide for the `hiperf record` command, which samples target programs to save performance data. It details command parameters for CPU selection, frequency, events, and call stack options, alongside usage syntax and practical examples. Key features include process ID selection, duration settings, and stack unwinding modes like dwarf, supporting both system-wide and specific thread profiling. Intended for developers and performance analysts, this guide facilitates system diagnostics and optimization through precise data collection.

### stat命令_3more.md
This reference documentation details the usage of three specific commands within the hiperf performance analysis tool: stat, dump, and report. The document is structured into three distinct sections, each providing a parameter table, usage syntax, and practical examples for the respective command. Key information includes how stat monitors performance counters for specific processes or CPUs, how dump reads raw perf.data for verification, and how report analyzes and converts sampling data into formats like JSON or ProtoBuf. This guide is intended for developers and testers performing system-level performance profiling and debugging.

### 脚本.md
This technical guide explains how to use Python scripts within the Hiperf toolset to perform performance sampling and generate visualized flame graphs for OpenHarmony systems. The document details three core workflows: sampling processes or applications, collecting symbol tables for stack unwinding, and generating HTML reports. It highlights specific scripts like command_script.py for sampling, recv_binary_cache.py for matching ELF files via buildid, and make_report.py for creating visual reports. It includes usage syntax and practical examples for targeting specific packages or processes. Intended for developers or performance analysts using OpenHarmony who need to profile application behavior and visualize performance bottlenecks.
