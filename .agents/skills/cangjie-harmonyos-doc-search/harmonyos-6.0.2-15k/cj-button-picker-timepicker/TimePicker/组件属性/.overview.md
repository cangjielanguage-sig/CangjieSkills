# 组件属性

This directory contains comprehensive API reference documentation for configuring component properties within the Cangjie ArkUI framework. It specifically focuses on the detailed customization of picker components, covering a wide range of aspects including text styling, time formatting, haptic feedback, and loop modes. The documentation provides in-depth explanations of various functions that allow developers to fine-tune the visual presentation and interactive behavior of date-time and text pickers. By utilizing optional parameters and method chaining, these APIs offer flexible integration. This resource is primarily suitable for ArkUI developers using the Cangjie programming language who need to implement precise UI adjustments and enhance user interaction in their applications.

## Detailed Description

### func_dateTimeOptionsString_5more.md
This document serves as API reference documentation for configuring the appearance and behavior of a date-time picker component within the Cangjie ArkUI framework. It details five specific functions: dateTimeOptions, disappearTextStyle, enableHapticFeedback, loop, and selectedTextStyle. Key information includes how to customize time formatting with leading zeros, style text for selected and disappearing options, and manage haptic feedback or loop modes. All functions utilize optional parameters and return the component instance to support method chaining. This guide targets ArkUI developers who need to fine-tune picker interactions and visual presentation in their applications.

### func_textStylePickerTextSt_2more.md
This document provides API reference documentation for configuring the appearance and behavior of a picker component in the Cangjie programming language, specifically focusing on text styling and time format settings. It details two public functions: textStyle, which defines the visual attributes of non-selected text options, and useMilitaryTime, which toggles between 12-hour and 24-hour time displays. Key parameters include optional types for PickerTextStyle and Bool, with specific default values for color, font size, and weight. The documentation clarifies behavior when values are set to None, ensuring consistency with initial values. Intended for developers using the ArkUI framework in Cangjie, this reference requires knowledge of UI component configuration and aims to facilitate precise customization of picker interfaces.
