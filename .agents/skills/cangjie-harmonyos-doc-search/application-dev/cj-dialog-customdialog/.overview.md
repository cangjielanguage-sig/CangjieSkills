## Detailed Description

### 自定义弹窗CustomDialog/

This directory focuses on implementing custom dialog windows (modal interfaces) using the Cangjie language and the ArkUI framework for HarmonyOS development. It is designed to assist developers in moving beyond standard system alerts to create rich, interactive modal experiences that integrate seamlessly with the application's design.

The content provides a deep dive into the `CustomDialog` decorator, explaining how to define the UI structure of a dialog. It also details the `CustomDialogController`, a crucial component for lifecycle management. This controller allows developers to handle the instantiation, display, and dismissal of dialogs programmatically, ensuring that the application state remains consistent during user interactions.

In addition to logic, the directory covers configuration options for styling and behavior. Key topics include:

- **Interactive Popups:** Building dialogs that accept user input and trigger specific actions.
- **Visibility Management:** Controlling the open and close states efficiently to manage user flow.
- **Visual Customization:** Applying specific styles such as borders, alignment, and background blur effects to match the application's design language.

This resource is suitable for developers building user interfaces who need to understand the syntax and structure for creating flexible, system-capable modal windows in Cangjie.
