# cj-web-debugging-with-devtools

This directory serves as a specialized technical resource dedicated to the intricacies of debugging front-end pages within HarmonyOS applications using DevTools, with a specific focus on the Cangjie programming language ecosystem. It provides an in-depth exploration of the remote debugging workflow, offering developers the necessary knowledge to establish a stable connection between a development PC and mobile devices. The content is centered around the ArkWeb component, detailing critical implementation steps such as configuring the `setWebDebuggingAccess` API and effectively utilizing `hdc` command-line tools for automated port forwarding. Furthermore, it includes practical advice for diagnosing and resolving common connectivity hurdles. This guide is an indispensable tool for HarmonyOS developers and software engineers who require robust solutions for inspecting and debugging web applications directly on mobile hardware using the familiar interface of Chrome DevTools. By following these instructions, users can significantly enhance their development efficiency and troubleshooting capabilities in a cross-platform environment.

## Detailed Description

### 使用DevTools工具调试前端页面/

This directory provides a comprehensive and practical guide for debugging front-end pages in HarmonyOS applications using DevTools. It covers the essential workflow for enabling remote debugging between a PC and mobile devices, with a particular focus on Web components (ArkWeb) and the Cangjie language. The documentation delves into critical technical areas, including the configuration and usage of the `setWebDebuggingAccess` API, the mastery of `hdc` command-line tools, and the automation of port forwarding to streamline the development process. Furthermore, it addresses the troubleshooting of common connection issues, ensuring a smooth debugging experience. This resource is designed for HarmonyOS developers and engineers who need to inspect and debug web applications on mobile devices using Chrome DevTools. It acts as a complete reference for setting up, maintaining, and optimizing the debugging pipeline for modern web-based features in HarmonyOS, ensuring that developers can efficiently resolve issues and improve application performance.
