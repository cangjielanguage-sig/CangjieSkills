# 媒体文件uri的使用方式

This directory provides comprehensive technical documentation on the methods and techniques for utilizing media file URIs within HarmonyOS applications. It covers essential workflows for accessing media assets using the `photoAccessHelper` module, handling permissions such as `READ_IMAGEVIDEO`, and employing `PhotoViewPicker` for temporary authorization without explicit rights. Key topics include retrieving `PhotoAsset` objects, generating thumbnails, and extracting metadata like file size, dimensions, and timestamps. This resource is suitable for HarmonyOS developers working with Cangjie or ArkTS who need to implement robust image selection, URI handling, and media asset querying in their projects. It addresses scenarios ranging from basic access to complex metadata retrieval.

## Detailed Description

### 媒体文件uri的使用方式_1.md 媒体文件uri的使用方式_1.md
This technical guide explains how normal-level applications can utilize media file URIs, offering methods both with and without specific permissions. It covers using the photoAccessHelper module with the READ_IMAGEVIDEO permission and an alternative method using PhotoViewPicker for temporary authorization. Key information includes retrieving PhotoAsset objects, generating thumbnails, and reading specific metadata like file size, dimensions, and timestamps via PhotoKeys without explicit permissions. Targeted at HarmonyOS developers using the Cangjie language, the document provides code examples for implementing image selection and URI handling.

### 媒体文件uri的使用方式_2.md 媒体文件uri的使用方式_2.md
This document serves as a technical code example demonstrating how to query and retrieve detailed media asset information using a specific URI in an ArkTS environment. The primary focus is on the `uriGetAssets` function, which utilizes `PhotoAccessHelper` and `DataSharePredicates` to filter assets based on a URI obtained from a `PhotoViewPicker`. Key operations include configuring `FetchOptions` to select specific metadata columns like width, height, and title, retrieving the corresponding `PhotoAsset` object, and generating thumbnails. Additionally, it includes a utility extension for converting `MemberType` values to strings. This guide is intended for HarmonyOS developers seeking to implement media file processing and metadata extraction in their applications.
