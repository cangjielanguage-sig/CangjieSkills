# 基础类型定义

This directory provides essential type definitions for the ArkUI framework, specifically tailored for the Cangjie programming language. It focuses on the core components required to construct and customize buttons within user interfaces. The content covers configuration classes that manage display properties—such as shape, size, and state effects—as well as enumerations defining functional roles, visual styles, and geometric types. By offering these foundational building blocks, the documentation enables developers to implement consistent and interactive UI elements. This resource is primarily suitable for ArkUI developers and UI engineers who need to fine-tune the appearance and behavior of buttons in their applications starting from version 19.

## Detailed Description

### class_ButtonOptions.md class_ButtonOptions.md
This API reference document details the ButtonOptions class in the Cangjie language, designed to configure the display style of buttons within the ArkUI framework. The documentation outlines the class structure, five public properties including shape, state effect, style mode, control size, and role, and the class constructor. Key information includes that all properties are readable and writable, with the constructor offering default values like a capsule shape and emphasized style. The stateEffect parameter specifically manages the visual feedback upon pressing. This guide is intended for ArkUI developers seeking to customize button appearance and behavior using Cangjie.

### enum_ButtonRole_3more.md enum_ButtonRole_3more.md
This document serves as an API reference for button-related enumerations within the ArkUI framework using the Cangjie language. It details three primary enums: ButtonRole, defining functional states like NORMAL and ERROR; ButtonStyleMode, specifying visual emphasis levels such as EMPHASIZED and TEXTUAL; and ButtonType, outlining geometric shapes including Capsule and Circle. Key information includes specific enum values, their system capabilities, and a deprecated getValue method for retrieving integer representations. Targeted at UI developers, this reference aids in configuring button appearance and behavior in ArkUI applications starting from version 19.
