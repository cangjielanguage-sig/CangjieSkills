# cj-notification-badge

This directory provides a comprehensive development guide for managing notification badges on desktop icons, specifically designed for developers using the Cangjie language and NotificationKit. The documentation focuses on creating visual indicators for unread messages, ensuring users are promptly alerted to new activity within an application. It covers essential topics such as interface specifications, badge counting rules, and the specific logic for handling numerical limits. The guide details the core `setBadgeNumber()` function, which allows for dynamic increases and decreases in counts, and explains how to manage edge cases like hiding badges when the count is zero or displaying "99+" for high volumes. Additionally, it touches upon integration with the NotificationRequest object for badge increments. This resource is ideal for application developers seeking to implement robust notification systems that enhance user experience through clear, visual status updates on the desktop interface.

## Detailed Description

### cj-notification-badge.md

This file acts as a comprehensive development guide for managing notification badges on desktop icons, specifically designed to display unread notification counts to users. It covers the essential interface specifications and badge counting rules required for consistent implementation. The guide provides detailed, step-by-step development procedures, starting from importing the necessary modules to the actual modification of badge numbers within the application code.

A significant portion of the document is dedicated to the `setBadgeNumber()` function, which serves as the core mechanism for handling badge counts. This function supports both increasing and decreasing the count dynamically. The guide also outlines critical display logic rules: for instance, badges are automatically hidden when the count is set to 0, ensuring a clean interface when there are no notifications. Furthermore, it explains the logic for handling high volumes of unread messages, where the badge displays "99+" for any value exceeding 99. Finally, the document describes alternative methods for incrementing badges, such as using the NotificationRequest object. This guide is an essential resource for application developers utilizing the Cangjie language and NotificationKit to build responsive notification systems.
