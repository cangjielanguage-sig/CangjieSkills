## 2293767 无效参数

**错误信息**

Invalid params received on operating form.

**错误描述**

接口调用时存在无效入参。

**可能原因**

1. 未传入必选参数。
2. 参数类型错误。
3. 参数数量错误。
4. 空参数错误，比如传入空字符串（''）。
5. 参数格式错误。
6. 参数值错误。输入参数与app.json5、配置卡片的配置文件的对应配置需要保持一致。

**处理步骤**

按照可能原因进行排查，确认必选参数是否传入、传入的参数类型是否错误等。
