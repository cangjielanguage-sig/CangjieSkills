This directory contains API reference documentation for the `AtomicInt32` class in the Cangjie programming language. It focuses on thread-safe, lock-free operations for 32-bit integers, essential for concurrent programming. The documentation covers atomic arithmetic, bitwise operations, swapping, loading, and storing. It highlights the distinction between current implementations using default memory ordering and deprecated overloads requiring explicit memory order parameters. This resource is suitable for systems programmers and developers implementing low-level concurrency algorithms who need precise control over atomic state changes and synchronization semantics.
