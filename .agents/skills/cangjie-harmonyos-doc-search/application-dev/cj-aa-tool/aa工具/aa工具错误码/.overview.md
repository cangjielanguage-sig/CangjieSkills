# aa工具错误码

This directory contains troubleshooting documentation for error codes related to the `aa` (Ability Assistant) tool in HarmonyOS development. It covers issues encountered during application startup, ability invocation, and lifecycle management, including visibility validation failures, internal system errors, and command execution problems. Key topics include error code resolution, configuration checks, and debugging steps using `hdc` commands. This resource is suitable for developers, testers, and technical support personnel looking to diagnose and resolve runtime failures effectively.

## Detailed Description

### 10100102_aa_start命令无法拉起UI_10more.md
This document serves as a troubleshooting reference for specific error codes encountered when using the aa start command to launch applications. It covers issues ranging from unsupported ability types like UIExtensionAbility and invalid parameters to system constraints such as screen locks, application control policies, and permission verification failures. Each entry provides the error code, message, description, root causes, and recommended handling steps, such as checking parameters or unlocking the device. Intended for developers and technical support personnel, this guide aids in diagnosing and resolving application startup failures.

### 10103001_目标Ability可见性校验失败_8more.md
This document serves as a troubleshooting reference for resolving specific error codes encountered when using the aa tool in HarmonyOS development. It details eight distinct error codes, covering issues such as target ability visibility failures, missing abilities, service connection drops, and developer mode restrictions. Each entry provides the error message, root causes like incorrect module.json5 configuration or missing installations, and actionable resolution steps including specific hdc shell commands to verify application status. Targeted at developers and testers, this guide aids in debugging application startup, ability invocation, and configuration problems.

### 10108101_拉起Ability时内部错误_9more.md
This document serves as a troubleshooting reference for HarmonyOS developers, detailing specific error codes encountered during Ability lifecycle management and command-line operations. It covers ten distinct error codes, including internal system errors, type mismatches, package retrieval failures, and process termination issues. Each entry provides the error message, description, potential causes (e.g., uninstalled apps, wrong ability type), and specific handling steps, such as using hdc shell bm dump -a to verify installation or re-signing with debug certificates. Targeted at application developers and testers using the aa command-line tool, this guide helps diagnose and resolve runtime failures effectively.
