# cj-apis-resource

This directory contains the essential API reference documentation for the `ohos.resource` module within the Cangjie programming language environment. It is specifically designed to assist developers in understanding and implementing resource type definitions for HarmonyOS applications. The content provides a deep dive into the technical specifications required for programmatic resource management, including detailed instructions on module imports and the necessary setup for usage contexts. A significant portion of the documentation is dedicated to the `AppResource` class, outlining its constructor, properties, and how it encapsulates vital resource identifiers such as bundle names, module names, and resource IDs. Additionally, it clarifies the class's inheritance relationships with `Length`, `ResourceColor`, and `ResourceStr`, as well as its support for optional formatting parameters. This guide is an indispensable tool for Cangjie developers aiming to efficiently manage application resources.
