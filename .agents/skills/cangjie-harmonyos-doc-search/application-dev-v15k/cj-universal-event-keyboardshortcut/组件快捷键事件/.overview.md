# 组件快捷键事件

This directory focuses on the implementation and management of keyboard shortcuts within the ArkUI framework using the Cangjie language. It covers essential usage rules, system-level restrictions, and detailed API references for the `keyboardShortcut` function. Key topics include event priority, focus dependencies, conflict resolution mechanisms, and prohibited system key combinations. This documentation is specifically designed for developers seeking to enhance UI interaction, accessibility, and navigation efficiency through custom keyboard events while avoiding conflicts with system operations.

## Detailed Description

### 快捷键使用注意事项.md
This document outlines the usage rules and precautions for implementing keyboard shortcuts within the system, specifically detailing their priority over standard key events. It covers scenarios such as custom combination requirements, focus dependencies, and multi-window behavior. Key information includes that shortcuts trigger on window focus rather than component focus, are case-insensitive, and respond even if the component is hidden but not if disabled. The document also explains conflict resolution where the first node in the tree takes precedence and lists conditions for invalid bindings. This technical reference guide is intended for developers using the ArkUI framework to manage UI interactions and requires an understanding of component event handling.

### 禁止绑定的系统快捷键_3more.md
This document serves as a technical reference for developers regarding system shortcut key restrictions and behaviors within the HarmonyOS UI framework. It details specific prohibited key combinations like Alt+F4 and Ctrl+Shift+Esc that cannot be bound to custom actions. Additionally, it explains existing system key events, such as direction keys and Tab, highlighting their behavior based on component focus and event priority rules. The document includes a Cangjie code example demonstrating how to implement, toggle, and manage keyboard shortcuts programmatically. Intended for application developers, this guide ensures proper handling of input events and avoids conflicts with system-level operations.

### 组件快捷键事件_5more.md
This document serves as API reference documentation for implementing custom keyboard shortcuts in UI components using the Cangjie language. It details the keyboardShortcut function, presenting four overloads that accept either a character string or a FunctionKey combined with modifier keys. Key information highlights that these shortcuts trigger even when the component lacks focus, provided it is mounted in the active window. Developers can define a custom action callback or default to standard click behavior. This guide targets ArkUI developers seeking to enhance application accessibility and navigation efficiency.
