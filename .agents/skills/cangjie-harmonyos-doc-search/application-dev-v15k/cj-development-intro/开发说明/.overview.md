# 开发说明

This directory provides comprehensive documentation for developers utilizing the Cangjie API within the HarmonyOS SDK ecosystem. It covers critical aspects of the development lifecycle, including how to integrate and execute sample code, interpret API documentation regarding versioning and SystemCapabilities, and manage permissions and application models. Key topics include project template creation, the `canIUse` method for feature verification, Stage model compatibility, and handling deprecated interfaces. These guides are essential for Cangjie and HarmonyOS developers aiming to ensure correct API implementation, maintain code stability, and comply with system security requirements across various hardware configurations.

## Detailed Description

### 仓颉示例代码说明.md 仓颉示例代码说明.md
This guide instructs developers on how to integrate and run Cangjie API code snippets within a standard project template. It details the process of creating a template project, identifying generated files like index.cj, and inserting sample code into the build function. A key section explains handling Context objects by defining a Global class in main_ability.cj to store application context. The document clarifies that kit samples are incomplete snippets requiring manual integration. Targeted at Cangjie developers, this tutorial ensures users can successfully compile and execute API examples by following specific configuration steps.

### 开发说明_4more.md 开发说明_4more.md
This document serves as a usage guide for developers interpreting API documentation within the HarmonyOS-Cangjie SDK ecosystem. It details versioning indicators, SystemCapability (SysCap) definitions, and interface usage protocols involving Kit imports. Key information includes identifying starting versions for components, using the canIUse method to verify feature support on specific devices, and understanding that interfaces are encapsulated within Kits requiring import declarations. Targeted at application developers, this reference guide ensures correct API implementation and feature compatibility across different hardware configurations.

### 权限说明_3more.md 权限说明_3more.md
This document serves as a reference guide for developers using the Cangjie API, outlining essential usage constraints regarding permissions, application models, and interface lifecycle. It details the necessity of applying for specific permissions to access system resources and how they are documented within interface descriptions. The text explains the evolution of application models, explicitly stating that the Cangjie API is currently only compatible with the Stage model. Additionally, it provides guidelines for handling deprecated interfaces, noting their compatibility duration and advising migration to replacements. This information is crucial for developers ensuring compliance with system security requirements and maintaining code stability during API updates.
