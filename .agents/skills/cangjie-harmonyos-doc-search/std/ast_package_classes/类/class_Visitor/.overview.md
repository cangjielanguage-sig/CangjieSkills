# class_Visitor

This directory contains API reference documentation for the abstract `Visitor` class in the Cangjie programming language. The documentation covers the base class definition, control flow mechanisms, and a comprehensive list of `visit` function overloads for various syntax elements, including declarations, expressions, patterns, and types. This resource is suitable for compiler developers, language tool implementers, and engineers working on static analysis or AST transformations who need to extend or customize traversal logic.
