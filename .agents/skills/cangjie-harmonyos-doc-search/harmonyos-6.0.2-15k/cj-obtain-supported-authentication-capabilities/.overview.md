# cj-obtain-supported-authentication-capabilities

This directory serves as a comprehensive technical guide for application developers utilizing the Cangjie programming language to build secure, biometric-enabled applications. The primary focus of this content is to instruct developers on how to effectively query a device's supported authentication capabilities using the UserAuthenticationKit. It provides a deep dive into the `getAvailableStatus` interface, which is crucial for verifying whether a specific authentication type—such as face recognition—is supported by the device hardware at a particular trust level, for example, ATL1. The tutorial meticulously outlines the necessary development steps, starting with the prerequisite of applying for the `ohos.permission.ACCESS_BIOMETRIC` permission. It then guides the user through the process of invoking the relevant APIs with the precise parameters required for a successful query. By following this document, developers can ensure that their applications perform proper capability verification before attempting to initiate user authentication processes. This not only enhances the security of the application but also significantly improves the user experience by preventing errors related to unsupported hardware features. This resource is ideally suited for developers who need to implement robust and error-free biometric authentication checks in their Cangjie projects.
