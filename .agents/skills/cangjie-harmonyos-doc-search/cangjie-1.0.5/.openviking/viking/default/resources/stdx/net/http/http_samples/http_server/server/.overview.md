# server

本目录包含使用仓颉语言构建 HTTP 服务器的相关文档与代码示例。内容涵盖了从基础服务构建、请求分发器配置到高级功能的完整流程，包括 HTTP/2 服务端推送、分块传输编码、HTTP 重定向以及 TLS 证书的热加载。核心知识点涉及 `ServerBuilder`、`HttpResponseWriter`、`RedirectHandler` 以及安全连接配置。该文档适合具备仓颉基础语法及网络编程知识的后端开发者阅读，旨在帮助开发者构建高性能、安全且功能丰富的网络应用。

## 详细描述

### response_中的_chunk_3more_b37e03fe.md
本文档旨在通过Cangjie语言代码示例，演示HTTP服务器的高级功能实现。主要涵盖了三个核心主题：如何在响应中使用分块传输编码并发送尾部信息、如何处理HTTP重定向请求，以及如何实现TLS证书的热加载。关键信息包括使用HttpResponseWriter进行流式写入、利用RedirectHandler设置308重定向，以及通过updateCert和updateCA方法动态更新安全凭证。这是一份面向Cangjie开发者的技术指南，适用于需要构建具备流式响应、重定向逻辑和动态TLS配置能力的网络应用场景。

### server_5more_1517df59.md
本文档提供了使用仓颉语言 stdx.net.http 库构建 HTTP 服务端的代码示例与教程。涵盖基础服务构建、通过分发器注册多路径处理器、自定义请求分发器与处理逻辑，以及配置 TCP 和 TLS 网络参数。重点介绍了 ServerBuilder 的使用、HttpRequestHandler 的注册机制，以及如何通过 TransportConfig 和 TlsServerConfig 实现安全连接与性能调优。适用于希望开发后端服务的仓颉语言开发者，需具备基础语法及网络编程知识。

### server_push.md
本文档详细介绍了在Cangjie语言中实现HTTP/2服务端推送的机制，通过代码示例展示了客户端与服务端的交互流程。内容分为客户端和服务端两部分，重点讲解了TLS配置、ALPN协议设置、ClientBuilder与ServerBuilder的使用，以及如何注册路由和处理推送请求。核心要点包括必须启用TLS和ALPN协议"h2"，客户端使用response.getPush()接收推送，服务端利用HttpResponsePusher.getPusher()主动推送资源。该文档适合具备Cangjie基础及网络编程经验的开发者阅读，属于技术教程性质。
