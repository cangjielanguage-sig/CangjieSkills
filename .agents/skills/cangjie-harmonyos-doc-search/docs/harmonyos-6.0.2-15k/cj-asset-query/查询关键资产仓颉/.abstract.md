This directory provides a complete technical guide for querying critical assets using the Cangjie language within the AssetStoreKit framework. It covers essential development tasks, including synchronous interface usage, batch querying with pagination, and handling IPC transmission constraints. The documentation details API specifications, attribute parameters for access control, and data security limitations regarding unencrypted fields. Designed for developers and system integrators, this resource facilitates the implementation of secure asset storage, synchronization, and retrieval, ensuring optimal performance and adherence to system-level restrictions.
