This directory provides comprehensive API reference documentation for the `PackingOption` class in the Cangjie language, focusing on the configuration of image encoding parameters. It covers the technical specifications of class properties such as format, quality, buffer size, desired dynamic range, and EXIF metadata inclusion. The documentation details support for standard image formats including JPEG, WebP, PNG, and HEIF, alongside configuration for quality ranges and buffer management. This resource is specifically designed for multimedia developers and engineers implementing image packing functionality within the SystemCapability.Multimedia.Image.ImagePacker framework.
