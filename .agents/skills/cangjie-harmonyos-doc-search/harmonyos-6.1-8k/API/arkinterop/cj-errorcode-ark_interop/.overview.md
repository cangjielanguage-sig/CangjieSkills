# cj-errorcode-ark_interop

本目录是ArkTS互操作库的参考手册集合，专注于记录和解析仓颉与ArkTS交互过程中产生的特定错误码。文档内容详细覆盖了错误码范围34300001至34300008，针对非法索引、代码异常、对象生命周期管理、线程校验、类型匹配以及模块导入限制等复杂场景提供了全面的错误信息、成因分析及处理步骤。该文档的主要目的是帮助开发者在Beta阶段能够快速定位并有效解决互操作异常，从而提升开发效率。本资料特别适合正在进行跨语言开发的仓颉应用开发者，是排查混合语言编程问题的重要参考资料。关键词：ArkTS、仓颉、互操作、错误码、线程校验、模块导入。
