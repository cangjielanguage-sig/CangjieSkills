This directory serves as a comprehensive introductory resource for the Core File Kit, a specialized service integral to the HarmonyOS ecosystem. It is specifically designed to enable developers to access and manage application and user files with high efficiency and security. The documentation covers a wide array of essential topics, starting with file classification models and the critical concept of sandbox isolation, which ensures data security and privacy. It also provides detailed mechanisms for inter-app file sharing, utilizing URIs or File Descriptors (FDs) to facilitate secure data exchange between applications. Furthermore, the content delves into the underlying architecture of the Application and User File Access Frameworks, offering insights into key components such as FilePicker and FileManager. This resource is highly suitable for developers seeking to implement robust file management solutions, including backup, restore, and cross-device access features, while strictly ensuring data consistency and portability across the HarmonyOS environment. By understanding these core mechanisms, developers can build applications that handle data securely and efficiently in a multi-device world.
