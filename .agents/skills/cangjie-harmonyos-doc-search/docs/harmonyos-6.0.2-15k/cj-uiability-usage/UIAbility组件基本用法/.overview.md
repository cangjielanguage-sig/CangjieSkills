# UIAbility组件基本用法

This directory covers the fundamental usage of the UIAbility component in HarmonyOS development using the Cangjie language. It focuses on lifecycle management, specifically the `onWindowStageCreate` callback, and how to set startup pages to avoid white screen errors using `loadContent`. Additionally, it details how to acquire and utilize `UIAbilityContext` for managing application states and system interactions. This resource is suitable for HarmonyOS developers working with the ArkUI framework and Cangjie who need to initialize application entry points and handle context-based operations effectively.

### UIAbility组件基本用法_2more.md
This technical guide outlines the fundamental usage of the UIAbility component, focusing on lifecycle configuration and context acquisition. Intended for HarmonyOS developers using the Cangjie language, this guide serves as a practical reference for initializing application entry points.

### 获取UIAbility的上下文信息.md

Key takeaways include the pattern of storing context globally for cross-component access and implementing error handling during ability termination. This tutorial is intended for HarmonyOS developers using the Cangjie language and ArkUI framework who need to interact with system capabilities and manage ability states.
