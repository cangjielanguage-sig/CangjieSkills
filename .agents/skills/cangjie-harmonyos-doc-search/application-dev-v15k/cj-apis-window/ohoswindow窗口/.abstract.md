This directory provides comprehensive API documentation for the `ohos.window` module in the Cangjie programming language, designed for HarmonyOS application development. It covers essential window management capabilities, including the creation, configuration, lifecycle control, and event handling of windows. Key topics include window types, geometry definitions, system bar properties, orientation control, and sub-window management. The documentation serves as a reference for classes, enumerations, and functions required to build robust graphical user interfaces. It is suitable for application developers and system integrators utilizing WindowManager capabilities to implement complex window layouts and interactions.
