## 详细说明

### 使用_--debug-macro_输出宏展开结果.md
这份文档旨在指导仓颉开发者利用 --debug-macro 选项调试宏展开代码，解决编译期错误难以定位的问题。文档涵盖了宏展开问题的背景、通过命令行或配置文件启用 debug 模式的方法、以及 .macrocall 输出文件的解读。关键信息包括该模式能生成完整展开代码以辅助错误溯源，但存在行列号重排、不支持宏内调用及带括号宏等限制。本文适合使用仓颉宏进行元编程的开发者阅读。

### 宏的编译和使用.md
本文档是一份关于仓颉编程语言宏的编译与使用的开发指南。文档主要阐述了宏定义与调用必须分离的编译约束，并通过示例展示了目录结构与代码实现。核心内容涵盖了两阶段编译流程：首先使用`--compile-macro`编译宏包，随后通过`--import-path`指定路径编译调用包。文档还提供了Linux和Windows平台的具体命令，解释了动态库依赖处理及仓颉runtime初始化配置。关键要点在于宏定义需使用public修饰且需先编译。目标受众为仓颉语言开发者，旨在指导其正确构建和运行包含宏的项目。

### 并行宏展开_2more_b6ff6447.md
本文档旨在介绍仓颉语言中宏处理的并行优化机制及自定义报错功能。主要涵盖并行宏展开的启用方法与风险，以及 `diagReport` 接口的使用。关键信息包括：使用 `--parallel-macro-expansion` 可加速编译，但需注意全局变量的并发冲突，建议使用线程锁；`diagReport` 允许在宏解析时输出格式化的错误或警告信息，包含位置和提示。适用于需要优化编译性能或增强宏调试能力的仓颉语言开发者。
