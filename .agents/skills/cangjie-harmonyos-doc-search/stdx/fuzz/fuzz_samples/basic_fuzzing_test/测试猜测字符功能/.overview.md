## 详细描述

### 测试猜测字符功能_1.md
本文档是一份关于在仓颉语言中使用 Fuzzer 进行自动化测试的教程，旨在演示如何通过模糊测试发现特定输入 "Cangjie!" 触发的异常。文档主要包含被测 API 代码示例、Fuzzer 初始化流程以及针对 Linux 和 macOS 系统的详细编译命令。关键信息涵盖了编译器标志（如 `--sanitizer-coverage-inline-8bit-counters`）的使用、链接器选项（如 `whole-archive`）的配置，以及解决符号依赖和 GLIBC 版本问题的方法。该文档面向具备仓颉语言基础及编译链接知识的开发者，旨在指导其搭建 Fuzz 测试环境并理解覆盖率插桩机制。

### 测试猜测字符功能_2.md
本文档是一份模糊测试执行日志，演示了使用 libFuzzer 在仓颉程序中发现崩溃的过程。内容涵盖了 Fuzzer 初始化、通过 CrossOver 和 ChangeByte 等变异策略逐步扩展输入语料库，以及最终的崩溃检测。测试会话最终由特定输入 "Cangjie!" 触发了 TRAP 异常，表明 default.api 函数中存在错误。日志提供了崩溃产物及失败输入的 Base64 表示。该技术报告旨在帮助负责调试软件漏洞和验证字符猜测功能健壮性的开发者和 QA 工程师。
