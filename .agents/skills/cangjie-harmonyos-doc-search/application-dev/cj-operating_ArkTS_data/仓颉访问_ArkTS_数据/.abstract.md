This directory serves as a comprehensive technical resource for developers working on interoperability between the Cangjie programming language and ArkTS within the HarmonyOS ecosystem. It provides in-depth documentation on how Cangjie code can access, manipulate, and manage ArkTS data structures, focusing on the utilization of the `JSValue` type for type identification, data conversion, and memory lifecycle management. The content covers critical distinctions between data copying and referencing, alongside detailed mapping tables for type alignment. Furthermore, it offers practical guides on cross-language function invocation, object manipulation (including Sendable types), and concurrency control using `AsyncLock`. This material is essential for Cangjie developers seeking to integrate dynamic libraries with ArkTS, handle complex cross-language interactions, or ensure thread safety in concurrent environments.
