# 客户端

本目录包含关于蓝牙低功耗（BLE）GATT客户端开发的文档和代码示例。内容涵盖了从连接建立、服务发现、特征值读写到通知管理及断开连接的完整流程。主要使用Cangjie语言和HarmonyOS API，适用于需要在应用中实现蓝牙设备通信功能的开发者。

## 快速导航

- 想要了解基础架构与UUID定义？ → 客户端_1.md
- 想要实现主动连接与数据读写？ → 客户端_2.md
- 想要操作描述符或管理通知？ → 客户端_3.md
- 想要启用Indicate或断开连接？ → 客户端_4.md

## 详细描述

### 客户端_1.md 客户端_1.md
本文档提供了Cangjie语言编写的GattClientManager类代码，用于管理BLE GATT客户端连接及服务发现。涵盖了UUID常量定义、描述符与特征值的初始化、日志记录工具，以及检查和发现特定服务、特征值及描述符的逻辑。代码定义了服务、特征值及描述符的特定UUID，包含构造BLE对象的辅助方法，以及通过遍历服务匹配UUID并记录值的checkService核心函数。面向使用Cangjie进行HarmonyOS蓝牙低功耗开发的开发者，适用于实现客户端GATT操作的场景。

### 客户端_2.md 客户端_2.md
本文档主要介绍BLE客户端（Client端）的主动连接与数据交互实现流程。文档详细涵盖了发起连接、服务发现、读取特征值及写入特征值四个核心功能模块。代码示例展示了如何创建GATT客户端实例、订阅连接状态变化回调，并在确保连接成功和服务存在的前提下进行数据读写操作。关键信息包括连接状态校验、异步回调处理及异常捕获。这是一份面向开发者的API使用指南或教程，旨在指导开发者实现蓝牙低功耗设备的通信功能。

### 客户端_3.md 客户端_3.md
本文档展示了BLE GATT客户端在连接建立后的关键操作，包括读取描述符值、写入描述符值及管理特征值变更通知。代码详细演示了连接状态校验、描述符初始化、回调处理及异常捕获，强调了操作前需确保服务端资源存在。这是一份面向HarmonyOS应用开发者的代码参考，适用于实现蓝牙数据交互功能的场景。

### 客户端_4.md 客户端_4.md
本文档提供了BLE GATT客户端操作的代码示例，重点介绍如何启用或禁用特征值变更指示以及处理客户端主动断开连接。主要内容包括用于订阅服务端通知的`Indicate`函数、用于资源清理和断开连接的`stopConnect`函数，以及连接状态和特征值变更的回调包装类。关键信息涉及检查连接状态、设置特征值变更指示以及正确关闭GATT客户端以释放资源，并演示了通过`BusinessException`进行错误处理。这是面向在HarmonyOS/OpenHarmony应用中实现BLE通信的开发者的API文档或代码参考指南。
