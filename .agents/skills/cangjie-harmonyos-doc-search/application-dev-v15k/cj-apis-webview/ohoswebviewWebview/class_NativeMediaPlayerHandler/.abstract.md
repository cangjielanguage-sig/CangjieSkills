This directory provides comprehensive API reference documentation for the `NativeMediaPlayerHandler` class and associated functions within the Cangjie programming language ecosystem. It is specifically designed to enable robust communication between an application's native media player and the ArkWeb kernel. The documentation covers essential aspects of media event handling, including playback status, buffering, duration tracking, and error management. It requires the SystemCapability.Web.Webview.Core capability (version 19 or higher). This resource is best suited for system developers and application engineers tasked with integrating native media capabilities into webview environments or building custom video playback controls.
