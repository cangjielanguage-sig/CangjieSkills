This directory contains API reference documentation for the `AudioChannelLayout` enumeration in the Cangjie programming language. It covers definitions for various audio channel configurations, ranging from standard Mono and Stereo to complex surround sound setups like 5.1, 7.1, and 9.1.6, as well as Higher Order Ambisonics (HOA) formats such as ACN_N3D and FUMA. The documentation includes utility functions for comparing layouts and converting them to strings. These resources are intended for multimedia software developers and audio engineers working on spatial audio processing and playback, requiring the SystemCapability.Multimedia.Audio.Core capability (API version 19+).
