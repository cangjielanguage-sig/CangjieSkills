This directory functions as a specialized technical library for the Connectivity Kit, providing a comprehensive glossary of Bluetooth terminology and protocols. It encompasses a broad spectrum of wireless communication standards, ranging from audio and input protocols like A2DP, HFP, and HID to Low Energy (BLE) architectural components such as GATT and Characteristics. Furthermore, it details data access profiles including MAP and PBAP, alongside essential networking concepts like MTU, RSSI, and UUID. By distinguishing between Classic Bluetooth and BLE standards and clarifying device roles (e.g., Source vs. Sink), this collection serves as an essential reference for software developers and systems engineers seeking to implement robust Bluetooth connectivity and understand subsystem architecture.
