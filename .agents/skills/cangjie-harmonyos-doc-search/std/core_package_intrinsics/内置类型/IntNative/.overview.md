# IntNative

The IntNative directory provides comprehensive API reference documentation for the IntNative type within the Cangjie programming language. This type represents a platform-dependent signed integer that automatically adjusts to the system's bit width. The documentation covers essential extensions providing mathematical constants like Max and Min, alongside implementations for the Comparable and Countable interfaces. Additionally, it details extensions for Hashable and ToString functionalities. This resource is suitable for Cangjie developers seeking to utilize platform-specific integer behaviors, perform arithmetic progressions, or implement data structures requiring hashing and string representation.
