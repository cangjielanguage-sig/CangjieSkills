This directory contains comprehensive API reference documentation for the `AVTranscoderConfig` class, a fundamental component for configuring audio and video transcoding tasks within the Cangjie language framework. The documentation covers the initialization of configuration objects, system capabilities, and detailed parameter settings for output specifications. Key topics include mandatory file formats (MP4), supported codecs (AAC, AVC, HEVC), and automatic behaviors for video bitrate and dimension calculations based on source resolution. It requires a solid understanding of video processing concepts to effectively utilize the provided APIs.
