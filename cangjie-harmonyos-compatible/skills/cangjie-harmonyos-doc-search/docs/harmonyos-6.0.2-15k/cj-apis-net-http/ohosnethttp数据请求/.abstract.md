This directory provides comprehensive API reference documentation for the `ohos.net.http` module in the Cangjie programming language, part of the HarmonyOS NetworkKit. It covers essential components for performing HTTP data requests, including client authentication, response handling, caching mechanisms, and proxy configuration. The documentation details classes for managing request lifecycles, configuring options, and tracking performance metrics. It is suitable for Cangjie developers building HarmonyOS applications that require robust internet access, secure SSL communication, and efficient network data transfer.
