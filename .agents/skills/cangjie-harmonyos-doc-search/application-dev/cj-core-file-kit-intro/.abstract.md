This directory provides a comprehensive introduction to the Core File Kit, a fundamental service within the OpenHarmony ecosystem designed to facilitate efficient and secure file management. It covers a wide range of topics, including file classification models, usage scenarios, and architectural principles. Key features such as sandbox isolation for data protection, cross-device synchronization, and network transfers are highlighted in detail. The documentation also offers technical insights into the file access framework, specifically examining the roles of FilePicker, ExtensionAbility, and file managers. This resource is primarily intended for application developers and device manufacturers who need to build robust file management systems, implement secure data sharing mechanisms, or create intuitive file selection interfaces. By leveraging these concepts, users can ensure data consistency and portability while significantly enhancing the overall user experience and application performance.
