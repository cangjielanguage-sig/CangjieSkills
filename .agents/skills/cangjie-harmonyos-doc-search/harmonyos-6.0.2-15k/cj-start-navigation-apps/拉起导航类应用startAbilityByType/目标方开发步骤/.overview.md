# 目标方开发步骤

This directory serves as a comprehensive guide for HarmonyOS developers focusing on the "target side" implementation of map applications. It details the necessary procedures to enable an application to receive and process external requests for map services. The content covers the configuration of the `module.json5` file to declare specific capabilities such as Navigation, RoutePlan, and PlaceSearch using `linkFeature` and URI attributes. Furthermore, it explains the technical implementation of parsing parameters within the `UIAbility` lifecycle, specifically the `onCreate` method. The tutorials provide Cangjie code examples to assist developers in initializing variables and handling data fields required for various location-based scenarios. This resource is essential for developers looking to integrate robust map functionalities into their HarmonyOS applications using the Cangjie language.

## Detailed Description

### 目标方开发步骤_1.md
This technical tutorial guides developers on configuring the target side of a map application to handle external requests. It details configuring module.json5 to declare supported features like Navigation, RoutePlan, and PlaceSearch via linkFeature and URI attributes. The document explains parsing parameters within UIAbility.onCreate, specifying required and optional data fields for route planning, navigation, and location search scenarios. It includes a Cangjie code example demonstrating variable initialization. This guide is intended for HarmonyOS developers implementing map capabilities using the Cangjie language.

### 目标方开发步骤_2.md
This document provides a code example for implementing a target application's ability to handle map service requests in HarmonyOS. It covers the lifecycle methods onCreate and onNewWant for receiving intents, and loadPage for URI-based routing. Key information includes parsing JSON parameters from want.parameters to extract location data and POI IDs, then using localStorage to pass this data to specific pages like NavigationPage, RoutePlanPage, or PlaceSearchPage based on the URI scheme. This guide is intended for developers integrating map navigation or route planning features into their applications.
