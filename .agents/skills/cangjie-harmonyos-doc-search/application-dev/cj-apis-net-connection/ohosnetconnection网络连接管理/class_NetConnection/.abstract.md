This directory contains API reference documentation for the `NetConnection` class within the Cangjie language's NetworkKit. It focuses on network connection management, enabling developers to monitor and handle various network state transitions, such as switching between WiFi and cellular networks. The documentation covers event subscription mechanisms for network availability, property changes, capability changes, and block status updates. It also details the registration and unregistration processes required for active monitoring. This resource is suitable for Cangjie developers who need to implement robust network status monitoring and handle connection events programmatically in their applications.
