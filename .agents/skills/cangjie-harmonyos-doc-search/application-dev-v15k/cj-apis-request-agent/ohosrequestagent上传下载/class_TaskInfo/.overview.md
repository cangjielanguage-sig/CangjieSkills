# class_TaskInfo

This directory provides comprehensive API reference documentation for the `TaskInfo` class within the Cangjie language, specifically designed for the `SystemCapability.Request.FileTransferAgent`. It details the data structures and properties essential for defining, querying, and managing asynchronous file transfer tasks, including uploads and downloads. Key topics include task lifecycle management, progress tracking, fault reporting, and the configuration of execution modes (foreground/background) and priority levels. The documentation also covers constructors for task initialization and error handling mechanisms. This resource is suitable for developers working on file transfer functionalities who need to understand how to monitor task states, handle network disconnections, and configure task attributes effectively using Cangjie syntax.
