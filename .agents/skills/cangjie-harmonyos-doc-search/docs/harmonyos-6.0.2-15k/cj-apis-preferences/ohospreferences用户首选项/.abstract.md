This directory provides API reference documentation for the `ohos.preferences` module within the HarmonyOS ArkData framework, specifically designed for the Cangjie language. It focuses on lightweight data persistence using Key-Value storage mechanisms, enabling applications to efficiently manage local settings and user preferences. The documentation covers module imports, configuration options, supported data types, and the core `Preferences` class for data manipulation. It is suitable for HarmonyOS developers looking to implement robust data storage solutions, requiring familiarity with application contexts and project configuration.
