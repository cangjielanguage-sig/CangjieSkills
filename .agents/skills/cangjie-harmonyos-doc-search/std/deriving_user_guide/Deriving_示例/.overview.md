# Deriving_示例

This directory provides comprehensive guides and references for using the `@Derive` attribute in the Cangjie programming language to automatically implement common interfaces. It covers essential topics such as basic implementation, field collection rules, customizing output order, and handling generic types with constraints. Key features include using `@DeriveExclude`, `@DeriveInclude`, and `@DeriveOrder` to fine-tune code generation. These resources are designed for Cangjie developers looking to reduce boilerplate code, enhance type safety, and streamline the implementation of standard behaviors like `ToString`, `Hashable`, and `Equatable` through macro-based automation.

## Detailed Description

### Deriving_示例.md Deriving_示例.md
This document serves as a tutorial guide for using the `@Derive` attribute in the Cangjie programming language to automatically implement interfaces like `ToString`. It covers basic implementation, field collection rules, excluding specific fields using `@DeriveExclude`, explicitly including properties with `@DeriveInclude`, and customizing output order via `@DeriveOrder`. Key takeaways include that the mechanism collects constructor fields by default but ignores static fields and properties unless specified. Classes must be final, and field types must support the target interface to avoid compilation errors. This guide targets Cangjie developers seeking to reduce boilerplate code through automatic derivation.

### 常见的_Deriving_语法_4more.md 常见的_Deriving_语法_4more.md
This document serves as a technical reference for using the @Derive macro in the Cangjie programming language to automatically generate implementations for common interfaces. It covers syntax rules, including macro placement and repetition, and explains how to include or exclude specific fields and properties. The text lists supported interfaces such as ToString, Hashable, Equatable, and Comparable, while noting that custom interfaces are currently unsupported. A key feature discussed is the @DeriveOrder macro, which allows developers to customize the priority of fields during sorting and comparison operations. This guide is intended for Cangjie developers looking to streamline code by automating boilerplate logic for standard type behaviors.

### 泛型_2more.md 泛型_2more.md
This technical guide explains how to implement interfaces for generic types in the Cangjie language using the @Derive attribute and manual extensions with constraints. The document covers manual extension with where clauses, the default constraint behavior of @Derive, and methods to override these constraints for specific interfaces like ToString and Hashable. Key takeaways include that @Derive automatically applies constraints to generic parameters, but developers can customize them per interface. Additionally, the guide notes that while runtime performance is equivalent to hand-written code because it uses macros instead of reflection, it does increase compilation time. This content targets Cangjie developers seeking to optimize type safety and code generation for generic classes.
