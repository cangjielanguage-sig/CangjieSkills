This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on the TextInput component. It covers a wide range of functionalities including text styling, input validation, keyboard handling, cursor management, and visual decorations. The documents provide detailed syntax, parameter definitions, and behavioral notes for functions like caretStyle, passwordIcon, and heightAdaptivePolicy. This resource is suitable for software developers and UI engineers building HarmonyOS applications who need to fine-tune user input interactions and customize the appearance of text fields.
