# 示例代码

本目录包含使用仓颉语言在ArkUI框架中实现页面转场动画的示例代码。主要涵盖了页面退入场动画的配置，包括缩放、透明度变化以及平移效果的实现。通过具体的代码文件（如index.cj和page1.cj），演示了如何利用`PageTransitionEnter`、`PageTransitionExit`接口及`@State`状态变量来控制动画逻辑。这些示例适合具备ArkUI基础和仓颉语言语法的HarmonyOS应用开发者，旨在帮助开发者掌握自定义页面转场动画的实现方法，提升应用的交互体验。

## Detailed Description

### 示例代码1设置退入场动画.md
本文档旨在通过代码示例演示如何在ArkUI应用中使用仓颉语言配置页面的退入场动画。文档包含index.cj和page1.cj两个源码文件，重点展示了build方法构建UI以及pageTransition方法实现动画逻辑。核心内容是利用PageTransitionEnter和PageTransitionExit接口，结合@State状态变量（scale和opacity），根据路由类型动态控制页面的缩放和透明度变化，实现平滑的页面切换效果。适用于具备ArkUI基础和仓颉语言语法的HarmonyOS应用开发者，用于学习自定义页面转场动画的实现方式。

### 示例代码2设置退入场平移效果_3b33f89f.md
本文档演示了如何使用仓颉语言和ArkUI框架配置页面的退入场平移效果。主要涵盖`index.cj`和`page1.cj`两个代码文件，展示了通过重写`pageTransition`方法，利用`PageTransitionEnter`和`PageTransitionExit`接口实现页面切换的逻辑。关键信息包括设置动画时长（1200ms）、曲线类型以及滑动方向（左滑或右滑），并实现了两个页面间的路由跳转与视觉反馈。这是一个面向仓颉开发者的示例教程，旨在帮助开发者掌握ArkUI中页面转场动画的实现方法。
