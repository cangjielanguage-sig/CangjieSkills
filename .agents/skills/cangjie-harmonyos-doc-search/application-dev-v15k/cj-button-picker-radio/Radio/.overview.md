# Radio

This directory contains comprehensive API reference documentation for the Radio component within the Cangjie ArkUI framework. It focuses on the implementation of single-selection user interactions, covering everything from basic component creation to advanced customization. Key topics include the Radio component API, state management attributes, event handling, and the RadioIndicatorType enum for configuring selection styles like TICK, DOT, and CUSTOM. This documentation is specifically designed for developers utilizing the Cangjie language to construct HarmonyOS user interfaces. It provides the necessary syntax, configuration options, and code examples to help developers integrate functional and visually tailored radio buttons into their applications effectively.
