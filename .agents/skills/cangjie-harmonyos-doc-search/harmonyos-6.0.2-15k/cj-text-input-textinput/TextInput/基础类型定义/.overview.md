# 基础类型定义

This directory provides essential API reference documentation for fundamental types within the ArkUI framework, specifically designed for the Cangjie language. It focuses on the core components required to implement and manage text input functionality in user interfaces. The documentation covers event handling classes, controller classes for programmatic manipulation, and enumerations for defining input constraints and styles. Key concepts include submission events, cursor management, and input type validation such as passwords or email addresses. These resources are suitable for software developers and UI engineers seeking to configure robust text interactions, visual styles, and input behaviors in ArkUI-based applications.

## Detailed Description

### class_SubmitEvent_4more.md class_SubmitEvent_4more.md
This document serves as API reference documentation for the ArkUI framework in the Cangjie language, specifically defining event classes and style enums for text input components. It covers the SubmitEvent class for handling user submissions, alongside three enumerations: CancelButtonStyle for clear button visibility, EnterKeyType for keyboard action labels, and TextInputStyle for input field appearance and behavior. Key details include the SubmitEvent.text property for retrieving input content and specific style behaviors like the Inline input mode, which restricts error display and text dragging. All components require SystemCapability.ArkUI.ArkUI.Full. Targeted at developers building UI applications using Cangjie and ArkUI, this reference helps configure text input interactions and visual styles.

### class_TextInputController.md class_TextInputController.md
This document provides API reference documentation for the TextInputController class in the Cangjie language, designed to control the TextInput component within the ArkUI framework. It details the class constructor and methods for managing cursor placement, retrieving text metrics, and handling text selection. Key functionalities include setting the caret position, getting the caret offset and text content line count, calculating the text content rectangle relative to the component, and programmatically stopping the editing state. The documentation specifies system capabilities and starting versions for each method. This guide is intended for developers building ArkUI applications who require precise programmatic control over text input behaviors and properties.

### enum_InputType.md enum_InputType.md
This API reference document defines the InputType enum for specifying input field behaviors in the Cangjie ArkUI framework. It details ten enumeration values including Normal, Number, Email, Password, and PhoneNumber, alongside newer types like USER_NAME and URL. Each entry specifies allowed characters, UI constraints like password masking with eye icons, and system capabilities. Some types support password vault integration for auto-filling. This is intended for software developers using the ArkUI framework to configure text input validation and keyboard layouts.
