This directory provides comprehensive documentation on HarmonyOS application permission groups and file access mechanisms. It covers the logic of requesting and authorizing permissions collectively, detailing specific groups such as Location, Camera, and Media. Additionally, it addresses file and folder access methods, including system directory access on 2-in-1 devices and permission-free workflows using Pickers. Key topics include permission grouping, ACL restrictions, media handling, and hardware-specific restrictions for sensors. This resource is suitable for application developers seeking to implement correct system permissions, manage file storage, or handle media selection within their HarmonyOS applications efficiently. It serves as a vital reference for ensuring compliance with system security models while optimizing user experience during permission requests and file interactions.
