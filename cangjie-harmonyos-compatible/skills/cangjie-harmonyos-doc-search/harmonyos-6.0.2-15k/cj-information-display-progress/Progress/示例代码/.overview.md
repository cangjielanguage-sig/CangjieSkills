# 示例代码

This directory contains a collection of code examples and technical tutorials designed for the Cangjie UI framework, specifically focusing on the implementation and customization of the Progress component within HarmonyOS development. The content covers a wide range of functionalities, including how to configure various progress bar types such as Linear, Eclipse, ScaleRing, Ring, and Capsule. It also delves into advanced styling options like stroke width, shadows, gradients, and borders, as well as dynamic behaviors such as smooth animations and scan effects. These examples provide practical implementation details for creating diverse and visually appealing progress indicators. This resource is suitable for Cangjie developers and UI designers seeking to enhance user interface interactions and refine visual transitions in their applications.

## Detailed Description

### 示例1设置进度条的类型.md 示例1设置进度条的类型.md
This document serves as a code tutorial demonstrating how to configure various progress bar types using the type attribute in the Cangjie UI framework. The content covers five distinct progress types: Linear, Eclipse, ScaleRing, Ring, and Capsule, alongside specific styling options like ScaleRingStyleOptions and RingStyleOptions. Key takeaways include setting values, totals, colors, and custom parameters such as stroke width and scale count to achieve different visual effects. Intended for Cangjie developers building HarmonyOS applications, this example provides practical implementation details for creating diverse progress indicators within a user interface. Keywords: Cangjie, Progress component, ProgressType, UI styling, HarmonyOS development.

### 示例2设置环形进度条属性_3more.md 示例2设置环形进度条属性_3more.md
This technical tutorial demonstrates how to customize Progress component properties in the Cangjie UI framework. It covers three distinct examples: setting visual attributes for ring progress bars using strokeWidth and shadow, implementing animations via status and enableScanEffect, and configuring capsule progress bars with text content and borders. Key takeaways include the usage of RingStyleOptions and CapsuleStyleOptions to control appearance and behavior. The document targets UI developers seeking to enhance progress indicators with gradients, shadows, and dynamic effects.

### 示例5设置进度平滑动效.md 示例5设置进度平滑动效.md
This document provides a code example demonstrating how to implement smooth animation effects for a Progress component using the Cangjie language. The primary focus is on the enableSmoothEffect property within the RingStyleOptions class, which allows developers to toggle animation smoothing. The code snippet illustrates a comparison between two Progress bars—one with the effect enabled and one disabled—controlled by a button that increments the progress value. This tutorial is designed for developers working with UI components in the Cangjie framework, specifically those looking to refine visual transitions in progress indicators. Key concepts include state management, component styling, and UI event handling.
