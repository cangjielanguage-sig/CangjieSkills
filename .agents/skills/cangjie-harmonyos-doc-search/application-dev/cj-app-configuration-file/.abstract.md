This directory serves as a comprehensive repository for application configuration documentation, specifically focusing on the HarmonyOS/OpenHarmony ecosystem. It centralizes technical resources related to the `app.json5` configuration file format, which is the standard for defining application manifests, bundle properties, and runtime behaviors. The content covers a wide array of critical topics, including bundle identification, versioning strategies, API compatibility levels, and runtime behavior settings. Furthermore, it provides detailed guidance on environment variables, multi-instance modes, font scaling rules, and device compatibility requirements. This collection is specifically designed for application developers and configuration engineers who utilize DevEco Studio to manage build profiles, define project properties, and control application capabilities effectively. By providing these specifications, the directory ensures that developers can create robust, compliant applications that function correctly across diverse OpenHarmony devices.
