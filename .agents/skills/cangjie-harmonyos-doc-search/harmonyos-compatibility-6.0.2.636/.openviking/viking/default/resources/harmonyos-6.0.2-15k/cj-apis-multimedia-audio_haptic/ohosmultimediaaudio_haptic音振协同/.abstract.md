This directory provides comprehensive API reference documentation for the HarmonyOS `ohos.multimedia.audio_haptic` module, focusing on audio-haptic synergy (synchronized sound and vibration). It covers the Cangjie language implementation for managing multimedia experiences where audio and tactile feedback are combined. Key components include the `AudioHapticManager` and `AudioHapticPlayer` classes, configuration options, callback types, and latency modes. This documentation is suitable for developers and engineers building immersive applications requiring precise control over sensory feedback, specifically targeting API version 19 and above.
