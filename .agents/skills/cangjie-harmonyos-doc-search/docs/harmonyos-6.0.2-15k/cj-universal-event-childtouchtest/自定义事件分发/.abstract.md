This directory focuses on customizing touch event distribution within the ArkUI framework using the Cangjie language. It covers the `onChildTouchTest` mechanism, allowing developers to control how touch events are dispatched to child nodes, manage event conflicts, and handle geometric data for touch points. Key topics include touch result strategies, event propagation control, and coordinate system mappings. This documentation is intended for advanced Cangjie and ArkUI developers who need to build sophisticated UI interaction logic, resolve touch event conflicts in complex layouts, and implement granular control over event flows.
