# class_AVMetadata

This directory provides comprehensive API reference documentation for the `AVMetadata` class, a critical component for multimedia applications developed in the Cangjie programming language. It serves as a central resource for understanding how to encapsulate and manipulate audio and video metadata fields. The content covers a wide array of properties, ranging from standard metadata like media titles, artists, and duration to complex technical attributes including geographic location, sample rates, HDR types, and video dimensions. It highlights that most fields are nullable strings or custom types, which are primarily read-only in the current implementation but serve as essential input parameters for configuring AVRecorder. This documentation is specifically tailored for multimedia developers and software engineers who require precise control over media file attributes, track management, and metadata extraction in their Cangjie-based projects.

### var_trackCount_4more.md var_trackCount_4more.md
This document provides API reference documentation for media resource properties within the Cangjie programming language. It covers four public member variables: trackCount, videoHeight, videoOrientation, and videoWidth. These variables define essential media metadata such as track quantity, video dimensions in pixels, and rotation degrees. All properties are of the nullable String type and became available starting from version 19. Although defined as read-write, the documentation notes that some variables are currently read-only. This reference is designed for developers seeking to access and manipulate media file attributes programmatically.
