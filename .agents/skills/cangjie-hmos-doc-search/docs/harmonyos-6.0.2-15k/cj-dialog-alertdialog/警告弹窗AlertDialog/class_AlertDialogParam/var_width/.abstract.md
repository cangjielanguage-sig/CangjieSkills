This directory contains API reference documentation for the `var_width` component within the Cangjie programming language and ArkUI framework. It primarily focuses on the initialization and configuration of alert dialog components, specifically detailing the `init()` constructor function and the `width` property used for setting backboard dimensions. The documentation covers essential aspects such as required system capabilities, version history, and a wide array of parameters for customization, including alignment, modal state, background blur, and visual styling. This resource is suitable for software developers and UI engineers building user interfaces with Cangjie who need to implement, configure, and customize alert pop-ups in their applications.
