# class_PromptAction

This directory provides comprehensive API reference documentation for the `PromptAction` class within the Cangjie programming language, specifically designed for the ArkUI framework. It covers the creation, management, and lifecycle of various user interface popups, including text prompts, interactive dialog boxes, action menus, and custom dialogs. The documentation details static methods for displaying and closing these components, with specific attention to parameter definitions, version-specific overloads (notably versions 12 and 19), and asynchronous callback mechanisms. This resource is essential for application developers seeking to implement robust user notifications, modal interactions, and menu selection logic in their ArkUI-based applications.
