# Marquee

This directory contains comprehensive API documentation for the Marquee component within the ArkUI framework, specifically designed for developers using the Cangjie language. It covers the implementation of scrolling single-line text, detailing component behavior, initialization, and performance constraints. Key topics include event handling for scroll lifecycles, text styling properties, and configuration parameters like play state and direction. This resource is suitable for HarmonyOS developers looking to integrate interactive text animations and manage UI component styling efficiently.

## Detailed Description

### Marquee_4more.md Marquee_4more.md
This document provides API reference documentation for the Marquee component within the ArkUI framework, designed to display scrolling single-line text. The content details the component's behavior, noting it scrolls only when text width exceeds the component width. Key sections include the component description, child components (none), and two constructor overloads for initialization. Important parameters cover play state, text source, step size, loop count, and direction. The document highlights performance considerations, recommending no more than four instances to maintain frame rates. It supports all common attributes but no common events. This technical reference is intended for developers using the Cangjie language to implement user interfaces.

### 组件事件_2more.md 组件事件_2more.md
This document serves as an API reference for handling events in ArkUI scrolling components using the Cangjie language. It details three specific callback functions: onBounce, onFinish, and onStart, along with their parameters, system capabilities, and a practical code example. Key information includes that onBounce triggers per scroll cycle, onFinish triggers after all cycles complete, and onStart triggers when content changes or scrolling begins. All functions return This and accept a ()->Unit callback. This guide is intended for HarmonyOS developers using Cangjie to implement interactive scrolling text (Marquee) animations, providing the necessary syntax to manage lifecycle events during text scrolling.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring text-related component properties within the Cangjie ArkUI framework. It details specific functions for text styling, including scaling permissions, color, font family, size, weight, and marquee update strategies. Each function entry provides the Cangjie syntax, system capabilities, version requirements, and parameter descriptions. Notable constraints include that text scaling only applies when font size uses 'fp' units, and the default font is 'HarmonyOS Sans'. This technical reference is intended for HarmonyOS developers using the Cangjie language to design and style user interface components.
