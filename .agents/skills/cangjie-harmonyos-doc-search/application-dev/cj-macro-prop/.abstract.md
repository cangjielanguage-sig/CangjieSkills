This directory contains specialized documentation and code examples related to the `@Prop` macro in the Cangjie (CJ) language, specifically designed for the ArkUI framework. It focuses on the critical mechanism of one-way data synchronization from parent to child components, a core concept for building modular and maintainable user interfaces. The content covers variable passing rules, initialization requirements, local mutability constraints, and the nuances of observing simple versus complex data types. It is suitable for developers working with ArkUI who need to master state management nuances and implement robust, predictable parent-child data flow using the `@Prop` decorator.
