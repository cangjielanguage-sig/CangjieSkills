# x509_package_type

本目录包含 x509 包中关于类型定义的核心文档，主要聚焦于 IP 地址的数据表示形式。核心内容是定义了类型别名 `IP`，将其规范为 `Array<Byte>` 类型，以便在 x509 包中统一记录和处理 IP 地址数据。这种定义方式确保了 IP 地址在底层存储和处理时的一致性，能够灵活兼容 IPv4 和 IPv6 等不同长度的地址格式。该文档属于 API 参考资料范畴，旨在为使用 x509 包进行开发的程序员提供清晰的数据类型规范。它不仅解释了类型本身的构成，还阐明了其在 x509 证书处理流程中的具体应用场景。适合具备基础数据类型知识及网络协议背景的开发者阅读，有助于深入理解 x509 证书处理中的数据结构实现，确保在进行证书验证或数据解析时能正确使用该类型。
