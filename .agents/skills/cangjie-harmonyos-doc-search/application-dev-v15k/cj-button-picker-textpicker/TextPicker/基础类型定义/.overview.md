# 基础类型定义

This directory contains API reference documentation for fundamental data structures and classes used within the ArkUI framework, specifically focusing on picker components and selection logic. It covers definitions for range parameters, selection results, and content configuration for text and cascade pickers. Key topics include deprecated classes for legacy support and current implementations for handling UI data selection events. The documentation is primarily written for the Cangjie language and targets HarmonyOS developers who need to configure data behaviors, manage selection states, and handle user interactions in text-based picker interfaces.

### class_RangeParamssupdeprecatedsup.md class_RangeParamssupdeprecatedsup.md

The content outlines the class structure, focusing on three public properties: singlerange, multirange, and cascaderange, alongside their corresponding initialization constructors. Key information includes the data types for these ranges, such as arrays of strings or TextCascadePickerRangeContent objects, and their read-write capabilities. Although marked as deprecated, the class is available starting from API version 19. This documentation targets developers configuring data selection behaviors in UI components, providing the necessary syntax and parameter definitions for implementation.

### class_TextPickerOptions.md class_TextPickerOptions.md
This API reference document details the TextPickerOptions class in the Cangjie language, designed to configure parameters for text picker components within the ArkUI framework. The documentation covers the class constructor and three public properties: range, selected, and value. Key information includes that range defines the data list and cannot be empty, while selected sets the default index and takes priority over the value property, which sets the default text. Both optional parameters default to Option.None. This guide targets ArkUI developers using Cangjie who need to implement text selection interfaces.

### class_TextPickerRangeContent.md class_TextPickerRangeContent.md

It covers the class properties icon and text, along with four constructor overloads that accept combinations of String and AppResource types. Key information includes that the icon is a required image resource, while text is optional and subject to truncation if it exceeds the column width. This reference is intended for HarmonyOS developers using the Cangjie language to implement text selection interfaces, requiring knowledge of resource management and UI components.

### class_TextPickerResData.md class_TextPickerResData.md
This API reference document details the Cangjie class TextPickerResData, which serves as a parameter for onChange events to return selected text and index information. The documentation covers the class definition, properties value and index, and the constructor method init. Key information includes the data types for the selected text (String) and its position (UInt32), both of which are readable and writable. The constructor initializes these mandatory parameters, with specific notes regarding the validity of the value parameter for text-only lists. Intended for ArkUI developers, this class requires SystemCapability.ArkUI.ArkUI.Full support starting from version 12.
