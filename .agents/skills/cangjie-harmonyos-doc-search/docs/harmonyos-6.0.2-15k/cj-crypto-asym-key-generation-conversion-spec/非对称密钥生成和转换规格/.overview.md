# 非对称密钥生成和转换规格

This directory provides technical specifications for generating and converting asymmetric keys within the Cangjie framework. It covers a comprehensive range of cryptographic algorithms, including RSA, DSA, ECC, Diffie-Hellman, SM2, Ed25519, and X25519. The documents detail implementation methods using string parameters or explicit key parameters, supported key lengths, and API version requirements (specifically API 12+). Designed for developers integrating cryptographic functions, this reference guide ensures secure key agreement and digital signature implementation with forward security and performance considerations.

### DH.md DH.md

It covers three generation approaches: using string parameters (e.g., DH_modp2048), explicit key parameters (p, g, l, pk, sk), and prime/private key lengths. The text details supported well-known groups (modp, ffdhe), parameter definitions, and constraints like bit length ranges (512-10000) and performance considerations for non-standard groups. Intended for developers using API version 12+ who need to implement secure key agreement.

### DSA.md DSA.md
This technical reference document outlines the implementation and usage of the Digital Signature Algorithm (DSA) for generating keys and verifying signatures. It details two primary key generation methods: using string parameters (e.g., DSA1024) and using specific mathematical key parameters (p, q, g, pk, sk). Key information includes supported key lengths (1024, 2048, 3072 bits), API version requirements, and performance constraints regarding synchronous generation of larger keys. The document clarifies that DSA is strictly for digital signatures, not encryption, and highlights specific limitations on generating private keys from parameter sets. Targeted at developers integrating cryptographic functions, this guide requires prerequisite knowledge of public-key cryptography and modular arithmetic.
