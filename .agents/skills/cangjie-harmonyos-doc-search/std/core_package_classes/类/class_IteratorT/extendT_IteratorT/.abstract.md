This directory contains comprehensive API documentation for the Iterator type in the Cangjie programming language. It covers a wide range of utility functions and extension methods designed for efficient data sequence manipulation, including terminal operations like `reduce` and `count`, intermediate operations like `filter` and `map`, and traversal control methods like `skip` and `zip`. The documentation distinguishes between operations that consume iterators and those that produce new ones. It is suitable for Cangjie developers looking to implement functional programming patterns and handle collections effectively.
