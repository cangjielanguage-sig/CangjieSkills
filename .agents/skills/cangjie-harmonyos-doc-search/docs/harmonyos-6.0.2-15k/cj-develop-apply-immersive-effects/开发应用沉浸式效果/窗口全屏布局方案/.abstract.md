This directory provides comprehensive technical specifications and implementation guides for window fullscreen layouts within HarmonyOS applications. It focuses on how applications manage system avoidance areas, detailing the differences between immersive modes that hide system UI and extended layouts that allow content to flow behind system bars. Key technical concepts include `setWindowLayoutFullScreen`, dynamic avoidance area listeners, and UI padding adjustments. These resources are specifically designed for HarmonyOS developers and UI designers using Cangjie or ArkUI who aim to build distraction-free, responsive interfaces for media consumption or gaming.
