# 结构体

This directory serves as a central repository for API reference documentation regarding core data structures in the Cangjie programming language, with a specific emphasis on time manipulation and measurement. It encompasses detailed guides for the `DateTime` struct, which handles complex calendar logic, time zone conversions, and formatting, as well as the `MonoTime` struct, which is optimized for monotonic time tracking essential for performance metrics. The documentation includes method definitions, operator overloading details, and interface implementations. This resource is ideal for Cangjie developers, system architects, and application engineers who need to implement precise time-based logic, manage temporal data across different zones, or perform high-accuracy duration measurements and performance testing within their software projects.

## Quick Navigation

What do you want to do?

- Work with calendar dates, time zones, parsing, or formatting? → Go to `struct_DateTime/`
- Measure elapsed time, performance, or handle monotonic clocks? → Go to `struct_MonoTime/`

## Detailed Description

### struct_DateTime/

This directory contains comprehensive API reference documentation for the `DateTime` struct in the Cangjie programming language. It covers a wide range of functionalities including date-time arithmetic, formatting, parsing, time zone conversion, and operator overloading. The documentation details methods for manipulating time components, creating instances from various sources, and comparing dates. It is suitable for Cangjie developers who need precise control over time data, handling edge cases like leap years and time zone offsets, and implementing robust time-based logic in their applications.

### struct_MonoTime/

This directory contains API reference documentation for the `MonoTime` struct within the Cangjie time package. It focuses on representing monotonic time, which is essential for measuring elapsed durations accurately without being affected by system clock changes. The documentation covers struct definitions, inheritance from interfaces like `Hashable` and `Comparable`, and operator overloads for arithmetic and comparison operations. It is suitable for Cangjie developers who need to implement precise time measurement logic, performance testing, or time-priority task queues.
