# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework, specifically utilizing the Cangjie language. It covers essential functionalities for text and input components, ranging from text recognition and conflict resolution to menu customization and input styling. Key topics include `dataDetectorConfig`, `editMenuOptions`, `placeholder` settings, cursor styling, and custom keyboard layouts. These resources are designed for software developers and UI engineers who require detailed syntax, parameter descriptions, and behavioral notes to implement sophisticated text interactions and user interface features in their applications.

## Detailed Description

### func_dataDetectorConfigTex_2more.md
This document serves as API reference documentation for the ArkUI framework in the Cangjie language, detailing configuration methods for text components. It covers two primary functions: dataDetectorConfig, which configures text recognition and defines conflict resolution rules for overlapping entities, and editMenuOptions, which allows customization of menu extensions including text, icons, and callbacks. Key information includes the dependency of data detection on the enableDataDetector setting and specific logic for entity overlap resolution. The target audience is software developers building user interfaces using ArkUI, requiring knowledge of Cangjie syntax and component configuration.

### func_placeholderString_Pla_6more.md
This document serves as API reference documentation for configuring text input component properties in the ArkUI framework using the Cangjie language. It covers six specific functions: placeholder, enterKeyType, caretColor, enableKeyboardOnFocus, selectedBackgroundColor, and enableDataDetector. Key functionalities include setting hint text, customizing keyboard return key types, defining cursor and selection colors, controlling automatic keyboard behavior on focus, and enabling smart text entity recognition for interactive elements like links. Each function entry provides syntax, parameter descriptions, and system capability requirements. Intended for application developers, this guide assumes familiarity with Cangjie syntax and ArkUI component development to effectively customize text input interactions and visual styles.

### 组件属性_5more.md
This document serves as API reference documentation for specific component properties within the ArkUI framework using the Cangjie language. It details four primary functions: bindSelectionMenu, copyOptions, customKeyboard, and placeholder. Key information includes how to configure custom selection menus for text spans, manage copy-paste capabilities, define custom keyboard layouts that overlay the interface, and style placeholder text. This technical guide is intended for developers seeking to customize text input behaviors and user interactions in their applications.
