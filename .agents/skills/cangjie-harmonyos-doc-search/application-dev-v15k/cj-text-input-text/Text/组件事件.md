## 组件事件

### func onCopy((String) -> Unit)

```cangjie
public func onCopy(callback: (String)->Unit): This
```

**功能：** 长按文本内部区域弹出剪贴板后，点击剪切板复制按钮，触发该事件。目前文本复制仅支持文本。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|(String)->Unit|是|-|回调函数，参数为复制的文本内容。|

### func onTextSelectionChange((Int32, Int32) -> Unit)

```cangjie
public func onTextSelectionChange(callback: (Int32, Int32) -> Unit): This
```

**功能：** 文本选择的位置发生变化时，触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|(Int32, Int32)->Unit|是|-|回调函数，入参为所选文本的起始位置和结束位置。|
