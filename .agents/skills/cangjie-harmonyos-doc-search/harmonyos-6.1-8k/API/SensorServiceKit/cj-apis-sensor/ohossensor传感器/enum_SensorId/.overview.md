# enum_SensorId

本目录汇集了仓颉语言中传感器API的参考文档，重点涵盖`SensorId`枚举定义及多种传感器的使用指南。内容涉及环境光、重力、陀螺仪、霍尔、心率、线性加速度、方向、接近光及佩戴检测等传感器。文档详细说明了各传感器的功能、系统能力及起始版本，并提供了通过`on`、`once`、`off`方法进行数据订阅、单次获取和取消订阅的代码示例，包括回调类定义与异常处理。这些文档适合使用SensorServiceKit进行HarmonyOS开发的程序员，需具备仓颉语言基础。
