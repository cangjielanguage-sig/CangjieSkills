# cjpm_manual

This directory serves as the comprehensive manual for the Cangjie Programming Language's official project management tool, CJPM. It covers the entire software development lifecycle, including project initialization, building, testing, and installation or uninstallation. The documentation provides detailed insights into command-line usage, configuration specifications, build scripts, and dependency management. Key topics include CJPM, package management, build configuration, and dependency resolution. This resource is designed for Cangjie developers who want to efficiently organize their code, automate build processes, and resolve common development issues.
