## Detailed Description

### cj-universal-gesture-swipegesture.md

This document serves as the essential API reference documentation for the `SwipeGesture` component in the Cangjie language. It is designed to assist developers in detecting swipe gestures based on velocity, providing the technical foundation for responsive touch interfaces. The content covers the component's initialization method in detail, explaining how to configure the finger count, swipe direction, and speed threshold to match specific application needs. It also describes the `onAction` event callback, which allows the application to react dynamically to detected gestures.

A significant portion of the document is dedicated to the `SwipeDirection` enum. It defines the constraints for gesture detection, offering clear definitions for Horizontal, Vertical, All, or None directions. This allows developers to restrict user input to specific axes or allow free-form swiping. To bridge the gap between theory and practice, the document includes a practical code example. This example demonstrates how to bind the gesture to a UI element and update state variables, providing a clear template for implementation. This guide targets developers building ArkUI applications who require precise control over touch interactions and gesture recognition.
