# 系统相册资源使用指导

This directory provides comprehensive technical guidance for HarmonyOS developers on accessing and managing system album resources using the photoAccessHelper module and MediaLibraryKit. It covers specific album types such as favorites, videos, and screen captures, utilizing the Cangjie programming language. The documentation details essential prerequisites, including module initialization, permission acquisition (like READ_IMAGEVIDEO), and data assumptions. It is designed for application developers and software engineers seeking to integrate system media library features, offering practical code examples and step-by-step instructions for retrieving album objects and media assets efficiently.

## Detailed Description

### 系统相册资源使用指导.md 系统相册资源使用指导.md
This document serves as a usage guide for developers on how to utilize the photoAccessHelper module to access and manage specific system album resources like favorites, videos, and screen captures. It covers the scope of supported album types, prerequisites regarding module initialization and permissions, and assumptions about pre-existing resource data. Key points include the necessity of obtaining the PhotoAccessHelper instance beforehand and the requirement that target resources must already exist in the database for the examples to work. The target audience is application developers who need to interact with system albums, requiring prior knowledge of permission application and module setup.

### 收藏夹/

### 视频相册/
