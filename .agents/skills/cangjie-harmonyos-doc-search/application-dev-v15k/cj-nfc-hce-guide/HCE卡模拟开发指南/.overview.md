# HCE卡模拟开发指南

This guide provides a comprehensive technical overview of Host Card Emulation (HCE) technology specifically tailored for the Cangjie development framework and HarmonyOS ecosystem. It thoroughly details the principles of simulating NFC cards without relying on secure hardware elements, covering essential implementation scenarios such as foreground and background swiping. Key topics include Application ID (AID) management, APDU command processing, and system configuration constraints like screen unlock requirements. Designed for developers proficient in ArkTS or Cangjie, this resource equips you with the necessary API references and architectural knowledge to build secure, interactive applications that communicate seamlessly with NFC readers. Whether you are building payment solutions or access control systems, this documentation covers the full development lifecycle.

### 简介_3more.md 简介_3more.md
This document introduces Host Card Emulation (HCE) technology for the Cangjie development framework, explaining how applications simulate NFC cards without secure hardware. It details usage scenarios, distinguishing between foreground swiping, where the active app handles transactions, and background swiping, which relies on Application ID (AID) matching. The text outlines specific constraints, such as the requirement for an unlocked screen and proper permission declarations in configuration files. Furthermore, it summarizes key API interfaces, including start(), stop(), on(), and transmit(), essential for managing communication with NFC readers. This guide serves as a technical overview for developers implementing NFC card emulation features.
