This directory focuses on the `bindSheet` component within the ArkUI framework, specifically utilizing the Cangjie language. It provides comprehensive guides on implementing and configuring semi-modal pages (bottom sheets) for various UI scenarios. Key topics include managing nested scrolling interactions, customizing dismissal and spring-back behaviors, and understanding component lifecycles. The documentation covers essential parameters, gesture handling rules, and usage constraints to ensure smooth user experiences. This resource is suitable for UI developers and engineers building context-preserving popup interfaces with complex interaction logic in Cangjie applications.
