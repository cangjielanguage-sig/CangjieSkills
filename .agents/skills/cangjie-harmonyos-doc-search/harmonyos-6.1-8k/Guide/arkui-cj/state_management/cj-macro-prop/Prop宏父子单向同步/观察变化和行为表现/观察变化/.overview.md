# 观察变化

本目录深入探讨了Cangjie编程语言在ArkUI开发框架下的状态管理核心概念，重点聚焦于“观察变化”这一机制。它详细解析了如何利用`@Prop`装饰器监听数据变动，涵盖了从基础数据类型到复杂对象（如类、数组、集合）的全方位观察规则。文档不仅解释了数据单向同步的原理，还特别区分了不同数据结构在响应式更新中的行为差异（如整体赋值与深层观察）。内容旨在帮助ArkUI/Cangjie开发者深入理解状态传播机制，解决数据驱动UI更新过程中的常见问题，是构建高性能、响应式用户界面的重要参考资料。

## 详细说明

### 观察变化_1.md
本文档详细阐述了Cangjie状态管理中@Prop装饰器的变化观察机制。涵盖了基础类型、结构体、类、数组及其他集合的观察规则，以及与@State的同步场景。关键点包括：基础类型可观察数值变化；结构体仅支持整体赋值；类需配合@Observed和@Publish实现深层观察；普通数组仅支持整体赋值，而ObservedArrayList支持项级变更。@Prop与父组件@State单向同步，不影响数据源。该参考指南面向ArkUI/Cangjie开发者，旨在帮助其理解状态传播与数据响应式原理。
