This directory provides comprehensive API reference documentation for the HarmonyOS system account management module (`ohos.account.osAccount`) using the Cangjie programming language. It covers essential data structures like `DomainAccountInfo` and `OsAccountInfo`, enumerations for account types, and the core `AccountManager` class for handling account operations. Additionally, it includes a detailed list of system constraints for device management. This documentation is intended for system application developers and engineers who need to implement user account creation, deletion, querying, and restriction enforcement within HarmonyOS applications.
