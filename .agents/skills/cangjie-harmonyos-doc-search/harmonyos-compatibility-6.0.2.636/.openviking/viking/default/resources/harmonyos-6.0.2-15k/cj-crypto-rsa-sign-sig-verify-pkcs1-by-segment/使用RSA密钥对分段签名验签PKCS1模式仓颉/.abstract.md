This directory focuses on implementing segmented RSA signing and verification using the PKCS1 padding mode within the Cangjie programming language. It covers the essential workflows for handling large data volumes that cannot be processed in a single pass, utilizing the CryptoArchitectureKit. Key concepts include asymmetric encryption, RSA1024 key pairs, PKCS1 padding, and SHA256 digest algorithms. The content is designed for Cangjie developers who need to perform secure digital signatures on chunked data, ensuring data integrity and authentication through step-by-step tutorials and practical code examples.
