The `stdreflect` directory provides comprehensive documentation for the `reflect` package within the Cangjie programming language ecosystem. It focuses on enabling runtime type inspection, manipulation, and invocation, allowing developers to interact dynamically with program metadata. The content covers essential aspects such as platform compatibility constraints, visibility rules for global variables and functions, and specific limitations regarding type support. This resource is specifically designed for Cangjie developers who aim to implement dynamic runtime behaviors, manage access control boundaries, or require deep integration with the language's type system. It serves as a foundational guide for understanding how to leverage reflection capabilities effectively in Cangjie applications.
