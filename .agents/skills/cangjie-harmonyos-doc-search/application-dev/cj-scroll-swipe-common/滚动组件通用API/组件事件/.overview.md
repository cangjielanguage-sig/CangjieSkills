# 组件事件

This directory contains API reference documentation for scroll-related event callbacks within the Cangjie ArkUI framework. It focuses on the mechanisms developers use to monitor, control, and respond to scroll interactions in UI components. The documentation covers a range of event types, from detecting the start and end of scrolling to intercepting scroll actions before they occur. Key concepts include offset tracking, boundary detection, and scroll state management. The scope includes both post-event notifications and pre-event interception capabilities. This resource is essential for UI developers and system architects working with the Cangjie language who require precise control over component scrolling behaviors and event handling logic to create responsive user interfaces.

## Detailed Description

### func_onDidScrollOnScrollCa_5more.md
This document provides comprehensive API reference documentation for scroll-related event callbacks in the Cangjie ArkUI framework. It details five specific functions: `onDidScroll`, `onReachEnd`, `onReachStart`, `onScrollStart`, and `onScrollStop`. The content explains how these functions handle various scroll events, such as frame-by-frame offset tracking for real-time updates, detecting start/end boundaries (including spring edge effects), and identifying when scrolling is initiated or ceased by touch inputs or Scroller APIs. A notable feature is that all these functions return the component instance, facilitating method chaining for cleaner code. This reference is intended for developers building UI components using the Cangjie language who need to implement custom scroll behaviors and listeners.

### func_onWillScrollOptionFlo_2more.md
This document serves as API reference documentation for the `onWillScroll` function in the Cangjie language, designed to handle pre-scroll events within ArkUI components. It details two overloaded function signatures: one allows modification of the scroll offset via a `ScrollResult` return value, while the other is for read-only observation returning Unit. Key sections include parameter descriptions for offset, state, and source, alongside system capability requirements and version notes. Important takeaways are that the callback provides the calculated offset before the actual scroll takes place and excludes specific triggers like `scrollEdge`. This guide targets UI developers seeking to programmatically control or monitor scroll behaviors in their applications.
