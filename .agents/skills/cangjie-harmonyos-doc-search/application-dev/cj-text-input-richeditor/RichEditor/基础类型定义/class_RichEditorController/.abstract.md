This directory provides comprehensive API reference documentation for the `RichEditorController` class, specifically designed for use with the Cangjie language within the ArkUI framework. It serves as a critical technical resource for developers aiming to implement and control RichEditor components programmatically. The documentation thoroughly details the class architecture, including its inheritance from `RichEditorBaseController`, and enumerates the methods required for sophisticated content manipulation. Key functionalities covered include inserting text and image spans with specific options, updating styles across defined ranges, deleting content segments, and managing selection menus. Furthermore, it explains how to retrieve span data and modify paragraph formatting. This guide is indispensable for software developers building complex text editing interfaces, offering specific insights into parameter behaviors, return types, and system capabilities required for version 22+ environments.
