This directory contains the technical reference documentation for the Common Event Manager (CEM) tool, a specialized command-line utility designed to assist developers in the complex task of debugging and testing public events. It provides comprehensive coverage of the tool's operational capabilities, including simulating event publication to verify system behavior and printing detailed subscriber information to trace event flows. The documentation highlights critical environment prerequisites, such as the necessity of the hdc tool for connectivity, and thoroughly explains the tool's three core commands: help, publish, and dump. Furthermore, it addresses specific technical constraints, such as the limitation of the dump command to engineering builds. This resource is essential for system-level developers and QA engineers who require a reliable method to validate event interactions, inspect subscriber states, and troubleshoot communication issues between system components directly from the command line, ultimately ensuring the stability and reliability of the event system.
