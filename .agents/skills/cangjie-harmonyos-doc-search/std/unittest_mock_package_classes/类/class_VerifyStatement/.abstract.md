This directory contains essential API documentation for the `VerifyStatement` class, a core component of the Cangjie unit testing framework focused on mocking and verification. It provides detailed guidance on verifying the execution frequency of stub signatures within mock objects. The documentation covers the class definition, creation constraints enforced by the `@Called` macro, and various member functions such as `atLeastOnce`, `atLeastTimes`, `once`, and `times`. It also explains critical exception handling for `MockFrameworkException` and `IllegalArgumentException`. This resource is specifically designed for developers and software engineers who are writing unit tests and need to rigorously validate mock behavior and ensure specific functions are called the correct number of times.
