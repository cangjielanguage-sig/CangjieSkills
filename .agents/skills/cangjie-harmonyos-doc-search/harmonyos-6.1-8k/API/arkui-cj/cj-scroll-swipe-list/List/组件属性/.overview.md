# 组件属性

本目录包含ArkUI框架中List组件的属性配置API参考文档，主要面向使用仓颉语言进行应用开发的开发者。文档详细介绍了如何通过函数配置列表的布局方向、多列显示、边缘效果、分割线、粘性样式以及多选模式等核心功能。内容涵盖了性能优化（如懒加载预加载）和交互体验定制的具体实现，旨在帮助开发者在版本22及以上的环境中构建高性能、交互丰富的复杂列表界面。

## 详细说明

### func_alignListIte_7more_10f6ea8b.md func_alignListIte_7more_10f6ea8b.md
本文档是ArkUI框架List组件的API参考，详细说明了配置列表布局、行为及样式的函数。主要涵盖`alignListItem`（交叉轴对齐）、`cachedCount`（懒加载预加载）、`chainAnimation`（边界动画）、`divider`（分割线）、`edgeEffect`（边缘效果）及`lanes`（多列布局）六个核心函数。关键信息包括参数定义、默认值（如`cachedCount`初始值为1）及特定行为逻辑，所有功能均支持SystemCapability.ArkUI.ArkUI.Full。文档面向使用仓颉语言开发ArkUI应用的开发者，旨在帮助其优化列表性能并定制交互体验。

### func_listDirectio_3more_b5d27a24.md func_listDirectio_3more_b5d27a24.md
本文档是ArkUI框架下Cangjie语言的API参考文档，详细介绍了配置列表组件行为的三个核心函数。主要涵盖listDirection（设置排列方向）、multiSelectable（启用多选）和sticky（固定组头组尾）。每个函数条目均包含功能描述、系统能力、起始版本及参数详情，明确了参数类型和默认值。这些函数均返回This以支持链式调用。文档旨在帮助开发者在版本22及以上的环境中，精确控制列表的布局方向、选择模式及粘性样式，适用于需要构建复杂列表界面的ArkUI应用开发者。
