# class_PhotoAsset

This directory provides comprehensive API reference documentation for the `PhotoAsset` class within the MediaLibraryKit framework, specifically designed for the Cangjie language. It serves as a technical guide for encapsulating file attributes within the PhotoAccessHelper system, covering essential operations such as accessing read-only properties, retrieving thumbnails, and modifying metadata. Key topics include property definitions (e.g., `displayName`, `uri`), method implementations like `commitModify` and `getThumbnail`, and the management of system permissions like `READ_IMAGEVIDEO`. This documentation is tailored for HarmonyOS application developers and assumes familiarity with Cangjie syntax and application context management.

## Detailed Description

### class_PhotoAsset_6more.md
This document serves as API reference documentation for the PhotoAsset class in the Cangjie language, designed to encapsulate file attributes within the PhotoAccessHelper system. It covers read-only properties such as displayName, photoType, and uri, alongside methods for modifying metadata (commitModify) and retrieving member parameters (get). Key information includes the requirement for the WRITE_IMAGEVIDEO permission for modifications and the necessity of specifying fetchColumns when accessing specific attributes. The document also details specific error codes for exception handling. Intended for developers using the MediaLibraryKit, this reference assumes familiarity with Cangjie syntax and application context management.

### func_getThumbnailSize_2more.md
This document serves as API reference documentation for Cangjie developers working with the MediaLibraryKit to manipulate photo assets. It primarily details two functions: getThumbnail, which retrieves a file's thumbnail as a PixelMap with an optional size parameter, and set, which modifies specific metadata like the asset title. Key information includes required permissions such as ohos.permission.READ_IMAGEVIDEO, system capabilities, parameter definitions, and potential BusinessException error codes. The text provides practical code examples demonstrating how to fetch assets and apply these operations. Intended for HarmonyOS application developers, this reference assumes familiarity with the Cangjie language syntax and context management.
