This directory focuses on the RelativeContainer component within the Cangjie UI and ArkUI frameworks. It covers the implementation of relative positioning to optimize complex interface layouts by reducing deep component nesting. Key topics include alignment rules, anchor configurations, dimension priority, component chains, and dependency management. The documentation provides practical code examples in Cangjie and ArkTS to help developers create responsive and efficient user interfaces. It is suitable for HarmonyOS developers and UI engineers looking to master relative positioning constraints and layout performance optimization.
