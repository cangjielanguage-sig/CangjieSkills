This directory contains documentation and examples for the `Rect` component within the ArkUI framework using the Cangjie language. It covers the API reference for creating rectangles, configuring attributes like dimensions and border radii, and practical code examples for styling shapes. Key topics include component constructors, universal attributes, rounded corners, and declarative UI implementation. This resource is suitable for UI developers and programmers working on HarmonyOS or OpenHarmony applications who need to implement and customize geometric shapes in their user interfaces.
