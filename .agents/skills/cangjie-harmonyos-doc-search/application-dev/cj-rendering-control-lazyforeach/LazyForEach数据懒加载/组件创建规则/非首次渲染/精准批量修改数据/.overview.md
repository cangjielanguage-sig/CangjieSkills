# 精准批量修改数据

This directory provides comprehensive technical guidance on implementing precise batch data modifications for UI components, specifically focusing on `LazyForEach` within the Cangjie and ArkUI frameworks. It details how to utilize `BasicDataSource` and `notifyDatasetChange` to achieve efficient, granular control over list data updates. The content covers two main approaches: utilizing specific data operations like `DataMoveOperation` and `DataExchangeOperation`, and using direct array assignment with calculated operations. Key concepts include managing index references and adhering to modification constraints such as avoiding mixing interfaces. This material is essential for developers aiming to optimize rendering performance and minimize resource consumption during complex data state changes in their applications.

## Detailed Description

### 精准批量修改数据_1.md
This tutorial demonstrates how to implement precise batch data modifications for LazyForEach components in Cangjie using BasicDataSource and notifyDatasetChange. The document covers two code examples: one utilizing specific data operations like DataMoveOperation and DataExchangeOperation, and another using direct array assignment with calculated operations. Key takeaways include the importance of referencing indices from the pre-modification array state and avoiding mixing onDatasetChange with other modification interfaces. This guide targets Cangjie developers seeking efficient, granular control over list data updates to optimize rendering performance.

### 精准批量修改数据_2.md
This document serves as a technical guide for implementing precise batch data modifications using specific operation types within a UI framework's LazyForEach component. It covers array transformation examples, defining operations like DataMoveOperation, DataExchangeOperation, DataAddOperation, and DataDeleteOperation based on index changes. Key takeaways include critical constraints: a single index can only be operated on once per change, developers can manually provide keys to optimize performance, and a RELOAD operation invalidates all other operations. This reference is intended for developers optimizing list rendering and data updates in ArkUI or similar environments.
