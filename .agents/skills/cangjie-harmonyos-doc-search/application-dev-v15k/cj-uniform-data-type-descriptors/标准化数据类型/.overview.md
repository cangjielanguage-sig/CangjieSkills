# 标准化数据类型

This directory provides comprehensive documentation on the Uniform Type Descriptor (UTD) system, designed to resolve data type ambiguity and facilitate cross-application and cross-device data transmission. It covers the design principles of hierarchical structures, classification into physical and logical types, and specific definition attributes. The content includes tutorials for querying media types, mapping file extensions to MIME types using the Cangjie language, and guides for defining custom data types. It is suitable for HarmonyOS and Cangjie developers implementing file management, sharing, or data processing features.

## Detailed Description

### 场景介绍_4more.md 场景介绍_4more.md
This document introduces the Uniform Type Descriptor (UTD) system designed to resolve data type ambiguity and facilitate cross-application and cross-device data transmission. It covers the design principles of hierarchical structures, classification into physical and logical types, specific definition attributes, and preset data types. UTD replaces flat definitions with a hierarchical model supporting inheritance, categorizing types as general.entity (physical) or general.object (logical). It defines types using attributes like typeId, belongingToTypes, and mimeTypes. This guide targets HarmonyOS developers implementing file management, sharing, or data processing features.

### 如何查询媒体类文件归属类型.md 如何查询媒体类文件归属类型.md
This tutorial demonstrates how to use the Uniform Type Descriptor (UTD) module to identify and classify media file types in the Cangjie programming language. It covers querying types via filename extensions and MIME types, comparing type equality, and verifying hierarchical belonging relationships. The code example illustrates functions like getUniformDataTypeByFilenameExtension, getTypeDescriptor, and belongsTo to confirm that a specific type like general.mp3 falls under broader categories like general.audio. This guide targets Cangjie developers needing to implement file type detection and validation logic.

### 如何通过文件后缀获取对应的MIMEType列表_2more.md 如何通过文件后缀获取对应的MIMEType列表_2more.md
This technical tutorial demonstrates how to perform bidirectional mapping between file extensions and MIME types using the uniformTypeDescriptor module in the Cangjie language. The document covers two primary workflows: retrieving a list of MIME types from a specific file extension (e.g., ".mp3") and retrieving a list of file extensions from a specific MIME type (e.g., "audio/mp3"). Key information includes step-by-step code examples utilizing functions like getUniformDataTypeByFilenameExtension, getUniformDataTypeByMIMEType, and getTypeDescriptor, along with exception handling for BusinessException. This guide is intended for developers working within the ArkData framework who need to programmatically identify and convert file data types.

### 接口说明.md 接口说明.md
This document serves as a quick reference guide for common Uniform Type Descriptor (UTD) interfaces used for handling standardized data types. It covers the UniformDataType enumeration and functions for type hierarchy checks, such as belongsTo, isLowerLevelType, and isHigherLevelType, alongside methods for retrieving type IDs via filename extensions or MIME types. Key information includes the capability to query specific data types with optional parent type filtering. Intended for developers working with data definitions, this summary complements the full API documentation by highlighting essential utility functions for type management and validation.
