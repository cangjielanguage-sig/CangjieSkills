## Detailed Description

### 整数类型/

This directory contains the detailed reference documentation for integer types in the Cangjie programming language. The content is structured to provide a complete understanding of how integers are handled, starting with their definitions and classifications. It explicitly covers the distinctions between signed and unsigned types, ranging from Int8 to Int64, as well as the special Native types designed for platform-specific optimizations.

The documentation delves into the technical specifics of representation ranges, which is crucial for preventing data overflow and ensuring numerical accuracy. It also provides a comprehensive guide to literal notations, explaining how to represent numbers in various bases (decimal, hexadecimal, etc.), the correct application of suffix rules, and the usage of character byte literals.

Furthermore, this section details the full suite of operators supported by integer types. This includes standard arithmetic operations for calculations, bitwise operations for low-level data manipulation, and relational operators for logic flow. Finally, it outlines the type conversion rules, clarifying how and when integers can be converted to other types. These documents are highly suitable for developers who need to deeply understand the basic usage, technical details, and best practices of Cangjie language integer data types to build high-performance applications. By adhering to the guidelines provided, developers can ensure their code adheres to language standards and avoids common pitfalls associated with integer arithmetic.
