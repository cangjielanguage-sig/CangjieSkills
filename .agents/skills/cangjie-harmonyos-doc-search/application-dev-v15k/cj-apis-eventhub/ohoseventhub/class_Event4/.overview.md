# class_Event4

This directory provides comprehensive API documentation for the `Event4` class and related subscription functions within the Cangjie programming language. It specifically addresses the handling of events that require four generic arguments, covering the full lifecycle from emission to unsubscription. The documentation details the integration with the `EventHub` and `EventCallBack4` interfaces, offering practical code examples for implementation. This resource is essential for developers utilizing the AbilityKit framework and the AbilityRuntime Core system to build robust, event-driven applications with complex parameter passing requirements.

### class_Event4_4more.md class_Event4_4more.md
This document provides API reference documentation for the Event4 class in the Cangjie programming language, designed to handle events requiring four generic arguments. It details the class definition, inheritance from EventBase, and three primary methods: emit for triggering events with four parameters, and two overloaded off functions for unsubscribing specific callbacks or all listeners. Key functionality includes passing generic parameters (A1-A4) during event emission and managing subscriptions. The document includes practical code examples demonstrating integration with EventHub and EventCallBack4. Intended for developers building applications using the AbilityKit framework, specifically those managing event-driven logic with multiple parameters.

This reference guide targets Cangjie developers working with the AbilityKit, specifically those implementing event handling logic within the AbilityRuntime Core system.
