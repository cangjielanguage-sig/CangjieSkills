# cj-process-model-stage

This directory serves as a critical technical resource for understanding the system's process model, specifically focusing on the architectural logic behind how application components—namely UIAbility and ExtensionAbility—are mapped to distinct operating system processes. The content provides a deep dive into the default allocation strategies that govern main, extension, and render processes, ensuring developers understand the baseline behavior of the runtime environment. Beyond the basics, it addresses advanced configuration scenarios required for system applications and specialized hardware like 2-in-1 devices, where multi-process setups are often necessary for performance and stability. Key technical concepts covered include the implementation of process isolation via the `isolationMode` attribute within `module.json5` configuration files and the assignment of custom process names for system-level applications. Additionally, the documentation outlines Inter-Process Communication (IPC) mechanisms, such as the common event service, which are vital for data exchange between isolated processes. This comprehensive guide is tailored for system architects and application developers seeking to optimize resource allocation, enhance application security through isolation, and manage complex process lifecycles effectively.
