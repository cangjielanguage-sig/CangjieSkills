# onKeyEvent

本目录主要介绍ArkUI框架中`onKeyEvent`方法的使用与事件处理机制。内容涵盖了组件获焦时的外设键盘按键事件处理、函数签名、回调参数（如KeyType、keyText）详解，以及事件冒泡机制的控制方法。重点讲解了如何通过`stopPropagation`阻止事件冒泡，并提供了视觉演示。适合需要实现键盘交互逻辑、控制输入流及管理事件响应的ArkUI开发者参考。

### onKeyEvent_1.md onKeyEvent_1.md
本文档介绍了ArkUI中`onKeyEvent`方法的用法，用于处理组件获焦时的外设键盘按键事件。文档涵盖了函数签名、`KeyEvent`回调参数详情（如`KeyType`、`keyText`）、事件冒泡机制演示以及如何通过`stopPropagation`阻止冒泡。关键点包括事件默认冒泡、按键包含按下和抬起两个阶段，以及使用`stopPropagation`方法可限制事件仅在当前组件响应。面向需要实现键盘交互逻辑的ArkUI开发者，属于API参考与教程结合的文档。
