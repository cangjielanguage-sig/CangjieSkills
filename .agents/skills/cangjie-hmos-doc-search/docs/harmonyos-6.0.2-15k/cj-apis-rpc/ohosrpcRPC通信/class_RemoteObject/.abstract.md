This directory provides comprehensive API reference documentation for the `RemoteObject` class and associated Inter-Process Communication (IPC) functions within the Cangjie programming language ecosystem. It focuses on the architecture required to implement remote objects, manage their lifecycles, and facilitate communication between processes. Key topics include retrieving peer information (PID/UID), managing object descriptors, handling death notifications, and sending synchronous or asynchronous messages. The documentation is specifically designed for system developers and engineers responsible for constructing robust IPC services, offering detailed specifications on parameters, return values, and exception handling for error codes like `BusinessException`.
