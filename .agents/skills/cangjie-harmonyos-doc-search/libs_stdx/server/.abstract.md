This directory is a comprehensive educational resource designed for developers utilizing the Cangjie programming language to build secure network applications. It focuses specifically on the implementation of a Transport Layer Security (TLS) server, providing a step-by-step code tutorial that addresses the complexities of encrypted communication. The content covers the entire lifecycle of setting up a secure server, starting with the necessary imports of standard libraries and progressing to the technicalities of parsing X509 certificates and private keys from PEM files. It offers in-depth explanations on configuring the TLS server context, creating a `TlsServerConfig`, and binding a `TcpServerSocket` to port 8443. Additionally, the tutorial explores advanced concurrency patterns, demonstrating how to manage multiple client connections simultaneously through a custom `acceptLoop` extension that leverages the `spawn` functionality. By detailing the handshake process and data reading mechanisms via `TlsSocket`, this guide ensures developers understand both the security and networking aspects. It is intended for Cangjie developers who possess a foundational understanding of network programming and have their own certificate files ready for integration. By following this guide, developers will gain the practical skills necessary to deploy secure, high-performance servers capable of handling encrypted traffic efficiently.
