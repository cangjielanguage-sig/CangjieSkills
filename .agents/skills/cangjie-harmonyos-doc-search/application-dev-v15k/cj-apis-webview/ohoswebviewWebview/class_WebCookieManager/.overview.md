# class_WebCookieManager

This directory provides comprehensive API reference documentation for the `WebCookieManager` class within the Cangjie language, specifically tailored for the ArkWeb framework. It encompasses a wide range of functionalities essential for controlling cookie behaviors in Web components, such as clearing session and persistent data, configuring cookies for specific URLs, and managing third-party permissions. The documentation highlights critical features like incognito mode support, asynchronous persistence, and error handling for invalid inputs. It is primarily intended for software developers and engineers working on HarmonyOS applications who require precise control over web data privacy, storage, and synchronization within WebView environments.

## Detailed Description

### class_WebCookieManager_5more.md class_WebCookieManager_5more.md
This document serves as API reference documentation for the WebCookieManager class in the Cangjie language, designed to control cookie behaviors within Web components. It covers static methods for clearing all cookies, clearing session cookies, and configuring cookies for specific URLs. Key information includes support for both normal and incognito modes, specific error handling for invalid URLs or values, and the recommendation to sync cookies before WebView loading. Version 20 introduces an includeHttpOnly parameter for advanced control. The target audience is developers using the ArkWeb kit who need to manage persistent or session-based web data in their applications.

### static_func_existCookieBoo_5more.md static_func_existCookieBoo_5more.md
This document serves as an API reference for the WebCookieManager class in the Cangjie language, detailing static methods for managing web cookies within the ArkWeb framework. It covers five key functions: checking cookie existence, fetching cookies by URL, and querying or setting permissions for general and third-party cookies. Key information includes support for incognito mode in existence checks and fetch operations, as well as specific error handling for invalid URLs. All methods require SystemCapability.Web.Webview.Core starting from version 12. This technical reference is intended for software developers using Cangjie to implement cookie management and privacy controls in HarmonyOS web applications.
