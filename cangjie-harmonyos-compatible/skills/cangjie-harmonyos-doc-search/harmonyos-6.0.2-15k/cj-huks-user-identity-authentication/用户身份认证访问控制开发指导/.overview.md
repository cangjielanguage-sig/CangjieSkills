# 用户身份认证访问控制开发指导

This directory provides a specialized development guide focused on user identity authentication and access control mechanisms. It is designed to assist developers in integrating advanced biometric security features, particularly fingerprint authentication, with the Universal Keystore Kit (HUKS) using the Cangjie language. The content encompasses the entire security workflow, ranging from generating secure cryptographic keys and managing sessions to performing SM4 encryption operations secured by UserIAM. This resource is ideal for HarmonyOS application developers who require a deep understanding of how to implement secure access controls and protect sensitive user data through robust authentication protocols.
