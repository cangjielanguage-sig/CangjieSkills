This directory serves as a practical resource hub for the Cangjie programming language, specifically focusing on the application of regular expressions for text processing and data parsing. It includes detailed tutorials that guide developers through the standard regex library's capabilities, ranging from basic pattern matching to advanced text manipulation. Key topics covered include the use of the MatchData class for handling capture groups, implementing case-insensitive and multi-line matching strategies, and utilizing Unicode support for internationalization. Furthermore, it demonstrates string replacement techniques. This collection is ideal for Cangjie developers seeking to enhance their applications with robust search-and-replace functionalities and complex data extraction logic.
