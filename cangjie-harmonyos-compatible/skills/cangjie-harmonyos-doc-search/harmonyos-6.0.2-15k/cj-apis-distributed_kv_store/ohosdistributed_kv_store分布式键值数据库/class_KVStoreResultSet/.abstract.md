This directory contains API reference documentation for the `KVStoreResultSet` class in the Cangjie programming language, specifically designed for managing database query results within distributed data systems. It covers essential functionalities such as cursor navigation, data retrieval, and position tracking for the ArkData framework. Key topics include methods for moving through result sets, checking cursor status, and accessing key-value pairs. This documentation is suitable for developers working on HarmonyOS applications who need to handle distributed data management and iterate through query results efficiently.
