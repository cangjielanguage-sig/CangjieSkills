This directory serves as a comprehensive resource for understanding state management within the Cangjie declarative UI framework. It details the fundamental mechanisms where state changes drive UI rendering, clearly distinguishing between state variables and regular variables. The content covers essential component-level decorators such as @State, @Prop, and @Link, alongside application-level solutions like AppStorage and LocalStorage. Furthermore, it addresses data flow patterns, including unidirectional and bidirectional flows, and nested object observation. This guide is ideal for developers building dynamic applications who require a deep understanding of data synchronization between components, pages, and global states to ensure efficient and responsive UI updates.
