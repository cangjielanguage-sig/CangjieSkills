# 资源分类

This directory provides a comprehensive guide to organizing and managing application resources within the development framework. It covers the structural hierarchy of resource directories, including base and qualifier directories for device adaptation, as well as specific resource groups like element, media, and profile. The documentation details naming conventions, file formats, and the handling of raw files. It is designed for developers and system architects who need to efficiently categorize assets, implement internationalization strategies, and ensure compatibility across diverse devices in the HarmonyOS ecosystem.

## Detailed Description

### 资源分类.md 资源分类.md
This document serves as a structural reference guide for organizing resource files within application development projects. It details the standard directory hierarchy under the resources folder, distinguishing between the base directory for default resources, qualifier directories for specific device contexts like language or screen density, and rawfile or resfile for arbitrary file storage. Key takeaways include the definition of resource group directories element, media, and profile and the specific location for shared resources in the stage model AppScope resources. This guide is intended for developers needing to correctly categorize and manage project assets. Keywords: resource classification, directory structure, stage model, qualifier directories, base, rawfile.

### 资源组目录.md 资源组目录.md
This technical reference document defines the structure and specifications of resource group directories used to organize application assets. It details three primary directory types: element for typed JSON data, media for multimedia files, and profile for custom configurations. Key information includes strict naming conventions for element files (e.g., boolean.json, string.json), supported media formats like JPEG and H.264 AVC, and the requirement for profile files to be JSON. The document also provides JSON structure examples for various data types. This guide is intended for developers and system integrators managing resource files and configurations within the software framework.

### 资源目录/
This directory serves as a comprehensive technical reference for the architecture and management of application resource directories, specifically tailored for the HarmonyOS ecosystem. It details the structural hierarchy of resources, distinguishing between base directories and qualifier directories used for localization and device adaptation. The documentation covers critical aspects such as naming conventions, resource compilation into binary files, and the specific ordering rules for qualifiers like MCC, language, and orientation. Furthermore, it addresses the handling of non-compiled resources through rawfile and resfile directories, explaining access methods and sandbox path extraction. This guide is indispensable for software developers, system architects, and localization specialists who need to efficiently organize application assets, ensure compatibility across diverse devices, and implement robust internationalization strategies.
