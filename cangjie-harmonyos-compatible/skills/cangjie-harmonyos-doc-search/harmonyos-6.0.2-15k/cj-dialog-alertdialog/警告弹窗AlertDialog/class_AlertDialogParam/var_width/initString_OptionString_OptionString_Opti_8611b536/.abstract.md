This directory contains comprehensive API reference documentation for initializing and configuring an alert dialog component using the Cangjie language within the ArkUI framework. It covers the core constructor signature, system capabilities, and an extensive range of parameters governing content, layout, behavior, and visual styling. Key topics include mandatory message strings, alignment defaults, modal properties, and specific visual adjustments such as borders, corners, and transitions. These resources are specifically designed for ArkUI developers seeking to implement or customize dialog interfaces, requiring a solid understanding of Cangjie syntax and UI component integration.
