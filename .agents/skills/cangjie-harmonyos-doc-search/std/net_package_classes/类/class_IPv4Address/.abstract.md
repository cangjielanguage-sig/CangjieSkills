This directory contains API reference documentation for the `IPv4Address` class in the Cangjie programming language. It covers the definition, constructors, static properties, utility methods, and operators for representing and manipulating Internet Protocol version 4 addresses. Key topics include address creation from bytes or integers, conversion to other formats (like IPv6 or strings), serialization, and network classification checks (e.g., private, broadcast). This documentation is suitable for developers implementing network functionality who need precise technical specifications for IPv4 handling.
