This directory contains comprehensive documentation for the Checkbox component within the ArkUI framework, specifically designed for the Cangjie language. It covers the fundamental API reference, component properties, event handling, and practical code examples for implementing toggle controls. Key topics include component initialization, custom styling (shapes, colors, indicators), and state management using `onChange` events. This resource is suitable for HarmonyOS application developers and UI engineers who need to integrate or customize checkbox functionality in their user interfaces.
