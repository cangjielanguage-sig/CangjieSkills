# cj-quick-start-cangjie-module-cpp

This directory serves as a quick-start technical resource for developers utilizing the Cangjie programming language within the HarmonyOS environment, focusing on integrating C++ modules and managing application deployment. ## Detailed Description

### 仓颉调用模块内cpp文件/

This directory functions as an essential technical resource for developers utilizing the Cangjie programming language within the HarmonyOS development environment. It specifically addresses the complex integration of C++ modules and the deployment of applications that rely on these hybrid architectures. The guide provides meticulous, step-by-step instructions on bridging high-level Cangjie code with low-level C++ implementations. By leveraging the Foreign Function Interface (FFI), developers can ensure efficient performance and maximize code reuse, which is vital for resource-intensive applications.

In addition to code bridging, the material covers the critical configuration steps required to run applications on various target platforms. This includes detailed procedures for deploying to local physical devices and software emulators, ensuring that the application behaves correctly across different environments. Key technical topics explored in this section include the proper use of the `foreign` keyword to declare external functions, configuring `cjpm.toml` for correct library linking, and utilizing `extern "C"` to prevent name mangling in C++.

Moreover, the guide explains how to modify `build-profile.json5` to achieve architecture compatibility, a common stumbling block in cross-platform development. This content is specifically tailored for Cangjie developers who are looking to extend their application capabilities through native code integration. It serves as a practical manual for validating work across different testing environments using DevEco Studio, providing the necessary tools and knowledge to streamline the development workflow. By following these guidelines, developers can effectively harness the power of native C++ libraries while maintaining the productivity of the Cangjie language.
