# P2P模式开发指导

This directory serves as a comprehensive technical resource for developers aiming to implement Wi-Fi Peer-to-Peer (P2P) functionality using the Cangjie language and the ConnectivityKit. It provides in-depth guidance on establishing direct TCP/IP connections between devices without relying on a traditional Access Point. The documentation covers critical concepts such as P2P mode definitions, device discovery mechanisms, and the management of P2P groups. It includes detailed API references and practical code examples for handling connection states and event callbacks. This guide is specifically designed for software developers and engineers who are building connectivity applications requiring robust peer-to-peer communication workflows, offering both theoretical background and actionable implementation steps to ensure successful integration of wireless P2P features into modern software systems.

## Detailed Description

### 主要场景开发步骤.md
This technical guide provides step-by-step instructions for implementing Wi-Fi P2P functionality using the Cangjie language. It covers two primary scenarios: creating or deleting P2P groups and establishing P2P connections. Key information includes prerequisites like system capabilities, code examples for managing persistent versus temporary groups, and methods for registering event callbacks to handle device discovery and connection state changes. The document is designed for developers building connectivity applications, offering practical implementation details for peer-to-peer communication workflows.

### 简介_3more.md
This document provides an overview of Wi-Fi P2P technology, explaining how to establish direct TCP/IP connections between devices without an Access Point. It covers the definition of P2P mode, usage scenarios such as group creation and connection establishment, and a detailed list of relevant Cangjie APIs. Key takeaways include the specific functions for device discovery, connection management, and event registration for monitoring peer devices and connection states. This technical guide targets developers implementing P2P functionality using the ConnectivityKit, requiring knowledge of the Cangjie programming language. Keywords: Wi-Fi P2P, Cangjie API, WLAN, TCP/IP, ConnectivityKit, device discovery, group management.
