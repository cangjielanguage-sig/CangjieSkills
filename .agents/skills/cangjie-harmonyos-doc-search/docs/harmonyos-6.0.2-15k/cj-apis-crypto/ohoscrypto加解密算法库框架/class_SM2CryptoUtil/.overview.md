# class_SM2CryptoUtil

This directory provides API reference documentation for the `SM2CryptoUtil` class within the Cangjie programming language, specifically designed for SM2 cryptographic operations. It covers essential functionalities for handling ASN.1 formatted SM2 ciphertext, including both generation and parameter extraction. The documentation details function signatures, parameter definitions, return values, and error handling for exceptions such as invalid parameters or crypto operation failures. It is intended for developers utilizing the `SystemCapability.Security.CryptoFramework` to implement national standard encryption, requiring a solid understanding of Cangjie syntax and cryptographic data structures.
