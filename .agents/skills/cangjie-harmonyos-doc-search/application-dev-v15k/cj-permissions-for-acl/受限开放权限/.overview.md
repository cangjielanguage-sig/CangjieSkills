# 受限开放权限

This directory functions as a definitive guide for managing and applying restricted open permissions within the HarmonyOS and OpenHarmony development environments. It addresses the complex requirements developers face when seeking access to sensitive system capabilities that are otherwise protected. The content covers the complete lifecycle of permission management, beginning with the initial application process and eligibility criteria, moving through the App Gallery Connect (AGC) review, and concluding with the strict compliance audits required for app publication. It emphasizes the critical nature of matching usage scenarios to requested permissions to avoid rejection. Additionally, the directory provides detailed reference documentation for specific permissions introduced in API version 12, covering areas such as hardware access (HID, USB), file manipulation, data sharing, and advanced system features like virtual screens. It distinguishes between authorization types like system_grant and user_grant, outlining strict restrictions for enterprise and financial scenarios. This resource is essential for HarmonyOS developers and system engineers who need to securely implement high-risk functionalities while adhering to platform security standards.

## Detailed Description

### 申请方式.md 申请方式.md
This document outlines the application process and compliance requirements for developers seeking to use restricted permissions in HarmonyOS applications. It covers the eligibility criteria, noting that only specific special scenarios qualify, and details the subsequent review process by the App Gallery Connect (AGC). Key information includes the necessity of passing an approval process and the strict audit of usage scenarios during app publication, where mismatched permissions lead to rejection. This guide is intended for HarmonyOS developers preparing to publish apps that require sensitive system capabilities, ensuring they understand the approval and review workflow.

### [2] 权限列表/
This directory contains reference documentation for specific system permissions introduced in OpenHarmony and HarmonyOS API version 12. It covers sensitive capabilities related to hardware access (HID, USB, disk), file manipulation, data sharing, and system-level features like floating windows and virtual screens. The documents detail authorization types (system_grant vs. user_grant) and strict usage restrictions for scenarios such as 2in1 devices, financial applications, and enterprise tools. This resource is suitable for application developers and system engineers who need to implement secure access to restricted system resources or user data.
