# hdc

This directory contains comprehensive documentation for the HarmonyOS Device Connector (HDC), a command-line tool essential for debugging OpenHarmony and HarmonyOS devices. It covers the tool's architecture, installation, command syntax, file transfer, port forwarding, and application management. The resources also include troubleshooting guides for error codes, connectivity issues, and service process management. Suitable for software developers, QA engineers, and system administrators, this documentation provides the necessary instructions to establish a robust debugging environment and efficiently manage device interactions from Windows, Linux, or macOS systems.

## Detailed Description

### hdc_2more.md
This document introduces hdc (OpenHarmony Device Connector), a command-line tool enabling developers to debug OpenHarmony devices from Windows, Linux, or macOS systems. It details the tool's three-part architecture consisting of the client, server, and daemon, explaining their interaction and data flow. The guide covers environment preparation, including locating the tool within DevEco Studio and adding it to the system PATH. Key takeaways include the server's default listening port of 8710 and instructions for customizing this port via the OHOS_HDC_SERVER_PORT environment variable.

### hdc命令列表.md
This document serves as a technical reference guide for the hdc command-line tool, detailing parameters and commands for device interaction. It is divided into two main sections: global parameters for configuration (such as device selection via -t and logging levels) and a comprehensive command list covering device connection, file transfer, app installation, and debugging. Key takeaways include the requirement that global parameters must precede commands and the availability of specific utilities for port forwarding and system mounting.

### hdc调试日志.md
This technical guide details how to configure and retrieve debugging logs for the HDC (HarmonyOS Device Connector) tool. It covers server-side log configuration, including runtime log levels and environment variables, and device-side log collection using the hilog tool. Key information includes setting log levels (0-6) via the `-l` flag, where level 6 enables detailed USB diagnostics. Server logs are stored in OS-specific temp directories, while device logs are captured using `hdc shell hilog` commands.

### 基本使用方法.md
This document serves as a quick start guide for the OpenHarmony Device Connector (HDC) tool, detailing fundamental operations for developers. It covers prerequisites like enabling USB debugging, querying connected devices using `hdc list targets`, and executing shell commands. The guide explains how to access help information via `-h` or `help` flags, including verbose options. Additionally, it provides troubleshooting advice for common issues such as process exceptions and unrecognized devices, suggesting commands like `hdc kill -r`.

### 安全相关命令_2more.md
This document serves as a technical reference guide for specific hdc command-line tool functions related to security and version management. It details the keygen command for generating public-private key pairs and version query commands including -v/version and checkserver to retrieve SDK and server process information. The guide provides syntax formats, parameter definitions for custom filenames, and expected return values for version strings, including examples for practical implementation.

### 执行交互命令_2more.md
This reference guide documents the usage of the hdc tool for executing shell commands and managing applications on a device. It covers the `hdc shell` command for both interactive and non-interactive execution, alongside Application Management commands for installing and uninstalling packages. Key information includes syntax for targeting specific app bundles using the `-b` parameter, which requires a debug certificate, and specific flags for replacing existing apps or preserving data during uninstallation.

### 文件传输.md
This reference documentation details the usage of hdc commands for transferring files between a local host and a remote device. It covers two primary operations: file send for uploading files and file recv for downloading files. The document explains command syntax, parameters for preserving timestamps or syncing permissions, and specific flags for transferring data within debuggable application bundles. It includes usage examples and notes on debug certificate requirements.

### 服务进程管理.md
This document serves as a technical reference for managing the lifecycle of the hdc service process. It covers four main operational areas: starting and restarting the service, terminating the process, bypassing process checks for fast command execution, and launching the service in foreground mode. Key information includes log level priority rules, default network configurations, and the restriction that only a single service instance can run.

### 端口转发.md
This document serves as a technical reference guide for managing port forwarding tasks between a host PC and a device using the hdc command-line tool. It details four primary operations: listing active tasks, setting up forward port mapping, configuring reverse port mapping, and removing specific tasks. The guide specifies supported protocols like tcp and jdwp, command syntax, parameters, and potential return values indicating success or failure reasons such as port conflicts.

### 设备操作.md
This document serves as a technical reference guide for device operation commands within the hdc toolset. It details commands for system logging (hilog), debugging process management (jpid, track-jpid), device rebooting (target boot), and root-level file system operations (target mount, smode). The guide provides syntax, parameters, return values, and usage examples for each command, explicitly noting that functions like mounting system partitions and granting root permissions require a rooted device.

### hdc错误码/
This directory serves as a comprehensive repository for troubleshooting guides related to HarmonyOS Device Connector (HDC) error codes. It specifically addresses common issues encountered during command-line interactions, such as invalid bundle names, unsupported interactive modes, and file transfer failures. The documentation provides detailed root cause analysis and step-by-step resolution strategies using standard HarmonyOS commands like `hdc`, `bm`, and `aa`.

### 常见问题/
This directory serves as a specialized knowledge base for troubleshooting frequent technical issues encountered during the HarmonyOS and OpenHarmony development lifecycle. It focuses on resolving critical barriers that impede the development workflow, specifically targeting tool execution failures and hardware connectivity problems. The documentation covers a wide spectrum of solutions, including environment configuration, driver management, dependency checks, and system-level debugging across Windows, Linux, and macOS platforms.

### 设备连接管理/
This directory serves as a technical resource for managing connections between HarmonyOS devices and development environments using the HarmonyOS Device Connector (HDC). It covers critical operations such as switching between USB and wireless debugging modes, querying device lists, and managing multi-device environments. The documentation includes detailed command syntax, parameters, and troubleshooting steps for various network topologies, including local TCP and remote connections.
