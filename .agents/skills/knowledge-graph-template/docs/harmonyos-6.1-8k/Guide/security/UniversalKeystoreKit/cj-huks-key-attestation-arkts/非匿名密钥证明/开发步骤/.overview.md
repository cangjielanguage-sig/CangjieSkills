# 开发步骤

本目录提供了使用Cangjie语言在HarmonyOS HUKS框架下实现密钥证明功能的开发指南。内容涵盖了从确定密钥别名、初始化参数集、生成非对称密钥到调用匿名证明接口的完整流程。文档详细介绍了如何配置RSA密钥参数、设置必要的挑战属性（HUKS_TAG_ATTESTATION_CHALLENGE）以及获取证书链。这些资料适合熟悉通用密钥库套件（HUKS）及Cangjie语法的开发者，旨在帮助其在应用中安全地实现密钥认证与证明功能。

## 详细说明

### 开发步骤_1.md
本文档是一份关于使用Cangjie语言进行HUKS匿名密钥证明的开发指南。主要涵盖了确定密钥别名、初始化参数集、生成非对称密钥及调用anonAttestKeyItem方法进行证明四个步骤。文档提供了详细的Cangjie代码示例，重点说明了HuksOptions中必须包含HUKS_TAG_ATTESTATION_CHALLENGE属性，并演示了如何配置RSA密钥参数。关键信息在于通过特定API调用实现密钥的安全证明。该文档面向熟悉通用密钥库套件及Cangjie语法的开发者，旨在帮助其在应用中实现密钥认证功能。

### 开发步骤_2.md
本文档提供了在开发工作流中实现密钥证明的代码示例。内容涵盖了用于执行证明逻辑的publicAttestKey函数，以及通过结合密钥生成和证明来验证过程的attestKeyTest函数。关键要点包括特定的函数调用attestKeyItemext和publicGenKeyFunc，attestCertChain的检索，以及keyAlias和huksOptions参数的使用。该文档适用于从事加密密钥管理的开发者，特别是在HarmonyOS HUKS框架内，作为安全实施的实用参考。
