# class_HiTraceChain

This directory contains API reference documentation for the `HiTraceChain` class in the Cangjie language, part of the Performance Analysis Kit. It focuses on distributed service process call chain tracking, enabling developers to monitor business logic flows and performance across systems. Key concepts include `HiTraceId` instances, trace flags like `INCLUDE_ASYNC`, and lifecycle management methods. The documentation is suitable for developers working on HarmonyOS applications who need to implement distributed tracing, manage trace states, and perform system diagnostics using the `SystemCapability.HiviewDFX.HiTrace` capability.
