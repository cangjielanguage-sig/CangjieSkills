This directory contains API reference documentation for the core interfaces within the Cangjie database SQL package. It defines the standard contracts for database interactions, including connection management, query execution, transaction control, and result handling. Key components include interfaces for `Connection`, `Datasource`, `QueryResult`, `Transaction`, and `Statement`, alongside metadata definitions like `ColumnInfo` and legacy type definitions. This documentation is essential for developers implementing database drivers or building applications that interact with SQL databases using the Cangjie programming language, providing the necessary structural and behavioral specifications for robust data access.
