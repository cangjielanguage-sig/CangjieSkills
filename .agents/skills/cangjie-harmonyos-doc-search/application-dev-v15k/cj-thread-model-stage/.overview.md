# cj-thread-model-stage

This directory serves as a comprehensive technical resource dedicated to the threading architecture within the Stage model for Cangjie application development. It provides an in-depth analysis of the operational distinctions between the Main Thread and Cangjie threads, clarifying their specific roles in system operations. The documentation covers critical aspects such as UI rendering, event distribution, and lifecycle management, which are vital for creating responsive and stable applications. Furthermore, it details the EventHub mechanism for facilitating intra-thread communication and data synchronization between key components like UIAbility and UI. This guide is essential for Cangjie developers who need to master concurrency, optimize application performance, and ensure smooth component interaction within their applications using the Stage model. Understanding these threading concepts is crucial for preventing UI freezes and ensuring efficient resource utilization in a multi-threaded environment.
