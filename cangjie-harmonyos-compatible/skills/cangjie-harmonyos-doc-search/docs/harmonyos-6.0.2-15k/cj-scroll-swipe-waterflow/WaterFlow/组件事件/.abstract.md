This directory contains API reference documentation for the WaterFlow component in the ArkUI framework, specifically using the Cangjie language. It covers essential classes, enums, and event handling functions required to implement and manage waterfall flow layouts. Key topics include layout direction, flow modes, section management, and scroll event callbacks. This documentation is suitable for developers building HarmonyOS applications who need to create dynamic, high-performance list interfaces with complex scrolling behaviors and data grouping.
