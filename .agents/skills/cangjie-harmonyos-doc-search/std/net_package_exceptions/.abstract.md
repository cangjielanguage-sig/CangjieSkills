This directory provides comprehensive API reference documentation for exception handling classes within the Cangjie net package. It is dedicated to the architectural and functional details of error management mechanisms required for modern network programming. The content specifically covers the definitions, inheritance hierarchies, and constructor signatures for classes designed to handle socket errors and connection timeouts. By offering a clear technical reference, it enables developers to write more resilient and fault-tolerant code. It serves as a foundational guide for maintaining robust network connectivity. This directory is suitable for Cangjie developers, backend engineers, and system architects who are actively developing networked applications and need precise tools to catch, identify, and manage socket-related errors and timeout exceptions effectively.
