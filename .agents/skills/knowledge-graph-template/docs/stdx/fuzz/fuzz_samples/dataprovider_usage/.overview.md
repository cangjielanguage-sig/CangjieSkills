# dataprovider_usage

本目录包含关于在仓颉语言中使用 FuzzDataProvider 进行 API 测试的指南文档。内容涵盖了 FuzzDataProvider 类的基本用法、通过 consume 系列方法从变异数据源生成标准数据类型的代码示例，以及如何配置调试功能以打印日志追踪数据消费过程。该文档主要面向需要进行模糊测试和 API 调试的开发者，旨在提供比直接操作字节流更友好的测试方式，并包含特定编译标志的使用说明及调试输出格式。
