# 连接和传输数据

本目录专注于蓝牙低功耗（BLE）设备的连接建立与数据传输机制，核心基于GATT协议。内容涵盖了从基础理论到实际开发的完整流程，包括GATT客户端与服务端的实现原理、服务发现、特征值读写及通知处理。特别针对HarmonyOS平台，提供了使用仓颉语言进行开发的详细步骤及ConnectivityKit模块的应用指南。本资料适合从事蓝牙应用开发的工程师，旨在帮助其掌握在HarmonyOS生态下构建稳定、高效蓝牙通信功能的关键技术。
