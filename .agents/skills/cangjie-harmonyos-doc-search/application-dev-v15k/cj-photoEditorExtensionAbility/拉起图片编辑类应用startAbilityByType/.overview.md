# 拉起图片编辑类应用startAbilityByType

This directory provides a comprehensive guide for HarmonyOS developers on integrating image editing capabilities using the `startAbilityByType` interface and `PhotoEditorExtensionAbility`. The documentation is tailored for developers using ArkTS or Cangjie who need to implement seamless image modification features or extend existing applications with editing functionalities.
