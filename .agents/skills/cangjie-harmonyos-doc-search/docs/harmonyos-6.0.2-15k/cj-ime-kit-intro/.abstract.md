This directory contains the comprehensive introductory documentation for the IME Kit, a vital framework designed to facilitate seamless communication between applications and input method editors. It provides an in-depth look at the framework's principles, usage scenarios, and functional features, serving as a critical resource for developers working within the ArkUI environment. The content details the kit's provision of APIs for input method services, which are essential for creating soft keyboards, as well as framework APIs for custom edit boxes, including functionalities for binding and cursor movement. Furthermore, it addresses system-level capabilities for managing input methods, such as showing or hiding keyboards, while clearly outlining the specific system permissions required for these management functions. This guide is specifically tailored for developers aiming to implement custom text input interfaces or develop input method applications, offering the necessary API references and constraints to guide the development process.
