# stdsync

The `stdsync` directory provides comprehensive documentation for the Cangjie programming language's synchronization package, focusing on high-performance concurrency and thread safety. It covers essential concepts such as the M:N threading model, lightweight user-level threads, and atomic operations for various data types. The content details synchronization primitives like mutexes and the `synchronized` keyword, which ensures automatic lock release during exceptions. This documentation is suitable for Cangjie developers seeking to build efficient multi-threaded applications while abstracting away low-level operating system thread management complexities.

## Detailed Description

### 功能介绍.md
This document serves as a feature introduction for the Cangjie programming language's sync package, detailing its concurrency capabilities. It covers the M:N threading model, thread creation using the spawn keyword, atomic operations for integers, booleans, and references, and thread synchronization via mutexes and the synchronized keyword. Key takeaways include that Cangjie threads are lightweight, user-level threads, and the synchronized keyword ensures automatic lock release even during exceptions, solving common manual locking issues. This guide targets Cangjie developers looking to implement efficient concurrent programming without managing low-level OS thread details. Keywords: Cangjie, sync package, concurrency, spawn, atomic operations, synchronized, mutex, M:N threading.
