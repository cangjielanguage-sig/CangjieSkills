This directory contains API documentation for the AppStorage class, a central storage mechanism for application state data within the Cangjie language and ArkUI framework. It covers essential functionalities for managing application state lifecycles, including one-way and two-way data binding, property retrieval, updates, and deletion. Key topics include static methods like `prop`, `link`, `set`, and `has`, which facilitate reactive programming and synchronization between app state and UI components. This documentation is suitable for ArkUI developers and software engineers looking to implement robust state management solutions in their applications.
