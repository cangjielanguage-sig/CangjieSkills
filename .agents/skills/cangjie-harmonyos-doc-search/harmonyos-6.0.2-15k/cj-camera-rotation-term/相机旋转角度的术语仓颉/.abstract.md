This directory serves as a comprehensive technical repository for understanding and implementing camera rotation logic in mobile applications. It covers the mathematical relationships between device orientation, gravity sensors, and camera lens installation angles for both photo/video capture and preview modes. Key topics include screen rotation compensation, mirroring effects for front cameras, and specific formulas for calculating image orientation. This documentation is suitable for application developers and system engineers who need to programmatically handle image orientation, ensure correct display alignment, and adapt to various device rotation scenarios.
