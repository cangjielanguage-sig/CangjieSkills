# 使用AES对称密钥CBC模式加解密仓颉

This directory provides a comprehensive technical resource focused on implementing AES symmetric encryption and decryption using the CBC mode specifically within the Cangjie programming language. It covers critical security operations including the generation of 128-bit SymKeys, the configuration of Cipher instances using 'AES128|CBC|PKCS7', and the management of Initialization Vectors (IvParamsSpec). The resources range from step-by-step workflow guides to synchronous code examples utilizing the CryptoArchitectureKit. This content is highly suitable for Cangjie developers seeking to integrate advanced cryptographic security features into their applications, offering both the theoretical background and practical code necessary to ensure data confidentiality and integrity effectively.
