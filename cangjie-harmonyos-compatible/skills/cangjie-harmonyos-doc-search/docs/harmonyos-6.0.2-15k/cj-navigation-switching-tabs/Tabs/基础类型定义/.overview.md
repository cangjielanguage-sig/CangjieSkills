# 基础类型定义

This directory provides API reference documentation for fundamental type definitions within the ArkUI framework, specifically tailored for the Cangjie language. It encompasses classes and enums essential for configuring Tabs and TabBar components, covering aspects such as responsive grid layouts, visual styling, animation control, and tab management logic. Key topics include grid column options, divider styles, scrollable modes, transition proxies, animation events, and layout enumerations. This documentation is intended for HarmonyOS developers seeking to implement sophisticated UI behaviors, custom animations, and responsive designs in their applications using Cangjie.

## Detailed Description

### class_BarGridColumnOptions.md class_BarGridColumnOptions.md
This API documentation defines the BarGridColumnOptions class in Cangjie, used to configure grid layout settings for a TabBar component, specifically managing margins, gutters, and responsive column counts across different screen sizes. The document details the class structure, read-only properties for spacing (margin, gutter) and responsive columns (sm, md, lg), and the constructor method with default parameters. Key takeaways include that spacing properties do not support percentages, column counts must be non-negative even integers, and specific screen size breakpoints are defined (e.g., small screens are 320-600.vp). A value of -1 for columns defaults to full width. This reference guide targets developers using the ArkUI framework in Cangjie who need to implement responsive TabBar layouts.

This technical reference targets ArkUI developers using Cangjie who need to customize divider appearance in their user interfaces. Keywords: DividerStyle, Cangjie, ArkUI, API reference, UI styling.

### class_TabContentTransitionProxy.md class_TabContentTransitionProxy.md
This document serves as API reference material for the Cangjie class TabContentTransitionProxy, designed to manage custom switching animations within the Tabs component. The documentation details the class structure, highlighting two read-only properties, from and to, which provide the index values for the starting and target pages. It also explains the finishTransition method, which developers must invoke to notify the system that the custom animation has concluded. Key takeaways include understanding how to access page indices and the necessity of signaling transition completion. This guide targets developers implementing advanced UI transitions in HarmonyOS applications using the Cangjie language.

### class_TabsAnimationEvent_2more.md class_TabsAnimationEvent_2more.md
This document provides API reference documentation for the TabsAnimationEvent class and AnimationMode enum in the Cangjie language, specifically for managing animation behaviors within the ArkUI Tabs component. It details the TabsAnimationEvent class, which encapsulates animation metrics like current offset, target offset, and velocity. It also defines the AnimationMode enumeration, which specifies the sequence of content loading and animation during tab switches. Key properties include read-only Float32 values for offsets and velocity. The enum offers three modes: loading content before animation, animation before content, or disabling animation entirely. All elements are available starting from API version 19. This reference guide targets developers using the Cangjie language to build UIs in HarmonyOS, specifically those customizing tab switching animations and transitions.

### enum_LayoutStyle_3more.md enum_LayoutStyle_3more.md
This document serves as API reference documentation for ArkUI enums related to TabBar layout and positioning. It details three enumerations: LayoutStyle, BarPosition, and BarMode. LayoutStyle defines tab distribution behavior in non-scrolling states, offering options like ALWAYS_CENTER and ALWAYS_AVERAGE_SPLIT. BarPosition determines tab placement (Start or End) relative to vertical orientation, while BarMode controls whether tabs divide space evenly (Fixed) or scroll upon overflow (Scrollable). Key information includes specific functional behaviors for each enum value and their system capabilities. This reference is intended for developers configuring Tab components within the ArkUI framework.
