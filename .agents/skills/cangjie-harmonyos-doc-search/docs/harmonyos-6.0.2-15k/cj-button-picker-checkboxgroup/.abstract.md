This directory contains documentation and resources for the `cj-button-picker-checkboxgroup` component, specifically focusing on the implementation of checkbox groups within the ArkUI framework using the Cangjie language. It covers the essential aspects of creating, configuring, and managing checkbox groups to handle collective selection states, including select-all functionality. Key topics include the component constructor, property customization for visual styling, and event handling for state changes. This resource is suitable for application developers and UI engineers building interactive forms and multi-selection interfaces in HarmonyOS applications who require detailed API references and practical implementation examples.
