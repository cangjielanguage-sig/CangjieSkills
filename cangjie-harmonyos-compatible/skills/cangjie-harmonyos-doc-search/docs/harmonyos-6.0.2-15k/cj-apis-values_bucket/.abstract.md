This directory provides comprehensive API reference documentation for the `ohos.values_bucket` module, a critical component of the Cangjie programming language ecosystem. It is specifically designed to facilitate the handling of data collections required for database insertion within HarmonyOS applications. The documentation centers on the `VBValueType` enumeration, which rigorously defines the permissible data field types for database operations, encompassing Null, Integer, Double, String, and Boolean. Additionally, it covers the module import path, necessary system capabilities, and the data structures used for transmitting key-value pairs. This resource is tailored for developers leveraging the ArkData kit who possess a solid understanding of Cangjie syntax and database concepts, aiming to streamline the implementation of robust data storage and retrieval mechanisms.
