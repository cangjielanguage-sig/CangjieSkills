# data_package_classes

本目录提供了数据包中核心类的 API 参考文档，主要聚焦于 CSV 和 JSON 格式的数据序列化策略。文档深入解析了 CsvStrategy、JsonStrategy 以及 SerializableProvider 三个关键组件，阐述了它们如何通过继承 DataStrategy 基类和实现 DataProvider 接口来协同工作。内容涵盖了从策略生成到数据提供（provider 方法）的完整流程，包括对无限数据流（isInfinite 属性）的处理。该文档专为仓颉语言开发者设计，旨在为构建高效、可扩展的数据处理系统提供详实的技术指导。

## 详细描述

### data_package_classes.md data_package_classes.md
本文档是数据包中CSV和JSON序列化策略类的API参考。涵盖了CsvStrategy、JsonStrategy及SerializableProvider三个核心类。前两者继承自DataStrategy，通过provider方法生成SerializableProvider实例。该类实现了DataProvider接口，利用isInfinite属性和provide方法返回可迭代数据对象。文档面向仓颉语言开发者，旨在辅助其实现数据序列化与提供功能。
