This directory provides API reference documentation for the `ohos.bluetooth.a2dp` module in the Cangjie programming language, designed for the HarmonyOS/OpenHarmony ecosystem. It focuses on the A2DP Source profile, enabling developers to implement Bluetooth audio streaming, manage device connections, and configure codec parameters. The documentation includes classes for profile management and enumerations for audio encoding settings like sample rates and channel modes. This resource is suitable for software developers building applications that require high-quality audio transmission to remote Bluetooth devices.
