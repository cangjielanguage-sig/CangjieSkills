This directory serves as a comprehensive resource for the HarmonyOS Relational Store module, specifically tailored for developers using the Cangjie programming language. It provides detailed API reference documentation centered on the ArkData kit, enabling the management of local SQLite-based databases with ease. The content covers critical aspects of application development, including distributed data synchronization across multiple devices and secure storage operations to protect sensitive information. Key topics addressed include database creation, configuration, encryption standards, query predicates, result sets, and asset management for files and images. This documentation is essential for HarmonyOS developers seeking to implement robust persistent local data storage, handle complex multi-device synchronization scenarios, and ensure high-level data security within their applications.
