# 权限列表

This directory contains reference documentation for specific system permissions introduced in OpenHarmony and HarmonyOS API version 12. It covers sensitive capabilities related to hardware access (HID, USB, disk), file manipulation, data sharing, and system-level features like floating windows and virtual screens. The documents detail authorization types (system_grant vs. user_grant) and strict usage restrictions for scenarios such as 2in1 devices, financial applications, and enterprise tools. This resource is suitable for application developers and system engineers who need to implement secure access to restricted system resources or user data.

## Detailed Description

### ohospermissionACCESS_DDK_H_7more.md ohospermissionACCESS_DDK_H_7more.md
This reference document defines specific OpenHarmony system permissions introduced in version 12, detailing their usage scenarios and authorization requirements. It covers permissions for HID driver access, clipboard reading, persistent file access, input event interception and monitoring, short-term media saving, and user file modification. Key information highlights that many permissions are restricted to 2in1 devices or specific scenarios like cloud desktops, banking apps, or development tools. Authorization types vary between system_grant and user_grant. This guide targets application developers needing to implement sensitive features like hardware access or file manipulation on the OpenHarmony platform.

### ohospermissionACCESS_DISK__9more.md ohospermissionACCESS_DISK__9more.md
This document serves as a technical reference for nine specific sensitive permissions introduced in HarmonyOS API 12. It details permissions regarding disk hardware access, file preloading, proxy configuration, device management restrictions, fraud detection data access, Bluetooth MAC address persistence, and virtual screen management. Key information highlights that all permissions utilize system authorization and are strictly restricted to particular scenarios, such as financial trading, enterprise traffic management, UAD applications, anti-fraud tools, IoT device binding, and car connectivity. This guide is intended for developers needing to understand eligibility and usage constraints for these high-privilege system capabilities.

### ohospermissionREAD_WRITE_U_7more.md ohospermissionREAD_WRITE_U_7more.md
This reference document defines seven restricted HarmonyOS permissions introduced in API version 12, covering USB debugging, IoT networking, kernel memory management, and data sharing controls. Topics include USB device access, Wi-Fi peer MAC retrieval, code memory protection exemptions for cross-platform frameworks, JIT compilation permissions, and clipboard or UDMF sharing scope management. Key takeaways are that these permissions require system authorization and are strictly limited to specific scenarios like 2in1 devices, gaming, or enterprise allow-listed applications. The target audience is HarmonyOS developers building IDE tools, IoT apps, games, or cross-platform applications requiring low-level system access.

### ohospermissionSYSTEM_FLOAT_9more.md ohospermissionSYSTEM_FLOAT_9more.md
This reference document defines specific OpenHarmony system permissions available starting from API version 12, detailing their usage scopes and authorization requirements. It covers permissions for global floating windows, contact data, audio and video files, desktop directory access, and USB DDK interfaces. Key information includes valid application scenarios, alternative solutions like Pickers for data access, and authorization types (system_grant or user_grant). Several permissions are restricted to 2in1 devices. This guide targets HarmonyOS application developers needing to request sensitive system capabilities or access user data securely.
