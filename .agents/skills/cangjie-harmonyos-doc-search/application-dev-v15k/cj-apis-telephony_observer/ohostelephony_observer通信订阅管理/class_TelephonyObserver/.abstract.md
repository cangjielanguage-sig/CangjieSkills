This directory contains API reference documentation for the `TelephonyObserver` class within the Cangjie programming language, designed for the HarmonyOS ecosystem. It provides comprehensive resources for managing subscriptions to telephony communication events, including network state changes, signal status updates, SIM card events, and cellular data connection states. The documentation covers static methods for subscribing (`on`) and unsubscribing (`off`) from these events, detailing parameters, system capabilities, required permissions, and error handling. This collection is essential for Cangjie developers utilizing the TelephonyKit to implement real-time monitoring and responsive behaviors based on telephony hardware and network status in their applications.
