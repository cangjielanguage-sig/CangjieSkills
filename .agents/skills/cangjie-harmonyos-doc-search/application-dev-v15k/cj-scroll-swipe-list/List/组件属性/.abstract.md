This directory contains API reference documentation for configuring the List component within the ArkUI framework using the Cangjie language. It covers a wide range of properties and methods essential for defining layout structures, managing scrolling behaviors, optimizing rendering performance, and handling user interactions. Key topics include multi-column adaptive layouts, edge effects, sticky headers, and scroll alignment. These documents are designed for software developers and UI engineers who require detailed technical specifications to implement advanced list features and customize component behaviors in their applications.
