# 加速Web页面的访问

This directory focuses on techniques to optimize Web page loading performance within the ArkWeb framework using the Cangjie language. It covers essential strategies such as pre-connection, pre-loading, and prefetching POST requests to significantly reduce latency and improve the overall user experience. Key concepts include DNS resolution, socket connections, resource caching, and lifecycle management (onAppear, onPageEnd). It is specifically suitable for developers looking to enhance web application responsiveness and network efficiency through proactive resource management. By leveraging these methods, developers can minimize wait times and ensure smoother transitions during web interactions.

## Detailed Description

The following documents provide specific technical implementations and code examples for accelerating web access.

### 加速Web页面的访问_3more.md 加速Web页面的访问_3more.md

This technical guide explains how to accelerate Web page loading using pre-connection and pre-loading techniques. It covers two main methods: pre-resolving and pre-connecting via the static method prepareForPageLoad, and pre-loading resources via the instance method prefetchPage. Key takeaways include using prepareForPageLoad for DNS resolution and socket connections before page load, and prefetchPage to download resources without executing JavaScript. The document provides Cangjie code examples demonstrating implementation within Web component lifecycle events like onAppear and onPageEnd. It is intended for developers using the ArkWeb framework to optimize web application performance and user experience.

### 预获取post请求.md 预获取post请求.md

This technical guide explains how to prefetch POST requests within a Web component using the ArkWeb framework and Cangjie language. It covers two primary scenarios: prefetching resources during the onAppear lifecycle and clearing them in onPageEnd, and predicting future requests to prefetch in advance. Key takeaways include the implementation of WebviewController.prefetchResource to cache requests with specific keys and validity times, and clearPrefetchedResource for cache management. This document targets developers seeking to optimize web page loading performance by proactively managing network requests.
