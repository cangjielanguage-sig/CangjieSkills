# class_Utf16String

This directory contains API reference documentation for the `Utf16String` class in the Cangjie programming language. The documentation covers class properties, constructors, string manipulation methods (like split, replace, search), operator overloads, and memory management (dispose). It is suitable for Cangjie and HarmonyOS developers who need efficient string handling, JavaScript interaction, and precise control over UTF-16 code units and characters.
