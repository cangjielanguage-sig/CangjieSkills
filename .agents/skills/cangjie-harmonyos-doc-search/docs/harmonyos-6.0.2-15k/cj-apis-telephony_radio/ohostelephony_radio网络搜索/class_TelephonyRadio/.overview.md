# class_TelephonyRadio

This directory contains API reference documentation for the Cangjie TelephonyRadio class within the TelephonyKit framework. It covers static methods for retrieving telephony status, network search information, radio technology details, and signal metrics. Key functionalities include checking radio module status, obtaining ISO country codes, and determining 5G support. The documentation is intended for Cangjie developers building telephony applications on HarmonyOS, requiring knowledge of system capabilities like SystemCapability.Telephony.CoreService and specific permissions such as ohos.permission.GET_NETWORK_INFO.
