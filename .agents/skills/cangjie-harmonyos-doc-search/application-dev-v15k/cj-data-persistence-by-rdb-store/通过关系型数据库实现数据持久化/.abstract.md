This directory provides a comprehensive guide to implementing data persistence using relational databases, specifically leveraging SQLite within the HarmonyOS ArkData framework. It is designed to assist developers in managing complex data with strong relationships by covering core concepts such as predicates, result sets, and system constraints. The content ranges from theoretical introductions to practical implementation steps, including schema creation, CRUD operations, and database lifecycle management. Targeted at developers using the Cangjie language, this resource ensures efficient local storage solutions, performance optimization, and robust data handling in application development. It serves as an essential reference for mastering the RdbStore component.
