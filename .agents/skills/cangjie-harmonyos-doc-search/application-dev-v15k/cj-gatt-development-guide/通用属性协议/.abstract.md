This directory provides a comprehensive guide to the Generic Attribute Protocol (GATT), specifically designed for developers working within the HarmonyOS ecosystem. It serves as a central resource for understanding how Bluetooth Low Energy (BLE) devices transmit data, covering the essential framework of attributes and services. The documentation bridges the gap between theoretical protocol concepts and practical application, utilizing the Cangjie language and ArkTS for implementation. Key topics include server initialization, service discovery, and client-side data exchange. This collection is ideal for software developers and engineers who possess a basic understanding of wireless protocols and are seeking to implement efficient, robust connectivity features in their applications using the ConnectivityKit.
