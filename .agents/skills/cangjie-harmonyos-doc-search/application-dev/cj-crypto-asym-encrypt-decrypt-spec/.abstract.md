This directory provides a centralized collection of technical specifications and API references dedicated to asymmetric key encryption and decryption algorithms within the Cangjie programming language ecosystem. It encompasses essential industry standards, notably GM/T 0009-2012 (SM2) and RSA implementations, offering granular details on encryption modes, padding schemes, and parameter configurations. As the documentation is currently in Beta status, it represents a work-in-progress resource tailored for developers and security engineers. These professionals rely on this guide to implement secure cryptographic operations, manage diverse key types, and correctly handle ciphertext formats in Cangjie applications. The specifications ensure that cryptographic implementations are not only functional but also aligned with established security protocols and best practices.
