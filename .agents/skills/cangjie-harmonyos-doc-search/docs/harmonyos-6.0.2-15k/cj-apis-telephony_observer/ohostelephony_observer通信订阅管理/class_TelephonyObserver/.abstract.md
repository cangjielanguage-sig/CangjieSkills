This directory contains API reference documentation for the `TelephonyObserver` class in the Cangjie programming language. It focuses on the TelephonyKit, providing detailed guides for subscribing to and unsubscribing from various telephony state events. Key topics include monitoring network state changes, SIM card status, signal information, data connection states, and cellular data flow. The documentation includes function signatures, parameter definitions, error codes, and practical code examples. It is suitable for Cangjie developers integrating telephony monitoring features into their applications who need to handle asynchronous callbacks and manage system capabilities.
