# 组件属性

This directory provides API reference documentation for configuring component properties within the Cangjie ArkUI framework. It focuses on scrollable component behaviors, covering aspects such as setting scroll directions, managing edge effects, customizing scrollbars, and defining friction coefficients for inertial scrolling. The documentation includes functions for initial offsets, nested scrolling modes, and visual appearance adjustments. It is intended for developers using the Cangjie language who need to fine-tune user interaction experiences and physics in their application interfaces.
