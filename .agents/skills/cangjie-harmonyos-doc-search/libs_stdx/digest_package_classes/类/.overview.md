# 类

This directory provides API reference documentation for cryptographic classes within the Cangjie programming language. It encompasses implementations of standard hash algorithms, including MD5, the SHA family (SHA-1, SHA-224, SHA-256, SHA-384, SHA-512), and the SM3 algorithm, alongside the HMAC class for Hash-based Message Authentication Code. These resources detail constructors, properties, and methods for data processing, digest generation, and context management. Designed for developers integrating secure cryptographic operations, this documentation requires familiarity with Cangjie syntax and fundamental cryptographic concepts to effectively implement data integrity and authentication features.
