# Rating

This directory provides comprehensive API documentation and practical examples for the Rating component within the ArkUI framework using the Cangjie programming language. It covers the creation, configuration, and event handling of interactive rating interfaces, allowing developers to implement star-based selection systems. Key topics include component constructors, star styling, step size configuration, and change event callbacks. The resources are designed for ArkUI developers using Cangjie who need to build robust, user-friendly rating features in their applications, ranging from static displays to fully interactive input controls.

## Detailed Description

### Rating_4more.md Rating_4more.md
This document serves as API reference documentation for the Rating component in the Cangjie language, designed for selecting ratings within a specified range. It details component creation through two overloaded constructors accepting either Float64 or Int64 for the rating value, alongside a boolean indicator parameter. Key information includes that the rating value is automatically clamped between 0 and the number of stars. The indicator parameter determines interactivity; when true, the component becomes a read-only display with smaller default dimensions (12.0.vp) compared to the interactive state (28.0.vp). The component fully supports universal attributes and events. This guide targets ArkUI developers using Cangjie who need to implement interactive or static rating interfaces.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling events on a rating component within the ArkUI framework using the Cangjie language. It details two overloaded onChange functions that trigger when the rating value changes. The first overload accepts a callback with a Float64 parameter representing the new rating, while the second overload accepts a void callback. Both functions return the component instance for chaining and are available from API version 12. This guide targets developers implementing interactive rating bars in ArkUI applications who need to respond to user input.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring properties of a Rating component within the Cangjie ArkUI framework. It details three primary functions: starStyle for customizing the appearance of unselected, selected, and partially selected stars using image URIs; stars for defining the total number of rating items; and stepSize for setting the rating increment. Key information includes support for asynchronous image loading, default values of 5 stars and 0.5 step size, and specific constraints on image aspect ratios. This technical guide targets developers implementing interactive rating interfaces.
