# 接口介绍

This directory provides a comprehensive technical reference for the AssetStoreKit API, focusing on the management and querying of key assets. It covers the `query` function interface, attribute tags, data structures, and configuration parameters for access control and synchronization. Key topics include security warnings regarding `DATA_LABEL` fields, data type constraints, and pagination logic for query results. Designed for developers implementing secure asset storage and synchronization, these documents offer essential specifications for parameter definitions, data handling, and API response customization to ensure compliance and efficient data management.

## Detailed Description

### 接口介绍_1.md 接口介绍_1.md
This document serves as a technical reference guide for the AssetStoreKit API, specifically detailing the interface for querying key assets. It introduces the `query` function, which accepts an array of `AssetParam` objects to retrieve asset data, and references detailed external documentation. The content outlines the parameter structure for asset attributes and provides a critical security warning regarding `DATA_LABEL` fields. These specific attributes store custom business information without encryption, meaning personal data must not be placed there. This guide is intended for developers implementing asset synchronization, offering essential parameter definitions and data handling instructions to ensure compliance and security.

### 接口介绍_2.md 接口介绍_2.md
This document serves as a technical reference defining attribute tags and data structures for managing critical assets within the AssetStoreKit framework. It details configuration parameters for access control, authentication types, synchronization settings, and persistence options, alongside various data label fields for storing custom business information. Key takeaways include specific data type constraints, byte length limits updated in API12, and distinctions between integrity-protected, normal, and local-only data storage. Intended for developers implementing secure asset storage, this guide provides the necessary parameters to configure asset properties and security behaviors.

### 接口介绍_3.md 接口介绍_3.md
This document serves as a technical reference for parameters used in key asset query operations within the AssetStoreKit API. It details optional input fields including `RETURN_TYPE`, `RETURN_LIMIT`, `RETURN_OFFSET`, `RETURN_ORDERED_BY`, and `REQUIRE_ATTR_ENCRYPTED`. Key information includes data type definitions (UInt32, Bool), value ranges for pagination offsets, and sorting logic based on auxiliary information. The document explains how to control result volume, implement batch queries, and filter for encrypted custom attributes. Intended for software developers integrating asset management capabilities, this guide provides the necessary specifications to customize API responses effectively.
