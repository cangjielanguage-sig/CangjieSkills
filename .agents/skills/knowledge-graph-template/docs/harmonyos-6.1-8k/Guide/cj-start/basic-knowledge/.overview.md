# basic-knowledge

This directory serves as a foundational resource for HarmonyOS application development, specifically focusing on the Stage model and the Cangjie programming language. It covers the complete application package lifecycle, including architectural overviews, package structures, and the specific usage of HAP and HAR packages. The content provides in-depth guidance on configuration files like `app.json5` and `module.json5`, as well as mechanisms for installation, uninstallation, and updates. Additionally, it addresses common development challenges, consistency verification for multi-module apps, and includes a glossary of core terms. This collection is suitable for developers seeking to master packaging specifications, configuration requirements, and system architecture in HarmonyOS.

## Detailed Description

### README_zh/
This directory contains a comprehensive guide to HarmonyOS application package development, focusing on the Beta features of the Stage model. The documentation covers the application package overview, Stage model structure, and the development and usage of HAP and HAR packages. It details mechanisms for application installation, uninstallation, and updates, along with explanations of `app.json5` and `module.json5` configuration files. Additionally, it includes installation update consistency checks, a FAQ, and a glossary. It serves as an important reference for understanding packaging standards and configuration requirements.

### cj-app-configuration-file/
This directory serves as a comprehensive technical repository for HarmonyOS application configuration, specifically focusing on the `app.json5` file. It provides extensive documentation on global application settings, covering critical aspects such as application identity, version information, and other global properties necessary for the application to function correctly within the HarmonyOS ecosystem.

### cj-application-configuration-file-overview-stage/
This directory provides a detailed overview of application configuration files under the Stage model, helping developers understand their structure, purpose, and role in the development lifecycle. The documentation explains how configuration files provide essential information to compilation tools, the operating system, and the app market. It specifically analyzes the core `app.json5` (global config like Bundle name, version) and `module.json5` (module info and runtime permissions) files.

### cj-application-package-glossary/
This directory contains a glossary of core terms regarding HarmonyOS application packages and the Stage model. Content covers key concepts such as HAP, HAR, HSP, Module, ExtensionAbility, and UIAbility. It elaborates on the differences between static and dynamic shared packages, HAP file composition, and the Stage model architecture introduced in API 9. It aims to help developers deeply understand packaging mechanisms and componentization concepts.
