## Detailed Description

### float.md

本文档介绍了仓颉编程语言中的浮点类型，详细说明了Float16、Float32和Float64的定义、精度及适用场景。主要内容包括浮点类型字面量的十进制与十六进制表示法、类型后缀（f16/f32/f64）的使用，以及浮点类型支持的算术、关系和复合赋值操作符。关键信息指出Float64精度最高（约15位），建议优先选用以减少误差；十六进制字面量必须包含指数部分；浮点类型不支持自增自减，但支持与整数类型的转换。这是一份面向仓颉语言开发者的基础参考文档，旨在指导开发者正确处理带小数部分的数值计算。
