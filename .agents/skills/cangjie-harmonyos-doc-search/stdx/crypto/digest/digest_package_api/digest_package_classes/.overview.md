# digest_package_classes

This directory serves as a comprehensive API reference for cryptographic digest classes within the Cangjie programming language. It covers a wide range of hashing and authentication algorithms, including the legacy MD5, the extensive SHA family (SHA-1, SHA-224, SHA-256, SHA-384, SHA-512), the Chinese national standard SM3, and HMAC message authentication codes. The documentation details class properties, constructors, and essential methods for state management and data processing. It is designed for developers working on Cangjie projects who require robust data encryption, integrity verification, and secure authentication mechanisms to protect sensitive information and ensure data trustworthiness in their applications.

## Detailed Description

### 类/ (Classes)

This subdirectory hosts the complete API reference documentation for encryption-related classes available in the Cangjie language. It provides a technical deep dive into the implementation interfaces for a variety of cryptographic algorithms essential for modern security. Specifically, it covers the MD5 hash function, the comprehensive SHA series (including SHA-1, SHA-224, SHA-256, SHA-384, and SHA-512), the SM3 algorithm (widely used in Chinese cryptography standards), and HMAC (Hash-based Message Authentication Code) for verifying data integrity and authenticity.

The documentation meticulously describes the attributes of each class, such as the algorithm name, block size, and digest length, which are crucial for configuring cryptographic operations correctly. Furthermore, it details the constructors required to instantiate these objects and the core methods necessary for processing data streams efficiently. Key methods include `write` for feeding data into the digest, `finish` for finalizing the computation and retrieving the hash result, and `reset` for clearing the internal state to allow the reuse of the object without reallocation.

Additionally, the text places a strong emphasis on state management mechanisms, which are vital for maintaining the correct context during multi-stage hashing operations. It also provides comprehensive guidance on handling `CryptoException`, ensuring that developers can manage potential security failures or invalid input parameters gracefully. This resource is essential for developers aiming to implement secure data encryption, perform rigorous integrity checks, and establish security authentication protocols within their Cangjie applications, offering the necessary tools to build secure and compliant software systems.
