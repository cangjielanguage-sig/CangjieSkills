This directory contains API reference documentation for the `CertExtension` class within the Cangjie DeviceCertificateKit framework. It focuses on the comprehensive management, validation, and retrieval of X.509 certificate extension fields, which are crucial for establishing trust in security systems. Key functionalities include verifying Certificate Authority (CA) status, retrieving serialized data, accessing specific extensions via Object Identifiers (OIDs), and checking for unsupported critical extensions. The documentation provides detailed method signatures, return types, specific error codes (such as memory or crypto failures), and practical Cangjie code examples. It is specifically designed for security developers and system integrators who are implementing robust cryptography operations and security features in Cangjie applications.
