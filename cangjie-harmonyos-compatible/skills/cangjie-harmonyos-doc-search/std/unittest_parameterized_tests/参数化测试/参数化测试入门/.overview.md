# 参数化测试入门

This directory serves as a comprehensive introduction to parameterized testing within the Cangjie unittest framework, specifically designed to enhance test automation and coverage efficiency. It covers the fundamental concepts of data-driven testing using data DSL, ranging from value-driven tests with arrays and ranges to sophisticated random testing strategies for generating edge cases. The content addresses critical challenges such as combinatorial explosion and the management of non-deterministic test results. By exploring configuration options like random seeds, generation steps, and reduction steps, developers can learn to stabilize test cases and significantly improve debugging workflows. This resource is essential for Cangjie developers seeking to maximize code reliability through advanced testing methodologies.

## Detailed Description

Below are the detailed contents of the files included in this directory:

### 参数化测试入门_1.md
This tutorial introduces parameterized testing in the Cangjie unittest framework, explaining how to use data DSL for automated input insertion. It covers value-driven testing using arrays and ranges, demonstrating single and multiple parameters while warning about combinatorial explosion. The document advances to random testing via unittest.random<T>(), which generates edge-case values, and explains failure output including seeds and reduction steps. Key takeaways include the recommendation to mix random and manual tests. This guide is intended for Cangjie developers looking to enhance test coverage and efficiency.

Keywords: Cangjie, unittest, parameterized testing, value-driven testing, random testing, data DSL, combinatorial testing, test automation.

### 参数化测试入门_2.md
This tutorial explains how to make random testing reproducible by utilizing random seeds and configuration options in the Cangjie testing framework. It addresses the challenge of non-deterministic test results by demonstrating how to use the `randomSeed` output to configure tests for consistent execution. Key topics include analyzing failure reports, understanding generation and reduction steps, and controlling test depth using `generationSteps` and `reductionSteps`. The document highlights that while random testing is powerful, reproducibility is essential for debugging and sharing results. It is intended for developers using the Cangjie language who need to stabilize and manage random test cases effectively.
