This directory provides API reference documentation for the HarmonyOS Critical Asset Storage Service (ohos.asset_store) specifically for the Cangjie language. It covers the secure storage, retrieval, update, and deletion of sensitive data such as passwords and tokens. Key topics include the AssetStoreKit, authentication workflows, data structures, and comprehensive error handling. This documentation is suitable for Cangjie developers looking to implement secure data management within the SystemCapability.Security.Asset framework.
