# cj-power-shell

This directory provides the essential documentation for the `cj-power-shell` tool, a robust utility developed to assist engineers in debugging and managing device power states efficiently. The guide focuses on the practical application of command-line instructions to control screen activity, switch between distinct power modes—such as normal, power-saving, and performance—and manage auto-sleep timeout settings. It is an indispensable resource for developers operating within the hdc shell environment who require precise control over power state transitions and mode configurations. The documentation includes detailed syntax, parameter definitions, and usage examples, enabling users to simulate various power scenarios effectively. Whether you are optimizing battery life or testing performance behaviors, this guide offers the necessary technical reference to ensure accurate system debugging and reliable power management during the software development lifecycle.

## Detailed Description

### cj-power-shell.md cj-power-shell.md
This document serves as a reference guide for the power-shell tool, designed to help developers debug device power states. It details commands for managing screen activity and power modes, including setmode for switching between normal, power-saving, and performance modes, wakeup and suspend for screen control, and timeout for managing auto-sleep settings. The guide provides syntax, parameters, and usage examples for each command. Intended for developers, it requires prior access to the hdc shell environment. Key concepts include power state transitions, mode configuration, and system debugging.
