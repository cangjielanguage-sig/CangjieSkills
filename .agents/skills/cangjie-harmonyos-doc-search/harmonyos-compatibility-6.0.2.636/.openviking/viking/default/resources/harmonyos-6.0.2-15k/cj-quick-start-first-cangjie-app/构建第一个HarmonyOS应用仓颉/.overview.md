# 构建第一个HarmonyOS应用仓颉

This directory provides a comprehensive guide for developers starting their journey with HarmonyOS application development using the Cangjie (仓颉) programming language. It covers the essential workflow from project creation and environment setup to building user interfaces and implementing page navigation. Key topics include DevEco Studio configuration, project structure analysis, UI component implementation (Row, Column, Button), and state management. This resource is suitable for beginners and developers transitioning to Cangjie who need practical, step-by-step instructions to build and run their first functional HarmonyOS app on real devices or emulators.

## Detailed Description

### 使用真机或模拟器运行应用.md 使用真机或模拟器运行应用.md
This tutorial guides developers on running HarmonyOS applications written in the Cangjie language using either a local real device or the DevEco Studio emulator. The document details the steps for connecting a device, configuring automatic signing via a Huawei account, and creating a virtual device. A key technical takeaway is the requirement to modify the build-profile.json5 file to include x86_64 in the abiFilters when running on x86 emulators, as the default compilation architecture is arm64-v8a. This guide is intended for developers using DevEco Studio to deploy and test their Cangjie projects.

### 创建仓颉工程_2more.md 创建仓颉工程_2more.md
This tutorial guides developers through creating a Cangjie project in DevEco Studio and explains the resulting directory structure. It covers the step-by-step process of selecting the "Empty Ability" template and configuring basic project settings. The document provides a detailed breakdown of the project hierarchy, highlighting key components such as the source code location in entry/src/main/cangjie, the package management file cjpm.toml, and configuration files like module.json5 and app.json5. It also clarifies the roles of build scripts and dependency folders. Targeted at HarmonyOS developers using the Cangjie language, this guide serves as a foundational reference for setting up the development environment and understanding project organization.

### 构建第一个页面.md 构建第一个页面.md
This tutorial guides developers through constructing the initial user interface page using the Cangjie programming language within a HarmonyOS development environment. It covers the project file structure, specifically the index.cj file, and demonstrates the use of basic UI components like Row, Column, Text, and Button. The document provides code examples showing how to implement state management with @State, handle click events, and layout components to create a responsive interface. It is intended for developers beginning application development with Cangjie, requiring basic knowledge of the project structure and UI layout concepts. Keywords: Cangjie, HarmonyOS, UI development, Row, Column, Button, state management, index.cj.

### 构建第二个页面_2more.md 构建第二个页面_2more.md
This tutorial guides developers through creating a secondary page and implementing bidirectional navigation in a Cangjie-based application. The document covers creating a new Cangjie file, adding UI components like Text and Button, and utilizing the Router module for page transitions. Key takeaways include using Router.push(url: "Second") to navigate forward and Router.back(url: "EntryView") to return, emphasizing the import of the router module and event binding in onClick handlers. It targets developers familiar with Cangjie syntax and HarmonyOS project structure who need to implement multi-page flows.
