# 结构体

This directory serves as a comprehensive repository for core data structures within the Cangjie standard library, specifically focusing on high-precision numeric types. It provides detailed documentation for structs that handle arbitrary-precision arithmetic, effectively addressing the limitations of standard primitive types in complex scenarios. Key topics include large integer operations, decimal financial calculations, bitwise manipulation, and type conversions. This resource is essential for Cangjie developers working on applications requiring exact numerical precision, such as cryptographic systems, financial software, or complex mathematical modeling, ensuring robust and accurate data handling without overflow or rounding errors. By utilizing these structures, developers can implement reliable numeric logic tailored to specific domain requirements.

## Detailed Description

The following subsections provide in-depth API documentation for the specific structs available in this directory. Each section covers the struct's initialization methods, supported operators, and advanced functionalities to assist developers in integrating these types into their projects.

### [1] struct_BigInt/

This directory contains comprehensive API documentation for the `BigInt` struct in the Cangjie standard library, designed for arbitrary-precision signed integer arithmetic. It covers a wide range of functionalities including initialization from various data types, arithmetic and bitwise operators, type conversions, and advanced mathematical operations like modular exponentiation and prime testing. The documentation also details interface implementations for parsing and formatting numbers in different bases. This resource is essential for Cangjie developers who need to handle large numbers, perform high-precision calculations, or manage low-level bit manipulation and data conversion in their applications.

### [2] struct_Decimal/

This directory contains API documentation for the `Decimal` struct in the Cangjie programming language's standard math library. It focuses on arbitrary-precision signed decimal numbers, essential for high-precision financial and mathematical calculations where standard floating-point types are insufficient. The documentation covers initialization from various types, arithmetic and comparison operators, precision manipulation, rounding, and type conversions. It is suitable for Cangjie developers who need to implement robust numeric logic, handle specific rounding modes, or manage overflow strategies in their applications.
