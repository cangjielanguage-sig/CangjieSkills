# 开发步骤

This directory serves as a comprehensive resource for developers utilizing the Cangjie programming language, specifically focusing on the implementation of lightweight data storage mechanisms using the Preferences API. It details the complete development workflow, starting from importing necessary modules and obtaining Preferences instances within a UIAbility context to performing fundamental CRUD tasks such as writing, reading, and deleting key-value pairs. Furthermore, the documentation explores critical concepts for maintaining data integrity, including data persistence via the flush method, subscribing to data changes using custom callbacks, and managing the full lifecycle of preference files. These guides are meticulously designed for application developers working with the ArkData and AbilityKit frameworks who require efficient strategies for simple data persistence and effective storage resource management.

## Detailed Description

### 开发步骤_1.md
This document provides a step-by-step tutorial for implementing lightweight data storage using the Preferences API in the Cangjie programming language. It covers essential operations including importing necessary modules, obtaining a Preferences instance within a UIAbility context, and performing CRUD tasks such as writing, reading, and deleting key-value pairs. Key concepts include data persistence via the flush method, subscribing to data changes using custom callbacks, and managing the lifecycle of preference files through deletion. The guide is intended for application developers working with the ArkData and AbilityKit frameworks who need to manage simple data persistence efficiently.

### 开发步骤_2.md

This technical reference is designed for Cangjie developers who need to manage application data persistence and clean up storage resources effectively.
