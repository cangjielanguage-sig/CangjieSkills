This directory provides comprehensive API reference documentation for the `PhotoKeys` enum within the Cangjie programming language. It is designed to assist developers in accessing and retrieving metadata for photo and video files. The content covers a wide range of file attributes, including physical dimensions, file sizes, timestamps, and display names, while also detailing system capabilities and version-specific requirements. This documentation is essential for developers building media applications or system-level file management tools that require precise querying of file attributes using data predicates and understanding of operator overloads.
