This directory serves as the central repository for API reference documentation regarding the `cj-apis-preferences` module, a critical component of the HarmonyOS ArkData framework specifically adapted for the Cangjie programming language. It provides developers with the necessary resources to implement lightweight Key-Value (KV) data persistence mechanisms, which are essential for efficiently managing application settings and storing small datasets locally. The documentation encompasses a wide range of technical topics, including detailed module imports, complex configuration structures, a comprehensive list of supported data types, and the core `Preferences` class used for data manipulation. This resource is primarily designed for HarmonyOS developers who are working with the Cangjie syntax and require robust, efficient solutions for local data storage, real-time data change subscriptions, and the management of persistent application contexts. By utilizing these APIs, developers can ensure a seamless user experience through reliable state management.
