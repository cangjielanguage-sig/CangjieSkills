# class_CommonEventSubscriber

This directory contains API reference documentation for the `CommonEventSubscriber` class in the Cangjie programming language, specifically designed for the HarmonyOS BasicServicesKit. It covers the management of ordered common events, including data manipulation, event lifecycle control, and subscriber configuration. Key functionalities include retrieving and setting event codes and data, aborting or finishing events, and checking event properties like stickiness. This documentation is suitable for application developers working with the Common Event Service to implement event-driven communication and control event propagation within their HarmonyOS applications.
