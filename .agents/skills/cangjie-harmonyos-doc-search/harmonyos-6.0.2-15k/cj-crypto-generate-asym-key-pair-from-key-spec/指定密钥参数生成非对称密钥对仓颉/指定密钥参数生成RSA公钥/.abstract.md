This directory serves as a technical resource for generating RSA public keys using specified parameters within the CryptoArchitectureKit framework. It thoroughly covers the implementation details required to construct key specifications such as `RSACommonParamsSpec` and `RSAPubKeySpec`, initialize asymmetric key generators, and handle BigInt inputs in big-endian mode. The documentation includes practical Cangjie code examples demonstrating how to parse hexadecimal strings for modulus and exponent, alongside validation logic to ensure key consistency. This content is specifically tailored for software developers and security engineers who need to instantiate RSA public keys from existing parameters for cryptographic operations, offering a robust alternative to generating new key pairs.
