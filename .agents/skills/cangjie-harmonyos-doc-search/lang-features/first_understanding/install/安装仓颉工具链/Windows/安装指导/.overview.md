# 安装指导

本目录提供了在 Windows 操作系统上部署仓颉开发环境的完整指导文档。内容涵盖了 SDK 的获取（exe 及 zip 包）、环境变量的详细配置（包括 CANGJIE_HOME 和 Path），到安装完成后的系统验证与生效确认的全过程。核心关键词包括仓颉 SDK、Windows 安装、环境变量配置及工具链验证。该文档面向需要在 Windows 平台进行仓颉语言开发的开发者，旨在帮助用户快速搭建可用的开发环境。

## 快速导航

- **你想了解如何安装 SDK？**
    - 查看 exe/zip 安装方式及环境变量配置 → 安装指导_1.md
- **你想确认安装是否成功？**
    - 查看安装后的验证步骤及系统设置 → 安装指导_2.md

## 详细描述

### 安装指导_1.md
本文档旨在指导开发者在 Windows 平台上安装仓颉 SDK。涵盖了 exe 和 zip 两种安装方式，以及环境变量的临时配置与永久生效设置。介绍了针对 CMD、PowerShell 和 Bash 等不同环境的安装脚本，详细说明了配置 CANGJIE_HOME 和 Path 系统变量的步骤，以确保工具链全局可用。适用于需要在 Windows 系统下搭建仓颉开发环境的开发者。

### 安装指导_2.md
本文档旨在指导用户完成仓颉编译工具链在Windows系统上的安装配置最后步骤。主要内容包括确认设置操作、系统重启的必要性说明以及配置完成后的环境验证。关键要点是设置生效可能需要重启命令行窗口或系统，成功后用户可在CMD或PowerShell中直接使用仓颉编译工具。该文档属于安装教程的一部分，面向需要在Windows环境下配置仓颉开发环境的开发者。
