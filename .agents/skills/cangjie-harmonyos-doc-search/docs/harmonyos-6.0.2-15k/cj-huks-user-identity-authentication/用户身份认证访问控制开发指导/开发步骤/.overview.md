# 开发步骤

This directory contains a technical tutorial series focused on implementing fingerprint-based access control for cryptographic keys using the Universal Keystore Kit (HUKS) in the Cangjie language. It covers the complete workflow of generating secure keys, initializing cryptographic sessions, and performing SM4 encryption operations integrated with biometric authentication via UserIAM. Key topics include key property configuration, session management, authentication token retrieval, and secure data encryption. This guide is suitable for application developers working on HarmonyOS applications who need to integrate biometric security features to protect sensitive data.

## Detailed Description

### 开发步骤_1.md
This technical tutorial guides developers through implementing fingerprint-based access control for cryptographic keys using the Universal Keystore Kit in the Cangjie language. The document covers two primary development steps: generating a key with specific security attributes and initializing a cryptographic session that requires fingerprint authentication. Key information includes code examples demonstrating how to configure key properties such as HuksUserAuthType and HuksAuthAccessType for an SM4 key, and subsequently obtaining an authentication token via UserAuthenticationKit. This guide targets application developers working on secure data encryption who need to integrate biometric authentication into their Cangjie-based applications.

### 开发步骤_2.md
This document provides a code tutorial for implementing secure data operations using the HarmonyOS Universal Keystore (HUKS) integrated with UserIAM biometric authentication. Key sections include session initialization to retrieve a challenge, triggering fingerprint authentication to obtain an access token, and performing SM4 encryption operations. The code demonstrates the workflow of passing the authentication token into updateSession and finishSession functions to authorize cryptographic actions. Intended for developers using the Cangjie language, this guide explains how to enforce access control during sensitive data processing.

### 开发步骤_3.md
This document provides code examples for finalizing a HUKS cryptographic session and testing SM4 encryption with biometric authentication. It covers the `publicFinishFunc` implementation for session finalization and the `testSm4Cipher` function demonstrating the complete encryption workflow including update and finish operations. Key information includes the use of `finishSession`, error handling via try-catch blocks, and the necessity of passing an authentication token (`fingerAuthToken`) during the update and finish phases. It also includes a basic validation check to ensure encryption success. This is a technical tutorial intended for developers implementing secure encryption in HarmonyOS applications using the HUKS framework, requiring knowledge of cryptographic concepts.
