# 接口

This directory contains API reference documentation for core collection interfaces in the Cangjie programming language. It covers a wide range of data structures including lists, sets, maps, queues, stacks, and deques, distinguishing between mutable and read-only variants. Key concepts include generic types, element comparison, ordered collections, and safe handling of empty states using Option types. This documentation is suitable for Cangjie developers, library implementers, and software engineers seeking to understand or utilize standard collection interfaces for efficient data manipulation and storage in their applications.

### interface_QueueT_2more.md interface_QueueT_2more.md
This document serves as API reference documentation for two core data structure interfaces in the Cangjie language: Queue and ReadOnlyList.
