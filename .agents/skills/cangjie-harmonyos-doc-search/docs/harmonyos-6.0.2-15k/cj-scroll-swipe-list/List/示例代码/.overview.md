# 示例代码

This directory serves as a comprehensive resource for Cangjie developers, offering practical code examples focused on the HarmonyOS UIKit List component. It addresses critical aspects of UI development, including the implementation of scroll event callbacks using `onScrollIndex` to track visible items, dynamic configuration of child element alignment via `ListItemAlign`, and the setup of edit modes for item deletion. Additionally, it covers layout constraints for horizontal scrolling and state management techniques. By exploring these examples, developers can learn to create interactive, responsive, and user-friendly list interfaces. This collection is ideal for application developers looking to deepen their understanding of list manipulation, event handling, and layout control within the Cangjie framework.

## Detailed Description

### 示例1_添加滚动事件_2more.md
This technical tutorial provides Cangjie code examples for implementing specific features within the HarmonyOS UIKit List component. The document is divided into two main sections: adding scroll event callbacks and configuring child element alignment. The first example demonstrates using the onScrollIndex method to track the first and last visible items during vertical scrolling. The second example illustrates how to manipulate ListItemAlign to adjust item positioning across multiple lanes. Key takeaways include understanding event handling and layout properties for list views. This guide targets application developers seeking to enhance list interactivity and layout control.
