# cj-certManager-guidelines

This directory serves as an essential technical resource for developers operating within the HarmonyOS ecosystem, specifically targeting the secure management of application certificates and private credentials. It offers in-depth guidance on utilizing core frameworks such as DeviceCertificateKit and the Universal Keystore (HUKS) to establish a secure foundation for applications. The content thoroughly addresses the complete lifecycle of credentials, encompassing initial installation, secure storage, complex cryptographic operations—including data signing and verification—and the secure removal of sensitive materials. Furthermore, it highlights critical implementation details regarding system permission configuration, the adoption of the Cangjie programming language, and the specific interfaces introduced in API version 12 and beyond. This documentation is ideally suited for HarmonyOS application developers, particularly those utilizing the Stage model, who are seeking to integrate advanced security mechanisms like digital signatures and comprehensive credential management into their software solutions.

## Detailed Description

Below is a detailed breakdown of the subdirectory included in this package, providing specific insights into the development guidelines and technical specifications covered.

### 证书管理开发指导/
This directory provides comprehensive development guidance for managing application certificates and private credentials within the HarmonyOS ecosystem. It focuses on utilizing the DeviceCertificateKit and Universal Keystore (HUKS) to handle the full lifecycle of credentials, including installation, cryptographic operations (signing/verification), and removal. Key topics include permission configuration, Cangjie programming language implementation, and API version 12+ interfaces. Suitable for HarmonyOS application developers, particularly those using the Stage model and seeking to implement secure digital signatures and credential management in their apps.
