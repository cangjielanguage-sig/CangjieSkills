# 开发步骤

This directory provides a comprehensive technical guide for developers focused on implementing image decoding functionality using the Cangjie language and the ImageKit framework. It details the complete development workflow, beginning with the essential step of importing the Image module and covering various methods for obtaining image data. The content explains how to retrieve sandbox paths, acquire file descriptors using CoreFileKit, and fetch resource files as byte arrays or descriptors via LocalizationKit. Furthermore, it guides users through creating ImageSource instances, decoding them into PixelMap objects, and configuring options for standard and HDR formats. This documentation is specifically designed for application developers who possess prerequisite knowledge of Cangjie syntax and HarmonyOS context management.

## Detailed Description

### 开发步骤_1.md
This document serves as a step-by-step tutorial for developers implementing image decoding functionality using the Cangjie language and ImageKit. The guide outlines the core development workflow, beginning with importing the Image module. It details four distinct methods for obtaining image data: retrieving sandbox paths, acquiring file descriptors via CoreFileKit, and fetching resource files as byte arrays or descriptors using LocalizationKit. The final step demonstrates creating an ImageSource instance from these inputs. Key takeaways include the specific code snippets for context handling and file access. This technical guide targets application developers with prerequisite knowledge of Cangjie syntax and application context management.

### 开发步骤_2.md
This technical tutorial guides developers through image decoding and resource management using the Cangjie language and ImageKit. It details methods to create ImageSource objects from file descriptors, buffers, or resource files, and explains how to decode these sources into PixelMap objects. Key sections cover configuring DecodingOptions for standard formats like RGBA_8888 and handling HDR content using dynamic range settings. The document concludes with instructions for manually releasing PixelMap and ImageSource resources. Intended for application developers, this guide requires familiarity with Cangjie syntax and HarmonyOS context management.
