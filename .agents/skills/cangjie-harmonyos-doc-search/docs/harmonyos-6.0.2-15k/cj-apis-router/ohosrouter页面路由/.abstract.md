This directory provides API reference documentation for the `ohos.router` module and associated classes used in the ArkUI framework with the Cangjie language. It focuses on managing page navigation, URL-based access, and page state tracking. Key concepts include page jumping, stack management, and routing modes like Single and Standard. This documentation is essential for HarmonyOS developers building applications in Cangjie who need to implement complex navigation logic, handle page lifecycles, and manage parameters effectively.
