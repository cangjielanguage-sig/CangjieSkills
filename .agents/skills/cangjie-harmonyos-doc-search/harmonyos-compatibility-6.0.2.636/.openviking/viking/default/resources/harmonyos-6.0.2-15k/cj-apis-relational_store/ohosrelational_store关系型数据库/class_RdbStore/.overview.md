# class_RdbStore

This directory contains API reference documentation for the `RdbStore` class in the Cangjie programming language, part of the ArkData kit. It covers the management of relational databases, including CRUD operations, transaction handling, backup and restore, and distributed data synchronization. Key topics include SQL execution, event listening, and cloud sync capabilities. This documentation is intended for developers building HarmonyOS applications who need to implement robust data persistence, cross-device synchronization, and efficient database management using Cangjie syntax and SQLite-based storage.
