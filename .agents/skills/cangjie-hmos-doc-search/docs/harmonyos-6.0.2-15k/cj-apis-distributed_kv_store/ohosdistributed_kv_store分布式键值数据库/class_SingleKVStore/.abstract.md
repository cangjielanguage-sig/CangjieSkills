This directory contains API reference documentation for the `SingleKVStore` class within the Cangjie language's ArkData framework. It covers the management of distributed key-value store databases, including data persistence, synchronization, transaction management, and event subscriptions. Key functionalities include CRUD operations (put, get, delete), backup and restore, query capabilities, and sync configuration. This documentation is suitable for developers building applications requiring local or distributed data management, providing detailed method signatures, parameters, error codes, and practical Cangjie code examples.
