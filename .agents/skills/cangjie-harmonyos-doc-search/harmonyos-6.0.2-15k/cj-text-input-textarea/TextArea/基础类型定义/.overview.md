# 基础类型定义

This directory provides essential API references and type definitions for text handling components within the ArkUI framework, specifically designed for the Cangjie language. It encompasses configuration classes that define text selection behaviors and input field constraints, as well as controller classes that offer programmatic manipulation of TextArea components. Key concepts include menu policies for selection, input validation types like EMAIL and NUMBER, and methods for cursor management and text retrieval. This documentation is intended for ArkUI developers who require granular control over text input interfaces, enabling the implementation of robust user interactions and precise input validation in their applications.

## Detailed Description

### class_SelectionOptions_2more.md
This API reference document defines configuration classes for text handling within the ArkUI framework using the Cangjie language. It details the SelectionOptions class, which configures text selection behavior via a menu policy, and the TextAreaType enumeration, which specifies input field constraints. Key information includes the constructor for SelectionOptions accepting a MenuPolicy parameter and specific TextAreaType values like EMAIL, NUMBER, and PHONE_NUMBER, each defining distinct allowed character sets and validation rules. Intended for developers building user interfaces, this documentation assists in implementing precise text selection menus and input type validations.

### class_TextAreaController.md
This document serves as an API reference for the TextAreaController class in the Cangjie language, designed to manage and manipulate the TextArea component within the ArkUI framework. It details the class constructor and various functional methods categorized by cursor control, text selection, and content retrieval. Key functionalities include setting the caret position, retrieving cursor offsets and text content dimensions, managing text selection with highlighting, and stopping the editing state. Several methods require version 19 or later. The target audience is ArkUI developers using Cangjie who need programmatic control over text input behaviors and states.
