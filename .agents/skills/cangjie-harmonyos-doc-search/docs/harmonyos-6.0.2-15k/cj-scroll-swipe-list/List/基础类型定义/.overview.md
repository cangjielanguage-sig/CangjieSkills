# 基础类型定义

This directory contains fundamental type definitions and classes essential for managing ArkUI List components in the Cangjie language. It covers data structures for tracking visible content, controlling scroll alignment behaviors, and handling scrolling logic programmatically. Key concepts include `VisibleListContentInfo`, `ScrollSnapAlign`, and `ListScroller`. These resources are designed for ArkUI developers who need to implement precise list rendering, interaction logic, and scroll effects using Cangjie syntax. By utilizing these definitions, developers can effectively manage complex list layouts, handle user interactions, and ensure smooth navigation within grouped list structures.

### class_VisibleListContentInfo.md class_VisibleListContentInfo.md
This API reference document defines the Cangjie class `VisibleListContentInfo`, which represents detailed information about visible sub-components within a List component. The documentation covers the class properties, including the index of the item, its specific area within a `ListItemGroup`, and its index inside that group. It also details the constructor, which accepts named parameters with default values for group-related fields. Key takeaways include understanding how to track item visibility and positioning within complex list structures. Intended for ArkUI developers using Cangjie, this document helps in managing list rendering and interaction logic.

### enum_ScrollSnapAlign.md enum_ScrollSnapAlign.md
This document provides API reference details for the `ScrollSnapAlign` enum, which defines the alignment behavior of list items upon the completion of a scroll action. The content enumerates four specific alignment modes: NONE (default), START, CENTER, and END, each accompanied by functional descriptions and system capability metadata. Key takeaways include the constraint that accurate alignment is limited to scenarios with equal-height items, and specific behavioral notes for START and END modes where full item visibility may override strict alignment at list boundaries. This reference material targets ArkUI developers using the Cangjie language who need to implement precise scroll snapping effects in list components.
