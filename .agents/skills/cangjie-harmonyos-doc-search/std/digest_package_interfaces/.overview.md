# digest_package_interfaces

This directory contains the API reference documentation for the Digest interface in the Cangjie programming language. It defines the standard contract for implementing digest algorithms, which are essential for cryptographic hash functions. The documentation details the interface structure, covering properties like `algorithm`, `blockSize`, and `size`, alongside methods such as `write`, `finish`, and `reset`. It highlights requirements for input and return types, the mechanism for updating the digest context via `write`, and the finalization process using `finish` which returns the hash value and prevents further calculation until `reset` is called. This resource is targeted at developers implementing or using cryptographic hash functions, requiring familiarity with Cangjie syntax and basic cryptographic concepts. It is a critical resource for maintaining consistency in cryptographic operations.
