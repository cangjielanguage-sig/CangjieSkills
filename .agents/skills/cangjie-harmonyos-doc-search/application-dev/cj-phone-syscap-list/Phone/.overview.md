# Phone

This directory provides comprehensive documentation on system capabilities (SysCap) and configuration profiles for Phone devices. It includes reference guides for developers to understand supported features, minimum system capability sets, and API usage protocols. The content spans diverse domains such as ArkUI, Multimedia, Telephony, Security, and Graphics, offering detailed manifests for specific device profiles like Phone_5. These documents are essential for application developers ensuring compatibility and system engineers configuring builds or verifying hardware and software support.

## Detailed Description

### Phone_1.md
This document serves as a reference guide for developers to understand the system capabilities (SysCap) supported by Phone devices. It defines SysCap as independent operating system features and directs developers to the SysCap Usage Guide for detailed instructions. The main content highlights the minimum system capability set for the current Phone version, which can be queried via the SDK's default.json file. A key takeaway is that developers can directly call APIs corresponding to these capabilities without performing runtime canIUse() isolation checks. This information is intended for application developers building Phone apps to ensure compatibility and improve development efficiency.

### Phone_2.md
This document serves as a system capability reference list defining the supported features and modules for a specific phone device profile. It covers diverse domains including ArkUI, Bundle Management, Graphics (WebGL, GLES), Window Management, Notifications, Communication (WiFi, Bluetooth, Net), Location, Multimodal Input, Power Management, and Multimedia. The file enumerates specific capabilities like IPC, NetStack, and Media Codecs, acting as a manifest for hardware and software support. It is intended for system developers or build engineers configuring device profiles or checking feature availability.

### Phone_3.md
This document serves as a configuration manifest defining the system capabilities and subsystems supported by a specific phone device profile. It enumerates capabilities across major domains including Multimedia (Media, Audio, Camera), Telephony (Core, Call, SMS), Security (Huks, DeviceAuth), Globalization (I18n), Resource Scheduling, and System Diagnostics (HiviewDFX). The content is organized hierarchically to map specific functional modules to broader system categories, indicating the feature set available for developers or the system configuration required for this device type. This reference document targets system engineers, build configuration managers, or developers verifying feature availability within the operating system environment.

### Phone_4.md
This document functions as a reference list enumerating system capabilities available for a specific device profile, likely a phone system. It categorizes capabilities into domains such as Security, Account, User IAM, File Management, Distributed Data, Ability Runtime, and Application services. The content provides specific identifiers like SystemCapability.Ability.AbilityRuntime.Core, which are essential for defining system features, dependencies, and access permissions. Intended for system developers and engineers, this list aids in configuring system profiles and verifying feature support during application development.

### Phone_5.md
This document serves as a configuration reference listing the specific system capabilities supported by the Phone_5 device profile. The content encompasses a wide range of functional domains including security and cryptography, bundle management, multimedia processing (audio, video, image), advanced graphics (2D, 3D, Vulkan), and ability runtime features. Key takeaways include the inclusion of advanced cryptographic frameworks, native graphics interfaces, and multimedia enhancements like spatial audio and screen capture, indicating a high-feature device configuration. This reference is intended for system developers, application engineers, and device integrators who need to verify API availability and hardware support for the Phone_5 profile.
