This directory provides comprehensive documentation for the `RangeExpr` class within the Cangjie Abstract Syntax Tree (AST) package. It focuses on the structural definition and manipulation of range expressions, supporting both half-open and closed range operators. The content covers essential API components, including class constructors, mutable properties for accessing expression boundaries, and utility functions for token conversion and tree traversal. Designed for compiler developers and language tool implementers, this resource offers the necessary specifications to programmatically construct, analyze, and interact with range expression nodes in the Cangjie language ecosystem.
