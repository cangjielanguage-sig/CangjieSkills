# 使用WebRTC进行Web视频会议

This directory provides comprehensive technical guides for implementing WebRTC-based video conferencing capabilities within HarmonyOS applications. It focuses on the critical integration of native system permissions with web-based media capture APIs, specifically bridging the gap between HarmonyOS native code and W3C standards like `navigator.mediaDevices.getUserMedia`. The tutorials cover essential configurations for camera and microphone access, permission request handling, and the setup of Web components to facilitate real-time communication. The guides ensure developers can effectively manage the complex interaction between the operating system's security model and the web environment's media requirements. It is suitable for HarmonyOS developers working with either the Cangjie language or ArkTS who need to embed browser-based video features into their native applications, ensuring a seamless user experience for media streaming and conferencing.

## Detailed Description

### 使用WebRTC进行Web视频会议_1.md 使用WebRTC进行Web视频会议_1.md
This guide explains how to enable WebRTC video conferencing capabilities in HarmonyOS applications by integrating camera and microphone access. It covers declaring permissions in module.json5 and string.json, and implementing application-side logic in Cangjie to manage context and permission requests. Key takeaways include the necessity of configuring ohos.permission.CAMERA and ohos.permission.MICROPHONE, and using the onPermissionRequest interface to handle W3C standard API calls like navigator.mediaDevices.getUserMedia. This tutorial is intended for HarmonyOS developers using the Cangjie language and ArkUI framework to build web-integrated applications requiring media device access.

### 使用WebRTC进行Web视频会议_2.md 使用WebRTC进行Web视频会议_2.md
This technical tutorial demonstrates how to implement WebRTC video conferencing functionality within a HarmonyOS application by integrating native permission handling with web-based media capture. The content covers two primary code sections: an ArkTS backend for managing system permissions and an HTML frontend for accessing media streams. Key implementation details include using AbilityAccessCtrl to request camera and microphone permissions, configuring a Web component with an onPermissionRequest dialog, and utilizing navigator.mediaDevices.getUserMedia in JavaScript to capture and display video and audio. It targets HarmonyOS developers with knowledge of ArkTS and web technologies who need to embed browser-based video features into native apps.
