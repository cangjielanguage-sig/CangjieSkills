# class_TelephonyCall

This directory contains API reference documentation for the `TelephonyCall` class in the Cangjie programming language, designed for managing telephony operations. It covers core functionalities including formatting phone numbers to local or E.164 standards, retrieving device call states, and launching the system dialer. The documentation details static methods for checking active calls, verifying voice capabilities, and validating emergency numbers. Intended for application developers using the TelephonyKit, these resources provide essential parameters, return types, system capabilities, and error handling codes to implement comprehensive call management features.
