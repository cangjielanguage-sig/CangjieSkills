# cj-web-set-dark-mode

本目录提供了在仓颉ArkUI框架下为Web组件配置深色模式的完整技术指南。内容涵盖了从基础的深色模式开关设置到高级的强制深色模式实现，详细讲解了 `darkMode()` 和 `forceDarkAccess()` 两个核心接口的使用方法。文档不仅包含Cangjie语言的代码实现示例，还涉及HTML端的媒体查询配置，帮助开发者实现前后端联动的深色模式适配。核心关键词包括仓颉、ArkUI、Web组件、深色模式、forceDarkAccess。该资料特别适合正在使用仓颉语言开发Web应用并希望优化用户界面显示效果的开发者阅读。

## Detailed Description

### cj-web-set-dark-mode.md
本文档介绍了如何在仓颉ArkUI框架中为Web组件配置深色模式。主要内容包括使用darkMode()接口设置关闭、开启或跟随系统的深色模式，以及通过forceDarkAccess()接口实现强制深色模式，并提供了相应的Cangjie代码示例和HTML媒体查询配置。关键点在于WebDarkMode.Auto模式跟随系统，WebDarkMode.On模式跟随前端页面，而强制深色模式需配合WebDarkMode.On使用，且颜色转换可能不完全符合预期。该文档面向使用仓颉语言进行Web应用开发的开发者，属于开发指南类文档。
