This directory provides comprehensive API reference documentation for the `ohos.background_task_mgr` module within the Cangjie language environment, specifically tailored for HarmonyOS application development. It focuses on mechanisms to manage background tasks effectively, preventing the system from suspending applications during critical operations. Key topics include defining specific long-running task modes (such as data transfer or audio playback), requesting temporary suspension delays, and managing the lifecycle of these tasks. The documentation includes detailed function signatures, parameters, return values, and error handling codes. This resource is essential for Cangjie developers aiming to optimize background execution and handle system resource constraints in their HarmonyOS apps.
