# 富文本RichEditor

本目录专注于ArkUI的RichEditor组件，为使用仓颉语言的开发者提供全面的开发指南。内容涵盖了创建支持图文混排和交互式编辑的富文本编辑器，包括自定义选择菜单、通过编程方式添加文本与图片内容，以及实现各类事件回调（如输入法交互、粘贴拦截等）。该文档适用于需要构建复杂文本输入、展示功能及自定义交互界面的ArkUI应用开发人员。

## 详细说明

### 富文本RichEditor_3more_3b7ec41a.md 富文本RichEditor_3more_3b7ec41a.md
