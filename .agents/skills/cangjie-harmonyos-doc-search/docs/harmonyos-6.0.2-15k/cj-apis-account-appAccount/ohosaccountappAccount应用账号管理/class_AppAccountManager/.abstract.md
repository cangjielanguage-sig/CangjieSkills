This directory contains API reference documentation for the `AppAccountManager` class in the Cangjie programming language, specifically designed for the HarmonyOS BasicServicesKit. It covers comprehensive functionalities for managing application accounts, including creation, deletion, authentication token handling, credential management, and data synchronization. Developers will find detailed guides on access control, event subscription, and authenticator interactions. The documentation includes function signatures, parameter definitions, error codes, and practical code examples. It is suitable for software developers integrating secure account management and authentication features into their HarmonyOS applications using Cangjie syntax.
