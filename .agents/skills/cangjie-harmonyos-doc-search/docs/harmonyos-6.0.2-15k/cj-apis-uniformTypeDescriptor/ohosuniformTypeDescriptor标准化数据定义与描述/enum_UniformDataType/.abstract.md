This directory contains API reference documentation for the `UniformDataType` enumeration within the Cangjie programming environment and the Unified Data Management Framework (UDMF). It provides a comprehensive taxonomy of file types and data formats, ranging from audio, video, and images to text, archives, and system-specific entities. The documentation details constant names, hierarchical parent categories, and API version requirements (starting from version 19). It is suitable for developers working on OpenHarmony systems who need to implement file classification, data handling, or media processing logic using standardized type identifiers.
