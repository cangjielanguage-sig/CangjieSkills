# cj-power-shell

This directory contains the documentation for the `cj-power-shell` tool, a specialized command-line utility designed for developers to debug and manage device power states efficiently. It serves as a comprehensive reference guide for controlling power modes, screen states, and auto-sleep settings via the hdc shell. The documentation covers key functionalities, including switching between distinct energy profiles such as Normal, Power Saving, and Performance, as well as overriding system sleep timers to prevent interruptions during long-running tests. This resource is suitable for system developers, QA engineers, and power management specialists who need to perform granular power debugging tasks. Whether the goal is to wake a device programmatically, enforce specific energy consumption profiles, or validate power-saving features, this guide provides the necessary instructions to optimize device performance and battery life during the development cycle. It provides a centralized location for all power-related shell commands, streamlining the debugging process.

## Detailed Description

### cj-power-shell.md cj-power-shell.md

This document serves as the definitive command reference guide for the power-shell tool, enabling developers to debug and manage device power states with precision. It details specific commands essential for power control, including `setmode` for changing power modes, `wakeup` and `suspend` for screen control, and `timeout` for managing auto-sleep settings. The guide provides in-depth syntax, parameter explanations, and practical examples for switching between operational modes such as Normal, Power Saving, and Performance. Additionally, it covers how to override system sleep timers, a critical feature for preventing device sleep during automated tests. Intended for developers using the hdc shell, this tool facilitates basic power debugging tasks, such as waking the device remotely or setting specific energy profiles to monitor power consumption. By following this guide, users can ensure their devices maintain the desired power behavior throughout the development and testing phases, making it an indispensable tool for power-related troubleshooting. The guide is structured to help users quickly find the necessary commands for their specific debugging scenario. Understanding these commands is crucial for maintaining system stability and ensuring efficient energy usage.
