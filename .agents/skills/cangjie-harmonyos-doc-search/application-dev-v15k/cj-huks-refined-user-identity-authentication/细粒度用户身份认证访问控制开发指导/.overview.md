# 细粒度用户身份认证访问控制开发指导

This directory provides a comprehensive technical guide for implementing fine-grained user identity authentication and access control within HarmonyOS applications. It focuses on leveraging the Universal Keystore Kit (HUKS) to enforce secondary authentication mechanisms—such as biometric verification or lock screen passwords—specifically for sensitive key operations like encryption and decryption. The documentation covers essential concepts, including the use of the HUKS_TAG_KEY_AUTH_PURPOSE tag, supported cryptographic modes (AES/CBC, AES/GCM, SM4/CBC), and practical implementation workflows using the Cangjie language. It is intended for software developers seeking to enhance application security by ensuring that sensitive data remains protected and is only accessed following explicit user verification.

## Detailed Description

### 细粒度用户身份认证访问控制开发指导.md 细粒度用户身份认证访问控制开发指导.md
This development guide explains how to implement fine-grained user identity authentication access control using HUKS, enabling secondary authentication for specific key operations like encryption or decryption. The document details the concept of extending existing access controls to require biometric or lock screen password verification only during designated scenarios. Key information includes the use of the HUKS_TAG_KEY_AUTH_PURPOSE tag during key generation to specify these requirements and a constraint noting that only AES/CBC, AES/GCM, and SM4/CBC modes support this for symmetric encryption. Intended for developers securing sensitive data, this guide facilitates scenarios where data is stored without authentication but accessed only after user verification.

### 开发步骤/
This directory outlines the development steps for implementing secure SM4 cryptographic operations with biometric authentication using the Cangjie language. It covers the complete workflow from generating keys with fingerprint access control in the Universal Keystore Kit to managing secure decryption sessions integrated with the User Authentication Kit. Key topics include key attribute configuration, session initialization, biometric verification, and token handling. This guide is suitable for software developers building secure applications on HarmonyOS who require biometric protection for sensitive data processing.
