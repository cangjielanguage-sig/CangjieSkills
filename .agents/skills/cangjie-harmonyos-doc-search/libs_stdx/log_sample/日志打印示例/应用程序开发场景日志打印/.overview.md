# 应用程序开发场景日志打印

This directory focuses on logging mechanisms within application development scenarios, specifically utilizing the Cangjie programming language. It covers the practical implementation of custom logging frameworks designed to enhance security and performance. Key topics include sensitive data masking (such as passwords) to prevent information leakage, structured logging with key-value pairs for better parsing, log level management, and performance optimization via lazy evaluation techniques. The content demonstrates how to handle output streams, serialize complex data types, and inject context into logs. These resources are highly suitable for software developers and system architects seeking to build robust, secure, and efficient logging systems that facilitate debugging and compliance in production environments. By mastering these patterns, developers can ensure their applications maintain high performance while providing necessary observability without exposing sensitive user data.

## Detailed Description

The following documents provide detailed code examples and implementations for logging in the Cangjie language.

### 应用程序开发场景日志打印_1.md
This document serves as a practical code example for implementing custom logging mechanisms in the Cangjie programming language. It details the creation of a PasswordFilter class to mask sensitive information like passwords and a TextLogger for handling output streams. The main section demonstrates usage patterns, including structured logging with key-value pairs and lazy evaluation techniques to avoid unnecessary computation for disabled log levels. Key concepts include log level management, attribute filtering, and performance optimization through lambda expressions. This guide is designed for developers seeking to secure logs and optimize performance in application scenarios.

### 应用程序开发场景日志打印_2.md
This document provides a code implementation and output example for a structured logging system in application development. It covers the Logger class implementation for log level management and attribute handling, and the TextLogWriter class for serializing various data types to text output. Key functions include log for immediate and lazy message logging, withAttrs for context injection, and specific writer methods for formatting key-value pairs. The output demonstrates structured logging with timestamps, levels, and complex data types like arrays and objects. This is intended for software developers looking to understand or implement a custom logging framework with structured output capabilities.
