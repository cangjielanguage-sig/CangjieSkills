This directory provides comprehensive API reference documentation for the `AdsBlockManager` class, implemented in the Cangjie language specifically for the ArkWeb framework. It focuses on the technical implementation and configuration of ad-blocking mechanisms within Web and Webview components. The documentation covers essential functionalities such as configuring domain lists (AllowedList and DisallowedList), applying suffix matching logic, and managing custom EasyList syntax rules. Developers will find detailed explanations regarding the persistence of settings, clearly distinguishing between temporary list modifications and persistent custom rules. This resource is specifically designed for application developers who require granular control over web content filtering, enabling them to create cleaner browsing experiences by effectively managing ad-blocking behaviors, parameter requirements, and exception handling within their applications.
