# class_DeviceInfo

This directory contains API reference documentation for the Cangjie `DeviceInfo` class, designed for querying terminal device information within the OpenHarmony environment. It covers a wide range of static properties, including device identifiers (ODID, UDID), hardware specifications (brand, model), and software metadata (OS versions, build time). All functionalities rely on the SystemCapability.Startup.SystemInfo capability starting from API version 22. This documentation is suitable for Cangjie application developers who need to access system hardware and software details to implement system-aware features or diagnostics.

## Detailed Description

### class_DeviceInfo_12more.md class_DeviceInfo_12more.md
This document serves as API reference documentation for the Cangjie DeviceInfo class, which provides static properties to query terminal device information. It details various read-only properties including the developer anonymous device identifier (ODID), device brand, ABI list, and build metadata like version, host, and time. Key information includes specific ODID generation rules based on developer ID and regeneration scenarios like factory resets. All properties belong to the SystemCapability.Startup.SystemInfo capability starting from version 22. This reference is intended for application developers using the Cangjie language who need to access system hardware and software information.

### static_prop_displayVersio_12more.md static_prop_displayVersio_12more.md

All properties share the SystemCapability.Startup.SystemInfo capability and became available in API version 22. The content is intended for developers requiring access to device metadata, OS versioning, and manufacturer details to implement system-aware features in their applications.

### static_prop_marketName_11more.md static_prop_marketName_11more.md

### static_prop_versionId/
This directory provides comprehensive documentation and practical code examples for the `versionId` static property in the Cangjie language and HarmonyOS environments. It focuses on retrieving a device's comprehensive version identifier, which is a read-only string combining attributes such as device type, brand, OS name, and build type. The resources include API reference details regarding syntax, data types, and required system capabilities, as well as implementation examples for logging device metadata and managing runtime exceptions. This collection is designed for Cangjie and HarmonyOS developers building OpenHarmony system applications who require precise device identification and system information access for diagnostics or conditional logic.
