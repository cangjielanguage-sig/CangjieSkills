# 组件事件

This directory provides comprehensive API reference documentation for managing component events within the Cangjie ArkUI framework. It specifically focuses on the complex mechanisms of scroll event handling, offering developers the tools to monitor, control, and customize scroll behaviors in their applications. The content covers a range of callbacks, from observing scroll states to intercepting and modifying scroll offsets before they are applied. It is designed for UI developers and system engineers working with the Cangjie language who require precise control over user interactions in scrollable components, ensuring a responsive and tailored user experience.

## Detailed Description

### func_onDidScrollscrollOffs_5more.md

This document serves as API reference documentation for scroll event handling within the Cangjie ArkUI framework. It details five primary functions: onDidScroll, onReachEnd, onReachStart, onScrollStart, and onScrollStop. Key information includes function signatures, callback parameters such as scrollOffset and ScrollState, and specific trigger conditions, including edge behaviors like spring effects and programmatic scrolling via the Scroller controller. The content is intended for developers utilizing the ArkUI system capabilities to manage and respond to user interactions in scrollable components. Keywords: Cangjie, ArkUI, scroll events, API reference, callback functions, Scroller.

### func_onWillScrollFloat64Sc_3more.md

This API reference document details the onWillScroll event callback functions for ArkUI scroll components in the Cangjie programming language. It covers two primary function overloads: one returning Float64 to modify the scroll offset and another returning Unit for observation purposes. Additionally, it documents a deprecated onScroll function, recommending replacements like onDidScroll for specific components. Key information includes that these callbacks trigger before scrolling, providing the calculated offset, scroll state, and source. The Float64 variant allows developers to override the scroll distance. The document specifies that ScrollEdge and non-animated ScrollToIndex operations do not trigger this event. This guide is intended for UI developers implementing custom scroll behaviors or tracking metrics in ArkUI applications.
