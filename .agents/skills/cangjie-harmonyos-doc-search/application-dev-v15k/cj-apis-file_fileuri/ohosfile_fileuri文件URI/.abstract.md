This directory provides comprehensive API documentation for the `ohos.file_fileuri` module, a critical component for HarmonyOS developers using the Cangjie language. It centers on the `FileUri` class, which enables secure file sharing by managing the conversion between file URIs and application sandbox paths. The documentation covers essential functionalities such as URI generation, path encoding, and string representation, supporting various URI types including sandbox and public directories. It includes details on error handling, static methods like `getUriFromPath`, and integration with the CoreFileKit. This resource is ideal for developers needing to implement file open, read, and write operations within the HarmonyOS environment.
