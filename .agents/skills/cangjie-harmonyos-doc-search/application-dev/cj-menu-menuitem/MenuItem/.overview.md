# MenuItem

This directory contains API reference documentation for the MenuItem component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of menu items supporting submenus, event handling for state changes, and comprehensive styling properties for typography and selection states. Key topics include component constructors, universal attributes, and the `onChange` event. This resource is intended for UI developers and software engineers building hierarchical menu structures and customizing visual presentations in their applications, requiring system version 22 or later.

## Detailed Description

### MenuItem_5more.md MenuItem_5more.md
This document serves as API reference documentation for the MenuItem component in the ArkUI framework using the Cangjie language. It details how to implement specific menu items that support submenus. The main sections cover module imports, component creation via two constructors, and supported universal attributes. Key information includes the parameters for defining start icons, content, end icons, and label info, alongside options for custom UI descriptions using the @Builder macro. Currently in Beta, this documentation is intended for developers constructing user interfaces who need to integrate hierarchical menu structures into their applications.

### 组件事件_2more.md 组件事件_2more.md
This document provides API reference documentation for the onChange event handler used in ArkUI components. It details the function signature, functional description, system capabilities, version requirements, and parameter specifications. Key information includes that the onChange function accepts a callback with a Boolean parameter representing the new selection state, triggering only upon manual interaction that alters the component's state. The document also references the Menu component for implementation examples. This technical reference is intended for software developers building applications using the ArkUI framework who need to handle state change events within their user interfaces.

### 组件属性/
This directory serves as a comprehensive resource for API reference documentation regarding component properties within the ArkUI framework, specifically designed for the Cangjie programming language. It focuses extensively on the styling and configuration of menu items, providing developers with the necessary functions to manipulate typography, such as font size, weight, style, and family, as well as text color settings for both content and labels. Furthermore, it covers the management of selection states and the visual representation of selected items through icons. These guides are intended for UI developers and system engineers seeking to programmatically enhance the visual presentation and interactivity of their applications, ensuring compatibility with system version 22 or later.
