This directory provides comprehensive API reference documentation for the `Iterator` class within the Cangjie programming language ecosystem. Furthermore, it covers a robust set of functional-style operations for data sequence manipulation, including intermediate and terminal operations. This resource is essential for Cangjie developers aiming to implement custom iterators, perform complex data transformations, or efficiently manage collection traversals in their applications.

## Detailed Description

### class_IteratorT_4more.md
This document serves as API reference documentation for the abstract Iterator class in the Cangjie programming language. It details the class definition, its inheritance from the Iterable interface, and key methods including the constructor init, iterator, and next. The primary functionality involves traversing container elements via the next method, which returns an Option type to safely handle the end of iteration. A practical code example demonstrates iterating over an array using a loop and pattern matching. This reference is intended for Cangjie developers seeking to implement or utilize iterators for collection traversal.

### extendT_IteratorT_where_T__2more.md
This API reference document details extensions for the Cangjie Iterator class based on generic type constraints. It covers two specific extensions: one for types implementing Comparable and another for types implementing Equatable. The Comparable extension provides max() and min() functions to find extreme values, returning Option. The Equatable extension adds a contains() function to check for element presence. Crucially, the documentation notes that these operations consume iterator elements. This guide targets Cangjie developers seeking to perform comparison and equality checks on iterators.
