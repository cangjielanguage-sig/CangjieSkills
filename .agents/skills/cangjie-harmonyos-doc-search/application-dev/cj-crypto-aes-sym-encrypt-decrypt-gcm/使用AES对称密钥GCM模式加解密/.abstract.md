This directory serves as a comprehensive technical resource for implementing AES symmetric encryption and decryption using the GCM (Galois/Counter Mode). It provides a deep dive into the necessary workflows, covering key generation, cipher initialization, data processing, and the management of authentication tags to ensure both confidentiality and integrity. The content is specifically tailored for developers utilizing the Cangjie programming language and the CryptoArchitectureKit. By combining theoretical API steps with practical synchronous code examples, this collection helps developers securely integrate cryptographic features into their applications. It addresses specific requirements such as the AES128|GCM|PKCS7 algorithm string and the handling of 16-byte authentication tags, making it an essential reference for secure data handling in Cangjie projects.
