# 使用ImagePacker完成图片编码

本目录主要介绍如何使用仓颉语言的ImagePacker组件进行图片编码。内容涵盖了将PixelMap对象编码为JPEG、WebP、PNG及HEIF等常见格式的完整流程，包括API使用说明、参数配置（如质量、HDR支持）以及工程配置方法。文档还涉及文件流处理和资源管理，适合需要进行图片保存与传输功能的仓颉应用开发者参考。

### 开发步骤.md
本文档是一份开发教程，指导开发者使用仓颉语言的ImageKit进行图片编码。文档主要涵盖两个核心流程：将图片编码进文件流和直接编码进文件。关键内容包括创建ImagePacker对象、配置编码参数（如格式、质量及HDR支持），以及利用PixelMap或ImageSource对象进行处理。文档重点介绍了packToData和packToFile等API方法，并提供了包含文件I/O和资源管理的代码示例。该文档面向需要实现图片保存功能的仓颉开发者，要求读者具备ImageKit和CoreFileKit模块的相关知识。
