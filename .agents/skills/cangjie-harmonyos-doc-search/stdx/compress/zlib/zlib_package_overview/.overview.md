# zlib_package_overview

本目录包含 `stdx.compress.zlib` 包的概览文档，专注于介绍基于 deflate 算法的数据压缩与解压功能。文档内容全面，涵盖了 deflate-raw 和 gzip 数据格式的支持、三种压缩等级的配置以及流式处理机制，同时明确说明了当前版本暂不支持文件打包功能。此外，文档还详细列出了输入输出流类、压缩等级与封装类型枚举及异常类等 API 接口。这份资料非常适合需要在应用程序中集成高效数据压缩功能的开发者查阅，核心关键词包括 deflate、gzip、流式压缩、CompressLevel。

### zlib_package_overview.md

这份文档是 stdx.compress.zlib 包的概览，旨在介绍基于 deflate 算法的压缩与解压功能。文档主要包含功能介绍和 API 列表，详细说明了支持的 deflate-raw 和 gzip 数据格式、三种压缩等级以及流式处理机制，并明确指出暂不支持文件打包功能。API 部分涵盖了输入输出流类、压缩等级与封装类型枚举及异常类。该文档面向需要集成数据压缩功能的开发者，提供了核心概念说明和接口索引，关键词包括 deflate、gzip、流式压缩、CompressLevel。
