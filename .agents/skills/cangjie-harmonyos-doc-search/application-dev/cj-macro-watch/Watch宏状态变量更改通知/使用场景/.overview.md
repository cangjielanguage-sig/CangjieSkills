# 使用场景

This directory provides a comprehensive collection of tutorials and practical examples focused on the application of the `@Watch` decorator in ArkUI development using the Cangjie language. It explores specific usage scenarios ranging from synchronizing state between parent and child components to executing distinct logic based on which property has been modified. By examining real-world cases like counter updates and shopping basket management, these documents illustrate how to effectively manage state changes, optimize rendering performance, and handle complex dependencies. This content is highly suitable for developers who want to deepen their understanding of ArkUI's reactive state management mechanisms and build robust, interactive user interfaces.

## Detailed Description

### Watch和自定义组件更新_2more.md Watch和自定义组件更新_2more.md
This tutorial demonstrates how to implement the @Watch decorator with @Link to handle custom component updates in ArkUI using the Cangjie language. The document covers two primary examples: a basic counter update mechanism and a shopping basket list modification scenario. Key takeaways include the processing steps where changes to @State variables trigger @Link updates, subsequently invoking @Watch callbacks to modify local state and trigger asynchronous re-rendering of UI components like Text and ForEach. It targets ArkUI developers seeking to understand state management, specifically the interaction between parent and child components and reactive UI updates.

### 使用changedPropertyName进行不同的逻辑处理.md 使用changedPropertyName进行不同的逻辑处理.md
This tutorial demonstrates how to implement conditional logic within the @Watch decorator in ArkUI Cangjie applications to handle different state variable changes. The document presents a code example using @State variables and a shared @Watch callback function to selectively update a dependent variable based on which property changed. Key takeaways include understanding the execution flow of the state management framework and how to control UI re-rendering efficiency. This guide is intended for developers using the ArkUI framework who need to manage complex state dependencies and side effects in their applications.
