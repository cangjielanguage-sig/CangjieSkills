### cj-universal-attribute-enable.md cj-universal-attribute-enable.md
This API reference document details the enabled function for controlling component interactivity within the ArkUI framework using the Cangjie language. It covers the module import, function signature, parameters, and return values. The function accepts a ?Bool parameter where true enables interaction with click, touch, key, focus, and mouse events, while false disables them. A critical constraint is that changes to the enabled state only take effect when the component is not currently being interacted with. This documentation targets developers seeking to manage component states and event handling in their applications.
