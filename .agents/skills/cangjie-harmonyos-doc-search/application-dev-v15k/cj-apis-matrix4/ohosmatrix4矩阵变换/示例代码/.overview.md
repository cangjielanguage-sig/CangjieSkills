# 示例代码

This directory contains a comprehensive collection of practical code examples designed for the Cangjie programming language, specifically tailored for UI development within the HarmonyOS ecosystem. The content focuses on the implementation and manipulation of matrix transformations to achieve complex visual effects. It covers a wide range of topics, from basic matrix operations like initialization, scaling, rotation, and inversion to advanced image mapping techniques such as perspective warping and coordinate skewing. Key technical concepts include the Matrix4 class, Matrix4Transit, and PolyToPolyOptions. These examples are highly suitable for HarmonyOS developers and UI engineers who are using the Cangjie UI kit and need to apply precise geometric transformations to interface elements or create dynamic, custom visual effects in their applications. By following these tutorials, developers can gain a deeper understanding of how to manipulate 2D and 3D coordinate systems effectively.

## Detailed Description

The following files provide specific implementations and tutorials for matrix transformations in Cangjie.

### 示例1创建矩阵_5more.md
This document serves as a practical tutorial for implementing matrix transformations in the Cangjie programming language, specifically within a UI development context. It covers five key examples: initializing matrices with specific values or identity, combining scaling and inversion effects, applying rotation and skew transformations, and performing coordinate point translations. Key takeaways include the usage of Matrix4 methods such as initialize, identity, scale, invert, combine, rotate, skew, and transformPoint to manipulate visual components. The content is designed for HarmonyOS developers using the Cangjie UI kit who need to apply geometric transformations to interface elements.

### 示例6映射效果.md
This document provides a code example demonstrating how to implement advanced image mapping effects using matrix transformations in the Cangjie programming language for HarmonyOS development. The primary topic is the usage of the Matrix4Transit class and its setPolyToPoly method to warp UI elements. Key information includes the configuration of PolyToPolyOptions to map source coordinates to destination coordinates, creating a perspective or skew effect on an image component. This example serves as a practical guide for developers looking to apply custom geometric transformations within their HarmonyOS applications.
