This directory contains API reference documentation for extending the generic `DataStrategyProcessor` class within the Cangjie programming language. It focuses on advanced data manipulation techniques essential for property-based testing, covering functions like `map`, `flatMap`, and `product`. The documentation explains how these methods transform data strategies, generate Cartesian products, and manage shrinking logic for both finite and infinite strategies. This resource is suitable for developers utilizing the Cangjie unit testing framework who require sophisticated data generation capabilities and testing logic.
