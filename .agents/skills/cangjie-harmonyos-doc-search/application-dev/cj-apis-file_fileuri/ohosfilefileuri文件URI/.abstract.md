This directory provides comprehensive API reference documentation for the `ohos.file.fileuri` module within the HarmonyOS environment, specifically tailored for the Cangjie programming language. It focuses on the essential mechanisms required to convert standard file paths into Uniform Resource Identifiers (URIs), a critical step for enabling secure file sharing and manipulation across application boundaries. The content covers core components such as the `FileUri` class, URI encoding protocols, sandbox path handling, and specific error management strategies. This resource is highly suitable for HarmonyOS developers using Cangjie who need to implement robust file management features, including opening, reading, and writing files, while adhering to system security constraints.
