# 基础概念与规范

This directory outlines the core principles, algorithms, and specifications for focus management within a UI framework, specifically designed for non-pointing devices like remote controls or keyboards. It covers fundamental concepts such as focus chains and hierarchical pages, details navigation algorithms including linear and projection strategies, and defines technical specifications for active and passive focus behaviors. This documentation is essential for UI developers and system architects building applications for TV, automotive, or other interfaces requiring robust keyboard navigation support.

## Detailed Description

### 基础概念.md 基础概念
This document defines the core concepts and mechanisms of focus management within a UI framework, specifically for non-pointing input devices. It covers Focus and Focus Chains, Focus State visibility rules, Hierarchical Pages (like Dialogs and Popups), and Root Container behavior. Key takeaways include that focus states only appear after activation via TAB key or API calls, hierarchical pages trap focus internally and grab it upon creation, and the root container handles default focus distribution to child components. This reference guide targets UI developers working on applications requiring keyboard or remote control navigation, such as TV or automotive interfaces.

### 走焦算法.md 走焦算法
This technical reference document defines the algorithms governing focus movement between child components within a focus management system. It details three specific strategies: Linear Focus (default, tree-order based), Projection Focus (geometry-based for wrapped layouts), and Custom Focus (component-defined). Key takeaways include that Linear navigation follows node mounting order and restricts arrow keys to the container's direction, while Projection navigation calculates overlap and center-point distance to determine the next target, with specific logic for TAB and Shift+TAB keys in wrapped Flex containers. This guide targets UI developers and system architects implementing focus management logic, requiring knowledge of component trees and layout systems.

### 走焦规范.md 走焦规范
This document defines the technical specifications and logic for focus navigation within a UI framework, categorizing behaviors into active and passive mechanisms. It covers Active Focus Navigation, detailing keyboard inputs like TAB and arrow keys, programmatic requests via requestFocus, and touch interactions. It also explains Passive Focus Navigation, which handles automatic focus transfers triggered by component deletion, property changes, or page switching. Key takeaways include the Z-pattern traversal for keys and the sibling-priority logic for passive events. This reference guide targets UI developers and system engineers implementing focus management. Keywords: focus navigation, UI framework, requestFocus, keyboard inputs, ArkUI.
