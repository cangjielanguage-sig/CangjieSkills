# 基础类型定义

This directory provides API reference documentation for fundamental styling classes within the Cangjie ArkUI framework. It covers the definition and configuration of visual components such as backplates, indicators, and various tab bar styles (bottom, sub, and icon). Key topics include border radius, color properties, layout modes, and text styling. These resources are designed for Cangjie developers and UI designers looking to implement and customize navigation components and visual styles in applications targeting system version 19 or later.

## Detailed Description

### class_BoardStyle.md class_BoardStyle.md
This document serves as an API reference for the Cangjie BoardStyle class, which defines styling properties for backplate components within the ArkUI framework. The documentation details the class structure, specifically focusing on the read-only borderRadius property and the class constructor. Key information includes that borderRadius accepts a Length type in virtual pixels (vp), defaults to 8.0.vp, and does not support percentage values. The constructor allows customization of this radius via a named parameter. Intended for ArkUI developers, this reference aids in configuring visual styles for system components starting from API version 19.

### class_IndicatorStyle.md class_IndicatorStyle.md
This API reference document defines the Cangjie class IndicatorStyle, used to configure the visual appearance of underline indicators within the ArkUI framework. The documentation details the class structure, read-only properties including color, height, width, borderRadius, and marginTop, and the class constructor with default parameters. Key information includes that all length properties exclude percentage support, and setting the width to 0.0.vp automatically adjusts the underline to match the text width. This resource targets UI developers using the Cangjie language to customize tab or indicator components, requiring knowledge of ArkUI system capabilities.

### class_TabBarIconStyle_3more.md class_TabBarIconStyle_3more.md
This document serves as an API reference for configuring TabBar styles and layouts within the Cangjie ArkUI framework. It details the TabBarIconStyle class for defining icon colors, alongside the LayoutMode and SelectedMode enums for controlling content arrangement and selection visuals. Key information includes that TabBarIconStyle modifies SVG fill colors via read-only properties, LayoutMode automatically switches orientation based on width, and SelectedMode offers underline or background styles. Intended for Cangjie developers, this guide provides the necessary parameters and system capabilities to customize TabBar components effectively.

### class_BottomTabBarStyle/
This directory contains API reference documentation for the `BottomTabBarStyle` class within the Cangjie ArkUI framework. It comprehensively covers the definition, initialization, and styling of bottom and side tab bars used in application navigation. Key topics include various constructor overloads, static factory methods, padding configuration, and layout customization options such as icon and label styling. The documentation highlights support for flexible resource management using String and AppResource types, localized padding for mirroring, and fluent interface patterns for method chaining. This content is suitable for Cangjie developers and UI designers implementing navigation components in applications targeting system version 19 or later.

### class_LabelStyle/
This directory contains documentation for the `LabelStyle` class within the Cangjie language and ArkUI framework. It covers the API reference for configuring text and font styles in Label components, including text overflow handling, adaptive font sizing, height policies, and color states. The documentation details the constructor and various read-only properties that are immutable upon initialization. It is suitable for developers working with the ArkUI framework who need to customize text display properties and styling behaviors in their UI applications. Keywords include LabelStyle, TextOverflow, adaptive font, ArkUI, and Cangjie.

### class_SubTabBarStyle/
This directory provides comprehensive API documentation for the `SubTabBarStyle` class within the ArkUI framework, specifically designed for the Cangjie language. It covers the complete lifecycle of styling sub-tabs, ranging from initialization via constructors and static factory functions to detailed configuration of visual elements like boards, indicators, and labels. Key topics include switching animations, method chaining for fluent API usage, and specific constraints related to horizontal layouts. This resource is essential for ArkUI developers looking to implement dynamic and visually consistent tabbed interfaces in their applications.
