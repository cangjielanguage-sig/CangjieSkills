# decimal_basic_arithmetic

This directory serves as a comprehensive educational resource for developers working with the Cangjie programming language, specifically targeting those who require high-precision numerical computations. It provides a practical tutorial on the `Decimal` type, which is essential for applications where standard floating-point arithmetic may result in unacceptable rounding errors, such as in financial systems or scientific calculations. The content covers the complete workflow of using `Decimal`, starting from object initialization through string parsing and BigInt construction. It proceeds to demonstrate standard arithmetic operations, including addition, subtraction, multiplication, and division. Additionally, the guide delves into advanced division techniques, offering insights into controlling rounding with `divWithPrecision` and retrieving both quotient and remainder via `divAndMod`. This directory is suitable for Cangjie developers seeking to master precise mathematical operations, featuring executable code snippets and expected outputs to facilitate immediate learning and verification.
