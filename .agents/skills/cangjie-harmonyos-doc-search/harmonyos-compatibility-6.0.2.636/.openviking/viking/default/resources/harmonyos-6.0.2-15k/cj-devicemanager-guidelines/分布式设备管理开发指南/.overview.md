# 分布式设备管理开发指南

This directory serves as a comprehensive development guide for distributed device management, focusing on cross-device collaboration. It covers the fundamental concepts of distributed business, including device discovery, binding, status querying, and listening. Key topics involve establishing trust relationships via LAN or Bluetooth, managing device states, and handling necessary permissions like `ohos.permission.DISTRIBUTED_DATASYNC`. The content provides step-by-step tutorials using the Cangjie language and the DistributedServiceKit module. It is suitable for developers building distributed applications that require robust connectivity and interaction between multiple devices.

## Detailed Description

### 分布式设备管理简介_2more.md 分布式设备管理简介_2more.md
This document introduces distributed device management as the entry point for cross-device collaboration and provides a tutorial for requesting necessary permissions. Main topics include the definition of distributed business, four core functions (discovery, binding, query, and listening), operational mechanisms, and system constraints. Key takeaways explain how to establish trust relationships between devices via LAN or Bluetooth and the requirement for user authorization due to sensitive data. The guide details the development steps for the Stage model, specifically configuring module.json5 and using the requestPermissionsFromUser API in Cangjie to request the ohos.permission.DISTRIBUTED_DATASYNC permission. This content is intended for developers building distributed applications.

### 设备发现开发指导.md 设备发现开发指导.md
This development guide instructs developers on implementing device discovery using the DeviceManager API within the DistributedServiceKit module. It outlines the scenario, interface specifications, and a step-by-step coding process in Cangjie. Key sections include importing necessary modules, creating a device manager instance with success and failure callbacks, and invoking the startDiscovering method. Important constraints include a two-minute discovery duration, a maximum of 99 devices, and local area network requirements for Wi-Fi scenarios. This guide targets developers building distributed applications requiring nearby device connectivity.

### 设备绑定开发指导_3more.md 设备绑定开发指导_3more.md
This development guide instructs developers on establishing trusted relationships with distributed devices and managing their status using the DistributedServiceKit in Cangjie. It covers three core scenarios: device binding to establish trust, querying available trusted devices, and monitoring device online or offline status changes. Key APIs include bindTarget for binding, getAvailableDeviceList for querying, and on for status callbacks. The guide provides step-by-step instructions and Cangjie code examples for implementing these features, emphasizing the prerequisite of distributed data synchronization permissions. Targeted at application developers working on distributed systems, this document facilitates the creation of robust device management functionalities.
