# class_Process

This directory contains API reference documentation for the Cangjie Process class, focusing on system process management and interaction. It covers functionalities such as retrieving process details (pid, name, command), managing process lifecycles (checking status, termination), and executing subprocesses. The documentation includes details on properties, static functions, and deprecated methods like `run`, `start`, and `runOutput`, guiding developers toward modern alternatives. It addresses platform-specific limitations, exception handling, and IO redirection. This resource is suitable for Cangjie developers who need to integrate system-level process control into their applications or maintain legacy code involving subprocess execution.
