This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on the Slider component. It covers a wide range of customization options including block styling (borders, colors, shapes), track appearance, interaction modes, and responsive distances. Developers will find detailed parameters, default values, and version requirements for functions like `blockStyle`, `trackColor`, and `sliderInteractionMode`. This documentation is suitable for software developers and UI designers using the Cangjie language to build interactive and visually refined user interfaces.
