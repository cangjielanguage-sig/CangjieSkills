This directory provides comprehensive API reference documentation for the `ohos.net.connection` module within the HarmonyOS NetworkKit, specifically designed for the Cangjie programming language. It covers essential network management functionalities, including connection monitoring, property configuration, DNS resolution, and proxy settings. Key components include classes for network handles, capabilities, and connection events, alongside functions for querying network states and managing application-specific network bindings. This documentation is suitable for Cangjie developers building network-aware applications who need to programmatically handle network transitions, manage connectivity, and implement robust network status monitoring in HarmonyOS environments.
