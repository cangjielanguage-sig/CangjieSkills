This directory provides comprehensive technical documentation and resources for subscribing to application crash events within the Cangjie ecosystem. It covers the usage of the Performance Analysis Kit to monitor application stability by implementing event watchers for specific crash types like CjError and NativeCrash. The content includes API references for adding and removing watchers, as well as practical development steps for configuration, manual crash testing, and log analysis. It is suitable for Cangjie developers and system engineers using DevEco Studio who need to debug application failures, interpret complex crash logs, and optimize error handling mechanisms in HarmonyOS or OpenHarmony environments.
