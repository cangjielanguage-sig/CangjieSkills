# 访问和管理动态照片资源

This directory provides technical documentation for accessing and managing Moving Photo resources within the HarmonyOS ecosystem using the Cangjie language. It covers the complete lifecycle of dynamic photos, which combine static images with video and audio clips. Key topics include retrieving MovingPhoto objects via Picker or sandbox storage, exporting resources to the application sandbox, and reading content directly as ArrayBuffers. This guide is intended for developers and multimedia engineers looking to integrate advanced media handling, playback, and processing capabilities into their applications using MediaLibraryKit.

### 读取动态照片资源.md 读取动态照片资源.md
This document provides a code example demonstrating how to access and export resources from a MovingPhoto object using the MediaLibraryKit in Cangjie. The main topic is the `requestContent` method, which supports two primary operations: exporting image and video files to the application sandbox via file URIs, and reading their content directly as ArrayBuffers. Key takeaways include understanding the method's overloads for file export versus memory access, utilizing `ResourceType` to distinguish between image and video data, and implementing error handling for `BusinessException`. This technical reference is intended for application developers working with multimedia resources in the HarmonyOS ecosystem who need to process dynamic photo assets.
