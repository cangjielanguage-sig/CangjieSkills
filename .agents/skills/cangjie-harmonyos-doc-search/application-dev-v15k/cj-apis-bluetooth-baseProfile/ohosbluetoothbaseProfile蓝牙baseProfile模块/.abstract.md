This module provides the foundational API reference for the HarmonyOS Bluetooth Base Profile using the Cangjie programming language. It covers essential data structures, enumerations, and interfaces required for managing Bluetooth connectivity, including connection state monitoring, disconnection cause analysis, and device list retrieval. Key components include the `BaseProfile` interface, state change parameters, and callback types. Designed for HarmonyOS developers, this documentation requires SystemCapability.Communication.Bluetooth.Core (version 19) and specific permissions like `ohos.permission.ACCESS_BLUETOOTH`. It is suitable for software engineers implementing robust Bluetooth features in Cangjie-based applications.
