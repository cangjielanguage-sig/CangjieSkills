### 完整示例_1.md 完整示例_1.md
This document provides a complete Cangjie code example demonstrating how to control audio playback using the AVPlayer class, specifically implementing a play-pause-resume sequence. It covers initializing the player, registering callbacks for state changes and errors, and illustrates three distinct methods for setting media sources: using a file system URL, a file descriptor (FD) from HAP resources, and a data source descriptor for seek mode. Key takeaways include the implementation of setAVPlayerCallback for event handling and the specific syntax for accessing sandbox files and resource managers. Intended for HarmonyOS developers with knowledge of Cangjie, this tutorial serves as a practical guide for integrating media playback capabilities.

### 完整示例_2.md 完整示例_2.md
This document provides code examples demonstrating how to implement media playback using the AVPlayer framework. It covers playing local sandbox files via data sources in No Seek mode and playing live streams via URL. Key sections include the StateChangeCallback class, which manages the player lifecycle by handling state transitions such as initialized, prepared, playing, and paused. The code illustrates setting up file descriptors, configuring audio renderer info, and implementing logic for pausing and seeking. This tutorial is intended for developers building media applications who need to understand AVPlayer state management and data source configuration.
