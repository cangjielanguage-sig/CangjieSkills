# 关系型数据库跨设备数据同步

This directory provides comprehensive technical resources for implementing cross-device synchronization for relational databases, specifically designed to ensure data consistency across multiple devices in a distributed environment. It covers essential technical concepts such as distributed tables, encrypted channels, and the underlying operational mechanisms required for seamless data management. The documentation details the complete synchronization process, including local and distributed data change notifications, and outlines specific constraints like database limits and key exclusions. Designed for application developers, particularly those working with the Cangjie language and HarmonyOS architecture, these guides offer both theoretical background and practical coding steps for managing distributed data effectively. Please note that the features described are currently in Beta.

## Detailed Description

### 关系型数据库跨设备数据同步_6more.md 关系型数据库跨设备数据同步_6more.md
This technical guide explains how to implement cross-device synchronization for relational databases, enabling data consistency across multiple devices. It covers usage scenarios, core concepts like distributed tables, and the underlying operational mechanism involving encrypted channels and data management services. Key sections detail the sync process, local and distributed data change notifications, and specific constraints such as the 16-database limit and the exclusion of composite keys. The document also lists essential APIs for subscribing to data changes. Intended for application developers, this guide provides the necessary instructions to manage distributed data effectively, though the feature is currently in Beta.

### 开发步骤.md 开发步骤.md
This document serves as a development tutorial guiding developers through implementing distributed data synchronization using the Cangjie language. It covers three primary steps: importing required modules like ArkData and AbilityKit, requesting the DISTRIBUTED_DATASYNC permission, and creating a relational database with a defined security level. Key takeaways include the importance of configuring security levels to control data access and the specific code implementation for initializing an RdbStore within a UIAbility. This guide targets application developers working on cross-device data features, requiring knowledge of Cangjie syntax and HarmonyOS architecture.
