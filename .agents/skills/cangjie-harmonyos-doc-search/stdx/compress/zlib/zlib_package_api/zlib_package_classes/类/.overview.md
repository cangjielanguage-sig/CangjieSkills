# 类

本目录包含 Cangjie 语言中用于数据压缩与解压的核心类 API 文档，主要基于 `stdx.compress.zlib` 包。涵盖了压缩输入流、压缩输出流、解压输入流及解压输出流的详细使用说明。文档重点介绍了类的构造函数配置、核心读写方法、资源管理及异常处理机制。这些内容适用于需要在 Cangjie 项目中实现流式数据压缩与解压功能的开发者，要求具备基础的流处理知识。

## 详细描述

### class_CompressInputStream.md class_CompressInputStream.md
这是一份Cangjie语言中CompressInputStream类的API参考文档，旨在指导开发者如何创建并使用压缩输入流来处理数据压缩。文档主要涵盖类的构造函数配置、read数据读取与压缩方法、close资源释放方法，以及相关的异常处理说明。关键信息包括构造函数支持自定义压缩格式、等级和缓冲区大小，read函数将绑定流数据压缩后输出至字节数组，且必须在读取完毕后调用close以防止内存泄漏。该文档面向使用stdx.compress.zlib包进行流式数据压缩的开发者，需具备基础的流处理知识。

### class_CompressOutputStream.md class_CompressOutputStream.md
这份 API 参考文档详细介绍了 CompressOutputStream 类，用于在 Cangjie 语言中将数据压缩并写入绑定输出流。主要内容包括构造函数参数配置（如压缩格式、等级及缓冲区大小），以及 write、flush 和 close 等核心方法的使用说明。文档强调了 close 方法对于完成压缩尾部写入和资源释放的重要性，并提供了代码示例。该文档面向需要使用 zlib 包进行流式数据压缩的开发者。

### class_DecompressInputStream.md class_DecompressInputStream.md
本文档是Cangjie语言中DecompressInputStream类的API参考文档，旨在指导开发者如何对输入流进行数据解压。主要内容包括类的构造函数配置、read方法的数据读取与解压逻辑、close方法的资源释放机制，以及完整的代码示例演示。关键点在于支持自定义解压格式（如DeflateFormat）和缓冲区大小，必须显式调用close以防止内存泄漏，并处理ZlibException异常。适用于需要在Cangjie项目中实现zlib数据解压功能的开发人员。

### class_DecompressOutputStream.md class_DecompressOutputStream.md
这份文档是Cangjie语言中DecompressOutputStream类的API参考文档，旨在说明如何创建和管理解压输出流。文档主要涵盖了类的构造函数、close、flush及write等核心成员方法，详细阐述了参数配置（如WrapType和缓冲区大小）以及ZlibException异常处理机制。关键信息指出该类继承自OutputStream，通过绑定底层输出流实现数据的解压与写入，并提供了包含压缩与解压全流程的代码示例。该文档面向使用stdx.compress.zlib包进行数据流处理的开发者，要求具备基本的流处理和异常处理知识。
