# 创建轮播Swiper

This directory provides comprehensive technical documentation for implementing and configuring the Swiper component to create sliding carousels in Cangjie applications using the ArkUI framework. It covers a wide range of functionalities, from basic layout constraints and loop control to advanced features like automatic playback and navigation point customization. The guides also delve into complex configurations such as programmatic page switching, vertical scrolling modes, and multi-item display layouts. Designed for UI developers, these resources include code examples and visual references to help optimize user experience and implement custom navigation behaviors effectively. This collection is essential for developers seeking to master dynamic content presentation in their applications.
