# class_HidHostProfile

This directory provides comprehensive API reference documentation for the `HidHostProfile` class in the Cangjie language, part of the HarmonyOS ConnectivityKit. It focuses on managing Bluetooth Human Interface Device (HID) connections, detailing how to retrieve connected devices, check connection states, and handle asynchronous event callbacks. Key technical aspects include permission requirements (`ohos.permission.ACCESS_BLUETOOTH`), random MAC address security, and business exception handling. This resource is intended for developers and system engineers implementing Bluetooth HID profiles, requiring a solid understanding of Cangjie programming and HarmonyOS system capabilities.
