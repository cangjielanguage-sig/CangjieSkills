# cj-graphic-drawing-ellipse

本目录包含ArkUI框架中Ellipse椭圆绘制组件的API参考文档，旨在为使用仓颉（Cangjie）语言进行图形界面开发的开发者提供指导。文档全面涵盖了模块导入方式、组件初始化方法（支持自定义宽高参数）、以及通用属性和事件的支持情况。特别指出该组件目前处于Beta阶段，起始版本为22。此外，文档还提供了详细的Cangjie代码示例，演示了如何创建实心椭圆及空心椭圆环，并解释了参数默认值的处理逻辑及图形绘制通用属性的引用方式。这份文档非常适合具备ArkUI基础的开发者查阅，以实现复杂的图形绘制需求。
