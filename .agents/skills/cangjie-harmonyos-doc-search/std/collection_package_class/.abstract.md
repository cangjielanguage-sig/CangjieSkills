This directory serves as a comprehensive API reference for the core collection classes within the Cangjie programming language. It covers essential data structures such as dynamic arrays, linked lists, hash maps, sets, queues, and stacks, alongside iterators and node definitions. The documentation focuses on class definitions, constructors, properties, and manipulation methods, emphasizing efficient data management and algorithmic implementation. It is designed for Cangjie developers who need to implement robust data handling solutions, requiring familiarity with generic types, interfaces like `Hashable` and `Comparable`, and standard collection operations to build scalable, high-performance applications. This reference is crucial for anyone looking to master the standard library's data handling capabilities.
