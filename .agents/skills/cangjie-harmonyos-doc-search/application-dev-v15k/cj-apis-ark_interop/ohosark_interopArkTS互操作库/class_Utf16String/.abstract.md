This directory contains API reference documentation for the `Utf16String` class in the Cangjie programming language, specifically designed for HarmonyOS development. It focuses on efficient UTF-16 string storage, ArkTS interoperability, and optimized performance for JavaScript interactions. The documentation covers class definitions, properties, operator overloads, and various string manipulation methods including searching, splitting, and memory management. It is suitable for Cangjie developers working within the ArkUI ecosystem who need to handle text processing and cross-language data exchange with high efficiency.
