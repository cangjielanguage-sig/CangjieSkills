This directory contains Cangjie code examples focused on implementing user authentication using the UserAuthenticationKit. It covers various scenarios including basic biometric (Face) and PIN authentication at specific trust levels, as well as advanced features like reusing device unlock states and cross-application authentication. The examples demonstrate how to configure authentication parameters (`AuthParam`), manage UI widgets, handle asynchronous callbacks, and manage exceptions. These resources are suitable for developers integrating secure biometric verification and credential management into their applications, providing practical implementations for handling security workflows, trust level configurations, and the complete authentication lifecycle.
