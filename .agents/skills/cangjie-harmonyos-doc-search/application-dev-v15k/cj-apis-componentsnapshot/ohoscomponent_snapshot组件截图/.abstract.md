This directory contains API reference documentation for the `ohos.component_snapshot` module and related classes within the Cangjie UIKit framework. It focuses on enabling developers to capture screenshots of UI components, covering both loaded and unloaded elements. Key topics include configuration options for scaling and rendering synchronization, as well as methods for asynchronous, synchronous, and off-screen rendering. This documentation is suitable for HarmonyOS and ArkUI developers using the Cangjie language who need to implement precise image capture features, handle visual effects, or manage component rendering boundaries in their applications.
