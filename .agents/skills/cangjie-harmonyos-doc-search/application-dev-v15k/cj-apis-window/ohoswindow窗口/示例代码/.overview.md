# 示例代码

This directory contains a collection of Cangjie code examples specifically curated for HarmonyOS application development, with a strong focus on advanced window management and event handling mechanisms. It covers essential techniques such as configuring main window touchability to control user interaction, dynamically monitoring keyboard height changes for layout adjustments, and creating modal sub-windows with specific callback behaviors. The examples leverage core components like WindowStage, AppStorage, and ArkUI to demonstrate practical implementations of window properties and user interaction events. This resource is highly suitable for developers who are already familiar with the Cangjie language and the HarmonyOS application lifecycle and are looking to implement sophisticated multi-window interactions and responsive UI behaviors in their projects. By studying these examples, developers can better understand how to manipulate window stages and handle system-level events effectively.

### 示例1获取主窗口设置不可触属性_2more.md 示例1获取主窗口设置不可触属性_2more.md
This technical tutorial provides comprehensive Cangjie code examples for managing main window properties and events within the HarmonyOS development environment. The document is logically divided into two primary sections: setting window touchability and monitoring keyboard height changes. Key takeaways include the specific usage of `setWindowTouchable(false)` to effectively disable user interaction on the main window, as well as implementing event listeners for keyboard height adjustments using a custom callback class. The examples utilize essential components such as WindowStage, AppStorage, and ArkUI components to illustrate these concepts. This guide is intended for developers familiar with Cangjie and the HarmonyOS application lifecycle who are seeking to implement advanced window management features and responsive layouts.

### 示例3设置子窗口回调函数.md 示例3设置子窗口回调函数.md
This tutorial offers a practical demonstration of how to create a modal sub-window in a Cangjie application and implement a callback mechanism to close it when the user clicks outside the designated window area. The code covers critical steps including MainAbility initialization, storing the WindowStage in AppStorage for global access, and configuring SubWindowOptions with the `isModal` property. Key takeaways include using the `on` method to listen for `DialogTargetTouch` events and managing window properties like grayscale. This guide is intended for developers using the Cangjie language and ArkUI framework who need to handle complex multi-window interactions and modal behaviors in HarmonyOS applications.
