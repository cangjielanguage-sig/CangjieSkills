This directory contains documentation for `hiperf`, a cross-platform command-line tool designed for developers to capture and debug performance data, similar to the Linux `perf` tool. It covers essential commands for logging, sampling, and reporting, alongside Python scripts for generating visual flame graphs in OpenHarmony environments. Key topics include hardware/software event monitoring, callstack recording, and data visualization. This resource is suitable for system performance engineers and developers seeking to analyze application behavior, optimize system resources, and debug performance issues on connected devices.
