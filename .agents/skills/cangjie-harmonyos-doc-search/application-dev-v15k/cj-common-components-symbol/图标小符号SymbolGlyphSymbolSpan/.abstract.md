This directory focuses on the usage of SymbolGlyph and SymbolSpan components within the HarmonyOS ArkUI framework using the Cangjie language. It covers rendering standalone icons, embedding icons within text, managing events, and creating custom animations. Key topics include system resource referencing via @r syntax, state management with @State, and visual effect strategies. This resource is suitable for application developers and engineers working on HarmonyOS or OpenHarmony ecosystems who need to implement dynamic, interactive, and visually rich iconography in their user interfaces.
