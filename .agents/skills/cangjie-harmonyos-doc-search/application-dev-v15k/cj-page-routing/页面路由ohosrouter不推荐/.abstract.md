This directory provides comprehensive documentation on the `ohos.router` module for page navigation within HarmonyOS and Cangjie applications. It covers essential routing operations, including page jumping, returning to previous or specific pages, passing data, and managing the page stack lifecycle. Additionally, it addresses user experience enhancements such as adding confirmation dialogs before navigation to prevent data loss. Crucially, the content marks this module as not recommended for new development, advising developers to adopt the Navigation component for better functionality. This resource is suitable for HarmonyOS and Cangjie developers maintaining legacy code or seeking to understand routing mechanics before migrating to the recommended framework.
