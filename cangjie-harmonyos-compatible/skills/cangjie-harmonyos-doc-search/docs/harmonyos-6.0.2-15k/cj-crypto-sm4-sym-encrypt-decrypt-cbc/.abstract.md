This directory serves as a specialized technical repository focused on the implementation of SM4 symmetric encryption and decryption utilizing the Cipher Block Chaining (CBC) mode and PKCS7 padding within the Cangjie programming language environment. It comprehensively addresses the critical workflows necessary for secure data handling, specifically detailing the generation of cryptographically secure 128-bit symmetric keys, the instantiation of Cipher objects, and the secure management of initialization vectors (IVs) through the CryptoArchitectureKit. The resource is meticulously crafted for software developers and security engineers aiming to embed high-grade cryptographic capabilities into their Cangjie-based applications. By combining theoretical step-by-step guidance with practical, executable code examples, this directory empowers users to successfully implement and validate security features, ensuring efficient handling of both segmented and synchronous data processing scenarios. This collection stands as a vital reference for mastering cryptographic standards in the Cangjie ecosystem.
