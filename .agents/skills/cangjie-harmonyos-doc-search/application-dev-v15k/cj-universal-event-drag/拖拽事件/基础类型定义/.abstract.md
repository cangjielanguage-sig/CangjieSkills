This directory provides fundamental type definitions and API references for implementing drag-and-drop functionality within the ArkUI framework using the Cangjie language. It covers essential classes, structs, and enumerations that manage drag behaviors, event states, and visual configurations. Key components include `DragInfo`, `DragBehavior`, `PreDragStatus`, and `DragEvent`, which collectively handle data transfer, gesture recognition, and animation control. This documentation is suitable for developers and UI engineers building interactive applications requiring precise drag-and-drop mechanics and custom visual feedback.
