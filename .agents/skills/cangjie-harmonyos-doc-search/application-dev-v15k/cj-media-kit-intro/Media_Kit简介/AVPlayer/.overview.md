# AVPlayer

The AVPlayer directory provides essential technical documentation for the AVPlayer component, a system designed to handle media resource transcoding and playback for applications. It covers the complete architecture and data flow for both Audio and Video workflows, explaining how the Player Framework routes data to the Audio Framework and Graphic Framework via respective HDIs. Key technical concepts include the separation of software and hardware decoding, the use of XComponent for video surfaces, and the abstraction provided by the Cangjie interface layer. Furthermore, it serves as a reference for supported media specifications, including protocols, audio/video codecs, and subtitle formats. It is particularly relevant for ensuring compatibility across different media types and optimizing performance through hardware acceleration. This documentation is tailored for application developers seeking to implement robust media playback features without managing the complexities of low-level parsing or decoding.

## Detailed Description

### AVPlayer_3more.md AVPlayer_3more.md
This document outlines the architecture and data flow of the AVPlayer component, which handles media resource transcoding and playback for applications. It details two main workflows: Audio Playback and Video Playback. The text explains how the Player Framework processes media streams, routing audio data to the Audio Framework and Audio HDI, while video data is decoded and sent via the Graphic Framework and Display HDI. Key concepts include the use of XComponent for video surfaces and the separation of software and hardware decoding. This technical guide is intended for developers using the Cangjie interface layer to implement integrated media playback features without managing low-level parsing or decoding.

### 支持的格式与协议.md 支持的格式与协议.md
This reference document outlines the supported media formats, protocols, and technical specifications for a video playback system. It categorizes information into supported protocols (local, network VOD, and live streaming), audio formats (AAC, MP3, etc.), video containers (MP4, MKV, TS), and subtitle support (SRT, VTT). Key takeaways include the requirement for file descriptors in local playback, the mandatory support for H264 and H265 codecs, and specific constraints regarding DASH internal subtitles. The document targets application developers, advising them to use mainstream formats to avoid compatibility issues like stuttering or artifacts.
