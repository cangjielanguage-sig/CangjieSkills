This directory contains comprehensive code examples for implementing video recording functionality, primarily focusing on the HarmonyOS ecosystem using the Cangjie programming language. It covers the entire development lifecycle, from initializing the CameraKit and configuring AVRecorder profiles to managing camera sessions and handling resource cleanup. Key topics include custom callback definitions, status listeners, video mode support, aspect ratio matching, and dynamic codec selection for HDR formats. These examples are suitable for HarmonyOS developers and multimedia engineers looking to integrate robust video capture and recording capabilities into their applications.
