This directory provides comprehensive resources for integrating Cangjie modules into ArkTS applications within the HarmonyOS ecosystem. It covers the fundamental concepts of the Cangjie language, practical implementation guides for cross-language interoperability using declarative macros, and references to official API documentation. Key topics include the lightweight runtime, high concurrency features, and specific steps for module integration using DevEco Studio. This content is suitable for HarmonyOS developers and system architects looking to leverage Cangjie for high-performance scenarios and cross-language functionality.
