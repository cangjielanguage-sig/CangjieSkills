# class_ScanFilter

This directory provides API reference documentation for the `ScanFilter` class in the Cangjie programming language, focusing on defining parameters for filtering Bluetooth Low Energy (BLE) device scans. The content details the class structure, emphasizing public properties such as device identifiers, names, service UUIDs, service data, and manufacturer-specific information like IDs and data masks. Key takeaways include the specific data types for each filter parameter, such as nullable Strings and Byte arrays, alongside the system capability requirement `SystemCapability.Communication.Bluetooth.Core` starting from version 19. This reference is intended for software developers integrating Bluetooth scanning functionalities into applications, requiring knowledge of Cangjie syntax and BLE protocols.
