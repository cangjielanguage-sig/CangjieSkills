# RSA

This directory provides comprehensive technical documentation for implementing RSA asymmetric encryption within the Cangjie framework. It covers essential padding schemes such as NoPadding, PKCS1, and PKCS1_OAEP, detailing data length constraints, key type mappings, and specific parameter configurations. The resources also address the management of OAEP parameters, including message digests and mask generation functions. Designed for developers and security engineers, these guides assist in selecting appropriate encryption modes, managing API version 12+ compatibility, and ensuring secure cryptographic configurations.

## Detailed Description

### RSA_3more.md RSA_3more.md
This technical reference document details RSA asymmetric encryption modes supported by the Cangjie framework, focusing on padding schemes and data length constraints. It covers three specific modes: NoPadding, PKCS1, and PKCS1_OAEP, explaining their input/output length requirements and specific parameters like digests and mask generation functions. The document provides tables mapping key types to string parameters (e.g., "RSA2048|PKCS1") for API version 12+. It highlights that output length always matches the key length and warns of performance costs for large keys or long plaintexts in synchronous operations. This guide targets developers implementing cryptography in Cangjie who need to select appropriate padding modes and manage data length limits.

### 获取设置OAEP填充模式的参数.md 获取设置OAEP填充模式的参数.md
This document serves as a technical reference for managing OAEP padding parameters in RSA encryption, specifically for API version 12 and later. It details the specific parameters involved in PKCS1_OAEP padding, including message digest (md), mask generation function (mgf), MGF1 digest (mgf1_md), and the encoding parameter source (pSource). The provided table clarifies the read and write capabilities for each parameter using specific enum values. Notably, only the pSource parameter supports both getting and setting, while the others are read-only. This guide targets software developers and security engineers implementing cryptographic operations who need to understand parameter accessibility within the API.
