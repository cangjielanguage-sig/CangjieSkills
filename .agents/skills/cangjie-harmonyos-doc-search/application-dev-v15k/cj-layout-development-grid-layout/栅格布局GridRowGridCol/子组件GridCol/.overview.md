# 子组件GridCol

This directory contains technical documentation for the `GridCol` component within the ArkUI framework using the Cangjie language. It focuses on configuring child components within a `GridRow` system to create responsive and flexible grid layouts. Key topics include controlling column width (`span`), spacing (`offset`), and visual ordering (`order`) across various device breakpoints. This resource is suitable for UI developers and interface designers looking to implement adaptive grid systems in their applications.

## Detailed Description

### offset.md
This document defines the offset attribute used in grid layouts to specify the column spacing between child components relative to the previous one. It covers two data types: Int32 for fixed offsets and GridColColumnOption for responsive design across six device breakpoints (xs, sm, md, lg, xl, xxl). Key information includes the default value of 0 and explanations of how offsets interact with the standard 12-column grid system, supported by Cangjie code examples. This technical reference is intended for UI developers using the ArkUI framework to implement flexible and responsive grid layouts.

### order.md
This reference documentation explains the `order` attribute used to control the layout sequence of child components within a grid system. It covers sorting logic for unset, equal, and different values, and details two data types: `Int32` for static ordering and `GridColColumnOption` for responsive design across six breakpoints. Key takeaways include that components without an order appear first, followed by those with ascending values. The document provides Cangjie code examples demonstrating how to reorder grid columns visually regardless of their code sequence. This guide targets UI developers using the ArkUI framework with Cangjie who need to manage component arrangement and responsive layouts.

### 子组件GridCol_2more.md
This document serves as a technical reference for the GridCol component, explaining how to configure layout properties within a GridRow system using the Cangjie language. It details the usage of span, offset, and order attributes, offering specific code examples for parameter passing and property setting. The text highlights the span attribute, which determines component width, distinguishing between fixed integer values for uniform layouts and GridColColumnOption for responsive design across six device breakpoints. Targeted at UI developers, this guide provides practical examples for implementing both static and adaptive grid layouts in application interfaces.
