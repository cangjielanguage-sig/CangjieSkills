## 详细描述

### Flow_表达式.md Flow_表达式.md
本文档旨在介绍仓颉语言中的流表达式，用于简化数据处理和函数组合。主要涵盖Pipeline表达式（`|>`）和Composition表达式（`~>`）的定义、语法糖形式及类型兼容性要求。文档详细解释了Pipeline的数据流向机制和Composition的函数组合逻辑，并指出了操作符的求值顺序及与命名参数函数交互时的限制。这是一份面向仓颉开发者的语言特性参考文档，适合具备基础语法的开发者阅读。

### 变长参数_afca7e87.md 变长参数_afca7e87.md
本文档详细阐述了仓颉编程语言中变长参数的语法规则与使用场景。作为一种函数调用语法糖，它允许将参数序列直接传递给最后一个Array类型的形参。文档重点说明了变长参数仅适用于最后一个非命名参数，不支持命名参数，并列举了其适用的函数类型及操作符重载范围。此外，还解释了函数重载决议时的优先级逻辑，即优先匹配非变长参数版本。这是一份面向仓颉语言开发者的技术参考文档，旨在指导开发者正确应用此特性以简化代码编写。

### 尾随_lambda_11dd48e0.md 尾随_lambda_11dd48e0.md
本文档介绍仓颉语言中尾随 lambda 的语法，旨在通过模拟内置语法提升代码可读性与可扩展性。主要涵盖了将 lambda 置于圆括号外的调用规则，以及当 lambda 为唯一参数时省略圆括号的特殊用法。文档通过 `myIf` 和 `f` 函数示例，详细对比了普通调用与尾随 lambda 调用的区别，展示了简化代码的具体方法。该文档适合仓颉语言开发者阅读，帮助其掌握高阶函数的简洁写法。
