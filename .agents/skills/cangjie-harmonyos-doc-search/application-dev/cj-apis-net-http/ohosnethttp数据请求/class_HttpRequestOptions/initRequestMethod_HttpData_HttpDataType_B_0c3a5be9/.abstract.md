This directory contains technical documentation for the `initRequestMethod` API within the Cangjie programming language, specifically focusing on the initialization of HTTP request options. It serves as a comprehensive guide for configuring network communication, covering essential aspects such as request methods, data types, headers, and timeouts. The documentation also delves into advanced networking features, including DNS over HTTPS, SSL security configurations, proxy settings, and caching strategies. Designed for software developers and engineers working with the NetStack system capability, these resources provide the necessary parameters and structural definitions to build robust, secure, and customizable HTTP/HTTPS client applications. The files offer both high-level constructor definitions and granular parameter references to facilitate precise network control.
