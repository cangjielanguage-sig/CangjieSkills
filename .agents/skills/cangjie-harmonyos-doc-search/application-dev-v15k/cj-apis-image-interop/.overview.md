# cj-apis-image-interop

This directory contains the essential API documentation for the `cj-apis-image-interop` module, specifically focusing on the `ohos.image.interop` package. The core function of this module is to enable robust interoperability between Cangjie's native `PixelMap` data structures and the ArkTS runtime environment. It provides a detailed technical overview of the `JSSystemObjectInteropType` interface and the extended `PixelMap` class, highlighting the static and instance methods necessary for effective type conversion. Key functionalities include the `fromJSValue` method for transforming ArkTS JSValue into PixelMap, and the `toJSValue` method for the reverse conversion, both of which rely on a `JSContext` parameter. This documentation is specifically curated for Cangjie developers who are integrating image processing features across different language boundaries. Users are expected to have a working knowledge of the ImageKit framework and the specific interop mechanisms used within ArkTS to fully leverage the capabilities described herein.

## Detailed Description

### cj-apis-image-interop.md cj-apis-image-interop.md

This API reference document provides a comprehensive technical breakdown of the `ohos.image.interop` module. Its primary objective is to enable seamless interoperability between Cangjie's `PixelMap` objects and the ArkTS execution environments. The content covers the `JSSystemObjectInteropType` interface in detail and describes the extensions made to the `PixelMap` class, with a specific focus on the static and instance methods available for type conversion.

The documentation highlights critical functions such as `fromJSValue`, which is used to convert an ArkTS JSValue into a PixelMap, and `toJSValue`, which handles the reverse operation. Both functions are documented as requiring a `JSContext` parameter to function correctly. This resource is indispensable for Cangjie developers who need to bridge image processing capabilities with ArkTS, ensuring that data types are correctly translated between the two systems. It is assumed that readers have a prerequisite understanding of the ImageKit and ArkTS interop mechanisms to effectively apply the information provided.
