# 组件属性

This directory contains API reference documentation for the Cangjie ArkUI framework, focusing on the configuration and customization of component properties, specifically for text input and display controls like TextArea. It covers a wide range of functionalities including custom keyboards, text styling (fonts, spacing, colors), input validation, layout constraints, and user interaction behaviors such as selection and copy options. These documents provide detailed parameter definitions, system capabilities, and version requirements. This resource is suitable for HarmonyOS developers and UI engineers who need granular control over text rendering, input mechanisms, and component appearance within their applications.

Key information includes the ability to replace system input methods with custom UI components using customKeyboard, which supports overlay modes and gesture interception. Additionally, it explains how to set text decoration styles, toggle auto-fill features, and control keyboard activation behavior when elements gain focus. This guide is intended for developers building user interfaces who need granular control over input interactions and text presentation.

### func_showCounterBool_Float64_Bool.md
This document provides API reference details for the showCounter function, which configures a character counter display for text input components based on specific thresholds. It covers the function signature, system capabilities, version requirements, and a detailed parameter table explaining value, thresholdPercentage, and highlightBorder. Key information includes that the function requires maxlength to operate and displays the current character count relative to the maximum. It triggers visual warnings like red borders and shaking when input exceeds the defined percentage threshold. The thresholdPercentage must be between 1 and 100 to be effective. This is intended for ArkUI developers needing to implement input validation and user feedback mechanisms in their applications.
