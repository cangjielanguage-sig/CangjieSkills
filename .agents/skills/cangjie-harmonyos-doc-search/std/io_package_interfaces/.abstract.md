This directory serves as the central repository for API reference documentation concerning input/output stream interfaces within the Cangjie language's `io` package. It comprehensively covers four primary interfaces: `InputStream`, `OutputStream`, `IOStream`, and `Seekable`. The documentation details essential operations such as the `read` method for input streams, `write` and `flush` methods for output streams, and `seek` functionality for managing cursors via properties like `length` and `position`. Additionally, it defines `IOStream` as a composite interface that merges input and output capabilities. This documentation is tailored for software developers responsible for implementing or consuming stream-based IO operations, necessitating a strong grasp of Cangjie syntax and type systems. Core keywords for this section include Cangjie, API, interfaces, InputStream, OutputStream, Seekable, IOStream, byte array, and cursor.
