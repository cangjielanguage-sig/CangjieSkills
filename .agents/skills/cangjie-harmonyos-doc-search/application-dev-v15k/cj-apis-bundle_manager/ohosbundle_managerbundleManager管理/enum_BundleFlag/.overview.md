# enum_BundleFlag

This directory provides essential API documentation for the `BundleFlag` enumeration within the Cangjie language's BundleManager framework. It details the flags used to define the content scope when retrieving application package information, covering aspects such as HAP modules, abilities, extension abilities, permissions, signatures, and metadata. Furthermore, it includes references for utility functions like `getValue()` designed to access underlying enumeration values. This documentation is specifically suitable for Cangjie developers and system integrators who need to configure precise bundle info queries, manage application package data programmatically, and understand the complex dependencies between different bundle flags and their version requirements.

### enum_BundleFlag_13more.md enum_BundleFlag_13more.md
This file serves as the primary reference for the `BundleFlag` enumeration. The document details various enum values, including flags for default info, HAP modules, abilities, extension abilities, permissions, signatures, and metadata.
