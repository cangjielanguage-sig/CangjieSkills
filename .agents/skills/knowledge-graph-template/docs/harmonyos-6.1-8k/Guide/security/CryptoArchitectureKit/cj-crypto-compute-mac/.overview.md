## Detailed Description

### 消息认证码计算/

This subdirectory provides a comprehensive introduction to Message Authentication Codes (MAC) and Hash-based Message Authentication Codes (HMAC), focusing on their calculation methodologies and practical application scenarios in software security. The content thoroughly covers the basic concepts and working principles of MAC and HMAC, explaining how these algorithms function to validate the source and integrity of data. It details the supported algorithm specifications, including industry standards like SHA256 and the SM3 cryptographic hash function, offering flexibility for different compliance and security needs.

The documentation further breaks down specific development implementation steps, providing a roadmap for integrating these security features into Cangjie projects. By emphasizing the use of shared key mechanisms, it illustrates how to establish secure channels that guarantee data integrity and authenticity, effectively mitigating the risk of data tampering during transmission. This section is particularly suitable for Cangjie language developers and professionals involved in encryption application development. It serves as a complete reference guide, covering the entire lifecycle from theoretical algorithm selection and analysis to practical code implementation, enabling developers to effectively perform data integrity verification and enhance the security posture of their applications.
