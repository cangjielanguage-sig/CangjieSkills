# 开发案例

This directory contains development examples and tutorials focused on implementing cryptographic operations using the Cangjie programming language and the HarmonyOS Universal Keystore Kit (HUKS). It covers a range of algorithms including AES (CBC, GCM), RSA (ECB with various paddings), and SM2. The content details the complete lifecycle of key management, such as generation, encryption, decryption, and deletion, utilizing session-based workflows. It is suitable for developers working within the HarmonyOS ecosystem who need to secure data storage and transmission through standard and advanced cryptographic techniques.

## Detailed Description

### AESCBCPKCS7.md AESCBCPKCS7.md
This document provides a Cangjie code example demonstrating how to perform AES encryption and decryption using the CBC mode and PKCS7 padding within the Universal Keystore Kit. It covers key generation, data encryption, data decryption, and key deletion. The code details the configuration of cryptographic properties, including algorithm selection, key size, padding, block mode, and initialization vector (IV) usage. Key takeaways include the use of HuksParam for setting cryptographic attributes and the session-based workflow involving initSession and finishSession for secure operations. It emphasizes the importance of using a random IV in production environments. This tutorial targets developers working with the HarmonyOS Universal Keystore Service (HUKS) who need to implement secure data storage or transmission using AES/CBC/PKCS7 in Cangjie.

### AESGCMNoPadding/
This directory provides comprehensive technical documentation and code tutorials for implementing AES-GCM (Galois/Counter Mode) encryption without padding using the Cangjie language and the HarmonyOS Universal Keystore Kit (HUKS). It covers the complete cryptographic lifecycle, detailing the processes of generating AES keys, encrypting plaintext, decrypting ciphertext, and securely deleting keys. Key technical concepts include HuksParam configuration, algorithm selection, and the management of GCM-specific parameters such as Nonce, Associated Data (AAD), and the AE Tag. This resource is specifically designed for developers operating within the HarmonyOS ecosystem who require robust solutions for secure data storage and transmission, as well as effective key lifecycle management.
