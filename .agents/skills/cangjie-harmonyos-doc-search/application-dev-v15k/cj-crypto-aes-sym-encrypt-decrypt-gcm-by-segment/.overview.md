# cj-crypto-aes-sym-encrypt-decrypt-gcm-by-segment

This project provides a detailed technical implementation of AES symmetric encryption using the Galois/Counter Mode (GCM) with segmented processing, specifically developed for the Cangjie programming language. It addresses the critical need for secure data handling by breaking down large files into manageable segments, thereby optimizing memory usage and processing speed. The guide covers the complete lifecycle of encryption and decryption, including the generation and management of Initialization Vectors (IV) and the verification of Authentication Tags to prevent tampering. By utilizing the CryptoArchitectureKit, the project demonstrates how to effectively implement AES-128 and PKCS7 padding standards within the Cangjie ecosystem. This resource is invaluable for Cangjie developers and security engineers who require a reliable, production-grade solution for integrating robust cryptographic features into their software, ensuring secure data transmission and storage against modern threats.

## Detailed Description

### [1] 使用AES对称密钥GCM模式分段加解密仓颉/
This directory focuses on implementing AES symmetric encryption in GCM mode with segmented processing using the Cangjie programming language. It provides a deep dive into the technical workflow for encryption and decryption, ensuring developers understand how to securely manage cryptographic parameters. Specifically, it covers the handling of initialization vectors (IV) and authentication tags, which are crucial for the security of the GCM mode. The implementation details chunked data processing via the CryptoArchitectureKit, allowing for efficient handling of large data streams. Key topics explored in this directory include AES-128 encryption standards, PKCS7 padding implementation, and general secure data handling practices for large files. This resource is suitable for Cangjie developers and security engineers looking to integrate robust cryptographic features into their applications for secure data transmission and storage.
