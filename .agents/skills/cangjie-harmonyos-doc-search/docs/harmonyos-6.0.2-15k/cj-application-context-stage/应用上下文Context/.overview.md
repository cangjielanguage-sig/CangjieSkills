# 应用上下文Context

This directory focuses on the Context mechanism within the HarmonyOS development framework, specifically designed for the Cangjie language. It comprehensively covers the fundamental definitions, inheritance structures, and holding relationships of the Context class, alongside specific implementations like UIAbilityContext and AbilityStageContext. The content details typical usage scenarios, including retrieving application file paths, accessing encrypted partitions for secure data storage, obtaining Context instances for cross-module interaction, and subscribing to intra-process Ability lifecycle changes. By providing practical guides and code examples, it equips developers with techniques for system resource management, data persistence, and component interaction. This documentation is suitable for application developers and engineers using the AbilityKit framework who need to understand context management, application-wide state configuration, and robust local storage implementation.
