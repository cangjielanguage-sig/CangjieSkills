This directory provides comprehensive API reference documentation for the `Locale` class within the Cangjie LocalizationKit. It is designed to assist developers in implementing internationalization (I18n) features by managing locale-specific data, cultural formatting rules, and regional settings. The documentation covers the class structure, constructors, read-only properties, and methods for locale manipulation. It is suitable for Cangjie software developers who need to handle localization, manage language tags, or ensure their applications adapt to specific regional requirements effectively. The content ensures users understand how to access system capabilities like SystemCapability.Global.I18n and utilize specific locale identifiers for robust global application support.
