# class_AlertDialog

This directory contains API reference documentation for the `AlertDialog` class within the Cangjie programming language and the ArkUI framework. It comprehensively covers the construction and display of modal alert pop-ups, focusing on class definitions and overloaded static `show` methods. Key topics include configuring dialogs using parameters like `AlertDialogParamWithConfirm` and `AlertDialogParamWithButtons`, as well as advanced shadow customization options introduced in API version 19. The documentation details the necessary system capabilities, specifically SystemCapability.ArkUI.ArkUI.Full. This technical resource is intended for software developers and application engineers looking to implement user notifications and modal alerts with specific styling in their Cangjie-based applications.

## Detailed Description

### class_AlertDialog_7more.md
This document serves as API reference documentation for the AlertDialog class in the Cangjie programming language, detailing how to construct and display alert pop-ups within the ArkUI framework. The content focuses on the class definition and several overloaded static show methods. Key sections explain how to configure dialogs using AlertDialogParamWithConfirm or AlertDialogParamWithButtons, with specific overloads introduced in API version 19 to support shadow customization via ActionSheetShadowOptions or ShadowStyle. All functions require the SystemCapability.ArkUI.ArkUI.Full system capability. This technical guide is intended for software developers seeking to implement modal alerts and user notifications in their applications. Keywords: AlertDialog, Cangjie, ArkUI, API reference, show method, shadow options, AlertDialogParamWithConfirm, AlertDialogParamWithButtons.

### static_func_showAlertDialo_3more.md
This API reference document details the static functions used to define and display AlertDialog components in the Cangjie language. It covers three overloaded show methods: a basic version accepting dialog parameters, and two extended versions that accept additional shadow configuration parameters (ActionSheetShadowOptions or ShadowStyle). Key information includes the mandatory AlertDialogParamWithOptions parameter and the introduction of shadow support in API version 19, whereas the basic function started in version 12. All functions return Unit and belong to the ArkUI system capability. This guide targets application developers using the Cangjie language who need to implement alert dialogs with or without specific shadow styling in their UI.
