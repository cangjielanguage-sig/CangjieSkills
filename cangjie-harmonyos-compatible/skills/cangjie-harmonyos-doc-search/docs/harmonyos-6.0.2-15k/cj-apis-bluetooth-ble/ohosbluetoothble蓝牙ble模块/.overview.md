# ohosbluetoothble蓝牙ble模块

This directory contains API reference documentation for the `ohos.bluetooth.ble` module in the Cangjie programming language, designed for HarmonyOS application development. It covers comprehensive Bluetooth Low Energy (BLE) functionalities, including advertising, scanning, GATT server and client operations, and data management. Key components include classes for configuring broadcast packets, managing connection states, and handling characteristic interactions. Suitable for software developers and system integrators, this module requires the `SystemCapability.Communication.Bluetooth.Core` capability and targets API version 19 and above. It provides the necessary tools to implement robust BLE communication features in Cangjie projects.

## Detailed Description

### class_AdvertiseData.md
Defines the AdvertiseData class for configuring BLE advertising packet contents, including serviceUuids, manufactureData, and serviceData. It enforces a 31-byte limit for broadcast packets.

### class_AdvertiseSetting.md
Defines the AdvertiseSetting class for configuring BLE advertising parameters such as connectable status, interval, and txPower, including valid ranges and defaults.

### class_AdvertisingDisablePa_2more.md
Documents classes for managing advertising parameters: `AdvertisingDisableParams` for stopping broadcasts and `AdvertisingEnableParams` for starting them, utilizing an advertisingId.

### class_AdvertisingParams.md
Details the AdvertisingParams class used to configure initial BLE advertising settings, covering data, response, settings, and duration (in 10ms units).

### class_AdvertisingStateChangeInfo.md
Documents the AdvertisingStateChangeInfo class, which describes state changes (starting or stopping) via advertisingId and state enum properties.

### class_BLECharacteristic.md
Defines the BLECharacteristic class for BLE characteristic interface parameters, including UUIDs, values, descriptors, and GATT properties.

### class_BLEConnectionChangeState.md
Models the GATT connection state with properties for deviceId (remote address) and state (ProfileConnectionState).

### class_BLEDescriptor.md
Defines the BLEDescriptor class for BLE descriptor interface parameters, including service, characteristic, and descriptor UUIDs and values.

### class_CharacteristicReadRequest.md
Encapsulates parameters for server-side characteristic read requests, including deviceId, transId, offset, and relevant UUIDs.

### class_DescriptorReadRequest.md
Encapsulates parameters for server-side descriptor read requests, requiring specific UUIDs and transaction matching for responses.

### class_GattProperties.md
Defines the GattProperties class to configure GATT characteristic attributes like write, read, notify, and indicate permissions.

### class_GattService.md
Defines the GattService class for GATT service parameters, including serviceUuid, primary status, characteristics, and included services.

### class_ManufactureData.md
Models BLE broadcast data content with manufactureId (UInt16) and manufactureValue (byte array).

### class_NotifyCharacteristic.md
Structures parameters for server-side characteristic notifications, distinguishing between notifications and indications via the confirm property.

### class_ScanOptions.md
Configures BLE scanning parameters such as interval, dutyMode, matchMode, and phyType to customize scan behavior.

### class_ScanResult.md
Reports data from Bluetooth device scans, including connectable status, raw data, deviceId, deviceName, and rssi.

### class_ServerResponse.md
Encapsulates server-to-client response parameters for read/write operations, including status, transId, offset, and value.

### class_ServiceData.md
Represents service data content within broadcast packets, mapping a service UUID to a byte array value.

### enum_AdvertisingState.md
Enum for managing advertising states: STARTED, STOPPED, ENABLED, and DISABLED, with standard comparison utilities.

### enum_BluetoothBleCallbackType.md
Enum for BLE advertising and scanning subscription events, such as ADVERTISING_STATE_CHANGE and BLE_DEVICE_FIND.

### enum_BluetoothBleGattClientDeviceCallbackType.md
Enum for GATT client callback events, including characteristic changes, connection state updates, and MTU changes.

### enum_BluetoothBleGattServerCallbackType.md
Enum for GATT server callback events, covering characteristic read/write operations, descriptor access, and connection changes.

### enum_GattWriteType.md
Enum for GATT write operations: WRITE (requires response) and WRITE_NO_RESPONSE.

### enum_MatchMode.md
Enum for hardware filtering thresholds during scanning: MATCH_MODE_AGGRESSIVE (low threshold) and MATCH_MODE_STICKY (high threshold).

### enum_PhyType.md
Enum for Bluetooth physical layer types during scanning, such as PHY_LE_1M and PHY_LE_ALL_SUPPORTED.

### enum_ScanDuty.md
Enum for scan operational modes: Low Power, Balanced, and Low Latency.
