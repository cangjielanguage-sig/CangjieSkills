# 创建自定义组件

This directory focuses on the creation and structuring of custom components within the ArkUI framework using the Cangjie programming language. It covers essential concepts such as component architecture, the specific syntax rules for the `build()` function, and parameter initialization for data flow. Key topics include the use of decorators like `@Component` and `@Entry`, constraints on UI rendering logic, and methods for handling events between parent and child components. This resource is suitable for HarmonyOS developers and UI engineers seeking to enhance code reusability and encapsulate business logic effectively.

## Detailed Description

### build函数.md build函数.md
This reference guide defines the syntax rules and constraints for the `build()` function used in UI description within the Cangjie language framework. It details root node requirements for `@Entry` and `@Component` decorators, and lists specific prohibitions regarding local variables, logging, scopes, and control flow syntax. Key takeaways include the requirement for a unique root node, the restriction against ForEach as a root, the necessity of using `@Builder` for rendering methods, and the prohibition of direct state variable modification within the function. This guide targets HarmonyOS developers using Cangjie who need to structure UI components correctly and avoid compilation errors.

### 创建自定义组件_4more.md 创建自定义组件_4more.md
This guide explains how to create and structure custom components in ArkUI using the Cangjie language to enhance code reusability and separate business logic from UI. It covers component characteristics, basic usage examples, and structural requirements including the `@Component`, `@Entry`, and `@Reusable` decorators, alongside the mandatory `build()` function. Key information includes that custom components are class-based without inheritance, have private members, and are limited to 128 members per class. The document targets ArkUI developers using Cangjie who need to encapsulate UI elements and logic into reusable modules.

### 自定义组件的参数规定.md 自定义组件的参数规定.md
This document outlines the rules and syntax for initializing parameters when creating custom components in the Cangjie programming language. It covers two primary scenarios: initializing basic member variables such as integers and colors, and passing function callbacks from parent to child components. Key takeaways include the use of the build method for component instantiation and the syntax for passing member properties and methods like submit to handle events. The document serves as a practical tutorial for developers, illustrating how to establish data flow and interaction between components using the `@Component` macro. It is intended for UI developers working with Cangjie and HarmonyOS who require knowledge of component parameterization and event handling.
