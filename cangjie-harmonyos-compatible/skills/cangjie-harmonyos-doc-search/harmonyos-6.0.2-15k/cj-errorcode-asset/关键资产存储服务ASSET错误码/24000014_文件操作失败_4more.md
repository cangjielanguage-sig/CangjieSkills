## 24000014 文件操作失败

**错误信息**

The file operation failed.

**可能原因**

1. 业务手动删除了设备中data/service/el1/public/asset_service某一级目录。
2. 文件系统损坏。

**处理步骤**

重启设备，若仍未解决，请恢复出厂设置。

## 24000015 获取系统时间失败

**错误信息**

Getting the system time failed.

**可能原因**

系统时间被篡改。

**处理步骤**

调整成正确的系统时间。

## 24000016 缓存数量超限

**错误信息**

The cache exceeds the limit.

**可能原因**

业务调用[preQuery](../apis/AssetStoreKit/cj-apis-asset_store.md#func-prequeryarrayassetparam)预查询后，没有通过[postQuery](../apis/AssetStoreKit/cj-apis-asset_store.md#func-postqueryarrayassetparam)释放资源。

**处理步骤**

业务调用[preQuery](../apis/AssetStoreKit/cj-apis-asset_store.md#func-prequeryarrayassetparam)预查询后，通过[postQuery](../apis/AssetStoreKit/cj-apis-asset_store.md#func-postqueryarrayassetparam)释放资源。

## 24000017 该子功能不支持

**错误信息**

The capability is not supported.

**可能原因**

支持API，但是不支持API内部某些子特性（功能），如批量查询关键资产明文。

**处理步骤**

调整API参数，使用可替代的调用方式，如多次调用API查询关键资产。
