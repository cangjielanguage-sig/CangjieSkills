# json_package_api

This directory serves as the central API documentation hub for the Cangjie language's `encoding_json` package. It provides a comprehensive technical reference covering the essential components required for JSON data manipulation, including core class definitions, enumeration types, exception handling mechanisms, and interface specifications for serialization and deserialization. Designed for Cangjie developers, this documentation offers the structural blueprints necessary for building robust applications that handle JSON parsing, generation, and data binding. It ensures type safety, data integrity, and effective error management during JSON operations.

## Detailed Description

### encoding_json_package_classes
This directory serves as a comprehensive technical reference for the core class definitions within the Cangjie language's JSON library. It is designed to provide developers with the structural blueprints necessary for building, manipulating, and serializing JSON data structures effectively.

### encoding_json_package_enums
This directory contains API reference documentation for enumeration types within the Cangjie language `encoding_json` package, focusing on the definition and usage of the `JsonKind` enumeration. The document details the mapping of various data types in the JSON standard to the Cangjie language, covering everything from basic nulls, booleans, and numeric types to complex strings, arrays, and object structures. By defining enumeration members such as `JsNull`, `JsBool`, and `JsInt`, the document provides developers with a type identification mechanism for recognizing and processing JSON data structures. This is crucial for ensuring type safety and data integrity during JSON parsing. This document is primarily intended for advanced Cangjie language developers.

### encoding_json_package_exceptions
This directory contains documentation regarding the exception handling mechanism within the JSON package, focusing on the `JsonException` class used for handling exceptional situations. The content covers the class definition, inheritance structure, and detailed descriptions of constructors, aiming to help developers effectively manage error scenarios when processing `JsonValue` types. This document is an API reference type, suitable for Cangjie language developers to consult when performing JSON data processing, error catching, and throwing. By mastering these exception handling mechanisms, developers can write more robust code involving JSON operations, ensuring that the program can respond correctly when encountering data format errors or processing exceptions.

### encoding_json_package_interfaces
This directory specifically collects API reference documentation for the `ToJson` interface in the `encoding_json` package. The core content is establishing the standard specification for bidirectional conversion between `JsonValue` and `DataModel`. The document deeply analyzes the mechanisms of JSON serialization and deserialization, detailing the interface definition, extension implementations for `DataModel`, and the specific usage, parameter types, and return values of the static method `fromJson` and instance method `toJson`. Additionally, it highlights the `JsonException` exceptions that may be encountered during the data conversion process. This document is designed for Cangjie language developers to understand and implement data conversion standards.
