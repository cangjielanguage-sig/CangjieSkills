This directory provides comprehensive API reference documentation for the `GeoCodeRequest` class designed for the Cangjie language. It covers the essential components required to construct and configure geocoding requests, allowing for the precise conversion of textual location descriptions into geographic coordinates. The documentation details public properties such as location strings, ISO 3166-1 alpha-2 country codes, and locale settings, alongside spatial constraints using WGS84 standards. It is intended for developers working on location services who need to filter search results by region, language, and specific coordinate boundaries.
