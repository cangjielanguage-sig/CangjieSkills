# class_RSAPrivateKey

This directory provides comprehensive API reference documentation for the `RSAPrivateKey` class in the Cangjie programming language. It is designed to assist developers in generating, decoding, and managing RSA private keys securely. The documentation covers essential functionalities such as key initialization with specific bit lengths and public exponents, decoding from DER and PEM formats (including password-protected keys), and performing cryptographic operations like decryption and digital signing. Key topics include PKCS1 compliance, key length constraints (512 to 16384 bits), and advanced security features like OAEP and PSS padding. This resource is suitable for software developers and security engineers implementing robust cryptographic solutions.
