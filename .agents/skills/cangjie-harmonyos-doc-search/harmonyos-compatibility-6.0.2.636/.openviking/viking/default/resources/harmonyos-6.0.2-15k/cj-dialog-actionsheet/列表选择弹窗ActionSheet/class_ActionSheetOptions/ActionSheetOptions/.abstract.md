This directory provides comprehensive API reference documentation for the `ActionSheetOptions` class, specifically designed for the Cangjie language and ArkUI framework. It serves as a guide for configuring and instantiating Action Sheet UI components, covering a wide array of parameters including content settings, layout properties, visual styles, and window behaviors. Key topics include defining titles and messages, managing interactive sheets, implementing modal masking, and handling dismissal callbacks. This documentation is essential for UI developers and software engineers who need to programmatically control the behavior, appearance, and animation effects of action sheets within their interactive applications.
