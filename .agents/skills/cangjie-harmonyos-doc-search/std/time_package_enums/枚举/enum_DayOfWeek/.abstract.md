This directory contains comprehensive API reference documentation for the `DayOfWeek` enum within the Cangjie language's time package. It covers the fundamental definition of the seven days of the week, ranging from Sunday to Saturday, and includes detailed methods for conversion between integers and strings. Furthermore, it provides essential information on operator overloading functions, enabling arithmetic and comparison operations such as addition, subtraction, and equality checks. This documentation is specifically suitable for Cangjie developers who need to implement robust date logic, calculate future or past days, or compare day values effectively in their software applications.
