This directory provides a specialized technical guide for developers utilizing the Cangjie programming language within the OpenHarmony ecosystem. It focuses specifically on the implementation details required to retrieve properties of cryptographic keys stored in the HUKS (OpenHarmony Universal Keystore). The content thoroughly covers essential prerequisites, such as the requirement for keys to be pre-generated or imported, and explicitly notes that this functionality is not supported on lightweight devices. It is highly suitable for Cangjie developers who need to integrate key management capabilities into their applications. The guide details the usage of the `getKeyItemProperties` interface, explains parameter constraints—including the 128-byte limit for key aliases—and provides a robust code example demonstrating error handling and the parsing of return objects to access the `properties` field.
