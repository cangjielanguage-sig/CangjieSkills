# extend_Rune

This directory contains API documentation for extending the `Rune` type in the Cangjie programming language, focusing on character encoding and classification utilities. It covers low-level UTF-8 manipulation, including encoding and decoding operations within byte arrays, as well as comprehensive ASCII character validation and conversion functions. Key topics include multi-byte character handling, ASCII range checks, case transformation, and memory usage calculation. It details specific static functions for byte-to-character conversion, instance methods for character classification, and utilities for determining UTF-8 byte lengths. This resource is suitable for Cangjie developers working on text processing, internationalization, or low-level data parsing who need robust tools for character data manipulation.

## Detailed Description

### extend_Rune_4more.md
This API documentation file details extensions for the Cangjie Rune type, specifically focusing on UTF-8 encoding and decoding operations within byte arrays. The document covers three static functions: fromUtf8 for converting bytes to characters, getPreviousFromUtf8 for locating character start indices, and intoUtf8Array for writing characters into byte arrays. Key takeaways include the handling of multi-byte character lengths, the return of tuples containing characters and indices, and the throwing of IllegalArgumentException for invalid sequences. This reference guide targets Cangjie developers who require low-level manipulation of UTF-8 byte sequences and character data.

### func_isAsciiOct_6more.md
This document serves as API reference documentation for character classification and conversion functions in the Cangjie programming language. It details six specific functions: isAsciiOct, isAsciiPunctuation, isAsciiUpperCase, isAsciiWhiteSpace, toAsciiLowerCase, and toAsciiUpperCase. Key information includes the functionality of each method, such as validating characters against specific ASCII ranges or converting character case, along with their respective return types of Bool or Rune. The target audience is Cangjie developers who need to manipulate or validate ASCII characters within their applications, providing essential utility for text processing tasks.

### static_func_utf8SizeArray_10more.md
This document serves as API reference documentation for the Cangjie programming language, detailing methods for the Rune type related to UTF-8 size calculation and ASCII character classification. The content covers two overloaded utf8Size static functions—one accepting a byte array and index, another accepting a single Rune—alongside multiple instance methods like isAscii, isAsciiControl, and isAsciiLetter. Key takeaways include the logic for determining UTF-8 byte lengths by scanning leading bytes and the specific ranges used to identify various ASCII character subsets. This reference is intended for developers implementing text processing or encoding logic in Cangjie who need to validate character types or calculate memory usage.
