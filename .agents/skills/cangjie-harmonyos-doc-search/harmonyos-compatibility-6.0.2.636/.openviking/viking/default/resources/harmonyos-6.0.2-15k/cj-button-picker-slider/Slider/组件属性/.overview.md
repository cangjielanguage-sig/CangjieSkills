# 组件属性

This directory contains API reference documentation for configuring the properties of the Slider component within the Cangjie ArkUI framework. It covers a wide range of customization options, including visual styling of the block and track, interaction modes, and responsive behavior. Developers can find detailed parameters for setting colors, sizes, shapes, and valid sliding ranges. The documentation is essential for UI developers looking to create highly customized and interactive slider controls in their applications using the Cangjie language.

## Detailed Description

### func_blockBorderColorResou_4more.md func_blockBorderColorResou_4more.md
This document serves as API reference documentation for configuring the visual appearance of a Slider component's block in the Cangjie ArkUI framework. It details four specific functions: blockBorderColor, blockBorderWidth, blockColor, and blockSize, including their parameters, system capabilities, and version requirements. The documentation highlights that the behavior of these styling functions depends heavily on the SliderBlockType (DEFAULT, IMAGE, SHAPE) and SliderStyle. For instance, border settings do not apply to IMAGE type blocks, while size defaults vary by style. This technical reference is intended for developers building UI applications using the Cangjie language who need to customize Slider component aesthetics.

### func_blockStyleSliderBlock_5more.md func_blockStyleSliderBlock_5more.md
This document serves as API reference documentation for configuring slider block components within the ArkUI framework using the Cangjie language. It primarily details overloaded `blockStyle` functions that allow developers to customize the slider's appearance by setting the block type, image resources (via String or AppResource), and custom geometric shapes like Circle or Rect. Additionally, it documents the `minResponsiveDistance` function to control the minimum interaction threshold for sliding. The file also notes deprecated functions `maxLabel` and `minLabel` from version 12. Intended for UI developers, this reference provides parameter definitions, default values, and system capabilities to facilitate precise slider customization.

### func_minResponsiveDistance_7more.md func_minResponsiveDistance_7more.md
This document serves as API reference documentation for configuring the appearance and behavior of a Slider component within the ArkUI framework using the Cangjie language. It details specific functions for setting the minimum responsive distance, styling the selected portion via border radius and color, and toggling UI elements like step indicators and bubble tips. Additionally, it covers defining valid sliding ranges with overloaded support for Float32 and Int64 types. Key information includes parameter constraints, default values, and system capabilities. This guide targets UI developers seeking to customize slider interactions and visual styles in their applications.

### func_sliderInteractionMode_6more.md func_sliderInteractionMode_6more.md
This document serves as an API reference for configuring the appearance and interaction behavior of Slider components within the ArkUI framework using the Cangjie language. It details six specific functions: sliderInteractionMode, stepColor, stepSize, trackBorderRadius, trackColor, and trackThickness. Key information includes parameter definitions, data types like ResourceColor and Length, default values, and specific constraints such as the proportional relationship between track thickness and block size. This technical reference is intended for UI developers needing to programmatically customize slider properties, requiring knowledge of the Cangjie syntax and ArkUI system capabilities.
