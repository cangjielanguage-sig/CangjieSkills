This directory provides comprehensive API reference documentation for the `Hasher` interface within the Cangjie programming language. It focuses on the mechanisms for computing combined hash values across various data types, specifically detailing the interface structure and overloaded methods for inputting unsigned integers. The content is essential for developers who need to implement hashing logic, update hash states, or manage custom data structures. Key topics include the `Hasher` interface definition, `write` function overloads for UInt types, and state management methods like `finish` and `reset`. This documentation is suitable for Cangjie developers looking to integrate robust hashing capabilities into their applications.
