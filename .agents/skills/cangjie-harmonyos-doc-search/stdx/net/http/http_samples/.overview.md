# http_samples

This directory contains a comprehensive collection of code samples and documentation for HTTP-related programming in the Cangjie language. It covers a wide range of critical topics, including client and server implementation, WebSocket communication, cookie management, data compression (gzip), and server logging. The resources are designed to help developers understand network protocols, handle stateful interactions, and optimize data transmission. It is suitable for developers working on web applications, network services, or real-time communication systems using the Cangjie ecosystem.

## Detailed Description

### cookie/
This directory is a specialized resource dedicated to HTTP Cookie management within the Cangjie programming language. It provides a structured collection of documentation and code examples designed to facilitate the implementation of stateful web interactions.

### h1_gzip/
This directory mainly demonstrates how to implement HTTP server-side gzip data compression functionality in the Cangjie programming language. It details the complete technical process from setting up an HTTP server, configuring necessary response headers, to using `CompressInputStream` for data stream compression, and how the client uses `DecompressInputStream` for decompression verification. Core knowledge points cover the application of the `stdx.compress.zlib` library, the method of setting the `Content-Encoding` header, and efficient data processing mechanisms based on stream reading and writing. This tutorial is very suitable for those committed to improving network transmission efficiency and reducing bandwidth usage.

### http_client/
This directory is dedicated to collecting detailed usage documentation and code guides for the HTTP client module in the Cangjie language. It not only covers standard methods for initiating basic HTTP requests but also delves into advanced network configurations, including but not limited to TLS certificate verification, TCP connection parameter adjustment, proxy server settings, and handling mechanisms for chunked transfer encoding. The documentation highlights how to use ClientBuilder to build highly customized client instances and guides developers in handling file stream uploads and security-related configurations. This resource is primarily aimed at developers who need to perform network programming in the Cangjie ecosystem, interface with RESTful APIs, or handle complex network communication scenarios, aiming to help users fully master these capabilities through rich examples.

### http_server/
This directory acts as a comprehensive technical resource for developers looking to build HTTP servers using the Cangjie programming language. It provides an in-depth exploration of server-side development, covering everything from the initial setup of the server environment to advanced features.

### log/
This directory focuses on the implementation and configuration of logging functionality in the Cangjie language HTTP server environment. It details how to build server instances through code examples, register request handlers, and specifically demonstrates how to enable and manage log levels (for example, setting to DEBUG mode). The documentation not only explains the configuration steps but also deeply analyzes the standard format of log output, including key information such as timestamps, thread IDs, and operation details.
