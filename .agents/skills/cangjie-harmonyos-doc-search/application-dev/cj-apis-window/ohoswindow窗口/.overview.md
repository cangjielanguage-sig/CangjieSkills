## Detailed Description

### class_AvoidArea.md class_AvoidArea.md
This API reference documentation defines the AvoidArea class in Cangjie, which specifies screen regions that UI elements should avoid. It details properties for visibility and rectangular boundaries (top, bottom, left, right), along with the constructor. All properties are readable and writable using the Rect type. It is intended for developers handling screen layout constraints within the WindowManager system capability.

### class_Configuration.md class_Configuration.md
This document details the Configuration class used to define parameters for creating child or system windows. It covers the class structure, including properties for name, window type, context, display ID, and parent ID, as well as the constructor. All properties are readable and writable, with display ID and parent ID defaulting to -1. It targets Cangjie developers using the WindowManager.Core capability.

### class_Rect_2more.md class_Rect_2more.md
This document provides API reference for data structures in Cangjie window management, specifically the Rect class (representing rectangular areas with coordinates and dimensions) and the Size class (defining dimensions). It details public properties (left, top, width, height) and constructors requiring named parameters. These classes belong to the WindowManager.Core capability and are available from version 22.

### class_TitleButtonRect.md class_TitleButtonRect.md
This document defines the TitleButtonRect class, which specifies the rectangular region for window control buttons (minimize, maximize, close) relative to the top-right corner. It details four public properties (right, top, width, height) and the constructor signature using virtual pixels (vp). It targets developers working on window session management and title bar layouts.

### class_WindowStage.md class_WindowStage.md
This document details the WindowStage class, which functions as a window manager for handling Window instances. It covers functions like createSubWindow, getMainWindow, getSubWindow, and loadContent, including parameters, return types, and potential BusinessException errors. It highlights that loadContent should be called during UIAbility startup and targets Cangjie developers.

### enum_AvoidAreaType.md enum_AvoidAreaType.md
This document defines the AvoidAreaType enum, categorizing screen regions where content should not be displayed. It enumerates types such as TypeSystem, TypeCutout, TypeSystemGesture, TypeKeyboard, and TypeNavigationIndicator. It also documents equality operators and targets developers working on UI layout and screen obstructions within the WindowManager capability.

### enum_ColorSpace.md enum_ColorSpace.md
This document provides API reference for the ColorSpace enum, specifying available color space types for window management. It details the enum structure, members (Default, WideGamut), and comparison operators. Key information includes system capability requirements for WindowManager.Core and the dependency of WideGamut behavior on screen hardware. It is intended for GUI developers.

### enum_SystemBarType.md enum_SystemBarType.md
This document defines the SystemBarType enum in the Cangjie WindowManager module. It details specific values (Status and Navigation) and overloaded comparison operators. The enum inherits from Equatable, supports WindowManager.Core, and is available from version 22. It targets developers who need to programmatically identify or manipulate system bar types.

### enum_WindowEventType.md enum_WindowEventType.md
This document defines the WindowEventType enum, representing various window lifecycle events (e.g., WindowShown, WindowActive, WindowInactive). It details enum values and comparison operators. It is associated with the WindowManager system capability and is intended for developers implementing logic to handle and compare window state changes.

### enum_WindowStageEventType.md enum_WindowStageEventType.md
This document defines the WindowStageEventType enum, representing callback event types for window stage lifecycle states. It details values like Shown, Active, Inactive, Resumed, and Paused, explaining their meanings regarding visibility and focus. It includes equality operators and targets developers handling window lifecycle events in Cangjie.

### enum_WindowStatusType.md enum_WindowStatusType.md
This document defines the WindowStatusType enum, used to describe application window states. It details values like Undefined, FullScreen, Maximize, Minimize, Floating, and SplitScreen, alongside operator overloads. It is associated with the Window.SessionManager capability and targets developers handling window layout states.

### enum_WindowType.md enum_WindowType.md
This document defines the WindowType enum for classifying window types within the WindowManager system. It details values like TypeApp, TypeMain, TypeFloat, and TypeDialog, noting that TypeFloat requires specific permissions. It targets Cangjie developers who need to understand window classifications and usage constraints.
