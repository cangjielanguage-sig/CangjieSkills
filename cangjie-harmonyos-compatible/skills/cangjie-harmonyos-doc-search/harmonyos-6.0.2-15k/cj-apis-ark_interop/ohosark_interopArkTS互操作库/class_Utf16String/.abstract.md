This directory contains API reference documentation for the `Utf16String` class in the Cangjie language, designed for high-performance UTF-16 string storage and seamless interoperability with ArkTS. It covers class definitions, properties, operator overloads, and various string manipulation methods including searching, splitting, and conversion. Key topics include memory management via `dispose`, JSValue conversion, and performance optimizations for the Napi subsystem. This documentation is suitable for HarmonyOS developers and software engineers working with ArkUI who require efficient handling of UTF-16 encoded strings and need to integrate Cangjie code with ArkTS environments.
