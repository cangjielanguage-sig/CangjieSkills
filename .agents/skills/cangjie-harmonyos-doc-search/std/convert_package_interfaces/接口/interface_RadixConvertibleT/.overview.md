# interface_RadixConvertibleT

This directory contains API reference documentation for the Cangjie programming language's `RadixConvertible` interface and its implementations across standard integer types. It covers extensions for signed (Int8, Int16, Int32, Int64) and unsigned (UInt8, UInt16, UInt32, UInt64) integers, enabling conversions between string representations and numeric values across various numerical bases (radix 2 to 36). Key functionalities include parsing strings into integers using strict or safe methods (`parse`, `tryParse`) and formatting integers as strings (`toString`). This documentation is suitable for Cangjie developers who need precise control over numeric parsing, formatting, and error handling in different radix systems.
