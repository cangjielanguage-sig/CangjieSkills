This directory contains comprehensive API reference documentation for core interfaces in the Cangjie programming language. It covers essential type abstractions including collections, iteration, comparison operations, hashing, and C language interoperability. Key topics include the `Collection`, `Comparable`, and `Hashable` interfaces, as well as specialized utilities for resource management and string representation. This documentation is suitable for Cangjie developers, systems engineers, and language learners seeking to implement custom types, understand type constraints, or utilize standard library features for data manipulation and system interaction.
