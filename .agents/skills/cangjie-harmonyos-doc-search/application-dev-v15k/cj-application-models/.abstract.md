This directory serves as the definitive guide for the application model framework, a system designed to abstract essential capabilities to simplify and standardize the application development process. It comprehensively covers the model's constituent elements, including application components, process and thread models, task management, and configuration files. The documentation places a strong emphasis on the "Stage model," which is the primary long-term framework for development. Key topics include the object-oriented development approach using UIAbility and ExtensionAbility components, specific process types (main, extension, render), and task management rules where each UIAbility instance creates a persistent task without a stack structure. This resource is specifically suitable for application developers who need to understand system architecture, lifecycle management, and component configuration to build robust applications.
