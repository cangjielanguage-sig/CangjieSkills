# class_ErrorManager

This directory provides comprehensive API reference documentation for the Cangjie ErrorManager class, a critical component of the HarmonyOS AbilityKit. It focuses on the complete lifecycle management of observers used for robust error handling and system performance monitoring. The documentation details static methods for registering observers to catch unhandled exceptions and track main thread loop performance, alongside procedures for unregistering them. It includes specific technical details such as parameter requirements (e.g., "error" or "loopObserver" strings), version compatibility (starting from version 12), and potential BusinessException errors with specific codes. This resource is designed for HarmonyOS application developers using the Cangjie language who need to build resilient applications with advanced error tracking and performance analysis capabilities.
