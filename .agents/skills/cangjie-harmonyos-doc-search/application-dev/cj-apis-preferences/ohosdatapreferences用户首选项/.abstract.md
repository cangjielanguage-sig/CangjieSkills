This directory contains API reference documentation for the HarmonyOS `ohos.data.preferences` module, specifically designed for the Cangjie language. It focuses on lightweight Key-Value data persistence, enabling developers to manage application settings and local data efficiently. The documentation covers configuration options, storage types (XML, GSKV), data change events, and the complete lifecycle of preference instances. It is suitable for HarmonyOS developers using Cangjie who need to implement reliable data storage, handle data constraints, and monitor changes within their applications.
