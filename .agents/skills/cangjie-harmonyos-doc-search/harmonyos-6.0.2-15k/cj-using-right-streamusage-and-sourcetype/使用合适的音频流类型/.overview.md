# 使用合适的音频流类型

This directory provides comprehensive guidance on selecting and configuring audio stream types to ensure correct audio behavior and an optimal user experience. It covers the technical definitions of stream types, their impact on system resources like volume control and audio focus, and practical implementation methods for playback and recording. Core topics include StreamUsage, SourceType, AudioRenderer, and AVRecorder. This resource is suitable for application developers and audio engineers who need to manage audio parameters for scenarios such as music playback, VoIP calls, and voice recognition.
