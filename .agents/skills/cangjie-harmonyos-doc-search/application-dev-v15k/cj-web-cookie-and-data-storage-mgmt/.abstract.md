This directory serves as a comprehensive technical resource dedicated to the management of cookies and data storage within the Cangjie programming environment. It specifically targets developers utilizing the ArkWeb and ArkUI Web components, providing essential guidance on handling client-side data persistence and application state. The documentation covers a broad spectrum of topics, ranging from the fundamental mechanisms of cookie management—including critical security attributes like SameSite, storage path definitions, and synchronization interfaces—to advanced strategies for optimizing web performance. Furthermore, it details the configuration of various cache modes to enhance resource loading speeds and the effective management of DOM Storage for both temporary and persistent data retention. This collection of documents is highly suitable for application developers who are looking to implement robust, secure, and efficient data management solutions in their web-based applications, ensuring both high performance and adherence to security best practices in the Cangjie ecosystem. The content is structured to facilitate quick learning and practical application.
