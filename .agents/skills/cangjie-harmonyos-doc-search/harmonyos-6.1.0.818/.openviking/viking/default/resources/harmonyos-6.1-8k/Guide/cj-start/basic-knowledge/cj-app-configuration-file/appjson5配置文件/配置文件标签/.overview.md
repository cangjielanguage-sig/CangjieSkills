# 配置文件标签

本目录包含关于HarmonyOS应用配置文件标签的详细文档，主要聚焦于`app.json5`文件的结构与使用规则。内容涵盖了应用基础信息（如bundleName、versionCode）、API版本配置、设备差异化配置（如tablet、default）以及多开模式和端云同步等高级特性。文档详细阐述了标签的定义、数据类型及命名规范，并解释了特定设备配置如何覆盖公共配置的逻辑。该目录适合使用DevEco Studio进行HarmonyOS应用开发的开发人员，作为配置应用级属性和查询标签用法的权威参考指南。
