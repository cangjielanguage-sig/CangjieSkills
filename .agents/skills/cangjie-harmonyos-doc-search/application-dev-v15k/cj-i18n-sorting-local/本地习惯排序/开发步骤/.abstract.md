This directory serves as a comprehensive guide for developers implementing locale-aware string operations using the Collator class within the LocalizationKit framework for the Cangjie language. It focuses on the essential development steps required to achieve accurate internationalization (i18n) in applications. The content covers the complete workflow, from importing modules and instantiating objects with specific CollatorOptions to performing complex string comparisons. Key topics include handling sensitivity settings, numeric ordering, and utilizing specific collation methods such as Pinyin or Stroke for Chinese characters. Additionally, it addresses advanced scenarios like Turkish case-insensitive searching. This resource is ideal for Cangjie developers and localization engineers aiming to build robust multi-language applications that require precise text sorting and searching capabilities across different linguistic contexts.
