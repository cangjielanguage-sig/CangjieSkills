# 基础类型定义

This directory contains essential API reference documentation for fundamental data structures and classes utilized within the ArkUI framework when developing applications using the Cangjie language. It specifically addresses core components required for advanced image processing and state management. The documentation covers the `ColorFilter` class for applying 4x5 matrix transformations to images, the `ImageError` class for diagnosing loading failures, and the `ImageLoadResult` class for retrieving precise layout metrics. These resources are designed for application developers who need to implement robust image rendering, error handling, and accurate UI layout calculations. It assumes familiarity with ArkUI capabilities and requires version 22 or later. Keywords: ArkUI, Cangjie, ColorFilter, ImageError, ImageLoadResult, API Reference, Image Processing, Error Handling, Layout Metrics.

### class_ImageLoadResult.md class_ImageLoadResult.md
This document provides API reference documentation for the Cangjie class ImageLoadResult, which defines the data structure returned upon successful image loading. The content details public properties including image dimensions, component dimensions, and specific drawing metrics such as content width, height, and x/y offsets. Key information highlights that content-related properties are only valid when the loadingStatus returns 1, with all measurements in pixels. This reference is intended for developers working with the ArkUI framework who need to handle image loading states and precise layout calculations in their applications.
