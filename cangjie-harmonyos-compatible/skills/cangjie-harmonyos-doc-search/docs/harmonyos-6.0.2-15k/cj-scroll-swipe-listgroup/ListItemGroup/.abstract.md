This directory provides comprehensive documentation for the `ListItemGroup` component within the ArkUI framework, utilizing the Cangjie programming language. It covers the complete API reference, practical implementation examples for advanced UI layouts, and foundational type definitions. Key topics include component constraints, initialization parameters, sticky headers, card-style effects, and styling enumerations. It ensures developers understand the specific constraints and capabilities of grouping items effectively. This documentation is intended for HarmonyOS developers and UI engineers who need to build structured, complex list interfaces with precise control over grouping behavior, visual hierarchy, and component configuration.
