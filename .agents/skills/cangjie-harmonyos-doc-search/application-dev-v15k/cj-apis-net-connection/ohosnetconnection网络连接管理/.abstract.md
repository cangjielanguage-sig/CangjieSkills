This directory provides API reference documentation for the HarmonyOS NetworkKit module `ohos.net.connection`, designed for the Cangjie programming language. It covers comprehensive network connection management, including defining network specifications, managing connection properties, and monitoring network states. Key components include classes for network handles, capabilities, and addresses, alongside functions for querying and reporting network status. This documentation is suitable for HarmonyOS developers and system application builders who need to implement robust network-aware features, manage connectivity transitions, and handle network-specific configurations within their applications.
