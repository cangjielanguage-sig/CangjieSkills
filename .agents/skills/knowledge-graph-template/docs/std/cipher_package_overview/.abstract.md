This directory contains the documentation for the `std.crypto.cipher` package, a fundamental module for implementing symmetric encryption and decryption within the standard library. It offers a detailed architectural overview, guiding developers through the available cryptographic components and their interactions. The documentation is primarily centered around the `BlockCipher` interface, which is defined as the universal standard for block cipher algorithms, ensuring a consistent approach to data security. This resource is structured as API documentation, providing a functional introduction alongside a comprehensive list of interfaces. It is specifically tailored for software developers, security engineers, and system architects who require a deep understanding of the package's design and capabilities. By covering critical topics such as symmetric encryption, block cipher standards, and API structures, this directory serves as a vital reference for integrating robust cryptographic features into applications using the `std.crypto` module.
