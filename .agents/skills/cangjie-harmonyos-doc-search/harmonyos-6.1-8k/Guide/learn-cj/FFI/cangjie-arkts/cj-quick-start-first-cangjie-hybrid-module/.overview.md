# cj-quick-start-first-cangjie-hybrid-module

This directory serves as a practical quick-start resource for developers looking to integrate the Cangjie programming language into existing HarmonyOS applications built with ArkTS. It focuses on a hybrid development approach, enabling the incremental adoption of Cangjie features within a current project structure. The guide covers essential workflows, including analyzing the existing project architecture, configuring the development environment for mixed-language support, and establishing cross-language interoperability. Key topics include ArkTS, Cangjie, hybrid development, function calls, and UI component embedding. This material is specifically designed for developers who want to enhance their applications with Cangjie's advanced capabilities while maintaining their existing ArkTS codebase, ensuring a flexible and efficient development process.
