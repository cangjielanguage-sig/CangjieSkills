# 图片边框设置

This directory provides comprehensive documentation and resources for configuring image borders within the ArkUI framework using the Cangjie programming language. It covers the `borderImage` API, fundamental data type definitions for gradients and border options, and practical code examples for dynamic styling. Key topics include linear gradients, border repetition modes, and interactive UI controls. This content is suitable for Cangjie developers and UI designers working on HarmonyOS applications who need to implement advanced visual effects and complex border rendering starting from API version 19.

## Detailed Description

### 图片边框设置_2more.md
This document serves as API reference material for configuring image borders on UI components within the ArkUI framework using the Cangjie language. It details the `borderImage` function, including its signature, system capabilities, version requirements, and parameter specifications. The core takeaway is the usage of the `borderImage` function, which accepts a mandatory `BorderImageOption` parameter to apply image or gradient borders. It is available from version 19 and requires full ArkUI system capabilities. Targeted at developers using the ArkUI framework, this reference guide requires knowledge of Cangjie syntax and UI component styling.
