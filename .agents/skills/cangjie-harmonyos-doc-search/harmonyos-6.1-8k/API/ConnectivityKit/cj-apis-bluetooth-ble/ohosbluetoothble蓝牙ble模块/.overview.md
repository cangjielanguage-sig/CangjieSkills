## 详细描述

### class_AdvertiseData.md class_AdvertiseData.md
本文档是Cangjie语言中用于定义BLE广播报文数据内容的AdvertiseData类的API参考文档。文档涵盖了类的属性定义（包括服务UUID、制造商数据、服务数据及设备名称标志）和构造函数参数说明。关键信息指出该类仅支持传统广播，报文最大长度限制为31字节，超限将导致启动失败。构造函数支持配置是否携带设备名称和发射功率，其中携带发射功率会增加3字节开销。适用于进行蓝牙低功耗开发的Cangjie程序员，需了解蓝牙广播机制。

### class_AdvertiseSetting.md class_AdvertiseSetting.md
本文档定义了用于配置蓝牙低功耗（BLE）广播发送参数的 `AdvertiseSetting` 类。文档详细说明了类的三个核心属性：可连接性、广播间隔和发射功率，以及类的构造函数。关键信息包括广播间隔和发射功率的具体取值范围、单位及建议值，构造函数提供了默认参数以简化初始化。该API属于系统能力 `SystemCapability.Communication.Bluetooth.Core`，起始版本为22。面向使用仓颉语言进行蓝牙开发的开发者，属于API参考文档，需具备基础BLE开发知识。

### class_AdvertisingParams.md class_AdvertisingParams.md
本文档是Cangjie语言中AdvertisingParams类的API参考文档，用于定义首次启动BLE广播时的配置参数。主要涵盖了类的属性定义，包括广播数据、扫描响应数据、广播设置及持续时间，以及类的构造函数。关键信息详细说明了各属性的类型、读写权限及持续时间单位（10ms），并标注了系统能力要求。该文档面向使用Cangjie进行蓝牙核心功能开发的开发者，旨在帮助其正确配置低功耗蓝牙广播参数。

### class_AdvertisingStateC_8b1c661b.md class_AdvertisingStateC_8b1c661b.md
