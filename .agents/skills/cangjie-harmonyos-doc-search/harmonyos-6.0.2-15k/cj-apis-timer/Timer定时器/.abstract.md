This directory contains comprehensive API documentation for the Timer module within the Cangjie programming language standard library. It is designed to assist developers in scheduling and executing functions after specific time intervals, covering both one-time and repetitive task scenarios. The documentation details critical system capabilities, function signatures, and parameter definitions for essential timing operations. Key topics include the `once` and `repeat` static functions for task creation and the `cancel` method for lifecycle management. This resource is specifically suitable for Cangjie developers working on ArkUI applications who require precise control over asynchronous timing logic, event loop queuing, and periodic execution within their software projects.
