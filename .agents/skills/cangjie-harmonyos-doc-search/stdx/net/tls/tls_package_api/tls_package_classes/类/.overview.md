# 类

## 详细描述

### class_TlsSessionContext.md class_TlsSessionContext.md
这是一份关于 TlsSessionContext 类的 API 参考文档，主要阐述了该类在 TLS 连接复用中用于验证客户端合法性和确保服务端实例一致性的作用。文档详细列出了类的继承关系及核心成员，包括通过名称创建实例的静态方法 fromName、生成字符串的 toString 方法以及相等性比较操作符。关键要点在于，尽管通过相同名称创建的实例可能不相等，但建议服务器在整个生命周期内复用同一个 TlsSessionContext 实例。该文档面向使用 Cangjie 语言进行安全网络通信开发的程序员，涉及 TLS 会话恢复、上下文管理及安全验证等概念。

### class_TlsSocket/
本目录包含 Cangjie 语言中 TlsSocket 类的 API 参考文档，涵盖了用于在客户端和服务端之间建立安全加密传输通道的核心功能。文档详细介绍了属性配置（如证书、加密套件）、数据传输接口（读写操作）、连接状态管理及异常处理机制。核心关键词包括 TLS 协议、Socket 编程、加密通信、X509 证书及会话恢复。该文档适合具备网络编程基础并需要实现安全通信的开发者阅读。
