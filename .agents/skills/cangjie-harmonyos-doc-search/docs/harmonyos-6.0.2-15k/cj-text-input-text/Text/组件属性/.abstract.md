This directory contains API reference documentation for component properties within the ArkUI framework, specifically using the Cangjie programming language. It covers a wide range of text styling, layout configuration, and interaction behaviors, including font customization, data detection, text overflow, and touch response regions. The documentation details function signatures, parameters, system capabilities, and version requirements (starting from API 12 or 19). It is suitable for UI developers and software engineers building HarmonyOS applications who need precise control over text rendering, user interaction, and component layout constraints.
