This directory provides the essential API documentation for the `cj-apis-displaySync` module, a specialized library designed for the Cangjie programming language within the HarmonyOS ArkUI framework. The documentation focuses on variable frame rate control, a sophisticated feature that enables developers to synchronize custom UI rendering logic with the display's refresh cycle. This synchronization is crucial for optimizing rendering performance and ensuring visual consistency. Key components covered in this documentation include the `DisplaySync` class, which manages the synchronization process; the `IntervalInfo` class, which handles timing data; and the `OnOffType` enum, which defines state configurations. These tools facilitate the precise management of frame drawing timestamps and callback events. This resource is specifically suitable for HarmonyOS developers and software engineers who aim to optimize application performance and implement self-drawn UI tasks with rigorous performance demands.
