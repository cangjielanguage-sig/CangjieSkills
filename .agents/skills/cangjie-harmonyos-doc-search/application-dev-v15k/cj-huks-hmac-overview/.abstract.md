This directory provides a comprehensive technical reference for implementing HMAC (Hash-based Message Authentication Code) within the HUKS (HarmonyOS Universal Keystore Store) framework. It covers the fundamental definitions of MAC and HMAC, emphasizing their critical role in verifying information integrity across unreliable media. The documentation details the specific cryptographic algorithms supported by HUKS, including a detailed table of supported digest algorithms such as SHA256, SHA384, SHA512, and SM3. Furthermore, it specifies corresponding key length ranges and the minimum API level requirements (API 15+). This resource is essential for developers and security engineers who require a deep understanding of HMAC capabilities and constraints to secure their applications effectively and ensure compliance with system specifications.
