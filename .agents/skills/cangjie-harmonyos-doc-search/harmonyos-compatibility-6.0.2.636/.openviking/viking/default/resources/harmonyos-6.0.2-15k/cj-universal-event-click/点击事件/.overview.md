# 点击事件

This directory provides comprehensive documentation and resources for handling click events within the ArkUI framework using the Cangjie language. It covers the core `onClick` API, practical code examples for event processing, and fundamental type definitions required for managing user interactions. Key topics include event callbacks, coordinate extraction, state management, and behavioral constraints like touch duration and displacement. This content is suitable for developers building HarmonyOS applications who need to implement responsive UI interactions and understand the underlying event handling mechanisms in Cangjie.

## Detailed Description

### 点击事件_2more.md 点击事件_2more.md
This document serves as API reference documentation for the click event functionality in the ArkUI framework, specifically detailing the onClick method used to handle user interactions on components. It covers the function signature, system capabilities, version requirements, and parameter definitions. It also includes specific behavioral constraints regarding touch duration and movement displacement. The core function is onClick, which accepts a callback with a ClickEvent parameter. Crucially, the event fails to trigger if the press exceeds 800 milliseconds or if the finger moves more than 20 pixels, distinguishing a click from a long press or drag. This is intended for developers using the Cangjie language and ArkUI framework to build user interfaces, requiring knowledge of event handling and component lifecycle.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating how to handle and process click events within a HarmonyOS application UI. It covers event data resolution, state management, and UI component interaction using the UIKit framework. The code defines helper functions to extract coordinates and target properties from ClickEvent and EventTarget objects. It implements an EntryView class with buttons that trigger these events, updating state variables to display detailed event information like timestamps and global positions. This serves as a practical reference for developers learning the Cangjie language and HarmonyOS UI event handling mechanisms.
