# cj-universal-attribute-clickeffect

This directory provides a comprehensive API reference for developers utilizing the Cangjie language within the ArkUI framework, specifically targeting the implementation of click rebound animations. The documentation centers on the `clickEffect` universal attribute, which is pivotal for creating responsive and interactive user interfaces. It thoroughly explains how to manipulate the intensity of visual feedback through the level parameter, offering options such as LIGHT, MIDDLE, and HEAVY. Additionally, it covers the customization of the zoom ratio using the optional scale parameter, providing developers with granular control over the animation's appearance. The guide also details default scale values associated with each level and lists necessary system capability requirements. This resource is essential for UI developers and software engineers dedicated to refining application interactivity and ensuring a high-quality, consistent user experience through effective visual feedback mechanisms.
