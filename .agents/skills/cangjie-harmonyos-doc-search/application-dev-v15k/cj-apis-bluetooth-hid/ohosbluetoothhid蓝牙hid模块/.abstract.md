This directory provides comprehensive API reference documentation for the OpenHarmony Bluetooth HID (Human Interface Device) module, specifically tailored for the Cangjie programming language. It serves as a technical guide for developers utilizing the ConnectivityKit to implement Bluetooth HID features in HarmonyOS applications. The content covers essential aspects such as project configuration, required permissions, system capabilities, and the creation of HID host profile instances. Additionally, it details error handling mechanisms and event-driven programming patterns necessary for managing device connections. This resource is ideal for software developers seeking to integrate robust Bluetooth HID functionalities, offering code examples and structural definitions to facilitate application development and ensure seamless connectivity.
