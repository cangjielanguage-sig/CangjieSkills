This directory serves as a comprehensive technical guide for Cangjie developers who are utilizing the Unified User Authentication Framework. It specifically addresses the critical requirement of cancelling an ongoing user authentication process, which is essential for creating responsive applications. The documentation thoroughly covers the interface description, detailing the necessary development steps such as applying for specific permissions and configuring the required parameters. A significant portion of the guide is dedicated to the `UserAuthInstance.cancel()` function, explaining that it operates on a successfully started authentication instance. Furthermore, it provides a practical Cangjie code example that illustrates how to cancel a Face and PIN authentication process operating at a trust level of ATL3. This resource is ideally suited for developers integrating biometric or password authentication features who need to implement robust and error-free cancellation logic to handle user interruptions or system timeouts effectively.
