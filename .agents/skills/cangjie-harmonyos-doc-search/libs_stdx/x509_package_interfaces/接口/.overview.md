# 接口

This directory provides comprehensive API documentation for cryptographic interfaces within the Cangjie programming language, specifically focusing on the x509 package. It details the core `Key` interface alongside its specialized extensions: `DHParameters`, `PrivateKey`, and `PublicKey`. The documentation covers essential functionalities such as encoding and decoding cryptographic keys in DER and PEM formats, managing Diffie-Hellman key exchange parameters, and handling password-based encryption for private keys. It serves as a technical reference for ensuring secure data exchange and identity verification. This resource is essential for software developers and security engineers implementing robust cryptographic protocols, requiring knowledge of X.509 standards, key management, and secure encoding practices.

## Detailed Description

### interface_DHParameters_2more.md interface_DHParameters_2more.md
This API documentation defines the DHParameters and Key interfaces for the Cangjie programming language, focusing on cryptographic key handling. The Key interface serves as a base for public and private keys, providing methods to encode and decode keys in DER and PEM formats. The DHParameters interface extends Key to specifically manage Diffie-Hellman key exchange parameters, offering similar encoding and decoding capabilities tailored to DH standards. Key sections include function signatures, parameter descriptions, return values, and potential X509Exception errors. This reference is intended for developers implementing security protocols, requiring knowledge of cryptographic concepts like DER, PEM, and Diffie-Hellman.

### interface_PrivateKey.md interface_PrivateKey.md
This API reference document defines the PrivateKey interface in the Cangjie programming language, which extends the Key interface to handle private key operations. The documentation details static methods for decoding keys from DER and PEM formats, as well as instance methods for encoding keys back to these formats. Key functions include decodeDer, decodeFromPem, encodeToDer, and encodeToPem, all supporting optional password-based encryption and decryption. It specifies parameters like DerBlob and String, return types, and potential X509Exception errors for invalid formats or empty passwords. This guide targets software developers implementing cryptographic security features who need to parse, generate, or secure private keys within the x509 package.

### interface_PublicKey.md interface_PublicKey.md
This document serves as API reference documentation for the PublicKey interface in the Cangjie programming language, defining the structure and functionality for handling public keys. It details the interface inheritance from the Key type and documents three specific member functions: encodeToPem, decodeDer, and decodeFromPem. The summary highlights that the interface facilitates encoding public keys to PEM format and decoding them from both DER and PEM formats. It specifies input parameters like DerBlob and String, return types such as PemEntry, and potential X509Exception errors for invalid formats. This technical reference is intended for developers implementing cryptographic operations, requiring knowledge of the Cangjie language and X.509 standards.
