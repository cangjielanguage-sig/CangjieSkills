### ohosbackground_task_mgr后台任务管理/
This directory provides comprehensive API reference documentation for the `ohos.background_task_mgr` module, specifically curated for the Cangjie programming language within the HarmonyOS ecosystem. The core focus of this documentation is to enable developers to manage background tasks with high efficiency, ensuring that applications are not suspended by the system during critical operations. It covers a robust set of functionalities, beginning with the definition of long-running task modes. These modes are vital for applications that require sustained execution, such as those performing audio playback or collecting location data, where user experience depends on uninterrupted service.

In addition to continuous tasks, the documentation details the process for requesting short-time delay tasks, which permit applications to perform background work for a limited duration of up to 3 minutes. This is particularly useful for transient operations like data synchronization or file cleanup. The guide also thoroughly explains task lifecycle management, offering methods for task cancellation and the retrieval of time-related data to track execution duration accurately.

Furthermore, the documentation includes essential information on required system capabilities, version requirements (specifically starting from API 12), and comprehensive error handling strategies. It details the necessary permissions and system configurations that must be in place before these background tasks can be successfully requested and executed. By providing clear error codes and handling guidelines, it empowers developers to build resilient applications that can gracefully manage system constraints. This makes it an ideal reference for Cangjie developers looking to implement sophisticated background execution logic, manage transient tasks, and guarantee application continuity across various usage scenarios while maintaining system stability and adhering to best practices for resource management.
