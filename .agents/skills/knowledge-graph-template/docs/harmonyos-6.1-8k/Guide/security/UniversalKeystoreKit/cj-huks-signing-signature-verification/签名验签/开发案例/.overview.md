# 开发案例

本目录汇集了基于仓颉语言和鸿蒙通用密钥库套件（HUKS）的加密开发案例，重点展示了数字签名的实现方法。内容涵盖了ECC、RSA（支持PKCS1_V1_5和PSS填充）以及国密SM2等多种主流算法，详细讲解了从密钥生成、参数配置、签名验签到密钥删除的完整生命周期管理。文档包含具体的代码示例和HUKS接口调用流程，适合具备基础密码学知识并致力于鸿蒙系统安全开发的仓颉语言开发者参考。

## Quick Navigation

- 想要实现 **ECC** 算法签名 → ECC256SHA256.md
- 想要实现 **RSA** 算法签名
    - 使用 **PKCS1_V1_5** 填充模式 → RSASHA256PKCS1_V1_5.md
    - 使用 **PSS** 填充模式 → RSASHA256PSS.md
- 想要实现 **国密 SM2** 算法签名 → SM2SM3.md

## Detailed Description

### ECC256SHA256.md ECC256SHA256.md
本文档展示了如何使用仓颉语言和通用密钥库套件实现基于ECC256算法和SHA256摘要的数字签名功能。文档涵盖了密钥生成、签名、验签及密钥删除的完整流程，并包含数据转换与属性配置的辅助函数。核心内容包括配置HUKS参数（如算法、密钥长度、用途），通过initSession、updateSession和finishSession接口进行会话管理，以及testSignVerify函数演示的端到端测试流程。适用于需要在鸿蒙系统中进行安全加密开发的开发者，要求具备基本的密码学知识和仓颉编程能力。

### RSASHA256PKCS1_V1_5.md RSASHA256PKCS1_V1_5.md
本文档提供了使用通用密钥库套件进行RSA签名和验证的Cangjie语言代码示例，具体配置为SHA256摘要算法和PKCS1_V1_5填充模式。文档涵盖了密钥生成、签名及验证的参数配置，以及生成密钥、执行签名、验证签名和删除密钥的完整流程函数。关键信息包括定义RSA 2048位密钥、SHA256摘要和PKCS1_V1_5填充的HuksParam配置，以及通过initSession、updateSession和finishSession等会话接口实现加解密操作的方法。这是一个面向使用HarmonyOS通用密钥库套件的开发者的教程示例，旨在指导如何在Cangjie语言中实现RSA数字签名功能。

### RSASHA256PSS.md RSASHA256PSS.md
本文档提供了使用Cangjie语言通过通用密钥库套件实现RSA/SHA256/PSS签名与验签的代码示例。文档涵盖了密钥生成、签名及验签的属性配置，以及具体的密钥生成、签名、验签和删除功能的实现。关键信息包括如何配置HUKS参数（如算法、填充模式和摘要），以及利用会话机制（initSession/finishSession）执行加密操作。该文档面向HarmonyOS或Cangjie开发者，旨在指导其实现基于RSA-PSS的安全数字签名流程。

### SM2SM3.md SM2SM3.md
1. 本文档演示了如何在仓颉语言中使用通用密钥库套件实现SM2密钥生成、SM3摘要签名及验签。
2. 涵盖了密钥生成、签名和验签的属性配置，以及密钥生命周期管理函数，包括生成、签名、验证和删除。
3. 代码通过Huks API实现，指定SM2算法、256位密钥及SM3摘要，testSignVerify函数展示了完整流程。
4. 面向仓颉语言开发者，适用于鸿蒙系统中需要实现国密算法的安全开发。
