# class_Display

This directory provides essential API reference documentation for the Cangjie Display class, which serves as the primary interface for managing screen instances and attributes within the WindowManager system. The content covers a broad spectrum of display functionalities, ranging from basic device status and screen dimensions to advanced features like pixel density, color spaces, HDR formats, orientation, and refresh rates. It also includes detailed information on specific properties such as rotation angle, scaled density, and physical DPI, alongside methods for retrieving screen geometry like available areas and cutout information. This documentation is specifically tailored for Cangjie developers focused on UI layout and display management in the HarmonyOS ecosystem, offering the necessary technical details to leverage system capabilities starting from version 12.

## Detailed Description

### class_Display_13more.md
This document provides API reference documentation for the Cangjie Display class, which manages screen instances and attributes within the WindowManager system. It details read-only properties covering device status, dimensions, pixel density, color spaces, HDR formats, orientation, and refresh rates. Intended for developers working on display management, this documentation outlines the system capabilities available starting from version 12, focusing on retrieving physical and logical screen characteristics.
