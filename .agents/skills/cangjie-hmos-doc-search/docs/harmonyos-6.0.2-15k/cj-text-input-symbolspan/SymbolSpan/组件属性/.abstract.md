This directory provides comprehensive API reference documentation for configuring the properties of UI components, specifically focusing on the `SymbolSpan` component within the Cangjie programming language and the ArkUI framework. It covers essential styling and rendering configurations, including effect strategies, font attributes (color, size, weight), and visual rendering modes. The documents detail specific function signatures, system capabilities, and version requirements, offering insights into overloaded methods that accept various data types such as arrays, integers, strings, and enums. Key technical details include specific value ranges for font weight and default settings for font size. This content is highly suitable for developers and UI engineers working with ArkUI who require precise programmatic control over the visual presentation and behavior of symbol glyphs in their application interfaces.
