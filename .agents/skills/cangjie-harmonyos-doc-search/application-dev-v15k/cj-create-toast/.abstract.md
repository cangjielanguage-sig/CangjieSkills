This directory provides a specialized technical overview for Cangjie developers aiming to implement Toast notifications within the ArkUI development environment. It serves as a definitive guide on using the `PromptAction` class to generate system-standard, non-intrusive user feedback messages. The documentation thoroughly explores the definition of a Toast, emphasizing the importance of adhering to system defaults regarding text density and notification frequency to prevent user disruption. A significant focus is placed on the technical distinction between the `DEFAULT` and `TOP_MOST` display modes, explaining how `TOP_MOST` utilizes a sub-window for higher z-index layering compared to the main window rendering of `DEFAULT`. This resource is particularly suitable for software engineers and UI developers who require a deep understanding of ArkUI's prompt capabilities. It ensures that implemented notifications are lightweight, devoid of interactive elements, and consistent with the platform's design language, thereby enhancing the overall application quality and user experience. By following the guidelines in this directory, developers can effectively communicate status updates or alerts without interrupting the user's primary workflow.
