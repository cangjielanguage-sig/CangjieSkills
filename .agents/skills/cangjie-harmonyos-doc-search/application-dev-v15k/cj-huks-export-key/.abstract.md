This directory provides a comprehensive development guide designed for Cangjie developers working with the Universal Keystore Kit (HUKS). It specifically addresses the technical requirements and procedures for exporting public keys associated with persistent asymmetric keys. The documentation covers a range of supported cryptographic algorithms, including ECC, RSA, and SM2, with specific notes regarding limitations on lightweight devices. It breaks down the implementation into a clear three-step workflow: defining a key alias, calling the `exportKeyItem` interface, and parsing the resulting X.509 DER format key material. Additionally, the guide includes practical code examples focusing on error handling and function invocation, making it an essential resource for developers needing to integrate public key access into their business logic.
