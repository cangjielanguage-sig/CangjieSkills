This directory serves as a technical resource for managing connections between HarmonyOS devices and development environments using the HarmonyOS Device Connector (HDC). It covers critical operations such as switching between USB and wireless debugging modes, querying device lists, and managing multi-device environments. The documentation includes detailed command syntax, parameters, and troubleshooting steps for various network topologies, including local TCP and remote connections. Designed for developers and system administrators, these guides facilitate efficient debugging, automation, and interaction setup for HarmonyOS applications.
