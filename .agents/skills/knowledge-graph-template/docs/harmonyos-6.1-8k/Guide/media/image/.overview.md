# image

This directory serves as a comprehensive technical resource for the Image Kit, specifically focusing on image processing capabilities within the OpenHarmony and HarmonyOS ecosystems using the Cangjie (仓颉) programming language. It covers the complete image development lifecycle, including decoding, encoding, PixelMap manipulation, transformations, and EXIF metadata editing. The documentation is structured to guide developers through modular tasks such as reading and writing pixel data, scaling, rotating, and managing image properties. It is suitable for developers building applications that require advanced image display, editing, or optimization features, providing both conceptual overviews and practical API examples.

## Detailed Description

### README_zh
This directory contains the Chinese navigation index documentation for the Image Kit (Image Processing Service). It is designed to help developers understand and utilize the image processing features of this Beta version. The documentation covers the complete process from basic concepts to specific API implementations, including using ImageSource for image decoding, utilizing PixelMap for image transformation and bitmap operations, editing EXIF information, and using ImagePacker for image encoding. The content emphasizes the modular structure of the image processing flow, explaining decoding, editing/processing, and encoding in separate stages. It is suitable for developers who need to integrate image processing functions into their applications, providing a clear entry point for development guidance.

### cj-image-decoding
This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language, specifically targeting image decoding functionalities within the HarmonyOS and OpenHarmony development environments. It provides detailed documentation and examples to assist developers in implementing image decoding solutions effectively.

### cj-image-encoding
This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, specifically focusing on the critical task of image encoding. It provides in-depth documentation and practical examples for using the relevant tools and APIs to encode images efficiently within the supported development environments.

### cj-image-overview
This directory provides overview documentation for the Image Kit (Image Development Suite) in the OpenHarmony system, aiming to provide comprehensive image development guidance for application developers. The content covers the core mechanisms of image decoding, PixelMap bitmap operations, image processing, and encoding, detailing the complete development steps from acquiring images to generating new ones. The document highlights features such as read/write permissions, multi-format support, and efficient algorithms, and explains the usage background of key classes like ImageSource and ImagePacker and their supporting relationship with the Image component. As a conceptual guide, it is particularly suitable for developers who need to display, edit, or optimize images, helping them quickly establish an overall understanding of the image processing flow.
