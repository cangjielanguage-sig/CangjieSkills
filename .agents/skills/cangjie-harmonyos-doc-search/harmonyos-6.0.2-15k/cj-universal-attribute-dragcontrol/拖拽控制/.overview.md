# 拖拽控制

This directory provides comprehensive documentation for implementing and customizing drag-and-drop interactions within the ArkUI framework using the Cangjie language. It covers essential APIs for enabling drag functionality, configuring visual previews, and managing context menus. Key topics include the `draggable` modifier, `dragPreview` customization, and fundamental data structures for defining visual behaviors like scaling and shadows. This resource is suitable for UI developers seeking to enhance user interactivity in HarmonyOS applications with dynamic drag features.
