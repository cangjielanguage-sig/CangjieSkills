This directory contains API reference documentation for the HarmonyOS HiAppEvent module in the Cangjie programming language. It covers the framework for application event tracking, reporting, and observation, enabling developers to monitor faults, statistics, security, and user behavior. Key components include event definitions, data types, configuration options, and subscription mechanisms. It is suitable for Cangjie developers integrating performance analysis, debugging, and custom logging into their applications within the HiviewDFX subsystem.
