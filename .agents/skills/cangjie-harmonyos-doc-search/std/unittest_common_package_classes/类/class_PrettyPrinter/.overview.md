# class_PrettyPrinter

This directory provides comprehensive API reference documentation for the Cangjie `PrettyPrinter` class, a utility designed for sophisticated formatted console output. It covers a wide range of features including color management, text alignment (left, right, center), indentation control, and string appending mechanisms. The documentation highlights the class's ability to handle both raw strings and objects implementing the `PrettyPrintable` interface, with a focus on method chaining for fluent code construction. This resource is essential for Cangjie developers, particularly those building testing frameworks or command-line tools that require structured, readable, and aesthetically pleasing text output.

### class_PrettyPrinter_9more.md
This document serves as the primary API reference for the Cangjie PrettyPrinter class, designed to handle formatted output with color, alignment, and indentation control. It details the class constructor, the `isTopLevel` property, and various append methods including standard string appending, line appending, and specific alignment functions like `appendCentered` and `appendLeftAligned`. Key information includes support for adding both raw strings and objects implementing the `PrettyPrintable` interface, with the note that standard string append methods do not support multi-line strings. All append methods return the printer instance for method chaining. This reference is intended for Cangjie developers, likely within a testing or utility context, who need to generate structured, readable text output.
