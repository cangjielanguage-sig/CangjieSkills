# Span

This directory contains comprehensive documentation for the Span component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the component's architecture, text styling properties, event handling, and practical code examples. Key topics include inline text display, font customization, decoration styles, and click interactions. This resource is suitable for HarmonyOS developers and UI designers looking to implement rich text formatting and user interaction handling in their applications using ArkUI version 22 and above.

## Detailed Description

### Span_5more.md Span_5more.md
This document provides API reference documentation for the Span component within the ArkUI framework, designed to display inline text as a child of the Text component. It details the module import process, the component creation method init which accepts a text content parameter, and specifies that no child components are supported. Key information includes the restriction on general attributes and the exclusive support for the onClick event, noting that the event target is invalid due to the component's lack of size information. Intended for developers using the Cangjie language, this guide requires understanding of basic ArkUI component architecture and resource handling.

### 组件事件_2more.md 组件事件_2more.md
This document provides API reference documentation for ArkUI component events and base types in the Cangjie language. It primarily covers the onClick function, which registers a callback for click events, and the BaseSpan abstract class, which serves as the foundation for Span components. Key details include the function signature accepting a nullable ClickEvent callback and the system capabilities required for these features. Intended for software developers, this reference helps in implementing user interaction handling and understanding component inheritance structures within the ArkUI framework, specifically targeting version 22 and above.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring text styling properties within the ArkUI framework using the Cangjie programming language. It details specific functions including decoration, fontColor, fontFamily, fontSize, fontStyle, fontWeight, letterSpacing, and textCase. Each function accepts nullable resource types like ResourceColor or Length and returns the component instance to support method chaining. All functions require SystemCapability.ArkUI.ArkUI.Full and are available starting from version 22. This technical reference is intended for UI developers using Cangjie to customize text appearance in HarmonyOS applications.
