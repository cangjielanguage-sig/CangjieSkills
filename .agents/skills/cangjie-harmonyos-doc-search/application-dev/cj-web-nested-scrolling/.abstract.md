This directory serves as a specialized technical resource for implementing nested scrolling mechanisms tailored for Web components within the ArkUI framework, utilizing the Cangjie programming language. It addresses the complex challenges associated with embedding web content into native HarmonyOS applications, focusing on the creation of a unified and fluid user experience across multi-layered interfaces. The documentation thoroughly covers essential application scenarios, the configuration of the `nestedScroll` property interface, and specific scrolling behavior rules for supported containers such as List and Grid. It is primarily designed for ArkUI developers and system engineers who need to master the coordination of touch events and scrolling hierarchies between Web components and their parent containers using the `NestedScrollMode` enum.
