This directory contains API documentation for the `MaxMinValue` interface in the Cangjie programming language. It covers the generic interface definition and its extensions across various numeric types, including signed integers (Int8, Int16, Int32, Int64, IntNative), unsigned integers (UInt8, UInt16, UInt32, UInt64, UIntNative), and floating-point numbers (Float16, Float32, Float64). The primary focus is on providing static methods `getMax` and `getMin` to retrieve boundary values. This documentation is suitable for Cangjie developers who need to programmatically access numeric limits for validation, boundary checks, or range constraints within their applications.
