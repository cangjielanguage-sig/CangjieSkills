# cj-common-components-custom-dialog

This directory serves as a specialized technical resource dedicated to the implementation of custom pop-up dialogs using the `CustomDialog` component within the ArkUI framework, specifically targeting the Cangjie language. It provides a deep dive into the mechanics of building interactive overlays, covering essential topics such as the `@CustomDialog` decorator, `CustomDialogController` management, and comprehensive user interaction handling. Despite the industry trend and framework recommendations favoring the Navigation component over `CustomDialog`—hence the "not recommended" label—this collection remains an invaluable reference for developers who must maintain existing codebases or require specific custom overlay behaviors that standard navigation cannot easily provide. The guide explores advanced implementation details, including modal properties, complex styling techniques involving borders and shadows, and the often complex intricacies of nested dialog lifecycles. It is primarily suitable for HarmonyOS developers and Cangjie language practitioners looking to master overlay mechanics and state management.

### 基础自定义弹出框CustomDialog不推荐/

This directory serves as a technical resource for implementing custom pop-up dialogs using the `CustomDialog` component within the ArkUI framework, specifically targeting the Cangjie language. Although the usage of `CustomDialog` is marked as "not recommended" in favor of the Navigation component, this collection provides detailed instructions for developers who need to build or maintain custom interactive overlays. The content covers fundamental concepts such as the `@CustomDialog` decorator, `CustomDialogController` management, and user interaction handling. It also explores advanced topics including modal properties, complex styling with borders and shadows, and the intricacies of nested dialog lifecycles. This guide is suitable for HarmonyOS developers looking to master overlay mechanics and state management in Cangjie applications.
