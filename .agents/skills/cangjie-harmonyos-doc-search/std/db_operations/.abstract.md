This directory serves as an essential technical resource for developers utilizing the Cangjie programming language to interact with databases. It specifically focuses on the OpenGauss driver, providing a detailed walkthrough of the `std.database.sql` library. The content covers the full spectrum of standard CRUD (Create, Read, Update, Delete) operations, offering practical, executable code examples for each stage. Developers will learn the critical workflow involving driver acquisition, secure connection establishment, and the use of PreparedStatement for safe parameter binding. The guide also explains how to handle complex database responses, such as retrieving auto-generated keys and processing result sets. This documentation is tailored for Cangjie developers who need to integrate robust, secure, and efficient SQL database functionalities into their software applications, ensuring adherence to best practices in data management.
