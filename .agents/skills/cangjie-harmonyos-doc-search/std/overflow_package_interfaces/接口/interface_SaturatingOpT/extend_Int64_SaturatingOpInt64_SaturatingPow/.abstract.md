This directory provides a comprehensive collection of API reference documentation designed for extending the Int64 type within the Cangjie programming language to support advanced saturating arithmetic capabilities. It thoroughly covers the implementation of SaturatingOp and SaturatingPow interfaces, detailing specific functions such as saturatingAdd, saturatingMul, saturatingDiv, and saturatingPow. The documentation highlights the critical saturation strategy where operations return the type's maximum value on overflow and minimum value on underflow, effectively preventing wrapping behavior and ensuring numerical stability. Additionally, it covers safe bit-shifting and subtraction methods. This resource is essential for Cangjie developers who need to perform safe, predictable arithmetic operations on 64-bit integers without the risks associated with standard overflow errors or undefined behavior in their applications.
