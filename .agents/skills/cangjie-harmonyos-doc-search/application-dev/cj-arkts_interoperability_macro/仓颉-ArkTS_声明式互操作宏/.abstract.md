This directory provides a comprehensive technical guide for the Cangjie-ArkTS declarative interop macro mechanism. It focuses on parsing annotated Cangjie code to automatically generate ArkTS declaration files and interoperability layers, offering developers a near-native calling experience. The content covers type mapping rules, usage procedures, and specific implementation scenarios for functions, classes, and enums. Designed for HarmonyOS and OpenHarmony developers, this resource aims to streamline cross-language integration, enhance development efficiency, and ensure type safety between Cangjie backend logic and ArkTS frontend applications.
