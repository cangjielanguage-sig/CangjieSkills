This directory provides comprehensive tutorials for integrating Cangjie modules into HarmonyOS ArkTS projects using DevEco Studio. It focuses on enabling interoperability between the ArkTS and Cangjie programming languages, covering various integration scenarios such as adding modules within the same project and incorporating static library modules. Key technical aspects include configuration file generation (cjpm.toml, oh-package.json5), dependency management, and the implementation of cross-language function calls. These resources are specifically tailored for HarmonyOS developers who wish to extend their applications by combining the robust features of ArkTS with the capabilities of the Cangjie language.
