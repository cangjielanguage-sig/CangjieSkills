# 绑定半模态页面bindSheet

This directory focuses on the `bindSheet` component within the ArkUI framework, specifically utilizing the Cangjie language. It provides comprehensive guides on implementing and configuring semi-modal pages (bottom sheets) for various UI scenarios. Key topics include managing nested scrolling interactions, customizing dismissal and spring-back behaviors, and understanding component lifecycles. The documentation covers essential parameters, gesture handling rules, and usage constraints to ensure smooth user experiences. This resource is suitable for UI developers and engineers building context-preserving popup interfaces with complex interaction logic in Cangjie applications.

## Detailed Description

### 使用嵌套滚动交互.md
This guide explains how to implement and configure nested scrolling interactions within semi-modal panels in ArkUI using the Cangjie language. It details interaction priority rules based on content position (top, middle, bottom) to determine whether gestures resize the panel or scroll the content. Key information includes the requirement to apply the .nestedScroll modifier with specific NestedScrollOptions to scrollable containers like Lists. The document provides a complete code example demonstrating the configuration to ensure smooth gesture handling. This tutorial targets developers building complex UIs with scrollable components inside bottom sheets.

### 屏蔽部分关闭行为.md
This technical guide explains how to customize and control the dismissal and spring-back behaviors of half-modal sheets in Cangjie applications. The document covers the onWillDismiss interface for handling dismissal logic and the onWillSpringBackWhenDismiss interface for managing spring-back animations during user interactions. Key information includes that declaring these interfaces overrides default behaviors, requiring explicit calls to dismissSheetAction.dismiss() or springBackAction.springBack() to execute actions. Examples demonstrate restricting closure to slide-down gestures and disabling spring-back effects. This guide targets Cangjie developers building UIs who need granular control over modal interaction logic.

### 绑定半模态页面bindSheet_3more.md
This document serves as a technical guide for implementing the `bindSheet` semi-modal page component within the ArkUI framework. It covers the definition, use cases, and configuration options for semi-modal interactions, including support for different device widths and modal types. Key sections detail usage constraints, specifically advising against specific dismissal interfaces unless necessary, and define the lifecycle callback sequence: `onWillAppear`, `onAppear`, `onWillDisappear`, and `onDisappear`. The document highlights that semi-modals are best for simple tasks like sharing or content creation, while complex flows should use full modal transitions. Targeted at UI developers, this guide provides essential parameters and behavioral rules for creating context-preserving popup interfaces.
