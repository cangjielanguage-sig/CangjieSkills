This directory provides comprehensive documentation on the ArkUI framework's mirroring capability, which flips display content on the X-axis to accommodate Right-to-Left (RTL) reading habits. It covers core concepts like LTR and RTL layouts, activation conditions, and specific implementation details for components like Canvas. Additionally, it outlines usage constraints and limitations for various UI elements. This resource is essential for ArkUI developers and UI engineers working on internationalization (i18n) and bidirectional layout adaptation within the HarmonyOS ecosystem.
