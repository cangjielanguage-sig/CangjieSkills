This directory serves as an essential resource for OpenHarmony developers, providing a detailed tutorial on how to successfully add Cangjie pages to projects primarily built with ArkTS. The content delves into the conceptual framework of Cangjie page components, clarifying a critical architectural distinction: these components are designed to function as embedded elements within ArkTS containers rather than existing as standalone, independent pages. The guide meticulously walks through the file creation process using DevEco Studio, ensuring developers can generate the necessary code structure with confidence. Key technical topics include the application of the `@HybridComponentEntry` decorator to Cangjie classes and the utilization of `CJHybridComponent` within ArkTS files to achieve seamless integration. This documentation is specifically tailored for developers navigating the complexities of a mixed ArkTS and Cangjie development environment, offering the precise instructions needed to implement hybrid components effectively.
