This directory contains API reference documentation for the `ohos.web.webview` module in the Cangjie programming language, designed for HarmonyOS application development. It covers essential components for integrating web content into native apps, including navigation history management, HTTP header handling, security level classification, and user interaction detection. The documentation details classes like `BackForwardList`, `HistoryItem`, `WebHeader`, and enums such as `SecurityLevel` and `WebHitTestType`. It also includes comprehensive references for `WebCookieManager` and `WebviewController`. This resource is suitable for Cangjie developers and engineers using the ArkUI framework and ArkWeb kit to build robust web-enabled applications with advanced browsing capabilities.
