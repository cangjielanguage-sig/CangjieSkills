This directory contains the API reference documentation for the `cj-apis-telephony_sim` module, a critical component for developers working with the Cangjie programming language in the HarmonyOS environment. It provides a robust framework for managing telephony SIM cards, enabling applications to query hardware types, track operational states, and access detailed account information. The documentation outlines essential enumerations for card standards and details the usage of the `IccAccountInfo` and `TelephonySim` classes for data retrieval and management. This resource is specifically curated for software developers aiming to integrate advanced telephony features into their applications, requiring adherence to specific permission models and system capabilities introduced in API version 19.
