This directory provides comprehensive technical documentation on the `@BuilderParam` macro within the ArkUI and Cangjie UI frameworks. It focuses on how developers can dynamically reference `@Builder` functions to inject specific UI content into custom component instances, effectively acting as slot placeholders. The content covers initialization methods, usage scenarios, type matching, and common troubleshooting for compilation errors. It is suitable for HarmonyOS developers and UI engineers looking to implement dynamic, declarative UI components with flexible content injection capabilities while managing component scope and state effectively.
