This directory provides comprehensive API references for handling component events within the ArkUI framework using the Cangjie language. It focuses specifically on the intricate event handling mechanisms required for text input components. The documentation covers a wide array of functionalities, including real-time text modification tracking, clipboard operations like copy and paste, scroll monitoring, and form submission logic. Additionally, it details interception events that allow developers to control text insertion and deletion. This resource is essential for software developers and UI engineers seeking to implement robust, interactive text controls with granular management over user input behaviors and system-level event responses.
