# cj-acm-tool

The `cj-acm-tool` directory functions as a centralized documentation hub for the Account Manager (ACM) command-line utility. It is specifically tailored for developers and system administrators who require precise control over local account management within a shell environment. This resource covers the complete account lifecycle, including creation, deletion, switching, and deactivation, while also detailing the configuration of account constraints. It is an essential guide for professionals managing diverse account types such as admin or guest, ensuring they can enforce system-level policies effectively. Users should possess a working knowledge of system permissions and the hdc tool to utilize this documentation fully.

## Detailed Description

### [1] acm工具/

This directory provides in-depth technical documentation for the Account Manager (acm) command-line tool. It is designed as a specialized utility for developers and system administrators who need to manage local accounts with high efficiency. The documentation comprehensively covers the full spectrum of account lifecycle operations. Users will find detailed instructions on creating new accounts, deleting obsolete ones, switching between active users, and deactivating accounts as needed. Furthermore, it addresses the configuration of specific account constraints, allowing for fine-tuned control over user permissions and behaviors.

The content assumes that the reader has a certain level of technical proficiency, specifically familiarity with shell environments, system permissions, and the hdc tool. It serves as a vital resource for scenarios requiring the management of distinct account types, such as admin or guest accounts. By following these guidelines, users can enforce system-level constraints and maintain a secure, organized account structure directly via the command line.
