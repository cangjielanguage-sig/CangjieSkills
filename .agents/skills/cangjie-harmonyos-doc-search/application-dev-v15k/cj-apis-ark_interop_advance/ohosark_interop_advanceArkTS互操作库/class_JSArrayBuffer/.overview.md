# class_JSArrayBuffer

This directory provides comprehensive API reference documentation for the `JSArrayBuffer` class within the Cangjie programming language, specifically designed to handle generic raw binary data buffers within the ArkUI NAPI framework. It serves as a crucial resource for developers needing to manage low-level memory and data structures. The content covers core functionalities such as the read-only `byteLength` property and various conversion functions like `readBytes`, `toFloat32Array`, and `toInt32Array`. It emphasizes bidirectional data handling, enabling the conversion of JavaScript ArrayBuffer objects into native Cangjie arrays or ArkTS-compatible JSValue wrappers. This documentation is essential for Cangjie developers working on HarmonyOS applications who require precise binary data manipulation and robust interoperability between the ArkTS and Cangjie environments.

### func_toInt64ArrayJSValue_12more.md
This API reference document details Cangjie functions for converting data into various typed arrays within the ArkUI Napi framework. Key information includes two distinct conversion variants for each type: one returns a native Cangjie Array, while the other returns a JSValue representing the corresponding ArkTS TypedArray, such as BigInt64Array or Uint8Array.
