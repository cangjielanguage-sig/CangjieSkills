# 组件事件

This directory provides comprehensive API reference documentation for managing component events within the ArkUI framework, specifically utilizing the Cangjie programming language. It focuses extensively on the intricacies of text input event handling, offering detailed guidance on callback functions for content modifications, clipboard operations, and cursor management. The documentation covers critical aspects such as monitoring edit states, intercepting text insertion or deletion, and handling system input method interactions. It is designed for developers and engineers building ArkUI applications who require precise control over user interactions, state synchronization, and advanced text input behaviors.

## Detailed Description

### func_onChangeString_-_Unit_7more.md
This document serves as an API reference for text input event handling functions within the ArkUI framework using the Cangjie language. It details callback functions for content changes, scrolling, clipboard operations (copy/cut), and specific input events (insert/delete), along with their parameters and system capabilities. Key takeaways include the specific trigger conditions for onChange, such as keyboard input and pasting, and the restriction of onDidInsert and onDidDelete to system input methods only. The documentation also highlights versioning requirements, with most functions starting from version 12 and some from version 19. This guide is intended for developers implementing text input components who need to manage user interactions, cursor logic, and state changes programmatically.

### func_onEditChangedBool_-_U_6more.md
This document provides API reference documentation for text input event handling functions within the ArkUI framework using the Cangjie language. It details six specific callback functions: onEditChanged, onPaste, onSubmit, onTextSelectionChange, onWillDelete, and onWillInsert. Key information includes function signatures, system capabilities, and parameter descriptions for monitoring edit states, handling paste and submit actions, tracking cursor selection, and intercepting text insertion or deletion. The document highlights that interception functions return boolean values to allow or deny operations and are restricted to system input methods. This reference guide targets application developers using ArkUI who need to implement advanced text input control and event interception logic. Keywords: ArkUI, Cangjie, text input, event handling, callbacks, API reference.
