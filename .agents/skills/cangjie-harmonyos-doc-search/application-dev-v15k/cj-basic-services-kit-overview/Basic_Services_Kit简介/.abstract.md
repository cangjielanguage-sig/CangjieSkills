This directory provides a comprehensive introduction to the Basic Services Kit, a foundational framework designed specifically for Cangjie language developers aiming to build robust applications. It covers a wide array of essential system capabilities, ranging from clipboard operations and file transfers to inter-process communication (IPC) and device management. The documentation details usage scenarios for data processing, background downloads, and power management, while also clarifying architectural boundaries with other system kits like Ability Kit and Core File Kit. It is highly suitable for developers seeking to understand available system services, identify appropriate APIs for common tasks, and grasp the functional relationships within the broader development ecosystem. By exploring these documents, users can effectively leverage system utilities like account management and time zones to enhance their application's functionality.
