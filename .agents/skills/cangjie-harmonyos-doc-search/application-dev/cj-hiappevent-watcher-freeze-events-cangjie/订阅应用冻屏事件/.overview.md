# 订阅应用冻屏事件

This directory serves as a comprehensive technical guide for developers utilizing the Cangjie language to implement subscription mechanisms for application freeze events. It focuses on the practical application of the HiAppEvent module to monitor system performance anomalies, specifically targeting app freeze scenarios. The documentation covers the complete development workflow, including importing necessary dependencies, configuring Watchers and AppEventFilters, and managing event callbacks to parse critical parameters such as exception messages and memory usage. Furthermore, it provides a detailed reference for Cangjie interfaces, outlining methods for initiating and terminating event subscriptions. This content is essential for Cangjie application developers using DevEco Studio who are dedicated to optimizing application stability, conducting thorough performance analysis, and ensuring a seamless user experience through proactive debugging and anomaly detection.
