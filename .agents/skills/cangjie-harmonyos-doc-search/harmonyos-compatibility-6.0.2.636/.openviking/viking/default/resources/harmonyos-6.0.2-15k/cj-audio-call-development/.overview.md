# cj-audio-call-development

This directory serves as a specialized resource hub for developers focusing on the implementation of audio call functionality within HarmonyOS applications. It provides a comprehensive guide designed to assist in the creation of Voice over IP (VOIP) and other communication features. The content primarily addresses the technical challenges of managing simultaneous audio streams, detailing the use of `AudioCapturer` for local voice recording and `AudioRenderer` for remote audio playback. Key topics include audio scene management, ringtone mode verification, and the lifecycle management of audio streams. This directory is suitable for application developers seeking practical examples in Cangjie and ArkTS to effectively handle audio data flow, permissions, and state validation.
