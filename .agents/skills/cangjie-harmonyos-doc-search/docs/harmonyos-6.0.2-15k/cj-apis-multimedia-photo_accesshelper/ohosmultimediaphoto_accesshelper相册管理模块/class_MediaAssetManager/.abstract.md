This directory contains API reference documentation for the Cangjie class `MediaAssetManager`, part of the MediaLibraryKit for HarmonyOS development. It focuses on requesting and managing media assets like images, moving photos, and videos using strategy patterns. Key functionalities include retrieving image data, loading dynamic photos, and saving video files to the application sandbox. The documentation covers static methods, required permissions (such as `ohos.permission.READ_IMAGEVIDEO`), system capabilities, and exception handling. It is intended for HarmonyOS developers who need to integrate media asset handling, file management, and resource access into their applications using the Cangjie language.
