### enum_Date.md enum_Date.md
本文档是Cangjie语言的API参考文档，定义了用于配置系统时间和日期格式的Date枚举。主要涵盖DateFormat、TimeFormat、AutoGainTime和AutoGainTimeZone等成员及toString方法。文档详细解释了如何设置日期格式、12/24小时制以及自动获取网络时间，并提供了包含异常处理的代码示例。该文档面向使用BasicServicesKit进行系统设置开发的开发者，旨在帮助其通过枚举值读取和配置时间相关设置。
