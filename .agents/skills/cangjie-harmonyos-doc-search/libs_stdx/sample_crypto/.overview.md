# sample_crypto

The `sample_crypto` directory is a specialized technical resource designed to assist developers in mastering cryptographic operations within the Cangjie programming environment. It provides a focused, practical tutorial on the SM4 algorithm, a standard symmetric encryption method widely used in secure data transmission. The content delves into the specifics of configuring the SM4 cipher in Cipher Block Chaining (CBC) mode, which is essential for enhancing security in block encryption. Key topics include the proper generation and handling of cryptographic keys, the management of initialization vectors (IVs), and the transformation of data between string and byte array formats. By leveraging the `stdx.crypto.crypto` library, this guide offers a step-by-step approach to executing encryption and decryption routines and validating the output. This directory is an ideal starting point for Cangjie developers, security engineers, or students who require a concise yet complete example of implementing modern symmetric cryptography in their applications.
