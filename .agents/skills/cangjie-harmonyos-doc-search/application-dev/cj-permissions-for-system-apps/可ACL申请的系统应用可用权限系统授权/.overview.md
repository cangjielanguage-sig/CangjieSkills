# 可ACL申请的系统应用可用权限系统授权

This directory contains reference documentation for sensitive system permissions in OpenHarmony and HarmonyOS that require Access Control List (ACL) enablement. It covers permissions available from API version 12 onwards, categorized by functionality such as account management, casting, factory operations, security, and telephony. These permissions typically use `system_grant` authorization and are restricted to `system_basic` or `system_core` levels. This resource is essential for system application developers and security integrators who need to implement privileged functionalities and understand the specific authorization requirements for accessing restricted device capabilities.

### ohospermissionACCESS_ACCO_19more.md
Defines API 12 permissions for account management, UI abilities, cloud synchronization, device finding, USB configuration, system dialogs, status bar icons, audio effects, and security features like secure paste and developer mode. All listed permissions use system_grant authorization, require ACL enablement, and are categorized as system_basic or system_core levels.

Lists API 12 permissions for casting engines, enterprise bundle installation, sensor management, print jobs, security models, developer mode, audio capture, Wi-Fi info, and power management.
