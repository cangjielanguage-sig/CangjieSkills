# 应用链接说明

This directory provides comprehensive documentation on configuring application links (URIs) for HarmonyOS development. It details the implementation of deep linking, routing rules, and specific interaction features within the `module.json5` configuration file. Key topics include the `uris` tag structure, URL construction constraints, and the `linkFeature` attribute for scenarios like login and payment. This resource is essential for HarmonyOS developers and system integrators aiming to enhance cross-application navigation and web-to-app connectivity.

## Detailed Description

### uris标签说明.md
This reference guide explains the configuration of the uris tag within the module.json5 file for defining application routing and deep linking capabilities. It details specific fields including scheme, host, port, path, pathStartWith, and pathRegex, alongside the linkFeature attribute. The document outlines URL construction rules, constraints like mandatory lowercase schemes, and the 150 limit for linkFeatures. It categorizes linkFeature values for system recognition (e.g., Navigation) and one-click return scenarios (e.g., Pay, Login). Targeted at HarmonyOS developers, this guide ensures proper URI matching and enhances cross-application navigation experiences.

### 配置示例.md
This document serves as a technical reference providing a JSON configuration example for implementing an authorization login scenario. It focuses on the "uris" array structure, explaining the relationship between network parameters and functional attributes. Key information includes the definitions for scheme, host, path, and the linkFeature parameter, which is set to "Login" to trigger specific app behaviors. This guide is designed for developers or system integrators who need to configure deep links or web-to-app connections, requiring a basic understanding of JSON syntax and URI components.
