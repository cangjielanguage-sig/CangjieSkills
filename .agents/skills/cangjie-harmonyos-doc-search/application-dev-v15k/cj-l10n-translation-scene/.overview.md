# cj-l10n-translation-scene

This directory contains a specialized guide focused on localization best practices, specifically targeting the critical challenge of providing sufficient translation context. It addresses the common problem of ambiguity in UI strings by outlining effective strategies for conveying scene information to translators. The content details two primary methodologies: embedding rich, descriptive annotations directly within string resource files and supplementing these with visual interface screenshots. Key concepts covered include defining part of speech, clarifying key term meanings, establishing maximum text length constraints, and explaining variable definitions. This resource is essential for developers and localization managers who need to prepare technical assets for translation, ensuring that the final localized product accurately reflects the original linguistic intent and user experience. By following these guidelines, teams can significantly reduce translation errors and improve the quality of international software releases.
