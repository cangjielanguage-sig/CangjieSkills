# 基础类型定义

This directory defines the fundamental data structures and enumerations required for implementing drag-and-drop functionality within the Cangjie ArkUI framework. It covers essential classes like `DragInfo`, `DragItemInfo`, and `DragEvent`, alongside enumerations such as `DragBehavior`, `DragResult`, and `PreDragStatus`. These components manage data transfer, visual representation, interaction states, and event handling. Designed for Cangjie developers and HarmonyOS engineers, this documentation provides the necessary building blocks to create interactive UI components with robust drag-and-drop capabilities, requiring SystemCapability.ArkUI.ArkUI.Full (version 19 or later).

## Detailed Description

### class_DragInfo_2more.md class_DragInfo_2more.md
This API reference document defines data structures for handling drag-and-drop interactions in the Cangjie ArkUI framework. It details the DragInfo class for event parameters and the DragItemInfo struct for visual representation during dragging. Key information includes DragInfo storing coordinates and JSON-formatted extra parameters like selectedIndex, while DragItemInfo configures the drag visual using either a PixelMap image or a custom builder function. Targeted at Cangjie developers, this documentation requires understanding of ArkUI components and system capabilities to implement drag functionality.

### enum_DragBehavior_2more.md enum_DragBehavior_2more.md
This API reference document defines two enumerations, DragBehavior and DragResult, used for managing drag-and-drop interactions in the ArkUI framework. The documentation details the DragBehavior enum (COPY, MOVE, UNKNOWN) for describing data manipulation intent and the DragResult enum (DRAG_SUCCESSFUL, DROP_ENABLED, etc.) for indicating operation status. Key information includes that DragBehavior specifies copy or move actions returned via onDragEnd, while DragResult controls drop permissions and outcomes within onDrop and onDragMove callbacks. This is intended for UI developers implementing drag-and-drop functionality using the Cangjie language.

### enum_PreDragStatus.md enum_PreDragStatus.md
This API reference document defines the PreDragStatus enum used to track the lifecycle of drag-and-drop gestures in the ArkUI framework. It details six specific states ranging from initial gesture detection to animation completion and cancellation scenarios. Key information includes specific trigger conditions for each state, such as timing thresholds (e.g., 50ms for detection, 500ms for ready) and distinct animation phases like lift and landing. This documentation is intended for Cangjie developers implementing custom drag behaviors or handling pre-drag UI feedback in ArkUI applications.

### class_DragEvent/
This directory provides comprehensive API reference documentation for the `DragEvent` class within the Cangjie language, specifically tailored for the ArkUI framework. It encompasses the essential tools required to handle complex drag-and-drop interactions in application development. Key topics include public properties such as `dragBehavior` and `useCustomDropAnimation`, as well as methods for accessing real-time data like coordinates, velocity, and keyboard modifier states. The documentation also explains how to manage system versus custom drop animations. This resource is intended for software developers and engineers working on HarmonyOS applications who need to implement or customize interactive drag-and-drop functionality, requiring SystemCapability.ArkUI.ArkUI.Full (version 19 or later).
