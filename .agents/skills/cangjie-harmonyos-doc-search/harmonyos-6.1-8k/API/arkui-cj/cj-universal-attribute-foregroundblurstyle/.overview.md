# cj-universal-attribute-foregroundblurstyle

本目录提供了ArkUI框架中通用属性“前景模糊样式”的详细API参考文档，专门面向使用仓颉语言进行应用开发的工程师。该文档的核心内容是指导开发者如何为组件添加内容模糊效果，从而丰富UI的视觉表现力。文档涵盖了模块的导入方式、`foregroundBlurStyle`函数的两种重载形式（分别用于设置基础模糊样式及带选项的模糊样式），以及相关的`BlurStyle`枚举和`ForegroundBlurStyleOptions`配置类。通过链式调用支持，开发者可以灵活地控制模糊效果。此文档适用于ArkUI API 22及以上版本，是构建现代化、高质感用户界面的重要参考资料。

## Detailed Description

### cj-universal-attribute-foregroundblurstyle.md cj-universal-attribute-foregroundblurstyle.md

本文档是ArkUI框架的API参考文档，主要介绍如何为组件添加内容模糊效果。文档包含模块导入说明及两个重载的foregroundBlurStyle函数定义，分别支持仅设置模糊样式和同时设置模糊样式与选项。关键参数包括BlurStyle枚举和ForegroundBlurStyleOptions类，函数返回组件实例本身以支持链式调用，起始版本为22。面向使用仓颉语言开发ArkUI应用的开发者，用于实现UI视觉特效。
