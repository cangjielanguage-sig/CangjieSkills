This directory contains comprehensive API reference documentation for the `FileIo` class in the Cangjie programming language, designed for HarmonyOS application development. It covers a wide range of file system operations, including basic file access, directory manipulation, stream creation, and random access file handling. The documentation details static functions for reading, writing, copying, moving, and deleting files within the application sandbox, along with robust error handling and exception management. It is suitable for Cangjie developers and software engineers who need to implement efficient file I/O operations, manage system resources, and handle file permissions using the CoreFileKit.
