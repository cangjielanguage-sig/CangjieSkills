# cj-prerequisites

This directory serves as the comprehensive starting point for developers aiming to implement user identity authentication features within HarmonyOS applications. It focuses on the essential prerequisites and the complete workflow required to build secure verification systems. The content specifically addresses the integration of advanced biometric capabilities, such as face and fingerprint recognition, while emphasizing the critical need for proper system-level authorization. Developers will find detailed instructions on querying device hardware capabilities, managing the authentication initiation process, and handling verification results effectively. Additionally, the guide highlights the mandatory configuration of the `ohos.permission.ACCESS_BIOMETRIC` permission within the `module.json5` file. This documentation is specifically tailored for application developers seeking to enhance their apps with robust, secure identity verification mechanisms, offering a structured roadmap that links to specific implementation guides for every stage of the development lifecycle.

## Detailed Description

### cj-prerequisites.md cj-prerequisites.md

This document acts as the definitive guide for understanding the prerequisites and establishing the workflow for developing user identity authentication features. It provides a comprehensive, step-by-step process that developers must follow to successfully integrate secure verification into their applications. The workflow covers essential stages such as querying device capabilities to ensure hardware support, initiating the authentication request, and verifying the final results. Furthermore, it addresses optional functionalities, including the ability to cancel operations and customize the user experience to fit specific application needs.

A critical technical requirement highlighted in this guide is the declaration of the `ohos.permission.ACCESS_BIOMETRIC` permission. This permission must be explicitly configured in the `module.json5` file to grant the application access to sensitive biometric capabilities, such as face and fingerprint recognition. The guide explains that these features rely on system-level authorization to maintain high security standards. Ultimately, this document is intended for application developers who are preparing to integrate secure identity verification, acting as a strategic roadmap that provides links to detailed implementation guides for each specific development stage.
