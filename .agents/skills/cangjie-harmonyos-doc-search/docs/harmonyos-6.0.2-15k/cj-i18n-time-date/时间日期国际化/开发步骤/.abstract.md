This directory provides a technical guide for developers using the LocalizationKit framework in the Cangjie programming language. It focuses on the development steps required to implement internationalization features, specifically the formatting of time, dates, and relative time ranges. Key topics include the `RelativeTimeFormat` and `DateTimeFormat` classes, covering object instantiation, configuration options, and locale-specific styling. This documentation is suitable for Cangjie developers who need to display user-friendly temporal data and manage precise localization settings in their applications.
