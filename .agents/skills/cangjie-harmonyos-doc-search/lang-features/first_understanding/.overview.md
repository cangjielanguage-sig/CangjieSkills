# first_understanding

The `first_understanding` directory provides a comprehensive introduction to the Cangjie programming language, designed to help developers get started from scratch. It covers essential topics including environment setup, core language features, and writing the first program. This section is ideal for beginners who want to understand the design philosophy, syntax basics, and installation procedures of Cangjie. By exploring these resources, users will gain a solid foundation in multi-paradigm programming, type safety, and efficient concurrency, enabling them to quickly set up their development environment and begin coding.

## Quick Navigation

**What do you want to do?**

- Set up the development environment and configure tools → [1] install/
- Understand core features, philosophy, and language basics → [2] basic/
- Write and run your first "Hello World" program → [3] hello_world/

## Detailed Description

### [1] install/
This directory serves as the central hub for all resources related to the installation and configuration of the Cangjie programming language. It is designed to guide developers through the process of setting up a complete development environment, ensuring all necessary tools and dependencies are correctly installed.

### [2] basic/
This directory contains introductory documentation for the Cangjie programming language, aiming to help developers fully understand its core features and design philosophy. The content covers key areas such as multi-backend support, concise syntax, multi-paradigm programming, type and memory safety, efficient concurrency, ecosystem compatibility, and UI development. Cangjie balances development efficiency with runtime performance, featuring static strong typing, automatic memory management, and lightweight threads. It is suitable for all-scenario application developers to read as an introductory overview to master the Cangjie language and its application value.

### [3] hello_world/
This directory is an introductory tutorial for the Cangjie programming language, designed to guide beginners in writing and running their first "Hello World" program. The documentation details two core methods: compiling directly using the `cjc` compiler and building using the `cjpm` project management tool. The content comprehensively covers basic code structure, comment syntax, cross-platform compilation command differences, project initialization steps, and standard directory structures. This tutorial is particularly suitable for Cangjie language beginners, helping users quickly master the basic development workflow, smoothly set up the development environment, and run their first program.
