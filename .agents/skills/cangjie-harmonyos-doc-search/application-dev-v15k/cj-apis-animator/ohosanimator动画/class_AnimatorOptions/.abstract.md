This directory contains comprehensive documentation for the `AnimatorOptions` class in the Cangjie language, specifically designed for configuring animation behaviors within the ArkUI framework. It covers the class constructor and its essential properties for defining animation parameters such as duration, delay, iterations, and easing curves, including complex cubic-bezier and spring physics. The content is highly suitable for HarmonyOS developers and UI engineers who need to implement, customize, and control visual effects and transitions in their applications using Cangjie syntax.
