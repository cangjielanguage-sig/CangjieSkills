# 示例

This directory serves as a practical resource for developers implementing cryptographic operations within the Cangjie programming language. It focuses specifically on RSA (Rivest-Shamir-Adleman) algorithms, providing synchronous code examples that range from low-level key construction to high-level signature schemes. The content covers essential tasks such as parsing hexadecimal strings for key components using BigInt, configuring RSA PSS parameters, and managing the complete workflow of signing and verifying messages. These examples are highly suitable for software engineers and security professionals who require a deep understanding of how to manually define key specifications and integrate secure digital signatures into their Cangjie applications.

## Detailed Description

### 示例_1.md
This document provides a synchronous code example in the Cangjie language for constructing RSA asymmetric key pair specifications. It covers the import of cryptographic and BigInt libraries, a generic function genRsaKeyPairSpec for building key specs from parameters, and a specific implementation genRsa2048KeyPairSpec that parses hexadecimal strings for modulus, public exponent, and private exponent. The code demonstrates how to instantiate RSACommonParamsSpec and RSAKeyPairSpec objects, utilizing BigInt parsing for large numerical values typical in cryptography. This example targets developers working with cryptographic operations in Cangjie who need to programmatically define RSA key parameters.

### 示例_2.md
This code example demonstrates the implementation of RSA PSS (Probabilistic Signature Scheme) for message signing and verification. The document covers generating RSA key pairs, initializing cryptographic objects, and specifically configuring PSS parameters like salt length, trailer field, and message digest algorithms. Key takeaways include the methods for setting and retrieving PSS specifications on both signer and verifier instances to ensure consistency, as well as handling multi-part data updates. Intended for developers integrating cryptographic security, this tutorial illustrates the complete workflow from parameter configuration to signature validation.
