# ohoswifi_managerWLAN

This directory contains API reference documentation for the `ohos.wifi_manager` module in the HarmonyOS Cangjie development environment. It covers WLAN and Peer-to-Peer (P2P) connectivity services, providing data structures, enumerations, and functions for managing WiFi states, scanning, and connections. Key components include classes for scan information and P2P configuration, enums for security types and device addresses, and functions for event callbacks and device discovery. This documentation is suitable for developers and engineers working on network communication modules who need to implement robust WiFi functionality using the Cangjie language.

### class_WifiInfoElement.md class_WifiInfoElement.md
