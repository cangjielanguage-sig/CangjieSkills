# restool工具

This directory contains documentation for the restool tool, a command-line utility designed for compiling and managing application resources within HarmonyOS and OpenHarmony development environments. It covers essential workflows such as resource compilation (full and incremental), resource ID management, and command-line parameter configuration. The documentation explains how restool integrates with the SDK toolchains to generate indexes and parse resources for programmatic access via the resource management API. Suitable for software developers and build engineers, these guides provide the necessary instructions to automate resource handling, validate icons, and configure multi-module projects efficiently.

## Detailed Description

### 使用实例.md 使用实例.md
This document serves as a practical guide for using the restool command-line tool to manage and compile application resources. It covers two primary workflows: resource compilation and fixing resource IDs. Key sections explain the commands for full and incremental compilation, detailing the two-step process for the latter. Additionally, it provides instructions on generating or manually creating an id_defined.json file to assign specific IDs to resources. This tutorial targets software developers working with HarmonyOS or OpenHarmony project structures who need to automate resource handling and ID management via the command line.

### 参数说明.md 参数说明.md
This document serves as a reference guide for the command-line options of the restool resource compilation tool. It covers a comprehensive table of command flags and a detailed explanation of the target-config parameter. Key options include required inputs for resource directories, configuration files, and output paths, alongside optional flags for ID generation, multi-module compilation, and icon validation. The target-config section specifies syntax for filtering resources based on attributes like Locale, Device, and Density using specific matching rules. This technical documentation is intended for developers using the CLI to build and manage application resources.

### 简介.md 简介.md
This document introduces restool, a resource compilation tool designed for application engineering. It covers the tool's core functionality of compiling resource files to create indexes and parse resources, as well as its integration with the resource management API and its location in the SDK's toolchains subdirectory. The main takeaway is that restool processes resources so developers can access them programmatically through specific interfaces. This technical reference is intended for developers working within the SDK environment who need to manage and retrieve application resources. Keywords: restool, resource compilation, SDK, toolchains, resource management API.
