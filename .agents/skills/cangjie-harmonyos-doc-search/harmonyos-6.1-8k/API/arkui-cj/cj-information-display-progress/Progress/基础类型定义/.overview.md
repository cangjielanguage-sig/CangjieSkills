# 基础类型定义

本目录包含ArkUI框架中进度条组件相关的基础类型定义文档，主要面向使用仓颉语言进行UI开发的开发者。内容涵盖了环形进度条样式配置类、进度状态枚举以及通用样式接口。这些API文档详细说明了如何通过配置属性（如宽度、阴影、动效）和状态（如加载中、处理中）来实现定制化的进度条界面。核心关键词包括RingStyleOptions、ProgressStatus、CommonProgressStyleOptions、ArkUI及仓颉语言，旨在帮助开发者深入理解进度条组件的底层结构与配置逻辑。

## 详细描述

### class_RingStyleOptions.md class_RingStyleOptions.md
本文档是Cangjie语言中RingStyleOptions类的API参考文档，旨在定义环形进度条的样式配置。文档涵盖了该类的核心属性，包括进度条宽度、阴影开关、状态控制、平滑动效及扫光效果，并详细说明了构造函数的参数及其默认值。关键信息指出该类继承自CommonProgressStyleOptions，且status属性在LOADING状态下会触发特定动效。本文档主要面向使用ArkUI框架进行UI开发的Cangjie语言开发者，帮助他们通过配置这些选项来实现定制化的环形进度条界面。

### enum_ProgressStatus_fe2e7588.md enum_ProgressStatus_fe2e7588.md
这份文档是仓颉语言中 ProgressStatus 枚举的 API 参考文档，用于定义进度条的当前状态。文档涵盖了枚举的结构定义，包括 Loading（加载中）和 Progressing（处理中）等具体成员值，并详细说明了用于比较状态值相等性的 == 和 != 运算符。关键信息包括该枚举继承自 Equatable，具备 SystemCapability.ArkUI.ArkUI.Full 系统能力，且起始版本为 22。本文档主要面向使用 ArkUI 框架的开发人员，帮助他们在应用中实现或操作进度指示器。

### interface_CommonProgres_56bcfffc.md interface_CommonProgres_56bcfffc.md
该文档定义了ArkUI框架中进度条通用样式选项的接口。主要内容包括接口CommonProgressStyleOptions的定义、功能描述、系统能力要求及起始版本信息。关键信息指出这是一个密封接口，用于配置进度条样式，需要完整的ArkUI系统能力，自版本22起可用。属于API参考文档，面向使用ArkUI框架进行UI开发的开发者，特别是需要自定义进度条外观的人员。
