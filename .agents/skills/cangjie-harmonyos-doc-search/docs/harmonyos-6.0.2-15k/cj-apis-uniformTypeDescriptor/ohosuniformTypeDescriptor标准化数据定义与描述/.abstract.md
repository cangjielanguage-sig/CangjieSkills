This directory provides API reference documentation for the `ohos.uniformTypeDescriptor` module within the HarmonyOS Unified Data Management Framework (UDMF). It focuses on standardizing data type definitions and descriptions using the Cangjie programming language. Key topics include retrieving standardized data type IDs via MIME types or filename extensions, managing hierarchical type relationships, and utilizing the `TypeDescriptor` class and `UniformDataType` enumeration. This documentation is essential for developers working on distributed data management, data interoperability, and file classification in OpenHarmony systems starting from API version 19.
