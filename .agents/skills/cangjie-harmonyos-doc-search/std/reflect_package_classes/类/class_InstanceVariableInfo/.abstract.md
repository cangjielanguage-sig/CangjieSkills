This directory contains comprehensive API reference documentation for the `InstanceVariableInfo` class within the Cangjie language reflection package. It covers the metadata structure used to describe instance member variables, including properties like name, type, annotations, and modifiers. The documentation details methods for runtime access and modification of variable values, as well as operator overloads for equality comparison. It is suitable for Cangjie developers who need to dynamically inspect or manipulate program structure using reflection, requiring familiarity with Cangjie syntax and core interfaces. This documentation set ensures developers have the necessary tools to implement robust reflection mechanisms in their applications.
