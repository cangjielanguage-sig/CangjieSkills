# class_Matrix2D

This directory contains API reference documentation for the `Matrix2D` class within the Cangjie ArkUI framework. It focuses on 2D matrix transformations essential for manipulating graphics in HarmonyOS applications. The documentation covers class constructors, mutable properties for scaling and translation, and methods for matrix operations like inversion, rotation, and identity creation. Designed for ArkUI developers and graphics programmers, these resources provide the necessary syntax and code examples to implement complex 2D coordinate system manipulations and rendering effects efficiently.

## Detailed Description

### class_Matrix2D_8more.md class_Matrix2D_8more.md
This document serves as API reference documentation for the Matrix2D class in the Cangjie language, designed for handling 2D matrix transformations within the ArkUI framework. It covers the class constructor, which configures the length unit, and details six mutable properties: rotateX, rotateY, scaleX, scaleY, translateX, and translateY. These Float64 properties control horizontal and vertical skewing, scaling, and translation distances. The document includes a practical code example demonstrating how to apply these transformations to a CanvasRenderingContext2D object. Intended for HarmonyOS developers, this guide requires prior knowledge of Cangjie syntax and canvas rendering concepts.

### func_identity_3more.md func_identity_3more.md
This document serves as API reference documentation for matrix transformation functions within the Cangjie ArkUI framework. It details three specific methods: identity() for creating unit matrices, invert() for calculating matrix inverses, and rotate() for performing rotation operations around a defined point. Key information includes that all functions return the matrix instance (This), facilitating method chaining. The rotate function specifically accepts parameters for angle and rotation center coordinates (rx, ry). Practical code examples demonstrate usage within a Canvas rendering context. The target audience is ArkUI developers working with 2D graphics and transformations who need to manipulate matrix states programmatically.
