# 启动UIAbility的指定页面

This directory covers the technical implementation of launching specific pages within a UIAbility component in HarmonyOS development. It distinguishes between cold starts (initialization) and hot starts (state recovery), detailing how to use the Want object to pass parameters for navigation. Key topics include lifecycle callbacks like `onCreate`, `onWindowStageCreate`, and `onNewWant`, as well as routing logic using the Cangjie language. This guide is suitable for application developers using the Stage model who need to implement precise inter-page navigation, deep linking, or cross-app interactions.

### 概述_2more.md 概述_2more.md
This technical guide explains how to launch specific pages within a UIAbility component, distinguishing between cold starts (full initialization) and hot starts (quick state recovery). It details how a calling UIAbility can specify the target page by configuring custom parameters within the Want object. The document includes a Cangjie code example demonstrating the implementation of this navigation logic using a "router" parameter. Intended for application developers using the Stage model, this guide facilitates precise inter-page navigation across different UIAbility instances.

### 目标UIAbility冷启动.md 目标UIAbility冷启动.md
This technical guide explains the process of handling a target UIAbility cold start within the HarmonyOS development framework. It details the specific lifecycle callbacks involved, focusing on receiving parameters in onCreate() and parsing the Want object in onWindowStageCreate() to determine the page URL. The document provides a Cangjie code example demonstrating how to extract routing information from the Want parameters and utilize windowStage.loadContent() to display the correct interface. This resource is designed for developers implementing inter-Ability navigation and startup logic, emphasizing the separation of parameter reception and UI loading.

### 目标UIAbility热启动.md 目标UIAbility热启动.md
This guide explains how to handle the hot start scenario for a UIAbility component in application development, specifically when an instance is already running in the background. It covers the lifecycle behavior difference between cold and hot starts, a practical example involving SMS and Contacts apps, and step-by-step code implementation using the Cangjie language. The core takeaway is that during a hot start, the onNewWant() callback is triggered instead of initialization methods. Developers must parse Want parameters within this method and use the Router to navigate to the target page. This tutorial targets application developers needing to implement cross-app navigation or deep linking into specific pages of an already active application.
