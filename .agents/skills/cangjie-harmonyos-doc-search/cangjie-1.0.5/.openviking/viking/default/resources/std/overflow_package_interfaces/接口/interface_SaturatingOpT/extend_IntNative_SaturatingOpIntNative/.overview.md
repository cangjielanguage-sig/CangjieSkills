### extend_IntNative_Saturatin_9more.md extend_IntNative_Saturatin_9more.md
This API reference document details the implementation of the SaturatingOp interface for the IntNative type in the Cangjie programming language. The content covers the extension declaration and defines eight public functions: saturatingAdd, saturatingDec, saturatingDiv, saturatingInc, saturatingMod, saturatingMul, saturatingNeg, and saturatingShl. Key information includes that these functions perform arithmetic using a saturation strategy, clamping results to the type's maximum or minimum values upon overflow or underflow instead of wrapping. For instance, saturatingShl limits the shift amount to prevent errors. This documentation targets Cangjie developers requiring safe arithmetic operations that prevent integer wrapping errors in their applications.
