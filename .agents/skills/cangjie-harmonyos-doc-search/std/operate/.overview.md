# operate

This directory serves as a specialized educational resource focused on the advanced manipulation of Abstract Syntax Tree (AST) objects within the Cangjie programming language ecosystem. It provides a step-by-step practical tutorial that zeroes in on the `ClassDecl` node type, guiding developers through the complex process of transforming raw source code into a structured AST. The content meticulously explains how to perform type casting from generic declarations to specific class declarations and demonstrates how to programmatically alter the AST by injecting new member functions. Key technical concepts covered include the utilization of the `quote` function for dynamic code generation, the application of `parseDecl` for parsing operations, and the implementation of the `add` method to insert `FuncDecl` nodes into a class body, thereby modifying the structure size. This material is specifically curated for developers who have a solid grasp of Cangjie syntax and AST theory and are looking to implement these techniques in real-world scenarios such as building compiler tools, static analyzers, or sophisticated metaprogramming utilities. By following this guide, users will gain the necessary skills to dynamically extend class definitions and understand the internal mechanics of AST modification in Cangjie.
