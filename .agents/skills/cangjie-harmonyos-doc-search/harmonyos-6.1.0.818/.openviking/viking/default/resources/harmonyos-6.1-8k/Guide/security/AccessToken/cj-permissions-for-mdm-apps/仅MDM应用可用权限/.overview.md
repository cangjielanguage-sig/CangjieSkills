# 仅MDM应用可用权限

## 详细描述

### ohospermissionENT_9more_9c555cb4.md ohospermissionENT_9more_9c555cb4.md
该文档是OpenHarmony系统企业级权限的参考文档，详细定义了九个以ENTERPRISE为前缀的权限。主要涵盖设备管理应用管理、恢复密钥管理、策略委托、应用信息获取、用户限制、APN及通话策略管理、Kiosk模式设置和壁纸设置等功能。文档列出了每个权限的级别（多为system_basic）、授权方式（均为system_grant）、ACL使能状态及起始API版本（12至20）。部分权限限定了支持设备类型。主要面向系统开发者和企业应用开发者，用于理解设备管控所需的权限配置。

### ohospermissionEN_17more_a893026b.md ohospermissionEN_17more_a893026b.md
该文档列出了OpenHarmony系统中用于企业设备管理的17个权限定义。涵盖证书管理、设置查询、MDM应用安装、安全策略、网络控制（蓝牙/WiFi）、应用管理及设备操作（重启/锁定）等领域。所有权限均为系统授权，级别多为system_basic，需ACL使能且起始版本为12，赋予设备管理员对企业设备的全面管控权。面向OpenHarmony企业应用及MDM开发者，用于了解和申请必要的系统权限。

### 仅MDM应用可用权限_16more_1849f6a0.md 仅MDM应用可用权限_16more_1849f6a0.md
本文档是一份API参考文档，专门列出了HarmonyOS中仅对MDM（移动设备管理）应用开放的权限。主要涵盖设备信息查询、网络管理、应用安装策略、恢复出厂设置及WiFi配置等15个具体权限项。关键信息指出这些权限均为系统授权且不支持自动签名，开发调试和发布时必须完成手动签名。文档面向MDM应用开发者，旨在指导其正确申请和使用高敏感度的系统管理权限。
