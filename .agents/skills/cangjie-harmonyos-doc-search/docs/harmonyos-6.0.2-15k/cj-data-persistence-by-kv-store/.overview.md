# cj-data-persistence-by-kv-store

This directory serves as a comprehensive technical guide focused on implementing data persistence using Key-Value (KV) databases, specifically tailored for the HarmonyOS ecosystem. It provides in-depth coverage of storing low-complexity data efficiently, addressing critical topics such as usage scenarios, data size constraints, and database instance management. The content explores API references for both single-version and device collaborative databases, emphasizing the use of asynchronous APIs for CRUD operations like put, get, and delete. Designed for application developers using the Cangjie programming language and the ArkData kit, this resource is essential for those building distributed systems or simple data models. It ensures developers can implement secure, high-performance persistent storage solutions while strictly adhering to platform guidelines and optimizing for distributed data consistency.
