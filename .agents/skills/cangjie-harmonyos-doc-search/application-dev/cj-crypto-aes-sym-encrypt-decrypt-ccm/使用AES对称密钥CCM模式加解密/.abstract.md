This directory provides comprehensive resources for implementing AES symmetric encryption and decryption specifically using the CCM (Counter with CBC-MAC) mode. It covers the complete technical workflow within the CryptoArchitectureKit API, ranging from key generation and cipher creation to data processing via update and doFinal methods. Key topics include managing cryptographic parameters like IV and AAD, handling the 12-byte authentication tag (authTag) lifecycle, and understanding specific constraints such as the prohibition of segmented operations. These materials are tailored for software developers and security engineers utilizing the Cangjie programming language in a Beta environment who require both theoretical understanding and practical implementation details for cryptographic security features.
