# ohoswebwebviewWebview

本目录包含HarmonyOS应用开发中Web组件相关的Cangjie语言API参考文档。它涵盖了WebView的核心功能模块，包括网页显示控制、历史记录管理、安全级别评估、HTTP头处理以及Cookie管理。文档详细介绍了`WebviewController`、`BackForwardList`、`HistoryItem`等关键类和枚举，旨在帮助开发者实现混合开发、网页导航、交互检测及安全状态监控。适用于使用仓颉语言进行HarmonyOS/OpenHarmony应用开发，并需要集成Web功能的工程师。

## Detailed Description

### class_BackForwardList.md class_BackForwardList.md
本文档是Cangjie语言中BackForwardList类的API参考文档，旨在管理WebView的浏览历史列表。文档涵盖了类定义、只读属性currentIndex和size，以及getItemAtIndex方法。关键信息指出历史列表最多保存50条记录，依赖SystemCapability.Web.Webview.Core系统能力，并返回包含URL、标题和图标的HistoryItem对象。文档面向HarmonyOS开发者，提供了详细的Cangjie代码示例，演示如何通过WebviewController获取并输出当前历史记录的详细信息，适用于需要实现网页导航和状态管理的应用开发场景。

### class_HistoryItem_2more_71167390.md class_HistoryItem_2more_71167390.md
本文档是Cangjie语言Webview模块的API参考文档，主要定义了HistoryItem和HitTestValue两个数据类。HistoryItem用于表示页面历史记录项，包含图标、URL及标题等属性；HitTestValue用于提供点击区域的元素信息，包含元素类型及附加参数（如链接地址）。文档详细列出了各属性的读写能力、类型及系统能力要求（SystemCapability.Web.Webview.Core），起始版本均为22。该文档面向使用Cangjie进行Web应用开发的开发者，旨在帮助其处理网页历史记录管理和交互元素检测。

### class_WebHeader_d772c825.md class_WebHeader_d772c825.md

### enum_SecurityLevel.md enum_SecurityLevel.md
本文档定义了用于表示网页安全级别的SecurityLevel枚举，适用于WebView核心能力。主要内容包括枚举定义、四个具体安全级别（NoneLevel、Secure、Warning、Dangerous）的详细说明，以及相等性判断和字符串转换等操作符与方法的接口描述。关键信息在于区分不同安全状态：Secure代表HTTPS及信任证书，Dangerous涉及钓鱼或恶意软件。该枚举继承自Equatable和ToString父类型，支持版本22及以上。面向使用仓颉语言进行Web应用开发的开发者，用于评估和响应网页安全状态。关键词：SecurityLevel, WebView, 仓颉, API文档。
