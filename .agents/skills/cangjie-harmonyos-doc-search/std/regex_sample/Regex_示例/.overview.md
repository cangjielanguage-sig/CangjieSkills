# Regex_示例

This directory serves as a practical resource hub for the Cangjie programming language, specifically focusing on the application of regular expressions for text processing and data parsing. It includes detailed tutorials that guide developers through the standard regex library's capabilities, ranging from basic pattern matching to advanced text manipulation. Key topics covered include the use of the MatchData class for handling capture groups, implementing case-insensitive and multi-line matching strategies, and utilizing Unicode support for internationalization. Furthermore, it demonstrates string replacement techniques. This collection is ideal for Cangjie developers seeking to enhance their applications with robust search-and-replace functionalities and complex data extraction logic.

## Detailed Description

### MatchData_中捕获组的使用.md
This document serves as a practical tutorial demonstrating how to extract and manipulate capture groups using the MatchData class in the Cangjie programming language's standard regex library. It covers iterating through regex matches with `lazyFindAll`, accessing group counts, and retrieving group content and positions via numeric indices. Furthermore, it explains how to handle named capture groups using `getNamedGroups`. The key takeaway is the distinction between accessing groups by index versus name to obtain both the matched string and its position. This guide is intended for Cangjie developers who need to parse structured text data using regular expressions.

### Regex_匹配大小写_5more.md
This document serves as a practical tutorial for the Cangjie programming language's standard regex library. It covers five key functionalities: case-insensitive matching using the IgnoreCase option, multi-line pattern matching with MultiLine, Unicode character support via the Unicode flag, extracting match details using MatchData, and string manipulation through replace and replaceAll methods. Each section includes executable code examples and expected output to demonstrate syntax and behavior. The guide targets Cangjie developers seeking to implement text processing and pattern matching in their applications.
