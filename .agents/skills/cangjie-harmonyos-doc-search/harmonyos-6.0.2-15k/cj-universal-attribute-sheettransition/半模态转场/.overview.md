This directory focuses on the implementation and configuration of semi-modal transitions within the Cangjie UI framework. It provides comprehensive resources for developers looking to integrate interactive, draggable sheet interfaces using the `bindSheet` function. The content covers essential API references, configuration options like `SheetOptions`, and practical code examples for nested modals. Key topics include component lifecycle management, animation constraints, and state handling. This documentation is suitable for Cangjie developers and UI designers building responsive HarmonyOS applications who need to create customizable and interactive modal components.

## Detailed Description

### 半模态转场_2more.md 半模态转场_2more.md
This document serves as API reference documentation for implementing semi-modal transitions using the bindSheet function within the Cangjie UI framework. It covers the function's signature, parameters for visibility and content building, and configuration options via SheetOptions. Key information includes critical behavioral notes regarding the component lifecycle, specifically that the host node must be mounted before the sheet appears, and that exit animations are non-interruptible. The document targets developers seeking to create interactive, draggable sheet interfaces while understanding specific rendering and animation constraints.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the implementation of nested modal sheets using the `bindSheet` method within a UI component. The code covers state management with `@State` variables, lifecycle callbacks like `onAppear` and `onDisappear`, and the use of `@Builder` functions for custom layouts. Key takeaways include how to toggle visibility for two distinct modal layers and configure sheet options such as `onDisappear`. Intended for Cangjie developers building HarmonyOS applications, this example serves as a practical reference for creating interactive, multi-level modal interfaces.
