# restool工具

This directory contains comprehensive documentation for `restool`, a specialized application engineering resource compilation tool located within the SDK toolchains. It covers essential workflows such as compiling resource files, generating indexes, and managing resource IDs effectively. The content includes practical usage examples for full and incremental builds, detailed explanations of command-line parameters, and strategies for locking resource IDs to ensure stability. This documentation is suitable for developers and build engineers who need to configure resource compilation processes, handle multi-module builds, and maintain consistent resource identifiers across application updates.

## Detailed Description

### 使用实例.md 使用实例.md
This document serves as a practical usage guide for the restool command-line tool, demonstrating resource compilation and ID management workflows. The content is divided into two main sections: compiling resources and fixing resource IDs. Key information includes specific commands for full compilation using the -f flag and a two-step process for incremental compilation involving middleware generation. Additionally, it details how to create and utilize an id_defined.json file to lock specific resource IDs, either via command-line arguments or by placing the file in the resource directory. Intended for developers managing application resources, this guide provides step-by-step instructions for controlling build processes and maintaining stable resource identifiers.

### 参数说明.md 参数说明.md
This document serves as a reference guide for the command-line options of the restool resource compilation tool. It details a comprehensive table of command flags, distinguishing between mandatory parameters like input/output paths and optional features such as ID generation and multi-module compilation. Additionally, it provides a specific section explaining the `--target-config` option, outlining syntax and matching rules for filtering resources based on attributes like MccMnc, Locale, and Device. This technical documentation is intended for developers who need to configure and execute resource builds using the restool utility.

### 简介.md 简介.md
This document serves as an introduction to restool, an application engineering resource compilation tool. It outlines the tool's primary functions, which include compiling resource files, creating resource indexes, and parsing resources for easy access. The text explains that developers utilize the Resource Manager Interface to retrieve these resources after processing. Additionally, it specifies the tool's physical location within the SDK installation directory, specifically inside the toolchains subdirectory. This reference material is intended for developers using the SDK to manage application resources effectively. Keywords: restool, resource compilation, SDK, toolchains, resource management.
