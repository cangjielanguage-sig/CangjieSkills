This directory provides a comprehensive overview of state observation mechanisms and behavioral performance within a reactive UI framework. It details how the framework monitors data changes across different data types—ranging from primitive values to complex objects and collections—and translates these changes into UI updates. Key concepts include the @State decorator, on-demand rendering, and the specific observation rules of the Cangjie language. This material is essential for developers seeking to optimize application performance by understanding the underlying principles of state management and ensuring efficient, responsive UI rendering.
