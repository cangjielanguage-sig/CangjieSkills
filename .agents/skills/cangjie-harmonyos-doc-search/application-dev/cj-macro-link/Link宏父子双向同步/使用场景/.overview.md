# 使用场景

This directory serves as a comprehensive practical guide for implementing state management in Cangjie ArkUI development, specifically focusing on the diverse usage scenarios of the `@Link` decorator. It covers the implementation of two-way data synchronization between parent and child components across various data types, including simple types, class objects, and arrays. Key technical concepts explored include `@Observed`, `@Publish`, `ObservedArrayList` for array mutation detection, and the `@Watch` decorator for handling side effects during synchronization. These resources are designed for ArkUI developers who wish to deepen their understanding of component interaction and master advanced state synchronization techniques to build responsive and dynamic user interfaces. By following these tutorials, developers can ensure efficient data flow and state consistency within their applications.

## Detailed Description

The following files provide specific code examples and explanations for different data binding scenarios:

### 数组类型的Link_2more.md 数组类型的Link_2more.md

This tutorial provides advanced examples for using the @Link decorator in Cangjie ArkUI development to manage state synchronization between parent and child components. It covers two main scenarios: handling array type changes using ObservedArrayList and utilizing the @Watch decorator with @Link to update local variables during two-way synchronization. Key takeaways include that ObservedArrayList enables detection of array modifications like additions and replacements, while @Watch allows side effects such as updating local @State variables without affecting the parent component. The target audience is ArkUI developers familiar with basic state management decorators like @State and @Link.

### 简单类型和类对象类型的Link.md 简单类型和类对象类型的Link.md

This tutorial demonstrates the implementation of two-way data synchronization using the @Link decorator in ArkUI with the Cangjie language. It specifically covers how to bind both simple types and class object types between parent and child components. Key takeaways include the mechanism where changes in a child's @Link variable update the parent's @State, and the requirement for class types to use @Observed and @Publish. The document provides a complete code example showing bidirectional updates for button widths. This guide is intended for developers learning state management and component interaction in ArkUI applications.
