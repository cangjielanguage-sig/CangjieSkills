# 基础类型定义

This directory contains API reference documentation for fundamental layout constraint types within the ArkUI framework, specifically designed for the Cangjie programming language. It covers essential classes and enumerations used to define barriers and guidelines, enabling developers to implement complex and responsive UI layouts. Key topics include barrier styles, localized barrier directions, and guideline positioning. These definitions are crucial for creating adaptive interfaces that support features like mirroring for internationalization. This documentation is intended for ArkUI developers using Cangjie who need precise control over layout constraints starting from API version 12.

## Detailed Description

### class_BarrierStyle.md class_BarrierStyle.md
This API reference document details the BarrierStyle class used to define barrier parameters within the ArkUI framework for the Cangjie language. The documentation covers the class constructor and three public properties: id, direction, and referencedId. Key information includes that the class configures a barrier's unique identifier, its directional constraints (vertical or horizontal), and the specific components it relies upon. Crucially, vertical barriers serve as horizontal anchors and vice versa. Intended for ArkUI developers using Cangjie, this guide assists in implementing complex layout constraints starting from API version 12.

### class_GuideLinePosition.md class_GuideLinePosition.md
This API reference document details the Cangjie class GuideLinePosition, which defines position parameters for guidelines within the ArkUI framework. The documentation covers the class constructor and two primary public properties: start and end. Key information includes that both properties accept nullable Length types, where start specifies the distance from the container's left or top edge, and end specifies the distance from the right or bottom edge. Intended for ArkUI developers using Cangjie, this reference supports system capability ArkUI.Full starting from version 12, aiding in precise layout control.

### class_GuideLineStyle.md class_GuideLineStyle.md
This API reference document details the GuideLineStyle class used to define the properties of guidelines within the ArkUI framework. It covers the class constructor and three public properties: id, direction, and position. Key information includes that the id must be unique and distinct from component names, direction determines anchoring constraints based on the axis, and position sets the guideline's location with specific rules for auto sized containers. This documentation is intended for developers using the Cangjie language to implement layout guidelines in ArkUI applications.

### class_LocalizedBarrierStyle.md class_LocalizedBarrierStyle.md
This document provides API reference documentation for the LocalizedBarrierStyle class within the ArkUI framework, designed for the Cangjie programming language. It outlines the structure and parameters required to define a barrier used in layout constraints. The main sections include the class constructor and detailed descriptions of its properties: id, localizedDirection, and referencedId. Key information highlights that the barrier ID must be unique, the direction dictates valid anchor usage (e.g., vertical barriers for horizontal anchors), and the barrier relies on an array of referenced component IDs. This reference material targets developers building complex UI layouts who need to implement barrier-based positioning logic. It requires knowledge of Cangjie syntax and ArkUI layout systems.

### enmu_LocalizedBarrierDirection.md enmu_LocalizedBarrierDirection.md
This document serves as an API reference for the LocalizedBarrierDirection enum in the Cangjie language, defining directional properties for barrier lines within the ArkUI framework. It details four enumeration values: START, END, TOP, and BOTTOM, explaining their specific positioning relative to referenced UI elements. Key information includes that the enum supports mirroring modes; START and END positions dynamically adjust based on Left-to-Right (LTR) or Right-to-Left (RTL) layouts, whereas TOP and BOTTOM remain fixed. This reference is intended for UI developers using the ArkUI framework who need to implement responsive layout barriers that adapt to different localization settings.
