This directory provides comprehensive API reference documentation and practical examples for implementing WebSocket connections using the Cangjie language in HarmonyOS. It covers the complete lifecycle of WebSocket communication, including connection establishment, data transmission, event handling, and secure termination. Key topics include asynchronous callbacks, proxy configuration, client certificate authentication, and error management. This documentation is intended for Cangjie developers and network engineers who need to integrate real-time, bidirectional communication capabilities into their applications using the SystemCapability.Communication.NetStack.
