# 基础类型定义

This directory provides foundational type definitions for the ArkUI framework in Cangjie, covering classes, enums, and interfaces. It includes geometric definitions, styling options, event handling, layout configurations, and animation parameters. These types are essential for constructing user interfaces and managing component behavior. Intended for ArkUI developers, this documentation supports API version 22 and ensures type safety and structural consistency in application design.
