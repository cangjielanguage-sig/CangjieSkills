## 指定压缩点数据获取密钥对象

1. 指定Uint8Array类型的ECC压缩点数据，调用[convertPoint](../../../API_Reference/source_zh_cn/apis/CryptoArchitectureKit/cj-apis-crypto.md#static-func-convertpointstring-arrayuint8)对象，用于密钥对象生成。
2. 调用[genECCCommonParamsSpec](../../../API_Reference/source_zh_cn/apis/CryptoArchitectureKit/cj-apis-crypto.md#static-func-genecccommonparamsspecstring)，指定曲线名'NID_brainpoolP256r1'，生成ECC的非对称公共密钥参数。
3. 构造[ECCPubKeySpec](../../../API_Reference/source_zh_cn/apis/CryptoArchitectureKit/cj-apis-crypto.md#struct-eccpubkeyspec)，参数pk指定为得到的point对象。
4. 通过得到的公钥参数，调用[createAsyKeyGeneratorBySpec](../../../API_Reference/source_zh_cn/apis/CryptoArchitectureKit/cj-apis-crypto.md#func-createasykeygeneratorbyspecasykeyspec)，创建非对称密钥生成器（AsyKeyGeneratorBySpec）。
5. 调用[generatePubKey](../../../API_Reference/source_zh_cn/apis/CryptoArchitectureKit/cj-apis-crypto.md#func-generatepubkey)，得到指定的公钥。
6. 调用[getEncodedPoint](../../../API_Reference/source_zh_cn/apis/CryptoArchitectureKit/cj-apis-crypto.md#static-func-getencodedpointstring-point-string)，得到非压缩点数据。
7. 调用[getAsyKeySpec](../../../API_Reference/source_zh_cn/apis/CryptoArchitectureKit/cj-apis-crypto.md#func-getasykeyspecasykeyspecitem-1)，获取ECC算法中公钥pk的x坐标。

```cangjie
import kit.CryptoArchitectureKit.*

func eccPointCompressedToPoint() {
    let pkData: Array<UInt8> = [2, 143, 39, 57, 249, 145, 50, 63, 222, 35, 70, 178, 121, 202, 154, 21, 146, 129, 75, 76,
        63, 8, 195, 157, 111, 40, 217, 215, 148, 120, 224, 205, 82]
    let returnPoint = ECCKeyUtil.convertPoint('NID_brainpoolP256r1', pkData)
    AppLog.info('convertPoint success')
    let eccCommonParamsSpec = ECCKeyUtil.genECCCommonParamsSpec('NID_brainpoolP256r1')
    var eccPubKeySpec: ECCPubKeySpec = ECCPubKeySpec(params: eccCommonParamsSpec, pk: returnPoint)
    eccPubKeySpec.specType = PUBLIC_KEY_SPEC
    let generatorBySpec = createAsyKeyGeneratorBySpec(eccPubKeySpec)
    let pubKey = generatorBySpec.generatePubKey()
    let returnData = ECCKeyUtil.getEncodedPoint('NID_brainpoolP256r1', returnPoint, 'UNCOMPRESSED')
    AppLog.info('returnData: ${returnData}') // 4,143,39,57,249,145,50,63,222,35,70,178,121,202,154,21,146,129,75,76,63,8,195,157,111,40,217,215,148,120,224,205,82,83,92,185,21,211,184,5,19,114,33,86,85,228,123,242,206,200,98,178,184,130,35,232,45,5,202,189,11,46,163,156,152
    let eccPkX = pubKey.getAsyKeySpec(AsyKeySpecItem.ECC_PK_X_BN)
    AppLog.info('returnPoint x data: ${returnPoint.x}') // 64750044510792891439269945828433327517677381559622384455951527515863444933970
    AppLog.info('ECC_PK_X_BN：${eccPkX}') // 64750044510792891439269945828433327517677381559622384455951527515863444933970
}
```
