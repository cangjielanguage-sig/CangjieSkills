# ohoshidebugDebug调试

This directory contains API reference documentation for the `ohos.hidebug` module in the Cangjie programming language, part of the Performance Analysis Kit. It covers system and application performance profiling, including memory usage statistics (native, system, heap), CPU utilization metrics, and resource management functions. Key components include classes for memory info, thread usage, and trace flags, alongside functions for retrieving system diagnostics and managing application resource limits. Designed for system developers and performance engineers working on HarmonyOS (API version 19+), these tools facilitate deep debugging and optimization of application processes and system resources.

## Detailed Description

### class_NativeMemInfo.md class_NativeMemInfo.md
This API reference defines the `NativeMemInfo` class in Cangjie, designed to describe application process memory information. It details seven read-only properties representing specific memory metrics, including private clean and dirty memory, shared clean and dirty memory, and aggregate values like PSS, RSS, and VSS. All values are 64-bit unsigned integers measured in kilobytes. This documentation targets system developers and performance engineers analyzing memory usage, requiring the `SystemCapability.HiviewDFX.HiProfiler` system capability (API version 19+).

### class_SystemMemInfo.md class_SystemMemInfo.md
This document defines the `SystemMemInfo` class used to describe system memory information in Cangjie. It outlines three read-only properties: `availableMem`, `freeMem`, and `totalMem`. All properties are of type `UInt64`, represent memory values in Kilobytes, and require the `SystemCapability.HiviewDFX.HiProfiler.HiDebug` system capability (API version 19+). This reference is intended for developers working on system performance monitoring or debugging who need to access hardware memory statistics.

### class_ThreadCpuUsage_2more.md class_ThreadCpuUsage_2more.md
This API reference details components for system performance profiling in Cangjie. It covers the `ThreadCpuUsage` class, which exposes read-only properties `cpuUsage` and `threadId` to describe thread CPU metrics, and the `TraceFlag` enumeration, which defines trace collection types such as `MAIN_THREAD` and `ALL_THREADS`. It requires the `SystemCapability.HiviewDFX.HiProfiler.HiDebug` capability (API version 19+) and is intended for developers implementing debugging and profiling features.

### class_Tags/
This directory contains API reference documentation for the `Tags` class in Cangjie, designed for system profiling and debugging within the HiProfiler framework. It defines a comprehensive set of static `UInt64` bit-flag constants used to identify and trace various system modules, including Ability Manager, ArkUI, Bluetooth, Distributed Hardware, and Graphics. These tags are essential for performance analysis and event categorization in the OHOS environment for API version 19 and above.
