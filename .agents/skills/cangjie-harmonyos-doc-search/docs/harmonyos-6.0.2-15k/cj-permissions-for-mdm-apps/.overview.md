# cj-permissions-for-mdm-apps

This directory serves as a specialized repository for reference documentation concerning OpenHarmony permissions that are exclusively reserved for Mobile Device Management (MDM) applications. It focuses specifically on the capabilities introduced in API version 12, providing essential details on the elevated privileges required for advanced device administration within an enterprise environment. The content covers critical operational areas such as file management, enterprise device control, security policy enforcement, network configuration, and system administration. Key permissions discussed include `FILE_GUARD_MANAGER` and a comprehensive suite of `ENTERPRISE_*` permissions, alongside authorization methods like `system_grant` and protection levels such as `system_basic` and `system_core`. This documentation is primarily intended for system developers and enterprise application engineers who are responsible for implementing robust administrative policies, managing hardware and software configurations, and ensuring strict security compliance on enterprise-grade devices. By utilizing these permissions, developers can ensure their applications have the necessary authority to execute critical management tasks effectively and securely within the OpenHarmony ecosystem, thereby facilitating seamless enterprise mobility management.
