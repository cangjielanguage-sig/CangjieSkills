## 代码示例

本模块提供了同步接口，以下为同步接口的使用示例。

### 查询单条关键资产明文

查询别名是demo_alias的关键资产明文。

```cangjie
import kit.AssetStoreKit.*
import ohos.base.BusinessException

try {
    let qry_alias: AssetParam = AssetParam.ALIAS("demo_alias".toArray())// 指定了关键资产别名，最多查询到一条满足条件的关键资产
    let qry_return_type: AssetParam = AssetParam.RETURN_TYPE(0)// 此处表示需要返回关键资产的所有信息，即属性+明文
    let query_attr: Array<AssetParam> = [qry_alias, qry_return_type]
    let query_res: Array<Array<AssetParam>> = query(query_attr)
} catch(e: BusinessException) {
    AppLog.error("Failed to query Asset. Code is ${e.code}, message is ${e.message}")
}
```

### 查询单条关键资产属性

查询别名是demo_alias的关键资产属性。

```cangjie
import kit.AssetStoreKit.*

try {

}
```

### 批量查询关键资产属性

批量查询标签1是demo_label的关键资产属性，从第5条满足条件的结果开始返回，一共返回10条，且返回结果以DATA_LABEL_NORMAL_1属性内容排序。

```cangjie
import kit.AssetStoreKit.*
import ohos.base.BusinessException

try {
    let qry_alias: AssetParam = AssetParam.ALIAS("demo_alias".toArray())// 指定了关键资产别名，最多查询到一条满足条件的关键资产
    let qry_return_type: AssetParam = AssetParam.RETURN_TYPE(1)// 此处表示仅返回关键资产属性，不包含关键资产明文
    let qry_data_label_normai_1: AssetParam = AssetParam.DATA_LABEL_NORMAL_1(5)//此处表示查询结果的偏移量，即从满足条件的第5条关键资产开始返回
    let qry_return_limit: AssetParam = AssetParam.RETURN_LIMIT(10)//此处表示查询10条满足条件的关键资产
    let qry_return_order_by: AssetParam = AssetParam.RETURN_ORDERED_BY(qry_data_label_normai_1)// 此处查询结果以DATA_LABEL_NORMAL_1属性内容排序
    let query_attr: Array<AssetParam> = [qry_alias, qry_return_type, qry_data_label_normai_1, qry_return_limit, qry_return_order_by]
    let query_res: Array<Array<AssetParam>> = query(query_attr)
} catch(e: BusinessException) {
    AppLog.error("Failed to query Asset. Code is ${e.code}, message is ${e.message}")
}
```
