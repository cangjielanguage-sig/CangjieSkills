### database_sql_package_exceptions.md database_sql_package_exceptions.md
This document provides comprehensive API reference documentation for the `SqlException` class, which is designed to handle SQL-related errors in the Cangjie programming language. It is an essential resource for understanding how to effectively manage database exceptions within a Cangjie application, ensuring that developers have the tools necessary for precise error tracking.

The text details the class structure, noting that it inherits from the base Exception class, and outlines three key properties: `errorCode` for vendor-specific integer codes, `message` for error descriptions, and `sqlState` for five-character status strings. These properties allow developers to capture detailed information about database failures.

Additionally, the documentation describes three constructors allowing instantiation with no arguments, a message only, or a combination of message, SQL state, and error code. This reference is intended for developers implementing database error handling, offering specific parameters and types for robust exception management.
