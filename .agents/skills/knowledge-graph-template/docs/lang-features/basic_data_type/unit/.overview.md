# unit

本目录提供了关于编程语言中 Unit 类型的详细参考文档。Unit 类型作为一种特殊的类型，在编程语言中扮演着重要角色，特别是在处理不返回有意义的值的函数或表达式时。文档内容涵盖了 Unit 类型的核心定义、其在实际编程中的具体用途（例如在 print 函数、赋值操作及循环表达式中的应用），以及该类型所支持的操作限制。重点强调了 Unit 类型主要关注副作用而非返回值，其唯一的字面量表示为 `()`，并且仅支持赋值、判等和判不等操作，不支持算术或其他运算。该目录适合希望深入理解语言类型系统、掌握基础语法规则以及需要正确处理无返回值操作的开发者阅读。
