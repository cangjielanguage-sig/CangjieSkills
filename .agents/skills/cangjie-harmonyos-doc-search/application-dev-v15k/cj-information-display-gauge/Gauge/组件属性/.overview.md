# 组件属性

This directory contains API reference documentation for configuring properties of the ArkUI Gauge component using the Cangjie programming language. It covers essential visual and functional customizations, including segmented color configurations, gradient settings, layout angles, indicator styles, and stroke dimensions. The documentation details specific function overloads, parameter constraints, and system capabilities required for version 12 and later. It is suitable for developers seeking to programmatically enhance the appearance and behavior of gauge charts and data panels within their applications.

## Detailed Description

### func_colorsArrayAppResourc_7more.md
This document provides API reference documentation for the colors function in the Cangjie language, designed to configure segmented colors for gauge charts within the ArkUI framework. The content details seven function overloads that accept various input types, including arrays of resource-integer pairs or individual color definitions combined with offset values. Key information includes the requirement for offsets to be ratio values between 0 and 1, which are automatically clamped if they fall outside this range, and support for multiple color data types like Color, AppResource, and UInt32. This technical reference targets ArkUI developers using version 12 or later who need to programmatically customize the visual appearance of gauge components.

### func_colorsArrayColor_Floa_7more.md
This API reference document details the overloaded `colors` functions used to configure color stops for gauge charts in the ArkUI framework. The content covers seven function overloads that accept arrays of tuples, pairing various color types—such as Color, LinearGradient, UInt32, and AppResource—with numeric width values like Float32, Int32, or UInt32. Key information includes that all methods return `This` for method chaining, support segmented color settings, and require SystemCapability.ArkUI.ArkUI.Full starting from version 12. Notably, gradient configurations are limited to a maximum of 9 groups. This documentation targets Cangjie language developers seeking to customize the visual appearance of data panels or gauge components.

### func_description_-_Unit_8more.md
This document provides API reference details for configuring the ArkUI Gauge component using the Cangjie programming language. It covers methods for defining the gauge's visual layout and behavior, specifically focusing on setting start and end angles, custom description builders, and indicator styles. Key functions include startAngle, endAngle, indicator, and privacySensitive. Important takeaways include warnings that small angle differences may cause rendering errors and the specific behavior of privacy mode, which masks values and resets the pointer. This reference guide targets developers utilizing ArkUI to create gauge interfaces, requiring knowledge of Cangjie syntax and UI component properties.

### func_strokeWidthLength_4more.md
This document provides API reference documentation for configuring circular gauge charts within the ArkUI framework using the Cangjie language. It covers three primary functions: strokeWidth for defining ring thickness, trackShadow for applying shadow effects, and value for setting dynamic data values. Key information includes specific constraints for the ring thickness, such as a maximum limit equal to the radius and no percentage support, alongside default parameters for shadow styling. The document targets developers seeking to customize the visual properties and data behavior of gauge components in their applications.
