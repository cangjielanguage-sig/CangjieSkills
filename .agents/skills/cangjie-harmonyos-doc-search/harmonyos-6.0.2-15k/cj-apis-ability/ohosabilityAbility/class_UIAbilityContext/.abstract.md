This directory provides API reference documentation for the `UIAbilityContext` class in the Cangjie programming language, designed for HarmonyOS application development. It encompasses the management of UIAbility lifecycles, inter-component communication, and system resource access. Key topics include launching abilities, handling asynchronous results, managing visibility states, and configuring mission properties. The documentation is intended for developers utilizing the AbilityKit to build robust applications, offering technical guidance on function signatures, parameters, error handling, and version-specific capabilities.
