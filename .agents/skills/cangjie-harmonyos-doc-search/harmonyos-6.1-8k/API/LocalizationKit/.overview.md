# LocalizationKit

LocalizationKit is a comprehensive documentation repository designed for developers using the Cangjie programming language within the HarmonyOS ecosystem. It focuses on internationalization (I18n) and resource management capabilities, providing detailed API references and error code definitions. The content covers core modules such as `ohos.i18n`, `ohos.resource_manager`, `ohos.raw_file_descriptor`, and `ohos.resource`. Currently in the Beta stage, this kit is essential for developers aiming to implement robust application localization, efficient resource scheduling, and precise error handling in their HarmonyOS applications.

## Detailed Description

### [1] README_zh/
This directory serves as the index document for the Cangjie language localization development service (Beta feature), aiming to provide developers with navigation guidance for APIs and error codes. The documentation content mainly covers core modules such as Internationalization (ohos.i18n), Resource Management (ohos.resource_manager), Raw File Descriptors (ohos.raw_file_descriptor), and Resources (ohos.resource). All functions are currently in the Beta stage and are organized via links to provide detailed interface references and error code definitions. This document is suitable for developers using the Cangjie language for application development, especially those needing to implement application internationalization, resource scheduling, and error handling.

### [2] cj-apis-i18n/
This directory serves as a specialized repository for Cangjie language API documentation focused on Internationalization (I18n) within the HarmonyOS ecosystem. It provides comprehensive references for developers aiming to implement robust system-level localization features.

### [3] cj-apis-raw_file_descriptor/
This directory contains the API reference documentation for the `ohos.raw_file_descriptor` module in the Cangjie language. The documentation details how to represent and access raw file descriptors in HarmonyOS HAP packages. Core content covers the definition of the `RawFileDescriptor` class, including key attributes such as file descriptor, start offset, and file length, used for locating and reading raw resources. This feature is currently in the Beta stage and is suitable for developers using the Cangjie language for HarmonyOS development who need to access file resources at a low level via file descriptors.

### [4] cj-apis-resource/
This directory contains the API reference documentation for the `ohos.resource` module in the Cangjie language, focusing on defining and managing application resource types. Core content covers the detailed definition of the `AppResource` class, which encapsulates key attributes such as application package name, module name, and resource ID, and supports inheritance for multiple resource types. The documentation also provides module import instructions, sample code running guides, and detailed descriptions of system capabilities (SystemCapability.Global.ResourceManager). This document is primarily aimed at Cangjie developers using the HarmonyOS LocalizationKit for development, helping them efficiently handle resource management tasks.

### [5] cj-apis-resource_manager/
This directory contains the API reference documentation for the HarmonyOS Resource Manager module, specifically tailored for the Cangjie (CJ) programming language. It provides a comprehensive guide for developers to handle application resources efficiently.
