# enum_SensorId

This directory provides API reference documentation for the `SensorId` enum and various sensor implementations in the Cangjie programming language using the SensorServiceKit. It covers environmental, motion, and biometric sensors, detailing system capabilities, version requirements, and code examples for managing data streams via subscription, retrieval, and unsubscription. Suitable for Cangjie developers and engineers building HarmonyOS/OpenHarmony applications requiring hardware sensor integration.
