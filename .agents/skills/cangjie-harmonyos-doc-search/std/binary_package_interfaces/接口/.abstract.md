This directory contains API documentation for the Cangjie programming language's standard library, specifically focusing on binary data manipulation interfaces. It covers endianness handling, including Big-Endian, Little-Endian, and byte swapping mechanisms. The documentation details methods for serializing and deserializing primitive data types like integers, floating-point numbers, and Booleans. It is suitable for Cangjie developers working on systems programming, network protocols, file I/O, and cross-platform data exchange.
