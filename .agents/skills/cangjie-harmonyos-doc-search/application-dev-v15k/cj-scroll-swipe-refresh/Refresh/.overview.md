# Refresh

This directory contains comprehensive documentation and resources for the Refresh component within the ArkUI framework, specifically utilizing the Cangjie programming language. It covers the implementation of pull-down refresh functionality, including API references for component creation, event handling, and property configuration. Key topics include `RefreshParams`, state management, offset tracking, and custom refresh behaviors. The materials are designed for developers working on HarmonyOS applications who need to integrate interactive refresh mechanisms into their user interfaces.

## Detailed Description

### Refresh_4more.md Refresh_4more.md
This document serves as API reference documentation for the Refresh container component within the ArkUI framework, specifically using the Cangjie programming language. It details a container that enables pull-down operations with refresh animations. The main sections cover sub-component support, the component creation method `init`, and supported attributes. Key information includes the requirement for a `RefreshParams` object and a content lambda, support for a single child component, and availability starting from version 12. The document targets developers seeking to implement interactive refresh behaviors in their user interfaces.

### 组件事件_2more.md 组件事件_2more.md
This document provides API reference documentation for event handling and parameter configuration of a Refresh component within the Cangjie ArkUI framework. It details three primary event callback functions—onOffsetChange, onRefreshing, and onStateChange—alongside the RefreshParams class definition. Key information includes specific parameter types such as Float64 for offset distance and RefreshStatus for state tracking, as well as constructors for RefreshParams that support two-way binding via the @Binder macro. Intended for developers implementing pull-to-refresh functionality, this reference requires familiarity with Cangjie syntax and ArkUI component lifecycles.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring pull-down refresh properties within the ArkUI framework using the Cangjie language. It details four specific functions: pullDownRatio, pullToRefresh, and two overloads of refreshOffset. Key takeaways include setting the drag sensitivity ratio (0-1), enabling refresh triggers, and defining the pixel threshold (default 96vp) required to initiate a refresh action. The documentation specifies parameter types, default values, and validation rules, such as clamping values to valid ranges. This technical reference is intended for software developers implementing custom refresh behaviors in ArkUI applications.
