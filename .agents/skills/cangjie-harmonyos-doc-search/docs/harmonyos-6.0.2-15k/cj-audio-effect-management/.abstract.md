This directory serves as a comprehensive technical resource for developers working with audio processing within the Cangjie programming environment, specifically utilizing the AudioKit framework. It provides in-depth documentation on the architecture and implementation of audio sound effect management systems. The content covers two primary aspects: querying global audio effect modes associated with specific `StreamUsage` scenarios and managing effects for individual audio playback instances. By detailing key concepts such as `AudioStreamManager`, `AudioRenderer`, and `AudioEffectMode`, this guide enables developers to programmatically control audio playback with precision. It is specifically designed for multimedia application developers who need to configure scene-specific audio modes, query system capabilities, or optimize audio experiences for scenarios such as music playback, gaming, and interactive media applications.
