This directory provides comprehensive development guidance for managing application certificates and private credentials within the HarmonyOS ecosystem. It focuses on utilizing the DeviceCertificateKit and Universal Keystore (HUKS) to handle the full lifecycle of credentials, including installation, cryptographic operations (signing/verification), and removal. Key topics include permission configuration, Cangjie programming language implementation, and API version 12+ interfaces. Suitable for HarmonyOS application developers, particularly those using the Stage model and seeking to implement secure digital signatures and credential management in their apps.
