# 常见连接场景

This directory serves as a comprehensive resource for establishing and managing connections within the HarmonyOS development ecosystem. It focuses on the HDC (HarmonyOS Device Connector) tool, providing technical guides for various connectivity scenarios. The content covers local connections via USB and TCP, as well as remote debugging across different networks. Key topics include environment setup, command-line syntax, IP configuration, and troubleshooting connectivity issues. These documents are essential for developers and technicians who need to configure reliable communication channels between hosts and devices. The guides assume the user possesses basic knowledge of command-line operations and network principles.

## Detailed Description

### USB连接场景_2more.md USB连接场景_2more.md
This technical guide provides comprehensive instructions for establishing connections between a PC and a device using the HDC tool via USB and TCP protocols. It details two primary scenarios: direct USB connection and local TCP connection. Each section includes environment confirmation tables and step-by-step connection procedures. Key requirements highlighted include enabling USB debugging, using official cables, and ensuring devices are on the same network segment for TCP. The document also specifies essential commands such as `hdc list targets` and `hdc tconn IP:PORT`, while noting that TCP debugging is currently unstable. This guide is intended for developers or technicians setting up debugging environments for HarmonyOS devices, requiring basic command-line knowledge.

### 远程连接场景.md 远程连接场景.md
This technical guide explains the process of establishing a remote connection between an HDC client and server across different networked PCs. It covers the command syntax using the `-s` parameter to specify network listening parameters, including IP address and port configuration. The guide provides a detailed two-step connection procedure, key information regarding the `hdc -s [ip]:[port] [command]` format, and error return values. It also offers specific instructions for starting the server with network forwarding and executing client commands. This document is intended for developers managing remote device debugging and requires basic knowledge of network configuration and HDC commands.
