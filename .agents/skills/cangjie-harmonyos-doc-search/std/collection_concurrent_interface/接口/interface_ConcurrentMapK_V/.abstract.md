This directory contains API reference documentation for the `ConcurrentMap` interface in the Cangjie language. It covers thread-safe key-value mapping operations, ensuring atomicity in concurrent environments. Key topics include data manipulation functions like `add`, `put`, `remove`, `replace`, and subscript operators, along with deprecation notices for legacy methods. It is suitable for Cangjie developers working on concurrent applications who need reliable, synchronized collection handling without manual locking mechanisms.
