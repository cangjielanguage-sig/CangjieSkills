This directory provides comprehensive API reference documentation for the `Iterator` class within the Cangjie programming language. It serves as a central resource for understanding the abstract class used for traversing container elements, detailing its inheritance from `Iterable` and core traversal methods. Beyond the basics, it covers extensive extensions that enable comparison operations, equality checks, and advanced functional programming utilities. Developers will find guidance on terminal operations like `reduce`, intermediate operations like `map` and `filter`, and traversal control mechanisms. This documentation is essential for Cangjie developers aiming to master sequential data access, implement efficient collection handling, and utilize functional programming patterns in their applications.
