This directory contains a specialized development guide for Cangjie developers focused on subscribing to application events within the HarmonyOS environment. It provides a detailed overview of the API interfaces necessary for writing and watching events, bridging the gap between theoretical definitions and practical coding. The guide features a comprehensive, step-by-step tutorial that walks developers through the process of configuring a Watcher, setting specific trigger conditions, and applying filters to capture relevant data. It includes practical code examples demonstrating how to log user interactions, such as button clicks, and how to set up subscription callbacks to handle these events. Additionally, the document covers the verification of output logs to ensure correct implementation. This resource is ideal for developers with a basic understanding of the HarmonyOS development environment and event handling concepts who wish to implement robust event monitoring in their applications.
