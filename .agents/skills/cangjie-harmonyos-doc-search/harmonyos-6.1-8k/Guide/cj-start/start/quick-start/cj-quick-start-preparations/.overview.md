# cj-quick-start-preparations

本目录旨在为OpenHarmony应用开发初学者提供使用仓颉语言进行开发前的全面准备工作指南。文档内容深入涵盖了ArkUI框架的三种开发范式对比、Stage应用模型的基本概念，以及仓颉与ArkTS的互操作性说明。重点介绍了仓颉声明式开发范式适用于复杂场景，且明确指出该范式仅支持Stage模型（API 22起）。此外，还详细提供了DevEco Studio集成开发环境及仓颉SDK的环境配置指引。该资料非常适合希望快速了解工程目录结构、理解开发流程及环境搭建的移动系统应用开发人员参考。通过阅读本文档，开发者可以建立起对仓颉语言在OpenHarmony生态中定位的清晰认知。
