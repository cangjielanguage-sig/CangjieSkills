# 数据库加密

This directory provides comprehensive technical documentation focused on implementing database encryption within the ArkData framework using the Cangjie language. It addresses the critical need for data security and integrity by thoroughly covering encryption strategies for both relational and Key-Value (KV) databases. The content details essential configuration steps, such as setting the `encrypt` attribute in `StoreConfig` or `KVOptions`, and explains how to retrieve the necessary `UIAbilityContext` for initialization. Furthermore, it highlights the immutability of encryption attributes once a database is created, emphasizing the importance of correct initial setup. This resource is specifically designed for application developers and system architects who need to secure local data storage, manage specific security levels, and ensure robust protection against unauthorized access in their applications using the ArkData kit. By following these guides, developers can effectively prevent data leakage and ensure compliance with security standards.

## Detailed Description

The following files provide in-depth technical guides and code examples to assist developers in implementing these security measures effectively.

### 关系型数据库加密.md 关系型数据库加密.md
This document serves as a technical guide for implementing encryption in relational databases using the Cangjie language and ArkData framework. It details the process of obtaining the UIAbilityContext and configuring the StoreConfig object. Key information includes setting the encrypt attribute to true to enable security, as the default state is unencrypted. The guide provides code examples for initializing the database with a specified security level. This resource is intended for developers seeking to secure local data storage within their applications.

### 场景介绍_2more.md 场景介绍_2more.md
This technical guide explains how to implement database encryption to enhance data security and integrity within the system. It covers general encryption principles, immutable encryption attributes, and specific configuration for Key-Value (KV) databases. Key information includes that encryption is set during database creation via the encrypt parameter in KVOptions, with Cangjie code examples demonstrating context retrieval and enabling encryption. This document is intended for application developers using the ArkData kit who require secure data storage mechanisms.
