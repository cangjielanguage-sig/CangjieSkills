This directory contains comprehensive API reference documentation for configuring component properties within the Cangjie ArkUI framework. It specifically focuses on the intricate details of scroll-related attributes, covering both interaction behaviors and visual styling. Key topics include managing scroll physics through friction and speed limits, handling nested scrolling logic, customizing scroll bar dimensions and colors, and defining edge effects like Spring or Shadow. These documents are essential resources for UI developers seeking to implement polished, high-performance scrolling experiences. They provide the necessary parameters, constraints, and default values to fine-tune application interfaces effectively, ensuring that components like List, Grid, and WaterFlow behave exactly as intended.
