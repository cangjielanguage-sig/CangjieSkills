# stdxnettls

`stdxnettls` 是一个专注于安全网络通信的 TLS（传输层安全）包，支持 TLS 1.2 及 1.3 协议。该目录涵盖了用于创建加密通道、管理会话及证书认证的核心 API，并详细说明了基于 OpenSSL 3 的环境依赖配置。主要内容包括 TlsSocket 类、配置结构体、密码套件定义以及跨平台（Linux、Windows、macOS）的库安装指南。本文档适合具备网络安全基础的开发人员，用于查阅 API 定义及配置开发环境。

### 功能介绍.md 功能介绍.md
本文档介绍了tls包的功能及其环境依赖配置。该包支持TLS 1.2及1.3协议，用于安全加密网络通信。文档重点详细说明了在Linux、Windows和macOS系统上安装OpenSSL 3依赖库的步骤，包括通过包管理器或源码编译安装，以及配置LD_LIBRARY_PATH、PATH等环境变量以确保系统链接器能找到libssl和libcrypto相关文件。关键信息指出必须使用OpenSSL 3，否则程序将抛出TlsException异常。这是一份面向开发者的环境配置指南，旨在确保依赖库正确加载。
