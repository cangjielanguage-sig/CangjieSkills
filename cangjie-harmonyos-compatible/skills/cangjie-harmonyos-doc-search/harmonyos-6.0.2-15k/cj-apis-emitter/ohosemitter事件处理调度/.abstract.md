This directory covers the `ohos.emitter` module for the Cangjie programming language, focusing on event-driven communication mechanisms within HarmonyOS applications. It details how to handle, dispatch, and prioritize events between threads or within a single thread. Key components include event priority definitions, callback structures, and the core `Emitter` struct for managing subscriptions and emissions. This documentation is suitable for Cangjie developers working with the BasicServicesKit and SystemCapability.Notification.Emitter modules to implement robust event-driven logic in system version 12 or later.
