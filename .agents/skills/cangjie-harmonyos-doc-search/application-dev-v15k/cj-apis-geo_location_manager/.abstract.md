This directory contains the comprehensive API reference documentation for the HarmonyOS Location Kit module, specifically tailored for the Cangjie programming language. It serves as a central resource for integrating location-based services into applications, covering essential functionalities such as GNSS positioning, geocoding, geofencing, and satellite monitoring. The documentation details request configurations for both single and continuous location tracking, defines data structures for coordinates and addresses, and outlines enumerations for setting priorities and handling errors. It is designed for developers creating location-aware applications who require precise control over positioning accuracy, power consumption, and system permissions. By utilizing these APIs, developers can create robust navigation, social networking, and logistics applications tailored for the HarmonyOS environment.
