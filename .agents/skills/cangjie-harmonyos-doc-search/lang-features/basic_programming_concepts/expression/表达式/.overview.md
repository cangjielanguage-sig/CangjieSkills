# 表达式

本目录全面介绍了仓颉编程语言中的表达式系统，涵盖了条件判断、循环控制及表达式的基础定义。内容详细讲解了 `if`、`for-in`、`while` 等核心控制流表达式的语法、执行逻辑及高级特性（如元组解构、where条件），并深入探讨了表达式的求值机制与类型推导规则。核心关键词包括仓颉、表达式、循环控制、条件判断、类型推导及迭代器。这些资料适合仓颉语言的初学者及希望深入理解语言基础语法的开发者阅读，旨在帮助用户掌握代码控制流与表达式求值的核心概念。

## 详细描述

### break_与_continue_表达式_8f3258a8.md break_与_continue_表达式
本文档旨在介绍仓颉编程语言中用于控制循环流程的 break 和 continue 表达式。主要内容包括两者的基本定义、返回类型 Nothing 以及在 for-in 循环中的具体应用示例。关键信息指出，break 用于终止当前循环执行后续代码，而 continue 用于跳过本轮循环直接进入下一轮。文档通过查找特定整除数和打印奇数的代码实例，直观展示了这两个表达式的区别与用法。该文档适合仓颉语言初学者阅读，要求读者具备基本的循环结构知识。

### for-in_表达式.md for-in表达式
本文档详细介绍了仓颉编程语言中用于遍历实现了Iterable接口类型的for-in表达式。主要涵盖基本语法与执行流程、遍历区间与数组、元组解构、迭代变量的不可修改性、使用通配符忽略变量以及where条件过滤等关键特性。文档通过代码示例演示了如何高效处理循环逻辑，旨在帮助开发者掌握该表达式的各种应用场景。这是一份面向仓颉语言开发者的基础语法教程。

### while_表达式_2more_49a85e30.md while表达式
本文档旨在介绍仓颉编程语言中 `while` 和 `do-while` 循环表达式的语法结构、执行逻辑及应用场景。主要内容包括 `while` 表达式的条件判断与循环体执行流程，以及 `do-while` 表达式的先执行后判断机制。核心要点在于区分两者的执行顺序：`while` 先判断条件再执行，`do-while` 先执行一次循环体再判断条件。文档通过二分法求平方根和蒙特卡洛算法求圆周率的实例演示了具体用法。该文档属于编程语言教程，面向仓颉语言的学习者，帮助他们掌握基本的循环控制结构。

### 表达式.md 表达式
本文档旨在阐述仓颉编程语言中表达式的广义定义及求值机制。主要涵盖条件表达式、循环表达式及代码块的规则。仓颉将表达式定义为任何可求值的语言元素，具有确定类型。文档详细说明了if表达式的类型灵活性、循环表达式的Unit类型，以及代码块取最后一个表达式值的规则。面向仓颉语言学习者，帮助其理解基础语法和控制流逻辑。

### if_表达式/
本目录主要介绍仓颉编程语言中 `if` 表达式的语法规则与应用场景。内容涵盖了 `if` 表达式的基本结构、执行流程、类型推导规则，以及 `let pattern` 在条件语句中的高级用法和变量绑定作用域。文档详细讲解了布尔条件判断、`else` 分支省略规则及多级 `else if` 逻辑，并分析了常见的语法错误。核心关键词包括仓颉语言、if表达式、let pattern、类型推导和条件控制流。这些资料适合仓颉语言的初学者及开发者，旨在帮助其掌握条件控制流的使用及理解表达式求值与类型系统的交互。
