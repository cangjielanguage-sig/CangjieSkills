# 接口

This directory provides comprehensive API documentation for arithmetic interfaces in the Cangjie programming language, focusing on strategies to handle integer overflow and underflow. It covers specific power operation interfaces alongside general arithmetic operation templates for various integer types. Key strategies include wrapping, checked, saturating, throwing, and carrying approaches, offering developers flexibility in error handling and numerical stability. This resource is essential for Cangjie developers and systems programmers who require precise control over low-level mathematical operations and robust error management in performance-critical applications.
