# 拖拽控制

This directory focuses on drag-and-drop control mechanisms within the ArkUI framework using the Cangjie language. It covers essential APIs for enabling drag functionality, customizing drag previews, and managing context menus. Key topics include the `draggable` attribute, `dragPreview` configuration, and priority hierarchies for visual feedback. It also references fundamental type definitions for interaction logic and animations. This resource is suitable for HarmonyOS developers and UI engineers looking to implement sophisticated drag-and-drop interactions and visual effects in their applications.

## Detailed Description

### func_dragPreviewString_2more.md
This API reference document details the dragPreview function used to configure custom preview images for component dragging in the ArkUI framework. It covers two function overloads: one accepting a String ID for component screenshots and another accepting a builder function for custom UI construction. Key information includes the strict priority hierarchy for preview sources, where bindContextMenu overrides dragPreview, which in turn overrides the onDragStart return value. The documentation also notes that screenshots exclude visual effects like shadows and rotation. This guide targets ArkUI developers implementing drag-and-drop interactions who need to control the visual feedback during the drag operation.

### 拖拽控制_3more.md
This document provides API reference documentation for configuring drag-and-drop capabilities in the ArkUI framework using the Cangjie language. It covers the draggable function to enable or disable drag responses and the dragPreview function to customize the visual appearance during dragging. The text explains default drag behaviors for components like Text and Image, noting that some require specific settings like copyOption. Key information includes parameter definitions for Bool and DragItemInfo, and the priority of preview images over event callbacks. This guide is intended for developers implementing custom drag interactions in ArkUI applications.

Intended for HarmonyOS developers using the Cangjie language, this snippet serves as a practical reference for enhancing user interface interactions.
