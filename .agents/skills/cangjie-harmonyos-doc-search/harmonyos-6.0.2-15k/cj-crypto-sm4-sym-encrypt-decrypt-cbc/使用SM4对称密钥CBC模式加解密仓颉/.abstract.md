This directory serves as a comprehensive technical resource dedicated to the implementation of SM4 symmetric encryption and decryption using the CBC mode and PKCS7 padding within the Cangjie programming language. It thoroughly covers the essential workflows required for secure data handling, including the generation of 128-bit symmetric keys, the creation of Cipher instances, and the management of initialization vectors using the CryptoArchitectureKit. The content is specifically designed for software developers and security engineers who are looking to integrate robust cryptographic operations into their Cangjie applications. By providing both theoretical step-by-step instructions and practical code examples, this collection ensures that users can successfully implement and verify security features in their software projects, handling both segmented and synchronous data processing effectively.
