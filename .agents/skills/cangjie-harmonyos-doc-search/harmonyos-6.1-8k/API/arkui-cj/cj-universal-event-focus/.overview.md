# cj-universal-event-focus

本目录包含ArkUI框架中关于焦点事件的API参考文档，主要面向使用仓颉语言进行应用开发的开发者。文档详细阐述了组件获取与失去焦点的逻辑处理、核心接口定义（如`onFocus`和`onBlur`）以及不同组件的默认获焦能力。内容涵盖了焦点事件的基本概念、当前支持的限制（如仅支持外接键盘）以及容器组件的焦点管理机制。此外，文档还说明了Button等组件默认可获焦，而Text等组件需显式设置的规则。该资料适用于需要实现键盘导航和复杂焦点交互的应用场景，帮助开发者构建无障碍且易用的用户界面。

## Detailed Description

### cj-universal-event-focus.md
这份文档是ArkUI框架中关于焦点事件的API参考文档，旨在指导开发者处理组件在获取或失去焦点时的逻辑。文档主要包含焦点事件的基本概念、当前支持的限制（如仅支持外接键盘）、组件默认获焦能力的详细说明，以及onFocus和onBlur两个核心函数的接口定义。关键信息指出Button等组件默认可获焦，而Text等需显式设置，且容器组件的获焦依赖于子组件或手势配置。该文档面向使用Cangjie语言进行ArkUI开发的开发者，适用于需要实现键盘导航和焦点管理的应用场景。
