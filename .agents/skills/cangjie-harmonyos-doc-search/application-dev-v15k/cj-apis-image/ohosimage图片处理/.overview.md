# ohosimage图片处理

This directory contains comprehensive API reference documentation for the `ohos.image` module within the HarmonyOS Cangjie development framework. It covers the entire image processing pipeline, including decoding, encoding, pixel manipulation, and High Dynamic Range (HDR) support. Key components include classes for Image, PixelMap, and ImageSource, alongside enums for formats and metadata. Designed for multimedia developers and engineers, these resources facilitate the creation of advanced image applications requiring precise control over image data, metadata management, and rendering capabilities within the SystemCapability.Multimedia.Image.Core framework.

## Detailed Description

### Files

- **class_GainmapChannel.md class_GainmapChannel.md**
  API reference for the GainmapChannel class in Cangjie, handling single-channel data for gainmap images per ISO 21496-1 standards. It details properties like gainmapMax and gamma for HDR functionality.

- **class_HdrGainmapMetadata.md class_HdrGainmapMetadata.md**
  Cangjie class defining HDR gainmap metadata structures, managing channel data (RGB) and headroom values for base and alternate images according to ISO 21496-1.

- **class_Image.md class_Image.md**
  Core Cangjie class for basic image manipulation, offering read-only properties like clipRect and format, alongside methods for resource management and data retrieval.

- **class_ImageCreator.md class_ImageCreator.md**
  Cangjie class for requesting native image data regions and managing image queues (dequeueImage/queueImage) for UI drawing and compilation.

- **class_ImageInfo.md class_ImageInfo.md**
  Encapsulates image metadata like size, density, and pixel format. It supports basic properties from version 12 and extended features like stride and HDR from version 19.

- **class_ImageReceiver.md class_ImageReceiver.md**
  Manages image reception and surface ID retrieval for multimedia components like Camera, including methods for instance management.

- **class_Metadata.md class_Metadata.md**
  Stores and manages image metadata (e.g., EXIF), providing methods to retrieve all attributes as a string map from image objects.

- **class_Picture.md class_Picture.md**
  Handles multi-picture objects comprising main and auxiliary images, including methods for reading and writing metadata with error handling.

- **enum_AlphaType.md enum_AlphaType.md**
  Enum defining image transparency types (OPAQUE, PREMUL, UNPREMUL, UNKNOWN) for alpha channel configurations in image processing.

- **enum_AntiAliasingLevel.md enum_AntiAliasingLevel.md**
  Enum specifying image scaling algorithms ranging from nearest neighbor (NONE) to cubic (HIGH) for anti-aliasing operations.

- **enum_ComponentType.md enum_ComponentType.md**
  Enum categorizing image components like YUV_Y (luminance), YUV_U/V (chrominance), and JPEG for the image receiver system.

- **enum_DecodingDynamicRange.md enum_DecodingDynamicRange.md**
  Enum for specifying decoding dynamic ranges (AUTO, HDR, SDR), noting that incremental sources default to SDR.

- **enum_HdrMetadataKey.md enum_HdrMetadataKey.md**
  Enum identifying HDR metadata keys (e.g., HDR_GAINMAP_METADATA, HDR_STATIC_METADATA) within the pixelmap class for manipulation.

- **enum_HdrMetadataType.md enum_HdrMetadataType.md**
  Enum specifying metadata types for HDR images (NONE, BASE, GAINMAP, ALTERNATE) to programmatically identify formats.

- **enum_ImageFormat_2more.md enum_ImageFormat_2more.md**
  Defines ImageFormat (JPEG, YCBCR_422_SP) and MetadataType (EXIF, FRAGMENT) enums for image handling and metadata identification.

- **enum_PackingDynamicRange.md enum_PackingDynamicRange.md**
  Enum specifying desired dynamic range during encoding (AUTO, SDR), adapting to PixelMap content or enforcing standard range.

- **enum_ScaleMode_2more.md enum_ScaleMode_2more.md**
  Enum defining image scaling behaviors like CENTER_CROP (scales and crops) and FIT_TARGET_SIZE (fits dimensions).

- **func_createImageCreatorSiz_4more.md func_createImageCreatorSiz_4more.md**

- **func_createImageSourceStri_3more.md func_createImageSourceStri_3more.md**

- **func_createPicturePixelMap_2more.md func_createPicturePixelMap_2more.md**

- **func_createPixelMapInitial_2more.md func_createPixelMapInitial_2more.md**
