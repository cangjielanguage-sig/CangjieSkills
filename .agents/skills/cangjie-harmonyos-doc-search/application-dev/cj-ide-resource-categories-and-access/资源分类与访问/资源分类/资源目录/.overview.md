# 资源目录

This directory serves as a comprehensive technical guide for managing application resource directories and structures within the development environment. It provides detailed explanations on how to organize resources using base and qualifier directories to support localization and device-specific configurations. Key topics include strict naming conventions, resource compilation processes, and the handling of raw files versus compiled resources. It is specifically designed for developers and system architects who need to ensure their application resources are correctly matched, compiled, and deployed across a wide variety of devices, regions, and screen densities. By following these guidelines, users can optimize resource management and ensure compatibility. The documentation also references international standards such as ISO 639 and ITU-T E.212 to ensure global compliance. Included files cover directory structures, naming rules, and specific qualifier definitions.

## Detailed Description

### 资源目录_1.md
This reference guide explains the structure and naming conventions for application resource directories, focusing on the base and qualifier directories used for resource management and localization. The document details the base directory for default resources and qualifier directories for specific scenarios like language or device type. Key takeaways include that resources are compiled into binary files referenced by type and name, and qualifier directories must follow strict naming rules regarding the order of attributes (e.g., language, screen density) and the use of underscores or hyphens. This guide is intended for developers organizing application resources to ensure proper matching and compilation across different devices and regions. Keywords: resource directory, qualifier, base directory, naming conventions, localization, resource compilation.

### 资源目录_2.md
This reference document defines resource qualifiers and directory structures for application resource management. It covers qualifier types such as mobile country codes, language, script, region, orientation, device type, color mode, and screen density, referencing standards like ISO 639 and ITU-T E.212. Additionally, it explains the rawfile and resfile directories, noting that resources within them are packed without compilation or IDs. Key takeaways include the specific DPI ranges for screen densities and the distinction that resfile resources are extracted to the application sandbox path. This guide is intended for developers organizing application resources for diverse device configurations.
