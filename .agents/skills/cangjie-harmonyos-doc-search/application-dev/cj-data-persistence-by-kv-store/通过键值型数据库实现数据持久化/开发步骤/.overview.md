# 开发步骤

This directory serves as an essential resource for HarmonyOS developers working with the Cangjie language to implement and manage distributed key-value databases using the ArkData kit. It provides a structured approach to data persistence, covering the entire lifecycle from initialization to cleanup. The documentation details how to obtain a KVManager instance, configure a SingleKVStore with specific security options, and perform fundamental CRUD operations including put, get, and delete. Additionally, it highlights best practices for resource management, such as closing and deleting stores, and emphasizes robust error handling using BusinessException and pattern matching. These guides are specifically designed for developers seeking to build reliable, data-driven applications on the HarmonyOS platform, ensuring they have the necessary tools to manage both local and distributed data effectively.

## Detailed Description

### 开发步骤_1.md
This document provides a step-by-step tutorial for implementing key-value database operations using the Cangjie language and the ArkData kit. It covers obtaining a KVManager instance, creating a SingleKVStore with specific configuration options, and performing basic CRUD operations including put, get, and delete. Key takeaways include the use of KVOptions for security settings, handling BusinessException for errors, and pattern matching for data retrieval. The guide targets HarmonyOS application developers seeking to manage local or distributed data persistence within their applications.

### 开发步骤_2.md
This document provides code examples for managing the lifecycle of a distributed key-value database in Cangjie. It covers closing a specific KV store using the closeKVStore method and permanently deleting it using deleteKVStore via the kvManager instance. Key takeaways include the necessity of passing the bundle name and store ID as parameters, along with implementing try-catch blocks to handle BusinessException errors for robust logging. Intended for HarmonyOS developers using the Cangjie language, this tutorial serves as a practical guide for resource cleanup and data management steps.
