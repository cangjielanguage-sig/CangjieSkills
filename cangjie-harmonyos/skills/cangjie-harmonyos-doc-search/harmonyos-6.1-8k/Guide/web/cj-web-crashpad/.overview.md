# cj-web-crashpad

本目录提供了关于 `cj-web-crashpad` 的技术指南，专注于 Web 组件的崩溃收集与深度分析。文档详细阐述了如何利用 Crashpad 工具高效地捕获进程崩溃时的关键数据，包括崩溃文件的生成路径及其在应用主进程沙箱目录下的存储机制。核心内容涵盖了使用 `minidump_stackwalk` 解析二进制 `.dmp` 文件以获取详细的堆栈信息，以及利用 `llvm-addr2line` 工具将内存地址映射回源码具体位置的完整操作步骤。该文档旨在帮助开发者快速定位崩溃原因和寄存器状态，非常适合需要深入调试 Web 组件稳定性问题、且具备基础 Linux 环境调试能力的开发人员参考。
