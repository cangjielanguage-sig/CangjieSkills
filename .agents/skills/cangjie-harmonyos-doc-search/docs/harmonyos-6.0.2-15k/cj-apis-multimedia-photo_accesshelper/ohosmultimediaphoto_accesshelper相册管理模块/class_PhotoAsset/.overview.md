# class_PhotoAsset

This directory provides comprehensive API reference documentation for the `PhotoAsset` class within the Cangjie MediaLibraryKit framework. It is designed to assist developers in encapsulating and managing media file properties effectively. The documentation covers essential read-only attributes such as `displayName`, `photoType`, and `uri`, while also detailing methods for metadata modification and thumbnail retrieval. Key topics include specific permission requirements like `READ_IMAGEVIDEO` and `WRITE_IMAGEVIDEO`, error code handling, and the correct usage of `fetchOptions` for data retrieval. This resource is suitable for Cangjie developers building file management systems or media viewing applications who require robust interaction with the device's file management system and need to implement features like asset editing and thumbnail display.

## Detailed Description

The following files provide in-depth technical specifications and usage examples for the PhotoAsset class and its associated functions.

### class_PhotoAsset_6more.md class_PhotoAsset_6more.md
This API reference document details the PhotoAsset class in Cangjie, designed to encapsulate and manage media file properties. It covers read-only properties like displayName, photoType, and uri, alongside methods for modifying metadata (commitModify) and retrieving specific member parameters (get). Key information includes the requirement for WRITE_IMAGEVIDEO permissions for modifications and the necessity of specifying columns in fetchOptions when fetching data. The document also lists specific error codes and provides usage examples. It is intended for developers using the MediaLibraryKit to interact with the file management system.

### func_getThumbnailSize_2more.md func_getThumbnailSize_2more.md
This document serves as API reference material for Cangjie developers working with photo assets in the MediaLibraryKit. It primarily documents two functions: getThumbnail, which retrieves a PixelMap of a file with an optional size parameter, and set, which modifies specific metadata like the asset title. The content includes detailed function signatures, required permissions such as READ_IMAGEVIDEO, system capabilities, and potential error codes. Practical code examples demonstrate fetching assets via PhotoAccessHelper and applying these operations. This guide is intended for developers building file management or media viewing applications who need to display thumbnails and edit asset properties.
