# 不推荐案例

This directory serves as a comprehensive repository of technical documentation designed to highlight anti-patterns and common pitfalls encountered during ArkUI development using the Cangjie language. It specifically addresses critical issues related to the `ForEach` component, focusing on scenarios that lead to incorrect UI updates and significant performance degradation caused by improper key generation strategies. Key topics covered include component lifecycle management, state management nuances, rendering efficiency optimization, and the implementation of stable key generators to ensure smooth UI behavior. These resources are essential for developers seeking to optimize application performance and avoid complex bugs associated with list rendering and dynamic data manipulation. By understanding these "not recommended" cases, developers can write more robust and efficient code.

## Detailed Description

### 不推荐案例_2more.md 不推荐案例_2more.md

This document serves as a technical guide highlighting an anti-pattern when using the ForEach component in UI development. It focuses on the section "Unexpected Rendering Results," demonstrating how using the data source index within the keyGeneratorFunc causes incorrect UI updates. The key takeaway is that relying on index for key generation leads to component reuse errors and duplicate rendering during list modifications; therefore, developers must avoid using index in key generation rules. Intended for developers working with the ArkUI framework and Cangjie language, this material assumes knowledge of state management and component lifecycle.

### 渲染性能降低.md 渲染性能降低.md

This document serves as a tutorial demonstrating a performance anti-pattern in ArkUI development using the Cangjie language. It explains how omitting the keyGeneratorFunc parameter in the ForEach component leads to unnecessary component recreation during data insertion operations. The text details the lifecycle behavior, showing that default index-based keys cause subsequent items to be re-rendered. It concludes by providing the correct implementation using a stable key generator based on item content. This guide targets developers looking to optimize rendering efficiency and manage component lifecycle in ArkUI applications.
