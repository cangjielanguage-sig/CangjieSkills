This directory provides comprehensive API reference documentation for scroll-related event callbacks within the Cangjie ArkUI framework. It covers the full lifecycle of scrolling events, ranging from pre-scroll interception to post-scroll state monitoring and edge detection. Key topics include handling user inputs, API controller calls, boundary bouncing effects, and frame-by-frame offset calculations. The documentation details specific functions such as `onDidScroll`, `onWillScroll`, `onScrollFrameBegin`, and various edge detection methods. This resource is essential for software developers and UI engineers building interactive applications who require precise control over scroll behaviors and event handling logic using the Cangjie language.
