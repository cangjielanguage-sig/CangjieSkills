# 拆包工具

This directory provides comprehensive documentation for the OpenHarmony Unpacking Tool, a utility designed for decompressing and parsing application packages such as HAP, HSP, and App files. It covers both command-line usage and Java API integration, detailing how to extract configuration data and inspect package contents. The documentation also includes schema definitions for internal data structures like `AppInfo` and `AbilityInfo`. Suitable for developers building application markets, package management tools, or those needing to debug application bundles, this resource requires knowledge of Java and HarmonyOS package structures.

## Detailed Description

### 包解析接口.md 包解析接口.md
This document serves as an API reference for the UncompressEntrance class, designed to parse HAP, HSP, and App packages to extract configuration data. It details four Java interface methods, specifically overloaded versions of parseApp and parseHap, which accept file paths or input streams. Key takeaways include the ParseAppMode enumeration (ALL, HAP_LIST, HAP_INFO) for controlling parsing depth and the return type UncompressResult. Intended for developers building application markets or package management tools, this documentation requires knowledge of Java and HarmonyOS package structures.

### 拆包工具_2more.md 拆包工具_2more.md
This document introduces the OpenHarmony Unpacking Tool, a debugging utility designed to decompress and parse application packages like HAP, HSP, and App files. The content covers the tool's definition, its location within the SDK, specific constraints regarding the Cangjie language, and system requirements. Key information includes the tool's dual functionality: command-line decompression and Java interface parsing. It requires a Java 8 or higher environment. Notably, HSP-related features are unavailable for Cangjie programs, as the language currently only supports HAR and HAP packages. This guide targets OpenHarmony developers needing to inspect or debug application package contents.

### 拆包指令说明.md 拆包指令说明.md
This technical reference guide provides command-line instructions for using the app_unpacking_tool.jar to decompress various application package formats. The document details five distinct operational modes: unpacking HAP, App, HSP, and APPQF packages, plus a specific mode for extracting rpcid files from HAP packages. Each section includes a command example and a parameter table defining required inputs like file paths and optional flags like --force for overwriting existing files. Targeted at developers, this guide requires knowledge of Java command-line execution to manipulate application bundles effectively.

### 拆包工具信息字段/
This directory contains technical reference documentation for data structures used in HarmonyOS application unpacking and parsing tools. It covers schema definitions for configuration objects within HAP packages, including application metadata (`AppInfo`), component capabilities (`AbilityInfo`, `ExtensionAbilityInfo`), and distribution settings (`Distro`). The documents detail field attributes, data types, and model-specific constraints (FA vs. Stage models). It is suitable for developers, system architects, and tool creators who need to understand the internal structure of application bundles for analysis, debugging, or building parsing utilities.
