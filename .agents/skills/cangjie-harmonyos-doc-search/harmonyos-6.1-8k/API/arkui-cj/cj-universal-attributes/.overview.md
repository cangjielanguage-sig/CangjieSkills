# cj-universal-attributes

本目录是UI框架通用属性的索引文档，目前处于Beta阶段，旨在为开发者提供一套标准化的样式与行为配置参考。文档内容全面且结构清晰，涵盖了布局设置（包括尺寸、位置及Flex布局）、视觉效果（如边框、背景、透明度、渐变及模糊效果）、交互控制（涉及焦点管理、拖拽操作、弹窗及菜单逻辑）以及高级功能（如模态转场与安全区域适配）。通过提供组件标识、Z序控制、形状裁剪等具体属性的详细文档链接，该目录极大地提升了开发效率，帮助用户快速定位所需配置。它主要适合正在使用该UI框架进行应用界面构建的开发者，是快速查阅和定位组件通用配置的必备指南。
