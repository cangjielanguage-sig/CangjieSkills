# Swiper

This directory contains comprehensive documentation and code examples for the Swiper component within the ArkUI framework, specifically designed for the Cangjie language. It covers the creation and configuration of sliding carousel view containers, including navigation indicators, animation effects, and event handling. Key topics include API references for child components, controller usage, and advanced UI customization like digital indicators and overflow handling. This resource is suitable for HarmonyOS developers and UI engineers seeking to build dynamic, interactive, and responsive carousel interfaces in mobile applications.
