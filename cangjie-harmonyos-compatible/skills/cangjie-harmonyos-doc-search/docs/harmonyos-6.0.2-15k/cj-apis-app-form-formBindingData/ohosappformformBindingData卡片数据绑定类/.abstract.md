This directory contains API reference documentation for the HarmonyOS FormKit, specifically focusing on card data binding classes implemented in the Cangjie programming language. It covers the `FormBindingData` class, which is essential for creating and managing data objects for form cards, and the `ProxyData` class, which handles proxy refresh subscriptions. Key topics include JSON data handling, subscription identifiers, and system capability requirements. This documentation is suitable for developers building form-based applications on HarmonyOS system version 19 who need to implement dynamic card data display, updates, and data proxy capabilities. The directory includes specific references for class constructors, properties like `key` and `subscriberId`, and functions such as `createFormBindingData`.
