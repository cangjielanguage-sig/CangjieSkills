## 详细描述

### 仓颉示例代码说明.md 仓颉示例代码说明.md
本文档旨在指导开发者如何将仓颉API示例代码集成到工程模板中进行编译和运行。主要涵盖创建仓颉模板工程、在index.cj中添加示例代码，以及在main_ability.cj中定义Global类以处理Context对象的步骤。关键点在于示例代码仅为片段，需结合模板使用；若涉及Context对象，需通过Global类进行静态存储和访问。面向使用仓颉语言开发的开发者，属于开发指南类文档。

### 开发说明_4more_75c94c85.md 开发说明_4more_75c94c85.md
本文档旨在指导开发者查阅和理解OpenHarmony仓颉SDK的API参考文档，属于开发指南类文档。主要涵盖版本说明、系统能力说明及接口使用说明三个部分。文档详细解释了如何识别接口起始版本，利用SystemCapability判断设备支持情况及能力差异，以及通过导入Kit声明来使用SDK封装的接口。关键信息包括系统能力的定义、canIUse接口的使用以及Kit模块的导入方式。该文档面向应用开发者，旨在帮助其正确理解文档规范，高效利用API进行开发。

### 权限说明_3more_b708b3ef.md 权限说明_3more_b708b3ef.md
本文档旨在说明仓颉API的权限申请机制、应用模型限制及废弃接口的处理规范。主要涵盖权限申请与调用说明、应用模型（仅支持Stage模型）的适用性，以及废弃接口的标注与兼容性策略。关键信息包括：调用敏感接口需申请特定权限；仓颉API仅限Stage模型使用；废弃接口虽有5个API Level的兼容期，但建议开发者尽快适配替代方案。面向使用仓颉语言进行应用开发的开发者，属于API参考文档的一部分，帮助开发者理解合规调用接口的前提条件。
