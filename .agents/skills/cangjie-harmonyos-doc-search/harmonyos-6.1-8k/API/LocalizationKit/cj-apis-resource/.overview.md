# cj-apis-resource

本目录包含仓颉语言中 `ohos.resource` 模块的 API 参考文档，专注于定义和管理应用资源类型。核心内容涵盖了 `AppResource` 类的详细定义，该类封装了应用包名、模块名、资源 ID 等关键属性，并支持多种资源类型的继承。文档还提供了模块导入说明、示例代码运行指南以及系统能力（SystemCapability.Global.ResourceManager）的详细说明。该文档主要面向使用 HarmonyOS LocalizationKit 进行开发的仓颉开发者，帮助他们高效地处理应用资源管理和本地化配置。

## Detailed Description

### cj-apis-resource.md cj-apis-resource.md
本文档是仓颉语言中 `ohos.resource` 模块的 API 参考文档，旨在定义资源类型。主要内容包括模块导入说明、示例代码运行指南，以及核心类 `AppResource` 的详细定义。`AppResource` 类继承自 `Length`、`ResourceColor` 和 `ResourceStr`，封装了应用包名、模块名、资源 ID、参数及类型等属性，并提供了相应的构造函数。文档明确了系统能力 `SystemCapability.Global.ResourceManager` 及起始版本 22。该文档面向使用 HarmonyOS LocalizationKit 的仓颉开发者，要求读者了解仓颉工程模板结构及上下文配置。
