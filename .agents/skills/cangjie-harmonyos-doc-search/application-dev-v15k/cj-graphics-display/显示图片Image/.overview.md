# 显示图片Image

This directory serves as a comprehensive guide for using the Image component in the Cangjie programming language within the HarmonyOS ArkUI framework. It covers fundamental image display techniques, including loading local and network resources, handling vector graphics (SVG), and managing image loading events like success and failure callbacks. Additionally, it explores advanced customization through property configuration such as scaling, interpolation, and color filters. This resource is suitable for application developers seeking to enhance UI visual quality and implement robust image handling logic in their Cangjie-based applications.

## Detailed Description

### 事件调用.md 事件调用.md
This document provides a practical code example demonstrating how to handle image loading events in the Cangjie programming language for HarmonyOS development. The primary focus is on the Image component, specifically utilizing the onComplete callback to retrieve image dimensions and component size, and the onError callback to manage loading failures. Key takeaways include the implementation of state management to dynamically update the UI with image metadata upon successful load. This tutorial is designed for application developers using the Cangjie language who need to monitor image loading status and access image properties within their user interfaces.

### 显示图片Image_3more.md 显示图片Image_3more.md
This guide instructs developers on using the Image component to display various image formats within applications. It covers the component interface, loading resources (local, network, app resources, media library), and displaying vector graphics (SVG). Key information includes the `Image(src)` API, the requirement for internet permissions for network images, the use of `@r` for resource access, and the ability to modify SVG colors via `fillColor`. It also details path handling for SVGs referencing bitmaps. This technical reference targets application developers using the Cangjie language and ArkUI framework.

### 添加属性/
This directory focuses on enhancing the Image component within the Cangjie ArkUI framework by adding and configuring various display properties. It covers essential techniques for optimizing image rendering, including scaling modes, interpolation for clarity, repetition styles, rendering modes, and color filters. Developers will find practical code examples to manipulate image appearance and performance. This resource is suitable for Cangjie developers looking to customize visual layouts and improve the user interface quality of their applications through precise property configuration. The guides provide executable examples to demonstrate the impact of different settings on visual output.
