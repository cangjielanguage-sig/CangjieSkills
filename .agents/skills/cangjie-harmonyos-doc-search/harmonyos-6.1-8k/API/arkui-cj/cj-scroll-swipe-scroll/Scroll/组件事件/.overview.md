# 组件事件

本目录包含关于ArkUI框架中滚动组件事件处理的API参考文档。内容主要涵盖使用仓颉语言开发的滚动事件回调函数，包括滚动帧控制、边缘检测以及滚动生命周期管理（如onWillScroll和onDidScroll）。这些文档详细说明了事件触发条件、参数定义及返回值逻辑，旨在帮助开发者实现自定义滚动行为、精确控制偏移量及处理边缘交互。适合使用仓颉语言进行ArkUI应用开发的开发者查阅。

## 详细描述

### func_onScrollFram_2more_d6abfea4.md
本文档是Cangjie语言的API参考文档，详细介绍了滚动组件的两个关键事件处理函数：onScrollFrameBegin和onScrollEdge。文档涵盖了这两个函数的功能定义、触发条件、回调参数及系统能力要求。关键信息指出，onScrollFrameBegin允许在每帧滚动开始时修改实际滚动量，并特别说明了嵌套滚动时需设置EdgeEffect为None；onScrollEdge则用于检测滚动至边缘的情况。该文档面向使用ArkUI框架的开发者，旨在指导其实现自定义滚动行为和边缘交互逻辑。

### func_onWillScroll_3more_cc5b9281.md
这份文档是ArkUI框架中Scroll组件滚动事件回调的API参考文档。主要涵盖了onWillScroll（包含返回OffsetResult和Unit的两种重载）以及onDidScroll三个函数的定义与用法。文档详细说明了这些回调的触发条件、参数含义（如水平/垂直偏移量、滚动状态、来源）及返回值逻辑，其中onWillScroll支持在滚动前修改偏移量。该文档面向使用仓颉语言进行ArkUI开发的开发者，旨在提供滚动事件监听与控制的接口规范。
