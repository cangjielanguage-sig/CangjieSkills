# 目标方开发步骤

This directory serves as a comprehensive resource for HarmonyOS developers tasked with configuring an application to function as a target service provider for map functionalities. It thoroughly covers the necessary development steps, including the configuration of the `module.json5` file to declare specific features such as Navigation, RoutePlan, and PlaceSearch via the `linkFeature` attribute. Furthermore, it details the technical implementation required to parse incoming parameters within the `UIAbility` lifecycle, offering specific parameter tables for different scenarios and Cangjie code examples. This guide is essential for developers who need to enable their applications to seamlessly receive, process, and respond to external map service requests.

## Detailed Description

### 目标方开发步骤_1.md
This technical guide outlines the development steps for configuring a HarmonyOS application as a target service provider for map functionalities. It covers configuring the module.json5 file to declare supported features like Navigation, RoutePlan, and PlaceSearch using the linkFeature attribute and URI matching. The document details how to parse incoming parameters within the UIAbility.onCreate method, providing specific parameter tables for route planning, navigation, and location search scenarios. It includes a Cangjie code example demonstrating data handling. Intended for HarmonyOS developers, this guide enables apps to receive and process external requests for map services.

### 目标方开发步骤_2.md
This code snippet demonstrates how to implement the target side logic for handling map-related intents in a HarmonyOS application. It covers lifecycle methods like onCreate and onNewWant for parsing JSON parameters, and a loadPage function for routing based on specific URIs. Key information includes extracting coordinates, POI IDs, and vehicle types from want.parameters, storing them in localStorage, and dynamically loading pages such as NavigationPage, RoutePlanPage, or PlaceSearchPage based on the action type. This implementation guide is intended for HarmonyOS developers integrating map capabilities to handle external navigation requests.
