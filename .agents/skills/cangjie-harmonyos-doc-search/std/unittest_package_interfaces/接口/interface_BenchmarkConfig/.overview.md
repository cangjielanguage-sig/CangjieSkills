# interface_BenchmarkConfig

This directory provides essential API reference documentation for the `BenchmarkConfig` interface, a key component for performance testing in the Cangjie language. It focuses on extending the `Configuration` class to facilitate detailed benchmark configurations. The documentation covers critical parameters such as batch execution sizes, garbage collection behavior, minimum batch counts, execution duration, and warmup periods. By explaining function signatures for integers, ranges, and durations, it allows developers to customize the `@Configuration` macro for precise control over test execution. This resource is intended for Cangjie developers and QA engineers who need to configure and optimize performance benchmarks within the unittest framework.

## Detailed Description

### extend_Configuration_BenchmarkConfig.md extend_Configuration_BenchmarkConfig.md
This API reference document details the extension of the Configuration class to implement the BenchmarkConfig interface for performance testing in the Cangjie language. It covers configuration functions for batch execution, garbage collection, minimum batches, duration, and warmup periods. Key methods include batchSize, which accepts Int64 or Range, explicitGC, minBatches, minDuration, and warmup, which accepts Int64 or Duration. These functions allow developers to fine-tune benchmark parameters such as execution counts, timing constraints, and garbage collection behavior. The target audience is developers utilizing the unittest framework to write and configure performance benchmarks.

### interface_BenchmarkConfig_8more.md interface_BenchmarkConfig_8more.md
This API reference document defines the BenchmarkConfig interface for configuring performance test parameters within the Cangjie testing framework. It details function signatures for setting batch sizes, warmup periods (by count or duration), minimum execution duration, garbage collection types, and minimum batch counts. The interface is implemented to customize the @Configuration macro, allowing precise control over benchmark execution behavior through overloaded methods for integers, ranges, and durations. This guide targets Cangjie developers who need to fine-tune performance testing setups and requires knowledge of the testing framework and basic data types.
