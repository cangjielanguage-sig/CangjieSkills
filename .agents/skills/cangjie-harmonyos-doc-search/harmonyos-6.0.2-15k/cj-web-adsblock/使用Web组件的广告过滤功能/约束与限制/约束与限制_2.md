- 在[WebviewController](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#class-webviewcontroller)类中，增加开启/关闭广告过滤特性的接口[enableAdsBlock()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-enableadsblockbool)，支持Web实例级的特性开关。
- 新增[AdsBlockManager](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#class-adsblockmanager)全局单例类，提供自定义广告过滤配置、控制网站级特性开关的能力。
- Web实例上提供了[onAdsBlocked()](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-onadsblockedadsblockeddetails---unit)回调通知方法，支持将拦截信息通知到上层应用。
- [AdsBlockManager](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#class-adsblockmanager)接口[setAdsBlockRules()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-setadsblockrulesstring-bool)接口仅能设置一份自定义配置，此配置会持久化，应用冷启动无需重新配置，可避免每次冷启动配置规则都触发广告过滤配置的编译解析。
- [AdsBlockManager](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#class-adsblockmanager)接口[addAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockdisallowedlistarraystring)、[removeAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-removeadsblockdisallowedlistarraystring)、[clearAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-clearadsblockdisallowedlist)、[addAdsBlockAllowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockallowedlistarraystring)、[removeAdsBlockAllowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-removeadsblockallowedlistarraystring)、[clearAdsBlockAllowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-clearadsblockallowedlist)操作的数据不会持久化，应用冷启动需要重新设置。
- 如果1个Web实例启用了广告过滤特性，但未调用[AdsBlockManager](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#class-adsblockmanager)接口[addAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockdisallowedlistarraystring)、[removeAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-removeadsblockdisallowedlistarraystring)、[clearAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-clearadsblockdisallowedlist)、[addAdsBlockAllowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockallowedlistarraystring)、[removeAdsBlockAllowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-removeadsblockallowedlistarraystring)、[clearAdsBlockAllowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-clearadsblockallowedlist)配置disallowlist和allowlist数据，则默认所有网站均启用广告过滤。
- allowlist和disallowlist数据共同使用时，allowlist的优先级高于disallowlist，即先使用allowlist匹配，如果匹配成功就不再使用disallowlist匹配，该网站会启用广告过滤特性。
- 如果应用没有使能广告过滤特性，那么确保Web组件不会向服务器请求默认的内置easylist配置文件。
