This directory serves as a practical guide to parameterized testing within the Cangjie unittest framework, designed to help developers automate test input insertion using Data DSL. It covers a wide range of topics, from basic value-driven testing with single and multiple parameters to handling complex types and implementing advanced random testing strategies. Key concepts include Cartesian product combinations, avoiding combinatorial explosion, and utilizing `unittest.random()` for edge-case-biased data. Additionally, it addresses the critical aspects of reproducibility and configuration in random testing, such as using random seeds and interpreting failure outputs. Targeted at Cangjie developers, these documents aim to significantly improve test coverage, efficiency, and reliability through automated data generation and shrinking mechanisms.
