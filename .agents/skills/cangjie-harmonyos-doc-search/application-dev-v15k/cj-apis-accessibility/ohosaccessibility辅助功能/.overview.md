# ohosaccessibility辅助功能

This directory contains API reference documentation for the HarmonyOS Accessibility module, specifically designed for the Cangjie programming language. It covers a comprehensive range of classes, enums, and functions necessary for implementing barrier-free features, including accessibility service management, event handling, gesture simulation, and caption styling. Key components include definitions for ability states, event types, capabilities, and action enumerations. Intended for developers working on system version 19, this documentation provides the technical specifications required to build assistive applications that support users with visual, auditory, or motor impairments.
