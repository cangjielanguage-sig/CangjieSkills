This directory serves as the primary resource for understanding the Universal Keystore Kit (HUKS), a comprehensive service framework designed to provide unified secure key management and cryptographic operation capabilities for applications. The documentation thoroughly details the system's three-layer architecture, comprising the SDK, Service, and Core layers, with a specific emphasis on the security requirement that the Core layer must execute within secure environments such as Trusted Execution Environments (TEE). It outlines the core functions spanning the entire key lifecycle, including generation, usage (encompassing encryption, signing, and access control), deletion, and attestation. Furthermore, the text notes critical dependencies on the User Authentication Kit. This conceptual guide is essential for developers and OEMs aiming to implement secure key storage and cryptographic operations, ensuring they understand the architectural and security prerequisites of the system.
