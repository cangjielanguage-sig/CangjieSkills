# class_PhotoSession

This directory contains API reference documentation for the `PhotoSession` class within the Cangjie CameraKit framework. It focuses on managing normal photo mode sessions, including camera capabilities like flash, exposure, focus, and zoom. The documentation covers class definitions, event listener management (registration and unregistration), and session preconfiguration for resolution settings. Targeted at software developers building multimedia applications on HarmonyOS, these resources provide method signatures, parameter descriptions, error codes, and Cangjie code examples to implement robust photo capture functionality and handle asynchronous state changes effectively.
