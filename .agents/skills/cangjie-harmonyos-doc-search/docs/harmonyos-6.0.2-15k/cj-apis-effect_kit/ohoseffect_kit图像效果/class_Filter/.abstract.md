This directory provides comprehensive API reference documentation for the Cangjie Filter class and associated image processing functions within the Cangjie development environment. It focuses on applying visual effects to input images, including blur, brightness adjustments, grayscale conversion, color inversion, and custom color matrix transformations. Key features include support for effect chaining, where methods return the Filter head node, and specific parameter constraints for valid image manipulation. This documentation is essential for Cangjie developers utilizing the ImageKit and ArkGraphics2D frameworks to build multimedia image processing features in HarmonyOS applications. It offers syntax details, parameter definitions, and code examples to facilitate efficient development.
