# cj-common-components-switch

本目录详细介绍了Cangjie ArkUI框架中Toggle组件的开发指南，旨在帮助开发者掌握创建和管理开关、复选框及状态按钮的核心技能。文档深入探讨了Toggle接口的多种类型（包括Button、Checkbox和Switch），并提供了丰富的属性配置选项，如selectedColor和switchPointColor，以实现高度自定义的UI样式。同时，内容涵盖了状态变更的事件处理机制（onChange）以及包含或不包含子组件的组件创建语法。通过蓝牙开关等实战示例，开发者可以快速将理论知识应用于实际项目中。本指南特别适合具备ArkUI基础并希望提升交互体验的Cangjie开发者阅读。

### cj-common-components-switch.md cj-common-components-switch.md
