# enum_ProfileUuids

This directory provides comprehensive API reference documentation for the `ProfileUuids` enum within the Cangjie programming language, specifically designed for developers implementing Bluetooth connectivity solutions. The document details the Universally Unique Identifiers (UUIDs) required to identify and manage a wide array of Bluetooth communication profiles. It enumerates specific members for standard protocols, including Hands-Free Profile (HFP), Headset Profile (HSP), Advanced Audio Distribution Profile (A2DP), Audio/Video Remote Control Profile (AVRCP), Human Interface Device (HID), and HID over GATT Profile (HOGP), while also accounting for unknown profile types. In addition to member definitions, the resource covers inherited methods such as equality operators and the `toString` function, which are vital for logic implementation and debugging. It also stipulates critical system requirements, including the `SystemCapability.Communication.Bluetooth.Core` capability and a minimum API version of 19. This documentation is ideal for software engineers and system developers seeking precise programmatic control over Bluetooth profile types to ensure seamless device interaction and robust communication protocols in their applications.
