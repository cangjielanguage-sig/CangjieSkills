# cj-crypto-architecture-kit-intro

This directory introduces the Crypto Architecture Kit, a robust framework designed to abstract the complexities and differences between various third-party cryptographic libraries. It provides developers with essential security functions, including encryption, digital signing, and hashing, while covering fundamental concepts like symmetric and asymmetric keys. The kit offers specific capabilities such as key generation, message digests, and secure random number generation. It is important to note that the kit currently supports only OpenSSL, lacks multi-threading support, and explicitly excludes key management. Consequently, developers are responsible for managing their own keys or integrating with the Universal Keystore Kit. This resource is suitable for developers implementing cryptographic operations who need a standardized interface, offering guidance on algorithm selection and advising against weak algorithms like MD5 in high-security scenarios.
