# class_RelativeTimeFormat

This directory provides comprehensive API reference documentation for the `RelativeTimeFormat` class, a crucial component of the Cangjie LocalizationKit. It is dedicated to enabling internationalization (i18n) by allowing developers to format relative time strings—such as "yesterday" or "next year"—according to specific locale conventions. The documentation covers the full lifecycle of the formatter, from object initialization using system defaults or specific locale arrays to the conversion of numeric values and time units into human-readable text. It also details advanced configuration options and granular formatting capabilities. This resource is specifically designed for Cangjie developers who need to implement robust, localized time representations that dynamically adapt to the user's language and regional settings within their applications.
