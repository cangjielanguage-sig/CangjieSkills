This directory serves as a comprehensive resource for Cangjie developers aiming to implement robust internationalization (i18n) features within their applications. It specifically addresses the technical requirement to set an application's preferred language independently of the device's system language, a critical capability for supporting multilingual users effectively. The documentation covers the utilization of the LocalizationKit framework, detailing how to manage language settings programmatically using APIs like `System.setAppPreferredLanguage`. By following this guide, developers can ensure that their application's interface resources dynamically align with the user's selected locale. This content is highly suitable for software engineers working on global applications where user language preferences may differ from the operating system's default settings, offering a tailored and accessible experience.
