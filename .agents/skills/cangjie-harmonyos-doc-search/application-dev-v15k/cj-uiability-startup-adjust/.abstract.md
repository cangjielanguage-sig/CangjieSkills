This directory serves as a comprehensive technical resource specifically designed for HarmonyOS developers who need to adapt their applications to the latest platform standards. It focuses on the critical architectural shift from explicit Want mechanisms to App Linking for inter-application navigation, a change driven by the deprecation of explicit Want starting from API 18. The directory covers the entire migration process, including the necessary configuration of `module.json5` for domain verification and the practical implementation of the `openLink` interface using modern programming languages like Cangjie or ArkTS. Furthermore, it addresses advanced topics such as handling return results from launched UIAbilities, ensuring strict security compliance, and establishing robust fallback mechanisms. This guide is highly suitable for developers aiming to modernize their app's navigation logic, ensuring secure and compliant cross-application communication within the HarmonyOS ecosystem.
