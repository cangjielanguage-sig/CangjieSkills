# cj-crypto-sym-encrypt-decrypt-spec

This directory serves as a comprehensive repository for technical specifications regarding symmetric key encryption and decryption algorithms. It is designed to standardize the implementation of mainstream cryptographic algorithms, specifically focusing on AES, 3DES, and SM4. The documentation provides detailed definitions for various encryption modes, including ECB, CBC, and GCM, as well as data padding rules such as PKCS7 and NoPadding. Furthermore, it outlines the specific methods for configuring these algorithm specifications using string parameters, ensuring flexibility and ease of use. This resource is primarily suitable for developers working with the CryptoArchitectureKit, offering essential API references and integration guidance to facilitate the secure and correct implementation of encryption interfaces within their applications. By adhering to these specifications, developers can ensure robust security and interoperability across different systems.

## Detailed Description

The following section provides a comprehensive breakdown of the subdirectory contained within this specification folder. It outlines the technical scope and intended usage of the documentation available to developers.

### [1] 对称密钥加解密算法规格/

This subdirectory hosts the technical specification documents that define the standards for symmetric key encryption and decryption algorithms. It provides a rigorous definition of implementation norms for widely used algorithms, including AES (Advanced Encryption Standard), 3DES (Triple Data Encryption Standard), and SM4 (a Chinese national standard block cipher). The scope of these documents extends to the specific encryption modes supported by these algorithms, such as Electronic Codebook (ECB), Cipher Block Chaining (CBC), and Galois/Counter Mode (GCM). Additionally, it covers data padding rules essential for block ciphers, including PKCS7 and NoPadding. The directory also details the methodology for configuring algorithm specifications through string parameters, allowing for dynamic setup. These documents are specifically curated for developers utilizing the CryptoArchitectureKit to develop encryption functionalities. They serve as a vital resource, providing API references and integration guidance to assist developers in understanding the underlying mechanics and correctly invoking the necessary encryption interfaces for secure data handling.
