The SymbolSpan directory provides comprehensive documentation and resources for the SymbolSpan component within the Cangjie ArkUI framework. This component serves as a child element of the Text component, specifically designed to display and customize system-preset icon symbols. The content covers API references, implementation examples, and detailed property configurations such as rendering strategies, effect strategies, and font attributes. It is suitable for HarmonyOS application developers using the Cangjie language who need to integrate dynamic, scalable system icons into their user interfaces with precise control over visual appearance and interaction effects.
