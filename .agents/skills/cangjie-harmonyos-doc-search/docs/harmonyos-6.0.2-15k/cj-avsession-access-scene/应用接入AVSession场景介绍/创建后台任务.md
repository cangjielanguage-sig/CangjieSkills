## 创建后台任务

当应用需要实现后台播放等功能时，需要使用[BackgroundTasks Kit](../../task-management/cj-background-task-overview.md)（后台任务管理）的能力，申请对应的长时任务，避免进入挂起（Suspend）状态。

对媒体类播放来说，需要申请[AUDIO_PLAYBACK BackgroundMode](../../../API_Reference/source_zh_cn/apis/BackgroundTasksKit/cj-apis-background_task_mgr.md#enum-backgroundmode)的长时任务。
