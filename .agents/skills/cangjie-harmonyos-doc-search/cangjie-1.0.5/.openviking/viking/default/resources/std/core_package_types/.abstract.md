It is dedicated to defining the standard type aliases that developers use to simplify type declarations and ensure consistency across different codebases. The documentation thoroughly covers the three primary aliases: `Byte`, `Int`, and `UInt`. It explicitly details how these aliases map to specific built-in types—`UInt8`, `Int64`, and `UInt64`—thereby removing ambiguity regarding data storage size and signedness. This reference is indispensable for Cangjie developers who require precise knowledge of data representations for low-level programming or API design. It is best suited for individuals with a basic understanding of the language's syntax and primitive types who are looking to deepen their technical expertise. By standardizing these types, the core package facilitates better interoperability and code maintenance.
