This directory provides API reference documentation for the Cangjie class `AlertDialogParamWithButtons` within the ArkUI framework. It covers the configuration of alert dialogs featuring two confirmation buttons, including class definitions, properties, and constructors. Key topics include primary and secondary button setup, system capabilities starting from version 12, and extensive UI customization options such as alignment, background blur, and transitions. This resource is designed for Cangjie developers and HarmonyOS UI engineers seeking to implement interactive, customized modal windows and popups with specific visual and behavioral requirements.
