This directory contains API reference documentation for the `RawSocket` class in the Cangjie programming language, designed for low-level network programming. It covers essential socket operations including initialization, configuration, data transmission, and connection management. Key topics include socket options, timeouts, binding, listening, and sending/receiving data across protocols like TCP, UDP, UDS, and ICMP. The documentation details method signatures, parameters, return values, and exception handling. It is suitable for developers who need to implement custom network protocols or manage socket connections directly using Cangjie.
