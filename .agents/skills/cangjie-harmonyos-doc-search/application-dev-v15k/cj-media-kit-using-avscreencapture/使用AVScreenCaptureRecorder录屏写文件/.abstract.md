This directory provides comprehensive resources for implementing screen recording functionality using the AVScreenCaptureRecorder module within the HarmonyOS ecosystem. It covers the complete development workflow, including instance creation, audio-video parameter configuration, recording controls, and resource management. Key topics include permission handling, state management, and system behaviors like call interruptions. The content is tailored for HarmonyOS application developers and software engineers using the Cangjie language, offering both theoretical guides and practical code examples to integrate screen capture and media playback features effectively.
