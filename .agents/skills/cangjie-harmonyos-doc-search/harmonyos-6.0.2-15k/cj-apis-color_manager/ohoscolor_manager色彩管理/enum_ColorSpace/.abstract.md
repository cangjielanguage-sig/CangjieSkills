This directory provides comprehensive API reference documentation for the `ColorSpace` enumeration implemented in the Cangjie language. It is primarily designed for the ArkGraphics2D kit and ColorManager Core system capabilities. The content details the technical specifications of various color gamut types, ranging from standard definitions like sRGB and Adobe RGB to wide gamut options such as DCI-P3 and Display P3, alongside video standards like BT.601, BT.709, and BT.2020. It addresses critical technical aspects including transfer functions (Linear, HLG, PQ) and encoding ranges (Full, Limit). This resource is essential for graphics developers working within the HarmonyOS/OpenHarmony ecosystem who require precise control over color rendering, conversion, and configuration in their 2D graphics applications.
