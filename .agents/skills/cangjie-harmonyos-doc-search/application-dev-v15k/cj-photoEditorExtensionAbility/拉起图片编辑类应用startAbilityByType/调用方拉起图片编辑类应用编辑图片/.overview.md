# 调用方拉起图片编辑类应用编辑图片

This directory serves as a technical guide for developers aiming to integrate image editing capabilities into their applications by invoking external image editing apps. It details the end-to-end process, which includes selecting images via the `PhotoViewPicker`, securely copying files to the application's local sandbox, and launching the system editor panel using the `startAbilityByType` interface. The documentation emphasizes critical technical requirements such as managing URI read/write permissions, configuring specific launch parameters, and handling asynchronous callbacks to retrieve the edited image data. These resources are specifically designed for HarmonyOS developers working with Cangjie or ArkTS who need to implement the `PhotoEditorExtensionAbility` framework to provide seamless image modification experiences within their software.
