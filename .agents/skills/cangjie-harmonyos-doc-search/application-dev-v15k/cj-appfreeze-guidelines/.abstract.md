This directory serves as a specialized technical repository dedicated to the identification, analysis, and resolution of Application Not Responding (AppFreeze) issues within the HarmonyOS and OpenHarmony operating systems. It provides an in-depth look at the underlying mechanisms responsible for freeze detection, the intricacies of system logging workflows, and the categorization of specific fault types, including main thread stalls and lifecycle timeouts. The resource offers practical, step-by-step guides on essential tasks such as log acquisition, stack trace analysis, and debugging methodologies specifically designed for the Stage model. This documentation is highly suitable for software developers, quality assurance engineers, and system performance analysts who are focused on maintaining application stability, diagnosing performance bottlenecks, and troubleshooting unresponsive application behaviors in a complex ecosystem.
