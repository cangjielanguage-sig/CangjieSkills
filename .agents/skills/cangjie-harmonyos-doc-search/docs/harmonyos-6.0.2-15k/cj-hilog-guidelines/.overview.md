# cj-hilog-guidelines

This directory serves as a comprehensive technical guide specifically designed for Cangjie developers who are utilizing the HiLog system to output and manage application logs. It provides an in-depth look at the necessary interfaces, parameter definitions, and system constraints required for effective logging. The content is crucial for developers who need to debug applications and analyze runtime behavior within the DevEco Studio environment. Key areas of focus include the five distinct log levels—DEBUG, INFO, WARN, ERROR, and FATAL—as well as performance optimization techniques like the `isLoggable` check. Additionally, the guide outlines critical system limits, such as the 4096-byte log limit and the 31-byte tag limit, and introduces the usage of `kit.PerformanceAnalysisKit`. This resource is highly suitable for application developers seeking to implement robust logging practices in their Cangjie projects.
