This directory serves as a comprehensive collection of API reference documents for enumerations used within the Cangjie testing and performance framework. It specifically covers definitions for garbage collection types (ExplicitGcType), precise time measurement units (TimeUnit), and CPU performance counters (PerfCounter). These enumerations are essential for developers who need granular control over memory management, accurate time tracking, and low-level hardware or software event monitoring during performance analysis and benchmarking. The documentation is primarily suitable for systems programmers and performance engineers working in the Cangjie language who are building robust testing tools or analyzing system metrics. It includes details on interface inheritance, such as ToString, and mappings to system calls like Linux's perf_event_open.
