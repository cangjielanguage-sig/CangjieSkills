# cj-permissions-for-enterprise-apps

This directory serves as a comprehensive technical reference for developers working with permissions in enterprise-grade applications within the HarmonyOS ecosystem. It focuses on the definitions, access levels, and version evolution of sensitive capabilities required for enterprise functionality, such as enterprise security, process management, eSIM configuration, Wi-Fi control, domain accounts, and file control. The documentation highlights critical changes introduced in API versions 14 and 15, specifically the expansion of access for certain permissions from MDM or system-only apps to general enterprise applications. This resource is vital for system and enterprise application developers implementing device management, security features, or applications for enterprise-customized devices, offering crucial insights into manual signing requirements and authorization modes. It ensures developers have the necessary guidance to leverage advanced system capabilities securely and effectively.

## Detailed Description

### 企业类应用可用权限/

This directory provides comprehensive reference documentation for permissions available to enterprise applications within the HarmonyOS ecosystem. It focuses on the definitions, access levels, and version evolution of sensitive capabilities required for enterprise-grade functionality. Key topics covered include enterprise security, process management, eSIM configuration, Wi-Fi control, domain accounts, and file control. The documents highlight critical changes in API versions 14 and 15, where access to certain permissions expanded from MDM or system-only apps to general enterprise applications. This resource is essential for system and enterprise application developers who are implementing device management, security features, or applications for enterprise-customized devices, particularly regarding manual signing requirements and authorization modes. By detailing the shift in access levels, this documentation helps developers navigate the complexities of compliance and functionality in modern enterprise environments.
