# digest_使用

本目录包含仓颉编程语言中关于摘要算法使用的示例文档。内容涵盖了 HMAC-SHA512、SM3 以及 MD5、SHA 系列（SHA1/224/256/384/512）等多种加密哈希算法。文档详细介绍了如何实例化算法对象、写入数据、获取摘要以及进行结果比对。这些资料适合仓颉开发者参考，旨在帮助开发者快速掌握标准库中的加密功能，实现数据完整性校验、消息认证及安全哈希计算等场景。

## 详细描述

### HMAC_算法示例_2more_a0dac397.md
本文档提供了在仓颉编程语言中使用 HMAC-SHA512 和 SM3 算法的代码示例。主要涵盖 HMAC-SHA512 算法的调用，演示了密钥初始化、分块写入数据、重置实例及结果比对；以及 SM3 算法的调用，展示了基本的哈希计算流程。关键信息包括目前仅支持 HMAC-SHA512，示例详细展示了 write、finish、reset 及 HMAC.equal 等成员函数的具体用法，并提供了十六进制格式的运行结果输出。这是一份面向仓颉开发者的教程文档，旨在帮助开发者理解如何利用标准库进行加密哈希计算，适用于需要实现数据完整性校验或摘要生成的场景。

### MD5_算法示例_6more_c038efad.md
本文档演示了仓颉编程语言中 MD5 及 SHA 系列哈希算法的使用方法。文档包含 MD5、SHA1、SHA224、SHA256、SHA384 和 SHA512 六个算法的代码示例。核心内容展示了实例化算法对象、调用 write 写入数据、调用 finish 获取摘要及十六进制编码转换的标准流程。这是一份面向仓颉开发者的代码参考教程，旨在帮助开发者快速实现数据加密摘要功能。
