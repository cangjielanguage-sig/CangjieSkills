This directory contains documentation for the `Support` struct and related system event constants within a Cangjie or similar development environment. It primarily focuses on defining string identifiers for common system events, including Bluetooth states, IVI (In-Vehicle Infotainment) updates, hardware changes, and user lifecycle management. The files serve as API references for developers needing to subscribe to or broadcast system-level notifications. Keywords: Support struct, system events, API reference, Bluetooth, IVI, constants, Cangjie. Suitable for software developers and system integrators.
