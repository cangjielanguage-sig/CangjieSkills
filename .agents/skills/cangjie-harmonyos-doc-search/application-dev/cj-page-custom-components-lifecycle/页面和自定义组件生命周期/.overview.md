# 页面和自定义组件生命周期

This directory serves as a comprehensive technical resource dedicated to the intricate lifecycle management of pages and custom components within the ArkUI framework, specifically utilizing the Cangjie language. It provides an in-depth examination of the entire component lifecycle, spanning from initial creation, member initialization, and rendering flows to the critical aspects of deletion mechanisms and resource cleanup. Key topics include the functional distinctions between `@Component` and `@Entry` decorators, the nuances of state variable management, strategies for achieving minimal UI updates, and the precise execution order of lifecycle callbacks during complex navigation events. This guide is essential for ArkUI developers and system architects who aim to deeply understand component behavior, optimize application performance, manage memory efficiently, and ensure robust resource handling throughout the application's runtime.

### 页面和自定义组件生命周期_3more.md 页面和自定义组件生命周期_3more.md
This document details the lifecycle processes for pages and custom components in the ArkUI framework. It distinguishes between custom components decorated with @Component and page entry components decorated with @Entry. The text explains the creation and rendering flow, including member initialization, the aboutToAppear callback, and the build method execution. It further describes the re-rendering mechanism triggered by state variable changes, emphasizing how the framework achieves minimal UI updates. This technical guide is intended for developers seeking to understand component initialization, state management, and rendering optimization in ArkUI applications.

### 自定义组件的删除/
This directory serves as a technical resource for understanding the deletion mechanisms and lifecycle management of custom components within the ArkUI framework, specifically developed using the Cangjie language. It provides in-depth coverage of critical processes such as the `aboutToDisappear` lifecycle callback, the unregistration of state variables including @Link and @Prop, and the backend node destruction process. Additionally, it explores the complex execution order of component deletion in relation to various page navigation events, such as `router.pushUrl` and `router.replaceUrl`. This content is highly suitable for ArkUI developers and system architects who aim to optimize application performance, manage memory efficiently, and ensure robust resource cleanup during component transitions and routing operations.
