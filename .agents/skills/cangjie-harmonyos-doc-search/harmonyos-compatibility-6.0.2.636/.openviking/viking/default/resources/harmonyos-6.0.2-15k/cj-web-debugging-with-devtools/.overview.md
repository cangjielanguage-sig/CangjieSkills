# cj-web-debugging-with-devtools

This directory serves as a comprehensive technical guide specifically designed for debugging front-end pages within HarmonyOS Web components using DevTools. It thoroughly covers the end-to-end workflow, starting from enabling debugging APIs and configuring necessary permissions to establishing stable remote connections between a development computer and mobile devices. Key technical topics include the implementation of the `setWebDebuggingAccess` method, practical usage of the `hdc` tool, automation scripts for port forwarding, and detailed troubleshooting for common connection issues. This resource is essential for front-end developers and engineers working on HarmonyOS applications who need to efficiently inspect, debug, and resolve complex issues in web views.
