# class_MacroExpandParam

This directory contains essential API documentation for components within the Cangjie programming language's Abstract Syntax Tree (AST) implementation. It specifically focuses on the structural definition of macro expansion parameters and the mechanisms for traversing syntax tree nodes. The content provides detailed specifications for the `MacroExpandParam` class, which handles macro call nodes, and the `traverse` function, which facilitates the Visitor pattern for node processing. Key topics include AST structure, mutable properties, token conversion, and customizable traversal logic. This documentation is highly suitable for compiler developers, language engineers, and researchers building static analysis tools or working on compiler infrastructure for the Cangjie language.

### class_MacroExpandParam_11more.md class_MacroExpandParam_11more.md

This API documentation defines the MacroExpandParam class, which represents macro call nodes within the Abstract Syntax Tree (AST) of the Cangjie programming language. The content covers the class definition, its inheritance from FuncParam, and a comprehensive list of mutable properties. Key properties include fullIdentifier, macroInputs, and specific tokens for parentheses and brackets used in macro syntax. The document also outlines the init constructor and the toTokens method for converting nodes back to token sequences. It notes that invalid token assignments trigger ASTException. This reference is intended for developers working on compiler tools or AST manipulation who require detailed structural information about macro expansions.
