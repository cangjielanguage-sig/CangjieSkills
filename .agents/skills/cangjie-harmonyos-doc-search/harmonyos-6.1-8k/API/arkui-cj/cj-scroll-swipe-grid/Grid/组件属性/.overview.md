# 组件属性

本目录包含ArkUI框架中Grid组件的API参考文档，主要面向使用仓颉语言的应用开发者。文档详细介绍了Grid组件的关键属性配置，涵盖了网格布局的行列模板设置、行列间距控制以及缓存行为优化。核心内容涉及`cachedCount`、`columnsGap`、`rowsGap`、`columnsTemplate`和`rowsTemplate`等函数的使用方法与参数约束。这些资料旨在帮助开发者精细控制Grid组件的显示逻辑、布局结构及性能表现，适用于需要构建复杂网格界面的UI开发场景。

## 详细描述

### func_cachedCountI_5more_6df280a5.md
本文档是ArkUI框架中Grid组件的API参考文档，主要介绍了使用Cangjie语言配置网格布局和缓存行为的方法。文档涵盖了设置预加载GridItem数量的cachedCount函数、定义行列间距的columnsGap与rowsGap函数，以及控制列数和列宽的columnsTemplate函数。关键信息包括cachedCount仅在LazyForEach中生效以优化性能，以及columnsTemplate支持auto-fit、auto-fill等关键字实现自适应布局。该文档面向具备ArkUI开发基础的应用开发者，旨在帮助其精细控制Grid组件的显示与性能。

### func_rowsTemplateString.md
本文档是ArkUI框架中Grid组件rowsTemplate函数的API参考文档，用于设置网格布局的行数、固定行高或最小行高。主要内容包括函数签名、语法示例（如fr单位和repeat关键字）、参数约束以及三种布局模式的详细说明。关键信息指出了不同repeat模式（auto-fit、auto-fill、auto-stretch）的区别，以及Grid在同时设置、仅设置一个或都不设置行列模板时的布局与滚动行为差异。文档面向使用仓颉语言的UI开发者，旨在帮助其精确控制Grid组件的行列结构和显示逻辑。
