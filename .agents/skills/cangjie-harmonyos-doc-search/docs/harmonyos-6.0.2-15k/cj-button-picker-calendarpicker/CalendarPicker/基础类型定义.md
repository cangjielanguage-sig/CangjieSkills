## 基础类型定义

### class CalendarOptions

```cangjie
public open class CalendarOptions {
    public CalendarOptions(
        public let hintRadius!: Length = 16.vp,
        public let selected!: DateTime = DateTime.now()
    )
}
```

**功能：** 配置日历选择器组件的参数。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### let hintRadius

```cangjie
public let hintRadius: Length = 16.vp
```

**功能：** 描述日期选中态底板样式。

**类型：** [Length](./cj-common-types.md#interface-length)

**读写能力：** 只读

**起始版本：** 19

#### let selected

```cangjie
public let selected: DateTime = DateTime.now()
```

**功能：** 设置选中项的日期。初始值：当前系统日期。

**类型：** DateTime

**读写能力：** 只读

**起始版本：** 19

#### CalendarOptions(Length, DateTime)

```cangjie
public CalendarOptions(
    public let hintRadius!: Length = 16.vp,
    public let selected!: DateTime = DateTime.now()
)
```

**功能：** 构造一个CalendarOptions对象，初始化日历选择器组件中的参数。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|hintRadius|[Length](./cj-common-types.md#interface-length)|否|16.vp| **命名参数。** 描述日期选中态底板样式。<br>取值范围：[0, 16]。<br>单位：vp<br>初始值：底板样式为圆形。<br/>**说明：**<br/>hintRadius为0，底板样式为直角矩形。hintRadius为0 ~ 16，底板样式为圆角矩形。hintRadius>=16，底板样式为圆形。|
|selected|DateTime|否|DateTime.now()| **命名参数。** 设置选中项的日期。选中的日期未设置或日期格式不符合规范则为初始值。<br>初始值：当前系统日期。|

### enum CalendarAlign

```cangjie
public enum CalendarAlign {
    | START
    | CENTER
    | END
}
```

**功能：** 对齐方式类型。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

CENTER

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### END

END

START
