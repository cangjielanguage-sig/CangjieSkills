# internationalization

This directory serves as a comprehensive resource hub for internationalization (i18n) and localization (l10n) within the Cangjie development ecosystem. It covers a wide array of critical topics including calendar systems, time zone handling, daylight saving time transitions, UI design for global audiences, singular and plural rules, and translation best practices. Additionally, it provides guidelines for linguistic testing and sensitive content review. This collection is suitable for developers, architects, UI/UX designers, and localization engineers aiming to adapt applications for global markets, ensuring cultural compatibility and technical robustness across different regions.

## Detailed Description

### [1] README_zh/
This directory contains the Chinese index documentation for the localization development kit, designed to guide developers in implementing internationalization and localization features in their applications. The content covers core topics such as an i18n overview, UI design, calendar systems, time zone and daylight saving time handling, localized names, translation scenarios, singular/plural support, and language testing. It pays special attention to technical details like DST transitions and timezone display, noting that some features are currently in the Beta stage. This document is suitable for application developers looking to adapt their apps for the global market.

### [2] cj-i18n-calendar/
This directory provides detailed development documentation for the `cj-i18n-calendar` module, focusing on solving international calendar handling issues in application development. The content revolves around the `Calendar` class within `LocalizationKit`, detailing how to configure and convert between various calendar systems, including Gregorian, Chinese, Buddhist, and Islamic calendars. It covers basic module imports, time and time zone settings, and深入 explains date arithmetic and conversion logic between calendars. This resource is ideal for developers building global applications that need to handle complex date differences across regions.

### [3] cj-i18n-dst-transition/
This directory contains specification documentation regarding the Daylight Saving Time (DST) transition mechanism in the Cangjie system. The content covers the basic definition of DST, system-level automatic configuration rules, and how applications synchronize time via standard interfaces. The core focus is on three major processing rules: calculating the 23-hour or 25-hour differences on DST days, resolving gaps and overlaps caused by time jumps, and recommending the use of UTC or GMT for data storage and transmission to prevent information loss. This document is intended for Cangjie developers working on internationalization.

### [4] cj-i18n-l10n/
This directory focuses on implementation guides for internationalization (i18n) and localization (l10n), helping developers build software products for the global market. Content spans the full lifecycle from basic concepts and system development guidelines to resource configuration, translation, sensitive taboo checks, and testing. Key emphases include the complete separation of UI elements and code logic, avoiding hardcoded cultural assumptions, and dynamic loading mechanisms for multi-language resources. This guide is suitable for architects and engineers involved in cross-regional application development.
