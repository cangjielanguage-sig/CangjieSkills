This directory serves as a comprehensive resource for the Circle component within the ArkUI framework, specifically tailored for developers working with Cangjie applications. It focuses on the technical implementation of drawing circular shapes, providing detailed API reference documentation. The content covers the instantiation of the Circle component through two primary constructors: one utilizing width and height parameters, and a parameterless alternative that necessitates explicit size attributes. Key technical specifications are addressed, including the logic where the circle diameter defaults to the shorter side when dimensions differ, as well as the graceful handling of invalid values. Furthermore, the documentation enumerates supported universal and graphic-specific attributes—such as stroke and fill—and includes practical code examples demonstrating the creation of solid circles and stroked rings. This guide is intended for Cangjie developers seeking to integrate circular graphics into their user interfaces, assuming prior familiarity with ArkUI component structures and Length types.
