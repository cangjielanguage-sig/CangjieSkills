# 数据保存和恢复

This directory serves as a technical resource for developers working with the Cangjie language and the AbilityKit framework, focusing specifically on the critical aspects of data saving and application recovery. It details methodologies for preserving application state during unexpected errors or terminations, ensuring a seamless user experience. The content covers two primary approaches: active state management using `appRecovery` and `ErrorObserver`, and passive state saving via `onSaveState` and launch reason detection. Key technical concepts include handling `wantParams`, identifying `APP_RECOVERY` triggers, and implementing restoration logic within the `onCreate` lifecycle method. These guides are indispensable for developers seeking to enhance application stability, prevent data loss, and implement robust error recovery mechanisms in their software projects.

## Detailed Description

### 数据保存和恢复_3more.md 数据保存和恢复_3more.md
This technical guide explains how to implement active state saving and recovery using the appRecovery feature in Cangjie applications. It covers importing necessary packages, registering an ErrorObserver callback, implementing data saving via the onSaveState method, handling data recovery in onCreate during app restart, and unregistering the observer. Key takeaways include triggering save and restart functions within an error callback, storing data in wantParams, and retrieving it from want.parameters when the launch reason is APP_RECOVERY. This tutorial targets developers using the AbilityKit framework who need to ensure application resilience and data persistence after errors.

### 被动保存和恢复_2more.md 被动保存和恢复_2more.md
This technical guide explains how to implement passive state saving and restoration mechanisms for applications using the Cangjie language. It covers the implementation of the onSaveState method for data persistence and the onCreate method for data recovery based on launch reasons, as well as detecting fault-based restarts using specific markers. Key takeaways include saving data to wantParams during onSaveState and checking for LaunchReason.APP_RECOVERY or the ABILITY_RECOVERY_RESTART: true parameter in onCreate to handle restoration. This guide targets application developers working with the AbilityKit framework who need to ensure app resilience and data persistence during unexpected terminations.
