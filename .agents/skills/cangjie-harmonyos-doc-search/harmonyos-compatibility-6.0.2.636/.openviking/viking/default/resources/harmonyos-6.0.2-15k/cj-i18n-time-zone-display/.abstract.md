This directory provides a comprehensive development guide focused on the internationalization (i18n) of time zone displays within the Cangjie programming ecosystem. It addresses the critical requirement of adapting time zone names to conform to specific regional language habits and cultural norms. The documentation covers essential usage scenarios and offers detailed, step-by-step instructions for implementation. Key technical elements include importing the LocalizationKit, constructing TimeZone objects, and leveraging the `getDisplayName` method with parameters for locale and daylight saving time status. This resource is tailored for Cangjie developers aiming to build globally accessible applications that display time-sensitive data accurately across different languages and regions. It ensures that applications respect the linguistic nuances of their target audience.
