# 密钥对材料格式

This directory contains technical reference documents defining the binary memory layout and byte structure for cryptographic key pair materials. It covers specifications for various algorithms including RSA, ECC, DSA, DH, and Curve25519, detailing how to map variables to memory offsets and construct key byte arrays. The content explains the composition of key materials, including headers, original data, and length fields for variable components. It is suitable for software developers and system architects implementing low-level cryptographic storage or communication protocols who need to manually format raw key data.

## Detailed Description

### 密钥对材料格式_1.md
This technical reference document defines the memory layout and byte structure for key pair materials, specifically using RSA as an example. It details the composition of key materials, consisting of a header and the original data, and explains how to map variables to specific memory offsets. The document provides a Cangjie code snippet demonstrating the construction of an RSA 2048 key byte array, including encoding the algorithm type, key size, and component lengths. It serves as a guide for developers who need to manually format raw key data for cryptographic operations, referencing the HuksKeyAlg structure for algorithm values.

### 密钥对材料格式_2.md
This technical reference document defines the specific binary data structure and byte layout for key pair materials across multiple cryptographic algorithms. It details the format specifications for RSA, ECC, DSA, DH, and Curve25519 algorithms, presenting tables that map algorithm identifiers, key sizes, and parameter lengths to their corresponding data fields. A critical design pattern is the use of 4-byte length fields preceding variable-length data components, such as the modulus in RSA or coordinates in ECC, ensuring consistent parsing. Intended for software developers and system architects implementing low-level cryptographic storage or communication protocols, this guide requires an understanding of asymmetric cryptography concepts.
