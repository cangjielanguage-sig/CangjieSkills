This directory provides comprehensive technical documentation for implementing drag-and-drop functionalities within the ArkUI framework. It covers the complete drag-and-drop lifecycle, including event mechanisms, data transfer via UDMF, and visual customization like backdrop images. The content distinguishes between gesture-based and mouse-driven operations, addressing advanced scenarios such as cross-application data transfer and UI feedback management. It is suitable for developers and UI engineers looking to integrate interactive data movement, copying, or deletion features into their applications using ArkUI or the Cangjie framework.
