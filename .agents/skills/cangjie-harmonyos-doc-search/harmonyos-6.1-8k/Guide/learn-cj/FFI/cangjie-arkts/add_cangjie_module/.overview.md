# add_cangjie_module

This directory serves as a comprehensive technical resource dedicated to the integration of the Cangjie programming language within the HarmonyOS development ecosystem. As Cangjie is a core language for the platform, this guide provides a structured approach to incorporating Cangjie modules, covering both dynamic and static library implementations, into standard ArkTS projects. The documentation addresses critical configuration aspects, such as setting up the DevEco Studio environment, managing `cjpm.toml` settings, and defining TypeScript types to ensure type safety across language boundaries. Additionally, it explores the interoperability mechanisms that facilitate smooth interaction between ArkTS and Cangjie. This resource is ideally suited for HarmonyOS application developers who wish to adopt mixed programming techniques, allowing them to combine the strengths of multiple languages and execute cross-language function calls effectively in their software solutions.
