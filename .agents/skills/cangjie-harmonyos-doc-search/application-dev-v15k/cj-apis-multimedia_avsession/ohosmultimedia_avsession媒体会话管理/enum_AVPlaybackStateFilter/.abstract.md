This directory contains comprehensive API reference documentation for the `AVPlaybackStateFilter` enum within the Cangjie programming language. It is designed to assist developers in specifying which media playback state fields—such as playback status, speed, position, volume, and video dimensions—should be monitored for changes. The documentation covers the enum definition, specific filter keys for granular control, and utility functions for string representation. This module is part of the SystemCapability.Multimedia.AVSession.Core capability, available starting from version 19. It is suitable for developers building multimedia applications who need to manage or filter playback state updates efficiently and require precise control over event handling.
