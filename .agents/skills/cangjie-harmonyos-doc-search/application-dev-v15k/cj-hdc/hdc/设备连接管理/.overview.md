# 设备连接管理

This directory focuses on managing device connections within the HarmonyOS ecosystem using the HarmonyOS Device Connector (hdc) tool. It covers essential operations such as querying device lists, switching between USB and wireless debugging modes, and handling multi-device environments. Additionally, it addresses common connection scenarios including local USB/TCP links and remote network configurations. The content is designed for developers, testers, and system administrators who need reliable command-line solutions for device debugging, connectivity management, and network configuration in HarmonyOS development workflows.

## Detailed Description

### usb调试和无线调试切换.md usb调试和无线调试切换.md
This technical reference guide documents commands for switching between USB and wireless debugging modes using the hdc tool. It covers the `tmode` command for opening or closing network connection channels and the `tconn` command for connecting to devices via IP address and port. Key information includes specific parameters, return values, and usage examples, alongside critical warnings that switching modes restarts the device daemon and disconnects active USB connections. The document targets developers or system administrators who need to manage device connectivity, requiring familiarity with command-line operations and network configuration.

### 查询设备列表_3more.md 查询设备列表_3more.md
This reference guide explains how to manage connected devices using the HarmonyOS Device Connector (hdc) tool. It covers querying device lists, targeting specific devices using the -t parameter, and waiting for device connections. Key commands include hdc list targets [-v] to view identifiers and hdc -t [connect-key] [command] for multi-device operations. The document defines the connect-key as the serial number for USB or IP:Port for network connections, while detailing return values and potential error messages. This guide targets developers or testers managing HarmonyOS devices who need to handle single or multiple device connections via command line.
