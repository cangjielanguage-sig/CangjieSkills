# class_DeviceKVStore

This directory contains API reference documentation for the `DeviceKVStore` class in the Cangjie language, part of the ArkData framework. It focuses on managing device-collaborative distributed databases, enabling developers to handle data isolation where local data is read-write and remote data is read-only. Key topics include querying data by key or prefix, retrieving result sets, and counting query results. This documentation is suitable for developers implementing distributed data features like cross-device photo sharing who require knowledge of Cangjie syntax and distributed data management concepts.
