This directory serves as a technical resource for developers and performance engineers focused on analyzing EventHandler dump logs to diagnose application freezes and system responsiveness issues. It provides in-depth instructions on examining current running statuses, history event queues, and specific priority queue configurations. Key topics include methods for calculating task duration using timestamps, understanding the functional roles of VIP and High priority queues, and identifying scheduling starvation. The documentation covers specific mechanisms such as ArkUI input transmission chains and periodic watchdog tasks, making it suitable for those troubleshooting thread scheduling and event handling bottlenecks.
