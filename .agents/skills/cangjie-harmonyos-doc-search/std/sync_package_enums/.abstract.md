This directory serves as the definitive source for API reference documentation regarding enumeration types within the synchronization package of the Cangjie programming language. It is designed to assist developers in understanding and implementing strict behavioral contracts for concurrent operations. The content covers a wide range of synchronization topics, including detailed explanations of timer catchup strategies, atomic operation memory ordering, and mutex lock fairness. Specifically, it provides crucial definitions for the Delay, Burst, and Skip strategies, which allow developers to precisely manage how systems handle delayed timer executions and task scheduling. Additionally, the documentation outlines MemoryOrder and ReadWriteMutexMode enums, while clearly marking them as deprecated to guide developers away from legacy implementations. This directory is highly suitable for Cangjie developers who are building robust concurrent systems and need granular control over thread synchronization primitives, ensuring that their applications remain responsive and consistent under heavy load. Mastering these enums is essential for optimizing performance and correctness in multi-threaded environments.
