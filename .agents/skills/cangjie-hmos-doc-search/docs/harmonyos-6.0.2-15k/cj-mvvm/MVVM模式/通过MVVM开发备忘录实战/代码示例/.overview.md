# 代码示例

This directory serves as a comprehensive resource for developers working with the Cangjie programming language within the HarmonyOS ecosystem. It focuses on the practical implementation of the Model-View-ViewModel (MVVM) architectural pattern through detailed To-Do List application examples. The content covers critical aspects of modern UI development, including project structuring, data modeling, and the creation of reactive user interfaces. Key technical concepts demonstrated include state synchronization and data binding using specific decorators such as `@Observed`, `@Publish`, `@State`, and `@Link`. By examining these examples, developers can learn how to effectively separate concerns, manage application state, and build modular, reusable components. This material is ideal for Cangjie developers and software engineers seeking to enhance their understanding of structured, reactive application design and best practices in HarmonyOS development.

## Detailed Description

The files in this section provide specific code implementations and architectural guidance for building applications using the MVVM pattern.

### 代码示例_1.md
This document provides a code example demonstrating the refactoring of a To-Do List application using the MVVM architectural pattern in the Cangjie programming language. It details the project directory structure and presents code implementations for the main entry view, data models, and specific UI components like the list and selection buttons. Key takeaways include the use of reactive programming concepts through decorators such as @Observed, @Publish, @State, and @Link to manage state synchronization between the View and ViewModel layers. This example serves as a practical guide for developers aiming to build structured, reactive UI applications within the HarmonyOS ecosystem.

### 代码示例_2.md
This document provides a code example demonstrating the implementation of a Todo application using the MVVM architecture in the Cangjie language. It covers View components like ThingComponent and TodoListComponent, alongside ViewModels such as ThingViewModel and TodoListViewModel. The code illustrates state management using decorators like @Observed, @Publish, and @Link, highlighting data binding and UI updates. It emphasizes modular design for better code reusability and clarity. This tutorial targets Cangjie developers looking to understand MVVM patterns in HarmonyOS UI development.
