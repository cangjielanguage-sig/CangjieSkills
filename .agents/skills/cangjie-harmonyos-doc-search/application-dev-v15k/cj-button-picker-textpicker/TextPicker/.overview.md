## Detailed Description

### TextPicker_4more.md TextPicker_4more.md
This document provides API reference documentation for the TextPicker component, a sliding selector used for choosing text content in the ArkUI framework using the Cangjie language. It details two primary initialization methods: one using a TextPickerOptions object and another accepting an array of strings with optional parameters for the selected index and value. Key information includes parameter definitions, version compatibility (starting at version 12 or 19), and selection logic where the index takes priority over the value. The document notes that empty arrays are invalid and the value parameter only works for text lists. Intended for developers familiar with Cangjie and ArkUI, this guide explains how to configure and implement the TextPicker while supporting all universal attributes and events.

### 组件事件.md 组件事件.md
This document serves as API reference documentation for the onChange event callback function within a TextPicker component using the Cangjie language. It details the function signature, system capabilities, and version requirements, specifically noting availability from version 12. The main section focuses on the callback parameter, which returns a TextPickerResData object containing the selected text and index. Key information includes the conditional behavior of the return value: it provides text for text or mixed lists but returns empty for image-only lists. This guide is intended for developers building ArkUI interfaces who need to handle user selection events in TextPicker components.
