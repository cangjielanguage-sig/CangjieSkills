# 加解密

本目录主要涵盖数据加解密相关的开发指南与实现案例，重点介绍了AES、RSA、SM2等主流算法的应用。内容涉及UniversalKeystoreKit框架的密钥全生命周期管理、API调用流程以及基于HarmonyOS HUKS和仓颉语言的实战开发案例。核心关键词包括AES、RSA、SM2、HUKS、密钥管理、数据安全。该文档适用于需要在应用中集成数据安全保护功能的开发者，帮助其快速掌握加密技术的集成与实现。

## 详细描述

### 加解密_55162ad7.md
本文档旨在介绍如何使用AES 128、RSA 2048和SM2等算法进行数据的加解密操作。主要内容包括加解密的具体实现示例，以及指向密钥生成支持算法详细规格的参考链接。关键信息在于明确了当前支持的典型算法类型，并提示该功能处于Beta阶段，开发者需查阅关联文档以获取具体场景介绍。文档面向需要实现数据安全保护的开发者，作为开发指南或API参考文档，帮助其快速掌握加解密功能的集成方法。

### 开发步骤.md
这份文档是UniversalKeystoreKit框架的加密开发指南，旨在指导开发者完成密钥的全生命周期管理。文档涵盖生成密钥、加密、解密及删除密钥四个核心步骤。关键信息详细说明了调用generateKeyItem、initSession和finishSession等API的流程，并针对AES、RSA、SM2等不同算法提供了具体的参数配置示例，强调了IV、NONCE等必要参数的设置。该文档面向应用开发者，帮助其在应用中安全地实现数据加解密功能。

### 开发案例/
本目录汇集了基于仓颉语言和HarmonyOS通用密钥库（HUKS）的加密算法开发案例。内容涵盖了SM2国密、AES（CBC/PKCS7、GCM/NoPadding）以及RSA（OAEP/SHA256、PKCS1_V1_5）等多种算法的完整实现流程，包括密钥生成、参数配置、数据加解密及密钥生命周期管理。核心关键词包括HUKS、仓颉语言、SM2、AES、RSA、数据安全。该文档适合致力于HarmonyOS应用安全开发、需要掌握HUKS API调用及数据加密技术的开发者参考。
