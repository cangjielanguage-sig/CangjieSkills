# 使用场景

This directory focuses on practical usage scenarios for conditional rendering within the Cangjie and ArkUI declarative UI frameworks. It covers the implementation of `if` statements, the impact of conditional logic on component lifecycle, and state management strategies for child components. Key topics include state-driven UI updates, nested conditional logic, and preserving state across branch switches. This content is suitable for Cangjie developers and UI engineers looking to master dynamic interface construction and understand the underlying mechanics of component destruction and recreation during conditional rendering.

## Detailed Description

### if_else_语句和子组件状态.md if_else_语句和子组件状态.md
This technical guide illustrates how conditional rendering with if-else statements impacts the state management of child components. It compares two scenarios: one using local @State variables and another utilizing @Link variables connected to a parent component. The key takeaway is that switching conditional branches destroys and recreates component instances, causing local state loss. To preserve state across condition changes, developers must move state ownership to the parent component using the @Link decorator. This tutorial targets UI developers familiar with state management decorators and component lifecycle.

### 使用if进行条件渲染.md 使用if进行条件渲染.md
This document serves as a tutorial for implementing conditional rendering in Cangjie using if statements within a declarative UI framework. Main sections include a code example demonstrating state-driven UI updates and the underlying mechanism of component lifecycle during condition re-evaluation. Key information explains that state changes trigger condition re-evaluation, causing the framework to delete previously rendered components and construct new ones for the active branch. The intended audience is Cangjie developers building dynamic user interfaces who need to understand how conditional logic affects component rendering and updates.

### 嵌套if语句.md 嵌套if语句.md
This document serves as a code example demonstrating the usage of nested conditional statements within the Cangjie UI framework. It illustrates how to implement nested `if-else` logic inside a `Column` component without affecting the parent component's rules. The code utilizes `@State` variables to control the visibility and styling of `Text` elements based on boolean flags. Key takeaways include understanding that nested conditions function independently of parent layout rules and how to manage multiple state triggers. This tutorial is intended for Cangjie developers learning control flow and state-driven UI rendering.
