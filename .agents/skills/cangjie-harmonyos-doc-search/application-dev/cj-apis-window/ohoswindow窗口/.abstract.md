This directory contains comprehensive API reference documentation for the HarmonyOS window management module (ohos.window) specifically designed for the Cangjie programming language. It covers essential components for developing graphical user interfaces, including window creation, configuration, lifecycle management, and event handling. Key topics include window types, screen orientation, system bar properties, and layout constraints like avoid areas. Intended for application developers and system integrators, these resources provide the technical specifications needed to implement robust window management features, handle screen obstructions, and customize system UI elements within the WindowManager framework starting from API version 22.
