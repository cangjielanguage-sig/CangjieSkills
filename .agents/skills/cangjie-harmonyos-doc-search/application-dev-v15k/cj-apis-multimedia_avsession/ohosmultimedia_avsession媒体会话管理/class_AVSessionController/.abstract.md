This directory provides API reference documentation for the `AVSessionController` class in the Cangjie language, designed for HarmonyOS multimedia applications. It covers session management, including retrieving metadata, monitoring playback states, and sending control commands. Developers will find details on event listeners for device and state changes, as well as methods to interact with the AVSession framework. This resource is essential for developers building robust media applications that require precise control over audio-video sessions and dynamic response to session events.
