This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically detailing the extension of the `UIntNative` type through the `ThrowingOp` interface. It covers a wide array of arithmetic and bitwise operations—including `throwingAdd`, `throwingMul`, `throwingShl`, and `throwingSub`—that prioritize safety by utilizing an exception-throwing strategy. Instead of wrapping around on errors, these functions throw specific exceptions like `OverflowException` and `OvershiftException`. This resource is essential for Cangjie developers who need to implement robust error handling and explicit arithmetic checks in their software, ensuring that integer overflows and invalid shifts are caught and managed gracefully during runtime. By using these APIs, developers can prevent silent data corruption and improve the reliability of their numerical computations.
