This directory contains essential API reference documentation for the `Indicator` class, utilized within the ArkUI framework and implemented using the Cangjie language. It serves as a guide for configuring navigation points inside Swiper components, covering the creation of specific indicator types like `DigitIndicator` and `DotIndicator`. The content details instance methods for positioning elements (bottom, left, right, end), explains layout behaviors such as default adaptive sizing, and outlines interaction area constraints. It also clarifies priority rules for conflicting positioning attributes. This documentation is specifically tailored for UI developers and system engineers who possess knowledge of Cangjie syntax and ArkUI layout principles and are working on customizing Swiper component behaviors in system version 19 or higher.
