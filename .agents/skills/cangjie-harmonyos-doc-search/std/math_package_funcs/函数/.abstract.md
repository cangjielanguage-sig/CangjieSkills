This directory contains API reference documentation for mathematical and bitwise utility functions within the Cangjie standard library. It covers a comprehensive range of operations including basic arithmetic, trigonometric and hyperbolic functions, logarithmic and exponential calculations, number theory algorithms like GCD and LCM, and low-level bit manipulation. The documentation details function signatures, parameter constraints, return types, and exception handling for various numeric types such as Int8, Int64, Float16, and Float64. This resource is suitable for Cangjie developers seeking precise implementation details and verified code examples for mathematical computations and bitwise operations.
