This directory provides technical documentation for digital signature and verification algorithms within a cryptographic framework. It covers the principles of data integrity, sender identity verification, and specific implementation details for various algorithms including DSA, SM2, Ed25519, ECDSA, and RSA. The documents detail parameter construction, supported key types, digest combinations, and API compatibility (version 12+). Suitable for developers and security engineers, these guides ensure correct algorithm instantiation and secure integration of cryptographic functions.
