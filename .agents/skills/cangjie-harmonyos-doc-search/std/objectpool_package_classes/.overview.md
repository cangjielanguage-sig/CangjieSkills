This document serves as the comprehensive API reference for the deprecated `ObjectPool` class within the Cangjie standard library. It provides a technical deep dive into a concurrent-safe mechanism specifically engineered for caching and reusing allocated objects, a technique crucial for minimizing memory allocation costs in high-performance applications. The content thoroughly covers the class definition, including the constructor initialization process which requires a creation function and allows for an optional reset function. It details the core methods `get` and `put`, explaining their roles in object lifecycle management. Key takeaways highlighted in the document include the pool's restriction to storing objects of a single type and the critical safety requirement that objects returned via `put` must not be accessed further to prevent data races. Intended primarily for Cangjie developers who need to maintain legacy code or understand resource pooling patterns, this guide includes practical usage examples to demonstrate efficient resource management in concurrent environments, while prominently warning of the class's future deprecation to ensure long-term code maintainability.
