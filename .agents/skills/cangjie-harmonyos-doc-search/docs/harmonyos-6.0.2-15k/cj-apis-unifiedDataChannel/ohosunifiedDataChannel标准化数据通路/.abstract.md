This directory contains API reference documentation for the HarmonyOS Unified Data Management Framework (UDMF) using the Cangjie programming language. It covers standardized data channels for cross-application sharing, defining core classes like UnifiedData, UnifiedRecord, and specific data types such as Image, Video, and Text. The documentation details functions for data manipulation (insert, delete, query, update) and configuration options. It is suitable for HarmonyOS developers implementing distributed data management, enabling efficient data exchange and standardized type handling across applications.
