# cj-uiability-startup-adjust

This directory serves as a specialized technical repository for HarmonyOS developers focusing on the Cangjie language, specifically addressing the modernization of application startup and navigation patterns. The core subject matter revolves around the critical transition from traditional explicit Want jumps to the more secure and standardized App Linking mechanism. It covers the entire lifecycle of link adaptation, including initial configuration in `module.json5`, the coding of the `openLink` interface, and the management of return results through UIAbility. Furthermore, it addresses complex scenarios such as implicit matching rules, domain verification for security, and the nuanced configuration of `OpenLinkOptions` to differentiate between AppLinking and DeepLinking. This resource is essential for developers aiming to ensure their applications comply with API 18 standards while maintaining robust cross-application communication and data exchange capabilities. It provides the necessary blueprint for upgrading legacy navigation logic to meet current ecosystem requirements, ensuring that applications remain secure, interoperable, and aligned with the latest HarmonyOS development best practices. By following these guidelines, developers can ensure a seamless user experience during application switching while strictly adhering to the platform's security protocols.

### 显式Want跳转切换应用链接跳转适配指导/
