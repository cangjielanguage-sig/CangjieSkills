# 应用安装与更新一致性校验

This directory provides technical reference documents detailing consistency verification rules for application installation and updates. It focuses on ensuring security and legality through signature certificate validation and configuration file checks. Key topics include version identity definitions, field validation for appId and bundleName, and specific logic for installation versus update scenarios. Suitable for developers and release managers, these guides help maintain deployment stability by enforcing strict checks on metadata like app.json5 and module.json5 files.

## Detailed Description

### 应用安装与更新一致性校验_2more.md
This technical reference document outlines consistency verification rules for installing and updating multi-module applications to ensure security and legality. It primarily focuses on signature certificate validation and configuration file checks. Key sections define version identity based on app.json5 and provide a detailed table of verification rules for fields such as appId, appIdentifier, appDistributionType, appProvisionType, and apl. The document distinguishes between installation requirements and update scenarios, specifically noting differences between same-version and different-version updates. This guide is intended for developers and release managers handling complex application packaging and deployment.

### 配置文件一致性校验.md
This document serves as a technical reference defining consistency validation rules for application configuration fields during installation and update processes. It details a comprehensive table of fields including bundleName, versionCode, apiReleaseType, and appType, mapping them to their sources in app.json5 or module.json5 files. Key information highlights the specific validation logic for installation versus updates, such as mandatory consistency for bundleName and versionCode, or specific restrictions for the isStage model. Intended for developers and system integrators working on HarmonyOS application packaging, this guide ensures deployment stability by enforcing strict checks on critical metadata to prevent conflicts.
