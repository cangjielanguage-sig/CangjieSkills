# 使用Web组件的PDF文档预览能力

This directory provides a comprehensive technical guide on implementing PDF document preview functionality within applications using the Web component. It covers various loading scenarios including network PDFs, local sandbox files, and application resource files, alongside necessary permission configurations and UI persistence settings. The guide also details URL parameter configurations for customizing the viewing experience, such as zoom levels and toolbar visibility. Written in Cangjie, this content is tailored for application developers building ArkUI interfaces who need to integrate and customize document viewing capabilities. It specifically addresses the differences between static loading and dynamic updates, as well as the nuances between different resource URL formats.

## Detailed Description

### 使用Web组件的PDF文档预览能力_1.md 使用Web组件的PDF文档预览能力_1.md
This guide explains how to implement PDF document preview functionality within applications using the Web component. It covers three primary loading scenarios: network PDFs, local sandbox files, and application resource files. Key information includes necessary permission configurations, such as internet access and file system access, and the requirement to enable domStorageAccess for UI persistence. The document clarifies that while the src attribute sets the initial document, the loadUrl() interface must be used for dynamic updates. Written in Cangjie, this tutorial targets application developers building ArkUI interfaces who need to integrate document viewing capabilities.

### 使用Web组件的PDF文档预览能力_2.md 使用Web组件的PDF文档预览能力_2.md
This technical guide explains how to implement PDF document preview capabilities within an application using the Web component. It covers resource loading methods, specifically comparing `@rawfile` and `resource://` URLs, and details supported URL parameters for controlling the view. Key information includes the ability to configure the initial state using parameters like `page`, `zoom`, `toolbar`, and `navpanes`. Notably, the `@rawfile` method does not support these parameters, whereas the resource URL method allows for granular control over the preview interface. This document is intended for application developers using the Cangjie language who need to embed and customize PDF viewing experiences.
