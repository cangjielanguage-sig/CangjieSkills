This directory functions as the primary documentation repository for the `runtime_package_funcs` module, a critical component of the Cangjie programming language's standard library. It is dedicated to providing comprehensive API references and technical specifications for runtime management functions that govern system-level operations. The scope of this documentation includes, but is not limited to, garbage collection control, heap memory analysis, compiler optimization hints, and system resource monitoring. By detailing these functionalities, the directory assists developers in fine-tuning application performance, debugging memory leaks, and managing CPU profiling sessions. It is an indispensable resource for Cangjie developers, backend engineers, and system programmers who require deep visibility into the runtime environment. Furthermore, it addresses platform-specific behaviors and tracks deprecation notices, such as the transition from `GC` to `gc`, ensuring that development teams can maintain modern, efficient, and robust codebases while successfully navigating the evolving landscape of the Cangjie language ecosystem.
