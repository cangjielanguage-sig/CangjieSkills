This directory contains API reference documentation for the `ohos.bluetooth.connection` module in the HarmonyOS Cangjie development environment. It covers essential Bluetooth functionalities including device discovery, pairing, connection management, and state monitoring. Key components include data structures for battery and device info, enums for transport and bond states, and functions for handling callbacks and remote device interactions. Designed for developers using the ConnectivityKit, these resources facilitate the implementation of robust Bluetooth communication features in Cangjie applications, ensuring proper handling of permissions, system capabilities, and asynchronous events.
