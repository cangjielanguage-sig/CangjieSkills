This directory contains API reference documentation for the `ArbitraryRange` interface in the Cangjie programming language. It focuses on generating random values within specified ranges for various numeric types, facilitating property-based testing. The documentation covers interface definitions and extensions for signed and unsigned integers (Int8, Int16, Int32, Int64, IntNative, UInt8, UInt16, UInt32, UInt64, UIntNative) and floating-point numbers (Float16, Float32, Float64). Key components include static methods for boundary retrieval and the `arbitraryRange` function for creating Generators. This resource is suitable for developers implementing property-based testing frameworks or needing constrained random data generation for unit tests.
