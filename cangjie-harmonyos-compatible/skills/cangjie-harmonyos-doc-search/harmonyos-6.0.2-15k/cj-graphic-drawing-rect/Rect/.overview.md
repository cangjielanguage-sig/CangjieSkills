# Rect

This directory contains comprehensive documentation and code examples for the Rect component within the ArkUI framework, specifically tailored for the Cangjie language in HarmonyOS development. It covers the complete lifecycle of rectangle implementation, from component creation using various constructors to advanced styling with border radii. Key topics include handling dimension constraints, utilizing universal attributes, and rendering complex shapes like rounded corners with specific height and width parameters. This resource is suitable for UI developers and programmers who possess prerequisite knowledge of Cangjie syntax and need to implement custom geometric shapes and layouts in their applications.

## Detailed Description

### Rect_4more.md Rect_4more.md
This document serves as API reference documentation for the Rect component, used for drawing rectangles within the ArkUI framework using the Cangjie language. It details component creation through two init constructors: one accepting named width and height parameters, and another creating a zero-sized rectangle that requires subsequent attribute configuration. The text specifies parameter constraints, such as non-negative values and default units, while noting support for universal and graphic drawing attributes. Key information includes handling of exception values and the system capability requirements. This reference is intended for UI developers who need to implement rectangular shapes and possess prerequisite knowledge of Cangjie syntax and ArkUI universal attributes.

### 示例代码.md 示例代码.md
This document serves as a practical code example demonstrating the usage of the Rect component within the Cangjie UIKit framework for HarmonyOS development. The primary focus is on rendering various rectangle styles, including basic filled shapes, stroked outlines, and complex rounded corners. Key information includes methods for setting uniform corner radii, distinct height and width radii, and specific radii for individual corners using array parameters. This snippet is designed for developers learning to implement custom UI shapes and layout styling in Cangjie applications.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring border radius properties within the ArkUI framework using the Cangjie language. It details five specific functions: radius (with three overloads for single values, arrays, and tuple arrays), radiusHeight, and radiusWidth. Key information includes that all functions require non-negative values, default to virtual pixels (vp), and handle invalid inputs by reverting to the initial value of 0. These features are available starting from API version 12. The target audience is UI developers using Cangjie who need to customize the corner rounding of components.
