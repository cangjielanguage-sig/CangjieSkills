This directory contains API reference documentation for the `ContextMenuOptions` class initializer within the ArkUI framework. It provides comprehensive technical details on constructing context menu objects with a wide array of configuration options. The documentation covers essential parameters for spatial positioning, visual styling, animation transitions, and lifecycle event handling. Key topics include offset adjustments, arrow display logic, preview content, and border radius customization. This resource is suitable for UI developers and engineers using the ArkUI framework who need to programmatically implement and fine-tune context menus in their applications, ensuring precise control over layout and user interaction behaviors.
