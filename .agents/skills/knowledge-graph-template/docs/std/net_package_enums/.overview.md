# net_package_enums

This directory serves as a specialized repository for API reference documentation regarding the `net_package_enums` module, with a specific focus on the `SocketNet` enumeration within the Cangjie programming language. It is designed to provide developers with a clear and technical definition of transport layer protocol types, which are foundational components for establishing network communication. The documentation thoroughly covers the enum's architecture, detailing its three primary variants: TCP (Transmission Control Protocol), UDP (User Datagram Protocol), and UNIX (Unix Domain Sockets). Furthermore, it explains the integration of essential inherited interfaces, including `ToString` for serialization and `Equatable` for comparison logic. This directory is highly suitable for Cangjie developers, network engineers, and software architects who are implementing socket-based functionality and require precise, authoritative definitions of protocol behaviors to ensure type safety and correct operational logic in their applications.
