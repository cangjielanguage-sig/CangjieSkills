This directory contains comprehensive API reference documentation for the `WebCookieManager` class in the Cangjie language, specifically designed to manage cookie behaviors within Web components using the ArkWeb framework. It covers essential functionalities including clearing cookies, checking existence, setting permissions, and handling third-party cookies. Key features include support for both normal and incognito modes, asynchronous saving operations, and specific error handling via `BusinessException`. This documentation is suitable for developers working on HarmonyOS applications who need to implement robust web data persistence, session management, and privacy controls programmatically.
