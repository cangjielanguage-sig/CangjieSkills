## Detailed Description

### ohosrunning_lockRunninglock锁/

This directory serves as the central repository for API reference documentation regarding the `ohos.running_lock` module in the Cangjie programming environment. Its primary focus is on power management, offering developers the tools necessary to prevent system sleep and control screen states effectively through the use of RunningLocks.

The documentation is structured to cover three main components:
1.  **Main Module Functions:** These provide the entry points for interacting with the power management system, allowing developers to request and manage locks programmatically.
2.  **The `RunningLock` Class:** This class is essential for lock management, allowing applications to acquire and release locks to maintain device activity during operations that must not be interrupted.
3.  **The `RunningLockType` Enumeration:** This defines various lock types, including those used for proximity control, enabling fine-grained management over how and when the device stays awake.

This documentation is particularly suitable for HarmonyOS and Cangjie developers. It is intended for those who need to manage device power states programmatically, ensure the device remains awake during critical tasks (such as downloads, navigation, or media playback), or implement sophisticated sensor-based screen control features. By utilizing these APIs, developers can optimize user experience by balancing the need for continuous operation with the device's power consumption constraints. Specifically, the inclusion of sensor-based controls allows for dynamic screen management, such as turning the screen off when a user is on a call and the phone is near their face, which is a common requirement in modern mobile application development. The reference material provided here is essential for understanding the specific parameters and methods required to implement these behaviors correctly.
