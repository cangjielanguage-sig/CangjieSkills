# basic-services

This directory serves as a comprehensive documentation hub for the Basic Services Kit, focusing on essential system capabilities for HarmonyOS/OpenHarmony application development. It covers core functionalities such as inter-process communication (IPC), file transfer (upload and download), clipboard management, and device management. The documentation is designed to assist developers in integrating low-level communication protocols, network transmission features, and system event handling into their applications. It is particularly suitable for developers looking to implement cross-device interactions, background file operations, and efficient event-driven architectures within their software projects.

## Detailed Description

### [1] README_zh
This directory is the Chinese documentation center for the Basic Services Kit, aiming to provide comprehensive technical guidance for developers. As the main entry point for the project, it details the core architecture and functional modules of the suite, with a focus on efficient inter-process communication (IPC) mechanisms and reliable network file transfer capabilities (upload and download). The documentation explicitly states that all current features are in the Beta testing stage, meaning functionalities may still be undergoing iterative optimization. Through built-in navigation links, users can easily jump to detailed implementation pages for various sub-modules. This document is particularly suitable for developers who need to integrate underlying communication protocols or network transmission functions into their applications, helping them quickly understand the system architecture and locate necessary technical details to accelerate the development process.

### [2] cj-basic-services-kit-overview
This directory contains the overview documentation for the Basic Services Kit, designed to guide application developers in core basic capabilities such as clipboard management, file transfer, inter-process communication (IPC), and device management. The documentation details typical usage scenarios like cross-device copying and large file background downloads, covering the scope of data file processing, common events, device information, and time zone queries. Additionally, it helps developers clarify the boundaries between the Basic Services Kit and the Core File Kit. It is suitable for developers who need to integrate file compression, upload/download, and system settings queries into their applications.

### [3] common-event
This directory contains documentation for the Common Event Service (CES), a mechanism designed for efficient inter-process communication (IPC) and event-driven development. It covers fundamental concepts, classifications, and operational mechanisms of CES, providing the necessary foundation for developers to implement event handling and communication between different processes within the system.

### [4] request
This directory serves as a centralized repository for documentation and technical resources concerning file upload and download functionalities. It focuses on implementation details for HarmonyOS/OpenHarmony applications, specifically leveraging the capabilities provided by the system to handle data transmission tasks efficiently.
