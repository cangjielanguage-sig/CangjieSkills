This directory provides comprehensive API reference documentation for component properties within the ArkUI framework, specifically tailored for the Cangjie language. It focuses on the technical implementation of grid layout manipulation, covering essential functions for setting column offsets, defining element display order, and specifying column occupancy. Key concepts include responsive design patterns, the `GridColColumnOption` type, and the rendering logic for various layout parameters. This documentation is intended for software developers and UI engineers seeking to build sophisticated, responsive grid systems in ArkUI applications who need granular control over component positioning and spanning behavior.
