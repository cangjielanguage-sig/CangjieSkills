This directory serves as the central repository for the `cj-apis-wifi_manager`, a specialized API collection designed for the HarmonyOS operating system using the Cangjie programming language. It focuses extensively on Wireless Local Area Network (WLAN) management, providing developers with the necessary tools to implement complex connectivity solutions. The content covers a wide array of functionalities, ranging from basic Station (STA) mode operations to advanced Peer-to-Peer (P2P) connections. It includes detailed schemas for network configuration, IP information management, and security type definitions. Furthermore, the documentation outlines callback mechanisms essential for handling asynchronous network events. This resource is primarily intended for software developers and system engineers who are building or maintaining connectivity features within HarmonyOS applications, offering the structural definitions required to create robust, efficient, and secure WiFi networking capabilities.
