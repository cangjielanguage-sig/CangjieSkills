# Link宏父子双向同步

This directory focuses on the `@Link` macro in Cangjie ArkUI development, specifically designed for establishing two-way data binding between parent and child components. It covers technical rules, variable types, synchronization mechanisms, constraints, and practical usage scenarios including complex types like classes and arrays. Key concepts include `@Observed`, `@Publish`, and `ObservedArrayList`. This resource is suitable for developers familiar with state management decorators like `@State` who need to implement robust state synchronization and manage component interactions effectively.

## Detailed Description

### Link宏父子双向同步_4more.md Link宏父子双向同步_4more.md
This technical reference document explains the @Link macro, which establishes two-way data binding between parent and child components. It details macro usage rules, supported variable types (including complex types like classes and arrays), and variable transfer protocols. Key takeaways include that @Link variables share values with parent sources, must be initialized by the parent, and support synchronization for basic types, enums, and classes decorated with @Observed. Intended for developers familiar with @State, this guide is essential for managing state synchronization in component hierarchies.

### 常见问题.md 常见问题.md
This document serves as a troubleshooting guide for ArkUI developers using the Cangjie language, specifically addressing type mismatch errors with the @Link decorator. It covers a specific FAQ regarding state variable type errors, presenting both a counter-example and a correct implementation. The key takeaway is that a @Link variable in a child component must share the exact same type as its parent's @State data source; developers cannot link to a sub-property directly but must link to the whole object. This guide is intended for developers familiar with state management decorators like @State, @Link, and @Observed.

### 观察变化和行为表现.md 观察变化和行为表现.md
This technical guide explains the change observation mechanisms and framework behavior of the @Link decorator in state management. It covers observation rules for primitives, classes, and arrays, and details the lifecycle and synchronization processes between parent and child components. Key takeaways include that primitives sync automatically, while classes require @Observed and @Publish decorators, and arrays need ObservedArrayList for internal change detection. The document outlines the three-step mechanism: initial rendering, parent-to-child updates, and child-to-parent synchronization. Intended for developers building UI components, this reference material helps users implement two-way data binding and understand state synchronization workflows effectively.

### 限制条件.md 限制条件.md
This reference document outlines the specific constraints and usage rules for the @Link macro in Cangjie UI development. It covers scope limitations, declaration syntax, initialization requirements, type consistency, and data source restrictions. Key takeaways include that @Link is restricted to child components, requires variable declaration without local initialization, demands exact type matching with the parent's state, and cannot be initialized by constants or used with Function types. The document provides code examples illustrating correct and incorrect usage patterns. It targets Cangjie developers implementing state management in custom components to ensure compilation success and proper data flow.
