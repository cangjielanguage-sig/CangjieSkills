This directory contains the API reference documentation for the `ohos.ark_interop` library, a Beta-stage module facilitating interoperability between the Cangjie language and ArkTS environments. It covers core classes for runtime management, data type conversions, function calls, and asynchronous operations, enabling seamless cross-language integration. Key components include `JSContext`, `JSValue`, `JSArray`, and various type extensions. This documentation is suitable for Cangjie and HarmonyOS developers working on applications that require bridging native logic with ArkTS/JavaScript runtimes, providing essential tools for data exchange, object manipulation, and lifecycle management.
