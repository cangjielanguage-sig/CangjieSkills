# appjson5配置文件

This directory contains technical documentation for configuring `app.json5` files within the HarmonyOS development environment. It covers essential application settings such as bundle identification, versioning, API compatibility, and resource management. Key topics include font scaling, icon configuration, multi-app modes, and environment variables. The resources provide detailed attribute tables, JSON structure definitions, and practical code examples. Suitable for HarmonyOS application developers and system engineers using DevEco Studio, these guides assist in correctly setting up application manifests, packaging constraints, and deployment configurations to ensure proper system integration and responsive design.

## Detailed Description

### configuration标签.md configuration标签.md
This reference document explains how to use the configuration tag within profile files to manage application font size scaling relative to system settings. It covers the file location in AppScope, JSON structure, and a detailed attribute table defining fontSizeScale and fontSizeMaxScale. Key takeaways include the ability to set font scaling to follow or ignore the system, and capping the maximum scaling ratio to prevent layout issues, with specific default values provided. Intended for application developers, this guide requires knowledge of JSON and app resource management to implement responsive text sizing effectively.

### icon标签_3more.md icon标签_3more.md
This technical reference guide details the configuration of specific application tags within a project's JSON file. It covers the icon tag for layered image resources, the appEnvironments tag for custom runtime variables, and the multiAppMode tag for application multi-opening capabilities. Key information includes instructions for referencing foreground and background resources, defining environment variable names and values, and specifying multi-instance or app clone types with maximum counts. Intended for developers configuring application manifests, this document provides attribute tables and JSON code samples to facilitate proper setup.

This document serves as a reference guide providing a comprehensive example of the app.json5 configuration file structure to help developers understand its schema. Key information includes API compatibility settings, debugging flags, and advanced configurations such as multi-app mode, environment variables, and asset access groups. The example illustrates how to define specific system capabilities and constraints. Intended for HarmonyOS application developers, this document assumes familiarity with JSON5 syntax and app configuration concepts, serving as a practical template for setting up application manifests.
