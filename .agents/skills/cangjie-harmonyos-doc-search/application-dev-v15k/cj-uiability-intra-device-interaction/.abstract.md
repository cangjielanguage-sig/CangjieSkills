This directory serves as a vital technical resource for HarmonyOS developers utilizing the Cangjie programming language, focusing specifically on the mechanisms of intra-device interaction via UIAbility components. It provides a deep dive into the architectural patterns required to start UIAbility components within the same application, a core capability for building responsive and modular apps. The guide covers essential navigation logic, including standard startup procedures, launching specific pages directly, and retrieving execution results from called components. Key topics include the AbilityKit framework, Want object configuration for parameter passing, and lifecycle management—specifically handling `onCreate` and `onNewWant` events. It also details inter-component data exchange strategies. This resource is ideal for Cangjie developers managing internal application flow, handling cold and hot starts, and implementing state management in multi-module projects.
