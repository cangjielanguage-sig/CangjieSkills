# 资源目录

This directory provides comprehensive technical documentation for organizing and managing application resource directories, primarily focusing on HarmonyOS development environments. It covers the fundamental architecture of resource files, including the default base directory and the complex system of qualifier directories used for localization and device adaptation. Key topics include resource compilation processes, strict naming conventions for qualifiers, and the handling of uncompiled assets. This guide is essential for software developers and engineers aiming to optimize application performance across different devices, languages, and screen configurations by adhering to standardized resource management practices.

## Detailed Description

### 资源目录_1.md 资源目录_1.md
This document serves as a technical reference guide for organizing application resource directories, specifically detailing the structure of the default base directory and qualifier directories used for localization and device adaptation. It explains that resources are compiled into binary files referenced by type and name. Key sections cover the naming requirements for qualifier directories, including the specific combination order of dimensions like language, screen density, and device type, as well as the rules for connecting these qualifiers using underscores or hyphens. The document targets developers who need to manage resources for diverse scenarios, ensuring proper file matching through strict adherence to naming conventions.

### 资源目录_2.md 资源目录_2.md
This reference document defines resource qualifier types and explains the usage of specific raw resource directories for application development. It details a comprehensive table of qualifiers, including mobile country and network codes, language, script, region, screen orientation, device type, color mode, and screen density, referencing international standards like ISO and ITU-T. Additionally, it distinguishes between the "rawfile" and "resfile" directories, noting that both store uncompiled files without resource IDs, but "resfile" resources are extracted to the application sandbox path. This guide targets software developers managing resource matching and non-compiled assets in HarmonyOS applications.
