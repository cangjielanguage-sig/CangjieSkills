This directory contains API reference documentation for core data structures in the Cangjie programming language. It covers fundamental types such as Arrays, Strings, Ranges, Durations, and Hashers, alongside specialized structures for C interoperability and low-level memory management. The documentation details struct definitions, properties, methods, and operator overloads, providing essential guidance for both high-level application development and system-level programming. It is suitable for Cangjie developers seeking to understand type behaviors, implement custom algorithms, or perform Foreign Function Interface (FFI) operations with C code.
