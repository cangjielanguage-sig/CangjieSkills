This directory contains API reference documentation for the `GeoLocationManager` class in the Cangjie programming language, part of the LocationKit for HarmonyOS. It covers a comprehensive range of location-based services including geocoding, GNSS data management, continuous location tracking, and event subscription mechanisms. The documentation details static functions for retrieving current locations, converting coordinates to addresses, and managing location service status changes. It includes essential information on required permissions like `ohos.permission.APPROXIMATELY_LOCATION`, system capabilities, and error handling. This resource is suitable for Cangjie developers building location-aware applications who need precise technical specifications and implementation examples.
