# 使用Web组件加载页面

本目录主要介绍在HarmonyOS应用开发中如何利用Web组件加载不同类型的页面内容。涵盖了加载网络页面、加载HTML文本数据以及加载本地页面的多种技术方案。核心知识点包括Web组件配置、WebviewController的使用、网络权限配置、data URL格式应用以及本地文件路径处理（rawfile和沙箱路径）。文档提供了基于仓颉（Cangjie）和ArkTS语言的代码示例，适合需要实现Web内容展示、页面动态跳转或本地HTML渲染的HarmonyOS开发者阅读。

## 详细说明

### 使用Web组件加载页面_2more_49d28dce.md 使用Web组件加载页面_2more_49d28dce.md
本文档旨在指导开发者如何在ArkUI中使用Web组件加载页面，重点介绍加载网络页面的实现方法。文档涵盖了网络权限配置、src参数的静态特性限制以及使用WebviewController的loadUrl接口进行动态页面跳转的技术细节。通过Cangjie语言代码示例，展示了从默认页面加载到通过按钮交互切换URL的完整流程。该指南适合具备ArkUI和Cangjie基础的开发者阅读，关键词包括Web组件、loadUrl、网络权限及页面动态加载。

### 加载HTML格式的文本数据_9d1dc23b.md 加载HTML格式的文本数据_9d1dc23b.md
本文档演示如何在仓颉语言中利用data URL直接加载HTML字符串数据。主要涵盖Web组件的配置、WebviewController的使用以及data URL格式的构建。关键信息在于通过在字符串前添加data:text/html前缀，将HTML内容作为数据源传递给Web组件的src属性，从而实现无需网络请求的本地HTML渲染。文档面向使用仓颉语言进行HarmonyOS应用开发的开发者，适用于需要动态加载或展示HTML片段的场景。

### 加载本地页面/
本目录主要介绍在 HarmonyOS 应用开发中加载本地页面的不同技术方案。内容涵盖了通过 Web 组件加载本地 HTML 文件（支持 rawfile 和沙箱路径两种方式）以及通过生命周期回调加载应用初始页面的方法。文档涉及 Cangjie 和 ArkTS 两种语言环境，包含代码示例、权限配置及路径获取等关键知识点。适用于需要实现本地 Web 页面展示或应用启动页面加载逻辑的 HarmonyOS 开发者。
