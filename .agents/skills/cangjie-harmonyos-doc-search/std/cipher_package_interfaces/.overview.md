# cipher_package_interfaces

This directory provides essential API reference documentation for the `cipher_package_interfaces`, specifically centering on the `BlockCipher` interface. It acts as the definitive guide for the standard contract governing block encryption and decryption algorithms within the cipher package. The content thoroughly details interface properties, including `algorithm` for name retrieval and `blockSize` for block length, alongside comprehensive method overloads for `encrypt` and `decrypt`. Crucially, the documentation highlights dual implementation modes for cryptographic operations: a standard mode returning a new byte array and a performance-oriented mode writing to pre-allocated output arrays to optimize memory usage. This resource is tailored for developers responsible for implementing or utilizing cryptographic primitives, requiring a solid grasp of the Cangjie language syntax and basic cryptography concepts to effectively leverage the interface specifications and ensure secure, efficient code execution.
