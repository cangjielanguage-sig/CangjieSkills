This directory serves as a comprehensive technical reference for configuration file tags utilized in application development, with a specific focus on the HarmonyOS environment and `app.json5` files. It encompasses a wide range of topics, including basic tag definitions, bundle identification, versioning control, API compatibility, and advanced system integration features. The documents provide structured tables and detailed attribute descriptions to assist developers in correctly implementing app properties. This resource is primarily designed for application developers and DevEco Studio users who require precise configuration management for debugging, building, and deploying applications across different API versions. It ensures proper app identity, runtime settings, and build process optimization.
