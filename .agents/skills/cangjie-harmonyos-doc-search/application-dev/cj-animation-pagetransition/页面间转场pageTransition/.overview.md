### class_CommonTransition.md class_CommonTransition.md
This API reference document details the CommonTransition class in the Cangjie language, designed to configure general page transition animations within the ArkUI framework. The documentation covers the class definition and four primary methods: slide, translate, scale, and opacity. Key information includes parameters for setting slide effects, 3D translation distances, scaling factors with adjustable center points, and opacity levels for entry and exit transitions. All functions return This to support method chaining. This guide targets ArkUI developers using Cangjie who need to implement custom visual effects during page navigation. Keywords: ArkUI, Cangjie, CommonTransition, animation, slide, translate, scale, opacity.

### class_PageTransitionEnter_2more.md class_PageTransitionEnter_2more.md

It details the PageTransitionEnter and PageTransitionExit classes, both inheriting from CommonTransition, which manage entry and exit animations respectively. Intended for application developers, this reference enables the creation of sophisticated navigation effects within ArkUI interfaces.

Key information explains how these types influence PageTransitionEnter and PageTransitionExit component styles during navigation scenarios like moving to a new page or returning to a previous one. Intended for developers using Cangjie, this guide helps manage page redirection and visual transition effects effectively.
