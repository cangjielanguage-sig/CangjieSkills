# cj-actions-entities

This directory functions as a specialized technical resource for HarmonyOS developers, providing detailed documentation on common actions and entities utilized in implicit Want calls. It thoroughly covers the definitions and implementation details of specific action constants, such as `ACTION_VIEW_DATA` and `ACTION_HOME`, alongside entities like `ENTITY_BROWSABLE` which are used for filtering application categories. Beyond mere definitions, the document highlights critical security concerns, explicitly advising against the continued use of these implicit mechanisms due to potential hijacking risks. It outlines the system's future plans to deprecate these non-essential constants, urging developers to adopt specific type-based application launching methods for better security and stability. This content is highly suitable for HarmonyOS developers involved in configuring module skills, managing implicit intents, or seeking to modernize their application launching logic to align with evolving security standards and deprecation schedules. It is an essential read for maintaining app security.
