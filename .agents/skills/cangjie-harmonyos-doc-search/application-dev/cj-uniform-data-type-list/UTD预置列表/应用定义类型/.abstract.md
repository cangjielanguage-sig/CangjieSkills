This directory contains technical reference documentation defining Application Defined Types (ADT) within a system architecture. It outlines how custom data types are maintained using UTD-IDs and provides extensive mapping tables for file extensions and MIME types across various software ecosystems. The content covers a wide range of formats, including Microsoft Office, OpenDocument, Adobe products, AutoCAD, and multimedia files. It is intended for developers, system integrators, and administrators who need to configure file associations, implement MIME type detection, or ensure interoperability with specific applications.
