This directory contains comprehensive API documentation for the `Channel` class within the Cangjie language, specifically designed to facilitate communication channels for Secure Element (SE) sessions. It provides detailed technical specifications for the class definition, including member functions for session management, channel status checks, and resource cleanup. Additionally, it covers the critical `transmit` function for sending ISO/IEC 7816 compliant APDU commands. The documentation includes essential information on system capabilities, return types, and robust exception handling for various error codes. This resource is intended for developers implementing secure element functionality who require a deep understanding of session management, applet selection, and low-level communication protocols.
