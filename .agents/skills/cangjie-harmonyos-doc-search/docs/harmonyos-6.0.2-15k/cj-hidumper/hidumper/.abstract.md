This directory hosts documentation for HiDumper, a unified command-line tool essential for acquiring system information, debugging, and analyzing problems within HarmonyOS environments. It provides comprehensive coverage of system diagnostics, including inspecting system abilities, monitoring performance metrics like CPU and memory usage, and debugging specific services such as WindowManager and RenderService. Additionally, it addresses advanced features like JavaScript heap analysis, garbage collection, and Inter-Process Communication (IPC) statistics. This resource is specifically designed for system developers, QA engineers, and administrators who require deep system introspection to diagnose crashes or optimize resource usage effectively.
