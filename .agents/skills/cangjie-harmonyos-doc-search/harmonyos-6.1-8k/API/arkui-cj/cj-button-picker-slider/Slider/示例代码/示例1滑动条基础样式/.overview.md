# 示例1滑动条基础样式

本目录展示了如何在ArkUI框架中使用仓颉语言配置和自定义滑动条的基础样式。内容涵盖了OutSet（外置）、InSet（内置）以及垂直方向滑动条的实现，重点演示了气泡、刻度、滑块和滑轨的显示控制。通过style、showTips、blockColor等属性，开发者可以调整交互效果和颜色，并利用onChange回调实现状态双向绑定。该文档适合具备ArkUI基础和仓颉语法知识的开发者，用于学习UI组件的属性配置与状态管理。

## 详细描述

### 示例1滑动条基础样式_1.md
本文档旨在演示如何使用仓颉语言在ArkUI框架中配置和自定义滑动条的基础样式。主要涵盖了OutSet（外置）、InSet（内置）以及垂直方向滑动条的实现，重点展示了如何通过属性控制气泡、刻度、滑块和滑轨的显示。关键信息包括利用style、showTips、showSteps属性调整交互效果，使用blockColor、trackColor等自定义颜色，以及通过onChange回调实现状态双向绑定。这是一个代码示例文档，适用于具备ArkUI基础和仓颉语法知识的开发者，用于学习UI组件的属性配置与状态管理。

### 示例1滑动条基础样式_2.md
本文档旨在演示如何在ArkUI中实现垂直内嵌式滑动条的基础样式与配置。主要涵盖了Slider组件的垂直方向设置、方向反转、步长显示及提示功能的实现。关键信息包括通过设置direction为Axis.Vertical和reverse为true来实现从下往上的滑动逻辑，以及如何利用onChange回调处理数值变化。该文档属于代码示例教程，适合具备ArkTS基础的开发者参考，用于构建自定义交互界面。
