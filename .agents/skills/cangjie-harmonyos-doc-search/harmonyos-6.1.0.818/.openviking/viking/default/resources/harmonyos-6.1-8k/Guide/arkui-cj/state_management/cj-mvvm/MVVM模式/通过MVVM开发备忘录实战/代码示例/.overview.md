# 代码示例

本目录汇集了使用仓颉语言和ArkUI框架开发待办事项应用的代码示例。核心内容聚焦于MVVM架构模式的应用，详细展示了如何通过ViewModel解耦业务逻辑与UI逻辑。文档深入讲解了@Observed、@Publish、@State和@Link等关键装饰器在状态管理和数据绑定中的具体用法。这些资料适合具备仓颉语言基础并致力于HarmonyOS应用开发的开发者，旨在帮助他们构建结构清晰、可维护性强的响应式用户界面。

## 详细描述
### 代码示例_1.md
该文档演示了如何使用Cangjie语言和MVVM模式重构待办事项应用。涵盖了项目目录结构，并提供了模型层、视图层以及它们通过ViewModel交互的代码实现。关键点包括使用@Observed、@Publish、@State和@Link等装饰器进行状态管理和数据绑定，展示了如何解耦UI逻辑和业务逻辑。目标受众是熟悉Cangjie和ArkUI的开发者，作为实现结构化响应式UI的实用教程或参考。

### 代码示例_2.md
本文档通过代码示例展示了如何使用仓颉语言和ArkUI框架基于MVVM架构模式构建待办事项应用。文档涵盖了ThingComponent和TodoListComponent等UI组件，以及ThingViewModel和TodoListViewModel等视图模型。关键信息包括利用@Observed、@Publish和@Link装饰器进行状态管理和响应式数据绑定，实现了业务逻辑与界面的清晰分离。该示例强调了模块化设计带来的代码复用性和可维护性优势。本文档面向使用仓颉进行HarmonyOS开发的开发者，旨在帮助他们掌握MVVM模式的应用及最佳实践。
