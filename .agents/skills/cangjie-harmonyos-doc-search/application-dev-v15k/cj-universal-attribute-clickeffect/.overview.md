# cj-universal-attribute-clickeffect

This directory serves as the central repository for documentation regarding the `cj-universal-attribute-clickeffect` module, a specific extension within the Cangjie ArkUI framework. It provides a comprehensive guide for developers aiming to implement click rebound animations, a critical feature for enhancing the responsiveness and tactile feel of user interfaces in HarmonyOS applications. The content covers the technical specifications of the `clickEffect` function, including its signature, system capabilities, and configuration parameters such as the `level` enum (LIGHT, MIDDLE, HEAVY) and the `scale` parameter. By defining default shrinkage ratios and offering practical code examples, this documentation assists Cangjie developers in creating polished, interactive experiences for components like Radio buttons. Whether you are building a new application or refining an existing one, this resource offers the necessary technical details to ensure your UI elements react dynamically to user input, thereby improving overall user satisfaction and engagement. This documentation is a must-read for anyone looking to master universal attributes in Cangjie.
