This directory contains API reference documentation for the Cangjie class `JSHashMapEx`, designed to facilitate declarative interoperability with ArkTS Map types within the ArkUI framework. It covers class definitions, generic constraints, constructors, and a comprehensive set of instance and static methods for data manipulation, including insertion, deletion, retrieval, and type conversion. Key topics include lambda-based operations, Option-based retrieval, and operator overloading. This documentation is suitable for developers implementing cross-language features who require knowledge of Cangjie syntax, ArkTS type systems, and Napi capabilities starting from version 12.
