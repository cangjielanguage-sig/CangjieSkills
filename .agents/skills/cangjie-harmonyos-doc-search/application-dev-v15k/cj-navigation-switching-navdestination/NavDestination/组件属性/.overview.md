# 组件属性

This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It focuses on navigation and layout customization, including setting back button icons, managing page menus, controlling system bar styles, and configuring navigation titles. Key topics cover layout extension into non-safe areas, menu display limits, and title bar customization. This documentation is suitable for application developers and software engineers working with Cangjie syntax and ArkUI component structures who need to fine-tune the visual and functional behavior of navigation interfaces.

## Detailed Description

### func_backButtonIconAppReso_5more.md func_backButtonIconAppReso_5more.md
This document provides API reference documentation for Cangjie language functions used in configuring navigation and layout behaviors within the ArkUI framework. Main topics include setting the back button icon via AppResource or PixelMap, defining page menus with specific display limits for portrait and landscape modes, and controlling layout extension into non-safe areas. Key information details the menus function's limit of 3 icons vertically and 5 horizontally, with overflow handled automatically. The ignoreLayoutSafeArea function allows extending components into system bars but warns of potential event interception by system components. Intended for developers using ArkUI, this reference requires knowledge of Cangjie syntax and UI component structures.

### func_systemBarStyleResourceColor.md func_systemBarStyleResourceColor.md
This API documentation describes the `systemBarStyle` function used to configure the system status bar style within a Navigation component in the Cangjie ArkUI framework. The document covers the function signature, system capabilities, version requirements, and a detailed parameter table for the `style` argument. Key information highlights that the function accepts a required `ResourceColor` parameter and returns `This`, but crucially, it must be used as the root node of a Navigation destination page to function correctly. Intended for application developers using Cangjie, this reference guide provides the necessary constraints and parameters for customizing system bar appearances in Navigation-based applications.
