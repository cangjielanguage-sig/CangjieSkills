# extend_Rune

This directory contains API reference documentation for extending the `Rune` type in the Cangjie programming language. It focuses on low-level character manipulation, specifically covering UTF-8 encoding and decoding operations, ASCII character classification, and case conversion utilities. Key topics include converting byte arrays to characters, locating character boundaries, and validating character types using specific hexadecimal ranges. This documentation is suitable for Cangjie developers working on text processing engines, internationalization support, or any application requiring precise byte-level character operations and validation.

## Detailed Description

### extend_Rune_4more.md extend_Rune_4more.md
This document serves as API reference documentation for extending the Rune type in the Cangjie programming language, focusing on UTF-8 encoding and decoding operations. It details three primary static functions: fromUtf8, which converts byte arrays to characters; getPreviousFromUtf8, which locates character boundaries by searching backwards; and intoUtf8Array, which encodes characters into byte arrays. Key information includes function parameters, return values containing character data and byte lengths, and exception handling for invalid UTF-8 sequences. This guide targets developers requiring low-level character manipulation and byte-level text processing.

### func_isAsciiOct_6more.md func_isAsciiOct_6more.md
This document serves as API reference documentation for the Cangjie programming language, detailing six utility functions for ASCII character classification and case conversion. The main sections cover four predicate functions—isAsciiOct, isAsciiPunctuation, isAsciiUpperCase, and isAsciiWhiteSpace—alongside two transformation functions, toAsciiLowerCase and toAsciiUpperCase. Key information includes specific hexadecimal ranges for punctuation and whitespace checks, return types of Bool for checks and Rune for conversions, and behavior where non-convertible characters remain unchanged. This reference is intended for Cangjie developers needing to validate or manipulate ASCII character data within their applications.

This API reference document details utility functions for the Cangjie Rune type, focusing on UTF-8 size calculation and ASCII character classification. This documentation serves Cangjie developers who need to validate encoding, calculate byte lengths, or perform character type checks in their applications.
