# 接口介绍

This directory contains technical documentation for the AssetStoreKit API, focusing on the management and querying of key assets. It covers the `query` function interface, attribute parameter definitions for access control and persistence, and detailed query options for pagination and sorting. Key topics include data security constraints (specifically regarding unencrypted custom fields), API versioning updates (API 12), and storage classifications. This documentation is intended for developers and system integrators who need to implement secure asset storage, synchronization, and retrieval functionalities within their applications.

## Detailed Description

### 接口介绍_1.md 接口介绍_1.md
This document serves as a reference guide for the API interface used to query and synchronize new key assets. It primarily covers the `query` function, which accepts an array of `AssetParam` objects, and details the specific parameters required for the query. A critical security warning is provided regarding attributes named "DATA_LABEL," emphasizing that these fields store unencrypted custom business information and must not contain personal data. This documentation is intended for developers integrating asset management features who need to understand parameter structures and data security constraints. Keywords: API reference, key assets, query interface, AssetParam, data encryption, security warning.

### 接口介绍_2.md 接口介绍_2.md
This document serves as a reference guide defining the attribute parameters for managing critical assets within the AssetStoreKit API. It details configuration options for access control, authentication types, synchronization, and persistence, alongside various data label fields for storing custom information with or without integrity protection. Key takeaways include specific data type constraints, byte length limits updated for API 12, and the distinction between critical, normal, and local-only data storage. Intended for developers implementing secure asset storage, this reference requires understanding of data structures and API versioning.

### 接口介绍_3.md 接口介绍_3.md
This document provides API reference details for query parameters within the AssetStoreKit interface. It outlines optional parameters such as RETURN_TYPE, RETURN_LIMIT, and RETURN_OFFSET for controlling result sets, alongside RETURN_ORDERED_BY for sorting and REQUIRE_ATTR_ENCRYPTED for filtering encrypted data. Key information includes specific data types (UInt32, Bool), value ranges for pagination, and default behaviors for result ordering. This technical reference is designed for developers implementing asset queries who need to manage data retrieval, pagination, and security filtering. Keywords: API reference, AssetStoreKit, query parameters, pagination, data encryption.
