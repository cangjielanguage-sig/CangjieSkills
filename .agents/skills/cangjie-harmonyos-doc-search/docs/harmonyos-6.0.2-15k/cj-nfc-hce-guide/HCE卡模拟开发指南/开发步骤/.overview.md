# 开发步骤

This directory contains essential technical documentation for implementing Host Card Emulation (HCE) functionality within HarmonyOS applications using the Cangjie programming language. It provides a comprehensive walkthrough of the development steps required to simulate smart cards for contactless interactions, such as payments or secure access. The content covers the entire implementation spectrum, starting with configuration in `module.json5` for permissions and actions, importing necessary modules, and checking device capabilities for NFC and HCE support. It details how to manage the HCE service lifecycle, specifically distinguishing between foreground execution—where priority is managed via `EntryAbility`—and background execution. Key technical processes include subscribing to APDU commands, processing data through callbacks, and transmitting appropriate responses. These guides are tailored for HarmonyOS developers who have a working knowledge of Cangjie and understand NFC protocols, enabling them to build robust, contactless transaction applications.

## Detailed Description

### HCE应用前台刷卡.md HCE应用前台刷卡.md

This document provides a technical tutorial for implementing Host Card Emulation (HCE) functionality in the foreground of a HarmonyOS application using the Cangjie language. It covers configuration in module.json5 for permissions and actions, importing necessary modules, checking device capabilities, and managing the HCE service lifecycle within the EntryAbility class. Key steps include enabling foreground priority via hceService.start, subscribing to and processing APDU commands through callbacks, and transmitting responses. It emphasizes stopping the service when the application goes to the background to release resources. Targeted at HarmonyOS developers with knowledge of Cangjie and NFC concepts, this guide facilitates the creation of applications that simulate smart cards for contactless transactions.

### HCE应用后台刷卡.md HCE应用后台刷卡.md

This document provides a step-by-step tutorial for implementing Host Card Emulation (HCE) functionality in an application using the Cangjie language. It covers configuration in module.json5, including declaring NFC permissions, HCE actions, and specific Application IDs (AIDs). The guide explains importing necessary modules, checking device capabilities for NFC and HCE, and subscribing to APDU data events. Key takeaways include handling incoming APDU commands via callbacks, transmitting responses, and managing the service lifecycle by unsubscribing upon application exit. This technical guide is intended for HarmonyOS developers with prerequisite knowledge of Cangjie programming and NFC protocols.
