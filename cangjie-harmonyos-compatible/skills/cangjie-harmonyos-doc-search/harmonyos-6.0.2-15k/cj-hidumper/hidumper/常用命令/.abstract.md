This directory contains a comprehensive collection of command references for the `hidumper` tool in HarmonyOS. It covers essential system diagnostics, including inspecting system abilities, monitoring performance metrics like CPU and memory, and debugging specific services such as WindowManager and RenderService. The documentation also details advanced features like JavaScript heap analysis, garbage collection, and Inter-Process Communication (IPC) statistics. These guides are designed for system developers, QA engineers, and administrators who need to perform deep system introspection, diagnose crashes, or optimize resource usage on HarmonyOS devices.
