This directory contains technical documentation for the `abilities` tag used in HarmonyOS and OpenHarmony application configuration. It covers the definition and configuration of UIAbility components, including attributes for lifecycle management, window display modes, background tasks, and cross-device migration. The content details data types, default values, and constraints for various properties like startup modes, permissions, and process isolation. It is suitable for application developers and system engineers who need to configure application manifests to control component behavior, user interface presentation, and system interactions.
