## Detailed Description

### class_JSArray.md class_JSArray.md
这份文档是Cangjie语言中JSArray类的API参考，旨在指导开发者如何安全地引用和操作ArkTS数组。主要内容包括类定义、只读属性size、以及重载的下标操作符[]，分别用于读取元素和写入不同类型的值（JSValue或JSHeapObject）。文档详细列出了参数类型、返回值及可能抛出的BusinessException异常（如索引越界、引用不可达或线程不匹配），并提供了代码示例。适用于进行ArkTS互操作开发的Cangjie程序员，需具备基础API调用知识。

### class_JSBigInt_2more_608e354a.md class_JSBigInt_2more_608e354a.md
这是一份仓颉语言的API参考文档，旨在规范ArkTS与仓颉互操作中的JSBigInt和JSBoolean数据类型封装。文档涵盖了JSBigInt类的toBigInt转换方法，以及JSBoolean类的toBool和toJSValue转换方法。关键信息包括类型转换逻辑、返回值类型、BusinessException异常处理（如错误码34300003和34300004）及具体代码示例。该文档面向HarmonyOS开发者，帮助其在仓颉侧安全地操作和转换ArkTS的基础数据类型。

### class_JSCallInfo.md class_JSCallInfo.md
这份文档是Cangjie语言中JSCallInfo类的API参考，用于描述ArkTS函数调用的相关信息。主要内容包括类的功能定义、生命周期说明，以及count属性（参数数量）、thisArg属性（this指针）和下标操作符（按索引获取参数）的详细用法。文档强调了该对象仅在调用期间有效，并列举了可能抛出的BusinessException错误码。该文档面向进行Cangjie与ArkTS互操作的开发者，旨在帮助他们安全地访问跨语言调用的参数和上下文。

### class_JSExternal.md class_JSExternal.md
本文档提供了仓颉语言中 `JSExternal` 类的 API 参考，旨在实现将仓颉对象引用传递至 ArkTS 运行时以进行互操作。文档涵盖了类定义、继承关系（继承自 `JSHeapObject`）、核心方法 `cast()` 和 `getData()` 的详细说明，以及相关的异常错误码和代码示例。`JSExternal` 持有 `SharedObject` 的强引用，`cast` 方法支持类型安全转换并返回 `Option`，`getData` 则直接获取对象，两者均可能抛出如线程不匹配或越界访问等业务异常。该文档面向需要进行仓颉与 ArkTS 混合编程的开发者，帮助他们掌握如何在跨语言调用中传递和访问自定义对象。

### class_JSFunction.md class_JSFunction.md
本文档是Cangjie语言中JSFunction类的API参考文档，旨在说明如何安全引用和调用ArkTS函数。文档涵盖了类定义及其继承自JSHeapObject的关系，重点介绍了三个重载的call方法，分别支持无参、单参及数组参数的函数调用。关键内容包括参数thisArg的配置、JSValue类型的返回值，以及处理外部错误和线程不匹配的BusinessException异常。该文档面向进行ArkTS互操作开发的程序员，要求读者熟悉JSContext和JSValue的使用，以便正确实现跨语言函数调用。
