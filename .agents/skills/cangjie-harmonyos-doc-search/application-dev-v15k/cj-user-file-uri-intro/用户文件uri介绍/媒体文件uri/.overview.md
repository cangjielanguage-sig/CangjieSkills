# 媒体文件uri

This directory serves as a technical reference for managing media file Uniform Resource Identifiers (URIs) in HarmonyOS development. It defines standard URI formats for images, videos, and audio, explaining syntax and field components like media type indicators and database IDs. The content covers retrieval methods via the PhotoAccessHelper module, including interfaces like PhotoViewPicker and getAssets. Additionally, it addresses usage scenarios, permission protocols, and metadata access. This guide is suitable for developers seeking to integrate media libraries, understand file path structures, and implement privacy-compliant media access in their applications.
