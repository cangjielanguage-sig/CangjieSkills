# cj-data-reliability-security-overview

This directory provides a comprehensive technical overview of HarmonyOS data reliability and security features, focusing on the mechanisms designed to protect application data integrity and privacy. It covers essential topics such as database backup and recovery, whole-file encryption using the Hardware Unique Key Storage (HUKS), and data classification for cross-device access control. The guide also details E-class encrypted databases, which significantly enhance security by destroying keys upon screen lock. Suitable for HarmonyOS application developers, this resource is crucial for those seeking to implement robust data persistence and security measures for sensitive information like financial data and user credentials. It serves as a conceptual guide for understanding the operational mechanisms and constraints of the system's security architecture.

## Detailed Description

### cj-data-reliability-security-overview.md cj-data-reliability-security-overview.md
This document outlines HarmonyOS data reliability and security features, including backup, recovery, encryption, and classification mechanisms to protect application data. Key sections cover functional scenarios, basic concepts, operational mechanisms, and constraints. Topics include database backup and recovery, whole-file encryption using HUKS, data classification for cross-device access control, and E-class encrypted databases. Developers can perform backups without closing databases, while the system handles encryption keys automatically via HUKS. E-class databases enhance security by destroying keys upon screen lock. Constraints include a maximum of five backups for key-value databases and annual automatic key rotation. This conceptual guide targets HarmonyOS application developers seeking to implement data persistence and security measures for sensitive information like financial data or credentials.
