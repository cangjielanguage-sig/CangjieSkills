This directory contains the essential API reference documentation for the `ref_package_enums` module, a specific component of the Cangjie language standard library dedicated to memory management utilities. The primary focus of this directory is the `CleanupPolicy` enum, which defines the garbage collection strategies applicable to weak references. The documentation provides a deep dive into the enum's structure, its two distinct policy variants—`EAGER` and `DEFERRED`—and the associated overloaded equality operators. It explains how the `EAGER` policy facilitates immediate object reclamation by the Garbage Collector (GC), whereas the `DEFERRED` policy preserves objects until memory pressure becomes critical. Furthermore, it details the enum's inheritance from the `Equatable` interface and its integration with the `WeakRef` class. This resource is indispensable for Cangjie developers, software engineers, and systems architects who are actively involved in building robust applications requiring fine-grained control over object lifecycles and memory efficiency.
