# cj-test-kit-overview

本目录包含仓颉语言Test Kit自动化测试框架的概述文档，旨在为开发者提供全面的单元测试与UI测试解决方案。文档详细介绍了单元测试的核心能力，包括用例定义、断言接口、预置清理动作及多种执行模式；同时也涵盖了UI测试的关键功能，如控件查找、UI及窗口操作模拟、Shell命令模拟及弹框监听。该文档重点强调了框架对自动化脚本编写的支持以及测试结果的便捷查看，适合仓颉语言开发者阅读，用于指导其进行功能验证和自动化测试流程的搭建。
