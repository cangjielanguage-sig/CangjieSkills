# 关闭特定域名页面的广告过滤

This directory provides comprehensive technical guidance on managing ad filtering behaviors for specific domains within Web components. It focuses on the mechanisms to selectively disable ad blocking for certain websites while maintaining it for others, utilizing the `AdsBlockManager`. Key technical concepts include the implementation of allowlists and disallowlists, domain suffix matching logic, and the priority hierarchy where AllowList overrides DisallowedList. The documentation includes practical code examples in both Cangjie and ArkTS, illustrating how to handle exceptions like blocking a parent domain but allowing specific subdomains. This resource is specifically designed for developers working with ArkWeb components who require granular, programmatic control over ad blocking configurations in their applications.

## Detailed Description

### 关闭特定域名页面的广告过滤_1.md
This technical guide explains how to selectively disable ad filtering for specific domains in a Web component using the AdsBlockManager. It covers the implementation of the addAdsBlockDisallowedList interface and the logic of domain suffix matching. Key information includes the interaction between DisallowedList and AllowList, where AllowList takes higher priority to re-enable filtering for specific subdomains. The document provides Cangjie code examples demonstrating how to configure these lists to manage exceptions, such as blocking a parent domain while allowing specific subdomains. This guide is intended for developers using ArkWeb components who require granular control over ad blocking behavior.

### 关闭特定域名页面的广告过滤_2.md
This document provides a code example demonstrating how to configure ad filtering allowlists and disallowlists for specific domains within a Web component using ArkTS. It covers the usage of AdsBlockManager methods to block ads on a main domain while permitting them on specific subdomains. Key takeaways include the requirement to call enableAdsBlock(true) for these settings to take effect and the fact that the domain lists are not persistent and reset upon application restart. This guide is intended for developers seeking to implement granular ad control in their web applications.
