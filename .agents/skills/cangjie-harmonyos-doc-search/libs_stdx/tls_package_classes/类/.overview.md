## Detailed Description

### class_TlsSessionContext.md class_TlsSessionContext.md

This API reference document details the TlsSessionContext class in the Cangjie language, designed to manage TLS session contexts for secure connection resumption and server identity verification. The documentation covers the class definition, the static factory method fromName, string conversion via toString, and equality comparison operators. Key information includes that the class ensures clients reconnect to the legitimate server instance and that while contexts are created using a distinguishing name, instances with identical names are not guaranteed to be equal. Consequently, server instances should reuse a single TlsSessionContext object. This guide targets developers implementing secure network protocols using the Cangjie standard library.

### class_TlsSocket/

This directory contains comprehensive API reference documentation for the `TlsSocket` class in the Cangjie programming language. It covers the implementation of secure, encrypted network communication using TLS protocols. The documentation details properties for connection inspection, methods for data transmission and comparison, configuration options for timeouts and sessions, and static factory methods for socket initialization. It is suitable for developers building secure network applications who need to manage TLS handshakes, handle encrypted data streams, and inspect connection metadata like certificates and cipher suites.
