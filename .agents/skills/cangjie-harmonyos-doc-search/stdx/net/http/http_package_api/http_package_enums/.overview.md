# http_package_enums

本目录是仓颉（Cangjie）语言 HTTP 包中核心枚举类型的 API 参考文档。它详细定义了网络编程中处理文件传输、HTTP 协议协商以及 WebSocket 通信所需的基础数据结构。文档重点涵盖了 `FileHandlerType`（用于配置文件上传或下载模式）、`Protocol`（定义 HTTP 1.0/1.1/2.0 版本）以及 `WebSocketFrameType`（描述文本、二进制及控制帧）三个核心枚举。这些枚举均继承了 `Equatable` 和 `ToString` 接口，并实现了相等性运算符，为开发者提供了类型安全的配置选项。该文档适合具备 HTTP 和 WebSocket 协议基础的开发者查阅，旨在帮助其在仓颉开发环境中高效构建网络应用。

### http_package_enums.md http_package_enums.md

本文档是 HTTP 包的 API 参考文档，详细说明了文件处理、HTTP 协议及 WebSocket 帧相关的枚举定义。主要涵盖三个核心枚举：用于配置文件上传或下载模式的 `FileHandlerType`，定义 HTTP 版本（1.0/1.1/2.0）的 `Protocol`，以及描述 WebSocket 帧类型（如文本、二进制、控制帧）的 `WebSocketFrameType`。文档重点介绍了各枚举的变体、继承的 `Equatable` 与 `ToString` 接口，以及相等性运算符的实现。面向使用仓颉语言进行网络编程的开发者，需具备 HTTP 和 WebSocket 协议基础。
