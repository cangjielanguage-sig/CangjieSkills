# Navigation

This directory provides comprehensive documentation for the Navigation component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the core architecture of route navigation, including component lifecycle, constructor methods, event handling, and property configuration. Key topics include NavPathStack management, toolbar customization, title bar settings, and UI state transitions. This resource is suitable for HarmonyOS developers and UI engineers looking to build complex, multi-page application structures with dynamic navigation capabilities and precise control over interface layouts.

## Detailed Description

### Navigation_4more.md Navigation_4more.md
This document serves as API reference for the Navigation component within the ArkUI framework, detailing its role as a root view container for route navigation in Cangjie applications. It covers component descriptions, lifecycle notes, subcomponent capabilities, and four specific constructor methods for initialization with or without route stacks and child components. The component includes a title bar, content area, and toolbar, switching between home and non-home pages via NavPathStack. It supports most common attributes and events but excludes text styles. Targeted at developers using the Cangjie language to build complex page navigation structures.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling event callbacks within Navigation components using the Cangjie programming language. It details three specific functions: onTitleModeChange, onNavBarStateChange, and onNavigationModeChange. These functions allow developers to listen for and respond to UI state changes, such as title bar scrolling behavior, navigation bar visibility, and transitions between single or double-column layouts. All functions require a callback parameter and return the current instance. This guide targets HarmonyOS developers building dynamic user interfaces with ArkUI who need to manage navigation state changes programmatically.

This documentation is suitable for HarmonyOS developers and UI engineers who need to implement and customize navigation logic, page transitions, and interface layouts within their applications using Cangjie.

### 示例代码/
This directory contains practical code examples and tutorials designed for developers building HarmonyOS applications using the Cangjie language. It focuses specifically on the implementation and management of the Navigation component, a crucial element for mobile app architecture. The content covers two main areas: the structural configuration of navigation interfaces—including title bars, menus, and toolbars—and the programmatic management of page routing stacks. Key concepts include NavPathStack methods, page mapping, decorators like @Entry and @Component, and stack manipulation operations such as push, pop, and move. These examples are best suited for developers who already have a basic understanding of Cangjie and wish to master complex UI navigation and state management within the HarmonyOS ecosystem.

Developers will find detailed parameter definitions, constraints, and usage examples for functions that control navigation bars, safe areas, and visual effects. This documentation is suitable for UI developers and software engineers building complex navigation interfaces in Cangjie who need precise control over component behavior and layout constraints.
