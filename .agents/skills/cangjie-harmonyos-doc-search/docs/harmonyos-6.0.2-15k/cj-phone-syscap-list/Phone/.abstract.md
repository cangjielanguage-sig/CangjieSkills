This directory contains documentation regarding SystemCapability (SysCap) definitions and reference lists for the Phone device profile. It provides a comprehensive inventory of supported operating system features, ranging from AI components and multimedia frameworks to security protocols and telephony services. The content is designed to help software developers and system architects verify feature availability, ensure compatibility, and understand the hardware-software configuration before application development. Key topics include SysCap definitions, API namespaces, and specific subsystem capabilities like ArkUI, Distributed Data, and HiviewDFX.
