This directory contains API reference documentation for the `URL` class in the Cangjie programming language, specifically within the `stdx.encoding.url` package. It covers comprehensive URL parsing, manipulation, and component access, including scheme, host, path, and query handling. The documentation details methods for resolving relative URLs, merging paths, and validating URL structures based on RFC 3986 standards. It also addresses security considerations regarding plaintext credentials. This resource is suitable for Cangjie developers who need robust tools for handling network resources, performing string-to-URL conversions, or programmatically manipulating URL components.
