## 基础类型定义

### class ListItemOptions

```cangjie
public class ListItemOptions {
    public var style: ListItemStyle
    public init(style!: ListItemStyle = ListItemStyle.NONE)
}
```

**功能：** ListItem组件参数。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### var style

```cangjie
public var style: ListItemStyle
```

**功能：** 设置List组件卡片样式。

**类型：** [ListItemStyle](#enum-listitemstyle)

**读写能力：** 可读写

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### init(ListItemStyle)

```cangjie
public init(style!: ListItemStyle = ListItemStyle.NONE)
```

**功能：** 构造一个ListItemOptions类型的对象。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|style|[ListItemStyle](#enum-listitemstyle)|否|ListItemStyle.NONE| **命名参数。** 设置List组件卡片样式。<br/>初始值：ListItemOptions(style: ListItemStyle.NONE)<br/>style设置为ListItemStyle.NONE时无样式。<br/>style设置为ListItemStyle.CARD时，建议配合[ListItemGroup](cj-scroll-swipe-listgroup.md)的ListItemGroupStyle.CARD同时使用，显示默认卡片样式。  <br/>卡片样式下，ListItem初始规格：高度48.vp，宽度100.percent，左右内边距8.vp。<br/>卡片样式下， 为卡片内的列表选项提供了默认的focus、hover、press、selected和disable样式。<br/>**说明：**<br/>当前卡片模式下，使用默认Axis.Vertical排列方向，如果listDirection属性设置为Axis.Horizontal，会导致显示混乱。<br/>List属性alignListItem的初始值：ListItemAlign.Center，居中对齐显示。|
