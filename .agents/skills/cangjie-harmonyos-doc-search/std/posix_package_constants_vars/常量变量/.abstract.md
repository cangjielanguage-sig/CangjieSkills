This directory contains API reference documentation for a collection of deprecated POSIX constants within the Cangjie programming language. It covers integer constants used for low-level file system operations, including file opening flags, access modes, permission masks, and file type definitions. Additionally, it includes constants related to POSIX signal handling for process control. All entries are marked as deprecated and will be removed in future versions. This documentation is suitable for Cangjie developers maintaining legacy code or migrating applications away from these obsolete system-level definitions.
