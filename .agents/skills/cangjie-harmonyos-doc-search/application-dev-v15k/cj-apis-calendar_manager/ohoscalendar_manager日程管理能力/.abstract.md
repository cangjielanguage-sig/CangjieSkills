This directory provides comprehensive API reference documentation for the Cangjie programming language's CalendarKit module, focusing on schedule management capabilities within the SystemCapability.Applications.CalendarData framework. It covers essential data structures, enumerations, and classes required for creating, querying, and managing calendar events, accounts, and configurations. Key components include event filtering, location handling, recurrence rules, and permission management. Designed for application developers and software engineers, this documentation facilitates the integration of robust calendar functionalities into applications, requiring knowledge of Cangjie syntax and system capabilities starting from API version 20.
