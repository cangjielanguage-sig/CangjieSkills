This directory focuses on the configuration of application components and metadata within HarmonyOS and Cangjie development environments. It covers essential setup tasks such as defining application identities (bundle names), managing version information, and configuring visual elements like icons and labels. Key topics include `app.json5` and `module.json5` file settings, permission declarations, and device compatibility. This documentation is suitable for developers using DevEco Studio or working with Cangjie projects who need to establish the foundational attributes and capabilities of their applications.
