## 详细描述

### README_zh.md
该文档是ArkData（方舟数据管理）模块的仓颉语言API参考索引，旨在为开发者提供数据管理相关功能的文档导航。主要内容分为仓颉API和错误码两大部分。API部分涵盖数据共享谓词、分布式键值数据库、用户首选项、关系型数据库及数据集；错误码部分列出了关系型数据库、分布式键值数据库和用户首选项的异常代码。所有列出的功能目前均为Beta特性，文档提供了指向具体API接口和错误处理详情的链接，涉及数据存储、查询及分布式数据同步等核心概念。本文档面向使用仓颉语言开发HarmonyOS应用的开发者，作为查阅数据管理接口和排查错误的参考指南。
