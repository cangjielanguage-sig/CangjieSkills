# 富文本RichEditor

This directory provides a comprehensive guide for developing the RichEditor component within the ArkUI framework using the Cangjie language. It covers essential functionalities such as creating basic editors, managing mixed text and graphics, configuring custom selection menus, and handling complex event callbacks like IME interactions and paste interception. Designed for HarmonyOS application developers, these resources enable the creation of interactive text input areas, including comment sections and code editors, with advanced features like dynamic content management and custom user interactions.

### 富文本RichEditor_3more.md 富文本RichEditor_3more.md
This document serves as a development guide for implementing the RichEditor component in ArkUI using the Cangjie language, focusing on mixed text and graphics editing. It covers creating a basic RichEditor without attribute strings for simple displays and configuring custom selection menus using the bindSelectionMenu method. The guide provides Cangjie code examples demonstrating the use of RichEditorController for text manipulation and replacing default system menus with custom Menu components for actions like cut, copy, and paste. It targets application developers looking to implement interactive text input areas, such as comment sections or code editors, within the HarmonyOS ecosystem.

### 添加文本内容_2more.md 添加文本内容_2more.md
This technical guide explains how to programmatically add text and image content to the ArkUI RichEditor component using the Cangjie language. The document covers two primary methods: using addTextSpan to create mixed-style text and addImageSpan to insert visual elements like icons or charts. Key takeaways include the automatic cursor update behavior, which moves the caret to the right of the inserted content when the component is focused. The guide provides practical Cangjie code examples demonstrating implementation and styling options. It targets developers building rich text editing applications within the ArkUI framework.
