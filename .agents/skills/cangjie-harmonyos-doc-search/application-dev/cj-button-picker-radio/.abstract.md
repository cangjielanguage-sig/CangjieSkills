This directory contains the essential documentation for the `cj-button-picker-radio` component, a fundamental UI element designed for the ArkUI framework using the Cangjie language. It serves as a comprehensive guide for HarmonyOS developers who need to implement single-selection interfaces where users are required to choose one option from a mutually exclusive list. The documentation covers the complete lifecycle of the Radio component, starting with initialization which requires `value` and `group` parameters to effectively manage mutual exclusion. It details the `checked` attribute for state management and the `onChange` event for handling user inputs dynamically. By combining API references with practical code examples, this guide helps developers build robust, standard-compliant interfaces efficiently, ensuring a seamless user experience in HarmonyOS applications.
