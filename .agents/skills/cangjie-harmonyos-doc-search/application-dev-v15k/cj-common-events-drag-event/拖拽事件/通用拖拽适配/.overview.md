# 通用拖拽适配

This directory serves as a comprehensive technical resource for implementing universal drag-and-drop functionality within HarmonyOS applications. It addresses the specific challenges and methodologies for enabling drag capabilities across different programming languages and frameworks, specifically Cangjie and ArkTS. The content covers critical implementation details such as resolving gesture conflicts between system and custom interactions, customizing drag visuals using component snapshots and pixel maps, and managing data exchange via UDMF. Key technical topics include the use of `parallelGesture`, `DragItemInfo`, and event handling callbacks like `onDragStart` and `onDrop`. This resource is specifically designed for HarmonyOS developers who possess a foundational understanding of ArkUI, UIKit, or the Cangjie language and wish to enhance user interaction through advanced, cross-component drag-and-drop features. By following these guides, developers can create seamless and intuitive user experiences involving complex data transfer and visual feedback.

## Detailed Description

### 通用拖拽适配_1.md 通用拖拽适配_1.md
This technical tutorial guides developers through implementing universal drag-and-drop functionality for components using the Cangjie language, specifically utilizing the Image component as a primary example. The document covers enabling drag capabilities via the draggable attribute and onDragStart callback, resolving gesture conflicts using parallelGesture, customizing the drag background image via onPreDrag, and handling drag completion results with onDragEnd. Key information includes the use of UDMF for data management, DragItemInfo for custom visuals, and componentSnapshot for generating drag bitmaps, while specifically addressing conflicts between system long-press gestures and custom gestures. The content targets HarmonyOS application developers with prerequisite knowledge of the Cangjie language and UIKit framework.

### 通用拖拽适配_2.md 通用拖拽适配_2.md
This document provides a practical code example demonstrating how to implement universal drag-and-drop functionality in ArkTS. It covers the implementation of draggable components using onDragStart and drop targets using onDrop, onDragEnter, onDragMove, and onDragLeave. The example highlights creating custom drag visuals via pixelMapBuilder, managing component visibility during drag, and handling event data logging and toast prompts. It is intended for HarmonyOS developers seeking to integrate interactive drag-and-drop features into their applications using the ArkUI framework.
