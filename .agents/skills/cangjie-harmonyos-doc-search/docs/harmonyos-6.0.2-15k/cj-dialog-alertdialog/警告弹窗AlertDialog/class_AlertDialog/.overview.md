# class_AlertDialog

This directory provides comprehensive API reference documentation for the `AlertDialog` class within the Cangjie language and the ArkUI framework. It is designed to assist developers in implementing user notifications and confirmation dialogs by detailing the necessary class definitions and construction methods. The content covers a range of functionality, from basic display capabilities available since API version 12 to advanced visual customization features introduced in API version 19, such as shadow styling using `ActionSheetShadowOptions` or `ShadowStyle`. By exploring these documents, developers will learn how to utilize parameters like `AlertDialogParamWithConfirm` and `AlertDialogParamWithButtons` to create robust user interfaces. This resource is essential for Cangjie developers and software engineers looking to enhance application interactivity through pop-up components, offering both foundational knowledge and advanced styling techniques.

## Detailed Description

### class_AlertDialog_7more.md class_AlertDialog_7more.md
This document serves as API reference for the AlertDialog class in the Cangjie language, detailing how to construct and display alert pop-ups within the ArkUI framework. It covers the class definition and multiple overloaded static show functions. These methods accept parameters like AlertDialogParamWithConfirm or AlertDialogParamWithButtons to define the dialog content. Key information includes that basic display functionality starts from API version 12, while version 19 introduces shadow customization via ActionSheetShadowOptions or ShadowStyle parameters. This technical reference targets Cangjie developers building UI applications who need to implement user notifications or confirmations.
