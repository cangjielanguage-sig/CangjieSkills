This directory contains documentation regarding "Structures" (结构体), primarily focusing on their application within a specific unit testing and benchmarking framework. It covers the definition of custom data types, API references for input providers, and detailed configuration keys used to control test parameters. Additionally, it includes utilities for performance measurement and timeout handling. The content is suitable for developers, QA engineers, and students who need to understand the internal data structures of the framework to configure tests, generate benchmark data, or implement advanced testing logic.
