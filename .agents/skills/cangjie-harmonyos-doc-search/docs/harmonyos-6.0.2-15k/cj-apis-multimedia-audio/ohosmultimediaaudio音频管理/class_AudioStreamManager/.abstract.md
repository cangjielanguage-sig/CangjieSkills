This directory contains API reference documentation for the `AudioStreamManager` class within the Cangjie programming language and the AudioKit framework. It focuses on managing, querying, and monitoring audio stream information, including capturers and renderers. The documentation covers methods for retrieving current audio states, checking stream activity, and handling event listeners for state or device changes. Key topics include synchronous functions, error handling via `BusinessException`, and practical code examples. This resource is suitable for multimedia developers and software engineers working on audio applications in the HarmonyOS ecosystem who need to control and observe audio stream behaviors.
