# class_FuncParam

This directory contains essential API reference documentation for the Cangjie AST package, specifically targeting the structural definition and traversal of function parameter nodes. It provides in-depth details on the `FuncParam` class, which serves as the representation for function parameters within the abstract syntax tree. The documentation covers class properties for accessing syntax tokens (such as assign, colon, and not), parameter types, and default expressions, as well as constructors for node creation and utility methods for debugging and serialization. Furthermore, it includes resources for AST traversal, explaining how to walk through syntax tree nodes using the Visitor pattern. Key topics encompass AST manipulation, exception handling for invalid tokens, and controlling traversal flow. This technical content is designed for compiler developers, language tool implementers, and engineers who require programmatic access to and control over the Cangjie language's syntax structures.
