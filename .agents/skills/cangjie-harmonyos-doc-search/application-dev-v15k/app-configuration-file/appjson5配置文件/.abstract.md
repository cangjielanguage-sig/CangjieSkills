This directory contains technical documentation for configuring application manifests using the `app.json5` file format, primarily within the HarmonyOS or OpenHarmony ecosystem. It covers essential configuration aspects such as bundle identification, versioning, API compatibility, and resource management. Key topics include font scaling settings, layered icon definitions, environment variables, and multi-app mode configurations. The resources provide detailed attribute tables, JSON examples, and structural skeletons to assist developers in defining application identity, runtime behaviors, and build settings. This documentation is suitable for application developers and DevEco Studio users seeking precise control over app properties and system integration.
