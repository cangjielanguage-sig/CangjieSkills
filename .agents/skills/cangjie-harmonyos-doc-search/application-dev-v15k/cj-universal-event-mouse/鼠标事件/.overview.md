# 鼠标事件

This directory focuses on mouse event handling within the ArkUI framework using the Cangjie programming language. It covers the fundamental definitions of the `MouseEvent` class, practical implementation examples for UI interactions like hovering and clicking, and the specific API references for the `onMouse` callback. Key topics include event properties (coordinates, button types), state management, and event registration. This documentation is suitable for developers working on HarmonyOS applications who need to integrate mouse input handling into their UI components, specifically targeting API version 12 and above.

## Detailed Description

### 基础类型定义.md 基础类型定义.md
This document serves as an API reference for the MouseEvent class in the Cangjie programming language, designed to describe mouse interaction objects within the ArkUI framework. It details the class structure, defining public properties such as event timestamp, screen coordinates, component-relative coordinates, mouse button type, and action type. Additionally, it specifies the constructor parameters required to instantiate these objects. Key information includes the distinction between global screen positions and local component positions, as well as the use of specific enums for button and action states. Intended for developers working with ArkUI, this documentation supports the implementation of mouse event handling starting from API version 12.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating mouse event handling in the Cangjie programming language for HarmonyOS application development. It covers the implementation of onHover and onMouse event listeners within a UI component, specifically using Button and Text elements inside a Column layout. The code illustrates how to modify state variables based on hover status and how to extract detailed mouse event data such as button type, action, and local or screen coordinates. This example is intended for developers familiar with Cangjie syntax and the UIKit framework who need to implement interactive UI features.

### 鼠标事件_3more.md 鼠标事件_3more.md
This document serves as an API reference for handling mouse events within the ArkUI framework using the Cangjie language. It covers general event behavior, permissions, and the specific definition of the `onMouse` function. The function registers a callback for clicks and movements, providing a `MouseEvent` object with details like coordinates, timestamps, and button states. It notes that events pass through by default and currently only support external mice. Targeted at developers building UI applications, this reference requires knowledge of ArkUI and Cangjie syntax. Keywords: ArkUI, Cangjie, MouseEvent, onMouse, UI interaction, API reference.
