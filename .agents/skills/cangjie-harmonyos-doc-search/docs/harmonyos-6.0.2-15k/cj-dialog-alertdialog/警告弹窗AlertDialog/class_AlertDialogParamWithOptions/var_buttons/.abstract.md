This directory contains API reference documentation for configuring and initializing multi-button alert dialogs within the ArkUI framework using the Cangjie programming language. It covers the `buttons` variable definition, constructor signatures, and parameter configurations for styling and layout. Key topics include button arrays, modal properties, background effects, and system capabilities. These resources are suitable for UI developers and software engineers looking to implement customizable, interactive alert popups in their applications, ensuring compatibility with specific system versions and visual requirements.
