# serialization_samples

This directory serves as a comprehensive resource for developers working with the Cangjie programming language, specifically focusing on the critical tasks of data serialization and deserialization. It provides practical samples and detailed guides on converting complex data types—ranging from custom classes to advanced collections like HashMaps and HashSets—into JSON formats suitable for network transmission and local storage. The content covers essential protocols such as `Serializable`, `Hashable`, and `Equatable`, offering deep insights into object state management and data model mapping. These materials are highly recommended for backend developers and system architects who have a foundational understanding of Cangjie and are looking to implement robust data persistence and API integration strategies.

## Detailed Description

### [1] serialize_and_deserialize_class

This directory details the complete workflow for implementing custom class serialization and deserialization in the Cangjie programming language. The core content revolves around the implementation of the `Serializable` interface, demonstrating how to convert object state into a `DataModel` by writing a `serialize` method, and how to reconstruct objects from the data model using a static `deserialize` method. The documentation provides an in-depth exploration of `DataModelStruct` applications, field mapping mechanisms, and interaction details with `JsonValue` and `JsonObject`, thereby achieving efficient bidirectional conversion between objects and JSON formats. This material is particularly suitable for those who have already mastered Cangjie basics and wish to deepen their understanding of data handling.

### [2] serialize_hashmap_and_hashset

This directory focuses on processing advanced data structures in the Cangjie programming language, elaborating on the serialization and deserialization mechanisms of `HashSet` and `HashMap`. The documentation not only demonstrates how to convert complex collection data into JSON format for storage and transmission but also explains in depth the protocol specifications that custom classes must follow, including specific implementation details for `Serializable`, `Hashable`, and `Equatable`. Through example code, developers can intuitively see how `HashSet` maps to JSON arrays and how `HashMap` maps to key-value pair objects. This tutorial is essential for Cangjie developers engaged in backend development, API design, or local cache implementation.
