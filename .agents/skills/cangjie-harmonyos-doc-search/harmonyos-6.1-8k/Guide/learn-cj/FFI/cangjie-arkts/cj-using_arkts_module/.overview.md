# cj-using_arkts_module

本目录介绍如何在仓颉语言中调用 ArkTS 模块，实现跨语言互操作。内容涵盖导入互操作库、创建 ArkTS 运行时、获取上下文、加载模块及调用方法等步骤。核心包括使用 JSRuntime 和 mainContext 管理环境，利用 requireSystemNativeModule 导入模块，并通过 JSValue 对象调用方法。适用于需在仓颉代码中复用 ArkTS 系统能力的开发者，需具备基础互操作知识。

## Detailed Description

### cj-using_arkts_module.md cj-using_arkts_module.md
本文档是一份详细的开发者指南，旨在指导用户如何在仓颉侧调用 ArkTS 模块，从而实现高效的跨语言互操作。文档系统地介绍了整个操作流程，主要涵盖了以下几个关键方面：首先是如何正确导入互操作库，其次是创建和配置 ArkTS 运行时环境，接着是如何获取必要的上下文信息。此外，文档还详细讲解了如何通过模块名来加载特定的模块，以及如何调用模块中的具体方法。在技术实现上，核心要点包括使用 JSRuntime 和 mainContext 来有效管理运行环境，利用 requireSystemNativeModule 函数来导入系统模块，以及通过 JSValue 对象来执行具体的方法调用。这份文档特别适用于那些需要在仓颉代码中复用 ArkTS 系统能力的开发者，建议读者在阅读前具备基础的互操作知识。
