This directory contains comprehensive API reference documentation for the `FlexOptions` class utilized within the Cangjie language and the ArkUI framework. It serves as a technical guide for configuring layout properties specific to Flex containers, allowing developers to manipulate the alignment, direction, and spatial arrangement of child components. The documentation covers essential aspects such as the class constructor, public properties like `direction`, `wrap`, and `justifyContent`, and critical layout constraints regarding wrapping and spacing. This resource is specifically tailored for software developers and UI engineers working on ArkUI interfaces who require precise, programmatic control over flexible layouts and possess a foundational understanding of Flex layout concepts and Cangjie syntax. By detailing the interaction between main and cross axes, these documents provide the necessary specifications for building responsive and adaptive user interfaces.
