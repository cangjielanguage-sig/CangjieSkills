This directory provides comprehensive documentation for implementing drag-and-drop functionality in the Cangjie ArkUI framework. It covers essential API references for event handling (onDragStart, onDrop, onDragEnter, etc.), configuration attributes, and data structures like DragInfo and DragEvent. The content includes detailed function signatures, version differences (API 12 vs 19), and practical code examples for customizing drag visuals and managing interactions. It is suitable for Cangjie developers and HarmonyOS engineers looking to build interactive UI components with robust drag-and-drop capabilities.
