# cj-attribute-animation-overview

本文档深入解析了ArkUI框架中的属性动画机制，旨在为开发者提供关于属性动画分类与标准的全面指南。内容涵盖了可动画属性与不可动画属性的精确定义、判断依据（即是否引起UI变化及是否适合过渡），以及系统内置可动画属性（包括布局属性、仿射变换、背景等）的详细分类。此外，文档还探讨了自定义可动画属性的实现方式及数据类型插值规则。本文档适合ArkUI开发者阅读，旨在帮助开发者深入理解属性动画的底层逻辑，从而在应用开发中实现流畅、自然且高性能的UI交互体验。

## Detailed Description

### cj-attribute-animation-overview.md

本文档概述了ArkUI中的属性动画机制，旨在解释属性动画的分类及标准。主要内容包括可动画属性与不可动画属性的定义、判断标准（UI变化及过渡适用性），以及系统可动画属性（如布局、仿射变换、背景等）的分类。文档还涉及自定义可动画属性及数据类型插值规则。关键点在于可动画属性必须能引起UI变化且适合过渡，虽然通常需连续数据类型，但枚举类型若引起位置变化也可支持动画。本文属于概念指南，面向ArkUI开发者，帮助其理解如何利用属性动画实现流畅的UI交互。
