This directory provides comprehensive API references for foundational data structures essential for event and gesture handling within the ArkUI framework using the Cangjie language. It encompasses base event properties, specific gesture event types such as pinch and rotation, and structures for controlling gesture recognition logic. Key topics include input metrics, finger tracking, coordinate systems, and gesture judgment results. This documentation is specifically designed for developers building ArkUI applications who require precise control over touch interactions, custom gesture implementation, and low-level input event processing.
