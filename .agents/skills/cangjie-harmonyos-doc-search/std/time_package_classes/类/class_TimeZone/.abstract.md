This directory contains API reference documentation for the `TimeZone` class in the Cangjie programming language. It covers the core functionality for representing time zones, managing UTC offsets, and handling time zone identifiers. Key topics include class definition, static properties (Local/UTC), constructors, string representation, comparison operators, and static loading methods from various data sources like environment variables or raw byte arrays. This documentation is suitable for Cangjie developers and software engineers working on date and time functionality who need to implement or understand time zone handling, validation, and data parsing within their applications.
