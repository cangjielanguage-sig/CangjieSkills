## 详细描述

### TextInput_5more_08d8d32d.md TextInput_5more_08d8d32d.md
本文档是ArkUI框架中TextInput组件的API参考文档，旨在指导开发者如何创建和使用单行文本输入框。文档主要内容包括模块导入方式、组件初始化构造函数init的详细说明，以及组件支持的通用属性和事件列表。关键信息指出该组件当前处于Beta阶段，支持基本输入模式。构造函数接受三个可选命名参数：占位符文本、当前文本值和控制器对象，用于灵活配置输入框状态。文档面向使用仓颉语言开发ArkUI应用的程序员，提供了必要的接口定义和参数说明，以便在用户界面中集成文本输入功能。

### 基础类型定义_2more_3de06505.md 基础类型定义_2more_3de06505.md
这份文档是ArkUI框架中TextInputController类的API参考文档，旨在指导开发者如何通过控制器对象管理TextInput组件。文档详细定义了类的构造函数及核心方法，包括设置光标位置、指定文本选择范围以及退出编辑状态，并提供了参数说明、系统能力和起始版本信息。此外，文档包含示例代码，演示了控制器的绑定与光标移动的具体用法。该文档面向使用仓颉语言进行HarmonyOS应用开发的开发者，提供了实现输入框交互控制的关键技术细节。

### 组件事件.md 组件事件.md
本文档是Cangjie语言中组件事件处理的API参考文档，详细定义了输入框组件的交互回调接口。文档涵盖了六个主要事件处理函数：onChange（内容变化）、onCopy（复制）、onCut（剪切）、onEditChange（编辑状态）、onPaste（粘贴）及onSubmit（提交）。所有函数均返回This以支持链式调用，回调参数涵盖字符串或布尔值，起始版本为22，系统能力为ArkUI.Full。该文档面向使用ArkUI框架进行应用开发的Cangjie语言开发者，旨在帮助其实现精细化的用户输入交互逻辑。

### 组件属性/
本目录包含ArkUI框架中使用仓颉（Cangjie）语言开发的文本输入组件属性API参考文档。内容涵盖了文本输入的全方位配置，包括基础样式定制（如字体、颜色、对齐方式）、交互行为控制（如光标、键盘类型、焦点管理）以及输入限制规则（如长度限制、过滤规则）。所有API均支持链式调用，起始版本为API 22。这些文档适用于需要精细化管理UI组件外观与逻辑的ArkUI应用开发者，旨在帮助构建高效、美观的用户输入界面。
