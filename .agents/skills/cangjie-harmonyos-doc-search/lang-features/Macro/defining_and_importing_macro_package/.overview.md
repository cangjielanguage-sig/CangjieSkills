# defining_and_importing_macro_package

本目录深入探讨了仓颉语言中宏包系统的核心机制，重点讲解宏包的定义规则、可见性控制以及导入机制。文档详细解析了 `macro package` 声明的语法，区分了宏与非宏声明在可见性上的不同，并明确了包之间重导出的严格限制与规则。核心要点包括宏包仅允许宏定义对外可见、宏包与非宏包在重导出权限上的差异等。此外，还通过多包依赖的实际案例，演示了如何利用重导出机制来简化宏使用者的依赖管理流程。这份技术指南专为仓颉语言开发者设计，特别适合那些需要深入编写、维护或使用宏的开发人员阅读，以帮助他们更好地理解模块化编程中的宏管理。

## Detailed Description

### defining_and_importing_macro_package.md

本文档旨在阐述仓颉语言中宏包的定义规则、可见性限制及导入机制。主要涵盖 `macro package` 声明、宏与非宏声明的可见性差异、以及包之间重导出的限制与规则。核心要点是宏包仅允许宏定义对外可见，且宏包可重导出宏包和非宏包，而非宏包禁止重导出宏包。文档通过多包依赖示例演示了如何通过重导出简化宏使用者的依赖管理。这是一份面向仓颉语言开发者的技术指南，适合需要编写或使用宏的用户阅读。
