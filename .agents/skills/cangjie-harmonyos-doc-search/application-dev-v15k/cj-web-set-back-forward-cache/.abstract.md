This directory contains a technical guide for developers using the ArkWeb engine in the Cangjie environment, focusing on the Back/Forward Cache (BFCache). It details how to enable and configure BFCache to accelerate page navigation speeds and improve responsiveness. The guide covers enabling the cache before kernel initialization and configuring limits like page capacity and retention time, with a default of 600 seconds. By providing Cangjie code examples, it helps developers reduce HTTP requests and ensure rapid page state restoration. This resource is essential for optimizing user experience through efficient state management and performance tuning in web applications.
