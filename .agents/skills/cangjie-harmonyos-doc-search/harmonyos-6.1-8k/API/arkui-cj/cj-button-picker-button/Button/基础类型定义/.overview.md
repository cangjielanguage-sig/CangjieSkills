### enum_ButtonRole_2more_d0ecdff7.md enum_ButtonRole_2more_d0ecdff7.md
本文档是ArkUI框架中Cangjie语言的API参考文档，用于定义按钮属性。文档主要包含两个枚举：ButtonRole（定义按钮角色，如Normal和Error）和ButtonStyleMode（定义重要程度，如Normal、Emphasized和Textual）。关键信息显示，这两个枚举均继承自Equatable，并提供了标准的相等与不等运算符用于值比较。这些组件自版本22起可用。本文档面向需要通过编程控制按钮样式和语义角色的ArkUI开发者。

### enum_ButtonType_7d1ec57f.md enum_ButtonType_7d1ec57f.md
