### class_ComponentInfo.md class_ComponentInfo.md

### class_Offset_3f2981bd.md class_Offset_3f2981bd.md
本文档是Cangjie语言中Offset类的API参考文档，旨在定义用于表示二维位置偏移的数据结构。文档涵盖了类定义、x与y坐标属性（均为Float64类型）以及构造函数的详细说明。关键信息包括该类具备ArkUI全量系统能力，起始版本为22。此文档主要面向使用ArkUI框架进行UI开发的程序员，提供了处理组件位置偏移所需的基础数据类型定义。

### class_RotateResult.md class_RotateResult.md
这份文档是Cangjie语言中RotateResult类的API参考文档，旨在定义用于封装旋转变换结果的数据结构。文档主要涵盖类的属性定义，包括旋转轴向量坐标、中心点坐标变换以及旋转角度，并详细说明了构造函数的参数。关键信息指出所有属性均为Float64类型且可读写，该类属于SystemCapability.ArkUI.ArkUI.Full系统能力，起始版本为22。这份资料主要面向使用ArkUI框架进行UI开发的程序员，帮助他们理解和处理图形旋转相关的数据参数。

### class_ScaleResult_2more_2e1d268c.md class_ScaleResult_2more_2e1d268c.md
这是一份仓颉语言的ArkUI API参考文档，旨在定义图形变换与尺寸描述的基础数据结构。文档主要涵盖ScaleResult和Size两个类：ScaleResult用于表示缩放结果，包含x、y、z轴缩放因子及中心点坐标；Size用于定义对象大小，包含宽度和高度属性。两者均提供构造函数及可读写属性，系统能力为SystemCapability.ArkUI.ArkUI.Full，起始版本为22。该文档面向ArkUI框架开发者，提供了处理组件缩放和尺寸计算的核心数据类型定义，关键词包括ScaleResult、Size、缩放因子、中心点坐标、ArkUI。

### class_TranslateRe_2more_76588def.md class_TranslateRe_2more_76588def.md
