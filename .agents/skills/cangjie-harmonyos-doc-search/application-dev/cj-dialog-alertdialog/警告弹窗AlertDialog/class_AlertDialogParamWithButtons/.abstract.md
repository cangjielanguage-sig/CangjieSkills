This directory provides comprehensive API documentation for the Cangjie class `AlertDialogParamWithButtons`, specifically tailored for configuring alert dialogs that feature two action buttons within the ArkUI framework. It covers the class definition, inheritance from `AlertDialogParam`, and the necessary constructor parameters for initialization. Key topics include specifications for `primaryButton` and `secondaryButton` properties, system capabilities, and version requirements (starting from version 22). Additionally, it details customizable attributes such as alignment, background style, and transition effects. This resource is intended for ArkUI developers using the Cangjie language who need to implement interactive modal dialogs with dual-button functionality.
