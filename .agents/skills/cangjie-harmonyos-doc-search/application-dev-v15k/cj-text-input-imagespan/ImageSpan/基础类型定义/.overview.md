# 基础类型定义

This directory contains the foundational type definitions and API references for the Cangjie language within the ArkUI framework. It focuses on core classes necessary for image processing and UI component management, specifically covering error handling, color filtering, and loading state encapsulation. Key components include the `CJImageError` for failure management, `ColorFilter` for matrix-based color adjustments, and `ImageLoadResult` for tracking loading metrics. These resources are essential for developers aiming to implement robust image rendering and error handling logic in their applications.

Intended for ArkUI developers, this reference guide helps implement color transformations using matrix math, requiring knowledge of Cangjie programming and color filter concepts.
