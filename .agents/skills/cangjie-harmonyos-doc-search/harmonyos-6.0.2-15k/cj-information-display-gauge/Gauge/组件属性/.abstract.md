This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It primarily focuses on the customization and behavior of Gauge components, covering aspects such as color settings (solid and gradient), geometric definitions (angles, stroke width), and dynamic data values. Key topics include color arrays, shadow effects, pointer styles, and privacy modes. This documentation is suitable for UI developers and software engineers working on HarmonyOS applications who need to implement and fine-tune visual data representations and component interactions.
