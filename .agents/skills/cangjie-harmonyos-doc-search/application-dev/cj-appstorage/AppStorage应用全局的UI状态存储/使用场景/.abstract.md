This directory provides comprehensive guides on practical usage scenarios for state management in ArkUI applications developed with the Cangjie language. It covers essential topics such as implementing application logic using AppStorage and LocalStorage, managing complex data types like DateTime and collections, and optimizing performance by avoiding common anti-patterns. Key concepts include two-way data synchronization, reactive UI updates, and the effective use of decorators like @StorageLink and @LocalStorageLink. These resources are specifically designed for ArkUI developers who aim to build efficient, high-performance applications with robust state handling and data binding capabilities.
