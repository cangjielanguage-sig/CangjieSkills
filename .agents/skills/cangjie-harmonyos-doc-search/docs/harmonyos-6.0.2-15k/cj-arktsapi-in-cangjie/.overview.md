# cj-arktsapi-in-cangjie

This directory serves as a technical resource for Cangjie developers seeking to integrate ArkTS APIs and standard libraries into their applications. It addresses the interoperability challenges between the two languages by providing a detailed tutorial on creating and managing an ArkTS runtime instance using `JSRuntime`. The content covers essential workflows, including the loading of pre-compiled modules such as NAPI .so files or .abc bytecode, and the subsequent invocation of ArkTS interfaces via the `call` method. Key technical constraints, such as the use of `mainContext` and the requirement to operate on the main thread, are thoroughly explained. This guide is ideal for developers who need to leverage mature ArkTS features that are currently absent in the Cangjie ecosystem, while also noting the limitations regarding partial module support.
