# 基础类型定义

This directory serves as a comprehensive repository for fundamental type definitions within the ArkUI framework, specifically tailored for managing drag-and-drop interactions using the Cangjie language. It encompasses essential classes and enumerations that allow developers to granularly control visual feedback, animation behaviors, and interaction logic during drag operations. Key topics include multi-selection gathering effects for Grid and List components, scaling animations during long-press events, and the customization of visual attributes such as shadows and corner radii. These definitions are critical for ensuring a polished and responsive user experience. The documentation is primarily designed for ArkUI developers and UI engineers working on API version 19 or later who require precise control over component behaviors and aesthetic presentation during complex user interactions.

## Detailed Description

### class_DragInteractionOptions.md class_DragInteractionOptions.md

This API reference document defines the DragInteractionOptions class used to configure visual effects and behaviors during drag-and-drop interactions in the ArkUI framework. It details the class constructor and two read-only properties: isMultiSelectionEnabled and defaultAnimationBeforeLifting. Key information includes that isMultiSelectionEnabled enables multi-selection gathering effects specifically for Grid and List items, with specific restrictions on sub-component dragging and context menu compatibility. The defaultAnimationBeforeLifting property controls whether the default scaling animation appears during the long-press phase. This documentation targets ArkUI developers using the Cangjie language who need to customize drag interaction behaviors in version 19 or later.

### enum_DragPreviewMode.md enum_DragPreviewMode.md

This document provides API reference documentation for the DragPreviewMode enum in the Cangjie language, used to configure drag-and-drop visual behaviors within the ArkUI framework. It enumerates four modes: AUTO, DISABLE_SCALE, ENABLE_DEFAULT_SHADOW, and ENABLE_DEFAULT_RADIUS. The documentation explains that AUTO delegates control to the system for positioning and scaling, while the other values allow developers to disable scaling or enable default visual effects like shadows and rounded corners for non-text components. Key information includes the default corner radius of 12vp and the availability starting from API version 19. This guide is intended for UI developers seeking to fine-tune the aesthetic and interactive feedback of drag operations in their applications.
