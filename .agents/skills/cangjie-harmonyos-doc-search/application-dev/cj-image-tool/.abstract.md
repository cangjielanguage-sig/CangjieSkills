This directory contains a specialized development guide focused on the reading and editing of JPEG image EXIF metadata using the Cangjie language within the OpenHarmony ecosystem. It covers the technical intricacies of the EXIF format and provides practical scenarios for manual data correction, such as fixing shooting time or adjusting lens parameters. The guide includes step-by-step tutorials on utilizing the ImageKit API to create ImageSources and modify attributes like ImageWidth. It is specifically designed for OpenHarmony developers building gallery or photography applications who need to programmatically manage image metadata, offering crucial insights into the current Beta status and the tool's JPEG-only support limitations. The documentation aims to bridge the gap between raw image data and application-level requirements, providing a robust foundation for image processing tasks.
