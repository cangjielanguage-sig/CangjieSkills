# data_package_overview

This directory contains the API overview documentation for the `stdx.unittest.data` library, a specialized tool designed to facilitate input serialization for Cangjie unit tests. It provides comprehensive details on supporting JSON, CSV, and TSV formats, enabling developers to externalize test data for robust parameterized testing. The content covers essential functions like `csv`, `json`, and `tsv`, as well as strategy classes such as `CsvStrategy` and `JsonStrategy` for format implementation. This resource is suitable for Cangjie developers who possess knowledge of the language's standard testing capabilities and are seeking to optimize their test suites by integrating external data sources.
