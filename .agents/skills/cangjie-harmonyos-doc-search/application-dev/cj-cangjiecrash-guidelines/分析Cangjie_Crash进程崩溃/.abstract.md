This directory provides a comprehensive technical guide for analyzing and debugging process crashes in Cangjie applications. It focuses on handling uncaught exceptions, distinguishing between system Errors and logic Exceptions, and utilizing crash logs effectively. Key topics include log retrieval via DevEco Studio, stack trace analysis, and root cause identification strategies. The content also covers specific case studies on resource exhaustion like OutOfMemoryError and StackOverflowError. This resource is suitable for Cangjie developers, software engineers, and technical support personnel aiming to improve application stability and master debugging techniques.
