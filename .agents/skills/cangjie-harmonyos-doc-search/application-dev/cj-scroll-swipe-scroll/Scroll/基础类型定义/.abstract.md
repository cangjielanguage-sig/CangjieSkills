This directory provides fundamental type definitions and API references for implementing scrolling behaviors and edge effects within the Cangjie ArkUI framework. It covers configuration options for animations and fading edges, data structures for scroll results and geometry, enumerations for alignment and clipping, and callback types for event handling. Additionally, it includes documentation for the `Scroller` controller class. Designed for software developers using Cangjie, these resources are essential for building interactive, high-performance user interfaces with precise control over scroll mechanics and visual feedback.
