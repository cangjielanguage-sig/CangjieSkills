# Rect

This directory contains comprehensive documentation for the Rect component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the API reference for creating and configuring rectangle drawing tools, including initialization parameters, supported attributes, and event handling. The content also provides practical code examples demonstrating styling techniques such as fill, stroke, and rounded corners. Suitable for UI developers and HarmonyOS application builders, this resource facilitates the implementation of 2D shapes and declarative UI design in Cangjie applications.

## Detailed Description

### Rect_5more.md Rect_5more.md
This document provides API reference documentation for the Rect component, a rectangle drawing tool within the ArkUI framework designed for the Cangjie programming language. The content details the module import process, component creation using the init function, and supported attributes and events. Key information includes the init method parameters, which accept optional width and height values of type Length with a minimum range of zero. The component supports general attributes alongside specific graphic drawing properties. Intended for UI developers, this guide explains how to instantiate and configure rectangular shapes in application interfaces.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring border radius properties within the ArkUI framework using the Cangjie programming language. It details five specific functions: radiusWidth, radiusHeight, and three overloads of radius that accept single values, arrays, or tuples. These methods allow developers to set uniform or specific corner radii, including support for separate width and height dimensions for each corner. Key information includes that all parameters default to 0.vp, require non-negative values, and revert to initial values upon encountering exceptions. The system capability is ArkUI.Full starting from version 22. This technical reference is intended for UI developers using Cangjie to style component appearances.
