# ohosmultimedia_avsession媒体会话管理

This directory contains API reference documentation for the HarmonyOS multimedia AVSession module in the Cangjie programming language. It covers comprehensive media session management, including audio-video playback control, casting operations, metadata handling, and device management. Key components include classes for session controllers, playback states, media descriptions, and enumerations for command types and events. Designed for developers building multimedia applications, this documentation provides the necessary structures and interfaces to integrate with the system playback control center, manage remote casting, and handle complex media interactions effectively.
