# regex_package_classes

The `regex_package_classes` directory serves as a comprehensive API reference for regular expression processing within the Cangjie programming language. It is designed to assist developers in navigating the complexities of text pattern matching by providing detailed documentation on all relevant classes. This directory covers both active and deprecated components, ensuring that developers have access to the `Regex` class for modern pattern matching as well as legacy classes like `Matcher` and `RegexOption` for maintaining older systems. Key functionalities documented include compiling expressions, performing matches, replacing text, splitting strings, and managing capture groups. Additionally, it addresses specific behaviors such as lazy evaluation and configuration modes, which are critical for optimizing performance and behavior in complex text processing scenarios. This documentation is essential for Cangjie developers seeking to implement robust text processing, maintain legacy systems, or transition from deprecated regex implementations to current standards. By offering a clear distinction between modern and legacy APIs, it empowers developers to write cleaner, more efficient code while managing technical debt effectively. Whether you are debugging complex patterns or optimizing string operations, this directory provides the necessary structural guidance.
