# 基础类型定义

This directory provides essential type definitions for implementing gesture handling within the ArkUI framework using the Cangjie programming language. It focuses on the core structures required to manage touch interactions, specifically pan gestures. The content includes detailed API references for configuration classes that allow dynamic adjustment of gesture properties without UI refreshes, as well as enumerations that define directional constraints and axis-based movements. These definitions are crucial for developers aiming to create responsive and interactive user interfaces, providing the necessary tools to optimize performance and handle complex event logic. This documentation is specifically suitable for software engineers and ArkUI developers working with Cangjie who need precise control over gesture recognition behaviors, parameter constraints, and system capabilities in their applications.

## Detailed Description

### class_PanGestureOptions.md class_PanGestureOptions.md
This API reference document details the PanGestureOptions class, enabling developers to dynamically configure pan gesture properties in ArkUI without triggering UI refreshes. The documentation covers the class constructor and three key setter methods: setDirection, setDistance, and setFingers. Key information includes parameter constraints, such as the valid finger count range of 1-10 and the handling of negative distance values. It also provides a specific optimization tip for Tabs components to avoid event conflicts. Intended for ArkUI developers using the Cangjie language, this reference helps optimize gesture recognition performance and behavior in application interfaces.

### enum_PanDirection.md enum_PanDirection.md
This API reference document defines the PanDirection enum in the Cangjie language, used to specify drag gesture directions within the ArkUI framework. The content details enum members including cardinal directions (Left, Right, Up, Down), axis-based directions (Horizontal, Vertical), and special states (None, All, Computed). It also documents overloaded bitwise operators (&, |) for combining directions. Key information includes the requirement for system capability SystemCapability.ArkUI.ArkUI.Full and availability starting from version 19. This documentation targets software developers using the Cangjie language to implement gesture recognition in ArkUI applications.
