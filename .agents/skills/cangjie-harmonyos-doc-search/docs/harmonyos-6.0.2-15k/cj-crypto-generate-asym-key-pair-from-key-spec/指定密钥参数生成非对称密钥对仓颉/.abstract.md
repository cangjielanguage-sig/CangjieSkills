This directory provides technical resources and code examples for generating asymmetric key pairs using specified parameters within the Cangjie programming language and the CryptoArchitectureKit framework. It covers essential algorithms including RSA, ECC, and SM2, detailing how to construct parameter specifications like `ECCCommonParamsSpec` and `RSACommonParamsSpec`. The guides emphasize handling BigInt inputs in big-endian mode and retrieving key attributes for secure storage. These materials are suitable for Cangjie developers and security engineers implementing custom cryptographic operations, key generation workflows, and parameter validation in the HarmonyOS ecosystem.
