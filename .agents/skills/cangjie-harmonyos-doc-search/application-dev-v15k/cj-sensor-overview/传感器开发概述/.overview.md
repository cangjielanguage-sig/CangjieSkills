# 传感器开发概述

This directory provides a comprehensive technical overview of sensor development, designed to assist developers in understanding and utilizing the sensor subsystem effectively within the operating system environment. It covers the complete spectrum of sensor capabilities, ranging from the categorization of motion, environmental, and position sensors to the intricate operational mechanisms that drive data acquisition. The documentation highlights critical architectural components, including the Sensor API, Sensor Framework, and HDF layer, while also addressing essential compliance requirements such as permission management and subscription rules. By detailing measurement units, physical axes, and data flow, this guide serves as a vital resource for system and application developers aiming to implement advanced features like health tracking, gaming controls, and device orientation adjustments. This overview ensures that developers have the necessary architectural understanding and compliance guidelines to successfully integrate hardware sensors into their applications, facilitating the creation of responsive and context-aware software solutions. It is particularly suitable for developers utilizing the SensorServiceKit API.

## Detailed Description

### 传感器类型.md 传感器类型.md
This reference document defines the various system sensor types available to developers for accessing hardware data and building applications. The content focuses on a comprehensive categorization of sensors, including motion sensors like accelerometers and gyroscopes, environmental sensors for temperature and light, and position sensors such as magnetometers. Key information includes specific measurement units, physical axes, and primary use cases for each sensor type, ranging from step counting and compass creation to automatic screen brightness adjustment. Intended for application developers using the SensorServiceKit API, this guide aids in selecting appropriate sensors for features like health tracking, gaming, and device orientation.

### 运作机制_2more.md 运作机制_2more.md
This document outlines the operational mechanism of the sensor subsystem, detailing its four-module architecture and usage constraints. It covers the Sensor API, Sensor Framework, Sensor Service, and HDF layer functions, alongside specific permission requirements and subscription rules. The text explains data flow from hardware adaptation to application interfaces and mandates specific permissions like ohos.permission.ACCELEROMETER for sensitive data access. It emphasizes that subscription and unsubscription calls must be paired to manage data reporting effectively. Intended for system and application developers, this guide provides the necessary architectural understanding and compliance guidelines for implementing sensor features.
