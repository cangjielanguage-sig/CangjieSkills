This directory contains comprehensive API reference documentation for configuring the properties of the Progress component within the ArkUI framework, specifically tailored for the Cangjie programming language. It provides detailed technical specifications for customizing the visual appearance and functional behavior of progress indicators. Key topics include methods for setting solid and gradient colors using ResourceColor and ColorStop parameters, defining specific geometric shapes such as Ring, Eclipse, and ScaleRing, and managing layout styles like Linear and Capsule. The documentation also covers progress value management, including automatic clamping, and details version-specific requirements for API 12 and 19. This resource is essential for UI developers and software engineers seeking to programmatically control and style progress bars in their applications, ensuring precise visual integration and functional accuracy.
