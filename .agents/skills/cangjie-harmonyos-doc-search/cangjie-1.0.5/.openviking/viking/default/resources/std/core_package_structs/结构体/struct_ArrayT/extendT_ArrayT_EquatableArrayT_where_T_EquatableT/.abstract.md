This directory contains API reference documentation for the Cangjie programming language, specifically focusing on the extension of the `Array` type where elements implement the `Equatable` interface. It covers essential functionalities for array comparison, searching for elements or sub-arrays, and structural manipulation like trimming prefixes and suffixes. Key topics include the equality operator (`==`), `indexOf` and `lastIndexOf` functions, and methods for modifying array boundaries. This documentation is suitable for Cangjie developers looking to implement robust search logic, perform equality checks, or manipulate array data structures efficiently.
