This directory contains API reference documentation for the `AssertPrintable` interface within the Cangjie programming language's unit testing framework. It covers the core interface definition required for custom assertion printing and details specific implementations for various data types, including `Option<T>`, `String`, `Float16`, `Float32`, and `Float64`. These documents explain how to format test failure outputs using `PrettyPrinter`, handling nested differences, and managing prefixes for expected versus actual values. This resource is suitable for developers working on or extending the Cangjie testing framework who need to understand or customize assertion display logic.
