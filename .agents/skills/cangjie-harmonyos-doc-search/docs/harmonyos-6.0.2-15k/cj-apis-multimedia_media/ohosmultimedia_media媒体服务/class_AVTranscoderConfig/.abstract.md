This directory contains API reference documentation for the `AVTranscoderConfig` class, a fundamental component within the Cangjie language multimedia framework designed for managing audio and video transcoding operations. The documentation provides comprehensive technical details on initializing configuration objects and defining media parameters, such as bitrates, codec formats, file containers, and frame dimensions. It outlines specific system capabilities and strict constraints, including mandatory MP4 container support, codec limitations (AAC for audio, AVC/HEVC for video), and automatic bitrate calculation logic based on resolution tiers. Furthermore, it details default behaviors like frame dimension inheritance from the source. This resource is essential for multimedia developers and engineers who need to implement or configure media encoding features in their applications, ensuring compatibility with system version 20 and above. It serves as a practical guide for understanding the structural requirements and capabilities of the transcoding system.
