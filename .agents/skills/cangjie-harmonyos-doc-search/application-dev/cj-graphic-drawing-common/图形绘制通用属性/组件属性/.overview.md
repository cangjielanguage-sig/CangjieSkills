# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It focuses on the graphical styling and rendering of shape components, detailing functions for both fill and stroke attributes. The content covers essential visual properties such as color, opacity, line width, dash patterns, and line styles, as well as advanced rendering settings like miter limits and anti-aliasing. By providing specific parameter types, default values, and system capabilities, these documents guide developers in handling visual inputs and managing edge cases effectively. This resource is suitable for UI developers and software engineers who require precise control over the aesthetic customization and visual quality of graphical elements in ArkUI applications, starting from API version 22.
