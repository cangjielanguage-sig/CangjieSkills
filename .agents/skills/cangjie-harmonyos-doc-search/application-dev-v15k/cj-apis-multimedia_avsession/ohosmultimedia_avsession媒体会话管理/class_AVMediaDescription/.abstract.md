This directory contains API reference documentation for the `AVMediaDescription` class in the Cangjie programming language. It focuses on defining metadata attributes for playlist media items within the Multimedia AVSession Core module. The documentation covers constructors for initializing media objects with various parameters, including media identification, URIs, DRM schemes, and playback timing. It also details public properties for managing media metadata like titles, artists, and images. This resource is suitable for software developers and multimedia application engineers who need to integrate media playback features and manage AV sessions in Cangjie-based systems.
