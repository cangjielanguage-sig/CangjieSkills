This directory serves as a comprehensive resource for understanding and implementing System Capability (SysCap) within the HarmonyOS ecosystem. It details the theoretical framework of SysCap, including definitions, compatibility rules, and the relationship between system features and APIs. Furthermore, it provides practical development guidance for managing capabilities across different devices, utilizing tools like DevEco Studio and the Cangjie canIUse API. This documentation is essential for HarmonyOS application developers seeking to ensure their applications function correctly across a wide range of hardware configurations by properly handling API availability and device-specific features.
