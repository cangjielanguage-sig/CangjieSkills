This directory serves as a comprehensive resource for documentation regarding the experimental coverage printing functionality within the Cangjie fuzzer ecosystem. It specifically addresses the technical mechanisms required to generate detailed statistics on function testing while ensuring that the performance and efficiency of the active fuzzing process remain completely unaffected. Key topics covered in this directory include the configuration of the `-print_coverage=1` parameter, the application of specific compilation flags such as `--sanitizer-coverage-inline-8bit-counters`, and the integration of a custom libfuzzer library. Furthermore, the documentation provides a comparative analysis of output examples between C and Cangjie implementations, explicitly noting current discrepancies in source location reporting where Cangjie may show unknown filenames. This resource is primarily designed for software developers, QA engineers, and security researchers who are responsible for setting up, configuring, and analyzing the code coverage of the Cangjie fuzzer environment.
