# 在ArkTS应用中使用仓颉模块

This directory provides comprehensive resources for integrating Cangjie modules into ArkTS applications within the HarmonyOS ecosystem. It covers the fundamental concepts of the Cangjie language, practical implementation guides for cross-language interoperability using declarative macros, and references to official API documentation. Key topics include the lightweight runtime, high concurrency features, and specific steps for module integration using DevEco Studio. This content is suitable for HarmonyOS developers and system architects looking to leverage Cangjie for high-performance scenarios and cross-language functionality.

## Detailed Description

### 使用指导.md 使用指导.md
This guide instructs developers on integrating Cangjie modules into ArkTS applications using declarative interop macros. Key topics include adding Cangjie modules to ArkTS projects, implementing interop functions decorated with @Interop[ArkTS], generating TypeScript declaration files, and loading the module to call Cangjie functions. Important takeaways include the requirement for API 12 or higher, the specific device types supported, and the prohibition of importing interop modules into other modules. This tutorial targets HarmonyOS developers using DevEco Studio to enable cross-language functionality between ArkTS and Cangjie.

### 参考文档.md 参考文档.md
This document serves as a navigational hub directing developers to official resources regarding interoperability between the Cangjie programming language and ArkTS. It primarily references two external documentation sources: a detailed overview guide explaining the integration concepts and a specific API reference library for the interoperation modules. The key takeaway is that comprehensive technical details and function definitions are hosted externally on the Huawei Developer site. This reference index is intended for software engineers working within the HarmonyOS ecosystem who need to implement cross-language functionality between Cangjie and ArkTS components.

### 概述.md 概述.md
This document provides a high-level overview of the Cangjie programming language, highlighting its runtime characteristics and integration capabilities. The text focuses on the language's execution environment and its relationship with ArkTS. Key information includes that Cangjie operates on a lightweight runtime optimized for high performance and concurrency. Crucially, it supports cross-language interoperability with ArkTS, allowing developers to embed Cangjie modules within ArkTS applications to enhance overall performance. This summary targets software developers and system architects interested in leveraging Cangjie for high-performance scenarios within the HarmonyOS ecosystem. Keywords: Cangjie, lightweight runtime, high concurrency, ArkTS interoperability, cross-language integration.
