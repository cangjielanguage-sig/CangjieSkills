This directory serves as a technical guide for developers seeking to implement image editing features by invoking a system image editing application from within their own app. It covers the end-to-end process, including selecting images from the gallery, copying them to a local sandbox, and launching the editor with specific parameters. Key technical concepts include URI conversion, permission management via flags, and the use of the `startAbilityByType` interface to interact with `PhotoEditorExtensionAbility`. The documentation explains how to handle callbacks to retrieve the edited image data. This content is specifically designed for HarmonyOS application developers using either Cangjie or ArkTS, providing the necessary instructions to seamlessly integrate system-level image editing capabilities into their software projects.
