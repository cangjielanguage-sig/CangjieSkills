This directory contains API reference documentation for the HarmonyOS Cangjie file permission module, specifically focusing on file authorization and access control. It covers the mechanisms for granting, persisting, revoking, and deactivating permissions for file URIs. Key components include classes for error handling (`PolicyErrorResult`), enums for operation modes and error codes, and functions for managing persistent access. The documentation is intended for HarmonyOS application developers using the Cangjie language who need to implement secure file management features, requiring the `ohos.permission.FILE_ACCESS_PERSIST` permission and the `FolderAuthorization` system capability.
