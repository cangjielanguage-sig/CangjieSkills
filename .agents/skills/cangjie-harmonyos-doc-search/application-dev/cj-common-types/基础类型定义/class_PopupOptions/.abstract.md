This directory contains comprehensive API reference documentation for the `PopupOptions` class and related configuration properties within the ArkUI framework using the Cangjie language. It covers the structural definition of popup windows, including initialization parameters, layout positioning, visual styling (such as shadows, blur, and arrow dimensions), and event handling mechanisms like button callbacks and dismissal events. The documentation is designed for developers and UI engineers who require granular control over popup behavior and appearance in HarmonyOS applications. Key topics include component configuration, property management, and advanced customization features available from API version 22.
