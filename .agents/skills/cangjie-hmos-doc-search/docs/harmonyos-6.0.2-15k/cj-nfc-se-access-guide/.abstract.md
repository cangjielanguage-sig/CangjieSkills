This directory serves as a comprehensive technical resource and development guide designed for software engineers aiming to integrate Secure Element (SE) technology into their applications using the Cangjie language and the HarmonyOS ConnectivityKit. It provides an in-depth exploration of SE fundamentals, specifically distinguishing between and managing embedded SE (eSE) and NFC-enabled SIM cards. The content covers the complete end-to-end workflow required for managing SE services, establishing secure sessions, handling logical channels, and transmitting APDU data effectively. It is particularly suitable for application developers focused on building secure NFC features, such as card simulation, who require a solid understanding of access control permissions and resource management within the HarmonyOS ecosystem. By following this guide, developers can ensure secure communication and proper resource handling in their applications.
