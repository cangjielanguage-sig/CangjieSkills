# 应用权限组列表

This directory serves as a centralized resource for HarmonyOS application developers, providing detailed reference documentation regarding system permission groups and specific requirements for multi-device collaboration. It encompasses a broad spectrum of functionalities, ranging from hardware access like Camera and Microphone to connectivity features such as Bluetooth, NearLink, and distributed data synchronization. The content explains the architectural logic behind permission grouping, where related permissions are requested together to optimize the user experience, and provides a comprehensive index of permissions necessary for communication and data sharing. This documentation is essential for developers aiming to implement robust features while adhering to system security protocols, ensuring that all necessary access rights are correctly declared and managed within their applications.

## Detailed Description

### 多设备协同_9more.md 多设备协同_9more.md
This document serves as a reference index listing required permissions for various HarmonyOS system features, specifically focusing on multi-device collaboration and communication capabilities. The main sections cover Multi-device Collaboration, Bluetooth, NearLink, Phone, Call Logs, Messages, Clipboard, Screen Capture, and File access. Key information includes direct links to detailed documentation for specific permissions like ohos.permission.DISTRIBUTED_DATASYNC, ohos.permission.ACCESS_BLUETOOTH, and ohos.permission.READ_MESSAGES, distinguishing between normal, system, and restricted permissions. This reference is intended for application developers needing to declare the correct access rights to enable connectivity, communication, and data sharing functionalities in their apps.

### 应用权限组列表_13more.md 应用权限组列表_13more.md
This reference document outlines the application permission groups available in the system, detailing the specific sub-permissions included within each group. It covers major categories such as Location, Camera, Microphone, Contacts, Calendar, Fitness, Body Sensors, Media, Audio, and Ad Tracking. A key concept explained is that permissions belonging to the same group are typically requested together via a single user authorization dialog, streamlining the user experience. Intended for application developers, this guide assists in understanding permission structures to ensure proper compliance with system authorization mechanisms and to facilitate accurate permission requests during app development.
