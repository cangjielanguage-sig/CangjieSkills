This directory serves as a comprehensive technical resource for the `cj-apis-emitter` project, specifically focusing on the `ohos.emitter` module designed for the Cangjie programming language. It provides essential documentation and structural code skeletons for implementing event-driven communication mechanisms within HarmonyOS applications. The content covers critical aspects such as event handling, dispatching, and prioritization across different threads or within a single execution context. Key components detailed here include event priority definitions, callback structures, and the core `Emitter` struct used for managing subscriptions and emissions. This documentation is primarily suitable for Cangjie developers utilizing the BasicServicesKit and SystemCapability.Notification.Emitter modules to build robust, responsive event-driven logic in HarmonyOS system version 12 or later. It acts as a vital guide for mastering the intricacies of the emitter pattern in this specific development environment.
