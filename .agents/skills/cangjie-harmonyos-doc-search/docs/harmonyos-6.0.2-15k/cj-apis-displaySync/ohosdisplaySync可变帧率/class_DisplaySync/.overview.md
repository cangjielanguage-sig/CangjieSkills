# class_DisplaySync

This directory contains essential API reference documentation for the `DisplaySync` class in the Cangjie programming language, designed specifically for the HarmonyOS operating system. It provides a detailed technical overview of configuring frame rates and managing callbacks within UI self-drawing scenarios, allowing developers to precisely synchronize custom rendering logic with the display's refresh cycle. The content covers critical system capabilities, including the requirement for `SystemCapability.ArkUI.ArkUI.Full`, and explains the usage of specific types like `OnOffType`, `IntervalInfo`, and `Callback1Argument` for robust event handling. Additionally, it addresses frame synchronization control through methods for defining frame rate limits and managing callback states. This documentation is highly suitable for HarmonyOS developers and software engineers working with the ArkUI framework who aim to optimize application performance and ensure smooth visual rendering in their projects.
