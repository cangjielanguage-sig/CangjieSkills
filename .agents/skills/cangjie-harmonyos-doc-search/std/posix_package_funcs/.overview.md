# posix_package_funcs

The `posix_package_funcs` directory serves as a comprehensive repository for documentation regarding POSIX-style system functions specifically implemented within the Cangjie programming language. This collection covers a wide array of low-level system operations, including but not limited to file manipulation (such as access, read, write, and open), process management (including getpid, kill, and nice), and the retrieval of system information. It is crucial to note that every function contained within this directory is explicitly marked as deprecated and is scheduled for removal in future versions of the language. Consequently, this resource is primarily suitable for Cangjie developers who are tasked with maintaining legacy codebases, seeking to understand historical low-level system interfaces, or actively planning the migration of existing projects to newer, stable, and non-deprecated APIs.

## Detailed Description

### 函数/
This directory contains the API reference documentation for a comprehensive set of POSIX-style system functions in the Cangjie programming language. It covers low-level operations including file manipulation (access, read, write, open), process management (getpid, kill, nice), and system information retrieval. A critical aspect of this collection is that every function listed is explicitly marked as deprecated and scheduled for removal in future versions. This documentation is suitable for Cangjie developers maintaining legacy code, understanding low-level system interfaces, or migrating existing projects to newer, non-deprecated APIs. The content serves as a vital guide for ensuring that developers are aware of the lifecycle of these system calls and can take appropriate action to modernize their codebases before these functions are permanently excluded from the language environment.
