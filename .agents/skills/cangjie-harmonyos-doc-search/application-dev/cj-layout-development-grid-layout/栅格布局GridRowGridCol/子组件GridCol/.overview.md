# 子组件GridCol

This directory serves as a comprehensive resource for the `GridCol` sub-component within the ArkUI framework, specifically tailored for developers using the Cangjie language. It provides in-depth technical documentation on essential grid layout properties, including `span`, `offset`, and `order`. The content covers how to manipulate column widths, adjust spacing relative to neighboring components, and control the visual arrangement sequence of child elements. A significant focus is placed on responsive design strategies, utilizing `GridColOptions` to adapt layouts across six distinct device breakpoints (xs, sm, md, lg, xl, xxl). Additionally, it explains the underlying 12-column grid calculation logic. This documentation is ideal for software engineers and UI developers seeking to create adaptive, robust, and responsive user interfaces in the ArkUI ecosystem.

## Detailed Description

### offset.md offset.md
This API documentation defines the offset attribute for controlling the column spacing of grid sub-components relative to their predecessors in ArkUI. The content covers two implementation types: using Int32 for uniform offsets and GridColOptions for responsive configurations across six device breakpoints (xs, sm, md, lg, xl, xxl). Key takeaways include understanding the 12-column grid calculation logic and viewing Cangjie code examples that illustrate how offsets determine component placement. This reference guide is intended for developers building responsive grid layouts using the ArkUI framework.

### order.md order.md
This reference documentation explains the order attribute used to control the arrangement sequence of child components within a grid layout system. It details sorting logic for default, mixed, and explicitly set values, distinguishing between Int32 for static ordering and GridColOptions for responsive breakpoints (xs to xxl). Key takeaways include that components without an order value appear first, followed by those with ascending values. The document provides Cangjie code examples demonstrating how to implement both static and device-specific sorting behaviors. This guide targets developers using the ArkUI framework and Cangjie language to build responsive user interfaces.
