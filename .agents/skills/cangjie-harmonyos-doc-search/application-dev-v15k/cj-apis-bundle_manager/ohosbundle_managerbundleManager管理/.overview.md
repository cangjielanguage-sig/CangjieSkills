# ohosbundle_managerbundleManager管理

This directory contains comprehensive API reference documentation for the HarmonyOS BundleManager framework in the Cangjie programming language. It covers the management of application bundles, abilities, extension abilities, permissions, and metadata. Key components include classes for querying bundle information, enumerations for defining component types and flags, and structures for configuration details like routing and dependencies. This documentation is essential for developers building applications on the HarmonyOS ecosystem who need to programmatically access system capabilities, manage application lifecycles, and configure component behaviors.

## Detailed Description

### class_DefaultAppManager.md class_DefaultAppManager.md
This document provides API reference for the `DefaultAppManager` class in Cangjie, designed to query default application capabilities. It focuses on the static method `isDefaultApplication` to determine if the app is the default handler for a type (e.g., images). It includes method signatures, parameters, return values, and error handling (codes 401, 801), along with system capabilities and code examples.

### class_Metadata_2more.md class_Metadata_2more.md
This API reference defines data structures for managing application metadata and signature information. It details the `Metadata` class for name-value pairs, `SignatureInfo` for security details, and `ModuleMetadata` for module-level data. It covers property definitions, data types, and read-write capabilities, intended for developers using the BundleManager framework on system version 12.

### enum_AbilityFlag_3more.md enum_AbilityFlag_3more.md
This document details enumeration types in Cangjie for the BundleManager framework. It covers `AbilityFlag` for filtering UIAbility info, `AbilityType` for classifying components (PAGE, SERVICE, DATA), and `ApplicationFlag` for app info retrieval criteria. It assists system developers in managing application and component metadata with API version 12.

### enum_ApplicationType.md enum_ApplicationType.md
This API reference documents the `ApplicationType` enum in Cangjie, categorizing default system applications like BROWSER, IMAGE, AUDIO, VIDEO, and document handlers. It includes the `getValue()` function and is associated with `BundleManager.BundleFramework.DefaultApp`. It targets developers working on system-level app management requiring API version 19.

### enum_BundleType_2more.md enum_BundleType_2more.md
This document defines enumeration types in Cangjie for the BundleManager framework. It covers `BundleType` (distinguishing standard apps from atomic services) and `CompatiblePolicy` (shared library version compatibility). It lists values like APP, ATOMIC_SERVICE, and BACKWARD_COMPATIBILITY, supported from system version 12.

It helps developers configure UI behavior within the BundleManager framework starting from version 12 or 19.
