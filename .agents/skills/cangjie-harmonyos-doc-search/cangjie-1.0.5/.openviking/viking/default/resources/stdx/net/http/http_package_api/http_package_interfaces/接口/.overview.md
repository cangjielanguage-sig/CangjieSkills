# 接口

本目录包含Cangjie语言HTTP服务器核心组件的API参考文档，主要定义了处理HTTP请求、路由分发、协议服务创建以及Cookie管理的关键接口。内容涵盖HttpRequestHandler、ProtocolServiceFactory、HttpRequestDistributor及CookieJar等核心模块，涉及请求处理流程、路由机制、多协议支持及安全状态管理。文档面向HTTP服务器开发者及网络编程人员，旨在提供构建高性能、安全HTTP服务所需的接口规范与实现指南。

## 详细描述

### interface_HttpReq_2more_e25e44df.md
本文档是Cangjie语言HTTP服务器的API参考文档，旨在定义处理HTTP请求及创建协议服务的核心接口。主要涵盖HttpRequestHandler接口及其handle方法，用于处理请求、构造响应和路由分发；以及ProtocolServiceFactory接口及其create方法，用于生成不同协议版本的服务实例。关键信息包括Handler需通过HttpRequestDistributor注册、需防范DNS重绑定攻击、Factory支持HTTP/1.1和HTTP/2.0协议。面向构建HTTP服务器的开发者，需具备Cangjie语言基础及网络编程知识。

### interface_HttpRequestDistributor.md
这是一份Cangjie语言的API参考文档，定义了HttpRequestDistributor接口，用于将HTTP请求按URL路径分发给对应的处理器。文档涵盖了接口的三个核心方法：用于注册处理器的register重载函数，以及用于根据路径查找处理器的distribute函数。关键信息指出默认实现非线程安全，且必须在服务器启动前完成注册，否则结果未定义。该文档面向HTTP服务器开发者，旨在指导如何实现和使用请求路由机制，涉及异常处理和线程安全注意事项。

### interface_CookieJar/
本目录包含Cangjie语言HTTP包中CookieJar接口的API参考文档，涵盖了HTTP Cookie的管理、存储、解析及清除等核心功能。文档详细介绍了接口定义、静态方法以及实例操作，严格遵循RFC 6265标准。内容包括Cookie的存储限制、清理策略、域名处理及安全属性配置。适合需要进行HTTP状态管理、网络编程的开发者阅读，帮助实现安全合规的Cookie存储与传输逻辑。
