This directory contains essential API reference documentation for the `initEventTarget` constructor within the Cangjie language and the ArkUI framework. It focuses on the technical specifications required to initialize complex gesture event objects programmatically. The documentation covers a wide range of input parameters, including timestamps, source types, pressure, tilt, axes, modifier keys, and physical metrics such as velocity, scale, and finger lists. It provides specific details for handling various gestures like Pan, Pinch, Rotation, and Swipe, as well as multi-touch tracking. This resource is designed for software developers and UI engineers working with the SystemCapability.ArkUI.ArkUI.Full module who need to implement sophisticated touch interactions and gesture recognition in their applications.
