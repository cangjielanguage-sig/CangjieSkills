This directory provides a comprehensive technical reference for `cj-actions-entities`, focusing on the definition and utilization of application capabilities within a specific configuration context. It primarily addresses the "skills" field of configuration files, offering detailed explanations of how to implement actions and entities. Actions are defined as operations—such as launching entry points, selecting resources, or viewing data—while entities serve to categorize components, including default types, home screen icons, and browsers. Although the documentation and the features it describes are currently marked as Beta and are not recommended for production deployment, this resource remains essential for developers. It is specifically suitable for software engineers and system integrators who are configuring application behaviors, managing inter-component communication, or require a deep understanding of the structural framework governing these capabilities. By mastering these definitions, developers can better control how their applications interact with the system and other components.
