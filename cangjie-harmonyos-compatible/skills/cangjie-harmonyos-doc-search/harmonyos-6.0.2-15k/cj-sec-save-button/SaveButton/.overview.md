# SaveButton

This directory contains comprehensive documentation for the SaveButton component within the ArkUI framework, specifically tailored for the Cangjie language. It covers the implementation of a specialized security control that enables users to grant temporary storage permissions through a single click, effectively bypassing standard system permission dialogs. The documentation includes detailed API references for component creation, definitions of basic enumeration types for styling and authorization results, and practical code examples for HarmonyOS applications. It is suitable for developers seeking to integrate secure saving interactions, customize button appearances (Capsule, Normal, Circle), and handle authorization results efficiently within their user interfaces.

## Detailed Description

### SaveButton_5more.md SaveButton_5more.md
This document serves as API reference documentation for the SaveButton component within the ArkUI framework, specifically for the Cangjie language. It describes a security control that allows users to obtain temporary storage permissions via a click, bypassing standard permission dialogs. The content covers component creation methods, including default initialization and constructors for customizing icons, text, and button types, as well as the onClick event callback. Key takeaways include the requirement for at least an icon or text, the default Capsule style, and the return of authorization results. This guide is intended for developers implementing secure saving interactions in their applications.

### 基础类型定义.md 基础类型定义.md
This API reference document defines basic enumeration types for configuring a Save Button component within the ArkUI framework using the Cangjie language. It details three primary enumerations: SaveIconStyle for visual styles, SaveDescription for text labels, and SaveButtonOnClickResult for handling authorization results. Key information includes specific values such as FullFilled and Lines for icons, various text options like SaveToGallery and Download, and status codes for success or failure. All definitions require SystemCapability.ArkUI.ArkUI.Full starting from version 20. This technical reference is intended for developers implementing save functionality in ArkUI applications.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the implementation and configuration of the SaveButton component within a HarmonyOS application. This practical reference is intended for HarmonyOS developers using the Cangjie language to integrate secure save controls into their user interfaces.
