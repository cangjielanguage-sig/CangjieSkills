# cj-permissions-for-all-user

This directory serves as a comprehensive technical resource for developers working with HarmonyOS permissions that require explicit user authorization. It focuses specifically on the `user_grant` permission model, detailing the necessary frameworks for requesting sensitive capabilities at runtime, with a particular emphasis on changes introduced in API version 12. Key topics covered include the `system_basic` protection level, device-specific constraints such as Tablet exclusivity, and the correct configuration within `module.json5`. This guide is essential for developers aiming to implement secure access to system features like screen capture, Bluetooth, and location services while strictly adhering to user privacy compliance standards and ensuring a seamless user experience across different devices.

## Detailed Description

### 开放权限用户授权/

This directory provides comprehensive documentation on HarmonyOS permissions that require explicit user authorization (`user_grant`). It serves as a critical guide for understanding the general framework required to request sensitive permissions at runtime, ensuring that applications interact with system capabilities securely and transparently. The documentation delves into specific permission definitions that were introduced or updated in API version 12, keeping developers current with the latest HarmonyOS standards.

A significant portion of the content is dedicated to the `system_basic` protection level, explaining how these permissions differ from others and the specific security implications they carry. It also addresses device-specific constraints, such as features that are exclusive to Tablet devices, helping developers tailor their applications for different form factors. Furthermore, the directory offers detailed instructions on the correct configuration within `module.json5`, which is a vital step for the system to recognize and grant these permissions correctly.

This resource is essential for developers who need to implement secure access to system capabilities like screen capture, Bluetooth, and location services. By following these guidelines, developers can ensure their applications function correctly while strictly ensuring compliance with user privacy requirements and maintaining user trust.
