This directory contains technical documentation for the ArkUI framework, specifically focusing on the initialization and configuration of custom dialog components. It covers the `CustomDialogOptions` constructor, layout parameters like alignment and offset, display modes, and detailed backplate styling rules including borders and visual effects. The content is intended for UI developers using the Cangjie language or ArkUI to build interactive interfaces. Key topics include lifecycle management, mask behavior, and precedence rules for styling properties, providing a comprehensive guide for creating polished, functional dialog windows.
