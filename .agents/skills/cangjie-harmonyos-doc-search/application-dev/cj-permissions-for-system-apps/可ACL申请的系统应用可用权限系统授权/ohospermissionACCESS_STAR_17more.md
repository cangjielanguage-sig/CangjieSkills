## ohos.permission.ACCESS_STARTUPGUIDE

允许系统应用访问开机向导应用的普通数据、普通公共事件。

仅手机、平板设备应用可申请此权限。

**权限级别：** system_basic

**授权方式：** 系统授权（system_grant）

**ACL使能：** true

**起始版本：** 18
