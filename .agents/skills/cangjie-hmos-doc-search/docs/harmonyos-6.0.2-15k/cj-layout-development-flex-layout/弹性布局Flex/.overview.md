# 弹性布局Flex

This directory provides a comprehensive guide to the Flex (Elastic) layout system within the ArkUI framework, specifically using the Cangjie language. It covers fundamental concepts like main and cross axes, layout directions, wrapping behavior, and adaptive stretching properties (flexBasis, flexGrow, flexShrink). Additionally, it details alignment mechanisms for both main and cross axes. This resource is suitable for HarmonyOS developers and UI designers seeking to master responsive interface design, precise element positioning, and space distribution using Cangjie and ArkTS.

## Detailed Description

### 场景示例.md
This document serves as a practical code example demonstrating how to implement a specific Flex layout scenario using the Cangjie language. The content focuses on configuring a Flex container to arrange child elements horizontally with space-between justification and vertical centering. Key information includes the use of FlexParams to define FlexDirection.Row, FlexAlign.SpaceBetween, and ItemAlign.Center, applied to three text elements with distinct styling. This tutorial is intended for developers working with the ArkUI framework in Cangjie who need to master layout alignment and spacing properties for user interface design.

### 布局换行.md
This document explains the wrapping behavior of Flex layouts in Cangjie development, specifically how the wrap property controls single-line versus multi-line arrangements when content overflows. It details three specific FlexWrap options: NoWrap (the default), Wrap, and WrapReverse. The text clarifies that NoWrap compresses child element widths to fit the container, while Wrap and WrapReverse create new lines arranged along the main axis or its reverse direction. Each concept is illustrated with executable Cangjie code snippets using FlexParams. This technical reference targets UI developers using the Cangjie language who need to manage layout overflow and alignment.

### 概述_3more.md
This document provides an overview of the Flex (Elastic) layout system within the ArkUI framework, explaining how to arrange, align, and distribute space for child elements effectively. It covers basic concepts such as the main axis and cross axis, and details layout directions including Row, RowReverse, Column, and ColumnReverse. The text defines axis terminology and illustrates how the direction parameter controls the arrangement of child elements, supported by Cangjie code examples and diagrams for each direction type. Intended for developers using the ArkUI framework and Cangjie language, this guide serves as a foundational reference for building responsive UI components like navigation bars and page frameworks.

### 自适应拉伸.md
This technical guide explains how to achieve adaptive layouts in Flex containers by configuring child element properties. It details three specific attributes: flexBasis for setting base dimensions, flexGrow for allocating remaining space, and flexShrink for handling space shortages. The document provides Cangjie code examples and mathematical breakdowns of how space is calculated based on these ratios, demonstrating how flexBasis overrides width and how flexGrow distributes space proportionally. It targets developers using the ArkUI framework and Cangjie language who need to create responsive user interfaces.

### 主轴对齐方式/
This directory serves as a comprehensive technical resource for understanding and implementing main axis alignment within Flex layouts across modern development environments. It specifically addresses the configuration of child element positioning using the `justifyContent` property, detailing how space is distributed between elements. The documentation covers a wide range of alignment modes, including Start, Center, End, SpaceBetween, SpaceAround, and SpaceEvenly, explaining the specific spacing logic and visual behavior for each. By providing executable code snippets and practical examples in both Cangjie and ArkTS, this collection assists developers in achieving precise and responsive UI layouts. It is highly suitable for UI developers, front-end engineers, and designers working with the Cangjie programming language or the ArkTS framework for HarmonyOS applications who need to master layout distribution and spacing control.

### 交叉轴对齐方式/
This directory focuses on the mechanisms of cross-axis alignment within layout systems, specifically utilizing the ArkUI framework and the Cangjie programming language. It covers the fundamental rules governing how parent containers and child elements interact regarding positioning, including the priority hierarchy where child settings override parent configurations. Key topics include `alignItems`, `alignSelf`, and `alignContent` for multi-line layouts. This documentation is designed for HarmonyOS developers and UI designers seeking to master precise control over component positioning, resolve alignment conflicts, and implement complex layout behaviors in their applications.
