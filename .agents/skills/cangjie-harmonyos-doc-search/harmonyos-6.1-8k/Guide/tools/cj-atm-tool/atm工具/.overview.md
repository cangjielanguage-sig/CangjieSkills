# atm工具

本目录包含 Access Token Manager (atm) 工具的参考文档，主要用于查询和设置应用进程的权限及访问控制信息。内容涵盖了环境准备、命令列表、参数说明以及权限授予与取消的操作指南。该工具目前处于 Beta 阶段，适合具备 hdc 工具使用经验的开发者、测试人员及系统维护人员，用于应用权限调试、进程属性查询及安全审计。核心关键词包括 atm、权限管理、tokenid、访问控制。
