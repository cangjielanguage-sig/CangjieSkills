# 栅格布局GridRowGridCol

This directory focuses on the Grid Layout system within the ArkUI framework using the Cangjie programming language. It covers the implementation of responsive and adaptive user interfaces using the `GridRow` container and `GridCol` child components. Key topics include the 12-column system, nested layouts, breakpoints, spacing (gutters/margins), and column spanning. This documentation is suitable for UI developers and software engineers aiming to build flexible, multi-device compatible application interfaces with structural regularity and unified positioning.

## Detailed Description

### 栅格组件的嵌套使用.md 栅格组件的嵌套使用.md
This tutorial explains how to implement nested grid layouts using GridRow and GridCol components in the Cangjie framework to achieve complex responsive designs. It covers the concept of nesting grids within a 12-column system, provides a complete code example demonstrating a multi-level layout with a main area split into left and right sections and a footer, and visualizes the result. The key takeaway is that child components inherit space from their parent GridCol, and the system allows flexible layout definition through parameters like Columns, Margin, Gutter, and span without worrying about specific device states. This guide targets Cangjie developers familiar with basic UI components who need to build advanced, responsive application interfaces.

### 概述.md 概述.md
This document provides an overview of the Grid Layout system, highlighting its utility in mobile interface design and multi-device adaptation. It details four primary advantages: providing structural regularity, ensuring unified positioning annotations, enabling flexible spacing adjustments, and supporting auto-wrapping with self-adaptation. The text specifies that the GridRow container component must be used in conjunction with the GridCol child component within grid layout scenarios. This guide targets UI developers and designers working with ArkUI who need to create responsive and consistent layouts across various devices.
