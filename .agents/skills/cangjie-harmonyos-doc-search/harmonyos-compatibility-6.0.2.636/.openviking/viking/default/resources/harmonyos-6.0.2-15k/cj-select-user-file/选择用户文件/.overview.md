# 选择用户文件

This directory contains technical tutorials for HarmonyOS developers focusing on file selection mechanisms using the Cangjie language. It covers how to access user files—specifically documents, audio, and media—without requiring complex permission applications. Key topics include using system pickers like DocumentViewPicker, AudioViewPicker, and PhotoAccessHelper, handling URIs with temporary read-only permissions, and reading file data via FileFs APIs. These guides are suitable for application developers building features that require file interaction, storage, or media playback on the HarmonyOS platform.

## Detailed Description

The following files provide specific implementation details for different file types:

### 选择文档类文件.md 选择文档类文件.md
This tutorial provides a step-by-step guide for HarmonyOS developers on selecting and reading document files using the Cangjie language. It covers importing required modules, configuring DocumentSelectOptions to filter file types, and utilizing the DocumentViewPicker to launch the file selection interface. Key steps include handling the returned URI, noting its temporary read-only permission, and using FileFs APIs to open and read file data via file descriptors. The guide is intended for developers building applications that require user file access and interaction.

### 选择用户文件_2more.md 选择用户文件_2more.md
This guide instructs developers on using the system FilePicker to select and save user files without applying for permissions. It details specific picker options including PhotoViewPicker, DocumentViewPicker, and AudioViewPicker, along with a dedicated section for image and video selection. Crucially, the document notes that the CoreFileKit PhotoViewPicker is deprecated and recommends using PhotoAccessHelper for media files. DocumentViewPicker manages generic files, while AudioViewPicker handles audio. This technical guide targets HarmonyOS developers implementing file sharing or storage features.

### 选择音频类文件.md 选择音频类文件.md
This tutorial guides developers on selecting audio files using the AudioViewPicker in the Cangjie language. It covers importing necessary modules, creating selection options, and invoking the picker interface to retrieve file URIs. Key information includes the fact that returned URIs possess temporary read-only permissions that expire when the app exits the background. The document further explains how to open files via URI to obtain a file descriptor (fd) and read data using the FileFs API. This guide targets application developers working with file systems and media playback on the HarmonyOS platform.
