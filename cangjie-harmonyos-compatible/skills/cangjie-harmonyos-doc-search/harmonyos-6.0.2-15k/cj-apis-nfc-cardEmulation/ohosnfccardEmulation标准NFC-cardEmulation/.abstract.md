This directory provides comprehensive API reference documentation for the `ohos.nfc.cardEmulation` module within the HarmonyOS ecosystem, utilizing the Cangjie programming language. It focuses on Host Card Emulation (HCE), enabling applications to emulate NFC cards without relying on a secure element. Key topics include module configuration, system capability verification, enumerations for card types and events, and the implementation of the `HceService` class for managing APDU commands. This resource is essential for developers building secure NFC applications, such as payment services, requiring knowledge of Cangjie and NFC protocols.
