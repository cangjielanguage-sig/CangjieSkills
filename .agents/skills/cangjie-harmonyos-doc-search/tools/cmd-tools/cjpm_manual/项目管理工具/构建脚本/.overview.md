# 构建脚本

本目录包含关于仓颉包管理器（cjpm）构建脚本机制的详细文档。它主要介绍了如何通过 `build.cj` 文件在命令执行前后定义自定义行为，涵盖了脚本结构、执行流程、支持的命令列表（如 build、test、clean）以及依赖管理。核心内容包括功能函数定义、日志重定向、多模块依赖处理及 `script-dependencies` 配置。该文档适合需要扩展构建流程的仓颉语言开发者阅读，帮助他们掌握如何利用构建脚本实现复杂的编译逻辑和自动化任务。

## 详细描述

### 构建脚本_1.md
这份文档介绍了 cjpm 构建脚本机制，旨在指导开发者如何在 cjpm 命令执行前后定义自定义行为。主要涵盖构建脚本 build.cj 的文件位置、代码模板结构、执行流程以及支持的命令列表（如 build、test、clean 等）。关键信息包括功能函数的返回值定义（0为成功）、日志重定向路径、多模块场景下的依赖处理以及 --skip-script 选项的使用。这是一份面向仓颉语言开发者的技术指南，帮助他们扩展构建流程。

### 构建脚本_2.md
本文档是一份关于Cangjie包管理器构建脚本的指南，旨在指导开发者如何编写和配置构建脚本。主要内容包括定义stagePreBuild和stagePostBuild函数以响应cjpm build命令，以及通过cjpm.toml中的script-dependencies字段管理构建脚本特有的依赖模块。关键信息在于构建脚本依赖与源码依赖相互独立，需分别配置。文档面向需要自定义构建流程的Cangjie开发者，要求具备基础的Cangjie语法和cjpm配置知识。
