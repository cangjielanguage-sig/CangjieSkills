# cj-camera-picker

This repository is a dedicated resource for developers working with the Cangjie programming language on the HarmonyOS platform, specifically targeting the integration of system camera capabilities. It provides a practical guide on how to invoke the native CameraPicker to handle photo and video capture tasks efficiently. A primary focus of this collection is demonstrating how to leverage system-provided interfaces to bypass the often tedious and complex permission application processes required for direct hardware access. The content covers crucial technical implementation details such as configuring `PickerProfile`, managing URIs for file storage, and handling UI state updates. This project is highly suitable for mobile application developers who need a reliable, code-driven reference to embed media capture functionality into their Cangjie applications without the overhead of low-level hardware control.
