# 基础类型定义

本目录包含ArkUI框架中用于列表组件的基础类型定义，主要涉及Cangjie语言下的API参考文档。内容涵盖了列表分割线的样式配置类（ListDividerOptions）以及列表项组的样式枚举（ListItemGroupStyle）。这些基础类型为开发者提供了自定义列表外观的底层参数支持，适用于使用Cangjie进行ArkUI应用开发并需要精细控制UI组件视觉表现的技术人员。

## 快速导航

- 你想自定义列表项之间的分割线外观吗？
  → 配置线宽、颜色及边距参数：class_ListDividerOptions.md
- 你想设置列表项组的整体卡片风格吗？
  → 选择无样式或默认卡片样式：enum_ListItemGroupStyle_b88e4bfc.md

## 详细描述

### class_ListDividerOptions.md class_ListDividerOptions.md
本文档是Cangjie语言中ListDividerOptions类的API参考文档，用于定义ListItem分割线的样式。文档详细介绍了类的属性，包括线宽、颜色、起始边距和结束边距，以及这些属性的构造函数。关键信息显示，构造函数中仅线宽为必填项，其余属性均为可选且可读写。该类属于ArkUI全功能系统能力，起始版本为22。文档主要面向使用Cangjie进行ArkUI应用开发的开发者，旨在提供自定义列表分割线视觉效果的参数配置指南。

### enum_ListItemGroupStyle_b88e4bfc.md enum_ListItemGroupStyle_b88e4bfc.md
本文档是ArkUI框架中ListItemGroupStyle枚举的API参考文档，旨在定义List组件的卡片样式配置。文档主要涵盖了枚举定义、两个核心枚举值（None表示无样式，Card表示默认卡片样式）以及相等与不相等比较操作符。关键信息指出该枚举继承自Equatable，支持系统全能力，起始版本为22。该文档面向使用仓颉语言进行UI开发的开发者，提供了具体的样式设置选项及比较逻辑，适用于需要自定义列表项组外观的场景。
