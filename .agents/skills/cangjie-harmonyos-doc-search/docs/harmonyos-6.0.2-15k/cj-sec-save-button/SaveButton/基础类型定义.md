## 基础类型定义

### enum SaveIconStyle

```cangjie
public enum SaveIconStyle {
    | FullFilled
    | Lines
}
```

#### FullFilled

**功能：** 设置保存按钮的图标风格。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 20

#### Lines

```cangjie
Lines
```

**功能：** 保存按钮展示线条样式图标。

**起始版本：** 20
