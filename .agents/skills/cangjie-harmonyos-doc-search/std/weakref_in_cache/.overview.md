# weakref_in_cache

This directory contains a technical tutorial focused on implementing a memory-efficient caching mechanism in the Cangjie programming language. It addresses the critical challenge of preventing Out of Memory (OOM) errors when storing expensive calculation results by utilizing `WeakRef`. The document provides a detailed walkthrough of defining a `Cacheable` interface, creating a `Data` class with a static recalculation method, and building a `Cache` class that manages data via `WeakRef` using `CleanupPolicy.DEFERRED`. Key learning points include the logic for checking reference validity, ensuring that if the garbage collector clears the cache, the system automatically recalculates the data. This guide is intended for Cangjie developers seeking to balance performance optimization with rigorous memory management in resource-intensive applications.
