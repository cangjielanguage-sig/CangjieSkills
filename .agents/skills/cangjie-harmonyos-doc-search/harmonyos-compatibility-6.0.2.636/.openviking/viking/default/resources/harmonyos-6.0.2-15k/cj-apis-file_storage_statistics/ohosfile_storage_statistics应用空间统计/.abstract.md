This directory provides comprehensive API reference documentation for the `ohos.file_storage_statistics` module within the Cangjie programming language environment, specifically tailored for HarmonyOS development. It focuses on the mechanisms required to query, monitor, and manage storage space on devices effectively. The content covers the definition of storage statistics data structures and the implementation of functions to retrieve specific storage metrics, such as application size, cache size, and total system capacity. Key topics include the `BundleStats` class, error handling, and system capability requirements. This resource is essential for Cangjie developers aiming to build storage-aware applications or implement features that require precise storage monitoring and management on the HarmonyOS platform.
