This directory provides comprehensive technical documentation for importing keys into the HarmonyOS Universal KeyStore (HUKS). It covers the mechanisms for both plaintext and encrypted key import, detailing the cryptographic algorithms (AES, RSA, ECC, ECDH, X25519) and data formats (X.509, Length-Data) required for secure key management. The content distinguishes between standard and lightweight device specifications, outlining security constraints and API level dependencies. It is suitable for security developers and OEMs implementing secure key transfer and storage solutions on HarmonyOS devices.
