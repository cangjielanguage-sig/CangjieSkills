# class_AbilityMonitor

This directory provides comprehensive API reference documentation for the `AbilityMonitor` class within the Cangjie language environment, specifically tailored for HarmonyOS developers. It focuses on the functionality required to match and monitor specific `UIAbility` objects during runtime. The documentation covers essential class constructors, identification properties like `abilityName` and `moduleName`, and a robust suite of callback functions. Key topics include tracking lifecycle events such as creation, destruction, foreground and background transitions, and window stage changes. This resource is ideal for application developers working with the SystemCapability.Ability.AbilityRuntime.Core system capability to manage ability states and behaviors effectively.
