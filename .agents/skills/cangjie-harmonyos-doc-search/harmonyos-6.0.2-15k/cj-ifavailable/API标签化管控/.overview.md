# API标签化管控

This directory focuses on API tagging and management within the Cangjie programming language, specifically utilizing the `@IfAvailable` attribute for fine-grained control. It covers techniques for conditional code execution based on API levels and System Capabilities (syscap) to ensure compatibility across diverse device configurations and system versions. Key topics include macro expressions, lambda usage, compile-time scope restrictions, and runtime behavior, including intersection and union rules for capability checks. It also addresses weak symbols and implicit package imports. This resource is suitable for Cangjie developers working in DevEco Studio who need to handle version compatibility, prevent compilation errors, and manage feature support efficiently in their applications.

### 概述_3more.md 概述_3more.md
This document serves as a technical guide for Cangjie developers, introducing the @IfAvailable macro expression used for fine-grained API usage control based on global labels. It details the syntax, requiring a label-value pair and two parameterless lambdas, and explains the semantic behavior where execution depends on runtime conditions. Key sections cover specific checks: level checks restrict API usage based on version hierarchy, while syscap checks manage device capability compatibility using intersection and union rules. The document highlights that symbols in the first lambda are weak and that specific packages are implicitly imported. Intended for developers managing API compatibility across different system versions and devices, this guide ensures proper API tagging and usage within DevEco Studio projects.
