# class_RefType

This directory contains comprehensive API reference documentation for the Cangjie language's Abstract Syntax Tree (AST) implementation, specifically focusing on type representation and tree traversal mechanisms. It details the `RefType` class, which is responsible for representing non-primitive type nodes, including custom types and built-ins like Array or String, along with their generic parameters. Additionally, it covers the `traverse` function, which enables developers to iterate over syntax tree nodes using the Visitor pattern. Key topics include type identifiers, generic arguments, AST manipulation, and static analysis. This documentation is primarily suitable for compiler developers, tool builders, and engineers performing code generation who need to understand and interact with the structural elements of the Cangjie language programmatically.
