This directory contains comprehensive API reference documentation for the `RandomAccessFile` class and its associated synchronous write functions within the Cangjie development environment. It focuses on providing developers with the tools necessary for performing random read and write operations on files, managing file descriptors, and controlling file pointers. Key topics include the instantiation of file objects, handling byte arrays and strings with UTF-8 encoding, and configuring write options for precise data manipulation. The documentation details essential methods such as close, read, and setFilePointer, alongside specific system capability requirements. This resource is suitable for software developers and system engineers looking to implement robust file management and I/O features in their Cangjie applications, offering detailed parameter insights and practical usage examples.
