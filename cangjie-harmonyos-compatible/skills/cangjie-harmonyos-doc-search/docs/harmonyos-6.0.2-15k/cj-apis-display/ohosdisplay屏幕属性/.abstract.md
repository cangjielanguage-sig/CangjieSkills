This directory contains API reference documentation for the `ohos.display` module in the Cangjie programming language, focusing on screen properties and window management within the HarmonyOS ecosystem. It covers a wide range of display features including screen geometry, cutout areas, waterfall displays, and foldable device characteristics like crease regions and display modes. The documentation also details event listeners for monitoring display changes and screen capture status. It is suitable for developers building applications that require advanced UI layout adaptation, multi-screen support, or specific handling for foldable hardware and complex screen shapes.
