# class_ResultSet

This directory provides API reference documentation for the `ResultSet` class in the Cangjie programming language, part of the HarmonyOS ArkData RelationalStore framework. It covers the complete lifecycle of handling query results, including cursor navigation, data type retrieval (String, Int64, Blob, Asset), metadata inspection, and resource management. The documents detail function signatures, system capabilities, parameters, return values, and comprehensive `BusinessException` error codes. This resource is essential for Cangjie developers who need to programmatically access, traverse, and manage data returned from relational database queries efficiently and safely.
