This directory contains comprehensive API reference documentation for the `ArrayList` class in the Cangjie programming language. It covers the implementation of a dynamic, resizable array structure, detailing class definitions, properties, initialization methods, and various manipulation functions. Key topics include memory management, sorting extensions, string conversion, and operator overloading. The documentation is intended for Cangjie developers seeking to implement or understand dynamic arrays, requiring knowledge of generic types and collection interfaces. It includes both current implementations and notes on deprecated sorting methods.
