This directory provides a comprehensive technical overview of the @Builder macro within the Cangjie UI framework, serving as a lightweight yet powerful mechanism for reusing UI elements. It abstracts UI components into custom build functions to streamline development. The content covers fundamental definitions, distinguishing between private and global functions, and delves into complex parameter passing rules, specifically the nuances between pass-by-value and pass-by-reference. It also addresses critical state management topics, such as using @Observed classes to ensure dynamic UI updates. Designed for developers proficient in Cangjie syntax and ArkUI, this guide offers practical code examples and advanced scenarios to help users optimize their declarative UI architecture, manage state synchronization effectively, and master intricate component interactions.
