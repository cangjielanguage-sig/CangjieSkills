This directory contains essential API reference documentation for the `AlertDialogButtonBaseOptions` class, a core component for developers building user interfaces with the Cangjie language and the ArkUI framework. It comprehensively covers the configuration, styling, and initialization of buttons within alert dialogs. The documentation details the class structure, highlighting seven key properties: `action`, `backgroundColor`, `defaultFocus`, `enabled`, `fontColor`, `style`, and `value`. Furthermore, it explains the constructor requirements, distinguishing between mandatory parameters like text content and optional settings such as color defaults. By defining data types like `ResourceStr` and `VoidCallback`, this reference guide is tailored for developers who need precise control over dialog button behavior, appearance, and user interaction, ensuring full compatibility with ArkUI system versions starting from 22.
