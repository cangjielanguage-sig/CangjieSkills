# 画布组件常用方法

本目录主要介绍ArkUI框架中Canvas组件的常用绘图方法与CanvasRenderingContext2D对象的使用。内容涵盖了基础几何图形（如arc、rect）的绘制、文本渲染（fillText、strokeText）以及渐变色填充（线性、径向）的实现。文档提供了ArkTS和仓颉（Cangjie）语言的代码示例，旨在帮助开发者掌握2D图形界面的核心绘图技巧，适合从事ArkUI应用开发并需要自定义图形绘制的开发者参考。

## 详细描述

### 画布组件常用方法_1.md 画布组件常用方法_1.md
本文档旨在介绍ArkUI画布组件的常用方法，重点讲解CanvasRenderingContext2D对象的使用。文档主要涵盖基础形状绘制和文本绘制两个部分，详细说明了如何使用arc、ellipse、rect等接口绘制几何图形，以及利用fillText和strokeText进行文本渲染。关键信息包括fill、stroke等核心绘图方法，以及fillStyle、globalAlpha等样式属性的配置。文档通过Cangjie语言代码示例演示了具体实现，适合使用ArkUI框架进行图形界面开发的开发者参考。

### 画布组件常用方法_2.md 画布组件常用方法_2.md
本文档旨在介绍Canvas组件中常用的文本绘制与渐变色填充方法，通过代码示例展示具体实现方式。主要涵盖文本填充与描边、线性与径向渐变色的创建及应用等核心绘图功能。重点展示了fillText、strokeText用于文本处理，以及createRadialGradient和addColorStop用于构建复杂渐变效果，并提供了ArkTS和仓颉（Cangjie）两种语言的代码实例。适用于ArkUI应用开发者，需具备基础组件布局和绘图上下文操作知识。
