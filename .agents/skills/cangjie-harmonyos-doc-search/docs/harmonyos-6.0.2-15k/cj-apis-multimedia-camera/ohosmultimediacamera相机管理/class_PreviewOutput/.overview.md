# class_PreviewOutput

This directory contains API reference documentation for the `PreviewOutput` class within the Cangjie CameraKit framework. It covers the management of camera preview outputs, including configuration, event handling, and resource management. Key topics include frame rate settings, image rotation, listener registration for frame and error events, and resource release. This documentation is intended for developers building multimedia applications in Cangjie who need to implement and control camera preview functionality. It assumes familiarity with application contexts, surface IDs, and event-driven programming.
