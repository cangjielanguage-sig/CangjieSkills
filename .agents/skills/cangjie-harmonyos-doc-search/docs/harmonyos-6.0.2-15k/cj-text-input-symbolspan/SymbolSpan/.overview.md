# SymbolSpan

This directory contains documentation and code examples for the SymbolSpan component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the integration of system-preset icon symbols into text interfaces, detailing initialization, property configuration, and visual customization. Key topics include rendering strategies, effect strategies, and font attributes. This resource is suitable for HarmonyOS developers and UI engineers looking to enhance their applications with rich, system-standard iconography using precise programmatic control.

## Detailed Description

### SymbolSpan_4more.md SymbolSpan_4more.md
This document serves as API reference for the SymbolSpan component, a child of the Text component used to display icon symbols within the ArkUI framework. It details the component creation process using the init method, which requires an AppResource parameter referencing system-preset symbols. Key information includes that SymbolSpan inherits properties from the parent Text component but does not support universal attributes or events directly. The documentation emphasizes that only system-preset symbol resources are valid. This reference is intended for developers using the Cangjie language to integrate system icons into text interfaces, specifically targeting system version 19 and above.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the implementation and customization of the SymbolSpan component in HarmonyOS applications. The code is organized into three distinct Row components, each showcasing a specific aspect of SymbolSpan: font weight variations (Lighter, Normal, Bold), rendering strategies (Single, Multiple Color, Multiple Opacity), and effect strategies (None, Scale, Hierarchical). It illustrates how to apply properties like fontWeight, renderingStrategy, and effectStrategy to system symbols (e.g., ohos_trash, ohos_wifi) to alter their visual appearance and behavior. This serves as a practical reference for HarmonyOS developers using the Cangjie language to build user interfaces with rich iconography.
