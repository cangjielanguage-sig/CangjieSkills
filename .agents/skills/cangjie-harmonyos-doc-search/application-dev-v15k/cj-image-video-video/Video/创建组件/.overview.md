# 创建组件

This directory contains API documentation for creating video components within the ArkUI framework using the Cangjie programming language. It focuses on the various initialization constructors available for configuring video playback, specifically detailing how to handle different video sources like AppResource and String paths. The documents cover parameters for playback speed (Float64 or PlaybackSpeed enum), preview URIs, and controller setup. It is suitable for HarmonyOS developers looking to implement video functionality, including handling network permissions and supported formats like mp4, mkv, and TS.

## Detailed Description

### initAppResource_Float64_Ap_2more.md initAppResource_Float64_Ap_2more.md
This API documentation details the initialization constructors for a video component in the Cangjie language, specifically handling AppResource sources. It covers two overloaded init methods that differ in how playback speed is defined, either via a Float64 value or a PlaybackSpeed enum. Key information includes the requirement for internet permissions when using network videos, support for mp4, mkv, and TS formats, and specific constraints on allowed playback speed values. Targeted at HarmonyOS developers, this reference guide assists in configuring video playback properties, controllers, and preview images within ArkUI applications.

### initAppResource_Float64_St_2more.md initAppResource_Float64_St_2more.md
This document provides API reference documentation for two overloaded constructors used to initialize a video component in the Cangjie programming language. It details the function signatures, parameters, required permissions, and system capabilities for creating video players. Specifically, it covers initialization using AppResource for the video source, with options for specifying playback speed via Float64 or PlaybackSpeed enum. Key parameters include src (supporting local rawfile and network resources), currentProgressRate (specific values like 0.75x to 2.0x), previewUri, and controller. Developers must request the ohos.permission.INTERNET permission for network videos. Supported formats are mp4, mkv, and TS. This reference guide targets HarmonyOS developers using ArkUI who need to implement video playback functionality.
