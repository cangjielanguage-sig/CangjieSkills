# cj-environment

本目录包含ArkUI框架中Environment单例对象的仓颉语言开发文档。它详细介绍了如何查询设备环境参数（如语言、深浅色模式、布局方向）以适配不同的应用场景。核心内容涵盖Environment内置参数列表、通过AppStorage访问环境变量的机制，以及`envProp`和`@StorageProp`的具体代码实现。本文档适合具备AppStorage基础知识的ArkUI开发者阅读，旨在帮助开发者实现根据系统环境动态调整应用界面的功能。

## 详细说明

### cj-environment.md cj-environment.md
本文档介绍了ArkUI框架中Environment单例对象的使用方法，旨在帮助开发者查询设备环境参数（如语言、深浅色模式）以适配不同场景。主要内容包括Environment内置参数列表（如colorMode、layoutDirection等），以及如何在UI组件和应用逻辑中通过AppStorage访问这些环境变量的使用场景。核心要点在于Environment属性不可变，需通过AppStorage获取；文档详细说明了从Environment到AppStorage再到Component的数据流向，以及使用envProp和@StorageProp的具体代码实现。面向使用仓颉语言的ArkUI开发者，阅读前需具备AppStorage相关知识，适用于需要根据系统环境动态调整应用界面的开发场景。
