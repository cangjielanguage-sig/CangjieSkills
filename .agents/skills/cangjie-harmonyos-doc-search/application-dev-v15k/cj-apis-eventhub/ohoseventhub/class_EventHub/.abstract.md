This directory contains API reference documentation for the `EventHub` class within the Cangjie language's AbilityKit framework. It serves as an abstract event management center designed for event-driven architectures in HarmonyOS applications. The documentation covers methods for creating, retrieving, and validating callback events with varying parameter counts (0 to 5). It includes details on generic types, system capabilities, and version 12 compatibility. This resource is suitable for Cangjie developers and HarmonyOS engineers looking to implement robust event handling and communication logic in their applications.
