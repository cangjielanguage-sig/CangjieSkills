# cj-apis-app-ability-want

This directory serves as a comprehensive resource for the `Want` class API within the HarmonyOS Cangjie SDK. It is designed to assist developers in mastering the mechanisms required for passing information between application components, a fundamental aspect of the HarmonyOS architecture.
