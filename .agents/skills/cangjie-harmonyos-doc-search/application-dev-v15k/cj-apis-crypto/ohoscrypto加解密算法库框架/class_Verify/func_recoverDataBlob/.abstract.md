This directory provides comprehensive documentation and resources for the `recover` function within the Cangjie CryptoFramework, designed to restore original data from signature data. It covers API specifications, raw RSA key data in DER format, and practical implementation examples. Key topics include DataBlob handling, signature recovery mechanisms, and asymmetric encryption operations. This content is suitable for developers and security engineers working with cryptographic algorithms, specifically those needing to implement or test data recovery and verification routines using RSA keys.
