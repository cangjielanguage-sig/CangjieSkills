# 组件事件

This directory provides comprehensive API references for handling component events within the ArkUI framework using the Cangjie language. It focuses specifically on the intricate event handling mechanisms required for text input components. The documentation covers a wide array of functionalities, including real-time text modification tracking, clipboard operations like copy and paste, scroll monitoring, and form submission logic. Additionally, it details interception events that allow developers to control text insertion and deletion. This resource is essential for software developers and UI engineers seeking to implement robust, interactive text controls with granular management over user input behaviors and system-level event responses.

## Detailed Description

### func_onChangeString_-_Unit_7more.md

This document serves as an API reference for text input event handling functions within the ArkUI framework using the Cangjie language. It details seven primary functions: `onChange`, `onContentScroll`, `onCopy`, `onCut`, `onDidDelete`, `onDidInsert`, and `onEditChange`. Each entry specifies the function signature, trigger conditions, callback parameters, and system capability requirements. Key information includes handling text modifications, clipboard operations, scroll offsets, and specific insertion or deletion events exclusive to system input methods. The documentation is intended for developers implementing interactive text components, providing necessary parameters like text content, cursor positions, and offset values to manage user input logic effectively.

### func_onPasteString_-_Unit_7more.md

This document serves as an API reference for input event handling within the Cangjie ArkUI framework. It details specific callback functions designed to manage user interactions with text input components. Key sections cover clipboard operations via `onPaste`, password visibility toggles, form submission handling with `onSubmit`, and text selection tracking. Additionally, it introduces interception logic through `onWillDelete` and `onWillInsert`, allowing developers to control whether text modifications proceed based on boolean return values. The documentation specifies system capabilities, starting versions, and parameter types for each event. This resource is intended for software developers building UIs who need granular control over text input behaviors and event responses.
