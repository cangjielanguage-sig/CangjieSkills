# tools

This directory serves as a centralized repository for a comprehensive suite of command-line tools designed for the OpenHarmony and HarmonyOS ecosystems. It covers a wide range of functionalities including application lifecycle management, system debugging, performance analysis, and resource handling. The collection includes essential utilities like the Bundle Manager (bm), HiLog, and HDC, alongside specialized tools for account management, power control, and media processing. These resources are primarily intended for developers, QA engineers, and system integrators seeking to streamline development workflows, diagnose system issues, and optimize application performance.

## Detailed Description

### [1] README_zh
This directory serves as a debugging command tool index center specifically designed for developers and testers. It aggregates multiple development and debugging tools in the Beta stage, aiming to help users quickly locate and access required system-level tools. The documentation covers a wide range, including independent functional tools such as aa, bm, cem, anm, restool, param, power-shell, atm, and acm, as well as file processing packing/unpacking toolsets, and general command-line toolsets integrating toybox, mediatool, and devicedebug. Given that all tools are in the Beta testing or development stage, this document specifically notes their status.

### [2] cj-aa-tool
This directory serves as a comprehensive knowledge base for the Ability Assistant (aa) tool, a critical command-line utility within the OpenHarmony application development framework. It provides extensive documentation designed to assist developers in understanding and utilizing the tool's capabilities effectively.

### [3] cj-acm-tool
This directory serves as a comprehensive repository for the `cj-acm-tool`, specifically focusing on the ACM (Account Management Tool) documentation. It provides a detailed guide for managing the lifecycle and permission constraints of local accounts via the command line.

### [4] cj-anm-tool
This directory contains documentation for the Advanced Notification Manager (anm) tool. This tool aims to provide developers with notification printing, parameter setting, and debugging/testing capabilities. The documentation details environment requirements, command lists, and highlights the usage of three core commands: help, dump, and setting. Content covers restrictions on supporting only the eng version, execution via hdc shell, and how to configure cache quantities and enable switches. This guide is suitable for developers who need to debug notification functions.

### [5] cj-app-check-tool
The `cj-app-check-tool` directory provides a robust scanning utility designed for the comprehensive analysis of application installation packages, specifically targeting HAP, HSP, and App pack formats. This tool is critical for developers aiming to maintain package integrity and compliance.

### [6] cj-atm-tool
This directory serves as a comprehensive repository for the Access Token Manager (atm) tool documentation. It focuses on providing essential guides for querying and configuring application process permissions and access control details within the system.

### [7] cj-bm-tool
