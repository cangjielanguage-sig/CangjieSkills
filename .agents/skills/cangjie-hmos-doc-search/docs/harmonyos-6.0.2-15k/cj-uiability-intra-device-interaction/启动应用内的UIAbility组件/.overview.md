# 启动应用内的UIAbility组件

This directory provides technical guidance on starting UIAbility components within the same HarmonyOS application. It covers the fundamental concepts of UIAbility as the system's smallest scheduling unit, detailing scenarios such as basic startup, launching specific pages, and retrieving return results. The content focuses on internal navigation logic, lifecycle management, and data exchange using the AbilityKit framework and the Stage model. It is suitable for HarmonyOS developers using the Cangjie language who need to implement complex component interactions and manage application processes effectively.

## Detailed Description

### 启动应用内的UIAbility组件.md 启动应用内的UIAbility组件.md
This technical guide explains the methods for starting UIAbility components within the same application, defining UIAbility as the system's smallest scheduling unit used for module navigation. The document covers three primary scenarios: basic startup, starting a component to receive return results, and launching a specific page within a UIAbility. It distinguishes intra-app navigation from inter-app jumps, focusing on internal functional interactions. Targeted at application developers using the AbilityKit framework, this guide provides essential instructions for implementing navigation logic and managing component lifecycles within HarmonyOS applications.

### 启动UIAbility的指定页面/

It comprehensively covers the mechanisms for both cold starts, which involve initializing a new instance, and hot starts, which resume an existing instance. Key topics include utilizing the Want object to pass routing parameters, managing lifecycle callbacks such as onCreate, onWindowStageCreate, and onNewWant, and implementing navigation logic via the Router module. This resource is specifically suitable for developers using the Cangjie language and the Stage model who need to manage precise navigation flows between application components.

### 启动应用内的UIAbility/
This directory provides comprehensive technical guidance for managing UIAbility lifecycles within the same HarmonyOS application using the Cangjie language. It covers essential operations such as initiating specific UIAbility components via the `startAbility()` method, configuring Want objects with parameters like bundleName and abilityName, and passing custom data between components. Additionally, it details how to terminate UIAbility instances and manage application processes using methods like `terminateSelf()` and `killAllProcesses()`. This resource is suitable for HarmonyOS developers working with the Stage model who need to implement multi-Ability navigation, handle parameter passing via JSON, and control application visibility and lifecycle events effectively.

### 启动应用内的UIAbility并获取返回结果/
This directory serves as a technical resource for HarmonyOS developers utilizing the Cangjie programming language within the Stage model. It focuses on the specific workflow of initiating an in-app UIAbility and subsequently retrieving return results, a critical pattern for applications requiring data exchange between distinct user interfaces, such as login screens or multi-step forms. The content covers the full lifecycle of this interaction, from the caller perspective using `startAbilityForResult` to the callee perspective using `terminateSelfWithResult`. Key technical concepts include the construction of `Want` objects for parameter passing, the management of asynchronous callbacks, the parsing of JSON data from results, and the proper handling of result codes. This guide is best suited for developers who have a foundational understanding of the AbilityKit framework and Cangjie syntax and are looking to implement complex, data-driven navigation flows in their applications.
