# cj-crypto-sm4-sym-encrypt-decrypt-gcm-by-segment

This directory serves as a specialized repository for the technical implementation of segmented encryption and decryption using the SM4 symmetric key algorithm, specifically operating within the GCM (Galois/Counter Mode) framework. The content is meticulously designed to address the complexities of processing large data volumes, utilizing advanced chunked processing techniques to optimize performance and memory efficiency. Built upon the robust foundation of the CryptoArchitectureKit, the code and documentation are exclusively tailored for the Cangjie programming language environment. It comprehensively covers critical operations such as SM4_128 key generation, precise GCM parameter configuration, and the management of authentication tags to ensure uncompromised data integrity. This directory is highly suitable for software developers and security engineers who are developing secure applications and require a deep understanding of high-performance cryptographic integration, particularly those navigating the Beta-phase implementations of the CryptoArchitectureKit.
