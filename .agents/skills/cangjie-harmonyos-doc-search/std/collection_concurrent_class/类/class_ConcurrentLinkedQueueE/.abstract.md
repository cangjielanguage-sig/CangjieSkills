This directory contains comprehensive API reference documentation for the Cangjie `ConcurrentLinkedQueue` class, a thread-safe, non-blocking collection specifically designed for high-concurrency scenarios. It covers class constructors, the non-atomic size property, and essential methods for element manipulation, with a specific focus on the `add` function for enqueuing. Key topics include the deprecation of legacy methods like `dequeue`, `enqueue`, and `head` in favor of `remove`, `add`, and `peek`, respectively. The documentation also explains the queue's utility in producer-consumer models and task scheduling. This resource is suitable for Cangjie developers who require knowledge of concurrent programming and generic collections to build efficient multi-threaded applications.
