This reference document outlines the rules for passing and accessing variables decorated with the @Prop macro within a component framework. It covers three main aspects: initialization from parent components, usage in initializing child components, and external access permissions. Key takeaways include that @Prop variables must be initialized by the parent upon instance creation and cannot be initialized internally. They support various parent source types like @State and @Link, but regular parent variables only provide initial values without triggering UI updates. Additionally, @Prop variables are strictly private to the component and cannot be modified by access modifiers. This guide is intended for developers managing state propagation and component interaction.
