# 拉起图片编辑类应用startAbilityByType

This directory provides a comprehensive guide for HarmonyOS developers on implementing image editing features using the `startAbilityByType` mechanism. It covers the entire workflow, from the host application invoking the editor to the extension application implementing the editing interface. Key topics include `PhotoEditorExtensionAbility`, lifecycle management, data passing via URIs, and saving edited PixelMap data. This resource is suitable for developers looking to integrate system-level image editing capabilities or create dedicated editor extensions using ArkTS or Cangjie.

## Detailed Description

### 使用场景_2more.md 使用场景_2more.md
This document outlines the usage scenario and API implementation for enabling image editing capabilities across applications using the PhotoEditorExtensionAbility. It covers the workflow where host apps invoke image editing panels via startAbilityByType and details the specific interfaces required for the extension. Key information includes how to register an editor page, load original images using onStartContentEditing, and save modified PixelMap data via saveEditedContentWithImage. This guide targets HarmonyOS developers who need to integrate image editing features into apps that lack native editing tools or are creating dedicated editor extensions.

### 图片编辑类应用实现图片编辑页面/
This directory provides comprehensive technical tutorials for implementing a photo editing page within HarmonyOS applications using the Cangjie language and DevEco Studio. It covers the end-to-end development process, starting with creating the `PhotoEditorExtensionAbility` and overriding lifecycle callbacks to building the user interface for image manipulation. Key technical topics include utilizing `onStartContentEditing` for page loading and data passing via `LocalStorage`, as well as persisting changes using `saveEditedContentWithImage`. Additionally, it addresses configuration requirements in `module.json5` and handling image packing options. These resources are specifically designed for HarmonyOS developers looking to integrate robust image editing capabilities, read images from URIs, and manage extension contexts effectively.

### 调用方拉起图片编辑类应用编辑图片/
This directory serves as a technical guide for developers seeking to implement image editing features by invoking a system image editing application from within their own app. It covers the end-to-end process, including selecting images from the gallery, copying them to a local sandbox, and launching the editor with specific parameters. Key technical concepts include URI conversion, permission management via flags, and the use of the `startAbilityByType` interface to interact with `PhotoEditorExtensionAbility`. The documentation explains how to handle callbacks to retrieve the edited image data. This content is specifically designed for HarmonyOS application developers using either Cangjie or ArkTS, providing the necessary instructions to seamlessly integrate system-level image editing capabilities into their software projects.
