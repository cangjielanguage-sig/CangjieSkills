### 使用3DES对称密钥ECB模式加解密仓颉_3more.md 使用3DES对称密钥ECB模式加解密仓颉_3more.md
This technical guide provides step-by-step instructions for performing 3DES encryption and decryption using the ECB mode and PKCS7 padding in the Cangjie programming language. The document is divided into two main workflows: Encryption and Decryption. Both sections detail the sequence of API calls required to process data. Key steps include generating a 192-bit symmetric key, creating a Cipher instance with the specification '3DES192|ECB|PKCS7', and initializing it with the appropriate mode. The guide highlights the use of `update` for large data segments and `doFinal` to finalize the operation, noting that ECB mode requires no additional parameters. This guide targets Cangjie developers implementing cryptographic security, specifically those utilizing the CryptoArchitectureKit for symmetric key operations.
