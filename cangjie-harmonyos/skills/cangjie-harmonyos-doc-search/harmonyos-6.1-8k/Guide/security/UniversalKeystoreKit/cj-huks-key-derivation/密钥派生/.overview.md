# 密钥派生

本目录主要介绍密钥派生相关的开发指南与实现案例，内容涵盖基于HKDF256算法的密钥派生操作、HUKS（HarmonyOS Universal KeyStore）密钥全生命周期管理（生成、派生、删除）以及使用仓颉语言的高级开发案例。核心关键词包括HKDF256、HUKS、密钥管理、仓颉。适用于需要进行安全开发、密钥生命周期管理及实现复杂加密算法的HarmonyOS开发者。

## 详细描述

### 密钥派生_6d1c6da2.md
本文档旨在介绍如何使用HKDF256算法完成密钥派生操作，并提供了相关场景及算法规格的参考链接。主要涵盖密钥派生的具体实现示例，以及通过链接跳转查看密钥生成支持的算法列表和详细规格。核心信息包括以HKDF256为例的派生流程，以及该功能目前处于Beta阶段，用户需查阅关联文档了解完整的算法支持情况。文档面向需要进行密钥管理的开发者，适用于需要通过主密钥生成子密钥的安全开发场景。

### 开发步骤.md
这份文档是HUKS密钥开发的操作指南，旨在指导开发者完成密钥的生成、派生及删除全流程。主要涵盖生成密钥时配置存储属性、通过会话接口（initSession、updateSession、finishSession）进行密钥派生，以及废弃密钥的删除步骤。文档重点阐述了派生密钥的存储管理方式（HUKS管理或导出）及其参数组合规则。本文档适合HarmonyOS安全开发人员，需了解基础密钥概念。关键词：HUKS、密钥生成、密钥派生、密钥删除、存储标志。
