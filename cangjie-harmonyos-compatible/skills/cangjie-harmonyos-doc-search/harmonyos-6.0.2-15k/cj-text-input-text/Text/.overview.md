# Text

This directory provides comprehensive documentation for the Text component within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers essential aspects of text display and interaction, including API references for initialization, event handling, component properties, and fundamental type definitions. The content ranges from basic text rendering to advanced features like subcomponents (Span, ImageSpan), data detection, and custom menus. It is suitable for HarmonyOS developers and UI engineers seeking to implement and customize text elements in their applications using declarative UI syntax.

## Detailed Description

### Text_4more.md Text_4more.md
This document provides API reference documentation for the Text component within the ArkUI framework, tailored for the Cangjie programming language. It outlines how to display text segments and supports subcomponents like Span, ImageSpan, and SymbolSpan. The main sections cover three distinct initialization methods: accepting application resources, string content, or a builder function for subcomponents. Key information includes parameter definitions for TextController and specific behaviors regarding content precedence when using Spans. The component supports all universal attributes and events. This guide is intended for developers building user interfaces, requiring knowledge of ArkUI and Cangjie syntax.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling text-related component events within the ArkUI framework using the Cangjie language. It details two primary event functions: onCopy, which triggers when text is copied via the clipboard, and onTextSelectionChange, which fires when text selection boundaries change. Key information includes the specific callback parameters for each function, returning the copied string or selection indices, alongside system capability requirements and version compatibility. This guide is intended for developers implementing interactive text features, requiring knowledge of Cangjie syntax and ArkUI components.
