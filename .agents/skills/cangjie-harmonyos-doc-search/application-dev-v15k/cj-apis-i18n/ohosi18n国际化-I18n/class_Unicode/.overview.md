# class_Unicode

This directory provides comprehensive API reference documentation for the `Unicode` class within the Cangjie LocalizationKit, focusing on character analysis and conversion mechanisms. It details a wide range of static methods used to inspect and classify characters based on specific properties. These methods are crucial for handling diverse language scripts and ensuring accurate text representation. Key functionalities include retrieving character types, validating digits, detecting ideographs, checking letter status, determining case (lower/upper), and identifying right-to-left (RTL) text orientation. Additionally, it covers utility functions for checking whitespace and space characters. The documentation includes detailed function signatures, parameter requirements, return types, and practical code examples. This resource is specifically intended for Cangjie developers, software engineers, and technical architects working on internationalization (I18n) and text processing who require precise programmatic control over string character validation and classification to build robust, language-aware applications.
