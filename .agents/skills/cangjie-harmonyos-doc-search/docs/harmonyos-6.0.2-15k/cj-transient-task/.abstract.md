This directory provides a comprehensive technical guide designed for HarmonyOS developers who are utilizing the Cangjie language to implement short-time background tasks, specifically known as transient tasks. The primary focus is on extending application execution for brief, yet critical, operations such as state saving or data synchronization. The content thoroughly covers the necessary constraints that developers must navigate, including specific application timing rules, daily usage quotas, and limits on concurrent tasks. Additionally, it offers detailed API descriptions for the full lifecycle of these tasks: requesting, querying, and canceling them. This resource is particularly suitable for developers who need to ensure their applications remain stable during brief background activities, handle timeout callbacks to prevent unexpected process termination, and strictly manage quota consumption to adhere to system policies.
