# cj-application-state-management-overview

本文档概述了框架中的应用级状态管理能力，旨在帮助开发者实现跨页面或整个应用的状态数据共享。文档涵盖了四种核心机制：用于UIAbility内页面间共享的LocalStorage、作为中央存储的AppStorage、用于数据持久化的PersistentStorage以及同步设备环境参数的Environment。重点介绍了如何通过AppStorage和PersistentStorage解决仅靠装饰器无法实现的跨页面状态共享及数据持久化问题。本文档适合需要实现复杂状态管理或数据持久化的应用开发者阅读，属于概念性参考文档。

## Detailed Description

### cj-application-state-management-overview.md

本文档概述了框架中的应用级状态管理能力，旨在帮助开发者实现跨页面或整个应用的状态数据共享。文档主要介绍了四种核心机制：用于UIAbility内页面间共享的LocalStorage、作为中央存储的AppStorage、用于数据持久化的PersistentStorage以及同步设备环境参数的Environment。关键点在于AppStorage作为单例对象提供中央存储，PersistentStorage配合其实现数据持久化，从而解决仅靠装饰器无法实现跨页面状态共享的问题。本指南面向需要实现复杂状态管理或数据持久化的应用开发者，属于概念性参考文档。
