This directory serves as a comprehensive resource for developers working within the Cangjie UI framework, specifically focusing on the implementation and utilization of the Toggle component. The content is designed to assist in creating interactive elements that allow users to switch between two distinct states, such as on/off or active/inactive. It provides detailed technical guidance on using various underlying types, including Button, Checkbox, and Switch, to construct these components. The guide covers essential aspects like constructor syntax, the integration of child components, and the customization of visual styles through properties like `selectedColor` and `switchPointColor`. Furthermore, it addresses the logic behind user interactions by explaining event handling via the `onChange` callback. To ensure practical understanding, the documentation includes a real-world example of a Bluetooth switch. This resource is best suited for Cangjie developers who already have a foundational understanding of UI syntax and state management and are looking to implement robust toggle controls in their projects.
