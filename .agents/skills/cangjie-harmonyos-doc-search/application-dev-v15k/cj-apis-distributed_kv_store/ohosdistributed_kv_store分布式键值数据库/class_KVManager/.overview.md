# class_KVManager

This directory contains API reference documentation for the `KVManager` class in the Cangjie programming language, specifically designed for managing distributed key-value database instances within the ArkData kit. It covers essential functionalities such as creating, retrieving, and closing database stores, as well as managing subscriptions to distributed data service status changes. Key topics include lifecycle management, error handling, and data synchronization reliability. This documentation is suitable for Cangjie developers who need to implement robust distributed data management and handle service lifecycle events in their applications.

### class_KVManager_4more.md class_KVManager_4more.md

The content is intended for developers using the ArkData kit who need to control the lifecycle of distributed databases within their applications.

### func_offDistributedDataSer_3more.md func_offDistributedDataSer_3more.md
This API reference document details methods for managing subscriptions to distributed data service status changes in Cangjie. It covers onDistributedDataServiceDie for subscribing to service termination events and two overloaded offDistributedDataServiceDie functions for removing specific or all subscriptions. Key information includes the requirement to re-register data change listeners upon service death and the use of the Callback0Argument parameter. All functions belong to the DistributedKVStore system capability and may throw parameter errors. This guide targets Cangjie developers working with distributed data management who need to handle service lifecycle events and ensure data synchronization reliability.
