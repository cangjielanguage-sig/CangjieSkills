This directory provides a comprehensive technical reference for the matching mechanisms of Explicit and Implicit Wants, which are fundamental to launching target application components within the system. It details the precise rules governing how parameters provided by a caller align with target component configurations to ensure successful invocation. The content distinguishes between the direct, deterministic nature of explicit matching and the flexible, capability-based nature of implicit matching. Core keywords include `bundleName`, `abilityName`, `action`, `entities`, `URI`, `type`, `module.json5`, and `skills`. This resource is essential for application developers, system integrators, and QA engineers who need to ensure correct component invocation, handle complex parameter passing, and implement reliable application routing. By mastering these mapping rules, developers can avoid common runtime errors and ensure their applications interact seamlessly with the system's intent resolution framework.
