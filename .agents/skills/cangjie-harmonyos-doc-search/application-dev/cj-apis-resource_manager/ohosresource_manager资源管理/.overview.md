### class_Configuration.md class_Configuration.md
This document provides API reference documentation for the Cangjie Configuration class, which represents the current state of a device. It details the class definition and its seven public properties: direction, locale, deviceType, screenDensity, colorMode, mcc, and mnc. Key information includes that all properties are readable and writable, covering aspects like screen orientation, language settings, and mobile network codes. The class belongs to the SystemCapability.Global.ResourceManager module starting from version 22. This reference guide targets software developers working with resource management in the Cangjie programming language who need to access or modify device configuration parameters.
