# cj-apis-componentutils

This directory contains essential API reference documentation for the `ohos.arkui.component_utils` module, a critical component for developers working with the Cangjie programming language in the HarmonyOS ArkUI ecosystem. It provides a detailed overview of utility classes and data structures necessary for querying and manipulating UI component geometric properties. The scope of this documentation includes handling component size, position, and various transformations such as translation, scaling, and rotation. Key components highlighted include `ComponentUtils` for retrieving metrics and result classes like `ComponentInfo`, `Offset`, and `RotateResult` that encapsulate layout data. This resource is specifically designed for HarmonyOS developers using Cangjie who require the capability to programmatically access, analyze, and modify UI component layout states and transformation matrices to achieve advanced interface manipulation and dynamic user experiences.

### ohosarkuicomponent_utilsComponentUtils/

This directory hosts the API reference documentation for the `ohos.arkui.component_utils` module. It is a specialized resource for the Cangjie programming language, designed to support the HarmonyOS ArkUI framework.

**Scope and Coverage:**
The documentation provides in-depth details on utility classes and data structures that are fundamental for querying and manipulating UI component geometric properties. It covers a wide array of attributes, including the basic size and position of components, as well as advanced transformations such as translation, scaling, and rotation.

**Key Components and Classes:**
A major focus is placed on the `ComponentUtils` class, which serves as the primary tool for retrieving component metrics. Additionally, the directory documents various result classes that are essential for handling layout data. These include `ComponentInfo`, `Offset`, and `RotateResult`, among others. These classes allow developers to encapsulate and interpret layout data effectively.

**Developer Utility:**
This documentation is highly suitable for HarmonyOS developers who utilize Cangjie. It is particularly useful for those who need to programmatically access and analyze UI component layout states. By understanding transformation matrices and geometric properties, developers can perform advanced interface manipulation, ensuring their applications are both dynamic and responsive to layout changes.
