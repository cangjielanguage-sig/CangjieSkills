## Detailed Description

### User_Authentication_Kit简介_2more.md User_Authentication_Kit简介_2more.md
This document introduces the User Authentication Kit, a system-level service enabling local user identity authentication via face, fingerprint, and password for sensitive operations. It covers the kit's definition, usage scenarios, and key features including unified interfaces, trust level perception, custom authentication, result reuse mechanisms, and credential change detection. Key takeaways include the normalized API for multi-modal authentication, the ability to specify trust levels to prevent low-security usage in high-risk scenarios, and support for reusing recent authentication results within five minutes. This technical overview targets developers integrating secure authentication into applications for scenarios like login and payments.

Keywords: User Authentication Kit, system-level authentication, biometric authentication, trust level, credential management, API reference

### 约束与限制.md 约束与限制.md
This document outlines mandatory usage constraints for third-party applications accessing system-level local identity authentication features. The content focuses on specific limitations regarding user interface implementation, emphasizing the requirement to utilize native system controls rather than custom solutions. The key takeaway is that third-party apps are strictly prohibited from using custom interfaces for local identity authentication; they must invoke the system's built-in authentication control to ensure security and consistency. This reference guide targets third-party application developers integrating local authentication capabilities, ensuring compliance with system security policies.

Keywords: third-party applications, local identity authentication, system controls, constraints, limitations, security policy, UI requirements

### 运作机制/
This directory provides a comprehensive technical overview of the operational mechanisms governing the Unified User Authentication Framework. It focuses on the architectural design, security protocols, and trust level classifications essential for building secure authentication systems. Key topics include the definition of Authentication Trust Levels (ATL) based on error rates (FRR, FAR, SAR), the issuance and structure of AuthTokens within a Trusted Execution Environment (TEE), and the integration with the Universal Keystore Service. The documentation addresses the critical balance between user convenience and high-level security, offering guidance for various scenarios ranging from low-risk personalization to high-security payments. This resource is specifically designed for developers, security architects, and system integrators who need to understand the underlying workflows, data structures, and security standards required to implement robust user authorization and key management solutions effectively.
