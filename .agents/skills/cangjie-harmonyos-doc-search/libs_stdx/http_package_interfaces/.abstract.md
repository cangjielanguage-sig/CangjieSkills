This directory functions as the definitive API reference documentation for the core interfaces comprising the Cangjie HTTP package. It is an essential resource for developers aiming to construct robust, high-performance HTTP servers and clients within the Cangjie ecosystem. The directory meticulously details the structural components necessary for effective network communication, ranging from high-level request routing to low-level protocol handling. It covers critical functionalities such as the `HttpRequestDistributor` for mapping URL paths, the `HttpRequestHandler` for executing request logic, and the `ProtocolServiceFactory` for enabling support for both HTTP/1.1 and HTTP/2.0 standards. Furthermore, it addresses the complexities of client-side state management through the `CookieJar`, ensuring compliance with RFC 6265. This documentation is specifically tailored for backend developers and software engineers who demand granular control over their application's network layer, security protocols, and data exchange mechanisms. By providing clear definitions and structural skeletons, this directory enables the creation of secure, scalable, and efficient web applications. Whether you are troubleshooting network issues or designing a new service from scratch, this documentation serves as a vital guide for mastering the Cangjie HTTP package's capabilities.
