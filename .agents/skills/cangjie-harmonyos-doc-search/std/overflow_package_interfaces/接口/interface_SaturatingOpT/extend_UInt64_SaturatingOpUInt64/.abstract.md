This directory provides API reference documentation for implementing the `SaturatingOp` interface and related arithmetic functions for the `UInt64` type in the Cangjie programming language. It focuses on saturating arithmetic operations, where results are clamped to the maximum or minimum values of the type to prevent overflow or underflow errors. Key topics include addition, subtraction, multiplication, division, modulo, negation, increment, decrement, and bitwise shifts. This documentation is suitable for Cangjie developers who need safe, boundary-checked mathematical operations to ensure predictable behavior in their applications.
