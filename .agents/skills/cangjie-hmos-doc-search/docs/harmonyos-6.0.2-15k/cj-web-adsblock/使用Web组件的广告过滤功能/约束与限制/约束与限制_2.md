- 在[WebviewController](../../../cj-apis-webview/.overview.md)类中，增加开启/关闭广告过滤特性的接口[enableAdsBlock()](../../../cj-apis-webview/.overview.md)，支持Web实例级的特性开关。
- 新增[AdsBlockManager](../../../cj-apis-webview/.overview.md)全局单例类，提供自定义广告过滤配置、控制网站级特性开关的能力。
- Web实例上提供了[onAdsBlocked()](../../../cj-web-web/.overview.md)回调通知方法，支持将拦截信息通知到上层应用。
- [AdsBlockManager](../../../cj-apis-webview/.overview.md)接口[setAdsBlockRules()](../../../cj-apis-webview/.overview.md)接口仅能设置一份自定义配置，此配置会持久化，应用冷启动无需重新配置，可避免每次冷启动配置规则都触发广告过滤配置的编译解析。
- [AdsBlockManager](../../../cj-apis-webview/.overview.md)接口[addAdsBlockDisallowedList()](../../../cj-apis-webview/.overview.md)、[removeAdsBlockDisallowedList()](../../../cj-apis-webview/.overview.md)、[clearAdsBlockDisallowedList()](../../../cj-apis-webview/.overview.md)、[addAdsBlockAllowedList()](../../../cj-apis-webview/.overview.md)、[removeAdsBlockAllowedList()](../../../cj-apis-webview/.overview.md)、[clearAdsBlockAllowedList()](../../../cj-apis-webview/.overview.md)操作的数据不会持久化，应用冷启动需要重新设置。
- 如果1个Web实例启用了广告过滤特性，但未调用[AdsBlockManager](../../../cj-apis-webview/.overview.md)接口[addAdsBlockDisallowedList()](../../../cj-apis-webview/.overview.md)、[removeAdsBlockDisallowedList()](../../../cj-apis-webview/.overview.md)、[clearAdsBlockDisallowedList()](../../../cj-apis-webview/.overview.md)、[addAdsBlockAllowedList()](../../../cj-apis-webview/.overview.md)、[removeAdsBlockAllowedList()](../../../cj-apis-webview/.overview.md)、[clearAdsBlockAllowedList()](../../../cj-apis-webview/.overview.md)配置disallowlist和allowlist数据，则默认所有网站均启用广告过滤。
- allowlist和disallowlist数据共同使用时，allowlist的优先级高于disallowlist，即先使用allowlist匹配，如果匹配成功就不再使用disallowlist匹配，该网站会启用广告过滤特性。
- 如果应用没有使能广告过滤特性，那么确保Web组件不会向服务器请求默认的内置easylist配置文件。
