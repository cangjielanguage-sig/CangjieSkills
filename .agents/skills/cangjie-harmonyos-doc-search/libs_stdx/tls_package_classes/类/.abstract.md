This directory serves as a comprehensive API reference for classes within the Cangjie programming language, specifically focusing on secure networking components. It provides detailed documentation for implementing Transport Layer Security (TLS) protocols, covering both session management and socket communication. The content includes essential functionalities such as secure connection resumption, server identity verification, encrypted data transmission, and connection metadata inspection. Designed for developers building secure network applications, this directory offers the necessary technical specifications to manage TLS handshakes, handle encrypted streams, and ensure robust authentication using the Cangjie standard library.
