# class_CertExtension

This directory provides comprehensive API reference documentation for the `CertExtension` class and related utility functions within the DeviceCertificateKit framework, tailored for the Cangjie programming language. It focuses on the intricate handling of X.509 certificate extension fields, offering developers the tools necessary to validate Certificate Authority (CA) status, retrieve serialized DER-encoded data, and access specific extension objects using Object Identifiers (OID). Beyond basic class methods, the documentation includes functions for managing OID lists and detecting unsupported critical extensions, which are crucial for maintaining security compliance. The content details parameter specifications, return types, and specific error codes for issues such as memory allocation failures or cryptographic errors. This directory is essential for software developers and security engineers who are building secure applications and require a deep understanding of certificate parsing and validation mechanisms in the Cangjie environment.

### class_CertExtension_4more.md
This document serves as API reference documentation for the CertExtension class within the DeviceCertificateKit, detailing methods to handle certificate extension fields in the Cangjie programming language. It covers the class definition and three primary functions: checkCA for validating CA status, getEncoded for retrieving serialized data, and getEntry for accessing specific extension objects via Object Identifiers (OID). Key information includes detailed parameter descriptions, return types, and potential BusinessException error codes related to memory, runtime, or crypto operations. Code examples demonstrate usage with DER-encoded data. The target audience is software developers implementing security certificate validation and parsing, requiring knowledge of cryptography concepts and the Cangjie language.

### func_getOidListExtensionOi_2more.md
This document provides API reference documentation for two Cangjie language functions within the DeviceCertificateKit used for managing certificate extensions. It details the getOidList function for retrieving object identifier lists based on type and the hasUnsupportedCriticalExtension function for checking unsupported critical extensions. Key information includes function signatures, parameters like ExtensionOidType, return values such as Array<DataBlob> or Bool, and specific error codes for parameter, memory, runtime, and crypto failures. The target audience is security developers using the SystemCapability.Security.Cert module who need to parse or validate certificate extensions.
