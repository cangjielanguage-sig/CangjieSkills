This directory serves as a comprehensive documentation hub for HiDumper, a unified command-line tool essential for developers and testers working within HarmonyOS and OpenHarmony environments. It provides detailed guidance on acquiring system information for deep analysis and debugging. The documentation covers a broad spectrum of functionalities, including retrieving system capabilities, capturing crash logs, monitoring network traffic, and analyzing storage I/O. Furthermore, it addresses performance monitoring through CPU usage and memory statistics, as well as Inter-Process Communication (IPC) data analysis. Advanced topics such as JavaScript heap analysis and garbage collection techniques are also included. This resource is specifically tailored for system developers, QA engineers, and administrators who require robust tools to diagnose system states, troubleshoot application crashes, and optimize overall system performance using the hdc environment.
