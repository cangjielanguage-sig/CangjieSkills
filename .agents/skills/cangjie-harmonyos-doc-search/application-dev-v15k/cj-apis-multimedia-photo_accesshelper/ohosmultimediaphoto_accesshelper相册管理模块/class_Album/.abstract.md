This directory provides comprehensive API reference documentation for the `Album` class within the Cangjie language, specifically tailored for HarmonyOS developers building media-rich applications. It focuses on the system's file management framework, detailing how to manage photo albums effectively. Key functionalities include accessing album metadata (such as names, types, URIs, and content counts), modifying album properties, and persisting these changes to the database using specific write permissions. Additionally, it covers methods for retrieving media assets like images and videos using fetch options. This resource is essential for developers utilizing the MediaLibraryKit who require programmatic control over photo library data, ensuring they can handle permissions, error codes, and data fetching efficiently in their applications.
