# cj-web-secure-shield-mode

本目录提供了关于“坚盾守护模式”的完整技术文档，这是一种专为高安全需求场景设计的系统级安全防护方案。该模式的核心机制在于严格限制设备功能及HTML5特性，从而有效防御潜在的远程攻击。文档内容涵盖了ArkWeb组件中被禁用的特性清单（包括WebAssembly、WebGL、JIT编译、getUserMedia等），并详细阐述了如何评估应用在此模式下的兼容性。此外，还提供了开启该模式的具体操作步骤，以及针对特定API调用问题的排查与调试建议。本指南主要面向应用开发者，旨在帮助其在高安全环境中识别并解决功能异常与性能瓶颈，确保应用的稳定运行。
