This directory contains essential API documentation for the `LengthProp` interface and its implementations in the Cangjie language, designed specifically for the ArkUI framework. It comprehensively covers extensions for both `Int64` and `Float64` types, enabling developers to seamlessly interpret numeric values as structured length units such as px, vp, fp, lpx, and percent. The documentation details read-only properties for accessing raw values and unit types, highlighting dependencies on SystemCapability.ArkUI.ArkUI.Full starting from version 22. This resource is highly suitable for ArkUI developers and Cangjie programmers who need to handle unit conversions, manage layout dimensions, and utilize length properties programmatically within their user interface designs. By defining clear interfaces for these types, the documentation ensures type safety and consistency in UI development workflows.
