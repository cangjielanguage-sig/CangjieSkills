# 在ArkTS应用中使用仓颉模块

This directory provides comprehensive resources for integrating Cangjie modules into ArkTS applications within the HarmonyOS ecosystem. It covers the fundamental architecture of the Cangjie language, emphasizing its lightweight runtime and high-concurrency capabilities, as well as practical implementation steps for cross-language interoperability. Key topics include using declarative interop macros, managing dependency configurations, and optimizing performance. This documentation is specifically designed for HarmonyOS developers and system architects using DevEco Studio who seek to leverage Cangjie's performance benefits within their ArkTS projects.

## Detailed Description

### 使用指导.md 使用指导.md
This guide provides instructions for integrating Cangjie modules into ArkTS applications using declarative interop macros. It covers adding Cangjie modules to ArkTS projects, implementing interop logic with the @Interop[ArkTS] macro, generating TypeScript declarations, and loading the module in ArkTS. Key information includes the requirement for API 12+ support, the automatic generation of dependency configurations in oh_package.json5, and the specific import syntax for loading the .so file. The document targets HarmonyOS developers using DevEco Studio who need to combine ArkTS and Cangjie code within a single project.

### 概述.md 概述.md
This document provides a high-level overview of the Cangjie programming language, focusing on its runtime environment and integration capabilities. It covers the lightweight runtime architecture, performance benefits in high-concurrency scenarios, and cross-language interoperability with ArkTS. The core takeaway is that Cangjie is designed for high performance and concurrency on a lightweight runtime. Crucially, it allows developers to embed Cangjie modules within ArkTS applications to enhance overall performance. This introductory text targets developers and system architects looking to understand Cangjie's architectural advantages and its role within the HarmonyOS ecosystem. Keywords: Cangjie, lightweight runtime, high concurrency, ArkTS interoperability, performance optimization.
