This directory focuses on implementing AES symmetric encryption in GCM mode with segmented processing using the Cangjie programming language. It covers the technical workflow for encryption and decryption, handling initialization vectors (IV), authentication tags, and chunked data processing via the CryptoArchitectureKit. Key topics include AES-128, PKCS7 padding, and secure data handling for large files. This resource is suitable for Cangjie developers and security engineers looking to integrate robust cryptographic features into their applications for secure data transmission and storage.
