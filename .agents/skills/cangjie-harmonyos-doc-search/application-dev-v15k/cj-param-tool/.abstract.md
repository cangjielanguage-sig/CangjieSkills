This directory contains the reference documentation for the `cj-param-tool`, a specialized command-line utility designed for developers to manage and operate system parameters on standard systems. It serves as a comprehensive guide covering environment prerequisites, a full command list, and detailed usage instructions for operations such as listing, getting, setting, waiting for, and saving parameters. Key features include filtering parameters by permissions, fuzzy matching during wait operations, and persisting specific parameters to the workspace. This resource is intended for developers who have access to the `hdc` tool and a connected device, providing essential commands for system-level configuration and debugging. It is a crucial resource for understanding the underlying parameter management mechanisms and ensuring correct system behavior during development and testing phases.
