This directory contains API documentation for the `Scroller` class within the ArkUI framework, implemented using the Cangjie language. It covers the controller interface for scrollable container components, detailing methods for programmatic scrolling, state management, and animation control. Key topics include basic scrolling operations (scrollTo, scrollBy), edge navigation, inertial fling, index-based navigation, and state queries like current offset and item positioning. This documentation is intended for software developers building UI applications who need to implement or manipulate complex scrolling behaviors in their interfaces.
