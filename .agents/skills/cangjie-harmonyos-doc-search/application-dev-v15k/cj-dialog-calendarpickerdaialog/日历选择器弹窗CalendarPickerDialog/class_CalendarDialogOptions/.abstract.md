This directory provides API reference documentation for the `CalendarDialogOptions` class within the Cangjie programming language and the ArkUI framework. It focuses on the configuration of parameters for calendar picker dialogs, covering class definitions, constructors, and properties such as button styles, background blur, and colors. The documentation details event callbacks like `onAccept` and `onCancel`, alongside dialog lifecycle events. It is intended for developers building UI components who need to customize the appearance and behavior of calendar dialogs, requiring knowledge of Cangjie syntax and ArkUI system capabilities.
