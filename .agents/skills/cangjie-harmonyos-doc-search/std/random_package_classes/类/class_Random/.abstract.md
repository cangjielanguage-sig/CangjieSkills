This directory provides API reference documentation for the `Random` class within the Cangjie standard library's `std.random` package. It covers the generation of pseudo-random numbers across various data types, including signed and unsigned integers, floating-point values, and byte arrays. The documentation details class constructors, seeding mechanisms, and methods for both uniform and Gaussian distributions. It is suitable for Cangjie developers implementing randomization logic, statistical simulations, or data generation, providing code examples and exception handling details to facilitate correct implementation.
