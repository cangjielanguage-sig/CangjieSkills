This directory contains API reference documentation for the core interfaces within the Cangjie programming language's SQL package. It covers essential components for database interaction, including connection management, query execution, transaction control, and result handling. Key topics include the `Connection`, `QueryResult`, `Transaction`, and `Statement` interfaces, alongside definitions for data types and metadata. This documentation is suitable for software developers and database engineers who are implementing or consuming database drivers in the Cangjie environment, providing the necessary specifications to build robust database applications.
