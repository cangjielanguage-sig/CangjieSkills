# 使用AES对称密钥CCM模式加解密仓颉

This directory offers comprehensive technical tutorials for implementing AES symmetric encryption and decryption using CCM mode within the Cangjie programming environment. It covers the entire cryptographic workflow, ranging from key generation and cipher creation to initialization with `CcmParamsSpec`, data processing via `update` and `doFinal`, and authentication tag extraction. Key technical points include the use of AES128, the restriction that CCM mode does not support segmented operations, and the requirement for a 12-byte authentication tag for verification. These resources are specifically tailored for Cangjie developers utilizing the `CryptoArchitectureKit` who possess familiarity with cryptographic concepts and API references.
