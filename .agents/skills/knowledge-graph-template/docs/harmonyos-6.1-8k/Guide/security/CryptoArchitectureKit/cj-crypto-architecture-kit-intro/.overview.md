# cj-crypto-architecture-kit-intro

本目录包含 Crypto Architecture Kit 的介绍文档，这是一个专为开发者设计的密码学工具包，旨在提供加解密、签名等核心功能，并屏蔽底层实现差异以简化开发。内容涵盖了对称与非对称密钥的概念、密钥生成与加解密等核心能力，以及与 Universal Keystore Kit 的关系。该 Kit 特别适合需要集成密码学功能、处理临时会话密钥或自行实现密钥存储的开发者。请注意，该 Kit 不包含密钥管理功能，且存在仅支持 OpenSSL、不支持多线程等使用约束。

## Detailed Description

### cj-crypto-architecture-kit-intro.md cj-crypto-architecture-kit-intro.md

本文档全面介绍了 Crypto Architecture Kit 的功能与使用方法。该 Kit 提供了加解密、签名等密码学能力，通过屏蔽底层差异帮助开发者简化集成工作。文档详细阐述了对称与非对称密钥的概念、密钥生成及加解密等核心功能，并说明了该 Kit 与 Universal Keystore Kit 的关联及使用约束。重要提示：该 Kit 不提供密钥管理，需应用自行保管；当前仅支持 OpenSSL 引擎，不支持多线程操作，且部分算法不适用于高安全等级场景。本文档主要面向需要集成密码学功能的开发者，适用于临时会话密钥处理或自行实现密钥存储的场景。
