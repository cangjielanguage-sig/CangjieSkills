This directory serves as a practical resource for developers working with the Cangjie programming language, specifically focusing on system-level process management. It contains a detailed code sample that illustrates how to effectively manage subprocess operations using the language's standard library. The tutorial covers a wide range of essential topics, including how to launch processes within specific working directories, access vital process metadata such as Process ID (PID) and process name, and forcefully terminate running processes when necessary. Additionally, it addresses the complexities of handling standard output through the use of pipes. Designed exclusively for Linux environments, this guide is ideal for Cangjie developers aiming to implement sophisticated process control and inter-process communication (IPC) in their applications. Users should be aware that the examples provided are not compatible with Windows platforms and require a specific pre-existing directory structure to execute successfully. By exploring this content, developers will learn to utilize key functions like `launch`, `ProcessRedirect.Pipe`, and `wait` to build robust system tools. This overview highlights the practical application of these features in real-world scenarios, ensuring that developers can integrate these techniques into their own projects with confidence.
