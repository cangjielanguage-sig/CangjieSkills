This directory serves as a comprehensive technical resource for developers working with the Cangjie language and the HarmonyOS UI framework, specifically focusing on the integration of system-level credential management capabilities. It provides detailed guidance on implementing automatic username and password saving functionalities by leveraging the system Password Vault. The content thoroughly covers essential development scenarios, including user login and registration processes, with a strong emphasis on configuring input fields, handling auto-fill triggers, and ensuring strict security compliance. Key technical topics include `InputType` configuration, `enableAutoFill` settings, and the enforcement of password complexity rules. This resource is primarily intended for application developers who aim to significantly enhance user experience and security by ensuring their applications seamlessly support system password managers while adhering to necessary security constraints, such as lock screen requirements and character limits.
