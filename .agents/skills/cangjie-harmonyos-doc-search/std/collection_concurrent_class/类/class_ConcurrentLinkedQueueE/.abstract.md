This directory provides comprehensive API reference documentation for the Cangjie `ConcurrentLinkedQueue` class, a thread-safe, non-blocking queue specifically designed for multi-threaded environments. It covers the complete class definition, constructors, the `size` property, and key methods for element manipulation, including `add`, `dequeue`, `enqueue`, and `head`. The documentation emphasizes the queue's role in preventing data conflicts and deadlocks, while also noting the non-atomic nature of the `size` property and the deprecation of specific methods in favor of newer alternatives like `remove` and `peek`. This resource is essential for Cangjie developers implementing concurrent systems—such as producer-consumer models or task scheduling—who need precise technical details to manage shared data structures effectively and safely.
