This directory contains a technical tutorial focused on the implementation of dynamic loading capabilities within the Cangjie programming language. It provides a comprehensive, step-by-step guide for developers aiming to build modular applications where code can be loaded and executed at runtime rather than being statically linked. The guide covers essential technical procedures, including the creation of dynamic library modules and executables using the `cjpm` build tool. Furthermore, it explores the advanced use of reflection to interact with global variables dynamically. This resource is highly suitable for Cangjie developers who need to understand the intricacies of runtime library management, package initialization, and the `std.reflect` API to create flexible, extensible, and maintainable software systems.
