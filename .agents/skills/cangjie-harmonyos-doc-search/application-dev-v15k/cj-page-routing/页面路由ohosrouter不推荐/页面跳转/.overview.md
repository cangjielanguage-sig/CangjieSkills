# 页面跳转

This directory focuses on page navigation mechanisms within Cangjie application development. It comprehensively covers the Router module, detailing jump modes (pushUrl, replaceUrl), instance management (Standard, Single), and data passing between pages. Key topics include the 32-page stack limit, lifecycle management, and parameter retrieval using `getParams`. The content includes practical code scenarios for use cases like detail views and login flows. This resource is suitable for developers working with the Cangjie language and UIKit framework who need to implement robust navigation logic, manage page transitions, and handle data transfer in their applications.

## Detailed Description

### 页面跳转_1.md 页面跳转_1.md
This technical guide explains page navigation mechanisms using the Router module in Cangjie application development. It covers two jump modes, pushUrl and replaceUrl, which determine if the current page is preserved or destroyed, and two instance modes, Standard and Single, controlling page instance management. Key information includes the 32-page stack limit and the Router.clear method. The document provides four practical code scenarios demonstrating how to combine these modes for specific use cases like detail views, login flows, and single-instance pages. It targets developers implementing navigation logic and managing page lifecycles.

### 页面跳转_2.md 页面跳转_2.md
This technical tutorial explains how to pass and retrieve data during page navigation in Cangjie applications using the Router module. The document covers two primary operations: sending parameters via the params attribute in the Router.pushUrl method and receiving them using Router.getParams on the target page. Key takeaways include the specific syntax for passing a string parameter and handling the return type Option<String> when retrieving data. This guide is intended for developers familiar with Cangjie and the UIKit framework who need to implement data transfer between UI pages. Keywords: Cangjie, Router, page navigation, parameter passing, pushUrl, getParams, UIKit.
