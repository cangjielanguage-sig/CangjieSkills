This directory contains comprehensive API documentation for the `StructTypeInfo` class within the Cangjie programming language. It focuses on providing robust reflection capabilities, enabling developers to perform runtime type inspection on struct types. The content covers retrieving metadata for public constructors, instance variables, and static variables, as well as dynamic instance construction. It includes implementation notes regarding manual boxing and unboxing. This documentation is essential for developers who need to implement advanced type introspection, dynamic binding, or runtime type system manipulation in their Cangjie applications.
