# cj-crypto-asym-key-generation-conversion-spec

This directory serves as a comprehensive technical repository for specifications regarding the generation and conversion of asymmetric keys within the Cangjie framework. It encompasses a wide array of cryptographic algorithms, including but not limited to RSA, DSA, ECC, Diffie-Hellman, SM2, Ed25519, and X25519. The documentation provides in-depth details on implementation methodologies, distinguishing between string parameters and explicit key parameters, while also outlining supported key lengths and specific API version requirements (notably API 12+). This resource is primarily tailored for developers and security architects tasked with integrating cryptographic functions, offering essential guidance to ensure secure key agreement, robust digital signature implementation, and strict adherence to forward security and performance standards within the Cangjie ecosystem.

## Detailed Description

### 非对称密钥生成和转换规格/
This directory provides technical specifications for generating and converting asymmetric keys within the Cangjie framework. It covers a comprehensive range of cryptographic algorithms, including RSA, DSA, ECC, Diffie-Hellman, SM2, Ed25519, and X25519. The documents detail implementation methods using string parameters or explicit key parameters, supported key lengths, and API version requirements (specifically API 12+). Designed for developers integrating cryptographic functions, this reference guide ensures secure key agreement and digital signature implementation with forward security and performance considerations.
