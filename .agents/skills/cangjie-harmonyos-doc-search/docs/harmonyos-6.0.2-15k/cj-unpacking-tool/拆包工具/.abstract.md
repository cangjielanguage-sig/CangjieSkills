This directory contains comprehensive documentation for the HarmonyOS Unpacking Tool, a utility designed to decompress and analyze application packages such as HAP, HSP, and App files. It covers essential topics including command-line usage, Java API references for parsing, and detailed data structure definitions for configuration files. Key concepts include parsing modes, extraction of pack.info, and schema definitions for metadata, permissions, and distribution settings. This resource is suitable for HarmonyOS developers, application market builders, and tool engineers who need to inspect package structures or integrate parsing capabilities into their workflows.
