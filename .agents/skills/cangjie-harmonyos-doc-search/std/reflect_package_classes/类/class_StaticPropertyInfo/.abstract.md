This directory contains API reference documentation for the `StaticPropertyInfo` class within the Cangjie reflection system. It focuses on describing and inspecting static member property information at runtime. Key topics include accessing metadata such as names, types, annotations, and modifiers, alongside methods for retrieving and modifying static property values. The documentation also covers utility functions for hash generation and equality checks. This resource is suitable for Cangjie developers who need to introspect class structures and dynamically interact with static class members using reflection features.
