# 开发步骤

This directory serves as a comprehensive resource for developers focusing on Host Card Emulation (HCE) implementation within the HarmonyOS ecosystem. It provides step-by-step technical tutorials covering the entire development lifecycle for NFC-based card emulation features. The content is divided into two primary scenarios: foreground card swiping and background card swiping. Key topics include configuring `module.json5` for necessary permissions and AID groups, initializing and managing the `HceService`, and handling APDU command callbacks. The guides also detail lifecycle management, ensuring services are correctly started and stopped during application state changes. Designed for developers proficient in ArkTS or Cangjie, these documents offer the necessary code structures and configuration details to build robust applications capable of interacting with NFC readers seamlessly.

## Detailed Description

The following files provide in-depth technical instructions for each scenario:

### HCE应用前台刷卡.md HCE应用前台刷卡.md

This technical tutorial guides developers through implementing Host Card Emulation (HCE) for foreground card swiping in HarmonyOS applications. The document covers configuration steps in module.json5 for permissions and actions, followed by code implementation within the EntryAbility class. It details the lifecycle management of HCE services, specifically handling onForeground and onBackground events. Key takeaways include declaring the ohos.permission.NFC_CARD_EMULATION permission, initializing HceService, subscribing to APDU commands via callbacks, and managing AID lists. The code demonstrates how to receive commands and transmit responses like [0x90, 0x00]. Intended for HarmonyOS application developers with knowledge of NFC concepts and the Cangjie or ArkTS programming language.

### HCE应用后台刷卡.md HCE应用后台刷卡.md

This document serves as a technical tutorial for implementing Host Card Emulation (HCE) background card swiping functionality using the Cangjie language. It covers the essential steps including configuring NFC permissions and AIDs in module.json5, importing necessary modules, and verifying device capabilities. The guide details the process of subscribing to HCE APDU data, handling command reception and transmission, and managing the service lifecycle during application exit. Key takeaways involve setting up the HceService, defining callbacks for APDU commands, and ensuring proper resource cleanup. This content is intended for developers building NFC-based applications requiring card emulation features.
