This directory contains comprehensive documentation for the `ohos.font` module within the HarmonyOS ArkUI framework, specifically designed for the Cangjie programming language. It covers the management of custom fonts, system font enumeration, and detailed font configuration including fallback strategies and UI settings. Key topics include the `Font` and `FontInfo` classes for font registration and metadata retrieval, as well as advanced structures like `UIFontConfig` and `UIFontFallbackInfo` for system-level typography control. This resource is suitable for HarmonyOS developers and UI engineers looking to implement custom typography, query system fonts, or manage complex font rendering logic in their applications.
