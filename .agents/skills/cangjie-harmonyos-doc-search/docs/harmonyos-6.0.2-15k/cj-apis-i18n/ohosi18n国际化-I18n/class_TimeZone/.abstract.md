This directory contains comprehensive API reference documentation for the TimeZone class within the Cangjie LocalizationKit. It focuses on the essential methods required for managing, querying, and manipulating timezone information in Cangjie applications. The content covers retrieving system-supported timezone IDs, obtaining available zone city IDs, fetching localized city display names, and creating TimeZone objects. Additionally, it details advanced functionalities such as finding timezones via geographic coordinates and accessing instance methods for offsets and display names. The documentation specifies return types, parameters, and necessary system capabilities like SystemCapability.Global.I18n. This resource is suitable for Cangjie developers implementing internationalization features who need to handle complex timezone conversions, display formatting, and location-based services.
