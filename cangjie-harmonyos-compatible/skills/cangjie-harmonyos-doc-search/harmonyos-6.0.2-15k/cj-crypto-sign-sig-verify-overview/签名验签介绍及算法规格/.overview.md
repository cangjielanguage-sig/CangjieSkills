## Detailed Description

### DSA_3more.md DSA_3more.md
This technical reference document outlines the configuration parameters for DSA, SM2, and Ed25519 digital signature algorithms. It details how to construct specific string parameters by concatenating asymmetric key types and digests using a pipe symbol to define algorithm specifications. Key takeaways include DSA's support for various key lengths and digests, SM2's exclusive use of the SM3 digest, and Ed25519's simplified parameter structure. The document specifies API version 12+ compatibility and notes that DSA with NoHash does not support segmented signing. Intended for developers implementing cryptographic functions, this guide ensures correct algorithm instantiation and parameter formatting.

### ECDSA.md ECDSA.md
This document serves as a technical reference for implementing ECDSA (Elliptic Curve Digital Signature Algorithm) within a specific algorithm library framework. It details the string parameter format used to specify algorithm combinations and provides a comprehensive table of supported asymmetric key types and digest algorithms. Users must construct parameters using the format KeyType|Digest, such as ECC224|SHA256. The framework supports various curves including standard ECC sizes, BrainPool variants, and Secp256k1, compatible with API version 12+. A generic ECC type is available for key compatibility. This guide targets developers integrating cryptographic signatures who need to select appropriate curve and digest combinations.
