This directory contains technical documentation for asymmetric encryption and decryption algorithms within the Cangjie framework. It covers specifications for various algorithms, including SM2 and RSA, detailing encryption modes, padding schemes, and API compatibility. Key topics include algorithm parameter construction, digest algorithms, and ciphertext format conversion. This resource is suitable for Cangjie developers and security engineers looking to implement secure cryptographic operations, manage key configurations, and understand supported standards like GM/T 0009-2012.
