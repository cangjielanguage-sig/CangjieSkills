This directory focuses on implementing access control mechanisms based on device classification and data grading within the ArkData framework using the Cangjie language. It comprehensively covers the fundamental concepts of security levels—ranging from S1 to S4 for data and SL1 to SL5 for devices—and provides practical tutorials for applying these classifications to both relational and key-value databases. Key topics include security level configuration, cross-device synchronization rules, and data protection policies. This resource is suitable for Cangjie developers and system architects aiming to secure distributed applications by ensuring data only syncs to compliant devices.
