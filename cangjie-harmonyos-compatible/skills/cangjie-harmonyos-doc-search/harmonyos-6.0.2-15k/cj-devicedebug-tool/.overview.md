# cj-devicedebug-tool

This directory contains the essential documentation for the `cj-devicedebug-tool`, a specialized command-line utility tailored for developers who require advanced capabilities in managing application processes. The tool is specifically designed to interact with the Application Management Service (AMS) to send signals and terminate debug application processes. Within this directory, users will find a reference guide that explains the operational syntax, including the `devicedebug kill -<signal> <pid>` command, and outlines the necessary prerequisites, such as operating within the `hdc shell`. The documentation emphasizes that the tool is intended solely for debuggable applications and provides detailed error return values for scenarios involving invalid PIDs or non-debuggable targets. By supporting signals 1 through 64, this resource offers developers granular control for manual process termination during complex debugging and testing workflows. Core keywords associated with this tool include devicedebug, kill, signal, pid, debug, hdc, and process termination.
