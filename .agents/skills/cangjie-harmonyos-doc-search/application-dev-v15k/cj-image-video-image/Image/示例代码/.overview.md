# 示例代码

This directory contains a comprehensive collection of example code for the Cangjie programming language, specifically tailored for the HarmonyOS application development framework. It focuses extensively on the Image component, covering a wide range of functionalities from basic loading to advanced styling. Key topics include handling various image formats (PNG, JPG, SVG, GIF), implementing interactive events like onClick, applying color filters and matrix manipulations, and configuring visual properties such as objectFit, objectRepeat, and rendering modes. The examples also highlight state management with @State and resource referencing. This collection is highly suitable for developers who are already familiar with Cangjie syntax and UIKit basics and are looking to implement robust, dynamic, and visually appealing image components in their HarmonyOS applications.

### 示例1加载基本类型图片_3more.md 示例1加载基本类型图片_3more.md
This tutorial demonstrates how to use the Image component in the Cangjie programming language for HarmonyOS application development. It covers three main examples: loading basic image formats including PNG, GIF, SVG, and JPG, adding interactive events such as onClick and onFinish, and applying color filter effects. This tutorial targets Cangjie developers seeking to implement flexible and styled image components in their applications.
