# class_URL

This directory contains API reference documentation for the `URL` class in the Cangjie programming language, specifically within the `stdx.encoding.url` package. It covers comprehensive URL parsing, manipulation, and component access, including scheme, host, path, and query handling. The documentation details methods for resolving relative URLs, merging paths, and validating URL structures based on RFC 3986 standards. It also addresses security considerations regarding plaintext credentials. This resource is suitable for Cangjie developers who need robust tools for handling network resources, performing string-to-URL conversions, or programmatically manipulating URL components.

### func_resolveURLURL_2more.md func_resolveURLURL_2more.md
This document provides API reference documentation for the Cangjie programming language, specifically detailing methods within the URL class. It covers two main functions: resolveURL and toString. The resolveURL function generates a new URL instance by resolving a reference URL against a base URL according to RFC 3986 protocols, handling relative paths and query strings. The toString function returns the string representation of the URL, encoding the host name while using raw attributes for other components. Key information includes examples of URL resolution logic and the specific concatenation rules for string output. This documentation is intended for developers working with network resources in Cangjie who require precise URL manipulation and formatting capabilities.
