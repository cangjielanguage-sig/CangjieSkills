This document explains how to use PersistentStorage to persist UI state data across application restarts by synchronizing with AppStorage. It covers the overview of the persistence mechanism, the relationship between PersistentStorage and AppStorage, and specific limitations regarding data types and performance constraints. Key takeaways include that PersistentStorage relies on AppStorage for access, supports simple types and JSON-serializable objects but not nested objects, and performs synchronous disk writes. Developers should avoid persisting large datasets or frequently changing variables to prevent UI performance issues.
