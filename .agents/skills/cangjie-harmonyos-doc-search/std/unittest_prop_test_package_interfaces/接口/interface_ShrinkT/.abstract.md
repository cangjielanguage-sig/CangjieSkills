This directory contains API documentation for the `Shrink` interface in the Cangjie programming language, focusing on implementations that enable value reduction strategies for property-based testing. It covers the core interface definition and extensions for a wide range of data types, including collections like HashMap and Array, as well as primitive types such as integers, floats, and strings. These documents detail how the `shrink()` function generates iterables of smaller values to facilitate debugging and failure analysis. This resource is suitable for Cangjie developers working on testing frameworks or data manipulation libraries who need to understand how specific types support shrinking operations.
