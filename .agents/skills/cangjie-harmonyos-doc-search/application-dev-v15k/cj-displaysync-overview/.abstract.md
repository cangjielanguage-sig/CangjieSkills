This directory serves as a definitive guide for HarmonyOS developers aiming to master variable frame rate capabilities on Low-Temperature Polycrystalline Oxide (LTPO) screens. It addresses the critical technical challenge of balancing high-performance visual rendering with optimal power efficiency to extend battery life. The documentation provides a deep dive into the introduction of variable frame rates, detailing their practical application in diverse usage scenarios such as high-fidelity animations and standard UI drawing. Furthermore, it elucidates the complex operating mechanism that governs system decision-making and the distribution of frame rates across the display pipeline. The guide also outlines essential constraints related to hardware limitations that developers must consider. By leveraging specific APIs like `expectedFrameRateRange` and `displaySync`, developers can programmatically request desired frame rates. The system then collects these requests, evaluates them against power and performance metrics, and dynamically adjusts the hardware refresh rate. This resource is vital for those seeking to optimize app fluidity and energy efficiency.
