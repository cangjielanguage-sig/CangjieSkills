# class_HuksKeySize

This directory provides comprehensive API reference documentation for the `HuksKeySize` class within the HarmonyOS Universal KeyStore (HUKS) framework. It is dedicated to defining constant values for cryptographic key lengths across a wide range of algorithms, including RSA, ECC, AES, CURVE25519, DH, SM2, and SM4. Written specifically for the Cangjie language, these resources are critical for security developers who need to configure precise key generation parameters. The documentation ensures correct bit size specifications for hardware-backed key storage and encryption operations, strictly requiring the SystemCapability.Security.Huks.Core capability. It serves as a vital technical guide for implementing secure cryptographic standards in HarmonyOS applications, covering API version 22 and above, and facilitating the integration of robust security features into the system architecture.
