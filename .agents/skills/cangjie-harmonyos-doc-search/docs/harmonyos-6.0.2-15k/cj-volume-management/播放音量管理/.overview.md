# 播放音量管理

This directory serves as a comprehensive resource for developers working on audio functionality within the HarmonyOS environment, specifically utilizing the Cangjie programming language. It addresses the complexities of playback volume management by breaking down the architecture into three distinct layers: System, Application, and Audio Stream volumes. The documentation explains the multiplicative relationship between these layers and provides practical guidance on how to manipulate them. Key topics include monitoring system volume changes, understanding API limitations such as read-only access, and implementing precise volume control for audio streams using MediaKit and AudioKit. This collection is essential for software engineers and developers aiming to build robust multimedia applications with refined audio control capabilities.

## Detailed Description

The following files provide in-depth technical guidance on specific aspects of volume management, ranging from architectural concepts to code implementation.

### 播放音量管理_3more.md 播放音量管理_3more.md
This technical guide explains HarmonyOS playback volume management, detailing three volume types: System, Application, and Audio Stream. It defines their hierarchy and multiplicative relationship, where the final output depends on all three levels. The document provides Cangjie code examples for monitoring system volume changes via AudioVolumeManager, noting that API access is read-only for system volume. It explicitly states that application volume management is currently unsupported. This guide targets developers needing to implement audio control logic in HarmonyOS applications.

### 音频流音量.md 音频流音量.md
This document serves as a technical guide for managing audio stream volume in Cangjie applications. It details the implementation of volume control using the setVolume method across two primary interfaces: AVPlayer from MediaKit and AudioRenderer from AudioKit. Key takeaways include the specific volume range of 0.0 to 1.0, where 1.0 represents maximum volume, and the necessity of handling potential BusinessException errors during execution. The content provides complete code snippets for both scenarios. This guide is designed for software developers integrating audio playback or rendering features, requiring familiarity with Cangjie syntax and multimedia libraries.
