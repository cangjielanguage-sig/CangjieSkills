## Detailed Description

### Router切换Navigation_2more.md Router切换Navigation_2more.md
This guide instructs developers on migrating from the Router module to the Navigation component in Cangjie development to leverage enhanced animations and flexible stack management. It covers page structure differences, comparing Router's @Entry components with Navigation's split architecture of Navigation containers and NavDestination subpages. The document provides Cangjie code examples demonstrating how Router.pushUrl translates to NavPathStack.pushPath and how to handle navigation stacks using NavPathStack. It targets application developers seeking to modernize their routing logic for better multi-platform deployment and dynamic effects.

### 生命周期_5more.md 生命周期_5more.md
This technical guide details lifecycle management and routing capabilities for Router and Navigation components in the Cangjie UI framework. Main sections cover page lifecycle methods, transition animations, shared element transitions, cross-package routing, and route interception. Key information includes that Router uses pageTransition and sharedTransition, while Navigation relies on component events and geometryTransition. Navigation supports cross-package routing via pageMap, whereas Router requires manual implementation for route interception. The document targets developers building applications using the Cangjie language and ArkUI framework, providing code examples for implementation.

### 路由操作.md 路由操作.md
This technical guide details routing operations for Cangjie development, focusing on the global Router and the Navigation component's NavPathStack. It covers essential page management tasks like pushing, popping, replacing, and clearing pages, alongside methods to query stack size and parameters. The document further explains three approaches for child pages to access the NavPathStack: using @Provide/@Consume decorators, the onReady callback, or the global AppStorage. Targeted at HarmonyOS developers, this reference provides code examples for implementing flexible navigation logic and managing page states effectively.
