# class_LocationRequest

This directory provides comprehensive technical documentation for the `LocationRequest` class within the Cangjie language framework, specifically designed to assist developers in configuring parameters for location information requests. It covers a wide array of class properties such as priority, scenario, timeInterval, distanceInterval, and maxAccuracy, specifying their data types, default values, and valid input ranges. The documentation elucidates critical logic governing these parameters, including the rule that the scenario setting overrides priority unless set to UNSET, and the requirement for precise location permissions to enable maxAccuracy functionality. Furthermore, it provides recommended accuracy values tailored to specific scenarios like navigation or daily life. This resource is indispensable for developers implementing location services, requiring a solid grasp of Cangjie syntax and system capabilities to build robust, location-aware applications.
