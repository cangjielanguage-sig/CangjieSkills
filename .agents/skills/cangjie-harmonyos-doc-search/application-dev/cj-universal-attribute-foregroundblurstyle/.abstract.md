This directory provides the comprehensive API reference documentation for the `cj-universal-attribute-foregroundblurstyle` module, a specialized component of the Cangjie ArkUI framework. It is dedicated to the `foregroundBlurStyle` attribute, which enables developers to apply high-quality content blur effects to various UI components, thereby enhancing the visual depth and aesthetic quality of applications. The documentation covers the technical specifications required to implement these effects, including a detailed analysis of two overloaded function signatures that allow for flexibility between standard blur applications and highly customized visual configurations. By defining parameters such as `BlurStyle` and `ForegroundBlurStyleOptions`, the guide facilitates the creation of dynamic interfaces. Furthermore, it outlines essential system capability requirements, ensuring compatibility with framework versions starting from 22. This resource is indispensable for Cangjie developers and UI engineers who need to integrate advanced visual styling, method chaining, and precise parameter control into their development workflow.
