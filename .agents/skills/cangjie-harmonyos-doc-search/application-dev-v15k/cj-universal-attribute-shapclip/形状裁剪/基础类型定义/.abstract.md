This directory contains API reference documentation for fundamental shape classes within the Cangjie ArkUI framework. It covers the base class `ShapeAbstract` and its derived implementations like `CircleShape`, `RectShape`, and `PathShape`, alongside utility classes such as `ProgressMask`. These definitions are essential for creating geometric shapes used in clipping, masking, and custom drawing interfaces. The documentation targets UI developers working with ArkUI system capabilities, specifically those implementing visual effects and geometric manipulations in applications running on version 12 or later.
