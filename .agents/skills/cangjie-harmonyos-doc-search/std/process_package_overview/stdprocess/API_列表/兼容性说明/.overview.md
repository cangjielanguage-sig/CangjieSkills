# 兼容性说明

This directory provides comprehensive API reference documentation focused on process management and cross-platform compatibility. It details the `CurrentProcess`, `SubProcess`, and `Process` classes, outlining their members, methods, and specific behaviors across Linux, Windows, and macOS. Key topics include environment variable handling, standard I/O streams, process control functions, and critical deprecation notices for legacy APIs. The documentation guides developers on transitioning from deprecated classes like `CurrentProcess` to modern alternatives like `std.env` and `SubProcess`. It is essential reading for developers working on system-level operations who need to manage subprocesses, query process details, or ensure their code remains compatible with supported operating systems while adhering to the latest API standards.
