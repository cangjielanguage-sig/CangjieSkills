# 单一手势

This directory focuses on implementing single-hand gestures within the Cangjie UI framework. It covers essential interaction patterns including dragging, pinching, swiping, tapping, and long-pressing. The documentation provides API references, parameter configurations, and code examples for binding gestures to components like Text and Column. It addresses specific challenges such as gesture competition and conflict resolution. Suitable for Cangjie and HarmonyOS developers, these resources require a basic understanding of UI components and state management to build interactive user interfaces effectively.

## Detailed Description

### 拖动手势PanGesture.md 拖动手势PanGesture.md
This API documentation explains how to implement and configure the PanGesture for drag interactions in Cangjie applications. It details the constructor parameters including finger count, direction, and minimum distance, while providing a code example demonstrating how to bind the gesture to a Text component and update its position using event callbacks. Key takeaways include the default 5px trigger threshold and critical warnings about gesture competition with scrollable parent components like List and Grid. The document advises on resolving conflicts between parent and child gestures or between PanGesture and SwipeGesture. Intended for UI developers, this guide requires knowledge of Cangjie syntax and state management. Keywords: PanGesture, Cangjie, gesture recognition, touch events, UI interaction, gesture conflict.

### 捏合手势PinchGesture_2more.md 捏合手势PinchGesture_2more.md
This document serves as a technical guide for implementing multi-touch gestures, specifically pinch and rotation, within the Cangjie UI framework. It covers the PinchGesture and RotationGesture APIs, detailing their constructors, parameters such as finger count and distance or angle thresholds, and event callbacks like onActionUpdate. Key takeaways include understanding how to configure gesture sensitivity and bind these gestures to components like Column and Text to dynamically manipulate scale and rotation properties. The content provides runnable code examples demonstrating state management during gesture interactions. Intended for Cangjie developers building interactive user interfaces, this reference requires prerequisite knowledge of UI components and state variables.

### 滑动手势SwipeGesture.md 滑动手势SwipeGesture.md
This document provides API documentation and a usage example for the SwipeGesture component in the Cangjie language, detailing how to detect and handle swipe interactions based on finger count, direction, and speed. It covers the constructor parameters, a code example demonstrating gesture binding and state updates, and a note on gesture competition with PanGesture. Key takeaways include the default speed threshold of 100vp/s, support for logical operations on direction enums, and the specific trigger conditions that differentiate SwipeGesture from PanGesture. Intended for HarmonyOS developers using Cangjie, this guide requires basic knowledge of UI components and event handling. Keywords: SwipeGesture, Cangjie, HarmonyOS, gesture recognition, UI interaction, API reference.

### 点击手势TapGesture_2more.md 点击手势TapGesture_2more.md
This document serves as a technical reference and tutorial for implementing TapGesture and LongPressGesture in the Cangjie UI framework. It details the API constructors, parameters, and behaviors for recognizing single or multiple taps and long presses. Key information includes parameter definitions such as count for click frequency, fingers for touch points, and duration for press timing. The document provides runnable code examples demonstrating how to bind these gestures to Text components and handle callback events. Intended for Cangjie developers, this guide facilitates the creation of interactive user interfaces by explaining gesture recognition logic and event handling.
