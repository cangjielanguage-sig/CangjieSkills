This directory contains API reference documentation for the `JSValue` struct in the Cangjie programming language, specifically designed for ArkTS interoperation within the HarmonyOS ArkUI framework. It covers type conversions, data manipulation, object binding, and lifecycle management for JavaScript values. Key topics include type checking methods like `isNumber` and `isString`, casting functions such as `asObject` and `asBigInt`, and array/property manipulation. This documentation is suitable for developers working on cross-language integration between Cangjie and ArkTS, focusing on safe data handling and Napi capabilities starting from API version 13.
