# class_Display

This directory provides comprehensive API reference documentation for the Cangjie Display class, a critical component for modeling screen instances within the WindowManager system. It covers a wide array of hardware attributes, ranging from device identification and physical dimensions to density metrics, refresh rates, and advanced capabilities like color spaces and HDR formats. Furthermore, it includes details on screen rotation, scaled density, display states, and methods for identifying non-usable regions such as notches. This documentation is specifically designed for developers working on window management features who need to query hardware display states and adapt application layouts to specific hardware configurations.

## Detailed Description

### class_Display_13more.md
This document serves as API reference documentation for the Cangjie Display class, which models screen instances within the WindowManager system. It details a comprehensive set of read-only properties that describe display attributes, including device identification, physical dimensions, density metrics, refresh rates, and supported capabilities like color spaces and HDR formats. Key information includes the requirement to obtain a Display instance via specific methods before accessing properties such as orientation, densityDPI, and available dimensions for 2in1 devices. This guide is intended for developers working on window management features who need to query hardware display states and configurations.

### prop_rotation_8more.md
This document serves as an API reference for managing display device properties and screen metrics in the Cangjie programming language. It details read-only properties such as screen rotation angles, scaled density, display state, width, and physical pixel density (xDPI, yDPI). Additionally, it documents functions for retrieving the available screen area on 2in1 devices and identifying non-usable regions like cutouts or notches. Key information includes data types, version requirements, and specific error codes for exceptions. This guide is intended for developers needing to adapt application layouts to specific hardware display configurations.
