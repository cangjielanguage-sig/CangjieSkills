This directory contains API reference documentation for the TelephonyRadio class and related static functions within the TelephonyKit in the Cangjie programming language. It covers functionalities for managing and querying telephony network states, including retrieving ISO country codes, network selection modes, operator names, and radio technology details. Key topics include signal strength monitoring, 5G New Radio capability checks, and radio power status. The documentation is designed for Cangjie developers and system integrators working on HarmonyOS applications who need to access device network capabilities, SIM card information, and radio configurations with proper permission handling.
