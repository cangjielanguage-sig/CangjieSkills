# Regex_示例

This directory acts as a specialized guide for Cangjie developers, providing practical examples and tutorials focused on the implementation and optimization of regular expressions. It covers the essential usage of the MatchData class for handling capture groups, iterating through results, and extracting specific string positions. Beyond the basics, it explores advanced regex features such as case-insensitive matching, multi-line pattern support, and Unicode character handling. The content also includes methods for string manipulation, including find-and-replace operations with specific scope control. These resources are specifically designed for programmers who need to parse structured text, validate complex data patterns, or perform sophisticated text processing tasks using the Cangjie standard library. The directory is structured to help users quickly locate solutions for specific regex challenges, ranging from basic data extraction to complex text substitution.

## Detailed Description

### MatchData_中捕获组的使用.md MatchData_中捕获组的使用.md
This document serves as a practical tutorial for Cangjie developers, demonstrating how to utilize the MatchData class to handle regex capture groups. The content illustrates iterating through matches using lazyFindAll, accessing group counts, and retrieving both the content and position of numbered and named groups. Key takeaways include the usage of matchString and matchPosition methods for data extraction and the getNamedGroups function for mapping names to indices. This guide is intended for programmers seeking to parse structured text patterns within the Cangjie standard library environment.

### Regex_匹配大小写_5more.md Regex_匹配大小写_5more.md
This document serves as a practical tutorial for using regular expressions in the Cangjie programming language, specifically focusing on advanced matching modes and string manipulation. It covers case-insensitive matching using IgnoreCase, multi-line pattern matching with MultiLine, Unicode character support via the Unicode flag, extracting match details with MatchData, and performing string replacements using replace and replaceAll.
