# 拆包工具信息字段

This directory contains technical reference documentation for data structures used in HarmonyOS application unpacking and parsing tools. It covers schema definitions for configuration objects within HAP packages, including application metadata (`AppInfo`), component capabilities (`AbilityInfo`, `ExtensionAbilityInfo`), and distribution settings (`Distro`). The documents detail field attributes, data types, and model-specific constraints (FA vs. Stage models). It is suitable for developers, system architects, and tool creators who need to understand the internal structure of application bundles for analysis, debugging, or building parsing utilities.

## Detailed Description

### AbilityFormInfo结构体信息.md AbilityFormInfo结构体信息.md
This document provides a technical reference for the `AbilityFormInfo` structure, defining configuration properties for application forms or cards. It covers identification, refresh mechanisms, visual dimensions, and window settings, including specific rules for the `providerAbility` field across FA and Stage models. It is designed for HarmonyOS developers configuring form metadata to ensure proper widget behavior.

### AbilityInfo结构体信息.md AbilityInfo结构体信息.md
This document defines the structure and attributes of the `AbilityInfo` component. It covers fields for identification, configuration, permissions, and UI properties. It details data types, Stage model compatibility, and boolean flags for features like Picture-in-Picture. Intended for developers configuring application abilities and their metadata.

### AppInfo结构体信息.md AppInfo结构体信息.md
This document defines the `AppInfo` data object structure. It details application identity fields (bundle name, vendor), versioning, display properties, and build configurations. Key takeaways include bundle types (app, atomic service, shared) and API 10 constraints. It aids developers in understanding application metadata for packaging and deployment.

### CommonEvent结构体信息_6more.md CommonEvent结构体信息_6more.md
This document defines data structures for configuring application components within the Stage model. It details field attributes for CommonEvent, DependencyItem, ModuleAtomicService, PreloadItem, DeviceConfig, and DefPermission. It serves as a schema guide for static public events, dependencies, and security permissions.

### DefinePermission结构体信息_5more.md DefinePermission结构体信息_5more.md
This document defines the schema for DefinePermission, DefPermissionsGroups, FormInfo, ModuleMetadataInfo, and ModuleWindowInfo. It covers permission management attributes like grant modes and distributed scene support, alongside UI specifications for forms and windows.

### Distro结构体信息_7more.md Distro结构体信息_7more.md
This document defines data structures used in application configuration files, mapping to Stage and FA models. It details Distro, MetaData, ReqPermission, UsedScene, and Shortcut structures, highlighting distinctions between models and permission request configurations.

### ExtensionAbilityInfo结构体信息_3more.md ExtensionAbilityInfo结构体信息_3more.md
This document defines data structures for ExtensionAbilityInfo, SkillInfo, and UriInfo within the Stage Model. It details attributes for extension capabilities, permissions, visibility, and supported types, alongside intent handling and URI configuration.

### HapInfo结构体信息.md HapInfo结构体信息.md
This document defines the structure and fields of the `HapInfo` class. It details application model types (FA and Stage), package information, abilities, and permissions. It distinguishes between FA and Stage specific fields for HAP package composition.

### IntentInfo结构体信息_7more.md IntentInfo结构体信息_7more.md
This document defines data structures for IntentInfo and DistroFilter, used for managing shortcuts and distribution filtering. It details the IntentInfo structure and the DistroFilter schema, which uses policy strings and value lists for matching rules.

### UncompressResultBundle信息结构_3more.md UncompressResultBundle信息结构_3more.md
This document defines data structures for the UncompressResult object returned during bundle parsing. It details the UncompressResult wrapper, PackInfo for package details, and ProfileInfo, including parsing success flags and references to AppInfo and HapInfo.
