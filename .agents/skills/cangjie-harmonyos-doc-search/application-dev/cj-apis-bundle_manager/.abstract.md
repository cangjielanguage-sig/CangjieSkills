This directory serves as a comprehensive API reference for the Cangjie programming language's BundleManager framework within the HarmonyOS/OpenHarmony ecosystem. It focuses on the structural definitions and interfaces required for managing application bundles, metadata, permissions, and system capabilities. Key areas include bundle information retrieval, ability configuration, window management, and extension types. This documentation is designed for Cangjie developers and system integrators who need to programmatically access and manipulate application lifecycles, permissions, and component states to build robust system-level applications. By providing detailed insights into module loading and component interaction, this resource enables the creation of sophisticated software that leverages the full power of the HarmonyOS architecture. It is an essential guide for anyone looking to master the intricacies of application management in a distributed operating system environment.
