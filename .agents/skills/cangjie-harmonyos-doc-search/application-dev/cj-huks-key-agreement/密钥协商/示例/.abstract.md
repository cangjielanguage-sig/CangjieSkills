This directory contains technical examples and tutorials for implementing cryptographic key agreement protocols using the HarmonyOS Universal KeyStore (HUKS). It covers X25519 and Diffie-Hellman (DH) algorithms, demonstrating workflows for key generation, session management (init, update, finish), and key export or storage. The examples are written in Cangjie and ArkTS, providing practical guidance for developers integrating secure key exchange and management into HarmonyOS applications. Core topics include HUKS parameter configuration, data type conversion, and error handling. This content is suitable for HarmonyOS developers and security engineers looking to implement robust cryptographic solutions.
