This directory contains API reference documentation for concurrent classes within the Cangjie standard library. It focuses on thread-safe data structures designed for high-concurrency scenarios, including various implementations of maps and queues. The documentation covers class definitions, initialization, atomic operations, and element manipulation methods such as blocking and non-blocking operations. It is suitable for Cangjie developers who need to implement efficient, thread-safe data storage and retrieval logic, manage shared resources, or handle producer-consumer patterns in multi-threaded applications.
