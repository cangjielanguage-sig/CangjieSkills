This directory serves as the central repository for technical documentation regarding the `cj-persiststorage` module, a critical component for Cangjie developers working within the HarmonyOS ecosystem. It focuses extensively on the `PersistentStorage` singleton object, which is designed to bridge the gap between volatile memory and persistent storage for UI states. The documentation explains how to maintain specific `AppStorage` properties on disk, thereby ensuring that user settings and interface states are preserved even after an application terminates and restarts. It delves into the technical synchronization mechanisms required to write and retrieve data efficiently. Furthermore, it outlines the supported data types, ranging from simple primitives to complex JSON-serializable objects, while also highlighting strict constraints such as the ban on nested objects and the 2kb file size limit. Additionally, it details the precise initialization sequences required to avoid common pitfalls. This resource is indispensable for HarmonyOS developers and software engineers who are proficient with `AppStorage` and are seeking to implement reliable, high-performance state management and data persistence strategies in their applications.
