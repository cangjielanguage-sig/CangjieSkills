# 实现页面间的跳转

This directory provides a comprehensive technical overview of implementing page navigation within HarmonyOS applications that utilize a hybrid architecture combining ArkTS and Cangjie. It addresses the specific challenges developers face when routing between these two distinct language environments, which do not share a direct router connection. The documentation covers critical scenarios including standard forward navigation using the native router module and the complex interoperability required for backward navigation. Key topics include the utilization of `router.pushUrl`, the application of Cangjie-ArkTS interop macros for function registration, and the management of cross-language callbacks. This guide is specifically tailored for developers working on mixed-language applications who need to bridge routing capabilities and ensure seamless user flow between ArkTS and Cangjie components.

## Detailed Description

### 实现页面间的跳转_1.md
This tutorial explains how to implement page navigation between ArkTS and mixed ArkTS/Cangjie pages in HarmonyOS. It details two main scenarios: navigating forward using the standard router module and navigating back, which requires interoperability because Cangjie and ArkTS routers are not directly connected. Key takeaways include using router.pushUrl for standard jumps and registering ArkTS routing functions via Cangjie-ArkTS interop macros to enable cross-language calls. The guide provides code examples for registering functions and generating interface definitions. It targets developers working on mixed-language applications who need to bridge routing capabilities between ArkTS and Cangjie environments.

### 实现页面间的跳转_2.md
This technical tutorial explains how to implement page navigation from a Cangjie component back to an ArkTS page in a HarmonyOS hybrid application. It details the project structure, TypeScript interface declarations, and dependency configuration for libohos_app_cangjie_entry.so. The guide demonstrates registering an ArkTS router callback using registerJSFunc in the second.ets file and invoking this callback from a Cangjie button click event in second.cj using globalJSFunction.get. Key concepts include cross-language function registration and lifecycle management. This is intended for developers building mixed ArkTS and Cangjie applications.
