This directory contains API reference documentation for the core classes of the Cangjie unit testing framework, focusing on mocking, stubbing, and verification mechanisms. It covers essential components like ActionSelector, MockFramework, and various specific selectors for methods, getters, and setters. The documentation details how to manage mock lifecycles, define argument matchers, and enforce interaction rules. It is suitable for Cangjie developers and QA engineers looking to implement robust unit tests with precise control over object behavior and dependency isolation.
