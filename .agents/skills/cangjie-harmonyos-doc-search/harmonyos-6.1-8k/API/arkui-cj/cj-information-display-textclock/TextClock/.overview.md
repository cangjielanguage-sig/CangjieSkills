### 示例代码.md 示例代码.md
本文档旨在提供ArkUI框架中TextClock组件的Cangjie语言代码示例，帮助开发者掌握该组件的样式设置与交互控制。文档主要包含两个部分：示例一演示了利用textShadow属性为文本时钟添加多层阴影效果；示例二展示了TextClock的基本用法，包括设置时间格式、时区偏移，以及通过TextClockController控制时钟启停和监听onDateChange事件更新数据。关键概念涉及ShadowOptions、时间格式化及状态管理。该文档适合具备Cangjie基础的开发者参考学习。

### 组件事件_de1daa27.md 组件事件_de1daa27.md
本文档是Cangjie语言中组件事件的API参考文档，主要介绍了用于处理日期变化的回调函数。文档涵盖了函数定义、功能说明、系统能力要求、起始版本以及参数详情表。核心信息是`onDateChange`方法，该方法接收一个可选的Int64类型参数的回调函数，用于在日期变化时触发，支持ArkUI全功能，起始版本为22。该文档面向使用Cangjie语言开发ArkUI应用的开发者，旨在帮助其实现日期选择或监听功能。

### 组件属性.md 组件属性.md
