### func_blackBoxTT_13more.md func_blackBoxTT_13more.md
This document serves as API reference documentation for the Cangjie runtime package, detailing functions for memory management, garbage collection control, and system resource monitoring. It covers compiler optimization control via blackBox, heap memory snapshot generation with dumpHeapData, manual garbage collection triggering using gc, and various introspection functions to retrieve statistics on heap usage, thread counts, and GC performance metrics like time and freed memory. Key takeaways include the ability to prevent dead code elimination, force garbage collection with varying intensity levels, and monitor runtime health through detailed metrics on memory allocation and thread activity. Note that the uppercase GC function is deprecated in favor of gc. This reference guide targets Cangjie developers and system engineers who need to optimize performance, debug memory issues, or monitor runtime behavior in production environments.
