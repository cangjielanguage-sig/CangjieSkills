This directory provides comprehensive documentation on binding gesture methods to UI components in the ArkUI framework using the Cangjie language. It covers core concepts such as responding to gesture events, implementing priority and parallel gesture handling, and defining foundational types for gesture recognition. Key topics include TapGesture implementation, event masking, and managing interaction conflicts between parent and child components. This resource is suitable for UI developers and software engineers seeking to enhance application interactivity through robust touch control mechanisms.
