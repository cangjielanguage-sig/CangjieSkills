# 使用运动和方向传感器监测设备状态

This directory provides a comprehensive guide on monitoring device status using motion and orientation sensors within the HarmonyOS environment. It details the implementation of W3C standard interfaces, such as Accelerometer and Gyroscope, to capture data like acceleration and angular velocity. The content covers essential configuration steps, including mandatory permission declarations in `module.json5` and the setup of the `onPermissionRequest` interface. Additionally, it explores the integration of native code with web components using the Cangjie language. This resource is ideal for developers creating interactive web applications, fitness tracking tools, or motion-controlled games that rely on precise hardware sensor data.

## Detailed Description

### 概述_2more.md
This document serves as an overview for accessing motion and orientation sensor data via W3C standard interfaces within Web components. It details supported interfaces such as Accelerometer, Gyroscope, and DeviceOrientationEvent, explaining their specific data outputs like acceleration, angular velocity, and quaternions. Key information includes the mandatory permission declarations in module.json5 for accelerometer and gyroscope access, alongside the need to configure the onPermissionRequest interface. This guide is intended for developers building interactive web applications, such as fitness tools or motion-controlled games, requiring hardware sensor integration.

### 开发步骤/
This directory outlines the development steps for integrating device sensors into hybrid applications using the Cangjie language and HarmonyOS. It covers the full workflow from backend permission handling in native code to frontend data retrieval using standard Web APIs. Key topics include UIAbility context management, system permission requests for accelerometers and gyroscopes, and JavaScript implementation of the Generic Sensor API and legacy events. This guide is suitable for HarmonyOS developers and web engineers working on mobile-first or PWA projects that require hardware sensor access.
