# ast_package_overview

The `ast_package_overview` directory acts as the definitive documentation entry point for the Cangjie Abstract Syntax Tree (AST) package. It provides a structured approach to understanding the internal mechanics of the Cangjie compiler, with a specific focus on the transformation of source code tokens into structured AST nodes. This directory covers critical topics such as syntax parsing, macro expansion management, and the sophisticated "Macro With Context" functionality, which is crucial for resolving complex nested macro scenarios. Additionally, it offers a complete API reference detailing serialization, tokenization, error handling, and various compiler operations. This documentation is specifically curated for software developers, compiler engineers, and students who are looking to deepen their expertise in language design, metaprogramming, and the development of language extensions within the Cangjie ecosystem.

## Detailed Description

### stdast/

The `stdast` directory serves as the central documentation hub for the Cangjie Abstract Syntax Tree (AST) package, providing critical insights into syntax parsing and macro expansion management. It thoroughly explains the process of converting source code tokens into AST nodes and introduces the "Macro With Context" functionality, which is essential for handling complex nested macro scenarios. The directory also houses a complete API reference that covers serialization, tokenization, error handling, and various compiler operations. This documentation is tailored for software developers, compiler engineers, and students who wish to deepen their understanding of language design, metaprogramming, and the creation of language extensions in the Cangjie ecosystem.
