# ConnectivityKit

ConnectivityKit is a comprehensive software development kit designed for the Cangjie programming language within the HarmonyOS ecosystem. It provides extensive support for short-range communication services, including Bluetooth (A2DP, BLE, HFP), WLAN management, NFC, and Secure Element (SE) modules. This kit offers detailed API references for integrating connectivity features and thorough error code documentation for troubleshooting. It is currently in the Beta stage and is suitable for developers and engineers building robust connectivity applications using Cangjie.

## Detailed Description

### [1] README_zh
This directory serves as the core index guide for the Cangjie language connectivity kit (short-range communication service). It is specifically designed to aggregate and navigate API interfaces and error code documentation related to Bluetooth and WLAN. The content is primarily divided into two major sections: Cangjie API interfaces and error code references. It covers technical details for Bluetooth A2DP, BLE, HFP, basic configuration, and WLAN management modules. Additionally, it integrates error code information for Bluetooth, Wi-Fi, NFC, and Secure Elements. Currently, all related functions are in the Beta stage. This document is intended for engineers using the Cangjie language for short-range communication application development, aiming to provide a convenient entry point for quickly locating module interfaces and querying exception handling information.

### [2] cj-apis-bluetooth-a2dp
This directory serves as a comprehensive repository for the HarmonyOS Bluetooth A2DP (Advanced Audio Distribution Profile) module, specifically tailored for the Cangjie programming language. It provides essential API reference documentation designed to facilitate the integration of high-quality audio streaming capabilities into applications.

### [3] cj-apis-bluetooth-base_profile
This directory serves as a comprehensive resource for the HarmonyOS Bluetooth Base Profile module, specifically tailored for developers utilizing the Cangjie programming language. It provides essential API reference documentation needed to integrate standard Bluetooth functionalities, ensuring a solid foundation for various Bluetooth operations.

### [4] cj-apis-bluetooth-ble
This directory contains the API reference documentation for Bluetooth Low Energy (BLE) functionality specifically designed for the Cangjie programming language within the HarmonyOS ecosystem. It covers essential BLE operations including scanning for devices, connecting to peripherals, and managing data transfer, enabling developers to build power-efficient connectivity solutions.

### [5] cj-apis-bluetooth-constant
This directory contains API reference documentation for the Cangjie language Bluetooth constants module, mainly defining basic constants required for Bluetooth development.
