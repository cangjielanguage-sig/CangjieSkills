# cj-dialog-overview

本目录包含CJ框架弹窗系统的核心概览文档，专注于为开发者提供全面的弹窗组件选择与使用指南。文档深入探讨了模态与非模态弹窗的交互逻辑差异，详细介绍了Dialog、Menu、Popup及Toast等关键组件的适用场景。同时，涵盖了弹窗的层级管理（后进先出原则）以及移动端开发中子窗尺寸的严格限制。该资料主要面向应用开发者，旨在帮助其理解弹窗类型转换机制及使用边界，从而构建符合规范且用户体验良好的应用界面。

## 详细说明

### cj-dialog-overview.md cj-dialog-overview.md
本文档是CJ框架弹窗组件的权威指南，旨在帮助开发者根据具体的交互需求精准选择合适的弹窗类型。文档首先详细区分了模态弹窗（具有强交互性，要求用户必须响应）与非模态弹窗（具有弱交互性，通常会自动消失），并列举了Dialog、Menu、Popup、Toast等组件的具体应用场景，为开发者提供了清晰的选型依据。此外，文档还深入说明了弹窗的层级堆叠规则，即遵循后进先出（LIFO）的原则，以及移动端开发中子窗无法超出主窗口的规格约束。该指南特别适合应用开发者阅读，提供了关于弹窗类型转换及使用限制的关键信息，确保开发出的界面既符合框架规范又能满足用户交互预期。
