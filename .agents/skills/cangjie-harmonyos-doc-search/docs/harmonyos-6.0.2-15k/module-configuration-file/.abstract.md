This directory serves as a comprehensive resource for configuring the `module.json5` file within HarmonyOS and OpenHarmony application development. It encompasses technical references for defining module properties, permissions, abilities, and extension abilities, alongside specific guides for metadata configuration. Key topics include component lifecycle management, HAP distribution strategies, UI configuration, and system resource permissions. The documentation provides detailed attribute tables, JSON5 examples, and usage scenarios for tags such as `abilities`, `skills`, and `metadata`. It is designed for application developers, system architects, and engineers who need to configure application manifests, manage module behaviors, and ensure proper packaging and deployment across diverse device profiles.
