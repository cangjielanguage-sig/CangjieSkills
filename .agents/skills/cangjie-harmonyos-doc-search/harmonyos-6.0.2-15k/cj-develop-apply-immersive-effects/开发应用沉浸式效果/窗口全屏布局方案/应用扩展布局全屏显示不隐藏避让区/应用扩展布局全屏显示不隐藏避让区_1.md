### 应用扩展布局，全屏显示，不隐藏避让区

可以通过调用窗口强制全屏布局接口[setWindowLayoutFullScreen()](../../API_Reference/source_zh_cn/arkui-cj/cj-apis-window.md#func-setwindowlayoutfullscreenbool)实现界面元素延伸到状态栏和导航条；然后通过接口[getWindowAvoidArea()](../../API_Reference/source_zh_cn/arkui-cj/cj-apis-window.md#func-disablelandscapemultiwiavoidareatype)和[on(WindowCallbackType, Callback1Argument\<AvoidAreaOptions>)](../../API_Reference/source_zh_cn/arkui-cj/cj-apis-window.md#func-onwindowcallbacktype-callback1argumentavoidareaoptions)获取并动态监听避让区域的变更信息，页面布局根据避让区域信息进行动态调整；设置状态栏或导航条的颜色等属性与界面元素进行匹配。

1. 调用[setWindowLayoutFullScreen()](../../API_Reference/source_zh_cn/arkui-cj/cj-apis-window.md#func-setwindowlayoutfullscreenbool)接口设置窗口全屏。

    ```cangjie
    // main_ability.cj
    class MainAbility <: UIAbility {
        // ...
        public override func onWindowStageCreate(windowStage: WindowStage): Unit {
            let windowClass: Window = windowStage.getMainWindow()

            let isLayoutFullScreen = true
            windowClass.setWindowLayoutFullScreen(isLayoutFullScreen)

            windowStage.loadContent("EntryView")
        }
    }
    ```

2. 使用[getWindowAvoidArea()](../../API_Reference/source_zh_cn/arkui-cj/cj-apis-window.md#func-disablelandscapemultiwiavoidareatype)接口获取当前布局遮挡区域（例如状态栏、导航条）。

    ```cangjie
    // main_ability.cj
    // 获取布局避让遮挡的区域
    var `type` = AvoidAreaType.TYPE_NAVIGATION_INDICATOR
    var avoidArea = windowClass.getWindowAvoidArea(`type`)
    var bottomRectHeight = avoidArea.bottomRect.height
    AppStorage.setOrCreate('bottomRectHeight', bottomRectHeight)

    `type` = AvoidAreaType.TYPE_SYSTEM
    avoidArea = windowClass.getWindowAvoidArea(`type`)
    var topRectHeight = avoidArea.topRect.height
    AppStorage.setOrCreate('topRectHeight', topRectHeight)
    ```

3. 注册监听函数，动态获取避让区域的实时数据。常见的触发避让区回调的场景如下：应用窗口在全屏模式、悬浮模式、分屏模式之间的切换；应用窗口旋转；多折叠设备在屏幕折叠态和展开态之间的切换；应用窗口在多设备之间的流转。

    ```cangjie
    // main_ability.cj
    // 注册监听函数，动态获取避让区域数据
    class AvoidAreaCallback <: Callback1Argument<AvoidAreaOptions> {
        public func invoke(arg: AvoidAreaOptions): Unit {
            match (arg.areaType) {
                case TYPE_SYSTEM => AppStorage.setOrCreate('topRectHeight', arg.area.topRect.height)
                case TYPE_NAVIGATION_INDICATOR => AppStorage.setOrCreate('bottomRectHeight', arg.area.bottomRect.height)
                case _ => return
            }
        }
    }

    class MainAbility <: UIAbility {
        // ...
        public override func onWindowStageCreate(windowStage: WindowStage): Unit {
            // ...
            windowClass.on(WindowCallbackType.WindowAvoidAreaChange, AvoidAreaCallback())

            windowStage.loadContent("EntryView")
        }
    }
    ```

4. 布局中的UI元素需要避让状态栏和导航条，否则可能产生UI元素重叠等情况。

    > **说明：**
    >
    > 避让区域存在大小为0的情况，当获取到的避让区域为0时，开发者需注意针对处理适配此时的页面区域和布局，避免贴边、内容裁剪等问题，影响应用界面正显示或美观性。
