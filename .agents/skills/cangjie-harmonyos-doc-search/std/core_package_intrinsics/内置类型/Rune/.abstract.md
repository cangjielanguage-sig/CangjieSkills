This directory provides comprehensive documentation for the "Rune" data type within the Cangjie programming language, focusing on Unicode character representation and manipulation. It covers the fundamental definition of Rune as a Unicode scalar value, detailing valid code point ranges while explicitly excluding surrogate pairs. Additionally, it includes API references for extending Rune capabilities through standard interfaces like Comparable and Hashable, as well as low-level operations for UTF-8 encoding, ASCII classification, and case conversion. This resource is suitable for developers and programmers working on text processing engines, internationalization support, and applications requiring precise character encoding constraints.
