This directory contains API reference documentation for the `LinkedBlockingQueue` class in the Cangjie programming language. It covers a thread-safe, blocking concurrent queue with configurable capacity, detailing class definitions, initialization methods, and various queue operations. Key topics include blocking and non-blocking element insertion and extraction, deprecation notices for legacy methods, and exception handling for invalid states. This documentation is suitable for Cangjie developers implementing concurrent data structures who need to manage thread synchronization, resource limits, and shared resource access efficiently.
