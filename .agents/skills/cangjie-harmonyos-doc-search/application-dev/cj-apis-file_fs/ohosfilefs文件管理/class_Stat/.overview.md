# class_Stat

This directory contains API reference documentation for the Cangjie `Stat` class and related file type checking functions within the `FileIo` module. It covers detailed file metadata inspection, including access times, permissions, ownership, and inode numbers, alongside methods to distinguish between regular files, directories, symbolic links, and device files. Designed for Cangjie developers working on file system operations, these resources provide the necessary tools to inspect file attributes and implement robust file management logic. Keywords: Cangjie, FileIo, Stat, file metadata, file types, permissions.

## Detailed Description

### class_Stat_9more.md class_Stat_9more.md
This document serves as API reference documentation for the Cangjie Stat class, which encapsulates detailed file metadata. It covers read-only properties including access time (atime), modification time (mtime), file size, owner and group IDs (uid, gid), and inode number (ino). A significant section explains the mode property, defining file permission bits in octal format. Key information highlights that instances must be constructed using FileIo.stat() and that atime updates may be disabled by default. This guide targets developers working with file system operations who need to inspect file attributes and permissions.

### func_isBlockDevice_4more.md func_isBlockDevice_4more.md
This API reference document details four specific functions in the Cangjie language used to determine file types via the FileIo module. It covers isBlockDevice, isCharacterDevice, isDirectory, and isFifo, providing function signatures, descriptions, return values, and usage examples for each. These functions allow developers to distinguish between block devices, character devices, directories, and named pipes (FIFOs), returning boolean results based on file metadata. Targeted at Cangjie developers implementing file system logic, this guide requires knowledge of the CoreFileKit and exception handling. Key concepts include file granularity, caching behavior, and inter-process communication mechanisms.

### func_isFile_3more.md func_isFile_3more.md
This API reference document details three specific functions in the Cangjie language used to determine file types. It covers isFile(), isSocket(), and isSymbolicLink(), providing syntax, descriptions, system capabilities, and return value tables for each. Key information includes that all functions return a Boolean value indicating whether the target file matches the specific type (regular file, socket, or symbolic link) and are typically invoked via FileIo.stat(). The content targets Cangjie developers implementing file management logic, requiring knowledge of exception handling and file paths. Keywords: Cangjie, FileIO, API reference, file type checking.
