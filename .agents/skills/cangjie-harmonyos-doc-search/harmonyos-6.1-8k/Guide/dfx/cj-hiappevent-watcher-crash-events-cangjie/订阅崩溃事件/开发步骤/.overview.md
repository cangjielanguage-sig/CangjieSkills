# 开发步骤

本目录提供了在仓颉应用中实现崩溃监控与日志分析的完整开发指南。内容涵盖了从配置系统事件订阅、编写崩溃处理回调逻辑，到解析原始崩溃日志数据的全过程。核心知识点包括HiAppEvent系统的使用、AppEventFilter与Watcher的配置、CjError与NativeCrash的区别，以及崩溃日志的数据结构分析。该文档适合使用DevEco Studio进行应用开发，并希望提升应用稳定性和故障排查能力的开发者参考。

## 详细说明

### 开发步骤_1.md 开发步骤_1.md
这是一份关于在仓颉应用中订阅和处理崩溃事件的开发教程。涵盖了导入依赖模块、配置AppEventFilter和Watcher进行系统事件订阅、以及通过代码触发崩溃场景的具体步骤。关键信息包括崩溃事件的回调处理逻辑、CjError与NativeCrash的栈回溯差异及耗时说明，以及异常捕获对事件上报时机的影响。该指南面向使用DevEco Studio进行应用开发的开发者，旨在帮助他们实现崩溃监控与日志分析。

### 开发步骤_2.md 开发步骤_2.md
本文档作为技术参考示例，展示了由HiAppEvent系统捕获的应用程序崩溃事件的原始日志输出。内容详细描述了崩溃日志的结构，涵盖事件域、事件类型及具体参数（包括Bundle元数据、崩溃类型、异常堆栈跟踪和系统标识符）。关键要点包括识别CjError崩溃、涉及的特定Bundle版本以及外部日志文件路径，这些对于排除运行时故障至关重要。该文档旨在帮助开发者理解在开发环境中分析崩溃时可用的数据格式。
