# cj-arkts_interop_guidelines

This directory serves as a comprehensive resource for developers working on the interoperability between the Cangjie language and ArkTS. It establishes a standardized framework for the development process, ensuring that cross-language interactions are handled with precision and safety. The scope of the documentation encompasses several critical technical domains, including thread models, exception handling mechanisms, memory management strategies, and context isolation. By addressing these areas, the guidelines aim to mitigate common risks such as deadlocks, cross-thread errors, improper exception propagation, and memory leaks. Key concepts associated with this directory include interoperability, thread safety, JSContext, exception capture, and garbage collection. This material is specifically tailored for HarmonyOS application developers who are integrating Cangjie and ArkTS, providing them with the necessary knowledge to construct robust, stable, and high-performance cross-language applications. Following these guidelines is crucial for minimizing runtime errors and optimizing the resource usage of applications running on the HarmonyOS platform.
