# 示例代码

This directory provides a specialized collection of code examples and technical tutorials aimed at solving complex gesture recognition and scrolling issues within HarmonyOS application development. It specifically addresses the challenges developers face when building user interfaces with nested components, such as scrollable lists inside tabs or multi-layered scrolling containers. The content covers critical strategies for managing gesture conflicts, ensuring that touch inputs are correctly routed between parent and child elements to maintain a fluid user experience. Key topics include the implementation of gesture interception logic, the use of `onGestureRecognizerJudgeBegin`, and the configuration of parallel gesture recognizers using `shouldBuiltInRecognizerParallelWith`. The examples are provided in both Cangjie and ArkTS, making this resource highly valuable for developers looking to master advanced interaction patterns and hierarchical navigation structures on the HarmonyOS platform. By studying these examples, developers can learn to prevent common UI glitches and ensure seamless navigation in their applications.

## Detailed Description

The following sections provide in-depth details on the specific examples and subdirectories available in this collection.

### 示例1嵌套滚动/
This directory contains code examples and tutorials demonstrating how to implement nested scrolling functionality, specifically focusing on resolving gesture conflicts between parent and child components. It covers implementations in both the Cangjie programming language and ArkTS, utilizing methods like `shouldBuiltInRecognizerParallelWith` and `PanGesture` to manage scroll priorities. The examples illustrate how to ensure smooth interaction transitions when inner components reach their boundaries. This resource is suitable for developers working on the HarmonyOS platform who need to handle complex UI interactions and hierarchical scrollable structures.

### 示例2嵌套场景下拦截内部容器手势.md 示例2嵌套场景下拦截内部容器手势.md
This tutorial demonstrates how to resolve gesture conflicts in nested Tabs components by intercepting inner container gestures. The document covers the implementation of the onGestureRecognizerJudgeBegin callback within a Cangjie code example. Key information includes tracking the inner Tabs index using a state variable and returning GestureJudgeResult.REJECT when a pan gesture reaches the inner container's boundary, thereby enabling the outer Tabs to handle the swipe. This guide is intended for developers using the Cangjie language for HarmonyOS application development who need to manage complex nested navigation scenarios.
