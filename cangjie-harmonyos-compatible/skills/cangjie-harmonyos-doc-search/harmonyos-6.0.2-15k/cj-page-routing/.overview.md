# cj-page-routing

This directory serves as a specialized technical repository for page routing within the Cangjie and ArkUI development ecosystems, focusing specifically on the `ohos.router` module. It provides an in-depth look at navigation patterns that are now considered legacy, offering detailed explanations on essential operations such as page jumping, returning to previous states, and implementing user confirmation dialogs. The documentation covers complex topics including URL-based navigation, parameter passing for data transfer, and the intricacies of page stack management and lifecycle handling. While the `ohos.router` module remains functional, this resource explicitly marks it as non-recommended, highlighting the industry's shift toward the standard Navigation component. Consequently, this directory is most suitable for developers tasked with maintaining legacy HarmonyOS codebases, as well as those seeking to understand the historical context of routing implementations to facilitate a smooth migration to modern frameworks. Core keywords include HarmonyOS, Cangjie, ArkUI, ohos.router, page stack, and lifecycle.

Key topics include URL-based navigation, data transfer, page stack management, and lifecycle handling. This collection is intended for developers maintaining legacy code or seeking to understand historical routing implementations before migrating to the new framework. The guides serve as a crucial reference for debugging older applications where the routing logic is deeply intertwined with the `ohos.router` API. By documenting these deprecated methods, the directory ensures that developers have the necessary resources to support existing software while planning their transition strategies to the more robust and feature-rich Navigation component that defines the current HarmonyOS development standards.
