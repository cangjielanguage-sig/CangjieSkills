# 用户文件uri介绍

This directory provides a comprehensive technical guide for developers working with User File Uniform Resource Identifiers (URIs) within the HarmonyOS ecosystem. It covers the definitions, structures, and acquisition methods for both Document and Media file URIs, ensuring developers understand how to uniquely identify and manipulate files. Key topics include URI syntax, usage constraints, permission protocols, and API interfaces such as DocumentViewPicker and PhotoAccessHelper. This resource is essential for application developers who need to implement secure file management, access media libraries, and handle file operations within their applications while adhering to strict privacy standards and avoiding permission errors. By following these guidelines, developers can effectively integrate file handling capabilities, ensuring data security and system stability.
