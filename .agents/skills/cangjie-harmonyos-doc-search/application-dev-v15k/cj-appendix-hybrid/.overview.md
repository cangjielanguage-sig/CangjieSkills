# cj-appendix-hybrid

This directory contains the technical documentation for implementing hybrid development in HarmonyOS applications, specifically focusing on the integration of Cangjie UI components within ArkTS pages. It serves as a comprehensive guide for developers who need to merge Cangjie logic into existing ArkTS projects without completely rewriting the application. The documentation covers the essential background of mixed development, providing a detailed comparison with pure Cangjie development modes, particularly highlighting differences in lifecycle management and routing systems. It includes step-by-step instructions for project configuration, emphasizing the necessity of using `CJHybridComponentV2` and `NodeContainer` for successful component embedding. Additionally, it clarifies the limitations of this approach, such as the absence of cross-language state synchronization and the restricted lifecycle interfaces for Cangjie pages. This resource is intended for HarmonyOS developers who possess a strong understanding of both ArkTS and Cangjie and are looking to optimize their development workflow by leveraging the strengths of both languages.

## Detailed Description

### cj-appendix-hybrid.md cj-appendix-hybrid.md
This guide explains how to implement hybrid development by embedding Cangjie UI components into ArkTS pages within HarmonyOS applications. It covers the background of mixed development, compares it with pure Cangjie mode regarding lifecycle and routing, details project configuration, and provides code examples. Key takeaways include the necessity of using CJHybridComponentV2 and NodeContainer for integration. While state management decorators are supported, cross-language state sync is not, and Cangjie pages in this mode lack full lifecycle interfaces and routing capabilities. This tutorial targets HarmonyOS developers familiar with both ArkTS and Cangjie who need to integrate Cangjie logic into existing ArkTS applications. Keywords: HarmonyOS, Cangjie, ArkTS, Hybrid Development, CJHybridComponentV2, NodeContainer, UI components, State management.
