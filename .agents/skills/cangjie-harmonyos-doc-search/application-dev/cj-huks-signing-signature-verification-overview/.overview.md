# cj-huks-signing-signature-verification-overview

This directory provides a comprehensive technical reference for data signing and signature verification within the OpenHarmony HUKS (Hardware Universal KeyStore) framework. It is specifically designed to guide developers and vendors in implementing secure key management services that ensure data integrity and non-repudiation. The documentation covers a wide array of cryptographic algorithm specifications, including RSA, ECC, ED25519, and SM2, detailing their interaction with various digests and padding modes. It addresses the specific needs of both standard and lightweight devices, offering clear distinctions between mandatory and optional specifications. By adhering to these guidelines, users can ensure their applications maintain high security standards and achieve optimal cross-platform compatibility across the OpenHarmony ecosystem.

## Detailed Description

### cj-huks-signing-signature-verification-overview.md

This reference document serves as a critical guide for understanding the algorithm specifications required for data signing and signature verification within the HUKS framework. Its primary objective is to ensure data integrity and non-repudiation for applications utilizing the OpenHarmony key management service. The document provides a detailed breakdown of supported algorithm combinations tailored for both standard and lightweight devices. It extensively covers major cryptographic algorithms, including RSA, ECC, ED25519, and SM2, while specifying the required digests and padding modes for each. A key focus of the document is the distinction between mandatory and optional specifications. It advises developers to prioritize mandatory specifications, such as RSA/SHA256 and ECC/SHA256, to guarantee cross-platform compatibility. This resource is indispensable for developers and vendors seeking to implement secure and compliant cryptographic functions within the OpenHarmony ecosystem.
