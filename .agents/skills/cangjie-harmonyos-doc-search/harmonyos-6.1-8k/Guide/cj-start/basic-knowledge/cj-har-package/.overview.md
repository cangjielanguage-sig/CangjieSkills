# cj-har-package

This directory serves as a definitive technical resource for the `cj-har-package` project, focusing extensively on the HAR (Harmony Archive) format. It is designed to assist developers in understanding and implementing static shared packages that enable the efficient distribution of Cangjie components and resources across multiple modules and projects. The content encompasses the full spectrum of HAR usage, starting from basic conceptual definitions to advanced workflows involving development, export, referencing, and the final compilation and publishing phases. By integrating with DevEco Studio, this documentation provides the necessary guidance for streamlining the development lifecycle. It is particularly suitable for software engineers and developers working within the HarmonyOS ecosystem who are utilizing the Cangjie language to build modular applications and distribute reusable libraries. The documentation emphasizes best practices for component reuse and resource management, ensuring that developers can maintain clean and efficient codebases while leveraging the power of shared packages.

## Detailed Description

### HAR/

This directory contains the complete technical documentation for HAR (Harmony Archive), a specialized static shared package format used for sharing Cangjie components and resources between different modules or engineering projects. The documentation is structured to guide developers through the entire lifecycle of a HAR package. It begins with the basic concepts, establishing a solid foundation for understanding what HAR is and how it functions within the Cangjie environment. Subsequently, it delves into the practical aspects of development and export, teaching users how to encapsulate their logic and assets effectively. The content also covers the critical steps of referencing these packages in other projects, ensuring seamless integration and dependency management. Finally, it addresses the compilation and publishing processes, which are vital for distributing the packages to other teams or the public. Key themes explored in this section include HAR package structures, the Cangjie language syntax, component reuse strategies, resource management techniques, and the specific tooling provided by DevEco Studio. These documents are specifically tailored for developers using DevEco Studio for HarmonyOS application development, especially those focused on modular development and library distribution.
