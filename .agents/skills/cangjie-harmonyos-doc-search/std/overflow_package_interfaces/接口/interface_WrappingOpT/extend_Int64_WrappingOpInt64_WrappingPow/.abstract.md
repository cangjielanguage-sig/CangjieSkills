This directory provides comprehensive API reference documentation for implementing wrapping arithmetic and bitwise operations on the `Int64` type within the Cangjie programming language. It specifically covers the `WrappingOp` and `WrappingPow` interfaces, detailing functions for essential arithmetic tasks such as addition, subtraction, multiplication, division, modulo, negation, exponentiation, and bit shifting. A primary focus is the high-order truncation strategy used to handle overflow, ensuring that results wrap around predictably rather than raising runtime errors. This resource is highly suitable for Cangjie developers and systems programmers who require precise, deterministic control over integer overflow behavior and low-level bit manipulation in their mathematical computations.
