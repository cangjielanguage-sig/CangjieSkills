# cj-common-event-publish

本目录提供了仓颉（Cangjie）语言中关于公共事件发布的开发指南。文档详细介绍了如何利用 BasicServicesKit 发布公共事件，涵盖了场景介绍、接口说明以及发布携带或不携带信息的事件。核心内容包括 `publish` 方法的使用、`CommonEventPublishData` 的配置（如无序、有序或粘性事件）以及完整的代码示例。该文档适合仓颉应用开发者阅读，旨在帮助开发者掌握基础模块导入和事件处理机制。
