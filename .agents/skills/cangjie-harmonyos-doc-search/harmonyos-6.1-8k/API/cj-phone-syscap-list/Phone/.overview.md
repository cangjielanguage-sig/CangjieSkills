# Phone

## 详细描述

### Phone_1.md
本文档旨在定义系统能力（SysCap）概念，并列出当前版本Phone设备支持的最小系统能力集。主要涵盖SysCap的定义、开发前的阅读指引以及设备能力集说明。关键信息指出，开发者应先阅读SysCap使用指南；文档列出的能力集对应的API可直接调用，无需进行canIUse()隔离判断，具体可通过SDK中的default.json查询。该文档面向Phone应用开发者，属于参考类文档，旨在帮助开发者判断设备能力支持情况以提高开发效率。

### Phone_2.md
本文档作为特定Phone设备配置支持的系统能力综合参考列表。涵盖了广泛的子系统，包括ArkUI、图形、窗口管理、通信协议、多媒体处理、电话、电源管理和安全框架。内容由分层标识符（如SystemCapability.Multimedia.Media.Core和SystemCapability.Security.Huks.Core）组成，定义了系统架构内可用的具体功能特性。旨在供系统工程师和应用开发者使用，该列表有助于验证功能可用性、管理依赖关系以及了解支持的硬件和软件服务范围。

### Phone_3.md
本文档是特定Phone设备配置支持的系统能力综合参考列表。它枚举了包括安全、文件管理、多媒体、用户身份验证、传感器、分布式数据和能力框架在内的多个领域的能力。该列表提供了细粒度的功能标识符，如加密框架、云同步管理器和3D图形引擎，对于系统配置和应用兼容性至关重要。旨在供系统工程师和应用开发者使用，该文件有助于确定开发和部署可用的硬件和软件功能。
