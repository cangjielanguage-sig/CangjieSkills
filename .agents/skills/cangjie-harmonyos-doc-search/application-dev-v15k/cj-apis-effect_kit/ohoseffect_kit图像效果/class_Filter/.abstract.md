This directory serves as a technical repository for API reference documentation regarding the Cangjie Filter class and its associated image processing functions within the ImageKit framework. It provides detailed specifications for applying a variety of visual effects to input images, ranging from fundamental adjustments like blur and brightness to complex color operations such as grayscale, inversion, and custom matrix transformations. The documentation thoroughly explains system capabilities, the implementation of effect chaining to combine multiple filters, and strict parameter constraints, such as the 0.0-1.0 range for brightness or the 5x4 Float32 array requirement for color matrices. This content is intended for developers and software engineers working with multimedia image processing in the Cangjie language, specifically those utilizing PixelMap objects and ArkGraphics2D libraries to build dynamic image manipulation features.
