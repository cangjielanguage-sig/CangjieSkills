## Detailed Description

The following files provide the specific API definitions and usage details:

### class_BundleStats.md class_BundleStats.md
This API reference document defines the Cangjie class BundleStats, which represents application storage space statistics. It details the class structure and provides specifications for three public properties: appSize, cacheSize, and dataSize. Key information includes that all properties are of type Int64, measured in Bytes, and are readable and writable. These variables specifically cover installation files, cache files, and other data storage respectively. The class belongs to the SystemCapability.FileManagement.StorageService.SpatialStatistics capability starting from version 20. This document targets Cangjie developers needing to manage or monitor application storage usage.

### ohosfile_storage_statistic_6more.md ohosfile_storage_statistic_6more.md
This document serves as API reference documentation for the ohos.file_storage_statistics module in the Cangjie programming language, designed to query storage space on HarmonyOS devices. It details three primary functions: getCurrentBundleStats for retrieving application-specific storage data, getFreeSize for available internal storage, and getTotalSize for total internal storage capacity. Key information includes function signatures, return types like BundleStats and Int64, and potential error codes. The document targets developers requiring storage monitoring capabilities, providing code examples and system capability requirements for implementation.
