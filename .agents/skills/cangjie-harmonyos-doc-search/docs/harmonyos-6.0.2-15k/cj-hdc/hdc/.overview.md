# hdc

This directory contains comprehensive documentation for the HarmonyOS Device Connector (hdc), a command-line tool designed for debugging HarmonyOS and OpenHarmony devices across Windows, Linux, and macOS. It covers the tool's architecture, environment setup, and a wide array of functionalities including file transfer, app installation, port forwarding, and log management. Additionally, it provides essential troubleshooting resources for error codes, connectivity issues, and device management. This documentation is suitable for developers, QA engineers, and system administrators seeking to effectively interact with and debug HarmonyOS devices via the command line.

## Detailed Description

### hdc_2more.md hdc_2more.md
This document introduces hdc (HarmonyOS Device Connector), a command-line tool for debugging HarmonyOS devices from Windows, Linux, or macOS. It outlines the tool's three-part architecture (client, server, daemon) and covers environment preparation using DevEco Studio. Key sections include optional configurations like adding the tool to the system PATH or modifying the default server port via environment variables, providing essential setup steps for developers.

### hdc命令列表.md hdc命令列表.md
This document serves as a quick reference guide for the HDC command-line tool, detailing available parameters and commands for device interaction. It covers global parameters and a comprehensive command list categorized by function, including file management, app installation, debugging, and port forwarding. It emphasizes the requirement to place global parameters before specific commands and is intended for developers managing devices via the command line.

### hdc调试日志.md hdc调试日志.md
This technical guide details how to configure, manage, and retrieve debugging logs for the HDC tool. It covers server-side log management, setting runtime log levels, and configuring environment variables across different OS platforms. It also explains device-side log acquisition using hilog commands, providing specific syntax for foreground and background server modes, targeting developers troubleshooting connectivity issues.

### 基本使用方法.md 基本使用方法.md
This document is a quick start guide for the hdc tool, detailing fundamental operations for interacting with OpenHarmony devices. It covers prerequisites like enabling USB debugging, querying connected devices, executing shell commands, and accessing help documentation. It includes troubleshooting tips for connection issues and is intended for developers facilitating basic device management and debugging tasks.

### 安全相关命令_2more.md 安全相关命令_2more.md
This reference guide focuses on security key generation and version verification within the hdc tool. It details the keygen command for creating public-private key pairs and version query commands for retrieving SDK and server process information. The guide provides command syntax, parameter definitions, and expected return values, targeting developers managing secure connections or debugging version compatibility.

### 执行交互命令_2more.md 执行交互命令_2more.md
This guide details the usage of hdc for executing shell commands and managing applications on HarmonyOS devices. It covers interactive and non-interactive shell commands and application lifecycle management tasks like installation and uninstallation. Key information includes command syntax for shell operations and parameters for replacing apps or preserving data, targeted at developers with knowledge of debugging certificates.

### 文件传输.md 文件传输.md
This document details the usage of the hdc tool for transferring files between a local host and a remote HarmonyOS device. It covers sending and receiving files, explaining command syntax, parameters for preserving timestamps, and managing file permissions. It specifically highlights accessing debuggable application data directories, intended for developers needing to manage device files during development.

### 服务进程管理.md 服务进程管理.md
This reference guide covers managing the lifecycle of the hdc service process. It details operations for starting, terminating, bypassing process queries, and launching the service in foreground mode. Key information includes command syntax, return values, and behaviors like log level priority and the -r restart flag, emphasizing that only a single service instance is allowed.

### 端口转发.md 端口转发.md
This document outlines the command-line interface for managing port forwarding between a host PC and a device using hdc. It details listing active tasks, establishing forward and reverse port mappings, and removing tasks. It provides supported protocol types, command syntax, and return values, serving as a guide for developers needing to redirect network traffic for application debugging.

### 设备操作.md 设备操作.md
This reference guide details managing and debugging devices using hdc. It covers commands for log retrieval (hilog), listing JDWP process IDs (jpid), real-time process monitoring (track-jpid), and rebooting devices. Each section provides syntax, parameters, and usage examples, enabling precise device interaction for application debugging and state management.

### hdc错误码/
This directory is a specialized repository for troubleshooting documentation regarding hdc error codes. It addresses technical issues like invalid bundle names, unsupported modes, and remote path restrictions. It provides in-depth error descriptions, root cause analysis, and resolution strategies, making it essential for developers needing immediate solutions to command-line execution failures.

### 常见问题/
This directory serves as a comprehensive troubleshooting and FAQ resource for the HarmonyOS and OpenHarmony development ecosystems. It covers critical challenges related to the hdc tool and device connectivity, including environment compatibility checks, driver installation (Zadig), and debugging workflows. It is suitable for resolving issues where the tool fails to execute or devices are not recognized.

### 设备连接管理/
This directory is a technical resource for managing device connections within the HarmonyOS ecosystem. It focuses on the hdc tool, providing references for establishing communication channels, switching between USB and wireless modes, and managing commands in multi-device environments. It addresses scenarios like local USB, TCP, and remote debugging, designed for developers configuring or troubleshooting connections.
