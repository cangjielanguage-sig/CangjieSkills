## 详细描述

### Module类型.md Module类型.md
本文档旨在介绍HarmonyOS开发中Module的分类、特性及使用场景。主要涵盖Ability类型的Module（entry和feature）与Library类型的Module（HAR和HSP），并对比了HAR与HSP的编译运行及发布引用差异。核心要点包括：HAP是应用安装基本单位，entry类型HAP唯一；HAR随使用方编译存在多份拷贝，支持独立发布；HSP运行时仅存在一份代码，支持应用内及集成态引用。本文属于参考文档，面向HarmonyOS应用开发者，适用于项目架构设计及模块化开发场景。

### 应用程序包概述_3more_d763be8c.md 应用程序包概述_3more_d763be8c.md
本文档旨在介绍基于Stage模型开发应用前所需掌握的应用程序包基础知识。文档主要涵盖应用与应用程序包的定义、系统管理机制以及跨平台兼容性，并详细阐述了应用的多Module设计机制。关键信息包括系统屏蔽芯片差异以支持多平台运行，以及通过模块化设计实现功能解耦、维护便利和多设备精准适配。这是一份面向开发者的基础指南，旨在帮助其理解应用架构设计与管理机制。

### 选择合适的包类型.md 选择合适的包类型.md
本文档旨在指导开发者根据应用需求，在HAP、HAR和HSP三种HarmonyOS包类型中做出选择。文档详细对比了三者的功能场景、组件支持能力及依赖限制。核心信息包括：HAP用于独立安装运行的功能模块；HAR作为静态共享包适合SDK发布但存在代码冗余；HSP作为动态共享包可减小应用包体积。此外，文档还说明了HAR不支持声明页面及禁止循环依赖等约束。该指南面向HarmonyOS应用开发者，用于优化模块化架构设计。
