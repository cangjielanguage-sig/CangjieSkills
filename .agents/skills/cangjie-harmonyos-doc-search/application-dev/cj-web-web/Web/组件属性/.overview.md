# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the Cangjie language framework, with a specific focus on the WebView component. It covers a broad spectrum of configuration options, ranging from display modes (such as dark mode) and resource access permissions (including files, geolocation, and DOM storage) to JavaScript interaction proxies and user interface behaviors like scrolling and zooming. These documents are essential resources for developers building HarmonyOS applications who require precise control over web content rendering, security settings, and user interaction gestures. The APIs generally follow a fluent builder pattern and are designed for use with SystemCapability.Web.Webview.Core version 22 or higher.

## Detailed Description

### func_darkModeWebDarkMode_6more.md
This document serves as API reference documentation for configuring WebView settings and permissions within the Cangjie language framework. It covers six distinct builder functions focused on display modes and resource access: darkMode, forceDarkAccess, domStorageAccess, fileAccess, geolocationAccess, and imageAccess. Key information includes the dependency of forced dark mode on the general dark mode setting, as well as specific toggles for DOM storage, file systems, location services, and automatic image loading. Intended for developers working with SystemCapability.Web.Webview.Core starting from version 22, this guide enables precise control over web component behavior and security.

### func_javaScriptProxyArrayS_5more.md
This document provides API reference documentation for five configuration functions within the Cangjie Webview component, focusing on JavaScript interaction, content security, and display settings. It details the javaScriptProxy function for injecting app-side methods into the web window, alongside mixedMode for HTTP/HTTPS content control, nestedScroll for scroll coordination, onlineImageAccess for network image permissions, and verticalScrollBarAccess for UI visibility. Key information includes that all functions utilize named parameters with default values and return This to support a fluent builder pattern. This reference is intended for HarmonyOS developers configuring Webview components to manage security, interactivity, and layout behavior.

### func_zoomAccessBool.md
This document serves as API reference documentation for the zoomAccess function, which configures gesture-based zooming capabilities within a webview component. The content covers the function signature, system capabilities, version requirements, and a detailed parameter table explaining the input values. Key takeaways include that the function accepts a nullable Boolean parameter where true enables zooming and false disables it, with a default state of zooming being disabled. It is available starting from version 22 under the Webview Core capability. This reference guide targets developers using the Cangjie language to build webview applications, specifically those needing to control user interaction behaviors like zooming. Keywords: API reference, zoomAccess, Cangjie, webview, gesture zoom, SystemCapability.
