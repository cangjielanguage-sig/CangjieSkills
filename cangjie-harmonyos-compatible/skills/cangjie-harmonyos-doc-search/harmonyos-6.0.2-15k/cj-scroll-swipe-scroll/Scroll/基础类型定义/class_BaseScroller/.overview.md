# class_BaseScroller

This directory contains API reference documentation for the `BaseScroller` class and associated scrolling functions within the Cangjie ArkUI framework. It covers the core sealed abstract base class used to manage scrolling functionality in components such as Scroll, List, Grid, and WaterFlow. Additionally, it details specific functions for programmatic navigation, including relative scrolling, edge positioning, pagination, and index-based scrolling. Key topics include inertial scrolling control, animation configuration, and performance considerations for large datasets. This documentation is suitable for ArkUI developers using the Cangjie language who need to implement custom scrolling behaviors, control scroll positions programmatically, or query component states.

## Detailed Description

### class_BaseScroller_8more.md
This document provides API reference documentation for the BaseScroller class, a sealed abstract base class in the Cangjie language designed to manage scrolling functionality within ArkUI components. It details the class initialization and key member functions including currentOffset, fling (overloaded for Float64 and Int64), getItemIndex, getItemRect, and isAtEnd. Key information includes support for Scroll, List, Grid, and WaterFlow components, enabling developers to control inertial scrolling via velocity, retrieve item positions or indices, and check scroll status. The document specifies that direct inheritance is not supported. This reference guide targets ArkUI developers using Cangjie who need to programmatically control scroll behavior and query component states.

### func_scrollByLength_Length_7more.md
This document serves as an API reference for scrolling control functions within the Cangjie ArkUI framework, detailing methods to manipulate scroll positions programmatically. The content covers four primary functions: scrollBy for relative movement, scrollEdge for edge positioning with optional velocity, scrollPage for pagination with animation control, and scrollTo for absolute positioning. Key takeaways include that these functions support components like Scroll and List, require named parameters, and generally prohibit percentage values for offset parameters. All methods are available starting from API version 12. This reference is intended for developers implementing custom scrolling behaviors in ArkUI applications using the Cangjie language.

### func_scrollToIndexInt32_Bo_2more.md
This document serves as API reference documentation for the scrollToIndex function in the ArkUI framework, detailing how to programmatically scroll container components to a specific item index. It covers two overloaded function signatures: one for basic scrolling and another adding an extra offset parameter. Both include detailed parameter tables explaining index targeting, smooth animation settings, and alignment options. Key takeaways include support for List, Grid, and WaterFlow components, starting from API version 12. Crucially, it warns that enabling smooth scrolling triggers layout calculations for all passed items, potentially causing performance issues with large datasets. It also notes specific parameter constraints, such as index validation and component-specific alignment support. This reference guide targets ArkUI developers using the Cangjie language who need to implement scroll navigation in list-based interfaces.

### func_scrollToLength_Length_3more.md
This API reference document details the scrollTo function overloads in the Cangjie language for controlling scroll position within ArkUI components. It covers three specific function signatures that accept Length offsets combined with different animation configurations: a duration and curve pair, a ScrollAnimationOptions object, or a boolean flag. Key information includes that offsets use vp units without percentage support, and negative values trigger clamping or bouncing effects. The document specifies system capabilities and version 12 compatibility. This technical guide is intended for developers implementing custom scrolling behaviors and animations in ArkUI applications.
