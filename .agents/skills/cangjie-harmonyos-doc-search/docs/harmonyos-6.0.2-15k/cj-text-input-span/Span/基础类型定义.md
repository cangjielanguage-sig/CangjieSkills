## 基础类型定义

### class TextBackgroundStyle

```cangjie
public class TextBackgroundStyle {
    public var color: UInt32
    public var radiusBorder: BorderRadiuses
    public var radiusDimension: Length
    public init(
        color!: ResourceColor = Color.TRANSPARENT,
        radiusBorder!: BorderRadiuses = BorderRadiuses(),
        radiusDimension!: Length = 0.0
    )
}
```

**功能：** 设置文字背景颜色及圆角。

> **说明：**
>
> 其中，radiusBoder和radiusDimension仅定义一个即可，如两个均定义则仅有 radiusDimension生效；

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### init(ResourceColor, BorderRadiuses, Length)

```cangjie
public init(
    color!: ResourceColor = Color.TRANSPARENT,
    radiusBorder!: BorderRadiuses = BorderRadiuses(),
    radiusDimension!: Length = 0.0
)
```

**功能：** 创建TextBackgroundStyle类型的对象。

> **说明：**
>
> 其中，radiusBoder和radiusDimension仅定义一个即可，如两个均定义则仅有 radiusDimension生效

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|color|[ResourceColor](./cj-common-types.md#interface-resourcecolor)|否|Color.TRANSPARENT| **命名参数。** 文本背景色。|
|radiusBorder|[BorderRadiuses](./cj-common-types.md#class-borderradiuses)|否|BorderRadiuses()| **命名参数。** 文本背景圆角。|
|radiusDimension|[Length](./cj-common-types.md#interface-length)|否|0.0| **命名参数。** 文本背景圆角长度尺寸。|
