This directory serves as a vital technical resource for understanding thread control mechanisms within the Cangjie programming language, specifically tailored for HarmonyOS application development. It addresses the critical architectural challenge of ensuring that UI code executes on the correct OS thread to maintain system stability and responsiveness. The documentation covers the fundamental background distinguishing UI logic from non-UI logic, the development paradigm for effective thread scheduling, necessary module imports, and the specifics of thread creation using the `spawn` keyword. Furthermore, it details the `launch` function API. Key takeaways include utilizing the `Main` object to bind threads to the UI thread and employing `spawn (Main)` for safe state updates to prevent application lag. This guide is essential for HarmonyOS developers seeking to master concurrency and optimize UI interactions.
