This directory contains API reference documentation for the `Watcher` struct within the Cangjie programming language, specifically designed for the HiAppEvent system. It provides comprehensive details on creating and configuring event observers, focusing on initialization parameters, trigger conditions, event filters, and callback mechanisms. Key topics include the distinction between real-time and condition-based callbacks, as well as the precedence rules governing them. This documentation is essential for Cangjie developers looking to implement robust application event monitoring, subscription logic, and custom filtering capabilities in their software projects.
