This directory contains API reference documentation for the ArkUI framework using the Cangjie programming language. It covers core infrastructure components including resource management, Foreign Function Interface (FFI) containers, state management classes like ObservedObject, and UI rendering base classes. The documentation details internal interfaces, data structures, and utility functions essential for building and extending the UI system. It is primarily intended for framework developers and system-level engineers working on low-level architecture, native interoperability, and component lifecycle management within the ArkUI ecosystem.
