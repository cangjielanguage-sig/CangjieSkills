This directory contains a comprehensive collection of troubleshooting guides for HarmonyOS Bundle Manager (bm) tool error codes. It covers a wide range of issues related to HAP package installation, uninstallation, and configuration, including signature verification failures, API version mismatches, system account errors, and file system exceptions. Each document provides specific error codes, root causes, and actionable remediation steps. This resource is suitable for HarmonyOS developers, QA engineers, and technical support personnel using DevEco Studio or command-line tools to debug application deployment failures.
