# 基础类型

本目录定义了系统中用于跨应用和跨平台数据交互的基础类型。内容涵盖基础类型定义、UTD-ID命名规范、各类文件格式（如图像、视频、音频、文档、代码等）的详细分类、文件扩展名及MIME类型映射。该文档集为开发人员和系统集成者提供了标准化的数据字典，用于文件识别、数据验证及内容管理系统的构建。

## 详细描述

### 基础类型_1.md
本文档旨在定义系统中的基础类型，这些类型用于跨应用、跨设备及跨平台的通用数据交互。主要涵盖基础类型的定义、其通用数据类型的特性，以及标识符UTD-ID的命名规范。核心信息指出基础类型通过UTD-ID（格式为general.xxx）进行标识，并提供了当前系统中预定义的通用类型列表。该文档属于参考文档，面向需要处理数据类型标准化及跨平台交互的开发人员或系统集成者。

### 基础类型_2.md
本文档作为参考指南，定义了一个分层的数据和文件类型分类系统，涵盖物理存储实体和逻辑内容对象。主要内容包括基础类型（如general.entity和general.object）及其派生类型，重点详细列出了各种图像格式（如PNG、JPEG、TIFF等）及其对应的文件后缀和MIME类型。核心信息在于展示了类型之间的继承关系，例如具体图片类型继承自通用图像类型，为系统识别和处理文件格式提供了标准化的数据字典。该文档面向开发人员和系统集成人员，适用于文件处理、数据验证或内容管理系统的开发场景。

### 基础类型_3.md
该文档作为参考手册，详细列出了系统支持的图像和视频基础类型及其对应的文件扩展名和MIME类型。内容主要分为图像类型（如SVG、HEIC、JPEG 2000）和视频类型（如AVI、MPEG、3GPP、蓝光视频）两大类。文档通过表格形式展示了类型标识符、父级分类、文件后缀及MIME类型的映射关系，为媒体文件识别提供标准定义。主要面向开发人员或系统集成商，用于配置文件类型检测、媒体处理或系统兼容性设置。

### 基础类型_4.md
1. 本文档作为参考列表，定义了各种视频和音频文件格式、扩展名及其MIME类型。
2. 涵盖了DivX、Ogg和H.264等视频格式，以及MP3、AAC、FLAC、MIDI和各种移动音频编解码器等音频格式。
3. 表格将内部类型标识符映射到文件扩展名和标准MIME类型，为媒体处理提供技术规范。
4. 适用于需要在软件系统中配置文件类型识别或媒体播放支持的开发人员或系统集成商。

### 基础类型_5.md
该文档作为技术参考手册，详细定义了系统支持的多媒体音频和压缩存档文件的基础类型。

主要涵盖音频格式（如RTTTL、SID、AC3）以及多种压缩归档格式（如TAR、ZIP、BZ2、ARJ、XAR）的分类与属性。

文档通过表格形式列出了类型标识符、父类型、文件扩展名、MIME类型及中文描述，提供了文件类型与系统内部标识符的精确映射关系。

主要面向开发人员或系统集成者，用于文件类型识别、MIME处理配置及系统文件管理功能的实现。

### 基础类型_6.md
该文档旨在定义和分类系统中的基础文件类型，建立了内部类型标识、文件扩展名与MIME类型之间的映射关系。内容主要涵盖压缩归档（如LZMA）、磁盘镜像（如ISO、IMG）、各类文本格式（如HTML、XML、RTF、配置文件）以及日程数据等类别。文档详细列出了每种类型的父级分类、常见后缀及具体描述，为文件识别和处理提供了标准化的参考依据。该参考文档主要面向开发人员或系统架构师，用于辅助文件系统管理或数据分类系统的构建与维护。

### 基础类型_7.md
该文档作为参考表，定义了系统中各种文件类型的内部标识、扩展名、MIME类型及其层级关系。
涵盖日历格式（ICS）、分隔文本（CSV/TSV）、XML衍生格式（MathML、RSS）以及C、C++、Java、TypeScript等多种编程语言的源代码类型。
关键信息包括内部类型名称与标准MIME类型之间的映射，为数据处理提供了全面的分类依据。
适用于需要在软件应用中配置文件识别或MIME处理的开发人员或系统管理员。

### 基础类型_8.md
该文档是一份关于系统基础文件类型与数据格式的参考映射表，旨在定义内部类型标识与标准MIME类型及文件扩展名之间的对应关系。主要内容包括脚本语言类型（如JavaScript、Python、PHP、Shell）、数据交换格式（JSON、YAML）以及通用对象类型（如URI、VCard、可执行文件）的详细分类。文档通过表格形式展示了每种类型的父类继承关系、支持的扩展名和MIME类型，例如将general.json映射为.json和application/json。这份资料主要面向开发人员和系统集成者，用于准确识别和处理系统中的各类文件及数据流。

### 基础类型_9.md
本文档作为参考指南，定义了各种基础数据类型、其层级关系、文件扩展名及MIME类型。主要涵盖二进制数据、三维网格模型、安全证书（CER, CRT, CRL）、CAD格式（IGES）、字体类型（TrueType, OpenType）、复合对象（OFD, PRN）以及电子书格式（EPUB）。关键信息在于展示了特定类型如何继承自父类别（如general.certificate继承自general.object）及其对应的技术标识符。该文档面向需要在软件系统中分类或处理特定文件格式的开发人员或系统集成商，为数据管理提供了结构化的分类法。
