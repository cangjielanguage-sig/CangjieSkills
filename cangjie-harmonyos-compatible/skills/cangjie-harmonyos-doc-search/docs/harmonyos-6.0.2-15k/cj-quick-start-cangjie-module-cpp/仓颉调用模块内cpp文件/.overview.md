# 仓颉调用模块内cpp文件

This directory contains specialized technical resources for HarmonyOS developers working with the Cangjie language, specifically targeting system-level integration and application deployment. It provides a comprehensive guide on achieving interoperability between Cangjie and C++ code within a single module, utilizing DevEco Studio for development. The content covers critical steps such as creating projects, adding C++ sources, declaring native functions with the `foreign` keyword, and configuring build dependencies in `cjpm.toml`. Furthermore, it addresses the operational requirements for running applications on various hardware, including real devices and emulators, with detailed instructions on signing and ABI filter configuration for x86 architectures. This documentation is essential for developers seeking to leverage native C++ capabilities or validate their Cangjie applications across diverse execution environments.

### 仓颉调用模块内cpp文件_2more.md 仓颉调用模块内cpp文件_2more.md
This tutorial guides developers on implementing interoperability between Cangjie and C++ within a HarmonyOS module using DevEco Studio. The document outlines a step-by-step process including creating a Cangjie project, adding a C++ source file, and writing native functions using extern "C". It details how to declare these functions in Cangjie using the foreign keyword and configure the cjpm.toml file to establish FFI dependencies. Key takeaways include the syntax for cross-language calls and build configuration requirements. This guide is intended for HarmonyOS developers seeking to integrate native C++ logic into Cangjie applications.

### 使用真机或模拟器运行应用.md 使用真机或模拟器运行应用.md
This tutorial guides developers on running HarmonyOS applications written in the Cangjie language using DevEco Studio. It covers two primary execution environments: local real devices and the emulator. Key steps include connecting a device, configuring automatic signing via a Huawei account, and creating a virtual device. A critical technical detail is the requirement to modify the build-profile.json5 file to include x86_64 ABI filters when running Cangjie projects on x86-based emulators. This document targets developers needing to test and deploy their applications across different hardware architectures.
