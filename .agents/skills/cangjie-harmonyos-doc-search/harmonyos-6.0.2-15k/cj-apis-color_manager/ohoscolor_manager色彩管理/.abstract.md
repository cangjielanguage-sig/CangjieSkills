This directory contains API reference documentation for the `ohos.color_manager` module within the Cangjie ArkGraphics2D kit. It focuses on color management capabilities, enabling developers to create, manage, and query color space properties in HarmonyOS applications. Key components include the `ColorSpaceManager` class, `ColorSpacePrimaries` struct, and the `ColorSpace` enumeration. It covers standard and custom color space creation, gamma values, white points, and primary color coordinates. This documentation is suitable for graphics developers using the Cangjie programming language who need precise control over color rendering and gamut definitions in 2D graphics applications.
