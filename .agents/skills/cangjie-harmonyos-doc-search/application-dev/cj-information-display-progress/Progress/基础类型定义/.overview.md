# 基础类型定义

This directory contains fundamental type definitions for the ArkUI framework, specifically focusing on progress bar components within the Cangjie programming language environment. It covers essential interfaces, enumerations, and configuration classes that define the visual style, behavior, and state of progress indicators. Key elements include style options, progress status enums, and common interfaces for UI customization. This documentation is suitable for HarmonyOS developers and UI engineers who need to implement or customize progress bars in their applications using Cangjie.

## Detailed Description

### class_RingStyleOptions.md
This API reference document defines the RingStyleOptions class used to configure the visual style and behavior of ring progress bars in the ArkUI framework. It details class properties including strokeWidth, shadow, status, enableSmoothEffect, and enableScanEffect, along with their specific data types and default values. It also documents the class constructor. The class inherits from CommonProgressStyleOptions and allows developers to toggle animations like smooth transitions and scan effects, or set the progress state such as Loading versus Progressing. This guide targets HarmonyOS developers using the Cangjie language who need to customize UI components.

### enum_ProgressStatus.md
This document serves as an API reference for the Cangjie programming language's ProgressStatus enum, defining the state of a progress bar within the ArkUI framework. The content details the enum definition, specific values including Loading and Progressing, and inherited comparison operators for equality and inequality. Key information includes the system capability requirements, the starting version 22, and the inheritance from the Equatable parent type. This documentation is intended for software developers building user interfaces using the ArkUI framework who need to manage and compare progress states in their applications.

### interface_CommonProgres_aac26eff.md
This document serves as an API reference for the CommonProgressStyleOptions interface within the Cangjie programming language, designed to define common style options for progress bars. The content includes the interface definition marked as sealed, a brief functional description, system capability requirements, and the starting version number. Key information highlights that this interface is part of the ArkUI framework, specifically requiring SystemCapability.ArkUI.ArkUI.Full support and available from version 22 onwards. This technical documentation is intended for Cangjie developers and UI engineers working on ArkUI applications who need to implement or customize progress bar styles.
