This directory provides comprehensive API documentation for extending the Int32 type with saturating arithmetic operations within the Cangjie programming language. It focuses on a robust set of functions designed to perform mathematical calculations—such as addition, multiplication, division, and bit shifting—using a saturation strategy. Unlike standard arithmetic that wraps around on overflow or underflow, these operations clamp results to the maximum or minimum Int32 values, ensuring data integrity. This resource is specifically tailored for Cangjie developers who need to implement safe, bounded integer manipulations and prevent common arithmetic errors in their software projects.
