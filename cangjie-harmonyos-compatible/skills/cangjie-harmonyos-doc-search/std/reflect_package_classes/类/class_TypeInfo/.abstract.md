This directory provides comprehensive API reference documentation for the `TypeInfo` class within the Cangjie programming language's `std.reflect` package. It serves as a guide for runtime type inspection, detailing how to programmatically access metadata such as properties, functions, annotations, and inheritance hierarchies. The content covers essential reflection capabilities, including retrieving member information, checking subtype relationships, and handling type modifiers. This documentation is intended for Cangjie developers who require advanced tools for dynamic code analysis and introspection.
