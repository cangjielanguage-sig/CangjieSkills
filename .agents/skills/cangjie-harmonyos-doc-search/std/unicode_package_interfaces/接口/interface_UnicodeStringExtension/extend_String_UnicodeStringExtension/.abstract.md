This directory provides comprehensive API reference documentation for the `UnicodeStringExtension` interface within the Cangjie standard library. It details the extension of the `String` type to facilitate advanced Unicode character set operations, such as case conversion (lower, upper, title), whitespace detection, and string trimming. Key technical elements include the `CasingOption` enum for locale-specific transformations, handling of `IllegalArgumentException` for invalid UTF-8 encoding, and the management of deprecated methods. This resource is essential for Cangjie developers seeking to implement precise text manipulation, validation logic, and input sanitization while adhering to Unicode standards.
