## ohos.permission.INSTALL_BUNDLE

允许应用安装、卸载其他应用（除了企业相关应用，目前有企业InHouse应用，企业MDM应用和企业normal应用）。

**权限级别：** system_core

**授权方式：** 系统授权（system_grant）

**ACL使能：** true

**起始版本：** 12
