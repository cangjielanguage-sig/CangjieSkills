This directory contains API reference documentation for the `Driver` class, the main entry point for the Cangjie UiTest framework. It covers essential functionalities for UI automation, including component location, gesture simulation (touch and mouse), input injection, and device control. Key topics involve assertions, screen capture, and handling asynchronous operations. Designed for developers and QA engineers using the Cangjie language and TestKit, these resources provide the syntax, parameters, and error handling details required to create robust automated test scripts.
