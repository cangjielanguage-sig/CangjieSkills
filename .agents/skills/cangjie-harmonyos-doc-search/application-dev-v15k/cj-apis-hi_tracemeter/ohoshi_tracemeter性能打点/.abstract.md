This directory contains comprehensive API documentation for the HiTraceMeter performance tracking module within the Cangjie programming language ecosystem. It focuses on the `PerformanceAnalysisKit`, providing essential resources for developers to implement instrumentation capabilities such as measuring task duration, recording numerical values, and tracking process trajectories. The documentation covers specific class methods, import instructions, and configuration guidelines for project files like `index.cj` and `main_ability.cj`. It is specifically designed for software developers working on HarmonyOS or OpenHarmony systems who need to monitor application performance, debug execution flows, and analyze trace data using the hiTraceMeter tool. By utilizing these APIs, developers can gain granular insights into their application's runtime behavior, identify bottlenecks, and optimize efficiency effectively. This collection serves as a critical reference for integrating performance analysis into the development lifecycle.
