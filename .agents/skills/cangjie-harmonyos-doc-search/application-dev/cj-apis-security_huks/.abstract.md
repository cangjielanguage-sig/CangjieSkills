This directory functions as the primary API reference documentation for the OpenHarmony Universal KeyStore System (HUKS), meticulously curated for developers using the Cangjie programming language. It provides an extensive overview of the cryptographic capabilities available within the HarmonyOS ecosystem, focusing on the secure management of sensitive data. The directory covers a broad spectrum of functionalities, including the generation of cryptographic keys, their secure storage, and the protocols for importing and exporting them. Additionally, it addresses session management, which is essential for maintaining state during multi-step cryptographic processes. By detailing the classes required to define algorithms, key sizes, padding modes, and access control, this documentation serves as a critical tool for HarmonyOS developers and security engineers. It enables them to implement hardware-backed key management solutions that meet rigorous security standards, ensuring the integrity and confidentiality of applications built on the OpenHarmony platform.
