# digest_使用

This directory is a specialized collection of technical documentation and code examples designed for developers working with the Cangjie programming language. It focuses specifically on the implementation and usage of cryptographic digest algorithms, which are fundamental for ensuring data integrity, security, and authentication in software applications. The directory covers a broad spectrum of hashing standards, ranging from legacy algorithms like MD5 and SHA1 to modern, secure standards such as SHA256, SHA384, SHA512, and the Chinese national standard SM3. Additionally, it explores HMAC (Hash-based Message Authentication Code) implementations for secure message verification. The provided examples illustrate critical programming patterns, including how to handle chunked data processing, manage hash object states, reset instances for reuse, and format output bytes into readable hexadecimal strings. This resource is highly suitable for Cangjie developers who need to implement robust security features, verify data consistency, or handle sensitive information requiring cryptographic protection. By following these practical guides, developers can efficiently integrate complex cryptographic operations into their projects with confidence.

## Detailed Description

### HMAC_算法示例_2more.md HMAC_算法示例_2more.md
This document provides practical code examples for implementing cryptographic hashing algorithms, specifically HMAC-SHA512 and SM3, in the Cangjie programming language. It covers two primary topics: utilizing HMAC-SHA512 member functions for chunked data processing and comparison, and demonstrating the SM3 hash function for string data. Key takeaways include the initialization of hash objects, the use of write and finish methods for data processing, and the ability to reset HMAC instances for reuse. The examples also illustrate hex encoding of output bytes. This tutorial is intended for Cangjie developers seeking to integrate cryptographic security features into their applications.

### MD5_算法示例_6more.md MD5_算法示例_6more.md
This document provides practical code examples for implementing common cryptographic hash algorithms using the Cangjie programming language. It covers six distinct algorithms: MD5, SHA1, SHA224, SHA256, SHA384, and SHA512. Each example demonstrates the standard workflow of importing necessary crypto libraries, instantiating a specific hash class, writing input data, finalizing the computation, and converting the resulting byte array to a hexadecimal string.
