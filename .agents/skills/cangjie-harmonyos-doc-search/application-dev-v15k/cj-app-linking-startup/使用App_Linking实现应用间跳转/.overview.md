# 使用App_Linking实现应用间跳转

This directory provides comprehensive resources for HarmonyOS developers to implement App Linking, enabling secure inter-app navigation and deep linking. It covers the entire development lifecycle, including configuration in AppGallery Connect (AGC), client-side setup in DevEco Studio, and implementation using the Cangjie language. Key topics include domain verification, handling incoming links, and troubleshooting common integration issues. Suitable for developers working on both the calling (source) and target applications, as well as those needing to debug connectivity or routing conflicts.

## Detailed Description

### 简介_4more.md 简介_4more.md
This document serves as an introductory guide for HarmonyOS developers on implementing App Linking to ensure secure and seamless user navigation. It covers the definition, applicable scenarios like scan-to-open and social sharing, and the technical principles involving domain verification and fallback to web content. The guide details the development workflow, outlining specific responsibilities for cloud, client, and frontend developers in the target application, as well as the caller's role. Key takeaways include the requirement for HTTPS URIs and the collaboration between AGC console configuration and DevEco Studio setup to handle links regardless of app installation status.

### 被拉起应用开发指导/
This directory provides a comprehensive guide for HarmonyOS developers on implementing App Linking functionality, allowing applications to be launched directly via web URLs. It covers the end-to-end process from service activation in AppGallery Connect (AGC) to local configuration in DevEco Studio and handling incoming links in Cangjie code. Key topics include domain verification, JSON file hosting, `module.json5` configuration, and URI parsing within lifecycle methods. This resource is suitable for developers seeking to integrate secure deep linking capabilities into their HarmonyOS applications.

### 拉起方实现跳转指导.md 拉起方实现跳转指导.md
This technical guide instructs developers on how to implement App Linking functionality to launch target applications from a caller application. It covers using the AbilityContext.openLink interface with specific parameters like appLinkingOnly and explains automatic redirection via System Browser or ArkWeb. The document details two launch modes: strict App Linking only, which requires exception handling, and App Linking preferred, which defaults to the browser. It also notes domain matching restrictions for web-based redirections and provides a Cangjie code example. This guide targets application developers using the Cangjie language who need to integrate deep linking or cross-app navigation capabilities.

### FAQ.md FAQ.md
This FAQ document serves as a troubleshooting guide for developers implementing HarmonyOS AppLinking and domain verification. It addresses common configuration errors in module.json5 and server-side applinking.json files, alongside network connectivity issues. Key sections explain the domain verification lifecycle, including specific wait times and retry mechanisms, and provide instructions for using the hdc shell hidumper command to verify status. The document also clarifies the many-to-many relationship between apps and domains and how to handle routing conflicts. It is intended for developers resolving integration issues.
