# cj-universal-gesture-longpressgesture

This directory provides essential documentation for the `cj-universal-gesture-longpressgesture` module, focusing on the `LongPressGesture` class used in Cangjie-based ArkUI development. It serves as a comprehensive technical resource aimed at HarmonyOS developers who need to integrate sophisticated long-press interaction capabilities into their user interfaces. The documentation thoroughly covers the complete lifecycle of the gesture, starting from component initialization—where developers can specify parameters like finger count, repetition, and duration—to handling various event callbacks such as onAction, onCancel, and onActionEnd. Furthermore, it clarifies critical behavioral constraints and technical specifications, including the default 500ms duration, the 15px movement threshold that triggers a failure, and the priority rules established when long-press gestures conflict with drag events. By including practical code examples, this guide helps developers effectively bind gestures and manage application states to ensure a smooth user experience.
