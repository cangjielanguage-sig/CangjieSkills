This directory contains essential API reference documentation for the `RichEditorImageSpanResult` class in the Cangjie programming language, specifically designed for the ArkUI framework. It focuses on the data structure used to handle image information returned by the backend in rich text editor components. The content covers a wide range of class properties, including image size, vertical alignment, object fit settings, span position, pixel map content, resource strings, image style, and offset attributes. Furthermore, it details multiple constructors available for object initialization. This documentation is suitable for developers building ArkUI applications who need to manage and display image spans within rich text components effectively.
