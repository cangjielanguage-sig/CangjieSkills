This directory contains comprehensive documentation for the Verification API within a Cangjie language mocking framework. It covers technical references for the `Verify` class, utility methods, error handling, and practical usage patterns for asserting method calls. Key topics include cardinality functions, parameter matching, ordered vs. unordered verification, and the distinction between expectations and verification. The documentation is designed for developers writing unit tests who need to validate interactions between test code and mock or spy objects, ensuring precise control over test assertions and debugging capabilities.
