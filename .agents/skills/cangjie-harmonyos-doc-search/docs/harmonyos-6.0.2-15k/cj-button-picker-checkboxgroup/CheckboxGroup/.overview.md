# CheckboxGroup

This directory provides comprehensive documentation for the CheckboxGroup component within the ArkUI framework, specifically designed for developers using the Cangjie language. It covers the essential aspects of creating, configuring, and managing checkbox groups to handle collective selection states, including select-all functionality. Key topics include the component constructor, property customization for visual styling, and event handling for state changes. This resource is suitable for application developers and UI engineers building interactive forms and multi-selection interfaces in HarmonyOS applications who require detailed API references and practical implementation examples.

## Detailed Description

### CheckboxGroup_4more.md CheckboxGroup_4more.md
This document is API reference material for the CheckboxGroup component in the ArkUI framework. It details how to create a group to control the collective state of checkboxes, enabling select-all functionality. The primary section covers the `init` constructor, which accepts a `group` string parameter to associate checkboxes. Key takeaways include that only the first CheckboxGroup with a matching name is effective and that manual state management is required for cached components like Lists. This guide is intended for developers building UIs in ArkUI version 12 or higher, providing the necessary syntax and system capability details for implementation.

### 组件事件_2more.md 组件事件_2more.md
This document serves as API reference documentation for the CheckboxGroup component's event handling within the Cangjie ArkUI framework. It details the onChange callback function, which triggers when the selection state of the group or its internal checkboxes changes. The content defines the CheckboxGroupResult class, which encapsulates the selection status and a list of selected names, alongside the SelectStatus enum that categorizes states as All, Part, or None. Key takeaways include the specific function signatures and data structures required to manage checkbox interactions. This guide targets developers building user interfaces who need to handle multi-selection logic in HarmonyOS applications.
