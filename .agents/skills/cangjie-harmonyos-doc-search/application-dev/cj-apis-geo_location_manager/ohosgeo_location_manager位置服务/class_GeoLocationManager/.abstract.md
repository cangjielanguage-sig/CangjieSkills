This directory contains comprehensive API reference documentation for the Cangjie `GeoLocationManager` class, specifically designed to facilitate location services within HarmonyOS applications. It covers essential functionalities such as retrieving current geographical coordinates using various request configurations and verifying the operational status of location services. Key topics include detailed method signatures, required system permissions like `ohos.APPROXIMATELY_LOCATION`, return types, and robust exception handling for `BusinessException`. This documentation is primarily suitable for application developers using the Cangjie language who need to integrate precise location features, manage system capabilities, and handle permission constraints effectively in their apps.
