This directory functions as a specialized technical library for the Connectivity Kit, providing a comprehensive glossary of Bluetooth terminology and protocols. It encompasses a broad spectrum of wireless communication standards, ranging from audio and input protocols like A2DP, HFP, and HID to Low Energy (BLE) architectural components such as GATT and Characteristics. Furthermore, it details data access profiles including MAP and PBAP, alongside essential networking concepts like MTU, RSSI, and UUID.
