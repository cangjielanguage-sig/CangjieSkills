This directory contains the API reference documentation for the HarmonyOS Advertising Service Framework, specifically designed for the Cangjie programming language. It comprehensively covers the AdsKit module, providing essential classes and interfaces for configuring ad requests, managing ad loading, handling interaction events, and displaying advertisements. Key components include listeners for status updates, parameter configuration objects, and data structures for ad content. This documentation is suitable for HarmonyOS developers and software engineers looking to integrate robust advertising capabilities, such as Banner, Splash, and Native ads, into their applications while ensuring compliance and efficient performance.
