This directory provides a comprehensive collection of API reference documentation for component properties within the Cangjie ArkUI framework. It focuses extensively on the mechanisms required to style and layout text components, covering a broad spectrum of functional attributes. The documentation details specific functions for adjusting typography, such as font families and weights, as well as layout properties like line spacing and text alignment. By including technical specifications like parameter types, default values, and system capability requirements, it serves as a vital guide for implementing precise visual adjustments. The content emphasizes fluent interface patterns that return the current object instance for efficient method chaining. This directory is intended for software developers and UI engineers utilizing the Cangjie language who need to customize the aesthetic and structural aspects of text in ArkUI applications.
