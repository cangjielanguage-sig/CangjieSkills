This directory contains API reference documentation for functions within the Cangjie programming language's AST and macro processing ecosystem. It covers a wide range of utilities including lexical analysis, token manipulation, AST parsing (declarations, expressions, types, patterns), macro context validation, and error reporting. These functions are essential for metaprogramming tasks, enabling developers to inspect, generate, and transform code programmatically. The documentation is suitable for compiler developers, tool builders, and macro authors who need deep integration with the Cangjie compilation process.
