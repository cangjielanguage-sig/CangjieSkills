# 组件属性

This directory provides comprehensive API reference documentation for configuring the properties of UI components, specifically focusing on the Indexer component within the ArkUI framework using the Cangjie programming language. It covers a wide array of customization options, including alignment, text styling, color schemes, popup behavior, and selection states. Developers can access detailed parameter tables, default values, and method signatures for functions such as `alignStyle`, `popupFont`, and `selectedFont`. This documentation is primarily suitable for UI developers and software engineers aiming to fine-tune the visual presentation and interaction logic of alphabetical index bars and their associated popups in their applications.
