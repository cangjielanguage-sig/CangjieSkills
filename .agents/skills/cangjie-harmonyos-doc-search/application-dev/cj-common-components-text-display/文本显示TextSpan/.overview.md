### 文本显示TextSpan_2more.md 文本显示TextSpan_2more.md
This document provides a guide for developers on implementing text display using the Text and Span components in the ArkUI framework with the Cangjie language. It explains the primary purpose of these components, highlighting Text's support for custom selection menus and Span's role in inline text presentation. The main section details two methods for creating Text instances: using direct string literals or referencing AppResource files via the @r syntax. Key takeaways include practical code examples for both instantiation methods and styling properties. This tutorial targets UI developers seeking to enhance user experience through flexible text rendering and resource management.

### 添加事件_2more.md 添加事件_2more.md
This tutorial guide explains how to add interactive events to Text components and implement a complex layout scenario using the ArkUI framework in Cangjie. The document is divided into two main sections: adding universal events like onClick and a "Hot Search" scenario example. Key takeaways include the syntax for binding click event handlers and the practical application of text styling properties such as maxLines, textOverflow, constraintSize, and textAlign to manage text truncation and alignment. This content is intended for developers seeking to enhance UI interactivity and text display formatting within their applications.

### 添加子组件.md 添加子组件.md
This tutorial guides developers on implementing the Span component within ArkUI using the Cangjie language. It explains that Span must be a child of Text or RichEditor to display content. The document covers four main areas: creating Span instances, configuring text decorations and colors, setting text case (uppercase/lowercase), and adding click events. Key takeaways include the limitation that Span cannot render independently and only supports onClick events due to the absence of size information. This guide is intended for developers building complex text displays, such as product manuals, requiring granular styling and interaction.
