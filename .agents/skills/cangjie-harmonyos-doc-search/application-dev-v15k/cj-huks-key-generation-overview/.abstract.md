This directory provides a comprehensive technical reference focused on the principles and specifications for generating keys using the OpenHarmony HUKS (Hardware Universal KeyStore) service. It serves as a critical resource for understanding how to implement secure cryptographic operations within the OpenHarmony ecosystem. The documentation covers essential key generation concepts, including the importance of cryptographic randomness, mechanisms for secure storage, and specific usage restrictions designed to enhance security. Furthermore, it offers detailed algorithm specifications tailored to different device capabilities, distinguishing between standard and lightweight device profiles. Key topics include supported algorithms such as AES, RSA, ECC, SM2, and SM4 for standard devices, and AES, DES, and 3DES for lightweight devices. This guide is specifically suitable for application developers and system architects who require a deep understanding of key lifecycle management and algorithm compatibility, ensuring their applications meet the security standards required for API level 15 or higher. By adhering to these specifications, developers can guarantee that keys are cryptographically secure, stored in a secure area, and restricted to single purposes such as encryption or signing.
