# 基础类型定义

This directory serves as a comprehensive repository for basic type definitions within the Cangjie ArkUI framework, specifically targeting the configuration and customization of button components. It provides the essential structural blueprints that developers need to programmatically define button attributes, ensuring precise control over user interface elements. The content encompasses detailed API references for configuration classes that manage display styles, as well as enumerations that specify geometric shapes, functional roles, and visual emphasis modes. By covering properties such as state effects, control size, and button types, this directory equips UI developers and system architects with the critical tools required to build responsive, interactive, and visually consistent applications.

## Quick Navigation

## Detailed Description

### class_ButtonOptions.md class_ButtonOptions.md
This API reference document details the `ButtonOptions` class in the Cangjie language, designed to configure the display style of buttons within the ArkUI framework. The documentation covers the class definition, five configurable properties including shape, state effect, style mode, control size, and role, and the class constructor. Key information includes the read-write capabilities of all properties and the default values provided in the constructor, such as `ButtonType.Capsule` and state effect enabled. This resource is intended for developers using ArkUI who need to programmatically customize button appearance and interaction behavior.

### enum_ButtonRole_3more.md enum_ButtonRole_3more.md
This API reference document defines enumeration types for button properties within the Cangjie ArkUI framework. It details three primary enums: `ButtonRole` for functional roles like normal or error states, `ButtonStyleMode` for visual emphasis levels, and `ButtonType` for geometric shapes such as capsule or circle. Key information includes specific enum values, system capabilities, and version 19 compatibility. Notably, `ButtonRole` and `ButtonStyleMode` include a deprecated `getValue` function for retrieving integer mappings. This documentation targets developers building user interfaces, providing the necessary definitions to customize button appearance and behavior in ArkUI applications.
