This directory provides comprehensive API reference documentation for the OpenHarmony Bluetooth Hands-Free Profile (HFP) module, specifically tailored for the Cangjie programming language. It encompasses the essential components required to implement hands-free communication features, including module imports, system capabilities, and necessary permissions such as `ohos.permission.ACCESS_BLUETOOTH`. The documentation details the creation and management of the `HandsFreeAudioGatewayProfile`, enabling developers to handle Bluetooth call interfaces, connection states, and device events. This resource is ideal for software developers working on HarmonyOS applications who need to integrate robust Bluetooth audio gateway functionalities using Cangjie syntax. By following these guides, developers can effectively manage device connections, ensure proper error handling, and implement seamless audio streaming for hands-free scenarios.
