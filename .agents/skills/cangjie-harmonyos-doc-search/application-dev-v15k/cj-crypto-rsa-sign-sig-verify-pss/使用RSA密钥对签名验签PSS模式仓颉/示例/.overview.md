# 示例

This directory serves as a comprehensive practical resource for developers working with the Cangjie programming language, specifically focusing on cryptographic implementations using the CryptoArchitectureKit. It provides detailed code examples that cover fundamental security operations, including the manual construction of RSA asymmetric key pair specifications and the execution of digital signing and verification processes. The examples illustrate how to handle large integers using BigInt, configure specific algorithm parameters like salt length and mask generation functions, and manage multi-part data updates securely. These tutorials are designed for software engineers and security professionals who require a deep understanding of how to integrate and configure advanced cryptographic primitives, such as RSA PSS with SHA256, within their Cangjie-based applications to ensure data integrity and authenticity. By following these examples, users can gain hands-on experience with the library's API structure and best practices for secure coding, ensuring they can effectively implement robust security features in their software projects.

## Detailed Description

The following files provide specific code examples and structural skeletons for cryptographic tasks in Cangjie.

### 示例_1.md
This document provides a synchronous code example demonstrating how to construct RSA asymmetric key pair specifications using the Cangjie programming language and the CryptoArchitectureKit. The content focuses on defining functions to create RSACommonParamsSpec and RSAKeyPairSpec objects, utilizing BigInt for handling large numerical values like modulus and exponents. Key takeaways include the implementation of a helper function genRsaKeyPairSpec for general construction and genRsa2048KeyPairSpec, which parses hexadecimal strings to generate a specific RSA-2048 key pair configuration. This tutorial is intended for developers implementing cryptographic operations in Cangjie who need to manually define or import RSA key parameters.

### 示例_2.md
This code example demonstrates the implementation of digital signing and verification using the RSA PSS algorithm with SHA256. The primary topics covered include generating RSA 2048 key pairs, initializing signer and verifier objects, and configuring PSS-specific parameters such as salt length, trailer field, and mask generation function (MGF) settings. Key takeaways include the methods for setting and retrieving cryptographic specifications, handling multi-part data updates, and validating the final signature result. Intended for developers integrating cryptographic security, this snippet illustrates the correct sequence of operations for secure message authentication using advanced RSA schemes.
