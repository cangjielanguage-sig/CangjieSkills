## Detailed Description

The following files provide in-depth information on the technical specifications and coding practices required for successful WebSocket integration.

### 场景介绍_2more.md
This document provides a technical overview and API reference for implementing WebSocket connections in HarmonyOS applications. It covers the connection lifecycle including creation, connection establishment, data transmission, disconnection, and error handling, alongside a heartbeat mechanism. Key interfaces include createWebSocket, connect, send, and close, along with event subscription methods (on/off) for open, message, close, and error events. The ohos.permission.INTERNET permission is required. This guide targets developers needing real-time bidirectional communication features. Keywords: WebSocket, HarmonyOS, API, NetworkKit, bidirectional communication, heartbeat, event subscription.

### 开发步骤.md
This document provides a step-by-step tutorial for implementing WebSocket communication using the Cangjie programming language and NetworkKit. It outlines a five-step development process covering module import, connection creation, event subscription, connection initiation, and active disconnection. The included code example demonstrates handling asynchronous callbacks for open, message, close, and error events, alongside methods for sending data and managing the connection lifecycle. Targeted at Cangjie developers, this guide serves as a practical reference for integrating real-time network communication capabilities into applications.
