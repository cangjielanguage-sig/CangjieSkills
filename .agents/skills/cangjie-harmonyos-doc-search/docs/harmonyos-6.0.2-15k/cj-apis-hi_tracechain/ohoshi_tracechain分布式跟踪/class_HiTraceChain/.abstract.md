This directory contains API reference documentation for the `HiTraceChain` class in the Cangjie language, designed for the PerformanceAnalysisKit within HarmonyOS. It covers distributed tracing and call chain tracking functionalities, enabling developers to monitor system performance and debug complex workflows. The documentation details static methods for initiating traces, managing trace identifiers, controlling trace flags, and implementing tracepoints. It is suitable for developers looking to implement or manage distributed tracing in their applications to ensure efficient performance analysis and lifecycle management of trace chains.
