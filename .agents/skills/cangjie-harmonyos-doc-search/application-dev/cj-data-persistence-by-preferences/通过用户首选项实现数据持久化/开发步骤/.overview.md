# 开发步骤

This directory serves as a practical resource for developers working with the Cangjie programming language in the HarmonyOS ecosystem, specifically focusing on the implementation and management of lightweight data storage. It provides detailed instructions on utilizing the Preferences API to handle local application data efficiently. The scope of these documents encompasses the entire data management lifecycle, including the initialization of storage instances, performing essential read and write operations, ensuring data persistence through flushing, and managing data change notifications. Furthermore, it addresses critical maintenance tasks such as the proper deletion of storage instances and the cleanup of persistent files to maintain system hygiene. This guide is ideal for application developers seeking robust solutions for local data persistence, memory management, and data integrity within their HarmonyOS applications.

## Detailed Description

### 开发步骤_1.md
This document serves as a step-by-step tutorial for implementing lightweight data storage using the Preferences API in the Cangjie programming language for HarmonyOS development. It covers module imports, obtaining Preferences instances, and core data operations including writing, reading, and deleting key-value pairs. Additionally, it details data persistence via the flush method and subscribing to data change notifications using custom callbacks. Key takeaways include understanding that put() overwrites existing values and flush() is essential for saving data to disk. Targeted at application developers familiar with Cangjie syntax and HarmonyOS architecture, this guide provides practical code examples for managing local application settings and simple data efficiently.

### 开发步骤_2.md
This document serves as a technical guide for using the deletePreferences() method in Cangjie development to remove data storage instances. It details the method's functionality, which involves clearing the instance from memory and deleting associated persistent files, including backups and corrupted files. Key takeaways include strict warnings against using the instance post-deletion to prevent data consistency issues and the irreversibility of the deletion process. The content includes a practical code example demonstrating error handling. This resource is intended for developers managing application data persistence and cleanup. Keywords: deletePreferences, Cangjie, data persistence, memory management, API reference.
