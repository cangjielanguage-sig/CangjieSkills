# 音频录制流管理

This directory provides a comprehensive technical guide for developers focused on audio recording stream management within the Cangjie programming environment. It specifically utilizes the AudioKit API to demonstrate how to effectively monitor and control audio capture processes. The content covers the implementation of the AudioStreamManager for overseeing system-wide streams and the AudioCapturer for managing application-specific recording states. Key topics include subscribing to change events, retrieving stream information such as unique IDs and client UIDs, and handling device descriptors. Additionally, the documentation underscores the critical requirement of declaring the `ohos.permission.USE_BLUETOOTH` permission to access accurate device names and addresses. This resource is tailored for developers building recording applications who need to ensure precise audio state management and seamless integration with system hardware.

## Detailed Description

### 开发步骤及注意事项.md 开发步骤及注意事项.md
This technical guide details the implementation steps for managing audio capture streams using the AudioStreamManager API in the Cangjie language. It covers creating the manager instance, subscribing to audio capturer change events via callbacks, and optionally retrieving current stream information. Key takeaways include the specific code structure for handling device descriptors and the critical requirement to declare the ohos.permission.USE_BLUETOOTH permission to access accurate device names and addresses. This document serves as a practical tutorial for developers needing to monitor audio recording states and device configurations within their applications.

### 音频录制流管理_3more.md 音频录制流管理_3more.md
This guide explains how to monitor and manage audio recording stream states for applications. It covers monitoring application-specific streams via AudioCapturer and managing all system recording streams via AudioStreamManager. Key information includes checking the state property or registering stateChange callbacks for specific streams, and using getStreamManager(), on(), and getCurrentAudioCapturerInfoArray() for global stream monitoring and querying details like unique IDs and client UIDs. Intended for developers using the AudioKit API in Cangjie to build recording applications, this document assumes prior knowledge of creating AudioCapturer instances.
