# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the Cangjie ArkUI framework, with a specific focus on image components. It covers essential functionalities such as setting image sources, managing display attributes, optimizing memory usage, and handling user interactions. Key topics include placeholder configuration, color transformations, drag-and-drop capabilities, object fitting, and loading strategies. Designed for software developers and UI engineers, these documents offer detailed parameters, system capabilities, and constraints to facilitate the creation of high-performance, visually consistent user interfaces using the Cangjie language.

## Detailed Description

### func_altString_6more.md
This document serves as API reference documentation for image component configuration functions within the Cangjie ArkUI framework. It details methods for setting placeholder images using various sources like String, AppResource, and PixelMap, optimizing memory usage through automatic resizing during decoding, applying color transformations via RGBA matrices, and controlling clipboard interaction permissions. Key information includes that `alt` supports local formats but not network images, `autoResize` reduces memory by downsampling to display size, and `colorFilter` overrides the `renderMode` attribute. Additionally, `copyOption` enables copying via gestures but excludes SVG support. This technical reference is intended for developers utilizing the Cangjie language to build and optimize user interfaces in ArkUI applications.

### func_draggableBool_7more.md
This document serves as an API reference for configuring image display and component interaction properties within the Cangjie ArkUI framework. It details seven specific functions: draggable, dynamicRangeMode, fillColor, fitOriginalSize, interpolation, matchTextDirection, and objectFit. Each entry defines the function signature, system capability, starting version, and parameters. Key information includes constraints such as the incompatibility of draggable with onDragStart events, and limitations for SVG sources regarding dynamic range and interpolation settings. This technical reference is intended for developers using the Cangjie language to build user interfaces, requiring knowledge of basic UI component properties and resource handling.

### func_objectRepeatImageRepe_4more.md
This document serves as an API reference for configuring image display properties within the ArkUI framework using the Cangjie language. It details four specific functions: objectRepeat, renderMode, sourceSize, and syncLoad. Key information includes parameter definitions, default values, and specific constraints such as SVG incompatibility for repetition and rendering modes, and the recommendation to use synchronous loading only for small local images to prevent UI blocking. This guide is intended for software developers working on ArkUI applications who require fine-grained control over image decoding, rendering styles, and loading strategies.
