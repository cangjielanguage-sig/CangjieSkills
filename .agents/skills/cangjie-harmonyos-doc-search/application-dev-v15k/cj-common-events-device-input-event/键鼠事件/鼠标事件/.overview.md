# 鼠标事件

This directory focuses on mouse interaction handling within the Cangjie UI framework (ArkUI). It covers essential APIs for managing mouse events, including hover states, click detection, and cursor tracking. Key topics include the `hoverEffect` function for visual feedback, the `onMouse` callback for detailed event data, and the integration of mouse inputs with touch gesture systems. This documentation is suitable for UI developers looking to implement desktop or mouse-based interactive features in Cangjie applications.

## Quick Navigation

- **What do you want to do?**
    - Apply built-in visual effects when the mouse hovers over a component → hoverEffect.md
    - Handle detailed mouse events like clicks, coordinates, and button states → onMouse.md
    - Understand the general logic of mouse events and their integration with touch gestures → 鼠标事件_2more.md

## Detailed Description

### hoverEffect.md
This API documentation explains the usage of the hoverEffect function in Cangjie for defining mouse hover state behaviors on UI components. It covers the function signature, the HoverEffect enumeration, and a practical code example demonstrating different visual styles. The document details four fixed effect modes: Auto (component default), Scale (size animation), Highlight (background darkening), and None (disabled). It emphasizes that these effects are non-customizable. Targeted at Cangjie UI developers, this reference guide helps implement interactive visual feedback for desktop or mouse-based interfaces.

### onMouse.md
This document provides API reference documentation for the onMouse function in the Cangjie UI framework, detailing how to handle mouse events on components. It covers the function signature, a description of the MouseEvent callback parameters (coordinates, buttons, actions), a note on button states, and a practical code example demonstrating event handling on a Button and Column. Key takeaways include the ability to capture specific mouse data like screen coordinates and button types, support for event bubbling, and the usage of the MouseEvent object to implement custom interaction logic. Intended for developers building UI applications in Cangjie who need to implement custom mouse interactions, requiring knowledge of basic UI components and event handling.

### 鼠标事件_2more.md
This document serves as a technical reference for implementing mouse interactions in the ArkUI framework using the Cangjie language. It covers the primary mouse events, specifically onHover for tracking cursor entry and exit, and onMouse for handling clicks and movements. Key sections explain the event processing logic, where left-click actions are converted into touch events for unified handling, and detail the hoverEffect attribute. The document provides a practical code example demonstrating how to bind the onHover callback to dynamically change a component's appearance. Intended for UI developers, this guide ensures compatibility between mouse inputs and existing touch gesture systems.
