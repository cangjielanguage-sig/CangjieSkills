This directory provides essential API reference documentation for the `cj-apis-hi_tracechain` module, specifically developed for the Cangjie language within the HarmonyOS environment. It is dedicated to the implementation of distributed tracing, a critical feature for modern application development that allows for the observation of service interactions. The content covers the core classes and enums necessary to execute call chain tracking, conduct performance analysis, and perform debugging across complex boundaries including devices, threads, and processes. Key components detailed in this documentation include the `HiTraceChain` class, the `HiTraceId` structure, and various enums defining flags and tracepoint types. This resource is specifically suitable for HarmonyOS developers utilizing the PerformanceAnalysisKit who need to monitor system performance, instrument business processes, and manage trace lifecycles in distributed systems, starting from API version 12.
