# PBKDF2

本目录包含关于使用仓颉语言和HUKS接口实现PBKDF2密钥派生算法的文档。内容涵盖了密钥参数定义、三阶段派生流程（初始化、更新、完成）以及密钥的完整生命周期管理。核心知识点包括AES算法配置、SHA256摘要、盐值处理及迭代次数设置。这些资料适合需要在HarmonyOS应用中实现安全密钥管理功能的开发人员参考，旨在指导其构建安全的密钥派生解决方案。

## 详细描述

### PBKDF2_1.md PBKDF2_1.md
本文档提供了使用通用密钥库套件进行PBKDF2密钥派生的仓颉代码示例。文档涵盖了定义密钥参数、构建用于生成密钥、初始化及完成派生过程的参数集。关键信息包括针对AES算法、SHA256摘要、盐值、迭代次数及存储标志的具体HuksParam配置，展示了三阶段派生流程。该文档属于代码教程，面向熟悉仓颉语言和密码学概念的开发者，旨在指导其在应用中实现安全的密钥派生功能。

### PBKDF2_2.md PBKDF2_2.md
该文档旨在演示如何通过HUKS接口实现PBKDF2密钥派生算法，重点展示了基于会话的三阶段操作流程。文档涵盖了初始化、更新和结束会话的底层封装函数，以及密钥生成与删除的公共接口。关键信息包括通过Init、Update、Finish步骤完成数据派生，利用自定义对象进行统一的异常处理和日志记录，并在testDerive函数中整合了从密钥生成、派生操作到密钥销毁的完整生命周期。这主要面向需要实现安全密钥管理功能的开发人员，特别是涉及HarmonyOS系统集成的场景。
