# cj-media-kit-intro

This directory serves as an introductory resource for the Media Kit framework, a comprehensive solution tailored for the Cangjie (CJ) ecosystem. It focuses on the development of robust audio and video playback, recording, and processing functionalities. The content covers a wide array of essential modules, including AVPlayer, AVRecorder, AVScreenCapture, SoundPool, AVMetadataExtractor, and AVImageGenerator. Key features highlighted in this documentation include a lightweight engine architecture, HDR video support, low-latency audio performance, and robust encoding capabilities. Furthermore, it details the system architecture, data flow, and supported formats such as MP4, M4A, H264, and H265. This resource is specifically suitable for application developers utilizing Cangjie, JS, or Native interfaces who require the technical specifications to implement advanced multimedia features, ranging from local file playback to network streaming and screen recording.

## Detailed Description

### Media_Kit简介/
Media Kit is a comprehensive framework designed for developing audio and video playback and recording functionalities. It covers modules like AVPlayer, AVRecorder, AVScreenCapture, SoundPool, AVMetadataExtractor, and AVImageGenerator. Key features include a lightweight engine, HDR video support, low-latency audio, and robust encoding capabilities. The documentation details system architecture, data flow, supported formats (MP4, M4A, H264, H265), and integration with hardware interfaces. Suitable for application developers using Cangjie, JS, or Native interfaces, this kit provides the necessary specifications to implement multimedia features, from local playback to network streaming and screen recording.
