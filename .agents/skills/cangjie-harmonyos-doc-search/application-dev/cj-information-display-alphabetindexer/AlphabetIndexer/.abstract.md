This directory contains comprehensive documentation for the AlphabetIndexer component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of alphabetical or logical indexing to facilitate rapid navigation in user interfaces. The content includes API references for component creation, event handling, property configuration, and practical code examples for custom popup displays. It is suitable for HarmonyOS developers and UI engineers looking to integrate interactive index bars and manage data linkage in their applications.
