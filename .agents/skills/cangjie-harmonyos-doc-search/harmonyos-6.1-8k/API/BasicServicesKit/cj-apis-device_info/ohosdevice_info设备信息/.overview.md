# ohosdevice_info设备信息

本目录包含关于 `ohos.device_info` 模块的详细文档，该模块专为鸿蒙系统开发设计，使用仓颉语言编写。它主要用于查询终端设备的静态属性，包括设备标识符、硬件规格、系统构建信息及各类版本号。所有属性均为只读，部分敏感信息需要特定权限。该模块目前处于 Beta 阶段，适合需要获取设备元数据进行应用逻辑判断、数据统计或适配的鸿蒙应用开发者。
