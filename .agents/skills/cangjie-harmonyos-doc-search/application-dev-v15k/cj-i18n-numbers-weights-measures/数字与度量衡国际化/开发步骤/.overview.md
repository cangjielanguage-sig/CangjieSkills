# 开发步骤

This directory contains technical guides for implementing internationalization (i18n) features using the LocalizationKit in the Cangjie programming language. It covers essential development steps for formatting numbers, converting measurement units, and handling currency displays across different locales. Key topics include number formatting styles, unit conversion logic, and locale-specific configurations. These resources are designed for developers working on globalized applications who need to standardize data presentation, ensuring accurate and culturally appropriate output for users worldwide.

## Quick Navigation

**What do you want to learn?**

*   Convert measurement units (e.g., US cups to liters) and manage localization styles → 度量衡转换.md
*   Format numbers with specific grouping, notation, or digit limits → 数字格式化.md
*   Format currencies and units with precise display configurations → 货币和单位格式化.md

## Detailed Description

### 度量衡转换.md
This document serves as a technical guide for implementing measurement unit conversions and localization formatting using the LocalizationKit. It details the usage of the `I18NUtil.unitConvert` interface, explaining parameters for source and target units, values, and locale settings. Key sections include module import instructions, a breakdown of formatting styles (long, short, narrow), and a practical Cangjie code example demonstrating the conversion from US cups to liters. The document is designed for developers seeking to standardize unit display across different regions, providing clear examples of how to manipulate output styles for internationalized applications.

### 数字格式化.md
This document provides a guide for implementing number formatting in the Cangjie programming language using the LocalizationKit's `NumberFormat` class. It covers the development workflow including module import, object creation, and formatting methods, followed by a detailed reference of `NumberOptions` parameters like digit limits, grouping, and notation styles. The text explains how to configure locale-specific formatting, scientific or compact notation, and currency or percentage styles, supported by illustrative tables and code examples. Targeted at Cangjie developers, this guide requires basic knowledge of the language and serves as a practical reference for internationalization tasks.

### 货币和单位格式化.md
This document serves as a technical guide for formatting currencies and measurement units using the LocalizationKit API in the Cangjie language. It covers configuration parameters such as currency sign, display style, unit display format, and specific usage scenarios, providing tables that illustrate output variations. Key takeaways include understanding how to utilize `NumberOptions` to define styles like 'currency' or 'unit' and implementing these via the `NumberFormat` class. The content includes practical code examples demonstrating how to generate localized strings for financial and metric data. This resource is intended for developers implementing internationalization features who require precise control over number presentation.
