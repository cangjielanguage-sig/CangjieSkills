# 网络连接管理

本目录提供了基于仓颉语言进行HarmonyOS网络连接管理的开发指南与API参考。内容涵盖网络状态监控、域名解析、网络能力查询及连接重建等核心功能。通过使用NetworkKit，开发者可以管理WiFi、蜂窝及以太网网络，实现应用与特定网络的绑定、优先级控制及DNS解析。本文档适合需要处理网络状态迁移、优化网络连接质量或进行底层网络查询的HarmonyOS应用开发者，帮助他们构建稳定高效的网络通信模块。

## 详细说明

### 使用对应网络解析域名获取所有IP_ef16fd67.md 使用对应网络解析域名获取所有IP_ef16fd67.md
本文档旨在指导开发者如何在仓颉应用中通过默认网络解析域名以获取所有IP地址。文档涵盖了权限声明、NetworkKit包导入以及核心API调用三个主要步骤。关键信息包括需要申请ohos.permission.INTERNET权限，使用kit.NetworkKit中的connection模块，并调用getAddressesByName方法。文档提供了完整的仓颉代码示例，展示了如何实现该功能及日志记录。目标受众为使用仓颉语言进行HarmonyOS应用开发的开发者，需具备基本的网络编程知识。

### 接收指定网络的状态变化通知.md 接收指定网络的状态变化通知.md
本文档是一份开发指南，旨在指导开发者如何在HarmonyOS应用中接收指定网络的状态变化通知。文档详细介绍了声明权限、导入NetworkKit、创建NetConnection对象、注册订阅以及处理网络可用和不可用回调的完整流程。通过提供的Cangjie代码示例，展示了如何配置网络规格、设置超时时间及实现事件监听。关键步骤包括使用createNetConnection方法、register和unregister方法。目标受众为需要监控网络状态的应用开发者，需具备基本的Cangjie语言和HarmonyOS开发知识。

### 监控默认网络变化并主动重建网络连接_2more_b3742a72.md 监控默认网络变化并主动重建网络连接_2more_b3742a72.md
本文档旨在指导开发者使用Cangjie语言监控默认网络变化并主动重建连接，以应对网络状态切换。文档首先列举了网络切换的常见场景，随后详细介绍了如何通过NetConnection监听网络可用性事件，并提供了获取所有已注册网络列表的代码示例。关键内容包括使用getAllNets方法及申请ohos.permission.GET_NETWORK_INFO权限。本文属于技术开发指南，面向需要处理网络状态迁移的HarmonyOS应用开发者。

### 网络连接管理_6more_65fa1dd8.md 网络连接管理_6more_65fa1dd8.md
本文档是使用仓颉语言进行网络连接管理的指南和API参考。它涵盖了WiFi、蜂窝和以太网网络的管理，包括优先级控制、质量评估和DNS解析。主要部分包括网络生产者与消费者等基本概念、使用场景以及详细的接口列表。文档详细介绍了获取默认网络、绑定应用到特定网络、查询连接属性及订阅状态变化的API。该文档面向需要在应用中实现网络监控、优化和连接功能的仓颉开发者。

### 根据数据网络查询网络的能力信息及连接信息/
本目录包含关于如何使用数据网络查询网络能力及连接信息的开发指南与技术文档。内容主要涵盖NetworkKit的使用方法，包括权限声明、模块导入、获取网络句柄（NetHandle）、解析网络类型（如蜂窝、Wi-Fi）以及遍历所有可用网络以获取详细属性。文档通过Cangjie代码示例演示了`getDefaultNet`、`getNetCapabilities`和`getConnectionProperties`等关键API的调用。适用于HarmonyOS应用开发者，特别是需要处理网络连接状态和属性查询的软件工程师。
