This directory provides a specialized technical guide focused on the implementation of system-wide dark and light mode adaptation for applications developed using the Cangjie framework. It addresses the growing need for applications to dynamically adjust their visual appearance based on user system settings, thereby enhancing user comfort and experience. The documentation covers a wide array of implementation strategies, ranging from basic color adaptation using custom resource directories or system resource IDs to more complex image adaptation via resource qualifiers or SVG fill properties. Additionally, it includes specific instructions for configuring Web components to ensure they respect the current theme. The guide also delves into the programmatic aspects of theming, such as listening for mode switch events and handling configuration updates. Key technical concepts discussed include the `dark` resource qualifier, `AbilityStage` lifecycle methods, `AppStorage`, and `@Watch` decorators. This resource is primarily suitable for developers and UI engineers who are looking to build robust, responsive applications that offer a seamless visual experience across both light and dark system environments.
