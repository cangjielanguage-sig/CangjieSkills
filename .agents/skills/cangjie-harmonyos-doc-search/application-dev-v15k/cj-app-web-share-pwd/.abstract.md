This directory contains the technical documentation necessary for enabling shared account passwords between mobile applications and web pages via the Password Locker service. It provides a detailed overview of the feature, including its introduction, applicable scenarios, and the specific integration steps required for implementation. The content focuses on the critical requirement to integrate auto-fill capabilities for both platforms and bind them using App Linking. It further explains the process of enabling App Linking in the AGC console, associating the application, and configuring domain names. This guide is suitable for developers seeking to streamline user login experiences across app and web environments, ensuring that saved credentials are recommended and usable interchangeably to enhance user convenience.
