# cj-har-package

The `cj-har-package` directory functions as a specialized technical resource center for the Harmony Archive (HAR) format, a pivotal component within the HarmonyOS ecosystem. It offers in-depth documentation regarding static shared packages, which are essential for the efficient distribution of Cangjie components, source code, and various resource files. The provided material comprehensively covers the full lifecycle of HAR packages, starting from their fundamental definitions and system constraints to the practical aspects of development and element export. Furthermore, it guides developers through the consumption of these packages in applications and outlines the critical compilation and publishing processes. This documentation is explicitly designed for HarmonyOS developers who employ DevEco Studio and the Cangjie programming language, providing the necessary knowledge to modularize codebases effectively and share libraries across diverse projects and development teams.

## Detailed Description

The following subsection details the specific contents of the directory, outlining the scope of the technical documentation provided for the Harmony Archive (HAR) format.

### HAR/
This directory contains technical documentation for the Harmony Archive (HAR) format within the HarmonyOS ecosystem. It covers the complete lifecycle of HAR packages, which are static shared packages used for distributing Cangjie components, code, and resources. Key topics include the definition and constraints of HARs, how to develop and export elements, how to consume them in applications, and the compilation and publishing processes. This documentation is suitable for HarmonyOS developers using DevEco Studio and the Cangjie programming language who need to modularize code or share libraries.
