This directory contains comprehensive API reference documentation for handling component events within the ArkUI framework, specifically utilizing the Cangjie language. The content primarily focuses on scroll event handling, equipping developers with the necessary tools to intercept, modify, and monitor scroll behaviors with high precision. Key topics covered include frame-based offset interception, edge effect detection, and the observation of scroll states before and after movement occurs. This documentation is highly suitable for UI developers and system architects who aim to implement custom scroll mechanics, manage nested scrolling scenarios, and ensure robust control over user interactions and boundary effects in their applications.
