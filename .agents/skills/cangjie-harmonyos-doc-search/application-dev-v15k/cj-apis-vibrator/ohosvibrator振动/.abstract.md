This directory contains API reference documentation for the OpenHarmony (OHOS) vibrator module, specifically designed for the Cangjie programming language. It covers the implementation of haptic feedback and motor vibration control, including time-based, preset, and custom file-based vibration effects. Key components include classes for vibration attributes, descriptors for custom files, and enums for usage scenarios and stop modes. The documentation also details functions for starting and stopping vibrations, along with system capability checks. This resource is suitable for Cangjie developers integrating sensor interactions and haptic feedback into their applications, requiring knowledge of file management and system permissions.
