# 组件事件

This directory provides comprehensive API reference documentation for the ArkUI Swiper component, specifically tailored for the Cangjie programming language. It focuses on the intricate aspects of component events, ranging from advanced animation control to standard lifecycle management. The content covers essential functionalities such as defining custom frame-by-frame content transitions, handling animation completion callbacks, and responding to user gestures or index changes. By detailing parameters like scroll offsets, target indices, and translation behaviors, these documents serve as a critical resource for HarmonyOS developers. They are intended for those looking to build highly interactive and visually dynamic carousel or slider interfaces, requiring a deep understanding of the ArkUI framework and Cangjie syntax to effectively manage component states and visual effects.

## Detailed Description

### func_customContentTransiti_2more.md func_customContentTransiti_2more.md
This document serves as API reference documentation for the ArkUI Swiper component in the Cangjie language, focusing on advanced animation control. It covers two primary functions: customContentTransition, which allows developers to define custom frame-by-frame animations for page switching by manipulating properties like opacity and scale, and onAnimationEnd, which registers a callback triggered when switching animations conclude. Key information includes specific behaviors for loop scenarios, swipe groups, and methods to offset default sliding using negative translation. The document also details callback parameters, such as the final index and displacement. Intended for HarmonyOS developers, this reference requires prerequisite knowledge of the ArkUI framework and Cangjie syntax to implement custom visual effects and handle animation lifecycle events effectively.

### func_onAnimationStartInt32_4more.md func_onAnimationStartInt32_4more.md
This API reference document details event handling functions for the Swiper component in the Cangjie ArkUI framework. It covers four specific callback functions: onAnimationStart, onChange, onContentDidScroll, and onGestureSwipe. Key information includes the specific triggers for each event, such as animation starts, index changes, and sliding processes, along with their respective parameters like current index, target index, and scroll offsets. The document also highlights important constraints, such as avoiding UI refreshes in onChange when using LazyForEach. This guide is intended for developers implementing interactive carousel or slider interfaces.
