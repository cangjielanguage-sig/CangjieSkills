This directory contains essential technical documentation for Cangjie developers focusing on the implementation of internationalization (i18n) features. It specifically addresses how to accurately retrieve system language and region settings using the LocalizationKit. The content provides a deep dive into the implementation principles governing language lists and region definitions, offering step-by-step development instructions to guide the integration process. Beyond basic retrieval, the guide explains complex behaviors such as how the system manages extended parameters during language switching, particularly the mechanism for removing attributes that do not match the new language. By including code examples for importing modules and calling critical System APIs like `getSystemLanguage`, `getSystemRegion`, and `getSystemLocale`, this document serves as a practical reference for building dynamic, locale-aware applications that handle specific attributes efficiently.
