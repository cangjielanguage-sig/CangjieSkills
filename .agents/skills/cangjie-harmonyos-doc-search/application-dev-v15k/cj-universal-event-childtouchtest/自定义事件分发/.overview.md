# 自定义事件分发

This directory covers the mechanism for custom touch event distribution in the ArkUI framework using the Cangjie language. It focuses on how parent nodes can influence child node touch testing before events are dispatched, allowing for granular control over gesture conflicts and event propagation. Key topics include the `onChildTouchTest` function, `TouchResult` classes, and dispatch strategies like `FORWARD_COMPETITION`. This documentation is suitable for HarmonyOS developers and UI engineers who need to implement sophisticated touch interactions, manage overlapping component behaviors (such as Lists and Buttons), and customize event flows beyond standard system defaults.
