# class_FuncType

This directory provides comprehensive API documentation for the `FuncType` class and related traversal mechanisms within the Cangjie programming language's Abstract Syntax Tree (AST) framework. It focuses on the structural representation of function types, detailing how syntax elements like arrows, parentheses, and type parameters are modeled. The content covers essential operations such as constructing AST nodes from token collections, converting nodes back to tokens, and traversing the syntax tree using the Visitor pattern. Key concepts include handling specific syntax structures like `(Int32) -> Unit` and managing traversal flow. This documentation is primarily suitable for compiler developers, language engineers, and programmers involved in parsing, analysis, or transformation of Cangjie code.

## Detailed Description

### class_FuncType_11more.md class_FuncType_11more.md
This API documentation defines the FuncType class, which represents function type nodes within an Abstract Syntax Tree (AST) for the Cangjie programming language. The document details the class structure, including mutable properties for syntax elements like arrows, parentheses, keywords, and the specific parameter and return type nodes. It also covers constructors for creating instances from token collections and a method to convert nodes back to tokens. Key information includes the handling of the (Int32) -> Unit syntax structure and the throwing of ASTException for invalid token assignments. This reference is intended for compiler developers or programmers working with AST manipulation who need to programmatically parse or construct function types.

### func_traverseVisitor.md func_traverseVisitor.md
This document serves as API reference documentation for the traverse function within the Cangjie AST package. It details the method used to traverse the current syntax tree node and its child nodes using a provided Visitor instance. The documentation outlines the function signature, specifically the v parameter which accepts a Visitor type, and explains the mechanism for controlling traversal flow. Key information includes the ability to terminate the traversal early by overriding the visit function and invoking breakTraverse. The text also references a sample guide for customizing visitor functions. This resource is designed for developers and language engineers who require programmatic access to AST structures for analysis or transformation tasks.
