# class_SM2PrivateKey

This directory contains API reference documentation for the `SM2PrivateKey` class within the Cangjie programming language. It focuses on the comprehensive management, parsing, and utilization of SM2 private keys for cryptographic security. Key topics include key initialization, decoding from DER and PEM formats (including support for password-protected keys), data decryption, and digital signing using SM3 hashing. The documentation details essential functions such as `init`, `decodeDer`, `decodeFromPem`, `decrypt`, and `encodeToDer`. This resource is specifically designed for software developers implementing security features who require precise guidance on SM2 key generation, serialization, and cryptographic operations.

## Detailed Description

### class_SM2PrivateKey_8more.md
This document provides API reference documentation for the SM2PrivateKey class in the Cangjie programming language, detailing the management and usage of SM2 private keys. It covers the class definition, initialization, static decoding methods for DER and PEM formats (including password-protected keys), data decryption, and DER encoding. Key information includes support for signing and decryption operations, adherence to PKCS1 standards, and handling of ASN.1 encoded ciphertext. Essential functions include init, decodeDer, decodeFromPem, decrypt, and encodeToDer, all of which may throw CryptoException. This technical reference is intended for software developers implementing cryptographic security features who need to handle SM2 key generation, parsing, and decryption operations.

### func_encodeToDerString_5more.md
This document provides API reference documentation for cryptographic functions in the Cangjie language, specifically focusing on private key encoding and digital signing. Main sections cover functions for encoding keys to DER and PEM formats, supporting optional AES-256-CBC encryption, alongside a data signing function using SM2 with SM3 hashing and a utility method for string representation. Key information includes that password parameters allow for unencrypted output, while the signing process specifically utilizes the SM3 digest algorithm. All operations handle errors via CryptoException. This reference guide targets software developers implementing security features who require precise details on key serialization and digital signature generation.
