# location

This directory serves as a central repository for Location Kit documentation and development resources, specifically tailored for the HarmonyOS and OpenHarmony ecosystems. It covers essential topics ranging from introductory concepts and positioning technologies (GNSS, WLAN, Bluetooth) to detailed permission guidelines and development standards for the Cangjie programming language. The content is designed to assist developers in integrating location-based services, managing user permissions, and understanding hardware constraints. It is suitable for mobile application developers and system engineers looking to implement precise or approximate positioning features in their applications.

## Detailed Description

### README_zh/
This directory acts as the Chinese documentation navigation center for Location Kit (Location Services). It aims to provide comprehensive guidance for mobile app developers regarding this Beta feature. The documentation structure is clear, covering a basic introduction to Location Kit, the process of applying for location permissions, and specific development methods for obtaining device location information. Through this document, developers can systematically understand the core concepts of location services and master the complete development chain from permission configuration to functional implementation. This resource is particularly suitable for developers who need to integrate positioning, navigation, or location-based service functions in their applications, helping them quickly verify features and complete basic integration during the Beta phase to provide users with a more precise location experience.

### cj-location-guidelines/
This directory contains a comprehensive collection of development guidelines and technical documentation designed for developers working with the Cangjie programming language and the OpenHarmony operating system. The primary focus of this repository is to provide standards and best practices for utilizing location services within this specific development environment.

### cj-location-kit-intro/
This directory provides introductory documentation for Location Kit, aiming to help developers deeply understand the core functions and diverse positioning technologies of location services. The content is detailed, covering scenario overviews and basic concepts, including key technologies such as coordinate systems, Global Navigation Satellite Systems (GNSS), base station positioning, and WLAN/Bluetooth positioning. Additionally, the document highlights constraints and limitations during integration, explicitly stating that applications require users to enable switches and grant authorization, and that positioning capabilities are highly dependent on device hardware support. By reading this document, developers can master how to use these technologies to cover indoor and outdoor scenarios, thereby effectively improving application experience. This document is particularly suitable for developers needing to integrate location functions.
