This directory provides comprehensive API reference documentation for the `WindowProperties` class in the Cangjie programming language. It serves as a technical guide for configuring static window attributes within the WindowManager system capability. The content covers a wide array of properties, including geometric definitions (window and drawable rectangles), display modes (full-screen settings), and behavioral flags (focusability, touchability, privacy mode). It details the public constructor and specifies that all properties are readable and writable. This documentation is targeted at developers working on system-level window management or GUI applications who need to instantiate and configure window properties, specifically for system version 22 and above.
