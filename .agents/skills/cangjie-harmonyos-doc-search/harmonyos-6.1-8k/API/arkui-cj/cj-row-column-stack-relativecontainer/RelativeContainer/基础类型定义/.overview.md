# 基础类型定义

本目录包含ArkUI框架中用于布局约束的基础类型定义，主要涉及屏障和辅助线的配置。核心关键词包括BarrierStyle、GuideLineStyle、GuideLinePosition、布局约束、仓颉语言。这些文档详细介绍了如何定义ID、方向、位置及依赖关系，适用于使用仓颉语言进行ArkUI应用开发，需要实现复杂相对布局和组件间约束的开发者。

- 你想定义组件间的屏障约束吗？

- 你想配置辅助线的位置参数吗？

    - 设置辅助线的ID、方向和位置规则 → class_GuideLineStyle.md

## 详细描述

### class_BarrierStyle.md class_BarrierStyle.md
本文档提供了ArkUI中BarrierStyle类的API参考，用于定义屏障的ID、方向及依赖组件。涵盖了类的属性定义（id、direction、referencedId）及其构造函数，详细说明了屏障方向与锚点约束的关系。关键信息包括ID必须唯一且不可重名，垂直方向屏障仅作水平锚点，水平方向屏障仅作垂直锚点，起始版本为22。面向使用仓颉语言进行ArkUI布局开发的开发者，适用于需要实现组件间屏障约束的场景。

### class_GuideLinePosition_06870158.md class_GuideLinePosition_06870158.md
这份文档是Cangjie语言中GuideLinePosition类的API参考文档，用于定义ArkUI界面中guideline的位置参数。文档详细介绍了类的结构，包括start和end两个可读写属性及其构造函数。start属性表示guideline距离容器左侧或顶部的距离，end属性表示距离右侧或底部的距离，两者均为可选的Length类型，可通过命名参数初始化。该文档适用于使用ArkUI框架进行UI布局开发的开发者，需具备基本的Cangjie语言和ArkUI布局知识。

### class_GuideLineStyle.md class_GuideLineStyle.md
这是一份Cangjie语言的API参考文档，旨在定义GuideLineStyle类，用于配置辅助线的ID、方向和位置。文档涵盖了id、direction和position三个核心属性及其构造函数，详细说明了各属性的读写能力、类型及默认值。关键信息包括id的唯一性要求、方向对锚点行为的限制以及位置声明的优先级规则。该文档适用于ArkUI应用开发者，特别是需要在相对容器中使用辅助线进行布局定位的场景，提供了完整的参数配置指南。
