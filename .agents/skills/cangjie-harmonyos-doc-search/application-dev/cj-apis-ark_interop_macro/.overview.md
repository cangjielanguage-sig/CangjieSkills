# cj-apis-ark_interop_macro

This directory provides the essential API reference documentation for the `ohos.ark_interop_macro` module, a sophisticated tool designed to facilitate seamless cross-language development within the HarmonyOS ecosystem. The module is specifically engineered to simplify the complex interactions between Cangjie and ArkTS by automatically generating ArkTS declaration files and the necessary interop layer code. At the heart of this module is the `@Interop` macro, a powerful feature that allows developers to declaratively expose Cangjie classes to ArkTS environments. The documentation provides an in-depth look at the macro's syntax, parameters, and practical usage scenarios. Furthermore, it addresses critical constraints such as the current Beta status of the module, specific import limitations that developers must navigate, and the technical requirement for data types to implement the `JSInteropType` interface. This resource is indispensable for HarmonyOS developers, system architects, and engineers who are seeking to implement efficient, robust, and declarative interoperability between Cangjie and ArkTS, thereby streamlining their development workflow and ensuring type safety across language boundaries. By leveraging these tools, developers can significantly reduce boilerplate code and minimize errors associated with manual Foreign Function Interface (FFI) bindings.
