This directory contains a technical integration guide focused on enabling shared account passwords between mobile applications and web pages through the utilization of the Password Locker feature. The content provides a thorough explanation of the feature's functionality, outlines the specific scenarios where it is applicable, and details the precise access method required for implementation. Key information within the guide includes the critical prerequisite that both the app and web platforms must support auto-fill capabilities. Furthermore, it describes the necessary steps to bind the relationship between the two platforms via App Linking configuration in the AGC console. This allows users to access saved credentials across platforms seamlessly. This resource is suitable for developers looking to synchronize login credentials for a unified user experience.
