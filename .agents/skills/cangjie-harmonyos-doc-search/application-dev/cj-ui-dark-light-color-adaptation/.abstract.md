This directory provides a specialized technical guide designed for developers working within the Cangjie framework ecosystem who aim to implement sophisticated dark and light mode adaptation in their applications. The primary objective is to enhance user experience by ensuring that the application UI responds dynamically to environmental lighting or user system preferences. The content comprehensively covers the mechanisms required for color adaptation, detailing the use of custom resource directories alongside system presets. It also addresses the complexities of image resource adaptation, offering solutions such as using qualifiers or manipulating SVG fillColor properties to ensure icons remain visible and aesthetically pleasing in both modes. Furthermore, the guide includes instructions for Web component configuration to maintain consistency across hybrid interfaces. This resource is essential for application developers looking to build responsive UI themes that minimize maintenance overhead by avoiding duplicate files and leveraging system resources like `sys.color.ohos_id_color_text_primary` for automatic color switching.
