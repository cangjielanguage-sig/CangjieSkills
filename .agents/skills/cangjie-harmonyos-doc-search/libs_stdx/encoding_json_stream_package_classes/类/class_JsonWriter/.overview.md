# class_JsonWriter

This directory contains comprehensive documentation for the Cangjie `JsonWriter` class, a specialized utility designed to serialize objects and construct JSON structures directly into an OutputStream. It covers essential aspects of the class, including initialization procedures, configuration settings via `writeConfig`, and methods for manually building complex JSON entities like objects and arrays. Key topics include stream buffering, the insertion of raw JSON strings, and state management. This documentation is intended for developers using the Cangjie language who require efficient JSON stream generation and assumes familiarity with the `JsonSerializable` interface and standard output operations. It is particularly useful for scenarios requiring manual control over the JSON structure or high-performance serialization tasks.

## Detailed Description

### class_JsonWriter_9more.md
This document provides API reference documentation for the Cangjie JsonWriter class, designed to serialize objects into an OutputStream. It covers the class initialization, configuration options via writeConfig, and methods for manually constructing JSON structures like startObject, endObject, startArray, and endArray. Key information includes the requirement to call flush to write buffered data and the use of jsonValue for inserting raw, unescaped JSON strings. The documentation emphasizes the importance of proper stream management to ensure data integrity. Intended for developers working with JSON streams, this documentation assumes familiarity with the JsonSerializable interface and stream output operations.

Key takeaways include support for method chaining via return values, which allows for more readable and compact code, built-in serialization for basic types and collections like Array and HashMap, and error handling through IllegalStateException when the writer state is invalid. Intended for developers using Cangjie to generate JSON streams, this guide provides the necessary syntax and behavioral constraints for effective data serialization.
