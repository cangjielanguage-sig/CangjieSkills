This directory contains essential API reference documentation for the `SheetOptions` class, specifically designed for the Cangjie language and ArkUI framework. It focuses on the configuration of optional properties for half-modal pages and bottom-sheet interfaces. The content provides a deep dive into the class definition, its inheritance from `BindOptions`, and a comprehensive constructor initialization method. Key topics covered include visual styling, layout sizing, interaction behaviors, and lifecycle event callbacks. Developers will find detailed parameters for granular control over appearance, such as blur styles and dismissal actions, alongside system capability requirements. This documentation is intended for ArkUI developers and UI engineers who require knowledge of UI component construction to implement customizable, complex sheet interfaces.
