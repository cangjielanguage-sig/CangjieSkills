# 触屏事件

本目录包含关于ArkUI框架中触屏交互的文档，主要使用仓颉语言编写。内容涵盖了基础的点击事件处理以及更底层的触摸事件机制。核心知识点包括`onClick`回调函数、`ClickEvent`参数解析、`onTouch`回调方法以及`TouchType`事件类型（如按下、抬起、移动、取消）。这些文档适合使用仓颉语言开发ArkUI应用的开发者，旨在帮助他们实现UI交互逻辑、手势识别及触控反馈功能。

## 详细描述

### 触屏事件_2more_d73ff9ac.md
本文档介绍了ArkUI中的触屏事件，重点讲解由手指或手写笔触发的点击事件。文档涵盖了触屏事件的定义、原理图以及点击事件机制，详细说明了`onClick`回调函数及其`ClickEvent`参数（如坐标和事件源）。核心内容包括一个使用仓颉语言编写的代码示例，演示了如何通过按钮点击控制图片的显示与隐藏。该文档面向使用仓颉语言的ArkUI开发者，作为实现UI交互逻辑的参考指南，帮助开发者理解并应用触屏回调功能。

### 触摸事件.md
本文档旨在介绍ArkUI框架中如何使用Cangjie语言处理组件的触摸事件。主要涵盖onTouch回调函数的定义、TouchType事件类型（按下、抬起、移动、取消）的说明，以及如何通过event参数获取触控位置和组件信息。核心要点是`onTouch`方法的使用，它接收`TouchEvent`参数以识别动作类型并提取触控点坐标、组件全局位置及尺寸等详细信息。面向使用Cangjie开发ArkUI应用的开发者，适用于需要实现交互手势和触控反馈的场景。
