### 桩使用指南/
This directory serves as a comprehensive guide for using stubs and mock objects within the Cangjie unit testing framework. It covers essential topics such as sharing mocks safely, capturing arguments for verification, configuring default behaviors via Stub Modes, and creating custom parameter matchers. The documentation addresses advanced techniques like using `ValueListener`, `SyntheticFields`, and the `@On` macro to optimize test code. The guide provides in-depth instructions on how to leverage these tools to simulate various component behaviors, ensuring that units of code can be tested in isolation from their dependencies. By utilizing features such as argument capturing, developers can rigorously verify internal logic and interactions. Furthermore, the inclusion of advanced optimization techniques like the `@On` macro allows for the creation of cleaner, more concise test suites. Overall, this documentation is an essential resource for mastering the mock framework's capabilities to build robust and error-free applications.
