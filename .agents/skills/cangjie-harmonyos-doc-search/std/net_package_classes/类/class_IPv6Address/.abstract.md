This directory contains API reference documentation for the `IPv6Address` class within the Cangjie programming language's standard library. It covers the implementation of Internet Protocol version 6 addresses, including class definitions, initialization methods, utility functions for type inspection, scope management, serialization, and comparison operators. The documentation adheres to RFC standards 4291, 5952, and 4007. It is designed for software developers and network engineers who need to manipulate, validate, or convert IPv6 addresses in Cangjie applications.
