# class_Preferences

This directory contains API reference documentation for the Preferences class in the Cangjie language, part of the HarmonyOS ArkData framework. It covers the management of lightweight application data, including creating, reading, updating, and deleting key-value pairs. Key topics include instance caching, data persistence via `flush`, subscription to data changes, and static methods for managing preference lifecycles. Suitable for HarmonyOS developers, this documentation requires familiarity with application contexts (StageContext) and system capabilities to effectively implement local data storage and ensure data consistency.
