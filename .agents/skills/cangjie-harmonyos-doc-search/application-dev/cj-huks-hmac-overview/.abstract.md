This directory serves as a definitive guide for the HMAC (Hash-based Message Authentication Code) functionality integrated into the OpenHarmony HUKS (Hardware Universal KeyStore) framework. It is specifically structured to provide developers and system integrators with a deep understanding of how HMAC is utilized to ensure message integrity and data authenticity. The content covers a broad range of algorithm specifications, clearly delineating between mandatory and optional cryptographic standards to aid in decision-making. Key technical details include a comprehensive table of supported digest algorithms—such as SHA256, SHA384, SHA512, and SM3—alongside their corresponding key lengths and the API levels at which they are supported. The documentation emphasizes the importance of adhering to mandatory specifications to ensure seamless compatibility across the OpenHarmony platform. This resource is vital for anyone involved in the development or integration of secure cryptographic services, offering the necessary specifications to implement robust security measures effectively.
