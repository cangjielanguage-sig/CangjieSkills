These resources are designed for Cangjie developers seeking to structure test execution flows, validate code behavior, and optimize performance within their test suites.

## Detailed Description

### AfterAll_宏_6more.md AfterAll_宏_6more.md
This document serves as a reference guide for specific macros used in a unit testing framework, detailing their syntax and execution behavior within the test lifecycle. It covers six main macros: lifecycle hooks including @BeforeAll, @BeforeEach, @AfterAll, and @AfterEach, alongside assertion mechanisms like @Assert and @AssertThrows. Key information includes how lifecycle hooks manage setup and teardown tasks at the class or method level, and how @Assert supports value comparison, boolean checks, custom assertions, and approximate equality using a delta parameter. @AssertThrows is used to verify expected exceptions. This guide is intended for developers writing unit tests who need to structure test execution flows and validate code behavior.

### Bench_宏.md Bench_宏.md
This reference documentation explains the `@Bench` macro used for performance benchmarking by measuring function execution times and calculating statistical distributions. It covers the macro's core functionality, supported statistical parameters including median, error margins, and mean, as well as integration with parameterized DSL. Key information includes the batch execution mechanism for generating metrics and the tabular output format that details results for various argument combinations. This guide targets Cangjie developers seeking to implement performance testing and analyze execution efficiency within their test suites.

### Configure_宏.md Configure_宏.md
This document serves as a reference guide for the `@Configure` macro, which provides configuration parameters for test classes and functions in the Cangjie testing framework. It covers syntax rules, parameter inheritance where function-level settings override class-level ones, and details specific parameters for general testing (e.g., randomSeed) and benchmarking (e.g., batchSize, warmup). Key information includes the case-sensitive syntax, support for expressions as values, and specific configurations for `@Bench` functions like garbage control and execution duration. This guide is intended for developers using the Cangjie unit testing framework to customize test execution and performance benchmarks.

### CustomAssertion_宏.md CustomAssertion_宏.md
This reference documentation explains the `@CustomAssertion` macro, which enables developers to define custom assertion functions within the Cangjie unittest framework. Key sections cover function requirements, return value handling, nested assertion support, and generic type specification. Custom assertions must be top-level functions accepting `AssertionCtx` as the first parameter. The macro generates tree-structured output to improve readability, supports nesting other assertion macros, and propagates return values to the caller. Exception handling differs between `@Assert` and `@Expect` contexts. This guide targets Cangjie developers seeking to extend standard testing capabilities with specific, reusable validation logic.

### Expect_宏_6more.md Expect_宏_6more.md
This document serves as a technical reference for testing macros within the Cangjie unit testing framework. It covers assertion macros including @Expect for comparisons and approximate equality, @ExpectThrows for exception handling, and @Fail variants for expected failures. Additionally, it explains @Measure for configuring performance metrics in benchmark tests and @Parallel for enabling concurrent test execution. Key takeaways include the distinction between macros that stop execution versus those that continue, the requirement for stateless tests in parallel mode, and the incompatibility of parallel execution with benchmarks. This guide is intended for developers implementing unit tests and performance benchmarks.

### PowerAssert_宏_4more.md PowerAssert_宏_4more.md
This reference documentation outlines four advanced macros for the Cangjie unit testing framework: @PowerAssert, @Skip, @Strategy, and @Tag. The document explains how @PowerAssert provides detailed visualizations of sub-expression values upon failure, including support for delta comparisons. It details @Skip for conditionally bypassing tests, @Strategy for creating reusable data generation strategies, and @Tag for applying metadata to filter test execution via command-line options. Key takeaways include the syntax for approximate equality, tag inheritance rules from classes to methods, and the requirement for explicit return types in strategy functions. This guide is intended for developers seeking to enhance test diagnostics, data management, and execution control.

### TestCase_宏.md TestCase_宏.md
This reference documentation defines the `@TestCase` macro used to designate functions within a `@Test` class as unit test cases in the Cangjie language. It details syntax requirements, specifically that functions must return `Unit`, and extensively covers parameterized testing using a domain-specific language (DSL). Key sections explain supported parameter sources, including arrays, ranges, random generation, and external files like JSON or CSV. The document also describes advanced customization through the `DataStrategy` and `Arbitrary` interfaces and clarifies execution behavior regarding lifecycle hooks. This guide targets Cangjie developers implementing unit tests, particularly those requiring data-driven or parameterized testing scenarios.

### TestTemplate_宏_4more.md TestTemplate_宏_4more.md
This technical reference document details specific macros used within the Cangjie unit testing framework to enhance test functionality and configuration. It covers four main macros: `@TestTemplate` for creating test templates, `@Timeout` for setting execution time limits, `@Types` for supplying type parameters to generic tests, and `@UnittestOption` for registering custom configuration options. The text provides syntax rules, usage constraints (such as `@Types` requiring `@Test`), and code examples demonstrating integration with the `Configuration` class and handling type inheritance. Targeted at developers writing unit tests in Cangjie, this guide explains how to implement advanced features like generic testing, timeouts, and custom configuration management.

### Test_宏_2more.md Test_宏_2more.md
This document serves as API reference documentation for the @Test and @TestBuilder macros used within a unit testing framework. It details the @Test macro's functionality for converting top-level functions or classes into unit test cases, alongside the @TestBuilder macro for declaring dynamic test suites. Key takeaways include the requirement that @Test classes must have a no-argument constructor and cannot inherit from other classes. The implementation automatically introduces the unittest.TestCases base class, providing ctx and name fields that users should not modify. This guide is intended for developers writing unit tests who need to understand macro application rules and available test context properties.
