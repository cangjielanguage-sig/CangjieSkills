# class_AudioManager

This directory contains technical documentation for the Cangjie AudioManager class and associated AudioKit framework functions. It focuses on comprehensive audio management capabilities, including volume control, device routing, session handling, and stream management. The documentation covers system API version 19 requirements, necessary permissions like `ohos.permission.MODIFY_AUDIO_SETTINGS`, and error handling mechanisms. It is designed for Cangjie developers and multimedia engineers seeking to implement robust audio control features in their applications, providing the necessary API references and code examples to manage audio settings effectively.

## Detailed Description

### class_AudioManager_4more.md
This document provides API reference documentation for the Cangjie AudioManager class, designed to manage audio volume and devices. It details three primary methods: getAudioScene for retrieving scene modes, getRoutingManager for device routing, and getSessionManager for session management. Key information includes the requirement for the ohos.permission.MODIFY_AUDIO_SETTINGS permission, system capabilities starting from API version 19, and specific error handling via BusinessException. This technical reference targets Cangjie developers working on multimedia applications who need to control audio settings and handle potential runtime errors.

### func_getStreamManager_2more.md
This API reference document details Cangjie functions for retrieving audio management instances within the AudioKit framework. It covers the getStreamManager and getVolumeManager functions, outlining their syntax, system capabilities, return types, and exception handling. Key information includes the specific manager instances returned and the BusinessException error code 6800301 for creation failures. The document provides Cangjie code examples demonstrating implementation and error logging. Targeted at developers working with multimedia audio, this reference serves as a guide for accessing core audio stream and volume control functionalities in version 19 of the system.
