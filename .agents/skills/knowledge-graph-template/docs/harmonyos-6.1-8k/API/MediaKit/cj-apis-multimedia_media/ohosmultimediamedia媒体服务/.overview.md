# ohosmultimediamedia媒体服务

本目录提供了仓颉语言中 `ohos.multimedia.media` 媒体服务模块的API参考文档，主要涵盖音视频资源访问与视频缩略图生成功能。核心内容包括通过文件句柄访问特定音视频片段、配置缩略图输出参数、定义帧提取策略以及使用 `AVImageGenerator` 进行图像生成。该模块适用于需要在HarmonyOS应用中实现多媒体处理、视频预览及封面生成的开发者，帮助其高效利用系统媒体能力。

## 详细说明

### class_AVFileDescriptor.md class_AVFileDescriptor.md
本文档是Cangjie语言中AVFileDescriptor类的API参考文档，旨在描述通过文件句柄访问的音视频资源。文档涵盖了类定义、属性（fd、offset、length）及构造函数的详细说明，重点介绍了如何在同一文件中根据偏移量和长度播放特定音视频片段。关键信息包括fd为必填项，需通过getRawFd或open获取，而offset和length的非法输入会导致解析错误。该文档面向多媒体应用开发者，适用于处理连续存储资源的复杂播放场景。

### class_PixelMapParams_2b67c916.md class_PixelMapParams_2b67c916.md
这是一份Cangjie语言的API参考文档，详细介绍了PixelMapParams类的定义与用法。该类用于配置获取视频缩略图时的输出格式参数。文档主要涵盖了类的构造函数以及width和height两个可读写属性，明确了它们均为Int32类型。关键信息指出，宽高参数必须大于0且不大于原始视频尺寸，否则系统将不对缩略图进行缩放处理。该文档面向多媒体应用开发者，旨在帮助其正确使用AVImageGenerator系统能力来生成指定尺寸的视频缩略图。

### enum_AVImageQueryOptions.md enum_AVImageQueryOptions.md
本文档是Cangjie语言中AVImageQueryOptions枚举的API参考文档，用于定义获取视频缩略图时请求时间点与实际视频帧的对应关系。文档详细介绍了四种核心查询选项：选取最近帧、最近关键帧、之后关键帧及之前关键帧，并涵盖了相等性比较和字符串转换等操作。该枚举属于多媒体媒体系统能力，起始版本为22。主要面向使用AVImageGenerator进行多媒体开发的程序员，帮助其精确控制视频帧提取逻辑。

### ohosmultimediamed_5more_b7aea8c3.md ohosmultimediamed_5more_b7aea8c3.md
这份文档是ohos.multimedia.media模块的API参考指南，旨在帮助仓颉语言开发者接入系统媒体资源。文档主要介绍了当前处于Beta阶段的媒体子系统，重点讲解了如何使用AVImageGenerator获取视频缩略图。核心内容包括模块导入方式、所需权限（如麦克风权限）、以及createAVImageGenerator函数的详细定义，涵盖其返回值、系统能力、起始版本及异常处理（如内存不足错误码5400101）。此外，文档还提供了Context配置和示例代码说明，适用于需要在HarmonyOS应用中处理媒体缩略图的开发场景。

### class_AVImageGenerator/
本目录包含仓颉编程语言中 `AVImageGenerator` 类的API参考文档，主要涵盖从视频资源中提取缩略图和帧图像的功能。核心内容包括媒体文件描述符的设置、基于时间点的帧提取方法以及多媒体资源的释放机制。文档详细介绍了参数定义、错误码处理及并发使用规则，适用于具备多媒体开发基础的开发者，用于实现视频预览、封面生成及资源管理功能。
