This directory contains API reference documentation for the `AtomicInt64` class in the Cangjie programming language. It focuses on providing low-level atomic primitives for 64-bit integers, essential for concurrent programming and thread-safe logic. The documentation covers core operations such as construction, value swapping, arithmetic addition and subtraction, bitwise manipulations, and compare-and-swap mechanisms. It distinguishes between current implementations using default memory ordering and deprecated versions requiring explicit `MemoryOrder` parameters. This resource is suitable for systems programmers and developers implementing high-performance, thread-safe code who need precise control over atomic memory operations.
