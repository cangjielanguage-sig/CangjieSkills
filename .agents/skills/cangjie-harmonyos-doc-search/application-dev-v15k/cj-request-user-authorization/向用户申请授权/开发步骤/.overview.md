# 开发步骤

This directory provides a comprehensive guide for implementing runtime permission requests in HarmonyOS applications using the Cangjie language. It covers the complete workflow from declaring permissions in configuration files to handling user authorization results, with a specific focus on location access. The tutorials detail critical implementation steps such as checking authorization status, managing permission requests within the `onWindowStageCreate` lifecycle, and creating UI triggers. It is suitable for application developers looking to master privacy management and user authorization logic in the HarmonyOS ecosystem.

## Detailed Description

### 开发步骤_1.md 开发步骤_1.md
This tutorial guides developers through the process of requesting location permissions in a HarmonyOS application using the Cangjie language. It outlines a three-step workflow: declaring required permissions in the configuration, verifying current authorization status via the checkAccessToken method, and dynamically requesting user authorization using requestPermissionsFromUser. Key information includes handling the logic between precise and approximate location permissions and ensuring UI content loads before requesting permissions. The document targets application developers implementing runtime permission management.

### 开发步骤_2.md 开发步骤_2.md
This technical guide instructs developers on implementing user permission requests in HarmonyOS applications using the Cangjie language. It covers requesting permissions within the onWindowStageCreate lifecycle method of a UIAbility or UIExtensionAbility, and requesting permissions directly from the UI layer. A critical constraint is that requestPermissionsFromUser must be called after onWindowStageCreate execution to prevent failures. The guide details callback handling for authorization results and context retrieval for UI-based requests. This is intended for HarmonyOS application developers familiar with Cangjie syntax and the AbilityKit framework.

### 开发步骤_3.md 开发步骤_3.md
This document serves as a tutorial step for implementing runtime permission requests in HarmonyOS applications using the Cangjie language. It covers the creation of a user interface with a button to trigger permission requests, specifically for location access. Key sections include retrieving the UIAbilityContext, utilizing the AbilityAccessCtrl manager to request permissions, and handling the authorization results via a callback. The text explains that if users deny permissions, the app must prompt them and guide them to system settings to manually enable access. This guide targets developers building HarmonyOS apps who need to manage user privacy permissions dynamically.
