# 开发步骤

This directory provides comprehensive development tutorials and technical guides focused on image decoding using the ImageKit within the Cangjie programming language. It covers the end-to-end development process, starting from importing necessary modules and acquiring image data through various input methods like sandbox paths or resource managers, to instantiating ImageSource objects and decoding images into PixelMap formats. The content addresses both standard RGBA8888 decoding and HDR image processing, including configuration of DecodingOptions and memory management. These resources are specifically designed for application developers in the HarmonyOS or OpenHarmony ecosystem looking to implement robust image handling and manipulation features in their applications.

## Detailed Description

### 开发步骤_1.md
This document serves as a development tutorial guiding developers through the image decoding process using the ImageKit in the Cangjie programming language. The content is structured into four sequential steps: importing the Image module, acquiring image data through sandbox paths or resource managers, instantiating an ImageSource object, and decoding the image into a PixelMap by setting DecodingOptions. Key takeaways include the various methods for inputting image data, such as using file descriptors, byte buffers, or RawFileDescriptors. This guide is intended for application developers seeking to implement image handling functionality within their software projects.

### 开发步骤_2.md
This technical guide provides code examples for decoding images into PixelMap objects using the Cangjie language. It covers two primary decoding methods: standard decoding with editable RGBA8888 pixel formats and HDR image decoding using automatic dynamic range settings. Key takeaways include the process of creating image sources from resource managers, configuring specific decoding options, and verifying HDR content via image info. Additionally, the document instructs developers on manually releasing PixelMap and ImageSource objects to ensure proper memory management. This guide targets application developers working within the HarmonyOS or OpenHarmony ecosystem who require practical steps for image manipulation and resource handling.
