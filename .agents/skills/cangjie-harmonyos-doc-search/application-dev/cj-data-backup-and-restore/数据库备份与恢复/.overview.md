# 数据库备份与恢复

This directory provides technical guides for implementing database backup and recovery mechanisms within the ArkData framework, utilizing the Cangjie programming language. It covers essential strategies for ensuring data integrity, business continuity, and availability during system failures or critical operations. The content addresses both relational databases (RdbStore) and Key-Value (KV) databases, detailing manual and automatic backup modes, data restoration procedures, and exception handling. Key topics include transaction integrity, data loss prevention, file path configuration, and managing result sets. These resources are designed for developers working on distributed data management who need to integrate robust data protection and recovery capabilities into their applications.

## Detailed Description

### 关系型数据库备份.md 关系型数据库备份.md
This document serves as a technical guide for implementing relational database backups to ensure data recovery and business continuity. It covers two backup modes, manual and automatic, with a specific focus on the manual backup process. The key section provides a Cangjie code tutorial demonstrating how to use the backup API, including necessary imports, RdbStore initialization, and file path configuration. It explains that manual backups can use default or absolute paths. This guide is intended for developers seeking to integrate data protection capabilities into their applications using the ArkData framework.

### 关系型数据库数据恢复.md 关系型数据库数据恢复.md
This technical guide outlines the procedure for recovering relational database data using manual backups after a database rebuild. It details three critical steps: throwing and catching database exception error codes, closing all open result sets, and invoking the restore interface. The document provides Cangjie code snippets demonstrating how to handle specific error codes like 14800011, manage result sets, and use the restore method with file path verification. It targets developers familiar with Cangjie and relational database management who need to implement robust data recovery mechanisms.

### 数据库备份与恢复_3more.md 数据库备份与恢复_3more.md
This development guide explains how to implement database backup and recovery functionality to ensure data integrity and availability during critical operations or system failures. It covers scenario introductions regarding transaction integrity and data loss, followed by a detailed tutorial for Key-Value (KV) databases. Key information includes step-by-step Cangjie code examples for creating a KV store, inserting data, performing backups using the backup interface, simulating data loss, and restoring data using the restore interface. It also notes that KV databases support deleting backups to free space. This document is intended for developers working with distributed data management who need to safeguard against data corruption or accidental deletion.
