# cj-apis-ark_interop

The `cj-apis-ark_interop` directory is a specialized documentation collection dedicated to the `ohos.ark_interop` library, a pivotal Beta-stage module for the HarmonyOS development ecosystem. It addresses the growing need for interoperability between the Cangjie language and ArkTS environments, enabling developers to leverage the strengths of both languages within a single application. The directory covers a wide array of technical topics, including runtime management, which is crucial for maintaining stable execution contexts, and data type conversions, which ensure that information flows accurately between Cangjie and JavaScript runtimes. Additionally, it provides detailed guidance on function calls and asynchronous operations, allowing for responsive and efficient cross-language communication. By offering in-depth references for core classes like `JSContext`, `JSValue`, and `JSArray`, this documentation serves as a fundamental resource for Cangjie and HarmonyOS developers. It is specifically designed for those tasked with bridging native logic with ArkTS/JavaScript runtimes, providing the essential tools required for sophisticated data exchange, precise object manipulation, and robust lifecycle management in modern application development. Mastering these concepts allows for the creation of highly modular and performant applications.
