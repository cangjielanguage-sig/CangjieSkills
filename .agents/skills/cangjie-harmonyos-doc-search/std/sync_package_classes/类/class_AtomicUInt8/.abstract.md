This directory provides comprehensive API reference documentation for the `AtomicUInt8` class within the Cangjie programming language. It is designed to assist developers in implementing thread-safe operations on `UInt8` data types, covering essential synchronization primitives such as compare-and-swap, atomic arithmetic, bitwise manipulations, and value swapping. A significant focus is placed on the deprecation of functions requiring explicit memory order parameters, directing users toward simplified versions with default ordering. This documentation is specifically tailored for systems programmers and developers building concurrent applications who need precise, low-level control over shared state to prevent data races.
