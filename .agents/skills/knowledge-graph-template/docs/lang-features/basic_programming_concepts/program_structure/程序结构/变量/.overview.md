# 变量

本目录主要介绍仓颉编程语言中变量的核心概念与使用规则。内容涵盖变量的定义、语法结构、修饰符（如 `let`、`var`、`const`）以及类型推断和初始化策略。文档详细区分了不可变与可变变量的差异，明确了全局与局部变量的初始化要求，并通过代码示例展示了在控制流结构（如 `try-catch`）中不可变变量的行为及编译器的错误检查机制。这些资料适合仓颉语言开发者及初学者，旨在帮助其掌握变量声明、管理及错误处理中的关键语法。

## 详细说明

### 变量_1.md 变量_1.md
本文档旨在介绍仓颉编程语言中变量的定义、语法及核心使用规则。主要涵盖变量构成、修饰符（如`let`、`var`、`const`）、类型推断及初始化策略。重点区分了不可变与可变变量，明确了全局/静态变量必须初始化而局部变量可延迟初始化但需在使用前赋值，并展示了编译器对潜在错误的保守检查机制。这是一份面向仓颉语言开发者的基础语法教程，帮助其掌握变量声明与管理的核心概念。

### 变量_2.md 变量_2.md
本文档作为代码示例，展示了仓颉编程语言中变量的不可变性规则。内容涵盖了在 `try-catch` 等控制流结构中使用 `let` 关键字声明变量的情况。核心要点在于，使用 `let` 声明的变量是不可变的；若在 `catch` 块中尝试为该变量赋值，将导致编译错误，因为不可变值无法被重新赋值或修改。该材料适合正在学习仓颉语法的开发者，特别是希望理解可变与不可变变量声明区别及错误处理上下文的读者。关键词：仓颉, 变量, 不可变性, let, try-catch, 编译错误。
