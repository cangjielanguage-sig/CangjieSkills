# 组件属性

This directory provides comprehensive API reference documentation for defining and manipulating component properties within the ArkUI framework, specifically tailored for the Cangjie language. It primarily focuses on the Menu component, offering detailed guidance on visual customization and layout configuration. Key topics covered include text styling (such as font size, weight, family, and color), the implementation of visual dividers, border radius adjustments, and sub-menu expansion behaviors. These documents are essential resources for developers working on HarmonyOS applications who require precise control over UI element aesthetics and functionality using Cangjie syntax and resource management techniques.

## Detailed Description

### func_fontLength_FontWeight_4more.md
This API reference document details methods for styling text and dividers within a Menu component in the ArkUI framework using the Cangjie language. It covers two overloaded font functions for setting size, weight, family, and style, a fontColor function for text color, and a menuItemDivider function for visual separators. Key parameters include Length for size with a default of 16.vp, FontWeight, and support for both String and AppResource types for font families. The menuItemDivider allows customization of stroke width, color, and margins, available from API version 19. This guide is intended for developers using ArkUI to customize Menu appearance, requiring knowledge of Cangjie syntax and resource management.

### func_menuItemGroupDividerD_4more.md
This API reference document details specific styling functions for Menu components within the Cangjie ArkUI framework. It covers four main functions: menuItemGroupDivider for configuring top and bottom divider styles, two overloaded radius functions for setting border corner radii using either a Length or BorderRadiuses object, and subMenuExpandingMode for defining sub-menu expansion behavior. Key information includes parameter definitions such as stroke width, color, margins, and corner radius constraints, alongside system capabilities and starting version numbers. This documentation is intended for developers seeking to customize the visual appearance and layout of Menu interfaces in HarmonyOS applications.
