This directory serves as a definitive resource for developers working within the Cangjie programming ecosystem, specifically targeting those who need to implement robust inter-thread communication (ITC) using the Emitter mechanism. The content provides a deep dive into the architecture of event-driven programming, explaining how to effectively handle event subscription, publishing, and cancellation within a single process. It details the critical operational mechanism that utilizes an internal event queue to manage serial execution, ensuring data consistency and thread safety across different threads. The guide covers a wide range of essential topics, from initial scenario introductions to comprehensive interface descriptions for core APIs like `on`, `once`, `emit`, and `off`. Furthermore, it includes a practical, step-by-step tutorial complete with code examples to facilitate hands-on learning and immediate application of concepts. This documentation is vital for application developers using the BasicServicesKit who aim to build scalable, responsive applications. It emphasizes the importance of proper lifecycle management, teaching developers how to prevent memory leaks by correctly unsubscribing from events. By mastering these concepts, developers can create decoupled systems where components communicate efficiently without direct dependencies, thereby improving code maintainability and performance.
