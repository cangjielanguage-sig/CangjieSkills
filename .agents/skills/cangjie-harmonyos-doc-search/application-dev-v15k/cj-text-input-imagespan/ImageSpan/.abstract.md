The ImageSpan directory provides comprehensive documentation for the ImageSpan component within the ArkUI framework, specifically designed for the Cangjie language. It covers the integration of inline images into text flows, detailing initialization methods, component properties, event handling, and practical code examples for styling and alignment. Key topics include resource management, error handling, and visual customization like scaling and background styles. This resource is suitable for software developers and UI engineers building rich text interfaces on HarmonyOS who need to embed mixed media content directly into text components.
