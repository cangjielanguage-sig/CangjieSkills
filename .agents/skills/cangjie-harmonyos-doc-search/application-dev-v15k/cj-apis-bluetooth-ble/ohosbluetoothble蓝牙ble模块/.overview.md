# ohosbluetoothble蓝牙ble模块

This directory provides comprehensive API reference documentation for the HarmonyOS Bluetooth Low Energy (BLE) module, specifically designed for the Cangjie programming language. It covers essential BLE functionalities including advertising, scanning, and GATT (Generic Attribute Profile) operations for both client and server roles. The documentation details data structures, enumerations, and functions required to manage device connections, data transmission, and state changes. It is intended for software developers and engineers building BLE-enabled applications using the ConnectivityKit, requiring knowledge of Cangjie syntax and Bluetooth protocols.
