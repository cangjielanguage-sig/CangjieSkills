This directory contains documentation for the `AtomicInt8` class within the Cangjie sync package, focusing on thread-safe operations for 8-bit integers. It covers essential atomic primitives such as compare-and-swap, arithmetic operations (add, subtract), bitwise manipulations (and, or, xor), and load/store mechanisms. The content details both current implementations using default memory ordering and deprecated versions requiring explicit memory order parameters. This resource is designed for Cangjie developers and systems programmers implementing low-level concurrency algorithms or multithreaded applications requiring precise synchronization and data consistency.
