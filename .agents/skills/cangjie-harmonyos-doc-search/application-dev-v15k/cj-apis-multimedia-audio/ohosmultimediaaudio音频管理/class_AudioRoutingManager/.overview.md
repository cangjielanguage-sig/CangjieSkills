# class_AudioRoutingManager

This directory contains API reference documentation for the `AudioRoutingManager` class in the Cangjie language, designed for managing audio routing within the HarmonyOS multimedia framework. It covers functionalities such as retrieving available audio devices, setting communication devices, and monitoring device connection or priority changes through callbacks. Key topics include device selection, event listening, and error handling. This documentation is intended for developers working on audio applications who need to implement dynamic audio routing and device management using the AudioKit framework.
