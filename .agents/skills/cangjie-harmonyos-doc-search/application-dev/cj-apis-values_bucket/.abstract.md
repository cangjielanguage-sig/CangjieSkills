This directory provides a comprehensive API reference for the `ValuesBucket` data structure, which is essential for handling data persistence in the Cangjie language. It is specifically designed for HarmonyOS developers who need to transmit key-value data to databases efficiently. The documentation thoroughly details the `VBValueType` enum, enumerating the permissible database field types such as Integer, Double, String, and Boolean to ensure type safety. Beyond type definitions, it includes critical information regarding the module's Beta status, the necessary import of `kit.ArkData`, and advanced system capabilities for distributed data management introduced in version 22. By utilizing this resource, developers can effectively implement data storage solutions and manage type definitions within their HarmonyOS applications, ensuring robust and scalable data handling. This documentation acts as a definitive guide for understanding the constraints and capabilities of the data management system.
