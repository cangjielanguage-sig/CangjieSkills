# 手势触发控制

This directory focuses on the gesture trigger control mechanism within the ArkUI framework, providing essential resources for developers looking to master complex user interactions. It covers the fundamental principles of gesture interception, explaining how applications can dynamically permit or block gestures based on system-defined thresholds. Key topics include the usage of `onGestureJudgeBegin` and `onGestureRecognizerJudgeBegin` APIs to resolve conflicts between overlapping components, such as distinguishing between a long press and a drag action. The materials include practical code examples in both Cangjie and ArkTS, demonstrating how to analyze touch coordinates to make real-time decisions. This content is highly suitable for HarmonyOS developers and UI engineers who need to implement sophisticated gesture handling in applications with layered or complex layouts, ensuring a smooth and intuitive user experience.

## Detailed Description

### 手势触发控制_1.md 手势触发控制_1.md
This document outlines the gesture trigger control mechanism in ArkUI, enabling applications to intercept or permit gestures after system thresholds are satisfied. It details the core concept of gesture interception and introduces two primary APIs: onGestureJudgeBegin for basic interception and onGestureRecognizerJudgeBegin for enhanced control over gesture recognizers. A practical Cangjie code example demonstrates how to resolve gesture conflicts between overlapping components (Image and Stack) by analyzing touch coordinates to decide between a long press or a drag action. This technical guide is intended for developers implementing complex gesture interactions in ArkUI applications.

### 手势触发控制_2.md 手势触发控制_2.md
This code example demonstrates advanced gesture conflict resolution in ArkUI by implementing conditional gesture interception within a stacked layout. The content defines a UI with a Scroll container, a descriptive Text, and a complex Stack component containing a draggable Image and a transparent overlay. The core logic utilizes the `onGestureJudgeBegin` callback to distinguish between LongPress and Drag gestures based on touch coordinates. It returns `GestureJudgeResult.CONTINUE` for the upper half to trigger LongPress, and `REJECT` otherwise to allow the underlying Image drag. This tutorial targets HarmonyOS developers familiar with ArkTS who need to manage overlapping gesture events in complex user interfaces.
