# 布局约束

This directory serves as a comprehensive resource for understanding and implementing layout constraints within the ArkUI framework, specifically tailored for Cangjie developers building HarmonyOS applications. It covers essential APIs and practical coding examples aimed at controlling component dimensions and managing visibility hierarchies. Key topics include the `aspectRatio` function for defining width-to-height relationships and the `displayPriority` function for handling component visibility in Row, Column, or Flex containers during space shortages. The documentation explains calculation logic for constrained dimensions and invalidation rules for non-positive values. This guide is suitable for UI developers and software engineers who require precise control over layout logic and dynamic rendering to create responsive, adaptive user interfaces that function correctly across different device configurations.

## Detailed Description

### 布局约束_4more.md 布局约束_4more.md
This document serves as an API reference for layout constraints within the ArkUI framework, specifically targeting Cangjie developers. It details methods to control component dimensions and visibility. The main sections cover the aspectRatio function, available in both Float64 and Int64 variants, which defines the width-to-height ratio and explains calculation logic when width or height is constrained. Additionally, it documents the displayPriority function, which manages component visibility hierarchy in Row, Column, or Flex containers during space shortages. Key takeaways include the invalidation of aspectRatio for non-positive values and the specific behavior of displayPriority where lower priority components are hidden if space is insufficient. This guide is intended for UI developers needing precise control over component layout and rendering behavior.
