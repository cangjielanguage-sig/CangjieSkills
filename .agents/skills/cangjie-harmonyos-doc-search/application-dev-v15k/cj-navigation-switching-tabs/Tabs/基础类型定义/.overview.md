# 基础类型定义

This directory contains API reference documentation for fundamental type definitions used in the ArkUI framework with the Cangjie language. It covers essential classes and enumerations for configuring Tab components, including layout options, divider styles, animation controllers, and transition proxies. Key topics include responsive grid settings, visual styling, and programmatic control over tab behaviors. These definitions are crucial for building dynamic and responsive user interfaces. This documentation is suitable for UI developers and system architects working with ArkUI to implement complex tab navigation and animation logic.

## Detailed Description

### class_BarGridColumnOptions.md class_BarGridColumnOptions.md
This API reference document defines the BarGridColumnOptions class used to configure grid layout settings for a TabBar component in the ArkUI framework. It details the class properties including margin, gutter, and responsive column counts (sm, md, lg), along with the class constructor. Key information includes that margins and gutters do not support percentages, and column counts must be non-negative even integers. Specific breakpoints are defined for small (320-600vp), medium (600-800vp), and large (840-1024vp) screens, where a value of -1 defaults to full width. This document is intended for UI developers using the Cangjie language to build responsive interfaces.

### class_DividerStyle.md class_DividerStyle.md
This API reference document outlines the DividerStyle class in Cangjie, designed to define the visual properties of divider lines in ArkUI applications. The documentation covers the class structure, specifically detailing read-only properties for stroke width, color, and start or end margins. It provides a comprehensive breakdown of the constructor parameters, including default values and constraints such as the exclusion of percentage support for length-based attributes. Intended for UI developers, this reference enables precise customization of divider aesthetics using Length and ResourceColor types.

### class_TabContentTransitionProxy.md class_TabContentTransitionProxy.md
This document serves as API reference for the TabContentTransitionProxy class, which facilitates custom transition animations within the Tabs component of the ArkUI framework. It details the class definition, read-only properties from and to representing page indices, and the finishTransition method. Developers use this proxy to retrieve the start and end index of a tab switch and must explicitly call finishTransition to signal the animation's completion to the system. This is intended for Cangjie developers implementing custom UI behaviors in ArkUI applications. Keywords: ArkUI, Cangjie, Tabs, custom animation, proxy, API reference.

### class_TabsAnimationEvent_2more.md class_TabsAnimationEvent_2more.md
This document serves as API reference documentation for the Cangjie programming language, detailing the TabsAnimationEvent class and AnimationMode enum used in the ArkUI framework. The main sections cover the class definition with properties like currentOffset, targetOffset, and velocity, alongside its constructor, and the enumeration defining animation switching behaviors. Key information includes that all event properties are read-only Float32 values measuring offsets and velocity, while the enum controls whether content loads before or after the animation, or if animation is disabled entirely. This technical guide is intended for developers utilizing the ArkUI framework to implement and customize Tabs component animations and transitions. Keywords: Cangjie, ArkUI, Tabs, AnimationMode, API reference, UI development, event handling.

### class_TabsController.md class_TabsController.md
This document serves as an API reference for the Cangjie TabsController class, designed to manage tab switching within the Tabs component. It details the class initialization and key methods including changeIndex for navigation, preloadItems for performance optimization, and setTabBarOpacity or setTabBarTranslate for visual adjustments. Crucially, a single controller cannot manage multiple Tabs components. The changeIndex method defaults to index 0 for invalid inputs, while preloadItems suggests batch loading to maintain performance. Targeted at ArkUI developers using the Cangjie language, this guide provides the necessary interfaces for programmatic control over tab navigation and appearance.

The document also distinguishes between Fixed and Scrollable layout modes. Intended for developers using the Cangjie language, this reference provides system capabilities and versioning details necessary for implementing precise UI tab controls.
