This directory serves as a comprehensive resource for API reference documentation regarding the `FormExtensionAbility` module within the HarmonyOS Cangjie framework. It is specifically designed to assist developers in mastering the intricate lifecycle management of form widgets, commonly known as cards. The content covers essential operations such as widget creation, destruction, refresh cycles, and configuration updates. Additionally, it details the `FormExtensionContext` class and outlines specific restrictions related to multimedia modules. This documentation is highly suitable for application developers using the Cangjie language who aim to build stable, high-performance form-based applications and need to strictly adhere to system capabilities and dependencies. It provides the necessary guidance to ensure widgets function correctly within the broader HarmonyOS environment, ultimately facilitating the development of responsive and reliable user interface components.
