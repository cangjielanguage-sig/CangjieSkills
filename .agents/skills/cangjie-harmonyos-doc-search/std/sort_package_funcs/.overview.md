# sort_package_funcs

This directory serves as a comprehensive technical resource dedicated to sorting functionalities within the Cangjie standard library. It acts as a central hub for API documentation regarding sorting algorithms, specifically focusing on the implementation and usage of `sort` and `unstableSort` functions. The scope of this directory encompasses a wide array of collection types, including `Array`, `ArrayList`, and `List`, providing developers with the necessary tools to handle data ordering efficiently. Key topics covered include the utilization of the `Comparable` interface for natural ordering, the creation of custom comparison functions for specialized logic, and key mapping techniques for sorting based on derived properties. Furthermore, it provides essential guidance on parameters related to stable sorting and descending order, while also documenting deprecated functions to aid in legacy code maintenance. This resource is ideally suited for Cangjie developers, software engineers, and system architects who are looking to implement robust sorting mechanisms, optimize collection manipulation, or ensure their applications adhere to standard library best practices.
