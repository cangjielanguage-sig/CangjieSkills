# 组件创建规则

This directory serves as a comprehensive technical guide for developers working with the LazyForEach API in the ArkUI framework and Cangjie programming language. It details the fundamental rules governing component creation, emphasizing the critical role of the `itemGenerator` function and key-value generation strategies. The content spans from the basics of initial rendering and unique key management to complex non-initial rendering scenarios involving data manipulation. By addressing performance optimization through `@Observed` and `@ObjectLink`, this collection helps developers build efficient, responsive user interfaces while avoiding common rendering bugs and state management issues.

## Detailed Description

### 组件创建规则.md 组件创建规则.md

This document outlines the component creation rules for the LazyForEach API, specifically explaining how the itemGenerator function processes data source items. The content is divided into two main sections covering the scenarios of LazyForEach first render and non-first render. Key takeaways include the dependency on key-value generation rules and the specific logic applied to create components for each array item. This technical reference guide is intended for developers working with list rendering and UI optimization, providing essential knowledge on component lifecycle and rendering behavior.

### 首次渲染.md 首次渲染.md

This technical guide explains the behavior of LazyForEach during initial rendering, focusing on key generation mechanisms. It covers two main scenarios: generating unique keys for data items and the rendering errors caused by duplicate keys. The key takeaway is that unique keys ensure correct component creation and state management, whereas identical keys lead to unpredictable behavior and cache conflicts during scrolling. The document provides Cangjie code examples demonstrating both successful and failed implementations. It targets developers using ArkUI or Cangjie frameworks who need to optimize list performance and avoid rendering bugs.

### 非首次渲染/

This directory focuses on advanced rendering techniques for dynamic lists in the ArkUI framework using the Cangjie programming language. It specifically addresses "non-initial rendering" scenarios, covering how to efficiently update, swap, add, delete, and modify data within a LazyForEach component without causing unnecessary full reloads. Key topics include data source management, notification mechanisms like `notifyDataChange`, and performance optimization using `@Observed` and `@ObjectLink`. This resource is suitable for developers building complex, responsive user interfaces who need to master granular UI updates and data synchronization in Cangjie applications.
