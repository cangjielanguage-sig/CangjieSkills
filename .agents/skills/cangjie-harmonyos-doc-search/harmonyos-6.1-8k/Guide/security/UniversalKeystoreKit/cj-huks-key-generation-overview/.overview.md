# cj-huks-key-generation-overview

本目录专注于OpenHarmony HUKS服务的密钥生成机制与算法规格概览。它详细阐述了密钥生成的核心原则，包括随机性保障、安全存储策略及用途限制。文档涵盖了三种密钥存储安全等级（DE、CE、ECE）的区分，并针对标准设备和轻量级设备列出了详细的算法支持列表，如AES、RSA、ECC及SM2等。此外，还涉及密钥长度、API级别要求及别名安全规范。该资料主要面向需要在OpenHarmony系统中实现安全密钥管理的开发者，旨在提供权威的技术参考与实施指导。

## Detailed Description

### cj-huks-key-generation-overview.md cj-huks-key-generation-overview.md

本文档旨在介绍OpenHarmony HUKS服务的密钥生成机制及支持的算法规格。主要涵盖密钥生成的核心概念（如随机性、安全存储、用途限制）、三种密钥存储安全等级（DE、CE、ECE）以及标准设备和轻量级设备支持的算法列表。文档详细列举了AES、RSA、ECC、SM2等算法的密钥长度与API级别要求，并强调密钥用途的唯一性及禁止在别名中包含敏感信息。这是一份面向开发者的技术参考指南，旨在指导其正确使用HUKS接口生成和管理安全密钥。
