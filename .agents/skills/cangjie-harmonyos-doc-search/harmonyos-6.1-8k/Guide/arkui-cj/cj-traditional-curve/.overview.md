# cj-traditional-curve

本目录提供了关于ArkUI框架中传统曲线的详细开发指南，主要面向使用Cangjie语言进行应用开发的工程师。文档深入探讨了基于数学公式的传统曲线（如三阶贝塞尔曲线）的原理，分析了其与物理曲线的本质区别及各自的适用场景。内容涵盖了传统曲线的局限性（即缺乏物理含义）、相关API接口的参考说明，以及FastOutSlowIn、Ease等多种曲线效果的Cangjie代码示例。通过本文档，开发者可以掌握插值计算的基础知识，并学会在动画开发中正确选择和使用传统曲线。
