This directory contains API reference documentation for the `componentSnapshot` class within the Cangjie programming environment and ArkUI framework. It covers the functionality required to capture screenshots of UI components, including both asynchronous and synchronous methods, as well as off-screen rendering capabilities. Key topics include the class declaration, system capability requirements, and specific static functions like `get`, `getSync`, and `createFromBuilder`. This documentation is suitable for HarmonyOS and ArkUI developers using Cangjie who need to implement visual capture features, handle component snapshots, or render custom components programmatically in their applications.
