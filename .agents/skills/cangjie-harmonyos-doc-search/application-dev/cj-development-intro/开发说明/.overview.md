# 开发说明

This directory provides essential development guidelines for the OpenHarmony Cangjie SDK. It covers compiling and running sample code using standard project templates, understanding API documentation conventions including version support and SystemCapability (SysCap), and managing system permissions and application models. Key topics include Context object management, API compatibility checks via `canIUse`, and the distinction between Stage and FA models. This documentation is suitable for Cangjie developers and application engineers working with the OpenHarmony ecosystem who need to ensure correct API usage, handle access control, and test code snippets effectively.

## Detailed Description

### 仓颉示例代码说明.md 仓颉示例代码说明.md
This guide instructs developers on how to compile and run Cangjie API code snippets by integrating them into a standard project template. It covers creating a Cangjie template project, modifying the index.cj file with sample code, and configuring the main_ability.cj file to handle Context objects via a Global class. The document clarifies that kit samples are incomplete and require specific imports and class definitions to function. It provides detailed code examples for setting up the UI component and managing global state for Context and WindowStage. This tutorial targets Cangjie developers who need to test API examples, requiring basic knowledge of the Cangjie project structure and ArkUI framework.

### 开发说明_4more.md 开发说明_4more.md
This document serves as a guide for developers to understand the structure and conventions of the OpenHarmony Cangjie SDK API documentation. It explains how to interpret version support numbers and defines SystemCapability (SysCap), which indicates feature availability across different devices. Key sections include instructions on using the `canIUse` method to check API compatibility and details on importing interface modules via Kits. The document emphasizes that developers must verify device-specific capabilities before using interfaces. Intended for application developers working with the OpenHarmony Cangjie SDK, this reference helps ensure correct API usage and compatibility during the Beta phase.

### 权限说明_3more.md 权限说明_3more.md
This document serves as a reference guide for developers regarding system permissions, application models, and deprecated interfaces within the Cangjie API ecosystem. It details the necessity of requesting permissions for resource access and how they are documented in interface descriptions. The text clarifies that Cangjie APIs are exclusively supported in the Stage model, distinguishing it from the FA model. Additionally, it explains the deprecation policy, noting that deprecated interfaces remain compatible for five API levels. This guide is intended for developers seeking to understand access control, model constraints, and API lifecycle management.
