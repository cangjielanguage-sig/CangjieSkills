This directory serves as a technical resource for developers implementing AES-GCM (Galois/Counter Mode) encryption with NoPadding using the HarmonyOS Universal Keystore Kit (HUKS). It provides detailed code examples in Cangjie, demonstrating how to utilize hardware-backed key storage to secure sensitive data. The documentation covers the complete cryptographic workflow, starting from key generation and configuration of AES-128 properties, through to data encryption and decryption. It also emphasizes the correct handling of essential security parameters like Nonce, Additional Authenticated Data (AAD), and AE tags. Furthermore, it addresses key lifecycle management, specifically the secure deletion of keys. This guide is suitable for software engineers and security-focused developers working within the HarmonyOS ecosystem who need to ensure data confidentiality, integrity, and authenticity in their applications.
