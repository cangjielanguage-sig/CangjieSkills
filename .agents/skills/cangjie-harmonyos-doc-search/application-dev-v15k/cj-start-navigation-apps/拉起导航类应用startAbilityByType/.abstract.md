This directory provides comprehensive technical documentation for HarmonyOS developers focusing on the integration and configuration of navigation capabilities using the `startAbilityByType` API. It covers the complete workflow, ranging from the client-side invocation of map features—such as route planning, active navigation, and location search—to the server-side configuration required to act as a target service provider. Key technical topics include detailed parameter construction using GCJ-02 coordinates, POI IDs, vehicle types, and the specific `module.json5` configurations needed to expose these features. The content is specifically tailored for developers proficient in the Cangjie language who need to implement or support complex map service interactions within the UIAbility lifecycle.
