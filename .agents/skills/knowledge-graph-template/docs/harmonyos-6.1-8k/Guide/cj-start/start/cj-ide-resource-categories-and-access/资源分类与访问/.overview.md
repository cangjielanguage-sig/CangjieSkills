# 资源分类与访问

本目录主要介绍HarmonyOS应用开发中的资源管理机制，涵盖资源的创建、分类、匹配规则及访问方式。核心关键词包括资源目录、限定词、系统资源、资源匹配和资源引用。适合HarmonyOS及仓颉开发者阅读，旨在帮助规范资源组织，实现多语言与多设备适配，并正确引用资源。

## 详细描述

### 创建资源目录和资源文件_2more_216c4a2e.md
本文档指导用户如何在DevEco Studio中创建资源目录和资源文件，并详细说明了资源的可翻译特性配置。主要内容包括创建资源目录与文件的三种方式（同时创建、仅创建目录、仅创建文件），以及资源可翻译特性的功能介绍、使用约束和JSON配置示例。关键信息包括限定词目录的命名规范、资源组类型支持，以及通过attr属性（包含translatable和priority字段）标记base目录下字符串资源翻译状态的方法。这是一份面向HarmonyOS开发者的操作指南，适用于需要在DevEco Studio中管理应用资源及进行国际化处理的场景。

### 资源分类与访问_93cd0d80.md
本文档旨在介绍应用开发中资源的分类方式及其在不同设备或配置下的访问与表现机制。文档主要涵盖了应用资源和系统资源两大核心主题，详细阐述了开发者如何通过资源文件自定义管理应用资源，以及如何直接使用系统预置的分层参数资源。关键信息在于区分了应用资源的自定义特性与系统资源随设备类型、深浅色等配置自动变化的特性。该文档目前处于Beta阶段，主要面向需要进行UI适配和资源管理的应用开发者，帮助其理解资源引用的基础概念。

### 资源匹配_2more_2b947473.md
这份文档主要阐述了应用资源匹配的规则及开发限制。文档详细说明了系统如何根据设备状态优先从限定词目录中查找资源，明确了匹配优先级（如移动国家码、区域、横竖屏等）以及精确匹配的要求。此外，文档列出了重要限制，包括资源名称不能使用仓颉语言保留关键字，以及color.json不支持透明色需通过代码设置。这是一份面向应用开发者的技术参考文档，旨在帮助开发者正确管理和调用应用资源。

### 资源访问.md
本文档旨在指导开发者如何在项目中访问和引用应用资源及系统资源。主要内容包括应用资源（如字符串、媒体、rawfile文件）的引用方式，以及系统资源（如颜色、字体、间距）的使用规范。关键点在于通过`@r(app.type.name)`访问应用资源，利用`@rawfile`引用原始文件，并使用`@r(sys.type.resource_id)`调用系统资源以统一视觉风格。文档还涵盖了字符串占位符处理和rawfile描述符接口的细节。这是一份面向仓颉开发者的技术参考文档，适用于需要管理UI资源和样式的应用开发场景。

### 资源分类/
本目录旨在指导应用开发中资源文件的分类存储与目录结构管理。内容涵盖了资源目录（如base、限定词、rawfile）与资源组目录（element、media、profile）的定义及层级关系，详细介绍了Stage模型下的资源组织、限定词命名规范及资源编译机制。核心关键词包括资源分类、目录结构、限定词、资源组及多场景适配。本文档适合应用开发人员阅读，帮助其规范资源文件组织，实现高效的多语言与多设备资源适配。
