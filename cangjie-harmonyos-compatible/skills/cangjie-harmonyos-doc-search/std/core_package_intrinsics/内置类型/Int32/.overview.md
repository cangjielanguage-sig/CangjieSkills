# Int32

This directory serves as a comprehensive API reference for the Int32 type within the Cangjie programming language, specifically focusing on its 32-bit signed integer capabilities. It thoroughly documents the type's range, core properties, and a wide array of interface implementations that extend its functionality. Key areas covered include mathematical constants like Max and Min, the Comparable interface for value ordering, the Countable interface for positional operations, and the Hashable interface for generating hash codes. Additionally, the documentation explores extensions for type conversion, particularly the implementation of the ToString interface. This technical resource is essential for Cangjie developers seeking to master integer behaviors, perform complex comparisons, and utilize utility methods effectively within the core package.
