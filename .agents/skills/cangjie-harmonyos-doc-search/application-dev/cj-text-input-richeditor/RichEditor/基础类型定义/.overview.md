# 基础类型定义

This directory provides API reference documentation for fundamental data structures and classes within the ArkUI framework's RichEditor component, specifically for the Cangjie language. It covers essential definitions for text styling, image spans, layout configurations, selection management, and event handling. Key topics include text decoration, paragraph formatting, cursor control, and rich text manipulation operations. These resources are designed for HarmonyOS developers who need to programmatically manage complex text editing interfaces, providing the necessary type definitions to implement custom behaviors and styles in version 22+ system environments.
