### 通用属性通用事件_1.md 通用属性通用事件_1.md

### 通用属性通用事件_2.md 通用属性通用事件_2.md
This document serves as a reference list for supported universal events within a UI framework, specifically detailing available event handlers for component interaction. The content covers a wide range of event types including lifecycle events like onAppear and onDisAppear, focus management with onBlur and onFocus, and complex drag-and-drop operations such as onDragStart and onDrop. Additionally, it lists input handling events for mouse, keyboard, and touch interactions, along with visibility tracking via onVisibleAreaChange. Each event is linked to its specific definition page for detailed implementation. This reference guide is intended for developers seeking to integrate interactive behaviors and event handling logic into their application components.
