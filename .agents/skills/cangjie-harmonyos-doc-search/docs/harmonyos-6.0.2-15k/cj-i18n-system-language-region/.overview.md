# cj-i18n-system-language-region

This directory provides a specialized technical guide for the Cangjie programming language, focusing on the internationalization (i18n) system, specifically the retrieval and management of system language and region settings. It serves as a practical manual for utilizing the LocalizationKit to access critical system locale data. The documentation delves into the nuances of language switching behavior, explaining how applications should react when system settings change. It also covers the handling of extended parameters, such as local digits, detailing the logic for attribute removal if a new language does not support them. The guide includes step-by-step development instructions, demonstrating how to import necessary modules and effectively use key APIs like `System.getSystemLanguage`, `System.getSystemRegion`, and `System.getSystemLocale`. This resource is essential for Cangjie developers, software engineers, and technical architects who are building applications requiring dynamic adaptation to user locale settings and robust internationalization support to reach a global audience. By following this guide, developers can ensure their applications respect user preferences and handle locale transitions smoothly.
