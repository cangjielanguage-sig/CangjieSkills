This directory contains API reference documentation for the `GeolocationPermissions` class in the Cangjie language, specifically designed for the HarmonyOS ArkWeb framework. It covers the management of geolocation permissions within WebView components, including granting access, deleting specific or all permissions, and querying stored permission states. Key topics include handling origins, managing incognito modes, and adhering to system permissions like `ohos.permission.LOCATION`. This documentation is suitable for HarmonyOS developers who need to programmatically control location access and privacy settings in their web applications.
