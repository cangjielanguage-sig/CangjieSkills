This directory outlines the development steps for integrating device sensors into hybrid applications using the Cangjie language and HarmonyOS. It covers the full workflow from backend permission handling in native code to frontend data retrieval using standard Web APIs. Key topics include UIAbility context management, system permission requests for accelerometers and gyroscopes, and JavaScript implementation of the Generic Sensor API and legacy events. This guide is suitable for HarmonyOS developers and web engineers working on mobile-first or PWA projects that require hardware sensor access.
