### 本地RAW文件播放场景下设置URL.md 本地RAW文件播放场景下设置URL.md
This technical guide explains how to configure media source URLs for playing local RAW files using the AVPlayer component in the Cangjie programming language. The document covers two distinct scenarios: playing files located in the application sandbox and playing resources bundled within the HAP package. Key information includes that for sandbox files, developers must open the file path to obtain a file descriptor (fd) and assign it to the url property using the "fd://" prefix. For bundled resources, the resourceManager.getRawFd method retrieves the descriptor, which is then wrapped in an AVFileDescriptor and assigned to the fdSrc property. This guide is intended for application developers working on HarmonyOS or OpenHarmony systems who need to implement local media playback functionality.
