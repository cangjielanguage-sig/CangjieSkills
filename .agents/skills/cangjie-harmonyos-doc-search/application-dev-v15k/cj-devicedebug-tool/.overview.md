# cj-devicedebug-tool

This directory contains the documentation for the `cj-devicedebug-tool`, a specialized command-line utility designed for developers and system engineers working within the HarmonyOS or OpenHarmony environment. It functions as a comprehensive reference guide for the devicedebug tool, which is used to interface with the Activity Manager Service (AMS) to manage application lifecycles effectively. The documentation specifically focuses on enabling users to send system signals and forcibly terminate debug application processes. It covers two primary functional areas: the help command, which provides usage instructions, and the kill command, which handles process termination. Key technical details include the mandatory prerequisite of using the hdc shell, the specific syntax requiring a signal number (ranging from 1-64) and a valid Process ID (PID), and defined return values for error handling. This resource is suitable for developers who require granular control over debugging sessions and need to manually terminate specific debuggable applications. Keywords: devicedebug, kill, signal, PID, debug, hdc, AMS, process termination.
