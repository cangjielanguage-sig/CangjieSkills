# enum_AssetParam

This directory contains API reference documentation for the `SystemCapability.Security.Asset` module within the Cangjie programming language framework. It focuses on defining parameters, attributes, and synchronization mechanisms for critical asset management. Key topics include data labeling (synchronized vs. local), access control settings, authentication parameters, and conflict resolution strategies. The documentation is designed for developers implementing secure data storage, retrieval, and synchronization features, providing detailed specifications for enums like `AssetParam` and constants related to update times and sync types.

## Detailed Description

### DATA_LABEL_NORMAL_1ArrayU_16more.md
This document provides an API reference for attributes and query parameters related to critical asset management in the SystemCapability.Security.Asset module. It details data labels for custom auxiliary information (both synchronized and local), persistence settings, access control mechanisms, and query result configurations like pagination and sorting. Key concepts include the distinction between normal and local data labels regarding synchronization, the absence of integrity protection for custom fields, and specific controls for asset access and retrieval. This reference is intended for developers using the Cangjie language to implement secure data storage and retrieval features.

### SYNC_TYPEUInt32_3more.md
This document serves as an API reference for defining attributes and retrieval methods related to key asset synchronization and updates in the Cangjie programming language. It covers the SYNC_TYPE constant for synchronization types, the UPDATE_TIME constant for data timestamps, and the getTag() function for retrieving attribute identifiers. Key information includes that all elements belong to the SystemCapability.Security.Asset system capability starting from version 19, with getTag() returning a UInt32 AssetTag value. This technical documentation is intended for developers building secure applications using the Cangjie framework who need to manage asset metadata and synchronization states.

### enum_AssetParam_13more.md
This API reference document defines the AssetParam enum, which specifies attribute name types supported by critical assets in the Cangjie language. It details specific enum values including access control settings (ACCESSIBILITY), unique indexing (ALIAS), authentication parameters (AUTH_TYPE, AUTH_TOKEN, AUTH_CHALLENGE), conflict resolution strategies, and custom data labels (DATA_LABEL_CRITICAL). Key information includes the mapping to AssetTag tags and the inclusion of CJ_UNKNOWN_TYPE for invalid operations. This documentation is intended for developers implementing secure asset management who need to configure asset properties, user authentication, and data integrity within the SystemCapability.Security.Asset framework starting from version 19.
