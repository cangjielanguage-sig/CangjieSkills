# ohosbundlebundle_managerbundleManager管理

本目录包含仓颉语言中 `ohos.bundle.bundle_manager` 模块的 API 参考文档，涵盖 HarmonyOS 应用包管理的核心功能。主要内容包括应用及模块元数据查询、默认应用管理、组件配置（如 Ability 和 ExtensionAbility）、权限控制及窗口属性设置。文档详细定义了用于描述路由、签名、依赖关系及显示方向的类与枚举。该目录适用于使用仓颉语言进行鸿蒙应用开发的开发者，旨在帮助其深入理解并利用 BundleManager 框架进行应用信息检索、模块配置及系统交互。

### class_AbilityInfo/
描述Ability组件配置信息，包含包名、图标、权限、窗口模式等核心只读属性，映射自配置文件。

### class_ApplicationInfo/
定义应用程序配置信息结构，涵盖基本信息、身份标识、安装路径、运行特性及权限列表等核心只读属性。

### class_BundleFlag/
定义静态常量，用于指定获取应用包信息时的内容范围，支持按需获取模块、Ability及签名信息。

### class_BundleInfo/
封装应用包元数据，包括应用名称、版本号、权限状态、安装时间及模块配置，支持分布式版本兼容性检查。

### class_BundleManager/
提供Bundle信息查询、链接访问性检查及基于Ability名称获取配置文件的核心功能，含静态方法及异常处理。

### class_ExtensionAbilityInfo/
封装ExtensionAbility组件配置信息，涵盖应用包名、模块名、权限和元数据等只读属性，用于查询组件元数据。

### class_HapModuleInfo/
定义HAP模块信息结构，涵盖模块属性、依赖关系、资源路径、UI配置、元数据及预加载和路由表配置。

### enum_ExtensionAbilityType/
定义系统扩展能力类型，涵盖后台服务、数据共享、无障碍服务、输入法等，说明功能描述及使用限制。
