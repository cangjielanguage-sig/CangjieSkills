This directory contains API reference documentation for the `ShowDialogOptions` class in the Cangjie programming language, designed for the ArkUI framework. It covers the configuration properties and constructor parameters required to display and customize dialog boxes in HarmonyOS applications. Key topics include text content, layout settings, visual styles like background blur, and behavioral flags such as modal states and hover interactions. This documentation is suitable for software developers and UI engineers using Cangjie to build user interfaces, specifically those needing to implement custom modal or non-modal dialog windows with precise control over appearance and behavior.
