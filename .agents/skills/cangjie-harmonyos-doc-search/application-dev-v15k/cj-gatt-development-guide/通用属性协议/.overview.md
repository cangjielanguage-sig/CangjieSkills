# 通用属性协议

This directory provides a comprehensive guide to the Generic Attribute Protocol (GATT), specifically designed for developers working within the HarmonyOS ecosystem. It serves as a central resource for understanding how Bluetooth Low Energy (BLE) devices transmit data, covering the essential framework of attributes and services. The documentation bridges the gap between theoretical protocol concepts and practical application, utilizing the Cangjie language and ArkTS for implementation. Key topics include server initialization, service discovery, and client-side data exchange. This collection is ideal for software developers and engineers who possess a basic understanding of wireless protocols and are seeking to implement efficient, robust connectivity features in their applications using the ConnectivityKit.

## Detailed Description

### 简介_2more.md 简介_2more.md
This document serves as an introduction to the Generic Attribute Protocol (GATT), explaining its role in data transmission between Bluetooth Low Energy devices. It covers the definition of GATT as a framework for attributes and services, followed by a description of primary usage scenarios. Key takeaways include understanding how devices provide and consume services, specifically focusing on client-side read/write operations and server-side service management with notifications. Intended for developers working with BLE, this overview provides foundational knowledge for implementing GATT-based communication.

### 主要场景开发步骤/
This directory outlines the essential development steps for implementing Bluetooth Low Energy (BLE) scenarios within the HarmonyOS ecosystem. It focuses on the core interactions between GATT servers and clients, utilizing the Cangjie language and ArkTS. The content comprehensively covers the complete lifecycle of Bluetooth communication, ranging from server initialization and service management to client connection and data exchange. It is designed for software developers who possess a foundational understanding of Bluetooth protocols and asynchronous programming and are looking to build robust, efficient connectivity features in their applications.

### 接口说明/
This directory provides essential documentation for the Cangjie Bluetooth BLE GATT interfaces, serving as a central resource for developers implementing wireless connectivity features. It encompasses a high-level overview for quick navigation and a detailed API reference for deep technical implementation. The content covers critical aspects such as connection management, service discovery, characteristic and descriptor read/write operations, MTU size negotiation, and the handling of asynchronous events through callbacks. These documents are intended for software developers utilizing the Cangjie programming language who need precise, structured access to GATT specifications to build efficient Bluetooth Low Energy applications. The documentation directs users to the ConnectivityKit reference for complete code examples.
