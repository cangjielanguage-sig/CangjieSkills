# 基础类型定义

This directory serves as a foundational repository for basic type definitions within the ArkUI framework and Cangjie language ecosystem. It primarily focuses on the structural configuration and styling of dialog components, specifically those related to date selection and picker interfaces. By providing detailed specifications for classes like `DatePickerDialogOptions` and `PickerDialogButtonStyle`, this section enables developers to customize user interactions, visual appearances, and event handling logic. It is suitable for UI developers and system architects seeking to implement robust, customizable dialog interfaces in their applications, ensuring a consistent and responsive user experience across different devices and API versions.

## Detailed Description

### class_DatePickerDialogOptions/
This directory contains API reference documentation for the `DatePickerDialogOptions` class within the Cangjie language and ArkUI framework. It covers the configuration of date sliding picker dialogs, including properties for setting date ranges, display modes (lunar calendar, military time), and visual styles for text and buttons. The documentation also details event callbacks for dialog lifecycle and user interactions. It is suitable for ArkUI developers and UI engineers looking to implement customizable date selection interfaces in their applications.

### class_PickerDialogButtonStyle/
This directory contains detailed API reference documentation for the `PickerDialogButtonStyle` class, a fundamental resource for configuring the visual presentation and interactive behavior of confirmation buttons within PickerDialogs. The documentation encompasses a broad spectrum of styling capabilities, including button type, style mode, role, font attributes (size, color, weight, style, family), background colors, and border radius. It also explains interaction logic, particularly the configuration of the Enter key response. The materials are provided for developers utilizing both ArkUI and Cangjie programming languages. This directory is suitable for UI developers and system architects aiming to create highly customized and responsive dialog interfaces, with technical support starting from API version 19.
