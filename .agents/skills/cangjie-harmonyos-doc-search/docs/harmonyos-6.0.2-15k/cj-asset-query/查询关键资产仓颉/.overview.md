# 查询关键资产仓颉

This directory provides a complete technical guide for querying critical assets using the Cangjie language within the AssetStoreKit framework. It covers essential development tasks, including synchronous interface usage, batch querying with pagination, and handling IPC transmission constraints. The documentation details API specifications, attribute parameters for access control, and data security limitations regarding unencrypted fields. Designed for developers and system integrators, this resource facilitates the implementation of secure asset storage, synchronization, and retrieval, ensuring optimal performance and adherence to system-level restrictions.

## Detailed Description

### 代码示例.md 代码示例.md
This document provides Cangjie code examples demonstrating the usage of synchronous interfaces in the AssetStoreKit for querying critical assets. The content is divided into three main scenarios: retrieving a single asset's plaintext, retrieving a single asset's attributes, and batch querying attributes with pagination and sorting. Key concepts include using AssetParam to specify query conditions such as ALIAS, RETURN_TYPE, RETURN_LIMIT, and RETURN_ORDERED_BY. The examples also illustrate error handling with BusinessException. This technical guide is intended for developers seeking to implement asset query functionality within their applications.

### 约束和限制.md 约束和限制.md
This document serves as a technical reference outlining specific constraints and limitations related to the transmission of critical assets through IPC channels. The primary topic focuses on the limitations imposed by IPC buffer sizes during batch queries of critical assets. Key information includes the recommendation to perform batch queries in groups of no more than 40 items when the total number of critical assets exceeds this threshold, ensuring data integrity and transmission stability. Intended for developers and system integrators, this reference guide requires an understanding of IPC mechanisms and asset querying workflows to optimize performance and avoid transmission errors.

### 接口介绍/
This directory contains technical documentation for the AssetStoreKit API, focusing on the management and querying of key assets. It covers the `query` function interface, attribute parameter definitions for access control and persistence, and detailed query options for pagination and sorting. Key topics include data security constraints (specifically regarding unencrypted custom fields), API versioning updates (API 12), and storage classifications. This documentation is intended for developers and system integrators who need to implement secure asset storage, synchronization, and retrieval functionalities within their applications.
