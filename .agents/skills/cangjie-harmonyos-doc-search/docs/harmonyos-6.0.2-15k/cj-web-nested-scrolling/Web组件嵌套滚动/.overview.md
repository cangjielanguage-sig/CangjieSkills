# Web组件嵌套滚动

This directory focuses on the implementation and configuration of nested scrolling for Web components within ArkUI scrollable containers. It provides comprehensive resources for enabling coordinated scrolling between child Web views and parent containers. The content covers the `nestedScroll` property interface, the `NestedScrollMode` enumeration, event propagation logic, supported container types, and input event compatibility. Key concepts include the four scrolling modes (SELF_ONLY, SELF_FIRST, PARENT_FIRST, PARALLEL) and the mechanism for passing unconsumed scroll offsets to the nearest parent container based on axis direction. This collection is suitable for HarmonyOS developers using Cangjie or ArkTS who need to integrate Web components into complex, multi-layered scrolling interfaces.

## Detailed Description

### Web组件嵌套滚动_1.md
This technical guide explains how to implement nested scrolling for Web components within ArkUI scrollable containers to enable coordinated scrolling between child and parent components. The document covers the nestedScroll property interface, the NestedScrollMode enumeration, event propagation logic, supported container types, and input event compatibility. Key information includes the four scrolling modes (SELF_ONLY, SELF_FIRST, PARENT_FIRST, PARALLEL) and how unconsumed scroll offsets are passed to the nearest parent container based on axis direction. Targeted at HarmonyOS developers using the Cangjie language, this guide assists in integrating Web components into complex, multi-layered scrolling interfaces.

### Web组件嵌套滚动_2.md
This document provides a code example demonstrating how to configure and control nested scrolling behavior for Web components within a parent Scroll container in ArkUI. It covers the implementation of the nestedScroll method, specifically focusing on the scrollForward and scrollBackward parameters. The example allows dynamic switching between four scrolling modes: SELF_ONLY, SELF_FIRST, PARENT_FIRST, and PARALLEL via interactive buttons, illustrating how scroll events are prioritized between the child Web view and the parent container. This technical example is intended for developers using ArkTS to build complex layouts involving nested scrollable components.
