# ohosskill

本目录包含仓颉语言编写的 `ohos.skill` 模块 API 参考文档，主要涵盖 HarmonyOS 应用开发中的技能（Skill）与 URI 处理机制。文档详细定义了 `SkillUri` 类和 `Skill` 类，用于描述 URI 协议、路径匹配规则以及应用的动作、实体和域名校验等属性。这些组件支持 MIME 类型和 UniformDataType 规范，是实现应用间跳转、数据分享及意图匹配的核心。适用于具备仓颉语法基础及 HarmonyOS 系统框架（如 BundleManager、AbilityKit）知识的应用开发者。

## Detailed Description

### class_SkillUri.md
这是一份Cangjie语言的API参考文档，定义了用于描述URI信息的SkillUri类。文档涵盖了URI协议、主机、端口、路径及其匹配方式（前缀、正则），以及数据类型标识和文件处理限制等属性。所有属性均为只读，支持MIME和UniformDataType规范，适用于应用间跳转和分享场景，系统能力依赖BundleManager框架。面向HarmonyOS应用开发者，需了解Cangjie语法及系统框架。

### ohosskill_4more_d9cb8c68.md
这是一份仓颉语言的API参考文档，详细介绍了ohos.skill模块中的Skill标签对象。文档主要包含模块导入说明、示例代码运行指南以及Skill类的定义。核心信息在于Skill类的四个只读属性：actions、entities、uris和domainVerify，分别用于接收Action、Entity、Uri集合及域名校验状态。该对象需通过getBundleInfoForSelf接口获取，系统能力属于BundleManager框架。文档面向HarmonyOS应用开发者，要求具备Context及AbilityKit相关前置知识。
