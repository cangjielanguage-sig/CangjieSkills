# 非首次渲染

This directory focuses on managing dynamic updates and rendering efficiency for list components in the Cangjie (ArkUI) framework, specifically utilizing the `LazyForEach` component. It covers various scenarios for non-initial rendering, including data swapping, single and bulk modifications, sub-property updates, and adding or deleting items. Key concepts include `BasicDataSource`, notification methods like `notifyDataChange`, and deep observation mechanisms using `@Observed` and `@ObjectLink`. This resource is suitable for developers seeking to optimize UI performance and ensure precise state synchronization in dynamic applications.

## Detailed Description

### 交换数据.md 交换数据.md
This document serves as a code tutorial demonstrating how to implement data swapping within a list component using the Cangjie programming language. It covers the implementation of a custom MyDataSource class extending BasicDataSource to manage data operations, specifically the moveData method which handles element swapping and notifies the UI. The example details the EntryView component, utilizing LazyForEach to render items and handle click events to trigger the exchange logic. Key takeaways include understanding the relationship between data source manipulation and UI updates via notifyDataMove. This guide targets developers working with dynamic list rendering and data binding in this UI framework.

### 改变单个数据.md 改变单个数据.md
This tutorial demonstrates how to modify and refresh a single data item within a list using the LazyForEach component in Cangjie. The content covers the implementation of a custom data source class extending BasicDataSource, specifically focusing on the changeData method and the UI interaction logic. Key takeaways include the mechanism where updating data triggers notifyDataChange, which subsequently signals the LazyForEach component to rebuild only the specific item at the changed index. This document serves as a practical guide for developers building dynamic list interfaces, illustrating the data-to-UI binding flow for individual item updates.

### 改变多个数据.md 改变多个数据.md
This tutorial demonstrates how to handle bulk data updates and trigger a full reload within a LazyForEach component in the Cangjie framework. It covers the implementation of a custom DataSource extending BasicDataSource, specifically focusing on methods for modifying data and notifying changes. Key information includes the workflow where clicking an item modifies all data entries and calls reloadData, prompting LazyForEach to compare keys and rebuild nodes accordingly. The document explains the caching mechanism where matching keys reuse existing components. This guide is intended for developers managing dynamic list rendering and state synchronization in Cangjie applications.

### 改变数据子属性.md 改变数据子属性.md
This technical guide explains how to optimize rendering performance when updating sub-properties of items within a LazyForEach list. It covers the performance limitations of standard refreshing and introduces the @Observed and @ObjectLink deep observation mechanism. The document provides a Cangjie code example demonstrating how to implement this pattern to ensure only specific components update rather than reconstructing the entire ListItem. Key takeaways include the efficiency gains of deep observation for complex structures. This guide targets developers seeking to improve UI performance in dynamic lists, requiring knowledge of data binding and component lifecycles.

### 非首次渲染_3more.md 非首次渲染_3more.md
This technical guide explains how to manage dynamic updates for the LazyForEach component during non-initial rendering cycles using the Cangjie language. The document details two primary scenarios: adding data and deleting data from a data source. Key takeaways include the necessity of implementing custom data source methods that call specific notification interfaces, such as notifyDataAdd and notifyDataDelete. These calls trigger internal listener callbacks, instructing LazyForEach to create or remove child components at specific indices. The content provides practical code examples demonstrating how to bind these data changes to UI interactions like button clicks. Intended for ArkUI developers, this tutorial ensures efficient list rendering and synchronization between data and view states.

### 精准批量修改数据/
This directory provides a comprehensive guide on implementing precise batch data modifications for LazyForEach components within the Cangjie development environment. It focuses on utilizing BasicDataSource and DataOperation to execute granular updates—such as moving, exchanging, adding, and deleting data items—without the performance cost of reloading the entire dataset. Key topics include understanding operation constraints, correct index referencing, and optimizing UI updates through key comparisons. This resource is specifically designed for UI developers and engineers who need to manage dynamic data updates efficiently and ensure smooth list rendering in Cangjie applications.
