This directory provides comprehensive API reference documentation for the `ohos.ability_access_ctrl` module within the HarmonyOS Cangjie development environment. It focuses on program access control management, covering essential components for security and permission handling. Key topics include the `GrantStatus` enumeration for permission states, the `AtManager` class for managing access tokens, and methods for verifying and requesting user permissions. This documentation is suitable for Cangjie developers who need to implement robust authentication, authorization, and runtime permission request flows in their applications, ensuring secure interaction with system capabilities.
