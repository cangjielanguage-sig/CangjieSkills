# 应用沙箱目录

This directory provides a comprehensive technical guide to the Application Sandbox mechanism in HarmonyOS, focusing on security isolation and file system management. It covers the fundamental concepts of sandboxing, the mapping between virtual sandbox paths and real physical paths, and detailed file organization structures including encryption levels (EL1-EL5). Key topics include data isolation, path mapping, Context API usage, and storage lifecycle management. This resource is essential for application developers and system architects who need to implement secure data storage, manage application resources efficiently, and understand the underlying file system architecture to prevent unauthorized access and ensure data security.

## Detailed Description

### 应用沙箱目录_2more.md
This document defines the Application Sandbox Directory mechanism, a security isolation feature designed to protect application data from unauthorized access and path traversal. It covers the composition of the sandbox directory, file access permissions, and the distinction between application sandbox paths and real physical paths. Key takeaways include that applications are restricted to viewing only their own files and essential system files, while user file access requires specific authorization. The document highlights that sandbox paths are virtual and isolated from the physical paths visible to system processes like the hdc shell. This technical guide targets application developers who need to understand file system isolation and path mapping for secure data management.

### 应用沙箱路径和真实物理路径的对应关系.md
This reference document details the mapping relationship between application sandbox paths and their corresponding real physical paths on the device. It covers mappings for installation bundles, encrypted data directories (el1 and el2 levels), databases, and distributed files. Key information includes the definition of path variables like USERID and PACKAGENAME, as well as specific path variations for applications running in independent Extension sandboxes compared to standard applications. This guide is intended for developers working with file storage who need to understand the underlying file system structure for debugging or advanced file operations. Keywords: sandbox path, physical path, file mapping, el1, el2, ExtensionAbility, application storage.

### 应用文件目录与应用文件路径/
This directory serves as a comprehensive technical resource for understanding HarmonyOS application file structures and path management within the application sandbox. It covers the hierarchical organization, encryption levels (EL1 through EL5), and the distinction between App-level and HAP-level storage. Key topics include standard directory definitions (such as files, cache, and preferences), Context API usage for path retrieval, and data lifecycle management. This resource is essential for HarmonyOS developers seeking to implement secure data storage, manage application resources efficiently, and handle cross-device file sharing effectively while adhering to strict system security standards and avoiding common pitfalls like hardcoded paths. It provides the necessary context for developers to navigate the file system architecture securely.
