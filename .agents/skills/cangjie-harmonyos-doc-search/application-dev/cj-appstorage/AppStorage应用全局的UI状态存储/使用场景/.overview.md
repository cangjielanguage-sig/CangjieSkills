# 使用场景

This directory provides comprehensive guides on practical usage scenarios for state management in ArkUI applications developed with the Cangjie language. It covers essential topics such as implementing application logic using AppStorage and LocalStorage, managing complex data types like DateTime and collections, and optimizing performance by avoiding common anti-patterns. Key concepts include two-way data synchronization, reactive UI updates, and the effective use of decorators like @StorageLink and @LocalStorageLink. These resources are specifically designed for ArkUI developers who aim to build efficient, high-performance applications with robust state handling and data binding capabilities.

### 不建议借助StorageLink的双向同步机制实现事件通知.md 不建议借助StorageLink的双向同步机制实现事件通知.md
This technical guideline advises against using the @StorageLink and AppStorage two-way synchronization mechanism for implementing event notifications in ArkUI applications. The document covers performance optimization, state management, and the @Watch decorator. Key takeaways include that using @StorageLink for events triggers unnecessary UI refreshes across all bound components, degrading performance. A Cangjie code example demonstrates this pattern, and the text suggests avoiding direct UI binding of these variables while minimizing @Watch function complexity. The target audience is ArkUI developers using the Cangjie language who need to optimize application performance and manage state efficiently. Keywords: ArkUI, Cangjie, @StorageLink, AppStorage, event notification, performance optimization, @Watch.

### 从应用逻辑使用AppStorage和LocalSto_2more.md 从应用逻辑使用AppStorage和LocalSto_2more.md
This guide explains how to implement state management using AppStorage and LocalStorage in Cangjie-based ArkUI applications. It covers usage within application logic and UI components, highlighting the differences between the singleton AppStorage and instance-based LocalStorage. Key takeaways include using static APIs for AppStorage, instance methods for LocalStorage, and achieving two-way data synchronization via @StorageLink and @LocalStorageLink decorators for both primitive types and custom objects. This tutorial targets ArkUI developers seeking to manage application state and data binding effectively.

### 装饰DateTime类型变量_3more.md 装饰DateTime类型变量_3more.md
This tutorial demonstrates how to use the @StorageLink decorator with complex data types in ArkUI Cangjie development to achieve reactive UI updates. It covers three specific data types: DateTime, Map, and Set, providing complete code examples for each. The examples illustrate that modifying these variables triggers view refreshes. For collection types like Map and Set, the code emphasizes reassigning the variable after mutation to ensure the UI updates correctly. This guide targets ArkUI developers using the Cangjie language who need to manage state for dates and collections.
