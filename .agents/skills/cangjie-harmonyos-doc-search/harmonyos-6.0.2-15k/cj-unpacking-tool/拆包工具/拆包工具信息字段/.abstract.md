This directory contains technical reference documentation for data structures utilized in HarmonyOS application unpacking and parsing tools. It comprehensively covers schema definitions for various configuration objects found within HAP (Harmony Ability Packages), including application metadata, ability configurations, permissions, and distribution settings. Key topics include the distinctions between FA and Stage models, form configurations, event handling, and shortcut behaviors. This documentation is suitable for software developers, system integrators, and tool engineers who need to programmatically analyze, parse, or validate HarmonyOS application packages and their internal configuration files.
