This directory contains comprehensive reference documentation for error codes within the Meta-Ability subsystem, primarily targeting HarmonyOS/OpenHarmony developers. It covers a wide range of runtime exceptions, including application lifecycle management, component interactions (Ability, Extension), installation-free services, and system constraints like process limits. The documents provide detailed error messages, causes, and troubleshooting steps for issues ranging from context absence and URI validation to patching failures and image editing errors. It is suitable for software developers and system integrators debugging application behavior and resolving system-level exceptions.
