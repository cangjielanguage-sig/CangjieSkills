This directory contains API reference documentation for the `WebDownloadItem` class within the ArkWeb framework, designed for the Cangjie programming language. It covers the management of web download tasks, including starting, pausing, resuming, canceling, and monitoring download progress. Key functionalities include retrieving file metadata (URL, MIME type, size), tracking download status and speed, and handling errors through serialization and deserialization. This documentation is suitable for HarmonyOS developers building applications with WebView components who need to implement robust file download capabilities and manage download lifecycles programmatically.
