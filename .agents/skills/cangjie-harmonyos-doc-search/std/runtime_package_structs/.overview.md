# runtime_package_structs

This directory serves as a specialized reference for the Cangjie runtime package, specifically focusing on the structural definitions used to access system and runtime statistics. It primarily documents three deprecated structs—MemoryInfo, ProcessorInfo, and ThreadInfo—which were historically utilized for retrieving heap data, CPU details, and thread metrics. The content highlights the critical transition from these object-oriented structures to a more functional approach using global functions. Key topics include memory allocation tracking, physical memory usage, processor counts, and thread statistics. This documentation is essential for Cangjie developers involved in performance monitoring or maintaining legacy codebases, providing the necessary guidance to migrate from deprecated static properties to modern global function equivalents like `getAllocatedHeapSize` and `getProcessorCount`. By understanding these changes, developers can ensure their applications remain compatible with the latest version of the Cangjie standard library while effectively managing system resources. The directory is particularly relevant for those refactoring existing code to adhere to current best practices and avoid using obsolete APIs. It assumes the reader has a working knowledge of the Cangjie language and its standard library ecosystem.

## Detailed Description

The directory contains a single documentation file that outlines the deprecated structures previously used for system monitoring. This file is crucial for understanding the evolution of the Cangjie runtime API. Below is the detailed breakdown of the file's contents:

### runtime_package_structs.md runtime_package_structs.md

This API documentation file defines three deprecated structs within the Cangjie runtime package used for accessing system and runtime statistics. It covers MemoryInfo for heap data, ProcessorInfo for CPU details, and ThreadInfo for thread metrics. All structs expose static properties returning Int64 values but are marked for deprecation. Developers must migrate to equivalent global functions like getAllocatedHeapSize or getProcessorCount to access allocated memory, physical memory, processor counts, and thread statistics. This reference guide targets Cangjie developers needing to monitor runtime resources, requiring knowledge of the language's standard library structure. Please refer to this file for the complete specifications and migration details.
