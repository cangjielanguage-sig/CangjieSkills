# cj-apis-bluetooth-constant

本目录包含仓颉语言蓝牙常量模块的API参考文档，主要定义了蓝牙开发中所需的基础常量。核心内容涵盖了 `ProfileConnectionState` 枚举，用于描述蓝牙设备的四种连接状态（已连接、正在连接、已断开、正在断开），并提供了状态判等、判不等及字符串转换等操作方法。该模块起始版本为22，适用于使用 ConnectivityKit 进行蓝牙应用开发的开发者，为管理蓝牙连接状态提供了标准化的数据结构和逻辑支持。

## 详细说明

### cj-apis-bluetooth-constant.md cj-apis-bluetooth-constant.md

本文档是仓颉语言蓝牙常量模块的API参考文档，旨在定义蓝牙相关的常量。核心内容为ProfileConnectionState枚举，详细描述了蓝牙设备profile的四种连接状态：已连接、正在连接、已断开及正在断开。文档涵盖了该枚举的成员定义、功能说明以及判等、判不等和字符串转换等操作方法，起始版本为22。该文档面向使用ConnectivityKit进行蓝牙开发的开发者，提供了管理蓝牙连接状态所需的基础数据结构和操作逻辑。
