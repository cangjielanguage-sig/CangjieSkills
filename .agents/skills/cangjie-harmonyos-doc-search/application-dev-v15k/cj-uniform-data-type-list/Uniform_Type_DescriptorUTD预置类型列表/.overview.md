## Detailed Description

### Uniform_Type_DescriptorUTD预置类型列表.md Uniform_Type_DescriptorUTD预置类型列表.md
This reference document defines the Uniform Type Descriptor (UTD) system, which standardizes data type descriptions to resolve ambiguity between formats like MIME types and file extensions. The content categorizes preset types into three main sections: Basic Types, System-associated Types, and Application-defined Types. Key information includes how UTD facilitates seamless cross-application and cross-device data transmission by providing a unified standard, thereby eliminating complex adaptation needs at the target end. This guide is intended for developers and system architects handling data interoperability and type management.

### 系统关联类型.md 系统关联类型.md
This document serves as a technical reference defining system-associated data types that facilitate cross-application interaction within specific operating systems. The content focuses on a comprehensive table listing predefined types for HarmonyOS, MacOS, Debian, Android, and RedHat, categorized by attributes such as UTD-ID, belonging type, file suffixes, and MIME types. Key information includes the identification scheme using the os-name.xxx format and specific mappings for formats like .hap, .apk, and .dmg. Intended for developers and system architects, this reference aids in implementing file type recognition and data handling across different platforms.

### [4] 应用定义类型/
This directory contains comprehensive reference documentation for Application Defined Types, custom data types maintained by specific applications using reverse domain naming conventions. It covers the theoretical framework of these types and provides extensive technical tables mapping file extensions to MIME types and internal identifiers. The content spans a wide range of software ecosystems, including Microsoft Office, OpenDocument, Adobe products, AutoCAD, and various multimedia formats. This resource is essential for developers, system architects, and administrators who need to configure file associations, implement data parsing logic, or ensure system integration across diverse file formats.
