# class_RefType

This directory provides essential API reference documentation for components within the Abstract Syntax Tree (AST) of the Cangjie programming language. It focuses on the `RefType` class, which models non-primitive type nodes, and the `traverse` function, which enables systematic navigation of syntax tree structures. Key topics include the management of type identifiers, generic arguments, tokenization processes, and the implementation of visitor patterns for tree traversal. This documentation is specifically designed for compiler developers, language tool creators, and software engineers who require precise tools to programmatically inspect, analyze, or modify Cangjie code structures. It serves as a technical guide for building robust development tools.

### class_RefType_9more.md
This API reference document details the RefType class, which represents non-primitive type nodes within the Abstract Syntax Tree (AST) of the Cangjie language. The documentation outlines the class structure, properties for managing type identifiers and generic arguments—such as lAngle, rAngle, and typeArguments—as well as constructors and the toTokens method. Key information includes that RefType handles custom types and built-in types like Array or String, supporting generic type parameters while inheriting from TypeNode. This technical guide is intended for compiler developers or tool creators requiring precise AST manipulation and tokenization capabilities.

### func_traverseVisitor.md
This document provides API reference documentation for the traverse function in the Cangjie programming language, designed to navigate Abstract Syntax Tree (AST) nodes. This reference material targets developers working with AST manipulation in Cangjie who need to programmatically inspect or modify code structures.
