This directory provides comprehensive API reference documentation for the `ohos.telephony_sim` module, designed for the Cangjie programming language and TelephonyKit. It focuses on the management and querying of SIM card information, covering data definitions, account details, and operational classes. Key components include enumerations for card types and states, the `IccAccountInfo` class for reading card properties, and the `TelephonySim` class for executing telephony functions. This documentation is essential for developers building applications that require access to SIM status, operator details, and network configurations, adhering to system permissions and API version 19 requirements.
