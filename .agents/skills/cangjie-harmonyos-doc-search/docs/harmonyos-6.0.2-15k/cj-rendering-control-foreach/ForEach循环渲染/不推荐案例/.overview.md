# 不推荐案例

This directory serves as an essential educational resource for ArkUI/Cangjie developers, focusing on anti-patterns and common pitfalls in list rendering. It specifically addresses the incorrect usage of the `ForEach` component, providing detailed analyses of why certain implementations are discouraged. The core content covers the critical importance of key generation, explaining how using data source indices as keys can lead to unexpected rendering results, such as duplicate UI elements, and how omitting custom key generators can cause significant performance degradation due to unnecessary component recreation. By understanding these "not recommended" cases, developers can master the framework's key matching mechanism and lifecycle management. This directory is highly suitable for developers seeking to debug rendering issues, optimize application performance, and ensure robust state management in their Cangjie projects.

## Detailed Description

### 不推荐案例_2more.md 不推荐案例_2more.md
This document serves as a best practices guide warning developers against incorrect key generation in ForEach loops. It specifically addresses the topic of "Unexpected Rendering Results" caused by using the data source index as the key. The key information provided includes a Cangjie code example demonstrating that using `index` in `keyGeneratorFunc` causes component reuse errors during list updates, resulting in duplicate UI elements. The text explains the framework's key matching mechanism and advises developers to avoid index-based keys to ensure correct rendering. This guide is intended for ArkUI/Cangjie developers managing list rendering and state.

### 渲染性能降低.md 渲染性能降低.md
This tutorial addresses rendering performance degradation in ArkUI applications caused by improper usage of the ForEach component. It illustrates how omitting the keyGeneratorFunc parameter leads to index-based key generation, forcing unnecessary component recreation and lifecycle execution when data is modified. The document analyzes the underlying mechanism through code examples and log outputs, demonstrating why default keys fail to maintain component identity. It concludes by providing the correct implementation using a custom key generator based on item content to ensure component reuse. This guide targets Cangjie developers seeking to optimize list rendering efficiency and understand state management best practices.
