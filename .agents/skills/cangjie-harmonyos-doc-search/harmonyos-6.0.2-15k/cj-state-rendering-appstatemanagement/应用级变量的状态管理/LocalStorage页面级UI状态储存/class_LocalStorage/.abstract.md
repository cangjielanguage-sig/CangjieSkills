This directory provides API reference documentation for the `LocalStorage` class in the Cangjie ArkUI framework. It covers page-level UI state storage, including class constructors, property management, and data binding techniques. Key functionalities include retrieving values, checking existence, creating one-way or two-way bindings, and managing property lifecycles. This documentation is intended for ArkUI developers using Cangjie who need to implement robust state management, data persistence, and synchronization between UI components and the storage layer.
