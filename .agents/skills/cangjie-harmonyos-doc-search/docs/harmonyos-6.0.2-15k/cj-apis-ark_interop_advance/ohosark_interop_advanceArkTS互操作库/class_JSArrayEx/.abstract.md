This directory contains comprehensive API documentation for the `JSArrayEx` class within the Cangjie programming language, specifically designed to facilitate declarative interoperability with ArkTS Arrays in HarmonyOS development. It covers the class definition, properties like `size`, and methods for array manipulation such as `clone`, `concat`, and `get`. Additionally, it includes functions for setting values, converting arrays, and using subscript operators. The documentation is tailored for Cangjie developers working on ArkUI applications who need to manage array data and ensure seamless type conversion between Cangjie and ArkTS environments, particularly when dealing with Napi and framework-level interactions. It serves as a technical guide for understanding the bridge between native Cangjie logic and the ArkTS frontend layer.
