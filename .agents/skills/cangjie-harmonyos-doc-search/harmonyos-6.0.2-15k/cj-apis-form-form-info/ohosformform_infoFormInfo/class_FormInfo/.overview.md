# class_FormInfo

This directory provides comprehensive API reference documentation for the `FormInfo` class within the Cangjie programming language framework. It focuses on the configuration and metadata of cards (widgets), systematically detailing read-only properties that define identity, display characteristics, structural settings, and update behaviors. Key topics include card dimensions, shapes, transparency, update cycles, form types, and system version compatibility (specifically version 20). This documentation is intended for application developers utilizing the SystemCapability.Ability.Form framework who need to access or manipulate card attributes programmatically to create dynamic, responsive, and visually consistent user interfaces.

## Detailed Description

### class_FormInfo_21more.md

This document serves as API reference documentation for the FormInfo class in the Cangjie language, detailing the configuration information for cards. It systematically lists read-only properties that define various card attributes, including identity details like bundleName and abilityName, display characteristics such as displayName and colorMode, and structural settings like supportDimensions and formType. The document specifies that all properties are read-only and available starting from system version 20. It is intended for application developers working with the SystemCapability.Ability.Form framework who need to access or manipulate card metadata. Key concepts include card dimensions, shapes, and dynamic status.

### prop_transparencyEnabled_3more.md

This document serves as an API reference for three specific read-only properties related to card configuration in the Cangjie programming language. It details the properties transparencyEnabled, updateDuration, and updateEnabled. Each section defines the property's functionality, data type, read-only access capability, and the starting version 20. The properties control whether a card supports background transparency, the duration of the card's update cycle, and whether updates are enabled. All are read-only boolean or integer values introduced in version 20. This reference is intended for developers using the Cangjie framework to manage widget or card behaviors, specifically regarding visual transparency and update mechanisms.
