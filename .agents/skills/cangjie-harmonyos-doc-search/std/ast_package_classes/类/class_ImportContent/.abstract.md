This directory provides comprehensive API reference documentation for the `ImportContent` class within the Cangjie Abstract Syntax Tree (AST). It details the structural representation of import statement nodes, including class definitions, inheritance from the `Node` parent, and a wide array of mutable properties. Key topics include distinguishing between import types (single, alias, multi), handling structural tokens like braces and commas, and managing potential `ASTException` errors. Additionally, it covers methods for type checking, token conversion, and AST traversal. This documentation is specifically designed for compiler developers and software engineers who are building tools to parse, analyze, or transform Cangjie source code.
