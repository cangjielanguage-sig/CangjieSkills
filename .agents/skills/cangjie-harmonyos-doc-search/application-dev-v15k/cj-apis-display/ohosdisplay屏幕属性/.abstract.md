This directory contains API reference documentation for the `ohos.display` module in the Cangjie programming language, focusing on screen attribute management within the WindowManager system. It covers essential data structures and functions for handling standard displays, foldable devices, and non-standard screen shapes like cutouts and waterfall screens. Key topics include display physical resolution, fold crease regions, HDR formats, and event listeners for dynamic hardware changes. This documentation is suitable for HarmonyOS developers and UI engineers who need to adapt application layouts to various screen configurations, manage display states, and implement responsive logic for foldable hardware.
