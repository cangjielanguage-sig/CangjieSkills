## 组件事件

### func onError(() -> Unit)

```cangjie
public func onError(callback: ()-> Unit): This
```

**功能：** 播放失败时触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|()->Unit|是|-|回调函数，播放失败时触发。|
