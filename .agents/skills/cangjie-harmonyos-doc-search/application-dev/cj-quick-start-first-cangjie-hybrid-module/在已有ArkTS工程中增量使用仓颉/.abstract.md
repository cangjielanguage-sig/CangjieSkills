This directory focuses on the incremental integration of the Cangjie programming language into existing ArkTS projects within the OpenHarmony and HarmonyOS ecosystems. It covers hybrid development workflows, including environment configuration, cross-language interoperability (synchronous and asynchronous calls), and embedding Cangjie UI components into ArkTS pages. The resources are designed for developers with basic ArkTS knowledge who wish to leverage Cangjie's capabilities without rewriting their entire codebase, facilitating a smooth transition to mixed-language development.
