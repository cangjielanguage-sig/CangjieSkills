## 详细说明

### func_onErrorVoidC_8more_d526ee99.md func_onErrorVoidC_8more_d526ee99.md
本文档是ArkUI框架下使用仓颉语言的媒体播放组件API参考，主要定义了用于监听和控制播放状态的事件回调函数。文档详细介绍了八个核心函数：onError、onFinish、onPause、onPrepared、onSeeked、onSeeking、onStart和onUpdate，分别处理播放失败、结束、暂停、准备完成、进度条操作及进度更新等场景。关键信息包括这些函数均接受VoidCallback或携带PlaybackInfo/PreparedInfo的Callback作为参数，返回This以支持链式调用，且起始版本为22。文档面向需要实现精细媒体播放控制的开发者，要求具备仓颉语言基础及ArkUI开发知识。

### func_onFullscreenChange_fcf578eb.md func_onFullscreenChange_fcf578eb.md
该文档详细介绍了 ArkUI 框架中用于监听视频全屏状态变化的 API 函数 `onFullscreenChange`。文档主要包含函数签名、功能描述、系统能力要求、起始版本及参数说明等部分。关键信息指出，该函数接收一个必填的 `Callback<FullscreenInfo, Unit>` 类型参数，当视频进入或退出全屏时触发回调，并返回 `This` 以支持链式调用。此功能需要 SystemCapability.ArkUI.ArkUI.Full 系统能力，起始版本为 22。这是一份 API 参考文档，主要面向使用 ArkUI 进行视频应用开发的开发者，旨在帮助他们实现全屏交互逻辑。关键词：ArkUI, 视频, 全屏, 回调, API, onFullscreenChange。
