# 拉起邮件类应用mailto方式

This directory provides comprehensive technical documentation on utilizing the `mailto` protocol to launch email applications within the HarmonyOS/OpenHarmony ecosystem. It covers the standard URI format, parameter configuration (subject, body, cc, bcc), and implementation details for both web (HTML) and native application (Cangjie language) environments. Additionally, it guides developers on how to configure their own applications to receive and process `mailto` links. This resource is suitable for developers looking to integrate email composition features or implement deep linking capabilities for email handling in their apps, specifically focusing on the interaction between the calling application and the email client via the `Want` object mechanism. It addresses both the client-side invocation and the server-side reception of these links, ensuring a complete understanding of the data flow.

## Detailed Description

The following documents provide step-by-step instructions and code examples for implementing the mailto functionality.

### 使用场景_3more.md
This technical guide explains how to use the mailto protocol to launch email clients from web pages or applications. It covers common usage scenarios, the standard protocol format with parameters like subject, body, cc, and bcc, and specific implementation steps for both web (HTML) and application (Cangjie code) environments. Key information includes the URI structure mailto:address?key=value and code snippets demonstrating how to construct a Want object to trigger the email client with pre-filled content. The document is targeted at developers needing to integrate email functionality, specifically those using the Cangjie language or standard HTML.

### 目标方开发步骤.md
This technical guide instructs developers on enabling their application to handle `mailto` protocol links initiated by other applications. The document covers two primary steps: configuring the `module.json5` file to declare the `mailto` scheme and specific actions, and implementing code in the Cangjie language to parse the URI. Key takeaways include the necessity of registering the scheme under skills and handling URI extraction in both `onCreate` and `onNewWant` lifecycle callbacks to support cold and hot starts. This guide is intended for HarmonyOS or OpenHarmony application developers seeking to implement deep linking capabilities for email composition.
