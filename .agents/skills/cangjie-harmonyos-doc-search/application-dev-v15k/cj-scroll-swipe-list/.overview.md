# cj-scroll-swipe-list

This directory serves as a comprehensive resource for the `cj-scroll-swipe-list` component within the Cangjie ArkUI framework. It focuses on the implementation and usage of the List component, designed to display continuous data streams using uniform-width items. The documentation covers essential topics such as component initialization, subcomponents like `ListItem` and `ListItemGroup`, and rendering logic using `ForEach` and `LazyForEach`. It also details advanced features including multi-column layouts, sticky headers, and event handling. This resource is tailored for HarmonyOS developers and UI engineers looking to build responsive, interactive list interfaces with precise control over scrolling and layout behaviors.
