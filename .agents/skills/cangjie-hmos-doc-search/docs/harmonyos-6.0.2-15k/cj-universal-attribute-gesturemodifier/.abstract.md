This directory serves as a comprehensive resource for the `cj-universal-attribute-gesturemodifier`, a critical component within the Cangjie ArkUI framework designed to enhance user interaction capabilities. It specifically addresses the `gestureModifier` attribute, which empowers developers to move beyond static gesture definitions and implement dynamic, programmatic bindings for UI components. The documentation covers essential technical elements, including the `GestureModifier` interface, the `applyGesture` method, and the utilization of the `UIGestureEvent` object to define custom logic. By supporting conditional statements such as if/else, this API allows for highly responsive and context-aware gesture handling. This directory is intended for Cangjie developers and software engineers utilizing the ArkUI framework who require advanced, flexible control over component gestures and interaction behaviors in their application development projects.
