This directory focuses on the launch modes of UIAbility components in HarmonyOS development. It comprehensively covers how system instances are managed during startup, specifically detailing singleton, multiton, and specified modes. Key topics include lifecycle callbacks (onNewWant, onCreate), configuration via module.json5, and instance management strategies for different scenarios like document editing. This resource is suitable for HarmonyOS application developers looking to configure component behavior, optimize resource management, and implement precise instance control using the AbilityKit API and Cangjie programming language.
