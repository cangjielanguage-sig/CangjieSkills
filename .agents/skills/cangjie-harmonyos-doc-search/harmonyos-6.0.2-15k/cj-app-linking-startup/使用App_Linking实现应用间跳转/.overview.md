# 使用App_Linking实现应用间跳转

This directory provides a comprehensive guide for HarmonyOS developers on implementing App Linking to enable seamless inter-app navigation and deep linking. It covers the entire development lifecycle, including service introduction, configuration in AppGallery Connect (AGC) and DevEco Studio, domain verification, and code implementation for both calling and receiving applications. Key topics include the `openLink` interface, handling web fallbacks, and troubleshooting common errors. Suitable for client, cloud, and frontend developers looking to integrate secure HTTPS-based linking with Cangjie language support.

## Detailed Description

### FAQ.md FAQ.md
This FAQ document provides troubleshooting guidance and configuration instructions for HarmonyOS AppLinking and domain verification processes. It covers client-side configuration in module.json5, server-side setup including the applinking.json file placement, and methods to verify domain status using the hdc shell command. Key information includes the 20-second initialization wait, 24-hour retry logic for failed verifications, and handling CDN caching delays. The document also explains the many-to-many relationship between apps and domains and how to resolve conflicts when multiple apps share a domain. Targeted at HarmonyOS developers using DevEco Studio, this reference guide addresses common errors like client-error and http_unknown, ensuring proper linking functionality.

### 拉起方实现跳转指导.md 拉起方实现跳转指导.md
This technical guide instructs developers on how to implement App Linking functionality to launch target applications. It details two primary methods: using the AbilityContext.openLink interface and leveraging system browsers or ArkWeb. The guide explains the appLinkingOnly parameter, distinguishing between strict App Linking launches with custom exception handling and a preferred mode that falls back to browsers. It also outlines domain matching constraints for web-based redirections. A Cangjie code example demonstrates the implementation. This document targets application developers needing to integrate cross-app navigation and deep linking capabilities.

### 简介_4more.md 简介_4more.md
This document serves as an introductory guide for implementing App Linking, a service that enables seamless navigation to specific app content via HTTPS links regardless of installation status. It covers the definition, applicable scenarios like scan-to-open and ad traffic, implementation principles involving domain verification, and a development overview dividing tasks between cloud, client, and frontend roles. Key takeaways include the security benefits of domain verification and the fallback mechanism to web content when the app is not installed. The guide targets HarmonyOS developers, specifically cloud, client, and frontend engineers, requiring knowledge of AGC and DevEco Studio.

### 被拉起应用开发指导/
This directory provides comprehensive guidance for HarmonyOS developers on implementing App Linking and deep linking functionalities. It covers the entire workflow from enabling services in the AppGallery Connect (AGC) console and configuring domain verification in DevEco Studio to handling incoming links and parsing parameters within the application code. Key topics include AGC configuration, `module.json5` setup, domain verification, and URI handling using the Cangjie language. This guide is suitable for developers looking to enable seamless transitions from web URLs to native app content.
