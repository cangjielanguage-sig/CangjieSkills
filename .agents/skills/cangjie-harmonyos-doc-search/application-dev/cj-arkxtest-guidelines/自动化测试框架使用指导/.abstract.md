This directory provides comprehensive guidance for automated testing within the OpenHarmony and HarmonyOS ecosystems. It covers the Cangjie automated testing framework, including Unit Test and UI Test implementations, as well as command-line testing strategies using shell commands and the hdc tool. Key topics include environment setup in DevEco Studio, script creation, test execution workflows, and troubleshooting common UI test failures. This resource is suitable for developers and QA engineers seeking to ensure application quality through structured testing, log analysis, and component interaction automation.
