This directory provides comprehensive documentation for the `registerJavaScriptProxy` function, focusing on the use of array strings for method registration and JSON-based permission configurations within the ArkWeb framework. It includes detailed API references for Cangjie developers, practical ArkTS code examples demonstrating bidirectional communication, and a technical schema for defining access control rules. The resources are essential for developers building hybrid applications on HarmonyOS who need to securely inject native methods into WebView environments and manage interaction permissions effectively.
