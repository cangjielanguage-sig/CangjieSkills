# Refresh

This directory contains comprehensive documentation and code examples for the Refresh component within the ArkUI framework, specifically designed for the Cangjie language. It covers the implementation of pull-down page operations, including API references for component structure, event handling, and property configuration. Developers will find technical guides on managing refresh states, customizing drag sensitivity, and handling lifecycle callbacks. Suitable for software developers building interactive UIs in HarmonyOS, this resource provides the necessary tools to create robust, user-friendly refresh behaviors in applications.

## Detailed Description

### Refresh_4more.md Refresh_4more.md
This document provides API reference documentation for the Refresh container component within the ArkUI framework, designed to enable pull-down page operations with refresh animations. The content details the component's structure, including its support for a single child component, and outlines the initialization method init. Key information includes the required parameters, specifically RefreshParams for configuration and a lambda function for content declaration, alongside system capability requirements starting from version 12. The document confirms full support for universal attributes and events. Intended for developers using the Cangjie language, this reference serves as a technical guide for implementing interactive refresh behaviors in application interfaces.

### 组件事件_2more.md 组件事件_2more.md
This document serves as API reference documentation for event handling and parameter configuration of a Refresh component within the ArkUI framework using the Cangjie language. It covers three primary event callback functions: onOffsetChange for tracking pull-down distance, onRefreshing for entering the refresh state, and onStateChange for monitoring status changes. Additionally, it defines the RefreshParams class, which manages the refreshing state and supports two-way data binding via the @Binder macro. Key information includes specific version requirements and the use of Float64 for offset values. This technical guide is intended for developers implementing pull-to-refresh functionality in their applications.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring pull-down refresh properties within the ArkUI framework using the Cangjie language. It details four specific functions: pullDownRatio, pullToRefresh, and two overloads of refreshOffset. Key information includes the ability to control drag sensitivity using a 0-1 coefficient, enable or disable the refresh trigger, and define the specific offset distance required to initiate a refresh, with a default of 96vp. The document specifies that invalid offset values revert to defaults. This technical reference is intended for software developers implementing custom refresh behaviors in UI components, requiring knowledge of the Cangjie syntax and ArkUI system capabilities.
