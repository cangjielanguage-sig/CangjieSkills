# 仅对MDM应用开放

This directory provides reference documentation for OpenHarmony permissions exclusively available to Mobile Device Management (MDM) applications. It details specific permissions introduced in API version 12, covering file management, enterprise device control, security policies, network configuration, and system administration. Key topics include the FILE_GUARD_MANAGER permission and various ENTERPRISE_* permissions used for elevated device management capabilities. The documents outline authorization methods like system_grant and protection levels such as system_basic and system_core. This resource is designed for system developers and enterprise application engineers who need to implement administrative policies, manage device hardware or software configurations, and enforce security restrictions on enterprise devices.

## Detailed Description

### ohospermissionFILE_GUARD__15more.md ohospermissionFILE_GUARD__15more.md
This reference document defines specific OpenHarmony permissions introduced in API version 12, focusing on file management and enterprise device control. The content details the FILE_GUARD_MANAGER permission for file scanning and attributes, alongside a comprehensive suite of ENTERPRISE_* permissions. These enterprise permissions cover security policies, connectivity (Bluetooth/WiFi), system settings, application management, and device operations like rebooting or locking. Key takeaways include that all permissions utilize the system_grant authorization method, with most classified as system_basic level, while FILE_GUARD_MANAGER and ENTERPRISE_RECOVERY_KEY are restricted to system_core. This document targets system developers and enterprise application engineers who need to implement elevated device management capabilities and security policies.
