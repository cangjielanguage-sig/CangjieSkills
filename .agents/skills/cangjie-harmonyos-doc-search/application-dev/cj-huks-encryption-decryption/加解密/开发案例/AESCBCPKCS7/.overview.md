# AESCBCPKCS7

This directory provides a comprehensive technical guide for implementing AES/CBC/PKCS7 encryption and decryption workflows using the Cangjie language on HarmonyOS. It focuses on the Universal Keystore Kit (HUKS), offering detailed code examples for managing the entire lifecycle of cryptographic keys. Key topics include generating 128-bit AES keys, configuring PKCS7 padding and CBC mode, handling Initialization Vectors (IV), and performing secure data operations. The documentation also covers essential maintenance tasks such as decrypting data and securely deleting keys from the keystore. This resource is specifically designed for HarmonyOS developers and security engineers seeking to implement standard, high-security data protection mechanisms within their applications using HUKS APIs like `generateKeyItem`, `initSession`, and `finishSession`. By following these examples, developers can ensure their applications adhere to security best practices while handling sensitive information.

## Detailed Description

The following files provide the specific implementation details for the cryptographic operations described above.

### AESCBCPKCS7_1.md

This document provides a Cangjie code example demonstrating how to implement AES/CBC/PKCS7 encryption and decryption using the Universal Keystore Kit. It covers helper functions for data conversion, property configuration for key generation and cryptographic operations, and specific functions for generating keys and encrypting data. The code utilizes HUKS (HarmonyOS Universal Keystore) APIs like generateKeyItem, initSession, and finishSession. It specifies a 128-bit AES key, PKCS7 padding, and CBC mode, highlighting the necessity of an Initialization Vector (IV). This tutorial targets HarmonyOS developers using the Cangjie language who need to integrate secure data encryption capabilities into their applications.

### AESCBCPKCS7_2.md

This document serves as a technical code example demonstrating how to perform decryption and key deletion using the HUKS framework. It covers two main functions: DecryptData, which outlines the steps to initialize a session and finish decryption using a specific key alias, and DeleteKey, which illustrates the process of removing a key item from the keystore. Key takeaways include the usage of HuksOptions for configuration and the sequence of API calls like initSession and finishSession. Intended for developers working with cryptographic operations, this guide assumes prior knowledge of key generation and basic encryption concepts.
