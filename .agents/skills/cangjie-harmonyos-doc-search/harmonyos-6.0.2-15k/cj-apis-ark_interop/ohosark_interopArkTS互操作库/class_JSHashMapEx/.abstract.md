This directory contains API reference documentation for the `JSHashMapEx` class in the Cangjie programming language. It focuses on declarative interoperability with ArkTS Map types, enabling efficient data management between Cangjie and ArkTS environments. The documentation covers class definitions, generic constraints, initialization, and various data manipulation methods including insertion, deletion, retrieval, and type conversion. It is suitable for developers working on ArkUI cross-language interoperability who need to handle hash map structures and Napi operations.
