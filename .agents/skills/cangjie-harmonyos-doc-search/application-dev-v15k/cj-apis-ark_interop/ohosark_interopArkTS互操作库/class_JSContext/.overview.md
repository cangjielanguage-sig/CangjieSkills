# class_JSContext

This directory contains API reference documentation for the `JSContext` class in the Cangjie programming language, specifically designed for HarmonyOS ArkTS interoperability. It covers the core class definition and various functions for creating and manipulating ArkTS objects, such as ArrayBuffers, BigInts, Strings, and external objects. The documentation details methods for memory management, multithreading tasks, and module loading. It is intended for Cangjie developers and system engineers building native applications who require knowledge of NAPI and cross-language data conversion within the SystemCapability.ArkUI.ArkUI.Napi framework.
