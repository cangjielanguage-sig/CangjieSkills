# 示例代码

This directory contains Cangjie code examples focused on implementing user authentication using the UserAuthenticationKit. It covers various scenarios including basic biometric (Face) and PIN authentication at specific trust levels, as well as advanced features like reusing device unlock states and cross-application authentication. The examples demonstrate how to configure authentication parameters (`AuthParam`), manage UI widgets, handle asynchronous callbacks, and manage exceptions. These resources are suitable for developers integrating secure biometric verification and credential management into their applications, providing practical implementations for handling security workflows, trust level configurations, and the complete authentication lifecycle.

## Detailed Description

### 示例代码_1.md
This document provides Cangjie code examples for implementing user authentication using the UserAuthenticationKit. It covers three scenarios: basic Face and PIN authentication at Trust Level ATL3, authentication with device unlock reuse, and cross-application authentication reuse. The examples illustrate setting AuthParam and WidgetParam, obtaining userAuthInstance, subscribing to result callbacks via event listeners, and handling exceptions. Targeted at developers integrating secure biometric or credential verification, focusing on AuthTrustLevel and ReuseUnlockResult configurations.

### 示例代码_2.md
This document provides a code example demonstrating the implementation of user authentication, specifically using facial recognition. It covers setting authentication parameters, generating random challenges, configuring the user interface widget, obtaining the authentication instance, and subscribing to result callbacks. Key takeaways include the configuration of AuthParam for trust levels and UserAuthType.FACE, alongside error handling mechanisms. The snippet illustrates the complete lifecycle from instance creation to initiating the auth process. This is intended for developers integrating biometric security features into applications, requiring knowledge of asynchronous event handling and security parameters.
