# 开发步骤

This directory provides comprehensive technical tutorials focused on the specific development steps required to utilize the HarmonyOS Universal Keystore Kit (HUKS) with the Cangjie programming language. It specifically addresses the procedures for importing cryptographic keys into the secure keystore environment. The documentation covers essential concepts such as defining key materials, configuring key properties—including algorithm type, key size, purpose, and import type—and invoking the necessary APIs for key execution. Topics include handling X25519 public keys and AES256 keys. This content is designed for HarmonyOS developers and security engineers seeking to implement robust key management and cryptographic verification features in their applications. By following these guides, developers can ensure secure integration of external keys for encryption, decryption, and signature verification.

## Detailed Description

### 导入X25519密钥公钥.md 导入X25519密钥公钥.md
This document serves as a code tutorial demonstrating how to import an X25519 public key using the Cangjie programming language and the Universal Keystore Kit. It covers the essential steps of defining the 32-byte key material, specifying the key alias, and configuring key properties such as algorithm type, key size, purpose, and import type. Key takeaways include the use of HuksParam to set attributes like HUKS_ALG_X25519 and HUKS_KEY_TYPE_PUBLIC_KEY, followed by invoking the importKeyItem function to execute the import. This guide is intended for developers implementing cryptographic key management, specifically those needing to integrate external X25519 public keys for verification purposes.

### 开发步骤_2more.md 开发步骤_2more.md
This technical tutorial guides developers through the process of importing keys into the HarmonyOS Universal Keystore Kit (HUKS). The content outlines three essential steps: specifying a key alias, encapsulating key properties and materials, and invoking the importKeyItem API. Key information includes requirements for key attributes like HuksKeyAlg and HuksKeySize, along with a Cangjie code example demonstrating the import of an AES256 key. This guide is intended for HarmonyOS developers implementing secure key management, requiring knowledge of cryptographic concepts and the Cangjie programming language.
