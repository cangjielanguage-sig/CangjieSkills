This directory provides comprehensive API reference documentation for the `JSArrayBuffer` class within the Cangjie programming language, specifically tailored for the ArkUI NAPI framework. It covers the representation and manipulation of generic raw binary data buffers. Key topics include the class definition, the read-only `byteLength` property, and various data conversion methods. The documentation details how to read raw bytes into Cangjie arrays and convert buffers into specific typed arrays such as Int32, Float32, or Float64. Furthermore, it explains how to return these structures as JSValue objects to ensure seamless interoperability with ArkTS. This resource is essential for Cangjie developers building HarmonyOS applications who require efficient binary data handling and robust interaction between Cangjie and JavaScript environments.
