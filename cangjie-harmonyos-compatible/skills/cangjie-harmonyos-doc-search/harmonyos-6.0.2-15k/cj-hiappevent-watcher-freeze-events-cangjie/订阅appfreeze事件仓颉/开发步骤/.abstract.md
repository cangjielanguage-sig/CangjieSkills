This directory serves as a specialized resource for HarmonyOS developers aiming to enhance application stability through advanced event monitoring. It details the process of subscribing to system-level application freeze events using the Cangjie language, leveraging the powerful HiAppEvent framework. The documentation covers a complete workflow, including project initialization, configuration of event watchers and filters, and the creation of trigger mechanisms using ArkTS. Additionally, it provides reference materials for interpreting the resulting logs to identify root causes of performance issues. This guide is essential for software engineers and QA professionals working within the HarmonyOS environment who need to diagnose ANRs, monitor main thread blocks, and analyze resource usage metrics to maintain high application performance standards.
