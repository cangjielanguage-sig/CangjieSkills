# 组件获焦能力说明

本目录详细说明了ArkUI框架中各类组件的获焦能力及`focusable`属性的默认值。内容涵盖基础组件、容器组件及媒体组件的交互状态，旨在帮助开发者理解组件的默认交互行为。文档适用于需要进行键盘导航、无障碍访问设计或精细焦点控制的UI开发者，为界面交互设计提供权威参考。

- 你想了解容器组件（如List、Grid）和媒体组件的获焦规则吗？ → 组件获焦能力说明_2.md

## 详细描述

### 组件获焦能力说明_1.md
本文档旨在说明各基础组件的获焦能力及其focusable属性的默认值，为开发者提供组件交互特性的参考。文档主要包含基础组件获焦能力列表，详细列出了AlphabetIndexer、Button、Checkbox、TextInput等多种组件的交互状态。关键信息在于区分组件是否具备获焦能力，并明确标注了focusable属性的默认布尔值，帮助开发者理解组件的默认交互行为。这是一份面向UI开发者的参考文档，适用于需要处理键盘导航或无障碍访问的应用开发场景。

### 组件获焦能力说明_2.md
本文档旨在说明ArkUI框架中各容器组件和媒体组件的获焦能力及其默认属性值。文档主要分为容器组件和媒体组件两个部分，详细列出了包括Column、Flex、Grid、List、Scroll、Swiper等在内的多种组件。关键信息指出，除Badge和RelativeContainer外，绝大多数容器组件默认均可获焦且focusable属性为true，Video组件同样默认支持获焦。该参考文档面向ArkUI开发者，用于辅助界面交互设计及焦点控制逻辑的实现。
