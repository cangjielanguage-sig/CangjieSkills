This directory contains a technical demonstration focused on the critical infrastructure task of performing hot updates for TLS certificates using the Cangjie programming language. In modern network security, the ability to rotate certificates without service interruption is essential for maintaining compliance and operational security. This directory provides a practical guide on how to achieve this by managing a `TlsServerConfig` object within a custom server implementation. It specifically addresses the challenge of applying new cryptographic credentials to incoming traffic while preserving the integrity and stability of ongoing sessions. The content is designed for developers and system engineers who are building secure, high-availability network servers in Cangjie. It covers essential topics such as socket programming, the lifecycle of TLS connections, and the specific syntax required for mutable configuration properties. By studying this example, users will learn how to implement a robust `MyServer` class that handles certificate updates seamlessly, ensuring that their applications remain secure and operational during maintenance windows. Keywords include Cangjie, TLS, hot update, certificate, TlsServerConfig, and socket programming.
