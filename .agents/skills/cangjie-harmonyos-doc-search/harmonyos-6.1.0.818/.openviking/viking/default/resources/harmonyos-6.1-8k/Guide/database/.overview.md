# database

This directory serves as a comprehensive technical resource for the ArkData module on the OpenHarmony platform. It covers the full spectrum of data management, including standardized data definitions (UTD), various persistence mechanisms (Preferences, KV-Store, RelationalStore), cross-device synchronization, and data security (encryption, backup, access control). Designed for application developers, it provides guidance on selecting the right storage solutions, implementing distributed data consistency, and ensuring data reliability. Whether dealing with lightweight configuration or complex relational data, this documentation addresses the needs of developers building robust, secure, and high-performance applications.

## Detailed Description

### [1] README_zh
This directory is the Chinese navigation index for the ArkData module, aiming to provide a comprehensive entry point for data management functionality documentation for application developers. The documentation covers standardized data definitions (UTD), various data persistence schemes (Preferences, Key-Value databases, Relational databases), cross-device data synchronization for the same application, and data reliability and security (backup and recovery, encryption, access control). All features are currently Beta, suitable for developers requiring data storage, synchronization, and security management to consult as a directory for ArkData-related development guides.

### [2] cj-access-control-by-device-and-data-level
This directory provides a comprehensive guide to implementing access control mechanisms within distributed data management systems, specifically focusing on the intersection of device classification and data classification. It addresses the complexities of securing data in a distributed environment by defining how different device levels interact with data classification policies to ensure that sensitive information is only accessible to authorized devices under specific conditions.

### [3] cj-app-data-persistence-overview
This directory focuses on application data persistence mechanisms under the OpenHarmony standard system, aiming to guide developers in persisting in-memory data to the device. Content covers three core data storage forms: User Preferences for lightweight configuration, Key-Value Database (KV-Store) for distributed scenarios and simple business data, and RelationalStore supporting complex queries and custom SQL. By comparing the characteristics and applicable scenarios of each form, the document helps developers make the best choice based on specific business needs. This is a conceptual guide for OpenHarmony application developers.

### [4] cj-data-backup-and-restore
This directory serves as a comprehensive technical resource dedicated to the critical subjects of database backup and recovery.
