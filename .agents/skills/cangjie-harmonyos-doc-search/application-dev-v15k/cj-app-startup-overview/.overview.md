# cj-app-startup-overview

This directory serves as a comprehensive technical resource designed to assist developers in transitioning from the deprecated explicit Want method to the modern, link-based application startup mechanism. It provides a detailed conceptual overview of how to launch specific applications securely and efficiently within the development environment. The content primarily focuses on the critical distinctions between Deep Linking and App Linking, emphasizing the substantial security advantages of the latter, such as the implementation of HTTPS schemes and rigorous domain verification processes. Additionally, the documentation covers the operational behavior of the `openLink` interface across a variety of different scenarios and conditions. This guide is essential for developers working on cross-app navigation and those utilizing `UIAbility` components who need to implement robust, secure, and efficient application startup flows using URL schemes. By mastering these concepts, developers can ensure their applications adhere to current best practices for security and usability.

## Detailed Description

The following file provides the core technical documentation for understanding and implementing the new application startup standards. It serves as a definitive guide for navigating the changes in how applications are invoked and linked.

### cj-app-startup-overview.md cj-app-startup-overview.md
This document provides a comprehensive overview of launching specific applications using application links, effectively replacing the deprecated explicit Want method. It covers the definition and mechanism of application links, clearly distinguishing between Deep Linking and App Linking. Key takeaways include the strong recommendation to use App Linking for its HTTPS scheme and domain verification, which offers significantly higher security compared to the customizable but often vulnerable Deep Linking. The document also explains the behavior of the openLink interface under various conditions. Targeted at developers needing to implement cross-app navigation, this guide serves as a conceptual reference for adapting to the new link-based startup mechanism.
