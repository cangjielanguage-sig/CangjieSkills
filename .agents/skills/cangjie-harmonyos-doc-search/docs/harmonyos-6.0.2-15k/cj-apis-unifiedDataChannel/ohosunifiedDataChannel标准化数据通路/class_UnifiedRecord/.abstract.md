This directory contains essential API reference documentation for the UnifiedRecord class and its associated functions within the Unified Data Management Framework (UDMF). It serves as a technical guide for understanding the abstract definition of data content, covering initialization methods, type identification, and value retrieval mechanisms. Key topics include the structural overview of the UnifiedRecord class, specific constraints for creating records with complex types like PixelMap or Want, and the implementation of the getValue function for accessing record data. This documentation is specifically suitable for Cangjie and HarmonyOS developers utilizing the ArkData kit to implement distributed data management capabilities in their applications. By mastering these components, developers can effectively manage and manipulate unified data objects across distributed environments.
