This directory contains API reference documentation and practical examples for configuring component dimensions and layout spacing within the ArkUI framework using the Cangjie language. It covers essential properties such as width, height, padding, margin, constraintSize, and layoutWeight. The content explains how to define size boundaries, manage outer spacing, and distribute space flexibly within parent containers. It is suitable for Cangjie developers and UI designers building HarmonyOS applications who need precise control over component geometry and responsive layout mechanics.
