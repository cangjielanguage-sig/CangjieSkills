This directory contains technical documentation designed to assist in diagnosing application main thread freezes, commonly referred to as AppFreeze. The content focuses on analyzing specific system logs, particularly `THREAD_BLOCK_6S` and `THREAD_BLOCK_3S` events, to identify the root causes of application unresponsiveness. It covers essential techniques such as comparing different log types to distinguish between system overload and specific code blockages, interpreting event queue statuses, and analyzing stack traces within environments like ArkUI and JS runtime. These guides are crucial for understanding how to pinpoint performance bottlenecks, inter-process communication issues, or memory leaks. The material is highly technical and is best suited for system developers, engineers, and debuggers who possess a solid understanding of thread management and log analysis tools.
