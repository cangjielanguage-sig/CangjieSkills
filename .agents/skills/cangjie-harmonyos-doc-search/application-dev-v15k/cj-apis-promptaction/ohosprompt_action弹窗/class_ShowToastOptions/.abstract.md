This directory serves as a central repository for API reference documentation regarding the `ShowToastOptions` class, specifically tailored for the Cangjie language and ArkUI framework. It provides essential technical details for configuring text prompt boxes, commonly known as toasts, within application user interfaces. The scope of documentation includes a deep dive into various configuration parameters such as message content, display duration, alignment, offset, and complex visual styling options like background colors, text colors, blur effects, and shadows. Furthermore, it addresses interaction settings including hover mode and display area constraints. This collection of documents is highly suitable for software developers and UI engineers who are tasked with implementing and customizing transient notification popups, ensuring they are both visually appealing and functionally robust according to ArkUI standards.
