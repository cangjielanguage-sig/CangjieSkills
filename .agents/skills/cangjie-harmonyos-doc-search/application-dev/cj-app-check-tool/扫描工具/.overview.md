# 扫描工具

This directory provides comprehensive technical documentation for the `app_check_tool.jar`, a specialized utility designed to analyze HarmonyOS application packages, including HAP, HSP, and App formats. It covers critical aspects of package structure optimization, such as identifying duplicate files, detecting oversized files, and analyzing file size distribution by type. The documentation details command-line parameters, JSON output structures, and system constraints like the Java 8 requirement. It is intended for application developers and build engineers seeking to perform data-driven troubleshooting, audit package contents, and optimize storage usage within their applications.
