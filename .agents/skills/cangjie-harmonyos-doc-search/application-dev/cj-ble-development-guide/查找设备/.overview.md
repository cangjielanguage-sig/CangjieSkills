# 查找设备

This directory focuses on Bluetooth Low Energy (BLE) device discovery and connectivity within the OpenHarmony ecosystem. It covers essential operations such as BLE scanning, advertising, and broadcast management using the Cangjie language and ConnectivityKit. The resources include development guides, API usage instructions, and links to sample code repositories. It is suitable for software engineers and developers looking to implement device visibility, parse advertising packets, and manage communication lifecycles in HarmonyOS applications.

## Detailed Description

### 查找设备_5more.md 查找设备_5more.md
This guide provides development instructions for Bluetooth Low Energy (BLE) scanning and advertising operations using Cangjie APIs. It covers essential steps like applying for the ohos.permission.ACCESS_BLUETOOTH permission and outlines scenarios for starting and stopping scans and advertisements. The document details key interfaces such as startBleScanning, stopBleScanning, startAdvertising, and stopAdvertising, alongside methods for subscribing to device discovery events and status updates. Targeting developers working with the ConnectivityKit, this tutorial enables the implementation of scenarios where devices discover nearby BLE peripherals or broadcast their own presence.

### 示例代码.md 示例代码.md
This document functions as a navigational resource or index for OpenHarmony development samples. Its primary purpose is to direct users to specific example code hosted on an external GitCode repository. The main topic covered is the implementation of broadcast functionality, specifically focusing on enabling and disabling broadcasts within the Cangjie programming language environment. Key information includes the direct link to the BasicFeature Connectivity Broadcast directory, which contains the source code. This document is intended for OpenHarmony developers or students looking for practical references to understand connectivity features. It serves as a gateway to hands-on learning materials rather than a standalone tutorial.

### 主要场景开发步骤/
This directory serves as a comprehensive technical resource for developers implementing core Bluetooth Low Energy (BLE) scenarios within the HarmonyOS and OpenHarmony ecosystems. It focuses on essential connectivity workflows, specifically the management of advertising broadcasts and the execution of device scanning operations. The content covers technical implementation using the Cangjie language and ArkTS, addressing key tasks such as parameter configuration, data construction, lifecycle management, and the parsing of raw advertising packets. Designed for software engineers working with the ConnectivityKit, these guides provide the necessary code examples and architectural guidance to build robust device discovery and communication features. By following these steps, developers can effectively manage device visibility and interpret incoming data signals.
