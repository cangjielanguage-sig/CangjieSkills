### USER_ROTATION_PORTRAIT

```cangjie
USER_ROTATION_PORTRAIT
```

**功能：** 调用时临时旋转到竖屏，之后跟随传感器自动旋转，受控制中心的旋转开关控制，且可旋转方向受系统判定。

**系统能力：** SystemCapability.WindowManager.WindowManager.Core

**起始版本：** 19
