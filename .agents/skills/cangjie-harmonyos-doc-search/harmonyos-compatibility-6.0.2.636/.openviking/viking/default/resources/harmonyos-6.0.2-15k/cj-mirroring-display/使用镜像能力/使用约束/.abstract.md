This directory provides comprehensive technical documentation regarding usage constraints within the ArkUI framework, specifically focusing on UI adaptation and mirroring capabilities for internationalization. It covers the handling of right-to-left (RTL) language support, automatic layout adjustments, and specific component behaviors. The content includes reference indices for basic and advanced UI components, universal attributes, and detailed guidelines for implementing mirroring in layouts, Canvas, and XComponent. It is suitable for software developers and UI designers seeking to ensure compatibility and proper localization in their applications.
