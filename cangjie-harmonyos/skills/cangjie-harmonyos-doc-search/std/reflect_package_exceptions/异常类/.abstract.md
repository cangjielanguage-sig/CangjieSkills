This directory contains comprehensive API reference documentation for exception classes within the Cangjie reflection package. It covers a range of specific runtime errors, including IllegalSetException, MisMatchException, and their parent class ReflectException. The documents detail class inheritance hierarchies, available constructors, and specific usage scenarios for handling errors during reflective operations. This resource is essential for Cangjie developers implementing reflection mechanisms who need to understand error types, instantiation patterns, and robust exception handling strategies.
