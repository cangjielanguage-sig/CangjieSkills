# cj-application-models

本目录主要聚焦于系统应用模型的架构设计，特别是Stage模型的核心概念与实现细节。内容全面覆盖了应用模型的五大构成要素：应用组件、进程模型、线程模型、任务管理模型以及配置文件。文档深入剖析了Stage模型作为长期演进方向的特性，包括其面向对象的开发方式、UIAbility与ExtensionAbility组件的分类，以及基于app.json5和module.json5的配置规范。此外，还详细阐述了UIAbility实例与独立任务的对应关系。该资料非常适合应用开发者阅读，旨在帮助开发者构建清晰的应用架构认知，深入理解组件生命周期及底层运行机制，从而高效地进行应用开发。通过掌握这些核心概念，开发者可以更好地适应系统演进，优化应用性能与用户体验。
