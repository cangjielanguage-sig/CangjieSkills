# 资源分类与访问

This directory provides comprehensive documentation on managing, classifying, and accessing resources in HarmonyOS development using the Cangjie language. It covers the creation of resource files, the distinction between application and system resources, and the logic for matching resources to specific device configurations. Key topics include resource qualifiers, resource groups, internationalization, and programmatic access methods. Designed for application developers and system architects, these guides help ensure efficient asset organization and consistent UI adaptation across various devices and themes.

## Detailed Description

### 创建资源目录和资源文件_2more.md 创建资源目录和资源文件_2more.md
This technical guide instructs developers on creating and managing resource directories and files within DevEco Studio. It details three specific workflows: creating directories and files simultaneously, creating directories alone, and creating files individually, while explaining naming conventions like qualifier.resourcegroup. Additionally, the document covers the resource translatable feature, explaining how to use the attr property in JSON to define translation scope and status for strings, strarrays, and plurals. Key concepts include resource qualifiers, resource groups, and translation attributes like translatable and priority. This guide is intended for application developers organizing project resources and localization.

### 资源分类与访问.md 资源分类与访问.md
This document serves as a conceptual guide explaining the classification and access of resources in application development. It primarily covers two main categories: Application Resources and System Resources. The key information highlights that Application Resources allow developers to define and manage custom values for different devices or configurations, while System Resources provide pre-built definitions that automatically adapt to device types and themes like dark or light mode using layered parameters. Intended for application developers, this guide provides foundational knowledge for effectively managing UI elements such as colors, fonts, and images across various environments. Keywords: resource classification, application resources, system resources, UI adaptation, configuration management.

### 资源匹配_2more.md 资源匹配_2more.md
This technical reference guide details the system logic for matching application resources based on current device states. It covers the priority hierarchy of qualifier directories, ranging from mobile country codes to screen density, and explains the fallback mechanism to the base directory. Key takeaways include the strict matching requirement for specific qualifiers and the exclusion of rawfile from this process. Additionally, the document specifies naming restrictions, prohibiting the use of Cangjie language reserved keywords like func and main. This information is essential for developers optimizing applications for diverse device configurations and internationalization.

### 资源访问.md 资源访问.md
This technical guide explains how to access and reference application and system resources within the HarmonyOS development environment using the Cangjie language. It details the syntax for accessing application resources via the `@r(app.type.name)` format, including strings with placeholders, plural resources, and media files, as well as referencing rawfile directory assets using `@rawfile`. Additionally, it covers accessing system resources like colors and fonts using `@r(sys.type.resource_id)` to ensure consistent UI design. Key takeaways include understanding resource ID mapping in `cj_res_entry` and specific syntax rules for file paths. The document targets HarmonyOS developers building UI components, providing code examples for practical implementation.

### 资源分类/
This directory provides a comprehensive guide to organizing and managing application resources within the development framework. It covers the structural hierarchy of resource directories, including base and qualifier directories for device adaptation, as well as specific resource groups like element, media, and profile. The documentation details naming conventions, file formats, and the handling of raw files. It is designed for developers and system architects who need to efficiently categorize assets, implement internationalization strategies, and ensure compatibility across diverse devices in the HarmonyOS ecosystem.
