# 自定义渲染XComponent

This directory focuses on the XComponent component within the HarmonyOS ecosystem, specifically designed for complex custom rendering scenarios such as camera previews and game graphics. It covers the integration of the Cangjie language with Native C++ graphics processing using EGL and OpenGLES. Key topics include the self-drawing principle, NativeWindow buffer submission, XComponentController lifecycle management, and surface positioning. This resource is suitable for HarmonyOS developers and C++ programmers looking to bridge Cangjie UI logic with high-performance native graphics capabilities.

## Detailed Description

### 概述_4more.md
This document provides a technical overview of the XComponent component, designed for complex custom rendering scenarios like camera previews and game graphics using EGL/OpenGLES. It explains the self-drawing principle where developers use NativeWindow to submit buffers to a surface managed by XComponent. Key sections cover the XComponentController scenario, detailing how the Cangjie side handles lifecycle and input events while passing the SurfaceId to the Native side for rendering. The guide also addresses surface positioning and transparency compositing. Intended for developers using the Cangjie language, it bridges UI integration with high-performance native graphics processing.

### 示例代码/
This directory provides a comprehensive collection of example code demonstrating the integration of the Cangjie language with high-performance Native C++ graphics rendering on the HarmonyOS platform. It focuses on the practical implementation of the XComponent component, Foreign Function Interface (FFI) declarations, and the management of EGL and OpenGL ES 3.0 environments. The examples illustrate how to bridge Cangjie UI logic with C++ backend processing to manage rendering surfaces, handle lifecycle callbacks, and execute complex geometric drawing operations. This resource is specifically suitable for HarmonyOS developers and C++ programmers aiming to combine Cangjie application interfaces with native graphics capabilities for advanced visual applications.
