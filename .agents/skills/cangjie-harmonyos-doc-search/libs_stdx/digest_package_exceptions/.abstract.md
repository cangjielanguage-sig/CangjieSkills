This directory serves as a specialized documentation resource for exception handling within the digest package, specifically designed for developers utilizing the Cangjie programming language. It focuses exclusively on the `CryptoException` class, which is the primary mechanism for managing runtime errors that arise during digest and cryptographic operations. The documentation provides a deep dive into the class's architecture, detailing its inheritance from the base Exception type and outlining the specific functionality of its two public constructors. By explaining how to initialize exceptions with or without custom error messages, this guide enables the creation of more secure and stable software. This resource is highly suitable for backend developers, security engineers, and system architects who are integrating cryptographic features into Cangjie applications and need to ensure that error states are handled gracefully and predictably.
