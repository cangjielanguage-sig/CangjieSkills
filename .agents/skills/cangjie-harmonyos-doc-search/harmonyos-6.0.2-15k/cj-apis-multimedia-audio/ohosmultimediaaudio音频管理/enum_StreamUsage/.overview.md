# enum_StreamUsage

This directory contains essential API reference documentation for the `StreamUsage` enum in the Cangjie programming language, specifically designed to categorize and manage multimedia audio stream usage types. It covers a wide range of specific enum values, including Music, Voice Communication, Alarm, Ringtone, and Navigation, as well as utility functions for comparing and converting these values. Key technical details include the required system capability `SystemCapability.Multimedia.Audio.Core`, version 19 compatibility, and inheritance from `Equatable` and `ToString`. This documentation is suitable for Cangjie developers and audio engineers integrating multimedia features, enabling precise audio stream management for various scenarios such as immersive games, movies, and critical accessibility services. Understanding these definitions is crucial for ensuring correct audio behavior and user experience in Cangjie-based applications.
