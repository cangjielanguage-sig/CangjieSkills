# class_Icons

This directory contains comprehensive API reference documentation for the Cangjie `Icons` class, a critical component designed to manage icon types for sidebar control buttons within ArkUI applications. The documentation covers a wide array of constructor overloads that handle various combinations of `String` and `AppResource` types for shown, hidden, and switching states. Key topics include initialization methods, mandatory versus optional parameter requirements, and system resource fallback mechanisms. This documentation is primarily suitable for ArkUI developers working with the Cangjie language who need to implement dynamic UI state changes and manage icon resources effectively in version 19 environments. It provides the necessary technical details to ensure robust icon handling, error management, and visual consistency in graphical user interfaces, ensuring that developers can handle resource loading failures gracefully and maintain a seamless user experience.

## Detailed Description

The following files provide specific API details for the Icons class, covering constructor definitions and initialization logic essential for building responsive UI components.

### class_Icons_5more.md
This document serves as API reference documentation for the Cangjie Icons class, designed to manage icon types for sidebar control buttons. It details eight overloaded constructors that accept combinations of String and AppResource types for the shown, hidden, and switching states. Key takeaways include the mandatory nature of shown and hidden parameters, the optional switching parameter with a default empty string, and the system's fallback to default icons if resource acquisition fails. This guide targets ArkUI developers implementing dynamic UI state changes in version 19 environments.

### initString_AppResource_Str_4more.md

The content details the init methods, specifically defining parameters for shown, hidden, and switching states, which accept combinations of String and AppResource types. Key takeaways include the requirement for named parameters, the optional nature of the switching parameter in some overloads, and the fallback to default icons upon resource retrieval errors. Targeted at ArkUI developers, this reference requires knowledge of the Cangjie language and resource management.
