This directory contains comprehensive documentation and resources for the AlertDialog component within the Cangjie language and ArkUI framework. It covers the implementation, configuration, and customization of warning popups, including button layouts, parameter classes, and styling options. Key topics include the `DialogButtonDirection` enum, various `AlertDialogParam` classes for different button configurations, and practical code examples. This resource is suitable for Cangjie developers and UI engineers working on HarmonyOS applications who need to implement interactive modal windows and user notifications.
