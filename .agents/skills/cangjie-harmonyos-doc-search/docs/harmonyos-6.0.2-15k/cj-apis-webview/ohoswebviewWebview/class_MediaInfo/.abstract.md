This directory contains comprehensive API reference documentation for the `MediaInfo` class within the Cangjie programming language. It focuses on the data structure used to transfer web media information from a webview environment to native applications, facilitating the creation of custom media players. Key topics include the class constructor, initialization parameters, and property mappings to HTML5 video and audio attributes. It covers essential configurations such as media sources, surface rendering, HTTP headers, and playback settings like muted and preload. This documentation is intended for developers working with the SystemCapability.Web.Webview.Core system who need to integrate native media playback capabilities with web components.
