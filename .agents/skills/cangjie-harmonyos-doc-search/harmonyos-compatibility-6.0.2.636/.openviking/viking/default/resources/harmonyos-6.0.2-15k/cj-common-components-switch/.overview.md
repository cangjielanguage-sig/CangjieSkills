# cj-common-components-switch

This directory contains the essential documentation for the `cj-common-components-switch` module, specifically focusing on the Toggle component within the Cangjie UI framework. It acts as a definitive guide for developers aiming to implement binary state switches effectively. The content covers the full lifecycle of component usage, from creation via the Toggle interface to advanced style customization using properties such as `selectedColor` and `switchPointColor`. It also provides detailed instructions on event handling using the `onChange` callback. The guide distinguishes between three distinct toggle types—ButtonType, CheckboxType, and SwitchType—explaining the nuances of instantiating them with or without child components. Included is a practical code example demonstrating a Bluetooth toggle with toast notifications. This resource is tailored for Cangjie developers who have a foundational knowledge of UI component syntax and event binding.
