# 网页中安全区域计算和避让适配

This directory focuses on the critical technical aspects of calculating safe areas and implementing avoidance adaptations for web components in HarmonyOS development. It provides a deep dive into the mechanisms required to handle immersive modes, ensuring that web content remains visible and unobstructed by system UI elements such as status bars and navigation bars. The documentation covers the distinction between safe and non-safe areas, the use of the ArkWeb kernel for position monitoring, and specific implementation strategies using CSS environment variables and meta tags. This resource is specifically designed for web developers and UI/UX engineers who need to optimize layouts for devices with non-rectangular screens or those utilizing full-screen immersive effects, ensuring a seamless user experience free from layout conflicts.

## Detailed Description

### 实现场景.md 实现场景.md
This technical guide explains how to implement immersive effects for Web components in HarmonyOS development. It covers enabling immersive mode using the expandSafeArea API, configuring viewport behavior via the viewport-fit meta tag, and managing web element layout using CSS env() functions. Key information includes the necessity of setting viewport-fit=cover to allow content into non-safe areas and using safe-area-inset-* variables to prevent content overlap with system bars. The document provides code examples in Cangjie and HTML/CSS, targeting developers seeking to optimize web layout for devices with non-rectangular screens or system UI overlays.

### 概述.md 概述.md
This document provides an overview of safe area definitions and adaptation mechanisms for Web components operating in immersive mode. It covers the distinction between safe and non-safe areas, the potential overlap issues with system UI elements like status bars, and the W3C CSS-based solution for layout adaptation. Key information includes how the ArkWeb kernel monitors component positions and calculates necessary avoidance distances to support irregular screen displays. This guide is intended for web developers seeking to resolve layout conflicts and ensure proper content visibility in immersive environments.
