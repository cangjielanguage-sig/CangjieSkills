# 关系型数据库跨设备数据同步

This directory provides comprehensive technical documentation for implementing cross-device synchronization of relational databases, specifically tailored for the HarmonyOS ecosystem. It details the architecture and operational mechanisms required to maintain data consistency across multiple devices, utilizing distributed tables and secure encrypted channels. The content covers essential concepts such as push and pull synchronization modes, data change notifications, and system constraints regarding database connections and security levels. It includes specific API references like setDistributedTables, sync, and onDataChange. This resource is primarily designed for application developers using the Cangjie language who need to integrate robust distributed data features into their applications, ensuring seamless and secure data interaction between user devices while adhering to strict security protocols.

## Detailed Description

### 场景介绍_5more.md
This document outlines the implementation of cross-device synchronization for relational databases, enabling applications to maintain data consistency across multiple devices. Key sections include basic concepts of distributed tables, the operating mechanism using encrypted channels, data change notifications, and system constraints. It details the API functions setDistributedTables, sync, and onDataChange for managing data flow and subscriptions. Important takeaways involve push/pull synchronization modes and limitations on database connections and table keys. Intended for application developers, this guide provides the necessary technical specifications and interface descriptions to build distributed data features.

### 开发步骤.md
This document serves as a step-by-step tutorial for developers implementing distributed relational database synchronization using the Cangjie language. It covers five main stages: importing necessary modules, requesting the DISTRIBUTED_DATASYNC permission, creating a database with distributed table configuration, triggering data synchronization via SYNC_MODE_PUSH, and setting up remote data change subscriptions. Key takeaways include the security constraint that data only syncs to devices with equal or higher security levels and the use of specific APIs like setDistributedTables and onDataChange. This guide targets application developers building cross-device data features within the HarmonyOS ecosystem.
