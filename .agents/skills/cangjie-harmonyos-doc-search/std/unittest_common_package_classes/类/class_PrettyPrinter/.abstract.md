This directory provides comprehensive API reference documentation for the Cangjie `PrettyPrinter` class, a utility designed for sophisticated formatted console output. It covers a wide range of features including color management, text alignment (left, right, center), indentation control, and string appending mechanisms. The documentation highlights the class's ability to handle both raw strings and objects implementing the `PrettyPrintable` interface, with a focus on method chaining for fluent code construction. This resource is essential for Cangjie developers, particularly those building testing frameworks or command-line tools that require structured, readable, and aesthetically pleasing text output.
