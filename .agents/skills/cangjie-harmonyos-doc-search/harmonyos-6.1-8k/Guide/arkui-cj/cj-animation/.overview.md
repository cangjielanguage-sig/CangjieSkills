# cj-animation

本目录专注于ArkUI框架下的动画机制与实现指南，旨在为开发者提供全面的动画开发参考。内容涵盖了属性动画、转场动画、组件动画、动画曲线设置、动画衔接、高阶效果及帧动画等核心主题。文档深入解析了通过帧率和曲线控制属性值变化的原理，并详细区分了系统驱动与开发者驱动的实现差异。通过学习这些内容，开发者可以利用动画接口为UI变化添加流畅过渡，从而显著增强应用的交互反馈并有效引导用户操作。该资源适合ArkUI应用开发者阅读，作为快速掌握各类动画使用方法及注意事项的学习手册。

## Detailed Description

### cj-animation.md

本文档旨在概述ArkUI中的动画机制，指导开发者利用动画接口为UI变化添加流畅过渡。主要涵盖属性动画、转场动画、组件动画、动画曲线、动画衔接、高阶效果及帧动画等内容。重点介绍了动画通过帧率和曲线控制属性值变化的原理，强调了动画在增强交互反馈和引导用户方面的作用，并区分了系统驱动与开发者驱动的实现差异。该文档面向ArkUI应用开发者，作为动画开发的学习指南，帮助其快速掌握各类动画的使用方法和注意事项。
