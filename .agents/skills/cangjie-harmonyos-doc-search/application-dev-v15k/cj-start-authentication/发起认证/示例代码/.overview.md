# 示例代码

This directory serves as a comprehensive collection of Cangjie code examples designed to assist developers in implementing robust user authentication mechanisms using the UserAuthenticationKit. The content covers a wide range of security scenarios, including basic Face and PIN authentication at Trust Level ATL3, as well as advanced methods like device unlock reuse and arbitrary app reuse. Key technical concepts demonstrated include the configuration of `AuthParam` and `WidgetParam`, instance acquisition, event listener subscription, and asynchronous error handling. These examples are specifically tailored for developers looking to integrate secure identity verification and biometric features into their applications, offering practical guidance on managing security APIs and authentication workflows effectively. By following these code structures, developers can ensure their applications meet high security standards while providing a smooth user experience.

## Detailed Description

The following files provide specific code implementations and technical details for the authentication scenarios mentioned above.

### 示例代码_1.md 示例代码_1.md
This document provides Cangjie code examples demonstrating how to implement user authentication using the UserAuthenticationKit. It covers three specific scenarios: basic Face and PIN authentication at Trust Level ATL3, authentication utilizing device unlock reuse, and authentication with arbitrary app reuse. Key information includes the setup of `AuthParam` and `WidgetParam`, obtaining a `userAuthInstance`, subscribing to result callbacks via event listeners, and error handling. The examples illustrate the workflow from parameter configuration to starting the authentication process. This technical reference is intended for developers integrating secure identity verification features into their applications.

### 示例代码_2.md 示例代码_2.md
This document provides a code example demonstrating the implementation of user authentication, specifically utilizing facial recognition. It covers the configuration of authentication parameters including random number generation and trust levels, UI widget setup, instance acquisition, and result subscription. Key information includes the use of AuthParam for security settings, WidgetParam for UI text, and event listeners for handling UserAuthResult. The snippet also details error handling via a try-catch block. This content targets developers integrating biometric authentication into applications, requiring knowledge of asynchronous programming and security APIs.
