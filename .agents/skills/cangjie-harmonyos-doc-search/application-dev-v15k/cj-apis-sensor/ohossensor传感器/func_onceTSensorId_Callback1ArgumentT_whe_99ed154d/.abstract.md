This directory provides in-depth API documentation for the `once` function in the Cangjie programming language, a critical component for developers building applications on the HarmonyOS platform. It specifically addresses the asynchronous retrieval of a single instance of sensor data, offering a detailed breakdown of the function signature, system capabilities, and required parameters. The documentation is particularly notable for its comprehensive table, which maps supported sensor types to their corresponding response data types and outlines the specific permissions needed for access, such as those for Accelerometers or Heart Rate monitors. Key technical elements discussed include the generic constraint `T <: Response`, the critical nature of permission management for hardware access, and error handling via `BusinessException`. This resource is ideally suited for HarmonyOS developers utilizing the Cangjie framework who need to integrate hardware sensors, demanding a solid understanding of asynchronous callbacks, generic type constraints, and the security protocols involved in permission management.
