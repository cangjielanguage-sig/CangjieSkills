## 详细描述

### 使用SM4对称密钥GCM模式分段加_2more_3d965eeb.md
本文档是一份技术教程，旨在指导开发者使用SM4对称密钥的GCM模式进行分段加解密。文档详细描述了加密流程，包括生成128位SM4密钥、创建指定参数的Cipher实例、初始化加密模式及GCM参数。核心内容重点讲解了如何通过多次调用update方法分段处理数据，并强调了不同加密模式下update结果的拼接逻辑及空数组判断。最后，文档说明了调用doFinal完成加密并提取16字节authTag作为解密认证信息的重要性。本文面向熟悉CryptoArchitectureKit及对称加密概念的开发者，关键词包括SM4、GCM、分段加密、authTag。

### 示例.md
本文档提供了使用仓颉语言进行SM4_128/GCM/PKCS7同步加密与解密的代码示例。涵盖了生成GCM参数、初始化加密/解密器、分块处理数据、获取认证标签以及通过原始数据生成对称密钥等核心步骤。重点展示了GCM模式下认证标签的处理方式，以及如何利用CryptoArchitectureKit接口实现分块update和doFinal的完整流程。适用于需要在仓颉开发环境中实现数据安全加密的开发者，作为API使用的实战参考。

### 解密_a88442ba.md
这份文档是一份关于使用SM4算法进行解密操作的教程指南。主要涵盖创建Cipher实例、初始化解密模式、分块更新数据及获取最终结果四个步骤。文档详细说明了如何配置SM4_128、GCM分组模式和PKCS7填充模式，并强调了通过createCipher、initialize、update和doFinal四个API的调用顺序来实现解密。目标受众是使用CryptoArchitectureKit的开发人员，需具备基础密码学知识。关键词：SM4解密、GCM模式、CryptoArchitectureKit、API调用流程。
