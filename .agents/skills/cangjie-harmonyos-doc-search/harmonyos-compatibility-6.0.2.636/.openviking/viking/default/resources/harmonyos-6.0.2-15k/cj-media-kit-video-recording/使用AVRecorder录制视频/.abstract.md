This directory provides a comprehensive technical guide for developers on implementing video recording functionality using the AVRecorder API within the HarmonyOS ecosystem. It covers the complete development lifecycle, including audio and video capture, encoding, packaging, and state management operations such as starting, pausing, resuming, and stopping recordings. Key topics include strict adherence to the state machine, permission handling (MICROPHONE, CAMERA), camera integration via Surface, file descriptor management, and resource cleanup. The content is specifically tailored for application developers using the Cangjie language who need to build robust multimedia applications with local video file generation capabilities.
