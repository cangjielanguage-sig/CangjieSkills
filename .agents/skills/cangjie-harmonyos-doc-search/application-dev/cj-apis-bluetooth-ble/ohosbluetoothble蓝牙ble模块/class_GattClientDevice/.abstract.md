This directory provides API reference documentation for the `GattClientDevice` class in the Cangjie programming language, designed for HarmonyOS developers using the ConnectivityKit. It encompasses the full spectrum of Bluetooth Low Energy (BLE) GATT client operations, including connection lifecycle management, service discovery, and data transfer through characteristics and descriptors. Additionally, it covers event subscription for connection states, characteristic changes, and MTU negotiations. This resource is essential for developers implementing robust, asynchronous BLE communication in their applications.
