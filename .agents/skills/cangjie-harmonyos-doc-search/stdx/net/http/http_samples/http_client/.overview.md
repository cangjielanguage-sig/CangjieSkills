# http_client

本目录专门收录了仓颉语言中 HTTP 客户端模块的详细使用文档与代码指南。它不仅涵盖了发起基础 HTTP 请求的标准方法，还深入探讨了高级网络配置，包括但不限于 TLS 证书验证、TCP 连接参数调整、代理服务器设置以及分块传输编码的处理机制。文档重点展示了如何利用 ClientBuilder 构建高度定制化的客户端实例，并指导开发者处理文件流上传与安全相关的配置。该资源主要面向需要在仓颉生态系统中进行网络编程、对接 RESTful API 或处理复杂网络通信场景的开发者，旨在通过丰富的示例帮助用户全面掌握 HTTP 客户端的各种高级配置与请求发送方式。

## Detailed Description

### http_client.md

本文档提供了仓颉语言中 HTTP 客户端的使用示例和代码指南。主要涵盖基础请求示例、自定义网络配置（如 TLS 证书和 TCP 连接）、分块传输与尾部头处理，以及代理设置。重点介绍了如何使用 ClientBuilder 构建客户端、处理文件流上传及自定义安全配置。文档强调示例需配合服务端及特定证书文件才能运行。这是一份面向开发者的教程文档，旨在帮助用户掌握 HTTP 客户端的各种高级配置与请求发送方式。
