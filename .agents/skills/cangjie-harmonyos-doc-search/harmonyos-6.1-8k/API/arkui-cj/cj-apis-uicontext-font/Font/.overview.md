# Font

本目录包含ArkUI框架下基于仓颉语言的字体管理相关文档，涵盖了字体API参考、数据结构定义及实用示例代码。核心内容包括Font类的使用方法、FontInfo类的属性定义，以及如何注册自定义字体和获取系统字体信息。这些文档旨在帮助HarmonyOS开发者高效管理应用字体资源，适用于需要处理字体加载、查询及元数据解析的ArkUI应用开发人员。

## Detailed Description

### Font_3more_6fcf34ca.md Font_3more_6fcf34ca.md
这份文档是ArkUI框架中Font类的API参考文档，旨在指导开发者如何注册自定义字体及获取系统字体信息。文档主要涵盖Font类的定义及其三个核心方法：getFontByName用于根据名称获取字体详情，getSystemFontList用于获取系统支持的字体列表，registerFont用于在字体管理中注册自定义字体。使用这些API前必须先通过UIContext获取Font实例。文档详细说明了各方法的参数、返回值及可能抛出的BusinessException异常。该文档适用于ArkUI应用开发者，特别是需要管理应用字体资源的开发人员。

### class_FontInfo.md class_FontInfo.md
本文档定义了Cangjie语言中的FontInfo类，旨在封装和描述字体的详细属性信息。文档详细列出了该类的公共属性，涵盖字体家族、全名、PostScript名称、文件路径、粗细、宽度以及斜体、等宽和符号支持等布尔标识。所有属性均具备读写能力，该类属于ArkUI全功能系统能力，起始版本为22。主要面向使用Cangjie开发ArkUI应用的程序员，适用于需要处理或查询字体元数据的场景。

### 示例代码.md 示例代码.md
本文档旨在提供基于仓颉语言和ArkUI框架的字体管理功能示例代码。文档分为三个主要部分：注册自定义字体、获取系统字体列表以及获取指定字体的详细信息。通过具体的代码实现，展示了如何利用getUIContext().getFont()接口加载TTF资源、查询系统可用字体及解析字体属性（如路径、字重、样式等）。这些示例为HarmonyOS应用开发者提供了实用的字体处理参考，要求读者具备基础的仓颉编程和ArkUI开发知识。
