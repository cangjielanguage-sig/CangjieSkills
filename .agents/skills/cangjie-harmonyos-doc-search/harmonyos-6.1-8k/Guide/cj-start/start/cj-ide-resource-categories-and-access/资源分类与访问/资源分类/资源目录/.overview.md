# 资源目录

本目录包含应用资源管理的相关文档，旨在指导开发者规范地组织和管理应用资源。内容涵盖资源目录结构、限定词命名规范（如语言、屏幕密度等）、资源编译机制以及特殊目录（rawfile、resfile）的使用与访问方式。核心关键词包括资源限定词、多场景适配、目录规范和资源访问。该文档适合应用开发人员阅读，帮助其实现高效的多语言、多设备资源适配。

## 详细描述

### 资源目录_1.md
本文档旨在阐述应用资源目录的结构、功能及限定词命名规范，指导开发者有效管理资源。主要涵盖默认base目录与限定词目录（如en_US）的用途，以及限定词目录的详细命名要求。关键信息包括资源文件编译为二进制ID的机制，以及限定词组合顺序、连接方式（下划线或中划线）和取值范围等规则。属于技术参考文档，面向应用开发人员，帮助其理解如何通过目录结构实现多场景资源适配。

### 资源目录_2.md
本文档是应用资源目录配置参考指南，旨在规范资源限定词及特殊目录的使用。主要内容包括移动网络码、语言、文字、国家地区、屏幕方向、设备类型、颜色模式及屏幕密度等限定词的定义与取值标准。此外，文档还阐述了rawfile和resfile目录的特性：两者均支持自定义子目录且不编译，rawfile通过路径直接引用，resfile解压至应用沙箱并通过Context访问。该文档面向应用开发者，指导资源文件的分类管理与访问。
