# 加载本地页面

This directory serves as a technical resource for HarmonyOS developers aiming to implement local web page rendering within their applications. It explores the necessary procedures for loading HTML content from both the application's `rawfile` resources and secure sandbox paths. The documentation covers the use of the Cangjie language for Web component integration, including dynamic URL loading and local CSS styling. Additionally, it provides essential insights into the ArkTS-based `MainAbility` lifecycle, demonstrating how to utilize `GlobalContext` to bind file directories and synchronize data between the Ability and UI components. This guide is suitable for developers building hybrid applications that require seamless interaction between native code and local web assets.

## Detailed Description

### 加载本地页面_1.md
This technical guide demonstrates methods for loading local HTML pages within a Web component using the Cangjie language. It covers two primary approaches: loading files from the application's rawfile directory and loading from application sandbox paths. Key information includes using the $rawfile resource reference for initialization, the loadUrl() interface for dynamic page changes, and referencing local CSS styles. Additionally, it explains how to access sandbox files using GlobalContext and file access permissions. The document targets HarmonyOS developers, providing practical code examples for implementing local web content rendering and resource management.

### 加载本地页面_2.md
This code snippet demonstrates the lifecycle implementation for a MainAbility in a HarmonyOS application, specifically focusing on initialization and page loading. It covers the onCreate method for context setup and the onWindowStageCreate method for UI rendering. Key information includes using GlobalContext to bind filesDirectory for data synchronization between Ability and UI components, and using windowStage.loadContent to display the EntryView. This technical reference is intended for mobile application developers using ArkTS who need to understand Ability lifecycle management and context usage. Keywords: HarmonyOS, ArkTS, Ability lifecycle, GlobalContext, WindowStage.
