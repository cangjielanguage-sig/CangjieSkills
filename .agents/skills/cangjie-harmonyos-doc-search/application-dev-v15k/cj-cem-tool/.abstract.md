This directory contains the essential reference guide for the Common Event Manager (CEM) tool, a robust utility designed to streamline the debugging and testing of public events for developers. The tool enables users to print detailed event logs and simulate the publication of events, which is crucial for verifying system logic and event handling mechanisms. The documentation thoroughly covers the environment prerequisites needed to operate the tool, presents a full command list, and provides detailed usage instructions for the help, publish, and dump commands. It highlights important technical details, such as the syntax for publishing events with custom codes and data, and clarifies that the dump command is restricted to engineering versions of the software. This resource is specifically tailored for developers and testers working within the hdc shell environment who require precise tools for validating system-level event management and ensuring the reliability of event-driven features.
