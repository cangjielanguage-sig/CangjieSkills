This directory provides comprehensive API reference documentation for the `ohos.emitter` module in the Cangjie programming language, focusing on event-driven communication and scheduling within HarmonyOS applications. It covers core components such as the `Emitter` struct, `InnerEvent` class, and various data structures for callbacks and event priorities. Key topics include event subscription types, priority-based dispatching (IMMEDIATE, HIGH, LOW, IDLE), and inter-thread communication. This documentation is suitable for Cangjie developers looking to implement robust event queues, manage notification flows, and handle asynchronous events effectively using SystemCapability.Notification.Emitter.
