# cj-apis-bluetooth-constant

This directory serves as a repository for the Cangjie (cj) APIs specifically designed for Bluetooth constant definitions within the HarmonyOS ecosystem. It is a crucial resource for developers aiming to implement robust Bluetooth connectivity features using the Cangjie programming language. The content primarily focuses on standardizing values used across Bluetooth operations, including device categorization, profile connection states, and specific profile identifiers. By providing a comprehensive set of enumerations—such as MajorClass, ProfileId, and ProfileUuids—this module ensures that developers can reliably manage device types and communication protocols. It is intended for use in applications requiring the SystemCapability.Communication.Bluetooth.Core capability, supporting API version 19 and above.

## Detailed Description

### ohosbluetoothconstant蓝牙constant模块/
This module provides constant definitions and enumerations essential for Bluetooth operations within the HarmonyOS connectivity framework using the Cangjie programming language. It covers device categorization, profile connection states, profile identifiers, and UUIDs for standard Bluetooth profiles. Designed for developers implementing Bluetooth functionality, it ensures standardized values for identifying device types, managing connection statuses, and interacting with specific communication protocols. Key components include enums for MajorClass, ProfileId, and ProfileUuids, all requiring the SystemCapability.Communication.Bluetooth.Core capability starting from API version 19.
