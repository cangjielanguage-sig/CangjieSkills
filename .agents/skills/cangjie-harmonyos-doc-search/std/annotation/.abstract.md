This directory contains technical documentation and tutorials focused on the advanced usage of annotations within the Cangjie programming language. It specifically covers the mechanisms for defining custom annotation classes, applying them to target classes, and retrieving their values dynamically using reflection. The content provides a deep dive into the TypeInfo API, illustrating how to use methods like `TypeInfo.of()` and `findAnnotation()` to access and manipulate metadata at runtime. This resource is designed for Cangjie developers and software engineers who need to implement runtime introspection, dynamic code analysis, or sophisticated metadata handling in their applications.
