# 基准测试

This directory provides a comprehensive guide to benchmarking within the Cangjie unit testing framework. It covers the fundamentals of performance testing, including the use of the `@Bench` macro, warmup phases, and noise reduction techniques. The content also addresses advanced topics such as achieving reliable results, understanding internal measurement algorithms, parametric benchmarking, and advanced configuration options like custom metrics and reporting. Designed for Cangjie developers and performance engineers, these resources help users accurately measure code execution time, optimize performance, and ensure reproducible results.

## Detailed Description

### 基准测试入门.md 基准测试入门.md
This document serves as an introductory guide for implementing benchmarking within the Cangjie unit testing framework. It covers the framework's internal capabilities for ensuring result reliability, such as managing warmup phases, handling repetitions, and reducing noise from garbage collection. The text explains the usage of the @Bench macro to construct simple benchmarks and details the execution methods via the --bench option or cjpm bench command. Key takeaways include the automation of statistical analysis and the ease of integrating performance tests. This guide targets Cangjie developers seeking to measure and optimize code performance efficiently.

### 如何取得理想结果.md 如何取得理想结果.md
This guide explains how to minimize execution time variance to achieve reliable and reproducible benchmarking results. It covers the reliability metric `Err%` and details external factors users must manage, including compiler optimizations, background CPU tasks, I/O operations, unnecessary code optimizations, side effects, and redundant static allocations. Key takeaways include that an `Err%` under 3% indicates reliability, while over 10% requires investigation. Users should enable optimizations like `-O2`, isolate CPU cores, ensure function purity, and manage memory to avoid GC interference. The framework provides warnings but cannot guarantee the elimination of all influencing factors. This guide targets developers using the benchmarking framework who need to ensure their performance tests are accurate and stable.

### 框架的测试方式.md 框架的测试方式.md
This document details the core algorithm and logic used by a benchmarking framework to measure function execution times accurately. It covers the pseudocode implementation of `measureBatchSomeFunc`, the internal `Benchmark` class structure, and processes like warmup and batch size calculation. The key takeaway is that the framework isolates the execution time of a specific function by calculating the time difference between loop iterations, effectively excluding overhead from the testing loop and data retrieval. This technical reference is intended for developers or performance engineers seeking to understand the underlying measurement mechanics of the framework.

### 参数化基准测试/
This directory serves as a comprehensive resource for implementing parametric benchmarking in the Cangjie programming language. It details the effective use of `@Bench` and `@Strategy` macros to optimize performance testing, highlighting how to avoid common pitfalls like memory bloat and garbage collection interference. The content also delves into data management strategies, explaining the default immutability of input data and how to configure setups for scenarios requiring data modification. Designed for developers and performance engineers with a background in unit testing, this guide ensures users can generate meaningful, consistent, and high-performance benchmark results while managing data states effectively and reducing code redundancy.

### 高级特性/
This directory contains advanced configuration guides for a Cangjie testing and benchmarking framework. It covers input regeneration strategies, detailed report generation, custom metrics, and parameter tuning to prevent compiler optimizations. Key topics include `BenchInputProvider`, `@Strategy` annotation, HTML/CSV reporting, and micro-benchmark precision. It is suitable for Cangjie developers and performance engineers seeking granular control over benchmarks, accurate performance simulation, and in-depth analysis beyond standard timing.
