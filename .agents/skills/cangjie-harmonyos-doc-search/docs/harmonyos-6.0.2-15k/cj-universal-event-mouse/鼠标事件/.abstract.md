This directory provides comprehensive documentation for handling mouse events within the ArkUI framework using the Cangjie language. It covers the fundamental `MouseEvent` class definition, the specific implementation of the `onMouse` callback function, and practical code examples for building interactive user interfaces. Key topics include event properties such as timestamps, screen and relative coordinates, button states, and action types, alongside reactive state management techniques using decorators like `@State`. This resource is designed for application developers and UI engineers working on HarmonyOS applications who need to capture and process mouse input effectively to create responsive and interactive user experiences.
