### 货币和单位格式化

货币和单位的格式化基于数字格式化，在创建货币和单元格式化对象时，将数字的显示风格分别设置为“currency(货币)”和“unit(单位)”。同样，货币和单位的构造函数也支持通过[NumberOptions](../../API_Reference/source_zh_cn/apis/LocalizationKit/cj-apis-intl.md#struct-numberoptions)设置不同的格式，各属性参数取值和显示效果如下表所示。

**货币格式化选项**

以货币单位: USD，数值: -12300为例。

**表9** 货币单位的符号(currencySign)

| 取值 | 显示效果 |
| -------- | -------- |
| standard | -US$12,300.00 |
| accounting | (US$12,300.00) |

**表10** 货币的显示方式(currencyDisplay)

| 取值 | 显示效果 |
| -------- | -------- |
| symbol | -US$12,300.00 |
| narrowSymbol | -$12,300.00 |
| code | -USD 12,300.00 |
| name | -12,300.00 US dollars |

**单位格式化选项**

以单位名称：hectare，数字大小：-12300为例。

**表11** 单位的显示格式(unitDisplay)

| 取值 | 显示效果 |
| -------- | -------- |
| long | -12,3000 hectares |
| short | -12,300 ha |
| narrow | -12,300ha |

**表12** 单位的使用场景(unitUsage)

| 取值 | 显示效果 |
| -------- | -------- |
| 为空 | -12,300 ha |
| 不设置 | -47.491 sq mi |
| area-land-agricult | -30,393.962 ac |

**开发实例**

<!-- run -->

```cangjie
// 导入模块
import kit.LocalizationKit.*

// 格式化货币
let n1 = NumberOptions(style: 'currency', currency: 'USD')
let currencyFormat: NumberFormat = NumberFormat('zh-CN', options: n1)
var formattedNumber: String = currencyFormat.format(123400.0) // formattedNumber = 'US$123400'

// 用名称表示货币
let n2 = NumberOptions(style: 'currency', currency: 'USD', currencyDisplay: 'name')
let currencyNameFormat: NumberFormat = NumberFormat('zh-CN', options: n2)
formattedNumber = currencyNameFormat.format(123400.0) // formattedNumber = '123400美元'

// 格式化度量衡
let n3 = NumberOptions(style: 'unit', unit: 'hectare', unitUsage: '')
let unitFormat: NumberFormat = NumberFormat('en-GB', options: n3)
formattedNumber = unitFormat.format(123400.0) // formattedNumber = '123400 ha'

// 格式化特定场景下度量衡，如面积-土地-农业
let n4 = NumberOptions(style: 'unit', unit: 'hectare', unitUsage: 'area-land-agricult')
let unitUsageFormat: NumberFormat = NumberFormat('en-GB', options: n4)
formattedNumber = unitUsageFormat.format(123400.0) // formattedNumber = '304928.040730482 ac'
```
