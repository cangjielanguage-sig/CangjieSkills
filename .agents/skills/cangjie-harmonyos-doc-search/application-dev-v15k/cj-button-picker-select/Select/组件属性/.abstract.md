This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework. It primarily focuses on the Select and Dropdown menu components, detailing methods to customize appearance, behavior, and layout. Key topics include arrow positioning, menu alignment, option dimensions, font styling, and color customization. These documents provide function signatures, parameter types, and system capability constraints. This resource is suitable for UI developers and engineers using the Cangjie language to build and refine user interfaces, offering precise technical specifications for component manipulation starting from API version 12.
