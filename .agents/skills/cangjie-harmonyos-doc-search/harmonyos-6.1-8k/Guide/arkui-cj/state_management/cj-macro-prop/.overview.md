# cj-macro-prop

This directory serves as a comprehensive technical resource focused on the `@Prop` decorator within the ArkUI framework, specifically addressing the implementation of one-way data synchronization between parent and child components. It covers essential concepts such as variable passing, access rules, macro usage restrictions, and state management mechanisms. The documentation provides a deep dive into one-way data flow, local copy characteristics, and nested object observation rules to ensure state consistency. This resource is designed for developers possessing a foundational understanding of ArkUI and framework engineers seeking to master best practices for component data transfer and state synchronization in a declarative UI environment.

## Detailed Description

### Prop宏父子单向同步/
This directory provides a detailed exposition of the core functionality and usage specifications of the `@Prop` decorator in the ArkUI framework, with a primary focus on implementing one-way data synchronization between parent and child components. The content comprehensively covers the basic concepts of `@Prop`, including the protocols for variable passing, the rules governing variable access, and specific restrictions regarding macro usage. Furthermore, it addresses state management mechanisms in complex scenarios, providing a deep dive into the nuances of one-way data flow. The documentation explains the characteristics of local copies and the rules for observing nested objects, which are critical for maintaining application performance and consistency. The ultimate goal of this documentation is to help developers master best practices for data transfer between components. It is suitable for developers with a basic knowledge of ArkUI and framework engineers who need to understand the underlying mechanics of component interaction.
