This directory provides comprehensive API documentation for the Zoom interface within the Cangjie language environment, specifically tailored for the CameraKit framework. It covers essential functionalities for configuring camera zoom levels, retrieving current zoom ratios, and managing smooth zoom transitions. Key topics include the `setZoomRatio` function, parameter constraints involving Float32 precision, error handling mechanisms, and system capabilities. The documentation is intended for multimedia and application developers who need to implement robust zoom features in camera applications. It assumes the audience has prior knowledge of session management, the Camera framework, and core multimedia concepts to effectively utilize these references and handle potential BusinessException errors.
