This directory contains API reference documentation for the `ContentType` enum within the ArkUI framework, specifically written for the Cangjie language. It provides a comprehensive definition of constants used to enable contextual auto-fill functionality across a wide range of user data types. The content covers categories such as geographical locations (country, district), communication details (email, phone numbers), personal credentials (usernames, passwords), and specific address components. These definitions are essential for facilitating automatic data saving and filling when contextual auto-fill or password vault features are active. This documentation is tailored for developers building HarmonyOS applications who require SystemCapability.ArkUI.ArkUI.Full (version 19 or later) to create seamless and efficient user input experiences. By utilizing these constants, developers can ensure their forms interact correctly with the system's auto-fill services.
