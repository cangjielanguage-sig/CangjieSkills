### time_package_exceptions.md time_package_exceptions.md

This document functions as the primary API reference for exception handling within the Cangjie time package. It provides a technical deep dive into the error handling mechanisms that developers must utilize when working with time data, ensuring stability and correctness in applications.

The text details two specific exception classes that are central to the package's error management strategy. The first, `InvalidDataException`, is the standard handler for errors that occur during the timezone loading process, ensuring that missing or corrupt timezone data is caught gracefully. The second, `TimeParseException`, is used to manage errors that happen when parsing time strings, allowing for precise control over input validation failures.

Both classes are architecturally built to inherit from the core `Exception` type, ensuring they integrate seamlessly with the language's existing error handling framework. The documentation explicitly outlines the public interface for these classes, noting that each provides two constructors: a default initializer for standard use cases and a variant accepting a custom `String` message parameter for more descriptive error reporting. This reference is intended for Cangjie developers who need to implement error handling or debug time-related operations in their applications.
