# 组件内转场transition

This directory focuses on component internal transitions within the ArkUI framework using the Cangjie language. It comprehensively covers the implementation of visual effects during component insertion, deletion, and visibility changes. Key topics include the TransitionEffect API, asymmetric transitions, nested component configurations, and fundamental type definitions for animations. It is suitable for HarmonyOS developers and UI designers looking to enhance user experience with smooth, dynamic interface animations and precise control over component lifecycle behaviors.

## Detailed Description

### 示例代码.md 示例代码.md
This document provides Cangjie code examples demonstrating various implementations of the TransitionEffect API for UI animations in HarmonyOS development. It covers three specific scenarios: using a single interface for bidirectional appearance and disappearance, utilizing different interfaces for distinct entry and exit effects via asymmetric transitions, and configuring transitions on nested parent-child components. Key takeaways include combining effects like opacity, rotation, and scaling, alongside animation parameters such as duration and easing curves. This guide is intended for developers using the Cangjie language to implement dynamic and complex UI transitions.

### 组件内转场transition_4more.md 组件内转场transition_4more.md
This document serves as an API reference for configuring component internal transitions in ArkUI using the Cangjie language, specifically detailing how to apply animation effects during component insertion and deletion. The content covers the transition property, explaining its two trigger methods—structural changes like if/ForEach and Visibility attribute changes—and documents three function overloads: a default setup, a version accepting a TransitionEffect, and a version including an onFinish callback. Key takeaways include the system capability requirements, version 12 availability, and the specific parameters for defining transition effects and handling animation completion events. Intended for ArkUI developers, this guide helps enhance user experience by implementing smooth visual transitions for dynamic UI elements.

### 基础类型定义/
This directory serves as a comprehensive API reference for fundamental type definitions within the ArkUI framework, specifically tailored for the Cangjie language. It covers essential classes and enums used to configure visual transformations and animations for UI components, including scaling, translation, rotation, and transition effects. By providing detailed specifications for properties like axis vectors, multipliers, and animation parameters, this documentation enables developers to implement dynamic and spatially complex user interfaces. It is suitable for UI developers and system architects working with ArkUI version 12+ who require precise control over component styling and lifecycle animations.
