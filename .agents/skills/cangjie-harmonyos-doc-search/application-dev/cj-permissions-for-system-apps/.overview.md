## Detailed Description

### 可ACL申请的系统应用可用权限系统授权/
This directory functions as a comprehensive reference guide for sensitive system permissions in OpenHarmony and HarmonyOS that specifically require Access Control List (ACL) enablement to function correctly. It meticulously documents permissions that have become available starting from API version 12, organizing them into distinct functional categories to assist developers in locating the necessary controls for their specific use cases. Key categories covered include account management, casting capabilities, factory operations, security features, and telephony functions.

The documentation highlights that these permissions typically utilize the `system_grant` authorization mode, meaning they are granted by the system during installation rather than through user interaction. Furthermore, access to these capabilities is strictly restricted to applications running at `system_basic` or `system_core` privilege levels. This resource is essential for system application developers and security integrators who need to implement privileged functionalities. It provides the necessary context to understand the specific authorization requirements for accessing restricted device capabilities, helping to prevent configuration errors and ensuring that applications maintain the appropriate security posture within the ecosystem. By referencing this documentation, developers can ensure their applications adhere to the necessary privilege escalation protocols required for core system services.
