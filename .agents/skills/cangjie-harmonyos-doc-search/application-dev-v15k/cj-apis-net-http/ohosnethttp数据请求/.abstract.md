This directory contains API reference documentation for the `ohos.net.http` module in the Cangjie programming language, designed for HarmonyOS development. It covers essential components for implementing HTTP data requests, including request configuration, response handling, SSL certificate management, and performance monitoring. Key topics include the `HttpRequest` and `HttpResponse` classes, multipart form data, proxy settings, and caching mechanisms. This documentation is suitable for software developers and engineers using the NetworkKit framework who need to build secure, efficient, and robust network communication features in their applications.
