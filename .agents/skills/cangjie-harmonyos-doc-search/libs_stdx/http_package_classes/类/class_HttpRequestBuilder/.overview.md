# class_HttpRequestBuilder

This directory contains API reference documentation for the `HttpRequestBuilder` class in the Cangjie language. It focuses on the construction and configuration of HTTP requests, providing developers with tools to define request methods, headers, bodies, URLs, and timeouts. The documentation highlights the builder's fluent interface design, which allows for method chaining to create customized `HttpRequest` instances. Key topics include initialization, body content management, standard HTTP verbs (GET, POST, PUT), and timeout settings. This resource is suitable for software developers and engineers integrating HTTP client functionality into Cangjie applications who need to programmatically build and manage network requests.

### class_HttpRequestBuilder_8more.md
This API reference document details the HttpRequestBuilder class in the Cangjie language, designed for constructing HttpRequest instances. It covers class initialization methods, including a default constructor and a copy constructor, alongside configuration methods for headers, trailers, and request body. Key information includes the builder's fluent interface design, where methods return the instance for chaining. The copy constructor performs deep copies for headers and trailers but shares the body stream. Body content can be set via byte arrays, input streams, or strings, replacing any existing content. This guide targets software developers integrating HTTP functionality who need to programmatically build and customize HTTP requests.
