# class_UiWindow

This directory contains API reference documentation for the `UiWindow` class within the Cangjie UiTest framework. It provides comprehensive details on managing UI windows during automated testing, covering essential operations like retrieving properties (bounds, titles), manipulating states (maximize, minimize, split-screen), and handling window focus. The documentation includes method signatures, return types, error handling via `BusinessException`, and practical Cangjie code examples. It is designed for developers utilizing the TestKit and Driver components to create robust UI automation scripts that require precise control over window behaviors and attributes.
