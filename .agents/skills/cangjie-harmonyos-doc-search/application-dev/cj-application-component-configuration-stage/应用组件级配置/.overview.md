# 应用组件级配置

This directory focuses on the configuration of application components and metadata within the HarmonyOS development environment. It covers essential setup tasks such as defining application icons, labels, version numbers, supported device types, permissions, and package naming conventions. Key topics include `app.json5` and `module.json5` configuration, system priority rules for UI elements, and reverse domain naming for unique identification. This documentation is suitable for HarmonyOS developers who need to configure project properties, manage application metadata, and ensure proper system integration during the initial setup and packaging phases.

## Detailed Description

### 图标和标签配置.md 图标和标签配置.md
This guide explains the configuration and generation mechanisms for application icons and labels within HarmonyOS app and module files. Key topics include the generation logic for HAPs with or without UIAbility, usage scenarios, configuration examples for app.json5 and module.json5, and system control rules for hiding desktop icons. Important takeaways are that module.json5 configuration is optional in newer DevEco versions, system priority rules determine which icon displays based on specific skills, and hiding desktop icons is restricted to pre-installed applications with specific privileges. This technical reference is intended for HarmonyOS developers configuring application metadata and UI presentation.

### 应用版本声明配置_3more.md 应用版本声明配置_3more.md
This document serves as a configuration guide for defining application metadata and module capabilities within a development project. It covers three primary configuration areas: application version declaration, supported device types, and module permissions. Key information includes specifying `versionCode` and `versionName` in the `app.json5` file for version control, configuring `deviceTypes` in `module.json5` to determine hardware compatibility, and using `requestPermissions` to declare necessary system access. This reference material is intended for developers setting up project configuration files to ensure proper app functionality and compliance.

### 应用组件级配置_2more.md 应用组件级配置_2more.md
This document serves as a configuration guide for developers setting up application-level properties and identifiers. It specifically covers the configuration of the application package name. The key information provided is that the bundleName tag must be configured in the app.json5 file within the AppScope directory to ensure application uniqueness. The document recommends using a reverse domain naming convention, such as com.example.demo, structured by domain suffix, vendor name, and application name. This guide is intended for application developers defining basic metadata during the development process.
