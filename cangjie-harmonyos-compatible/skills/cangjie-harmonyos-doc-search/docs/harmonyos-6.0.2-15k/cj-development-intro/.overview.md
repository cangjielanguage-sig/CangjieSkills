# cj-development-intro

The `cj-development-intro` directory acts as a comprehensive guide for developers utilizing the Cangjie programming language in conjunction with the HarmonyOS SDK. It focuses on the practical execution of Cangjie API code snippets and provides clear instructions on interpreting API documentation fields. The content is essential for managing application permissions and understanding the structural constraints of application models. Key topics include the integration of code into project templates, the utilization of SystemCapability (SysCap) to ensure device compatibility, and strict adherence to Stage model constraints. This resource is ideally suited for Cangjie application developers who require a reliable reference for API examples, need to navigate complex SDK specifications, and must ensure their applications comply with system access rules and lifecycle requirements.

## Detailed Description

### 开发说明/

This directory provides essential documentation for developers working with the Cangjie language and the HarmonyOS SDK. It covers the practical execution of Cangjie API code snippets, interpretation of API documentation fields, and the management of permissions and application models. Key topics include integrating code into project templates, understanding SystemCapability (SysCap) for device compatibility, and adhering to the Stage model constraints. This resource is suitable for Cangjie application developers who need to effectively reference API examples, navigate SDK specifications, and ensure compliance with system access rules and lifecycle requirements.
