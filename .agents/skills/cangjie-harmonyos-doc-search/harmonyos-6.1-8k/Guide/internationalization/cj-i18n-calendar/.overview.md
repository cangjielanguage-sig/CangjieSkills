# cj-i18n-calendar

本目录提供了 `cj-i18n-calendar` 模块的详细开发文档，专注于解决应用开发中的国际化日历处理问题。文档核心内容围绕 `LocalizationKit` 中的 `Calendar` 类展开，详细阐述了如何配置和转换包括公历、农历、佛历及伊斯兰历在内的多种历法系统。它不仅涵盖了基础的模块导入、时间与时区设置，还深入讲解了日期的加减运算及历法间的转换逻辑。该资源特别适合致力于构建全球化应用、需要处理复杂多地区日期差异的开发者参考，能够有效提升应用在不同文化环境下的兼容性与用户体验。

### cj-i18n-calendar.md cj-i18n-calendar.md
本文档是一份面向开发者的国际化开发指南，旨在介绍如何使用LocalizationKit中的Calendar类设置日历和历法。文档涵盖了使用场景说明、详细的开发步骤（包括导入模块、设置时间与时区、日期加减操作）以及公历转农历的代码示例。此外，还列出了支持的多种日历类型（如佛历、农历、伊斯兰历等）。关键信息在于展示了如何通过接口实现日历的本地化配置、日期计算及类型转换。目标受众为需要处理多地区日历差异的应用开发者，需具备基础编程能力。
