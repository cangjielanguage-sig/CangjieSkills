# 系统能力SystemCapability使用指南

This directory provides a comprehensive guide to System Capabilities (SysCap) within the HarmonyOS/OpenHarmony ecosystem. It details how system features map to APIs and ensures application compatibility across various devices. The content covers core concepts, configuration methods, and development logic, including how to define capabilities in JSON and check API availability using Cangjie. It is designed for HarmonyOS developers using DevEco Studio who need to understand device compatibility rules, manage capability sets, and ensure their applications function correctly on specific hardware configurations. By mastering these concepts, developers can optimize their apps for diverse device types and leverage the full potential of the HarmonyOS SDK.

## Detailed Description

### SysCap开发指导.md SysCap开发指导.md
This guide instructs developers on configuring and managing System Capabilities (SysCap) for application compatibility across different devices. It covers adding custom SysCap via JSON files, single versus cross-device development logic, checking API availability using Cangjie code, and the technical lifecycle of SysCap generation. Key takeaways include defining addedSysCaps in syscap.json, understanding union/intersection logic for capability sets, and using the canIUse method for runtime checks. The document explains how component assembly leads to SysCap differences and how PCID/RPCID ensures compatibility during installation. This is a technical tutorial for HarmonyOS/OpenHarmony application developers using DevEco Studio and Cangjie.

### 概述.md 概述.md
This document provides an overview of SystemCapability (SysCap) concepts within the HarmonyOS ecosystem, explaining how system features relate to APIs and device compatibility. It covers SysCap definitions, the relationship between support, required, and association capability sets, device categorization (typical vs. custom), and SDK integration with DevEco Studio. A key takeaway is the compatibility rule: an app can run on a device only if its required capability set is a subset of the device's support set. DevEco Studio filters API suggestions based on the selected device's capabilities. This guide targets HarmonyOS developers using DevEco Studio to ensure their applications are compatible with specific hardware configurations.
