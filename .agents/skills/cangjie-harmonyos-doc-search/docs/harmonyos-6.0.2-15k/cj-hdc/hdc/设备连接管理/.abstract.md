This directory serves as a comprehensive technical resource for managing device connections within the HarmonyOS development ecosystem. It focuses extensively on the HarmonyOS Device Connector (hdc) tool, providing essential references for establishing and maintaining communication channels between hosts and devices. The documentation covers critical operations such as switching between USB and wireless debugging modes, querying device lists, and managing commands in multi-device environments. Furthermore, it addresses common connectivity scenarios, including local USB, TCP, and remote debugging across different networks. This content is specifically designed for developers and testers who possess command-line interface knowledge and need to configure, monitor, or troubleshoot device connections efficiently.
