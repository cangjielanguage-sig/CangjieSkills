# class_FuncParam

This directory contains comprehensive API reference documentation for the Cangjie language's Abstract Syntax Tree (AST) implementation. It specifically focuses on the `FuncParam` class, which represents function parameter nodes, and the `traverse` function used for navigating syntax trees. The documentation details class inheritance, mutable properties for syntax tokens, type definitions, initialization expressions, and the Visitor pattern for controlled traversal. This resource is primarily intended for compiler developers, language tool builders, and software engineers who require deep technical knowledge to parse, analyze, modify, or traverse Cangjie code structures programmatically.
