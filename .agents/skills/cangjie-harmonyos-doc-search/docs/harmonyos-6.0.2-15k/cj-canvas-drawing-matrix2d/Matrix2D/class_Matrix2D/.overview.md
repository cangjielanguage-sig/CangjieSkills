# class_Matrix2D

This directory contains API reference documentation for the Matrix2D class within the Cangjie language and ArkUI framework. It focuses on handling 2D matrix transformations essential for graphical manipulation. The documentation covers class constructors, geometric properties like scaling and rotation, and specific methods for matrix operations such as inversion and translation. Designed for ArkUI and HarmonyOS developers, these resources provide the technical details and code examples needed to implement complex 2D graphical transformations in Canvas contexts.
