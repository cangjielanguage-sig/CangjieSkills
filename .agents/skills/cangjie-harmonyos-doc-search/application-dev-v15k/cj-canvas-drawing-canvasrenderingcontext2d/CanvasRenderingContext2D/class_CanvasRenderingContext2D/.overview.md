# class_CanvasRenderingContext2D

This directory contains API reference documentation for the `CanvasRenderingContext2D` class in the Cangjie language, used for 2D drawing on ArkUI Canvas components. It covers initialization, path creation, shape drawing, text rendering, image manipulation, gradients, and transformations. The documentation details method signatures, parameters, and system capabilities starting from API 12. It is suitable for HarmonyOS developers building graphical interfaces.
