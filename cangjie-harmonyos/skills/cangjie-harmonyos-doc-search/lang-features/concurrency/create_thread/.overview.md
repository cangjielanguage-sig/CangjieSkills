# create_thread

本目录详细介绍了仓颉编程语言中多线程编程的基础知识，重点在于如何创建和管理线程以实现高效的并发执行。文档深入讲解了利用 `spawn` 关键字结合无参 `lambda` 表达式来启动新线程的具体语法与用法，并通过实际代码演示了主线程与子线程如何并行工作。此外，内容还涵盖了线程的生命周期特性（如随主线程终止）以及线程控制函数 `sleep()` 的应用。核心关键词包括：线程创建、并发编程、spawn、lambda 表达式、仓颉语言。本资料非常适合仓颉语言的初学者、希望理解并发机制的开发者，以及正在构建多线程应用的技术人员参考。

## Detailed Description

### create_thread.md create_thread.md

本文档旨在介绍如何在仓颉编程语言中创建线程以实现代码的并发执行。主要内容包括使用 `spawn` 关键字配合无参 `lambda` 表达式创建新线程的方法，以及通过代码示例展示主线程与新线程的并发执行过程。关键信息指出 `lambda` 表达式即为新线程执行的代码块，且新线程会随主线程结束而终止。文档还简要提及了用于暂停线程执行的 `sleep()` 函数。这是一份面向仓颉开发者的基础教程，适用于需要掌握多线程并发编程基础的用户。
