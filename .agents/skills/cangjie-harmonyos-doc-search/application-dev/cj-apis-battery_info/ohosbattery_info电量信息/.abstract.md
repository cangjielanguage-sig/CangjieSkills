This directory contains API reference documentation for the `ohos.battery_info` module within the Cangjie programming language ecosystem. It covers the essential components needed to monitor and manage device power states, including real-time battery metrics, charging status, health conditions, and capacity levels. The documentation details the `BatteryInfo` class and its associated enumerations for charge states, health, and plugged types. It is suitable for HarmonyOS developers and software engineers building applications that require power management features, battery status monitoring, or energy consumption tracking. Key concepts include SystemCapability.PowerManager.BatteryManager.Core, API version 22, and Beta status.
