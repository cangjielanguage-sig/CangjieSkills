# 音频焦点

This directory provides comprehensive documentation on the system's audio focus management mechanism, which is crucial for handling audio stream conflicts and ensuring a seamless user experience. It covers the core concepts of requesting and releasing audio focus, managing concurrent streams, and handling interruptions via `InterruptEvent`. Key topics include `StreamUsage`, `SourceType`, `InterruptMode`, and specific focus strategies like `SHARE_MODE` and `INDEPENDENT_MODE`. Additionally, it addresses special scenarios such as ducking, mixing, and silent playback. This resource is primarily suitable for developers and software engineers implementing audio playback or recording features who need to ensure correct audio behavior across various application scenarios.

## Detailed Description

### 音频焦点_3more.md 音频焦点_3more.md
This guide explains the system's audio focus management mechanism, ensuring applications handle audio stream conflicts correctly. It covers requesting audio focus, releasing audio focus, and handling focus changes via InterruptEvent. Key information includes that the system automatically requests focus when starting playback (e.g., AudioRenderer.start) and releases it on stop or pause. Developers must use correct StreamUsage types and listen for interruptions. Special scenarios include concurrent modes for short sounds (SoundPool) and silent playback using setMediaMuted or setSilentModeAndMixWithOthers. This technical guide targets developers implementing audio playback or recording features.

The guide aims to help developers implement correct audio behavior by setting appropriate stream types and interrupt modes.
