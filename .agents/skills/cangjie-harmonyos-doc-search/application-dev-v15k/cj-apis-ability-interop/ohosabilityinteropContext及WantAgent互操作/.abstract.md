This directory contains API reference documentation for the `ohos.ability.interop` module, focusing on interoperability between Cangjie and ArkTS environments in HarmonyOS. It covers mechanisms for converting JavaScript values (JSValue) to various Context types (like AbilityContext, UIExtensionContext) and handling WantAgent objects across language boundaries. Key topics include the `SystemObjectInteropType` interface, context creation functions, and type conversion methods. This documentation is intended for HarmonyOS developers using the Cangjie language who need to integrate with ArkTS runtime components, manage cross-language contexts, or handle system capabilities starting from API version 19.
