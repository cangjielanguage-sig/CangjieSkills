This directory serves as a comprehensive resource for the `cj-apis-emitter` module, specifically tailored for the Cangjie programming language environment within HarmonyOS. It focuses on the critical aspects of event-driven communication and scheduling, enabling developers to build responsive and decoupled applications. The documentation details the architecture of the `Emitter` struct and `InnerEvent` class, alongside mechanisms for callback management and event prioritization. It is an essential guide for Cangjie developers aiming to master asynchronous event handling, implement priority-based dispatching strategies (IMMEDIATE, HIGH, LOW, IDLE), and facilitate efficient inter-thread communication using SystemCapability.Notification.Emitter.
