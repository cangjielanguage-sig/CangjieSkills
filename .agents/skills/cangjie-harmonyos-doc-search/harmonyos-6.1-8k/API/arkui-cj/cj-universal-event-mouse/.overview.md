# cj-universal-event-mouse

本目录包含ArkUI框架中Cangjie语言的鼠标事件API参考文档，旨在指导开发者处理组件的鼠标点击和移动交互。文档详细介绍了模块导入方式、核心函数`onMouse`的定义、`MouseEvent`参数类型（包含时间戳、按键、坐标等）及返回值类型。关键信息指出该功能目前处于Beta阶段，仅支持外接鼠标触发，且事件默认透传。本文档面向使用Cangjie语言进行ArkUI应用开发的开发者，提供了处理鼠标输入事件的标准接口说明。

## Detailed Description

### cj-universal-event-mouse.md

本文档是ArkUI框架中Cangjie语言的鼠标事件API参考文档，旨在指导开发者处理组件的鼠标点击和移动交互。文档主要介绍了模块导入方式及核心函数`onMouse`的详细定义，包括其参数类型`MouseEvent`（包含时间戳、按键、坐标等）和返回值类型。关键信息指出该功能目前处于Beta阶段，仅支持外接鼠标触发，且事件默认透传。本文档面向使用Cangjie语言进行ArkUI应用开发的开发者，提供了处理鼠标输入事件的标准接口说明。通过阅读本文档，开发者可以掌握在Cangjie语言环境下利用ArkUI框架进行鼠标事件监听与响应的标准方法。
