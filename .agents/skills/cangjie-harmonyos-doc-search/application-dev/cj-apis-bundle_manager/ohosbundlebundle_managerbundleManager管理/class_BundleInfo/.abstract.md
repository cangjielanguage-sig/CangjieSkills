This directory contains API reference documentation for the `BundleInfo` class in the Cangjie language framework, focusing on application bundle metadata. It covers properties such as bundle names, version codes, installation timestamps, configurations, module information, and permission states. The documentation explains how to retrieve this data using the `getBundleInfoForSelf` interface with specific flags. It is suitable for developers working on HarmonyOS applications who need access to system-level bundle management capabilities and permission logic. This documentation is essential for understanding the structural mapping of application data within the system environment. Key topics include BundleInfo, Cangjie, API reference, application metadata, version codes, permissions, and bundle management.
