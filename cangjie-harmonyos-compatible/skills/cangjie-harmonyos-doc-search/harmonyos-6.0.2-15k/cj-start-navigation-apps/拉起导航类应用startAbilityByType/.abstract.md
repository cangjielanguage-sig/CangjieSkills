This directory provides comprehensive technical documentation for invoking navigation application extension panels on HarmonyOS using the `startAbilityByType` interface. It covers the complete implementation lifecycle for both the calling application (requesting map services) and the target application (providing map services). Key topics include route planning, navigation, location search, parameter configuration using the GCJ-02 coordinate system, and `module.json5` setup. The guides include Cangjie code examples for constructing JSON parameters, handling callbacks, and parsing incoming requests. This resource is suitable for HarmonyOS application developers looking to integrate robust map functionalities or enable their apps to respond to external map requests effectively.
