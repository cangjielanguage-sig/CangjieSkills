# 应用文件目录与应用文件路径

This directory provides a comprehensive technical overview of application file directory structures and path management within the OpenHarmony development environment. It details the hierarchical organization of storage, emphasizing the five encryption levels (EL1-EL5) and their specific security use cases. Key topics include the distinction between App-level and HAP-level storage, the strict requirement to use Context APIs for path retrieval to ensure compatibility, and the standardization of directories for persistent data, caches, and temporary files. This resource is essential for developers aiming to implement secure data persistence, manage application lifecycles, and facilitate cross-device file sharing effectively.

## Detailed Description

### 应用文件目录与应用文件路径_1.md 应用文件目录与应用文件路径_1.md
This technical guide outlines the application file directory structure and path management for OpenHarmony developers. It details the hierarchical organization, specifically focusing on the persistent storage directory and five encryption levels (EL1-EL5). Key takeaways include the recommendation to use EL2 for default security and EL1 for pre-unlock access, the strict requirement to use Context APIs for path retrieval to ensure compatibility, and the distinction between App-level and HAP-level storage directories. The document serves as a reference for developers implementing secure data persistence and understanding file lifecycles.

### 应用文件目录与应用文件路径_2.md 应用文件目录与应用文件路径_2.md
This reference document outlines the standard directory structure and file paths for application data storage. It details specific directories such as bundle, base, files, cache, preferences, and temp, mapping them to their corresponding Context properties. Key information includes the intended use for each path, such as storing HAP resources, persistent private data, distributed files, or temporary caches, along with their lifecycle behaviors like automatic cleanup on uninstall or app exit. This guide is intended for developers seeking to correctly implement data persistence, resource management, and cross-device file sharing within the application framework.
