This directory provides comprehensive API documentation for the `ConstructorInfo` class, a core component of the Cangjie reflection framework designed to represent metadata about class constructors. It covers essential aspects of constructor inspection, including accessing inheritance hierarchies, retrieving applied annotations, and managing parameter lists. The documentation highlights critical behaviors such as the non-guaranteed order of parameter lists and the necessity of using index properties for accurate positioning. Additionally, it details methods for dynamic constructor invocation and standard utility operations. This resource is specifically tailored for Cangjie developers who are implementing advanced reflection features, requiring the ability to programmatically inspect type metadata and instantiate objects dynamically within their applications. It serves as a complete reference for understanding how to interact with constructor metadata effectively.
