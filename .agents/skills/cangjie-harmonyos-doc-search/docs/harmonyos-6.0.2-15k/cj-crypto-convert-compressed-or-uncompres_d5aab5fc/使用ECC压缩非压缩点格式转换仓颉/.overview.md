# 使用ECC压缩非压缩点格式转换仓颉

This directory serves as a technical repository for developers utilizing the Cangjie programming language in conjunction with the CryptoArchitectureKit, with a specific focus on Elliptic Curve Cryptography (ECC) point format conversions. It addresses the critical need to manipulate compressed and uncompressed point data, a common requirement in modern cryptographic systems. The documentation provides step-by-step instructions for converting raw byte arrays to Point objects, generating public keys from compressed data, and retrieving specific coordinate information. These resources are highly suitable for Cangjie developers, security engineers, and system architects implementing secure key exchange protocols or digital signature schemes, particularly those working with standard curves such as NID_brainpoolP256r1.

## Detailed Description

### 使用ECC压缩非压缩点格式转换仓颉_2more.md 使用ECC压缩非压缩点格式转换仓颉_2more.md
This technical guide explains how to convert between compressed and uncompressed ECC point data formats using the Cangjie programming language and CryptoArchitectureKit. It covers the conversion process from raw byte arrays to Point objects and back, specifically detailing how to transform uncompressed data into compressed format. The document highlights the use of ECCKeyUtil.convertPoint to generate point objects and ECCKeyUtil.getEncodedPoint with a format parameter ("COMPRESSED" or "UNCOMPRESSED") to retrieve the desired byte representation. A practical code example demonstrates this workflow using the NID_brainpoolP256r1 curve. This guide is intended for Cangjie developers implementing cryptographic key generation and conversion who need to manipulate ECC point data structures.

### 指定压缩点数据获取密钥对象.md 指定压缩点数据获取密钥对象.md
This tutorial demonstrates how to generate an ECC public key object from compressed point data using the CryptoArchitectureKit in the Cangjie programming language. The document outlines a sequential process involving data conversion, parameter specification, key generation, and data extraction. Key steps include using convertPoint to process raw data, genECCCommonParamsSpec for curve parameters, and generatePubKey to create the key object. It also details retrieving uncompressed point data and the X coordinate using getEncodedPoint and getAsyKeySpec. This guide is intended for developers implementing cryptographic operations, specifically those working with ECC curves like NID_brainpoolP256r1.
