This directory acts as a central hub for API documentation regarding a robust process management package. It provides detailed references for creating, controlling, and managing system processes across different operating systems. Key topics include functions for process execution, class definitions for process entities, stream redirection enums, and specific exception classes for error handling. Furthermore, it offers in-depth guidance on cross-platform compatibility, highlighting differences in behavior between Linux, Windows, and macOS, as well as essential migration paths for deprecated APIs. This resource is designed for developers who need to implement complex system-level operations, manage subprocess lifecycles, and ensure their applications adhere to the latest API standards while maintaining broad OS support.
