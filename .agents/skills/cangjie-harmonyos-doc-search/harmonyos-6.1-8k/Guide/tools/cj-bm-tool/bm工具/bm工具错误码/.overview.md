# bm工具错误码

本目录汇集了HarmonyOS/OpenHarmony应用开发中Bundle Manager (bm)工具相关的错误码排查文档。内容涵盖应用安装、卸载、签名验证、权限配置、HAP/HSP包管理及Native库解析等常见故障。文档详细分析了各类错误代码的成因，并提供了具体的修复步骤，如修改配置文件、重新签名或使用hdc命令。主要面向应用开发者和测试人员，旨在帮助快速定位并解决应用部署过程中的技术问题。
