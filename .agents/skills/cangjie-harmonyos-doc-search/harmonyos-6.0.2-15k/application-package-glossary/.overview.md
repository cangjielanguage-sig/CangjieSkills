# application-package-glossary

This directory provides a specialized glossary focused on the terminology used in HarmonyOS application packages and the Stage model. It is designed to assist developers in understanding the specific language and concepts that define the architecture of HarmonyOS applications. The glossary covers a broad spectrum of terms, including various package types such as HAP, HAR, and HSP, as well as fundamental components like UIAbility and ExtensionAbility. Additionally, it addresses architectural nuances, such as the differences between static and dynamic shared packages, and details the composition of HAP files. This resource is ideal for HarmonyOS developers who need a reliable reference to clarify terminology and gain a deeper understanding of application structure and packaging mechanisms.

### application-package-glossary.md application-package-glossary.md
This document serves as a glossary defining key terminology related to HarmonyOS application packages and the Stage model. It covers terms alphabetically, focusing on package types (HAP, HAR, HSP), components (UIAbility, ExtensionAbility), and architectural concepts (Stage Model, Module). Key information includes the distinction between static (HAR) and dynamic (HSP) shared packages, the composition of HAP files, and the specific roles of UIAbility and ExtensionAbility components in user interaction and extended scenarios. This reference guide is intended for HarmonyOS developers needing to understand application structure and packaging concepts.
