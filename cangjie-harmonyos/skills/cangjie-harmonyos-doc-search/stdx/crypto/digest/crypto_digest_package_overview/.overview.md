# crypto_digest_package_overview

本目录提供了 `stdx.crypto.digest` 包的全面技术概述，重点涵盖了 MD5、SHA 系列、HMAC 以及国密 SM3 等常用消息摘要算法。文档不仅详细介绍了各类加密算法的功能特性，还深入讲解了 OpenSSL 3 依赖库在 Linux、Windows 和 macOS 三大主流操作系统上的安装流程与环境变量配置（如 LD_LIBRARY_PATH 和 PATH）。此外，文档还提供了完整的 API 列表、HashType 结构体定义及 CryptoException 异常处理说明。这份资料是开发人员在集成加密功能前配置运行环境及查阅接口规范的必备指南。
