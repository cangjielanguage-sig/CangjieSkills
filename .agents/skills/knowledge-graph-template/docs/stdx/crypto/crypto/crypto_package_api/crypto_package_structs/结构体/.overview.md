# 结构体

本目录包含Cangjie语言中用于对称加密的核心结构体API参考文档。主要涵盖了定义加密算法工作模式的`OperationMode`结构体以及定义填充策略的`PaddingMode`结构体。文档详细介绍了ECB、CBC、GCM等常见加密模式，以及PKCS7等填充方式，并包含相关的属性和成员函数说明。这些内容适合需要在Cangjie项目中实现或调用对称加密功能的开发者，帮助他们正确配置加密参数。

## 详细描述

### struct_OperationMode.md
该文档是Cangjie语言中OperationMode结构体的API参考文档，用于定义对称加解密算法的工作模式。文档详细列出了ECB、CBC、OFB、CFB、CTR和GCM六种静态常量模式，以及mode属性和toString、相等性比较等成员函数。关键信息在于该结构体实现了ToString和Equatable接口，支持将模式转换为字符串及比较操作，涵盖了从基础的ECB到支持认证加密的GCM等多种加密模式。主要面向需要在Cangjie项目中实现或调用对称加密功能的开发者，需具备基本的密码学概念。

### struct_PaddingMode_095e5b0c.md
本文档是关于 PaddingMode 结构体的 API 参考文档，旨在定义对称加解密算法的填充模式。主要内容包括结构体定义、继承自 Equatable 协议、静态常量 NoPadding 和 PKCS7Padding 的具体说明，以及 paddingType 属性和相等性操作符（==、!=）的用法。关键信息指出了两种填充模式对应的初始值（0 和 1）及其比较逻辑。该文档面向使用加密功能的开发人员，帮助其理解和配置加密算法的填充策略。
