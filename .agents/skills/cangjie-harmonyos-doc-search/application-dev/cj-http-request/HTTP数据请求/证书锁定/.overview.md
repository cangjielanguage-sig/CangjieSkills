# 证书锁定

This directory focuses on Certificate Pinning (证书锁定), a critical security mechanism designed to protect mobile applications from Man-in-the-Middle (MitM) attacks by strictly restricting HTTPS connections to specific, trusted certificates. It covers the technical implementation of network security configurations using JSON, specifically tailored for the HarmonyOS framework. Key topics include defining trust anchors, configuring domain rules, and utilizing SHA256 hash algorithms for public key pinning. Additionally, it addresses the operational risks associated with certificate updates. This resource is essential for mobile developers and system administrators aiming to harden application network security and enforce strict trust policies to ensure data integrity.

### 证书锁定_3more.md 证书锁定_3more.md
This technical guide explains how to implement certificate pinning to secure HTTPS connections by restricting them to specific developer-defined certificates. The document covers two primary methods: pre-setting application-level certificates (crt/pem files) and pre-setting certificate public key hashes, alongside instructions for fetching domain certificates using OpenSSL. Configuration occurs in `network_config.json`, with a critical warning that server certificate updates will cause connection failures unless the app is updated, as the system matches all hashes in the certificate chain. Detailed OpenSSL commands are provided for extracting public keys and calculating SHA256 hashes. This guide targets mobile application developers using the HarmonyOS framework who need to enhance network security.
