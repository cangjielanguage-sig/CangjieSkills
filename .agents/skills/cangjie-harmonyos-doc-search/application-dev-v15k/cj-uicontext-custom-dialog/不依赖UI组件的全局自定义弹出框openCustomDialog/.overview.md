# 不依赖UI组件的全局自定义弹出框openCustomDialog

This directory serves as a specialized resource for HarmonyOS developers working with the Cangjie language, focusing on the implementation of global custom dialogs via the `PromptAction.openCustomDialog` interface. It addresses the limitations of the standard `CustomDialogController` by offering a decoupled approach that supports dynamic UI updates and complex application scenarios. The documentation covers critical technical aspects, including the dialog lifecycle sequence, dual parameter input methods, and ID-based management for opening and closing modals. This collection is ideal for ArkUI developers seeking to master flexible, state-driven popup mechanisms and integrate them seamlessly into their application architecture without relying on rigid UI component dependencies.

## Detailed Description

### 不依赖UI组件的全局自定义弹出框openCustom_3more.md
This technical guide explains how to implement global custom dialogs in Cangjie using the PromptAction.openCustomDialog interface, offering a flexible alternative to the restrictive CustomDialogController. Key sections cover the two parameter input methods, the dialog lifecycle sequence, and procedures for opening and closing dialogs using unique IDs. The document provides Cangjie code examples demonstrating dynamic creation and management. It targets ArkUI developers seeking decoupled, dynamically updatable UI components for complex application scenarios.

### 完整示例.md
This document provides a complete code example demonstrating how to implement and manage custom dialogs using the Cangjie language in a HarmonyOS application context. The content covers the definition of custom dialog builders using the @Builder decorator, the setup of the main UI layout with trigger buttons, and the logic for opening and closing dialogs via PromptAction. Key takeaways include using PromptAction.openCustomDialog with CustomDialogOptions to display content and storing the returned ID to enable closing the dialog programmatically. This example targets Cangjie developers building UIs who need practical guidance on implementing modal interactions and state management within the ArkUI framework.
