This directory contains API reference documentation for the `ohos.settings` module in the Cangjie programming language, specifically focusing on data item names and retrieval functions for HarmonyOS system settings. It covers enumerations for Date, DomainName, and Display settings, alongside the generic `getValue` function used to fetch these configurations. Key topics include system time formats, display properties like brightness and screen timeout, and data scoping between device-shared and user-specific domains. This documentation is intended for HarmonyOS application developers and system engineers who need to integrate system settings management, such as reading date formats or adjusting display preferences, into their Cangjie-based applications using the BasicServicesKit.
