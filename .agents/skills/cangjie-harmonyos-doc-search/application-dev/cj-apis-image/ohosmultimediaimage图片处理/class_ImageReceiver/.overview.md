# class_ImageReceiver

This directory contains comprehensive API reference documentation for the Cangjie `ImageReceiver` class, a critical component within the ImageKit framework designed to receive images from external producers such as cameras. It covers the full lifecycle of image reception, including defining receiver properties, managing surface IDs, registering event callbacks, and handling image reading operations. Key topics include memory management, buffer lifecycles, error handling, and system capabilities. This documentation is suitable for developers implementing multimedia image handling in Cangjie who need to manage surface interactions, process asynchronous image data, and ensure efficient resource allocation and deallocation.

### class_ImageReceiver_5more.md class_ImageReceiver_5more.md
This document serves as API reference documentation for the Cangjie ImageReceiver class, designed to receive images from producers like cameras. It covers read-only properties including capacity, format, and size, alongside the getReceivingSurfaceId method for obtaining surface IDs. Key takeaways emphasize that ImageReceiver acts as a consumer where image attributes are determined by the producer, and instances must be manually released to free memory. The content includes error handling details and usage examples, targeting developers implementing multimedia image handling who need to manage surface interactions and memory resources.

### func_onReceiveType_Callbac_2more.md func_onReceiveType_Callbac_2more.md
This API reference document details the registration and removal of event callbacks for image reception within the Cangjie development environment. It covers two primary functions: on, which registers a callback for the ImageArrival event, and off, which removes the registered callback to release buffers. Key information includes parameter definitions, system capabilities, and version requirements (version 22), alongside practical Cangjie code examples demonstrating implementation. Targeted at developers working with multimedia image handling, specifically those managing image receivers and buffer lifecycles using the ImageKit.

### func_release_3more.md func_release_3more.md
This document provides API reference documentation for the Cangjie language, specifically detailing methods for the ImageReceiver class. It covers three main functions: release() for manually freeing memory to prevent leaks, readLatestImage() to retrieve the newest image, and readNextImage() to fetch the subsequent image. Key information emphasizes that read operations must be triggered after specific callbacks and that returned Image objects must also be released to allow new data reception. The content includes system capabilities, error codes, and usage examples. This guide targets developers using the ImageKit who need to manage image buffers and system resources efficiently.
