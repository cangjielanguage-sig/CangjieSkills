This document provides a code example demonstrating how to integrate Cangjie UI components with Native C++ graphics rendering using the XComponent. It covers the Cangjie implementation, including Foreign Function Interface (FFI) definitions, a custom XComponentController for lifecycle management, and the main UI layout with interactive buttons. The code illustrates passing SurfaceId to the Native side to create a NativeWindow and EGL/GLES environment, enabling drawing and color changing on the main page. This tutorial targets developers familiar with Cangjie and Native interop who need to implement high-performance graphics rendering in HarmonyOS applications.

Keywords: XComponent, Cangjie, NativeWindow, EGL, GLES, FFI, HarmonyOS, SurfaceId, Graphics Rendering

### native代码/
This directory contains C++ source code and documentation for native graphics rendering on HarmonyOS and OpenHarmony systems. It focuses on integrating hardware-accelerated 2D/3D graphics using OpenGL ES 3.0 and the NativeXComponent API. The content covers the complete graphics pipeline, including EGL context management, native window handling, and plugin lifecycle operations. Key components include wrappers for EGL contexts, managers for surface IDs, and renderers for drawing geometric patterns. This material is suitable for C++ developers and graphics engineers working on high-performance visual effects in native environments.
