This directory contains API reference documentation and usage guides for the `ohos.telephony_call` module and `TelephonyKit` framework in the Cangjie programming language. It covers essential telephony operations such as dialing numbers, managing call states, formatting phone numbers, and handling emergency calls. The content includes data structures like `NumberFormatOptions` and `CallState`, along with practical implementation examples. It is suitable for Cangjie developers building HarmonyOS applications who need to integrate robust telephony features, manage system permissions, and handle call-related exceptions within their software.
