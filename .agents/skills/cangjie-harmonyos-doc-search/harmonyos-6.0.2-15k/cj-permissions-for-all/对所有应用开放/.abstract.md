This directory provides comprehensive documentation for permissions available to all applications within the HarmonyOS development environment. It encompasses the general workflow for applying for permissions, detailed lists of user-granted permissions involving sensitive data, and system-granted permissions for hardware and network access. Key topics include runtime permission requests, access control lists (ACL), protection levels, and security attributes. This resource is specifically designed for application developers who need to implement secure access to device features, ensuring compliance with privacy standards and optimizing the development process for permission handling. It serves as a central hub for understanding both user and system authorization mechanisms.
