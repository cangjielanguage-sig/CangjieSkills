# 示例1嵌套滚动

This directory contains code examples and tutorials demonstrating how to implement nested scrolling functionality across different UI frameworks, specifically Cangjie and ArkUI (ArkTS). It focuses on resolving gesture conflicts between parent and child scrollable components using techniques like `shouldBuiltInrecognizerParallelWith` and dynamic recognizer control. The examples illustrate logic where inner components handle gestures first, passing control to outer components at boundaries. Suitable for developers working on HarmonyOS/OpenHarmony applications or using the Cangjie language who need to manage complex touch interactions and smooth scrolling transitions in nested layouts.
