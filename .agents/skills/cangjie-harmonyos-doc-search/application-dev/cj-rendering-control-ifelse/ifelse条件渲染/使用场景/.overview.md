# 使用场景

This directory focuses on practical usage scenarios for conditional rendering within the ArkUI framework using the Cangjie language. It covers the implementation of `if` statements, component lifecycle management during state changes, and state preservation strategies across conditional branches. Key topics include `if...else` logic, nested conditional statements, and the impact of `@State` and `@Link` decorators on child component state. Understanding these scenarios is crucial for building responsive interfaces that maintain data integrity during UI updates. This resource is suitable for Cangjie developers and UI engineers looking to master dynamic UI updates and state management in ArkUI applications.

## Detailed Description

The following documents provide specific examples and technical guidance for implementing conditional logic in your applications.

### if_else_语句和子组件状态.md if_else_语句和子组件状态.md
This technical guide illustrates how conditional rendering with if...else statements impacts state management in child components within the ArkUI framework using Cangjie. It covers two scenarios: state loss when using local @State variables in child components, and state preservation by promoting state to the parent component using @Link. The document demonstrates that switching if-else branches destroys and recreates component instances, resetting local state. To maintain state across conditional changes, developers must move the state variable to the parent component and reference it via @Link. This tutorial targets ArkUI developers familiar with Cangjie syntax and basic state management decorators like @State and @Link.

### 使用if进行条件渲染.md 使用if进行条件渲染.md
This tutorial demonstrates how to implement conditional rendering in ArkUI using Cangjie's if statements. It covers a practical code example involving a counter and explains the component lifecycle mechanism. Key takeaways include that state variable changes trigger condition re-evaluation, causing the framework to delete previously rendered components and construct new ones from the active branch. The document targets developers building dynamic user interfaces, focusing on state-driven UI updates and component management within the ArkUI framework.

### 嵌套if语句.md 嵌套if语句.md
This document serves as a code example demonstrating the implementation of nested conditional statements within the Cangjie ArkUI framework. It specifically illustrates that nesting conditional logic does not affect the rules of parent components. The main topic involves using nested `if` statements inside a `Column` layout to dynamically render different `Text` components based on state variables. Key information includes the use of `@State` decorators for `toggle` and `toggleColor` to control the visibility and content of nested UI elements. This tutorial is designed for Cangjie developers seeking to understand conditional rendering and state management in ArkUI applications.
