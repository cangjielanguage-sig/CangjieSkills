# 基础类型定义

This directory defines fundamental data structures and style classes for the Cangjie ArkUI framework, specifically focusing on sidebar component customization. It covers configuration classes for button styles, divider appearances, and icon management. Key concepts include layout attributes (width, height, margins), visual styling (stroke width, color), and resource handling for UI states. These definitions are essential for developers building ArkUI interfaces who need to fine-tune the visual presentation and behavior of sidebar controls in version 19 environments.

## Detailed Description

### class_ButtonStyle.md class_ButtonStyle.md
This API reference document defines the ButtonStyle class used to configure attributes for sidebar control buttons in the Cangjie programming language. The documentation details the class constructor, which accepts named parameters for layout and styling. Key parameters include left, top, width, and height, all measured in vp units with specific default values, alongside an icons property for managing button states. The class requires SystemCapability.ArkUI.ArkUI.Full and is available starting from version 19. This guide targets developers building ArkUI interfaces who need to customize the appearance and positioning of sidebar control buttons.

### class_SideBarDividerStyle.md class_SideBarDividerStyle.md
This API reference document defines the SideBarDividerStyle class used to configure the visual appearance of divider lines within a SideBar component in the Cangjie ArkUI framework. It details the class properties including strokeWidth, color, startMargin, and endMargin, along with their types and read-only access. It also documents the constructor method for initializing these style attributes. The document specifies default values for margins and color, and includes a note explaining that the divider occupies remaining space and visibility depends on container width thresholds. This technical reference is intended for UI developers building applications with ArkUI, requiring knowledge of Cangjie syntax and layout components.
