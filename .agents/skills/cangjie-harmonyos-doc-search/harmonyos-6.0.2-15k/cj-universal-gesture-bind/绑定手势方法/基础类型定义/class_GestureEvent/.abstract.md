This directory contains API reference documentation for the `GestureEvent` class within the Cangjie language and ArkUI framework. It covers the structural definition and properties of gesture events used to handle user interactions such as rotation, swiping, panning, and pinching. Key topics include event initialization, coordinate calculations, scaling ratios, and velocity metrics. This documentation is suitable for software developers and UI engineers building interactive applications who need to implement sophisticated touch and mouse gesture recognition using the SystemCapability.ArkUI.ArkUI.Full module.
