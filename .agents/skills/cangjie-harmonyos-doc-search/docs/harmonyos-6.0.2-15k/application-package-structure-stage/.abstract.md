This directory serves as a definitive technical guide for understanding the application package structure within the Stage model of HarmonyOS development. It meticulously documents the evolution of an application project from its initial development state in DevEco Studio through the complex structural transformations that occur during compilation and final release. The content delves into critical aspects such as the logical organization of project directories, the specific functions and syntax of essential configuration files like `app.json5` and `module.json5`, and the integration of Cangjie source code. Furthermore, it explains the generation of build artifacts, specifically HAP and HAR files, which are crucial for deployment. This documentation is primarily tailored for HarmonyOS developers—especially those working with the Cangjie language—who require a thorough grasp of project architecture, build mechanisms, and deployment workflows to optimize their application management and ensure successful delivery. By mastering these structural concepts, developers can better navigate the complexities of the HarmonyOS ecosystem, ensuring their applications are built correctly and packaged efficiently for distribution.
