# class_PhotoSession

This directory contains API reference documentation for the `PhotoSession` class within the Cangjie CameraKit framework. It focuses on managing normal photo mode operations in camera applications, covering session initialization, configuration, and event handling. Key topics include preconfiguring resolution and aspect ratios, registering and unregistering callbacks for focus and zoom states, and handling error events. The documentation is intended for developers building multimedia features in HarmonyOS/OpenHarmony using the Cangjie language, providing technical specifications and code examples to implement effective camera control logic.
