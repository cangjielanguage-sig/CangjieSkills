# 构建第一个OpenHarmony应用仓颉

This directory provides a comprehensive guide for developers looking to build their first OpenHarmony application using the Cangjie programming language. It covers the entire development lifecycle, from project initialization and understanding directory structures to building user interfaces with ArkUI and implementing page navigation. Key topics include DevEco Studio configuration, component usage, state management, and deployment settings for both emulators and real devices. This resource is ideal for developers in the Beta phase who are transitioning to OpenHarmony or starting with Cangjie, offering practical code examples and configuration steps to create functional applications.

## Detailed Description

### 仓颉工程目录结构.md 仓颉工程目录结构.md
This reference document outlines the standard directory structure and file organization for Cangjie projects. It details the project tree hierarchy, focusing on the main entry module, which contains source code in the cangjie directory, resources, and module configuration. Key information includes the roles of configuration files like cjpm.toml for package management, module.json5 for stage settings, and hvigor scripts for build automation. It also explains the purpose of AppScope for global settings and oh_modules for dependencies. This guide is intended for Cangjie developers to understand project layout and build configurations effectively.

### 实现页面间的跳转_2more.md 实现页面间的跳转_2more.md
This tutorial guides developers on implementing page navigation and running applications built with the Cangjie language in the OpenHarmony environment. It covers forward and backward navigation using the router module, alongside instructions for running apps on real devices or emulators. Key code examples demonstrate using pushUrl and back methods within onClick events. For x86 emulators, developers must modify build-profile.json5 to include x86_64 in abiFilters alongside the default arm64-v8a. This guide targets OpenHarmony developers using Cangjie, providing essential steps for basic app interaction and deployment.

### 构建第一个OpenHarmony应用仓颉_2more.md 构建第一个OpenHarmony应用仓颉_2more.md
This tutorial guides developers through creating their first OpenHarmony application using the Cangjie programming language within DevEco Studio. It covers the step-by-step process of initializing a project, selecting the Cangjie Empty Ability template, and configuring basic settings. A key takeaway is the necessary modification of the build-profile.json5 file to convert the default HarmonyOS project to an OpenHarmony project by adjusting the runtimeOS and SDK version fields. Intended for developers in the Beta phase, this guide requires the latest DevEco Studio version and focuses on bridging the gap between standard HarmonyOS creation and OpenHarmony deployment.

### 构建第一个页面_2more.md 构建第一个页面_2more.md
This tutorial guides developers through building basic user interface pages using the Cangjie language within the ArkUI framework. It covers constructing the first page by adding Text and Button components to the index.cj file, followed by creating a second page file named second.cj with similar UI elements. Key concepts include using @Entry and @Component decorators, state management with @State, and handling user interactions via onClick events. The document provides complete code examples for layout structures using Row and Column components. Intended for developers beginning HarmonyOS application development with Cangjie, this guide serves as a practical introduction to page creation and component implementation.
