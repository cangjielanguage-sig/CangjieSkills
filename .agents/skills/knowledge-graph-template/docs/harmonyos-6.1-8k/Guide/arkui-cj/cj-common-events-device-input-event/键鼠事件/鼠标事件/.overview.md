# 鼠标事件

本目录包含ArkUI仓颉框架中关于鼠标事件处理的API参考文档。主要涵盖了鼠标交互的核心接口，包括`onMouse`点击事件处理、`onHover`悬停状态监听以及事件冒泡机制。文档详细介绍了MouseEvent对象的属性、按键值定义及输入源区分逻辑。适合需要为应用实现自定义鼠标交互、支持外设设备或优化触控板体验的仓颉语言开发者阅读。
