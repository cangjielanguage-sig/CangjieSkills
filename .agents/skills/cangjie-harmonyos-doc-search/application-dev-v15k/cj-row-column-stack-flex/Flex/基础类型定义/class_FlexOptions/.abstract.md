This directory provides comprehensive API reference documentation for the `FlexOptions` class in the Cangjie language, a critical component for configuring Flex container layouts within the ArkUI framework. It is designed to assist developers in building sophisticated HarmonyOS user interfaces by offering detailed technical specifications on layout properties. The content covers the constructor's signature, system capabilities, and a thorough explanation of parameters such as direction, wrap, justifyContent, alignItems, alignContent, and space. Furthermore, it addresses specific behavioral constraints, such as the requirement for wrapping to enable `alignContent` and the invalidation of `space` under certain justification modes. This documentation is highly suitable for developers and system architects who require precise control over component alignment and spacing strategies in their applications.
