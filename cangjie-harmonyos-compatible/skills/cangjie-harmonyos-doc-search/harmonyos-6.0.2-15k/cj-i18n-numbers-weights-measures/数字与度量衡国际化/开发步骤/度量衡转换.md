### 度量衡转换

单位转换并根据区域和风格进行格式化，通过[I18NUtil](../../API_Reference/source_zh_cn/apis/LocalizationKit/cj-apis-i18n.md#class-i18nutil)类的[unitConvert](../../API_Reference/source_zh_cn/apis/LocalizationKit/cj-apis-i18n.md#static-func-unitconvertunitinfo-unitinfo-float64-string-string)接口实现，具体开发步骤如下。

1. 导入模块。

   ```cangjie
   import kit.LocalizationKit.*
   ```

2. 度量衡转换。

   将度量衡从fromUnit转换到toUnit，数值为value，并根据区域和风格进行格式化。style可取不同的值，显示不同的效果，具体请参见表13。

   ```cangjie
   let convertedUnit: String = I18NUtil.unitConvert(fromUnit: UnitInfo, toUnit: UnitInfo, value: Float64, locale: String, style!: ?String = None)
   ```

**格式化风格**

以fromUnit为美制单位cup，toUnit为公制单位liter，数字大小：1000为例。

**表13** 格式化使用的风格(style)

| 取值 | 显示效果 |
| -------- | -------- |
| long | 236.588 liters |
| short | 236.588 L |
| narrow | 236.588L |

**开发实例**

<!-- run -->

```cangjie
// 导入模块
import kit.LocalizationKit.*

// 设置要转换的单位和目标单位
let fromUnit: UnitInfo = UnitInfo('cup', 'US')
let toUnit: UnitInfo = UnitInfo('liter', 'SI')

// 以en-US区域参数转换度量衡
var convertedUnit: String = I18NUtil.unitConvert(fromUnit, toUnit, 1000.0, 'en-US') // convertedUnit = '236.588 L'

// 显示完整的度量衡
convertedUnit = I18NUtil.unitConvert(fromUnit, toUnit, 1000.0, 'en-US', style: 'long') // convertedUnit = '236.588 liters'
```
