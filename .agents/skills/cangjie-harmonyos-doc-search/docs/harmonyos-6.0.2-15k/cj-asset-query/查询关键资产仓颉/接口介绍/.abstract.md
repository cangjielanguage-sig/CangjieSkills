This directory contains technical documentation for the AssetStoreKit API, focusing on the management and querying of key assets. It covers the `query` function interface, attribute parameter definitions for access control and persistence, and detailed query options for pagination and sorting. Key topics include data security constraints (specifically regarding unencrypted custom fields), API versioning updates (API 12), and storage classifications. This documentation is intended for developers and system integrators who need to implement secure asset storage, synchronization, and retrieval functionalities within their applications.
