This directory focuses on the Model-View-ViewModel (MVVM) architecture pattern within the context of HarmonyOS ArkUI development using the Cangjie language. It covers theoretical principles, layer separation, and practical implementation through a memo application tutorial. Key topics include state management, component decoupling, and scalable application structuring. Designed for developers with prior knowledge of State Management V1, this resource aims to improve code maintainability and development efficiency in complex projects by enforcing clean architecture standards.
