This directory contains API reference documentation for the `ohos.nfc.cardEmulation` module in HarmonyOS, specifically designed for the Cangjie programming language. It covers Host Card Emulation (HCE) functionality, allowing applications to simulate NFC cards without secure elements. Key topics include enumerations for card types and events, functions to check device capabilities and default service status, and the `HceService` class for managing APDU data exchange. This documentation is suitable for developers building NFC-based payment or access applications who need to implement card emulation, handle reader commands, and manage service lifecycles within the HarmonyOS ecosystem.
