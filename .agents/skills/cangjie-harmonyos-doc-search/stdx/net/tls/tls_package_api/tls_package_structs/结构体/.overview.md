# 结构体

本目录包含 Cangjie 语言 TLS 库中核心结构体的 API 参考文档。内容涵盖了 TLS 协议实现所需的关键数据结构，包括客户端与服务端配置、密码套件定义以及会话管理。这些文档详细说明了各结构体的属性、方法及使用规范，旨在帮助开发者构建安全、高效的网络通信应用。适用于从事 Cangjie 网络编程及 TLS 安全协议实现的开发人员。

## 详细描述

### struct_CipherSuite_9192ada4.md struct_CipherSuite_9192ada4.md
本文档是Cangjie语言TLS库中CipherSuite结构体的API参考文档，旨在定义和描述TLS协议中的密码套件。文档主要内容包括结构体的基本定义、继承的ToString和Equatable接口，以及allSupported静态属性、toString方法和相等性运算符的详细说明。关键信息在于该结构体提供了获取所有支持密码套件列表、获取套件名称以及比较套件对象的功能。文档面向使用Cangjie进行网络通信开发的程序员，特别是涉及TLS安全协议实现的场景，要求读者具备Cangjie语法基础及TLS相关概念。

### struct_TlsClientConfig.md struct_TlsClientConfig.md
这份文档是Cangjie语言中TlsClientConfig结构体的API参考说明，旨在定义TLS客户端的连接配置。文档涵盖了核心属性如密钥日志回调、证书验证模式、ALPN协议、TLS 1.2及1.3加密套件、客户端证书、域名SNI、协议版本范围、安全级别和签名算法。关键要点包括设置协议版本时需避免逻辑冲突以防止握手异常，以及部分属性对空字符的严格校验。该文档面向需要实现安全网络通信的开发者，提供了构建TLS客户端所需的详细配置规范。

### struct_TlsSession_44c11c53.md struct_TlsSession_44c11c53.md
本文档是 Cangjie 语言中 TlsSession 结构体的 API 参考文档，旨在说明如何表示和管理已建立的客户端 TLS 会话。文档涵盖了结构体定义、继承的父类型以及 hashCode、toString 和相等性比较操作符等核心成员函数。关键信息指出该结构体实例由系统在握手成功后生成，用户不可创建，主要用于通过会话 ID 复用连接以省略握手流程。该文档面向进行 TLS 网络编程的开发者，提供了会话状态管理与比较的接口说明。

### struct_TlsServerConfig/
本目录包含仓颉语言中 `TlsServerConfig` 结构体的 API 参考文档，用于定义和配置 TLS 服务端参数。内容涵盖了应用层协议协商（ALPN）、加密套件、证书验证、协议版本范围及安全级别等核心配置项。该文档详细介绍了初始化构造函数、属性定义及异常处理机制，适用于需要构建安全 TLS 连接、进行精细化网络编程的后端开发人员。
