# class_BundleInfo

This directory provides essential API reference documentation for the `BundleInfo` class in the Cangjie programming language, focusing on the data structures required for managing application bundle information. It covers a broad spectrum of read-only properties, such as bundle names, version codes, installation times, application configurations, module details, and permission states. The documentation also explains the mechanisms for data retrieval, specifically the `getBundleInfoForSelf` method, and highlights the availability of features across different API versions (12 and 19). Furthermore, it addresses specific metadata needs, including signature information, vendor identity, and system identifiers like UIDs. This resource is tailored for application developers and software engineers who need to integrate robust metadata queries, manage runtime configurations, and ensure security verification within their Cangjie-based applications. By utilizing these references, developers can effectively handle application lifecycle management and ensure compliance with system security requirements.
