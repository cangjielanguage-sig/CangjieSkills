### synchronized_关键字.md synchronized_关键字.md
本文档旨在介绍仓颉编程语言中用于简化并发控制的 synchronized 关键字。文档主要涵盖了该关键字与 Lock 实例的配合使用方法、自动加锁与解锁的执行机制，以及在遇到控制转移表达式（如 break、throw）时的锁释放行为。核心信息在于 synchronized 能确保代码块执行前后自动管理锁的生命周期，从而避免手动解锁遗漏或异常导致的资源占用。这是一份面向具备基础多线程知识的仓颉开发者的技术指南，重点在于提升代码的安全性与便利性。

### 原子操作_Atomic.md 原子操作_Atomic.md
本文档介绍了仓颉语言中针对整数、布尔值及引用类型的原子操作，用于保障多线程数据安全。内容涵盖整数类型的读写、交换及算术运算（如fetchAdd），以及布尔和引用类型的读写与交换，并提供了多线程计数等代码示例。关键信息包括操作返回修改前的值、compareAndSwap的逻辑及顺序一致性内存排序。该文档面向仓颉语言开发者，作为实现并发安全操作的API参考指南。
