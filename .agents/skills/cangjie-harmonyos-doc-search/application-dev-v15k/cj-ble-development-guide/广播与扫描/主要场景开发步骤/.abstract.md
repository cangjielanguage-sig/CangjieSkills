This directory serves as a comprehensive technical guide for developers navigating the primary development scenarios within Bluetooth Low Energy (BLE) ecosystems. It details the step-by-step procedures required to establish, manage, and optimize wireless communication links between devices. The content specifically addresses the dual aspects of BLE interaction: broadcasting a device's presence to the outside world and scanning the environment to detect other devices. By covering the full lifecycle of these operations—from initialization and parameter configuration to data parsing and resource cleanup—this documentation ensures developers can build stable and efficient connectivity solutions. It is designed for software engineers using Cangjie, ArkTS, or similar frameworks targeting HarmonyOS and OpenHarmony platforms who require a deep understanding of BLE protocol implementation, state management, and data handling. The guides provided here are essential for creating applications that rely on seamless device discovery and interconnectivity.
