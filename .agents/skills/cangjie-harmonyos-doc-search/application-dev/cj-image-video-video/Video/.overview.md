# Video

This directory contains comprehensive documentation for the Video component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers essential aspects of video playback, including component initialization, configuration, state management, and event handling. Developers will find API references for data structures like `VideoController`, `FullscreenInfo`, and `PlaybackInfo`, alongside practical code examples for implementing controls such as play, pause, seek, and fullscreen toggling. This resource is suitable for HarmonyOS developers looking to integrate robust video functionality into their applications using Cangjie.

## Detailed Description

### Video_7more.md Video_7more.md
This document provides API reference documentation for the Video component within the ArkUI framework, designed for basic video playback and control in Cangjie applications. It details the module import, required internet permissions for network videos, and the component initialization process. Key sections cover the constructor parameters, such as video source and controller, alongside configuration methods for auto-play, looping, muting, and object fitting. The documentation notes that the component is currently in Beta and supports only simple playback scenarios, targeting developers seeking to integrate standard video functionality into their user interfaces.

### 基础类型定义.md 基础类型定义.md
This API reference document defines fundamental data structures and control interfaces for video playback within the Cangjie ArkUI framework. It details four main classes: FullscreenInfo, PlaybackInfo, and PreparedInfo for state management, and VideoController for playback manipulation. Key functionalities include tracking fullscreen status, playback progress, and video duration, alongside methods to start, stop, pause, seek, and toggle fullscreen modes. All elements support SystemCapability.ArkUI.ArkUI.Full starting from version 22. This technical reference is intended for Cangjie developers building video applications requiring granular playback control.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating how to implement and control a Video component using the Cangjie language in an ArkUI environment. It covers component initialization, state management for playback settings, and the implementation of a VideoController to handle user interactions. The code illustrates essential video operations including starting, pausing, stopping, toggling fullscreen, seeking to specific timestamps, and adjusting playback speed. This example is intended for HarmonyOS developers using Cangjie who need to integrate video playback functionality into their applications.

### 组件事件/
This directory provides essential API reference documentation for handling component events, specifically focusing on video playback controls within the ArkUI framework using the Cangjie language. It covers a comprehensive set of event callbacks designed to monitor and respond to player status changes. Key topics include error handling, playback lifecycle events (such as start, pause, finish, and seeking), and fullscreen mode transitions. The documentation details function signatures, parameter types like PreparedInfo and FullscreenInfo, and return values that support method chaining. This resource is intended for developers building video applications who need to implement robust event listeners and manage player behavior programmatically.
