# compile_and_build

This directory functions as a comprehensive technical repository dedicated to the compilation and build processes within the Cangjie programming language ecosystem. It provides extensive documentation covering the core toolchain, including the `cjc` compiler, the `cjpm` project manager, and advanced conditional compilation techniques. The content is designed to guide developers through the entire software development lifecycle, from writing source code and managing dependencies to generating optimized executable files. It addresses specific needs such as understanding compiler frontends, configuring build outputs, and implementing conditional logic for cross-platform compatibility. This documentation is primarily suitable for Cangjie language developers, build engineers, and systems programmers who require a thorough understanding of the build mechanisms, command-line interfaces, and optimization strategies available in the Cangjie environment.

## Detailed Description

The following sections provide in-depth information regarding the specific tools and features available for building Cangjie projects.

### [1] cjc_usage/
This directory primarily contains usage guides and documentation for the Cangjie programming language compiler, `cjc`. The documentation details the basic functions of the `cjc` command, the differences between it and the frontend compiler `cjc-frontend`, as well as specific compilation syntax and examples. Content covers the complete compilation process from source code to executable files, the linking process, and custom configuration of output files. This document is suitable for Cangjie language developers, compiler tool users, and technical personnel who need to understand the build process, aiming to help users quickly master command-line compilation operations and understand the compiler's working mechanisms and option configurations.

### [2] cjpm_usage/
This directory serves as a comprehensive guide for the Cangjie language's official project management tool, `cjpm`. It is designed to help developers understand the tool's role as a unified compilation entry point and a robust dependency management system.

### [3] conditional_compilation/
The `conditional_compilation` directory is a specialized resource focused on the conditional compilation capabilities of the Cangjie programming language. It provides essential guidance for developers looking to optimize their build processes by selectively compiling code based on specific conditions.
