This directory provides API reference documentation for the `CustomDialogOptions` class within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers the configuration of custom dialog properties, including dimensions, borders, shadows, background styles, and lifecycle callbacks. The documentation details various constructors for initialization, ranging from basic empty instances to comprehensive configurations involving layout positioning and visual styling. This resource is suitable for HarmonyOS UI developers and engineers who need to implement and customize modal and non-modal dialog interfaces, popup components, and transition effects in their applications.
