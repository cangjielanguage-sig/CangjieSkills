# cj-web-debugging-with-devtools

This directory serves as a specialized resource for debugging front-end pages within HarmonyOS applications using Chrome DevTools. It comprehensively covers the technical workflow required to inspect web components, starting from enabling debugging switches and configuring necessary permissions to establishing stable connections via the `hdc` tool. The content highlights critical topics such as remote debugging for mobile devices, creating automation scripts for port forwarding, and resolving common connectivity issues. It is specifically designed for front-end developers and HarmonyOS engineers who need to efficiently inspect, debug, and optimize web components running in the ArkWeb environment, ensuring smooth performance and user experience.
