This directory contains comprehensive documentation for the ImageAnimator component within the ArkUI framework, designed for implementing frame-by-frame image playback in HarmonyOS applications. It covers essential technical specifications, including API references, basic type definitions, practical code examples, event handling, and detailed component properties. Targeted at developers using the Cangjie language, these resources provide the necessary tools to integrate and control custom frame animations, manage image sequences, and handle animation lifecycle events effectively. This collection is ideal for UI engineers and system architects seeking to enhance user interface interactivity through dynamic visual effects.
