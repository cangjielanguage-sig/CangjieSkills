This directory contains API reference documentation for fundamental type definitions used within the ArkUI framework and Cangjie language. It primarily focuses on components and configurations related to the Swiper control, including navigation indicators (arrows, digits, dots), animation controllers, transition proxies, and display modes. These definitions allow developers to customize the appearance, behavior, and layout of carousel and slider interfaces. Suitable for ArkUI developers and UI engineers using Cangjie, this documentation provides the necessary structural details to implement dynamic, responsive, and visually polished user interface components.
