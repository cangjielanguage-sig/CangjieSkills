This directory contains comprehensive documentation for the `FuzzDataProvider` class within the Cangjie programming language. It serves as a utility class designed to facilitate fuzzing operations by converting raw mutation data byte streams into standard Cangjie basic data types. The documentation covers the class structure, public properties, and a wide array of methods for consuming data types such as integers, booleans, and strings. Additionally, it details error handling mechanisms, specifically the `ExhaustedException`. This resource is essential for developers and security engineers building fuzzing frameworks who require a mechanism to interpret byte sequences as structured data programmatically.
