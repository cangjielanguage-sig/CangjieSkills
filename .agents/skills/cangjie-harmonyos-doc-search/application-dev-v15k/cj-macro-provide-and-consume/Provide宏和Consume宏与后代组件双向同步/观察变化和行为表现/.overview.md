# 观察变化和行为表现

This directory provides an in-depth technical examination of state observation and behavioral patterns within the Cangjie UI framework. It is designed to help developers understand the complex mechanisms behind UI reactivity, focusing on how the framework detects data changes and manages rendering cycles. The content covers critical concepts such as dependency injection, state synchronization using decorators like @Provide and @Consume, and the implementation of minimal rendering for performance optimization. Furthermore, it details the specific rules for observing changes in different data types, including primitives, collections, and complex objects. This documentation is highly suitable for advanced developers and framework engineers who need to debug state issues or optimize application performance through a thorough understanding of the framework's internal operations.

## Detailed Description

### 框架行为.md 框架行为.md

This technical reference document details the internal framework behavior regarding state management and rendering cycles using @Provide and @Consume decorators. It covers two main phases: initial rendering and data change handling. During initial rendering, the document explains how variables are registered in a map and how dependency injection occurs via constructors. For data changes, it describes the mechanism of dependency recording, change notification, and the UI update process involving markNeedUpdate and CustomView.rerender. Key takeaways include the implementation of minimal rendering through recursive subProps_ updates. This guide targets advanced developers or framework engineers seeking to understand the underlying mechanics of state synchronization and rendering optimization.

### 观察变化.md 观察变化.md

This technical guide explains the observation rules for state changes across different data types in the Cangjie UI framework. It details how decorators monitor value updates for primitives, element changes in collections, and specific method calls or assignments for complex types like DateTime, HashMap, HashSet, and function variables. The document includes practical code examples demonstrating reactive updates using @Provide and @Consume decorators. It serves as a reference for developers to ensure proper UI reactivity when managing application state.
