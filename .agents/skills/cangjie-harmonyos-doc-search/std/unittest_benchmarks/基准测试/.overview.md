This directory contains comprehensive documentation for the Cangjie language's benchmarking framework. It covers the fundamentals of writing performance tests using the `@Bench` macro, strategies for obtaining reliable results, and the internal algorithms used for measurement precision. The content also explores advanced topics such as parametric benchmarking, custom measurement sources, and detailed reporting. Key concepts include statistical analysis, overhead elimination, data state management, and compiler optimization handling. This resource is suitable for Cangjie developers and performance engineers seeking to implement accurate performance testing, optimize code efficiency, and gain granular insights into system behavior.

## Detailed Description

### 基准测试入门.md 基准测试入门.md
This document serves as a tutorial introducing the benchmarking capabilities of the Cangjie unit testing framework. It details the framework's internal features for ensuring result reliability, such as managing warmup, repetition, and reducing garbage collection noise. The text explains how to construct benchmarks using the `@Bench` macro and provides a code example. Key takeaways include the automatic handling of statistical analysis and framework overhead. Users can execute these tests via the `--bench` option or `cjpm bench` command. This guide is intended for Cangjie developers looking to implement performance testing.

### 如何取得理想结果.md 如何取得理想结果.md
This guide explains how to minimize execution time variance to obtain reliable and reproducible benchmarking results. It covers the interpretation of the Err% metric and details external factors affecting results, such as compiler optimizations, background CPU tasks, I/O operations, unnecessary code optimizations, side effects, and memory allocation. Key takeaways include that an Err% under 3% indicates reliability, while over 10% requires investigation. Users must manage factors like enabling -O2 compiler flags, isolating I/O, ensuring function purity, and managing GC load. The framework provides warnings but cannot guarantee the exclusion of all external influences. This guide targets developers using the benchmarking framework who need to ensure their performance tests are accurate and stable.

### 框架的测试方式.md 框架的测试方式.md
This document outlines the core algorithm and internal logic of a benchmarking framework's testing methodology. It details the pseudo-code implementation of the measureBatchSomeFunc function, the Benchmark class structure, and the execution workflow including warmup, batch size calculation, and statistical analysis. The key takeaway is that the framework isolates actual function execution time by calculating the time difference between batch runs, effectively eliminating overhead from loops and data fetching. This technical reference is intended for developers or performance engineers seeking to understand the framework's measurement precision and internal mechanisms. Keywords: benchmarking, performance measurement, batch processing, overhead elimination, statistical analysis, Cangjie language.

### 参数化基准测试/
This directory serves as a technical guide for implementing parametric benchmarking in the Cangjie language. It covers the essential use of `@Bench` and `@Strategy` macros, offering insights into basic syntax and advanced data generation strategies. The documentation highlights common pitfalls associated with naive data initialization, such as memory allocation issues and garbage collection interference, providing solutions to ensure accurate performance measurement. Additionally, it explains the framework's default behavior regarding input data immutability, ensuring that every function call receives an identical data version for consistency. Key concepts include parametric benchmarking, immutable input, and data state management. This guide is suitable for developers and performance engineers familiar with unit testing who need to write accurate, high-performance benchmarks and manage data states effectively.
