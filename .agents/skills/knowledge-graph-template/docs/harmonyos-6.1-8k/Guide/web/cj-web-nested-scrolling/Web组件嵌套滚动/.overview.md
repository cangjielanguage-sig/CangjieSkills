# Web组件嵌套滚动

本目录包含关于在ArkUI框架中实现Web组件嵌套滚动的技术文档。内容涵盖了`nestedScroll`属性接口的使用、`NestedScrollMode`枚举类型的四种模式（SelfOnly、SelfFirst、ParentFirst、Parallel）以及滚动事件的传递逻辑。文档提供了Cangjie代码示例，并演示了如何动态配置滚动参数。这些资料适合ArkUI开发者，旨在帮助他们处理复杂的父子容器协同滚动交互场景。

## 详细描述

### Web组件嵌套滚动_1.md
本文档旨在说明如何在ArkUI框架中实现Web组件的嵌套滚动，使Web内容与父容器能够协同滚动。主要内容包括应用场景描述、nestedScroll属性接口的使用、NestedScrollMode枚举类型的四种模式（SelfOnly、SelfFirst、ParentFirst、Parallel）、滚动事件的传递逻辑及方向判定规则。文档还列出了支持的容器组件（如List、Grid）和输入方式，并提供了Cangjie代码示例。这是一份面向ArkUI开发者的技术指南，帮助开发者处理复杂的嵌套滚动交互。

### Web组件嵌套滚动_2.md
本文档旨在演示ArkUI中Web组件的嵌套滚动功能实现及效果。文档提供了一个完整的代码示例，展示了在父容器Scroll中嵌套Web组件的布局结构，重点介绍了如何通过按钮动态配置nestedScroll属性中的scrollForward和scrollBackward参数。核心内容涵盖了SelfOnly、SelfFirst、ParentFirst和Parallel四种滚动模式的切换逻辑及其对父子组件滚动优先级的影响。这是一份面向开发者的教程或示例文档，旨在帮助开发者掌握Web组件在复杂滚动场景下的交互控制。
