# 布局约束

This directory provides comprehensive documentation on layout constraints within the ArkUI framework, specifically tailored for the Cangjie language. It covers essential mechanisms for controlling component dimensions and visibility, focusing on the `aspectRatio` method for defining width-to-height ratios and the `displayPriority` function for managing component visibility in Row, Column, or Flex containers. The content explains calculation logic for missing dimensions, invalid value handling, and priority-based hiding mechanisms during space shortages. This resource is suitable for UI developers and engineers working on HarmonyOS applications who need precise control over responsive layout behavior, component rendering logic, and adaptive user interfaces to ensure optimal user experience across different screen sizes.

## Detailed Description

### 布局约束_4more.md 布局约束_4more.md

This document serves as an API reference for layout constraints within the ArkUI framework using the Cangjie language. It details functions to control component dimensions and visibility. The main sections cover the aspectRatio method, available in both Float64 and Int64 overloads, which defines the width-to-height ratio and explains calculation logic when width or height is missing. Additionally, it describes the displayPriority function, which manages component visibility hierarchy in Row, Column, or Flex containers during space shortages. Key takeaways include the invalid value handling for aspect ratios and the priority-based hiding mechanism where lower priority components are hidden first. This guide is intended for UI developers needing precise control over component layout and responsive behavior.

This document provides practical Cangjie code examples demonstrating specific UI layout constraints and properties within a HarmonyOS development context. Key takeaways include understanding how dimensions are calculated based on ratios and how layout engines hide lower-priority items when space is constrained. This guide targets developers using the Cangjie language for UI development, specifically those needing to implement responsive sizing and priority-based rendering logic.
