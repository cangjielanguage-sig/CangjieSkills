This directory defines fundamental data structures and classes used within the Cangjie language and ArkUI framework. It covers essential components for image processing, including error handling, color transformations, and loading results. Key topics include the `CJImageError` class for failure management, `ColorFilter` for matrix-based color adjustments, and `ImageLoadResult` for tracking image loading states and dimensions.
