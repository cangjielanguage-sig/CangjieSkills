This directory contains comprehensive API reference documentation for the `StringBuilder` class in the Cangjie programming language. It covers efficient string construction, including class definitions, properties like capacity and size, and various initialization constructors. The documentation details methods for appending diverse data types (numeric, text, boolean), content manipulation, and capacity management. It highlights performance advantages over standard strings through dynamic resizing and automatic type conversion, exclusively supporting UTF-8 encoding. This resource is suitable for Cangjie developers seeking to optimize string manipulation, memory usage, and understand the nuances of high-performance string operations.
