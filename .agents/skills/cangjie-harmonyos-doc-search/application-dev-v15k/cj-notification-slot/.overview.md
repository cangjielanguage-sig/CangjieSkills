# cj-notification-slot

This directory contains the comprehensive development guide for the `cj-notification-slot` module, a critical resource for developers working within the Cangjie ecosystem to manage system notifications. It focuses on the configuration and management of notification channels, known as slots, which determine how alerts are presented to users across different application contexts. The guide provides in-depth definitions of five specific slot types, including SOCIAL_COMMUNICATION and SERVICE_INFORMATION, and explains their support for various user interface features such as banners, lock screen visibility, and vibration patterns. Furthermore, it details the essential API interfaces—addSlot, getSlot, and removeSlot—necessary for querying and manipulating slot properties programmatically. This documentation is specifically tailored for application developers utilizing the NotificationKit framework who possess a foundational understanding of the Cangjie programming language and module import mechanisms.
