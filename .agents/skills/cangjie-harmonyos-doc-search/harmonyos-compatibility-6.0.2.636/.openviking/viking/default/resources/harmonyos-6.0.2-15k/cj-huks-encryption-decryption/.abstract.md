This directory serves as a technical resource for developers implementing encryption and decryption using the Cangjie programming language within the HarmonyOS ecosystem. It focuses on leveraging the HarmonyOS Universal Keystore Service (HUKS) for secure key management and cryptographic operations. The content covers essential algorithms like AES, RSA, and SM2, guiding developers from key generation to data processing. It is specifically designed for Cangjie developers seeking to integrate robust security features and ensure data protection in their applications through standard and advanced cryptographic techniques.
