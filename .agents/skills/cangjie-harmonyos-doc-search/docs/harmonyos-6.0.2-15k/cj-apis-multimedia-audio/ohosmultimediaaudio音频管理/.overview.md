# ohosmultimediaaudio音频管理

This directory contains comprehensive API reference documentation for the HarmonyOS multimedia audio module, specifically designed for the Cangjie programming language. It covers core audio functionalities including audio capture, rendering, device management, volume control, and session handling. The documentation details various classes, enums, and functions necessary for developing robust multimedia applications, such as configuring audio streams, handling interruptions, and managing audio routing. Suitable for software developers and audio engineers working within the HarmonyOS ecosystem, this resource provides the technical specifications needed to implement advanced audio features using the AudioKit framework.
