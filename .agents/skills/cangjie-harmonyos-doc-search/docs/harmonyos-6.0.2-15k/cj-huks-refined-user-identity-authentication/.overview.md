# cj-huks-refined-user-identity-authentication

This directory serves as a comprehensive resource dedicated to the implementation of fine-grained user identity authentication and access control within the HarmonyOS ecosystem. It specifically addresses the critical need for enhancing HUKS (HarmonyOS Universal Keystore) key security by integrating robust secondary authentication methods, such as biometric verification or lock screen passwords, to authorize specific cryptographic operations. The content delves into technical details including HUKS key generation workflows, the application of the `HUKS_TAG_KEY_AUTH_PURPOSE` attribute, and the configuration of supported encryption modes like AES and SM4. This material is primarily intended for software developers and security engineers who are building secure applications requiring hardware-backed key storage and conditional user verification for sensitive data access.
