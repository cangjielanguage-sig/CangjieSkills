This directory provides comprehensive documentation for the HarmonyOS HiLog logging module within the Cangjie programming language environment. It covers the essential APIs, including the LogLevel enumeration and the Hilog class, enabling developers to implement structured logging for debugging and monitoring application status. Key topics include log severity levels, formatting constraints, privacy tags, and module configuration. This resource is suitable for Cangjie developers and application engineers working with the Performance Analysis Kit to integrate secure and efficient logging mechanisms into their HarmonyOS software projects. It serves as a central hub for understanding how to effectively utilize the SystemCapability.HiviewDFX.HiLog capability.
