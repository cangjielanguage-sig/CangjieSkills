# cj-atm-tool

The `cj-atm-tool` directory serves as the definitive documentation hub for the Access Token Manager (ATM), a powerful command-line utility designed to query application process permissions and access control information. This directory is tailored for developers and system engineers who need to inspect and manage the security permissions of running applications. The content provides a thorough technical reference, beginning with the environment prerequisites necessary for operation, most notably the requirement for the hdc tool. It offers an in-depth breakdown of the `dump` command syntax, which is central to the tool's functionality. Users will find detailed guidance on how to query process information and analyze permission usage types. The documentation highlights the use of specific filters—including token ID, bundle name, process name, and permission name—to refine data retrieval. By supplying practical examples of various command combinations, this guide empowers users to effectively manage and verify access control data, ensuring system integrity and proper permission handling. This resource is crucial for maintaining a secure and well-audited application environment.
