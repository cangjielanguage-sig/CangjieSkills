# cj-universal-attribute-touchtarget

This directory contains the comprehensive API reference documentation for configuring touch hot zones within the Cangjie ArkUI framework. It focuses on the technical implementation of the `responseRegion` and `responseRegionArray` functions, which are essential for developers needing to define single or multiple rectangular touch areas for components that support generic click or gesture events. The documentation covers critical technical details, including the `Rectangle` parameter structure for defining position and size, system capabilities, and specific version requirements. This resource is primarily suitable for ArkUI developers and UI engineers who aim to customize interactive areas, expand click targets beyond the visual component size to improve accessibility, and enhance the overall user experience through optimized touch interaction handling.
