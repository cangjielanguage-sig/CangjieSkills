## 概述

[Context](../../../cj-apis-ability/.overview.md)是应用中对象的上下文，其提供了应用的一些基础信息，例如[resourceManager](../../../cj-apis-resource_manager/.overview.md)（资源管理）、[applicationInfo](../../../cj-apis-bundle_manager/.overview.md)（当前应用信息）、[dir](../../../cj-apis-ability/.overview.md)（应用文件路径）、[area](../../../cj-apis-ability/.overview.md)（文件分区）等，以及应用的一些基本方法，例如[getApplicationContext()](../../../cj-apis-ability/.overview.md)等。[UIAbility](../../../cj-apis-ability/.overview.md)组件和各种[ExtensionAbility](../../../cj-apis-ability/.overview.md)派生类组件都有各自不同的Context类，包括基类Context、[ApplicationContext](../../../cj-apis-ability/.overview.md)、[AbilityStageContext](../../../cj-apis-ability/.overview.md)、[UIAbilityContext](../../../cj-apis-ability/.overview.md)、[ExtensionContext](../../../cj-apis-ability/.overview.md)等。

- 各类Context的获取方式
    - 获取[UIAbilityContext](../../../cj-apis-ability/.overview.md)。每个[UIAbility](../../../cj-apis-ability/.overview.md)中都包含了一个Context属性，提供操作应用组件、获取应用组件的配置信息等能力。

    ```cangjie
    import kit.AbilityKit.{UIAbility, Want, LaunchParam}
    import kit.UIKit.AppLog
    import kit.ArkUI.WindowStage

    class MainAbility <: UIAbility {
        public override func onCreate(want: Want, launchParam: LaunchParam): Unit {
            let abilityContext = this.context
            // ...
        }

        public override func onWindowStageCreate(windowStage: WindowStage): Unit {
            AppLog.info("MainAbility onWindowStageCreate.")
            windowStage.loadContent("EntryView")
        }
    }
    ```

     > **说明：**
     >
     > 页面中获取Ability实例的上下文信息请参见[获取UIAbility的上下文信息](cj-uiability-usage.md#获取uiability的上下文信息)。

    - 获取[AbilityStageContext](../../../cj-apis-ability/.overview.md)（Module级别的Context）。和基类Context相比，额外提供[HapModuleInfo](../../../cj-apis-bundle_manager/.overview.md)、[AbilityConfiguration](../../../cj-apis-ability/.overview.md)等信息。

    ```cangjie
    import kit.AbilityKit.AbilityStage

    class MyAbilityStage <: AbilityStage {
        public override func onCreate(): Unit {
            let abilityStageContext = this.context
            //...
        }
    }
    ```
