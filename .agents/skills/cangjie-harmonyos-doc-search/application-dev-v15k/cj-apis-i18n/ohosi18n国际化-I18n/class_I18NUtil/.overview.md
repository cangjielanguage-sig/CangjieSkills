# class_I18NUtil

This directory contains comprehensive API reference documentation for the `I18NUtil` class, a core component of the LocalizationKit designed for the Cangjie programming language. It focuses on providing robust internationalization (I18N) utilities, enabling developers to handle complex localization tasks such as locale matching, date formatting sequences, and ISO standard code conversions. It is suitable for Cangjie developers who need to implement precise localization features, manage error handling via BusinessException, and ensure compatibility with system capabilities starting from version 19.
