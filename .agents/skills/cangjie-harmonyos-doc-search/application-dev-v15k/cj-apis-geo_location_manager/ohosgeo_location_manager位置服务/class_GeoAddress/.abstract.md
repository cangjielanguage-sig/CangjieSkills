This directory contains comprehensive API reference documentation for the `GeoAddress` class within the Cangjie programming language. It is designed to assist developers in encapsulating and managing geocoding address information efficiently. The content covers a wide range of geographical and administrative data structures, including WGS84 coordinates, country specifics, locality details, and postal codes. It also details descriptive arrays for city and administrative codes. This documentation is essential for software engineers and developers working on location-aware applications who require precise data structuring and parsing capabilities using the SystemCapability.Location.Location.Geocoder capability.
