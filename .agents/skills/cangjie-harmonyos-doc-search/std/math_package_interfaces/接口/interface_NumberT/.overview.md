# interface_NumberT

This directory provides comprehensive API reference documentation for the generic `Number` interface within the Cangjie programming language. It serves as a technical guide for understanding how arithmetic operations are standardized across different numeric types to enable generic programming. The documentation covers the core interface definition, including operator overloading for addition, subtraction, multiplication, division, and unary negation. It also details specific implementations for a wide range of integer and floating-point types, such as IntNative, UInt8, and Float64. Key topics include type hierarchies, polymorphism, and generic constraints. This resource is essential for Cangjie developers, language implementers, and software engineers aiming to utilize generic programming or create custom numeric types that integrate seamlessly with the language's core arithmetic behaviors.
