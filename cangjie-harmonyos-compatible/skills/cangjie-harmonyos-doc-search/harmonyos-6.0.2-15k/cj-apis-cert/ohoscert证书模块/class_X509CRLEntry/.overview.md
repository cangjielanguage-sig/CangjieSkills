# class_X509CRLEntry

This directory provides API reference documentation for the `X509CRLEntry` class in the Cangjie language, focusing on representing revoked certificate objects within X.509 Certificate Revocation Lists (CRL). It covers essential functionality for retrieving issuer details, extension data, revocation dates, and serialized formats. The documentation is tailored for security developers using the DeviceCertificateKit who need to implement certificate validation and revocation logic. Key concepts include cryptography, exception handling, and data encoding, requiring a solid understanding of X.509 standards and Cangjie syntax.
