This directory contains API reference documentation for the `AVCastController` class in the Cangjie programming language. It focuses on managing established audio-video casting sessions within the AVSession framework. The documentation covers essential functionalities such as retrieving playback state, handling event subscriptions (on/off), managing DRM licenses, and sending control commands. Key concepts include `AVPlaybackState`, `AVQueueItem`, and `BusinessException` handling. This resource is suitable for multimedia developers and software engineers building applications that require robust casting control logic, event management, and digital rights management implementation.
