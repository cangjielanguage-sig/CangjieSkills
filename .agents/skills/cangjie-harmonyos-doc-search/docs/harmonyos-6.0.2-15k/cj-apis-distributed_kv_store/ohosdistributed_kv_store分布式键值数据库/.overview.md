# ohosdistributed_kv_store分布式键值数据库

This directory contains API reference documentation for the HarmonyOS Distributed Key-Value Store module in the Cangjie language. It covers the implementation of distributed data management, including database creation, configuration, synchronization, and querying across devices. Key components include KVManager, SingleKVStore, DeviceKVStore, and various data structures like Entry and Schema. This documentation is suitable for developers using the ArkData framework to build applications requiring robust cross-device data consistency, secure storage, and efficient data retrieval mechanisms.

### class_ChangeNotification.md class_ChangeNotification.md
This API reference details the ChangeNotification class, a notification object for data changes within a distributed key-value store system. It covers the class definition, four read-only properties (insertEntries, updateEntries, deleteEntries, deviceId), and the toString method. These properties track data additions, updates, and deletions. This class requires the SystemCapability.DistributedDataManager.KVStore.Core capability and is intended for developers handling change events and device identification.

### class_KVOptions.md class_KVOptions.md
This document details the KVOptions class used to provide configuration information for creating databases. It also supports defining a storage schema, specifying default values, and noting required permissions for distributed data sync.

### class_Query.md class_Query.md
This document serves as API reference documentation for the Cangjie Query class, designed to represent database queries using predicates within the DistributedDataManager.KVStore system. The content details the class constructor init, the getSqlLike method for retrieving query statements, and prefixKey for defining key prefix conditions. It notes the limitation of 256 predicates per Query object and specific system capability requirements for developers constructing search conditions.
