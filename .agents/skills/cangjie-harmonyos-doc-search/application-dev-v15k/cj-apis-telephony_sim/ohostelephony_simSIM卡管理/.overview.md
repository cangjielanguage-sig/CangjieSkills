## Detailed Description

### enum_CardType_2more.md enum_CardType_2more.md
This API reference document defines Cangjie enumerations for telephony card management, specifically CardType and SimState. The CardType section categorizes various SIM card standards, including single-mode (SIM, USIM, RUIM) and dual-mode variants, alongside carrier-specific cards like China Telecom and Unicom. The SimState section outlines operational statuses such as unknown, not present, locked, not ready, ready, and loaded. Both enums provide a getValue() function to retrieve their integer representations. Intended for developers utilizing the TelephonyKit, this documentation supports system capabilities starting from version 19.
