## Detailed Description

### class_JsonArray_9more.md
This document provides API reference documentation for the JsonArray class in the Cangjie programming language, designed to encapsulate and manipulate array-type JSON data. It covers class inheritance from JsonValue, multiple constructors for initialization from lists or empty states, and instance methods for data manipulation. Key functions include add for inserting elements, get for safe index-based retrieval returning Option, getItems for accessing the underlying list, and size for counting elements. The kind method identifies the type as JsArray. This technical reference targets Cangjie developers who need to parse, construct, or interact with JSON structures programmatically.

### func_toJsonString_4more.md
This API reference document details specific functions for converting and manipulating JSON data structures in the Cangjie programming language. It covers the toJsonString overloads for JsonArray, the toString method for JsonString, and the array subscript operator []. The documentation also specifies return types and potential exceptions, such as IllegalArgumentException for invalid formatting parameters or JsonException for out-of-bounds array access. This resource is intended for developers utilizing the JSON encoding package who require precise control over data serialization and element retrieval.
