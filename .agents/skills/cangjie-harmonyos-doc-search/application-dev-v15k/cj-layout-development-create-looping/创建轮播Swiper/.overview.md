# 创建轮播Swiper

This directory provides a comprehensive guide to implementing and customizing the Swiper component for sliding carousels using the Cangjie language within the ArkUI framework. It covers essential topics such as basic configuration, loop playback, auto-play settings, and layout constraints. Additionally, it delves into advanced features like customizing navigation indicators and arrows, implementing custom transition animations, and controlling page switching programmatically. Targeted at UI developers and HarmonyOS developers, these resources offer practical code examples to create dynamic and visually appealing carousel interfaces for home pages and content recommendations.

## Detailed Description

### 创建轮播Swiper_4more.md 创建轮播Swiper_4more.md
This guide explains how to implement and configure the Swiper component for creating sliding carousels in application development. It covers layout constraints, loop playback control, and automatic playback settings. The document details how Swiper sizing behaves based on parent or child dimensions and margins. It explains the loop property for continuous navigation and the autoPlay and interval properties for timed transitions, providing Cangjie code examples for each. This tutorial targets UI developers using the ArkUI framework and Cangjie language who need to implement carousel features for home pages or content recommendations.

### 导航点样式.md 导航点样式.md
This document serves as a guide for customizing the appearance of Swiper navigation indicators and arrows using the Cangjie language. It covers two main areas: configuring navigation dots via the indicator attribute and managing navigation arrows using the displayArrow property. Key takeaways include methods to adjust position, dimensions, colors, and selected states for indicators, as well as controlling arrow visibility, background, and hover behavior. Intended for UI developers, this tutorial provides practical code examples for implementing both default and bespoke navigation styles in Swiper components.

### 自定义切换动画.md 自定义切换动画.md
This document serves as a tutorial for implementing custom switching animations within the Swiper component using the Cangjie language. It focuses on utilizing the customContentTransition API to manipulate page properties frame-by-frame. The content includes a complete code example demonstrating how to dynamically adjust opacity, scale, translation, and zIndex based on the slide position. Key takeaways involve understanding the SwiperContentAnimatedTransition callback and the logic for calculating visual changes during transitions. This guide targets HarmonyOS developers with prior knowledge of Cangjie and UIKit who seek to create advanced, non-standard visual effects for sliding page layouts.

### 页面切换方式_3more.md 页面切换方式_3more.md
This technical tutorial demonstrates advanced configuration and control methods for the Swiper component within the Cangjie ArkUI framework. It covers three primary topics: programmatic page switching using a SwiperController, setting the carousel orientation via the vertical property, and displaying multiple child components simultaneously using the displayCount attribute. Key takeaways include practical Cangjie code examples illustrating controller methods like showNext and changeIndex, as well as property configurations for layout adjustments. Intended for developers familiar with Cangjie syntax, this guide serves as a reference for implementing dynamic and flexible carousel interfaces in application development.
