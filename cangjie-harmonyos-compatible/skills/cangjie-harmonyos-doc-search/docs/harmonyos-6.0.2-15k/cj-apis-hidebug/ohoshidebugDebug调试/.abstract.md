This directory provides API reference documentation for the `ohos.hidebug` module in the Cangjie language, focusing on HarmonyOS debugging and performance analysis. It covers memory metrics (NativeMemInfo, SystemMemInfo), CPU usage, thread profiling, and trace capture capabilities. Key components include the PerformanceAnalysisKit for resource monitoring and the Tags class for system event categorization. Intended for HarmonyOS developers, these tools require the SystemCapability.HiviewDFX.HiProfiler.HiDebug capability (API 19+) to facilitate application optimization and system diagnostics.
