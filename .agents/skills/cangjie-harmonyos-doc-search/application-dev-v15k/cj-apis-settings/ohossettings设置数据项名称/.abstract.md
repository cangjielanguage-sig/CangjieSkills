This directory provides API reference documentation for the `ohos.settings` module in the Cangjie programming language, targeting HarmonyOS developers. It encompasses enumerations, classes, and functions necessary for accessing and modifying system settings data items. Key areas include display, sound, network, wireless, input methods, and general device configurations. The documentation details how to query domains, retrieve values, and observe changes, all under the `SystemCapability.Applications.Settings.Core` capability starting from API version 19. It is essential for developers building system-level applications requiring programmatic control over device preferences and behaviors.
