# 备忘录开发实战

This directory contains a practical tutorial series for building a memo application using the ArkUI framework and the Cangjie language. It covers essential concepts such as state management with `@State`, `@Prop`, and `@Link` decorators, dynamic list rendering using `ForEach`, and UI logic reuse via `@Builder` methods. The content progresses from basic implementation to architectural optimization, illustrating the MVVM pattern. It is suitable for developers learning HarmonyOS development who want to understand reactive UI design and component interaction in Cangjie.

## Detailed Description

### Builder方法.md Builder方法.md
This tutorial demonstrates how to use the @Builder method in ArkUI to define reusable UI logic within components, thereby reducing code duplication and improving clarity. The document covers the definition of @Builder methods, data separation strategies, and component structuring using a Todo List application example. Key information includes the implementation of a displayIcon @Builder method within the ThingsComponent class, which encapsulates image rendering logic to streamline the main build function. This guide is intended for ArkUI developers familiar with Cangjie syntax who seek to optimize component architecture and maintainability. Keywords: @Builder, ArkUI, Cangjie, Component, Code Reuse, UI.

### PropLink的作用.md PropLink的作用.md
This document explains the usage and differences between the @Prop and @Link decorators for state management in ArkUI component development. It covers the definitions of unidirectional (@Prop) and bidirectional (@Link) data transmission between parent and child components. Key takeaways include that @Prop performs a deep copy allowing local updates without syncing to the parent, while @Link synchronizes changes both ways. The included Cangjie code example demonstrates a To-Do list application illustrating these concepts. This tutorial targets HarmonyOS developers using the Cangjie language who need to manage component state and data flow.

### 备忘录开发实战_2more.md 备忘录开发实战_2more.md
This tutorial guides developers through building a memo application using the ArkUI framework and Cangjie language to understand basic UI design and state management. The document focuses on the `@State` decorator, explaining its role in defining state variables that act as data sources to trigger UI updates upon modification. Key information includes a practical code example demonstrating how to toggle a to-do item's completion status, dynamically changing icons and text styles. The content targets developers learning ArkUI basics, emphasizing immediate functional development over complex architectural patterns. Keywords: ArkUI, Cangjie, @State decorator, state management, UI refresh, tutorial.

### 循环渲染组件.md 循环渲染组件.md
This tutorial serves as a practical guide for implementing dynamic list rendering using the ForEach loop in the ArkUI framework with the Cangjie language. It illustrates how to refactor repetitive component code by iterating over a data array to generate list items. The document details the structure of a To-Do application, breaking down the TodoComponent header, AllChooseComponent for global state control, and ThingsComponent for individual items. Key takeaways include the use of @Prop and @Link decorators for state synchronization and the syntax for embedding ForEach within a List container. This guide is intended for developers learning ArkUI component composition and state management.

### 总结.md 总结.md
This document summarizes code structure optimization in ArkUI development, illustrating how components and state variables interact to create reactive user interfaces. It covers the roles of @Entry components and sub-components, the function of state variables as binding agents, and the natural alignment of ArkUI with the MVVM architectural pattern. Key takeaways include the metaphor of building blocks for UI construction, the automatic refresh mechanism via state variables, and the recommendation to adopt MVVM for organizing scalable, feature-rich applications. Intended for developers working with ArkUI, this guide serves as a conceptual bridge between basic component usage and formal architectural design patterns.
