This directory serves as a comprehensive technical resource dedicated to understanding and implementing interoperability between the Cangjie language and ArkTS within the OpenHarmony ecosystem. It provides a detailed examination of the mechanisms required for bidirectional communication, specifically covering how ArkTS can invoke Cangjie code and how Cangjie can call back into ArkTS. The content focuses heavily on the interoperability library, defining critical types such as `JSValue` for data transfer, `JSContext` for runtime conversion, `JSCallInfo` for function parameters, and `JSRuntime` for environment management. This documentation is essential for developers aiming to achieve library-level reuse and seamless integration between Cangjie and ArkTS codebases in their applications, ensuring efficient cross-language development workflows. It addresses the complexities of type conversion and runtime management, providing a solid foundation for building robust, multi-language applications.
