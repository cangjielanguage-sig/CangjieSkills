# 常见使用问题

This directory serves as a specialized technical resource designed to assist developers in troubleshooting and resolving frequent issues encountered when building applications with the Cangjie language and ArkUI framework. It specifically addresses complex UI rendering anomalies and performance optimization challenges, such as screen flickering during dynamic data loading and unexpected behaviors when manipulating list items. The content delves into the mechanics of List components, LazyForEach, and data synchronization strategies, offering practical solutions to replace inefficient full reloads with targeted dataset operations. These guides are essential for Cangjie developers and engineers who are implementing dynamic lists, infinite scrolling, or state management, ensuring their applications deliver a seamless and visually stable user experience.

## Detailed Description

### 在List内使用屏幕闪烁.md
This technical guide addresses and resolves screen flickering issues encountered when dynamically loading data within a List component in Cangjie. The document covers the problematic implementation using notifyDataReload triggered by onScrollIndex, and the optimized solution utilizing notifyDatasetChange with DataAddOperation. The primary takeaway is that replacing full data reloads with specific dataset change operations not only eliminates visual flickering but also significantly improves loading performance. This guide targets Cangjie developers working with ArkUI components, specifically those implementing infinite scrolling or dynamic data loading in List views.

### 渲染结果非预期.md
This troubleshooting guide addresses an issue where deleting items in a LazyForEach component results in unexpected behavior. It covers the problem demonstration, root cause analysis regarding index mismatches, and the corrected code implementation. The key takeaway is that after deleting a data item, developers must call `reloadData()` and modify the `keyGeneratorFunc` to include the index (e.g., `item + index.toString()`) to force component rebuilding and ensure indices are updated correctly. This document targets Cangjie developers working with dynamic lists and data binding who need to handle state synchronization accurately.
