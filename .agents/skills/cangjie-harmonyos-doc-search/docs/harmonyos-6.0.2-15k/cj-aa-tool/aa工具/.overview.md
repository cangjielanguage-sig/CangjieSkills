# aa工具

This directory contains documentation for the "aa" (Ability Assistant) command-line tool, a utility designed for HarmonyOS developers to manage application lifecycles, perform debugging, and execute automated tests. It covers essential commands for starting and stopping applications, attaching debuggers, and managing processes. The content includes detailed syntax references, parameter configurations, error code troubleshooting, and integration guides for IDE tools. Suitable for software developers, QA engineers, and system integrators, this resource facilitates efficient application development, testing, and performance tuning within the hdc shell environment.

## Detailed Description

### aa工具_4more.md aa工具_4more.md
This document serves as a reference guide for the "aa" (Ability assistant) command-line tool, designed to help developers launch applications, execute test cases, and perform debugging tasks. The content covers environment setup requirements, specifically the need for the hdc tool, and provides a comprehensive list of supported commands including start, force-stop, test, attach, detach, appdebug, and process. Key takeaways include the distinction between interactive and direct shell execution and the specific functions of each command for managing application components and processes. Intended for software developers, this guide assumes familiarity with command-line interfaces and the hdc shell environment.

### 进入调试模式命令attach_3more.md 进入调试模式命令attach_3more.md
This reference document details command-line instructions for managing application debugging states. It covers three primary commands: aa attach for entering debug mode, aa detach for exiting, and aa appdebug for setting, canceling, or querying the wait-for-debug state. Key parameters include the required bundle name (-b) and optional persistence flags (-p). The document provides comprehensive error codes, return values, and usage examples for troubleshooting and execution. Targeted at developers and technical users, this guide facilitates precise control over application lifecycle and debugging behaviors via the terminal.
