This directory serves as a comprehensive resource for the ColumnSplit component within the Cangjie ArkUI framework. It is dedicated to a specific layout utility designed to arrange child components vertically, separated by distinct horizontal dividers. The documentation thoroughly covers the component's behavior, including how child elements are managed, the initialization processes required, and the specific attributes available for customization, such as divider margins and resizeability. A key feature highlighted is the interactive capability to drag dividers to adjust child heights dynamically. This resource is essential for Cangjie developers aiming to build responsive and interactive user interfaces. It includes detailed syntax examples and outlines system capability requirements, ensuring that developers have all the necessary technical information to successfully implement resizable vertical layouts in their applications. By leveraging this component, developers can create sophisticated UI structures that adapt to user interaction.
