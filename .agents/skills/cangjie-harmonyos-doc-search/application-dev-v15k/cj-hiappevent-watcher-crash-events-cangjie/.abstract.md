This directory serves as a specialized technical resource dedicated to the implementation of crash event subscription capabilities using the Cangjie programming language within the HarmonyOS environment. It provides a detailed guide on integrating the Performance Analysis Kit to effectively monitor and enhance application stability. The content specifically addresses the critical distinction between CjError and NativeCrash event types, offering developers the necessary workflows to configure event watchers, manage subscription lifecycles, and perform in-depth analysis of stack unwinding data. This resource is primarily designed for Cangjie application developers and QA engineers who require robust tools and comprehensive API references to track, debug, and resolve system-level crashes. By leveraging the materials provided here, users can ensure robust application performance and maintain high reliability standards in their software projects. The guide bridges the gap between system-level crash data and actionable debugging insights, making it an essential component of the development toolkit for stability-focused engineering.
