# unittest_dynamic_tests

This directory provides a specialized guide for the Cangjie testing framework, focusing on the implementation and execution of dynamic tests. Unlike standard static tests, dynamic tests are crucial for scenarios where test data is generated or discovered at runtime, such as reading from external files or databases. The primary focus is on the `@TestBuilder` annotation, which enables developers to programmatically construct test suites rather than relying solely on compile-time definitions. Key concepts include the builder pattern for creating `TestSuite` objects, the use of `UnitTestCase` for handling variable data, and the specific constraints associated with dynamic test methods. Furthermore, the documentation explains how to execute these tests programmatically using `runTests()` and generate comprehensive reports through various reporters like `ConsoleReporter` and `XmlReporter`. This resource is ideal for developers seeking to extend their testing capabilities beyond static scenarios, offering the flexibility needed for complex, data-driven testing environments. By mastering these techniques, users can achieve more granular control over test execution and output formatting.
