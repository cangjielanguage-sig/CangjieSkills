This directory contains documentation regarding programming functions, primarily focusing on deprecated POSIX system calls and file operations. It covers a wide range of low-level tasks including file manipulation, permission management, process control, and system information retrieval. The content is written in Chinese and serves as a reference for legacy code maintenance or migration projects. It is suitable for developers and students working with system-level programming who need to understand obsolete APIs, platform compatibility (Linux, macOS, Windows), and function signatures for C-style interfaces.
