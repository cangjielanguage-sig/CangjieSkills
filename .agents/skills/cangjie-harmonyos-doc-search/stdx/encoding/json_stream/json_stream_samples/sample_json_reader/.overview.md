## Detailed Description

### sample_json_reader.md sample_json_reader.md

本文档是仓颉编程语言中进行 JSON 流式反序列化的实战指南。它首先演示了如何定义一个类来实现 JsonDeserializable 接口，这是处理自定义对象反序列化的基础。接着，文档深入讲解了利用 JsonReader 进行手动解析的过程，包括如何使用 peek 预读、startObject 开始对象解析、readName 读取字段名以及 readValue 读取值。此外，文档还展示了从 JSON 字符串到目标对象的完整转换流程，并特别强调了如何处理 Option（可选值）、Bool（布尔值）、Array（数组）和 HashMap（哈希映射）等多种数据类型。对于需要高效、灵活处理 JSON 数据的仓颉开发者而言，这是一份极具价值的代码参考教程。
