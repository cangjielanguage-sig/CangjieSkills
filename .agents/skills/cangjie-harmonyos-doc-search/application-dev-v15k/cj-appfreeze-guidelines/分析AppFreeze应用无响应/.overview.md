### 应用无响应检测能力点.md 应用无响应检测能力点.md
This technical reference document outlines the mechanisms for detecting application non-responsive (appfreeze) faults to assist developers in troubleshooting. It details three specific fault types: main thread execution stall (THREAD_BLOCK_6S), user input response timeout (APP_INPUT_BLOCK), and Ability lifecycle switch timeout (LIFECYCLE_TIMEOUT). The text explains detection principles involving watchdog threads and liveness checks, distinguishing between warning and error events based on time thresholds (e.g., 3s vs 6s). It also provides a table of specific timeout durations for various lifecycle states like Load, Foreground, and Connect.
