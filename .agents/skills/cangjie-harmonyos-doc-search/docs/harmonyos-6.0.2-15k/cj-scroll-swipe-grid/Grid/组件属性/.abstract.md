This directory contains API reference documentation for configuring properties of the Grid component within the ArkUI framework, specifically using the Cangjie language. It covers a comprehensive range of functionalities including item alignment, layout templates (columns and rows), scrolling behaviors, friction, and scrollbar customization. Key topics involve optimizing performance with LazyForEach, managing grid dimensions, and handling interactive gestures. This documentation is suitable for software developers and UI engineers looking to build responsive, high-performance grid interfaces in ArkUI applications.
