# digest_package_exceptions

本目录包含digest包中关于异常处理的API参考文档，主要定义了用于处理摘要和加解密错误的`CryptoException`类。文档详细介绍了该类的继承关系、构造函数及其在加密操作中的应用场景。核心关键词包括异常处理、加密错误、CryptoException、API参考。该文档主要面向使用仓颉语言进行安全加密功能开发的程序员，帮助他们捕获和处理运行时的加密异常，确保程序的健壮性。

### digest_package_exceptions.md digest_package_exceptions.md
本文档是digest包中关于异常处理的API参考文档，主要定义了用于处理摘要和加解密错误的CryptoException类。文档涵盖了该类的继承关系及其两个公共构造函数：无参构造函数和接收自定义错误信息的构造函数。关键信息指出，此类专门用于在加密操作出现错误时抛出异常，允许开发者通过构造函数传递具体的错误描述。目标受众为使用仓颉语言进行安全加密功能开发的程序员，他们需要利用此类来捕获和处理运行时的加密异常。
