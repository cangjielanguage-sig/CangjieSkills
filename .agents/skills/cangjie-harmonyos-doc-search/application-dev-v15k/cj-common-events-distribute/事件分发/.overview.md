# 事件分发

This directory focuses on the event dispatch mechanisms within the ArkUI framework, detailing how user interactions like touches and mouse inputs are processed and routed to specific components. It covers the fundamental concepts of event dispatch, the algorithms for collecting event response chains, and the specific logic behind touch testing. Key topics include touch events, mouse events, hitTestBehavior, and event propagation. This documentation is suitable for ArkUI developers and UI engineers who need to understand the underlying logic of event handling to build responsive and interactive user interfaces.

## Detailed Description

### 事件响应链的收集.md 事件响应链的收集.md
This technical reference document explains the mechanism and algorithm for collecting event response chains in ArkUI. It covers the traversal logic, pseudocode implementation, and a specific example involving component trees and the hitTestBehavior attribute. Key information includes that the collection follows a right-subtree-prioritized post-order traversal. The example demonstrates that touching Component 5 results in a response chain of 5, 3, 1, where Component 3's default behavior blocks the left subtree of Component 1. This is intended for ArkUI developers needing to understand touch event propagation and component interaction logic.

### 概述.md 概述.md
This document provides a conceptual overview of event dispatch mechanisms within the ArkUI framework, explaining how user interactions are processed and routed to components. It covers the definition of event dispatch, the classification of touch events into Touch and Mouse categories, and the critical role of touch testing in determining event distribution. Key takeaways include the distinction between Touch and Mouse event types, their respective input sources like finger, pen, or joystick, and the specific events they trigger such as click, drag, or gesture. Crucially, it highlights that touch testing is the deciding factor for the event response chain and component binding. This reference material is intended for developers working with ArkUI who need to understand the underlying logic of event handling to build responsive user interfaces. Keywords: ArkUI, event dispatch, touch test, touch events, mouse events, event response chain, user interaction.

### 触摸测试.md 触摸测试.md
This technical guide details the ArkUI touch testing mechanism, defining how component response areas are evaluated and event response chains are constructed upon receiving touch or mouse inputs. Key sections include the basic traversal flow, touch test control modes via hitTestBehavior, disable controls, touch hot zone configuration, and security component interactions. The document explains how specific attributes like hitTestBehavior (Default, None, Block, Transparent) influence event propagation among siblings and parent nodes, and how enabled or responseRegion settings impact the collection process. It serves as a reference for developers aiming to customize UI event handling and interaction logic.
