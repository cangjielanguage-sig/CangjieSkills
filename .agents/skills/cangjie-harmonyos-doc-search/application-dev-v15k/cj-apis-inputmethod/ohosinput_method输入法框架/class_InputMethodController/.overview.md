# class_InputMethodController

This directory contains API reference documentation for the `InputMethodController` class within the Cangjie IMEKit framework. It provides comprehensive details for developers implementing custom text input fields and managing interactions with the input method service. Key topics include binding self-drawn controls, managing keyboard visibility, handling text selection, cursor updates, and event subscriptions. The documentation covers function signatures, parameters, system capabilities, and exception handling. It is suitable for Cangjie application developers and input method engineers who need to programmatically control text editing behaviors, keyboard display logic, and event listeners in their applications.
