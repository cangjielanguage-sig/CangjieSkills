This directory contains API reference documentation for the Cangjie programming language, focusing on the `ThrowingOp` interface and its implementations across various integer types. It covers exception-handling arithmetic operations that throw `OverflowException` or `OvershiftException` instead of wrapping values. The content includes interface definitions, specific function references like `throwingShr` and `throwingSub`, and extensions for signed and unsigned integers (Int8, Int16, Int32, Int64, IntNative, UInt8, UInt16, UInt32, UInt64, UIntNative). This resource is suitable for Cangjie developers requiring strict error handling and data integrity in high-reliability applications.
