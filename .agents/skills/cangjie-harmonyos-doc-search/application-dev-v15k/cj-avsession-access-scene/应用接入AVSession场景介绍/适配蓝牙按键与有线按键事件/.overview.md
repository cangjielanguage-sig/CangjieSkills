# 适配蓝牙按键与有线按键事件

This directory provides a comprehensive technical guide for developers on how to adapt Bluetooth and wired media key events within applications using the AVSession framework. It covers essential implementation strategies for handling media control commands, detailing the differences between abstract command registration and raw key event processing. Key topics include AVSession setup, AVMetadata configuration, and the specific callback mechanisms required for KeyEvent handling. The documentation emphasizes the critical necessity of setting metadata to ensure the system correctly routes events to the application. This content is specifically suitable for application developers seeking to integrate seamless media playback controls that function consistently regardless of whether the input source is Bluetooth or wired hardware, ensuring a unified user experience.

### 适配蓝牙按键与有线按键事件_1.md 适配蓝牙按键与有线按键事件_1.md
This technical guide instructs developers on adapting Bluetooth and wired media key events using the AVSession framework. It details two implementation approaches: the recommended method involves registering AVSession control commands (e.g., play, pause) to abstract hardware events, while the alternative method uses HandleMediaKeyEvent to process raw KeyEvent objects directly. The document provides Cangjie code examples for setting up listeners and callbacks, emphasizing the necessity of setting metadata for event reception. It targets application developers seeking to integrate media playback controls without distinguishing between input modes.
