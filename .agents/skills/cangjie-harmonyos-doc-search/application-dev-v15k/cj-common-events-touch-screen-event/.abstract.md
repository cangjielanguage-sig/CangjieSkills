This directory provides a comprehensive technical guide for developers utilizing the Cangjie UI framework to effectively manage touch screen interactions. It focuses on the critical aspects of event handling, specifically distinguishing between Click Events and Touch Events. The content explains how to use the `onClick` function for standard press-and-lift actions and the `onTouch` function for tracking detailed finger movements such as Down, Move, Up, and Cancel. Furthermore, it addresses advanced features like multi-touch support and the extraction of specific event data, including coordinates, touch IDs, and component dimensions. Designed for application developers, this documentation offers practical Cangjie code examples to illustrate how to implement interactive features like toggling image visibility. It serves as a vital reference for building responsive and dynamic user interfaces within the UIKit environment.
