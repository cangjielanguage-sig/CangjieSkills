This directory contains the API reference documentation for the TextPicker component within the ArkUI framework, specifically tailored for the Cangjie programming language. It serves as a comprehensive guide for developers looking to implement a sliding text selector in their applications. The content covers critical aspects such as initialization parameters—including data range, selected index, and default values—as well as component attributes like looping and item height. Additionally, it details event handling mechanisms for selection changes. This resource is ideal for software engineers and UI developers working with Cangjie syntax who require precise text selection functionality in their user interfaces. It provides code examples demonstrating state management and event logging, ensuring developers have practical references for implementation.
