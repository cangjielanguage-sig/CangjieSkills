# 示例代码

本目录包含使用仓颉语言开发 ArkUI 应用的布局示例代码，主要涵盖了元素对齐方式、主轴方向布局以及位置偏移的实现方法。通过具体的代码演示，帮助开发者掌握 Stack 组件的 align 属性、Row 组件的 direction 属性，以及 position、markAnchor 和 offset 等定位属性的使用。这些示例适合正在学习 ArkUI 布局机制且使用仓颉语言的开发者参考，旨在提升界面布局的实践能力。

## 详细描述

### 示例1对齐方式和主轴方向上的布局.md 示例1对齐方式和主轴方向上的布局.md
本文档旨在演示如何在ArkUI中使用仓颉语言设置元素内容的对齐方式及子元素在父容器主轴方向上的布局。文档主要包含两个核心部分：一是利用Stack组件的align属性（如BottomEnd、TopStart）控制子组件的对齐位置；二是通过Row组件的direction属性（如Ltr、Rtl）调整子元素的排列顺序。关键信息在于展示了具体的代码实现方式，帮助开发者理解布局属性的实际效果。该文档适合正在学习ArkUI布局机制的仓颉语言开发者阅读，作为布局配置的实践参考。

### 示例2位置偏移.md 示例2位置偏移.md
本文档旨在通过Cangjie代码示例，演示ArkUI框架中基于父组件、相对定位及锚点的位置偏移实现方法。文档主要涵盖三个核心部分：position（相对于父组件左上角偏移）、markAnchor（相对于起点偏移）和offset（相对定位偏移）。关键信息包括详细解释了各属性中x与y坐标的正负方向定义及百分比支持，并展示了在Row和Stack容器中的具体应用。该文档适合正在学习ArkUI布局系统的Cangjie语言开发者参考，需具备基础组件知识。
