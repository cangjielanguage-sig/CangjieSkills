# 构建第一个OpenHarmony应用仓颉

本目录包含使用仓颉语言构建首个OpenHarmony应用的完整教程集合。内容涵盖从在DevEco Studio中创建工程、配置OpenHarmony环境，到使用ArkUI组件构建UI页面、实现页面间导航以及理解仓颉工程目录结构的全过程。核心知识点包括DevEco Studio配置、仓颉语法、UI布局及路由跳转。该文档适合仓颉语言初学者及希望入门OpenHarmony应用开发的开发者阅读。

## Detailed Description

### 仓颉工程目录结构.md
本文档详细说明了仓颉工程的标准目录结构，并解释了关键文件和文件夹的功能与用途。涵盖了工程整体目录树、entry模块详情（源码、资源、配置）、以及hvigor、oh_modules等全局配置和依赖管理目录。关键信息包括entry模块用于生成HAP包，cjpm.toml用于包管理，module.json5用于模块配置，以及区分了应用级与模块级的构建和依赖配置。这是一份面向仓颉开发者的参考指南，旨在帮助开发者理解工程组织结构及各配置文件的作用。

### 实现页面间的跳转_2more_c5f33de4.md
这是一份面向仓颉语言开发者的OpenHarmony应用开发教程，旨在指导实现页面间导航及应用运行。文档主要包含两个部分：一是通过router模块实现页面跳转与返回，提供了index.cj和second.cj的代码示例，演示了pushUrl和back方法的使用；二是介绍在真机和模拟器上运行应用的步骤，特别强调了x86模拟器需在build-profile.json5中配置abiFilters以支持x86_64架构。本文档帮助开发者完成首个仓颉应用的构建与调试。

### 构建第一个OpenHarmony应_2more_7b7ec94d.md
这份文档是一份使用仓颉语言构建首个OpenHarmony应用的入门教程。主要内容包括在DevEco Studio中创建[Cangjie] Empty Ability工程，以及通过修改build-profile.json5文件将HarmonyOS工程转换为OpenHarmony工程的具体步骤。关键要点涉及配置compileSdkVersion、compatibleSdkVersion及runtimeOS字段。该文档面向初学者，旨在指导其完成工程创建与配置。关键词：OpenHarmony、仓颉、DevEco Studio、工程配置、教程。

### 构建第一个页面_2more_d6def944.md
这份文档是一份使用仓颉语言开发HarmonyOS应用的入门教程，旨在指导用户构建基础UI页面。文档分为构建第一个页面和构建第二个页面两部分。第一部分详细说明了如何在index.cj文件中使用Row和Column布局添加Text组件和Button组件，并配置点击事件。第二部分介绍了创建second.cj文件的方法，并演示了如何添加文本和返回按钮。关键知识点包括ArkUI组件的使用、@Entry和@Component装饰器的应用以及页面结构搭建。该文档适合仓颉语言初学者，用于学习基础页面开发流程。
