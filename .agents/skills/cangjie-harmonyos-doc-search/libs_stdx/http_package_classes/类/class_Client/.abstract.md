This directory contains API reference documentation for the HTTP Client class in the Cangjie programming language. It covers the core functionality for sending HTTP/1.1 and HTTP/2 requests, managing connections, and handling protocol upgrades. Key topics include client configuration (timeouts, proxies, cookies), convenience methods for standard HTTP verbs (GET, POST, PUT, DELETE), and low-level request sending. It is suitable for software developers integrating network communication into Cangjie applications who need detailed technical specifications and usage guidelines.
