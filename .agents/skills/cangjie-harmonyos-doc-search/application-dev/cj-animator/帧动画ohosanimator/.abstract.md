This directory focuses on frame animation within the HarmonyOS ArkUI framework, specifically utilizing the `ohos.animator` API and the Cangjie language. It covers the fundamentals of frame animation, comparing it with property animation, and provides practical implementation guides for creating custom physics-based effects like parabolic motion. Key topics include `onFrame` callbacks, real-time UI updates, and animation lifecycle management. This resource is suitable for HarmonyOS developers, students, and graphics programming enthusiasts looking to master granular control over animation frames and smooth rendering in mobile applications.
