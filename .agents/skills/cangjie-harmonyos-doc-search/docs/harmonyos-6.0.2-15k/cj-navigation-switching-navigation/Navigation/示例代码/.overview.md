# 示例代码

This directory serves as a practical resource collection for Cangjie developers working on HarmonyOS applications, focusing specifically on navigation architecture and UI layout implementation. It includes detailed code examples that demonstrate how to effectively manage the navigation stack using `NavPathStack` methods, covering operations like pushing, popping, and moving pages. Additionally, it explores the configuration of the Navigation component, detailing the setup of title bars, menus, and toolbars using `@Builder` functions and state management. By illustrating key functions such as `pushPathByName`, `popToName`, and `toolbarConfiguration`, these examples provide essential knowledge for handling complex routing logic and creating structured user interfaces. This content is ideal for developers seeking to master navigation control and UI customization in the Cangjie ecosystem.

## Detailed Description

### 示例2使用路由栈方法.md
This document provides a practical code example demonstrating how to manipulate the navigation stack using NavPathStack methods in a Cangjie application. It covers essential navigation operations including pushing pages with specific launch modes, popping to specific names or indices, moving pages within the stack, and retrieving stack metadata. The example implements EntryView, PageOne, and PageTwo to illustrate key functions such as pushPathByName, popToName, moveToTop, and clear, effectively showing how to manage page lifecycles and navigation history. This tutorial is intended for developers using the Cangjie language to build HarmonyOS applications who need to implement complex navigation logic and state management.

### 示例代码_2more.md
This document provides a Cangjie code example demonstrating the implementation of a Navigation page layout within a HarmonyOS application. It covers the configuration of the Navigation component, specifically focusing on the title bar, menu bar, content area, and toolbar. The code illustrates the use of `@Builder` functions for custom titles and menus, state management with `@State`, and properties like `toolbarConfiguration` and `titleMode`. It also notes that the example requires a real device for testing as system routing does not support the previewer. This is intended for Cangjie developers looking to implement complex navigation structures and UI layouts in their applications.
