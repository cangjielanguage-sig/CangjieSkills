# 基础类型定义

This directory provides essential API references and type definitions for implementing media playback controls within the ArkUI framework using the Cangjie programming language. It focuses on the core components required to manage video instances, including the `VideoController` class for lifecycle management and enumerations for playback speed and seeking modes. Key topics cover video initialization, playback state manipulation, fullscreen control, and precise navigation logic. This documentation is designed for application developers and software engineers seeking to integrate robust video functionalities and fine-tune media behavior in their applications using API version 12.

## Detailed Description

### class_VideoController.md class_VideoController.md
This document serves as an API reference for the VideoController class in the Cangjie language, designed to manage and control video playback instances within the ArkUI framework. It details the class initialization and various functional methods including playback controls (start, pause, stop, reset), progress seeking (setCurrentTime), and display management (requestFullscreen, exitFullscreen). Key information includes the ability to control multiple videos, support for specific seek modes, and the requirement for the SystemCapability.ArkUI.ArkUI.Full capability. This reference targets application developers implementing video features, requiring prior knowledge of the Cangjie language and multimedia APIs.

### enum_PlaybackSpeed_2more.md enum_PlaybackSpeed_2more.md
This document serves as API reference documentation for media playback controls in the Cangjie programming language within the ArkUI framework. It details two primary enumerations: PlaybackSpeed, which defines specific forward playback rates ranging from 0.75x to 2.00x, and SeekMode, which specifies navigation behaviors such as jumping to previous, next, or closest keyframes, or performing accurate seeking. Key information includes the specific enum values, their functional descriptions, system capabilities, and the requirement of API version 12. The target audience is software developers implementing media playback features who need precise control over video speed and seeking logic.
