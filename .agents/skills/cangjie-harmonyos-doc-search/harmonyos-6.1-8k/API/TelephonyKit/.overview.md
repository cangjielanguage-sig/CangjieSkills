# TelephonyKit

TelephonyKit is a comprehensive documentation repository for the HarmonyOS telephony subsystem, specifically tailored for developers using the Cangjie programming language. It provides essential resources for integrating telephony capabilities into applications, including API references, core interface definitions, and detailed error code guides. The kit covers critical functionalities such as call management (`ohos.telephony.call`), dialing implementation, and system-level troubleshooting. Designed for HarmonyOS application engineers and technical support teams, this documentation assists in understanding API specifications, handling runtime exceptions, and ensuring stable communication features during the Beta phase of development.

## Detailed Description

### README_zh
This directory serves as the official entry documentation collection for the Telephony Kit (Cangjie language version), specifically designed for engineers using the Cangjie language for HarmonyOS application development. It primarily covers the API overview of telephone-related functions, core interface definitions, and detailed error code references, serving as the foundational material for developers accessing telephone capabilities. The documentation highlights key modules such as `ohos.telephony.call`, with a specific focus on the implementation of dialing functions and error handling mechanisms. As the current functionality is in the Beta stage, this document is crucial for developers to understand the stability, availability, and version limitations of the features. This directory is suitable as an index center for consulting API specifications, troubleshooting runtime errors, and obtaining development guidance.

### cj-apis-telephony-call
This directory serves as a comprehensive repository for API reference documentation regarding the HarmonyOS telephony call management module, specifically implemented using the Cangjie programming language. It is designed to assist developers in seamlessly integrating telephony features by providing detailed technical specifications and interface descriptions.

### cj-errorcode-telephony
This directory contains the error code reference guide for the telephony subsystem, aimed at providing developers and technical support personnel with a systematic basis for troubleshooting. The documentation details the error code range from 8300001 to 8800999, providing in-depth analysis of various common issues including invalid input parameters, service connection failures, system internal errors, and SIM card-related anomalies (such as unrecognized, unactivated, and data read/write failures). By providing specific error messages, detailed descriptions, potential cause analysis, and clear handling steps for each error code, this guide constructs a complete troubleshooting logic ranging from basic parameter validation to complex hardware checks. It is primarily suitable for application developers and technical support teams, effectively assisting in debugging telephone functions and quickly locating runtime exceptions to ensure communication stability.
