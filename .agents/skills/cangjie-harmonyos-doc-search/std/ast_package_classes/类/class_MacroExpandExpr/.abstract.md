This directory contains technical documentation for the `MacroExpandExpr` class and associated utility functions within the Cangjie language's Abstract Syntax Tree (AST). It focuses on the structural representation and programmatic manipulation of macro invocation nodes. The documentation covers class definitions, mutable properties for accessing specific tokens (like the `@` operator), initialization methods, and validation logic. Additionally, it includes references for functions that convert nodes to tokens and traverse the AST using the Visitor pattern. This content is intended for compiler developers and programmers working on syntax analysis or AST construction in the Cangjie programming environment.
