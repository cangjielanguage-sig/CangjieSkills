This directory contains the essential API reference documentation for the `InputEvent` class within the Cangjie Multimodal Input Kit. It serves as a comprehensive technical guide for defining the structure of basic device-reported input events, which are fundamental to building interactive applications. The content thoroughly details the class definition, its constructor, and five critical public properties: id, deviceId, actionTime, screenId, and windowId. Key information highlights that all properties are read-write integers representing vital event metadata, such as precise timing and target locations. This module is strictly intended for Cangjie developers who need to handle and process raw input event data. It requires the system capability `SystemCapability.MultimodalInput.Input.Core` and is available starting from version 19, making it a crucial resource for modern application development in the Cangjie ecosystem.
