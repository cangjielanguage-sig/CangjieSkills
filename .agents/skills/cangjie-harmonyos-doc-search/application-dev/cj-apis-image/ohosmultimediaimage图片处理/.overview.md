# ohosmultimediaimage图片处理

This directory contains comprehensive API reference documentation for the HarmonyOS multimedia image processing module in the Cangjie programming language. It covers core functionalities including image decoding, encoding, PixelMap manipulation, and metadata management. Key components include ImageSource, ImageReceiver, PixelMap, and various configuration options for handling image data streams and formats. Designed for software developers and engineers building multimedia applications, this documentation provides the necessary interfaces and classes to implement efficient image processing, transformation, and resource management within the SystemCapability.Multimedia.Image framework.

## Detailed Description

### class_Component.md class_Component.md
This API reference details the Cangjie Component class, which describes image color components. It covers the class definition and its four read-only properties: byteBuffer, componentType, pixelStride, and rowStride. Key usage notes for rowStride are provided to prevent display artifacts when reading camera preview streams.

### class_ImageInfo.md class_ImageInfo.md
This document provides API reference for the Cangjie ImageInfo class, representing image metadata. It details seven public properties including size, density, stride, pixelFormat, and alphaType. It includes a critical warning that decoded MIME types may not be valid for encoding.

This document details the Cangjie class ImagePropertyOptions, designed to represent indices for querying image properties. It covers the index property (UInt32) and defaultValue property (String), both readable and writable, along with the initialization method.
