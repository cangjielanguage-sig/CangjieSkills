# cj-common-components-radio-button

This directory serves as a comprehensive technical resource for the `cj-common-components-radio-button` module within the Cangjie ArkUI framework. It is specifically designed for developers working on HarmonyOS applications who need to implement single-selection user interfaces. The documentation provides an in-depth look at the Radio component, guiding users through the initialization process using the `init` interface. It thoroughly explains essential configuration parameters, including `value`, `group`, and `indicatorType`, which are pivotal for defining the component's functionality and visual presentation. Additionally, the guide covers advanced topics such as state management via the `checked` property and event handling using the `onChange` callback to capture user selections. To facilitate practical understanding, the document includes a real-world scenario demonstrating the integration of Radio components to switch sound modes. This resource is ideal for Cangjie developers seeking to enhance their applications with interactive and responsive UI controls.

Keywords: Cangjie, ArkUI, Radio component, UI, single selection, onChange event, state management, HarmonyOS
