# MVVM模式

This directory focuses on the Model-View-ViewModel (MVVM) architecture pattern within the context of HarmonyOS ArkUI development using the Cangjie language. It covers theoretical principles, layer separation, and practical implementation through a memo application tutorial. Key topics include state management, component decoupling, and scalable application structuring. Designed for developers with prior knowledge of State Management V1, this resource aims to improve code maintainability and development efficiency in complex projects by enforcing clean architecture standards.

## Detailed Description

### MVVM模式_3more.md MVVM模式_3more.md
This guide introduces the MVVM architecture pattern and its integration with ArkUI's UI development mode to assist developers in structuring scalable applications. It explains the core concepts of Model, View, and ViewModel, detailing how state variables act as the bridge for data-driven UI updates. Key sections cover the classification of View components (page, business, common), the distinction between page-specific ViewModel data and project-wide Model data, and the role of the Model layer as a data provider. Intended for developers with prior knowledge of State Management V1, this document aims to simplify maintenance and improve development efficiency in complex projects.

### 架构核心原则.md 架构核心原则.md
This document outlines core architectural principles designed to enforce strict layer separation and component decoupling within a software system. The content covers three primary rules: prohibiting cross-layer access between View, ViewModel, and Model; preventing lower layers from directly accessing upper layer data; and restricting direct access between non-parent-child components in the View layer. Key takeaways include the mandate that data flow must rely on notifications or events rather than direct references, ensuring that components remain modular by only interacting with direct children or communicating upwards via events. Intended for software developers and architects, this reference guide serves as a standard for implementing clean architecture patterns like MVVM. Keywords: Architecture, MVVM, Decoupling, Layer Separation, Component Design.

### 备忘录开发实战/
This directory contains a practical tutorial series for building a memo application using the ArkUI framework and the Cangjie language. It covers essential concepts such as state management with `@State`, `@Prop`, and `@Link` decorators, dynamic list rendering using `ForEach`, and UI logic reuse via `@Builder` methods. The content progresses from basic implementation to architectural optimization, illustrating the MVVM pattern. It is suitable for developers learning HarmonyOS development who want to understand reactive UI design and component interaction in Cangjie.

### 通过MVVM开发备忘录实战/
This resource offers a deep dive into the practical application of the MVVM (Model-View-ViewModel) architecture pattern, specifically tailored for developing a memo application. It addresses common development challenges such as code bloat and maintenance difficulties by teaching developers how to effectively decouple logic. The curriculum spans both theoretical architectural design and concrete implementation using the Cangjie language within the HarmonyOS ArkUI ecosystem. Core concepts include data layer separation, reactive state management, and component categorization. This guide is ideal for developers who wish to transition from basic coding to structured, scalable software design, ensuring their applications remain robust and easy to update as features grow.
