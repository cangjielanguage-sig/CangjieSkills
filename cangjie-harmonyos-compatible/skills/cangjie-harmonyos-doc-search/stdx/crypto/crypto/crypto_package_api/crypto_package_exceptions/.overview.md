# crypto_package_exceptions

本目录专门收录了 crypto 包中关于异常处理机制的核心文档，重点聚焦于 `SecureRandomException` 类的详细定义。该文档深入阐述了该异常类的继承体系（继承自 `Exception`），并详细列出了其支持的构造函数，包括无参构造函数和允许传入自定义错误消息的构造函数。通过这些内容，开发者可以掌握如何在安全随机数生成过程中发生错误时，正确抛出和捕获异常。核心关键词涵盖：crypto 包、异常处理、SecureRandomException、安全随机数、仓颉语言 API。本文档主要面向使用仓颉语言进行底层加密开发或应用层安全功能实现的程序员，是构建健壮加密系统不可或缺的 API 参考资料。

## Detailed Description

### crypto_package_exceptions.md crypto_package_exceptions.md
本文档定义了 crypto 包中用于处理安全随机数生成错误的异常类。主要涵盖了 `SecureRandomException` 类的定义，包括其继承自 `Exception` 的父类关系，以及两个构造函数：无参构造和带消息参数的构造。关键信息在于该类提供了创建默认异常实例和自定义异常信息实例的方法，用于在安全随机数操作失败时抛出。该文档面向使用仓颉语言进行加密开发的程序员，属于 API 参考文档，用于错误处理和异常捕获。
