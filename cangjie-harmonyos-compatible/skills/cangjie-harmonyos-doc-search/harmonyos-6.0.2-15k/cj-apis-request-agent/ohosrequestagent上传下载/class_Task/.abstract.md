This directory contains API reference documentation for the Cangjie `Task` class, part of the SystemCapability.Request.FileTransferAgent framework. It covers the management of file upload and download operations, including task initialization, lifecycle control (start, pause, resume, stop), and event subscription (progress, completion, response headers). Designed for Cangjie developers building HarmonyOS or OpenHarmony applications, these documents provide the necessary interfaces to handle asynchronous file transfers, monitor task status, and manage exceptions effectively within API version 12 and later.
