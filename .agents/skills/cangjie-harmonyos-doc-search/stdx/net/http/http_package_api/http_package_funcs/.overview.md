# http_package_funcs

本目录是Cangjie语言HTTP包的API参考文档集合，专注于定义和处理HTTP请求、响应及协议升级的便捷函数。文档详细介绍了三个核心函数：用于回复特定错误码的`handleError`、专门处理404响应的`notFound`，以及支持协议升级和CONNECT请求的`upgrade`。特别值得注意的是，`upgrade`函数提供了发送响应头并返回`StreamingSocket`以进行底层读写的能力。该文档主要面向使用Cangjie进行网络编程的开发者，旨在提供处理HTTP上下文和连接管理的标准接口，简化网络应用的开发流程。关键词包括Cangjie语言、HTTP包、API参考、错误处理、协议升级、网络编程、请求响应。

## Detailed Description

### http_package_funcs.md
本文档是Cangjie语言HTTP包的API参考文档，主要定义了用于处理HTTP请求响应及协议升级的便捷函数。文档涵盖了三个核心函数：用于回复特定错误码的handleError、专门处理404响应的notFound，以及支持协议升级和CONNECT请求的upgrade。关键信息指出，upgrade函数会先发送响应头并将请求体置空，返回StreamingSocket供后续底层读写操作。该文档面向使用Cangjie进行网络编程的开发者，旨在提供处理HTTP上下文和连接管理的标准接口。
