## Detailed Description

### 使用Deep_Linking实现应用间跳转_2more.md 使用Deep_Linking实现应用间跳转_2more.md
This technical guide explains how to implement inter-application navigation using Deep Linking technology. It covers the core functionality of launching apps via URIs and details the implementation principles based on implicit Want matching. The system identifies target applications by matching URIs provided in the interface; if multiple installed apps satisfy the conditions, the system displays a selection dialog. The mechanism relies on implicit Want matching rules. This guide is intended for application developers seeking to enable cross-app launching capabilities, likely within the HarmonyOS ecosystem given the terminology. Keywords: Deep Linking, URI matching, implicit Want, inter-application jump.

### 目标应用操作指导.md 目标应用操作指导.md
This guide instructs developers on configuring a target application to receive and process deep links from other applications. It covers configuring the module.json5 file with specific skills tags and handling incoming links within the UIAbility lifecycle. Key information includes the requirement to create a separate skill object for deep links, defining custom schemes and hosts, and ensuring actions are not empty. The document provides Cangjie code examples demonstrating how to extract and parse the URI and query parameters in onCreate or onNewWant to trigger specific business logic. This technical tutorial is intended for HarmonyOS developers using the Cangjie language to implement cross-application navigation.

### 拉起方应用实现应用跳转/
This directory serves as a comprehensive resource for HarmonyOS developers focusing on the implementation of application jumping functionality from the calling application (拉起方). These guides are suitable for developers aiming to integrate complex cross-application navigation, web-to-native transitions, and deep linking capabilities into their HarmonyOS projects.
