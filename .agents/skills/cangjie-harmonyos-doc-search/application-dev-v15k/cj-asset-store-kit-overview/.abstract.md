This directory serves as the definitive technical guide for the Asset Store Kit, a specialized framework designed to facilitate the secure storage and management of short, sensitive user data. It addresses the critical need for protecting high-value information such as passwords, authentication tokens, and cryptographic keys within application environments. The documentation provides a deep dive into the kit's underlying security infrastructure, emphasizing the implementation of AES256-GCM encryption and its reliance on the Universal Keystore System to ensure data confidentiality and integrity within a trusted execution environment. Beyond basic storage, the guide explains the sophisticated multi-layered access control mechanisms that regulate data access, taking into account variables such as data ownership, the current lock screen status of the device, and mandatory user authentication. Additionally, it outlines essential operational constraints that developers must adhere to, including the enforcement of alias uniqueness, limitations on batch query volumes, and strict data deletion policies. Supporting data payloads up to 1KB, this kit is optimized for performance and security. This resource is specifically curated for developers utilizing the Cangjie language who require a reliable, secure method to implement data protection and manage sensitive information lifecycles in their applications.
