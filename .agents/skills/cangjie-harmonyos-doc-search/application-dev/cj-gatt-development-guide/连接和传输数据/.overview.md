# 连接和传输数据

This directory focuses on Bluetooth Low Energy (BLE) connectivity and data transfer mechanisms, specifically utilizing the Generic Attribute Profile (GATT). It comprehensively covers the implementation principles for both GATT clients and servers, detailing how to establish connections, broadcast for discovery, and perform read/write operations. The content includes theoretical development guides, practical step-by-step implementation procedures using languages like ArkTS and Cangjie, and complete code examples tailored for the HarmonyOS and OpenHarmony ecosystems. It is highly suitable for software developers, IoT engineers, and system architects looking to build robust, production-ready Bluetooth communication protocols in their applications. By exploring these resources, users will gain a deep understanding of the core mechanisms based on Services, Characteristics, and Descriptors.

It covers an introduction to GATT roles and details the implementation principles for both GATT clients and servers. Key information includes how clients initiate connections and perform read/write operations, while servers broadcast to be discovered and handle requests.
