# 高级特性

This directory provides comprehensive documentation on advanced features for the Cangjie benchmarking framework. It covers essential topics such as configuring input data regeneration strategies for stateful functions, generating detailed HTML reports and CSV exports, and utilizing custom measurement sources like CPU cycles and Perf counters. Additionally, it details advanced configuration parameters for precise test execution control and methods to prevent compiler optimizations. This resource is suitable for developers and performance engineers seeking granular insights into system behavior and accurate benchmarking results.

## Detailed Description

### 每次调用前的设置.md 每次调用前的设置.md
This guide explains how to configure input data regeneration for benchmarking functions that modify their state to ensure accurate results. It covers the BenchInputProvider interface, the @Strategy annotation, and four specific provider implementations: ImmutableInputProvider, GenerateEachInputProvider, BatchSizeOneInputProvider, and BatchInputProvider. Key information includes the trade-offs of each provider, such as handling generation time overhead, precision limits for micro-benchmarks, and potential GC or cache effects. The content targets developers using the Cangjie benchmarking framework who need to handle stateful test data effectively.

### 高级特性_3more.md 高级特性_3more.md
This documentation describes advanced features of a benchmarking framework designed for complex performance analysis and result verification. It covers two primary areas: detailed reporting and custom measurement sources. The reporting section explains generating HTML-based visualizations using the `--report-format=html` option, which requires Gnuplot to display kernel density estimates and raw data charts, alongside CSV export options for statistical analysis. The custom sources section details the `@Measure` annotation and the `Measurement` interface, enabling the use of specific metrics like `TimeNow`, `CpuCycles`, and Linux `Perf` counters. Key takeaways include the ability to visualize unstable test data and measure hardware-specific events beyond execution time. This guide targets developers with a background in performance testing and statistics who need granular insights into system behavior.

### 高级配置参数_2more.md 高级配置参数_2more.md
This technical guide details advanced configuration parameters for a benchmarking framework, focusing on precise control over test execution and accuracy. It covers specific parameters like batchSize, minBatches, warmup, minDuration, and explicitGC, explaining their defaults and impact on performance statistics. The document introduces a DSL syntax for iterating over multiple parameter values to verify their influence on results. Additionally, it addresses avoiding unnecessary compiler optimizations by using arguments to hide literal values and storing return values in global variables to prevent dead code elimination. This reference is intended for developers writing complex benchmarks who need to simulate real-world runtime behavior and ensure deterministic results.
