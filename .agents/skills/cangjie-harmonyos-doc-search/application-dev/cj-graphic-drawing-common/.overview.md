# cj-graphic-drawing-common

This directory serves as a foundational resource for graphic drawing within the ArkUI framework using the Cangjie programming language. It focuses on the common properties and attributes shared across various 2D graphic components, such as Circle, Ellipse, Line, Path, Rect, and Shape. Key topics include styling configurations, stroke properties like dash arrays and line caps, fill settings, and viewport management. This collection is suitable for developers utilizing Cangjie to build user interfaces who require precise control over 2D graphics rendering and aesthetic customization in their applications.

### 图形绘制通用属性/
This directory focuses on the common properties for graphic drawing components within the ArkUI framework using the Cangjie language. It covers supported components like Circle, Ellipse, Line, Path, Rect, and Shape, detailing shared attributes for fill, stroke, and rendering. Key topics include styling, stroke properties (dash arrays, line caps), and viewport management. Suitable for developers using Cangjie to build user interfaces with ArkUI who need precise control over 2D graphics rendering and aesthetic customization. The documentation within this section is essential for understanding how to manipulate the visual appearance of basic geometric shapes. It explains the underlying mechanics of how strokes are applied to paths and how fills interact with the shape boundaries. Furthermore, it addresses viewport management, which is crucial for ensuring that graphics scale and display correctly across different device resolutions. By mastering these common properties, developers can create visually consistent and performant graphical user interfaces.
