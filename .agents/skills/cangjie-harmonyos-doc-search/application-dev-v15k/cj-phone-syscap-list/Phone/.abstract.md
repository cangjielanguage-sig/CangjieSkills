This directory contains documentation regarding System Capabilities (SysCap) for Phone device profiles within the HarmonyOS or OpenHarmony ecosystem. It covers the conceptual definition of SysCap and provides detailed technical reference lists enumerating supported features across various subsystems like AI, Multimedia, Security, and Telephony. These documents serve as essential manifests for developers and engineers to verify hardware support, configure system permissions, and ensure API compatibility during application development or system integration.
