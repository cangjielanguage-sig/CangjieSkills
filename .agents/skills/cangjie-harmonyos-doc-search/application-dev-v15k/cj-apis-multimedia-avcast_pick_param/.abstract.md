This directory contains the comprehensive API reference documentation for the `ohos.multimedia-avcast_picker_param` module, specifically developed for the Cangjie programming language. It is dedicated to defining the enumeration values that control the AV cast picker window state, a fundamental aspect of multimedia user interface design. The documentation provides detailed instructions on module imports, offers practical usage guidelines for Cangjie template projects, and thoroughly defines the `AVCastPickerState` enumeration. Among the key technical details provided are the enum values `StateAppearing` and `StateDisappearing`, which are crucial for tracking component visibility. Additionally, it includes information on standard operators for equality comparison and string conversion. The document also specifies the required system capabilities and confirms compatibility with API version 20. This resource is specifically tailored for HarmonyOS developers who are utilizing the AVSessionKit to implement and manage multimedia casting interfaces and their state transitions effectively.
