# 设置依赖关系

This directory focuses on configuring dependency relationships for UI components within the ArkUI framework, specifically utilizing the RelativeContainer. It covers essential layout concepts such as setting reference boundaries for alignment, positioning components relative to anchor points, and defining anchor point configurations. Key topics include horizontal and vertical alignment rules, offset handling, and avoiding dependency cycles. The documentation supports both Cangjie and ArkTS languages. It is suitable for developers and designers working on the HarmonyOS platform who need to build complex, interconnected user interfaces with precise relative positioning capabilities.

## Detailed Description

### 设置参考边界.md 设置参考边界.md
This technical reference document explains how to configure reference boundaries to align child components with anchor points within a container. The content distinguishes between horizontal and vertical alignment settings. Key information includes the specific boundary options available: left, middle, and right for horizontal alignment, and top, center, and bottom for vertical alignment. Crucially, the document notes specific constraints where setting all three boundaries in either direction results in the tail-end boundary (right or bottom) being ignored, with only the start and middle boundaries taking effect. This guide is intended for developers or designers working on component layout positioning. Keywords: reference boundaries, alignment, anchor point, horizontal, vertical, container, layout.

### 设置相对于锚点的对齐位置_2more.md 设置相对于锚点的对齐位置_2more.md
This document serves as a technical guide for developers on configuring component alignment relative to anchor points within the ArkUI framework using the Cangjie language. It details the usage of the alignRules property, specifying horizontal and vertical alignment options such as Start, Center, End, Top, and Bottom. Additionally, it explains how to apply position offsets using the offset attribute while noting the behavior of anchors when offsets are applied. The text includes a practical code example demonstrating a complex RelativeContainer layout. This guide is intended for developers seeking precise control over UI component positioning and layout management.
