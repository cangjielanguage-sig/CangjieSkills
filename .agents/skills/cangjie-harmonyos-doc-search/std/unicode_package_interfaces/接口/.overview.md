# 接口

This directory serves as a centralized repository for API reference documentation specifically designed for interfaces within the Cangjie programming language. It is dedicated to providing robust extensions for standard types, enabling advanced Unicode text processing and comprehensive internationalization support. The documentation covers critical functionalities such as character classification, case conversion, string trimming, and whitespace detection, while also addressing locale-specific rules and encoding error handling. This resource is essential for Cangjie developers and software engineers who aim to build applications requiring sophisticated text analysis, precise input validation, or complex input sanitization, offering the necessary structural definitions to handle diverse text data efficiently.

## Detailed Description

### interface_UnicodeRuneExtension/

This directory contains API reference documentation for the `UnicodeRuneExtension` interface in the Cangjie programming language. It focuses on extending the `Rune` type with robust Unicode character utilities, covering essential text processing tasks such as character classification and case conversion. Key features include methods for identifying letters, numbers, and whitespace, as well as transforming character case (lower, upper, title) with support for locale-specific rules via `CasingOption`. This documentation is suitable for Cangjie developers implementing internationalization, text analysis, or input validation features.

### interface_UnicodeStringExtension/

This directory contains API reference documentation for the `UnicodeStringExtension` interface in the Cangjie programming language. It focuses on extending standard string types with robust Unicode-specific manipulation capabilities, including case conversion (toUpper, toLower, toTitle), whitespace detection (isBlank), and trimming operations (trim, trimStart, trimEnd). The documentation covers function signatures, locale-specific handling via `CasingOption`, and error handling for invalid UTF-8 encoding. It is suitable for Cangjie developers and software engineers requiring advanced text processing, internationalization features, and input sanitization in their applications.
