# cj-common-types

This directory serves as a comprehensive resource for API reference documentation concerning common types within the ArkUI framework, specifically designed for the Cangjie (仓颉) programming language. It focuses on the core data structures that are indispensable for UI development, providing a solid foundation for building modern interfaces. The documentation covers a wide spectrum of essential elements, including geometric attributes like Area and Offset, style configurations such as Color, Font, and Shadow, and interaction events like Event and Gesture. It also includes layout alignment systems such as Alignment and Flex, along with parameters for animations. This collection is tailored for developers utilizing the Cangjie language to create HarmonyOS applications, equipping them with the necessary type specifications and interface details to execute precise UI layouts and sophisticated interaction controls.

## Detailed Description

### 基础类型定义/

This directory contains the ArkUI framework's basic type API reference documentation for the Cangjie language, covering the core data structures required for UI development. The content is comprehensive and primarily includes geometric attributes such as Area and Offset, which define the spatial properties of UI components. It also details style configurations like Color, Font, and Shadow, enabling developers to customize the visual appearance of their applications. Furthermore, the documentation covers interaction events including Event and Gesture, which are essential for handling user input and creating responsive interfaces. Layout alignment mechanisms such as Alignment and Flex are also explained, providing the tools necessary for structuring complex layouts. Additionally, animation parameters are included to support the creation of smooth and dynamic transitions. These documents provide developers with the underlying type specifications and interface descriptions for building HarmonyOS application interfaces. They are suitable for programmers using the Cangjie language for ArkUI application development, aiming to help them master the usage of basic data types to achieve refined UI layout and interaction control.
