# class_Params

This directory provides comprehensive API reference documentation for the Cangjie `Params` class and related static constants within the HarmonyOS development environment. It details system preset string constants used as keys for `Want.parameters`, which are crucial for configuring application behaviors at the system level. The documentation covers a wide range of functionalities, including ability lifecycle management, navigation control, fault detection, and cross-device migration behaviors. Key topics include UIAbility configuration, atomic service sharing, and application continuation logic. This resource is intended for HarmonyOS developers using the Cangjie language who need to implement specific extra parameters for application jumps, manage sharing scenarios, and customize migration logic across devices.

## Detailed Description

The following files provide specific API details for the constants mentioned above.

### class_Params_6more.md class_Params_6more.md
This document provides API reference documentation for the Cangjie Params class, which defines system preset string constants used as keys for Want.parameters. It covers constants related to ability lifecycle management, such as ABILITY_BACK_TO_OTHER_MISSION_STACK for navigation control and ABILITY_RECOVERY_RESTART for fault detection, as well as sharing parameters like CONTENT_TITLE_KEY and SHARE_URL_KEY. Key information includes the specific string values and their functional roles in application jumps and cross-device sharing. Intended for HarmonyOS developers using Cangjie, this reference helps configure extra parameters for UIAbility behaviors and atomic service sharing scenarios.

### static_const_SUPPORT_CONTI_2more.md static_const_SUPPORT_CONTI_2more.md
This API reference document defines static constant strings used to configure cross-device migration behaviors in the Cangjie language. The content details two specific constants: `SUPPORT_CONTINUE_PAGE_STACK_KEY` and `SUPPORT_CONTINUE_SOURCE_EXIT_KEY`. Key information includes that both are String types defaulting to true; the first controls whether page stack information is migrated, while the second determines if the source application exits automatically during the process. These constants belong to the SystemCapability.Ability.AbilityBase system capability starting from version 22. This documentation is intended for HarmonyOS developers using Cangjie who need to customize application continuation and migration logic.
