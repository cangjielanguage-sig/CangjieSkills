This directory provides API reference documentation for the `TelephonyData` class in the Cangjie programming language. It is designed to assist developers in querying cellular network status and SIM card information. The content covers static methods for retrieving data flow types, connection states, default SIM IDs, and slot IDs, as well as checking cellular data and roaming status. Key aspects include handling return types like `DataFlowType` and `DataConnectState`, managing slot indexing, and understanding required permissions such as `ohos.permission.GET_NETWORK_INFO`. This documentation is intended for application developers implementing telephony features who need to access system cellular data capabilities and handle potential business exceptions.
