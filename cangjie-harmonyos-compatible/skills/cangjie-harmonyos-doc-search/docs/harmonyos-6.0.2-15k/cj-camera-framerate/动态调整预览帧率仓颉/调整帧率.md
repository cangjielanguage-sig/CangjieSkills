## 调整帧率

1. 调用[PreviewOutput](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-previewoutput)，查询当前支持的帧率范围。

    > **说明：**
    >
    > 需要在Session调用[commitConfig](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-commitconfig)完成配流之后调用。

    ```cangjie
    func getSupportedFrameRange(previewOutput: PreviewOutput): Array<FrameRateRange> {
        // 获取支持的帧率范围，不同的硬件平台可能提供不同的帧率范围
        return previewOutput.getSupportedFrameRates()
    }
    ```

2. 根据实际开发需求，调用[PreviewOutput](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-previewoutput)类提供的[setFrameRate](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-setframerateint32-int32)接口对帧率进行动态调整。

    > **说明：**
    >
    > - 需要在Session调用[commitConfig](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-commitconfig)完成配流之后调用。
    > - 可在Session调用[start](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-start)启动预览前后任意时刻调用。

    ```cangjie
    func setFrameRate(previewOutput: PreviewOutput, minFps: Int32, maxFps: Int32): Unit {
        previewOutput.setFrameRate(minFps, maxFps)
    }
    ```

3. （可选）通过[PreviewOutput](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-previewoutput)类提供的[getActiveFrameRate](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-getactiveframerate)接口查询已设置过并生效的帧率。

    仅通过[setFrameRate](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-setframerateint32-int32)接口显性设置过帧率才可查询当前生效帧率信息。

    ```cangjie
    func getActiveFrameRange(previewOutput: PreviewOutput): FrameRateRange {
        return previewOutput.getActiveFrameRate()
    }
    ```
