## Detailed Description

### 内置编译标记/

This directory contains detailed documentation on the built-in compilation flags available in the Cangjie language. The content is structured to provide a thorough understanding of how annotations and markers can be leveraged to influence the compilation process and runtime behavior, serving as a critical reference for advanced programming tasks.

Key areas covered include:
*   **Metaprogramming Attributes:** Detailed explanations of attributes such as `@Attribute`, which facilitate metaprogramming capabilities. This section explores how developers can write code that manipulates or introspects other code structures dynamically, enabling powerful abstractions and reducing boilerplate.
*   **API Deprecation Management:** Comprehensive guidance on using markers like `@Deprecated` to manage the evolution of APIs. This helps developers signal to users when specific functions or classes are obsolete, ensuring smoother transitions and better long-term maintainability of software libraries without breaking existing client code immediately.
*   **Compilation Behavior Control:** In-depth documentation on flags like `@When` and `@FastNative`. These markers are crucial for optimizing performance—`@FastNative` is particularly important for bridging to high-efficiency native code—while `@When` allows for controlling logic flow based on compilation conditions, facilitating cross-platform compatibility.

These documents aim to help developers optimize code performance, manage API lifecycles, and achieve cross-platform compatibility. They are suitable for Cangjie language developers and technical personnel who need a deep understanding of compiler directives to build advanced, efficient applications.
