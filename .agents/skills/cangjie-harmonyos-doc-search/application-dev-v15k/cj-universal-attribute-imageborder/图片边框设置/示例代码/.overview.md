## Detailed Description

### 示例1设置渐变色边框.md
This document serves as a code tutorial demonstrating how to apply a gradient color border to UI components using the borderImage interface in the Cangjie programming language. It covers the implementation of a Text component within a Row and Column layout, specifically focusing on the configuration of the BorderImageOption class. Key parameters include the gradient source (linear gradient), slice dimensions, border width, outset, and repeat mode. The example illustrates defining a linear gradient with specific colors and angles, setting edge widths using pixel and viewport units, and applying the STRETCH repeat mode. Targeted at developers using the Cangjie language for HarmonyOS application development, this guide requires basic knowledge of UI component construction and layout management.

### 示例2动态调整属性值.md
This document provides a Cangjie code example demonstrating how to dynamically adjust the properties of the borderImage interface using interactive UI controls. The code defines an EntryView component with state variables for border image attributes. It implements a user interface with sliders for slice, width, and outset values, a select component for repeat modes, and a toggle switch for the fill property. The example illustrates the relationship between state management and UI rendering, showing how changes in slider values or selection states immediately update the visual appearance of a text component's border image. This tutorial is intended for developers using the Cangjie language and UIKit framework to build interactive user interfaces.
