This directory contains API reference documentation for the `Contact` struct and its associated components within the Cangjie programming language. It covers the structural definition of contact objects, including constructors, properties, and specific variables for managing communication data like emails, phone numbers, and postal addresses. The documentation details system capability requirements, data types, and versioning information (starting from version 19). It is suitable for application developers and software engineers building contact management or communication applications who need to understand how to instantiate, manipulate, and store contact data structures using Cangjie syntax and generic collections.
