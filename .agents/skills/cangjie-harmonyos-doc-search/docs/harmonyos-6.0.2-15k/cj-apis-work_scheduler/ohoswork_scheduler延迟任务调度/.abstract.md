This directory provides comprehensive API reference documentation for the `ohos.work_scheduler` module in the Cangjie language, designed for managing delayed task scheduling in HarmonyOS. It covers essential components including enums for trigger conditions (battery, charging, network, storage), data types, and functions for task lifecycle management (start, stop, query). Additionally, it details the `WorkInfo` class for configuring task constraints. Suitable for system developers and application engineers using Cangjie to optimize background task execution based on device states and system idle time.
