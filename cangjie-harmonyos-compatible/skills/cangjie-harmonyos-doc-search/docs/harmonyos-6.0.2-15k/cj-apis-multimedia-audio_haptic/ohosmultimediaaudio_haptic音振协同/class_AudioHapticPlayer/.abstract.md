This directory contains API reference documentation for the `AudioHapticPlayer` class in the Cangjie language, designed for managing synchronized audio and haptic feedback. It covers essential functionalities such as playback control, event handling, resource management, and status queries. Key topics include registering callbacks for interruptions, starting and stopping playback, and managing system capabilities. This documentation is suitable for developers using the AudioKit to build multimedia applications that require integrated sensory experiences, specifically targeting system version 19 and above.
