This directory provides comprehensive API reference documentation for the `MediaAlbumChangeRequest` class within the HarmonyOS PhotoAccessHelper framework, specifically tailored for the Cangjie programming language. It details the mechanisms for handling modification requests for media albums, including initialization, asset manipulation, and property updates. The documentation covers essential aspects such as method signatures, system capabilities, version requirements (API 12+), and error handling via `BusinessException`. It is designed for developers seeking to implement programmatic album management and asset manipulation in HarmonyOS applications.
