This directory contains API reference documentation for core interfaces in the Cangjie programming language, primarily focusing on property-based testing and random data generation. It covers essential interfaces such as `Generator`, `RandomSource`, `Arbitrary`, `ArbitraryRange`, and `Shrink`. These components enable developers to create random values, access data structures, and reduce test cases to minimal failures. The documentation is suitable for Cangjie developers, QA engineers, and software testers working with the `unittest_prop_test` package who need to implement robust testing logic, fuzzing strategies, or custom randomization algorithms.
