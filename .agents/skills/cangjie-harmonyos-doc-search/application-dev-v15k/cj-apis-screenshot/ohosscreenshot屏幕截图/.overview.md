### class_PickInfo_2more.md class_PickInfo_2more.md
This API reference document defines the PickInfo and Rect classes in the Cangjie language for handling image capture information. The documentation covers the properties and constructors for both classes, explaining how to store capture data and define geometric regions. Key takeaways include that PickInfo encapsulates a read-only Rect and a PixelMap object, while Rect defines the capture area's boundaries and dimensions in pixels. Both classes are part of the SystemCapability.WindowManager.WindowManager.Core and require version 19. This guide targets developers working on window management or screen capture functionalities who need to understand the data structures for image picking.

The content targets developers working with system-level window management capabilities on specific hardware form factors.
