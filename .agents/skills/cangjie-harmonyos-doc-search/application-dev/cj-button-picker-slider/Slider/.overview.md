# Slider

This directory contains comprehensive documentation and resources for the ArkUI Slider component within the Cangjie framework. It covers the essential aspects of implementing interactive sliding controls used for adjusting settings like volume or brightness. The content includes API references for initialization, event handling, component properties, and practical code examples. Designed for developers building user interfaces, this collection provides the necessary tools to create customized, responsive, and interactive slider controls with precise control over aesthetics and behavior.

## Detailed Description

### Slider_5more.md Slider_5more.md
This document serves as API reference documentation for the ArkUI Slider component within the Cangjie framework, designed for adjusting settings like volume or brightness. The primary focus is the component's initialization method, which details parameters for setting the minimum, maximum, step size, current value, style, axis direction, and reverse behavior. It specifies default values, such as a range of 0.0 to 100.0, and logic for handling invalid inputs. Additionally, the document lists supported common attributes and events. This guide is intended for developers building user interfaces who need to implement interactive sliding controls.

### 组件事件.md 组件事件.md
This document provides API reference documentation for the onChange event handler of a Slider component within the ArkUI framework. It details the function signature, system capabilities, and version requirements. The main focus is on the callback function that triggers upon user interaction, passing the current progress value and the change mode. Key information includes specific trigger conditions for different states like Begin, End, Moving, and Click, noting that dragging actions do not trigger the Click state. This resource is intended for developers implementing interactive UI controls who need to handle slider value changes and gestures effectively.
