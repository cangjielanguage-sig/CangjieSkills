# class_Path2D

本目录包含仓颉语言中 Path2D 类的 API 参考文档，主要用于在 ArkUI 框架的 Canvas 上进行 2D 图形绘制。内容涵盖了路径的创建（包括空路径和 SVG 字符串）、基本图形绘制（如矩形、圆弧）、复杂曲线（贝塞尔曲线、椭圆）以及路径变换操作。这些接口适用于版本 22 及以上，旨在为开发者提供构建复杂矢量路径的完整技术细节，适合需要进行自定义 2D 图形开发的 ArkUI 应用人员使用。

### func_arcToFloat64_4more_59e8c905.md func_arcToFloat64_4more_59e8c905.md

### func_rectFloat64__2more_92ecad78.md func_rectFloat64__2more_92ecad78.md
本文档是ArkUI开发中Cangjie语言的API参考文档，主要介绍了用于路径绘制的两个核心函数。文档分为两个主要部分，分别详细说明了rect和closePath函数的用法。rect函数用于创建矩形路径，需传入左上角坐标及宽高四个Float64参数，默认单位为vp。closePath函数则用于将当前点连接回起点以闭合路径。文档包含了函数签名、功能描述、系统能力、起始版本（22）及参数详情。目标受众是使用Cangjie进行ArkUI 2D图形开发的开发者，旨在提供精确的接口定义和使用规范。
