# 自定义组件的删除

This directory provides a comprehensive technical overview of the deletion and destruction mechanisms for custom components within the ArkUI framework. It covers the entire lifecycle process, from the initial trigger of component removal to the final garbage collection. Key topics include the `aboutToDisappear` callback, the unbinding of state variables like `@Link` and `@Prop`, and the specific execution order of lifecycle events during conditional rendering, page navigation, and application state changes. The documentation distinguishes between different programming contexts (Cangjie and ArkTS) and navigation methods (`pushUrl` vs. `replaceUrl`). It is essential for developers aiming to master resource management, prevent memory leaks, and ensure smooth state transitions in their applications.
