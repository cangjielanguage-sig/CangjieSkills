# 使用场景

This directory serves as a comprehensive resource for HarmonyOS developers utilizing the Cangjie language, focusing specifically on practical usage scenarios for state management. It details the application of the `@Watch` decorator to monitor state changes and trigger UI updates efficiently. The content covers complex interactions such as parent-child component synchronization via `@Link` and the implementation of conditional logic to handle multiple state variables within a single callback. By exploring these patterns, developers can learn to build responsive, data-driven applications with robust side-effect handling. This collection is essential for those looking to master reactive programming concepts and optimize the rendering performance of their custom components in the HarmonyOS environment.

## Detailed Description

### Watch和自定义组件更新_2more.md Watch和自定义组件更新_2more.md

This technical tutorial explains how to use the @Watch decorator with @Link to manage state changes and UI updates in Cangjie custom components. The document covers two main scenarios: basic component updates and observing array changes within child components. Key takeaways include the execution flow where parent @State changes trigger child @Link updates, invoking @Watch callbacks to modify local state and asynchronously re-render the UI. It targets HarmonyOS developers using Cangjie who need to implement reactive state management and side effects in their applications. Keywords: @Watch, @Link, @State, Cangjie, state management, custom components, UI updates.

### 使用changedPropertyName进行不同的逻辑处理.md 使用changedPropertyName进行不同的逻辑处理.md

This tutorial demonstrates how to implement conditional logic within a shared @Watch callback function in Cangjie development. The document covers the usage of the @Watch decorator with multiple @State variables and manual event handling. The step-by-step explanation details the rendering flow and logic execution. This guide is intended for HarmonyOS developers using the Cangjie language who require advanced state management techniques to handle multiple observed variables with a single function. Keywords: Cangjie, @Watch, @State, HarmonyOS, state management, UI development, callback function.
