This directory contains API reference documentation for fundamental Cangjie classes used in the ArkUI framework to define UI component borders and styling. It covers classes for specifying border colors, widths, and corner radii, with specific support for both standard layouts and internationalized (RTL) interfaces. Key concepts include `EdgeColors`, `EdgeWidths`, `LocalizedBorderRadiuses`, and localized edge properties. These documents are suitable for Cangjie developers and UI designers looking to implement precise, responsive, and localized styling for application components.
