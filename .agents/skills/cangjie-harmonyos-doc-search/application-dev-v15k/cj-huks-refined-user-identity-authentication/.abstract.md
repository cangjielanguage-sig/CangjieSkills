This directory serves as a specialized repository for technical documentation and code examples related to the implementation of fine-grained user identity authentication and access control within the HarmonyOS ecosystem. It specifically targets developers utilizing the Cangjie programming language to build secure applications. The core focus is on the integration of the Universal Keystore Kit (HUKS) to enforce robust secondary authentication mechanisms—such as biometric verification or lock screen passwords—during critical cryptographic operations. By detailing the use of specific tags like `HUKS_TAG_KEY_AUTH_PURPOSE` and supporting modes such as AES/CBC, AES/GCM, and SM4/CBC, this resource provides the necessary guidance for ensuring that sensitive data remains protected and is only accessed following explicit user verification. It is an essential reference for software developers aiming to elevate the security posture of their applications through precise identity management.
