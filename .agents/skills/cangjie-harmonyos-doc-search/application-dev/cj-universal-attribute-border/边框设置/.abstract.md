This directory contains essential API reference documentation for configuring component borders within the Cangjie ArkUI framework. It provides a technical deep dive into styling properties, enabling developers to define the visual boundaries of UI components with precision. The content covers a range of attributes including border width, color, radius, and style, offering both granular control over individual edges and uniform application across the component. Key topics include function overloads, parameter types like `EdgeWidths` and `Length`, and the specific system capability requirements (version 22). This documentation is specifically tailored for Cangjie developers and UI designers who are building user interfaces and need to understand the correct order of operations for method chaining to ensure that border styles are applied effectively and aesthetically. By following these guides, developers can enhance the visual hierarchy and user experience of their applications.
