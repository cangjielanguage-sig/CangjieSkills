# 文本显示TextSpan

This directory focuses on text display and manipulation within the ArkUI framework using the Cangjie programming language. It covers fundamental components like Text and Span, styling customization, event handling, and advanced features such as selection menus and rich text layouts. Key topics include text overflow, alignment, decoration, and interactive text elements. Designed for HarmonyOS developers and UI designers, these resources provide practical code examples to enhance text presentation, readability, and user interaction in applications.

## Detailed Description

### 场景示例.md
This document provides a practical code example demonstrating how to implement a hot search ranking interface using Cangjie UI components. The primary focus is on text display properties and layout management within a list format. Key concepts include the application of maxLines, textOverflow, textAlign, and constraintSize attributes to handle text truncation and alignment effectively. The example illustrates how to style ranking numbers, text labels, and status badges like "Hot" or "Explosive" within a Row and Column structure. This tutorial is intended for developers using the Cangjie language and ArkUI framework who need to create complex text layouts with overflow handling.

### 文本显示TextSpan_2more.md
This document serves as a development guide for implementing text display using the Text and Span components within the ArkUI framework. It covers component definitions, specifically focusing on the creation of Text elements via string literals and AppResource references. The guide details how to bind custom selection menus to Text components and provides Cangjie syntax examples for styling and resource management. It targets UI developers seeking to render text content and manage localization resources effectively.

### 添加事件.md
This document serves as a brief tutorial demonstrating how to bind universal events, specifically click and touch handlers, to the Text component in the Cangjie UIKit framework. The content covers the usage of universal events like onClick and onTouch, providing a practical code example within a Scroll and Column layout. The key takeaway is the syntax for attaching an onClick lambda function to a Text element to execute logging logic upon user interaction. This guide targets HarmonyOS developers using the Cangjie language who need to implement interactive UI components.

### 添加子组件.md
This document serves as a tutorial for developers on implementing the Span component within the ArkUI framework using the Cangjie language. It details how to add Span as a child component to Text or RichEditor to display segmented text content. The guide covers four main topics: creating a Span, setting text decorations and colors via the decoration property, enforcing text casing using textCase, and handling click events. Key information includes the requirement that Span must be embedded in a Text component to render and that it only supports onClick events due to lacking size information.

### 自定义文本样式/
This directory provides a comprehensive guide to customizing text styles within the ArkUI framework using the Cangjie programming language. It covers essential visual adjustments such as text alignment, overflow handling, line height, and decoration lines, alongside advanced features like baseline offset, letter spacing, and adaptive font sizing. Additionally, it addresses text transformation and user interaction capabilities like text copying. These tutorials are designed for HarmonyOS developers and UI designers seeking to enhance the presentation, readability, and interactivity of text components in their applications through practical code examples and clear syntax demonstrations.

### 选中菜单/
This directory provides comprehensive documentation and tutorials focused on the implementation and customization of selection menus for text components within the ArkUI framework. It covers a range of technical topics, including enabling default selection behaviors, binding custom menus using `bindSelectionMenu`, and extending existing menu options via `editMenuOptions`. The content addresses development in both Cangjie and ArkTS, offering code examples for creating custom menu items with specific callbacks and controlling menu visibility. It is specifically designed for UI developers and HarmonyOS engineers who aim to build advanced text interaction features, such as custom copy or translation functions, to enhance the user experience in their applications.
