This directory contains API reference documentation for configuring Webview component properties using the Cangjie language within the ArkWeb framework. It covers a comprehensive range of settings including security permissions, layout modes, font customization, JavaScript interaction, and media playback controls. Developers can find detailed parameters for managing web content rendering, storage access, and user interface behaviors. Suitable for application developers building hybrid applications on HarmonyOS who need granular control over Webview capabilities and system integration.
