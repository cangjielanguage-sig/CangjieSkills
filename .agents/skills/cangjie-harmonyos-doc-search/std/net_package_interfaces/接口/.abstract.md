This directory serves as a comprehensive API reference for network socket interfaces within the Cangjie programming language. It details the specifications for three primary communication paradigms: server-side listening, stream-based connections, and datagram packet transmission. The documentation covers critical aspects such as socket lifecycle management, address binding, timeout configurations, and exception handling for network errors. By defining the inheritance hierarchies and core methods, these documents provide the foundation for building networked applications. This resource is essential for Cangjie developers and systems programmers looking to implement low-level network protocols or manage socket resources efficiently.
