This directory contains API reference documentation for the ArkUI framework's internal interfaces and binding mechanisms within the Cangjie language environment. It primarily focuses on the `CustomView` and `RemoteView` base classes, which serve as foundations for UI components, and the `bind` function used for linking `@Builder` decorated functions to custom components. Key concepts include declarative UI definitions, observed properties, and dynamic UI construction for navigation elements. These documents are strictly intended for system framework developers or advanced ArkUI developers working in a Beta environment, as many classes are marked for internal use only.
