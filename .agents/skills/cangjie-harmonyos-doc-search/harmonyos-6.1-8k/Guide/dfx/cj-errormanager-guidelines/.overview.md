# cj-errormanager-guidelines

本目录提供了Cangjie语言中错误管理功能的全面开发指导，核心目标是帮助开发者有效地监听并处理应用运行时发生的未捕获异常。文档内容涵盖了从场景介绍、接口说明到具体开发示例的完整流程，重点阐述了如何利用`errorManager`模块进行错误观测器的注册与注销。核心知识点包括`on`和`off`接口的使用方法，以及`ErrorObserver`中`onUnhandledException`和`onException`回调函数的具体功能与实现逻辑。通过文档中提供的Cangjie代码示例，开发者能够掌握如何在`UIAbility`生命周期中无缝集成错误监听机制，从而在应用意外退出前获取详细的错误信息并进行上报。这份指南非常适合致力于提升应用稳定性、优化问题排查流程的应用开发者阅读和使用。
