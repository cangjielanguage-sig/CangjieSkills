# cj-crypto-convert-binary-data-to-sym-key

本目录提供了一份专门针对Cangjie编程语言开发者的技术指南，核心主题是加密开发中常见的二进制数据与对称密钥对象之间的转换。文档深入探讨了如何利用现有的二进制数据（如字节数组）构建可用于加解密操作的密钥对象，特别聚焦于3DES和HMAC这两种主流算法的具体实现路径。内容涵盖了从数据封装（DataBlob）、密钥生成器（SymKeyGenerator）的初始化，到最终通过convertKey方法生成密钥并获取编码数据的全生命周期。此外，文档内嵌了详尽的Cangjie代码示例，展示了如何生成192位3DES密钥及HMAC密钥。该资源非常适合已掌握基础加密概念并希望在Cangjie Beta阶段深入实践密钥管理技术的开发者阅读。

## Detailed Description

### cj-crypto-convert-binary-data-to-sym-key.md cj-crypto-convert-binary-data-to-sym-key.md

本文档是一份面向Cangjie开发者的技术教程，主要介绍如何将二进制数据转换为对称密钥对象以用于后续加解密操作。文档重点讲解了3DES和HMAC两种算法的实现流程，包括将数据封装为DataBlob、创建SymKeyGenerator、调用convertKey生成密钥以及获取编码数据的完整步骤。文中提供了具体的Cangjie代码示例，演示了生成192位3DES密钥和HMAC密钥的方法。该文档适合具备基础加密知识的开发者，旨在帮助其在Beta阶段掌握密钥转换技术。
