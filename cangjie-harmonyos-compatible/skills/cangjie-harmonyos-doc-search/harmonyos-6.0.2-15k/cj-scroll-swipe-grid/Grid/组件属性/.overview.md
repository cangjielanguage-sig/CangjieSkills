# 组件属性

This directory contains API reference documentation for configuring properties of the Grid component within the ArkUI framework, specifically using the Cangjie language. It covers a comprehensive range of functionalities including item alignment, layout templates (columns and rows), scrolling behaviors, friction, and scrollbar customization. Key topics involve optimizing performance with LazyForEach, managing grid dimensions, and handling interactive gestures. This documentation is suitable for software developers and UI engineers looking to build responsive, high-performance grid interfaces in ArkUI applications.

## Detailed Description

### func_alignItemsGridItemAli_5more.md
This document provides API reference documentation for configuring Grid component properties in the Cangjie language. It details methods for item alignment, preloading optimization, cell dimensions, and column spacing. Key functions include `alignItems` for positioning, `cachedCount` for LazyForEach performance with options to show preloaded nodes, `cellLength` for defining row or column size based on layout direction, and `columnsGap` for spacing. Each entry specifies parameters, default values, and system capability versions. This technical reference targets ArkUI developers using Cangjie to optimize grid layouts and rendering performance.

### func_columnsTemplateString_5more.md
This document provides API reference documentation for configuring Grid component layout and interaction behaviors in the Cangjie language. It details five key functions: columnsTemplate for defining column structures, edgeEffect for scroll boundary feedback, editMode for item dragging, and enableScrollInteraction for gesture control. Key information includes the use of flexible units like 'fr' and keywords such as 'auto-fit' or 'auto-stretch' within columnsTemplate to dynamically manage column widths. Additionally, edge effects can be customized to trigger even when content is smaller than the component, and edit mode allows for GridItem repositioning. This technical reference is intended for software developers using the ArkUI framework to build responsive and interactive grid interfaces.

### func_frictionFloat64_7more.md
This document serves as an API reference for configuring layout and scrolling behaviors in ArkUI components using the Cangjie language. It details six primary functions: friction for controlling inertial scrolling, layoutDirection for setting the main axis, maxCount and minCount for limiting displayed rows or columns, multiSelectable for enabling mouse selection, and nestedScroll for managing parent-child scroll linkage. Key information includes parameter types, default values, and specific constraints, such as friction values greater than zero and the dependency of count limits on layout direction. This technical guide is intended for developers implementing complex grid or scrollable interfaces in ArkUI applications.

### func_rowsGapLength_2more.md
This document serves as API reference documentation for configuring row properties in the ArkUI Grid component using the Cangjie language. It details the `rowsGap` function for setting inter-row spacing and the `rowsTemplate` function for defining row counts, heights, and layout structures. Key information includes parameter definitions, valid value ranges like fractional units, and the behavior of three distinct layout modes depending on template configurations. The text explains how settings affect scrolling, grid item sizing, and property validity. Intended for developers, this guide requires understanding of grid layout concepts and is essential for implementing responsive or fixed grid interfaces.

### func_scrollBarBarState_4more.md
This document provides API reference documentation for configuring scroll bar properties and animation support in the ArkUI framework using the Cangjie language. It covers four main functions: scrollBar, scrollBarColor, scrollBarWidth, and supportAnimation.
