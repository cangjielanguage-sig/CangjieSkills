This directory serves as a comprehensive resource for HarmonyOS developers regarding system permissions and access controls, specifically targeting API version 12 and later. It encompasses a wide array of permissions necessary for hardware interaction—such as Bluetooth, Camera, and Microphone access—as well as data retrieval for sensitive categories like Calendar, Health, and Media files. Additionally, it addresses specific file system permissions tailored for 2-in-1 devices. The documentation outlines critical implementation details, including permission levels, grant modes (specifically user_grant), and complex workflows like background location access. This collection is essential for developers aiming to ensure compliance and proper functionality when configuring system capabilities in their HarmonyOS applications.
