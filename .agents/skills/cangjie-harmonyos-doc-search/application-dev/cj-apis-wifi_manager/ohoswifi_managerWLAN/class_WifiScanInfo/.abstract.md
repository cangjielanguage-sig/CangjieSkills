This directory serves as a comprehensive resource for API reference documentation regarding the `WifiScanInfo` class within the Cangjie programming language. It is specifically curated to define the data structures necessary for handling WLAN hotspot scan results. The content encompasses critical network parameters such as SSID, BSSID, RSSI, frequency bands, channel width, and security types, offering a complete view of access point attributes. Furthermore, it details system capability requirements, specifically the WiFi STA permission, and establishes version compatibility starting from API version 22. This documentation is highly suitable for developers and engineers involved in creating WiFi connectivity solutions, providing them with the necessary tools to parse, manage, and utilize detailed network information effectively in their software projects.
