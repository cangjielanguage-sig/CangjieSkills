# class_DotIndicator

This directory provides a complete set of API reference materials for the `DotIndicator` class, utilized within the Cangjie language and the HarmonyOS ArkUI development environment. The primary focus of these documents is to guide developers in the implementation and fine-tuning of dot-style navigation indicators for Swiper components. The documentation encompasses a variety of configuration aspects, ranging from basic visual properties like color and size to advanced features such as masking and interaction scaling. It highlights critical default values, such as the 6vp dimension and the 1.33x press scaling factor, as well as the `maxDisplayCount` function for managing content overflow. This resource is indispensable for HarmonyOS developers and UI professionals who are building sophisticated user interfaces and require detailed knowledge of component behavior and styling constraints, particularly for API version 19 and later.

## Detailed Description

The following section provides a comprehensive breakdown of the files included in this directory, offering specific insights into the API methods and configuration options available for the DotIndicator class.

### class_DotIndicator_7more.md class_DotIndicator_7more.md

This document serves as API reference documentation for the DotIndicator class in the Cangjie language, designed to configure dot-style navigation indicators for Swiper components. It details the class constructor and configuration methods controlling visual properties like color, dimensions, and masking. Key takeaways include default dimension values (6vp), a 1.33x scaling effect on press, and the maxDisplayCount function for handling overflow scenarios, which restricts interaction. Intended for HarmonyOS developers using ArkUI, this reference requires prior understanding of UI components and layout parameters.

### func_selectedColorResource_3more.md func_selectedColorResource_3more.md

This API reference document details methods for customizing the appearance of the selected dot indicator within the Swiper component in the Cangjie ArkUI framework. The document covers three specific functions: selectedColor, selectedItemHeight, and selectedItemWidth. Key information includes parameter definitions for ResourceColor and Length types, default values (0x007DFF, 6vp, 12vp), and specific constraints such as the lack of support for percentage values in dimensions. Intended for UI developers, this guide enables precise styling of navigation indicators starting from API version 19.
