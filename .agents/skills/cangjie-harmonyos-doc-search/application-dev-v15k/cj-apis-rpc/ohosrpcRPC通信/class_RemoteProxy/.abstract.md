This directory contains API reference documentation for the Cangjie `RemoteProxy` class, a core component for Inter-Process Communication (IPC). It covers the implementation of `IRemoteObject`, detailing transaction codes, interface management, and connection status checks. Additionally, it includes functions for managing remote object lifecycles, such as registering and unregistering death notifications, and handling message requests. This documentation is essential for developers building distributed applications or services that require robust communication between processes, providing detailed specifications on parameters, return types, and exception handling.
