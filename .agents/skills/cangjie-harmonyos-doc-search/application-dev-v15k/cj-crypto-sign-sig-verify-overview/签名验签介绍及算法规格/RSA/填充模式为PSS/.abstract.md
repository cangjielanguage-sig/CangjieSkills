This directory provides technical documentation and reference guides for implementing RSA cryptographic operations using the Probabilistic Signature Scheme (PSS) padding mode. It covers essential aspects such as parameter construction syntax, compatibility matrices for various key sizes (RSA512 to RSA8192), and specific constraints regarding hash algorithms, Mask Generation Functions (MGF), and salt lengths. Additionally, it addresses API compatibility and key type handling for signature verification. This resource is designed for developers, security engineers, and cryptographers who need to configure or validate RSA-PSS parameters within their systems.
