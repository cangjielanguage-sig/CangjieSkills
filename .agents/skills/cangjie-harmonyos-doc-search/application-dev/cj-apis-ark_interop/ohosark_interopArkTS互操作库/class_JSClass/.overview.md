# class_JSClass

This directory contains API reference documentation for the `JSClass` in the Cangjie programming language, specifically designed for interoperability with ArkTS and JavaScript. It covers the core functionalities of `JSClass`, including instantiating objects from ArkTS class constructors, dynamically defining methods and properties, and managing class prototypes. Key topics include object creation via `new()`, adding accessors, and runtime class manipulation. This documentation is suitable for developers working on cross-language integration who need to dynamically interact with JavaScript objects and class structures within the Cangjie environment.

### class_JSClass_4more.md class_JSClass_4more.md

### func_new_3more.md func_new_3more.md
