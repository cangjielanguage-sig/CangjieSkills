This directory provides comprehensive API reference documentation for the `ohos.telephony_sim` module within the Cangjie programming language, designed for HarmonyOS telephony services. It encompasses the management and retrieval of SIM card information, including hardware types, operational states, and account details. Key components include enumerations for card standards, the `IccAccountInfo` class for data access, and the `TelephonySim` class for core management functions. This documentation is intended for software developers seeking to integrate telephony features, requiring specific permissions and system capabilities starting from API version 19.
