# 气泡提示Popup

This directory focuses on implementing and customizing bubble tip popups within the ArkUI framework using the Cangjie language. It covers essential topics such as system-provided versus custom popups, modal and non-modal configurations, styling attributes, and animation effects. Developers will learn how to use `bindPopup`, handle state changes, and create interactive UI components. This resource is suitable for application developers looking to enhance user interface interactions with informational alerts, overlays, and dynamic visual feedback.

## Detailed Description

### 气泡提示Popup_4more.md 气泡提示Popup_4more.md
This document serves as a development guide for implementing bubble tip popups within the ArkUI framework using the Cangjie language. It covers the distinction between system-provided PopupOptions and custom CustomPopupOptions, modal versus non-modal window configurations, and specific implementation scenarios including text-only popups, state change event handling, and interactive popups with buttons. Key concepts include the bindPopup attribute, the mask property for window modes, and the use of primaryButton and secondaryButton for user interaction. The target audience is application developers seeking to add informational alerts or screen recording overlays to their UI components.

### 气泡样式.md 气泡样式.md
This document serves as a technical guide for customizing the visual appearance and behavior of popup bubbles in ArkUI applications using the Cangjie language. It details specific styling attributes including background color, mask transparency, sizing logic, and placement positioning relative to the host component. Key takeaways include understanding default behaviors like the transparent background with blur effects and learning how to override them using the PopupOptions interface. The provided code example demonstrates practical implementation of parameters such as popupColor, mask, and placement. This resource is intended for developers looking to refine UI interactions and component styling within the ArkUI framework. Keywords: ArkUI, Cangjie, Popup, PopupOptions, UI styling, bindPopup.

### 气泡的动画_2more.md 气泡的动画_2more.md
This tutorial demonstrates how to implement and customize popup animations and content in the ArkUI framework using the Cangjie language. The document covers two main topics: defining transition effects for entry and exit animations using TransitionEffect, and creating custom popups via CustomPopupOptions with @Builder functions. Key takeaways include using the bindPopup method to attach popups to components, configuring parameters like placement and popupColor, and applying specific animation types such as opacity, translation, and scaling. This guide is intended for ArkUI developers seeking to enhance user interface interactions with dynamic and styled popup components.
