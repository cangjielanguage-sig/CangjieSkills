# cj-apis-app-ability-app_recovery

本目录包含仓颉语言中 `ohos.app.ability.app_recovery` 模块的 API 参考文档，专注于提供应用在故障状态下的恢复能力。文档详细涵盖了模块导入方法、运行所需权限列表，以及核心函数 `restartApp()` 的完整说明。关键内容包括重启进程并拉起 Ability 的具体规则、状态数据的传递机制、与 `ErrorManager` 的协同工作方式，以及防止频繁重启的一分钟内调用限制。该资源主要面向仓颉应用开发者，旨在通过提供在 `index.cj` 或 `main_ability.cj` 中的配置与运行示例，帮助开发者轻松实现应用的自动或主动重启功能，从而显著提升应用的健壮性和用户体验。
