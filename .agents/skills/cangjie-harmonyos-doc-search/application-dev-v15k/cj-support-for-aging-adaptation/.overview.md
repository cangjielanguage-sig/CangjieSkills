# cj-support-for-aging-adaptation

This directory serves as a comprehensive technical resource hub dedicated to implementing "Age-Friendly Adaptation" (适老化) within HarmonyOS applications, specifically tailored for developers utilizing the Cangjie language and the ArkUI framework. It addresses the critical necessity for digital accessibility by offering in-depth guidance on supporting system font scaling up to 3.2x, maintaining robust layout stability, and leveraging specific system components for magnification. The repository covers essential adaptation rules, precise configuration methods within `app.json5`, and strategic approaches to prevent UI overlap during scaling processes. This collection is highly suitable for developers aiming to create inclusive, responsive, and accessible user interfaces that effectively cater to the needs of elderly users, ensuring a comfortable, legible, and seamless user experience across various device settings and accessibility preferences.

## Detailed Description

### 支持适老化/

This directory provides comprehensive technical resources for implementing "Age-Friendly Adaptation" (适老化) in HarmonyOS applications. It focuses on ensuring applications are accessible to elderly users by supporting system font scaling, maintaining layout stability, and utilizing specific system components for magnification. The content covers adaptation rules for scaling levels up to 3.2x, configuration methods in `app.json5`, and strategies to prevent UI overlap. Designed for developers using the Cangjie language and ArkUI framework, this collection includes detailed guides, component behavior specifications, and practical code examples to create responsive and accessible user interfaces.

**Key Technical Areas:**
*   **Scaling Adaptation:** It provides detailed rules and implementation details for supporting font scaling levels up to 3.2x, ensuring text remains readable for all users.
*   **Layout Integrity:** It outlines strategies to ensure the UI remains stable and prevents overlap when interface elements are magnified or scaled.
*   **Configuration:** It offers step-by-step methods for setting up adaptation features in `app.json5`, allowing for easy integration into existing projects.
*   **Framework Specifics:** It includes resources specifically optimized for the Cangjie language and ArkUI component behaviors, ensuring compatibility and performance.
