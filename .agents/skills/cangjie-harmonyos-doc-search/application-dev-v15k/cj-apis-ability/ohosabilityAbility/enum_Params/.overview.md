# enum_Params

This directory contains comprehensive API reference documentation for the `Params` enum within the HarmonyOS ability framework, specifically tailored for the Cangjie programming language. It serves as a technical resource for developers looking to understand and implement parameter configurations for system capabilities. The content covers a wide array of constants used in Want parameter operations, including display modes, cross-device continuation flags, and page stack management. Key topics include ability recovery, app cloning, content sharing, atomic service routing, and inter-component communication. The documentation also details utility methods such as operator overloads for equality checks, `getValue`, and `toString`. This reference is essential for developers building complex applications that require deep integration with the HarmonyOS system runtime and cross-device interaction features.
