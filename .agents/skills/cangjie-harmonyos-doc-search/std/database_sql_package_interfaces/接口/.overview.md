# 接口

This directory contains API reference documentation for the core interfaces within the Cangjie database SQL package. It defines the standard contracts for database interactions, including connection management, query execution, transaction control, and result handling. Key components include interfaces for `Connection`, `Datasource`, `QueryResult`, `Transaction`, and `Statement`, alongside metadata definitions like `ColumnInfo` and legacy type definitions. This documentation is essential for developers implementing database drivers or building applications that interact with SQL databases using the Cangjie programming language, providing the necessary structural and behavioral specifications for robust data access.

## Detailed Description

### interface_ColumnInfo.md
This API documentation defines the Cangjie ColumnInfo interface, which provides metadata for columns returned by database Select or Query statements. The document details six properties: displaySize, length, name, nullable, scale, and typeName. Key information includes specific behaviors for the length property across different data types, such as representing precision for numbers or bytes for binary data, and the mapping logic for typeName relative to Cangjie types. This reference guide targets developers implementing or using database drivers who need to programmatically inspect result set structures and data type constraints.

### interface_Connection.md
This document provides API reference documentation for the Connection interface within the Cangjie database SQL package, defining the standard contract for managing database connections. It covers the interface structure, which inherits from the Resource type, and details its core members: the state property and methods createTransaction, getMetaData, and prepareStatement. Key information includes that the interface handles connection states, creates transaction objects, retrieves metadata as a string map, and prepares SQL statements using ? placeholders. It also outlines potential SqlException scenarios. This reference is intended for developers implementing database drivers or interacting with data sources, requiring an understanding of SQL syntax and resource management.

### interface_Datasource_2more.md
This document provides API reference documentation for two core interfaces within the database SQL package of the Cangjie programming language. It details the `Datasource` interface, which inherits from `Resource`, and the `Driver` interface. Key information includes the `Datasource` methods for establishing connections and setting options, alongside `Driver` properties for metadata like name, version, and connection pooling affinity. The `Driver` interface also defines the `open` function to instantiate data sources. This reference is intended for developers implementing database drivers or managing database connections, requiring knowledge of Cangjie syntax and SQL concepts.

### interface_QueryResult.md
This API documentation defines the QueryResult interface, which represents the result set of a SQL Select statement in the Cangjie programming language. The document details the interface inheritance from Resource, the columnInfos property for metadata, and methods for data retrieval and iteration. Key functions include next() for row traversal, get() for retrieving values, and getOrNull() for handling nullable database columns. A deprecated next overload is also noted. This reference is intended for developers implementing or using database drivers who need to understand how to navigate and extract data from query results.

### interface_SqlDbType_supdep_2more.md
This API documentation defines the deprecated `SqlDbType` and `SqlNullableDbType` interfaces for the Cangjie programming language, serving as parent classes for SQL data types. The document details the `name` property and strict implementation requirements, including single-parameter constructors and public `value` properties. It distinguishes between standard types and nullable types, where null values are represented using `Option.None`. Key takeaways include the deprecation warnings and the specific structural constraints for user-defined types. This reference guide targets developers extending database functionality who need to understand legacy type definitions before their removal.

### interface_Transaction.md
This API reference document defines the Transaction interface in the Cangjie language, specifying the core behaviors and properties required for managing database transactions. The documentation details mutable properties for transaction configuration, such as access mode, deferrable mode, and isolation level, alongside essential lifecycle methods including begin, commit, and rollback. Key information includes support for savepoint management through save, release, and named rollback functions, with all operations potentially throwing SqlException on errors. This guide targets developers implementing database drivers or applications requiring transaction control, assuming prior knowledge of SQL concepts and Cangjie syntax.

### interface_UpdateResult.md
This API reference document defines the UpdateResult interface in the Cangjie programming language, designed to represent the outcomes of database modification statements. The documentation outlines the interface structure and details two essential properties: lastInsertId and rowCount. Key takeaways include that lastInsertId retrieves the auto-generated identifier from an Insert operation, returning 0 if unsupported, while rowCount reports the number of rows affected by Insert, Update, or Delete commands. Both properties utilize the Int64 type. This resource is intended for Cangjie developers implementing database logic or drivers who require a standard contract for handling query execution results.

### interface_Statement/
This directory provides comprehensive API reference documentation for the `Statement` interface within the Cangjie database package. It focuses on defining the contract for SQL statement pre-execution, covering essential operations such as parameter binding, query execution, and data updates. Key topics include the interface definition, property details for parameter metadata, and specifications for functions like `set`, `setNull`, `query`, and `update`. The directory also includes documentation for a deprecated function designed to execute SQL statements using array parameters, which is crucial for maintaining older codebases. This content is primarily suitable for developers implementing database drivers, maintaining legacy codebases, or utilizing the database SQL package, requiring a strong understanding of SQL execution mechanics and the Cangjie language.
