This directory hosts a comprehensive development guide designed for reading and editing image EXIF metadata specifically within the HarmonyOS ecosystem, utilizing the Cangjie programming language. It provides a deep dive into EXIF concepts, details supported formats such as JPEG, and offers a step-by-step tutorial on creating an ImageSource to manipulate image properties effectively. The guide includes practical Cangjie code examples that show how to retrieve file descriptors, read specific properties like BitsPerSample, and modify data such as ImageWidth using the ImageKit API. It is highly suitable for HarmonyOS developers building gallery or camera applications who require manual correction or management of photo metadata.
