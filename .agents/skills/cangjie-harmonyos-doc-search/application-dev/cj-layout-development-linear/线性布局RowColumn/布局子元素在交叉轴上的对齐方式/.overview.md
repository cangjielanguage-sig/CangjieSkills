# 布局子元素在交叉轴上的对齐方式

This directory serves as a technical resource for developers working with the ArkUI framework and Cangjie language, focusing specifically on the alignment of child elements along the cross axis in layout containers. It provides in-depth explanations and practical examples for controlling vertical positioning within Row containers and horizontal positioning within Column containers. The content covers essential properties such as `alignItems` for global container settings and `alignSelf` for overriding alignment on individual elements, emphasizing the priority of these properties. By including detailed code examples, screenshots, and diagrams, this guide helps developers achieve precise UI layout control and consistent presentation across various screen sizes. It is suitable for both beginners learning layout basics and experienced developers refining their interface design skills.
