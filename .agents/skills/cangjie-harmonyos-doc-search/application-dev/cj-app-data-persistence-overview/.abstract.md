This directory provides a detailed technical overview of application data persistence mechanisms specifically engineered for the OpenHarmony standard system. It addresses the critical development task of saving memory data to persistent device storage, ensuring data survives application restarts and system reboots. The documentation thoroughly analyzes three primary data storage architectures: Preferences, Key-Value (KV) Store, and Relational Store. It offers essential comparisons, noting that Preferences provide high-speed access for small configuration volumes, KV-Store functions as a non-relational database optimized for distributed scenarios and simple relationships, and Relational Store manages complex data structures using rows, columns, and custom SQL. This resource is indispensable for OpenHarmony developers, software engineers, and system architects who need to evaluate and select the most appropriate persistence strategy to meet their application's specific performance, scalability, and data complexity requirements.
