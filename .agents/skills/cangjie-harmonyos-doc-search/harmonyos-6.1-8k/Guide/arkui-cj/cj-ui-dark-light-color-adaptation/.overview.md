# cj-ui-dark-light-color-adaptation

本目录提供了仓颉应用开发中UI深浅色模式适配的完整指南。文档详细介绍了颜色资源的自定义与系统调用、图片资源的限定词适配及SVG填充色调整，以及Web组件的深色模式配置。核心内容包括通过创建`dark`目录定义深色资源、利用系统资源ID实现自动切换，以及使用`fillColor`属性适配SVG图标。该指南适用于需要实现UI主题切换功能的仓颉应用开发者，旨在提升用户在不同显示模式下的视觉体验。
