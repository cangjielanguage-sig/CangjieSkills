# 使用AVPlayer设置播放URL

This directory serves as a comprehensive technical resource for developers working with the AVPlayer framework in the Cangjie language, specifically focusing on the configuration of playback URLs. It covers essential implementation scenarios ranging from streaming media playback to local RAW file handling. The content distinguishes clearly between network resources, application sandbox files, and HAP package resources, providing specific code examples and property usage for each context. It is highly suitable for HarmonyOS application developers and multimedia engineers looking to integrate robust media playback capabilities into their applications using AVPlayer and MediaKit. The guides ensure developers can correctly trigger the initialized state for various media sources.

## Detailed Description

### 使用AVPlayer设置播放URL.md 使用AVPlayer设置播放URL.md
This development guide provides instructions on configuring playback URLs using the AVPlayer framework across different usage scenarios. The document details specific methods for setting URLs in two primary contexts: streaming media playback and local RAW file playback. It clarifies that this guide focuses exclusively on URL configuration rather than complete playback implementation, directing readers to a separate video playback guide for comprehensive examples. Intended for developers seeking to implement media playback functionality, this resource targets those needing to handle both network streams and local resources within their applications.

### 本地RAW文件播放场景下设置URL.md 本地RAW文件播放场景下设置URL.md
This technical guide explains how to configure playback URLs for local RAW files using the AVPlayer component in the Cangjie language. It covers two distinct scenarios: playing files from the application sandbox and playing resources bundled within the HAP package. Key sections demonstrate code examples for obtaining file descriptors (fd) and assigning them to the player, distinguishing between the url property for sandbox paths and the fdSrc property for HAP resources. The document highlights the use of FileFs.open and resourceManager.getRawFd to trigger the initialized state. It targets HarmonyOS application developers seeking to implement local media playback functionality.

### 流媒体播放场景下设置URL/
This directory provides a technical overview and implementation guide for setting media URLs in streaming scenarios using the Cangjie language. It focuses on the AVPlayer component and MediaKit, covering essential tasks such as playing standard HTTP/HTTPS resources, managing HLS (m3u8) streams for live or VOD, and customizing HTTP headers for authentication. The content also explores advanced use cases like using local RAW file descriptors and parsing local m3u8 files within the application sandbox to trigger online playback. These resources are tailored for Cangjie developers and multimedia engineers seeking to build robust streaming applications with flexible resource handling capabilities.
