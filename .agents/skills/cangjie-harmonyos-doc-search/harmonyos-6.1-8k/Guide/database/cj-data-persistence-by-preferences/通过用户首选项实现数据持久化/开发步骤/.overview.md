# 开发步骤

本目录包含仓颉语言在HarmonyOS应用开发中的轻量级数据存储教程，重点讲解Preferences API的使用。内容涵盖了从模块导入、实例获取、数据读写与删除、持久化操作到数据变更监听的完整流程，以及如何彻底移除Preferences实例及其文件。文档旨在帮助具备基础仓颉语言能力的开发者快速掌握本地数据持久化技术，适用于需要管理用户偏好设置或轻量级数据的场景。关键词：Preferences、数据持久化、仓颉、API教程。

## 详细描述

### 开发步骤_1.md 开发步骤_1.md
本文档是一份针对仓颉语言的轻量级数据存储开发教程，旨在指导开发者使用Preferences API进行本地数据管理。内容涵盖模块导入、获取实例、数据写入与读取、数据删除、持久化操作、数据变更订阅以及文件删除等八个主要步骤。重点介绍了put、get、delete、flush等核心方法的使用，以及通过自定义Callback实现数据变更监听的机制。适用于具备基础仓颉语言和HarmonyOS应用开发能力的开发者，帮助其快速掌握轻量级数据持久化技术。关键词：Preferences、数据持久化、仓颉、API教程。

### 开发步骤_2.md 开发步骤_2.md
本文档主要介绍如何使用deletePreferences方法从内存及持久化存储中彻底移除指定的Preferences实例及其相关文件。涵盖了方法的功能描述、调用后的注意事项以及Cangjie语言的示例代码。关键信息包括：该方法会同时删除备份和损坏文件；调用后严禁继续使用该实例以免数据不一致；删除操作不可逆。面向使用Cangjie语言进行应用开发的程序员，适用于需要清理或重置用户偏好数据的场景。
