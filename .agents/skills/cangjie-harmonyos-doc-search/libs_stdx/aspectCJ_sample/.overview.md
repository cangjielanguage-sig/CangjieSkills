# aspectCJ_sample

This directory provides a comprehensive educational framework for Cangjie developers seeking to implement Aspect-Oriented Programming (AOP) within their software projects. By utilizing the `stdx.aspectCJ` library, the content demonstrates how to effectively separate cross-cutting concerns—such as logging, security checks, and performance monitoring—from the main business logic. The tutorial focuses on compile-time behavior modification, offering deep dives into specific annotations like `@InsertAtEntry`, `@InsertAtExit`, and `@ReplaceFuncBody`. These tools allow developers to inject code at precise execution points or completely replace function logic while preserving the original context. Additionally, the directory addresses the practicalities of the development environment by detailing the mandatory two-step Linux compilation process, which requires specific plugins like `libcollect-aspects.so` and `libwave-aspects.so`. This resource is invaluable for developers who want to write cleaner, more modular, and maintainable Cangjie code by leveraging advanced metaprogramming techniques to handle systemic functionalities elegantly. It is particularly suitable for those with a grasp of basic Cangjie syntax who are ready to explore more advanced, structural programming capabilities to improve software architecture.
