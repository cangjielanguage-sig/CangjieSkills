### class_FuzzDataProvider_1.md class_FuzzDataProvider_1.md
这是一份关于仓颉编程语言中FuzzDataProvider类的API参考文档，旨在介绍该工具类的定义及其在模糊测试中的用途。文档主要包含类的代码定义，展示了其公共属性data、remainingBytes和offset的类型与结构，并简述了其核心功能。关键信息在于该类作为工具，能够将变异数据的字节流转化为标准的仓颉基本数据类型，支持多种数据结构。该文档面向使用仓颉语言进行模糊测试开发的程序员，帮助他们理解如何利用此类处理测试数据流。

### class_FuzzDataProvider_2.md class_FuzzDataProvider_2.md
本文档是 FuzzDataProvider 类的 API 参考手册，详细列出了用于从模糊测试数据源中提取各种数据类型的方法。主要内容包括布尔值、整数、浮点数、字节数组及字符串（ASCII/UTF8）的获取接口。关键点在于，所有基础类型消耗方法在变异数据不足时均会抛出 ExhaustedException，而字符串方法支持指定最大长度。此外，还提供了将剩余数据全部转换为字节数组或字符串的 API。该文档面向编写模糊测试用例的开发者，旨在提供标准化的数据消耗接口。

### class_FuzzDataProvider_3.md class_FuzzDataProvider_3.md
该文档主要阐述了当输入数据长度不足时，FuzzDataProvider 的行为机制及异常处理策略。涵盖了 fuzz 框架对 ExhaustedException 的自动捕获机制、变异数据随时间增长的特性，以及达到最大长度限制时的进程退出逻辑。关键点在于开发者通常无需手动捕获 ExhaustedException，框架会自动通知 libfuzzer 继续变异。若达到 max_len 仍无法满足需求，进程将退出，建议修改测试用例而非盲目增大 max_len。面向使用该框架编写模糊测试的开发者，属于 API 使用指南的一部分。
