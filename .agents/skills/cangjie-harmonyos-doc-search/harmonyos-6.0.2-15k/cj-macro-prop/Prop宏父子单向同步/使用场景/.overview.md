# 使用场景

This directory contains technical tutorials and examples focused on state management usage scenarios within the Cangjie ArkUI framework. It specifically explores the synchronization mechanisms between parent and child components using the @State and @Prop decorators. Key topics include handling nested object states, managing array item synchronization, and understanding one-way data flow for simple data types. These guides are essential for HarmonyOS developers looking to master complex component interactions, deep observation of class properties, and efficient UI updates in their applications.

## Detailed Description

### Prop嵌套场景.md Prop嵌套场景.md
This tutorial demonstrates how to handle nested object state management using the @Prop decorator in Cangjie for ArkUI development. It covers the definition of nested classes decorated with @Observed, the usage of @Prop to receive nested data in child components, and the propagation of state changes across object layers. The core takeaway is that every layer of a nested class structure must be decorated with @Observed, and every layer must be received via @Prop to ensure the UI correctly perceives and updates based on nested data changes. This guide targets HarmonyOS developers using Cangjie who need to manage complex, hierarchical state within their application components.

This technical tutorial illustrates data synchronization patterns in Cangjie ArkUI, specifically how parent component @State variables sync with child component @Prop variables. The document is divided into two main examples: passing a single class object and passing array items. Key takeaways include the use of the @Observed and @Publish decorators to enable deep observation of nested class properties, ensuring that modifications within child components update the parent state. It also demonstrates using ObservedArrayList for tracking array modifications. This guide is intended for developers implementing complex state management and component communication in HarmonyOS applications.

### 父组件State到子组件Prop简单数据类型同步.md 父组件State到子组件Prop简单数据类型同步.md
This tutorial demonstrates one-way data synchronization between a parent component's @State variable and a child component's @Prop variable using simple data types in Cangjie. The document presents a countdown game example to illustrate component initialization, state management, and rendering triggers. Key takeaways include that parent state changes automatically update child props, while child prop modifications do not sync back to the parent. Additionally, any subsequent parent updates will overwrite local changes made within the child component. This guide is intended for developers learning ArkUI state management and component interaction patterns.

### 父组件State数组项到子组件Prop简单数据类型同步.md 父组件State数组项到子组件Prop简单数据类型同步.md
This technical tutorial demonstrates the synchronization behavior between a parent component's @State array items and a child component's @Prop simple data types in the Cangjie UI framework. The document covers a code example involving a parent EntryView and child Child component, illustrating direct initialization and ForEach rendering, followed by an analysis of state changes upon user interaction. Key takeaways include that @Prop creates a local copy, meaning child modifications do not sync back to the parent. It highlights that replacing the entire parent array triggers ForEach updates based on diff algorithms but may not update direct index-bound props, and explains how component state is preserved for matching keys. This guide targets UI developers using Cangjie, requiring knowledge of state management decorators like @State and @Prop.
