# 基于Cangjie编写和执行测试

This directory serves as a comprehensive technical resource for developers focusing on the complete lifecycle of testing HarmonyOS applications using the Cangjie language. It encompasses the initial setup of the development environment using DevEco Studio, the creation of both unit and UI automated test scripts, and the execution of these scripts on connected hardware devices. The documentation details specific procedures for writing assertions, utilizing the UiTest framework, and running tests via graphical or command-line interfaces. This guide is essential for HarmonyOS developers and QA engineers seeking to establish a robust automated testing workflow.

## Detailed Description

### 执行测试脚本.md 执行测试脚本.md
This technical guide outlines procedures for executing test scripts on connected hardware devices within the DevEco Studio environment. It covers two primary execution methods: the graphical interface in DevEco Studio and the command-line interface (CMD) using the aa test command. Key information includes parameter configurations for bundle names, module names, and specific test runners. The document explains that execution is currently limited to TestClass granularity and provides examples of command syntax and XML result interpretation. Targeted at developers, this guide requires prior knowledge of hdc environment variables and hardware connectivity for application testing.

### 搭建环境.md 搭建环境.md
This document acts as a setup guide for establishing the HarmonyOS development environment. The primary topic covered is the installation and configuration of DevEco Studio, the official integrated development environment for HarmonyOS. Key information includes a direct reference to the official developer website for downloading the software and instructions to perform subsequent configuration steps. The document is intended for software developers preparing to build HarmonyOS applications, serving as an initial prerequisite step. Relevant keywords include DevEco Studio, HarmonyOS, environment setup, IDE configuration, and development tools.

### 新建和编写测试脚本.md 新建和编写测试脚本.md
This document serves as a tutorial for developers on creating and writing test scripts in DevEco Studio using the Cangjie language. It covers creating Instrument Tests within the ohosTest directory, writing unit test scripts with essential elements like imports and assertions, and developing UI test scripts using the UiTest framework. Key information includes the requirement for unit tests to contain assertion interfaces and the method for UI tests to extend unit tests by adding interaction capabilities like finding components and clicking. The guide targets HarmonyOS application developers seeking to implement automated testing for their applications.
