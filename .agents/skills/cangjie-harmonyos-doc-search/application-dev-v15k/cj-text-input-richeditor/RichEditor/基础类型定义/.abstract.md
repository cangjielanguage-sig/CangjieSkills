This directory contains fundamental type definitions and API references for the ArkUI framework using the Cangjie programming language. It primarily focuses on data structures, classes, and enumerations essential for building rich text editing interfaces, including text styling, image handling, clipboard events, and layout configurations. Key components include RichEditor controllers, span styles, and event handling classes. This documentation is suitable for HarmonyOS developers and software engineers who need to implement complex text manipulation, custom menus, and dynamic UI styling within their applications.
