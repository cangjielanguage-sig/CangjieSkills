# CheckboxGroup

This directory contains documentation for the CheckboxGroup component within the ArkUI framework using the Cangjie language. It covers the implementation of checkbox groups for managing multi-selection states, including "select all" functionality, custom styling, and event handling. Key topics include component initialization, attribute configuration, state management, and basic type definitions like `CheckboxGroupResult`. This resource is suitable for HarmonyOS developers and software engineers looking to build interactive user interfaces with complex form controls and selection logic.

### CheckboxGroup_7more.md CheckboxGroup_7more.md
This document serves as API reference documentation for the CheckboxGroup component in the ArkUI framework using the Cangjie language. It details how to create and manage a group of checkboxes to control select all or unselect all states. Key sections include the component initialization method, specific attributes for setting selection status and colors, and event handling for state changes. Important takeaways include that individual Checkbox properties override group settings and that manual state control is required when using cached components like Lists. This technical guide is intended for developers implementing complex selection logic in their applications.

### 基础类型定义.md 基础类型定义.md
This document serves as an API reference defining basic data structures for managing checkbox group states within the Cangjie ArkUI framework. It primarily details the CheckboxGroupResult class, which encapsulates the selected names and status of checkboxes, and the OnCheckboxGroupChangeCallback type alias for event handling. Key information includes the class's read-write properties, constructor parameters, and system capability requirements starting from version 22. Intended for software developers, this documentation provides the essential type definitions needed to implement and track multi-selection interactions in user interfaces.
