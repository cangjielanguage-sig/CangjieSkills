# 示例代码

This directory contains a collection of code examples demonstrating advanced layout techniques using the RelativeContainer component in the Cangjie UI framework. It covers essential concepts such as anchoring components to containers or siblings, setting margins and offsets, implementing guidelines and barriers, and configuring horizontal chains. These examples provide practical solutions for complex relative positioning and constraint-based layouts. Suitable for developers and system integrators working with HarmonyOS applications, this resource helps master precise UI configuration and responsive design behaviors using Cangjie syntax.

## Detailed Description

### 示例1以容器和容器内组件作为锚点进行布局.md 示例1以容器和容器内组件作为锚点进行布局.md
This document serves as a code tutorial demonstrating how to utilize the alignRules interface to position components within a RelativeContainer using anchors. The main topic covers relative layout strategies, specifically anchoring child components to the parent container or to other sibling components. Key information includes the use of the __container__ keyword for parent alignment and component IDs for inter-component positioning, utilizing VerticalAnchor and HorizontalAnchor to define precise placement rules. This example is designed for developers working with the Cangjie language and UI framework who need to understand complex layout dependencies and relative positioning.

The examples demonstrate how to manipulate component positioning using properties like margin, bias, and guideLine to achieve complex relative layouts. Targeted at developers familiar with Cangjie syntax and basic UI concepts, this guide serves as a reference for implementing precise relative positioning in HarmonyOS applications.

### 示例5设置屏障.md 示例5设置屏障.md
This document serves as a code tutorial demonstrating how to utilize the barrier interface within a RelativeContainer to manage complex component alignment in Cangjie. The main topic covers the implementation of layout barriers, specifically focusing on the barrier function and BarrierDirection parameters. Key information includes the creation of two barriers, one vertical (RIGHT) and one horizontal (BOTTOM), which dynamically calculate their position based on referenced components. Child components then anchor to these barriers using AlignRuleOption, ensuring responsive layout adjustments. This example is intended for UI developers using the Cangjie language for HarmonyOS application development, providing a practical reference for relative positioning and constraint-based layouts.
