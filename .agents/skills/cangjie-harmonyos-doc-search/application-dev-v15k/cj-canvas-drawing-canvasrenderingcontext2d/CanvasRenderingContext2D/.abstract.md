This directory provides comprehensive documentation for the `CanvasRenderingContext2D` interface within the Cangjie UIKit and ArkUI frameworks. It covers essential 2D drawing operations, including rendering shapes, text, images, and managing canvas settings. Key topics include performance optimization for drawing instructions, text measurement, and rendering context configuration. The documentation highlights critical constraints such as rendering queues and dimension limits. This resource is suitable for Cangjie and HarmonyOS developers who need to implement custom graphics, manage rendering lifecycles, or perform precise layout calculations in their applications.
