# enum_CommonEventBatteryChangedKey

This directory contains API reference documentation for the Cangjie programming language, specifically focusing on the `CommonEventBatteryChangedKey` enum. It covers query keys used to access detailed data within battery change common events, such as state of charge (SOC), charging status, and health metrics. The documentation includes enum members, operator overloads, and utility functions like `toString`. Designed for developers working on power management features, these resources require the `SystemCapability.PowerManager.BatteryManager.Core` capability starting from version 19. This guide is essential for those implementing battery monitoring or debugging power-related system events, providing the necessary tools to programmatically extract and interpret battery status information efficiently.
