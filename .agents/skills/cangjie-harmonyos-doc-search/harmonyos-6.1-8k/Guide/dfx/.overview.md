# dfx

This directory serves as a comprehensive repository for the Design for X (DFX) and Performance Analysis Kit documentation within the Cangjie and OpenHarmony ecosystem. It covers critical aspects of application stability and performance, including fault detection, logging, event subscription, performance tracing, and error management. Key topics include handling application freezes (AppFreeze), process crashes, and utilizing tools like HiLog, HiTraceMeter, and HiAppEvent. This resource is suitable for Cangjie developers and system engineers focused on application debugging, performance optimization, and fault troubleshooting.

## Detailed Description

### README_zh/
This directory is the core index document for the performance analysis service in Cangjie application development, aiming to provide developers with comprehensive guidance for fault troubleshooting and performance optimization. Content covers fault detection (including process crashes and application unresponsiveness), logging, event subscription (covering application and system events), performance tracking, error management, and the use of command-line tools. The documentation details how to use HiAppEvent to subscribe to crash and freeze events, as well as using tools like hdc and hitrace for system debugging. All features are currently Beta, making this suitable for Cangjie developers needing application debugging and performance analysis.

### cj-appfreeze-guidelines/
This directory serves as a specialized technical repository focusing on the critical aspect of application stability within the OpenHarmony and HarmonyOS operating environments. It addresses the phenomenon of Application Freezes (AppFreeze), offering technical guidelines and analysis methods to help developers maintain application responsiveness.

### cj-cangjiecrash-guidelines/
This repository serves as a comprehensive technical resource designed to assist developers in analyzing and troubleshooting process crashes within the Cangjie language ecosystem. It provides in-depth guidance on critical topics such as interpreting crash dumps, understanding failure causes, and implementing robust error handling mechanisms.

### cj-errormanager-guidelines/
This directory provides comprehensive development guidance for error management functionality in the Cangjie language, with the core goal of helping developers effectively listen to and handle uncaught exceptions during application runtime. The documentation covers the complete process from scenario introduction and interface descriptions to specific development examples. It focuses on using the `errorManager` module to register and unregister error observers. Key knowledge points include the usage of `on` and `off` interfaces, as well as the specific functionality and implementation logic of the `onUnhandledException` and `onException` callback functions in `ErrorObserver`.

### cj-hiappevent-event-reporting/
This directory serves as a comprehensive resource for the `cj-hiappevent-event-reporting` module, specifically designed for developers working within the Cangjie and ArkUI ecosystem. It focuses on the critical functionality of application event handling, providing the necessary tools and instructions to implement effective event reporting mechanisms.
