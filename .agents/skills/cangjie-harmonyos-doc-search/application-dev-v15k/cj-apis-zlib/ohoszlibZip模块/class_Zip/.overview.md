# class_Zip

This directory contains API reference documentation for the Zip class and related functions within the Cangjie language's Zlib subsystem. It covers data compression and decompression capabilities, including stream management, buffer handling, and error processing. Key topics include the `Zip` class, `compress`, `uncompress`, `deflate`, and `inflate` functions, along with their initialization and termination routines. The documentation is intended for Cangjie developers implementing data compression features who need detailed function signatures, parameter definitions, and exception handling guidelines for the SystemCapability.BundleManager.Zlib framework.

## Detailed Description

### class_Zip_2more.md
API reference for the Zip class in Cangjie, focusing on the `compress` function. It details data transfer between buffers, `ZipOutputInfo` return values, exception handling, and includes code examples for buffer allocation and compression workflows.

### func_compress2ArrayByte_ArrayByte_Compres_d7edafae.md
API reference for the `compress2` function in the Cangjie Zlib subsystem. It explains compressing source data into a destination buffer, parameter descriptions, compression levels, return values, and error codes, with a practical usage example.

### func_compressBoundInt32_2more.md
Documentation for `compressBound` and `deflate` functions. It details calculating compression size limits and performing data compression using ZStream structures, including signatures, error handling, and Cangjie code examples.

### func_deflateEndZStream.md
Describes the `deflateEnd` function for freeing dynamically allocated compression stream structures. It covers the function signature, ZStream parameters, return values, and specific exception handling for stream errors.

API reference for `getZStream` and `inflate` functions. It covers retrieving the current zlib stream object and decompressing data, including syntax, parameters, error codes, and practical code examples for stream management.

### func_inflateEndZStream.md
