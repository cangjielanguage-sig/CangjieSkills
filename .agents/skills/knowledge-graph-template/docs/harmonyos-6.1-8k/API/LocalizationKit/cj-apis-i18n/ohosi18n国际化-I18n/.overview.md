# ohosi18n国际化-I18n

本目录包含HarmonyOS应用开发中关于国际化（I18n）的仓颉语言API参考文档。内容主要涵盖系统级国际化能力，包括获取应用偏好语言、日历类型枚举定义、日历对象获取以及日期时间的本地化处理。核心功能涉及System类、CalendarType枚举、getCalendar函数及Calendar类的详细使用方法。该文档集成了LocalizationKit能力，旨在帮助使用仓颉语言的开发者实现多语言支持、多历法系统及精确的日期时间本地化功能，适用于从事HarmonyOS国际化应用开发的工程技术人员。
