This directory serves as a comprehensive repository for API reference documentation related to the `ohos.hidebug` module, specifically tailored for the Cangjie programming language within the HarmonyOS development environment. It is primarily focused on providing developers with advanced debugging and performance analysis tools necessary for creating high-performance applications. The content covers critical system metrics including detailed memory statistics (such as NativeMemInfo and SystemMemInfo), real-time CPU usage monitoring, in-depth thread profiling, and trace capture functionalities. By utilizing these APIs, developers can leverage the PerformanceAnalysisKit for resource monitoring and the Tags class for efficient system event categorization. This documentation is essential for HarmonyOS developers who require deep system diagnostics and application optimization capabilities, specifically targeting systems with the SystemCapability.HiviewDFX.HiProfiler.HiDebug capability (API 19+). It enables the creation of stable, efficient software by providing granular visibility into system resource utilization.
