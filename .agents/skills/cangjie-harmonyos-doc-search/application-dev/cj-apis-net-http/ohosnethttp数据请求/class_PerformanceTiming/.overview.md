# class_PerformanceTiming

This directory provides comprehensive API reference documentation for the Cangjie `PerformanceTiming` class and its associated variables, specifically designed to capture and analyze network request performance metrics with high precision. It covers granular timing data for various critical stages of the request lifecycle, including DNS resolution, TCP connection establishment, TLS negotiation, server redirects, and response parsing, all measured in milliseconds. The documentation details properties and variables of type Float64 that support read and write access, measuring duration from the initial request or callback. This resource is suitable for developers implementing or analyzing network communication features who require precise timing data to optimize performance, utilizing the SystemCapability.Communication.NetStack capability available from version 22.

## Detailed Description

### class_PerformanceTiming_10more.md

This document provides API reference documentation for the Cangjie PerformanceTiming class, which captures network request performance metrics in milliseconds. It details ten public properties that track specific stages of the request lifecycle, such as DNS resolution, TCP connection, TLS handshake, redirects, and response parsing. Key information includes that all properties are of type Float64, support read and write access, and measure duration from the initial request. The class requires the SystemCapability.Communication.NetStack system capability and is available starting from version 22. This documentation is intended for developers implementing or analyzing network communication features who require granular timing data to optimize performance.

### var_totalTiming.md

This document provides an API reference for the totalTiming variable in the Cangjie language, detailing its role in measuring network request performance. The content outlines the variable's declaration as a Float64, its read-write capabilities, and its specific function of tracking the time elapsed from a request callback to the application. Key information includes the required system capability, SystemCapability.Communication.NetStack, and the introduction of this feature in version 22. This documentation is intended for developers working on network communication modules who need to monitor or manipulate timing metrics for HTTP requests.
