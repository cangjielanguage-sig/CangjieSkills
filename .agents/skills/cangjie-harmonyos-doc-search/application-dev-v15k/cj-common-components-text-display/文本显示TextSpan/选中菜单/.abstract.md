This directory provides comprehensive documentation and tutorials focused on the implementation and customization of selection menus for text components within the ArkUI framework. It covers a range of technical topics, including enabling default selection behaviors, binding custom menus using `bindSelectionMenu`, and extending existing menu options via `editMenuOptions`. The content addresses development in both Cangjie and ArkTS, offering code examples for creating custom menu items with specific callbacks and controlling menu visibility. It is specifically designed for UI developers and HarmonyOS engineers who aim to build advanced text interaction features, such as custom copy or translation functions, to enhance the user experience in their applications.
