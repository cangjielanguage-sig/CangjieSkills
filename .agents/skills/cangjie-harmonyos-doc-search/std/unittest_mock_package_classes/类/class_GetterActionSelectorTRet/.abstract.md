This directory contains API documentation for the `GetterActionSelector` class and associated functions within a mock testing framework, specifically tailored for the Cangjie language. It provides comprehensive details on defining stub behaviors for property getter functions, allowing developers to control field access, return values, and exception handling with precision. The documentation covers essential methods for synthetic field access, original value retrieval, and consecutive return sequences, as well as extensions for void methods and error simulation. This resource is suitable for developers utilizing the `@On` macro for unit testing who require advanced mocking capabilities to spy on object properties and simulate complex execution scenarios effectively.
