This directory contains a collection of complete, practical code examples written in the Cangjie language, designed to assist developers in mastering the MediaKit framework for media application development. It specifically targets the implementation of the AVPlayer class, providing deep dives into streaming media playback for various protocols including HLS Video on Demand (VOD), HLS Live, and DASH. Beyond basic playback, the content covers advanced features such as track selection, surface ID management, and the configuration of custom HTTP headers. Furthermore, it addresses the critical aspects of player lifecycle management, state machine transitions, and robust error handling mechanisms. These resources are ideal for developers seeking to build professional-grade video players or integrate complex media functionalities into their Cangjie-based projects, offering clear guidance on handling asynchronous callbacks and maintaining playback stability.
