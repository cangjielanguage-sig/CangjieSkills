### 使用ImageSource完成图片解码.md 使用ImageSource完成图片解码.md
This document serves as a technical guide explaining how to utilize the ImageSource component to perform image decoding. It primarily focuses on converting various supported archived image formats into a unified PixelMap structure, which is essential for displaying images or performing image processing within applications. The text details the specific formats supported, including JPEG, PNG, GIF, WebP, BMP, SVG, ICO, DNG, and HEIF, noting that hardware capabilities may affect support. Key information includes the definition of decoding and its role in the image processing pipeline. The intended audience consists of developers needing to implement image handling features, who should have a basic understanding of the system's image overview and transformation modules. Keywords: ImageSource, image decoding, PixelMap, image formats, image processing.

### 开发示例-对资源文件中的图片进行解码.md 开发示例-对资源文件中的图片进行解码.md
This tutorial provides a step-by-step guide for developers on decoding images stored in resource files using the Cangjie language. The document covers four main stages: acquiring the ResourceManager, creating an ImageSource using either byte buffers or file descriptors from the rawfile folder, generating a PixelMap for image manipulation, and manually releasing resources to manage memory. Key takeaways include the specific code syntax for loading "test.jpg" and the critical requirement to call Release methods on PixelMap and ImageSource objects after use. This guide is intended for Cangjie developers implementing image processing features in their applications.
