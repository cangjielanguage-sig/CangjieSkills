This directory provides comprehensive documentation for the `MemberAccess` class within the Cangjie language's Abstract Syntax Tree (AST). It focuses on modeling member access expressions, such as `T.a`, detailing the class architecture, inheritance from the `Expr` type, and specific mutable properties like `baseExpr`, `field`, `dot`, and `typeArguments`. Additionally, it covers essential utility functions for converting AST nodes to tokens and traversing the tree structure using the Visitor pattern. This resource is designed for developers and engineers involved in building compiler tools, static analyzers, or any program requiring syntactic analysis and manipulation of Cangjie code. It provides the necessary API references to programmatically handle expression parsing and tree walking.
