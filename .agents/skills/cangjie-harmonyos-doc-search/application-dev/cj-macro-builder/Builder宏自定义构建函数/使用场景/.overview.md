# 使用场景

This directory serves as a practical guide for developers working with the ArkUI framework in the Cangjie language, focusing specifically on advanced usage scenarios for the @Builder decorator. It covers essential techniques for structuring dynamic user interfaces, including the intricacies of passing @Builder functions as parameters, implementing nested builders, and utilizing custom build functions within components. A significant emphasis is placed on state management integration, demonstrating how to ensure UI refresh through pass-by-reference mechanisms and decorators like @State and @Observed. This content is highly suitable for Cangjie developers seeking to optimize their UI architecture and master complex component interactions.

## Detailed Description

### 使用全局和局部的Builder传入CustomBui_2more.md
This technical guide demonstrates advanced usage of the @Builder decorator in ArkUI Cangjie development. It covers two primary scenarios: passing @Builder functions as CustomBuilder parameters and implementing nested @Builder methods. The first section illustrates how both global and local @Builder functions can be passed to components like bindSheet since CustomBuilder is a function type. The second section explains multi-layer nesting, emphasizing that pass-by-reference is required at every level to ensure dynamic UI refresh in deeply nested builders. This document targets developers seeking to optimize UI construction and state management in ArkUI applications.

### 自定义组件内使用自定义构建函数_3more.md
This tutorial demonstrates how to implement and utilize custom @Builder functions within the ArkUI framework using the Cangjie language to achieve dynamic UI rendering. It covers three specific scenarios: creating private @Builder methods inside components, defining global @Builder functions with complex object parameters, and clarifying that UI refresh is driven by state management macros rather than the builder itself. Key takeaways include methods for updating UI content through lifecycle functions, event handling, and the use of @State and @Observed decorators to track data changes. This guide is intended for Cangjie developers who possess a basic understanding of ArkUI component structure and state management principles.
