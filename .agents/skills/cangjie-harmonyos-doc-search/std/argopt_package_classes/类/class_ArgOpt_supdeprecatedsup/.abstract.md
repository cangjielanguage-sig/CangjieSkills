This directory contains essential API reference documentation for the deprecated `ArgOpt` class within the Cangjie programming language ecosystem. It is designed to assist developers in understanding and maintaining legacy command-line argument parsing logic. The content comprehensively covers the initialization of instances using short and long argument specifications, syntax validation rules, and exception handling for encoding issues. Key topics include the definition of valid parameter prefixes, value extraction methods, and the management of unparsed arguments. Although the class is deprecated in favor of the `parseArguments` function, this documentation remains vital for developers maintaining existing codebases or requiring specific insights into the previous parsing architecture. It provides the necessary technical details to ensure robust command-line interface implementation in legacy projects, offering specific rules for argument prefixes and value extraction.
