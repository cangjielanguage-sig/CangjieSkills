This directory focuses on the event dispatch mechanisms within the ArkUI framework, detailing how user interactions like touches and mouse inputs are processed and routed to specific components. It covers the fundamental concepts of event dispatch, the algorithms for collecting event response chains, and the specific logic behind touch testing. Key topics include touch events, mouse events, hitTestBehavior, and event propagation. This documentation is suitable for ArkUI developers and UI engineers who need to understand the underlying logic of event handling to build responsive and interactive user interfaces.
