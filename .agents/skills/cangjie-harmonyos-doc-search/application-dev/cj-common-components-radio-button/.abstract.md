This directory contains the technical API documentation for the Radio component, a fundamental UI element within the Cangjie ArkUI framework. It is designed to support developers in building intuitive single-selection user interfaces where users are required to select exactly one option from a predefined list. The documentation provides a thorough explanation of the component's lifecycle, starting with the creation of Radio instances via the `init` interface. It details the various properties available for customization, such as `checked` for state management and `indicatorType` for visual styling. Additionally, the guide covers the implementation of event handling logic using the `onChange` callback to respond to user interactions. It also clarifies the use of `value` and `group` parameters, which are essential for establishing mutual exclusion between different radio buttons. To facilitate practical understanding, the document includes a real-world scenario example that demonstrates sound mode switching with toast notifications. This resource is highly suitable for developers who have a foundational knowledge of Cangjie syntax and are seeking to implement robust, interactive radio controls in their UI applications.
