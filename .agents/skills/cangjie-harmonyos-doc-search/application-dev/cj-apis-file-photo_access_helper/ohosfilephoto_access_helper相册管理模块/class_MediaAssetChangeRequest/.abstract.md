This directory provides API reference documentation for the `MediaAssetChangeRequest` class within the Cangjie language's MediaLibraryKit. It focuses on managing media asset modification, creation, and deletion via the PhotoAccessHelper system. Key functionalities include initializing requests, creating image and video assets, adding resources, handling camera photos, and managing metadata. The documentation outlines constructors, static methods, and instance functions, including error handling and system capabilities. It is intended for Cangjie developers building media applications who require programmatic tools for file management, asset manipulation, and media library integration.
