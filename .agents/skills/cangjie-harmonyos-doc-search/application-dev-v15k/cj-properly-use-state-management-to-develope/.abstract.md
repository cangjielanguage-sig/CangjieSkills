This directory contains a specialized development guide designed for Cangjie developers who are facing challenges with state management. It provides a deep dive into resolving common UI issues, specifically when the interface fails to refresh or suffers from poor performance. The guide covers essential strategies for property management, including the optimization of data structures by merging simple arrays and splitting large objects. It also offers detailed instructions on using decorators like `@Observed` and `@Publish` effectively. Furthermore, it highlights the importance of using `ObservedArrayList` over standard lists in iterative components to ensure proper data binding. This resource is suitable for developers looking to ensure their UI remains responsive and synchronized with the underlying data state through comparative code examples and best practices.
