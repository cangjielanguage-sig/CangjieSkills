# cangjie-load-arkts

This directory acts as a central repository for technical documentation regarding the interoperability between the Cangjie and ArkTS programming languages within the HarmonyOS ecosystem. It is designed to assist developers in understanding and implementing the mechanisms required to import and load ArkTS modules directly within Cangjie code. The content covers essential technical aspects, including the usage of the `JSContext.requireArkModule` interface and the implementation of dynamic loading strategies for diverse module types such as HAR, HSP, Native, System, and HAP. Furthermore, it details the necessary configuration steps involving `oh-package.json5` and outlines critical usage restrictions, including thread limitations and initialization constraints. This documentation is specifically tailored for HarmonyOS developers and system architects who need to facilitate seamless cross-language communication and manage complex dependencies in their applications. By mastering these concepts, developers can enhance the modularity and performance of their HarmonyOS software projects.
