# 按键事件

This directory covers the handling of key input events within the ArkUI framework using the Cangjie language. It includes API references for the `KeyEvent` class, definitions for component interaction via `onKeyEvent`, and practical code examples. Key topics include event properties (keyCode, timestamp), focusable components, and callback implementation. This documentation is suitable for application developers working on HarmonyOS interfaces who need to integrate hardware input handling, such as keyboards or remote controls, into their UI applications.

## Detailed Description

### 基础类型定义.md 基础类型定义.md
This API reference document defines the KeyEvent class for handling key input events within the ArkUI framework using the Cangjie language. It details the class structure, listing properties such as isStopPropagation, keyText, keyCode, keySource, and timestamp, alongside the class constructor. Key information includes that all properties are readable and writable, capturing comprehensive event data like device ID, meta key states, and timestamps, available starting from API version 12. This documentation is intended for application developers working on ArkUI interfaces who require detailed keyboard or input device event handling logic.

### 按键事件_3more.md 按键事件_3more.md
This API reference document defines key events for component interaction with keyboards or remote controls in the ArkUI framework. It covers the definition of key events, permission requirements, and the specific onKeyEvent function signature. Key information includes that these events apply to focusable components like Buttons, with future support planned for Text and Image. It details the onKeyEvent method, which accepts a callback triggered upon key actions when the component is focused, starting from version 12. This document is intended for developers building UI applications who need to handle hardware input. Keywords: ArkUI, key events, onKeyEvent, focusable, callback, keyboard interaction.

### 示例代码.md 示例代码.md
This document serves as a practical code example demonstrating how to implement and handle key events in a Cangjie-based HarmonyOS application. The content focuses on UI component construction, specifically using the Button and Column components, and managing state updates. Key information includes the implementation of the onKeyEvent callback, which captures and displays detailed event properties such as keyType, keyCode, keyText, deviceId, metaKey, and timestamp. This snippet is intended for developers with prior knowledge of Cangjie syntax and the HarmonyOS UIKit who need to integrate input device interactions into their user interfaces.
