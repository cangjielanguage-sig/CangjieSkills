# cj-hiappevent-watcher-freeze-events

This directory serves as a comprehensive technical resource for Cangjie developers utilizing the HiAppEvent framework, with a specific focus on the analysis and management of system appfreeze events. The documentation provided herein offers a granular examination of the event structure and attributes, enabling developers to effectively monitor application stability. It covers a wide spectrum of data points, including the definition of the params object, general event data, exception details, full thread stacks, and memory usage statistics. Key technical attributes such as timestamps, process IDs, fault UUIDs, and specific metrics for THREAD_BLOCK_6S events are thoroughly detailed. Additionally, the documentation highlights critical warnings concerning external log file size limits, which are vital for preventing write failures. This content is primarily suitable for software developers and system engineers tasked with diagnosing freeze issues and implementing event subscription interfaces to ensure optimal application performance and reliability. Core keywords include HiAppEvent, appfreeze, Cangjie, thread stacks, memory usage, and event subscription.
