This directory provides comprehensive API reference documentation for component lifecycle and event handling within the ArkUI framework, specifically utilizing the Cangjie language. It details critical functions for managing page navigation, intercepting system events like the back key, and responding to visibility state changes. The documentation covers a range of lifecycle hooks, including component mounting, appearance, and destruction phases. This resource is essential for software developers and UI engineers seeking granular control over application behavior, state preservation, and user interaction logic during page transitions.
