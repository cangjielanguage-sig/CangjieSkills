# 组合手势

This directory focuses on Composite Gestures within the Cangjie UI framework, specifically designed for HarmonyOS application development. It provides comprehensive resources on how to combine basic gestures—such as tapping, long-pressing, and dragging—into sophisticated, multi-step interaction patterns using the `GestureGroup` component. The content covers essential technical concepts including the three distinct recognition modes: Sequence (serial execution), Parallel (simultaneous recognition), and Exclusive (competition-based). It also addresses event management, such as handling cancellations and state updates. This collection is highly suitable for HarmonyOS developers and UI engineers who are proficient in Cangjie syntax and ArkUI basics, and who need to create responsive, touch-driven user interfaces with complex logic. By mastering these composite gestures, developers can significantly enhance the interactivity and user experience of their applications.

## Detailed Description

### 示例.md 示例.md
This document provides a practical code example demonstrating the implementation of sequential gesture recognition using the Cangjie language for HarmonyOS development. It covers the usage of the GestureGroup component with GestureMode.Sequence, combining LongPressGesture and PanGesture to manipulate UI state and element position. Key takeaways include how to trigger a counter increment during a long press, followed by dragging a UI element with dynamic border style changes, utilizing state variables like offsetX and offsetY. This tutorial is intended for HarmonyOS developers familiar with Cangjie syntax and ArkUI basics who need to implement complex gesture interactions.

### 组合手势_6more.md 组合手势_6more.md
This document serves as API reference documentation for the Composite Gesture feature within the Cangjie UI kit, detailing how to combine multiple basic gestures into complex interactions. It covers the initialization method requiring a GestureMode and an array of gesture types, the onCancel event for sequence cancellations, and the GestureMode enum definitions. Key concepts include the three recognition modes: Sequence (sequential success), Parallel (simultaneous), and Exclusive (first success wins). It also specifies ordering rules for TapGestures. This guide targets developers building UI applications using the ArkUI framework who need to implement advanced gesture handling.
