This directory contains the API reference for the abstract `Visitor` class in the Cangjie programming language, which implements the Visitor design pattern for traversing and modifying Abstract Syntax Trees (ASTs). It covers the core class structure, control mechanisms like `breakTraverse`, and a comprehensive set of `visit` methods for various syntax nodes, including declarations, expressions, and patterns. These resources are essential for compiler developers and language engineers building code analysis or transformation tools, providing the necessary interfaces to define custom logic during AST traversal.
