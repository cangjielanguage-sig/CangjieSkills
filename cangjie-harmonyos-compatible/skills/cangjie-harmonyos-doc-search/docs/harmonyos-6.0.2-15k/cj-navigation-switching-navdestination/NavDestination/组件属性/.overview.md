# 组件属性

This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It primarily focuses on customizing Navigation components, including setting back button icons, managing system status bar styles, and configuring navigation titles and menus. The documentation covers specific function signatures, parameter types, and boundary conditions for layout extensions. It is suitable for Cangjie developers and UI designers looking to programmatically control the appearance and behavior of navigation headers, status bars, and layout safety areas in their applications.

## Detailed Description

### func_backButtonIconAppReso_5more.md func_backButtonIconAppReso_5more.md
This document serves as API reference documentation for Cangjie developers working with the ArkUI framework to customize navigation components. It covers four main functions: setting the back button icon using either AppResource or PixelMap, configuring the top-right menu with specific display limits for vertical and horizontal orientations, and controlling layout extensions into non-safe areas. Key information includes the overflow behavior for menu items and the specific boundary conditions required for the ignoreLayoutSafeArea function to take effect, alongside warnings about potential event interception by system components. This guide is intended for developers familiar with Cangjie syntax and UI layout principles.

### func_systemBarStyleResourceColor.md func_systemBarStyleResourceColor.md
This document provides API reference documentation for the systemBarStyle function in the Cangjie language, designed to configure the system status bar style within a Navigation component. The content details the function signature, functionality, system capabilities, and version requirements, specifically highlighting the required ResourceColor parameter. Key takeaways include the constraint that this function must be used as the root node of a Navigation destination page to take effect and is available starting from version 20. This guide targets ArkUI developers seeking to customize status bar visuals, requiring knowledge of Navigation components and resource color definitions.

### func_titleString_Navigatio_7more.md func_titleString_Navigatio_7more.md
This document serves as an API reference for configuring navigation titles and properties within the ArkUI framework using the Cangjie language. It details multiple overloaded title functions that allow developers to set page titles via strings, custom builders, or specific objects, along with optional configurations. Additionally, it covers methods to hide the title bar, define the navigation destination mode, and customize the back button icon. Key information includes parameter types, default values, and system capabilities. The documentation targets application developers seeking to programmatically control navigation header appearance and behavior in their user interfaces.
