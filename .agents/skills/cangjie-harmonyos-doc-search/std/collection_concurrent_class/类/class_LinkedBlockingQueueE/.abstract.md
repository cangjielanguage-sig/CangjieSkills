This directory contains API reference documentation for the `LinkedBlockingQueue` class within the Cangjie standard library. It focuses on a thread-safe, concurrent queue implementation that supports blocking mechanisms and user-defined capacity limits. The documentation covers class definitions, initialization methods, and various queue manipulation operations, including both blocking and non-blocking behaviors. Key topics include deprecated constructors, exception handling for invalid capacities, and return types like `Option` for empty queues. This resource is suitable for Cangjie developers implementing concurrent data structures and managing thread-safe operations in multi-threaded applications.
