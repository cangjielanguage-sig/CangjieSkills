This directory provides comprehensive API reference documentation for the `RelativeTimeFormat` class in the Cangjie language, specifically designed for the LocalizationKit. It focuses on the internationalization of relative time expressions, enabling developers to format time differences—such as "next year" or "2 minutes ago"—based on specific locales. The documentation covers essential functionalities including object initialization through multiple constructor overloads, basic string formatting, and advanced methods for granular control over output parts and configuration options. This resource is ideal for developers seeking to implement robust, locale-aware time formatting in their Cangjie applications.
