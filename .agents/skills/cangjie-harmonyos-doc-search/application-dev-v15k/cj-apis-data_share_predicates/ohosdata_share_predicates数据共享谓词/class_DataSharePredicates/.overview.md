# class_DataSharePredicates

This directory contains API reference documentation for the Cangjie `DataSharePredicates` class, a component of the ArkData kit designed for constructing query conditions in data sharing operations. It covers essential methods for filtering, sorting, and limiting results within distributed data management, supporting both RDB and KVDB (schema) databases. The documentation details initialization, logical operators like `and` and `equalTo`, and query configuration functions such as `limit` and `orderBy`. It is intended for Cangjie developers building data-driven applications who need to manage distributed data queries effectively, noting that the class is not thread-safe.
