# cj-cem-tool

本目录包含OpenHarmony公共事件管理工具（cem）的详细操作指南。该工具专为开发者设计，旨在提供强大的公共事件调试与测试功能。文档内容全面，涵盖了从环境准备到核心命令（如help、publish、dump）的具体使用方法。通过本文档，开发人员可以掌握如何发布具有特定名称、数据和结果码的公共事件，以及如何在工程版本（eng）中查看已发送事件的详细信息和订阅者状态。这对于需要模拟事件发布流程或监控事件在系统中流转的开发人员来说，是一份不可或缺的参考文档。

## 详细说明

### cj-cem-tool.md cj-cem-tool.md
本文档是OpenHarmony公共事件管理工具（cem）的操作指南，旨在为开发者提供公共事件的调试与测试能力。文档涵盖了环境准备及help、publish、dump三大核心命令的使用方法。重点介绍了如何使用publish命令发布指定名称、数据及结果码的公共事件，以及利用dump命令查看已发送事件和订阅者信息（仅限eng版本）。该文档适用于需要模拟事件发布或监控事件流转的开发人员。
