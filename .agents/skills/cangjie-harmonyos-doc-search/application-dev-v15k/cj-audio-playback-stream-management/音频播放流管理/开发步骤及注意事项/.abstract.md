This directory provides comprehensive technical guides and code examples for managing audio streams using the AudioStreamManager API within the Cangjie programming language. It covers the complete development lifecycle, including creating manager instances, subscribing to audio renderer change events via callbacks, and retrieving current audio renderer information. Key topics include implementing the AudioRendererChangeCallback interface, handling necessary permissions such as `ohos.permission.USE_BLUETOOTH` for accessing device details, and logging stream properties. These resources are specifically designed for application developers utilizing the AudioKit framework who need to handle audio state changes, monitor audio output, or debug audio device connections effectively.
