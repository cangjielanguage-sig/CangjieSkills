This directory provides essential API reference documentation for the Cangjie `Form` class and its associated encoding utilities. It focuses on the storage and management of HTTP request form information, specifically designed to handle key-value pairs often found in URL query components. The documentation covers essential data manipulation operations such as adding, setting, retrieving, and removing entries, as well as parsing URL-encoded strings and handling exceptions for invalid syntax. Furthermore, it includes details on percent-encoding logic required for data transmission, adhering to RFC 3986 standards. This resource is intended for developers utilizing the Cangjie language who require robust tools for handling URL structures, form submissions, and HTTP request data.
