# 订阅崩溃事件仓颉

This directory provides a comprehensive technical guide for subscribing to crash events using the Cangjie programming language within the HarmonyOS development environment. It serves as a central repository for developers aiming to implement robust application stability monitoring by detailing the necessary interfaces and procedures for tracking CjError and NativeCrash events. The content covers essential aspects such as API definitions, configuration of event watchers, and the practical steps required to capture and analyze crash data effectively. This resource is highly suitable for Cangjie developers, QA engineers, and system architects who are focused on improving application reliability, debugging complex exceptions, and ensuring a seamless user experience through effective error handling and log analysis in DevEco Studio.

## Detailed Description

### 接口说明.md 接口说明.md

This document acts as a concise technical reference for developers utilizing Cangjie interfaces to subscribe to application events, with a specific emphasis on monitoring crash events categorized as CjError and NativeCrash. It outlines the core subscription interface functionality, providing essential guidance while directing users to external documentation for in-depth parameter constraints and value ranges. The text details the definitions of two critical methods: `addWatcher`, which is responsible for adding an observer to initiate event subscriptions, and `removeWatcher`, which is utilized to cancel these subscriptions. By providing a clear overview of these components, the document ensures developers can easily integrate event tracking capabilities. It offers the necessary function signatures and return types, such as `Option<AppEventPackageHolder>`, required for successful integration into their applications.

### 开发步骤/

This directory functions as an extensive technical resource for Cangjie developers seeking to implement and understand crash event subscription within HarmonyOS applications via the HiAppEvent module. It meticulously covers the end-to-end development lifecycle, starting from importing necessary dependencies and configuring Watchers with AppEventFilters to simulating crash scenarios through UI triggers. The documentation elucidates critical behaviors, including the callback mechanisms for crash data transmission, the nuanced differences in stack unwinding between CjError and NativeCrash, and the specific timing of reporting for caught versus uncaught exceptions. Additionally, it provides practical examples of raw log outputs to assist in debugging APP_CRASH events. Through a structured approach, this guide is vital for DevEco Studio users who need to monitor application stability, interpret crash logs accurately, and handle system-level exceptions to maintain a robust user experience.
