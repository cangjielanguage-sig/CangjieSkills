This directory provides comprehensive development guides for implementing internationalization (i18n) features using the LocalizationKit in the Cangjie programming language. It covers essential tasks such as unit conversions, number formatting, and currency display. The documentation includes detailed function signatures, configuration options like `NumberOptions`, and practical code examples for handling localized data presentation. It is suitable for Cangjie developers looking to integrate robust localization capabilities into their applications, ensuring accurate and culturally appropriate formatting for global users.
