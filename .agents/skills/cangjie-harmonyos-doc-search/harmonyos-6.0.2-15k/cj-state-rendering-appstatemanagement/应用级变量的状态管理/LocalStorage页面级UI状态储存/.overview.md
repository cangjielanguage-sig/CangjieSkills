## Detailed Description

### LocalStorage页面级UI状态储存_2more.md LocalStorage页面级UI状态储存_2more.md
This document serves as a technical guide explaining the LocalStorage mechanism for managing page-level UI state within the Cangjie framework. It covers an overview of LocalStorage as an in-memory database, usage rules regarding component tree inheritance, and specific limitations on type mutability and scope. Key concepts include the @Entry decorator for instance allocation, and the @LocalStorageProp and @LocalStorageLink decorators for one-way and two-way data synchronization respectively. It emphasizes that LocalStorage is shareable within a package but type definitions are fixed after creation. Targeted at developers using the Cangjie framework to build UIs, specifically those needing to manage state across components within a package.

### 示例代码.md 示例代码.md
This document provides Cangjie code examples demonstrating state management using LocalStorage decorators within the HarmonyOS ArkUI framework. It covers two primary topics: @LocalStorageProp for one-way data binding and @LocalStorageLink for two-way data synchronization. Key information highlights that @LocalStorageProp variables are read-only at the component level, requiring direct storage manipulation for updates, while @LocalStorageLink enables automatic state synchronization across parent and child components upon modification. Intended for application developers, this reference guide illustrates how to implement shared state management effectively.
