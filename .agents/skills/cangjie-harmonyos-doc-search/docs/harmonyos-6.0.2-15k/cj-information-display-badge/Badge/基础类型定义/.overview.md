# 基础类型定义

This directory serves as a comprehensive resource for the foundational type definitions required to implement Badge components within the ArkUI framework using the Cangjie programming language. It provides essential API references that cover the full lifecycle of badge creation, from initial parameter configuration to visual styling and final positioning. The documentation details critical classes such as `BadgeParams` for defining core logic, `BadgeStyle` for aesthetic customization, and `BadgePosition` for spatial layout. These resources are tailored for ArkUI developers working on system version 12 or higher who need to integrate notification markers or status indicators into their user interfaces with high precision.

## Detailed Description

### class_BadgeParams.md class_BadgeParams.md
This API reference document outlines the BadgeParams class, which defines the foundational parameters for creating Badge components in the Cangjie language. The documentation details two primary constructors: one for numeric message counts with a configurable maximum limit, and another for text-based content. Key parameters include count, value, style, and position, allowing developers to customize appearance and placement. The class supports specific behaviors like hiding badges for non-positive counts and capping numeric displays. Intended for ArkUI developers working on system version 12 or higher, this guide provides the necessary specifications to implement notification markers effectively. Keywords: BadgeParams, Cangjie, ArkUI, API reference, Badge component, constructors, UI parameters.

Intended for developers building UIs with ArkUI, this reference assists in customizing badge visuals. Keywords include Cangjie, ArkUI, BadgeStyle, UI styling, and API reference.

### enum_BadgePosition.md enum_BadgePosition.md
This document provides API reference documentation for the Cangjie programming language, specifically defining the BadgePosition enumeration used to control the visual placement of badge dots within the ArkUI framework. The content details three specific enum values: Left, Right, and RightTop, each accompanied by a functional description explaining the exact positioning relative to the parent component. Key information includes the specific alignment behaviors, such as vertical centering for side positions versus corner placement for RightTop, alongside system capability requirements and the initial API version 12.
