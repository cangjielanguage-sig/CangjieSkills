# 组合手势

This directory focuses on advanced gesture recognition strategies within the Cangjie ArkUI framework, specifically addressing how to manage and combine multiple gestures. It covers the technical implementation of recognition modes such as Parallel, Exclusive, and Sequence, explaining how they affect event propagation and user interaction. The content includes practical Cangjie code examples demonstrating scenarios like single-tap versus double-tap conflicts and complex sequences like long-press followed by panning. This resource is essential for UI developers and system architects looking to build responsive, multi-touch interfaces that require precise control over gesture behavior and state management.

## Detailed Description

### 并行识别_2more.md 并行识别_2more.md
This technical guide explains the implementation and behavior of Parallel and Exclusive gesture recognition modes within a UI framework. It details `GestureMode.Parallel`, where gestures run simultaneously without interference, and `GestureMode.Exclusive`, where the first successful gesture terminates others. The document uses Cangjie code examples to demonstrate how single-tap and double-tap gestures interact, highlighting that Exclusive mode results depend heavily on gesture binding order, whereas Parallel mode allows both to trigger if conditions are met. It targets UI developers using the Cangjie language who need to manage complex gesture interactions in their applications.

### 组合手势_2more.md 组合手势_2more.md
This document explains how to implement combined gestures in the Cangjie ArkUI framework using the `GestureGroup` API. It covers the three recognition modes: Sequence, Parallel, and Exclusive, with a specific focus on Sequence recognition. The text provides a detailed Cangjie code example demonstrating a Sequence gesture combining `LongPressGesture` and `PanGesture` to move a component, illustrating event handling and state updates. Key takeaways include the logic of sequential gesture failure and the specific behavior of the `onActionEnd` callback. This guide is intended for developers building interactive UIs who need to handle complex multi-touch interactions.
