# 接口

This directory serves as a comprehensive repository for API documentation regarding core interfaces within the Cangjie programming language. It primarily addresses the fundamental mechanisms of data transformation, specifically focusing on type-to-string formatting, string-to-type parsing, and numeric base conversions. The content covers essential interfaces such as `Formattable`, `Parsable`, and `RadixConvertible`, detailing their implementations across various primitive data types including integers, floating-point numbers, and Runes. This documentation is vital for Cangjie developers who need to implement robust data serialization, handle user input validation, or perform complex numeric manipulations within their applications.

## Quick Navigation

- Convert integers to strings or parse strings to integers in different bases (radices) → [3] interface_RadixConvertibleT

## Detailed Description

### [1] interface_Formattable
This directory contains API documentation for the `Formattable` interface in the Cangjie programming language, focusing on string conversion capabilities for various numeric and primitive types. It covers the core interface definition and its extensions across signed integers (Int8, Int16, Int32, Int64), unsigned integers (UInt8, UInt16, UInt32, UInt64), floating-point numbers (Float16, Float32, Float64), and the Rune type. The documents detail the `format` method, which accepts format strings to generate string representations, handling potential exceptions. This resource is suitable for Cangjie developers looking to implement or utilize type-to-string formatting functionality within their applications.

### [2] interface_ParsableT
This directory contains API documentation for the Cangjie language's `Parsable` interface and its type-specific extensions. It covers the standardization of string-to-type conversions for primitive data types, including Booleans, Integers (signed and unsigned), Floating-point numbers, and Runes. The documentation details two primary parsing methods: `parse` for exception-based error handling and `tryParse` for safe, Option-based error handling. This resource is suitable for Cangjie developers seeking robust mechanisms for parsing string inputs into specific data types, handling conversion errors, and understanding type system constraints.

### [3] interface_RadixConvertibleT
This directory contains API documentation for the Cangjie programming language's `RadixConvertible` interface and its implementations across standard integer types. It covers the core interface definition and extensions for signed (Int8, Int16, Int32, Int64) and unsigned (UInt8, UInt16, UInt32, UInt64) integers. The documentation details methods for parsing strings to integers and converting integers to strings across various numerical bases (radices). Key features include strict parsing with exceptions, safe parsing using the Option type, and string formatting. This resource is suitable for Cangjie developers who need to perform base conversions, handle numeric string parsing, or implement robust error handling for numeric data types.
