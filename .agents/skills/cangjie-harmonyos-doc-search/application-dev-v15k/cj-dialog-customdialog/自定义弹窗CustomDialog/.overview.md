# 自定义弹窗CustomDialog

This directory provides comprehensive resources for implementing custom dialog windows in HarmonyOS applications using the Cangjie programming language and the ArkUI framework. It covers the essential `CustomDialog` decorator, the `CustomDialogController` for managing dialog lifecycles, and detailed configuration options for visual styling and behavior. Key topics include UI component creation, interaction handling, modal interfaces, and API references. This content is suitable for Cangjie developers and UI designers seeking to build flexible, custom-styled pop-up windows with specific interaction logic.

## Detailed Description

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating how to implement and display a custom dialog in the Cangjie programming language for HarmonyOS development. The content covers the definition of a MyDialog class decorated with @CustomDialog and the setup of an EntryView class containing the trigger logic. Key information includes the use of CustomDialogController to manage the dialog lifecycle, specifically showing how to bind buttons to close the dialog and trigger the dialog from a main view. This example targets Cangjie developers looking to understand UI component creation and interaction handling within the HarmonyOS application framework.

### 自定义弹窗CustomDialog_2more.md 自定义弹窗CustomDialog_2more.md
This document serves as API reference documentation for the CustomDialogController class in the Cangjie language, designed for creating and managing custom dialog windows within the ArkUI framework. It details the class structure, initialization options, and essential methods such as open, close, bindView, and setBuilder. Key takeaways include the requirement for custom dialog components to use the @CustomDialog decorator and possess a specific controller property. The documentation also clarifies implicit method calls during macro expansion and SubWindow mode restrictions. This technical guide targets application developers seeking to implement flexible, custom-styled modal interfaces in HarmonyOS applications.
