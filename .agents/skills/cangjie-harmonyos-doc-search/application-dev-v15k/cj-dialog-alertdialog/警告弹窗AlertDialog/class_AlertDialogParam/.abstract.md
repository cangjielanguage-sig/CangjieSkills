This directory contains API reference documentation for the `AlertDialogParam` class within the Cangjie ArkUI framework. It provides comprehensive details on configuring alert dialogs for HarmonyOS applications, covering visual appearance, layout, behavior, and event handling. Key topics include dialog initialization, property customization like alignment, width, and masking, as well as specific API version support. This documentation is suitable for software developers and UI engineers using the Cangjie language who need to implement and style interactive alert popups and modal dialogs in their applications.
