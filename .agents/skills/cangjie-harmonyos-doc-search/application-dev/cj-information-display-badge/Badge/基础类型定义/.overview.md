# 基础类型定义

This directory serves as a comprehensive resource for defining basic types within the ArkUI framework using the Cangjie programming language. It specifically targets the structural configuration of Badge components, which are vital UI elements for displaying notifications, counts, and status indicators. The documentation covers essential enumerations for precise positioning and classes for detailed styling, enabling developers to control both layout and visual aesthetics with high fidelity. Key technical topics include the BadgePosition enum, BadgeStyle class properties, component inheritance from Equatable, and attribute configuration. This material is primarily intended for UI developers and HarmonyOS application engineers who require a deep understanding of badge implementation and customization to build robust user interfaces for API version 22 and later.
