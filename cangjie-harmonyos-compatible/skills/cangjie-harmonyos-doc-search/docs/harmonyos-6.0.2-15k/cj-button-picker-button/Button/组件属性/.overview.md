# 组件属性

This directory contains API reference documentation for configuring properties of the Button component within the ArkUI framework using the Cangjie language. It covers a wide range of customization options, including visual styles, dimensions, text rendering, and interaction behaviors. Key topics include button styling, control sizing, text overflow handling, adaptive font sizing, and shape configuration. These documents are essential for UI developers and software engineers building HarmonyOS applications who require granular control over button aesthetics and functionality to create responsive and visually appealing user interfaces.
