# 实现属性动画

This directory focuses on implementing property animations within the ArkUI framework using the Cangjie language. It covers two primary approaches: using the `animation` interface for direct attribute binding without closures and the `animateTo` interface for state-driven transitions. Key topics include rotation, translation, opacity, performance optimization (preferring scale over layout changes), and the technical distinctions between different animation methods. This resource is suitable for ArkUI developers looking to create dynamic, efficient UI effects and understand the nuances of animation implementation in Cangjie.

### 使用animation产生属性动画.md 使用animation产生属性动画.md

This document serves as a tutorial for developers on implementing property animations in ArkUI using the `animationStart` and `animationEnd` interfaces without closures. It contrasts this method with `animateTo` and provides a Cangjie code example demonstrating how to animate rotation, translation, and opacity by wrapping component attributes. Key takeaways include performance recommendations favoring the scale attribute over layout changes to reduce overhead, using transition animations for component appearance or disappearance, and cautioning against unnecessary animation end callbacks.
