This directory contains comprehensive API reference documentation for the Cangjie programming language, specifically focusing on the `initResourceStr` constructor utilized within the ArkUI framework. It covers the end-to-end configuration of alert dialogs and popup components, ranging from initialization to advanced visual styling. Key topics include dialog definition, layout alignment, window properties like modality and masking, and user interaction behaviors such as dismissal callbacks. This documentation is suitable for Cangjie developers seeking to implement sophisticated, customizable user interface components with specific visual effects, transitions, and interaction logic in their applications.
