This directory provides comprehensive technical guidance for developing Wi-Fi Peer-to-Peer (P2P) functionalities using the Cangjie language within the HarmonyOS ecosystem. It covers the implementation of direct TCP/IP connections between devices without an Access Point, including creating and managing P2P groups, device discovery, and establishing connections. Key topics include API usage (createGroup, startDiscoverDevices), event handling, configuration parameters for persistent groups, and monitoring state changes. This documentation is suitable for application developers and system engineers looking to integrate wireless connectivity features into their applications, requiring a basic understanding of HarmonyOS system capabilities and Cangjie syntax. It serves as a complete resource for mastering P2P interactions.
