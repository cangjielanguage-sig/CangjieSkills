This directory contains API reference documentation for the `IRemoteObject` interface in the Cangjie language, focusing on Inter-Process Communication (IPC) capabilities. It covers the core functionalities required for establishing and managing communication between processes, including message transmission, lifecycle monitoring, and error handling. Key topics include synchronous and asynchronous messaging via `MessageSequence`, death notification management, and interface descriptor querying. This documentation is suitable for developers and system architects who are implementing robust IPC mechanisms and need to manage remote object interactions effectively within their Cangjie applications.
