# 添加事件

This directory focuses on implementing event callbacks for the ArkUI RichEditor component using the Cangjie language. It comprehensively covers essential lifecycle and interaction events, including real-time content changes, Input Method Editor (IME) handling, paste interception, component initialization, and text selection. These guides enable developers to create rich, interactive text editing experiences with advanced features like auto-correction, custom paste logic for rich media, and dynamic content management. It is specifically suitable for HarmonyOS developers seeking to enhance user interaction, automate data synchronization, and extend the functionality of rich text editors within their applications.

### 添加图文变化前和图文变化后可触发的回调_2more.md 添加图文变化前和图文变化后可触发的回调_2more.md
This document provides a guide for implementing event callbacks in the ArkUI RichEditor component using the Cangjie language. It covers two main topics: handling content changes via onDidChange and managing Input Method Editor (IME) events using aboutToImeInput and onImeInputComplete. The guide explains that onDidChange is suitable for content saving and UI updates, while IME callbacks enable smart input features like auto-correction and word association. Both sections include practical Cangjie code examples demonstrating how to capture and log event data. The target audience is ArkUI developers looking to enhance rich text editing capabilities with automated synchronization and intelligent input assistance.

### 添加完成粘贴前可触发的回调.md 添加完成粘贴前可触发的回调.md
This document serves as a tutorial for implementing the onPaste callback within the ArkUI RichEditor component to intercept paste events before completion. The content explains how this callback facilitates content formatting, such as converting HTML to supported rich text or stripping tags, and enables image pasting which is not supported by default. It provides a Cangjie code example demonstrating how to trigger the callback and log actions. Key takeaways include the ability to override default plain-text limitations to support rich media. The target audience is ArkUI developers using Cangjie who require custom paste logic and advanced content handling in their applications.

This document serves as a tutorial for implementing specific callbacks within the ArkUI RichEditor component using the Cangjie language. Key takeaways include practical code examples demonstrating how to bind these callbacks to a controller to manipulate text spans dynamically. The guide targets HarmonyOS developers seeking to enhance user interaction and content management in rich text editing scenarios.
