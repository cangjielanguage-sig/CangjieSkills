# json_stream_package_overview

本目录提供了 `stdx.encoding.json.stream` 包的详细概览文档，旨在帮助开发者掌握仓颉（Cangjie）对象与 JSON 数据流之间的序列化与反序列化技术。文档内容涵盖了核心 API 的功能介绍，重点解析了 `JsonWriter` 和 `JsonReader` 的使用方法。此外，它还详细列出了支持的数据类型范围，包括基础类型、集合类型（如 Array、HashMap）、特殊类型（如 Option、BigInt），以及用于定制化处理的自定义接口 `JsonSerializable` 和 `JsonDeserializable`。这份 API 参考文档非常适合需要在仓颉语言中进行复杂 JSON 数据处理、流式读写操作或需要扩展标准序列化行为的开发者查阅。

## Detailed Description

### json_stream_package_overview.md json_stream_package_overview.md

本文档概述了 `stdx.encoding.json.stream` 包，旨在实现仓颉对象与 JSON 数据流之间的序列化与反序列化转换。文档主要包含功能介绍和 API 列表两部分，详细说明了 `JsonWriter` 和 `JsonReader` 的用途，并列出了支持的接口、类、枚举及结构体。关键信息包括支持的基础数据类型、集合类型（如 Array、HashMap）及其他类型（如 Option、BigInt），以及用于自定义序列化行为的 `JsonSerializable` 和 `JsonDeserializable` 接口。这是一份 API 参考文档，面向需要在仓颉编程语言中进行 JSON 数据处理的开发者。
