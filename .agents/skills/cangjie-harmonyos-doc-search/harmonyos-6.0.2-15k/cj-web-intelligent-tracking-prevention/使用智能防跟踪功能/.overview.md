## Detailed Description

The following sections provide in-depth technical guidance and code examples for implementing and managing Intelligent Tracking Prevention features within the ArkWeb framework.

### 使用智能防跟踪功能_1.md
This technical guide explains how to implement Intelligent Tracking Prevention (ITP) within the ArkWeb component to block third-party tracking cookies. It covers enabling and disabling the feature via enableIntelligentTrackingPrevention, checking its status, and managing a global domain bypass list using addIntelligentTrackingPreventionBypassingList and removeIntelligentTrackingPreventionBypassingList. Key information includes that ITP is disabled by default and bypass lists apply to the entire application, not just a single component. The document targets developers using the Cangjie language and ArkWeb framework to enhance user privacy in web applications.

### 使用智能防跟踪功能_2.md
This document serves as a code tutorial for managing the Intelligent Tracking Prevention bypass list within the ArkWeb framework using the Cangjie language. It details two primary operations: removing specific domains from the bypass list and clearing the entire list. Key takeaways include the implementation of the removeIntelligentTrackingPreventionBypassingList and clearIntelligentTrackingPreventionBypassingList static methods, complete with error handling for BusinessException. The content targets HarmonyOS developers seeking to implement privacy controls in web applications, demonstrating how to integrate these functions into a UI component with a Web controller.
