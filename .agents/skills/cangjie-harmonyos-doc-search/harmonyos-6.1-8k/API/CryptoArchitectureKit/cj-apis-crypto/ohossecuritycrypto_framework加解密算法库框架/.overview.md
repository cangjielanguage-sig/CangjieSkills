# ohossecuritycrypto_framework加解密算法库框架

本目录包含OpenHarmony仓颉语言加解密算法库框架的API参考文档，旨在提供统一的密码算法接口以屏蔽底层实现。内容涵盖对称与非对称加解密、消息摘要、消息认证码（MAC）、随机数生成及密钥管理等核心功能。文档详细介绍了DataBlob数据结构、Cipher加解密流程、各类参数规范（如GCM、CCM）以及工厂函数的使用方法。该框架适用于使用Cangjie语言进行HarmonyOS应用开发并需要实现数据安全加密、完整性校验及密钥管理的程序员。

## 详细描述

### class_CcmParamsSpec.md class_CcmParamsSpec.md
定义CCM模式对称加解密的参数配置，包含authTag、aad、iv属性。文档说明了各参数的严格字节长度要求及加密时从doFinal提取authTag的流程。

### class_DataBlob_39b3feb8.md class_DataBlob_39b3feb8.md
定义用于存储blob数据的buffer数组类型，包含可读写的data属性（Array<UInt8>）及构造函数，适用于处理二进制数据块。

### class_GcmParamsSpec.md class_GcmParamsSpec.md
定义GCM模式对称加解密的参数，包含aad、iv、authTag属性。文档明确了iv和authTag的长度限制及authTag提取规则。

### class_IvParamsSpec.md class_IvParamsSpec.md
定义用于对称加解密的IvParamsSpec类，涵盖iv属性及AES、3DES等算法的长度要求，适用于CBC、CTR等模式。

### class_Md.md class_Md.md
介绍消息摘要计算类，包含digest、getMdLength和update方法，说明了update与digest的两段式调用逻辑及错误处理。

### class_ParamsSpec_b10477d7.md class_ParamsSpec_b10477d7.md
定义对称加解密操作的参数规范基类，包含algName属性，用于指定IvParamsSpec、GcmParamsSpec等子类类型。

### class_Random.md class_Random.md
指导使用加密框架进行随机数计算，支持CTR_DRBG算法，包含generateRandom和setSeed函数及参数限制说明。

### class_SymKey.md class_SymKey.md
定义对称密钥对象，包含algName和format属性，提供clearMem（清除内存）和getEncoded（获取字节流）方法。

### enum_CipherSpecItem.md enum_CipherSpecItem.md
定义加解密操作参数枚举，支持RSA和SM2算法，详细列出了RSA PKCS1_OAEP模式的参数配置。

### enum_CryptoMode_49adbf61.md enum_CryptoMode_49adbf61.md
定义加解密操作模式枚举，包含EncryptMode与DecryptMode值，用于指定加密或解密操作类型。

### func_createMacStr_3more_fe9bf5a4.md func_createMacStr_3more_fe9bf5a4.md
介绍createMac、createMd和createRandom三个工厂函数，用于生成消息认证码、消息摘要和随机数对象。

### func_createSymKeyGenera_4f17823f.md func_createSymKeyGenera_4f17823f.md
介绍通过指定算法名称获取对称密钥生成器实例的函数，包含参数规范及异常处理说明。

### interface_Key.md interface_Key.md
定义加密密钥的父类接口，包含algName、format属性及getEncoded方法，用于获取符合ASN.1等规范的密钥数据。

### ohossecuritycrypt_4more_e6c2a309.md ohossecuritycrypt_4more_e6c2a309.md
框架总览文档，重点介绍createCipher函数，说明PKCS5/PKCS7填充规则、分组模式明文长度要求及RSA/SM2使用限制。

### class_Cipher/
包含Cipher类的API参考，涵盖对称与非对称加解密的核心接口，详细介绍了initialize、update和doFinal方法的使用规范。

### class_Mac/
包含Mac类的API参考，涵盖消息认证码计算的完整流程，包括初始化、数据更新及结果获取，涉及HMAC等算法。

### class_SymKeyGenerator/
包含对称密钥生成相关的API，涵盖SymKeyGenerator类、密钥转换方法convertKey及随机密钥生成函数generateSymKey。
