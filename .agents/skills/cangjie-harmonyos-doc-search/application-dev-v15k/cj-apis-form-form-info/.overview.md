## Detailed Description

### ohosformform_infoFormInfo/
This directory contains API reference documentation for the `ohos.form.form_info` module within the HarmonyOS Cangjie development environment. It focuses on the data structures, classes, and enumerations used to manage system card (form) information, configurations, and states. Key components include the `FormInfo` class for card metadata, filters for querying forms, and enums defining dimensions, shapes, types, and states. These resources are part of the SystemCapability.Ability.Form capability starting from version 20. This documentation is suitable for Cangjie software engineers and developers building or managing form-based applications who need programmatic access to card properties and lifecycle management.

Within this section, developers will find the necessary definitions to interact with the form system. The `FormInfo` class acts as the primary container for metadata, while the provided enumerations standardize how form attributes like shape and dimension are handled across the application. By utilizing these APIs, engineers can ensure their applications correctly interpret and manipulate form states, adhering to the specifications set forth in SystemCapability.Ability.Form version 20.
