# 使用AudioRenderer播放对端的通话声音

This directory provides comprehensive technical guidance on utilizing the AudioRenderer component to play remote call audio within HarmonyOS applications. It covers the complete workflow from retrieving the UIAbility context to implementing audio output logic. Key technical aspects include configuring `audioRendererInfo` parameters—specifically setting stream usage to `STREAM_USAGE_VOICE_COMMUNICATION` and content type to speech—as well as managing the AudioRenderer lifecycle. The content addresses state validation, error handling, and data reading from files. This resource is ideal for HarmonyOS developers building VOIP applications or implementing complex audio playback features using ArkTS or Cangjie.
