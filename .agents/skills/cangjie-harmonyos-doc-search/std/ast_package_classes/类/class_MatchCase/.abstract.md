This directory contains API documentation for the `MatchCase` class within the Cangjie programming language's Abstract Syntax Tree (AST). It covers the structural definition of match expression case branches, detailing properties for patterns, guards, and the `=>` operator. Additionally, it outlines methods for initialization, token conversion, and tree traversal using the Visitor pattern. This documentation is intended for compiler developers and tool builders who need to programmatically manipulate or analyze Cangjie code structures, specifically focusing on match expression logic and syntax tree navigation.
