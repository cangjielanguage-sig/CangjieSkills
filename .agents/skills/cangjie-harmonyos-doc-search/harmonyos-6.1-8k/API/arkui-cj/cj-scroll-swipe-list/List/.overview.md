## 详细说明

### List_5more_9f09686f.md List_5more_9f09686f.md
这份文档是ArkUI框架中List组件的API参考文档，旨在指导开发者使用Cangjie语言创建用于连续展示同类数据的列表容器。文档主要涵盖模块导入、支持的子组件（如ListItem、ListItemGroup）及渲染控制、子组件索引计算规则、组件初始化参数（space、initialIndex、scroller）以及支持的通用属性和事件。关键信息指出该组件处于Beta阶段，详细说明了索引值的计算逻辑，并强调了即使子组件隐藏仍会计算索引值。本文档适合具备ArkUI和Cangjie基础的开发者查阅，用于构建可滚动的列表界面。

### 组件事件_2more_a7f11376.md 组件事件_2more_a7f11376.md
本文档是Cangjie语言ArkUI开发的API参考文档，定义了组件滚动相关的事件处理接口。主要涵盖onScrollFrameBegin（控制每帧滚动偏移）和onScrollIndex（监听子组件索引变化）两个函数，以及OnScrollFrameBeginHandlerResult结果类。关键点在于通过回调参数控制实际滑动量及获取列表显示区域的索引信息。文档面向ArkUI开发者，适用于需要精细控制滚动行为或监控列表状态的场景，起始版本为22。
