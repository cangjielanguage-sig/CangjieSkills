# Stage模型应用程序包结构

This directory provides a comprehensive technical overview of the application package structure for the Stage model in HarmonyOS development. It covers the entire lifecycle of the application structure, starting from the development state within DevEco Studio to the structural transformation that occurs during the compilation and release phases. Key topics include the organization of project directories, the specific roles of configuration files like `app.json5` and `module.json5`, the handling of Cangjie source code, and the generation of build artifacts such as HAP and HAR files. This documentation is specifically suitable for HarmonyOS developers, particularly those utilizing the Cangjie language, who need a deep understanding of project organization, build processes, and deployment workflows to effectively manage their applications.

This technical guide explains the structural transformation of HarmonyOS projects from development to release. This document targets HarmonyOS developers using DevEco Studio to understand build artifacts and deployment workflows.
