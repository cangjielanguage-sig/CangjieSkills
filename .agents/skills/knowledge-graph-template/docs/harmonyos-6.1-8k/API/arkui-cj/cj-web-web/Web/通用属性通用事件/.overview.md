# 通用属性通用事件

本目录包含UI框架中通用属性与通用事件的参考文档，旨在为开发者提供快速索引。内容涵盖了布局尺寸、视觉效果、交互控制及变换动画等核心属性，以及组件生命周期、焦点管理、鼠标键盘输入等关键事件。文档涉及组件约束、弹性布局、样式配置及事件处理等概念，适合应用开发人员在构建用户界面时查阅，以快速定位和应用所需的组件配置与交互逻辑。

## 快速导航

  → 查看通用属性列表 通用属性通用事件_1.md

## 详细描述

### 通用属性通用事件_1.md
本文档旨在提供UI框架中支持的通用属性列表，作为开发者的快速参考索引。文档涵盖了布局尺寸（如width、height、layoutWeight）、视觉效果（如backgroundColor、border、opacity）、交互控制（如focusable、enabled、bindMenu）以及变换动画（如scale、translate）等多个维度的属性。关键信息在于每个属性均链接至详细的定义文档，涉及组件约束、弹性布局、焦点管理及样式配置等核心概念。该文档主要面向应用开发人员，帮助其在构建用户界面时快速定位和应用所需的通用组件属性。

### 通用属性通用事件_2.md
本文档旨在列出系统支持的通用事件，明确组件可用的交互事件范围。主要涵盖组件生命周期事件（onAppear、onDisAppear）、焦点控制（onBlur、onFocus）、鼠标交互（onHover、onMouse）、键盘输入（onKeyEvent）、触摸操作（onTouch）及可见区域变化（onVisibleAreaChange）。关键信息在于明确仅支持这九种特定事件，并为每个事件提供了指向详细功能说明的链接，便于查阅具体参数。该文档属于API参考手册，面向使用该UI框架的开发者，帮助其快速掌握通用事件接口的使用。
