# 向用户申请授权

This directory serves as a comprehensive resource for implementing runtime authorization requests for sensitive user permissions within HarmonyOS applications. It details the essential procedures for declaring permissions, triggering dynamic authorization dialogs, and verifying access tokens using core APIs such as `requestPermissionsFromUser` and `checkAccessToken`. The documentation highlights critical constraints, including the non-persistent nature of permissions, requirements to keep system dialogs visible, and the specific timing needed for requests during `onWindowStageCreate`. This content is specifically designed for application developers—particularly those using the Cangjie language—who need to securely integrate system capabilities like location or camera while strictly adhering to user privacy principles and system security guidelines.

### 向用户申请授权_2more.md 向用户申请授权_2more.md
This guide instructs developers on implementing runtime authorization requests for sensitive user permissions (user_grant) within an application. It covers the steps to trigger dynamic authorization dialogs and verify results, alongside a detailed section on constraints and limitations. Key takeaways include the necessity of using requestPermissionsFromUser() to request access and checkAccessToken() to verify status before every operation. The document emphasizes that permissions cannot be persisted, system dialogs must not be obscured, and specific timing is required when calling requests during onWindowStageCreate(). Intended for application developers needing to access system capabilities like location or camera while adhering to user privacy principles.
