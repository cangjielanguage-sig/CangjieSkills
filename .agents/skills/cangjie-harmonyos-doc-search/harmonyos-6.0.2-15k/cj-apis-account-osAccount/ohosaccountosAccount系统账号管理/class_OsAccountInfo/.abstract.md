This directory contains API reference documentation for the `OsAccountInfo` class within the Cangjie programming language. It comprehensively covers the data structure used to represent operating system account details, including the class constructor, property definitions, and attribute management. Key topics include account instantiation, system capabilities, version requirements (starting from API version 19), and the handling of various account attributes such as local ID, creation time, distributed info, and constraints. This documentation is specifically designed for system developers and software engineers who need to manage, query, or integrate OS account functionalities into their applications.
