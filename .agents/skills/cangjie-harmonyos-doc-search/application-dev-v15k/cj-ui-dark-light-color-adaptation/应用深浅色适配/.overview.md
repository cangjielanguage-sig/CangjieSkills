# 应用深浅色适配

This directory provides comprehensive technical guidance on adapting applications to support dark and light display modes. It covers essential strategies for synchronizing with system settings, programmatically enforcing specific themes, and managing resource directories for colors and images. Key topics include the `setColorMode` API, system default judgment rules, and advanced event handling for theme transitions. This documentation is specifically designed for Cangjie developers seeking to create responsive, accessible, and visually consistent user interfaces that align with operating system preferences.

## Detailed Description

### 应用主动设置深浅色模式_2more.md 应用主动设置深浅色模式_2more.md
This technical guide instructs developers on how to programmatically override system dark and light mode settings within an application. It covers the usage of the `setColorMode` API to fix the theme or revert to system defaults, alongside the system's logic for handling resource directories. Key takeaways include that API calls take precedence over system settings, and the presence of a dark resource directory dictates automatic theme switching for system components. Intended for Cangjie developers, this document helps ensure consistent UI experiences regardless of system configuration.

### 概述.md 概述.md
This document serves as a technical overview for adapting applications to the system's dark and light display modes to improve user experience. It primarily covers the "Application Dark/Light Adaptation" section, which includes following system settings, actively setting modes, and understanding system default judgment rules. The text categorizes adaptation strategies based on the relationship between the application and system configuration. This guide is intended for developers seeking to implement responsive UI themes and ensure their applications align with system-level display preferences.

### 应用跟随系统的深浅色模式/
This directory focuses on the technical implementation of system-wide dark and light mode adaptation for applications. It is designed to help developers ensure their user interfaces remain consistent with the operating system's visual settings, thereby enhancing user comfort and accessibility. The guide covers a wide range of topics, including color adaptation using custom resource directories or system resource IDs, image resource adaptation via qualifiers or SVG properties, and specific configurations for Web components. It also delves into advanced programming techniques such as implementing event listeners through AbilityStage lifecycle methods and utilizing AppStorage for state management during theme transitions. This resource is specifically tailored for developers working with the Cangjie language, providing them with the essential knowledge and code patterns required to handle custom logic when the system theme changes.
