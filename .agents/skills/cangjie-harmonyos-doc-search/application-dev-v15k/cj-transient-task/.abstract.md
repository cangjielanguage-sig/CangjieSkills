This directory serves as a comprehensive technical resource for Cangjie developers aiming to implement transient tasks within their applications. It specifically addresses the requirement to extend application runtime in the background to execute short-duration operations, such as saving state or performing quick maintenance, without keeping the main application interface active. The content thoroughly covers essential system constraints that developers must navigate, including specific application timing rules, daily quotas (which default to 10 minutes), and strict limits on concurrent execution. By providing detailed API interfaces for requesting, querying, and canceling tasks, this guide helps developers manage background processes efficiently. It is designed for those who need to balance functionality with system resource limits to ensure application stability and prevent process termination.
