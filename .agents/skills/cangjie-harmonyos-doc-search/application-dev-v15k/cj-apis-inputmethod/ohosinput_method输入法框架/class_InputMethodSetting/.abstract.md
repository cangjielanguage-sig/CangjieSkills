This directory provides comprehensive API reference documentation for the Cangjie `InputMethodSetting` class, part of the IMEKit framework. It details essential functionalities for managing and querying input method configurations, including retrieving installed IMEs, filtering by activation status, and handling subtypes. Additionally, it covers event subscription mechanisms and UI dialog interactions. The documentation includes syntax details, parameters, return types, and specific error codes. It is designed for Cangjie developers seeking to integrate robust input method framework capabilities into their applications.
