This directory provides a comprehensive technical overview of the PersistentStorage module within the ArkUI framework, specifically designed to manage the persistence of UI state across application restarts. It thoroughly explains the synchronization mechanisms with AppStorage, the lifecycle of data persistence, and the correct implementation patterns required to avoid common errors. Key topics include supported data types, the critical order of operations for initialization, performance constraints such as the 2kb data limit, and strategies to prevent data loss during app updates. This resource is essential for application developers using ArkUI or Cangjie who need to build robust applications with reliable state management and consistent user experiences.
