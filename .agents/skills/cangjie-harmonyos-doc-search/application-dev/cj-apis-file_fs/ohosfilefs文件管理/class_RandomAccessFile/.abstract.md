This directory provides comprehensive API reference documentation for the `RandomAccessFile` class in the Cangjie programming language, specifically designed for random read and write file operations. It covers core functionalities such as managing file descriptors, manipulating offset pointers, and handling data buffers. The documentation details methods for reading data, setting file pointers, and writing strings or byte arrays, including parameters for length, offset, and encoding. It also addresses error handling through `BusinessException` codes. This content is intended for Cangjie developers who possess knowledge of the FileIO kit and system file management, offering the technical details necessary to implement complex file I/O logic effectively.
