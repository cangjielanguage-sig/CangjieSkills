### class TextClockController

```cangjie
public class TextClockController {
    public init()
}
```

**功能：** TextClock容器组件的控制器，可以将该控制器绑定到TextClock组件，通过它控制文本时钟的启动与停止。一个TextClock组件仅支持绑定一个控制器。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12
