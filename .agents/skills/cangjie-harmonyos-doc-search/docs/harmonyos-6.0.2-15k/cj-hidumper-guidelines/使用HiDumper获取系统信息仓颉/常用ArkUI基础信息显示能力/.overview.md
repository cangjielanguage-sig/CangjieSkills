# 常用ArkUI基础信息显示能力

This directory provides technical documentation on utilizing system tools to display and debug fundamental information within ArkUI applications. It specifically addresses techniques for extracting window hierarchies, component trees, and navigation stacks using command-line utilities like `hidumper`. The guides cover identifying Window IDs, isolating specific UI nodes, and analyzing route stacks for applications using the Navigation component. These resources are essential for developers and QA engineers seeking to perform deep-level debugging of UI structures, verify window management logic, and troubleshoot page navigation issues in HarmonyOS environments.

## Detailed Description

### 常用ArkUI基础信息显示能力_4more.md 常用ArkUI基础信息显示能力_4more.md
This technical guide explains how to use the hidumper tool to retrieve window and component tree information for ArkUI applications. It covers retrieving full window information to identify Window IDs, fetching the complete component tree for a specific application, and isolating details for a specific node within that tree. The document provides specific shell commands for each operation, explains the relationship between Window IDs and built-in system windows, and illustrates output formats for debugging UI hierarchies. Intended for developers and testers debugging ArkUI interfaces, it requires knowledge of the hdc shell and window management concepts. By following these instructions, users can effectively map out the visual structure of their applications and pinpoint specific component attributes during the development process.

### 获取期望应用的Inspector树_2more.md 获取期望应用的Inspector树_2more.md
This technical guide explains how to retrieve the Inspector tree and navigation stack information for HarmonyOS applications using shell commands. It covers two main procedures: obtaining the component Inspector tree and fetching the application route stack. Key information includes the prerequisite of enabling the ArkUI debug switch and specific hidumper commands targeting the WindowManagerService. The guide clarifies that the Inspector tree matches DevEco tools, while the navigation stack command is exclusive to apps using the Navigation component. Intended for developers and QA engineers, this document aids in debugging UI hierarchies and page routing logic. It serves as a command-line alternative to graphical tools, offering precise insights into the application's current state and navigation history.
