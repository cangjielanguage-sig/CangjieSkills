# cj-crypto-key-derivation-overview

This directory contains a critical technical reference document designed to assist developers in implementing robust cryptographic key derivation functions within a specific framework. It provides a comprehensive overview of the supported algorithm configurations, specifically focusing on PBKDF2 for password-based key derivation and HKDF for HMAC-based extraction and expansion. The documentation details the supported HMAC digest algorithms, including SHA1, SHA224, SHA256, SHA384, SHA512, and SM3, ensuring compatibility with various security standards. It also clarifies the specific string parameter formats necessary for instantiating these generators and outlines the three operational modes of HKDF. This resource is tailored for developers implementing security features who require a deep understanding of cryptographic concepts and are working within API version 12 and above. By following these specifications, developers can ensure their implementations meet the required security standards and functional requirements.

## Detailed Description

### cj-crypto-key-derivation-overview.md cj-crypto-key-derivation-overview.md

This file acts as the primary technical reference for the cryptographic framework's key derivation capabilities. It provides a detailed specification of the supported algorithm configurations, ensuring developers have the necessary parameters to implement secure key generation effectively.

Key topics covered in this document include:
*   **PBKDF2 Algorithm:** A breakdown of the password-based derivation method that utilizes iterative hashing to enhance security against brute-force attacks.
*   **HKDF Algorithm:** An explanation of the HMAC-based extraction and expansion process used for deriving keys from input secrets.
*   **Supported Digests:** A comprehensive list of compatible HMAC digest algorithms, specifically SHA1, SHA224, SHA256, SHA384, SHA512, and SM3.
*   **Parameter Formats:** The specific string formats required to instantiate the key derivation generators correctly.
*   **HKDF Modes:** A guide to the three operational modes: EXTRACT_ONLY, EXPAND_ONLY, and EXTRACT_AND_EXPAND.

The document targets developers implementing security features, assumes familiarity with cryptographic concepts, and is applicable to API version 12 and above.
