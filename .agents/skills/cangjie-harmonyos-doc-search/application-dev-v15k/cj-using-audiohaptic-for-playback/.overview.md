# cj-using-audiohaptic-for-playback

This directory contains a technical guide designed for developers working with the Cangjie language, focusing on the implementation of synchronized audio and haptic playback via the AudioHaptic module. The content provides a deep dive into the development process required to create cohesive sensory experiences. It covers the essential prerequisites, such as applying for the `ohos.permission.VIBRATE` permission, and moves into the technicalities of registering audio and haptic resources using URIs. The guide details the configuration of playback parameters, including latency modes and stream usage, to ensure performance meets application requirements. Furthermore, it documents the complete lifecycle of the AudioHapticPlayer, from initialization and playback control to the critical steps of resource release and unregistration. This resource is specifically suitable for application developers aiming to build immersive, multi-sensory interfaces. It is particularly relevant for those developing features like dynamic ringtones, tactile keyboard feedback, or enhanced notification systems where precise timing between sound and vibration is crucial for user satisfaction.

## Detailed Description

### cj-using-audiohaptic-for-playback.md

This document serves as a comprehensive development guide for implementing synchronized audio and haptic playback using the AudioHaptic module in the Cangjie language. It details the necessary steps including permission application for vibration, registering audio and haptic resources, and configuring parameters like latency mode and stream usage. The guide explains the complete lifecycle of the AudioHapticPlayer, from creation and playback control to resource release and unregistration. Key takeaways involve managing URIs for audio and vibration files and ensuring the `ohos.permission.VIBRATE` is granted. Intended for application developers, this tutorial facilitates the creation of immersive user experiences for scenarios such as ringtones, keyboard feedback, and notifications.
