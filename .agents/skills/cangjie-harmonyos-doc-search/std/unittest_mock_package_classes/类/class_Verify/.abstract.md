This directory provides comprehensive API documentation for the `Verify` class within the Cangjie unit testing framework. It is designed to assist developers in defining and executing behavior verification on mock objects. The content covers essential concepts such as verification statements using the `@Called` macro, execution frequency checks, argument validity, and call order validation. Key static methods detailed include `clearInvocationLog`, `noInteractions`, `ordered`, `that`, and `unordered`. This documentation is suitable for developers utilizing the mock framework to write precise unit tests, assuming familiarity with Cangjie syntax and general mocking principles.
