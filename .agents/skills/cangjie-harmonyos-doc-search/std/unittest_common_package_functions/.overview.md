### unittest_common_package_functions.md unittest_common_package_functions.md
This document provides API reference documentation for functions in the unittest common package, specifically designed for managing test option configurations. It covers three main functions: `registerOptionValidator` for registering custom validation logic, `setOptionInfo` for setting general option descriptions and valid types, and `setOrUpdateOptionInfo` for updating specific type descriptions. Key information includes the recommendation to use the `@UnittestOption` macro instead of directly calling the validator function. This technical reference is intended for developers working with the Cangjie language who need to customize or extend unit testing framework behaviors. The file acts as a structural guide, outlining the necessary imports, class definitions, and function signatures required to implement these configurations effectively within a testing environment.
