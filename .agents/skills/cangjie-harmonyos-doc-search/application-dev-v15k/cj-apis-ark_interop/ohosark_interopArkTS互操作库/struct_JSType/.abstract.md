This directory provides comprehensive API reference documentation for the `JSType` struct within the Cangjie language framework, primarily targeting developers utilizing ArkUI and Napi capabilities. It covers the structural definition of ArkTS data types, including static constants for types such as UNDEFINED, NUMBER, STRING, and OBJECT. Additionally, it details operator overloads for equality and inequality comparisons, alongside utility methods like `toString()`. This resource is essential for managing type checking and ensuring interoperability between native and JavaScript environments, with features available starting from API version 12. It serves as a technical guide for validating type equality and mapping standard JavaScript types to specific values within the system architecture.
