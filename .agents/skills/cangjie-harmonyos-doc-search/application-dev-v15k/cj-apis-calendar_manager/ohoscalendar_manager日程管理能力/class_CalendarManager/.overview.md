# class_CalendarManager

This directory contains API reference documentation for the `CalendarManager` class and associated event management functions within the Cangjie programming language ecosystem. It covers essential calendar operations, including the creation, deletion, and retrieval of calendar objects, as well as the management of calendar events. Key technical aspects include system capabilities, required permissions such as `ohos.permission.WRITE_CALENDAR` and `ohos.permission.READ_CALENDAR`, and comprehensive error handling for `BusinessExceptions`. This documentation is specifically designed for application developers seeking to integrate robust calendar data management features into their software using the Cangjie CalendarKit.
