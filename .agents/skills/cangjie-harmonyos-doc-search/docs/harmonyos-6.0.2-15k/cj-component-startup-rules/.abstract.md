This directory serves as a comprehensive resource for HarmonyOS developers, focusing on the critical component startup rules defined for the Stage model. Its primary purpose is to ensure robust system security and a seamless user experience by enforcing strict guidelines on how and when components can be activated. The documentation covers a broad spectrum of operational scenarios, ranging from general restrictions to complex permission validations. It specifically addresses the nuances of cross-application communication, the stringent requirements for background startup processes (limited to system apps), and the intricate rules governing distributed cross-device interactions involving UIAbility. Key technical elements include the verification of the `exported` field and the necessity of specific permissions such as `ohos.permission.START_ABILITIES_FROM_BACKGROUND` and `ohos.permission.DISTRIBUTED_DATASYNC`. These guidelines are effective from API 18 onwards. This directory is essential reading for developers seeking to implement compliant, secure, and efficient component startup logic within their HarmonyOS applications.
