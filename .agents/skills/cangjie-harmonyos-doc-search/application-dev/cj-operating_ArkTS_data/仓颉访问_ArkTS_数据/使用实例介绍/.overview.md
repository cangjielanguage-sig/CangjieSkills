# 使用实例介绍

This directory provides practical examples and technical guides for achieving interoperability between ArkTS and Cangjie within the HarmonyOS ecosystem. It covers essential topics such as manipulating ArkTS objects (both Sendable and ordinary) from Cangjie code, invoking ArkTS functions, and managing concurrency using AsyncLock mechanisms. Key concepts include cross-language communication, data sharing via `ark_interop`, thread safety, and context management during function calls. These resources are suitable for developers working on HarmonyOS applications who need to integrate Cangjie dynamic libraries with ArkTS, handle concurrent data access, or implement complex cross-language interactions.

## Detailed Description

### 操作_ArkTS_的_sendable_对象.md 操作_ArkTS_的_sendable_对象.md
This guide explains how to operate on ArkTS sendable objects within Cangjie code to enable efficient concurrent communication via pass-by-reference. The document covers defining a `@Sendable` class in ArkTS, implementing property access logic in Cangjie using the `ark_interop` library, creating TypeScript declarations, and invoking the function from ArkTS. Key information includes extracting properties like `num1` and `num2` from a `JSObject` in Cangjie and performing calculations, highlighting that Cangjie handles sendable objects like standard ArkTS objects. This tutorial targets developers working on ArkTS and Cangjie interoperability who need to manage concurrent data sharing.

### 操作_ArkTS_的普通对象.md 操作_ArkTS_的普通对象.md
This technical guide demonstrates how to manipulate ordinary ArkTS objects within Cangjie code using the ark_interop library. It details a complete workflow including Cangjie function implementation, TypeScript interface declarations, and ArkTS invocation. Key topics cover reading and writing object properties using `JSObject[key]`, creating new objects via `JSContext.object()`, and enumerating enumerable properties. The document highlights that property assignment fails silently on sealed objects or non-writable properties and explains how to access the ArkTS global object. This guide targets developers implementing cross-language interoperability between ArkTS and Cangjie.

### 调用_ArkTS_函数.md 调用_ArkTS_函数.md
This technical guide explains how to invoke ArkTS functions from Cangjie code within HarmonyOS development. It covers two primary scenarios: standard function calls and method calls requiring a `this` pointer. Key sections demonstrate retrieving functions via parameters or collections, converting data types using `JSContext` and `JSCallInfo`, and handling callbacks. The document highlights the importance of explicitly passing the `thisArg` parameter when calling methods to prevent runtime errors associated with undefined contexts. Targeted at developers familiar with both ArkTS and Cangjie, this tutorial provides essential code examples for implementing bidirectional interoperation and managing object context during cross-language function execution.

### ArkTS_异步锁/
This directory serves as a specialized technical guide for developers working within the OpenHarmony and HarmonyOS ecosystems, focusing specifically on the implementation of ArkTS AsyncLock mechanisms to handle concurrency issues. It provides in-depth insights into managing data races in multi-concurrent environments through the use of Sendable objects and Cangjie backend integration. The content covers essential architectural patterns, including TypeScript interface declarations, Worker thread initialization, and cross-thread communication strategies. Furthermore, it explores asynchronous interoperability between ArkTS Worker threads and Cangjie dynamic libraries, detailing message listening and promise handling. This resource is ideal for advanced developers seeking to master multi-threading, ensure thread-safe data access, and execute efficient cross-language function calls in their applications.
