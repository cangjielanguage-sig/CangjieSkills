This directory contains comprehensive API reference documentation for the Cangjie `AVMetadataExtractor` class, a core component of the MediaKit framework designed for retrieving metadata from various media resources. It covers essential functionalities such as setting data sources for both streaming media and local file descriptors, fetching album art as PixelMaps, and obtaining general media information. Additionally, it details resource management procedures to ensure efficient memory usage. This documentation is suitable for HarmonyOS developers and multimedia application engineers who need to programmatically access media file details, handle album covers, and manage system resources effectively within their Cangjie projects.
