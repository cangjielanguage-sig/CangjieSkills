# ohossecuritycrypto_framework加解密算法库框架

This directory contains the API documentation for the OpenHarmony Security Crypto Framework, specifically designed for the Cangjie programming language. It provides a comprehensive library for cryptographic operations, including symmetric and asymmetric encryption, decryption, message digests, message authentication codes (MAC), and secure random number generation. The framework covers essential data structures like DataBlob and key management interfaces, alongside specific parameter specifications for algorithms like AES, SM4, RSA, and SM2. It is intended for developers and security engineers building secure applications on the OpenHarmony platform who need to implement robust data protection and integrity features.
