# 查询关键资产仓颉

This directory provides technical resources for querying critical assets using the Cangjie language within the AssetStoreKit framework. It covers synchronous interfaces, parameter configuration, and data retrieval strategies. Key topics include querying single asset plaintext, batch querying with pagination, and understanding IPC buffer constraints. This content is suitable for developers and system integrators seeking to implement secure and efficient asset management logic while adhering to system performance limitations.

## Detailed Description

### 代码示例.md 代码示例.md
This document provides Cangjie code examples demonstrating how to use synchronous interfaces in the AssetStoreKit to query critical assets. The content is divided into three main sections: querying single asset plaintext, querying single asset attributes, and batch querying asset attributes with pagination and sorting. Key takeaways include the configuration of AssetParam objects—such as ALIAS, RETURN_TYPE, RETURN_LIMIT, and RETURN_ORDERED_BY—to filter and control query results. The examples also illustrate error handling using BusinessException. This technical reference is designed for developers seeking to implement asset retrieval logic, offering practical guidance on parameter usage for different data access requirements.

### 约束和限制.md 约束和限制.md
This document serves as a technical reference outlining specific constraints and limitations for querying critical assets. It focuses on the technical bottleneck caused by Inter-Process Communication (IPC) buffer sizes during data transmission. The key information provided is a strict recommendation to implement pagination or batching logic: when the total number of critical assets exceeds 40, queries must be split into smaller batches, with each batch containing a maximum of 40 items. This guideline is essential for developers and system integrators to prevent transmission failures and ensure system stability when handling large volumes of asset data.

### 接口介绍/
This directory provides a comprehensive technical reference for the AssetStoreKit API, focusing on the management and querying of key assets. It covers the `query` function interface, attribute tags, data structures, and configuration parameters for access control and synchronization. Key topics include security warnings regarding `DATA_LABEL` fields, data type constraints, and pagination logic for query results. Designed for developers implementing secure asset storage and synchronization, these documents offer essential specifications for parameter definitions, data handling, and API response customization to ensure compliance and efficient data management.
