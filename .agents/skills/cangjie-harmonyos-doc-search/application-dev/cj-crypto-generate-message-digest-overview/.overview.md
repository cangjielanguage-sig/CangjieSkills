# cj-crypto-generate-message-digest-overview

This directory serves as a comprehensive technical reference for developers working with message digest algorithms within a cryptographic API. It provides a foundational understanding of how these algorithms map arbitrary input messages to fixed-length outputs, emphasizing essential characteristics such as determinism and fixed output size. The content covers a wide array of supported algorithms, including SHA1, SHA256, SHA512, MD5, and SM3, and provides a detailed table specifying their respective byte lengths and the minimum API version required (version 12+). Furthermore, it notes the current Beta status of the feature and includes relevant keywords for easy searching. This documentation is ideal for software engineers and security professionals who need to select the correct algorithm specification and verify version compatibility when implementing cryptographic functions in their systems.
