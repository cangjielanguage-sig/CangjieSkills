This directory provides comprehensive API documentation for the `Event4` class and related subscription functions within the Cangjie programming language. It specifically addresses the handling of events that require four generic arguments, covering the full lifecycle from emission to unsubscription. The documentation details the integration with the `EventHub` and `EventCallBack4` interfaces, offering practical code examples for implementation. This resource is essential for developers utilizing the AbilityKit framework and the AbilityRuntime Core system to build robust, event-driven applications with complex parameter passing requirements.
