This directory provides technical guides and code examples for implementing Bluetooth Low Energy (BLE) GATT client functionality, specifically focusing on connecting to a server to read and write data. It covers the complete workflow from establishing connections and discovering services to performing read/write operations and managing disconnections. The content includes implementations in both Cangjie and ArkTS languages within the HarmonyOS ecosystem. It is suitable for developers looking to integrate BLE communication into their applications, offering detailed insights into GATT protocols, UUID management, and asynchronous callback handling.
