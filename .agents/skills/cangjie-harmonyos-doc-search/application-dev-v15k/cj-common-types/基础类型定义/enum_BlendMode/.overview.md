# enum_BlendMode

This directory contains technical documentation for the `BlendMode` enumeration utilized within the ArkUI framework and the Cangjie programming language. It focuses on image blending and compositing operations, covering a wide spectrum of modes from basic Porter-Duff operators to advanced color effects such as Luminosity, Overlay, and Hue. The included files provide detailed mathematical formulas and visual logic explaining how source and destination pixels interact to determine final color and alpha values. This resource is essential for ArkUI developers and graphics programmers aiming to implement sophisticated visual layering, image compositing, and dynamic color manipulation in their applications, with specific references to API version 19 requirements.
