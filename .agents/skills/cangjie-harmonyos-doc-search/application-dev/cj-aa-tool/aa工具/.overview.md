# aa工具

This directory contains comprehensive documentation for the "aa" (Ability Assistant) command-line tool used in the OpenHarmony and HarmonyOS development environments. It covers essential operations for application lifecycle management, including launching applications, debugging, performance tuning, and process control. Key topics include commands like `start`, `force-stop`, `test`, `attach`, and `process`, alongside detailed error code troubleshooting. This resource is suitable for developers, QA engineers, and system integrators who need to manage UIAbility and ServiceExtensionAbility components, execute automated tests, or perform runtime debugging via the hdc shell environment.

## Detailed Description

### aa工具_4more.md
This document serves as a reference guide for the "aa" (Ability assistant) command-line tool, designed to help developers launch applications, execute test cases, and perform debugging tasks within the OpenHarmony environment. It covers environment requirements involving the hdc tool, a comprehensive list of supported commands such as start, force-stop, test, attach, and process, along with usage examples. Key information includes the tool's ability to manage UIAbility and ServiceExtensionAbility components, force-stop processes, and integrate with IDE tools for performance tuning. Targeted at OpenHarmony developers, this guide requires prior knowledge of the hdc shell environment and application debugging concepts.

### 应用调试调优命令process.md
This reference document details the `aa process` command used for integrating debugging and tuning tools within an IDE for application development. It covers command syntax, a comprehensive parameter list including required flags like bundle name and ability name, return values, specific error codes, and usage examples. Key information includes the mutually exclusive options for debugging (`-D`) and tuning (`-p`), along with the optional sandbox entry flag (`-S`). This guide targets developers and system integrators needing to programmatically debug or optimize application performance, providing specific error handling and execution feedback.

### 强制停止进程命令force-stop_3more.md
This reference documentation outlines three specific `aa` command-line interface operations for application lifecycle management. It details the `force-stop` command to terminate processes, the `test` command to initiate testing frameworks with configurable parameters, and the `attach` command to enable application debugging. Each section provides comprehensive syntax definitions, parameter descriptions, return values, and specific error codes for troubleshooting issues like service connection failures or invalid permissions. Designed for developers and QA engineers, this guide serves as a practical manual for executing process control, running automated tests, and setting up debug environments using bundle names.

### 退出调试模式命令detach_2more.md
This technical reference document outlines command-line instructions for managing application debugging states, specifically exiting debug mode and configuring wait-for-debug settings. The content is divided into two main sections: the aa detach command for terminating debug sessions using a bundle name, and the aa appdebug command for setting, canceling, or retrieving debug wait states. Key information includes parameter definitions such as the persistent flag -p, return values for success and failure, and specific error codes for troubleshooting issues like connection failures or invalid developer modes. This guide is intended for developers and system administrators who require precise control over application debugging processes via the terminal.

### aa工具错误码/
This directory contains troubleshooting documentation for error codes related to the `aa` (Ability Assistant) tool in HarmonyOS development. It covers issues encountered during application startup, ability invocation, and lifecycle management, including visibility validation failures, internal system errors, and command execution problems. Key topics include error code resolution, configuration checks, and debugging steps using `hdc` commands. This resource is suitable for developers, testers, and technical support personnel looking to diagnose and resolve runtime failures effectively.

### 启动命令start/
This directory provides comprehensive technical documentation on the `aa start` command within the HarmonyOS development ecosystem. It focuses specifically on the Stage model, detailing the protocols for launching core components such as UIAbility and ServiceExtensionAbility. The content covers essential technical aspects including explicit and implicit startup syntax, parameter passing mechanisms, URI configuration, and error code troubleshooting. Designed specifically for developers and testers utilizing the Cangjie programming language, these resources offer practical guidance for debugging application startup processes, implementing command-line control logic, and managing data transfer during component initialization. Whether you are troubleshooting launch failures or testing parameter retrieval, this directory serves as a critical reference for effective command-line application management and lifecycle control.
