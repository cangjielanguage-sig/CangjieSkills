# Flex布局

本目录包含ArkUI框架中Flex布局相关的API参考文档，主要面向使用仓颉语言进行UI开发的开发者。文档详细介绍了如何通过`alignSelf`、`flexBasis`、`flexGrow`和`flexShrink`等属性控制子组件在弹性容器中的布局行为。内容涵盖了组件的对齐方式、基准尺寸设置、剩余空间分配以及空间不足时的压缩比例，旨在帮助开发者实现精细化的界面布局调整。

### Flex布局_6more_40fced89.md
这份文档是ArkUI框架中Flex布局属性的API参考手册，旨在指导开发者使用仓颉语言控制子组件在弹性容器中的布局行为。文档主要涵盖了`alignSelf`（交叉轴对齐）、`flexBasis`（基准尺寸）以及`flexGrow`（剩余空间占比）三个核心函数。关键信息指出这些属性仅对Flex、Column等特定父组件生效，起始版本为22，并详细说明了参数限制（如`flexBasis`不支持百分比）。该文档适用于需要精细调整UI布局的开发人员。

### func_flexShrinkFl_2more_063dd5bb.md
这份文档是ArkUI框架的API参考，详细说明了flexShrink函数的用法，该函数用于设置组件在父容器空间不足时的压缩比例。文档涵盖了接受?Float64和?Int64参数的两个重载版本。关键信息指出，父容器为Column或Row时需设置主轴尺寸且初始值为0，而Flex容器初始值为1。函数返回组件实例本身。该文档面向使用仓颉语言进行UI布局开发的开发者，旨在帮助其精确控制组件的弹性布局行为。
