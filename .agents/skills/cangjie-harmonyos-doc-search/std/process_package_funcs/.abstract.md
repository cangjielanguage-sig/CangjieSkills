The `process_package_funcs` directory serves as a comprehensive API reference for process management within the Cangjie programming language. It is designed to facilitate system-level operations, enabling developers to create, execute, and manage external subprocesses with precision. The content covers essential tasks such as handling command arguments, configuring environment variables, and managing input/output redirection. It provides detailed documentation for functions that execute commands—either capturing output or running silently—and utilities for finding existing processes or launching new ones. This resource is ideal for developers who need to integrate robust process control into their Cangjie applications, offering clear guidance on parameters, return values, exceptions, and resource management to ensure efficient and reliable system interaction.
