# class_Params

本目录包含仓颉语言中 `Params` 类的 API 参考文档，主要定义了 HarmonyOS 开发中 `Want.parameters` 字段常用的系统预置关键字。内容涵盖 Ability 生命周期管理（如故障重启检测、跨任务栈返回行为）、原子化服务跨端分享配置以及跨端迁移行为控制（如页面栈迁移、源端应用退出）。适用于使用仓颉语言进行 HarmonyOS 应用开发且需要处理系统参数、跨端交互及 UIAbility 逻辑的开发者，要求 API 22 及以上版本。

## 详细说明

### class_Params_6more_fd5dd763.md class_Params_6more_fd5dd763.md
本文档是Cangjie语言中Params类的API参考文档，定义了Want.parameters字段中常用的系统预置关键字。文档详细介绍了ABILITY_BACK_TO_OTHER_MISSION_STACK、ABILITY_RECOVERY_RESTART及分享相关的CONTENT_TITLE_KEY等静态常量。关键信息包括利用这些常量处理应用故障重启检测、控制跨任务栈返回行为以及配置原子化服务跨端分享的数据。部分参数仅限系统设置。面向HarmonyOS应用开发者，需具备UIAbility生命周期和Want机制的基础知识，适用于API 22及以上版本。

### static_const_SUPP_2more_58379494.md static_const_SUPP_2more_58379494.md
本文档定义了用于控制 HarmonyOS 跨端迁移行为的两个静态常量。主要涵盖 `SUPPORT_CONTINUE_PAGE_STACK_KEY` 和 `SUPPORT_CONTINUE_SOURCE_EXIT_KEY` 的详细定义。关键信息包括两者均为字符串类型，默认值为 true，分别用于控制是否迁移页面栈信息及源端应用是否退出，起始版本为 22。该文档面向使用仓颉语言进行应用开发并需要处理跨端迁移逻辑的开发者。
