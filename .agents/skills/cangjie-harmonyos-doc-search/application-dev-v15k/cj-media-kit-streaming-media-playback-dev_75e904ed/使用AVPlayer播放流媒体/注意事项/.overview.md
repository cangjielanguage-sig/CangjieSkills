# 注意事项

This directory serves as a comprehensive resource for developers working with the AVPlayer framework in the Cangjie language, specifically focusing on the nuances and advanced configurations of streaming media playback. It addresses critical operational considerations for both DASH and HLS protocols, providing solutions for customizing playback behaviors, managing track selections, and optimizing buffering mechanisms. The documentation includes detailed explanations of event sequences, bitrate adaptation strategies, and manual overrides for default adaptive streaming logic. These guides are essential for multimedia developers aiming to build robust video applications that maintain high performance and user satisfaction across varying network conditions and device capabilities.

## Detailed Description

### DASH设置视频起播策略_2more.md
This technical guide explains how to customize DASH video playback strategies and manually manage audio/video tracks using the AVPlayer framework in the Cangjie language. It covers setting video startup resolution via PlaybackStrategy and implementing manual track switching by listening to events, querying track descriptions, and selecting specific indices. The document provides Cangjie code examples demonstrating how to override default adaptive behaviors, such as forcing a 1920x1080 startup resolution or selecting specific tracks based on metadata like width and height. Intended for multimedia developers seeking granular control over streaming quality and track selection in weak network or specific user requirement scenarios.

### 注意事项_3more.md
This technical guide details specific considerations and operational differences for streaming media playback, focusing on buffering management and HLS bitrate adaptation. It covers monitoring buffering states and events, and implementing HLS multi-bitrate switching. Key information includes the buffering event sequence (START to END) and continuous CACHED_DURATION reporting. For HLS, it describes using availableBitrates to check options and setBitrate to change quality, noting that the player selects the closest match and requires specific states. Targeted at developers using the AVPlayer API in Cangjie who need to optimize streaming performance and user experience.
