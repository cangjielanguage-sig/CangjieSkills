This directory offers a technical overview of the Want object, a fundamental element used for passing information between application components in the Cangjie framework. It thoroughly covers the definitions, distinctions, and practical applications of Explicit and Implicit Wants. The content explores essential attributes such as bundleName, abilityName, actions, and entities, providing developers with the knowledge to handle both precise component targeting and system-level request routing. Designed for Cangjie application developers, this guide serves as a critical resource for mastering component navigation, data transfer mechanisms, and understanding the system's matching logic for implicit intents. By studying these materials, developers can effectively manage application startup and interaction flows.
