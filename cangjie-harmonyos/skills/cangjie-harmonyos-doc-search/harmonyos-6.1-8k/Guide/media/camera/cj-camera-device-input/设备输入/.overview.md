# 设备输入

本目录专注于相机设备的输入控制与基础功能开发，旨在为开发者提供构建多媒体相机应用的核心技术指导。内容涵盖了从开发环境准备、权限申请到具体功能实现的完整流程，重点介绍了如何使用CameraKit API创建并管理相机输入流。核心知识点包括获取场景模式、查询输出流能力以及实现预览、拍照和录像等基础操作。文档中包含Cangjie代码示例，并特别指出了当前功能的Beta阶段状态。该目录适用于具备基础开发知识的移动应用开发者，帮助其快速掌握设备调用的关键逻辑与最佳实践。

## 详细描述

### 开发步骤.md 开发步骤.md
本文档指导开发者使用CameraKit API进行相机功能开发，涵盖从接口导入到获取输出能力的步骤。主要内容包括导入接口库、通过CameraManager创建并打开相机输入流、获取支持的场景模式及查询预览和拍照等输出流能力。核心要点包括使用createCameraInput、getSupportedSceneModes和getSupportedOutputCapability等关键方法，并强调需先完成相机管理。文档提供了Cangjie代码示例，属于面向具备基础开发知识者的教程，适用于构建多媒体相机应用。

### 设备输入_92c269c3.md 设备输入_92c269c3.md
本文档旨在指导开发者如何通过调用和控制相机设备，开发具备基础功能的相机应用。主要涵盖开发准备工作（如申请相关权限）以及相机的基础操作，包括预览、拍照和录像。关键信息指出当前功能处于Beta阶段，开发前必须参考开发准备文档完成权限申请，随后才能进行设备调用与控制。面向需要进行相机功能开发的移动应用开发者，属于开发指南类文档。
