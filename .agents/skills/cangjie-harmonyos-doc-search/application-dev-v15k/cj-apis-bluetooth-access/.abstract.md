This directory serves as the definitive API reference documentation for the HarmonyOS Bluetooth Access module, specifically architected for the Cangjie programming language. It provides a comprehensive overview of the essential functionalities required to effectively manage Bluetooth radio states within the HarmonyOS ecosystem. The content covers critical operations such as enabling and disabling the Bluetooth hardware, querying the current operational status, and implementing robust mechanisms for monitoring state changes through callback subscriptions. Key technical topics include the `BluetoothState` enumeration, the `BluetoothAccessCallbackType` interface, and core functions like `enableBluetooth` and `getState`. This documentation is primarily intended for HarmonyOS developers utilizing the ConnectivityKit to implement basic Bluetooth control and state monitoring features in their applications, ensuring they are aware of the specific permissions and system capabilities required for successful execution.
