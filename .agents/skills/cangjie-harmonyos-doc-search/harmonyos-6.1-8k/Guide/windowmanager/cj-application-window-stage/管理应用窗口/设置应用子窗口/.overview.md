# 设置应用子窗口

本目录主要介绍在HarmonyOS应用中如何创建和管理子窗口。内容涵盖了子窗口的开发步骤、属性设置、显示与销毁，以及在不同场景下的使用限制和最佳实践建议。重点讲解了使用仓颉语言进行开发的流程，并对比了子窗口与控件overlay能力的优劣。适合熟悉ArkUI和AbilityKit框架的HarmonyOS应用开发者阅读，旨在帮助开发者掌握子窗口的实现方案及正确选择窗口模式。

## 详细描述

### 开发步骤.md 开发步骤.md

本文档是一份使用仓颉语言开发HarmonyOS应用子窗口的教程指南。涵盖了创建、设置属性、显示及销毁子窗口四个核心步骤。解释了未设置大小时的默认尺寸规则，并提供了在onWindowStageCreate生命周期及页面按钮点击事件中实现子窗口管理的两种代码示例，重点演示了createSubWindow、showWindow和destroyWindow接口的使用。面向熟悉ArkUI和AbilityKit的HarmonyOS应用开发者。

### 设置应用子窗口_d8a9eeac.md 设置应用子窗口_d8a9eeac.md

本文档旨在指导开发者如何按需创建应用子窗口（如弹窗）并进行属性设置。主要内容包括子窗口的基本定义，以及针对特定场景（如移动设备悬浮窗、分屏模式）的使用限制说明。核心要点是建议在移动设备、分屏及自由窗口模式下，优先使用控件的overlay能力替代子窗口，以获得更好的实时跟随效果和更高的自由度，避免系统限制带来的动效和样式问题。文档面向使用ArkUI框架的应用开发者，属于开发指南类文档，帮助开发者正确选择窗口实现方案。
