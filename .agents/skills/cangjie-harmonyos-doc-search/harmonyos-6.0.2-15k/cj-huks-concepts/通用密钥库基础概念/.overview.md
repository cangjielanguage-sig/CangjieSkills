# 通用密钥库基础概念

This directory serves as a comprehensive educational resource for developers and system architects aiming to master the General Key Store (HUKS) within the OpenHarmony ecosystem. It focuses on the critical security infrastructure, specifically the Trusted Execution Environment (TEE), and the technical specifications of cryptographic key materials. By detailing the structural definitions, encoding rules, and serialization requirements for various algorithms like RSA, ECC, and DSA, it ensures a solid foundation for secure application development. This resource is indispensable for those needing to implement robust key management, understand hardware-backed security guarantees, or handle complex cryptographic data formats effectively. It provides the necessary prerequisite knowledge for integrating secure storage and processing capabilities into mobile applications.

## Detailed Description

### 通用密钥库基础概念_2more.md 通用密钥库基础概念_2more.md
This document introduces fundamental concepts necessary for developers using the General Key Store for application development. The primary section covers the Trusted Execution Environment (TEE), defining it as a secure area within a mobile device's main processor. Key information explains that TEE ensures the secure storage and processing of sensitive data by providing a protected environment for "Trusted Applications." It guarantees security through protection, confidentiality, integrity, and access control. This guide serves as prerequisite reading for developers preparing to integrate the General Key Store into their applications.

### 密钥材料格式/
This directory defines the standardized formats for cryptographic key materials used within the HUKS system and OpenHarmony ecosystem. It covers the structural definitions, encoding rules, and serialization requirements for public keys, private keys, and key pairs across various algorithms like RSA, ECC, and DSA. Key topics include X.509 DER standards, byte-level memory layouts, and Cangjie programming language examples. This documentation is essential for software developers, system architects, and security engineers implementing cryptographic functions, key import/export operations, or integrating with hardware security modules.
