# interface_RandomSource

This directory contains API reference documentation for the `RandomSource` interface in the Cangjie programming language. It covers the generation of pseudo-random numbers across various data types, including signed and unsigned integers, floating-point numbers, booleans, and runes. The documentation details methods for generating values within default ranges, specific bounds, and Gaussian distributions. It is suitable for Cangjie developers implementing random number generators, property-based testing frameworks, or applications requiring robust randomization logic. Key topics include `next` functions, `suggest` functions, and interface implementation details.
