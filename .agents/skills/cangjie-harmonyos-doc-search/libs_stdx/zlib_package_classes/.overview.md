## Detailed Description

### 类/

This directory contains the complete API reference documentation for stream-based compression and decompression classes within the Cangjie programming language's zlib package. It is designed to be the definitive guide for developers implementing data transformation, covering four primary classes: `CompressInputStream`, `CompressOutputStream`, `DecompressInputStream`, and `DecompressOutputStream`. The documentation thoroughly details the constructors required to initialize these streams, the methods for reading and writing data, and the strategies for effective buffer management. It also emphasizes the importance of resource cleanup to prevent memory leaks and ensure system stability. Targeted at Cangjie developers, the resources include syntax definitions, usage examples, and error handling details, providing all the necessary tools to implement efficient data compression workflows in applications. This makes it an indispensable resource for any Cangjie project requiring high-performance data handling.
