# cj-request-user-authorization-second

This directory contains a specialized technical tutorial aimed at HarmonyOS developers who are using the Cangjie programming language. It focuses on the specific and often tricky workflow of handling secondary permission requests that occur after a user has initially denied access. The guide explains that standard permission requests are automatically blocked by the system following a rejection, which can hinder app functionality. To solve this, it introduces the `requestPermissionOnSetting` API, which allows the application to directly launch the system permission settings dialog. The content covers essential technical components such as `UIAbilityContext` and the `AbilityAccessCtrl` module. This resource is suitable for developers who already possess knowledge of the AbilityKit framework and need to implement a robust mechanism to guide users to manually grant critical permissions, such as location access, ensuring the application remains functional even after an initial denial.

## Detailed Description

### cj-request-user-authorization-second.md cj-request-user-authorization-second.md

This tutorial is a critical resource for HarmonyOS developers utilizing the Cangjie language, focusing specifically on the workflow required for secondary permission requests. It addresses a common development challenge: when a user denies a permission, the system blocks subsequent standard requests, potentially limiting app functionality. The document explains that the solution lies in redirecting the user to the system settings to manually enable the permission. It introduces the `requestPermissionOnSetting` API, detailing its role in launching the system permission settings dialog. The guide provides a practical, step-by-step code example that demonstrates how to obtain the `UIAbilityContext` and effectively invoke the API. It specifically covers permissions such as `APPROXIMATELY_LOCATION`, making it highly relevant for location-based services. By following this guide, developers with knowledge of the AbilityKit framework can ensure their applications maintain necessary access rights through a guided user intervention process, improving the robustness of their permission handling strategies. Key topics include HarmonyOS, Cangjie, permission request logic, `requestPermissionOnSetting`, `UIAbilityContext`, `AbilityAccessCtrl`, user authorization, and secondary request mechanisms.
