This directory contains API documentation for the `DeviceInfo` class in the Cangjie programming language, specifically designed for querying terminal device information. It covers static, read-only properties related to device identity, build metadata, operating system distribution, and hardware specifications. Key topics include version identifiers, bootloader details, and unique device identifiers. This resource is suitable for software developers and system integrators working with HarmonyOS or Cangjie applications who need to access system attributes like build hashes, OS types, and hardware profiles for debugging or feature adaptation.
