# 接口

This directory serves as a comprehensive API reference for network socket interfaces within the Cangjie programming language. It details the specifications for three primary communication paradigms: server-side listening, stream-based connections, and datagram packet transmission. The documentation covers critical aspects such as socket lifecycle management, address binding, timeout configurations, and exception handling for network errors. By defining the inheritance hierarchies and core methods, these documents provide the foundation for building networked applications. This resource is essential for Cangjie developers and systems programmers looking to implement low-level network protocols or manage socket resources efficiently.

## Detailed Description

### interface_ServerSocket.md
This document provides API reference documentation for the ServerSocket interface in the Cangjie programming language, defining the necessary operations for server-side socket communication. The documentation covers the interface definition, the localAddress property for reading bound addresses, and methods for binding the socket and accepting client connections, including a timeout variant. Key takeaways include that ServerSocket inherits from Resource and ToString, supports blocking connection acceptance with optional timeouts, and handles specific exceptions like SocketException and SocketTimeoutException during binding or connection attempts. Intended for network developers using Cangjie, this reference requires understanding of basic socket programming concepts and resource management.

### interface_StreamingSocket.md
This document provides API reference documentation for the StreamingSocket interface in the Cangjie programming language, defining a duplex socket for stream-based network communication. It details the interface definition, inheritance hierarchy from IOStream and Resource, and specifications for properties including localAddress, remoteAddress, readTimeout, and writeTimeout. Key information includes support for binding and connecting, utilizing buffering for ordered byte transmission where packet boundaries are not guaranteed. It handles blocking operations with configurable timeouts and specific exceptions like SocketException. This reference is intended for Cangjie developers implementing network protocols or managing socket connections.

### interface_DatagramSocket/
This directory provides comprehensive API reference documentation for the `DatagramSocket` interface in the Cangjie programming language. It focuses on packet-based network communication, specifically handling unreliable, unordered data transmission typical of protocols like UDP. The content covers the interface definition, inheritance hierarchy, and detailed specifications for properties such as localAddress, remoteAddress, and timeout settings. Additionally, it documents core functions for data transfer, including syntax, parameters, and exception handling. This resource is suitable for Cangjie developers and software engineers implementing network protocols or applications requiring datagram communication, offering the necessary technical details to manage socket data transfer and errors effectively.
