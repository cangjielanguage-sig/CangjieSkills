# 实现页面间的跳转

This directory provides comprehensive technical guidance on implementing page navigation between ArkTS and mixed ArkTS-Cangjie pages within HarmonyOS applications. It addresses the specific challenge where ArkTS and Cangjie routers are not interoperable, requiring developers to utilize Cangjie-ArkTS interop macros and global HashMaps for function registration. The content covers essential scenarios, including navigating forward using the standard router module and navigating back from a Cangjie component. Furthermore, it details the necessary project directory structures, TypeScript interface declarations, and dependency configuration in oh-package.json5. This resource is specifically designed for developers building cross-language hybrid applications using HarmonyOS ArkUI and Cangjie who need to effectively manage routing logic and lifecycle events across different language components.

## Detailed Description

### 实现页面间的跳转_1.md 实现页面间的跳转_1.md
This tutorial explains how to implement page navigation between ArkTS and mixed ArkTS-Cangjie pages in HarmonyOS. It details two main scenarios: navigating forward using the standard router module and navigating back from a Cangjie component. Key takeaways include the fact that ArkTS and Cangjie routers are not interoperable, requiring developers to register ArkTS routing functions via Cangjie-ArkTS interop macros. The guide provides code examples for registering functions in a global HashMap and generating the necessary .d.ts interface files. This document is intended for developers building cross-language applications using HarmonyOS ArkUI and Cangjie.

### 实现页面间的跳转_2.md 实现页面间的跳转_2.md
This technical tutorial explains how to implement page navigation between ArkTS and Cangjie components in a HarmonyOS application. It covers the project directory structure, TypeScript interface declarations for function registration, and dependency configuration in oh-package.json5. The guide details registering an ArkTS router callback using registerJSFunc in second.ets and triggering it from a Cangjie button click in second.cj using globalJSFunction.get. Key takeaways include the bidirectional communication mechanism and lifecycle management of callbacks. Intended for developers building hybrid HarmonyOS apps, it demonstrates the specific mechanism for cross-language communication to navigate back to a previous page.
