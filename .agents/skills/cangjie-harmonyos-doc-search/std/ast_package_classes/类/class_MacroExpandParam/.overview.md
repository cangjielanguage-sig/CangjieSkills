# class_MacroExpandParam

This directory provides comprehensive API references for the Cangjie programming language, specifically focusing on components related to Abstract Syntax Tree (AST) manipulation and traversal. It includes detailed documentation for the `MacroExpandParam` class, which is essential for handling macro call nodes within function parameters, as well as the `traverse` function, which enables systematic navigation of syntax trees using the Visitor pattern. Key topics covered include macro syntax handling, token conversion, inheritance structures, and custom traversal logic. This documentation is primarily suitable for compiler engineers, language tool developers, and advanced users working on code analysis or transformation within the Cangjie ecosystem who require a deep understanding of AST internals.

## Detailed Description

### class_MacroExpandParam_11more.md
This API reference document details the MacroExpandParam class, which represents macro call nodes within function parameters in the Cangjie programming language. The content covers the class definition, its inheritance from FuncParam, and various mutable properties for handling macro syntax elements like identifiers, parentheses, brackets, and input tokens. Key takeaways include the specific handling of attribute macros versus standard macro calls, the ability to convert nodes back to tokens via toTokens(), and the throwing of ASTException for invalid token assignments. This documentation targets developers or compiler engineers working with Abstract Syntax Trees (AST) who need to programmatically manipulate or analyze macro expansions.

### func_traverseVisitor.md
This document serves as API reference for the traverse function in the Cangjie language, detailing how to traverse Abstract Syntax Tree (AST) nodes. The content covers the function signature, functional description, and parameter details. Key information highlights that the function accepts a Visitor instance to visit the current node and its children. It also explains how to customize traversal behavior, specifically how to terminate the process early by overriding the visit function and calling breakTraverse. The intended audience consists of developers working on AST analysis or transformation tools who need to navigate syntax trees programmatically. Relevant keywords include AST traversal, Visitor pattern, Cangjie language, and syntax tree navigation.
