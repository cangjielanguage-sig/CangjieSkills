# enum_StreamUsage

This directory contains comprehensive API reference documentation for the `StreamUsage` enum within the Cangjie programming language, specifically designed for the multimedia audio core system. It covers the categorization of audio stream usage types, including definitions for scenarios such as Music playback, Voice Communication, Alarms, Gaming, and Movies. The documentation details specific enum values, their functional roles in applications (like VoIP or notifications), and essential operators for type comparison. It also includes utility functions for string representation. This resource is suitable for Cangjie developers who need to implement, identify, and manage various audio scenarios, ensuring compatibility with SystemCapability.Multimedia.Audio.Core and version 19.
