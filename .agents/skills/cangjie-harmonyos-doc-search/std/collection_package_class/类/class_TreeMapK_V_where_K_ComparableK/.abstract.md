This directory contains API reference documentation for the `TreeMap` class in the Cangjie programming language. It covers an ordered key-value storage structure implemented via a balanced binary search tree, requiring keys to be comparable. The documentation details class definitions, initialization methods, interface extensions for equality and string conversion, and essential functions for querying, modifying, and traversing data. It is suitable for Cangjie developers seeking efficient, ordered data structures for applications like databases or caches, providing comprehensive guides on methods such as `add`, `remove`, `get`, and iteration capabilities.
