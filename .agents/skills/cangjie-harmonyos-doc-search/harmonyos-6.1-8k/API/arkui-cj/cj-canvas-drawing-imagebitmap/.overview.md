本目录包含Cangjie语言中ArkUI框架的ImageBitmap类API参考文档。该文档详细介绍了如何创建和管理用于存储Canvas渲染像素数据的对象，涵盖了类定义、构造函数以及尺寸属性等核心内容。此功能目前处于Beta阶段（起始版本22），主要面向使用Cangjie语言进行ArkUI应用开发，特别是涉及Canvas 2D绘图和图像处理场景的开发者。通过本文档，开发者可以了解如何利用ImageBitmap进行高效的图像数据操作。
