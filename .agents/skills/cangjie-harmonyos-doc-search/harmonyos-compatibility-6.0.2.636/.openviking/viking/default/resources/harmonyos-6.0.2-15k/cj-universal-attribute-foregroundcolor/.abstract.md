This directory contains the essential API reference documentation for the `cj-universal-attribute-foregroundcolor` module, specifically designed for the Cangjie ArkUI framework. It provides a detailed technical overview of how to set the foreground color for UI components, explaining the two overloaded `foregroundColor` functions that accept either `ColoringStrategy` or `ResourceColor` parameters. The content covers critical implementation details, including default inheritance from parent components and the specific lack of support for attribute animations. Furthermore, it illustrates the use of smart coloring strategies, such as INVERT. This documentation is highly suitable for Cangjie developers who are actively building HarmonyOS interfaces and need to customize component appearance with precision. By offering practical code examples for basic usage and color inversion, this guide serves as a vital tool for enhancing UI design and functionality.
