This directory contains API reference documentation for the HarmonyOS `ohos.pasteboard` module, specifically designed for the Cangjie programming language. It covers the implementation of system clipboard functionality, including data representation, property configuration, and system pasteboard management. Key components include classes for data records and system operations, enums for sharing options, and functions for data construction. This documentation is suitable for Cangjie developers using the BasicServicesKit to implement copy-paste features, handle various data types like text and images, and manage data sharing scopes within HarmonyOS applications.
