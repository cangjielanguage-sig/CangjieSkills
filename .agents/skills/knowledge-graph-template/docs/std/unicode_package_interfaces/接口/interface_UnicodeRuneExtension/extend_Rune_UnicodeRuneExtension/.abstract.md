This directory provides comprehensive API reference documentation for extending the Cangjie language's `Rune` type to implement the `UnicodeRuneExtension` interface. It focuses on two core aspects of Unicode character handling: classification and case conversion. The documentation details member functions for identifying character properties—such as determining if a character is a letter, number, or whitespace—and functions for transforming character case, including support for locale-specific options. By adhering to specific Unicode definitions, these resources enable precise text manipulation. This content is essential for Cangjie developers involved in building robust text processing engines, internationalization tools, or any application requiring accurate character validation and transformation.
