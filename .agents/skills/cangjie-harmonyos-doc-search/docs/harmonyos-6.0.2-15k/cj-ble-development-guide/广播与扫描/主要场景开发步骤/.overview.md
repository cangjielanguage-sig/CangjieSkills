# 主要场景开发步骤

This directory serves as a comprehensive technical guide for developers implementing core Bluetooth Low Energy (BLE) scenarios using the Cangjie language within the HarmonyOS/OpenHarmony ecosystem. It details the essential workflows required to establish and manage BLE interactions, focusing specifically on the critical lifecycles of advertising and scanning. The content covers a wide range of operations, including configuring custom broadcast parameters, controlling device visibility, managing scan filters, and parsing raw advertising data packets. By providing detailed step-by-step instructions and practical code examples, this documentation is specifically tailored for software engineers and developers aiming to build efficient, resource-aware applications that require robust device discovery, data interpretation, and communication capabilities.

## Detailed Description

The following sections provide in-depth technical details and code examples for each specific scenario covered in this directory.

### 开启关闭广播.md 开启关闭广播
This tutorial provides a step-by-step guide and code example for managing the Bluetooth Low Energy (BLE) advertising lifecycle using the Cangjie language. It covers prerequisites like importing modules and enabling Bluetooth, followed by instructions on starting advertising with custom parameters, temporarily disabling and re-enabling broadcasts, and permanently stopping advertising to release resources. Key information includes constructing AdvertiseSetting and AdvertiseData objects, managing the advertising handle identifier, and handling state change callbacks. Intended for developers working on HarmonyOS/OpenHarmony systems, this document explains how to control BLE visibility and manage advertising resources effectively.

### 开启关闭扫描/
This directory focuses on implementing and managing Bluetooth Low Energy (BLE) scanning functionality using the Cangjie language within the HarmonyOS development framework. It covers the complete lifecycle of device discovery, including enabling Bluetooth, configuring scan filters and options, and managing the start and stop processes. Additionally, it provides technical references for parsing raw BLE advertising data packets to extract specific information like service UUIDs, local names, and manufacturer data. This content is suitable for HarmonyOS developers and software engineers looking to integrate robust device discovery and data interpretation capabilities into their applications.
