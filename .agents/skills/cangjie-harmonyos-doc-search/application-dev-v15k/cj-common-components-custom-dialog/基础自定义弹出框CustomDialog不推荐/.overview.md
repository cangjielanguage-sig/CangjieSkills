# 基础自定义弹出框CustomDialog不推荐

This directory provides technical tutorials focused on implementing custom pop-up dialogs using the ArkUI framework and the Cangjie language within the HarmonyOS ecosystem. It explicitly addresses a specific implementation pattern using `@CustomDialog` and `CustomDialogController` while noting that this approach is currently not recommended for new development. The content covers essential aspects such as dialog creation, user interaction handling, modal versus non-modal behaviors, and complex styling including borders and shadows. Furthermore, it delves into advanced architectural patterns like nesting dialogs and managing component lifecycles to prevent errors. This resource is suitable for Cangjie developers and UI engineers who need to maintain legacy code or understand specific overlay mechanics, with a strong recommendation to utilize the Navigation component for page-level scenarios instead.
