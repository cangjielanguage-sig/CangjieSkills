# 组件标识

This directory provides comprehensive documentation for the ArkUI framework's component identification module within the Cangjie language ecosystem. It details the mechanisms for assigning unique identifiers to UI components, facilitating precise targeting and manipulation. The content covers core APIs like `id` and `key`, practical code examples for property retrieval, and advanced extension capabilities designed for automated testing scenarios. These tools allow for component inspection, event simulation, and tree traversal. This resource is specifically tailored for ArkUI developers and QA engineers aiming to implement robust UI testing and component management strategies.

## Detailed Description

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the correct usage of the `getInspectorByKey` interface to retrieve properties of a Select component. The code illustrates two scenarios: calling the interface directly in the main thread and calling it from a child thread using the `launch` keyword to switch execution context. Key information highlights that `getInspectorByKey` must be executed on the main thread to ensure complete attribute information is retrieved. This tutorial is designed for ArkUI developers using the Cangjie language who need to programmatically inspect UI component properties across different threads.

### 组件标识_4more.md 组件标识_4more.md
This document serves as API reference documentation for the ArkUI framework's component identification module, detailing how to assign unique identifiers to components within an application. It covers the module import statement and provides detailed specifications for two primary functions: `id` and `key`. Both functions accept a nullable string to ensure uniqueness, returning the component instance itself. While `id` is the standard identifier for general use, `key` is intended specifically for application testing. A critical note is that if both are set, the last assigned value overrides the previous one. This guide targets developers using the Cangjie language building ArkUI applications who need to manipulate or test specific components via unique IDs.

### 基于组件标识的拓展能力/
This directory provides a comprehensive overview of extension capabilities based on component identifiers within the Cangjie ArkUI framework. It focuses on API references that enable UI component inspection, event simulation, and the retrieval of component trees. These functionalities are strictly designed for application testing, offering developers the tools to programmatically inspect attributes and simulate interactions like touch, keyboard, and mouse events. Key topics include component attribute retrieval, JSON parsing, and automated event triggering. This documentation is highly suitable for developers and QA engineers who are building automated test scripts and performing UI validation for ArkUI applications.
