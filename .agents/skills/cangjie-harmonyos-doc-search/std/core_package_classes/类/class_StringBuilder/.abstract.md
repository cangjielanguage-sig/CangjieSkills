This directory contains API reference documentation for the `StringBuilder` class in the Cangjie programming language. It focuses on efficient string construction, offering dynamic capacity expansion and UTF-8 support to optimize performance over standard strings. The documentation covers class definitions, constructors, properties, and a wide range of methods for appending data types, managing memory, and converting results. It is suitable for Cangjie developers seeking high-performance string manipulation techniques, memory management strategies, and detailed syntax for building complex strings dynamically.
