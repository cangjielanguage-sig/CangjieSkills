This directory contains API reference documentation for the `ohos.bluetooth.socket` module, specifically designed for the Cangjie programming language within the HarmonyOS ecosystem. It covers the Bluetooth Serial Port Profile (SPP), enabling developers to implement socket-based communication between devices. Key functionalities include server listening, client connection, data transmission, and socket lifecycle management. The documentation details essential classes like `SppOptions`, enums like `SppType`, and various operational functions. It is suitable for software developers and engineers building Bluetooth connectivity features who need to handle SPP connections, manage socket events, and ensure robust data exchange in their applications.
