This directory provides comprehensive documentation for the `RichEditorTextStyleResult` class, a crucial component within the Cangjie ArkUI framework designed for managing rich text styles. It details the encapsulation of text style information returned by the backend, covering essential font attributes such as color, size, weight, family, and style, alongside text decoration options. Furthermore, it addresses advanced styling capabilities introduced in API version 19, including text shadows, line height, and letter spacing, which are designated as read-only. This documentation is intended for ArkUI developers working with the Cangjie language who require a robust structure to handle and apply complex text formatting within their applications, leveraging the SystemCapability.ArkUI.ArkUI.Full capability to create dynamic user interfaces.
