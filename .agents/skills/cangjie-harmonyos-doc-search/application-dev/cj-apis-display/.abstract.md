This directory serves as a specialized technical resource for developers working with the Cangjie programming language within the HarmonyOS ecosystem. It contains comprehensive API reference documentation for the `ohos.display` module, which is integral to the WindowManager framework. The primary focus is on screen properties and display configurations, providing the necessary tools to query display attributes and manage complex screen behaviors. Key areas covered include the management of foldable device states—such as monitoring fold status, identifying crease regions, and switching display modes—as well as handling screen orientations and listening for display-related events. This documentation is specifically designed for developers tasked with building adaptive user interfaces and robust window management systems that must accommodate a wide variety of hardware configurations, including advanced form factors like waterfall screens and foldable devices.
