# bm工具

This directory contains comprehensive documentation for the Bundle Manager (bm) tool used within the Cangjie and HarmonyOS development environments. It covers command-line operations for the full application lifecycle, including installation, uninstallation, querying, debugging, and patching. Key topics include handling HAR and HAP packages, managing shared libraries and overlays, querying application information, and resolving installation or signature conflicts. This resource is suitable for developers, system administrators, and technical support personnel who need to manage application deployment and troubleshoot issues via the shell.

## Detailed Description

### bm工具_6more.md bm工具_6more.md
This document serves as a technical reference guide for the Bundle Manager (bm) tool, which facilitates application debugging tasks like installation, uninstallation, and querying within the Cangjie development environment. It outlines environment prerequisites, specifically the need for the hdc tool, and provides a comprehensive list of supported commands. The content details the syntax, parameters, and usage examples for core operations such as install and uninstall. Key takeaways include the current support for HAR and HAP packages but the exclusion of HSP packages for Cangjie. This guide is intended for developers managing application lifecycles via the command line.

### 共享库查询命令dump-shared_6more.md 共享库查询命令dump-shared_6more.md
This document serves as a command-line reference guide for the Bundle Manager (bm) tool, detailing specific operations for querying shared libraries, managing dependencies, and handling overlays. It covers six distinct commands: dump-shared, dump-dependencies, compile, copy-ap, dump-overlay, and dump-target-overlay. Key information includes the syntax, parameter definitions (such as bundle name and module name), and practical usage examples for tasks like listing installed libraries, performing AOT compilation, and inspecting overlay module information. Intended for developers or system administrators, this guide facilitates debugging and management of application resources and system configurations.

### 常见问题.md 常见问题.md
This document serves as a troubleshooting guide addressing specific errors encountered when reinstalling pre-installed system applications. It details a specific scenario involving "downgrade installation" or "signature information inconsistency" errors, structured into problem description, possible causes, and handling steps. The key takeaway is that enhanced security controls cause the system to restore the pre-installed image version before installing a new app with the same bundleName, leading to these conflicts. This guide is intended for system developers or technical support personnel resolving application installation issues.

### 查询应用信息命令dump_6more.md 查询应用信息命令dump_6more.md
This document serves as a command-line reference guide for the bm tool, used to manage application bundles and system information. It details six primary commands: dump for querying app info, clean for clearing data, enable and disable for managing app states, get for retrieving device UDID, and quickfix for applying patch updates. Each section provides syntax, parameter descriptions, and usage examples for operations like listing installed bundles, managing caches, and installing HQF patch files. This guide targets developers and system administrators needing to debug or maintain HarmonyOS applications via the shell.

### bm工具错误码/
This directory contains a comprehensive collection of troubleshooting guides for the HarmonyOS/OpenHarmony Bundle Manager (bm) tool. It covers a wide range of error codes related to application installation, uninstallation, and configuration failures. Key topics include signature verification issues, permission mismatches, dependency conflicts, HAP package parsing errors, and device compatibility problems. These documents provide root cause analysis and step-by-step resolution procedures, such as re-signing packages, modifying JSON5 configuration files, or using specific shell commands. This resource is essential for developers and system engineers diagnosing deployment issues in the HarmonyOS ecosystem.
