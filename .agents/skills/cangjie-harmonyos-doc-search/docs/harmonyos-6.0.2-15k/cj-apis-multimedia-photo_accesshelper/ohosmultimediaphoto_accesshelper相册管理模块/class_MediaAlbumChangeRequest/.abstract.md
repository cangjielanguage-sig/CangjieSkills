This directory provides comprehensive API reference documentation for the `MediaAlbumChangeRequest` class within the Cangjie programming language ecosystem. It is designed to assist developers in handling photo album modifications using the PhotoAccessHelper and MediaLibraryKit frameworks. The documentation covers essential operations such as initializing change requests, adding and removing photo assets, and renaming albums. It includes detailed specifications on system capabilities, version requirements (starting from API version 19), and exception handling for common errors. This resource is ideal for Cangjie developers working on file management applications who require programmatic control over media library contents.
