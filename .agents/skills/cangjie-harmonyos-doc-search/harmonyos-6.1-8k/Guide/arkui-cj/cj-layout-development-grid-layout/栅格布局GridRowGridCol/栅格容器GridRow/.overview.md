## 详细描述

### 布局的总列数.md 布局的总列数
本文档旨在说明如何在 ArkUI 的 GridRow 组件中通过 columns 属性设置栅格布局的总列数。文档涵盖了三种主要配置方式：默认 12 列、自定义固定列数以及使用 GridRowOptions 针对不同设备断点（xs, sm, md 等）进行差异化设置。重点介绍了 GridRowOptions 的断点回退机制，即未设置的尺寸会继承默认值或前一个尺寸的配置。文中包含详细的 Cangjie 代码示例，适合具备 ArkUI 基础的开发者参考，用于实现响应式栅格布局设计。

### 排列方向_2more_427a2456.md 排列方向
本文档旨在说明如何在栅格布局中配置 GridRow 容器的子组件排列方向及间距属性。主要涵盖两个部分：一是通过 direction 属性设置子组件的排列方向（从左往右或从右往左）；二是通过 gutter 属性设置子组件在水平和垂直方向的间距。关键信息包括：direction 属性支持 Row（默认）和 RowReverse 两种模式；gutter 属性既支持 Length 类型统一设置间距，也支持 GutterOption 类型分别定义水平和垂直间距。文档提供了 Cangjie 语言代码示例及效果展示。

### 栅格系统断点.md 栅格系统断点
本文档旨在阐述 ArkUI 栅格系统的断点规则，指导开发者基于设备宽度实现响应式布局。主要涵盖默认断点定义、GridRow 组件中的断点自定义方法，以及支持扩展至六种尺寸（xs 至 xxl）的配置方式。关键信息包括断点数组的设置逻辑、窗口尺寸参考机制，以及通过 Cangjie 代码示例演示如何动态调整栅格列数。该文档适用于需要构建多设备适配界面的 ArkUI 应用开发者。
