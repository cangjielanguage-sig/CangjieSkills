This directory provides comprehensive API reference documentation for the core classes within the Cangjie fuzzing framework. It covers the essential components required to build, configure, and execute automated fuzzing tests, including the `FuzzerBuilder` for instance construction, the `Fuzzer` class for runtime management, and specialized data providers like `FuzzDataProvider` and `DebugDataProvider` for converting raw byte streams into structured data. This resource is suitable for developers, QA engineers, and security professionals who need precise control over data generation, target function definition, and fuzzing behavior in the Cangjie programming language.
