# 扩展的导入导出

本目录详细介绍了仓颉（Cangjie）编程语言中扩展功能的导入导出机制及可见性规则。内容涵盖了直接扩展和接口扩展在同包与跨包场景下的导出逻辑，重点分析了泛型约束对访问修饰符的影响，以及接口扩展成员的可见性限制。文档还阐述了无需显式导入扩展定义即可使用扩展的规则，并通过代码示例展示了跨包调用时的具体行为。核心关键词包括：扩展、导入导出、可见性、泛型约束、接口扩展、访问控制。这些资料适合需要深入理解模块封装、代码组织及访问权限管理的开发者阅读。

### 扩展的导入导出_1.md 扩展的导入导出_1.md

本文档旨在说明Cangjie语言中扩展的导入导出机制及可见性规则。文档主要涵盖直接扩展和接口扩展两种场景，分别讨论了同包与跨包情况下的导出逻辑。核心要点包括：直接扩展的导出依赖于被扩展类型及泛型约束的访问修饰符；接口扩展在同包内不受接口可见性限制，跨包时则受限于接口及约束的最小访问级别。这是一份技术参考文档，适合需要深入理解模块封装和访问控制机制的开发者阅读。关键词：扩展、导入导出、可见性、泛型约束、接口扩展。

### 扩展的导入导出_2.md 扩展的导入导出_2.md

本文档详细说明了仓颉编程语言中扩展功能的导入与导出规则，重点解析了接口扩展的成员可见性及访问控制机制。

文档主要涵盖两个核心主题：一是接口扩展导出的限制，即仅接口中声明的成员会被导出，扩展中新增的成员对外不可见；二是扩展的导入规则，指出无需显式导入扩展定义，只需导入被扩展类型、接口及泛型约束即可使用。

关键信息包括：通过代码示例展示了跨包调用时，未导入接口或未在接口中定义的成员会导致编译错误，强调了依赖类型和接口导入来激活扩展功能的特性。
