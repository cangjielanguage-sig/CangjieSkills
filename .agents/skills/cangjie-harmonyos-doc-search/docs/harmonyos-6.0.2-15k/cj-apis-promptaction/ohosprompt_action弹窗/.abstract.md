This directory contains comprehensive API documentation and code examples for the `ohos.prompt_action` module in the HarmonyOS ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of various user interface popups, including action menus, dialogs, toasts, and custom modal windows. The resources detail configuration classes, enumeration types, and practical usage scenarios for building interactive UI components. This documentation is suitable for HarmonyOS developers working exclusively in Cangjie who need to implement robust user notifications, modal interactions, and menu selection logic with precise control over styling and behavior.
