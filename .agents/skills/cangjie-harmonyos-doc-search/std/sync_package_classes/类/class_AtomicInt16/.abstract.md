This directory contains API reference documentation for the `AtomicInt16` class in the Cangjie programming language, focusing on thread-safe operations for 16-bit integers. It covers essential atomic mechanisms such as compare-and-swap, arithmetic operations (fetchAdd, fetchSub), bitwise manipulations (fetchAnd, fetchOr, fetchXor), and swap/load/store functions. The documentation highlights the deprecation of variants requiring explicit `MemoryOrder` parameters, guiding developers toward default memory ordering implementations. This resource is suitable for developers and systems engineers working on concurrent applications, low-level synchronization, and lock-free data structures requiring precise atomic state management.
