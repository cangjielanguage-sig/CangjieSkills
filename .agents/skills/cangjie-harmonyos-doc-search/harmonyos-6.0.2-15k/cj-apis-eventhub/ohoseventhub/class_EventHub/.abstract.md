This directory contains API reference documentation for the `EventHub` class within the Cangjie programming language and the AbilityKit framework. It focuses on event-driven architecture, providing developers with tools to manage, retrieve, and emit callback events. The documentation covers methods for obtaining event centers and handling events with varying numbers of generic parameters (from zero to five). Key topics include type-safe event handling, generic programming, and the `EventCallBack` interface. This resource is suitable for software developers building HarmonyOS applications who need to implement robust event communication mechanisms using the AbilityRuntime Core system.
