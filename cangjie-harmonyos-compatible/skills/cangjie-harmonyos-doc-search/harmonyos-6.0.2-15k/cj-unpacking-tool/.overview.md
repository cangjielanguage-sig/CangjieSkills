# cj-unpacking-tool

The `cj-unpacking-tool` directory serves as a repository for the HarmonyOS Unpacking Tool, a specialized utility designed for decompressing and analyzing application packages. It focuses on handling various HarmonyOS package formats, including HAP, HSP, and App files. The content covers essential technical aspects such as command-line usage, Java API references for parsing, and detailed data structure definitions for configuration files like `pack.info`. Key topics include parsing modes, metadata extraction, and schema definitions for permissions and distribution settings. This resource is primarily suitable for HarmonyOS developers, application market builders, and tool engineers who need to inspect package structures or integrate parsing capabilities into their workflows.
