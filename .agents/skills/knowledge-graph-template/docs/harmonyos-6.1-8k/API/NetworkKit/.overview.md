# NetworkKit

NetworkKit is a comprehensive documentation repository for HarmonyOS network services, specifically tailored for the Cangjie (仓颉) programming language. It provides essential resources for managing network connections and handling data requests. The content covers API references for `ohos.net.connection` and `ohos.net.http`, alongside detailed error code documentation to assist in debugging and system maintenance. This directory is primarily designed for application developers and system administrators working within the HarmonyOS ecosystem who need to implement robust network functionality and resolve network-related issues efficiently.

### [1] README_zh
This directory contains the index documentation for the Network Kit (Network Service) in the Cangjie language. It aims to provide developers with a comprehensive navigation entry for network connection management, data request APIs, and error codes. The core content covers two main sections: Cangjie APIs and error codes, specifically including `ohos.net.connection` (network connection management) and `ohos.net.http` (data requests) along with their corresponding error code descriptions. The document explicitly marks all features as Beta and organizes them efficiently via links to help developers quickly locate interface definitions and exception handling information. It is primarily intended for developers using the Cangjie language for application development, especially those needing to implement network functions and debug network errors.

### [2] cj-apis-net-connection
This directory serves as a specialized repository for API reference documentation concerning the `ohos.net.connection` module within the HarmonyOS operating system, specifically written for the Cangjie (仓颉) programming language. It is dedicated to the interfaces and functionalities required for managing network connections, providing developers with the necessary technical details to implement connectivity features in their applications.

### [3] cj-apis-net-http
This directory contains the complete API reference documentation for the `ohos.net.http` module, specifically designed for the Cangjie programming language within the HarmonyOS development ecosystem. It serves as a critical resource for understanding and implementing data requests, offering detailed guidance on handling HTTP protocols and network communication tasks.

### [4] cj-errorcode-net-connection
This directory is specifically used to store error code reference documentation for the network connection management module, aiming to provide systematic debugging support for developers. The content comprehensively covers various exceptions that may occur during the module's operation, including but not limited to illegal parameter input, connection service failure, system internal errors, duplicate or non-existent callback objects, and exceeding request limits. For each error code, the document provides a detailed description of the error information, analysis of potential root causes, and specific troubleshooting and handling steps (e.g., guiding developers to check parameter ranges, confirm service status, or investigate memory usage). This document is mainly suitable for application developers, helping them quickly locate and effectively resolve network connection-related issues during development, testing, and maintenance.
