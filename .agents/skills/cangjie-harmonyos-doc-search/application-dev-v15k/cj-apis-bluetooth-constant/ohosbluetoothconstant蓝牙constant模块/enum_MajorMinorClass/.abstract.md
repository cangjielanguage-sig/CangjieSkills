This directory contains API references for the `MajorMinorClass` enum in the Cangjie programming language, specifically designed for Bluetooth device classification. It defines constants for identifying various hardware categories, including Audio/Video, Computer, Health, Peripheral, Toy, and Wearable devices. All entries utilize the `SystemCapability.Communication.Bluetooth.Core` capability and are available from API version 19 onwards. This documentation is essential for developers implementing Bluetooth connectivity who need to programmatically identify, categorize, and manage connected devices within their applications.
