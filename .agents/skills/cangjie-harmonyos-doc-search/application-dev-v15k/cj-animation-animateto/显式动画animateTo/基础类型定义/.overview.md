## Detailed Description

### class_ExpectedFrameRateRange.md class_ExpectedFrameRateRange.md

This API reference document defines the Cangjie class ExpectedFrameRateRange, which is used to specify desired frame rate configurations within the ArkUI framework. The documentation details the class constructor and three public properties: min, max, and expected, all of type Int32. Key information includes specific constraints for frame rate values measured in FPS, ensuring the minimum is greater than zero, the maximum is at least the minimum, and the optimal rate falls between them. All members are readable and writable. This guide targets Cangjie developers working on ArkUI applications who require precise control over display refresh rates starting from API version 12.
