This directory provides a technical overview and implementation guide for anonymous key attestation within the Universal Keystore Kit (HUKS) framework. It is designed to assist developers in integrating high-level security features that allow key usage verification without compromising user privacy. The content encompasses the full development process, including the definition of key aliases, initialization of parameter sets, generation of asymmetric keys, and the invocation of specific attestation APIs. Key topics include the mandatory HUKS_TAG_ATTESTATION_CHALLENGE property, network connectivity prerequisites, and the configuration of RSA 2048 parameters. This documentation is specifically curated for HarmonyOS developers and software engineers proficient in Cangjie who are tasked with building secure applications requiring cryptographic proof of key integrity and identity protection.
