# cj-mirroring-display

This directory serves as a specialized technical resource for ArkUI developers focusing on internationalization (i18n) and localization (l10n). It specifically addresses the implementation of mirroring capabilities, a Beta feature designed to dynamically adapt user interfaces for Right-to-Left (RTL) reading habits. The content covers the automatic horizontal flipping of layouts, the distinction between Left-to-Right (LTR) and RTL environments, and the necessary adjustments for component positioning. It is suitable for developers aiming to create seamless, bidirectional user experiences for global markets, ensuring that applications function correctly across diverse linguistic environments while navigating the specific constraints of a Beta feature. Key topics include layout flipping, direction properties, and component adaptation strategies. By following this guide, developers can ensure their applications are culturally and linguistically appropriate for users worldwide, avoiding common pitfalls associated with manual layout adjustments and ensuring a consistent user experience across different language settings.

## Detailed Description

The following section details the contents of the subdirectory, providing a deep dive into the technical aspects of ArkUI mirroring.

### 使用镜像能力/

This directory provides comprehensive documentation on ArkUI's mirroring capabilities, a critical feature currently in Beta for adapting user interfaces to Right-to-Left (RTL) reading habits. It serves as a technical guide for developers implementing internationalization (i18n) and localization (l10n) by detailing how layouts automatically flip horizontally to accommodate different languages. The content covers the core concepts of LTR and RTL, the specific conditions required to trigger mirroring (such as setting the direction property), and the constraints developers must navigate.

Furthermore, it highlights which components are pre-adapted and which require manual intervention, such as replacing absolute positioning terms with relative ones. This resource is specifically tailored for ArkUI developers aiming to create seamless, bidirectional user experiences for global markets, ensuring that applications function correctly across diverse linguistic environments.
