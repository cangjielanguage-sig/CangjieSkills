# cj-account-overview

This directory provides a comprehensive conceptual overview of the account management system, specifically focusing on the architecture that enables multiple users and distinct account types to coexist and remain isolated on a single device. It details the definitions and interrelationships of four primary account categories: System, Domain, Distributed, and Application. The content covers critical aspects such as data isolation mechanisms, user identity management, and the lifecycle dependencies between different account types. For instance, it explains how System Accounts act as the central identity hub and how their deletion impacts associated accounts. This documentation is primarily intended for system developers or architects who need a deep understanding of the account module's structural framework and data isolation strategies to build robust applications.

### cj-account-overview.md cj-account-overview.md

This document provides a conceptual overview of the account management system, detailing how multiple users and account types are supported and isolated on a single device. It covers the introduction to multi-user support, definitions of four account categories (System, Domain, Distributed, and Application), and the relationships between them. Key takeaways include that System Accounts serve as the central identity hub. Domain accounts have a 1:1 relationship with System accounts, while Distributed and Application accounts have 1:many and many:many relationships respectively, often with independent lifecycles. Deleting a System Account removes associated accounts. This reference guide is intended for system developers or architects understanding the account module's structure and data isolation mechanisms. Keywords: Account management, System account, Domain account, Distributed account, Data isolation, User identity.
