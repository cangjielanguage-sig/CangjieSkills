This directory contains comprehensive API reference documentation for the `StoreConfig` class within the Cangjie programming language. It focuses on managing configuration settings for relational and vector databases under the SystemCapability.DistributedDataManager framework. Key topics include database initialization, security levels, encryption, storage path management, and advanced features like semantic indexing and full-text search. The documentation is essential for developers seeking to implement robust data storage solutions, offering detailed guidance on properties such as `allowRebuild`, `autoCleanDirtyData`, and `vector` capabilities to optimize application performance and data integrity.
