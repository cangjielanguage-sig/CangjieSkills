This directory contains comprehensive API reference documentation for the TimeZone class within the Cangjie LocalizationKit, specifically designed to enhance internationalization (I18n) system capabilities. It covers a wide range of functionalities, including retrieving system-supported timezone and city identifiers, obtaining localized city display names based on specific locales, and creating TimeZone instances from city IDs. Additionally, it addresses advanced features such as timezone retrieval via geographic coordinates and the management of UTC offsets. The documentation includes detailed code examples, parameter definitions, and error code specifications. It is suitable for Cangjie developers implementing global features who require precise timezone data handling, localization support, and robust timezone management starting from system version 19.
