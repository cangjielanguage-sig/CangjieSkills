This directory contains comprehensive API reference documentation for the `SM2CryptoUtil` class within the Cangjie programming language ecosystem. It focuses on SM2 cryptographic operations, specifically the generation and parsing of ASN.1 formatted ciphertext. Key topics include the `genCipherTextBySpec` method, `getCipherTextSpec` function, parameter definitions, return values, system capabilities, and exception handling with specific error codes. The documentation highlights the default "C1C3C2" mode and provides practical code examples for implementation. This resource is suitable for developers utilizing the CryptoFramework or CryptoArchitectureKit who require robust implementation of SM2 encryption, decryption, and data parsing in their Cangjie applications.
