# cj-crypto-generate-message-digest-overview

This directory provides a comprehensive technical reference for message digest algorithms within the CJ crypto API. It covers the fundamental principles of one-way hash operations that generate fixed-length outputs from variable inputs, a critical component for ensuring data integrity and security in software applications. The documentation details supported algorithms such as SHA1, SHA224, SHA256, SHA384, SHA512, MD5, and SM3, including their specific byte lengths and API version requirements. By providing a clear specification table, this resource helps developers understand the constraints and capabilities of each hashing method. This guide is essential for developers implementing cryptographic hashing, offering the necessary parameters to select the correct algorithm type and size for secure data handling, verification processes, and compliance with specific security standards. It serves as a foundational document for anyone looking to integrate secure hashing mechanisms into their systems using the CJ framework.
