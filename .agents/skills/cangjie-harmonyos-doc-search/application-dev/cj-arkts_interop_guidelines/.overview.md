# cj-arkts_interop_guidelines

This directory serves as a comprehensive repository for the interoperability guidelines between the Cangjie (CJ) language and ArkTS, specifically tailored for the HarmonyOS development environment. It addresses the complexities of bridging native code with script-based environments, providing rigorous standards for threading models, memory management, exception handling, and object lifecycle management. The content highlights critical operational constraints such as main thread restrictions, proper JSRuntime utilization, and cross-engine context safety. Furthermore, it offers strategies for preventing common issues like memory leaks. This resource is indispensable for HarmonyOS developers and system engineers who require a deep understanding of native-script integration to build robust, high-performance applications.

## Detailed Description

### 仓颉-ArkTS_互操作开发规范/
This directory is the primary source of truth for development standards and technical guidelines regarding the interoperability between the Cangjie language and ArkTS within the HarmonyOS ecosystem. It is designed to assist developers in navigating the complexities of integrating native Cangjie code with ArkTS scripts, ensuring that the interaction between the two languages is both seamless and efficient.

The documentation covers a wide range of critical technical aspects necessary for stable system operation. Key areas of focus include:
*   **Threading Models:** Detailed explanations of main thread restrictions and how to handle concurrency safely without blocking the UI.
*   **Memory Management:** Best practices for allocation, deallocation, and preventing memory leaks that can degrade application performance over time.
*   **Exception Handling:** Protocols for managing errors across the native-script boundary to prevent crashes.
*   **Object Lifecycle Management:** Guidelines for ensuring objects are created and destroyed correctly across different engines.

Additionally, the directory delves into specific implementation details such as JSRuntime usage and cross-engine context safety. These documents are essential reading for HarmonyOS developers and system engineers working on native-script integration, providing the knowledge required to ensure application stability and optimal performance.
