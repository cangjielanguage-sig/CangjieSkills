This directory provides API reference documentation for the `ContextMenuOptions` class within the Cangjie ArkUI framework. It covers the configuration of context menu parameters, including positioning, visual styling, lifecycle callbacks, and animation transitions. Key features include background blur settings, arrow visibility, preview content, and event handling for menu appearance and disappearance. Designed for ArkUI developers and UI engineers, this documentation assists in customizing the behavior and aesthetics of context menus in application interfaces, with features available starting from API version 19.
