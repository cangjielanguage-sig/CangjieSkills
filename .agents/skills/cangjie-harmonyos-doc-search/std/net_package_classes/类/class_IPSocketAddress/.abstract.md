This directory contains comprehensive API reference documentation for the `IPSocketAddress` class within the Cangjie standard library's net package. It focuses on the representation and manipulation of immutable IP protocol socket addresses, which combine IP addresses with port numbers. The documentation covers class definitions, properties, constructor overloads, and various utility methods for parsing, inspection, and conversion. Key topics include handling IPv4 and IPv6 formats, big-endian byte array requirements, and exception-based error handling. This resource is essential for Cangjie developers and software engineers involved in network programming, socket binding, and connection management who require precise control over network address validation and manipulation.
