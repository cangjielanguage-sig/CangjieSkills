This directory provides a specialized technical guide for developers focused on capturing local voice call audio using the AudioCapturer module within the HarmonyOS environment, specifically utilizing the Cangjie programming language. It comprehensively covers the setup process, including obtaining the UIAbility context and configuring audio streams with the critical `SOURCE_TYPE_VOICE_COMMUNICATION` parameter. The documentation highlights essential requirements such as microphone permissions and the implementation of callbacks for processing audio data. Additionally, it addresses the complexities of the AudioCapturer lifecycle, offering code examples for start, stop, and release operations with strict state validation. This resource is designed for application developers with existing knowledge of Cangjie syntax and HarmonyOS basics who need to implement reliable, state-aware audio recording logic in their applications.
