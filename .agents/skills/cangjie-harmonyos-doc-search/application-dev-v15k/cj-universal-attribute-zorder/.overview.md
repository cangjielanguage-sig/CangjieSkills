### cj-universal-attribute-zorder.md cj-universal-attribute-zorder.md
This document serves as API reference documentation for the zIndex attribute in the Cangjie programming language, specifically for the ArkUI framework, explaining how to control component stacking order. It covers the function signature `zIndex(value: Int32)`, parameter details regarding layer hierarchy, and two code examples demonstrating static stacking and dynamic state-driven modification. Key takeaways include that higher zIndex values place components on top of lower ones, with a default value of 0. The examples illustrate usage within a Stack container and clarify stable sorting behavior when indices are equal. The target audience is developers using the Cangjie language to build HarmonyOS applications, requiring knowledge of ArkUI components and state management.
