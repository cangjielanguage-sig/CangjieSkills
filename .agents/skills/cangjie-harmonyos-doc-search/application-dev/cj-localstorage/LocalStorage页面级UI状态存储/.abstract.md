This directory covers the LocalStorage mechanism for page-level UI state management within the ArkUI and Cangjie frameworks. It details how to use decorators like `@LocalStorageProp` and `@LocalStorageLink` to synchronize data between components and storage, supporting both one-way and two-way data binding. The content includes API definitions, usage constraints, lifecycle management, and practical scenarios for sharing state across pages and components. It is suitable for HarmonyOS developers looking to implement efficient, persistent, or shared application states.
