# 示例代码

This directory contains a collection of practical code examples designed for ArkUI development using the Cangjie language, with a specific focus on the `RelativeContainer` component. It covers a comprehensive range of layout techniques, from basic relative positioning using containers and sibling components as anchors to more advanced configurations. Key topics include setting margins for child components, utilizing the Bias parameter for vertical positioning offsets, implementing auxiliary guidelines, and managing complex responsive layouts using barrier constraints. These examples are tailored for developers who are already familiar with the basics of ArkUI and Cangjie and wish to deepen their understanding of relative positioning, layout constraints, and precise UI structuring.

## Detailed Description

### 示例1以容器和容器内组件作为锚点进行布局.md
This document provides a practical code example demonstrating how to implement relative layouts using containers and internal components as anchors in ArkUI with Cangjie. It covers the usage of the alignRules interface within a RelativeContainer, specifically defining alignment parameters like VerticalAlignParam and HorizontalAlignParam. The example positions five Row components by anchoring them to the parent container (__container__) and sibling components (e.g., row1, row2) to create a complex grid structure. This tutorial targets developers using the Cangjie language for ArkUI development who need to understand relative positioning and layout constraints. Keywords: ArkUI, Cangjie, RelativeContainer, alignRules, layout, positioning.

### 示例2子组件设置外边距_3more.md
This document provides practical code examples for advanced layout configurations within the ArkUI RelativeContainer component using the Cangjie language. It covers three specific scenarios: setting margins for child components, utilizing the Bias parameter for vertical positioning offsets, and implementing auxiliary guidelines for anchoring. The examples demonstrate how to manipulate alignment rules, apply spacing via margins, and create custom reference lines to achieve precise UI layouts. Intended for developers familiar with ArkUI and Cangjie seeking to master relative layout positioning and styling.

### 示例5设置屏障.md
This tutorial demonstrates how to implement barrier constraints within a RelativeContainer using the Cangjie language for ArkUI development. The document focuses on the barrier interface, BarrierStyle configuration, and aligning child components relative to dynamic barriers. Key takeaways include the creation of two barriers (barrier1 and barrier2) based on the positions of row1 and row2, which then serve as anchors for positioning row3 and row4. This ensures responsive layout behavior where components adjust based on the collective dimensions of referenced elements. Intended for developers familiar with Cangjie and ArkUI, this example serves as a practical guide for managing complex relative layouts.
