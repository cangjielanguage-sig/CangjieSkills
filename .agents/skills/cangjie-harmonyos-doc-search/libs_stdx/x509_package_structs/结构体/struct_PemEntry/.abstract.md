This directory provides comprehensive API reference documentation for the `PemEntry` struct within the Cangjie language's X.509 package. It is dedicated to the handling of PEM-encoded data, a standard format used for storing cryptographic keys and certificates. The documentation covers the struct's core definition, initialization methods, and various utility functions for data manipulation. Key topics include parsing PEM text, managing headers, encoding binary data to strings, and identifying specific cryptographic standards such as X.509, PKCS#8, and CRLs. This resource is essential for developers and security engineers implementing cryptographic parsing, generation, or validation routines who require a deep understanding of RFC 7468 and X.509 standards.
