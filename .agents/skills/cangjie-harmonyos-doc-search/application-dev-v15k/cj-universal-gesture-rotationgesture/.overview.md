# cj-universal-gesture-rotationgesture

This directory provides comprehensive API reference documentation for the RotationGesture component in the Cangjie language, specifically tailored for ArkUI developers. It focuses on the implementation and handling of multi-touch rotation interactions, offering detailed insights into component initialization. Key topics include configuring parameters for finger count and angle sensitivity, as well as defining event callbacks for various gesture lifecycle stages such as start, update, end, and cancellation. The documentation highlights critical constraints, including the requirement of 2 to 5 fingers to trigger the gesture and a default 1-degree minimum change threshold. Furthermore, it includes a practical code example that demonstrates state-driven UI rotation. This guide is intended for developers with existing knowledge of gesture binding and state management who are looking to enhance user interaction in their Cangjie-based applications.
