This directory provides a comprehensive development guide focused on the essential protocols for requesting user authorization for device location information before utilizing Location Kit capabilities. It covers the complete scenario overview, defining the various permission types and the step-by-step development procedures for requesting authorization. Key topics include the critical distinction between `ohos.permission.LOCATION` for precise, meter-level accuracy and `ohos.permission.APPROXIMATELY_LOCATION` for 5km accuracy. The guide also clarifies that requesting both permissions simultaneously grants precise location access. This resource is suitable for application developers integrating location services who need to understand permission declaration and request logic to ensure their applications function correctly within the system's privacy framework.
