# stddatabasesql

The `stddatabasesql` directory serves as the comprehensive documentation repository for the `database.sql` package within the Cangjie programming language ecosystem. It provides essential resources for developers aiming to integrate database functionality into their applications using SQL/CLI interfaces. The content encompasses fundamental concepts such as data type mapping between SQL and Cangjie, connection management, and transaction handling. It is specifically tailored for Cangjie developers and database engineers who require a deep understanding of API structures, driver interactions, and type conversions to build robust, data-driven applications.

## Detailed Description

### 功能介绍.md
This document serves as an API reference for the database.sql package, detailing how the Cangjie programming language interfaces with databases. It covers the package's reliance on SQL/CLI interfaces and database drivers, and provides a comprehensive data type mapping table. The core content is the mapping table that correlates SQL types (e.g., VARCHAR, BLOB, TIMESTAMP) with their corresponding Cangjie types (e.g., String, io.InputStream, time.DateTime) and internal SqlDataType representations. It notes that currently only SQL/CLI is supported. This is intended for Cangjie developers who need to perform database operations and understand type conversions.

### API_列表/
