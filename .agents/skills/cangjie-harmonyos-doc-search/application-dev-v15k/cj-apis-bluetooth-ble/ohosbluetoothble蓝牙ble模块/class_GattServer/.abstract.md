This directory contains API reference documentation for the `GattServer` class in the Cangjie programming language, designed for managing Bluetooth Low Energy (BLE) server operations. It covers essential functionalities including server instantiation, service management (adding and removing), event handling (callbacks for reads, writes, and connection states), and client notifications. The documentation is part of the ConnectivityKit and provides detailed parameters, error codes, and practical code examples. It is suitable for developers implementing BLE server-side logic who need precise control over GATT profiles, characteristic interactions, and protocol stack communication using Cangjie syntax.
