This directory provides comprehensive technical documentation on implementing adaptive sizing for Web components within the HarmonyOS and Cangjie development ecosystems. It specifically addresses the use of the `layoutMode(WebLayoutMode.FIT_CONTENT)` property to enable Web content to dynamically adjust its height and scroll synchronously with native application elements. The content covers essential implementation details, practical code examples, and specific usage scenarios such as hybrid app integration and mini-programs. Furthermore, it outlines critical system constraints, lifecycle management, and JavaScript interaction capabilities. This resource is designed for application developers seeking to create seamless, high-performance hybrid interfaces that blend Web and native components effectively. It ensures developers understand the nuances of the ArkWeb component, including its underlying Chromium kernel and security features.
