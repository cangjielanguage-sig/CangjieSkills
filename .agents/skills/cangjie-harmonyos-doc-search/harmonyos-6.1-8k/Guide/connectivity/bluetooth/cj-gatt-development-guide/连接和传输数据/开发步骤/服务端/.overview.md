# 服务端

本目录包含使用仓颉语言开发蓝牙低功耗（BLE）GATT服务端的完整指南。文档详细介绍了从构建服务端实例、添加服务和特征值，到处理连接状态变化、特征值与描述符的读写请求，以及发送通知和释放资源的全流程。内容基于ConnectivityKit，涵盖回调机制、数据响应逻辑及异常处理。核心关键词包括仓颉、BLE、GATT、服务端、特征值、描述符、通知。该文档适合具备仓颉编程基础及蓝牙协议知识的HarmonyOS开发者，旨在帮助其实现稳定高效的蓝牙服务端应用。

## 详细描述

### 服务端_1.md
本文档是一份使用仓颉语言开发蓝牙低功耗（BLE）GATT服务端的教程，旨在指导开发者构建服务端实例并管理蓝牙通信。文档主要包含四个核心部分：创建服务端实例、添加包含特征值和描述符的服务、订阅连接状态变化事件以及处理数据传输操作。关键信息包括如何通过ConnectivityKit构建GattService对象、利用回调机制实时监听连接状态（如StateConnected）及客户端的读写请求。该文档面向具备仓颉编程基础的开发人员，提供了完整的代码示例及异常处理逻辑，帮助实现蓝牙服务端的核心功能。

### 服务端_2.md
本文档是一份Cangjie语言开发指南，旨在指导开发者处理BLE GATT服务端的特征值读写请求。主要内容包括特征值读取与写入的回调逻辑实现、数据回复机制，以及描述符读写事件的订阅方法。关键信息在于读取时需调用sendResponse回复数据，写入时根据needRsp判断是否回复。文档提供了完整的代码示例，演示了如何定义回调类并使用gattServer.on订阅相关事件。目标受众为具备Cangjie基础及蓝牙协议知识的开发者，用于实现服务端与客户端的数据交互。

### 服务端_3.md
本文档旨在指导开发者使用Cangjie语言处理BLE服务端的描述符读写请求及发送特征值变化通知。主要涵盖描述符读取与写入的回调实现、`sendResponse`响应机制，以及通过`notifyCharacteristicChanged`发送通知或指示的区别与应用。文档提供了完整的代码示例，演示了如何订阅事件、判断是否需要响应及处理数据。关键点在于区分写入请求中的`needRsp`标志和通知中的`confirm`参数。适用于具备ConnectivityKit基础知识的蓝牙应用开发人员。

### 服务端_4.md
本文档是蓝牙低功耗（BLE）服务端开发指南，重点讲解特征值变化的通知与指示机制及服务端资源释放。主要内容包括配置通知所需的描述符UUID、使用notifyCharacteristicChanged发送数据，以及通过removeService和close方法关闭服务端实例。文档提供了仓颉语言代码示例，强调异常处理和资源管理。目标受众为HarmonyOS蓝牙应用开发者，需了解基础BLE协议和仓颉编程。
