This directory contains API reference documentation for the `X509Cert` class within the DeviceCertificateKit framework, designed for the Cangjie programming language. It provides comprehensive details on managing X.509 certificates, covering methods for validation, data extraction, and cryptographic verification. Key topics include retrieving certificate constraints, serial numbers, public keys, and signature algorithms. The documentation includes syntax definitions, return types, error handling codes, and practical usage examples. It is suitable for security developers and software engineers implementing robust certificate validation and parsing features in their applications.
