## 音频流音量

管理音频流音量的接口是 `AVPlayer` 或 `AudioRenderer` 的 `setVolume()` 方法。使用[AVPlayer](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#func-createavplayer)设置音频流音量的示例代码如下：

```cangjie
import kit.MediaKit.*

func setVolume() {
    try {
        let volume: Float32 = 1.0 // 指定的音量大小，取值范围为[0.00-1.00]，1表示最大音量。
        avPlayer.setVolume(volume)
        AppLog.info("Invoke setVolume succeeded.")
    } catch (e: BusinessException) {
        AppLog.error("Invoke setVolume failed, code is ${e.code}, message is ${e.message}")
    }
}
```

使用[AudioRenderer](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#func-createaudiorendereraudiorendereroptions)设置音频流音量的示例代码如下：

```cangjie
import kit.AudioKit.*
import ohos.base.BusinessException

func setVolume() {
    try {
        audioRenderer.setVolume(0.5) // 音量范围为[0.0-1.0]。
        AppLog.info("Invoke setVolume succeeded.")
    } catch (e: BusinessException) {
        AppLog.error("Invoke setVolume failed, code is ${e.code}, message is ${e.message}")
    }
}
```
