This directory provides comprehensive API reference documentation for the `TaskInfo` class within the Cangjie programming language ecosystem. It serves as a technical guide for defining the data structures used in file transfer tasks, detailing a wide array of read-only properties such as unique task identifiers, source and destination URLs, timestamps, and configuration data. The documentation thoroughly explains critical status indicators, including action types (upload and download), execution modes (foreground and background), and specific error types. Furthermore, it covers advanced attributes like task priority, progress tracking, and retry logic. This resource is specifically designed for developers implementing or interacting with the `SystemCapability.Request.FileTransferAgent` (starting from version 22) who need to query task status, manage retry mechanisms, and implement progress notification strategies.
