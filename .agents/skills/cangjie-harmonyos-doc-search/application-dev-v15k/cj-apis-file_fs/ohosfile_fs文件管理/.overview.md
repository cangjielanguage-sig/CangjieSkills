# ohosfile_fs文件管理

This directory contains comprehensive API reference documentation for the `ohos.file_fs` module in the Cangjie programming language, designed for HarmonyOS file management. It covers essential file I/O operations, including reading, writing, copying, and monitoring file system changes. The documentation details classes for file handling, enumerations for access modes, and structs for configuration options. It is suitable for Cangjie developers working with SystemCapability.FileManagement.File.FileIO who need to implement robust file system features, manage file attributes, and handle asynchronous operations within application sandboxes.

## Detailed Description

### class_File.md
This document serves as an API reference for the File class in Cangjie, detailing file objects opened via the open interface. It covers read-only properties for descriptors and paths, methods for directory retrieval, and file locking mechanisms like tryLock and unLock. It is targeted at developers managing file resources and concurrency using SystemCapability.FileManagement.File.FileIO.

### class_ProgressListener.md
This document provides API reference for the ProgressListener class, a listener for file copy progress. It details the class definition, constructor, and the invoke method, which executes a callback receiving a Progress struct with processedSize and totalSize metrics. It includes usage examples for tracking file operation status.

### class_ReaderIterator.md
This API reference covers the ReaderIterator class, designed to facilitate file reading through iteration. It details the next() function, return types like ReaderIteratorResult, and potential exceptions. Users must construct an instance using the readLines method before invoking iterator functions.

### class_TaskSignal_2more.md
This document covers TaskSignal, which handles interruption signals for file copy tasks, and WatchEventListener, a callback-based class for monitoring file system events. It includes constructors, the cancel() method, and the invoke() method, with examples showing integration with CopyOptions and ProgressListener.

### class_WatchEvent_2more.md
This API reference covers the WatchEvent class, which structures event data (file names, event types), and the Watcher class used to manage the listening process. It details event masks (e.g., IN_MODIFY, IN_CREATE) and lifecycle methods start() and stop() for implementing file management features.

### enum_AccessFlagType_3more.md
This document provides API reference for file management enumerations: AccessFlagType for verifying file location, AccessModeType for checking permissions, and LocationType for distinguishing storage types. It offers specific flags to validate access rights and determine storage context within the system.

### enum_OpenMode.md
This document defines the OpenMode enumeration, providing constant flags for controlling file opening behavior. It details access modes (READ_ONLY, WRITE_ONLY), creation options (CREATE, TRUNC), and special behaviors (NONBLOCK, SYNC). These flags serve as parameters for the open interface in FileIO operations.

### enum_WhenceType.md
This API reference defines the WhenceType enum for relative offset position types used by the lseek interface. It details values like SEEK_SET, SEEK_CUR, and SEEK_END, which set the offset relative to the file start, current position, or end, assisting developers in file pointer manipulation.

### ohosfile_fs文件管理_5more.md
This document details the ConflictFileException class for handling file conflicts and the CopyOptions class for managing copy progress. It includes properties like data, copySignal, and progressListener, along with code examples demonstrating asynchronous file operations for HarmonyOS developers.

### struct_ConflictFiles.md
This document details the ConflictFiles struct, designed to handle file conflict information during directory copy and move operations. It covers read-only properties srcFile and destFile (file paths) and supports the copyDir and moveDir interfaces for developers handling file management I/O.

### struct_Filter.md
This document defines the Filter struct for configuring file filtering criteria for the listFile interface. It allows filtering by suffix, display name, file size, and last modified time. It notes that mimeType and excludeMedia are reserved capabilities currently not supported.

### struct_ListFileOptions.md
This document details the ListFileOptions struct used to configure file listing operations. It covers properties for controlling recursive directory scanning, limiting the number of files returned, and setting string encoding filters, defaulting to non-recursive listing with UTF-8 encoding.

### struct_Options_3more.md
This document provides API reference for three data structures: Options (text encoding), Progress (tracking copy status), and ReadOptions (controlling read parameters). It includes member variable definitions, data types, and default values for configuring encoding, monitoring progress, and customizing read behaviors.

### struct_ReadTextOptions.md
This API reference details the ReadTextOptions struct for configuring parameters for the readText interface. It covers properties for encoding (UTF-8 only), length, and offset to control the read range and starting position, helping developers customize text reading operations.

### struct_ReaderIteratorResult.md
This document details the ReaderIteratorResult struct for handling return values for file reading iterators. It covers read-only properties done (completion status) and value (text content), targeting developers implementing file management operations who need to understand iteration data structures.

### struct_WriteOptions.md
This document details the WriteOptions struct for configuring file write operations. It covers properties for encoding (utf-8), length (buffer size), and offset (write position), providing Cangjie developers with granular control over write operations in the FileIO module.

### class_FileFs/
This directory contains API reference for the Cangjie FileFs class, a utility for comprehensive file system management. It covers static methods for reading, writing, copying, moving, and deleting files, as well as checking permissions and managing attributes within application sandboxes.

### class_RandomAccessFile/
This directory serves as a repository for API reference regarding the RandomAccessFile class, enabling random read/write access to files. It covers core properties, synchronous stream operations, and guides on writing data with various buffer types for low-level file I/O capabilities.

### class_Stat/
This directory contains API reference for the Cangjie Stat class and file type checking functions. It covers the encapsulation of file metadata (access times, ownership, inode) and functions for identifying file types like directories, sockets, and symbolic links for system-level file management.

### class_Stream/
This directory contains API reference for the Stream class, focusing on robust file stream operations. It covers the lifecycle of stream handling (read, write, close, flush), handling data types, and configurable options like encoding and offsets for managing data streams in Cangjie applications.
