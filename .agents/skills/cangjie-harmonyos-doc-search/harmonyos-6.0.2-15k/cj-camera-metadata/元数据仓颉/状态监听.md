## 状态监听

在相机应用开发过程中，可以随时监听metadata数据以及输出流的状态。

- 通过注册监听获取metadata对象，监听事件固定为MetadataObjectsAvailable。检测到有效metadata数据时，callback返回相应的metadata数据信息，MetadataOutput创建成功时可监听。

    ```cangjie
    class MetadataObjectsAvailableCallBack <: Callback1Argument<Array<MetadataObject>> {
        public open func invoke(metadataObjectArr: Array<MetadataObject>): Unit {
            AppLog.info("metadata ouput metadataObjectsAvailable")
        }
    }

    func onMetadataObjectsAvailable(metadataOutput: MetadataOutput): Unit {
        metadataOutput.on(CameraCallbackType.MetadataObjectsAvailable, MetadataObjectsAvailableCallBack())
    }
    ```

    > **说明：**
    >
    > 当前的元数据类型仅支持人脸检测（FACE_DETECTION）功能。元数据信息对象为识别到的人脸区域的矩形信息（Rect），包含矩形区域的左上角x坐标、y坐标和矩形的宽高数据。

- 通过注册回调函数，获取监听metadata流的错误结果，callback返回metadata输出接口使用错误时返回的错误码，错误码类型参见[Camera错误码](../../../API_Reference/source_zh_cn/errorcodes/cj-errorcode-multimedia-camera.md)。

    ```cangjie
    class ErrorCallBack <: Callback1Argument<BusinessException> {
        public open func invoke(error: BusinessException): Unit {
            AppLog.error("Metadata output error code: ${error.code}")
        }
    }

    func onMetadataError(metadataOutput: MetadataOutput): Unit {
        metadataOutput.on(CameraCallbackType.CameraError, ErrorCallBack())
    }
    ```
