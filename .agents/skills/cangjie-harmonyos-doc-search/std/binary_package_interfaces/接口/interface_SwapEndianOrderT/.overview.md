# interface_SwapEndianOrderT

This directory contains API reference documentation for the `SwapEndianOrder` interface within the Cangjie standard library's binary package. It covers the implementation of byte order reversal (endianness swapping) across various integer types, including Int8, Int16, Int32, Int64, and their unsigned counterparts. The core functionality revolves around the `swapBytes()` method, which reverses the byte sequence of numeric values. This documentation is essential for Cangjie developers working with low-level binary data, network programming, or cross-platform compatibility where precise control over data representation is required.
