This directory serves as a comprehensive resource for the `aa` (Ability Assistant) command-line tool, specifically designed for OpenHarmony and HarmonyOS development environments. It focuses on application lifecycle management, debugging, and performance tuning. The content covers essential commands for launching, stopping, testing, and attaching to processes, as well as troubleshooting error codes. This documentation is intended for developers, QA engineers, and system integrators who need to manage UIAbility and ServiceExtensionAbility components or perform runtime debugging via the hdc shell.
