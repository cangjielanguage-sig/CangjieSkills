## 详细描述

### func_blockBorderC_6more_34e63418.md
本文档是ArkUI框架中Slider组件的API参考文档，旨在定义滑块外观与交互样式的配置接口。文档主要涵盖了六个核心函数，包括设置滑块描边及本体颜色、滑轨背景与选中颜色的blockBorderColor、blockColor、trackColor和selectedColor，以及控制步长刻度与气泡提示显示的showSteps和showTips。关键信息指出这些函数均支持资源类型参数，起始版本为22，并详细说明了气泡提示的显示逻辑与位置规则。该文档面向使用Cangjie语言进行UI开发的开发者，帮助他们精细定制Slider组件的视觉效果和交互体验。

### func_trackThicknessLeng_e46a9e5c.md
本文档是ArkUI框架中trackThickness函数的API参考，用于设置滑块滑轨的粗细。文档涵盖了函数签名、功能描述、系统能力、起始版本及参数详情。关键信息指出，blockSize会根据特定比例随trackThickness同比例增减，OutSet和InSet样式比例分别为1:4和5:3。若设置值小于等于0或导致尺寸超出组件宽高，系统将取初始值。该文档面向使用ArkUI进行UI开发的程序员，旨在帮助其精确控制Slider组件的样式表现。关键词：ArkUI, Slider, trackThickness, API, UI组件。
