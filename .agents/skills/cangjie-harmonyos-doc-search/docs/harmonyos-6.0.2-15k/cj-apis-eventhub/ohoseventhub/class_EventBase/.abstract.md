This directory contains API reference documentation for the `EventBase` abstract class within the Cangjie AbilityKit, focusing on event handling and type validation mechanisms. It details methods for validating event parameter counts (from 0 to 5 arguments) and returning corresponding Event objects like `Event0` through `Event5`. The documentation includes syntax details, return types, potential `BusinessException` errors, and practical Cangjie code examples for registering callbacks and emitting events via `EventHub`. It is intended for developers building applications using the HarmonyOS AbilityRuntime Core who require knowledge of generic types and event-driven programming.
