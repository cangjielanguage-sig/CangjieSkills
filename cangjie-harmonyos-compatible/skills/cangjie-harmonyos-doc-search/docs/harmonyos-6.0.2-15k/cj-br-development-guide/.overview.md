# cj-br-development-guide

This directory provides a comprehensive development guide for implementing basic Bluetooth control functions using the Cangjie programming language. It covers essential operations including enabling, disabling, and retrieving the status of Bluetooth. The content details specific APIs such as `enableBluetooth`, `disableBluetooth`, and state change callbacks, offering step-by-step tutorials with Cangjie code examples. It explains how to import the `ConnectivityKit`, handle state transitions, and verify functionality through logs. Targeted at application developers, this guide requires the `SystemCapability.Communication.Bluetooth.Core` system capability and serves as a practical reference for integrating Bluetooth access features.
