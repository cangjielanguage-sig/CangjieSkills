# runtime_package_overview

This directory serves as the central documentation hub for the Cangjie programming language's runtime package, a critical component for developers interacting with the program's execution environment. It provides in-depth resources on system programming, focusing heavily on memory management, automatic garbage collection (GC) control, and system resource monitoring. The content is tailored for Cangjie developers and system programmers who require low-level access to optimize application performance, tune memory usage, and manage runtime behavior efficiently. By offering both introductory guides and technical references, this package enables precise control over heap memory, GC cycles, and processor statistics, ensuring robust application deployment and efficient resource utilization in complex software systems. Mastering these tools is essential for building high-performance applications in the Cangjie ecosystem, allowing developers to push the boundaries of what the language can achieve in terms of speed and reliability.

## Detailed Description

This section breaks down the specific documentation available within the package structure, providing detailed insights into the capabilities of the runtime environment.

### stdruntime/
The `stdruntime` directory provides comprehensive documentation for the Cangjie programming language's runtime package, designed to facilitate interaction with the program's execution environment. It covers essential aspects of system programming, including memory management, automatic garbage collection (GC) control, and system resource monitoring. Developers will find resources for managing heap memory, triggering GC cycles, and retrieving statistics on threads and processors. This documentation is suitable for Cangjie developers and system programmers who need to optimize application performance, tune memory usage, and gain low-level control over runtime behavior. It serves as both an introductory guide and a technical reference for utilizing the runtime API effectively.
