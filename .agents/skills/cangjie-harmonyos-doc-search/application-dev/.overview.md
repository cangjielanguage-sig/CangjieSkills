# application-dev

This directory serves as a comprehensive technical repository for HarmonyOS and OpenHarmony application development, specifically focusing on the Cangjie programming language and the ArkUI framework. It encompasses a wide range of resources including cross-language interoperability with ArkTS, UI component development, system capabilities (sensors, network, crypto), application lifecycle management, and essential development tools. The content is tailored for developers, system architects, and engineers seeking to build robust, high-performance applications within the HarmonyOS ecosystem, offering both conceptual overviews and detailed API references.

## Detailed Description

### README_zh
This directory serves as a central hub for documentation related to the HarmonyOS development ecosystem, specifically focusing on the ArkUI framework and the Cangjie programming language. It provides access to resources for managing application windows, exploring Beta features of the ArkUI framework, and comprehensive guides for learning Cangjie.

### cj-cangjie-overview
This directory functions as the primary gateway for developers interested in the Cangjie programming language, specifically within the OpenHarmony ecosystem. It contains a high-level overview document that defines Cangjie as the state-of-the-art, high-level language tailored for creating robust applications on the OpenHarmony platform.

### cj-arkts_interoperability_lib
This directory contains a guide for HarmonyOS developers implementing interoperability between ArkTS and Cangjie using a manual library approach. The documentation covers the end-to-end process, starting with creating a Cangjie module and defining functions that utilize JSContext and JSCallInfo parameters.

### cj-application-models
This directory serves as a comprehensive resource for understanding the system's application model, specifically focusing on the "Stage model" architecture. It provides a deep dive into the abstraction layers designed to simplify and standardize the application development process.

### cj-apis-bluetooth
This directory provides a specialized collection of API reference documentation for the Bluetooth Low Energy (BLE) module, specifically implemented in the Cangjie programming language for the HarmonyOS ecosystem. It acts as a technical guide for developers aiming to integrate wireless communication capabilities into their applications.

### cj-animation
This directory serves as a comprehensive knowledge base for the `cj-animation` project, dedicated entirely to the theory and application of animations within the ArkUI framework. It is designed to empower developers to construct fluid, responsive, and highly interactive user interfaces.

### cj-hdc
The `cj-hdc` directory serves as a comprehensive resource hub for the HarmonyOS Device Connector (HDC), a pivotal command-line tool designed for debugging and managing OpenHarmony and HarmonyOS devices. This directory consolidates essential technical documentation that guides users through the complexities of the HDC tool.

### cj-huks
This directory functions as the primary API reference documentation for the OpenHarmony Universal KeyStore System (HUKS), meticulously curated for developers using the Cangjie programming language. It provides an extensive overview of the cryptographic capabilities available within the HarmonyOS ecosystem.

### cj-data-persistence
This directory provides a detailed technical overview of application data persistence mechanisms specifically engineered for the OpenHarmony standard system. It addresses the critical development task of saving memory data to persistent device storage, ensuring data survives application restarts and system reboots.

### cj-permissions
This directory serves as the definitive guide for application permissions, designed to assist developers in navigating the complex landscape of authorization requirements. It functions as a central index, categorizing permissions into four distinct groups to simplify the application process.
