# cj-universal-attribute-hovereffect

This directory serves as the definitive documentation for the `cj-universal-attribute-hovereffect` module within the Cangjie ArkUI framework. It focuses on the `hoverEffect` function, a critical API for configuring visual states during mouse hover interactions on UI components. The content details the function signature, system capabilities, and the `HoverEffect` parameter, which supports values like Auto, Highlight, or None. It includes practical code examples showing how to apply these effects to Column and Text components, complete with event logging. This resource is tailored for Cangjie developers with basic knowledge of UI component construction and event handling who seek to implement interactive mouse behaviors. By utilizing this guide, developers can significantly enhance user experience through responsive visual feedback.
