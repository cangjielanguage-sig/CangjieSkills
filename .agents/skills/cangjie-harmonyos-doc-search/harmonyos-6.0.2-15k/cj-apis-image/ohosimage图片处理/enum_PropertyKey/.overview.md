# enum_PropertyKey

This directory contains API reference documentation for the `PropertyKey` enumeration within a multimedia image processing framework, specifically designed for the Cangjie programming language. It covers a comprehensive range of image metadata constants, including EXIF data, GPS location tags, camera settings (aperture, ISO, shutter speed), and face detection metrics. The documentation details read/write permissions, system capabilities, and API version requirements for each property. It is suitable for software developers and engineers building multimedia applications who need to programmatically access, modify, or understand image properties and metadata structures.
