# 组件属性

This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It focuses specifically on the Navigation component, covering a wide range of customization options including menu configuration, toolbar settings, title management, layout behavior, and state persistence. Developers will find detailed parameter definitions, constraints, and usage examples for functions that control navigation bars, safe areas, and visual effects. This documentation is suitable for UI developers and software engineers building complex navigation interfaces in Cangjie who need precise control over component behavior and layout constraints.

### func_recoverableBool_3more.md
This document serves as API reference documentation for configuring specific behaviors of the Navigation component in the Cangjie ArkUI framework. It details three Boolean configuration functions: recoverable, enableDragBar, and enableModeChangeAnimation. The enableDragBar function manages drag bar visibility in split views, while enableModeChangeAnimation toggles transition effects during layout mode changes. This guide targets application developers building UIs with ArkUI who need to manage navigation state persistence and visual layout behaviors.
