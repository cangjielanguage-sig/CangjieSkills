This directory contains comprehensive API reference documentation for the Cangjie `Event5` class and its associated subscription function within the AbilityKit framework. It specifically covers the management of events that require five generic parameters (A1 through A5). The documentation details the class definition, inheritance from `EventBase`, and methods for triggering (`emit`) and unsubscribing (`off`) from events. Additionally, it explains the subscription mechanism using the `on` function and `EventCallBack5`. Key topics include event-driven programming, generic type support, and integration with `EventHub`. This resource is suitable for Cangjie developers implementing complex event handling logic in applications requiring SystemCapability.Ability.AbilityRuntime.Core (version 12 or later). It serves as a technical guide for building robust, event-based architectures in Cangjie applications.
