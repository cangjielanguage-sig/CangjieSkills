This directory provides a comprehensive guide to HarmonyOS open permissions that utilize system authorization (`system_grant`). It details permissions automatically granted by the system upon installation, specifically those classified as "normal" level. Key topics include permission definitions, application methods, and the technical distinction that these permissions do not involve ACL enablement fields. The content is essential for application developers who need to identify which permissions are pre-authorized and how to declare them correctly in configuration files. By covering access to device capabilities like connectivity, sensors, and system controls, this resource ensures compliant access to system services without user interaction during runtime, streamlining the development process for standard app features.
