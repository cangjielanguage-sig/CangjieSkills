# 使用SM4对称密钥ECB模式加解密

This directory serves as a comprehensive technical resource for developers aiming to implement secure data encryption and decryption using the SM4 symmetric key algorithm. Specifically, it focuses on the Electronic Codebook (ECB) mode combined with PKCS7 padding, a common requirement for securing sensitive information in applications. The content covers the complete lifecycle of cryptographic operations, from generating 128-bit keys to processing data chunks and finalizing results. It highlights the use of the CryptoArchitectureKit and the specific string configuration 'SM4_128|ECB|PKCS7'. These materials are primarily intended for software engineers working with the Cangjie programming language and the HarmonyOS ecosystem who require practical guidance on integrating standardized cryptographic algorithms into their applications to ensure data integrity and confidentiality.

### 使用SM4对称密钥ECB模式加解密_3more.md 使用SM4对称密钥ECB模式加解密_3more.md
This technical guide provides step-by-step instructions for performing encryption and decryption using the SM4 symmetric key algorithm in ECB mode with PKCS7 padding. The document is divided into two main workflows: Encryption and Decryption. Both sections detail the sequence of API calls required to generate keys, create Cipher instances, initialize operations, process data, and finalize results. Key steps include generating a 128-bit SM4 key via createSymKeyGenerator, creating a Cipher with the string 'SM4_128|ECB|PKCS7', and using the initialize, update, and doFinal methods. The guide highlights that ECB mode requires no encryption parameters and supports data chunking for large payloads. This tutorial targets developers working with the CryptoArchitectureKit who need to implement SM4 cryptographic operations in their applications.

Key takeaways include the specific usage of the SM4_128|ECB|PKCS7 cipher configuration, the initialization of cipher modes, and error handling using BusinessException.
