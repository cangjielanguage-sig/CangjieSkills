# class_InstanceFunctionInfo

This directory contains API reference documentation for the `InstanceFunctionInfo` class within the Cangjie reflection package. It focuses on describing metadata for instance member functions, enabling developers to inspect and analyze function structures programmatically. The documentation covers class properties, dynamic invocation of both standard and generic methods, and metadata inspection utilities such as annotation retrieval and modifier checks. It is suitable for developers working with runtime reflection, introspection, and dynamic code execution in the Cangjie programming language who need to understand type systems and exception handling.
