This directory provides comprehensive technical documentation regarding the usage restrictions for access qualifiers on member properties within Cangjie custom components. It focuses on the critical rules governing state management, specifically how decorators such as @State, @Prop, @Link, and @StorageLink interact with initialization protocols and access modifiers. The content covers validation rules to prevent compiler errors, ensuring proper data flow and synchronization between parent and child components. It is highly suitable for Cangjie developers and HarmonyOS application builders who need to define valid component interfaces, maintain code integrity, and master the syntactic constraints of UI state management. By understanding these restrictions, developers can avoid common pitfalls and ensure robust application architecture.
