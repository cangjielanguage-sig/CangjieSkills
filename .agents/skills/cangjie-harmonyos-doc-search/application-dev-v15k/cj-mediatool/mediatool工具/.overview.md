# mediatool工具

This directory contains comprehensive documentation for the mediatool, a lightweight command-line utility enabling developers to manipulate media library resources utilized by the Gallery application. The content covers the tool's technical definition, pre-installed location in the /bin directory, and accessibility via hdc shell. Key information includes prerequisites such as enabling developer mode and ensuring device connectivity, emphasizing that no installation is required. It is intended for developers needing to manage image and video data through a command-line interface, offering workflows for querying, exporting, and deleting media assets.

### 命令行说明.md 命令行说明.md
This document serves as a reference guide for the mediatool command-line interface, detailing commands to manage media library resources. It covers three primary subcommands: recv for exporting source files, delete for permanent removal, and query for searching resources by display name. Key information includes path restrictions limited to /data/local/tmp, the inability to access hidden albums, and the irreversible nature of deletion operations. The query command supports flags to return either real file paths or URIs. This technical documentation targets developers or system administrators who need to manipulate media assets programmatically via a shell environment.
