# 接口

This directory functions as a central hub for interface definitions and technical documentation within the Cangjie programming language's development environment. It is specifically designed to house the structural blueprints and API references that are critical for the language's unit testing framework. The primary focus of this directory is to provide comprehensive details on assertion interfaces, particularly the `AssertPrintable` contract, which dictates how custom data types are formatted and displayed when test failures occur. By covering a wide range of data types—including generic options, strings, and various floating-point precisions—it ensures that developers can produce clear, human-readable diagnostic outputs. This directory is an essential resource for software engineers, framework contributors, and quality assurance specialists who are tasked with extending the testing capabilities of Cangjie. It is particularly valuable for those who need to implement custom display logic for complex types or wish to gain a deeper understanding of how the testing framework handles differences between expected and actual values through tools like `PrettyPrinter`. Mastering these interfaces allows for more robust debugging and a better developer experience when writing automated tests.

## Detailed Description

### [1] interface_AssertPrintable/

This directory contains API reference documentation for the `AssertPrintable` interface within the Cangjie programming language's unit testing framework. It covers the core interface definition required for custom assertion printing and details specific implementations for various data types, including `Option<T>`, `String`, `Float16`, `Float32`, and `Float64`. These documents explain how to format test failure outputs using `PrettyPrinter`, handling nested differences, and managing prefixes for expected versus actual values. This resource is suitable for developers working on or extending the Cangjie testing framework who need to understand or customize assertion display logic.
