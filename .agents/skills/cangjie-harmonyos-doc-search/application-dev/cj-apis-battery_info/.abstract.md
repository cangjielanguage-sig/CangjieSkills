This directory serves as the comprehensive API reference documentation for the `cj-apis-battery_info` module, a critical component within the Cangjie programming language ecosystem designed for HarmonyOS development. It provides developers with the essential tools and interfaces required to monitor and manage device power states efficiently. The documentation covers a wide range of functionalities, including accessing real-time battery metrics, determining current charging status, evaluating battery health conditions, and checking capacity levels. By detailing the `BatteryInfo` class and its associated enumerations for charge states, health status, and plugged types, this resource empowers developers to implement robust power management features. It is specifically suitable for HarmonyOS developers and software engineers aiming to build applications that require battery status monitoring or energy consumption tracking. Key technical concepts include SystemCapability.PowerManager.BatteryManager.Core, API version 22, and the module's Beta status, ensuring users are aware of the system requirements and stability.
