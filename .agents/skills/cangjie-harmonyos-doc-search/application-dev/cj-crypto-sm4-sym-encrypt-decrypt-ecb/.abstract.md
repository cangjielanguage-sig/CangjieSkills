This directory serves as a comprehensive technical resource dedicated to the implementation of the SM4 symmetric key algorithm within the Cangjie programming environment. It specifically focuses on the Electronic Codebook (ECB) mode of operation, augmented with PKCS7 padding to handle data block alignment requirements. The directory provides a complete guide for the cryptographic lifecycle, ranging from the generation of secure 128-bit keys to the processing of data chunks and the finalization of encrypted or decrypted outputs. By utilizing the CryptoArchitectureKit and the specific configuration string 'SM4_128|ECB|PKCS7', this project offers a standardized approach to data security. It is ideally suited for software engineers and developers working within the HarmonyOS ecosystem who require practical, reliable methods to ensure data integrity and confidentiality in their applications. The content bridges the gap between theoretical cryptographic standards and practical coding implementation.
