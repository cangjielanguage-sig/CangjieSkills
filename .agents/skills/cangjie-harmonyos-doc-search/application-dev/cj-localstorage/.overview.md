# cj-localstorage

This directory focuses on the LocalStorage mechanism for managing page-level UI state within the ArkUI and Cangjie frameworks. It provides a comprehensive overview of implementing decorators like `@LocalStorageProp` and `@LocalStorageLink` to facilitate seamless data synchronization between components and storage. The content covers both one-way and two-way data binding strategies, alongside detailed API definitions, usage constraints, and lifecycle management. It also explores practical scenarios for sharing state across pages and components. This resource is specifically designed for HarmonyOS developers seeking efficient solutions for implementing persistent or shared application states in their software projects.

## Detailed Description

### LocalStorage页面级UI状态存储/

This directory covers the LocalStorage mechanism for page-level UI state management within the ArkUI and Cangjie frameworks. It serves as a technical guide for developers aiming to master state synchronization in their applications.

The content details how to use decorators like `@LocalStorageProp` and `@LocalStorageLink` to synchronize data between components and storage. It explains the distinction between these decorators, supporting both one-way data binding (for read-only access) and two-way data binding (for interactive state updates). Additionally, the directory includes API definitions and usage constraints to ensure developers adhere to best practices.

Lifecycle management is also a key focus, providing insights into how state is initialized, updated, and destroyed. By exploring practical scenarios for sharing state across pages and components, this guide helps developers build robust applications. It is suitable for HarmonyOS developers looking to implement efficient, persistent, or shared application states.
