# cj-performance-analysis-kit-overview

This directory provides an overview of the Performance Analysis Kit, a service designed to help developers observe application runtime states through event, log, and trace analysis. It covers essential usage scenarios such as debugging and online monitoring, alongside core capabilities like HiLog and HiTrace. The content highlights APM system construction, exception handling, and fault analysis methods for issues like Cangjie Crash, CppCrash, and AppFreeze. Suitable for developers with programming and operating system knowledge, this guide aids in improving application stability and user experience using DevEco Studio and related SDKs.
