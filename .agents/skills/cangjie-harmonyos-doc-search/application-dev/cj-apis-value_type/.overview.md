# cj-apis-value_type

This directory serves as a comprehensive resource for the `ohos.value_type` module, specifically tailored for the Cangjie programming language within the HarmonyOS ecosystem. It provides the API reference for the `CommonEventValueType` enum, a critical component for developers needing to encapsulate and manage additional information within common events. The documentation details a wide range of supported data types, encompassing basic primitives such as Int32, String, Bool, and Float64, as well as complex types like File Descriptors and their respective array variants. Operating under the `SystemCapability.Notification.CommonEvent`, this module is currently in Beta. It is primarily suitable for HarmonyOS developers utilizing Cangjie who require precise control over structured data handling in event-driven applications, ensuring they can effectively pass diverse data payloads through the common event system.
