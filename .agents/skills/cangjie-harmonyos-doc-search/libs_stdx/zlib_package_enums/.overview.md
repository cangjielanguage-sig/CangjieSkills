## Detailed Description

### zlib_package_enums.md zlib_package_enums.md

This document serves as the primary API reference documentation for enumerations within the zlib package in the Cangjie programming language. It is structured to assist developers in understanding the specific configuration options available for data compression tasks.

The content details two primary enumerations:

1.  **CompressLevel**: This enumeration defines the trade-off between processing speed and the compression ratio. It includes three specific levels:
    *   `BestCompression`: Optimizes for the smallest possible output size.
    *   `BestSpeed`: Optimizes for the fastest processing time.
    *   `DefaultCompression`: Provides a standard balance between the two.
2.  **WrapType**: This enumeration specifies the data format to be used for the output. It supports:
    *   `DeflateFormat`: The raw deflate compression format.
    *   `GzipFormat`: The Gzip wrapper format.

The document is intended for Cangjie developers implementing compression functionality who need to configure specific compression behaviors and output formats. Keywords: Cangjie, zlib, API reference, enumerations, compression levels, data formats.
