# 组件事件

This directory provides comprehensive API reference documentation for component events within the ArkUI framework, specifically tailored for the Cangjie programming language. It primarily focuses on the Grid component, covering essential event handling mechanisms for complex user interactions such as drag-and-drop operations, scrolling behaviors, and boundary detection. Key topics include drag event lifecycles (start, move, enter, leave), item dropping logic, scroll index tracking, and scrollbar customization. These resources are essential for software developers and UI engineers building responsive, interactive grid layouts who require granular control over component states and user gestures.

## Detailed Description

### func_onItemDragEnterItemDr_5more.md func_onItemDragEnterItemDr_5more.md
This API reference document details drag-and-drop event handling functions for grid elements within the ArkUI framework using the Cangjie language. It covers five specific functions: onItemDragEnter, onItemDragLeave, onItemDragMove, and two overloads of onItemDragStart. The functions handle drag entry, exit, movement, and initiation, utilizing ItemDragInfo and index parameters. Crucially, onItemDragStart determines drag capability based on return type and notes conflicts with LongPressGesture. This is intended for developers implementing interactive grid components, requiring knowledge of ArkUI system capabilities and event handling.

### func_onItemDropItemDragInf_5more.md func_onItemDropItemDragInf_5more.md

The target audience is software developers using the ArkUI framework who need to implement interactive scrolling and drag-and-drop features in grid layouts.

### func_onScrollIndexUInt32_-_4more.md func_onScrollIndexUInt32_-_4more.md
This document serves as API reference documentation for scroll-related event callbacks within the ArkUI Grid component, specifically for the Cangjie language. It details four primary functions: two overloads of onScrollIndex for tracking visible item indices, plus onScrollStart and onScrollStop for monitoring scroll state transitions. Key information includes version differences, where version 19 expands index tracking to include both start and end positions, and the specific triggers for scroll events, such as user gestures or Scroller animations. The content is intended for developers utilizing ArkUI to implement responsive grid interfaces, providing the necessary parameters and system capability requirements to handle scrolling logic effectively.
