This directory provides comprehensive API documentation for various Cangjie language structs, primarily focusing on generic tuple wrappers and testing utilities. It covers the implementation of `TupleWrapper` structs for handling 2 to 5 element tuples, alongside specialized structs like `Function0Wrapper` and `KeyRandom` for unit testing and randomization. Key features include property-based testing interfaces (`Arbitrary`, `Shrink`), standard interfaces (`ToString`, `Equatable`), and functional manipulation methods. This documentation is suitable for Cangjie developers working on advanced data structures, functional programming patterns, or building robust testing frameworks requiring random data generation and tuple management.
