# 观察变化和行为表现

This directory serves as a comprehensive guide to understanding the observation of data changes and the behavioral performance of components within the Cangjie programming language and ArkUI framework. It delves into the intricacies of state management, specifically focusing on how decorated variables like `@Prop` are initialized and updated across parent-child component hierarchies. Furthermore, it provides deep insights into change observation mechanisms, explaining how various data structures—ranging from primitive types to complex collections—interact with the system to detect and synchronize changes. By distinguishing between value and reference observation, this documentation helps developers grasp the nuances of internal mutations versus whole assignments. This resource is highly suitable for Cangjie and ArkUI developers who are looking to master reactive programming patterns, optimize component state updates, and build highly responsive and efficient user interfaces.

## Detailed Description

### 框架行为.md 框架行为.md

This technical reference document explains the initialization and update mechanisms of `@Prop` decorated variables within a parent-child component hierarchy. It covers the initial rendering process where parent data initializes child variables, and the update behavior characterized by one-way data flow. Key takeaways include that child `@Prop` updates remain local and do not sync to the parent, while parent data updates overwrite any local child modifications. The document also notes that `@Prop` cannot refresh when the application is in the background, recommending `@Link` as an alternative. This guide targets developers needing to understand state management and component lifecycle behaviors.

### 观察变化/

This directory provides a comprehensive technical overview of change observation mechanisms within the Cangjie programming language and ArkUI state management. It details how specific decorators, such as `@Prop`, interact with various data structures—including primitive types, structs, classes, arrays, and collections—to detect and synchronize changes. The documentation highlights critical distinctions between value and reference observation, particularly regarding internal mutations versus whole assignments. It also addresses specific behaviors of collections like HashSet and ObservedArray, clarifying exactly when updates trigger UI refreshes. This resource is designed for Cangjie and ArkUI developers seeking to master reactive programming patterns, optimize component state updates, and understand the nuanced limitations of observable data structures in their applications.
