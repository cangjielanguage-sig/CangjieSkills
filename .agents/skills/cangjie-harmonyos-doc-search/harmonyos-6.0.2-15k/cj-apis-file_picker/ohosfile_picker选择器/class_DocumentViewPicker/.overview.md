# class_DocumentViewPicker

This directory contains API reference documentation for the Cangjie `DocumentViewPicker` class, designed for HarmonyOS application development. It covers the implementation of system-level file pickers that facilitate the selection and saving of various document formats. Key topics include the class constructor, asynchronous methods for saving and selecting files using `AsyncCallback`, and configuration options like `DocumentSaveOptions`. This documentation is suitable for developers working with file management services who need to integrate user-interactive file dialogs into their applications using the Cangjie language.

## Detailed Description

### class_DocumentViewPicker_3more.md
This document provides API reference documentation for the Cangjie class DocumentViewPicker, designed to facilitate the selection and saving of various document formats within applications. It details the class constructor, which requires a UIAbilityContext parameter, and the getSelectedIndex method. This method retrieves the index of the selected file suffix type after a successful save operation, specifically when used with DocumentSaveOptions. Key information includes system capabilities, version requirements (starting from version 12), and usage constraints, such as the method returning -1 if no suffix choices are provided. The content targets application developers working with file management services, offering code examples for implementation.

### func_saveAsyncCallbackArra_2more.md
This API reference document details the usage of asynchronous file saving and selection functions within the DocumentViewPicker component for Cangjie development. It covers two primary functions: save, which launches a picker to save files, and select, which allows users to choose files. Both sections include function signatures, parameter descriptions, and Cangjie code examples. Key information includes that both methods utilize AsyncCallback to return an array of file URIs and accept optional configuration objects like DocumentSaveOptions or DocumentSelectOptions. The examples demonstrate error handling and result processing. This guide targets HarmonyOS developers using the Cangjie language who need to implement file management features requiring user interaction via system pickers.
