# 示例代码

This directory provides a comprehensive collection of Cangjie language code examples tailored for HarmonyOS UIKit development, with a primary focus on the versatile implementation of AlertDialog components. The content guides developers through creating interactive user prompts, ranging from simple confirmation alerts to complex multi-option selections. It also addresses advanced use cases such as rendering dialogs outside the main window context and applying detailed visual customizations like borders, shadows, and specific dimensions. By utilizing key parameter structures such as `AlertDialogParamWithConfirm` and `AlertDialogParamWithOptions`, these examples demonstrate how to handle alignment, offsets, and dismissal events effectively. This directory is an essential resource for Cangjie developers and OpenHarmony engineers aiming to build sophisticated, user-friendly interfaces with robust alert systems.

## Detailed Description

### 示例1弹出多个按钮的弹窗.md 示例1弹出多个按钮的弹窗.md
This document serves as a code tutorial demonstrating how to create Alert Dialogs with one, two, or three buttons using the Cangjie language and HarmonyOS UIKit. The main topics cover the implementation of three distinct dialog configurations: a single confirm button, a primary and secondary button pair, and a list of three option buttons. Key information includes the specific parameter structures required for each scenario, such as AlertDialogParamWithConfirm and AlertDialogParamWithOptions, along with shared properties like alignment, offset, and dismissal event handling. This example is designed for Cangjie developers seeking to implement interactive dialog components in OpenHarmony applications.

### 示例2可在主窗外弹出的弹窗_2more.md 示例2可在主窗外弹出的弹窗_2more.md
This document provides Cangjie code examples demonstrating advanced configurations for AlertDialogs in HarmonyOS development. It covers two specific scenarios: displaying a dialog outside the main window and customizing the dialog's visual style. Key information includes using AlertDialogParamWithOptions with showInSubWindow set to true to enable sub-window display and handling dismissal events. The second example utilizes AlertDialogParamWithConfirm to demonstrate styling properties such as dimensions, border styles, corner radius, and shadow effects. The target audience is HarmonyOS developers using the Cangjie language who need to implement or customize alert dialogs in their UI applications.
