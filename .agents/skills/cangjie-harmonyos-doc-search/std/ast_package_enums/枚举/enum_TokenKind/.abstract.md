This directory contains API documentation for the `TokenKind` enumeration in the Cangjie programming language. It defines the complete set of lexical tokens used by the compiler, including keywords, operators, punctuation, and data types. The documentation is split across multiple files, covering everything from basic arithmetic operators to complex control flow structures and type definitions. It is intended for compiler developers and language engineers working on parsing, syntax analysis, or tooling for the Cangjie language.
