# cj-text-introduction

## 详细说明

### cj-text-introduction.md cj-text-introduction.md
本文档旨在介绍系统中的文本组件，阐述其在构建用户交互界面中的作用，并指导开发者根据场景选择合适的组件。主要涵盖文本元素的定义及其在UI中的功能，并详细列出了文本显示、文本输入和富文本编辑三类核心组件。关键信息包括：Text和Span用于显示静态文本；TextInput和TextArea适用于纯文本的单行或多行输入；RichEditor则支持插入图片或自定义图标等富文本需求。该文档面向使用ArkUI框架进行页面开发的开发者，属于组件概览类指南。
