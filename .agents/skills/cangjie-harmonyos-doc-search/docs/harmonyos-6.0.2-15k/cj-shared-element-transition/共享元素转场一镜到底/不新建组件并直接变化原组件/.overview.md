# 不新建组件并直接变化原组件

This directory serves as an essential resource for developers working with ArkUI and HarmonyOS, focusing on the sophisticated technique of modifying existing component instances to achieve fluid animations instead of creating new components. This approach is vital for optimizing rendering performance and ensuring smooth user experiences during complex layout changes. The guides delve into the integration of component transitions with attribute animations, the utilization of `animateTo` for state interpolation, and the application of `TransitionEffect` for managing opacity and visibility. Targeted at UI developers proficient in Cangjie or ArkTS, these documents provide practical, code-based examples for handling intricate scenarios such as expandable lists, dynamic image sizing, and container expansion. By following these strategies, developers can ensure their applications remain responsive and visually polished during every state transition.

### 不新建组件并直接变化原组件_1.md

This technical guide explains how to achieve seamless "one-shot" animation effects in ArkUI by modifying existing components rather than creating new ones. It covers the concept of combining component transitions with attribute animations, specifically for scenarios involving container expansion and sibling component visibility changes. The document outlines a two-step process involving state variable construction and binding appear/disappear transitions, illustrated by a Cangjie code example of an expandable post list. This guide targets UI developers familiar with ArkUI and Cangjie syntax who need to implement complex layout transitions.

### 不新建组件并直接变化原组件_2.md

This document demonstrates how to implement an expandable UI component in ArkTS by modifying the state of an existing component instance rather than creating a new one, ensuring smooth layout transitions. The code covers the layout structure using Row and Column, image rendering with ForEach, conditional rendering for a comment section, and the implementation of click events with animateTo to handle state changes and layout animations. Key takeaways include the use of TransitionEffect for opacity animations, the animateTo function to interpolate state variables like itemHeight and avatarSize, and the logic for dynamically calculating image sizes based on the expansion state. This technical guide targets HarmonyOS developers familiar with ArkTS and declarative UI, specifically those looking to optimize performance and user experience in list interactions.
