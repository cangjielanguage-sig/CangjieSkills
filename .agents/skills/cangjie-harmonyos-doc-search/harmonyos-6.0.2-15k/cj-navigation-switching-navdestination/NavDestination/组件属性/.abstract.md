This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It primarily focuses on customizing Navigation components, including setting back button icons, managing system status bar styles, and configuring navigation titles and menus. The documentation covers specific function signatures, parameter types, and boundary conditions for layout extensions. It is suitable for Cangjie developers and UI designers looking to programmatically control the appearance and behavior of navigation headers, status bars, and layout safety areas in their applications.
