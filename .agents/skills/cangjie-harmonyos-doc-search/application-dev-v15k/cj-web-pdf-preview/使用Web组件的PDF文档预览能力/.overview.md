# 使用Web组件的PDF文档预览能力

This directory provides a comprehensive technical guide designed to help developers implement robust PDF document preview functionality using the Web component within the ArkUI framework. It thoroughly covers essential implementation details across various loading scenarios, including network PDFs, local sandbox files, and application resource files, while explicitly detailing necessary permissions like internet and file system access. Furthermore, the guide explores advanced customization options through URL parameters to control the viewing experience, such as zoom levels, page numbers, and toolbar visibility. It also clarifies the differences between static `src` usage and dynamic `loadUrl()` updates. Targeted specifically at developers utilizing the Cangjie language, this resource offers step-by-step instructions and practical code examples to effectively integrate and enhance PDF viewing capabilities in their applications.

## Detailed Description

### 使用Web组件的PDF文档预览能力_1.md 使用Web组件的PDF文档预览能力_1.md
This guide explains how to implement PDF document preview functionality within applications using the Web component. It covers three loading scenarios: network PDFs, local sandbox files, and application resource files, detailing necessary permissions like internet access and file system access. Key takeaways include using the src parameter or loadUrl() interface, noting that src is static and requires loadUrl() for dynamic updates. Code examples demonstrate enabling domStorageAccess and fileAccess. Targeted at developers using the Cangjie language and ArkUI framework, this tutorial provides step-by-step implementation for integrating PDF viewing.

### 使用Web组件的PDF文档预览能力_2.md 使用Web组件的PDF文档预览能力_2.md
This technical guide explains how to implement and configure PDF document preview capabilities within a Web component using the Cangjie language. It covers resource loading methods, specifically comparing `@rawfile` and resource path strings, and details supported URL parameters for view control. Key information includes the ability to manipulate the initial display state using parameters such as `page`, `zoom`, `toolbar`, and `navpanes` appended to the file URL. The document notes that the `@rawfile` method does not support these parameters, while the string resource path does. This reference is intended for application developers seeking to customize PDF viewing experiences in their apps.
