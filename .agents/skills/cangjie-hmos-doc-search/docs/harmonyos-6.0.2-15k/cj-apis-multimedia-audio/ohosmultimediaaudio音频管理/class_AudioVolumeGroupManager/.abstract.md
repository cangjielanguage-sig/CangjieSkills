This directory contains API reference documentation for the `AudioVolumeGroupManager` class in the Cangjie programming language, part of the AudioKit framework. It covers comprehensive audio volume management functionalities, including querying volume levels, amplitude, ring modes, mute states, and device-specific properties. The documentation details synchronous functions for retrieving system audio metrics and methods for subscribing to audio state changes like microphone and ring mode updates. It is suitable for software developers and multimedia engineers integrating precise audio control and monitoring capabilities into their applications.
