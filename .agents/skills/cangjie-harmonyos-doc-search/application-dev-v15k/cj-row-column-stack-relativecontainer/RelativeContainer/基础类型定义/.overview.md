# 基础类型定义

This directory contains API reference documentation for fundamental layout classes and enumerations in the Cangjie language within the ArkUI framework. It covers definitions for barriers and guidelines used to create complex, responsive UI layouts. Key components include `BarrierStyle`, `GuideLineStyle`, `GuideLinePosition`, and localized barrier configurations supporting internationalization. These resources are essential for ArkUI developers who need to implement dynamic layout constraints, alignment rules, and adaptive interfaces in HarmonyOS applications.

Key information includes that both properties accept nullable Length types to specify distances from container edges: start measures from the left or top, while end measures from the right or bottom. This reference is intended for ArkUI developers using the Cangjie language who need to configure layout guidelines, requiring familiarity with the Length type and system capabilities.

### class_GuideLineStyle.md class_GuideLineStyle.md
This API reference document details the GuideLineStyle class in the Cangjie language, used to define guidelines within ArkUI layouts. The documentation covers the class constructor and its three public properties: id, direction, and position. Key information includes that the direction property determines if the guideline is vertical or horizontal, which dictates valid anchor points for components. The position property sets the guideline's location, defaulting to start: 0 if unspecified, and requires unique IDs to avoid conflicts. This resource is intended for ArkUI developers using Cangjie to implement complex layout constraints and alignment rules.

### enmu_LocalizedBarrierDirection.md enmu_LocalizedBarrierDirection.md
This API reference document defines the LocalizedBarrierDirection enum for the Cangjie language within the ArkUI framework. It specifies the directional positioning of barrier lines relative to referenced UI components, specifically supporting mirroring modes for internationalization. The document details four enumeration values: START, END, TOP, and BOTTOM. Key takeaways include that START and END dynamically switch between left and right sides depending on LTR or RTL layout modes, whereas TOP and BOTTOM remain static. This documentation targets developers implementing adaptive user interfaces in HarmonyOS, requiring knowledge of layout constraints and system capabilities available from version 19.
