### 获取应用文件路径_1.md 获取应用文件路径_1.md
This technical guide explains how to retrieve application file paths using the Context class and its subclasses within the HarmonyOS framework. It distinguishes between application-level paths obtained via ApplicationContext and module-level paths accessed through AbilityStageContext, UIAbilityContext, and ExtensionContext. Key takeaways include the lifecycle differences: application-level files persist until the app is fully uninstalled, whereas module-level files are deleted when the specific HAP is removed. The document provides a detailed comparison table of directory attributes like cacheDir, filesDir, and databaseDir. This information is essential for developers managing data storage and understanding application sandbox directories.
