This directory provides comprehensive API reference documentation for the `cj-apis-hi_tracechain` module, specifically designed for the Cangjie programming language within the HarmonyOS ecosystem. It focuses on the critical domain of distributed tracing, enabling developers to track and manage service calls across complex, interconnected environments. The documentation details the `ohos.hi_tracechain` module, offering the structural definitions needed to configure and manage distributed service call chains. Key components covered include the `HiTraceChain` class for lifecycle management, the `HiTraceId` class for unique identification, and various enums for flags and tracepoint types. This resource is essential for HarmonyOS developers and system integrators who require robust tools for performance analysis, fault diagnosis, and monitoring business logic flows that span multiple threads, processes, and devices.
