# 拉起系统应用

This directory provides comprehensive technical documentation on launching system applications and accessing their capabilities within a development framework. It details the mechanisms for interacting with system-level resources, focusing on two primary methodologies: utilizing System Picker components for secure resource access and employing specific interfaces for direct application navigation. Key concepts include system pre-authorization for pickers, which eliminates the need for explicit permission requests, and direct jumps to essential apps like Settings or Calendar. The content covers critical areas such as permission management, file handling, and media integration. This documentation is specifically designed for application developers who aim to integrate system-level features seamlessly, access user resources securely, and enhance application functionality through efficient system interactions. By leveraging these guides, developers can ensure their applications adhere to security best practices while providing robust functionality.

## Detailed Description

The following files provide in-depth technical guidance and reference material for implementing system application launches.

### 拉起系统应用_2more.md
This technical guide outlines methods for launching system applications and accessing their capabilities. It covers two primary approaches: using System Picker components and utilizing specific interfaces for direct jumps. Key information highlights that System Pickers, such as file or photo selectors, allow developers to access user resources without explicit permission requests due to system pre-authorization. Additionally, specific interfaces enable direct navigation to apps like Settings or Calendar. This document is intended for application developers seeking to integrate system-level features or access user resources securely and efficiently.

### 支持跳转系统应用的能力清单.md
This document serves as a reference list detailing the capabilities for launching specific system applications and interfaces. It covers five main areas: Settings, Telephony, Camera, File Management, and Media Library. Key information includes specific APIs for handling permission requests, such as requestPermissionOnSetting for re-prompting denied permissions, and makeCall for initiating dialer actions. It also outlines the use of various Pickers (Camera, Document, Audio, Photo) for accessing and saving system resources. This guide is intended for application developers seeking to integrate system-level interactions, manage user permissions, or access media files within their applications.
