# interface_BaseProfile

This directory contains API reference documentation for the `BaseProfile` interface within the ConnectivityKit, specifically designed for the Cangjie language. It covers the management of Bluetooth profile connections, including methods to subscribe to and unsubscribe from connection state change events. Key topics include event handling, callback registration, device state retrieval, and permission management (specifically `ohos.permission.ACCESS_BLUETOOTH`). This documentation is suitable for HarmonyOS developers looking to implement robust Bluetooth connectivity features, handle asynchronous state changes, and manage error codes within their applications.
