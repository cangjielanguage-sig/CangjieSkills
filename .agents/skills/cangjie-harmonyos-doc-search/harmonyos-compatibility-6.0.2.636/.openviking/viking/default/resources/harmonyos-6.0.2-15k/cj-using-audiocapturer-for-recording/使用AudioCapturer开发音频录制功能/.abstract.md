This directory provides a comprehensive technical guide for implementing audio recording functionality using the AudioCapturer module. It focuses on capturing raw PCM audio data, offering developers granular control over the audio capture process. The content covers the complete development lifecycle, including parameter configuration, state management, and resource release, with code examples provided in both Cangjie and ArkTS. It is suitable for application developers and HarmonyOS engineers with prior audio development experience who need to integrate robust audio capture features into their applications. By following these resources, developers can effectively manage microphone permissions and handle PCM data streams to create high-quality recording applications. This collection ensures a thorough understanding of both theoretical concepts and practical implementation strategies for audio capture, enabling the creation of flexible and powerful audio recording solutions.
