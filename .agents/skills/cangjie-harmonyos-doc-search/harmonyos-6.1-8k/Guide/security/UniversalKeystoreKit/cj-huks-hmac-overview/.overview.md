# cj-huks-hmac-overview

本目录提供了关于HMAC（基于哈希的消息认证码）技术的全面概述，特别是针对OpenHarmony系统中HUKS（通用密钥库系统）的实现细节。文档详细阐述了HMAC的基本工作原理，并明确列出了HUKS所支持的各类算法规格，包括摘要算法类型、密钥长度限制以及对应的API级别要求。特别强调了SHA256、SHA384、SHA512及SM3作为必选规格的重要性，建议开发者在开发过程中优先采用这些算法，以确保应用在不同OpenHarmony设备上的全平台兼容性。该文档主要面向OpenHarmony应用开发者及设备适配厂商，适用于所有涉及消息完整性验证、身份认证及密钥管理的技术场景。
