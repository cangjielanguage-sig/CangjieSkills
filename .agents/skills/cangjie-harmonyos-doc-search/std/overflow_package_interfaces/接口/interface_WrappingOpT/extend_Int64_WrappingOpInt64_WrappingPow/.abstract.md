This directory provides API reference documentation for extending the `Int64` type in the Cangjie programming language with wrapping arithmetic and bitwise operations. It specifically details the implementation of the `WrappingOp` and `WrappingPow` interfaces. The content covers a comprehensive range of operations, including addition, subtraction, multiplication, division, modulo, negation, exponentiation, and bit shifting. A key focus is the high-bit truncation strategy used to handle overflow, ensuring that operations wrap around rather than throwing errors. This documentation is essential for Cangjie developers who require precise control over integer overflow behavior and perform low-level data processing.
