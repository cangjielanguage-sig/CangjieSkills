## Detailed Description

### class_AppEventFilter.md class_AppEventFilter.md
本文档说明AppEventFilter类的用途，用于配置Watcher的订阅过滤条件以筛选特定事件。包含domain（必填）、eventTypes和names（可选命名参数）三个可读写属性，帮助开发者精确控制事件监听范围。

### class_AppEventGroup_d768ee4d.md class_AppEventGroup_d768ee4d.md
本文档定义AppEventGroup类，用于获取订阅返回的事件组参数。包含name（事件名称）和appEventInfos（事件对象集合）两个可读写属性，常用于Watcher的onReceive回调中获取事件组详细信息。

### class_AppEventInfo.md class_AppEventInfo.md
本文档介绍AppEventInfo类，用于定义应用事件追踪参数。涵盖事件领域、名称、类型及参数对象规范，明确了严格的命名规则、支持的数据类型（字符串、数值、布尔及数组）及参数个数限制。

### class_AppEventPackageHolder.md class_AppEventPackageHolder.md
本文档介绍AppEventPackageHolder类，用于处理应用事件的订阅数据。包含构造函数、设置数据大小阈值的setSize方法及获取订阅事件的takeNext方法，支持按字节大小或条数阈值获取事件包。

### class_AppEventPackage_dc85a634.md class_AppEventPackage_dc85a634.md
本文档定义AppEventPackage类，用于封装订阅返回的事件包参数。包含data数组、自动递增的packageId、row（事件数量）和size（字节大小）四个核心可读写属性，用于解析通过takeNext接口获取的事件数据。

### class_AppEventReportConfig.md class_AppEventReportConfig.md
本文档说明AppEventReportConfig类，用于定义数据处理者上报事件的配置。包含domain、name和isRealTime三个核心属性，明确了各属性的命名规范（如字符类型、长度限制）及读写权限。

### class_ConfigOptio_2more_254ccdc4.md class_ConfigOptio_2more_254ccdc4.md
本文档涵盖ConfigOption和Domain两个类。ConfigOption提供disable开关和maxStorage存储配额设置，阐明了配额规格及FIFO清理机制；Domain定义系统领域名称常量，用于控制事件上报及存储策略。

### class_Event.md class_Event.md
本文档定义Event类，包含APP_CRASH、APP_FREEZE、USER_LOGIN等静态常量，用于系统和应用事件名称的标识。这些只读字符串常量供开发者调用Write接口时使用，区分了系统事件和预留的应用事件。

### class_Param_9c201212.md class_Param_9c201212.md
本文档定义Param类，包含USER_ID、DISTRIBUTED_SERVICE_NAME和DISTRIBUTED_SERVICE_INSTANCE_ID等静态常量，用于规范事件日志中的关键标识符，适用于分布式系统事件追踪。

### class_TriggerCondition.md class_TriggerCondition.md
本文档说明TriggerCondition类，用于定义Watcher的onTrigger回调触发条件。包含row、size和timeOut三个可读写属性，若设置为0或负值则不触发回调，其中size单位为字节，timeOut单位为30秒。

### enum_EventType_b40e27b5.md enum_EventType_b40e27b5.md
本文档介绍EventType枚举，包含Fault（故障）、Statistic（统计）、Security（安全）和Behavior（行为）四种类型，用于对应用事件进行分类记录，适用于故障排查、统计分析和安全监控场景。

### enum_EventValueType.md enum_EventValueType.md
本文档定义EventValueType枚举，表示事件参数的数据类型。涵盖Int32、Float64、String、Bool、Int64等基础类型及其数组形式的枚举成员，用于应用事件打点或日志记录。
