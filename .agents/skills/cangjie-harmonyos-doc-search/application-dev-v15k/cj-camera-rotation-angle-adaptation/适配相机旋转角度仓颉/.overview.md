# 适配相机旋转角度仓颉

This directory provides a comprehensive technical guide for developers working with camera rotation adaptation using the Cangjie programming language on HarmonyOS. It covers essential topics such as calculating device rotation angles via sensors, adapting camera previews, and handling video recording metadata to ensure correct orientation. Key concepts include CameraKit, MediaKit, gravity sensors, and display rotation synchronization. These resources are specifically designed for software engineers and application developers building responsive camera applications that require precise image alignment across various device orientations and screen states.

## Detailed Description

### 录像.md 录像.md
This document provides a technical guide for handling video rotation during the recording process using CameraKit and MediaKit APIs. It details the steps to retrieve the current video rotation angle based on device orientation and apply it to the recording metadata. Key sections include using the VideoOutput.getVideoRotation method after session configuration and setting the result to AVMetadata.videoOrientation. The document includes a Cangjie code example demonstrating how to pass the device degree to obtain the correct ImageRotation. This guide is intended for developers implementing video recording features who need to ensure proper orientation alignment relative to gravity. Keywords: Video recording, rotation, VideoOutput, AVMetadata, CameraKit, Cangjie, device orientation.

### 计算设备旋转角度.md 计算设备旋转角度.md
This technical guide demonstrates how to calculate a device's rotation angle using gravity or accelerometer sensor data in the Cangjie programming language. The document covers prerequisite permissions, sensor availability checks, and the implementation of callback handlers. Key information includes the mathematical logic using trigonometric functions to convert x and y coordinates into a normalized 0-360 degree angle, with a fallback mechanism to the accelerometer if the gravity sensor is unsupported. Intended for HarmonyOS developers, this tutorial provides the necessary code snippets and logic to implement device orientation features effectively.

### 适配相机旋转角度仓颉_2more.md 适配相机旋转角度仓颉_2more.md
This development guide instructs developers on how to adapt camera image rotation angles across different screen states and device orientations using the Cangjie language. It covers session creation, preview adaptation, photo and video recording, and calculating device rotation angles. The guide distinguishes between preview rotation, which relies on Display.rotation, and capture rotation, which depends on device gravity. It provides code examples for importing modules and creating sessions via CameraManager with specific SceneMode settings. This tutorial targets application developers working on camera functionality who need to ensure correct image orientation in various usage scenarios.

### 预览/
This directory serves as a comprehensive technical resource for developers implementing camera preview functionality, with a specific focus on rotation management and synchronization. It provides detailed guides and practical code examples demonstrating how to align the camera preview stream with the device's display orientation using the CameraKit API. Key concepts covered include calculating rotation angles, handling the `isDisplayLocked` parameter, and registering event listeners for dynamic updates. The materials are specifically tailored for software engineers utilizing the Cangjie language, ArkUI framework, or ArkTS to build responsive camera applications that adapt seamlessly to screen orientation changes.
