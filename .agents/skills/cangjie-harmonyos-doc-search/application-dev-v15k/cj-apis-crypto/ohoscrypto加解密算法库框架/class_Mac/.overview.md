# class_Mac

This directory provides comprehensive API reference documentation for the Mac class within the Cangjie programming language's CryptoFramework. It is dedicated to Message Authentication Code (MAC) encryption calculations, covering the full spectrum of necessary properties and methods for cryptographic operations. Key topics include symmetric key initialization, sequential data processing via updates, and final result retrieval. This documentation is specifically suitable for developers implementing security features who need to master the workflow of MAC generation, from key setup and data feeding to final computation. It addresses critical aspects such as error handling, system capability requirements, version constraints, and specific parameter types like SymKey and DataBlob, serving as a robust guide for secure application development in the Cangjie environment.
