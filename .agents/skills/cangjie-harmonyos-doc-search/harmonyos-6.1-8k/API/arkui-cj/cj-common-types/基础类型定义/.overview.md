# 基础类型定义

本目录包含ArkUI框架中仓颉（Cangjie）语言的基础类型API参考文档，涵盖了UI开发所需的核心数据结构。内容主要包括几何属性（Area、Offset）、样式配置（Color、Font、Shadow）、交互事件（Event、Gesture）、布局对齐（Alignment、Flex）以及动画参数等。这些文档为开发者提供了构建HarmonyOS应用界面的底层类型规范和接口说明。适用于使用仓颉语言进行ArkUI应用开发的程序员，旨在帮助他们掌握基础数据类型的使用方法，实现精细化的UI布局与交互控制。

## 详细描述

### Subdirectories
包含AlignRuleOption（对齐规则）、AnimateParam（动画参数）、ContextMenuOptions（菜单配置）、CustomPopupOptions（自定义弹窗）、PopupOptions（弹窗配置）、SheetOptions（半模态配置）、ContentType（自动填充类型）、RenderFit（缩放模式）及LengthProp（长度属性接口）等API文档，支持精细化的UI布局、动画、弹窗及样式控制。

### Geometry & Layout Classes
涵盖Area（区域几何）、HorizontalAlignParam（对齐参数）、LengthMetrics（长度单位）、Margin（外边距）、Offset（偏移量）、Position（位置）及Rectangle（矩形）等类，用于定义组件的尺寸、位置及布局约束。

### Style & Appearance Classes
包含Color（颜色）、EdgeStyles（边框样式）、Font（字体）、ShadowOptions（阴影）等类，用于配置组件的视觉外观，如颜色、边框、字体及阴影效果。

### Event & Interaction Classes
定义BaseEvent（事件基类）、KeyEvent（按键）、MouseEvent（鼠标）、TouchEvent（触摸）及TouchObject（手指信息）等类，用于处理用户交互事件及输入响应。

### Popup & Modal Classes
包含BindOptions（半模态属性）、ContentCoverOptions（全屏模态转场）、DismissPopupAction（弹窗关闭）、SheetOptions（半模态配置）等类，用于管理弹窗、模态页面的显示、关闭及交互逻辑。

### Enums
涵盖Alignment（对齐）、Direction（方向）、FlexAlign（弹性布局）、ImageFit（图片适配）、Curve（动画曲线）、GestureMode（手势模式）、Visibility（可见性）等大量枚举，用于定义组件的布局行为、样式选项、交互状态及动画参数。

### Interfaces & Types
包含ResourceColor（资源颜色）、Length（长度接口）、VoidCallback（回调类型）等接口及类型别名，提供基础数据结构支持及函数签名定义。
