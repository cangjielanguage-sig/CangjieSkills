This directory provides comprehensive documentation for HarmonyOS system permissions that are explicitly restricted from Access Control List (ACL) applications. It focuses on high-privilege capabilities required for system-level operations, such as managing distributed hardware, controlling system lights, and handling user authentication. The documents outline specific permission levels (system_basic), authorization methods (system_grant), and API version constraints. These resources are critical for system developers and application engineers who need to implement sensitive features, understand the boundaries of ACL usage, and ensure their applications meet the necessary privilege requirements for accessing core system functionalities without standard ACL authorization. By referencing these files, developers can navigate the complex landscape of system authorization and ensure compliance with HarmonyOS security standards.
