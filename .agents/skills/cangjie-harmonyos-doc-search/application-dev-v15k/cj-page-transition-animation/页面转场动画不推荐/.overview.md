# 页面转场动画不推荐

This directory provides technical documentation and code examples for implementing page transition animations within the Cangjie UI framework. It covers the configuration of `RouteType` (None, Push, Pop), methods to disable specific page transitions, and the underlying mechanics of `PageTransitionEnter` and `PageTransitionExit`. Although the directory title indicates this approach is not recommended in favor of navigation or modal transitions, it serves as a reference for developers needing legacy or specific custom routing logic. The content is suitable for Cangjie developers looking to fine-tune navigation behaviors, manage page stack operations, and understand the nuances of animation properties like slide, scale, and opacity.
