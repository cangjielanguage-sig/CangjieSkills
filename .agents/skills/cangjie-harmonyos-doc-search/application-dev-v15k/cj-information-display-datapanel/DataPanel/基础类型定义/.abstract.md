This directory provides essential API references for basic type definitions within the Cangjie ArkUI framework, focusing on data visualization and UI styling components. It includes detailed documentation for shadow options, linear gradients, and data panel layout types. These resources are designed for developers working with HarmonyOS applications who need to implement sophisticated visual effects and configure data presentation styles. By understanding these fundamental types, developers can effectively customize the appearance and behavior of UI elements using the Cangjie language.
