The `cj-hitrace` directory functions as a comprehensive resource hub for the hitrace command-line tool, which is essential for tracking business process call chains and diagnosing system faults. It covers the full spectrum of trace management, including environment setup with the hdc tool, capturing, configuring, and dumping traces. Key topics include snapshot mode, buffer size parameters, duration settings, and clock synchronization. Additionally, it details how to generate binary trace files for visualization using the HiSmartPerf tool. This documentation is tailored for developers, QA engineers, and performance specialists working within HarmonyOS and OpenHarmony environments who require granular diagnostic capabilities to analyze system performance and resolve complex distributed issues.
