# cj-huks-key-agreement-overview

本文档是OpenHarmony通用密钥库系统（HUKS）关于密钥协商功能的参考指南，旨在为开发者提供全面的技术概览。文档深入阐述了密钥协商的基本概念与核心原理，重点讲解了如何通过公钥交换机制实现安全密钥共享，从而有效规避私钥在传输过程中的泄露风险。内容涵盖了OpenHarmony平台支持的详细算法规格，特别强调了ECDH、DH和X25519这三种必选算法，这些算法均支持API 15及以上版本，是保障应用兼容性的首选。本文档适合OpenHarmony应用开发者及安全架构师阅读，有助于其深入理解底层安全机制，并在开发过程中正确选择和实施符合标准的密钥协商算法。

## 详细描述

### cj-huks-key-agreement-overview.md

本文档旨在介绍密钥协商的基本概念及OpenHarmony支持的算法规格。主要涵盖密钥协商原理介绍和算法规格表。核心信息指出，密钥协商通过交换公钥实现安全密钥共享，避免私钥传输。文档列出了ECDH、DH和X25519三种必选算法，均支持API 15及以上版本，建议开发者使用必选规格以保障兼容性。该文档属于参考指南，面向OpenHarmony开发者，旨在帮助其理解安全机制并正确选择算法。
