This directory provides comprehensive API reference documentation for the HilogChannel class and associated logging utilities within the Cangjie language ecosystem. It is designed to assist developers in implementing structured logging for applications and services, covering essential features such as log type definition, domain tagging, and various logging levels including debug, info, error, and fatal. Additionally, it includes functions for log level verification and warning outputs. This documentation is specifically tailored for Cangjie developers utilizing the SystemCapability.HiviewDFX.HiLog capability to ensure effective system monitoring and debugging.
