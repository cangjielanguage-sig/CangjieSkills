This directory contains comprehensive documentation for the Toggle component within the ArkUI framework, specifically designed for the Cangjie language. It covers the implementation and customization of interactive controls, including Checkbox, Button, and Switch styles. The content includes API references for constructors, events, and visual properties, alongside practical code examples for styling and state management. Suitable for HarmonyOS developers and software engineers building user interfaces, this resource provides the necessary technical details to integrate and configure toggle elements effectively in applications.
