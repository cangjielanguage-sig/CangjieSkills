This directory contains comprehensive API reference documentation for fundamental Cangjie language components within the ArkUI framework, specifically designed to support navigation and UI lifecycle management. It details essential data structures and enumerations, including classes for managing navigation states and path stacks, as well as enums defining visibility change reasons. Key topics cover the configuration of navigation titles, modes (Standard or Dialog), and the handling of UI events triggered by app state switches or page transitions. This documentation is intended for developers implementing navigation logic and page stack management in ArkUI applications, offering the necessary definitions, constructors, and parameter requirements for API version 19 and above.
