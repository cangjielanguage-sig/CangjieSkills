# 广播与扫描

This directory provides a comprehensive guide to Bluetooth Low Energy (BLE) broadcasting and scanning functionalities within the ConnectivityKit. It covers the core mechanisms required for low-power device discovery, including the initialization, management, and optimization of wireless communication links. Key topics include API methods for starting and stopping advertising, scanning processes, event subscription callbacks, and full lifecycle management. This documentation is specifically tailored for software developers using the Cangjie language, ArkTS, or similar frameworks targeting HarmonyOS and OpenHarmony platforms who need to implement robust device interconnectivity solutions.

It covers the primary scenarios of starting and stopping both advertising and scanning processes to enable low-power device discovery.
