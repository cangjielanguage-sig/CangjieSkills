# cj-camera-metadata

This directory acts as a centralized resource for developers implementing camera metadata handling using the Cangjie programming language. It specifically addresses the integration of descriptive image data, focusing heavily on face detection functionalities within modern camera applications. The provided materials cover the entire development lifecycle, ranging from the initial definition of metadata and the creation of output streams to the active management of capture sessions. Key technical topics include the utilization of TAG/Key pairs for memory optimization and the execution of specific API calls such as `createMetadataOutput` and `Session.start`. Furthermore, the directory details the requirements for status monitoring, including registering callbacks for data availability and managing business exceptions. This content is tailored for camera application developers who possess a solid understanding of camera preparation and permission application, offering the necessary tools to build responsive and data-rich features.
