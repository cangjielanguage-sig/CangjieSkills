# class_BundleManager

This directory contains API reference documentation for the Cangjie `BundleManager` class within the HarmonyOS ecosystem. It covers methods for querying application bundle information, verifying URL accessibility, and retrieving JSON configuration profiles from modules. Key functionalities include getting bundle info by name or UID, checking link capabilities, and accessing metadata for abilities and extension abilities. This documentation is suitable for Cangjie developers and application engineers working with the AbilityKit who need to manage system bundle data, implement deep linking, or programmatically access application configuration files like `module.json5`.
