# ohossettings设置数据项名称

This directory contains API reference documentation for the `ohos.settings` module in the Cangjie programming language, specifically focusing on data item names and system settings management. It covers a wide range of configuration options including wireless connectivity, display parameters, input methods, network settings, sound, and text-to-speech. The documentation details enumerations, classes, and functions used to query and modify device states, requiring the SystemCapability.Applications.Settings.Core capability. It is intended for HarmonyOS developers and system integrators working with version 19 or higher who need to programmatically control device behavior and user preferences.

## Detailed Description

### class_WirelessAirplantMode_2more.md
This document defines the WirelessAirplantMode class and Date enum for managing airplane mode radios (Bluetooth, Cellular, NFC, Wi-Fi) and date-time formats. It targets developers using the SystemCapability.Applications.Settings.Core capability to control which radios are disabled and how dates are displayed.

### enum_Display.md
This document provides the API reference for the Display enum, which controls visual parameters such as screen brightness (0-255), font scaling, screen rotation, animation speeds, and sleep timeouts. It includes the toString() method and is intended for Cangjie developers.

### enum_DomainName.md
This document defines the DomainName enum used to categorize query domains within the system settings core. It distinguishes between device properties (DEVICE_SHARED) and user-specific attributes (USER_PROPERTY), helping developers manage different property domains.

### enum_Input.md
This document defines the Input enum for configuring system input method settings. It covers members like DEFAULT_INPUT_METHOD and toggles for text editing behaviors such as auto-capitalization and password visibility, using specific value formats for lists and binary toggles.

### enum_Network_2more.md
This document defines enumerations for network and phone functionalities. It covers the Network enum (data roaming, HTTP proxy) and the Phone enum (Real-Time Text calling status), allowing developers to query or modify device network and telephony settings.

### enum_Sound.md
This document defines the Sound enum for configuring device sound effects and audio settings. It includes controls for vibration behaviors, default ringtones, and haptic feedback, targeting system developers managing audio configurations.

### enum_TTS.md
This document defines the TTS enum for Text-to-Speech settings. It details members for pitch, rate, and engine selection (e.g., DEFAULT_TTS_SYNTH), providing application developers with the tools to manage speech conversion capabilities.

### enum_Wireless.md
This document defines the Wireless enum for configuring wireless network settings. It includes members for Bluetooth discoverability, Wi-Fi DHCP retry counts, and airplane mode radio lists, assisting developers in managing device connectivity.

### func_getValueT_PStageCo_6eeef7d5.md
This document details the getValue function, which retrieves the value of a specific data item from system settings. It uses generics for the name and domain, supports different domains like DEVICE_SHARED, and requires a StageContext.

### func_registerKeyObserverT_PStageContext_T_8139f6e7.md
This document describes the registerKeyObserver function, designed to register an observer for monitoring changes to specific data keys within a defined domain. It includes parameters for context, name, domain, and observer callbacks.

### func_unregisterKeyObserver_2more.md
This document details the unregisterKeyObserver function for removing key observers and the DisplayAutoScreenBrightnessMode class, which defines static constants for auto and manual screen brightness modes.

### ohossettings设置数据项名称_6more.md
This document serves as the module overview for ohos.settings, covering module imports, usage instructions, and specifications for functions like getUriSync and getValue. It supports both existing database items and custom developer-defined items.

### enum_General/
This directory contains API reference documentation for the General enum, defining system configuration constants for managing general settings like geolocation origins, airplane mode status, accessibility features, and device naming. It is essential for system developers integrating device management features.
