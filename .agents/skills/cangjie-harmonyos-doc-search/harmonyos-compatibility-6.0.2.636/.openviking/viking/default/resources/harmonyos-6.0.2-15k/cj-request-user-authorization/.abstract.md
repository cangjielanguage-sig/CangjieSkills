This directory serves as a comprehensive technical guide focused on the mechanisms of requesting runtime user authorization within HarmonyOS applications developed using the Cangjie language. It thoroughly covers the procedures for implementing permission dialogs, verifying authorization status via access tokens, and managing user responses effectively. The content highlights essential constraints such as dialog visibility, frequency limits, and the specific timing requirements within the `onWindowStageCreate` lifecycle. This resource is specifically designed for application developers utilizing the AbilityKit framework who need to securely integrate sensitive system capabilities while maintaining a seamless and compliant user experience.
