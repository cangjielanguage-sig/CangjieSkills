# ohosresource_manager资源管理

本目录提供了基于仓颉语言的HarmonyOS资源管理模块API参考文档。它涵盖了应用资源的获取、配置管理、设备能力适配以及本地化支持等核心功能。主要内容包括Configuration（设备配置）、DeviceCapability（设备能力）、相关枚举类型以及ResourceManager类的详细接口说明。该模块旨在帮助开发者根据当前设备环境（如语言、屏幕密度、方向）动态适配资源，适用于需要进行国际化处理和多设备适配的HarmonyOS应用开发人员。

## 详细描述

### class_Configuration.md class_Configuration.md
本文档是 Configuration 类的 API 参考文档，旨在定义和表示当前设备的状态。文档详细列出了该类的公共属性，包括屏幕方向、语言地区、设备类型、屏幕密度、颜色模式以及移动国家码和网络码。所有属性均为可读写类型，属于 SystemCapability.Global.ResourceManager 系统能力，起始版本为 22。该文档面向使用 Cangjie 语言进行资源管理的开发者，提供了设备配置信息的完整数据结构定义，帮助开发者获取和设置设备环境参数。

### class_DeviceCapability_31931676.md class_DeviceCapability_31931676.md
本文档是Cangjie语言的API参考文档，定义了DeviceCapability类，用于表示设备支持的能力。主要内容包括类的定义及其两个公共属性：deviceType（设备类型）和screenDensity（屏幕密度）。关键信息指出该类属于SystemCapability.Global.ResourceManager系统能力，起始版本为22，用于获取当前设备的硬件特性。文档面向使用资源管理器的开发者，旨在帮助其根据设备类型和屏幕密度进行应用适配。

### enum_ArgsValueTyp_4more_998e57b2.md enum_ArgsValueTyp_4more_998e57b2.md
本文档是仓颉语言中关于全局资源管理的API参考文档，定义了四个核心枚举类型。主要涵盖ArgsValueType（格式化字符串参数）、ColorMode（颜色模式）、DeviceType（设备类型，目前仅支持手机和平板）及Direction（屏幕方向）。所有枚举均属于SystemCapability.Global.ResourceManager系统能力，起始版本为22。文档面向仓颉开发者，提供了资源管理相关的类型定义，旨在帮助开发者处理不同设备和环境下的资源适配问题。

### enum_NumberValueT_2more_2d052fb2.md enum_NumberValueT_2more_2d052fb2.md
这是一份Cangjie语言的API参考文档，定义了资源管理模块中用于表示数值类型和屏幕密度的枚举。文档主要包含NumberValueType枚举（涵盖Int32和Float32等数值包装）和ScreenDensity枚举（涵盖从低密度到超特高密度的多种屏幕规格）。所有枚举成员均具备SystemCapability.Global.ResourceManager系统能力，起始版本为22，旨在规范资源数据的类型表示与屏幕适配。该文档面向需要处理资源数值及屏幕适配逻辑的应用开发者。

### ohosresource_mana_3more_a8983dd5.md ohosresource_mana_3more_a8983dd5.md
本文档介绍ohos.resource_manager模块，该模块提供基于当前配置获取应用资源的能力。主要涵盖模块概述、配置参数（如语言、区域、屏幕方向、分辨率等）、模块导入方式及仓颉代码示例的使用说明。模块根据包含语言、区域、设备类型及分辨率等信息的Configuration动态适配资源。使用时需导入kit.LocalizationKit，示例代码需在仓颉模板工程中运行，部分场景需配置Context。本文档面向使用仓颉语言进行HarmonyOS应用开发的开发者，属于API参考文档。

### class_ResourceManager/
本目录包含仓颉语言中ResourceManager类的API参考文档，旨在为HarmonyOS应用开发者提供全面的资源管理指南。内容涵盖了资源访问、覆盖、配置获取以及本地化适配等核心功能，包括字符串、媒体文件、RawFile、布尔值及数值资源的读取与处理。该文档详细介绍了相关函数的参数、返回值及异常处理机制，适用于使用仓颉语言进行应用开发并需要高效管理应用及系统资源的开发人员。
