This directory contains the essential API reference documentation for exception handling mechanisms within the Abstract Syntax Tree (AST) library of the Cangjie programming language. It provides a detailed breakdown of the error hierarchy, specifically focusing on three critical exception classes: `ASTException` for handling general library errors, `MacroContextException` for addressing macro context interface issues, and `ParseASTException` for managing node parsing failures. These classes are architecturally designed to inherit from the core `Exception` type, ensuring a unified approach to error management. Each class supports two distinct constructors: a default initializer for standard cases and a parameterized constructor that accepts a custom error message string for more granular error reporting. This documentation is highly suitable for software developers, compiler engineers, and language tool creators who are integrating the Cangjie AST library into their workflows. It serves as a vital guide for understanding specific error types, enabling the implementation of robust error handling and improving the stability and debuggability of applications that perform complex AST manipulation and parsing. By referencing this document, users can ensure their code adheres to standard error management practices within the Cangjie ecosystem.
