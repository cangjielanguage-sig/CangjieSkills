# 布局子元素在主轴上的排列方式

本目录主要介绍在UI布局系统中如何控制子元素在主轴上的排列方式。核心内容围绕 `justifyContent` 属性展开，涵盖了从起始端、结束端到空间均匀分割等多种对齐策略。文档特别针对 ArkUI 框架下的 Column 和 Row 容器进行了详细说明，并提供了 Cangjie 语言的代码示例。这适合需要掌握 Flex 布局对齐技巧、进行精准 UI 界面调整的开发人员参考。

### 布局子元素在主轴上的排列方式_5e8d3980.md 布局子元素在主轴上的排列方式_5e8d3980.md
本文档旨在介绍如何使用justifyContent属性来控制布局容器内子元素在主轴上的排列方式。文档主要涵盖了主轴排列的基本概念，以及从起始位置、结束位置或均匀分割空间等不同的排列选项。核心信息在于justifyContent属性提供了灵活的布局控制，支持从主轴起始端、结束端开始排布，或对主轴空间进行均匀分割。该文档适用于使用该布局系统的开发人员，作为UI布局调整的参考指南。

### Column容器内子元素在垂直方向上的排列/
本目录详细介绍了在 ArkUI 框架中使用 Cangjie 语言时，如何控制 Column 容器内子元素的垂直排列。重点讲解了 `justifyContent` 属性的使用，涵盖了 Start、Center、End、SpaceBetween、SpaceAround 和 SpaceEvenly 六种对齐模式。文档包含详细的 Cangjie 代码示例及效果图，旨在帮助开发者理解 FlexAlign 枚举值如何控制子元素在垂直轴上的分布、间距及对齐位置，从而实现精准的 UI 布局。适用于使用 ArkUI 和 Cangjie 语言的开发者。

### Row容器内子元素在水平方向上的排列/
本目录主要介绍在ArkUI框架中，如何使用Row容器控制子元素在水平方向上的排列方式。内容涵盖了`justifyContent`属性的六种FlexAlign取值（如Start、Center、SpaceEvenly等）及其布局效果，并提供了基于Cangjie语言的代码示例。该文档适合正在学习ArkUI布局管理和Cangjie语言的开发者，旨在帮助掌握Flex布局中的水平对齐与间距控制技巧。
