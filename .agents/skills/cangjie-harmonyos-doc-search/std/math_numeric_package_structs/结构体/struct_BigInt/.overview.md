This directory contains comprehensive API documentation for the `BigInt` struct in the Cangjie programming language, designed for arbitrary-precision signed integer calculations. The documentation includes details on interface implementations such as `Comparable`, `Hashable`, and `Formattable`, alongside specific extensions for parsing and radix conversion. This resource is suitable for Cangjie developers requiring high-precision arithmetic capabilities, handling large numbers, or performing complex mathematical operations with robust error handling and overflow strategies.
