# 开发示例

This directory serves as a practical guide for developers aiming to implement robust application stability features using the Cangjie language and AbilityKit framework. It focuses on critical mechanisms for application self-recovery and data preservation, ensuring that apps can gracefully handle crashes and unexpected terminations. The content covers essential procedures such as invoking recovery functions, configuring manifest files, and managing state restoration. By following these examples, developers can learn how to prevent data loss and maintain a seamless user experience during error events. This resource is ideal for software engineers and application developers who need to integrate advanced error recovery and state management capabilities into their projects to enhance overall software reliability.

## Detailed Description

### 使能开启自恢复特性_2more.md 使能开启自恢复特性_2more.md

This technical guide instructs developers on enabling the application self-recovery feature to improve app stability. The document covers two primary implementation steps: invoking the enableAppRecovery function within the AbilityStage initialization using Cangjie code, and configuring the module.json5 manifest file to mark specific abilities as recoverable. Key information includes the specific parameters for the recovery function, such as restart flags and save modes, and the necessary JSON attribute recoverable set to true. This guide is intended for application developers who need to implement crash recovery mechanisms in their projects.

### 数据保存和恢复/

This directory serves as a technical resource for developers working with the Cangjie language and the AbilityKit framework, focusing specifically on the critical aspects of data saving and application recovery. It details methodologies for preserving application state during unexpected errors or terminations, ensuring a seamless user experience. The content covers two primary approaches: active state management using `appRecovery` and `ErrorObserver`, and passive state saving via `onSaveState` and launch reason detection. Key technical concepts include handling `wantParams`, identifying `APP_RECOVERY` triggers, and implementing restoration logic within the `onCreate` lifecycle method. These guides are indispensable for developers seeking to enhance application stability, prevent data loss, and implement robust error recovery mechanisms in their software projects.
