# 使用

This directory serves as a comprehensive technical resource for HarmonyOS developers utilizing the Cangjie programming language, specifically focusing on the integration and consumption of HAR (Harmony Archive) packages. It provides essential guidance on how to effectively reference and utilize code modules and assets across different parts of a project. The content covers the syntax and procedures for importing UI components, classes, and methods, as well as accessing non-code resources such as strings and images defined within a module's resource directory. These guides are crucial for developers aiming to build modular, maintainable, and scalable applications by leveraging shared libraries and resource management techniques within the HarmonyOS ecosystem. By following these instructions, developers can ensure smooth dependency management and efficient resource utilization in their Cangjie projects.

## Detailed Description

### 使用_3more.md
This technical guide explains how to reference and utilize HAR (Harmony Archive) dependencies within Cangjie-based HarmonyOS projects. The document details the process of importing specific elements from a configured HAR, focusing on two main areas: referencing Cangjie UI components and referencing classes and methods. It provides practical code examples demonstrating the import syntax for accessing exported resources like MainPage, Log, and custom functions. Key takeaways include the prerequisite of configuring HAR dependencies and the specific syntax for integrating these modules into application logic. This guide is intended for HarmonyOS developers using the Cangjie language to modularize their applications.

### 引用HAR的资源.md
This tutorial serves as a guide for HarmonyOS developers on how to reference resources stored in a HAR module using the Cangjie language. The document focuses on utilizing the `@r` syntax to access string and image resources defined in the HAR's `src/main/resources` directory. Key takeaways include the specific import of `ohos.state_macro_manage.r` and practical code examples showing how to implement `@r(app.string.hello_har)` for text and `@r(app.media.icon_har)` for images within a UI component. This guide is intended for developers building modular applications who need to share and consume resources across different modules.
