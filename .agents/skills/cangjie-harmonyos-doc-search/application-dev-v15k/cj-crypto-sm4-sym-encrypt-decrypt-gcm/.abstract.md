This directory serves as a comprehensive resource for implementing SM4 symmetric encryption and decryption using the Galois/Counter Mode (GCM) within the Cangjie programming environment. It focuses on the SM4_128 algorithm, PKCS7 padding, and the management of authentication tags to ensure data integrity and confidentiality. The content is tailored for Cangjie developers who possess prior knowledge of the CryptoArchitectureKit and fundamental cryptographic concepts. By utilizing the provided guides and APIs, developers can secure their applications with robust encryption standards, covering the complete lifecycle from key generation to data processing.
