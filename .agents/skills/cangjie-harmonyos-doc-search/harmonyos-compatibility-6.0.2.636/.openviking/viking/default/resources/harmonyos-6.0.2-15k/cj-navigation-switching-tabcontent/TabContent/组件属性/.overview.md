# 组件属性

This directory contains API reference documentation specifically focused on component properties within the Cangjie ArkUI framework. It primarily addresses the configuration of the `tabBar` function, providing essential guidance for implementing tab navigation in user interfaces. The documentation covers various function overloads, parameter definitions, system capabilities, and version-specific constraints, such as SVG icon handling. This resource is designed for software developers and UI engineers utilizing the Cangjie language who require detailed technical specifications to build and customize navigation components effectively.

## Detailed Description

### func_tabBarString_6more.md
This document serves as API reference documentation for the `tabBar` function in the Cangjie language, detailing methods to configure TabBar display content within the ArkUI framework. It covers six function overloads that accept combinations of `String` and `AppResource` types, allowing developers to set simple content or distinct icon and text pairs. Key information includes the requirement for version 12 system capabilities and a specific constraint that SVG icon sources must have intrinsic width and height attributes removed to allow proper sizing control. This technical guide is intended for software developers building user interfaces using ArkUI, providing the necessary syntax and parameter definitions for implementing tab navigation components.

### func_tabBar_-_Unit_3more.md
This document provides API reference documentation for three overloaded tabBar functions used to configure TabBar content within the Cangjie ArkUI framework. The content details function signatures, parameters, system capabilities, and version requirements for custom UI callbacks, SubTabBarStyle, and BottomTabBarStyle. Key information includes the necessity of using the @Builder decorator for custom UI descriptions and specific styling behaviors for version 19 styles, such as the lack of underlines and error handling for icons. This reference is intended for developers building user interfaces who need to implement or customize tab navigation components.
