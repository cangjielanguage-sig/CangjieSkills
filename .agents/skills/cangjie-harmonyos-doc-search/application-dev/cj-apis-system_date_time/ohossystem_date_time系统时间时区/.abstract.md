This directory contains API reference documentation for the `ohos.system_date_time` module in the Cangjie programming language, specifically designed for the OpenHarmony (OHOS) environment. It covers functionalities for retrieving system time, calculating uptime, and managing timezone settings. Key components include the `SystemDateTime` class and the `TimeType` enum, which allow developers to distinguish between active uptime and total elapsed time including deep sleep. This documentation is suitable for Cangjie developers working on OHOS applications who need to implement precise time tracking and timezone features using the BasicServicesKit.
