This directory serves as the definitive guide for the structural components of the `encoding_json_stream` package, specifically focusing on the configuration data structures required for JSON serialization in the Cangjie programming language. It provides an in-depth examination of the `WriteConfig` struct, which is the central tool for developers needing to control how data is serialized into JSON format. The documentation covers a broad spectrum of formatting capabilities, ranging from simple static presets like "compact" and "pretty" to complex, mutable properties that manage indentation, newline behavior, and separator spacing. Additionally, it addresses essential functional requirements such as HTML escaping for security and custom date formatting. By outlining specific default values and validation rules for string properties, this directory acts as a crucial reference for backend developers and systems engineers who need to ensure their JSON output meets specific formatting standards and data integrity requirements, whether for APIs, logging, or data exchange. This ensures that the generated JSON is both human-readable and machine-parsable according to specific needs.
