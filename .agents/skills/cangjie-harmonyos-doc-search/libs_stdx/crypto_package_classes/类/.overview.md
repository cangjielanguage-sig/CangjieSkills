## Detailed Description

### class_SM4/
This directory provides comprehensive documentation for the SM4 symmetric encryption algorithm implemented in the Cangjie programming language. It encompasses the core `SM4` class definition, detailing its constructor, properties, and supported cryptographic modes such as ECB, CBC, OFB, CFB, CTR, and GCM. The content also covers essential functional APIs for encrypting and decrypting data, supporting both byte arrays and input/output streams for various data sizes. Key technical aspects include key size constraints, initialization vector (IV) requirements, padding mechanisms, and GCM-specific features like Authenticated Encryption with Associated Data (AAD). This resource is designed for software developers and security professionals seeking to integrate robust SM4 encryption into their Cangjie applications.

### class_SecureRandom/
This directory contains API reference documentation for the `SecureRandom` class in the Cangjie programming language, focusing on cryptographically secure pseudo-random number generation. It covers the class constructor, entropy sources, and various methods for generating random data types including integers, floating-point numbers, and byte arrays. The documentation details function parameters, return values, and exception handling for security-sensitive operations. It is suitable for developers building applications requiring high-security standards, such as session key generation, privacy data protection, and cryptographic algorithms.
