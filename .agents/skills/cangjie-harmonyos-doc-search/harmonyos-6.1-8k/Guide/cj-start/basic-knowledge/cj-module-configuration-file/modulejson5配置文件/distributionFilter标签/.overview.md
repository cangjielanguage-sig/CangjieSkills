# distributionFilter标签

本目录包含关于 HarmonyOS 应用包（HAP）分发策略配置的技术文档。主要介绍 `distributionFilter` 标签的使用规范，帮助开发者根据设备特性（如屏幕形状、密度、国家代码）实现精准的云端匹配和差异化分发。适用于需要解决多模块工程下应用包分发冲突或针对特定硬件/地域条件进行分发的开发人员。

## 详细描述

### distributionFilter标签.md
这份文档详细说明了 distributionFilter 标签的用途与配置规范，旨在定义 HAP 的分发策略以实现应用市场的精准云端匹配。文档涵盖了适用场景（如多 Entry 设备类型重叠）、四个核心属性（screenShape、screenWindow、screenDensity、countryCode）及其配置规则。关键要点包括属性匹配逻辑、Entry 间配置的一致性要求，以及特定属性仅适用于轻量级穿戴设备的限制。这是一份面向开发者的技术参考文档，用于解决多模块工程下的应用包分发冲突。

### screenShape标签_4more_3f0a7d3b.md
这份文档旨在指导开发者配置应用分发过滤规则，实现基于设备特性的差异化 HAP 分发。文档详细解析了 screenShape、screenWindow、screenDensity 及 countryCode 四个标签的属性定义，重点说明了 policy（包含或排除）与 value 的用法。通过 JSON 示例展示了如何在 distributionFilter_config.json 中定义规则并在 module.json5 中引用。这是一份技术参考文档，适用于需根据设备硬件和地域条件精准分发应用模块的开发人员。
