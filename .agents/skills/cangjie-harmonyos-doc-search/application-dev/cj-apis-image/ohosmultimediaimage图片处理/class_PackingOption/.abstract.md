This directory serves as a comprehensive resource for developers working with the Cangjie programming language, specifically focusing on the `PackingOption` class within the SystemCapability.Multimedia.Image.ImagePacker framework. It provides detailed API reference documentation necessary for configuring image packing and encoding operations. The content covers a wide array of class properties, including format specifications, quality settings, buffer size allocations, desired dynamic range, and property flags. It outlines support for major image formats such as JPEG, PNG, WebP, and HEIC, while also detailing specific quality constraints and buffer requirements. Furthermore, the directory includes documentation for the class constructor, explaining how to initialize objects with parameters for metadata handling and encoding constraints. This documentation is best suited for developers who possess a solid understanding of image processing concepts and Cangjie syntax and are looking to implement robust image encoding solutions in their multimedia applications.
