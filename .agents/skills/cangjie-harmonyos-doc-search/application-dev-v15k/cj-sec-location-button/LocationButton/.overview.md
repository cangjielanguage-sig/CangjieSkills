# LocationButton

This directory contains documentation for the LocationButton component within the ArkUI framework, specifically designed for the Cangjie language. It covers the implementation of a security control that enables users to grant temporary precise location permissions through a single click, bypassing standard dialogs. The content includes API references, basic type definitions for styling and authorization results, and practical code examples for HarmonyOS applications. It is suitable for developers integrating secure location access features and customizing UI elements for location-based scenarios.

### LocationButton_5more.md LocationButton_5more.md
This document serves as API reference documentation for the LocationButton component within the ArkUI framework, specifically for the Cangjie language. It details a security control that allows users to obtain temporary precise location permissions via a click, bypassing standard permission dialogs. Key sections cover component creation methods, including a default constructor and a customizable version accepting icon, text, and button type parameters, as well as the onClick event callback. Important constraints include the requirement for at least an icon or text, static styling properties, and the return of authorization results. This guide is intended for developers implementing secure location access features in their applications.

### 基础类型定义.md 基础类型定义.md
This API reference document defines basic enumeration types for location button components within the ArkUI framework using the Cangjie language. It details three primary enumerations: LocationIconStyle for visual appearance, LocationDescription for text labels, and LocationButtonOnClickResult for authorization status. The document lists specific enum values such as FullFilled and Lines for icons, various text descriptions like CurrentLocation and ShareLocation, and authorization results including Success and TemporaryAuthorizationFailed. It targets developers implementing location-based UI features who need to configure button styles, descriptions, and handle permission logic.
