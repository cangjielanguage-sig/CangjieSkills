This directory provides comprehensive technical documentation on the `@Prop` decorator within the ArkUI framework, focusing on establishing one-way data synchronization between parent and child components. It covers core concepts like synchronization mechanisms, variable passing rules, and usage restrictions. Key topics include initialization constraints, type matching, and deep observation of data changes. This resource is suitable for HarmonyOS developers and UI engineers who need to manage state efficiently, understand data flow patterns, and implement reactive updates in their applications.
