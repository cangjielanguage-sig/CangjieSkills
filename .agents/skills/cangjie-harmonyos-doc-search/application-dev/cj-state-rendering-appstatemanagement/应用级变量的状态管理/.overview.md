# 应用级变量的状态管理

This module focuses on the state management of application-level variables within the ArkUI framework using the Cangjie programming language. It covers comprehensive mechanisms for storing and managing data across an application's lifecycle, including global state (AppStorage), page-level state (LocalStorage), persistent storage (PersistentStorage), and device environment states (Environment). Designed for Cangjie developers building HarmonyOS applications, this documentation provides the necessary APIs and concepts to handle data synchronization, persistence, and UI binding effectively, ensuring robust and responsive user interfaces.

## Detailed Description

### class_Environment.md class_Environment.md
This document serves as API reference documentation for the Cangjie Environment class, which manages device environment states within an application process. It details the class definition and two primary static methods: `envProp` for creating properties synchronized with device states, and `keys` for retrieving all existing property keys. Key information includes that the Environment is instantiated by the UI framework at startup and supports generic types for property values. The `envProp` function requires a string key and a default value, returning a success boolean. This documentation targets Cangjie developers utilizing the ArkUI framework who need to interact with system-level environment data.
