# 窗口全屏布局方案

This directory focuses on technical schemes and implementation guides for window fullscreen layouts within HarmonyOS applications. It comprehensively covers how to handle system avoidance areas, distinguishing between scenarios where system bars are hidden versus visible. Key topics include immersive layouts, window configuration APIs like `setWindowLayoutFullScreen`, and dynamic UI adjustment for status and navigation bars. Suitable for HarmonyOS developers and system architects using ArkUI, ArkTS, or Cangjie, this resource helps create adaptive interfaces that maximize screen real estate while managing system interactions effectively.

### 应用扩展布局隐藏避让区.md 应用扩展布局隐藏避让区.md
This tutorial guides developers on implementing an immersive full-screen layout by hiding system bars for applications like games and movies. It covers setting the window layout to full screen, disabling the status bar and navigation indicator using specific APIs, and constructing the UI without avoidance logic. The document provides Cangjie code examples demonstrating the use of `setWindowLayoutFullScreen` and `setSpecificSystemBarEnabled` to achieve a layout where content occupies the entire screen, with system bars accessible via a swipe gesture. This guide is intended for HarmonyOS developers using the ArkUI framework and Cangjie language who need to create immersive user experiences.

### 窗口全屏布局方案.md 窗口全屏布局方案.md
This document outlines the technical scheme for implementing window fullscreen layouts, specifically focusing on how applications handle system avoidance areas. The content is divided into two primary scenarios: application extended layout with fullscreen display that does not hide avoidance areas, and application extended layout that hides avoidance areas. Key information includes the distinction between these two modes regarding UI visibility and screen real estate usage. Intended for developers and system architects, this guide serves as a reference for configuring window behavior in fullscreen modes. Keywords include window layout, fullscreen display, avoidance areas, and application extension.

### 应用扩展布局全屏显示不隐藏避让区/
This directory provides comprehensive resources for implementing immersive full-screen layouts in HarmonyOS applications. The core objective is to enable UI elements to extend into system areas—such as the status bar and navigation bar—without hiding these critical system components. By retrieving avoidance area dimensions and dynamically adjusting padding, developers can prevent content overlap. The documentation covers key APIs like `setWindowLayoutFullScreen`, `getWindowAvoidArea`, and `@StorageProp`. This collection is suitable for HarmonyOS developers using either Cangjie or ArkTS who need to build adaptive interfaces that handle complex screen states, including rotation and multi-window scenarios, ensuring a seamless user experience.
