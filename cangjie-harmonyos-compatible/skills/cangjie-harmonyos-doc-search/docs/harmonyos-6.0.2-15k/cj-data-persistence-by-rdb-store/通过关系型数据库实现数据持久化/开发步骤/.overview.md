# 开发步骤

This directory provides a structured tutorial series for developers implementing data persistence using the relational database (RdbStore) within the Cangjie framework on HarmonyOS. It covers the complete development lifecycle, starting from initial database configuration, schema creation, and version management to performing standard CRUD operations and handling advanced tasks like result set processing, backup, and deletion. Key concepts include StoreConfig initialization, RdbPredicates, and resource management. These guides are essential for application developers utilizing the ArkData kit to build robust local data storage solutions and manage database evolution effectively.

## Quick Navigation

**What do you want to do?**

- Initialize the database and manage schema versions? → 开发步骤_1.md
- Perform Create, Read, Update, Delete (CRUD) operations? → 开发步骤_2.md
- Process query results, backup, or delete the database? → 开发步骤_3.md

## Detailed Description

### 开发步骤_1.md
This tutorial guides developers on implementing data persistence using the relational database (RdbStore) in the Cangjie framework. It covers database configuration, exception handling references, and version management logic. The document provides a detailed Cangjie code example demonstrating how to initialize StoreConfig, create tables, and handle schema upgrades or downgrades based on database version numbers, such as adding or dropping columns within a UIAbility. It is intended for application developers using the ArkData kit who need to manage local database lifecycles and schema evolution.

### 开发步骤_2.md
This document provides a tutorial on performing CRUD operations within a relational database using the Cangjie language. Main topics include data insertion, modification, deletion, and querying using RdbPredicates. Key information highlights that databases are context-specific, generate temporary files like -wal and -shm, and persist data immediately without explicit flush commands. The guide targets HarmonyOS developers managing local data storage, requiring knowledge of RdbStore and exception handling.

### 开发步骤_3.md
This tutorial guides developers through advanced relational database operations using the Cangjie language. It covers processing query results by iterating through a ResultSet and explicitly closing it to release memory. The document further explains manual database backup and restoration procedures, distinguishing them from system-only automatic methods. Finally, it demonstrates how to permanently delete a database using the deleteRdbStore method. Key takeaways emphasize resource management and data safety practices. This guide targets application developers implementing data persistence and lifecycle management in their applications.
