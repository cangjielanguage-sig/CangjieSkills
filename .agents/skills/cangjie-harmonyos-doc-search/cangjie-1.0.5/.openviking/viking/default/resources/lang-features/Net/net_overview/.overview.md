# net_overview

本目录提供了仓颉语言网络编程的全面概览，旨在帮助开发者理解其基础架构、支持的协议栈及核心编程特性。文档深入探讨了从传输层（包括 UDP、TCP 及 Unix Domain Socket）到应用层（涵盖 HTTP 多版本及 WebSocket 升级机制）的完整抽象与实现细节。特别强调了仓颉通过 `std.socket` 包提供的网络功能，以及其独特的“伪阻塞”模型——即网络操作虽表现为阻塞式，但仅阻塞仓颉轻量级线程，不会阻塞底层系统线程，从而保证高并发性能。该资源非常适合需要掌握仓颉网络通信模型、进行 Socket 开发或构建高性能网络应用的开发者参考。

## Detailed Description

### net_overview.md net_overview.md

本文档旨在介绍仓颉语言网络编程的基础架构、支持协议及核心特性。主要涵盖传输层（UDP/TCP/Unix Domain）和应用层（HTTP/WebSocket）协议的抽象与实现。关键信息包括仓颉通过 std.socket 包提供网络功能，支持 UdpSocket、TcpSocket、HTTP 多版本及 WebSocket 升级，且其网络编程虽为阻塞式但仅阻塞仓颉线程而不阻塞系统线程。适合需要了解仓颉网络编程模型的开发者。
