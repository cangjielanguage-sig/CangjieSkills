# cj-navigation-introduction

本目录深入探讨了ArkUI框架中Navigation组件的核心概念与应用实践，旨在帮助开发者理解组件导航与传统页面路由的本质区别。文档详细剖析了Navigation的架构设计，重点展示了其在组件树层级中的独特位置以及相比传统Router的六大显著优势。核心内容涵盖了一次开发多端部署的强大能力、标题栏与内容区的显式分离、基于UIBuilder的灵活页面配置以及丰富的组件属性动效。关键词包括Navigation、Router、页面路由、组件导航、ArkUI架构、多端部署。本资料特别适合ArkUI应用开发者，尤其是那些致力于优化页面路由管理、提升用户交互体验以及需要实现复杂跨层级跳转场景的专业技术人员。

## Detailed Description

### cj-navigation-introduction.md
本文档旨在介绍组件导航与页面路由的区别，重点推荐使用Navigation组件以实现更灵活的应用内页面跳转和组件内跳转。主要涵盖架构差异分析，详细阐述了Navigation在组件树层级中的位置及其相对于传统Router的六大设计优势。核心要点包括Navigation具备更强的一次开发多端部署能力、显式区分标题栏与内容区、支持基于UIBuilder的灵活页面配置以及丰富的组件属性动效。适用于ArkUI应用开发者，特别是寻求优化页面路由管理、提升用户体验及实现复杂交互场景的开发人员。
