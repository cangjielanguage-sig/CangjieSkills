This directory provides a technical tutorial focused on the practical application of the CString type within the Cangjie programming language to facilitate robust interoperability with C functions. It comprehensively covers string passing and memory management, detailing how to define foreign functions and manually create or free CStrings using LibC. Furthermore, the guide explains the process of converting C-side strings to native Cangjie String types and demonstrates the use of the try-with-resource syntax for automatic memory management via CStringResource. The content illustrates bidirectional string exchange, emphasizing the necessity of unsafe blocks for direct memory manipulation and the critical importance of proper memory handling to prevent leaks. It also includes specific compilation commands for building the C library and linking it with the Cangjie executable. This resource is intended for Cangjie developers requiring C interoperability and assumes basic knowledge of both Cangjie syntax and C compilation processes.
