### enum_DiagReportLevel_2more.md enum_DiagReportLevel_2more.md
This API reference document defines two enumeration types used within the Cangjie language's AST or diagnostic system. It details the `DiagReportLevel` enum for error severity and the `ImportKind` enum for import statement variations. Key information includes that `DiagReportLevel` supports ERROR and WARNING, mapping to integers 0 and 1 via the `level()` function. `ImportKind` distinguishes between Single, Alias, All, and Multi imports, inheriting from ToString to provide string representations. This documentation targets developers working on compiler internals or syntax tree analysis who need to understand diagnostic severity and import structures.
