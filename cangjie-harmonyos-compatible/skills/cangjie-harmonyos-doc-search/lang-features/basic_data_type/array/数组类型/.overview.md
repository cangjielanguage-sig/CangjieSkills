# 数组类型

本目录涵盖了仓颉编程语言中的数组类型体系，主要分为值类型数组（VArray）和引用类型数组（Array）。内容详细阐述了这两种数组的定义、语法构造、初始化方式、成员操作以及它们在内存管理和性能上的差异。重点涉及堆内存分配优化、垃圾回收压力减少、C语言互操作性、类型安全及引用语义等核心概念。这些资料适合需要深入理解仓颉集合数据结构、进行高性能内存调优或与底层C语言交互的开发者阅读。

## 详细描述

### VArray.md VArray.md

本文档介绍了仓颉编程语言中的值类型数组 VArray，阐述了其定义、语法、使用方法及与引用类型数组的性能差异。涵盖了 VArray 的语法定义与类型约束、初始化方式（字面量及构造函数）、成员操作（下标访问与 size 属性）以及与 C 语言的互操作性。关键点包括 VArray 能减少堆内存分配和垃圾回收压力，但因拷贝开销不建议用于大尺寸数组；元素类型受限，不能包含引用类型或枚举；支持通过字面量或构造函数初始化。这是一份面向仓颉开发者的参考文档，适用于需要优化内存管理或进行 C 语言互操作的场景，读者需具备值类型与引用类型的基础知识。

### Array/

本目录详细介绍了仓颉编程语言中的 Array 类型，涵盖了从基础定义到高级操作的完整流程。主要内容包括数组的构造方法（如字面量、构造函数）、元素访问与遍历、以及修改元素时的内存行为和引用语义。文档重点强调了类型安全、固定长度特性及索引越界处理。这些资料适合仓颉语言的初学者以及需要深入理解集合数据结构与内存管理的开发者阅读。
