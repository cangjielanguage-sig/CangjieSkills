This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically detailing the implementation of the `ThrowingOp` interface for the `UInt16` type. It covers a wide range of arithmetic and bitwise operations designed with an exception-throwing strategy to manage errors robustly. Key topics include standard operations like addition, subtraction, multiplication, and division, as well as negation and bit shifting. These functions throw specific exceptions, such as `OverflowException` and `OvershiftException`, to signal errors explicitly. This documentation is essential for Cangjie developers who require safe numeric operations that prioritize error handling over silent value wrapping, thereby ensuring data integrity and application reliability.
