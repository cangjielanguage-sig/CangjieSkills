# harmonyos-6.0.2-15k

This directory contains the complete documentation and reference materials for HarmonyOS version 6.0.2, with a specific focus on the Cangjie programming language. It covers a vast array of topics including the Cangjie language syntax, ArkUI framework, state management, multimedia processing, connectivity protocols, and security mechanisms. Additionally, it includes general HarmonyOS setup, packaging, and configuration guides. The content is designed to assist developers in building, deploying, and optimizing applications using the Cangjie language, offering both theoretical overviews and practical implementation guides. Core keywords include HarmonyOS, Cangjie, ArkUI, API reference, development guide, security, multimedia, and connectivity. This resource is suitable for HarmonyOS developers, system architects, and software engineers utilizing the Cangjie language to build native applications.

## Detailed Description

### Getting Started & Basics
*   **[application-dev-preparation]**: Guides developers through the initial setup, including account registration, DevEco Studio installation, and code signing.
*   **[cj-development-intro]**: Explains how to execute Cangjie API code snippets, manage permissions, and adhere to Stage model constraints.
*   **[cj-quick-start-first-cangjie-app]**: A tutorial for creating the first Cangjie application, covering project creation, UI implementation, and deployment.
*   **[cj-quick-start-preparations]**: Outlines the necessary tools, concepts, and prerequisites for starting Cangjie development.

### UI & Layout
*   **[cj-overview]**: Introduces the ArkUI framework, declarative UI syntax, and the relationship between pages and components.
*   **[cj-layout-development-overview]**: Covers layout mechanisms like Linear, Flex, Grid, and Stack, along with constraints and responsive design.
*   **[cj-state-management-overview]**: Explains state synchronization using decorators like @State, @Prop, and @Link, as well as AppStorage and LocalStorage.
*   **[cj-animation]**: Details animation curves, transitions, and effects to enhance user interface fluidity and responsiveness.
*   **[cj-common-components-...]**: Covers UI elements such as Buttons, Lists, Dialogs, and Pickers, including their styling and event handling.

### System & APIs
*   **[cj-apis-...]**: Provides extensive API references for system services like AbilityKit, ConnectivityKit, and NotificationManager.
*   **[cj-application-models]**: Details the Stage model architecture, including UIAbility, ExtensionAbility, and task management.
*   **[cj-process-model-stage]**: Explains process isolation, IPC mechanisms, and the mapping of components to processes.
*   **[cj-thread-model-stage]**: Covers the distinction between the Main Thread for UI operations and Cangjie Threads for background tasks.

### Multimedia
*   **[cj-media-kit-intro]**: Introduces the Media Kit framework for audio and video playback, recording, and processing.
*   **[cj-audio-...]**: Covers audio recording, playback, device management, and audio-haptic synergy.
*   **[cj-camera-...]**: Details camera input, preview, recording, and advanced features like HDR and metadata handling.
*   **[cj-image-...]**: Covers image decoding, encoding, PixelMap manipulation, and image effects.

### Connectivity
*   **[cj-connectivity-kit-intro]**: Introduces the Connectivity Kit for wireless communication capabilities like Bluetooth, Wi-Fi, and NFC.
*   **[cj-bluetooth-...]**: Covers BLE, GATT, and classic Bluetooth protocols, including device discovery and data exchange.
*   **[cj-net-...]**: Handles HTTP requests, WebSocket connections, and network connection management.
*   **[cj-wifi-...]**: Manages Wi-Fi, Hotspot, and P2P connections.

### Security & Data
*   **[cj-huks-...]**: Details the Universal Keystore (HUKS) for secure key management and cryptographic operations.
*   **[cj-crypto-...]**: Covers encryption, digital signatures, hashing, and key derivation algorithms.
*   **cj-data-...**: Explains data persistence using RDB, KV store, and distributed data synchronization.

### Tools & Utilities
*   **[cj-hdc]**: The HarmonyOS Device Connector tool for debugging, file transfer, and log management.
*   **[cj-bm-tool]**: The Bundle Manager tool for installing, uninstalling, and querying application bundles.
*   **[cj-hidumper]**: A unified command-line tool for system diagnostics, debugging, and performance analysis.
*   **cj-restool**: A utility for compiling application resources and generating resource indexes.
