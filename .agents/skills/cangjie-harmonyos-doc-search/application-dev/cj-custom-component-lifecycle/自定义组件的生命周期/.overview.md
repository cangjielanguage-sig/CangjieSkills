# 自定义组件的生命周期

This directory provides comprehensive documentation on the lifecycle management of custom components within the Cangjie ArkUI framework. It serves as an essential API reference for developers, detailing the sequence of events from component creation and building to destruction and recycling. Key topics include core lifecycle callbacks like `aboutToAppear` and `onDidBuild`, as well as advanced mechanisms for component reuse and page transition animations. The documentation also outlines specific constraints regarding state variable modifications and asynchronous operations to ensure application stability. Furthermore, it specifies system capabilities and version requirements for specific APIs. This resource is specifically designed for application developers and engineers utilizing declarative UI paradigms who need to master component initialization, state management, and routing behavior to build efficient, responsive applications.

### func_aboutToReuseReusePara_3more.md func_aboutToReuseReusePara_3more.md
This document serves as an API reference for lifecycle methods within the Cangjie ArkUI framework, specifically focusing on component reuse mechanisms and page transitions. It details three protected open functions: aboutToReuse, aboutToRecycle, and pageTransition. Key information includes that aboutToReuse receives ReuseParams when a component is retrieved from the cache, whereas aboutToRecycle triggers before the component is cached. Additionally, pageTransition handles animations for page entry and exit. All methods require SystemCapability.ArkUI.ArkUI.Full and are available starting from version 22. This reference targets developers building custom reusable components who need to manage state during recycling and implement transition effects.
