This directory provides essential API reference documentation for fundamental data structures used in handling touch interactions within the ArkUI framework, specifically designed for the Cangjie language. It comprehensively covers classes representing touch events and individual touch objects, detailing properties such as event types, coordinates, timestamps, and unique identifiers. Key concepts include event propagation, multi-touch support, and the distinction between different coordinate systems and refresh rates. This documentation is highly suitable for developers building responsive user interfaces who need to manage, interpret, and respond to raw touch data effectively in their applications.
