# 示例代码

This directory contains example code demonstrating the age-friendliness (适老化) capabilities of UI components in the Cangjie programming language for HarmonyOS development. It focuses on how components like SideBarContainer and DatePickerDialog adapt to system font size adjustments to improve accessibility. The examples include configuration details, styling options, and visual comparisons of UI behavior under different scaling factors, specifically highlighting the transition from standard (1x) to large (1.75x) font sizes. This resource is suitable for developers looking to implement and verify accessibility behaviors, event callbacks, and adaptive layouts in their applications using Cangjie.

## Detailed Description

### 示例代码_1.md
This document demonstrates the age-friendliness (适老化) capabilities of UI components in the Cangjie programming language, specifically triggered by system font size adjustments. It covers two main examples: the SideBarContainer component, where long-pressing the control button activates the feature, and the DatePickerDialog component, which responds to font scaling. Key takeaways include that these accessibility features only trigger when the system font size exceeds 1x, with code snippets and visual comparisons provided for 1x versus 1.75x scaling. This technical guide is designed for HarmonyOS developers using Cangjie to implement and verify accessibility behaviors in their applications.

### 示例代码_2.md
This document provides a code example demonstrating the configuration and usage of a DatePickerDialog component, emphasizing styling and accessibility features. It covers the definition of button styles, the configuration of dialog options including date ranges, time formats, and text styles, and the implementation of event callbacks. It also includes a visual comparison table. The code details specific parameters for PickerDialogButtonStyle and DatePickerDialogOptions, highlighting how to handle lifecycle events and date changes. The table illustrates the UI's adaptive behavior under different system font scaling settings for age friendliness. This reference material targets developers seeking to implement customizable date pickers with accessibility support in their applications.
