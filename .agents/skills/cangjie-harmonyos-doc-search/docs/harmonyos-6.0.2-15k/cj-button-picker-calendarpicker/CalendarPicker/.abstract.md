This directory contains documentation and resources for the CalendarPicker component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of a dropdown calendar popup for date selection, including API references, basic type definitions, and practical code examples. Key topics include component initialization, configuration attributes like edgeAlign and textStyle, event handling, and state management. This content is suitable for HarmonyOS developers and Cangjie programmers looking to integrate customizable date selection functionality into their applications.
