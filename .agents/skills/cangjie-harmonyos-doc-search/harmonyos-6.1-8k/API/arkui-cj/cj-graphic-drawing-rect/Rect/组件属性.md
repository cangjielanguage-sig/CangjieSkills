## 组件属性

### func radiusWidth(?Length)

```cangjie
public func radiusWidth(value: ?Length): This
```

**功能：** 设置圆角的宽度，仅设置宽时宽高一致。异常值按照初始值处理。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 22

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|value|?[Length](./cj-common-types.md#interface-length)|是|-|圆角的宽度。初始值：0.vp|
