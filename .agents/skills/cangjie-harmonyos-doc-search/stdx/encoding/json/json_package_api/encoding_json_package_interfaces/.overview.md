# encoding_json_package_interfaces

本目录专门收录了 `encoding_json` 包中 `ToJson` 接口的 API 参考文档，核心内容是确立 `JsonValue` 与 `DataModel` 之间双向转换的规范标准。文档深入剖析了 JSON 序列化与反序列化的机制，详细介绍了接口定义、对 `DataModel` 的扩展实现，以及静态方法 `fromJson` 和实例方法 `toJson` 的具体用法、参数类型和返回值。此外，还重点说明了在数据转换过程中可能遇到的 `JsonException` 异常情况。该文档专为 Cangjie 语言开发者设计，是理解和实现 JSON 数据处理逻辑不可或缺的核心技术资料。

### encoding_json_package_interfaces.md encoding_json_package_interfaces.md
