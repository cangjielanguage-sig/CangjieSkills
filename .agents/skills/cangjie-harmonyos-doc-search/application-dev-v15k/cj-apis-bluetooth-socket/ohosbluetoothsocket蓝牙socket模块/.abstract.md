This directory contains API reference documentation for the HarmonyOS Bluetooth Socket module, specifically designed for the Cangjie programming language. It comprehensively covers the implementation of the Serial Port Profile (SPP) for Bluetooth communication, including server and client socket management, data transmission, and event handling. Key components include configuration classes like `SppOptions`, enumerations for link types, and functions for connection lifecycle management (`sppConnect`, `sppListen`, `sppAccept`). This module is suitable for developers using the ConnectivityKit to build robust Bluetooth-enabled applications, requiring knowledge of Cangjie syntax and standard Bluetooth protocols.
