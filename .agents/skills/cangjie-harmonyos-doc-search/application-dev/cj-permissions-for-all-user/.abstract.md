This directory serves as a comprehensive technical resource for developers working with HarmonyOS permissions that require explicit user authorization. It focuses specifically on the `user_grant` permission model, detailing the necessary frameworks for requesting sensitive capabilities at runtime, with a particular emphasis on changes introduced in API version 12. Key topics covered include the `system_basic` protection level, device-specific constraints such as Tablet exclusivity, and the correct configuration within `module.json5`. This guide is essential for developers aiming to implement secure access to system features like screen capture, Bluetooth, and location services while strictly adhering to user privacy compliance standards and ensuring a seamless user experience across different devices.
