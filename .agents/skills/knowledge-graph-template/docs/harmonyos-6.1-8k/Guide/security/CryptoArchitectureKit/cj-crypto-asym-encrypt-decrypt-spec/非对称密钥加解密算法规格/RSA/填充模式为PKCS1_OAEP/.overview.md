# 填充模式为PKCS1_OAEP

本目录包含关于RSA加密中PKCS1_OAEP填充模式的技术文档。内容涵盖了如何构建加密参数字符串、不同RSA密钥长度支持的摘要算法与MGF组合，以及密钥类型的兼容性规范。核心关键词包括RSA、PKCS1_OAEP、摘要算法、MGF1和密钥长度。这些文档适合需要在系统中集成非对称加密功能、配置加密参数或解决密钥兼容性问题的开发人员参考。

## 详细描述

### 填充模式为PKCS1_OAEP_1.md
本文档旨在指导用户如何构建用于RSA加解密的字符串参数，特别是针对PKCS1_OAEP填充模式。文档详细说明了参数的拼接规则，即由非对称密钥类型、填充模式、摘要算法和掩码摘要通过符号“|”连接。关键信息包括具体的参数示例以及输入数据长度的限制条件，即数据大小需小于密钥字节长度减去摘要长度等。这是一份技术参考文档，主要面向需要在创建非对称加解密实例时指定算法规格的开发人员。

### 填充模式为PKCS1_OAEP_2.md
本文档详细列出了在使用PKCS1_OAEP填充模式时，不同RSA密钥长度所支持的摘要算法与掩码生成函数（MGF）组合。文档涵盖了从RSA512到RSA8192等多种密钥长度，明确了每种密钥下可用的摘要算法（如MD5、SHA系列）及对应的MGF1掩码摘要算法。所有组合均要求API版本12及以上，并提供了通用的RSA密钥兼容性规则，强调了摘要算法与密钥长度的匹配关系。这是一份面向开发者的技术参考文档，用于指导加密参数的正确配置与兼容性查询。

### 填充模式为PKCS1_OAEP_3.md
本文档旨在阐述PKCS1_OAEP_3填充模式下RSA加解密参数的兼容性规范。文档重点讨论了密钥类型的输入规则，指出为了兼容由密钥参数生成的密钥，系统允许在输入密钥类型时不指定长度。关键信息在于，实际的加解密运算将完全取决于所输入密钥的实际长度。这属于技术参考文档的一部分，主要面向进行加密算法集成的开发人员，旨在解决密钥参数匹配与兼容性问题。
