This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically focusing on the `ohoscalendar_manager` module for schedule management capabilities. It covers essential data structures, classes, and enumerations required to integrate calendar functionality into applications. Key topics include calendar account management, event creation and filtering, location handling, and recurrence rules. The documentation is designed for developers working with the SystemCapability.Applications.CalendarData system capability who need to build robust calendar features, manage permissions, and handle complex scheduling logic within the HarmonyOS ecosystem.
