# 权限列表

This directory contains technical documentation regarding HarmonyOS permission definitions and usage guidelines for developers. It covers specific permissions introduced or updated in API version 12, focusing on sensitive system capabilities such as Bluetooth, Camera, Location, Microphone, and file access on tablets. The documents detail permission levels, authorization modes (specifically `user_grant`), and device compatibility constraints. This resource is suitable for HarmonyOS application developers who need to correctly declare permissions in `module.json5` configuration files and implement secure access to system resources or public directories.

## Detailed Description

### ohospermissionACCESS_BLUE_14more.md ohospermissionACCESS_BLUE_14more.md

This document serves as a reference guide for HarmonyOS permissions introduced or updated in API version 12. It details specific permissions such as Bluetooth, Camera, Location, Microphone, and Health Data access. Key takeaways include that all listed permissions are normal level requiring user authorization, with a specific manual grant process required for background location access. The target audience is application developers needing to declare and request sensitive system capabilities in their module.json5 configuration files.

### ohospermissionREAD_WRITE_D_2more.md ohospermissionREAD_WRITE_D_2more.md

This reference document defines specific HarmonyOS permissions required for applications to access public directories on tablets. It details the `ohos.permission.READ_WRITE_DOWNLOAD_DIRECTORY` and `ohos.permission.READ_WRITE_DOCUMENTS_DIRECTORY` permissions. Key information indicates that both permissions are classified as normal level, require `user_grant` authorization, and are supported starting from API version 12 exclusively on Tablet devices. They allow read and write access to the Download and Documents directories respectively. This documentation is intended for HarmonyOS application developers implementing file management features who need to understand permission requirements and device compatibility.
