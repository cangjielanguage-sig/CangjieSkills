# 受限开放权限

This directory provides comprehensive technical documentation regarding restricted open permissions for the HarmonyOS and OpenHarmony ecosystems. It details the specific procedures for applications to access elevated privileges during the Beta phase, including the manipulation of Access Control Lists (ACL) and Application Privilege Levels (APL). The content covers critical configuration changes required in the `HarmonyAppProvision` file, specifically for debugging purposes, while clearly distinguishing these temporary measures from the official commercial release requirements. Furthermore, it acts as a detailed reference repository for API 12 system-level permissions, covering hardware interfaces, network settings, and sensitive data access. This documentation is primarily designed for HarmonyOS developers, system integrators, and security engineers involved in building high-privilege system applications or managing complex permission configurations. It serves as a vital resource for understanding the security boundaries and capabilities available within the operating system environment.

## Detailed Description

### 受限开放权限_2more.md 受限开放权限_2more.md
This technical guide outlines the application process for restricted open permissions currently in the Beta phase. It covers the application method, specifically how normal applications can access these permissions via the Access Control List (ACL) by elevating their APL level. Key information includes the requirement to modify the HarmonyAppProvision configuration file, specifically setting the "apl" field to "system_basic" within the JSON template. The document emphasizes that this direct modification method is intended solely for application debugging and is not valid for commercial release, which requires official market certificates. This guide targets HarmonyOS developers managing application permissions and configuration.

### 权限列表/
This directory serves as a comprehensive repository for OpenHarmony and HarmonyOS permission reference documents. It details the definitions, access levels, and authorization mechanisms for a wide array of system-level capabilities. Key topics include managing hardware interfaces like disk and Bluetooth, configuring network settings, accessing sensitive user data such as contacts and media, and customizing UI elements. The documentation primarily focuses on permissions introduced in API version 12, classified under the system_basic level. This resource is essential for system application developers and integrators seeking to implement secure, high-privilege features within their applications.
