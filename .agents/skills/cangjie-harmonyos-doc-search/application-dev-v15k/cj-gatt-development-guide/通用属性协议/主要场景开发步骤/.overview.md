# 主要场景开发步骤

This directory outlines the essential development steps for implementing Bluetooth Low Energy (BLE) scenarios within the HarmonyOS ecosystem. It focuses on the core interactions between GATT servers and clients, utilizing the Cangjie language and ArkTS. The content comprehensively covers the complete lifecycle of Bluetooth communication, ranging from server initialization and service management to client connection and data exchange. It is designed for software developers who possess a foundational understanding of Bluetooth protocols and asynchronous programming and are looking to build robust, efficient connectivity features in their applications.

## Detailed Description

### server端操作services和通知客户端信息/
This directory contains technical documentation and code examples for implementing a Bluetooth Low Energy (BLE) GATT Server, specifically focusing on managing services and notifying clients. It covers the complete server lifecycle, including initialization, service creation, handling read/write requests, descriptor operations, and resource cleanup. The content is primarily written for developers using the Cangjie language and ArkTS within the HarmonyOS ecosystem. Key topics include GATT server instantiation, callback registration for connection states, and response handling mechanisms. This guide is suitable for software developers with a foundational understanding of Bluetooth protocols and asynchronous programming.

### 连接server端读取和写入信息/
This directory provides a comprehensive technical guide for implementing a Bluetooth Low Energy (BLE) GATT client using the Cangjie language within the HarmonyOS ecosystem. It covers the complete lifecycle of client-server communication, including establishing connections, discovering services, and performing read and write operations on characteristics and descriptors. The documentation emphasizes connection state management, UUID validation, and proper resource cleanup. It is suitable for HarmonyOS developers who possess a foundational understanding of BLE protocols and Cangjie syntax and are looking to build robust Bluetooth connectivity features in their applications.
