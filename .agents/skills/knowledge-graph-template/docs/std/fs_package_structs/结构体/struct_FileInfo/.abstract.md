This directory contains API reference documentation for the `FileInfo` struct within the Cangjie programming language's file system package. It covers comprehensive file system operations including metadata inspection, permission management, and file attribute queries. Key topics include file type checking, size retrieval, timestamp access, and read/write/execute permissions across different operating systems like Windows and Linux. The documentation highlights platform-specific behaviors and potential race conditions. It is suitable for Cangjie developers who need precise programmatic control over file system entities and require detailed understanding of file attributes and access rights.
