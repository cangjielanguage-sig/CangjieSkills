# 示例代码

This directory contains a collection of code examples and tutorials focused on advanced UI layout techniques using the Cangjie programming language and HarmonyOS development framework. It specifically targets the `RelativeContainer` component, demonstrating how to manage complex positioning through anchors, chains, barriers, and margins. Key topics include relative positioning, constraint-based layouts, chain modes (SPREAD, PACKED), and bidirectional text support. These resources are suitable for developers and system administrators looking to master flexible and responsive user interface design in Cangjie applications.

## Detailed Description

### 示例1以容器和容器内组件作为锚点进行布局.md 示例1以容器和容器内组件作为锚点进行布局.md
This document provides a code example demonstrating how to implement layout positioning using containers and internal components as anchors within a RelativeContainer. It covers the usage of the alignRules interface, RelativeContainer, and Row components in the Cangjie programming language. The example illustrates positioning elements relative to the parent container (__container__) and sibling components via specific IDs, utilizing vertical and horizontal alignment anchors like Top, Bottom, Start, and End. This tutorial is intended for developers working with HarmonyOS UI development in Cangjie who need to understand relative positioning.

### 示例2子组件设置外边距_3more.md 示例2子组件设置外边距_3more.md

It covers three specific scenarios: setting margins for child components, utilizing the bias attribute for vertical offsetting between anchors, and implementing guidelines as positioning anchors. Key takeaways include how to manipulate component positioning via alignRules, margin, bias, and guideLine properties to create flexible UI structures. Intended for HarmonyOS developers, this tutorial serves as a guide for mastering relative positioning and spacing in Cangjie UI development.

### 示例5设置屏障.md 示例5设置屏障.md
This document provides a code example demonstrating how to implement layout barriers within a RelativeContainer using the Cangjie language. It covers the `barrier` interface, `BarrierStyle` configuration, and `AlignRuleOption` for anchoring child components relative to dynamic barriers. The code creates two barriers ("barrier1" and "barrier2") based on the positions of "row1" and "row2", allowing other components ("row3", "row4") to align to these calculated edges (RIGHT and BOTTOM). This tutorial is intended for developers using the Cangjie UI framework to build complex relative layouts.
