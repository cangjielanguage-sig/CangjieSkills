# 关系型数据库跨设备数据同步

This directory provides a comprehensive technical guide focused on the implementation of cross-device data synchronization for relational databases within the HarmonyOS ecosystem. It thoroughly explains the mechanisms required to maintain data consistency across multiple devices, covering essential concepts such as distributed table configuration, synchronization modes (push and pull), and change notifications. The documentation highlights critical constraints, including database limits, and introduces vital APIs like `setDistributedTables` and `sync`. This resource is primarily suitable for application developers using the Cangjie language who are looking to integrate robust distributed data capabilities into their applications to ensure seamless user experiences across different hardware.

## Detailed Description

The following section provides detailed summaries of the documents included in this directory, covering both theoretical scenarios and practical implementation steps.

### 场景介绍_5more.md 场景介绍_5more.md
This document outlines the scenario and implementation of cross-device data synchronization for relational databases. It covers basic concepts, operating mechanisms including data sync and change notifications, constraints, and relevant API interfaces. Key takeaways include the ability to set tables as distributed, the push/pull sync modes, and specific limitations like the 16-database limit. Important APIs include `setDistributedTables` and `sync`. This guide targets application developers needing to implement data consistency across multiple devices.

### 开发步骤.md 开发步骤.md
This document serves as a step-by-step tutorial for implementing distributed relational database synchronization using the Cangjie language. It covers five main stages: importing necessary modules, requesting the DISTRIBUTED_DATASYNC permission, creating the database and configuring distributed tables, triggering data synchronization using SYNC_MODE_PUSH, and setting up remote data change subscriptions. Key takeaways include the importance of security level compliance and the use of specific APIs like setDistributedTables and onDataChange. This guide is intended for developers building cross-device data capabilities within the HarmonyOS ecosystem.
