# 使用WebRTC进行Web视频会议

This directory provides comprehensive technical tutorials for implementing WebRTC-based video conferencing within HarmonyOS applications. It covers the complete workflow from configuring camera and microphone permissions in `module.json5` to utilizing the W3C standard `navigator.mediaDevices.getUserMedia` interface. The guides detail how to bridge native permission handling with web components, ensuring seamless access to hardware resources. Key topics include Cangjie language implementation, ArkTS backend logic, and hybrid application development. Suitable for HarmonyOS developers with prerequisite knowledge of Cangjie syntax and application security configuration, these resources facilitate the integration of web-based media capture features for robust video communication solutions.

## Detailed Description

### 使用WebRTC进行Web视频会议_1.md 使用WebRTC进行Web视频会议_1.md
This technical tutorial guides developers on implementing WebRTC video conferencing within a HarmonyOS application using the Cangjie language. It covers declaring camera and microphone permissions in the module.json5 configuration file and defining corresponding resource strings. The document explains utilizing the W3C standard navigator.mediaDevices.getUserMedia interface to access media devices. Key sections include permission configuration, context retrieval in MainAbility, and handling permission requests via the Web component. Intended for HarmonyOS developers, this guide requires prerequisite knowledge of Cangjie syntax and application security configuration to successfully integrate web-based media capture features.

### 使用WebRTC进行Web视频会议_2.md 使用WebRTC进行Web视频会议_2.md
This technical tutorial demonstrates how to implement WebRTC video conferencing functionality within a HarmonyOS application by integrating native permission handling with web-based media capture. The document covers two main sections: the ArkTS backend logic for requesting camera and microphone permissions using the AbilityAccessCtrl manager, and the frontend HTML and JavaScript code for capturing media streams. Key information includes the implementation of the Web component's onPermissionRequest handler to manage user consent dialogs and the use of navigator.mediaDevices.getUserMedia to access video and audio inputs. This guide is intended for HarmonyOS developers seeking to build hybrid applications that require seamless access to hardware resources through a web interface.
