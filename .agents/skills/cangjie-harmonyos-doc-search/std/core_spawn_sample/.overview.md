### core_spawn_sample.md

This document serves as a practical tutorial for Cangjie concurrency programming, demonstrating how to manage threads using the spawn keyword and Future type. It covers three main scenarios: basic concurrent execution where threads run independently, synchronization using Future.get() to ensure the main thread waits for completion, and thread cancellation via future.cancel() and status checks. Key takeaways include understanding the non-blocking nature of spawn and the necessity of explicit synchronization or cancellation handling. This guide targets developers learning Cangjie's threading model, providing code samples and expected outputs to illustrate execution flow and timing.
