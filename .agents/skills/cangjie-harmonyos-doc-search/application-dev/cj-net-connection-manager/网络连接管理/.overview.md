# 网络连接管理

This directory focuses on network connection management within the HarmonyOS ecosystem using the Cangjie programming language and NetworkKit. It covers essential tasks such as DNS resolution, monitoring network status changes, managing network connections (WiFi, cellular, Ethernet), and querying network capabilities. Developers will learn how to handle network migration, bind applications to specific networks, and implement robust connectivity logic. This resource is suitable for HarmonyOS application developers and system engineers aiming to build applications with stable and intelligent network features.

## Detailed Description

### 使用对应网络解析域名获取所有IP.md
This technical tutorial guides developers on resolving domain names to retrieve all associated IP addresses using the Cangjie programming language and NetworkKit. The content covers three main steps: declaring the required ohos.permission.INTERNET permission, importing the connection module from kit.NetworkKit, and invoking the getAddressesByName method. Key takeaways include understanding the permission prerequisites and reviewing the provided code sample which demonstrates how to execute the resolution and handle the returned NetAddress array. This guide is intended for Cangjie developers implementing network connectivity features within the HarmonyOS ecosystem.

### 接收指定网络的状态变化通知.md
This tutorial guides developers on subscribing to status change notifications for a specified network in HarmonyOS using the Cangjie language. It covers the necessary steps including declaring the GET_NETWORK_INFO permission, importing NetworkKit, and creating a NetConnection object with specific network capabilities and timeouts. Key takeaways involve using the register() method to subscribe, handling netAvailable and netUnavailable event callbacks, and calling unregister() to stop listening. The document provides a complete code example demonstrating callback implementation and resource management. Intended for HarmonyOS application developers, this guide ensures apps can dynamically react to network connectivity changes.

### 监控默认网络变化并主动重建网络连接_2more.md
This technical guide explains how to monitor default network changes and retrieve active network lists to ensure application connectivity remains stable during network switches. It details scenarios like switching between WiFi and cellular due to signal quality or user actions. The document provides Cangjie code examples demonstrating how to register callbacks for network availability events using createNetConnection and how to fetch all connected networks via getAllNets. It also specifies the required ohos.permission.GET_NETWORK_INFO permission. Intended for developers using the NetworkKit, this guide helps implement robust network migration logic in applications.

### 网络连接管理_6more.md
This document provides a technical guide for the Network Connection Management module, designed for developers using the Cangjie language. It outlines capabilities for managing WiFi, cellular, and Ethernet connections, including priority management, quality assessment, and DNS resolution. The text defines core concepts like network producers and consumers, details usage scenarios, and presents a comprehensive API reference. Key interfaces allow users to obtain network handles, bind applications to specific networks, and subscribe to status changes. This resource is essential for developers implementing robust network monitoring and selection logic in their applications.

### 根据数据网络查询网络的能力信息及连接信息/
This directory provides comprehensive technical guides for HarmonyOS developers focusing on network management using the NetworkKit framework within the Cangjie language environment. It details the procedures for querying network capabilities and connection properties, essential for applications requiring real-time network awareness. Key topics include permission configuration (specifically ohos.permission.GET_NETWORK_INFO), necessary module imports, and the retrieval of network handles via methods like getDefaultNet and getAllNets. The guides explain how to identify network types—such as Cellular and Wi-Fi—and specific features like MMS or Internet access. Additionally, it covers the extraction of link details through connection properties. These resources are designed for software developers and system engineers aiming to implement robust network status monitoring and data retrieval functionalities in their applications, ensuring they can effectively manage and respond to network state changes.
