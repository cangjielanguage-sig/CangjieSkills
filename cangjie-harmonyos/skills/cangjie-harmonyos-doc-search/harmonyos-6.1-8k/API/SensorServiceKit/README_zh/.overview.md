# README_zh

本目录是Sensor Service Kit的仓颉语言索引文档，旨在为开发者提供API接口和错误码的文档入口。内容主要涵盖仓颉API接口文档及传感器错误码列表，所有特性目前均为Beta版本。文档详细链接了`ohos.sensor`模块的说明，包含传感器调用方法及错误码定义。该文档主要面向使用仓颉语言进行HarmonyOS开发的程序员，适用于需要集成或调试传感器功能的开发场景，是开发过程中的关键参考资源。通过本文档，开发者可以快速定位传感器相关的接口说明及异常处理方案，从而提高开发效率。
