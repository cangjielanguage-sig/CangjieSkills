### class_RSAPublicKe_8more_df56a6ac.md
本文档是 Cangjie 语言中 RSAPublicKey 类的 API 参考文档，详细说明了 RSA 公钥的生成、格式转换及加密操作。文档涵盖了从私钥初始化公钥、PEM 与 DER 格式的编解码方法，以及支持 PKCS1 和 OAEP 填充模式的数据加密功能。关键信息包括该类继承自 PublicKey，推荐在高安全场景使用 OAEP 模式，且操作可能抛出 CryptoException。该文档面向需要在 Cangjie 应用中集成 RSA 加密和密钥管理的开发人员。

### func_verifyDigest_Array_9cf73f98.md
本文档介绍了Cangjie语言中用于验证数字签名的API函数verify。主要内容包括函数签名、参数定义（摘要方法、数据摘要、签名及填充模式）、返回值及异常处理。关键信息指出该函数支持PKCS1和PSS填充模式，推荐在高安全场景使用PSS，验证成功返回true，失败返回false或抛出CryptoException。文档面向需要在Cangjie应用中实现加密签名验证的开发人员。
