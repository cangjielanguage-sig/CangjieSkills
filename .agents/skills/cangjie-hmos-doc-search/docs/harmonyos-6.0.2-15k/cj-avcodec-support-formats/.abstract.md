This directory contains essential technical documentation for the `cj-avcodec-support-formats` project, focusing on the comprehensive media format capabilities provided by the AVCodec library. It is designed to serve as a definitive reference for software engineers, multimedia developers, and system integrators who require precise information on codec and container compatibility. The documentation covers a wide array of media processing functionalities, including video and audio encoding and decoding, with clear distinctions made between hardware-accelerated and software-based implementations. Key topics include the support for industry-standard codecs such as H.264 and H.265 for video, and AAC and MP3 for audio. Additionally, it details the encapsulation and parsing capabilities for various container formats like MP4, MKV, and FLV, highlighting specific stream types and technical constraints—such as limitations on MP3 sampling rates and AAC channel counts within MP4 containers. This resource is crucial for anyone tasked with verifying compatibility or optimizing performance in media playback and recording applications.
