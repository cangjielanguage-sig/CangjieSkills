This directory contains API reference documentation for component properties within the Cangjie ArkUI framework, focusing specifically on text styling and visual effects. It covers a wide range of attributes including typography settings (font size, weight, family), text positioning (baseline offset, line height), and decorative elements (shadows, backgrounds). The documentation provides function signatures, parameter descriptions, and system capability requirements. It is suitable for UI developers and software engineers using the Cangjie language to build and customize the visual appearance of text components in ArkUI applications.
