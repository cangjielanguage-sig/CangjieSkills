This directory contains comprehensive documentation for the `ohos.common_event_manager` module within the Cangjie development environment. It focuses on event-driven communication mechanisms, enabling developers to publish, subscribe to, and manage public events across HarmonyOS applications. Key topics include the `CommonEventManager` class, system-level event constants, and asynchronous callback handling. This resource is essential for Cangjie developers and application engineers utilizing the BasicServicesKit to implement robust, decoupled logic for reacting to system state changes like Wi-Fi connectivity or user lifecycle events.
