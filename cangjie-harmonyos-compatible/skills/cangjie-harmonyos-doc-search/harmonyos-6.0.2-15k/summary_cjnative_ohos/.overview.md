# summary_cjnative_ohos

This directory contains a comprehensive collection of documentation and guides for developing native applications on the OpenHarmony platform using the Cangjie programming language. It covers a wide spectrum of development topics, ranging from getting started and application framework fundamentals to advanced UI implementation with ArkUI, system capabilities, and security features like cryptography and user authentication. The resources are structured to assist developers in building, testing, and optimizing high-performance native apps, providing detailed references for cross-language interoperability, multimedia handling, and secure data management. It is suitable for both beginners starting their first Cangjie project and experienced developers integrating complex system services.
