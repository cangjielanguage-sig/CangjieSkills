### class_ProxyData.md class_ProxyData.md
This document provides API reference for the ProxyData class, which manages subscription data information for card proxy refreshes in the Cangjie language. It details the class constructor and two public properties: key and subscriberId. Key information includes that the key property serves as a subscription identifier matching the data publisher, while subscriberId defines subscription conditions, defaulting to the current card's formId. Both properties are read-write strings. This reference is intended for developers implementing form capabilities, specifically those handling card data updates and proxy refresh mechanisms within SystemCapability.Ability.Form.
