# interface_JsonSerializable

本目录包含仓颉语言中 `JsonSerializable` 接口的 API 参考文档，涵盖了该接口的核心定义及其针对多种数据类型的扩展实现。内容涉及基础数值类型（如 Int、Float）、字符串、集合类型（如 Array、HashMap、Option）以及特殊类型（如 DateTime、BigInt）的 JSON 序列化机制。核心功能是通过 `toJson` 方法将数据写入 `JsonWriter` 以实现流式编码。本文档适合需要在仓颉程序中进行 JSON 数据处理和序列化的开发者阅读。
