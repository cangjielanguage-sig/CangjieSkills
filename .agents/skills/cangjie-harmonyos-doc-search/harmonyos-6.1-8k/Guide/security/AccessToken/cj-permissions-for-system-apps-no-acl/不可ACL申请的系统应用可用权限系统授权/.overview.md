# 不可ACL申请的系统应用可用权限系统授权

本目录包含关于OpenHarmony系统中不可通过ACL申请但系统应用可用的权限授权文档。内容涵盖了特定系统权限的定义、功能、保护级别及授权方式，重点介绍了分布式硬件、锁屏UI扩展、开机广播及网络管理等敏感权限。这些权限通常要求APL等级为system_basic或system_core，且授权方式为system_grant。本文档主要面向系统开发者及应用工程师，旨在帮助其理解权限申请限制、确认应用资格并提升开发效率。
