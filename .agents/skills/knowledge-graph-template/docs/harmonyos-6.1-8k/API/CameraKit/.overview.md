# CameraKit

CameraKit is a comprehensive documentation repository dedicated to the Cangjie (仓颉) programming language's camera services within the HarmonyOS and OpenHarmony ecosystems. It focuses on the `ohos.multimedia.camera` module, providing essential resources for multimedia application development. This collection covers core API references, interface usage guidelines, and comprehensive error code lists. Currently in the Beta stage, these documents are vital for developers to understand feature boundaries, implement correct interface calls, and perform efficient troubleshooting. It is suitable for both beginner and senior engineers working with Cangjie to integrate stable camera functionalities into their applications, ensuring robust performance across various devices.

## Detailed Description

### README_zh/
This directory serves as the documentation index center for the Cangjie language Camera Kit, designed for engineers developing multimedia applications using the Cangjie language. It centrally manages technical materials related to the `ohos.multimedia.camera` module, covering core API interface references and a complete list of error codes. As the current functionality is in the Beta stage, this documentation is crucial for developers to understand the boundaries of camera management features, correctly call interfaces, and perform efficient exception troubleshooting. Both beginners and senior developers can use this entry point to quickly locate necessary technical details, ensuring smooth integration and stable operation of camera functions.

### cj-apis-multimedia-camera/
This directory contains the comprehensive API reference documentation for the camera management module specifically designed for the Cangjie programming language within the HarmonyOS and OpenHarmony ecosystems. It serves as a critical resource for developers looking to implement camera functionalities using Cangjie, providing detailed interface definitions and usage guidelines to facilitate effective development.

### cj-errorcode-multimedia-camera/
This directory specifically collects error code reference documentation for the Camera module, serving as an important resource for multimedia application developers debugging camera functions. The documentation details various error situations ranging from basic parameter validation to complex service exceptions, including but not limited to invalid input parameters, illegal operations, unconfigured or inactive sessions, configuration locks, camera conflicts, and service exceptions. By providing clear error messages, in-depth cause analysis, and specific handling steps, this document aims to help developers quickly locate the root cause of problems, ensuring applications can efficiently and stably manage camera resources and states. It is primarily targeted at multimedia application developers and serves as the authoritative guide for handling camera-related exceptions.
