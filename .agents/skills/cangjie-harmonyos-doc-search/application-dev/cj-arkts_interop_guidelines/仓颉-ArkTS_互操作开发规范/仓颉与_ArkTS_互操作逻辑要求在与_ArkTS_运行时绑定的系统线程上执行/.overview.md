# 仓颉与_ArkTS_互操作逻辑要求在与_ArkTS_运行时绑定的系统线程上执行

This directory provides comprehensive technical guidelines on the threading requirements essential for interoperability between the Cangjie language and ArkTS in HarmonyOS development. It emphasizes the strict rule that all cross-language logic must execute on the system thread bound to the ArkTS runtime to maintain application stability. The content covers critical concepts such as the distinction between Cangjie user-level threads and ArkTS system threads, thread management APIs like `JSContext.isInBindThread()`, and mechanisms for module registration. It is designed for developers working on native-JS integration who need to handle multi-threading contexts and avoid runtime exceptions like `JSThreadMisMatch`.
