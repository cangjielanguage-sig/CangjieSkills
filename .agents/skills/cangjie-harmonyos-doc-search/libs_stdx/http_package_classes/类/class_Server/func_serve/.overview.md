# func_serve

This directory contains comprehensive technical documentation for the `func_serve` module, a robust backend component designed to initiate and manage server-side processes for both HTTP/1.1 and HTTP/2 traffic. It provides in-depth specifications on request validation, response generation, connection management, and protocol negotiation via TLS ALPN. Key technical areas include strict RFC 9112 compliance enforcement, header processing rules, stream management, and flow control mechanisms. The documentation is specifically tailored for backend developers and system engineers who are implementing, configuring, or debugging the core HTTP server logic, ensuring high performance and strict adherence to web protocol standards. It serves as a critical reference for maintaining server stability, handling edge cases like 100-continue, and managing resource limits effectively.

## Detailed Description

The following files provide granular technical specifications for the `func_serve` implementation. They cover the full lifecycle of request handling, from initial connection and protocol selection to specific validation rules for both HTTP/1.1 and HTTP/2 standards.

### func_serve_1.md

This API documentation details the `serve()` function, which initiates a server-side process that handles HTTP/1.1 and HTTP/2 traffic. It covers HTTP/1.1 request validation (headers, syntax, size limits), response generation rules (defaults, body handling, connection management), and HTTP/2 activation via TLS ALPN. The function enforces strict RFC 9112 compliance, automatically manages connection headers, handles specific status codes like 100-continue, and prevents duplicate server starts. This technical reference is intended for backend developers implementing or configuring the HTTP server.

### func_serve_2.md

This document outlines the operational rules and validation logic for an HTTP/2 server implementation. It covers request validation regarding headers, trailers, and pseudo-headers, alongside response processing details like automatic header modification and body handling. Key topics include stream management, flow control mechanisms using 65535 initial windows, request prioritization by urgency, and protocol selection via ALPN. The document specifies strict compliance rules, often resulting in stream closure for invalid headers. This technical reference is intended for developers configuring or debugging the HTTP/2 server behavior, ensuring adherence to protocol standards and resource management.
