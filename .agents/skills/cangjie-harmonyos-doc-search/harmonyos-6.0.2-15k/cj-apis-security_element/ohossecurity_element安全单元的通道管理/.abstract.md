This directory contains API reference documentation for the `ohos.security_element` module in HarmonyOS, focusing on managing communication channels for Secure Elements (SE) such as eSE and SIM cards. It covers core classes including Reader, Session, Channel, and SEService, alongside essential enums and service creation functions. Designed for developers using the Cangjie language, these resources provide the necessary interfaces to establish connections, handle data transmission compliant with ISO/IEC 7816 standards, and manage the lifecycle of secure hardware interactions.
