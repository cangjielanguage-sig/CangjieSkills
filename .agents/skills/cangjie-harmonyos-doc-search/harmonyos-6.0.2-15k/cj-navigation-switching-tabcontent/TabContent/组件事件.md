## 组件事件

### func onWillHide(() -> Unit)

```cangjie
public func onWillHide(callback: () -> Unit): This
```

**功能：** 逻辑回调，TabContent将要隐藏的时候触发该回调。场景包括TabContent切换，页面切换，窗口前后台切换。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|()->Unit|是|-|TabContent将要隐藏的回调函数。|
