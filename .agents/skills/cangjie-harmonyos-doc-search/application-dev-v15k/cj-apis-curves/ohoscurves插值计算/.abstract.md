This directory provides comprehensive API reference documentation for the `ohos.curves` module and associated classes within the Cangjie ArkUI framework. It focuses on interpolation calculations essential for creating smooth and dynamic UI animations. The content covers the core `ICurve` interface, module setup, and a wide variety of curve implementations, including standard cubic Bezier curves, step functions, and physics-based spring animations. Key concepts include normalized time parameters, automatic value clamping, and motion timing control. This documentation is specifically designed for ArkUI developers using the Cangjie language who aim to enhance user experience through complex, non-linear, and realistic motion effects in their applications.
