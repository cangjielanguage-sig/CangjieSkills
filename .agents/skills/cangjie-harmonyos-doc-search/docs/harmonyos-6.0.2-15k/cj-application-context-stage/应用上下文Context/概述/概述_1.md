## 概述

[Context](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-context)是应用中对象的上下文，其提供了应用的一些基础信息，例如[resourceManager](../../API_Reference/source_zh_cn/apis/LocalizationKit/cj-apis-resource_manager.md#class-resourcemanager)（资源管理）、[applicationInfo](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-bundle_manager.md#struct-applicationinfo)（当前应用信息）、[dir](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#prop-cachedir)（应用文件路径）、[area](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#enum-areamode)（文件分区）等，以及应用的一些基本方法，例如[getApplicationContext()](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#func-getapplicationcontext)等。[UIAbility](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-uiability)组件和各种[ExtensionAbility](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-extensionability)派生类组件都有各自不同的Context类，包括基类Context、[ApplicationContext](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-applicationcontext)、[AbilityStageContext](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-abilitystagecontext)、[UIAbilityContext](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-uiabilitycontext)、[ExtensionContext](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-extensioncontext)等。

- 各类Context的获取方式
    - 获取[UIAbilityContext](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-uiabilitycontext)。每个[UIAbility](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-uiability)中都包含了一个Context属性，提供操作应用组件、获取应用组件的配置信息等能力。

    ```cangjie
    import kit.AbilityKit.{UIAbility, Want, LaunchParam}
    import kit.UIKit.AppLog
    import kit.ArkUI.WindowStage

    class MainAbility <: UIAbility {
        public override func onCreate(want: Want, launchParam: LaunchParam): Unit {
            let abilityContext = this.context
            // ...
        }

        public override func onWindowStageCreate(windowStage: WindowStage): Unit {
            AppLog.info("MainAbility onWindowStageCreate.")
            windowStage.loadContent("EntryView")
        }
    }
    ```

     > **说明：**
     >
     > 页面中获取Ability实例的上下文信息请参见[获取UIAbility的上下文信息](cj-uiability-usage.md#获取uiability的上下文信息)。

    - 获取[AbilityStageContext](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-abilitystagecontext)（Module级别的Context）。和基类Context相比，额外提供[HapModuleInfo](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-bundle_manager.md#struct-hapmoduleinfo)、[AbilityConfiguration](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-abilityconfiguration)等信息。

    ```cangjie
    import kit.AbilityKit.AbilityStage

    class MyAbilityStage <: AbilityStage {
        public override func onCreate(): Unit {
            let abilityStageContext = this.context
            //...
        }
    }
    ```
