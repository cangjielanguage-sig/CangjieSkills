# 基础类型定义

本目录主要定义了 ArkUI 框架中 Swiper 轮播组件相关的核心基础类型，涵盖了指示器与控制器两大类。内容详细介绍了如何通过 API 配置数字指示器、圆点指示器以及通用指示器的样式、布局和交互行为，同时提供了 SwiperController 用于管理组件的翻页逻辑与动画效果。这些文档基于仓颉语言编写，适用于 HarmonyOS 应用开发，特别是需要精细控制轮播图导航显示及切换逻辑的开发者查阅。

## 详细描述

### class_DigitIndicator.md class_DigitIndicator.md
本文档是 DigitIndicator 类的 API 参考文档，旨在定义 Swiper 组件中数字导航点的样式。文档主要内容包括类定义、构造函数以及用于配置字体样式和颜色的方法，如 digitFont、fontColor、selectedDigitFont 和 selectedFontColor。关键信息指出该类继承自 Indicator，支持自定义普通与选中状态的文本外观，起始版本为 22。文档面向使用仓颉语言开发 HarmonyOS ArkUI 界面的开发者，适用于需要精细控制数字分页指示器显示效果的场景。

### class_SwiperController_fad2550c.md class_SwiperController_fad2550c.md
本文档是 ArkUI 框架下 SwiperController 类的 API 参考文档，主要介绍如何通过该控制器管理 Swiper 组件的翻页及动画。文档涵盖了类的构造函数 init、用于停止播放动画的 finishAnimation 方法（支持回调参数）、以及实现翻页功能的 showNext 和 showPrevious 方法。核心要点在于开发者需定义该对象并绑定至 Swiper 组件，以控制子组件的带效切换。该文档面向使用 Cangjie 语言进行 ArkUI 应用开发的开发人员，提供了组件控制的具体接口说明。

### class_DotIndicator/
本目录包含仓颉语言中 DotIndicator 类的 API 参考文档，主要用于在 ArkUI 框架下配置 Swiper 组件的圆点导航指示器。内容涵盖了指示器的构造函数、核心属性设置（如颜色、宽高、蒙版显示及最大显示数量）以及选中状态的样式配置。该文档详细说明了交互视觉效果（如按压放大）和尺寸限制，适合使用仓颉语言进行 HarmonyOS 应用开发并希望自定义轮播图导航样式的开发者查阅。

### class_Indicator/
本目录包含 Cangjie 语言及 ArkUI 框架中 `Indicator` 类的 API 参考文档，专注于 Swiper 组件导航点（指示器）的配置与管理。内容涵盖了指示器的创建（数字或圆点）、位置布局（如 start、top、bottom、left 等）以及样式设置。文档详细阐述了布局优先级规则、取值范围限制及默认交互区域高度等关键细节。该资料适合需要精细控制 Swiper 组件导航点行为与布局的 ArkUI 开发者阅读。
