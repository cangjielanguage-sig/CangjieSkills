# 基础类型定义

This directory provides essential API reference documentation for fundamental data structures utilized in touch event handling within the Cangjie ArkUI framework. It specifically defines classes and enumerations that manage touch test results, dispatch strategies, and coordinate geometry. Key components include the `TouchResult` class for overriding system hit testing, the `TouchTestStrategy` enum for controlling event propagation, and the `TouchTestInfo` class for encapsulating precise touch location data. This documentation is intended for HarmonyOS developers who require granular control over touch interactions, custom component behavior, and event flow management in their applications. By understanding these base types, developers can implement sophisticated gesture recognition and custom UI behaviors that go beyond standard system defaults.

## Detailed Description

The following files detail the specific classes and enums available for managing touch interactions, providing the structural definitions necessary for advanced UI development.

### class_TouchResult_2more.md class_TouchResult_2more.md
This API reference documentation defines the TouchResult class and TouchTestStrategy enum for customizing touch event dispatch in the Cangjie ArkUI framework. It details the class constructors, which accept a strategy and an optional component ID, alongside the three specific dispatch strategies: DEFAULT, FORWARD, and FORWARD_COMPETITION. Key information includes how the strategy parameter dictates event flow to child nodes and the requirement for the ID parameter in non-default scenarios. Intended for HarmonyOS developers, this document provides the necessary interfaces to override standard system hit testing and control event propagation behavior.

### class_TouchTestInfo.md class_TouchTestInfo.md
This document provides API reference documentation for the Cangjie class TouchTestInfo, which encapsulates coordinate and identification data for touch points within the ArkUI framework. The content details the class structure, read-only properties for various coordinate systems (window, parent, and component), component ID, and size information, alongside the class constructor. Key information includes the storage of Float32 coordinates for precise touch location tracking, a RectResult for component dimensions, and a unique String ID. This reference is intended for ArkUI developers needing to handle touch event geometry and component identification in version 19 or later.
