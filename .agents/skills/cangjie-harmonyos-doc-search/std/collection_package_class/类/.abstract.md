This directory contains API reference documentation for core collection classes in the Cangjie programming language. It covers a wide range of data structures including lists, sets, maps, queues, and stacks, as well as specific iterators and nodes. Key topics include dynamic arrays, linked lists, hash-based storage, and tree-based ordered collections. The documentation details class definitions, constructors, properties, and manipulation methods. It is suitable for Cangjie developers seeking to implement efficient data management, requiring knowledge of generic types, interfaces like `Hashable` and `Comparable`, and standard collection operations.
