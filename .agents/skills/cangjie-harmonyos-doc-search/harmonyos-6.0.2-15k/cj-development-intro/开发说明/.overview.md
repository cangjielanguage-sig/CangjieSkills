# 开发说明

This directory provides essential documentation for developers working with the Cangjie language and the HarmonyOS SDK. It covers the practical execution of Cangjie API code snippets, interpretation of API documentation fields, and the management of permissions and application models. Key topics include integrating code into project templates, understanding SystemCapability (SysCap) for device compatibility, and adhering to the Stage model constraints. This resource is suitable for Cangjie application developers who need to effectively reference API examples, navigate SDK specifications, and ensure compliance with system access rules and lifecycle requirements.

## Detailed Description

### 仓颉示例代码说明.md 仓颉示例代码说明.md
This document serves as a practical guide for developers on how to execute Cangjie API code snippets, which are not standalone programs but require integration into a project template. The content outlines a step-by-step process involving creating a Cangjie template project, inserting sample code into the index.cj file within the EntryView class, and configuring main_ability.cj to manage Context objects by defining a Global class. Key takeaways include the necessity of placing code in specific locations and the specific implementation pattern for accessing application context. This tutorial targets Cangjie developers seeking to reference and run API examples effectively.

### 开发说明_4more.md 开发说明_4more.md
This document serves as a usage guide for developers reading API documentation within the HarmonyOS-Cangjie SDK ecosystem. It clarifies common documentation fields to facilitate easier API lookup and implementation. The main sections cover version specifications, SystemCapability (SysCap) definitions, and interface usage instructions. Key takeaways include understanding version support indicators, utilizing SysCap to determine device compatibility via lists or the canIUse method, and importing Kits to access encapsulated interface modules. The document targets application developers who need to understand system capabilities and correctly import SDK modules for their projects.

### 权限说明_3more.md 权限说明_3more.md
This document serves as a reference guide for developers using the Cangjie API, outlining permission requirements, application model constraints, and deprecated interface handling. It covers permission application processes, distinguishes between FA and Stage application models, and explains the lifecycle and compatibility of deprecated interfaces. Key information includes the critical constraint that Cangjie APIs are exclusively compatible with the Stage model. Permissions are explicitly marked in interface descriptions, and deprecated interfaces remain compatible for five API levels but require migration to alternatives. This guide targets application developers needing to understand system access rules and API evolution within the Cangjie development environment.
