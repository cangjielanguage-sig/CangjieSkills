# 保存用户文件

This directory contains technical guides for saving user files in the HarmonyOS environment using the Cangjie language. It covers various file types and saving modes, including document handling, audio files, and specific download modes. Key topics include FilePicker usage, permission management, URI handling, and system file interactions. These resources are designed for application developers looking to implement secure file storage, download features, or save-as functionality within their apps.

## Detailed Description

### DOWNLOAD模式保存文件.md DOWNLOAD模式保存文件.md
This technical guide explains how to implement the DOWNLOAD mode for saving files using the DocumentViewPicker in a Cangjie development environment. The document covers mode characteristics, required module imports, configuration of DocumentSaveOptions, and the implementation of the save callback logic. Key takeaways include that DOWNLOAD mode automatically creates a Download/包名/ directory, bypasses the file selection interface, and returns a URI with persistent permissions. It is important to note that other documentSaveOptions parameters are ignored when this mode is active. This tutorial targets HarmonyOS developers using Cangjie who need to save files directly to a specific download path without user intervention.

### 保存用户文件_3more.md 保存用户文件_3more.md
This technical guide instructs developers on saving user files using the FilePicker capability in the Cangjie development environment. It covers permissions, system isolation, media file handling, and a detailed tutorial for saving document files. Key points include the temporary nature of Picker permissions, the deprecation of PhotoViewPicker for media, and the specific workflow for documents involving DocumentSaveOptions, URI retrieval, and FileFs operations. The content targets application developers implementing file download or save-as features who need to manage file storage and access permissions securely.

### 保存音频类文件.md 保存音频类文件.md
This tutorial provides a step-by-step guide for developers on saving audio files using the Cangjie language within a HarmonyOS environment. It covers importing necessary modules, configuring AudioSaveOptions, and utilizing the AudioViewPicker to invoke the system file picker. Key steps include retrieving the file URI, opening the file with FileFs.openSync to obtain a file descriptor, and writing data via FileFs.writeSync. The document highlights best practices such as using global variables for URI storage and specifies the required READ_WRITE mode for file operations. This guide is intended for application developers implementing file saving functionality.
