# cj-universal-gesture-tapgesture

This directory serves as a comprehensive resource for the TapGesture component within the ArkUI framework, specifically designed for the Cangjie programming language. It provides an in-depth API reference that enables developers to implement sophisticated touch recognition capabilities, including single, double, and multi-finger tap events. The documentation thoroughly explains the component's creation via the `init` method, detailing how to specify parameters such as tap count and finger number. It also covers the `onAction` event used for handling successful recognitions and outlines critical technical constraints, such as the 300ms timeout for multi-taps and the 60vp distance limit. Furthermore, the guide includes practical code examples that demonstrate how to manage gesture priority and parallelism between parent and child components. This resource is primarily intended for application developers using Cangjie to build interactive and responsive touch interfaces for HarmonyOS applications.
