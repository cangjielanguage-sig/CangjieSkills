# 支持适老化

This directory focuses on "Age-Friendly Adaptation" (适老化) for application development, specifically within the Cangjie framework and HarmonyOS ecosystem. It covers how to adapt applications for elderly users by supporting system font scaling, ensuring layout stability, and utilizing system component magnification features like "Care Mode." Key topics include configuration methods (JSON), specific scaling levels (1x to 3.2x), and component-specific behaviors (long-press vs. automatic scaling). This resource is suitable for developers aiming to enhance accessibility and user experience for elderly demographics.

## Detailed Description

### 支持适老化_3more.md 支持适老化_3more.md
This guide instructs developers on adapting applications for elderly users by supporting system font scaling and ensuring layout stability. It covers adaptation rules, specific font scaling levels ranging from 1x to 3.2x, and configuration methods using JSON files. Key information includes the requirement to prevent layout overlap at 1.75x scaling, setting global limits via `fontSizeMaxScale`, and overriding limits for specific components using the `maxFontScale` attribute. The document also details how to retrieve font size and weight through lifecycle callbacks and context queries. Intended for developers using the Cangjie framework, this technical guide provides code examples for implementing accessibility features.

### 适配适老化的系统组件及触发方式.md 适配适老化的系统组件及触发方式.md
This document outlines the age adaptation feature, which magnifies system components via long-press or system font settings to improve accessibility for elderly users. It covers adaptation rules, activation steps via "Care Mode," operational definitions, popup limitations, and integration with other capabilities like sliding. Key takeaways include the requirement for specific configuration tags and the distinction between components triggered by long-press (e.g., SideBarContainer) versus those scaling automatically with font size (e.g., PickerDialog). Popup magnification is capped at 2x. This technical reference guide targets developers implementing accessibility features, requiring knowledge of system configuration and component interaction.

### 示例代码/
This directory contains example code demonstrating the age-friendliness (适老化) capabilities of UI components in the Cangjie programming language for HarmonyOS development. It focuses on how components like SideBarContainer and DatePickerDialog adapt to system font size adjustments to improve accessibility. The examples include configuration details, styling options, and visual comparisons of UI behavior under different scaling factors, specifically highlighting the transition from standard (1x) to large (1.75x) font sizes. This resource is suitable for developers looking to implement and verify accessibility behaviors, event callbacks, and adaptive layouts in their applications using Cangjie.
