This directory provides a comprehensive introduction to Image Kit within the HarmonyOS ecosystem, focusing on the fundamental concepts and workflows for image development. It covers the core stages of image handling, including decoding to PixelMap, processing operations like rotation and scaling, and encoding for storage. The content details a five-step development process, highlights efficient multi-format support, and outlines necessary read/write permissions. It also clarifies the framework's relationship with the Image component. This resource is suitable for developers seeking to integrate image manipulation and display capabilities into their applications, offering a foundational understanding of how to effectively manage image resources in a HarmonyOS environment.
