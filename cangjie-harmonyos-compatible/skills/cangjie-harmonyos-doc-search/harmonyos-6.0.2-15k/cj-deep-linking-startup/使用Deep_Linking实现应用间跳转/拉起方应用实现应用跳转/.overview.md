# 拉起方应用实现应用跳转

This directory serves as a comprehensive resource for HarmonyOS developers focusing on the implementation of application jumping functionality from the calling application (拉起方). It specifically addresses the use of the Cangjie language and the ArkUI framework to enable seamless navigation between different applications. The content covers critical techniques such as intercepting DeepLinks within Web components to trigger native jumps, utilizing the `openLink` interface with specific configurations, and employing `startAbility` through implicit Want matching. These guides are suitable for developers aiming to integrate complex cross-application navigation, web-to-native transitions, and deep linking capabilities into their HarmonyOS projects.

## Detailed Description

### 使用Web组件实现应用跳转

This technical tutorial demonstrates how to implement application navigation from a Web component using DeepLink interception. The document covers the implementation logic utilizing the `onLoadIntercept` callback in Cangjie and provides frontend HTML examples for triggering the jump via `window.open` or anchor tags. Key takeaways include the mechanism for intercepting URL requests, checking for specific DeepLink patterns, and using the `UIAbilityContext.openLink` method to launch the target application while preventing default web loading. This guide targets HarmonyOS developers using the Cangjie language and ArkUI framework who need to integrate web-to-native navigation capabilities.

### 拉起方应用实现应用跳转_3more

This technical guide instructs developers on implementing application jumping functionality using Cangjie. It covers two primary implementation methods: utilizing the `openLink()` interface with specific URL and option configurations, and employing the `startAbility()` interface via implicit Want matching. Key takeaways include the necessity of obtaining the `UIAbilityContext` and the specific parameter requirements for each API, such as setting `appLinkingOnly` to false or defining a URI within a Want object. This tutorial is designed for HarmonyOS developers seeking to integrate cross-application navigation capabilities.
