# interface_AutoExposure

This directory contains essential API reference documentation for the AutoExposure interface, a core component of the CameraKit framework designed for the Cangjie language. It provides developers with the technical specifications needed to implement and manage automatic exposure operations in camera-enabled applications. The content covers a wide array of functionalities, including the configuration of exposure compensation, the selection of auto-exposure modes, and the precise setting of metering points. Additionally, it details system capability requirements, parameter constraints, and error handling protocols. This documentation is specifically intended for software developers and engineers working on multimedia applications who require advanced programmatic control over camera hardware to optimize image capture and processing.

## Detailed Description

### func_setExposureBiasFloat3_3more.md
This document serves as API reference documentation for configuring camera exposure settings using the Cangjie language. It covers three primary functions: setExposureBias for adjusting exposure compensation values, setExposureMode for defining the auto-exposure mode, and setMeteringPoint for specifying the center point of exposure metering. Key information includes parameter constraints, such as automatic clamping of bias values to supported ranges, potential BusinessException errors, and system capability requirements. The content provides code examples demonstrating usage within a PhotoSession. This guide targets developers working with the CameraKit to implement advanced photographic controls in their applications.

### interface_AutoExposure_4more.md
This document serves as API reference documentation for the AutoExposure interface in the Cangjie language, designed to handle device automatic exposure operations within the CameraKit. It covers the interface definition, system capabilities, and detailed specifications for key methods such as getExposureMode, getExposureValue, and getMeteringPoint. Key information includes return types like ExposureMode and Float32, specific error codes for session configuration issues, and code examples demonstrating usage within a photo session. The document is intended for developers building multimedia camera applications who need to programmatically control exposure settings, requiring prerequisite knowledge of Cangjie syntax and camera session management.
