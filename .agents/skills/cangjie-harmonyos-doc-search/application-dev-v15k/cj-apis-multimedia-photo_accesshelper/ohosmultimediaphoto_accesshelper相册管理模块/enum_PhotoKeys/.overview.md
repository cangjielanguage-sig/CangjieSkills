# enum_PhotoKeys

This directory contains API reference documentation for the `PhotoKeys` enum within the Cangjie programming language, specifically designed for the `PhotoAccessHelper` system. It defines keys used to access and query photo and video file metadata, such as URIs, dimensions, timestamps, and file types. The documentation covers enum member definitions, data types, versioning information, and operator overloading for equality and string conversion. Key topics include the distinction between standard and millisecond-precision timestamps and specific constraints on query predicates. This resource is suitable for developers working on file management systems who need to manipulate or query media file attributes using Cangjie syntax and photo access helper capabilities.
