This directory contains API documentation for managing secure camera operations and event listeners in the Cangjie programming language. It focuses on the `SecureSession` class, which facilitates high-security applications like face recognition and banking by integrating with a Secure Trusted Application (TA). Additionally, it covers functions for registering and unregistering camera callbacks, specifically for error handling and focus state changes. This documentation is suitable for developers using CameraKit who need to implement secure preview streams or manage camera events programmatically.
