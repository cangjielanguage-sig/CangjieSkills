This directory serves as a comprehensive technical guide for the Harmony Ability Package (HAP), which acts as the fundamental unit for HarmonyOS application installation, execution, and distribution. It provides in-depth coverage of HAP architecture, clearly distinguishing between entry and feature types, and offers best practices for optimizing resource loading through single versus multi-HAP configurations. The content extends to the full application lifecycle, providing detailed procedures for debugging, installing, and updating packages using both DevEco Studio and command-line tools such as hdc and bm. Key technical topics include bundle naming conventions, signing certificate consistency, HAR references, and deployment commands. This resource is specifically tailored for HarmonyOS developers, particularly those utilizing the Cangjie language, who need to efficiently structure, package, and debug their applications. It addresses specific constraints regarding configuration and signing, ensuring developers adhere to strict requirements for consistent bundle names across modules within the broader HarmonyOS ecosystem.
