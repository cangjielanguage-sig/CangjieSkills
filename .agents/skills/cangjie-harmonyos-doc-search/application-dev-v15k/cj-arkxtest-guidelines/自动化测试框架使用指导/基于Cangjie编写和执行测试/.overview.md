# 基于Cangjie编写和执行测试

This directory serves as a comprehensive resource for developers working with the Cangjie language in the OpenHarmony ecosystem, focusing specifically on the complete testing lifecycle. It guides users through the initial setup of the HarmonyOS development environment using DevEco Studio, proceeds to the creation of robust unit and UI test scripts, and concludes with methods for executing these tests via both graphical interfaces and command-line tools. Key topics include environment configuration, the use of assertions, the UiTest framework, and the interpretation of XML test results. This documentation is tailored for HarmonyOS application developers and QA engineers seeking to establish a reliable automated testing workflow.

## Detailed Description

The following files provide step-by-step instructions for each stage of the testing process.

### 执行测试脚本.md 执行测试脚本.md
This guide instructs developers on executing test scripts for OpenHarmony applications using DevEco Studio or the command line. It details the graphical execution within DevEco Studio and the command-line interface (CMD) using the aa test command. Key takeaways include the necessity of hardware connection, specific command parameters like -b for bundle name and -s for custom runners, and the interpretation of XML-based test results. The document notes that only TestClass-level execution is currently supported via CMD. Targeted at developers and testers using the OpenHarmony toolchain, requiring knowledge of hdc environment variables for CLI usage.

### 搭建环境.md 搭建环境.md
This document provides a brief guide for setting up the HarmonyOS development environment. The content focuses on the initial step of obtaining the necessary integrated development environment. Key information includes a direct reference to the official website for downloading DevEco Studio and instructions to perform subsequent configuration actions. This guide is designed for developers preparing to build HarmonyOS applications, serving as a starting point for environment preparation. Keywords include DevEco Studio, HarmonyOS, environment setup, and configuration.

### 新建和编写测试脚本.md 新建和编写测试脚本.md
This guide instructs developers on creating and writing test scripts within DevEco Studio using the Cangjie language. It covers creating Instrument Tests in the ohosTest directory, writing unit test scripts with assertions, and developing UI test scripts using the UiTest framework. Key information includes the requirement for unit tests to contain imports, logic, and assertions like @Expect, while UI tests extend these capabilities by utilizing a Driver to simulate interactions such as clicking components and verifying text changes. This tutorial targets HarmonyOS application developers who need to implement unit and UI testing on devices or emulators.
