# extend_UInt64_CheckedOpUInt64

This directory serves as a comprehensive API reference for the `CheckedOp` interface implementation specifically designed for the `UInt64` type within the Cangjie programming language. It focuses on providing safe arithmetic and bitwise operations that prevent undefined behavior by handling potential errors explicitly. The documentation covers a wide range of functions, including basic arithmetic like addition, multiplication, division, and modulo, as well as increment, decrement, negation, subtraction, and bitwise shifts. A core feature of these operations is the use of the `Option` return strategy, which returns `None` upon overflow or invalid input rather than wrapping values or throwing exceptions. This resource is essential for Cangjie developers who prioritize safety and robustness in their numerical logic, particularly when working with unsigned 64-bit integers where overflow risks are high.
