This module provides comprehensive API reference documentation for the PhotoAccessHelper system in the Cangjie programming language, specifically focusing on album management and media asset handling within HarmonyOS. It covers core functionalities such as album creation, modification, asset retrieval, and change monitoring. Key components include classes for managing albums and photo assets, enums for defining types and subtypes, and configuration options for data fetching. This documentation is suitable for developers building file management or media gallery applications who require programmatic access to system media libraries, assuming familiarity with Cangjie syntax and system capabilities.
