# 用户相册资源使用指导

This directory provides a comprehensive guide for HarmonyOS developers on managing user album resources using the MediaLibraryKit and Cangjie programming language. It covers essential operations such as retrieving album lists, accessing images and videos, renaming albums, adding media, and removing assets. Key topics include permission handling, `photoAccessHelper` usage, and `MediaAlbumChangeRequest` implementation. This resource is suitable for developers building media-centric applications who need programmatic control over the device's media library.

## Detailed Description

### 用户相册资源使用指导_2more.md 用户相册资源使用指导_2more.md
This document serves as a usage guide for developers to manage user albums using the photoAccessHelper module, specifically focusing on retrieving album resources. It covers prerequisites such as obtaining the module instance and applying for the 'ohos.permission.READ_IMAGEVIDEO' permission. The main section details the step-by-step process of fetching user albums using the getAlbums interface, including setting search predicates and configuring FetchOptions. Key takeaways include Cangjie code examples demonstrating how to execute the query and handle results. Targeted at HarmonyOS developers, this guide assumes prior knowledge of development preparation and that resources are pre-existing in the database.

### 获取用户相册中的图片和视频.md 获取用户相册中的图片和视频.md
This tutorial guides developers on retrieving images and videos from a specific user album using the MediaLibraryKit in the Cangjie programming language. It covers prerequisites such as obtaining the photoAccessHelper instance and requesting necessary permissions like 'ohos.permission.READ_IMAGEVIDEO'. The document outlines a six-step development process involving setting predicates, calling getAlbums to locate the album, and using getAssets to fetch media resources. It provides complete Cangjie code examples demonstrating these API calls and error handling. Targeted at HarmonyOS application developers, this guide explains the essential workflow for accessing user media libraries programmatically.

### 重命名用户相册.md 重命名用户相册.md
This document serves as a development guide explaining how to rename user albums by modifying the Album.albumName property using the MediaLibraryKit. It details the necessary prerequisites, including specific permissions and obtaining the photoAccessHelper instance, and outlines strict naming constraints such as character limits and forbidden symbols. The guide provides a step-by-step workflow involving fetching the album, creating a MediaAlbumChangeRequest, and applying changes to the database. It includes a Cangjie code example demonstrating the implementation. This resource is designed for developers working on media management applications who require programmatic control over album metadata.

### 添加图片和视频到用户相册中/
This directory provides a comprehensive technical guide for HarmonyOS developers aiming to implement media asset management features using the Cangjie programming language. The documentation covers essential prerequisites, such as obtaining the `photoAccessHelper` instance and configuring read/write permissions, as well as the core logic involving `DataSharePredicates` and `MediaAlbumChangeRequest`.
