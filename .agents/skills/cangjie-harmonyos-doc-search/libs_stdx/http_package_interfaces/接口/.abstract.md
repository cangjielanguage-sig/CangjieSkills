This directory provides comprehensive API reference documentation for the core interfaces within the Cangjie HTTP package. It is designed to assist developers in building robust HTTP servers and clients by detailing essential components such as request routing, request handling logic, protocol service creation, and cookie management. Key topics include the `HttpRequestDistributor` for URL path mapping, `HttpRequestHandler` for processing requests, `ProtocolServiceFactory` for HTTP/1.1 and HTTP/2.0 support, and `CookieJar` for RFC 6265-compliant state management. This resource is suitable for backend developers and software engineers seeking granular control over network communication and security protocols in Cangjie applications.
