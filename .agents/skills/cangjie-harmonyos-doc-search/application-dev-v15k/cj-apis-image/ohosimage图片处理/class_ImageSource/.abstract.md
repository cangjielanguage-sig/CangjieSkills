This directory contains API reference documentation for the `ImageSource` class in the Cangjie language, part of the ImageKit framework. It covers functionalities for retrieving image information, decoding images into PixelMaps, handling animated formats like GIF, and managing image metadata (EXIF). Additionally, it includes support for incremental data updates for streaming scenarios. This documentation is suitable for software developers and multimedia engineers building applications that require robust image processing, decoding, and metadata manipulation capabilities using the Cangjie language.
