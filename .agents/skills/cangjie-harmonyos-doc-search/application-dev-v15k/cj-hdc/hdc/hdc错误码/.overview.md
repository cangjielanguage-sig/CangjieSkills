# hdc错误码

This directory serves as a comprehensive repository for troubleshooting guides related to the hdc (HarmonyOS Device Connector) command-line tool. It specifically focuses on resolving error codes that arise during shell command execution, application debugging, and file transfers between the host and device. The documentation covers scenarios such as invalid bundle names, unsupported interactive modes, and version compatibility issues. By providing root cause analysis and specific command-line solutions, these resources are essential for developers and testers aiming to maintain efficient workflows and resolve connectivity obstacles in HarmonyOS application development.

## Detailed Description

### E003001_命令行指定的包名非法.md E003001_命令行指定的包名非法.md
This troubleshooting guide addresses error code E003001, which occurs when an invalid bundle name is specified in the hdc shell command. The document categorizes the issue into three main causes: the application is not installed, not built in debug mode, or not currently running. It provides specific command-line instructions using hdc, bm, and aa tools to verify installation status, check debug configuration, and confirm resource mounting. Key takeaways include the requirement for debug-signed applications and the necessity of starting the app to mount directories. This guide is intended for developers debugging HarmonyOS applications via the command line. Keywords: hdc shell, bundle name, debug mode, HarmonyOS, error code.

This document serves as a troubleshooting reference for specific error codes encountered when using the hdc command-line tool for shell execution and file transfer. Each entry provides the error message, description, root causes (e.g., empty parameters, outdated SDK/ROM), and specific resolution steps like upgrading system versions or correcting input syntax. Targeted at developers and testers working with HarmonyOS device connectivity, this guide helps diagnose and resolve hdc command failures efficiently.
