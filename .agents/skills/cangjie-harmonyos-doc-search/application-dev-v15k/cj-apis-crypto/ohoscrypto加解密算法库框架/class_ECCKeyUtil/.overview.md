# class_ECCKeyUtil

This directory contains API reference documentation for the `ECCKeyUtil` class within the Cangjie programming language ecosystem. It focuses specifically on Elliptic Curve Cryptography (ECC) operations, providing essential tools for handling key parameters and performing point conversions. The documentation covers critical methods for converting encoded byte arrays into Point objects, generating common parameter specifications based on curve NIDs, and encoding point objects back into byte arrays. It includes details on supported formats like COMPRESSED and UNCOMPRESSED, system capabilities, and error handling. This resource is suitable for Cangjie developers implementing security features, particularly those working with the CryptoFramework kit and asymmetric encryption concepts.
