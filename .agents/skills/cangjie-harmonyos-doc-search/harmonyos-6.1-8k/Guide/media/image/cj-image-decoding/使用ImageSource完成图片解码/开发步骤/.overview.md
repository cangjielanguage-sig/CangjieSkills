# 开发步骤

本目录提供了使用仓颉语言在HarmonyOS/OpenHarmony平台上进行图片解码的完整开发指南。内容涵盖了从导入ImageKit模块、通过多种方式（如沙箱路径、资源管理器、文件描述符）获取图片数据，到创建ImageSource实例及生成PixelMap对象的全过程。此外，还详细介绍了标准图片与HDR图片的解码参数配置以及资源释放的最佳实践。该文档适合需要集成图片处理功能的应用开发者参考。

## 详细描述

### 开发步骤_1.md 开发步骤_1.md
本文档是一份关于使用仓颉语言ImageKit进行图片解码的步骤教程。它指导开发者导入必要模块，通过沙箱路径或资源管理器获取图片数据，并创建ImageSource实例。主要章节涵盖了处理文件描述符、字节数组和RawFileDescriptor等不同数据源的方法。文档详细介绍了设置解码参数以生成PixelMap对象的过程。该文档面向HarmonyOS/OpenHarmony平台的应用开发者，提供了将图片处理功能集成到应用中的代码示例。

### 开发步骤_2.md 开发步骤_2.md
本文档旨在指导开发者使用仓颉语言在HarmonyOS中进行图片解码与资源管理。主要内容包括标准图片解码（设置可编辑及像素格式）、HDR图片解码（自动动态范围）以及后续的资源释放步骤。关键信息涉及`createImageSource`、`DecodingOptions`配置及`release`方法调用，以确保内存正确回收。该文档属于开发教程的一部分，面向具备基础HarmonyOS开发能力的应用开发者，重点在于图像处理的前置步骤。
