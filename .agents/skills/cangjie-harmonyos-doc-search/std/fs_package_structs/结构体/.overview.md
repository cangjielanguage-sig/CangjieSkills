# 结构体

This directory contains API reference documentation for core data structures within the Cangjie programming language's file system package. It focuses on essential structs used for file input/output operations, system-level resource management, and path manipulation. Key topics include file handle access via `FileDescriptor`, metadata inspection through `FileInfo`, and cross-platform path handling using `Path`. These resources cover OS-specific behaviors on Unix, Windows, and macOS, addressing concepts like file attributes, permissions, and normalization. This documentation is suitable for Cangjie developers who need to implement robust file system interactions, manage low-level file resources, or handle file paths securely and efficiently across different operating systems.

## Detailed Description

### struct_FileDescriptor.md struct_FileDescriptor.md
This document provides API reference documentation for the Cangjie language's FileDescriptor struct, which is used to access file handle information. The main sections include the struct definition, a conceptual explanation of file handles across different operating systems like Unix and Windows, and the specification of the fileHandle property. Key information highlights that a file handle is an OS-allocated data structure containing file metadata and physical location details, while the fileHandle property exposes this as an IntNative type. This documentation targets Cangjie developers working on file I/O operations who require an understanding of system-level file management and handle retrieval.

### struct_FileInfo/
This directory contains API reference documentation for the `FileInfo` struct in the Cangjie programming language's file system package. It covers file metadata retrieval, attribute inspection, and permission management. Key topics include file size, timestamps, access rights (read/write/execute), and platform-specific behaviors on Windows and Linux/macOS. The documentation highlights critical considerations such as the lack of data caching in `FileInfo` and potential race conditions during file operations. This resource is suitable for Cangjie developers who need to programmatically inspect and manage file system attributes and permissions securely and efficiently.

### struct_Path/
This directory contains comprehensive API reference documentation for the `Path` struct within the Cangjie programming language's file system package. It covers the struct's definition, properties, methods, and operator overloads designed for representing and manipulating local file system paths. Key topics include path normalization, component extraction (like file names and extensions), parent directory retrieval, and equality comparisons. The documentation details OS-specific behaviors, constraints, and exception handling. It is suitable for developers working on file I/O operations who need precise, cross-platform path manipulation logic using Cangjie syntax.
