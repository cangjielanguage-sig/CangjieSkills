This directory provides comprehensive technical documentation for developers implementing flashlight (torch) functionality within camera applications using the Cangjie programming language. It covers the complete lifecycle of torch management, from initial hardware capability checks and mode control to real-time status monitoring. Key technical areas include utilizing the CameraKit API, managing state conflicts during camera switching, and registering event listeners for dynamic updates. The guides address specific methods such as `isTorchSupported`, `setTorchMode`, and `TorchStatusChangeCallBack`. This resource is essential for Cangjie developers seeking to robustly integrate hardware lighting controls and handle asynchronous state changes in their multimedia applications. The documentation ensures developers can effectively manage edge cases like automatic torch deactivation during camera transitions and interpret status info parameters correctly.
