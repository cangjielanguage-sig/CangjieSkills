This directory contains API reference documentation for the `HiAppEvent` class in the Cangjie programming language, part of the Performance Analysis Kit for HarmonyOS. It covers application event tracking capabilities, including data processing, configuration, user management, and real-time monitoring. Key functionalities include adding processors, managing event parameters, and configuring storage quotas. This documentation is suitable for Cangjie developers seeking to implement robust analytics, performance monitoring, and event-driven logging in their applications, with detailed guidance on error handling and system capabilities.
