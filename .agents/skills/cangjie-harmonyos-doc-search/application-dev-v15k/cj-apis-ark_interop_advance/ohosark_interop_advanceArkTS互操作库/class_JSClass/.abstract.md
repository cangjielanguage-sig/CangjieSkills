This directory provides API reference documentation for the `JSClass` component in the Cangjie language, focusing on ArkUI cross-language interoperability. It details how to securely reference and manipulate ArkTS class constructors, including extending functionality with accessors and methods. The content covers object instantiation, property management, and the integration of `JSFunction` or `JSLambda` implementations. Targeted at developers utilizing the NAPI subsystem to bridge native code with JavaScript, these documents require familiarity with ArkTS and Cangjie syntax, supporting system capabilities from version 13 onwards.
