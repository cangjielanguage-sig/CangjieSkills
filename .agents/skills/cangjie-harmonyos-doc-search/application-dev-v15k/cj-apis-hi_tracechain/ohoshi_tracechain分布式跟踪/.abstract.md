This directory contains API reference documentation for the `ohos.hi_tracechain` module in the Cangjie programming language, designed for HarmonyOS distributed tracing. It covers the core classes and enums required to implement, configure, and manage distributed service call chains. Key components include the `HiTraceChain` class for lifecycle management, `HiTraceId` for identification, and various enums for flags and tracepoint types. This documentation is suitable for HarmonyOS developers and system integrators focused on performance analysis, fault diagnosis, and monitoring business logic flows across threads, processes, and devices.
