## Detailed Description

### enum_JsonToken/

This subdirectory contains the comprehensive API reference documentation for the `JsonToken` enumeration, which is a fundamental part of the Cangjie programming language's standard library for handling JSON data. The primary focus of this documentation is on the token type definitions that are utilized during the parsing of JSON data streams. It offers an in-depth look at the various enumeration members available to developers, such as structural markers like `BeginArray` and primitive value types like `JsonBool`.

Beyond simple definitions, the content illustrates the practical application of these tokens, specifically how they are used in conjunction with the `JsonReader.peek()` method. This method is crucial for stream-based processing, as it allows developers to inspect the upcoming token in the data stream without actually consuming it, thereby enabling more robust parsing logic and error handling.

Additionally, the documentation covers the implementation of operator overloading for equality operations, ensuring that token instances can be compared intuitively. It also highlights that the module fully implements the `Equatable` and `Hashable` interfaces. This is particularly important for developers who need to use these tokens as keys in hash-based collections or require strict equality checks for state validation. Overall, this directory is an essential resource for developers engaged in JSON structure judgment and high-performance stream reading tasks.
