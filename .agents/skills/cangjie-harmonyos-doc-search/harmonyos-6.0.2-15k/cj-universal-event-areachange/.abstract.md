This directory contains the complete API reference documentation for the `onAreaChange` universal event, a vital feature for developers working within the Cangjie UI framework. It offers an in-depth technical explanation of how to configure and manage callbacks that are triggered by alterations in a component's size or position. The documentation meticulously covers the function signature, input parameters, and critical behavioral constraints, specifically highlighting that the event is designed to respond only to layout changes and not to rendering transformations such as translate or offset. By providing a clear code example that demonstrates the capture and display of old and new area values, this guide serves as a practical tool for UI developers. It is intended for ArkUI professionals who need to ensure their applications can accurately monitor and react to component geometry changes, facilitating the creation of highly responsive and adaptive user interfaces. This resource is crucial for maintaining layout integrity in complex applications.
