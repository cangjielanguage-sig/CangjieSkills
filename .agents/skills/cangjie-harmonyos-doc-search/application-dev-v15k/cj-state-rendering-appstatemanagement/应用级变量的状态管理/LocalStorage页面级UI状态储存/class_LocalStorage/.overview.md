# class_LocalStorage

This directory contains API reference documentation for the `LocalStorage` class in the Cangjie language, specifically designed for ArkUI applications. It covers the management of page-level UI state storage, including constructors, property retrieval, data binding (one-way and two-way), and storage manipulation functions like clearing, deleting, and setting values. Key concepts include state synchronization, generic types, and lifecycle management. This documentation is suitable for HarmonyOS developers using Cangjie and ArkUI who need to implement robust state management mechanisms in their applications.

## Detailed Description

### class_LocalStorage_5more.md class_LocalStorage_5more.md
This document serves as API reference documentation for the LocalStorage class in the Cangjie language, designed for managing page-level UI state storage in ArkUI applications. It details the class constructor, the prop function for retrieving one-way bindings, and management functions like clear and delete for removing properties. Key information includes that properties can only be deleted if they have no active subscribers, such as those linked via @LocalStorageLink or @LocalStorageProp. The prop method specifically provides read-only access that does not sync changes back to the storage. This guide targets HarmonyOS developers using Cangjie and ArkUI who need to implement state management mechanisms.
