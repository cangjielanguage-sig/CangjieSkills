# cj-development-intro

This directory serves as the definitive introductory resource and comprehensive guide for developers working with the Cangjie programming language within the HarmonyOS SDK ecosystem. It acts as a central hub for understanding the essential workflows and best practices required for successful application development. The content covers critical operational aspects of the development lifecycle, providing detailed instructions on how to integrate and execute sample code, interpret complex API documentation with a specific focus on versioning and SystemCapabilities, and manage permissions and application models effectively. Key educational topics include the creation of project templates, the application of the `canIUse` method for robust feature verification, ensuring full compatibility with the Stage model, and the proper handling of deprecated interfaces to future-proof applications. This content is specifically suitable for Cangjie and HarmonyOS developers who aim to ensure correct API implementation, maintain long-term code stability, and strictly comply with system security requirements across a wide range of hardware configurations.

### 开发说明/
