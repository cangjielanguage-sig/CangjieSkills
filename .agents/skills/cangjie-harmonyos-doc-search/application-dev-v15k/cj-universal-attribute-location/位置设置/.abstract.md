This directory provides comprehensive API reference documentation for configuring component positioning and alignment within the ArkUI framework using the Cangjie language. It covers essential layout mechanics including absolute and relative positioning, anchor point adjustments, layout direction, and alignment rules for various containers. Key topics include functions like `markAnchor`, `offset`, `position`, and `align`, alongside definitions for fundamental types like `AlignRuleOption` and `Bias`. This resource is suitable for UI developers and HarmonyOS application builders seeking precise control over spatial arrangement and responsive design behaviors.
