# 接口

This directory contains API reference documentation for core interfaces within the Cangjie unittest framework. It covers essential components for data-driven testing, including data generation strategies (DataProvider, DataStrategy), test case minimization (DataShrinker), and output formatting (PrettyPrintable, KeyFor). These documents define method signatures, properties, and implementations for standard types like Array and Range. This resource is suitable for developers implementing property-based testing, parameterized tests, or customizing test output configurations in Cangjie.

## Detailed Description

### interface_DataProvider_2more.md interface_DataProvider_2more.md
This document serves as API reference documentation for the Cangjie language, defining core interfaces used in data-driven testing strategies. It details the DataProvider interface, which supplies test data via a provide method returning an Iterable, and the DataShrinker interface, used to minimize test cases during debugging. The text also explains how standard types like Array and Range are extended to implement DataProvider. Key takeaways include the method signatures for data generation and shrinking logic. This reference is intended for developers implementing property-based testing or custom data strategies in Cangjie.

### interface_DataStrategy.md interface_DataStrategy.md
This document serves as API reference documentation for the Cangjie DataStrategy interface, which defines data generation strategies for parameterized testing. It details the interface's core components, including the provider function for data generation, the shrinker function for data reduction, and the isInfinite property. Additionally, it documents implementations of this interface for Array and Range types, explaining how these standard collections can serve as data sources. Key takeaways include understanding how to configure data providers and shrinkers using a Configuration object to manage test data flow. This technical reference is intended for developers implementing or utilizing parameterized tests within the Cangjie unittest framework.

### interface_PrettyPrintable_2more.md interface_PrettyPrintable_2more.md
This document provides API reference documentation for two specific interfaces within the Cangjie unittest framework: PrettyPrintable and KeyFor. The text details the PrettyPrintable interface, which enables formatted color and indentation printing, and its extensions for Array and ArrayList types. It also explains the KeyFor interface, designed for defining configuration keys with a name property, often used with the @UnitestOption macro. Key takeaways include the pprint method signature and the usage of KeyFor for accessing test configuration values. This guide is intended for developers seeking to extend test output formatting or manage custom test configurations.
