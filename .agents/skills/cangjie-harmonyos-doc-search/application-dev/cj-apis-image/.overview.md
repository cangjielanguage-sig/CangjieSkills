# cj-apis-image

This directory contains API reference documentation for the HarmonyOS multimedia image processing module, specifically designed for the Cangjie programming language. It provides comprehensive resources for developers working with image data streams, covering essential functionalities such as image decoding, encoding, PixelMap manipulation, and metadata management. The documentation focuses on the SystemCapability.Multimedia.Image framework, offering interfaces for efficient image transformation and resource handling. It is suitable for software developers and engineers building multimedia applications who need to implement robust image processing features within the HarmonyOS ecosystem.

### [1] ohosmultimediaimage图片处理/

This directory contains comprehensive API reference documentation for the HarmonyOS multimedia image processing module in the Cangjie programming language. It covers core functionalities including image decoding, encoding, PixelMap manipulation, and metadata management. Key components include ImageSource, ImageReceiver, PixelMap, and various configuration options for handling image data streams and formats. Designed for software developers and engineers building multimedia applications, this documentation provides the necessary interfaces and classes to implement efficient image processing, transformation, and resource management within the SystemCapability.Multimedia.Image framework.
