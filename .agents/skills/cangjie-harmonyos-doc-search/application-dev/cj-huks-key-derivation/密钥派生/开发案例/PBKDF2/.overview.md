# PBKDF2

This directory serves as a comprehensive technical resource for developers implementing PBKDF2 (Password-Based Key Derivation Function 2) cryptographic operations within the HarmonyOS ecosystem. It focuses on utilizing the Universal Keystore Kit (HUKS) to manage secure key derivation processes, specifically tailored for the Cangjie programming language. The content covers critical aspects of cryptographic security, including the configuration of algorithm parameters, session lifecycle management, and the secure storage or deletion of sensitive key material. By providing detailed code examples and workflow demonstrations, this documentation assists developers in integrating robust password-based encryption into their applications. It is particularly suitable for backend engineers, mobile application developers, and security architects who require a deep understanding of hardware-backed keystore operations and secure key management protocols to protect user data effectively and ensure compliance with security standards.

## Detailed Description

Below are the detailed summaries of the files contained in this directory, outlining specific implementation strategies and code structures.

### PBKDF2_1.md PBKDF2_1.md
This document provides a Cangjie code example demonstrating how to perform PBKDF2 key derivation using the Universal Keystore Kit (HUKS). The content details the configuration of parameter sets for key generation, initialization, and finalization stages. Key information includes the specific attributes required for the PBKDF2 algorithm, such as salt, iteration count, and digest method, alongside the storage flags for the resulting AES key. Intended for developers working with cryptographic operations in Cangjie, this tutorial illustrates the complete workflow for deriving and storing secure keys programmatically.

### PBKDF2_2.md PBKDF2_2.md
This document provides code examples for implementing PBKDF2 key derivation using the HarmonyOS Universal Keystore Service (HUKS). It details the session management lifecycle, including initialization, update, and finish operations, alongside key deletion functionality. The content highlights a wrapper pattern for error handling and presents a testDerive function that demonstrates the complete workflow from key generation to cleanup. This technical reference is designed for developers seeking to integrate secure cryptographic operations into HarmonyOS applications, emphasizing the correct sequence of API calls for key derivation.
