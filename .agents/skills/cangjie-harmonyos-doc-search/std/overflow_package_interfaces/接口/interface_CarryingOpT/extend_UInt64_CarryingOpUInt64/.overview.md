# extend_UInt64_CarryingOpUInt64

This directory provides comprehensive API documentation for the `CarryingOp` interface implementation specifically tailored for the `UInt64` type within the Cangjie programming language. It focuses on low-level arithmetic and bitwise operations that utilize a wrapping strategy, enabling developers to detect overflow or truncation explicitly during execution. The documentation covers a wide range of functions, including addition, subtraction, multiplication, division, negation, and bit shifting. Each operation is designed to return a tuple containing a Boolean flag indicating overflow status alongside the resulting `UInt64` value. This resource is essential for Cangjie developers engaged in systems programming, cryptographic implementations, or performance-critical applications where precise control over numeric computations and error handling is paramount.
