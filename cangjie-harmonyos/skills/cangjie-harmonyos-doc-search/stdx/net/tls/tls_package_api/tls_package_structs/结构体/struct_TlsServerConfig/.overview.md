# struct_TlsServerConfig

本目录包含仓颉语言中 `TlsServerConfig` 结构体的 API 参考文档，用于定义和配置 TLS 服务端参数。内容涵盖了应用层协议协商（ALPN）、加密套件、证书验证、协议版本范围及安全级别等核心配置项。该文档详细介绍了初始化构造函数、属性定义及异常处理机制，适用于需要构建安全 TLS 连接、进行精细化网络编程的后端开发人员。

## 详细描述

### prop_supportedAlp_2more_82e24e39.md
这份文档是仓颉语言中TLS服务器配置相关的API参考文档，旨在说明如何配置应用层协议协商及初始化服务器配置对象。文档主要包含supportedAlpnProtocols属性的定义与功能说明，以及init构造函数的参数与用途介绍。关键信息包括ALPN协议的协商机制（服务端从客户端列表中选取交集）、属性类型为字符串数组、包含空字符时的异常处理，以及构造函数所需的证书链和私钥参数。该文档适用于需要实现安全TLS连接并进行协议协商的后端开发人员。

### struct_TlsServer_11more_22ae3893.md
本文档是 Cangjie 语言中 TlsServerConfig 结构体的 API 参考文档，旨在定义和配置 TLS 服务端参数。主要涵盖了客户端身份认证、密钥日志回调、证书验证模式、TLS 1.2 及 1.3 加密套件、DH 参数、协议版本范围、安全级别以及服务端证书链与私钥的配置。关键信息包括各属性的默认值、类型约束及异常处理，例如版本设置不当会引发 TlsException。该文档面向使用 Cangjie 进行网络编程的开发者，提供了构建安全 TLS 连接所需的详细配置选项。
