This directory provides comprehensive guidelines for integrating HiTraceChain, a lightweight distributed tracing tool, into applications developed using the Cangjie (仓颉) language. It covers the fundamental architecture of tracing, including the generation and management of chainIds, and offers step-by-step tutorials on using necessary APIs to initiate and terminate traces. The content focuses on solving debugging challenges in complex business flows across distributed environments, such as multiple devices or processes. It is suitable for Cangjie developers seeking to implement robust monitoring, correlate logs across threads, and enhance problem diagnosis efficiency to maintain high application performance and reliability.
