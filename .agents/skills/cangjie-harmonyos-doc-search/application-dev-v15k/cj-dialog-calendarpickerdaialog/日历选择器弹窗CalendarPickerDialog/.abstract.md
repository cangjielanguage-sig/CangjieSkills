This directory provides comprehensive documentation and resources for the `CalendarPickerDialog` class, a component designed for implementing date selection popup interfaces within the Cangjie programming language and ArkUI framework. It covers essential aspects such as the class definition, the static `show` method, and configuration options. The content includes API references for related styling classes and practical code examples demonstrating UI layout, state management, and lifecycle callbacks. This material is intended for HarmonyOS developers and UI engineers who need to integrate and customize date picker components in their applications.
