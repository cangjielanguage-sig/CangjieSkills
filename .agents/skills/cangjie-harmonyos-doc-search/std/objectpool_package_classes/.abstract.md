This directory contains the API reference documentation for the `ObjectPool` class within the Cangjie standard library. It focuses on a specific implementation designed for concurrent-safe object caching and reuse, intended to help developers minimize the overhead associated with frequent memory allocations. The documentation thoroughly covers the class definition, constructor initialization requirements, and the essential methods used for object lifecycle management, such as `get` and `put`. It is a critical resource for Cangjie developers and system engineers looking to optimize application performance through efficient memory management strategies. However, users should be aware that this class is currently marked as deprecated, and the documentation serves as a reference for existing implementations or legacy systems.
