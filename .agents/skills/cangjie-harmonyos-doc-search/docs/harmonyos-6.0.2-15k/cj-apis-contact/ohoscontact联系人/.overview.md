# ohoscontact联系人

This directory contains comprehensive API reference documentation for the `ohos.contact` module in the Cangjie programming language, designed for HarmonyOS application development. It covers essential contact management capabilities, including creating, querying, updating, and deleting contacts, as well as managing groups and user profiles. The documentation details necessary system permissions, data structures like `ContactAttributes` and specific attribute types (Email, Phone, Address), and function signatures for data manipulation. It is suitable for developers building contact-centric applications who need to integrate system-level contact data handling using the ContactsKit framework.
