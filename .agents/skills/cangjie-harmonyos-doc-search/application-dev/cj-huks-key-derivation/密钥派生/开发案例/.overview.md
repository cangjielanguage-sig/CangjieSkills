# 开发案例

This directory serves as a collection of development case studies focused on cryptographic key derivation within the HarmonyOS ecosystem. It provides technical documentation and code examples utilizing the Universal Keystore Kit (HUKS) and the Cangjie programming language. The content covers essential algorithms such as HKDF and PBKDF2, detailing workflows for parameter configuration, session management, and secure key storage. These resources are suitable for developers, security architects, and backend engineers aiming to implement robust, hardware-backed security protocols and ensure compliance with cryptographic standards in their applications.

## Detailed Description

### HKDF/
This directory provides comprehensive technical documentation and code examples for implementing HMAC-based Extract-and-Expand Key Derivation Function (HKDF) within the HarmonyOS ecosystem. It focuses on utilizing the Universal Keystore Kit (HUKS) and the Cangjie programming language to perform secure cryptographic operations. The content covers the complete workflow of key derivation, including parameter configuration, session management, and resource cleanup. Key topics include AES, SHA256, and error handling patterns. These resources are suitable for developers building secure applications on HarmonyOS who need to derive encryption keys from existing secrets or master keys, ensuring robust data protection and compliance with cryptographic standards.

### PBKDF2/
This directory serves as a comprehensive technical resource for developers implementing PBKDF2 (Password-Based Key Derivation Function 2) cryptographic operations within the HarmonyOS ecosystem. It focuses on utilizing the Universal Keystore Kit (HUKS) to manage secure key derivation processes, specifically tailored for the Cangjie programming language. The content covers critical aspects of cryptographic security, including the configuration of algorithm parameters, session lifecycle management, and the secure storage or deletion of sensitive key material. By providing detailed code examples and workflow demonstrations, this documentation assists developers in integrating robust password-based encryption into their applications. It is particularly suitable for backend engineers, mobile application developers, and security architects who require a deep understanding of hardware-backed keystore operations and secure key management protocols to protect user data effectively and ensure compliance with security standards.
