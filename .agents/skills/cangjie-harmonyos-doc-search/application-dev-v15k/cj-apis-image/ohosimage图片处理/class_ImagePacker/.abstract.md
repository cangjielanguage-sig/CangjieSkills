This directory contains API reference documentation for the Cangjie ImagePacker class and associated packing functions within the ImageKit framework. It covers image compression, encoding, and packing into formats like JPEG, WebP, and PNG. Key topics include instance management, supported formats, and methods for packing image sources, PixelMaps, and Pictures into byte arrays or file descriptors. The documentation details parameters such as PackingOption, error handling codes, and provides Cangjie code examples. It is intended for software developers working on multimedia image processing who need to implement image encoding and storage solutions in their applications.
