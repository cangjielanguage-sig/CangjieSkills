# 通用属性协议

This directory focuses on the Generic Attribute Profile (GATT) within Bluetooth Low Energy (BLE) communications. It provides a comprehensive framework for defining attributes, services, and data transmission between devices. The content covers high-level concepts, practical development steps for HarmonyOS, and detailed interface specifications for the Cangjie language. It is suitable for software developers and engineers aiming to implement BLE connectivity, manage server services, or handle client interactions in HarmonyOS applications using Cangjie or ArkTS.

### 简介_2more.md 简介_2more.md
This document provides a high-level introduction to the Generic Attribute Protocol (GATT) used in Bluetooth Low Energy (BLE) communications. It covers the definition of GATT, explaining its function as a framework for attributes and services, and outlines primary usage scenarios. Key information includes how GATT facilitates data transmission between devices, enabling clients to read and write information and servers to manage services and send notifications. This introductory guide targets developers or engineers working with BLE connectivity who need to understand the basic concepts and operational context of GATT.
