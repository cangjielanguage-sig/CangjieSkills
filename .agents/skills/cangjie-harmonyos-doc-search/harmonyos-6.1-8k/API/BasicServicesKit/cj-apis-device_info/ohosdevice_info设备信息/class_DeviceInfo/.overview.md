# class_DeviceInfo

本目录包含Cangjie语言中 `DeviceInfo` 类的API参考文档，主要用于查询终端设备的静态属性。内容涵盖设备标识符（如ODID、UDID）、硬件规格（品牌、型号、制造商）、系统构建信息（Bootloader版本、构建时间）以及各类版本号（SDK API、安全补丁、Feature版本等）。所有属性均为只读，依赖 `SystemCapability.Startup.SystemInfo` 系统能力，部分敏感信息（如序列号）需要特定权限。该文档适合需要获取设备元数据进行应用逻辑判断、数据统计或系统兼容性适配的Cangjie开发者。
