# Hyperlink

This directory provides comprehensive technical documentation for the Hyperlink component within the Cangjie ArkUI framework. It encompasses the component's core functionality for external URL navigation, detailed API references for initialization using various parameter types, and guides on styling through generic properties and events. Key topics include the mandatory `ohos.permission.INTERNET` permission, support for child components like Images, and specific color customization options. This collection is designed for application developers and HarmonyOS engineers seeking to effectively implement and customize web navigation links in their user interfaces using Cangjie syntax.

## Detailed Description

### Hyperlink_3more.md Hyperlink_3more.md
This document serves as a reference guide for the Hyperlink component, which enables navigation to external URLs upon clicking within its defined area. It covers the component's basic functionality, required permissions, and supported child components. Key details include the requirement for the `ohos.permission.INTERNET` permission for network access and the limitation that it only works with the system browser. Additionally, it specifies that the component can contain an Image child component. This technical reference is intended for application developers integrating web navigation features into their UI.

### 创建组件.md 创建组件.md
This document serves as API reference documentation for initializing the Hyperlink component within the Cangjie ArkUI framework. It details six overloaded init methods categorized by parameter types, specifically handling combinations of String and AppResource for the web address and display content. Key takeaways include the mandatory address parameter and the option to define display text via String or AppResource, or a subcomponent lambda. Crucially, the documentation notes that text content is not displayed if a subcomponent is present. Targeted at application developers, this guide requires knowledge of Cangjie syntax and ArkUI component structure to implement web navigation links effectively.

### 通用属性通用事件_3more.md 通用属性通用事件_3more.md
This document serves as API reference documentation for the Hyperlink component within the ArkUI framework, specifically using the Cangjie language.
