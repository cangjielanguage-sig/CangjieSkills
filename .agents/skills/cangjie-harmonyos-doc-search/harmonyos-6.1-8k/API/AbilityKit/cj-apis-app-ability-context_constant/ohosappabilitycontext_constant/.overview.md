# ohosappabilitycontext_constant

本目录包含鸿蒙应用开发中 `ohos.app.ability.context_constant` 模块的 API 参考文档，主要面向使用仓颉语言进行应用开发的开发者。文档详细介绍了 Context 相关的常量定义，重点涵盖文件加密分区等级（AreaMode）以及 UIAbility 启动后的进程模式。内容涉及不同加密等级（El1 至 El5）下的数据安全策略、文件读写权限控制，以及模块导入方式和权限配置。通过这些文档，开发者可以深入理解如何配置上下文常量以保障应用数据安全并管理应用生命周期。

## Detailed Description

### enum_AreaMode.md enum_AreaMode.md
本文档是 Cangjie 语言中 AreaMode 枚举的 API 参考文档，用于定义文件加密分区等级以保障数据安全。文档涵盖了 El1 至 El5 五种加密模式，详细说明了设备级、用户级及应用级加密区在锁屏和解锁状态下的文件读写权限。此外，还列出了相等性判断和字符串转换等基础方法。主要面向需要根据应用场景配置数据加密策略的开发者，帮助其理解不同安全等级的访问控制机制。关键词包括 AreaMode、加密等级、数据安全、文件权限、El1、El2、El3、El4、El5。
