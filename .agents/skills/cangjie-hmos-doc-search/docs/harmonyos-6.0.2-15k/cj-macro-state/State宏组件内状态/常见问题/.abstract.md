This directory provides a comprehensive collection of technical guides designed to assist Cangjie UI and HarmonyOS developers in mastering state management and resolving common architectural issues. It focuses on critical best practices, such as the prohibition of state variable modifications within the build method to prevent infinite rendering loops and application freezes. Furthermore, it covers the intricacies of lifecycle management to avoid memory leaks, specifically regarding callback registration and unregistration. The guides also delve into the correct usage of arrow functions for state updates and the scoping rules of decorators like @State, @Observed, and @Publish. This resource is essential for developers building custom components who need to ensure UI refresh logic functions correctly and maintain optimal application performance and memory efficiency.
