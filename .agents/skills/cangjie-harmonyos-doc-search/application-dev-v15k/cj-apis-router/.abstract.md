This directory serves as a comprehensive technical resource for the `cj-apis-router` module, specifically focusing on the intricacies of page routing within the Cangjie ArkUI framework. It provides detailed API references for the `ohos.router` module, enabling developers to implement robust navigation logic, manage page stacks, and handle state transitions effectively. Key topics include URL-based navigation, `RouterState` management, and lifecycle constraints. This documentation is tailored for HarmonyOS developers working in a pure Cangjie environment who need to master page routing and lifecycle rules to build seamless user experiences. By adhering to the guidelines provided, developers can ensure their applications handle navigation events correctly and maintain stability during page transitions, avoiding common errors related to premature method invocation.
