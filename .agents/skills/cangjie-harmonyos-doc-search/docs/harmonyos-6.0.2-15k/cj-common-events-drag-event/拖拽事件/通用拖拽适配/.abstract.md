This directory provides comprehensive resources for implementing universal drag-and-drop functionality within the ArkUI Cangjie framework. It covers the complete lifecycle of drag interactions, from enabling drag attributes and resolving gesture conflicts to customizing visual feedback and handling drop events. Key technical topics include UDMF data management, PixelMap manipulation, and specific event callbacks like onDragStart, onDragEnd, and onDrop. The materials are designed for application developers and UI engineers who need to create intuitive, interactive interfaces by integrating complex drag-and-drop mechanics into components such as Images, Buttons, and Lists. The collection includes both theoretical guides and practical code examples.
