# Core_File_Kit简介

本目录介绍了OpenHarmony的Core File Kit（文件基础服务），旨在帮助开发者全面掌握应用文件和用户文件的管理机制。内容涵盖文件分类模型、沙箱隔离安全机制、跨应用文件分享（URI/FD）以及底层框架架构原理。适合需要构建文件管理功能、集成文件选择器或深入理解OpenHarmony文件系统架构的开发者，提供了从基础概念到技术实现的完整指导。
