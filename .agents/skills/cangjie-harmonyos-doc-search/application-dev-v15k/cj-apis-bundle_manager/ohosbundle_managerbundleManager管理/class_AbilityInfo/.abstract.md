This directory provides comprehensive API reference documentation for the `AbilityInfo` class in the Cangjie programming language, tailored for the HarmonyOS ecosystem. It details the metadata and configuration of an application Ability, encapsulating vital attributes such as bundle names, labels, icons, permissions, launch types, and window modes. The documentation explains how instances are retrieved via the `getBundleInfoForSelf` method and outlines support for advanced features like app cloning and dock exclusion. It is structured to offer both a high-level class overview and specific property definitions. This resource is essential for Cangjie developers working within the BundleManager framework who need to access, manage, and define application attributes and component behaviors for HAP modules.
