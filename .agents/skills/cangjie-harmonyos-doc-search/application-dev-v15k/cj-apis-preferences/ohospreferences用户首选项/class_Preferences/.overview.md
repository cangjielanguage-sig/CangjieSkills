# class_Preferences

This directory contains API reference documentation for the Preferences class in the Cangjie language, part of the HarmonyOS ArkData framework. It covers interfaces for managing lightweight application data storage using key-value pairs. Key topics include instance creation, data retrieval, modification, persistence, and cache management. The documentation details methods for reading and writing data types like Int64, Float64, String, and Bool, as well as handling data change subscriptions. It is suitable for HarmonyOS developers implementing local data persistence who are familiar with Cangjie syntax and application contexts.
