This directory provides foundational type definitions and API references for configuring progress components within the ArkUI framework using the Cangjie language. It covers a comprehensive range of style options for various progress bar types, including Linear, Ring, Eclipse, and Capsule, alongside configuration classes and status enumerations. Developers can utilize these definitions to customize visual appearance, animation behaviors, and state management. This documentation is suitable for Cangjie developers and UI designers building HarmonyOS applications who require precise control over progress indicator styling and functionality.
