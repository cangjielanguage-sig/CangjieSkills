# 参数化测试入门

This directory serves as a practical guide to parameterized testing within the Cangjie unittest framework, designed to help developers automate test input insertion using Data DSL. It covers a wide range of topics, from basic value-driven testing with single and multiple parameters to handling complex types and implementing advanced random testing strategies. Key concepts include Cartesian product combinations, avoiding combinatorial explosion, and utilizing `unittest.random()` for edge-case-biased data. Additionally, it addresses the critical aspects of reproducibility and configuration in random testing, such as using random seeds and interpreting failure outputs. Targeted at Cangjie developers, these documents aim to significantly improve test coverage, efficiency, and reliability through automated data generation and shrinking mechanisms.

## Detailed Description

### 参数化测试入门_1.md

This tutorial introduces parameterized testing within the Cangjie unittest framework, demonstrating how to automate test input insertion using Data DSL. The guide covers value-driven testing with single and multiple parameters, handling complex types, and advanced random testing strategies. Key information includes the Cartesian product combination of parameters, warnings against combinatorial explosion, and the use of `unittest.random()` for generating edge-case-biased data. It also highlights the framework's ability to shrink failing test cases to minimal reproducible examples. Targeted at Cangjie developers, this document aims to improve test coverage and efficiency through automated data generation.

### 参数化测试入门_2.md

This tutorial explains how to manage reproducibility and configuration in random testing within the Cangjie framework. It addresses the issue of non-deterministic results by introducing the use of randomSeed to stabilize test outcomes. The document details how to interpret failure output, specifically analyzing generation steps, reduction steps, and the actual data causing failures. Furthermore, it covers configuration options like generationSteps and reductionSteps to control test execution depth and duration. Key takeaways include using the @Configure attribute for seeds and understanding the mechanism of data reduction. This guide is intended for developers seeking to implement reliable, shareable, and configurable random tests.
