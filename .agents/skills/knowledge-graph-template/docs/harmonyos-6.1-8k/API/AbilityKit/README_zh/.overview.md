# README_zh

本目录是Ability Kit（程序框架服务）的仓颉语言API参考索引，旨在为HarmonyOS应用开发者提供核心模块接口及错误码的文档导航。文档内容全面覆盖了UIAbility、Want、访问控制、包管理及应用恢复等关键模块，并详细列出了元能力、包管理和访问控制等子系统的通用错误码。所有内容目前均为Beta特性，涉及应用生命周期管理、权限请求处理及故障恢复等核心概念。本文档特别适合使用仓颉语言进行HarmonyOS应用开发的开发者，作为查阅框架接口定义、理解系统行为以及排查应用错误的权威参考指南。通过本文档，开发者可以快速定位所需的API接口，理解不同模块之间的交互关系，并在开发过程中遇到错误时进行有效的故障排查。
