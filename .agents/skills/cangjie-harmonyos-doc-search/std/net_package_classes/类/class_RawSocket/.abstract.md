This directory contains API reference documentation for the `RawSocket` class in the Cangjie programming language. It covers low-level network programming operations, including socket initialization, data transmission (send/receive), configuration options, and lifecycle management (bind, connect, close). Key topics include socket properties like timeouts and addresses, handling exceptions such as `SocketException`, and support for protocols like TCP, UDP, and ICMP. This documentation is suitable for developers implementing custom network protocols or requiring direct socket manipulation who need detailed technical specifications and usage guidelines.
