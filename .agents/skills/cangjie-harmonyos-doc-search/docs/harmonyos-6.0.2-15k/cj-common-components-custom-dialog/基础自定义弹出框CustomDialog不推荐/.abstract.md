This directory serves as a technical resource for implementing custom pop-up dialogs using the `CustomDialog` component within the ArkUI framework, specifically targeting the Cangjie language. Although the usage of `CustomDialog` is marked as "not recommended" in favor of the Navigation component, this collection provides detailed instructions for developers who need to build or maintain custom interactive overlays. The content covers fundamental concepts such as the `@CustomDialog` decorator, `CustomDialogController` management, and user interaction handling. It also explores advanced topics including modal properties, complex styling with borders and shadows, and the intricacies of nested dialog lifecycles. This guide is suitable for HarmonyOS developers looking to master overlay mechanics and state management in Cangjie applications.
