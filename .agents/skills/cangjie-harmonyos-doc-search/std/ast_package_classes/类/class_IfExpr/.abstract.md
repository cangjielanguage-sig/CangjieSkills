This directory contains comprehensive documentation for the `IfExpr` class, a critical component within the Abstract Syntax Tree (AST) of the Cangjie programming language. It focuses on the structural representation and manipulation of conditional expressions, detailing class definitions, constructors, and essential properties such as `condition`, `ifBlock`, and `elseExpr`. Additionally, it covers AST utility functions for token conversion and tree traversal using the Visitor pattern. Key topics include syntax error handling via `ASTException` and programmatic access to code structure. This documentation is specifically suitable for developers building compiler tools, static analysis applications, or language parsers who need to programmatically access and manipulate conditional logic structures.
