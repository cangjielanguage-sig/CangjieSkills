# 组合手势

This directory focuses on the implementation and management of composite gestures within HarmonyOS applications using the Cangjie language and the ArkUI framework. It provides comprehensive resources on how to utilize the `GestureGroup` component to combine basic gestures—such as LongPress, Pan, and Tap—into complex, multi-step interaction flows. Key topics include gesture recognition strategies (Sequence, Parallel, Exclusive), state management using `@State` decorators, and handling gesture lifecycle events like `onActionStart` and `onActionUpdate`. This content is highly suitable for Cangjie developers and UI engineers aiming to build sophisticated, responsive touch interfaces and dynamic user experiences. By mastering these concepts, developers can create intuitive controls that require specific touch sequences or simultaneous inputs.

## Detailed Description

### 示例.md
This document provides a practical code example demonstrating the implementation of sequential gesture recognition using the Cangjie language in a HarmonyOS application. It covers the usage of the GestureGroup component with GestureMode.Sequence to combine LongPressGesture and PanGesture within a single interaction flow. Key information includes the management of UI state through @State decorators to track position offsets and interaction counts, as well as handling gesture lifecycle events like onActionStart and onActionUpdate. The example visually demonstrates how a long press triggers a counter, followed by a drag gesture to move the element. This tutorial is intended for Cangjie developers seeking to implement complex touch interactions and dynamic UI updates.

### 组合手势_6more.md
This document provides API reference documentation for implementing composite gestures within the ArkUI framework using the Cangjie language. It focuses on creating gesture groups that combine multiple basic gestures, such as Tap or Pan, into complex interactions. Key sections include the component initialization function, which accepts a GestureMode and an array of GestureTypes, and the detailed definition of the GestureMode enum. The enum defines three recognition strategies: Sequence (sequential success), Parallel (simultaneous recognition), and Exclusive (first success wins). Additionally, it covers the onCancel event for sequence gestures. This guide targets UI developers seeking to handle sophisticated user touch interactions.
