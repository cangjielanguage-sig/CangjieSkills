This directory focuses on video playback implementation using the AVPlayer API in HarmonyOS. It covers the complete development lifecycle, from player initialization and resource configuration to playback control and resource release. Key topics include state management, error handling, audio interruptions, and integration with XComponent. It also provides practical code examples in the Cangjie language for advanced scenarios like live streaming and multi-track selection. This resource is suitable for application developers seeking to build robust multimedia features with fine-grained control over video playback.
