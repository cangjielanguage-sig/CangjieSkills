This directory contains technical specifications for symmetric key encryption and decryption algorithms. It covers implementation details for 3DES, SM4, and AES, including supported modes (ECB, CBC, GCM, etc.), padding schemes (PKCS5, PKCS7), and parameter configuration syntax. The documents provide guidance on key lengths, block sizes, and API requirements (specifically API version 12+). It is suitable for developers integrating cryptographic functions using the CryptoArchitectureKit or similar libraries who need to understand algorithm configurations and string parameter formats for instantiating cryptographic instances.
