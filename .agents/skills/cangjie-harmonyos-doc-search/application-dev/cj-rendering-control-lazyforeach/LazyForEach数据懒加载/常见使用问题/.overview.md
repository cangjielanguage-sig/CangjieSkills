# 常见使用问题

This directory serves as a comprehensive troubleshooting resource for developers utilizing the Cangjie framework and ArkUI, specifically targeting common UI and data synchronization challenges. It provides in-depth technical solutions for visual anomalies and logic errors that frequently occur during dynamic data manipulation. Key topics covered include eliminating screen flickering in List components during infinite scrolling and fixing rendering bugs in LazyForEach related to item deletion and index management. By addressing these specific pain points, the guides help improve application performance and ensure a stable user experience. This collection is highly suitable for Cangjie developers, UI engineers, and technical support staff who need to debug complex list rendering behaviors or optimize data loading mechanisms in their applications.

## Detailed Description

The following documents provide specific solutions and code examples for the issues mentioned above.

### 在List内使用屏幕闪烁.md
This technical guide addresses and resolves screen flickering issues encountered when dynamically loading data in a List component within the Cangjie framework. The document covers the problematic implementation of onDataReloaded inside the onScrollIndex callback and demonstrates the optimized solution using onDatasetChange with DataAddOperation. The primary takeaway is that replacing notifyDataReload with notifyDatasetChange not only eliminates visual flickering but also improves loading performance by avoiding a full dataset refresh. This guide targets Cangjie developers working with UI components, specifically those implementing infinite scrolling or dynamic data loading in List views.

### 渲染结果非预期.md
This document addresses a specific rendering bug in LazyForEach where deleting list items results in unexpected behavior. It covers the problematic code demonstrating incorrect index usage, the root cause analysis regarding stale indices, and the corrected code implementation. The fix requires calling `reloadData()` after deletion and modifying the `keyGenerator` to include the index (e.g., `item + index.toString()`). This ensures subsequent items are rebuilt with updated indices, preventing wrong deletions. This guide targets developers working with the Cangjie language and ArkUI framework who need to manage dynamic lists and data updates correctly.
