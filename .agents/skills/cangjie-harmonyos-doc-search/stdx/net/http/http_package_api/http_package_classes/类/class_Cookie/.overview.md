### class_Cookie_10more_4fc58898.md class_Cookie_10more_4fc58898.md
本文档是 Cangjie 语言 HTTP 包中 Cookie 类的 API 参考文档，旨在帮助开发者构建和管理 HTTP Cookie 以维持有状态会话。文档主要内容包括类的构造函数定义及各属性参数说明，涵盖了 cookieName、cookieValue、expires、maxAge、domain、path、secure、httpOnly 等核心属性的获取方式。关键信息指出该类遵循 RFC 6265 协议，支持生成 Set-Cookie 头部值及解析未定义属性。主要面向使用 Cangjie 进行网络编程的开发者，用于实现服务器端的个性化服务和状态管理。
