# core_package_interfaces

This directory serves as the central repository for core interface definitions within the Cangjie programming language ecosystem. It focuses on the fundamental building blocks required for type system interoperability, collection management, and standard utility operations. Key topics include C interoperability (CType), hashing mechanisms (Hashable), comparison logic (Comparable), and concurrency primitives. This documentation is specifically designed for Cangjie developers who need to implement custom data structures, enforce type constraints, or leverage generic programming and operator overloading in their applications. By mastering these interfaces, developers can ensure their code integrates seamlessly with the standard library, adheres to language best practices, and effectively utilizes the root type hierarchy (Any) for robust application design. Whether you are building high-performance collections, bridging native code, or simply trying to understand how to make a custom class work with a HashMap, this directory provides the necessary specifications to succeed.

## Detailed Description

### 接口/
This directory contains comprehensive API reference documentation for core interfaces in the Cangjie programming language. It serves as the definitive guide for the fundamental type system components that underpin the language's architecture. A significant portion of this documentation is dedicated to interoperability with C (CType), providing the necessary specifications for developers integrating Cangjie code with existing native codebases and system libraries.

Beyond interoperability, the directory extensively covers collection management through the Collection and Iterable interfaces, which are vital for handling data sequences and creating custom containers. It also details comparison operations (Comparable, Equatable) required for sorting objects and checking equality, as well as hashing (Hashable, Hasher) for ensuring efficient data storage and retrieval in hash-based collections.

Furthermore, the documentation includes utility functions such as ToString for string representation and Resource for resource management. It elaborates on the root type hierarchy (Any) and specialized interfaces for counting and concurrency. This content is essential for Cangjie developers seeking to understand type constraints, implement custom data structures, manage object lifecycles, or utilize standard library features for generic programming and operator overloading. By understanding these interfaces, developers can create robust, type-safe applications that fully leverage the Cangjie standard library. Mastering these interfaces is a prerequisite for advanced Cangjie development.
