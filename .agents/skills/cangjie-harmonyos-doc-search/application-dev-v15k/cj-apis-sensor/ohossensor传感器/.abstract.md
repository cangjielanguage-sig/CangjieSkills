This directory contains comprehensive API reference documentation for the HarmonyOS sensor module, specifically designed for the Cangjie programming language. It covers a wide range of sensor functionalities, including motion sensors (accelerometer, gyroscope), environmental sensors (light, temperature), and orientation data processing. The documentation details response classes, configuration options, enumerations for sensor IDs and accuracy, and functions for data retrieval and transformation. Suitable for developers building sensor-aware applications, this resource provides the necessary definitions, permissions, and system capabilities required to integrate hardware sensors effectively into HarmonyOS software solutions.
