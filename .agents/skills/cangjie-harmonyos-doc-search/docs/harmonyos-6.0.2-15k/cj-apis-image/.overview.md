# cj-apis-image

This directory serves as a comprehensive API reference for the `ohos.image` module within the Cangjie programming language, specifically tailored for HarmonyOS application development. It covers essential image processing functionalities such as decoding, encoding, PixelMap manipulation, and High Dynamic Range (HDR) support compliant with ISO 21496-1 standards. Designed for software developers and multimedia engineers, this documentation provides detailed structural descriptions of classes, enums, and functions necessary for building robust image applications using the ImageKit framework and SystemCapability.Multimedia.Image.Core. It acts as a central resource for understanding the architecture and capabilities of image handling in the Cangjie ecosystem, enabling the creation of visually rich and performant multimedia experiences.
