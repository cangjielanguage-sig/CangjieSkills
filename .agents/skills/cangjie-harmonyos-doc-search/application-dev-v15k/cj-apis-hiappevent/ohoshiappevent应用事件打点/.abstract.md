This directory contains API reference documentation for the HiAppEvent module in the Cangjie programming language, designed for HarmonyOS application event tracking and analysis. It covers essential components for logging, observing, and processing application events, including enums, structs for configuration and filtering, and classes for data handling. Key topics include event definitions, subscription management, data processors, and storage configuration. This documentation is suitable for Cangjie developers and system integrators looking to implement robust performance monitoring, user behavior analysis, and fault diagnosis within the SystemCapability.HiviewDFX.HiAppEvent framework.
