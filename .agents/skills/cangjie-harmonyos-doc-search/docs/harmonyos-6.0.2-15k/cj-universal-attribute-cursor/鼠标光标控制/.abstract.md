This directory focuses on mouse cursor control within the Cangjie ArkUI framework for HarmonyOS development. It covers the `CursorControl` class, its methods for setting and restoring cursor styles, and the `PointerStyle` enum for defining specific cursor appearances. The content includes practical code examples demonstrating dynamic cursor manipulation based on user interactions like hovering and clicking. It is suitable for Cangjie developers and UI designers looking to enhance user experience through custom pointer behaviors and visual feedback in their applications.
