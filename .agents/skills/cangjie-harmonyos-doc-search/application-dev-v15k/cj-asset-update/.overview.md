# cj-asset-update

This directory serves as a comprehensive technical resource hub focused on updating critical assets using the Cangjie programming language. It is centered around the AssetStoreKit framework, offering in-depth guidance on implementing synchronous interfaces and modifying asset attributes with precision. The documentation emphasizes essential security configurations, such as encryption control and data type constraints, which are paramount for protecting sensitive information. Key areas of focus include the practical handling of `AssetParam` structures, the secure management of plaintext secrets, and the implementation of robust error handling mechanisms for business exceptions. Additionally, it addresses specific API version updates, such as the expansion of custom data size limits to 2048 bytes in API 12. This content is primarily designed for software developers and systems engineers seeking to integrate secure asset management features into their applications while ensuring strict adherence to data privacy standards and efficient API utilization.
