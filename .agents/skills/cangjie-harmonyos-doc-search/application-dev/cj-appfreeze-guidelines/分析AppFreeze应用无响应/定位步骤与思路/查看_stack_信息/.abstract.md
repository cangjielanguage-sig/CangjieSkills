This directory contains technical guides and debugging logs focused on analyzing stack traces to diagnose application issues in OpenHarmony/OHOS environments. It covers scenarios such as application freezes (appfreeze), IPC deadlocks, SQLite database anomalies, and resource loading failures. The documents provide methodologies for using Process ID (Pid) and Thread ID (Tid) to identify bottlenecks like lock contention or synchronous blocking calls. Suitable for system developers, debuggers, and performance engineers troubleshooting native code, database operations, and IPC interactions.
