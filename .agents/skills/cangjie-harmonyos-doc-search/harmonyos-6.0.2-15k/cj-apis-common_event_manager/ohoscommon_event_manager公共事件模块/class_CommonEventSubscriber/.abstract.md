This directory contains API reference documentation for the `CommonEventSubscriber` class in the Cangjie programming language, part of the HarmonyOS BasicServicesKit. It covers the management of ordered common events, including data retrieval and modification, event lifecycle control (aborting, finishing), and subscriber configuration inspection. Key topics include event codes, string data, sticky events, and error handling for `BusinessException`. This documentation is suitable for application developers building event-driven applications who need to handle data flow and control propagation within the Common Event Service.
