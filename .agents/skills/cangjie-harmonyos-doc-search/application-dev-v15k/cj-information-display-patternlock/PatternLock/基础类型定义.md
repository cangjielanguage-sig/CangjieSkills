### class CircleStyleOptions

```cangjie
public class CircleStyleOptions {
    public init(
        color: Color,
        radius: Length,
        enableWaveEffect: Bool
    )
}
```

**功能：** 表示宫格圆点的背景圆环样式。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### init(Color, Length, Bool)

```cangjie
public init(
    color: Color,
    radius: Length,
    enableWaveEffect: Bool
)
```

**功能：** 构造一个CircleStyleOptions对象。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|color|[Color](./cj-common-types.md#class-color)|是|-|背景圆环颜色。初始值与[pathColor](#func-pathcolorcolor)值相同。|
|radius|[Length](./cj-common-types.md#interface-length)|是|-|背景圆环的半径。初始值[circleRadius](#func-circleradiuslength)的11/6。|
|enableWaveEffect|Bool|是|-|波浪效果开关。<br/>初始值：true。|
