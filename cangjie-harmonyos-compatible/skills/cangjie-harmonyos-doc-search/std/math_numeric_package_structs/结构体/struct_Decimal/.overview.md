# struct_Decimal

This directory contains API documentation for the `Decimal` struct in the Cangjie programming language's standard math library. It focuses on arbitrary-precision signed decimal numbers, essential for high-precision financial and mathematical calculations where standard floating-point types are insufficient. The documentation covers initialization from various types, arithmetic and comparison operators, precision manipulation, rounding, and type conversions. It is suitable for Cangjie developers who need to implement robust numeric logic, handle specific rounding modes, or manage overflow strategies in their applications.
