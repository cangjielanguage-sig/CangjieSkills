# 使用Web组件的广告过滤功能

This directory focuses on the ad filtering capabilities of the ArkWeb component, providing a comprehensive guide for developers working with the Cangjie language. It covers the implementation of EasyList syntax rules for blocking network requests and hiding page elements, as well as the complete lifecycle of ad blocking management. Key topics include rule configuration, exception handling, statistics collection, and system constraints. This documentation is suitable for developers and system administrators looking to integrate robust, customizable ad-blocking features into their web applications while understanding the technical boundaries and operational logic of the ArkWeb framework.

## Detailed Description

### 使用Web组件的广告过滤功能_2more.md
This technical reference guide explains the ArkWeb component's ad filtering capabilities, focusing on the implementation of EasyList syntax rules for blocking network requests and hiding page elements. The document covers an overview of the filtering mechanism and a detailed breakdown of common EasyList syntax rules, including URL blocking, exception rules, and element hiding. Key takeaways include specific syntax examples for intercepting URLs based on domains, creating exceptions to prevent false positives, and using CSS selectors to hide specific ad elements. It emphasizes that exception rules must accompany standard blocking rules to function correctly. Intended for developers configuring ad filtering in ArkWeb applications, this reference material requires basic understanding of web technologies and rule-based filtering.

### 使用场景/
This directory provides comprehensive usage scenarios for implementing and managing ad filtering within applications built on the ArkWeb framework using the Cangjie language. It covers the complete lifecycle of ad blocking functionality, starting with enabling the feature and applying custom easylist rules via the AdsBlockManager. Additionally, it details methods for collecting filtering statistics with performance-optimized callbacks and managing granular domain exceptions through allowlists and disallowlists. This documentation is specifically tailored for application developers who need to integrate robust, customizable ad blocking capabilities into their Web components while maintaining control over specific website behaviors.

### 约束与限制/
This directory contains comprehensive documentation regarding the constraints and limitations applicable to system features, with a specific focus on web component frameworks and ad-blocking functionalities. It covers technical restrictions, usage boundaries, persistence behaviors, and domain matching logic essential for system configuration. Key topics include ad-blocking rules, allowlist and disallowlist priority mechanisms, and suffix matching for domain names. This documentation is primarily suitable for developers and system administrators who need to understand operational boundaries, configure network security policies, and integrate ad-blocking capabilities into web applications using the ArkWeb API.
