# cj-permissions-for-all

This directory serves as a specialized resource for HarmonyOS developers, focusing on the implementation and management of open permissions that utilize system authorization (`system_grant`). It specifically addresses "normal" level permissions, which are distinct from sensitive permissions because they are automatically granted by the system upon application installation. The content covers critical aspects such as permission definitions, the correct application methods, and the technical nuances regarding the absence of ACL enablement fields. This guide is suitable for application developers seeking to streamline their development process by understanding which permissions are pre-authorized. It ensures compliant access to essential device capabilities—including connectivity, sensors, and system controls—without requiring runtime user interaction, thereby facilitating the creation of standard app features with minimal friction and improved user experience. This documentation is particularly useful for those building apps that require background access to standard hardware features.

## Detailed Description

### 开放权限系统授权/
This directory provides a comprehensive and technical guide to HarmonyOS open permissions that utilize system authorization (`system_grant`). It focuses specifically on permissions that are automatically granted by the system upon installation, distinguishing them from higher-risk permissions that require user consent. The content primarily covers permissions classified as "normal" level, which are essential for standard application functionality. Key topics include detailed permission definitions, the precise application methods required for implementation, and the critical technical distinction that these permissions do not involve ACL (Access Control List) enablement fields. This distinction is vital for developers to understand to avoid configuration errors. The content is indispensable for application developers who need to identify exactly which permissions are pre-authorized by the system. It explains how to declare these permissions correctly in configuration files to ensure the application functions as intended. By covering access to a wide range of device capabilities—such as network connectivity, various sensors, and basic system controls—this resource ensures compliant access to system services. Crucially, it allows developers to implement these features without triggering user interaction prompts during runtime, significantly streamlining the development process and user experience for standard app features.
