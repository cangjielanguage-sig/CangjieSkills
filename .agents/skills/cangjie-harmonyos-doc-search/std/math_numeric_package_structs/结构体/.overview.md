# 结构体

This directory functions as a specialized repository for documentation regarding core data structures in the Cangjie programming language, with a primary focus on high-precision numeric types. It provides extensive resources for the `BigInt` struct, which is tailored for arbitrary-precision signed integer calculations, and the `Decimal` struct, which is essential for handling arbitrary-precision signed decimal numbers. The content encompasses a broad spectrum of functionalities, including initialization from diverse data types, arithmetic and bitwise operations, type conversions, and complex mathematical utilities. Furthermore, it addresses critical software engineering aspects such as overflow strategies, rounding modes, and robust error handling mechanisms. This documentation is specifically suitable for Cangjie developers engaged in developing applications for fields like cryptography, financial technology, or scientific research, where standard numeric types are insufficient due to precision or range constraints.

## Detailed Description

### struct_BigInt/

This directory contains comprehensive API documentation for the `BigInt` struct in the Cangjie programming language, designed for arbitrary-precision signed integer calculations. It covers initialization from various data types, arithmetic and bitwise operators, type conversions, and mathematical utilities like modular exponentiation and prime checking. The documentation includes details on interface implementations such as `Comparable`, `Hashable`, and `Formattable`, alongside specific extensions for parsing and radix conversion. This resource is suitable for Cangjie developers requiring high-precision arithmetic capabilities, handling large numbers, or performing complex mathematical operations with robust error handling and overflow strategies. It serves as a critical reference for ensuring numerical accuracy in large-scale computations.

### struct_Decimal/

This directory provides API reference documentation for the `Decimal` struct in the Cangjie programming language's standard library. It focuses on arbitrary-precision signed decimal numbers, essential for high-precision numeric calculations. The content covers initialization from various types, mathematical operations, type conversions, and operator overloads. Key features include handling overflow strategies, rounding modes, and string parsing. This documentation is suitable for Cangjie developers implementing financial or scientific algorithms requiring exact decimal representation and precise arithmetic control. This ensures that developers can maintain data integrity in sensitive computational environments.
