# MVVM模式

This directory focuses on the Model-View-ViewModel (MVVM) architecture pattern within the ArkUI framework and HarmonyOS ecosystem. It covers core architectural principles, state management, and the practical application of MVVM in application development. Key topics include decoupling layers, data flow constraints, and reactive UI components using the Cangjie language. The content is designed for developers and software architects looking to build scalable, maintainable applications by mastering state variables, component interaction, and clean architecture patterns.

## Detailed Description

### MVVM模式_3more.md MVVM模式_3more.md
This guide introduces the MVVM architecture pattern to help developers design scalable ArkUI application structures and manage complex state variables effectively. It covers the core concepts of MVVM, detailing the distinct roles of the Model, View, and ViewModel layers within the ArkUI framework. Key takeaways include the explanation that ArkUI's state variables function as the ViewModel to automatically drive UI updates, and the distinction between page-specific data and project-wide business data. The document also categorizes View components into page, business, and common types. Intended for developers already familiar with State Management V1, this guide aims to simplify maintenance and iteration during product upgrades.

### 架构核心原则.md 架构核心原则.md
This document defines the core architectural principles governing data flow and component interaction within a software system, likely based on an MVVM pattern. It covers three specific constraints: prohibiting cross-layer access between View, ViewModel, and Model; preventing lower layers from directly accessing upper layer data; and restricting direct access between non-parent-child components in the View layer. The key takeaway is enforcing strict decoupling through notification patterns and event-driven communication, ensuring components only interact with known children or via abstracted events for parents and siblings. This guide targets software developers and architects designing or maintaining the system, requiring an understanding of layered architecture and component-based design. Keywords: Architecture, MVVM, Decoupling, Data Flow, Component Design, Notification Pattern.

### 备忘录开发实战/

Suitable for developers learning HarmonyOS or Cangjie, this collection focuses on practical code examples, such as Todo lists, to demonstrate how to achieve efficient, reusable, and scalable UI structures.

This resource provides a practical guide to developing a memo application using the Model-View-ViewModel (MVVM) architecture within the HarmonyOS ecosystem. It is suitable for developers and software engineers looking to master MVVM implementation, improve code maintainability, and understand state synchronization techniques like `@Observed` and `@Link` in modern application development.
