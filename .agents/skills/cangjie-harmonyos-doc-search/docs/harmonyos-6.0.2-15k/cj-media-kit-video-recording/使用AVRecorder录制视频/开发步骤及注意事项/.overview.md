# 开发步骤及注意事项

This directory provides a comprehensive technical guide for developers implementing video recording functionality using the AVRecorder module in the Cangjie language. It covers the complete development lifecycle, from initial setup and configuration to advanced resource management. Key topics include integrating with camera modules via Surface, configuring event listeners for state changes, setting recording parameters like video codecs, and managing file descriptors. The documentation emphasizes critical prerequisites such as permission handling and application sandbox file management. It is specifically designed for application developers working on multimedia features who need detailed code examples and API configuration instructions to build robust recording applications.

## Detailed Description

### 开发步骤及注意事项_1.md
This technical tutorial guides developers through implementing video recording using the AVRecorder module in the Cangjie language. It outlines the integration process with camera modules via Surface for data transmission. Key sections include creating an AVRecorder instance, configuring essential event listeners for state changes and errors, setting recording parameters like video codec and file paths using file descriptors, and obtaining the SurfaceID for data input. The document emphasizes prerequisites such as permission handling and file management within the application sandbox. It targets application developers working on multimedia features, providing code examples and configuration details for the AVRecorder API.

### 开发步骤及注意事项_2.md
This document provides a step-by-step guide for managing the video recording lifecycle, specifically focusing on input source initialization and state transitions. It details steps 5 through 11, covering initialization, starting, pausing, resuming, stopping, resetting, and releasing resources. The guide highlights specific API calls like AVRecorder.start(), pause(), resume(), stop(), reset(), and release(), alongside corresponding camera operations such as camera.VideoOutput.start. It emphasizes state changes (idle, started, paused, stopped, released) and the necessity of synchronizing the recorder with the input source. This technical tutorial targets developers implementing video recording functionality who need to understand resource management and API sequencing.
