# 常用命令

本目录包含关于在 OpenHarmony 环境下使用 `hitrace` 命令的参考文档。内容涵盖了系统追踪信息的捕获、管理、导出及配置，包括查看标签、设置缓冲区、快照模式及数据压缩等操作。核心关键词包括 hitrace、性能分析、trace 捕获、hdc shell。这些文档适合需要在 OpenHarmony 设备上进行系统性能调试和数据分析的开发者及系统工程师阅读。

## 详细描述

### 常用命令_1.md
本文档是关于在hdc shell环境中使用hitrace命令的参考指南，旨在指导用户捕获和管理系统追踪信息。内容涵盖查看可用追踪标签、开始与结束追踪记录、以及设置缓冲区大小和持续时间等捕获参数。关键操作包括使用`hitrace -l`列出标签，通过`--trace_begin`和`--trace_finish`控制记录流程，以及利用`-b`、`-t`和`-o`参数配置缓冲区、时长和输出路径，以捕获特定模块（如app、ability）的trace。该文档适用于需要在OpenHarmony环境下进行性能分析或调试的开发者和系统工程师。

### 常用命令_2.md
本文档提供了hitrace工具的命令行使用示例，重点介绍trace信息导出、快照模式管理及捕获配置。涵盖了将trace导出至控制台或文件、快照模式的开启与关闭、抓取后压缩、设置输出时钟为boot时间以及结束捕获但不打印等操作。关键命令包括`--trace_dump`、`--start_bgsrv`及`-z`压缩选项。快照trace默认保存于`/data/log/hitrace/`，建议使用Smartperf_Host工具进行可视化分析。这是一份面向开发者的参考指南，适用于需要在OpenHarmony设备上进行系统性能追踪和数据分析的场景。
