This directory contains API references and constant definitions for the `Support` class within the Cangjie programming language framework. It primarily focuses on system-level common events, providing static constant strings for various hardware and software state changes. Key topics include user lifecycle management, Wi-Fi connectivity (including P2P and scanning), storage volume management, and system notifications. These resources are essential for developers building system-level applications that need to subscribe to, broadcast, or react to real-time system events. All constants require the `SystemCapability.Notification.CommonEvent` capability starting from API version 22.
