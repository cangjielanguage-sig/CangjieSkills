This directory provides comprehensive documentation for the `ohos.screenshot` module within the HarmonyOS ecosystem, specifically designed for the Cangjie language. It covers the technical implementation of screen capture features, including full-screen captures and specific region selection on tablets and 2-in-1 devices. Key topics include the definition of capture data structures, API references for configuration and execution, and practical coding examples. This resource is essential for developers utilizing ArkUI and ImageKit who need to programmatically capture screen content, manage system permissions, and handle memory resources effectively in their applications.
