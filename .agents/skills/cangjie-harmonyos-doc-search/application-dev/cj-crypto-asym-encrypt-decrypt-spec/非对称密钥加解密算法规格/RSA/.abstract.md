This directory serves as a comprehensive resource for implementing RSA asymmetric encryption within the Cangjie framework. It covers essential technical aspects, including supported padding schemes (NoPadding, PKCS1, and PKCS1_OAEP), input data length constraints, and parameter configuration. The documentation includes API references for managing OAEP parameters, compatibility matrices for various key sizes, and guides for constructing configuration strings. Designed for developers and security engineers, these materials provide the necessary specifications to ensure parameter compatibility, manage performance considerations, and securely configure cryptographic operations. Keywords: RSA, Cangjie, Asymmetric Encryption, PKCS1_OAEP, API Reference, Cryptography.
