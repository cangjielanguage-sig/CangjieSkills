# context

This directory provides a comprehensive technical overview of managing context and communication between nested macros within the Cangjie programming language. It is designed to assist developers in navigating the complexities of macro hierarchies, specifically addressing how to enforce strict parent context constraints and establish reliable communication channels for passing messages between inner and outer macro scopes. The documentation details critical API usage, including `assertParentContext` for triggering compilation errors upon validation failure, and `setItem` combined with `getChildMessages` for transferring data from child to parent macros. This resource is highly suitable for Cangjie developers working on advanced macro systems who need to master macro interaction, implement robust context validation, and handle inter-macro data flow effectively to ensure compilation integrity and correct program behavior. By following the guidelines in this directory, developers can create more reliable and maintainable macro-based architectures.
