# 使用场景

本目录主要介绍ArkUI框架中`@Builder`装饰器及自定义构建函数的高级使用场景。内容涵盖了如何将全局和局部`@Builder`函数作为参数传递、处理多层嵌套调用时的状态同步问题，以及在仓颉语言的自定义组件中结合状态管理宏（如`@State`、`@Observed`）实现UI动态刷新。核心知识点包括CustomBuilder类型参数、引用传递规则以及状态驱动UI刷新机制。本文档适合具备ArkUI基础语法知识的开发者，旨在帮助其掌握复杂的UI构建技巧和组件化开发模式。

## 详细描述

### 使用全局和局部的Builder传入_2more_1e88766f.md 使用全局和局部的Builder传入

本文档旨在指导开发者如何在ArkUI中使用全局和局部@Builder函数作为CustomBuilder类型参数，并处理多层嵌套场景下的状态同步。文档主要涵盖两个核心主题：一是将@Builder函数作为参数传递给如bindSheet等组件接口，实现灵活的UI构建；二是讲解多层@Builder方法嵌套调用时，为确保最内层UI能动态刷新，必须在每一层调用中采用按引用传递参数的方式。关键信息包括CustomBuilder的函数本质及嵌套调用的引用传递规则。本文适合熟悉ArkUI基础语法的开发者阅读，用于掌握复杂的UI构建技巧。

### 自定义组件内使用自定义构建函数_3more_9876ffa8.md 自定义组件内使用自定义构建函数

这份文档旨在指导开发者在仓颉语言的ArkUI框架中如何使用@Builder装饰器进行UI构建。文档主要涵盖三个场景：在自定义组件内部使用私有@Builder方法、定义全局@Builder函数并传递参数、以及通过状态管理宏触发UI刷新的机制。关键信息包括演示了@State、@Observed和@Publish等状态管理装饰器与@Builder的配合使用，明确了UI刷新是由状态变量变化驱动的。这是一份面向仓颉开发者的代码示例教程，适合具备基础ArkUI开发知识的用户学习自定义构建函数的用法。
