# 示例代码

This directory serves as a comprehensive practical resource for the Cangjie UI framework, specifically tailored for HarmonyOS application development. It contains curated code examples that illustrate fundamental layout mechanics essential for building robust and responsive user interfaces. The content focuses on two primary technical areas: configuring content alignment and main axis direction within containers like Stack and Row, and mastering various component positioning techniques such as absolute, anchor-based, and relative positioning. By exploring these examples, developers can gain a deeper understanding of how to control the spatial arrangement and flow of UI elements effectively. This collection is highly suitable for developers who are actively learning Cangjie UI layout mechanics or those looking to refine their skills in UIKit framework layout control to create polished applications.

## Detailed Description

### 示例1对齐方式和主轴方向上的布局.md 示例1对齐方式和主轴方向上的布局.md
This document provides a code example demonstrating how to configure content alignment within elements and the layout direction of child elements along the main axis using the Cangjie UI framework. The main topics include using the align attribute to position text within Stack containers specifically BottomEnd and TopStart and using the direction attribute to control the horizontal arrangement of children in Row containers Left-to-Right vs. Right-to-Left. Key takeaways involve understanding how align affects internal positioning relative to the parent and how direction dictates the flow sequence of child components. This tutorial is designed for developers learning Cangjie UI layout mechanics specifically those working with HarmonyOS application development.

### 示例2位置偏移.md 示例2位置偏移.md
This document provides a practical code example demonstrating various UI component positioning techniques in the Cangjie language for HarmonyOS development. It covers three distinct layout methods: absolute positioning relative to the parent using position, anchor-based offsetting with markAnchor, and relative positioning using offset. Key takeaways include understanding the specific coordinate direction differences for each method, such as how markAnchor moves up or left for positive values while offset moves down or right. The target audience is Cangjie developers seeking to master layout control and component alignment within the UIKit framework.
