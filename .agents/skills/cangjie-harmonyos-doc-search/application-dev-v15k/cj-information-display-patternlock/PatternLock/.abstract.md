This directory provides comprehensive documentation for the PatternLock component within the ArkUI framework, designed for implementing secure, gesture-based password verification interfaces. It covers API references for component creation, basic type definitions, event handling, and property configuration using the Cangjie programming language. The content includes practical code examples demonstrating state management, visual customization, and validation logic. Suitable for HarmonyOS developers and software engineers looking to integrate 9-grid pattern authentication into their applications, with support starting from API version 12.
