This directory provides comprehensive API reference documentation for the `Map<K, V>` interface within the Cangjie programming language. It focuses on the implementation and usage of mutable collections designed for storing key-value pairs. The content covers specific value modification operations, such as the `replace` function and the `[]` operator, alongside broader interface specifications including inheritance from `ReadOnlyMap<K, V>`. It details essential mutation methods like adding, removing, and clearing entries, while explaining constraints such as the prohibition of duplicate keys. This documentation is suitable for Cangjie developers seeking to understand generic types, collection interfaces, and the specific behaviors of mutable map structures to effectively manage data in their applications. By mastering these interfaces, developers can ensure robust data handling and manipulation within their software projects.
