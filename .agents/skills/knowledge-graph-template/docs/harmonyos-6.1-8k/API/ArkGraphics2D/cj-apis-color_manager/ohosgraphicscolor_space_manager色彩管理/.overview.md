# ohosgraphicscolor_space_manager色彩管理

本目录提供了基于仓颉（Cangjie）语言的OpenHarmony图形色彩管理模块API参考文档。它涵盖了色彩空间的核心定义、管理及创建逻辑，包括标准色域（如Srgb、DisplayP3）与自定义色域的处理。主要涉及ColorSpaceManager类、ColorSpacePrimaries类以及ColorSpace枚举，支持获取Gamma值、白点值及三原色坐标等操作。该模块属于ArkGraphics2D色彩管理核心能力，适用于需要进行图形渲染、色彩校正及高级图像处理的开发人员。

## Detailed Description

### class_ColorSpaceManager.md class_ColorSpaceManager.md
这是一份ColorSpaceManager类的API参考文档，旨在指导开发者使用Cangjie语言进行色域对象实例的管理。文档详细列出了获取色域类型、Gamma值及白点值三个核心功能，涵盖了各方法的返回值类型、系统能力要求及异常处理机制。关键信息包括所有方法均需通过create()获取实例后调用，且可能抛出参数异常错误码。该文档主要面向图形应用开发人员，提供了完整的代码示例和错误处理参考，是ArkGraphics2D色彩管理模块的重要参考资料。

### class_ColorSpacePrimaries.md class_ColorSpacePrimaries.md
这是一份ColorSpacePrimaries类的API参考文档，用于定义色彩空间中红、绿、蓝三原色及白点的坐标位置。文档详细列出了八个Float32类型的公共属性，分别对应红、绿、蓝及白点的x和y坐标，并提供了包含所有参数的构造函数。该类属于图形2D颜色管理核心能力，所有属性均为可读写，起始版本为22。适用于需要进行色彩空间定义和管理的图形开发人员。

### ohosgraphicscolor_5more_87d05e37.md ohosgraphicscolor_5more_87d05e37.md
该文档是ohos.graphics.color_space_manager模块的API参考文档，旨在指导开发者使用仓颉语言进行色彩管理。主要内容包括模块导入方式、代码示例说明以及两个核心重载函数：用于创建标准色域对象的create(ColorSpace)和用于创建自定义色域对象的create(ColorSpacePrimaries, Float32)。文档详细列出了函数参数、返回值、异常处理及对应的错误码。关键信息在于区分标准与自定义色域的创建逻辑及参数限制。目标受众为使用ArkGraphics2D进行图形开发的开发人员，需具备仓颉编程基础。

### enum_ColorSpace/
本目录包含关于图形色彩空间（ColorSpace）的API参考文档，主要面向使用Cangjie语言进行图形开发的开发人员。文档详细定义了系统支持的各种色彩空间常量（如DisplayP3、Srgb、Bt2020等），涵盖了RGB色域类型、转换函数（HLG、PQ、Linear）及编码范围（Full、Limit）等核心概念。此外，还提供了色彩空间枚举的比较运算符和字符串转换方法。这些内容属于SystemCapability.Graphic.Graphic2D.ColorManager.Core系统能力，适用于需要精确控制色彩表现的场景。
