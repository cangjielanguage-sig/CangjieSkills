This directory provides a comprehensive development guide for software engineers utilizing the Cangjie programming language to implement user authentication queries. It focuses specifically on the mechanism for querying the enrollment status of various authentication credentials, including face recognition, fingerprint scanning, and PIN codes. The documentation thoroughly details the `getEnrolledState` interface, enabling applications to effectively detect and respond to changes in a user's registered security credentials. Key topics covered in this resource include precise interface specifications, the configuration of necessary system permissions such as `ohos.permission.ACCESS_BIOMETRIC`, and a detailed, step-by-step implementation guide accompanied by practical code examples. By explaining how to pass `UserAuthType` parameters to retrieve `EnrolledState` objects—which contain vital data like credential counts and digests—this guide empowers developers to create applications that dynamically adapt to the availability of authentication methods. This resource is ideally suited for application developers looking to enhance security and user experience.
