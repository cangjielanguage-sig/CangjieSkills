This directory serves as a comprehensive resource for API reference documentation regarding the Cangjie `Want` class within the HarmonyOS development environment. It focuses on the `Want` object, a fundamental element used to describe the intention of an operation, such as initiating an ability or transferring data between components. The content covers a wide range of topics, including class constructors, read-only properties like bundleName and abilityName, and the critical distinctions between explicit and implicit wants. Additionally, it touches upon advanced system capabilities such as Data Leakage Prevention (DLP) and atomic service sharing. This documentation is specifically designed for Cangjie and HarmonyOS developers who need to implement inter-component communication, manage application permissions, and configure parameters for launching specific abilities effectively. By utilizing these references, developers can ensure their applications adhere to system capability requirements and utilize the full potential of the HarmonyOS framework.
