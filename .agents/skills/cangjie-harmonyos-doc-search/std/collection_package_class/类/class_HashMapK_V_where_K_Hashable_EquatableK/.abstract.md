This directory contains comprehensive API reference documentation for the `HashMap` class in the Cangjie programming language. It details the implementation of a hash table-based map structure where keys must be `Hashable` and `Equatable`. The documentation covers class definitions, generic constraints, initialization methods, core operations like lookups and modifications, and extensions for equality and string conversion. It is suitable for Cangjie developers seeking to implement efficient key-value storage, manage collections, and understand the specific behaviors and exceptions associated with hash maps in the standard library.
