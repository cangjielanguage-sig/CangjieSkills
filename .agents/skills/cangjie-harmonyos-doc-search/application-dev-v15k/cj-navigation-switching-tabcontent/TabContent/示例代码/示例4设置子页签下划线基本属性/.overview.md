# 示例4设置子页签下划线基本属性

This directory contains code examples demonstrating how to configure and animate the underline indicator for sub-tabs in HarmonyOS applications. It covers both static property customization and dynamic animations using ArkTS and Cangjie languages. Key topics include setting visual attributes like color, width, height, border radius, and spacing, as well as implementing smooth transitions using the `animateTo` function. These examples are suitable for developers working with the ArkUI framework who want to enhance user interface design through detailed tab navigation styling and interactive visual effects.
