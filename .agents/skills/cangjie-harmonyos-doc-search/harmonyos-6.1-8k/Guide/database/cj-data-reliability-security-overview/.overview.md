# cj-data-reliability-security-overview

本目录详细介绍了OpenHarmony系统中关于数据可靠性与安全的核心功能与实现机制。文档内容广泛覆盖了数据库的备份与恢复流程、全库加密技术、数据分类分级策略以及E类加密数据库的应用。它不仅解释了基本概念和运作机制，还重点阐述了支持无需关库的全量备份、利用HUKS（通用密钥库系统）自动管理密钥、E类数据库在锁屏时自动销毁密钥等关键技术点。同时，文档也明确了键值库最多备份5份及密钥年度轮换等系统约束。这份资料是OpenHarmony应用开发者的必备指南，尤其适用于涉及敏感信息处理或对数据持久化安全性有极高要求的业务场景。

## Detailed Description

### cj-data-reliability-security-overview.md cj-data-reliability-security-overview.md
本文档概述了OpenHarmony的数据可靠性与安全功能，旨在通过数据库备份、恢复、加密及分类分级机制保障数据完整性与安全性。主要涵盖功能场景、基本概念、运作机制及约束限制，重点介绍数据库备份恢复、全库加密、数据分类分级及E类加密数据库。关键信息包括支持无需关库的全量备份、利用HUKS自动管理密钥、E类数据库锁屏销毁密钥、键值库最多备份5份及密钥年轮换。文档面向OpenHarmony应用开发者，适用于需处理敏感或关键业务数据的开发场景。
