This directory focuses on the ArkUI framework's mirroring capability, essential for internationalization and bidirectional text support. It covers how to horizontally flip UI content to accommodate Right-to-Left (RTL) reading habits, such as Uyghur or Arabic, alongside standard Left-to-Right (LTR) layouts. Key topics include automatic mirroring triggers, manual Canvas rendering adjustments, and specific usage constraints for various components. This documentation is suitable for ArkUI developers and UI designers aiming to create applications that seamlessly adapt to different system languages and regional display requirements.
