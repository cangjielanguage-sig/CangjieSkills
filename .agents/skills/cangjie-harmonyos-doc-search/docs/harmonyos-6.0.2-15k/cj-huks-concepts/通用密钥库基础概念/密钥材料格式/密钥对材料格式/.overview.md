# 密钥对材料格式

This directory provides comprehensive technical reference documentation defining the precise memory layout and byte structure required for cryptographic key pair materials. It covers the serialization formats for a wide range of algorithms, including RSA, ECC, DSA, DH, and Curve25519, detailing how headers, algorithm identifiers, and raw key components are organized. The content includes practical Cangjie code examples demonstrating how to manually allocate and populate byte arrays for specific key types. This resource is essential for software developers and system engineers working within the OpenHarmony ecosystem who need to implement low-level cryptographic storage, transmission protocols, or interface directly with the HUKS API.
