This directory contains API reference documentation for the `PopupOptions` class and related configuration variables within the ArkUI framework, specifically designed for the Cangjie language. It covers the comprehensive setup of popup windows, including layout positioning, visual styling, arrow properties, message content, and event handling. Developers will find details on constructors, default values, and advanced features like background blur and transition effects. This documentation is suitable for HarmonyOS developers looking to implement interactive popup dialogs, menus, or bubble components in their applications.
