# 启动命令start

This directory provides comprehensive technical documentation for the `aa start` command within the HarmonyOS development environment. It focuses on the mechanisms required to launch Stage model application components, specifically UIAbility and ServiceExtensionAbility. The content covers a wide range of topics, including explicit and implicit startup syntax, parameter configuration, window positioning constraints, and URI scheme handling. Additionally, it addresses error codes and debugging flags essential for troubleshooting. These resources are primarily suitable for application developers and QA testers who utilize command-line interfaces to manage application lifecycles, verify component behaviors, and debug complex startup scenarios during the development and testing phases.

## Detailed Description

### 启动命令start_1.md
This document serves as a technical reference for the `aa start` command, used to launch Stage model application components like UIAbility and ServiceExtensionAbility. It details command syntax for both explicit and implicit starts, a comprehensive parameter list including window positioning and debug flags, return values, and a table of specific error codes. Key takeaways include the requirement that target components must have `exported` set to true, specific constraints for window positioning on 2in1 devices, and the availability of debug modes. This guide is intended for developers and testers using command-line tools to manage application lifecycles and debug issues.

### 启动命令start_2.md
This technical guide explains how to implicitly start an Ability using the aa start command with URI schemes in HarmonyOS development. It details configuring the target application's module.json5 file with specific skills and URI attributes, and demonstrates command-line syntax for launching pages, passing various parameter types, and opening a browser. Key takeaways include the specific JSON structure for URI matching and the Cangjie code snippet for retrieving parameters in the onCreate lifecycle method. Intended for developers debugging or testing application startup flows via the command line interface.
