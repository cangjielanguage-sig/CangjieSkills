# cj-screenProperty-guideline

This directory serves as a technical resource for HarmonyOS developers, focusing on the implementation of screen property queries and status monitoring using the Display interface. It addresses the critical need for applications to adapt dynamically to various hardware configurations to ensure optimal user experiences. Key topics covered include the retrieval of fundamental screen metrics such as resolution, pixel density, and refresh rates, which are essential for rendering high-quality, responsive UIs. The guide also tackles complex scenarios like managing unavailable display areas on punch-hole screens and responding to hardware state changes, such as screen rotation and the folding/unfolding of foldable devices. With code examples provided in both ArkUI and the Cangjie language, this collection is ideal for developers seeking to optimize their applications for diverse HarmonyOS device form factors and ensure layout consistency.

## Detailed Description

### 使用Display实现屏幕属性查询及状态监听/

This subdirectory provides a comprehensive guide on leveraging the Display interface within the HarmonyOS development environment. It is designed to assist developers in creating responsive and adaptive user interfaces by accurately querying screen hardware properties.

The content begins by detailing the retrieval of essential screen metrics. Developers will learn how to programmatically access the screen's resolution, density, and refresh rate. These parameters are crucial for ensuring that visual elements are scaled correctly and animations run smoothly across different devices.

Beyond basic metrics, the guide addresses the challenges posed by modern screen designs, specifically "punch-hole" screens. It explains how to identify and handle unavailable display areas (such as camera cutouts) to prevent UI elements from being obscured or overlapping with hardware components.

Furthermore, the documentation covers dynamic state monitoring. It provides instructions on setting up listeners for screen orientation changes, allowing apps to adjust layouts automatically in real-time. It also includes specific guidance for foldable devices, demonstrating how to detect the fold state to provide a seamless user experience during transitions between folded and unfolded modes. The guide includes practical code examples in both ArkUI and Cangjie, catering to developers using different language stacks within the HarmonyOS ecosystem. By following these guidelines, developers can ensure their applications remain visually consistent and functionally robust regardless of the specific display hardware in use.
