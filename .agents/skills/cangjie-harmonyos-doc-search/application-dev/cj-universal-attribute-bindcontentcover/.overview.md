# cj-universal-attribute-bindcontentcover

This directory contains API reference documentation for the Cangjie ArkUI framework, specifically focusing on the `bindContentCover` universal attribute. It provides comprehensive details on how to bind full-screen modal pages with transition effects to UI components. The documentation covers essential aspects such as function signatures, required parameters (including visibility state and custom content builders), configuration options, return values, and system capabilities. It also highlights supported transition animations like vertical switching and fading, while noting constraints such as the lack of support for screen rotation or routing jumps. This resource is primarily suitable for ArkUI developers looking to implement interactive modal interfaces within their Cangjie applications, offering the necessary technical guidance to ensure proper implementation and usage of the attribute in a development environment.
