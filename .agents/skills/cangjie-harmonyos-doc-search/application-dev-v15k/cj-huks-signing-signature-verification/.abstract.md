This directory serves as a specialized technical resource for implementing digital signing and signature verification using the Cangjie programming language and the Universal Keystore Kit (HUKS). It provides a structured approach to the complete cryptographic lifecycle, covering key generation, signing, verification, and deletion. The content is designed to support a variety of algorithms, including ECC, RSA, and SM2, with a specific focus on national cryptographic standards. It emphasizes session-based workflows and hardware-backed security to ensure robust protection. This directory is suitable for Cangjie developers and security engineers who need to integrate high-assurance cryptographic features into their applications.
