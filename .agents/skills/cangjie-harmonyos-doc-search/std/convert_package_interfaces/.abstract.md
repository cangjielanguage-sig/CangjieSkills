This directory provides a comprehensive overview of the `convert_package_interfaces` module, a fundamental part of the Cangjie programming language's standard library. It is designed to assist developers in understanding and implementing the core interfaces that facilitate type conversion and string manipulation. The documentation focuses heavily on three primary interfaces: `Formattable`, `Parsable`, and `RadixConvertible`. These components are crucial for applications that require precise data formatting, robust parsing logic, and the ability to handle numeric conversions across various radix systems. By detailing the methods and protocols associated with these interfaces, the directory serves as a vital resource for Cangjie developers. It enables the creation of applications that can seamlessly transition between primitive numeric types and their string representations, ensuring data integrity and providing comprehensive error handling for character and numeric types.
