This directory contains technical guides and stack trace analysis documents focused on debugging application issues within the HarmonyOS/OpenHarmony environment. It covers diagnosing application freezes (appfreeze), analyzing IPC communication failures, troubleshooting SQLite database operations, and resolving resource loading errors. The content provides specific examples of stack traces, explaining how to interpret Pid/Tid, identify mutex locks, and distinguish between frozen and busy threads. These resources are suitable for system developers, debuggers, and engineers proficient in C++, NAPI, and decompiling tools who need to diagnose runtime performance issues or crashes.
