# 安全单元访问开发指南

This directory provides a comprehensive guide for developers on how to access and utilize Secure Elements (SE) within applications using the Cangjie language and the HarmonyOS ConnectivityKit. It covers the fundamental concepts of SE technology, including eSE and NFC-enabled SIM cards, and provides practical tutorials for implementing secure communication scenarios like simulating NFC cards. The guide details the complete workflow for managing SE services, sessions, logical channels, and APDU data transmission. It is suitable for application developers working on secure NFC features who need to understand access control permissions and resource management within the HarmonyOS ecosystem.

## Detailed Description

### 主要场景开发步骤.md 主要场景开发步骤.md
This document serves as a comprehensive development tutorial guiding developers through the process of accessing a Secure Element (SE) within an application using the Cangjie language. It specifically covers the "Application Access to Secure Element" scenario, detailing technical steps from module import to data transmission. The code demonstrates the full workflow: creating an SEService, retrieving readers, selecting a specific reader (e.g., SIM), opening a session and logical channel using an AID, transmitting command data, and managing resource cleanup. It is intended for application developers working on secure communication features, requiring knowledge of Cangjie and the ConnectivityKit API. Keywords: Secure Element, Cangjie, ConnectivityKit, NFC, SE Service, Logical Channel, HarmonyOS.

### 简介_3more.md 简介_3more.md
This document serves as a technical introduction to Secure Element (SE) technology, defining key components like eSE and NFC-enabled SIM cards. It covers usage scenarios where applications simulate NFC cards by writing data to SEs, subject to access control permissions. The text outlines key interfaces for managing SE connections, including creating services, retrieving readers, opening sessions and logical channels, and transmitting APDU data. This overview is intended for developers implementing secure NFC functionality, providing a bridge to the full API reference.
