# 透明度变化的旋转屏动画

This directory provides comprehensive resources for implementing screen rotation animations featuring opacity transitions. It addresses the technical challenges of maintaining visual continuity when a device changes orientation, focusing on the smooth fading in and out of UI components. The materials cover implementation strategies for both Cangjie and HarmonyOS (ArkTS) development environments. Key topics include handling window size change events, configuring system settings for auto-rotation, and utilizing state management links like @StorageLink. These guides are ideal for developers seeking to refine application polish and user experience during dynamic layout adjustments.

## Detailed Description

### 透明度变化的旋转屏动画_1.md 透明度变化的旋转屏动画_1.md
This tutorial explains how to implement opacity transition animations for components during screen orientation changes in Cangjie applications. It covers the mechanism where the system automatically applies TransitionEffect.OPACITY to components added or removed during rotation, ensuring elegant appearance and disappearance. Key sections include the UI implementation using @StorageLink to switch views based on orientation and the logic for listening to windowsSizeChange events in MainAbility to update display state. The document highlights that developers can rely on default transitions or manually set them. Targeted at Cangjie/ArkUI developers, this guide provides code examples to enhance user experience during window rotation.

### 透明度变化的旋转屏动画_2.md 透明度变化的旋转屏动画_2.md
This document explains how to implement a screen rotation animation with opacity transitions for application views in a HarmonyOS application. It covers the necessary code implementation for window management, specifically listening to window size changes, and the required configuration in the module.json5 file to enable auto-rotation. Key information includes setting the orientation attribute to "auto_rotation" and utilizing window callbacks to manage transitions. The animation logic ensures that the disappearing view fades out while the new view fades in, alongside window size and position adjustments. This guide is intended for HarmonyOS developers familiar with ArkTS and application configuration, aiming to enhance user experience during device orientation changes. Keywords: HarmonyOS, screen rotation, opacity animation, window management, ArkTS, auto-rotation, view transition.
