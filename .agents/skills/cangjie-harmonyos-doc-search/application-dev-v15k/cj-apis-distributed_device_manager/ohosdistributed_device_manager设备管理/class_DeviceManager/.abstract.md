This directory contains API reference documentation for the `DeviceManager` class in the Cangjie programming language, specifically designed for HarmonyOS distributed hardware scenarios. It covers essential functionalities for managing trusted and local devices, including device discovery, binding, status monitoring, and information retrieval. Key topics include authentication, permission handling, and error management within the DistributedServiceKit. This documentation is suitable for application developers building distributed features who need to implement device connectivity, query device states, and manage hardware interactions across a network.
