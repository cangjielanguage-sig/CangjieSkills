This directory contains essential technical documentation for configuring system vibration effects, specifically targeting developers and system integrators implementing haptic feedback. It provides a complete guide to the three supported vibration types: fixed duration, preset, and custom vibrations. The content focuses heavily on the JSON-based configuration schema required for custom effects, detailing the structure of MetaData, Channels, and Patterns. It explains critical parameters for defining vibration events, such as StartTime, Duration, Intensity, and Frequency. Furthermore, it covers advanced features like Curve modulation and specifies system constraints, including event limits and file size restrictions. This resource is ideal for those needing precise control over vibration hardware using JSON and vibration APIs.
