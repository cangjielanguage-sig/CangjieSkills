# 应用组件级配置

This directory focuses on the configuration of application components and metadata within the HarmonyOS and Cangjie development frameworks. It covers essential setup tasks such as defining application icons, labels, version numbers, package names, device types, and permissions. Key topics include `app.json5` and `module.json5` file management, UIAbility skills, and system security policies. This documentation is suitable for HarmonyOS and Cangjie developers using DevEco Studio who need to ensure proper app representation, functionality, and compliance with system standards.

## Detailed Description

### 图标和标签配置.md 图标和标签配置.md
This document explains how to configure application icons and labels in HarmonyOS development, specifically within the `app.json5` and `module.json5` files. It covers the generation mechanism based on HAP content and UIAbility skills, application scenarios like desktop display, configuration examples, and system control rules regarding icon visibility. Key takeaways include that `app.json5` configuration is mandatory and recommended, while `module.json5` is optional unless specific entry abilities are defined. The system prioritizes module-level icons for home entries but defaults to app-level ones otherwise. Hiding desktop icons requires special privileges for pre-installed apps only. Targeted at HarmonyOS developers using DevEco Studio, this guide ensures proper app representation and compliance with system security policies.

### 应用版本声明配置_3more.md 应用版本声明配置_3more.md
This document serves as a configuration guide for defining application metadata and module capabilities within HarmonyOS development projects. It covers three main areas: application version declaration, module device type support, and module permission configuration. Key information includes configuring `versionCode` and `versionName` in the `app.json5` file for versioning, and using `deviceTypes` and `requestPermissions` tags in `module.json5` to specify supported hardware and declare necessary system access rights. This reference material targets HarmonyOS developers who need to correctly set up project configuration files to ensure proper app functionality and compliance.

### 应用组件级配置_2more.md 应用组件级配置_2more.md
This document serves as a configuration guide for defining application-level attributes, specifically focusing on identification features like package names within the Cangjie development framework. The primary section covers application package name configuration, detailing the specific file location and required tags. Key information includes the requirement to configure the `bundleName` tag in the `app.json5` file located in the AppScope directory. The document recommends using a reverse domain naming convention, such as `com.example.demo`, to ensure application uniqueness. This guide targets Cangjie application developers who need to set up their project's basic configuration and understand the directory structure.
