本目录提供了HarmonyOS蓝牙基础Profile模块（ohos.bluetooth.base_profile）的API参考文档，主要面向使用仓颉语言进行蓝牙应用开发的开发者。文档涵盖了蓝牙Profile的基础接口定义、状态变化参数封装、断开原因枚举以及回调事件类型。核心功能包括设备连接状态管理、回调订阅与取消订阅，以及相关的权限配置说明。该模块目前处于Beta阶段，旨在帮助开发者实现高效的蓝牙设备连接管理与状态监听，适用于蓝牙核心功能的开发与调试场景。
