# 访问和管理动态照片资源

This directory provides technical documentation for accessing and managing moving photo resources within the HarmonyOS ecosystem. It covers the integration of static images with short video and audio segments, focusing on the Media Library framework and MediaLibraryKit in the Cangjie programming language. Key topics include obtaining MovingPhoto objects, reading resource data, and handling hybrid media files. This guide is intended for application developers and multimedia engineers seeking to implement rich media features, manage dynamic photo assets, and enhance user creativity through advanced resource manipulation.

### 读取动态照片资源.md 读取动态照片资源.md
This document explains how to access and export resources from a dynamic photo object using the MediaLibraryKit in the Cangjie programming language. It covers the requestContent method usage, specifically focusing on two modes: exporting files to the application sandbox and reading raw ArrayBuffer data for both image and video components. The code example demonstrates defining file URIs for export, using ResourceType to specify content type (IMAGE_RESOURCE or VIDEO_RESOURCE), and implementing error handling via BusinessException. This is a technical code example or tutorial aimed at developers working on multimedia applications who need to handle moving photo assets within the HarmonyOS ecosystem.

### 获取动态照片对象/
This directory provides comprehensive technical documentation for developers working with dynamic photo assets in the HarmonyOS ecosystem using the Cangjie programming language. It specifically addresses the retrieval and instantiation of MovingPhoto objects, which are essential for applications that require playback or advanced resource manipulation of media files. The content covers two distinct approaches: accessing the system media library through the PhotoViewPicker interface and loading assets directly from the application's private sandbox storage.
