This directory contains comprehensive API reference documentation for the `EnumDecl` class, a fundamental component representing Enum definition nodes within the Cangjie language's Abstract Syntax Tree (AST). It covers the complete class architecture, including inheritance from the `Decl` base class, detailed property definitions for enum members, and syntax token management. Key topics include accessing constructors, declarations, and super types, as well as handling specific syntax elements like braces and ellipsis. Furthermore, it details critical methods for object initialization from token streams, serialization back to tokens, and AST traversal using the Visitor pattern. This documentation is essential for compiler developers and language engineers who require a deep understanding of AST manipulation, tokenization processes, and the structural nuances of Cangjie enums to effectively build or modify language tooling.
