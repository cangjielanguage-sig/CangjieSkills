# cj-uniform-data-structure

This directory provides a comprehensive guide for implementing standardized data structures in the Cangjie programming language, specifically targeting Uniform Type Descriptor (UTD) data types. It addresses scenarios involving cross-application data interaction, such as drag-and-drop, and offers detailed, step-by-step development instructions with code examples. The content covers creating UnifiedRecord objects for plain text and hyperlinks, managing them within UnifiedData objects, and retrieving records using pattern matching for types like STRING or INTEGER. This resource is essential for Cangjie developers building HarmonyOS applications who need to implement standardized data exchange mechanisms between apps. Keywords: Cangjie, UTD, UnifiedData, UnifiedRecord, Cross-application, Drag-and-drop, HarmonyOS.
