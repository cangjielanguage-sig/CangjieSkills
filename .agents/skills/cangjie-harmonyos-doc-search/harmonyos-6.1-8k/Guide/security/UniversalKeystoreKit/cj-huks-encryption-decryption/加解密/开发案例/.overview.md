# 开发案例

本目录汇集了基于仓颉语言和HarmonyOS通用密钥库（HUKS）的加密算法开发案例。内容涵盖了SM2国密、AES（CBC/PKCS7、GCM/NoPadding）以及RSA（OAEP/SHA256、PKCS1_V1_5）等多种算法的完整实现流程，包括密钥生成、参数配置、数据加解密及密钥生命周期管理。核心关键词包括HUKS、仓颉语言、SM2、AES、RSA、数据安全。该文档适合致力于HarmonyOS应用安全开发、需要掌握HUKS API调用及数据加密技术的开发者参考。

## 快速导航

## 详细描述

### SM2.md SM2.md
本文档演示了如何使用仓颉语言和HUKS API实现SM2国密算法的密钥管理及加解密操作。文档涵盖了生成、加密、解密和删除密钥的完整流程，重点展示了如何配置算法参数（如256位密钥、SM3摘要）以及使用`initSession`和`finishSession`进行会话式操作。关键信息包括通过`HuksParam`定义属性及利用密钥别名管理密钥。这是一份面向鸿蒙开发者的代码示例教程，旨在指导开发者实现基于SM2的数据安全功能。

### [2] AESCBCPKCS7/
本目录展示了如何在仓颉语言中利用HUKS（HarmonyOS Universal KeyStore）接口实现AES/CBC/PKCS7加密与解密功能。内容涵盖了密钥生成、加密参数配置、数据加解密逻辑以及密钥的删除管理。核心关键词包括HUKS、AES加密、CBC模式、PKCS7填充、仓颉语言及HarmonyOS开发。该文档适用于具备基础密码学知识的HarmonyOS开发者，旨在帮助其掌握数据安全存储与密钥生命周期管理的实现方法。

### [3] AESGCMNoPadding/
本目录包含关于使用AES-GCM无填充模式进行数据加密与解密的文档和代码示例。内容主要基于HarmonyOS通用密钥库系统（HUKS），涵盖了密钥生成、属性配置（如AAD、NONCE、AE Tag）、会话管理（initSession、finishSession）以及密钥删除等核心流程。文档特别展示了如何在仓颉语言中集成HUKS API，适合需要在HarmonyOS应用中实现高安全性数据加密的开发者参考。

### [4] RSAECBOAEPSHA256/
本目录展示了如何在鸿蒙系统的仓颉语言中，利用HUKS框架实现RSA/ECB/OAEP/SHA256模式的加密与解密操作。内容涵盖了密钥生成、参数配置、数据加密、解密以及密钥删除的完整流程。核心知识点包括HuksParam的算法定义、initSession/finishSession API的使用以及密钥生命周期管理。该文档适合需要在HarmonyOS应用中进行安全数据传输和密钥管理的开发者参考。

### [5] RSAECBPKCS1_V1_5/
本目录详细介绍了在仓颉编程语言环境下，如何利用HarmonyOS通用密钥库（HUKS）实现基于RSA算法的安全通信。具体涵盖了ECB模式配合PKCS1_V1_5填充标准的完整实现路径，包括密钥对的生成、参数配置、数据加密与解密的核心逻辑，以及密钥资源的销毁管理。核心关键词涵盖HUKS、RSA加密、PKCS1_V1_5、仓颉语言、密钥生命周期管理。该资料特别适合致力于HarmonyOS应用安全开发的仓颉语言使用者，旨在帮助开发者快速掌握HUKS API的调用方法，构建安全可靠的数据保护机制。
