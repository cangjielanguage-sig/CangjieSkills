This directory contains API reference documentation for the `GeoLocationManager` class in the Cangjie programming language, designed for HarmonyOS development. It covers a comprehensive suite of location services including GNSS positioning, geocoding, geofencing, and location status monitoring. The documents detail static methods for retrieving current locations, converting addresses to coordinates, and managing event subscriptions for satellite status and NMEA data. Essential for developers integrating LocationKit, these references include function signatures, required permissions like `ohos.permission.APPROXIMATELY_LOCATION`, and error handling codes to ensure robust location-based application implementation.
