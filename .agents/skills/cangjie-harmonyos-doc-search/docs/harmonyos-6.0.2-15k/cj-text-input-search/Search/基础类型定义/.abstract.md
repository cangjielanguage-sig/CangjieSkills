This directory provides essential API references for the ArkUI Search component within the Cangjie language ecosystem. It encompasses the core class for component control, enumerations for input behavior configuration, and structures defining geometric data types. Key topics include search controller methods, input type validation, cursor offset management, and UI element bounding boxes. Designed for HarmonyOS developers, these documents facilitate the creation of interactive and precise user interfaces by offering detailed specifications for system capabilities introduced in API version 19.
