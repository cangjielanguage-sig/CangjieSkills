This directory contains a comprehensive collection of command references for the `hidumper` tool, essential for OpenHarmony and HarmonyOS system diagnostics. It covers a wide range of functionalities including system information retrieval, process monitoring, memory analysis, IPC statistics, and specific service debugging like WindowManager and RenderService. The guides provide syntax for dumping heap snapshots, checking FPS, and managing crash logs. These resources are designed for developers and system administrators who need to inspect system state, debug services, analyze resource usage, or diagnose performance bottlenecks and memory leaks in a production or development environment.
