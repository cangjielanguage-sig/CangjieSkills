# class_UIAbilityContext

This directory provides API reference documentation for the `UIAbilityContext` class in the Cangjie programming language, essential for HarmonyOS developers using the AbilityKit framework. It details the class structure, properties, and methods for managing UIAbility lifecycles, system resources, and inter-component communication. Key functionalities include starting abilities, handling background transitions, returning results, and launching atomic services or links. This documentation is intended for developers building complex applications requiring precise control over ability states and navigation flows.
