# 显式Want与隐式Want匹配规则

This directory serves as a comprehensive technical reference for understanding the matching mechanisms of Explicit and Implicit Wants used to launch target application components. It covers the fundamental rules governing how caller-provided parameters align with target component configurations. It distinguishes between the direct nature of explicit matching and the flexible, capability-based nature of implicit matching. Key topics include the mandatory requirements for explicit matching, such as `bundleName` and `abilityName`, as well as the complex logic for implicit matching involving `action`, `entities`, `URI`, and `type` against `module.json5` skills. Additionally, it addresses specific behaviors like wildcard usage, URI parsing, and linkFeature scenarios. This documentation is essential for application developers who need to ensure correct component invocation, parameter handling, and application routing behavior within the system.

## Detailed Description

### 显式Want与隐式Want匹配规则_2more.md 显式Want与隐式Want匹配规则_2more.md
This technical reference document defines the matching rules for Explicit and Implicit Wants used to launch target application components. It primarily details the principles of Explicit Want matching, explaining how caller-provided parameters align with target component configurations. Key takeaways include the requirement that bundleName and abilityName are mandatory for explicit matching, while fields like action, entities, and uri are ignored during matching but still transmitted to the target. The document also clarifies the behavior of optional fields such as deviceId and moduleName. Intended for application developers, this guide ensures correct component invocation and parameter handling.

### 隐式Want匹配原理/
This directory provides a comprehensive technical reference for the principles and rules governing implicit Want matching in the system. It covers the logic used to match a caller's request parameters—specifically action, entities, URI, and type—against the skills configuration defined in a target application's module.json5. Key topics include URI component parsing, wildcard usage, linkFeature scenarios, and the specific behaviors for empty versus non-empty inputs. This documentation is suitable for developers configuring component capabilities, implementing application routing, or handling implicit intent invocations to ensure correct system behavior and application launching.
