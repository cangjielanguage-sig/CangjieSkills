# 前端页面调用应用侧函数

This directory provides comprehensive technical guides and tutorials focused on enabling frontend web pages to invoke application-side functions within hybrid development environments. It covers the essential implementation of JavaScript proxies, native function mapping, and secure communication configurations between web views and native code. Key topics include component initialization methods, memory management strategies to prevent leaks, and granular URL-based permission settings using JSON. These resources are specifically suitable for application developers working with ArkUI or Cangjie frameworks who need to establish robust, secure, and efficient interaction channels between web components and native applications.

## Detailed Description

### 前端页面调用应用侧函数_1.md 前端页面调用应用侧函数_1.md
This technical guide explains how to enable frontend web pages to invoke application-side functions using Web components. It details two primary registration methods: using `javaScriptProxy()` during component initialization and `registerJavaScriptProxy()` after initialization. The document provides Cangjie code examples demonstrating how to map native functions to frontend-accessible objects. It emphasizes that `registerJavaScriptProxy()` must be paired with `deleteJavaScriptRegister()` to prevent memory leaks. This guide targets application developers working with hybrid web-native integration who need to implement communication between web views and native code.

### 前端页面调用应用侧函数_2.md 前端页面调用应用侧函数_2.md
This document serves as a technical tutorial for enabling frontend pages to invoke application-side functions in ArkUI applications. It covers the implementation of JavaScript proxy registration and deletion using the webController, along with detailed JSON configuration for URL-based permissions at both object and method levels. Key information includes the requirement to call refresh() for registration to take effect and the specific syntax for defining scheme, host, and path permissions. The content provides code examples in ArkTS for the app side and HTML/JavaScript for the web side. This guide is intended for developers working on hybrid applications who need secure and controlled communication between web components and native code.
