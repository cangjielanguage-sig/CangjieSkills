# 结构体

This directory serves as a centralized repository for API reference documentation regarding fundamental data structures in the Cangjie programming language, specifically within the context of cryptographic operations. It provides detailed specifications for structs that govern the behavior of symmetric encryption and decryption algorithms. Key topics include the `OperationMode` struct, which defines standard block cipher modes like ECB, CBC, and GCM, and the `PaddingMode` struct, which outlines data padding schemes such as PKCS7. The documentation highlights the implementation of core interfaces like `ToString` and `Equatable`, enabling developers to easily retrieve mode identifiers and perform comparisons. This content is tailored for Cangjie developers, security engineers, and system architects who require precise technical guidance to implement robust cryptographic functionality in their applications.

## Detailed Description

### struct_OperationMode.md struct_OperationMode.md
This API reference document defines the OperationMode struct in the Cangjie programming language, which specifies working modes for symmetric encryption and decryption algorithms. The content details static properties for standard modes including ECB, CBC, OFB, CFB, CTR, and GCM, alongside the string property mode and inherited methods like toString and equality operators. Key information includes the struct's implementation of ToString and Equatable interfaces, enabling mode string retrieval and comparison. This documentation targets Cangjie developers implementing cryptographic functions, requiring knowledge of basic encryption concepts and Cangjie syntax.

### struct_PaddingMode.md struct_PaddingMode.md
This document provides API reference documentation for the PaddingMode struct in the Cangjie language, which defines padding modes used in symmetric encryption and decryption algorithms. The main sections cover the struct's definition, its inheritance from the Equatable protocol, and its members. Key information includes two static constants, NoPadding and PKCS7Padding, representing specific padding protocols with underlying integer values, alongside a paddingType property. The document also details overridden equality operators for comparing mode instances. Intended for developers implementing cryptographic functionality, this reference explains how to select and compare padding schemes within the crypto package.
