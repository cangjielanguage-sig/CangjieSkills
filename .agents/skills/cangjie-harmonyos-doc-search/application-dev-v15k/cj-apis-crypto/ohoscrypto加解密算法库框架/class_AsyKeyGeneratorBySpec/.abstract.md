This directory contains API reference documentation for the `AsyKeyGeneratorBySpec` class within the Cangjie programming language's CryptoFramework. It focuses on the generation and management of asymmetric key pairs based on specific parameters, covering algorithms such as DSA. The documentation details core functionalities including the `algName` property, `generateKeyPair()`, `generatePriKey()`, and `generatePubKey()` functions, along with their return types, system capabilities, and exception handling. This resource is suitable for software developers and cryptographic engineers implementing secure key generation and retrieval operations using the CryptoArchitectureKit.
