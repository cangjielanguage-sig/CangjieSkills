This directory provides comprehensive technical documentation for implementing ad filtering capabilities using the ArkWeb component within the HarmonyOS ecosystem. It covers the fundamental mechanisms of network-level interception and CSS-based element hiding, utilizing standard EasyList syntax for rule definition. Key topics include the `AdsBlockManager` API, domain matching logic, event handling for blocked ads, and the management of allowlists and disallowlists. Additionally, it outlines critical system constraints and performance thresholds. This resource is intended for application developers and system architects aiming to integrate robust ad-blocking features, customize filtering rules, and optimize user experience while strictly adhering to operational boundaries.
