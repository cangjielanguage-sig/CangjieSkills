This directory provides a comprehensive technical guide for HarmonyOS developers who need to navigate the complexities of application privilege levels and security models. It specifically addresses the common development hurdle where an application requires access to restricted system capabilities—such as global floating windows or screen capture—that exceed the app's standard Ability Privilege Level (APL). The content focuses on the Access Control List (ACL) mechanism, which allows for the temporary elevation of permissions strictly during the debugging phase. It details two primary methods for resolving level mismatches: utilizing the integrated features of DevEco Studio or manually editing the `HarmonyAppProvision` JSON configuration file. Additionally, the guide covers critical post-configuration steps, including editing specific fields like "allowed-acls" and "app-services-capabilities," and the necessity of re-signing the application. This resource is essential for developers ensuring their apps function correctly with high-level resources while adhering to the constraint that these methods are not suitable for commercial release.
