# 查看_eventHandler_信息

This directory provides technical guides for analyzing `eventHandler` dump logs to diagnose system performance issues, specifically application freezes (appfreeze) and scheduling anomalies. It covers the interpretation of task execution times, VIP and High priority queues, and watchdog timer logs. Developers will learn how to calculate task duration, identify bottlenecks in event queues, and distinguish between application freezes and thread starvation. This resource is suitable for system developers and engineers debugging event handling, thread management, and performance optimization in ArkUI applications.

## Detailed Description

### 查看_eventHandler_信息_1.md 查看_eventHandler_信息_1.md
This technical guide instructs developers on analyzing eventHandler dump logs to diagnose application freezes (appfreeze) by examining task execution times. The document details how to interpret the "dump begin" and "Current Running" sections, analyze the "History event queue information," and review VIP priority queues. Key takeaways include calculating task duration using timestamps like trigger time and complete time. If a task's duration exceeds the fault detection threshold, it is the likely cause of the freeze; otherwise, developers should check the history queue for the most time-consuming tasks. This reference material targets developers debugging system performance issues, requiring basic knowledge of log reading and thread management. Keywords: eventHandler, dump, appfreeze, log analysis, task duration, trigger time.

### 查看_eventHandler_信息_2.md 查看_eventHandler_信息_2.md
This technical reference document explains the log output and functionality of VIP and High priority event queues within the EventHandler system. It covers specific log entries for user input events and system watchdog tasks. Key information includes that VIP queues handle the transmission chain from user input to the ArkUI application, which are system-created and require no developer attention. The High priority queue contains periodic watchdog tasks occurring every 3 seconds. The document advises comparing the movement of these tasks against warning or block events for diagnostic purposes. Intended for system developers or engineers debugging event handling and performance issues.

### 查看_eventHandler_信息_3.md 查看_eventHandler_信息_3.md
This document provides a technical analysis of event handler logs to diagnose potential system freezing or scheduling issues. It covers high priority event queue information, specifically examining logs generated by a watchdog timer. The key takeaway is the interpretation of queue growth where the first task remains unchanged; this indicates either an application freeze preventing task scheduling or starvation caused by the accumulation of tasks in higher priority queues. This reference material is intended for system developers or debuggers troubleshooting thread execution and priority handling. Keywords: event handler, watchdog, high priority queue, system freeze, debugging, thread scheduling.
