# cj-web-content-scrolling

本目录主要介绍如何在ArkWeb组件中利用Cangjie语言实现Web页面内容的滚动控制。内容涵盖了`WebviewController`接口（如`scrollTo`和`scrollBy`）的调用方式、平滑滚动动画的生成以及强制中断动画的方法。文档提供了完整的Cangjie代码示例和HTML配置，适用于需要精细控制Web视图滚动行为的ArkWeb应用开发者。请注意，相关功能目前处于Beta阶段。

## 详细说明

### cj-web-content-scrolling.md cj-web-content-scrolling.md
本文档旨在介绍如何在ArkWeb组件中利用WebviewController接口实现Web页面内容的滚动控制。文档涵盖了scrollTo和scrollBy接口的调用方式、动画滚动效果的生成及强制中断方法，并提供了完整的Cangjie代码示例和HTML配置。关键信息指出，当页面内容超出显示区域时可进行滚动，且动画效果不支持手势打断，需通过执行极短时间的动画来强制停止。该文档面向使用Cangjie语言进行ArkWeb应用开发的开发者，相关功能目前处于Beta阶段。
