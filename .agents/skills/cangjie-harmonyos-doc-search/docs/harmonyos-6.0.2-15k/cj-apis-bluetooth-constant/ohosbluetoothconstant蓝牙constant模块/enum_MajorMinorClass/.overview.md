# enum_MajorMinorClass

This directory contains API reference documentation for the `MajorMinorClass` enumeration within the Cangjie programming language. It defines standardized constants for classifying Bluetooth device types, covering categories such as Audio/Video, Computer, Health, Imaging, Peripheral, Toy, and Wearable devices. All definitions require the `SystemCapability.Communication.Bluetooth.Core` capability and are available from API version 19. This documentation is designed for software developers implementing Bluetooth connectivity features who need to identify, categorize, and manage connected hardware roles within their applications.
