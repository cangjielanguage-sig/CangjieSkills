## 详细描述

### 文件 class_Application_9more_d7f8a3cd.md
本文档是Cangjie语言中ApplicationInfo类的API参考文档，旨在定义应用程序的配置信息结构。文档详细列出了该类的所有只读属性，涵盖应用基本信息、身份标识、安装路径及运行特性等。关键属性包括用于访问控制的accessTokenId、区分应用与原子化服务的bundleType、以及标识分身应用的appIndex。该类通过getBundleInfoForSelf接口获取，主要面向使用BundleManager框架的开发者，用于读取和管理应用自身的元数据及状态。

### 文件 let_debug_10more_1e22f1c3.md
该文档是Cangjie语言的API参考，定义了用于获取应用状态和元数据的多个只读属性。涵盖调试模式、应用描述与图标资源、可用性状态、安装来源及标签等核心属性。所有属性属于BundleManager框架核心能力，起始版本为22。文档详细说明了Bool、String及AppResource等数据类型，并关联了app.json5配置文件。面向Cangjie开发者，用于查询应用配置信息。

### 文件 let_labelId_10more_e86bc3dd.md
本文档是Cangjie语言的API参考文档，定义了应用程序信息的多个只读属性。主要涵盖资源标识（labelId、labelResource）、应用元数据（metadataArray）、权限列表（permissions）、进程名称（process）及SDK发布类型（releaseType）等核心字段。关键信息包括这些属性均属于BundleManager核心系统能力，起始版本为22，且部分属性需通过特定Flag参数获取。文档旨在帮助开发者读取应用配置、权限及兼容性信息，适用于需要查询或管理应用详情的开发场景。

### 文件 let_systemApp_2more_8415f9aa.md
本文档定义了Cangjie语言中用于获取应用信息的两个只读属性：systemApp和uid。主要内容包括`systemApp`属性，用于标识应用是否为系统应用；以及`uid`属性，用于获取应用程序的用户标识符。关键信息涵盖属性类型（Bool和Int32）、读写权限（只读）、系统能力要求（SystemCapability.BundleManager.BundleFramework.Core）及起始版本（22）。该文档面向使用Cangjie语言进行应用开发的程序员，适用于需要通过BundleManager框架查询应用元数据的场景。
