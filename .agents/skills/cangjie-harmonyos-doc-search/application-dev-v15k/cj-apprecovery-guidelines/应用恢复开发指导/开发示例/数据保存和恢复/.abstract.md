This directory serves as a technical resource for developers working with the Cangjie language and the AbilityKit framework, focusing specifically on the critical aspects of data saving and application recovery. It details methodologies for preserving application state during unexpected errors or terminations, ensuring a seamless user experience. The content covers two primary approaches: active state management using `appRecovery` and `ErrorObserver`, and passive state saving via `onSaveState` and launch reason detection. Key technical concepts include handling `wantParams`, identifying `APP_RECOVERY` triggers, and implementing restoration logic within the `onCreate` lifecycle method. These guides are indispensable for developers seeking to enhance application stability, prevent data loss, and implement robust error recovery mechanisms in their software projects.
