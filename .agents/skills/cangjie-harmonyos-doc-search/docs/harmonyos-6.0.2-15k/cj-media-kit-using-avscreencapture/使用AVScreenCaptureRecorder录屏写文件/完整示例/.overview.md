# 完整示例

This directory serves as a comprehensive repository for complete code examples written in the Cangjie language, targeting developers utilizing the MediaKit framework for media application development. It provides in-depth implementation guides for two critical scenarios: screen recording and media playback error handling. The content covers complex technical requirements such as configuring capture settings (resolution, bitrate), managing state change callbacks for privacy and microphone status, and implementing custom exception handling logic. These examples are highly suitable for software engineers and audio-video developers seeking practical references to integrate screen capture functionality and robust error reporting mechanisms into their applications, ensuring efficient resource management and runtime stability.

## Detailed Description

### 完整示例_1.md
This document provides a complete code example in Cangjie demonstrating how to implement screen recording to a file using the AVScreenCaptureRecorder class. It covers the main class structure, configuration parameters like resolution and bitrate, and the implementation of start and stop recording methods. Key takeaways include setting up the capture configuration, handling state change callbacks for events such as privacy mode and microphone status, and managing resource release. This example is intended for developers building media applications who need to integrate screen capture functionality using the MediaKit framework.

### 完整示例_2.md
This document provides a code example demonstrating how to implement a custom error callback class for an AVPlayer. The primary focus is on defining the ErrCallBack class, which inherits from Callback1Argument<BusinessException> to handle specific business exceptions. Key sections include the class initialization, which accepts an AVPlayer instance, and the implementation of the invoke method designed to process error events, currently illustrated by logging the exception. This reference material serves as a practical guide for developers integrating media playback functionality, showing how to structure error reporting logic. The target audience includes software developers working with audio-video SDKs who require a mechanism to manage and log runtime exceptions effectively.
