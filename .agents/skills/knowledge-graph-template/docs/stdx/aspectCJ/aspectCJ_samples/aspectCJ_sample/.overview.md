# aspectCJ_sample

本目录专门收录了仓颉语言中面向切面编程（AOP）的实战示例与开发指南。它深入探讨了如何利用 `stdx.aspectCJ` 库实现代码的非侵入式增强，重点涵盖了 `@InsertAtEntry`（入口插桩）、`@InsertAtExit`（退出插桩）和 `@ReplaceFuncBody`（函数体替换）三大核心注解的应用场景。文档不仅提供了完整的代码实现，还详细阐述了在 Linux 环境下进行切面收集与织入的两步编译流程。对于希望掌握 AOP 技术、优化代码结构或进行底层逻辑拦截的仓颉开发者而言，这是一份极具参考价值的资料。

## 详细说明

### aspectCJ_sample.md
本文档旨在提供仓颉语言中面向切面编程（AOP）的开发示例。文档详细介绍了三种核心注解的用法：`@InsertAtEntry` 用于函数入口插桩，`@InsertAtExit` 用于函数退出前插桩，以及 `@ReplaceFuncBody` 用于替换函数体。每个示例均包含完整的代码实现、Linux平台下的两步编译流程（收集切面与织入切面）及预期运行结果。关键要点在于掌握 `stdx.aspectCJ` 库的使用及编译插件的配置。该文档适合具备仓颉语言基础并希望利用AOP技术进行代码增强的开发者参考。
