# cj-image-tool

本目录提供了关于在OpenHarmony操作系统中使用仓颉语言进行图片处理的详细技术文档。核心内容聚焦于JPEG格式图片的EXIF元数据读取与编辑功能，旨在帮助开发者解决拍摄数据修正等实际问题。文档详细介绍了ImageSource对象的创建流程，以及如何利用`getImageProperty`和`modifyImageProperty`等关键接口进行属性操作。鉴于该功能目前处于Beta阶段且仅支持JPEG格式，本资源主要面向图库、相机等需要深度处理图片元数据的应用开发者，为其提供必要的开发指导与API参考。

### cj-image-tool.md cj-image-tool.md
本文档介绍如何在OpenHarmony中使用仓颉语言读取和编辑JPEG图片的EXIF信息。内容涵盖EXIF定义、修正拍摄数据的应用场景及开发步骤。重点说明了创建ImageSource对象、使用getImageProperty读取和modifyImageProperty修改属性的方法。文档指出当前仅支持JPEG格式且处于Beta阶段，面向需要处理图片元数据的开发者，适用于图库或相机应用开发。
