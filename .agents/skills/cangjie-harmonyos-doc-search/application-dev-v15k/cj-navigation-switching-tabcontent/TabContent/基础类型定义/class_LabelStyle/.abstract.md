This directory provides comprehensive API reference documentation for the `LabelStyle` class in the Cangjie programming language, specifically tailored for the ArkUI framework. It covers the structural definition and instantiation of label styles, detailing how to manage text appearance through various properties. Key topics include text overflow handling, maximum line limits, adaptive font size ranges, and color states for selected versus unselected text. This documentation is essential for UI developers looking to programmatically customize label behavior and aesthetics within their applications, ensuring proper text rendering and layout adaptation.
