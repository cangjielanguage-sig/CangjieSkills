# 焦点事件

This directory provides a comprehensive guide to focus management within the Cangjie ArkUI framework, covering everything from core algorithms to practical implementation. It details how to handle keyboard inputs, customize focus styles, and manage component states like focus gain and loss. Key topics include focus groups, priority settings, and navigation strategies for non-pointing devices. This documentation is essential for UI developers and system architects aiming to build accessible, keyboard-driven applications for platforms such as TVs and automotive interfaces.

## Detailed Description

### 焦点与按键事件.md 焦点与按键事件.md
This technical guide explains how keyboard inputs, specifically Enter and Space, trigger click or tap events on focused components within the ArkUI framework. It details the specific event bubbling behaviors, distinguishing between click events and key events, and clarifies that both can respond simultaneously. The document includes a Cangjie code example demonstrating a button with an onClick handler to illustrate these concepts. Key takeaways include that key-triggered clicks do not bubble up, unlike standard key events, and focus activation state does not impact click responsiveness. This guide is intended for developers building UI applications using the Cangjie language who need to implement accessible keyboard navigation.

### 焦点样式_2more.md 焦点样式_2more.md
This document provides a guide and API reference for managing component focus styles and programmatic focus control in the Cangjie ArkUI framework. It covers "Focus Styles" for customizing visual appearance and "Active Focus/Blur" for manual focus transfer. Key APIs include `focusBox(style: FocusBoxStyle)` for setting stroke properties and `FocusControl.requestFocus(keyValue: String)` for triggering focus. The document notes that focused components automatically have their `zIndex` raised to `INT_MAX`. Intended for Cangjie developers, this guide helps implement navigation and visual feedback using code examples and state management.

### 焦点组与获焦优先级.md 焦点组与获焦优先级.md
This document serves as a technical guide for managing component focus behavior in Cangjie UI applications using focus groups and priority settings. It details the focusScopePriority and focusScopeId APIs, providing a code example that demonstrates how to define focus scopes and control navigation flow. Key concepts include the distinction between focus groups and standard containers, where groups allow Tab key skipping and internal arrow key navigation, and priority settings dictate initial focus targets. Intended for Cangjie developers, this reference requires basic UI framework knowledge to implement custom focus logic effectively.

### 获焦失焦事件.md 获焦失焦事件.md

It details the `onFocus` and `onBlur` function signatures, explaining how to bind callbacks that trigger when components gain or lose focus. The key takeaway is a practical code example demonstrating how to pair these interfaces to monitor focus transitions, specifically changing button background colors dynamically during keyboard navigation. This guide targets Cangjie developers implementing interactive UI behaviors requiring focus management and state updates.

### 设置组件是否可获焦/
This directory provides a comprehensive guide on managing component focusability within the ArkUI framework using the Cangjie language. It covers essential APIs such as `focusable`, `enabled`, `visibility`, and `focusOnTouch`, explaining how to control whether a UI component can receive user input focus. The content details the categorization of components into three types—default focusable, capable but default unfocusable, and incapable—and describes behaviors like automatic focus transfer when states change dynamically. It is suitable for UI developers and engineers looking to implement robust focus control logic, handle keyboard events, and manage user interaction flows in declarative UI applications. Understanding these concepts is crucial for creating accessible and navigable user interfaces.
