# 不新建组件并直接变化原组件

本目录包含关于ArkUI开发中高级动画技巧的教程，重点介绍如何在不新建组件容器的情况下，通过直接修改原组件属性来实现流畅的“一镜到底”视觉效果。内容涵盖了组合转场动画、属性动画、状态变量控制UI更新以及Cangjie代码实现。核心知识点包括TransitionEffect、animateTo方法及布局尺寸动态调整。该文档适合具备ArkUI和Cangjie基础的HarmonyOS开发者，用于实现复杂的容器展开和组件动态切换交互。

## 详细描述

### 不新建组件并直接变化原组件_1.md
本文档是一份ArkUI开发教程，旨在介绍如何在不新建容器的情况下，通过组合转场动画与属性动画实现“一镜到底”的视觉效果。文档主要阐述了该方法的基本原理、实现步骤，并提供了点击卡片展开详情的Cangjie代码示例。关键内容包括利用状态变量控制兄弟组件的显隐以触发转场，以及配置TransitionEffect和animateTo实现平滑过渡。该文档面向具备ArkUI和Cangjie基础的开发者，适用于实现容器展开及组件动态切换的交互场景。

### 不新建组件并直接变化原组件_2.md
本文档演示了如何在ArkUI中通过直接修改原组件属性而非新建组件来实现展开/收起动画效果。涵盖了使用animateTo方法控制布局尺寸变化、transition属性实现透明度转场以及状态变量驱动的UI更新。核心要点在于利用状态变量（如isExpand、itemHeight）配合动画参数，实现点击后卡片高度、图片尺寸及评论区显示的平滑过渡。适用于HarmonyOS开发者，作为实现复杂UI交互和动画效果的代码参考教程。
