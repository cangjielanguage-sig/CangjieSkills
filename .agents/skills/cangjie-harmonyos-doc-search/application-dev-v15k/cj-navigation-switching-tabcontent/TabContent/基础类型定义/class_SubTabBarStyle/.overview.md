# class_SubTabBarStyle

This directory provides comprehensive API reference documentation for the `SubTabBarStyle` class within the Cangjie language framework, specifically tailored for ArkUI applications. It focuses on the configuration of sub-tab appearance and behavior, detailing initialization methods that utilize String or AppResource content, static factory functions, and various property setters for board style, ID, and indicator style. The documentation highlights key features such as automatic jump animations during tab switching and specific restrictions where board and indicator styles apply only to horizontal mode. It is an essential resource for developers using Cangjie to build user interfaces, offering method signatures, parameters, and return values to facilitate fluent-style tab customization and programmatic UI component styling.
