# ohosinput_method输入法框架

This directory contains the API reference documentation for the HarmonyOS Input Method Framework (IMF) implemented in the Cangjie programming language. It covers essential components for developing and managing input method editors (IMEs), including data structures for text configuration, window management, and event handling. Key topics include input attributes, keyboard status, cursor control, and system settings. Designed for system developers and application engineers working on text entry interfaces, this documentation provides the necessary definitions and utilities to integrate robust input functionalities within the HarmonyOS ecosystem.

## Detailed Description

### class_InputAttribute.md class_InputAttribute.md
This API reference defines the `InputAttribute` class in Cangjie for configuring input box properties. It details the constructor and read-only properties `textInputType` and `enterKeyType`, which define text behavior and Enter key functionality. It is intended for developers working on system input methods.

### class_InputMethodProperty.md class_InputMethodProperty.md
This document provides API reference for the `InputMethodProperty` class, defining attributes for input method applications. It covers the constructor, properties like name and id, and notes that the icon field is reserved and unsupported.

### class_InputMethodSubtype.md class_InputMethodSubtype.md
This reference defines the `InputMethodSubtype` class for managing input method subtypes to facilitate language or mode switching. It details properties such as locale, language, and mode, all of which are read-only.

### class_InputWindowInfo_3more.md class_InputWindowInfo_3more.md
This document covers three data classes: `InputWindowInfo` for soft keyboard properties, `Movement` for cursor direction, and `Range` for text selection boundaries. All classes are read-only and initialized via constructors.

### class_TextConfig.md class_TextConfig.md
This document defines the `TextConfig` class, a configuration structure for edit boxes. It details properties for input attributes, cursor positioning, text ranges, and window identification, with read-write capabilities.

### enum_Direction_3more.md enum_Direction_3more.md
This reference details enums for cursor movement (`Direction`), Enter key behavior (`EnterKeyType`), and text editing actions (`ExtendAction`). It defines constants for standard input behaviors and text manipulation features.

### enum_IMFEventType.md enum_IMFEventType.md
This document defines the `IMFEventType` enum, categorizing callback events like text insertion, deletion, and cursor manipulation. It is intended for developers handling user interactions and text editing operations programmatically.

### enum_KeyboardStatus.md enum_KeyboardStatus.md
This reference defines the `KeyboardStatus` enum, specifying visibility states (NONE, HIDE, SHOW) for the input method soft keyboard. It is used to track or control keyboard display states.

### enum_RequestKeyboardReason.md enum_RequestKeyboardReason.md
This document defines the `RequestKeyboardReason` enum, categorizing triggers for keyboard requests such as Mouse, Touch, or Other. It helps developers identify the source of input requests.

### enum_TextInputType.md enum_TextInputType.md
This reference defines the `TextInputType` enumeration for specifying text input styles like TEXT, NUMBER, and EMAIL. It is used to configure keyboard behaviors and input validation.

### func_getSetting_4more.md func_getSetting_4more.md
This document details functions for input method settings, including `getSetting` and `getSystemInputMethodConfigAbility`. It also defines data structures like `CursorInfo` and `FunctionKey` for managing UI interactions.

### ohosinput_method输入法框架_9more.md ohosinput_method输入法框架_9more.md
This is the main module overview for `ohos.input_method`, covering imports, permissions, and core functions like `getController` and `getDefaultInputMethod`. It targets developers integrating input functionalities.

### class_InputMethodController/
This directory contains API reference for the `InputMethodController` class, covering the management of input method interactions, binding self-drawn controls, handling text selection, and managing keyboard visibility.

### class_InputMethodSetting/
This directory provides documentation for the `InputMethodSetting` class, facilitating the management of input method configurations, filtering installed methods, and querying specific subtypes.
