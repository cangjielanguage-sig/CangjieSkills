This directory contains comprehensive documentation for the Badge component within the ArkUI framework, designed for HarmonyOS application development using the Cangjie programming language. It covers the complete implementation lifecycle, including API references, foundational type definitions, and practical code examples for creating and configuring notification markers. Key topics include `BadgeParams`, styling, positioning, and state-driven visibility. This resource is suitable for developers working on system version 12 or higher who need to integrate status indicators and information reminders into their user interfaces with precision.
