This directory contains API reference documentation for the `Config` class within the Cangjie language's FileTransferAgent system. It covers the configuration of upload and download tasks, detailing constructors, network constraints, progress notifications, and data handling properties. Key topics include HTTP protocol settings, file path management, and task initialization parameters. This documentation is suitable for software developers and system integrators who need to implement robust file transfer capabilities, manage network behaviors, and configure task priorities in Cangjie applications.
