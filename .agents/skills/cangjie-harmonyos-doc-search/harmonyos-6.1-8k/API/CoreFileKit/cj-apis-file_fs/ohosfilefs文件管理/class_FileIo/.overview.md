# class_FileIo

本目录包含仓颉语言中 `FileIo` 类的 API 参考文档，涵盖了文件系统操作的核心功能。主要内容包括文件的创建、读写、复制、移动、删除、权限检查以及目录管理等静态方法。文档详细介绍了各函数的参数定义、返回值、系统能力要求及异常处理机制。适用于使用 CoreFileKit 进行 HarmonyOS 应用开发的程序员，旨在帮助开发者掌握应用沙箱内的文件 I/O 操作与数据持久化。
