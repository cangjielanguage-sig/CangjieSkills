### func ==(JSType)

```cangjie
public operator func ==(target: JSType): Bool
```

**功能：** 对两个 JSType 进行判等。

**系统能力：** SystemCapability.ArkUI.ArkUI.Napi

**起始版本：** 13

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|target|[JSType](#struct-jstype)|是|-|对比的目标类型。|

**返回值：**

|类型|说明|
|:----|:----|
|Bool|为 true 时代表两个类型相等。|
