This directory contains documentation for the restool tool, a command-line utility designed for compiling and managing application resources within HarmonyOS and OpenHarmony development environments. It covers essential workflows such as resource compilation (full and incremental), resource ID management, and command-line parameter configuration. The documentation explains how restool integrates with the SDK toolchains to generate indexes and parse resources for programmatic access via the resource management API. Suitable for software developers and build engineers, these guides provide the necessary instructions to automate resource handling, validate icons, and configure multi-module projects efficiently.
