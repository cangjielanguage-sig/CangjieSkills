# cj-net-connection-manager

This directory serves as a comprehensive technical resource dedicated to managing network connections within HarmonyOS applications using the Cangjie programming language. It focuses extensively on the NetworkKit framework, providing developers with the essential tools required for monitoring real-time network status, performing domain name resolution, querying network capabilities, and handling connection rebuilding processes. The guide covers the management of diverse network types, including WiFi, cellular, and Ethernet, and explains how to implement advanced features such as application binding to specific networks, priority control, and DNS resolution. This documentation is specifically designed for HarmonyOS application developers who need to handle complex network state transitions, optimize connection quality, or perform low-level network queries to build robust and efficient communication modules.

## Detailed Description

### 网络连接管理/
This directory provides development guides and API references for HarmonyOS network connection management based on the Cangjie language. The content covers core functions such as network status monitoring, domain name resolution, network capability queries, and connection rebuilding. By utilizing NetworkKit, developers can manage WiFi, cellular, and Ethernet networks, enabling application binding to specific networks, priority control, and DNS resolution. This documentation is suitable for HarmonyOS application developers who need to handle network state migration, optimize network connection quality, or perform low-level network queries, helping them build stable and efficient network communication modules.
