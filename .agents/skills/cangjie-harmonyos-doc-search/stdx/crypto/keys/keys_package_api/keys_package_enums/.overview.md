# keys_package_enums

本目录 `keys_package_enums` 专门用于存储密钥包相关的枚举类型API参考文档，核心目标是定义和规范加密算法实现中所需的各种配置选项。文档内容主要聚焦于两大核心组件：一是用于ECDSA（椭圆曲线数字签名算法）密钥生成的 `Curve` 枚举，详细列举了包括NIST P系列和Brainpool BP系列在内的八种主流椭圆曲线，并阐述了它们各自的安全特性；二是用于RSA加密操作的 `PadOption` 枚举，涵盖了OAEP、PSS和PKCS1等多种填充模式，并明确建议开发者优先采用安全性更高的PSS或OAEP模式以规避潜在的安全隐患。该文档主要面向需要进行底层加密参数配置、密钥管理或安全系统集成的开发人员，提供了清晰的类型定义、使用方法及安全最佳实践指导。

## Detailed Description

### keys_package_enums.md keys_package_enums.md
这是一份关于密钥包枚举类型的API参考文档，旨在定义加密算法中使用的配置选项。文档主要包含两个部分：Curve枚举用于选择ECDSA密钥生成的椭圆曲线类型，详细列出了NIST P系列和Brainpool BP系列共八种曲线及其安全特性；PadOption枚举用于设置RSA的填充模式，涵盖OAEP、PSS和PKCS1，并建议优先使用更安全的PSS或OAEP以避免安全风险。该文档适合需要配置加密参数的开发人员阅读，提供了清晰的类型定义和安全指导。
