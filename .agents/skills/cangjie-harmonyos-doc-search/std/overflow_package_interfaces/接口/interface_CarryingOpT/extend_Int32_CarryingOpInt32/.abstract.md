This directory serves as a comprehensive API reference for the `CarryingOp` interface implementation tailored for the `Int32` type in the Cangjie programming language. It provides detailed documentation on a wide array of arithmetic functions that employ a wrapping strategy to manage integer overflows effectively. The scope includes fundamental operations such as addition, subtraction, multiplication, division, and modulo, as well as negation and bit shifting. A defining feature of these operations is their return type: a tuple comprising the computed result and a Boolean flag that signals whether truncation took place. This documentation is essential for developers who demand exact precision in integer arithmetic and require robust mechanisms for detecting and handling overflow conditions in their software projects.
