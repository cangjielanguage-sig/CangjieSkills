# 组件属性

本目录包含ArkUI框架下Cangjie语言的组件属性API参考文档。主要涵盖图形组件的填充、描边、边框样式及抗锯齿等视觉呈现属性的设置方法。文档详细介绍了相关函数的参数类型、默认值、取值范围及异常处理逻辑。适用于需要通过代码精细控制UI图形绘制效果的ArkUI应用开发者。

## 详细描述

### func_fillResource_8more_7083fb63.md
这是一份ArkUI框架的Cangjie语言API参考文档，详细说明了图形组件的填充与描边属性设置方法。文档涵盖了填充颜色、填充透明度、描边颜色、虚线样式、偏移量、线帽及拐角样式等核心函数。关键内容包括各属性的参数类型、默认值（如填充默认黑色）、取值范围限制及异常处理逻辑。这些接口系统能力为ArkUI.Full，起始版本为22。文档主要面向使用Cangjie语言的ArkUI开发者，旨在帮助其通过代码精确控制图形的视觉呈现效果。

### func_strokeMiterL_5more_555f9f2b.md
本文档是ArkUI框架下Cangjie语言的API参考文档，旨在定义图形元素边框的绘制样式属性。文档主要包含四个函数：strokeMiterLimit用于设置斜接长度与宽度的比值极限；strokeOpacity用于设置边框透明度，支持数值和资源类型；strokeWidth用于设置边框宽度；antiAlias用于控制抗锯齿开关。关键信息涵盖了各属性的参数类型、合法取值范围、默认值及异常处理机制，例如透明度限制在0.0至1.0之间。该文档面向ArkUI应用开发者，适用于需要精细控制图形绘制效果的UI编程场景。
