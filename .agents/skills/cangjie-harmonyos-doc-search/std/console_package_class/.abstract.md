This directory contains documentation for the deprecated console input/output (I/O) classes within the Cangjie programming language ecosystem. It focuses on the structural definitions and API references for the `Console`, `ConsoleReader`, and `ConsoleWriter` components, which handle standard stream operations. The content highlights deprecation notices and guides developers toward migrating to the modern `env` package. This resource is specifically suitable for Cangjie developers maintaining legacy codebases or those needing to understand the specifications of these obsolete components for compatibility reasons.
