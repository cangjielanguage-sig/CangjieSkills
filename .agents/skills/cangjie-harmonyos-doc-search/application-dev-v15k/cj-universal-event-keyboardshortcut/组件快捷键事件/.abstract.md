This directory focuses on the implementation and management of keyboard shortcuts within the ArkUI framework using the Cangjie language. It covers essential usage rules, system-level restrictions, and detailed API references for the `keyboardShortcut` function. Key topics include event priority, focus dependencies, conflict resolution mechanisms, and prohibited system key combinations. This documentation is specifically designed for developers seeking to enhance UI interaction, accessibility, and navigation efficiency through custom keyboard events while avoiding conflicts with system operations.
