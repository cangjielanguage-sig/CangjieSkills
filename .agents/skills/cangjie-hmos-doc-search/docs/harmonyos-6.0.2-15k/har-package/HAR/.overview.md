# HAR

This directory contains technical documentation for HAR (Harmony Archive), a static shared package format used in HarmonyOS development for distributing Cangjie components, code, and resources. It covers the complete lifecycle of HAR packages, including creation, compilation, publishing, and consumption within DevEco Studio. Key topics include dependency management, resource conflict resolution, and integration with OHPM repositories. This resource is suitable for HarmonyOS developers and library maintainers looking to modularize their applications and share code efficiently across projects.

## Detailed Description

### HAR_4more.md HAR_4more.md
This technical guide defines HAR (Harmony Archive), a static shared package designed for sharing Cangjie components, code, and resources across HarmonyOS modules and projects. The document outlines usage scenarios for internal and external SDK distribution via OHPM repositories, details creation methods in DevEco Studio, and lists critical constraints. Key takeaways include that HARs cannot run standalone, do not support transitive or circular dependencies, and automatically merge permissions during compilation. It also specifies requirements for binary HARs, such as SDK version matching and specific packaging configurations for Cangjie libraries. This guide is intended for developers managing shared libraries and dependencies in HarmonyOS applications.

### 开发.md 开发.md
This technical guide instructs developers on exporting Cangjie components, classes, methods, and resources from a HAR package for external reference. It details using the public modifier to expose code elements and explains the compilation behavior where HARs integrate directly into the host application. The document outlines resource management, specifically the priority rules for resolving file conflicts during the HAP build process, favoring AppScope over HAP modules and dependent HARs. It is intended for HarmonyOS developers utilizing the Cangjie language to create modular, reusable libraries.
