# cj-universal-event-areachange

This directory contains the essential API reference documentation for the area change event functionality within the Cangjie ArkUI framework. It focuses specifically on the `onAreaChange` function, enabling developers to effectively monitor and respond to dynamic changes in a component's size or position. The documentation provides a deep dive into the technical requirements, including module imports, function signatures, parameters, and return values. Importantly, it clarifies the specific behavior of this event, noting that it is triggered exclusively by layout changes rather than rendering transformations like translate or offset. This resource is highly suitable for ArkUI developers and engineers tasked with building responsive user interfaces that require real-time geometry monitoring and adaptive layout adjustments.

## Detailed Description

### cj-universal-event-areachange.md cj-universal-event-areachange.md
This document serves as the primary API reference documentation for the component area change event within the Cangjie ArkUI framework. It details the `onAreaChange` function, a critical tool that allows developers to handle callbacks triggered by changes in a component's size or position.

The documentation is structured to provide comprehensive technical guidance, covering:
*   **Implementation Details:** Clear instructions on module imports, the exact function signature, and the expected parameters and return values.
*   **Behavioral Constraints:** Crucial specifications regarding the event's trigger conditions, explicitly stating that it responds only to layout changes and not rendering changes like translate or offset.
*   **State Management:** Information on the callback parameters, which represent the previous and current Area states, allowing for delta calculations.

This guide is intended for ArkUI developers who are implementing responsive UI logic requiring precise geometry monitoring to ensure their applications adapt correctly to dynamic layout environments.
