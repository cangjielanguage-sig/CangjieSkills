# 内容对齐

本目录主要介绍ArkUI框架中Flex布局组件的`alignContent`属性使用方法，重点讲解如何控制多行子元素在交叉轴上的对齐方式。内容涵盖了Start、Center、End、SpaceBetween、SpaceAround及SpaceEvenly等多种对齐模式，并提供了基于Cangjie语言的完整代码示例与效果图。这些文档适合具备ArkUI和Cangjie基础语法的开发者阅读，旨在帮助用户优化多行容器的布局排版，解决UI开发中的对齐问题。

## 详细说明

### 内容对齐_1.md 内容对齐_1.md
本文档旨在指导开发者如何在ArkUI框架的Flex布局中使用alignContent参数来控制多行子元素在交叉轴上的对齐方式。文档详细列举了Start、Center、End、SpaceBetween及SpaceAround五种对齐选项，并为每种选项提供了基于Cangjie语言的完整代码示例及效果图。核心要点是该参数仅在多行Flex布局（即wrap属性生效时）下起作用。这份教程适合具备基础ArkUI和Cangjie语法知识的开发者，用于优化多行容器的布局排版。

### 内容对齐_2.md 内容对齐_2.md
本文档旨在通过代码示例演示ArkUI中Flex布局组件的alignContent属性用法，重点讲解多行对齐方式。文档主要涵盖了FlexAlign.SpaceAround和FlexAlign.SpaceEvenly两种对齐模式，展示了在开启FlexWrap.Wrap换行时的布局效果。关键信息包括具体的Cangjie语言代码实现、子元素宽度设置以及alignContent对交叉轴上各行间距的影响，特别是SpaceEvenly模式下子元素各行间距与首尾行距交叉轴两端距离相等的特性。该文档适合正在学习或使用ArkUI框架进行UI开发的开发者，作为布局调整的参考教程。
