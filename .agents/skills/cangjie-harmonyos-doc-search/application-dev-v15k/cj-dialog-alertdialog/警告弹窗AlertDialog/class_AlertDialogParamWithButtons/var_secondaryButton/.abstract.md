This directory contains API reference documentation for configuring the secondary button within AlertDialog components using the Cangjie language and ArkUI framework. It covers the initialization of dialogs featuring two confirmation buttons, detailed constructor parameters for layout and styling, and specific properties for the secondary button variable. Key topics include button customization, modal behavior, event handling, and system capabilities. This documentation is suitable for software developers and UI engineers working on ArkUI applications who need to implement interactive alert dialogs with specific secondary action configurations and visual styles.
