# cangjie_arkts_overview

本目录提供了仓颉与ArkTS在OpenHarmony系统上互操作机制的全面概述。文档重点介绍了通过库级别调用实现生态复用的技术方案，涵盖了双向调用场景、互操作宏、动态导入及HLE工具等调用方式，并详细解析了JSValue、JSContext、JSCallInfo和JSRuntime等核心类型。该文档适用于需要在OpenHarmony平台上进行跨语言开发的开发者，旨在帮助其理解并掌握两种语言间的数据传递与运行时交互机制。

## 详细说明

### cangjie_arkts_overview.md cangjie_arkts_overview.md
本文档概述了仓颉与ArkTS在OpenHarmony系统上的互操作机制，旨在通过库级别的调用实现生态复用。内容涵盖了使用场景分类（仓颉应用调用ArkTS及反之）、调用方式（互操作宏、库、动态导入、HLE工具）以及互操作库的核心类型介绍。重点介绍了互操作库中的核心类型，包括用于数据传递的JSValue、辅助类型转换的JSContext、封装调用参数的JSCallInfo以及代表运行时的JSRuntime。适用于需要在OpenHarmony平台上进行跨语言开发的开发者，属于技术参考文档。
