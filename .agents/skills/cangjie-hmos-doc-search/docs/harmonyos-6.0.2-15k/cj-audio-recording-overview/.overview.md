# cj-audio-recording-overview

This directory provides a comprehensive development overview for selecting the appropriate audio recording APIs within the system. It covers four primary methods: AudioCapturer (Cangjie, PCM), OpenSL ES (Native, cross-platform), OHAudio (Native, low-latency), and AVRecorder (Cangjie, m4a output). The guide details development prerequisites, including necessary permissions like `ohos.permission.MICROPHONE` and foreground requirements. It is designed for media application developers using Cangjie or Native APIs who need to implement audio input functionality, helping them distinguish between raw PCM data handling and integrated file generation solutions.

## Detailed Description

### cj-audio-recording-overview.md cj-audio-recording-overview.md
This document serves as a development overview guiding developers on selecting appropriate audio recording APIs within the system. It compares four main methods: AudioCapturer (Cangjie, PCM), OpenSL ES (Native, cross-platform), OHAudio (Native, low-latency), and AVRecorder (Cangjie, m4a output). It also covers development prerequisites. Key takeaways include that AudioCapturer, OpenSL ES, and OHAudio support only PCM and require manual data handling, whereas AVRecorder integrates encoding and file generation. Developers must request the `ohos.permission.MICROPHONE` permission and initiate recording in the foreground. This guide targets media application developers using Cangjie or Native APIs who need to implement audio input functionality.
