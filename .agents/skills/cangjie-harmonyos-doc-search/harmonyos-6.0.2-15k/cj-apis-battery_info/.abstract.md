This directory provides a specialized collection of API reference documentation for the `ohos.battery_info` module, specifically developed for the Cangjie programming language within the HarmonyOS environment. It serves as a critical resource for software engineers aiming to build energy-efficient applications by providing detailed interfaces for querying essential battery metrics. The content encompasses a broad spectrum of power management functionalities, including the monitoring of charging states, the assessment of battery health, and the handling of common event keys. Inside, developers will find comprehensive definitions for enumerations regarding capacity levels, charge states, health states, and plugged types, as well as documentation for the central `BatteryInfo` class which facilitates real-time data retrieval. This directory is indispensable for Cangjie developers and system engineers who are tasked with implementing sophisticated battery monitoring systems, optimizing power management features, and tracking energy consumption to enhance user experience and device longevity.
