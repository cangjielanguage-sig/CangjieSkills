This directory provides comprehensive API reference documentation for the `ohos.background_task_mgr` module, specifically tailored for the Cangjie programming language within the HarmonyOS ecosystem. It focuses on enabling developers to manage background tasks efficiently, preventing application suspension during critical operations. The documentation covers a wide range of functionalities, including defining long-running task modes like audio playback and location services, requesting short-time delay tasks (up to 3 minutes), and managing task lifecycles through cancellation and time retrieval. It includes essential details on system capabilities, version requirements (starting from API 12), and error handling. This resource is ideal for Cangjie developers seeking to implement robust background execution logic, handle transient tasks, and ensure application continuity in various usage scenarios.
