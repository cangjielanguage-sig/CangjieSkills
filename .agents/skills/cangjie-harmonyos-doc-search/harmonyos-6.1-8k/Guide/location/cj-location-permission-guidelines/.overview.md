# cj-location-permission-guidelines

本目录包含一份针对HarmonyOS应用开发者的位置权限申请指导文档。文档详细阐述了在应用中集成位置功能所需的关键步骤，重点介绍了Location Kit的使用前提及两种核心权限：精准位置和模糊位置。内容深入分析了前台申请权限的两种方式及其带来的精度差异，明确指出单独申请模糊权限仅能提供约5公里的定位精度，而同时申请两者则可获得米级的高精度定位。该指南旨在帮助开发者理解不同权限策略对应用功能的影响，从而做出最佳选择。它适用于具备基础开发配置知识并希望规范处理位置权限的HarmonyOS开发者。

## Detailed Description

### cj-location-permission-guidelines.md
本文档是一份开发指导，旨在指导开发者在应用中申请位置权限。文档涵盖场景概述和开发步骤，介绍了Location Kit的使用前提及两种核心权限：精准位置和模糊位置。关键信息阐明了前台申请权限的两种方式及其对应的精确度差异，即单独申请模糊权限获取5公里精度，同时申请两者则获取米级精度。该文档面向HarmonyOS应用开发者，需具备基础的开发配置知识。
