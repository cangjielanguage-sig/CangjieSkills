This directory contains API reference documentation for the `JSHashMapEx` class in the Cangjie programming language. It focuses on declarative interoperability with ArkTS Map types, enabling seamless data mapping between Cangjie and JavaScript environments. The documentation covers class definitions, generic type constraints, initialization, and a comprehensive suite of methods for data manipulation, including insertion, deletion, retrieval, and type conversion. It is suitable for Cangjie developers working on ArkUI applications who need to manage key-value pairs across language boundaries, specifically targeting SystemCapability.ArkUI.ArkUI.Napi.
