# stdxnettls

The `stdxnettls` directory provides a specialized TLS package focused on establishing secure, encrypted network channels for modern applications. It encompasses a wide range of functionalities, from low-level socket management to high-level session configuration, fully supporting TLS 1.2 and 1.3 standards. Central to this package is its reliance on the OpenSSL 3 library, necessitating specific environment setups for optimal performance. The content includes a detailed API index for developers to navigate classes, enums, and error handling structures. This resource is ideal for software engineers and system architects who require a reliable reference for implementing secure communication protocols, managing certificate verification, and ensuring cross-platform compatibility on Linux, Windows, and macOS systems.

### API_列表.md API_列表.md
This document serves as a comprehensive index for the TLS package API, categorizing core components used to establish secure network communication. The content is organized into four main sections: Classes for session management and socket connections, Enums for security modes and algorithms, Structs for configuration and cipher suites, and Exception classes for error handling. Key components include TlsSocket for creating encrypted channels and TlsSessionContext for session resumption, alongside configuration structures for client and server setups. It also details enumerations for signature algorithms, TLS versions, and certificate verification modes. Intended for developers implementing secure protocols, this reference guide requires prerequisite knowledge of TLS concepts and programming interfaces.

### 功能介绍.md 功能介绍.md
This document serves as a setup and feature guide for a TLS package designed for secure encrypted network communication. It covers the package's capabilities, including support for TLS 1.2 and 1.3 protocols, and provides detailed installation instructions for the mandatory OpenSSL 3 dependency across Linux, Windows, and macOS operating systems. Key takeaways include the necessity of specific dynamic libraries like libssl and libcrypto, and the requirement to configure environment variables such as LD_LIBRARY_PATH or PATH to ensure the system linker locates these files. The guide targets developers who need to configure their environment to prevent runtime exceptions and utilize the library's functions like handshakes and session resumption.
