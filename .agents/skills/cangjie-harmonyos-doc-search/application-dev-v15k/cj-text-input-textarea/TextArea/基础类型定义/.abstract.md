This directory provides essential API reference documentation for fundamental type definitions within the Cangjie ArkUI framework. It focuses on the core classes and enumerations required to configure text handling, input validation, and component control mechanisms in user interfaces. The content covers specific configurations for text selection menus, input field constraints, and the programmatic management of TextArea components. By defining these foundational elements, the directory enables developers to fine-tune user interactions with text fields, ensuring a responsive and intuitive user experience. This documentation is specifically designed for Cangjie developers who are building ArkUI interfaces and need to implement robust text editing, cursor manipulation, and input validation features in their applications.
