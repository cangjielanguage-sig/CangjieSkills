# AppStorage应用全局的UI状态存储

This directory provides comprehensive documentation for AppStorage, a global UI state storage mechanism within the ArkUI framework designed for application-level data management. It covers the core concepts of AppStorage as a central hub for bridging PersistentStorage and Environment variables with the UI, distinguishing it from page-level LocalStorage. The content includes theoretical definitions, practical code examples for one-way and two-way data binding using decorators like @StorageProp and @StorageLink, and detailed API documentation. It is specifically tailored for developers using the Cangjie language and ArkUI version 12 or higher to implement robust state management solutions across multiple UIAbility instances.

## Detailed Description

### AppStorage应用全局的UI状态存储_2more.md
This document defines AppStorage, a global UI state storage mechanism designed for application-level data management within the ArkUI framework. It details the concept of AppStorage as a central hub distinct from page-level LocalStorage, explaining its role in bridging PersistentStorage and Environment variables with the UI. Key sections cover system capabilities, version requirements, and usage instructions for singleton creation and state synchronization. Important takeaways include support for state sharing across multiple UIAbility instances and the necessity of @StorageProp or @StorageLink decorators for UI interaction. This reference documentation targets developers using the Cangjie language, noting that it does not support mixed ArkTS scenarios.

### 示例代码.md
This document provides practical code examples for state management in Cangjie application development, specifically focusing on AppStorage decorators. It covers two main sections: the usage of @StorageProp for one-way data binding and @StorageLink for two-way data synchronization. Key takeaways include understanding that @StorageProp requires explicit AppStorage calls for updates, whereas @StorageLink allows direct variable modification that syncs across components. This serves as a reference guide for developers implementing shared state in HarmonyOS UI components.

### class_AppStorage/
This directory contains API documentation for the AppStorage class within the ArkUI framework, specifically designed for Cangjie developers. It focuses on application state management, providing mechanisms for creating, retrieving, updating, and deleting state properties. The documentation covers various static methods for establishing one-way and two-way data bindings, managing property lifecycles, and synchronizing state across components. It is suitable for developers looking to implement robust state management solutions in their applications using the Cangjie language and ArkUI version 12 or higher.
