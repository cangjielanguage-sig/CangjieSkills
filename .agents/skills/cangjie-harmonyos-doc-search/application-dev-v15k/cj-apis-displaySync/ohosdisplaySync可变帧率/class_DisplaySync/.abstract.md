This directory provides comprehensive API reference documentation for the `DisplaySync` class, specifically developed for the Cangjie language within the HarmonyOS ArkUI framework. It is designed to assist developers in managing frame rates and registering callbacks for UI self-drawing content. The documentation details the static `create` method for object instantiation, the `on` and `off` methods for managing subscriptions, and functions for configuring expected frame rate ranges. It also covers starting and stopping per-frame callbacks. This resource is essential for ArkUI developers and graphics engineers who need precise control over rendering cycles and frame synchronization to optimize the performance of graphical applications.
