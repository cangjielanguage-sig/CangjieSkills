This directory provides comprehensive API reference documentation for the `ohos.net.networkSecurity` module within the HarmonyOS NetStack system, specifically tailored for the Cangjie programming language. It covers essential components for network communication security, focusing on certificate handling, data structures, and verification processes. Key topics include certificate encoding formats (PEM, DER), data encapsulation types, and validation against system or custom Certificate Authorities (CA). This resource is designed for Cangjie developers and system engineers who require precise technical specifications to implement secure network protocols and manage certificate data effectively in their applications.
