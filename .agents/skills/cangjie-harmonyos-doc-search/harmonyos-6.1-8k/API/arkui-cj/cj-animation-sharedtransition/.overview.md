# cj-animation-sharedtransition

本目录专门收录了ArkUI框架下Cangjie语言关于`cj-animation-sharedtransition`的API参考文档。该文档的核心目的是指导开发者如何通过`sharedTransition`属性，在应用页面进行路由跳转时，实现丝滑的共享元素转场动效。内容覆盖了从基础的函数定义到高级的参数配置，详细解析了共享ID、动画选项等关键参数的用法。同时，文档还特别指出了特定效果类型（如Exchange）下的行为限制，例如motionPath仅在Exchange模式下生效，以及该模式不支持内容平滑过渡等细节。通过提供的代码示例，开发者可以快速上手。本资源非常适合具备一定ArkUI基础的开发者，用于提升应用的UI交互质量和页面切换的视觉连贯性。

## 详细描述

### cj-animation-sharedtransition.md cj-animation-sharedtransition.md

本文档是ArkUI框架下Cangjie语言的API参考文档，旨在说明如何通过sharedTransition属性实现页面路由跳转时的共享元素转场动效。文档主要内容包括函数定义、参数详解（如共享ID和动画选项）、特定效果类型的行为限制及代码示例。关键信息指出，共享元素需在两个页面拥有相同ID，且Exchange效果类型下motionPath才生效，但该模式不支持内容平滑过渡。文档适用于具备ArkUI基础的开发者，用于构建流畅的页面切换体验。
