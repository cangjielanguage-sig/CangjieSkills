This directory contains API reference documentation for the `PackageInfo` class in the Cangjie programming language. It covers the reflection capabilities used to inspect package metadata, including hierarchy, naming conventions, and public members like variables and functions. The documentation details properties, member functions, operator overloading for equality, and static methods for dynamic library loading. It is suitable for developers working with runtime introspection, reflection APIs, and dynamic module management who need to programmatically access and manipulate package structures and their contents.
