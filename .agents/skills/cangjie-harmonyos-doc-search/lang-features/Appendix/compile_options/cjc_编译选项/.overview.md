## 详细说明

### cjc_用到的环境变量_656a388e.md cjc_用到的环境变量_656a388e.md
本文档说明仓颉编译器环境变量配置，重点介绍 `TMPDIR` (Linux/macOS) 和 `TMP` (Windows) 用于指定临时文件路径，包含默认位置及自定义命令示例，帮助用户管理编译过程中的临时文件。

### cjc_编译选项_746e9efe.md cjc_编译选项_746e9efe.md
本文档介绍 cjc 编译器常用选项及语法规则，涵盖长/短选项定义及参数传递方式（等号或空格），明确了长选项可选参数必须用等号，短选项参数可加空格或紧接，帮助开发人员正确配置参数。

### 优化选项_308dcabb.md 优化选项_308dcabb.md
本指南列出控制代码生成效率的优化参数，涵盖 CHIR 优化（如常量传播、内联）、激进浮点优化及通用优化级别（-O0 至 -Oz）。指出 O2 自动启用 CHIR 优化，Os/Oz 专注缩减体积且禁止与 LTO 混用。

### 其他功能.md 其他功能.md
本文档涵盖高级配置与调试功能，包括报错颜色、链接器透传、实验性增量编译及中间表示（AST、CHIR、LLVM IR）输出。指出增量编译需配合 `--experimental` 使用且有风险，`--dump-to-screen` 可输出调试信息。

### 安全编译选项_4d03fdf4.md 安全编译选项_4d03fdf4.md
本指南指导通过特定选项提升 Release 版本安全性，涵盖路径移除、符号表剥离、运行时路径禁用及 Linux 链接器加固。关键选项包括 `--trimpath`、`--strip-all` 及栈不可执行设置，面向关注生产环境安全的开发者。

### 宏选项_2more_444514d1.md 宏选项_2more_444514d1.md
本文档介绍宏选项及条件编译，包括宏定义、展开代码生成、并行展开及自定义编译条件。关键选项有 `--compile-macro`、`--debug-macro`、`--parallel-macro-expansion` 和 `--cfg`，面向宏开发及条件编译用户。

### 实验性功能选项.md 实验性功能选项.md
本指南介绍实验性功能，重点为 `--enable-eh`（效应处理器），允许通过 `perform` 和 `handle` 实现模块化副作用处理。文档说明了效应机制及风险，指出 API 可能变更，适合需要高级抽象的开发者。

### 并行编译选项.md 并行编译选项.md
本指南介绍并行编译选项以提升效率，包括设置最大并行数的 `--jobs` 和激进策略 `--apc`。指出 `--apc` 可能影响运行性能，且在优化构建、LTO、混淆或针对 Windows/macOS 编译时默认关闭。

### 编译插件选项_dc0dffe0.md 编译插件选项_dc0dffe0.md
本文档介绍 `--plugin` 选项，指出该功能目前为实验特性，仅供内部验证，暂不支持自定义插件，强行使用可能报错，面向内部人员明确选项限制。

### 代码混淆选项/
本目录包含代码混淆功能的参考文档，涵盖字符串、常量混淆及控制流平坦化等技术。介绍通过命令行参数（如 `--fobf-all`）和配置文件（`--obf-config`）控制混淆策略，适用于防止逆向工程。

### 代码覆盖率插桩选项/
本目录包含代码覆盖率插桩选项的技术文档，涵盖插桩级别、PC 守卫等核心选项。重点阐述了需自行实现 C 侧回调函数以适配包初始化机制，适合具备 C/C++ 互操作知识的开发者。

### 单元测试选项/
本目录包含单元测试的配置选项文档，涵盖启用测试框架、单独编译测试文件及使用模拟功能。核心关键词包括 `--test`、`--test-only`、`--mock`，旨在帮助用户配置编译流程以执行单元测试。

### 基本选项/
本目录汇集核心命令行选项参考文档，涵盖模块导入、库链接、输出控制、性能优化及工具链配置。介绍了如何通过参数精细管理依赖、控制编译行为及进行跨平台构建，适用于定制构建流程的开发人员。
