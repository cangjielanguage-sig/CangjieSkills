# 事件上报

This directory provides comprehensive documentation for event reporting within the Performance Analysis Kit, specifically tailored for Cangjie application development. It details the implementation of event tracking, user identification, and property management systems. The content covers both the theoretical API definitions and practical coding steps required to integrate these features into a project. Key concepts include data processors for logic management, user ID interfaces for tracking, and user property interfaces for attribute enrichment. This resource is ideal for Cangjie developers and software engineers aiming to configure analytics, monitor application performance, and manage user context effectively. The documentation includes API references currently in Beta, alongside complete code examples for verification and debugging, ensuring a robust integration process for modern applications requiring detailed behavioral insights and performance metrics.

## Detailed Description

The following documents provide the technical specifications and implementation guides necessary to utilize the event reporting features effectively.

### 事件上报_2more.md 事件上报_2more.md
This document outlines the HiAppEvent interfaces for handling and reporting application events, currently in a Beta phase. It details three specific interface categories: data processors for managing event reporting logic, user ID interfaces for attaching user identifiers, and user property interfaces for setting user attributes. Key functions include addProcessor, removeProcessor, setUserId, and setUserProperty, allowing developers to control data flow and enrich event data with user context. This API reference targets developers integrating the Performance Analysis Kit who need to configure event tracking and user data management.

### 开发步骤.md 开发步骤.md
This tutorial outlines the development steps for implementing event tracking and reporting in a Cangjie application using the PerformanceAnalysisKit. The guide covers five main procedures: adding a data processor with specific configurations, setting and retrieving user IDs, managing user properties, writing event data for tracking, and removing the processor. Key concepts include the Processor class for data handling and HiAppEvent methods for logging user attributes and behavior events. Intended for Cangjie developers, this document provides complete code examples to configure analytics, manage user context, and verify successful event logging through the IDE.
