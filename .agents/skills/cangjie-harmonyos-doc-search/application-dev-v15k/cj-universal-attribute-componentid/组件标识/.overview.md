# 组件标识

This directory provides API reference documentation and code examples for managing component identification and simulating user interactions within the ArkUI framework using the Cangjie language. It covers essential testing utilities such as setting unique identifiers, retrieving component attributes, and automating input events like touch, mouse, and key presses. Designed primarily for developers and QA engineers building automated testing frameworks for HarmonyOS applications, these resources offer the necessary tools to programmatically access UI components and validate application behavior under simulated user inputs.

## Detailed Description

### func_sendKeyEventKeyEvent_2more.md func_sendKeyEventKeyEvent_2more.md
This document serves as API reference documentation for two Cangjie functions designed to simulate user input events specifically for application testing. It covers the sendKeyEvent and sendMouseEvent functions, detailing their syntax, required parameters (KeyEvent and MouseEvent objects), and return values. Key takeaways include that both functions return a Bool indicating success or failure, are available from version 12, and are explicitly marked for testing only due to high performance costs. The target audience is developers working on ArkUI applications who need to automate input testing, though they are advised against using these in production environments.
