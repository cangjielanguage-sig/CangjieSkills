# 基础类型定义

This directory serves as a comprehensive repository for fundamental type definitions within the ArkUI framework, specifically designed for developers using the Cangjie language. It encompasses essential API references that define the structural and visual properties of list components. The content focuses on enabling precise customization of user interface elements, ranging from the styling of divider lines between list items to the configuration of group presentation styles. By providing detailed specifications for classes and enumerations, this directory equips software developers with the necessary tools to create refined and functional UI layouts. It is particularly suitable for engineers looking to manipulate list aesthetics and behavior, ensuring that applications meet specific design requirements and system compatibility standards, such as those introduced in system version 22.

## Quick Navigation

**What do you want to do?**

*   Configure the visual style of list item divider lines (width, color, margins) → class_ListDividerOptions.md
*   Define the card style for list item groups (None or Card) → enum_ListItemGroupStyle.md

## Detailed Description

### class_ListDividerOptions.md

This document provides an API reference for the `ListDividerOptions` class within the ArkUI framework. It is designed to assist Cangjie developers in configuring the visual style of divider lines for `ListItem` components. The reference details the class definition and its constructor, which mandates a line width parameter while treating color and margins as optional. It comprehensively covers four configurable properties, including stroke width, color, and start or end margins. All properties are readable and writable, utilizing types such as `Length` and `ResourceColor`. This documentation is essential for developers who need to customize the separation between list items to achieve a specific user interface design.

### enum_ListItemGroupStyle.md

This document serves as an API reference for the `ListItemGroupStyle` enum in the Cangjie language, intended for software developers using the ArkUI framework. It details the enum used to configure card styles for List components. The documentation specifies the enum's two primary values: `None`, which applies no style, and `Card`, which provides the default card appearance. Additionally, it includes specifications for equality operators (`==` and `!=`) to facilitate the comparison of enum instances. Key information highlights that this feature is available starting from system version 22 and that the enum inherits from `Equatable`. This reference provides the necessary syntax and functional descriptions to effectively implement and manipulate list item grouping styles.
