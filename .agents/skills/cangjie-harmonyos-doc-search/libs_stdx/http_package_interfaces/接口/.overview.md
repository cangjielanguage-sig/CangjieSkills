# 接口

This directory provides comprehensive API reference documentation for the core interfaces within the Cangjie HTTP package. It is designed to assist developers in building robust HTTP servers and clients by detailing essential components such as request routing, request handling logic, protocol service creation, and cookie management. Key topics include the `HttpRequestDistributor` for URL path mapping, `HttpRequestHandler` for processing requests, `ProtocolServiceFactory` for HTTP/1.1 and HTTP/2.0 support, and `CookieJar` for RFC 6265-compliant state management. This resource is suitable for backend developers and software engineers seeking granular control over network communication and security protocols in Cangjie applications.

## Detailed Description

### interface_HttpRequestDistributor.md interface_HttpRequestDistributor.md
This document serves as API reference documentation for the HttpRequestDistributor interface in the Cangjie HTTP package, detailing how to route requests to specific handlers based on URL paths. It covers the interface definition, the distribute function for retrieving handlers, and two overloaded register functions for associating paths with either HttpRequestHandler objects or lambda functions. Key takeaways include that the default implementation is non-thread-safe and requires registration before server startup. The distribute method returns a NotFoundHandler for missing paths, while register throws an HttpException on duplicate paths. Targeted at developers building HTTP servers in Cangjie, this guide requires understanding of HTTP concepts and the HttpContext and HttpRequestHandler interfaces.

### interface_HttpRequestHandl_2more.md interface_HttpRequestHandl_2more.md
This API documentation defines two core interfaces for building HTTP servers in the Cangjie language. It covers HttpRequestHandler for request processing logic and ProtocolServiceFactory for creating protocol-specific service instances. Key information includes that HttpRequestHandler allows users to access request details and construct responses, requiring registration via HttpRequestDistributor and warning against DNS rebinding attacks. Additionally, ProtocolServiceFactory generates services for protocols like HTTP/1.1 and HTTP/2.0 using client sockets. This reference guide targets backend developers implementing custom HTTP server behaviors.

### interface_CookieJar/
This directory contains comprehensive API documentation for the `CookieJar` interface within the Cangjie programming language's HTTP package. It serves as a vital technical reference for managing HTTP cookies, covering a wide range of essential operations such as storage, retrieval, parsing, and lifecycle management. The documentation places a strong emphasis on strict adherence to RFC 6265 standards, detailing complex mechanisms for automatic cookie eviction, domain filtering, and security protocols like public suffix rejection. This resource is specifically designed for software developers and engineers building HTTP client functionality who require granular, programmatic control over cookie persistence, state management, and secure transmission in network applications.
