This directory serves as a comprehensive resource for developers working with the Cangjie programming language to implement secure digital signatures. It focuses specifically on using RSA key pairs with PKCS1 padding mode and SHA256 hashing. The content includes both theoretical workflow guides and practical code implementations using the CryptoArchitectureKit. It addresses essential tasks such as key pair generation, data signing, signature verification, and handling large data volumes through segmented processing. This collection is ideal for Cangjie developers seeking to enhance application security through asymmetric cryptography.
