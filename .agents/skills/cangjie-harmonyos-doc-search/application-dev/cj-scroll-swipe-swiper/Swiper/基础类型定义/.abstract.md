This directory contains API reference documentation for fundamental classes used in the ArkUI framework with the Cangjie language, specifically focusing on Swiper component navigation and control. It covers the definition and styling of indicators (dots and digits) and the controller logic for managing Swiper behavior. Key concepts include `DigitIndicator`, `DotIndicator`, `Indicator`, and `SwiperController`. This documentation is suitable for UI developers and system architects using the Cangjie language to build interactive user interfaces with precise control over carousel navigation and animation.
