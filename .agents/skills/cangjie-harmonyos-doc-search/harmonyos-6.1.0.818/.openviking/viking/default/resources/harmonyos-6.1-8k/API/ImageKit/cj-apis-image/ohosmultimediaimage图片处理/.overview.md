# ohosmultimediaimage图片处理

本目录包含HarmonyOS仓颉语言中多媒体图像处理模块的API参考文档。内容涵盖图像解码、编码、像素操作、属性管理及图像接收等核心功能。文档详细定义了Component、PixelMap、ImageSource等关键类，以及AlphaType、ImageFormat等枚举类型，旨在帮助开发者进行底层图像数据流操作、相机预览处理及图片格式转换。适用于使用仓颉语言进行多媒体应用开发、图像处理及相机功能实现的工程师。

## 详细描述

### class_Component_7b88c29e.md
本文档定义了Cangjie语言中用于描述图像颜色分量的Component类，涵盖byteBuffer、componentType等核心只读属性。文档重点强调在读取相机预览流数据时需严格按rowStride读取以防止花屏，面向底层图像数据流操作人员。

### class_ImageInfo.md
本文档是ImageInfo类的API参考，用于表示图片基本信息。属性包括尺寸、像素密度、格式、透明度等。文档特别指出mimeType反映真实格式，并提醒用户解码与编码支持的格式范围不同，需谨慎使用。

### class_ImagePropertyOpti_5e152821.md
本文档定义了ImagePropertyOptions类，用于指定查询图片属性时的参数配置。包含index和defaultValue两个可读写属性，支持通过索引查询特定图片元数据，适用于需要精确获取属性的场景。

### class_InitializationOptions.md
本文档关于InitializationOptions类，定义PixelMap对象的初始化配置参数。涵盖尺寸、透明度、像素格式等属性，构造函数支持命名参数设置，旨在指导开发者正确配置图像初始化选项。

### class_PositionArea.md
本文档介绍PositionArea类，用于表示图片指定区域内的数据。详细定义了像素数据、偏移量等属性，并指出像素数据仅支持BGRA_8888格式，区域读写范围受原图尺寸限制。

### class_Region_2more_7fdcd152.md
本文档介绍了Region和Size类。Region类通过Size对象和坐标定义区域，Size类指定图像尺寸。两者均支持读写属性，适用于需要精确控制图像区域和尺寸的开发场景。

### class_SourceOptions.md
本文档定义了用于ImageSource初始化的SourceOptions类。包含sourceDensity、sourcePixelFormat等属性，重点阐述了sourceDensity在解码缩放中的计算逻辑，帮助开发者理解像素密度对解码输出的影响。

### enum_AlphaType.md
本文档定义了图像透明度类型的AlphaType枚举，包含Opaque、Premul等成员。文档解释了不透明、预乘Alpha等概念，适用于处理图像透明度属性的场景。

### enum_ComponentType.md
本文档定义了图像组件类型的ComponentType枚举，包含YuvY、YuvU等成员。支持YUV色彩空间与JPEG格式的区分，具备标准比较与字符串转换能力。

### enum_DecodingDynamicRange.md
本文档定义了图像解码时期望的动态范围模式DecodingDynamicRange，包含Auto、Hdr和Sdr成员。用于精确控制图像解码的动态范围输出。

### enum_ImageFormat_9b94482a.md
本文档定义了图片编码格式的ImageFormat枚举，包含Jpeg等成员。提供了处理图片格式逻辑所需的必要定义和接口说明。

### enum_PackingDynamicRange.md
本文档定义了描述图像编码时期望动态范围的PackingDynamicRange枚举，包含Auto和Sdr成员，提供了动态范围处理的具体实现细节。

### enum_ReceiveType_3more_9adbad2b.md
本文档定义了图像接收与缩放相关的枚举类型，包括ReceiveType和ScaleMode，并列出了系统支持的SVG 1.1标签清单，适用于图像接收及SVG渲染场景。

### func_createImageReceiverSize_ImageFormat_Int32.md
本文档说明如何通过指定参数创建ImageReceiver实例。强调实际接收的图片属性由生产者决定，且使用后必须调用release方法释放内存，适用于相机预览流等场景。

### func_createImageS_2more_375f064b
本文档介绍通过URI路径创建ImageSource实例的方法。支持多种图片格式，强调仅支持应用沙箱路径，并提醒使用完毕后必须调用release方法释放内存。

### func_createImageS_2more_9687b33c
本文档说明通过文件描述符创建ImageSource实例的方法。文档特别强调由于图片占用内存较大，开发者必须在实例使用完毕后主动调用release方法以释放资源。

### func_createImageS_2more_a354025f
本文档介绍通过缓冲区创建ImageSource实例的方法。核心要点是输入缓冲区必须是未解码的图像数据，并强调了内存管理的重要性。

### func_createImageSourceR_fcba064b
本文档详细说明了通过RawFileDescriptor创建ImageSource实例的功能与用法。特别强调因内存占用较大，使用完毕后需主动调用release方法释放资源。

### func_createPixelMapArrayUInt8_Initializat_d0bddb75
本文档说明如何通过字节数组和初始化选项创建PixelMap对象。指出该函数默认采用Bgra8888格式，且因占用内存较大，使用完成后必须主动调用release方法释放资源。

### ohosmultimediaima_4more_3896d330
本文档是ohos.multimedia.image模块的API参考概览，涵盖模块导入、使用说明及createImagePacker函数的定义，帮助开发者理解图片打包与处理的核心接口。

### class_DecodingOptions/
本目录包含DecodingOptions类的API参考，用于配置图像解码参数。涵盖图片索引、采样率、旋转角度、像素格式等关键设置，帮助开发者实现灵活的图像处理，如局部解码。

### class_Image/
本目录包含Image类的API参考，涵盖图像定义、属性及方法。文档详细介绍了clipRect、format等只读属性，强调了图像实例的不可变性及内存释放的重要性。
