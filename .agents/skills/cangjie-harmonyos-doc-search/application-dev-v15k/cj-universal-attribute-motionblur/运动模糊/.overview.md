## Detailed Description

### 基础类型定义.md 基础类型定义.md
This API reference document defines basic data structures for implementing motion blur effects within the ArkUI framework using the Cangjie language. It details two primary classes: MotionBlurOptions, which configures blur parameters, and MotionBlurAnchor, which specifies coordinate points. Key information includes that MotionBlurOptions contains a read-only radius (Float64) and an anchor object, while MotionBlurAnchor defines read-only x and y coordinates (Float64) ranging from 0.0 to 1.0. Both classes are available starting from API version 19. This documentation targets developers building UI animations who need to configure motion blur properties, specifically ensuring anchor points align with animation scaling.

### 示例代码属性动画状态下添加运动模糊效果.md 示例代码属性动画状态下添加运动模糊效果.md
This document provides a Cangjie code example demonstrating how to implement a motion blur effect on an image during property animations. The main topics include state management, event handling, animation configuration, and the application of visual effects. Key information involves using `@State` variables to control dimensions and blur parameters, utilizing `.animationStart` with `AnimateParam` to define duration and curves, and applying the `.motionBlur` modifier with `MotionBlurOptions` to anchor the blur effect. This example is intended for developers using the Cangjie language and ArkUI framework who wish to enhance user interfaces with dynamic visual effects during transitions.

### 运动模糊_2more.md 运动模糊_2more.md
This document provides API reference documentation for the motionBlur function in the ArkUI framework, designed to apply dynamic blur effects during component scaling or displacement animations. The content details the function signature, system capabilities, version requirements, and parameter definitions for MotionBlurOptions. Key takeaways emphasize strict usage constraints: the blur radius must be initialized to 0, reset to 0 via AnimateParam.onFinish, and kept below 1. Developers must ensure blur anchors match scale anchors and avoid using this feature in transition or particle animation scenarios. This technical guide targets ArkUI developers using the Cangjie language who require precise control over visual motion effects.
