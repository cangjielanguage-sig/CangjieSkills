This directory provides a comprehensive collection of code examples designed to demonstrate the implementation of diverse visual effects and rendering optimizations within the ArkUI framework using the Cangjie language. It covers a wide spectrum of image manipulation techniques, ranging from basic adjustments like color inversion and opacity to complex transformations such as pixel stretching, spherical distortion, and blend modes. Furthermore, it addresses performance-oriented features including renderGroup, freeze, and shadow batching. These resources are specifically tailored for developers seeking to master advanced UI styling and enhance the visual fidelity and performance of their applications using ArkUI and Cangjie.
