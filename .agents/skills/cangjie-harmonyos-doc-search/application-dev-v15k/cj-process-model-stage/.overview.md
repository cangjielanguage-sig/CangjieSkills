# cj-process-model-stage

This directory serves as a technical resource for understanding the system's process model, focusing on the architectural allocation of application components to distinct processes. It provides an in-depth look at the standard execution model, defining how UIAbilities operate within the main process, how ExtensionAbilities are configured to share processes, and the specific handling of WebViews via independent render processes. The documentation covers specialized configurations for 2in1 devices, detailing the use of the `isolationMode` field to achieve HAP isolation. It also guides system app developers in creating custom multi-process environments using `module.json5`. Furthermore, the content introduces critical Inter-Process Communication (IPC) mechanisms, such as the common event service. This resource is designed for developers and system architects who need to master process isolation, optimize component allocation, and implement secure communication channels.
