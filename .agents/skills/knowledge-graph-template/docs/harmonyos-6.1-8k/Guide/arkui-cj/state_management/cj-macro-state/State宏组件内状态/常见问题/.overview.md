## 详细描述

### 不允许在build里改状态变量_2more_23983eac.md 不允许在build里改状态变量

本文档旨在指导开发者避免在build方法中修改状态变量，并正确管理回调注册以防止内存泄漏。主要内容包括禁止在build中修改状态变量的原因及后果（如死循环导致应用冻结），以及通过回调修改状态变量时必须在aboutToDisappear中解注册以避免内存泄漏的机制。关键点在于build内修改状态变量会触发无限循环渲染，导致应用无响应；注册箭头函数修改状态时，需在组件销毁前解注册，防止因捕获this实例导致的内存泄漏。面向使用ArkUI和仓颉语言的开发者，要求具备状态管理及组件生命周期的基础知识。

### 使用箭头函数改变状态变量未生效_2more_60f5758e.md 使用箭头函数改变状态变量未生效

本文档主要指导开发者解决ArkUI框架下使用Cangjie语言时状态变量更新失效的问题。文档首先分析了箭头函数中this指向的定义时作用域特性，强调需显式传入this.vm以实现状态代理赋值。其次，重点阐述了状态变量仅能触发直接绑定UI组件刷新的机制，并通过示例演示了简单类型的值拷贝特性及对象引用替换对UI渲染的影响。本文适合具备基础Cangjie和ArkUI语法知识的开发者，旨在帮助其深入理解@State、@Publish等装饰器的响应式原理。
