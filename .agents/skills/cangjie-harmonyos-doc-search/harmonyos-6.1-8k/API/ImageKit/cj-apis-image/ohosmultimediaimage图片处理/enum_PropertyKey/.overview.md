# enum_PropertyKey

本目录包含关于图像属性键（PropertyKey）的API参考文档，主要用于定义和操作Exif图像元数据。内容涵盖光圈值、GPS信息、ISO感光度、拍照模式及场景识别等核心属性，详细说明了如何使用`modifyImageProperty`和`getImageProperty`接口进行数据的读写与修改。文档适用于多媒体图像开发人员，特别是使用Cangjie语言进行图像处理应用开发的工程师，提供了从基础属性到高级场景配置的完整参考。

## 详细描述

### FNumber_11more_0123fd4a.md
这是一份图像属性常量的API参考文档，旨在定义和说明图像元数据的标准格式与操作方法。文档涵盖了光圈值、人脸数量、闪光灯状态、焦距及GPS位置信息（如经纬度及其引用）等关键属性。每个条目详细列出了修改传参的格式要求（如非负有理数字符串或特定日期格式）、代码示例及读取结果。核心内容指导开发者如何使用`imageSource.modifyImageProperty`方法精确控制图像属性。该文档适用于多媒体图像开发人员，要求其具备基础的图像元数据处理能力。

### GpsTimestamp_11more_20ccea33.md
这份文档是图像属性常量的API参考手册，旨在规范图像元数据的读写操作。文档涵盖了GPS时间戳、ISO感光度、图像尺寸、光源、设备型号及图片方向等核心属性。每个条目详细说明了功能、修改传参格式（如时间格式或整数字符串）、代码示例及读取结果，特别是Orientation属性提供了详细的数值映射关系。该文档适用于需要使用imageSource.modifyImageProperty接口处理图像元数据的开发人员，属于多媒体图像核心能力的参考文档。

### PhotoMode_18more_95ef5180.md
本文档是多媒体图像核心模块的API参考，详细定义了用于修改和读取图像元数据的各种属性键。内容涵盖拍照模式、物理光圈、像素尺寸、角度信息及多种特定场景（如沙滩、绿植、舞台）的配置参数。文档提供了每个属性的修改格式说明（如非负整数字符串）、modifyImageProperty调用示例及系统能力要求，所有功能起始版本均为22。旨在帮助开发者在图像处理应用中精确控制相机参数和场景识别逻辑。

### SensitivityType_7more_06cb8f2c.md
本文档提供了多媒体图像核心模块中图像属性键及相关操作函数的API参考文档。主要内容包括灵敏度类型、标准输出灵敏度、用户注释、白平衡等属性键的定义，以及用于比较和字符串转换的操作符函数。关键信息包括各属性的修改传参格式（支持数字或字符串）、具体代码示例及读取结果，以及操作符函数的参数与返回值说明。所有功能均属于SystemCapability.Multimedia.Image.Core系统能力，起始版本为22。面向需要通过imageSource接口修改或读取图像元数据的开发者，适用于图像处理应用开发场景。

### enum_PropertyKey_8more_1b36abb3.md
