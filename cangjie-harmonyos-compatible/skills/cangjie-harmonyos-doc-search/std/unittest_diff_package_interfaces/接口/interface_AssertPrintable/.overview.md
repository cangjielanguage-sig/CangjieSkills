# interface_AssertPrintable

This directory contains API documentation for the `AssertPrintable` interface within the Cangjie programming language's testing framework. It covers the core interface definition and its extensions for various data types, including floating-point numbers (Float16, Float32, Float64), Option, and String. These components are essential for formatting and displaying assertion results in unit testing macros like `@Assert` and `@Expect`. The documentation details properties for nested differences and functions for customizing output via `PrettyPrinter`. This resource is suitable for developers implementing custom assertion logic or those needing detailed control over test failure displays in Cangjie.
