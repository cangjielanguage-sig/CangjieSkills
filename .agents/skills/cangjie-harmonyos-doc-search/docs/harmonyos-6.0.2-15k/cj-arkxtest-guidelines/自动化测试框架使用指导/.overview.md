# 自动化测试框架使用指导

This directory provides a comprehensive guide to the HarmonyOS automated testing framework, specifically focusing on the Cangjie language and shell command-based testing. It covers the architecture of the Cangjie Automated Testing Framework, including unit testing and UI testing components, as well as practical troubleshooting for common errors. Additionally, it offers detailed instructions for writing and executing test scripts using DevEco Studio and performing script-free UI automation via shell commands. This resource is suitable for developers and QA engineers looking to implement robust testing workflows for HarmonyOS applications.

## Detailed Description

### 常见问题.md 常见问题.md
This document serves as a troubleshooting guide for resolving common errors encountered during UI test case execution. It details three specific failure scenarios: window retrieval failures, concurrent API call restrictions, and widget existence errors. Key solutions include enabling the ArkUI test mode parameter via specific shell commands, avoiding multi-thread or multi-process calls to UITest APIs, and re-running tests when UI states change unexpectedly. This reference guide is intended for developers and QA engineers debugging UI automation scripts, providing specific error messages, root causes, and remediation steps.

### 概述_2more.md 概述_2more.md
This guide outlines the architecture and functionality of the Cangjie Automated Testing Framework for HarmonyOS. It details the two core components: the Cangjie HarmonyOS Unit Test Framework, built upon std.unittest and adapted via TestRunner, and the UiTest framework for UI component interaction. The document explains implementation principles, illustrating how the unit test framework serves as the base for scheduling and execution, while UiTest provides APIs for UI automation. Key takeaways include the script execution flow, from parameter parsing to XML report generation. This technical guide is intended for developers using the Cangjie language to write and execute automated test scripts on the HarmonyOS platform.

### 基于Cangjie编写和执行测试/
This directory serves as a comprehensive technical resource for developers focusing on the complete lifecycle of testing HarmonyOS applications using the Cangjie language. It encompasses the initial setup of the development environment using DevEco Studio, the creation of both unit and UI automated test scripts, and the execution of these scripts on connected hardware devices. The documentation details specific procedures for writing assertions, utilizing the UiTest framework, and running tests via graphical or command-line interfaces. This guide is essential for HarmonyOS developers and QA engineers seeking to establish a robust automated testing workflow.

### 基于shell命令测试/
This directory provides comprehensive documentation for executing automated UI testing on HarmonyOS/OpenHarmony systems using shell commands via the hdc tool. It covers a wide range of testing functionalities, including screen capturing, layout hierarchy dumping, UI interaction recording, and the simulation of complex user inputs such as touch gestures and hardware key events. Additionally, it includes guides for environment setup, version verification, and daemon management. These resources are specifically designed for developers and QA engineers who require efficient, script-free testing workflows and remote control capabilities for their applications.
