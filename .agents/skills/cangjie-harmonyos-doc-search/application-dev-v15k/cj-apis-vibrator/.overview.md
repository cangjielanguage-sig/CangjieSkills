# cj-apis-vibrator

This directory provides the API reference documentation for the OpenHarmony (OHOS) vibrator module, specifically designed for the Cangjie programming language. It focuses on the implementation of haptic feedback and motor vibration control, covering time-based, preset, and custom file-based vibration effects. The documentation details key components such as classes for vibration attributes, descriptors for custom files, and enums for usage scenarios and stop modes. It also includes functions for starting and stopping vibrations, as well as system capability checks. This resource is essential for Cangjie developers integrating sensor interactions and haptic feedback into their applications, requiring knowledge of file management and system permissions.
