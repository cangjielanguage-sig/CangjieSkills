The `core_package_enums` directory serves as a comprehensive API reference for the fundamental enumeration types that form the backbone of the Cangjie programming language's standard library. It provides detailed documentation for a wide array of core data structures, ranging from low-level system utilities like `AnnotationKind` and `Endian` to high-level functional programming components such as `Option` and `Ordering`. This directory is essential for Cangjie developers who need to understand the precise definitions, valid usage contexts, and interface implementations of these types. Whether you are implementing custom annotations, handling platform-specific byte orders, managing safe null states, or performing type comparisons, this resource offers the necessary specifications to ensure type safety and system reliability. It is the go-to guide for anyone looking to master the core enumerations available in the Cangjie ecosystem.
