# 像素单位

This directory provides comprehensive documentation on pixel units and conversion mechanisms within the Cangjie ArkUI framework. It covers the definitions and practical applications of four primary pixel types: physical pixels (px), virtual pixels (vp), font pixels (fp), and logical pixels (lpx). The content includes detailed API references for utility functions that facilitate conversions between these units, ensuring responsive design across different screen densities. Developers will find guidance on handling screen density ratios and design width configurations. This resource is essential for Cangjie developers and UI engineers aiming to achieve precise layout measurements and consistent visual scaling in cross-platform application development. Understanding these units is critical for creating interfaces that render correctly on devices with varying resolutions and display sizes, making this directory a key reference for mastering layout adaptability in ArkUI.
