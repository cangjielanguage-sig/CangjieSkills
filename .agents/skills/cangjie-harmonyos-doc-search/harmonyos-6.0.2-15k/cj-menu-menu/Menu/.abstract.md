This directory contains comprehensive API reference documentation for the ArkUI Menu component within the HarmonyOS ecosystem, specifically tailored for the Cangjie language. It covers the structural implementation of vertical menus, including sub-components like MenuItem and MenuItemGroup, as well as configuration options for submenu expansion modes and styling attributes. The documentation details binding methods, width calculations, and visual customization such as typography and borders. It is suitable for HarmonyOS developers and UI/UX engineers looking to implement interactive, multi-level menus and refine user interface behaviors in their applications.
