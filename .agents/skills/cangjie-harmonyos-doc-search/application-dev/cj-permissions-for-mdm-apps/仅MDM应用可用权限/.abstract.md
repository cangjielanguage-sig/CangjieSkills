This directory provides comprehensive reference documentation for permissions exclusively available to Mobile Device Management (MDM) and enterprise applications within the OpenHarmony and HarmonyOS environments. It details system-level authorizations required for advanced device administration, including network control, application management, security policies, and system settings modifications. Key topics include system_grant authorization levels, ACL enablement, API version 12 requirements, and specific manual configuration protocols for signing. This resource is essential for system developers and enterprise integrators aiming to implement robust administrative controls and security policies on managed devices.
