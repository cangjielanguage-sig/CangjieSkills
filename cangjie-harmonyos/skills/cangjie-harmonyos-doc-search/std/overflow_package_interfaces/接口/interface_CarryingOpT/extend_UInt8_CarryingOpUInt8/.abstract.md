This directory contains API reference documentation for the Cangjie language, specifically focusing on the `CarryingOp` interface implementation for the `UInt8` type. It covers a comprehensive set of arithmetic and bitwise operations designed with explicit overflow detection capabilities. All functions utilize a wrapping strategy and return tuples containing a Boolean flag indicating overflow or truncation status alongside the resulting value. This documentation is essential for developers engaged in low-level systems programming, cryptography, or any application requiring precise control over numeric operations and error handling. By providing detailed specifications for functions like addition, division, and bit shifting, this resource ensures developers can safely manage edge cases in 8-bit unsigned integer arithmetic.
