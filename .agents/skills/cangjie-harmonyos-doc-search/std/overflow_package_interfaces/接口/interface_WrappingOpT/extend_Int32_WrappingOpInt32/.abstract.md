This directory provides comprehensive API documentation for the `WrappingOp` interface implementation specifically tailored for the `Int32` type within the Cangjie standard library. It details a robust set of arithmetic and bitwise operations—such as addition, multiplication, division, modulo, negation, increment, decrement, and shifting—that utilize a high-bit truncation strategy. This approach ensures that results wrap around upon overflow rather than causing runtime errors. Additionally, it specifies that shift operations rely on the low 5 bits of the shift count when values exceed bit width. This resource is essential for Cangjie developers who need deterministic integer overflow behavior for low-level programming, performance optimization, or algorithmic implementations where wrapping semantics are required.
