This directory contains comprehensive technical documentation for the `func_serve` module, a robust backend component designed to initiate and manage server-side processes for both HTTP/1.1 and HTTP/2 traffic. It provides in-depth specifications on request validation, response generation, connection management, and protocol negotiation via TLS ALPN. Key technical areas include strict RFC 9112 compliance enforcement, header processing rules, stream management, and flow control mechanisms. The documentation is specifically tailored for backend developers and system engineers who are implementing, configuring, or debugging the core HTTP server logic, ensuring high performance and strict adherence to web protocol standards. It serves as a critical reference for maintaining server stability, handling edge cases like 100-continue, and managing resource limits effectively.
