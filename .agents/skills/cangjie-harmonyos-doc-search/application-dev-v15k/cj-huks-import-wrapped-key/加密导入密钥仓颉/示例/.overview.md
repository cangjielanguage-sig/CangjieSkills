# 示例

This directory contains a comprehensive set of code examples demonstrating cryptographic key management and secure data operations within the HarmonyOS ecosystem, specifically utilizing the Universal Keystore (HUKS) framework and Cangjie programming language. It covers essential security workflows including key generation, import, deletion, encryption, and complex key agreement protocols like ECDH. The examples illustrate how to handle byte arrays, configure cryptographic parameters, and manage multi-stage sessions for chunked data processing. These resources are designed for security developers and system integrators looking to implement hardware-backed security features and secure key provisioning in their applications.

## Detailed Description

### 示例_1.md
This document provides a Cangjie code example demonstrating cryptographic key management and data manipulation using the Universal Keystore Kit. It covers the initialization of encryption parameters such as IV, AAD, and various AES keys, alongside utility functions for array slicing and type conversion. Key takeaways include the implementation of helper functions to handle byte arrays, assign data lengths, and manage ECDH key agreement processes. The code illustrates how to structure data buffers for secure operations. Intended for Cangjie developers, this example serves as a practical reference for implementing secure key storage and encryption workflows within their applications.

Keywords: Cangjie, Universal Keystore Kit, Cryptography, AES, ECDH, Key Management, Encryption, Byte Array

### 示例_2.md
This document provides code examples for configuring cryptographic parameters within the HarmonyOS Universal Keystore Service (HUKS) framework. It details the setup of HuksOptions for various security operations, including ECC key generation for unwrapping, ECDH key agreement, and AES key import. Key configurations demonstrate the use of AES-256-GCM for encryption, AES-192-CBC for wrapped keys, and specific algorithm suites for key unwrapping. The snippet serves as a reference for developers implementing secure key management, highlighting how to define tags, algorithms, padding, and modes for complex cryptographic workflows.

### 示例_3.md
This document provides code examples demonstrating how to implement key management and cryptographic operations using the HarmonyOS Universal Keystore (HUKS) SDK. The content covers essential key lifecycle functions including generation, import, deletion, and wrapped key import. It details the implementation of multi-stage cryptographic sessions through Init, Update, and Finish operations, specifically highlighting chunked data processing logic to handle large inputs. Key takeaways include the use of try-catch blocks for error handling and the orchestration of the full cipher workflow. This reference material is intended for HarmonyOS developers seeking to integrate hardware-backed security features into their applications.

### 示例_4.md
This document serves as a code example demonstrating cryptographic operations, specifically key agreement, key import, and encryption using the HUKS framework. The content covers four primary functions: performing key agreement to derive a shared secret, importing KEKs and shared secrets, generating and exporting public keys, and encrypting plain keys and KEKs with tag extraction. Key takeaways include the workflow for session management (init, update, finish), handling HuksOptions, and separating ciphertext from authentication tags during encryption. This reference material targets security developers and system integrators building secure applications on HarmonyOS who require practical implementation details for key lifecycle management and secure data exchange.

### 示例_5.md
This document demonstrates a secure key import protocol between two devices using HUKS, specifically showing how to wrap and serialize key material for encrypted transport. It covers the BuildWrappedDataAndImportWrappedKey function for data serialization and the ImportWrappedKey function simulating the workflow. Key steps include generating wrapping key pairs, performing ECDH key agreement, and encrypting the target key and KEK. The code illustrates a double-layer encryption mechanism where the target key is encrypted by a KEK, and the KEK is encrypted by a shared secret derived from ECDH. It details the byte-level construction of the wrapped data payload including lengths, nonces, and authentication tags. This is a technical tutorial intended for security developers implementing secure key provisioning in HarmonyOS applications, requiring knowledge of cryptography and HUKS APIs.

Keywords: HUKS, key import, ECDH, encryption, serialization, HarmonyOS, key agreement, wrapped key.

### 示例_6.md
This code example demonstrates the final steps of a secure key exchange process, specifically focusing on wrapping, importing, and cleaning up cryptographic keys between two devices. The main topics cover constructing wrapped data containing encryption materials, importing the wrapped AES key on the receiving device, and securely deleting all temporary keys used during the process. Key information includes the usage of `BuildWrappedDataAndImportWrappedKey` to prepare data and `publicImportWrappedKeyFunc` for the import, followed by the deletion of wrapping keys and ECDH parameters to ensure security. This tutorial is designed for developers implementing secure key management protocols, emphasizing the importance of lifecycle cleanup.
