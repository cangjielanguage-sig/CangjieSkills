# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental layout classes within the ArkUI framework, specifically designed for the Cangjie programming language. It focuses on the core data structures required to implement advanced layout constraints, such as barriers and guidelines. Key topics include unique identification mechanisms, directional anchoring logic (vertical vs. horizontal), and precise positioning relative to container edges. These definitions are essential for developers aiming to construct complex, responsive user interfaces with strict alignment and relative positioning requirements. By utilizing these types, developers can ensure robust and flexible UI structures in their Cangjie applications, facilitating the creation of sophisticated and adaptive graphical user interfaces.

### class_BarrierStyle.md class_BarrierStyle.md
This document provides API reference documentation for the Cangjie class BarrierStyle, part of the ArkUI framework. It defines parameters for creating layout barriers, specifically covering the class structure, properties, and initialization method. Key sections detail the id for unique identification, direction to specify anchor behavior using BarrierDirection, and referencedId to list dependent components. Important takeaways include the requirement for unique IDs and the directional logic where vertical barriers act as horizontal anchors. This technical reference targets developers utilizing ArkUI layout systems to implement complex positioning constraints in Cangjie applications.

### class_GuideLinePosition.md class_GuideLinePosition.md
This API reference document defines the GuideLinePosition class used to specify positioning parameters for guidelines within the ArkUI framework. The documentation details the class structure, specifically focusing on the start and end properties and the class constructor. Key information includes that both properties are optional Length types representing distances from container edges; start measures from the left or top, while end measures from the right or bottom. The constructor initializes these values with a default of None. This reference is intended for Cangjie developers building UI layouts using ArkUI who need precise control over guideline placement.

### class_GuideLineStyle.md class_GuideLineStyle.md
This document serves as API reference documentation for the Cangjie class GuideLineStyle, which defines parameters for creating layout guidelines in the ArkUI framework. The content covers the class structure, specifically detailing the properties id, direction, and position, alongside the constructor initialization. Key information includes the requirement for unique IDs, axis-specific anchoring behavior where vertical guidelines serve horizontal anchors, and positioning rules such as the default start: 0 value and restrictions when using "auto" sized containers. This technical reference targets ArkUI developers utilizing Cangjie to implement precise relative container layouts and alignment strategies.
