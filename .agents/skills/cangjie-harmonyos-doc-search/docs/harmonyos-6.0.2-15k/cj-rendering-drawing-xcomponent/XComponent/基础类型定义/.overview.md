# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental Cangjie classes utilized within the ArkUI framework, specifically focusing on the management of XComponent components. It covers essential type definitions including display area specifications, rotation configuration options, and component controllers. These classes enable developers to handle Surface rendering, enforce layout constraints, and manage orientation behaviors effectively. The documentation is tailored for ArkUI developers and system integrators who need to integrate native graphics, camera functionalities, or complex UI layouts requiring precise control over component surfaces and their interaction with system interfaces.

## Detailed Description

### class_SurfaceRect.md
This API reference document defines the Cangjie class `SurfaceRect`, which specifies the display area of a Surface held by an XComponent. The documentation details the class structure, four public properties (`offsetX`, `offsetY`, `surfaceWidth`, `surfaceHeight`), and the initialization constructor. Key information includes that coordinates are relative to the XComponent's top-left corner, dimensions default to the component size if unset, and values must not exceed 8192px to avoid rendering errors. This guide is intended for ArkUI developers managing Surface rendering and layout in Cangjie applications.

### class_SurfaceRotationOptions.md
This API documentation defines the Cangjie class `SurfaceRotationOptions`, which configures orientation locking behavior for an XComponent's Surface during screen rotation. The document details the class structure, specifically the public `lock` property and the `init` constructor. Key information includes that the `lock` property is a read-write Boolean with a default value of `false`, meaning the orientation is not locked by default. The class requires the `SystemCapability.ArkUI.ArkUI.Full` capability and is available starting from version 19. This reference guide targets developers using the ArkUI framework who need to manage UI component behavior during device orientation changes.

### class_XComponentController.md
This document provides API reference documentation for the `XComponentController` class in Cangjie, designed to manage and control XComponent components within the ArkUI framework. It details the class constructor and methods for manipulating Surface properties, including retrieving Surface IDs for system interfaces, and getting or setting display areas and rotation behaviors. Key information includes specific validity constraints, where certain methods only apply to `SURFACE` or `TEXTURE` type components, and notes on rotation locking behavior during screen orientation changes. This guide targets application developers using Cangjie and ArkUI who need to integrate native graphics or camera functionalities.
