# class_Support

This directory contains API references and constant definitions for the `Support` class within the Cangjie programming language framework. It primarily focuses on system-level common events, providing static constant strings for various hardware and software state changes. Key topics include user lifecycle management, Wi-Fi connectivity (including P2P and scanning), storage volume management, and system notifications. These resources are essential for developers building system-level applications that need to subscribe to, broadcast, or react to real-time system events. All constants require the `SystemCapability.Notification.CommonEvent` capability starting from API version 22.

## Detailed Description

### static_const_COMMON_EVENT_10more.md
This document serves as an API reference defining static constant strings for system common events in the Cangjie programming language. It covers events related to user lifecycle management, such as user updates, removal, switching, unlocking, and storage volume removal. Key takeaways include specific string values for events like COMMON_EVENT_USER_INFO_UPDATED and COMMON_EVENT_USER_SWITCHED, noting that several user lifecycle events are currently reserved and unsupported. All constants require the SystemCapability.Notification.CommonEvent capability starting from version 22. This reference is intended for developers building system-level applications that need to listen for or broadcast notifications regarding user state changes and hardware storage status.

### static_const_COMMON_EVENT__8more.md
This API reference document defines eight static constant strings representing Wi-Fi and Wi-Fi P2P system common events for the Cangjie language. The content covers events related to P2P connection states, device states, group information, peer discovery, and general Wi-Fi power states or signal strength (RSSI). Key information includes the specific string values for each event, descriptions of their triggers, and defined state codes for power and P2P status transitions. All constants utilize the SystemCapability.Notification.CommonEvent capability and are available starting from version 22. This documentation is intended for developers building applications that require real-time monitoring of Wi-Fi hardware status and connectivity changes.

This document serves as API reference documentation defining static constant strings for system common events in the Cangjie programming language. Key information includes the specific string values for each event, their functional descriptions, and system capability requirements, with specific state values provided for the Wi-Fi hotspot event. The target audience is system developers using the Cangjie framework who need to subscribe to or handle system-level hardware notifications.
