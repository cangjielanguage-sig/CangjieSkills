# interface_ColorManagement

本目录包含仓颉开发环境中相机色彩管理的API参考文档。主要涉及设置色彩空间（如P3广色域、HDR模式）、获取当前激活的色彩空间以及相关的配置处理。文档详细介绍了`setColorSpace`和`getActiveColorSpace`等核心接口，包括参数映射、异常处理及代码示例。适用于使用CameraKit进行多媒体开发的工程师，旨在帮助开发者实现SDR及HDR高动态范围成像功能。
