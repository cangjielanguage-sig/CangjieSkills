This directory provides API reference documentation for the `ohos.app.ability.ui_ability` module in the Cangjie programming language, part of the HarmonyOS AbilityKit framework. It covers core classes like `Ability`, `Context`, and `UIAbility`, focusing on lifecycle management, resource access, and system configuration. A significant portion addresses interoperability between Cangjie and ArkTS, specifically converting JSValue types to Context objects. This content is intended for HarmonyOS developers and system engineers using Cangjie to build applications with user interfaces, manage application lifecycles, and implement cross-language component communication.
