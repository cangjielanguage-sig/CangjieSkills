## Detailed Description

### 加密导入密钥仓颉_2more.md
This technical guide details the procedure for securely importing ECDH keys into the HUKS framework using an encrypted import mechanism in the Cangjie language. It covers prerequisites, supported algorithms, and a detailed 10-step development workflow involving key generation, key agreement, encryption, and material packaging. The process requires two devices: Device A prepares and encrypts the target key using a KEK and a shared secret derived via key agreement, while Device B generates a wrapping key to receive and import the encrypted material. Temporary keys must be deleted after the process. This guide targets developers implementing secure key management in HarmonyOS applications who need to understand HUKS key material formats and cryptographic protocols.
