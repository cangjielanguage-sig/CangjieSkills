This directory provides comprehensive documentation on the event dispatch mechanisms within the ArkUI framework. It covers the fundamental concepts of event handling, including the classification of touch and mouse events, and details the critical Touch Test process used to determine event response chains. Key topics include the algorithms for collecting response chains, traversal orders, and how component properties like `hitTestBehavior` influence event propagation. This resource is designed for ArkUI developers and UI engineers who need to understand the underlying logic of user interactions, customize gesture recognition, or manage component response behaviors effectively.
