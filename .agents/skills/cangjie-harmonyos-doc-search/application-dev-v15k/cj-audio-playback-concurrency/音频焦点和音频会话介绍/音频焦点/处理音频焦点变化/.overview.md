# 处理音频焦点变化

This directory provides technical guidance on managing audio focus changes within applications. It covers the system's audio focus strategy, automatic system actions (pausing, ducking), and the `InterruptEvent` notification mechanism. Key topics include handling forced versus shared interruptions, maintaining state consistency, and implementing callbacks for various audio components like AVPlayer and AudioRenderer. This resource is suitable for application developers and software engineers working on audio playback or recording features who need to ensure a seamless user experience during audio interruptions.

It details the `InterruptEvent` interface, focusing on two critical parameters: `InterruptForceType` and `InterruptHint`. The document explains the difference between system-enforced forced interruptions and shared interruptions, as well as specific hints like resume, pause, stop, and ducking. By handling these events correctly, developers ensure their applications maintain state consistency and provide a seamless audio experience.
