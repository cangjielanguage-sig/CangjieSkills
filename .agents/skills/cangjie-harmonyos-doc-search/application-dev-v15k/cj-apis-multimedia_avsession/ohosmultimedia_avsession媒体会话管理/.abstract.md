This directory contains comprehensive API reference documentation for the HarmonyOS AVSession (Audio-Video Session) framework, specifically designed for the Cangjie programming language. It covers the management of media sessions, including playback control, metadata handling, audio-video casting, and device management. Key components include classes for session controllers, playback states, media descriptions, and enumerations for command types and connection states. This resource is suitable for software developers and engineers building multimedia applications who need to integrate system-level media controls, handle casting features, and manage audio-video interactions within the HarmonyOS ecosystem.
