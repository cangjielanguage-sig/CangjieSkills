This directory serves as a comprehensive technical resource for the `@Link` macro within the Cangjie ArkUI development framework. It is specifically curated to address the challenges of state synchronization by enabling robust two-way data binding between parent and child components. The content explores technical rules, variable type constraints, and synchronization mechanisms, with a particular emphasis on managing complex data structures such as classes and arrays. By leveraging key concepts like `@Observed`, `@Publish`, and `ObservedArrayList`, this guide provides the necessary tools for creating reactive user interfaces. It is ideally suited for developers who possess a working knowledge of state management decorators like `@State` and are seeking to deepen their expertise in component interaction and advanced state management patterns.
