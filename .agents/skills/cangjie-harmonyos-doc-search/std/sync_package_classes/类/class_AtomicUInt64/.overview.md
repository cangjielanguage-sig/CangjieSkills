# class_AtomicUInt64

This directory contains API reference documentation for the `AtomicUInt64` class in the Cangjie programming language. It focuses on providing thread-safe, low-level synchronization primitives for the `UInt64` data type. The documentation covers essential atomic operations including Compare-And-Swap (CAS), arithmetic (add, subtract), bitwise manipulations (AND, OR, XOR), and memory access methods (load, store, swap). It highlights the deprecation of functions requiring explicit `MemoryOrder` parameters in favor of simplified overloads. This resource is suitable for systems programmers and developers building concurrent or multi-threaded applications who require precise control over data consistency and atomic variable manipulation.
