This directory provides comprehensive API reference documentation for the `ohos.data_share_predicates` module within the Cangjie language ecosystem. It is dedicated to defining predicates that filter data during DataShare database operations, including querying, updating, and deleting records. The content covers module imports, usage instructions for standard and Context-dependent configurations, and the `DataSharePredicates` class for constructing complex query conditions. Supporting both RDB and KVDB databases, it details methods for logical operations, sorting, and limiting results. This documentation is intended for Cangjie developers building data-driven applications who require effective management of distributed data queries and possess a solid understanding of database concepts.
