This directory provides API reference documentation for the `QualifiedType` class in the Cangjie programming language's Abstract Syntax Tree (AST). It details the representation of user-defined member types, such as `T.a`, covering class definitions, inheritance from `TypeNode`, and initialization methods. Key topics include mutable properties for base types, identifiers, dot tokens, and generic type arguments, including specific handling for angle brackets and comma separators. The documentation also addresses serialization, traversal via the Visitor pattern, and `ASTException` error handling. This resource is designed for compiler developers and language tool implementers who need to parse and manipulate qualified type nodes programmatically.
