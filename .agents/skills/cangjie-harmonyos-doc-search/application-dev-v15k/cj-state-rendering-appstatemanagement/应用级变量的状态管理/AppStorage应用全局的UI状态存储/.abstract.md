This directory provides comprehensive documentation for AppStorage, the global UI state storage mechanism designed for the ArkUI framework and Cangjie programming language. It details the implementation of a singleton storage system created at application startup, which facilitates central state management accessible across the entire app, distinguishing it from page-level LocalStorage. The content covers the integration of AppStorage with PersistentStorage and Environment variables, highlighting its role in state sharing between multiple UIAbility instances. It also explains the necessity of using @StorageProp and @StorageLink decorators for UI synchronization. This resource is essential for HarmonyOS developers and software engineers aiming to master application-level state management, data persistence, and reactive programming in Cangjie-based projects, particularly for version 12 and above.
