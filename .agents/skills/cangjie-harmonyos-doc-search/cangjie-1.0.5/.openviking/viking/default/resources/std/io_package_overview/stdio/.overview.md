# stdio

The `stdio` directory provides essential documentation for the standard input/output library within the Cangjie programming language ecosystem. It focuses on stream-based interfaces that facilitate data exchange between programs and external devices, such as files and networks. The content covers fundamental I/O concepts, stream manipulation, and data handling mechanisms. Key topics include buffered operations, sequential reading, and encoding conversion. This documentation is designed for Cangjie developers who need to implement robust data channels, manage buffers, and handle errors effectively in their applications.

## Detailed Description

### API_列表.md API_列表.md
This document serves as a comprehensive API index for an I/O package, detailing the core components available for stream manipulation and data handling. It categorizes the library into Functions, Interfaces, Classes, Enums, and Exceptions. Key functionalities include stream copying, buffered I/O operations, sequential reading via chained streams, and simultaneous writing to multiple outputs. The documentation also covers string encoding conversion and cursor seeking capabilities. Designed for developers, this reference guide provides quick access to definitions for implementing robust input/output operations, error handling, and buffer management within the application framework.

### 功能介绍.md 功能介绍.md
This document serves as an introductory overview of the io package in the Cangjie programming language, explaining its role in facilitating data exchange between programs and external devices. It covers the definition of I/O operations, the concept of stream-based interfaces, and the distinction between input and output streams. Key takeaways include the definition of streams as data channels for ordered data, where input streams read from sources like files or networks, and output streams write to them. Intended for Cangjie developers, this foundational text provides the necessary context for understanding the library's architecture before implementing specific I/O tasks.
