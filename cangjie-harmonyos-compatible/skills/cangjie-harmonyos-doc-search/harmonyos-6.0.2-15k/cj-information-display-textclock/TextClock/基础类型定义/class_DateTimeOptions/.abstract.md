This directory provides comprehensive API reference documentation for the `DateTimeOptions` class, designed for the Cangjie language and ArkUI framework. It covers the essential configuration settings required for formatting date and time displays in applications. Key topics include localization settings, component formatting styles (such as year, month, and hour), and numbering systems. The documentation is intended for developers building internationalized applications who need precise control over how temporal data is presented to users across different locales and regions.
