# 密钥对材料格式

This directory serves as a technical reference for defining the precise memory layout and byte structure of cryptographic key pair materials. It encompasses detailed specifications for a wide range of algorithms, including RSA, ECC, DSA, DH, and Curve25519. The content explains how to map essential variables—such as algorithm identifiers, key sizes, and component lengths—into standardized byte arrays. It is specifically tailored for software developers and system architects who are implementing low-level cryptographic storage, transmission protocols, or manual key import processes. The documents provide both theoretical structural definitions and practical code examples to ensure accurate implementation and system compatibility.

## Detailed Description

### 密钥对材料格式_1.md
This technical reference defines the memory layout and byte structure for key pair materials, specifically using RSA as an illustrative example. It explains that key material consists of a header and the original data, detailing how to map variables like algorithm ID, key size, and component lengths into a byte array. The document provides a Cangjie code snippet demonstrating the construction of an RSA-2048 key pair, explicitly showing the hex values for the header fields (algorithm, size, lengths) and the key components (modulus n, exponent e, exponent d). This guide is intended for developers who need to manually format and import cryptographic key materials into the system.

### 密钥对材料格式_2.md
This technical reference document defines the binary data structure and byte layout for cryptographic key pair materials across multiple algorithms. It details specific formats for RSA, ECC, DSA, DH, and Curve25519, outlining the sequence of algorithm identifiers, key sizes, length fields, and actual key values. Key takeaways include the consistent use of 4-byte fields for metadata followed by variable-length byte arrays for components like moduli, exponents, and coordinates. This specification is intended for software developers and system architects implementing low-level cryptographic storage or transmission protocols.
