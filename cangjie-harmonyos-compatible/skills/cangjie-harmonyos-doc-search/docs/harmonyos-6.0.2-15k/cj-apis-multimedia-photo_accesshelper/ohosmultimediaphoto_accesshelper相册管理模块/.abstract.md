This module provides comprehensive API reference documentation for the PhotoAccessHelper system capability in HarmonyOS, specifically designed for the Cangjie programming language. It covers the management of photo albums, media asset access, modification, and selection. Key functionalities include querying photos and videos, handling change notifications, configuring selection options, and managing metadata. The documentation is intended for developers building media-centric applications who need to interact with the system media library, requiring knowledge of Cangjie syntax, file management APIs, and system permissions like READ_IMAGEVIDEO.
