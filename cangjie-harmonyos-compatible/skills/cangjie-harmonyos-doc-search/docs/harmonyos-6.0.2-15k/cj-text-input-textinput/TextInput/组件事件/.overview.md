# 组件事件

This directory provides comprehensive API reference documentation for component events within the ArkUI framework, specifically tailored for the Cangjie language. It focuses on the intricate event handling mechanisms required for text input components. The documentation covers a wide array of callbacks, including text content changes, scrolling behavior, clipboard operations (copy, cut, paste), and the interception of text insertion or deletion actions. Key topics include parameter definitions for tracking cursor positions, scroll offsets, and edit states, as well as specific system constraints like input method limitations. This resource is essential for developers aiming to implement robust, interactive text components with fine-grained control over user input and system interactions.

## Detailed Description

### func_onChangeString_-_Unit_7more.md

This document serves as API reference documentation for text input event handling functions in the Cangjie language within the ArkUI framework. It covers a series of callback functions including onChange, onContentScroll, onCopy, onCut, onDidDelete, onDidInsert, and onEditChange. Key information includes parameter definitions for tracking text content, scroll offsets, and edit states. Developers should note specific constraints, such as the requirement to adjust cursor logic in preview scenarios for onChange and the limitation of onDidDelete and onDidInsert to system input method scenarios. This guide is intended for developers implementing interactive text components.

### func_onPasteString_-_Unit_7more.md

This document serves as an API reference for Cangjie language functions handling text input events within the ArkUI framework. It details event callbacks for pasting, password visibility changes, submission, text selection, and interception of text insertion or deletion. Key functions include onPaste, onSubmit, onWillInsert, and onWillDelete, which allow developers to control or monitor user input behavior. Notably, interception functions return Boolean values to permit or block specific actions. This reference is intended for software developers using the ArkUI framework to implement interactive text input components, providing system capabilities, version requirements, and parameter definitions for each callback.
