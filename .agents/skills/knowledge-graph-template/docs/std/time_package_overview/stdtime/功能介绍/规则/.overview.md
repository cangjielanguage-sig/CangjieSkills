# 规则

This directory contains technical specifications and reference guides focused on the rules governing date and time formatting. It covers parsing logic, pattern letter counts, and specific era notation standards. The documents define how input string lengths and character quantities directly influence output formatting for components such as AM/PM markers, years, months, timezones, and chronological eras. This collection is essential for software developers, engineers, and system integrators who are implementing or configuring date/time logic within applications, ensuring precise localization and data representation.

### 纪年.md 纪年.md
This document serves as a technical reference specification defining the parsing logic and output format for the "Anno Domini" (AD) era notation based on input string length. The content is presented in a table format that maps three specific input lengths—1, 2, and 3 characters—to their corresponding parsed values and final outputs. Specifically, it details that a single character input results in "A", two characters result in "AD", and three characters result in the full phrase "Anno Domini". This information is crucial for developers or system integrators working on date formatting libraries, localization modules, or calendar systems that require flexible handling of era abbreviations.
