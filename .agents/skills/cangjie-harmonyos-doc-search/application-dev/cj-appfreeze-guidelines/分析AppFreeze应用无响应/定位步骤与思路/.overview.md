# 定位步骤与思路

This directory provides a comprehensive technical guide for diagnosing and troubleshooting application unresponsiveness (appfreeze) issues within the OpenHarmony/HarmonyOS ecosystem. It covers the end-to-end workflow, from initial log collection using DevEco Studio or shell commands to advanced analysis of Binder IPC, EventHandler queues, and stack traces. Key topics include HiviewDFX fault detection logic, Hilog integration, and Trace analysis. These resources are designed for software developers, system engineers, and performance maintainers seeking to identify root causes of system freezes, thread blocking, and lifecycle timeouts.

## Detailed Description

### 定位步骤与思路_2more.md 定位步骤与思路_2more.md
This technical guide outlines the methodology for diagnosing application unresponsiveness issues by collecting and analyzing system logs. It covers the general troubleshooting workflow and details three specific methods for retrieving fault logs managed by the FaultLog module. Key information includes instructions for obtaining logs via DevEco Studio, the hiAppEvent subscription interface, or directly via shell commands in ROOT mode, including specific file paths and naming conventions. The document is intended for software developers debugging application performance issues, specifically those using DevEco Studio and HarmonyOS/OpenHarmony tools like hilog and trace.

### 查看_binder_信息.md 查看_binder_信息.md
This technical guide instructs developers on analyzing Binder information to diagnose application freeze (appfreeze) issues. It details how to interpret Binder call chains, identify IPC_FULL states where thread IDs are zero, and analyze wait times to determine if an IPC call is the root cause. The document explains scenarios like buffer exhaustion, lock contention, and transient stacks, noting that data capture may have latency depending on the fault type. It serves as a troubleshooting reference for system engineers investigating performance bottlenecks and IPC communication failures.

### 确认基本信息.md 确认基本信息.md
This technical guide explains how to extract and interpret basic information from OpenHarmony app freeze logs generated by HiviewDFX. It covers identifying process details like PID and foreground status, determining fault timestamps, and referencing a table of detection durations for various fault types such as THREAD_BLOCK and LIFECYCLE_TIMEOUT. Key takeaways include the specific detection logic where foreground apps report immediately after 6 seconds, whereas background apps require five cumulative 3-second blocks, and instructions for calculating the exact fault start time. Intended for developers debugging application stability issues, this document provides essential context for analyzing system-level freeze reports.

### 结合_hilog_2more.md 结合_hilog_2more.md
This technical guide outlines methods for analyzing application freezes (appfreeze) by integrating Hilog logs and Trace data. It details DFX-related logging mechanisms, including fault reporting, stack traces, and background detection. The document provides a step-by-step analysis workflow: correlating fault timestamps with Hilog output to identify freeze points, distinguishing between silent hangs and excessive logging scenarios. Additionally, it explains using Trace to diagnose performance bottlenecks caused by dense main thread execution or specific function timeouts. Targeted at developers and system maintainers, this guide aids in diagnosing root causes of application unresponsiveness.

### 查看_eventHandler_信息/
This directory contains technical documentation for analyzing event handler logs to diagnose system performance issues like application freezes and scheduling bottlenecks. It covers interpreting dump logs, understanding VIP and High priority event queues, and identifying root causes of watchdog failures. Key topics include event queue structures, task duration calculations, and thread scheduling analysis. These guides are intended for system developers and engineers troubleshooting responsiveness issues in event-driven systems.

### 查看_stack_信息/
This directory contains technical guides and debugging logs focused on analyzing stack traces to diagnose application issues in OpenHarmony/OHOS environments. It covers scenarios such as application freezes (appfreeze), IPC deadlocks, SQLite database anomalies, and resource loading failures. The documents provide methodologies for using Process ID (Pid) and Thread ID (Tid) to identify bottlenecks like lock contention or synchronous blocking calls. Suitable for system developers, debuggers, and performance engineers troubleshooting native code, database operations, and IPC interactions.
