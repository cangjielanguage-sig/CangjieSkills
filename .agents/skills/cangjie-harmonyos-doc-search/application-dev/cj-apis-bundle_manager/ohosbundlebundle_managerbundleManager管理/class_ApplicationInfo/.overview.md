# class_ApplicationInfo

This directory contains API reference documentation for the `ApplicationInfo` class within the Cangjie programming language's BundleManager framework. It encapsulates comprehensive configuration data for applications, covering identity, resources, installation paths, permissions, and system flags. The documentation details read-only properties used to query application status, access control tokens, and metadata. It is suitable for Cangjie developers who need to programmatically retrieve application configuration, distinguish between app types (APP vs. ATOMIC_SERVICE), and manage system integration using the `getBundleInfoForSelf` method.

## Detailed Description

### class_ApplicationInfo_9more.md class_ApplicationInfo_9more.md
This API reference document defines the ApplicationInfo class in Cangjie, which encapsulates comprehensive configuration data for an application. It details a wide array of read-only properties categorized by function, including identity (accessTokenId, uid), resources (icon, label), installation paths, permissions, and specific flags like cloudFileSyncEnabled and dataUnclearable. Key information includes the ability for third-party apps to retrieve this data via getBundleInfoForSelf and support for distinguishing between app types (APP vs. ATOMIC_SERVICE) and provisioning types (debug vs. release). Intended for developers using the BundleManager framework, this document provides the necessary attributes to query application status, access control tokens, and metadata within the system environment.

### let_systemApp_2more.md let_systemApp_2more.md
This document serves as API reference documentation for two read-only properties in the Cangjie programming language related to application identification. It covers the systemApp property, which checks if an application is a system app, and the uid property, which retrieves the application's unique identifier. Both properties are defined with their types, read-only access, system capabilities, and starting version 22. Key takeaways include that systemApp returns a Boolean value, while uid returns an Int32. Both are read-only and belong to the BundleManager framework core capability. This reference is intended for developers using the Cangjie language who need to query application metadata or permissions within the system bundle framework.
