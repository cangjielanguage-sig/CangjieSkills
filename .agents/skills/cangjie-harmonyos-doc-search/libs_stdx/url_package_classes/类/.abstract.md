This directory contains API reference documentation for core classes within the Cangjie programming language's `stdx.encoding.url` package. It focuses on the structural representation and manipulation of URL components and HTTP form data. Key topics include URL parsing, component access (scheme, host, path), handling user credentials, and managing key-value pairs for form submissions. The documentation emphasizes adherence to RFC 3986 standards and covers percent-encoding logic. This resource is suitable for Cangjie developers who need to programmatically handle network resources, process HTTP requests, or manipulate URL strings securely and efficiently.
