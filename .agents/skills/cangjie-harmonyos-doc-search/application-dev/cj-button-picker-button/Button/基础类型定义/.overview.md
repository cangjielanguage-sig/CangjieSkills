# 基础类型定义

This directory provides essential API reference documentation for fundamental UI component types within the ArkUI framework, specifically tailored for the Cangjie programming language. It comprehensively covers the structural and functional definitions required to implement and customize buttons in user interfaces. Key topics include configuration classes for button appearance and enumerations defining button shapes, roles, and style modes. This documentation is intended for Cangjie developers and system architects working on version 22 system capabilities who need precise control over button behavior and visual presentation.

## Detailed Description

### class_ButtonOptions.md class_ButtonOptions.md
This API reference document details the ButtonOptions class used to configure the display style of buttons within the ArkUI framework. It covers the class definition, five configurable properties including shape, state effect, style mode, control size, and role, alongside the class constructor. Key information includes that all properties are optional and readable/writable, with the constructor accepting named parameters that have specific default values like ButtonType.Capsule and true for state effects. Intended for Cangjie developers, this guide assists in customizing button appearance and behavior for version 22 system capabilities. Keywords: ButtonOptions, Cangjie, ArkUI, ButtonStyleMode, ControlSize, ButtonRole, API reference.

### enum_ButtonRole_2more.md enum_ButtonRole_2more.md
This document serves as API reference documentation for the Cangjie language within the ArkUI framework, specifically defining two enumerations: ButtonRole and ButtonStyleMode. The main sections detail the enum definitions, their specific values (Normal, Error, Emphasized, Textual), and overloaded equality operators. Key information includes that ButtonRole categorizes buttons by function (standard vs. warning), while ButtonStyleMode defines visual importance (general, highlighted, or text-only). Both types inherit from Equatable to support comparisons. This technical reference is intended for developers building user interfaces, providing the necessary syntax and functional descriptions to implement button behaviors and styles correctly.

### enum_ButtonType.md enum_ButtonType.md
This API reference document defines the ButtonType enumeration used to specify the shape of buttons within the ArkUI framework in the Cangjie language. It details specific enum values including Normal, Capsule, Circle, and RoundedRectangle, along with their geometric properties, and documents the equality and inequality operator functions for comparing instances. Key information includes that the enum inherits from Equatable and is available starting from system version 22, with each member representing a distinct visual style ranging from default squares to fully circular buttons. This documentation targets UI developers using Cangjie to design graphical interfaces, requiring knowledge of basic enumeration usage and ArkUI components.
