This directory provides API reference documentation for common scrollable components within the ArkUI framework using the Cangjie language. It covers configuration classes for edge effects, fading visuals, nested scrolling, and drag events, as well as the specific properties and events applicable to List, Grid, Scroll, and WaterFlow components. The documentation provides detailed parameters for customizing scroll physics, visual clipping, and interaction behaviors. It is intended for HarmonyOS developers and UI engineers seeking granular control over scrolling mechanics and user interactions to build responsive application interfaces.
