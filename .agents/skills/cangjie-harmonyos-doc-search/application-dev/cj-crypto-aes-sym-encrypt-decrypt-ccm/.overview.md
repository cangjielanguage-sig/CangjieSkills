# cj-crypto-aes-sym-encrypt-decrypt-ccm

This directory is a comprehensive technical guide dedicated to the implementation of AES symmetric encryption and decryption using the CCM (Counter with CBC-MAC) mode, specifically tailored for the Cangjie programming language. It offers a deep dive into the CryptoArchitectureKit API, covering the full spectrum of the cryptographic workflow. Users will find detailed instructions on key generation, cipher creation, and the execution of data processing through update and doFinal methods. The content rigorously addresses the management of critical cryptographic parameters, including Initialization Vectors (IV), Additional Authenticated Data (AAD), and the 12-byte authentication tag (authTag). Furthermore, it highlights essential operational constraints, such as the prohibition of segmented operations, which are crucial for maintaining the integrity and security of the encryption process. This resource is ideally suited for software developers and security engineers working in a Beta environment who require a robust understanding of both the theoretical underpinnings and practical implementation strategies for cryptographic security features. By following this guide, developers can effectively integrate authenticated encryption into their applications, ensuring data confidentiality and integrity.
