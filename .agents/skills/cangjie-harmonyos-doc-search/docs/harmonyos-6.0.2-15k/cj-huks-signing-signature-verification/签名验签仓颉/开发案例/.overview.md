# 开发案例

This directory contains Cangjie code examples for cryptographic operations using the Universal Keystore Kit (HUKS). It covers digital signing and verification using various algorithms like ECC, RSA, and SM2. Key topics include key generation, lifecycle management, and specific parameter configurations for different hashing and padding modes (SHA-256, PKCS1_V1_5, PSS, SM3). These examples are suitable for Cangjie developers working on HarmonyOS who need to integrate secure, hardware-backed cryptographic features and national cryptographic standards into their applications.

## Detailed Description

### ECC256SHA256.md ECC256SHA256.md
This document provides a Cangjie code example demonstrating how to implement digital signing and verification using the ECC 256-bit algorithm with SHA-256 hashing via the Universal Keystore Kit. The code covers the complete cryptographic workflow, including key generation, signing, verification, and key deletion. It details how to configure specific Huks parameters for each operation, such as algorithm type, key size, purpose, and digest method. Additionally, it includes helper functions for data type conversion and a test function to orchestrate the process. This tutorial is intended for developers using the Cangjie language who need to integrate secure cryptographic operations into their applications.

### RSASHA256PKCS1_V1_5.md RSASHA256PKCS1_V1_5.md
This document provides a Cangjie code example demonstrating RSA digital signature generation and verification using SHA256 digest and PKCS1_V1_5 padding via the Universal Keystore Kit. Key topics include key generation, signing, verification, and deletion. It details property configuration functions for setting algorithm parameters and helper functions for data type conversion. The code illustrates the complete lifecycle of a cryptographic operation, utilizing a 2048-bit RSA key. It highlights specific HUKS parameter configurations for algorithm, padding, and digest modes required for secure signing. Targeted at Cangjie developers implementing security features on HarmonyOS, this tutorial requires basic understanding of cryptographic concepts and the HUKS API.

### RSASHA256PSS.md RSASHA256PSS.md
This document provides a Cangjie code example demonstrating how to perform digital signing and verification using the RSA algorithm with SHA256 digest and PSS padding mode within a Universal Keystore environment. It covers key generation with specific cryptographic parameters, the signing process using session-based operations, the verification process involving session updates, and key deletion. Key takeaways include the configuration of HuksParam objects for RSA 2048-bit keys, the use of HUKS_PADDING_PSS and HUKS_DIGEST_SHA256, and the specific API calls like initSession, finishSession, and updateSession required for secure cryptographic operations. This technical guide targets developers implementing security features in Cangjie who need to integrate hardware-backed key storage and cryptographic signatures into their applications.

### SM2SM3.md SM2SM3.md
This document provides a Cangjie code example demonstrating the implementation of SM2 key generation and SM3 digital signature operations using the UniversalKeystoreKit. It covers defining cryptographic properties, generating SM2 keys, signing plaintext data, verifying signatures, and managing key lifecycle through deletion. Key takeaways include the specific configuration of HuksParam for SM2/SM3, the session-based approach for signing and verification, and the complete workflow encapsulated in the testSignVerify function. Intended for developers working with the HarmonyOS Universal Keystore Service (HUKS) who need to integrate Chinese national cryptographic standards into their applications.
