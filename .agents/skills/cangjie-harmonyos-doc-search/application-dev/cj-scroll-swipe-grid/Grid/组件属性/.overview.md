# 组件属性

This directory contains comprehensive API reference documentation for configuring component properties within the Cangjie ArkUI framework, with a specific focus on the Grid component. It covers essential aspects of layout management, including performance optimization through item caching and the structural definition of rows and columns. Key topics include `cachedCount`, `columnsGap`, `rowsGap`, `columnsTemplate`, and `rowsTemplate`. These resources are designed for developers and UI engineers who require precise control over grid rendering, responsive layout geometry, and resource management to build efficient and dynamic application interfaces. The documentation provides technical details on function signatures, parameter definitions, and layout behaviors.
