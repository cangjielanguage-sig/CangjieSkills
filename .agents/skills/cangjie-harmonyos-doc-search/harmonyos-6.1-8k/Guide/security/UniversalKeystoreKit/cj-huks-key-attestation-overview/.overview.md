# cj-huks-key-attestation-overview

本目录提供了关于OpenHarmony HUKS（通用密钥库系统）密钥证明功能的全面概述文档。它深入探讨了密钥证明的核心概念、基于PKI证书链的验证机制，以及匿名与非匿名证明模式的差异。文档详细列出了支持的算法规格（包括RSA、ECC、SM2等），并涵盖了密钥属主信息格式、密钥来源校验OID以及API 15+的具体支持情况。此外，还说明了模拟器环境下的相关限制。该资料主要面向应用开发者，旨在指导开发者如何通过证书链验证密钥的合法性与硬件来源，非常适合涉及高安全级别密钥管理与设备身份认证的应用场景。
