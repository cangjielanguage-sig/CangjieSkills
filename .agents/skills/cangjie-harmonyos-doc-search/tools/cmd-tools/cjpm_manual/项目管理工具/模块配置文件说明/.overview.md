# 模块配置文件说明

本目录详细介绍了仓颉编程语言包管理工具（cjpm）的配置文件 `cjpm.toml` 的各项功能与语法。内容涵盖模块版本定义、依赖管理（源码、Git、测试依赖）、工作空间配置、环境变量动态替换、命令剖面（profile）设置以及跨平台编译选项。旨在帮助开发者掌握构建参数配置、依赖解析及编译流程控制，适用于所有使用仓颉进行项目构建和管理的开发人员。

## 详细描述

### cjc-version_10more_9651e794.md cjc-version_10more_9651e794.md

### dependencies.md dependencies.md
本文档说明 dependencies 字段的配置方法，涵盖本地路径和远程 git 依赖设置。解释了 git 依赖的优先级规则、锁文件机制、身份验证方式及如何强制指定编译产物类型。

### package-configuration.md package-configuration.md
本文档说明 package-configuration 字段的用途，涵盖 output-type、compile-option 及 combine-all-deps 三个核心选项。重点介绍了配置优先级合并逻辑及开启 LTO 优化的条件。

### test-dependencies_4more_8bc0ff90.md test-dependencies_4more_8bc0ff90.md
本文档说明 cjpm.toml 中特定依赖管理字段，涵盖 test-dependencies、script-dependencies、replace 及 ffi.c。关键点包括测试依赖范围、间接依赖替换及 C 库链接配置。

### workspace_c6a99e70.md workspace_c6a99e70.md
本文档说明 workspace 字段的配置方法，用于统一管理多模块。涵盖成员路径定义、筛选规则及公共选项设置，指出公共配置自动生效且不可与 package 字段共存。

### 模块配置文件说明.md 模块配置文件说明.md

### 环境变量配置_d5a97c94.md 环境变量配置_d5a97c94.md
本文档介绍如何在 cjpm.toml 中使用环境变量动态替换配置值。涵盖支持该功能的字段列表及 `${变量名}` 语法，旨在提供配置灵活性。

### profile/
本目录包含 profile 配置项文档，用于控制构建、测试等命令的默认行为。内容涵盖编译优化、测试执行策略及环境变量管理。

### target/
本目录包含 target 字段配置文档，涵盖不同后端和平台的隔离编译选项、配置合并规则及宏包交叉编译策略。
