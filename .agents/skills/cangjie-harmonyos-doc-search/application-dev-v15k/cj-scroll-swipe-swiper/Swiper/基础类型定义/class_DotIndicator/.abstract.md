This directory provides a complete set of API reference materials for the `DotIndicator` class, utilized within the Cangjie language and the HarmonyOS ArkUI development environment. The primary focus of these documents is to guide developers in the implementation and fine-tuning of dot-style navigation indicators for Swiper components. The documentation encompasses a variety of configuration aspects, ranging from basic visual properties like color and size to advanced features such as masking and interaction scaling. It highlights critical default values, such as the 6vp dimension and the 1.33x press scaling factor, as well as the `maxDisplayCount` function for managing content overflow. This resource is indispensable for HarmonyOS developers and UI professionals who are building sophisticated user interfaces and require detailed knowledge of component behavior and styling constraints, particularly for API version 19 and later.
