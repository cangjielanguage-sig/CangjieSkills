This directory provides essential API reference documentation for the `PickerDialogButtonStyle` class, a key component in the Cangjie programming language for styling picker dialog buttons. It is designed to assist developers in defining the visual aesthetics and interactive behaviors of confirmation buttons within user interfaces. The documentation covers detailed constructor parameters, such as button type, style mode, role, font attributes, background color, and border radius. It also explains how to configure default interaction behaviors, such as the Enter key response. This resource is ideal for UI and ArkUI developers who possess knowledge of Cangjie syntax and are looking to implement custom styling for dialog components in their applications.
