# cj-apis-net-connection

This directory serves as a specialized repository for API reference documentation concerning the `ohos.net.connection` module within the HarmonyOS operating system, specifically written for the Cangjie (仓颉) programming language. It is dedicated to the intricacies of network connection management, offering developers detailed insights into retrieving network connection properties, querying network capabilities, and executing DNS resolution. Furthermore, the documentation addresses HTTP proxy configuration and the monitoring of network state changes. By defining core classes such as `NetHandle`, `NetConnection`, and `NetCapabilities`, this resource aims to empower developers to implement robust network status monitoring, address resolution, and specific network binding. It is an essential guide for developers utilizing Cangjie for HarmonyOS application development who need to navigate and manage complex network connection scenarios efficiently.

## Detailed Description

### ohosnetconnection网络连接管理/
This directory provides the Cangjie language API reference documentation for the `ohos.net.connection` module within the HarmonyOS system, focusing specifically on network connection management. The documentation encompasses a wide range of functionalities, including the retrieval of network connection properties, querying network capabilities, performing DNS resolution, configuring HTTP proxies, and listening for network state changes. Central to this module are core classes such as `NetHandle`, `NetConnection`, and `NetCapabilities`. These classes are instrumental for developers aiming to implement network status monitoring, resolve addresses, and bind applications to specific networks. The content is tailored for developers using the Cangjie language to create HarmonyOS applications, offering the necessary guidance to handle complex network connection scenarios and ensure robust connectivity management.
