This directory provides a comprehensive technical guide on using the `@Observed` and `@Publish` macros within the Cangjie and ArkUI frameworks to manage state for nested class objects and arrays. It addresses the complexities of observing deep property changes, overcoming limitations of simpler state management methods. The content covers macro specifications, behavioral mechanisms, common troubleshooting issues, and strict usage constraints. It is designed for Cangjie developers who are building reactive UI applications and need to implement robust two-way data binding and state synchronization for complex data models.
