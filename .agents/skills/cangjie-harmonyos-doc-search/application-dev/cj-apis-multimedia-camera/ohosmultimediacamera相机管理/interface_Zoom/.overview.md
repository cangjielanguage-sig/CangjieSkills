# interface_Zoom

This directory contains comprehensive API reference documentation for the Zoom interface within the Cangjie CameraKit framework. It focuses on the technical implementation of camera zoom controls, specifically detailing how to manage smooth transitions and set precise zoom ratios using Float64 values. The documentation covers essential methods such as `setSmoothZoom`, `setZoomRatio`, and `getZoomRatio`, while also addressing system capabilities, version requirements, and potential exceptions like "Session not config." Designed for Cangjie developers, these resources provide the necessary code examples and parameter definitions to effectively integrate advanced zoom functionalities into multimedia applications.

### func_setSmoothZoomFloat64_2more.md func_setSmoothZoomFloat64_2more.md
This API reference document details two Cangjie functions for controlling camera zoom behavior using Float64 values. It covers setSmoothZoom for triggering smooth zoom transitions and setZoomRatio for setting specific zoom ratios with precision constraints. Key information includes that setZoomRatio supports a precision limit of two decimal places and may require a short delay to take effect, while setSmoothZoom initiates a transition. The documentation provides parameter definitions, system capabilities, version requirements, potential exceptions like "Session not config," and practical code examples. This resource is intended for Cangjie developers working with the CameraKit to implement zoom functionality in multimedia applications.
