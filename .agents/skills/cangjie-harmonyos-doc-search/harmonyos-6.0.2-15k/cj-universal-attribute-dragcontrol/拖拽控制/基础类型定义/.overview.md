# 基础类型定义

This directory provides essential API reference documentation for fundamental data structures used in drag-and-drop interactions within the ArkUI framework, specifically for the Cangjie language. It details the configuration classes and enumerations necessary for defining visual behaviors, such as scaling animations, multi-selection gathering effects, and drag preview appearances including shadows and rounded corners. These definitions are critical for developers seeking to customize the user experience of drag operations in Grid and List components. The documentation targets developers familiar with Cangjie syntax and UI component structures who need fine-grained control over interaction logic.

## Detailed Description

### class_DragInteractionOptions.md class_DragInteractionOptions.md

This document provides API reference documentation for the Cangjie class `DragInteractionOptions`, which configures visual effects and behaviors during drag-and-drop interactions in the ArkUI framework. It covers the class constructor and two key properties: `isMultiSelectionEnabled`, which enables multi-selection gathering effects for Grid and List items, and `defaultAnimationBeforeLifting`, which toggles the default scaling animation before lifting. Key information includes that both properties are read-only Booleans defaulting to false, with specific constraints on multi-selection regarding child components, preview image priority, and context menu incompatibility. This guide targets developers using ArkUI who need to customize drag interactions, requiring familiarity with Cangjie syntax and UI component structures.

### enum_DragPreviewMode.md enum_DragPreviewMode.md

This document serves as API reference documentation for the `DragPreviewMode` enum in the Cangjie language, defining configuration options for controlling drag-and-drop visual behaviors in ArkUI applications. The content details the enum definition and provides specific descriptions for its four member values: `AUTO`, `DISABLE_SCALE`, `ENABLE_DEFAULT_SHADOW`, and `ENABLE_DEFAULT_RADIUS`. Key takeaways include that `AUTO` allows system-managed scaling and positioning, while other flags explicitly disable scaling or enable default visual effects like shadows and rounded corners (default 12vp) for non-text components during drag operations. This reference is intended for developers using the Cangjie language to build UIs, specifically those implementing custom drag-and-drop interactions who need fine-grained control over the drag preview's appearance.
