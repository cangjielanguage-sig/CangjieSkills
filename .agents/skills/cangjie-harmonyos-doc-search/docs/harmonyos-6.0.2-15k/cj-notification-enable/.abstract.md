This directory provides a comprehensive development guide focused on the implementation of user notification authorization within Cangjie applications. It covers the complete workflow required to interact with the NotificationKit framework, specifically detailing how to check current notification statuses and request necessary permissions from users. Key technical elements include the `isNotificationEnabled` and `requestEnableNotification` interfaces, proper management of `UIAbilityContext`, and the handling of specific error codes such as 1600004, which signifies a user's refusal to grant permissions. This resource is specifically tailored for Cangjie developers seeking to build compliant, user-friendly applications that respect privacy settings while ensuring critical notification features function correctly. The guide emphasizes best practices for triggering permission dialogs only when strictly necessary, thereby optimizing the user experience and adhering to platform compliance standards. By following this guide, developers can ensure their applications handle notification permissions robustly, avoiding common pitfalls related to user rejection and context management.
