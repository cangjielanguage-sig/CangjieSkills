# class_Indicator

This directory provides comprehensive API reference documentation for the Cangjie Indicator class within the ArkUI framework. It is designed to assist developers in configuring the positioning, style, and layout behavior of navigation dots used within Swiper components. The documentation covers essential topics such as static factory methods for creating DigitIndicator and DotIndicator objects, instance methods for precise placement (including bottom, end, left, and right), and handling layout behaviors like RTL/LTR support and property priority rules. This resource is specifically suitable for ArkUI developers using the Cangjie language who require detailed customization of Swiper navigation indicators for cross-platform user interfaces.

### func_startLength_2more.md func_startLength_2more.md
This document serves as API reference documentation for configuring the position of navigation dots within the Swiper component in the Cangjie ArkUI framework. It details two specific functions: start and top. Both functions accept a Length parameter and return the current object instance for method chaining. The start function sets the horizontal offset relative to the left or right edge depending on LTR or RTL modes. The top function defines the vertical position, taking precedence over the bottom attribute and defaulting to the bottom if unset. Both functions require version 19 system capabilities. This is intended for UI developers building cross-platform interfaces using Cangjie who need precise control over Swiper indicator placement.
