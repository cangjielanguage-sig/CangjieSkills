This directory contains API reference documentation for the `MessageSequence` class within the Cangjie IPC Kit, designed for HarmonyOS inter-process communication (IPC). It covers data serialization and deserialization, enabling developers to manage message formatting, file descriptors, and memory capacity. The documentation details methods for reading and writing primitive types, arrays, strings, and Parcelable objects. It is suitable for Cangjie developers implementing RPC or IPC scenarios who require precise control over data transmission and system resource management.
