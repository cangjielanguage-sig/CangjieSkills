# cj-atm-tool

The `cj-atm-tool` directory functions as a centralized repository for the Access Token Manager (ATM) tool documentation, a specialized utility designed to facilitate the querying of application process permissions and the management of access control information within the operating system. This resource is indispensable for understanding the complex mechanisms of system security, providing detailed insights into environment setup via the hdc shell, and the utilization of specific commands such as `help` and `dump`. It covers critical procedures for inspecting access control data using various identifiers, including token IDs, package names, and process names. Furthermore, it guides users through retrieving system application processes, verifying current permission states, and conducting audits of historical permission usage. This documentation is primarily suitable for software developers and system administrators who require robust tools for debugging applications, enforcing strict security compliance, and maintaining comprehensive oversight of the operating system's permission management framework.

Additionally, it includes detailed guides on retrieving system application processes, checking current permission states, and auditing historical permission usage records.
