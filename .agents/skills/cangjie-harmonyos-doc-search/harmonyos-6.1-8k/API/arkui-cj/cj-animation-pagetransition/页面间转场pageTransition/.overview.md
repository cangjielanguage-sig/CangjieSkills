## 详细说明

### class_CommonTransition.md class_CommonTransition.md
本文档是ArkUI框架中CommonTransition类的API参考文档，旨在定义页面转场的通用动效。文档详细介绍了该抽象密封类的四个核心方法：slide用于设置滑入滑出效果，translate用于设置三维平移，scale用于设置缩放及中心点，opacity用于控制透明度。关键信息包括各方法的参数类型、默认值及取值范围，且所有方法均返回This以支持链式调用。该文档面向使用仓颉语言进行HarmonyOS应用开发的开发者，帮助他们实现丰富的页面切换动画。

### class_PageTransit_2more_585e0563.md class_PageTransit_2more_585e0563.md
本文档是ArkUI框架下Cangjie语言的API参考文档，主要介绍了用于定义页面自定义转场动画的PageTransitionEnter和PageTransitionExit类。文档详细说明了这两个类的构造函数，支持配置路由类型、动画时长、曲线和延迟等参数，并提供了onEnter和onExit回调方法，用于处理从0到1的转场进度逐帧动画。这两个类均继承自CommonTransition，适用于需要精细控制页面入场和退场视觉效果的开发场景。目标受众为熟悉Cangjie语言和ArkUI开发的开发者，旨在帮助他们实现丰富的页面交互体验。

### enum_RouteType.md enum_RouteType.md
本文档是Cangjie语言中RouteType枚举的API参考文档，旨在定义和管理页面转场类型。文档主要涵盖了None、Push和Pop三个枚举值，详细说明了它们在页面跳转或回退时如何影响PageTransitionEnter和PageTransitionExit组件的转场效果。此外，还提供了用于比较枚举值的相等与不相等运算符。该枚举继承自Equatable，适用于ArkUI框架，起始版本为22。本文档面向使用ArkUI进行应用开发的开发者，帮助其实现精细化的页面路由转场控制。

### enum_SlideEffect_2more_f3d1e54f.md enum_SlideEffect_2more_f3d1e54f.md
本文档提供了ArkUI框架中Cangjie语言的API参考，主要定义了页面转场时的滑入滑出效果枚举及转场事件回调类型。主要内容包括SlideEffect枚举（包含Left、Right、Top、Bottom四个方向选项）及其相等性比较操作符，以及PageTransitionCallback类型定义。SlideEffect用于指定页面入场或出场的滑动方向；PageTransitionCallback用于监听转场进度（0到1）和路由类型。所有接口均系统能力为ArkUI.Full，起始版本为22。面向使用Cangjie语言进行ArkUI应用开发的开发者，适用于需要实现自定义页面转场动画的场景。
