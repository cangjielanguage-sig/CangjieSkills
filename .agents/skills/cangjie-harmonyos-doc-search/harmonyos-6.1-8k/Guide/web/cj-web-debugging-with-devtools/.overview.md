# cj-web-debugging-with-devtools

This directory serves as a comprehensive technical guide for developers aiming to debug Web front-end pages running on HarmonyOS devices using the DevTools suite. It bridges the gap between PC development environments and mobile hardware, offering detailed insights into cross-device debugging capabilities and specific version compatibility requirements. The content covers essential technical workflows, including code configuration, operational procedures, and the utilization of `hdc` commands for effective port forwarding. Furthermore, it provides automation scripts designed to streamline the setup process and summarizes troubleshooting methods for resolving common connectivity issues. This material is highly suitable for front-end developers working with mobile Web components and HarmonyOS application developers who need efficient debugging strategies involving Cangjie and Web technologies.

## Detailed Description

### 使用DevTools工具调试前端页面/
This subdirectory is dedicated to the practical application of DevTools for debugging front-end pages on HarmonyOS devices directly from a computer. It begins by defining DevTools within the context of the HarmonyOS ecosystem and outlines its powerful cross-device debugging capabilities. The documentation specifies the device version compatibility requirements necessary to ensure a stable debugging session, which is critical for developers working with varying device generations.

Inside, developers will find specific code configurations and detailed, step-by-step operational instructions to establish the connection between the development environment and the target device. To enhance efficiency, the directory provides automation scripts that simplify the often complex process of port forwarding using `hdc` commands, saving valuable development time. Finally, it acts as a reference guide by summarizing common connection problems and offering effective troubleshooting methods. This section is essential reading for front-end developers targeting mobile Web components and HarmonyOS developers utilizing Cangjie, ensuring they can diagnose and resolve issues quickly.
