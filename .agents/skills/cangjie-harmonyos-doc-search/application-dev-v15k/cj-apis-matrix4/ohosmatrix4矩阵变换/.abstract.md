This directory contains comprehensive API documentation and code examples for the `ohos.matrix4` module within the HarmonyOS ArkUI framework, specifically designed for the Cangjie programming language. It covers essential 2D and 3D graphical transformations, including matrix operations, rotation, scaling, translation, and polygon mapping. The resources detail classes like `Matrix4`, `Point`, and various transformation options, alongside practical implementation guides. This documentation is suitable for software developers and UI engineers working on HarmonyOS applications who need to implement complex visual effects, geometric manipulations, and dynamic interface animations using Cangjie.
