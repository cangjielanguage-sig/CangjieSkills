# cj-want-overview

This directory serves as a comprehensive technical resource for understanding the Want object within the Cangjie development framework. It focuses on the essential mechanism of passing information between application components, which is a cornerstone of modular application architecture. The content thoroughly covers the definitions, distinctions, and practical usage scenarios of Explicit and Implicit Wants. Key technical topics include intra-app launches utilizing specific parameters like bundleName and abilityName, as well as the complex system matching logic for implicit requests involving actions and URIs. This documentation is specifically designed for application developers using the Cangjie language who require a deep understanding of component interaction, startup mechanisms, and how to effectively handle system-level requests without knowing specific targets.
