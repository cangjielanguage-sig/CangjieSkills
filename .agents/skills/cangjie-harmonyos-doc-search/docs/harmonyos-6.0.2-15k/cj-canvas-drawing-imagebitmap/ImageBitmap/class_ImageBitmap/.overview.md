# class_ImageBitmap

This directory contains technical documentation for the `ImageBitmap` class within the Cangjie language, specifically tailored for the ArkUI framework. It serves as a comprehensive guide for developers working with canvas-rendered pixel data, detailing the necessary APIs for image creation, manipulation, and resource management. Key topics include various constructors for initializing objects from local image paths or PixelMaps, handling dimension specifications, and managing supported formats like JPG, PNG, and BMP. This documentation is essential for application developers and system engineers building HarmonyOS applications who require robust solutions for image processing, rendering operations, and efficient graphics memory handling.

## Detailed Description

### class_ImageBitmap_6more.md class_ImageBitmap_6more.md
This document serves as an API reference for the ImageBitmap class in the Cangjie language, used for storing canvas-rendered pixel data within the ArkUI framework. It details multiple constructors for initializing objects from local image sources or PixelMaps, including options to specify dimensions using Float64 or Int64. Additionally, it documents read-only properties for retrieving the image's width and height in virtual pixels. Key information includes support for formats like JPG and PNG and specific path resolution rules for different module types. This guide is intended for developers working with ArkUI system capabilities to handle image processing and rendering tasks.
