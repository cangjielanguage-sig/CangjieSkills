This directory provides comprehensive guides for HarmonyOS developers on how to subscribe to system environment variable changes using the Cangjie language and AbilityKit. It covers dynamic adaptation to settings like language, screen orientation, and memory levels. The content details implementation methods across different components, including ApplicationContext, AbilityStage, UIAbility, and ExtensionAbility. By utilizing callbacks such as `onConfigurationUpdate` and `EnvironmentCallback`, developers can ensure their applications respond intelligently to runtime configuration updates without restarting. These resources are essential for application developers seeking to enhance user experience through intelligent UI adaptation and resource management.
