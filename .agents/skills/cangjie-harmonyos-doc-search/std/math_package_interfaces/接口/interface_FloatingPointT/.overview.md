# interface_FloatingPointT

This directory contains API documentation for the FloatingPoint interface and its specific implementations for various floating-point types (Float16, Float32, Float64) within the Cangjie programming language. It covers the core interface definition, inheritance hierarchy, and extensions that provide access to essential mathematical constants (like Pi and E), special values (infinity, NaN), and numerical limits (minimum normal and denormal numbers). Additionally, it details utility methods for checking the state of floating-point instances. This documentation is suitable for Cangjie developers who need to perform precise numerical computations, understand floating-point behavior, or implement custom floating-point types adhering to the standard interface.
