This directory provides a comprehensive guide to data backup and restoration strategies within the ArkData framework. It focuses on ensuring data integrity, business continuity, and transaction safety during system failures or critical operations. The content covers essential techniques such as manual and automatic backup methods for relational databases, data restoration procedures, and specific implementation scenarios for Key-Value (KV) databases. It is designed for application developers using the Cangjie language who need to implement robust data protection mechanisms, manage database exceptions, and handle storage lifecycle effectively.
