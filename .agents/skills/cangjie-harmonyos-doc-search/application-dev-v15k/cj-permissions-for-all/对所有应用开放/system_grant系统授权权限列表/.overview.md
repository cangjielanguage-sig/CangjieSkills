# system_grant系统授权权限列表

This directory serves as a comprehensive repository for technical documentation regarding system_grant permissions within the HarmonyOS development ecosystem. It focuses on the specifications required for applications to request and utilize system-level authorizations that are granted automatically by the system. The content covers a wide array of capabilities, ranging from audio modification and background running locks to critical hardware access like Bluetooth, network configuration, and biometric authentication. By detailing protection levels, ACL enablement status, and mandatory authorization methods, these documents provide essential guidance for application developers. The primary goal is to assist developers in correctly declaring permissions in their configuration files to ensure secure and compliant access to device features and system resources.
