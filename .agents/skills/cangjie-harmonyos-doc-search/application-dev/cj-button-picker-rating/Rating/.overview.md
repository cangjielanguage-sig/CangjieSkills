This document serves as API reference documentation for configuring properties of a Rating component within the ArkUI framework using the Cangjie language. Key takeaways include default values (5 stars, 0.5 step), validation logic where non-positive values revert to defaults, and specific constraints on image loading (asynchronous only, support for local and network URIs but not PixelMap). The target audience is UI developers seeking to implement and customize interactive rating controls.
