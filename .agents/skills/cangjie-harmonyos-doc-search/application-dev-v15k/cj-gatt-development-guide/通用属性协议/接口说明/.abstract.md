This directory provides essential documentation for the Cangjie Bluetooth BLE GATT interfaces, serving as a central resource for developers implementing wireless connectivity features. It encompasses a high-level overview for quick navigation and a detailed API reference for deep technical implementation. The content covers critical aspects such as connection management, service discovery, characteristic and descriptor read/write operations, MTU size negotiation, and the handling of asynchronous events through callbacks. These documents are intended for software developers utilizing the Cangjie programming language who need precise, structured access to GATT specifications to build efficient Bluetooth Low Energy applications. The documentation directs users to the ConnectivityKit reference for complete code examples.
