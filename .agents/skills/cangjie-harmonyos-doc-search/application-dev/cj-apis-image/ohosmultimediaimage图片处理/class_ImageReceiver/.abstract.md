This directory contains comprehensive API reference documentation for the Cangjie `ImageReceiver` class, a critical component within the ImageKit framework designed to receive images from external producers such as cameras. It covers the full lifecycle of image reception, including defining receiver properties, managing surface IDs, registering event callbacks, and handling image reading operations. Key topics include memory management, buffer lifecycles, error handling, and system capabilities. This documentation is suitable for developers implementing multimedia image handling in Cangjie who need to manage surface interactions, process asynchronous image data, and ensure efficient resource allocation and deallocation.
