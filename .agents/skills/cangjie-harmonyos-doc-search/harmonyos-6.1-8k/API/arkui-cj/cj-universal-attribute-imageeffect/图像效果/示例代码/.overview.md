### 示例1设置图片不同属性效果.md 示例1设置图片不同属性效果.md
本文档是一个代码示例，旨在演示如何使用仓颉语言在ArkUI框架中为图片和文本组件设置多种视觉效果。文档涵盖了模糊、背景模糊、阴影、灰度、亮度、饱和度、对比度、图像反转、叠色、深褐色及色相旋转等主要属性。通过具体的代码实现，展示了不同参数值（如灰度0~1、亮度大于1变亮）对视觉呈现的具体影响。该文档适用于使用仓颉语言进行HarmonyOS应用开发的开发者，可作为UI样式美化和图像处理的实践参考。

### 示例2设置图片不同变化效果/
本目录包含关于在 ArkUI 框架中使用仓颉语言实现高级图像和视觉特效的代码示例。内容涵盖前景智能取反色、边缘像素扩展、混合模式、球面效果、离屏渲染、系统导航条反色、阴影批处理及线性渐变模糊等多种技术。这些示例展示了如何配置 `invert`、`pixelStretchEffect` 和 `freeze` 等属性，以优化 UI 渲染和视觉表现。适用于希望掌握高级 UI 渲染技巧和特效处理的 ArkUI 开发者及测试人员。
