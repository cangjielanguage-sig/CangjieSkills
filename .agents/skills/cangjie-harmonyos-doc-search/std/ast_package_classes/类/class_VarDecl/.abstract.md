This directory contains comprehensive technical documentation for the `VarDecl` class and associated traversal utilities within the Cangjie programming language's Abstract Syntax Tree (AST) framework. It focuses on the structural representation of variable declarations, detailing how to access, modify, and construct AST nodes programmatically. Additionally, it covers the visitor pattern implementation for navigating syntax trees effectively. Key concepts include node properties, token conversion, exception handling, and tree traversal logic. This resource is designed for compiler developers, language engineers, and software engineers building tools that require deep analysis or transformation of Cangjie code structures.
