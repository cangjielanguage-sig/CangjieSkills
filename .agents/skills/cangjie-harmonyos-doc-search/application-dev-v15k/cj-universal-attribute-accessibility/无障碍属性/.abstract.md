This directory provides comprehensive API reference documentation for implementing accessibility features within the ArkUI framework using the Cangjie language. It covers essential properties and functions designed to optimize applications for users with disabilities, particularly those relying on screen readers and assistive technologies. Key topics include setting component descriptions, managing accessibility levels, grouping components, and configuring virtual nodes for custom UIs. This documentation is suitable for Cangjie and ArkUI developers aiming to ensure their applications are inclusive, compliant with accessibility standards, and provide a seamless experience for all users.
