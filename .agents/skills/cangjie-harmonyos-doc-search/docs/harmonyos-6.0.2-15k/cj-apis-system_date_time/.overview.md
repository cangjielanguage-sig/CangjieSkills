# cj-apis-system_date_time

This directory serves as a comprehensive resource for developers working within the OpenHarmony ecosystem, specifically focusing on the Cangjie programming language. It contains detailed API documentation for the `ohos.system_date_time` module, which is integral to the BasicServicesKit. The content covers a wide array of time management functionalities, including retrieving the current system time, configuring timezones, and handling various time-related enumerations. Developers will find essential information on calculating elapsed time relative to the Unix epoch and distinguishing between active time and total system uptime, which includes periods of deep sleep. This documentation is vital for Cangjie developers (version 12+) who need to implement precise time tracking, scheduling, and synchronization features in their applications, ensuring robust exception handling and accurate timekeeping across different device states.
