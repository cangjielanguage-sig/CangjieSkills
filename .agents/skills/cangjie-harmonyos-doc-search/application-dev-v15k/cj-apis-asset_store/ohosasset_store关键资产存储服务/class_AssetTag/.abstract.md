This directory contains API reference documentation for the `AssetTag` class within the Cangjie language's `SystemCapability.Security.Asset` module. It defines static constant identifiers used for managing key asset attributes, including authentication, data labels, persistence, and conflict resolution. The documentation covers how these constants combine `AssetTagType` (BYTES, NUMBER, BOOL) with unique identifiers to serve as keys for `Asset_Attr`. It is suitable for developers implementing secure asset management applications who need precise definitions for tagging, synchronization logic, and system capability metadata.
