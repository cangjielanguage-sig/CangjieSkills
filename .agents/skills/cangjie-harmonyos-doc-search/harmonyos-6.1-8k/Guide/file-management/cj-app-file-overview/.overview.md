# cj-app-file-overview

本目录包含关于应用文件系统的核心文档，旨在全面阐述应用文件的定义、存储结构及其与应用沙箱环境的紧密关系。内容详细涵盖了应用文件目录的层级结构、应用沙箱目录的组成要素，以及严格的文件访问权限与存储规范。文档的核心要点在于解释应用数据如何存储在专属目录中，应用沙箱目录如何限定应用的可见范围，系统文件为何只读，以及应用仅能向特定子目录写入数据的限制机制。这是一份概念性指南，非常适合需要深入理解应用文件系统架构、掌握数据隔离与安全存储规范的开发者阅读。

## Detailed Description

### cj-app-file-overview.md
本文档旨在概述应用文件的定义、存储结构及其与应用沙箱的关系。主要涵盖应用文件的定义、应用文件目录的结构、应用沙箱目录的组成，以及文件访问权限和存储规范。核心要点包括应用数据存储在专属目录中，应用沙箱目录限定了应用的可见范围，系统文件只读，且应用仅能向应用文件目录下的特定子目录写入数据。本文属于概念性指南，面向需要理解应用文件系统架构的开发者。
