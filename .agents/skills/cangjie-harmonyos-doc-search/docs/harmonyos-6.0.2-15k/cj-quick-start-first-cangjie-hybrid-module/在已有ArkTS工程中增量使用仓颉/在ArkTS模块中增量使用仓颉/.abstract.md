This directory provides resources for HarmonyOS developers looking to integrate Cangjie language capabilities into existing ArkTS projects incrementally. It covers setting up hybrid development environments, embedding Cangjie UI components within ArkTS pages, and enabling cross-module function calls between pure ArkTS and Cangjie code. Key topics include Interop configurations, HybridComponent usage, and @Interop annotations. Suitable for developers using DevEco Studio who want to leverage Cangjie for high-performance business logic or UI elements while maintaining their current ArkTS architecture.
