# cj-apis-net-connection-interop

This directory provides API documentation for the Cangjie network connection interoperability module, designed to facilitate communication between Cangjie and ArkTS environments. It focuses on the `NetHandle` class, detailing the `JSSystemObjectInteropType` interface and extensions for bidirectional conversion. Key features include the `fromJSValue` and `toJSValue` methods, which enable the transformation of Cangjie objects into ArkTS JSValue types and vice versa using a `JSContext`. This resource is intended for Cangjie developers who need to integrate network management logic with ArkTS system capabilities, ensuring seamless cross-platform functionality.
