This directory provides essential API reference documentation for the `Matrix4Transit` class and related transformation functions within the ArkUI framework, utilizing the Cangjie programming language. It focuses on the intricate management of 4x4 matrix transformations, a core component for handling 2D and 3D graphical operations. The documentation covers a broad spectrum of geometric manipulations, including rotation, scaling, skewing, inversion, and matrix combination, as well as polygon vertex mapping. Furthermore, it includes specific functions for transforming coordinate points and applying axis translations. This resource is specifically designed for ArkUI developers and graphics engineers who need to implement complex visual effects and precise coordinate system manipulations, requiring a solid foundation in matrix operations and Cangjie syntax.
