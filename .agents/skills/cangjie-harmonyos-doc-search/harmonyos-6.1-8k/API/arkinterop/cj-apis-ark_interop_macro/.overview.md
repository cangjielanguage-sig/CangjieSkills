# cj-apis-ark_interop_macro

本目录包含 `ohos.ark_interop_macro` 模块的 API 参考文档，主要介绍仓颉与 ArkTS 之间的声明式互操作宏。核心内容涵盖 `@Interop` 宏的定义与用法，该宏能够自动生成 ArkTS 声明文件及互操作层代码，支持 `String` 和 `Int64` 等实现了 `JSInteropType` 的类型，从而简化跨语言开发流程。目前该功能处于 Beta 阶段，适用于需要在仓颉和 ArkTS 环境间进行数据交互与调用的开发者。
