# 配置文件标签

This directory contains technical reference documentation for application configuration files, specifically focusing on the `app.json5` format used in HarmonyOS/OpenHarmony development. It covers the structure, syntax, and permissible tags required for defining application properties, build settings, and device compatibility. Key topics include bundle naming conventions, API versioning, multi-app modes, and runtime limits. These resources are designed for developers and configuration engineers who need to accurately implement application manifests and build profiles using DevEco Studio.

## Detailed Description

### 配置文件标签_1.md
This document acts as a technical reference guide defining the structure and syntax of the app.json5 configuration file. It primarily focuses on enumerating and explaining the specific tags permissible within the file, organized through a detailed table (Table 1) that provides descriptions for each configuration element. Key information includes the valid schema definitions required for proper application setup. Intended for developers and configuration engineers, this document ensures accurate implementation of app settings by providing a comprehensive list of supported tags and their functions.

### 配置文件标签_2.md
This document provides a technical reference for application configuration attributes, specifically for HarmonyOS/OpenHarmony development. It details essential tags such as bundleName, bundleType, versionCode, and API compatibility settings like minAPIVersion and targetAPIVersion. The content explains data types, default values, and specific naming conventions for each attribute, covering aspects ranging from basic app identification to build configurations like debug mode and multi-project support. Key takeaways include the strict reverse-domain naming rules for bundleName and the distinction between app and atomic service types. This reference guide is intended for developers using DevEco Studio to configure application manifests and build profiles for the Stage model.

### 配置文件标签_3.md
This document serves as a technical reference for application configuration tags, detailing attributes used to define app behavior, build settings, and device compatibility. Key sections cover device-specific configurations for tablets and defaults, overlay application settings, build hash generation, environment variables, and runtime limits like maxChildProcess. It also explains features such as multi-app mode, cloud file sync, and asset access groups. Each entry specifies data types, default values, and conditional requirements, such as API version dependencies. This guide is intended for developers configuring application manifests, requiring knowledge of JSON5 structure and the operating system's packaging tools.
