This directory contains API reference documentation for the `RdbStore` class in the Cangjie language, part of the ArkData framework for HarmonyOS. It covers relational database management, including CRUD operations, transaction control, distributed data synchronization, and event handling. Key topics include SQL execution, backup and restore, and cloud sync capabilities. The documentation is intended for Cangjie developers building applications that require local and distributed data persistence, providing detailed function signatures, error codes, and code examples for robust database implementation.
