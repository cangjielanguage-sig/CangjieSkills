# 滚动组件通用API

This directory provides a comprehensive API reference for common scrollable components within the Cangjie ArkUI framework. It covers shared attributes, events, and configuration classes essential for implementing precise scrolling behaviors in List, Grid, Scroll, and WaterFlow components. Key topics include edge effects, content clipping, scroll snapping, nested scrolling, and event callbacks for monitoring scroll states. This documentation is designed for UI developers and engineers using the Cangjie language to build high-performance, interactive HarmonyOS applications with polished scrolling experiences.
