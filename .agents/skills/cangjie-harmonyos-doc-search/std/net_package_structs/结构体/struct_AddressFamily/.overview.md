# struct_AddressFamily

This directory contains comprehensive API reference documentation for the `AddressFamily` struct within the Cangjie network package. It covers the definition of addressing schemes for network sockets, including static constants for protocols like IPv4, IPv6, and UNIX, as well as operator overloads for equality and inequality comparisons. The documentation details properties, constructors, interface implementations, and platform-specific values such as Linux-only support for NetLink. It is suitable for Cangjie developers working on network programming who need to implement or configure sockets and require precise comparison of address family values.
