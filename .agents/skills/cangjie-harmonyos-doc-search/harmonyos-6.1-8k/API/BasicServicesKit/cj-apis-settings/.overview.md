# cj-apis-settings

This directory serves as a comprehensive repository for API reference documentation regarding HarmonyOS system settings, specifically tailored for the Cangjie (仓颉) programming language. It provides essential resources for developers looking to interact with the underlying system configuration, covering areas such as date and time formatting, data domain definitions, and the retrieval of system values. Key topics include Date, DomainName, getValue, Display, and system settings. This documentation is primarily suitable for HarmonyOS application developers and system engineers who utilize the BasicServicesKit and ohos.settings modules to manage device parameters like brightness, time, and user-specific data isolation effectively. It acts as a vital technical guide for ensuring applications can correctly query and modify system-level preferences within the HarmonyOS ecosystem.
