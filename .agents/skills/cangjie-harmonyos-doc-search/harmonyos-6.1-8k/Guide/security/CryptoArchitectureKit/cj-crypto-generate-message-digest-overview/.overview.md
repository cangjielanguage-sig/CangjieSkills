## 详细描述

### cj-crypto-generate-message-digest-overview.md

本文档是一份面向开发者的 API 参考指南，旨在深入介绍消息摘要算法的基础理论及系统当前支持的算法规格。文档首先定义了消息摘要的概念，并详细说明了其主要特性，包括确定性（相同输入产生相同输出）和固定输出长度等，这些特性对于数据验证至关重要。此外，文档还提供了详细的算法支持列表，涵盖了 HASH 类型的多种算法，具体包括 SHA256、MD5 和 SM3 等。在技术约束方面，文档明确指出所有相关算法均要求 API 版本 12 及以上，并提示当前功能处于 Beta 阶段，提醒开发者注意接口的稳定性。这对于需要实现数据加密或进行完整性校验的开发人员来说，是正确选择和使用摘要算法的重要参考资料。
