This directory serves as a comprehensive technical resource for implementing data persistence using relational databases within the Cangjie development environment, specifically leveraging SQLite. It is designed to assist developers in mastering the full lifecycle of local data storage, ranging from basic initialization to complex data manipulation and maintenance. The documentation covers critical technical concepts including predicates, result sets, and operating mechanisms, while providing detailed insights into API interfaces such as `getRdbStore`, `insert`, and `query`. Furthermore, it addresses system constraints, supported data types, and performance optimization strategies to ensure efficient application behavior. This resource is ideal for application developers familiar with Cangjie and ArkUI who need to manage complex data relationships, ensure data integrity, and perform advanced maintenance tasks like backup and restoration in their applications.
