# dynload

This directory contains a technical tutorial focused on the implementation of dynamic loading capabilities within the Cangjie programming language. It provides a comprehensive, step-by-step guide for developers aiming to build modular applications where code can be loaded and executed at runtime rather than being statically linked. The guide covers essential technical procedures, including the creation of dynamic library modules and executables using the `cjpm` build tool. Furthermore, it explores the advanced use of reflection to interact with global variables dynamically. This resource is highly suitable for Cangjie developers who need to understand the intricacies of runtime library management, package initialization, and the `std.reflect` API to create flexible, extensible, and maintainable software systems.

## Detailed Description

### dynload.md dynload.md
The `dynload.md` file serves as an in-depth tutorial designed to guide Cangjie developers through the complex process of implementing dynamic loading. It begins by establishing the necessary project structure, detailing how to create both a dynamic library module and an executable using the `cjpm` build tool. The document then transitions into runtime operations, explaining how to load the library dynamically and manipulate its global variables using reflection.

The tutorial is structured around several key technical areas. It covers project setup and the specific command `cjpm init --type=dynamic` required for library initialization. It also provides in-depth instructions on using the `std.reflect` namespace, specifically focusing on the `PackageInfo.load` and `getVariable` functions to achieve runtime interaction.

Additionally, the document highlights a critical implementation detail regarding system stability: `PackageInfo.load` relies strictly on the filename to identify the package. Consequently, developers are warned that renaming files will lead to errors. This guide is an essential resource for those seeking to develop modular, dynamically loaded applications in Cangjie, offering the necessary knowledge to handle runtime dependencies effectively.
