This directory contains API reference documentation for the `ActionSheetOptions` component within the ArkUI framework. It provides comprehensive guides for developers looking to instantiate, configure, and style action sheet dialogs in HarmonyOS applications. The documentation covers constructor signatures, configuration parameters for content and behavior, and specific styling properties for the backdrop. It is suitable for HarmonyOS developers using the Cangjie language and UI engineers who need to implement interactive, customizable dialog components with specific visual and functional requirements.
