This directory contains comprehensive API documentation for extending the UInt32 type within the Cangjie programming language to implement the ThrowingOp interface. It focuses on a wide array of arithmetic and bitwise operations that utilize strict exception-handling strategies. Specifically, these functions are designed to throw OverflowException or OvershiftException when errors occur, such as arithmetic overflow or invalid shift amounts, rather than allowing silent wrapping. This resource is essential for Cangjie developers working with the core package who require safe, checked mathematical operations on unsigned 32-bit integers. It serves as a vital reference guide for ensuring robustness in numerical computations where explicit error handling is mandatory.
