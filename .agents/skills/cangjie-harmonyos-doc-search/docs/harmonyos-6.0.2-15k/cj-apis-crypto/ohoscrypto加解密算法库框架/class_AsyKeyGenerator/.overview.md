# class_AsyKeyGenerator

This directory contains essential API reference documentation for the `AsyKeyGenerator` class in the Cangjie programming language, specifically designed for the CryptoFramework. It focuses on the generation and conversion of asymmetric cryptographic keys, supporting standard algorithms such as RSA and ECC256. The documentation details the class structure, properties, and methods required to create random key pairs, convert raw binary data blobs into KeyPair objects, and import keys from PEM-formatted strings. Including detailed error codes and parameter specifications, this resource is suitable for software developers and security engineers implementing cryptographic security features and key management solutions in their applications.
