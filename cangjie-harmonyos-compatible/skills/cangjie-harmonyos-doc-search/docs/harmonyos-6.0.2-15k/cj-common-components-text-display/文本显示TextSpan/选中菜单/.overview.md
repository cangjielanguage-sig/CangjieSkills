# 选中菜单

This directory focuses on the implementation and customization of selection menus for text components within the HarmonyOS ArkUI development environment. It provides comprehensive guidance on enabling default selection behaviors, binding fully custom menus, and extending standard menus with additional options. The content covers specific technical implementations using both the Cangjie language and ArkTS, detailing the use of `TextController`, `bindSelectionMenu`, `editMenuOptions`, and event handling callbacks like `onCreateMenu` and `onMenuItemClick`. This resource is designed for HarmonyOS application developers who need to create sophisticated text interaction experiences, manage user selections, and implement custom editing behaviors in their mobile applications. By following these guides, developers can learn how to intercept standard actions, append custom items, and control the UI presentation of text selection menus effectively.

## Detailed Description

### 选中菜单_1.md 选中菜单_1.md
This guide explains how to implement and customize selection menus for the Text component in ArkUI using the Cangjie language. It covers enabling default selection via the copyOption property, binding fully custom menus using bindSelectionMenu, and extending standard menus with editMenuOptions. Key information includes the necessity of TextController for menu control and the use of Builder functions for custom UI elements. This tutorial targets HarmonyOS application developers seeking to enhance text interaction capabilities within their apps.

### 选中菜单_2.md 选中菜单_2.md
This document provides a code example demonstrating how to customize and handle text selection menus in ArkTS applications. The main topics include implementing the onCreateMenu callback to filter standard options and append custom items, and using onMenuItemClick to manage user interactions. Key information shows how to intercept specific actions like Copy or custom items by returning true, while allowing default behavior for others like Select All. The example also illustrates binding these handlers to a Text component using editMenuOptions. This tutorial is intended for developers familiar with ArkTS and HarmonyOS UI development who need to implement custom text editing behaviors. Keywords: ArkTS, Text selection menu, editMenuOptions, event interception, custom menu items.
