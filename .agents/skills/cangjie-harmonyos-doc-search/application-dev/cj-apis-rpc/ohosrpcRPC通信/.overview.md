### interface_Parcelable.md interface_Parcelable.md
This API reference document defines the Parcelable interface for serializing objects during Inter-Process Communication (IPC) in the Cangjie language. It details the interface definition, the marshalling function for writing data to a MessageSequence, and the unmarshalling function for reading data back. Both methods return a Bool indicating success or failure. The document includes practical code examples demonstrating how to implement the interface in a custom class and handle arrays of parcelable objects. This guide targets developers building IPC-enabled applications who need to transfer custom data types between processes.

### class_Ashmem/
This directory contains comprehensive API reference documentation for the Ashmem class within the Cangjie language, specifically designed for managing anonymous shared memory to facilitate inter-process communication (IPC) on the same device. It covers a wide range of functionalities, including memory protection constants like PROT_READ and PROT_WRITE, static methods for object creation, and file descriptor duplication. Additionally, it details operations for mapping, unmapping, reading, and writing memory, along with error handling for business exceptions. This documentation is intended for developers working on IPC features who require a deep understanding of memory mapping concepts to implement efficient shared data exchange between processes.

### class_MessageSequence/
This directory contains API reference documentation for the `MessageSequence` class within the Cangjie IPC Kit, designed for HarmonyOS inter-process communication (IPC).
