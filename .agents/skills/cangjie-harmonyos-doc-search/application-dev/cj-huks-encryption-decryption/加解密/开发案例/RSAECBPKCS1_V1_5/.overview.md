# RSAECBPKCS1_V1_5

This directory contains technical documentation and code examples for implementing RSA encryption and decryption using the ECB mode and PKCS1_V1_5 padding scheme within the HarmonyOS Universal Keystore (HUKS) framework. It covers the complete cryptographic lifecycle, including key generation, data encryption, decryption, and key deletion using the Cangjie language. The content is tailored for HarmonyOS developers who need to integrate secure cryptographic operations into their applications, providing specific parameter configurations and workflow guidance for utilizing HUKS APIs effectively.

## Detailed Description

### RSAECBPKCS1_V1_5_1.md RSAECBPKCS1_V1_5_1.md
This document provides a Cangjie code example demonstrating how to implement RSA encryption and decryption using the ECB mode and PKCS1_V1_5 padding within the HarmonyOS Universal Keystore (HUKS) framework. The content covers utility functions for data conversion, configuration functions for defining cryptographic properties like algorithm, key size, and padding, and execution functions for key generation and data encryption. Key takeaways include the specific HUKS parameter sets required for RSA/ECB/PKCS1_V1_5, such as using a 2048-bit key size and the workflow involving initSession and finishSession. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to integrate secure cryptographic operations into their applications.

### RSAECBPKCS1_V1_5_2.md RSAECBPKCS1_V1_5_2.md
This document serves as a code tutorial demonstrating RSA decryption and key deletion operations using the HarmonyOS Universal Keystore Service (HUKS). It details the implementation of two main functions: DecryptData and DeleteKey. The decryption section illustrates the multi-step process of configuring options, initializing a session with a key alias, and finalizing the session to retrieve plaintext. The deletion section shows how to securely remove a key item using its alias. This guide is intended for developers working with HUKS APIs who need to manage cryptographic data lifecycles, specifically focusing on post-generation operations like decryption and cleanup.
