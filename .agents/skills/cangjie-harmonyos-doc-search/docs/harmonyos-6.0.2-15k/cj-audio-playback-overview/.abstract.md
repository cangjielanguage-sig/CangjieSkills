This directory provides a specialized technical overview for developers implementing audio playback features using the Cangjie language. It functions as a strategic guide to navigating the available audio subsystems, ensuring that developers can match technical requirements with the correct API. The scope of the document covers four distinct playback methods: the **AudioRenderer** for advanced, low-level raw PCM processing; **AudioHaptic** for multi-sensory feedback involving synchronized vibration; **AVPlayer** for streamlined playback of standard media formats such as MP3; and **SoundPool** for high-performance, low-latency sound effects. Additionally, the resource outlines critical environmental constraints, specifically noting the current lack of support for background or screen-off playback. This documentation is primarily suitable for application developers and audio engineers who need to evaluate trade-offs between data format support, latency sensitivity, and overall usage scenarios to build robust audio applications.
