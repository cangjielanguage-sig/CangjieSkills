# specified启动模式

This directory provides comprehensive documentation on the "specified" startup mode for UIAbility components within the HarmonyOS ecosystem. It is designed to help developers manage specific application instances, particularly for scenarios like document editing where multiple files require distinct lifecycle management. The content covers the underlying mechanisms involving `startAbility`, `AbilityStage.onAcceptWant`, and key lifecycle callbacks such as `onNewWant` and `onCreate`. Additionally, it includes practical Cangjie code examples and configuration instructions for `module.json5`. This resource is ideal for HarmonyOS developers seeking to implement efficient resource management and precise instance control based on unique business keys.

### specified启动模式_1.md specified启动模式_1.md
This technical guide explains the specified launch mode for UIAbility, designed for scenarios requiring specific instance management like document applications. It details the operational principle involving startAbility, AbilityStage.onAcceptWant, and lifecycle callbacks like onNewWant and onCreate. The document outlines configuration steps in module.json5 and provides a Cangjie code example demonstrating how to pass a unique instanceKey via Want parameters. The core mechanism uses this key to match existing instances; a match triggers reuse, while a mismatch creates a new instance. Targeted at HarmonyOS developers, this guide requires knowledge of UIAbility lifecycle and basic application configuration.

### specified启动模式_2.md specified启动模式_2.md
This document provides a code example tutorial for implementing the "specified" UIAbility startup mode using the Cangjie language. It covers constructing a Want object with custom parameters to start an ability and implementing the onAcceptWant() lifecycle callback in AbilityStage to return a specific instance key. The key takeaway is that the system reuses an existing UIAbility instance if the key returned by onAcceptWant() matches a previous one, triggering onNewWant() instead of onCreate(). This guide targets application developers needing to manage specific UIAbility instances based on business logic.
