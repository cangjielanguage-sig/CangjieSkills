# 示例代码

This directory provides a collection of Cangjie code examples designed to illustrate advanced UI event handling mechanisms within the ArkUI framework. The content focuses specifically on configuring touch event dispatch strategies to manage interactions between overlapping or nested components, such as Lists and Buttons. By exploring concepts like `TouchTestStrategy`, `FORWARD_COMPETITION`, `FORWARD`, and `DEFAULT` modes, developers can learn to use the `onChildTouchTest` modifier effectively. These resources are tailored for Cangjie developers who need to solve touch event conflicts, enable scrolling in non-interactive areas, and maintain the responsiveness of specific UI elements in complex application layouts.

## Detailed Description

The following files provide specific implementations and comparisons of event handling strategies:

### 示例1设置事件派发策略为FORWARD_COMPETITION.md
This document provides a Cangjie code example demonstrating how to configure the event dispatch strategy to FORWARD_COMPETITION for handling touch events in a UI layout. It covers the implementation of the touchTestInfo function within an EntryView class, specifically targeting a List component to allow scrolling when touching blank areas, while ensuring a Button component remains clickable. Key information includes the use of TouchTestStrategy.FORWARD_COMPETITION and the onChildTouchTest modifier to manage event distribution between child components. This tutorial is intended for developers using the Cangjie language and ArkUI framework to resolve touch event conflicts in complex layouts.

### 示例2设置事件派发策略为FORWARD_2more.md
This document illustrates how to configure touch event dispatch strategies in Cangjie UI development using the onChildTouchTest callback. It presents two comparative code examples demonstrating the FORWARD and DEFAULT strategies within a layout containing a List and a Button. Key takeaways include that the FORWARD strategy permits List scrolling in blank areas while blocking Button click events, whereas the DEFAULT strategy allows Button clicks but prevents List scrolling in the specific context shown. This tutorial targets Cangjie developers seeking to understand touch event control and component interaction behaviors.
