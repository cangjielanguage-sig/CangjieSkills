This directory provides comprehensive API reference documentation for the `ThrowingOp` interface implementation specifically tailored for the `Int32` type within the Cangjie programming language. It focuses on a suite of arithmetic and bitwise operations designed to enforce strict data integrity through exception-based error handling. Unlike standard operations that might wrap values on overflow, these functions throw specific exceptions like `OverflowException` and `OvershiftException` to signal errors immediately. The content covers essential operations such as addition, subtraction, multiplication, division, negation, and bit shifting. This resource is highly suitable for Cangjie developers who need to implement robust error checking and safe arithmetic logic to prevent silent data corruption in critical applications.
