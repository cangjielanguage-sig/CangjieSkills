This directory provides API reference documentation for the `JSContext` class in the Cangjie programming language, designed to manage single-threaded ArkTS interoperation contexts. It details the creation and conversion of data types such as ArrayBuffers, BigInts, and strings, alongside methods for module loading and thread management. Key concepts include lifecycle management, N-API integration, and exception handling. This resource is intended for Cangjie developers working on cross-language integration with ArkTS, offering the necessary tools to handle data mapping, memory management, and multithreading tasks.
