# cj-displaysync-overview

This directory provides a technical overview of OpenHarmony's Variable Frame Rate capability, a sophisticated feature designed to harmonize high-performance visual output with power efficiency on LTPO (Low Temperature Polycrystalline Oxide) displays. It covers the end-to-end operating mechanism, ranging from how developers submit frame rate requests to how the system processes these requests to drive hardware refresh rates. Key topics include specific usage scenarios like animation configuration, the API-based approach for setting expected frame rates, and the constraints imposed by hardware capabilities and system power policies. This documentation is specifically tailored for OpenHarmony developers who need to implement dynamic refresh rates to optimize application fluidity and maximize battery life. By utilizing this feature, applications can significantly reduce power usage during static scenes while maintaining high refresh rates during dynamic interactions, providing a superior user experience. Mastering this capability allows for the creation of responsive yet energy-conscious applications.

This guide is an essential resource for OpenHarmony developers seeking to optimize application power efficiency and manage display performance effectively.
