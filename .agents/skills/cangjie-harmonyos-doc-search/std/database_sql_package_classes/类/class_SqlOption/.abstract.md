This directory contains comprehensive API reference documentation for the `SqlOption` class within the Cangjie programming language, specifically designed for database connection configuration. It defines a robust set of pre-defined string constants covering essential parameters such as Host, URL, Database, and authentication credentials. Furthermore, it addresses operational settings including timeouts, character encoding, and advanced SSL/TLS security options. These constants serve as standardized keys for database drivers, effectively preventing naming conflicts and ensuring consistency. This documentation is primarily suitable for software developers and system architects who are configuring secure, reliable, and standardized database interactions in Cangjie applications.
