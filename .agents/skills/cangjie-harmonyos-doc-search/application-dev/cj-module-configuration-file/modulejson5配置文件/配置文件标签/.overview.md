# 配置文件标签

This directory contains technical reference documentation for configuration tags used within the `module.json5` file, primarily for HarmonyOS and OpenHarmony application development. It covers a comprehensive range of module attributes, including identification, entry points, process management, component definitions, build settings, and runtime configurations. The documents provide detailed definitions, data types, and constraints for various tags to help developers correctly structure application modules, manage dependencies, and define system interactions. This resource is suitable for software developers and system architects seeking to understand schema requirements and optimize application packaging and behavior.

### 配置文件标签_2.md 配置文件标签_2.md
This document provides a technical reference for configuring Module attributes in application development, specifically for HarmonyOS or OpenHarmony systems. It details a comprehensive list of configuration tags, including module identification (name, type), entry points (srcEntry, mainElement), process management (process, isolationMode), and component definitions (abilities, extensionAbilities). The content specifies data types, optionality, and constraints for each attribute, covering deployment settings like installationFree and deviceTypes. Key takeaways include the distinction between module types such as entry and feature, and the specific requirements for process isolation and permissions. This guide is intended for developers configuring application manifests to define module structure, runtime behavior, and system interactions.

### 配置文件标签_3.md 配置文件标签_3.md
This reference documentation defines specific configuration tags for HarmonyOS application modules, detailing their attributes, behaviors, and constraints. It covers build settings like dHash and compressNativeLibs, library management via libIsolation, and UI features such as fileContextMenu. Additionally, it explains runtime configurations including appEnvironments, querySchemes, hnpPackages, and appStartup. Key information includes boolean flags for compression, string arrays for URL schemes, and redirection properties for UIAbility introduced in API version 17. Specific restrictions are noted, such as PC-only features or entry-module exclusivity. This guide targets HarmonyOS developers configuring module files to manage HAP and HAR packaging, dependencies, and startup behavior.
