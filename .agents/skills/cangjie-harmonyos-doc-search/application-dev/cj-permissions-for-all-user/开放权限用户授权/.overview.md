# 开放权限用户授权

This directory provides comprehensive documentation on HarmonyOS permissions that require explicit user authorization (`user_grant`). It covers the general framework for requesting sensitive permissions at runtime, as well as specific permission definitions introduced in API version 12. Key topics include the `system_basic` protection level, device-specific constraints (such as Tablet exclusivity), and the correct configuration in `module.json5`. This resource is essential for developers who need to implement secure access to system capabilities like screen capture, Bluetooth, and location services while ensuring compliance with user privacy requirements.

## Detailed Description

### ohospermissionCUSTOM_SC_80e0ea22.md ohospermissionCUSTOM_SC_80e0ea22.md
This document defines the system permission `ohos.permission.CUSTOM_SCREEN_CAPTURE`, which authorizes applications to capture screen images and perform screenshot operations. It covers the permission's description, access level, authorization method, supported device types, and the minimum API version required. Key details include the `system_basic` protection level, the requirement for explicit `user_grant` authorization, and exclusivity to Tablet devices starting from API version 12. This reference is intended for developers building applications for HarmonyOS tablets that require screen capture functionality.

### 开放权限用户授权_2more.md 开放权限用户授权_2more.md
This document serves as a reference guide for open permissions requiring user authorization (`user_grant`) available to all applications. It details the authorization mechanism, emphasizing that these permissions must be declared in the installation package and dynamically requested via a runtime popup for user approval. The document outlines the application process, linking to instructions on declaring permissions and requesting user authorization. Key takeaways include the necessity of manual user consent and the distinction that normal-level permissions do not involve ACL fields.
