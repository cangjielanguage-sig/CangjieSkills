This directory contains API reference documentation for configuring the properties of the Indexer component within the ArkUI framework using the Cangjie language. It covers a wide range of styling and behavioral configurations, including text fonts, colors, popup window appearance, item geometry, and interaction feedback like haptic vibration. The documents provide detailed parameter descriptions, default values, and system capability requirements. This resource is suitable for HarmonyOS developers and UI designers looking to programmatically customize the look and feel of index lists and their associated popups in their applications.
