# 使用场景

This directory focuses on practical usage scenarios for state management in the Cangjie programming language, specifically within the HarmonyOS development ecosystem. It provides in-depth tutorials on implementing reactive state synchronization between components using the `@Provide` and `@Consume` decorators. The content covers a range of data handling requirements, from basic integer counters to complex collections such as HashMaps and HashSets. By exploring these examples, developers can learn how to ensure automatic UI updates and maintain data consistency across the component tree. These resources are highly suitable for HarmonyOS developers and Cangjie programmers who aim to build responsive applications with efficient cross-component communication and robust state observation mechanisms. The tutorials emphasize real-world implementation details, including initialization, modification, and deletion of data entries, ensuring a comprehensive understanding of state propagation.

### 使用场景_2more.md 使用场景_2more.md
This tutorial illustrates state management in Cangjie using the @Provide and @Consume decorators to achieve bidirectional synchronization between ancestor and descendant components. The document presents two distinct code examples: one demonstrating basic state sharing with a simple Int64 counter, and another handling complex data types like HashMap. Key takeaways include how modifications to the provided variable in any descendant component automatically update the state across the entire component tree, supporting operations such as initialization, modification, and deletion of map entries. This guide is intended for HarmonyOS developers seeking to implement efficient cross-component communication and state observation in their applications.

### 装饰Set类型变量.md 装饰Set类型变量.md
This tutorial demonstrates how to implement reactive state management for HashSet variables using Cangjie's @Provide and @Consume decorators. The document presents a code example featuring a parent and child component, where the child component modifies a shared HashSet<Int64>. Key takeaways include observing that operations such as adding, clearing, or removing elements from the set automatically trigger view refreshes. This guide is designed for Cangjie developers building HarmonyOS applications who need to synchronize complex collection data across different UI components.
