This directory contains comprehensive API reference documentation for the `UnixServerSocket` class within the Cangjie programming language's net package. It covers the implementation of Unix domain socket server functionality, including class initialization via file paths or socket addresses, configuration properties like backlog size, and connection management. Key topics include the `accept` method for handling clients, socket binding, listening, and resource cleanup. The documentation also highlights critical limitations, such as the lack of Windows support, and details exception handling for `SocketException` and `IllegalArgumentException`. This resource is designed for developers building network applications who require precise control over socket lifecycles and low-level configurations.
