# 开发步骤

This directory serves as a comprehensive technical guide for developers utilizing the Cangjie LocalizationKit, specifically focusing on the implementation of internationalization (i18n) and localization (l10n) features. It details the development steps required to effectively format time-related data, ensuring applications can communicate temporal information accurately across different cultural contexts. Core keywords include RelativeTimeFormat, DateTimeFormat, locale configuration, and style customization. The content is designed for Cangjie developers who need to integrate robust time formatting logic, covering everything from basic module imports to advanced configuration options for displaying relative time, dates, and time ranges. By following these guides, developers can ensure their applications provide a native and intuitive user experience regarding time representation for global users, handling complex scenarios such as numeric versus textual representations and locale-specific date styles.

## Detailed Description

### 相对时间格式化.md

This document provides a technical guide for developers on how to implement relative time formatting using the RelativeTimeFormat class within the Cangjie LocalizationKit. It covers the development steps including module import, object instantiation, and formatting methods like format and formatToParts. It also details configuration options for numeric representation and display styles through explanatory tables. Key takeaways include understanding how to control output via RelativeTimeFormatInputOptions to switch between numeric or textual representations and different length styles. This guide targets Cangjie developers implementing internationalization features who need to display time differences relative to the current date in various locales.

### 时间日期和相对时间格式化/

This directory provides comprehensive technical documentation for formatting dates, times, and relative time ranges using the DateTimeFormat class within the Cangjie LocalizationKit. It covers the complete development lifecycle, from importing modules to retrieving configurations, with a strong focus on internationalization (i18n) and localization (l10n). Key topics include style options (full, long, short), locale-specific behaviors for zh-CN and en, and advanced customization such as alternative numbering systems and date range formatting. This resource is essential for Cangjie developers seeking to implement precise, culturally aware time display logic in their applications.
