# webSocket

本目录专注于仓颉语言中 WebSocket 网络编程的实践指南。它深入探讨了如何利用标准库扩展 `stdx.net.http` 来构建高性能的实时双向通信应用。文档内容涵盖了从基础的 HTTP 握手升级协议到复杂的消息帧处理机制，包括文本与二进制数据的传输、心跳检测以及连接的优雅关闭。核心关键词涵盖仓颉语言、WebSocket 协议、HTTP 升级、客户端/服务器架构、数据帧处理及网络流控制。该资源特别适合已经掌握仓颉语言基础语法，并希望深入理解网络底层通信或开发即时通讯、在线游戏等实时应用的开发者阅读。

## Detailed Description

### webSocket.md

本文档演示了如何使用仓颉语言的 stdx.net.http 库实现 WebSocket 客户端与服务器的双向通信。主要涵盖服务器启动、握手升级（含子协议与自定义头）、消息收发循环（处理文本、二进制、Ping/Pong 及分片帧）及连接关闭流程。重点介绍了 upgradeFromClient 和 upgradeFromServer 的用法，以及如何通过 read 和 write 方法处理不同帧类型，确保数据完整传输和优雅关闭。适合具备仓颉语言基础的开发者参考，用于构建需要实时双向数据交互的网络应用。
