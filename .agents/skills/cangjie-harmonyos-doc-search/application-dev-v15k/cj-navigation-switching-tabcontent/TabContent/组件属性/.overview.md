# 组件属性

This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It specifically focuses on the `tabBar` function, detailing various overloads for setting up navigation bars with text, icons, custom UI callbacks, and specific styles. Key topics include resource handling (String/AppResource), SVG icon requirements, and style configurations like SubTabBarStyle and BottomTabBarStyle. This documentation is suitable for HarmonyOS developers and UI engineers building navigation interfaces who need detailed parameter specifications, system capability requirements, and version constraints for effective UI development.

## Detailed Description

The following files provide specific implementation details for the TabBar component properties:

### func_tabBarString_6more.md func_tabBarString_6more.md
This document provides API reference documentation for the tabBar function in the Cangjie language, designed to configure the display content of a TabBar component within the ArkUI framework. It details six function overloads that accept either a single content parameter or a combination of icon and text parameters, supporting both String and AppResource types. Key information includes a specific requirement for SVG icons to have intrinsic width and height attributes removed to ensure correct sizing; otherwise, the SVG's original dimensions are applied. All functions require system capability version 12. This reference guide targets HarmonyOS developers using Cangjie to build user interfaces, specifically those implementing navigation bars with localized or static resources.

### func_tabBar_-_Unit_3more.md func_tabBar_-_Unit_3more.md
This API reference document details the tabBar function overloads in the Cangjie language for configuring TabBar content within the ArkUI framework. It covers three specific function signatures: one accepting a custom UI callback and two accepting style objects (SubTabBarStyle and BottomTabBarStyle). Key information includes that the callback method requires @Builder and bind usage, while the style-based methods (available from version 19) handle icon errors with gray blocks and remove underlines. All functions return This to support method chaining. This documentation targets ArkUI developers using Cangjie who need to implement tab navigation interfaces, providing necessary parameters, system capabilities, and version requirements for effective UI development.
