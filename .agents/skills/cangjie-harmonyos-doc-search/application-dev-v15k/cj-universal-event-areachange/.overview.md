# cj-universal-event-areachange

This directory serves as a comprehensive resource for the `onAreaChange` event within the Cangjie ArkUI framework, specifically targeting developers who need to monitor and react to dynamic changes in component geometry. The documentation provides a deep dive into the event's mechanics, explaining how to track size and position variations effectively. It covers essential technical aspects such as the function signature, input parameters, and system capabilities, while also clarifying specific behavioral constraints—most notably, that the callback is triggered exclusively by layout changes and ignores rendering transformations like translate or offset. By including a practical code example that illustrates how to capture and display both old and new area dimensions, this guide facilitates the implementation of responsive UI designs. This material is intended for application developers who have a foundational understanding of Cangjie syntax and are managing complex ArkUI component lifecycles.
