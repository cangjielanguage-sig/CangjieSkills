# cj-crypto-sym-encrypt-decrypt-spec

The `cj-crypto-sym-encrypt-decrypt-spec` directory serves as a comprehensive technical repository for symmetric key encryption and decryption specifications within the CryptoArchitectureKit. It provides essential documentation regarding the implementation of block ciphers, detailing the nuances of various encryption modes such as ECB, CBC, and GCM. Furthermore, it addresses critical configuration aspects including padding mechanisms and string parameter formatting required for algorithms like 3DES, SM4, and AES. This directory is an indispensable resource for software developers and security engineers who are integrating cryptographic functions into their applications. It offers a reliable reference for correctly configuring encryption parameters and adhering to block cipher constraints, ensuring that data remains secure during storage and transmission.

## Detailed Description

### 对称密钥加解密算法规格/

This directory acts as the central hub for technical specifications governing symmetric key encryption algorithms utilized by the CryptoArchitectureKit. It is designed to assist developers in navigating the complex landscape of cryptographic standards by providing clear, actionable implementation details. The content covers a wide array of supported encryption modes, including Electronic Codebook (ECB), Cipher Block Chaining (CBC), and Galois/Counter Mode (GCM), explaining the specific security implications and use cases for each. For instance, while ECB might be simpler, the documentation highlights its weaknesses compared to CBC or GCM for sensitive data.

Beyond mode selection, the directory provides in-depth guidance on padding mechanisms, such as PKCS#7 or ZeroPadding, which are crucial for ensuring that data blocks fit the encryption algorithm's requirements. It also standardizes string parameter formatting, ensuring that developers can correctly instantiate algorithm specifications (e.g., "AES/CBC/PKCS5Padding") without ambiguity. Specific attention is given to widely used algorithms such as 3DES (Triple Data Encryption Standard), SM4 (a Chinese national standard), and AES (Advanced Encryption Standard). For each of these, the documentation outlines how to handle key lengths and block cipher constraints effectively. By consolidating this information, the directory serves as a vital reference for developers who need to ensure their cryptographic implementations are both secure and compliant with the framework's architectural requirements, ultimately preventing common configuration errors that could lead to security vulnerabilities.
