This directory provides comprehensive API reference documentation for implementing and managing gesture interactions within the ArkUI framework using the Cangjie language. It covers a wide range of gesture handlers, including basic gestures like tap, long press, pan, pinch, rotation, and swipe, as well as complex gesture groups. Additionally, it details the `UIGestureEvent` class for dynamically binding and managing these gestures on UI components. This resource is suitable for software developers and UI engineers building interactive HarmonyOS applications who require precise control over touch events and system capabilities.
