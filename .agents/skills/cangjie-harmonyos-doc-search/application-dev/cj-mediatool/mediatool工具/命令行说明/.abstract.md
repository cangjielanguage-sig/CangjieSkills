This directory serves as a comprehensive resource for the `mediatool` command-line interface, specifically focusing on the management of media library resources within a device environment. It provides detailed references for a range of operations, including the importation of local files, the export of media assets back to the local system, and the querying of resource metadata. Additionally, it covers critical maintenance tasks such as permanently deleting resources via URI and locating items by display name. Key functionalities discussed include handling synchronous or asynchronous thumbnail creation, managing source file deletion, and executing bulk operations. This documentation is primarily intended for developers and system administrators who require a robust tool for manipulating media assets programmatically. Users should possess a solid understanding of command-line interfaces, file paths, and URI structures to effectively utilize the tools described.
