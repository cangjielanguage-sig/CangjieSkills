# 绑定手势方法

This directory focuses on the methods and techniques for binding gesture recognition to UI components within the ArkUI framework using the Cangjie language. It covers standard gesture binding, priority handling, parallel execution, and event response mechanisms. Key topics include `TapGesture`, `priorityGesture`, `parallelGesture`, and conflict resolution. It is suitable for developers and UI engineers looking to implement interactive touch interfaces, manage gesture hierarchies, and handle complex user interactions in HarmonyOS applications.

### 示例.md 示例.md
This document provides a Cangjie code example demonstrating the difference between priority and parallel gesture handling in UI components. It covers the implementation of TapGesture, priorityGesture, and parallelGesture within a Column layout. The example illustrates that priorityGesture causes the parent component's gesture to override the child's, while parallelGesture allows both child and parent gestures to trigger simultaneously. This is intended for developers using the Cangjie language for HarmonyOS application development to understand gesture conflict resolution and event handling.

### 绑定手势识别.md 绑定手势识别.md
This API reference document details how to bind gesture recognition to components within the ArkUI framework using the Cangjie language. It covers three primary binding methods: standard gesture, parallelGesture for simultaneous parent-child triggering, and priorityGesture for parent-first recognition, each supporting overloads with a GestureMask parameter. Key information includes the non-bubbling nature of gesture events, conflict resolution between click and double-click gestures, and specific priority rules for long-press interactions. All functions require a GestureType parameter and are available from API version 19. This guide is intended for UI developers needing to implement complex touch interactions and manage gesture hierarchies in their applications.
