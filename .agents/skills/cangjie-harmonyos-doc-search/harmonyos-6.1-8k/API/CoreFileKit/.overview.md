# CoreFileKit

CoreFileKit is a comprehensive documentation repository designed for HarmonyOS developers utilizing the Cangjie programming language. It focuses on the Core File Kit, providing essential resources for file URI handling, file system operations, and error management. This collection covers modules such as `ohos.file.fileuri` and `ohos.file.fs`, alongside detailed error code references for the file management subsystem. It is suitable for developers seeking to implement file I/O, manage user data, or handle file-related exceptions within their HarmonyOS applications. The documentation serves as a vital navigation hub for integrating file basic services efficiently. Note that many features described within this kit are currently in the Beta stage, offering early access to evolving capabilities for the Cangjie ecosystem.

## Detailed Description

### [1] README_zh
This directory contains the Cangjie language index documentation for the Core File Kit (File Basic Services). It aims to provide developers with a navigation entry point for APIs and error codes. The documentation covers two core modules: File URI (`ohos.file.fileuri`) and File Management (`ohos.file.fs`), and details file management-related error codes. All listed features are currently in the Beta stage. This document is suitable for developers using the Cangjie language for application development, particularly in scenarios involving file URI processing, file system operations, and error handling. Through this document, developers can quickly locate specific API references and error code descriptions to efficiently integrate file basic services.

### [2] cj-apis-file_fileuri
This directory provides a specialized collection of API reference documentation designed for the Cangjie programming language, specifically targeting the `ohos.file.fileuri` module. It is an essential resource for HarmonyOS developers who need to implement file URI handling and manipulation within their applications.

### [3] cj-apis-file_fs
This directory serves as a comprehensive resource for the `ohos.file.fs` module within the Cangjie programming language ecosystem. It focuses specifically on file system operations tailored for HarmonyOS application development. The content covers essential functionalities for managing files and directories, ensuring developers have the necessary tools for robust file I/O implementation.

### [4] cj-errorcode-filemanagement
This directory serves as a specialized knowledge base dedicated to the error codes of the file management subsystem. It provides a structured overview of documentation that spans essential modules such as basic file Input/Output (I/O), user data management, and other related components, aiding developers in effective debugging and error resolution.
