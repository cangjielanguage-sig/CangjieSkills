# cj-crypto-generate-sym-key-randomly

This directory provides a technical tutorial focused on the random generation of symmetric keys using the Cangjie CryptoArchitectureKit. It covers the implementation details for AES256 and SM4_128 algorithms, guiding developers through the specific API calls required for each step. The core workflow involves creating a SymKeyGenerator with a specific algorithm string, calling generateSymKey to create the key object, and using getEncoded to retrieve the binary data for storage or encryption. This resource is suitable for Cangjie developers implementing cryptographic operations, offering practical code examples to facilitate secure key management. The guide ensures developers understand how to handle sensitive cryptographic material securely within the Cangjie environment, bridging the gap between high-level security requirements and low-level code implementation. Keywords include Cangjie, CryptoArchitectureKit, symmetric key generation, AES256, SM4_128, and cryptography.
