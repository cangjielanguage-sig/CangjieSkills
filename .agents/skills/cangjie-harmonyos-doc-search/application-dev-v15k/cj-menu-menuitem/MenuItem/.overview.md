# MenuItem

This directory provides comprehensive technical documentation for the MenuItem component within the Cangjie ArkUI framework. It covers the component's definition, structural composition, and usage constraints, specifically noting that it contains no subcomponents. The content includes API references for creating menu items using various constructors, handling events like `onChange`, and configuring component properties such as font styling and selection states. It also confirms full support for common properties and events. This documentation is suitable for HarmonyOS application developers and interface designers working with the Cangjie language to build interactive menu systems.
