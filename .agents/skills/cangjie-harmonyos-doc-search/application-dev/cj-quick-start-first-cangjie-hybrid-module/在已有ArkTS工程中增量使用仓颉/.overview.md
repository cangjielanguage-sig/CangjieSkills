### 原ArkTS工程初始状态.md 原ArkTS工程初始状态.md

It details the directory structures of entry and my_module, provides code examples for Navigation routing, and explains configuration files like router_map.json and module.json5. This guide targets HarmonyOS developers setting up multi-module ArkTS applications with custom routing.
