# class_ScanFilter

This directory contains essential API reference documentation for the `ScanFilter` class within the Cangjie programming language, specifically designed to manage the filtering of Bluetooth Low Energy (BLE) broadcast packets. It thoroughly covers the class structure, defining specific properties such as `deviceId`, `name`, `manufactureId`, `manufactureData`, `serviceData`, and various UUIDs along with their corresponding masks. The documentation guides developers on setting precise criteria—such as device addresses or service data—to ensure that only matching BLE advertisements are reported to the system. Additionally, it outlines system capabilities starting from version 22 and clarifies current limitations, explicitly noting which fields are reserved and unsupported. This resource is ideal for software developers and engineers integrating BLE scanning functionality into applications, providing the technical details required to implement robust and efficient device discovery filters.
