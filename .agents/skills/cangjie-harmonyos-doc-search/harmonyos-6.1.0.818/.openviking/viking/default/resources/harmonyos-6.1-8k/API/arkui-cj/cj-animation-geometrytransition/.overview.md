# cj-animation-geometrytransition

本目录提供了关于ArkUI框架中geometryTransition API的详细技术文档，该API专为使用仓颉语言（Cangjie）进行应用开发的场景设计。文档的核心主题是组件内的隐式共享元素转场，旨在帮助开发者在视图切换过程中实现丝滑的上下文传承过渡效果。内容涵盖了API的完整函数定义、关键参数（id和follow）的深入说明、严格的使用限制以及配合animateTo使用的实际代码示例。通过学习本文档，开发者可以掌握如何通过绑定相同id的入出组件来协调位置和大小，从而将视觉焦点从旧视图平滑引导至新视图。这份资料非常适合具备ArkUI基础动画知识并希望提升应用界面交互流畅度的开发者参考。

## 详细说明

### cj-animation-geometrytransition.md
本文档介绍了ArkUI框架中用于实现组件内隐式共享元素转场的geometryTransition API，旨在视图切换时提供丝滑的上下文传承过渡。文档涵盖了函数定义、参数说明（id和follow）、使用限制及配合animateTo的代码示例。关键点在于该API通过绑定相同id的入出组件，协调其位置和大小，将视觉焦点从旧视图引导至新视图，且必须配合animateTo使用。适用于使用仓颉语言开发ArkUI应用的开发者，需具备基础动画知识。
