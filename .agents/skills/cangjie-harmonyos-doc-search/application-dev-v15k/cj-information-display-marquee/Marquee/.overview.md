# Marquee

This directory provides comprehensive technical documentation for the Marquee component within the ArkUI framework, specifically tailored for developers using the Cangjie programming language. It covers the complete implementation of horizontally scrolling single-line text, including detailed API references for constructors, event handling mechanisms, and property configuration. Key topics include playback control parameters, performance optimization recommendations, scrolling strategies, and lifecycle event management such as `onBounce` and `onFinish`. This resource is essential for software developers and UI engineers building dynamic applications in the ArkUI ecosystem who require precise control over text animations and component behavior.

## Detailed Description

### Marquee_4more.md Marquee_4more.md
This document serves as API reference documentation for the Marquee component in the ArkUI framework, designed to display horizontally scrolling single-line text. It covers two constructor overloads in Cangjie, detailing parameters such as start, src, step, loop, and fromStart to control playback behavior, speed, and direction. Key information includes a performance recommendation to limit Marquee instances to four to maintain frame rates, suggesting the Text component as an alternative. The document specifies that scrolling activates only when text width exceeds component width and notes full support for common attributes but no common events. This resource is intended for developers building user interfaces in Cangjie who need to implement text scrolling animations.

### 组件事件_2more.md 组件事件_2more.md
This document provides API reference documentation for event handling functions associated with a scrolling Marquee component in the Cangjie ArkUI framework. It details three specific callback functions: onBounce, onFinish, and onStart, including their syntax, parameters, and specific trigger conditions. Key information includes that onBounce triggers per scroll cycle, onFinish fires after all loops complete, and onStart activates when content changes or scrolling begins. The document also features a practical code example demonstrating how to implement these events within a UI application. This resource is intended for software developers building applications using the Cangjie language and ArkUI system capabilities, specifically those managing text scrolling animations and lifecycle events.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring text-related component properties within the ArkUI framework using the Cangjie language. It details specific functions for text styling and behavior, including allowScale, fontColor, fontFamily, fontSize, fontWeight, and marqueeUpdateStrategy. Additionally, it explains how to manage marquee scrolling strategies upon property updates. This technical reference is intended for developers implementing UI components who require precise control over text rendering and dynamic behavior.
