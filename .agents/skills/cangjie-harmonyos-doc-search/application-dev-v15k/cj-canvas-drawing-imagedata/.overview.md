# cj-canvas-drawing-imagedata

This directory provides comprehensive API reference documentation for the `ImageData` class within the Cangjie language, specifically tailored for the ArkUI framework. It serves as a technical guide for developers who need to interact directly with the pixel-level data of a canvas. The documentation covers the complete class definition, including essential read-only properties such as the data array, height, and width, which are fundamental for rendering operations. It also details the two initialization constructors that allow for the creation of ImageData objects using specific dimensions and optional unit metrics. Key technical specifications highlighted include the data property's storage of color values in the 0 to 255 range and the default use of virtual pixels for dimensions. This resource is crucial for developers engaged in image processing, custom graphical effects, or any scenario requiring the programmatic creation and manipulation of raw canvas image data, ensuring high-performance and flexible rendering capabilities within their applications.
