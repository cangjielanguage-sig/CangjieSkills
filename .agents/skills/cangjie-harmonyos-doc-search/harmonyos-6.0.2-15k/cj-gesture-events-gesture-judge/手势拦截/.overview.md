# 手势拦截

This directory provides a comprehensive technical guide on gesture interception mechanisms within the HarmonyOS and ArkUI ecosystems. It addresses the resolution of gesture conflicts, particularly in complex UI layouts involving nested scrolling and overlapping components. The content covers two primary strategies: Gesture Trigger Control and Gesture Response Control. Key topics include event flow management, gesture arbitration, and dynamic state enabling using ArkTS and Cangjie. It is intended for developers and UI engineers seeking to optimize interaction ranges and ensure precise gesture execution in sophisticated applications.

## Detailed Description

### 手势拦截.md 手势拦截.md
This technical guide explains gesture interception, a mechanism designed to resolve gesture conflicts and ensure gestures execute as intended. The document outlines typical use cases such as nested scrolling and optimizing interaction ranges by filtering component responses. It details two primary implementation strategies: Gesture Trigger Control and Gesture Response Control. Key information focuses on how these methods manage event flow to improve user experience. Intended for developers working on complex UI layouts, this guide provides essential concepts for handling advanced touch interactions and event distribution.

### 手势响应控制/
This directory focuses on advanced gesture response control mechanisms within the ArkUI framework, specifically addressing complex scenarios like nested scrolling and gesture conflicts. It covers technical implementations using ArkTS and Cangjie, detailing APIs such as `shouldBuiltInRecognizerParallelWith` and `onGestureRecognizerJudgeBegin` to manage gesture arbitration, parallelism, and dynamic state enabling. The content is designed for developers building sophisticated user interfaces on HarmonyOS or OpenHarmony who need to resolve interaction issues between overlapping scrollable components and customize gesture behaviors.

### 手势触发控制/
This directory focuses on the advanced mechanism of gesture trigger control within the HarmonyOS development ecosystem. It provides comprehensive resources for developers looking to implement custom logic for intercepting or allowing gestures, specifically after system thresholds have been satisfied. The content covers essential definitions of gesture interception, introduces critical APIs such as `onGestureJudgeBegin` and `onGestureRecognizerJudgeBegin`, and offers practical code examples in the Cangjie language. It is particularly suitable for HarmonyOS developers and UI engineers who require fine-grained control over gesture conflicts, event passing, and recognition logic in complex, multi-layered UI layouts using ArkUI.
