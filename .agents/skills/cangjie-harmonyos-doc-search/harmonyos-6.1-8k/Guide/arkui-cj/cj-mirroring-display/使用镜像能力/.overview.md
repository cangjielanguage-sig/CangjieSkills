# 使用镜像能力

本目录包含关于ArkUI框架镜像能力的开发文档，旨在帮助开发者实现从右向左（RTL）的UI布局适配。内容涵盖了镜像能力的基本概念、生效条件、以及组件的适配现状与使用约束。通过查阅这些文档，开发者可以了解如何利用direction属性触发镜像，识别已自动适配的组件，并掌握在布局和边框设置中使用start/end等泛化方向词的方法。这些资料适合需要进行国际化应用开发，特别是针对阿拉伯语、希伯来语等RTL语言区域进行UI适配的ArkUI开发者。

## 详细描述

### 使用约束.md
这份文档旨在说明ArkUI框架在镜像能力方面的适配现状与使用约束。文档详细列出了已默认适配镜像的基础组件（如Swiper、List）、高级组件、通用属性及接口。同时指出了仍需开发者进行适配的场景：在涉及界面布局和边框设置时，需使用start/end等泛化方向词替代left/right等绝对方向词以实现自适应镜像；Canvas组件目前仅有限支持文本绘制的镜像。这是一份面向开发者的参考指南，帮助其快速识别已支持镜像的功能及正确处理未适配的布局场景。

### 使用镜像能力_3more_134c3945.md
本文档介绍了ArkUI框架的镜像能力，旨在通过X轴水平翻转显示内容，以支持从右向左的阅读习惯。主要涵盖功能概述及效果对比、镜像能力生效的具体条件，以及LTR和RTL的基本概念定义。关键点在于镜像能力仅在组件direction属性设为Rtl，或设为Auto且系统语言为RTL（如维吾尔语）时生效。面向需要进行国际化适配或针对特定语言区域调整UI布局的ArkUI开发者。
