# ohoscert证书模块

This module provides comprehensive API reference documentation for the OpenHarmony Cangjie certificate framework, focusing on X.509 digital certificate management, Certificate Revocation Lists (CRLs), and chain validation. It covers essential classes, enums, and functions for parsing, validating, and building certificate chains, handling extensions, and managing trust anchors. Designed for security developers and system architects, the documentation assumes familiarity with cryptographic standards and the Cangjie programming language. It supports the SystemCapability.Security.Cert capability, enabling robust implementation of security features in OpenHarmony applications.

## Detailed Description

### Files

*   **class_CertCRLCollection.md class_CertCRLCollection.md**
    Manages X.509 certificate and CRL collections, offering methods to filter and retrieve specific items based on match parameters.

*   **class_CertChainBuildParameters.md class_CertChainBuildParameters.md**
    Specifies parameters for building certificate chains, including filtering criteria, validation rules, and maximum chain length.

*   **class_CertChainBuildResult_2more.md class_CertChainBuildResult_2more.md**
    Defines classes for handling chain building results and structuring input data, featuring read-only properties and specific byte formats.

*   **class_CertChainValidationParameters.md class_CertChainValidationParameters.md**
    Configures parameters for certificate chain validation, allowing developers to set trust anchors, revocation checks, and key usage rules.

*   **class_CertChainValidationR_2more.md class_CertChainValidationR_2more.md**
    Handles X509 certificate chain validation, storing results and verifying chains while excluding time validity checks.

*   **class_CertResult.md class_CertResult.md**
    Defines result codes for certificate operations, categorizing success, parameter errors, and specific cryptographic failures.

*   **class_DataBlob_3more.md class_DataBlob_3more.md**
    Documents data structures for buffer arrays (DataBlob), formatted binary data (EncodingBlob), and subject information (GeneralName).

*   **class_EncodingFormat.md class_EncodingFormat.md**
    Defines constants for encoding formats used in security operations, specifically FORMAT_DER, FORMAT_PEM, and FORMAT_PKCS7.

*   **class_RevocationCheckParameter.md class_RevocationCheckParameter.md**
    Encapsulates parameters for verifying certificate revocation status, supporting both OCSP and CRL mechanisms with configurable options.

*   **class_X500DistinguishedName.md class_X500DistinguishedName.md**
    Handles X.509 defined Name objects, providing methods to retrieve distinguished names, attributes, and encoded serialized data.

*   **class_X509CRLMatchParameters.md class_X509CRLMatchParameters.md**
    Defines filtering criteria for matching X.509 CRLs, with optional properties for issuer, certificate, and date limits.

*   **class_X509TrustAnchor.md class_X509TrustAnchor.md**
    Represents trust anchors for validating X509 certificate chains, with properties for CA certificates, public keys, and name constraints.

*   **enum_CertItemType.md enum_CertItemType.md**
    Specifies fields for retrieving certificate data components like public keys, extensions, and unique IDs.

*   **enum_EncodingType.md enum_EncodingType.md**
    Represents encoding formats for X509 certificate subject names, currently defining ENCODING_UTF8.

*   **enum_ExtensionEntryType.md enum_ExtensionEntryType.md**
    Represents object types within security certificate extension fields, such as ENTRY, ENTRY_CRITICAL, and ENTRY_VALUE.

*   **enum_ExtensionOidType.md enum_ExtensionOidType.md**
    Used for filtering Object Identifiers within certificate extension fields, with values like ALL, CRITICAL, and UNCRITICAL.

*   **enum_GeneralNameType.md enum_GeneralNameType.md**
    Represents certificate subject usage types, including DNS names, IP addresses, and email addresses.

*   **enum_KeyUsageType.md enum_KeyUsageType.md**
    Specifies permitted key usage within digital certificates, covering functions like digital signatures and key encipherment.

*   **enum_RevocationCheckOptions.md enum_RevocationCheckOptions.md**
    Configures certificate revocation status checks, offering options to prioritize OCSP or enable network access.

*   **enum_ValidationPolicyType.md enum_ValidationPolicyType.md**
    Specifies strategies for online certificate chain validation, distinguishing between X509 and SSL policies.

*   **func_createCertCRLCollecti_3more.md func_createCertCRLCollecti_3more.md**
    Outlines functions for creating certificate collections, PKIX validators, and extension objects from encoded data.

*   **func_createTrustAnchorsWit_2more.md func_createTrustAnchorsWit_2more.md**
    Details functions for constructing trust anchor arrays from P12 files and generating distinguished name objects.

*   **func_createX500Distinguish_3more.md func_createX500Distinguish_3more.md**
    Factory functions for creating X.509 security objects like distinguished names, CRLs, and certificates from byte arrays.

*   **func_createX509CertChainEn_2more.md func_createX509CertChainEn_2more.md**
    Overloaded functions for creating X509 certificate chain objects from serialized data or existing certificate arrays.

*   **ohoscert证书模块_4more.md ohoscert证书模块_4more.md**
