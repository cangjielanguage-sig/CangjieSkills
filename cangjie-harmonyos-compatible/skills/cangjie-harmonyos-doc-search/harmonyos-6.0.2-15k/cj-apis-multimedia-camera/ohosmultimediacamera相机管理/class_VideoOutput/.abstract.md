This directory contains API reference documentation for the `VideoOutput` class within the Cangjie CameraKit framework. It covers the management of video recording sessions, including configuration, lifecycle control, event handling, and resource management. Key topics include frame rate settings, video profiles, rotation calculations, and callback registration for recording states and errors. This documentation is intended for software developers and application engineers building multimedia applications using the Cangjie language on HarmonyOS, providing the necessary technical details to integrate robust video recording capabilities.
