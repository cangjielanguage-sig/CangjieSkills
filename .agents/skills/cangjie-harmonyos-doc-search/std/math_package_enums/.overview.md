# math_package_enums

This directory serves as the definitive API reference for the `RoundingMode` enumeration within the Cangjie math package, acting as a critical resource for developers handling complex numerical data. It meticulously defines the rules governing numerical rounding operations, offering six distinct strategies that balance between standard IEEE 754 modes and the widely adopted HalfUp rule. The documentation is designed to resolve precision ambiguity by providing a clear comparison table that demonstrates exactly how different decimal values are processed across various modes. It also offers detailed textual descriptions for each mode—Ceiling, Down, Floor, HalfEven, HalfUp, and Up—alongside complete documentation for essential utility functions like `toString` and equality operators. This resource is indispensable for developers, particularly those in financial engineering or scientific computing, who require exact, predictable, and standardized control over numerical precision in their Cangjie applications.
