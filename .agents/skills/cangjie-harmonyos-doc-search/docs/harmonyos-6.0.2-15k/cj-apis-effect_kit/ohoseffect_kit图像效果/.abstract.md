This directory contains API reference documentation for the `ohos.effect_kit` module, focusing on image processing and visual effects in the Cangjie programming language. It covers essential functionalities such as creating filter chains, handling color data, and implementing smart color picking from PixelMaps. Key components include the `Filter` class for effects like blur and brightness, and the `ColorPicker` class for color analysis. This documentation is suitable for HarmonyOS developers using the ImageKit and ArkGraphics2D frameworks to build multimedia applications requiring advanced image manipulation and color extraction features.
