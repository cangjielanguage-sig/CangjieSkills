This directory provides comprehensive documentation for the `PerformanceTiming` class, a specialized tool within the Cangjie language ecosystem designed for the NetworkKit framework. It focuses on the precise capture and analysis of HTTP request performance metrics, enabling developers to gain deep insights into network behavior. The content covers a wide range of critical network stages, including DNS resolution, TCP connection establishment, TLS handshake execution, redirect management, and response processing. By utilizing read-only properties of type Float64, the class allows for accurate measurement of time durations starting from the initial request. This documentation is essential for software engineers and system architects who need to diagnose network latency issues, optimize application throughput, and ensure robust communication capabilities. It also details the class inheritance from `ToString` and the specific system capabilities required for deployment. Implementation of this class requires the SystemCapability.Communication.NetStack capability to be present in the system environment.
