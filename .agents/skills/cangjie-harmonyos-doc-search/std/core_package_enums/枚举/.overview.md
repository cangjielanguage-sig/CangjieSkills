## Detailed Description

### enum_AnnotationKind_2more.md enum_AnnotationKind_2more.md
This API reference document details two core enumerations in the Cangjie language: AnnotationKind and Endian. The AnnotationKind enum specifies the valid targets for custom annotations, listing options such as Type, Parameter, Init, MemberFunction, and Extension. The Endian enum defines byte order modes, specifically Big and Little, and includes a static Platform property to detect the runtime environment's endianness, potentially throwing an UnsupportedException. Key takeaways include understanding annotation targets and platform-specific byte order detection. This documentation targets developers working with system-level features or custom metadata, requiring knowledge of basic programming concepts and the Cangjie syntax.

### enum_Ordering.md enum_Ordering.md
This API reference document defines the Ordering enum in the Cangjie programming language, used to represent comparison results. It details the three enum variants—LT, GT, and EQ—and their implementation of the Comparable, Hashable, and ToString interfaces. Key information includes the comparison hierarchy where GT is greater than EQ, which is greater than LT, specific hash code assignments, and string conversion methods. This documentation serves Cangjie developers who need to handle comparison operations and utilize standard library types.
