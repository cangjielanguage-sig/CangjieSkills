# cj-unpacking-tool

The `cj-unpacking-tool` directory serves as a central repository for a robust utility tailored specifically for the HarmonyOS operating system environment. This tool is engineered to facilitate the decompression, inspection, and analysis of various application package formats, including HAP (HarmonyOS Ability Package), HSP (HarmonyOS Shared Package), standard App packages, and APPQF files. By offering both a command-line interface (CLI) and a Java-based API, the project provides flexible integration options for different workflows, ranging from quick manual checks to automated build pipelines. It is primarily designed for HarmonyOS developers, application market engineers, and system integrators who require deep access to package internals for tasks such as extracting configuration metadata, debugging application structures, or ensuring compliance with system standards. The tool enables users to programmatically parse package contents, making it an essential asset for development, testing, and quality assurance processes within the HarmonyOS ecosystem.

### 拆包工具/
This subdirectory acts as the comprehensive documentation hub for the HarmonyOS Unpacking Tool, a specialized utility designed to facilitate the decompression and analysis of various HarmonyOS-specific package formats. The documentation provides in-depth guidance on handling HAP (HarmonyOS Ability Package), HSP (HarmonyOS Shared Package), standard App packages, and APPQF files. It thoroughly covers two primary modes of operation: command-line usage for efficient, script-based extraction and analysis, and Java API integration for embedding the tool's capabilities directly into custom software solutions.

The content includes extensive interface references, specific command instructions, and detailed data structure schemas for various package components. These resources enable users to effectively extract configuration metadata and debug application structures with precision. This documentation is particularly suitable for HarmonyOS developers, application market engineers, and system integrators who need to programmatically parse package contents or rigorously inspect internal metadata. Whether the goal is to verify package integrity, understand internal dependencies, or automate the processing of application uploads, this directory provides the necessary technical specifications and usage examples to achieve those objectives. By bridging the gap between raw package data and readable metadata, the tool simplifies the complexities of HarmonyOS package management.
