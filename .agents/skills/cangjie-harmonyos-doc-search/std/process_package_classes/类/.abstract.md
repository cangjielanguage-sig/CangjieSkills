This directory contains API reference documentation for process management classes within the Cangjie programming language. It covers the creation, control, and monitoring of system processes, including the main process, child processes, and subprocesses. Key topics include process lifecycle management, environment variable handling, standard I/O stream redirection, and inter-process communication. The documentation also addresses deprecated APIs and legacy behaviors. It is suitable for Cangjie developers working on system programming, application automation, and operating system interaction who need robust tools for process control and data stream management.
