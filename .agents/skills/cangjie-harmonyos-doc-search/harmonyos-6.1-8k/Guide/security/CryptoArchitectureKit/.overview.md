# CryptoArchitectureKit

The CryptoArchitectureKit is a comprehensive cryptographic framework designed for the Cangjie programming language, providing developers with essential tools for encryption, decryption, and data security. It covers a wide range of algorithms including AES, 3DES, SM4, SHA256, MD5, and MAC, supporting various modes like ECB, CBC, GCM, and CCM. The kit facilitates key generation, conversion, and segmented processing for large data volumes. It is currently in Beta and is ideal for developers integrating security features into HarmonyOS or Cangjie-based applications, offering detailed API documentation and implementation guides to ensure data confidentiality and integrity.

## Detailed Description

### [1] README_zh
This directory serves as the Chinese navigation index for the Crypto Architecture Kit. It provides a comprehensive entry point for developers, covering key generation, conversion, various encryption and decryption algorithms (AES, 3DES, SM4), message digests (SHA256, MD5), MAC, and secure random number generation. All features are currently in Beta.

### [2] cj-crypto-3des-sym-encrypt-decrypt-ecb
This directory serves as a comprehensive technical resource dedicated to the implementation of 3DES (Triple Data Encryption Standard) symmetric encryption and decryption using the Electronic Codebook (ECB) mode. It is specifically designed for developers working within the Cangjie ecosystem.

### [3] cj-crypto-aes-sym-encrypt-decrypt-cbc
This directory serves as a specialized technical repository focused on the implementation of AES (Advanced Encryption Standard) symmetric encryption and decryption utilizing the CBC (Cipher Block Chaining) mode, specifically tailored for the Cangjie programming language.

### [4] cj-crypto-aes-sym-encrypt-decrypt-ccm
This directory provides a specialized technical guide focused on the implementation of AES symmetric encryption using the CCM (Counter with CBC-MAC) mode, specifically designed for the Cangjie programming language. It serves as a comprehensive resource for developers.

### [5] cj-crypto-aes-sym-encrypt-decrypt-ecb
This directory serves as a comprehensive technical guide for implementing AES symmetric encryption and decryption using the Electronic Codebook (ECB) mode, specifically tailored for the HarmonyOS ecosystem. It is designed for developers utilizing the Cangjie language.
