This directory serves as a comprehensive repository for API reference documentation regarding exception handling within an HTTP package, specifically tailored for the Cangjie programming language. It covers a wide array of specific error scenarios through six defined exception classes: ConnectionException, CoroutinePoolRejectException, HttpException, HttpStatusException, HttpTimeoutException, and WebSocketException. The content provides detailed insights into class definitions, their inheritance hierarchies—mostly deriving from Exception or IOException—and the necessary constructor parameters for each. It specifically notes that HttpStatusException uniquely requires a status code and message, while others generally need only a message. This documentation is highly suitable for software developers and engineers integrating HTTP or WebSocket protocols who require precise mechanisms to implement robust error handling and manage complex network or protocol failures.
