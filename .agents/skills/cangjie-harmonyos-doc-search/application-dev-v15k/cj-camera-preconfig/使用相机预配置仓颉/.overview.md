# 使用相机预配置仓颉

This directory provides a comprehensive guide and resources for using the Camera Preconfiguration feature in the Cangjie programming language within the HarmonyOS ecosystem. It covers the streamlined workflow for camera application development, contrasting standard complex configurations with simplified pre-integrated settings for common scenarios like photo and video capture. Key topics include CameraKit API usage, session management, hardware compatibility checks, and resolution specifications. This collection is suitable for application developers seeking to implement custom camera interfaces efficiently without the overhead of professional-grade API implementation, offering both theoretical specifications and practical code examples.

## Detailed Description

### 使用相机预配置仓颉.md 使用相机预配置仓颉.md
This guide introduces the Camera Preconfiguration feature in Cangjie to streamline camera application development by offering pre-integrated settings for common scenarios. It contrasts the tedious standard workflow of querying capabilities and parsing profiles with the simplified preconfig interface for PhotoSession and VideoSession. Key takeaways include using the preconfig function to quickly generate necessary output configurations without manual data filtering. The document targets developers seeking custom camera interfaces without the complexity of professional-grade development, distinguishing this method from system camera usage or full API implementation.

### 开发步骤.md 开发步骤.md
This document provides a step-by-step tutorial for developing camera applications using the CameraKit API in the Cangjie language. It covers importing interfaces, creating input and output streams, and initializing camera sessions. Key steps include using CameraManager to handle camera inputs, utilizing XComponent for preview surfaces, and implementing Preconfig capabilities for performance optimization. The guide details the session configuration workflow, specifically how to add inputs and outputs and commit configurations. It targets application developers seeking to implement photo or video capture functionality, requiring knowledge of Cangjie syntax and UI components.

### 规格说明.md 规格说明.md
This reference document outlines camera output specifications for the CameraKit system, defining four preconfiguration types and three aspect ratios. It details specific resolution outputs for preview, photo capture, and video recording across normal photo and video modes through comprehensive tables. A critical requirement is the use of the `canPreconfig` function to verify device compatibility before applying settings, as hardware capabilities vary. The document also notes that certain configurations default to the sensor's maximum capability. This guide is intended for developers integrating camera features who need to understand resolution mappings and ensure hardware compatibility.

### 完整示例/
This directory contains comprehensive code examples designed to guide developers through the complete implementation of camera functionality within HarmonyOS applications. It covers the entire spectrum of camera operations, ranging from the initial setup of the CameraManager and the configuration of inputs and outputs to the detailed management of the photo capture lifecycle. Key topics include defining callback classes for robust error handling, creating and configuring PhotoSessions, managing preview and photo streams, and adjusting hardware-specific settings like flash, focus, and zoom ratios. Additionally, the examples emphasize the critical importance of resource management and hardware capability checks to ensure application stability. This collection is suitable for HarmonyOS developers working with Cangjie or ArkTS who require practical, end-to-end references for integrating complex camera features into their software projects.
