# cj-universal-gesture-rotationgesture

This directory contains essential API reference documentation for the RotationGesture component, specifically developed for the Cangjie language within the ArkUI framework. It focuses on enabling developers to handle complex multi-touch rotation interactions efficiently. The documentation covers the complete setup of the component, including initialization parameters such as finger count (supporting 2 to 5 fingers) and angle sensitivity settings. Furthermore, it details the event callbacks associated with the gesture lifecycle—start, update, end, and cancellation—allowing for precise tracking of rotation changes via GestureEvent objects. This resource is ideal for Cangjie developers seeking to implement intuitive touch-based rotation controls in their applications, featuring a practical code example of a rotating text element.
