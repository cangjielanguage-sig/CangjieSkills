# cj-apis-multimedia-audio_haptic

This directory serves as the central repository for API reference documentation regarding the HarmonyOS Audio-Haptic Kit, specifically tailored for the Cangjie programming language. It addresses the technical challenges and methodologies involved in synchronizing audio playback with haptic feedback, a crucial capability for creating immersive and responsive user experiences. The documentation provides an in-depth look at the architecture and usage of core classes such as `AudioHapticManager` and `AudioHapticPlayer`. It is intended for software developers and multimedia engineers who are building applications that require precise, low-latency coordination between sound and vibration. The content covers a wide array of topics, including resource management strategies, the complete playback lifecycle, event handling mechanisms, and specific configuration options like independent audio/haptic muting and stream type settings. Furthermore, it outlines the necessary system capability requirements, noting that these features are supported starting from API version 19.
