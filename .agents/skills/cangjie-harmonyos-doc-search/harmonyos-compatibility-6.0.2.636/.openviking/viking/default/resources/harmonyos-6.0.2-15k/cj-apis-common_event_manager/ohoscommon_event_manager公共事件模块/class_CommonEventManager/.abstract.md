This directory contains API reference documentation for the `CommonEventManager` class within the Cangjie programming language and HarmonyOS ecosystem. It focuses on managing public common events, enabling inter-process communication (IPC) and system event monitoring. The documentation covers essential static methods for creating subscribers, publishing events with various data types, and unsubscribing from event streams. It includes detailed parameter descriptions, return values, and exception handling logic. This resource is suitable for application developers and system engineers working with the BasicServicesKit to implement robust notification features and event-driven architectures in HarmonyOS applications.
