This resource is ideal for application developers looking to refine the user experience of selection controls in their mobile applications.

The following files provide in-depth code examples and explanations for specific TextPicker features in Cangjie.

### 示例1设置选择器列数_4more.md 示例1设置选择器列数_4more.md
This document provides practical code examples for configuring and styling the TextPicker component in Cangjie for HarmonyOS development. It covers four distinct scenarios: setting up a basic selector with event handling, customizing text styles for selected and unselected items, removing divider lines, and configuring custom divider styles. The examples demonstrate the use of properties like textStyle, selectedTextStyle, and divider with DividerOptions to control appearance, including font weight, color, and stroke width. This guide targets application developers using the Cangjie language who need to implement and customize text selection interfaces in their UI layouts.

### 示例5设置渐隐效果.md 示例5设置渐隐效果.md
This document serves as a code example demonstrating how to implement a gradient fade effect for a TextPicker component in the Cangjie programming language. The content focuses on the usage of the gradientHeight modifier within a UI component structure, specifically applied to a TextPicker inside a Column. The key takeaway is the syntax .gradientHeight(100), which customizes the height of the fade effect. The code also illustrates basic state management with @State and event handling via onChange. This example is intended for developers building HarmonyOS applications using the Cangjie language who need to customize the visual appearance of picker components. Keywords: Cangjie, TextPicker, gradientHeight, UI, HarmonyOS.
