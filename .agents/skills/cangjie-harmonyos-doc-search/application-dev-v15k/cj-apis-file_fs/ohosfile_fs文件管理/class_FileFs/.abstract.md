This directory contains API reference documentation for the Cangjie `FileFs` class, a utility designed for comprehensive file system management. It covers a wide range of static methods for file and directory operations, including reading, writing, copying, moving, and deleting files. The documentation also details functions for checking permissions, managing file attributes, handling file descriptors, and monitoring file system changes. Intended for Cangjie developers, these resources provide syntax, parameters, error codes, and code examples necessary for implementing robust file I/O features within application sandboxes using the CoreFileKit.
