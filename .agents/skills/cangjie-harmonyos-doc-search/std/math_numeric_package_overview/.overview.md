# math_numeric_package_overview

This directory provides the essential API overview for the `std.math.numeric` package in the Cangjie language, designed to significantly extend mathematical capabilities beyond basic types. It focuses on providing robust support for arbitrary-precision integers (BigInt) and high-precision decimals (Decimal), enabling complex numerical computations. The content covers a wide range of common mathematical operations, including absolute values, GCD, square roots, and binary manipulation. Furthermore, it details critical implementation aspects such as rounding modes, overflow strategies, and type conversions. This resource is specifically suitable for developers and engineers who require high-precision numerical computations for advanced applications and serves as a comprehensive reference guide for the available mathematical utilities. Key features include struct definitions for core data types and enumerations for handling overflow scenarios efficiently.
