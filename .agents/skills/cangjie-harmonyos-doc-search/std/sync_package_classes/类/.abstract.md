This directory contains API reference documentation for synchronization and concurrency classes in the Cangjie programming language. It covers high-level coordination primitives like Mutexes, Barriers, Semaphores, and Timers, as well as low-level atomic operations for various integer types and references. The documentation includes both active classes and deprecated legacy components, guiding developers on thread-safe programming, resource management, and lock-free algorithms. It is suitable for software developers and systems programmers building multi-threaded applications who need to manage shared state, coordinate execution, or implement efficient synchronization mechanisms.
