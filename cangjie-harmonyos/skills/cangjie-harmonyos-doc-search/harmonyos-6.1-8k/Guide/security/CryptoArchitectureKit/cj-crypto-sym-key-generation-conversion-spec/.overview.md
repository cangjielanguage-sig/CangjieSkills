## 详细描述

### cj-crypto-sym-key-generation-conversion-spec.md cj-crypto-sym-key-generation-conversion-spec.md

本文档定义了系统支持的对称密钥生成算法及其规格，旨在指导开发者通过字符串参数生成特定密钥。文档详细介绍了AES、3DES、SM4及HMAC四种算法，列出了各算法支持的密钥长度、对应的字符串参数格式（如AES128、SM4_128、HMAC|SHA256）及API版本要求（12+）。关键内容包括各算法的基本特点、参数拼接规则及密钥长度限制。这是一份面向开发者的技术参考文档，适用于需要集成加密密钥生成功能的开发场景。
