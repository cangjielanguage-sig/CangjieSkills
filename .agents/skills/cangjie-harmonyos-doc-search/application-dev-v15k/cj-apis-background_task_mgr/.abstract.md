This directory contains the complete API reference documentation for the `cj-apis-background_task_mgr` module, specifically designed for the Cangjie programming language within the HarmonyOS ecosystem. It addresses the critical technical challenge of background task management, providing developers with the tools to prevent application suspension during essential operations. The documentation encompasses a wide range of functionalities, including the configuration of long-running task modes for continuous activities like audio playback and location services, as well as the implementation of short-time delay tasks that can run for up to 3 minutes. It also provides detailed guidance on task lifecycle management, such as cancellation and time retrieval. This resource is tailored for Cangjie developers who require a deep understanding of background execution logic to ensure application continuity, handle transient tasks effectively, and comply with strict system resource constraints and API 12+ version standards. By utilizing these APIs, developers can optimize battery life and performance while delivering a seamless user experience.
