This directory contains a specialized technical guide focused on the ArkUI Environment singleton within the Cangjie development ecosystem. It comprehensively covers the methodologies for querying and utilizing device parameters—such as system language, color mode, font scale, and layout direction—to facilitate adaptive application behavior. The guide details the architectural flow where Environment writes read-only system variables into AppStorage, making them accessible to developers through `Environment.envProp`, `@StorageProp`, or `AppStorage.prop`. It explains the critical update chain from Environment to AppStorage and finally to the Component. This resource is specifically tailored for Cangjie developers aiming to synchronize their UI components and application logic with dynamic system states, though it requires a solid foundational knowledge of AppStorage.
