# 常用命令

This directory serves as a comprehensive resource for the `hitrace` command-line tool within the HarmonyOS development environment. It focuses on system performance tracing, offering guidance on capturing, managing, and analyzing trace data via the hdc shell. The documentation covers a wide range of functionalities, from basic command syntax and tag configuration to advanced data management techniques like snapshot mode and compression. Core keywords include system performance, trace recording, buffer configuration, and debugging. These guides are specifically tailored for software developers, QA engineers, and system performance analysts who require precise tools for monitoring application behavior, diagnosing system issues, and optimizing performance using visualization tools like HiSmartPerf.

## Detailed Description

### 常用命令_1.md 常用命令_1.md
This document serves as a technical reference guide for using the hitrace command within the hdc shell to capture system performance traces. It details the procedures for listing available trace tags, starting and stopping trace recording sessions, and configuring capture parameters like buffer size and duration. Key takeaways include the ability to target specific modules such as app or ability using tags and export trace data to specified file paths. Intended for developers and QA engineers, this guide provides essential command syntax and usage examples for debugging and analyzing HarmonyOS system behavior.

### 常用命令_2.md 常用命令_2.md
This document serves as a practical reference guide for the hitrace command-line tool, focusing on advanced trace data management and capture modes. It covers dumping trace information to the console or specific files, utilizing snapshot mode for background tracing (start, dump, stop), and compressing output data. Additionally, it explains setting the trace clock to boot time and ending capture sessions without saving data. Key takeaways include default output paths and integration with the HiSmartPerf visualization tool. This guide is intended for system developers and performance analysts requiring detailed system behavior tracking and debugging capabilities.
