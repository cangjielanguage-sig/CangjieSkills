## Detailed Description

### 功能介绍.md 功能介绍.md
This document introduces the `reflect` package in the Cangjie programming language, detailing its capabilities for runtime type inspection and manipulation. It covers the package's core functionality, platform compatibility, and specific visibility constraints for global and member information. Key takeaways include the lack of macOS support, the restriction to `public` visibility for external access, and the current exclusion of function, tuple, and enum types. This reference guide targets Cangjie developers who need to implement dynamic runtime behavior while understanding strict access control limitations. Keywords: Cangjie, reflection, runtime, visibility, type inspection.
