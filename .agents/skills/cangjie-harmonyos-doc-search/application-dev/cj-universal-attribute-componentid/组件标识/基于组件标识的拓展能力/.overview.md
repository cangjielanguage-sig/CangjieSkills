# 基于组件标识的拓展能力

This directory provides a comprehensive overview of extension capabilities based on component identifiers within the Cangjie ArkUI framework. It focuses on API references that enable UI component inspection, event simulation, and the retrieval of component trees. These functionalities are strictly designed for application testing, offering developers the tools to programmatically inspect attributes and simulate interactions like touch, keyboard, and mouse events. Key topics include component attribute retrieval, JSON parsing, and automated event triggering. This documentation is highly suitable for developers and QA engineers who are building automated test scripts and performing UI validation for ArkUI applications.

## Detailed Description

### func_getInspectorByKeyStri_5more.md
This API reference document outlines testing-specific functions for the Cangjie ArkUI framework, enabling UI component inspection and event simulation. The content covers five primary functions: retrieving component attributes via ID, obtaining the full component tree, and sending events by ID, touch, or keyboard. Key takeaways include that all interfaces are designed strictly for application testing, carry significant performance overhead, and require main thread execution for accurate JSON attribute retrieval. This documentation targets developers and QA engineers creating automated test scripts for ArkUI applications.

### func_sendMouseEventMouseEvent.md
This document serves as API reference material for the Cangjie function sendMouseEvent, designed to simulate mouse interactions specifically for application testing. The content details the function signature, system capabilities, and version requirements, while defining the required MouseEvent parameter and Bool return value. Key takeaways include the explicit warning that this interface is time-consuming and intended solely for testing scenarios, not production use. Targeted at ArkUI developers, this documentation aids in understanding how to programmatically trigger mouse events for UI automation and validation purposes.
