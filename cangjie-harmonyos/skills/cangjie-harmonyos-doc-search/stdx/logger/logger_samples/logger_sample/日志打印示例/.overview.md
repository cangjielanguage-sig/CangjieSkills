# 日志打印示例

本目录包含仓颉语言的日志打印代码示例，旨在帮助开发者掌握高效的日志记录技巧。内容涵盖了 JsonLogger、SimpleLogger 和 TextLogger 的配置与使用，详细演示了日志级别设置、结构化日志输出、多线程并发记录以及通过 Lambda 表达式实现延迟求值以优化性能。此外，还包含复杂数据结构序列化和源码位置信息获取的示例。适合需要在仓颉项目中集成结构化日志系统、关注程序性能及并发安全的开发者参考。

## 详细描述

### 日志打印示例_1.md
本文档旨在演示如何在仓颉语言中使用 JsonLogger 类进行日志打印。主要内容包括配置全局日志器、设置日志级别、并发环境下的日志记录，以及通过 Lambda 表达式实现延迟求值以降低性能损耗。文档详细展示了记录复杂数据结构、自定义对象及源码属性的方法，并附带了对应的 JSON 输出结果。这是一份面向仓颉开发者的代码示例教程，适合需要实现结构化日志记录的应用程序开发者参考。

### 日志打印示例_2.md
本文档是仓颉语言的日志打印代码示例教程，旨在演示 stdx.log 和 stdx.logger 库的使用方法。主要涵盖 SimpleLogger 和 TextLogger 的配置，展示了不同日志级别（如 TRACE、INFO、ERROR）的调用。文档重点介绍了结构化日志（键值对）、延迟计算日志以优化性能、以及多线程并发日志记录。此外，还涉及自定义 LogValue 和源码位置信息获取。适合具备仓颉基础语法的开发者，用于学习在实际项目中集成高效的日志系统。

### 日志打印示例_3.md
本文档旨在演示如何在并发编程环境中使用日志库，重点展示了结构化日志记录与性能优化技巧。主要内容包括多线程环境下的日志调用、不同日志级别（INFO、DEBUG、TRACE、ERROR）的使用方法，以及复杂数据类型（如HashMap和数组）的序列化输出。文档详细介绍了通过Lambda表达式和ToStringWrapper实现延迟计算，从而在日志级别未开启时避免不必要的性能开销，并演示了如何自动记录源码位置信息。这是一份面向开发者的代码示例教程，适合需要掌握高效日志记录、关注程序性能及并发安全的用户参考。
