# 开发步骤

This directory serves as a technical resource for developers implementing camera functionality using the Cangjie language and the CameraKit framework. It provides a structured approach to multimedia development, covering the entire lifecycle of camera session management. Key topics include the initialization of PhotoSessions, configuration of inputs and outputs, and the dynamic switching between different capture modes such as photo and video. The documentation also highlights best practices for session control, error handling, and logging. These guides are specifically designed for software developers who have a prerequisite knowledge of Cangjie syntax and are seeking to integrate robust camera features into their applications.

## Detailed Description

### 开发步骤_1.md
This document provides a step-by-step tutorial for developing camera functionality using the Cangjie language and CameraKit. It covers importing necessary interfaces, creating and configuring a PhotoSession, and enabling the session by adding camera inputs and outputs like preview and photo streams. Key operations include createSession, beginConfig, addInput, addOutput, commitConfig, and start. Additionally, it explains session control techniques, such as stopping the session and switching between modes (e.g., from photo to video) by dynamically removing and adding outputs. This guide targets software developers with prerequisite knowledge of Cangjie syntax and multimedia application development.

### 开发步骤_2.md
This document serves as a technical tutorial snippet demonstrating how to reconfigure a camera session to switch from photo to video output. The content focuses on session management, specifically the sequence of beginning configuration, removing the photo output stream, and adding the video output stream. Key information includes the implementation of robust error handling using try-catch blocks for BusinessException and logging errors via Hilog. This code is intended for application developers working on camera functionality who need to dynamically manage output streams within a session.
