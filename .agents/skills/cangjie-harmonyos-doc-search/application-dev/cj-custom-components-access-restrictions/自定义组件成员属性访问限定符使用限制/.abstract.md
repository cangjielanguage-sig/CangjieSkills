This document collection provides a comprehensive technical guide on the usage restrictions and initialization rules for access qualifiers on custom component member properties within the Cangjie ArkUI framework. It covers the intricate compatibility requirements between access modifiers (such as `private` and `public`) and state management decorators (including `@State`, `@Link`, `@Prop`, `@StorageLink`, and `@Consume`). Key topics include external initialization constraints, validation rules, and compiler error prevention. By distinguishing between decorators that permit external initialization and those that forbid local initialization, this resource is essential for Cangjie developers and component architects aiming to ensure robust state management, adhere to framework standards, and avoid syntax pitfalls during application development.
