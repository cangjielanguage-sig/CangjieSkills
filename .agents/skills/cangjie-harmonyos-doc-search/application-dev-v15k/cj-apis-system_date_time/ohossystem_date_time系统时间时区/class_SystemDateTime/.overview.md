# class_SystemDateTime

This directory contains essential API reference documentation for the `SystemDateTime` class within the Cangjie programming language, specifically designed for developers utilizing the BasicServicesKit. It provides a detailed overview of methods required for retrieving system time, calculating uptime metrics, and managing timezone information. The content covers critical static functions such as `getCurrentTime`, `getTime`, `getRealActiveTime`, `getRealTime`, `getTimezone`, and `getUptime`. Key features include the ability to toggle between millisecond and nanosecond precision, distinct handling of Unix epoch time versus system uptime, and specific logic for deep sleep periods. This documentation is suitable for application developers who need to implement precise time measurement, track system state, or handle localization in their Cangjie applications, assuming a working knowledge of Cangjie syntax and exception handling.

### class_SystemDateTime_5more.md
This document serves as API reference documentation for the SystemDateTime class in the Cangjie programming language, detailing methods for retrieving system time and uptime metrics.
