# 使用Web组件的PDF文档预览能力

本目录介绍了在ArkUI应用中利用Web组件实现PDF文档预览的完整方案。内容涵盖了从基础配置、不同来源（网络、本地、应用内）PDF文件的加载方法，到通过URL参数精细控制预览状态（如页码、缩放、工具栏显示）的技术细节。文档包含仓颉语言代码示例及权限配置说明，适合具备ArkUI基础配置能力的开发者，旨在帮助开发者快速集成并定制化PDF预览功能。

## 详细描述

### 使用Web组件的PDF文档预览能力_1.md

本文档介绍了如何在ArkUI应用中使用Web组件实现PDF文档预览。内容涵盖加载网络、本地沙箱及应用内资源PDF的三种场景，以及相应的网络和文件访问权限配置。关键信息包括通过`src`参数加载文档、需开启`domStorageAccess`支持持久化，以及`src`参数不支持状态变量动态修改的限制。文档提供了仓颉语言代码示例，面向具备基础配置能力的ArkUI开发者。

### 使用Web组件的PDF文档预览能力_2.md

本文档介绍了如何使用Web组件加载PDF文件，并通过URL参数控制PDF预览的初始状态。主要内容包括Web组件的基础配置代码，以及支持的PDF预览参数列表，如指定页码、缩放比例、工具栏和导航窗格的显示控制。核心信息在于详细列出了nameddest、page、zoom等参数的语法规则，并提供了多个URL示例，展示了如何通过哈希值精确控制文档打开时的视图和界面元素。这是一份面向使用仓颉语言开发者的API参考文档，旨在帮助开发者在应用中实现定制化的PDF预览功能。
