This directory contains API reference documentation for the `AdsBlockManager` class, designed for Cangjie applications utilizing the SystemCapability.Web.Webview.Core capability. It comprehensively covers the management of ad filtering configurations within Web components, specifically focusing on manipulating AllowedList and DisallowList domain suffixes. Developers can learn how to add, remove, and clear domain rules, as well as set persistent custom ad-blocking rules using EasyList syntax. The documentation highlights the distinction between persistent and non-persistent data storage for different configuration types. This resource is suitable for developers looking to customize web browsing experiences by implementing robust ad filtering logic in their apps.
