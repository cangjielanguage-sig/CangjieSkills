# class_Window

This directory contains API reference documentation for the `Window` class in the Cangjie programming language, focusing on comprehensive window management operations. It covers essential functionalities such as window lifecycle control (creation, destruction, minimization), property configuration (background color, brightness, touchability), and event handling (callbacks, keyboard height). The documentation also details advanced features like immersive layouts, system bar management, and privacy modes. Designed for application developers and system integrators, these files provide technical specifications, parameter definitions, and error handling details (specifically `BusinessException` codes) necessary for building robust graphical user interfaces within the WindowManager framework.
