This directory serves as a comprehensive repository for interface definitions within the Cangjie programming language, specifically focusing on the data serialization mechanisms required for modern logging systems. It centralizes documentation for the `LogValue` interface, which defines the standard contract for converting data objects into formats suitable for log streams. The content covers the fundamental interface definition, the technical implementation details of the `writeTo` method, and extensive extensions for a wide variety of standard data types. These include primitive values such as `Bool` and `Int64`, as well as complex, structured types like `Array`, `HashMap`, and `Duration`. This resource is primarily designed for Cangjie developers and software engineers who are responsible for implementing or extending logging capabilities in their applications. It provides the necessary technical guidance to serialize both built-in and custom data types effectively, ensuring that all data structures are fully compatible with logging streams for consistent and reliable application observability.
