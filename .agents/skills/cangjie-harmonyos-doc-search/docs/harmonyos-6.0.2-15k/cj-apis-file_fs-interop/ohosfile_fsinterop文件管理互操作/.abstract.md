This directory contains API reference documentation for the `ohos.file_fs.interop` module, which facilitates interoperability between Cangjie file management objects and ArkTS JavaScript values. It covers the core interface `JSSystemObjectInteropType` and specific implementations for `File`, `RandomAccessFile`, and `Stream` classes. Key functionalities include bidirectional type conversion methods (`toJSValue`, `fromJSValue`) and ownership transfer mechanisms. This documentation is intended for HarmonyOS/OpenHarmony developers working in Cangjie who need to integrate native file I/O operations with ArkTS environments, ensuring seamless data exchange and object manipulation across language boundaries.
