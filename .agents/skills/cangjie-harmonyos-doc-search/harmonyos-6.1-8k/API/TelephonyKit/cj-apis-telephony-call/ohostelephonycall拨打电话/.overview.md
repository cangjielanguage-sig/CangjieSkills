本目录包含基于仓颉（Cangjie）语言的HarmonyOS电话呼叫管理模块API参考文档。它涵盖了拨打电话、跳转拨号界面、获取通话状态以及电话号码格式化等核心功能。文档详细介绍了相关的配置类（如紧急号码和号码格式化选项）、通话状态枚举以及核心Call类的使用方法。该模块目前处于Beta阶段，适用于需要在HarmonyOS应用中集成通信能力的开发者，提供了从基础呼叫到号码标准化的完整解决方案。

## 详细说明

### class_EmergencyNu_2more_37cfaaf2.md class_EmergencyNu_2more_37cfaaf2.md
本文档是Cangjie语言的API参考文档，主要定义了电话管理相关的两个配置类：EmergencyNumberOptions和NumberFormatOptions。文档涵盖了这两个类的属性定义及构造函数，其中EmergencyNumberOptions用于指定卡槽ID以判断紧急号码，NumberFormatOptions用于设置国家码以格式化电话号码。两者均属于SystemCapability.Telephony.CallManager系统能力，起始版本为22。文档还包含代码示例，展示了如何实例化NumberFormatOptions。主要面向需要进行电话功能开发的开发者，关键词包括Telephony、CallManager、紧急号码、号码格式化。

### enum_CallState.md enum_CallState.md
这是一份Cangjie语言的API参考文档，详细定义了用于表示通话状态的CallState枚举。文档涵盖了五种核心状态：未知、空闲、振铃、摘机和已接听，并说明了各状态的具体含义。此外，还介绍了该枚举继承的父类型及重载的相等性判断操作符（==, !=）和toString()方法。这些功能属于SystemCapability.Telephony.CallManager系统能力，适用于需要处理电话状态管理的应用开发人员，帮助他们准确识别和响应不同的通话场景。

### ohostelephonycall_3more_88d034b1.md ohostelephonycall_3more_88d034b1.md
本文档是关于ohos.telephony.call模块的API参考文档，主要面向使用仓颉语言的HarmonyOS开发者。文档概述了该模块提供的呼叫管理功能，包括拨打电话、跳转拨号界面、获取通话状态及格式化电话号码。核心部分涵盖了模块导入方法及示例代码的使用说明，特别指出了在index.cj和main_ability.cj中的配置要求及Context上下文的获取。目前该模块处于Beta阶段，适用于需要集成电话功能的移动应用开发场景。

### class_Call/
本目录包含Cangjie编程语言中TelephonyKit的Call类API参考文档。它主要涵盖了电话呼叫管理的核心功能，包括电话号码格式化（如E.164标准）、通话状态查询、设备语音能力检测以及拨号功能的实现。文档详细介绍了相关静态方法的参数定义、返回值、异常处理及代码示例。该目录适合使用Cangjie语言进行电话子系统应用开发的开发者，旨在帮助其集成电话拨打、状态监控及号码标准化处理能力。
