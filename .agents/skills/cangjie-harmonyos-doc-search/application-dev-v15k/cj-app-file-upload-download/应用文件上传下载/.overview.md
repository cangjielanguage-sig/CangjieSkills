# 应用文件上传下载

This directory serves as a technical resource for HarmonyOS developers focusing on file transfer functionalities using the Cangjie language. It provides in-depth guidance on managing network operations, specifically the download of remote resources to application directories and the upload of local files to servers. The documentation covers essential prerequisites, such as internet permission configuration, and details the usage of the `ohos.request` module and basic file IO interfaces. Readers will find practical Cangjie code examples illustrating task configuration, progress monitoring via callbacks, and file management. This material is ideal for developers building applications that require robust data synchronization, content delivery, or user file management within the HarmonyOS ecosystem.

## Detailed Description

### 下载网络资源文件至应用文件目录.md 下载网络资源文件至应用文件目录.md
This guide explains how to download network resources to an application's file directory using the HarmonyOS upload and download module. It covers prerequisites like internet permissions, configuration of download tasks, and file access using basic file IO interfaces. The document provides a Cangjie code example demonstrating the complete workflow: setting file paths, configuring download parameters (URL, headers), handling callbacks, waiting for completion, and cleaning up files. It notes that downloads are restricted to app directories and support custom proxies. This tutorial targets HarmonyOS developers using the Cangjie language who need to implement file downloading functionality.

### 应用文件上传下载_2more.md 应用文件上传下载_2more.md
This technical guide explains how to implement file upload and download functionality for applications using the ohos.request module. It focuses on uploading application files, detailing constraints such as the current limitation to cache directory files and the requirement for internet permissions. Key information includes a Cangjie code example demonstrating file creation, configuration of upload tasks using Config and FileSpec objects, and progress monitoring through callbacks. The document serves as a tutorial for developers working within the HarmonyOS ecosystem to manage network file transfers and system service proxies.
