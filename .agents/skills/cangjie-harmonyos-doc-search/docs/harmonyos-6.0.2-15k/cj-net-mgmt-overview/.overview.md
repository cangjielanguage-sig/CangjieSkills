# cj-net-mgmt-overview

This directory serves as a comprehensive entry point for the Network Kit module, specifically tailored for application developers looking to integrate advanced network functionalities into their software. It provides a high-level overview of essential capabilities, including HTTP data requests, WebSocket connections, and sophisticated network connection management. The content covers critical technical aspects such as WiFi and cellular priority handling, DNS resolution, and network quality assessment. Furthermore, it highlights the necessary permission declarations, specifically `ohos.permission.GET_NETWORK_INFO` and `ohos.permission.INTERNET`, required to ensure compliance and functionality. This resource is ideal for developers who need a foundational understanding of network operations and permission handling within the development environment. By reviewing these documents, developers can ensure they adhere to the necessary security protocols while leveraging the full power of the Network Kit.
