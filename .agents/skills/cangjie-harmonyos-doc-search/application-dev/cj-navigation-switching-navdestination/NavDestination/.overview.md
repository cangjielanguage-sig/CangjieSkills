# NavDestination

This directory provides comprehensive API reference documentation for the NavDestination component within the ArkUI framework, utilizing the Cangjie language. It serves as a guide for developers implementing the root container for sub-pages within the Navigation component. The content covers component creation, lifecycle behaviors, property configuration, and event handling mechanisms. Key topics include title bar management, back navigation logic, and context access. This documentation is intended for developers building multi-page HarmonyOS applications who require precise control over routing, UI display, and page transitions.
