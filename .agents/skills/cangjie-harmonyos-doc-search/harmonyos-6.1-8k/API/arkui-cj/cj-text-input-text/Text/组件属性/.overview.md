# 组件属性

本目录包含ArkUI框架中仓颉（Cangjie）语言的组件属性API参考文档，主要聚焦于文本样式设置与布局控制。文档详细涵盖了从基础字体外观（如颜色、字号、字重）到高级排版布局（如行间距、对齐方式、溢出处理）的各类核心函数。所有接口均支持链式调用，适用于版本22及以上。该目录适合使用仓颉语言进行ArkUI应用开发的开发者查阅，旨在帮助开发者实现对UI组件文本的精细化和定制化控制。

## 详细描述

### func_baselineOffs_8more_14e1cfbf.md
本文档是ArkUI框架中Cangjie语言的文本样式API参考文档，旨在提供设置文本外观相关功能的详细说明。文档涵盖了八个核心函数，包括基线偏移、装饰线、字体颜色、字体族、字号、字体样式、字重以及行高。每个函数条目均详细列出了功能描述、系统能力、起始版本（均为22）及参数定义，强调了参数类型、必填项和默认值，且所有函数均返回This以支持链式调用。该文档面向使用Cangjie语言开发ArkUI界面的开发者，用于精细控制文本的排版与视觉呈现。

### func_lineSpacingL_7more_6df64b12.md
本文档是ArkUI框架中仓颉语言的API参考文档，旨在定义用于文本样式和布局控制的七个核心函数。主要内容包括lineSpacing、maxFontSize、maxLines、minFontSize、textCase、textAlign及textOverflow的详细参数说明和功能描述。关键信息指出这些函数均返回This以支持链式调用，参数类型涵盖Length、Int32及特定枚举，且均从版本22开始可用。文档面向需要精细控制文本外观、对齐方式及溢出行为的ArkUI开发人员，提供了完整的接口规范和默认值参考。
