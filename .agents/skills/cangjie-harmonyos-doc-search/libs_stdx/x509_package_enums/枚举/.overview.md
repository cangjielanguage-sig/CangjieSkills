This directory serves as a specialized collection of API reference documentation for enumeration types defined in the Cangjie programming language, specifically targeting cryptographic mechanisms used within digital certificates. It provides in-depth technical specifications for public key algorithms and signature algorithms, detailing their supported variants, functional methods, and interface inheritance structures. Key technical concepts covered include RSA, DSA, ECDSA, SHA256, Equatable interfaces, and X.509 standards. This documentation is essential for developers, security architects, and systems engineers working on secure communication protocols, certificate validation logic, and cryptographic implementations in the Cangjie ecosystem.

## Detailed Description

### enum_PublicKeyAlgorithm.md enum_PublicKeyAlgorithm.md
This API reference document defines the PublicKeyAlgorithm enum in the Cangjie language, specifying supported public key algorithms for digital certificates. The content covers the enum definition, its four specific variants (RSA, DSA, ECDSA, and UnknownPublicKeyAlgorithm), and associated methods like toString() and equality operators. Key takeaways include the inheritance from Equatable and ToString interfaces, enabling algorithm comparison and string representation. Intended for developers working with cryptography and X.509 certificate validation, this document provides the necessary interface details for handling public key algorithm types.

### enum_SignatureAlgorithm.md enum_SignatureAlgorithm.md
This API reference document defines the SignatureAlgorithm enum in the Cangjie language, specifying cryptographic algorithms used to sign digital certificates for integrity and authenticity. The content details supported algorithm variants including RSA, DSA, and ECDSA combined with various hash functions like SHA256. It lists enum values, describes the UnknownSignatureAlgorithm fallback, and documents inherited methods such as toString and equality operators. Key takeaways include the comprehensive list of supported standards and the inheritance from Equatable and ToString interfaces. This documentation targets developers working with X.509 certificate security and cryptographic operations in Cangjie.
