# ohoswebwebviewWebview

This directory contains API reference documentation for the `ohos.web.webview` module in the Cangjie programming language, designed for HarmonyOS application development. It covers essential components for integrating web content into native apps, including navigation history management, HTTP header handling, security level classification, and user interaction detection. The documentation details classes like `BackForwardList`, `HistoryItem`, `WebHeader`, and enums such as `SecurityLevel` and `WebHitTestType`. It also includes comprehensive references for `WebCookieManager` and `WebviewController`. This resource is suitable for Cangjie developers and engineers using the ArkUI framework and ArkWeb kit to build robust web-enabled applications with advanced browsing capabilities.

### class_BackForwardList.md class_BackForwardList.md
This document provides API reference details for the BackForwardList class, which manages the navigation history of a WebView component in the Cangjie language. It covers read-only properties like currentIndex and size, and the getItemAtIndex method for retrieving specific HistoryItem objects. Key information includes that the list holds a maximum of 50 history entries, overwriting the oldest when exceeded. The included code example demonstrates retrieving and logging current history details such as URL, title, and icon. This reference is intended for application developers using the ArkUI framework and WebView capabilities who need to implement navigation history tracking.

### class_HistoryItem_2more.md class_HistoryItem_2more.md

The document is intended for developers implementing web browsing features, offering read-write properties to manage navigation history and handle user interaction events within a webview context.

This reference is intended for software developers working with webview functionality who need to instantiate and manipulate HTTP header objects within their applications.

### enum_SecurityLevel.md enum_SecurityLevel.md
This API reference document defines the SecurityLevel enum in the Cangjie language, used to classify the security status of web pages within a Webview context. It details four primary security levels: NoneLevel (neutral), Secure (HTTPS with trusted certs), Warning (HTTP or old TLS), and Dangerous (phishing or malware). Additionally, it documents comparison operators (==, !=) and a toString() method inherited from parent types. Key information includes that this enum belongs to the SystemCapability.Web.Webview.Core capability starting from version 22. This documentation targets developers building web applications using the Cangjie language who need to programmatically evaluate and handle web security states.

### enum_WebHitTestType.md enum_WebHitTestType.md
This API reference document defines the Cangjie enum WebHitTestType, used to identify the type of content located at a cursor node within a WebView. The documentation details the enum's specific values, including EditText for editable areas, Email for addresses, and Unknown for unrecognized content. It also outlines standard operators for equality comparison and a toString method for string representation. Key information includes the required system capability, SystemCapability.Web.Webview.Core, and the starting version 22. This document is intended for developers working with WebView components who need to handle different types of web content interactions programmatically.
