# 自定义文本样式

This directory provides a comprehensive technical guide for customizing text styles within the ArkUI framework, specifically designed for developers using the Cangjie programming language. It covers an extensive array of text presentation features, starting with fundamental attributes such as text alignment, overflow handling strategies, line spacing configuration, and decorative line application. Additionally, it delves into advanced styling mechanisms, including adaptive font sizing for responsive layouts, capitalization control, and precise baseline offset adjustments. The materials are structured as practical tutorials featuring executable code snippets and visual references to demonstrate rendering results. This content is ideal for UI developers and software engineers seeking to master text rendering nuances and implement sophisticated typography in their ArkUI-based applications.

## Detailed Description

### 自定义文本样式_1.md
This document serves as a practical guide for developers on how to customize text styles within the ArkUI framework using the Cangjie programming language. It covers specific text attributes including alignment, overflow handling, line spacing, decorative lines, and baseline adjustment. Each section provides executable code snippets demonstrating how to implement these styles, often accompanied by visual references to show the rendering results. Key takeaways include the requirement to pair textOverflow with maxLines for proper overflow control. This tutorial is intended for UI developers using ArkUI and Cangjie who need to fine-tune text presentation in their applications.

### 自定义文本样式_2.md
This document serves as a practical guide for developers on implementing advanced text styling features within the ArkUI framework using Cangjie code. It covers three specific text properties: baselineOffset for vertical positioning, adaptive font sizing using minFontSize and maxFontSize, and textCase for capitalization control. Key takeaways include the requirement to set both min and max font sizes simultaneously for adaptive scaling to work, and the need to pair them with layout constraints or maxLines. The document provides executable code snippets demonstrating visual differences for each property. This tutorial is intended for UI developers with basic knowledge of ArkUI component structure looking to refine text presentation.
