# 使用ImageSource完成图片解码

This directory provides technical resources for using the ImageSource API to decode images in the Cangjie programming language. It covers converting various image formats like JPEG, PNG, and WebP into PixelMaps for display or processing. Key topics include resource management, decoding options, and memory cleanup. Intended for Cangjie developers and application engineers in the HarmonyOS or OpenHarmony ecosystem, these guides offer practical examples and step-by-step instructions for implementing robust image handling capabilities.

## Detailed Description

### 使用ImageSource完成图片解码_2more.md 使用ImageSource完成图片解码_2more.md
This technical guide explains how to use the ImageSource API to decode various image formats into a unified PixelMap for display or processing in Cangjie applications. The document defines image decoding, lists supported formats including JPEG, PNG, GIF, WebP, and HEIF, and provides specific instructions for running example code. Key takeaways include understanding the conversion process and configuring the application context in the main ability file. Intended for Cangjie developers, this guide serves as a practical reference for implementing image handling capabilities, noting that the feature is currently in the Beta stage.

### 开发示例-对资源文件中的图片进行解码.md 开发示例-对资源文件中的图片进行解码.md
This tutorial provides a step-by-step guide for developers on how to decode images from resource files using the Cangjie programming language. The document covers obtaining the resource manager, creating an ImageSource via either a byte buffer or RawFileDescriptor, generating a PixelMap for image manipulation, and managing memory by releasing resources. Key takeaways include the two distinct methods for initializing an ImageSource and the critical requirement for manual resource cleanup to prevent memory leaks. It is intended for application developers working with image processing in the Cangjie environment who need to handle raw file assets.

### 开发步骤/
This directory provides comprehensive development tutorials and technical guides focused on image decoding using the ImageKit within the Cangjie programming language. It covers the end-to-end development process, starting from importing necessary modules and acquiring image data through various input methods like sandbox paths or resource managers, to instantiating ImageSource objects and decoding images into PixelMap formats. The content addresses both standard RGBA8888 decoding and HDR image processing, including configuration of DecodingOptions and memory management. These resources are specifically designed for application developers in the HarmonyOS or OpenHarmony ecosystem looking to implement robust image handling and manipulation features in their applications.
