This directory provides comprehensive resources for integrating Cangjie modules into ArkTS applications within the HarmonyOS ecosystem. It covers the fundamental architecture of the Cangjie language, emphasizing its lightweight runtime and high-concurrency capabilities, as well as practical implementation steps for cross-language interoperability. Key topics include using declarative interop macros, managing dependency configurations, and optimizing performance. This documentation is specifically designed for HarmonyOS developers and system architects using DevEco Studio who seek to leverage Cangjie's performance benefits within their ArkTS projects.
