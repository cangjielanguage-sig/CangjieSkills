This directory provides the complete API reference for the `JSArrayEx` class in the Cangjie programming language, a critical component for developers implementing declarative interoperability between Cangjie and ArkTS Array types. It focuses on the technical requirements for cross-language data manipulation within the HarmonyOS environment. The documentation covers a wide range of functionalities, including class definitions, read-only properties, and instance methods for operations like cloning, concatenation, and safe element access. It also details initialization procedures from native Arrays and internal static methods for JSValue conversion. This resource is specifically tailored for Cangjie developers leveraging ArkUI and Napi, requiring system capabilities version 12 or higher to manage complex data structures effectively.
