# class_Color

This directory provides detailed API reference documentation for the `Color` class in the Cangjie programming language, designed specifically for the ArkUI framework. It encompasses the complete structural definition of the class, detailing static properties for standard color constants, public constructors for custom color creation, and methods for color manipulation. Key topics include class inheritance from ResourceColor, initialization using RGBA components or 32-bit integers, alpha adaptation, and bit-packing orders. This documentation is intended for software developers and UI engineers who need to programmatically define, manage, and convert colors within their applications, ensuring precise styling and visual consistency across the user interface.

## Detailed Description

The following files provide specific technical details regarding the implementation and usage of the Color class.

### class_Color_14more.md
This document provides API reference documentation for the Color class in the Cangjie programming language, designed for the ArkUI framework. It details static properties representing standard color constants such as BLACK, RED, TRANSPARENT, and FOREGROUND, as well as public constructors for initializing custom colors using RGBA components or a 32-bit integer value. This technical reference targets developers implementing UI styling and color definitions within their applications. Keywords: Cangjie, ArkUI, Color class, API reference, RGBA, UI development.

### initUInt8_UInt8_UInt8_Floa_4more.md
This document serves as API reference documentation for constructing and manipulating Color objects in the Cangjie programming language within the ArkUI framework. It details two initialization methods: one using separate red, green, blue, and alpha channels, and another using a packed UInt32 value. Additionally, it covers a static function for alpha adaptation and an instance method for converting colors back to UInt32 format. Key takeaways include the specific data types required (UInt8, Float32, UInt32), the default alpha value of 1.0, and the bit-packing order for the UInt32 constructor (Alpha, R, G, B). This reference is intended for software developers building UI applications who need to handle color definitions and conversions programmatically.
