# 使用DevTools工具调试前端页面

This directory provides a comprehensive guide for debugging front-end pages in HarmonyOS applications using Chrome DevTools. It covers the entire workflow from enabling debugging switches and configuring permissions to establishing connections via the `hdc` tool. Key topics include remote debugging for mobile devices, automation scripts for port forwarding, and troubleshooting common connectivity issues. Designed for front-end developers and HarmonyOS engineers, this resource helps efficiently inspect and optimize web components running in the ArkWeb environment.

## Detailed Description

### 使用DevTools工具调试前端页面.md 使用DevTools工具调试前端页面.md
This document provides a guide on using DevTools to debug front-end pages for Web components. It introduces the capability to debug mobile device front-end pages from a computer. The main topics include an overview of the DevTools tool and the specific version requirements for the target device. Key information highlights that this feature supports remote debugging for devices running version 4.1.0 and above. This documentation is intended for front-end developers seeking to debug mobile web applications efficiently using desktop tools.

### 便捷脚本.md 便捷脚本.md
This guide provides automation scripts to simplify port forwarding configuration for debugging HarmonyOS WebViews using the hdc tool. It covers two main sections: a Batch script for Windows and a Shell script for Linux or Mac platforms. The Windows script intelligently maps ports to process IDs without deleting existing rules and automatically opens the browser inspection page. Conversely, the Linux script clears all existing forwarding rules before establishing new connections, starting from port 9222. This resource is intended for developers needing to quickly establish local-to-remote socket connections for application inspection.

### 常见问题与解决方法.md 常见问题与解决方法.md
This document serves as a troubleshooting guide for resolving connectivity and debugging issues when using the hdc tool and Chrome DevTools for HarmonyOS development. It covers five main topics: device discovery failures, unauthorized device errors, missing DevTools domain sockets, port forwarding failures, and Chrome's inability to detect debugged pages. Key takeaways include ensuring USB debugging is enabled, authorizing the computer connection, verifying the Web debugging switch is active, and correctly configuring TCP ports (default 9222) to match between the device and Chrome settings. This reference guide is intended for developers debugging web components who need to diagnose and fix connection interruptions or configuration mismatches.

### 调试步骤/
This directory serves as a comprehensive technical resource for HarmonyOS developers, particularly those working with the Cangjie language, who need to debug web components within their applications. It provides a structured workflow for enabling and utilizing Chrome DevTools to inspect web pages running in the ArkWeb environment. The content covers the entire setup process, beginning with the programmatic enabling of the debugging switch and the declaration of required system permissions. It further details the necessary hardware configurations, such as enabling USB debugging, and the network setup required to bridge the device with the development machine. Key technical elements include the use of `WebviewController.setWebDebuggingAccess`, `hdc` command-line tools, and domain socket forwarding. By following these guides, developers can establish a reliable connection for real-time debugging and performance analysis. This documentation is essential for any developer aiming to troubleshoot or optimize web-based functionalities in HarmonyOS apps.
