# 拉起邮件类应用mailto方式

This directory serves as a technical resource for developers working within the HarmonyOS environment, specifically focusing on the implementation of the `mailto` protocol to invoke email applications. It details the mechanisms required for both initiating email requests from a source application and configuring a target application to receive and process these requests. The content covers essential technical aspects such as URI construction, parameter handling (subject, body, cc, bcc), and the use of the `startAbility` method with `Want` objects. Furthermore, it provides specific implementation steps using the Cangjie language, including configuration in `module.json5` and lifecycle management for handling cold and warm starts. This guide is ideal for software engineers aiming to enhance their applications with deep-linking email capabilities or those developing email clients that need to respond to external system triggers.

## Detailed Description

The following files provide in-depth technical instructions for both the calling application and the target application. They cover the necessary code snippets, configuration files, and lifecycle methods required to successfully implement the mailto functionality in a HarmonyOS project.

### 使用场景_3more.md 使用场景_3more.md
This guide explains how to use the mailto protocol to launch email clients from web pages or applications, enabling users to send emails with pre-filled content. It covers common usage scenarios, the standard mailto protocol format including parameters like subject, body, cc, and bcc, and specific development steps for both HTML links and Cangjie application code. Key information includes the URI structure and a Cangjie code snippet demonstrating how to use startAbility with a Want object to trigger the email client. This technical guide targets developers integrating email functionality into web pages or HarmonyOS applications, requiring knowledge of HTML or Cangjie and UIAbility context. Keywords: mailto, email protocol, startAbility, Cangjie, UIAbilityContext, URI, web development, mobile application.

### 目标方开发步骤.md 目标方开发步骤.md
This technical guide outlines the steps for configuring a HarmonyOS application to handle mailto protocol launches. The document details two primary development phases: declaring the mailto scheme and specific actions within the module.json5 configuration file, and implementing URI parsing logic using the Cangjie language. Key takeaways include the necessity of registering the ohos.want.action.sendToData action and handling the want object in both onCreate and onNewWant lifecycle methods to support cold and warm starts. This tutorial is intended for developers building applications that need to process email links.
