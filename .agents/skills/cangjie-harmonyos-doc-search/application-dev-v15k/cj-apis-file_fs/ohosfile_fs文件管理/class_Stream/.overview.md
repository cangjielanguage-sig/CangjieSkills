# class_Stream

This directory contains essential API reference documentation for the `Stream` class in the Cangjie language, focusing on robust file stream operations. It covers the complete lifecycle of stream handling, including class definitions, instantiation via `FileFs`, and synchronous methods for reading, writing, closing, and flushing data. The documentation provides detailed insights into handling various data types, such as strings and byte arrays, with support for configurable options like encoding, offsets, and buffer lengths. It also includes syntax details, parameters, return values, and exception management. This resource is specifically designed for developers and software engineers working on file input/output systems, providing the technical specifications required to effectively manage data streams in Cangjie applications targeting system version 12.

## Detailed Description

### class_Stream_4more.md class_Stream_4more.md
This document serves as API reference documentation for the `Stream` class, which handles file stream operations in the Cangjie language. It covers the class definition and three primary synchronous methods: `close`, `flush`, and `read`. Each section details syntax, parameters, return values, potential exceptions, and code examples. Key takeaways include the requirement to instantiate streams via `FileFs.createStream` or `FileFs.fdopenStream` before use, and the `read` method's support for configurable length and offset options. Intended for developers working on file I/O, this guide assumes knowledge of the CoreFileKit and targets system version 12 capabilities.

### func_writeString_WriteOpti_2more.md func_writeString_WriteOpti_2more.md
This API reference document details the overloaded write functions used to write data into stream files within the Cangjie development environment. It covers two specific function signatures: one accepting a String buffer and another accepting an Array<Byte> buffer. Both sections detail parameters, return values, exceptions, and usage examples. Key information includes the use of WriteOptions to specify write length, offset position, and encoding, which defaults to utf-8. The functions return the actual number of bytes written as an Int64 and may throw BusinessException for file management errors. This documentation targets software developers implementing file input/output operations, requiring knowledge of stream handling and the Cangjie language syntax.
