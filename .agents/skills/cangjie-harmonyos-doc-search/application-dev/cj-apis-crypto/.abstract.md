The `cj-apis-crypto` directory acts as the central hub for cryptographic API documentation tailored for the Cangjie programming language within the OpenHarmony environment. It provides an extensive framework designed to facilitate secure application development by offering robust libraries for various cryptographic operations. Key topics covered include symmetric and asymmetric encryption, decryption, message digests, and message authentication codes (MAC). Additionally, the directory addresses the critical need for secure random number generation and comprehensive key management. It defines essential data structures such as DataBlob and outlines parameter specifications for prominent algorithms like AES, SM4, RSA, and SM2. This documentation is primarily intended for developers and security engineers who are tasked with building secure applications on the OpenHarmony platform and require detailed guidance on implementing effective data protection and integrity features.
