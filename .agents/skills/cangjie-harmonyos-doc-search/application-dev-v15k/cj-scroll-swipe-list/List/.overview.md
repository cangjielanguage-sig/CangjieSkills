# List

This directory contains comprehensive documentation for the List component within the Cangjie ArkUI framework, designed for displaying continuous data in uniform-width items. It covers essential aspects including component initialization, subcomponents like ListItem and ListItemGroup, and rendering logic using ForEach and LazyForEach. The content details universal attributes, specific events, and advanced properties such as multi-column layouts and sticky headers. Additionally, it provides foundational type definitions and practical code examples for complex interactions. This resource is suitable for HarmonyOS developers and UI engineers seeking to build responsive, interactive list interfaces with precise control over scrolling and layout behaviors.
