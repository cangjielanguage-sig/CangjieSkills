# 对称密钥加解密算法规格

This directory contains technical specifications for symmetric key encryption and decryption algorithms. It covers implementation details for 3DES, SM4, and AES, including supported modes (ECB, CBC, GCM, etc.), padding schemes (PKCS5, PKCS7), and parameter configuration syntax. The documents provide guidance on key lengths, block sizes, and API requirements (specifically API version 12+). It is suitable for developers integrating cryptographic functions using the CryptoArchitectureKit or similar libraries who need to understand algorithm configurations and string parameter formats for instantiating cryptographic instances.

## Detailed Description

### 3DES.md 3DES.md
This document serves as a technical reference for implementing 3DES encryption and decryption within a cryptographic library, detailing algorithm specifications, modes, and parameter configurations. It covers the four supported encryption modes (ECB, CBC, OFB, CFB), padding requirements (PKCS5/PKCS7/NoPadding), and the syntax for string-based parameter specification used to instantiate cryptographic instances. Key information includes the mandatory padding for ECB and CBC modes when data is not 64-bit aligned, the equivalence of PKCS5 and PKCS7 padding for 3DES, and the flexibility to specify or omit key length in the parameter string format like "3DES192|ECB|PKCS7". Intended for developers using API version 12+ who need to integrate symmetric encryption, requiring knowledge of block cipher concepts and parameter specifications.

### SM4_2more.md SM4_2more.md
This technical reference guide details the implementation of SM4 symmetric encryption, covering supported modes, padding schemes, and parameter configuration. It outlines seven encryption modes including ECB, CBC, and GCM, explains padding requirements like PKCS5 and PKCS7, and defines the string parameter syntax for creating cryptographic instances. Key takeaways include the 128-bit block size requiring padding for ECB and CBC modes, the specific string format for specifying algorithm specs (e.g., "SM4_128|ECB|PKCS7"), and the distinction that stream modes like CTR and GCM function as NoPadding. Intended for developers integrating cryptographic functions, specifically those using the CryptoArchitectureKit API.

### 对称密钥加解密算法规格_2more.md 对称密钥加解密算法规格_2more.md
