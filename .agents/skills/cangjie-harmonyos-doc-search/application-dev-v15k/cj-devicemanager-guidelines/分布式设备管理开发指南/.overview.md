# 分布式设备管理开发指南

This directory provides a comprehensive technical guide for distributed device management, specifically tailored for developers using the Cangjie language and the Stage model. It covers the fundamental concepts of distributed business, including device discovery, binding, querying, and status listening. The content details the operational mechanisms and constraints, such as network requirements and user authorization. Key topics include applying for the `ohos.permission.DISTRIBUTED_DATASYNC` permission, configuring `module.json5`, and utilizing the `DistributedServiceKit` to manage device interactions. This guide is essential for developers aiming to build cross-device applications that function seamlessly over LAN or Bluetooth, providing step-by-step instructions and code examples to implement robust distributed functionalities.

## Detailed Description

### 分布式设备管理简介_2more.md 分布式设备管理简介_2more.md
This document serves as a technical guide introducing distributed device management concepts and providing instructions for requesting necessary permissions. It covers the definition of distributed business, four core functions (discovery, binding, query, listening), operational mechanisms, constraints, and a development tutorial for applying for the ohos.permission.DISTRIBUTED_DATASYNC permission. Key takeaways include the requirement for devices to be on the same LAN or Bluetooth and the mandatory user authorization for sensitive data access. The tutorial details configuring module.json5 and using the requestPermissionsFromUser API in Cangjie. This guide targets developers using the Stage model and Cangjie language to build distributed applications.

### 设备发现开发指导.md 设备发现开发指导.md
This development guide instructs developers on using the DeviceManager API to discover nearby available devices. It covers the scenario overview, the startDiscovering interface specification, and a step-by-step implementation process. Key steps include importing the DistributedServiceKit module, creating a device manager instance with success and failure callbacks, and initiating discovery. Important constraints include the requirement for distributed data sync permissions, a two-minute discovery duration, a maximum of 99 devices, and the necessity of being on the same LAN for Wi-Fi scenarios. This tutorial targets Cangjie developers building distributed applications.

### 设备绑定开发指导_3more.md 设备绑定开发指导_3more.md
This development guide instructs developers on managing distributed device relationships using the Cangjie language and DistributedServiceKit. It covers three main scenarios: binding untrusted devices to establish trust, querying lists of available trusted devices, and monitoring device online or offline status changes. Key APIs include bindTarget, getAvailableDeviceList, and status callback registration. The document provides step-by-step implementation details and Cangjie code snippets for each function. Intended for application developers, it requires distributed data synchronization permissions to facilitate cross-device interactions.
