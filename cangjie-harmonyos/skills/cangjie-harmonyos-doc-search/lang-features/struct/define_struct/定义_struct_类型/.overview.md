### struct_构造函数.md
1. 本文档旨在阐述仓颉语言中 struct 的构造函数定义与使用规范。
2. 主要涵盖普通构造函数、主构造函数及自动生成构造函数三个部分。
3. 普通构造函数以 init 开头，要求必须初始化所有未初始化成员，并支持基于参数列表的重载；主构造函数与类型同名，允许通过 let 或 var 参数直接声明成员变量，以简化结构体定义；若未定义自定义构造函数且所有成员均有初值，系统将自动生成无参构造函数。
4. 本文档属于语言参考指南，适合具备基础编程语法的开发者阅读，关键词包括 struct、构造函数、初始化、重载及主构造函数。
