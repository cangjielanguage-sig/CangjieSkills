This directory contains API reference documentation for the `AVMediaDescription` class in the Cangjie programming language. It focuses on encapsulating metadata attributes for playlist media items within the AVSession Core system capability. The documentation covers constructors, initialization methods, and various properties such as media URI, artist, album details, and DRM schemes. It is designed for multimedia application developers who need to manage and describe media assets programmatically, supporting features like playback metrics and optional data types starting from version 19.
