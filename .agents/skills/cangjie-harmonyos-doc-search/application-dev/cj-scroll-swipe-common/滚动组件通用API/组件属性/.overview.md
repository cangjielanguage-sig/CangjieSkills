# 组件属性

This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework. It primarily focuses on scroll-related behaviors and visual styling, including edge fading effects, physics parameters like friction and fling speed, nested scrolling mechanisms, and scroll bar customization. Additionally, it covers content clipping and scroll interaction management. These documents are designed for developers using ArkUI Full capabilities who need to implement complex scrolling interactions and fine-tune UI component aesthetics in their applications.

## Detailed Description

### func_fadingEdgeOptionBool_5more.md func_fadingEdgeOptionBool_5more.md
This document serves as API reference documentation for Cangjie ArkUI developers, detailing functions that configure scroll component visual effects and physics. It covers two overloads of the fadingEdge function to enable edge fading and set its length, alongside flingSpeedLimit to restrict maximum initial fling velocity. Additionally, it documents friction overloads to adjust inertial scrolling resistance using numeric values or resource references. Key information includes parameter constraints, default values, and behavioral notes such as fadingEdge overriding overlay properties. Intended for developers building UIs with ArkUI Full capabilities, this guide assumes familiarity with component properties and scroll physics.

### func_nestedScrollNested_efd895f1.md func_nestedScrollNested_efd895f1.md
This document provides API reference documentation for the nestedScroll function in the Cangjie language, which configures nested scrolling behaviors to enable linkage between child and parent components. The content details the function signature, system capabilities, and version requirements, specifically focusing on the mandatory NestedScrollOptions parameter that defines scrolling modes for forward and backward directions. Key information includes the function's return type of the component instance T and its requirement for SystemCapability.ArkUI.ArkUI.Full starting from version 22. This reference is intended for developers building ArkUI interfaces who need to implement complex, coordinated scrolling interactions within their applications.

### func_scrollBarBarState_6more.md func_scrollBarBarState_6more.md
This document provides API reference documentation for configuring scroll bar appearance and behavior, as well as content clipping in ArkUI components using the Cangjie language. It details six specific functions: scrollBar, scrollBarColor, and scrollBarWidth for styling; clipContent (overloaded) for defining content clipping areas; and enableScrollInteraction for managing scroll gesture support. Key parameters include BarState, ResourceColor, Length, ContentClipMode, RectShape, and Bool. The documentation specifies default values, such as Auto for state and 4vp for width, and notes that enableScrollInteraction does not affect programmatic scrolling via the Scroller controller. Targeted at developers using the ArkUI framework (version 22+) to build user interfaces, this reference guide requires knowledge of Cangjie syntax and UI component properties.
