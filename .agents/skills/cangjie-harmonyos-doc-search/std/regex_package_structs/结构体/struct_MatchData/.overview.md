# struct_MatchData

This directory provides comprehensive API documentation for the `MatchData` struct within the Cangjie standard library's regex module. It serves as a technical reference for storing and querying regular expression match results. The content covers essential functionalities such as retrieving capture group counts, extracting match positions, and obtaining substrings via various overloads. It also details error handling mechanisms like `IllegalArgumentException` for invalid inputs. This resource is designed for Cangjie developers seeking to implement robust pattern matching and text analysis in their applications, offering both structural definitions and practical usage examples.
