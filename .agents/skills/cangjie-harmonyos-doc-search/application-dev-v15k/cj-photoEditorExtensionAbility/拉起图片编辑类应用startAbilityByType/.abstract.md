This directory provides a comprehensive guide for HarmonyOS developers on integrating image editing capabilities using the `startAbilityByType` interface and `PhotoEditorExtensionAbility`. It covers the complete workflow from the perspective of both the host application (caller) and the editing application (provider). Key technical areas include lifecycle management, URI handling, file sandboxing, and asynchronous result callbacks. The documentation is tailored for developers using ArkTS or Cangjie who need to implement seamless image modification features or extend existing applications with editing functionalities.
