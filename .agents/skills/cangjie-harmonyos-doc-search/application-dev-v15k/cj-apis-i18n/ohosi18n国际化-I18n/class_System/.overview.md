# class_System

This directory contains API reference documentation for the `System` class within the Cangjie programming language's LocalizationKit. It focuses on internationalization (I18n) features, enabling developers to retrieve and configure system-level language, region, and locale settings. The documentation covers static methods for accessing preferred languages, display countries, time formats, and system capabilities. It is designed for software developers implementing localization in global applications, providing method signatures, parameters, return values, and error handling details to ensure correct usage of system internationalization features.

## Detailed Description

### class_System_4more.md
This document serves as API reference documentation for the Cangjie programming language's System class within the LocalizationKit, focusing on internationalization (I18n) features available from version 19. It details three primary static methods: `getAppPreferredLanguage` for retrieving app language settings, and `getDisplayCountry` and `getDisplayLanguage` for localizing text based on specific locales and formatting rules. Key information includes method signatures, parameter requirements, return values, and potential `BusinessException` error codes. The content targets software developers implementing localization, providing code examples and system capability references to ensure correct usage in global applications.

### static_func_getFirstPrefer_6more.md
This document serves as an API reference for the Cangjie LocalizationKit, detailing static methods to retrieve system internationalization settings. It covers six main functions: retrieving the first preferred language, the full preferred language list, system-supported countries for a specific language, the current system language, all supported system languages, and the system locale. Each entry includes the function signature, system capability requirements, return types, and usage examples. The `getSystemCountries` method specifically details parameter validation and potential business exceptions. This guide targets Cangjie developers implementing localization features who need to query system language and region configurations.

### static_func_getSystemRegio_5more.md
This document serves as API reference documentation for the Cangjie LocalizationKit, detailing static functions used to retrieve and configure system internationalization settings. It covers five main functions: `getSystemRegion`, `getUsingLocalDigit`, `is24HourClock`, `isSuggested`, and `setAppPreferredLanguage`. Each entry provides the function signature, description, system capability, return types, parameters, and potential exceptions like `BusinessException`. Key functionalities include fetching system locale data, checking time formats, and managing app language preferences. This guide targets Cangjie developers implementing localization features in applications requiring version 19 system capabilities.
