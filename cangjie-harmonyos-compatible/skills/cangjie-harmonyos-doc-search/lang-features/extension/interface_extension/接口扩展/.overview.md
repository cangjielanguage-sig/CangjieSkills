# 接口扩展

本目录包含关于仓颉编程语言接口扩展机制的文档。它详细介绍了如何使用 `extend` 关键字为现有类型动态添加接口实现，涵盖了基础语法、多接口实现、泛型约束以及空实现复用等内容。此外，文档还深入探讨了接口扩展中的冲突处理规则、编译错误机制以及泛型继承结构下的边缘情况。这些资料适合仓颉语言开发者阅读，旨在帮助开发者掌握类型系统的扩展能力，并有效避免继承与泛型编程中的潜在陷阱。

## 详细描述

### 接口扩展_1.md 接口扩展_1.md
本文档旨在介绍仓颉语言中接口扩展的用法与规则，指导开发者如何为现有类型动态添加接口实现。主要涵盖基础语法、单接口与多接口实现（使用 &）、带泛型约束的扩展、复用已有成员的空实现，以及接口继承时的检查顺序与冲突处理。关键信息包括 extend 关键字的使用、子接口覆盖父接口实现的机制，以及避免继承冲突的注意事项。这是一份面向仓颉开发者的技术教程，帮助其掌握类型系统的扩展能力。

### 接口扩展_2.md 接口扩展_2.md
本文档旨在解释仓颉编程语言中接口扩展的冲突问题及特定边缘情况的行为。主要涵盖了类扩展多个接口时因默认实现冲突导致的编译错误，以及当类通过泛型基类间接继承接口默认实现时可能产生的非预期行为。关键信息包括编译器要求重写冲突函数的机制，以及在泛型继承结构中调用接口默认函数时可能触发的非预期行为警告。面向仓颉语言开发者，旨在帮助其深入理解接口扩展规则并避免泛型继承中的潜在陷阱。
