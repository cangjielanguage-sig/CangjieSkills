# 使用场景

This directory provides comprehensive tutorials and examples focused on the practical application of the `@Link` decorator in Cangjie ArkUI development. It addresses specific usage scenarios ranging from basic data types to complex array manipulations. The content covers essential concepts such as bidirectional data synchronization between parent and child components, the use of `ObservedArrayList` for tracking array mutations, and the integration of the `@Watch` decorator to handle side effects during state updates. By exploring these scenarios, developers can learn how to effectively manage state and trigger UI refreshes without affecting parent component state unnecessarily. This resource is specifically suitable for HarmonyOS developers and Cangjie language users who aim to deepen their understanding of state management mechanisms and component interaction patterns in modern UI development.

## Detailed Description

Below are the detailed breakdowns of the specific scenarios covered in this directory.

### 数组类型的Link_2more.md 数组类型的Link_2more.md

This tutorial provides advanced examples for using the @Link decorator in Cangjie ArkUI development. It covers two main scenarios: handling array type changes using ObservedArrayList to detect additions, deletions, and replacements, and utilizing the @Watch decorator with @Link to modify local @State variables during two-way synchronization. Key takeaways include understanding how @Link tracks array mutations and how to trigger side effects via @Watch without affecting parent component state. The target audience is HarmonyOS developers familiar with state management and component interaction.

### 简单类型和类对象类型的Link.md 简单类型和类对象类型的Link.md

This tutorial demonstrates bidirectional data synchronization between parent and child components using the @Link decorator in Cangjie for both simple types and class objects. The document provides a code example illustrating how to implement @Link with Int64 and a custom class, highlighting that changes in child components update the parent's @State and vice versa. Key takeaways include understanding the two-way binding mechanism where modifying @Link variables triggers UI refreshes in both components. This guide is designed for developers using the Cangjie language for UI development who need to master state management and component interaction patterns.
