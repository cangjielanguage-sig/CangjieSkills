This directory provides comprehensive API reference documentation for the HarmonyOS operating system account management module (`ohos.account.osAccount`) using the Cangjie programming language. It covers essential components for managing local and domain accounts, including account types, constraints, and manager classes. Key topics include the `AccountManager` and `OsAccountInfo` classes, domain account information, and system-level constraints for device functionality. This documentation is intended for system developers and software engineers building applications that require user identification, privilege management, and device policy control within the HarmonyOS ecosystem.
