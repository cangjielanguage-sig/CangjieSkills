# AESCBCPKCS7

本目录展示了如何在仓颉语言中利用HUKS（HarmonyOS Universal KeyStore）接口实现AES/CBC/PKCS7加密与解密功能。内容涵盖了密钥生成、加密参数配置、数据加解密逻辑以及密钥的删除管理。核心关键词包括HUKS、AES加密、CBC模式、PKCS7填充、仓颉语言及HarmonyOS开发。该文档适用于具备基础密码学知识的HarmonyOS开发者，旨在帮助其掌握数据安全存储与密钥生命周期管理的实现方法。

## 详细说明

### AESCBCPKCS7_1.md AESCBCPKCS7_1.md
本文档演示了在仓颉语言中使用HUKS接口实现AES/CBC/PKCS7加密的代码示例。主要涵盖密钥属性配置、加密解密参数设置及核心加密逻辑函数的实现。重点展示了如何通过HuksParam配置算法参数（如128位密钥、CBC模式），并调用generateKeyItem、initSession等API完成密钥生成与数据加密。适用于HarmonyOS开发者，需具备基础密码学知识以实现数据安全存储。

### AESCBCPKCS7_2.md AESCBCPKCS7_2.md
本文档主要演示了使用HUKS接口进行AES数据解密以及删除密钥的具体代码实现。文档包含两个主要部分：模拟解密场景（DecryptData函数）和模拟删除密钥场景（DeleteKey函数）。关键步骤包括获取解密参数配置、通过initSession初始化会话获取句柄、调用finishSession完成解密，以及使用deleteKeyItem删除指定别名的密钥。适用于HarmonyOS开发者，作为HUKS API的使用示例或教程参考，帮助开发者理解密钥生命周期管理中的解密与销毁流程。
