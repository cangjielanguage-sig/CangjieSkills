### regex_规则集_4.md
This document outlines specific behavioral rules, limitations, and security warnings for regular expressions within the Cangjie programming language. It covers quantifier handling, capture group limits, unsupported nested quantifier patterns, and input string restrictions. Key takeaways include a maximum of 63 capture groups, a compiled rule length limit of 65535, and a critical warning that unbounded repetition counts can cause resource exhaustion or ReDos attacks. It also notes that input strings must not contain null bytes to prevent infinite loops. This reference guide targets Cangjie developers who need to understand edge cases and constraints to ensure regex stability and security.
