This directory provides comprehensive API documentation for the LocalStorage class within the Cangjie language environment, specifically tailored for the ArkUI framework. It focuses on the mechanisms required for managing page-level UI state effectively. The content covers a wide range of functionalities, including property manipulation, data binding strategies, and interactions with AppStorage decorators. Developers will find detailed explanations on implementing two-way and one-way bindings using ObservedProperty objects, as well as methods for data retrieval and deletion. This resource is essential for HarmonyOS developers and software engineers aiming to build responsive applications with robust state management capabilities for system version 22.
