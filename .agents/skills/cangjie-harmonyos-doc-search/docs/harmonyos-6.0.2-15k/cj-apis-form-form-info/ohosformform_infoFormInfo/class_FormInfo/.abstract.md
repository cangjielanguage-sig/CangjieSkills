This directory provides comprehensive API reference documentation for the `FormInfo` class within the Cangjie programming language framework. It focuses on the configuration and metadata of cards (widgets), systematically detailing read-only properties that define identity, display characteristics, structural settings, and update behaviors. Key topics include card dimensions, shapes, transparency, update cycles, form types, and system version compatibility (specifically version 20). This documentation is intended for application developers utilizing the SystemCapability.Ability.Form framework who need to access or manipulate card attributes programmatically to create dynamic, responsive, and visually consistent user interfaces.
