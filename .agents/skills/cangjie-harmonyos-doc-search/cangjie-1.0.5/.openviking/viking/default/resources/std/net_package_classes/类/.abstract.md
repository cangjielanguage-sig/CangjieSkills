This directory contains API reference documentation for the Cangjie programming language's networking classes. It covers a comprehensive range of network communication components, including IP address manipulation (IPv4/IPv6), socket addressing, and various socket implementations (TCP, UDP, Unix Domain Sockets, and Raw Sockets). The documentation details class definitions, properties, methods, and exception handling for low-level network operations. It is suitable for software developers and network engineers working with Cangjie who need to implement robust network protocols, manage socket lifecycles, or handle inter-process communication (IPC).
