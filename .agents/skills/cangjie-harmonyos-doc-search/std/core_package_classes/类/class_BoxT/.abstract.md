This directory contains the API documentation for the generic `Box` class in the Cangjie programming language. It covers the core class definition that wraps values to provide class-based reference semantics for non-reference types like structs. Additionally, it details interface extensions for `Hashable`, `ToString`, and `Comparable`, enabling Box instances to support hashing, string representation, and ordered comparisons. This resource is suitable for Cangjie developers, library maintainers, and software engineers who need to manage object lifetimes, enable reference behavior for value types, or utilize Box objects in collections and comparisons.
