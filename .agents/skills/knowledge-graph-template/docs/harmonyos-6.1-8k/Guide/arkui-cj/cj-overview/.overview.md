## Detailed Description

### cj-overview.md cj-overview.md

本文档旨在介绍ArkUI（方舟UI框架）的基本概念及其基于仓颉的声明式开发范式，为应用UI开发提供基础设施概览。主要内容包括ArkUI的定义与功能、UI与组件的基本概念，以及基于仓颉的声明式开发范式介绍。ArkUI提供简洁语法、丰富组件及实时预览工具，支持可视化开发。组件是UI构建的最小单位，声明式开发范式则通过仓颉语法从组件、动画和状态管理三个维度提供UI绘制能力。该文档属于概览指南，面向使用仓颉语言进行应用UI开发的开发者，帮助他们理解框架基础和开发模式。
