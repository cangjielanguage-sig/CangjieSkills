This directory provides API reference documentation for the `Cookie` class constructor in the Cangjie HTTP package. It covers the initialization of cookie attributes, including parameter definitions, validation rules, and default behaviors based on RFC 6265. The content details mandatory and optional fields like name, value, expires, and security flags, while also addressing error handling through `IllegalArgumentException`. This resource is designed for developers and engineers implementing HTTP client or server functionality who require precise guidance on creating compliant cookies and managing protocol-specific exceptions.
