# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental type definitions within the ArkUI framework, specifically implemented in the Cangjie language. It focuses on the structural and styling configurations required for building robust user interfaces, particularly for components like the SideBar. The content covers essential classes such as `ButtonIconOptions`, `ButtonStyle`, and `DividerStyle`, detailing properties for dimensions, positioning, colors, and state management. These definitions are crucial for developers aiming to create highly customizable and responsive UI layouts, offering precise control over visual elements and their behaviors. By utilizing these types, developers can ensure their applications adhere to specific design guidelines while maintaining flexibility in UI implementation.

## Detailed Description

### class_ButtonIconOptions.md class_ButtonIconOptions.md
This API reference document defines the ButtonIconOptions class in the Cangjie language, designed to configure icons for a sidebar control button within the ArkUI framework. The documentation covers the class definition, three public properties, and the initialization method. Key information includes the use of nullable ResourceStr types for the shown, hidden, and switching properties, which correspond to the sidebar's visible, hidden, and transitioning states. The constructor requires the first two parameters while making the third optional. This guide targets Cangjie developers implementing dynamic UI components, specifically those managing state-dependent iconography for sidebars.

### class_ButtonStyle.md class_ButtonStyle.md
This API reference document defines the Cangjie class ButtonStyle, which configures attributes for sidebar control buttons within the ArkUI framework. The content details public properties for positioning and sizing, including left, top, width, and height, all utilizing Float64 types with vp units. It also covers the icons property for button iconography. Key information includes the class constructor, which accepts named parameters with specific default values like 24.0 vp for dimensions. Intended for ArkUI developers using Cangjie, this documentation supports UI customization starting from system version 22.

### class_DividerStyle.md class_DividerStyle.md
This API reference document details the Cangjie DividerStyle class, which defines the visual style for dividers in a SideBar component within the ArkUI framework. The documentation outlines the class structure, focusing on four key properties: strokeWidth, color, startMargin, and endMargin, all of which are readable and writable. It also explains the constructor parameters, their default values, and initial states. Key information includes a note that standard width and height attributes are ignored, with the divider automatically filling the remaining space. This resource is intended for developers using Cangjie to customize ArkUI interface layouts.
