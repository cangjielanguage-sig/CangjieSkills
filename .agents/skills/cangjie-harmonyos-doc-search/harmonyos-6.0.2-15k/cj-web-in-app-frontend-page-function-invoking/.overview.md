# cj-web-in-app-frontend-page-function-invoking

This directory contains a specialized technical tutorial designed for Cangjie developers working on hybrid application architectures. It focuses specifically on the mechanisms required to invoke frontend JavaScript functions directly from the native application side using the `WebviewController`. The content provides an in-depth analysis of the `runJavaScript()` and `runJavaScriptExt()` methods, distinguishing their use cases, particularly regarding `ArrayBuffer` support and `AsyncCallback` result handling. By exploring how to trigger existing HTML functions and inject new scripts for dynamic page manipulation, this guide equips developers with the skills necessary to create seamless interactions between native logic and web content. It is highly suitable for software engineers utilizing the ArkWeb framework who need to implement robust, bidirectional communication channels in their applications.

## Detailed Description

### cj-web-in-app-frontend-page-function-invoking.md cj-web-in-app-frontend-page-function-invoking.md

This tutorial guides Cangjie developers on invoking frontend JavaScript functions from the application side using the WebviewController. It details the usage of runJavaScript() and runJavaScriptExt(), highlighting the latter's support for ArrayBuffer inputs and AsyncCallback results. The document provides a comprehensive code example demonstrating how to trigger existing HTML functions and inject new JavaScript code to manipulate page elements. Key takeaways include understanding parameter differences and handling execution results via callbacks. This guide is intended for developers building hybrid applications with ArkWeb who require seamless native-to-web communication.

**Key technical concepts covered in this document include:**
*   **WebviewController Usage:** How to utilize the controller to bridge the native and web environments.
*   **Method Comparison:** The specific differences between `runJavaScript()` and the extended `runJavaScriptExt()`.
*   **Data Handling:** Techniques for passing `ArrayBuffer` inputs to web functions.
*   **Asynchronous Results:** Managing the output of script execution through `AsyncCallback`.
*   **Dynamic Injection:** Strategies for injecting new JavaScript code to alter the DOM or page behavior in real-time.
