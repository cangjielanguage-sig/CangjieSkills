# enum_SensorId

This directory provides comprehensive API reference documentation for the `SensorId` enumeration within the Cangjie programming language. It serves as a critical resource for developers working with hardware sensors, detailing the structure used to identify supported sensor types for subscription or unsubscription processes. The documentation covers the enum's structural definition, its inheritance from `Equatable` and `ToString`, and specific sensor members like Accelerometer, Gyroscope, Heart Rate, and Proximity. Additionally, it outlines essential system capability requirements such as `SystemCapability.Sensors.Sensor` and specifies a start version of 19. This resource is specifically designed for Cangjie developers who are implementing sensor interactions, managing device data, or building applications requiring real-time hardware monitoring and debugging capabilities. By utilizing these APIs, developers can ensure accurate sensor identification and efficient data handling within their software projects.
