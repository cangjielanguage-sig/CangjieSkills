# data_package_overview

本目录包含仓颉项目 `stdx.unittest.data` 库的 API 概览文档，旨在为单元测试提供 JSON、CSV 和 TSV 等序列化格式的测试数据支持。文档详细介绍了如何从文件中读取可序列化类型的数据，并将其作为参数化测试的参数源，涵盖了相关的读取函数、策略类及提供者类。该文档适合需要在仓颉项目中编写单元测试并利用外部数据文件进行参数化测试的开发者查阅。通过本文档，开发者可以掌握如何利用外部数据源简化测试用例的编写，实现数据驱动的测试流程，从而提高测试效率和覆盖率。核心关键词包括单元测试、参数化测试、数据驱动测试、JSON、CSV、TSV 以及仓颉 API。
