# 组件快捷键事件

This directory provides comprehensive documentation for implementing and managing keyboard shortcuts in the ArkUI framework using the Cangjie language. It covers essential technical concepts such as event processing logic, priority handling, and conflict resolution between custom and system shortcuts. The content includes detailed references for the `keyboardShortcut` interface, explaining how to configure custom key combinations, handle modifier keys, and manage focus-independent events. It is specifically designed for developers who need to integrate robust keyboard interactions, ensuring accessibility and efficient user control while avoiding conflicts with reserved system commands like Alt+F4. By mastering these guidelines, developers can create responsive interfaces that react to keyboard inputs even when components are not focused or visible.

## Detailed Description

### 快捷键使用注意事项.md 快捷键使用注意事项.md

This document serves as a technical reference guide for developers regarding the implementation and behavior of keyboard shortcuts within the system. It details the processing logic for various scenarios, including custom combinations, focus independence, and conflict resolution. Key information highlights that shortcuts take priority over standard key events, ignore case and left/right modifier distinctions, and respond even for hidden components. The document also lists prohibited system shortcuts like Alt+F4 and existing system events for navigation that override custom bindings. Intended for developers using the ArkUI framework, it provides essential rules for configuring the keyboardShortcut interface effectively.

### 组件快捷键事件_6more.md 组件快捷键事件_6more.md

This document provides API reference documentation for implementing custom keyboard shortcuts on ArkUI components using the Cangjie language. It details the keyboardShortcut function, covering four overloaded methods that accept either FunctionKey or String values combined with ModifierKey arrays, optionally including custom action callbacks. Key takeaways include that shortcuts trigger even if the component lacks focus or visibility, provided it is mounted in the focused window, and default to click behavior if no specific action is defined. This guide targets ArkUI developers seeking to enhance user interaction and accessibility through keyboard event handling.
