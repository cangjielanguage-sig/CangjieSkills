# enum_PropertyKey

This directory contains API reference documentation for the `PropertyKey` enum within the Cangjie multimedia framework. It defines constants for accessing and manipulating image metadata, including standard EXIF tags, GPS location data, camera settings, and proprietary extensions. The documentation covers read-write permissions, system capabilities, and API versioning for various properties like aperture, ISO, shutter speed, and scene detection. It is intended for developers building image processing or camera applications who need detailed programmatic access to image file properties.

### APERTURE_VALUE_19more.md APERTURE_VALUE_19more.md
This document serves as a reference for image metadata constants used within the Cangjie multimedia framework, defining keys for accessing various image properties like camera settings and copyright information. The file lists numerous constants including APERTURE_VALUE, ARTIST, BITS_PER_SAMPLE, and CAMERA_OWNER_NAME. Each entry details the constant's functionality, read-write permissions, required system capability, and the API version where it was introduced. Most constants are read-write and belong to the SystemCapability.Multimedia.Image.Core capability. While some properties like DATE_TIME and CAPTURE_MODE date back to version 12, many advanced metadata tags like CFA_PATTERN and CLOUD_ENHANCEMENT_MODE were introduced in version 19. This API reference is intended for developers working on image processing or camera applications in the Cangjie language who need to read or manipulate EXIF-style metadata.
