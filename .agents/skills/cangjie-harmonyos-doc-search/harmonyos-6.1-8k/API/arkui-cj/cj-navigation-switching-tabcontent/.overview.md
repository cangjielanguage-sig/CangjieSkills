# cj-navigation-switching-tabcontent

本目录提供了关于 ArkUI 框架中 TabContent 组件的详细 API 参考文档，专门针对使用 Cangjie 语言进行应用开发的场景。文档内容涵盖了 TabContent 组件的模块导入方式、支持的子组件、初始化方法以及通用属性与事件的具体限制。特别重点介绍了 tabBar 属性的多种重载形式，包括自定义构建函数、文本及图标设置等。此外，文档还明确了 TabContent 的尺寸由父组件决定、不支持直接滑动需嵌套 List 使用等关键约束。该资料适合具备 ArkUI 基础的开发人员查阅，旨在帮助开发者准确掌握参数定义和功能约束，从而高效构建 Tabs 组件内的切换页签内容视图。

### cj-navigation-switching-tabcontent.md

这是一份ArkUI框架中TabContent组件的API参考文档，旨在指导开发者使用Cangjie语言构建Tabs组件内的切换页签内容视图。文档主要涵盖模块导入、子组件支持、组件初始化方法以及通用属性与事件的限制说明。重点介绍了tabBar属性的多种重载形式，包括自定义构建函数、文本及图标设置。关键信息指出TabContent的尺寸由父组件决定，不支持直接滑动，需嵌套List使用。该文档面向具备ArkUI基础的开发人员，提供了详细的参数定义和功能约束说明。
