This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically detailing the implementation of the `CarryingOp` interface for the `UInt32` type. It focuses on a suite of arithmetic and bitwise operations designed to handle calculations safely using a wrapping strategy. The core functionality of these APIs involves returning a tuple containing the operation result alongside a Boolean flag that explicitly indicates if truncation or overflow occurred during the process. This documentation is essential for Cangjie developers who need to perform explicit overflow detection and handling, particularly in low-level programming contexts where precise integer control and safety are critical. Key topics include Cangjie, UInt32, overflow detection, wrapping strategy, and the `CarryingOp` interface.
