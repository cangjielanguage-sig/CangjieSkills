## Detailed Description

### class_SM4/

This directory contains the API reference documentation for the SM4 symmetric encryption algorithm within the Cangjie language. The content comprehensively covers the instantiation and configuration of the SM4 class, alongside encryption and decryption function interfaces designed for both arrays and streams. Key topics include parameter settings for various working modes such as ECB, CBC, and GCM, as well as specific requirements for IV lengths and padding mode rules. This documentation is tailored for developers who need to integrate the national cryptographic SM4 standard into Cangjie applications, facilitating the implementation of secure data transmission and processing.

### class_SecureRandom/

This directory provides the API reference documentation for the `SecureRandom` class in the Cangjie language, with a specific focus on generating cryptographically strong pseudo-random numbers. The documentation details the class definition, initialization methods suitable for high-security contexts, and functions capable of generating diverse data types, including integers of specified bit lengths, booleans, byte arrays, and floating-point numbers. By leveraging operating system or hardware entropy sources alongside OpenSSL algorithms, this class offers a higher security standard than the standard `Random` class. It is intended for developers specializing in cryptographic applications or privacy data protection, offering detailed interface descriptions and guidance on exception handling.
