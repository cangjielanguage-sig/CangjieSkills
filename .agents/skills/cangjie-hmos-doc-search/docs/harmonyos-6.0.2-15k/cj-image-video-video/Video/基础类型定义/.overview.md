# 基础类型定义

This directory provides essential API reference documentation for fundamental types used in media playback control within the ArkUI framework, specifically utilizing the Cangjie programming language. It encompasses the core `VideoController` class responsible for managing video instances, alongside critical enumeration types that define playback speeds and seek modes. The content covers a wide range of functionalities, including playback lifecycle management (start, pause, stop), progress navigation, display adjustments, and variable speed settings. It also details system capability requirements and API version availability. This documentation is primarily intended for application developers working on HarmonyOS who require precise control over multimedia features and user interaction interfaces in their applications. It serves as a foundational resource for understanding the structural components necessary for implementing robust video players and media handlers. By defining these core types, the directory ensures developers have the necessary tools to create responsive and user-friendly media experiences.

## Detailed Description

### class_VideoController.md class_VideoController.md
This document serves as API reference documentation for the VideoController class in the Cangjie language, designed to manage video playback within the ArkUI framework. It details the class constructor and various control methods including playback management (start, pause, stop, reset), progress seeking (setCurrentTime), and display mode adjustments (requestFullscreen, exitFullscreen). Key information includes the distinction between pausing and stopping behaviors, support for specific seek modes, and system capability requirements. This guide targets application developers building multimedia features in HarmonyOS using Cangjie, providing essential interfaces for controlling video instances and user interaction.

### enum_PlaybackSpeed_2more.md enum_PlaybackSpeed_2more.md
This API reference document defines enumeration types for media playback control in the Cangjie programming language. It covers the PlaybackSpeed enum, offering five speed multipliers ranging from 0.75x to 2.00x, and the SeekMode enum, which specifies four navigation strategies including keyframe-based and accurate seeking. Key information includes that both enums belong to the SystemCapability.ArkUI.ArkUI.Full system capability and are available starting from API version 12. This documentation targets developers building media applications using the ArkUI framework who need to implement variable playback speeds and precise media seeking functionality.
