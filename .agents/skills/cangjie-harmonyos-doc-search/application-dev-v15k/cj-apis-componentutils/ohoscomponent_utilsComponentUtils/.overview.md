# ohoscomponent_utilsComponentUtils

This directory contains API reference documentation for the `ohos.component_utils` module within the HarmonyOS ArkUI framework, specifically targeting the Cangjie language. It covers classes and utilities designed to retrieve and manipulate UI component geometric data, including size, position, and transformation states (translation, rotation, scaling). Key components include `ComponentUtils` for accessing component properties and data classes like `ComponentInfo`, `Offset`, `RotateResult`, `ScaleResult`, and `TranslateResult`. This documentation is suitable for HarmonyOS developers who need to programmatically access layout properties, implement custom animations, or handle precise component positioning and transformations in their applications.

### class_RotateResult.md class_RotateResult.md
This API reference document defines the RotateResult class, which encapsulates component rotation information for the ArkUI framework using the Cangjie language. The documentation details the class constructor and six read-only properties: x, y, and z representing the rotation axis vector; centerX and centerY for the transform center coordinates; and angle for the rotation degree. All parameters are of type Float32 and are required during object construction. This class is available starting from API version 19 under the SystemCapability.ArkUI.ArkUI.Full capability. The content targets software developers building UI components in HarmonyOS who need to handle or query rotation transformations programmatically.
