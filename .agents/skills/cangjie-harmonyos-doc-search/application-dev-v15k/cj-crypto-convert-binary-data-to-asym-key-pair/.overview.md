# cj-crypto-convert-binary-data-to-asym-key-pair

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language, specifically focusing on the critical security task of converting external binary data into usable asymmetric key pairs. Leveraging the robust capabilities of the CryptoArchitectureKit, the documentation covers a wide array of essential cryptographic algorithms, including ECC, SM2, and RSA. It provides in-depth technical guidance on processing various data formats such as raw binary data, PKCS#8, and X.509/DER. By demonstrating the practical application of classes like `AsyKeyGenerator` and `DataBlob`, alongside the `convertKey` method, this guide enables the seamless import and restoration of cryptographic keys. It is an invaluable tool for software developers and security engineers aiming to integrate pre-existing key material into Cangjie-based systems for robust encryption, decryption, and digital signature functionalities.

## Detailed Description

### 指定二进制数据转换非对称密钥对仓颉/
This directory provides technical guides for converting external binary data into asymmetric key pairs using the Cangjie programming language and the CryptoArchitectureKit. It covers specific algorithms including ECC, SM2, and RSA, detailing how to handle raw binary data, PKCS#8, and X.509/DER formats. The tutorials demonstrate the use of `AsyKeyGenerator`, `DataBlob`, and the `convertKey` method to import and restore cryptographic keys. These resources are designed for software developers and security engineers who need to integrate existing key material into Cangjie applications for encryption, decryption, or signature operations.
