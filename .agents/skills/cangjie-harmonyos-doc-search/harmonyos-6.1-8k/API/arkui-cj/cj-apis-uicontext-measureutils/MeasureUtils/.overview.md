# MeasureUtils

MeasureUtils 目录包含与 ArkUI 框架中文本测量和布局计算相关的 API 参考文档。该目录主要涵盖了用于计算文本宽度、高度的工具类，以及用于配置测量参数（如字体样式、约束宽度）和定义尺寸选项的类。这些工具适用于需要精确控制 UI 布局和文本渲染的场景，特别是针对 HarmonyOS 应用开发者。核心关键词包括 ArkUI、文本测量、UIContext、Cangjie 语言、布局计算、MeasureOptions 和 SizeOptions。该文档适合从事 ArkUI 应用开发并需要进行复杂文本尺寸计算的开发人员参考。
