### class_CJLeakWatcherT.md

This API reference document details the CJLeakWatcher class, designed to detect potential memory leaks in Cangjie objects within the HiChecker system capability. It covers the class definition and four primary methods: enable for activation, watch for registering objects with custom messages, check for retrieving leak lists, and dump for exporting leak data and heap snapshots to files. Key functionality involves triggering garbage collection to identify unrecovered objects. Targeted at Cangjie developers using the PerformanceAnalysisKit, this guide provides code examples for debugging memory issues and managing object lifecycles.
