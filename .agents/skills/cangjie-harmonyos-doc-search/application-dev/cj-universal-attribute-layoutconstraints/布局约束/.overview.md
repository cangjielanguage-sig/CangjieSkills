# 布局约束

This directory serves as a comprehensive guide for developers working with the HarmonyOS ArkUI framework and the Cangjie programming language, focusing specifically on the implementation and management of layout constraints. It provides a robust set of resources designed to help developers control the dimensions, positioning, and flow of UI components effectively. The directory includes detailed API documentation for fundamental functions such as `constraintSize`, `align`, and `direction`, alongside practical code examples that demonstrate how to apply these concepts in real-world scenarios. Key topics include defining component boundaries, aligning elements within parent containers, and managing layout direction. Furthermore, it offers tutorials on advanced responsive behaviors, such as setting aspect ratios and controlling component visibility based on available space. This documentation is suitable for software developers and UI engineers who are building adaptive user interfaces and need to ensure their applications render correctly across various device form factors.

## Detailed Description

The following files provide the specific technical details and code implementations necessary to master layout constraints in your projects.

### 布局约束_5more.md 布局约束_5more.md

This API reference documentation details layout constraint functions for the ArkUI framework in the Cangjie programming language. It covers three primary functions: `constraintSize` for defining component dimensions, `align` for positioning elements within parent containers, and `direction` for controlling layout flow. Key information includes that `constraintSize` accepts optional min/max width and height parameters, while `align` specifies valid parent components like Stack, Button, and Text. All functions return a generic type T and require system capability ArkUI.Full starting from version 22. This guide is intended for developers building UI layouts using the Cangjie language and ArkUI framework.

### 示例代码.md 示例代码.md

This document provides practical Cangjie code examples for HarmonyOS ArkUI developers, specifically focusing on layout constraints and component visibility management. It is divided into two main examples: setting component aspect ratios using `aspectRatio` and managing display priority using `displayPriority`. The first example illustrates how `aspectRatio` affects width and height calculations within Row and Grid containers. The second example demonstrates how `displayPriority` dynamically hides or shows child components in a Flex container based on available space and assigned priority levels. This tutorial targets developers familiar with the Cangjie language and ArkUI framework who need to implement responsive layout behaviors.
