# class_JSClass

This directory provides API reference documentation for the `JSClass` component in the Cangjie language, focusing on ArkUI cross-language interoperability. It details how to securely reference and manipulate ArkTS class constructors, including extending functionality with accessors and methods. The content covers object instantiation, property management, and the integration of `JSFunction` or `JSLambda` implementations. Targeted at developers utilizing the NAPI subsystem to bridge native code with JavaScript, these documents require familiarity with ArkTS and Cangjie syntax, supporting system capabilities from version 13 onwards.

### class_JSClass_5more.md class_JSClass_5more.md
This API reference document details the JSClass in the Cangjie language, providing a secure reference to an ArkTS class constructor for manipulation. The documentation covers the read-only prototype property and methods for extending class functionality, specifically addAccessor for defining getters and setters, and addMethod for adding new methods. Key information includes the class inheritance from JSProxyWithSubRef and support for JSFunction or JSLambda implementations. Intended for developers working on ArkUI cross-language interoperability using Napi, this guide requires knowledge of ArkTS and system capabilities starting from version 13.
