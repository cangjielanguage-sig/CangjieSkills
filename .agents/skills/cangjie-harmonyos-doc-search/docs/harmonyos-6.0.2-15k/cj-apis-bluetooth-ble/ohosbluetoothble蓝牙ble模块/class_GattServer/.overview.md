# class_GattServer

This directory contains API reference documentation for the GattServer class in the Cangjie language, designed for managing Bluetooth Low Energy (BLE) server operations within the ConnectivityKit. It covers the complete lifecycle of a GATT server, including service management, client connection handling, and data exchange mechanisms such as read/write requests and notifications. Key topics include adding and removing services, handling characteristic and descriptor interactions, and managing server callbacks. This documentation is intended for developers building BLE server-side applications who require a detailed understanding of GATT protocols and Cangjie syntax.

## Detailed Description

### class_GattServer_2more.md
This document provides API reference for the GattServer class in Cangjie, covering class definition, system capabilities, and the `addService` method. It details parameters, exceptions, and error codes, including a code example for constructing BLE services. It targets developers using ConnectivityKit.
