This directory focuses on Composite Gestures within the Cangjie UI framework, specifically designed for HarmonyOS application development. It provides comprehensive resources on how to combine basic gestures—such as tapping, long-pressing, and dragging—into sophisticated, multi-step interaction patterns using the `GestureGroup` component. The content covers essential technical concepts including the three distinct recognition modes: Sequence (serial execution), Parallel (simultaneous recognition), and Exclusive (competition-based). It also addresses event management, such as handling cancellations and state updates. This collection is highly suitable for HarmonyOS developers and UI engineers who are proficient in Cangjie syntax and ArkUI basics, and who need to create responsive, touch-driven user interfaces with complex logic. By mastering these composite gestures, developers can significantly enhance the interactivity and user experience of their applications.
