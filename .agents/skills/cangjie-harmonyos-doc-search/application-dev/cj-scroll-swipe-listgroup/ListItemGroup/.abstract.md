This directory contains documentation and resources for the ListItemGroup component within the ArkUI framework, specifically designed for the Cangjie language. It covers the implementation of grouped list layouts, including API references for component attributes, initialization constructors, and type definitions for dividers and styles. The content also includes practical code examples demonstrating sticky headers and footers. Suitable for HarmonyOS developers and software engineers looking to create structured, customizable list interfaces with specific design requirements and system compatibility standards.
