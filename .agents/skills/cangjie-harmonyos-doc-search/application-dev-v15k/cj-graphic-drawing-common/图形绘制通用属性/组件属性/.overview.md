# 组件属性

This directory contains API reference documentation for configuring UI component properties within the Cangjie ArkUI framework. It covers essential visual styling aspects, including anti-aliasing, fill colors, opacity settings, component dimensions, and comprehensive stroke styling for borders. The documents provide detailed function parameters, data type constraints, default values, and clamping rules to ensure precise UI rendering. It is specifically designed for developers using the Cangjie language who require programmatic control over the appearance and layout of graphical components in ArkUI applications.

## Detailed Description

### func_antiAliasBool_7more.md func_antiAliasBool_7more.md
This document serves as an API reference for configuring visual properties and dimensions of UI components in the Cangjie ArkUI framework. It details functions for anti-aliasing, fill color, fill opacity (supporting Float64, Int64, and AppResource types), height, and size. Key information includes specific parameter constraints, default values (e.g., anti-aliasing is true by default), and clamping rules for opacity values. The `fill` function overrides `foregroundColor` if set later. Targeted at developers using ArkUI, this reference requires knowledge of Cangjie syntax and basic UI concepts to implement component styling effectively.

### func_strokeOpacityFloat64_5more.md func_strokeOpacityFloat64_5more.md
This API reference document details Cangjie functions for configuring border and component dimensions within the ArkUI framework. It covers overloaded strokeOpacity methods accepting Float64, Int64, and AppResource types, alongside strokeWidth and width functions. Key information includes automatic value clamping for opacity between 0 and 1, and specific unit handling for width properties, such as defaulting to vp and restricting percentage usage. All methods return This to support fluent interface design. This documentation targets ArkUI developers using the Cangjie language who need to programmatically style UI component strokes and layout dimensions.

### func_strokeResourceColor_7more.md func_strokeResourceColor_7more.md
This document serves as API reference documentation for stroke styling functions within the Cangjie ArkUI framework. It covers seven distinct functions used to configure border properties, including color, dash arrays, offsets, line caps, line joins, and miter limits. Key information includes parameter definitions, default values, and specific constraints, such as the requirement for miter limits to be greater than or equal to 1.0. The document is intended for developers working with ArkUI system capabilities starting from version 12, providing the necessary syntax to customize graphical stroke appearances programmatically.
