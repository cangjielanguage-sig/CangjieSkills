# struct_Watcher

This directory provides comprehensive API reference documentation for the `Watcher` struct within the HiAppEvent system, specifically tailored for developers using the Cangjie language in HarmonyOS. The documentation also clarifies the functional differences between batch processing callbacks and real-time callbacks, ensuring developers can effectively manage event subscription and filtering logic in their applications. This resource is vital for those looking to integrate robust event observation capabilities into their HarmonyOS software.
