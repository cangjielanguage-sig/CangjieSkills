This directory provides technical guides for converting external binary data into asymmetric key pairs using the Cangjie programming language and the CryptoArchitectureKit. It covers specific algorithms including ECC, SM2, and RSA, detailing how to handle raw binary data, PKCS#8, and X.509/DER formats. The tutorials demonstrate the use of `AsyKeyGenerator`, `DataBlob`, and the `convertKey` method to import and restore cryptographic keys. These resources are designed for software developers and security engineers who need to integrate existing key material into Cangjie applications for encryption, decryption, or signature operations.
