# Tablet

This directory contains reference documentation defining the SystemCapability (SysCap) sets supported by Tablet devices within the HarmonyOS or OpenHarmony ecosystem. It outlines the minimum system capabilities, subsystems, and feature sets available for developers, covering areas such as ArkUI, multimedia, communication, security, and distributed hardware. These documents are essential for verifying API availability, configuring device profiles, and ensuring application compatibility without requiring isolation checks. They are suitable for application developers, system integrators, and device engineers working on tablet-specific builds.

## Detailed Description

### Tablet_1.md Tablet_1.md
This document serves as a reference guide defining the SystemCapability (SysCap) set supported by Tablet devices. It introduces the concept of SysCap as independent operating system features and advises developers to consult the SysCap usage guide before development. The text specifies that the list represents the minimum system capability set for the current version, which can be verified via the tablet.json file in the SDK. A key takeaway is that developers can directly invoke APIs corresponding to these capabilities without performing canIUse() isolation checks. This information is intended for application developers building Tablet applications to ensure compatibility and efficiency.
