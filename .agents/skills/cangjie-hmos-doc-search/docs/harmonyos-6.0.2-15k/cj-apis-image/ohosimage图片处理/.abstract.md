This directory contains comprehensive API reference documentation for the `ohos.image` module in the Cangjie programming language, designed for HarmonyOS application development. It covers core image processing capabilities including image decoding, encoding, PixelMap manipulation, and High Dynamic Range (HDR) support based on ISO 21496-1 standards. The documentation details classes, enums, structs, and functions for tasks ranging from basic image creation to advanced metadata management. It is intended for software developers and multimedia engineers building robust image applications using the ImageKit framework and SystemCapability.Multimedia.Image.Core.
