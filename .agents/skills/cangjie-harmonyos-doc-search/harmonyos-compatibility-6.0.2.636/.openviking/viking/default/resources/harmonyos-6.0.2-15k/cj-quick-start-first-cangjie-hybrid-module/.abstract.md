This directory provides a specialized technical guide for HarmonyOS developers focusing on the incremental adoption of the Cangjie programming language within existing ArkTS projects. It addresses the complexities of hybrid development, offering a structured approach to blending ArkTS and Cangjie codebases efficiently. The guide covers essential workflows such as initializing the project structure, managing module dependencies, and establishing robust interoperability for both logic and UI components. By utilizing DevEco Studio and Interop annotations, developers can efficiently call Cangjie interfaces—handling both synchronous and asynchronous operations—and embed Cangjie UI elements into ArkTS pages. This resource is tailored for developers who wish to leverage Cangjie's performance benefits in legacy applications without undertaking a full system rewrite, ensuring a smooth, cost-effective, and modern transition path for enterprise-grade applications.
