### 使用SM4对称密钥GCM模式分段加解密仓颉_2more.md 使用SM4对称密钥GCM模式分段加解密仓颉_2more.md
This technical guide details the implementation of segmented encryption and decryption using the SM4 symmetric key algorithm in GCM mode within the Cangjie programming environment. The document focuses specifically on the encryption workflow, covering key generation, Cipher instance creation, initialization, data segmentation via the update method, finalization, and authentication tag extraction. Key takeaways include the importance of handling the update method's output, noting that block modes like ECB/CBC buffer data until a block is full, whereas stream modes output immediately. It emphasizes extracting the 16-byte authTag for decryption verification. This guide targets Cangjie developers using the CryptoArchitectureKit who need to process large data in segments.
