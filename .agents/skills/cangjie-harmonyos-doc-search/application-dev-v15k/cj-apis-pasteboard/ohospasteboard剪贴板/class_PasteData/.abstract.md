This directory contains API reference documentation for the `PasteData` class in the Cangjie programming language, specifically designed for HarmonyOS/OpenHarmony development. It covers the creation, manipulation, and retrieval of clipboard content, including text, HTML, images, and custom binary data. The documentation details methods for adding records, managing properties, and extracting specific data types. It is suitable for software developers implementing clipboard functionality using the BasicServicesKit, providing essential code examples and system capability requirements for system version 12.
