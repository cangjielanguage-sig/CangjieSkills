This directory contains API reference documentation for the `ohos.i18n` module within the Cangjie LocalizationKit, designed to facilitate internationalization (I18n) and localization in HarmonyOS applications. It covers a wide range of functionalities including text normalization, entity recognition, phone number formatting, holiday management, and locale-specific indexing. The documentation also details utilities for handling calendars, time zones, Unicode character analysis, and system locale settings. It is intended for Cangjie developers and software engineers implementing robust global features, text processing, and cultural adaptation in their applications.
