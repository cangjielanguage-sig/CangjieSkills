This directory contains API reference documentation for the `UdpSocket` class in the Cangjie programming language. It covers the implementation of User Datagram Protocol (UDP) packet communication, including socket creation, configuration, data transmission, and reception. Key topics include socket options (reuseAddress, reusePort), buffer management, timeouts, and exception handling. The documentation details methods for binding, connecting, and closing sockets, as well as low-level system parameter retrieval. It is suitable for Cangjie developers building network applications who require precise control over connectionless communication and socket behavior.
