# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental data structures and event classes within the ArkUI framework, specifically designed for the Cangjie language. It covers the core definitions required for handling input device interactions and UI gestures. Key topics include the BaseEvent class for system events, BaseGestureEvent for finger tracking, and specific gesture types like pinch, rotation, and swipe. Additionally, it details structures for gesture judgment and categorization. This documentation is essential for developers building interactive applications who need to implement custom event handling and gesture recognition logic.

## Detailed Description

### class_BaseEvent.md class_BaseEvent.md
This API reference document defines the `BaseEvent` class, which serves as the foundational base class for event information in the Cangjie language. The content details the class structure and provides specifications for various read-only properties, including target, timestamp, source, pressure, tilt angles, axis values, and device ID. Key information includes the `getModifierKeyState` function for querying modifier key states like Ctrl and Alt. Intended for developers working with the ArkUI framework, this document supports `SystemCapability.ArkUI.ArkUI.Full` starting from version 19, providing essential data structures for handling input device interactions.

### class_BaseGestureEvent_3more.md class_BaseGestureEvent_3more.md
This document serves as API reference documentation for gesture event classes in the Cangjie language, specifically for the ArkUI framework. It covers the `BaseGestureEvent` base class, which stores finger information, and its derived classes: `LongPressGestureEvent` for tracking repeat triggers and `PanGestureEvent` for handling sliding movements. Key properties include offset coordinates and velocity vectors for pan gestures, measured in viewport units. Intended for software developers, this reference requires familiarity with Cangjie syntax and UI interaction design to implement custom gesture recognition and handling logic.

### class_GestureInfo_3more.md class_GestureInfo_3more.md
This API reference document defines data structures for handling gestures within the ArkUI framework using the Cangjie language. It details the `GestureInfo` class, which encapsulates basic gesture properties including tag, type, and system gesture status. The document also enumerates `GestureTypes` to categorize interactions such as tap, long press, pan, pinch, swipe, and rotation. Additionally, it explains `GestureJudgeResult`, which provides outcomes for custom gesture judgment logic, specifically `CONTINUE` and `REJECT` states. Intended for developers building interactive UIs, this documentation facilitates the implementation and customization of gesture recognition systems.

### class_PinchGestureEvent_4more.md class_PinchGestureEvent_4more.md
This API reference document defines specific gesture event classes for the Cangjie language within the ArkUI framework. It details four classes inheriting from `BaseGestureEvent`: `PinchGestureEvent`, `RotationGestureEvent`, `SwipeGestureEvent`, and `TapGestureEvent`. Key properties include scale and center coordinates for pinch gestures, rotation angle, and swipe speed and angle. These read-only events serve as parameters for the `onGestureJudgeBegin` callback. The content targets developers implementing gesture recognition in ArkUI applications, requiring knowledge of the Cangjie language and system capabilities.
