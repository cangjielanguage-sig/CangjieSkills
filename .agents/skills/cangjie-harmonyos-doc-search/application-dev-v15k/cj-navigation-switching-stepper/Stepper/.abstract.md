This directory contains documentation for the Stepper component within the ArkUI framework, designed for developers using the Cangjie language. It covers the implementation of navigation tools used to display progress across multiple task steps. Key topics include component initialization, child component restrictions (StepperItem), state management, and event handling for navigation logic. This resource is suitable for software developers building structured, multi-step user interfaces for HarmonyOS applications, providing both API references and practical code examples.
