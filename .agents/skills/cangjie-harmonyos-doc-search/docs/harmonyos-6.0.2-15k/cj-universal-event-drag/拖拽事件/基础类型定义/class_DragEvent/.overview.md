# class_DragEvent

This directory provides comprehensive API reference documentation for the `DragEvent` class within the Cangjie language, specifically tailored for the ArkUI framework. It encompasses the essential tools required to handle complex drag-and-drop interactions in application development. Key topics include public properties such as `dragBehavior` and `useCustomDropAnimation`, as well as methods for accessing real-time data like coordinates, velocity, and keyboard modifier states. The documentation also explains how to manage system versus custom drop animations. This resource is intended for software developers and engineers working on HarmonyOS applications who need to implement or customize interactive drag-and-drop functionality, requiring SystemCapability.ArkUI.ArkUI.Full (version 19 or later).

This document serves as an API reference for drag event handling functions within the ArkUI framework using the Cangjie language. It details four specific methods: getVelocityY, getWindowX, getWindowY, and setResult. Key information includes that getVelocityY returns the vertical drag speed in vp, getWindowX and getWindowY provide coordinates relative to the window's top-left corner, and setResult modifies the drag event outcome. All functions require the SystemCapability.ArkUI.ArkUI.Full capability and are available starting from version 19. This documentation targets application developers implementing interactive drag-and-drop features in HarmonyOS applications.
