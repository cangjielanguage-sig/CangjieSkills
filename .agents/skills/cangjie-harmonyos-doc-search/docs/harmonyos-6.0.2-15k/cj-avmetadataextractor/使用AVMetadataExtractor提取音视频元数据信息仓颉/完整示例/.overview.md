# 完整示例

This directory provides comprehensive Cangjie code examples designed for HarmonyOS developers focusing on advanced media processing and application architecture. It covers the extraction of audio metadata and album covers using the MediaKit framework, demonstrating various methods for setting data sources, including file descriptors from resource managers, sandbox paths, and custom data source descriptors with callbacks. Furthermore, it illustrates the implementation of custom data source logic for file reading operations using FileFs and the management of application lifecycle events within the UIAbility framework. These examples are essential for developers seeking to integrate robust media handling, resource management, and file I/O operations into their HarmonyOS applications using the Cangjie programming language. The content assumes prior knowledge of Cangjie, UI components, and file system operations.

## Detailed Description

### 完整示例_1.md
This document provides a complete Cangjie code example demonstrating how to extract audio metadata and album covers using the MediaKit. It covers three methods for setting data sources: using a file descriptor from resource manager, using a file descriptor from a sandbox path, and using a data source descriptor with a callback. Key takeaways include the instantiation of AVMetadataExtractor, configuration of fdSrc or dataSrc, retrieval of metadata and pixel maps, and the importance of resource release. Intended for HarmonyOS developers, this tutorial requires knowledge of the Cangjie language, UI components, and file system operations.

### 完整示例_2.md
This document provides Cangjie code examples demonstrating custom data source implementation and application lifecycle management. It covers the DataSrcCallback class, which handles file reading operations using FileFs.read with specific offsets and lengths, and the MainAbility class, which manages app initialization and UI content loading. Key takeaways include the callback logic for returning byte counts and the ability lifecycle methods like onCreate and onWindowStageCreate. Intended for Cangjie developers, this reference illustrates how to integrate file I/O callbacks within a standard UI application framework. Keywords: Cangjie, DataSrcCallback, MainAbility, FileFs, UIAbility, lifecycle.
