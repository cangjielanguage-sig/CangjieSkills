This directory provides a comprehensive guide to the `@Builder` macro in the Cangjie UI framework, focusing on creating custom build functions to abstract repetitive UI elements. It covers implementation methods (private vs. global), parameter passing rules (pass-by-value vs. pass-by-reference), and complex usage scenarios involving dynamic rendering and state management. Key topics include UI modularity, state synchronization, and component encapsulation. This resource is designed for developers familiar with Cangjie's declarative UI who aim to optimize code maintenance and build efficient, responsive HarmonyOS applications.
