This directory provides a comprehensive collection of example code tailored for developers utilizing the Cangjie language and the ArkUI framework. It focuses on the critical aspect of touch event dispatch strategies, offering detailed guidance on managing and resolving gesture conflicts between overlapping UI components, specifically Lists and Buttons. The content covers the practical application of the `touchTestInfo` function and the `onChildTouchTest` modifier to customize event distribution behaviors. By examining different strategies such as FORWARD_COMPETITION, FORWARD, and DEFAULT, developers can gain a deeper understanding of how to balance scrolling capabilities with click responsiveness. These resources are ideal for UI developers and HarmonyOS engineers seeking to implement sophisticated touch event handling and ensure smooth, intuitive user interactions in their applications.
