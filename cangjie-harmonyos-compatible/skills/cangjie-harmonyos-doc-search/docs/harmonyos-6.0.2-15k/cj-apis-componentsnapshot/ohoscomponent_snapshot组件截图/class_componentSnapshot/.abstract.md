This directory provides comprehensive API documentation for the `componentSnapshot` class within the Cangjie language and ArkUI framework. It covers the core functionality required to capture screenshots of loaded UI components, including both synchronous and asynchronous methods. The content details system capabilities, version requirements (API 19), and implementation examples for handling PixelMap data and off-screen rendering. It is suitable for HarmonyOS developers looking to integrate image capture features, manage component snapshots via IDs, or render custom UI components off-screen using the `createFromBuilder` function.
