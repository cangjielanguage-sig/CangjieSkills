This directory provides comprehensive API reference documentation for scroll-related event callbacks within the Cangjie ArkUI framework. It details the lifecycle of scroll components, covering events triggered before, during, and after scrolling actions. Key topics include offset calculation logic, state management, and the handling of specific conditions like reaching boundaries or edges. The documentation also highlights important deprecations, such as the shift from `onScroll` to `onWillScroll` and `onScrollEnd` to `onScrollStop`. This resource is essential for developers building interactive, scrollable interfaces who require precise control over component behaviors and event responses in Cangjie applications.
