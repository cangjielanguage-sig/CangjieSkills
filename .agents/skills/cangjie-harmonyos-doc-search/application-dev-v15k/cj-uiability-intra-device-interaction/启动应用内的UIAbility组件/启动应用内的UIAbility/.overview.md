# 启动应用内的UIAbility

This directory serves as a technical resource for developers working with HarmonyOS, focusing specifically on the lifecycle management of UIAbility components within a single application. It details the procedures for launching specific UIAbilities from other components, emphasizing the configuration of Want objects and the transfer of custom parameters via Cangjie code. Additionally, it covers the termination of instances and processes, including snapshot management and configuration in module.json5. By integrating concepts from the AbilityKit APIs and lifecycle callbacks like onCreate and onNewWant, this guide assists developers in building efficient multi-module applications with seamless internal navigation and robust state management.

## Detailed Description

### 启动应用内的UIAbility_1.md
This technical guide explains how to start a specific UIAbility from another within the same HarmonyOS application. It covers the implementation process for both the calling and target abilities. Key sections include configuring the Want object with parameters like bundleName and abilityName in the caller, and receiving data in the target's onCreate or onNewWant lifecycle callbacks. The document provides Cangjie code examples demonstrating how to pass custom parameters and context information. It is intended for developers building multi-module applications who need to manage internal navigation and data transfer between UIAbility components.

### 启动应用内的UIAbility_2.md
This technical guide explains methods for terminating UIAbility instances and application processes within HarmonyOS development using the Cangjie language. It covers stopping a specific UIAbility instance via the terminateSelf() method and closing all application processes using ApplicationContext.killAllProcesses(). Key information includes the default behavior of retaining task snapshots after termination, which can be disabled by configuring the removeMissionAfterTerminate field in module.json5. The document provides code examples demonstrating context retrieval and exception handling. This guide targets HarmonyOS developers managing application lifecycle and UIAbility states, requiring knowledge of the Cangjie syntax and AbilityKit APIs.
