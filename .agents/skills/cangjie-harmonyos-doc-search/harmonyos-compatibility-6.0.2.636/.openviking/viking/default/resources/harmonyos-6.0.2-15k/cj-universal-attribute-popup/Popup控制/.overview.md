# Popup控制

This directory provides comprehensive documentation for controlling popup windows within the ArkUI framework using the Cangjie language. It covers the `bindPopup` API, configuration options for standard and custom popups, and state management for visibility control. Key topics include event handling, styling properties, and lifecycle constraints to prevent layout errors. This resource is suitable for HarmonyOS developers and UI engineers looking to integrate interactive overlay elements, manage component states programmatically, and enhance user interface interactivity in their applications.

## Detailed Description

### Popup控制_3more.md Popup控制_3more.md
This API reference document details how to bind and control popup windows for UI components within the ArkUI framework using the Cangjie language. It covers two overloaded bindPopup functions that accept either CustomPopupOptions or PopupOptions to configure content and behavior. Key information includes the critical constraint that the show parameter cannot be set to true during page construction to avoid layout errors, and that popup visibility is managed via state changes rather than component lifecycle. This guide is intended for developers implementing interactive overlay elements in ArkUI applications.

### 示例代码.md 示例代码.md
This document provides a practical Cangjie code example demonstrating how to implement and configure popup components in a HarmonyOS application. It covers the `bindPopup` method, utilizing `PopupOptions` for standard dialogs with action buttons and `CustomPopupOptions` for custom content builders. Key information includes state management for visibility control, event callbacks like `onStateChange` and `onWillDismiss`, and styling properties such as background blur, arrow positioning, and transitions. This example targets HarmonyOS developers using the Cangjie language who need to integrate interactive popup menus into their UI components.
