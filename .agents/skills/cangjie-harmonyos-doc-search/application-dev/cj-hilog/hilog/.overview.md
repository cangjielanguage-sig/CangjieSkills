# hilog

This directory provides a complete technical overview of the HiLog logging system, a command-line utility essential for frameworks, services, and applications to record operations and system status. The documentation covers critical aspects such as environment setup, specifically the necessity of the hdc tool, and offers a detailed table of command-line options. Users will find extensive guidance on buffer management, log filtering by type or domain, flow control mechanisms, and procedures for dumping logs to disk with compression. It also addresses output formatting and privacy controls. This resource is tailored for developers and system administrators seeking to debug, monitor, and maintain system health effectively.
