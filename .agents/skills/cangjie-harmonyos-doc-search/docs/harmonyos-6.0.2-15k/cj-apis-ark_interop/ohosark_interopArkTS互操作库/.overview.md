# ohosark_interopArkTS互操作库

This directory contains the API reference documentation for the `ohos.ark_interop` library, designed to facilitate seamless interoperability between the Cangjie programming language and ArkTS within the HarmonyOS ecosystem. It covers a comprehensive range of classes, structs, and interfaces for managing JavaScript runtime environments, data types (arrays, strings, promises), and error handling. Key components include JSRuntime, JSContext, and various wrappers for ArkTS objects. This documentation is essential for Cangjie developers working on ArkUI applications who need to integrate native code with JavaScript logic using the Napi framework, ensuring type safety and efficient cross-language communication.
