This directory provides comprehensive API documentation for the Cangjie language, specifically focusing on the implementation of the `ThrowingOp` interface for the `IntNative` type. It covers a range of arithmetic and bitwise operations designed to prioritize safety by throwing exceptions—such as `OverflowException` and `OvershiftException`—upon encountering errors, rather than silently wrapping values or resulting in undefined behavior. Key topics include addition, multiplication, division, negation, and bit shifting. This resource is essential for Cangjie developers who require robust integer arithmetic and explicit error handling strategies to ensure application stability and correctness. By utilizing these APIs, developers can prevent common bugs associated with integer overflows and invalid shift operations, making it a critical reference for building secure, reliable, and high-performance systems where data integrity is paramount. The documentation ensures that developers have all the necessary information to implement safe numerical computations effectively.
