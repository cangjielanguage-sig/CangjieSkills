This directory provides essential API reference documentation for the `BenchmarkConfig` interface, a key component for performance testing in the Cangjie language. It focuses on extending the `Configuration` class to facilitate detailed benchmark configurations. The documentation covers critical parameters such as batch execution sizes, garbage collection behavior, minimum batch counts, execution duration, and warmup periods. By explaining function signatures for integers, ranges, and durations, it allows developers to customize the `@Configuration` macro for precise control over test execution. This resource is intended for Cangjie developers and QA engineers who need to configure and optimize performance benchmarks within the unittest framework.
