This directory defines fundamental data types and classes for gesture recognition within the Cangjie ArkUI framework. It covers core components such as `EventTargetInfo` for accessing component metadata, the base `GestureRecognizer` class for managing gesture states, properties, and validity, and specialized recognizers like `PanGestureRecognizer` for handling drag interactions. Additionally, it includes enumerations for operational states (e.g., Ready, Detecting) and information classes for scrollable targets. These definitions are essential for developers building interactive user interfaces, providing the necessary building blocks to handle, inspect, and control gesture events effectively in applications targeting version 20 or later.
