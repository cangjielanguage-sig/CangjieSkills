This directory contains the API reference documentation for the `ohos.ark_interop` library, designed to facilitate seamless interoperability between the Cangjie language and ArkTS (TypeScript/JavaScript) within the HarmonyOS ecosystem. It covers core interfaces for type conversion, runtime management, object manipulation, and asynchronous operations using the Napi framework. The documentation includes classes for handling arrays, functions, promises, and modules, alongside exception handling mechanisms. It is intended for Cangjie developers building native modules or cross-language applications requiring efficient data exchange and execution control between native and ArkTS environments.
