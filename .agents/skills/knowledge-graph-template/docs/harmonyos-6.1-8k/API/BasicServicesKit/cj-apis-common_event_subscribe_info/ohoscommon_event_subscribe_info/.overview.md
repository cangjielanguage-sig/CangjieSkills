## 详细描述

### class_CommonEventSubscribeInfo.md
这是一份Cangjie语言的API参考文档，用于定义公共事件订阅者的信息类`CommonEventSubscribeInfo`。文档涵盖了该类的核心属性，包括订阅事件列表、优先级范围、用户ID及发布者权限等，并详细说明了构造函数的参数配置。关键信息指出优先级限制在-100到1000之间，且设备ID目前为预留能力。该文档主要面向使用系统通知能力的应用开发者，提供了配置订阅条件的具体规范。
