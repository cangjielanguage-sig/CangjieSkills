# 功能介绍

This directory contains essential reference documentation for the `convert` package within the Cangjie programming language ecosystem. It provides a deep dive into the mechanisms required for converting strings to various data types and formatting types back into strings. The documentation thoroughly explains the `Formattable` interface, which is central to these operations, and breaks down the complex syntax of format specifications. Developers will find detailed explanations on how to utilize flags, width, precision, and specifiers to customize output. The guide also covers advanced formatting options, such as controlling alignment, adding padding, and switching between different numeric bases like binary, octal, and hexadecimal. Furthermore, it addresses the nuances of floating-point precision. This resource is specifically tailored for Cangjie developers aiming to master data presentation and conversion logic in their applications.

### 功能介绍_1.md
This file serves as the primary reference documentation for the `convert` package in the Cangjie language. It focuses on two main areas: string-to-type conversions and type-to-string formatting.

Key components covered in this document include:
*   **The Formattable Interface:** An overview of the interface used to handle formatting logic.
*   **Format Specification Syntax:** A detailed breakdown of the syntax, including:
    *   Flags for modifying output behavior.
    *   Width and precision settings for controlling layout.
    *   Specific specifiers for different data types.
*   **Output Control:** Instructions on how to manage alignment, padding, and numeric bases (binary, octal, hexadecimal).
*   **Floating-Point Precision:** Guidelines for setting precision in floating-point numbers.

The document targets Cangjie developers seeking to implement or utilize data conversion and formatting features in their applications.
