This directory contains API reference documentation for the `ohos.resource_manager` module in the Cangjie programming language, designed for HarmonyOS application development. It covers the core classes and enumerations necessary for managing application resources, handling device configurations, and adapting to different screen densities and locales. Key components include the ResourceManager, AppResource, and Configuration classes, alongside various enums for device types and display modes. This documentation is suitable for Cangjie developers who need to programmatically access resources, implement multi-language support, and ensure their applications adapt seamlessly to diverse device capabilities and user settings.
