# 接入步骤

本目录包含关于HarmonyOS应用间文件共享与打开的接入指南。文档详细介绍了如何使用仓颉语言实现文件打开功能的完整流程，涵盖了目标方（接收方）和调用方（发起方）的配置与代码实现。核心内容包括module.json5配置、Want对象构造、URI转换及权限设置。该指南适合需要实现应用间文件交互、数据共享功能的HarmonyOS开发者，特别是使用仓颉语言进行开发的用户。

## 详细描述

### 目标方接入步骤_3bc6eb93.md 目标方接入步骤_3bc6eb93.md
本文档旨在指导开发者如何配置应用以支持打开本地文件。文档主要涵盖两个核心步骤：一是在module.json5配置文件中声明文件打开能力，包括设置actions、uris的scheme及linkFeature；二是在应用代码中处理待打开文件，通过Want对象获取URI并使用FileIo进行读写操作。关键信息包括必须填写的配置字段及Cangjie语言的代码实现示例。该文档面向需要实现文件处理功能的HarmonyOS应用开发者，提供了从配置到编码的完整接入流程。

### 调用方接入步骤.md 调用方接入步骤.md
本教程指导开发者使用仓颉语言实现调用方接入以打开文件。文档涵盖四个主要步骤：导入AbilityKit等必要模块，获取应用文件路径并转换为URI，构造包含特定权限和操作的请求数据，以及调用startAbility接口。关键信息包括使用FileUri进行路径转换，通过flags配置读写权限，以及将action设置为"ohos.want.action.viewData"。该文档面向熟悉仓颉语法和AbilityKit框架的鸿蒙应用开发者，提供了处理文件共享场景的完整代码示例。
