# WebSocket_编程

本目录专注于仓颉语言中WebSocket协议的编程实现与应用。内容涵盖了从协议基础、握手升级流程、帧结构定义到数据报文读写操作的核心机制。文档详细介绍了如何通过WebSocket类建立长连接，处理不同类型的帧（如文本、二进制、Ping、Close及分片帧），并提供了完整的服务器端编程示例。适合具备网络编程基础的仓颉开发者，旨在指导其实现高效的实时双向通讯功能。

## 快速导航

  → 学习握手升级、帧结构定义及数据读写操作：WebSocket_编程_1.md
- **你想实现 WebSocket 服务器端并处理复杂帧类型？**
  → 掌握连接握手、子协议协商及分片数据处理：WebSocket_编程_2.md

## 详细描述

### WebSocket_编程_1.md
本文档旨在介绍仓颉语言中WebSocket协议的编程实现与应用机制。主要涵盖WebSocket协议基础、握手升级流程、帧结构定义（包括控制帧与应用数据帧）以及数据报文的读写操作。关键信息在于通过WebSocket类将HTTP连接升级为长连接，利用帧的属性进行双向实时通信，并提供了包含握手、消息收发及连接关闭的完整代码示例。该文档面向具备网络编程基础的仓颉开发者，旨在指导其实现实时通讯功能。

### WebSocket_编程_2.md
本文档旨在通过代码示例演示WebSocket服务器端的完整编程流程。主要涵盖连接握手与升级、子协议协商、以及针对不同帧类型（如文本、二进制、Ping、Close和分片帧）的收发处理逻辑。关键信息包括如何读取客户端消息、发送大数据包、处理分片数据以及优雅关闭连接，并附带了详细的运行输出结果。该教程适合具备基础网络编程能力的开发者，用于深入理解WebSocket通信机制及API的实际应用。
