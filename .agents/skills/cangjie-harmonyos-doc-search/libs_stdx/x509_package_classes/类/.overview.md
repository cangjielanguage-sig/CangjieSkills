This directory contains API documentation for classes related to X.509 cryptography within the Cangjie programming language. It covers the implementation of Distinguished Names (DN), digital certificates, and certificate signing requests (CSR). Key topics include certificate properties, validation logic, parsing, and cryptographic operations supporting RSA, ECDSA, and DSA algorithms. This documentation is suitable for software developers and security engineers implementing Public Key Infrastructure (PKI), secure communication protocols, and identity verification systems in Cangjie applications.

## Detailed Description

### class_X509Name.md class_X509Name.md
This API documentation defines the X509Name class in the Cangjie language, representing the Distinguished Name (DN) used to verify identities in digital certificates. The document details the class constructor, which accepts optional parameters for country, province, locality, organization, organizational unit, common name, and email. It lists public properties for accessing these fields and describes the overridden toString method for string representation. Key information includes the inheritance from the ToString parent class and the potential throwing of X509Exception during initialization. This reference guide targets developers implementing X.509 certificate handling, requiring knowledge of Cangjie syntax and basic cryptography concepts.

### class_X509Certificate/
This directory contains API reference documentation for the `X509Certificate` class within the Cangjie programming language. It focuses on the implementation and management of X.509 digital certificates, essential for Public Key Infrastructure (PKI) and secure communication. Key topics include certificate properties (subject, issuer, validity), validation logic (DNS checks, chain verification), and format handling (DER, PEM). It also covers cryptographic operations involving RSA, ECDSA, and DSA algorithms. This documentation is suitable for software developers and security engineers implementing cryptographic security features, identity verification, and trust store integration in Cangjie applications.

### class_X509CertificateRequest/
This directory provides comprehensive API reference documentation for the `X509CertificateRequest` class in the Cangjie programming language, specifically designed for handling digital certificate signing requests (CSR). It covers the complete functionality required for creating, parsing, and manipulating certificate requests. Key topics include the class constructor for initializing requests with private keys (supporting RSA, ECDSA, and DSA), properties for extracting specific data fields such as IP addresses, DNS names, email addresses, and public keys, and methods for decoding DER formatted binary data. The documentation highlights default SHA256 hashing, parsing of subject information, and alternative names. Additionally, it details interface implementations like Hashable and ToString. This resource is suitable for developers implementing cryptographic security features, certificate management systems, or any application requiring precise control over X.509 standards and data formats within the Cangjie environment.
