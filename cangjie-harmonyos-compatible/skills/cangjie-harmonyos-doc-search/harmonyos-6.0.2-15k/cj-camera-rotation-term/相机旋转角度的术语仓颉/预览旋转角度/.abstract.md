This directory provides technical documentation focused on the logic and mathematics behind calculating image rotation angles during camera preview on mobile platforms. It addresses the complexities of aligning the camera sensor output with the device's current display orientation. Key concepts include the relationship between lens installation angles, screen rotation compensation, and the specific behaviors of front versus rear cameras. The documentation details how to handle mirroring effects for front-facing lenses and interprets data from the `Display.rotation` API. It also breaks down eight specific scenarios involving different device orientations and charging port positions. This resource is designed for mobile application developers and system engineers building camera features who need a deep understanding of orientation transformation algorithms to ensure a correct user experience.
