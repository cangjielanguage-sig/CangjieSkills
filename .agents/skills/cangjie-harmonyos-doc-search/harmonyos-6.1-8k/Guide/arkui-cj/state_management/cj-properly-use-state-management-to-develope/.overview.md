# cj-properly-use-state-management-to-develope

本目录旨在指导开发者合理使用状态管理，解决UI不刷新及性能差的问题。文档主要涵盖两个核心方向：合理使用属性（如合并数组、拆分大对象、使用@Observed装饰类）以及合理使用ForEach/LazyForEach。重点介绍了在ForEach中使用ObservedArrayList配合@Publish装饰器，以确保数据变化时能正确触发UI刷新。文档通过仓颉语言的正反代码示例，详细阐述了可观测对象的应用场景，适合ArkUI开发人员参考学习。
