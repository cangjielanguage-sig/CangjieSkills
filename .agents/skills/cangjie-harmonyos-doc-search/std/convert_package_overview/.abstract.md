This directory serves as a comprehensive overview for the `convert` package within the Cangjie programming language ecosystem. It focuses on the standard conversion library, providing essential documentation for transforming data between strings and various types. Key topics include the `Formattable` interface, parsing logic, and radix conversion capabilities. This resource is designed for developers who need to implement precise data formatting, handle complex string parsing, or customize output presentation. It acts as both a quick reference and a deep-dive tutorial for mastering type conversion logic in Cangjie applications. Whether you are building user interfaces or processing data streams, this documentation provides the necessary tools for effective type management.
