## Detailed Description

### Reusable宏组件复用_2more.md Reusable宏组件复用_2more.md
This document serves as a technical reference explaining the usage and performance benefits of the @Reusable macro for custom components. It covers the definition of the decorator and provides an overview of the component lifecycle caching mechanism. Key takeaways include that @Reusable must be used with @Component, enabling the system to cache removed components and page objects for future reuse, thereby reducing the overhead of creating new nodes. Intended for developers seeking to optimize application performance through component reuse strategies.

### 使用场景.md 使用场景.md
This document outlines specific usage scenarios for implementing component reuse mechanisms to optimize application performance. It details three primary scenarios: list scrolling with large datasets, dynamic layout updates based on user interaction, and general contexts involving frequent creation and destruction of data item views. The core concept is that reusing existing views and only updating data content reduces overhead from layout calculations and view instantiation, thereby preventing lag and improving frame rates. This guide targets developers seeking to enhance UI responsiveness and fluidity in applications with complex or data-heavy interfaces. Keywords: component reuse, performance optimization, list scrolling, dynamic layout, view lifecycle.

### 限制条件.md 限制条件.md
This technical reference document outlines specific usage constraints and limitations for the @Reusable macro within the Cangjie ArkUI development framework. It covers project compatibility, scope of application, and nested usage restrictions. Key takeaways include that mixed projects are unsupported, @Reusable cannot be applied to @Builder functions, and nested usage is strongly discouraged due to increased memory consumption, inefficient reuse, and lifecycle management issues where methods like aboutToRecycle and aboutToReuse fail to pair correctly. The target audience is Cangjie developers needing to optimize component performance while avoiding architectural pitfalls.
