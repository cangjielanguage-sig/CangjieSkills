This directory serves as a comprehensive resource for the `cj-apis-form-form-info` module, specifically tailored for the HarmonyOS Cangjie development environment. It provides essential API reference documentation focused on the `ohos.form.form_info` module, which is critical for developers working with system cards (forms). The documentation covers a wide range of data structures, classes, and enumerations necessary for managing form information, configurations, and states effectively. Key topics include the `FormInfo` class for handling card metadata, specific filters for querying forms, and various enums that define dimensions, shapes, types, and states. This content is part of the SystemCapability.Ability.Form capability, available from version 20 onwards. It is primarily suitable for Cangjie software engineers and developers who are building or maintaining form-based applications and require detailed programmatic access to card properties and lifecycle management features.
