This directory contains API reference documentation for the Cangjie `HceService` class, designed to facilitate Host Card Emulation (HCE) functionality. It covers the management of APDU data exchange with NFC readers, including service initialization, lifecycle management, and asynchronous data transmission. Key topics include subscribing to APDU commands, setting foreground priority, registering AID lists, and resource cleanup. The documentation is essential for Cangjie developers building NFC-based applications that require card emulation capabilities, providing necessary details on permissions, system capabilities, and error handling.
