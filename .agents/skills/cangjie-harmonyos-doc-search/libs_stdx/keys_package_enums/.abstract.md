This directory provides the API reference documentation for enumeration types utilized within the Cangjie keys package, focusing on the critical configurations needed for cryptographic key generation and padding schemes. It thoroughly documents the `Curve` enum, which is essential for selecting Elliptic Curve Digital Signature Algorithm (ECDSA) keys, and the `PadOption` enum, which manages RSA padding settings. The reference material covers a broad spectrum of NIST curves (P224 through P521) and Brainpool curves (BP256 through BP512), providing developers with necessary insights into their respective security levels and performance metrics. Furthermore, it outlines padding modes such as OAEP, PSS, and PKCS1, offering explicit security advice to avoid PKCS1 due to known vulnerabilities, while advocating for the use of OAEP or PSS. This resource is specifically designed for software developers and security engineers who are implementing asymmetric encryption and digital signatures, requiring a deep understanding of cryptographic principles to build secure systems. By providing these definitions, the package ensures that developers can implement standardized and secure cryptographic practices efficiently.
