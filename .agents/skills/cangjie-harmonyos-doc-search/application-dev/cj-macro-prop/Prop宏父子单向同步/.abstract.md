This directory focuses on the `@Prop` macro within the ArkUI framework using the Cangjie language, specifically detailing one-way data synchronization from parent to child components. It covers the core mechanics, variable passing rules, usage constraints, and initialization requirements. Key topics include local mutability, type matching, and the distinction between simple and complex data observation. This documentation is intended for developers familiar with basic state management (like @State) who need to implement robust parent-child data flow and understand the behavioral nuances of the @Prop decorator in UI development.
