## Detailed Description

### cj-scroll-swipe-flowitem.md

This document serves as API reference documentation for the FlowItem component, a child element designed for the Waterfall Flow component in the Cangjie ArkUI framework. It details the component's usage constraints, specifically that it must be used solely as a child of the Waterflow component. The main sections cover subcomponent support, initialization constructors, and supported attributes. Key information includes two initialization methods: a default constructor and one accepting a child component builder. The component supports all common attributes and events and requires SystemCapability.ArkUI.ArkUI.Full. This documentation targets developers using the Cangjie language to build complex list layouts in HarmonyOS applications.
