# 在自绘编辑框中使用输入法

This directory provides a comprehensive guide on integrating input method functionality into self-drawn edit boxes using the IMEKit framework and the Cangjie language within DevEco Studio. It covers the essential technical concepts, such as utilizing the `InputMethodController` via the `getController` method, and provides practical steps for implementation. Key topics include binding input listeners, handling text events (insertion, deletion, selection), and managing focus and state variables for custom UI components. This resource is designed for HarmonyOS developers and UI engineers who need to implement flexible, custom text input controls with manual keyboard handling.
