# cj-ide-resource-categories-and-access

This directory serves as a comprehensive guide for managing resources within HarmonyOS application development, specifically designed for developers using the Cangjie language and the CJ IDE. The content is essential for those looking to standardize their project's resource organization, ensuring seamless multi-language support and multi-device adaptation. Whether you are building for phones, tablets, or wearables, this guide helps you correctly reference resources to optimize application performance and user experience. It is particularly suitable for HarmonyOS and Cangjie developers aiming to build scalable, internationalized applications within the CJ IDE environment, ensuring that their code remains clean and their assets are easily maintainable.

## Detailed Description

### 资源分类与访问/

This directory is a crucial resource for HarmonyOS and Cangjie developers, focusing on the fundamental aspects of resource management within the development environment. It details the entire lifecycle of resources, starting from their creation and classification. The guide explains how to structure resource directories effectively and how to use qualifiers to distinguish between different contexts, such as language, region, screen density, or device type.

Furthermore, it covers the complex rules of resource matching, ensuring that the application loads the correct assets based on the runtime environment. Developers will also find instructions on accessing both system resources and application-specific resources. By following the guidelines provided here, developers can ensure their applications are robust, adaptable to various devices, and capable of delivering a localized experience through proper resource references. The core keywords covered include resource directories, qualifiers, system resources, resource matching, and resource references, providing a complete vocabulary for effective resource handling in the CJ IDE. Mastering these concepts is key to creating professional-grade applications that feel native to users across different regions and hardware configurations.
