# 日志主干通用信息

This directory contains essential technical reference documentation designed for analyzing system logs, with a specific focus on diagnosing application freezes (appfreeze) and performance debugging within OpenHarmony environments. It comprehensively covers the interpretation of common log fields, main thread task queues, process stack traces, and Inter-Process Communication (IPC) mechanisms. Key topics include BinderCatcher usage, CPU load monitoring, and memory statistics analysis. These guides are primarily intended for system developers and engineers who need to troubleshoot complex application responsiveness issues, identify system bottlenecks, and resolve resource consumption problems effectively.

## Detailed Description

### 日志主干通用信息_1.md
This document serves as a reference guide for analyzing common fields within application freeze (appfreeze) logs to diagnose system issues. It details a table of key log fields such as EVENTNAME, PID, and MSG, explains the MSG field's content regarding main thread task queues, and provides examples of process stack traces and BinderCatcher information. Key information includes using timestamps and PIDs to narrow down log searches, identifying freeze causes through task accumulation analysis, and detecting long IPC wait times. This technical reference is intended for system developers or engineers troubleshooting application responsiveness and inter-process communication failures.

### 日志主干通用信息_2.md
This document serves as a technical reference for interpreting system log data, specifically focusing on performance debugging and IPC analysis within an OpenHarmony environment. It details four primary log categories: BinderCatcher for tracking inter-process communication transactions and wait times, PeerBinder Stacktrace for analyzing thread states of peer processes, cpuusage for monitoring system load and process resource consumption, and memory statistics for detailed memory breakdowns. The content provides concrete examples of log formats, helping developers identify application freezes, bottlenecks, and resource usage patterns. It is intended for system engineers and developers troubleshooting complex system behaviors.
