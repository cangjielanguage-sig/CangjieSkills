This directory contains API reference documentation for the `AlertDialogParam` class within the Cangjie ArkUI framework. It provides comprehensive details on configuring alert dialog windows, covering initialization, layout properties, visual styling, and behavioral settings. Developers can find specifications for variables such as title, message, border, and transitions, alongside system capability requirements starting from version 22. This documentation is suitable for software developers and UI designers looking to programmatically customize the appearance and interaction of alert dialogs and popup components in their applications.
