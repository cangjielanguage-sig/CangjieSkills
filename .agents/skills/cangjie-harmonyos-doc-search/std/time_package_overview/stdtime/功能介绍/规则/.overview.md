# 规则

This directory serves as a comprehensive repository for technical reference specifications regarding date and time parsing and formatting rules. It encompasses detailed guidelines for handling various temporal components, including AM/PM markers, years, months, fractional seconds, and timezone offsets, alongside specific rules for era designations like "Anno Domini." The documents provide precise mapping logic based on pattern letter counts and input string lengths to ensure data consistency and accuracy. This collection is primarily intended for software developers, system architects, and localization engineers who are implementing or maintaining date-time libraries and require exact standards for string formatting and parsing operations. By adhering to these rules, users can ensure correct data representation across different locales and systems, facilitating robust internationalization and precise timekeeping in software applications.
