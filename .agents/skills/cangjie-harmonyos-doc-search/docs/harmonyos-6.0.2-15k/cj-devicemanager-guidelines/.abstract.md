This directory provides the official development guidelines for the CJ Device Manager, focusing on the implementation of distributed device management and cross-device collaboration features. It covers the essential concepts of distributed business, including device discovery, binding, status querying, and listening. The guide details how to establish trust relationships via LAN or Bluetooth, manage device states, and handle necessary permissions such as `ohos.permission.DISTRIBUTED_DATASYNC`. It includes step-by-step tutorials using the Cangjie language and the DistributedServiceKit module. This resource is designed for developers building distributed applications that require robust connectivity and interaction between multiple devices.
