This directory contains API reference documentation for the `Contact` data structure within the Cangjie programming language. It covers the definition of the Contact struct, its constructor, and specific public properties used for managing contact information. Key topics include personal identifiers, organizational data, and lists for communication details like emails, phone numbers, and addresses. This documentation is suitable for software developers building contact management applications using the SystemCapability.Applications.ContactsData module, specifically targeting version 19 and above.
