This directory provides a comprehensive technical resource for diagnosing and resolving Application Not Responding (AppFreeze/ANR) issues within the Stage model. It covers detection mechanisms, system policies for forced exits, and detailed log analysis methodologies. Key topics include main thread stalling, input timeouts, lifecycle transitions, and debugging tools like Binder and Hilog. Designed for developers and system engineers, these documents facilitate root cause analysis of application instability and performance bottlenecks.
