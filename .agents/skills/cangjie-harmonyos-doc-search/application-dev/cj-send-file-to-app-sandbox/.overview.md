# cj-send-file-to-app-sandbox

This directory provides a specialized technical guide designed for HarmonyOS developers who need to interact directly with the application sandbox environment. It focuses on the critical workflow of pushing files into the sandbox for debugging and testing purposes, utilizing the standard hdc toolchain. The content explains the complex mapping logic between virtual sandbox paths and the device's real physical file system, ensuring developers understand exactly where their data actually resides. Furthermore, it addresses the security and permission models inherent in HarmonyOS, offering specific instructions on modifying file ownership with chown and using namespace entry (nsenter) to switch debugging contexts. This resource is essential for troubleshooting file access errors, verifying data persistence, and managing application-specific data during the development cycle. It assumes the user possesses prior knowledge of command-line interfaces and the HarmonyOS operating system architecture to effectively implement the strategies outlined. Mastering these techniques allows for a smoother development process and more accurate testing scenarios.
