This directory provides a comprehensive technical guide to implementing conditional rendering using if, else, and else if statements within the Cangjie UI framework. It thoroughly details the rules governing state variables, parent-child relationships, and container component restrictions. The content explains the critical update mechanism where state variable changes trigger the deletion of old components and the construction of new ones. Key topics include the requirement for non-empty builders and the prohibition of state changes within constructor expressions. This resource is essential for Cangjie developers and UI engineers looking to master dynamic user interface construction, optimize state management, and control UI content flow based on application state.
