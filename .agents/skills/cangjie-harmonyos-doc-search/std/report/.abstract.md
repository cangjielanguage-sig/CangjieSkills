This directory serves as the central repository for documentation regarding the `report` module, with a specific focus on the `diagReport` interface within the Cangjie AST package. It is designed to assist developers in the implementation of custom error reporting mechanisms directly within macro definitions. The documentation provides an in-depth look at the interface's functionality, supported by a comprehensive usage example that covers macro definition, compilation, and execution. It also clarifies the operational boundaries of the interface, particularly its behavior outside of macro expansion. Key concepts include the reporting of `WARNING` or `ERROR` levels on specific `Tokens` and the utilization of native compiler formatting. This guide is essential for Cangjie macro developers who need to validate input tokens and provide user-friendly diagnostic messages to enhance the development experience.
