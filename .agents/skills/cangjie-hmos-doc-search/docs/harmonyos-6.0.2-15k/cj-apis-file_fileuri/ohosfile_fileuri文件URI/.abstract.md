This directory provides comprehensive documentation for the `ohos.file_fileuri` module and the `FileUri` class, specifically tailored for the Cangjie programming language within the HarmonyOS ecosystem. It focuses on the essential functionality of converting file system paths into Uniform Resource Identifiers (URIs), a critical requirement for secure inter-application file sharing and access management. The content covers API references, module imports, and practical usage examples, including handling sandbox paths and encoding special characters. It is primarily suitable for Cangjie developers and system architects building applications that require robust file handling capabilities, ensuring compliance with AppFileService standards starting from API version 12. By utilizing these resources, developers can effectively manage file access permissions and integrate file operations seamlessly into their application logic.
