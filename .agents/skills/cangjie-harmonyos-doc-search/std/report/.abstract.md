This directory provides a comprehensive technical guide focused on the `diagReport` interface within the Cangjie AST package. It is an essential resource for developers aiming to implement sophisticated custom error reporting mechanisms directly inside macros. The documentation details how to generate native-style WARNING and ERROR messages, ensuring that diagnostics are both user-friendly and consistent with the compiler's output. It covers the complete lifecycle of usage, from macro definition and invocation to compilation, while highlighting critical constraints such as execution limits during macro expansion. This guide is specifically tailored for macro developers and Cangjie programmers who require precise input token validation and wish to improve the diagnostic quality of their development tools. By mastering these tools, developers can significantly enhance the robustness and usability of their language extensions.
