# 参数化测试

This directory focuses on advanced parameterized testing techniques within the Cangjie language testing framework. It covers type parameterization, coverage-guided random testing, and reusable data generation strategies using macros like `@Types` and `@Strategy`. The content addresses reducing code duplication, handling edge cases, and improving test efficiency through fuzzing and data-driven approaches. Suitable for Cangjie developers looking to optimize test suites, manage complex data generation, and enhance code reliability through sophisticated testing methodologies.

## Detailed Description

### 类型参数化测试.md 类型参数化测试.md
This tutorial explains how to implement type parameterized testing in the Cangjie language to reduce code duplication when testing functions supporting multiple types. It covers writing specific tests for strings, attempting to create generic test functions, and resolving compilation errors using the `@Types` macro. Key takeaways include the requirement of the `@Types` macro to specify concrete types like `Int64`, `Float64`, and `String` for generic test functions. The document demonstrates that each specified type runs as a separate test case, accommodating distinct behaviors such as handling NaN values. This guide targets Cangjie developers familiar with generics and testing frameworks who seek to optimize their test suites.

### 覆盖率引导的随机参数化测试.md 覆盖率引导的随机参数化测试.md
This technical guide introduces coverage-guided random parametric unit testing within the Cangjie framework to overcome the limitations of standard random testing. The document covers the inefficiency of pure random generation, the introduction of fuzzing-based techniques, specific compilation and runtime configuration requirements, and a comparative code example. Key takeaways include the necessity of compiling with `--sanitizer-coverage-trace-pc-guard` and `--sanitizer-coverage-trace-compares` flags, running with `--coverage-guided`, and increasing generation steps to ensure thorough coverage. This guide targets developers seeking advanced, deep testing capabilities for security or edge-case detection who are familiar with the Cangjie unit testing framework.

### 重用组合和映射参数策略.md 重用组合和映射参数策略.md
This tutorial explains how to use the `@Strategy` macro to create reusable, composable data generation strategies for testing in the Cangjie language. It covers the limitations of basic random data generation, manual custom generators, and the implementation of `@Strategy` to map and compose parameters for `@Test` functions. The document demonstrates how to define a unique array generator using `@Strategy`, allowing multiple tests to share the same data source without code duplication, thereby improving test clarity and maintainability. This guide targets developers using the Cangjie testing framework who need to manage complex test data or benchmarking scenarios.

### 参数化测试入门/
This directory serves as a comprehensive introduction to parameterized testing within the Cangjie unittest framework, specifically designed to enhance test automation and coverage efficiency. It covers the fundamental concepts of data-driven testing using data DSL, ranging from value-driven tests with arrays and ranges to sophisticated random testing strategies for generating edge cases. The content addresses critical challenges such as combinatorial explosion and the management of non-deterministic test results. By exploring configuration options like random seeds, generation steps, and reduction steps, developers can learn to stabilize test cases and significantly improve debugging workflows. This resource is essential for Cangjie developers seeking to maximize code reliability through advanced testing methodologies.
