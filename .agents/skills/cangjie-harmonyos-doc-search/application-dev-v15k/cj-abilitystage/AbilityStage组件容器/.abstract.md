This directory provides comprehensive documentation on the AbilityStage component container, specifically designed for HarmonyOS developers utilizing the Cangjie language. It serves as a complete resource for understanding and implementing Module-level initialization logic. The content covers the fundamental definition of AbilityStage, the step-by-step process for manual class creation and registration, and necessary configurations within `module.json5`. Furthermore, it addresses advanced topics such as lifecycle management, including callbacks for initialization, configuration updates, and memory level changes. This guide is essential for developers aiming to optimize HAP loading, manage resource preloading, handle thread creation, and ensure application stability through effective memory management strategies.
