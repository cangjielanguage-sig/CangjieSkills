This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically focusing on the `CommonEventBatteryChangedKey` enumeration. It details the structure and usage of query keys designed to extract granular data from battery change events, such as state of charge (SOC), voltage levels, charge state, and battery health. Additionally, it covers utility functions for string representation of these keys. This documentation is essential for system developers and software engineers building power management features or applications that require real-time monitoring and programmatic parsing of battery status updates within the system's power management framework.
