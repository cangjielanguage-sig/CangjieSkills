# hdc

hdc (OpenHarmony Device Connector) 是一个用于开发人员在PC端与OpenHarmony设备进行交互和调试的命令行工具。本目录涵盖了hdc工具的架构介绍、环境配置、命令参考、文件传输、端口转发及设备操作等核心功能。此外，还包含了错误码查询、常见问题排查及设备连接管理的详细指南。核心关键词包括HDC、OpenHarmony、调试、命令行、文件传输、端口转发。本文档适用于HarmonyOS/OpenHarmony开发人员、测试人员及技术支持人员，旨在帮助用户高效搭建调试环境并解决开发过程中的连接与操作问题。
