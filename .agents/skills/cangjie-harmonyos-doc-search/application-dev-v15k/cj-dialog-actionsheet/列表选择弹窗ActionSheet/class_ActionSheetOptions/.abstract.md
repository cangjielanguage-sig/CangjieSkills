This directory contains API reference documentation for the `ActionSheetOptions` class within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the configuration and customization of list selection popups, modal dialogs, and action sheets in HarmonyOS applications. Key topics include constructor parameters, visual styling (borders, colors, blur), and interaction behaviors (callbacks, modal states). This documentation is suitable for HarmonyOS developers and UI engineers using Cangjie who need to implement interactive, customizable dialog components with specific visual and functional requirements.
