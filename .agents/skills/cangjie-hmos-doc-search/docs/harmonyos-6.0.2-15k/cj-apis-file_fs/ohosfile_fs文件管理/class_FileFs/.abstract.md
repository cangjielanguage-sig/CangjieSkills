This directory contains API reference documentation for the `FileFs` class in the Cangjie programming language, part of the CoreFileKit. It covers a comprehensive range of static file system operations, including file access verification, copying, moving, reading, writing, and directory management. The documentation details function signatures, parameters, error handling, and system capabilities required for file I/O tasks. It is suitable for Cangjie developers building applications that require robust file management, metadata manipulation, and resource handling within application sandboxes on HarmonyOS/OpenHarmony environments.
