## 详细说明

### HAR_4more_d08452cc.md HAR_4more_d08452cc.md
这份文档介绍了HAR（Harmony Archive），一种用于在模块或工程间共享仓颉组件与资源的静态共享包。文档主要涵盖了HAR的定义、使用场景（如作为二方或三方库发布）、详细的约束限制（如不支持独立安装、循环依赖及权限合并机制）以及创建方法。关键信息包括HAR不支持依赖传递、二进制HAR的SDK版本要求及产物打包路径。该文档面向使用DevEco Studio进行HarmonyOS开发的开发者，旨在指导其利用HAR实现代码和资源的复用。

### 使用.md 使用.md
