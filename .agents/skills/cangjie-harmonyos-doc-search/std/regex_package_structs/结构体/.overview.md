### struct_Position.md struct_Position.md

This document provides API reference documentation for the Position struct in the Cangjie programming language. It details the struct's definition and its two public properties, start and end. The primary takeaway is that this struct is designed to store position information representing a half-open interval, utilizing Int64 values for both the beginning and end markers. The documentation explicitly defines the type and function of each field. This resource is intended for software developers working with Cangjie who require a standardized way to represent ranges or positional data within their code.

### struct_MatchData/

This directory contains comprehensive API documentation for the `MatchData` struct within the Cangjie standard library's regex module. It focuses on the mechanisms for storing and querying regular expression match results, specifically detailing methods for retrieving match positions, substrings, and capture group information. Key topics include `matchPosition`, `matchString`, `groupCount`, and exception handling for invalid inputs. This documentation is suitable for Cangjie developers implementing text processing logic who need to programmatically inspect regex matches and their locations, providing verified code examples to facilitate practical implementation.
