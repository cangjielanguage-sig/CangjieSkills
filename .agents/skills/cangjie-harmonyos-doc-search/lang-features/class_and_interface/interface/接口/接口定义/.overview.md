# 接口定义

## 详细描述

### 接口定义_1.md

本文档介绍了仓颉编程语言中接口的定义、修饰符使用及实现机制。主要涵盖接口的基本声明、`open` 与 `sealed` 修饰符的语义差异、类通过 `<:` 语法实现接口的规则，以及实例与静态成员函数的用法。文档强调了接口的抽象能力和子类型多态性，并通过 `Flyable` 和 `NamedType` 等示例展示了如何约束类型功能。这是一份面向开发者的语言教程，旨在帮助用户掌握接口定义与继承的核心概念。

### 接口定义_2.md

本文档旨在阐述仓颉编程语言中接口的高级定义规则，特别是静态成员和泛型成员的处理机制。主要内容包括静态成员函数有无默认实现时的访问差异、在泛型约束中对静态成员实现的强制要求、接口中泛型实例与静态函数的定义及open语义，以及接口成员默认public且实现类必须public的访问控制规则。文档通过代码示例展示了编译错误与正确用法，强调了静态多态的实现方式。这是一份面向仓颉语言开发者的技术参考文档，适合具备基础语法知识的用户阅读。关键词：仓颉、接口定义、静态成员、泛型约束、访问控制。
