This directory serves as a specialized technical repository for HarmonyOS developers working with the ArkUI framework and the Cangjie language. It focuses specifically on the creation, configuration, and management of custom pop-up dialogs using the `@CustomDialog` decorator and `CustomDialogController`. The content highlights a Beta feature that is currently not recommended for production environments, making it a resource for experimental development, testing, and future-proofing applications. It covers essential topics such as distinguishing between modal and non-modal behaviors, managing dialog persistence across different page routes, and handling component lifecycles effectively. This directory is ideal for developers aiming to build complex user interactions, such as system warnings or update prompts, who need to understand the specific architectural constraints and capabilities of custom dialogs in this ecosystem.
