This directory contains the essential documentation for the Cangjie Test Kit, a specialized automated testing framework created for developers working within the Cangjie language ecosystem. It provides a thorough overview of the framework's capabilities, designed to assist developers in implementing robust testing strategies. The documentation covers two fundamental areas: Unit Testing, which includes detailed guidance on test definitions, assertions, lifecycle management, and execution modes; and UI Testing, which extends these concepts to encompass widget location, user interaction simulation, window manipulation, and system dialog monitoring. Furthermore, the document highlights advanced features such as flexible assertion interfaces, stress testing support, and the simulation of diverse input methods including mouse, keyboard, and touch gestures. This resource is specifically suitable for Cangjie developers seeking to automate functional verification and enhance the reliability of UI interactions in their applications.
