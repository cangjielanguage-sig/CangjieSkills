# cj-apis-hitrace

This directory contains the technical documentation for the `cj-apis-hitrace` module, a crucial component for developers working with the Cangjie language in the HarmonyOS environment. It functions as an API reference guide, enabling users to trace process trajectories and measure program execution performance with precision. The documentation covers the `Hitrace` class, outlining methods for initiating and concluding task traces as well as monitoring variable values. It highlights the importance of matching task identifiers to ensure accurate tracking. This resource is specifically tailored for HarmonyOS developers and system engineers who need to conduct deep performance analysis and debugging. However, developers must note that the APIs described here are marked as deprecated as of version 12, suggesting they should look for alternative solutions in newer releases.

## Detailed Description

### cj-apis-hitrace.md cj-apis-hitrace.md

This document serves as the primary API reference for the `ohos.hitrace` module, which is designed to provide robust capabilities for tracing process trajectories and measuring program execution performance within the Cangjie programming environment. The text details the `Hitrace` class comprehensively, with a specific focus on its static methods. It explains how to use `startTrace` to begin tracking a designated task, how to utilize `finishTrace` to end the tracking process, and how to employ `traceByValue` to monitor changing numerical variables during runtime. Key information provided includes the strict requirement for matching task names and IDs between the start and finish functions to ensure data consistency. It is vital for users to note that the class and its methods are marked as deprecated as of version 12. This reference is intended for HarmonyOS developers who require performance analysis and debugging tools, particularly those maintaining or understanding legacy systems.
