This directory contains comprehensive API reference documentation for the `HashSet` class in the Cangjie programming language. It covers the implementation of the Set interface, focusing on storing unordered, unique elements using a hash-based mechanism derived from `HashMap`. The documentation details class definitions, properties, initialization methods, and various member functions for data manipulation, capacity management, and set algebra operations. It also includes extensions for equality comparison and string conversion. This resource is suitable for Cangjie developers working with generic collections constrained by `Hashable` and `Equatable` interfaces who need to implement or utilize hash-based data structures efficiently.
