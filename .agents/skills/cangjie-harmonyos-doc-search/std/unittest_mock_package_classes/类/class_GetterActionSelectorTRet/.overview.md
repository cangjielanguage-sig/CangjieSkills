### class_GetterActionSelector_8more.md class_GetterActionSelector_8more.md
This API reference document details the GetterActionSelector class, which enables developers to define stub behaviors for property getter functions within a mock testing framework. The content covers the class definition, inheritance from ActionSelector, and specific methods for controlling getter behavior, including field access, return values, and exception handling. Key methods include getsField for synthetic fields, getsOriginal for original values, returns for single or factory-generated values, returnsConsecutively for sequences, and throws for exceptions. These methods support chaining by returning CardinalitySelector or Continuation objects. This documentation targets developers using the @On macro for unit testing who need to mock or spy on object properties.
