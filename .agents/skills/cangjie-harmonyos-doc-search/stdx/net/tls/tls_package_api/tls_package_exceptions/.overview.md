# tls_package_exceptions

本目录包含了Cangjie语言标准库中TLS（传输层安全）包相关的异常处理文档。它详细定义了用于描述TLS协议处理过程中各类错误的TlsException类。文档内容不仅涵盖了该类的具体定义和继承自Exception的层级关系，还深入解析了其提供的两种构造函数：一种用于创建无消息的空实例，另一种允许开发者传入String参数以自定义异常详情。作为一份核心的API参考文档，本目录专为使用Cangjie语言进行网络编程、特别是涉及TLS安全通信开发的工程师设计，旨在提供清晰的错误处理规范和接口说明。

## 详细描述

### tls_package_exceptions.md
本文档定义了Cangjie语言TLS包中的异常处理类，用于描述TLS处理过程中出现的错误。主要内容包括TlsException类的定义、继承关系以及两个构造函数的详细说明。该类继承自Exception，提供无参构造函数创建空消息实例，以及接受String参数的构造函数以自定义异常信息。适用于使用TLS库进行网络通信开发的程序员，属于API参考文档。
