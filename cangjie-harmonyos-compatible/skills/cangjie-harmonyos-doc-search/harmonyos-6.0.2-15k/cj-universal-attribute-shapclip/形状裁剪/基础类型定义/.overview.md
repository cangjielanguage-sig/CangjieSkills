# 基础类型定义

This directory contains API reference documentation for fundamental shape classes in the Cangjie language within the ArkUI framework. It covers abstract base classes and specific geometric shapes like circles, ellipses, rectangles, and custom paths, used primarily for clipping, masking, and visual effects. Key concepts include ShapeAbstract, PathShape, ProgressMask, and various shape constructors. It is suitable for UI developers and system architects working with ArkUI version 12 who need to implement graphical manipulations and custom visual components in their applications.

## Detailed Description

### class_CircleShape_2more.md class_CircleShape_2more.md
This document serves as API reference documentation for the CircleShape and EllipseShape classes in the Cangjie language, designed for the ArkUI framework. It details the class definitions, their inheritance from ShapeAbstract, and their usage in clip and mask interfaces. The content covers two initialization methods for each shape: a default constructor creating a zero-sized object and a parameterized constructor accepting named width and height arguments of type Length. Key takeaways include the system capability requirements and the starting version 12. This guide targets UI developers seeking to implement circular or elliptical geometric shapes for visual effects in their applications.

### class_PathShape_2more.md class_PathShape_2more.md
This document serves as API reference documentation for the Cangjie language, detailing classes used for custom shapes and masking within the ArkUI framework. It covers the PathShape class, which inherits from ShapeAbstract, and the ProgressMask class. Key information includes PathShape's ability to create custom drawing paths via command strings for clip and mask operations, offering constructors for default, string-based, and dimension-based initialization. ProgressMask manages progress masking with properties for value, total, and color, including methods to update progress, change color, and toggle a breathing animation effect. The target audience is ArkUI developers requiring advanced graphical manipulation and UI masking capabilities.

### class_RectShape.md class_RectShape.md
This API reference document details the RectShape class in the Cangjie language, designed for defining rectangular shapes used in clipping and masking operations within the ArkUI framework. The content covers class inheritance from ShapeAbstract, initialization constructors for default or custom dimensions, and methods for configuring corner radii. Key functions include init, radius, radiusWidth, and radiusHeight, all accepting Length parameters with a default of 0.vp. The document specifies that abnormal values are handled by reverting to initial states. Intended for ArkUI developers, this guide provides the necessary interface definitions for creating and manipulating rectangular geometries in UI development.

### class_ShapeAbstract.md class_ShapeAbstract.md
This document serves as API reference documentation for the Cangjie language class ShapeAbstract within the ArkUI framework. It details the class definition, its inheritance from ContainerBase, and specifications for public methods such as fill, height, width, offset, and size. Key information includes that this abstract sealed class acts as a base for specific shapes like CircleShape and RectShape, allowing manipulation of dimensions in viewport units and fill colors. The content is intended for UI developers working with ArkUI version 12 who require foundational knowledge of Cangjie syntax and ArkUI component structures.
