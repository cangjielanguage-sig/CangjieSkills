# 应用文件目录与应用文件路径

This directory serves as a comprehensive technical resource for understanding HarmonyOS application file structures and path management within the application sandbox. It covers the hierarchical organization, encryption levels (EL1 through EL5), and the distinction between App-level and HAP-level storage. Key topics include standard directory definitions (such as files, cache, and preferences), Context API usage for path retrieval, and data lifecycle management. This resource is essential for HarmonyOS developers seeking to implement secure data storage, manage application resources efficiently, and handle cross-device file sharing effectively while adhering to strict system security standards and avoiding common pitfalls like hardcoded paths. It provides the necessary context for developers to navigate the file system architecture securely.

## Detailed Description

### 应用文件目录与应用文件路径_1.md 应用文件目录与应用文件路径_1.md
This technical guide details the HarmonyOS application file directory structure and path management within the application sandbox. It covers the hierarchical organization, specifically focusing on encryption levels (EL1 through EL5) and their security implications, and distinguishes between App-level and HAP-level storage directories. Key takeaways include the prohibition of hardcoded paths, the recommendation to use EL2 for default security, and the requirement to use Context APIs for path retrieval. This reference is intended for HarmonyOS developers designing secure data storage solutions.

### 应用文件目录与应用文件路径_2.md 应用文件目录与应用文件路径_2.md
This technical reference document defines the standard directory structure and file paths available to applications, mapping directory names to their specific Context properties and usage scenarios. It covers eight key directories: bundle, base, database, distributedfiles, files, cache, preferences, and temp. Key information includes the storage type, specific use cases such as HAP resources, cross-device sharing, or temporary runtime data, and lifecycle management details like deletion on uninstall or app exit. This guide targets application developers who need to correctly manage data persistence, caching, and resource access within the system's file architecture.
