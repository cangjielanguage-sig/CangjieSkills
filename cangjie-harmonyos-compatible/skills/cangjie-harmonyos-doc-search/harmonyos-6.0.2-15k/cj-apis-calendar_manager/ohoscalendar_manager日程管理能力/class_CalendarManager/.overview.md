# class_CalendarManager

This directory provides essential API reference documentation for the `CalendarManager` class and associated functions within the Cangjie language development environment. It serves as a technical guide for managing system calendar data, covering a range of operations from basic object manipulation to event handling. The documentation details critical methods for creating and deleting calendars, editing events, and retrieving calendar information, while emphasizing the importance of system permissions such as `ohos.permission.WRITE_CALENDAR` and `ohos.permission.READ_CALENDAR`. Furthermore, it addresses error handling through `BusinessException` and specific return value logic for restricted access scenarios. This content is specifically tailored for developers who are integrating native calendar features into their applications and require a solid understanding of Cangjie syntax and system capability definitions to ensure robust functionality.
