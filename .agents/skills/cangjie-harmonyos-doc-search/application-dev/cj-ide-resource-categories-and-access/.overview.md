# cj-ide-resource-categories-and-access

This directory serves as a definitive guide for HarmonyOS and Cangjie developers, focusing on the critical architectural components of resource management and accessibility within modern application development. It thoroughly explains the standards for creating and organizing resource directories, ensuring a clean separation between application-specific assets and system-level resources. The documentation provides in-depth analysis of the resource matching logic, which is vital for delivering adaptive user interfaces that function seamlessly across a multitude of device configurations, including varying screen sizes and densities. Furthermore, it bridges the gap between static assets and dynamic application behavior by detailing how to programmatically access and manipulate these resources using the Cangjie framework. Key technical areas covered include the implementation of resource qualifiers for precise targeting, strategies for effective localization and internationalization, the management of translatable attributes, and the application of adaptive styling techniques. This resource is indispensable for developers seeking to optimize their asset organization, minimize redundancy, and ensure their applications provide a consistent, high-quality user experience regardless of the hardware or locale.

## Detailed Description

### 资源分类与访问/
This section provides comprehensive technical guidance on managing, classifying, and accessing resources within HarmonyOS and Cangjie development environments. It covers the creation of resource directories, the distinction between application and system resources, and the logic behind resource matching for different device configurations. Additionally, it details how to programmatically access these resources using the Cangjie framework. Key topics include resource qualifiers, localization, translatable attributes, and adaptive UI styling. This documentation is suitable for HarmonyOS and Cangjie developers seeking to optimize asset organization and ensure consistent application behavior across diverse devices.
