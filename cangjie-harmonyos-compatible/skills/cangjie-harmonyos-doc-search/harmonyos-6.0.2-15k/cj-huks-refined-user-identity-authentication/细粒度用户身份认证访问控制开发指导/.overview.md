# 细粒度用户身份认证访问控制开发指导

This directory provides a comprehensive guide for implementing fine-grained user identity authentication and access control within the HarmonyOS ecosystem. It focuses on enhancing HUKS (HarmonyOS Universal Keystore) key security by integrating secondary authentication methods like biometrics or lock screen passwords for specific cryptographic operations. Key topics include HUKS key generation, the use of `HUKS_TAG_KEY_AUTH_PURPOSE`, and supported encryption modes such as AES and SM4. This resource is designed for software developers looking to build secure applications that require hardware-backed key storage and conditional user verification for sensitive data access.

## Detailed Description

### 细粒度用户身份认证访问控制开发指导.md 细粒度用户身份认证访问控制开发指导.md
This development guide explains how to implement fine-grained user identity authentication access control for HUKS keys. It extends existing capabilities by allowing secondary authentication via biometrics or lock screen passwords for specific key operations like encryption or decryption. The document details how to use the HUKS_TAG_KEY_AUTH_PURPOSE tag during key generation to define when authentication is required. It provides a practical example where encryption is unrestricted but decryption requires fingerprint verification. Additionally, it notes that only AES/CBC, AES/GCM, and SM4/CBC modes support this feature for symmetric encryption. This guide is intended for developers seeking to enhance data security with conditional authentication requirements.

### 开发步骤/
This directory contains technical tutorials for implementing secure cryptographic operations using the Cangjie language within the HarmonyOS ecosystem. It focuses on the Universal Keystore Kit (HUKS) and User IAM for biometric authentication. The guides cover generating SM4 keys with fingerprint access control, initializing encryption sessions, and performing authenticated decryption. It is suitable for software developers building secure applications that require hardware-backed key storage and biometric verification.
