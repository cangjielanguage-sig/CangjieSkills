# 拉起文件处理类应用startAbility

本目录主要介绍如何在HarmonyOS系统中使用`startAbility`接口拉起已安装的文件处理类应用，实现跨应用文件打开与共享功能。内容涵盖了API接口调用指南、Want参数详细配置（包括URI路径、文件类型UTD/MIME、读写权限flags及自定义参数），以及基于仓颉语言的完整接入步骤。该文档适用于需要进行应用间数据交互、文件流转的HarmonyOS应用开发人员，特别是涉及文件处理与权限管理的场景。
