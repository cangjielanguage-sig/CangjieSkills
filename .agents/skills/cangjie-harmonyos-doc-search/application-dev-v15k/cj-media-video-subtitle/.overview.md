# cj-media-video-subtitle

This directory serves as a specialized technical resource for implementing video subtitle functionality within the HarmonyOS development environment, specifically utilizing the Cangjie programming language. It focuses on the AVPlayer framework, providing developers with the necessary architectural patterns to integrate external subtitle tracks seamlessly into video playback scenarios. The documentation covers critical aspects of multimedia handling, including resource management through file descriptors or network URLs, event-driven display control, and the lifecycle management of subtitle tracks. It is particularly suitable for application engineers and multimedia developers aiming to build rich media experiences with robust, dynamic subtitle support, ensuring strict compliance with framework constraints regarding initialization timing and callback handling.

### 使用AVPlayer添加视频外挂字幕/

This directory provides a comprehensive guide for integrating external subtitles into video playback using the AVPlayer framework, specifically tailored for HarmonyOS developers using the Cangjie language. It covers the end-to-end process of managing subtitle sources, including setup via file descriptors or URLs, and controlling display through event callbacks.
