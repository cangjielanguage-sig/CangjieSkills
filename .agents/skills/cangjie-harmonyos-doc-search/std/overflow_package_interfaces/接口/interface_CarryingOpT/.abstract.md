This directory contains API reference documentation for the `CarryingOp` interface and its implementations across various integer types in the Cangjie programming language. It focuses on arithmetic and bitwise operations designed to detect truncation and overflow explicitly. Key concepts include carrying operations, wrapping strategies, and tuple return types containing boolean flags and result values. This documentation is suitable for Cangjie developers, systems programmers, and engineers who require precise low-level control over integer arithmetic, ensuring numerical stability and safety in performance-critical applications.
