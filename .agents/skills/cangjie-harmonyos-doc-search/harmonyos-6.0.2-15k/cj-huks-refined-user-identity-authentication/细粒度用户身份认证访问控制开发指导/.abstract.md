This directory provides a comprehensive guide for implementing fine-grained user identity authentication and access control within the HarmonyOS ecosystem. It focuses on enhancing HUKS (HarmonyOS Universal Keystore) key security by integrating secondary authentication methods like biometrics or lock screen passwords for specific cryptographic operations. Key topics include HUKS key generation, the use of `HUKS_TAG_KEY_AUTH_PURPOSE`, and supported encryption modes such as AES and SM4. This resource is designed for software developers looking to build secure applications that require hardware-backed key storage and conditional user verification for sensitive data access.
