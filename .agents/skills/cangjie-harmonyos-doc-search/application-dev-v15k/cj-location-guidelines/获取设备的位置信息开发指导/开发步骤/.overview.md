# 开发步骤

This directory provides comprehensive development guides for implementing location services using the LocationKit module within the Cangjie programming environment. It covers the complete workflow, starting from fundamental prerequisites such as requesting location permissions and importing necessary modules, to advanced configuration of location requests. The documentation specifically addresses two distinct scenarios: single location acquisition for static features like check-ins or service recommendations, and continuous location tracking designed for dynamic use cases like navigation and sports monitoring. Key technical concepts include managing location switch status, optimizing for power efficiency using cached locations, setting specific accuracy or speed priorities, handling WGS-84 coordinate conversions, and configuring request timeouts. Furthermore, it emphasizes battery conservation techniques for continuous tracking. This resource is tailored for application developers seeking to integrate robust, efficient, and accurate location-based functionalities into their applications using the Cangjie language.

## Detailed Description

### 开发步骤_1.md
This tutorial provides a step-by-step guide for developers to implement device location acquisition using the LocationKit module in the Cangjie language. It covers essential prerequisites like requesting location permissions and importing necessary modules. The document details checking the location switch status and explains two methods for single location retrieval: fetching cached system locations for power efficiency or requesting current locations with specific priorities like accuracy or speed. Key technical points include configuring request timeouts and handling WGS-84 coordinate conversions. This guide is intended for application developers integrating location-based features such as check-ins or service recommendations.

### 开发步骤_2.md
This document serves as a technical tutorial for implementing continuous location tracking, primarily for navigation and sports scenarios. It details the instantiation of the ContinuousLocationRequest object, specifically explaining how to configure the locationScenario and interval parameters. Key takeaways include a Cangjie code example demonstrating the usage of GeoLocationManager to start location updates and the critical requirement to stop tracking using the off method to conserve battery life. The content is designed for developers utilizing the LocationKit API who need to manage real-time location data efficiently.
