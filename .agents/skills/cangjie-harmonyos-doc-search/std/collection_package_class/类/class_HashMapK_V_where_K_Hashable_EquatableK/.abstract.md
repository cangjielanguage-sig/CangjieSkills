This directory contains comprehensive API reference documentation for the `HashMap` class in the Cangjie standard library. It details the implementation of a hash table data structure where keys must be `Hashable` and `Equatable`. The documentation covers class definitions, initialization methods, core operations like insertion and deletion, and extensions for equality and string conversion. It is designed for Cangjie developers seeking efficient key-value storage solutions, providing technical insights into time complexity, operator overloading, and exception handling for generic types.
