This directory provides API reference documentation for the `ObservedArrayList` class in the Cangjie language, a component designed for managing reactive list data states within the ArkUI framework. It covers the class definition, inheritance from `ObservedComplexAbstract` and `ArrayLike`, and essential properties like `size`. The documentation details initialization constructors, manipulation methods (append, clear, clone), and state observation mechanisms. Intended for HarmonyOS developers utilizing ArkUI Full capabilities (version 12+), it offers the necessary interfaces for handling dynamic collections and managing state changes in UI applications.
