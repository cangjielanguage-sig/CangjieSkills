# 组件级像素取整

This directory provides comprehensive documentation on component-level pixel rounding within the ArkUI framework, specifically tailored for the Cangjie language. It addresses the common UI challenge of visual artifacts, such as 1px layout gaps, caused by floating-point rendering imprecisions. The included resources cover the fundamental data structures for defining rounding policies, practical code examples demonstrating how to resolve alignment issues, and the specific API functions used to control pixel behavior. This guide is highly suitable for HarmonyOS developers and UI engineers who aim to achieve precise, high-quality visual rendering and eliminate sub-pixel alignment errors in their application interfaces.

## Detailed Description

### 基础类型定义.md 基础类型定义.md
This document serves as an API reference for the Cangjie class `PixelRoundPolicy`, which defines pixel rounding alignment for component boundaries within the ArkUI framework. The content details the class structure, specifically focusing on four directional properties: start, top, end, and bottom, along with their corresponding constructor. Key information includes that all properties are nullable `PixelRoundCalcPolicy` types defaulting to None, and the class supports read-only access to these alignment settings. Intended for HarmonyOS developers using Cangjie, this reference helps manage precise UI rendering by controlling pixel rounding behavior.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating how to resolve 1px layout gaps in parent components using the `pixelRound` attribute. The content includes a complete `EntryView` code snippet, an explanation of rendering behavior when pixel rounding is disabled, and visual comparisons. Key information highlights that fractional pixel values in parent component widths cause display gaps, which are mitigated by applying `PixelRoundPolicy` with `NO_FORCE_ROUND`. This guide targets ArkUI developers using the Cangjie language who need to handle precise layout rendering and sub-pixel alignment issues.

### 组件级像素取整_2more.md 组件级像素取整_2more.md
This API documentation outlines the `pixelRound` function for ArkUI, designed to manage pixel rounding at the component level to eliminate visual artifacts from floating-point rendering. The primary section details the function signature, system capabilities, and the `PixelRoundPolicy` parameter. Key takeaways include the logic that rounding depends on both component dimensions and position relative to the parent container, recalculating size based on rounded top-left and bottom-right coordinates. Intended for ArkUI developers, this reference helps ensure precise visual alignment in UI layouts.
