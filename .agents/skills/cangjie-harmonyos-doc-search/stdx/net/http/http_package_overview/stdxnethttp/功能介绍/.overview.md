# 功能介绍

本目录主要介绍了 http 库的核心功能，包括对 HTTP/1.1、HTTP/2 和 WebSocket 协议的全面支持。内容涵盖了协议升级机制、客户端与服务端的构建方式、请求响应处理以及必要的环境配置。特别强调了 OpenSSL 3 的依赖安装与验证，确保 TLS 功能正常运行。该文档适合需要进行网络通信集成、协议升级及环境部署的开发人员阅读，提供了从基础配置到高级 API 使用的完整指南。

### http.md http.md
本文档旨在介绍 http 库的核心功能、协议支持及使用方法，帮助开发者构建和管理 HTTP 客户端与服务端。主要涵盖 HTTP/1.1 与 HTTP/2 协议配置、ClientBuilder 与 ServerBuilder 实例构建、请求与响应的构造方式，以及常用工具类。关键信息包括 HTTP/2 需配置 TLS 和 ALPN、握手失败自动回退机制、构建后参数不可变性（除特定热更新）、Logger 需线程安全，以及通过 HttpContext 处理请求。该文档面向需要集成 HTTP 通信功能的开发者，要求具备基本的网络编程知识。
