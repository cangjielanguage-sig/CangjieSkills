This directory contains API reference documentation for the HarmonyOS Asset Store service, specifically designed for the Cangjie programming language. It covers the secure storage, management, and retrieval of critical assets such as passwords and tokens. Key topics include asset addition, querying, updating, removal, authentication, and error handling. The documentation details various structures, enumerations, and classes required for configuring security policies, accessibility, and synchronization. It is suitable for HarmonyOS developers and software engineers implementing secure data handling and asset management in their applications.
