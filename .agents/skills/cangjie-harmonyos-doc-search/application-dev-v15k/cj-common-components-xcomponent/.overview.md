# cj-common-components-xcomponent

This directory provides technical resources for developing high-performance custom rendering components using the Cangjie language on the OpenHarmony platform. It focuses on the XComponent, a critical UI element for complex graphics scenarios such as camera previews and game rendering. The content covers the integration of Cangjie UI logic with Native C++ using the Foreign Function Interface (FFI), EGL, and OpenGLES. It includes configuration guides for CMake, build profiles, and lifecycle management. This collection is suitable for HarmonyOS developers and C++ programmers looking to bridge Cangjie applications with native graphics capabilities to achieve optimal performance.

## Detailed Description

### the_minimum_version_of_CMa_2more.md the_minimum_version_of_CMa_2more.md
This technical guide details the setup for building a native C++ library that interfaces with the Cangjie language using FFI. It covers the CMakeLists.txt configuration for compiling the nativerender shared library, linking against OpenHarmony libraries like EGL and GLES. The document presents the exportffi.cpp source code, which acts as a glue layer exposing functions such as FFIChangeColor to Cangjie. Additionally, it provides instructions for modifying build-profile.json5 to enable native compilation and integrating the output into the Cangjie project via cjpm. This guide is intended for developers building hybrid OpenHarmony applications.

### 自定义渲染XComponent/
This directory focuses on the XComponent component within the HarmonyOS ecosystem, specifically designed for complex custom rendering scenarios such as camera previews and game graphics. It covers the integration of the Cangjie language with Native C++ graphics processing using EGL and OpenGLES. Key topics include the self-drawing principle, NativeWindow buffer submission, XComponentController lifecycle management, and surface positioning. This resource is suitable for HarmonyOS developers and C++ programmers looking to bridge Cangjie UI logic with high-performance native graphics capabilities.
