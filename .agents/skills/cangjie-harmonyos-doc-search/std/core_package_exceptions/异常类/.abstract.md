This directory contains API reference documentation for exception and error handling classes within the Cangjie programming language. It covers the core hierarchy of runtime error management, including base classes like `Exception` and `Error`, as well as specific subclasses for arithmetic issues, memory violations, illegal arguments, and unsupported operations. The documentation details constructors, properties, and methods for debugging and error reporting. It is suitable for Cangjie software developers who need to implement robust error handling, manage runtime exceptions, or understand the inheritance structure of system errors in their applications.
