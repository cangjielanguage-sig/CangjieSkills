This directory contains API reference documentation for the `ohos.eventhub` module within the Cangjie programming language and HarmonyOS AbilityKit framework. It covers the implementation of event-driven architecture, focusing on the `EventHub` class and a series of generic `Event` and `EventCallBack` classes designed to handle events with zero to five parameters. Key topics include event subscription, unsubscription, emission, and lifecycle management. This resource is suitable for Cangjie developers and system engineers building robust, type-safe event communication mechanisms in applications using SystemCapability.Ability.AbilityRuntime.Core.
