# class_WifiScanInfo

本目录包含Cangjie语言中关于WLAN热点扫描的API参考文档。主要定义了用于存储扫描结果的`WifiScanInfo`类及其相关的时间戳变量。内容涵盖了SSID、BSSID、信号强度、频段、加密类型等关键属性，以及用于记录扫描时间的变量。这些文档适用于从事WiFi站点（STA）功能开发的开发者，旨在帮助他们理解和处理扫描到的热点数据结构及时间信息。

### class_WifiScanIn_15more_52ab0d34.md class_WifiScanIn_15more_52ab0d34.md
