This directory contains API reference documentation for the deprecated `Matcher` class and associated regular expression functions in the Cangjie programming language. It covers legacy pattern matching capabilities, including scanning input sequences, locating subsequences, string replacement, and splitting operations. Key topics include the `Matcher` constructor, `find` methods, `replaceAll`, and region management. Developers are advised to migrate to the `Regex` class for future implementations. This documentation is suitable for Cangjie developers maintaining legacy code or requiring detailed syntax for regex operations, string manipulation, and exception handling within the deprecated framework.
