# P2P模式开发指导

This directory provides comprehensive technical guidance for developing Wi-Fi Peer-to-Peer (P2P) functionalities using the Cangjie language within the HarmonyOS ecosystem. It covers the implementation of direct TCP/IP connections between devices without an Access Point, including creating and managing P2P groups, device discovery, and establishing connections. Key topics include API usage (createGroup, startDiscoverDevices), event handling, configuration parameters for persistent groups, and monitoring state changes. This documentation is suitable for application developers and system engineers looking to integrate wireless connectivity features into their applications, requiring a basic understanding of HarmonyOS system capabilities and Cangjie syntax. It serves as a complete resource for mastering P2P interactions.

## Detailed Description

The files in this directory offer both high-level overviews and step-by-step implementation guides for P2P development.

### 主要场景开发步骤.md 主要场景开发步骤.md
This technical guide outlines the development steps for implementing Wi-Fi Peer-to-Peer (P2P) functionalities using the Cangjie language. It covers two primary scenarios: creating and deleting P2P groups, and establishing P2P connections. The document details prerequisite steps like importing modules and enabling Wi-Fi, followed by specific API calls such as createGroup, removeGroup, and startDiscoverDevices. It explains configuration parameters like netId for temporary versus persistent groups and demonstrates event handling through callbacks for device discovery and connection status changes. Intended for application developers building connectivity features, this guide requires knowledge of HarmonyOS system capabilities and Cangjie syntax.

### 简介_3more.md 简介_3more.md
This document introduces Wi-Fi Peer-to-Peer (P2P) mode functionality, explaining how to establish direct TCP/IP connections between stations without an Access Point. It covers usage scenarios like creating or deleting P2P groups and establishing connections. The text provides a comprehensive list of Cangjie APIs, highlighting key functions such as createGroup, startDiscoverDevices, and p2pConnect, alongside event registration methods for monitoring state changes. This technical reference is designed for developers implementing wireless connectivity features, offering the necessary interface definitions to manage P2P device discovery and interaction.
