# specified启动模式

This directory provides comprehensive technical documentation on the "specified" startup mode for UIAbility components within the HarmonyOS ecosystem. It focuses on advanced instance management strategies where system behavior is dictated by unique keys passed via Want parameters. The documentation covers essential topics such as the operational principles of instance matching, lifecycle callbacks (onNewWant vs. onCreate), and configuration in module.json5. Additionally, it offers practical implementation examples using the Cangjie language, specifically targeting scenarios like document applications that require precise control over multi-instance logic. This resource is ideal for HarmonyOS developers seeking to optimize resource management and user experience in complex applications.

## Detailed Description

### specified启动模式_1.md specified启动模式_1.md
This technical guide explains the "specified" launch mode for UIAbility components, designed for scenarios requiring specific instance management based on unique keys, such as document applications. It details the operational principle where the system uses a unique instanceKey passed via Want parameters to match existing instances through AbilityStage.onAcceptWant(). The document covers the resulting lifecycle callbacks, distinguishing between reusing an instance via onNewWant() or creating a new one via onCreate(). It also provides configuration steps for module.json5 and a Cangjie code example. Targeted at HarmonyOS developers, this guide facilitates precise control over application instance behavior.

### specified启动模式_2.md specified启动模式_2.md
This technical guide demonstrates how to implement the "specified" startup mode for UIAbility in HarmonyOS applications using the Cangjie language. The content covers constructing a Want object with custom parameters to initiate an ability and implementing the onAcceptWant() lifecycle callback in AbilityStage to return a unique instance key. Key information includes the system behavior where a matching key triggers the reuse of an existing instance via onNewWant() rather than creating a new one. This guide is intended for HarmonyOS developers familiar with the Stage model and ability lifecycle management.

### specified启动模式_3.md specified启动模式_3.md
This technical guide explains the specified startup mode for UIAbility, focusing on managing multiple instances in document applications through unique Key bindings. The content details the mechanism where file paths serve as Keys to control instance creation and reuse, supported by a four-step example demonstrating the lifecycle of UIAbility instances for different files. Key information highlights that the system launches a new instance for a new Key but retrieves and focuses an existing instance if the Key matches, ensuring efficient resource management. Intended for application developers, this document helps in implementing multi-instance logic for document-centric apps.
