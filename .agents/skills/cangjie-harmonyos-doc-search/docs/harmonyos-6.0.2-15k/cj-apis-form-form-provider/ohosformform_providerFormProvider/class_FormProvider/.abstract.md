This directory contains essential API reference documentation for the Cangjie `FormProvider` class, focusing on the management and interaction of form (card) providers. It provides developers with the technical specifications needed to retrieve current application form information, manage form refresh timing, and update form content efficiently. Key topics include the `getFormsInfo` method for querying states, `setFormNextRefreshTime` for scheduling updates, and `updateForm` for data modification. The documentation also covers parameter constraints, return values, and exception handling with specific error codes. This content is specifically tailored for Cangjie developers and application engineers using the FormKit who need to implement robust form lifecycle management, handle data binding structures, and effectively manage system-level errors in their applications.
