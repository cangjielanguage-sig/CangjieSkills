# RSAECBOAEPSHA256

本目录展示了如何在鸿蒙系统的仓颉语言中，利用HUKS框架实现RSA/ECB/OAEP/SHA256模式的加密与解密操作。内容涵盖了密钥生成、参数配置、数据加密、解密以及密钥删除的完整流程。核心知识点包括HuksParam的算法定义、initSession/finishSession API的使用以及密钥生命周期管理。该文档适合需要在HarmonyOS应用中进行安全数据传输和密钥管理的开发者参考。

## 快速导航

- 你想了解如何生成密钥并进行加密？ → 查看 RSAECBOAEPSHA256_1.md
- 你想了解如何解密数据或删除密钥？ → 查看 RSAECBOAEPSHA256_2.md

## 详细描述

### RSAECBOAEPSHA256_1.md RSAECBOAEPSHA256_1.md
本文档演示了如何在仓颉语言中使用RSA/ECB/OAEP/SHA256模式进行加密操作。文档涵盖了密钥生成、加密及解密的参数配置函数，以及生成密钥和加密数据的具体实现流程。核心内容包括通过HuksParam定义算法、密钥长度、填充模式（OAEP）、分组模式（ECB）和摘要（SHA256），并展示了调用generateKeyItem、initSession和finishSession等API的代码示例。该文档面向需要在鸿蒙系统中使用通用密钥库进行安全开发的开发者。

### RSAECBOAEPSHA256_2.md RSAECBOAEPSHA256_2.md
该文档提供了基于HUKS框架的RSA解密与密钥删除功能的代码实现示例。文档主要包含模拟解密场景和模拟删除密钥场景两个部分。关键信息包括解密过程通过获取参数、初始化会话和结束会话完成，密钥删除则通过指定别名调用删除接口实现。该文档属于代码示例或教程片段，适用于HarmonyOS应用开发者，读者需具备HUKS API及密钥管理的基础知识。关键词：HUKS、RSA解密、密钥删除、initSession、finishSession。
