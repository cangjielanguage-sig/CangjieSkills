## 组件属性

### func selectedColor(ResourceColor)

```cangjie
public func selectedColor(color: ResourceColor): This
```

**功能：** 设置组件打开状态的背景颜色。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|color|[ResourceColor](./cj-common-types.md#interface-resourcecolor)|是|-|设置组件打开状态的背景颜色。<br>初始值: 当ToggleType为Switch时，初始值为@r(sys.color.ohos_id_color_component_activated)。<br>当ToggleType为Checkbox时，初始值为@r(sys.color.ohos_id_color_component_activated)。<br>当ToggleType为Button时，初始值为@r(sys.color.ohos_id_color_component_activated)混合@r(sys.color.ohos_id_color_text_highlight_bg)的透明度。|

### func switchPointColor(ResourceColor)

```cangjie
public func switchPointColor(color: ResourceColor): This
```

**功能：** 设置Switch类型的圆形滑块颜色。仅对type为ToggleType.Switch生效。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|color|[ResourceColor](./cj-common-types.md#interface-resourcecolor)|是|-|Switch类型的圆形滑块颜色。初始值：@r(sys.color.ohos_id_color_foreground_contrary)|

### func switchStyle(Float64, ResourceColor, ResourceColor, Float64)

```cangjie
public func switchStyle(pointRadius!: Float64, unselectedColor!: ResourceColor, pointColor!: ResourceColor,
    trackBorderRadius!: Float64): This
```

**功能：** 设置Switch类型的样式。仅对toggleType为Switch生效。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|pointRadius|Float64|是|-| **命名参数。** 设置Switch类型的圆形滑块半径。<br> **说明：**<br> 设定值小于0时按照默认算法设置，设定值大于等于0时按照设定值设置。<br> 未设定此属性时，圆形滑块半径根据默认算法设置。<br> 默认算法：（组件高度（单位：vp） / 2） - （2.vp * 组件高度（单位：vp） / 20.vp）。|
|unselectedColor|[ResourceColor](./cj-common-types.md#interface-resourcecolor)|是|-| **命名参数。** 设置Switch类型关闭状态的背景颜色。<br>初始值：0x337F7F7F。|
|pointColor|[ResourceColor](./cj-common-types.md#interface-resourcecolor)|是|-| **命名参数。** 设置Switch类型的圆形滑块颜色。<br> 初始值：@r(sys.color.ohos_id_color_foreground_contrary)。|
|trackBorderRadius|Float64|是|-| **命名参数。** 设置Switch类型的滑轨的圆角。<br> **说明：**<br>设定值小于0时按照默认算法设置，设定值大于组件高度一半时按照组件高度一半设置，其他场合按照设定值设置。<br> 未设定此属性时，滑轨圆角根据默认算法设置。<br> 默认算法：组件高度（单位：vp） / 2。|
