This directory provides comprehensive API documentation for the `WrappingOp` interface and specific arithmetic functions tailored for the `UInt64` type within the Cangjie programming language. It focuses on essential operations such as addition, subtraction, multiplication, division, modulo, increment, decrement, negation, and bitwise shifts. A central theme is the management of arithmetic overflow through high-order truncation, a strategy where high bits are discarded to maintain performance and predictability without throwing exceptions. Additionally, it details specific logic for shift operations, such as utilizing the low 6 bits for large counts. This resource is ideal for Cangjie developers and systems programmers who require low-level control over 64-bit unsigned integer arithmetic and need to implement robust, overflow-safe logic in their applications.
