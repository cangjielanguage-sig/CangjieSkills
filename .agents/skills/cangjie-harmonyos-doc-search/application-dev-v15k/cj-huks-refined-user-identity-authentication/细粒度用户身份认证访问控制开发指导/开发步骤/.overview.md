# 开发步骤

This directory outlines the development steps for implementing secure SM4 cryptographic operations with biometric authentication using the Cangjie language. It covers the complete workflow from generating keys with fingerprint access control in the Universal Keystore Kit to managing secure decryption sessions integrated with the User Authentication Kit. Key topics include key attribute configuration, session initialization, biometric verification, and token handling. This guide is suitable for software developers building secure applications on HarmonyOS who require biometric protection for sensitive data processing.

## Detailed Description

### 开发步骤_1.md
This document provides a step-by-step tutorial for developers on generating and using an SM4 cryptographic key with fingerprint-based access control using the Cangjie language and Universal Keystore Kit. It covers two main development steps: generating a key configured with specific security properties, including fingerprint authentication requirements for decryption, and initializing a session for encryption which does not require user authentication. Key information includes the configuration of key attributes such as algorithm, block mode, padding, and user authentication types. The code examples demonstrate how to set parameters like HUKS_TAG_USER_AUTH_TYPE and HUKS_TAG_KEY_AUTH_PURPOSE to enforce security policies. This guide targets software developers working on secure applications who need to implement biometric authentication for sensitive cryptographic operations.

### 开发步骤_2.md
This technical guide provides Cangjie code examples for completing cryptographic sessions and performing secure decryption with user authentication. Main topics include session finalization logic, SM4 decryption parameter configuration, and integration with the User Authentication Kit. Key information demonstrates the workflow of initializing a session to retrieve a challenge, triggering a fingerprint scan via the userIAMAuthFinger function, and handling the resulting authentication token for access control. The document targets developers implementing secure key access control in applications requiring biometric verification, utilizing the Universal Keystore Kit and User IAM.

### 开发步骤_3.md
This document serves as a technical tutorial illustrating the implementation of the final step in a HUKS (HarmonyOS Universal KeyStore) session integrated with UserIAM authentication. It details the code structure for the finishSession and publicFinishFunc functions, which handle the completion of cryptographic operations and error management. Key sections include test functions testSm4CipherInit and testSm4CipherFinish, demonstrating the workflow of initializing a session, performing biometric authentication via UserIAM, and using the resulting authToken to finalize SM4 decryption. The content highlights the critical relationship between the authentication token and the secure data processing. Targeted at application developers, this guide requires prior knowledge of HUKS APIs and biometric integration concepts.
