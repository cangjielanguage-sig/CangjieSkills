# cj-apis-system_parameter_enhance

This directory provides the API reference documentation for the Cangjie SystemParameter class, a critical tool for developers managing system configurations through key-value pairs. It covers the necessary module imports and usage instructions for Cangjie projects, detailing the static methods within the SystemParameter class. Key information includes the `get` function for retrieving values with optional defaults and the `set` function for modifying values. The document also explains how to handle `BusinessException` for errors such as permission denial or invalid parameters. Additionally, it specifies system capabilities and error codes. This documentation is specifically designed for OpenHarmony developers using the BasicServicesKit to interact with system services, providing the technical guidance needed to effectively manage system settings and ensure application stability within the OpenHarmony ecosystem. By following these guidelines, developers can robustly integrate system parameter management into their software solutions.
