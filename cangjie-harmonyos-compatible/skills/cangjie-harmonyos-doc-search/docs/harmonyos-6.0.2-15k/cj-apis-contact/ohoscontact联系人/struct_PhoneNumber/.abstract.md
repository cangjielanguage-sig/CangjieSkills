This directory provides comprehensive API reference documentation for the `PhoneNumber` struct utilized within the Cangjie programming language's SystemCapability.Applications.ContactsData framework. It focuses on the structural definition of phone number objects, detailing constructors for object instantiation and read-write properties for managing label IDs, label names, and phone number strings. Furthermore, the documentation extensively lists static integer constants that define specific phone categories, including standard types like Mobile, Home, and Work, as well as specialized communication modes such as Telex and TTY/TDD. This resource is specifically designed for software developers and application engineers building contact management systems, offering the necessary technical specifications to implement effective contact data storage, categorization, and retrieval functionalities in a Cangjie environment.
