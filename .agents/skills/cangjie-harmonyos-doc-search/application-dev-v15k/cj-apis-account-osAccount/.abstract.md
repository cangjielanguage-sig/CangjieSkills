This directory serves as a comprehensive technical resource for the HarmonyOS system account management module, specifically tailored for the Cangjie programming language. It provides detailed API references that cover core data structures such as `DomainAccountInfo` and `OsAccountInfo`, alongside enumerations defining various account types. The documentation focuses heavily on the `AccountManager` class, which is central to executing account operations like creation, deletion, and querying. Furthermore, it addresses system constraints related to device management. This content is primarily designed for system application developers and engineers seeking to integrate robust user account management and restriction enforcement capabilities into their HarmonyOS applications, ensuring they have the necessary tools to handle complex user scenarios.
