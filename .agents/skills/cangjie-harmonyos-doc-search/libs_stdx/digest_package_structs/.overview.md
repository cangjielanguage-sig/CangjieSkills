# digest_package_structs

This directory contains the comprehensive API reference documentation for the `HashType` struct, a fundamental component of the Cangjie digest package. The content focuses on defining secure identifiers for a variety of cryptographic hash algorithms, ensuring type safety and standardization within the ecosystem. It covers a broad spectrum of algorithms, including MD5, SHA1, SHA256, SHA384, SHA512, and the SM3 standard. The documentation provides an in-depth look at the struct's architecture, specifically detailing its inheritance from the `ToString` and `Equatable` interfaces. It enumerates the static properties available for algorithm selection and describes the instance methods used for string conversion and equality checks. This resource is specifically tailored for Cangjie developers who are actively implementing cryptographic hashing solutions. It serves as a critical guide for understanding the available algorithm types, their specific interfaces, and how to effectively integrate this type-safe enumeration into digest functions to ensure robust and secure application development. By utilizing this documentation, developers can ensure they are correctly implementing the necessary cryptographic standards required for modern software security.
