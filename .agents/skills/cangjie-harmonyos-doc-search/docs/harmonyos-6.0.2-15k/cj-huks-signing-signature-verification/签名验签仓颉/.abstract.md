This directory provides comprehensive resources for implementing digital signature and verification functionalities using the Cangjie programming language within the HarmonyOS ecosystem. It centers on the Universal Keystore Kit (HUKS), covering the full lifecycle of cryptographic operations from key generation to deletion. The documentation supports a wide range of algorithms, including ECC, RSA, and national standards like SM2, ensuring data integrity and security. It is specifically designed for Cangjie developers who need to integrate hardware-backed cryptographic features and secure signing capabilities into their applications.
