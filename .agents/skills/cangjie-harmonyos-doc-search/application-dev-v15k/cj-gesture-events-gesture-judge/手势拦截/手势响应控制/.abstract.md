This directory focuses on managing and resolving gesture conflicts in complex UI scenarios, particularly nested scrolling. It covers technical implementations in Cangjie and ArkTS (HarmonyOS), detailing how to use APIs like `shouldBuiltInRecognizerParallelWith`, `onGestureRecognizerJudgeBegin`, and `parallelGesture` to control gesture responses dynamically. The content includes code examples for coordinating parent and child scroll components, adjusting recognizer states based on scroll position, and setting up parallel gestures. It is suitable for developers working on advanced user interfaces requiring precise interaction logic and smooth scrolling transitions.
