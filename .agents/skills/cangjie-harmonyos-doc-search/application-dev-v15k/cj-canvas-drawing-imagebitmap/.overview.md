# cj-canvas-drawing-imagebitmap

This directory serves as a comprehensive resource for the `ImageBitmap` functionality within the Cangjie UIKit and ArkUI frameworks. It is designed to assist developers in the complex tasks of canvas rendering, specifically focusing on the storage, manipulation, and management of pixel data. The documentation includes detailed API references, module import syntax, and initialization strategies using local image paths or PixelMap objects. Key topics cover support for standard image formats such as BMP, JPG, PNG, and SVG, dimension customization using Float64 or Int64, and resource lifecycle management via the `close()` method. This content is highly suitable for software developers utilizing the Cangjie language to build graphical user interfaces, manage image resources, and perform efficient pixel manipulation.

## Detailed Description

### ImageBitmap/
This directory provides comprehensive documentation for the ImageBitmap object and class within the Cangjie UIKit and ArkUI frameworks. It focuses on the storage, manipulation, and management of pixel data rendered by a canvas. The content covers essential API references, module import syntax, and detailed initialization strategies using local image paths or PixelMap objects. Key topics include support for standard formats like bmp, jpg, png, and svg, dimension customization using Float64 or Int64, and resource lifecycle management via the `close()` method. This documentation is suitable for software developers using the Cangjie language who are building graphical user interfaces and need to handle canvas rendering outputs, image resource handling, and pixel manipulation efficiently.
