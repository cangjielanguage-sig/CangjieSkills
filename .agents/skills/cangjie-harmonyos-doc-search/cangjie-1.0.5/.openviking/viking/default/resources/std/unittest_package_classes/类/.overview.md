This directory provides comprehensive API documentation for the core classes within the Cangjie unit testing framework. It covers the infrastructure for constructing and executing test suites, managing unit tests and benchmarks, and handling assertion contexts. Additionally, it details data processing strategies for property-based testing and various reporting mechanisms including console, text, CSV, and XML outputs. This documentation is intended for developers working with the Cangjie language who need to implement automated testing solutions, analyze performance metrics, or extend the testing framework's capabilities.
