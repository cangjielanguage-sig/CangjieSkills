This directory provides essential API reference documentation for the Timer module in the Cangjie programming language, designed for use with the ArkUI framework. It focuses on the mechanisms required to schedule and manage time-based tasks, including one-time executions and repetitive operations. The documentation covers critical functions such as `once` for delayed execution, `repeatDuration` for periodic intervals, and `cancel` for stopping tasks. It explains parameters like delay, interval, and CatchupStyle, offering developers the tools to implement robust timing logic. This content is specifically suitable for Cangjie developers working on HarmonyOS applications who need to handle asynchronous code execution, background operations, or precise event scheduling within their software architecture.
