# cj-arkgraphics2D-introduction

本目录包含ArkGraphics 2D（方舟2D图形服务）的简介指南，旨在帮助开发者深入理解该图形服务的核心功能与优势。文档详细介绍了ArkGraphics 2D的能力范围、典型使用场景及其技术亮点，重点阐述了其提供的统一图形API，特别是针对不同内容定制帧率的能力，包括同窗口多帧率支持和动态帧率配置，从而在保证用户体验流畅度的同时有效降低功耗。核心关键词涵盖ArkGraphics 2D、图形绘制、帧率定制、动态配置及功耗优化。该文档主要面向应用开发者，尤其是致力于优化自绘制内容、游戏或视频渲染性能的技术人员。
