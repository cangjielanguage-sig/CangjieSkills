# tools

This directory serves as a comprehensive repository for documentation regarding the Cangjie programming language's developer toolchain. It encompasses essential resources for command-line utilities and the Language Server Protocol (LSP) implementation, which are critical for integrating Cangjie support into various editors and IDEs. Key topics include project management via CJPM, debugging tools, code formatting, and environment setup. This documentation is suitable for all Cangjie developers, ranging from beginners configuring their initial environment to experienced users seeking advanced tooling capabilities to enhance coding efficiency and code quality.

## Detailed Description

### [1] cangjie-language-server/
This directory encompasses the core infrastructure and documentation for the Cangjie Language Server, a vital backend service designed to power language features in Integrated Development Environments (IDEs) supporting the Cangjie programming language. It provides the necessary details for understanding how the server operates to facilitate features like auto-completion, syntax highlighting, and error checking within editor environments.

### [2] cmd-tools/
The `cmd-tools` directory serves as a centralized repository for documentation regarding the Cangjie programming language's command-line utility suite. It encompasses a wide array of essential developer tools, including project management (CJPM), debugging, and other utilities necessary for the development lifecycle. This section is crucial for developers who prefer terminal-based workflows or need to automate build and test processes.

### [3] command_line_overview/
This directory specifically collects overview documents for command-line tools and language server tools in the Cangjie language development environment. It details how to use these tools for efficient development, covering key development stages from project creation and management, code debugging, to code formatting. Furthermore, the documentation emphasizes the importance of environment preparation and provides links to toolchain installation guides. As the entry point for the developer toolchain documentation, this directory is suitable for all Cangjie language developers, whether beginners configuring the environment or experienced developers looking up specific functions. By mastering these tools, developers can significantly improve coding efficiency and code quality.
