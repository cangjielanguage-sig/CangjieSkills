This directory provides comprehensive documentation on managing, classifying, and accessing resources in HarmonyOS development using the Cangjie language. It covers the creation of resource files, the distinction between application and system resources, and the logic for matching resources to specific device configurations. Key topics include resource qualifiers, resource groups, internationalization, and programmatic access methods. Designed for application developers and system architects, these guides help ensure efficient asset organization and consistent UI adaptation across various devices and themes.
