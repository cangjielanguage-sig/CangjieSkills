This directory provides API documentation for the `CString` type in the Cangjie programming language, focusing on C-style strings used for interoperability with C libraries. It covers core definitions, instantiation via constructors or `LibC`, and essential memory management procedures where developers must manually release memory. The content also includes extensions for string manipulation, such as lexicographical comparison and type conversion. Key topics include FFI, `mallocCString`, and resource management. This documentation is intended for developers requiring Foreign Function Interface capabilities to integrate C libraries into Cangjie applications and those handling low-level string operations.
