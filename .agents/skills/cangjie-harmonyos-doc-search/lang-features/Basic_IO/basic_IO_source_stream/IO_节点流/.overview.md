# IO_节点流

本目录主要介绍仓颉编程语言中的I/O节点流相关内容，涵盖了标准流与文件流的核心概念及操作方法。文档详细讲解了如何使用 `std.env` 包处理控制台输入输出，以及利用 `fs` 包进行文件系统的常规操作和流式读写。核心知识点包括 `ConsoleReader`、`ConsoleWriter`、`File` 类、`OpenMode` 枚举及 `try-with-resource` 资源管理。该目录适合仓颉语言开发者，特别是需要进行控制台交互、文件读写及资源管理的开发者参考。
