This directory contains API reference documentation for the `HiAppEvent` class in the Cangjie programming language, designed for HarmonyOS application development. It covers the PerformanceAnalysisKit's event tracking capabilities, including writing custom events, managing user identifiers and properties, configuring data processors, and setting up event watchers. Developers can find detailed function signatures, system capability requirements, error handling, and code examples for managing application event data storage and observation. This resource is suitable for Cangjie developers integrating analytics and performance monitoring into their applications.
