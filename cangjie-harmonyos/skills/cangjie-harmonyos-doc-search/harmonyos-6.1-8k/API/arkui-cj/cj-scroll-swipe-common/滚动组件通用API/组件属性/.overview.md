# 组件属性

本目录包含ArkUI框架中关于组件滚动交互与视觉属性的API参考文档，主要使用仓颉语言编写。内容涵盖了滚动组件的边缘渐隐效果、滑动速度限制、摩擦系数配置、父子组件嵌套滚动联动机制，以及滚动条的样式定制与内容裁剪策略。这些文档详细说明了相关函数的参数类型、默认值及行为逻辑，适用于API 22及以上版本。本目录主要面向HarmonyOS应用开发者，特别是需要精细控制List、Grid等可滚动容器交互体验和视觉效果的技术人员。

## 详细说明

### func_fadingEdgeOp_5more_34eb1eb1.md
这是一份Cangjie语言的ArkUI API参考文档，主要定义了滚动组件的边缘渐隐、滑动速度限制及摩擦系数配置。文档涵盖fadingEdge、flingSpeedLimit和friction三个核心函数，详细说明了其参数类型、默认值及行为逻辑。关键信息包括fadingEdge生效时会覆盖overlay属性并强制裁剪，flingSpeedLimit限制Fling初始速度，friction影响惯性滚动且默认值因设备类型而异。该文档适用于ArkUI全场景系统，起始版本为22，面向需要精细控制滚动交互体验的HarmonyOS应用开发者。

### func_nestedScrollNested_1d0477e2.md
本文档是ArkUI框架中nestedScroll函数的API参考文档，旨在配置子组件与父组件之间的嵌套滚动行为以实现滚动联动。文档主要包含函数签名、功能描述、系统能力、起始版本、参数详情及返回值说明。关键信息指出该函数接受必填的NestedScrollOptions参数来设置双向滚动模式，并返回组件实例T，适用于API 22及以上版本。主要面向需要实现复杂滚动交互逻辑的ArkUI应用开发者。

### func_scrollBarBar_6more_9a936429.md
本文档是ArkUI组件滚动条及内容裁剪相关的API参考文档，旨在指导开发者使用仓颉语言配置滚动条样式与交互。主要内容包括设置滚动条状态、颜色、宽度的函数，以及内容层裁剪和滚动手势控制的方法。关键点在于明确了各属性的默认值（如宽度4vp）、取值限制（如宽度不支持百分比）及裁剪范围。文档面向ArkUI应用开发者，适用于优化List、Grid等可滚动容器的用户体验和视觉效果。
