This directory acts as a specialized guide for Cangjie developers, providing practical examples and tutorials focused on the implementation and optimization of regular expressions. It covers the essential usage of the MatchData class for handling capture groups, iterating through results, and extracting specific string positions. Beyond the basics, it explores advanced regex features such as case-insensitive matching, multi-line pattern support, and Unicode character handling. The content also includes methods for string manipulation, including find-and-replace operations with specific scope control. These resources are specifically designed for programmers who need to parse structured text, validate complex data patterns, or perform sophisticated text processing tasks using the Cangjie standard library. The directory is structured to help users quickly locate solutions for specific regex challenges, ranging from basic data extraction to complex text substitution.
