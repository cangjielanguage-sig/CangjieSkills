# 资源分类与访问

This directory focuses on the classification, management, and access of resources within the HarmonyOS/Cangjie development environment. It covers the distinction between application and system resources, directory creation conventions, resource matching rules for different device states, and the syntax for accessing these resources programmatically. Key topics include localization, device adaptation, resource qualifiers, and the `cj_res_entry` mapping mechanism. It is suitable for developers and system integrators looking to optimize application performance and ensure visual consistency across various devices and configurations.

## Detailed Description

### 创建资源目录和资源文件_2more.md 创建资源目录和资源文件_2more.md
This technical guide explains how to create and manage resource directories and files in DevEco Studio, focusing on directory naming conventions and resource translatability. The document details three methods for creating resources: simultaneously creating directories and files, creating directories alone, or creating files alone, while explaining how qualifiers determine directory structure. It further introduces the attr property for JSON resources, which allows developers to mark strings as translatable or not and define translation priority levels like code or LT. Key takeaways include the automatic generation of directory names based on qualifiers and the specific application of translation attributes to string, strarray, and plural resource types within the base directory. This guide is intended for developers organizing application resources and managing localization workflows.

### 资源分类与访问.md 资源分类与访问.md
This document serves as a guide for classifying and accessing resources during application development. It covers two primary resource types: application resources and system resources. Key information explains that application resources allow developers to define and manage custom values for varying devices, while system resources utilize predefined, adaptive definitions that automatically adjust based on configurations like device type or dark/light themes. The document is intended for developers seeking to optimize UI elements such as colors, fonts, and images across different environments. Keywords: resource classification, application resources, system resources, adaptive configuration, UI development.

### 资源匹配_2more.md 资源匹配_2more.md
This technical reference document outlines the system rules for matching application resources to specific device states. It details the resource matching mechanism, the priority hierarchy of qualifier directories ranging from MCC and MNC to screen density, and specific naming restrictions. Key information includes that resources are prioritized from specific qualifier directories over the base directory, with rawfile excluded from matching. Exact matching is required for specific qualifiers like language and orientation. Additionally, resource names must avoid Cangjie language reserved keywords. This guide targets application developers managing localization and resource optimization.

### 资源访问.md 资源访问.md
This technical reference guide explains how to access and utilize application and system resources within the Cangjie development framework. The document covers two main sections: Application Resources and System Resources. It details the resource mapping mechanism in cj_res_entry, syntax for accessing specific types like strings, media, and rawfiles using @r(app.type.name) and @rawfile(), and methods for referencing system-defined styles via @r(sys.type.resource_id). Key takeaways include handling string placeholders, pluralization, and rawfile descriptors. Intended for Cangjie developers building HarmonyOS applications, this guide ensures proper asset management and visual consistency across apps.

### 资源分类/
This section provides a comprehensive guide to organizing and managing application resources, specifically within the HarmonyOS development environment. It covers the structural hierarchy of resource directories, distinguishing between resource directories (base, qualifiers, rawfile, resfile) and resource group directories (element, media, profile). Key topics include localization strategies, device adaptation, strict naming conventions, and the handling of various file formats like JSON and media assets. This documentation is essential for developers and system integrators seeking to optimize application performance and ensure proper resource matching across different devices and languages.
