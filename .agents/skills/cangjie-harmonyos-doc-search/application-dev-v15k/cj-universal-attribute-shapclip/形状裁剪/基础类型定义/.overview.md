# 基础类型定义

This directory contains API reference documentation for fundamental shape classes within the Cangjie ArkUI framework. It covers the base class `ShapeAbstract` and its derived implementations like `CircleShape`, `RectShape`, and `PathShape`, alongside utility classes such as `ProgressMask`. These definitions are essential for creating geometric shapes used in clipping, masking, and custom drawing interfaces. The documentation targets UI developers working with ArkUI system capabilities, specifically those implementing visual effects and geometric manipulations in applications running on version 12 or later.

### class_CircleShape_2more.md class_CircleShape_2more.md

It details the class definitions, their inheritance from ShapeAbstract, and their respective initialization methods. Key takeaways include the availability of default constructors creating zero-sized shapes and parameterized constructors accepting named width and height arguments of type Length. Both classes are specifically intended for use with clip and mask interfaces. The target audience consists of UI developers working with ArkUI system capabilities, specifically those implementing geometric clipping or masking effects in version 12 or later.

### class_PathShape_2more.md class_PathShape_2more.md

It covers the PathShape class, which inherits from ShapeAbstract for custom drawing paths used in clip and mask interfaces, and the ProgressMask class for creating progress-based masks. Key information includes PathShape constructors for default shapes, command strings, or specific dimensions, and ProgressMask methods for updating progress values, colors, and enabling breathing animations. This is intended for UI developers building ArkUI applications who need to implement custom clipping paths or dynamic progress masks.

### class_RectShape.md class_RectShape.md
This API documentation defines the RectShape class in the Cangjie language, designed for creating rectangular shapes used in clip and mask interfaces within the ArkUI framework. The document details the class inheritance from ShapeAbstract, two initialization constructors for setting dimensions, and three methods for configuring corner radii: radiusWidth, radiusHeight, and radius. Key information includes that all methods accept Length parameters with default values of 0.vp, and the class requires SystemCapability.ArkUI.ArkUI.Full starting from version 12. This reference guide targets ArkUI developers using Cangjie who need to implement geometric clipping or masking in their applications.

### class_ShapeAbstract.md class_ShapeAbstract.md
This API reference document defines the ShapeAbstract class, a base class for various shape components in the Cangjie ArkUI framework. It covers the class inheritance hierarchy and details five public methods: fill, height, offset, size, and width. The class redefines common properties for shapes like CircleShape and RectShape, utilizing ResourceColor for styling and Length for dimensions in vp. Targeted at UI developers using Cangjie for ArkUI development, specifically those needing to manipulate shape geometry and styling starting from version 12.
