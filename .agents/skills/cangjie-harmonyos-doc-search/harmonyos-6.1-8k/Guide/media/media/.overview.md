# media

This directory serves as a central repository for documentation related to the Media Kit media service development. It is designed to provide developers with a comprehensive guide to integrating and utilizing media functionalities within their applications. The content covers essential areas such as querying media information, understanding AVCodec supported formats, and performing video frame extraction. A key focus is placed on the AVImageGenerator tool, which allows for the extraction of video images at specific timestamps, though this feature is currently in Beta. This documentation is highly suitable for engineers specializing in media application development, particularly those working on video image processing, metadata retrieval, and ensuring codec compatibility. It aims to streamline the integration process of complex media capabilities.

## Detailed Description

### README_zh/
This directory contains the Chinese index documentation for Media Kit media service development, aiming to provide developers with a comprehensive entry point for functional guidance. The core content of the documentation covers key functions such as media information queries, AVCodec supported formats, and video frame extraction. Specifically, it highlights how to use the AVImageGenerator tool to extract video images at specified time points, a feature currently marked as Beta. This document is primarily intended for engineers engaged in media application development, especially suitable for development scenarios involving video image processing, media metadata acquisition, or codec compatibility checks, helping developers quickly integrate relevant media capabilities.

### cj-avcodec-support-formats/
This directory contains a reference document for AVCodec component supported formats, currently in the Beta stage, aiming to comprehensively clarify the multimedia processing capabilities and technical boundaries of the current version. The core content of the document is mainly divided into two sections: first, media codec capabilities, detailing the software and hardware decoding and encoding support for video formats including H.264 and H.265, as well as audio formats including AAC, MP3, and Flac; second, media data encapsulation and parsing, defining the stream types corresponding to mainstream container formats like MP4, MKV, and FLV, as well as specific encapsulation limitations (e.g., specific requirements for MP3 sampling rates). This document is primarily targeted at audio and video developers, aiming to help them quickly query and verify the compatibility of specific formats during project development and debugging.

### cj-avimagegenerator/
This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language and the MediaKit framework. It focuses specifically on the `AVImageGenerator` class, providing in-depth guidance on how to extract static images from video content. The documentation covers the necessary setup, usage patterns, and API details required to implement frame extraction effectively.
