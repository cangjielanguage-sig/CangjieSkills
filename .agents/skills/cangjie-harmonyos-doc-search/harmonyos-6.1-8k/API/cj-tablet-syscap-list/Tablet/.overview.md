# Tablet

本目录包含关于 Tablet 设备系统能力的文档，涵盖了最小系统能力集的定义、开发指南以及特定设备配置的详细参考列表。内容涉及 ArkUI、多媒体、安全、分布式数据等多个子系统，详细列出了设备支持的 API 和功能特性。这些文档旨在帮助系统工程师和应用开发者验证功能可用性，确保应用在 Tablet 平台上的兼容性，提高开发效率。

## 详细描述

### Tablet_1.md Tablet_1.md
本文档定义了当前版本 Tablet 设备支持的最小系统能力集，旨在帮助开发者了解设备特性支持情况。主要内容包括 SysCap 的定义说明、开发前的阅读建议，以及关于 Tablet 设备最小系统能力集的详细说明和 SDK 查询方式。关键信息指出，开发者使用该列表中的 SysCap 对应 API 开发 Tablet 应用时，可直接调用，无需进行 canIUse() 隔离判断，且该列表可通过 sdk 中的 tablet.json 文件查询。面向 Tablet 应用开发者，建议在开发前先阅读 SysCap 使用指南，以提高开发效率。

### Tablet_2.md Tablet_2.md
本文档作为特定 Tablet 设备配置支持的系统能力综合参考列表。它将功能分类为 ArkUI、图形、通信、多媒体、电源管理、安全和辅助功能等子系统。内容枚举了具体的能力标志，表明对 WebGL、AVSession、分布式硬件和用户认证等高级功能的完全支持。面向系统工程师和应用开发者，此配置文件有助于验证功能可用性并确保 Tablet 平台的兼容性。

### Tablet_3.md Tablet_3.md
本文档作为特定 Tablet 设备配置支持的系统能力综合参考列表。它枚举了包括杂项服务、文件管理、传感器、分布式数据管理、Ability 框架、安全、包管理、多媒体和图形在内的多个领域的能力。该列表详细说明了加密框架、分布式 KV 存储、音频空间化和 3D 图形等特定功能集，定义了应用程序可用的硬件和软件功能。面向系统工程师和应用开发者，该文件用于在开发和测试阶段验证 API 可用性并配置设备兼容性。
