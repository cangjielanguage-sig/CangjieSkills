### func_gridColOffsetInt32_7more.md

Key information includes system capabilities, starting version numbers, and specific parameter behaviors, such as the rendering implications of a zero span value. This technical reference is intended for developers implementing responsive grid layouts in ArkUI applications.

### func_spanGridColColumnOption.md
This document serves as an API reference for the span function within the Cangjie ArkUI framework, detailing how to configure the column span of grid elements. The content includes the function signature, system capabilities, version requirements, and a detailed parameter table explaining the GridColColumnOption type. Key takeaways include that the function sets the occupied column count and that a span value of 0 excludes the element from layout and rendering. This technical reference is intended for software developers building UI layouts using the ArkUI framework who need precise control over grid column distribution.
