This repository provides a comprehensive guide and implementation for AES symmetric encryption and decryption using the GCM (Galois/Counter Mode) within the Cangjie programming language ecosystem. It specifically targets segmented processing techniques, which are crucial for handling large data volumes efficiently without loading entire files into memory at once. The content covers essential cryptographic concepts such as secure key generation, initialization vector (IV) management, Additional Authenticated Data (AAD) integration, and authentication tag validation using the CryptoArchitectureKit. This resource is highly suitable for Cangjie developers who need to implement robust, memory-efficient, and secure data transmission protocols in their applications, ensuring both confidentiality and integrity of sensitive information.
