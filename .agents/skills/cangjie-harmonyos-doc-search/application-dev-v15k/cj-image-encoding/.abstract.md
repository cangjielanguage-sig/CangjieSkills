This directory contains a specialized technical guide designed for Cangjie developers who need to implement image encoding functionality in their applications. The core focus is on the ImagePacker API, a crucial component for converting PixelMap objects into standard, shareable image formats such as JPEG, PNG, WebP, and HEIF. These formats are essential for various scenarios, ranging from local storage to network transmission. The guide meticulously breaks down three primary workflows: encoding to file streams, which is useful for data transfer; encoding directly to files for local persistence; and saving images to the system gallery for user accessibility. Furthermore, it provides in-depth instructions on creating the ImagePacker instance and fine-tuning the output through PackingOption parameters, allowing developers to control the format and quality of the resulting images. By utilizing methods like `packing()` and `packToFile()` with different input sources, developers can ensure flexible and robust image handling. This documentation assumes the reader has prior experience with file system operations and understands the UIAbility context, making it an advanced resource for building media-rich applications in the Cangjie environment.
