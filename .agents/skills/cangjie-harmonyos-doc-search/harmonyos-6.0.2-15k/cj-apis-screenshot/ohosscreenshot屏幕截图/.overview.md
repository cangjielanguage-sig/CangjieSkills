### class_PickInfo_2more.md class_PickInfo_2more.md
This API reference document defines the Cangjie classes PickInfo and Rect for managing screen capture data within the WindowManager system. The documentation covers the properties and constructors for PickInfo, which encapsulates the capture region and image PixelMap, and Rect, which defines the geometric coordinates (left, top, width, height) of the capture area. Key information includes the read-only nature of PickInfo properties and the mutable properties of Rect, both requiring SystemCapability.WindowManager.WindowManager.Core starting from version 19. This guide is intended for developers implementing window management or image picking functionalities using the Cangjie language.
