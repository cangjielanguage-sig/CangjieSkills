# 自定义布局下的适配建议

This directory provides comprehensive guidelines and technical recommendations for adapting custom application layouts to ensure full compatibility with the Password Vault feature. It addresses critical scenarios including login, registration, and password modification, specifically focusing on UI patterns that may restrict core functionalities like credential autofill. Key topics include identifying unsupported layouts such as split-screen inputs and verification code logins, as well as managing autofill states during authentication failures. This documentation is essential for application developers and UI designers who are building custom authentication flows and need to integrate seamless, secure password management services without compromising user experience or functionality. By following these guidelines, developers can avoid common pitfalls that lead to restricted functionality and ensure a smooth integration of password vault services.

## Detailed Description

### 将导致功能受限的布局.md 将导致功能受限的布局.md
This reference document identifies specific interface layouts that restrict the functionality of the Password Vault feature. It categorizes limitations across three primary scenarios: Login, Registration, and Password Modification. The content highlights that layouts where the username and password are on separate screens, verification code logins, and certain incomplete password change forms are not supported for autofill. Key takeaways include the explicit "not supported" status for split-screen inputs and verification code scenarios. This guide is intended for developers and UI designers to ensure their application design remains compatible with the password filling service.

### 登录_4more.md 登录_4more.md
This guide outlines requirements for implementing login, registration, and password modification pages to ensure compatibility with password vault features like saving and autofilling. It details specific UI element requirements for these interfaces and explains how to handle failed authentication attempts. A key takeaway is setting the enableAutofill attribute to false during failed login or registration back navigation to prevent saving incorrect credentials. The document provides a Cangjie code example demonstrating state management for this autofill feature. This technical guide targets application developers building user authentication flows who need to integrate password management services.
