# cj-apis-crypto

This directory serves as a comprehensive API reference for the HarmonyOS Crypto Framework, specifically adapted for the Cangjie programming language. It provides developers with the necessary interfaces to implement robust security features within their applications. The content covers a broad spectrum of cryptographic operations, including symmetric and asymmetric encryption, digital signatures, complex key generation, message digests, and key agreement protocols. By supporting a diverse range of algorithms such as RSA, ECC, AES, SM2, and DSA, this framework ensures that developers can meet various security standards and requirements. This resource is primarily tailored for software developers and security engineers who are building applications in Cangjie and require advanced tools for data protection, secure key management, and the implementation of cryptographic protocols within the SystemCapability.Security.CryptoFramework environment.

### ohoscrypto加解密算法库框架/

This directory provides the complete API reference for the HarmonyOS Crypto Framework (ohoscrypto) as exposed to the Cangjie language. It serves as the definitive guide for developers looking to integrate cryptographic capabilities into their HarmonyOS applications using Cangjie. The documentation covers a wide range of cryptographic operations, ensuring that developers have access to tools for symmetric and asymmetric encryption, which are fundamental for data confidentiality. It also includes detailed references for digital signatures, which are vital for ensuring non-repudiation and data integrity, as well as key generation, message digests, and key agreement mechanisms.

The framework is architected to support a comprehensive suite of algorithms, including RSA, ECC, AES, SM2, and DSA. This variety allows developers to choose the most appropriate cryptographic standards for their specific use cases, whether they require high-performance symmetric encryption or secure asymmetric key exchanges. The inclusion of SM2 is particularly notable for applications requiring compliance with specific cryptographic standards. By abstracting the complexities of these algorithms, the framework enables developers to implement robust security features without needing to be cryptography experts themselves. This directory is intended for software developers and security engineers building Cangjie applications. It provides the necessary documentation to implement robust security features, manage complex key lifecycles, and develop secure cryptographic protocols, all within the scope of the SystemCapability.Security.CryptoFramework.
