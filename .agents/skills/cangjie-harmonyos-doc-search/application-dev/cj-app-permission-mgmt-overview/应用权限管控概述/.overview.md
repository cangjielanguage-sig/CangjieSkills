# 应用权限管控概述

This directory provides a comprehensive overview of the application permission control mechanism, specifically designed to protect system data and capabilities from unauthorized access. It covers the definition of protected data and functions, basic usage principles such as minimization and strict declaration, and the distinction between different authorization types. Key topics include system_grant (automatic installation authorization) and user_grant (runtime user authorization for sensitive data), as well as permission groups that combine related permissions to optimize user experience. Furthermore, it delves into fundamental concepts like TokenID, Ability Privilege Level (APL), and Access Control Lists (ACL). This documentation is primarily suitable for application developers who need to understand how to manage permissions, handle sensitive data access, and ensure user privacy and trust within the system architecture. By mastering these concepts, developers can effectively implement security measures and comply with system hierarchy requirements.

### 权限机制中的基本概念.md 权限机制中的基本概念.md
This reference document defines the fundamental concepts governing the system's permission mechanism to manage application resource access. It covers TokenID for unique application identity, APL (Ability Privilege Level) classifications for both applications and permissions, and the Access Control List (ACL). Key information includes how TokenID manages Access Tokens across multi-user and app cloning scenarios, how APL levels (normal, system_basic, system_core) restrict permission access based on application hierarchy, and how ACL allows lower-level apps to apply for higher-level permissions if enabled. This guide targets developers needing to understand permission authorization, identity mapping, and cross-level permission application.
