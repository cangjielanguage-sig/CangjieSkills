This directory provides comprehensive API reference documentation for the `ListItemGroupParams` class within the ArkUI framework, specifically tailored for the Cangjie language. It serves as a technical guide for developers building user interfaces, detailing the configuration parameters necessary for list item grouping components. The content covers essential class properties such as header, footer, space, and style, alongside multiple constructor overloads for object initialization. Key topics include the read-only nature of layout properties, the requirement for @Builder decorated functions, and version-specific updates like the style property introduced in version 19. This documentation is suitable for developers who need to programmatically define the structure, spacing, and visual styling of list item groups, ensuring precise control over UI component behavior and appearance.
