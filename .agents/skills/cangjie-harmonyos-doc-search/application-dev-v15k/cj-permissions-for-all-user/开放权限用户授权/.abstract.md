This directory focuses on the "user_grant" permission type within the HarmonyOS application development framework. It covers permissions that are open to all applications but require explicit user authorization at runtime. Key topics include the definition of user_grant permissions, the dual requirement of installation declaration and runtime approval, and specific implementation methods. It serves as a resource for developers handling sensitive data and hardware interactions, ensuring compliance with privacy controls. The content is essential for understanding how to properly request and manage sensitive access rights to protect user privacy while enabling necessary app functionality.
