# class_SheetOptions

This directory provides comprehensive API reference documentation for the `SheetOptions` class within the Cangjie language and ArkUI framework. It is specifically designed to assist developers in configuring optional properties for semi-modal pages, commonly referred to as sheets. The content covers a wide array of configuration parameters, including visual styling elements like colors and borders, layout sizing such as height and width detents, interaction behaviors like drag bars, and lifecycle event callbacks for appearance and dismissal. This documentation is essential for UI developers and system architects aiming to build sophisticated ArkUI applications, ensuring they can fully customize the presentation and behavior of sheet components. It targets system capabilities starting from version 12, offering the necessary technical details for advanced interface design and ensuring compatibility with the latest framework features.

## Detailed Description

The following sections provide in-depth summaries of the documentation files and subdirectories available in this module.

### class_SheetOptions.md
This document serves as API reference documentation for the SheetOptions class in the Cangjie language, designed to configure optional properties for semi-modal pages (sheets) within the ArkUI framework. It details the class definition, its inheritance from BindOptions, and a comprehensive list of constructor parameters. These parameters cover visual styling (colors, borders, shadows), layout sizing (height, width, detents), interaction behaviors (drag bar, outside interaction), and lifecycle event callbacks (appearance, dismissal, dimension changes). Key takeaways include the availability of specific options like preferType, showClose, and shouldDismiss, alongside system capability requirements starting from version 12. This reference is intended for UI developers using Cangjie to build ArkUI applications who need to customize the presentation and behavior of sheet components.

### init/
This directory contains API reference documentation for the `init` constructor function used to configure half-modal (semi-modal) sheet components within the Cangjie language and ArkUI framework. It covers a wide range of configuration options including visual styling, layout constraints, interaction behaviors, and lifecycle callbacks. Key topics include background colors, height detents, drag logic, and dismissal handlers. These resources are designed for developers building UI applications who need to implement or customize modal interfaces, specifically targeting version 12 or later of the framework.
