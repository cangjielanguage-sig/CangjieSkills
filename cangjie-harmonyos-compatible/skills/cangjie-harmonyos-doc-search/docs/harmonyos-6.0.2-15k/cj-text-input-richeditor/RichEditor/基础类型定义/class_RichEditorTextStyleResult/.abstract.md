This directory provides API reference documentation for the Cangjie class `RichEditorTextStyleResult`, utilized within the ArkUI framework to encapsulate text style information returned by the backend. It comprehensively covers the class structure, properties, and constructors required to define text appearance. Key topics include font attributes such as color, size, weight, and family, as well as text decoration. The documentation also details the distinction between read-write and read-only properties, highlighting advanced features like text shadow, line height, and letter spacing introduced in API version 19. This resource is specifically tailored for developers using the Cangjie language to implement and customize rich text editing capabilities programmatically.
