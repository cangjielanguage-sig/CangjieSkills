This directory contains API reference documentation for the `On` class within the Cangjie UiTest framework. It provides comprehensive details on locating and matching target UI controls based on specific characteristics like state, position, and attributes. The documentation covers class initialization, property-matching methods (e.g., clickable, checked, text), relative positioning, and hierarchical scoping. Designed for software developers and QA engineers, these resources facilitate the creation of automated UI tests using the Cangjie programming language and TestKit, enabling precise interaction with UI elements through method chaining and various matching modes.
