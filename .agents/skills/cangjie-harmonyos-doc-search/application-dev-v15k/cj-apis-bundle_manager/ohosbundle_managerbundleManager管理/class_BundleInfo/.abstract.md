This directory contains comprehensive API reference documentation for the `BundleInfo` class within the Cangjie programming language's BundleManager framework. It focuses on the structural definition and properties of application bundle information, enabling developers to access critical metadata. Key topics include the retrieval of application details, HAP module information, permission states, router maps, and signature data. The documentation outlines how to utilize the `getBundleInfoForSelf` method with specific flags to access various read-only subsets of data. This resource is essential for Cangjie application developers who need to programmatically query self-bundle metadata, manage application identity, handle versioning, and ensure security compliance through signature verification. By understanding these properties, developers can effectively manage application lifecycle and runtime behavior within the system environment.
