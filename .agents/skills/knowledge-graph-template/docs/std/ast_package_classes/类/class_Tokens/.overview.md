# class_Tokens

This directory contains comprehensive API reference documentation for the `Tokens` class within the Cangjie AST package. It covers the structural definition, initialization, and functional manipulation of sequences containing Token objects used in Abstract Syntax Tree (AST) processing. Key topics include the class inheritance hierarchy (ToString, Iterable, ToBytes), various constructors for flexible initialization, and methods for data access, modification, and conversion. Additionally, it details operator overloading for concatenation and subscripting. This documentation is intended for developers building compiler tools, text parsers, or manipulating ASTs who require a deep understanding of the Cangjie language syntax and standard collections.
