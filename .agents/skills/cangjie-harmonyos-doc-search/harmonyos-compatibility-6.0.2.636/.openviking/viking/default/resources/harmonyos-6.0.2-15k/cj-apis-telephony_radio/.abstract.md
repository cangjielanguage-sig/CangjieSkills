This directory serves as a comprehensive technical resource for the `cj-apis-telephony_radio` module, specifically designed to facilitate telephony radio operations within the OpenHarmony ecosystem using the Cangjie programming language. It provides a detailed API reference for the radio network search module, enabling developers to access critical system capabilities related to mobile connectivity. The documentation encompasses a wide range of essential data structures and enumerations necessary for managing network registration states, monitoring real-time signal strength, and identifying current radio technologies, including advanced 5G Non-Standalone (NSA) configurations. By offering classes such as `NetworkState` and `SignalInformation`, alongside specific enums for network selection, this directory equips developers with the tools needed to build robust telephony applications. It is specifically suitable for Cangjie developers who require precise control over device connectivity, need to interpret complex radio access technology indicators, and must handle dynamic network status changes efficiently within the `SystemCapability.Telephony.CoreService` framework.
