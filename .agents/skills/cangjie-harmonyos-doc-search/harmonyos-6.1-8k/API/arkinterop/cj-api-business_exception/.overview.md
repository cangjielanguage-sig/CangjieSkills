# cj-api-business_exception

本目录包含了Cangjie语言中`ohos.business_exception`模块的API参考文档，旨在为开发者提供接口调用过程中通用异常信息的标准定义。文档内容全面覆盖了`BusinessException`类的核心定义，详细说明了只读错误码`code`、用于获取自定义数据的`getData`方法以及用于获取错误信息的`toString`方法。此外，文档还介绍了用于异步处理的`AsyncCallback`类型。值得注意的是，该模块目前处于Beta阶段，且暂不支持Kit化导入。本文档主要面向需要在Cangjie应用中实现健壮的业务异常处理和异步回调机制的开发人员，是进行错误管理的重要参考资料。
