# 获取动态照片对象

This directory provides comprehensive technical documentation for retrieving and managing dynamic photo objects (MovingPhoto) within HarmonyOS applications using the Cangjie language. It covers essential workflows for developers, including how to fetch dynamic photos from the system media library using a Picker interface and how to programmatically load these assets directly from the application's sandbox storage. Key technical concepts involve the MediaLibraryKit, URI handling, PhotoAsset retrieval, and the requestMovingPhoto API. This resource is specifically designed for HarmonyOS developers and multimedia engineers seeking to implement advanced features like dynamic photo playback and processing in their applications.

## Detailed Description

### 获取动态照片对象_2more.md 获取动态照片对象_2more.md
This technical guide explains how to retrieve moving photo objects within an application using the Cangjie language, enabling playback or further processing. It details the process of obtaining moving photos from the media library via a Picker and constructing them from local sandbox files. The core workflow involves selecting a URI, retrieving the PhotoAsset using getAssets and getFirstObject, and finally obtaining the MovingPhoto object via requestMovingPhoto. The document includes practical Cangjie code examples demonstrating the implementation of these APIs and the handling of the MediaDataHandler callback. This guide targets application developers working with multimedia assets who need to integrate dynamic photo functionality into their HarmonyOS applications.

### 获取应用沙箱动态照片对象.md 获取应用沙箱动态照片对象.md
This document serves as a code tutorial demonstrating how to load a MovingPhoto object from an application sandbox using the MediaLibraryKit in the Cangjie language. The content covers the implementation of the loadMovingPhoto function and the prerequisite MainAbility setup for context retrieval. Key information includes the specific parameters required: the application context, the image file URI, and the video file URI, alongside error handling for BusinessException. This guide is intended for HarmonyOS developers working with multimedia assets who need to programmatically access and manage dynamic photos within their app's local storage. Keywords: MediaLibraryKit, loadMovingPhoto, Cangjie, HarmonyOS, MovingPhoto, App Sandbox.
