This directory contains a technical tutorial series focused on implementing fingerprint-based access control for cryptographic keys using the Universal Keystore Kit (HUKS) in the Cangjie language. It covers the complete workflow of generating secure keys, initializing cryptographic sessions, and performing SM4 encryption operations integrated with biometric authentication via UserIAM. Key topics include key property configuration, session management, authentication token retrieval, and secure data encryption. This guide is suitable for application developers working on HarmonyOS applications who need to integrate biometric security features to protect sensitive data.
