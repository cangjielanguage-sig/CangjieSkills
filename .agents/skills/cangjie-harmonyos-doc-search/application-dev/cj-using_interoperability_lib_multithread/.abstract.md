This directory provides a specialized technical guide focused on the interoperability between Cangjie and ArkTS, with a specific emphasis on handling multithreading. It addresses the significant architectural challenge where ArkTS's single-threaded nature conflicts with Cangjie's support for multithreading. The content outlines essential protocols to ensure system stability, such as confining ArkTS execution to its specific thread, performing rigorous data type conversions before spawning threads, and utilizing `context.postJSTask` for seamless context switching. Beyond theoretical rules, the guide offers practical, code-centric tutorials that walk developers through implementing asynchronous operations using both callbacks and Promises. It includes complete examples covering Cangjie logic, TypeScript interface definitions, and ArkTS invocation methods. This resource is tailored for software engineers and system architects seeking to robustly integrate Cangjie's concurrent processing capabilities into ArkTS applications while maintaining thread safety and performance.
