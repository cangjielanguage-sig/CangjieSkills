This directory contains essential API reference documentation for the `ProtocolType` struct, a fundamental component of the Cangjie programming language's standard library designed for network programming. It focuses on the representation and manipulation of socket protocol types. The included documentation provides a detailed breakdown of the struct's static properties, which define common network protocols like TCP, UDP, ICMP, IPv4, and IPv6, as well as an Unspecified type. Furthermore, it covers the necessary operators for comparing protocol instances and the interfaces the struct conforms to, such as Equatable and Hashable. This directory is highly suitable for systems programmers and backend developers working with the net package who need to implement, configure, or compare network protocols in their Cangjie-based software solutions.
