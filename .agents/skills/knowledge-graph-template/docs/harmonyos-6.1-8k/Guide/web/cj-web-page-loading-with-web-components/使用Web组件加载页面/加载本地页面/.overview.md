# 加载本地页面

本目录主要介绍在 HarmonyOS 应用开发中加载本地页面的不同技术方案。内容涵盖了通过 Web 组件加载本地 HTML 文件（支持 rawfile 和沙箱路径两种方式）以及通过生命周期回调加载应用初始页面的方法。文档涉及 Cangjie 和 ArkTS 两种语言环境，包含代码示例、权限配置及路径获取等关键知识点。适用于需要实现本地 Web 页面展示或应用启动页面加载逻辑的 HarmonyOS 开发者。

- 你想配置应用启动时的初始页面吗？

## 详细描述

### 加载本地页面_1.md
本文档旨在指导开发者如何在应用中加载本地HTML页面文件。文档主要介绍了两种加载方式：通过rawfile目录加载和通过沙箱路径加载。关键内容包括如何引用本地CSS样式、使用Web组件的loadUrl方法、利用GlobalContext单例获取沙箱路径以及开启fileAccess权限。文档提供了完整的Cangjie代码示例，涵盖了从资源文件放置到Ability与UI数据同步的全过程。这适用于使用ArkUI和Cangjie语言进行HarmonyOS应用开发的开发者，帮助他们实现本地Web页面的展示与交互。

### 加载本地页面_2.md
本文档演示了如何通过覆盖窗口阶段生命周期方法在 HarmonyOS 应用中加载本地页面。内容涵盖了 onWindowStageCreate 生命周期回调、WindowStage 对象以及用于指定目标页面路由的 loadContent 方法。代码片段展示了开发者必须覆盖 onWindowStageCreate 并调用 windowStage.loadContent("EntryView") 以在创建应用程序窗口时显示初始 UI。该技术参考或教程片段适用于使用 ArkTS 且需要为其应用程序主 Ability 实现初始页面加载逻辑的 HarmonyOS 开发者。
