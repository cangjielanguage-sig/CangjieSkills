# 组件安全区方案

This directory provides technical documentation for implementing Component Safe Area layouts in HarmonyOS applications using the Cangjie language and ArkUI framework. It focuses on managing the interaction between UI elements and system bars, such as the status bar and navigation bar, to prevent content occlusion and achieve immersive display effects. Key concepts include `expandSafeArea`, `SafeAreaType`, `safeAreaPadding`, and handling scrolling containers. It is suitable for HarmonyOS developers and UI engineers looking to optimize window layouts, maintain visual consistency, and create full-screen user experiences.

## Detailed Description

### 图文场景.md 图文场景.md
This document provides a technical tutorial on implementing immersive layouts for image-text scenarios in HarmonyOS applications using the Cangjie language. It covers the configuration of the expandSafeArea attribute for distinct top and bottom UI elements, specifically addressing scenarios where status bar and navigation bar elements differ. The core solution involves applying expandSafeArea with SafeAreaType.SYSTEM and SafeAreaEdge.TOP to top components, and SafeAreaEdge.BOTTOM to bottom components, demonstrated via a complete code example. This guide targets HarmonyOS developers familiar with declarative UI paradigms and Cangjie syntax who need to manage system safe areas effectively.

### 底部页签场景.md 底部页签场景.md
This technical guide explains how to implement bottom tab bar scenarios where the background extends into the system navigation area while keeping interactive elements accessible. It covers the default behaviors of Navigation and Tabs components, which handle extension automatically when aligned correctly, and custom implementations using the expandSafeArea property. Key takeaways include understanding that standard components simplify this process, while custom layouts require explicit property settings to extend backgrounds into safe areas. The document includes a Cangjie code example demonstrating these concepts. It targets UI developers working with immersive layouts and system safe areas.

### 扩展安全区方案_2more.md 扩展安全区方案_2more.md
This document outlines a technical scheme for extending UI component rendering into non-safe areas like status bars and navigation bars to achieve immersive display effects. It covers the logic of the expandSafeArea property, which expands drawing regions without affecting layout, and the safeAreaPadding attribute for internal spacing. Key takeaways include that components must not use fixed dimensions and that parent components should not clip content. The document provides a Cangjie code example demonstrating background image extension. This guide targets developers implementing immersive interfaces, focusing on layout constraints and system component integration.

### 滚动类场景.md 滚动类场景.md
This technical guide addresses implementing immersive effects for scrolling containers in Cangjie development, specifically where the expandSafeArea attribute fails on child components. The document outlines two primary solutions: setting matching background colors and applying expandSafeArea to the parent scroll container, or using clipContent(ContentClipMode.SAFE_AREA) to extend the content clipping area. Key takeaways include code examples demonstrating Scroll, Column, and SafeAreaType configurations to prevent system bars from obscuring content. This guide is intended for HarmonyOS developers seeking to resolve layout issues in scrollable views.
