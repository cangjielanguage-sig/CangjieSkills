# 应用定义类型

This directory contains reference documentation for application-defined file types, focusing on mapping internal identifiers, MIME types, and file extensions. It covers a wide range of software ecosystems including Microsoft Office, OpenDocument, Adobe, AutoCAD, and various multimedia formats. The documents define how specific applications maintain custom data structures using reverse domain notation IDs. This resource is essential for developers and system architects who need to implement file type recognition, configure system integration, or manage data interaction within a software ecosystem.

### 应用定义类型_1.md
This document serves as a reference guide defining application-defined types, explaining how specific applications or organizations maintain and identify custom data structures. The primary topic covers the definition of these types, emphasizing that data interaction depends on specific application recognition. Key information includes the mandatory identification ID format, which follows reverse domain notation such as `com.company-name.xxx` or `org.orgnization-name.xxx`. The document notes that the system currently includes a predefined list of such types. Intended for developers and system architects, this text helps users understand how to implement and identify custom types within the system ecosystem.
