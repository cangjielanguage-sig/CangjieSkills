# 向用户申请授权

This directory serves as a comprehensive technical resource for implementing runtime user authorization for sensitive system permissions within HarmonyOS applications. It covers the `user_grant` permission model in depth, detailing how to trigger dynamic dialogs, verify authorization results using `checkAccessToken()`, and handle user denials by guiding them to system Settings. The content addresses specific constraints, such as the prohibition of obscuring system dialogs and the critical timing rules regarding UI content loading. It is suitable for application developers integrating privacy-sensitive features such as location or camera access using the Cangjie language, offering both theoretical guidelines and practical implementation steps to ensure compliance and user privacy. By following these guidelines, developers can ensure their applications adhere to privacy standards while providing a seamless user experience.

## Detailed Description

### 向用户申请授权_2more.md 向用户申请授权_2more.md
This guide instructs developers on implementing runtime user authorization for sensitive system permissions, specifically focusing on triggering dynamic dialogs and verifying results. It details the constraints of the user_grant permission model, emphasizing that applications must check permissions every time using checkAccessToken() and request them via requestPermissionsFromUser() before accessing protected interfaces. Key takeaways include the prohibition of obscuring system dialogs, the requirement to guide users to system Settings upon denial, and specific timing rules regarding UI content loading. This technical guide targets application developers integrating privacy-sensitive features like location or camera access.
