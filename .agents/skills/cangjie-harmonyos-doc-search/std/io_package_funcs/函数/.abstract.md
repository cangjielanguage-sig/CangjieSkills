This directory serves as a comprehensive API reference for input/output stream utility functions within the Cangjie standard library. It focuses on essential operations for data transfer, stream manipulation, and content reading. The documentation covers both safe operations that enforce UTF-8 validation and unsafe alternatives for performance or specific data handling needs. Key concepts include stream copying, seekable constraints, byte array conversion, and exception handling for malformed data. This resource is designed for Cangjie developers seeking to implement robust I/O functionality, requiring an understanding of generic types, stream interfaces, and memory safety considerations. The files provide syntax definitions, parameter details, and verified code examples to facilitate correct implementation.
