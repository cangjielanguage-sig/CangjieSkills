# 组件内容模糊

This directory focuses on the implementation of content blur effects for UI components within the ArkUI framework, specifically utilizing the Cangjie programming language. It provides comprehensive resources for applying foreground blur styles, such as the "Thin Material" effect, to enhance visual hierarchy and aesthetics. The content covers practical code examples, detailed API references for the `foregroundBlurStyle` function, and fundamental type definitions for configuring blur parameters like radius, scale, and adaptive color modes. It is suitable for developers working on HarmonyOS applications who seek to integrate sophisticated material design visual effects and depth into their user interfaces.

The documentation outlines the function's signature, system capabilities, and availability starting from version 12. Key takeaways include the required `ForegroundBlurStyle` parameter for defining the blur style and the optional `ForegroundBlurStyleOptions` parameter for additional configuration. This guide is designed for developers utilizing the ArkUI framework who need to implement visual blur effects to enhance their application's user interface.
