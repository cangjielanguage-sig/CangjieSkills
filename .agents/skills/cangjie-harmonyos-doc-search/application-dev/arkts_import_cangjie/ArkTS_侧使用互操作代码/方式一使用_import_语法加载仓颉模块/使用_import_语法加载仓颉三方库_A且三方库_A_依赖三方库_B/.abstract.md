This directory provides a collection of technical guides focused on integrating Cangjie third-party libraries into ArkTS projects using the `import` syntax, specifically addressing complex scenarios where the primary library (Library A) has a dependency on another Cangjie library (Library B). It details multiple implementation strategies, ranging from nested sub-packages to independent HAR module compilation. Key topics include managing cross-language dependencies, configuring build environments like `cjpm.toml` and `oh-package.json5`, and utilizing `JSModule` for interoperability. These resources are tailored for HarmonyOS developers who need to ensure type safety and seamless function exposure when bridging Cangjie and ArkTS code.
