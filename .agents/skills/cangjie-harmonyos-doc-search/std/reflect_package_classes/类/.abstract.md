This directory contains API reference documentation for the Cangjie programming language's reflection system, specifically focusing on type information classes. It covers a wide range of metadata structures, including generic types, parameters, classes, interfaces, structs, and various member types like functions, properties, and variables (static and instance). The documentation enables runtime type inspection, dynamic invocation, and metadata manipulation. It is suitable for Cangjie developers, system architects, and programmers implementing advanced reflection features or dynamic type analysis.
