# class_MethodActionSelectorTRet

This directory provides comprehensive API reference documentation for the `MethodActionSelector<TRet>` class, a critical component of the Cangjie unit testing framework. It is designed to assist developers in configuring stub behaviors for member functions within mock and spy objects. The documentation covers essential concepts such as method chaining, the insertion of stub code via the `@On` macro, and the definition of specific return behaviors. It includes detailed explanations of functions for handling direct values, closure factories, and exception scenarios. Furthermore, it outlines potential exceptions like `IllegalArgumentException` and return types such as `CardinalitySelector`. This resource is suitable for software developers and QA engineers looking to implement precise logic control and verification in their unit tests using the Cangjie language.

## Detailed Description

### class_MethodActionSelector_5more.md
This API reference document details the MethodActionSelector<TRet> class, designed to configure stub behaviors for member functions within the Cangjie unit testing framework. The documentation covers the class definition, its inheritance from ActionSelector, and four primary member functions: callsOriginal, returns (supporting direct values and closure factories), and returnsConsecutively. Key information includes how these methods allow developers to insert stub code via the @On macro and enable method chaining by returning CardinalitySelector or Continuation instances. The document specifies parameters, return types, and potential exceptions like IllegalArgumentException. This technical guide is intended for developers writing unit tests who need to define specific return behaviors or execution logic for mock and spy objects.

### func_returnsConsecutivelyA_3more.md
This API documentation defines functions for configuring stub behaviors in a unit testing framework, specifically focusing on return sequences and exception handling. The content covers the returnsConsecutively function, which allows stubs to return values from a list sequentially, and two overloads of the throws function for triggering exceptions via a factory closure or a direct object. Key information includes parameter requirements, return types like Continuation and CardinalitySelector, and the distinction between testing exception recovery versus test failure. This reference guide targets developers using the Cangjie language to write unit tests with mocking capabilities.
