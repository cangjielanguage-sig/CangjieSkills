# telephony

This directory serves as a comprehensive resource hub for the Telephony Kit, specifically focusing on cellular communication services. It is designed to assist developers in integrating fundamental calling capabilities into their applications, with a primary emphasis on the "Make Call" functionality. The content covers the Beta version of the component, providing essential architectural insights and technical documentation. It is particularly suitable for developers working with the Cangjie language who need to implement voice communication features. By utilizing these resources, developers can efficiently access cellular services, understand system constraints, and build stable, reliable calling applications for mobile environments.

## Detailed Description

### [1] README_zh/
This directory acts as the Chinese documentation entry point for the Telephony Kit (Cellular Communication Service). It provides a detailed overview of the Beta version component, specifically targeting basic communication capabilities within cellular networks. The content centers on the "Make Call" module, serving as a navigation guide for developers building applications with calling features. It thoroughly explains the component's positioning, core functions, and provides links to more detailed documentation. This section is ideal for developers seeking to integrate basic cellular communication, helping them quickly grasp the service architecture and access the technical materials required to implement phone dialing functionalities efficiently.

### [2] cj-telephony-call/
This directory offers a specialized development guide for implementing the "Make Call" function in third-party applications using the Cangjie language. The documentation provides an in-depth look at call status codes, system constraints, and core API interfaces, including voice capability detection and launching the dialer interface. It covers the entire development lifecycle, from module imports to interface invocation, supported by practical code examples. This resource is primarily intended for programmers using the Cangjie language, addressing scenarios where basic calling functionality needs to be seamlessly integrated into an application while adhering to system requirements.
