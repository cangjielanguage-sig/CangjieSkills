# 类

This directory serves as a comprehensive repository for API reference documentation regarding core classes within the Cangjie programming language, specifically targeting JSON data processing. It focuses on the `json.stream` package, providing essential tools for both serialization and deserialization of JSON data via streaming interfaces. The documentation covers the `JsonReader` and `JsonWriter` classes, which are designed for high-performance, low-level data manipulation. By utilizing these classes, developers can avoid loading entire documents into memory, making this resource ideal for handling large JSON payloads, network applications, or scenarios requiring precise control over parsing logic and resource management.

## Detailed Description

### class_JsonReader/

This section provides the API reference documentation for the `JsonReader` class in the Cangjie programming language. It is dedicated to offering robust deserialization capabilities, converting JSON data streams into native Cangjie objects. The documentation comprehensively covers the class's constructors and core parsing methods, including `endArray`, `peek`, and `readName`, alongside stream-based reading functions like `readValue` and `skip`. It explains in detail how to efficiently read, skip, and navigate through JSON data via input streams. The `peek` method allows for lookahead capabilities, while `skip` enables the efficient ignoring of unwanted data segments, which is crucial for parsing complex or partially relevant JSON structures. This guide is particularly suitable for Cangjie developers who require low-level, stream-based JSON parsing and demand fine-grained control over the data reading process to optimize performance.

### class_JsonWriter/

This directory contains the API reference documentation for the `JsonWriter` class in the Cangjie language, focusing on stream-based JSON serialization. It provides a detailed explanation of how to construct JSON structures and write them to output streams efficiently. Key topics include class initialization, configuration options, and structural methods for defining objects and arrays, as well as specific functions for writing values. The documentation also delves into critical concepts such as buffering mechanisms for performance optimization, flush operations, and the implementation of the `JsonSerializable` interface. Understanding the buffering mechanism is key to minimizing I/O operations, thereby enhancing the overall throughput of applications. This resource is essential for developers looking to utilize the `json.stream` package for high-efficiency, low-level JSON encoding and complex data stream operations.
