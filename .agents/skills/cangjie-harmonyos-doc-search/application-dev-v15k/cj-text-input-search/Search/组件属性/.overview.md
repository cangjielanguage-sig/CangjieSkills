# 组件属性

This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework. It focuses on text input, search components, and user interaction customization. Key topics include custom keyboards, text styling (fonts, spacing, colors), input filtering, and search component behaviors like cursor styles and cancel buttons. These documents provide detailed parameter definitions, default values, and behavioral notes for developers. It is suitable for HarmonyOS developers using the Cangjie language who need to fine-tune the appearance and functionality of UI components to enhance user experience.
