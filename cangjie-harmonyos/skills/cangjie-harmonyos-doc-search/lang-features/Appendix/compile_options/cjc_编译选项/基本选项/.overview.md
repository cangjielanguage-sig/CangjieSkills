### --target-cpu_value.md --target-cpu_value.md
这是一份关于编译器选项 --target-cpu 的参考文档，用于指定编译目标的 CPU 类型以启用特定指令集和优化。文档警告该功能为实验性，需配合 --experimental 使用，且会降低二进制可移植性。主要内容包括已测试的 CPU 类型（如 generic、tsv110）以及 x86-64 和 aarch64 架构下大量未经验证的 CPU 列表。此外，文档介绍了 native 参数用于自动检测当前机器 CPU，并指出默认值为 generic 以确保架构内的通用性。该文档面向需要针对特定硬件进行性能优化的开发者。
