This directory contains comprehensive API reference documentation for the `Random` class and associated functions within the Cangjie standard library. It covers the generation of pseudo-random numbers, including integers (signed and unsigned), floating-point values, byte arrays, and Gaussian-distributed numbers. Key topics include class initialization with seeds, method deprecations, parameter constraints, and exception handling. This documentation is suitable for Cangjie developers who need to implement randomization logic, statistical sampling, or custom data generation in their applications, requiring familiarity with basic language syntax and type systems.
