# 应用文件上传下载

This directory provides comprehensive resources for implementing file upload and download operations in HarmonyOS applications using the Cangjie programming language. It covers the essential `ohos.request` module for network transfers and `ohos.file_fs` for local file management. Key topics include configuring download tasks, handling upload restrictions to the application cache directory, and managing necessary permissions such as `ohos.permission.INTERNET`. These guides and code examples are specifically designed for developers seeking to integrate robust network resource management and file transfer capabilities into their Cangjie-based projects.

## Detailed Description

### 下载网络资源文件至应用文件目录.md 下载网络资源文件至应用文件目录.md
This tutorial guides HarmonyOS developers on downloading network resources to an application's file directory using the Cangjie language. It covers the usage of the `ohos.request` module for download tasks and `ohos.file_fs` for subsequent file access. Key information includes the requirement for the `ohos.permission.INTERNET` permission and a detailed code example demonstrating how to configure download parameters, handle response callbacks, and manage file operations like checking existence and deletion. The document targets developers building applications that require network resource management within the HarmonyOS ecosystem.

### 应用文件上传下载_2more.md 应用文件上传下载_2more.md
This technical guide explains how to implement file upload and download functionality for applications using the ohos.request module. It covers the prerequisites, specifically the Beta status and permission requirements (ohos.permission.INTERNET), and details the file upload process. The document highlights that uploads are currently restricted to the application cache directory (cacheDir). It provides a comprehensive Cangjie code example demonstrating file creation, upload configuration (Config, FileSpec), task creation, and progress event handling. This is intended for HarmonyOS application developers using the Cangjie programming language who need to manage network file transfers.

### 示例代码.md 示例代码.md
This document serves as a gateway to downloadable example code demonstrating file download functionality within the OpenHarmony ecosystem using the Cangjie programming language. The content primarily consists of a direct link to a Git repository containing the source code for the FileDownload feature under the BasicFeature and Connectivity categories. It provides developers with practical implementation references for handling network connectivity and file management tasks in Cangjie applications. The target audience includes OpenHarmony developers seeking to understand or integrate file downloading capabilities into their Cangjie-based projects.
