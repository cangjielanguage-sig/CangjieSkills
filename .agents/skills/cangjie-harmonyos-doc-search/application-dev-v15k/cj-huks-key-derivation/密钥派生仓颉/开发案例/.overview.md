# 开发案例

This directory serves as a specialized collection of development examples and technical documentation focused on implementing cryptographic key derivation functions within the HarmonyOS ecosystem. It provides in-depth resources for utilizing the HarmonyOS Universal Keystore (HUKS) framework to secure applications through robust key management practices. The content primarily covers the implementation of HKDF (HMAC-based Extract-and-Expand) and PBKDF2 algorithms, offering practical code patterns in ArkTS and Cangjie. Developers will find guidance on critical security operations, including parameter configuration, session management, and key lifecycle handling. By following these examples, users can understand the nuances of generating source keys, initializing derivation sessions, and managing salts and iteration counts effectively. This directory is essential for software developers and security engineers who need to integrate high-standard cryptographic storage and derivation mechanisms into their HarmonyOS applications, ensuring data protection and compliance with security best practices.

## Detailed Description

The following subdirectories contain specific technical guides and code examples for implementing key derivation functions in HarmonyOS. These resources are designed to bridge the gap between theoretical cryptographic concepts and practical application code.

### HKDF/

This directory provides technical documentation and code examples for implementing HMAC-based Extract-and-Expand Key Derivation Function (HKDF) within the HarmonyOS Universal Keystore (HUKS) framework. It covers the essential cryptographic processes required to derive secure keys from existing secrets, including configuration of parameter sets, session management, and key lifecycle operations. The examples demonstrate how to generate source keys, initialize derivation sessions, and finalize them to produce derived keys using specific algorithms like AES and SHA-256. This content is suitable for developers proficient in ArkTS or Cangjie who are building secure applications requiring robust key management and cryptographic capabilities.

### PBKDF2/

This directory provides comprehensive technical resources for implementing PBKDF2 key derivation within the HarmonyOS ecosystem, specifically utilizing the Cangjie programming language and the UniversalKeystoreKit (HUKS). It covers the end-to-end cryptographic process, from initial key generation and parameter configuration to session management and final key deletion. Key topics include setting up HuksParam arrays for algorithms like AES and SHA256, managing derivation parameters such as salts and iteration counts, and implementing robust error handling. These materials are designed for software developers and security engineers seeking to integrate secure key storage and cryptographic operations into HarmonyOS applications, offering both theoretical guidance and practical code patterns.
