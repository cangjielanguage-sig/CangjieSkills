This directory contains comprehensive API reference documentation for the `NotificationContent` class within the Cangjie language framework. It focuses on defining the structure, data types, and configuration of system notification content. Key topics include various notification formats such as basic text, long text, multi-line, and picture support, as well as specific system capabilities and version requirements. Additionally, it covers constructor functions for instantiating these objects with optional parameters. This documentation is specifically designed for developers working in this ecosystem who need to programmatically implement, manage, or update system notification features in their applications.
