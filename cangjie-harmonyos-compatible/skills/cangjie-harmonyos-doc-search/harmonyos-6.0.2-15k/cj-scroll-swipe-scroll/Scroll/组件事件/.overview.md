# 组件事件

This directory provides comprehensive API reference documentation for scroll-related event callbacks within the Cangjie ArkUI framework. It covers the full lifecycle of scrolling events, ranging from pre-scroll interception to post-scroll state monitoring and edge detection. Key topics include handling user inputs, API controller calls, boundary bouncing effects, and frame-by-frame offset calculations. The documentation details specific functions such as `onDidScroll`, `onWillScroll`, `onScrollFrameBegin`, and various edge detection methods. This resource is essential for software developers and UI engineers building interactive applications who require precise control over scroll behaviors and event handling logic using the Cangjie language.

### func_onWillScrollFloat64Fl_2more.md
This API documentation details the onWillScroll function for the ArkUI framework, which registers a callback triggered before a Scroll component performs a scrolling action. The document covers two function overloads: one returning OffsetResult to modify scroll behavior and another returning Unit for observation only. It details trigger conditions, system capabilities, and parameter definitions including offsets, state, and source. Key information includes that the callback provides calculated horizontal and vertical offsets in vp, current scroll state, and operation source. Developers can intercept or monitor scroll events triggered by user input, API calls, or boundary rebounds. This reference guide targets ArkUI developers using the Cangjie language who need to implement custom scroll logic or event tracking.
