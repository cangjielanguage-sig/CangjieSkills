This directory serves as a comprehensive resource for developers working with the Cangjie programming language, specifically focusing on the integration and usage of standard extension libraries (stdx). It provides essential technical guidance on compiling programs that rely on complex dependencies such as crypto, encoding, and networking modules. The content covers critical aspects of the development workflow, including environment variable configuration, the setup of the `cjc` compiler and `cjpm` build tool, and the management of static and dynamic binary artifacts. Furthermore, it addresses OS-specific linking requirements for Linux, macOS, and Windows. This documentation is primarily suitable for Cangjie developers seeking to streamline their build processes and resolve dependency linking issues in projects utilizing the stdx ecosystem.
