# cj-common-pixelunits

本目录提供了仓颉ArkUI框架中像素单位系统的核心参考文档。内容涵盖了物理像素、屏幕密度相关像素、字体像素和视窗逻辑像素等四种主要单位的详细定义与区别。文档重点介绍了vp作为默认基准单位的重要性，并提供了基于UIContext实例的单位转换API使用指南及示例代码。该资源专为仓颉开发者设计，旨在帮助开发者深入理解不同像素单位的应用场景，从而在UI布局开发中实现精准的屏幕适配和响应式设计，确保应用在不同设备上的一致性体验。

## Detailed Description

### cj-common-pixelunits.md
本文档旨在介绍仓颉ArkUI框架中的像素单位系统。文档主要包含四种像素单位的定义说明、单位转换API的使用方法以及示例代码演示。关键信息详细阐述了物理像素、屏幕密度相关像素、字体像素和视窗逻辑像素的区别，明确了vp为默认基准单位，并展示了如何利用UIContext实例进行单位间的相互转换。这是一份面向仓颉开发者的参考指南，帮助开发者在UI布局中正确应用不同像素单位以适配不同屏幕。
