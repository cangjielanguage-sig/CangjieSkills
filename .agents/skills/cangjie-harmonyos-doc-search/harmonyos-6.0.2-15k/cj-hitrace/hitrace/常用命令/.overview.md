# 常用命令

This directory acts as a centralized technical hub for the `hitrace` command-line utility, which is indispensable for performing deep performance analysis within the HarmonyOS and OpenHarmony operating environments. It offers extensive reference documentation aimed at helping users proficiently capture, manage, and export system trace data through the command line interface. The guides thoroughly explain essential procedures such as enumerating trace tags, controlling recording sessions, and fine-tuning capture parameters like buffer size and time limits. Beyond basic tracing, the content delves into sophisticated functionalities including snapshot mode for background tasks, output compression, and clock synchronization settings. This collection is ideally suited for system developers, QA engineers, and performance specialists who need granular diagnostic capabilities to monitor system health and enhance application efficiency.

## Detailed Description

### 常用命令_1.md 常用命令_1.md
This document serves as a technical reference guide for using the `hitrace` command within the `hdc shell` environment to capture system performance traces. It covers listing available trace tags, initiating and terminating trace recording sessions, and configuring capture parameters such as buffer size, duration, and output file paths. Key information includes how to filter traces by specific system modules like app or ability, and how to export results to designated files using flags like `-b`, `-t`, and `-o`. The guide targets developers or QA engineers familiar with command-line interfaces who need to analyze system behavior and performance in HarmonyOS.

### 常用命令_2.md 常用命令_2.md
This document serves as a command reference guide for the hitrace tool, detailing methods to capture, manage, and export system trace data. It covers key operations including dumping trace data to the console or specific files, managing snapshot mode for background recording, compressing trace output, and configuring trace clocks. Key takeaways include the use of specific flags like -o for output paths and -z for compression, alongside references to the HiSmartPerf tool for visualization. This guide is intended for system developers and performance engineers analyzing OpenHarmony system behavior.
