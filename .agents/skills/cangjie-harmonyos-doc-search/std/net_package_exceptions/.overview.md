### net_package_exceptions.md net_package_exceptions.md

This document serves as the primary API reference documentation for exception classes within the net package, specifically handling socket-related errors in the Cangjie programming language. It provides a technical deep dive into the architecture of network error handling, detailing two primary classes that developers will encounter.

The first class covered is `SocketException`, which inherits from `IOException`. This class is designed to manage general socket errors, placing them within the broader context of input/output exceptions. The second class is `SocketTimeoutException`, which inherits from the base `Exception` class. This class is specifically tailored for timeout scenarios, allowing for distinct handling logic when operations exceed their time limits.

Both classes are documented with their respective constructors, offering the flexibility to create instances either with default settings or by passing custom error messages. This feature is critical for debugging and logging, as it allows developers to attach specific context to exceptions. The key takeaway is the structural definition of these exceptions, including their inheritance hierarchy and initialization methods. By understanding these definitions, developers can instantiate these exceptions using a default constructor or by passing a specific string message to describe the error. This reference is intended for Cangjie developers working on network programming who need to handle socket errors and timeouts gracefully, ensuring their software can respond predictably to network instability.
