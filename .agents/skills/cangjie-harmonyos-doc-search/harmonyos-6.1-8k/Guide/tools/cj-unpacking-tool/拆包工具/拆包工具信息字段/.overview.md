# 拆包工具信息字段

## 详细说明

### AbilityFormInfo结构体信息.md AbilityFormInfo结构体信息.md
本文档定义了AbilityFormInfo结构体，用于配置应用卡片的属性与行为。涵盖卡片标识、定时刷新、外观规格、UI路径及提供方Ability配置等字段。关键信息包括刷新频率单位、尺寸支持、色调模式及FA与Stage模型下providerAbility的配置差异。这是一份面向开发者的API参考文档，用于指导卡片功能的开发配置。

### AbilityInfo结构体信息.md AbilityInfo结构体信息.md
本文档详细定义了AbilityInfo结构体的字段属性，是应用开发中的API参考文档。内容涵盖基础标识、配置类型、权限管理、资源引用及多语言支持等核心字段。关键信息包括Stage与FA模型的区分、卡片使能状态、画中画模式支持及多用户共享配置。该文档面向开发人员，旨在辅助其准确配置Ability组件的元数据与行为特性。

### AppInfo结构体信息.md AppInfo结构体信息.md
本文档详细定义了AppInfo结构体的字段属性，用于描述应用程序的元数据信息。主要涵盖应用基础标识（如包名、版本号）、API兼容性配置、UI资源（图标、标签）、构建配置（调试模式、SDK版本）以及多语言支持等字段。关键信息包括区分应用、原子化服务和共享库的bundleType，Stage模型新增的分布式通知及描述字段，以及仅限API10及以后使用的编译SDK版本配置。这是一份面向开发者的API参考文档，适用于应用开发、配置解析及系统框架集成场景。

### CommonEvent结构体信息_6more_d69b0e9c.md CommonEvent结构体信息_6more_d69b0e9c.md
本文档是一份技术参考文档，详细定义了应用程序配置中涉及的关键数据结构及其字段属性。主要涵盖了CommonEvent（静态公共事件）、DependencyItem（共享包依赖）、ModuleAtomicService与PreloadItem（预加载配置）、DeviceConfig（设备与SDK配置）以及DefPermission（自定义权限）六个结构体。文档通过表格形式列出了各字段的类型、描述和备注，重点说明了Stage模型下的静态订阅者配置、Ark版本兼容性、分布式通知开关及多语言权限标签等核心概念。

### DefinePermission结_5more_b84faac8.md DefinePermission结_5more_b84faac8.md
本文档旨在定义应用权限配置、表单信息及模块元数据相关的数据结构规范。主要涵盖DefinePermission权限结构、DefPermissionsGroups权限组、FormInfo表单尺寸、ModuleMetadataInfo元数据及ModuleWindowInfo窗口设计配置。关键信息包括权限的证书申请与分布式场景支持、多语言标签描述、表单的最小与默认尺寸设置，以及模块窗口的设计宽度配置。面向应用开发人员或系统架构师，用于配置应用模块权限、界面布局及元数据属性。

### Distro结构体信息_7more_48d82a38.md Distro结构体信息_7more_48d82a38.md
本文档详细定义了应用配置相关的数据结构，包括Distro、MetaData、权限及快捷方式等，主要用于HarmonyOS/OpenHarmony开发中的模块和元能力配置。主要涵盖Distro结构体（模块分发信息）、MetaData及CustomizeData（元数据）、ReqPermission及UsedScene（权限申请与使用场景）、以及Shortcut（快捷方式）结构体的字段定义。关键信息包括区分FA模型与Stage模型的字段差异（如FA模型特有字段在Stage中废弃），installationFree字段的返回值逻辑，以及权限使用场景（inuse/always）的配置方式。

### ExtensionAbilityI_3more_f575d12c.md ExtensionAbilityI_3more_f575d12c.md
本文档是关于HarmonyOS应用开发中ExtensionAbility相关数据结构的API参考文档。主要包含ExtensionAbilityInfo、SkillInfo和UriInfo三个结构体的详细字段定义。ExtensionAbilityInfo涵盖了名称、类型（如form、workScheduler）、权限及元数据等配置，并注明了Stage模型支持情况及部分类型的解析状态；SkillInfo定义了意图接收特征；UriInfo描述了URI的范式、路径等配置。面向HarmonyOS应用开发者，用于理解和配置ExtensionAbility的元数据及能力信息。

### HapInfo结构体信息.md HapInfo结构体信息.md
本文档详细定义了HarmonyOS开发中HapInfo结构体的字段组成及其属性，用于描述HAP包的配置信息。内容涵盖应用模型标识（FA/Stage）、包信息、Ability配置、权限集合、元数据、依赖项及文件大小等核心字段，并明确区分了FA模型与Stage模型的特有属性。关键信息包括区分FA与Stage模型的不同字段（如FA的packageStr与Stage的srcEntrance），以及HAP包的压缩与原始大小统计。该文档属于API参考手册，主要面向HarmonyOS应用开发者，用于理解HAP包的内部结构和解析应用配置。

### IntentInfo结构体信息_7more_9174a65e.md IntentInfo结构体信息_7more_9174a65e.md
本文档定义了IntentInfo和DistroFilter等数据结构，用于规范快捷方式信息及分发过滤条件。主要涵盖IntentInfo（目标类与包名）及DistroFilter的子结构体，包括ApiVersion、ScreenShape、ScreenDensity等。核心要点是所有过滤子结构体均采用统一模式，包含policy和value字段，用于基于设备属性控制分发。这是一份API参考文档，面向负责应用分发或快捷方式配置的开发人员，提供了实现系统集成所需的数据结构规范。

### UncompressResultB_3more_90f84931.md UncompressResultB_3more_90f84931.md
本文档定义了Bundle解压结果相关的数据结构，详细说明了UncompressResult、PackInfo和ProfileInfo三个结构体的字段组成及含义。主要内容包括UncompressResult结构体（包含解析状态、包大小、图标等）、PackInfo结构体（包含包名、HAP名称、设备类型等）以及ProfileInfo结构体（包含HAP名称、AppInfo、设备配置等）。关键信息涵盖了解析成功与否的标识、应用包大小、HAP包支持的设备类型、安装交付方式以及应用配置信息的存储结构（如Map形式的DeviceConfig）。
