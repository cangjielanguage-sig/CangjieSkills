# 使用场景

This directory outlines various usage scenarios for implementing and managing ad filtering within applications using the ArkWeb framework and HarmonyOS. It covers essential functionalities such as enabling ad blocking with custom rules, collecting statistics on blocked ads, and managing granular control over specific domains through allowlists and disallowlists. Key topics include the `AdsBlockManager` API, event handling via `onAdsBlocked`, and domain matching logic. These resources are designed for application developers seeking to integrate robust ad-blocking capabilities, customize filtering rules, and optimize user experience by exempting specific websites from filtering.

## Detailed Description

### 开启广告过滤.md 开启广告过滤.md
This technical guide explains how to implement ad filtering functionality in an application using ArkWeb components and Cangjie code. It covers the API usage of `AdsBlockManager.setAdsBlockRules()` and `Web.enableAdsBlock()`, provides a complete code example for selecting rule files via a document picker, and details the behavior of the replace parameter. Key takeaways include that custom easylist rules are applied globally across the application process and persist after restart. The replace parameter determines whether custom rules override or supplement built-in rules. This guide targets application developers working with the ArkWeb framework who need to integrate ad blocking capabilities.

### 收集广告过滤的信息.md 收集广告过滤的信息.md
This technical guide explains how to implement and handle ad blocking notifications within the ArkUI Web component using the Cangjie language. The document covers the usage of the `onAdsBlocked` callback interface and provides a code example demonstrating state management and event handling. Key information includes the specific notification logic, where the system reports first upon page load completion and subsequently at one-second intervals to minimize performance impact. It highlights accessing blocked ad counts and URLs from the callback details. This guide is intended for application developers working with web views who need to track and collect statistics on filtered advertisements.

### 关闭特定域名页面的广告过滤/
This directory provides comprehensive technical resources for developers looking to implement granular control over ad filtering in Web components. It focuses on the mechanisms required to disable ad blocking for specific domain pages using the `AdsBlockManager`. Key topics include the configuration of allowlists and disallowlists, the logic behind domain suffix matching, and the priority rules governing these lists (e.g., AllowList overriding DisallowedList). The documentation covers implementation in both the ArkWeb framework (using Cangjie) and HarmonyOS (using ArkTS), highlighting differences in persistence and setup requirements. It is suitable for application developers who need to manage complex ad filtering scenarios, such as exempting parent domains while blocking ads on subdomains, ensuring a tailored browsing experience within their applications.
