# Development Cases

This directory serves as a comprehensive collection of development cases focused on cryptographic security within the HarmonyOS ecosystem. It specifically targets developers implementing advanced key derivation algorithms using the Cangjie programming language and the Harmony Universal KeyStore (HUKS). The content provides practical guidance on utilizing HKDF and PBKDF2 standards to secure application data. By covering the full lifecycle of cryptographic keys—from generation and derivation to destruction—this resource addresses critical security requirements. It is designed for software engineers and security architects looking to integrate robust, standards-compliant encryption mechanisms into their HarmonyOS applications, ensuring data protection through proper key management practices.

## Detailed Description

### HKDF/

This directory provides in-depth documentation and code examples for implementing the HKDF (HMAC-based Extract-and-Expand Key Derivation Function) within the HarmonyOS environment. The examples are written using the Cangjie language and leverage the HUKS (Harmony Universal KeyStore) framework. The content comprehensively covers the entire lifecycle of key derivation operations. This includes detailed instructions on parameter configuration, managing cryptographic sessions, and the secure generation and destruction of keys. Additionally, it addresses error handling mechanisms to ensure stability. Key technical concepts covered include HKDF, HUKS integration, AES encryption standards, SHA256 hashing, and Cangjie programming syntax. This section is essential for developers requiring a secure method to derive keys from a master secret in their HarmonyOS applications.

### PBKDF2/

This directory focuses on the implementation of the PBKDF2 (Password-Based Key Derivation Function 2) algorithm, utilizing the Cangjie language and HUKS interfaces. The documentation guides developers through the complexities of defining key parameters and executing the three-stage derivation process: initialization, update, and completion. It emphasizes the complete lifecycle management of keys to maintain security integrity. Critical technical elements discussed include configuring the AES algorithm, utilizing SHA256 for message digests, handling salt values to prevent rainbow table attacks, and setting appropriate iteration counts to enhance security. These resources are invaluable for developers aiming to build secure key derivation solutions in HarmonyOS, providing the necessary foundation to protect sensitive user data with strong password-based encryption.
