# struct_JSValue

This directory contains API reference documentation for the `JSValue` struct in the Cangjie programming language, designed for HarmonyOS ArkUI development. It covers the essential functionalities for interoperability between Cangjie and ArkTS, including type checking, type conversion, object manipulation, and data binding. The documentation details methods for handling weak-typed variables within the ArkTS runtime, managing object lifecycles, and performing operations on arrays and objects. It is suitable for developers working on cross-language applications who need to manipulate JavaScript data types safely and efficiently using the Napi module.
