This directory serves as a comprehensive resource for implementing single-hand gestures within the Cangjie UI framework, specifically tailored for the HarmonyOS ecosystem. It provides in-depth coverage of essential interaction patterns, including dragging, pinching, swiping, tapping, and long-pressing. The content is designed to help developers master API references, parameter configurations, and the practical application of binding gestures to standard components such as Text and Column. Furthermore, it tackles complex scenarios like gesture competition and conflict resolution to ensure smooth user experiences. This collection is ideal for Cangjie and HarmonyOS developers who possess a foundational understanding of UI components and state management and are looking to enhance their applications with rich, interactive user interfaces.
