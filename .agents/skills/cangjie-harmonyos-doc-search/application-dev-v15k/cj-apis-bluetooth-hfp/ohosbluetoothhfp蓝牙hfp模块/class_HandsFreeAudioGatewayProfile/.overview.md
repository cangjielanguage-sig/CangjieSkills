# class_HandsFreeAudioGatewayProfile

This directory contains API reference documentation for the `HandsFreeAudioGatewayProfile` class in the Cangjie language, specifically designed for HarmonyOS Bluetooth connectivity. It focuses on managing Hands-Free Audio Gateway (HAG) connections, enabling developers to retrieve connected devices, check connection states, and monitor connection state changes through event subscriptions. Key topics include device management, event listeners (`on`/`off`), and permission handling (`ohos.permission.ACCESS_BLUETOOTH`). This documentation is suitable for HarmonyOS developers working on Bluetooth subsystems who need to implement or manage audio gateway functionalities in their applications.
