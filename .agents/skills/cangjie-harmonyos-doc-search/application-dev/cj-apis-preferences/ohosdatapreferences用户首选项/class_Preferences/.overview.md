# class_Preferences

This directory provides API reference documentation for the Cangjie Preferences class within the ArkData framework, designed for managing lightweight application preference data storage. It covers the complete lifecycle of preferences, including instance creation, retrieval, deletion, and data persistence operations like reading, writing, and clearing key-value pairs. Additionally, it details event subscription mechanisms for monitoring data changes. This documentation is intended for HarmonyOS developers using the Cangjie language who need to implement efficient local data storage and ensure data consistency in their applications.

## Detailed Description

### class_Preferences_2more.md class_Preferences_2more.md
This document details the Cangjie Preferences class API, focusing on the static method `deletePreferences` to remove specific preference instances from memory and persistent storage. It covers function signatures, parameters (UIAbilityContext, name), system capabilities, and business exceptions. The guide emphasizes avoiding concurrent calls and discarding old instances post-deletion to ensure data consistency, including code examples for retrieval and deletion.

### func_clear_3more.md func_clear_3more.md
This reference details data management functions: `clear()` to remove all data, `delete(String)` for specific key-value pairs, and `flush()` to persist cached changes. It highlights that modifications occur in memory and require `flush()` for persistence in XML mode. The content covers system capabilities, version 22 requirements, and exception handling for developers managing local preferences.

### func_getString_Preferences_2more.md func_getString_Preferences_2more.md
This document details data retrieval methods, specifically `get` and `getAll`. The `get` function retrieves a value by key with a default return for missing keys or type mismatches, supporting Int64, Float64, and String. The `getAll` function returns a HashMap of all pairs. It includes parameter descriptions, return types, and exception handling with Cangjie code examples.

### func_hasString_2more.md func_hasString_2more.md
This reference details the `has` and `off` functions. The `has` method checks for a specific storage key, while `off` unsubscribes from data change events. It covers function signatures, parameters (key, event), return types, and potential errors. Code examples demonstrate context retrieval, key checking, and event listener management for HarmonyOS developers.

### func_onPreferencesEvent_Callback1ArgumentString.md func_onPreferencesEvent_Callback1ArgumentString.md

Key takeaways include the requirement to execute `flush` to trigger callbacks and handling business exceptions, with a code example for implementing the callback interface.

### static_func_getPreferences_2more.md static_func_getPreferences_2more.md
This document details static methods for managing Preferences instances: `getPreferences` for retrieving instances (with caching) and `removePreferencesFromCache` for clearing memory cache. It explains that `getPreferences` caches for performance, while `removePreferencesFromCache` forces a reload, warning that using old instances after removal risks data inconsistency.

### static_func_removePreferencesFromCacheUIA_66575b52.md static_func_removePreferencesFromCacheUIA_66575b52.md
This reference details the static function `removePreferencesFromCache` to remove specific instances from the application cache. It explains that removing the cache forces subsequent `getPreferences` calls to reload data from persistent files. It warns that using the old instance after removal causes data consistency issues and lists specific error codes for stage mode.
