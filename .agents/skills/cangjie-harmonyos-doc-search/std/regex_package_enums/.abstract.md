This directory serves as the central repository for API reference documentation regarding the `regex_package_enums` module, specifically focusing on the `RegexFlag` enumeration within the Cangjie regex package. It provides a comprehensive overview of the flags used to control and fine-tune regular expression matching behavior. The content details the `RegexFlag` enum and its three distinct members: `IgnoreCase`, `MultiLine`, and `Unicode`. Each member is explained with functional descriptions and code snippets, illustrating how developers can modify regex execution to enable case insensitivity, manage multi-line string inputs, or ensure robust Unicode character support. This documentation is intended for Cangjie developers who are actively implementing regular expressions and need to customize matching modes for specific application requirements. Prerequisites for this material include a solid familiarity with Cangjie syntax and a basic understanding of regular expression concepts.
