# cj-anm-tool

The `cj-anm-tool` directory contains the essential documentation for the Advanced Notification Manager (ANM), a specialized command-line utility developed for software engineers. This tool is designed to assist in the intricate processes of debugging and testing notification functionalities within a controlled environment. The provided guide covers a wide array of topics, including the necessary environment prerequisites, a comprehensive command overview, and step-by-step usage instructions for key operations such as help, dump, and setting. It empowers developers to print and analyze active, recent, or distributed notifications, as well as configure critical system parameters like cache limits and enable switches. Because the tool requires the hdc shell and is strictly restricted to engineering (eng) versions, it is tailored specifically for developers who need granular control and visibility over notification states to ensure robust software performance during the testing lifecycle.
