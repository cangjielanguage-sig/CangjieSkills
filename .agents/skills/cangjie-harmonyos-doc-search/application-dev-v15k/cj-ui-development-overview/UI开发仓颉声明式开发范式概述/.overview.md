## Detailed Description

### UI开发仓颉声明式开发范式概述.md
This document provides a comprehensive overview of the ArkUI framework based on the Cangjie declarative development paradigm for building cross-device UIs. It details core capabilities including the Cangjie language's state management features, various layout types, system and custom components, page routing, graphics, and animation systems. Additionally, it covers interaction events like gestures and custom UI extension capabilities. Key takeaways include the framework's focus on high performance and simplified development through decorators that manage data and UI synchronization. This guide serves as an introductory reference for application developers using Cangjie to understand the fundamental structure and features of the ArkUI development environment.

### 特点.md
This document outlines the core features and advantages of a declarative UI framework. It covers three main topics: high development efficiency, superior performance, and rapid ecosystem growth. Key information includes the use of data-driven UI to simplify business logic, a C++ backend for rendering, and compiler optimizations like AOT and FFI. The document highlights how the framework leverages mainstream language ecosystems for evolution. This reference material targets developers and technical decision-makers evaluating the framework's capabilities and architectural benefits.

### 通用规则.md
This reference document establishes standard conventions for parameter handling within the ArkUI development framework. It covers two primary topics: default measurement units and protocols for managing invalid input values. Key takeaways include that length parameters default to virtual pixels (vp) for Int32, Int64, and Float64 types. Furthermore, the document specifies that when invalid values are passed, the system applies a default value if one is defined; otherwise, the specific attribute or interface fails to activate. This guide targets software developers and UI engineers building applications, requiring knowledge of basic data types and interface implementation. Keywords: ArkUI, default units, vp, exception handling, API reference.
