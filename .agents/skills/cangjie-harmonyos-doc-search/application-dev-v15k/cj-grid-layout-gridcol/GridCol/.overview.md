# GridCol

This directory contains comprehensive documentation for the GridCol component within the Cangjie ArkUI framework, designed for building responsive grid layouts in HarmonyOS applications. It covers API references, type definitions, and practical code examples for configuring column spanning, offsets, and ordering. Key topics include the `GridColColumnOption` struct for breakpoint-based responsiveness and integration with GridRow. This resource is suitable for developers and UI engineers seeking granular control over adaptive user interfaces using the Cangjie language.

## Detailed Description

### GridCol_4more.md GridCol_4more.md
This document provides API reference documentation for the GridCol component in the Cangjie language, designed for use within the ArkUI framework's grid layout system. It details component creation via two initialization methods, subcomponent rules, and supported universal attributes and events. Key parameters include span for defining column occupancy, offset for positioning, and order for sorting. Notably, a span of 0 prevents rendering. The component supports both integer and GridColColumnOption types for configuration. This reference guide targets developers building responsive layouts in HarmonyOS applications using Cangjie.

### 基础类型定义.md 基础类型定义.md
This API reference document defines the GridColColumnOption struct for configuring responsive grid layouts in the Cangjie ArkUI framework. The content focuses on the struct's constructor, which accepts named integer parameters for six device breakpoints (xs, sm, md, lg, xl, xxl) to specify column spans or offsets. Key information includes the default value of 12 for all parameters and the inheritance mechanism where unset breakpoint values cascade from the previous defined breakpoint. This documentation is intended for developers utilizing SystemCapability.ArkUI.ArkUI.Full to build adaptive user interfaces across different screen sizes.

### 示例代码.md 示例代码.md
This document provides practical Cangjie code examples demonstrating the usage of the GridCol component within a grid layout system. The code illustrates how to nest GridCol inside GridRow, configure column spanning and offsets, and dynamically render items using ForEach. It also references integration with GridRow for complete layout implementation. This tutorial is intended for developers using the Cangjie UI framework to build responsive grid interfaces.
