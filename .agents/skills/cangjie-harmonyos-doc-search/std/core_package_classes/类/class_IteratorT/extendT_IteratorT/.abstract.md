This directory contains comprehensive API reference documentation for extending the Iterator type in the Cangjie programming language. It covers a wide range of functional-style operations for data sequence manipulation, including intermediate operations like `map`, `filter`, and `flatMap`, as well as terminal operations like `reduce`, `count`, and `fold`. The documentation details method signatures, parameters, return values, and includes verified code examples. It is suitable for Cangjie developers looking to perform complex data transformations, control iteration flow, and manage collection traversals efficiently.
