# 页面转场动画不推荐

This directory provides technical documentation and code examples for implementing custom page transition animations in Cangjie (HarmonyOS), specifically focusing on the `pageTransition` function. While the directory title indicates this approach is not recommended in favor of Navigation or Modal transitions, the content covers detailed configurations for RouteType (None, Push, Pop), disabling transitions, and custom animation properties like slide and opacity. It serves as a reference for developers who need granular control over routing behaviors or maintain legacy code. The resources are suitable for Cangjie developers and UI engineers working within the ArkUI framework.
