This directory contains technical specifications and API references for asymmetric key encryption and decryption algorithms within the Cangjie programming language framework. It covers standards like GM/T 0009-2012 (SM2) and RSA implementations, detailing encryption modes, padding schemes, and parameter configurations. The documentation is currently in Beta status and is designed for developers and security engineers who need to implement secure cryptographic operations, manage key types, and handle ciphertext formats in Cangjie applications.

## Detailed Description

### SM2.md SM2.md
This document serves as API reference documentation for implementing the SM2 asymmetric encryption algorithm within the Cangjie framework, adhering to the GM/T 0009-2012 standard. It covers the algorithm's ciphertext structure (C1, C2, C3), string parameter configuration for key types and digest algorithms, and API version 12+ features for retrieving digest parameters and converting ciphertext formats. Key takeaways include the requirement to construct string parameters like "SM2_256|MD5" to specify encryption specs and the support for ASN.1 format conversion (C1C3C2) involving parameters such as xCoordinate and hashData. This guide targets developers working with cryptographic operations in Cangjie who need to perform SM2 encryption, decryption, and format manipulation.
