This directory contains comprehensive API reference documentation for the `ohos.i18n` module within the Cangjie LocalizationKit, designed to facilitate internationalization (I18n) in HarmonyOS applications. It covers a wide range of functionalities including text segmentation, entity recognition, phone number formatting, holiday management, and timezone handling. The resources provide detailed class definitions, method signatures, and usage examples for developers implementing global features. Suitable for Cangjie developers, this documentation ensures robust support for multi-language text processing, locale-specific data formatting, and system localization settings.
