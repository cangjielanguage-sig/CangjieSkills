# cj-account-password-update

This directory provides a technical guide for implementing account password update functionality within a password vault system using the Cangjie language. It covers update trigger logic, UI behavior, and provides code examples for a "Change Password" page. Key topics include using `InputType.NEW_PASSWORD` to trigger strong password generation and managing the `enableAutoFill` state to control credential saving. This resource is designed for application developers integrating auto-fill services who possess knowledge of Cangjie and UI component development. It serves as a practical reference for ensuring secure and user-friendly password management workflows.
