# cj-photoAccessHelper-savebutton

This directory provides a specialized technical tutorial for HarmonyOS developers utilizing the Cangjie programming language. It focuses on the critical functionality of saving user-generated files, specifically images and videos, to the device's system media library. The content covers essential implementation details, including the necessary `ohos.permission.WRITE_IMAGEVIDEO` permission and the use of a dialog authorization method to ensure secure access. The guide systematically breaks down the development process into four clear steps: defining the source application sandbox URI, setting up photo creation options, calling the `showAssetsCreationDialog` API to secure the destination URI, and performing the actual file copy using `CoreFileKit`. This resource is highly suitable for developers looking to implement robust media saving features, provided they have prior experience with Cangjie syntax, file management concepts, and the MediaLibraryKit. By following this guide, developers can ensure their applications handle media persistence efficiently and in compliance with system security protocols.

## Detailed Description

### cj-photoAccessHelper-savebutton.md

This document serves as a comprehensive tutorial for developers aiming to implement file saving capabilities within their HarmonyOS applications using the Cangjie language. Specifically, it addresses the requirement to save user files, such as images and videos, directly to the system media library. The tutorial begins by establishing the necessary security prerequisites, notably the `ohos.permission.WRITE_IMAGEVIDEO` permission, and explains the implementation of a dialog-based authorization method to comply with user privacy standards.

The core of the document is a structured guide divided into four distinct development steps:
1.  **Source URI Specification:** Instructs developers on how to correctly specify the source application sandbox URI.
2.  **Option Configuration:** Details the configuration of photo creation options to ensure metadata and file types are handled correctly.
3.  **API Invocation:** Demonstrates how to invoke the `showAssetsCreationDialog` API to successfully obtain the destination URI required for the save operation.
4.  **File Copying:** Covers the technical execution of copying file content using the `CoreFileKit`.

This guide is targeted at HarmonyOS application developers and assumes a working knowledge of Cangjie syntax, general file management principles, and the MediaLibraryKit framework.
