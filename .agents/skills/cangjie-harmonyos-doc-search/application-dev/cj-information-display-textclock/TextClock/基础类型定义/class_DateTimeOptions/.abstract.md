This directory provides comprehensive API reference documentation for the `DateTimeOptions` class within the ArkUI framework, tailored for the Cangjie programming language. It focuses on the configuration and customization of date and time formatting options, essential for implementing robust internationalization (i18n) and localization (l10n) features in HarmonyOS applications. The content covers the class constructor, a wide array of public properties, and specific formatting variables for components such as year, month, and time zone. This documentation is suitable for HarmonyOS developers and system architects using Cangjie who require precise control over date-time presentation, locale management, and specific display styles like numeric or long formats.
