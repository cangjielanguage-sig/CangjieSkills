# cj-wlan-overview

This directory serves as a comprehensive educational resource for Wireless Local Area Network (WLAN) service development, providing a high-level architectural framework essential for enabling wireless connectivity in modern applications. It thoroughly covers the general definitions of WLAN and Wi-Fi, distinguishing between the technologies, and details the implementation principles involving 2.4GHz and 5GHz frequency bands alongside 802.11 protocol standards. The content specifically breaks down three pivotal operational modes: STA (Station), which functions as a client for uplink services; P2P (Peer-to-Peer), which facilitates direct device-to-device connections through Group Owner and Client roles; and AP (Access Point), which acts as a central hotspot for downlink services. Additionally, the document references the ohos.wifiManager API to ground these concepts in practical implementation. This guide is ideally suited for developers working on connectivity applications who need to master the functional modes and core concepts of WLAN systems to build robust network solutions, bridging the gap between theoretical protocols and actual API usage.
