This directory contains essential API reference documentation for the `GeoAddress` class within the Cangjie programming language. It focuses on defining the data structures required for geocoded address information, encompassing geographical coordinates, administrative areas, and various location metadata. The documentation details the class constructor, specifications for public properties, and specific variables for address components. It is intended for developers implementing location services, specifically those working with the SystemCapability.Location.Location.Geocoder module. By providing structural definitions and data type specifications, this resource enables developers to effectively handle and interpret geospatial data in their applications.
