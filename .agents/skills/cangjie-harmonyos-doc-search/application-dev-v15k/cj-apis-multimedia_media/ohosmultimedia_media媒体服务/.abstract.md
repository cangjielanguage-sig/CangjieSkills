This directory provides API reference documentation for the HarmonyOS multimedia media service module, tailored for the Cangjie programming language. It encompasses a broad spectrum of functionalities including audio and video playback, recording, screen capture, transcoding, and metadata management. The documentation details essential classes, enums, structs, and factory functions necessary for developing robust multimedia applications. It is intended for software developers and engineers utilizing the MediaKit framework who require precise control over media processing, state management, and event handling within their Cangjie-based projects.
