# toybox

This directory contains comprehensive documentation for Toybox, a lightweight, consolidated Linux command-line utility collection designed to replace standard Linux commands within a single executable. It covers the tool's definition, Beta status, and specific usage prerequisites such as accessing the command line via hdc shell on a connected device or running within an application sandbox. The documentation also addresses troubleshooting common errors within the OpenHarmony environment, including permission issues and SELinux blocks. Furthermore, it provides a technical reference for system monitoring, process management, and network configuration. This resource is suitable for developers, system administrators, and embedded engineers working with OpenHarmony or Unix-like environments who need efficient command-line tools and debugging guides.

## Detailed Description

### toybox_2more.md toybox_2more.md
This document introduces toybox, a lightweight Linux command-line tool collection consolidated into a single executable file. It covers the tool's definition and outlines two specific usage prerequisites: accessing the command line via hdc shell on a connected device or running within an application sandbox. Key takeaways include the tool's current Beta status and its role as a unified replacement for standard Linux commands. This reference guide targets developers and system administrators seeking to utilize consolidated command-line utilities in various execution environments.

### 常见问题.md 常见问题.md
This troubleshooting guide addresses common errors and behavioral discrepancies encountered when using toybox commands within the OpenHarmony environment. It covers "Unknown command" errors, permission issues including SELinux blocks, standard Linux kernel error codes, and inconsistencies between shell built-ins and toybox implementations. Key takeaways include identifying missing compiled commands, checking kernel logs for "avc: denied," and forcing toybox execution using the "toybox [command]" format for commands like pwd or kill. This reference guide targets developers and system integrators debugging command-line tools in OpenHarmony.
