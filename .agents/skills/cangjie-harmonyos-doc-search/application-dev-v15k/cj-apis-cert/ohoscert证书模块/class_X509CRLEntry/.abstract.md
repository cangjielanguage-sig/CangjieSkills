This directory contains API reference documentation for the `X509CRLEntry` class within the Cangjie programming language's DeviceCertificateKit. It focuses on representing and managing revoked certificate objects found in Certificate Revocation Lists (CRLs). The documentation covers methods for retrieving issuer information, serial numbers, revocation dates, extensions, and encoded data. It is suitable for developers working on security applications, specifically those involved in certificate validation, cryptography operations, and revocation checking. The content includes syntax details, return types, and exception handling for `BusinessException` errors related to memory and crypto operations.
