This directory provides the API reference for the Cangjie programming language, focusing on the SystemCapability (SysCap) interface used to query operating system features. It details the definition of SysCap as independent OS characteristics and offers technical documentation for the `canIUse` function, including its signature, parameters, return values, and usage examples. The core takeaway is the `canIUse` method, which accepts a SysCap string name and returns a Boolean indicating feature support, allowing developers to adapt code for different devices. Targeted at Cangjie application developers, this guide enables conditional logic implementation based on hardware capabilities. It is suitable for developers needing to ensure their applications function correctly across various hardware environments by dynamically checking for feature availability at runtime. Keywords include Cangjie, SystemCapability, SysCap, `canIUse`, OS features, device compatibility, and conditional logic.
