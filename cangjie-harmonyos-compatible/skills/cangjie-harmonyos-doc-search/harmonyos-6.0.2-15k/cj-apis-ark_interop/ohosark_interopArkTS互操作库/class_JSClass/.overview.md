# class_JSClass

This directory contains API reference documentation for the `JSClass` within the Cangjie programming environment, specifically designed for HarmonyOS development. It focuses on providing safe references to ArkTS class constructors to enable dynamic manipulation, such as adding methods, properties, and accessors. The documentation covers object instantiation and class extension using the Napi subsystem, bridging Cangjie and JavaScript environments. It is suitable for developers working with ArkUI and JavaScript interoperability who need to programmatically construct and interact with ArkTS objects.

### class_JSClass_5more.md class_JSClass_5more.md
This document serves as API reference documentation for the JSClass class, which provides a safe reference to an ArkTS class constructor for dynamic manipulation. It details the read-only prototype property and key methods such as addAccessor and addMethod, allowing developers to define getters, setters, and custom methods using JSKeyable keys. The documentation highlights overloaded function signatures supporting both JSFunction and JSLambda types, complete with Cangjie code examples. Intended for HarmonyOS developers using the Napi subsystem, this resource requires familiarity with ArkUI and JavaScript interoperability to effectively extend and instantiate ArkTS classes programmatically.
