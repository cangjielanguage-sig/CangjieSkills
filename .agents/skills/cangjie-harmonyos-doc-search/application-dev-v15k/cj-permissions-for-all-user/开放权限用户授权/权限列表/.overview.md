# 权限列表

This directory serves as a comprehensive resource for HarmonyOS developers regarding system permissions introduced in API version 12. It provides detailed reference guides and API definitions for various permission types, ranging from hardware interactions like Bluetooth and Camera access to sensitive data privacy involving Location and Health information. Additionally, it covers specific file system access rights tailored for 2-in-1 devices. The documentation outlines critical attributes such as permission levels, authorization modes, and specific constraints, making it suitable for developers aiming to implement robust privacy controls and hardware capabilities in their HarmonyOS applications.

## Detailed Description

### ohospermissionACCESS_BLUE_15more.md ohospermissionACCESS_BLUE_15more.md
This document serves as a reference guide for HarmonyOS permissions introduced in API version 12. It details permissions for hardware access like Bluetooth, Camera, and Microphone, alongside data privacy permissions for Location, Health, and Calendar. Key takeaways include that all listed permissions are "normal" level requiring "user_grant" authorization. Specifically, the document outlines a strict application process for background location access, requiring users to manually enable it in settings after granting foreground permissions. This guide targets developers implementing privacy controls and hardware capabilities in HarmonyOS applications.

### ohospermissionREAD_WRIT_e087722f.md ohospermissionREAD_WRIT_e087722f.md
This API reference document defines the HarmonyOS permission ohos.permission.READ_WRITE_DOCUMENTS_DIRECTORY, outlining its function and configuration requirements. The content details the permission's scope, specifically allowing access to the public Documents directory, and lists critical attributes such as the normal permission level, user_grant authorization mode, and API version 12 introduction. A key constraint is that this permission is currently exclusive to 2-in-1 device applications. This information is essential for HarmonyOS developers targeting 2-in-1 devices who need to implement file management features within the public directory structure.
