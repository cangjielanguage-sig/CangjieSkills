# 示例代码

This directory provides a comprehensive collection of code examples tailored for developers utilizing the Cangjie programming language in the HarmonyOS environment. It focuses extensively on the implementation of custom page transition animations, a critical aspect of modern mobile app development. The content covers how to configure entry and exit effects, manipulate visual properties such as scaling and opacity, and define slide transitions with precise directional control. By demonstrating the use of the `onTransition` lifecycle method alongside `PageTransitionEnter` and `PageTransitionExit` classes, these examples guide developers in creating smooth, professional-grade navigation flows. This resource is ideal for HarmonyOS developers aiming to master the Cangjie ArkUI and UIKit frameworks, specifically those seeking to elevate user experience through dynamic and polished interface animations.

## Detailed Description

### 示例代码1设置退入场动画.md
This document provides a code example demonstrating how to configure custom page entry and exit animations using the Cangjie language. It covers the implementation of the `onTransition` lifecycle method, utilizing `PageTransitionEnter` and `PageTransitionExit` to control visual effects like scaling and opacity. The code illustrates how to bind animation progress to state variables for different route types, creating smooth transitions between an `EntryView` and `Page1`. This tutorial targets HarmonyOS developers using the Cangjie ArkUI framework who need to implement custom navigation transitions.

### 示例代码2设置退入场平移效果.md
This document serves as a code example demonstrating how to configure page entry and exit slide transition effects in a Cangjie application. The content includes two source files, index.cj and page1.cj, which implement navigation between pages with specific animation directions. Key information involves using the onTransition method to define PageTransitionEnter and PageTransitionExit options, utilizing SlideEffect.START and SlideEffect.END to control the translation direction. This tutorial is designed for developers using the Cangjie UIKit to enhance user experience with custom page transitions.
