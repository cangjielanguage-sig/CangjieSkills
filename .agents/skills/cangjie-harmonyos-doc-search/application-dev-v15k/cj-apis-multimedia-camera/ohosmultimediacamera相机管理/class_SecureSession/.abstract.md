This directory contains API documentation for the `SecureSession` class and related callback management functions within the Cangjie CameraKit framework. It covers high-security camera functionalities, such as secure preview streams for face recognition and banking, alongside event handling mechanisms for focus states and error monitoring. Key topics include the `SecureSession` class structure, `addSecureOutput` method, and the `on` and `off` functions for registering and unregistering camera event listeners. This documentation is intended for Cangjie developers building multimedia camera applications that require robust security features and real-time state management.
