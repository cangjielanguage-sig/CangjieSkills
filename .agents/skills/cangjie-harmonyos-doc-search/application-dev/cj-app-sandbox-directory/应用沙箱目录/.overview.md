# 应用沙箱目录

This directory provides comprehensive technical documentation on the application sandbox mechanism within the OpenHarmony environment. It covers the core concepts of file isolation, path mapping between virtual sandbox views and physical file systems, and data security protocols. Key topics include encryption levels (EL1-EL5), access permissions, and the distinction between App-level and HAP-level storage. This resource is essential for application developers and system integrators seeking to implement secure data handling, manage file persistence, and understand the architectural nuances of sandboxed file access.

## Detailed Description

### 应用沙箱目录_2more.md 应用沙箱目录_2more.md
This document defines the application sandbox directory mechanism, an isolation feature designed to secure application data by restricting file visibility and preventing malicious path traversal. It covers the composition of the sandbox directory, data access permissions, and the distinction between application sandbox paths and actual physical paths. Key takeaways include that applications can only access their own files and read-only system files within the sandbox, while user files require specific API authorization. The document clarifies that sandbox paths are virtualized views distinct from the physical paths seen in system processes like hdc shell. This technical guide targets application developers needing to understand file system isolation and path mapping for secure data handling.

### 应用沙箱路径和真实物理路径的对应关系.md 应用沙箱路径和真实物理路径的对应关系.md
This reference document outlines the mapping relationship between application sandbox paths and actual physical file system paths. It details specific mappings for installation bundles, encrypted data directories (el1 and el2 levels), databases, and distributed files. Key information includes the distinction between standard applications and independent sandbox Extension applications, illustrating how physical paths vary based on user ID and extension names. The document defines placeholders like USERID and EXTENSIONPATH to clarify path construction. This guide is intended for developers or system integrators managing file storage and data security within the application environment.

### 应用文件目录与应用文件路径/
This directory provides a comprehensive technical overview of application file directory structures and path management within the OpenHarmony development environment. It details the hierarchical organization of storage, emphasizing the five encryption levels (EL1-EL5) and their specific security use cases. Key topics include the distinction between App-level and HAP-level storage, the strict requirement to use Context APIs for path retrieval to ensure compatibility, and the standardization of directories for persistent data, caches, and temporary files. This resource is essential for developers aiming to implement secure data persistence, manage application lifecycles, and facilitate cross-device file sharing effectively.
