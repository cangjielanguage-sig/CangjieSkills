This directory contains API reference documentation for the `NetConnection` class within the Cangjie language's NetworkKit. It focuses on network connection management, specifically how to subscribe to and monitor network state changes, capabilities, and availability. Key topics include the registration and unregistration processes, handling various network events like switching between WiFi and cellular data, and managing callbacks for network handles and properties. This documentation is suitable for HarmonyOS developers and system application builders who need to implement real-time network status monitoring and handle network transitions effectively.
