This directory contains a detailed code sample designed to demonstrate the fundamental usage of the HashSet data structure within the Cangjie programming language. It provides a thorough explanation of initializing a HashSet and performing core manipulations, such as adding elements via the `add` function and removing elements using the `remove` function. The tutorial places significant emphasis on traversing elements using an iterator combined with pattern matching, illustrating how to effectively process collection items. Additionally, it clarifies that HashSets do not maintain a fixed order of elements, a critical aspect for developers to note. The guide also demonstrates how to handle Option types during the iteration process and verify the existence of elements using the `contains` function. This resource is primarily intended for developers who are learning the Cangjie standard library and require practical examples of collection manipulation, iteration logic, and type safety.
