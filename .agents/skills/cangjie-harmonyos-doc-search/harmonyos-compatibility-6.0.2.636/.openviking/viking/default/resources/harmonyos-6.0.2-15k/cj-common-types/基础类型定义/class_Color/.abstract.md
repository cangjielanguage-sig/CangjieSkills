This directory contains comprehensive API reference documentation for the `Color` class within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers the fundamental class structure, including its inheritance from `ResourceColor`, and provides a detailed list of static properties for standard colors like BLACK, WHITE, and TRANSPARENT. The documentation explains various initialization methods, ranging from RGBA component inputs to packed 32-bit integer values, and includes utility functions for color manipulation and conversion. This resource is essential for UI developers and system architects who need to programmatically define, manage, and manipulate color resources within their application interfaces, ensuring consistent and dynamic visual styling.
