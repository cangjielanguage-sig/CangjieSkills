# 密钥导入介绍及算法规格

This directory provides technical documentation for importing keys into the HUKS (HarmonyOS Universal Keystore Service) system. It covers mechanisms for both plaintext and encrypted key import, detailing the necessary cryptographic algorithms, data formats, and security protocols. Key topics include ECDH/X25519 key agreement, AES-GCM encryption, and algorithm compatibility across different device types. This resource is designed for security developers and system architects working on HarmonyOS or OpenHarmony applications who need to implement secure key lifecycle management and ensure data protection during key transfer.

## Detailed Description

### 加密导入.md 加密导入.md
This technical guide details the encrypted import mechanism for securely transferring keys into HUKS, ensuring end-to-end protection for high-security applications. The document outlines the development sequence, required HUKS capabilities including key generation, encryption, and import processes, and the specific data format for encrypted key materials. Key information includes the use of ECDH or X25519 for key agreement and AES-GCM for encryption, along with a detailed byte-level structure table for the import payload following a Length-Data format. Intended for security developers implementing sensitive business logic, this guide requires knowledge of cryptography and HUKS APIs.

### 密钥导入介绍及算法规格_2more.md 密钥导入介绍及算法规格_2more.md
This technical guide outlines the mechanisms for importing externally generated keys into the HUKS system for secure management. It covers two primary import methods: plaintext import and encrypted import, with specific details provided for plaintext import. Key takeaways include that HUKS ensures key plaintext remains within the secure environment post-import. Plaintext import is recommended for public keys on lightweight devices but exposes data during transfer, making it unsuitable for high-security symmetric keys. Targeted at developers working with HarmonyOS security features, specifically those managing key lifecycles on resource-constrained devices.

### 支持的算法_2more.md 支持的算法_2more.md
This reference document specifies cryptographic algorithm support for the OpenHarmony HUKS key import service. It categorizes supported algorithms and key lengths for standard and lightweight devices, distinguishing between mandatory and optional specifications to ensure compatibility. Additionally, it details the required import formats for various key types, including symmetric keys, asymmetric key pairs, and public keys, referencing standards like X.509 DER. The document serves as a technical guide for developers to select appropriate algorithms and formats when implementing key management features in OpenHarmony applications.
