This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie programming language. It focuses on layout management, scrolling behaviors, and constraint definitions for UI components. Key topics include setting row and column templates, managing gaps, handling nested scrolling, and optimizing performance through item caching. The documentation is essential for developers building complex, responsive user interfaces, particularly those implementing waterfall flows or grid systems. It requires familiarity with Cangjie syntax and ArkUI layout concepts.
