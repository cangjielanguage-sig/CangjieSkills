This directory contains technical documentation regarding configuration file tags used in application development, specifically focusing on the `module.json5` structure within HarmonyOS and OpenHarmony environments. It covers essential definitions for module properties, component behaviors, deployment settings, and packaging options. Key topics include module identification, permission management, process isolation, and HAP file attributes. These reference guides are designed for software developers and system architects who need to accurately configure application modules, manage dependencies, and ensure proper functionality across different device types. Prerequisite knowledge of JSON5 syntax is recommended.
