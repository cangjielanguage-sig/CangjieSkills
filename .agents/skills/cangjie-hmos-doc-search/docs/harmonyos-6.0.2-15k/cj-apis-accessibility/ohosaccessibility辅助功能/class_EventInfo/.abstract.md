This directory contains essential API reference documentation for the `EventInfo` class within the Cangjie programming language, specifically designed for the accessibility system. It comprehensively covers the class definition, constructor, and a wide range of properties used to represent interface change events, such as event type, bundle name, component type, and content indices. The documentation details essential data fields for tracking accessibility events under the `SystemCapability.BarrierFree.Accessibility.Core` capability, clearly distinguishing between required fields like type and optional fields for text movement and item counts. It is highly suitable for developers building accessibility services or applications requiring event tracking in system version 19, providing the technical specifications needed to implement robust accessibility features and handle system events effectively.
