# AESGCMNoPadding

本目录包含关于使用AES-GCM无填充模式进行数据加密与解密的文档和代码示例。内容主要基于HarmonyOS通用密钥库系统（HUKS），涵盖了密钥生成、属性配置（如AAD、NONCE、AE Tag）、会话管理（initSession、finishSession）以及密钥删除等核心流程。文档特别展示了如何在仓颉语言中集成HUKS API，适合需要在HarmonyOS应用中实现高安全性数据加密的开发者参考。

    - 查看完整的加密、解密及密钥删除流程代码实现 → AESGCMNoPadding_2.md

## 详细描述

### AESGCMNoPadding_1.md
本文档提供了使用仓颉语言和HUKS API进行AES/GCM/NoPadding加密与解密操作的代码示例。文档涵盖了数据类型转换工具函数、密钥生成属性配置、加密属性配置（包括AAD和NONCE）、解密属性配置（包含AE Tag提取）以及密钥生成流程。关键点包括设置算法参数（如HUKS_ALG_AES和HUKS_MODE_GCM）、处理附加认证数据（AAD）和随机数（NONCE），以及在解密时从密文中提取认证标签（AE Tag）。这是一个面向使用仓颉语言的HarmonyOS开发者的教程，旨在指导其利用通用密钥库实现安全数据加密。

### AESGCMNoPadding_2.md
本文档旨在演示如何使用AES-GCM无填充模式进行数据加密、解密及密钥删除的完整流程。文档主要包含模拟加密场景、模拟解密场景和模拟删除密钥场景三个核心代码片段。关键信息展示了通过initSession初始化会话、利用finishSession完成加解密操作，以及通过密钥别名调用deleteKeyItem删除密钥的具体实现，特别指出了解密时需对数据进行切片处理。这是一份代码教程类文档，主要面向需要集成HUKS通用密钥库系统的开发者，读者需具备基础的API调用和编程知识。
