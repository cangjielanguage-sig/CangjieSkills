This directory contains API reference documentation for configuring the properties of the Select component within the ArkUI framework using the Cangjie language. It covers a comprehensive range of customization options, including dropdown interface styling, menu alignment, background effects, option sizing, and typography. Developers can find detailed specifications for functions related to arrow positioning, control size, dividers, fonts, and selection behaviors. This documentation is suitable for UI developers and system engineers looking to programmatically customize the visual presentation and interaction logic of Select components to meet specific design requirements.
