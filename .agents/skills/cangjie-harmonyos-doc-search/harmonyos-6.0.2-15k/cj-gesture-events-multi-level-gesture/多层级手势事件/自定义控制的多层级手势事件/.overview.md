# 自定义控制的多层级手势事件

This directory provides a comprehensive guide to managing multi-level gesture events and touch interactions within the Cangjie framework. It covers essential mechanisms for controlling event distribution, resolving gesture conflicts between parent and child components, and customizing response regions. Key topics include `hitTestBehavior`, gesture binding methods (`.gesture`, `.priorityGesture`, `.parallelGesture`), and `responseRegion` properties. This resource is suitable for UI developers seeking precise control over complex UI layouts and event handling logic.

## Detailed Description

### hitTestBehavior对手势和事件的控制.md hitTestBehavior对手势和事件的控制.md
This technical guide explains how to use the `hitTestBehavior` property to manage touch event distribution and gesture responses in complex multi-level UI layouts. It details three specific modes: `HitTestMode.Block`, `HitTestMode.Transparent`, and `HitTestMode.None`, illustrating their effects on parent, child, and sibling components through code examples. Key takeaways include that Block consumes events and blocks others, Transparent allows events to pass to siblings, and None ignores events entirely. The document advises using these modes to control event flow in simple versus complex scenarios. Intended for UI developers using the Cangjie framework, this guide helps resolve gesture conflicts and ensures precise event handling.

### 绑定手势方法对手势的控制.md 绑定手势方法对手势的控制.md
This technical guide explains how to manage gesture response priorities between parent and child components using different binding methods in the Cangjie language. It covers three specific binding methods: standard `.gesture`, `.priorityGesture`, and `.parallelGesture`. The key takeaway is that standard binding prioritizes child components, priority binding forces the parent to respond first, and parallel binding allows both parent and child gestures to trigger simultaneously without conflict. This guide targets UI developers working with multi-level component hierarchies who need precise control over event handling.

### 自定义控制的多层级手势事件_2more.md 自定义控制的多层级手势事件_2more.md
This technical guide explains how to customize multi-level gesture event handling and touch event distribution in UI development. It covers the distinction between touch event distribution and gesture competition, specifically focusing on the `responseRegion` and `responseRegionArray` properties. Key information includes how these properties allow developers to define response areas that differ from a component's layout size, supporting single or multiple rectangular regions. The document clarifies that while these affect both `onTouch` and gestures, gesture binding methods only affect gestures. This guide is intended for UI developers using the Cangjie language who need precise control over event hit-testing and gesture response zones.
