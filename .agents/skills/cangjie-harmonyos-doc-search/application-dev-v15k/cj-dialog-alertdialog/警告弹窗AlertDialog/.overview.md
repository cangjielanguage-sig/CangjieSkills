### enum_DialogButtonDirection.md enum_DialogButtonDirection.md
This document serves as API reference documentation for the `DialogButtonDirection` enum in the Cangjie language, defining how buttons are arranged within warning dialogs. It details the enum definition and explains three specific enumeration values: AUTO, HORIZONTAL, and VERTICAL. Key information includes the specific layout logic for each value, where AUTO adapts based on button count (horizontal for two or fewer, vertical otherwise), while the others enforce fixed layouts. All features are supported from system version 12. This reference is intended for HarmonyOS developers using the ArkUI framework who need to customize the user interface of dialog boxes.
