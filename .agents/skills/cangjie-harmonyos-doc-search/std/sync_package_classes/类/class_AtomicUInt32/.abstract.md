This directory contains API reference documentation for the `AtomicUInt32` class in the Cangjie programming language. It focuses on atomic operations for unsigned 32-bit integers, essential for thread-safe, lock-free concurrent programming. Key topics include arithmetic operations (add, subtract), bitwise operations (and, or, xor), memory manipulation (load, store, swap), and compare-and-swap mechanisms. The documentation highlights the deprecation of explicit memory ordering arguments in favor of default ordering. It is suitable for systems programmers and developers implementing multi-threaded applications requiring precise control over shared data.
