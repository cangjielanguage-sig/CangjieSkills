This directory provides comprehensive API reference documentation for the `LocationRequest` class within the Cangjie language environment. It serves as a technical guide for configuring parameters essential for requesting location information. Key topics include defining priority levels, setting specific scenarios, managing time and distance intervals, and controlling maximum accuracy. The documentation explains critical logic, such as how scenario settings can override priority configurations and the specific permission dependencies required for high-accuracy location tracking. It is designed for developers and system architects building location-aware applications, offering insights into recommended values for diverse use cases ranging from high-precision navigation to low-power daily service tracking.
