This directory serves as the central repository for the API overview and usage guide of the `stdx.aspectCJ` package, a specialized library designed to bring Aspect Oriented Programming (AOP) capabilities to the Cangjie language. It provides a comprehensive framework for developers to manage cross-cutting concerns efficiently. The documentation details the usage of three core annotation classes: `InsertAtEntry`, `InsertAtExit`, and `ReplaceFuncBody`. These annotations allow for the precise weaving of logic into function entry points, exit points, or the complete replacement of function bodies. Additionally, the guide outlines strict specifications concerning scope, parameter constraints, and global variable limitations. It also provides critical instructions on the mandatory two-step compilation process, which requires the `libcollect-aspects` and `libwave-aspects` plugins. This resource is indispensable for Cangjie developers looking to implement advanced features like logging, monitoring, or security through compile-time instrumentation.
