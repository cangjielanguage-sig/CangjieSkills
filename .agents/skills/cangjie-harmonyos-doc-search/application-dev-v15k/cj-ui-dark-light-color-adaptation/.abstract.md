This directory serves as a comprehensive technical resource dedicated to the implementation of dark and light color adaptation for Cangjie applications. It addresses the critical requirement for modern applications to dynamically adjust their visual appearance in response to user preferences or operating system configurations. The content covers a wide array of essential strategies, including how to synchronize the application theme with the system's display mode, how to programmatically enforce a specific theme independent of system settings, and how to efficiently manage resource directories for colors and images. Key technical topics include the utilization of the `setColorMode` API, understanding system default judgment rules, and implementing advanced event handling for smooth theme transitions. This documentation is specifically designed for Cangjie developers seeking to create responsive, accessible, and visually consistent user interfaces that align perfectly with operating system preferences.
