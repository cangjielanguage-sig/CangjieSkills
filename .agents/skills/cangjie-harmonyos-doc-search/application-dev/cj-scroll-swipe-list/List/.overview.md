# List

This directory contains comprehensive documentation and resources for the ArkUI List container component within the Cangjie programming language framework. It covers essential aspects of implementing scrollable, multi-line data displays, including API references, component attributes, event handling, and practical code examples. Key topics include child component constraints, index calculation, scroll behavior customization, and layout optimization. This collection is designed for developers and system architects building high-performance, interactive user interfaces on HarmonyOS, providing the necessary syntax and configuration details to master complex list functionalities.

### List_5more.md List_5more.md
This document serves as API reference documentation for the ArkUI List container component in the Cangjie language. It describes a component designed to display continuous, multi-line data with uniform width. Key sections include module import, child component constraints (specifically ListItem and ListItemGroup), and detailed index calculation rules for rendering controls. The document outlines the component's initialization method, specifying parameters for spacing, initial index, and scroller binding. It also references common and scroll-specific attributes and events. This guide targets developers building UIs using the ArkUI framework, providing the necessary syntax and configuration details for implementing scrollable lists.

### 组件事件_2more.md 组件事件_2more.md
This document provides API reference documentation for scroll-related component events in the Cangjie ArkUI framework. It covers two primary functions: onScrollFrameBegin, which triggers at the start of each scroll frame to control offset, and onScrollIndex, which tracks when child components enter or leave the display area. Additionally, it defines the OnScrollFrameBeginHandlerResult class used to manage remaining scroll offsets. Key information includes parameter types, callback signatures, and system capabilities. This guide is intended for developers implementing custom scrolling behaviors or index tracking in Cangjie-based UI applications.
