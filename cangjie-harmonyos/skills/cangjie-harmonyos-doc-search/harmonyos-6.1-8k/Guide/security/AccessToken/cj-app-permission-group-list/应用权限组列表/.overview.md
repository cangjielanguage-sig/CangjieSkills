# 应用权限组列表

本目录包含 HarmonyOS 应用开发中关于权限组的参考文档。内容涵盖了多设备协同、通信媒体功能所需的特定权限，以及系统支持的标准应用权限组（如位置、相机、麦克风等）及其子权限列表。文档详细说明了权限申请机制、系统应用与普通应用的差异，以及受限权限的申请方式。主要面向应用开发者，旨在帮助其正确配置和申请权限，确保应用功能的合规实现。

## 详细描述

### 多设备协同_9more_0d61c94b.md
本文档是 HarmonyOS 开发者参考指南的一部分，旨在列出实现多设备协同、通信及媒体功能所需的权限。文档涵盖了多设备协同、蓝牙、星闪、电话、通话记录、信息、剪切板、截屏及文件访问等关键领域。它通过链接形式提供了具体权限名称（如 ohos.permission.DISTRIBUTED_DATASYNC）的详细定义，区分了系统应用与普通用户的权限差异，并说明了受限权限的申请方式。该文档主要面向应用开发者，帮助其在开发连接、通话及媒体相关应用时正确配置和申请权限。

### 应用权限组列表_13more_ff954ec5.md
本文档旨在列出系统支持的应用权限组及其包含的子权限，帮助开发者理解权限申请机制。文档涵盖了位置信息、相机、麦克风、通讯录、日历、健身运动、身体传感器、图片和视频、音乐和音频、广告跟踪及读取已安装应用列表等主要权限组。核心要点指出，同一权限组内的权限通常会在一个弹窗内统一请求用户授权，但地理位置、通讯录等特定组别除外。该参考文档主要面向应用开发者，建议在申请权限前结合概述文档阅读，以便合理申请权限。
