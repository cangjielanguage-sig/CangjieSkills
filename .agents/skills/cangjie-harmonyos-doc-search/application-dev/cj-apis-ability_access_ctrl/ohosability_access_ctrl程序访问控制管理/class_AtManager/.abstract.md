This directory contains technical documentation for the Cangjie `AtManager` class and associated permission management functions within the HarmonyOS development environment. It focuses on the mechanisms for access control, specifically detailing how to programmatically verify application permissions using `checkAccessToken` and how to interact with users to request runtime permissions via `requestPermissionsFromUser`. The content covers API signatures, parameter definitions, return types such as `GrantStatus`, and exception handling strategies. It is designed for Cangjie developers who need to implement secure access control, manage application identity tokens, and handle user authorization flows in their applications. This documentation assumes familiarity with system capabilities and the AccessToken framework.
