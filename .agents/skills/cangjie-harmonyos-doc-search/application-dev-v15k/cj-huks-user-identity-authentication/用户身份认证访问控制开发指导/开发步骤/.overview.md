# 开发步骤

This directory contains a technical tutorial series focused on implementing fingerprint-based access control for cryptographic keys using the Universal Keystore Kit (HUKS) in the Cangjie programming language. It covers the complete workflow from generating biometric-protected keys and initializing secure sessions to integrating UserIAM for fingerprint authentication and performing SM4 encryption operations. Key topics include HUKS key parameters, session management, authentication tokens, and secure data handling. This guide is designed for HarmonyOS application developers who need to implement secure access control and encryption features requiring biometric verification.

## Detailed Description

### 开发步骤_1.md 开发步骤_1.md
This technical tutorial guides developers through implementing fingerprint-based access control for cryptographic keys using the Universal Keystore Kit in Cangjie. The document covers two primary development steps: generating a key with specific biometric properties and initializing a key session to acquire an authentication token. Key takeaways include the configuration of essential parameters like HuksUserAuthType, HuksAuthAccessType, and HuksChallengeType during key generation, and the integration of UserAuthenticationKit for secure session management. Intended for HarmonyOS application developers, this guide assumes familiarity with cryptographic concepts and the Cangjie programming language.

### 开发步骤_2.md 开发步骤_2.md
This document provides a code tutorial for integrating HUKS key operations with UserIAM biometric authentication using the Cangjie language. It covers session initialization to retrieve a challenge, triggering fingerprint authentication via UserIAM, and performing secure data operations like SM4 encryption using the resulting authentication token. Key information includes the workflow of obtaining a challenge, authenticating the user to generate a token, and passing that token to update and finish sessions to authorize cryptographic actions. This guide targets HarmonyOS developers implementing secure access control and encryption features requiring biometric verification.

### 开发步骤_3.md 开发步骤_3.md
This document serves as a code tutorial snippet demonstrating the finalization of a HUKS (HarmonyOS Universal KeyStore) session and testing SM4 encryption with biometric authentication. It covers the implementation of the publicFinishFunc wrapper, which manages session termination and error handling, and the testSm4Cipher function, which validates the encryption workflow by passing a fingerprint authentication token. Key takeaways include the importance of passing the authentication token during both update and finish operations to secure the process. This technical guide is intended for developers implementing secure cryptographic operations in HarmonyOS applications, requiring prior knowledge of HUKS APIs and basic encryption concepts. Keywords: HUKS, SM4 encryption, biometric authentication, session management, HarmonyOS development.
