# class_NetConnection

This directory provides comprehensive API reference documentation for the `NetConnection` class in the Cangjie language, specifically designed for the NetworkKit framework. It covers the essential mechanisms for managing network connection states and handling various network-related events. The documentation details subscription methods for monitoring network availability, block status, and capability changes, alongside the necessary register and unregister functions for listener lifecycle management. It is intended for application developers who need to implement robust network monitoring, handle dynamic connectivity transitions like WiFi to cellular switching, and manage system permissions and error codes within their applications.

## Detailed Description

### class_NetConnection_4more.md
This document serves as API reference documentation for the NetConnection class in the Cangjie language, focusing on managing network connection states and event handling. It details the class functionality and three primary subscription methods: onNetAvailable, onNetBlockStatusChange, and onNetCapabilitiesChange. Key information includes the mandatory use of register and unregister methods to manage event listeners, as well as specific behaviors during network transitions like switching from WiFi to cellular. The content targets application developers utilizing the NetworkKit to monitor and respond to network status changes within their software.

### func_onNetConnectionProper_3more.md
This API reference document outlines three functions for subscribing to network state events using the Cangjie language's NetworkKit. The main sections cover onNetConnectionPropertiesChange, onNetLost, and onNetUnavailable, detailing their syntax, parameters, and usage examples. Key information includes the requirement to call register before subscribing and unregister to stop notifications, alongside the specific callback data structures like NetHandle and ConnectionProperties. Intended for application developers, this documentation facilitates dynamic monitoring of network connectivity changes, requiring prior knowledge of the NetConnection object lifecycle and system capabilities.

### func_register_2more.md
This document serves as API reference documentation for managing network state subscriptions in the Cangjie programming language. It details two primary functions: register(), which subscribes to network state changes, and unregister(), which cancels this subscription. Key information includes required permissions like ohos.permission.GET_NETWORK_INFO, specific system capabilities, and comprehensive error code tables for handling exceptions such as permission denial or service connection failures. Targeted at developers building network-aware applications, this guide provides code examples to implement listener registration and removal within the NetworkKit framework.
