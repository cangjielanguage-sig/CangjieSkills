This directory contains comprehensive API reference documentation for the `PhotoEditorExtensionContext` class within the HarmonyOS development framework. It focuses on defining the context for `PhotoEditorExtensionAbility`, detailing its inheritance from `ExtensionContext` and system capabilities. The content covers critical methods for saving edited images, specifically `saveEditedContentWithImage` and `saveEditedContentWithUri`. It includes detailed explanations of parameters, return values, error codes, and Cangjie code examples. This documentation is suitable for developers building photo editing extensions who need to manage image saving operations, handle exceptions, and configure context settings effectively.
