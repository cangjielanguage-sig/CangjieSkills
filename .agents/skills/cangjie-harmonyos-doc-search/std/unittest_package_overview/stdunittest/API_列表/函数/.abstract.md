This directory provides a comprehensive collection of API documentation for core functions within a specialized unit testing framework, primarily targeting developers utilizing the cjc command-line environment. It encompasses a wide range of assertion utilities, configuration management tools, and failure handling mechanisms. The documentation clearly delineates between strict validation functions that throw exceptions to halt execution and non-throwing checks that merely log results. It is highly suitable for developers implementing automated tests who require a deep understanding of generic types, testing workflows, and framework control. Key topics include equality comparisons, custom assertions, and the entryMain function for test execution. By mastering these functions, developers can ensure robust validation and efficient test management within their projects.
