The `cj-atm-tool` directory functions as a comprehensive technical repository for the Access Token Manager (atm), a specialized command-line utility designed for querying application process permissions and granular access control information. This documentation is indispensable for developers and security engineers who need to monitor or debug how applications request and utilize system permissions. It covers critical environment prerequisites, most notably the requirement for the hdc shell, ensuring users are prepared before execution. The text details the spectrum of available commands, placing significant emphasis on the dump command, which serves as the primary method for data extraction. Readers will find clear instructions on the syntax required for querying system process information and analyzing permission usage types. Furthermore, it explains how to leverage specific filters—including token ID, bundle name, process name, and permission name—to refine search results. This guide is targeted at professionals seeking to inspect access control mechanisms or resolve permission-related anomalies in their software projects.
