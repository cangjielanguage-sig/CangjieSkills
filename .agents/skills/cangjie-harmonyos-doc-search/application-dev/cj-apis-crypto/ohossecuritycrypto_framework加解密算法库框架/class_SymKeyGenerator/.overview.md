# class_SymKeyGenerator

This directory provides comprehensive API reference documentation for the `SymKeyGenerator` class within the Cangjie programming language's CryptoFramework. It focuses on the mechanisms for generating and converting symmetric keys, essential for secure data encryption and decryption. The documentation details specific class properties like `algName`, methods such as `convertKey`, and the standalone `generateSymKey` function. It also addresses specific algorithm requirements, including HMAC key lengths and 3DES192 implementation, alongside error handling for `BusinessException`. This resource is designed for Cangjie developers and security engineers who are building cryptographic applications and require precise guidance on key management and system capabilities.

### func_generateSymKey.md func_generateSymKey.md
This API documentation details the generateSymKey function in the Cangjie language, which retrieves a randomly generated symmetric key. The document covers the function signature, functional description, prerequisites, specific behaviors for HMAC algorithms, system capabilities, return values, exceptions, and a usage example. Key information includes the requirement to use createSymKeyGenerator beforehand and the reliance on OpenSSL's RAND_priv_bytes. It specifies that HMAC key length matches the hash algorithm if specified, otherwise convertKey is needed. The function returns a SymKey object and handles memory operation errors. This reference guide targets Cangjie developers implementing cryptographic security features using the CryptoArchitectureKit.
