# 预览仓颉

This directory provides comprehensive technical documentation for implementing camera preview functionality using the Cangjie programming language. It covers essential development steps such as importing necessary kits like CameraKit and BasicServicesKit, configuring the XComponent surface, and managing preview output streams. Key topics include ensuring correct aspect ratios to prevent distortion and initializing camera sessions. Furthermore, it details how to monitor stream lifecycle events—such as start, end, and error handling—using specific callbacks. This resource is designed for application developers working with camera APIs who need to integrate robust preview features and effectively manage stream states in their Cangjie-based applications. The guides assume prior knowledge of permission handling and basic API usage.

## Detailed Description

### 状态监听.md 状态监听.md
This document guides developers on monitoring camera preview output stream status during application development using the Cangjie language. It covers three specific monitoring events: preview stream start, preview stream end, and preview output errors. Key information includes Cangjie code examples for registering FrameStartCallBack, FrameEndCallBack, and ErrorCallBack via the previewOutput.on method. The text explains that FrameStart triggers on first exposure, FrameEnd on the last frame, and Error returns specific error codes. This technical guide targets camera application developers who need to handle stream lifecycle and error management.

### 预览仓颉_2more.md 预览仓颉_2more.md
This document serves as a development guide for implementing camera preview functionality using the Cangjie programming language. It outlines a step-by-step process including importing CameraKit and BasicServicesKit, creating a Surface via the XComponent component, and generating a preview output stream using supported device profiles. Key technical requirements include ensuring the aspect ratio of the preview stream matches the XComponent display area to avoid distortion. The guide provides code examples for initializing the camera input, configuring the session, and starting the preview stream. Intended for application developers, this tutorial assumes prior permission application and basic knowledge of the CameraKit API.
