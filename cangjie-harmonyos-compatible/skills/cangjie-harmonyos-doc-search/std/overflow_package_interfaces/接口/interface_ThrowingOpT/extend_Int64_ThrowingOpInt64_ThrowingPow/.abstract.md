This directory provides comprehensive API documentation for extending the `Int64` type within the Cangjie programming language, specifically focusing on exception-throwing arithmetic interfaces. It details the implementation of `ThrowingOp` and `ThrowingPow`, covering essential operations such as addition, subtraction, multiplication, division, modulo, increment, decrement, and bitwise shifts. The primary focus is on safety mechanisms where operations raise `OverflowException` or `OvershiftException` to prevent silent failures or integer wrapping. This resource is essential for Cangjie developers who need to implement robust mathematical logic with explicit error handling and strict overflow detection in their software projects.
