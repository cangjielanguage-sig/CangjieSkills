This directory serves as a centralized repository for technical guidelines regarding the HiDumper tool, specifically tailored for the HarmonyOS and OpenHarmony development environments. It provides comprehensive instructions on retrieving system information, debugging applications, and conducting rigorous performance analysis. The content covers critical operational areas such as environment setup, command-line usage, and monitoring system resources like CPU, memory, and network. A primary focus is placed on the integration with the Cangjie (仓颉) programming language, detailing advanced techniques for heap snapshots and garbage collection processes. Furthermore, it includes methodologies for ArkUI debugging, specifically targeting window hierarchies and component trees. This documentation is essential for developers and QA engineers seeking to optimize application performance, profile system behavior, and troubleshoot complex system issues efficiently.
