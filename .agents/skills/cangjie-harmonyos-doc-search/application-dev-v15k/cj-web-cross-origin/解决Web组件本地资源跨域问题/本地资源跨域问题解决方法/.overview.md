# 本地资源跨域问题解决方法

This directory provides comprehensive technical solutions for resolving Cross-Origin Resource Sharing (CORS) issues when accessing local resources within web applications. It specifically addresses the challenges developers face when trying to load local files via the file protocol in a hybrid environment. The content covers the backend configuration of allowed path lists using the `setPathAllowingUniversalAccess` API, as well as the frontend implementation using HTML and JavaScript to fetch these resources. Key topics include security permissions, path validation, exception handling (401 errors), and the integration between HarmonyOS ArkTS and Webview components. This resource is primarily suitable for HarmonyOS developers and engineers building hybrid applications who need to securely manage local file access and bypass browser security restrictions.

## Detailed Description

### 本地资源跨域问题解决方法_1.md
This technical guide explains how to resolve cross-origin access issues for local resources in web applications using the setPathAllowingUniversalAccess API. It details the configuration of allowed path lists, specifying valid formats for application files and resource directories obtained via Context. The document highlights that setting this list overrides the default fileAccess behavior and throws a 401 exception for invalid paths. It includes Cangjie code examples demonstrating context retrieval and path implementation. This guide targets HarmonyOS developers working with Webview components who need to manage local file security and access permissions.

### 本地资源跨域问题解决方法_2.md
This document serves as a technical guide demonstrating how to resolve Cross-Origin Resource Sharing (CORS) errors when accessing local files via the file protocol within a web application. The content covers an HTML and JavaScript implementation using XMLHttpRequest to fetch a local script file, highlighting the dependency on ETS-side path list configurations for successful access. Key takeaways include the specific file path structure and the conditional logic for handling success or failure states based on CORS policies. This material is intended for developers building hybrid applications, particularly those using HarmonyOS ArkTS to integrate web components with local rawfile resources.
