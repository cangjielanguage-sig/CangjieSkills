This directory provides API reference documentation for the Cangjie programming language, specifically focusing on saturating arithmetic operations for unsigned integer types. It details the implementation of the `SaturatingOp` interface for `UInt32` and documents specific utility functions for `UInt64` and `UInt32`. The content covers essential arithmetic and bitwise operations designed to prevent unexpected wrapping behavior by handling overflow and underflow through saturation strategies. This resource is ideal for Cangjie developers seeking safe, boundary-checked integer operations to ensure numerical stability in their software projects.
