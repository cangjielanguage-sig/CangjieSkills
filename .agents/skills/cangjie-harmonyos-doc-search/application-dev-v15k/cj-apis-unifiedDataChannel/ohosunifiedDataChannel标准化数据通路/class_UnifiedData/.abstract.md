This directory contains comprehensive API reference documentation for the `UnifiedData` class within the HarmonyOS ArkData kit, specifically implemented using the Cangjie language. It focuses on the Unified Data Management Framework (UDMF), providing essential resources for encapsulating, managing, and inspecting data records. Key topics covered include the class definition, metadata properties, constructors, and methods for adding, retrieving, and validating data records. This documentation is intended for developers working on distributed data management in HarmonyOS who require a deep understanding of unified data objects, type inspection, and data structure validation to build robust applications.
