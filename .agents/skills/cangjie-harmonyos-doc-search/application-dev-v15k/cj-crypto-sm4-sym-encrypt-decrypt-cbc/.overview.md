# cj-crypto-sm4-sym-encrypt-decrypt-cbc

This directory serves as a comprehensive technical resource for developers working within the Cangjie programming language ecosystem who need to implement high-standard cryptographic operations. It focuses specifically on the SM4 symmetric encryption algorithm operating in Cipher Block Chaining (CBC) mode, a standard widely recognized for its robustness in data protection. The content guides users through the complete lifecycle of securing data, from the initial generation of cryptographic keys and the management of Initialization Vectors (IVs) to the handling of data padding and processing via the CryptoArchitectureKit. It is particularly suitable for Cangjie developers, security engineers, and system architects who require a deep understanding of the `Cipher` lifecycle—encompassing `init`, `update`, and `doFinal` methods—to ensure data integrity and confidentiality in their applications. By mastering these concepts, developers can effectively integrate national cryptographic standards into their software solutions, ensuring compliance and security.

## Detailed Description

### [1] 使用SM4对称密钥CBC模式加解密仓颉/

This subdirectory provides a focused and practical exploration of implementing SM4 symmetric encryption and decryption using the CBC mode within the Cangjie programming language environment. It is designed to equip developers with the necessary skills to utilize the CryptoArchitectureKit effectively for secure data handling. The content covers essential cryptographic workflows in detail, starting with the generation of symmetric keys and the management of Initialization Vectors (IVs), which are critical components for maintaining the security of the CBC mode. It delves into specific technical requirements such as the SM4_128 block size, the operational mechanics of CBC mode, and the application of PKCS7 padding to ensure data blocks align correctly for encryption.

Furthermore, the directory offers a detailed breakdown of the `Cipher` lifecycle, explaining the specific roles of the `init`, `update`, and `doFinal` methods in processing data streams. This ensures developers understand how to initialize the cryptographic context, feed data into the cipher, and finalize the operation to retrieve the secure output. This resource is ideal for Cangjie developers looking for both theoretical background and practical code examples to implement robust data security measures, ensuring that sensitive information remains protected against unauthorized access and tampering.
