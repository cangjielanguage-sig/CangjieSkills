This directory contains API reference documentation for the Cangjie `MethodActionSelector` class, a crucial component for configuring stub behaviors in unit testing and mocking frameworks. It covers methods for defining return values, executing original logic, and handling exceptions or sequential return lists. Key topics include fluent chaining, mock object setup, and test flow control. This documentation is intended for software developers using the Cangjie language who need to implement advanced mocking strategies, manage test execution flows, and handle error scenarios within their unit tests.
