This directory contains API reference documentation for the `BaseDialogOptions` class in the Cangjie language, specifically designed for the ArkUI framework. It covers configuration properties for dialog components, including layout positioning (maskRect, alignment), behavioral settings (isModal), visual styling (maskColor, transition), and lifecycle event callbacks (onDidAppear, onWillDisappear). The documentation also details advanced features like keyboard avoidance and hover modes available in later API versions. This resource is suitable for application developers and UI engineers who need to customize dialog behaviors and appearances using Cangjie syntax.
