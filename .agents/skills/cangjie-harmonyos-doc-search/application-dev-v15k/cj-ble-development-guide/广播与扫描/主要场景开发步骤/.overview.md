# 主要场景开发步骤

This directory serves as a comprehensive technical guide for developers navigating the primary development scenarios within Bluetooth Low Energy (BLE) ecosystems. It details the step-by-step procedures required to establish, manage, and optimize wireless communication links between devices. The content specifically addresses the dual aspects of BLE interaction: broadcasting a device's presence to the outside world and scanning the environment to detect other devices. By covering the full lifecycle of these operations—from initialization and parameter configuration to data parsing and resource cleanup—this documentation ensures developers can build stable and efficient connectivity solutions. It is designed for software engineers using Cangjie, ArkTS, or similar frameworks targeting HarmonyOS and OpenHarmony platforms who require a deep understanding of BLE protocol implementation, state management, and data handling. The guides provided here are essential for creating applications that rely on seamless device discovery and interconnectivity.

## Detailed Description

### 开启关闭广播.md 开启关闭广播
This tutorial provides a step-by-step guide and code example for managing Bluetooth Low Energy (BLE) advertising operations using the Cangjie language. It covers essential prerequisites, including system capabilities and Bluetooth activation, before detailing the lifecycle of advertising. Key sections explain how to start advertising with specific parameters, temporarily disable it, re-enable it, and permanently stop it to release resources. The document highlights the use of AdvertisingParams, data construction, and state change callbacks. It is intended for developers implementing BLE connectivity who need to control device visibility and broadcast resources effectively.

### 开启关闭扫描/
This directory focuses on the implementation of Bluetooth Low Energy (BLE) scanning functionality, specifically the processes of starting and stopping device discovery. It covers the complete lifecycle of BLE scanning, including system prerequisites, scan management, and the critical parsing of raw advertising data packets. Key topics include the BleScanManager class, scan filters, and extracting specific data like service UUIDs and manufacturer information. The content is tailored for application developers working on HarmonyOS, OpenHarmony, or ArkTS environments who need to integrate robust Bluetooth connectivity and data interpretation into their applications.
