# linux_toolchain_install

This directory serves as a comprehensive resource for the installation and configuration of the Cangjie toolchain on Linux operating systems. It addresses the specific requirements for setting up the development environment across various mainstream distributions, including Ubuntu, UOS, and Kylin. The documentation provides essential instructions for installing basic dependency libraries and details the process for compiling OpenSSL 3 from source code. This guide is tailored for developers and technical personnel who need to deploy the Cangjie development environment on Linux, with a specific focus on managing complex dependencies and configuring environment variables correctly.

## Detailed Description

### Linux_版本工具链的支持与安装/

This directory contains detailed guides for installing and configuring the Cangjie toolchain on Linux systems. The content covers compatibility support for mainstream Linux distributions (such as Ubuntu, UOS, Kylin), installation commands for basic dependency libraries, and the source code compilation method for the key dependency OpenSSL 3. This document is suitable for developers who need to build a Cangjie development environment in a Linux environment, especially users involved in dependency management and environment variable configuration.
