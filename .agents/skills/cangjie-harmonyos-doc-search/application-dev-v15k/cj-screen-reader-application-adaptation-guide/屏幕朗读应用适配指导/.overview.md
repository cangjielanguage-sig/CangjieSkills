# 屏幕朗读应用适配指导

This directory provides a comprehensive technical guide for developers implementing screen reader accessibility features using the Cangjie language and ArkUI framework. It covers essential scenarios such as dynamic content updates, multi-dimensional nesting, multilingual support, and composite component grouping. Key topics include `accessibilityText`, `accessibilityGroup`, and event handling APIs. Designed for Cangjie developers and UI designers, these resources ensure applications are navigable and compliant with accessibility standards for visually impaired users.

## Detailed Description

### 内容动态变化场景_3more.md 内容动态变化场景_3more.md
This technical guide instructs developers on implementing accessibility announcements for dynamic UI changes using the Cangjie language. It covers three primary scenarios: dynamic content updates, control state changes, and operation errors. Key takeaways include using the `sendAccessibilityEvent` API with `EventInfo` for real-time text announcements, dynamically updating `accessibilityText` for component states like play/pause buttons, and grouping elements with `accessibilityGroup` to ensure error messages are audible, not just visual. The document provides code examples and parameter definitions for the `AccessibilityKit`. It targets application developers seeking to enhance accessibility compliance and user experience for dynamic interfaces.

### 多维嵌套场景.md 多维嵌套场景.md
This document serves as a technical guide for optimizing accessibility in multi-dimensional nested UI components using the Cangjie language. It addresses the issue of redundant screen reading announcements when child elements within a group contain overlapping information. The content contrasts incorrect implementation, where individual child controls cause repetitive audio feedback, with the correct approach using the accessibilityGroup(true) property on the parent container. Key takeaways include the importance of unifying focus management to reduce user steps and avoiding duplicate content descriptions. This resource is intended for Cangjie developers and UI designers seeking to improve the accessibility and usability of complex application interfaces.

### 多语种场景_3more.md 多语种场景_3more.md
This technical guide instructs developers on implementing specific accessibility features in applications using the Cangjie language. It covers three primary scenarios: handling multilingual text annotations, providing real-time feedback during control position adjustments, and managing focus shifts when controls disappear. Key takeaways include the need to carefully concatenate strings for right-to-left languages like Arabic, the requirement to announce movement positions in real-time to match visual feedback, and the protocol for logically shifting focus to the next control using the sendAccessibilityEvent API. The document provides code examples and parameter tables for implementation. It targets application developers seeking to enhance accessibility for visually impaired users.

### 按钮标注场景.md 按钮标注场景.md
This guide instructs developers on how to properly annotate non-text clickable controls for accessibility in Cangjie applications. It covers labeling requirements for custom buttons and virtual areas, emphasizing the use of the accessibilityText property. Key takeaways include the necessity of providing labels for non-text controls to ensure screen reader functionality, while explicitly excluding control types and instructional phrases like "double tap," as the system adds these automatically. The document includes a code example demonstrating dynamic labeling for a Play/Pause button. This is intended for Cangjie developers implementing accessibility features.

### 插画视频动画的播报场景.md 插画视频动画的播报场景.md
This technical guide instructs developers on implementing accessibility announcements for illustrations, videos, and list items within UI applications. It covers scenarios where illustrations must be paired with functional descriptions and where list items require combined information from nested elements. The key takeaway is utilizing the `accessibilityGroup(true)` attribute to merge multiple components into a single focusable object, ensuring screen readers convey complete context. Targeted at Cangjie language developers, the document provides code examples demonstrating how to group images, text, and other controls for optimal accessibility support.

### 概述_3more.md 概述_3more.md
This document serves as a development guide for implementing Screen Reader accessibility to assist visually impaired users. It covers an overview of accessibility principles, scenarios for labeling screen reading content, and methods to disable focus for decorative elements. Key takeaways include prioritizing accessibilityText over display text for non-text controls or additional context, and using .accessibilityLevel("no") to hide decorative UI elements from focus. The document provides Cangjie code examples demonstrating these attributes. It targets mobile application developers using the ArkUI/Cangjie framework who need to ensure their apps are navigable and understandable via voice feedback.

### 组合场景.md 组合场景.md
This technical guide addresses the optimization of accessibility for composite UI components by grouping them to reduce information redundancy and improve focus performance. It covers the principle of aggregating functionally related elements into a single focusable unit. Key information includes a Cangjie code example demonstrating the incorrect implementation of individual focus versus the correct method using the accessibilityGroup property. The guide explains that setting this property to true on a parent container prevents child components from being individually focused, requiring a combined accessibilityText for the group. This document targets UI developers using the Cangjie framework to create efficient experiences for screen reader users.
