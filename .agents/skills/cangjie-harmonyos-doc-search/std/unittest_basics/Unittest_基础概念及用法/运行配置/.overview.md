# 运行配置

This directory provides comprehensive documentation for configuring and executing unit tests within the CJC and cjpm development environment. It focuses on runtime flags and command-line options that allow users to control test execution flow, output visibility, and reporting mechanisms. Key topics covered include output capture settings to prevent log interleaving, parallel execution strategies for independent test classes, and advanced filtering using tags and patterns. Additionally, it details benchmarking capabilities and custom configuration options. This resource is essential for developers and QA engineers seeking to optimize test performance, manage reporting formats like XML and CSV, and ensure precise control over test execution behavior.

## Detailed Description

### --capture-output_7more.md --capture-output_7more.md
This reference document details specific command-line options for configuring output handling and progress reporting within the cjpm unit testing framework. It covers output capture flags, including enabling or disabling capture and showing all output, alongside coverage-guided testing and progress display controls like brief reports and entry limits. Key information explains that output capture is default for cjpm test to prevent interleaving and organize logs, while progress options allow customization of report verbosity. This guide targets developers using the cjpm tool who need to manage test execution visibility and reporting styles.

### 使用方法_8more.md 使用方法_8more.md
This document serves as a command-line reference guide for executing CJC-compiled unit tests, detailing various runtime flags to control test behavior. It covers options for benchmarking (`--bench`), filtering subsets by name patterns (`--filter`), listing tests without execution (`--dry-run`), managing test categories via tags (`--include-tags`, `--exclude-tags`, `--show-tags`), and setting global timeouts (`--timeout-each`). Key information includes specific syntax for wildcard filtering and logical operators for tag selection, with notes on priority where exclusion overrides inclusion. Additionally, it clarifies that code-level timeout settings take precedence over command-line arguments. This guide is intended for developers and QA engineers using the CJC unit testing framework to customize test execution and reporting.
