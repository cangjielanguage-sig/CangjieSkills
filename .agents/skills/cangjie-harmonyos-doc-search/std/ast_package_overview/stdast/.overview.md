# stdast

The `stdast` directory serves as the central documentation hub for the Cangjie language's Abstract Syntax Tree (AST) package, which is essential for low-level code manipulation and compiler construction. It thoroughly documents the syntax parser's functionality in transforming source code tokens into structured AST nodes, alongside advanced features for managing macro expansion contexts. Key topics include handling nested macro scenarios, context validation, and serialization mechanisms. This documentation is specifically tailored for compiler developers, language engineers, and advanced users engaged in metaprogramming. It provides the necessary technical depth for implementing custom macros, performing static analysis, and understanding the hierarchical structures of syntax nodes within the Cangjie ecosystem. By leveraging these resources, developers can effectively build tools that interact directly with the Cangjie compiler's internal representations.

### 功能介绍.md 功能介绍.md

This document introduces the `ast` package for the Cangjie language, detailing its capabilities in parsing source code into Abstract Syntax Trees (AST) and managing macro expansion contexts. It covers the syntax parser functionality for converting tokens to AST nodes and the "Macro With Context" feature, which provides functions to handle nested macro scenarios and context validation. Key information includes specific functions like `assertParentContext` for enforcing nesting constraints, `insideParentContext` for boolean checks, and various `setItem` overloads. These functions are restricted to direct calls only. This reference documentation targets compiler developers or advanced users working with Cangjie macros and AST manipulation, requiring knowledge of lexical analysis and macro systems.
