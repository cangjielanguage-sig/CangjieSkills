This directory contains API reference documentation for the `ohos.distributed_device_manager` module in the Cangjie programming language, designed for HarmonyOS distributed application development. It covers essential components for managing distributed hardware, including device discovery, authentication, state monitoring, and data type definitions. Key elements include the `DeviceManager` class, device state enums, and basic device information structures. This documentation is suitable for software developers building multi-device collaboration features who need to implement device discovery, binding, and status tracking logic using Cangjie.
