# 根据数据网络查询网络的能力信息及连接信息

本目录包含关于如何使用数据网络查询网络能力及连接信息的开发指南与技术文档。内容主要涵盖NetworkKit的使用方法，包括权限声明、模块导入、获取网络句柄（NetHandle）、解析网络类型（如蜂窝、Wi-Fi）以及遍历所有可用网络以获取详细属性。文档通过Cangjie代码示例演示了`getDefaultNet`、`getNetCapabilities`和`getConnectionProperties`等关键API的调用。适用于HarmonyOS应用开发者，特别是需要处理网络连接状态和属性查询的软件工程师。

## 详细描述

### 根据数据网络查询网络的能力信息及连接信息_1.md
本文档是一份开发指南，旨在指导开发者如何使用NetworkKit查询数据网络的能力及连接信息。主要涵盖权限声明、模块导入、获取网络句柄（NetHandle）、解析网络类型（如蜂窝、Wi-Fi）及具体能力（如MMS、计费状态）等步骤。文档通过Cangjie代码示例详细演示了调用getDefaultNet、getNetCapabilities和getConnectionProperties等关键API的方法。关键信息包括网络承载类型的判断及网络属性的获取。目标受众为HarmonyOS应用开发者，需具备Cangjie语言基础及权限管理知识。

### 根据数据网络查询网络的能力信息及连接信息_2.md
本技术文档演示了如何遍历可用的数据网络以检索其特定的能力和连接属性。它涵盖了对网络对象的迭代过程以及利用特定函数提取网络元数据。核心要点是实现一个循环，为每个网络项调用 getNetCapabilities 和 getConnectionProperties，以访问详细的网络状态信息。适用于从事网络连接功能开发的软件工程师，通常涉及移动端或系统级编程背景。
