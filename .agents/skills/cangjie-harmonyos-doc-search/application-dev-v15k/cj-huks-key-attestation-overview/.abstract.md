This directory contains essential documentation for understanding HUKS (OpenHarmony Universal KeyStore) key attestation, a critical security mechanism designed to verify the legitimacy of asymmetric public keys. It provides an in-depth look at how Public Key Infrastructure (PKI) certificate chains are utilized to establish a root of trust. The content covers the entire attestation process, explaining how the HUKS system generates a certificate chain that allows servers to validate the authenticity of client keys. It details the specific cryptographic algorithms supported by the system, including RSA, ECC, and SM2, with a focus on compatibility for API level 15 and above. Additionally, the documentation addresses advanced privacy features such as anonymous attestation, which helps protect device identity, and outlines technical constraints related to emulators and lightweight devices. This resource is specifically curated for developers and system architects who need to integrate secure key verification into OpenHarmony applications, ensuring that all cryptographic operations are anchored in legitimate hardware.
