This directory provides comprehensive API reference documentation for the `ConfigureMock` class, a core component of a testing framework designed for the Cangjie programming language. It covers the essential utilities required to configure mock objects, enabling developers to simulate specific behaviors during unit testing. The documentation details static functions for intercepting property getters, stubbing member methods, and inserting stub code into property setters. Key technical elements include argument matchers, reference tokens, and specific action selectors like `GetterActionSelector` and `MethodActionSelector`. Furthermore, it explains the parameters required for these methods, such as stub call expressions and line numbers. This resource is specifically tailored for developers and QA engineers who need to implement precise mocking strategies to validate object interactions and dependencies within their test suites.
