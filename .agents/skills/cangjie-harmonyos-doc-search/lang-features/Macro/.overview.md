# Macro

This directory provides a comprehensive guide to the Macro system within the Cangjie programming language. It covers the full spectrum of metaprogramming, ranging from basic concepts and syntax definitions to advanced implementation details and practical applications. Key topics include macro package organization, token types, quote expressions, Abstract Syntax Tree (AST) manipulation, compilation flags, and debugging strategies. This resource is suitable for Cangjie developers seeking to leverage metaprogramming for code abstraction, Domain Specific Language (DSL) creation, and advanced compiler interactions.

## Detailed Description

### Tokens_types_and_quote_expressions/
This directory serves as a comprehensive technical resource for understanding the low-level mechanisms of metaprogramming within the Cangjie programming language. It focuses specifically on the foundational data structures and syntactic features that enable developers to manipulate code at the token level, providing the necessary groundwork for building robust macros.

### builtin_compilation_flags/
This directory serves as a comprehensive repository for documentation regarding the built-in compilation flags within the Cangjie programming language. It covers essential metaprogramming attributes, API deprecation strategies, and compiler behavior configuration, offering developers the tools needed to control how macros are compiled and processed.

### compiling_error_reporting_and_debugging/
This directory serves as a comprehensive resource for understanding the compilation, error reporting, and debugging frameworks within the Cangjie programming language. It specifically addresses the complexities associated with macro programming, offering guidance on how to effectively track down issues and report errors during the macro expansion phase.

### defining_and_importing_macro_package/
This directory delves into the core mechanisms of the macro package system in the Cangjie language, focusing on definition rules, visibility control, and import mechanisms. The documentation details the syntax of the `macro package` declaration, distinguishes visibility between macro and non-macro declarations, and clarifies strict rules regarding re-exports between packages. Key points include that macro packages only allow macro definitions to be externally visible and the differences in re-export permissions between macro and non-macro packages. Additionally, it uses multi-package dependency cases to demonstrate how to use the re-export mechanism to simplify dependency management for macro users. This technical guide is designed for Cangjie developers, especially those needing to write, maintain, or use macros, to help them better understand modular programming.

### implementation_of_macros/
This directory serves as a comprehensive technical resource for understanding the implementation of macro systems, with a specific focus on the Cangjie programming language. It provides a deep dive into the architecture of metaprogramming, covering essential internal processes and design patterns that power the macro functionality.
