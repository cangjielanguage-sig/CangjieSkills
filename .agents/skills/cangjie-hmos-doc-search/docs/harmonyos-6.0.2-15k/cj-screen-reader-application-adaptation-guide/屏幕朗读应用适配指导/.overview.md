# 屏幕朗读应用适配指导

This directory provides a comprehensive technical guide for developers implementing accessibility features, specifically screen reading, in applications using the Cangjie language and ArkUI framework. It covers essential scenarios such as dynamic content announcements, multi-dimensional nesting, multilingual support, button labeling, and composite UI grouping. Key topics include AccessibilityKit usage, focus management, and event handling. It is suitable for mobile application developers aiming to optimize their apps for visually impaired users and ensure compliance with accessibility standards.

## Detailed Description

### 内容动态变化场景_3more.md 内容动态变化场景_3more.md
This document serves as a technical guide for developers implementing accessibility features in applications using the Cangjie language. It focuses on three specific scenarios: dynamic content changes requiring real-time announcements, control state updates such as play/pause toggles, and error reporting that goes beyond visual color cues. Key takeaways include code examples utilizing the AccessibilityKit to send active events via EventInfo, updating accessibilityText for state changes, and using accessibilityGroup to combine related elements. The document targets application developers aiming to improve user experience for visually impaired users by ensuring critical interface changes are audibly announced.

### 多维嵌套场景.md 多维嵌套场景.md
This document provides a guide on optimizing accessibility for multi-dimensional nested UI components to prevent redundant screen reading. It illustrates the common issue where nested focusable objects cause repetitive content announcements, increasing user effort. The content features a comparative code example in Cangjie, contrasting incorrect behavior with the correct implementation using the `accessibilityGroup` property. Key takeaways include unifying descriptions on parent controls and disabling focus on child elements to ensure concise information delivery. This guide targets developers working on accessible UI design within the Cangjie framework.

### 多语种场景_3more.md 多语种场景_3more.md
This technical guide provides best practices and implementation examples for accessibility features in Cangjie applications, specifically focusing on multilingual support, control movement feedback, and focus management. The document covers three main scenarios: handling multilingual text annotations to ensure correct reading order (especially for RTL languages), providing real-time audio feedback during control position adjustments, and programmatically resetting focus when controls disappear. Key information includes the necessity to match annotation languages with the app interface to avoid concatenation errors and the requirement to interrupt previous announcements during drag operations. It provides Cangjie code examples demonstrating how to use the sendAccessibilityEvent function with EventInfo parameters like customId to request focus for specific components. This guide is intended for developers using the Cangjie language and AccessibilityKit to build inclusive applications for visually impaired users.

### 按钮标注场景.md 按钮标注场景.md
This document serves as a technical guide for developers on implementing accessibility labels for non-text button controls in the Cangjie programming language. Main topics include the necessity of labeling interactive elements, specific content restrictions for labels, and a code example demonstrating the `accessibilityText` property. Key information highlights that labels must not include control types or instructional text like "double tap," as the screen reader appends these automatically. The document targets application developers using the UIKit framework who need to ensure their applications are accessible to visually impaired users utilizing screen readers.

### 插画视频动画的播报场景.md 插画视频动画的播报场景.md
This technical guide instructs developers on implementing accessibility screen reading for composite UI elements like illustrations and list items. It covers grouping illustrations with functional descriptions and handling list or grid items to ensure complete information is broadcast. The key takeaway is using the accessibilityGroup(true) attribute to merge images and text into a single focusable object, ensuring screen readers announce combined context rather than isolated elements. Targeted at UI developers using the Cangjie or ArkUI framework, this document provides code examples to optimize applications for users requiring assistive technologies.

### 概述_3more.md 概述_3more.md
This document serves as a development guide for implementing Screen Reader accessibility features to assist visually impaired users. It covers core accessibility principles, scenarios for labeling screen reading content, and methods to disable focus for decorative elements. Key information includes the priority of accessibilityText over display text for voice feedback and the use of .accessibilityLevel("no") to hide non-interactive UI components. The guide provides Cangjie code examples demonstrating how to set these properties. The target audience is mobile application developers using the ArkUI framework who need to ensure their applications provide logical navigation and clear voice feedback for accessibility compliance.

### 组合场景.md 组合场景.md
This technical guide instructs developers on optimizing accessibility for composite UI components by grouping them into a single focusable element. It covers the principles of semantic aggregation to reduce information redundancy and improve touch navigation performance. The document provides a comparative code example in Cangjie, demonstrating how to use the `accessibilityGroup` property to disable child focus and enable consolidated screen reading. Key takeaways include setting `accessibilityGroup(true)` on parent containers and using `accessibilityText` to customize the announcement content. Intended for UI developers, this guide ensures efficient and logical accessibility implementation for complex interfaces.
