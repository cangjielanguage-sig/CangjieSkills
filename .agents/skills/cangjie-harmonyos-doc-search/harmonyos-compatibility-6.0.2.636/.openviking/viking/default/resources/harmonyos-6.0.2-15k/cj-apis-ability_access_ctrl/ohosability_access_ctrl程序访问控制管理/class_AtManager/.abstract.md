This directory contains API reference documentation for the `AtManager` class and related permission management functions in the Cangjie language for HarmonyOS. It covers access control, verifying application permissions, and requesting user consent for system features like recording or photography. Key topics include checking access tokens, displaying global switch dialogs, and handling runtime permission requests. This documentation is suitable for system and application developers implementing security checks and managing authorization states within the `SystemCapability.Security.AccessToken` framework.
