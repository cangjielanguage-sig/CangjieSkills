# 基础类型定义

This directory defines the fundamental types and configurations for semi-modal pages (Sheets) within the Cangjie ArkUI framework. It covers essential classes for binding options, title settings, and general sheet properties, alongside enumerations for display styles. Key topics include lifecycle callbacks, visual customization, drag behaviors, and animation controls. These definitions are crucial for developers building interactive UI components that require precise control over modal presentation, dismissal logic, and layout sizing. It is suitable for UI developers and system architects working with the Cangjie language to create sophisticated application interfaces.

## Detailed Description

### class_BindOptions_3more.md class_BindOptions_3more.md
This API reference document defines classes for configuring and managing semi-modal page behaviors in the Cangjie ArkUI framework. It details `BindOptions` for setting background colors and lifecycle callbacks like `onAppear` and `onDisappear`, alongside `DismissSheetAction` and `SheetDismiss` for handling close events. Key information includes the specific parameters for visual customization and animation hooks, with a warning against modifying state variables in `onWillDisappear`. The document also explains how to use the `dismiss()` method to programmatically close panels. Intended for UI developers, this guide provides the necessary tools to implement interactive semi-modal components with precise control over their appearance and dismissal logic.

### class_SheetTitleOptions_5more.md class_SheetTitleOptions_5more.md
This document serves as API reference documentation for configuring semi-modal panels (Sheets) within the ArkUI framework using the Cangjie language. It details the SheetTitleOptions class for setting titles, the SpringBackAction class for controlling close animations, and enumerations for ScrollSizeMode, SheetMode, and SheetSize. Key information includes parameters for main and subtitles, methods for triggering spring-back effects, and options for scroll refresh timing, display hierarchy, and height presets. The EMBEDDED mode specifically requires mounting on Page or NavDestination nodes. Intended for UI developers, this reference assumes familiarity with Cangjie syntax and component lifecycle management.

### enum_SheetType.md enum_SheetType.md
This document serves as API reference for the Cangjie SheetType enum, used to configure the display style of semi-modal sheets in ArkUI. It details three specific enumeration values: BOTTOM, CENTER, and POPUP, each defining a distinct sheet behavior. Key information includes the specific functionality of the POPUP type, which acts as a follow-hand sheet but does not support follow-hand sliding or closing via downward swipes. All values require SystemCapability.ArkUI.ArkUI.Full starting from version 12. This reference is intended for UI developers using the Cangjie language to build ArkUI interfaces.

### class_SheetOptions/
This directory provides comprehensive API reference documentation for the `SheetOptions` class within the Cangjie language and ArkUI framework. It is specifically designed to assist developers in configuring optional properties for semi-modal pages, commonly referred to as sheets. The content covers a wide array of configuration parameters, including visual styling elements like colors and borders, layout sizing such as height and width detents, interaction behaviors like drag bars, and lifecycle event callbacks for appearance and dismissal. This documentation is essential for UI developers and system architects aiming to build sophisticated ArkUI applications, ensuring they can fully customize the presentation and behavior of sheet components. It targets system capabilities starting from version 12, offering the necessary technical details for advanced interface design and ensuring compatibility with the latest framework features.
