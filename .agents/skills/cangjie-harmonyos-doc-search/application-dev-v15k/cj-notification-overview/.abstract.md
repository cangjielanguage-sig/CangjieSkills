This directory contains documentation for the Notification Kit, a service designed for HarmonyOS application developers to publish local notifications directly to user devices. It covers essential topics such as usage scenarios, core capabilities, business workflows, notification styles, and system constraints. Key concepts include user authorization requirements, specific frequency limits, and the distinction between local and cloud-based notifications. The guide is suitable for developers implementing alerts for foreground scenarios like progress updates and payment notifications, and it references related kits like Push Kit and BackgroundTask Kit for extended functionality. This resource serves as a foundational guide for understanding how to effectively manage and display notifications within the HarmonyOS ecosystem, ensuring compliance with system constraints while optimizing user engagement through timely alerts. It is intended for HarmonyOS application developers seeking to enhance user interaction through system-level alerts.
