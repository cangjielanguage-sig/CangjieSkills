This directory focuses on the technical implementation of safe area calculations and avoidance adaptation for web pages within the ArkUI framework. It addresses the critical challenge of layout conflicts caused by immersive mode and system UI elements, such as status and navigation bars. Key topics include the `expandSafeArea` attribute, `viewport-fit` meta tags, and CSS `env()` functions for precise layout adjustment. This resource is suitable for developers using the Cangjie language and ArkWeb kernel who need to ensure content visibility and seamless user experiences on devices with irregular screens or immersive layouts.
