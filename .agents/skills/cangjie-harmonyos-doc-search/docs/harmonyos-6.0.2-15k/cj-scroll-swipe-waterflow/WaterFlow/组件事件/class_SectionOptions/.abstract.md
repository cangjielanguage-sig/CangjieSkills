This directory provides comprehensive API documentation for the `SectionOptions` class within the ArkUI framework, specifically tailored for developers using the Cangjie language. It details the configuration of grouping parameters for FlowItems, facilitating the creation of sophisticated WaterFlow layouts. The content covers class definitions, initialization constructors, and essential properties for layout customization, including item counts, cross counts, gaps, margins, and dynamic sizing callbacks. It supports both vertical and horizontal orientations, defining structural boundaries and spacing. This documentation is intended for UI developers aiming to implement complex list or grid layouts starting from API version 19.
