This directory contains comprehensive API reference documentation for the `AdDisplayOptions` class within the Cangjie programming language, specifically designed for the AdsKit framework. It provides essential resources for developers looking to configure and customize advertisement display behaviors in their applications. The documentation covers critical aspects such as managing video audio focus, implementing muting options, setting up mobile data usage reminders, and handling custom data for server-side reward verification. Additionally, it explains how to control ad refresh intervals through extra attributes. This content is suitable for software developers and engineers working with the Advertising system capability (version 19 or higher) who need to fine-tune ad interactions and user experience settings. A solid understanding of Cangjie syntax and the AdsKit environment is recommended for effective implementation of these advertising features. The included files detail both the constructor signature and the class properties.
