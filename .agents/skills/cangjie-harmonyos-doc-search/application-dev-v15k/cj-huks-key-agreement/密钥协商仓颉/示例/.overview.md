# 示例

This directory contains practical code examples for the HarmonyOS Universal Keystore Service (HUKS) and Universal Keystore Kit, written in the Cangjie programming language. It focuses on cryptographic operations, specifically asymmetric key agreement algorithms like X25519 and Diffie-Hellman (DH). The examples cover essential workflows such as key generation, session management (init, update, finish), key export, and lifecycle management including deletion. These resources are suitable for developers working within the OpenHarmony ecosystem who need to implement secure key exchange mechanisms and manage cryptographic keys effectively in their applications.

## Detailed Description

### 示例_1.md
This document provides a Cangjie code example demonstrating how to perform X25519 asymmetric key agreement using the UniversalKeystoreKit. The content focuses on defining key aliases, configuring parameter sets for key generation, and setting up properties for the key agreement process. Key information includes specific HuksParam configurations for the X25519 algorithm, key sizes, and the derivation of an AES-256 shared key. The example also illustrates helper functions for data conversion and error handling. This tutorial is intended for developers working with cryptographic operations in the Cangjie programming language who need to implement secure key exchange mechanisms.

### 示例_2.md
This document provides a code example demonstrating the implementation of key lifecycle management using the HUKS (HarmonyOS Universal Keystore Service) API. It covers key generation, session management (initialization, update, finish), key export, and key deletion. The code pairs internal HUKS function calls with public wrapper functions that handle error logging and exception management using a throwObject mechanism. It illustrates the standard three-stage operation process for cryptographic operations. This is intended for HarmonyOS application developers looking to implement secure cryptographic operations and key management in their applications.

### 示例_3.md
This document serves as a technical tutorial demonstrating the implementation of Diffie-Hellman (DH) key agreement using the Universal Keystore Kit (HUKS) in the Cangjie language. It covers the complete workflow including key generation, public key export, and the three-stage agreement process (Init, Update, Finish). Key sections include parameter definitions for DH2048, the `HuksDhAgreeExportKey` function for deriving shared secrets, and a test function verifying that both parties derive the same key. The document is intended for developers implementing secure cryptographic exchanges, providing practical code examples for data conversion and session management within the OpenHarmony ecosystem.

### 示例_4.md
This document provides a code example demonstrating how to perform Diffie-Hellman (DH) key agreement within the HarmonyOS Universal KeyStore (HUKS). It covers the implementation of the `HuksDhAgreeInHuks` function and a corresponding test function `HuksDhAgreeInHuksTest`. The code details the three-phase session process: initializing with storage and algorithm parameters, updating with the peer's public key, and finishing to generate a 256-bit AES key stored under a specific alias. It highlights the use of `HuksParam` for configuration and `initSession`, `updateSession`, and `finishSession` APIs. This technical reference is intended for developers implementing cryptographic key exchange in HarmonyOS applications.

### 示例_5.md
This code example demonstrates the implementation of Diffie-Hellman (DH) key agreement using the HarmonyOS Universal Keystore (HUKS) API. The document outlines a complete workflow involving generating asymmetric key pairs for two entities (Alice and Bob), exporting their public keys, and performing key agreement. It specifically highlights two scenarios: returning the agreed key to the application and storing it directly within HUKS. Key takeaways include the usage of functions like generateKeyItem, exportKeyItem, and HuksDhAgreeInHuks, along with proper key lifecycle management such as existence checks and deletion. This tutorial is designed for developers implementing secure cryptographic exchanges in HarmonyOS applications.
