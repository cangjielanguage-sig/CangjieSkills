This directory contains API reference documentation for the `ohos.ability.interop` module, focusing on interoperability between Cangjie and ArkTS in HarmonyOS applications. It covers mechanisms for converting system objects, specifically Context types and WantAgent, between Cangjie and JavaScript environments. Key topics include the `JSSystemObjectInteropType` interface, `JSValue` conversions, and specific functions for creating Context instances from JS values. This documentation is intended for HarmonyOS developers working with API level 19 and above who need to integrate ArkTS components with native Cangjie code.
