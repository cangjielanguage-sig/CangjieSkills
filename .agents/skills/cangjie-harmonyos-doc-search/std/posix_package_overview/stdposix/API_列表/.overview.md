# API_列表

This directory serves as a comprehensive technical reference for system-level programming APIs, specifically focusing on POSIX standards and their implementations. It provides detailed documentation for essential programming functions and constants used for low-level operations such as file system manipulation, process management, and access control. A significant emphasis is placed on deprecated interfaces, offering valuable insights for legacy code maintenance and ensuring cross-platform compatibility across Linux, macOS, and Windows environments. This resource is primarily designed for software developers maintaining older codebases, system programmers, and engineers involved in migrating away from obsolete interfaces. The content is organized into two main subdirectories: one for function definitions and another for constant values.

## Detailed Description

### [1] 函数/
This directory contains documentation regarding programming functions, with a specific focus on POSIX system-level APIs. It covers a wide range of operations including file system manipulation (open, read, write, unlink), process management (getpid, kill), and system queries. A significant portion of the content serves as a reference for deprecated functions, providing signatures, descriptions, and platform compatibility (Linux, macOS, Windows) for legacy code maintenance. It is suitable for developers working on system-level programming, maintaining older codebases, or migrating away from obsolete interfaces.

### [2] 常量/
This directory contains documentation and reference materials for programming constants, primarily focusing on deprecated POSIX standards. It covers immutable values used in file system operations, access control, signal handling, and process control. The content includes general introductions to constants as well as specific reference tables detailing flags like O_CREAT, signal types like SIGKILL, and permission modes like S_IRUSR. These resources are designed for software developers maintaining legacy code or working with cross-platform system programming on Linux, Windows, and macOS.
