This directory serves as a comprehensive technical repository for specifications regarding asymmetric key generation and conversion within the Cangjie framework, specifically targeting API 12 and later. It encompasses a wide array of major cryptographic algorithms, including RSA, DSA, ECC, Diffie-Hellman, SM2, Ed25519, and X25519. The documentation provides in-depth outlines for methods of key generation, utilizing both string parameters and specific key attributes. It rigorously details necessary constraints, supported key lengths, and parameter requirements to ensure compliance and security. This resource is primarily suitable for developers and system architects who are integrating cryptographic functions into Cangjie applications, ensuring the secure implementation of digital signatures, key exchange protocols, and encryption workflows.
