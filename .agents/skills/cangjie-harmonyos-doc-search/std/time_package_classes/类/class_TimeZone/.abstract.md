This directory contains comprehensive API reference documentation for the `TimeZone` class within the Cangjie programming language's time package. It covers the representation and management of time zones, including system local time, UTC, and custom zones. Key topics include class definition, static properties, initialization constructors, instance methods like `toString`, comparison operators, and static loading functions for system or custom time zone data. This documentation is suitable for Cangjie developers who need to handle time zone conversions, system time settings, and loading IANA time zone data in their applications.
