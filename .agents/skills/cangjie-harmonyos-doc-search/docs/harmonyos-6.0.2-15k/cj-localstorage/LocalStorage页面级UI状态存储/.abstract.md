This directory provides comprehensive documentation and guides for implementing LocalStorage, a page-level UI state storage mechanism within the Cangjie framework. It covers the core concepts of using LocalStorage as an in-memory database for managing state across component trees. Key topics include the `@LocalStorageLink` and `@LocalStorageProp` decorators for data synchronization, lifecycle management, and specific usage constraints. The content is designed for developers working with HarmonyOS applications who need to handle reactive state management, complex data types, and state sharing between views and UIAbility instances.
