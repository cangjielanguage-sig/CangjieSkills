This directory contains a comprehensive technical guide designed for Cangjie developers operating within the HarmonyOS ecosystem. It specifically addresses the interoperability between Cangjie and ArkTS, providing the necessary instructions to invoke ArkTS modules directly from Cangjie code. The content centers on utilizing the `ohos.ark_interop` library to facilitate this bridging process. Key areas of focus include the initialization of the ArkTS runtime, the mechanism for importing system native modules—such as `@ohos.file.photoAccessHelper`—and the subsequent invocation of their methods. This resource is essential for developers looking to extend their Cangjie applications by leveraging existing ArkTS capabilities, covering critical steps like creating a JSRuntime, accessing the main context, and utilizing `requireSystemNativeModule` to obtain a JSValue for method execution.
