This module provides the foundational Bluetooth profile functionality for HarmonyOS applications developed in the Cangjie language. It encompasses essential data structures and interfaces for managing Bluetooth connections, handling state changes, and diagnosing disconnection causes. Key components include enums for connection states and callback types, as well as the core `BaseProfile` interface for event subscription. This documentation is tailored for Cangjie developers integrating Bluetooth features using the ConnectivityKit, offering the necessary APIs to implement robust connectivity, manage permissions, and handle asynchronous profile events effectively.
