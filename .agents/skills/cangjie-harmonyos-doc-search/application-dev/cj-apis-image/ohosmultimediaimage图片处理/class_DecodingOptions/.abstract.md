This directory provides comprehensive API documentation for the `DecodingOptions` class within the Cangjie multimedia framework. It serves as a technical reference for configuring image decoding parameters, enabling developers to manipulate output specifications such as pixel format, dimensions, rotation, and color space. The documentation highlights advanced features like partial decoding for performance optimization and multi-frame image selection. It also details specific constraints, such as support for formats like RGBA8888. This resource is specifically tailored for software engineers and developers involved in multimedia image processing who require precise control over image decoding, transformation, and rendering workflows.
