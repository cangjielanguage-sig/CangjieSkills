# cj-using-audiocapturer-for-recording

This directory serves as a specialized technical resource for developers implementing audio recording capabilities within the HarmonyOS ecosystem, specifically utilizing the AudioCapturer module. It focuses on the capture of raw PCM audio data, providing developers with granular control over the audio input process, which is essential for high-fidelity audio applications. The content covers the entire development lifecycle, from initial parameter configuration and state management to resource release, ensuring stability and performance. It includes practical code examples written in both Cangjie and ArkTS to accommodate different development preferences. This guide is primarily suitable for application developers and HarmonyOS engineers who possess prior audio development experience and need to integrate robust, high-quality audio capture features into their applications. By leveraging these resources, developers can effectively manage microphone permissions and handle PCM data streams to build professional-grade recording tools.
