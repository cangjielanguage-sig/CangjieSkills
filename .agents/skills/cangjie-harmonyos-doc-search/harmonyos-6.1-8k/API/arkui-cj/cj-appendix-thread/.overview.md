# cj-appendix-thread

本目录提供了关于仓颉语言在OpenHarmony应用开发中线程控制机制的详细文档。它主要解决了UI逻辑必须在UI线程执行这一核心需求，涵盖了模块导入、UI线程上下文实例`UIThread`、用于向主线程提交任务的`launch`函数以及`MainThreadContext`类的使用。文档深入解释了仓颉用户态线程与OS线程无显式绑定的特性，以及由此产生的自定义调度需求。该文档适合正在使用仓颉语言进行OpenHarmony应用开发的开发者阅读，属于API参考类资料，旨在帮助开发者理解并实现跨线程的任务调度与上下文管理。

## 详细描述

### cj-appendix-thread.md cj-appendix-thread.md
本文档介绍了仓颉语言在OpenHarmony应用开发中的线程控制机制，旨在解决UI逻辑必须在UI线程运行的问题。主要内容包括导入模块说明、UI线程上下文实例UIThread、用于提交任务到主线程的launch函数以及MainThreadContext类。文档指出仓颉用户态线程与OS线程无显式绑定，因此需自定义调度。核心功能包括通过launch函数将任务提交至主线程执行，以及使用MainThreadContext管理线程上下文。适用于使用仓颉开发OpenHarmony应用的开发者，属于API参考文档。
