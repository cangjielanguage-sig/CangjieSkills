This directory serves as a technical guide for developers working on HarmonyOS applications, focusing on the interoperability between the Cangjie and ArkTS programming languages. It specifically addresses the mechanisms required to import and load ArkTS modules within Cangjie code. Key topics include the `JSContext.requireArkModule` interface, dynamic loading strategies for various module types (HAR, HSP, Native, System, HAP), and specific configuration files like `oh-package.json5`. The documentation also highlights critical usage restrictions, such as thread limitations and initialization constraints. This resource is essential for developers aiming to achieve seamless cross-language communication and manage complex dependencies in their applications.
