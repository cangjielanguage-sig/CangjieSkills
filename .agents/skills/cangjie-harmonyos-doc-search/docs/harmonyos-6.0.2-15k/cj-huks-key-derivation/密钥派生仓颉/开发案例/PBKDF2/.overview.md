# PBKDF2

This directory serves as a comprehensive guide for developers looking to implement PBKDF2 (Password-Based Key Derivation Function 2) within the HarmonyOS environment. It focuses on the practical application of the Universal Keystore Service (HUKS) and UniversalKeystoreKit to securely derive cryptographic keys from passwords or passphrases. The provided materials cover the entire cryptographic lifecycle, from generating base keys and configuring parameters like salt and iteration counts to managing derivation sessions and handling errors. Key technical aspects include the use of HUKS tags for algorithm specification and the storage of derived AES keys. This resource is particularly suitable for software engineers and security architects working with Cangjie or native HarmonyOS APIs who require robust solutions for secure key generation and data encryption. By utilizing these examples, developers can effectively integrate standardized key derivation mechanisms into their applications to enhance security and protect sensitive user data.

## Detailed Description

The following files provide specific code implementations and detailed walkthroughs for PBKDF2 key derivation scenarios. These examples are designed to be directly integrated into development workflows.

### PBKDF2_1.md PBKDF2_1.md
This document provides a Cangjie code example demonstrating how to perform PBKDF2 key derivation using the UniversalKeystoreKit. The content covers the configuration of parameter sets for three distinct stages: generating a base key, initializing the derivation session with specific PBKDF2 attributes like salt and iteration count, and finalizing the session to store the derived AES key. Key takeaways include the use of HUKS tags for algorithm specification, key storage flags, and the multi-step API interaction pattern. This tutorial is intended for developers implementing secure cryptographic key derivation within HarmonyOS applications.

### PBKDF2_2.md PBKDF2_2.md
This document illustrates the implementation of PBKDF2 key derivation using the HarmonyOS Universal Keystore Service (HUKS) API. It details wrapper functions for session operations like update, finish, and key deletion, emphasizing a specific error-handling pattern using a throwObject. The core content is the testDerive function, which demonstrates the complete cryptographic lifecycle: generating a source key, initializing the derivation, updating the session, finalizing to get the result, and deleting the key. This code snippet serves as a practical reference for developers building secure applications on the HarmonyOS platform.
