# run

本目录提供了仓颉语言可执行程序的运行指南，旨在帮助开发者在不同环境下成功执行程序。内容涵盖了 Linux、macOS 和 Windows 系统上的具体操作步骤，主要分为直接运行和使用 cjpm 运行两种模式。文档详细阐述了运行前必须进行的运行时库部署、如何定位编译产物路径，以及使用 cjpm 时所需的完整工具链安装和特定命令执行。该指南适合已完成编译并准备进行程序测试或部署的仓颉开发者，提供了从二进制文件直接执行到项目级运行管理的全流程操作参考。

## 详细描述

### run.md

本文档旨在指导用户如何在 Linux、macOS 及 Windows 系统上运行仓颉语言的可执行程序。主要包含直接运行和使用 cjpm 运行两种方式，涵盖了不同操作系统的具体操作步骤。关键信息包括运行前需先部署运行时库，直接运行需定位编译产物路径，而使用 cjpm 则需安装完整工具链并执行特定命令。适用于已完成编译的仓颉开发者，提供了从二进制文件执行到项目级运行的全流程指南。
