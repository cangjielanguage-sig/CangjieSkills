This directory serves as a comprehensive resource for the `cj-macro-link` project, focusing specifically on the `@Link` macro within the Cangjie UI and ArkUI development ecosystems. It addresses the critical need for implementing two-way data binding between parent and child components, a fundamental requirement for building reactive and interactive user interfaces. The content covers essential technical concepts such as state synchronization, variable transfer protocols, and observation mechanisms for various data types including primitives, classes, and arrays. It is specifically designed for developers who are already familiar with the `@State` decorator and need to manage reactive state more effectively, ensuring seamless bidirectional data flow across complex component hierarchies.
