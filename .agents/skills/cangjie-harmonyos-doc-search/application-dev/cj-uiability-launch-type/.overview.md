# cj-uiability-launch-type

This directory provides a technical overview of the launch modes available for UIAbility components, a fundamental aspect of application architecture. It thoroughly explains how the system manages component instances during the startup process, distinguishing between the "singleton" mode—which optimizes resources by reusing existing instances—and the "multiton" mode, which creates separate instances for distinct tasks. The documentation covers the implications of these modes on lifecycle callbacks, specifically `onNewWant()`, and their effect on the task list. By providing configuration examples for `module.json5`, this guide enables application developers to fine-tune their application's behavior. It is suitable for developers seeking to implement specific business logic requirements regarding instance management and user interface state, ensuring the app meets diverse user needs.

## Detailed Description

### cj-uiability-launch-type.md cj-uiability-launch-type.md

This document serves as a comprehensive guide for defining the launch modes associated with UIAbility components, with a specific focus on the rules governing system instance management during the application startup process. It provides an in-depth explanation of the two primary modes: "singleton" and "multiton." The singleton mode is described as the default behavior, where the system maximizes efficiency by reusing existing instances and triggering the `onNewWant()` callback. In contrast, the multiton mode is detailed as a configuration that creates a brand new instance for every `startAbility()` call. The document supports these concepts with specific configuration examples for the `module.json5` file, allowing for immediate practical application. Targeted directly at application developers, this guide is essential for controlling the UIAbility lifecycle and managing the component's presence in the task list, ensuring that the application behaves correctly according to specific business scenarios. Keywords: UIAbility, launch mode, singleton, multiton, module.json5, startAbility, onNewWant.
