# class_HceService

This directory contains API reference documentation for the Cangjie `HceService` class, designed to facilitate Host Card Emulation (HCE) functionality. It covers the management of APDU data exchange with NFC readers, including service initialization, lifecycle management, and asynchronous data transmission. Key topics include subscribing to APDU commands, setting foreground priority, registering AID lists, and resource cleanup. The documentation is essential for Cangjie developers building NFC-based applications that require card emulation capabilities, providing necessary details on permissions, system capabilities, and error handling.

## Detailed Description

### class_HceService_3more.md class_HceService_3more.md
This document serves as API reference documentation for the Cangjie HceService class, which implements Host Card Emulation (HCE) to manage APDU data exchange with NFC readers. The main sections detail the class overview and two primary methods: on for subscribing to incoming APDU command callbacks, and start for initializing the service, setting foreground priority, and registering AID lists. Key information includes the mandatory ohos.permission.NFC_CARD_EMULATION permission, system capability requirements, and specific error codes for exception handling. The document provides a practical code example demonstrating the integration within a UIAbility lifecycle. It targets Cangjie developers building NFC-based applications requiring card emulation capabilities.

### func_stopElementName.md func_stopElementName.md
This API reference document details the stop function used to terminate Host Card Emulation (HCE) services in Cangjie applications. The documentation covers the function signature, required permissions, system capabilities, input parameters, and potential business exceptions with specific error codes. Key takeaways include that the function cancels APDU subscriptions, exits foreground priority, and releases dynamically registered AID lists. It is mandatory to call this interface within the onDestroy lifecycle method of the HCE card emulation page. The target audience is HarmonyOS developers implementing NFC features who need to manage resource cleanup and application states effectively.

### func_transmitArrayUInt8_Callback0Argument.md func_transmitArrayUInt8_Callback0Argument.md
This API reference document details the transmit function for sending APDU data to a remote card reader asynchronously in Cangjie applications. The documentation covers the function signature, functionality, required permissions, system capabilities, parameters, and specific error codes. Key information includes the requirement for the ohos.permission.NFC_CARD_EMULATION permission and the constraint that this function must be called only after receiving APDU data via the on method. It takes a byte array for the response and a callback to handle the result. Intended for developers implementing NFC card emulation, the document includes a Cangjie code example demonstrating the implementation of callbacks and lifecycle management within a UIAbility.
