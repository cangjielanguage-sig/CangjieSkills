This directory provides API reference documentation for the Cangjie language and ArkUI framework, focusing on the implementation of AlertDialog components with two confirmation buttons. It covers the `init()` constructor, detailed parameter configurations, and the `secondaryButton` variable for customizing button attributes. Key topics include system capabilities, version requirements, and UI styling constraints. This resource is designed for HarmonyOS developers and UI engineers who need to build interactive, customized modal windows and popups, offering technical specifications for event handling, layout, and visual properties within the ArkUI framework.
