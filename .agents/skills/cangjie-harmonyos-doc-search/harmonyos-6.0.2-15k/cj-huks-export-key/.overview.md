# cj-huks-export-key

This directory serves as a comprehensive technical resource for Cangjie developers working with the Universal Keystore Kit (Huks). It specifically addresses the requirements and procedures for exporting public keys from persistent asymmetric keys. The guide thoroughly details the supported cryptographic algorithms, including ECC, RSA, and SM2, while noting that lightweight devices are exclusively limited to RSA support. It outlines a precise three-step development workflow: defining a key alias, invoking the exportKeyItem interface, and handling the resulting HuksReturnResult. Additionally, the document specifies that the public key is returned in the standard X.509 DER format and provides a complete, executable code example. This tutorial is essential for developers who need to access and utilize key material for secure business operations within the Cangjie ecosystem.
