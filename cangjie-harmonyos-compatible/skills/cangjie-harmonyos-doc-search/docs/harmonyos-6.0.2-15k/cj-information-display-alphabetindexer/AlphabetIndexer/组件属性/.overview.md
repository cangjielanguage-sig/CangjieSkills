# 组件属性

This directory contains API reference documentation for configuring the properties of the Indexer component within the ArkUI framework using the Cangjie language. It covers a wide range of customization options, including alignment styles, font settings, popup window appearance, and the visual state of selected items. Developers can find detailed parameters for adaptive folding, haptic feedback, and color schemes. The documentation is intended for HarmonyOS UI developers who need to programmatically style and control the behavior of index bars and their associated popups in their applications.

### func_alignStyleIndexerAlig_5more.md func_alignStyleIndexerAlig_5more.md

### func_popupFontLength_FontW_5more.md func_popupFontLength_FontW_5more.md
This document serves as an API reference for configuring the visual style of popup windows and their secondary index items within the ArkUI framework using the Cangjie language. It details five specific functions: two overloads for popupFont (handling String and AppResource font families), popupItemBackgroundColor, popupItemBorderRadius, and popupItemFont. The functions allow customization of font attributes like size, weight, and family, as well as background colors and border radii. Key takeaways include specific default values, such as 24.vp for font size, and the adaptive behavior of the border radius. This technical reference is intended for developers building UI components in HarmonyOS who need to programmatically style popup interactions.

### func_popupItemFontLength_F_6more.md func_popupItemFontLength_F_6more.md

It details functions for setting font styles, popup positioning, and color schemes for selected and unselected items, as well as title backgrounds. Intended for ArkUI developers, this guide facilitates the customization of visual feedback in indexers, requiring prior knowledge of Cangjie syntax and UI resource management.

### func_selectedBackgroundCol_5more.md func_selectedBackgroundCol_5more.md
This API reference document details Cangjie functions for configuring the visual appearance and behavior of selected items within an ArkUI component. It covers five specific functions: selectedBackgroundColor, selectedColor, two overloads of selectedFont, and usingPopup. The functions allow customization of background and text colors, font attributes including size, weight, family, and style, as well as popup usage. Default values are provided, such as a blue background (0x1A007DFF) and specific font settings, while the selectedFont method supports both string and AppResource types for font families. This is intended for HarmonyOS developers using the Cangjie language to style UI components starting from API version 12.
