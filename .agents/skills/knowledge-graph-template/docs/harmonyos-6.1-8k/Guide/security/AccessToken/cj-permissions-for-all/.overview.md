# cj-permissions-for-all

This directory serves as a comprehensive technical guide for the HarmonyOS permission system, specifically focusing on permissions that are openly available to all applications. It details the `system_grant` mechanism, explaining how certain permissions are automatically approved during the app installation process, thereby removing the need for manual user authorization and streamlining the onboarding experience. The documentation covers strict permission definitions, the absence of ACL enable fields in `normal` level permissions, and specific application guidelines. It is an essential resource for HarmonyOS developers working with API 12 who need to implement features related to Bluetooth, network connectivity, sensors, hardware control, security, data storage, vehicle engines, and window management without triggering runtime permission prompts.

## Detailed Description

### 开放权限系统授权/
This subdirectory offers an in-depth look at the system authorization permissions that are universally open to applications in the HarmonyOS ecosystem. The content is designed to be accessible yet thorough, covering the core authorization mechanisms starting with the strict definitions of various permission types. It specifically elucidates the `system_grant` authorization mode, illustrating how the system handles permission grants automatically at the installation stage. This approach ensures a frictionless user experience by bypassing the need for manual user confirmation dialogs during runtime.

Additionally, the documentation clarifies technical nuances, such as the fact that `normal` level permissions do not require ACL (Access Control List) enable fields. The directory also acts as a centralized reference hub for API 12, aggregating permission APIs for a wide array of core functionalities. Developers will find detailed information regarding permissions for Bluetooth operations, network access, sensor data, hardware control, security detection mechanisms, data storage protocols, vehicle engine interactions, and window management systems.
