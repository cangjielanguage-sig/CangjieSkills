This directory provides comprehensive technical documentation for the `ImageBitmap` object within the Cangjie programming language, specifically targeting the UIKit and ArkUI frameworks. It covers the essential mechanisms for storing, manipulating, and managing pixel data rendered by a canvas. The documentation details module imports, API definitions, various constructors for initializing objects from local image paths or PixelMaps, and handling supported formats like JPG, PNG, and BMP. This resource is designed for software developers, application architects, and system engineers working on HarmonyOS applications who require efficient graphics memory handling and robust image processing capabilities in their graphical user interfaces. By utilizing these references, developers can effectively implement rendering operations and manage image resources within their Cangjie-based projects.
