# 开发应用沉浸式效果

This directory focuses on designing and implementing immersive UI effects for applications, specifically minimizing visual disruption from system interface elements like status and navigation bars. It covers key concepts such as avoidance areas, safe areas, and immersive modes. The content compares two primary implementation approaches: Window Full-screen Layout and Component Safe Area. It is suitable for application developers and UI designers using HarmonyOS (ArkUI, Cangjie, or ArkTS) who aim to optimize user experience through distraction-free, responsive, and full-screen layouts for media consumption or gaming.

## Detailed Description

### 概述.md 概述.md
This document provides an overview of designing and implementing immersive application UI effects to minimize the visual disruption of system interface elements like status and navigation bars. It defines key concepts such as avoidance areas and safe areas, outlines design requirements for UI avoidance and color matching, and compares two implementation approaches: Window Full-screen Layout and Component Safe Area. The Window Full-screen Layout allows elements to extend into system areas, while the Component Safe Area only extends background drawing. Developers must handle interactive element placement carefully to avoid conflicts with system information. This guide targets application developers and UI designers seeking to optimize user experience through immersive layouts.

### 窗口全屏布局方案/
This directory provides comprehensive technical specifications and implementation guides for window fullscreen layouts within HarmonyOS applications. It focuses on how applications manage system avoidance areas, detailing the differences between immersive modes that hide system UI and extended layouts that allow content to flow behind system bars. Key technical concepts include `setWindowLayoutFullScreen`, dynamic avoidance area listeners, and UI padding adjustments. These resources are specifically designed for HarmonyOS developers and UI designers using Cangjie or ArkUI who aim to build distraction-free, responsive interfaces for media consumption or gaming.

### 组件安全区方案/
This directory provides a comprehensive technical guide on managing component safe areas within the HarmonyOS ArkUI framework. It focuses on achieving immersive display effects by extending UI components into system zones like status bars and navigation bars. Key topics include the `expandSafeArea` attribute, handling scrolling containers, bottom tab scenarios, and layout adaptation strategies. The documentation is tailored for application developers using the Cangjie or ArkTS languages who need to create adaptive, full-screen layouts while effectively managing system insets and visual consistency.
