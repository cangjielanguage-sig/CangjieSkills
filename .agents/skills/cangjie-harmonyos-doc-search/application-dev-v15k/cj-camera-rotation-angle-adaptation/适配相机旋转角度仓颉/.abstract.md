This directory provides a comprehensive technical guide for developers working with camera rotation adaptation using the Cangjie programming language on HarmonyOS. It covers essential topics such as calculating device rotation angles via sensors, adapting camera previews, and handling video recording metadata to ensure correct orientation. Key concepts include CameraKit, MediaKit, gravity sensors, and display rotation synchronization. These resources are specifically designed for software engineers and application developers building responsive camera applications that require precise image alignment across various device orientations and screen states.
