This directory contains API reference documentation for the `LocalStorageInterOp` class within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the internal mechanisms for state management, focusing on LocalStorage operations such as instance retrieval, property manipulation, data binding, and lifecycle management. Key topics include two-way data synchronization, JavaScript interoperability, and property subscription rules. This documentation is intended for framework developers and advanced engineers building ArkUI applications who need to manage local state and component rendering efficiently using Cangjie.
