# 开发步骤

本目录主要介绍在HarmonyOS环境下使用仓颉语言进行密钥导入的开发步骤。涵盖了通过UniversalKeystoreKit和HUKS框架导入X25519公钥及AES256密钥的具体实现。内容包括定义密钥别名、配置密钥属性集（如算法、尺寸、用途）以及调用importKeyItem接口等核心流程。适用于需要在HarmonyOS系统中进行密钥管理的开发者，要求读者具备仓颉编程基础及密码学常识。
