This directory contains documentation for the `WrappingOp` interface in the Cangjie programming language, which defines integer arithmetic operations that handle overflow by truncating high-order bits. It covers the core interface definition and its implementations across various integer types, including signed and unsigned variants (Int8, Int16, Int32, Int64, IntNative, and their unsigned counterparts). The documentation details operations like addition, subtraction, multiplication, division, and bit shifting, ensuring deterministic behavior where results wrap around instead of causing errors. This resource is suitable for Cangjie developers working on systems programming, low-level algorithms, or performance-critical code requiring precise control over numeric overflow.
