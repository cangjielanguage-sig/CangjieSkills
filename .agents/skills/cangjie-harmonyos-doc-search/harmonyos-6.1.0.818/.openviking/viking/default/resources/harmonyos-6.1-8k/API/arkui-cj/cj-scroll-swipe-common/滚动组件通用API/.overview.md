# 滚动组件通用API

本文档集定义了ArkUI框架中滚动组件的通用属性和事件API规范，主要涵盖List、Grid和Scroll三种核心组件。内容涉及滚动交互逻辑、状态监听、边缘效果处理及视觉样式定制。文档基于Cangjie（仓颉）语言编写，适用于API 22及以上版本。主要面向HarmonyOS应用开发者，特别是需要精细控制滚动容器交互体验和实现自定义滚动逻辑的前端技术人员。

### 滚动组件通用API_17f7e9f5.md 滚动组件通用API_17f7e9f5.md
本文档旨在定义滚动组件的通用属性和事件API，为相关UI组件提供标准化的接口规范。主要内容涵盖了API的适用范围，明确指出当前通用API仅支持List、Grid和Scroll三种组件，并提及文档处于Beta阶段。关键信息在于界定了通用API的适用边界，即目前仅限于列表、网格和基础滚动视图，开发者需注意这一功能限制。文档面向使用这些特定滚动组件的前端开发人员，作为API参考指南，帮助理解组件间的通用交互逻辑和参数配置。

### 组件事件/
本目录包含ArkUI框架中Cangjie语言关于组件滚动事件的API参考文档。主要涵盖了滚动交互过程中的各类回调机制，包括滚动状态监听（如开始、停止、到达边缘）以及滚动前的拦截与处理逻辑。核心关键词包括ArkUI、Cangjie、滚动事件、onDidScroll、onWillScroll、回调函数。这些文档适合使用Cangjie语言进行ArkUI应用开发，需要精细控制滚动组件交互行为、处理边缘效果或实现自定义滚动逻辑的开发人员阅读。

### 组件属性/
本目录包含ArkUI框架中关于组件滚动交互与视觉属性的API参考文档，主要使用仓颉语言编写。内容涵盖了滚动组件的边缘渐隐效果、滑动速度限制、摩擦系数配置、父子组件嵌套滚动联动机制，以及滚动条的样式定制与内容裁剪策略。这些文档详细说明了相关函数的参数类型、默认值及行为逻辑，适用于API 22及以上版本。本目录主要面向HarmonyOS应用开发者，特别是需要精细控制List、Grid等可滚动容器交互体验和视觉效果的技术人员。
