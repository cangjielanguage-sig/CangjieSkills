This directory provides comprehensive API reference documentation for the `Action` enum within the Cangjie language framework, specifically designed for accessibility operations. It covers a wide array of supported actions, ranging from focus management and navigation to complex text manipulation and system interactions like scrolling and clicking. The documentation details specific action constants, utility functions, operator overloads for equality checks, and inheritance hierarchies from `Equatable` and `ToString`. It is essential for developers implementing accessibility services or features who need to programmatically trigger or compare system UI actions. All components require the `SystemCapability.BarrierFree.Accessibility.Core` capability and are available starting from API version 19. The files distinguish between supported and unsupported actions, providing clear guidance on implementation requirements and parameter usage for specific accessibility tasks.
