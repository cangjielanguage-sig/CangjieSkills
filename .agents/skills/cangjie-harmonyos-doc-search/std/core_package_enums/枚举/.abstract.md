This directory contains comprehensive API reference documentation for core enumerations within the Cangjie programming language. It covers essential types used for system-level features, comparison operations, and safe null handling patterns. Key topics include defining custom annotation targets via `AnnotationKind`, detecting platform-specific byte order with `Endian`, representing comparison results using `Ordering`, and handling optional values through the `Option` type. These resources are designed for Cangjie developers seeking to implement robust, type-safe applications, manage system metadata, and utilize standard library types effectively. Understanding these enumerations is crucial for writing idiomatic and error-resistant code in the Cangjie ecosystem.
