This directory contains comprehensive documentation for the `SaturatingOp` interface in the Cangjie programming language, focusing on safe integer arithmetic operations. It covers the core interface definition and its implementations across various integer types, including signed and unsigned variants (Int8, Int16, Int32, Int64, IntNative, and their unsigned counterparts). The primary focus is on saturating arithmetic strategies, where results clamp to maximum or minimum values upon overflow or underflow rather than wrapping around. This resource is essential for Cangjie developers who need predictable, bounded numerical results and robust error handling in performance-critical or safety-critical applications.
