### 收集广告过滤的信息

在Web组件的广告过滤开关开启后，访问的网页如果发生了广告过滤，会通过Web组件的[onAdsBlocked()](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-onadsblockedadsblockeddetails---unit)回调接口通知到应用，应用可根据需要进行过滤信息的收集和统计。

```cangjie
// index.cj
import ohos.state_macro_manage.*
import kit.ArkWeb.WebviewController
import kit.UIKit.Web

@Entry
@Component
class EntryView {
    let webController = WebviewController()
    @State
    var totalAdsBlockCounts: Int64 = 0

    func build() {
        Column {
            Web(src: 'https://www.example.com', controller: webController).onAdsBlocked {
                details =>
                let adsBlockedSize = details.adsBlocked.size
                AppLog.info(" Blocked size: ${adsBlockedSize} in ${details.url}")
                totalAdsBlockCounts += adsBlockedSize
                AppLog.info("Total blocked counts : ${totalAdsBlockCounts}")
            }
        }
    }
}
```

由于页面可能随时发生变化并不断产生网络请求，为了减少通知频次、降低对页面加载过程的影响，仅在页面加载完成时进行首次通知，此后发生的过滤将间隔1秒钟上报，无广告过滤则无通知。
