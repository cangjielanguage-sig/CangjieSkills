# cj-apis-file_fs-interop

This directory serves as the central hub for API documentation regarding the `cj-apis-file_fs-interop` module, specifically tailored for the HarmonyOS/OpenHarmony development environment. It focuses on the `ohos.file_fs.interop` module, which is essential for facilitating interoperability between Cangjie file management objects and ArkTS JavaScript values. The documentation thoroughly covers the core interface `JSSystemObjectInteropType` and provides detailed insights into specific implementations for `File`, `RandomAccessFile`, and `Stream` classes. Key functionalities include bidirectional type conversion methods (`toJSValue`, `fromJSValue`) and ownership transfer mechanisms. This resource is intended for HarmonyOS/OpenHarmony developers working in Cangjie who need to integrate native file I/O operations with ArkTS environments, ensuring seamless data exchange and object manipulation across language boundaries. By leveraging these APIs, developers can ensure robust cross-language communication within their applications, effectively bridging the gap between native performance and JavaScript flexibility.
