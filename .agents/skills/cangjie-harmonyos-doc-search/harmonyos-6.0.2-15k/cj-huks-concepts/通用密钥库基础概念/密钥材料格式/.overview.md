# 密钥材料格式

This directory defines the standardized formats for cryptographic key materials used within the HUKS system and OpenHarmony ecosystem. It covers the structural definitions, encoding rules, and serialization requirements for public keys, private keys, and key pairs across various algorithms like RSA, ECC, and DSA. Key topics include X.509 DER standards, byte-level memory layouts, and Cangjie programming language examples. This documentation is essential for software developers, system architects, and security engineers implementing cryptographic functions, key import/export operations, or integrating with hardware security modules.

## Detailed Description

#### 公钥材料格式.md 公钥材料格式.md
This document specifies the standard encoding format for public key material during export and import operations. It focuses on the X.509 specification and Distinguished Encoding Rules (DER), providing a concrete code example of an ECC P-256 public key represented as a byte array in the Cangjie programming language. The key information is that all key materials strictly adhere to the X.509 DER standard to ensure compatibility. This technical reference is intended for software developers and system architects implementing cryptographic functions who require knowledge of raw key data structures. Keywords: X.509, DER, ECC, Cangjie, public key, encoding, cryptography.
