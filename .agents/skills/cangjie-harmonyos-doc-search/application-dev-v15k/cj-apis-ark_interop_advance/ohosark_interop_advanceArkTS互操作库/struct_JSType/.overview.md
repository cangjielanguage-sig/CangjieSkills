# struct_JSType

This directory provides comprehensive API reference documentation for the `JSType` struct in the Cangjie language, specifically tailored for developers working within the ArkUI and N-API ecosystems. It encompasses the enumeration of ArkTS data types, defining static constants for standard JavaScript types such as UNDEFINED, NUMBER, and OBJECT, as well as specialized types like EXTERNAL. Additionally, it covers operator overloads for equality and inequality checks, alongside utility methods like `toString()`. With a system capability requirement of `SystemCapability.ArkUI.ArkUI.Napi` and support starting from version 13, this documentation is essential for developers needing to identify, compare, or manage specific data types effectively in their cross-platform applications.
