This directory contains comprehensive API reference documentation for the `ohos.rpc` module in the Cangjie language, focusing on Inter-Process Communication (IPC) and Remote Procedure Call (RPC) mechanisms. It covers essential components for building robust communication between processes, including remote object management, data serialization, shared memory, and error handling. Key topics include `IRemoteObject`, `MessageSequence`, `Parcelable`, and `Ashmem`. This documentation is suitable for Cangjie developers and system engineers working on HarmonyOS applications that require secure and efficient data exchange across processes or devices.
