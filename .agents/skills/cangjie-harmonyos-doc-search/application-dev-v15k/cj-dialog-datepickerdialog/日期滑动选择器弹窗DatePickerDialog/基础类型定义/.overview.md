# 基础类型定义

This directory serves as a comprehensive repository for basic type definitions within the Cangjie language and ArkUI framework, specifically targeting the structural configuration of dialog components. It provides the essential building blocks required to implement sophisticated user interfaces, focusing heavily on date selection mechanisms and interactive button elements. By defining these core types, developers can ensure consistency and reliability across their applications. Key topics include `DatePickerDialogOptions` for managing complex date ranges, lunar calendar integrations, and display modes, as well as `PickerDialogButtonStyle` for fine-tuning visual attributes like typography, colors, and interaction logic. This documentation is meticulously tailored for UI developers and system architects aiming to construct robust, user-centric dialog interfaces compatible with API version 19 and above, ensuring precise control over both functionality and aesthetic presentation.

## Detailed Description

### class_DatePickerDialogOptions/
This directory contains API reference documentation for the `DatePickerDialogOptions` class in the Cangjie language, designed for the ArkUI framework. It covers the configuration of date sliding picker dialogs, including properties for setting date ranges, display modes (lunar calendar, military time), and visual styles for text and buttons. The documentation also details layout parameters, event callbacks for date changes, and dialog lifecycle management. It is suitable for UI developers working on system version 19 or higher who need to implement interactive date selection components.

### class_PickerDialogButtonStyle/
This directory contains comprehensive documentation for the `PickerDialogButtonStyle` class, a critical component for developers working within the ArkUI and Cangjie frameworks. It focuses on the configuration of visual and behavioral properties for buttons used specifically in picker dialogs. The documentation covers a wide range of styling attributes, including font size, color, weight, background color, and border radius, as well as functional aspects like button roles and interaction logic. Additionally, it addresses complex scenarios such as exception handling for date validation and default key response settings. This resource is suitable for UI developers and system architects aiming to implement custom dialog interfaces, ensuring adherence to API version 19 requirements and optimizing user interaction experiences.
