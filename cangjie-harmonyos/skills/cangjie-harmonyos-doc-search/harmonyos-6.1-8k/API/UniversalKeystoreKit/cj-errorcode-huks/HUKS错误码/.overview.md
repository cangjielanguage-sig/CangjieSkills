# HUKS错误码

本目录包含HUKS（Harmony Universal KeyStore）模块的错误码参考文档，旨在帮助开发者诊断和解决密钥操作中的异常问题。文档涵盖了从12000001到12000016的错误码，内容涉及外部系统错误、凭据绑定（如PIN、指纹）、内存不足、参数校验、算法库操作失败及UserIAM服务调用失败等场景。这些资料适用于使用OpenHarmony HUKS API进行安全开发的工程师，特别是在调试密钥生成、访问控制及身份认证流程时提供故障排查指导。
