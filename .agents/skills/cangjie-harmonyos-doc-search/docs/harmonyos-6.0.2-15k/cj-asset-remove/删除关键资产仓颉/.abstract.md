This directory serves as a comprehensive technical guide for developers working with the Cangjie programming language to manage and delete critical assets securely. It focuses on the AssetStoreKit module, providing both theoretical API documentation and practical implementation examples. The content covers essential aspects such as synchronous deletion workflows, parameter configuration, access control, and data labeling strategies. It emphasizes security compliance, including restrictions on personal data in unencrypted fields and updates from API 12. Additionally, it details the specific workflow of querying an asset by alias before removal to ensure existence. This resource is designed for software engineers and developers who need to integrate robust asset management capabilities into their applications, ensuring data integrity and adherence to security protocols during the deletion process.
