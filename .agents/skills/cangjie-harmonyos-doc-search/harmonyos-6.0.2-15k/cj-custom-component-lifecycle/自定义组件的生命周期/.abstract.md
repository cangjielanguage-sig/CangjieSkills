This directory provides comprehensive documentation on the lifecycle management of custom components within the HarmonyOS ArkUI framework, specifically tailored for the Cangjie language. It covers the complete spectrum of component states, from initialization and rendering to destruction and recycling. Key topics include the `@Reusable` decorator, the `ReuseParams` class, and specific lifecycle callbacks like `aboutToAppear` and `onPageShow`. This resource is essential for HarmonyOS developers and UI engineers seeking to master state management, optimize memory usage through component reuse, and ensure proper application behavior during page transitions.
