# 组合手势

This directory serves as a comprehensive resource for developers working with the Cangjie ArkUI framework, focusing specifically on the implementation of combined gestures. It details the `GestureGroup` API and the three core recognition modes: Sequence, Parallel, and Exclusive. The documentation guides users through complex interaction scenarios, such as handling simultaneous touch events, managing competitive recognition between single and double taps, and chaining gestures sequentially for actions like dragging. It includes practical code examples demonstrating state management and event callbacks. This content is ideal for Cangjie developers aiming to build sophisticated, responsive user interfaces with advanced touch handling capabilities.
