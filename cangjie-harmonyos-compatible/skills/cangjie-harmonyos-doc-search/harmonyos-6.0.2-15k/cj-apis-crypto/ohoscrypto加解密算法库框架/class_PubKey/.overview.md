# class_PubKey

This directory contains comprehensive API reference documentation for the `PubKey` class and associated encoding functions within the Cangjie programming language's CryptoFramework. It focuses on the implementation and management of public keys used in asymmetric cryptographic operations, such as encryption, digital signature verification, and key agreement protocols. The documentation details the class hierarchy, inheritance from the `Key` interface, and specific methods for retrieving key specifications and encoded data in formats like ASN.1 DER and PEM (supporting PKCS#1 and X.509 standards). Additionally, it covers system capabilities, version requirements, and error handling. This resource is suitable for software developers and security engineers working with the Cangjie language who need to integrate robust cryptographic features, specifically those handling RSA and ECC key management and encoding tasks.
