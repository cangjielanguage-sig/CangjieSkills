This directory contains the API reference documentation for the `ohos.bluetooth.constant` module in the Cangjie programming language, designed for HarmonyOS development. It provides essential enumerations and constants for Bluetooth operations, including device classification (MajorClass, MajorMinorClass), connection states (ProfileConnectionState), profile identifiers (ProfileId), and profile UUIDs (ProfileUuids). These definitions enable developers to programmatically identify, categorize, and manage Bluetooth devices and communication protocols. The module requires the `SystemCapability.Communication.Bluetooth.Core` capability and is available from API version 19. It is suitable for software engineers implementing robust Bluetooth connectivity features in HarmonyOS applications.
