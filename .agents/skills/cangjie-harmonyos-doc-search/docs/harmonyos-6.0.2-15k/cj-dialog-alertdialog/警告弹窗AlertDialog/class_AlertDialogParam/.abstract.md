This directory contains API reference documentation for the `AlertDialogParam` class within the Cangjie programming language and ArkUI framework. It covers the definition and configuration of alert dialog windows, detailing properties for message content, titles, alignment, styling, and behavioral settings like modal states. The documentation includes constructors, layout variables, and specific properties for customizing appearance and interaction logic. It is intended for developers and UI engineers building user interfaces who need to implement and configure alert pop-ups and modal windows in their applications.
