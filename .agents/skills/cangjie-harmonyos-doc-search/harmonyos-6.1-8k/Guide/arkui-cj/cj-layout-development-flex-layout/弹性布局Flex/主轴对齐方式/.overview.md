## 详细描述

### 主轴对齐方式_1.md

本文档旨在介绍ArkUI中Flex布局组件的主轴对齐方式设置方法。文档详细列举了justifyContent参数的六种取值：Start（默认）、Center、End、SpaceBetween、SpaceAround及SpaceEvenly。每种对齐方式均配有具体的行为描述和Cangjie语言代码示例，展示了子元素在主轴方向上的不同分布逻辑，如两端对齐、居中或等间距排列。该文档适用于使用ArkUI框架和Cangjie语言进行UI开发的开发者，帮助他们掌握Flex布局的排版控制。

### 主轴对齐方式_2.md

本文档作为一个实用的代码示例，演示了如何使用Cangjie编程语言和ArkUI框架在Flex布局容器中实现SpaceEvenly对齐模式。内容侧重于Flex组件的配置，特别是利用设置为FlexAlign.SpaceEvenly的justifyContent属性来沿主轴分布子元素。关键要点包括定义具有百分比宽度和不同背景颜色的子Text组件的语法，展示了如何在项目之前、之间和之后均匀分布空间。该片段旨在供学习Cangjie的HarmonyOS开发者使用，作为理解ArkUI开发中布局行为和样式属性的视觉参考。
