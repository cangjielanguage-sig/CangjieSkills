# ohosdatapreferences用户首选项

## 详细说明

### class_PreferencesOptions.md class_PreferencesOptions.md
本文档是Cangjie语言中PreferencesOptions类的API参考文档，旨在定义Preferences实例的配置选项。文档涵盖了类定义、属性（name、dataGroupId、storageType）及构造函数的详细说明。关键要点包括name属性的长度与字符限制、storageType默认为Xml且不可中途切换，以及dataGroupId暂不支持共享沙箱路径的说明。该文档面向使用分布式数据管理核心能力的开发者，提供了初始化配置所需的技术细节和约束条件。

### enum_PreferencesE_3more_29e6e9f9.md enum_PreferencesE_3more_29e6e9f9.md
本文档是Cangjie语言Preferences模块的API参考文档，定义了事件、存储模式及值类型三个枚举。主要涵盖PreferencesEvent（数据变更与多进程变更）、StorageType（XML与GSKV存储模式）及PreferencesValueType（整型、浮点、字符串、布尔值及其数组）。关键信息指出XML为默认模式需手动落盘，GSKV模式实时落盘，且存储模式选定后不可中途切换或自动迁移。面向使用分布式数据管理首选项功能的开发者。关键词：Cangjie, Preferences, 枚举, API, 存储模式, 事件类型。

### ohosdatapreferenc_5more_588a4e57.md ohosdatapreferenc_5more_588a4e57.md
本文档是ohos.data.preferences模块的API参考文档，旨在为仓颉语言开发者提供用户首选项功能的接口说明。文档主要介绍了如何利用键值对机制进行轻量级数据的持久化存储、修改和查询。核心内容包括模块导入方式、项目配置要求（如Context和dataGroupId）、以及键值长度的限制常量（键最大1024字节，值最大16MB）。该功能目前处于Beta阶段，适用于需要处理简单数据存储的应用开发场景。

### class_Preferences/
本目录包含仓颉语言中Preferences类的API参考文档，属于HarmonyOS ArkData kit的一部分。文档详细介绍了如何管理轻量级用户首选项数据，涵盖实例的获取与删除、数据的增删改查、持久化存储以及缓存管理。内容包含静态方法管理、数据变更订阅及异常处理机制。本文档适合使用仓颉语言进行HarmonyOS应用开发的开发者，旨在帮助其实现高效的数据持久化与上下文管理。
