# cj-crypto-sm4-sym-encrypt-decrypt-gcm-by-segment

This repository provides a comprehensive technical implementation of segmented encryption and decryption using the SM4 symmetric key algorithm in GCM mode, specifically tailored for the Cangjie programming language. It addresses the critical need for memory-efficient data processing by demonstrating how to handle large data streams through chunked operations. The content covers the entire cryptographic lifecycle, including secure key generation, initialization vector (IV) management, and the specific usage of `update` and `doFinal` methods for stream processing. Furthermore, it explores essential security standards such as PKCS7 padding and authentication tag verification. This resource is specifically designed for Cangjie developers and security engineers who aim to integrate robust, high-performance cryptographic capabilities into their applications while adhering to modern security best practices.

## Detailed Description

### [1] 使用SM4对称密钥GCM模式分段加解密仓颉/

This directory focuses on providing a robust implementation of segmented encryption and decryption using the SM4 symmetric key algorithm in GCM mode within the Cangjie programming language. It serves as a complete reference for developers needing to secure data without loading entire files into memory, making it highly relevant for high-performance applications.

The directory covers the complete cryptographic workflow in detail:
*   **Algorithm Configuration:** It explains how to configure the SM4 algorithm in GCM mode, which provides both data confidentiality and integrity through authenticated encryption.
*   **Streamlined Data Processing:** A significant portion of the content is dedicated to chunked data processing. It demonstrates the use of the `update` method to feed data in segments, followed by `doFinal` to conclude the operation. This approach is crucial for optimizing memory usage when dealing with large inputs.
*   **Security Parameters:** It provides clear guidance on handling Initialization Vectors (IVs) to ensure semantic security and managing authentication tags to verify that data has not been tampered with.
*   **Padding and API Usage:** The implementation details the application of PKCS7 padding to meet block size requirements and extensively utilizes the `CryptoArchitectureKit` API to perform these low-level operations efficiently.

This resource is suitable for Cangjie developers looking to integrate secure, efficient, and standard-compliant cryptographic operations into their applications.
