This directory provides the API reference documentation for the `cj-apis-cert_manager`, specifically focusing on the OpenHarmony Certificate Manager module developed for the Cangjie programming language. It serves as a critical resource for developers aiming to secure their applications through the management of digital certificates and credentials. The documentation comprehensively covers the full lifecycle of these certificates, including detailed procedures for installation, retrieval, signing, and verification. It also defines essential data structures for certificate metadata, enumerations for cryptographic algorithms (covering digests and padding), and specific error handling codes. Furthermore, it details the necessary system capabilities and permissions, such as `ohos.permission.ACCESS_CERT_MANAGER`, required to execute these operations. This content is tailored for HarmonyOS developers who need to implement secure cryptographic operations, manage user-trusted certificates, and ensure the integrity of digital signatures within their software solutions. By leveraging these APIs, developers can build secure, compliant applications that effectively handle sensitive data and authentication processes.
