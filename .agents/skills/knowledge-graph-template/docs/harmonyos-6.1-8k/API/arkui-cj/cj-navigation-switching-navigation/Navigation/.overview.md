# Navigation

本目录提供了基于仓颉语言的ArkUI框架Navigation组件的完整开发指南。内容涵盖了Navigation组件的API参考、属性配置、基础类型定义以及实际应用示例。它详细介绍了如何使用Navigation作为路由导航根视图容器，管理NavPathStack路由栈，以及实现页面间的跳转与状态管理。核心关键词包括Navigation组件、NavPathStack、路由导航、NavDestination、仓颉语言。该文档适合使用仓颉语言进行HarmonyOS应用开发，需要掌握页面路由架构和UI导航逻辑的开发者参考。

## 详细说明

### Navigation_5more_5a96f268.md Navigation_5more_5a96f268.md
这是一份ArkUI框架中Navigation组件的API参考文档，面向使用Cangjie语言的应用开发者。文档定义了Navigation作为路由导航根视图容器的用途，其包含标题栏、内容区和工具栏，支持通过路由栈切换首页与非首页内容。主要内容包括组件的导入模块、子组件支持、以及两种构造函数的详细参数说明：基础构造函数和绑定NavPathStack路由栈的构造函数。文档还特别指出了嵌套Navigation时的生命周期联动限制及NavDestination标题栏的显示规则，旨在帮助开发者掌握路由容器的配置与使用。

### 示例代码_91ed3a4b.md 示例代码_91ed3a4b.md
这份文档提供了使用Cangjie语言实现ArkUI Navigation组件路由导航的示例代码。文档主要展示了如何构建包含EntryView、PageOne和PageTwo的多页面应用结构，重点讲解了NavPathStack的管理、页面跳转方法（pushPath、pushPathByName、pop）以及NavDestination的使用。关键概念包括通过@Provide和@Consume传递路由栈对象、自定义页面映射函数pageMap以及处理返回事件。该示例适合具备Cangjie基础的开发者，旨在帮助其掌握鸿蒙应用中页面间导航与状态管理的实现方式。

### 组件属性.md 组件属性.md
本文档定义了ArkUI框架中使用仓颉语言管理组件属性的API接口。主要包含三个函数：`hideTitleBar`控制标题栏显隐，`navDestination`创建导航目标组件，以及`title`设置页面标题（支持自定义构建器和资源字符串两种重载）。关键信息涵盖参数类型（如`?Bool`、`CustomBuilder`）、默认值、命名参数说明及系统能力要求，所有接口起始版本均为22。属于API参考文档，面向使用仓颉语言开发HarmonyOS应用的开发者，用于配置UI导航和页面布局。

### 基础类型定义/
本目录包含Cangjie语言中用于ArkUI框架导航与UI配置的基础类型定义。它涵盖了页面导航路径信息、导航栈管理、导航选项配置、标题栏样式设置以及页面弹出信息等核心数据结构。这些类型定义是构建复杂页面路由和自定义导航界面的基石。主要面向使用Cangjie语言进行ArkUI应用开发的开发者，帮助他们精确控制页面跳转逻辑、栈操作行为及界面布局样式。
