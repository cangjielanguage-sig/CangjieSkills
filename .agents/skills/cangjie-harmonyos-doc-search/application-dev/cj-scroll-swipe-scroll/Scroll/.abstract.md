This directory provides comprehensive documentation and resources for the Scroll component within the ArkUI framework using the Cangjie language. It covers the implementation of scrollable interfaces, including API references, fundamental type definitions, event handling, and practical code examples. Key topics include Scroller controllers, nested scrolling strategies, edge effects, and performance optimization. Designed for HarmonyOS developers and UI architects, this collection enables the creation of interactive, high-performance user interfaces with precise control over scroll mechanics and visual feedback.
