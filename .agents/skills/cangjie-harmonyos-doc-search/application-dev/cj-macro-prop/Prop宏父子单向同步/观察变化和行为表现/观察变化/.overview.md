# 观察变化

This directory serves as a specialized technical resource focused on the intricacies of observing data changes within the Cangjie programming language's state management system. It specifically addresses the functionality of the `@Prop` decorator, a critical component for building reactive user interfaces in ArkUI. The documentation covers a wide spectrum of scenarios, ranging from simple primitive type updates to complex object and collection mutations. It clarifies the boundaries of automatic observation, explaining when deep observation mechanisms like `@Observed` and `@Publish` are necessary. Furthermore, it defines the strict one-way data synchronization flow from parent components to child components. This material is highly suitable for software developers and system architects working with Cangjie who need to implement robust, efficient, and predictable state management logic in their applications.

### 观察变化_1.md
This technical guide provides a detailed examination of the change observation mechanisms associated with the `@Prop` decorator in Cangjie state management. It is designed to help developers understand how data reactivity is maintained across different data structures. The document comprehensively covers the behavior of `@Prop` when interacting with primitive types, structs, classes, arrays, and various collections. It also establishes the synchronization rules that govern the interaction between `@Prop` and the parent `@State` decorator.

Important insights provided in this file include:
- **Type-Specific Behavior:** It clarifies that `@Prop` automatically detects value changes for primitive types but requires whole assignments for structs to trigger updates.
- **Class Observation:** The guide explains that standard class instances do not support internal observation by default; instead, they must be decorated with `@Observed` and `@Publish` to track internal property changes.
- **Array Handling:** It distinguishes between standard arrays, which only detect replacement, and `ObservedArrayList`, which supports tracking item modifications and structural changes.
- **Data Flow:** It reinforces the concept that synchronization is unidirectional, flowing strictly from the parent's `@State` to the child's `@Prop`.

This document is an essential reference for developers building ArkUI applications using Cangjie who need to manage component state and ensure data reactivity.
