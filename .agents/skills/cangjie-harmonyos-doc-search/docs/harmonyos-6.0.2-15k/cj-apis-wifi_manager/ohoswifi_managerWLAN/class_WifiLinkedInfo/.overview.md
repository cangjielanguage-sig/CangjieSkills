# class_WifiLinkedInfo

This directory contains API reference documentation for the `WifiLinkedInfo` class within the Cangjie programming language environment. It is designed to assist developers in accessing detailed information regarding the current WLAN connection status and network properties. The content covers a wide array of read-only properties, including SSID, BSSID, signal strength (RSSI), frequency, IP address, and link speeds, as well as specific WiFi capabilities and standards. This documentation is essential for developers implementing network connectivity features, specifically those requiring the SystemCapability.Communication.WiFi.STA capability. It serves as a guide for integrating WiFi Station features starting from API version 19, enabling the display and management of real-time WiFi metrics and configurations effectively.

## Detailed Description

### class_WifiLinkedInfo_18more.md
This API reference document details the WifiLinkedInfo class in Cangjie, which provides comprehensive information regarding the current WLAN connection status and network properties. The documentation enumerates numerous read-only properties such as SSID, BSSID, signal strength (RSSI), frequency, IP address, link speeds, and network flags like hidden or restricted status. Key takeaways include that all properties are read-only, the class requires the SystemCapability.Communication.WiFi.STA system capability, and it is available starting from API version 19. Intended for developers working on network connectivity features, this reference helps in accessing and displaying real-time WiFi connection metrics and configurations.

### let_supportedWifiCategory_3more.md
This API reference document defines properties and functions for managing WiFi capabilities within the Cangjie programming language. It details two read-only properties, supportedWifiCategory and wifiStandard, which respectively indicate the highest supported WiFi level and the current connection's standard. Additionally, it documents the toString function for obtaining a string representation of the class. Key information includes the data types WifiCategory and WifiStandard, the read-only nature of the properties, and the requirement for SystemCapability.Communication.WiFi.STA. Intended for developers, this documentation facilitates the integration of WiFi Station features starting from version 19.
