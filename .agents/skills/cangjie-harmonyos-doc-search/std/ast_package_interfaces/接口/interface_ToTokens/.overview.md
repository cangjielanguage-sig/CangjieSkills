# interface_ToTokens

This directory contains comprehensive API reference documentation for the `ToTokens` interface within the Cangjie language ecosystem. It details the core interface definition alongside numerous extensions that allow a wide variety of data types—including numeric primitives (signed and unsigned), strings, arrays, and AST nodes—to be converted into `Tokens` objects. This functionality is critical for operations such as quote interpolation, metaprogramming, and Abstract Syntax Tree (AST) manipulation. The documentation is specifically designed for Cangjie developers involved in building compiler tools, parsing systems, or advanced metaprogramming features who require a deep understanding of type-to-token conversion mechanisms.
