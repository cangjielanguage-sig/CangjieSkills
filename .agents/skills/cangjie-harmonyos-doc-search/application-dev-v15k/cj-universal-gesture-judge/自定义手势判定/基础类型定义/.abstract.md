This directory provides comprehensive API reference documentation for fundamental data structures and event classes within the ArkUI framework, specifically designed for the Cangjie language. It covers the core definitions required for handling input device interactions and UI gestures. Key topics include the BaseEvent class for system events, BaseGestureEvent for finger tracking, and specific gesture types like pinch, rotation, and swipe. Additionally, it details structures for gesture judgment and categorization. This documentation is essential for developers building interactive applications who need to implement custom event handling and gesture recognition logic.
