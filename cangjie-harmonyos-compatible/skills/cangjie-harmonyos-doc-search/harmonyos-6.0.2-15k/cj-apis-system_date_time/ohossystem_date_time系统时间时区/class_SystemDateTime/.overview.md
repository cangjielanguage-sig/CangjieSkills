# class_SystemDateTime

This directory contains API reference documentation for the `SystemDateTime` class within the Cangjie programming language. It is designed to assist developers in handling complex system time and timezone operations. The documentation covers essential functionalities such as retrieving the current time, calculating elapsed time since the Unix epoch, and tracking system uptime with support for both millisecond and nanosecond precision. It also distinguishes between active time and total time including deep sleep periods. This resource is suitable for Cangjie developers utilizing the BasicServicesKit who require precise time management and exception handling capabilities in their applications.

### class_SystemDateTime_5more.md class_SystemDateTime_5more.md
This document provides API reference documentation for the SystemDateTime class in the Cangjie language, designed to handle system time and timezone operations. It details four static functions: getCurrentTime, getTime, getRealActiveTime, and getRealTime, which allow developers to retrieve elapsed time since the Unix epoch or system boot. Key information includes the isNano parameter, which defaults to false for milliseconds but can be set to true for nanosecond precision, and the distinction between active time and total time including deep sleep. Intended for Cangjie developers working with system capabilities, this guide requires basic knowledge of exception handling and the BasicServicesKit.

Key takeaways include the ability to specify time units (milliseconds or nanoseconds) for uptime via a boolean parameter and the requirement to handle potential exceptions during execution. Targeted at software developers working with system-level time services, specifically those building applications requiring timezone or system uptime tracking.
