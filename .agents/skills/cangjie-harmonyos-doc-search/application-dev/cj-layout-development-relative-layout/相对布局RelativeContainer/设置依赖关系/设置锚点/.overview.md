# 设置锚点

This directory provides a comprehensive guide to configuring anchor points within the RelativeContainer component for ArkUI development. It explains the mechanisms for positioning child elements relative to parent containers and sibling elements, emphasizing the necessity of unique component IDs and specific alignment rules. The content includes both theoretical explanations and practical code examples in Cangjie and ArkTS, covering critical topics such as the default parent identifier, avoiding circular dependencies, and chaining elements for complex layouts. Suitable for UI developers and HarmonyOS application engineers, these resources are essential for mastering flexible, constraint-based layout design.

## Detailed Description

### 设置锚点_1.md
This guide explains how to configure anchor points for child elements within a RelativeContainer in ArkUI using the Cangjie language. It covers positioning relative to the parent container (__container__) and sibling elements, detailing the requirement for unique component IDs. Key takeaways include the necessity of IDs for referencing anchors, the default parent identifier, and the critical warning to avoid circular dependencies to ensure proper rendering. Intended for UI developers, this tutorial provides practical code examples to implement relative positioning effectively.

### 设置锚点_2.md
The document provides a practical code example demonstrating how to configure relative positioning using the RelativeContainer component in ArkTS. It focuses on setting anchors through the alignRules property and .id() modifiers to define spatial relationships between child elements. The example details how four Row components are positioned relative to the container and each other using vertical and horizontal alignment parameters. Key takeaways include understanding how to chain elements together for complex layouts. This technical guide is intended for developers learning to implement flexible, constraint-based layouts in HarmonyOS application development.
