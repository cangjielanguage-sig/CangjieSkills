This directory contains comprehensive documentation for the ActionSheet component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of list selection popups, including API references for core classes like `ActionSheet`, `ActionSheetOptions`, and related configuration objects for styling and behavior. Developers will find resources for managing dialog lifecycles, customizing visual appearances (shadows, borders), and handling user interactions. This documentation is suitable for HarmonyOS application developers and UI engineers looking to integrate interactive modal dialogs and selection menus into their Cangjie-based projects.
