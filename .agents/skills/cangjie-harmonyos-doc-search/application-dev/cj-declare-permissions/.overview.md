# cj-declare-permissions

This directory serves as a comprehensive technical resource for HarmonyOS developers, specifically addressing the critical task of declaring application permissions within the `module.json5` configuration file. The documentation provides a step-by-step approach to enabling authorization through the `requestPermissions` tag, ensuring that developers understand how to define essential attributes such as name, reason, and `usedScene`. It covers specific technical details, including usage timing and component abilities, while also establishing strict content standards for permission reasons. Special attention is given to `user_grant` types, highlighting the necessity for conciseness and robust multi-language support. Furthermore, the guide explains the user-facing aspect of how permission groups are displayed. This documentation is indispensable for application developers who need to navigate system requirements and ensure their applications meet the rigorous standards of app store validation processes.
