# 生命周期状态说明

This directory provides comprehensive technical documentation on lifecycle states within the HarmonyOS application development framework using the Cangjie language. It covers the complete lifecycle of UIAbility instances, including initialization, foreground/background transitions, and destruction, as well as WindowStage-specific events. Key topics include callback methods like onCreate, onDestroy, onForeground, and onBackground, along with resource management and event handling strategies. This guide is essential for developers seeking to master application state management, optimize resource usage, and ensure smooth user experiences in HarmonyOS apps.

## Detailed Description

### Create状态.md Create状态.md
This technical reference document explains the Create state within the application lifecycle, specifically detailing the initialization phase of UIAbility instances. The content covers the system-triggered onCreate callback, page initialization tasks such as variable definition and resource loading, and the function of the Want object for inter-component communication. Key takeaways include a Cangjie code example demonstrating how to override onCreate to handle startup parameters and prepare the UI for display. Intended for application developers using the Cangjie language and AbilityKit framework, this guide assists in managing app lifecycle events and setting up the initial application state.

### Destroy状态.md Destroy状态.md
This document defines the Destroy state within the UIAbility lifecycle, detailing its trigger conditions and the necessary cleanup operations. It explains that this state occurs when a UIAbility instance is destroyed, either programmatically via terminateSelf() or by user action through the recent task list. The text highlights the onDestroy() callback as the critical point for releasing system resources and saving data. A Cangjie code example demonstrates how to override this method. Intended for HarmonyOS developers using the Cangjie language, this reference guide ensures proper application lifecycle management and resource handling.

### Foreground和Background状态.md Foreground和Background状态.md
This document explains the lifecycle management of UIAbility instances when switching between foreground and background states. It details the onForeground() and onBackground() callbacks, specifying their trigger timing and appropriate use cases such as resource acquisition and release. Additionally, it covers the onNewWant() callback behavior for singleton launch modes. Key takeaways include using onForeground to prepare resources like location services and onBackground to save state or free memory. The guide provides Cangjie code examples and targets developers managing application lifecycle and resources within the UIAbility framework.

### WindowStageCreate和WindowStageDestroy状态.md WindowStageCreate和WindowStageDestroy状态.md
This document details the WindowStage lifecycle states, specifically Create and Destroy, within the UIAbility context for application development. It covers the onWindowStageCreate() callback for UI initialization and event subscription, and the onWindowStageDestroy() callback for resource cleanup. Key information includes using loadContent() to set pages and subscribing to window events to monitor states like foreground, background, and focus. The document provides Cangjie code examples demonstrating event handling for types such as SHOWN, ACTIVE, and HIDDEN. This guide targets developers using the Cangjie language and HarmonyOS/OpenHarmony frameworks to manage application window lifecycles.

This document serves as a technical reference for the onWindowStageWillDestroy() lifecycle callback in Cangjie application development. It details the execution timing of this state, specifically occurring before the WindowStage is destroyed while the object remains usable. The primary takeaway is the necessity of releasing resources and unsubscribing from WindowStage events, such as focus or visibility changes, within this callback. The provided Cangjie code snippet demonstrates using windowStage.off() for event cleanup and error handling. This guide targets HarmonyOS developers using the Cangjie language who need to manage UIAbility lifecycle events and resource cleanup effectively.
