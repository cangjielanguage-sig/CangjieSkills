# cj-sensorservice-kit-intro

This directory contains the comprehensive introductory documentation for the Sensor Service Kit, a Beta-phase development kit designed to empower applications with the ability to access raw sensor data and control vibration capabilities. The documentation provides an in-depth look at the usage scenarios for the Sensor and Vibrator modules, clearly explaining their pivotal roles in hardware abstraction and haptic interaction. It also addresses specific constraints and limitations, emphasizing the necessity of device hardware support, the requirement for specific permissions, and the critical need to pair sensor subscription and unsubscription calls to manage resources effectively. This guide is specifically suitable for application developers who are creating hardware-dependent features such as compasses, health trackers, or games, and who require a robust understanding of hardware abstraction and permission handling.
