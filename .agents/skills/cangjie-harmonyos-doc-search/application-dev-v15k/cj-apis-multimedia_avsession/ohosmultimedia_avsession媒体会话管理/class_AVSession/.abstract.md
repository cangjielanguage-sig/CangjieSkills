This directory provides API reference documentation for the `AVSession` class in the Cangjie language, essential for managing audio-video session lifecycles in HarmonyOS applications. It covers core functionalities such as session activation, deactivation, event dispatching, and state management. The documentation includes detailed specifications for handling playback states, metadata, media queues, and casting controls. Designed for multimedia application developers, it requires familiarity with the Cangjie language and session management concepts. Key topics include event subscription, error handling with `BusinessException`, and system capabilities for robust media session implementation.
