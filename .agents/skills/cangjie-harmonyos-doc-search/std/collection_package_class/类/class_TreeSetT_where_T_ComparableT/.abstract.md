This directory contains API reference documentation for the `TreeSet` class in the Cangjie programming language. It details an ordered collection implementation based on `TreeMap`, requiring elements to be `Comparable`. The documentation covers class definitions, properties, initialization methods, and various member functions for manipulation, iteration, and set operations. It is suitable for Cangjie developers needing efficient, ordered data storage for applications like databases or caches, providing comprehensive guides on methods for adding, removing, and querying sorted data.
