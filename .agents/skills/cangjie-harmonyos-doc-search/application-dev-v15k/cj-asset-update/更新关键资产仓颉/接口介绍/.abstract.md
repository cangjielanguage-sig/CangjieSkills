This directory provides technical documentation for the AssetStoreKit API, focusing on the synchronization and update of critical assets. It covers interface definitions, parameter structures like `AssetParam`, and attribute configurations including access control and data types. Key topics include security warnings regarding unencrypted data labels, size limits for custom data (updated to 2048 bytes in API 12), and encryption control flags. This documentation is intended for software developers and engineers integrating secure asset management features into their applications, ensuring correct implementation and adherence to data privacy standards.
