This directory contains a comprehensive collection of development guides for creating and managing List components using the Cangjie language and ArkUI framework. It covers fundamental concepts like component structure and layout constraints, as well as advanced features including grouped lists, sticky headers, and scroll position control. Developers will also find tutorials on performance optimization, custom styling, and interactive elements such as swipe actions and pull-to-refresh. These resources are designed for UI developers and application engineers building efficient, scrollable interfaces for HarmonyOS applications.
