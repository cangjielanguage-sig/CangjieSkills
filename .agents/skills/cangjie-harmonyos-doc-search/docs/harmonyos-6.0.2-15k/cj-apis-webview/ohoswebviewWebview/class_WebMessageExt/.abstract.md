This directory contains API reference documentation for the Cangjie `WebMessageExt` class, a data object designed for WebMessagePort communication within the WebView Core module. It covers the initialization of the class and provides comprehensive methods for getting and setting various data types, including strings, arrays, booleans, and binary buffers. The documentation details error handling, specifically the `BusinessException` for type mismatches. Suitable for developers implementing WebView functionality and structured message data exchange, this content requires knowledge of the `SystemCapability.Web.Webview.Core` capability introduced in version 19.
