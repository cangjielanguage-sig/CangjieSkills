# cj-apis-relational_store

This directory serves as a comprehensive API reference for the Relational Database (RDB) features in HarmonyOS, specifically designed for the Cangjie programming language. It encompasses the full spectrum of database functionalities, ranging from initial lifecycle management and configuration to complex data manipulation and querying. The documentation also addresses advanced features such as distributed synchronization across devices and security encryption for data protection. By detailing core classes like RdbStore, RdbPredicates, and StoreConfig, along with asset management and data type definitions, this resource is essential for developers seeking to build robust, secure, and efficient data persistence layers in their HarmonyOS applications using Cangjie. It acts as the definitive guide for implementing local storage strategies that integrate seamlessly with the broader HarmonyOS ecosystem, ensuring that applications can scale from local data storage to complex end-cloud scenarios.

### [1] ohosdatarelational_store关系型数据库/

This directory provides the essential API reference documentation for the Relational Database (RDB) module within the HarmonyOS Cangjie language framework. It is structured to assist developers in managing the complete database lifecycle, ensuring that applications can handle data efficiently from creation to deletion. The documentation covers critical data operations, allowing for the insertion, update, deletion, and querying of records using specific predicates.

Furthermore, it addresses the complexities of modern application development by including APIs for distributed synchronization, which enables data consistency across multiple devices, and security encryption to protect sensitive information. The core of the documentation focuses on key classes such as RdbStore (the main database interface), RdbPredicates (for constructing query conditions), and StoreConfig (for database configuration settings). Additionally, it provides definitions for asset management and supported data types, which are crucial for structuring data correctly.

This comprehensive guide is intended for developers utilizing the Cangjie language, offering the technical specifications needed to implement high-performance, secure data persistence and seamless end-cloud collaboration in HarmonyOS applications. By leveraging these APIs, developers can ensure their applications maintain data integrity and performance across local and cloud environments, facilitating a smooth user experience in the distributed HarmonyOS ecosystem. The inclusion of asset management APIs further aids in organizing complex data resources, making this directory a vital resource for sophisticated app development.
