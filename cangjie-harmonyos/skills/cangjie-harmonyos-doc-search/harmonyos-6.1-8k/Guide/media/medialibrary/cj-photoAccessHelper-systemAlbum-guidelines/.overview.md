# cj-photoAccessHelper-systemAlbum-guidelines

This document collection provides a comprehensive technical guide for developers aiming to integrate and manage system album resources within OpenHarmony and HarmonyOS applications. It focuses on the practical implementation of media management features, specifically detailing how to utilize the `photoAccessHelper` and `MediaLibraryKit` modules. The content covers accessing specialized system albums—such as Favorites, Video collections, and Screenshot/Screen Recording folders—and retrieving media assets. Designed specifically for programmers using the Cangjie language, this resource provides essential API references, parameter configurations, and code examples to streamline the development of robust file management and media access functionalities. By following these guidelines, developers can ensure their applications effectively interact with the user's media library.

## Detailed Description

### 系统相册资源使用指导/

This documentation set is designed to guide developers through the process of integrating and operating system album resources in OpenHarmony and HarmonyOS applications. It provides a complete workflow for utilizing the `photoAccessHelper` and `MediaLibraryKit` modules to interact with specific system albums, such as the Favorites album, Video albums, and Screenshot/Screen Recording albums.

The guide covers core functionalities including how to obtain album objects and retrieve image and video resources effectively. It is primarily targeted at developers using the Cangjie language for application development. By offering detailed API call instructions, precise parameter configurations, and illustrative example code, this documentation helps developers efficiently implement file management and media resource access features. This ensures that applications can seamlessly access and display media content from the device's native gallery, enhancing the user experience with robust media handling capabilities.
