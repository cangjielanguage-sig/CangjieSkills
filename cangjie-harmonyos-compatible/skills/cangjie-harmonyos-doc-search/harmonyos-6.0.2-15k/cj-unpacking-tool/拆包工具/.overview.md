# 拆包工具

This directory contains comprehensive documentation for the HarmonyOS Unpacking Tool, a utility designed to decompress and analyze application packages such as HAP, HSP, and App files. It covers essential topics including command-line usage, Java API references for parsing, and detailed data structure definitions for configuration files. Key concepts include parsing modes, extraction of pack.info, and schema definitions for metadata, permissions, and distribution settings. This resource is suitable for HarmonyOS developers, application market builders, and tool engineers who need to inspect package structures or integrate parsing capabilities into their workflows.

## Detailed Description

### 包解析接口.md 包解析接口.md
This document serves as an API reference for parsing HarmonyOS application packages (HAP, HSP, App) to extract configuration data. It details the UncompressEntrance class, specifically the parseApp and parseHap methods which support both file paths and input streams. Key takeaways include the support for different parsing modes (ALL, HAP_LIST, HAP_INFO) and the extraction of pack.info or JSON configuration files. Intended for developers building application markets, this guide requires knowledge of Java and HarmonyOS package structures. Keywords: HAP, HSP, App parsing, Java API, UncompressEntrance, pack.info.

### 拆包工具_2more.md 拆包工具_2more.md
This document provides a reference guide for the HarmonyOS Unpacking Tool, a debugging utility used to decompress and parse HAP, HSP, and App files. It details the tool's capabilities, including command-line operations and Java API interfaces, and specifies its location within the HarmonyOS SDK. Key takeaways include the requirement for a Java 8 or higher environment and a specific limitation where Cangjie programs do not support HSP packages. This guide is intended for HarmonyOS developers seeking to inspect package structures for debugging or analysis.

### 拆包指令说明.md 拆包指令说明.md
This technical reference guide provides command-line instructions for using the app_unpacking_tool.jar to decompress various application package formats. It details specific unpacking modes for HAP, App, HSP, and APPQF packages, alongside a dedicated section for extracting rpcid files from HAP packages. Key information includes required parameters like --mode, input paths, and output directories, as well as optional flags such as --force to overwrite existing files. Targeted at developers, this document serves as a practical manual for executing package extraction tasks efficiently.

### 拆包工具信息字段/
This directory contains technical reference documentation for data structures utilized in HarmonyOS application unpacking and parsing tools. It comprehensively covers schema definitions for various configuration objects found within HAP (Harmony Ability Packages), including application metadata, ability configurations, permissions, and distribution settings. Key topics include the distinctions between FA and Stage models, form configurations, event handling, and shortcut behaviors. This documentation is suitable for software developers, system integrators, and tool engineers who need to programmatically analyze, parse, or validate HarmonyOS application packages and their internal configuration files.
