This directory serves as a comprehensive technical resource for the HarmonyOS Cangjie development framework, specifically focusing on the `cj-apis-image` module. It provides extensive documentation and API references designed to facilitate robust image processing capabilities within applications. The content covers the entire image manipulation pipeline, ranging from fundamental decoding and encoding processes to advanced pixel manipulation and High Dynamic Range (HDR) support. Key components detailed in this resource include the Image, PixelMap, and ImageSource classes, as well as various enums for formats and metadata handling. This documentation is primarily intended for multimedia developers and software engineers who require precise control over image data, metadata management, and rendering capabilities. It serves as an essential guide for building advanced image applications that leverage the SystemCapability.Multimedia.Image.Core framework, ensuring high performance and visual fidelity in HarmonyOS environments.
