This directory serves as a comprehensive repository for technical documentation regarding the OpenHarmony HUKS (Hardware Universal KeyStore) service, specifically focusing on the specifications and conceptual frameworks for key generation. It is designed to assist developers in understanding critical security principles, including the implementation of cryptographic randomness, the management of secure storage lifecycles, and the enforcement of usage restrictions. The content provides an in-depth analysis of storage security levels—DE, CE, and ECE—and offers extensive tables listing supported cryptographic algorithms such as AES, RSA, ECC, and SM algorithms for both standard and lightweight devices. Additionally, it clarifies the distinction between mandatory and optional vendor specifications. This guide is essential for OpenHarmony developers aiming to ensure secure implementation, maintain consistent key usage, and achieve cross-platform compatibility in their software solutions.
