## Detailed Description

### class_LogRecord.md class_LogRecord.md
This API documentation defines the LogRecord class in Cangjie, which serves as the data payload for log messages passed to the Logger class. The document details the class constructor, properties for accessing timestamp, log level, message, and attributes, and a cloning method. Key information includes that LogRecord encapsulates log data such as time, level, message, and key-value pairs, and is typically instantiated automatically by the logger. The level property determines filtering, while attrs holds structured data. This reference is intended for developers working with the Cangjie logging framework who need to understand the internal structure of log entries or extend logging functionality.

### class_NoopLogger.md class_NoopLogger.md
This API documentation defines the NoopLogger class, a no-operation implementation of the Logger interface in the Cangjie language designed to discard all log messages. The document details the class constructor, the level property which is permanently set to OFF, and various methods including close, isClosed, log, and withAttrs. Key takeaways are that all methods are NO-OP implementations, meaning they perform no action, making this class useful for testing or disabling logging without changing code logic. The target audience is Cangjie developers looking for a silent logger implementation or stub for the logging package.

### class_LogWriter/
This directory provides comprehensive API reference documentation for the Cangjie `LogWriter` class and its associated utility functions. It focuses on the mechanisms required to serialize various data types into log output targets effectively. The content covers methods for structuring complex data containers, such as objects and arrays, as well as functions for writing primitive types, strings, and custom objects implementing the `LogValue` interface. Key topics include strict state management to prevent mismatched operations and the handling of specific data types like DateTime, Duration, and Exception. This documentation is specifically designed for Cangjie developers who are building or extending logging frameworks and need a deep understanding of serialization behavior, state constraints, and error handling within the logging system.

### class_Logger/
This directory contains API reference documentation for the logging system in the Cangjie programming language. It focuses on the abstract `Logger` class and associated logging functions, providing a comprehensive guide for developers. Key topics include log severity levels (debug, info, error, fatal), lazy message evaluation using lambda expressions for performance, and attribute management via key-value pairs. It is designed for developers implementing or extending logging functionality in Cangjie applications who need to understand class definitions, method signatures, and performance optimization techniques like the `enabled` check.
