This directory serves as a technical resource for HarmonyOS developers aiming to implement advanced visual effects using the ArkUI framework and Cangjie language. It specifically focuses on the `foregroundBlurStyle` attribute, providing practical code examples for applying content blur effects to UI components. The documentation covers a range of blur styles, including Thin, Regular, Thick, and specialized background variants like Ultra Thick. It details the configuration of `ForegroundBlurStyleOptions`, explaining how to manipulate parameters such as colorMode, adaptiveColor, and scale to achieve specific visual intensities over background images. This collection is ideal for developers and UI engineers seeking to enhance application aesthetics, create visual hierarchy, and improve user experience through depth and blur effects.
