This directory provides a comprehensive technical guide to implementing data persistence using Key-Value (KV) databases. It is designed to assist developers in understanding the fundamental principles and practical applications of KV storage within the ArkData framework. The content covers essential topics such as usage scenarios, system constraints (including key and value size limits), core interfaces, and the complete development lifecycle including configuration and CRUD operations. By integrating the Cangjie programming language, it offers efficient storage solutions for simple data structures without complex relationships. This resource is suitable for application developers working on distributed data storage or local data management within the ArkUI framework who need robust, scalable, and easy-to-implement data persistence mechanisms.
