This directory contains essential API reference documentation for the `CanvasPattern` class within the ArkUI framework, specifically designed for use with the Cangjie language. It covers the structural definition of the class, which represents an image filling template created via the `createPattern` method. The documentation places significant emphasis on the `setTransform` function, explaining how to apply 2D matrix transformations to patterns effectively. Furthermore, it includes vital details regarding system capability requirements, the current Beta status, and version compatibility starting from version 22. This guide is intended for developers implementing 2D graphics and custom image fills in ArkUI applications, requiring a prerequisite knowledge of matrix transformations and canvas drawing concepts.
