# 基础类型定义

This directory contains fundamental type definitions for configuring visual effects within the ArkUI framework using the Cangjie language. It primarily focuses on background blur styles, activation policies, and effect options, providing the necessary building blocks for creating dynamic and responsive UI components. Key concepts include depth-of-field simulation, material blurring, and window state management. These resources are designed for HarmonyOS developers who need granular control over visual aesthetics and application state behaviors.

## Detailed Description

### class_BackgroundBlurStyleOptions.md class_BackgroundBlurStyleOptions.md
This API reference document defines the BackgroundBlurStyleOptions class for configuring background blur effects in the ArkUI framework using the Cangjie language. It covers the class definition, which inherits from BlurStyleOptions, and details its read-only properties: inactiveColor for fallback colors when unfocused, and policy for activation strategies. The document also explains the constructor parameters, such as color modes, blur options, and scale. Key takeaways include the ability to control blur behavior based on window focus states. Intended for ArkUI developers, this documentation requires knowledge of Cangjie syntax and UI development concepts to implement visual styling effectively.

### enum_BlurStyle.md enum_BlurStyle.md
This document provides API reference documentation for the BlurStyle enum in the Cangjie language, used within the ArkUI framework to configure blur effects. It enumerates 13 distinct values categorized into background depth-of-field blurs (ranging from thin to ultra-thick) and component material blurs (ultra-thin to ultra-thick), alongside general options like NONE. Additionally, it documents the getValue() function for retrieving the integer representation of these styles. Available starting from system version 12, this reference is designed for developers implementing visual effects in HarmonyOS applications, offering granular control over blur intensity and material simulation.

### enum_BlurStyleActivePolicy.md enum_BlurStyleActivePolicy.md
This document serves as API reference documentation for the Cangjie enum BlurStyleActivePolicy, which defines the activation policies for blur effects in the ArkUI framework. It details three specific policy options: ALWAYS_ACTIVE, ALWAYS_INACTIVE, and FOLLOWS_WINDOW_ACTIVE_STATE, the latter linking the blur effect to the window's focus state. Additionally, it documents the getValue method for retrieving the enum's integer representation. Key information includes the system capability requirements and the specific behavior of each policy regarding window focus. This reference is intended for developers using the Cangjie language to implement dynamic visual effects in ArkUI applications, providing the necessary controls to manage blur visibility based on application state.
