# cj-apis-ability_access_ctrl

This directory serves as the central hub for API reference documentation regarding the `cj-apis-ability_access_ctrl` module, specifically built for the Cangjie language framework within the HarmonyOS environment. It is dedicated to the complex requirements of program access control and permission management, offering developers the necessary interfaces to secure their applications effectively. The documentation thoroughly covers critical components, including the `AtManager` class, which is instrumental in handling runtime permissions, and enumerations like `GrantStatus` that define various authorization states. Additionally, it provides guidance on managing result objects for permission requests and controlling global hardware switches such as cameras and microphones. This resource is highly suitable for HarmonyOS developers who are tasked with implementing robust security capabilities, verifying application permissions, and creating user consent logic that interacts with system dialogs to ensure a compliant user experience.
