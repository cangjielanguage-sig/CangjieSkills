This directory serves as a specialized technical repository for developers and system integrators focusing on Mobile Device Management (MDM) solutions within the OpenHarmony and HarmonyOS ecosystems. It centralizes documentation regarding the exclusive permissions required for enterprise-grade applications to perform advanced device administration tasks that standard apps cannot execute. The content covers critical areas such as granular network control, application lifecycle management, rigorous security policy enforcement, and deep system settings modification. By detailing `system_grant` authorization levels, ACL (Access Control List) enablement, and specific requirements for API version 12, this guide provides the necessary framework for implementing secure and compliant device management features. It is an essential resource for enterprise developers, system architects, and security professionals aiming to build robust administrative controls for managed devices, ensuring that applications adhere to the strict security protocols of the operating system.
