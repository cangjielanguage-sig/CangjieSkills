This directory provides comprehensive documentation for the `class_FuncType` module within the Cangjie AST package. It focuses on the structural definition of function types in the abstract syntax tree, detailing how nodes represent parameters, return values, and associated syntax elements like arrows and parentheses. Additionally, it covers essential utilities for traversing these syntax trees using the visitor pattern, enabling programmatic analysis and manipulation. Key topics include AST node construction, lexical token management, inheritance hierarchies, and traversal control mechanisms such as early termination. This resource is designed for software developers, language engineers, and compiler designers who are building tools for the Cangjie language or performing static analysis. It serves as a practical guide for those needing to understand the internal representation of function types and implement custom logic for walking through syntax tree structures.
