# 使用约束

This directory provides comprehensive technical documentation regarding usage constraints within the ArkUI framework, specifically focusing on UI adaptation and mirroring capabilities for internationalization. It covers the handling of right-to-left (RTL) language support, automatic layout adjustments, and specific component behaviors. The content includes reference indices for basic and advanced UI components, universal attributes, and detailed guidelines for implementing mirroring in layouts, Canvas, and XComponent. It is suitable for software developers and UI designers seeking to ensure compatibility and proper localization in their applications.

### 使用约束_4.md 使用约束_4.md
This document outlines specific usage constraints and adaptation requirements for implementing mirroring capabilities in a UI framework. It covers three main scenarios: interface layout and border settings, the Canvas component, and the XComponent component. Key takeaways include the necessity to replace absolute direction indicators like left/right with generalized start/end parameters to support adaptive mirroring. Additionally, the document specifies that the Canvas component only supports text mirroring, while the XComponent component does not support mirroring at all. This reference guide targets developers and UI designers working on internationalization or bidirectional interface adaptation who need to understand specific component behaviors and coding standards. Keywords: mirroring capabilities, UI layout, Canvas, XComponent, start/end parameters, internationalization, bidirectional support, usage constraints.
