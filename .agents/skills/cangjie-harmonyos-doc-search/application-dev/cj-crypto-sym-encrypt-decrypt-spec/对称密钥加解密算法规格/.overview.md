# 对称密钥加解密算法规格

This directory contains technical specifications for symmetric key encryption algorithms within the CryptoArchitectureKit. It covers implementation details, supported encryption modes (ECB, CBC, GCM, etc.), padding mechanisms, and string parameter formatting for algorithms like 3DES, SM4, and AES. The documents guide developers on how to construct algorithm specifications and handle key lengths. It is suitable for developers integrating cryptographic functions who need a reference for configuring encryption parameters and understanding block cipher constraints.

## Detailed Description

### 3DES.md 3DES.md
This technical reference document outlines the implementation and usage of the 3DES encryption algorithm within the CryptoArchitectureKit. It covers the algorithm's definition, supported encryption modes (ECB, CBC, OFB, CFB), padding mechanisms, and the specific string parameter format required for instance creation. Key information includes the requirement for 64-bit block padding, where PKCS5 and PKCS7 pad to 8 bytes, and the syntax "3DES[192]|Mode|Padding" for specifying algorithm specs. It also notes that key length can be omitted to rely on actual input. This guide targets developers integrating cryptographic functions, requiring knowledge of symmetric encryption concepts.

### SM4_2more.md SM4_2more.md
This technical reference document outlines the implementation and configuration of the SM4 symmetric encryption algorithm. It details the seven supported encryption modes, including ECB, CBC, and GCM, and explains padding requirements due to the 128-bit block size. Key sections cover padding modes (NoPadding, PKCS5, PKCS7) and the specific syntax for constructing string parameters used to instantiate cryptographic objects. Important takeaways include the fact that PKCS5 and PKCS7 are treated as 16-byte padding for SM4, and stream modes like CTR and GCM effectively ignore padding. This documentation is intended for developers configuring cryptographic specifications, requiring an understanding of block ciphers and encryption parameters.

### 对称密钥加解密算法规格_2more.md 对称密钥加解密算法规格_2more.md
This document specifies the supported symmetric key encryption algorithms, focusing on AES modes and configuration parameters for a cryptographic library. It details seven AES encryption modes (ECB, CBC, OFB, CFB, CTR, GCM, CCM), padding requirements, and key length options (128, 192, 256 bits). Users construct algorithm specifications using string parameters combining algorithm type, mode, and padding (e.g., "AES128|ECB|PKCS7"). It notes that PKCS5 and PKCS7 are treated identically for AES, and API version 12 supports omitting key length in the parameter string. This reference guide targets developers implementing encryption who need to understand specific mode constraints and parameter formatting.
