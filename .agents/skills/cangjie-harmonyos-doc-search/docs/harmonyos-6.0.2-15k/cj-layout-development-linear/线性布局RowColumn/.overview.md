# 线性布局RowColumn

This directory focuses on linear layouts within the ArkUI framework, specifically utilizing Row and Column containers to arrange child elements horizontally or vertically. It covers fundamental concepts like main and cross axes, spacing, and adaptive techniques such as stretching and scrolling to handle different screen sizes. The content also details alignment strategies for precise positioning. Designed for HarmonyOS developers using the Cangjie language, this guide provides the necessary tools to build responsive and structured user interfaces efficiently.
