# Deriving_示例

This directory provides comprehensive documentation and examples for the Cangjie programming language's Deriving feature, specifically focusing on the `@Derive` macro. It covers automatic interface implementation for classes and enums, including syntax rules, field collection, and advanced customization using attributes like `@DeriveInclude` and `@DeriveOrder`. Additionally, it addresses handling generic types and constraints. The content is designed for Cangjie developers looking to reduce boilerplate code and automate the implementation of common interfaces such as `ToString`, `Hashable`, and `Equatable` while maintaining runtime performance.

## Detailed Description

### Deriving_示例.md
This document serves as a tutorial for the Cangjie programming language's Deriving feature, demonstrating how to automatically implement interfaces like ToString for classes and enums. It covers basic implementation, field collection rules, class constraints, and advanced customization using attributes like DeriveExclude, DeriveInclude, and DeriveOrder. Key takeaways include that Deriving collects constructor fields but excludes static properties and private fields; derived classes must be final. Properties require explicit inclusion, and output order can be customized. This guide targets Cangjie developers seeking to reduce boilerplate code through automatic code generation.

### 常见的_Deriving_语法_4more.md
This technical reference guide explains the usage and syntax of the `@Derive` macro in the Cangjie programming language for automatically implementing common interfaces. It covers macro syntax rules, field and property inclusion or exclusion using `@DeriveInclude` and `@DeriveExclude`, supported interfaces (`ToString`, `Hashable`, `Equatable`, `Comparable`), and customizing comparison order with `@DeriveOrder`. Key takeaways include that the macro supports comma-separated lists, private members cannot be derived, and static members are ignored. This guide targets Cangjie developers seeking to automate boilerplate code for data structures and sorting logic.

### 泛型_2more.md
This technical guide explains how to implement interfaces for generic types in the Cangjie programming language, focusing on constraint application and the `@Derive` macro. Main sections cover manual extension with `where` clauses, default constraint behavior, and methods to override or customize constraints for specific interfaces. Key information includes that `@Derive` automatically applies constraints to generic parameters, but custom constraints must be specified individually for each derived interface. It also clarifies that deriving uses macros rather than reflection, ensuring runtime performance comparable to hand-written code, though it increases compilation time. This guide targets Cangjie developers familiar with generics and object-oriented programming concepts.
