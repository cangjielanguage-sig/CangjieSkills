# cangjie-language-server

This directory encompasses the core infrastructure and documentation for the Cangjie Language Server, a vital backend service designed to power language features in Integrated Development Environments (IDEs) supporting the Cangjie programming language. It acts as the central point of reference for understanding how the server communicates with clients to deliver essential functionalities such as syntax highlighting, code diagnostics, and symbol navigation. The content is structured to assist developers in setting up a robust language service protocol (LSP) implementation, covering everything from initial configuration to ongoing maintenance. It is highly suitable for IDE plugin creators, language tooling engineers, and system integrators who need to embed Cangjie support into their applications. By utilizing the guides and configurations provided in this directory, developers can significantly enhance the user experience for Cangjie programmers, providing them with a seamless, responsive, and intelligent coding environment.

## Detailed Description

### [1] LSPServer_manual/

This directory contains the reference manual for the Cangjie Language Server, aiming to provide a comprehensive configuration and startup guide for IDE developers or users. The documentation details how to utilize the server to provide IDE language services, covering feature introductions, usage instructions, and an in-depth analysis of startup parameters. Core content includes the implementation of key functions such as definition jumping, finding references, and code completion, as well as fine-grained control over logging, crash log generation, and auto-import functions through command-line arguments. This manual is particularly suitable for developers who need to integrate Cangjie language support, requiring readers to have a basic understanding of the LSP protocol and command-line operation capabilities. Through this document, users can quickly master server deployment and debugging skills to ensure the efficient operation of the development environment. As the Cangjie language evolves, this manual serves as the stable foundation for tooling support, ensuring that IDE integrations remain consistent and reliable across different versions.
