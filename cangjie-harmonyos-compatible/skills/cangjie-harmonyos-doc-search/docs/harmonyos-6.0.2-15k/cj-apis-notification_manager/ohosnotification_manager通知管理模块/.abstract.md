This module provides comprehensive API reference documentation for the `ohos.notification_manager` in the Cangjie programming language, designed for HarmonyOS application development. It covers the creation, configuration, and management of system notifications, including various content types like text, pictures, and live views, as well as notification channels (slots) and interaction controls. Developers can find detailed specifications for classes, enumerations, and functions to handle notification lifecycles, permissions, and distributed capabilities. This resource is suitable for software engineers and system developers implementing robust notification features in their applications.
