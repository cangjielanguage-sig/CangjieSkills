# 发起认证

This directory provides a complete technical guide for initiating user identity authentication requests designed to access protected system data securely. It encompasses the full development lifecycle, from API interface descriptions to the implementation of the unified user authentication widget. Key technical areas include the utilization of core functions such as `getUserAuthInstance`, `on`, `off`, and `start`, alongside the configuration of critical parameters like `AuthParam` and `WidgetParam`. The documentation supports diverse security methods, including face recognition, fingerprint verification, and lock screen passwords, while emphasizing the security and UI advantages of the unified widget. It is specifically tailored for application developers responsible for implementing secure authentication features, requiring a solid understanding of API integration, permission handling (specifically `ACCESS_BIOMETRIC`), and secure coding practices.

### 示例代码/
This directory serves as a comprehensive collection of Cangjie code examples designed to assist developers in implementing robust user authentication mechanisms using the UserAuthenticationKit. The content covers a wide range of security scenarios, including basic Face and PIN authentication at Trust Level ATL3, as well as advanced methods like device unlock reuse and arbitrary app reuse. Key technical concepts demonstrated include the configuration of `AuthParam` and `WidgetParam`, instance acquisition, event listener subscription, and asynchronous error handling. These examples are specifically tailored for developers looking to integrate secure identity verification and biometric features into their applications, offering practical guidance on managing security APIs and authentication workflows effectively. By following these code structures, developers can ensure their applications meet high security standards while providing a smooth user experience.
