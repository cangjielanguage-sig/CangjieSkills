This directory contains the essential API documentation for the `cj-apis-image-interop` module, specifically focusing on the `ohos.image.interop` package. The core function of this module is to enable robust interoperability between Cangjie's native `PixelMap` data structures and the ArkTS runtime environment. It provides a detailed technical overview of the `JSSystemObjectInteropType` interface and the extended `PixelMap` class, highlighting the static and instance methods necessary for effective type conversion. Key functionalities include the `fromJSValue` method for transforming ArkTS JSValue into PixelMap, and the `toJSValue` method for the reverse conversion, both of which rely on a `JSContext` parameter. This documentation is specifically curated for Cangjie developers who are integrating image processing features across different language boundaries. Users are expected to have a working knowledge of the ImageKit framework and the specific interop mechanisms used within ArkTS to fully leverage the capabilities described herein.
