This directory focuses on the methods and techniques for binding gesture recognition to UI components within the ArkUI framework using the Cangjie language. It covers standard gesture binding, priority handling, parallel execution, and event response mechanisms. Key topics include `TapGesture`, `priorityGesture`, `parallelGesture`, and conflict resolution. It is suitable for developers and UI engineers looking to implement interactive touch interfaces, manage gesture hierarchies, and handle complex user interactions in HarmonyOS applications.
