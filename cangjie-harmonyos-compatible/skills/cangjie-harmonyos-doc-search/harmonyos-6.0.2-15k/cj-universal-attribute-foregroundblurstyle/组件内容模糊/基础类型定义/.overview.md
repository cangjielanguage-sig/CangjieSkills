# 基础类型定义

This directory contains API reference documentation for fundamental data structures used in the ArkUI framework with the Cangjie language. It primarily focuses on types related to visual effects, specifically blur configurations and color adaptation. The content includes class definitions for blur options and style settings, as well as enumerations for adaptive color modes. These definitions are essential for developers implementing complex visual effects like grayscale blurring, content blurring, and dynamic color masking. Suitable for ArkUI application developers using Cangjie who need to manipulate UI appearance and visual styles.

### class_BlurOptions.md class_BlurOptions.md
This document serves as API reference documentation for the BlurOptions class in the Cangjie language, designed to handle grayscale blur parameters within the ArkUI framework. The content covers the class definition, the public property grayscale including its type and value constraints, and the class constructor used to initialize the object. Key details include that grayscale is a VArray<Float32, $2> with a valid range of 0 to 127. The class is available starting from version 12 and requires the full ArkUI system capability. This reference is intended for developers using the Cangjie language to build ArkUI applications who need to implement grayscale blur effects.

### enum_AdaptiveColor.md enum_AdaptiveColor.md
This document serves as API reference documentation for the AdaptiveColor enumeration used in ArkUI development. It details the enum definition and its two specific values: DEFAULT and AVERAGE. Key takeaways include that DEFAULT mode avoids time-consuming color blurring by using a default mask color, while AVERAGE mode applies color blurring to calculate the average color of a specific area for the mask. Both options are available starting from system version 12. This reference is intended for UI developers working with the ArkUI framework who need to configure color extraction and masking behaviors in their applications.
