# 基础类型定义

This directory provides essential API reference documentation for fundamental data structures used in handling touch interactions within the ArkUI framework, specifically designed for the Cangjie language. It comprehensively covers classes representing touch events and individual touch objects, detailing properties such as event types, coordinates, timestamps, and unique identifiers. Key concepts include event propagation, multi-touch support, and the distinction between different coordinate systems and refresh rates. This documentation is highly suitable for developers building responsive user interfaces who need to manage, interpret, and respond to raw touch data effectively in their applications.

## Detailed Description

### class_TouchEvent.md class_TouchEvent.md
This document serves as API reference documentation for the Cangjie TouchEvent class, designed to handle touch event data within the ArkUI framework. It covers the class definition, properties such as eventType, touches, changedTouches, timestamp, target, and source, as well as the constructor parameters. A key takeaway is the distinction between touches, which reports points at the device refresh rate, and changedTouches, which provides resampled points based on the screen refresh rate in non-injection scenarios. This guide is intended for developers using the Cangjie language to manage touch interactions and event propagation in their applications.

### class_TouchObject.md class_TouchObject.md
This API reference document details the TouchObject class in the Cangjie language, designed to represent information about a finger's interaction during a touch event. The documentation outlines the class constructor and six public properties: touchType, id, screenX, screenY, x, and y. Key takeaways include the distinction between screen-relative coordinates and element-relative coordinates, as well as the unique finger identifier for multi-touch support. Intended for ArkUI developers, this document serves as a guide for accessing raw touch data to build responsive user interfaces.
