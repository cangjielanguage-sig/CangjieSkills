This directory provides comprehensive technical guides for HarmonyOS developers using the Cangjie language to implement subscriptions for system environment variable changes. It covers how applications can dynamically detect and respond to system settings updates, such as language changes or screen orientation adjustments. The content details implementation methods across different components, including ApplicationContext, AbilityStage, UIAbility, and ExtensionAbility. By utilizing callbacks like `onConfigurationUpdate` and `EnvironmentCallback`, developers can ensure their applications adapt seamlessly to device configuration changes without restarting. This resource is suitable for developers seeking to enhance application reliability and user experience through dynamic configuration handling.
