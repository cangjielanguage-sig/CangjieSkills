This directory provides technical resources for developing high-performance custom rendering components using the Cangjie language on the OpenHarmony platform. It focuses on the XComponent, a critical UI element for complex graphics scenarios such as camera previews and game rendering. The content covers the integration of Cangjie UI logic with Native C++ using the Foreign Function Interface (FFI), EGL, and OpenGLES. It includes configuration guides for CMake, build profiles, and lifecycle management. This collection is suitable for HarmonyOS developers and C++ programmers looking to bridge Cangjie applications with native graphics capabilities to achieve optimal performance.
