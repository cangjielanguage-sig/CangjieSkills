This directory contains API reference documentation for the `ohos.running_lock` module in the Cangjie programming language, designed for HarmonyOS power management. It covers the `RunningLock` class for preventing system sleep, the `RunningLockType` enum for specifying lock types (such as proximity screen control), and module-level functions for creating locks. Key topics include system power states, sleep prevention, sensor-based screen control, and necessary permissions. This documentation is suitable for Cangjie developers building system applications that require precise control over device power behavior and screen states.
