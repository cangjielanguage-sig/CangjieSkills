This directory contains API reference documentation for the `ohos.arkui.shape` module within the Cangjie ArkUI framework. It provides comprehensive details on defining and manipulating graphical shapes such as rectangles, circles, ellipses, and paths. The documentation covers the abstract `BaseShape` class and its specific implementations, focusing on properties like dimensions, fill, and corner radii. Primarily used for clipping, masking, and basic drawing operations, these APIs are available starting from version 22 and are currently in a Beta stage. This resource is suitable for Cangjie developers looking to implement custom geometric shapes and graphical effects in their UI interfaces.

### class_BaseShape.md class_BaseShape.md
This document serves as API reference documentation for the abstract BaseShape class within the Cangjie ArkUI framework, detailing foundational properties and methods for graphical shapes. The content covers the class definition and specific functional methods including fill, height, width, size, and offset. Key information includes that all methods return This to allow chaining and accept types like ResourceColor and Length. The class requires SystemCapability.ArkUI.ArkUI.Full and is available starting from version 22. This reference is intended for Cangjie developers building UI interfaces who need to manipulate shape attributes programmatically. ### class_PathShape.md class_PathShape.md

Key information includes the required parameters for path dimensions and drawing instructions, with references to supported drawing commands. Targeted at ArkUI developers using Cangjie, this guide assists in implementing custom clipping or masking shapes starting from system version 22.
