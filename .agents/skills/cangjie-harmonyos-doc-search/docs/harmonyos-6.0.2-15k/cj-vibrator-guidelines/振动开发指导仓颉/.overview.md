# 振动开发指导仓颉

This directory serves as a comprehensive technical guide for developers using the Cangjie language to implement haptic feedback in HarmonyOS or OpenHarmony environments. It covers the complete lifecycle of vibration development, from permission application and API usage to custom JSON configuration for complex effects. Key topics include the Vibrator module, SensorServiceKit integration, and haptic pattern design. Suitable for application developers and system integrators, this resource provides the necessary tools and code examples to create responsive, immersive vibration experiences for device interactions such as alarms, calls, and UI feedback.

## Detailed Description

### 场景介绍_2more.md 场景介绍_2more.md
This document serves as a technical guide for the Vibrator module, detailing how to implement diverse vibration effects for device interactions. It covers usage scenarios such as button presses, alarms, and incoming calls, emphasizing control over intensity and duration. The interface section summarizes three core functions: startVibration to trigger specific effects, stopVibration to cease vibration, and isSupportEffect to verify parameter compatibility. Intended for developers integrating haptic feedback, this document provides a functional overview and directs users to comprehensive API references for further details.

### 开发步骤/
This directory provides a structured technical guide for developers working with the Cangjie language to control device vibrations in HarmonyOS or OpenHarmony environments. It covers the complete implementation lifecycle using the SensorServiceKit, starting from the necessary VIBRATE permission applications to the execution of complex vibration patterns. The tutorials detail how to initiate motor vibrations using fixed durations, built-in preset effects, or custom configuration files, as well as how to terminate these vibrations based on specific modes. Key technical concepts include the `startVibration` and `stopVibration` APIs, UIAbilityContext for resource handling, and comprehensive exception management. This resource is specifically designed for application developers who need to integrate haptic feedback into their apps and are looking for practical, code-oriented examples and best practices in system resource management. By following these steps, developers can ensure their applications provide responsive and compliant haptic experiences.

### 振动效果说明/
This directory contains comprehensive technical documentation for configuring and implementing haptic vibration effects within a software environment. It covers the complete JSON schema required for defining custom haptic configurations, including MetaData attributes, Channel parameters, and Pattern events. The documents explain various vibration types such as "transient" and "continuous," detailing specific parameters for frequency, intensity, duration, and timing curves. Additionally, it addresses system constraints like event count limits and file size restrictions. This resource is suitable for developers and system integrators who possess knowledge of JSON formatting and motor control concepts and require precise control over vibration patterns to create immersive, open-ended haptic experiences.
