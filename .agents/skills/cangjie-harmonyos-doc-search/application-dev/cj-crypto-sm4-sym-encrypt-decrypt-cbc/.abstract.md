This directory serves as a specialized technical resource for implementing the SM4 symmetric encryption algorithm within the HarmonyOS development environment. It focuses specifically on the Cipher Block Chaining (CBC) mode combined with PKCS7 padding, utilizing the Cangjie programming language and the CryptoArchitectureKit. The content is designed to assist developers in mastering the complete cryptographic workflow, from the generation of secure 128-bit symmetric keys to the management of initialization vectors (IVs). It is particularly suitable for developers building secure applications that require robust data protection, compliance with Chinese cryptographic standards, and efficient handling of chunked data processing.
