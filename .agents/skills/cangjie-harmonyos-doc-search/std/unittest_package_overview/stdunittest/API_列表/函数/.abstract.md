This directory provides detailed documentation for the core functions within a unit testing package tailored for the Cangjie language. It acts as a central reference for essential testing utilities, categorizing them into assertion functions, expectation functions, configuration management, and test execution entry points. The content clarifies the critical distinction between "assert" functions, which trigger exceptions upon failure, and "expect" functions, which record results without stopping execution. Additionally, it identifies `entryMain` as the designated entry point for the `cjc --test` compiler command. This directory is intended for developers and testers looking to implement robust automated testing logic, requiring a solid grasp of programming concepts and the specific syntax of this testing framework.
