# 扫描工具

This directory provides essential documentation for `app_check_tool.jar`, a robust utility tailored for analyzing and detecting issues within HAP and App installation packages. It covers a wide range of functionalities, including system constraints, usage examples for scanning duplicate files, identifying oversized files, and analyzing file size distribution. Key topics include JSON and HTML output formats, detailed parameter descriptions, and file suffix statistics. This resource is highly suitable for developers and build engineers who need to optimize package structure, troubleshoot application content, and conduct thorough audits of storage usage. By leveraging these guides, users can gain deep insights into their application's composition, manage package bloat effectively, and ensure optimal performance and deployment standards.

## Detailed Description

### 简介_4more.md 简介_4more.md
This document serves as a user guide for the app_check_tool.jar, a utility designed to analyze and detect issues within HAP and App installation packages. It covers the tool's introduction, system constraints, and specific usage examples for scanning duplicate files and identifying oversized files. Key information includes the tool's ability to analyze file size distribution, output results in JSON and HTML formats, and its requirement for Java 8. Detailed parameter descriptions and JSON output field definitions are provided for each scan type. Targeted at developers, this guide helps optimize package structure and troubleshoot application content.

### 统计各类型文件大小占比示例.md 统计各类型文件大小占比示例.md
This document serves as a technical reference for using the app_check_tool to analyze file size distribution within application packages. It details the command-line execution, specifically the --stat-suffix parameter, to generate statistics grouped by file extension. The content includes a comprehensive breakdown of the JSON output schema, explaining fields for task metadata, file suffixes, total sizes, and individual file attributes like compression status. Intended for developers or build engineers, this guide helps in auditing HAP, HSP, or App packages to understand storage usage and identify large file types.
