# cj-router-to-navigation

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie ArkUI framework, specifically targeting the migration from the legacy Router component to the modern Navigation component. In the evolving landscape of HarmonyOS application development, transitioning to the Navigation component is essential for achieving better architectural control and performance. This directory covers the fundamental architectural differences between the two systems, providing deep dives into lifecycle management, routing operations, and the specific management of NavPathStack. It addresses both imperative and declarative routing paradigms and explains stack-based page handling in detail. Additionally, it explores advanced features such as cross-package navigation and shared element transitions, which are critical for creating sophisticated user interfaces. The content is tailored for Cangjie developers, software engineers, and technical architects who are seeking to modernize their application's navigation logic, optimize animation performance, and implement flexible, cross-platform UI structures. By leveraging these guides, developers can ensure their applications are built using the most current and efficient standards available in the ecosystem.
