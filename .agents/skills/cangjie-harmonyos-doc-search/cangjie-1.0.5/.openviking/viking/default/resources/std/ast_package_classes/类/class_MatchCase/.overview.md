# class_MatchCase

This directory contains API documentation for the `MatchCase` class within the Cangjie programming language's Abstract Syntax Tree (AST). It covers the structural definition of match expression case branches, detailing properties for patterns, guards, and the `=>` operator. Additionally, it outlines methods for initialization, token conversion, and tree traversal using the Visitor pattern. This documentation is intended for compiler developers and tool builders who need to programmatically manipulate or analyze Cangjie code structures, specifically focusing on match expression logic and syntax tree navigation.

## Detailed Description

### class_MatchCase_9more.md
This API documentation defines the MatchCase class, which represents a single case branch within a match expression in the Cangjie language's Abstract Syntax Tree (AST). The document details the class structure, its inheritance from the Node class, and provides specifications for eight mutable properties including arrow, block, expr, keywordC, keywordW, patternGuard, and patterns. Key information includes the syntax structure involving case keywords, patterns separated by |, optional where guards, and the => operator, alongside potential ASTException errors for invalid access. This reference is intended for compiler developers or tool builders working with Cangjie AST manipulation.
