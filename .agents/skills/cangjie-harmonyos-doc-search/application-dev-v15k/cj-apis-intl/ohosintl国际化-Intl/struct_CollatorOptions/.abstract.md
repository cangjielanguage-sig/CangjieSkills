This directory provides comprehensive API reference documentation for the `CollatorOptions` struct in the Cangjie programming language, specifically designed for the LocalizationKit. It focuses on the configuration of internationalization (I18n) sorting rules and string comparison behaviors. The content covers the struct's constructor, its seven configurable properties, and parameters for handling locale matching, sensitivity, punctuation, and specific collation types like Pinyin or stroke ordering. It is suitable for Cangjie developers who need to customize sorting logic for multilingual applications, offering insights into default values, data types, and practical implementation examples.
