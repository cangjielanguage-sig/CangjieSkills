This directory provides technical documentation on utilizing system tools to display and debug fundamental information within ArkUI applications. It specifically addresses techniques for extracting window hierarchies, component trees, and navigation stacks using command-line utilities like `hidumper`. The guides cover identifying Window IDs, isolating specific UI nodes, and analyzing route stacks for applications using the Navigation component. These resources are essential for developers and QA engineers seeking to perform deep-level debugging of UI structures, verify window management logic, and troubleshoot page navigation issues in HarmonyOS environments.
