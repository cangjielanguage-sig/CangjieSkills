# cj-traditional-curve

This directory serves as a comprehensive technical resource for understanding traditional curves within the ArkUI framework, specifically tailored for developers utilizing the Cangjie language. It provides an in-depth explanation of the mathematical foundations behind traditional curves, including detailed definitions of cubic Bezier curves and Step curves. Furthermore, it critically examines the limitations of traditional curves in terms of physical realism when compared to physical curves, offering guidance on when to use each approach. The directory includes practical Cangjie code examples that demonstrate how to implement various curve types—such as FastOutSlowIn, Ease, and Linear—within an animation context. This material is essential for ArkUI developers who need to achieve specific animation timing effects or require a deeper understanding of interpolation mechanics.
