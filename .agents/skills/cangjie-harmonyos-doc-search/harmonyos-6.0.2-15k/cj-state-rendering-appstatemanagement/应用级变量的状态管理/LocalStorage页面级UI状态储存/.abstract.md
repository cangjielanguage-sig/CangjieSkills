This directory focuses on page-level UI state management using the LocalStorage mechanism within the Cangjie and HarmonyOS ArkUI frameworks. It comprehensively covers the theoretical concepts of LocalStorage as an in-memory database, usage rules for component tree inheritance, and specific decorators like @LocalStorageProp and @LocalStorageLink for data synchronization. The content includes technical guides, practical code examples, and detailed API references for the LocalStorage class. It is suitable for developers building UIs who need to manage state across components within a package, ensuring robust data persistence and synchronization between the UI and the storage layer.
