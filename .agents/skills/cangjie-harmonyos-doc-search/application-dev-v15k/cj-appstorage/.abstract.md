This directory serves as a comprehensive technical resource for AppStorage, a global UI state storage mechanism specifically designed for Cangjie-based development within the HarmonyOS ecosystem. It addresses the architectural need for application-level data sharing, providing a clear and detailed contrast with page-level LocalStorage to help developers choose the right storage strategy. The documentation thoroughly explores the implementation of reactive state management, focusing on the use of decorators such as @StorageProp and @StorageLink to ensure seamless data synchronization across various UI components. Beyond basic usage, it includes essential API references, defines strict usage constraints, and illustrates practical scenarios for managing complex data types and facilitating state sharing across different UIAbilities. This guide is particularly suitable for developers who aim to decouple their business logic from the user interface, thereby building applications that are both efficient and easier to maintain.
