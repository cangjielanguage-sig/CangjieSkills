This directory contains API reference documentation for the GZip class within the Cangjie programming language, specifically designed for the BasicServicesKit. It provides comprehensive details on interfaces for gzip file compression and decompression, leveraging the underlying Zlib subsystem. The documentation covers essential operations such as opening, reading, writing, and closing compressed files, with a focus on handling byte arrays, file descriptors, and specific error codes. This resource is suitable for developers who need to implement efficient data compression workflows or manage compressed file streams in Cangjie applications.
