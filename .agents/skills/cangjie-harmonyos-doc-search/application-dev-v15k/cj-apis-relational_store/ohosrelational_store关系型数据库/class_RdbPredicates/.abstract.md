This directory contains API reference documentation for the `RdbPredicates` class in the Cangjie programming language, part of the ArkData kit for HarmonyOS. It covers the construction of condition expressions for relational database queries, including logical operations, data filtering, sorting, and grouping. Key topics include query predicates, method chaining, and distributed data synchronization. The documentation is intended for developers building applications that require complex data retrieval and management from relational stores. Note that the class is not thread-safe and requires locking for concurrent access.
