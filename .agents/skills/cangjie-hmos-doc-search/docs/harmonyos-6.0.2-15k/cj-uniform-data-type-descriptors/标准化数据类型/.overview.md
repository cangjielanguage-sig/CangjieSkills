# 标准化数据类型

This directory focuses on the Uniform Type Descriptor (UTD) system within HarmonyOS, designed to standardize data types and resolve ambiguity for cross-application data transfer. It covers core concepts like hierarchical classification, physical vs. logical types, and practical implementation using the Cangjie language. Key topics include querying media types, mapping file extensions to MIME types, and defining custom data types. This resource is suitable for HarmonyOS developers working on file management, data sharing, and system integration who need a robust framework for data classification and type validation.

### Detailed Description

#### 场景介绍_4more.md
This document introduces the Uniform Type Descriptor (UTD) system in HarmonyOS, designed to resolve data type ambiguity and facilitate cross-application data transfer. It covers UTD design principles, hierarchical classification structures, and the specific attributes defining a type descriptor. Key information includes the distinction between physical (general.entity) and logical (general.object) classifications, which support inheritance and complex data management. The document details the structure of type definitions, including unique IDs, belonging types, and associated MIME types or extensions. This guide targets HarmonyOS developers implementing file management, sharing, or data search features who require a standardized approach to data typing.

#### 如何查询媒体类文件归属类型.md
This tutorial provides a step-by-step guide on using the Uniform Type Descriptor (UTD) module to query and verify media file types in the Cangjie language. The document covers querying data types by filename extension and MIME type, comparing type equality, and checking hierarchical belonging relationships. Key takeaways include using functions like getUniformDataTypeByFilenameExtension and belongsTo to validate if a specific type, such as general.mp3, falls under a broader category like general.audio. This guide is intended for developers implementing file type identification and validation logic.

#### 如何通过文件后缀获取对应的MIMEType列表_2more.md
This technical tutorial demonstrates how to bidirectionally map file extensions and MIME types using the uniformTypeDescriptor module in the Cangjie language. It covers two primary workflows: retrieving MIME types from a file extension (e.g., ".mp3") and retrieving file extensions from a MIME type (e.g., "audio/mp3"). The guide provides step-by-step code examples utilizing functions like getUniformDataTypeByFilenameExtension and getUniformDataTypeByMIMEType to query Uniform Type Descriptor (UTD) data types and extract associated lists. Intended for software developers working on file handling or data classification who need to programmatically resolve file type metadata.

#### 接口说明.md
This document serves as a quick reference guide for common Uniform Type Descriptor (UTD) interfaces used for managing standardized data types. It covers the UniformDataType enumeration and functions for type hierarchy validation, such as checking type belongingness and level relationships. Additionally, it details methods for querying data type IDs based on filename extensions or MIME types. The interfaces support both preset and custom data types, allowing developers to determine type relationships and retrieve specific type identifiers efficiently. This technical reference is intended for software developers integrating data type handling into their applications, requiring knowledge of basic type systems.

#### 应用自定义数据类型/
This directory provides comprehensive technical guidance for HarmonyOS developers on implementing custom data types using the Uniform Type Descriptor (UTD) framework. It addresses scenarios where standard data types are insufficient, enabling seamless cross-device and cross-application data interaction. The content covers both theoretical principles—such as UTD hierarchy validation, registration processes, and configuration constraints—and practical implementation steps. Developers will learn how to define proprietary formats, manage essential fields like TypeId, and ensure compliance with system requirements. This resource is essential for those looking to standardize data formats, extend existing types, or facilitate robust data sharing across the HarmonyOS ecosystem.
