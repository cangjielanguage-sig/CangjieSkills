# 注册控制命令

This directory provides technical guides for implementing media control commands in applications using the AVSessionKit framework and the Cangjie language. It covers essential playback features such as loop modes, fast forward, rewind, favorites, and progress seeking. The documentation details how to register specific commands, handle callbacks, and synchronize application states with the system's playback center. It is intended for HarmonyOS developers building media or telephony applications who need to integrate system-level media controls and ensure seamless user interaction with the playback interface.

## Detailed Description

### 循环模式.md 循环模式.md
This technical guide explains how to implement and synchronize loop mode controls for music applications using the AVSessionKit framework. It details the four fixed system loop modes: Random, Sequential, Single, and List. The document emphasizes that applications must listen for mode change instructions and report the updated LoopMode back to the system via AVPlaybackState. It also addresses mapping custom application modes to the fixed system modes. A Cangjie code example is provided to demonstrate setting up the event listener and updating the playback state. This guide is intended for developers building media applications who need to ensure their internal playback logic aligns with the system's control center.

### 快进快退_2more.md 快进快退_2more.md
This technical guide demonstrates how to implement media control features, specifically fast forward, rewind, and favorites, using the Cangjie language and AVSessionKit. The document covers two primary topics: configuring playback skip intervals and handling the toggle favorite command. Key information includes using AVMetadata to set skip durations, registering specific callbacks like FastForwardCallback and ToggleFavoriteCallback to respond to user actions, and updating AVPlaybackState to reflect status changes. Intended for application developers, this tutorial provides practical code examples for managing session-based media interactions and control responses.

### 注册控制命令_2more.md 注册控制命令_2more.md
This technical guide explains how to register and manage control commands for applications integrating with AVSession to enable playback center interactions. The document details specific control commands for media resources, such as play, pause, seek, and setSpeed, as well as commands for call applications like answer and hangUp. It emphasizes that commands must be registered via the on interface before session activation. Additionally, it explains how to handle unsupported commands by using the off interface to unregister them, which results in the playback center graying out the corresponding controls. The guide includes a Cangjie code example demonstrating the unregistration process. This reference material is intended for application developers implementing multimedia or telephony features who need to configure session control capabilities.

### 进度控制.md 进度控制.md
This document serves as a technical tutorial for implementing progress control and seek functionality in media applications using the Cangjie language and AVSessionKit. The content covers defining a SeekCallBack class, registering the callback with an AVSession, and managing playback states during the seek operation. Key takeaways include setting the state to PLAYBACK_STATE_BUFFERING to handle latency, performing the internal seek, and subsequently updating the state to PLAYBACK_STATE_PLAY with the new position and timestamp. This guide targets HarmonyOS developers who need to synchronize application playback with system media controls.
