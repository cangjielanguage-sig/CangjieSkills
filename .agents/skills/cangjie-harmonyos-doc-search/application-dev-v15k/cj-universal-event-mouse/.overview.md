# cj-universal-event-mouse

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language within the ArkUI framework, specifically focusing on universal mouse event handling mechanisms. It provides essential documentation and structural guidance for integrating mouse inputs into HarmonyOS applications, covering everything from basic event definitions to complex interaction logic. The content is meticulously tailored for developers targeting API version 12 and above, offering deep insights into the `MouseEvent` class, event registration processes, and state management strategies. By exploring this directory, developers will learn how to effectively manage user interactions such as hovering, clicking, and tracking coordinates, ensuring a responsive and intuitive user experience across various device environments. This collection is crucial for anyone looking to master input handling in the evolving Cangjie ecosystem, providing the necessary tools to create sophisticated and interactive user interfaces.

## Detailed Description

### 鼠标事件/
This subdirectory is dedicated to the comprehensive handling of mouse events within the ArkUI framework, specifically implemented using the Cangjie programming language. It provides a thorough breakdown of the `MouseEvent` class, detailing its fundamental definitions and the critical properties necessary for tracking user input, such as precise screen coordinates, specific button types (left, right, middle), and action timestamps. Beyond theoretical definitions, the directory includes practical implementation examples that demonstrate how to handle common UI interactions, including element hovering effects and click detection logic. Furthermore, it offers detailed API references for the `onMouse` callback, guiding developers through the proper setup of event listeners and efficient state management to ensure application stability. This documentation is particularly valuable for HarmonyOS developers aiming to build robust applications with rich mouse support, ensuring full compatibility with API version 12 and newer standards. The examples provided help bridge the gap between abstract API definitions and real-world application behavior, making it easier to implement complex input scenarios.
