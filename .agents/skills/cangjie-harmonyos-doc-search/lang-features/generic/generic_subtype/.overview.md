# generic_subtype

本目录深入探讨了仓颉编程语言中泛型系统的核心概念，特别是泛型类型的子类型关系及其型变规则。内容涵盖了泛型实例化后的继承逻辑、协变、逆变以及不型变的精确定义。重点介绍了仓颉语言中用户自定义泛型默认为不型变的特性，并解释了即使存在子类型关系，泛型容器之间通常也不自动继承的规则。此外，文档还涉及了内建类型（如元组和函数）的特殊处理规则。该资料适合希望深入理解仓颉类型系统安全性、限制及底层逻辑的开发者阅读，有助于编写更安全、更规范的代码。

### generic_subtype.md generic_subtype.md
本文档旨在阐述仓颉语言中泛型类型的子类型关系及型变规则。主要内容包括泛型实例化后的继承逻辑、型变（协变、逆变、不型变）的具体定义，以及仓颉中用户自定义泛型默认为不型变的特性。关键信息指出，即使存在子类型关系，泛型容器间也不自动继承（如 I<D> 不是 I<C> 的子类型），除非类型参数完全相同，但内建类型（如元组、函数）有特殊规则。文档面向仓颉语言开发者，帮助理解类型系统的安全性与限制。
