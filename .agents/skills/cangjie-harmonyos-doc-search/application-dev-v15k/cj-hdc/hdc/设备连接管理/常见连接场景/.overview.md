# 常见连接场景

This directory serves as a comprehensive technical resource for developers and system administrators working with the HarmonyOS Device Connector (HDC) tool. It focuses on various common connection scenarios required for effective device debugging and management. The content covers essential procedures for linking devices to PCs via USB and TCP, as well as establishing complex remote connections between separate client and server machines. Key topics include environment verification, command-line syntax for network forwarding, and stability considerations for different connection types. Whether setting up a local debugging environment or managing remote device interactions, users will find practical guidance on configuring hardware, drivers, and network settings. These guides are designed for technical professionals who require reliable connectivity solutions for their development and testing workflows within the HarmonyOS ecosystem, ensuring they can execute commands and manage devices efficiently across different network configurations.

### USB连接场景_2more.md USB连接场景_2more.md
This technical guide provides instructions for connecting devices to a PC using the HDC tool via USB and TCP. It details environment confirmation and connection steps for both methods. Key information includes verifying USB hardware, drivers, and direct port usage for stable USB connections, and ensuring network stability for TCP connections using specific IP and port commands. Intended for developers setting up device debugging environments, this guide requires basic knowledge of command-line interfaces and network settings. Keywords: HDC, USB connection, TCP connection, device debugging, HarmonyOS, wireless debugging, environment setup.

### 远程连接场景.md 远程连接场景.md
This technical guide explains how to establish a remote connection between an HDC client and server running on separate PCs. It covers the command syntax using the -s parameter to specify IP addresses and ports, detailing parameters, return values, and usage examples. The document provides a step-by-step tutorial for configuring the server to start network forwarding and executing commands from the client. Key takeaways include the specific command format and the note that the -s flag overrides environment variables. This guide is intended for developers or system administrators managing remote device debugging scenarios.
