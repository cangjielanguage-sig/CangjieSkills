This directory serves as an essential resource for Cangjie developers seeking to master performance tracking and distributed tracing using the HiTraceMeter framework. It provides a deep dive into the theoretical mechanics of the tool, specifically its integration with kernel ftrace buffers, alongside practical tutorials for coding and verification. The guide covers critical technical areas such as asynchronous time-slice tracking APIs, unique task ID management, and command-line log capturing. Designed specifically for users of DevEco Studio, this documentation enables developers to rigorously analyze system performance, monitor detailed process trajectories, and optimize business logic execution. It is the definitive reference for building high-performance, observable Cangjie applications.
