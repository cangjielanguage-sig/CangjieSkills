This directory provides comprehensive API reference documentation for the `MacroExpandExpr` class and associated utility functions within the Abstract Syntax Tree (AST) of the Cangjie programming language. It focuses on the structural representation of macro invocation nodes, detailing their properties, initialization, and behavior. The documentation also covers essential methods for converting AST nodes back into token collections and traversing the syntax tree using the Visitor pattern. Key concepts include macro syntax handling, token validation, and AST traversal customization. This resource is designed for compiler developers, language tool creators, and software engineers involved in the parsing, analysis, or transformation of Cangjie code.
