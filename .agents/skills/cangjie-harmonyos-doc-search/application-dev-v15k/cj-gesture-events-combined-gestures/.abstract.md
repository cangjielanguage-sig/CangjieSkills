This directory is a comprehensive technical guide dedicated to the implementation of combined gestures within the Cangjie ArkUI framework. It focuses extensively on the `GestureGroup` API, providing developers with the knowledge required to utilize the three core recognition modes: Sequence, Parallel, and Exclusive. The content addresses complex user interaction scenarios, such as processing simultaneous touch events, resolving competitive recognition between gestures like single and double taps, and chaining gestures sequentially to perform actions such as dragging. By including practical code examples that demonstrate state management and event callbacks, this resource serves as an essential tool for Cangjie developers and UI engineers aiming to build sophisticated, responsive user interfaces with advanced touch handling capabilities.
