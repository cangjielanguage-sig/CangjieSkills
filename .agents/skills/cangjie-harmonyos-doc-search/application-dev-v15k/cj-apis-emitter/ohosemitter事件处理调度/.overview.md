### enum_EventPriority.md enum_EventPriority.md
This document provides API reference documentation for the Cangjie EventPriority enum, which defines the precedence levels for event dispatching within the SystemCapability.Notification.Emitter module. The main sections enumerate four specific priority levels: IMMEDIATE, HIGH, LOW, and IDLE, detailing their relative execution order. Key information includes the fact that LOW is the default priority, IMMEDIATE triggers instant delivery, and IDLE events are handled only when no other events are pending.
