# extendT_CPointerT

This directory contains API documentation for extending the `CPointer` type within the Cangjie programming language. It focuses on low-level memory manipulation, providing essential interfaces for pointer arithmetic, resource management, and data access. Key topics include automatic memory release using `asResource`, null checks, reading and writing data, and pointer offsetting operations. These extensions are designed for developers working on C interoperability who need to manage raw pointers manually. Users must operate within unsafe contexts to ensure safety and prevent undefined behavior, and the generic type `T` must satisfy the `CType` constraint.
