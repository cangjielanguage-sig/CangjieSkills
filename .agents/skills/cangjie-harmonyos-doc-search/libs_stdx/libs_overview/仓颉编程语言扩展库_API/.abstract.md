This directory serves as the central repository for the API documentation and technical usage guidelines of the Cangjie programming language's extension library, known as stdx. It provides a structured overview of domain-specific packages designed to complement the standard library, covering advanced functionalities such as Aspect-Oriented Programming (AOP), cryptographic operations, data compression, network protocols, and unit testing. Additionally, it offers critical instructions for developers on how to configure build environments, manage dependencies, and handle OS-specific linking for Linux, macOS, and Windows. This resource is essential for Cangjie developers who need to integrate specialized libraries like `crypto`, `net`, and `encoding` into their software projects, ensuring they understand both the available APIs and the compilation requirements necessary to utilize these external modules effectively. Since these libraries are not distributed with the compiler, this documentation is vital for guiding users through the separate download and integration process.
