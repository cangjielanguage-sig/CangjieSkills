# 无障碍属性

This directory provides comprehensive API reference documentation for implementing accessibility features within the ArkUI framework using the Cangjie language. It covers essential properties and functions designed to optimize applications for users with disabilities, particularly those relying on screen readers and assistive technologies. Key topics include setting component descriptions, managing accessibility levels, grouping components, and configuring virtual nodes for custom UIs. This documentation is suitable for Cangjie and ArkUI developers aiming to ensure their applications are inclusive, compliant with accessibility standards, and provide a seamless experience for all users.

## Detailed Description

### func_accessibilityDescript_4more.md func_accessibilityDescript_4more.md
This document provides API reference documentation for Cangjie developers implementing accessibility features within the ArkUI framework. It covers four specific functions: accessibilityDescription (supporting both String and AppResource), accessibilityLevel, and accessibilityTextHint. The content explains how to set detailed component descriptions, control visibility to assistive services, and provide textual hints. Key information includes the specific values for accessibility levels, such as "auto" and "no-hide-descendants," and the reading order where descriptions follow component text. This guide is intended for developers aiming to optimize their applications for users with disabilities using screen readers and other assistive technologies.

### func_accessibilityVirtualN_2more.md func_accessibilityVirtualN_2more.md
This API reference document details the accessibilityVirtualNode function used to configure accessibility virtual child nodes for self-drawn components in the ArkUI framework. The content includes the function signature, system capabilities, version requirements, and parameter definitions, specifically highlighting the builder parameter for custom UI descriptions. Key information explains that these virtual nodes are laid out but not visually displayed, allowing assistive applications to retrieve node information. The document targets Cangjie developers building custom UIs who need to ensure accessibility compliance, requiring knowledge of Builder and bind methods.

### 无障碍属性_4more.md 无障碍属性_4more.md
This document serves as an API reference for configuring accessibility properties in Cangjie-based ArkUI components. It details three primary functions: accessibilityGroup for managing component grouping, and two overloads of accessibilityText for setting descriptive text via String or AppResource. Key concepts include enabling grouping to merge child components into a single selectable unit and defining custom text for screen readers to assist users with visual impairments. The documentation specifies that accessibility text overrides standard text attributes and explains text concatenation logic for grouped components. This guide targets ArkUI developers using the Cangjie language who need to implement accessibility features in their applications.
