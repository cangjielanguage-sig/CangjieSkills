# native代码

This directory contains C++ source code and documentation for native graphics rendering on HarmonyOS and OpenHarmony systems. It focuses on integrating hardware-accelerated 2D/3D graphics using OpenGL ES 3.0 and the NativeXComponent API. The content covers the complete graphics pipeline, including EGL context management, native window handling, and plugin lifecycle operations. Key components include wrappers for EGL contexts, managers for surface IDs, and renderers for drawing geometric patterns. This material is suitable for C++ developers and graphics engineers working on high-performance visual effects in native environments.

## Detailed Description

### egl_coreh.md egl_coreh.md
This document defines the `EGLCore` class, a C++ header file serving as an API wrapper for managing EGL contexts and OpenGL ES 3.0 rendering operations. It outlines the class structure, separating public lifecycle management methods like `EglContextInit`, `Draw`, and `Release` from private helper functions for shader compilation and geometry execution. Key functionality includes initializing the display and surface, handling window resizing, and rendering specific shapes such as stars with rotation transformations. It is intended for native graphics developers needing interface definitions to integrate hardware-accelerated graphics via the NativeXComponent framework.

### plugin_managercpp.md plugin_managercpp.md
This C++ source file implements the `PluginManager` class to manage the lifecycle and rendering operations of native plugin surfaces within a HarmonyOS application. It covers surface creation and destruction, window management, and rendering commands like drawing patterns and changing colors. The code utilizes static maps to track `PluginRender` instances and `OHNativeWindow` objects associated with specific surface IDs. Key functions include `SetSurfaceId` for initialization, `DestroySurface` for cleanup, and methods to update window dimensions or trigger visual updates. The class acts as a central controller bridging surface IDs with their corresponding native rendering contexts.

### egl_corecpp/
