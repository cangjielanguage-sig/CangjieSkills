# Video

This directory provides comprehensive documentation for the Video component within the ArkUI framework, specifically utilizing the Cangjie programming language. It covers the complete lifecycle of video integration, from component creation and initialization to advanced property configuration, event handling, and playback control via the VideoController. Key topics include network permissions, supported formats (mp4, mkv, TS), AI features, and UI customization. This resource is suitable for HarmonyOS developers seeking to implement robust video playback functionality, manage media states, and handle user interactions in their applications.

## Detailed Description

### Video_3more.md Video_3more.md
This document serves as a reference guide for the Video component, designed to play video files and manage playback states. It covers the component's basic description, required permissions for network access, and constraints regarding child components. Key takeaways include the limitation that the component only supports simple playback and cannot handle complex scenarios, the necessity of the `ohos.permission.INTERNET` permission for network videos, and the fact that it does not support child components. This technical reference is intended for developers integrating basic video functionality into their applications.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the implementation of a video player interface within a HarmonyOS application. The content focuses on the EntryView component structure, Video component configuration, and event handling for various playback controls. Key takeaways include the usage of VideoController methods for starting, pausing, stopping, seeking to specific timestamps, and managing fullscreen states, as well as state management for playback speed adjustments. This example targets HarmonyOS developers using the Cangjie language who need to integrate video playback functionality into their UI applications.

### 组件事件.md 组件事件.md
This document serves as an API reference for video playback component events within the ArkUI framework using the Cangjie language. It details event handling functions covering playback lifecycle management, including state changes like start, pause, and stop, as well as progress tracking via seeking and update events. Additionally, it covers status notifications for errors, completion, preparation, and fullscreen toggles. All methods accept a specific callback function and return the component instance to support method chaining. Most features are available from version 12, with the onStop event introduced in version 19. This guide targets software developers implementing video player controls and monitoring playback behavior in ArkUI applications.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring properties of a video component within the ArkUI framework using the Cangjie language. It details methods for playback control, UI display, and advanced AI features. Specific functions covered include autoPlay, controls, loop, muted, objectFit, and enableAnalyzer. Key information includes default values for boolean states and specific constraints for the AI analyzer, which requires custom controls and conflicts with the overlay attribute. This technical reference is intended for software developers integrating video playback and analysis features into applications, providing system capability requirements and version availability for each method.

This concise guide is intended for developers and system integrators who need to verify compatibility or understand the baseline capabilities of components. ### 创建组件/
This directory contains API documentation for creating and initializing video components within the ArkUI framework using the Cangjie programming language. It covers various constructor overloads that allow developers to configure video sources (AppResource or String), playback speeds (Float64 or PlaybackSpeed enum), preview images, and controllers. The documentation details supported video formats like mp4, mkv, and TS, and specifies necessary permissions for network access. This resource is suitable for HarmonyOS developers looking to implement robust video playback features in their applications.
