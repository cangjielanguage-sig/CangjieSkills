### cj-grid-layout-rowsplit.md cj-grid-layout-rowsplit.md

This file acts as the definitive API reference for the RowSplit component in the ArkUI framework, tailored for developers using the Cangjie language. The primary function of this component is to arrange child components horizontally while incorporating vertical dividers. The documentation provides a thorough explanation of the component's initialization function and enumerates the common attributes that developers can utilize. A significant portion of the text is dedicated to the `resizeable` property, which empowers users to drag dividers to adjust the width of the layout areas dynamically. Additionally, the document outlines important behavioral constraints, specifically noting that child widths are fixed upon initialization and cannot be altered through code later, though they remain adjustable through dragging. It also warns of potential layout issues when margins or borders lead to overflow. This guide is intended for developers constructing UI layouts in Cangjie who need resizable horizontal containers. By understanding these properties and constraints, developers can effectively manage layout space and user interaction within their applications.
