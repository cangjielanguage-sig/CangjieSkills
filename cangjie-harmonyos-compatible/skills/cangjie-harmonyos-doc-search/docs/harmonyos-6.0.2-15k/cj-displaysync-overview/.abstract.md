This directory provides a comprehensive technical overview of HarmonyOS's Variable Frame Rate capability, a crucial feature for modern mobile development. It is designed to assist developers in achieving the optimal balance between high-performance visual rendering and power efficiency, particularly on devices utilizing LTPO (Low-Temperature Polycrystalline Oxide) screens. The documentation covers the fundamental concepts of variable refresh rates, explores specific usage scenarios such as complex animations and UI drawing, and details the operating mechanism where the system dynamically adjusts refresh rates based on decision-making logic. It also addresses constraints imposed by hardware limitations. Key technical elements include the implementation of APIs like `expectedFrameRateRange` and `displaySync`, which allow applications to request specific frame rates. This resource is specifically suitable for HarmonyOS developers who are looking to optimize their application's power consumption without compromising on the smoothness and quality of the user interface. By mastering these concepts, developers can ensure their apps run efficiently across a variety of hardware configurations.
