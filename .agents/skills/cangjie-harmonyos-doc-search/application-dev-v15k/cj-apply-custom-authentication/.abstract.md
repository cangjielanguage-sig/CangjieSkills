This directory provides a specialized guide for Cangjie language developers working within the Unified User Authentication Framework. It focuses on the technical implementation of switching from standard system authentication to custom business authentication, a process essential for applications requiring specific fallback methods such as payment passwords. The content covers the complete switching logic, details supported authentication types, and outlines configuration constraints. Developers will find instructions on configuring the `navigationButtonText` field within `WidgetParam` to generate a navigation button. The guide further explains the system response mechanism, specifically the return of result code `12500011` upon user interaction, which triggers the application to launch a custom interface. Additionally, it addresses compatibility issues, explicitly noting that lock screen password authentication cannot be used with this feature. This documentation is vital for ensuring secure, flexible, and user-compliant authentication flows in Cangjie-based applications.
