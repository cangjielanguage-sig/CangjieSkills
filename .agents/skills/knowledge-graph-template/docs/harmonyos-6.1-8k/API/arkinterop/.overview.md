# arkinterop

This directory serves as the central documentation hub for the Cangjie programming language's interoperability features with ArkTS. It provides comprehensive API references, helper functions, macro definitions, and error code specifications designed to facilitate seamless cross-language development within the HarmonyOS ecosystem. The content covers core interoperation mechanisms, data type conversions, callback invocations, and exception handling. Currently in the Beta stage, these resources are essential for developers looking to integrate ArkTS components deeply into Cangjie applications or manage complex runtime interactions between the two environments.

## Detailed Description

### [1] README_zh/
This directory acts as the core navigation hub for the Cangjie language documentation system. It provides a unified entry point for developers accessing standard library APIs and ArkTS interoperability features. The documentation comprehensively covers core interop APIs, auxiliary functions, macro definitions, general exception handling, callback mechanisms, and error code definitions. As all mentioned features are currently in the Beta stage, this document serves as both an API index and a crucial guide for efficient cross-language development between Cangjie and ArkTS. It is particularly suitable for Cangjie developers in the HarmonyOS ecosystem who need deep integration with ArkTS components.

### [2] cj-api-business_exception/
This directory contains the API reference documentation for the `ohos.business_exception` module in the Cangjie language. It aims to provide standard definitions for general exception information during interface calls. The content covers the core definition of the `BusinessException` class, detailing the read-only error code `code`, the `getData` method for retrieving custom data, and the `toString` method for error messages. It also introduces the `AsyncCallback` type for asynchronous processing. Note that this module is currently in Beta and does not yet support Kit-based imports.

### [3] cj-api-callback_invoke/
This directory serves as a comprehensive repository for API reference documentation regarding the `ohos.callback_invoke` module within the Cangjie programming language environment. It specifically addresses the implementation standards and specifications for callback invocation, providing developers with the necessary guidelines to ensure correct behavior when invoking callbacks across different contexts.

### [4] cj-apis-ark_interop/
This directory serves as a specialized API reference repository for the Cangjie programming language, dedicated to enabling seamless interoperability with ArkTS and JavaScript environments. It provides a robust framework for developers to manage runtime interactions, ensuring that Cangjie code can effectively communicate and operate within the broader HarmonyOS application context.

### [5] cj-apis-ark_interop_helper/
This directory contains API reference documentation for the public auxiliary functions of ArkTS interoperability in the Cangjie language. It aims to provide developers with tool functions for data type conversion and interoperation. The documentation covers module import instructions and four core functions, including conversion between JSValue and napi_value, Stage mode determination, and bidirectional conversion between JSValue and HashMap.
