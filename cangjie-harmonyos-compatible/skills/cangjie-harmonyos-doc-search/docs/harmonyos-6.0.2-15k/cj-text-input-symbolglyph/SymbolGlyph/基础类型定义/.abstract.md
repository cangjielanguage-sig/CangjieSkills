This directory provides fundamental type definitions for symbol animation effects and rendering strategies within the ArkUI framework, specifically designed for the Cangjie language. It covers a comprehensive range of classes for visual effects—such as bounce, pulse, and scale—as well as enumerations defining animation strategies and rendering modes. These definitions are essential for developers looking to implement dynamic icon behaviors and control visual properties like color and opacity in HarmonyOS applications. The documentation is suitable for software engineers familiar with ArkUI and Cangjie syntax who need to enhance user interfaces with sophisticated symbol animations and precise visual control.
