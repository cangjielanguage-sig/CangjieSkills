# 数据库备份与恢复

This directory focuses on database backup and recovery mechanisms within the ArkData framework, specifically utilizing the Cangjie programming language. It covers essential procedures for securing relational and Key-Value (KV) databases against data loss, corruption, or system exceptions. Key topics include manual and automatic backup modes, exception handling during recovery, and practical implementation scenarios involving data insertion, backup simulation, and restoration. This documentation is suitable for developers and system maintainers looking to ensure data integrity and implement robust disaster recovery strategies in their applications.

## Detailed Description

### 关系型数据库备份.md
This technical guide outlines procedures for backing up relational databases to facilitate data recovery during unexpected exceptions. It covers two backup modes: manual and automatic (restricted to system applications), with a specific focus on the manual implementation. The key section demonstrates the backup API using a Cangjie code example, illustrating how to initialize an RdbStore and execute the backup command. Important details include specifying the backup filename, understanding default versus absolute path behaviors, and ensuring target directories exist. This document serves as a reference for developers utilizing the ArkData framework to secure application data.

### 关系型数据库数据恢复.md
This technical guide outlines the procedure for restoring data in a relational database following an exception and subsequent rebuild. It details a three-step process using the Cangjie programming language: catching specific database exceptions, closing all open result sets to prevent conflicts, and executing the restore interface to reload data from a backup file. Key takeaways include handling specific error codes like 14800011 and ensuring the backup file path is correct. This document targets developers responsible for database maintenance and data integrity within their applications.

### 场景介绍_2more.md
This document serves as a scenario-based guide and tutorial for implementing database backup, recovery, and deletion to maintain data integrity during critical operations or system failures. It outlines the necessity of these features for handling transactional consistency and data corruption. The content focuses on a step-by-step code example using the Cangjie language for Key-Value databases. Key steps include creating a KVStore, inserting data, performing backups with backup(), simulating data loss, restoring data with restore(), and managing storage with deleteBackup(). This guide is intended for developers using the ArkData framework who need to safeguard application data against accidental deletion or device issues.
