## Detailed Description

### class_ConnectionProperties.md
This document defines the Cangjie class `ConnectionProperties`, encapsulating network connection information within the NetManager Core system. It details the class constructor and six read-only properties: interfaceName, domains, linkAddresses, dnses, routes, and mtu. All properties are immutable and initialized via the constructor, requiring parameters for network configuration like DNS addresses and routing info. It is intended for developers using Cangjie for network management to handle network interface states and connectivity parameters.

### class_HttpProxy.md
This document provides API reference for the Cangjie `HttpProxy` class, designed to configure network proxy settings within the NetManager Core system. It details the constructor and three read-only properties: host, port, and exclusionList. A key feature is the exclusionList logic, supporting domain and IP matching with wildcards and case-insensitive comparisons to bypass the proxy. This guide targets developers implementing network communication features who need to define proxy server details and exclusion rules.

### class_LinkAddress_2more.md
This document provides API reference for two Cangjie classes, `LinkAddress` and `NetAddress`, used for managing network link and address information. It details properties and constructors for `LinkAddress` (combining a network address with a prefix length) and `NetAddress` (specifying an IP address string, family type, and port number). All properties are read-only public variables. This reference targets developers building network applications in Cangjie who need to handle network configurations and address parsing.

### class_NetCapabilities.md
This document provides API reference for the `NetCapabilities` class in Cangjie, representing network capability sets. It covers the constructor and four read-only properties: bearerTypes, linkUpBandwidthKbps, linkDownBandwidthKbps, and networkCap. The constructor requires an array of `NetBearType`, while bandwidth and specific capabilities are optional. Bandwidth values of 0 indicate unassessable speeds. It targets developers using the NetManager Core module to define or query network specifications.

### class_NetCapabilityInfo.md
This document provides API reference for the Cangjie class `NetCapabilityInfo`, encapsulating data network capabilities and handles. It details the constructor and two read-only properties: netHandle (representing the data network handle) and netCap (storing transmission capabilities and bearer types). It requires the SystemCapability.Communication.NetManager.Core capability and is intended for developers working with network management in Cangjie.

### class_NetHandle.md
This document provides API reference for the `NetHandle` class in the Cangjie NetworkKit, serving as a handle for data network operations. It details the class structure, including the read-only netId property, constructor, and methods for DNS resolution like `getAddressByName` and `getAddressesByName`. It requires the ohos.permission.INTERNET permission and is targeted at developers implementing network connectivity features.

### class_NetSpecifier_2more.md
This API reference defines two core classes for network management in Cangjie: `NetSpecifier` and `RouteInfo`. `NetSpecifier` provides instances for bearer data network capabilities and identifiers, while `RouteInfo` encapsulates network routing details. Both classes feature read-only properties and constructors requiring specific parameters. It targets developers implementing network communication features within the NetManager Core framework.
