# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It primarily focuses on text styling and formatting capabilities, covering font attributes such as weight, family, size, and specific typographic features. It also includes detailed guides on date and time display options, as well as visual effects like text shadows. These resources are specifically designed for HarmonyOS application developers who require precise control over UI appearance and text representation. Key topics include `dateTimeOptions`, `fontWeight`, and `textShadow` functions, offering the necessary syntax and parameters to customize application interfaces effectively. The documentation assumes a solid understanding of Cangjie syntax and ArkUI components.

### func_fontWeightString_2more.md func_fontWeightString_2more.md

The documentation is divided into sections for fontWeight(String) and format(String), detailing their syntax, parameters, and system capabilities. Key information includes that fontWeight accepts numeric strings or keywords like "bold," while format utilizes specific tokens such as "yyyy" and "MM" to construct custom date patterns, with extensive examples provided for valid formats. This resource is intended for developers requiring precise control over text styling and time representation in their UI applications.

### func_textShadowArrayShadow_2more.md func_textShadowArrayShadow_2more.md
This API reference document details the textShadow functions in the Cangjie language for setting text shadow effects within the ArkUI framework. It covers two overloaded functions: one accepting an array of ShadowOptions for multiple shadows, and another accepting individual parameters like radius, offset, and color for a single shadow. Key parameters include blur radius, shadow type, axis offsets, and color. The array version does not support the fill field or smart color mode. Both functions require SystemCapability.ArkUI.ArkUI.Full and are available from version 12. This documentation targets UI developers using Cangjie to style text components.
