This directory serves as the central repository for core interface definitions within the Cangjie programming language ecosystem. It focuses on the fundamental building blocks required for type system interoperability, collection management, and standard utility operations. Key topics include C interoperability (CType), hashing mechanisms (Hashable), comparison logic (Comparable), and concurrency primitives. This documentation is specifically designed for Cangjie developers who need to implement custom data structures, enforce type constraints, or leverage generic programming and operator overloading in their applications. By mastering these interfaces, developers can ensure their code integrates seamlessly with the standard library, adheres to language best practices, and effectively utilizes the root type hierarchy (Any) for robust application design. Whether you are building high-performance collections, bridging native code, or simply trying to understand how to make a custom class work with a HashMap, this directory provides the necessary specifications to succeed.
