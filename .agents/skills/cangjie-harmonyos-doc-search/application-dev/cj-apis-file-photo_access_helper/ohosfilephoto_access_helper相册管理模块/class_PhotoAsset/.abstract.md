This directory provides comprehensive API reference documentation for the PhotoAsset class within the Cangjie language, specifically tailored for the HarmonyOS PhotoAccessHelper system. It covers the encapsulation of file attributes, methods for retrieving metadata and thumbnails, and functions for modifying file properties. Key topics include read-only properties like displayName and uri, the commitModify method, and specific functions for getting and setting parameters. This documentation is suitable for HarmonyOS developers working on media file management who need to programmatically access, manipulate, and update image and video resources efficiently.
