This directory contains API reference documentation for the `DateTimeOptions` class within the Cangjie programming language and ArkUI framework. It covers the configuration of date and time formatting, including localization, styles, and specific component display options. Key topics include initialization constructors, public properties for formatting years, months, and time zones, and support for internationalized applications. This documentation is suitable for software developers and system architects working on ArkUI who need to implement precise, localized date and time representations in their applications.
