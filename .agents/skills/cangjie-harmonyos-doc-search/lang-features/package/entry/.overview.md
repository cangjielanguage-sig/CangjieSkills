### entry.md

本文档是仓颉语言开发者关于程序入口 `main` 函数的权威参考。它详细说明了 `main` 函数的定义规则、参数及返回值限制，确保开发者能够编写符合编译器要求的启动代码。文档内容涵盖了 `main` 函数的查找位置、编译检查机制、访问修饰符限制、合法的参数与返回值类型组合，以及常见错误示例。关键点包括：源文件根目录下只能有一个顶层 `main`，不可被导入，参数必须为空或 `Array<String>`，返回值必须是 `Unit` 或整数类型。通过阅读本文档，开发者可以深入理解仓颉程序的启动流程，避免因入口定义错误导致的编译失败。
