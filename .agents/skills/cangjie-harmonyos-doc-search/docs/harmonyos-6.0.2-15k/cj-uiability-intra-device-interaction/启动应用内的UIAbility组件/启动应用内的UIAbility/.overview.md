# 启动应用内的UIAbility

This directory provides comprehensive technical guidance for managing UIAbility lifecycles within the same HarmonyOS application using the Cangjie language. It covers essential operations such as initiating specific UIAbility components via the `startAbility()` method, configuring Want objects with parameters like bundleName and abilityName, and passing custom data between components. Additionally, it details how to terminate UIAbility instances and manage application processes using methods like `terminateSelf()` and `killAllProcesses()`. This resource is suitable for HarmonyOS developers working with the Stage model who need to implement multi-Ability navigation, handle parameter passing via JSON, and control application visibility and lifecycle events effectively.

### 启动应用内的UIAbility_1.md 启动应用内的UIAbility_1.md
This technical tutorial guides developers on initiating a specific UIAbility within the same application using the Cangjie language. The document details the process for the calling Ability to invoke the startAbility() method with a configured Want object, specifying parameters like bundleName, abilityName, and custom data. It also explains how the target Ability receives these parameters in its onCreate() or onNewWant() lifecycle callbacks. Key takeaways include understanding the Want object structure and parsing JSON-formatted parameters to retrieve caller information. This guide is intended for HarmonyOS developers implementing multi-Ability navigation in the Stage model.

### 启动应用内的UIAbility_2.md 启动应用内的UIAbility_2.md
This technical guide explains how to terminate UIAbility instances and application processes within a HarmonyOS application. It covers stopping a specific UIAbility instance using the terminateSelf() method and closing all application processes via the killAllProcesses() method. Key information includes Cangjie code examples demonstrating context retrieval and method execution. The guide highlights that terminateSelf() retains a task snapshot by default, which can be disabled by configuring the removeMissionAfterTerminate field in module.json5. This content targets HarmonyOS developers using the Cangjie language who need to manage application lifecycle and task visibility.
