Developers can find detailed parameters for setting colors, fonts, spacing, and menu behavior. Suitable for UI developers using the Cangjie language, these documents provide the necessary technical specifications to create polished and functional user interfaces, ensuring components meet specific design and interaction requirements.

## Detailed Description

### func_menuBackgroundColorRe_2more.md
This API reference document details functions for styling the background of dropdown menus within the Cangjie ArkUI framework. It covers two specific methods: menuBackgroundColor for setting solid colors and menuBackgroundBlurStyle for applying blur effects. Key information includes that both functions accept optional parameters with specific default values, namely Color.Transparent and BlurStyle.ComponentUltraThick, and return the current instance to support method chaining. These features are available starting from system version 22. This documentation is intended for UI developers seeking to customize menu appearances using Cangjie code.

### func_selectedOptionFontFon_5more.md
This API reference document details functions for styling text and background properties of dropdown menu options within the ArkUI framework using the Cangjie language. It covers five specific functions: selectedOptionFont, selectedOptionFontColor, optionBgColor, optionFont, and optionFontColor. The documentation specifies parameters for font style, weight, size, family, and colors. It highlights default values like 16.vp and "sans-serif," and notes that a size of 0 hides text while negative values revert to defaults. All functions are available starting from API version 22. This guide targets developers using ArkUI to customize the appearance of dropdown components.
