This directory serves as a comprehensive technical resource for understanding the matching rules governing Explicit and Implicit Wants within the application framework. It is designed to assist developers in mastering the mechanisms required to launch application components effectively. The content covers the alignment of caller parameters with target component configurations, focusing on critical fields such as bundleName, abilityName, action, entities, and URI. By detailing the nuances of priority handling, wildcard usage, and `module.json5` configuration requirements, this guide ensures robust implementation of cross-component invocation. It is highly suitable for application developers and system engineers utilizing the AbilityKit API to facilitate seamless component startup, data transmission, and intent filtering in a complex system environment. Mastering these rules is essential for ensuring application stability and correct inter-component communication.
