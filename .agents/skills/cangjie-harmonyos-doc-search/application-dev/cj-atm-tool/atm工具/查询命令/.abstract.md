This directory serves as a specialized repository for technical documentation regarding the `atm dump` command-line tool, which is essential for querying and managing system-level application data. It encompasses detailed guides on retrieving system application processes, checking current permission states, and auditing historical permission usage records. The content explains command syntax, various parameter flags for filtering specific data points like token IDs and bundle names, and how to interpret the resulting JSON output structures. Key functionalities include monitoring process attributes, defining permission usage types, and tracking access to sensitive system resources such as the camera. This documentation is primarily intended for system developers and administrators who need to debug applications, enforce security compliance, and maintain oversight of the operating system's permission management framework.
