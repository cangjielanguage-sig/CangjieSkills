This directory provides API reference documentation for the HarmonyOS Audio-Haptic Kit in the Cangjie language, focusing on synchronizing audio playback with haptic feedback. It covers core classes like `AudioHapticManager` and `AudioHapticPlayer`, configuration options, callback types, and latency modes. Designed for developers building immersive multimedia applications, this module enables precise control over sensory experiences, including resource management, playback lifecycle, and event handling. Key features include independent audio/haptic muting, stream type configuration, and system capability requirements starting from API version 19.
