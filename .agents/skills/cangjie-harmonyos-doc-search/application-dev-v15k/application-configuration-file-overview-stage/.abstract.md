This directory provides a comprehensive reference for the mandatory configuration files required in application projects utilizing the Stage model. It details the structure and purpose of essential files, specifically `app.json5` for global application settings—such as bundle name and version—and `module.json5` for module-level details. Key topics covered include the definition of application components such as UIAbility and ExtensionAbility, as well as the configuration of runtime permissions within the module settings. This resource is designed for developers who need to understand how to structure their project metadata effectively to meet the requirements of compilation tools, the operating system, and app market distribution. By mastering these configuration files, developers ensure their applications are correctly recognized and executed by the system environment, facilitating a smooth development lifecycle and successful deployment.
