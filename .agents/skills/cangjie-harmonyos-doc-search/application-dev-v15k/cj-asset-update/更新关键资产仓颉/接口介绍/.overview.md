# 接口介绍

This directory provides technical documentation for the AssetStoreKit API, focusing on the synchronization and update of critical assets. It covers interface definitions, parameter structures like `AssetParam`, and attribute configurations including access control and data types. Key topics include security warnings regarding unencrypted data labels, size limits for custom data (updated to 2048 bytes in API 12), and encryption control flags. This documentation is intended for software developers and engineers integrating secure asset management features into their applications, ensuring correct implementation and adherence to data privacy standards.

## Detailed Description

### 接口介绍_1.md 接口介绍_1.md
This document provides a technical reference for the API interface designed to synchronize and update key assets. It details the update function signature, specifically focusing on the AssetParam structure required for the query parameter list. A critical security takeaway is the warning regarding DATA_LABEL attributes, which store unencrypted custom business information and must not contain personal data. Intended for developers using the AssetStoreKit, this documentation ensures correct parameter implementation and adherence to data privacy standards during asset synchronization.

### 接口介绍_2.md 接口介绍_2.md
This document serves as a reference guide defining the attribute parameters for updating critical assets within the AssetStoreKit framework. It details a comprehensive table of properties including unique identifiers (ALIAS), access control settings (ACCESSIBILITY, AUTH_TYPE), persistence options, and synchronization types. Key information includes data types, mandatory requirements, and size limits for custom data labels (CRITICAL, NORMAL, and LOCAL), highlighting an increase from 512 to 2048 bytes for API12 and later. This technical reference is intended for developers implementing secure asset management who need to configure asset properties and update attributes programmatically.

### 接口介绍_3.md 接口介绍_3.md
This document serves as a reference guide defining the attribute parameters for an interface handling critical assets and their associated data. It details the structure of the SECRET field, custom auxiliary data labels (normal and local), and encryption control flags. Key information includes that the SECRET field holds plaintext assets up to 1024 bytes, while normal data labels support custom content up to 2048 bytes (increased from 512 in API 12) without integrity protection. Local labels are excluded from synchronization, and a boolean flag controls the encryption of auxiliary data. This is intended for software developers integrating secure asset management features into their applications.
