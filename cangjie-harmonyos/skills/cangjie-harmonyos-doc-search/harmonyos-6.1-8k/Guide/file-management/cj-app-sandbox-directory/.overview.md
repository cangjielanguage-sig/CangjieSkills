# cj-app-sandbox-directory

This directory serves as a comprehensive guide to the OpenHarmony application sandbox, focusing on the critical isolation mechanisms and security protection principles that govern app behavior. It provides in-depth coverage of file access specifications, distinguishing clearly between virtual sandbox paths and actual physical paths, along with their mapping relationships. The content also addresses data storage strategies across different encryption levels, ranging from EL1 to EL5, ensuring data security and privacy. Furthermore, it details the methods for securely retrieving paths using the Context API. This resource is essential for developers engaged in file management, data persistence, and cross-device collaboration, offering the necessary knowledge to build secure and robust applications within the OpenHarmony ecosystem.

## Detailed Description

### 应用沙箱目录/
This subdirectory provides a comprehensive explanation of the OpenHarmony application sandbox, focusing on the isolation mechanisms and security protection principles that are fundamental to the operating system's architecture. It thoroughly covers file access specifications, highlighting the critical differences between sandbox paths and physical paths, and explaining the mapping relationships that enable secure data handling. The content delves into data storage solutions, categorizing them by different encryption levels (EL1-EL5) to help developers understand how to protect data based on varying security requirements. Furthermore, it offers practical guidance on using the Context API to safely retrieve paths, ensuring compliance with security protocols. Core keywords include application sandbox, path mapping, data isolation, and EL1-EL5 encryption. This section is highly suitable for application developers who are tasked with file management, data persistence, and cross-device collaboration, providing them with the technical know-how to secure their applications effectively.
