This directory provides API reference documentation for the `PhotoOutput` class in the Cangjie CameraKit framework, essential for managing photo capture sessions in HarmonyOS applications. It covers core functionalities such as standard and customized photo capture, moving photo configuration, and image mirroring. Additionally, it details event callback management, resource lifecycle, and capability queries like rotation and codec support. The content is intended for Cangjie developers implementing camera features, requiring knowledge of context management, multimedia system capabilities, and exception handling.
