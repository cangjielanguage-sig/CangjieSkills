# 开发步骤

This directory provides a technical guide for developers using the LocalizationKit framework in the Cangjie programming language. It focuses on the development steps required to implement internationalization features, specifically the formatting of time, dates, and relative time ranges. Key topics include the `RelativeTimeFormat` and `DateTimeFormat` classes, covering object instantiation, configuration options, and locale-specific styling. This documentation is suitable for Cangjie developers who need to display user-friendly temporal data and manage precise localization settings in their applications.

## Detailed Description

### 相对时间格式化.md 相对时间格式化.md

This document provides a technical guide for developers on how to format relative time strings using the RelativeTimeFormat class within the LocalizationKit framework. It covers the development workflow including module import, object instantiation, and formatting methods like format and formatToParts. It also details configuration options for numeric representation and display styles. The guide explains how to control output using RelativeTimeFormatInputOptions, distinguishing between numeric values and textual phrases, as well as varying text lengths across different locales like en-GB and fr-FR. This tutorial targets Cangjie language developers implementing internationalization features who need to display user-friendly relative time data.

### 时间日期和相对时间格式化/
