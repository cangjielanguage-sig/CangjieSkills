### enum SliderInteraction

```cangjie
public enum SliderInteraction {
    | SLIDE_AND_CLICK
    | SLIDE_ONLY
    | SLIDE_AND_CLICK_UP
}
```

**功能：** 用户与滑动条组件交互方式枚举。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### SLIDE_AND_CLICK

```cangjie
SLIDE_AND_CLICK
```

**功能：** 用户可拖拽滑块或者点击滑轨使滑块移动，鼠标或手指按下即发生移动。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### SLIDE_AND_CLICK_UP

```cangjie
SLIDE_AND_CLICK_UP
```

**功能：** 用户可拖拽滑块或者点击滑轨使滑块移动，鼠标或手指抬起时，若与屏幕按压位置一致，则触发移动。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### SLIDE_ONLY

```cangjie
SLIDE_ONLY
```

**功能：** 不允许用户通过点击滑轨使滑块移动。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19
