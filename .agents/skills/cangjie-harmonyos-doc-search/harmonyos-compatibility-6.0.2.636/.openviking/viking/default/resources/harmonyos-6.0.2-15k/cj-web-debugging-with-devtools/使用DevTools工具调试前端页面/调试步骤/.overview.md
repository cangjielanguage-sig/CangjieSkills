# 调试步骤

This directory serves as a comprehensive technical resource for developers working on HarmonyOS applications, specifically focusing on the critical steps required to debug web components effectively. It covers the complete lifecycle of the debugging setup, starting from the initial application code configuration where developers must enable specific interfaces like `setWebDebuggingAccess` and declare necessary permissions such as `INTERNET`. The content also extends to the physical and network connection between the development machine and the target device, utilizing command-line tools like `hdc` and browser-based tools like Chrome DevTools. By following these guides, developers can master the art of remote debugging, handle dynamic process IDs, and ensure their web views are fully accessible for inspection. This collection is essential for any developer aiming to streamline their debugging workflow and resolve issues efficiently within the HarmonyOS ecosystem.

## Detailed Description

The following documents provide step-by-step instructions for configuring your environment and establishing connections for effective debugging.

### 应用代码开启Web调试开关_2more.md 应用代码开启Web调试开关_2more.md
This technical guide instructs developers on enabling web debugging for HarmonyOS applications. It covers two primary steps: configuring application code and connecting the device. The first section details calling the setWebDebuggingAccess interface in Cangjie and declaring the INTERNET permission in module.json5. The second section explains enabling developer mode, USB debugging, and verifying the connection using hdc commands. Key takeaways include the necessity of the specific API call and permission for DevTools to discover the webpage. This tutorial targets developers preparing for web debugging workflows.

### 端口转发_4more.md 端口转发_4more.md
This technical tutorial guides developers on enabling remote debugging for ArkWeb applications by forwarding device domain sockets to a local computer. The document details a step-by-step process: identifying the specific domain socket via hdc shell commands, forwarding it to local TCP port 9222, and verifying the connection. It further explains configuring Chrome DevTools to discover targets on this port. Key takeaways include the dynamic nature of process IDs requiring re-forwarding upon app restart and the ability to debug multiple apps by adding multiple ports. Intended for developers debugging web components, this guide ensures seamless integration between the device and Chrome browser. Keywords: ArkWeb, port forwarding, DevTools, hdc, Chrome debugging, domain socket.
