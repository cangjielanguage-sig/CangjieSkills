# 权限列表

This directory serves as a comprehensive repository for HarmonyOS system permission references, specifically focusing on API version 12. It provides detailed lists of permissions required for accessing a wide array of device capabilities, ranging from basic connectivity options like Bluetooth and Wi-Fi to advanced hardware interactions involving sensors and NFC. Additionally, it covers critical system controls such as wallpaper management and background processes, as well as specialized areas like security detection, dynamic code execution, and cloud synchronization. A key characteristic of these permissions is that they are all classified as normal level and utilize system_grant authorization. This collection is primarily designed for HarmonyOS application developers who need to accurately declare permissions in their configuration files to ensure compliant and functional access to specific device features and system services.
