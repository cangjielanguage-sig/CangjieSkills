This directory contains essential API reference documentation for the `Stream` class in the Cangjie language, focusing on robust file stream operations. It covers the complete lifecycle of stream handling, including class definitions, instantiation via `FileFs`, and synchronous methods for reading, writing, closing, and flushing data. The documentation provides detailed insights into handling various data types, such as strings and byte arrays, with support for configurable options like encoding, offsets, and buffer lengths. It also includes syntax details, parameters, return values, and exception management. This resource is specifically designed for developers and software engineers working on file input/output systems, providing the technical specifications required to effectively manage data streams in Cangjie applications targeting system version 12.
