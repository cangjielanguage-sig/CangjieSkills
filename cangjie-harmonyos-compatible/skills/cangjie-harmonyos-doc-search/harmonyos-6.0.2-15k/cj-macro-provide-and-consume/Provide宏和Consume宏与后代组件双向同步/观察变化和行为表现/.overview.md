# 观察变化和行为表现

This directory provides a comprehensive technical overview of state management and reactive behavior within the Cangjie UI framework. It is designed to help developers understand the underlying mechanisms that drive UI updates and component synchronization. The content covers critical concepts such as the `@Provide` and `@Consume` decorators, the `ObservedProperty` system, and the specific data types that trigger re-renders. By exploring both the framework's internal rendering flow and the rules of state observation, users can optimize application performance and ensure data consistency. This resource is primarily suitable for software developers and framework engineers looking to master reactive programming patterns and implement efficient state solutions in Cangjie applications.

## Detailed Description

### 框架行为.md

This technical reference document details the internal behavior of the framework regarding state management using @Provide and @Consume decorators. It covers two main phases: initial rendering and data change handling. Key information includes how @Provide variables are stored in a map for @Consume retrieval during component construction, and how state changes trigger dependency tracking via ObservedProperty. The document explains the update flow, including notifyChanges, onStateUpdate, and the CustomView rerender process, which ensures minimal rendering by updating only specific components and their sub-props. This guide is intended for developers or framework engineers seeking to understand the underlying mechanics of state synchronization and rendering optimization. Keywords: @Provide, @Consume, state management, rendering, ObservedProperty, UI update.

### 观察变化.md

This technical reference guide details the state observation capabilities within the Cangjie UI framework, specifically identifying which data types trigger UI updates when modified. It categorizes observable types into basic values, collections, and complex objects like DateTime, HashMap, and HashSet. Key takeaways include that complex objects support observation through specific method calls (e.g., addDays, set) or full reassignment, and function variables can be observed for output changes. The document provides code examples demonstrating parent-child state synchronization using @Provide and @Consume decorators. It targets developers implementing reactive state management in Cangjie applications. Keywords: State management, Cangjie, reactive UI, data observation, decorators.
