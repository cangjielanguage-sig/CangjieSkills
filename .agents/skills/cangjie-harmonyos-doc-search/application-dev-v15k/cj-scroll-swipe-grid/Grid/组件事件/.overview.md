# 组件事件

This directory contains comprehensive API reference documentation for event handling within the ArkUI Grid component, specifically designed for the Cangjie programming language. It covers a wide array of interactive functionalities, including granular drag-and-drop operations (start, enter, leave, move), item dropping logic, scroll boundary detection, and scrollbar customization. Furthermore, it details mechanisms for tracking scroll indices and monitoring scroll animation states. This documentation is suitable for UI developers and system architects aiming to build complex, responsive grid-based interfaces that require precise management of user gestures, component behaviors, and dynamic layout updates.

## Detailed Description

### func_onItemDragEnterItemDr_5more.md func_onItemDragEnterItemDr_5more.md
This document provides API reference documentation for handling drag-and-drop events within grid elements using the Cangjie language. It covers five specific functions: onItemDragEnter, onItemDragLeave, onItemDragMove, and two overloads of onItemDragStart. Key information includes the callback parameters, such as ItemDragInfo and element indices, which track drag position and state. The documentation highlights that the return type of onItemDragStart determines whether dragging is permitted and warns about event conflicts with LongPressGesture. This reference is intended for ArkUI developers implementing custom drag interactions for grid components.

### func_onItemDropItemDragInf_5more.md func_onItemDropItemDragInf_5more.md
This document serves as API reference documentation for event handling functions within the ArkUI Grid component using the Cangjie programming language. It covers five key functions: onItemDrop for managing drag-and-drop interactions, onReachEnd and onReachStart for detecting scroll boundaries, onScrollBarUpdate for customizing scrollbar attributes, and onScrollFrameBegin for controlling scroll offsets. Key information includes function signatures, parameter types like ItemDragInfo and ScrollState, return values, and specific trigger conditions such as spring effects. The content is intended for developers building grid-based user interfaces, providing the technical specifications needed to implement complex scrolling and interaction logic.

### func_onScrollIndexUInt32_-_4more.md func_onScrollIndexUInt32_-_4more.md
This document provides API reference documentation for Grid component scrolling event callbacks in the ArkUI framework using the Cangjie language. It details four specific functions: two overloaded onScrollIndex methods for tracking visible item indices, plus onScrollStart and onScrollStop for monitoring scroll animation states. Key information includes that onScrollIndex triggers when the first or last visible item changes, with one overload returning both start and end indices. The start and stop events handle both manual dragging and programmatic scrolling via Scroller. Version compatibility ranges from API 12 to 19. This is intended for UI developers implementing dynamic Grid layouts requiring scroll position tracking and event handling.
