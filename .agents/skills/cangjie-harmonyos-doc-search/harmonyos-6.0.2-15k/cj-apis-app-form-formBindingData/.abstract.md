This directory provides comprehensive API reference documentation for the HarmonyOS FormKit, specifically tailored for the Cangjie programming language. It focuses on the critical infrastructure required for card data binding within the HarmonyOS ecosystem. The content primarily details the `FormBindingData` class, which serves as the foundation for creating and managing data objects used in form cards, and the `ProxyData` class, designed to manage proxy refresh subscriptions efficiently. Key technical areas covered include JSON data parsing and handling, the management of subscription identifiers, and specific system capability requirements. This resource is ideal for developers targeting HarmonyOS system version 19 who are developing form-based applications and require robust solutions for dynamic card data display, real-time updates, and advanced data proxy capabilities. By mastering these APIs, developers can ensure their applications are responsive and data-efficient.
