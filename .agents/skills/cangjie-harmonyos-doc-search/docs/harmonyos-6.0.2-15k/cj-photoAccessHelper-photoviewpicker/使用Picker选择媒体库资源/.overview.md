# 使用Picker选择媒体库资源

This directory serves as a technical resource for Cangjie developers working within the HarmonyOS ecosystem, focusing on the selection and access of media library resources. It details the implementation of the system picker interface to select images and videos without requiring explicit user permissions, a critical feature for privacy and ease of use. Furthermore, it provides in-depth instructions on how to process the resulting URIs to read file data or retrieve media assets. Key technical areas include configuring `MPhotoSelectOptions`, managing `PhotoSelectResult`, utilizing the `FileFs` API for raw data access, and leveraging `MediaLibraryKit` for asset management. This guide is essential for developers building UIAbility components that require robust media file integration.

## Detailed Description

### 使用Picker选择媒体库资源.md 使用Picker选择媒体库资源.md
This tutorial guides developers on using the system picker interface to select media resources like images and videos without requiring specific permissions. It covers importing required modules, configuring MPhotoSelectOptions for file types and limits, and invoking the select method via MPhotoViewPicker. The process returns read-only URIs in a PhotoSelectResult. Crucially, developers cannot open files directly within the picker callback and must use global variables to manage URIs for subsequent file reading or metadata retrieval. This is intended for Cangjie developers working on UIAbility components who need to integrate user file selection features.

### 指定URI读取文件数据_2more.md 指定URI读取文件数据_2more.md
This technical guide explains how to read file data and retrieve media resources using specific URIs in the Cangjie programming language. It covers two primary workflows: using the FileFs API to open and read raw file data via a file descriptor, and utilizing the MediaLibraryKit to query and fetch image or video assets from the media library. Key steps include opening files with READ_ONLY mode, reading data into buffers, using DataSharePredicates for URI-based queries, and implementing MediaAssetDataHandler for asynchronous data retrieval. Intended for HarmonyOS developers, this tutorial requires knowledge of Cangjie syntax, file I/O operations, and media asset management.
