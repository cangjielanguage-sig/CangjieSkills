# cj-crypto-asym-encrypt-decrypt-spec

This directory serves as the central repository for technical specifications regarding asymmetric key encryption and decryption algorithms within the Cangjie programming language ecosystem. It provides a rigorous definition of implementation standards, ensuring consistency, interoperability, and security across applications developed in this language. The documentation primarily focuses on mainstream cryptographic algorithms, specifically SM2 and RSA, detailing their operational mechanics, key management, and data handling within the Cangjie framework. Key topics include the internal structure of ciphertexts, various padding modes (such as PKCS1_OAEP), parameter configurations, and comprehensive API usage guides. This resource is essential for developers who possess a foundational understanding of cryptography and are looking to integrate robust, standardized encryption mechanisms into their Cangjie-based projects. By adhering to these specifications, developers can ensure their implementations meet high security standards and function correctly within the broader cryptographic infrastructure.

This directory acts as a comprehensive resource, detailing the technical specifications and implementation norms for asymmetric key encryption and decryption algorithms specifically tailored for the Cangjie programming language. Furthermore, the documentation includes detailed API usage guides that facilitate the practical application of these theories in real-world coding environments. It places a strong emphasis on mainstream algorithms, particularly SM2 (a Chinese national standard) and RSA (a widely used international standard), ensuring that developers have access to relevant and modern cryptographic tools. Core keywords highlighted within this section include SM2, RSA, PKCS1_OAEP, ciphertext format conversion, and encryption modes. The material is specifically curated for developers who already have a grasp of basic cryptography concepts. Its primary goal is to serve as an authoritative technical reference, offering clear operational guidance to assist developers in successfully implementing secure encryption functions within the Cangjie framework, thereby enhancing the overall security posture of their applications.
