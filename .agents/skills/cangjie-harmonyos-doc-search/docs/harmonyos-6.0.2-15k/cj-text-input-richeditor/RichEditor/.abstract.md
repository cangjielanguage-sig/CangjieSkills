This directory contains comprehensive documentation and resources for the RichEditor component within the ArkUI framework, specifically designed for HarmonyOS application development using the Cangjie language. It covers the implementation of mixed graphics and text layouts, interactive editing capabilities, and detailed API references for component attributes, events, and fundamental data types. Developers will find specifications for text manipulation, image spans, paragraph styles, and event handling. This resource is suitable for software engineers and UI developers seeking to integrate advanced rich text editing features and customize user interactions in their applications.
