# ohosnetconnection网络连接管理

本目录提供了HarmonyOS系统中`ohos.net.connection`模块的仓颉（Cangjie）语言API参考文档，专注于网络连接管理。内容涵盖了网络连接属性的获取、网络能力的查询、DNS解析、HTTP代理配置以及网络状态变化的监听。核心类包括`NetHandle`、`NetConnection`、`NetCapabilities`等，旨在帮助开发者实现网络状态监控、地址解析及特定网络绑定等功能。适用于使用仓颉语言进行HarmonyOS应用开发，需要处理复杂网络连接场景的开发人员。

## 详细描述

### class_ConnectionPropert_52b26156.md class_ConnectionPropert_52b26156.md
本文档是Cangjie语言中ConnectionProperties类的API参考文档，旨在定义网络连接信息的数据结构。文档详细列出了该类的六个公共成员变量，包括网卡名称、域名、链路地址、DNS地址、路由信息及最大传输单元（MTU）。所有属性均支持读写操作，属于SystemCapability.Communication.NetManager.Core系统能力，起始版本为22。该文档主要面向需要处理网络配置和连接状态的开发者，提供了网络管理核心模块中关键属性的详细说明。

### class_HttpProxy.md class_HttpProxy.md
这是一份Cangjie语言的API参考文档，定义了用于网络代理配置的HttpProxy类。文档涵盖了该类的属性（如主机名、端口、排除列表、用户凭证）及其构造函数。重点介绍了exclusionList属性的详细匹配规则，包括域名、IP地址及通配符的匹配逻辑，并指出了端口的有效范围[0,65535]。该文档面向需要实现网络代理功能的开发者，提供了系统通信网络管理核心能力的配置规范。

### class_LinkAddress_3more_651d5ac8.md class_LinkAddress_3more_651d5ac8.md
本文档是Cangjie语言网络管理类的API参考文档。它主要介绍了LinkAddress（网络链路信息）、NetAddress（网络地址）和NetBlockStatusInfo（网络阻塞状态）三个类。关键内容包括地址字符串、前缀长度、IPv4/IPv6协议族类型及端口范围等属性的定义。文档明确这些组件属于SystemCapability.Communication.NetManager.Core系统能力，起始版本为22。面向应用开发者，该参考文档提供了管理网络连接、配置地址以及监控网络可用性或拥塞状态所需的数据结构。

### class_NetCapabilities.md class_NetCapabilities.md
本文档是Cangjie语言中NetCapabilities类的API参考文档，旨在定义网络的能力集。主要内容包括网络类型、上下行带宽及具体网络能力等属性的定义，以及类的初始化构造函数。关键信息指出bearerTypes数组仅包含一种网络类型，带宽单位为kb/s（0表示无法评估），所有属性均支持读写，且属于SystemCapability.Communication.NetManager.Core系统能力。该文档面向需要使用NetManager模块进行网络状态查询或配置的开发者。

### class_NetCapabilityInfo_879d74ba.md class_NetCapabilityInfo_879d74ba.md
本文档是Cangjie语言中NetCapabilityInfo类的API参考文档，旨在提供承载数据网络能力的实例。文档主要介绍了该类的定义及其两个核心属性：用于存储网络传输能力和承载类型的netCap，以及代表数据网络句柄的netHandle。关键信息指出这两个属性均为可读写，且该类属于SystemCapability.Communication.NetManager.Core系统能力，起始版本为22。该文档面向使用网络管理核心模块的开发者，帮助他们理解和操作网络能力信息。

### class_NetConnectionProp_6df6c3ab.md class_NetConnectionProp_6df6c3ab.md
这是一份Cangjie语言的API参考文档，旨在定义NetConnectionPropertyInfo类，用于封装和管理网络连接的相关信息。文档主要包含类定义及其两个核心属性：connectionProperties（网络连接属性）和netHandle（数据网络句柄）。这两个属性均为可读写类型，分别对应ConnectionProperties和NetHandle类型，属于SystemCapability.Communication.NetManager.Core系统能力，起始版本为22。该文档面向使用Cangjie语言进行网络管理开发的开发者，提供了操作网络连接参数的数据结构基础。

### class_NetHandle.md class_NetHandle.md
本文档是Cangjie语言中NetHandle类的API参考文档，旨在定义数据网络句柄及其操作。文档涵盖了网络ID属性（netId）的规范，以及两个核心域名解析方法：getAddressByName（获取首个IP）和getAddressesByName（获取所有IP）。关键信息包括方法参数、返回值类型、必需的ohos.permission.INTERNET权限，以及详细的错误码和异常处理说明。该文档主要面向使用NetworkKit进行网络连接管理的开发者，提供了从获取句柄到执行DNS解析的完整技术规范。

### class_NetSpecifie_2more_461b7199.md class_NetSpecifie_2more_461b7199.md
这是一份Cangjie语言的API参考文档，旨在定义网络管理核心模块中的数据结构。文档主要包含两个类：NetSpecifier用于提供承载数据网络能力的实例，包含网络传输能力和标识符（如蜂窝网络SIM卡槽或WLAN信息）；RouteInfo用于描述网络路由信息，涵盖目的地址、网关、接口名称及路由状态等属性。这些类均属于SystemCapability.Communication.NetManager.Core系统能力，起始版本为22。文档面向需要进行网络连接指定和路由配置的开发者，提供了详细的属性说明和构造函数定义。

### enum_NetBearType_2more_858e01cd.md enum_NetBearType_2more_858e01cd.md
本文档是Cangjie语言网络管理核心模块的API参考文档，旨在定义网络承载类型与网络能力的枚举值。主要涵盖NetBearType（如蜂窝、Wi-Fi、以太网）和NetCap（如互联网访问、彩信、非计费网络）的详细说明。文档重点阐述了网络能力标记（如NetCapabilityInternet与NetCapabilityValidated的区别）及其系统权限要求。适用于需要识别网络状态和能力的应用开发人员。

### enum_NetConnectionEvent.md enum_NetConnectionEvent.md
本文档是Cangjie语言中NetConnectionEvent枚举的API参考文档，用于定义网络连接事件类型。主要内容包括网络可用、丢失、阻塞状态变更、能力变更及连接属性变更等枚举成员，以及用于比较事件是否相等的运算符（==和!=）。文档指出该枚举继承自Equatable，属于SystemCapability.Communication.NetManager.Core系统能力，起始版本为22。该资料面向使用网络管理核心模块的开发者，旨在帮助其识别和处理网络状态变化事件。
