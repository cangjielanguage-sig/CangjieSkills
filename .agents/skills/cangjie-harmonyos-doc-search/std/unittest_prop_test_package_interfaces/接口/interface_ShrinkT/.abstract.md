This directory contains API documentation for the `Shrink` interface in the Cangjie programming language. It focuses on implementations that allow data types to generate smaller versions of themselves, a crucial capability for property-based testing and fuzzing. The documentation covers the core generic interface definition and its extensions across various data types, including primitive integers, floating-point numbers, strings, and complex collections like HashMaps and Arrays. It is suitable for Cangjie developers looking to implement data reduction strategies to isolate minimal failure cases in their test suites.
