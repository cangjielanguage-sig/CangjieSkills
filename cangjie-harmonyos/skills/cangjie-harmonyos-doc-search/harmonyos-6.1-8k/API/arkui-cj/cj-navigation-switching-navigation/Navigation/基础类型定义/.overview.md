# 基础类型定义

本目录包含Cangjie语言中用于ArkUI框架导航与UI配置的基础类型定义。它涵盖了页面导航路径信息、导航栈管理、导航选项配置、标题栏样式设置以及页面弹出信息等核心数据结构。这些类型定义是构建复杂页面路由和自定义导航界面的基石。主要面向使用Cangjie语言进行ArkUI应用开发的开发者，帮助他们精确控制页面跳转逻辑、栈操作行为及界面布局样式。

## 快速导航

你想做什么？

## 详细描述

### class_NavPathInfo_e4ac3b01.md class_NavPathInfo_e4ac3b01.md
本文档是Cangjie语言中NavPathInfo类的API参考文档，用于表示导航目标页面的信息。文档涵盖了类定义、属性（name、param、onPop）以及构造函数的详细说明。关键信息包括：name和param属性分别存储页面名称和详细参数，onPop属性定义页面弹出时的回调函数；构造函数支持命名参数初始化这些属性。该文档面向使用ArkUI框架进行应用开发的开发者，需具备Cangjie语言基础。

### class_NavPathStack.md class_NavPathStack.md
本文档是Cangjie语言中NavPathStack类的API参考文档，旨在管理ArkUI框架内的导航目标页面栈。主要内容包括类初始化方法init，以及用于栈操作的核心函数：弹出顶部页面的pop、通过对象推入页面的pushPath和通过名称推入页面的pushPathByName。文档详细说明了各方法的参数（如动画控制animated、导航选项options）及返回值。该类属于SystemCapability.ArkUI.ArkUI.Full系统能力，起始版本为22。主要面向需要实现页面跳转和栈管理的ArkUI应用开发者。

### class_NavigationOptions_5c83ee18.md class_NavigationOptions_5c83ee18.md
本文档是Cangjie语言中NavigationOptions类的API参考文档，主要用于定义导航栈操作的配置选项。文档详细介绍了类的核心属性，包括控制导航栈操作模式的launchMode和决定是否支持过渡动画的animated，以及类的构造函数初始化方法。关键信息指出这两个属性均为可空类型且可读写，并明确了其默认值和系统系统能力要求。该文档面向使用ArkUI框架进行应用开发的开发者，旨在帮助其在开发过程中灵活配置页面跳转和路由行为。

### class_NavigationTitleOptions.md class_NavigationTitleOptions.md
本文档是Cangjie语言中NavigationTitleOptions类的API参考文档，旨在定义Navigation标题栏的配置选项。文档涵盖了该类的核心属性，包括背景颜色、背景模糊样式、布局样式以及起始和结束边距，并详细说明了构造函数的参数及其默认值。关键信息指出所有属性均为可读写且可选，默认值为None，系统能力支持ArkUI全功能。该文档适用于使用ArkUI框架进行UI开发的开发人员，帮助他们自定义导航栏的外观和布局。

### class_PopInfo_2more_e8cf29a3.md class_PopInfo_2more_e8cf29a3.md
这是一份Cangjie语言的API参考文档，定义了ArkUI框架中用于页面弹出和布局样式的数据结构。文档涵盖`PopInfo`类，用于封装弹出页面的导航路径信息及操作结果；以及`BarStyle`枚举，用于指定标题栏或工具栏的布局模式，支持`Standard`（上方布局）和`Stack`（叠加布局），并包含相等性比较操作符。这些接口属于SystemCapability.ArkUI.ArkUI.Full能力，起始版本为22。该文档面向使用Cangjie开发ArkUI界面的开发者，提供了处理页面导航和UI布局样式的具体规范。

### enum_LaunchMode.md enum_LaunchMode.md
本文档定义了Cangjie语言中的LaunchMode枚举，用于规范导航栈的操作模式。主要内容包括枚举定义、四种启动模式（Standard、MoveToTopSingleTon、PopToSingleTon、NewInstance）的详细说明，以及相等与不等比较操作符。关键信息在于不同模式对NavDestination实例的处理差异：Standard为默认添加或替换，MoveToTopSingleTon将同名实例移至栈顶，PopToSingleTon弹出至同名实例，NewInstance则总是创建新实例。该枚举继承自Equatable，支持版本22。面向使用Cangjie开发ArkUI应用的开发者，适用于需要精细控制页面导航栈行为的场景。
