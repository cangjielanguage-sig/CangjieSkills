This directory provides comprehensive API reference documentation for the `SystemBarProperties` class in the Cangjie language, focusing on the configuration of system bar visual properties. It serves as a technical guide for developers looking to customize the appearance and behavior of status and navigation bars within their applications. The documentation details the constructor signature, parameter tables, and public properties, covering essential settings like background colors, content colors, icon light modes, and animation toggles. It highlights important logic, such as the precedence of content colors over icon light properties. This resource is suitable for application developers and UI engineers utilizing the WindowManager system capability who are working with API version 12 or later and need to fine-tune window-level UI elements for a specific visual style.
