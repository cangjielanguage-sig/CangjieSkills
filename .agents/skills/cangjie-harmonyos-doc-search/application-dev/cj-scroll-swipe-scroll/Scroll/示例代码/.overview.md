# 示例代码

This directory contains a collection of Cangjie code examples designed for the ArkUI framework, focusing specifically on advanced Scroll component implementations. It covers essential topics such as configuring Scroller controllers for programmatic control, implementing various nested scrolling strategies between parent and child components, and applying visual effects like edge fading. These examples demonstrate practical solutions for complex UI interactions, including coordinating scroll events and managing scroll boundaries. The content is suitable for HarmonyOS developers using the Cangjie language who need to build sophisticated, responsive user interfaces with custom scrolling behaviors.

## Detailed Description

### 示例代码1设置scroller控制器.md
This document provides a Cangjie code example demonstrating how to configure the Scroll component and utilize the Scroller controller for programmatic scrolling. The main topics cover Scroll component properties like direction, scroll bar styling, and friction, alongside event handling for scroll edges and stops. Key information includes practical implementations of Scroller methods such as scrollBy, scrollTo, scrollEdge, scrollPage, and fling, triggered via buttons to manipulate a vertical list. This tutorial is intended for ArkUI developers using the Cangjie language who need to implement custom scroll behaviors and UI controls.

### 示例代码2嵌套滚动实现方式一.md
This document provides a code example demonstrating how to implement nested scrolling between an inner List and an outer Scroll component in the ArkUI framework using Cangjie. The content covers the setup of a Flex layout containing a Scroll component, which houses a Column with a List, and details the use of state variables to track scroll position. Key information includes the implementation of the onScrollFrameBegin event to coordinate scrolling behavior. The core logic involves checking the listPosition state; when the inner List reaches its boundaries, subsequent scroll events are intercepted and delegated to the outer Scroll component via scrollBy. This example is intended for developers using the ArkUI framework and Cangjie language who need to create complex layouts with coordinated scrolling behaviors.

### 示例代码3嵌套滚动实现方式二.md
This document provides a code example demonstrating the second implementation method for nested scrolling in ArkUI using the Cangjie language. It covers the setup of a parent Scroll component containing a Tabs component, which houses a child List component. The core mechanism utilizes the nestedScroll property with NestedScrollOptions to coordinate scrolling behavior between the inner list and outer scroll area, specifically setting modes for forward and backward scrolling. This tutorial is intended for developers familiar with ArkUI and Cangjie seeking to implement complex scrolling interactions.

### 示例代码4嵌套滚动父组件向子组件传递滚动.md
This document provides a code example demonstrating how to implement nested scrolling where a parent Scroll component passes scroll control to a child List component in ArkUI. The content covers the setup of parent and child scrollers, disabling child scroll interaction, and implementing the onScrollFrameBegin callback logic. Key takeaways include using enableScrollInteraction(false) on the child and onScrollFrameBegin to calculate offsets. When the parent scrolls past a specific header height, it programmatically scrolls the child using scrollBy and returns zero offset to halt parent movement, ensuring a smooth transition. This tutorial targets ArkUI developers using the Cangjie language who need to handle complex nested scroll layouts.

### 示例代码5设置限位滚动_2more.md
This document serves as a practical tutorial for developers using the Cangjie language within the ArkUI framework, specifically demonstrating advanced configurations of the Scroll component. It covers two distinct examples: implementing basic limited scrolling with a list of items and enabling an edge fading visual effect. Key takeaways include the usage of the Scroller object for control, the ForEach loop for dynamic list generation, and the application of the fadingEdge method with FadingEdgeOptions to customize the fade length. This guide is intended for mobile application developers seeking to enhance user interface interactions and visual polish in their HarmonyOS applications.
