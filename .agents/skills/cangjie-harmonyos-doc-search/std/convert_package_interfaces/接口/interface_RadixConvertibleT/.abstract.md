This directory contains API documentation for the Cangjie programming language's `RadixConvertible` interface and its implementations across standard integer types. It covers the core interface definition and extensions for signed (Int8, Int16, Int32, Int64) and unsigned (UInt8, UInt16, UInt32, UInt64) integers. The documentation details methods for parsing strings to integers and converting integers to strings across various numerical bases (radices). Key features include strict parsing with exceptions, safe parsing using the Option type, and string formatting. This resource is suitable for Cangjie developers who need to perform base conversions, handle numeric string parsing, or implement robust error handling for numeric data types.
