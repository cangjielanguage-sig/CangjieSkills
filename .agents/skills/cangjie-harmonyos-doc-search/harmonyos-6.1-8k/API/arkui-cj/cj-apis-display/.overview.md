# cj-apis-display

This directory serves as a comprehensive repository for API documentation related to display management within the Cangjie programming language environment. It specifically targets the `ohos.display` module, providing essential resources for developers working on HarmonyOS applications. The content covers critical aspects of screen properties, including orientation, state monitoring, and advanced adaptations for foldable and waterfall screens. It is designed for software engineers and UI developers who need to implement robust display logic, handle multi-screen scenarios, and ensure optimal user interface layouts across diverse device form factors using Cangjie. By utilizing these standardized interfaces, developers can effectively manage complex display requirements such as irregular screen layouts and dynamic UI adjustments for foldable hardware.

## Detailed Description

### ohosdisplay屏幕属性/

This directory contains the API reference documentation for the `ohos.display` module in the Cangjie language, focusing on screen attribute management and display control. The content covers screen status, orientation, and foldable screen adaptation (such as fold state, crease area, and waterfall screen curved area), as well as the registration and deregistration of display listeners. This module provides developers with standardized interfaces for handling multi-screen displays, irregular screen layouts, and UI adaptation for foldable devices. It is primarily suitable for programmers using the Cangjie language for HarmonyOS window management and UI development.
