This directory focuses on the implementation and interaction design of half-modal pages (bindSheet) within the ArkUI framework using the Cangjie language. It covers essential concepts ranging from basic definitions and lifecycle management to advanced interaction patterns like nested scrolling and dismissal controls. The content is tailored for HarmonyOS and UI developers looking to create non-full-screen modal interfaces that maintain parent view visibility. Key topics include gesture priority, secondary confirmation dialogs, and device adaptation strategies.
