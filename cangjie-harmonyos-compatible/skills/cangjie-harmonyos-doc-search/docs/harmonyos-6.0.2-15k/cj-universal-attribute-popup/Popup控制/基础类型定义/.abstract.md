This directory provides API reference documentation for fundamental type definitions within the Cangjie language and ArkUI framework, specifically focusing on popup and dialog components. It covers essential classes such as `Action`, `DismissPopupAction`, `PopupOptions`, and `CustomPopupOptions`, alongside their constructors and event handling mechanisms. Key topics include button configuration, popup dismissal logic, visual styling, and state management. This documentation is suitable for HarmonyOS developers and UI engineers who need to implement interactive user interfaces, control popup behaviors, and manage component states programmatically.
