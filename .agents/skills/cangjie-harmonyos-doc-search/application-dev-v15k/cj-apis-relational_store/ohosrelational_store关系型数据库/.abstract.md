This directory contains API reference documentation for the HarmonyOS Relational Store module (`ohos.relational_store`) designed for the Cangjie programming language. It covers the management of local SQLite-based databases and distributed data synchronization. Key topics include database creation and deletion, configuration, data types, enumerations for sync states, and core classes like `RdbStore`, `RdbPredicates`, and `ResultSet`. It is intended for developers building applications requiring robust data persistence, complex SQL operations, and end-cloud synchronization within the HarmonyOS ecosystem.
