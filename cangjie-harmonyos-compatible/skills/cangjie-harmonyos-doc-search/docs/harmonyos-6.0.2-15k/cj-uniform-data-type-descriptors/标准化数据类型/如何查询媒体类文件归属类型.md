## 如何查询媒体类文件归属类型

下面以媒体类文件的归属类型查询场景为例，说明如何使用UTD。

1. 导入uniformTypeDescriptor模块。
2. 可根据 “.mp3” 文件后缀查询对应UTD数据类型，并查询对应UTD数据类型的具体属性。
3. 可根据 “audio/mp3” MIMEType查询对应UTD数据类型，并查询对应UTD数据类型的具体属性。
4. 将上述步骤查询出来的数据类型进行比较，确认类型是否相等。
5. 根据上述步骤中查询到的标准数据类型“general.mp3”与表示音频数据的已知标准数据类型“general.audio”做比较查询，确认是否存在归属关系。

```cangjie
// 1. 导入模块
import kit.ArkData.*
import kit.UIKit.BusinessException

try {
    // 2. 可根据 “.mp3” 文件后缀查询对应UTD数据类型，并查询对应UTD数据类型的具体属性
    let fileExtention = '.mp3'
    let typeId1 = getUniformDataTypeByFilenameExtension(fileExtention)
    let typeObj1 = getTypeDescriptor(typeId1)
    AppLog.info("typeId: ${typeObj1.typeId}")
    AppLog.info("belongingToTypes: ${typeObj1.belongingToTypes}")
    AppLog.info("description: ${typeObj1.description}")
    AppLog.info("referenceURL: ${typeObj1.referenceURL}")
    AppLog.info("filenameExtensions: ${typeObj1.filenameExtensions}")
    AppLog.info("mimeTypes: ${typeObj1.mimeTypes}")

    // 3. 可根据 “audio/mp3” MIMEType查询对应UTD数据类型，并查询对应UTD数据类型的具体属性
    let mineType = 'audio/mp3'
    let typeId2 = getUniformDataTypeByMIMEType(mineType)
    let typeObj2 = getTypeDescriptor(typeId2)
    AppLog.info('typeId: ${typeObj2.typeId}')
    AppLog.info('belongingToTypes: ${typeObj2.belongingToTypes}')
    AppLog.info('description: ${typeObj2.description}')
    AppLog.info('filenameExtensions: ${typeObj2.filenameExtensions}')
    AppLog.info('mimeTypes: ${typeObj2.mimeTypes}')

    // 4. 将数据类型进行比较，确认是否同一种数据类型
    if (typeObj1.equals(typeObj2)) {
        AppLog.info('typeObj1 equals typeObj2')
    } else {
        AppLog.info('typeObj1 not equals typeObj2')
    }

    // 5. 将查询到的标准数据类型“general.mp3”与表示音频数据的已知标准数据类型“general.audio”做比较查询，确认是否存在归属关系
    var ret = typeObj1.belongsTo('general.audio')
    AppLog.info('belongsTo, ret: ${ret}')
    let mediaTypeObj = getTypeDescriptor('general.media')
    ret = mediaTypeObj.isHigherLevelType('general.audio') // 确认是否存在归属关系
    AppLog.info('isHigherLevelType, ret: ${ret}')
} catch (e: BusinessException) {
    AppLog.error("ErrorCode: ${e.code},  Message: ${e.message}")
}
```
