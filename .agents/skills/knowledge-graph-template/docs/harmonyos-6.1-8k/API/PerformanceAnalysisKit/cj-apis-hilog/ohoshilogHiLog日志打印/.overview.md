## 详细描述

### enum_LogLevel_68cf28bf.md
本文档定义了仓颉语言中用于日志记录的 LogLevel 枚举，详细说明了各级别的功能与适用场景。文档涵盖了 Debug、Info、Warning、Error 和 Fatal 五个核心成员，明确了从详细流程分析到致命崩溃的不同严重程度。关键点在于区分各级别对业务的影响及恢复能力，如 Info 用于关键节点，Error 影响功能但可恢复，Fatal 则预示崩溃。该 API 属于 SystemCapability.HiviewDFX.HiLog 系统能力，主要面向仓颉开发者，旨在指导其规范日志输出以便于问题定位和系统监控。

### ohoshilogHiLog日志打_3more_bfc4d9e8.md
本文档介绍了ohos.hilog模块，旨在帮助应用和服务按指定级别输出日志以辅助调试。主要涵盖模块导入方法、仓颉语言API示例代码的使用说明及Context配置要求。关键信息指出该模块处于Beta阶段，需导入kit.PerformanceAnalysisKit，并详细说明了在仓颉工程index.cj和main_ability.cj文件中的运行与配置方式。面向使用仓颉语言的开发者，适用于需要集成日志功能以监控应用运行状态的开发场景。

### class_Hilog/
本目录包含仓颉语言中HiLog类的API参考文档，旨在指导应用和服务按指定级别输出日志。内容涵盖了类定义、各级别日志（debug、info、warn、error、fatal）的静态方法以及日志可打印性检查。核心知识点包括domain标识范围（0x0~0xFFFF）、tag长度限制（31字节）以及用于隐私控制的`{public}`和`{private}`标识。该文档适合使用仓颉语言进行HarmonyOS或OpenHarmony应用开发的开发者，帮助其掌握系统调试、监控及隐私过滤规范。
