# TestKit

The TestKit directory serves as a comprehensive documentation repository for the HarmonyOS application testing service, specifically tailored for the Cangjie (CJ) programming language. It provides essential resources for developers and QA engineers focusing on automated testing and quality assurance within the HarmonyOS ecosystem. Key components include the AbilityDelegatorRegistry mechanism and the UI Testing framework. This collection is designed for technical professionals building high-quality applications using Cangjie, offering detailed API references, error code diagnostics, and structural guides to facilitate robust testing solutions.

## Detailed Description

### [1] README_zh
This directory acts as the index center for the Test Kit (Application Testing Service) Cangjie language API documentation, designed specifically for developers in the HarmonyOS ecosystem. It systematically organizes various interfaces and error codes required for application testing. The core content covers the AbilityDelegatorRegistry mechanism and the ohos.ui_test module. As a showcase for Beta features, this document provides a functional overview and guides developers to specific API definitions and exception handling logic through links. It is suitable for developers and testers with basic knowledge of testing frameworks who are dedicated to building high-quality HarmonyOS applications using the Cangjie language.

### [2] cj-apis-ability_delegator_registry
This directory serves as the definitive source for API documentation regarding the `ability_delegator_registry` module. It is specifically designed for the HarmonyOS operating system and the Cangjie (CJ) programming language. It is a vital resource for software developers looking to implement ability delegation and registration within their testing environments.

### [3] cj-apis-ui_test
This directory contains the API reference documentation for the OpenHarmony Cangjie Language UI Testing Framework. It is a specialized toolkit designed to facilitate comprehensive automated testing solutions. The documentation provides extensive coverage of core testing functions, enabling developers to create robust UI test scripts for their applications.

### [4] cj-errorcode-uitest
This directory is dedicated to storing reference documentation for error codes related to the UI testing module. It primarily covers various exceptional situations encountered during UI automation testing, including but not limited to initialization configuration errors, assertion verification failures, loss of target control positioning, and unsupported operation commands. By providing detailed error descriptions, analysis of potential causes, and specific handling steps, this document assists developers and test engineers in quickly locating and fixing issues in test scripts. This resource is suitable for all technical personnel using the UI testing framework for application development or quality assurance and is recommended to be used in conjunction with general error code documentation for complete diagnostic information.
