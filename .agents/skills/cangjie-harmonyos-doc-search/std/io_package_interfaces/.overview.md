### io_package_interfaces.md io_package_interfaces.md

This document serves as API reference documentation for input and output stream interfaces in the Cangjie programming language. It defines four core interfaces: InputStream for reading data, OutputStream for writing and flushing buffers, IOStream which combines both, and Seekable for cursor manipulation within streams. Key details include method signatures like read and write which utilize Array<Byte> buffers, and properties in Seekable for managing stream position and length. This reference is intended for developers implementing or utilizing IO operations, requiring knowledge of basic Cangjie syntax and data types. Keywords: Cangjie, IO, Stream, Interface, API, Read, Write, Seek.
