# class_DotIndicator

This directory provides detailed API reference documentation for the `DotIndicator` class, specifically designed for the Cangjie language and ArkUI framework. It serves as a technical guide for configuring dot navigation indicators within Swiper components, covering essential aspects such as layout, styling, and interaction behaviors. The content includes instructions on setting dot dimensions, colors, and masks, as well as managing overflow scenarios where dot counts exceed the maximum display capacity. Furthermore, it offers specific methods for customizing the appearance of the selected indicator. This documentation is highly suitable for UI developers and system architects aiming to create polished, interactive navigation elements in their ArkUI-based applications, ensuring a seamless user experience for content sliders and galleries.

## Detailed Description

### class_DotIndicator_7more.md class_DotIndicator_7more.md
This document provides API reference documentation for the DotIndicator class in the Cangjie language, designed to configure dot navigation indicators for Swiper components. It details the class constructor and configuration methods including color, itemWidth, itemHeight, mask, and maxDisplayCount. Key information includes setting dot dimensions (default 6vp), color, and handling overflow scenarios where dot counts exceed the maximum display value (range 6-9). It notes that dots scale to 1.33x when pressed and that overflow modes currently lack interaction support. This reference guide targets UI developers building ArkUI applications who need to implement and customize navigation indicators.

### func_selectedColorResource_3more.md func_selectedColorResource_3more.md
This document serves as an API reference for configuring the appearance of the selected navigation indicator in the Swiper component using the Cangjie language. It details three specific functions: selectedColor, selectedItemHeight, and selectedItemWidth. Key information includes that these functions accept nullable parameters to set color, height, and width respectively. Notably, dimension parameters do not support percentages, with default values set to 0x007DFF for color, 6vp for height, and 12vp for width. This documentation is intended for UI developers utilizing the ArkUI framework to customize Swiper component behaviors. Keywords: Cangjie, Swiper, API reference, ArkUI, navigation indicator, UI styling.
