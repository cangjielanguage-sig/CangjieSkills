This directory focuses on the configuration of application components and metadata within the HarmonyOS development environment. It covers essential setup tasks such as defining application icons, labels, version numbers, supported device types, permissions, and package naming conventions. Key topics include `app.json5` and `module.json5` configuration, system priority rules for UI elements, and reverse domain naming for unique identification. This documentation is suitable for HarmonyOS developers who need to configure project properties, manage application metadata, and ensure proper system integration during the initial setup and packaging phases.
