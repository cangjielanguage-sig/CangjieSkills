This directory serves as a comprehensive educational resource for mastering runtime reflection within the Cangjie programming language, with a specific focus on the `memberInfo` module. It provides detailed guidance on how developers can programmatically inspect types, access internal class structures, and manipulate object data dynamically during application execution. The content thoroughly explains the retrieval of `TypeInfo` objects, the navigation of `instanceVariables` for reading and writing values, and the inspection of `instanceFunctions` to verify method signatures. By utilizing a practical example involving a `Rectangular` object, the documentation illustrates the effective use of `getValue`, `setValue`, and `TypeInfo.of` methods. This material is ideally suited for advanced developers, systems programmers, and library authors who are working with the Cangjie standard library and require robust introspection capabilities to build flexible, dynamic frameworks or debugging tools.
