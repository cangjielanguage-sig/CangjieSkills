This directory provides comprehensive API reference documentation for the `ohos.sensor` module in the Cangjie programming language, designed for HarmonyOS/OpenHarmony development. It covers sensor data structures, response classes for various hardware types (accelerometer, gyroscope, light, etc.), configuration enums, and subscription functions. The documentation enables developers to access, configure, and interpret device sensor data using the SensorServiceKit. It is suitable for software engineers and developers building applications requiring real-time environmental, motion, or biometric sensor integration.
