This directory provides comprehensive API documentation for the `ohos.system_date_time` module within the Cangjie programming language, specifically designed for the HarmonyOS and OpenHarmony platforms. It covers essential components for system time management, including the `SystemDateTime` class, the `TimeType` enumeration, and module-level integration guides. Key topics include retrieving current time, calculating uptime metrics (handling deep sleep states), and managing timezone settings. This documentation is suitable for Cangjie developers who need to implement precise time measurement, track system states, or handle localization in their applications using the BasicServicesKit.
