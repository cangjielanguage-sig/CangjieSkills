# 应用跟随系统的深浅色模式

This directory provides a specialized technical guide focused on the implementation of system-wide dark and light mode adaptation for applications developed using the Cangjie framework. It addresses the growing need for applications to dynamically adjust their visual appearance based on user system settings, thereby enhancing user comfort and experience. The documentation covers a wide array of implementation strategies, ranging from basic color adaptation using custom resource directories or system resource IDs to more complex image adaptation via resource qualifiers or SVG fill properties. Additionally, it includes specific instructions for configuring Web components to ensure they respect the current theme. The guide also delves into the programmatic aspects of theming, such as listening for mode switch events and handling configuration updates. Key technical concepts discussed include the `dark` resource qualifier, `AbilityStage` lifecycle methods, `AppStorage`, and `@Watch` decorators. This resource is primarily suitable for developers and UI engineers who are looking to build robust, responsive applications that offer a seamless visual experience across both light and dark system environments.

## Detailed Description

### 应用跟随系统的深浅色模式_1.md

This technical guide instructs developers on the comprehensive process of implementing system-wide dark and light mode adaptation in applications built using the Cangjie framework. It serves as a detailed tutorial for those aiming to create responsive User Interfaces (UIs) that automatically adjust to system preferences. The content is organized into four main technical areas. First, it covers color adaptation, providing instructions on using custom resource directories or system resource IDs to manage color schemes. Second, it addresses image adaptation, explaining how to utilize resource qualifiers or modify SVG fill properties to ensure images look correct in both modes. Third, it details the specific configuration required for Web components to function within the theme context. Fourth, it discusses listening for mode switch events. Key technical takeaways from this guide include the use of the `dark` resource qualifier for enabling automatic resource switching and the strategic employment of `AbilityStage` lifecycle methods. Furthermore, it highlights the use of `AppStorage` and `@Watch` decorators to execute custom logic when configuration updates occur. This document is a vital resource for ensuring applications maintain visual consistency and usability across different system themes.
