# 添加属性

This directory focuses on configuring and enhancing the Image component within the ArkUI framework using the Cangjie language. It covers essential properties for image manipulation, including scaling modes (objectFit), interpolation for quality enhancement, repetition for tiling effects, and rendering modes for color or performance optimization. The tutorials provide practical code examples to help developers customize image display, improve rendering quality, and manage loading behavior. It is suitable for ArkUI developers looking to refine UI visuals and optimize image performance in HarmonyOS applications.

## Detailed Description

### 图片插值_2more.md
This document serves as a code tutorial for ArkUI developers using the Cangjie language, demonstrating how to enhance image display quality and layout. It covers two primary topics: image interpolation and image repetition. The first section explains using the interpolation property with ImageInterpolation enum values like None, Low, Medium, and High to reduce blurriness when scaling images. The second section details the objectRepeat property to tile images along the X-axis, Y-axis, or both axes. Key takeaways include practical code snippets for implementing these visual effects. This guide is intended for developers seeking to optimize image rendering and tiling in their applications.

### 添加属性_2more.md
This tutorial demonstrates how to configure properties for the Image component in ArkUI using the Cangjie language to achieve flexible image display. The document focuses specifically on setting image scaling types using the objectFit attribute. Key information includes a complete code example illustrating six scaling modes: Contain, Cover, Auto, Fill, ScaleDown, and None, explaining how each affects the aspect ratio and boundaries of the image within a defined frame. Intended for ArkUI developers using Cangjie, this guide helps users customize image rendering to fit specific UI design requirements.

### 设置图片渲染模式_3more.md
This technical guide demonstrates how to manipulate image display properties in ArkUI using the Cangjie programming language. It covers three distinct configuration areas: setting the rendering mode to switch between original color and monochrome, configuring decoding dimensions via sourceSize to reduce resolution, and implementing synchronous loading to prevent UI flickering. Key takeaways include the usage of the renderMode, sourceSize, and syncLoad properties, with specific warnings about blocking the main thread during synchronous loads. This document targets application developers seeking to optimize image rendering and user experience in HarmonyOS applications.
