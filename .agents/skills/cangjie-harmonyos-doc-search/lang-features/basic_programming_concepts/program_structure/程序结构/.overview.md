## 详细描述

### const_变量.md const_变量.md
本文档旨在介绍仓颉编程语言中 `const` 变量的定义、特性及使用规范。主要涵盖 `const` 变量的编译时求值、不可变性、深度 const 语义及其与 `let` 的区别。文档还详细对比了值类型（如 struct）和引用类型（如 class）在内存分配、赋值拷贝及数据共享上的行为差异，并通过代码示例演示了具体效果。关键信息在于理解 `const` 的不可变本质及不同类型变量的底层机制。这是一份面向仓颉语言开发者的基础教程，帮助其掌握变量声明与类型系统。

### 作用域.md 作用域.md
本文档旨在阐述仓颉编程语言中“作用域”的概念及规则，用于解决命名冲突和元素访问控制。主要内容包括作用域的定义、嵌套关系及三条核心规则：外层定义在内层有效、内层定义在外层无效、以及内层对同名变量的遮蔽。文档说明大括号“{}”是构造作用域的语法基础，并通过代码示例演示了顶层与嵌套作用域中的变量绑定变化。这是一份面向仓颉初学者的基础教程，帮助开发者理解变量生命周期与可见性。

### 变量/
本目录主要介绍仓颉编程语言中变量的核心概念与使用规则。内容涵盖变量的定义、语法结构、修饰符（如 `let`、`var`、`const`）以及类型推断和初始化策略。文档详细区分了不可变与可变变量的差异，明确了全局与局部变量的初始化要求，并通过代码示例展示了在控制流结构（如 `try-catch`）中不可变变量的行为及编译器的错误检查机制。这些资料适合仓颉语言开发者及初学者，旨在帮助其掌握变量声明、管理及错误处理中的关键语法。
