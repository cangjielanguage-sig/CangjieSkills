This directory contains API reference documentation for the HarmonyOS HiAppEvent module, specifically tailored for the Cangjie programming language. It covers the comprehensive framework for application event tracking, logging, subscription, and analysis within the Performance Analysis Kit. Key components include data structures for event configuration, enumerations for event types, and classes for managing event packages and processors. This documentation is suitable for HarmonyOS developers and system integrators looking to implement robust performance analysis, fault monitoring, and user behavior tracking in their applications using Cangjie.
