# class_AppStorage

This directory contains API reference documentation for the `AppStorage` class within the Cangjie programming language and ArkUI framework. It focuses on global UI state management, serving as a central hub for application-level state, persistent storage, and environment variables. The documentation covers class definitions, static methods for data manipulation (get, set, delete), and data binding mechanisms (one-way and two-way). It is specifically designed for Cangjie developers building ArkUI applications who need to manage global state and data synchronization, excluding mixed ArkTS development scenarios.

### class_AppStorage_7more.md class_AppStorage_7more.md

AppStorage serves as a central hub for application-level state, bridging persistent storage and environment variables with the UI.
