This directory serves as a comprehensive technical resource for the HarmonyOS accessibility module, specifically adapted for the Cangjie programming language. It provides essential API reference documentation designed to assist developers in implementing robust barrier-free features within their applications. The content covers a wide array of critical functionalities, including accessibility application metadata, advanced gesture recognition, caption styling, event handling, and window management. By offering detailed specifications for classes, enums, and functions, this documentation enables the creation of vital assistive services such as screen readers, touch guides, and closed captioning systems. It is primarily intended for system developers and application engineers who are dedicated to enhancing software accessibility. The documentation provides the technical specifications required to leverage system capabilities effectively, starting from API version 19, ensuring that applications are inclusive and accessible to all users.
