This directory provides comprehensive API reference documentation for the `ShowDialogOptions` class, a critical component for configuring dialog boxes within the Cangjie programming language and the ArkUI framework. It thoroughly covers the configuration of dialog display and behavior, detailing visual elements such as background color, blur style, and shadow, as well as layout attributes including alignment, offset, and mask rectangles. Additionally, the documentation explains interactive features like button configuration, modal state management, and hover mode capabilities. All properties are readable and writable. Intended for developers building UI applications, this reference requires SystemCapability.ArkUI.ArkUI.Full and targets API version 22. The directory is split into specific files focusing on general class properties and specific variable configurations. Keywords: Cangjie, ArkUI, Dialog, API, UI Configuration, ShowDialogOptions, Layout, Modal State.
