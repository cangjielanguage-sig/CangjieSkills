# 基础类型定义

本目录包含ArkUI框架在仓颉语言下的基础类型定义文档，主要涉及图像处理领域的核心数据结构。内容涵盖了用于构建颜色滤镜矩阵的ColorFilter类、处理图片加载异常的ImageError类，以及封装图片加载成功结果的ImageLoadResult类。这些API参考文档适用于ArkUI应用开发者，旨在提供图像色彩处理、错误回调机制及加载状态管理的详细规范，帮助开发者在UI渲染和状态判断中正确使用这些数据结构。

## 快速导航

- 你想获取图片加载成功后的详细尺寸与布局信息？ → 查看 class_ImageLoadResult.md ImageLoadResult 定义

## 详细描述

### class_ColorFilter_2more_a5137f4d.md class_ColorFilter_2more_a5137f4d.md
本文档是ArkUI框架在仓颉语言下的API参考文档，主要定义了ColorFilter和ImageError两个类。文档首先介绍了ColorFilter类，用于构建4x5的颜色滤镜矩阵以实现图像色彩处理。其次详细说明了ImageError类，该类作为图片加载异常时的回调对象，包含组件宽度、高度及错误信息等属性。这些类均属于SystemCapability.ArkUI.ArkUI.Full系统能力，适用于版本22及以上。文档旨在帮助开发者在图像处理和错误回调场景中正确使用这些数据结构。

### class_ImageLoadResult.md class_ImageLoadResult.md
这是一份Cangjie语言的API参考文档，定义了ImageLoadResult类，用于封装图片加载成功后的结果信息。文档涵盖了图片原始尺寸、组件尺寸、加载状态以及实际绘制内容的宽高和偏移量等属性。关键点在于，实际绘制内容相关的属性仅在loadingStatus返回1时有效。该文档面向ArkUI应用开发者，旨在提供图片加载后的详细布局数据，支持开发者进行精确的UI渲染和状态判断。
