This directory provides essential API reference documentation for the `AudioHapticManager` class in the Cangjie programming language, specifically designed for the HarmonyOS ecosystem. It focuses on the technical implementation of synchronized audio and haptic (vibration) coordination. The content covers the complete lifecycle of audio-haptic management, starting with class definitions and resource registration via `registerSource`, through to player instantiation using `createPlayer`. It also includes detailed configuration options for latency modes and stream usage, alongside necessary permissions like `ohos.permission.VIBRATE` and error code troubleshooting. This documentation is intended for multimedia application developers and engineers aiming to build immersive, multi-sensory user experiences with precise control over sound and vibration feedback.
