# 应用无响应日志分析

This directory provides a comprehensive technical resource for analyzing Application Not Responding (ANR) and appfreeze logs within the HarmonyOS/OpenHarmony environment. It covers the interpretation of log headers, specific timeout scenarios like user input response and lifecycle switches, and main thread blockages. Key topics include `THREAD_BLOCK` events, IPC delays, CPU load, and memory usage analysis. Designed for software developers and system engineers, these guides enable effective root cause analysis of application stability and performance issues by correlating specific appfreeze logs with system hilog data.
