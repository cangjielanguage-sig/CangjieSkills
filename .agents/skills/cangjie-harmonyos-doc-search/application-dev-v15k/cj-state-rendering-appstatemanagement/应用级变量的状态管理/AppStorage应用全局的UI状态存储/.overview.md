# AppStorage应用全局的UI状态存储

This directory provides comprehensive documentation for AppStorage, the global UI state storage mechanism designed for the ArkUI framework and Cangjie programming language. It details the implementation of a singleton storage system created at application startup, which facilitates central state management accessible across the entire app, distinguishing it from page-level LocalStorage. The content covers the integration of AppStorage with PersistentStorage and Environment variables, highlighting its role in state sharing between multiple UIAbility instances. It also explains the necessity of using @StorageProp and @StorageLink decorators for UI synchronization. This resource is essential for HarmonyOS developers and software engineers aiming to master application-level state management, data persistence, and reactive programming in Cangjie-based projects, particularly for version 12 and above.

## Detailed Description

### AppStorage应用全局的UI状态存储_2more.md AppStorage应用全局的UI状态存储_2more.md
This document serves as a reference guide for AppStorage, a global UI state storage mechanism in the ArkUI framework. It explains that AppStorage is a singleton created at application startup to provide central storage for state properties accessible across the entire app, distinguishing it from page-level LocalStorage. The text details how AppStorage acts as a hub for PersistentStorage and Environment variables to interact with the UI. Key takeaways include its support for state sharing between multiple UIAbility instances and the requirement to use @StorageProp and @StorageLink decorators for UI synchronization. The document notes that this feature is exclusive to pure Cangjie scenarios starting from version 12. It is intended for developers managing application-level state and data persistence.

### 示例代码.md 示例代码.md
This document provides practical code examples demonstrating state management decorators in the Cangjie programming language for HarmonyOS development. It covers two main topics: the usage of @StorageProp for one-way data binding and @StorageLink for two-way data synchronization. Key takeaways include understanding that @StorageProp requires explicit AppStorage calls for updates, whereas @StorageLink automatically synchronizes state changes across parent and child components. The target audience is application developers seeking to implement reactive state management in Cangjie-based UI frameworks.
