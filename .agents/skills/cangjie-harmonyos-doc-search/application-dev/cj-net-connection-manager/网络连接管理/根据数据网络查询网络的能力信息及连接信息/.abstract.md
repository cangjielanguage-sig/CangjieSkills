This directory provides comprehensive technical guides for HarmonyOS developers focusing on network management using the NetworkKit framework within the Cangjie language environment. It details the procedures for querying network capabilities and connection properties, essential for applications requiring real-time network awareness. Key topics include permission configuration (specifically ohos.permission.GET_NETWORK_INFO), necessary module imports, and the retrieval of network handles via methods like getDefaultNet and getAllNets. The guides explain how to identify network types—such as Cellular and Wi-Fi—and specific features like MMS or Internet access. Additionally, it covers the extraction of link details through connection properties. These resources are designed for software developers and system engineers aiming to implement robust network status monitoring and data retrieval functionalities in their applications, ensuring they can effectively manage and respond to network state changes.
