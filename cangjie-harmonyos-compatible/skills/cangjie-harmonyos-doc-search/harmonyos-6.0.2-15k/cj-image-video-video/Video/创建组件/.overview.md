# 创建组件

This directory contains API documentation for creating and initializing video components within the ArkUI framework using the Cangjie programming language. It covers various constructor overloads that allow developers to configure video sources (AppResource or String), playback speeds (Float64 or PlaybackSpeed enum), preview images, and controllers. The documentation details supported video formats like mp4, mkv, and TS, and specifies necessary permissions for network access. This resource is suitable for HarmonyOS developers looking to implement robust video playback features in their applications.

## Detailed Description

### initAppResource_Float64_Ap_2more.md initAppResource_Float64_Ap_2more.md
This API documentation defines two overloaded constructors for initializing a video component within the ArkUI framework using Cangjie. The content details two init function signatures that accept an AppResource source, playback speed (either Float64 or PlaybackSpeed enum), a preview image, and a VideoController. Key information includes support for local and network video sources (mp4, mkv, TS formats) and specific playback speed values ranging from 0.75x to 2.0x. Network usage requires the ohos.permission.INTERNET permission. This reference guide targets developers implementing video playback features in HarmonyOS applications.
