# cj-camera-overview

本目录包含 Camera Kit（相机服务）的概览文档，旨在介绍其基本概念、功能及开发模型。文档详细阐述了相机应用的开发场景、工作流程以及输入设备管理、会话管理和输出管理三者之间的关系。核心内容包括通过接口实现预览、拍照、录像及控制闪光灯、曝光等参数，并深入解析了底层通过 HDI 和 BufferQueue 传递数据的机制。该文档适合需要开发相机应用或相关模块的开发者阅读，属于概览性指南。关键词：Camera Kit、相机开发、会话管理、HDI、BufferQueue。
