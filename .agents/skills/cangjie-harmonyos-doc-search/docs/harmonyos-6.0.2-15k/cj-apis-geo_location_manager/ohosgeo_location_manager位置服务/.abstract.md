This directory provides comprehensive API reference documentation for the HarmonyOS Location Kit module, specifically implemented in the Cangjie programming language. It covers a wide range of location services including continuous and single location requests, geocoding, reverse geocoding, and GNSS satellite management. Key components include data structures for geographical coordinates, configuration classes for various location scenarios, and enumerations for error handling and priority settings. This documentation is intended for HarmonyOS developers and software engineers building location-aware applications who need precise technical specifications for integrating positioning, navigation, and address conversion features.
