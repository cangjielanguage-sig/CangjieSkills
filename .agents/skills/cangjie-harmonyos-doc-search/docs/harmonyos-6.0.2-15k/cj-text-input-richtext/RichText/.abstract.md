This directory provides comprehensive documentation and practical code examples for the RichText component within the ArkUI framework, specifically tailored for developers using the Cangjie language. It covers the complete API reference for creating components that parse and display HTML strings, detailing the `init` constructor, universal attributes, and lifecycle events such as `onStart` and `onComplete`. The content also includes implementation examples for rendering HTML/CSS content and managing UI layouts in HarmonyOS applications. Key information highlights critical usage constraints, noting that the component is memory-intensive and unsuitable for heavy customization or repetitive list rendering, while suggesting alternatives like Web or RichEditor for complex scenarios. Included files offer both theoretical background and hands-on code samples. This resource is suitable for HarmonyOS developers seeking to integrate basic rich text display functionality, handle loading states, and manage complex UI layouts efficiently using weight-based distribution.
