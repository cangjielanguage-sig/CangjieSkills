### Search_5more_07cedc0c.md Search_5more_07cedc0c.md
本文档是ArkUI框架中Search组件的API参考文档，旨在指导开发者使用Cangjie语言实现搜索框功能。文档涵盖了模块导入、组件初始化方法init及其参数配置，包括搜索文本、占位符、图标和控制器。关键信息显示该组件目前处于Beta阶段，起始版本为22，并支持所有通用属性和事件。主要面向ArkUI应用开发者，适用于需要构建用户搜索输入界面的场景。

### 组件事件.md 组件事件.md
本文档定义了UI组件的事件处理API，详细说明了搜索、编辑及剪贴板操作等用户交互的回调函数。主要涵盖五个核心函数：onSubmit（提交搜索）、onChange（内容变化）、onCopy（复制）、onCut（剪切）和onPaste（粘贴）。所有函数均接受?(String) -> Unit类型的回调参数以处理文本内容，起始版本为22，支持完整的ArkUI系统能力。这是面向使用ArkUI框架和仓颉语言开发交互式界面的开发者的参考文档。
