This directory focuses on network connection management within the HarmonyOS ecosystem using the Cangjie programming language and NetworkKit. It covers essential tasks such as DNS resolution, monitoring network status changes, managing network connections (WiFi, cellular, Ethernet), and querying network capabilities. Developers will learn how to handle network migration, bind applications to specific networks, and implement robust connectivity logic. This resource is suitable for HarmonyOS application developers and system engineers aiming to build applications with stable and intelligent network features.
