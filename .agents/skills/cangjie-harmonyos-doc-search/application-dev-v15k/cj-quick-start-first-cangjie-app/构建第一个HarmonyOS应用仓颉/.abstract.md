This directory provides a comprehensive guide for developers starting their journey with HarmonyOS application development using the Cangjie programming language. It covers the entire lifecycle of creating a basic application, from setting up the project environment and understanding the file structure to building user interfaces and implementing page navigation. Key topics include DevEco Studio configuration, UI component implementation, state management, and routing logic. Suitable for beginners and developers transitioning to Cangjie, this resource equips users with the essential skills to build and run their first multi-page HarmonyOS app on emulators or real devices.
