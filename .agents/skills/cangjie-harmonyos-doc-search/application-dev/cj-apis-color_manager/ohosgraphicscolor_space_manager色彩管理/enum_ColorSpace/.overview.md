# enum_ColorSpace

This directory contains API reference documentation for the `ColorSpace` enumeration within the Cangjie graphic system. It covers definitions of various color gamuts (such as Display P3, SRGB, BT2020, and Adobe RGB), transfer functions (HLG, PQ, Gamma), and encoding ranges (Full, Limited). Additionally, it includes utility methods for comparing and converting color space values. This documentation is intended for software developers and engineers working on 2D graphics and color management who need to implement or manipulate color standards in their applications.
