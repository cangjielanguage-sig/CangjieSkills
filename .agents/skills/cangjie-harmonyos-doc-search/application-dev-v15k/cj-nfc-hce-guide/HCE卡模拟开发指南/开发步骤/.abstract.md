This directory serves as a comprehensive resource for developers focusing on Host Card Emulation (HCE) implementation within the HarmonyOS ecosystem. It provides step-by-step technical tutorials covering the entire development lifecycle for NFC-based card emulation features. The content is divided into two primary scenarios: foreground card swiping and background card swiping. Key topics include configuring `module.json5` for necessary permissions and AID groups, initializing and managing the `HceService`, and handling APDU command callbacks. The guides also detail lifecycle management, ensuring services are correctly started and stopped during application state changes. Designed for developers proficient in ArkTS or Cangjie, these documents offer the necessary code structures and configuration details to build robust applications capable of interacting with NFC readers seamlessly.
