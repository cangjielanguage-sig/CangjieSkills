This directory provides detailed API reference documentation for the `DotIndicator` class, specifically designed for the Cangjie language and ArkUI framework. It serves as a technical guide for configuring dot navigation indicators within Swiper components, covering essential aspects such as layout, styling, and interaction behaviors. The content includes instructions on setting dot dimensions, colors, and masks, as well as managing overflow scenarios where dot counts exceed the maximum display capacity. Furthermore, it offers specific methods for customizing the appearance of the selected indicator. This documentation is highly suitable for UI developers and system architects aiming to create polished, interactive navigation elements in their ArkUI-based applications, ensuring a seamless user experience for content sliders and galleries.
