This directory serves as a comprehensive resource for the `cj-apis-relational_store`, specifically focusing on the HarmonyOS Relational Store module adapted for the Cangjie programming language. It provides essential API documentation for developers looking to implement local SQLite-based database management and distributed data synchronization within their applications. The content covers a wide array of functionalities, ranging from basic database creation and deletion to complex configuration and data type handling. By detailing core classes such as `RdbStore`, `RdbPredicates`, and `ResultSet`, along with enumerations for synchronization states, this documentation is tailored for software engineers and developers who require robust data persistence solutions and sophisticated SQL operations. It is particularly suitable for those building applications within the HarmonyOS ecosystem that demand reliable end-cloud synchronization and high-performance data handling capabilities.
