This directory serves as a comprehensive technical resource for developers working within the Cangjie programming ecosystem, specifically focusing on the implementation of AES symmetric encryption and decryption using the CCM (Counter with CBC-MAC) mode. It provides a structured approach to utilizing the `CryptoArchitectureKit`, enabling developers to achieve robust authenticated encryption which ensures both data confidentiality and integrity. The directory covers the full spectrum of the cryptographic workflow, starting from the initial generation of symmetric keys and the instantiation of cipher objects, through to the detailed configuration of parameters and the final processing of data. It also highlights critical operational constraints, such as the inability to perform segmented updates in CCM mode and the specific requirement for a 12-byte authentication tag. This repository is ideally suited for Cangjie developers who have a foundational understanding of cryptographic concepts and are looking for practical, in-depth guidance on implementing secure data handling mechanisms in their applications.
