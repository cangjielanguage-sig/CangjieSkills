# cj-apis-user_auth

This directory serves as a comprehensive repository for API reference documentation regarding the `ohos.user_auth` module, specifically tailored for the Cangjie programming language within the HarmonyOS development environment. It focuses on the critical aspects of user authentication, providing the necessary tools for developers to implement robust biometric and credential-based security protocols. The documentation covers a wide array of essential components, including detailed specifications for authentication parameters, result handling mechanisms, trust levels, and enrollment states. This resource is primarily designed for software engineers and system integrators who are tasked with building secure applications. It is particularly relevant for those implementing high-security features such as device unlocking, secure payment processing, and rigorous identity verification, leveraging the capabilities of the SystemCapability.UserIAM.UserAuth.Core framework.

*   **Enumerations:** Enums detailing authentication types and specific error codes.

*   **Target Use Cases:** Device unlocking, payments, and identity verification.
