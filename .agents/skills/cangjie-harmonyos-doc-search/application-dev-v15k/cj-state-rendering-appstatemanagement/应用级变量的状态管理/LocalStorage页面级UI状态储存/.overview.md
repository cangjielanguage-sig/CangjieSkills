### LocalStorage页面级UI状态储存_2more.md LocalStorage页面级UI状态储存_2more.md
This technical guide explains the LocalStorage mechanism for managing page-level UI state within the Cangjie framework. It covers the concept of LocalStorage as an in-memory database, component tree inheritance via the @Entry decorator, and the specific decorators used for data synchronization. Key information includes the distinction between @LocalStorageProp for one-way sync and @LocalStorageLink for two-way sync, alongside limitations such as immutable property types and sharing scope restricted to the same package. Intended for Cangjie UI developers, this document provides the necessary reference for implementing state management across component trees.

### 示例代码.md 示例代码.md
This document provides Cangjie code examples demonstrating state management using LocalStorage within the HarmonyOS UIKit framework. It covers two primary decorators: @LocalStorageProp for one-way data binding and @LocalStorageLink for two-way data synchronization. Key takeaways include the distinction that @LocalStorageProp variables are read-only within the component and must be updated via the storage instance, whereas @LocalStorageLink allows direct modification that automatically syncs across parent and child components. This tutorial is intended for developers using the Cangjie language to implement reactive state management in their applications. Keywords: Cangjie, LocalStorage, State Management, HarmonyOS, @LocalStorageProp, @LocalStorageLink.
