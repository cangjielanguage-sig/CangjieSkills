# 栅格容器GridRow

This directory provides comprehensive technical documentation for the `GridRow` component within the ArkUI framework, utilizing the Cangjie programming language. It covers fundamental aspects of grid layout design, including how to configure total columns, manage arrangement directions, set spacing (gutters), and implement responsive breakpoints for adaptive designs. The content is tailored for UI developers and software engineers who need to build flexible, responsive user interfaces that function seamlessly across various device sizes and screen widths.

## Detailed Description

### 布局的总列数.md 布局的总列数.md
This technical guide explains how to configure the total number of columns in a GridRow layout using the Cangjie language. It covers three main configuration methods: the default 12-column setting, applying a fixed integer value for all devices, and using GridRowColumnOption for responsive design across different breakpoints (xs, sm, md, lg, xl, xxl). Key takeaways include understanding that unspecified breakpoints default to 12 or inherit values from the nearest defined size. The document provides code examples demonstrating these behaviors. It is intended for developers building responsive user interfaces with ArkUI, requiring knowledge of grid systems and breakpoint management.

### 排列方向_2more.md 排列方向_2more.md
This technical guide explains how to configure the arrangement direction and spacing of child components within the GridRow layout system. The document covers two primary configuration areas: the direction property for layout flow and the gutter property for element spacing. Key information includes using GridRowDirection.Row for default left-to-right arrangement or RowReverse for right-to-left. Additionally, it details setting spacing via the gutter attribute, which accepts a Length value for uniform gaps or a GutterOption object to define distinct horizontal and vertical distances. This reference material targets UI developers using the Cangjie language who need to customize grid layouts for flexible design requirements.

### 栅格系统断点.md 栅格系统断点.md
This document defines the grid system's breakpoint rules for responsive layout design based on device width. It covers default breakpoint ranges (xs, sm, md, lg), customization options for up to six breakpoints (including xl, xxl), and the configuration of the breakpoints and reference parameters within the GridRow component. Key information includes how to define custom width ranges using a monotonically increasing array to trigger layout changes, supported by a Cangjie code example demonstrating dynamic column spans. This technical guide targets UI developers using the ArkUI framework who need to implement adaptive layouts for various device widths.
