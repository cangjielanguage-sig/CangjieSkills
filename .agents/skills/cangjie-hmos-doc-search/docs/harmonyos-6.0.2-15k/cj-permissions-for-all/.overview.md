# cj-permissions-for-all

This directory serves as a comprehensive technical resource dedicated to managing application permissions within the HarmonyOS and OpenHarmony development ecosystems. It covers the complete lifecycle of permission handling, ranging from general application workflows to specific authorization mechanisms. The content addresses both user-granted permissions required for accessing sensitive private data and system-granted permissions necessary for hardware and network interactions. Key concepts include runtime permission requests, Access Control Lists (ACL), protection levels, and security attributes. This documentation is essential for application developers seeking to implement robust security features, ensure strict compliance with privacy standards, and optimize the configuration of device capabilities across various API versions.

## Detailed Description

### [1] 对所有应用开放/
This directory provides comprehensive documentation for permissions available to all applications within the HarmonyOS development environment. It encompasses the general workflow for applying for permissions, detailed lists of user-granted permissions involving sensitive data, and system-granted permissions for hardware and network access. Key topics include runtime permission requests, access control lists (ACL), protection levels, and security attributes. This resource is specifically designed for application developers who need to implement secure access to device features, ensuring compliance with privacy standards and optimizing the development process for permission handling. It serves as a central hub for understanding both user and system authorization mechanisms.

### [2] 开放权限系统授权/
This directory serves as a comprehensive resource for understanding the open permission system authorization framework, specifically tailored for the OpenHarmony and HarmonyOS development environments. It details the mechanism of `system_grant` permissions, which are automatically authorized by the system during the application installation phase, thereby bypassing the need for explicit user consent. The content covers the theoretical definitions, the declaration process in application manifests, and provides a detailed reference library for API version 12. This documentation is primarily designed for application developers who must accurately declare permissions to access essential device capabilities—such as hardware interfaces, sensors, and system utilities—while ensuring compliance with strict system security policies. By utilizing this guide, developers can streamline the permission configuration process and ensure their applications function correctly across different device hardware and software versions.
