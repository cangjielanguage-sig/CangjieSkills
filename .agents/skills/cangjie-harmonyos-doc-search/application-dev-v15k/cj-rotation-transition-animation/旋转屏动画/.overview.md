# 旋转屏动画

This directory serves as a comprehensive technical resource for implementing screen rotation animations within the HarmonyOS ecosystem, specifically targeting developers utilizing the Cangjie language and ArkTS frameworks. It addresses the critical UX challenge of maintaining visual continuity during display orientation changes, covering two primary implementation approaches: system default layout switching and custom opacity-based transitions. The guides delve into synchronization of window and view sizes, reactive state management, and specific configuration requirements in `module.json5`. These resources are essential for application developers who aim to build polished, responsive interfaces that adapt fluidly to device rotation, ensuring a seamless and professional visual experience for the end-user.

## Detailed Description

### 旋转屏动画_2more.md 旋转屏动画_2more.md
This document serves as a technical guide for implementing screen rotation animations to achieve natural transitions during display orientation changes. It covers two main types: layout switching and opacity changes, with a detailed focus on the layout switching method. Key information includes that layout switching is the system default behavior, synchronizing window and view size and position transitions. Implementation is straightforward, requiring the configuration of "orientation" as "auto_rotation" in the module.json5 file, accompanied by a Cangjie code example. The document is intended for application developers using the Cangjie language and HarmonyOS framework who need to manage screen rotation effects.

### 透明度变化的旋转屏动画/
This directory provides comprehensive technical guides on implementing opacity-based animations during screen rotation for HarmonyOS applications. It covers the implementation details for both the Cangjie framework and ArkTS, focusing on how to manage UI component transitions smoothly when device orientation changes. Key concepts include `TransitionEffect.OPACITY`, window size change callbacks, `@StorageLink` for reactive state management, and necessary configuration in `module.json5`. These resources are designed for developers seeking to create polished, responsive user interfaces that handle orientation changes with professional fade-in and fade-out effects, ensuring a seamless visual experience for the end-user.
