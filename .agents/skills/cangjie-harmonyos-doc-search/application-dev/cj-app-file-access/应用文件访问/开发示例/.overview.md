# 开发示例

This directory serves as a practical resource for developers, offering detailed tutorials and code examples focused on file input/output (I/O) operations using the Cangjie language. It covers a broad spectrum of file management tasks, including reading and writing data via stream interfaces, listing directory contents with specific filters, and handling application file paths through AbilityContext. The examples illustrate critical technical concepts such as buffered data transfer, stream constraints, and file pointer management. Designed for application developers, this collection helps users implement efficient file creation, copying, and reading functionalities while adhering to best practices for resource management and data integrity.

## Detailed Description

### 以流的形式读写文件_2more.md
This technical tutorial demonstrates file input/output operations using the Cangjie language. It covers two primary tasks: reading and writing files via stream interfaces, and listing directory files with filters. The stream example details creating input and output streams, buffered data transfer using a loop, and highlights critical constraints such as the need to close streams and the lack of support for concurrent read/write. The file listing section illustrates using `ListFileOptions` to filter results by suffix, name, size, and modification time. This guide targets application developers implementing file management features.

### 开发示例_3more.md
This tutorial provides Cangjie code examples for performing file input and output operations within an application context. It covers obtaining application file paths via AbilityContext and demonstrates two primary scenarios: creating, writing to, and reading from a new file, and copying content from a source file to a destination file. Key takeaways include the usage of FileIo methods for opening, reading, and writing files, as well as managing file offsets and buffers. The document targets application developers needing to implement basic file management features, emphasizing the importance of handling file pointers correctly during read/write operations.
