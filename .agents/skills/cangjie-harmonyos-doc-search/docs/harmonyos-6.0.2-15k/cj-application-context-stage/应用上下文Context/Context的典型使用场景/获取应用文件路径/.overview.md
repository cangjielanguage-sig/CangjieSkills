# 获取应用文件路径

This directory provides a comprehensive technical overview of retrieving and managing application file paths within the HarmonyOS development environment. It thoroughly explains the distinctions between application-level paths obtained via `ApplicationContext` and module-level paths accessed through `AbilityStageContext` or `UIAbilityContext`. The content covers essential directory attributes such as `cacheDir`, `filesDir`, and `databaseDir`, illustrating how data persistence varies between the entire application lifecycle and specific HAP modules. Furthermore, it includes practical tutorials demonstrating file input/output operations using the Cangjie language, focusing on methods like `open`, `write`, and `read` within the application sandbox. This resource is specifically tailored for HarmonyOS developers seeking to implement robust local data storage, manage file access securely, and understand the nuances of context-based path retrieval in their applications.

## Detailed Description

### 获取应用文件路径_1.md 获取应用文件路径_1.md
This technical guide explains how to retrieve application file paths using the Context class in HarmonyOS development. It distinguishes between application-level paths obtained via ApplicationContext and module-level paths via AbilityStageContext, UIAbilityContext, and ExtensionContext. A detailed table compares specific directory attributes like cacheDir, filesDir, and databaseDir, showing how their paths differ based on the context type. Key takeaways include that application-level files persist until the entire app is uninstalled, whereas module-level files are deleted when the specific HAP is removed. This document is intended for HarmonyOS developers managing data storage and file access within the application sandbox. Keywords: Context, ApplicationContext, file paths, sandbox, HAP, Module.
