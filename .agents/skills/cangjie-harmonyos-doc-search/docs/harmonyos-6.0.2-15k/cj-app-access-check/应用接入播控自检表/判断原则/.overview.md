# 判断原则

This directory contains reference documentation defining the principles and standards for application integration, specifically focusing on AVSession and media playback features. It covers the criteria for determining integration requirements based on app type, distinguishing between mandatory and optional functionalities. The content includes compatibility matrices for playback controls, media information, and navigation behaviors across various categories like Music, Video, and Live apps. It is suitable for developers and quality assurance personnel responsible for ensuring compliance with system integration standards and verifying feature implementation.

## Detailed Description

### 判断原则_1.md 判断原则_1.md
This document serves as a reference guide defining the principles for determining application integration requirements based on app type and functionality. The content is structured into three specific rules: mandatory items must be connected for all relevant app types, optional items are required only if the application possesses the corresponding functionality, and items marked as not required should be excluded. Key takeaways include the distinction between mandatory and optional connections and the reliance on actual feature presence. This guide is intended for developers or quality assurance personnel responsible for verifying compliance with integration standards.

### 判断原则_2.md 判断原则_2.md
This document serves as a reference matrix defining AVSession integration requirements and feature compliance standards for various media application types. It categorizes requirements into Basic Playback Control, covering playback information like media covers, titles, and progress, as well as control functions such as play, pause, and track navigation. The table differentiates between "Complete Experience Optimization" and "Basic Access Requirements" for Music, Audiobook, and Video apps, while listing specific access requirements for Live, Browser, News, and VoIP categories. It targets developers seeking to ensure their media applications meet system integration standards for playback control and session management.

### 判断原则_3.md 判断原则_3.md
This document functions as a reference table or compatibility matrix outlining the support requirements for basic playback features. It categorizes features into "Playback Info" (such as subtitles, scrolling lyrics, and media source identifiers) and "Playback Control" (including favorites, loop modes, and fast forward/rewind). Additionally, it addresses navigation behaviors like clicking the playback card to jump to specific pages. The table uses specific symbols to denote support status across different contexts, likely for compliance checking. This resource is designed for developers or quality assurance personnel to verify feature implementation and adherence to platform standards.
