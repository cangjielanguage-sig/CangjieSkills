## 重命名媒体资源

重命名修改的是文件的 `PhotoAsset.displayName` 属性，即文件的显示名称，包含文件后缀。

调用[setTitle](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-settitlestring)重命名后再通过[applyChanges](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-applychangesmediachangerequest)更新到数据库中完成修改。

在重命名文件之前，需要先获取文件对象，可以通过[FetchResult](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#class-fetchresult)中的接口获取对应位置的文件。

**前提条件**

- 获取相册管理模块photoAccessHelper实例。
- [申请相册管理模块权限](./cj-photoAccessHelper-preparation.md#申请相册管理模块功能相关权限)'ohos.permission.WRITE_IMAGEVIDEO'和'ohos.permission.READ_IMAGEVIDEO'。

下面以将获取的图片资源中第一个文件重命名为例。

**开发步骤**

1. 建立检索条件，用于获取图片资源。
2. 调用[getAssets](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-getassetsfetchoptions-1)接口获取目标图片资源。
3. 调用[getFirstObject](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-getfirstobject)接口获取第一张图片，即要重命名的图片对象。
4. 调用[setTitle](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-settitlestring)接口将图片重命名为新的名字。
5. 调用[applyChanges](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-applychangesmediachangerequest)接口将修改的图片属性更新到数据库中完成修改。

```cangjie
import kit.MediaLibraryKit.*
import kit.ArkData.*
import ohos.base.BusinessException

let phAccessHelper = getPhotoAccessHelper(Global.context)

func example() {
    let predicates: DataSharePredicates = DataSharePredicates()
    let fetchOptions: FetchOptions = FetchOptions(
        fetchColumns: ['title'],
        predicates: predicates
    )
    let newTitle: String = 'newTestPhoto'
    try {
        let fetchResult: FetchResult<PhotoAsset> = phAccessHelper.getAssets(fetchOptions)
        let photoAsset: PhotoAsset = fetchResult.getFirstObject()
        let assetChangeRequest: MediaAssetChangeRequest = MediaAssetChangeRequest(photoAsset)
        assetChangeRequest.setTitle(newTitle)
        phAccessHelper.applyChanges(assetChangeRequest)
        fetchResult.close()
    } catch (e: BusinessException) {
        AppLog.error('getAssets failed with err: ${e.code}, ${e.message}')
    }
}
```
