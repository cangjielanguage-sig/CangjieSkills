# cj-universal-attribute-renderfit

本目录包含ArkUI框架中`renderFit`通用属性的API参考文档，专为使用仓颉语言进行应用开发的开发者设计。该文档深入解析了如何在组件宽高发生动画变化时，通过`renderFit`属性精确控制内容的绘制与填充模式，以提升用户界面的视觉流畅度。文档内容涵盖模块导入规范、renderFit函数的具体定义、`RenderFit`参数类型的详细枚举说明、返回值类型以及相关的系统能力和起始版本信息。该API目前处于Beta阶段，默认值为`RenderFit.TopLeft`，起始版本为22，非常适合致力于优化组件尺寸变化动画效果的开发者参考使用。
