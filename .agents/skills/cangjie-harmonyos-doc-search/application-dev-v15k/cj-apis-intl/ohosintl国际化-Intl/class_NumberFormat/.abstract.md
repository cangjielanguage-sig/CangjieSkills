This directory contains technical documentation for the `NumberFormat` class within the Cangjie LocalizationKit, specifically designed to handle internationalized number formatting. It provides comprehensive guides on initializing the formatter using system or specific locales, configuring options via `NumberOptions`, and converting `Float64` numbers into localized string representations. The content also covers methods for inspecting active configuration settings. Key concepts include locale handling, scientific notation, and various decimal styles. This documentation is intended for Cangjie developers utilizing the I18n system capability (version 19 APIs) to implement robust localization features in their applications.
