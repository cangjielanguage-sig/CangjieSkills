# 开发步骤

This directory serves as a comprehensive technical resource for developers utilizing the CryptoArchitectureKit within the Cangjie programming language. It focuses specifically on the development steps required to implement robust cryptographic security features, such as Message Authentication Codes (MAC) and HMAC operations. The content provides practical code examples illustrating how to manage data input effectively, whether dealing with small messages or large data streams requiring segmented processing. Key topics include symmetric key generation, algorithm initialization (specifically SHA256), and the retrieval of authentication codes. This guide is highly suitable for software engineers, security architects, and backend developers who need to integrate secure data integrity checks and verification mechanisms into their Cangjie applications, ensuring compliance with security standards and handling variable data volumes efficiently.

## Detailed Description

### 以分段传入数据获取消息认证码计算结果为例.md 以分段传入数据获取消息认证码计算结果为例
This document provides a Cangjie code example demonstrating how to calculate a Message Authentication Code (MAC) by processing data in segments. The content covers generating a symmetric key using the HMAC algorithm, initializing a MAC instance with SHA256, and performing iterative updates on data chunks. Key takeaways include the workflow of key conversion, the segmented update process for handling large data streams, and retrieving the final result. This tutorial targets developers using the CryptoArchitectureKit who need to implement secure data integrity checks or HMAC verification in their applications.

### 开发步骤_4more.md 开发步骤_4more
This development guide provides step-by-step instructions and code examples for implementing HMAC operations using the CryptoArchitectureKit in the Cangjie programming language. The document covers two primary methods for data input: passing the entire message in a single update call versus splitting the data into segments for multiple updates. Both methods yield identical results, allowing developers to choose based on data volume. Key steps include creating a Mac instance with SHA256, generating a symmetric key, initializing the object, and finalizing the calculation to retrieve the authentication code and its length. This tutorial targets software developers integrating cryptographic security features, specifically those working with the Cangjie language and needing to handle variable data sizes for message authentication.
