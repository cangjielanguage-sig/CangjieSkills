# MVVM模式

This directory focuses on the Model-View-ViewModel (MVVM) architecture pattern within the ArkUI framework and Cangjie language. It covers core concepts, layer separation principles, and state management techniques to help developers design scalable and maintainable applications. Key topics include the roles of Model, View, and ViewModel, component decoupling, and reactive programming using decorators like `@Observed` and `@Publish`. It is suitable for HarmonyOS developers and software architects looking to master architectural best practices, reduce code bloat, and implement modular project structures effectively.

## Detailed Description

### MVVM模式_3more.md MVVM模式_3more.md
This guide explains the MVVM architecture pattern and its implementation in ArkUI to help developers design scalable project structures. It covers the core concepts of Model, View, and ViewModel, and details the specific roles of View, ViewModel, and Model layers within the ArkUI framework. The document highlights that ArkUI's state variables function as the ViewModel, enabling automatic data-driven UI updates. It distinguishes between project-wide Model data and page-specific ViewModel data, while categorizing View components into page, business, and common types. Intended for developers familiar with State Management V1, this guide aims to simplify maintenance and iteration by promoting a separation of concerns.

### 架构核心原则.md 架构核心原则.md
This document defines essential architectural principles for software design, focusing on strict layer separation and component decoupling. It covers three main rules: prohibiting cross-layer access between View, ViewModel, and Model; preventing lower layers from accessing upper layer data directly; and restricting direct access between non-parent-child components. Key takeaways include that Views must use ViewModels to access Models, while Models must notify ViewModels of updates rather than manipulating UI. Additionally, components should only communicate with direct children or parents via events and subscriptions to ensure loose coupling. This reference guide targets software developers and architects designing modular, maintainable systems using MVVM patterns. Keywords: Architecture, MVVM, Decoupling, Component Design, Layer Separation.
