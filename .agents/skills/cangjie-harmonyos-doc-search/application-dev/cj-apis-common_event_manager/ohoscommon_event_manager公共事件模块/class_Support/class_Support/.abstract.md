This directory contains documentation for the `Support` class, primarily focusing on API references and constant definitions for system-level events within a software framework. It covers a wide array of event categories including system lifecycle, power management, wireless connectivity (WiFi, Bluetooth, NFC), storage, telephony, and user interface states. These resources are designed for developers who need to subscribe to, handle, and react to system broadcasts and hardware state changes. The documentation provides specific string identifiers and constants necessary for implementing responsive application features.
