# 使用场景

本目录汇集了ArkUI框架中@Prop装饰器的多种使用场景与状态管理机制。内容涵盖了从简单数据类型到复杂嵌套对象的父子组件同步，重点讲解了单向数据流、本地拷贝特性以及@Observed装饰器在深层嵌套中的应用。文档通过Cangjie代码示例，详细阐述了数据流向、Diff算法行为及UI更新逻辑。适合具备ArkUI基础的开发者深入学习组件状态管理与数据传递的最佳实践。

## 详细描述

### Prop嵌套场景_dab3c5ad.md
本文档旨在演示ArkUI框架中@Prop装饰器在嵌套对象场景下的使用方法及状态同步机制。文档通过Cangjie代码示例，展示了包含Father和Son嵌套类的数据结构，以及父组件EntryView与子组件Child之间的数据传递。核心要点指出，在嵌套场景下，每一层类都必须使用@Observed装饰，且子组件接收数据时必须使用@Prop，才能确保深层嵌套属性的变化能被感知并触发UI更新。该文档适合具备ArkUI基础的开发者学习复杂对象的状态管理。

### 从父组件中的State类对象属性到_2more_42ba8fa5.md
这份文档旨在演示ArkUI中父组件@State与子组件@Prop之间的状态同步机制，重点讲解类对象和数组项的同步。主要内容包括两个示例：一是利用@Observed装饰类，实现父组件@State类对象属性到子组件@Prop的同步；二是使用ObservedArrayList管理数组，实现数组项到@Prop class类型的同步。关键信息在于@Observed和@Publish宏的使用，它们通过代理对象检测引用类型内部属性变化并通知@Prop更新，确保UI响应。文档适合学习ArkUI状态管理的开发者，需具备基础组件开发知识。

### 父组件State到子组件Prop简单数据类型同步.md
本文档旨在演示ArkUI中父组件@State与子组件@Prop之间简单数据类型的单向同步机制。文档通过倒计时游戏代码示例，详细讲解了数据流向：父组件状态变化会重置并同步更新子组件属性，而子组件属性的修改仅限于本地，不会反向同步给父组件。关键要点包括初始化过程、父组件更新触发子组件重渲染、以及子组件本地修改被父组件覆盖的行为。这是一份面向ArkUI开发者的教程，帮助理解单向数据流和状态管理基础。

### 父组件State数组项到子组件Prop简单数据类型同步.md
本文档旨在阐述ArkUI中父组件@State数组项与子组件@Prop简单数据类型的同步机制。文档通过代码示例演示了数据传递，重点分析了单向数据流、本地拷贝特性及ForEach的Diff算法行为。关键信息指出，@Prop为本地拷贝，子组件修改不回传父组件；父组件替换数组时，Diff算法会复用相同值的组件实例，保留局部修改状态。这是一份面向ArkUI开发者的技术指南，帮助理解状态管理和组件更新逻辑。
