This directory contains API reference documentation for the `ohos.labels` package within the Cangjie programming language ecosystem. It focuses on defining annotation labels and permission structures used for system APIs, specifically targeting HarmonyOS development. Key components include the `APILevel` class for API metadata, logical permission classes (`PermissionAnd`, `PermissionOr`), and the `PermissionValue` interface for managing permission sets. The documentation covers bitwise operations, system capabilities, and atomic service support. This content is intended for system developers, framework engineers, and software developers working on access control or API definition in Cangjie.
