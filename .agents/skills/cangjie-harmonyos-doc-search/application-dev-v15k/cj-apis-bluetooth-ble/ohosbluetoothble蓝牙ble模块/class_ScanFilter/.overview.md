# class_ScanFilter

This directory provides a comprehensive collection of API reference documentation for the `ScanFilter` class, specifically designed for use within the Cangjie programming language ecosystem. It focuses on the technical specifications required to define parameters for filtering Bluetooth Low Energy (BLE) device scans, enabling developers to precisely control device discovery processes. The documentation covers the class structure, detailing properties such as `deviceId`, `name`, `serviceUuid`, and `manufactureId`, along with their corresponding data masks. It highlights that these properties utilize nullable types like String and Byte arrays and support both read and write operations. This resource is suitable for software developers and engineers implementing Bluetooth scanning functionality, requiring the `SystemCapability.Communication.Bluetooth.Core` system capability starting from API version 19.
