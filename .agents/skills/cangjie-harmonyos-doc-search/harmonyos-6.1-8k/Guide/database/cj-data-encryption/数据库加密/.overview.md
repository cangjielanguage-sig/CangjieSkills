# 数据库加密

本目录汇集了关于ArkData框架中数据库加密的技术文档，旨在指导开发者如何通过配置参数来保障数据安全。内容涵盖了关系型数据库与键值型数据库的加密实现，重点介绍了如何利用StoreConfig和KVOptions设置加密属性，并结合安全级别（如S3）进行管理。文档包含基于仓颉（Cangjie）语言的代码示例，详细说明了获取UIAbility上下文及调用相关接口（如getRdbStore）的步骤。适用于希望提升应用数据存储安全性和保密性的应用开发人员。

## 详细说明

### 关系型数据库加密_fcd7d428.md
本文档旨在指导开发者如何在ArkData框架中为关系型数据库配置加密功能。主要内容包括获取UIAbility上下文以及通过StoreConfig设置数据库加密参数。核心要点是在StoreConfig中将encrypt属性设为true，并结合安全级别（如S3）调用getRdbStore接口来实现数据库加密存储。适用于使用仓颉语言进行应用开发，且需要保障数据库数据安全性的开发人员。

### 数据库加密_3more_82b82fab.md
本文档旨在指导开发者使用ArkData框架实现数据库加密，以增强数据存储的安全性和保密性。主要涵盖数据库加密的场景介绍及键值型数据库加密的具体实现步骤。关键信息包括加密属性在创建时不可变更，通过KVOptions中的encrypt参数设为true启用加密，并提供了获取Context及配置加密的Cangjie代码示例。该文档属于技术教程，面向使用ArkData框架的应用开发者。
