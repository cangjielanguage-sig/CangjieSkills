This directory contains comprehensive API reference documentation for the `CustomDialogOptions` class within the Cangjie ArkUI framework. It is designed to assist developers in configuring and customizing dialog boxes with high precision. The content covers essential aspects such as class structure, constructor parameters, and property definitions for styling, including background colors, border attributes, dimensions, and shadow effects. Key topics include the inheritance from `BaseDialogOptions`, the builder property for custom content, and specific visual properties like background blur styles. Targeted at software developers using the Cangjie language, this documentation ensures the implementation of flexible, visually customized dialog interfaces that adhere to system capability standards starting from API version 22.
