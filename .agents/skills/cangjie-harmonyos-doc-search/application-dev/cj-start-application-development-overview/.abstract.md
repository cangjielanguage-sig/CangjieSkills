This directory acts as a definitive navigation guide and educational resource for developers engaged in building applications using the OpenHarmony SDK, specifically utilizing the Cangjie programming language. It provides a structured approach to the development lifecycle, encompassing everything from initial setup and basic methods to complex system integration. The guide is divided into four critical sections: Getting Started, Development, Tools, and API Reference. It details SDK capabilities through various Kits, such as Application Framework, System, Media, and Graphics services. Furthermore, it highlights DevEco Studio as the recommended integrated development environment. This resource is tailored for developers who aim to master OpenHarmony fundamentals and efficiently leverage open capabilities and full API documentation to create robust applications.
