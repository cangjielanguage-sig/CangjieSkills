# ohosadvertisingadvertising广告服务框架

This directory contains the API reference documentation for the HarmonyOS advertising service framework (AdsKit) specifically designed for the Cangjie programming language. It covers the core components required to integrate advertising into applications, including ad loading, display configuration, request parameters, and event listeners. The documentation details classes for managing ad slots, handling callbacks, and configuring ad options for compliance and user experience. It is suitable for software developers and engineers working within the HarmonyOS ecosystem who need to implement monetization features using Cangjie syntax and asynchronous event handling patterns.

## Quick Navigation

**What do you want to do?**

## Detailed Description

### class_AdInteractionListene_2more.md class_AdInteractionListene_2more.md
This API reference defines listener classes for handling advertising events. It details the `AdInteractionListener` class for monitoring ad status changes and the `AdLoadListener` class for managing single ad slot request outcomes. Key information includes constructors and read-only properties utilizing lambda functions to handle callbacks for status updates, successful ad loading, and request failures with error codes.

### class_AdRequestParams.md class_AdRequestParams.md
This document serves as an API reference for the `AdRequestParams` class, detailing configuration parameters used in ad requests. It covers the class constructor and read-only properties, including the mandatory `adId`, optional `adType` (supporting splash, native, reward, etc.), dimensions, count, and keywords. It highlights integer mappings for ad types and the usage of named parameters for instantiation.

### class_Advertisement.md class_Advertisement.md
This API reference defines the data structure for requested ad content via the `Advertisement` class. It details the constructor and read-only properties such as `adType`, `uniqueId`, `rewarded`, `shown`, `clicked`, and `rewardVerifyConfig`. It emphasizes that all properties are immutable once initialized and targets developers managing ad data objects within the framework.

### class_MultiSlotsAdLoadListener.md class_MultiSlotsAdLoadListener.md
This documentation covers the `MultiSlotsAdLoadListener` class, designed for handling callbacks during multi-slot advertising requests. It details the constructor and properties for success callbacks, which return a HashMap mapping ad slot IDs to arrays of `Advertisement` objects, and failure callbacks, which provide error codes and messages.

### class_Parameter_2more.md class_Parameter_2more.md
This reference details the `Parameter` class and `ValueType` enum used in advertising modules. It covers the `Parameter` constructor accepting a string key and `ValueType` value, and the enumeration supporting INT, BOOL, and STRING types. It illustrates how to instantiate these objects and pass them as extra attributes in `AdRequestParams`.

### ohosadvertisingadvertising_5more.md ohosadvertisingadvertising_5more.md
This API reference details the HarmonyOS advertising service framework functions: `getAdRequestBody` for generating ad request data and `showAd` for displaying full-screen advertisements. It includes parameter definitions, return values, specific error codes, and Cangjie code examples demonstrating implementation within a template project context.

### class_AdDisplayOptions/
This directory contains API reference for the `AdDisplayOptions` class, designed to configure ad display behaviors. It covers managing video audio focus, muting options, mobile data usage reminders, and custom data for server-side reward verification. Additionally, it explains how to control ad refresh intervals through extra attributes.

### class_AdLoader/
This directory provides documentation for the `AdLoader` class, a core component for facilitating ad loading. It covers the lifecycle from initialization using `StageContext` to executing single and multi-slot ad loading functions. It includes details on configuring `AdRequestParams` and `AdOptions`, setting up listeners, and managing errors.

### class_AdOptions/
This directory contains API reference for the `AdOptions` class, used for configuring advertising request instances. Key topics include the constructor, child protection tags for COPPA compliance, ad content classification ratings (W, PI, J, A), toggles for non-personalized ads, and custom attributes for ad duration and traffic settings.
