# 前端页面调用应用侧函数

This directory focuses on the technical implementation of enabling frontend web pages to invoke application-side native functions within the HarmonyOS ecosystem. It covers essential techniques for hybrid app development, specifically detailing how to use Web components to bridge JavaScript and native code. The content includes registration methods, memory management, and security configurations using both the Cangjie language and ArkTS. It is suitable for HarmonyOS developers looking to facilitate secure and efficient communication between web content and native application logic using ArkUI and ArkWeb frameworks.

## Detailed Description

### 前端页面调用应用侧函数_1.md 前端页面调用应用侧函数_1.md
This technical guide explains how to enable frontend web pages to invoke application-side functions using Web components in HarmonyOS development. It covers two primary registration methods: using javaScriptProxy() during component initialization and registerJavaScriptProxy() after initialization. Key information includes the necessity of pairing registerJavaScriptProxy() with deleteJavaScriptRegister() to prevent memory leaks. The document provides Cangjie code examples demonstrating how to map native functions to frontend object names. Targeted at HarmonyOS developers using the Cangjie language and ArkUI framework, this guide facilitates hybrid app interaction capabilities.

### 前端页面调用应用侧函数_2.md 前端页面调用应用侧函数_2.md
This document provides a technical guide on enabling frontend webpages to invoke application-side functions within the ArkWeb framework. It details the implementation process using ArkTS to register and delete JavaScript proxies via webController, alongside a comprehensive JSON schema for configuring URL-based security permissions at both object and method levels. The content includes HTML and JavaScript examples demonstrating how to call these registered native functions. Key information highlights the requirement to call refresh() after registration and the specific structure of the permission parameter. This guide is intended for application developers working with ArkUI and ArkWeb components who need to facilitate secure interaction between web content and native application logic.
