# 基础类型定义

This directory defines the fundamental data structures and configuration classes required for implementing Flexbox layouts within the ArkUI framework using the Cangjie language. It comprehensively covers essential parameters for controlling layout direction, alignment, wrapping behavior, and spacing strategies for child components. Key components include `FlexParams`, `FlexSpaceOptions`, and `FlexOptions`. These definitions are crucial for developers and system architects aiming to build responsive and sophisticated user interfaces for HarmonyOS applications. By providing precise control over main and cross-axis properties, this documentation serves as a technical foundation for managing complex UI layouts programmatically.

## Detailed Description

### class_FlexParams.md class_FlexParams.md
This API reference document details the FlexParams class in Cangjie, used to configure the layout and alignment of child components within a Flex container in ArkUI. The content outlines the class constructor and five key public properties: direction, wrap, justifyContent, alignItems, and alignContent. Key information includes default values such as FlexDirection.Row and FlexAlign.Start, along with specific constraints like alignContent only functioning when wrapping is enabled. Intended for ArkUI developers, this guide requires a basic understanding of Flexbox layout concepts to effectively manage main and cross-axis alignment.

### class_FlexSpaceOptions.md class_FlexSpaceOptions.md
This API reference document details the FlexSpaceOptions class used to configure spacing for child components within a Flex container in the Cangjie language. The documentation covers the class definition, two public properties (mainSpace and crossSpace), and the class constructor. Key information includes that both properties are of type Length and control spacing along the main and cross axes respectively. The constructor accepts these as named parameters with a default value of 0.px. Intended for UI developers using the ArkUI framework, this document provides the necessary syntax and parameters to programmatically manage layout spacing.

### class_FlexOptions/
This directory provides comprehensive API reference documentation for the `FlexOptions` class in the Cangjie language, a critical component for configuring Flex container layouts within the ArkUI framework. It is designed to assist developers in building sophisticated HarmonyOS user interfaces by offering detailed technical specifications on layout properties. The content covers the constructor's signature, system capabilities, and a thorough explanation of parameters such as direction, wrap, justifyContent, alignItems, alignContent, and space. Furthermore, it addresses specific behavioral constraints, such as the requirement for wrapping to enable `alignContent` and the invalidation of `space` under certain justification modes. This documentation is highly suitable for developers and system architects who require precise control over component alignment and spacing strategies in their applications.
