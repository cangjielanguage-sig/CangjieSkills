# 加载本地页面

This directory serves as a comprehensive technical guide for loading local pages within HarmonyOS applications, addressing specific development needs for both Cangjie and ArkTS developers. It thoroughly covers the intricacies of rendering local HTML content inside a Web component, including resource loading from `rawfile` directories and managing application sandbox paths. Furthermore, it details the application lifecycle management in ArkTS, specifically focusing on the `onWindowStageCreate` method to programmatically set the initial UI. Key concepts include `WebviewController`, `GlobalContext`, file access permissions, and `WindowStage` functionality. These documents are ideal for developers seeking to implement offline web rendering or control app initialization sequences effectively.

## Detailed Description

The following documents provide in-depth technical instructions and code examples for implementing local page loading in HarmonyOS.

### 加载本地页面_1.md

This tutorial demonstrates methods for loading local HTML pages within a Web component using the Cangjie language. It covers two primary approaches: loading files directly from the application's resources/rawfile directory and accessing files located in the application's sandbox path. Key information includes using the @rawfile resource reference, utilizing WebviewController.loadUrl for dynamic loading, and managing sandbox paths via a GlobalContext singleton. The document also details enabling fileAccess permissions and referencing local CSS styles. Targeted at HarmonyOS developers, this guide provides practical code examples for implementing local web content rendering in ArkUI applications.

### 加载本地页面_2.md

This document demonstrates how to programmatically load a local page within a HarmonyOS application using the ArkTS language. The content focuses on the application lifecycle, specifically the `onWindowStageCreate` method, and the `WindowStage` class functionality. Key information includes the code snippet showing how to override the window stage creation event to invoke `windowStage.loadContent("EntryView")`, which sets the initial user interface. This technical reference is designed for HarmonyOS developers seeking to implement app initialization and navigation logic, requiring prior knowledge of ArkTS syntax and application lifecycle management.
