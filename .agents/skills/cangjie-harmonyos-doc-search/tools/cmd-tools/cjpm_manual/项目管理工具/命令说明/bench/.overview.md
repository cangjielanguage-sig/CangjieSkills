# bench

本目录包含关于 cjpm 包管理器中 `bench` 子命令的文档，主要介绍如何执行性能测试和基准测试。内容涵盖了基本用法、命令行参数选项以及与 mock 功能的交互限制。核心关键词包括 cjpm bench、性能测试、@Bench 宏、参数配置和 mock 限制。这些文档适合仓颉语言开发者，特别是需要评估代码性能、配置测试环境或理解基准测试约束的用户。

## 详细描述

### bench_1.md bench_1.md
本文档介绍了 cjpm 工具中 bench 子命令的用途与使用方法，用于执行性能测试并输出结果。文档涵盖了命令定义、编译产物路径、@Bench 宏标注、路径指定方式及执行前提。关键信息包括：bench 命令需项目构建成功，支持指定单包或多包路径，默认执行模块级测试，输出包含中位数和误差等性能指标。文档还提供了输入输出示例。这是一份面向仓颉语言开发者的参考文档，适用于需要评估代码性能的场景，要求用户具备基本的构建和单元测试知识。

### bench_2.md bench_2.md
本文档详细介绍了 `cjpm bench` 命令的参数选项，用于执行性能测试和基准测试。内容涵盖编译配置（并发数、增量编译）、执行控制（仅编译、仅运行）、测试过滤（子集匹配、标签筛选）以及报告生成（格式、路径、基线对比）。关键功能包括支持交叉编译、通过 `--filter` 和 `@Tag` 进行精细化的测试筛选，以及生成 CSV 格式的性能报告并与基线数据进行对比。这是一份面向开发者的参考文档，旨在帮助用户在 `cjpm` 构建环境中配置和运行性能测试。

### bench_3.md bench_3.md
该文档旨在说明 cjpm bench 命令对 mock 功能的支持限制及其运行时行为。文档主要涵盖了基准测试与模拟功能的交互，特别是为了防止编译器开销而移除完整 mock 支持的设计决策。关键信息指出，虽然编译器允许包含 mock 的代码通过编译以便与常规测试一起构建，但实际运行使用 mock 的基准测试会抛出运行时异常，因此用户应避免此类操作。本文档属于技术参考或使用指南，面向使用仓颉包管理器进行性能优化的开发者，旨在帮助其理解基准测试环境下的特定约束。关键词包括 cjpm bench、mock、基准测试、运行时异常和编译器开销。
