# enum_General

This directory serves as a comprehensive repository for API reference documentation related to the `General` enum within the Cangjie framework's Settings Core module. It is dedicated to defining system configuration constants and data items that are crucial for managing a wide variety of device general settings. The content covers critical aspects such as geolocation origins, airplane mode status, accessibility features, device naming, and developer options. These resources are meticulously designed for system developers and integrators who need to programmatically query or modify device behavior and configuration states. By outlining specific boolean or integer values and data representation methods, the documentation ensures seamless functionality and compatibility for system version 19 and above, making it an essential tool for robust device management and system integration.
