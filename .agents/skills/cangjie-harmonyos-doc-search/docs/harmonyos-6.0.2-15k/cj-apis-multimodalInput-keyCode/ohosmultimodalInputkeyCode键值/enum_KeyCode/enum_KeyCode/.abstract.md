This directory contains API documentation and reference lists for the KeyCode enumeration, which maps physical keyboard and hardware keys to programmatic constants. It covers a wide range of input types, including standard alphanumeric keys, media controls, system functions, international language inputs, and game controller buttons. The documents detail system capabilities, version compatibility, and interface implementations like Equatable and ToString. This resource is suitable for software developers, system engineers, and UI framework designers working on input event handling, driver implementation, or user interface logic in environments such as Cangjie or Android/Linux-based systems.
