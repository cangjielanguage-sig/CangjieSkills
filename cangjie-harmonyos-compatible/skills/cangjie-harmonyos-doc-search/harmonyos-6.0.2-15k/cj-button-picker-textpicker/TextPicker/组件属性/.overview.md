# 组件属性

This directory provides comprehensive API reference documentation for configuring Picker component properties within the ArkUI framework, specifically utilizing the Cangjie language. It serves as a technical resource for developers aiming to manipulate the behavior, layout, and aesthetics of Picker controls. The documentation covers a wide array of configuration options, including scroll behavior management (such as enabling loop scrolling), layout adjustments (item heights, dividers, and gradient effects), and selection logic (setting default indices for single or multi-column pickers). Furthermore, it provides specific instructions on text styling for different picker states. This content is suitable for HarmonyOS developers and UI engineers who require detailed parameter specifications, default values, and version requirements to effectively implement and customize Picker components in their applications.

### func_canLoopBool_8more.md func_canLoopBool_8more.md
This document serves as API reference documentation for configuring Picker component properties within the ArkUI framework using the Cangjie language. It details specific functions for controlling scroll behavior, visual styling, and selection logic. Main topics include enabling loop scrolling via canLoop, setting item heights using overloaded defaultPickerItemHeight methods, customizing divider styles with divider, and managing fade effects via gradientHeight. Additionally, it explains how to set default selected indices for both single and multi-column pickers using selectedIndex. Key information highlights parameter types, default values, and version requirements. This technical guide is intended for developers familiar with Cangjie and ArkUI who need to implement or customize Picker components in their applications.

### func_selectedTextStylePick_2more.md func_selectedTextStylePick_2more.md
This API reference document details methods for customizing text appearance within a Picker component in the Cangjie ArkUI framework. It covers two primary functions: selectedTextStyle for styling the currently selected item and textStyle for the remaining non-boundary options. Both functions accept a PickerTextStyle parameter to define color, font size, and weight, returning the component instance for chaining. The documentation specifies default values and system capabilities, targeting HarmonyOS developers who need to fine-tune the visual presentation of picker controls in their applications.
