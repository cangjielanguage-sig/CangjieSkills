This directory contains documentation and resources for the Span component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of inline text content, including component creation, styling attributes, and visual effects like shadows and backgrounds. The content includes API references, fundamental type definitions, and practical code examples for text decoration, font management, and layout adjustments. It is suitable for developers building HarmonyOS applications who need to customize text appearance and behavior using Cangjie syntax.
