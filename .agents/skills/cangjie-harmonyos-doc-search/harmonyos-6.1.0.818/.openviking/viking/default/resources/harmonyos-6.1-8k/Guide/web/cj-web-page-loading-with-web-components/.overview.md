# cj-web-page-loading-with-web-components

This directory serves as a comprehensive guide for HarmonyOS developers focusing on web content integration using the Web component. It specifically addresses the implementation details required to load and display various web resources, including remote network pages, raw HTML text strings, and local HTML files stored within the application. The documentation highlights critical technical areas such as configuring the Web component, managing the `WebviewController` for interaction control, setting up necessary network permissions, and utilizing data URLs. Furthermore, it explains path handling for both rawfile and sandbox directories. With code samples provided in both Cangjie and ArkTS, this resource is tailored for developers aiming to build rich hybrid applications or dynamic web-based interfaces on the HarmonyOS platform.

## Detailed Description

### 使用Web组件加载页面/

This subdirectory acts as a technical manual for HarmonyOS developers, focusing on the versatile capabilities of the Web component. It comprehensively covers the methodologies for integrating web-based content into native applications, ranging from simple network page loading to more complex scenarios like rendering HTML text strings and accessing local HTML files. Key technical discussions include the proper configuration of the Web component, the utilization of `WebviewController` for advanced control, and the specific network permissions required for secure data access. The guide also delves into the practical application of data URL formats and the nuances of file path management, distinguishing between rawfile assets and sandbox storage. By providing side-by-side code examples in Cangjie and ArkTS, this documentation ensures that developers can easily implement features such as web content display, seamless page transitions, and local HTML rendering, thereby enhancing the interactivity and functionality of their HarmonyOS applications.
