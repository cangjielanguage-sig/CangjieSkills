# ohoscomponent_utilsComponentUtils

This directory contains API reference documentation for the `ohos.component_utils` module within the HarmonyOS ArkUI framework, specifically designed for the Cangjie programming language. It covers utility classes and data structures used to retrieve and manipulate UI component geometry, transformations, and layout states. Key topics include component information encapsulation, coordinate offsets, and transformation results such as rotation, scaling, and translation. This documentation is suitable for software developers and UI engineers building advanced interfaces who need programmatic access to component layout data and spatial properties.

## Detailed Description

### class_ComponentInfo.md
This document serves as API reference documentation for the Cangjie ComponentInfo class, which encapsulates geometric and transformation data for UI component instances. The content details the class structure, specifically defining read-only properties such as size, localOffset, windowOffset, screenOffset, translate, scale, rotate, and transform. It also provides a comprehensive parameter table for the class constructor. Key information includes that all properties are immutable and offer spatial context from relative parent positioning to screen coordinates and affine matrix transformations. This reference is intended for Cangjie developers utilizing the ArkUI framework who need to access component layout and transformation states, specifically targeting system capability SystemCapability.ArkUI.ArkUI.Full.

### class_Offset.md
This document provides API reference documentation for the Cangjie language's Offset class, designed to represent coordinate information within the ArkUI framework. The content details the class structure, focusing on its two read-only public properties, x and y, both of which are Float32 types representing pixel coordinates. It explains the constructor that initializes these mandatory parameters. Key takeaways include that the class is immutable regarding its coordinates and is available from API version 19. This reference guide targets developers working on ArkUI interfaces who need to define or manipulate 2D positioning data.

### class_RotateResult.md
This document serves as API reference documentation for the Cangjie language's RotateResult class, which encapsulates component rotation data within the ArkUI framework. The content details the class constructor and six read-only properties: x, y, z (rotation axis vectors), centerX, centerY (transform center), and angle. Key information includes that all properties are Float32 types, initialized via the constructor to define the rotation axis, center point, and angle in pixels. This reference is intended for software developers building UI applications using the ArkUI system, specifically those implementing 2D or 3D geometric transformations.

This document provides API reference documentation for the ScaleResult class in the Cangjie language, used to encapsulate component scaling information within the ArkUI framework. It also outlines the constructor parameters required to instantiate the object. Key takeaways include the data types (Float32) and the read-only nature of the fields. This guide targets developers implementing geometric transformations in ArkUI applications, requiring knowledge of Cangjie syntax and UI layout concepts.
