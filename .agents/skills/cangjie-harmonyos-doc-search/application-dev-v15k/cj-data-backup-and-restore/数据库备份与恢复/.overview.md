# 数据库备份与恢复

This directory focuses on database backup and recovery strategies within the ArkData framework. It covers essential techniques for ensuring data integrity, business continuity, and transaction safety during system failures or critical operations. Key topics include manual and automatic backup methods for relational databases, data restoration procedures, and specific implementation scenarios for Key-Value (KV) databases. The content is tailored for application developers using the Cangjie language who need to implement robust data protection mechanisms, manage database exceptions, and handle storage lifecycle effectively.

## Detailed Description

### 关系型数据库备份.md 关系型数据库备份.md
This document serves as a technical guide for implementing backup strategies for relational databases within the ArkData framework to ensure data recovery and business continuity. It covers the distinction between manual and automatic backup methods, providing a detailed tutorial on the manual approach. Key information includes the usage of the backup API, demonstrated through a Cangjie code example that shows how to initialize an RdbStore, configure security levels, and specify backup file paths. The document targets application developers responsible for data integrity, requiring knowledge of Cangjie and database management to effectively utilize these backup capabilities against unexpected exceptions.

### 关系型数据库数据恢复.md 关系型数据库数据恢复.md
This technical guide explains the procedure for restoring relational database data from manual backups following a database rebuild and exception handling. It details the three-step recovery process: identifying database exceptions via specific error codes, closing all active result sets, and invoking the restore interface. Key takeaways include the necessity of handling error code 14800011, ensuring all ResultSets are closed to prevent conflicts, and correctly specifying the backup file path when calling the restore method. Targeted at developers using the Cangjie language, this document provides code examples for implementing robust data recovery mechanisms in applications.
