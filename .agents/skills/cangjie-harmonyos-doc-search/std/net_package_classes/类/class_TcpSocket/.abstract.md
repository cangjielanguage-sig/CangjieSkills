This directory contains comprehensive API reference documentation for the `TcpSocket` class in the Cangjie programming language. It covers the implementation of TCP client connections, detailing class constructors, inheritance from `StreamingSocket`, and various mutable properties for socket configuration. Key topics include network behavior control (Nagle's algorithm, keep-alive), socket option manipulation, data transmission (read/write), and platform-specific logic. The documentation is designed for Cangjie developers and network engineers who require fine-grained control over socket lifecycles, error handling, and low-level network communication protocols.
