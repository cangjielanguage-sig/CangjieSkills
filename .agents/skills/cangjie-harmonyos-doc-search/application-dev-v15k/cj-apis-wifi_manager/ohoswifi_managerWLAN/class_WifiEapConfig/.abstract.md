This directory contains essential API reference documentation for the `WifiEapConfig` class in the Cangjie programming language. It focuses on the configuration parameters required to establish secure WiFi connections using the Extensible Authentication Protocol (EAP). The content covers a wide range of technical details, including EAP methods, phase 2 authentication, user identities, passwords, and certificate management. It is designed for software developers and system integrators implementing enterprise-grade WiFi security, supporting both SIM-based and certificate-based authentication mechanisms. The documentation also addresses system capability definitions, version 19 compatibility, and specific validation rules for protocols like EAP_TLS and EAP_PEAP, providing a complete guide for authenticated network connections.
