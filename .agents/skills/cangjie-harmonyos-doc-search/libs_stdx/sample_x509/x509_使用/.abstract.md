This directory contains technical documentation and tutorials focused on the implementation and handling of X.509 digital certificates within the Cangjie programming language. It covers essential cryptographic operations including the generation of certificates, creation of Certificate Signing Requests (CSRs), parsing of PEM-encoded files, and the verification of certificate chains. Key topics include defining certificate attributes, managing validity periods, and validating trust chains using the `stdx.crypto.x509` library. This resource is specifically designed for Cangjie developers who need to integrate robust security features, such as TLS/SSL components or digital signing, into their applications using the standard crypto library.
