This directory serves as a comprehensive repository for API documentation regarding deprecated interfaces within the Cangjie programming language, with a specific focus on sorting and collection manipulation utilities. It encompasses detailed technical specifications for legacy sorting mechanisms, including both standard comparison-based sorting and custom comparator-driven sorting. The documentation highlights critical deprecation notices and provides necessary guidance for developers to transition to modern API standards. Key topics include Array type extensions and stable sorting parameters. This resource is primarily suitable for Cangjie software engineers, system architects, and maintenance teams responsible for preserving legacy codebases or refactoring older implementations to ensure compatibility with the latest language specifications and avoid breaking changes in future updates.
