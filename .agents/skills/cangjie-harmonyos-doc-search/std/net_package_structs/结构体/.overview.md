# 结构体

This directory provides comprehensive API reference documentation for core structs within the Cangjie network programming package. It covers essential components for socket communication, including address families, socket types, protocol definitions, and configuration options like keep-alive settings. The documentation details static constants, properties, constructors, and platform-specific behaviors for low-level network control. Designed for Cangjie developers and systems engineers, these resources offer the technical details needed to implement robust, cross-platform network applications and manage socket behaviors effectively.

### struct_OptionLevel.md struct_OptionLevel.md

Key information includes the specific integer values assigned to each protocol level, with the notable exception of the SOCKET constant, which adapts its value based on the operating system (macOS, Windows, or others). This documentation is intended for developers implementing network communication in Cangjie who need to configure socket behaviors at various protocol layers. Keywords: Cangjie, socket options, network programming, API reference, protocol levels.

### struct_SocketKeepAliveConfig.md struct_SocketKeepAliveConfig.md
This document serves as API reference documentation for the SocketKeepAliveConfig struct in the Cangjie programming language, designed to configure TCP KeepAlive settings for network sockets. It details the struct's properties including idle time, interval duration, and probe count, alongside its constructor, string conversion method, and equality operators. The struct implements ToString and Equatable interfaces. The constructor provides default values (45 seconds idle, 5 seconds interval, 5 probes) and throws exceptions for negative durations. Targeted at Cangjie developers working with network programming, this reference helps manage socket connection health and lifecycle through specific timeout and retry configurations.
