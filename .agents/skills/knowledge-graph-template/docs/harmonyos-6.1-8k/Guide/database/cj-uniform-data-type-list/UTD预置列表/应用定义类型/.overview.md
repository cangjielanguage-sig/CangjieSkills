### 应用定义类型_1.md
本文档旨在定义和说明应用定义类型的概念、标识规范及其在系统中的维护方式。主要涵盖应用定义类型的定义、数据交互依赖机制、UTD-ID标识符格式规范（如com.company-name.xxx）以及系统预定义的类型列表。核心要点在于此类类型由具体应用或组织维护，数据交互需特定应用识别，且遵循特定的UTD-ID命名规则。面向系统开发人员或架构师，用于理解自定义类型的注册与识别机制，属于技术参考文档。
