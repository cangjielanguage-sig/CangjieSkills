This directory serves as a comprehensive educational resource for developers utilizing the Cangjie programming language, specifically targeting the complexities of file system interactions and input/output (I/O) operations. It provides a detailed, practical tutorial that guides users through the essential `std.fs` and `std.io` libraries, which are critical for any application requiring data persistence or configuration management. The curriculum covers a broad spectrum of standard file operations, ranging from basic creation and deletion to more advanced tasks like reading, writing, seeking, and properly closing files. Beyond standard operations, the directory explores the use of static utility functions that simplify common coding tasks. It also provides deep insights into file access modes—such as Write, Append, and ReadWrite—and the technical manipulation of file pointers and byte arrays. This collection is perfectly suited for Cangjie developers who are looking to master file system manipulation through executable code samples and hands-on practice.
