# HTTP数据请求

This directory provides comprehensive technical documentation for implementing HTTP data requests using the Cangjie language and NetworkKit. It covers standard request lifecycles, streaming interfaces, and security measures like certificate pinning. Key topics include creating `HttpRequest` objects, configuring options, handling events, and managing SSL certificates. The resources are designed for application developers and software engineers working within the HarmonyOS/OpenHarmony ecosystem who need to integrate robust network communication capabilities into their applications.

### request接口开发步骤.md request接口开发步骤.md

### requestInStream接口开发步骤
This directory contains essential technical documentation and tutorials for developing the `requestInStream` interface using the Cangjie programming language. It covers the complete implementation lifecycle of HTTP streaming requests, which is crucial for applications that need to process data in real-time. Key topics include importing the NetworkKit module, creating and configuring `HttpRequest` objects, subscribing to stream events (headers, data, progress), and managing asynchronous callbacks. The documentation also delves into error handling, SSL certificate configuration, and request timeouts. These resources are designed for application developers and software engineers who aim to integrate efficient, high-performance network request capabilities and handle streaming responses effectively within their Cangjie applications.

### 证书锁定
This directory focuses on Certificate Pinning, a vital security technique used to secure HTTPS connections by strictly limiting them to specific, developer-defined certificates or public keys. It addresses the need to prevent Man-in-the-Middle (MitM) attacks and ensures robust network communication protocols. The content covers the complete workflow, from understanding the hierarchical JSON configuration structure—encompassing global base-config and domain-specific rules—to the practical execution of pinning using OpenSSL commands for SHA256 hash generation. It highlights critical operational considerations, such as the necessity of app updates when server certificates change. This documentation is primarily intended for application developers and system administrators, particularly those operating within the HarmonyOS/OpenHarmony ecosystem, who are responsible for implementing and maintaining high-security standards in their applications.
