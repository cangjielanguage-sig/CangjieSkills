This directory provides API reference documentation for the `ohos.telephony_observer` module in the Cangjie programming language, designed for the HarmonyOS ecosystem. It covers the management of telephony communication subscriptions, enabling developers to monitor real-time changes in network states, signal strength, SIM card status, and call states. Key components include data structures for event configuration, enumerations for lock reasons and event types, and the core observer class for handling subscriptions. This documentation is suitable for Cangjie developers building telephony applications that require responsive behaviors based on hardware and network status updates.
