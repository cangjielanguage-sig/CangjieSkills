# 接口

This directory contains API documentation for the Cangjie programming language's standard library, specifically focusing on binary data manipulation interfaces. It covers endianness handling, including Big-Endian, Little-Endian, and byte swapping mechanisms. The documentation details methods for serializing and deserializing primitive data types like integers, floating-point numbers, and Booleans. It is suitable for Cangjie developers working on systems programming, network protocols, file I/O, and cross-platform data exchange.

## Detailed Description

### interface_BigEndianOrderT/
This directory contains API documentation for the Cangjie programming language, specifically focusing on the `BigEndianOrder` interface and its implementations across various primitive data types. It covers extensions for signed and unsigned integers (Int8 to Int64, UInt8 to UInt64), floating-point numbers (Float16, Float32, Float64), and Boolean values. These extensions facilitate low-level binary data serialization and deserialization using big-endian byte order. The documentation details methods like `readBigEndian` and `writeBigEndian`, buffer requirements, and exception handling. This resource is suitable for Cangjie developers working on network protocols, file I/O, or systems programming requiring precise byte manipulation.

### interface_LittleEndianOrderT/
This directory provides API documentation for the Cangjie language's `LittleEndianOrder` interface and its type extensions. It enables binary serialization and deserialization for Booleans, Integers (Int8-64, UInt8-64), and Floating-point numbers (Float16-64) using little-endian byte order. Key functionalities include `readLittleEndian` and `writeLittleEndian` methods for converting between byte arrays and native types, with strict buffer size validation. This resource is designed for Cangjie developers working on low-level data processing, network protocols, or file I/O requiring precise binary manipulation.

### interface_SwapEndianOrderT/
This directory contains API reference documentation for the `SwapEndianOrder` interface within the Cangjie standard library's binary package. It covers the implementation of byte order reversal (endianness swapping) across various integer types, including Int8, Int16, Int32, Int64, and their unsigned counterparts. The core functionality revolves around the `swapBytes()` method, which reverses the byte sequence of numeric values. This documentation is essential for Cangjie developers working with low-level binary data, network programming, or cross-platform compatibility where precise control over data representation is required.
