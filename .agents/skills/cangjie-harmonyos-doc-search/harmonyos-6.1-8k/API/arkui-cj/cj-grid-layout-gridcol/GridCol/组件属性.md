### func gridColOffset(?Int32)

```cangjie
public func gridColOffset(value: ?Int32): This
```

**功能：** 设置相对于前一个栅格子组件偏移的列数。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 22

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|value|?Int32|是|-|相对于前一个栅格子组件偏移的列数。<br>初始值：12。|
