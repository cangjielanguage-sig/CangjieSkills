This directory contains essential API documentation for the `BenchmarkConfig` interface within the Cangjie unittest framework, specifically designed to facilitate high-precision performance testing. It thoroughly documents the extension of the Configuration class, enabling developers to implement specific benchmarking configurations. Key topics covered include methods to control execution parameters, such as defining batch sizes via fixed counts or ranges, managing garbage collection behavior, and setting constraints on minimum batches and duration. The documentation also details warmup configurations to ensure test stability. This resource is ideal for developers and software engineers using the Cangjie framework who need to customize and fine-tune benchmark test scenarios for accurate, reliable performance measurement and analysis.
