# bm工具

This directory contains documentation for the Bundle Manager (bm) tool, a command-line utility essential for managing application packages in the HarmonyOS/OpenHar ecosystem. It covers core operations like installation, uninstallation, updates, and querying application information, as well as advanced features such as dependency analysis, AOT compilation, and resource overlay management. Additionally, it includes a comprehensive troubleshooting guide for error codes. This resource is suitable for developers, QA engineers, and system administrators who need to debug, deploy, or maintain applications using the hdc shell or DevEco Studio.

### 共享库依赖关系查询命令dump-dependenci_5more.md 共享库依赖关系查询命令dump-dependenci_5more.md
This document serves as a technical reference guide for specific Bundle Manager (bm) command-line utilities used in application management and debugging. It details five distinct commands: dump-dependencies for viewing shared library info, compile for AOT compilation, copy-ap for transferring AP files, and dump-overlay or dump-target-overlay for querying resource overlay configurations. Each section provides the command syntax, a comprehensive list of parameters with descriptions, and practical usage examples. The content is designed for developers and system administrators who need to diagnose application dependencies, manage compilation states, or inspect overlay mechanisms within the operating system environment.

### 查询应用信息命令dump_5more.md 查询应用信息命令dump_5more.md
This document serves as a command-line reference guide for the Bundle Manager (bm) tool, detailing operations for application management and system queries. It covers five primary commands: dump for querying app details, clean for clearing data, get for retrieving device UDID, quickfix for managing patch installations, and dump-shared for inspecting shared libraries. Each section provides syntax, parameter descriptions, and usage examples, including specific flags for bundle names, device IDs, and HQF patch files. Intended for developers or system administrators managing HarmonyOS/OpenHarmony applications via the terminal.

### bm工具错误码/

It covers a wide range of issues related to HAP package installation, uninstallation, and configuration, including signature verification failures, API version mismatches, system account errors, and file system exceptions. Each document provides specific error codes, root causes, and actionable remediation steps. This resource is suitable for HarmonyOS developers, QA engineers, and technical support personnel using DevEco Studio or command-line tools to debug application deployment failures.
