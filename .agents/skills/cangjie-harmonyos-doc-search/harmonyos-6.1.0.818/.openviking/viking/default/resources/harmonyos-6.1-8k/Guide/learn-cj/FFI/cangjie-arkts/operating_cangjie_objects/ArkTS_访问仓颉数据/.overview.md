# ArkTS_访问仓颉数据

本目录汇集了关于在 ArkTS 中访问和操作仓颉（Cangjie）数据的详细技术文档。内容涵盖了三种主要的互操作方式：自定义函数、JSClass 和 JSExternal。文档重点讲解了如何通过这些机制实现跨语言的数据访问、性能优化以及安全封装。核心关键词包括 ArkTS、仓颉、互操作、JSClass、JSExternal 和数据绑定。这些资料适合致力于 HarmonyOS 应用开发，特别是需要处理 ArkTS 与仓颉语言混合编程及高性能场景的开发者阅读。

### JSClass.md JSClass.md
这份文档是一份关于使用 JSClass 优化仓颉与 ArkTS 互操作性能的教程。文档主要涵盖仓颉端类定义与注册、TypeScript 接口声明以及 ArkTS 调用示例。核心要点在于通过 JSClass 和 SharedObject 绑定，加速对象创建并减少内存占用，避免直接挂载方法的开销。文档详细演示了构造函数、方法绑定及对象引用转换的实现。适用于追求高性能场景的 HarmonyOS 开发者，需具备仓颉语言和 ArkTS 互操作基础。

### JSExternal.md JSExternal.md
这份文档旨在指导开发者如何利用 JSExternal 对象将仓颉数据绑定到 JSObject 上，以隐藏内部数据并提升接口安全性。文档涵盖了定义仓颉函数、TypeScript 接口声明及 ArkTS 调用示例。核心要点包括使用 `attachCJObject` 挂载隐藏属性，以及通过 `getAttachInfo` 获取并操作仓颉对象。这是一份面向 ArkTS 与仓颉互操作开发者的教程，重点在于实现安全的数据封装与交互。
