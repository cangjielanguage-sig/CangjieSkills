This directory contains API reference documentation for the `DatePickerDialogOptions` class in the Cangjie language, designed for the ArkUI framework. It covers the configuration of date sliding picker dialogs, including properties for setting date ranges, display modes (lunar calendar, military time), and visual styles for text and buttons. The documentation also details layout parameters, event callbacks for date changes, and dialog lifecycle management. It is suitable for UI developers working on system version 19 or higher who need to implement interactive date selection components.
