# 管理应用账号

This directory provides comprehensive technical documentation for managing application accounts using the Cangjie language, specifically focusing on the App Account SDK and BasicServicesKit framework. It covers the complete lifecycle of account management, ranging from creating local accounts and querying account lists to handling custom data and credentials securely. Furthermore, it addresses critical security workflows such as setting and retrieving authorization tokens and properly removing accounts upon user logout. Key technical concepts and APIs discussed include `createAccount`, `getAllAccounts`, `setAuthToken`, `getAuthToken`, and `removeAccount`. This documentation is primarily designed for application developers who need to implement robust user account persistence, secure authentication flows, and data management within their applications, ensuring data integrity and security throughout the user session.
