This directory serves as the definitive API reference for enumerations found within the Cangjie file system package. It is centered around the `OpenMode` enumeration, which is critical for defining the precise mechanics of file access and manipulation during input and output operations. The documentation thoroughly explains four primary variants: Read, Write, Append, and ReadWrite. It provides essential details on their behaviors, such as policies for file creation, content truncation, and exception handling when files are missing. Additionally, the text covers standard interface implementations, including ToString and Equatable, as well as equality operators. This documentation is specifically tailored for Cangjie developers who require granular control over file access modes to ensure robust and error-free file I/O implementation in their software projects. Understanding these modes is vital for preventing data loss and managing system resources effectively.
