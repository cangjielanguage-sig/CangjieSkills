This directory provides API reference documentation for the `CustomDialogControllerOptions` class within the Cangjie ArkUI framework. It covers configuration parameters for custom dialog appearance and behavior, including alignment, background styling, border attributes, and interaction logic. The documentation details properties for visual customization like blur, shadows, and dimensions, as well as behavior control such as modal settings and callbacks. Suitable for software developers building user interfaces on the HarmonyOS platform, this resource enables granular control over custom popups and modal windows using the Cangjie language.
