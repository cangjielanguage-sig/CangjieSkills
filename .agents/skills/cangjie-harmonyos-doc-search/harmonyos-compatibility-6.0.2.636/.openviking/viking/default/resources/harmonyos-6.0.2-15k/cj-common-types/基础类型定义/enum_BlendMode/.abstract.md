This directory contains technical documentation for the `BlendMode` enumeration, specifically designed for the ArkUI framework using the Cangjie language. It provides a comprehensive overview of image blending and compositing algorithms, detailing how source and destination pixels combine to create complex visual effects. The documentation covers a wide range of modes, from basic compositing operations like SRC_OVER to advanced color manipulations like HUE and LUMINOSITY. It includes mathematical formulas, system capability requirements, and API versioning details. This resource is essential for software developers, UI designers, and graphics programmers building HarmonyOS applications who require precise control over image layering, transparency, and color composition.
