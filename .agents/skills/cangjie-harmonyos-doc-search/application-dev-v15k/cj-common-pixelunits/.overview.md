# cj-common-pixelunits

This directory serves as a comprehensive technical resource dedicated to managing pixel units within the Cangjie ArkUI framework. It provides in-depth coverage of pixel unit definitions and the conversion mechanisms necessary for modern UI development. The content thoroughly explores essential concepts including physical pixels (px), virtual pixels (vp), font pixels (fp), and layout pixels (lpx). Furthermore, it details the specific APIs required for transforming between these units to achieve density-independent design. Key topics also encompass responsive layout calculations and the handling of system font scaling. This resource is highly suitable for Cangjie developers and UI designers who aim to ensure consistent, precise, and adaptive interface rendering across a wide variety of screen densities and device configurations.
