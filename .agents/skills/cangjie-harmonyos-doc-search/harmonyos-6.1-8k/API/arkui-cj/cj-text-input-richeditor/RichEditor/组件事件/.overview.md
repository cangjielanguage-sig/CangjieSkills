# 组件事件

本目录汇集了ArkUI框架中关于组件事件处理的API参考文档，重点涵盖文本输入控制、剪贴板交互以及富文本编辑器的生命周期管理。核心内容包括拦截粘贴事件、监听内容变更、处理输入法交互以及管理文本选择与删除操作。这些资料主要面向需要精细控制用户交互行为的ArkUI应用开发者，特别是使用仓颉语言进行开发的用户，旨在帮助开发者实现高度定制化的文本编辑功能。

## 详细描述

### func_onPastePaste_2more_07a86e0f.md
本文档主要介绍了ArkUI框架中用于处理粘贴和内容变更事件的API接口定义。文档涵盖了`onPaste`和`onDidChange`两个核心函数，分别用于在粘贴完成前拦截事件以及在组件执行增删操作后触发回调。关键信息指出，开发者可通过`onPaste`覆盖系统默认行为以实现图文粘贴，而`onDidChange`仅在文本实际发生变化时触发。这些接口均需特定的回调函数参数，起始版本为22。该文档属于API参考文档，面向需要精细控制文本输入和剪贴板交互的ArkUI应用开发者。

### func_onReadyVoidC_6more_c213715c.md
本文档是ArkUI富文本组件的API参考，定义了组件初始化、输入法交互及文本选择等事件的回调函数。主要涵盖onReady初始化完成、aboutToImeInput与onImeInputComplete处理输入法输入前后、aboutToDelete与onDeleteComplete处理删除前后，以及onSelect处理文本选中事件。关键信息包括回调参数类型（如RichEditorInsertValue）及通过布尔值控制操作执行的机制。文档面向使用仓颉语言的开发者，旨在帮助其精细控制富文本编辑器的用户交互行为。
