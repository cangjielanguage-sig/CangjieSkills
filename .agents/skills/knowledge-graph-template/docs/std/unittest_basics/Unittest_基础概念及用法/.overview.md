# Unittest_基础概念及用法

This directory serves as a comprehensive guide to the Cangjie (cjpm) unit testing framework, covering fundamental concepts, usage patterns, and configuration strategies. It provides resources for writing test cases using macros like `@Test` and `@TestCase`, managing test lifecycles with setup and teardown hooks, and configuring advanced execution behaviors. Additionally, it details assertion mechanisms and runtime options for optimizing test performance and output. This documentation is suitable for Cangjie developers and QA engineers seeking to implement robust unit testing, ensure code correctness, and automate testing workflows within the Cangjie ecosystem.

## Detailed Description

### 测试及测试用例.md 测试及测试用例.md
This document serves as a guide for writing and executing tests within the Cangjie unittest framework. It distinguishes between simple test functions and structured test classes, detailing the application of the `@Test` and `@TestCase` macros. Key information includes a code example demonstrating a test class with multiple test cases and the resulting output format from the `cjpm test` command. This tutorial is intended for Cangjie developers looking to implement unit testing, manage test lifecycles, and verify code behavior using assertions like `@Expect`.

### 测试生命周期.md 测试生命周期.md
This reference guide explains how to manage test lifecycle hooks in the Cangjie testing framework to share setup and cleanup code. It details the four lifecycle macros (@BeforeAll, @BeforeEach, @AfterEach, @AfterAll), their execution order, parameter constraints, and configuration rules within @Test classes. Key information includes that these hooks apply only to classes, not top-level functions, and specific execution behaviors in complex scenarios like type parameterized tests and parallel execution. It also notes that @BeforeEach and @AfterEach can accept a test case name string. This guide targets Cangjie developers writing unit tests who need to manage test environments and resources efficiently.

### 测试配置.md 测试配置.md
This document serves as a reference guide for configuring advanced features within a unit testing framework, specifically for users of the cjpm build tool. It outlines three primary configuration methods: utilizing the @Configure macro, passing command-line arguments during test execution, and modifying the cjpm configuration file. The text highlights that advanced functionalities require specific setup beyond defaults and notes a pending implementation regarding a configuration conversion algorithm. Targeted at developers using the cjpm ecosystem who need to customize test behavior, this guide assumes familiarity with basic unit testing and command-line operations.

### 断言/
This directory provides comprehensive documentation for assertion mechanisms within the Cangjie testing framework. It covers essential validation tools, including standard assertion macros for equality and boolean checks, manual failure triggers, and exception validation. Additionally, it explains how to perform approximate equality comparisons for floating-point numbers. These resources are tailored for developers writing unit tests in Cangjie who need to ensure code correctness, manage test execution flow, and handle complex error scenarios effectively.

### 运行配置/
This directory contains essential reference documentation for configuring and executing the Cangjie (cjpm) unit testing framework. It focuses on command-line interface options that allow users to fine-tune test execution, manage output visibility, and optimize performance. Key areas covered include output capture strategies to prevent interleaved logs, parallel execution configurations for faster testing, and advanced filtering mechanisms using tags and wildcards. Additionally, it addresses benchmarking setup, custom report generation, and timeout management. This documentation is tailored for developers and QA engineers who need to automate testing processes, ensure test isolation, and generate detailed execution reports within the Cangjie development ecosystem.
