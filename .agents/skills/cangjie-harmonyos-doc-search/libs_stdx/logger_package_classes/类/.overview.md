# 类

This directory contains API documentation for logging classes within the Cangjie programming language. It focuses on concrete implementations of loggers designed for various output formats, including structured JSON, plain text, and text-formatted streams. The documentation details class definitions, constructors, properties for log level management, and methods for handling output streams and attribute injection. It is suitable for Cangjie developers seeking to integrate robust logging capabilities, manage log records, or implement specific output formatting and structured logging in their applications.

## Detailed Description

### class_JsonLogger_2more.md
This API documentation defines two concrete logger implementations, JsonLogger and SimpleLogger, for the Cangjie programming language. The file details the class definitions, constructors, properties, and methods for both loggers, highlighting their inheritance from the Logger parent type. Key information includes that JsonLogger outputs structured JSON data while SimpleLogger outputs plain text, and both support features like log level management, output stream binding, and attribute injection via the withAttrs method. This reference is intended for developers integrating logging functionality into Cangjie applications who require specific output formatting or structured logging capabilities.

### class_TextLogger.md
This document provides API reference documentation for the Cangjie TextLogger class, which handles text-formatted log output to a specified stream. It covers the class initialization, the level property for filtering logs, and core methods such as log, close, and withAttrs for managing log records and attributes. Key information includes the specific text format structure and the inheritance from the base Logger type. Intended for Cangjie developers, this guide assists in implementing structured logging within applications by utilizing output streams and log records.
