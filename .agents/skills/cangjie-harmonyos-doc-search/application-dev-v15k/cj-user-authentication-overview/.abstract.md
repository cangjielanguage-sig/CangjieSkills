This directory serves as a comprehensive resource for the `cj-user-authentication-overview`, focusing primarily on the User Authentication Kit. It details a system-level service engineered to provide unified identity authentication capabilities across the platform. The content covers the kit's definition, practical usage scenarios, and essential features such as unified interfaces, trust level perception, and credential change detection. It also addresses mandatory constraints for third-party applications, specifically regarding UI implementation and security policies. Additionally, it explains operational mechanisms like Authentication Trust Levels (ATL) and AuthToken generation within a Trusted Execution Environment (TEE). This documentation is tailored for developers, security architects, and system integrators seeking to implement secure authentication methods like biometrics and passwords effectively.
