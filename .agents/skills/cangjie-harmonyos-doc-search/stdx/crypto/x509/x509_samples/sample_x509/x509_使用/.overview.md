# x509_使用

本目录包含使用仓颉语言处理 X.509 数字证书的教程与代码示例。内容涵盖了证书的创建、解析、读取及验证流程，重点介绍了如何生成证书签名请求（CSR）、提取证书关键信息（如序列号、有效期、DNS）以及验证信任链。核心关键词包括 `stdx.crypto.x509`、PEM 格式、公私钥解码、`X509Certificate.decodeFromPem` 和 `VerifyOption`。这些文档适合需要在仓颉项目中实现安全校验、加密通信或证书管理的开发者参考，要求具备基础的密码学知识。

## 详细说明

### 创建解析证书_2more_b61e4f5c.md 创建解析证书_2more_b61e4f5c.md
这份文档旨在演示如何使用仓颉语言创建和解析 X.509 数字证书及证书签名请求（CSR）。文档分为两个主要部分：第一部分通过代码示例展示如何基于父证书和密钥生成新证书，并提取序列号、有效期、DNS 及 IP 地址等关键信息；第二部分介绍如何利用私钥生成 CSR 并解析其内容。作为一份代码教程，文档要求用户预先准备 PEM 格式的证书和密钥文件。内容主要面向需要处理加密证书的开发者，涵盖了 X509Name、SerialNumber、公私钥解码等核心概念，适用于 stdx.crypto.x509 库的学习与应用。

### 读取解析证书_2more_ff62bbb5.md 读取解析证书_2more_ff62bbb5.md
本文档演示了如何使用仓颉语言读取、解析和验证 X.509 数字证书。内容涵盖解析证书必选字段（如序列号、公钥）与扩展字段，以及验证证书有效期、DNS 域名和信任链。重点介绍了 `X509Certificate.decodeFromPem` 的使用及 `VerifyOption` 配置方法。这是一份面向开发者的代码教程，适用于需要在仓颉项目中实现证书安全校验的场景，需具备基础密码学知识。
