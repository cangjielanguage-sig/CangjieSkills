## 创建组件

### init(String, () -> Unit)

```cangjie
public init(address: String, subcomponent: ()->Unit)
```

**功能：** 创建Hyperlink组件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|address|String|是|-|Hyperlink组件跳转的网页。|
|subcomponent|()->Unit|是|-|Image子组件。|

### init(String, String)

```cangjie
public init(address!: String, content!: String="")
```

**功能：** 创建Hyperlink组件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 16

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|address|String|是|-| **命名参数。** Hyperlink组件跳转的网页。|
|content|String|否|""| **命名参数。** Hyperlink组件中超链接显示文本。<br/> **说明：**<br/>组件内有子组件时，不显示超链接文本。|
