## 全局查询音效模式

主要包括全局音效查询相应[StreamUsage](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#enum-streamusage)对应场景的音效模式。

对于播放音频类的应用，开发者需要关注该应用的音频流使用什么音效模式并做出相应的操作，比如音乐App播放时，应选择音乐场景下的模式。在使用查询接口前，开发者需要使用[getStreamManager()](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#func-getstreammanager)创建一个AudioStreamManager音频流管理实例。

### 获取音频流管理接口

创建AudioStreamManager实例。在使用AudioStreamManager的API前，需要使用getStreamManager()创建一个AudioStreamManager实例。

```cangjie
import kit.AudioKit.*

let audioManager = getAudioManager()
let audioStreamManager = audioManager.getStreamManager()
```

### 查询对应场景的音效模式

```cangjie
import kit.AudioKit.*
import ohos.base.BusinessException

try {
    let audioEffectInfoArray = audioStreamManager.getAudioEffectInfoArray(StreamUsage.STREAM_USAGE_MUSIC)
    AppLog.info("getAudioEffectInfoArray: ${audioEffectInfoArray}")
} catch (_: BusinessException) {
    AppLog.error("Failed to get effect info array");
}
```
