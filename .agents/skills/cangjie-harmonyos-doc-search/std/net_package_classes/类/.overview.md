# 类

This directory provides API reference documentation for the Cangjie standard library's networking classes. It encompasses a wide array of components essential for network programming, including IP address management (IPv4/IPv6), socket operations (TCP, UDP, Raw), and Unix Domain Sockets for inter-process communication. The documentation details class definitions, properties, methods, and exception handling. It is designed for Cangjie developers and software engineers seeking to implement robust network protocols, manage socket connections, and handle address validation in their applications.

## Detailed Description

### class_SocketAddress.md class_SocketAddress.md
This document provides API reference documentation for the Cangjie SocketAddress class, representing immutable, protocol-independent socket addresses. It covers the class definition, inheritance from standard interfaces, and key members like family, size, and getAddressBytes. This technical reference is intended for developers implementing network functionality, offering essential details for managing socket address objects and their underlying byte representations.

### [2] class_IPAddress/
This directory contains API reference documentation for the `IPAddress` class in Cangjie's `std.net`. It covers the representation and manipulation of IPv4 and IPv6 addresses. Key topics include property inspection, serialization, comparison, DNS resolution, and safe parsing methods. It is designed for developers building network applications who need to handle IP address objects and perform network protocol operations.

### [3] class_IPPrefix/
This directory contains API reference documentation for the `IPPrefix` class, focusing on IP address prefixes and subnets. It covers parsing strings into IPPrefix objects, calculating network properties like broadcast addresses and masks, and performing comparisons. It is suitable for network engineers who need robust tools for subnet calculations and IP validation in Cangjie.

### [4] class_IPSocketAddress/
This directory contains API reference documentation for the `IPSocketAddress` class, representing immutable IP protocol socket addresses (IP + port). It covers definitions, parsing, IPv4/IPv6 formats, and exception-based error handling. This resource is essential for developers involved in socket binding and connection management who require precise control over network address validation.

### [5] class_IPv4Address/
This directory contains API reference documentation for the `IPv4Address` class. It covers the definition, constructors, utility methods, and operators for IPv4. Key topics include address creation from bytes or integers, conversion to other formats, serialization, and network classification checks (e.g., private, broadcast). It is suitable for developers implementing network functionality.

### [6] class_IPv6Address/
This directory contains API reference documentation for the `IPv6Address` class. It covers IPv6 implementation, including initialization, type inspection, scope management, and serialization. The documentation adheres to RFC standards 4291, 5952, and 4007. It is designed for developers who need to manipulate, validate, or convert IPv6 addresses.

### [7] class_RawSocket/
This directory contains API reference documentation for the `RawSocket` class for low-level network programming. It covers socket operations, configuration, data transmission, and connection management across protocols like TCP, UDP, and ICMP. It details method signatures and exception handling, suitable for developers implementing custom network protocols.

### [8] class_TcpServerSocket/
This directory contains API reference documentation for the `TcpServerSocket` class. It covers TCP server implementation, including initialization, listening, and configuration. Key topics include lifecycle management (bind, accept), low-level option manipulation, and exception handling. It is suitable for developers building robust server-side applications.

### [9] class_TcpSocket/
This directory contains API reference documentation for the `TcpSocket` class. It covers TCP client connections, inheritance from `StreamingSocket`, and configuration. Key topics include network behavior control (Nagle's algorithm), data transmission, and platform-specific logic. It is designed for developers requiring fine-grained control over socket lifecycles.

### [10] class_UdpSocket/
This directory contains API reference documentation for the `UdpSocket` class. It covers UDP packet communication, including creation, configuration, and data transmission. Key topics include socket options, buffer management, timeouts, and exception handling. It is suitable for developers building applications requiring connectionless communication.

### [11] class_UnixDatagramSocket/
This directory contains API reference documentation for the `UnixDatagramSocket` class for Unix Domain Sockets. It covers class structure, initialization, and data transmission functions. It is suitable for developers implementing inter-process communication on Unix-like systems who require precise technical specifications.

### [12] class_UnixServerSocket/
This directory contains API reference documentation for the `UnixServerSocket` class. It guides developers through implementing server-side services using Unix domain sockets. It covers initialization via paths, configuration properties like backlog, and connection handling. It is incompatible with Windows platforms.

### [13] class_UnixSocket/
This directory contains API reference documentation for the `UnixSocket` class, focusing on duplex stream-based communication using Unix domain sockets. It covers constructors, configuration properties, and methods for connecting, reading, and writing. It is designed for developers implementing low-level inter-process communication.

### [14] class_UnixSocketAddress/
This directory contains API reference documentation for the `UnixSocketAddress` class. It focuses on encapsulating Unix Domain Socket file system paths. It covers constructors, properties, and handling named, unnamed, and abstract addresses. It is suitable for developers managing socket addresses and converting them to strings.
