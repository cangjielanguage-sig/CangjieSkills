# 基础类型定义

This directory provides API reference documentation for core data structures and classes utilized by the ArkUI framework's Grid component in the Cangjie language. It encompasses definitions for layout configuration, scrollbar attribute calculations, and scrolling behavior enumerations. Key topics include managing grid layouts with irregular item sizes, calculating scrollbar metrics, and defining directional alignment strategies. These resources are tailored for HarmonyOS developers who require precise control over Grid component behaviors, positioning, and visual rendering to create sophisticated user interfaces.

## Detailed Description

### class_GridLayoutOptions.md class_GridLayoutOptions.md
This document serves as API reference documentation for the GridLayoutOptions class in the Cangjie language, designed to configure Grid layout behaviors within the ArkUI framework. It details the class constructor and its parameters, specifically focusing on how to manage regular and irregular GridItem sizes and positions. Key information includes the mandatory regularSize parameter, restricted to (1, 1), and optional callbacks like onGetIrregularSizeByIndex for single-template grids and onGetRectByIndex for dual-template grids to define custom spans and coordinates. The document explains collision handling logic for item placement. Intended for UI developers, this reference requires understanding of grid structures and Cangjie syntax to implement complex layouts.

### struct_ComputedBarAttribute.md struct_ComputedBarAttribute.md
This document provides API reference documentation for the ComputedBarAttribute struct in the Cangjie language, designed to represent scrollbar position and length within the ArkUI framework. The content details the struct's definition, its two read-only Float64 properties (totalLength and totalOffset), and its constructor. Key information includes that totalLength represents the Grid content's total size in pixels, while totalOffset indicates the content's shift relative to the display area. Both properties are immutable after initialization. This documentation targets HarmonyOS developers working with Grid components who need to handle scrollbar metrics programmatically. It specifies system capabilities and version requirements (version 19) for implementation.

### struct_OffsetOption_3more.md struct_OffsetOption_3more.md
This API reference document defines data structures and enumerations for ArkUI Grid component layout and scrolling behavior in the Cangjie language. It covers the OffsetOption struct for tracking sliding amounts, the GridDirection enum for layout orientation, and the GridItemAlignment enum for item alignment. Key information includes that OffsetOption stores the actual offset in vp, GridDirection supports row, column, and reverse modes, and GridItemAlignment includes a STRETCH mode that equalizes item heights based on the tallest item in a row, though it has specific constraints regarding scrollability and performance. This document targets ArkUI developers using Cangjie who need to configure Grid component behaviors.
