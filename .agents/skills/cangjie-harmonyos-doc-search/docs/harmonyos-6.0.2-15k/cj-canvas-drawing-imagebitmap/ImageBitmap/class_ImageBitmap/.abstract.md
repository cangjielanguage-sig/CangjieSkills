This directory contains technical documentation for the `ImageBitmap` class within the Cangjie language, specifically tailored for the ArkUI framework. It serves as a comprehensive guide for developers working with canvas-rendered pixel data, detailing the necessary APIs for image creation, manipulation, and resource management. Key topics include various constructors for initializing objects from local image paths or PixelMaps, handling dimension specifications, and managing supported formats like JPG, PNG, and BMP. This documentation is essential for application developers and system engineers building HarmonyOS applications who require robust solutions for image processing, rendering operations, and efficient graphics memory handling.
