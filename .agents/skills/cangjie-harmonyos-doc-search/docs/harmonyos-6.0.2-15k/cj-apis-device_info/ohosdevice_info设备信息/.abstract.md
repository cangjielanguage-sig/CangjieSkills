This directory provides comprehensive API documentation for the `ohos.device_info` module, specifically designed for the Cangjie programming language within the HarmonyOS ecosystem. It covers the querying of read-only terminal device information, including device identifiers, build metadata, operating system distribution, and hardware specifications. Key topics include accessing unique device IDs, bootloader details, and system attributes. This resource is suitable for HarmonyOS developers and system integrators who need to access system properties for debugging, analytics, or feature adaptation in their Cangjie applications. The documentation emphasizes the read-only nature of the module, guiding users through necessary permissions and context configurations to ensure successful implementation.
