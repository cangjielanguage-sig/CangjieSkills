This directory contains essential documentation for the Shield Guard Mode, a sophisticated system-level security feature engineered to mitigate remote attacks by strictly limiting device capabilities. The documentation details the specific HTML5 features disabled in ArkWeb, including WebAssembly, WebGL, and JIT compilation, which are critical steps in reducing the attack surface. It provides a comprehensive guide for developers and QA engineers to evaluate application compatibility, offering specific checks for restricted APIs such as getUserMedia and Service Workers. Key takeaways include the necessity of verifying functionality without these features and assessing performance impacts. This technical guide is intended for developers and QA engineers ensuring application stability in high-security environments.
