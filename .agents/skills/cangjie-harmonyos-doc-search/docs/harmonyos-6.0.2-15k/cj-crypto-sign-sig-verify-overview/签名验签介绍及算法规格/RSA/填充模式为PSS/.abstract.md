This directory provides comprehensive technical documentation for implementing RSA cryptographic operations using the PSS (Probabilistic Signature Scheme) padding mode. It covers essential aspects such as string parameter construction, supported algorithm combinations for various key sizes (RSA512 to RSA8192), and compatibility rules for hash algorithms and MGF1 mask generation functions. Additionally, it details specific parameter handling for signature and verification processes. This resource is designed for software developers, security engineers, and cryptographers who need to configure or integrate secure RSA signature functionalities within their systems.
