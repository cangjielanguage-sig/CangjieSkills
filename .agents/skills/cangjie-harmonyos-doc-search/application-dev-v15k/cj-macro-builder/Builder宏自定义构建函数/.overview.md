## Detailed Description

### Builder宏自定义构建函数_2more.md Builder宏自定义构建函数_2more.md
This technical guide introduces the @Builder macro in Cangjie UI, a mechanism for abstracting repetitive UI elements into reusable custom build functions. The document details two implementation approaches: private functions defined within custom components, which allow access to component state variables, and global functions defined outside components, suitable for stateless UI structures. Key takeaways include the specific syntax for defining and invoking these functions, the use of this for private methods, and recommendations on when to use each type. Targeted at developers with prior knowledge of Cangjie's declarative UI and component creation, this resource aims to simplify UI code maintenance and modularity.

### 参数传递规则_2more.md 参数传递规则_2more.md
This technical guide outlines parameter passing rules for custom build functions using the @Builder decorator in the ArkUI/Cangjie framework. It covers two primary modes: pass-by-value and pass-by-reference. Key takeaways include that pass-by-value is the default but prevents UI refresh when state variables change, whereas pass-by-reference is necessary for dynamic UI updates triggered by state modifications. The document specifies that only passing a single object literal directly triggers pass-by-reference. It also enforces strict type consistency and prohibits internal parameter modification. This reference is intended for developers managing state synchronization and component rendering in Cangjie-based applications.

### 使用场景/
This directory focuses on practical usage scenarios for the `@Builder` decorator within the ArkUI Cangjie development framework. It provides in-depth technical guidance on implementing dynamic UI rendering, specifically addressing how to effectively pass global and local builder functions as parameters to other components. The content covers complex architectural patterns such as multi-layer nesting and the critical requirement of pass-by-reference for ensuring dynamic UI refreshes in deeply nested structures. Furthermore, it clarifies the relationship between build functions and state management macros like `@Observed` and `@Publish`. This resource is highly suitable for HarmonyOS developers who are familiar with Cangjie syntax and are seeking to optimize UI construction, encapsulation, and state synchronization in complex component hierarchies.
