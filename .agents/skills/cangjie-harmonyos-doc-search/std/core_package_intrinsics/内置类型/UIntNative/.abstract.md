This directory serves as a comprehensive resource for the Cangjie language's `UIntNative` type, a platform-dependent unsigned integer. It details a series of API extensions designed to enhance the type's capabilities by implementing standard interfaces and adding utility properties. The documentation covers essential functionalities such as defining static properties for maximum and minimum values, enabling size comparisons through the `Comparable` interface, and supporting arithmetic progression via the `Countable` interface. Furthermore, it explains the implementation of `Hashable` for hash calculations and `ToString` for string conversions. This collection is suitable for Cangjie developers seeking to deepen their understanding of type behaviors, mathematical operations, and data representation for native unsigned integers.
