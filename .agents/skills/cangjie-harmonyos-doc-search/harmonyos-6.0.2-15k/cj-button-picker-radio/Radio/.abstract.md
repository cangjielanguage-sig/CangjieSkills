This directory contains comprehensive API reference documentation for the Radio component within the ArkUI framework, specifically implemented using the Cangjie language. It covers the essential aspects of building single-selection user interfaces, ranging from component initialization and group management to advanced styling and event handling. Key topics include the `RadioIndicatorType` enum for visual customization (TICK, DOT, CUSTOM) and state management via the `onChange` event. This documentation is primarily suitable for UI developers and system architects working on HarmonyOS applications who require detailed technical specifications to integrate and customize radio controls effectively using Cangjie syntax.
