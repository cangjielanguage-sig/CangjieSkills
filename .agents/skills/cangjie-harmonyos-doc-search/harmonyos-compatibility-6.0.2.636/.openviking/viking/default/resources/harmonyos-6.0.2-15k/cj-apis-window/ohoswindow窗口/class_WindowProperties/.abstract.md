This directory provides comprehensive API reference documentation for the `WindowProperties` class within the Cangjie language's WindowManager module. It focuses on the structural definition and instantiation of window configuration objects, detailing how to set up window geometry, types, and behavioral flags. The documentation covers essential attributes such as window dimensions, full-screen mode, focusability, touchability, brightness, and transparency. It is intended for Cangjie developers and software engineers who need to programmatically manage window lifecycles, visual presentation, and system capabilities, starting from API version 19. The resources here are crucial for understanding how to define and manipulate window behaviors effectively in a Cangjie application environment.
