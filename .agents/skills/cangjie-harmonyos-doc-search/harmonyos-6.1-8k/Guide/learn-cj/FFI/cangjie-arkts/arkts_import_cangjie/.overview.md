## Detailed Description

### ArkTS_侧使用互操作代码/

This subdirectory acts as the core documentation for implementing interoperability on the ArkTS side when interacting with Cangjie code. It is designed to assist developers in understanding the nuances of cross-language integration in a mixed programming environment.

The content primarily focuses on the two distinct methods available for loading Cangjie modules. First, it details the **static loading** approach, which leverages the standard `import` syntax to link modules at compile time, ensuring type safety and early binding. Second, it explains **dynamic loading**, which utilizes the `loadNativeModule` interface to load `.so` libraries at runtime. This method offers greater flexibility for applications that require conditional loading or plugin architectures.

Beyond loading mechanisms, the guide delves into the technicalities of **module integration** and **type definitions**. It explains how to ensure type safety and correct data mapping when functions and variables are passed between ArkTS and Cangjie. Additionally, it covers **dependency configuration**, ensuring that the build system correctly recognizes and packages the necessary native libraries. The section on the **cross-language call process** provides a step-by-step look at how invocations are handled, making it an indispensable resource for developers aiming to build robust, high-performance applications using both ArkTS and Cangjie.
