# class_NumberFormat

This directory provides comprehensive API reference documentation for the `NumberFormat` class within the Cangjie LocalizationKit, focusing on internationalization (I18n) features. It details how to format numbers according to specific locale conventions, supporting various initialization methods and configuration options. The documentation covers essential functionalities such as converting Float64 numbers to localized strings, handling different styles like decimal and scientific notation, and inspecting active formatting configurations. Designed for Cangjie developers, these resources are essential for implementing robust localization features in applications requiring version 19 compatibility and specific system capabilities.

## Detailed Description

### class_NumberFormat_5more.md
This document provides API reference documentation for the NumberFormat class within the Cangjie LocalizationKit, designed to format numbers according to specific locale conventions. It covers three initialization methods: a default constructor using the system locale, and two others accepting a single locale string or an array of strings, both supporting optional NumberOptions for configuration. Additionally, it documents the format method, which converts Float64 numbers into localized strings. Key information includes support for styles like decimal and scientific notation, system capability requirements for I18n, and version 19 compatibility. This technical reference is intended for developers implementing internationalization features in Cangjie applications.

### func_resolvedOptions.md
This document provides API reference documentation for the Cangjie function resolvedOptions(), which retrieves the configuration settings of a number formatting object. The file details the function signature, system capabilities, version requirements, and return type, specifically the NumberOptions struct. Key information includes the function's role in accessing properties like style and notation, supported by a code example demonstrating instantiation and option retrieval. Intended for Cangjie developers working on internationalization, this reference helps users inspect the active formatting options within a NumberFormat instance.
