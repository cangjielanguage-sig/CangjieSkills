# cj-apis-power

This directory hosts the API reference documentation for the `ohos.power` module specifically designed for the Cangjie programming language. It provides essential interfaces for system power management, enabling developers to query device states, configure contexts, and monitor power behaviors effectively. The documentation covers critical functionalities such as retrieving the current power mode and checking standby status. It includes definitions for the `DevicePowerMode` enum and outlines error handling mechanisms for service failures. This resource is tailored for Cangjie developers building HarmonyOS applications who require precise control and visibility over the device's power states to optimize app performance, ensure battery efficiency, and enhance the overall user experience through intelligent system-level interactions.

## Detailed Description

### cj-apis-power.md cj-apis-power.md

This document acts as the definitive API reference for the `ohos.power` module within the Cangjie ecosystem. It is structured to assist developers in performing system power management tasks, primarily focusing on querying and monitoring device states. The guide begins with detailed instructions on module imports and context configuration, ensuring that developers can correctly set up their environment before utilizing the power features.

A significant portion of the document is dedicated to specific function definitions. It details the usage of `getPowerMode` for retrieving the current power state, `isActive` for checking activity status, and `isStandby` for determining if the device is in standby mode. Furthermore, it introduces the `DevicePowerMode` enum, which defines specific states such as Normal and Power Save, providing a clear structure for state management.

To ensure robust application development, the documentation also covers error handling, specifically addressing scenarios involving service connection failures. By providing these interfaces and definitions, the guide empowers Cangjie developers working on HarmonyOS applications to effectively interact with and monitor device power behaviors. This allows for the creation of intelligent applications that adapt their behavior based on power availability, contributing to better resource management and device longevity.
