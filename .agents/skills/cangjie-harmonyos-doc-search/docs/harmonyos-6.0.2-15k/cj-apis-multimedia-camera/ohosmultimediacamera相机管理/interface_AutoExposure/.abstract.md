This directory contains essential API reference documentation for the AutoExposure interface, a core component of the CameraKit framework designed for the Cangjie language. It provides developers with the technical specifications needed to implement and manage automatic exposure operations in camera-enabled applications. The content covers a wide array of functionalities, including the configuration of exposure compensation, the selection of auto-exposure modes, and the precise setting of metering points. Additionally, it details system capability requirements, parameter constraints, and error handling protocols. This documentation is specifically intended for software developers and engineers working on multimedia applications who require advanced programmatic control over camera hardware to optimize image capture and processing.
