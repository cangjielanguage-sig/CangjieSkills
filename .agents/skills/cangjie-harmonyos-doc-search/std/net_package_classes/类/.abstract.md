This directory provides API reference documentation for the Cangjie standard library's networking classes. It encompasses a wide array of components essential for network programming, including IP address management (IPv4/IPv6), socket operations (TCP, UDP, Raw), and Unix Domain Sockets for inter-process communication. The documentation details class definitions, properties, methods, and exception handling. It is designed for Cangjie developers and software engineers seeking to implement robust network protocols, manage socket connections, and handle address validation in their applications.
