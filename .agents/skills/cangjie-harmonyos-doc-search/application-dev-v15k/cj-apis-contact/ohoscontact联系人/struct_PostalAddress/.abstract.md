This directory provides comprehensive API reference documentation for the `PostalAddress` struct within the Cangjie programming language, specifically designed for the `SystemCapability.Applications.ContactsData` framework. It covers the essential components required to create, define, and manage contact postal addresses programmatically. Key topics include the struct's constructor, static constants for categorizing address types (such as Home, Work, and Other), and properties for specific address details like city, country, street, and postal code. This resource is highly suitable for developers working on contact data applications who need to instantiate address objects and manage address attributes, requiring familiarity with Cangjie syntax and API version 19 requirements.
