# cj-errorcode-i18n

本目录专门用于存放I18n（国际化）模块的错误码参考文档，旨在为开发人员提供精准的故障排查支持。文档重点涵盖了I18n模块特有的错误码定义，特别是针对错误码890001（参数类型错误）的深入解析。内容不仅包括错误信息与描述，还详细列出了可能的原因及具体的处理步骤，同时提供了查阅通用错误码文档的指引。该资料目前处于Beta阶段，非常适合正在使用I18n模块进行API集成的开发者，能够有效帮助其解决接口调用过程中的参数类型不匹配问题，确保系统的稳定运行。
