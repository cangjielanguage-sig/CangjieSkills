# 基础类型定义

This directory contains essential API reference documentation for fundamental type definitions used in developing HarmonyOS ArkUI applications with the Cangjie language. It serves as a technical guide for developers looking to implement and customize user interface elements, specifically focusing on text rendering and component interaction. The content covers the structural definitions required for font styling, including family, size, and weight configurations, as well as the data structures needed for picker components, such as date selection results. By providing detailed class structures, property definitions, and constructor specifications, this directory enables developers to create visually consistent and functionally robust interfaces. It is intended for software engineers and UI developers who possess a working knowledge of the ArkUI framework and are seeking precise control over application styling and data handling.

## Detailed Description

### class_MyFont.md class_MyFont.md

This document provides API reference documentation for the Cangjie MyFont class, which is used to define font formatting styles within HarmonyOS ArkUI applications. It details the class structure, focusing on four configurable properties: family, size, style, and weight, alongside two overloaded constructors. Key information includes default values such as "HarmonyOS Sans" and 16.fp, read-write capabilities for all properties, and the restriction that the size property does not support percentages. The constructors allow developers to specify the font family either as a String or an AppResource. Intended for developers building user interfaces, this reference assumes familiarity with the Cangjie language and ArkUI framework system capabilities.

### class_PickerTextStyle_2more.md class_PickerTextStyle_2more.md

This API reference document defines configuration and result classes for ArkUI picker components in the Cangjie language. It covers the PickerTextStyle class for font styling and the DatePickerResult class for capturing date selection outcomes. Key details include read-only properties for text color, font, and date components (year, month, day), with specific constructors provided for initialization. Notably, the month parameter in DatePickerResult uses a 0-based index (0 for January). Targeted at developers using the ArkUI framework, this documentation assists in implementing and styling date selection interfaces effectively.
