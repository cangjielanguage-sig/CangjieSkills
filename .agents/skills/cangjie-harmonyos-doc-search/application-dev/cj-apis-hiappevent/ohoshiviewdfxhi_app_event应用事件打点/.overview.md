### class_AppEventFilter.md class_AppEventFilter.md
This API reference details the AppEventFilter class in Cangjie, designed to configure subscription filters for event watchers. The domain is mandatory, while eventTypes and names are optional arrays defaulting to empty, allowing flexible filtering for precise event observation.

This document provides API reference for the AppEventGroup class, defining the structure for subscribed event groups. This class is primarily used within the onReceive callback of a Watcher to access event details and supports read and write operations.

### class_AppEventInfo.md class_AppEventInfo.md

### class_AppEventPackage.md class_AppEventPackage.md
This document provides API reference for the AppEventPackage class, defining the structure of event packages returned by subscription services. It specifies four public properties: packageId (auto-incrementing ID), row (event count), size (byte size), and data (event strings). All properties are readable and writable, intended for managing application event data.
