## Detailed Description

### 使用ImageSource完成图片解码.md 使用ImageSource完成图片解码.md
This document explains how to use the ImageSource class to decode various image formats into a unified PixelMap for display or processing within an application. It covers the definition of image decoding and lists the supported file formats, including JPEG, PNG, GIF, WebP, BMP, SVG, ICO, DNG, and HEIF. The key takeaway is that decoding transforms archived images into PixelMaps, enabling further image manipulation. Support for formats like HEIF and DNG may vary depending on the hardware device. This guide targets developers working on image display or processing features who need to understand format compatibility and the decoding workflow.

### 开发示例-对资源文件中的图片进行解码.md 开发示例-对资源文件中的图片进行解码.md
This document serves as a development tutorial demonstrating how to decode images from resource files using the Cangjie language. The content is structured into four main steps: obtaining the ResourceManager, creating an ImageSource via either an Array<UInt8> buffer or a RawFileDescriptor, generating a PixelMap, and manually releasing resources. Key takeaways include understanding the two distinct methods for initializing an ImageSource and the necessity of calling Release methods on PixelMap and ImageSource objects to manage memory effectively. This guide is intended for developers working with image processing within the LocalizationKit framework who need to handle image assets from rawfile folders.
