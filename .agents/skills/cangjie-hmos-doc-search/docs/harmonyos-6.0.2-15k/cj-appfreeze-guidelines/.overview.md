# cj-appfreeze-guidelines

This directory serves as a comprehensive technical repository dedicated to the identification, diagnosis, and resolution of Application Not Responding (ANR) and AppFreeze phenomena, specifically tailored for applications running on the Stage model. It acts as a central hub for understanding the intricate behaviors of application stability, offering deep insights into detection mechanisms and the system policies governing forced exits. The content encompasses critical performance topics such as main thread stalling, input event timeouts, and complex lifecycle transitions. Furthermore, it introduces essential debugging tools, including Binder and Hilog, to aid in log analysis. This resource is meticulously designed for software developers and system engineers who require robust methodologies for root cause analysis to eliminate performance bottlenecks and ensure high application reliability.
