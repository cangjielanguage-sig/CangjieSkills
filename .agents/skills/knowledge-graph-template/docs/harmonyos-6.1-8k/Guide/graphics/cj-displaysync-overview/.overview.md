# cj-displaysync-overview

本目录提供了OpenHarmony可变帧率特性的全面概览文档，重点介绍如何利用相关API在LTPO屏幕上实现性能与功耗的最佳平衡。内容深入探讨了该特性的背景、核心运作机制（包括系统决策逻辑与硬件切换流程）、典型应用场景（如动画绘制）以及开发过程中的约束限制。通过接入控帧系统，开发者可以设置期望帧率，由系统根据实时功耗和硬件能力动态调整屏幕刷新率。该文档主要面向OpenHarmony应用开发者，特别适用于追求极致动画流畅度并致力于降低设备功耗的业务场景。

## 详细说明

### cj-displaysync-overview.md cj-displaysync-overview.md

本文档详细阐述了OpenHarmony的可变帧率特性，旨在指导开发者如何利用API接口在LTPO屏幕上有效平衡设备性能与功耗。文档内容涵盖四个主要部分：背景介绍、典型使用场景（例如动画绘制）、运作机制（解析系统如何进行决策以及硬件如何进行切换）以及相关的约束限制。开发流程上，开发者通过设置期望帧率接入控帧系统，随后系统会根据当前的功耗需求和硬件能力进行智能决策并分发指令，最终实现屏幕刷新率的动态调整。该文档面向OpenHarmony应用开发者，非常适合那些需要优化动画流畅度及降低功耗的复杂业务场景。
