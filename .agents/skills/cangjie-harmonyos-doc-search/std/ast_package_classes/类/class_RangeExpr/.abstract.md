This directory contains API documentation for the `RangeExpr` class and associated utility functions within the Abstract Syntax Tree (AST) implementation of the Cangjie programming language. It comprehensively covers the definition and structure of range expressions that utilize operators like `..` and `..=`, detailing class inheritance, initialization methods, and mutable properties such as start, end, and step tokens. Furthermore, it includes technical references for functions responsible for converting AST nodes into token types and traversing the syntax tree using the Visitor pattern. This documentation is specifically suitable for developers engaged in language tooling, compiler development, or parsing logic who need to manipulate or understand the structural components of range expressions and AST traversal mechanisms.
