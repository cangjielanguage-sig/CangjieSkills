# class_SubProcess

This directory contains essential API reference documentation for the Cangjie language's `SubProcess` class and related functions, designed to assist developers in managing child process operations. It covers the inheritance hierarchy from the `Process` class and details the properties for accessing standard input, output, and error streams. A significant focus is placed on the deprecation of legacy stream properties in favor of new pipe-based attributes. The documentation also explains process lifecycle management, specifically the `wait` function for handling exit codes and timeouts, and the `waitOutput` function for retrieving execution results. Critical advice regarding stream redirection to prevent deadlocks and warnings about handling large output streams are included. This content is suitable for Cangjie developers involved in system programming, process control, and I/O stream management who need to handle subprocess execution and exception handling effectively.

## Detailed Description

### class_SubProcess_8more.md
This document serves as API reference documentation for the Cangjie language's SubProcess class, which inherits from Process to manage child process operations. Main topics include properties for accessing standard input, output, and error streams, specifically noting the deprecation of stdIn, stdOut, and stdErr in favor of stdInPipe, stdOutPipe, and stdErrPipe. It details the wait function, which blocks execution to retrieve exit codes or handle timeouts via TimeoutException. Key takeaways involve understanding stream redirection to avoid deadlocks and managing process lifecycles. This guide targets developers implementing process control, requiring familiarity with I/O streams and exception handling.

### func_waitOutput.md
This document serves as API reference documentation for the Cangjie function waitOutput, designed to block the current process until a child process completes. It details the function signature, return values, and potential exceptions. The function returns a tuple containing the exit status code, standard output, and standard error as byte arrays. A critical takeaway is the warning that this function is unsuitable for scenarios with large output streams; developers should instead use SubProcess stream attributes with the wait function. The document targets Cangjie developers who need to manage subprocess execution and handle ProcessException errors.
