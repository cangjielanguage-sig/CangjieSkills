This directory provides a comprehensive guide for HarmonyOS developers on managing user album resources using the MediaLibraryKit and Cangjie programming language. It covers essential operations such as retrieving album lists, accessing images and videos, renaming albums, adding media, and removing assets. Key topics include permission handling, `photoAccessHelper` usage, and `MediaAlbumChangeRequest` implementation. This resource is suitable for developers building media-centric applications who need programmatic control over the device's media library.
