# cj-stage-model-development-overview

This directory provides a comprehensive overview of the Stage model development framework, serving as an essential guide for application developers. It details the core concepts required to build modern applications, including AbilityStage, UIAbility, ExtensionAbility, WindowStage, and Context. The documentation outlines a complete development workflow, guiding users through component development, process and thread models, and configuration file setup. It specifically highlights the functional differences between UIAbility, designed for user interaction, and ExtensionAbility, used for specific scenarios such as cards or input methods, while explaining their respective lifecycles and system management. By covering the architecture and necessary development steps, this resource acts as a foundational reference for developers looking to master the Stage model and implement efficient application structures.
