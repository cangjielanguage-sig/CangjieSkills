# cj-macro-builder

This directory serves as a comprehensive technical resource for the `@Builder` macro within the Cangjie UI framework. It focuses on a lightweight yet powerful mechanism designed for reusing UI elements by abstracting components into custom build functions. The content thoroughly covers fundamental definitions, differentiating between private and global functions, and explores complex parameter passing rules, specifically the nuances between pass-by-value and pass-by-reference. Furthermore, it addresses critical state management topics, such as utilizing `@Observed` classes to ensure dynamic UI updates. This guide is specifically designed for developers proficient in Cangjie syntax and ArkUI, offering practical code examples and advanced scenarios to help users optimize their declarative UI architecture, manage state synchronization effectively, and master intricate component interactions.
