# cj-connectivity-kit-intro

This directory serves as the primary entry point for the Connectivity Kit, a comprehensive technical framework designed to empower developers with the ability to integrate robust wireless communication services into their applications. It provides a detailed overview of the kit's extensive capabilities, covering a wide range of protocols including Bluetooth—with specific modules for state management, device pairing, low-energy (BLE) communication, and high-quality audio streaming—as well as WLAN connectivity modes such as Station, P2P, and AP. Furthermore, it introduces NFC card emulation features. The content is structured to guide developers through essential operating mechanisms, prerequisites for service activation, and constraints related to user authorization. This resource is highly suitable for both application and system developers aiming to implement seamless device interaction, establish IoT connectivity, and facilitate wireless data transfer, serving as a bridge to in-depth API references and practical implementation guides.
