# basic_fuzzing_test

This directory serves as a comprehensive resource for conducting basic fuzzing tests, with a specific focus on the Cangjie programming language. It provides a structured approach to identifying software defects through automated input generation. The documentation covers essential technical aspects such as environment configuration, compiler instrumentation, and crash analysis. By utilizing tools like libFuzzer and specific compiler flags, users can systematically test code stability. This guide is intended for software developers and quality assurance engineers who have a working knowledge of Cangjie and build systems, offering them the necessary insights to implement robust fuzzing pipelines and detect critical runtime errors effectively. The focus on practical implementation ensures that users can translate theoretical concepts into actionable testing strategies.

## Detailed Description

### [1] 测试猜测字符功能/

This subdirectory contains in-depth documentation regarding the application of fuzzing techniques to the "guess character" functionality within the Cangjie programming language. It serves as a practical manual for the entire lifecycle of automated fuzzing, designed to help developers identify edge cases and potential security vulnerabilities that are often missed during standard unit testing. The "guess character" function serves as an ideal target for demonstrating fuzzing capabilities due to its input-dependent logic.

The documentation meticulously covers the setup process, guiding users through the necessary environment configurations. It explains the usage of critical compiler flags, specifically `--sanitizer-coverage`, which is essential for tracking code execution paths during the fuzzing process. Additionally, it details the required linker options to ensure the fuzzing engine can interact correctly with the target application.

A significant portion of the content is dedicated to the analysis of execution logs. These logs provide real-world examples of how the fuzzer operates, particularly focusing on mutation strategies. The text highlights a specific case where the fuzzer's mutation algorithm successfully generated the input "Cangjie!", which triggered a TRAP exception. This example serves as a valuable case study for understanding how fuzzers can discover non-obvious crash conditions.

The core technical themes explored in this directory include the Cangjie language ecosystem, the integration of libFuzzer, the implementation of coverage instrumentation, and the methodologies for effective crash detection. This resource is specifically curated for developers and test engineers who have a foundational understanding of Cangjie and are familiar with compilation and linking processes. By following the guidelines provided here, users can successfully deploy a fuzzing environment to proactively detect and fix defects in their software projects.
