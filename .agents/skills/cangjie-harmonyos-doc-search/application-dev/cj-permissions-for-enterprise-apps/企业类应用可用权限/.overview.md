# 企业类应用可用权限

This directory provides comprehensive reference documentation for permissions available to enterprise applications within the HarmonyOS ecosystem. It focuses on the definitions, access levels, and version evolution of sensitive capabilities required for enterprise-grade functionality. Key topics covered include enterprise security, process management, eSIM configuration, Wi-Fi control, domain accounts, and file control. The documents highlight critical changes in API versions 14 and 15, where access to certain permissions expanded from MDM or system-only apps to general enterprise applications. This resource is essential for system and enterprise application developers who are implementing device management, security features, or applications for enterprise-customized devices, particularly regarding manual signing requirements and authorization modes.

## Detailed Description

### ohospermissionQUERY_AUDIT_10more.md ohospermissionQUERY_AUDIT_10more.md
This document serves as a reference guide for specific HarmonyOS permissions, detailing their definitions, access levels, and version evolution. It covers ten permissions related to enterprise security, process management, eSIM configuration, Wi-Fi control, domain accounts, and system information access. Most permissions are classified as system_basic with system_grant authorization. Key takeaways include version-specific changes, such as the expansion of access for audit events and process termination from MDM or system apps to general enterprise applications starting in API 14. This reference is intended for system and enterprise application developers implementing sensitive device management and security features.
