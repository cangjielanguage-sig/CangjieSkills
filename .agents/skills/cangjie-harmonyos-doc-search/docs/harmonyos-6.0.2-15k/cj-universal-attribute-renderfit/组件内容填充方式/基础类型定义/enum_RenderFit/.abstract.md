This directory contains API reference documentation for the `RenderFit` enum within the ArkUI framework and Cangjie language. It comprehensively covers content scaling, alignment, and aspect ratio preservation strategies used to control how visual elements fill UI components. Key topics include specific resizing modes like `RESIZE_CONTAIN`, `RESIZE_COVER`, and various alignment constants such as `CENTER` and `TOP_LEFT`. These documents are essential for HarmonyOS developers working with API version 12 who need to implement precise visual presentation, layout configurations, and complex animation behaviors in their applications.
