# cj-apis-ability-interop

This directory provides the essential documentation for the `cj-apis-ability-interop` module, a critical component designed to enable seamless interoperability between the Cangjie programming language and the ArkTS runtime environment within the HarmonyOS ecosystem. As developers increasingly adopt Cangjie, the need to bridge these two environments becomes vital for leveraging existing ArkTS components. This directory covers the technical mechanisms required for converting JavaScript values (JSValue) into various native Context types, such as AbilityContext and UIExtensionContext, and details the protocols for handling WantAgent objects across language boundaries. Key topics include the `SystemObjectInteropType` interface, context creation functions, and type conversion methods. This documentation is specifically intended for HarmonyOS developers using the Cangjie language who are targeting API version 19 and above, providing them with the necessary tools to integrate cross-language runtime components, manage system contexts effectively, and ensure robust application behavior.
