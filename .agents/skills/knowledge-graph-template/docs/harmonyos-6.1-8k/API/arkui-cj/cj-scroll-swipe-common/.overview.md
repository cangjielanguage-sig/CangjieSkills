# cj-scroll-swipe-common

This directory contains a specialized documentation set designed for the ArkUI framework, focusing on the standardization and implementation of common scroll and swipe functionalities. It provides a robust reference for defining universal properties and event APIs across essential container components. The documentation is authored in the Cangjie (仓颉) programming language and is intended for systems running API 22 and later versions. Key topics include scroll interaction logic, real-time state monitoring, edge effect processing, and the customization of visual styles. This resource is ideally suited for HarmonyOS application developers and UI engineers who need to implement advanced, custom scrolling behaviors and ensure a consistent, high-performance user experience across different scrollable components like Lists and Grids. By establishing a common set of APIs, this directory helps reduce redundancy in code and ensures consistent behavior across different UI elements.

## Detailed Description

### 滚动组件通用API/

This documentation collection defines the universal attribute and event API specifications for scroll components within the ArkUI framework. It serves as a central reference for the common attributes and events shared by the List, Grid, and Scroll components. The documentation delves into the technical details required to manage scroll interaction logic, enabling developers to dictate how users navigate through content. It also covers state monitoring mechanisms, allowing applications to react dynamically to scroll positions.

Furthermore, the guide addresses edge effect handling, which defines the visual feedback when a user reaches the limit of a scrollable area, and visual style customization to match specific design requirements. All code examples and specifications are provided in the Cangjie language, ensuring compatibility with API 22 and above. This documentation is primarily targeted at HarmonyOS developers who require fine-grained control over scroll containers and wish to implement bespoke scrolling logic to enhance the overall user experience. Whether building a simple list or a complex grid layout, developers will find the necessary tools to optimize performance and usability.
