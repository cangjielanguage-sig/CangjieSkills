# server端操作services和通知客户端信息

This directory contains technical documentation and code examples for implementing a Bluetooth Low Energy (BLE) GATT Server, specifically focusing on managing services and notifying clients. It covers the complete server lifecycle, including initialization, service creation, handling read/write requests, descriptor operations, and resource cleanup. The content is primarily written for developers using the Cangjie language and ArkTS within the HarmonyOS ecosystem. Key topics include GATT server instantiation, callback registration for connection states, and response handling mechanisms. This guide is suitable for software developers with a foundational understanding of Bluetooth protocols and asynchronous programming.
