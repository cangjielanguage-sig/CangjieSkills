# runtime_deploy

本目录专门用于提供仓颉运行时环境的部署文档，旨在解决在无编译环境下运行仓颉可执行程序的问题。内容涵盖了在 Linux、macOS 和 Windows 等主流操作系统上的独立部署流程，包括针对不同架构的 SDK 下载、文件解压以及关键环境变量（如 PATH、LD_LIBRARY_PATH 和 DYLD_LIBRARY_PATH）的配置方法。文档特别强调了动态库路径配置的重要性，指出非全静态链接的程序必须正确设置这些变量才能运行。该资源适合需要在生产环境或隔离环境中分发和运行仓颉应用程序的开发者与运维人员。

## 详细说明

### runtime_deploy.md
本文档是一份部署指南，旨在指导用户在Linux、macOS和Windows系统上独立部署仓颉运行时环境，以便在没有编译环境的情况下运行可执行程序。文档详细介绍了针对不同平台架构下载SDK、解压文件及配置环境变量（如LD_LIBRARY_PATH、DYLD_LIBRARY_PATH和PATH）的具体步骤。关键信息指出，若编译时未使用全静态链接，则必须在运行环境中正确配置动态库路径。本文档适用于需要在目标环境中部署和运行仓颉程序的开发者。
