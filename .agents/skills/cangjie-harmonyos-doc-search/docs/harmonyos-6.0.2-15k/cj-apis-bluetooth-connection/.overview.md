# cj-apis-bluetooth-connection

This directory provides a comprehensive collection of API reference documentation for the HarmonyOS `ohos.bluetooth.connection` module, specifically tailored for the Cangjie programming language. It covers the full spectrum of Bluetooth connectivity features, ranging from device discovery and pairing management to real-time state monitoring and battery information retrieval. The documentation outlines key architectural components, including enumerations for transport types and bond states, classes defining device parameters, and functions dedicated to handling asynchronous callbacks and connection operations. This resource is essential for software developers and system engineers aiming to build robust Bluetooth-enabled applications on the HarmonyOS platform, offering the precise definitions and code examples required to implement efficient wireless communication protocols.
