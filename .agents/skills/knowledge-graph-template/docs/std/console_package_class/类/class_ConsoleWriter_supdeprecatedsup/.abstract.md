This directory contains API reference documentation for the deprecated `ConsoleWriter` class and related console output functions in the Cangjie programming language. It covers the class structure, inheritance from `OutputStream`, and thread-safe writing mechanisms to standard output or error streams. It is suitable for Cangjie developers maintaining legacy code or understanding console I/O operations, noting the deprecation warning directing users to the `env` package.
