This directory contains API reference documentation for the `AbilityInfo` class in the Cangjie programming language, specifically within the HarmonyOS/OpenHarmony BundleManager framework. It covers the data structure used to store Ability component information, detailing properties defined in `module.json5` such as bundle names, permissions, launch types, and window configurations. The documentation is intended for application developers and system integrators who need to configure, query, and manage Ability component states and capabilities. Key topics include read-only properties, system flags for data retrieval, and component metadata.
