This directory serves as a specialized technical resource dedicated to the `ohos.device_info` module, explicitly designed for HarmonyOS developers utilizing the Cangjie programming language. It provides comprehensive documentation and API references for querying read-only terminal device information, covering critical aspects such as hardware specifications, build metadata, and operating system distribution details. The content thoroughly explains essential implementation requirements, including module imports, necessary system capabilities like `SystemCapability.Startup.SystemInfo`, and specific permissions such as `ohos.permission.sec.ACCESS_UDID` for accessing sensitive data like serial numbers. This resource is highly suitable for developers who need to programmatically access device configuration for system analysis, compatibility checks, or application diagnostics. It ensures users understand how to execute code within template projects to read extensive device data, while clarifying that configuration changes are not supported through this interface.
