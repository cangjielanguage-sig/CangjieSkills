This directory contains API reference documentation for the `I18NUtil` class within the LocalizationKit, specifically designed for the Cangjie programming language. It provides comprehensive resources for handling internationalization (i18n) tasks, including locale matching, date formatting, language and region code conversions, time period localization, and measurement unit conversions. The documentation is tailored for software developers who require precise control over localization features, offering detailed function signatures, error handling, and practical code examples to implement robust multi-language support in their applications.
