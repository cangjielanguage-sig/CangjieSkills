This directory contains technical specifications and API references for asymmetric key encryption and decryption algorithms within the Cangjie framework. It covers standards like GM/T 0009-2012 (SM2) and RSA implementations, detailing encryption modes, padding schemes, and key configurations. The documentation addresses ciphertext components, parameter formats, and API version updates. It is designed for developers and security engineers implementing cryptographic operations, requiring a solid understanding of asymmetric encryption concepts and security protocols.
