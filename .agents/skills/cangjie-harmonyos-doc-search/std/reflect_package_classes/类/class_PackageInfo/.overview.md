# class_PackageInfo

This directory contains API reference documentation for the `PackageInfo` class within the Cangjie language's reflection module. It covers the structural inspection of package metadata, including properties for hierarchy (parent, root, sub-packages), retrieval of public members (functions, variables, types), and operator overloading for equality comparisons. Key topics include runtime introspection, dynamic library loading, and exception handling for missing metadata. This documentation is suitable for Cangjie developers who need to programmatically analyze package structures, manage dynamic modules, or implement reflection-based features in their applications.

### class_PackageInfo_8more.md class_PackageInfo_8more.md
This document serves as API reference documentation for the PackageInfo class in the Cangjie language, designed to describe package metadata. It details properties for accessing package hierarchy and contents, such as name, qualifiedName, parentPackage, rootPackage, and subPackages, alongside collections of public variables and functions.
