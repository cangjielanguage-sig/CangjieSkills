This directory contains essential technical documentation for developers working on audio call implementations. It provides a comprehensive overview that clearly distinguishes between VoIP and cellular communication modes, highlighting critical architectural differences such as VoIP's reliance on IP networks versus the system-restricted nature of cellular calls. The content covers vital development tasks including the configuration of audio scene modes, the implementation of various ring modes (Silent, Vibrate, Normal), and the complex logic required for audio device switching. By utilizing specific APIs like `AudioManager` and `AudioVolumeGroupManager`, developers can manage audio states effectively and ensure proper hardware interaction. This resource is specifically suitable for application developers who need to integrate complex audio call features and must understand the underlying system audio behaviors to ensure a seamless, professional user experience across different devices and scenarios.
