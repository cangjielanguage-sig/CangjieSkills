### Detailed Description
#### cj-apis-file_statvfs.md
This document serves as the definitive API reference documentation for the `ohos.file_statvfs` module, enabling Cangjie applications to retrieve file system storage statistics efficiently. It provides a detailed breakdown of the `Statfs` class, focusing on its two primary static methods: `getFreeSize`, which is used for retrieving the number of available bytes, and `getTotalSize`, which returns the total storage capacity. The content is structured to provide both theoretical understanding and practical application.

The documentation outlines key technical information required for successful implementation, including:
*   **Method Signatures**: Precise definitions showing that methods accept a file path string as input and return an `Int64` value representing the size in bytes.
*   **System Requirements**: Essential details on system capabilities and version requirements, specifically noting support starting from API version 19.
*   **Error Handling**: Comprehensive guidance on potential `BusinessException` errors that developers might encounter during runtime.
*   **Practical Examples**: Executable code examples are included to facilitate immediate integration and testing.

This guide is specifically targeted at HarmonyOS developers utilizing the Cangjie language who need to monitor or manage file system storage space within their applications, ensuring they can handle storage constraints effectively and provide reliable functionality to end-users.
