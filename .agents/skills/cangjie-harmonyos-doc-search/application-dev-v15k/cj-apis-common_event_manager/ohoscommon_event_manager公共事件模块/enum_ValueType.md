## enum ValueType

```cangjie
public enum ValueType {
    | INT(Int32)
    | FLOAT64(Float64)
    | STRING(String)
    | BOOL(Bool)
    | FD(Int32)
    | ARRSTRING(Array<String>)
    | ARRAYI32(Array<Int32>)
    | ARRAYI64(Array<Int64>)
    | ARRAYBOOL(Array<Bool>)
    | ARRAYF64(Array<Float64>)
    | ARRAYFD(Array<Int32>)
    | ...
}
```
