This directory contains API reference documentation for the HiAppEvent module within the PerformanceAnalysisKit, specifically designed for the Cangjie programming language in the HarmonyOS ecosystem. It covers comprehensive application event tracking capabilities, including event logging, user identification, data management, and cloud reporting configuration. The documentation details static functions for setting parameters, managing watchers and processors, and handling data storage. It is suitable for HarmonyOS developers and system integrators looking to implement robust performance analysis, event monitoring, and user behavior tracking in their applications using Cangjie or ArkTS.
