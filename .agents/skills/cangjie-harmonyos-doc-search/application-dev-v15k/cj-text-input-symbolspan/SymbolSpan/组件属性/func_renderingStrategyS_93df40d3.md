### func renderingStrategy(SymbolRenderingStrategy)

```cangjie
public func renderingStrategy(value: SymbolRenderingStrategy): This
```

**功能：** 设置SymbolSpan渲染策略。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|value|[SymbolRenderingStrategy](./cj-text-input-symbolglyph.md#enum-symbolrenderingstrategy)|是|-|SymbolSpan渲染策略。<br>初始值：SymbolRenderingStrategy.SINGLE。|
