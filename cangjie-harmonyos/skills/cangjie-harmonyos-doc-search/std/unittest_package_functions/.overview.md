# unittest_package_functions

The `unittest_package_functions` directory serves as a comprehensive API reference repository for the core functions that constitute the backbone of the Cangjie language's unit testing framework. This directory is meticulously organized to assist developers in navigating the complex utilities required for building effective automated test suites. It provides in-depth coverage of assertion handling, which is crucial for verifying that code behaves as expected, alongside detailed documentation on test execution configuration and failure management protocols. Key topics explored within this directory include the usage of standard assertions such as `assertEqual` and `assertCaughtUnexpectedE`, as well as more advanced concepts like expectation-based validation and the invocation of custom assertion logic. Furthermore, it offers a unique look into the internal functions utilized for macro expansion, specifically those handling approximate equality calculations. This documentation is primarily tailored for Cangjie developers who are actively writing automated tests, framework maintainers responsible for the evolution of the testing infrastructure, and advanced users who are implementing sophisticated custom test validation logic to ensure high software quality.
