# cj-web-safe-area-insets

This directory serves as a comprehensive technical guide for managing safe area insets within web development environments, specifically targeting the complexities introduced by modern non-rectangular screens and immersive display modes. As device designs evolve with notches, punch holes, and rounded corners, ensuring that web content remains visible and interactive is crucial. This resource covers the full spectrum of adaptation strategies, ranging from fundamental front-end techniques—such as utilizing the `viewport-fit` meta tag and CSS `env()` functions—to advanced, low-level automatic calculation mechanisms inherent to the ArkWeb kernel. Key technical concepts discussed include safe areas, immersive mode, `safe-area-inset`, ArkWeb, and the Cangjie language. This documentation is essential for frontend developers and ArkWeb application developers who aim to create robust, full-screen web experiences that maintain visual integrity and usability across diverse device hardware without being obscured by system UI.

## Detailed Description

### 网页中安全区域计算和避让适配/

This subdirectory provides an in-depth introduction to the methodologies for handling safe area adaptation issues in Web development, with a particular focus on the challenges posed by non-rectangular screens and immersive modes. The content is structured to guide developers through the entire adaptation process, ensuring a seamless user experience. It begins with foundational HTML and CSS settings, detailing the correct usage of `viewport-fit` and the `env()` function to manually reserve space for system UI elements like status bars and navigation bars.

Moving beyond manual styling, the documentation explores the sophisticated automatic calculation mechanisms provided by the ArkWeb kernel. It explains how the system handles insets at a lower level, reducing the manual burden on developers while ensuring precision. Core keywords highlighted throughout this section include safe area, immersive mode, `env()`, `safe-area-inset`, ArkWeb, and Cangjie. This documentation is highly suitable for frontend developers and ArkWeb application developers who need to implement full-screen Web layouts and ensure that critical content remains visible and unobstructed by system UI elements, ultimately leading to a more polished and professional application interface.
