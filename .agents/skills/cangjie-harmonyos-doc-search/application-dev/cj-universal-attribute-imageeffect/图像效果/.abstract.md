This directory contains API references and code examples for applying visual effects to UI components within the ArkUI framework using the Cangjie language. It covers a wide range of image manipulation techniques, including color adjustments like contrast, brightness, saturation, and hue rotation, as well as advanced effects like blurring, shadows, and blending. The resources are designed for software developers working on HarmonyOS applications who need to enhance the visual presentation and styling of their interfaces. It includes both theoretical API documentation and practical implementation guides for creating high-performance, visually rich user experiences.
