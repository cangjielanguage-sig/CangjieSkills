# class_JSArrayBuffer

This directory contains API reference documentation for the `JSArrayBuffer` class within the Cangjie language environment, specifically tailored for the ArkUI Napi framework. It focuses on the mechanisms for handling generic raw binary data buffers, offering functionalities to read raw bytes and transform them into various typed arrays such as Float32, Float64, and Int16/32/64. Furthermore, it details the conversion of these buffers into ArkTS JSValue representations to ensure seamless interoperability. This documentation is suitable for HarmonyOS developers engaged in cross-language data manipulation who need to bridge Cangjie and ArkTS code effectively.

## Detailed Description

### class_JSArrayBuffer_13more.md class_JSArrayBuffer_13more.md
This document provides API reference documentation for the Cangjie JSArrayBuffer class, designed to handle generic raw binary data buffers within the ArkUI Napi framework. It covers the class definition, the read-only byteLength property, and multiple conversion methods. Key functionalities include reading raw bytes into Cangjie arrays and transforming data into specific typed arrays like Float32, Float64, and Int16/32/64. Additionally, it details methods to convert these buffers into ArkTS JSValue representations for interoperability. The documentation targets developers working on cross-language data manipulation in HarmonyOS applications, requiring knowledge of Cangjie and ArkTS.

### func_toInt64ArrayJSValue_12more.md func_toInt64ArrayJSValue_12more.md
This API reference document details Cangjie functions for converting data into various typed arrays and their ArkTS JSValue representations. It covers conversion methods for signed and unsigned integer types, including Int8, Int64, UInt8, UInt16, UInt32, and UInt64, as well as Uint8ClampedArray. Key information includes the distinction between functions returning native Cangjie arrays (e.g., Array<Int8>) and those returning ArkTS JSValue objects (e.g., BigInt64Array). All functions require the SystemCapability.ArkUI.ArkUI.Napi capability starting from version 19. This documentation is intended for HarmonyOS developers using the Cangjie language to interface with ArkTS via NAPI.
