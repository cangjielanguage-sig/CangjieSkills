This directory provides a comprehensive set of API reference documents for initializing and configuring dialog and popup components using the Cangjie language within the ArkUI framework. It covers the essential function signatures, system capabilities, and version requirements (starting from API version 19). The content details extensive parameters for layout, appearance, interaction, and visual styling, including background blur, border configuration, and dismissal callbacks. It also addresses specific constraints like mutual exclusivity between background styles and logic for intercepting dismissal actions. This resource is designed for Cangjie developers and UI engineers looking to create highly customizable modal or non-modal interfaces with precise control over visual properties and user interaction logic.
