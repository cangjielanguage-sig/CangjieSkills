# 开发步骤

This directory provides a comprehensive technical guide for developing video recording functionality using the Cangjie language, focusing on the integration of CameraKit and MediaKit APIs. It covers the complete development pipeline, starting from the initial setup involving module imports and the creation of data handling Surfaces using AVRecorder. The guide progresses to establishing video output streams, emphasizing the critical requirement of matching aspect ratios to prevent visual distortion. Furthermore, it details the operational lifecycle of recording, including the retrieval of output configurations and the strict management of start and stop sequences to ensure data integrity. Key technical elements include the use of MP4 and AVC formats, resolution consistency checks, and specific method calls like `getInputSurface` and `createVideoOutput`. This documentation is specifically designed for application developers and software engineers working on multimedia applications who require a deep understanding of Cangjie syntax and camera API integration to implement robust video capture features.

## Detailed Description

The following files provide step-by-step technical instructions for implementing video recording features.

### 开发步骤_1.md
This technical tutorial outlines the initial steps for developing video recording functionality using CameraKit and MediaKit APIs in the Cangjie language. The guide covers three sequential procedures: importing necessary modules, creating a Surface via AVRecorder to handle data, and establishing the video output stream using supported profiles. Key takeaways include the requirement to match the aspect ratio of preview and recording streams to prevent distortion and the use of specific methods like getInputSurface and createVideoOutput. Intended for application developers, this document serves as a practical guide for setting up camera recording pipelines.

### 开发步骤_2.md
This technical guide details the implementation steps for video recording functionality using the Cangjie language's CameraKit and MediaKit. It covers retrieving video output configuration, initiating the recording process, and stopping the recording session. The code demonstrates configuring AVRecorderProfile with MP4 and AVC formats, ensuring resolution consistency between VideoProfile and AVRecorderConfig, and strictly adhering to the start and stop sequence order. Specifically, recording starts by activating the video output before the recorder, while stopping reverses this order. This guide is intended for application developers working on multimedia features who require knowledge of Cangjie syntax and camera API integration.
