## Detailed Description

### ohoscrypto加解密算法库框架/

This directory contains the API reference documentation for the `ohoscrypto` cryptographic framework, designed for the Cangjie programming language. It provides a comprehensive suite of tools for implementing security features, including symmetric and asymmetric encryption, digital signatures, key derivation, and message digests. The framework supports standard algorithms such as RSA, ECC, AES, SM2, and SHA, alongside key agreement protocols like Diffie-Hellman. It is intended for software developers and security engineers building secure applications on the HarmonyOS/OpenHarmony platform, offering detailed specifications for classes, interfaces, and utility functions within the `SystemCapability.Security.CryptoFramework`.

The content within this subdirectory is structured to assist developers in navigating the complex landscape of cryptographic implementation. It details the specific classes and interfaces required to execute operations such as data encryption and decryption, ensuring data confidentiality. The inclusion of digital signature algorithms allows for the verification of data authenticity and integrity. Furthermore, the documentation covers key derivation functions, which are essential for generating secure cryptographic keys from passwords or other secrets. By supporting a mix of international standards (RSA, AES, SHA) and local standards (SM2), the framework ensures versatility for global and region-specific applications. This makes it an indispensable resource for ensuring that applications built on the HarmonyOS/OpenHarmony platform meet rigorous security requirements.
