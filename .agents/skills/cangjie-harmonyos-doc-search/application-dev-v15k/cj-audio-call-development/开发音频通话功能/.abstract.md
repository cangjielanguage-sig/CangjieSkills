This directory provides a comprehensive technical guide for developing audio call functionality within the HarmonyOS ecosystem. It covers the essential workflow of managing simultaneous audio input and output, utilizing components like AudioRenderer and AudioCapturer. Key topics include audio stream configuration, lifecycle management, and handling voice communication scenarios. The documentation is tailored for developers building communication or VOIP applications, offering foundational knowledge on audio data flow and component integration using languages such as ArkTS or Cangjie.
