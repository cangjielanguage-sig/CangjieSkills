# cj-anm-tool

This directory serves as the repository for the technical documentation of the Advanced Notification Manager (anm) tool, a specialized command-line utility designed to facilitate the debugging and testing of notification functionalities within a complex software environment. The documentation is meticulously crafted to assist developers in navigating the intricacies of the notification system, providing clear guidance on the necessary environment prerequisites, such as the requirement for the hdc shell and an engineering (eng) build version. It offers a comprehensive overview of the tool's core capabilities, detailing the usage of three primary commands: help, dump, and setting. Key functionalities covered include the ability to print active, recent, or distributed notifications for inspection, as well as the parameters required for configuring notification cache limits and managing the enable status. This guide is an essential resource for software developers, QA engineers, and system testers who require command-line access to inspect, diagnose, and modify notification system behaviors during the development and quality assurance processes. By utilizing this tool, users can effectively isolate issues and verify the correct operation of notification delivery mechanisms.
