This directory contains comprehensive API reference documentation for the `ohos.telephony_data` module, specifically designed for the Cangjie programming language within the HarmonyOS ecosystem. It focuses on the management and monitoring of cellular data, covering essential enumerations for connection states and traffic flow, as well as the core `TelephonyData` class. Key topics include querying network status, managing SIM card information, checking roaming settings, and handling data flow directions. This documentation is suitable for Cangjie and HarmonyOS developers who need to integrate robust telephony data monitoring and control capabilities into their applications.
