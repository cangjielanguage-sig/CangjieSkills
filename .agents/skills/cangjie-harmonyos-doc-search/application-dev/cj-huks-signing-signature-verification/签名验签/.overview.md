# 签名验签

This directory provides comprehensive resources for implementing digital signatures and verification using the Universal Keystore Kit (HUKS). It covers the full cryptographic lifecycle, including key generation, data signing, signature verification, and key deletion. The documentation details various algorithms such as SM2, RSA, and ECC, alongside hashing modes like SHA256 and SM3. It is suitable for application developers on HarmonyOS or OpenHarmony systems who require secure key management and data integrity features to protect their applications.

## Detailed Description

### 开发步骤.md 开发步骤.md
This document provides a step-by-step tutorial for developers on implementing cryptographic operations using the Universal Keystore Kit. It covers four main workflows: generating or importing keys, signing data, verifying signatures, and deleting keys. The guide details specific API calls such as generateKeyItem, initSession, updateSession, finishSession, and deleteKeyItem. It explains how to configure HuksOptions with algorithm parameters and data. Targeted at application developers requiring secure key management and cryptographic functionality within their software.

### 签名验签.md 签名验签.md
This document serves as a practical guide for developers implementing digital signing and signature verification processes. It outlines four specific cryptographic examples, including SM2/SM3, RSA/SHA256/PSS, and RSA/SHA256/PKCS1_V1_5, to assist in development. Key information includes references to a separate overview document detailing supported algorithms and specific usage scenarios. The content is designed for developers requiring code examples and implementation guidance for secure data authentication, likely within a Beta phase environment.

### 开发案例/
This directory contains Cangjie code examples for implementing digital signatures using the Universal Keystore Kit (HUKS). It covers various cryptographic algorithms including ECC, RSA, and SM2, combined with different hashing and padding modes like SHA256, PKCS1_V1_5, PSS, and SM3. The examples demonstrate the complete lifecycle of cryptographic operations, from key generation and property configuration to signing, verification, and key deletion. These tutorials are suitable for developers working on HarmonyOS or OpenHarmony systems who need to integrate security features and ensure data integrity using asymmetric encryption.
