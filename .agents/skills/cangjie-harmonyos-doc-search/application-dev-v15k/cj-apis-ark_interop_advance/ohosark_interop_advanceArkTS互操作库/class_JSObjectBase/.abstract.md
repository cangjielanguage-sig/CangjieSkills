This directory provides comprehensive API reference documentation for the `JSObjectBase` class and associated functions within the Cangjie programming language. It is specifically tailored for HarmonyOS developers working with the ArkUI Napi system to facilitate interoperability between Cangjie and ArkTS (JavaScript) environments. The documentation covers essential operations such as binding Cangjie instances to JavaScript references, invoking methods, defining property accessors, and inspecting object properties. Developers will find detailed parameter tables, return value specifications, and practical code examples. This resource is ideal for those needing to bridge native logic with JavaScript, requiring a solid understanding of both Cangjie syntax and JavaScript object models.
