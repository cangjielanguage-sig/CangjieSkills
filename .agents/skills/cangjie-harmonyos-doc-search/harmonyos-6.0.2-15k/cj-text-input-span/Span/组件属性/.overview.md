# 组件属性

This directory contains API reference documentation for component properties within the Cangjie ArkUI framework, focusing specifically on text styling and visual effects. It covers a wide range of attributes including typography settings (font size, weight, family), text positioning (baseline offset, line height), and decorative elements (shadows, backgrounds). The documentation provides function signatures, parameter descriptions, and system capability requirements. It is suitable for UI developers and software engineers using the Cangjie language to build and customize the visual appearance of text components in ArkUI applications.

## Detailed Description

### func_baselineOffsetLength_6more.md func_baselineOffsetLength_6more.md
This document serves as API reference documentation for text styling functions within the Cangjie ArkUI framework. It covers methods for modifying text appearance, including baselineOffset for vertical positioning, decoration for line styles, and font for comprehensive typography settings. Additional functions include fontColor and fontFamily for color and typeface management. Key information highlights that baselineOffset coexists with parent settings and impacts ImageSpan alignment, while the font function supports comma-separated font lists. All methods return This to facilitate fluent interface design. Intended for UI developers, this guide requires familiarity with Cangjie syntax and ArkUI components to effectively customize text spans and visual layouts.

### func_fontSizeLength_6more.md func_fontSizeLength_6more.md

This reference is intended for developers using the Cangjie language to configure text appearance and layout in ArkUI applications.

### func_textShadowFloat64_Sha_3more.md func_textShadowFloat64_Sha_3more.md
This API reference document details functions for configuring text visual effects, specifically shadows and background styles within the ArkUI framework using the Cangjie language. It covers two overloaded textShadow functions—one accepting individual parameters like radius, offset, and color, and another accepting an array of ShadowOptions for multiple shadows—alongside the textBackgroundStyle function. Key information includes parameter definitions for radius, offsetX, offsetY, and color, with specific notes on unit conversion (px) and version 19 compatibility. The document targets developers seeking to implement advanced text styling, highlighting system capabilities and constraints such as the lack of support for fill fields in array-based shadows.
