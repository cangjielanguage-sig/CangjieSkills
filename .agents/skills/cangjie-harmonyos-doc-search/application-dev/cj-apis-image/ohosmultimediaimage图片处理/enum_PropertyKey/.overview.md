# enum_PropertyKey

This directory contains API reference documentation for the `PropertyKey` enum within the Cangjie framework's Multimedia.Image.Core module. It focuses on defining, reading, and modifying image metadata properties, such as EXIF data, camera settings, and geolocation information. The documents cover specific property keys, required data formats for modification, and code examples for the `imageSource.modifyImageProperty` method. This resource is suitable for developers working on multimedia image processing applications who need to programmatically handle image metadata starting from system version 22.
