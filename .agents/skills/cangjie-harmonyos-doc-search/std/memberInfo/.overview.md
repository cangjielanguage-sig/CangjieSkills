### memberInfo.md memberInfo.md

This document serves as a practical tutorial demonstrating how to utilize reflection to access and manipulate class member information in the Cangjie programming language. It provides a step-by-step approach to understanding the reflection API, making it easier for developers to integrate these features into their own projects.

The content focuses on retrieving `TypeInfo` objects to inspect `instanceVariables` and `instanceFunctions`. By mastering these concepts, developers can create more adaptable and introspective applications. The guide explains the specific methods required to query type information effectively.

Key takeaways include using `getValue` and `setValue` to dynamically read and modify property values, as well as checking function return types at runtime. The example uses a `Rectangular` class to show how changing variable values affects method execution results. This guide is intended for Cangjie developers who have basic knowledge of the language syntax and wish to implement runtime type inspection or dynamic behavior.

**Why this is useful:**
Understanding reflection allows for the creation of flexible frameworks and libraries that can operate on objects without knowing their exact types at compile time. This tutorial provides the foundational skills necessary to build such dynamic systems in Cangjie.
