# application-package-glossary

This directory serves as a comprehensive reference resource for HarmonyOS developers, specifically focusing on the terminology associated with application packages and the Stage model architecture. It provides a structured glossary that defines critical concepts necessary for understanding how applications are built, packaged, and deployed within the HarmonyOS ecosystem. The content covers a range of package types, including the main HAP bundle, static HAR shared packages, and dynamic HSP shared packages. Furthermore, it details architectural components such as UIAbility and ExtensionAbility, alongside structural concepts like Modules and the Stage model itself. Introduced in API version 9, the Stage model represents a significant evolution in application architecture, and this glossary helps developers navigate its core components. This directory is suitable for software engineers and developers who require precise definitions and clarification on packaging formats and component structures during the development lifecycle. By providing clear definitions, it aids in reducing ambiguity and ensuring consistent understanding of technical terms across development teams.

## Detailed Description

### application-package-glossary.md

This document functions as an essential glossary that defines key terminology specifically related to HarmonyOS application packages and the Stage model architecture. The content is meticulously organized in alphabetical order, covering specific entries that start with the letters E, H, M, S, and U to facilitate easy navigation. Among the key topics covered are various package types such as HAP, HAR, and HSP, as well as architectural components including UIAbility and ExtensionAbility, and fundamental structural concepts like Module and the Stage Model. The text clearly distinguishes between static shared packages (HAR) and dynamic shared packages (HSP), while also defining the HAP as the primary application bundle used for distribution. Furthermore, it provides an explanation of the Stage model which was introduced in API version 9, highlighting its core components designed for User Interface (UI) and specific system extensions. This reference material is primarily targeted at HarmonyOS developers who need clarification on packaging formats and component definitions during the various stages of application development.
