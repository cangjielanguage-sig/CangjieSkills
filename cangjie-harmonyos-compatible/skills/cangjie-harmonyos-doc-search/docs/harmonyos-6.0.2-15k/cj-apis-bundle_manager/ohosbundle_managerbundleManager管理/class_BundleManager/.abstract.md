This directory contains API reference documentation for the Cangjie language's `BundleManager` class, specifically designed for HarmonyOS development. It covers methods for querying application bundle information, retrieving metadata, and verifying URL accessibility. Key topics include `getBundleInfo`, `canOpenLink`, and profile retrieval for abilities and extension abilities. The documentation includes parameter definitions, return types, error codes, and code examples. It is suitable for HarmonyOS developers using Cangjie and the AbilityKit who need to programmatically access application configuration files like `module.json5` and manage bundle information.
