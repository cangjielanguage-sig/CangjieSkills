This directory provides API reference documentation for the `ohos.telephony_data` module in Cangjie, designed for managing cellular data within the HarmonyOS telephony system. It covers key functionalities such as monitoring connection states, tracking data flow types, retrieving default SIM card details, and verifying roaming status. The content includes enumerations for network status and comprehensive class references for querying cellular configurations. It is intended for Cangjie developers and HarmonyOS engineers who need to implement mobile data features, handle system permissions, and monitor telephony subsystem states in their applications.
