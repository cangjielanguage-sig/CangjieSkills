This directory serves as the central repository for API documentation regarding the `cj-apis-componentsnapshot` module, specifically detailing the `ohos.component_snapshot` functionality within the Cangjie UIKit framework. It is designed to support developers in the implementation of high-fidelity screenshot capabilities for UI components. The content provides in-depth guidance on capturing images from various element states, including both loaded and unloaded components, ensuring versatility in application design. It thoroughly explores configuration options for scaling and rendering synchronization, alongside distinct methods for asynchronous, synchronous, and off-screen rendering. This documentation is highly suitable for HarmonyOS and ArkUI developers utilizing the Cangjie language who require precise image capture features, need to manage complex visual effects, or must strictly control component rendering boundaries within their software solutions. By leveraging these APIs, developers can enhance user experience through robust visual data handling and reporting features.
