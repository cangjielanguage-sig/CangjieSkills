# 应用链接说明

This directory serves as a comprehensive guide for developers working on HarmonyOS or OpenHarmony applications who need to implement and configure application links. It focuses specifically on the `uris` tag within the `module.json5` configuration file, which is crucial for handling application URI matching, routing, and deep linking. The documentation covers essential technical aspects such as defining schemes, hosts, ports, and various path matching rules (path, pathStartWith, pathRegex). Additionally, it explains the `linkFeature` attribute, which allows applications to register for specific system capabilities like Navigation, FileOpen, Login, and Pay, enabling features such as one-click return. This resource is suitable for mobile application developers and system integrators looking to facilitate cross-application interactions and enhance user experience through seamless linking and authentication flows.
