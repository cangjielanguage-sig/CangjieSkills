# class_Calendar

This directory contains API reference documentation for the Calendar class and related event management functions within the Cangjie programming language's CalendarKit framework. It covers essential operations such as creating, deleting, retrieving, and updating calendar events, as well as managing account details and configurations. Key topics include the Calendar class instantiation, batch operations, and event filtering. This documentation is suitable for developers working with the SystemCapability.Applications.CalendarData system capability who need to integrate robust calendar management features into their applications.
