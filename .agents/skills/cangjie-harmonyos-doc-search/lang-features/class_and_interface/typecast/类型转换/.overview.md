本文档旨在介绍仓颉编程语言中用于类型检查与转换的 `is` 和 `as` 操作符。文档详细说明了 `is` 操作符如何判断表达式运行时类型并返回布尔值，以及 `as` 操作符如何执行类型转换并返回 `Option` 类型以处理可能的转换失败。通过包含类继承关系的代码示例，展示了这两个操作符的具体用法及返回值逻辑。这是一份面向仓颉开发者的语言特性教程，适合需要掌握类型安全机制的开发者阅读。关键词：仓颉、is操作符、as操作符、类型检查、类型转换、Option类型。
