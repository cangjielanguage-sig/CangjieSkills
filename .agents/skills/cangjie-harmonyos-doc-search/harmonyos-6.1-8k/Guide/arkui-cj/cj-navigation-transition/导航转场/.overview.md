# 导航转场

本目录汇集了关于应用导航转场与页面管理的开发指南。内容涵盖了使用 Cangjie 语言和 ArkTS 框架创建导航子页、管理路由栈以及实现页面间跳转与转场效果。核心知识点包括 NavDestination 组件、NavPathStack 路由管理、页面布局配置及参数传递。这些文档适合具备基础语法的 HarmonyOS 应用开发者，旨在帮助构建层级清晰、交互流畅的用户界面。

## 详细描述

### 创建导航子页.md
本文档旨在指导开发者使用Cangjie语言创建并管理导航子页。文档详细介绍了两个子页（PageOne和PageTwo）的实现步骤，涵盖了NavDestination组件的使用、NavPathStack路由栈的初始化及页面跳转逻辑。核心要点包括在onReady生命周期中获取当前页面栈，利用pop方法实现页面返回，以及通过pushPath方法配合NavPathInfo实现页面间的参数传递与跳转。该教程适用于具备Cangjie基础的开发者，用于构建具有层级导航功能的用户界面。

### 导航转场_2more_c0dc14ec_1.md
本文档旨在介绍如何使用ArkUI组件实现页面间的导航转场效果。文档主要涵盖导航转场的定义、推荐使用的Navigation与NavDestination组件，以及创建导航页的具体实现步骤。核心内容包括通过NavPathStack管理路由栈，结合List组件和pushPath方法实现页面跳转，并提供了基于Cangjie语言的完整代码示例。该文档适用于使用Cangjie语言开发ArkUI应用的开发者，需具备基础组件开发知识。

### 导航转场_2more_c0dc14ec_2.md
本文档作为技术指南，介绍如何使用 ArkTS 声明式 UI 框架在 HarmonyOS 应用中实现导航转场。内容侧重于页面布局构建，详细说明了如何配置组件尺寸和背景样式以支持转场效果。关键要点包括使用 .size(width: 100.percent, height: 100.percent) 设置全屏尺寸，以及通过 .backgroundColor(Color.White) 应用白色背景。本文档适用于 HarmonyOS 移动应用开发者，假设读者具备 ArkTS 语法和 UI 组件结构的基础知识。
