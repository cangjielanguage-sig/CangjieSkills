### 使用_import_语法加载仓颉三_2more_09b1cc03.md 使用_import_语法加载仓颉三_2more_09b1cc03.md
这份文档是一份技术教程，旨在指导开发者在 ArkTS 工程中使用 import 语法加载存在依赖关系的仓颉三方库。文档主要涵盖通过 cjpm.toml 配置库依赖、编写仓颉互操作代码、在 ArkTS 侧创建类型声明文件（.d.ts）及配置 oh-package.json5 等步骤。关键信息包括如何建立项目目录结构、声明依赖路径、注册 JSModule 以及实现最终的导入调用。该文档适合需要实现 ArkTS 与仓颉跨语言互操作的开发者，重点在于处理多库依赖的配置与集成流程。

### 方案三三方库_B_作为一个模块编译成_har_包.md 方案三三方库_B_作为一个模块编译成_har_包.md
本文档是一份技术教程，旨在指导开发者将仓颉三方库 B 编译为 HAR 包模块，供仓颉三方库 A 依赖并最终在 ArkTS 中调用。主要内容包括创建仓颉静态库模块、配置 oh-package.json5 和 cjpm.toml 依赖关系、在 package_a 中实现 JS 互操作接口、编写 ArkTS 类型声明及最终调用代码。关键信息涉及仓颉与 ArkTS 的互操作机制、动态库编译及跨语言模块依赖管理。适用于进行 ArkTS 与仓颉混合开发的开发者，需具备基础的项目构建和依赖配置知识。

### 方案二三方库_B_作为三方库_A_的子包.md 方案二三方库_B_作为三方库_A_的子包.md
本文档介绍了在ArkTS工程中，如何将三方库B作为三方库A的子包进行集成，实现仓颉与ArkTS的互操作。主要内容包括创建嵌套的仓颉包目录及源码文件、在ArkTS侧添加仓颉模块、编写TypeScript类型声明文件、配置oh-package.json5和cjpm.toml依赖路径，以及在ArkTS代码中导入调用。关键点在于通过package_a.package_b的包名结构实现子包引用，利用JSModule注册接口，并通过配置文件将仓颉动态库与ArkTS类型声明关联，确保ArkTS能正确调用嵌套的仓颉接口。本指南面向需要在ArkTS项目中集成复杂仓颉三方库结构的开发者，适用于多包依赖管理的互操作场景。
