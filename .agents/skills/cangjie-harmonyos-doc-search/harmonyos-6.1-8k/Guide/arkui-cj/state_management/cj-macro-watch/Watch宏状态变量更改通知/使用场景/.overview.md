# 使用场景

本目录主要介绍ArkUI框架中@Watch装饰器的实际应用场景与交互机制。内容涵盖了@Watch与@Link装饰器的配合使用、父子组件间的状态同步、ArrayList数据变化监听以及基于changedPropertyName的精细化状态管理。通过具体的代码示例，展示了如何利用@Watch实现自定义组件更新、列表渲染及条件逻辑判断。本文档适合具备ArkUI基础状态管理知识的开发者，旨在帮助用户深入理解响应式更新逻辑并提升UI开发效率。

### Watch和自定义组件更新_2more_903a6d7e.md Watch和自定义组件更新
本文档旨在阐述ArkUI中@Watch装饰器与自定义组件更新的交互机制，重点讲解其与@Link装饰器的配合使用。文档主要包含两个代码示例：一是演示父组件@State变量变更如何触发子组件@Link变量的@Watch回调，从而更新子组件状态并重绘UI；二是展示观察ArrayList类型@Link变量时，如何通过回调计算总价并驱动ForEach列表更新。关键要点涵盖了状态变更传播、回调执行时机及异步渲染流程。这是一份面向ArkUI开发者的技术教程，适合具备基础状态管理知识的用户学习组件响应式更新逻辑。

### 使用changedPropertyName进行_a054136e.md 使用changedPropertyName进行
本文档旨在演示如何在ArkUI的@Watch装饰器函数中，根据状态变量变化执行差异化逻辑。文档通过Cangjie代码示例，展示了如何利用辅助变量判断触发源，从而仅在特定变量（如apple）变化时更新关联数据（fruit）。内容详细阐述了状态变量变更、回调函数调用及UI重渲染的完整流程。该文档适合掌握ArkUI基础的开发者，用于学习精细化状态管理与条件渲染的实现技巧。
