# cj-param-tool

本目录包含 param 工具的使用指南，旨在帮助开发人员通过命令行高效管理 OpenHarmony 标准系统的系统参数。文档内容涵盖了从环境准备（如使用 hdc 工具连接设备）到核心命令操作的完整流程，详细解析了 ls（查看参数）、get（获取值）、set（设置值）、wait（等待匹配）和 save（持久化保存）等关键指令。此外，还介绍了模糊匹配、超时设置等高级参数选项。该文档适合具备基本命令行操作知识、需要进行系统调试或参数配置的开发人员参考。
