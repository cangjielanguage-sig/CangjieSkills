# cj-app-linking-startup

This directory serves as a comprehensive startup guide for implementing App Linking within the HarmonyOS ecosystem, specifically tailored for developers utilizing the Cangjie language. It addresses the critical need for secure inter-app navigation and deep linking capabilities. The content spans the complete development lifecycle, beginning with the initial configuration steps in AppGallery Connect (AGC) and moving through to the client-side implementation in DevEco Studio. Furthermore, it provides essential insights into domain verification, handling incoming link requests, and troubleshooting common integration or routing conflicts. This resource is highly suitable for developers responsible for creating either the calling (source) or target applications, ensuring seamless connectivity and user experience across different software components.

### 使用App_Linking实现应用间跳转/

This directory provides comprehensive resources for HarmonyOS developers to implement App Linking, enabling secure inter-app navigation and deep linking. It covers the entire development lifecycle, including configuration in AppGallery Connect (AGC), client-side setup in DevEco Studio, and implementation using the Cangjie language.

The content is structured to guide developers through the complexities of linking applications. It starts with the backend configuration in AGC, moves to the IDE setup in DevEco Studio, and proceeds to the coding phase where the Cangjie language is utilized to write the linking logic. Key topics include domain verification, a crucial step for security, and the technical handling of incoming links to ensure proper routing.

Additionally, the directory addresses troubleshooting common integration issues. It is suitable for developers working on both the calling (source) and target applications, providing the necessary context for either side of the link. It is also an invaluable resource for those needing to debug connectivity problems or resolve routing conflicts that arise during development or testing.
