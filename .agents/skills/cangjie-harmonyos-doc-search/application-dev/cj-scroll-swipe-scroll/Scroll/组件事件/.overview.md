# 组件事件

This directory contains comprehensive API reference documentation for handling component events within the ArkUI framework, specifically utilizing the Cangjie language. The content primarily focuses on scroll event handling, equipping developers with the necessary tools to intercept, modify, and monitor scroll behaviors with high precision. Key topics covered include frame-based offset interception, edge effect detection, and the observation of scroll states before and after movement occurs. This documentation is highly suitable for UI developers and system architects who aim to implement custom scroll mechanics, manage nested scrolling scenarios, and ensure robust control over user interactions and boundary effects in their applications.

## Detailed Description

### func_onScrollFrameBeginOnS_2more.md func_onScrollFrameBeginOnS_2more.md
This document provides API reference documentation for scroll event handling within the ArkUI framework using the Cangjie language. It covers two main functions: `onScrollFrameBegin`, which allows developers to intercept and modify scroll offsets at the start of each frame, and `onScrollEdge`, which triggers when the scroll position reaches a boundary. Key information includes specific trigger conditions, such as the exclusion of controller calls for frame begin events, and the requirement to disable edge effects for nested scrolling implementations. The content is intended for developers seeking granular control over scroll behavior and edge detection in their applications.

### func_onWillScrollFloat64_F_3more.md func_onWillScrollFloat64_F_3more.md
This document provides API reference documentation for scroll event handling functions within the Cangjie ArkUI framework. It details three specific functions: two overloads of `onWillScroll` (one returning `OffsetResult`, one returning `Unit`) and `onDidScroll`. The `onWillScroll` functions trigger before scrolling, allowing developers to either modify the scroll offset or observe the intended movement and state. The `onDidScroll` function reports the actual offset during scrolling. All functions handle horizontal and vertical offsets, scroll states, and sources, triggered by user input, API calls, or boundary rebounds. This reference is intended for UI developers using the Cangjie language to implement custom scroll behaviors and event monitoring.
