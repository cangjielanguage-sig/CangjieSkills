This directory serves as a definitive technical guide for the HUKS (HarmonyOS Universal Keystore) key attestation mechanism, a critical security component used to validate the legitimacy of asymmetric public keys stored in hardware. The documentation explains how to leverage PKI certificate chains to establish trust in cryptographic keys. It provides a thorough overview of the attestation workflow, detailing the step-by-step process for certificate chain generation and the specific algorithm specifications required for implementation. Key topics include the structural composition of certificate chains, the formatting of key owner information for HAP apps and system services, and the use of OIDs to verify key origin (whether generated or imported). Additionally, the guide specifies that anonymous attestation is supported for third-party applications and lists compatible algorithms like RSA, ECC, and SM2 for API level 15+. This resource is specifically designed for developers focused on implementing secure key verification, though it does not address emulator or lightweight device scenarios.
