This directory contains technical guides and tutorials focused on interoperability between ArkTS and Cangjie within the HarmonyOS ecosystem. It covers methods for operating Cangjie objects in ArkTS, specifically detailing Custom Functions, JSClass, and JSExternal approaches. Key topics include SharedObject definitions, JSModule registration, TypeScript declarations, and performance optimization techniques like `attachCJObject`. These resources are designed for HarmonyOS developers who need to integrate Cangjie backend logic with ArkTS frontend code, ensuring efficient data access and secure cross-language object manipulation.
