This directory hosts the API reference documentation for the Blank component, a fundamental UI element within the ArkUI framework designed for the Cangjie programming language. The documentation focuses on the component's ability to automatically fill remaining space along a container's main axis, a critical feature for creating responsive and adaptive layouts. It provides in-depth details on component creation via the `init` function, including the configuration of the `min` parameter, and explores styling options such as the `color` attribute. Additionally, it defines strict usage constraints, ensuring the component functions correctly only within specific parent containers like Row, Column, or Flex. This resource is indispensable for Cangjie developers who need to implement flexible spacing, push elements to the edges of a container, or manage alignment within linear layouts. By explaining the logic behind automatic stretching and size calculation (max(min, size)), it empowers developers to build robust and dynamic user interfaces.
