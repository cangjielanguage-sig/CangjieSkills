This directory contains essential API reference documentation for the `BundleManager` class as implemented in the Cangjie language for HarmonyOS development. It serves as a comprehensive technical guide for developers looking to interact with the system's bundle management layer, covering tasks such as querying bundle information, checking URI scheme capabilities, and extracting JSON configuration profiles. The documentation details specific static methods including `canOpenLink`, `getBundleInfoForSelf`, and `getProfileByAbility`, providing complete function signatures, parameter definitions, return value specifications, and error handling via `BusinessException`. Furthermore, it includes practical code examples to assist in implementation. This content is specifically tailored for HarmonyOS application developers who require programmatic access to application metadata and bundle resources to build robust, system-integrated applications.
