# 传感器开发指导

This directory provides a comprehensive guide for sensor module development, currently in Beta, focusing on enabling applications to access device sensor data. It covers essential topics such as scenario introductions, API interface descriptions, sensor categorization (periodic vs. instantaneous), and step-by-step development tutorials using the Cangjie language. Key concepts include accelerometer models, data monitoring (`on`, `once`), and listener management. This resource is suitable for application developers looking to integrate hardware sensor capabilities, understand reporting behaviors, and manage system permissions effectively.

## Detailed Description

### 传感器开发指导_3more.md 传感器开发指导_3more.md
This document acts as a development guide for the sensor module, currently in Beta, designed to help applications access device sensor data. It covers two main sections: scenario introduction and interface description. The scenario section explains use cases such as detecting device orientation or tracking user steps. The interface section details key API functions, including on for continuous data monitoring, once for single data retrieval, off to unregister listeners, and getSensorList to query available sensors. This guide is intended for developers needing to integrate hardware sensor capabilities into their applications, providing a clear overview of available methods and their specific parameters.

### 备注_2more.md 备注_2more.md
This document provides supplementary notes on sensor development, establishing that implementation follows the accelerometer model. It categorizes sensors into two distinct types based on data collection: periodic sensors, which output data at fixed intervals like AMBIENT_TEMPERATURE and GRAVITY, and instantaneous sensors, which report data only upon specific trigger events, such as PEDOMETER and PROXIMITY. Additionally, the document references a sample code repository for retrieving sensor information. This guide is designed for developers seeking to understand sensor reporting behaviors and implement sensor functionalities effectively.

### 开发步骤.md 开发步骤.md
This document provides a step-by-step tutorial for developing sensor applications using the Cangjie language, utilizing the accelerometer as a primary example. It covers five key stages: importing necessary modules, querying supported sensor parameters, configuring required permissions, registering data listeners, and canceling active listeners. The guide details the usage of on() for continuous monitoring and once() for single events, explaining sampling period constraints and their impact on power consumption. It also distinguishes between periodic and instantaneous sensor behaviors. Intended for application developers, this guide requires basic knowledge of the Cangjie syntax and system permission management.
