This directory provides comprehensive API reference documentation for the `ohos.net.networkSecurity` module within the Cangjie development environment. It focuses on the critical aspects of network security, specifically the handling, encoding, and verification of digital certificates. The documentation covers essential enumerations for data representation, classes for encapsulating certificate blobs, and functions for validating certificates against system or custom Certificate Authorities (CAs). This resource is designed for software developers and system architects who are implementing secure network communication features and require a deep understanding of certificate management structures and verification processes in Cangjie.
