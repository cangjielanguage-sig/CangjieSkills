This directory provides a comprehensive technical guide for developers utilizing the Cangjie language to integrate the ASSET API for robust data protection. It specifically addresses the critical needs of financial applications by detailing how to secure sensitive information, such as user passwords and credit card numbers, through mandatory user authentication. The content covers the complete development lifecycle, including querying, adding, deleting, updating, and retrieving data, while emphasizing a security-first approach. It explains a specific workflow where accessing plaintext data triggers a strict identity verification process, utilizing biometrics or lock screen passwords to ensure authorized decryption. This guide is an essential resource for developers focused on building secure, high-trust applications that manage confidential financial data, ensuring compliance with rigorous security standards and protecting user privacy against unauthorized access in a digital landscape.
