# 使用

This directory serves as a comprehensive technical resource for HarmonyOS developers utilizing the Cangjie language, focusing specifically on the practical usage and integration of HAR (Harmony Archive) packages. It provides detailed instructions on how to configure project dependencies to consume shared libraries effectively within a development environment. The content covers critical aspects of modular development, including how to import and utilize Cangjie components, classes, and methods, as well as how to access specific resources like strings and images defined within a HAR module using the `@r` syntax. With practical code examples and clear architectural guidance, these documents are essential for developers aiming to build modular, maintainable applications by leveraging external libraries and efficient resource management in the HarmonyOS ecosystem. This section is suitable for both beginners learning about package integration and experienced developers optimizing their modular architecture.

## Detailed Description

### 使用_3more.md 使用_3more.md
This technical guide instructs developers on configuring dependencies and utilizing Cangjie components, classes, and methods from a HAR package within HarmonyOS projects. The document covers two main topics: referencing HAR Cangjie components and referencing HAR classes and methods. Key takeaways include the prerequisite of configuring HAR dependencies and the use of the import statement to access exported elements, illustrated through practical Cangjie code examples for UI integration and function calls. Intended for HarmonyOS developers using the Cangjie language, this guide facilitates the integration of shared libraries into application modules.

### 引用HAR的资源.md 引用HAR的资源.md
This document provides a technical tutorial for developers on how to reference resources located in a HAR module using the Cangjie language. The main topic focuses on the `@r` syntax for accessing string and image resources defined in the HAR's `src/main/resources` directory. Key information includes the specific code implementation showing how to use `@r(app.string.hello_har)` for text and `@r(app.media.icon_har)` for images within an Entry module's UI components. This guide is intended for HarmonyOS developers working with modular architecture and resource management in Cangjie.
