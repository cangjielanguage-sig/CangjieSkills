# 组件内转场transition

本目录提供了ArkUI框架中关于组件内转场（transition）的完整API参考文档，基于仓颉（Cangjie）语言编写。内容涵盖了组件插入和删除时的过渡动效配置，包括缩放、平移、旋转等变换参数的定义，以及TransitionEffect转场效果的详细说明。此外，还包含具体的代码示例，帮助开发者实现平滑的UI交互体验。该文档适用于使用仓颉语言进行ArkUI应用开发，希望掌握组件显隐动画及3D变换效果的开发人员。

### class_ScaleOptions.md class_ScaleOptions.md
本文档是ArkUI框架中Cangjie语言的ScaleOptions类API参考文档，旨在定义组件的缩放参数。文档涵盖了该类的核心属性，包括控制X、Y、Z轴缩放比例的x、y、z变量，以及设定变换中心点（锚点）坐标的centerX和centerY变量。此外，详细说明了构造函数的参数配置，如缩放倍数的正负值含义及中心点的默认单位。该文档面向ArkUI应用开发者，提供了实现组件缩放变换所需的具体参数定义和配置方法。

### class_TranslateOptions_03494c87.md class_TranslateOptions_03494c87.md
这是一份Cangjie语言的API参考文档，详细说明了TranslateOptions类的定义及其在ArkUI中用于配置组件平移参数的功能。文档主要包含类定义、x/y/z轴平移距离属性说明以及构造函数参数详解。关键信息指出属性类型为可空Length，单位为vp，取值范围无限，且构造函数支持命名参数并默认为0.0.vp。该文档面向ArkUI应用开发者，需具备Cangjie基础语法知识，适用于系统版本22及以上。

### enum_TransitionEdge_dbb26a84.md enum_TransitionEdge_dbb26a84.md
这份API参考文档详细定义了ArkUI框架中用于描述窗口边缘的TransitionEdge枚举类型。文档涵盖了枚举成员定义（Top、Bottom、Start、End）及其在LTR和RTL布局下的具体含义，以及继承自Equatable的相等与不相等运算符。关键点在于Start和End边缘会根据布局方向动态变化，且该接口自版本22起可用，具备完整的ArkUI系统能力。文档面向使用仓颉语言进行UI开发的程序员，旨在帮助其精确控制窗口边缘相关的过渡或布局逻辑。
