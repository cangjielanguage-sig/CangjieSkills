# 构建第一个仓颉与ArkTS混合应用

This directory provides a comprehensive guide for HarmonyOS developers on building applications that integrate the Cangjie programming language with ArkTS. It covers the complete development lifecycle, including project creation using the Hybrid Ability template, understanding the specific directory structure, and configuring the runtime environment for real devices or emulators. The tutorials detail how to construct pure ArkTS pages and hybrid pages that embed Cangjie components, as well as implementing complex page navigation logic across languages. Suitable for developers with basic knowledge of ArkTS and Cangjie looking to master mixed-language development in the HarmonyOS ecosystem.

## Detailed Description

### 仓颉与ArkTS混合工程目录结构.md
This document outlines the standard directory structure for HarmonyOS projects that integrate both Cangjie and ArkTS programming languages. It details the project tree layout, specifically focusing on the entry module which houses separate directories for Cangjie source code, ArkTS source code, and interoperability dependencies. Key information includes the specific roles of configuration files like cjpm.toml for Cangjie package management, module.json5 for module configuration, and the organization of resources and build scripts. This reference guide is intended for HarmonyOS developers who need to understand the architectural layout and file organization required to build mixed-language applications effectively.

### 使用真机或模拟器运行应用.md
This tutorial instructs developers on running HarmonyOS applications, specifically Cangjie and ArkTS hybrid projects, using DevEco Studio. The document is divided into two main sections: running on a local real device and running on an emulator. Key takeaways include the necessity of configuring automatic signing with a Huawei account for real devices and the requirement to modify the build-profile.json5 file to include x86_64 in abiFilters when using x86 emulators, as the default architecture is arm64-v8a. This guide is intended for developers setting up their runtime environment to test and validate their applications.

### 构建第一个仓颉与ArkTS混合应用_2more.md
This tutorial guides HarmonyOS developers through building their first hybrid application using Cangjie and ArkTS languages to understand the project structure and development workflow. The document details the project creation process within DevEco Studio, specifically focusing on selecting the "[Cangjie] Hybrid Ability" template and configuring project settings. Key takeaways include the distinction between hybrid and pure Cangjie templates and the steps to generate sample code for a simple page navigation app. Intended for developers with basic knowledge of Cangjie, ArkTS, and UI frameworks, this guide provides a quick start to mixed-language development.

### 构建第一个页面纯ArkTS页面.md
This tutorial provides a step-by-step guide for building a basic user interface page using pure ArkTS. It covers two main topics: utilizing text components to display content and adding button components to enable user interaction and page navigation. Key takeaways include understanding layout structures using RelativeContainer, Row, and Column, as well as implementing state management with the @State decorator. The document features code examples for the Index.ets file, demonstrating component styling and alignment. It is designed for developers beginning HarmonyOS application development who need to understand fundamental ArkTS UI construction and component properties.

### 构建第二个页面ArkTS与仓颉混合页面.md
This tutorial guides developers through creating a hybrid page combining ArkTS and Cangjie languages in a HarmonyOS application. It covers creating a Cangjie component file, setting up the ArkTS container page, and configuring the routing in main_pages.json. Key information includes the concept that Cangjie pages function as components embedded within ArkTS @Entry pages using CJHybridComponentV2. The document details the file structure, including the auto-generation of wrapper files, and provides code examples for both second.cj and second.ets. This guide targets HarmonyOS developers working on mixed-language development projects.

### 实现页面间的跳转/
This directory provides comprehensive technical guidance on implementing page navigation between ArkTS and mixed ArkTS-Cangjie pages within HarmonyOS applications. It addresses the specific challenge where ArkTS and Cangjie routers are not interoperable, requiring developers to utilize Cangjie-ArkTS interop macros and global HashMaps for function registration. The content covers essential scenarios, including navigating forward using the standard router module and navigating back from a Cangjie component. Furthermore, it details the necessary project directory structures, TypeScript interface declarations, and dependency configuration in oh-package.json5. This resource is specifically designed for developers building cross-language hybrid applications using HarmonyOS ArkUI and Cangjie who need to effectively manage routing logic and lifecycle events across different language components.
