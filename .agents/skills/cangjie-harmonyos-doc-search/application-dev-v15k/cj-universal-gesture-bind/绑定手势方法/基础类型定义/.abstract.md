This directory serves as the foundational reference for type definitions used in gesture handling within the ArkUI framework, specifically implemented using the Cangjie language. It encompasses the essential building blocks required to construct and manage user interactions, ranging from basic touch coordinate tracking to complex gesture masking rules. Key components include the `GestureType` base class, `EventTarget` for display area management, and specific enums for controlling event propagation. By defining the core properties and behaviors of touch inputs, this module provides the necessary infrastructure for developers to build responsive and interactive user interfaces. It is highly suitable for UI developers, system architects, and engineers working on the underlying logic of gesture recognition systems who need a deep understanding of data structures, type constraints, and the initialization of gesture-related objects.
