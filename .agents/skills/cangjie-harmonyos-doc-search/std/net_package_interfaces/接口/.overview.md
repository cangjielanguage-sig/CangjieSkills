# 接口

This directory contains API reference documentation for core network socket interfaces within the Cangjie programming language. It covers the essential components required for implementing network communication protocols, including server-side connection handling, stream-based data transmission, and packet-oriented messaging. Key topics include socket lifecycle management, blocking operations, address configuration, and exception handling. These resources are designed for Cangjie developers and network engineers seeking to build robust, low-level networking solutions, requiring a solid understanding of I/O streams and resource management principles.

## Quick Navigation

**What do you want to do?**
- Manage server-side connections and accept incoming requests → interface_ServerSocket.md
- Establish duplex, stream-based connections for ordered data transfer → interface_StreamingSocket.md
- Implement connectionless, packet-based communication (UDP) → interface_DatagramSocket/

## Detailed Description

### interface_ServerSocket.md interface_ServerSocket.md
This document provides the API reference for the ServerSocket interface in the Cangjie language, designed to facilitate server-side socket operations. It details the interface structure, which inherits from Resource and ToString, and outlines key members including the localAddress property and methods like bind and accept. The documentation explains the blocking behavior of connection acceptance, supports timeout configurations, and lists potential exceptions such as SocketException and SocketTimeoutException. Intended for Cangjie developers, this guide serves as a technical resource for implementing network communication protocols, requiring an understanding of socket programming and error management.

### interface_StreamingSocket.md interface_StreamingSocket.md
This document provides API reference documentation for the StreamingSocket interface in the Cangjie programming language, defining a duplex socket for stream-based network communication. It details the interface definition, inheritance hierarchy from IOStream and Resource, and specific properties including localAddress, remoteAddress, readTimeout, and writeTimeout. Key information includes the socket's ability to bind and connect, its use of buffering for ordered byte transmission without guaranteed packet boundaries, and blocking behavior for read/write operations. The text also outlines exception handling for socket states and invalid timeout values. This technical reference targets Cangjie developers implementing network protocols or managing socket connections, requiring prerequisite knowledge of I/O streams and resource management.

### interface_DatagramSocket/
This directory provides essential API reference documentation for the `DatagramSocket` interface within the Cangjie programming language's standard library. It focuses on packet-based network communication, specifically detailing the implementation of connectionless protocols like UDP. The documentation covers the structural definition of the socket interface, its inheritance hierarchy from Resource and ToString, and essential properties such as local and remote addresses. Furthermore, it provides in-depth technical specifications for blocking data transmission functions, including `receiveFrom` and `sendTo`, along with parameter types, return values, and exception handling strategies for socket errors and timeouts. This resource is indispensable for Cangjie developers and network engineers looking to implement robust, low-level networking solutions, manage socket lifecycles, and handle data flow with precision.
