### clean_1636135b.md clean_1636135b.md

### init_4more_59a861ec.md init_4more_59a861ec.md
本文档是仓颉包管理器（cjpm）的命令参考指南，旨在指导用户进行项目初始化与依赖管理。文档详细介绍了 init、check、update 和 tree 四个核心命令的功能与参数配置。init 用于创建模块或工作空间；check 用于验证依赖顺序及检测循环依赖；update 用于生成或更新 cjpm.lock 锁文件；tree 用于可视化展示包的依赖关系。每个部分均包含具体的使用示例和选项说明。这是一份面向仓颉开发者的技术参考文档，帮助用户掌握构建工具的基础操作和依赖分析技巧。

### install.md install.md
这份文档详细介绍了仓颉包管理器中 `install` 命令的功能与用法，旨在编译并将仓颉可执行项目安装到指定路径。文档主要涵盖了命令的多种配置选项（如 `--path`、`--git`、`--root`、`--name`）以及使用时的注意事项。关键信息包括支持本地路径和 Git 仓库两种安装方式、默认安装路径规则、动态库依赖处理及同名文件覆盖机制。该文档属于参考指南，面向仓颉开发者，帮助其掌握项目构建、部署及产物管理流程。

### run_1c538d39.md run_1c538d39.md
这份文档详细说明了 `cjpm run` 命令的功能与用法，旨在帮助开发者运行项目构建出的二进制产物。文档涵盖了命令的核心功能，即默认执行构建流程后运行程序，并列举了关键配置项，包括指定二进制名称、跳过编译、透传运行参数、运行调试版本及控制日志输出等。通过具体示例展示了如何结合构建参数与运行参数使用。这是一份面向使用 `cjpm` 工具的开发者的参考文档，重点在于掌握灵活控制构建与运行流程的参数配置。

### uninstall_caf44316.md uninstall_caf44316.md
本文档介绍了仓颉项目管理工具中 `uninstall` 命令的用法，用于卸载项目及清除相关文件。主要涵盖了必需参数 `name`、可选参数 `--root` 的配置，以及不同操作系统下的默认路径规则。关键信息包括支持批量删除、默认路径差异、同时清理 `bin` 和 `libs` 目录，以及 Windows 平台不支持中文路径的注意事项。该文档属于命令参考指南，面向需要管理已安装仓颉组件的开发者。
