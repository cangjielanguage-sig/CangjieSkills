This directory provides comprehensive API reference documentation for extending the `Int64` type within the Cangjie programming language. It specifically focuses on the implementation of the `ThrowingOp` and `ThrowingPow` interfaces, which are designed to handle arithmetic operations through a rigorous exception-throwing mechanism. Unlike standard operations that might silently wrap around on overflow, these functions throw specific exceptions like `OverflowException` or `OvershiftException` to ensure data integrity. The documentation covers a wide range of functions, including basic arithmetic, negation, power calculations, and bitwise shifts. This resource is essential for Cangjie developers who prioritize robust error handling and explicit exception management in high-stakes numerical computations to prevent silent data corruption and ensure program stability.
