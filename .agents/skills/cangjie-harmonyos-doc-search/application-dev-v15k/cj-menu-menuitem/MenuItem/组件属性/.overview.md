# 组件属性

This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on menu items. It covers essential styling and state management features, including font customization (size, weight, color), label appearance, selection icon configuration, and selection state logic. The documentation details function signatures, parameters, default values, and system capabilities required for implementation. Suitable for HarmonyOS developers using the Cangjie language, these resources provide the technical specifications needed to build and customize user interface components effectively.

## Detailed Description

### func_contentFontLength_Fon_3more.md func_contentFontLength_Fon_3more.md
This document provides API reference documentation for configuring the font style and color of menu item content in the Cangjie ArkUI framework. It details two overloaded functions for setting font properties (size, weight, family, style) and one function for setting font color. The documentation covers parameter definitions, default values, and data types like Length, FontWeight, String, AppResource, and ResourceColor. Key takeaways include the distinction between using a String or AppResource for the font family parameter, the default font being "HarmonyOS Sans," and the requirement that the color function accepts a ResourceColor type. All functions are available starting from API version 12. This reference guide targets developers using the Cangjie language to build HarmonyOS user interfaces, specifically those customizing the appearance of menu items.

### func_labelFontLength_FontW_5more.md func_labelFontLength_FontW_5more.md
This API reference document details functions for configuring the visual appearance of menu item labels and selection icons within the ArkUI framework. It covers overloaded methods for labelFont to define typography, labelFontColor for text color, and selectIcon for managing selection state visuals. Key information includes support for both string and resource-based font families in labelFont, defaulting to 16.vp size, and the ability to toggle default checkmarks or set custom icons using selectIcon. All functions require SystemCapability.ArkUI.ArkUI.Full. This guide targets HarmonyOS developers using the Cangjie language to customize menu component behaviors and styles.

### func_selectedBool.md func_selectedBool.md
This API reference document details the selected function in the Cangjie language, designed to set the selection state of a menu item. The document covers the function signature, system capability requirements, version compatibility, and parameter specifications. Key information includes that the function accepts a required Boolean parameter value, where true marks the item as selected and false leaves it unselected, with an initial default state of false. The function returns the current object instance to allow method chaining. Intended for ArkUI developers using Cangjie, this document serves as a technical guide for implementing menu item selection logic in user interfaces.
