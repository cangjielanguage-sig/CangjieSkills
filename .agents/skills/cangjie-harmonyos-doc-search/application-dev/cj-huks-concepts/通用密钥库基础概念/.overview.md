# 通用密钥库基础概念

This directory serves as a comprehensive educational resource for developers and security engineers working with the General Key Store (HUKS). It provides a deep dive into fundamental security concepts, specifically elucidating the architecture and benefits of the Trusted Execution Environment (TEE) for securing sensitive data. Beyond conceptual security, it offers rigorous technical specifications regarding the data formats of cryptographic key materials, including byte-level layouts and encoding standards for algorithms like RSA, ECC, and DSA. This documentation is suitable for professionals who require a solid grasp of hardware isolation, key management implementation, and the structural intricacies of cryptographic storage to build secure applications.

## Detailed Description

### 通用密钥库基础概念_2more.md 通用密钥库基础概念_2more.md
This document serves as a conceptual guide for developers preparing to use the General Key Store, outlining fundamental security concepts necessary for application development. The primary section covers the Trusted Execution Environment (TEE), detailing its role within mobile device processors. Key information includes the definition of TEE as a secure area for storing and processing sensitive data, supporting "Trusted Applications" by ensuring protection, confidentiality, integrity, and access control. The document targets application developers who need a foundational understanding of security environments before integrating the General Key Store, noting that the current version is in Beta.

### 密钥材料格式/
This directory provides comprehensive technical specifications for the data formats used in cryptographic key materials within the HUKS system. It covers the structural definitions for public keys, private keys, and key pairs across various algorithms like RSA, ECC, and DSA. The documentation details byte-level layouts, X.509 DER encoding standards, and specific implementation examples using the Cangjie language. It is designed for developers and security engineers who need to implement secure key management, import/export processes, or low-level cryptographic storage mechanisms.
