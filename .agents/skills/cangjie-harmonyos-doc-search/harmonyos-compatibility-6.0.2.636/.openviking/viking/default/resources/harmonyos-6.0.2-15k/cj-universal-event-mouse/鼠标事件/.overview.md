# 鼠标事件

This directory provides comprehensive documentation for handling mouse events within the ArkUI framework using the Cangjie language. It covers the fundamental `MouseEvent` class definition, the specific implementation of the `onMouse` callback function, and practical code examples for building interactive user interfaces. Key topics include event properties such as timestamps, screen and relative coordinates, button states, and action types, alongside reactive state management techniques using decorators like `@State`. This resource is designed for application developers and UI engineers working on HarmonyOS applications who need to capture and process mouse input effectively to create responsive and interactive user experiences.

## Detailed Description

### 基础类型定义.md 基础类型定义.md
This API reference document defines the MouseEvent class used for handling mouse interactions within the ArkUI framework using the Cangjie language. It details the class constructor and seven public properties, including timestamp, screen coordinates, component-relative coordinates, mouse button, and action type. Key information includes that all properties are readable and writable, utilizing types like Int64 and Float64, with specific enums for button and action. The class requires SystemCapability.ArkUI.ArkUI.Full and is available starting from version 12. This guide targets application developers implementing mouse event handling in their UI components.

### 示例代码.md 示例代码.md
This document provides a practical Cangjie code example demonstrating mouse event handling within a HarmonyOS application UI. The main topics include implementing the onHover event to dynamically change button text and color, and utilizing the onMouse event to capture detailed input data such as button type, action type, and coordinate positions. Key information highlights the use of the @State decorator for reactive UI updates and accessing event properties like local and screen XY coordinates. Intended for Cangjie developers, this example serves as a tutorial reference for building interactive user interfaces and managing component states.

### 鼠标事件_3more.md 鼠标事件_3more.md
This API reference document details the implementation and usage of mouse event handling within the ArkUI framework using the Cangjie language. It covers general event behavior, permissions, and specifically defines the `onMouse` function signature, system capabilities, and parameters. Key information includes that the `onMouse` function triggers on clicks or movement, accepting a callback with a `MouseEvent` object containing timestamps, button states, and screen or relative coordinates. The document notes that only external mice are currently supported and events are transparent by default. This is intended for developers building UI components who need to handle user input via mouse interactions.
