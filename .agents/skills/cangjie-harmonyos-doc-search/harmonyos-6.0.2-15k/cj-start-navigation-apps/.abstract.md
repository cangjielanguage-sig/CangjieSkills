This directory is a specialized technical resource designed for HarmonyOS developers utilizing the Cangjie language to build or integrate navigation capabilities. It centers on the `startAbilityByType` interface, a critical component for invoking navigation application extension panels. The documentation provides an in-depth look at the entire implementation lifecycle, covering both the calling application (which requests map services) and the target application (which provides them). Key technical areas include route planning logic, navigation execution, location search functionalities, and the precise configuration of parameters using the GCJ-02 coordinate system. Additionally, it details the necessary `module.json5` setup. With practical Cangjie code examples for constructing JSON parameters, managing callbacks, and parsing incoming requests, this guide is essential for developers seeking to enable robust map interactions or allow their apps to serve as map providers within the HarmonyOS ecosystem.
