# 设备无法识别

本目录包含针对HDC工具无法识别设备问题的故障排查指南。内容涵盖Windows系统下的驱动修复、注册表清理、端口冲突排查，以及Linux系统下的USB设备权限配置。核心关键词包括HDC连接、Windows驱动、注册表、Linux权限、udev规则及端口冲突。该文档适用于HarmonyOS/OpenHarmony开发人员及技术支持人员，旨在帮助他们快速定位并解决因物理连接、驱动损坏或软件配置导致的设备无法识别障碍。

## 详细描述

### 设备无法识别_1.md 设备无法识别_1.md
这份文档是一份故障排查指南，旨在解决HDC工具无法识别设备（即hdc list targets返回空列表）的问题。文档涵盖四种主要情况：设备管理器未显示HDC设备、Windows驱动损坏、守护进程通信失败及服务器连接失败。关键信息包括跨平台USB检查、Windows驱动重装步骤、端口冲突排查及注册表清理方案。该指南适用于HarmonyOS/OpenHarmony开发人员，帮助他们快速定位并解决物理连接或软件配置导致的连接障碍。

### 设备无法识别_2.md 设备无法识别_2.md
本文档是一份针对设备无法识别问题的故障排除指南，旨在帮助用户解决Windows和Linux系统下的设备连接故障。文档主要分为两个部分：Windows系统下通过注册表编辑器定位特定USB类驱动路径，修改并清空UpperFilters键值以修复驱动问题；Linux系统下解决非root用户运行hdc无法找到设备的问题，提供了临时和永久修改USB设备权限的方法，并强调了权限设置的安全风险。本文适合开发人员或技术支持人员参考，关键词包括注册表、USB驱动、权限管理和udev规则。
