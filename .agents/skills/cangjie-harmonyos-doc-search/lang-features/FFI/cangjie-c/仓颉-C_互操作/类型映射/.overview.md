# 类型映射

本目录详细介绍了仓颉语言与 C 语言进行互操作（FFI）时的类型映射规则与内存管理机制。内容涵盖了基础数据类型、结构体、指针、数组及字符串的映射方式，以及如何使用 `sizeOf`、`alignOf` 等工具函数获取内存布局信息。文档重点讲解了 `@C` 修饰符、`CPointer` 类型及 `unsafe` 块的使用，旨在帮助开发者在保证类型安全和内存一致性的前提下，高效调用 C 语言库或进行底层系统编程。适合需要深入理解仓颉与 C 交互细节的开发者阅读。

## 详细描述

### sizeOfalignOf_fc528e6b.md
这份文档介绍了仓颉语言中用于C互操作的两个核心函数：sizeOf和alignOf。文档详细说明了这两个泛型函数的声明，它们分别用于获取符合CType约束的类型的内存占用大小和内存对齐数值，返回类型均为UIntNative。通过一个包含@C结构体的代码示例，文档演示了如何在64位机器上计算并输出特定数据结构的内存布局信息。这是一份API参考文档，主要面向需要进行底层内存操作或与C语言进行交互的开发者，帮助他们准确掌握数据类型的物理存储特性。

### 基础类型_2more_e32f20bc.md
本文档旨在阐述仓颉语言与C语言在基础数据类型及结构体上的映射规则，以支持两者间的互操作。主要内容包括基本类型映射表（涵盖Unit、数值类型及Native类型）以及结构体映射机制。文档详细说明了如何使用`@C`修饰符定义与C结构体对应的仓颉结构体，并列举了相关的限制条件（如成员类型约束、禁止泛型等）。关键信息在于确保类型内存布局一致，并正确使用`foreign func`声明外部函数。这是一份面向仓颉开发者的技术参考指南，适用于需要调用C语言库或进行底层交互的场景。

### 指针.md
本文档介绍了仓颉编程语言中用于与C侧指针交互的CPointer类型，涵盖其定义、不安全操作及类型转换。主要内容包括映射C函数（如malloc）、在unsafe块中进行内存读写与偏移计算、判空操作，以及CPointer间的类型转换和从CFunc到CPointer的转换。关键点在于CPointer的泛型参数需满足CType约束，且读写等操作属于不安全行为，必须在unsafe块中调用以避免未定义行为。这是一份面向需要进行底层内存管理或与C库交互的开发者的技术参考文档。关键词：仓颉、CPointer、FFI、unsafe、内存管理、类型转换。

### 数组_2more_443b76b4.md
本文档主要介绍仓颉语言与 C 语言互操作时数组和字符串的处理机制。文档分为两部分：一是 `VArray` 类型的使用，详细说明了其作为函数参数需 `inout` 修饰、作为结构体成员需内存布局一致，并指出不支持柔性数组；二是 `CString` 类型的定义与操作，列举了 `size`、`compare` 等成员函数及内存管理方法。这是一份技术参考文档，旨在指导开发者正确处理仓颉与 C 之间的数据映射，适用于具备 C 语言基础的开发人员。
