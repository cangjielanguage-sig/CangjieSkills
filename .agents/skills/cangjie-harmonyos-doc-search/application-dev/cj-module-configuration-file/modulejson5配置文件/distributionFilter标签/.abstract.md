This directory provides comprehensive technical documentation for the `distributionFilter` tag within the HarmonyOS development ecosystem. It focuses on enabling developers to implement precise HAP (HarmonyOS Ability Package) distribution strategies by filtering based on specific device hardware capabilities and regional settings. Key topics include screen shape, window dimensions, pixel density, and country codes. These resources are specifically designed for HarmonyOS developers building multi-module applications who require granular control over cloud distribution. By utilizing these configuration guides, developers can ensure that the correct application variants are delivered to the appropriate target devices, optimizing user experience and resource management across diverse hardware profiles like smart wearables and tablets. The documentation also addresses complex scenarios such as overlapping device types and attribute consistency requirements.
