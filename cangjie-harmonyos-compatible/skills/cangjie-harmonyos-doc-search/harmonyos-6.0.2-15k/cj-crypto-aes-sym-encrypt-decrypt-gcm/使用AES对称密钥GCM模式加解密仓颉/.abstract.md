This directory contains technical guides for implementing AES symmetric encryption and decryption using the GCM mode in the Cangjie programming language. It covers the complete cryptographic workflow, including key generation, cipher configuration, data processing, and authentication tag handling. Key topics include AES128, GCM, PKCS7 padding, and the usage of the CryptoArchitectureKit. These resources are designed for Cangjie developers who need to integrate secure cryptographic operations into their applications, providing both theoretical steps and practical code examples for handling data securely and efficiently.
