This directory provides a comprehensive quick adaptation guide intended for developers utilizing the ArkUI framework and the Cangjie programming language to build user interfaces. The primary focus of this documentation is to facilitate the integration of system password auto-fill services, a critical feature for modern application security and usability. It details the specific constraints and InputType attributes required for various user interaction scenarios, such as employing USER_NAME for login interfaces and NEW_PASSWORD for registration flows. The guide highlights that developers can enable the password vault's auto-fill and save functionalities simply by setting the type property on standard TextInput controls, avoiding the need for complex custom implementations. Included within the document are practical Cangjie code examples that demonstrate exactly how to configure these components. This resource is ideally suited for software engineers and developers tasked with creating authentication screens who need to leverage native system-level password management features efficiently and correctly.
