This directory contains comprehensive API reference documentation for the Cangjie programming language's BundleManager framework within the HarmonyOS/OpenHarmony ecosystem. It covers essential classes, enumerations, and modules used for managing application bundles, metadata, permissions, and system capabilities. Key topics include bundle information retrieval, ability configuration, window management, and extension types. The documentation is intended for Cangjie developers and system integrators who need to programmatically access and manipulate application lifecycle, permissions, and component states. It provides the structural definitions and functional interfaces required for robust system-level application development.
