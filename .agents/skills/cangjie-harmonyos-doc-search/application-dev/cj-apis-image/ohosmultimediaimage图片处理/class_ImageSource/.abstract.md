This directory provides API reference documentation for the Cangjie `ImageSource` class within the ImageKit framework. It covers essential image processing tasks, including decoding images into PixelMaps, retrieving metadata, and managing animated image properties. Key functionalities include incremental data updates, Exif manipulation, and memory management. The documentation highlights critical usage constraints such as thread safety and manual resource release. It is intended for Cangjie developers working on multimedia applications who require efficient image data handling, decoding, and property modification capabilities.
