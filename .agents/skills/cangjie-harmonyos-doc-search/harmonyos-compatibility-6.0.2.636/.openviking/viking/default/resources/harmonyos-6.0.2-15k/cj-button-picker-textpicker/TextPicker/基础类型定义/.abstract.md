This directory contains API reference documentation for fundamental data structures and classes used in the ArkUI framework with the Cangjie language. It primarily focuses on type definitions for various picker components, including text, cascade, and range selectors. The content covers configuration parameters, selection result handling, and event callbacks, distinguishing between current and deprecated implementations. Key topics include `TextPickerOptions`, `TextPickerRangeContent`, and selection parameter classes. This documentation is suitable for software developers and UI engineers building interactive selection interfaces in Cangjie who need to understand data models and component configuration within API versions 12 and 19.
