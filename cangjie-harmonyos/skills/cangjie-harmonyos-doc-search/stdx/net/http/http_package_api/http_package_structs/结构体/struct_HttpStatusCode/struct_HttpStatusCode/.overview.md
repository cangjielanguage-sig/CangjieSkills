## 详细描述

### struct_HttpStatusCode_1.md
本文档定义了 Cangjie 语言中的 HttpStatusCode 结构体，用于标准化表示 HTTP 协议响应状态的三位数字代码。主要内容涵盖了从 1xx 信息响应到 5xx 服务器错误的所有标准状态码常量，如 200 OK、404 Not Found 等。关键信息在于所有常量均为 public static const 类型的 UInt16，提供了完整的 HTTP 状态码枚举值。该文档属于 API 参考资料类型，适用于需要处理 HTTP 请求与响应的 Cangjie 语言开发者。

### struct_HttpStatusCode_2.md
本文档旨在依据RFC 9110及相关扩展规范，定义并解释HTTP状态码的分类标准。文档主要涵盖了状态码的五大类别：1xx（信息）、2xx（成功）、3xx（重定向）、4xx（客户端错误）和5xx（服务器错误），并详细阐述了各类别所代表的请求处理状态及通信含义。关键信息指出，状态码的首位数字直接决定了响应的五种基本状态之一。这是一份技术参考文档，主要面向开发人员和网络工程师，旨在帮助其准确理解HTTP协议中的响应语义。关键词包括HTTP状态码、RFC 9110、响应分类、协议规范。
