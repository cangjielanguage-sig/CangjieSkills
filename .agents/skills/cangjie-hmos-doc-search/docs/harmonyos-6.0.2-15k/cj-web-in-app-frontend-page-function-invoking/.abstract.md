This directory contains a specialized technical tutorial designed for Cangjie developers working on hybrid application architectures. It focuses specifically on the mechanisms required to invoke frontend JavaScript functions directly from the native application side using the `WebviewController`. The content provides an in-depth analysis of the `runJavaScript()` and `runJavaScriptExt()` methods, distinguishing their use cases, particularly regarding `ArrayBuffer` support and `AsyncCallback` result handling. By exploring how to trigger existing HTML functions and inject new scripts for dynamic page manipulation, this guide equips developers with the skills necessary to create seamless interactions between native logic and web content. It is highly suitable for software engineers utilizing the ArkWeb framework who need to implement robust, bidirectional communication channels in their applications.
