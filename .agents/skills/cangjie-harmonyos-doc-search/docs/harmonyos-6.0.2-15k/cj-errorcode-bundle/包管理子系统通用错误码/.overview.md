# 包管理子系统通用错误码

This directory contains technical reference documentation for common error codes within the Package Management Subsystem. It covers a wide range of issues related to application lifecycle management, including installation, uninstallation, updates, and configuration validation. Key topics include bundle name resolution, HAP file parsing, permission verification, distributed services, and enterprise device management restrictions. These documents provide detailed error messages, root causes, and resolution steps. This resource is suitable for software developers, system integrators, and QA engineers using DevEco Studio or working with HarmonyOS bundle management to diagnose and resolve runtime or deployment errors.

## Detailed Description

### 17700001_指定的bundleName不存在_9more.md Error Codes 17700001-17700011
This document serves as a technical reference guide for troubleshooting specific error codes encountered during application development and installation. It details eleven error codes (17700001-17700011) covering issues such as missing bundle, module, or ability names, invalid user or device IDs, empty app IDs, and HAP installation failures due to parsing or signature errors. Each entry provides the error message, description, potential causes, and specific handling steps. The target audience is software developers using DevEco Studio who need to diagnose and resolve runtime or installation errors.

### 17700012_安装包路径无效或者文件过大导致应_10more.md Error Codes 17700012-17700024
This document serves as a troubleshooting reference for specific error codes encountered during application installation, uninstallation, and management. It details errors ranging from 17700012 to 17700024, covering installation failures due to invalid paths, file size limits exceeding 4GB, insufficient disk space, version downgrades, and missing dependencies. Additionally, it addresses issues with uninstalling preinstalled apps and querying bundle information. Each entry provides the error message, description, potential causes, and specific handling steps to resolve the issue. This guide is intended for developers and system integrators working with the installer and bundleManager modules to diagnose and fix application lifecycle errors.

### 17700025_输入的type无效_9more.md Error Codes 17700025-17700033
This document serves as a technical reference guide for troubleshooting specific error codes related to application management and distributed services. It covers nine distinct error codes (17700025-17700033), detailing issues such as invalid input types, disabled bundles or abilities, distributed service failures, and Overlay feature validation failures during HAP installation. Each entry provides the error message, description, potential causes, and specific handling steps, such as checking spelling, verifying network status, or confirming system application configurations like AllowAppDataNotCleared. Targeted at developers and system integrators, this guide assists in debugging application lifecycle issues, specifically focusing on bundle management, distributed networking, and overlay module constraints.

### 17700034_指定的module是overlay_8more.md Error Codes 17700034-17700041
This document serves as a reference guide for troubleshooting specific installation and uninstallation errors, ranging from code 17700034 to 17700041. It details issues related to overlay modules, shared library permissions, dependencies, and enterprise device management restrictions. Each entry provides the error message, description, potential causes, and specific handling steps, such as configuring the AllowAppShareLibrary privilege or using correct parameters for shared bundles. It is intended for developers and system administrators diagnosing application deployment failures.

### 17700042_数据代理中的uri配置错误_8more.md Error Codes 17700042-17700050
This document serves as a troubleshooting reference for resolving specific HAP installation and management errors in HarmonyOS development. It details nine distinct error codes (17700042-17700050), covering data proxy configurations (URI, permissions), multi-process isolation modes, enterprise device management restrictions, version update conflicts, and code signature verification failures. Each entry provides the error message, description, root causes, and step-by-step resolution instructions, emphasizing configuration alignment and system constraints. Targeted at application developers and system administrators, this guide helps diagnose and fix installation failures related to security, permissions, and versioning.

### 17700051_应用自升级时安装的应用与调用方包名_8more.md Error Codes 17700051-17700202
This document serves as a troubleshooting reference guide for resolving specific application installation and configuration errors identified by error codes 17700051 through 17700202. It covers issues related to enterprise MDM distribution, debug mode restrictions, permission verification failures, invalid link schemes, and .abc file handling. Key solutions include verifying signature configurations, checking device developer mode via hdc shell, adjusting APL levels in JSON profiles, and ensuring correct URL scheme configurations in querySchemes. The target audience is application developers and QA engineers seeking to diagnose and fix HAP installation and bundle manager errors.
