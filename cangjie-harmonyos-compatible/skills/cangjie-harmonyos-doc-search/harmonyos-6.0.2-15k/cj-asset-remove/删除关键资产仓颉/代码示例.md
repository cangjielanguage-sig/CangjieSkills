## 代码示例

本模块提供了同步接口，以下为同步接口的使用示例。

删除一条别名是demo_alias的关键资产。

```cangjie
import kit.AssetStoreKit.*
import ohos.base.BusinessException

try{
    let alias: AssetParam = AssetParam.ALIAS("demo_alias".toArray())// 此处指定别名删除单条数据，也可不指定别名删除多条数据
    let remove_attr: Array<AssetParam> = [alias]
    let query_res: Array<Array<AssetParam>> = query(remove_attr)
    if(!query_res.isEmpty()){
        remove(remove_attr)
    }
} catch(e: BusinessException) {
    AppLog.error("Failed to remove Asset. Code is ${e.code}, message is ${e.message}")
}
```
