## 详细说明

### class_FileHandler.md class_FileHandler.md
本文档是Cangjie语言中FileHandler类的API参考文档，旨在指导开发者处理HTTP文件下载和上传。文档主要涵盖类定义、构造函数参数（路径、处理类型、缓冲区大小）及handle方法的功能。关键信息包括：下载模式仅支持GET请求并需指定文件路径；上传模式仅支持POST请求，需指定目录路径并使用multipart/form-data格式。文档还详细说明了不同场景下的状态码返回（如404、400、500）及异常处理机制。该文档面向需要在服务端实现文件传输功能的开发人员，提供了详细的接口使用规范和参数配置指南。

### class_FuncHandler_2more_24fa1443.md class_FuncHandler_2more_24fa1443.md
本文档是Cangjie语言HTTP包的API参考文档，详细介绍了FuncHandler和HttpContext两个核心类。文档首先说明了FuncHandler作为HttpRequestHandler接口的包装类，能够将单个函数转换为请求处理器。接着，文档定义了HttpContext类，即服务端HTTP请求上下文，涵盖了获取客户端证书、请求对象、响应构建器的属性，以及用于判断HTTP/1.1或HTTP/2连接状态的isClosed方法。这些内容旨在帮助服务端开发者理解如何封装处理逻辑及管理请求上下文，是构建Web服务的重要参考资料。

### class_HttpHeaders.md class_HttpHeaders.md
这是一份Cangjie语言中HttpHeaders类的API参考文档，主要用于表示和操作HTTP报文中的header与trailer。文档详细说明了该类继承自Iterable接口，并定义了符合RFC 9110规范的字段名和字段值规则，如字段名不区分大小写且转为小写存储。核心内容包括add、set、get、getFirst、del及iterator等方法的参数、返回值及异常处理说明。该文档面向需要处理HTTP协议数据的开发者，提供了管理HTTP头部键值对的标准接口和操作指南。

### class_HttpRespons_3more_bebf1346.md class_HttpRespons_3more_bebf1346.md
该文档是HTTP包的API参考文档，详细介绍了三个核心类的功能与用法。主要涵盖HttpResponsePusher用于实现HTTP/2服务器推送，包括获取实例和发送推送请求的方法，并明确禁止嵌套推送；HttpResponseWriter支持用户控制HTTP响应消息体的发送过程，兼容HTTP/1.1分块传输和HTTP/2，并列举了write函数的异常处理；NotFoundHandler则作为便捷的404错误处理器。本文档面向使用该HTTP库进行服务端开发的程序员，提供了具体的接口定义、参数说明及使用限制。

### class_HttpResponse.md class_HttpResponse.md
本文档是仓颉语言 `HttpResponse` 类的 API 参考文档，用于定义客户端读取 HTTP 服务器响应的接口。文档详细列出了包括响应体、状态码、头部信息及协议版本在内的核心属性，以及资源释放和字符串转换等方法。此外，还介绍了 HTTP/2.0 特有的扩展功能，如获取服务器推送响应。关键点在于响应体不支持并发读取，且提供了明确的资源管理机制。该文档面向使用仓颉 HTTP 库的开发者，要求其具备 HTTP 协议及流处理的相关知识。

### class_OptionsHand_3more_19832d68.md class_OptionsHand_3more_19832d68.md
这份API参考文档详细介绍了HTTP处理相关的三个核心类。主要内容包括用于便捷处理OPTIONS请求并返回特定Allow头的OptionsHandler，负责单客户端连接请求解析、分发及响应的抽象类ProtocolService，以及用于生成重定向响应的RedirectHandler。文档重点说明了RedirectHandler构造函数对URL非空及3XX状态码的校验逻辑，以及各Handler的handle方法实现。该文档面向使用该HTTP框架的开发者，旨在提供具体的类定义、方法参数及异常处理细节，帮助开发者实现HTTP协议交互和请求路由。

### class_WebSocketFrame_83f87bd4.md class_WebSocketFrame_83f87bd4.md
本文档是Cangjie语言中WebSocketFrame类的API参考文档，旨在定义WebSocket通信中用于读取数据的基本单元。文档详细介绍了fin、frameType和payload三个核心属性，并阐述了如何利用这些属性识别和处理分段帧（首帧、中间帧、尾帧）。关键信息包括分段帧的载荷拼接规则以及控制帧穿插时的处理注意事项。该文档面向使用Cangjie进行网络编程的开发者，要求其具备WebSocket协议基础知识。
