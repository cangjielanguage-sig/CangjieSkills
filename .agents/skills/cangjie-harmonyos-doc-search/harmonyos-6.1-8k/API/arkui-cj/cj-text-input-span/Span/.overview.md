## 详细描述

### Span_5more_c4f2be67.md Span_5more_c4f2be67.md
本文档是ArkUI框架中Span组件的API参考文档，旨在指导开发者如何使用该组件作为Text的子组件来显示行内文本。文档主要内容包括模块导入、通过init方法传入ResourceStr参数创建组件，以及组件的属性和事件支持情况。关键要点指出Span组件无子组件且不支持通用属性，仅支持onClick事件，但受限于无尺寸信息，事件对象的target属性无效。该组件目前处于Beta阶段，主要面向使用仓颉语言进行UI开发的用户，适用于需要文本块内交互的场景。

### 示例代码.md 示例代码.md
本文档旨在演示如何在仓颉语言的ArkUI框架中使用Text和Span组件的文本样式属性。主要涵盖文本装饰（如下划线、删除线）、文本大小写转换以及字符间距设置的具体代码实现。通过示例代码展示了如何配置TextDecorationType、TextCase枚举值及letterSpacing参数，以实现不同的文本视觉效果。适用于正在学习或使用仓颉语言开发HarmonyOS应用的开发者，作为UI样式开发的参考教程。

### 组件事件_2more_e03adb41.md 组件事件_2more_e03adb41.md
本文档定义了ArkUI框架中组件事件及基础类型的API参考。主要包含onClick点击事件回调函数的详细说明，以及BaseSpan抽象基类的定义。onClick函数接收可空的ClickEvent回调参数并返回当前对象，用于处理点击交互；BaseSpan作为Span组件的基类，为组件提供基础结构。两者均系统能力完整，起始版本为22。面向使用仓颉语言进行ArkUI应用开发的开发者，适用于需要实现组件点击事件处理或基于Span进行组件扩展的场景。

### 组件属性.md 组件属性.md
本文档是ArkUI框架中仓颉语言的组件属性API参考，主要用于定义文本样式。文档详细列出了包括文本装饰、字体颜色、字体家族、字号、样式、字重、字符间距及大小写在内的八个核心函数。这些函数均支持链式调用，明确了参数类型、必填项及默认值，适用于版本22及以上系统。目标受众为ArkUI开发者，旨在帮助其通过代码精确控制UI组件的文本显示效果。
