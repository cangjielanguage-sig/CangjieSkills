This directory provides a comprehensive technical overview of change observation mechanisms within the Cangjie state management system, specifically designed for ArkUI developers. It delves into the intricacies of the `@Prop` decorator, explaining how data synchronization works between parent and child components. The content covers a wide range of data types, including primitives, structs, classes, and arrays, highlighting specific behaviors such as deep observation requirements and the limitations of standard versus observed arrays. Furthermore, it addresses critical constraints regarding collection reactivity, particularly focusing on `HashSet` mutations. This resource is vital for developers aiming to master reactive programming in Cangjie, ensuring efficient state management and accurate UI updates in their applications. By understanding these rules, developers can avoid common pitfalls related to data binding and ensure their interfaces respond correctly to state changes.
