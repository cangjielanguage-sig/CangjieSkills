This directory contains API reference documentation for the `TelephonyCall` class within the Cangjie programming language, specifically designed for the TelephonyKit framework. It provides comprehensive resources for managing telephony operations, such as formatting phone numbers into standard or E.164 formats, retrieving current device call states, and launching the system dialer. The documentation covers static methods for checking voice capabilities, validating emergency numbers, and handling specific `BusinessException` error codes for invalid inputs or system failures. This content is essential for Cangjie developers building HarmonyOS applications who require robust telephony integration and need to understand system permissions and error handling mechanisms.
