# class_Session

This directory contains API reference documentation for the Cangjie `Session` class and related channel management functions used in Secure Element (SE) communication. It covers the lifecycle management of sessions with SE readers, including methods to open basic and logical channels according to the ISO 7816-4 protocol. Key topics include session handling, channel opening, error code management, and system capability requirements. This documentation is suitable for developers implementing secure element access, managing SE connections, and handling communication exceptions within the Cangjie framework.

## Detailed Description

### class_Session_6more.md class_Session_6more.md
This document provides API reference documentation for the Cangjie Session class, which manages connection sessions with Secure Element (SE) readers. It details methods for session lifecycle management, including closing sessions and channels, checking status, and retrieving the Answer To Reset (ATR) or the parent Reader instance. Key information includes system capability requirements, version 19 compatibility, and specific error codes like 3300101 for illegal state exceptions. The content targets developers implementing secure element communication who need to handle SE connections and channels within the Cangjie framework.

Key sections include parameter definitions for the Applet ID (AID) and the optional P2 byte, return values indicating a Channel instance, and a comprehensive list of BusinessException error codes. The document highlights system capabilities and version requirements. It is intended for developers implementing secure element access, providing necessary details on handling exceptions related to security, IO errors, and invalid states.
