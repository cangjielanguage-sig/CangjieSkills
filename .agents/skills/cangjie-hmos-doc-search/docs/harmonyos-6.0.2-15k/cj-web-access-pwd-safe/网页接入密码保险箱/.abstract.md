This directory serves as a comprehensive technical resource for integrating the HarmonyOS system password vault with web-based login forms via the ArkWeb component. It thoroughly covers the end-to-end functionality, detailing user flows for saving credentials and auto-filling them on subsequent visits across mobile devices and 2-in-1 devices. The documentation delves into critical technical requirements, such as the necessity of successful form submissions and page navigation to trigger saving, and the importance of keeping ArkWeb instances active. Additionally, it provides extensive specifications for designing compatible password forms based on Chromium algorithms to ensure proper system recognition. This collection is indispensable for HarmonyOS application developers and frontend engineers aiming to implement secure, user-friendly H5 login features and optimize credential management within their native applications.
