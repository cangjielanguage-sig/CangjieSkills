# 场景示例

This directory serves as a comprehensive resource for developers working with the Cangjie language within the HarmonyOS ecosystem, specifically focusing on advanced UI interactions and navigation logic. It provides practical, code-based tutorials for implementing sophisticated page transition animations and managing routing stacks effectively. The content covers essential development tasks such as configuring entry and exit animations, handling page navigation events, and defining custom visual effects like sliding and fading. By exploring these examples, developers will learn to utilize key modules like `router.pushUrl` and the `Router` class to create fluid, professional navigation experiences. This collection is highly suitable for HarmonyOS developers aiming to master the nuances of Cangjie programming and elevate the user experience of their applications through dynamic, custom-built transitions.

## Detailed Description

The following files provide specific code implementations and structural guides for the scenarios described above. Each file focuses on different aspects of the routing and animation lifecycle within the Cangjie framework.

### 场景示例_1.md
This document provides a practical tutorial for implementing page transition animations using the Cangjie language in HarmonyOS development. It focuses on utilizing the router.pushUrl capability to define transition styles. The main content includes code examples for two pages, EntryView and Page1, demonstrating how to configure the pageTransition method. Key takeaways involve using PageTransitionEnter and PageTransitionExit with RouteType.Push and RouteType.Pop to create slide effects, specifically sliding from the right or left with a 1000ms duration. The guide is intended for developers seeking to enhance user experience with custom navigation animations.

### 场景示例_2.md
This document demonstrates how to implement page routing and custom transition animations in a Cangjie-based HarmonyOS application. It covers the implementation of two components, EntryView and Page1, utilizing the Router module for navigation and the pageTransition method for visual effects. Key information includes the use of Router.push and Router.back for page stack management, alongside PageTransitionEnter and PageTransitionExit to define slide and fade animations with specific durations. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to implement inter-page navigation and animation effects.
