# 设备连接管理

This directory serves as a technical resource for managing connections between HarmonyOS devices and development environments using the HarmonyOS Device Connector (HDC). It covers critical operations such as switching between USB and wireless debugging modes, querying device lists, and managing multi-device environments. The documentation includes detailed command syntax, parameters, and troubleshooting steps for various network topologies, including local TCP and remote connections. Designed for developers and system administrators, these guides facilitate efficient debugging, automation, and interaction setup for HarmonyOS applications.

## Detailed Description

### usb调试和无线调试切换.md usb调试和无线调试切换.md
This technical reference guide outlines commands for switching between USB and wireless debugging modes. It details the `tmode` command for opening or closing network channels and the `tconn` command for establishing TCP connections via IP address. Key information includes the deprecation of `tmode usb`, the requirement for devices and PCs to share a network, and the critical warning that switching modes restarts the daemon and interrupts active USB connections. Intended for developers, this document provides syntax, parameters, return values, and usage examples for managing device connections effectively.

### 查询设备列表_3more.md 查询设备列表_3more.md
This technical reference guide explains how to manage and query connected devices using the HarmonyOS Device Connector (hdc) tool. It covers three main operations: listing connected targets, specifying target devices for command execution, and waiting for device availability. Key information includes the syntax for `hdc list targets` to retrieve device identifiers and the usage of the `-t` parameter with a unique connect-key (serial number or IP:Port) to handle multi-device scenarios. The document details command parameters, return values, and error messages. It is intended for developers or system administrators using command-line tools to debug or automate interactions with HarmonyOS devices.

### 常见连接场景/
This directory serves as a comprehensive resource for establishing and managing connections between HarmonyOS devices and development environments using the HDC tool. It addresses various connectivity scenarios, ranging from direct physical connections via USB to local network configurations using TCP, as well as complex remote setups between separate computers. The documentation provides detailed instructions on command syntax, hardware prerequisites, network parameter configuration, and troubleshooting steps. Designed for software developers and system administrators, these guides facilitate efficient device debugging, interaction setup, and remote management across different network topologies.
