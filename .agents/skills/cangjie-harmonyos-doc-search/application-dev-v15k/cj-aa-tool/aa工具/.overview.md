# aa工具

This directory contains comprehensive documentation for the "aa" (Ability Assistant) command-line tool used in the HarmonyOS development ecosystem. It covers essential operations for application lifecycle management, including launching applications, debugging, performance tuning, and executing test cases. Key topics include Stage model components (UIAbility, ServiceExtensionAbility), command syntax for `start`, `force-stop`, `test`, `attach`, and `process`, as well as troubleshooting error codes. This resource is suitable for developers, QA testers, and system integrators seeking to manage application behaviors, diagnose runtime issues, and optimize performance via the hdc shell environment.

## Detailed Description

### aa工具_4more.md
This document serves as a reference guide for the "aa" (Ability assistant) command-line tool, designed to help developers launch applications, execute test cases, and perform debugging tasks. It covers environment requirements, specifically the prerequisite of using the hdc shell environment, and provides a comprehensive list of supported commands such as start, force-stop, test, attach, detach, appdebug, and process. Key information includes the tool's support for Stage model components like UIAbility and the syntax nuances for direct command execution. The target audience is developers seeking application debugging, testing, and performance tuning capabilities within the HarmonyOS development ecosystem.

### 应用调试调优命令process.md
This document serves as a reference guide for the `aa process` command, which enables application debugging and performance tuning within an IDE environment. It details the command syntax, a comprehensive parameter list including required flags like bundle name and ability name, and optional modes for debug or performance commands. The guide also specifies return values and lists specific error codes for troubleshooting. Key information includes the requirement for custom command definitions and the option to enter the application sandbox. This technical documentation is intended for developers and system integrators seeking to diagnose or optimize application behavior.

### 强制停止进程命令force-stop_2more.md
This reference documentation outlines the usage of two specific `aa` command-line interface commands: `force-stop` and `test`. The first section details how to forcibly terminate a process using a bundleName, including syntax, return values, and error codes related to service connection or process termination. The second section covers launching the test framework, providing a comprehensive list of optional parameters such as module name, test class, and timeout settings, alongside corresponding error codes. Key takeaways include the specific syntax for execution and the handling of persistent processes or debug mode restrictions. This guide is intended for developers and testers managing application lifecycles and executing automated tests.

### 进入调试模式命令attach_3more.md
This technical reference document outlines command-line instructions for managing application debugging states using the aa tool. It details three primary commands: attach for entering debug mode, detach for exiting, and appdebug for setting, canceling, or querying the wait-for-debug state. Key parameters include the mandatory bundleName and optional flags like -p for persistent debugging across reboots. The document provides syntax, return values, and specific error codes for troubleshooting issues such as developer mode restrictions or invalid bundle names. Targeted at developers, this guide facilitates precise control over application debugging workflows on specific devices.

### aa工具错误码/
This directory contains troubleshooting documentation for error codes related to the `aa` (Ability Assistant) tool in HarmonyOS development. It covers specific scenarios such as application launch failures, visibility verification issues, and internal Ability lifecycle errors. Key topics include UIExtensionAbility failures, implicit and explicit launch mismatches, configuration errors in `module.json5`, and service connection problems. This resource is suitable for HarmonyOS developers and technical support personnel who need to diagnose and resolve runtime issues using command-line tools like `hdc` and `aa`.

### 启动命令start/
This directory provides comprehensive technical documentation for the `aa start` command within the HarmonyOS development environment. It focuses on the mechanisms required to launch Stage model application components, specifically UIAbility and ServiceExtensionAbility. The content covers a wide range of topics, including explicit and implicit startup syntax, parameter configuration, window positioning constraints, and URI scheme handling. Additionally, it addresses error codes and debugging flags essential for troubleshooting. These resources are primarily suitable for application developers and QA testers who utilize command-line interfaces to manage application lifecycles, verify component behaviors, and debug complex startup scenarios during the development and testing phases.
