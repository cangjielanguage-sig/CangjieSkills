# 示例代码

This directory serves as a comprehensive resource for Cangjie developers, providing practical code examples focused on text styling within the Cangjie UI framework. It covers fundamental and advanced typography properties, including text decoration (underline, line-through, overline), case transformations (normal, lowercase, uppercase), and letter spacing. Furthermore, it details how to manage font attributes, line height, and baseline offset for precise vertical alignment. The examples also extend into visual aesthetics, demonstrating the implementation of text background styles with custom radii and complex text shadow effects. By utilizing `Span` components, developers can learn to customize text appearance effectively. This collection is intended for those building HarmonyOS applications who are already familiar with basic UI structures like Flex and Text, offering syntax references to enhance user interface design. Core keywords include: Cangjie, Span, Text, TextDecorationType, TextCase, letterSpacing, font, lineHeight, baselineOffset, textBackgroundStyle, and textShadow.
