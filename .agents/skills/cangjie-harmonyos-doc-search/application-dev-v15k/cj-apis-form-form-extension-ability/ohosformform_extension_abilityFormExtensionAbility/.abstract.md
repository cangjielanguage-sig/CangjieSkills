This directory provides comprehensive API reference documentation for the `FormExtensionAbility` module within the HarmonyOS Cangjie framework. It covers the complete lifecycle management of form widgets (cards), including creation, destruction, refresh, and configuration updates. Key components include the `FormExtensionContext` class, specific usage restrictions regarding multimedia modules, and detailed class structures for state management. This documentation is essential for developers building form-based applications who need to implement robust widget behaviors, manage extension contexts, and adhere to system capabilities and dependencies using the Cangjie language. It serves as a critical resource for ensuring stability and performance in widget development.
