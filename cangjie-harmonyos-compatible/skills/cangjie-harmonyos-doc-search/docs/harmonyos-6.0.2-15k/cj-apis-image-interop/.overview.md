# cj-apis-image-interop

This directory contains the API documentation for the `cj-apis-image-interop` module, a specialized library designed to facilitate seamless interoperability between Cangjie PixelMap objects and ArkTS JSValue types. It comprehensively covers the `ohos.image.interop` module, detailing the technical specifications of the `JSSystemObjectInteropType` interface and the extended `PixelMap` class. The documentation highlights critical conversion methods, including the `fromJSValue` static function for creating PixelMap instances from ArkTS data and the `toJSValue` function for converting back, both of which rely on a `JSContext` for execution. This resource is essential for Cangjie developers operating in cross-language environments, providing the necessary reference material to effectively handle image data. Users should possess familiarity with ImageKit and ArkTS interop mechanisms to fully utilize the capabilities outlined in this module for robust application development and efficient data management.
