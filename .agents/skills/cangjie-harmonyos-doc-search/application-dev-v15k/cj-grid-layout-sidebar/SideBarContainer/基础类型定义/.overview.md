# 基础类型定义

This directory contains foundational type definitions essential for the Cangjie ArkUI framework, specifically focusing on the styling and configuration of UI components. It covers classes responsible for defining button attributes, sidebar divider styles, and icon management. Key concepts include layout parameters, visual customization, viewport units, and resource handling strategies. These definitions are critical for developers building user interfaces, particularly those implementing sidebar controls and navigation elements. The documentation targets software developers using the Cangjie language who require precise control over the appearance and behavior of specific UI elements within their applications.

## Quick Navigation

## Detailed Description

### class_ButtonStyle.md class_ButtonStyle.md
This API reference document outlines the ButtonStyle class, which defines the attributes for sidebar control buttons within the Cangjie ArkUI framework. The documentation focuses on the class constructor, detailing parameters for layout and appearance such as left and top margins, width, height, and icon configurations. Key takeaways include the specific default values for these dimensions and the use of viewport units (vp). Intended for software developers using ArkUI, this document provides the necessary parameters to customize the visual style and positioning of sidebar control buttons.

### class_SideBarDividerStyle.md class_SideBarDividerStyle.md
This API reference document defines the SideBarDividerStyle class used to configure the appearance of divider lines within a SideBar component in the Cangjie ArkUI framework. The content details the class structure, read-only properties including color, stroke width, and start or end margins, as well as the constructor initialization method. Key information includes default values for parameters, system capability requirements, and specific layout behaviors regarding the divider's space occupation. This documentation is intended for developers using the Cangjie language to customize UI components, specifically needing to style separators in sidebar layouts.

### class_Icons/
This directory provides technical documentation for the `Icons` class in the Cangjie language, a crucial component for developers building user interfaces in ArkUI applications. It specifically addresses the representation and management of icon types for sidebar control buttons. The documentation covers the creation and configuration of icon objects through multiple overloaded constructors, utilizing String and AppResource types to define shown, hidden, and switching states. It also outlines system capabilities, version requirements (starting from version 19), and resource error handling strategies. This resource is designed for software developers seeking to implement robust icon state management and handle application resources effectively within their UI components.
