This directory contains API reference documentation for the Cangjie Router class within the ArkUI framework. It focuses on managing page routing, navigation, and state management for HarmonyOS applications. Key topics include page stack manipulation, navigation methods like `pushUrl` and `replaceUrl`, parameter passing via JSON strings, and lifecycle management features such as back alerts. The documentation is intended for application developers using the Cangjie language to implement robust navigation logic and handle page transitions effectively in their ArkUI projects.
