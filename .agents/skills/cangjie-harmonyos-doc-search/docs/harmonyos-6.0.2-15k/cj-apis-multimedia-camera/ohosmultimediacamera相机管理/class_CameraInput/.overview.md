# class_CameraInput

This directory contains API reference documentation for the `CameraInput` class within the Cangjie programming language's CameraKit framework. It covers the management of camera device inputs, including opening devices, handling error callbacks, and managing resources. Key topics include the `open` method for secure camera activation, the `on` function for event listeners, and the `close` method for resource release. The documentation details specific error codes, system capabilities, and asynchronous callback handling. It is intended for developers building multimedia applications who need to control camera hardware lifecycles and handle security exceptions.
