# mediatool工具

This directory contains documentation for the `mediatool`, a lightweight command-line utility designed for developers to manage media library resources on a device. It covers the tool's definition, prerequisites, and usage scenarios for manipulating images and videos displayed in the system Gallery. Key topics include exporting and deleting media files, resetting the media database, and handling media URIs. The documentation is suitable for developers and technical users who need to operate media resources via the `hdc shell` environment, requiring a connected device and enabled developer mode.
