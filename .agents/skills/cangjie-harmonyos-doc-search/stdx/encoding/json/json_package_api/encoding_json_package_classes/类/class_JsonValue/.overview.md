# class_JsonValue

本目录包含 Cangjie 语言中 `encoding_json` 包内 `JsonValue` 类的 API 参考文档。`JsonValue` 是处理 JSON 数据的核心类，用于表示 JSON 数据层，支持数据解析、类型判断、类型转换及序列化操作。文档详细介绍了如何将字符串解析为 JSON 对象，以及如何在各种数据类型（如整数、布尔值、数组、对象等）之间进行安全转换。此外，还涵盖了异常处理机制（`JsonException`）和字符串序列化方法。该文档适合需要在 Cangjie 项目中进行 JSON 编码、解码和数据操作的开发者阅读。
