It covers type conversions, type checking, object binding, and data manipulation methods required for seamless interaction between Cangjie native code and JavaScript/ArkTS environments. Key topics include lifecycle management, deprecated context-based methods, and safe data handling. This documentation is suitable for HarmonyOS developers using Cangjie for ArkUI application development who need to manage cross-language data operations and ensure type safety.
