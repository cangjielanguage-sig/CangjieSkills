This directory provides comprehensive API documentation for the `GetterActionSelector` class and associated exception handling functions within a unit testing mock framework. It focuses on enabling developers to configure specific behaviors for property getter functions found within mock or spy objects. The content covers essential methods for stubbing getters, allowing users to return specific values, access synthetic fields, invoke original logic, or throw exceptions. Furthermore, it details how to manage void returns and utilize exception factories. The documentation emphasizes the use of return types like `CardinalitySelector` and `Continuation` to facilitate method chaining and set execution expectations. This reference is primarily suitable for developers writing unit tests using the Cangjie programming language who need to implement precise mocking strategies and robust error handling in their test cases.
