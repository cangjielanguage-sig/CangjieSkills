This directory provides comprehensive API reference documentation for the `WrappingOp` interface implementation specifically tailored for the `Int16` type within the Cangjie programming language. It covers a wide array of arithmetic and bitwise operations, including addition, multiplication, division, negation, increment, decrement, and bit shifting. A defining characteristic of these operations is the use of high-order truncation to manage overflow, ensuring that results wrap around safely instead of triggering runtime errors. This resource is crucial for Cangjie developers who need deterministic integer behavior, particularly in systems programming, low-level algorithm design, or performance-critical code paths where exception handling is undesirable.
