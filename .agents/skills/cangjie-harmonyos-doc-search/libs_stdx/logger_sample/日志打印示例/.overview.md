# 日志打印示例

This directory contains practical code examples and tutorials for implementing logging in the Cangjie programming language. It covers various logging implementations including JsonLogger, SimpleLogger, and TextLogger, utilizing libraries like stdx.log and stdx.logger. Key topics include structured logging, concurrent logging with spawned tasks, lazy evaluation for performance optimization, and handling complex data structures. These examples are designed for Cangjie developers seeking to integrate efficient, high-performance, and structured logging solutions into their applications.

## Detailed Description

### 日志打印示例_1.md
This document provides practical code examples for implementing logging in the Cangjie programming language, specifically focusing on the JsonLogger class. It covers the setup of JsonLogger, concurrent logging using spawn, various log levels (TRACE, DEBUG, INFO, ERROR), and lazy evaluation techniques. Key takeaways include using lambda expressions for zero-cost logging when levels are disabled, logging complex data structures like HashMaps, and capturing source code metadata. The output demonstrates structured JSON formatting. The target audience is Cangjie developers looking to integrate structured logging into their applications.

### 日志打印示例_2.md

Key takeaways include using lazy evaluation with lambda expressions for performance optimization, capturing source code metadata, and implementing custom LogValue types. The example also demonstrates concurrent logging scenarios. This tutorial is intended for Cangjie developers seeking to integrate efficient, structured logging into their applications.

### 日志打印示例_3.md
This document serves as a code tutorial demonstrating advanced logging capabilities within the Cangjie programming language. It covers essential logging practices including multi-level logging (INFO, DEBUG, ERROR, TRACE), structured key-value data logging, and concurrent execution using spawned tasks.
