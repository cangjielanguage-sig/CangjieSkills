# enum_AudioChannelLayout

This directory contains API reference documentation for the `AudioChannelLayout` enum within the Cangjie multimedia framework. It defines constants for various audio channel configurations, ranging from standard Mono and Stereo to complex surround sound setups like 5.1.2 and 9.1.6, as well as Higher Order Ambisonics (HOA) formats. Additionally, it includes utility functions for comparing layouts and converting them to strings. These resources are intended for audio software developers working on spatial audio or multichannel playback systems, requiring the `SystemCapability.Multimedia.Audio.Core` module from API version 19.

## Detailed Description

### CH_LAYOUT_5POINT1POINT2_20more.md
This document serves as an API reference defining audio channel layout constants for the Cangjie multimedia framework. It enumerates various surround sound configurations ranging from 5.1.2 to 9.1.6, including specific variations like 7.1-WIDE and First Order Ambisonics (FOA) formats such as ACN_N3D and FUMA. Key information includes that all constants belong to the SystemCapability.Multimedia.Audio.Core module and are available starting from API version 19. This reference is intended for audio software developers configuring spatial audio or surround sound playback systems.

### CH_LAYOUT_AMB_ORDER2_ACN__17more.md
This API reference document defines enumeration constants for various audio channel layouts and an inequality operator for comparing them. The content covers Higher Order Ambisonics (HOA) configurations (2nd and 3rd order with ACN_N3D, SN3D, FUMA), standard layouts (Mono, Stereo, Surround, etc.), and the `!=` operator function. Key information includes that all constants require the SystemCapability.Multimedia.Audio.Core capability and are available from version 19. This document is intended for audio software developers using the Cangjie language who need to configure or process multichannel audio streams.
