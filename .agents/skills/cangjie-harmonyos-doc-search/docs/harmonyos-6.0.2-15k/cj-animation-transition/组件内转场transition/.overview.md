# 组件内转场transition

This directory focuses on intra-component transitions within the ArkUI framework using the Cangjie language for HarmonyOS development. It comprehensively covers the implementation of animation effects for component insertion, deletion, and state changes, utilizing `TransitionEffect` properties such as opacity, rotation, and scaling. The content includes detailed API references, practical code examples for bidirectional and asymmetric transitions, and definitions of fundamental transformation types. It is specifically suitable for UI developers and software engineers seeking to create smooth, dynamic user interfaces with precise control over visual effects, animation parameters, and component geometry in modern application design.

## Detailed Description

### 示例代码.md 示例代码.md
This document provides Cangjie code examples demonstrating various implementations of component transition effects in HarmonyOS development. It covers three scenarios: using a single interface for bidirectional transitions, using distinct interfaces for appearance and disappearance via asymmetric effects, and configuring transitions for nested parent-child components. The examples utilize TransitionEffect properties like OPACITY, rotate, scale, and AnimateParam to control animation duration and curves. Targeted at developers using the Cangjie language to implement UI animations, specifically focusing on state-driven component visibility changes.

### 组件内转场transition_4more.md 组件内转场transition_4more.md
This API reference document explains how to implement intra-component transitions in ArkUI using the Cangjie language. It focuses on configuring animation effects for component insertion and deletion to enhance user experience. The main sections cover triggering conditions, such as conditional rendering or visibility changes, and three function overloads for the transition method. Key information includes the use of TransitionEffect to specify animations and an optional callback parameter to handle animation completion events. Intended for UI developers, this documentation provides the syntax and parameters necessary to apply smooth state transitions starting from system version 12.
