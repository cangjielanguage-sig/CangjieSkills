This directory contains API reference documentation for component events within the ArkUI framework, specifically utilizing the Cangjie language. It focuses on the event handling mechanisms for text input components, covering a wide range of interactions from basic content changes to complex edit state monitoring. Key topics include event callbacks for text modification, clipboard operations, cursor management, and the interception of insertion or deletion actions. This documentation is essential for developers who need to implement robust text input controls, validate user input in real-time, and manage the lifecycle of text editing within their ArkUI applications.
