# Menu

This directory provides comprehensive API reference documentation for the Menu component within the ArkUI framework, specifically tailored for developers using the Cangjie language. It covers the essential architecture of vertical menu lists, detailing component creation via the init function, supported sub-elements like MenuItem and MenuItemGroup, and necessary integration methods such as bindMenu. Furthermore, it explores advanced configuration options, including submenu expansion modes and visual property manipulation. These resources are crucial for HarmonyOS application developers seeking to build robust, interactive menu interfaces with precise control over functionality and aesthetics.

## Detailed Description

### Menu_4more.md
This document serves as API reference documentation for the Menu component, a vertical list element in the ArkUI framework. It details the component creation using the init function, supported sub-components like MenuItem and MenuItemGroup, and compatibility with general attributes and events. Key information emphasizes that the Menu cannot be used standalone and must be paired with bindMenu or bindContextMenu methods. It also explains specific width calculation rules, including default 2-grid sizing and adaptive behavior. This guide targets developers using the Cangjie language to construct user interfaces requiring menu functionality.

### 基础类型定义_2more.md
This document serves as an API reference for the SubMenuExpandingMode enum within the ArkUI framework, specifically for Cangjie language development. It details three distinct expansion styles for submenus: SIDE_EXPAND (default side expansion), EMBEDDED_EXPAND (nested expansion), and STACK_EXPAND (floating overlay). The documentation includes a deprecated getValue method and provides a practical code example demonstrating the implementation of multi-level menus using the builder parameter. This resource is intended for developers building UI components in HarmonyOS, offering system capability details and versioning information to facilitate proper menu interface design.

### 组件属性/
This directory provides comprehensive API reference documentation for defining and manipulating component properties within the ArkUI framework, specifically tailored for the Cangjie language. It primarily focuses on the Menu component, offering detailed guidance on visual customization and layout configuration. Key topics covered include text styling (such as font size, weight, family, and color), the implementation of visual dividers, border radius adjustments, and sub-menu expansion behaviors. These documents are essential resources for developers working on HarmonyOS applications who require precise control over UI element aesthetics and functionality using Cangjie syntax and resource management techniques.
