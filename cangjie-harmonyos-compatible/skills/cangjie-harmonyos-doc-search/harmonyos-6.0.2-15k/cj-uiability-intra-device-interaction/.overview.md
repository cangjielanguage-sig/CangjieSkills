# cj-uiability-intra-device-interaction

This directory provides a technical overview of intra-device interaction capabilities within HarmonyOS, specifically focusing on the Cangjie language implementation. It centers on the UIAbility component, the system's smallest scheduling unit, and guides developers through the complexities of the Stage model. Key topics include internal navigation logic, component lifecycle management, and data exchange mechanisms using the AbilityKit framework. The documentation details practical scenarios such as basic startup, launching specific pages, and retrieving return results. This resource is highly suitable for HarmonyOS developers who need to implement sophisticated component interactions, manage application processes efficiently, and ensure seamless data flow within a single device environment.

### 启动应用内的UIAbility组件/
This directory provides technical guidance on starting UIAbility components within the same HarmonyOS application. The content focuses on internal navigation logic, lifecycle management, and data exchange using the AbilityKit framework and the Stage model. It is suitable for HarmonyOS developers using the Cangjie language who need to implement complex component interactions and manage application processes effectively.
