# class_NotificationRequest

This directory contains API reference documentation for the `NotificationRequest` class within the Cangjie programming language framework. It covers the structural definition, initialization constructors, and configuration properties required to create and manage system notification requests. Key topics include notification content, IDs, badge numbers, delivery time, and deduplication logic. The documentation details system capabilities, version requirements (starting from version 12 or 19), and reserved features. It is suitable for software developers and system engineers looking to implement robust notification handling in their Cangjie applications.
