This directory provides comprehensive technical documentation for configuring the `module.json5` file in HarmonyOS and OpenHarmony development. It covers essential aspects of module properties, permissions, device compatibility, UI components, and runtime behaviors. Key topics include ability definitions, extension capabilities, metadata handling, and distribution filtering. This resource is suitable for application developers, system integrators, and software engineers seeking to structure HAP (HarmonyOS Ability Package) manifests, manage application lifecycles, and implement specific features like shortcuts, context menus, and native package integration.
