# 自动化测试框架使用指导

This directory provides comprehensive guidance for automated testing within the OpenHarmony and HarmonyOS ecosystems. It covers the Cangjie automated testing framework, including Unit Test and UI Test implementations, as well as command-line testing strategies using shell commands and the hdc tool. Key topics include environment setup in DevEco Studio, script creation, test execution workflows, and troubleshooting common UI test failures. This resource is suitable for developers and QA engineers seeking to ensure application quality through structured testing, log analysis, and component interaction automation.

## Detailed Description

### 常见问题.md 常见问题.md
This document serves as a troubleshooting guide for resolving common errors encountered during UI test case execution. It addresses three specific failure scenarios: window retrieval failures, concurrent API call restrictions, and widget existence errors. Key solutions include enabling the ArkUI test mode via a specific shell command, avoiding multi-thread or multi-process concurrency, and re-running tests when UI states change unexpectedly. The content targets developers and QA engineers using the UITest framework who need to diagnose and fix test failures based on hilog error messages.

### 自动化测试框架使用指导_3more.md 自动化测试框架使用指导_3more.md
This guide explains the usage and implementation of the Cangjie automated testing framework for OpenHarmony applications. It covers the framework overview, implementation principles for both the Unit Test framework and the UI Test framework, and their execution workflows. Key information includes the framework's composition of a Unit Test base (using std.unittest and TestRunner) for case execution and reporting, and UiTest for UI automation and component interaction. Scripts run via TestRunner, generating XML reports stored on the device. It targets developers and testers using the Cangjie language on the OpenHarmony platform.

### 基于Cangjie编写和执行测试/
This directory serves as a comprehensive resource for developers aiming to implement automated testing using the Cangjie language within the OpenHarmony and HarmonyOS development environment. It systematically guides users through the entire testing process, beginning with the prerequisite setup of DevEco Studio. The documentation covers the creation of robust test scripts, including unit tests with assertions and UI tests utilizing the UiTest API for component interaction. Additionally, it provides detailed instructions on executing these tests via both the DevEco Studio graphical interface and the command line using the `aa test` command. Key topics include environment configuration, script writing, test execution strategies, and log analysis. This guide is specifically designed for developers and QA engineers familiar with OpenHarmony who wish to ensure application quality through structured testing.

### 基于shell命令测试/
This directory contains technical guides for performing automated testing on HarmonyOS devices using shell commands via the hdc tool. It covers essential operations like retrieving version information, simulating UI interactions (touch, swipe, input), and capturing device states (screenshots, layout dumps). The documentation details command syntax, JSON schemas for event recording, and prerequisites such as developer mode and APL levels. It is suitable for developers and QA engineers looking to implement command-line driven testing workflows.
