# class_A2dpSourceProfile

This directory contains API reference documentation for the `A2dpSourceProfile` class in the Cangjie language, part of the ConnectivityKit. It focuses on managing Bluetooth A2DP source connections, enabling developers to handle audio streaming to remote devices. The documentation covers class definitions, device connection management, playback state retrieval, and event subscription for connection state changes. Key topics include `getConnectedDevices`, `getConnectionState`, `getPlayingState`, and callback handling. It is suitable for Cangjie developers implementing Bluetooth audio source functionality, requiring permissions like `ohos.permission.ACCESS_BLUETOOTH`.
