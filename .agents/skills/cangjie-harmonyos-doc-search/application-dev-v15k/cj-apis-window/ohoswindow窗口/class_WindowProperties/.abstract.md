This directory contains essential API reference documentation for the `WindowProperties` class in the Cangjie programming language. It focuses on the configuration and state management of window attributes within the Window Manager system. The documentation covers the complete lifecycle of window properties, from instantiation using the constructor to querying read-only states. Key topics include defining window dimensions, setting behavioral flags like focusability and touchability, and managing display settings such as brightness and full-screen modes. This resource is intended for application developers who need to implement or query window behavior, ensuring their applications function correctly with system version 19 or later.
