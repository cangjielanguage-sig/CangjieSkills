# cj-start-intent-panel

This directory provides a comprehensive technical guide for HarmonyOS developers aiming to implement robust cross-application intent handling and system-level app selection mechanisms. The documentation focuses on decoupling application invocation from specific app IDs by utilizing business types. It covers essential interfaces such as `startAbilityByType` for launching vertical domain panels, `mailto` protocols for email integration, and `startAbility` for generic file opening. Key technical aspects include the mapping of input parameters like `type` and `sceneType` to `linkFeature` configurations within `module.json5`. This resource is ideal for developers building flexible, system-integrated applications that require seamless interaction with other services like navigation, finance, and flight booking. By following these guidelines, developers can enhance user experience through intelligent app selection and reduce dependencies on specific third-party app installations.

## Detailed Description

### cj-start-intent-panel.md

This document serves as a primary resource for understanding how to invoke applications on HarmonyOS without relying on hardcoded application identifiers. It introduces a method for launching applications based on business types, which allows for greater flexibility and dynamic system selection of apps.

The guide details the usage of the `startAbilityByType` interface, which is central to launching vertical domain panels. It explains how developers can configure their applications to handle specific domains such as navigation, finance, and flight by defining appropriate `linkFeature` settings in the `module.json5` file. Furthermore, it provides technical instructions on mapping input parameters—specifically `type` and `sceneType`—to these configurations, ensuring that the system correctly identifies and routes the intent to the appropriate application. The guide emphasizes the importance of these mappings for enabling the "Start Intent Panel," which presents users with relevant app choices based on the requested business type.

Beyond domain-specific launching, the document also covers standard invocation methods, including using `mailto` protocols to trigger email applications and employing `startAbility` to open various file types. This makes it a crucial reference for developers looking to implement comprehensive intent handling and ensure their applications can seamlessly interact with the broader system ecosystem.
