This directory contains essential API reference documentation for the `SocketDomain` struct in the Cangjie programming language, specifically designed to support network programming tasks. It provides a comprehensive overview of the struct used to encapsulate socket communication domains, which are fundamental for establishing network connections. The documentation covers a wide range of topics, including the definition of static constants for common protocols such as IPv4, IPv6, UNIX, NETLINK, and PACKET. Furthermore, it details the implementation of operator overloads for equality checks, standard interface methods like `hashCode` and `toString`, and platform-specific behaviors regarding protocol availability. This resource is highly suitable for Cangjie developers, systems engineers, and software architects who are implementing cross-platform network communication and require precise, low-level control over socket configurations and type comparisons.
