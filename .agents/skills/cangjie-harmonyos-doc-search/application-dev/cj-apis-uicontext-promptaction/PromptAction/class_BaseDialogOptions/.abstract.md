This directory provides comprehensive API reference documentation for the `BaseDialogOptions` class within the Cangjie ArkUI framework. It serves as a technical guide for defining configuration parameters for dialog components in user interfaces. The documentation covers a wide range of features, including dialog alignment, offset positioning, modal behavior, mask customization, transition effects, and lifecycle callbacks. It details the class constructor and properties that control visual styles and user interactions, such as autoCancel. This resource is specifically designed for software developers and UI engineers using Cangjie to build applications on HarmonyOS, particularly those focused on implementing custom dialog behaviors, animations, and window management logic.
