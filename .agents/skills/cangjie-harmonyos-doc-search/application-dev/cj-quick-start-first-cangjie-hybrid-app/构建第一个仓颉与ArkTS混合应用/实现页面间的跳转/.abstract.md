This directory provides comprehensive technical guidance on implementing page navigation within HarmonyOS applications that utilize a hybrid architecture of ArkTS and Cangjie. It specifically addresses the interoperability challenges between ArkTS and Cangjie routers, which are not natively compatible. The content covers essential workflows such as navigating from an ArkTS page to a mixed page, handling complex return logic, and registering callback functions for cross-language communication. Key technical concepts include the `@Interop[ArkTS]` macro, `.d.ts` interface generation, and the `registerJSFunc` mechanism. These resources are tailored for developers working on cross-language integration who need to master routing and function invocation in mixed environments.
