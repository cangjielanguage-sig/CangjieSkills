This directory provides API reference documentation for the HarmonyOS notification management module, specifically tailored for the Cangjie programming language. It serves as a comprehensive guide for developers aiming to construct, configure, and manage the lifecycle of system notifications. The content covers a wide range of features, including various content types such as text, pictures, and live views, as well as the management of notification channels (slots) and interactive elements like buttons and progress bars. By offering detailed definitions for classes, enumerations, and functions, this resource enables the implementation of rich notification features. It is suitable for HarmonyOS application developers seeking to integrate robust notification capabilities, manage user permissions, and handle distributed notification settings within their Cangjie-based projects.
