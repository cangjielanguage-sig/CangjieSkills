# 结构体

This directory contains API reference documentation for core data structures within the Cangjie Crypto and X.509 packages. It covers essential structs used for handling cryptographic data, including binary encoding (DER, PEM), certificate extensions (KeyUsage, ExtKeyUsage), and certificate management (SerialNumber, Signature, VerifyOption). Additionally, it details structures for creating certificate signing requests and managing certificate information. These documents are designed for Cangjie developers and security engineers implementing low-level cryptographic operations, SSL/TLS protocols, and identity management systems, providing the necessary definitions and methods to parse, validate, and generate security artifacts.

## Quick Navigation

**What do you want to do?**

- Handle binary or encoded data (DER/PEM) → struct_DerBlob.md, struct_Pem.md, `struct_PemEntry/`

- Manage certificate lifecycle (creation, signing, verification) → struct_SerialNumber_2more.md, struct_VerifyOption.md, struct_X509CertificateRequestInfo.md, `struct_X509CertificateInfo/`

## Detailed Description

### struct_DerBlob.md struct_DerBlob.md
This API reference document details the DerBlob struct within the Cangjie Crypto package, designed to encapsulate binary certificate data for parsing into cryptographic objects like X509 certificates and keys. The documentation outlines the struct's definition, properties including body and size, and its initialization method. It also details inherited functionality from Equatable and Hashable, specifically the hashCode function and equality operators. Key takeaways include the ability to construct a blob from a byte array to facilitate the creation of X509Certificate or key objects. This technical guide targets Cangjie developers working with low-level cryptographic data structures and DER encoding.

### struct_ExtKeyUsage.md struct_ExtKeyUsage.md
This API reference document defines the Cangjie struct ExtKeyUsage, which represents the Extended Key Usage extension in digital certificates. The documentation outlines static constants for specific key purposes such as ServerAuth, ClientAuth, CodeSigning, and OCSPSigning. It details the constructor that accepts an array of usage identifiers, allowing a single key to serve multiple functions, and a toString method for string representation. Key information includes the inheritance from the ToString trait and the specific UInt16 values assigned to each usage type. This document targets developers working with cryptography and SSL/TLS protocols who need to configure or validate certificate capabilities.

### struct_KeyUsage.md struct_KeyUsage.md
This API documentation defines the Cangjie struct KeyUsage, which represents the key usage extension field in digital certificates to specify permissible public key operations. The document details the struct definition, nine static UInt16 constants representing specific usage flags such as DigitalSignature, KeyEncipherment, and CertSign, an initializer accepting a bitmask, and a toString method. Key information includes the specific hexadecimal values for each flag and the ability to combine multiple usages via bitwise operations. This reference is intended for developers implementing digital certificate validation or cryptographic functions within the Cangjie programming environment.

### struct_Pem.md struct_Pem.md
This document provides API reference details for the Pem struct in the Cangjie programming language, designed to manage sequences of PEM entries. It covers the struct definition, properties like size, constructors, and methods including decode, encode, isEmpty, iterator, and toString. Key information highlights that the struct implements Collection<PemEntry> and ToString, enabling the conversion between PEM text strings and object representations, with error handling via X509Exception. This reference is intended for developers utilizing the x509 package to handle cryptographic data, requiring familiarity with Cangjie syntax and PEM formats.

### struct_SerialNumber_2more.md struct_SerialNumber_2more.md
This document serves as API reference documentation for the Cangjie programming language, specifically defining the SerialNumber and Signature structures used within X.509 digital certificate contexts. The text covers the SerialNumber struct, which generates unique identifiers compliant with RFC 5280 length constraints, and the Signature struct, designed for identity verification. Key information includes the SerialNumber initializer for random byte generation, hex string conversion methods, and the signatureValue property for accessing binary data. Both structures implement Equatable and Hashable interfaces to support comparison and hashing operations. This documentation targets developers working on security or cryptography applications who need to manipulate certificate data structures.

### struct_VerifyOption.md struct_VerifyOption.md
This API reference document details the VerifyOption struct in Cangjie, which serves as a configuration object for X.509 certificate verification functions. The documentation covers the struct definition and four specific public properties: time, dnsName, roots, and intermediates. Key information includes the data types and default behaviors for each field, such as using the current time for validation, system root certificates for trust chains, and optional domain name checks. This resource is intended for developers implementing security features who need to customize certificate validation logic within the x509 package.

### struct_X509CertificateRequestInfo.md struct_X509CertificateRequestInfo.md
This API reference document defines the X509CertificateRequestInfo struct in Cangjie, which encapsulates data required for X.509 certificate signing requests. The documentation details the struct's properties, including the subject's distinguished name, and arrays for DNS names, email addresses, and IP addresses. It also explains the public initializer, which sets default values for these fields. Key information includes the requirement for users to validate domain and email inputs, while the constructor automatically validates IP addresses, throwing an X509Exception for invalid entries. This resource is intended for developers implementing cryptographic operations or security protocols who need to construct certificate request objects programmatically.

### struct_PemEntry/
