This directory contains documentation related to "Class" structures, primarily focusing on the Cangjie programming language's database SQL package. It includes a general introduction to object-oriented programming concepts and detailed API references for SQL data type mappings. The content covers core infrastructure classes like DriverManager and PooledDatasource, as well as a comprehensive list of deprecated wrapper classes for SQL types (e.g., integers, timestamps, binary objects) and their nullable variants. This documentation is suitable for developers working with the Cangjie language, particularly those maintaining legacy code or migrating database interactions.
