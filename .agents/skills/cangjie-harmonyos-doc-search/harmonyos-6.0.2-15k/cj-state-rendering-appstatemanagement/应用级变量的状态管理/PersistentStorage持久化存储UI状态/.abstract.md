This directory provides comprehensive documentation on the PersistentStorage singleton object, a crucial component for HarmonyOS applications designed to persist UI state by synchronizing specific AppStorage properties to local disk storage. It covers the fundamental two-way synchronization mechanism, supported data types, and critical performance constraints, such as avoiding large datasets to prevent UI lag. The resources include technical guides, detailed API references for the Cangjie language, and practical code examples. This collection is ideal for HarmonyOS developers and application engineers seeking to implement reliable local state persistence that survives application restarts while maintaining optimal rendering performance.
