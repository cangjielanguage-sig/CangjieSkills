# crypto

The `crypto` directory acts as a comprehensive resource hub for cryptographic functionalities within the Cangjie programming language ecosystem. It is designed to assist developers in implementing robust security features by providing a structured collection of documentation, API references, and practical code examples. The content encompasses a wide range of topics, including the central API documentation for class-based libraries, detailed technical overviews of the `stdx.crypto.crypto` package, and specific implementations of the SM4 symmetric encryption algorithm. Furthermore, it addresses critical infrastructure needs such as OpenSSL 3 dependency management across Linux, Windows, and macOS platforms. This directory is primarily suitable for software developers and system integrators who require advanced encryption capabilities, secure random number generation, and guidance on configuring external cryptographic libraries in their Cangjie projects.

## Detailed Description

### [1] crypto_package_api
The `crypto_package_api` directory serves as the central API documentation hub for cryptographic operations within the Cangjie programming language ecosystem. It organizes resources related to security, covering class-based libraries, exception handling, and other core components necessary for developers to understand the available cryptographic interfaces.

### [2] crypto_package_overview
This directory provides a comprehensive technical overview of the `stdx.crypto.crypto` package, focusing on secure random number generation mechanisms and SM4 symmetric encryption/decryption functions compliant with national cryptographic standards. The documentation details related classes, structs, and exception APIs, and specifically includes an installation guide for the OpenSSL 3 dependency library. It covers system configuration and environment variable settings for three major platforms: Linux, Windows, and macOS. Designed for developers integrating advanced encryption features, this document requires readers to have system environment configuration capabilities and experience managing external library dependencies, serving as an important reference for setting up an encryption development environment.

### [3] crypto_samples
This directory provides a collection of sample code and documentation focused on cryptographic operations within the Cangjie programming language. It covers key security concepts including the SM4 encryption algorithm for data protection and the generation of secure random numbers, offering practical examples to help developers implement these features effectively.
