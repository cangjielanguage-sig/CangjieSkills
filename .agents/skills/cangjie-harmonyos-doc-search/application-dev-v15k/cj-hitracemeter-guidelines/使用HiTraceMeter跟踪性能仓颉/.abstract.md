This directory provides comprehensive resources for utilizing HiTraceMeter to track performance and implement distributed tracing within Cangjie applications. It covers the theoretical underpinnings of the tool, including its interaction with kernel ftrace buffers, and offers practical guidance on coding and verification. Key topics include asynchronous time-slice tracking APIs, unique task ID management, and command-line log capturing. This content is specifically designed for Cangjie developers working in DevEco Studio who aim to analyze system performance, monitor process trajectories, and optimize business logic execution.
