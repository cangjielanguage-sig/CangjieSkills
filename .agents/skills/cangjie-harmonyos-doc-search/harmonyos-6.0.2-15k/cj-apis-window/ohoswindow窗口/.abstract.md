This directory contains comprehensive API reference documentation for the `ohos.window` module in the Cangjie programming language, designed for HarmonyOS application development. It covers core window management capabilities, including window creation, configuration, lifecycle control, and event handling. Key topics include window types, geometry, avoidance areas, system bar properties, and orientation settings. The resources are intended for application developers and UI engineers who need to programmatically manage application windows, handle system UI interactions, and implement responsive layouts using the WindowManager capability in a pure Cangjie environment.
