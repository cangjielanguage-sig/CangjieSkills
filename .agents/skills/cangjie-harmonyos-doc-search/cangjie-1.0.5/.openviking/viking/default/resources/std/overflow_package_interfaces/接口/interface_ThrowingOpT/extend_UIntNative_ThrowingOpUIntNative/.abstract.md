This directory provides comprehensive API reference documentation for the Cangjie language, specifically detailing the implementation of the `ThrowingOp` interface for the `UIntNative` type. It focuses on arithmetic and bitwise operations that employ a throwing strategy for error handling, ensuring data integrity by explicitly throwing exceptions such as `OverflowException` and `OvershiftException` when errors occur. The documentation covers a wide range of operations including addition, subtraction, multiplication, division, modulo, increment, decrement, negation, and bit shifting. This resource is essential for Cangjie developers who need safe, checked arithmetic operations for unsigned native integers to prevent silent overflow errors and ensure robust application behavior.
