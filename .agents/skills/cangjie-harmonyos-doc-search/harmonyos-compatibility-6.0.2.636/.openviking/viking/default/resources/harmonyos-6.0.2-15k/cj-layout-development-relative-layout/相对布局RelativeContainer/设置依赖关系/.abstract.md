This directory focuses on configuring dependency relationships for UI components within the ArkUI framework, specifically utilizing the RelativeContainer. It covers essential layout concepts such as setting reference boundaries for alignment, positioning components relative to anchor points, and defining anchor point configurations. Key topics include horizontal and vertical alignment rules, offset handling, and avoiding dependency cycles. The documentation supports both Cangjie and ArkTS languages. It is suitable for developers and designers working on the HarmonyOS platform who need to build complex, interconnected user interfaces with precise relative positioning capabilities.
