# runtime_package_overview

This directory serves as the definitive entry point for comprehensive documentation regarding the Cangjie programming language's standard runtime package. It functions as a critical resource hub designed for developers and system engineers who require the ability to interact with, control, and fine-tune the program's execution environment at a low level. The documentation encompasses a broad spectrum of essential system-level topics, specifically focusing on advanced memory management techniques. This includes detailed guidance on interacting with Cangjie's automatic garbage collection system and implementing manual controls for heap optimization. Furthermore, it provides extensive coverage of performance profiling, thread monitoring, and CPU statistics. This documentation is specifically tailored for professionals who need deep system-level access to effectively debug applications, rigorously manage resource consumption, and optimize runtime performance for stability and efficiency in production environments.

The `stdruntime` directory provides essential documentation for the Cangjie programming language's standard runtime package. It serves as a central resource for understanding how to interact with and control the program's execution environment effectively. The content primarily focuses on advanced memory management techniques, including the interaction with Cangjie's automatic garbage collection system, as well as manual controls for heap optimization. Additionally, it covers performance profiling, thread monitoring, and CPU statistics. This documentation is specifically designed for Cangjie developers and system engineers who require deep system-level access to debug applications, manage resource consumption, and optimize runtime performance for production environments.
