# bigInt_basic_prop

This directory serves as a comprehensive educational resource focused on the fundamental aspects of the BigInt object within the Cangjie programming language. It is designed to assist developers in understanding how to effectively manage and manipulate large integer values that go beyond the limitations of standard primitive data types. The content primarily covers the initialization process, specifically demonstrating the use of the `BigInt.parse` method to convert string inputs into functional BigInt objects. Additionally, it provides detailed guidance on accessing and interpreting essential object properties, such as the `sign` (indicating positive or negative value) and `bitLen` (representing the bit length). Through practical examples, such as parsing the string "-123456", developers can observe how these attributes are derived and utilized in real-world scenarios. This directory is suitable for Cangjie developers seeking a quick reference or tutorial to solidify their understanding of BigInt instantiation and property inspection, ensuring they can handle arbitrary-precision arithmetic with confidence.
