This directory provides a comprehensive technical guide for HarmonyOS developers aiming to achieve interoperability between ArkTS and Cangjie within the same project. Designed for developers familiar with ArkTS who wish to incorporate Cangjie business logic, these resources facilitate the creation of high-performance hybrid applications by bridging the two languages seamlessly. The documentation ensures developers can successfully build, configure, and execute mixed-language projects in a unified workspace.
