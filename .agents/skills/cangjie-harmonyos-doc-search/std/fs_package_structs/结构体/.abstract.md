This directory contains API reference documentation for core data structures within the Cangjie programming language's file system package. It focuses on essential structs used for file input/output operations, system-level resource management, and path manipulation. Key topics include file handle access via `FileDescriptor`, metadata inspection through `FileInfo`, and cross-platform path handling using `Path`. These resources cover OS-specific behaviors on Unix, Windows, and macOS, addressing concepts like file attributes, permissions, and normalization. This documentation is suitable for Cangjie developers who need to implement robust file system interactions, manage low-level file resources, or handle file paths securely and efficiently across different operating systems.
