This directory contains API reference documentation for the Cangjie language's `CarryingOp` interface and its implementations across various integer types. It focuses on arithmetic operations designed to detect truncation and overflow using a wrapping strategy. Key concepts include explicit overflow detection, tuple return types containing a Boolean flag and the result, and low-level arithmetic safety. This documentation is suitable for Cangjie developers, systems programmers, and engineers working on performance-critical applications requiring precise numeric control and robust error handling.
