This directory provides API reference documentation for the `FetchResult` class in the Cangjie programming language, focusing on the PhotoAccessHelper system capability. It details how to manage file retrieval result sets, including resource cleanup, fetching asset arrays, and counting files. The documentation covers essential methods for navigating and accessing media assets, handling exceptions, and utilizing the MediaLibraryKit context. It is designed for developers building file management or media access applications who require efficient programmatic control over photo libraries and result set cursors.
