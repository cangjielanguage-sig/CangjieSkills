# hex_package_funcs

本目录提供了仓颉编程语言中用于处理十六进制编码与解码功能的API参考文档。该模块专注于解决二进制数据与十六进制字符串表示形式之间的相互转换问题，涵盖了从字节数组到字符串的编码以及从字符串到字节数组的解码过程。文档内容详细列出了核心函数的签名、参数类型、返回值类型以及相关的错误处理策略（如使用Option类型处理解码异常）。此目录非常适合需要在仓颉开发环境中进行底层数据处理、网络协议解析或数据加密解密操作的开发者查阅，能够帮助开发者快速掌握并应用这些基础工具函数。

### hex_package_funcs.md hex_package_funcs.md
本文档是仓颉编程语言中十六进制编码与解码函数的API参考文档。文档主要涵盖两个核心函数：用于将十六进制字符串解码为字节数组的fromHexString，以及将字节数组编码为十六进制字符串的toHexString。关键信息包括详细的参数类型、返回值说明以及错误处理机制，其中fromHexString通过Option类型处理解码成功或失败的情况。该文档面向需要在二进制数据与十六进制字符串之间进行转换的仓颉语言开发者，提供了清晰的函数签名和功能定义。
