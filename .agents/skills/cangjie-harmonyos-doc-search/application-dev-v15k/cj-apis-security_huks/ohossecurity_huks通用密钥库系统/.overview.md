# ohossecurity_huks通用密钥库系统

This directory contains the API reference documentation for the HarmonyOS Universal Keystore System (HUKS) implemented in the Cangjie programming language. It provides comprehensive definitions for cryptographic key management, including key generation, storage, encryption, decryption, and user authentication. The documentation covers essential classes, enums, and functions required to implement secure hardware-backed key operations. It is suitable for security developers and system architects working on OpenHarmony applications who need to integrate robust cryptographic services and manage key lifecycles securely.
