This directory contains API reference documentation for the `EventInfo` class within the Cangjie programming language's accessibility framework. It comprehensively covers the structure and properties required to handle interface change events, including event types, bundle names, component types, and navigation indices. Additionally, it details specific accessibility properties such as text announcements, movement granularity, and trigger actions. Designed for developers implementing barrier-free accessibility services, these documents require a solid understanding of UI components and event-driven programming. Key topics include the `SystemCapability.BarrierFree.Accessibility.Core` capability, event initialization parameters, and property management starting from API version 19.
