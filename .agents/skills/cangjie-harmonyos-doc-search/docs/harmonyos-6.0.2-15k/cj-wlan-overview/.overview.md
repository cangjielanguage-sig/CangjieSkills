# cj-wlan-overview

This directory serves as a comprehensive technical resource for WLAN service development, offering a deep dive into the definitions, implementation principles, and operational modes essential for wireless connectivity. It thoroughly covers the distinction between wired and wireless network sides, the intricacies of 2.4GHz and 5GHz frequency bands, and the 802.11 architecture. Furthermore, it provides detailed introductions to three critical modes: STA for client access, P2P for direct device-to-device links utilizing Group Owner roles, and AP for hotspot sharing. This guide is specifically tailored for developers working on connectivity features, acting as a foundational reference for mastering WLAN capabilities and effectively utilizing the `ohos.wifiManager` API within the development ecosystem. By understanding these core components, developers can better architect and implement robust wireless solutions for various applications.
