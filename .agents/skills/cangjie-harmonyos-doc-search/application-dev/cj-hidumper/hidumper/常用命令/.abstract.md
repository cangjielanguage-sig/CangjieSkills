This directory contains a comprehensive set of reference guides for the `hidumper` command-line tool used in OpenHarmony systems. It covers a wide range of functionalities, from basic system information retrieval and service debugging to advanced performance monitoring and memory analysis. Key topics include inspecting system abilities, analyzing network and CPU statistics, managing window and graphics services, and performing deep dives into process memory and JavaScript heap dumps. These documents are essential resources for system developers, QA engineers, and administrators who need to diagnose issues, monitor system health, or optimize performance on OpenHarmony devices.
