# 基础类型定义

This directory contains API reference documentation for fundamental data structures and classes used within the ArkUI framework for the Cangjie language. It covers essential UI components such as shadow configurations, text styling, text controllers, and menu item definitions. Additionally, it includes enumerations for text interaction types and data detection. These definitions are crucial for developers building user interfaces in HarmonyOS applications, providing the necessary building blocks to customize visual effects, manage text behavior, and handle user interactions programmatically.

## Detailed Description

### class_ShadowOptions.md
This document serves as an API reference for the Cangjie ShadowOptions class, used to configure shadow effects within the ArkUI framework. It details the class properties including radius, shadowType, offsetX, offsetY, color, and fill, specifying their types, read-write capabilities, and system requirements. The documentation also outlines the constructor parameters, highlighting default values and unit measurements in pixels. Key takeaways involve understanding the specific version availability for properties like shadowType and fill. This guide is intended for developers utilizing Cangjie for UI development, providing the necessary specifications to implement and customize shadow styling in their applications.

### class_TextController.md
This document serves as API reference documentation for the TextController class in the Cangjie language, designed to control Text component behavior within the ArkUI framework. It covers the class definition, the constructor method for object instantiation, and a specific function to manage selection menus. Key takeaways include the system capability requirement (ArkUI.Full) and the availability starting from version 19. The primary functionality exposed is the closeSelectionMenu method, which allows developers to programmatically dismiss text selection menus. This reference guide targets HarmonyOS developers using Cangjie who need fine-grained control over Text component interactions, specifically text selection UI states.

### class_TextFont.md
This API reference document details the TextFont class, which is used to configure text styles in the Cangjie ArkUI framework. The documentation outlines the class structure and two primary constructor overloads that differ by the font family parameter type: String or AppResource. Key information includes the parameters for size, weight, family, and style, all of which are named parameters with specific default values. The document specifies system capabilities and version requirements. Intended for software developers using the ArkUI framework, this guide provides the necessary syntax to instantiate text styling objects for application user interfaces.

### class_TextMenuItem.md
This document provides API reference documentation for the Cangjie TextMenuItem class, designed to represent text menu items within the ArkUI framework. It covers the class definition, detailing three public properties: content, icon, and id, all of which are readable and writable. The document explains three constructor overloads that accept combinations of String and AppResource types for flexible initialization. Key information includes the restriction that menu icons do not support network images. Intended for software developers using Cangjie, this reference assists in implementing menu functionality by defining item attributes and unique identifiers.

### class_TextMenuItemId.md
This API reference document defines the Cangjie class TextMenuItemId, which serves as an identifier for text menu items within the ArkUI framework. The documentation details static properties representing standard actions such as COPY, CUT, PASTE, and advanced features like AI_WRITER. It also outlines factory methods for creating custom IDs from AppResource or String inputs, plus an equals method for comparison. Key information includes system capabilities and the requirement of version 19. This guide is intended for developers implementing text selection and menu interaction logic in their applications.

### enum_TextSpanType_4more.md
This API reference document defines four enumeration types used for text handling and interaction within the ArkUI framework using the Cangjie language. The main sections cover TextSpanType for content classification, TextResponseType for menu triggers, TextDataDetectorType for entity recognition, and TextSelectable for focus and selection states. Key information includes specific values for image-text mixing, right-click or long-press menus, data detection like phone numbers and URLs, and selectable focus modes. All enums support full system capabilities starting from version 19. This documentation targets ArkUI developers implementing advanced text input and selection features in their applications.
