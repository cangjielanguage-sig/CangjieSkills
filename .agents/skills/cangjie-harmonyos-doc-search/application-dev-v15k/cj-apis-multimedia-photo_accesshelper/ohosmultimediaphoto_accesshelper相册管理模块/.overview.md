# ohosmultimediaphoto_accesshelper相册管理模块

This module provides comprehensive API reference documentation for the HarmonyOS PhotoAccessHelper system capability, written in the Cangjie programming language. It covers the management of photo albums, media assets, and user selection interfaces within the MediaLibraryKit framework. Key functionalities include accessing and modifying photo metadata, handling change notifications, configuring media selection options, and managing file creation and retrieval. It is designed for developers building file management or gallery applications who need to interact with system photo libraries, handle permissions, and implement robust media processing features in HarmonyOS applications.
