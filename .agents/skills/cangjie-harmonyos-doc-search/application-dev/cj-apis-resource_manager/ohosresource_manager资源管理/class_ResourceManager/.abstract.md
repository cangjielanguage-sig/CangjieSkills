This directory contains API reference documentation for the ResourceManager class in the Cangjie programming language, specifically designed for HarmonyOS application development. It covers comprehensive methods for managing application and system resources, including retrieving strings, colors, media, and configuration settings. Key functionalities include resource overlay management, localization support, and raw file access. The documentation is suitable for HarmonyOS developers and system integrators who need to programmatically handle dynamic resources, implement internationalization, and manage device capabilities within their applications using version 22 system capabilities.
