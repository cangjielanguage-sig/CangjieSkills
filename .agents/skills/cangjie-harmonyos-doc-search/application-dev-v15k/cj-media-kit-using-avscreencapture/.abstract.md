This directory contains a comprehensive technical media kit focused on implementing screen recording capabilities within the HarmonyOS ecosystem. It specifically utilizes the `AVScreenCaptureRecorder` module to demonstrate how to capture screen content and write it to files. The content covers the full development lifecycle, including instance creation, audio-video parameter configuration, recording controls, and resource management. It addresses critical aspects such as permission handling, state management, and system interruptions. This resource is tailored for HarmonyOS application developers and software engineers working with the Cangjie language who need to integrate robust screen capture and media playback features into their applications.
