This directory contains comprehensive API reference documentation for the `ECDSAPrivateKey` class in the Cangjie programming language. It focuses on the complete lifecycle of Elliptic Curve Digital Signature Algorithm (ECDSA) private keys, covering generation, manipulation, and format conversion. Key topics include key generation using the `Curve` enum, decoding keys from DER and PEM formats (supporting both plain and encrypted keys), and encoding keys to DER. The documentation also covers digital signing operations and error handling via `CryptoException`. This resource is suitable for software developers and security engineers implementing cryptographic operations, specifically those requiring robust management of ECDSA keys and secure data signing capabilities.
