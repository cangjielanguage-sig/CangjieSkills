# 使用镜像能力

This directory provides comprehensive documentation on ArkUI's mirroring capabilities, a critical feature currently in Beta for adapting user interfaces to Right-to-Left (RTL) reading habits. It serves as a technical guide for developers implementing internationalization (i18n) and localization (l10n) by detailing how layouts automatically flip horizontally to accommodate different languages. The content covers the core concepts of LTR and RTL, the specific conditions required to trigger mirroring (such as setting the direction property), and the constraints developers must navigate. It highlights which components are pre-adapted and which require manual intervention, such as replacing absolute positioning terms with relative ones. This resource is specifically tailored for ArkUI developers aiming to create seamless, bidirectional user experiences for global markets, ensuring that applications function correctly across diverse linguistic environments.

## Detailed Description

### 使用约束.md 使用约束.md
This document outlines the usage constraints and adaptation requirements for ArkUI's mirroring capabilities, specifically regarding layout direction. It details which features are pre-adapted, including basic components like Swiper and Tabs, advanced components like Popup, and universal attributes such as position and padding. Key takeaways include the need for manual adaptation in specific scenarios: developers must replace absolute direction indicators like left/right with generic terms like start/end for layout and border settings to ensure proper mirroring. Furthermore, the Canvas component offers limited support, restricted only to text drawing. This reference guide is intended for ArkUI developers implementing internationalization or bidirectional interface layouts.

### 使用镜像能力_3more.md 使用镜像能力_3more.md
This document introduces the ArkUI mirroring capability, currently in Beta, designed to adapt UI layouts for Right-to-Left (RTL) reading habits. It covers the overview of horizontal content flipping, specific activation conditions based on the direction property, and definitions of LTR and RTL concepts. Key takeaways include that mirroring triggers when direction is set to Direction.Rtl or Direction.Auto with an RTL system language. This technical guide is intended for developers using ArkUI to implement internationalization and localization features.
