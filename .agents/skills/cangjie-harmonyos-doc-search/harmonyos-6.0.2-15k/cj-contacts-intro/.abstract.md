This directory serves as a comprehensive entry point for developers interested in the Contacts Kit on HarmonyOS, with a specific focus on the Cangjie programming language. It provides essential documentation for integrating sophisticated contact management capabilities into native applications. The material covers the full scope of the kit, highlighting the critical distinction between the open Contact Picker feature—which allows for contact selection without requiring user permissions—and the restricted Contact Management functions that necessitate specific authorization. This resource is particularly suitable for HarmonyOS developers who need to navigate the complexities of permission handling and API interactions. By offering step-by-step tutorials on importing modules, retrieving UIAbilityContext, and invoking interfaces like selectContacts, it equips developers with the knowledge to implement both basic contact selection and advanced management features efficiently.
