This directory contains API reference documentation for the core classes within the Cangjie serialization package. It covers the data model hierarchy, including abstract base types and concrete implementations for primitive data types like integers, floats, and booleans. Additionally, it details complex structures such as sequences, strings, and field-based objects used for converting class instances into serializable formats. This documentation is suitable for developers implementing serialization logic in the Cangjie programming language who need to understand how to structure, encapsulate, and manipulate data programmatically.
