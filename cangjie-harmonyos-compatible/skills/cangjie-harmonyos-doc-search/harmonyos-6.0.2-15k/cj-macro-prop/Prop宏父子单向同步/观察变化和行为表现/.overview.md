# 观察变化和行为表现

This directory focuses on the mechanisms of observing data changes and behavioral patterns within the Cangjie state management system for ArkUI. It comprehensively covers the `@Prop` decorator's initialization, update flows, and synchronization rules between parent and child components. Key topics include one-way data flow, deep observation of various data types (primitives, structs, classes), and constraints on collection reactivity like `HashSet`. This resource is suitable for developers looking to master reactive programming, manage component state efficiently, and ensure accurate UI updates in their applications by understanding the underlying framework behavior and observation rules.

## Detailed Description

### 框架行为.md 框架行为.md

This technical reference document explains the initialization and update mechanisms of @Prop decorated variables within parent-child component relationships. It details the initial rendering process where parent data initializes child instances, and the update flow distinguishing between local child modifications and parent data source changes. Key takeaways include the one-way data flow where child updates do not sync back to the parent, and parent updates overwrite local child modifications. A critical note highlights that @Prop cannot refresh when the application is in the background, recommending @Link as an alternative. This guide targets developers managing component state and data synchronization.

### 观察变化/

This directory provides a comprehensive technical overview of change observation mechanisms within the Cangjie state management system, specifically designed for ArkUI developers. It delves into the intricacies of the `@Prop` decorator, explaining how data synchronization works between parent and child components. The content covers a wide range of data types, including primitives, structs, classes, and arrays, highlighting specific behaviors such as deep observation requirements and the limitations of standard versus observed arrays. Furthermore, it addresses critical constraints regarding collection reactivity, particularly focusing on `HashSet` mutations. This resource is vital for developers aiming to master reactive programming in Cangjie, ensuring efficient state management and accurate UI updates in their applications. By understanding these rules, developers can avoid common pitfalls related to data binding and ensure their interfaces respond correctly to state changes.
