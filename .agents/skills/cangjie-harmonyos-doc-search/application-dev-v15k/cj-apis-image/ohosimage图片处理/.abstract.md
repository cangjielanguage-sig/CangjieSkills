This directory contains comprehensive API reference documentation for the `ohos.image` module within the HarmonyOS Cangjie development framework. It covers the entire image processing pipeline, including decoding, encoding, pixel manipulation, and High Dynamic Range (HDR) support. Key components include classes for Image, PixelMap, and ImageSource, alongside enums for formats and metadata. Designed for multimedia developers and engineers, these resources facilitate the creation of advanced image applications requiring precise control over image data, metadata management, and rendering capabilities within the SystemCapability.Multimedia.Image.Core framework.
