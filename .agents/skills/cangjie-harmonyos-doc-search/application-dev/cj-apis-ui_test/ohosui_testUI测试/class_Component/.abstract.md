This directory contains API reference documentation for the `Component` class within the Cangjie UI testing framework. It covers a comprehensive range of methods for automating UI interactions, including simulating user inputs like clicking, dragging, and pinching, as well as querying component properties such as bounds, text, and state. The documentation details method signatures, parameters, return types, and exception handling for errors like invisible components. It is designed for software developers and QA engineers using the TestKit to create robust automated test scripts in the Cangjie programming language.
