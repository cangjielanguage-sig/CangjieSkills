# 精准批量修改数据

This directory focuses on techniques for performing precise batch data modifications within the ArkUI framework using the Cangjie language. It covers the implementation of granular updates for LazyForEach components, utilizing specific operation classes like DataMoveOperation, DataExchangeOperation, and others to map array changes efficiently. Key topics include manual data manipulation, direct array assignment, and the `notifyDatasetChange` method to optimize list rendering performance. This resource is suitable for UI developers and engineers looking to enhance application responsiveness and handle complex data updates without full UI reconstruction.

## Detailed Description

### 精准批量修改数据_1.md 精准批量修改数据_1.md
This tutorial demonstrates how to efficiently perform precise batch data modifications in ArkUI LazyForEach components using the Cangjie language. It covers two main approaches: manual data manipulation using specific operation types like DataMoveOperation and DataExchangeOperation, and direct array assignment with comparison-based operations. Key takeaways include using the notifyDatasetChange method to update the UI without full reconstruction, ensuring operation indices reference the pre-modification array state, and avoiding mixing this interface with other data modification methods. This guide targets UI developers seeking to optimize list rendering performance and handle complex data updates.

### 精准批量修改数据_2.md 精准批量修改数据_2.md
This document serves as a technical guide for implementing precise batch data modifications within a UI framework, specifically focusing on LazyForEach updates. It details the usage of specific operation classes like DataMoveOperation, DataExchangeOperation, DataAddOperation, and DataDeleteOperation to map array changes. Key takeaways include the rule that a single index can only be operated on once per onDatasetChange call, the option for developers to provide custom keys to bypass key generation, and the fact that RELOAD operations override others. This reference is intended for developers optimizing list rendering performance through granular data change notifications.
