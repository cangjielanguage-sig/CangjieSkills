# 使用SM4对称密钥GCM模式分段加解密

This directory focuses on the technical implementation of segmented encryption and decryption using the SM4 symmetric key algorithm in GCM (Galois/Counter Mode) mode. It covers essential cryptographic operations within the CryptoArchitectureKit, specifically tailored for the Cangjie programming language. Key topics include SM4_128 key generation, GCM parameter configuration, handling large data volumes via chunked processing, and ensuring data integrity through authentication tags. This resource is suitable for developers and security engineers looking to integrate secure, high-performance cryptographic features into their applications, particularly those dealing with Beta-phase implementations of the CryptoArchitectureKit.
