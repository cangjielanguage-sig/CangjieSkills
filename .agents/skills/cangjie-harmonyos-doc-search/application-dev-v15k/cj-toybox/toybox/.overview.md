# toybox

The `toybox` directory provides essential documentation for a lightweight Linux command-line utility collection consolidated into a single executable. It covers technical references, usage methods (hdc shell, application sandbox), troubleshooting common errors, and comprehensive command-line interface guides for system administration. Key topics include process management, network configuration, device node manipulation, and resolving permission errors such as SELinux denials. This documentation is suitable for developers, system administrators, and embedded engineers working with Linux environments who need efficient command lookup, execution guidance, and debugging support for embedded systems.

## Detailed Description

### toybox_2more.md toybox_2more.md
This document serves as a technical reference guide for toybox, a lightweight Linux command-line utility collection consolidated into a single executable. The content defines the tool's core function and outlines two primary usage methods: accessing the tool via hdc shell after connecting a device, or running it within an application sandbox. Key information includes the prerequisites for execution and the specific environments where toybox operates. Intended for developers or system administrators working with embedded systems, this guide provides the necessary context for utilizing these common Linux commands. Keywords include toybox, Linux command-line, hdc shell, and application sandbox.

### 常见问题.md 常见问题.md
This troubleshooting guide addresses common errors encountered when using the toybox command-line tool. It covers "Unknown command" issues, permission errors including SELinux denials, standard Linux kernel error codes, and discrepancies between shell built-ins and toybox implementations. Key takeaways include verifying command compilation, checking file permissions and kernel logs for "avc: denied," and using the "toybox [command]" prefix to explicitly invoke toybox commands instead of shell built-ins like `pwd` or `time`. This reference guide targets developers and system administrators troubleshooting toybox execution, requiring basic Linux command-line knowledge.
