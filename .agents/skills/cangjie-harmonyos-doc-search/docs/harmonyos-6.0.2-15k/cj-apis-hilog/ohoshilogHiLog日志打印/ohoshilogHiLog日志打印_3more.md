# ohos.hilog（HiLog日志打印）

hilog日志系统，使应用/服务可以按照指定级别、标识和格式字符串输出日志内容，帮助开发者了解应用/服务的运行状态，更好地调试程序。

## 导入模块

```cangjie
import kit.PerformanceAnalysisKit.*
```
