# class_WebviewController

This directory provides API reference documentation for the `WebviewController` class in the Cangjie language, designed for HarmonyOS development. It covers the management of Web component behaviors, including navigation, lifecycle, JavaScript interaction, security, and page properties. The documentation is intended for Cangjie developers using the ArkUI framework and ArkWeb kit to integrate web content into native applications. Key topics include history management, user agent customization, safe browsing, and asynchronous script execution.
