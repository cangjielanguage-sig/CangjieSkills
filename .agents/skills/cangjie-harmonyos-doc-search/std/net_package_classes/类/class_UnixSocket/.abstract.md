This directory contains API reference documentation for the `UnixSocket` class within the Cangjie net package, focusing on duplex stream-based communication using Unix domain sockets. It covers class constructors, inheritance from `StreamingSocket`, and configuration properties such as local and remote addresses, timeouts, and buffer sizes. The documentation details methods for connecting, reading, writing, and managing socket options, while noting platform incompatibility with Windows and specific exception handling requirements. This resource is suitable for Cangjie developers implementing low-level inter-process communication (IPC) who need precise control over socket behavior, data transmission, and error management.
