# ohosfilefs文件管理

This directory contains comprehensive API reference documentation for the `ohos.file.fs` module in the Cangjie programming language, designed for HarmonyOS application development. It covers essential file system capabilities including file I/O operations, directory management, stream handling, and random access. The documentation details various configuration classes for reading, writing, and listing files, alongside specific classes for file metadata, filtering, and conflict resolution. It is suitable for Cangjie developers and software engineers who need to implement robust file management features, handle system resources, and manage application sandbox paths effectively.
