This directory contains comprehensive API reference documentation for the `StaticVariableInfo` class within the Cangjie language's reflection package. It serves as a critical resource for developers aiming to describe, inspect, and manipulate static member variable information programmatically. The documentation thoroughly outlines properties for accessing variable metadata—including name, typeInfo, annotations, and modifiers—alongside methods like `getValue()` and `findAnnotation()`. It also covers runtime behaviors such as mutability checks and value modification. Key topics include reflection mechanisms, type system analysis, and exception handling. This documentation is best suited for Cangjie developers who require advanced tools to interact with static class members dynamically, assuming a deep understanding of the language's syntax and reflection concepts.
