## 详细描述

### CatchPattern_进阶介绍.md
本文档旨在介绍仓颉编程语言中CatchPattern的进阶用法，重点讲解类型模式与通配符模式。文档详细阐述了类型模式的两种语法：捕获单一异常类及其子类，以及使用连接符`|`捕获多种异常类型并绑定至最小公共父类。同时，介绍了通配符模式`_`用于捕获任意异常的机制。通过代码示例展示了异常捕获、变量绑定及类型转换的具体行为。这是一份面向仓颉开发者的技术指南，帮助开发者掌握复杂的异常处理逻辑和类型匹配规则。

### throw_和处理异常_5f95d44b.md
本文档旨在介绍仓颉语言中如何抛出异常以及使用 try 表达式处理异常。主要涵盖异常对象的创建、throw 关键字的使用规则，以及普通 try 表达式与 try-with-resources 资源自动管理表达式的区别。关键信息指出 throw 仅能抛出 Exception 子类型，Error 不可手动抛出，且未捕获异常可通过 Thread 类静态函数注册自定义处理。本文属于编程教程，面向已掌握自定义异常概念的仓颉语言开发者，旨在指导其完善异常处理机制。

### try-with-resources_表达式.md
本文档旨在介绍仓颉编程语言中的 try-with-resources 表达式，用于自动释放非内存资源。文档涵盖了语法结构、Resource 接口实现要求、变量作用域规则及异常处理机制。关键信息包括资源必须实现 Resource 接口，catch 和 finally 块可选，表达式返回类型为 Unit，且不建议手动释放资源。这是一份面向仓颉开发者的语言特性教程，帮助开发者理解如何高效管理资源生命周期。

### 普通_try_表达式.md
这份文档详细介绍了仓颉语言中普通 try 表达式的语法结构与异常处理机制。主要涵盖 try、catch 和 finally 三个核心组成部分的功能与交互，解释了 catch 块通过模式匹配捕获异常的规则，以及 finally 块确保资源释放的执行特性。文档重点说明了各块作用域的独立性及变量重定义限制，并阐述了 try 表达式类型的推断逻辑（即除 finally 外所有分支的最小公共父类型）。通过代码示例展示了异常捕获流程与类型推导。这是一份面向仓颉开发者的语言特性参考指南，旨在帮助开发者正确运用异常处理及理解表达式类型系统。
