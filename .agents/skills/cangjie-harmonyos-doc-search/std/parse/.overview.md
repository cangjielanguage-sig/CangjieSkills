# parse

This directory provides a technical overview of the parsing capabilities within the Cangjie standard library, specifically designed to convert raw source code into Abstract Syntax Tree (AST) objects. It is a crucial resource for understanding how the language processes code structure programmatically. The content covers two distinct parsing approaches: `parseDecl` for handling isolated declarations such as classes, and `parseProgram` for processing entire source files that include packages and import statements. Furthermore, it introduces essential tools for developers, including `quote`, `cangjieLex`, and `dump()`, which are used to visualize and debug the hierarchical relationships of AST nodes like `ClassDecl`, `VarDecl`, and `MacroDecl`. This documentation is highly suitable for developers engaged in Cangjie metaprogramming, compiler development, or anyone needing to analyze or manipulate Cangjie source code automatically. By mastering these parsing functions, developers can build powerful tools that understand and transform Cangjie code with precision.
