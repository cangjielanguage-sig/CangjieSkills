# cj-apis-element_name

本目录包含Cangjie语言中`ohos.element_name`模块的API参考文档，主要用于描述和标识HarmonyOS应用组件的结构体。文档详细介绍了`ElementName`类的定义、属性（如bundleName、abilityName等）及其构造函数的使用方法。该模块目前处于Beta阶段，使用时需导入`kit.AbilityKit`。本文档适合使用Cangjie语言进行HarmonyOS应用开发的开发者，旨在帮助他们正确引用和定位应用组件，掌握必填参数与可选参数的配置规范。

## 详细描述

### cj-apis-element_name.md cj-apis-element_name.md

本文档提供了Cangjie语言中`ohos.element_name`模块的API参考，用于描述应用组件结构体。文档详细介绍了ElementName类的定义，包括其属性（bundleName、abilityName、deviceId、moduleName）和构造函数。关键信息指出该模块目前处于Beta阶段，需导入kit.AbilityKit，构造函数中bundleName和abilityName为必填项，其余为可选参数。本文档面向使用Cangjie语言的HarmonyOS开发者，旨在帮助其正确标识和引用应用组件。
