This directory provides essential API reference documentation for the `Mac` class within the Cangjie programming language, specifically designed for Message Authentication Code (MAC) encryption calculations. It serves as a comprehensive guide for developers implementing cryptographic security, covering the complete workflow of initialization, data updates, and finalization. Key topics include the `algName` property, `initialize(SymKey)`, `doFinal()`, `getMacLength`, and `update` functions. The documentation details system capabilities, version requirements, symmetric key constraints, and exception handling for errors like `BusinessException` and memory operation failures. Intended for Cangjie developers and security engineers, this resource requires familiarity with the CryptoArchitectureKit and CryptoFramework to effectively manage MAC operations and ensure data integrity in secure applications.
