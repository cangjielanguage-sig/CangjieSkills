# cangjie-arkts

This directory serves as a comprehensive technical resource for developers working within the HarmonyOS/OpenHarmony ecosystem, focusing on the interoperability between the ArkTS and Cangjie programming languages. It covers integration mechanisms, module creation, data manipulation, and multi-threading scenarios for mixed-language development. Key topics include declarative macros, interoperability libraries, DevEco Studio configuration, and cross-language data types like JSValue and JSContext. This collection is suitable for developers seeking to leverage Cangjie's performance within ArkTS applications or utilize existing ArkTS ecosystems in Cangjie projects.

## Detailed Description

### [1] add_cangjie_module
This directory serves as a comprehensive technical resource dedicated to the integration of the Cangjie programming language within the HarmonyOS development ecosystem. As Cangjie is a core language for the platform, this guide provides a structured app development approach.

### [2] add_cangjie_page
This directory provides a detailed guide on creating and integrating Cangjie page components in ArkTS projects. It covers core concepts of mixed development, embedding Cangjie pages as components in ArkTS containers, and the specific steps for creating Cangjie HybridComponent Files in DevEco Studio.

### [3] arkts_import_cangjie
This directory serves as a comprehensive technical resource for developers working within the HarmonyOS/OpenHarmony ecosystem, specifically focusing on the interoperability between ArkTS and the Cangjie programming language. It provides in-depth instructions for cross-language integration.

### [4] cangjie-load-arkts
This directory contains essential documentation for developers utilizing the Cangjie programming language to build applications within the HarmonyOS ecosystem. It specifically addresses the technical challenges and solutions for interoperability when loading ArkTS content.

### [5] cangjie_arkts_overview
This directory provides a comprehensive overview of the interoperability mechanisms between Cangjie and ArkTS on OpenHarmony. It highlights technical solutions for ecosystem reuse via library-level calls, covering bidirectional scenarios, macros, dynamic imports, and core types like JSValue and JSContext.

### [6] cj-arkts_auxiliary_lib
This directory provides a usage guide for the Cangjie-ArkTS interoperability auxiliary library, focusing on type compatibility. It details the `getJSContext` interface, which converts Cangjie `UIAbilityContext` objects to ArkTS-compatible `JSValue` types, solving type mismatch issues when calling native modules.

### [7] cj-arkts_interop_guidelines
This directory serves as a comprehensive resource for developers working on the interoperability between the Cangjie language and ArkTS. It establishes a standardized framework for the development process, ensuring that cross-language interactions are consistent and reliable.
