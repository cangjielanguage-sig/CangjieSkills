# 焦点控制

This directory provides comprehensive API documentation and resources for managing focus control within the ArkUI framework using the Cangjie language. It covers essential focus behaviors such as setting default focus, managing focus scopes, customizing navigation priorities, and styling focus indicators. Key topics include `focusScopeId`, `tabIndex`, `focusable`, and `groupDefaultFocus`. Additionally, it includes basic type definitions and practical example code for implementing complex navigation flows. This resource is suitable for UI developers and system engineers building accessible, interactive applications for HarmonyOS, particularly those requiring keyboard or remote control navigation.

### func_focusScopePriorityStr_3more.md func_focusScopePriorityStr_3more.md
This document serves as API reference documentation for managing component focus behavior in the ArkUI framework using Cangjie. It details three key functions: `focusScopePriority` for setting focus acquisition order within specific containers, `focusScopeId` for defining focus groups and container IDs, and `tabIndex` for customizing Tab key navigation. Key takeaways include the distinction between focus group navigation rules, where arrow keys navigate inside groups while Tab keys exit them, and the strict mutual exclusivity between `tabIndex` and `focusScopeId`. The documentation specifies constraints like unique IDs and non-nesting rules. This guide targets UI developers needing precise control over focus traversal and accessibility in complex applications.

### func_groupDefaultFocusBool.md func_groupDefaultFocusBool.md
This API reference document defines the `groupDefaultFocus` function for ArkUI development using the Cangjie language, designed to manage focus behavior within component containers. The documentation details the function signature, system capabilities, version requirements, and the required boolean parameter `isGroupDefaultFocus`. Key information highlights that this function designates a component as the default focus target when its parent container first gains focus. It is essential to note that this feature must be used in conjunction with the `tabIndex` attribute and only triggers on the initial focus event. If multiple components are marked, the system defaults to the first one found via depth traversal. This guide is intended for developers implementing accessible and intuitive navigation flows in user interfaces.
