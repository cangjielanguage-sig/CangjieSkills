# class_UserAuthInstance

This directory provides comprehensive API reference documentation for the `UserAuthInstance` class within the Cangjie programming language ecosystem. It is specifically designed to assist developers in executing user identity authentication and managing unified authentication widgets, with a strong focus on biometric security features. The documentation covers the complete class definition, method implementations for starting and stopping authentication, and mechanisms for subscribing to authentication result events. It includes critical information on prerequisites, such as obtaining instances via `getUserAuthInstance`, required permissions like `ohos.permission.ACCESS_BIOMETRIC`, and error handling via `BusinessException`. This resource is essential for Cangjie developers building secure applications that require robust user authentication capabilities, specifically targeting system capability version 19.
