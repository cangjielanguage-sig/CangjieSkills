This directory serves as a comprehensive technical repository for the HUKS (Harmony Universal KeyStore) signing and signature verification overview within the OpenHarmony ecosystem. It focuses on the critical cryptographic protocols required to maintain data integrity and non-repudiation across diverse hardware environments. The documentation provides a detailed breakdown of algorithm specifications, carefully distinguishing between standard and light devices to ensure optimal compatibility and performance. It covers a wide array of cryptographic primitives, including RSA, ECC, ED25519, and SM2, alongside their specific digest methods and padding modes. Furthermore, it addresses essential technical constraints such as salt lengths for RSA PSS and supported ECC curves. This resource is specifically designed for developers and security architects working on API level 15 and above, offering the necessary guidelines to implement robust security features and select the correct cryptographic parameters for their applications.
