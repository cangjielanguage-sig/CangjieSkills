# stdcore

The `stdcore` directory contains the foundational documentation for the Cangjie language's standard library core package. It provides essential programming capabilities, including built-in types like integers and floats, common I/O functions, and standard interfaces such as ToString and Hashable. This package is imported by default, offering immediate access to core classes like Array and String without explicit imports. It is suitable for Cangjie developers seeking to understand the language's basic environment, implement custom types, or perform low-level system operations. The documentation covers exception handling, utility functions, and comprehensive API references necessary for robust application development.
