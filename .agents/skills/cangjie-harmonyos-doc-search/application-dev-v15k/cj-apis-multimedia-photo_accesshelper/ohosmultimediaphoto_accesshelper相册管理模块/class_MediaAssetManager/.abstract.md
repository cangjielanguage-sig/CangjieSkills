This directory contains API reference documentation for the Cangjie class `MediaAssetManager`, part of the MediaLibraryKit for HarmonyOS. It focuses on requesting and managing media assets—such as images, moving photos, and videos—using strategy patterns. Key functionalities include retrieving image data, requesting video files to sandbox paths, and handling dynamic photo content. The documentation covers static methods, required permissions (e.g., `ohos.permission.READ_IMAGEVIDEO`), parameter specifications, and exception handling. It is intended for Cangjie and HarmonyOS developers who need to implement robust media access and processing features within their applications.
