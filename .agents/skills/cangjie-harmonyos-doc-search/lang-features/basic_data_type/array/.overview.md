## Detailed Description

### 数组类型/

This subdirectory encompasses the full spectrum of the array type system in the Cangjie programming language, categorizing them into Value Arrays (VArray) and Reference Arrays (Array). The content provides a granular look at the definitions, syntax construction, and various initialization methods available to developers. It goes beyond surface-level syntax to explain member operations and the distinct differences in memory management and performance characteristics between the two array types.

A significant portion of the material is dedicated to performance optimization. It details how to leverage heap memory allocation to enhance application speed and how to implement strategies that reduce pressure on the garbage collector, a key factor in maintaining high-performance applications. Furthermore, the directory explores the complexities of C language interoperability, illustrating how these array types can be used to communicate effectively with native C code while maintaining type safety. It also clarifies the nuances of reference semantics. These materials are highly recommended for developers seeking a profound understanding of Cangjie's collection data structures, those performing high-performance memory tuning, and developers working on low-level interactions with the C language.
