# 自定义文本样式

This directory provides a comprehensive guide to customizing text styles within the ArkUI framework using the Cangjie programming language. It covers essential visual adjustments such as text alignment, overflow handling, line height, and decoration lines, alongside advanced features like baseline offset, letter spacing, and adaptive font sizing. Additionally, it addresses text transformation and user interaction capabilities like text copying. These tutorials are designed for HarmonyOS developers and UI designers seeking to enhance the presentation, readability, and interactivity of text components in their applications through practical code examples and clear syntax demonstrations.

## Detailed Description

### 自定义文本样式_1.md
This tutorial guide explains how to customize text styles within the ArkUI framework using the Cangjie programming language. The document covers four primary styling aspects: text alignment using the textAlign property, handling text overflow with textOverflow and maxLines, setting line height via lineHeight, and applying decoration lines using the decoration property. Each section includes executable code snippets demonstrating how to implement these visual adjustments. The content is designed for developers looking to enhance the presentation and readability of text components in their applications, providing clear examples of property usage and expected visual outcomes.

### 自定义文本样式_2.md
This technical tutorial demonstrates how to implement advanced text styling in the ArkUI framework using the Cangjie programming language. The document covers four specific text properties: baselineOffset for vertical positioning, letterSpacing for character gaps, adaptive font sizing using minFontSize and maxFontSize, and textCase for capitalization. Key information includes the requirement that adaptive font sizing properties must be set simultaneously and paired with layout constraints like maxLines to function correctly. Targeted at UI developers, this guide provides code examples to refine text appearance and layout behavior within HarmonyOS applications.

### 自定义文本样式_3.md
This document serves as a code tutorial for customizing text styles in Cangjie UI development, specifically focusing on text transformation and interaction. The main topics include using the textCase attribute to control capitalization—Normal, LowerCase, and UpperCase—and the copyOption attribute to enable text copying within an application. Key takeaways demonstrate the syntax for applying these properties to the Text component to alter visual presentation and user interaction. This guide is intended for HarmonyOS developers using the Cangjie language to implement specific text formatting and clipboard features in their applications.
