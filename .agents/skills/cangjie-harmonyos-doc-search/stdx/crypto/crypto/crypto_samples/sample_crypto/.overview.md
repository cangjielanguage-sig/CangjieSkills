# sample_crypto

本目录包含一份示例文档，旨在演示如何在仓颉编程语言中利用SM4算法实现数据的加密与解密。文档详细介绍了`stdx.crypto`模块的应用，涵盖了从导入加密库、配置CBC模式、初始化密钥到执行加解密操作的完整流程。此外，还展示了字节数组与字符串之间的转换技巧，以确保数据的完整还原。该资源特别适合仓颉开发者参考，为SM4类的实际应用提供了清晰的代码示例和最佳实践。
