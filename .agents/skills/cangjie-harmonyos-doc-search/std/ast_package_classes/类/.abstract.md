This directory provides comprehensive API reference documentation for the Abstract Syntax Tree (AST) classes of the Cangjie programming language. It covers the structural definition, properties, and methods for a wide array of syntax nodes, including declarations, expressions, types, patterns, and statements. Key topics include AST manipulation, token conversion, and the Visitor pattern implementation for traversing syntax trees. This documentation is intended for compiler developers, language tool engineers, and software developers working on static analysis, parsing, or code generation tools within the Cangjie ecosystem.
