# 导航转场

This directory provides comprehensive resources for implementing navigation transitions and page routing using the Cangjie UI framework. It details the architectural components required for building multi-page applications, specifically focusing on the `NavDestination` and `NavPathStack` components. The content covers the full lifecycle of navigation, from initializing path stacks and defining primary interfaces to executing complex routing logic like `pushPath` and `pop`. It also addresses animation effects during page transitions. Suitable for Cangjie developers, these guides offer both theoretical definitions and practical code examples, such as settings-style lists, to facilitate the development of intuitive and responsive user interfaces. By following these tutorials, developers can master the essential skills needed to manage application state and user flow effectively.

## Detailed Description

### 创建导航子页.md
This document serves as a technical tutorial demonstrating how to implement navigation sub-pages using the Cangjie UI framework. It covers the creation of two specific pages, PageOne and PageTwo, utilizing the NavDestination component and NavPathStack for routing management. The guide explains initializing the path stack via the onReady lifecycle method and implementing navigation logic: using the pop method to return to the previous page and pushPath to navigate to a new page with parameters. It targets Cangjie developers seeking to implement page transitions and stack management in their applications.

### 导航转场_2more.md
This document serves as a tutorial for implementing navigation transitions in a UI framework using the Cangjie language. It defines navigation transitions as the animation effects during page routing and recommends using the Navigation and NavDestination components. The primary section, "Creating a Navigation Page," outlines a three-step process: initializing the Navigation component with a NavPathStack, defining a List for primary interfaces, and implementing page jumps via the pushPath method. The document includes a complete code example demonstrating a settings-style list that navigates to specific pages based on user interaction. This guide targets developers seeking to implement routing and page transitions in their applications.
