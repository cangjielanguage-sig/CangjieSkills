This directory serves as a comprehensive API reference index for the Cangjie language's Abstract Syntax Tree (AST) package. It documents core interfaces, enumerations, data structures, and exception classes essential for compiler development and metaprogramming. The content covers serialization mechanisms, token conversion, lexical analysis, and hierarchical class structures for syntax nodes. Designed for compiler engineers, tool builders, and advanced developers, this resource facilitates the implementation of macros, source code manipulation, and static analysis tools within the Cangjie ecosystem.
