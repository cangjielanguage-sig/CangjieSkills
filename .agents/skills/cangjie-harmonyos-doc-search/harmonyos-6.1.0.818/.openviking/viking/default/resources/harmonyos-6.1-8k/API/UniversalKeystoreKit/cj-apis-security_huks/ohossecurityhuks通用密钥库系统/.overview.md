# ohossecurityhuks通用密钥库系统

本目录包含鸿蒙系统通用密钥库（HUKS）的仓颉语言API参考文档，涵盖密钥的全生命周期管理及密码学操作。内容包括密钥生成、导入、导出、删除、加解密会话管理，以及密钥属性配置（如算法、用途、填充模式、认证类型等）。核心关键词包括HUKS、仓颉、密钥管理、加密算法、安全认证。该文档适用于使用仓颉语言进行HarmonyOS/OpenHarmony安全应用开发的工程师，旨在帮助开发者实现硬件级密钥存储和精细化的访问控制。
