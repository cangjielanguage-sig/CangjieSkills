This directory serves as a comprehensive resource for the `cj-apis-ability_access_ctrl` module, specifically tailored for the HarmonyOS Cangjie development environment. It is dedicated to program access control management, providing developers with the necessary tools to implement robust security and permission handling mechanisms. The content covers critical components such as the `GrantStatus` enumeration for defining permission states and the `AtManager` class for managing access tokens. Additionally, it details methods for verifying and requesting user permissions. This documentation is primarily suitable for Cangjie developers who aim to secure their applications by implementing effective authentication, authorization, and runtime permission request flows, ensuring secure and compliant interaction with system capabilities.
