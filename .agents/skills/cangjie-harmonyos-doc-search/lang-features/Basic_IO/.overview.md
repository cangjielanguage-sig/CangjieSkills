# Basic_IO

This directory serves as a comprehensive educational resource for understanding Input/Output (I/O) operations within the Cangjie programming language. It covers the fundamental architecture of I/O streams, including stream abstractions, standardized interfaces for reading and writing, and the distinction between node streams and processing streams. Key topics include binary data handling, the decorator pattern, and specific implementations like buffered and string streams. The material explains how to efficiently interact with external data sources and unifies the handling of various I/O forms, such as files and networks. This content is suitable for beginners seeking to grasp the basics of I/O as well as experienced developers looking to deepen their understanding of underlying stream mechanisms and efficient data interaction in Cangjie. By mastering these concepts, users can effectively manage data flow across different contexts.

## Detailed Description

### [1] basic_IO_overview
This directory delves deeply into the infrastructure and core concepts of I/O (Input/Output) streams in the Cangjie programming language. It details how to utilize stream abstraction mechanisms to interact efficiently with external data sources. The content covers the definition of streams, standardized interface specifications for input and output streams (such as the use of `read` and `write` functions), and the classification logic of node streams versus processing streams. The documentation emphasizes the importance of Stream as an interface for handling binary data and introduces the application of the decorator pattern. It demonstrates how the Cangjie language unifies the handling of various I/O forms, such as files and networks. This guide is highly suitable for beginners of the Cangjie language and developers who need to deeply understand underlying I/O operations, aiming to help them build a solid foundation.

### [2] basic_IO_process_stream
This directory provides a comprehensive overview of basic I/O processing streams specifically designed for the Cangjie programming language. It focuses on the critical concepts of buffered streams and string streams, offering developers the knowledge necessary to optimize data handling and manipulation within their applications.

### [3] basic_IO_source_stream
This directory serves as a comprehensive educational resource for understanding Input/Output (I/O) operations within the Cangjie programming language, specifically focusing on source streams and node streams. It provides a deep dive into the fundamental principles required to establish data sources and manage raw data flow effectively.
