# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework, specifically utilizing the Cangjie programming language. It covers essential functions for defining the visual appearance, interaction behaviors, and dimensional constraints of UI components. Key topics include styling pattern locks, managing grid states, and setting uniform component sizes. This documentation is intended for UI developers and software engineers who are building applications using ArkUI and require precise control over component attributes and layout behaviors.

### func_activateCircleStyleCi_8more.md func_activateCircleStyleCi_8more.md

### func_sideLengthLength.md func_sideLengthLength.md
This document serves as API reference documentation for the sideLength function in the Cangjie programming language, designed to uniformly set a component's width and height within the ArkUI framework. The content details the function signature, system capabilities, version compatibility, and a parameter table specifying the required Length input. Key information indicates that the function sets equal dimensions for a component, defaults to 288.vp, and hides the component if the value is zero or negative. It returns the component instance to support method chaining. This reference guide targets Cangjie developers utilizing ArkUI for user interface development who need to programmatically control component sizing.
