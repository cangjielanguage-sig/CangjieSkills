# struct_Decimal

This directory provides API reference documentation for the `Decimal` struct in the Cangjie programming language's standard library. It focuses on arbitrary-precision signed decimal numbers, essential for high-precision numeric calculations. The content covers initialization from various types, mathematical operations, type conversions, and operator overloads. Key features include handling overflow strategies, rounding modes, and string parsing. This documentation is suitable for Cangjie developers implementing financial or scientific algorithms requiring exact decimal representation and precise arithmetic control.
