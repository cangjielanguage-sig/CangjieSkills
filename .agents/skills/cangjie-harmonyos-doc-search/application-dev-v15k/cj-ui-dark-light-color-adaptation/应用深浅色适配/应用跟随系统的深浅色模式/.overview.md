# 应用跟随系统的深浅色模式

This directory focuses on the technical implementation of system-wide dark and light mode adaptation for applications. It is designed to help developers ensure their user interfaces remain consistent with the operating system's visual settings, thereby enhancing user comfort and accessibility. The guide covers a wide range of topics, including color adaptation using custom resource directories or system resource IDs, image resource adaptation via qualifiers or SVG properties, and specific configurations for Web components. It also delves into advanced programming techniques such as implementing event listeners through AbilityStage lifecycle methods and utilizing AppStorage for state management during theme transitions. This resource is specifically tailored for developers working with the Cangjie language, providing them with the essential knowledge and code patterns required to handle custom logic when the system theme changes.

## Detailed Description

### 应用跟随系统的深浅色模式_1.md

This document is a comprehensive technical guide that explains the step-by-step process of implementing system-wide dark and light mode adaptation in applications. It addresses the critical need for UI consistency with system settings, ensuring that the application's visual appearance automatically adjusts to the user's preferred theme.

The guide covers three main areas of adaptation:
1.  **Color Adaptation:** It details how to use custom resource directories or system resource IDs to manage color changes effectively.
2.  **Image Adaptation:** It provides methods for adapting image resources using qualifiers or by manipulating SVG properties.
3.  **Web Component Configuration:** It includes specific instructions for ensuring web-based components within the app also follow the system theme.

Furthermore, the document highlights key takeaways such as using the 'dark' resource qualifier for automatic switching. It also provides advanced implementation details for developers using the Cangjie language, specifically how to set up event listeners via AbilityStage lifecycle methods and AppStorage. This allows for the execution of custom logic whenever the system mode changes, ensuring a robust and responsive user interface.
