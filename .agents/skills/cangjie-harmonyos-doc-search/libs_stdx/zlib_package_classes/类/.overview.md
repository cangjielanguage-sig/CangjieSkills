# 类

This directory contains API reference documentation for stream-based compression and decompression classes within the Cangjie programming language's zlib package. It covers four primary classes designed to handle data transformation: `CompressInputStream`, `CompressOutputStream`, `DecompressInputStream`, and `DecompressOutputStream`. These resources detail constructors, methods for reading and writing data, buffer management, and resource cleanup. Targeted at Cangjie developers, the documentation provides syntax, usage examples, and error handling details for implementing efficient data compression workflows in applications.

## Detailed Description

### class_CompressInputStream.md
This API reference document details the CompressInputStream class, designed to compress data from a bound input stream in the Cangjie programming language. It covers the class constructor for configuring compression parameters like format and buffer size, the read function for processing data into a byte array, and the close function for resource management. Key takeaways include the ability to bind any InputStream, customizable compression levels, and the necessity of calling close to prevent memory leaks. Targeted at Cangjie developers, this guide provides the necessary syntax and usage examples for implementing stream-based compression using the zlib package.

### class_CompressOutputStream.md
This API documentation defines the CompressOutputStream class in the Cangjie zlib package, designed to compress data and write it to a bound output stream. The document covers the class constructor, which configures compression format, level, and buffer size, alongside methods for writing, flushing, and closing the stream. Key information includes the requirement to call close() to finalize compressed data and release resources, as well as error handling via ZlibException. Intended for Cangjie developers, this reference guides users in implementing data compression using standard streams.

### class_DecompressInputStream.md
This document serves as API reference for the DecompressInputStream class in the Cangjie standard library, designed to decompress data from input streams. Main sections cover the class constructor, which binds to an InputStream and configures the decompression format and buffer size, alongside the read and close methods. Key information includes parameter definitions for WrapType and buffer length, return values for the read function, and exception handling for ZlibException. A practical code example demonstrates the decompression workflow. Intended for Cangjie developers, this documentation requires knowledge of input streams and byte arrays. Keywords: DecompressInputStream, zlib, Cangjie, API, decompression, InputStream.

### class_DecompressOutputStream.md
This API documentation defines the DecompressOutputStream class in the Cangjie standard library, designed to decompress data streams and output them to a bound OutputStream. It details the class constructor for configuring the output stream, compression format (WrapType), and buffer size. Additionally, it documents key methods: write for decompressing byte arrays, flush for clearing buffers, and close for resource management. The document highlights error handling via ZlibException for invalid states or incomplete data and includes a practical example demonstrating the decompression workflow from a byte array to a file. Targeted at Cangjie developers implementing data decompression, this reference requires knowledge of stream handling and the zlib package.
