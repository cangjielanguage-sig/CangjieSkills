# Image

This directory contains comprehensive documentation for the Image component within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers essential aspects such as component initialization, event handling, property configuration, and universal attribute support. The content includes API references for constructors, callbacks, and data structures, alongside practical examples for displaying various image formats like PNG, JPG, SVG, and GIF. It addresses critical topics like network permissions, animation lifecycle, and error handling. This documentation is suitable for HarmonyOS application developers and UI engineers seeking to implement robust, high-performance image display and interaction features in their applications.

## Detailed Description

### Image_3more.md Image_3more.md
This document provides a reference guide for the Image component, detailing its usage for displaying various image formats including PNG, JPG, SVG, and GIF. It covers supported formats, specific usage notes regarding focus states and animation behavior, required network permissions, and child component restrictions. Key takeaways include the requirement for ohos.permission.INTERNET for network images, the dependency of animation playback on node visibility events, and the need to enable focusable attributes for keyboard interaction. Intended for application developers, this guide assumes familiarity with UI component attributes and configuration files.

### 创建组件.md 创建组件.md
This document serves as an API reference for initializing the Image component in the Cangjie programming language within the ArkUI framework. It details four overloaded constructor methods: init(String), init(AppResource), init(PixelMap), and init(ImageContent), each accepting different data source types for loading images. Key takeaways include the component's behavior on load failure, default center cropping, and adaptive sizing when dimensions are undefined. It also specifies system capabilities and version requirements. The target audience is HarmonyOS developers using Cangjie who need to display images from various sources like networks, local files, or pixel maps.

### 组件事件.md 组件事件.md
This document serves as an API reference for image component event handling within the ArkUI framework using the Cangjie language. It details three primary callback functions: onComplete, which triggers upon successful image loading and returns dimensions; onError, invoked during loading failures; and onFinish, specific to animated SVG playback completion. All functions require mandatory callback parameters and are available starting from version 12. The documentation is intended for developers implementing robust image loading logic and animation lifecycle management in their applications.

### 通用属性通用事件.md 通用属性通用事件.md
This reference document outlines the support status of universal attributes and events for a specific UI component within the ArkUI framework. The content is divided into two primary sections: Universal Attributes and Universal Events. The key takeaway is that the component generally supports all universal attributes and events. However, a critical exception is noted for the Image component, which does not support the foregroundColor attribute; developers must use the fillColor attribute instead to set fill colors. This documentation is intended for developers and UI designers seeking to implement and style components correctly within the ArkUI development environment.
