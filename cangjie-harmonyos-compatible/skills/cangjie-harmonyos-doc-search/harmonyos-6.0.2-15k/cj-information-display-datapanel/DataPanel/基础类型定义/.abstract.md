This directory contains API reference documentation for fundamental data types and enumerations used within the ArkUI framework and the Cangjie programming language. It covers essential definitions for data panel styles, shadow configurations, and linear gradients. Key components include the `DataPanelType` enum for panel shapes, the `DataPanelShadowOptions` class for visual effects, and the `LinearGradient` and `ColorStop` classes for color management. These definitions are critical for developers and UI designers aiming to implement and customize data visualization components and graphical effects in their applications.
