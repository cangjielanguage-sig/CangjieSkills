This directory provides essential API reference documentation for the Cangjie class `AlertDialogParamWithConfirm`, specifically designed for use within the ArkUI framework. It focuses on the technical implementation of alert dialogs that feature a confirmation button, detailing the class structure, inheritance from `AlertDialogParam`, and constructor parameters. Key topics include system capabilities, versioning (introduced in version 22), and the granular configuration of the confirm button, including text, style, and event callbacks. Furthermore, it encompasses resources for initializing dialog components with advanced styling, layout alignment, and window properties like modality. This documentation is highly suitable for Cangjie developers and UI engineers aiming to build sophisticated, interactive modal dialogs and customizable user interface components with specific visual effects and interaction logic. It serves as a comprehensive guide for mastering the nuances of dialog management in modern application development.
