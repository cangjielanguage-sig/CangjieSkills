# 网络连接管理

This directory focuses on network connection management using the Cangjie language and HarmonyOS NetworkKit. It covers essential tasks such as DNS resolution, network state monitoring, capability querying, and handling network switches. Key topics include obtaining network handles, binding applications to specific networks, and managing permissions like `ohos.permission.INTERNET` and `ohos.permission.GET_NETWORK_INFO`. The resources are designed for developers building network-aware applications that require robust connectivity management across Wi-Fi, cellular, and Ethernet networks.

## Detailed Description

### 使用对应网络解析域名获取所有IP.md 使用对应网络解析域名获取所有IP.md
This technical guide demonstrates how to resolve a domain name to retrieve all associated IP addresses using the default network in a Cangjie application. The document outlines a three-step process: declaring the required ohos.permission.INTERNET permission, importing the kit.NetworkKit module, and calling the getAddressesByName function. Key information includes a code example showing the API usage, which returns an Array of NetAddress objects. It emphasizes the necessity of configuring normal-level permissions prior to network operations. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to implement network address resolution in their applications.

### 接口说明.md 接口说明.md
This document provides a reference guide for Cangjie NetworkKit APIs, specifically focusing on network connection management interfaces. The content is organized into a comprehensive table listing functions for retrieving network handles, binding applications to specific networks, querying network capabilities and properties, resolving domain names, and subscribing to network state changes. Key functions include getDefaultNet for obtaining network handles, setAppNet for binding apps, and multiple callback-based methods like onNetAvailable for monitoring network status changes asynchronously. This reference material targets Cangjie developers who need to implement network monitoring, connectivity management, and DNS resolution in their applications.

### 接收指定网络的状态变化通知.md 接收指定网络的状态变化通知.md
This document provides a step-by-step tutorial for developers on how to monitor and receive status change notifications for a specific network in HarmonyOS using the Cangjie language. It covers essential procedures including declaring the required GET_NETWORK_INFO permission, importing the NetworkKit, and creating a NetConnection object with specific network capabilities and timeout settings. Key takeaways involve using the createNetConnection method to target specific networks like cellular, registering callbacks for netAvailable and netUnavailable events, and managing the subscription lifecycle via register and unregister methods. This guide is intended for application developers who need to implement real-time network state awareness and resource management in their apps.

### 监控默认网络变化并主动重建网络连接_2more.md 监控默认网络变化并主动重建网络连接_2more.md
This technical guide explains how to monitor default network changes and proactively migrate application traffic to new networks to maintain connectivity. It covers scenarios triggering network switches, such as weak signals or interface toggles, and details two main procedures: monitoring network availability using `onNetAvailable` and retrieving all registered networks via `getAllNets`. Key information includes Cangjie code examples, the required `ohos.permission.GET_NETWORK_INFO` permission, and specific API methods within the `kit.NetworkKit`. Targeted at developers building network-aware applications, this document ensures robust handling of dynamic network environments and cross-network transitions.

### 简介_4more.md 简介_4more.md
This document provides an overview of network connection management capabilities, focusing on multi-network priority, quality assessment, and DNS resolution using the Cangjie programming language. The content covers basic concepts defining network producers and consumers, constraints specifying the development language, and typical usage scenarios. Key information includes network detection methods like DNS and HTTP probes, and network optimization logic for selecting the best connection among WiFi, cellular, and Ethernet. This guide targets developers seeking to implement network status monitoring, connection queries, and domain resolution in their applications.

### 根据数据网络查询网络的能力信息及连接信息/
This directory provides comprehensive resources for querying network capabilities and connection information using the NetworkKit module within the Cangjie programming language. It covers the complete workflow for HarmonyOS developers, starting from declaring necessary permissions like `ohos.permission.GET_NETWORK_INFO` to importing modules and obtaining network handles. The content explains how to identify network types (Cellular, Wi-Fi), check specific features (MMS, Internet), and retrieve link or routing details. It is suitable for developers aiming to implement robust network status monitoring, manage active data connections, and optimize application behavior based on real-time network states. Keywords include NetworkKit, Cangjie, NetHandle, getNetCapabilities, and getConnectionProperties.
