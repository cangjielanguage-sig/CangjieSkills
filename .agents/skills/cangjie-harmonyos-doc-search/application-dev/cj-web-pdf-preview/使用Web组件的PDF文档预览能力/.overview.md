# 使用Web组件的PDF文档预览能力

This directory serves as a comprehensive technical resource for developers aiming to implement PDF document preview capabilities within their applications. It focuses on utilizing the ArkUI Web component combined with the Cangjie programming language. The content covers the complete implementation lifecycle, beginning with basic setup and various loading scenarios—such as handling network PDFs, local sandbox files, and application resource files—and progressing to advanced customization techniques. It also addresses critical configuration steps, including necessary permissions in `module.json5` and the use of URL parameters to manipulate view states like zoom levels and UI element visibility. This guide is specifically designed for application developers working within the ArkUI framework who require robust integration of document viewing features.

## Detailed Description

### 使用Web组件的PDF文档预览能力_1.md 使用Web组件的PDF文档预览能力_1.md
This technical guide explains how to implement PDF document preview functionality within applications using the ArkUI Web component and the Cangjie programming language. It details three primary loading scenarios: network PDFs, local sandbox files, and application resource files, alongside necessary permission configurations in module.json5. Key takeaways include the requirement for INTERNET and fileAccess permissions, the use of domStorageAccess for UI persistence, and specific syntax for the src parameter. Intended for application developers using the ArkUI framework who need to integrate document viewing capabilities.

### 使用Web组件的PDF文档预览能力_2.md 使用Web组件的PDF文档预览能力_2.md
This document explains how to configure and control PDF document previews within a Web component using URL parameters. It covers the basic Web component implementation for PDF loading and details supported URL parameters like page navigation, zoom levels, and UI element visibility (toolbar, navigation panes). Developers can manipulate the initial view state by appending specific syntax such as page=3, zoom=scale, or toolbar=0 to the PDF URL. This technical reference is intended for application developers using the Web component to embed and customize PDF viewing experiences.
