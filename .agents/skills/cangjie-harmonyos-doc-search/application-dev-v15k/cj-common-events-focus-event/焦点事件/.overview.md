# 焦点事件

This directory serves as a technical resource for managing focus events and behaviors within the Cangjie ArkUI framework. It covers the interaction between focus, keyboard events, and click handlers, alongside customization of focus styles and programmatic control. Key topics include focus groups, acquisition priorities, and event callbacks like `onFocus` and `onBlur`. Additionally, it provides foundational concepts, component capability references, and rules for setting default focus. This guide is intended for UI developers and system architects aiming to implement robust keyboard navigation and accessibility in HarmonyOS applications.

## Detailed Description

### 焦点与按键事件.md 焦点与按键事件.md
This document explains the interaction mechanism between component focus, keyboard events (Enter/Space), and click handlers in UI development. It covers focus behavior, event triggering rules, and the specific bubbling differences between onClick and onKeyEvent. Key takeaways include that Enter and Space keys trigger click events on focused components, but unlike onKeyEvent, these triggered click events do not bubble up to parent components. The document provides a Cangjie code example demonstrating a button with an onClick handler. Intended for UI developers using the ArkUI framework, this guide helps implement keyboard accessibility and manage event propagation logic effectively.

### 焦点样式_2more.md 焦点样式_2more.md
This document guides developers on customizing system focus styles and implementing programmatic focus control in Cangjie ArkUI applications. It covers the `focusBox` API for styling focus frames and the `FocusControl.requestFocus` method for active focus management. Key takeaways include the automatic `zIndex` elevation to `INT_MAX` for focused components and the ability to define stroke color, width, and margins. The `requestFocus` function allows transferring focus via component IDs at the next frame signal. Targeted at UI developers using Cangjie, this reference requires knowledge of component attributes and event handling.

### 焦点组与获焦优先级.md 焦点组与获焦优先级.md
This document explains how to manage focus groups and focus acquisition priority in Cangjie UI development. It covers the API definitions for focusScopePriority and focusScopeId, a practical code example demonstrating nested components, and an analysis of focus behavior. Key concepts include setting container IDs, defining focus groups to separate Tab and arrow key navigation, and using FocusPriority to control initial focus targets. The document notes that focus groups cannot be mixed with tabIndex. This is intended for UI developers using the Cangjie language who need to implement complex keyboard navigation and focus management in HarmonyOS applications.

### 获焦失焦事件.md 获焦失焦事件.md
This document serves as API documentation and a tutorial for handling focus and blur events in Cangjie UI development. It details the `onFocus` and `onBlur` functions, explaining how to bind callbacks that trigger when components gain or lose focus. The text includes a complete code example demonstrating how to use these events with state management to visually indicate focus status on buttons via keyboard navigation. Key takeaways include the paired usage of these interfaces and the implementation of dynamic style changes. This resource is intended for Cangjie developers building interactive user interfaces.

### 基础概念与规范/

It covers essential definitions like Focus Chains, Root Containers, and Hierarchical Pages, as well as the algorithms driving focus movement. Additionally, it details the specifications for active and passive navigation behaviors, including keyboard traversal and programmatic requests. This resource is ideal for UI developers and system architects seeking to implement robust navigation logic and custom focus behaviors in component-based frameworks.

The content is essential for understanding keyboard navigation, accessibility compliance, and interaction logic. It is suitable for UI developers, accessibility engineers, and application designers who need to implement or verify focus states in their user interfaces.

### 设置组件是否可获焦/
This directory provides comprehensive technical guidance on managing component focusability within the ArkUI framework using the Cangjie language. It covers essential properties such as `focusable`, `enabled`, `visibility`, and `focusOnTouch`, detailing how to categorize components based on their inherent focus capabilities. The documentation explains critical behaviors, including implicit focus acquisition through click events, the removal of focus when components are disabled, and the logic behind automatic focus transfer. This resource is suitable for ArkUI developers and UI engineers seeking to implement robust keyboard navigation, debug focus behavior, or manage complex state-dependent focus logic in their user interfaces.

### 默认焦点/
This directory provides a technical overview of focus management mechanisms specifically designed for Cangjie UI development. It focuses on the essential practices for setting and managing default focus across pages and container components. The content covers the utilization of the `defaultFocus` API and clearly distinguishes its role from `FocusPriority`, which is used for determining child focus within containers. Additionally, it explores the complex logic behind focus chain formation during different types of focus events, such as overall versus non-overall focus. The directory also outlines specific rules for focus restoration, such as prioritizing the last focused node or the highest priority component when a user re-enters a view. This resource is highly suitable for Cangjie UI developers who are looking to implement sophisticated keyboard navigation and enhance accessibility features in their applications.
