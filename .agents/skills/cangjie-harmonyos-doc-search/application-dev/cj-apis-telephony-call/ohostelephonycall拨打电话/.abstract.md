This directory provides API reference documentation for the `ohos.telephony.call` module in the Cangjie language, designed for HarmonyOS developers. It encompasses telephony management functionalities including initiating calls, retrieving call status, formatting phone numbers, and configuring emergency options. The documentation covers core classes like `Call`, enumerations for call states, and configuration options for number formatting. It is intended for software engineers utilizing TelephonyKit to implement robust communication features, requiring knowledge of Cangjie and system version 22 capabilities.
