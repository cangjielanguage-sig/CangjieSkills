This directory serves as a comprehensive technical resource for the `cj-crypto-compute-mac` module, specifically designed to facilitate the implementation of Message Authentication Codes (MAC) within the Cangjie programming language ecosystem. It focuses heavily on Hash-based MAC (HMAC) algorithms, which are indispensable for modern security protocols requiring data integrity and authentication. The content guides developers through the process of using shared secret keys combined with cryptographic hash functions to generate fixed-length verification codes, effectively preventing unauthorized tampering during data transmission and storage. Key topics include the theoretical underpinnings of MAC, the specifics of supported hash algorithms such as SHA256, SM3, and MD5, and detailed practical implementation steps. This resource is ideally suited for software developers, security engineers, and system architects who are building secure applications in Cangjie and need to integrate robust, standardized message authentication mechanisms to protect sensitive information against evolving cyber threats.
