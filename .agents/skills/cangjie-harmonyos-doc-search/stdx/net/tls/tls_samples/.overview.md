# tls_samples

This directory contains a comprehensive collection of samples and documentation for implementing TLS (Transport Layer Security) using the Cangjie programming language. It covers essential aspects of secure communication, ranging from basic server and client configuration to advanced features like certificate hot updates and session resumption. The resources demonstrate how to handle PEM files, configure `TlsServerConfig` and `TlsClientConfig`, and manage secure TCP connections efficiently. This collection is suitable for Cangjie developers looking to build secure network applications, implement HTTPS services, or maintain high-availability servers with dynamic certificate updates.

## Detailed Description

### [1] cert_key
This directory contains documentation on handling server certificates and private keys in the Cangjie programming language. It focuses on reading and parsing a single PEM file containing both the certificate and private key, and applying them to initialize a TLS server configuration. The documentation details the complete process of using `Pem.decode` for data parsing, extracting `X509Certificate` and `PrivateKey` objects via label filtering, and finally constructing the `TlsServerConfig`. Core keywords include Cangjie, TLS, PEM parsing, X509 certificates, and private keys. This material is suitable for developers who need to configure HTTPS services in a Cangjie environment.

### [2] client
This directory provides a comprehensive guide to developing TLS clients using the Cangjie programming language. It details the entire process from establishing low-level TCP connections to high-level TLS security configuration, with particular emphasis on trust mode settings, ALPN protocol negotiation, and session state management. A key highlight is the demonstration of using `TlsClientConfig` and `TlsSocket` to achieve secure communication, along with an in-depth explanation of the session resumption mechanism via the `lastSession` variable to optimize reconnection performance. This resource is ideal for developers who have mastered basic Cangjie syntax and wish to delve deeper into network programming and secure communication implementation.

### [3] hot_update_cert
This directory offers a detailed guide on implementing TLS certificate hot updates in Cangjie server applications. It explores how to dynamically replace certificates without interrupting the service, covering the specific implementation details of the `MyServer` class, `TlsServerConfig` management strategies, and techniques for dynamically updating certificate chains and private keys using property setters. The core mechanism ensures that certificate configuration changes only affect new connections, thereby maintaining the stability of existing connections, achieving seamless switching by referencing the current configuration object in the `onAcceptedConnection` callback. This resource is highly suitable for Cangjie developers who need to maintain high-availability network services.

### [4] server
