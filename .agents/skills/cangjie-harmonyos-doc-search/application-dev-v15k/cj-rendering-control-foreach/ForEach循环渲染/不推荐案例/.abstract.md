This directory serves as a comprehensive repository of technical documentation designed to highlight anti-patterns and common pitfalls encountered during ArkUI development using the Cangjie language. It specifically addresses critical issues related to the `ForEach` component, focusing on scenarios that lead to incorrect UI updates and significant performance degradation caused by improper key generation strategies. Key topics covered include component lifecycle management, state management nuances, rendering efficiency optimization, and the implementation of stable key generators to ensure smooth UI behavior. These resources are essential for developers seeking to optimize application performance and avoid complex bugs associated with list rendering and dynamic data manipulation. By understanding these "not recommended" cases, developers can write more robust and efficient code.
