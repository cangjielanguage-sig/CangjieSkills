# 组件快捷键事件

This directory focuses on the implementation, management, and constraints of keyboard shortcuts within the ArkUI framework using the Cangjie language. It covers the `keyboardShortcut` interface, detailed usage rules, system-level restrictions, and event handling behaviors. Key topics include focus dependencies, conflict resolution, modifier key handling, and prohibited system key combinations. The documentation is designed for HarmonyOS developers who need to enhance user interaction through custom hotkeys while adhering to system constraints and event priorities.

## Detailed Description

### 快捷键使用注意事项.md 快捷键使用注意事项.md
This document serves as a technical reference guide detailing the usage rules, behaviors, and precautions for implementing keyboard shortcuts within the system, specifically noting their priority over standard OnKeyEvent events. It covers various scenarios including custom combination key requirements, conflict resolution when multiple components share shortcuts, focus dependencies, and unbinding methods. Key takeaways include that shortcuts respond based on window focus rather than component focus, hidden components still trigger shortcuts while disabled ones do not, and the system does not distinguish between left/right modifier keys or uppercase/lowercase characters. The document also outlines invalid binding scenarios such as duplicate keys or multi-character values. Intended for developers using the ArkUI framework, this guide requires knowledge of component event handling and the keyboardShortcut interface to effectively manage user input interactions.

### 禁止绑定的系统快捷键_3more.md 禁止绑定的系统快捷键_3more.md
This reference document outlines system shortcut key restrictions and event handling priorities for developers. It covers prohibited key combinations, existing system key events with priority rules, and a Cangjie code example. Key takeaways include that developers cannot bind specific combinations like Alt+F4 or Ctrl+Shift+Esc, and system events such as Tab or Arrow keys will intercept custom events based on component focus. The code example demonstrates dynamic shortcut binding and highlights limitations when assigning multiple shortcuts. This guide targets HarmonyOS developers using the Cangjie language who need to implement custom keyboard shortcuts while respecting system-level constraints.

### 组件快捷键事件_5more.md 组件快捷键事件_5more.md
This API documentation details how to implement custom keyboard shortcuts for components within the ArkUI framework using the Cangjie language. The document covers the general behavior of shortcut events and provides four overloaded function signatures for the keyboardShortcut method, supporting both character strings and function keys with optional modifier keys and custom actions. Key information includes that shortcuts trigger even if the component is not focused or visible, provided it is mounted in the focused window. If no custom action is defined, the shortcut defaults to a click event. The API requires SystemCapability.ArkUI.ArkUI.Full and is available from version 12. This guide targets developers building ArkUI applications who need to enhance user interaction via global or local keyboard hotkeys.
