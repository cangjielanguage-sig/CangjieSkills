This directory contains the API reference documentation for the HarmonyOS Bluetooth Access module, designed for the Cangjie programming language. It covers the essential functionalities for managing Bluetooth radio states, including enabling, disabling, and retrieving the current state of the device. The module also provides mechanisms for subscribing to and handling Bluetooth state change events through specific callback types and enums. Key components include the `BluetoothState` and `BluetoothAccessCallbackType` enums, along with functions for state management and event listening. This documentation is intended for HarmonyOS developers using the ConnectivityKit to integrate basic Bluetooth power operations and status monitoring into their applications.
