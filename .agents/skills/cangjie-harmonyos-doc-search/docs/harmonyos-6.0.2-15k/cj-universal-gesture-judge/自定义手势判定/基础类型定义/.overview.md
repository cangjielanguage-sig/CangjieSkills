# 基础类型定义

This directory provides comprehensive API references for foundational data structures essential for event and gesture handling within the ArkUI framework using the Cangjie language. It encompasses base event properties, specific gesture event types such as pinch and rotation, and structures for controlling gesture recognition logic. Key topics include input metrics, finger tracking, coordinate systems, and gesture judgment results. This documentation is specifically designed for developers building ArkUI applications who require precise control over touch interactions, custom gesture implementation, and low-level input event processing.

## Detailed Description

### class_BaseEvent.md class_BaseEvent.md
This document serves as an API reference for the BaseEvent class, which defines foundational properties for event handling in the Cangjie language within the ArkUI framework. It details read-only properties such as event target, timestamp, input device ID, source type, and specific input metrics like pressure, tilt angles, and axis values. Key information includes support for checking modifier key states and distinguishing between different input tools. All properties are read-only and available starting from API version 19. This reference is intended for developers working on ArkUI applications who need to process low-level input events and gestures.

### class_BaseGestureEvent_3more.md class_BaseGestureEvent_3more.md
This API reference document outlines the class structures for handling gesture events in the ArkUI framework using the Cangjie language. It details the base class BaseGestureEvent, which provides finger information, and its specific implementations: LongPressGestureEvent for detecting repeated triggers and PanGestureEvent for tracking sliding offsets and velocities. Key information includes read-only properties for finger lists, boolean repetition states, and precise coordinate metrics. This guide is intended for developers implementing custom gesture recognition logic, particularly for use within the onGestureJudgeBegin callback.

### class_GestureInfo_3more.md class_GestureInfo_3more.md
This document serves as API reference documentation for gesture handling structures in the Cangjie language within the ArkUI framework. It covers the `GestureInfo` class, which encapsulates basic gesture data including tag, type, and system gesture status. Additionally, it defines the `GestureTypes` enumeration, listing specific interactions such as tap, long press, pan, pinch, swipe, rotation, drag, and click. The document also details the `GestureJudgeResult` enum, used to control custom gesture recognition logic with options to continue or reject. Key information includes read-only properties for gesture attributes and system capabilities starting from version 19. This reference is intended for developers implementing or customizing gesture recognition in user interfaces.

### class_PinchGestureEvent_4more.md class_PinchGestureEvent_4more.md
This document provides API reference documentation for specific gesture event classes within the ArkUI framework using the Cangjie language. It details four classes: PinchGestureEvent, RotationGestureEvent, SwipeGestureEvent, and TapGestureEvent, all inheriting from BaseGestureEvent. Key information includes read-only properties such as scale, pinch center coordinates, rotation angles, and swipe speeds, which serve as parameters for gesture judgment callbacks. Intended for developers implementing touch interactions, this reference requires knowledge of the ArkUI system and gesture handling mechanisms.
