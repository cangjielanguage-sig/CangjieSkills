## Detailed Description

### Flex布局_6more.md Flex布局_6more.md
This document serves as an API reference for Flex layout properties within the ArkUI framework using the Cangjie language. It details the `alignSelf`, `flexBasis`, and `flexGrow` functions, including their parameters, return values, and system capabilities. Key information includes that these properties apply only to children of Flex, Column, Row, or GridRow containers. `alignSelf` overrides parent alignment settings, `flexBasis` defines the base size (defaulting to 'auto'), and `flexGrow` determines the proportion of remaining space allocated to a component. The target audience is ArkUI developers needing to fine-tune component layout behavior.

### func_flexShrinkFloat64_2more.md func_flexShrinkFloat64_2more.md
This API reference document details the flexShrink function used in the ArkUI framework to control the shrink ratio of child components within parent containers like Column, Row, or Flex. It documents two function overloads accepting ?Float64 and ?Int64 parameters, covering their functionality, system capabilities, parameters, and return values. Key information includes that the function sets the proportion of size reduction allocated to a component. Crucially, for Column and Row containers, the main axis size must be set for flexShrink to take effect, with default values of 0.0 or 0, whereas Flex containers default to 1.0 or 1. This guide targets ArkUI developers needing to implement responsive layout behaviors in Cangjie.
