# cj-image-overview

本目录提供了OpenHarmony系统中Image Kit（图片开发套件）的概览文档，旨在为应用开发者提供全面的图片开发指导。内容涵盖了图片解码、PixelMap位图操作、图片处理及编码的核心机制，详细介绍了从获取图片到生成新图片的完整开发步骤。文档重点阐述了读写权限、多格式支持及高效算法等特性，并说明了ImageSource和ImagePacker等关键类的使用背景及其与Image组件的支撑关系。该文档作为概念性指南，特别适用于需要进行图片显示、编辑或优化的开发者，帮助其快速建立对图片处理流程的整体认知。
