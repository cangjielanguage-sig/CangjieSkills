## 详细说明

### 应用代码开启Web调试开关_2more_26842c97.md 应用代码开启Web调试开关_2more_26842c97.md
本文档旨在指导开发者如何在HarmonyOS应用中开启Web调试功能，以便使用DevTools进行网页调试。文档主要涵盖三个关键步骤：在Cangjie代码中通过WebviewController.setWebDebuggingAccess开启调试开关、在module.json5配置文件中声明INTERNET权限、以及通过hdc命令连接设备并启用USB调试。核心要点包括代码配置、权限声明及设备连接验证。这是一份面向使用Cangjie语言开发者的操作指南，帮助其完成调试环境的前置准备。

### 端口转发_4more_13673f72.md 端口转发_4more_13673f72.md
这份文档是一份技术教程，旨在指导开发者如何通过端口转发在Chrome浏览器中调试ArkWeb内核的网页。文档详细介绍了使用hdc命令查询设备上的domain socket，将其转发至电脑TCP 9222端口，以及配置Chrome的调试工具页面以发现目标设备。关键信息指出socket名称包含应用进程号，需根据实际情况动态获取并转发。本文档面向需要调试HarmonyOS应用Web组件的开发者，前提是应用已开启Web调试开关并加载了网页。
