This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It covers a wide range of text input and search component attributes, including custom keyboards, text styling, input validation, and menu behaviors. Key topics include font customization, layout adjustments like spacing and alignment, and specific search component configurations such as button styles and caret settings. This documentation is suitable for UI developers and software engineers building HarmonyOS applications who need to fine-tune the visual appearance and functional behavior of input fields and search interfaces.
