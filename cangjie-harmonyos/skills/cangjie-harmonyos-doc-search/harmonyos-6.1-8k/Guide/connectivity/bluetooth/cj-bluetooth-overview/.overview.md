# cj-bluetooth-overview

本目录专注于提供蓝牙服务开发的全面技术概述，旨在帮助开发者深入理解蓝牙技术的核心机制。内容涵盖了蓝牙的基础物理原理，包括基于2.4GHz无线电波的通信方式及跳频扩频技术。文档重点对比了蓝牙技术的两大主要分支：传统蓝牙（BR/EDR）与低功耗蓝牙（BLE）。详细阐述了传统蓝牙在高速率数据传输和音频流媒体方面的成熟协议优势，以及低功耗蓝牙在极低功耗运行、穿戴设备连接和物联网（IoT）场景下的广泛应用。核心关键词涵盖蓝牙开发、BR/EDR、BLE、音频传输、物联网及穿戴设备。该资源特别适合嵌入式开发人员或移动应用开发者，用于在项目初期进行技术选型及建立扎实的蓝牙理论基础。

## 详细说明

### cj-bluetooth-overview.md cj-bluetooth-overview.md

本文档旨在提供蓝牙服务开发的概述，介绍蓝牙技术的基本原理及其两种主要分类。主要内容包括蓝牙技术的基础概述、传统蓝牙（BR/EDR）的特性与协议，以及低功耗蓝牙（BLE）的技术特点与应用场景。文档指出蓝牙基于2.4GHz无线电波和跳频技术。传统蓝牙速率高、协议成熟，适用于音频传输；低功耗蓝牙则以低功耗见长，适用于穿戴设备和物联网。这是一份面向开发者的技术指南，适用于需要了解蓝牙基础概念及区分不同蓝牙技术类型的开发场景。
