This directory contains API reference documentation for the `ohos.zlib` module within the Cangjie programming language, designed for the HarmonyOS ecosystem. It covers comprehensive functionalities for data compression, decompression, and integrity verification using the Zlib subsystem. Key components include classes for managing compression streams (ZStream), GZip operations, and Zip file handling, alongside enumerations for configuring compression levels, strategies, and flush modes. The documentation also details utility functions for file archiving and checksum calculations. It is intended for Cangjie developers implementing file management and data compression features in applications using the BasicServicesKit.
