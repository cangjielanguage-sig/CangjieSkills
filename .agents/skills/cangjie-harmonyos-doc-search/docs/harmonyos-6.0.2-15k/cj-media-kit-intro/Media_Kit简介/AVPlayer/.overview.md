# AVPlayer

The AVPlayer directory serves as a comprehensive technical resource for developers implementing media playback solutions using the Cangjie interface. It encompasses the system architecture, data flow, and compatibility specifications for a component responsible for audio and video transcoding and playback. The documentation details the complex interactions between the application layer, Player Framework, Audio/Graphic Frameworks, and Hardware Driver Interfaces (HDI). Furthermore, it provides a definitive list of supported media formats, protocols, and codecs, including mandatory H264/H265 support within MP4, MKV, and TS containers. This guide is essential for application developers seeking to ensure compatibility and robust performance for both local file playback and network streaming scenarios, offering the necessary constraints and guidelines to avoid common playback issues. By following these specifications, developers can effectively integrate media capabilities into their applications.

## Detailed Description

### AVPlayer_3more.md
This document outlines the architecture and data flow of the AVPlayer component, which handles media transcoding and playback for audio and video resources. It details two primary workflows: audio playback and video playback. Key sections explain the interaction between the application layer, Player Framework, Audio Framework, Graphic Framework, and Hardware Driver Interfaces (HDI). The document highlights that AVPlayer abstracts parsing and decoding, requiring only a media source and, for video, a SurfaceID from the XComponent. This technical guide is intended for developers using the Cangjie interface to implement integrated media playback capabilities.

### 支持的格式与协议.md
This reference document outlines the supported media formats, protocols, and technical specifications for a video playback system. It details supported protocols for local and network streaming, audio containers like AAC and MP3, and video formats including mandatory H264/H265 codecs within MP4, MKV, and TS containers. Key information includes the requirement for file descriptors in local playback, support for mainstream resolutions, and specific rules for subtitle handling in DASH protocols. The document targets application developers, advising them to use standard streams to ensure compatibility and avoid playback issues.
