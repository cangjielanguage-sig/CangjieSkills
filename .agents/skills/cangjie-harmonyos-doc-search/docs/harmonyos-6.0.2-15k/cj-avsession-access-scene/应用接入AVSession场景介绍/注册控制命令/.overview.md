# 注册控制命令

This directory provides technical guides for implementing media control commands using the AVSessionKit framework in HarmonyOS. It covers essential playback functionalities such as registering system commands, handling loop modes, managing fast forward and rewind operations, and implementing progress seeking. The documents include Cangjie code examples to demonstrate how to synchronize application states with the system control center and handle user interactions effectively. This resource is intended for developers building multimedia applications who need to integrate standard media controls and ensure seamless state management.

## Detailed Description

### 循环模式.md 循环模式.md
This document guides developers on implementing loop mode controls for music applications using the AVSessionKit framework. It covers the four fixed system modes—Random, Sequential, Single, and List—and explains the protocol for receiving mode switch commands and reporting the updated state back to the system. The content includes a Cangjie code example demonstrating how to set the initial AVPlaybackState and register a callback for SetLoopMode events. Key takeaways include the necessity of mapping custom app modes to the four fixed system modes and ensuring state synchronization. This technical guide targets developers integrating system-level playback controls into their multimedia applications.

### 快进快退_2more.md 快进快退_2more.md
This technical guide demonstrates how to implement media control features, specifically fast forward, rewind, and favorite toggling, using the AVSessionKit in the Cangjie programming language. The document covers two main sections: configuring skip intervals and handling playback direction changes, and managing the favorite state for media assets. Key information includes setting AVMetadata for skip durations, registering specific callbacks like FastForwardCallback and ToggleFavoriteCallback, and updating the session state via setAVPlaybackState. Intended for HarmonyOS developers, this tutorial provides practical code examples for enhancing media applications with interactive user controls.

### 注册控制命令_2more.md 注册控制命令_2more.md
This document guides developers on registering control commands within the AVSession framework to enable playback and call operations via the system control center. It details supported media commands like play, pause, and seek, as well as call commands such as answer and hangUp. Additionally, it explains how to handle unsupported commands by using the off interface to unregister them, which grays out the corresponding UI controls. Key takeaways include the prerequisite to register commands before activating the session. Intended for application developers using AVSessionKit, this reference includes Cangjie code examples for implementation.

### 进度控制.md 进度控制.md
This technical tutorial demonstrates how to implement progress control and seek functionality within an AV session using the Cangjie language. The document covers creating a seek callback, handling user interactions from the playback control center, and managing playback states. Key takeaways include setting the state to buffering before seeking to handle latency and synchronizing the new playback position and timestamp with the system after the seek operation completes. This guide targets application developers working on media playback features who are familiar with the AVSessionKit and Cangjie syntax. Keywords: AVSession, seek control, playback state, Cangjie, HarmonyOS.
