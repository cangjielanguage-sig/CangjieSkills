# 开发步骤

This directory provides a comprehensive guide for developing audio and video applications using the AVSessionKit in the Cangjie programming language on HarmonyOS. It covers the complete lifecycle of media session integration, from creating and activating sessions to configuring metadata, handling playback commands, and managing controller interactions. Key topics include setting AVMetadata, AVPlaybackState, implementing callbacks, and resource cleanup. This documentation is intended for application developers who need to implement robust media control features and manage session states effectively within their HarmonyOS applications.

### 开发步骤_1.md 开发步骤_1.md
This document serves as a development guide for integrating audio and video applications as media session providers using the AVSessionKit in the Cangjie programming language. It outlines the fundamental steps required to establish a media session, specifically focusing on creating and activating a session via the createAVSession method and dynamically setting media information like AVMetadata and AVPlaybackState. The text explains how these updates allow media controllers to retrieve and display current media status. Intended for HarmonyOS application developers, this tutorial assumes familiarity with Cangjie syntax and application context handling. Keywords: AVSession, Cangjie, AVMetadata, AVPlaybackState, Media Session Integration.

This document is intended for media application developers managing audio/video sessions and controls.

### 开发步骤_4.md 开发步骤_4.md
This document provides code examples for implementing and registering media control callbacks within an AVSession. It details the definition of callback classes for actions like Stop, PlayNext, Seek, and SetSpeed, and demonstrates registering these to handle events such as Play, Pause, and Rewind. Key information includes the necessity of executing playback logic within the callbacks and synchronizing state changes using SetAVPlayState or SetAVMetadata. It also notes that unsupported commands should be unregistered. This technical guide is intended for application developers integrating audio/video session management who possess prerequisite knowledge of the specific programming language syntax. Keywords: AVSession, Media Control, Callback Registration, Event Handling, Playback State, Audio/Video Development.

### 开发步骤_6.md 开发步骤_6.md
This tutorial provides Cangjie code examples for controlling AV sessions and managing their lifecycle, specifically focusing on controller interactions and resource cleanup. Main topics include obtaining a session controller, sending playback commands, monitoring state changes with specific filters, and performing cleanup operations. Key takeaways demonstrate how to use getController to send commands, listen to playback state changes like speed and position, and properly release resources by unregistering listeners and calling session.destroy upon application exit. Intended for developers building audio/video applications using the Cangjie language, this guide assumes prior knowledge of session creation and aims to ensure proper resource management in media apps.
