# log_package_types

本目录 `log_package_types` 专门用于定义日志包中的核心类型别名，旨在确立日志数据的标准化结构规范。文档详细阐述了日志属性的类型定义，特别是 `Attr` 类型的具体实现，将其定义为 `(String, LogValue)` 的键值对形式，以便于在日志消息中携带结构化信息。这种类型定义对于保证日志数据的一致性和可解析性至关重要。作为API参考文档的重要组成部分，本目录内容主要面向使用该日志库的开发人员，旨在帮助其深入理解底层类型系统，从而正确地构造、传递和管理日志属性。阅读者需具备基础的仓颉（Cangjie）语言类型系统知识，以便有效利用这些类型定义进行开发，确保日志系统的稳定运行。
