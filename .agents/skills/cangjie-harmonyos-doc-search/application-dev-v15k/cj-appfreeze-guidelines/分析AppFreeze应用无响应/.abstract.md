This directory provides a comprehensive technical resource for analyzing Application Not Responding (AppFreeze) issues within the HarmonyOS/OpenHarmony ecosystem. It covers the mechanisms of AppFreeze detection, system logging workflows, and specific fault types like main thread stalls and lifecycle timeouts. The content includes guides on log acquisition, stack trace analysis, and debugging methodologies for the Stage model. It is suitable for developers, QA engineers, and system performance analysts focused on troubleshooting application stability, performance bottlenecks, and unresponsive behavior.
