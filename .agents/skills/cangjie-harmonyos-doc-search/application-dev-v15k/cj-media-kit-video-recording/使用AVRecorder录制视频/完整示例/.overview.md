# 完整示例

This directory provides a comprehensive collection of Cangjie code examples focused on the complete lifecycle of video recording using the AVRecorder API. Furthermore, it addresses resource management and saving media assets to the system gallery. These examples are specifically designed for application developers using the Cangjie language who require practical guidance on implementing robust video capture features, ensuring proper error handling and resource release in their applications.
