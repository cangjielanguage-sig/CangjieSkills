# logger_package_overview

本目录提供了 `stdx.logger` 包的详细 API 概览文档，专注于为开发者提供灵活的日志记录解决方案。该文档全面涵盖了文本和 JSON 两种主要日志格式的打印功能，并深入剖析了基于 `Logger` 接口的三种核心实现类：`JsonLogger`、`SimpleLogger` 和 `TextLogger`。通过阅读这些内容，开发者可以清晰地理解每种 Logger 的具体用途，例如 JSON 格式输出、传统文本记录或键值对（KV）格式日志。这份文档是开发人员在构建应用程序时进行日志组件选型和集成的重要参考资料，旨在帮助用户根据业务需求快速定位并选择最合适的日志工具。
