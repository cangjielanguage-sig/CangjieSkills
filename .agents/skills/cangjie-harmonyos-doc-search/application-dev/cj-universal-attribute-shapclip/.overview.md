### cj-universal-attribute-shapclip.md

This API reference document details universal attributes for clipping and masking components within the ArkUI framework using the Cangjie language. The documentation covers three primary functions: `clip` for boundary clipping based on parent edges, `clipShape` for clipping according to specific geometric shapes, and `maskShape` for applying shape-based masks. Key information includes function signatures, parameter types like `BaseShape`, and return values that facilitate method chaining. Intended for developers working with ArkUI, this guide provides the necessary syntax to manipulate component geometry and visual rendering effectively.

**Detailed Breakdown:**
*   **Clipping Functions:** The document distinguishes between simple boundary clipping (`clip`) and more complex geometric clipping (`clipShape`), offering developers flexibility in how they constrain content.
*   **Masking Capabilities:** It explains the usage of `maskShape` to overlay shapes, allowing for creative visual effects.
*   **Technical Implementation:** By providing specific function signatures and details on the `BaseShape` parameter, the guide ensures developers can correctly implement these features using method chaining for cleaner code.
