# cj-declare-permissions-in-acl

本目录专门针对HarmonyOS应用开发过程中的高级权限管理问题，特别是当应用需要申请超出其默认APL（Ability Privilege Level）等级的受限权限时。文档详细阐述了利用ACL（Access Control List）机制在调试阶段临时获取高等级权限的完整流程与最佳实践。核心内容涵盖了两种主要的实现路径：一是利用DevEco Studio集成开发环境进行图形化配置，二是通过手动编辑`HarmonyAppProvision`配置文件中的`allowed-acls`及`app-services-capabilities`字段。该指南重点解决了如全局悬浮窗显示、屏幕截取等敏感系统功能在开发阶段的权限验证难题。必须特别注意的是，此方案仅限于开发与测试环境使用，严禁用于正式的商用发布。本文档非常适合正在开发涉及系统级敏感功能、需要跨级别申请权限的HarmonyOS应用开发者阅读与参考。

## Detailed Description

### cj-declare-permissions-in-acl.md
本文档旨在指导开发者在HarmonyOS应用调试阶段，通过ACL方式申请高于应用APL等级的受限权限。文档主要介绍了两种实现方式：通过DevEco Studio进行配置，或直接修改HarmonyAppProvision配置文件中的allowed-acls及app-services-capabilities字段。关键信息指出，此方法用于解决如全局悬浮窗或截屏等高等级权限的申请问题，但仅限开发调试使用，不可用于商用发布。目标受众为需要跨级别申请权限的HarmonyOS应用开发者。
