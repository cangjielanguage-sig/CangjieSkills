This directory serves as a comprehensive repository for API reference documentation related to the `ohos.multimedia_media` module, specifically tailored for the Cangjie programming language within the HarmonyOS development environment. It is dedicated to facilitating multimedia application development by offering extensive resources on core functionalities. These include audio and video playback, media recording, transcoding processes, screen capture capabilities, and metadata extraction. The documentation details essential classes such as AVPlayer, AVRecorder, and AVImageGenerator, as well as various enums for configuration and state management. This collection is primarily suitable for software developers and multimedia engineers aiming to build robust, feature-rich media applications using Cangjie.
