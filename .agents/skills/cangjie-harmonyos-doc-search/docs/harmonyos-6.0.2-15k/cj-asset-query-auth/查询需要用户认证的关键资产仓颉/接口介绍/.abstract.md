This directory provides comprehensive technical documentation for the AssetStoreKit framework, focusing on synchronous interfaces for querying and managing key assets. It covers API functions like preQuery, query, and postQuery, alongside detailed attribute parameters, data types, and security constraints. Key topics include access control settings, lifecycle options, data storage labels, and encryption configurations. Developers will find specific references for authentication tokens, custom data labels, and API versioning updates (e.g., API 12). This documentation is suitable for application developers and system integrators implementing secure asset storage solutions who need to understand API usage, data integrity, and parameter structures.
