# Stepper

This directory provides comprehensive documentation for the ArkUI Stepper component, a navigation tool essential for displaying progress across multiple task steps in HarmonyOS applications. It covers the component's API reference, practical implementation examples using the Cangjie language, and detailed event handling mechanisms. Key topics include module imports, constructor parameters, state management for step indices, and lifecycle callbacks such as onChange and onFinish. This resource is suitable for HarmonyOS developers and system architects looking to build robust multi-step workflows and step-by-step navigation interfaces using the ArkUI framework and Cangjie language.

### Detailed Description

#### Stepper_5more.md Stepper_5more.md
This document serves as API reference documentation for the ArkUI Stepper component, a navigation tool used to display progress across multiple task steps. It details the necessary module import, specifies that only StepperItem components are allowed as children, and describes the constructor function init. Key parameters include the optional index for the current step and the child builder. The document notes full support for common attributes and events, targeting developers building multi-step workflows in the ArkUI framework using the Cangjie language.

#### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating the implementation and usage of the Stepper component within the ArkUI framework using the Cangjie language. The content covers the definition of an EntryView class, state management for step indices and item statuses, and the configuration of StepperItem elements with custom labels and event handlers. Key takeaways include how to dynamically toggle item states such as Normal, Disabled, Waiting, and Skip via user interaction, as well as how to handle lifecycle events like onFinish, onSkip, and onChange. This tutorial is intended for HarmonyOS developers familiar with Cangjie and ArkUI who need to implement step-by-step navigation interfaces.

#### 组件事件.md 组件事件.md
This document serves as an API reference for event handling functions within a Stepper component, written in the Cangjie language. It details five specific event functions: onChange, onFinish, onNext, onPrevious, and onSkip. Key information includes the specific conditions triggering each callback, such as clicking navigation labels or reaching the final step, with many functions providing index parameters (UInt32) to track step transitions. All functions require SystemCapability.ArkUI.ArkUI.Full starting from version 22. This guide targets developers implementing step-based navigation logic in HarmonyOS applications, providing the necessary syntax and parameter definitions to manage user interactions effectively.
