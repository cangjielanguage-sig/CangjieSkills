# 示例代码

This directory serves as a comprehensive educational resource for Cangjie UI development within the HarmonyOS ecosystem, providing a series of code tutorials that address fundamental layout and positioning challenges. It focuses on teaching developers how to configure content alignment, manage main axis layout directions, and implement precise component positioning using various attributes. Key topics covered include the utilization of Stack and Row containers, alignment properties such as BottomEnd and TopStart, directional flow control with Ltr and Rtl, and advanced positioning techniques like absolute positioning, anchor-based adjustments, and relative offsets. These examples are specifically designed for Cangjie developers and HarmonyOS UI Kit users who are looking to master layout positioning and directional flow control to create polished and responsive user interfaces.

## Detailed Description

### 示例1对齐方式和主轴方向上的布局.md

This document serves as a code tutorial demonstrating how to configure content alignment and main axis layout direction in Cangjie UI development. It covers two primary layout concepts: using the align property within Stack containers to position content relative to the container, and using the direction property within Row containers to control the arrangement of child elements along the main axis. Key takeaways include practical implementations of Alignment.BottomEnd, Alignment.TopStart, Direction.Ltr, and Direction.Rtl. This example is intended for developers using the Cangjie language and HarmonyOS UI Kit who need to understand basic layout positioning and directional flow control.

### 示例2位置偏移.md

This document serves as a code tutorial demonstrating three distinct UI component positioning techniques within the Cangjie UIKit framework. It covers absolute positioning relative to the parent component using the position attribute, anchor-based adjustments using markAnchor, and relative layout shifts using offset. Key information includes the specific coordinate logic for each method, such as how positive and negative values determine direction differently for markAnchor compared to offset. The content is designed for Cangjie developers looking to implement precise layout control and understand the nuances of component placement in HarmonyOS applications.
