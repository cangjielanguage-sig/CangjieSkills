This directory contains comprehensive technical reference documentation for error codes within the HarmonyOS Meta-Ability subsystem. It covers a wide range of runtime exceptions, including Ability lifecycle management, application context issues, installation-free (atomic service) constraints, bundle management, and image editing failures. Each document provides detailed error messages, root cause analysis, and actionable troubleshooting steps. This resource is essential for application developers and system integrators looking to diagnose and resolve system-level errors, handle API version restrictions, and manage application updates effectively.
