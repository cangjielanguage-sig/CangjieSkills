This directory provides a detailed tutorial for getting started with the mock framework integrated into the Cangjie standard library's unit testing module. It is designed to assist developers in writing robust unit tests by enabling the testing of code in isolation through the substitution of complex or external dependencies. The guide covers all necessary setup requirements, including the specific imports required and the use of tooling commands like `cjpm`. It features a practical example that demonstrates the complete mock workflow, from creation to execution. Key educational takeaways include the methodology for creating mock objects, configuring behaviors such as custom return values and exception handling using the `@On` macro, and effectively substituting dependencies. This content is highly suitable for Cangjie developers who are seeking to implement comprehensive testing strategies for classes that rely on intricate dependency structures.
