## 播放实例音效管理

播放实例音效管理主要包括查询和设置当前音频播放流的音效模式，[音效模式](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#enum-audioeffectmode)包括EFFECT_NONE关闭音效模式和EFFECT_DEFAULT默认音效模式。默认音效模式会根据创建音频流的[StreamUsage](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#enum-streamusage)自动加载对应场景的音效。

### 获取播放实例

管理播放实例音效的接口是[getAudioEffectMode()](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#func-getaudioeffectmode)查询当前音频播放流的音效模式和[setAudioEffectMode(mode: AudioEffectMode)](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#func-setaudioeffectmodeaudioeffectmode)设置当前音频播放流的音效模式。在使用之前，需要使用[createAudioRenderer(options: AudioRendererOptions)](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#func-createaudiorendereraudiorendereroptions)先创建音频播放流AudioRenderer实例。

1. 导入音频接口。

    ```cangjie
    import kit.AudioKit.*
    ```

2. 配置音频渲染参数并创建AudioRenderer实例，音频渲染参数的详细信息请参见[AudioRendererOptions](../../../API_Reference/source_zh_cn/apis/AudioKit/cj-apis-multimedia-audio.md#class-audiorendereroptions)，创建AudioRenderer实例时会默认挂载EFFECT_DEFAULT模式音效。

    ```cangjie
    import ohos.base.BusinessException

    let audioStreamInfo = AudioStreamInfo(
        AudioChannel.CHANNEL_2, // 通道。
        AudioEncodingType.ENCODING_TYPE_RAW, // 编码格式。
        AudioSampleFormat.SAMPLE_FORMAT_S16LE, // 采样格式。
        AudioSamplingRate.SAMPLE_RATE_48000 // 采样率。
    )
    let audioRendererInfo = AudioRendererInfo(
        StreamUsage.STREAM_USAGE_MUSIC, // 音频流使用类型：音乐。根据业务场景配置，参考StreamUsage。
        0 // 音频渲染器标志。
    )
    let audioRendererOptions = AudioRendererOptions(audioRendererInfo, audioStreamInfo)
    let audioRenderer: audio.AudioRenderer | undefined = undefined;

    try {
        audioRenderer = createAudioRenderer(audioRendererOptions)
        AppLog.info("Invoke createAudioRenderer succeeded.")
    } catch (e: BusinessException) {
        AppLog.error("Invoke createAudioRenderer failed, code is ${e.code}, message is ${e.message}")
    }
    ```

### 查询当前播放实例的音效模式

```cangjie
import kit.AudioKit.*
import ohos.base.BusinessException

try {
    let effectMode = audioRenderer.getAudioEffectMode()
    AppLog.info("getAudioEffectMode: ${effectMode}")
} catch (e: BusinessException) {
    AppLog.error("Failed to getAudioEffectMode, code is ${e.code}, message is ${e.message}")
}
```

### 设置当前播放实例的音效模式

关闭系统音效：

```cangjie
import kit.AudioKit.*
import ohos.base.BusinessException

try {
    audioRenderer.setAudioEffectMode(AudioEffectMode.EFFECT_NONE)
    AppLog.info("Callback invoked to indicate a successful audio effect mode setting.")
} catch (e: BusinessException) {
    AppLog.error("Failed to setAudioEffectMode, code is ${e.code}, message is ${e.message}")
}
```

开启系统音效默认模式：

```cangjie
import kit.AudioKit.*
import ohos.base.BusinessException

try {
    audioRenderer.setAudioEffectMode(AudioEffectMode.EFFECT_DEFAULT)
    AppLog.info("Callback invoked to indicate a successful audio effect mode setting.")
} catch (e: BusinessException) {
    AppLog.error("Failed to setAudioEffectMode, code is ${e.code}, message is ${e.message}")
}
```
