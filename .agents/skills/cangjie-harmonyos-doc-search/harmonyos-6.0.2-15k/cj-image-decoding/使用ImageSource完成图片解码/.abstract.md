This directory provides a comprehensive technical guide on utilizing the ImageSource class to decode a wide variety of image formats into unified PixelMaps for application display or processing. It thoroughly covers the fundamental concepts of image decoding, enumerates supported file formats (including JPEG, PNG, GIF, WebP, BMP, SVG, ICO, DNG, and HEIF), and details practical implementation steps using the Cangjie language and ImageKit framework. The content includes specific tutorials on decoding images from resource files, managing memory effectively, and handling complex decoding options such as HDR. It is specifically suitable for developers working on image processing features who need a deep understanding of format compatibility and efficient decoding workflows within their software projects.
