This directory provides a comprehensive guide on controlling the alignment of child elements along the main axis within layout containers. It focuses on the `justifyContent` property, detailing how to position elements at the start, end, or center, as well as how to distribute space evenly between them. The content covers both theoretical concepts and practical implementations across different container types like Column and Row. It is suitable for UI developers and designers working with layout systems, specifically those using the Cangjie UI framework or HarmonyOS ArkUI, who need to master axis-based alignment to build structured and responsive user interfaces.
