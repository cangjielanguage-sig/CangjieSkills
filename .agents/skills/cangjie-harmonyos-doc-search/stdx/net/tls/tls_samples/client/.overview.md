## Detailed Description

### client.md

本文档是一份详尽的代码教程，旨在指导开发者如何使用仓颉编程语言构建一个功能完备的TLS客户端。文档内容覆盖了网络通信的关键环节，首先介绍了如何建立稳定的TCP连接，随后深入探讨了TLS安全层面的配置细节，包括但不限于信任模式的设定以及ALPN（应用层协议协商）协议的处理。

文档的核心重点在于会话状态的管理与恢复。通过详细解析 `TlsClientConfig` 和 `TlsSocket` 的使用方法，展示了如何在客户端与服务器之间建立安全通道。此外，文档特别强调了 `lastSession` 变量的作用，解释了如何利用它来保存和恢复会话状态，从而显著优化重连过程的效率。这份教程适合具备一定仓颉语法基础及网络编程概念的开发者阅读，能够帮助其快速掌握TLS客户端开发的关键技术点。
