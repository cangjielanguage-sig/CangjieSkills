This directory serves as a comprehensive introductory guide to the Cangjie programming language's basic syntax, specifically tailored for the ArkUI framework. It covers the fundamental structural elements required to build user interfaces, including Macros, UI Description, Custom Components, System Components, Attribute Methods, and Event Methods. Additionally, the content explores extended syntax features such as @Builder, with a strong emphasis on declarative UI structures, the critical role of state variables in triggering UI refreshes, and the implementation of chainable calls for configuration. This resource is highly suitable for developers who are new to Cangjie and require a solid foundational understanding of component composition and interaction logic to begin developing applications effectively.
