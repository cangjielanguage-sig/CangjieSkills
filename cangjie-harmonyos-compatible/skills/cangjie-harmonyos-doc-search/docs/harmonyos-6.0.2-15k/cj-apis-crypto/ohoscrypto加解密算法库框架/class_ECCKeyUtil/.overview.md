# class_ECCKeyUtil

This directory provides comprehensive API reference documentation for the `ECCKeyUtil` class within the Cangjie programming language, specifically designed for the Security.CryptoFramework. It focuses on Elliptic Curve Cryptography (ECC) operations, enabling developers to handle asymmetric public key parameters and perform point data conversions efficiently. The documentation covers essential functionalities such as generating common parameter specifications and transforming encoded byte arrays into Point objects, adhering to RFC5480 standards for both compressed and uncompressed formats. This resource is suitable for developers and security engineers looking to implement robust ECC key utilities, offering detailed syntax, parameter definitions, return values, and exception handling examples to facilitate secure application development.

## Detailed Description

### class_ECCKeyUtil_3more.md

This document serves as API reference documentation for the Cangjie programming language, specifically detailing the ECCKeyUtil class used for Elliptic Curve Cryptography operations. The primary focus is on generating asymmetric public key parameters and converting point data based on specific curve names. Key sections include the static methods convertPoint, which transforms encoded byte arrays into Point objects supporting compressed and uncompressed formats per RFC5480, and genECCCommonParamsSpec, which generates common parameter specifications. The documentation outlines input parameters, return values, and potential BusinessException errors. Intended for developers working with the Security.CryptoFramework, it provides the necessary syntax and examples to implement ECC key utilities effectively.

### static_func_getEncodedP_ca9fc213.md

This document serves as API reference documentation for the Cangjie static function getEncodedPoint, which converts elliptic curve Point objects into encoded byte arrays based on a specified curve name and format. The content covers the function signature, system capabilities, input parameters including curve name and compression format, return types, and specific error codes for exceptions. Key takeaways include support for both compressed and uncompressed point data formats and the requirement of a valid Point object. The document includes a practical code example demonstrating key generation and point encoding. Intended for developers using the CryptoArchitectureKit, this guide assumes familiarity with elliptic curve cryptography and the Cangjie programming language.
