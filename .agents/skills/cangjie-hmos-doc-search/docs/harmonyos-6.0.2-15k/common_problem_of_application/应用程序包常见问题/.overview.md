# 应用程序包常见问题

This directory functions as a specialized knowledge base for HarmonyOS developers, focusing on the intricacies of application package information and signature management. It addresses critical technical challenges, such as how to accurately retrieve the `appIdentifier` and fingerprint data, which are vital for application security and runtime logic. The content covers a range of methodologies, from utilizing the Cangjie programming language APIs to executing shell commands via the `bm` tool. Furthermore, it explains the nuances of signing modes—specifically comparing auto-signing versus manual signing via AppGallery Connect—and their implications for identifier stability. This resource is highly suitable for developers, security engineers, and QA professionals who require precise access to application metadata for debugging, verification, or ensuring consistency across multi-user development environments.

## Detailed Description

### 如何获取应用信息中appIdentifier.md 如何获取应用信息中appIdentifier.md
This technical guide outlines methods for retrieving the appIdentifier from application package information. It covers programmatic access using the Cangjie language and command-line retrieval via the bm tool. Key takeaways include using BundleManager.getBundleInfoForSelf with specific flags to access signatureInfo.appIdentifier within code, and using shell commands like bm dump to extract the identifier. The document targets HarmonyOS developers who need to access application signature details for runtime logic or debugging purposes.

### 如何获取签名信息中的指纹信息_2more.md 如何获取签名信息中的指纹信息_2more.md
This technical guide instructs HarmonyOS developers on retrieving application fingerprint information and understanding the appIdentifier. It details four retrieval methods: using the Cangjie API bundleManager.getBundleInfoForSelf, executing the bm dump shell command, extracting from .cer certificate files, and utilizing the keytool tool. Additionally, it defines appIdentifier, contrasting the random generation in auto-signing with the fixed, cloud-assigned value in manual signing via AppGallery Connect. Key takeaways include the recommendation for manual signing to ensure a consistent appIdentifier during cross-device debugging or multi-user development. This guide targets developers needing to verify signatures or manage stable application identifiers.
