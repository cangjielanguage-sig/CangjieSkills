# 场景示例

This directory serves as a comprehensive resource for developers working with the Cangjie language in HarmonyOS, specifically focusing on creating dynamic user experiences through page transition animations. It provides practical code examples illustrating how to implement navigation between views, such as EntryView and Page1, using the Router API. Key topics include configuring `PageTransitionEnter` and `PageTransitionExit` to achieve various visual effects like sliding, translation, and opacity adjustments. These examples are ideal for developers who want to enhance their application's interactivity and master custom routing logic within the Cangjie ecosystem. The content covers essential techniques for managing UI state and visual feedback during navigation events.

## Detailed Description

### 场景示例_1.md
This document provides a practical code example demonstrating how to implement page transition animations using the Cangjie language in a HarmonyOS application. It covers the implementation of two pages, EntryView and Page1, utilizing the Router.pushUrl and Router.back methods for navigation. The core focus is the pageTransition method, which configures PageTransitionEnter and PageTransitionExit with RouteType.Push and RouteType.Pop to create slide effects (left/right) with a 1000ms duration. This tutorial is intended for developers seeking to understand custom page routing animations and UI component interaction in the Cangjie development environment.

### 场景示例_2.md
This document provides a code example demonstrating page routing and transition animations in a HarmonyOS application using the Cangjie language. It covers the implementation of two pages, EntryView and Page1, utilizing the Router API for navigation and the pageTransition method for visual effects. Key information includes configuring PageTransitionEnter for sliding effects and PageTransitionExit for translation and opacity changes, alongside basic UI component layout. This tutorial targets HarmonyOS developers seeking to implement custom page transitions and navigation logic in Cangjie.
