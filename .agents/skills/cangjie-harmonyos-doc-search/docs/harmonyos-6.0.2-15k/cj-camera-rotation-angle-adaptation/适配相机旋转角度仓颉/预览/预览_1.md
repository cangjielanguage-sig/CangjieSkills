## 预览

完成[会话创建](#创建会话)后，开发者可根据实际需求，配置输出流。

1. 调用[PreviewOutput](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-previewoutput)类中的[getPreviewRotation](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-getpreviewrotationint32)接口，获取[预览旋转角度](./cj-camera-rotation-term.md#预览旋转角度)。

    displayRotation：[显示设备的屏幕旋转角度](./cj-camera-rotation-term.md#屏幕旋转角度)，可通过[display.getDefaultDisplaySync](../../../API_Reference/source_zh_cn/arkui-cj/cj-apis-display.md#func-getdefaultdisplaysync)获取[Display](../../../API_Reference/source_zh_cn/arkui-cj/cj-apis-display.md#class-display)对象并读取其rotation属性值，并将对应角度填入。

    例：Display.rotation = 1，表示显示设备屏幕顺时针旋转为90°，此处displayRotation填入90。

    ```cangjie
    import kit.ArkUI.*

    let initDisplayRotation = getDefaultDisplaySync().rotation
    let imageRotation = initDisplayRotation * 90
    ```

    该接口需要在session调用[commitConfig](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-commitconfig)完成配流后调用。

    ```cangjie
    func getPreviewRotation(previewOutput: PreviewOutput, imageRotation: Int32): ImageRotation {
        return previewOutput.getPreviewRotation(imageRotation)
    }
    ```

2. 调用[PreviewOutput](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-previewoutput)类中的[setPreviewRotation](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-setpreviewrotationimagerotation-bool)，设置图像的预览旋转角度。

    该接口需要在session调用[commitConfig](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-commitconfig)完成配流后调用。

    - previewRotation：预览旋转角度，取上一步[getPreviewRotation](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-getpreviewrotationint32)的返回值。
    - isDisplayLocked：可选入参，默认为false。当设置为false，即屏幕方向未锁定，[预览旋转角度](./cj-camera-rotation-term.md#预览旋转角度)将根据[相机镜头角度](./cj-camera-rotation-term.md#相机镜头安装角度)+[屏幕显示旋转角度](./cj-camera-rotation-term.md#屏幕旋转角度)的值计算；当设置为true，Surface旋转锁定，不跟随窗口变化，旋转角度仅取相机镜头角度计算。

    ```cangjie
    func setPreviewRotation(previewOutput: PreviewOutput, previewRotation: ImageRotation, isDisplayLocked: Bool): Unit {
        try {
            previewOutput.setPreviewRotation(previewRotation, isDisplayLocked: isDisplayLocked)
        } catch (error: BusinessException) {
            // 失败返回错误码error.code并处理
            AppLog.error("The previewOutput.setPreviewRotation call failed. error code: ${error.code}")
        }
    }
    ```

**预览流旋转接口完整示例：**

```cangjie
import kit.CameraKit.*
import kit.ArkUI.*
import ohos.base.*

class TestCallback <: Callback1Argument<Bool> {
    var cb: (Bool) -> Unit
    public init(cb: (Bool) -> Unit) {
        this.cb = cb
    }
    public open func invoke(value: Bool): Unit {
        cb(value)
    }
}
