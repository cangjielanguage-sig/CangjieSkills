# class_AsyKeyGenerator

This directory contains API reference documentation for the Cangjie `AsyKeyGenerator` class and its associated functions within the CryptoFramework. It covers the generation of random asymmetric keys, conversion of key data blobs, and parsing of PEM-formatted strings into KeyPair objects. Key topics include ECC256 and RSA algorithms, system capabilities, and error handling. This documentation is suitable for software developers and security engineers implementing cryptographic key management and asymmetric encryption operations in Cangjie applications using the CryptoArchitectureKit.

## Detailed Description

### class_AsyKeyGenerator_3more.md
This document serves as API reference documentation for the Cangjie AsyKeyGenerator class, which handles asymmetric key generation and conversion within the CryptoFramework. The content covers the class definition, the read-only algName property, and the convertKey function. Key information includes the requirement to instantiate the class via createAsyKeyGenerator() and the convertKey method's ability to accept optional public and private key data blobs to return a KeyPair object. The documentation also details system capabilities, version requirements, parameters, return values, and specific error codes like invalid parameters or memory errors. Targeted at developers using the CryptoArchitectureKit, it provides a code example demonstrating key conversion for the ECC256 algorithm.

### func_convertPemKeyString_String.md
This document serves as API reference material for the Cangjie function convertPemKey, designed to generate an asymmetric KeyPair from PEM-formatted string data. The documentation outlines the function signature, system capabilities, and version requirements. Key sections include parameter descriptions for optional public and private key strings, the KeyPair return value, and a comprehensive list of potential exceptions with specific error codes. A practical code example demonstrates importing RSA keys using the CryptoArchitectureKit. Developers using this function must ensure that at least one key material is provided, as both cannot be None. This resource targets software developers implementing cryptographic key management in Cangjie applications.

### func_generateKeyPair.md
This API reference document details the generateKeyPair function used to generate random asymmetric keys in the Cangjie programming language. The content covers the function signature, system capabilities, return values, potential exceptions with specific error codes, and a usage example. Key information includes that the function returns a KeyPair object and requires the SystemCapability.Security.CryptoFramework.Key.AsymKey capability. It handles errors such as invalid parameters, memory errors, and crypto operation failures. This guide targets software developers working with cryptographic operations in Cangjie, specifically those needing to implement RSA or other asymmetric encryption algorithms using the CryptoArchitectureKit.
