# 基础类型定义

This directory defines fundamental data types and configurations for the ArkUI framework in the Cangjie language. It covers essential structures for styling UI components, specifically focusing on gradients, image border repetition modes, and border image options. These definitions allow developers to customize visual aesthetics like linear gradients and complex border rendering. Suitable for Cangjie developers and UI designers working with ArkUI, this documentation provides the necessary building blocks for implementing advanced visual effects and layout styling starting from API version 19.

## Detailed Description

### class_LinearGradientOption.md class_LinearGradientOption.md
This document provides API reference documentation for the LinearGradientOption class in the Cangjie language, designed to configure linear gradient styles within the ArkUI framework. It details the class constructor and four read-only properties: angle, direction, colors, and repeating. Key information includes default values, data types, and specific behaviors, such as the direction property being overridden by angle and invalid colors being skipped. The document specifies system capabilities and version requirements. Intended for ArkUI developers, this reference aids in implementing visual gradients by defining start angles, directions, color stops, and repetition modes.

### enum_RepeatMode.md enum_RepeatMode.md
This document serves as API reference documentation for the RepeatMode enum in the Cangjie language, specifically defining how sliced images are repeated along borders. It details four enumeration values: SPACE, STRETCH, REPEAT, and ROUND. Key information includes the specific behavior of each mode, such as tiling with whitespace gaps, stretching to fill, repeating with clipping, or compressing images to fit integer tiling. Intended for UI developers using the ArkUI framework, this reference helps in customizing image border rendering effects.

### interface_BorderImageOptio_2more.md interface_BorderImageOptio_2more.md
This document serves as API reference documentation defining two specific sealed interfaces used within the ArkUI framework for Cangjie development. The main sections cover the definitions of BorderImageOptionSourceType and LengthEdgeWidthsType. Key information includes that BorderImageOptionSourceType is a union type accepting String, AppResource, or LinearGradientOption, while LengthEdgeWidthsType accepts LengthType or EdgeWidths. Both interfaces are available starting from API version 19 and support full ArkUI system capabilities. This reference is intended for Cangjie developers and UI designers who need to programmatically define border image sources and edge dimensions.

### class_BorderImageOption/
This directory contains comprehensive API reference documentation for the `BorderImageOption` class within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the configuration of image and gradient borders for UI components, detailing essential properties such as source, slice, width, outset, repeat, and fill. The documentation explains how to apply custom image borders to container components like Row and Column, supporting various dimension types and repetition modes. This resource is suitable for Cangjie developers and UI designers seeking to implement complex border styling and enhance visual aesthetics in their applications starting from API version 19.
