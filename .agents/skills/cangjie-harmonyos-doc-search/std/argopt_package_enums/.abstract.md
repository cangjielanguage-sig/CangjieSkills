This directory provides comprehensive API reference documentation for the enumerations included in the `argopt` package, a specialized library developed for command-line argument parsing within the Cangjie programming language. The documentation is centered around the core enumerations that dictate how command-line inputs are validated and structured. It thoroughly details the `ArgumentMode` enum, which defines the strict value requirements for arguments—categorizing them as `NoValue`, `RequiredValue`, or `OptionalValue`—and the `ArgumentSpec` enum, which specifies the structural syntax of arguments, including `Short`, `Long`, `Full`, and `NonOptions` types. Beyond basic definitions, the content covers the technical implementation of standard interfaces such as `ToString` and `Equatable` for the `ArgumentMode` enum. It also highlights the advanced capability of `ArgumentSpec` variants to hold lambda callback functions for dynamic value handling. This resource is specifically tailored for Cangjie developers and software engineers who are in the process of building or maintaining command-line interfaces and require a reliable guide for defining and parsing command options.
