# class_Router

This directory contains API reference documentation for the Cangjie Router class within the ArkUI framework. It focuses on managing page routing, navigation, and state management for HarmonyOS applications. Key topics include page stack manipulation, navigation methods like `pushUrl` and `replaceUrl`, parameter passing via JSON strings, and lifecycle management features such as back alerts. The documentation is intended for application developers using the Cangjie language to implement robust navigation logic and handle page transitions effectively in their ArkUI projects.

### static_func_pushUrlString__2more.md static_func_pushUrlString__2more.md
This API reference document details static router functions for page navigation in Cangjie applications. It covers the pushUrl function for navigating to specific pages and replaceUrl for replacing the current page, including their parameters, system capabilities, and version requirements. Key information includes that both functions accept a target URL, JSON string parameters, and an exception callback. Notably, parameters cannot pass methods or system objects; developers must construct JSON strings manually. pushUrl requires a RouterMode, whereas replaceUrl does not. This guide targets HarmonyOS ArkUI developers using Cangjie who need to implement application routing and data passing between pages.
