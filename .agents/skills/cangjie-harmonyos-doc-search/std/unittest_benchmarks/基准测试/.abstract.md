This directory contains comprehensive documentation for the Cangjie language's benchmarking framework. It covers the fundamentals of writing performance tests using the `@Bench` macro, strategies for obtaining reliable results, and the internal algorithms used for measurement precision. The content also explores advanced topics such as parametric benchmarking, custom measurement sources, and detailed reporting. Key concepts include statistical analysis, overhead elimination, data state management, and compiler optimization handling. This resource is suitable for Cangjie developers and performance engineers seeking to implement accurate performance testing, optimize code efficiency, and gain granular insights into system behavior.
