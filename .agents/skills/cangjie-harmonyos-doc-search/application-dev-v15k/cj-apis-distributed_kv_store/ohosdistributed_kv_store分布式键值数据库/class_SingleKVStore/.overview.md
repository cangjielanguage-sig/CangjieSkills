# class_SingleKVStore

This directory contains API reference documentation for the `SingleKVStore` class within the Cangjie ArkData framework. It covers the management of distributed key-value database instances, focusing on data persistence, synchronization, and transaction handling. Key functionalities include data manipulation (put, delete, get), backup and restoration, query operations, and event subscription for data changes. The documentation is intended for software developers working on distributed data management in HarmonyOS applications, providing detailed method signatures, error codes, and practical Cangjie code examples to implement robust database operations.
