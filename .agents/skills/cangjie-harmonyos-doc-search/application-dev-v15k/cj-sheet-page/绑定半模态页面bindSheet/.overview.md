# 绑定半模态页面bindSheet

This directory provides comprehensive technical guides for implementing and customizing semi-modal pages (bindSheet) within the ArkUI framework using the Cangjie language. It covers fundamental implementation, lifecycle management, and advanced interaction features such as nested scrolling and secondary confirmation dialogs. Key topics include the `bindSheet` attribute, dismissal behaviors, spring-back animations, and scroll priority coordination. These resources are designed for UI developers and HarmonyOS engineers seeking to build interactive, responsive overlay interfaces that require precise control over user flows and component transitions.

## Detailed Description

### 二次确认能力_2more.md
This technical guide explains how to implement secondary confirmation and customize dismissal behaviors for half-modal components using the Cangjie language. It covers implementing the onWillDismiss interface for confirmation dialogs, filtering dismissal reasons like slide-down, and managing spring-back animations via onWillSpringBackWhenDismiss. Key takeaways include intercepting close events with AlertDialog, conditionally executing dismissSheetAction.dismiss(), and controlling SpringBackAction.springBack() to enable or disable bounce effects. This guide targets UI developers building interactive interfaces who require granular control over modal lifecycle events and user interaction flows.

### 使用嵌套滚动交互.md
This guide explains how to configure nested scrolling interactions within semi-modal panels to coordinate content scrolling with panel resizing. It covers scroll priority rules based on content position (top, middle, bottom), default nested scroll modes, and implementation steps. Key takeaways include the specific logic where swiping at the top expands the panel while swiping in the middle scrolls content. Developers must apply the .nestedScroll method with PARENT_FIRST and SELF_FIRST options to vertical scroll containers like Lists. This tutorial targets HarmonyOS developers using the Cangjie language who need to integrate scrollable components inside sheets.

### 绑定半模态页面bindSheet_3more.md
This document guides developers on implementing semi-modal pages using the bindSheet attribute in the ArkUI framework. It defines the component as a non-fullscreen popup that retains parent view visibility, suitable for simple tasks like sharing or scheduling. The text covers configuration options for different device widths, usage constraints regarding dismissal callbacks, and the specific lifecycle callback sequence. Key information includes the ability to configure non-modal interactions and the lifecycle order: onWillAppear, onAppear, onWillDisappear, and onDisappear. Intended for UI developers, this reference helps optimize overlay interactions while advising on alternative transitions for complex workflows. Keywords: bindSheet, semi-modal, ArkUI, lifecycle, UI transitions, modal interaction.
