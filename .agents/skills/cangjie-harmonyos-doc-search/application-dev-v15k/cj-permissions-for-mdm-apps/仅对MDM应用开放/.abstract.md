This directory provides technical documentation for OpenHarmony system permissions that are exclusively available to Mobile Device Management (MDM) applications and specific enterprise security tools. It covers a wide range of capabilities, including file scanning, device administration, network configuration, and system settings management. Key concepts include `FILE_GUARD_MANAGER`, `ENTERPRISE` permissions, and granular hardware control. These resources are designed for system developers and enterprise architects building robust device management solutions or file security applications, specifically targeting API version 12 and utilizing system_grant authorization. Understanding these permissions is crucial for ensuring compliance and functionality in enterprise environments.
