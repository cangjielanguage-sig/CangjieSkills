This directory serves as a central repository for documentation regarding supplementary state management features within the Cangjie UI framework. It specifically focuses on introducing and explaining the @Watch macro, a powerful decorator designed to act as a listener for state variable changes. By covering this feature, the directory extends the understanding of capabilities beyond standard component and application state management. Key topics include the current Beta status of the @Watch macro and its primary utility for monitoring state updates in real-time. The content acts as a crucial navigation hub, directing developers to detailed documentation. This resource is intended for Cangjie UI developers who need advanced observation tools for state variables and are already comfortable with basic state management concepts. Core keywords include Cangjie UI, state management, @Watch, macro, state variables, and Beta.
