This directory serves as a comprehensive technical resource for developers focusing on certificate management within the HarmonyOS environment. It provides in-depth guidance on the implementation of application private credential management, utilizing tools such as the DeviceCertificateKit and the Cangjie language. The content covers essential security operations, including the installation, retrieval, and uninstallation of credentials, alongside complex cryptographic tasks like signing and verification. It details the integration with the Universal Keystore (HUKS) and supports algorithms such as RSA and ECC. Designed specifically for HarmonyOS application developers, this documentation assists in configuring necessary permissions, managing the credential lifecycle, and ensuring robust data security through SDK API version 12 or higher. It is an essential guide for building secure applications that require rigorous certificate handling and error management.
