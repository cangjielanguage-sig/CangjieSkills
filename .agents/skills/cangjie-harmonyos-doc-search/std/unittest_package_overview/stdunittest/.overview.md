# stdunittest

The `stdunittest` directory serves as the central documentation hub for the Cangjie unit testing framework, a critical tool for ensuring software reliability and performance. It provides a detailed overview of the framework's capabilities, guiding users through the process of writing, running, and debugging unit tests with support for both `cjc` and `cjpm` compilers. The content encompasses a wide range of testing needs, from basic assertions to complex parameterized testing using data strategies like DataProvider and Arbitrary. Additionally, it includes resources for performance benchmarking and configuration management. This documentation is primarily designed for Cangjie developers, QA engineers, and testers who aim to implement comprehensive automated testing solutions, streamline debugging processes, and maintain high code quality standards within their projects.
