This directory serves as a comprehensive technical resource for the `cj-apis-displaySync` module, specifically tailored for the HarmonyOS ArkUI framework. It focuses extensively on variable frame rate support, providing essential documentation and implementation guides for Cangjie developers. The content covers critical components such as the `DisplaySync` class and `IntervalInfo` data structures, offering deep insights into optimizing graphics performance. By enabling precise control over rendering cycles and frame synchronization in self-drawn UI scenarios, this documentation helps developers achieve superior visual fluidity and efficiency. It is primarily suitable for HarmonyOS developers and graphics engineers aiming to leverage the Cangjie language for advanced, high-performance, variable frame rate application development. The resources provided here are intended to bridge the gap between hardware capabilities and software rendering, ensuring that applications can dynamically adjust their frame rates to match display capabilities.
