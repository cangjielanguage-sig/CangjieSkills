This directory contains comprehensive documentation for the ArkUI RichEditor component, designed for HarmonyOS developers using the Cangjie language. It covers the implementation of mixed graphics and text interactive editing, including API references, component properties, event handling, and practical code examples. Key topics include text styling, image insertion, custom keyboards, and selection management. These resources are suitable for developers building complex user interfaces requiring advanced text manipulation and input method customization in version 22+ system environments.
