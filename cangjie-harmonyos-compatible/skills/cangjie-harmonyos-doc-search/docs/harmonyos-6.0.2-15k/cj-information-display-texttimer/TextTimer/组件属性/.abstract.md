This directory contains API reference documentation for component properties within the Cangjie ArkUI framework, specifically focusing on text styling and visual effects. It covers comprehensive functions for manipulating font attributes such as color, family, size, style, and weight, alongside utilities for applying text shadows. The documentation details default values, parameter types, and version requirements (notably API version 19). It is suitable for HarmonyOS developers and UI designers using the Cangjie language who need to configure and enhance the visual presentation of text components in their applications with precise control over typography and shadow effects. The files provide technical specifications for implementing these features effectively.
