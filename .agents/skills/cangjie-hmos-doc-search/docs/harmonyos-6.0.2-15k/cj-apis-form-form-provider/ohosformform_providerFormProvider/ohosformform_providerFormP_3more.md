# ohos.form.form_provider（FormProvider）

FormProvider模块提供了卡片提供方相关接口的能力，开发者在开发卡片时，可通过该模块提供接口实现更新卡片、设置卡片更新时间、获取卡片信息、请求发布卡片等。

## 导入模块

```cangjie
import kit.FormKit.*
```
