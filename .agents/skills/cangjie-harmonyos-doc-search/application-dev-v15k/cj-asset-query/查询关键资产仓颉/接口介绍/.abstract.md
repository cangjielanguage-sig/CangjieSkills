This directory provides a comprehensive technical reference for the AssetStoreKit API, focusing on the management and querying of key assets. It covers the `query` function interface, attribute tags, data structures, and configuration parameters for access control and synchronization. Key topics include security warnings regarding `DATA_LABEL` fields, data type constraints, and pagination logic for query results. Designed for developers implementing secure asset storage and synchronization, these documents offer essential specifications for parameter definitions, data handling, and API response customization to ensure compliance and efficient data management.
