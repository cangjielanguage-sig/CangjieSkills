## 开发步骤及注意事项

> **说明：**
>
> AVRecorder只负责视频数据的处理，需要与视频数据采集模块配合才能完成视频录制。视频数据采集模块需要通过Surface将视频数据传递给AVRecorder进行数据处理。当前常用的数据采集模块为相机模块，具体请参见[相机-录像](../camera/cj-camera-recording.md)。
> 文件的创建与存储，请参见[应用文件访问与管理](../../file-management/cj-app-file-access.md)，默认存储在应用的沙箱路径之下，如需存储至图库，请使用[安全控件保存媒体资源](../medialibrary/cj-photoAccessHelper-savebutton.md)对沙箱内文件进行存储。

AVRecorder详细的API说明请参见[AVRecorder API参考](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#class-avrecorder)。

1. 创建AVRecorder实例。

    ```cangjie
    var avRecorder: AVRecorder = createAVRecorder()
    ```

2. 设置业务需要的监听事件，监听状态变化及错误上报。

    | 事件类型 | 说明 |
    | -------- | -------- |
    | stateChange | 必要事件，监听播放器的state属性改变 |
    | error | 必要事件，监听播放器的错误信息 |

    ```cangjie
    import kit.MediaKit.*

    // 状态上报回调函数
    // 用户可以在此补充状态发生切换后想要进行的动作，回调函数的声明可以参考完整示例
    this.avRecorder.getOrThrow().on(AVRecorderCallbackType.AVRECORDER_STATE_CHANGE, StateChangeCallback())
    // 错误上报回调函数
    this.avRecorder.on(AVRecorderCallbackType.AVRECORDER_ERROR, ErrorCallBack())
    ```

3. 配置视频录制参数，调用prepare()接口，此时进入prepared状态。

    > **说明：**
    >
    > 配置参数需要注意：
    >
    > - 配置参数之前需要确保完成对应权限的申请，请参见[申请权限](#申请  权限)。
    > - prepare接口的入参avConfig中仅设置视频相关的配置参数，如示例代  码所示。
    >   如果添加了音频参数，系统将认为是“音频+视频录制”。
    > - 需要使用支持的[录制规格](./cj-media-kit-intro.md#支持的格  式)，视频比特率、分辨率、帧率以实际硬件设备支持的范围为准。
    > - 录制输出的url地址（即示例里avConfig中的url），形式为fd://xx (fd Int32)。需要调用基础文件操作接口（[Core File Kit的ohos.file.fs](../../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md)）实现应用文件访问能力，获取方式请参见[应用文件访问与管理](../../file-management/cj-app-file-access.md)。

    ```cangjie
    import kit.MediaKit.*
    import kit.CoreFileKit.*
    import ohos.base.*

    private var avProfile: AVRecorderProfile = AVRecorderProfile(
        ContainerFormatType.CFT_MPEG_4, // 视频文件封装格式，只支持MP4
        videoBitrate: 100000, // 视频比特率
        videoCodec: CodecMimeType.VIDEO_AVC, // 视频文件编码格式，支持avc格式
        videoFrameWidth: 640,  // 视频分辨率的宽
        videoFrameHeight: 480, // 视频分辨率的高
        videoFrameRate: 30 // 视频帧率
    )

    //通过MainAbility获取AbilityContext，参考完整示例
    var filePath: String = context.filesDirectory + "/example.mp4"
    var videoFile: File = FileFs.open(filePath, mode: READ_WRITE.mode | CREATE.mode)
    var fileFd = videoFile.fd // 获取文件fd

    var avConfig: AVRecorderConfig = AVRecorderConfig(
        avProfile,
        "fd://" + fileFd.toString(), // 参考应用文件访问与管理开发示例新建并读写一个视频文件
        videoSourceType: VideoSourceType.VIDEO_SOURCE_TYPE_SURFACE_YUV, // 视频源类型，支持YUV和ES两种格式
    )
    this.avRecorder.prepare(avConfig)
    ```

4. 获取视频录制需要的SurfaceID。

    调用getInputSurface()接口，接口的返回值SurfaceID用于传递给视频数据输入源模块。常用的输入源模块为相机，以下示例代码中，采用相机作为视频输入源为例，输入源模块通过SurfaceID可以获取到Surface，通过Surface可以将视频数据流传递给AVRecorder，由AVRecorder再进行视频数据的处理。

    ```cangjie
    avRecorder.getInputSurface()
    ```
