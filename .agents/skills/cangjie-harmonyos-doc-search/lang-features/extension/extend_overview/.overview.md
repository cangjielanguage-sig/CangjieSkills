### extend_overview.md extend_overview.md

本文档概述了仓颉编程语言中的扩展机制，旨在不破坏类型封装性的前提下为现有类型添加新功能。主要涵盖扩展的功能范围（如添加成员函数、操作符重载、属性及实现接口）、使用限制（如不能增加成员变量或访问私有成员），以及直接扩展与接口扩展的分类。关键点在于扩展不能增加成员变量、不能访问私有成员，且必须拥有具体实现。接口扩展允许现有类型实现新接口，增强了抽象灵活性。本文档适合具备仓颉基础语法的开发者阅读，作为语言特性参考指南使用。关键词：仓颉, 扩展, 封装性, 操作符重载, 接口实现
