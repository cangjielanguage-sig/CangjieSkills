This directory contains technical documentation for configuring and implementing RSA encryption and decryption using the PKCS1_OAEP padding mode. It covers parameter string syntax, supported algorithm combinations across various key sizes (RSA512 to RSA8192), and key type input flexibility. Key topics include digest algorithms, Mask Generation Function (MGF1) parameters, and input data size constraints. These resources are designed for developers, security engineers, and cryptographers who need to ensure accurate cryptographic configuration and compatibility within their systems.
