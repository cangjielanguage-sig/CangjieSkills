This directory contains API reference documentation for the AtManager class and related functions within the Cangjie language framework, focusing on access control and permission management. It covers essential operations such as verifying application permissions via access tokens, requesting user authorization through system dialogs, and managing global privacy switches like microphone access. The documentation details function signatures, parameters, return values, and error handling for security features. It is suitable for application developers implementing runtime permission requests, validating security capabilities, and managing user consent in HarmonyOS applications.
