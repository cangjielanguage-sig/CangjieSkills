# cj-arkts_auxiliary_lib

本目录提供了仓颉与ArkTS互操作辅助库的详细使用指南，专注于解决跨语言开发中的类型兼容性挑战。核心内容涵盖了辅助库中 `getJSContext` 接口的使用方法，该接口能够将仓颉端的 `UIAbilityContext` 对象转换为ArkTS可识别的 `JSValue` 类型。这一机制有效解决了在调用ArkTS原生模块（例如相机选择器等系统组件）时，因Context参数类型不匹配而导致的调用失败问题。文档还包含了在 `main_ability.cj` 中管理全局Context实例的实战代码示例。该资源特别适合正在使用仓颉语言开发OpenHarmony应用，并需要深度集成或调用现有ArkTS存量库的开发者阅读。

## 详细描述

### cj-arkts_auxiliary_lib.md
这份文档是关于仓颉-ArkTS互操作辅助库的使用指南，旨在帮助开发者更便捷地编写跨语言调用代码。文档主要介绍了辅助库提供的`getJSContext`接口，该接口用于将`UIAbilityContext`转换为`JSValue`，从而解决调用ArkTS模块（如相机选择器）时Context参数类型不匹配的问题。文档通过具体示例演示了在`main_ability.cj`中保存全局Context实例并进行转换的完整流程。目标受众为使用仓颉开发OpenHarmony应用并需调用ArkTS存量库的开发者。
