# 使用场景

This directory serves as a technical guide for usage scenarios regarding state management in the Cangjie programming language, primarily targeting HarmonyOS UI component development. It addresses the complex interactions between access modifiers (like `private` and `public`) and various state management macros (including `@State`, `@Link`, `@Prop`, and storage-related decorators). The content explains specific validation rules and restrictions to prevent compiler errors, emphasizing the importance of correct syntax for data binding and state synchronization. By providing clear examples of what works and what doesn't, this documentation helps Cangjie developers build robust applications by avoiding common pitfalls associated with access control in stateful components.

## Detailed Description

### 使用场景_1.md

This document outlines validation rules for combining access modifiers with state management macros in the Cangjie programming language. It details specific restrictions, such as the incompatibility of the private modifier with @State, @Prop, @Provide, and @BuilderParam, and the incompatibility of the public modifier with @StorageLink, @StorageProp, @LocalStorageLink, @LocalStorageProp, and @Consume. Through comparative code examples, the guide illustrates invalid syntax that triggers compiler errors versus correct implementations. This reference is essential for Cangjie developers building HarmonyOS UI components to ensure proper state management and avoid access modifier conflicts.

### 使用场景_2.md

This document illustrates the correct usage of the @Link decorator in Cangjie state management by comparing incorrect and correct code implementations. It features an Anti-example demonstrating a compilation error and a Positive example showing the valid syntax. The key takeaway is that variables decorated with @Link in a child component cannot use the private modifier, as they must be accessible for two-way data binding with the parent component. This guide targets Cangjie developers working on HarmonyOS applications who need to implement parent-child state synchronization. Keywords: Cangjie, @Link, state management, HarmonyOS, private modifier, two-way binding.
