This directory contains comprehensive documentation for the `LogLevel` struct, a fundamental component of the Cangjie programming language's logging package. It defines the hierarchy and properties of logging severity levels, ranging from OFF to ALL, including specific integer values and properties like name and value. The documentation covers the struct definition, initialization methods, string conversion, and comparison operator overloads. This resource is essential for developers who need to configure log output thresholds, filter logs based on severity, or implement logic involving log level comparisons in their Cangjie applications. By understanding these levels, developers can effectively manage application verbosity, control debugging output, and ensure proper error handling.
