This directory contains the essential API reference documentation for the data structures utilized within the `unittest_common` package of the Cangjie testing framework. It is designed to assist developers in understanding the core components that facilitate configuration management and command-line interface generation. The documentation specifically details the `KeyTags` struct, which is pivotal for defining configuration keys and managing tag names, and the `OptionInfo` struct, which is responsible for storing metadata for command-line options that appear in help pages. Key aspects covered include the properties of `KeyTags` and the various fields of `OptionInfo`, such as descriptions, names, type mappings, and user-defined statuses. This resource is highly suitable for software developers and QA engineers who are actively working with the Cangjie framework, providing them with the necessary definitions to handle complex configuration logic and automate the generation of help text effectively.
