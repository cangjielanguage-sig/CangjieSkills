# 布局概述

This directory provides a comprehensive guide to layout mechanisms within the ArkUI framework, specifically tailored for declarative UI development. It covers the fundamental principles of page structure, component positioning, and the strategic selection of layout types such as Linear, Stack, and Grid. Key topics include layout constraints, element sizing, and responsive adaptation strategies. Designed for application developers and UI engineers, these documents serve as an essential reference for optimizing page structure, managing visual presentation, and ensuring precise control over component behavior across various device sizes.

## Detailed Description

### 如何选择布局.md
This guide assists developers in selecting the appropriate declarative UI layout based on specific application scenarios. It covers ten common layout types including Linear, Stack, Flex, Relative, Grid, List, and Tabs. The document provides a comparison table detailing the specific use cases for each layout, such as using Stack for overlapping elements or RelativeContainer for complex positioning to reduce nesting. It highlights features like scrolling, multi-device adaptation, and view switching. It targets application developers using declarative UI frameworks, serving as a reference for optimizing page structure and visual presentation.

### 布局位置_2more.md
This technical guide explains layout positioning mechanisms and child element constraints within the ArkUI framework. It covers absolute and relative positioning attributes, followed by detailed constraints including stretching, scaling, percentage sizing, and conditional hiding. Key information includes the use of position and offset for location adjustments, and flexGrow, flexShrink, aspectRatio, layoutWeight, and displayPriority for managing how child elements adapt to container size changes. The document serves as a reference for UI developers requiring precise control over component layout and responsiveness across different device sizes.

### 布局概述_3more.md
This document provides a conceptual overview of layout mechanisms within the ArkUI framework, explaining how to arrange UI components to construct application pages. It covers the layout development process, hierarchical page structure, and the detailed composition of layout elements including component area, content area, and layout boundaries. Key information includes definitions of how attributes like width, height, border, margin, and align interact to determine the final size and position of components, distinguishing between the component area and the actual content size. This guide targets developers using declarative UI frameworks who need to understand the fundamental principles of page layout and element positioning.
