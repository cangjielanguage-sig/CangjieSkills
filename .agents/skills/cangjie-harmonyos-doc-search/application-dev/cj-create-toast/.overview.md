# cj-create-toast

This directory serves as a comprehensive technical resource for implementing Toast components within HarmonyOS applications using the Cangjie language. It is specifically designed to assist developers in creating temporary, non-intrusive user feedback mechanisms that strictly adhere to system standards. The content covers the complete API implementation chain, focusing heavily on the interaction between UIContext and PromptAction. Furthermore, it addresses critical technical aspects such as security constraints, usage recommendations, and the nuanced differences between display modes like Default versus TopMost. By exploring sub-window creation, display hierarchy, and keyboard avoidance logic, this guide ensures that developers can manage complex UI layering effectively. This resource is ideal for HarmonyOS developers and UI designers who need to master the technical details of lightweight status notifications. It ensures that applications provide clear, compliant feedback without disrupting the user workflow, ultimately enhancing the overall user experience through precise and controlled UI elements.

## Detailed Description

### 即时反馈Toast/
This directory focuses on the implementation and usage of Toast components within HarmonyOS applications. It provides comprehensive guidelines for displaying temporary, non-intrusive user feedback, covering essential aspects such as API implementation chains involving UIContext and PromptAction, security constraints, and specific usage recommendations. Additionally, it explores technical comparisons between different display modes (Default vs. TopMost) in ArkUI using the Cangjie language, detailing sub-window creation, display hierarchy, and keyboard avoidance logic. Key topics include text density, display duration, positioning, and interaction limitations. This resource is suitable for HarmonyOS developers and UI designers seeking to implement lightweight status notifications and master the technical nuances of feedback mechanisms. By understanding these components, developers can ensure their applications provide clear, system-compliant user feedback without disrupting the overall workflow. The guide emphasizes the importance of selecting the correct display mode to ensure that notifications appear above other UI elements when necessary, while also respecting system-level security and interaction boundaries. Mastering these elements allows for a polished user interface that communicates status updates efficiently.
