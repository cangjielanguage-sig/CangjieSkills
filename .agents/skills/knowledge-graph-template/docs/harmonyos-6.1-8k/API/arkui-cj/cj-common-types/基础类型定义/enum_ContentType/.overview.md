# enum_ContentType

本目录包含ArkUI框架中ContentType枚举的文档，主要用于定义支持情景化自动填充的内容类型。涵盖了手机号、邮箱、银行卡号、身份证号、地址、用户名及密码等多种数据类型。这些API旨在帮助使用仓颉语言开发ArkUI应用的开发者实现表单数据的智能自动保存与填充功能，提升用户体验。相关接口系统能力要求为SystemCapability.ArkUI.ArkUI.Full，起始版本为22。
