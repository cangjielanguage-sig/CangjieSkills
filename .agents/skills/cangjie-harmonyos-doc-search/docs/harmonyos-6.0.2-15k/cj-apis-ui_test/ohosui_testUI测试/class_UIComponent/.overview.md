# class_UIComponent

This directory contains API reference documentation for the `UIComponent` class within the Cangjie programming language's UiTest framework. It covers a comprehensive suite of methods designed for automated UI testing, including component interaction, state verification, property retrieval, and gesture simulation. Key topics include clicking, text input, scrolling, and checking component states like visibility or focus. The documentation is intended for developers and QA engineers using the TestKit to automate UI interactions in the HarmonyOS ecosystem, requiring familiarity with Cangjie syntax and testing concepts.
