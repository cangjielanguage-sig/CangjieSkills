This directory serves as a comprehensive resource for developers aiming to master the Network Kit within their application development lifecycle. It provides a detailed overview of the kit's core functionalities, specifically focusing on the execution of HTTP data requests and the intricate management of network connections. The content covers critical aspects such as the prioritization of WiFi, cellular, and Ethernet connections, ensuring optimal data flow based on network availability and quality. Additionally, it explores advanced features like network quality assessment and DNS resolution mechanisms. A significant portion of the guide is dedicated to security and access control, outlining the specific permissions required—such as `ohos.permission.GET_NETWORK_INFO` and `ohos.permission.INTERNET`—to leverage these network services effectively. This documentation is essential for developers seeking a foundational understanding of network capabilities and the necessary compliance measures for secure app development.
