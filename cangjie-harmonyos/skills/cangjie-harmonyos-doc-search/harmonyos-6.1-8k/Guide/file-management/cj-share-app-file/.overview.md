# cj-share-app-file

本目录专注于应用间文件共享的技术实现与规范定义，核心内容围绕基于URI的文件传输机制展开。文档详细阐述了如何利用startAbility启动能力进行文件分享，明确了应用沙箱内可共享的目录范围（涵盖el1与el2加密级别），并定义了包含file、bundleName和path的标准URI格式。此外，还介绍了被分享应用如何使用ohos.file_fs.open接口对共享文件进行读写操作。该资料主要面向应用开发人员，特别是那些需要在系统中实现跨应用数据交互与文件传输功能的开发者，提供了必要的规范指导与实现路径。

## 详细说明

### cj-share-app-file.md cj-share-app-file.md

本文档旨在介绍应用之间通过URI进行文件共享的机制与规范。主要涵盖基于startAbility的文件分享方式、应用可分享的沙箱目录路径以及文件URI的标准格式规范。核心信息包括文件URI由file、bundleName和path组成，可分享目录涵盖el1及el2加密级别的数据目录，被分享应用可通过ohos.file_fs.open接口对URI进行读写操作。该文档面向应用开发人员，适用于需要实现跨应用文件传输功能的开发场景。
