This directory provides comprehensive documentation for developers utilizing the Cangjie API within the HarmonyOS SDK ecosystem. It covers critical aspects of the development lifecycle, including how to integrate and execute sample code, interpret API documentation regarding versioning and SystemCapabilities, and manage permissions and application models. Key topics include project template creation, the `canIUse` method for feature verification, Stage model compatibility, and handling deprecated interfaces. These guides are essential for Cangjie and HarmonyOS developers aiming to ensure correct API implementation, maintain code stability, and comply with system security requirements across various hardware configurations.
