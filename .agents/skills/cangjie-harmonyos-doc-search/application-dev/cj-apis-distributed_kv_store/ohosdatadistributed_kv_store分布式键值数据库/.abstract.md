This directory provides API reference documentation for the distributed key-value database module in the Cangjie language, designed for the HarmonyOS ArkData framework. It covers the core functionalities required to implement distributed data management, including database creation, configuration, querying, and synchronization across devices. Key topics include schema definitions, security levels, data types, and system constraints. This documentation is suitable for developers building applications that need robust local storage and cross-device data collaboration capabilities.
