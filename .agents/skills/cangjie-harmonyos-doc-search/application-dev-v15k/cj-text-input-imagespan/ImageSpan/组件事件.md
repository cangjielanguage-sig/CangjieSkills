## 组件事件

### func onComplete((ImageLoadResult) -> Unit)

```cangjie
public func onComplete(callback: (ImageLoadResult) -> Unit): This
```

**功能：** 图片数据加载成功和解码成功时均触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 15

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|([ImageLoadResult](#class-imageloadresult))->Unit|是|-|回调函数，图片数据加载成功和解码成功时触发。参数：成功加载的图片尺寸。|

### func onError((CJImageError) -> Unit)

```cangjie
public func onError(callback: (CJImageError) -> Unit): This
```

**功能：** 图片加载异常时触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 15

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|([CJImageError](#class-cjimageerror))->Unit|是|-|回调函数，图片加载出现异常时触发。参数：图片加载异常信息。|
