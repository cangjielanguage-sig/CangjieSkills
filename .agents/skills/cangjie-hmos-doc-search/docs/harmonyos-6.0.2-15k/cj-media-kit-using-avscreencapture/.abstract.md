This directory serves as a specialized resource for developers working within the HarmonyOS ecosystem, specifically focusing on the MediaKit framework's screen recording capabilities. It details the implementation of screen capture using the `AVScreenCaptureRecorder` module, with all code examples and documentation provided in the Cangjie language. The content covers the full spectrum of development tasks, from the initial creation of recording instances and the fine-tuning of audio-video parameters to the complex management of application lifecycles and system permissions. Additionally, it tackles advanced use cases such as configuring privacy exemptions and handling display selection for 2-in-1 devices. This collection is ideal for software engineers and system developers who need to build reliable, high-performance screen recording features into their applications while ensuring efficient resource management and compliance with system privacy protocols.
