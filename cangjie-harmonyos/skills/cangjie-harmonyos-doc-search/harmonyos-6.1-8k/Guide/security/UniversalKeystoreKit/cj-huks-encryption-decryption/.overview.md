# cj-huks-encryption-decryption

This directory serves as a comprehensive resource for developers working with data encryption and decryption in the Cangjie programming language environment. It focuses on the practical application of mainstream cryptographic algorithms, including AES, RSA, and SM2, within the HarmonyOS ecosystem. The documentation provides in-depth guidance on the UniversalKeystoreKit framework, detailing the complete lifecycle of key management and specific API call flows. Furthermore, it offers real-world development cases demonstrating how to leverage HarmonyOS HUKS (Hardware Uniqueness Key Store) for enhanced hardware-level security. This collection is ideal for developers seeking to implement robust data protection mechanisms in their applications, providing the necessary tools to master complex encryption integrations efficiently.
