The ImageSpan directory provides comprehensive documentation for the ImageSpan component within the Cangjie ArkUI framework. It covers the integration of inline images into text elements, detailing initialization methods, component properties, event handling, and practical code examples. Key topics include image loading states, error management, visual styling (alignment, scaling, backgrounds), and fundamental type definitions. This resource is suitable for HarmonyOS developers using Cangjie who need to implement rich text layouts with embedded images, manage asynchronous loading, and customize visual presentation.
