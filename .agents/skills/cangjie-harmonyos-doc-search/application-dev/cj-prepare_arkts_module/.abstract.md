This directory contains a specialized technical guide designed to facilitate the integration of ArkTS modules into Cangjie applications, a key requirement for developers operating within the OpenHarmony ecosystem. The content primarily addresses the complexities associated with importing and utilizing NAPI modules, ensuring that cross-language interoperability is achieved with minimal friction. It provides a deep dive into the naming convention mapping rules that are essential for correctly referencing modules, clearly distinguishing between the handling of standard OpenHarmony system modules and external third-party libraries. By offering a detailed reference table and practical examples, such as the transformation of module names like @ohos.file.photoAccessHelper, this documentation helps developers avoid common configuration errors. This resource is ideally suited for backend developers, system integrators, and application engineers who are building or maintaining hybrid applications that leverage both Cangjie and ArkTS technologies.
