This directory provides comprehensive API reference documentation for the `SheetOptions` class within the Cangjie language and ArkUI framework. It focuses on configuring optional attributes for half-modal pages, covering visual styling, lifecycle events, and behavioral settings. Developers will find details on background colors, borders, dismissal logic, height detents, and interaction modes like drag bars. This documentation is essential for UI developers seeking to implement or customize sheet interfaces, requiring familiarity with Cangjie syntax and UI component lifecycles to create interactive and responsive semi-modal components. It serves as a technical guide for ensuring precise customization of UI elements in ArkUI applications, enabling the creation of sophisticated user interfaces with granular control over modal behaviors and appearance.
