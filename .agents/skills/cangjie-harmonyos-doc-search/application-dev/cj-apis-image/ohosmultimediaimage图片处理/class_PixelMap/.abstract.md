This directory provides API reference documentation for the `PixelMap` class in the Cangjie ImageKit framework, essential for HarmonyOS multimedia image processing. It covers a wide range of functionalities including image creation, pixel data reading and writing, geometric transformations, and color space management. Key topics include memory management, buffer operations, and property retrieval such as density and image info. This documentation is intended for software developers and engineers building image manipulation applications using the Cangjie programming language, offering detailed syntax, parameters, and error handling for system capabilities starting from version 22.
