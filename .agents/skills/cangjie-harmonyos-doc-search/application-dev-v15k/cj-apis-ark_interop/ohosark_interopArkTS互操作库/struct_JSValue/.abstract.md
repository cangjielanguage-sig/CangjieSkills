This directory contains API reference documentation for the `JSValue` struct in the Cangjie programming language, specifically designed for interoperability with the ArkTS runtime in HarmonyOS. It covers type conversions, object binding, property manipulation, and type checking within the Napi framework. The documentation details methods for transforming JavaScript values into Cangjie types and vice versa, handling lifecycle constraints, and managing object interactions. It is suitable for Cangjie developers working on ArkUI applications who need to integrate with JavaScript environments, ensuring safe data exchange and type management.
