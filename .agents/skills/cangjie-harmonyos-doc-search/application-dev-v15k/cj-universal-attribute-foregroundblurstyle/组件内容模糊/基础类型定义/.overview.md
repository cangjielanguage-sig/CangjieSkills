# 基础类型定义

This directory contains API reference documentation for fundamental Cangjie types used within the ArkUI framework to configure visual blur effects. It covers classes for defining blur parameters, styles, and foreground options, as well as enumerations for adaptive color modes. Key concepts include grayscale blur, content blur, scale intensity, and color sampling. These definitions are essential for developers implementing advanced UI visual effects in HarmonyOS applications using the Cangjie language.

## Detailed Description

### class_BlurOptions.md
This document serves as API reference documentation for the Cangjie class BlurOptions, which defines grayscale blur parameters within the ArkUI framework. The content details the class structure, specifically focusing on the public member variable grayscale and the class constructor. Key information includes that the grayscale property is a readable and writable VArray<Float32, $2> with a value range of [0, 127], which is also the required parameter for instantiating the object. This documentation is intended for Cangjie developers working on ArkUI interfaces who need to implement specific visual blur effects.

### class_BlurStyleOptions.md
This document provides API reference documentation for the Cangjie class BlurStyleOptions, used to configure content blur effects in the ArkUI framework. It details the class structure, specifically defining read-only properties like adaptiveColor, blurOptions, colorMode, and scale, along with their types and default values. Additionally, it specifies the constructor parameters required to instantiate the object. Key information includes the valid range for the scale parameter (0.0 to 1.0) and the read-only nature of all attributes. This guide targets developers implementing visual blur styles, requiring knowledge of Cangjie syntax and ArkUI system capabilities.

### class_ForegroundBlurStyleOptions.md
This document provides API reference documentation for the ForegroundBlurStyleOptions class in the Cangjie language, used to configure content blur effects within the ArkUI framework. It covers the class constructor and four public properties: adaptiveColor, blurOptions, colorMode, and scale. Key information includes the data types for color modes and grayscale parameters, as well as the scale property, introduced in version 19, which defines blur intensity between 0.0 and 1.0. All parameters are optional named arguments with specific default values. Intended for developers building UIs with ArkUI, this reference requires familiarity with Cangjie syntax and visual effect implementation.

### enum_AdaptiveColor.md
This document serves as API reference for the AdaptiveColor enum in the Cangjie language, defining color sampling modes for UI masks. It details the enum definition and two specific enumeration values: DEFAULT and AVERAGE. Key information includes that DEFAULT bypasses color sampling blur for performance, using the default color, while AVERAGE applies sampling blur to calculate the average color of a region for the mask, though this is noted to be more resource-intensive. Both are available from API version 12. This targets HarmonyOS ArkUI developers using Cangjie who need to implement adaptive color masking in their applications.
