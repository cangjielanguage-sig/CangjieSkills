This directory contains API reference documentation for the `LocaleOptions` struct within the Cangjie programming language. It focuses on the internationalization (i18n) framework, specifically detailing how to configure and initialize locale settings. The documentation covers essential properties such as calendar systems (e.g., "gregory"), collation rules (e.g., "pinyin"), numbering systems, and time display formats. It is designed for developers working on the SystemCapability.Global.I18n module (version 19+) who require precise control over regional formatting, sorting rules, and localization behaviors in their applications.
