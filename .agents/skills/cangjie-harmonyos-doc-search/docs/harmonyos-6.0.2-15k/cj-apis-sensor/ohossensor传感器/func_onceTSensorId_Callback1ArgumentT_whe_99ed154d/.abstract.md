This directory contains the API reference documentation for the Cangjie function `once`, a component of the SensorServiceKit designed for asynchronous single-instance sensor data retrieval. The documentation provides a technical deep dive into the function's signature, system capabilities, and input parameters, with a specific focus on sensor types and callback mechanisms.
Key topics covered include:
- **Function Mechanics:** How to use the `once` function for non-continuous data fetching.
- **Sensor Mapping:** A comprehensive table linking sensors like Accelerometer and Gyroscope to data types and permissions.
- **Error Handling:** A detailed list of business exceptions and error codes.
- **Implementation:** Practical code examples for developers.
This resource is essential for Cangjie developers who need to integrate one-time sensor data acquisition into their applications while ensuring proper permission management and error handling.
