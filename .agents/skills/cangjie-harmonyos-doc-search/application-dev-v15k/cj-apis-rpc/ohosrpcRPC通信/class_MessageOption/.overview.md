# class_MessageOption

This directory provides comprehensive API reference documentation for the Cangjie `MessageOption` class, a critical component for configuring options within Inter-Process Communication (IPC) and Remote Procedure Call (RPC) message requests. It covers the definition of static constants for synchronous (TF_SYNC) and asynchronous (TF_ASYNC) flags, file descriptor support (TF_ACCEPT_FDS), and wait time management. The documentation includes detailed references for the class constructor and methods such as `getFlags`, `setAsync`, `setFlags`, and `setWaitTime`. It is specifically suitable for Cangjie developers operating within the `SystemCapability.Communication.IPC.Core` framework who need to precisely control message transmission behavior, manage call modes, and handle timeouts effectively in their applications. The directory is divided into specific files focusing on class overview and function configuration to facilitate easy navigation and implementation.
