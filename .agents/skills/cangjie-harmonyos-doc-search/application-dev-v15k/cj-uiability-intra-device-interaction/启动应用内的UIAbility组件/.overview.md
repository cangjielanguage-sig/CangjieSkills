# 启动应用内的UIAbility组件

This directory provides a comprehensive technical guide for developers working with HarmonyOS applications, focusing on the mechanisms to start UIAbility components within the same application. It covers essential navigation logic, including standard startup, launching specific pages, and retrieving execution results. Key topics include the AbilityKit framework, Want object configuration, lifecycle management (such as `onCreate` and `onNewWant`), and inter-component data exchange. This resource is suitable for application developers using the Cangjie language who need to manage internal application flow, handle cold and hot starts, and implement robust state management in multi-module projects.

## Detailed Description

### 启动应用内的UIAbility组件.md 启动应用内的UIAbility组件.md
This technical guide explains how to start UIAbility components within the same application, defining UIAbility as the system's smallest scheduling unit for functional module transitions. The document covers three main implementation scenarios: starting a UIAbility, starting one to obtain a return result, and launching a specific page within a UIAbility. It distinguishes these internal operations from inter-app jumps. Targeted at application developers, this guide provides essential navigation logic for managing internal application flow and component interaction.

### 启动UIAbility的指定页面/
This directory focuses on the technical implementation of launching specific pages within a UIAbility component in HarmonyOS development using the Cangjie language. It covers the distinctions between cold starts (initializing new instances) and hot starts (restoring running instances), detailing how to pass parameters via the Want object to control navigation. Key topics include lifecycle callbacks like `onCreate`, `onWindowStageCreate`, and `onNewWant`, as well as routing mechanisms. This resource is suitable for developers using the AbilityKit framework who need to manage inter-page navigation, parameter passing, and application lifecycle states effectively.

### 启动应用内的UIAbility/
This directory serves as a technical resource for developers working with HarmonyOS, focusing specifically on the lifecycle management of UIAbility components within a single application. It details the procedures for launching specific UIAbilities from other components, emphasizing the configuration of Want objects and the transfer of custom parameters via Cangjie code. Additionally, it covers the termination of instances and processes, including snapshot management and configuration in module.json5. By integrating concepts from the AbilityKit APIs and lifecycle callbacks like onCreate and onNewWant, this guide assists developers in building efficient multi-module applications with seamless internal navigation and robust state management.

### 启动应用内的UIAbility并获取返回结果/
This directory provides comprehensive technical guidance on the HarmonyOS Cangjie framework mechanism for launching an in-app UIAbility and retrieving its execution results. It thoroughly details the complete interaction flow, covering the caller's role in initiating requests via `startAbilityForResult` and the callee's responsibility in returning data using `terminateSelfWithResult`. Key technical concepts include `Want` object construction, JSON parameter passing, asynchronous callback handling, and parsing `AbilityResult` return codes. This resource is specifically designed for developers building Stage model applications who require robust inter-ability communication and data return logic within their HarmonyOS projects. It serves as an essential reference for mastering inter-component data exchange and ensuring seamless user experiences across different application modules.
