This directory focuses on the implementation of image editing capabilities within the HarmonyOS ecosystem using the `cj-photoEditorExtensionAbility`. It serves as a comprehensive resource for developers looking to integrate system-level image editing features or create dedicated editor extensions. The content covers the complete workflow, including invoking the editor via `startAbilityByType`, managing the `PhotoEditorExtensionAbility` lifecycle, handling data transmission through URIs, and saving edited PixelMap data. This guide is suitable for developers working with ArkTS or Cangjie who need to build robust image editing interactions between host and extension applications.
