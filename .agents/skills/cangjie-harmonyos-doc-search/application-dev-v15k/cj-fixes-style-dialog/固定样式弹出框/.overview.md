# 固定样式弹出框

This directory provides comprehensive documentation and tutorials for implementing fixed-style popup components using the Cangjie language within the ArkUI and HarmonyOS frameworks. It covers a range of standard UI elements designed to simplify development by utilizing pre-defined layouts rather than custom designs. Key topics include ActionSheets for list selection, AlertDialogs for critical warnings, and PickerDialogs for date and time selection. The guides detail configuration parameters, transition animations, and user interaction handling. This resource is suitable for application developers seeking to integrate robust, interactive dialog menus and alerts into their user interfaces efficiently.

## Detailed Description

### 列表选择弹窗ActionSheet.md 列表选择弹窗ActionSheet.md
This document provides a code tutorial for implementing a list selection popup (ActionSheet) using the Cangjie language. It focuses on the `ActionSheet.show` interface to display multiple operation options. Key topics include configuring the popup's layout properties such as width, height, border styles, and background color, as well as defining complex transition animations using `TransitionEffect.asymmetric`. The example demonstrates how to populate the sheet with `SheetInfo` items and handle user interactions. This guide is intended for developers building UI components with ArkUI who need to create customizable, animated dialog menus.

### 固定样式弹出框_4more.md 固定样式弹出框_4more.md
This document serves as a development guide for implementing fixed-style popups in the ArkUI framework using the Cangjie language, aiming to simplify UI creation by utilizing pre-defined layouts. The content covers usage constraints, specifically the requirement for the PromptAction object, and details two main components: Action Menus (showActionMenu) and Dialogs (showDialog). Key information includes the ability to set popups as non-modal and the asynchronous return of selected button indices. The guide provides practical Cangjie code examples demonstrating how to configure titles, messages, buttons, and handle callback results. The target audience is application developers using Cangjie who need to implement standard user interaction elements like menus and alerts without custom layout design.

### 警告弹窗AlertDialog.md 警告弹窗AlertDialog.md
This document explains how to implement and use AlertDialogs in the Cangjie programming language to prompt users for critical decisions or permissions. It covers usage guidelines, the AlertDialog.show interface, and a practical code example demonstrating configuration parameters like buttons, alignment, and transition animations. Key takeaways include the importance of providing actionable options to avoid user frustration and the specific syntax for configuring dialog properties such as AlertDialogParamWithButtons and TransitionEffect. Targeted at developers using the Cangjie language and HarmonyOS framework who need to implement modal dialogs for user interaction.

### 选择器弹窗PickerDialog/
This directory provides comprehensive documentation for implementing PickerDialog components within Cangjie applications. It focuses on the technical aspects of integrating date selection interfaces, covering essential features such as lunar calendar switching, time display, and state management. The content guides developers through configuring date ranges, customizing text styles, and managing dialog lifecycles. It also details how to handle critical event callbacks like onDateAccept and onDateChange to ensure user choices are persisted. This resource is specifically designed for application developers utilizing the Cangjie language and UIKit framework who require robust, interactive popup dialogs for date selection in their user interfaces.
