# hidumper

HiDumper 是 OpenHarmony 系统中面向开发与测试人员的统一系统信息获取工具，旨在协助用户进行系统问题分析与定位。本目录涵盖了该工具的参考指南及常用命令集，内容涉及系统基础信息查询、核心服务状态监控、性能数据统计（如 CPU、内存、网络）以及高级内存分析。通过命令行操作，用户可以高效地获取系统集群能力、崩溃日志、进程状态等关键数据，适用于系统状态监控、故障日志转储及性能调优场景。

### hidumper_3more_04d679fa.md hidumper_3more_04d679fa.md
本文档是 HiDumper 工具的参考指南，这是一个为开发和测试人员设计的统一系统信息获取工具，旨在帮助用户分析和定位系统问题。文档主要包含环境准备要求及详细的命令行参数说明。关键内容涵盖了列出系统集群与能力、获取特定系统信息、崩溃日志、网络、存储、进程、CPU 及内存统计等功能，并支持将输出保存为压缩文件。该文档目前处于 Beta 阶段，适用于熟悉命令行工具和 hdc 连接的开发与测试人员。

### 常用命令/
本目录汇集了 OpenHarmony 系统中 hidumper 调试工具的常用命令参考指南。文档内容涵盖了系统基础信息查询、核心服务状态监控（如窗口、渲染、电源）、性能数据统计（CPU、内存、网络、IPC）以及高级内存分析（JS 堆内存、内存映射）。这些资料旨在帮助系统开发者和维护人员快速掌握命令行工具的使用，以便高效地进行系统状态监控、故障日志转储及性能调优。
