This directory serves as a central repository for API reference documentation concerning the `ohos.settings` module, explicitly designed for use with the Cangjie programming language. Its primary focus is on system settings management, providing developers with the necessary tools to query and modify a vast array of device states programmatically. The content covers an extensive range of configuration options, including wireless connectivity, display parameters, input methods, network settings, sound controls, and text-to-speech functionalities. By detailing the specific enumerations, classes, and functions required for these tasks, the documentation supports the effective implementation of the SystemCapability.Applications.Settings.Core capability. This resource is indispensable for HarmonyOS developers and system integrators targeting version 19 or higher, as it offers the technical guidance needed to programmatically control device behavior and customize user preferences within their applications.
