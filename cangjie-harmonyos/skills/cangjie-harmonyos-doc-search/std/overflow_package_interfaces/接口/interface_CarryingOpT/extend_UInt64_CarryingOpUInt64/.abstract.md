This directory provides comprehensive API reference documentation for the `CarryingOp` interface implementation tailored for the `UInt64` type within the Cangjie programming language. It details a suite of arithmetic and bitwise functions designed to handle potential overflows through a specific wrapping strategy. Instead of causing runtime errors, these operations return a tuple containing the calculation result and a Boolean flag indicating if truncation occurred. This documentation is essential for Cangjie developers who need precise, low-level control over unsigned 64-bit integer arithmetic and require reliable overflow detection mechanisms to ensure numerical integrity in their applications.
