This directory contains the essential API reference documentation for the class definitions within the `ref` package of the Cangjie programming language. It focuses specifically on weak reference mechanisms, which are critical tools for advanced memory management in modern software development. The content covers the generic `WeakRef` class and its sealed abstract parent, `WeakRefBase`, providing developers with the necessary knowledge to implement sophisticated garbage collection strategies. By utilizing a specified `CleanupPolicy`, developers can allow the garbage collector to handle reachable objects efficiently without manual intervention. The documentation also details key members such as the `value` property, which returns an `Option` type for safe access, and the `clear` method for forced cleanup. This resource is highly suitable for systems programmers and application developers who require precise control over object lifecycles, need to prevent memory leaks, or wish to optimize resource usage in Cangjie applications.
