This directory provides comprehensive API documentation for a deprecated Cangjie language interface titled `SortByExtension`. It covers the technical specifications of legacy custom sorting capabilities, specifically focusing on the extension of the Array type. The content details the implementation of overloaded `sortBy` functions, which utilize comparator functions returning an `Ordering` type to dictate element placement and stability. This documentation is essential for Cangjie developers who are maintaining older codebases or actively migrating existing implementations to the current standard `sort` API, ensuring they understand the logic and deprecation warnings associated with these legacy components.
