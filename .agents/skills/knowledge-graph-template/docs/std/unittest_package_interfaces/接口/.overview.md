# 接口

This directory provides comprehensive API reference documentation for core interfaces within the Cangjie programming language's testing and benchmarking frameworks. It covers essential components for performance testing, including input providers, measurement configurations, and result reporting, as well as utility interfaces for approximate equality comparisons in numerical computing. Key topics include `BenchmarkConfig`, `Measurement`, `Reporter`, and `NearEquatable`. These resources are designed for developers and software engineers who need to implement custom test logic, optimize performance benchmarks, or handle precise floating-point comparisons in their Cangjie projects.

## Detailed Description

### interface_BenchInputProvider.md interface_BenchInputProvider.md
This API reference document defines the `BenchInputProvider` interface for supplying input data during performance benchmarking in Cangjie. It covers the interface definition, its inheritance from `BenchmarkInputMarker`, and detailed specifications for the `get` and `reset` methods. Key information includes that `get` retrieves elements by index with execution time excluded from results, while `reset` initializes the data range. The document clarifies that users typically use the `@Strategy` macro instead of manually implementing this interface. This guide targets developers creating performance tests requiring dynamic input handling.

This resource is ideal for developers and software engineers using the Cangjie framework who need to customize and fine-tune benchmark test scenarios for accurate, reliable performance measurement and analysis.

### interface_NearEquatableCT_D/
This directory contains essential API documentation for the `NearEquatable<CT, D>` interface in the Cangjie programming language, specifically designed to facilitate approximate equality comparisons between objects. It addresses the complexities of floating-point arithmetic by providing implementations for Float16, Float32, and Float64 types, supporting both absolute and relative delta calculations. The documentation covers the core `isNear` method, parameter constraints, and exception handling for invalid delta values, such as negative or NaN inputs. This resource is highly suitable for developers working on numerical computing, financial applications, or unit testing in Cangjie who need precise control over comparison tolerances to ensure accuracy and reliability in their software projects.
