This directory contains API documentation for deprecated sorting interfaces within the Cangjie programming language. Key topics include auxiliary sorting functionality, custom comparators, and sort stability. These documents are intended for Cangjie developers maintaining legacy codebases or migrating to modern sorting APIs, as these components are obsolete and will be removed in future versions.
