# 使用场景

This directory explores practical usage scenarios for state management in Cangjie and HarmonyOS application development. It focuses on the implementation of AppStorage and LocalStorage for managing application-wide and component-scoped states, including handling complex data types like DateTime, Map, and Set. Additionally, it addresses performance best practices, specifically advising against using state synchronization mechanisms for event notifications. This content is suitable for Cangjie developers and HarmonyOS architects looking to optimize reactive UI updates and application architecture.

## Detailed Description

### 从应用逻辑使用AppStorage和LocalSto_2more.md
This technical guide demonstrates how to implement state management using AppStorage and LocalStorage in Cangjie applications. It covers usage within application logic and UI components, highlighting the singleton nature of AppStorage versus the instance-based LocalStorage. Key takeaways include using static APIs for AppStorage, creating bidirectional data synchronization via the link method, and employing @StorageLink and @LocalStorageLink decorators for reactive UI updates on both primitive and custom object types. This tutorial targets Cangjie developers building HarmonyOS applications who need to manage application-wide or component-scoped state.

### 装饰DateTime类型变量_3more.md
This tutorial demonstrates how to use the @StorageLink decorator to manage state for DateTime, Map, and Set data types in Cangjie applications. The document is divided into three sections, each providing a runnable code example for a specific data type: DateTime with a DatePicker, Map with key-value pairs, and Set with unique elements. Key takeaways include the method for triggering UI updates, particularly for Map and Set, which requires modifying a temporary copy and reassigning it to the state variable. This guide is intended for Cangjie developers implementing reactive state management in HarmonyOS UI development.

### 不建议借助StorageLink的双向同步机制实现事件通知
This directory provides critical technical guidance and best practices for implementing event notifications in application development, specifically within the HarmonyOS and Cangjie ecosystems. It strongly advises against utilizing `@StorageLink` and `AppStorage` for event-driven tasks due to the significant performance overhead caused by their two-way synchronization mechanisms. Instead, it promotes the use of the `Emitter` pattern for decoupled communication. The content covers the inefficiencies of global state refreshes, the benefits of callback-based event dispatching, and practical implementation strategies. This resource is essential for developers using the UIKit framework or ArkTS who aim to optimize UI rendering performance and maintain clean, readable code architecture while avoiding common pitfalls in state management. By following these guidelines, developers can ensure their applications remain responsive and efficient.
