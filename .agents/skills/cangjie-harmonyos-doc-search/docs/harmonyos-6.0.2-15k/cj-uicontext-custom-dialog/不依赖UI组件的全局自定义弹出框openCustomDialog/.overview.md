# 不依赖UI组件的全局自定义弹出框openCustomDialog

This directory provides a comprehensive technical resource for implementing global custom dialogs in HarmonyOS applications using the Cangjie language. It specifically focuses on the `PromptAction.openCustomDialog` interface, providing a robust solution to the dynamic creation limitations often encountered with `CustomDialogController`. The documentation covers essential implementation details, including parameter input methods via `CustomDialogOptions` and Lambda expressions, as well as the complete dialog lifecycle management involving appearance and disappearance callbacks. It is highly suitable for Cangjie developers who need to build complex, flexible, and decoupled UI components that can be updated dynamically at runtime. By mastering these techniques, developers can significantly enhance user interaction through robust modal windows without relying on static UI component dependencies.
