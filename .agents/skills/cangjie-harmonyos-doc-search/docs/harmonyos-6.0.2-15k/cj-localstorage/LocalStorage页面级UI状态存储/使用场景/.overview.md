# 使用场景

This directory provides comprehensive tutorials on using LocalStorage for state management in HarmonyOS applications developed with the Cangjie language. It covers a wide range of scenarios, from basic one-way and two-way data binding to sharing state across multiple views and UIAbility instances. Advanced topics include handling complex data types like DateTime and Map, as well as integrating state management in hybrid ArkTS and Cangjie environments. These guides are suitable for HarmonyOS developers looking to implement reactive state synchronization and manage global application logic effectively.

## Detailed Description

### LocalStorageProp和LocalStor_3more.md LocalStorageProp和LocalStor_3more.md
This tutorial illustrates state management in Cangjie applications using LocalStorage decorators. It covers three main scenarios: one-way data synchronization using @LocalStorageProp, two-way synchronization using @LocalStorageLink, and state sharing between sibling components. Key takeaways include understanding how to initialize LocalStorage instances, bind component variables to storage keys, and manage data flow direction. The document provides code examples showing how changes in local variables or storage instances propagate across the UI. It is intended for HarmonyOS developers seeking to implement reactive state management in their applications.

### 将LocalStorage实例从UIAbility共享到一个或多个视图.md 将LocalStorage实例从UIAbility共享到一个或多个视图.md
This tutorial demonstrates how to share a LocalStorage instance across multiple views in a HarmonyOS application using the Cangjie language. It covers creating a LocalStorage instance within the UIAbility class and accessing it in separate view components like EntryView and Page. The core technique involves using the `@Entry[storage]` decorator to link views to the shared storage and `@LocalStorageLink` for two-way data binding, ensuring state synchronization across pages. This guide targets HarmonyOS developers familiar with Cangjie syntax and UI component lifecycle management who need to manage global state across different pages.

### 应用逻辑使用LocalStorage_2more.md 应用逻辑使用LocalStorage_2more.md
This tutorial guide explains how to use LocalStorage for state management in Cangjie applications, covering both application logic and UI integration. The document details basic storage operations like setOrCreate, get, and link, and demonstrates UI implementation using @LocalStorageLink and @Entry decorators. Key takeaways include the mechanism for two-way synchronization between storage instances and UI components, ensuring state consistency across parent and child components. Intended for Cangjie developers, this guide requires prior knowledge of component-based UI architecture and basic state management concepts. Keywords: LocalStorage, Cangjie, state management, two-way binding, @LocalStorageLink, @Entry.

### 自定义组件外改变状态变量_2more.md 自定义组件外改变状态变量_2more.md
This guide explains how to modify state variables outside custom components and share LocalStorage between ArkTS and Cangjie in hybrid HarmonyOS development. It covers modifying state via a Model class in Cangjie and integrating ArkTS LocalStorage with Cangjie views using CJHybridComponentV2. Key concepts include using @LocalStorageLink for reactive binding, LocalStorage.setOrCreate for external updates, and the InterOp parameter to enable cross-language state synchronization. This is intended for developers building mixed-language UI applications who need to manage state consistency across ArkTS and Cangjie environments.

### 装饰DateTime类型变量_3more.md 装饰DateTime类型变量_3more.md
This tutorial demonstrates how to use the @LocalStorageLink decorator to manage state for DateTime, Map, and Set types in Cangjie applications. The document is divided into three sections, each providing a code example for one of these specific data types. Key takeaways include understanding that modifying these decorated variables triggers automatic UI refreshes, and for collections like Map and Set, updates often require reassigning the variable to the state property to ensure observability. This guide is intended for Cangjie developers using the UIKit framework who need to implement reactive state management for complex data structures in their user interfaces.
