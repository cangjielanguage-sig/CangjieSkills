## 详细描述

### 使用_import_语句导入其他包中的声明或定义.md
这份文档详细介绍了仓颉编程语言中 `import` 语句的用法，用于导入其他包的顶层声明或定义。主要涵盖了单条导入、列表导入及通配符导入的语法规范，以及导入语句在源文件中的位置要求。文档重点阐述了导入成员的作用域优先级、可见性规则、禁止循环依赖和自导入的限制，并说明了重名时的遮盖机制与函数重载决议。这是一份语言参考指南，旨在指导仓颉开发者正确处理包依赖和命名空间冲突。

### 重导出一个导入的名字_d11edaf8.md
本文档介绍了仓颉编程语言中重导出导入声明的机制，旨在简化大型项目中的依赖管理。文档详细说明了如何使用 public、internal 和 protected 等访问修饰符来控制重导出成员在不同包和模块中的可见性，并解释了 private 作为默认修饰符的作用范围。关键要点包括通过 public import 允许下游包直接使用导入的成员，以及明确禁止重导出整个包的限制。该技术指南面向需要管理复杂包层级结构并优化外部访问传递依赖的仓颉开发者。

### 隐式导入_core_包_2more_6e84d10a.md
这份文档旨在阐述仓颉编程语言中包的隐式导入机制及命名冲突解决方案。主要涵盖编译器自动导入 `core` 包的原理，以及使用 `import as` 语法重命名导入项的详细规则。关键信息包括重命名后原名称不可用、函数重载时的处理逻辑、通过包名重命名解决模块冲突，以及处理同名声明冲突的三种策略。这是一份面向开发者的语言特性参考指南，帮助用户理解命名空间管理并有效避免代码中的导入冲突。
