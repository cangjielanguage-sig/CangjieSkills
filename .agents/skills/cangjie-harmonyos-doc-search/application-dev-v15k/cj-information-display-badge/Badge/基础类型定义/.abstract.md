This directory contains API reference documentation for fundamental types used in configuring Badge components within the ArkUI framework using the Cangjie language. It covers the `BadgeParams` class for configuration, the `BadgeStyle` class for styling, and the `BadgePosition` enum for layout positioning. These definitions are essential for developers looking to implement notification badges or status indicators in their user interfaces. The documentation targets Cangjie developers working with system capabilities starting from version 12, providing the necessary specifications to build robust UI elements.
