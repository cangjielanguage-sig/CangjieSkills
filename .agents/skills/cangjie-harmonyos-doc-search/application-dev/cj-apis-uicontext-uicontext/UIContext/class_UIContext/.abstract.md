This directory contains API reference documentation for the `UIContext` class and related utility functions within the ArkUI framework, specifically designed for the Cangjie language. It covers essential UI functionalities including animation controls, screen density unit conversions (lpx, px, fp, vp), and dialog management (alerts, action sheets). The documentation details class definitions, method signatures, parameters, and system capabilities. It is suitable for software engineers and developers building responsive layouts and interactive components for HarmonyOS applications who require precise control over UI state, measurements, and user interactions.
