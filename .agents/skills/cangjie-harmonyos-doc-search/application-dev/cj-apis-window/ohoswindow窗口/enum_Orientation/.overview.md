# enum_Orientation

This directory provides comprehensive API reference documentation for the `Orientation` enum in the Cangjie language, specifically designed to facilitate screen display management within the WindowManager system. It thoroughly covers various static orientation modes, including Portrait and Landscape, alongside their inverted counterparts. Furthermore, it details sensor-based AutoRotation features that can dynamically adjust the display based on device movement, with options to either respect or bypass system locks. The documentation also includes definitions for a Locked mode and specific operator overloads. Key concepts involve UI layout adaptation, screen rotation logic, and system capability dependencies. This resource is highly suitable for developers working on Cangjie applications who need to implement robust window management features and control screen orientation behaviors programmatically.

## Detailed Description

### enum_Orientation_14more.md enum_Orientation_14more.md
This API reference document defines the Orientation enum in the Cangjie language, used to specify screen display modes within the WindowManager system. It details various static orientations like Portrait and Landscape, inverted modes, and sensor-based AutoRotation options that respect or ignore system locks. Additionally, it includes a Locked mode and an inequality operator. Key information includes the enum's inheritance from Equatable and its requirement for the SystemCapability.WindowManager.WindowManager.Core capability starting from version 22. This documentation is intended for developers managing UI layout and screen rotation behaviors in Cangjie applications.

### operator_func_Orientation.md operator_func_Orientation.md
This document serves as API reference material for the equality comparison operator overload within the Orientation enum. It details the function signature, system capabilities, version requirements, input parameters, and return types. The operator compares the current instance with another Orientation object, returning a Boolean value indicating equality, and is part of the WindowManager core system capability starting from version 22. Targeted at developers implementing window management logic who need to compare screen orientation states.
