# 开发步骤

This directory serves as a comprehensive technical resource for developers implementing video recording functionality using the Cangjie language. It details the integration of CameraKit and MediaKit to facilitate robust multimedia application development. The content spans the full development lifecycle, beginning with the initial setup of system modules and the creation of a Surface via the AVRecorder instance to manage data flow. It progresses to establishing video output streams based on device capabilities, emphasizing the critical need for consistent aspect ratios between preview and recording streams. Furthermore, it covers advanced configuration steps, such as setting up AVRecorderProfiles with MP4 and AVC codecs, and managing the precise execution order for starting and stopping recording streams. This guide is specifically tailored for software developers and application engineers who possess a foundational understanding of Cangjie syntax and are looking to integrate professional-grade camera capture and video recording features into their software projects.

## Detailed Description

The following files provide step-by-step instructions and code examples for the video recording implementation process.

### 开发步骤_1.md

This document serves as a technical tutorial guiding developers through the initial steps of implementing video recording using the CameraKit and MediaKit in the Cangjie language. The content is structured into three primary stages: importing necessary system modules, creating a Surface via the AVRecorder instance to manage data flow, and establishing the video output stream based on device capabilities. Key takeaways include the critical requirement to maintain consistent aspect ratios between preview and recording streams to ensure compatibility. Additionally, it references specific API methods like getInputSurface and createVideoOutput. This guide is intended for software developers building multimedia applications who require a foundational understanding of the Cangjie syntax and camera API integration.

### 开发步骤_2.md

This technical guide details the implementation steps for video recording functionality using Cangjie's CameraKit and MediaKit. It covers retrieving video output configuration, starting the recording process, and stopping the recording. Key information includes configuring an AVRecorderProfile with specific parameters like MP4 format and AVC codec, matching video profiles to ensure resolution consistency, and the critical execution order for starting and stopping streams. This tutorial targets application developers familiar with Cangjie programming who need to integrate camera video capture and recording features into their applications.
