This directory serves as a comprehensive technical guide for developers implementing core Bluetooth Low Energy (BLE) scenarios using the Cangjie language within the HarmonyOS/OpenHarmony ecosystem. It details the essential workflows required to establish and manage BLE interactions, focusing specifically on the critical lifecycles of advertising and scanning. The content covers a wide range of operations, including configuring custom broadcast parameters, controlling device visibility, managing scan filters, and parsing raw advertising data packets. By providing detailed step-by-step instructions and practical code examples, this documentation is specifically tailored for software engineers and developers aiming to build efficient, resource-aware applications that require robust device discovery, data interpretation, and communication capabilities.
