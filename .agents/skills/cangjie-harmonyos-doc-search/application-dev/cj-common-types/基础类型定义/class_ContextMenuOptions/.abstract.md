This directory contains API reference documentation for the `ContextMenuOptions` class within the Cangjie ArkUI framework. It provides comprehensive resources for configuring popup menus, covering class definitions, constructors, and specific properties for layout, styling, and lifecycle management. Key topics include menu positioning, visual appearance (background, blur, transitions), and event handling (onAppear, onDisappear). This documentation is intended for software developers and UI engineers using API version 22 who need to implement and customize context menu behaviors and aesthetics in their applications.
