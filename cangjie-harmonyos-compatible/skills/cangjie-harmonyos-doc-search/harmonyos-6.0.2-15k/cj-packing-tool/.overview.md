# cj-packing-tool

This directory serves as a comprehensive technical resource hub for the HarmonyOS application packaging tool, specifically focusing on the `app_packing_tool.jar`. It provides essential documentation and command-line guides tailored for developers and build engineers who require manual packaging capabilities or need to handle complex build scenarios outside the standard DevEco Studio environment. The content covers a wide array of packaging scenarios, including standard HAP and HSP generation, FastApp mode for market distribution, multi-project merging, and version normalization. Key topics include detailed command syntax, parameter definitions, validation rules, and compression logic for both release and debug builds. This collection is ideal for users seeking to automate build processes, manage complex module integrations, or ensure strict version consistency in their deployment pipelines.

## Detailed Description

### 打包工具/ [1]

This directory contains technical documentation and command-line guides for the HarmonyOS application packaging tool (`app_packing_tool.jar`). It covers various packaging scenarios including standard HAP and HSP generation, FastApp mode for market distribution, multi-project merging, and version normalization. Key topics include command syntax, parameter definitions, validation rules, and compression logic for release and debug builds. These resources are designed for developers and build engineers who need to manually package applications, manage complex module integrations, or ensure version consistency outside of the standard DevEco Studio build process.

**Key areas covered in this directory include:**

*   **Packaging Scenarios:** Instructions for generating standard HAP (Harmony Ability Package) and HSP (Harmony Shared Package), as well as specific configurations for FastApp mode intended for market distribution.
*   **Advanced Build Management:** Guides on multi-project merging strategies and version normalization to maintain consistency across complex module integrations.
*   **Technical Specifications:** Detailed breakdowns of command syntax, parameter definitions, and validation rules required for successful execution.
*   **Build Optimization:** Explanations of compression logic applicable to both release and debug builds, helping engineers optimize package size and performance.
