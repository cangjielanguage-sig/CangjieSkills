# 接口介绍

This directory serves as a comprehensive technical resource for developers working with the AssetStoreKit framework, focusing specifically on the API interfaces required for managing critical assets. It provides detailed guidance on asset deletion operations, specifically the `remove` function and its associated `AssetParam` structure, alongside a comprehensive reference table for asset attributes. The documentation covers essential topics such as access control parameters, synchronization settings, persistence options, and custom data labels. It also highlights critical security warnings regarding unencrypted data storage and updates in API12. This content is intended for developers implementing secure asset storage who need to understand data handling constraints, protection levels, and effective configuration of asset properties to ensure application security and data integrity.

### 接口介绍_1.md 接口介绍_1.md
This document serves as a technical reference guide for the API interface used to delete key assets. It primarily details the `remove` function and the structure of the `AssetParam` parameters required for the operation. The key information provided includes a specific security warning: attributes containing "DATA_LABEL" store custom business information without encryption and must not be used for personal data. This documentation is intended for developers integrating asset management features who need to understand parameter definitions and data handling constraints. Keywords: API reference, remove function, AssetParam, data encryption, security warning, asset deletion.

### 接口介绍_2.md 接口介绍_2.md
This document provides a reference table defining attributes for managing critical assets within the AssetStoreKit framework. It details access control parameters, synchronization settings, persistence options, and multiple custom data labels categorized by protection level and sync capability. Key takeaways include the distinction between data labels with and without integrity protection, the expansion of data length limits to 2048 bytes in API12, and options for local-only data storage. Intended for developers implementing secure asset storage, this reference requires understanding of data types like UInt32 and Bool to configure asset properties effectively.
