# modulejson5配置文件

This directory provides comprehensive technical documentation for configuring the `module.json5` file in HarmonyOS and OpenHarmony development. It covers essential aspects of module properties, permissions, device compatibility, UI components, and runtime behaviors. Key topics include ability definitions, extension capabilities, metadata handling, and distribution filtering. This resource is suitable for application developers, system integrators, and software engineers seeking to structure HAP (HarmonyOS Ability Package) manifests, manage application lifecycles, and implement specific features like shortcuts, context menus, and native package integration.

## Detailed Description

### definePermissions标签.md definePermissions标签.md
This reference documentation defines the `definePermissions` tag used for configuring system resource permissions in OpenHarmony HAPs. It details a comprehensive table of attributes, including name, grantMode, availableLevel, and description, specifying data types and default values. The document provides a JSON configuration example and highlights that this tag is exclusive to system resources, explaining permission granting modes and restriction levels. It is intended for system developers managing permission definitions within system resource configuration files.

### deviceTypes标签_2more.md deviceTypes标签_2more.md
This documentation outlines the configuration for `deviceTypes` and `pages` tags within a module's profile. It details supported device type enumerations like tablet and default, and explains how to specify page routing information through a separate profile resource. Key sections include the `pages` tag attributes, specifically the `src` array for page paths and the `window` object for display settings such as `designWidth`. JSON examples illustrate how to structure these configurations for device compatibility and page layout scaling.

### fileContextMenu标签.md fileContextMenu标签.md
This technical reference explains how to configure the `fileContextMenu` tag to register custom right-click menus for HarmonyOS applications on PC and 2-in-1 devices. It covers the JSON profile structure, attribute definitions for menu items, context rules like file types, and response behavior parameters. Key information includes the requirement to define a profile resource, a limit of five menu registrations, and the handling of parameters like `menuHandler` and `uriList` upon activation.

### hnpPackages标签.md hnpPackages标签.md
This document serves as a technical reference for the `hnpPackages` tag, which identifies Native software package information within an application configuration. It details the tag's attributes through a specification table and provides a JSON implementation example. Key takeaways include the mandatory 'package' attribute for naming and the 'type' attribute, which distinguishes between 'public' and 'private' package visibility. It targets developers integrating Native software packages.

### metadata标签.md metadata标签.md
This reference document defines the `metadata` tag used for storing custom metadata within HarmonyOS Ability Package (HAP) configurations. It details the tag's array structure and attributes (name, value, resource), provides specific usage scenarios for window geometry and splash screen removal, and offers a comprehensive JSON configuration example. It explains how to set default window dimensions and toggle starting window visibility, targeting developers configuring application behavior via JSON.

### shortcuts标签.md shortcuts标签.md
This technical reference guide explains how to configure application shortcuts using the `shortcuts` tag within HarmonyOS development. It details the tag structure, including attributes like `shortcutId`, `label`, `icon`, and the nested `wants` object. The document outlines the two-step configuration process: creating a `shortcuts_config.json` file and linking it via metadata in `module.json5`. It includes constraints on ID length and requirements for using `ohos.ability.shortcuts` as the metadata name.

### startWindow标签.md startWindow标签.md
This reference documentation defines the `startWindow` tag, which configures the startup page for UIAbility components via a specific profile file. It details configuration attributes and provides a JSON example for the `start_window.json` file. Available from API version 18, this tag overrides legacy fields and defines properties for icons, illustrations, branding, and background settings, including mandatory background color and optional image fitting modes.

### testRunner标签_4more.md testRunner标签_4more.md
This reference details configuration specifications for four module-level tags: `testRunner`, `dependencies`, `proxyData`, and `appEnvironments`. It provides attribute tables defining data types, constraints, and optionality for each tag, alongside JSON implementation examples. Key topics include setting up test frameworks, declaring shared library dependencies, defining data proxy URIs and permissions, and configuring environment variables for module capabilities and runtime behaviors.
