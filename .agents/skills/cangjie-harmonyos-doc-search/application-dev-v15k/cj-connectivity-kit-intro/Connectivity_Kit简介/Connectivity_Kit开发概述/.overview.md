# Connectivity_Kit开发概述

This directory serves as a comprehensive technical resource for the Connectivity Kit, designed to assist developers in integrating robust wireless communication services into their applications. It provides in-depth coverage of Bluetooth capabilities, detailing specific modules for state management, device pairing, low-energy communication, and high-quality audio streaming. Furthermore, it addresses WLAN connectivity modes—STA, P2P, and AP—alongside NFC card emulation features. The documentation thoroughly explains operating mechanisms, service activation requirements, and user authorization constraints. It is highly suitable for both application and system developers aiming to implement seamless device interaction, IoT connectivity, and wireless data transfer, offering direct links to relevant API references for practical implementation.

## Detailed Description

The following files provide specific technical details and API guidance for the connectivity components mentioned above.

### Connectivity_Kit开发概述_2more.md Connectivity_Kit开发概述_2more.md
This document provides a high-level overview of the Connectivity Kit, specifically focusing on Bluetooth capabilities to help developers integrate communication services into applications. It covers the general introduction to Bluetooth technology and details four specific modules: ACCESS for state management, CONNECTION for device pairing and discovery, BLE for low-energy communication, and A2DP for high-quality audio streaming. Each module description includes its specific function and links to corresponding API references. This guide targets application developers looking to implement wireless features like audio streaming, device pairing, or IoT connectivity, aiming to enhance user experience through seamless device interaction.

### WLAN简介_4more.md WLAN简介_4more.md
This technical guide introduces WLAN and NFC connectivity capabilities for system developers. It covers three WLAN modes: STA (client), P2P (peer-to-peer), and AP (hotspot), alongside NFC card emulation features. The document explains the operating mechanisms, emphasizing that connectivity services require manual activation and user authorization. It serves as a conceptual overview linking to specific API references for implementation. The target audience includes developers building applications requiring wireless communication, who need to understand these modes and constraints to effectively utilize the underlying connectivity kit.
