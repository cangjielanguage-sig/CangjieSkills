This directory contains comprehensive API reference documentation for the `Decl` class and its associated utility methods within the Abstract Syntax Tree (AST) of the Cangjie programming language. It provides a deep dive into the foundational architecture of declaration nodes, detailing how identifiers, keywords, modifiers, annotations, and generic parameters are structured and managed. Additionally, it covers essential functions for AST manipulation, including tree visualization, attribute inspection, token conversion, and node traversal using the Visitor pattern. This documentation is specifically designed for compiler developers, language tool implementers, and software engineers working on static analysis tools who require a granular understanding of Cangjie's internal code representation to build, debug, or optimize language processing systems.
