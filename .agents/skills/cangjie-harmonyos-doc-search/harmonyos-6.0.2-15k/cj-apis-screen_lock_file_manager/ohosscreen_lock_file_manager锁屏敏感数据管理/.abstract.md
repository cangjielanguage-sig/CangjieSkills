This directory contains API documentation for the `ohos.screen_lock_file_manager` module, designed to manage sensitive data access permissions on HarmonyOS devices. It focuses on handling encryption key lifecycles—destroying keys when the screen is locked and restoring them upon unlocking—to ensure data security. The documentation covers the core `ScreenLockFileManager` class, status enums for access requests, and module configuration requirements. It is intended for HarmonyOS developers using the Cangjie language who need to implement secure file access controls and manage permission states in locked-screen scenarios.
