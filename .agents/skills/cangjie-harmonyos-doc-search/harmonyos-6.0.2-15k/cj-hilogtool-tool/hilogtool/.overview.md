# hilogtool

The `hilogtool` directory contains documentation for a specialized utility designed to parse and decode HarmonyOS hilog log files. It covers the tool's usage scenarios, setup instructions, and command-line examples for converting encoded binary log files into readable plaintext. Key topics include environment configuration, data dictionary management, and troubleshooting parsing errors. This resource is suitable for developers and testers working within the HarmonyOS ecosystem who need to analyze offline system logs, debug applications, or share log data in a human-readable format.

## Detailed Description

### 使用场景.md
This technical reference document explains the specific usage scenario for the hilogtool, focusing on the handling of exported hilog log files. The content describes how hilog logs are stored as encoded binary gz files in the device's /data/log/hilog directory, necessitating the use of hilogtool to parse them into readable plaintext. Key takeaways include the distinction between offline hilog files, which require parsing, and kmsg logs or online shell viewing, which do not. This information is intended for developers needing to analyze offline system logs.

### 使用指导.md
This document provides a comprehensive usage guide for the HarmonyOS hilogtool, designed to parse Hilog log files. It details the process of acquiring the tool from the SDK, configuring environment variables on Windows and MacOS, and executing parsing commands. Key sections explain command parameters such as input and output paths, and the critical role of the data dictionary file in ensuring accurate log interpretation. The guide also highlights version requirements for parsing custom-named log files. Intended for developers and technical users, this manual facilitates efficient log analysis and debugging within the HarmonyOS ecosystem.

### 常用解析命令示例_5more.md
This technical guide provides instructions and examples for parsing binary hilog files into readable plaintext using the hilogtool. It covers parsing commands for current, specific, or single files, automation scripts for Windows and Mac, potential impact scenarios, error codes, and troubleshooting common issues. Key takeaways include the necessity of data dictionaries for decoding binary logs, specific commands to trigger dictionary generation when debugging custom binaries, and the meanings of various error codes. Targeted at developers and testers working with system logs, this document facilitates log analysis and sharing by converting binary data into human-readable formats.
