# 基础类型定义

本目录包含仓颉（Cangjie）语言中用于Web组件开发的基础类型定义文档。内容主要涵盖了HTTP头处理、页面加载生命周期事件（如加载开始、结束及拦截）、网页权限请求及资源请求对象等核心数据结构。这些API均属于SystemCapability.Web.Webview.Core系统能力，旨在为开发者提供处理WebView交互、网络请求拦截及权限管理所需的底层支持。适合使用仓颉进行Web应用开发、需要精细控制网页行为和网络请求的开发者查阅。

## 详细描述

### class_Header_4more_19cd5b9f.md class_Header_4more_19cd5b9f.md
这是一份Cangjie语言的API参考文档，旨在定义Web组件中用于处理HTTP头及页面加载事件的类。文档主要涵盖了Header类，用于封装请求/响应头的键值对；以及OnLoadInterceptEvent、OnPageBeginEvent和OnPageEndEvent三个事件类，分别用于处理资源加载拦截、页面加载开始和结束的逻辑。关键信息包括这些类的属性定义（如headerKey、url、data）及其构造函数，所有类均属于SystemCapability.Web.Webview.Core系统能力，起始版本为22。该文档面向使用Cangjie开发Webview应用的开发者，提供了处理网页生命周期和网络请求交互的基础数据结构。

### class_OnPermissionReque_dab0160e.md class_OnPermissionReque_dab0160e.md
本文档是仓颉编程语言中OnPermissionRequestEvent类的API参考文档，旨在定义Web组件接收权限请求时的参数结构。文档主要内容包括类定义、request属性及其类型PermissionRequest，以及用于初始化对象的构造函数init。关键信息指出该类属于SystemCapability.Web.Webview.Core系统能力，起始版本为22，其中request属性为可读写类型，用于执行授权或拒绝操作。该文档面向使用仓颉开发WebView功能的开发者，帮助他们处理网页权限交互逻辑。

### class_PermissionRequest_3ed1bb9d.md class_PermissionRequest_3ed1bb9d.md
本文档是Cangjie语言中PermissionRequest类的API参考文档，旨在帮助开发者处理Web组件中的网页权限请求。文档涵盖了该类的定义及其四个核心成员函数：deny用于拒绝权限，getAccessibleResource和getOrigin用于获取请求的资源列表及网页来源，grant用于授权屏幕捕获等特定操作。该类属于SystemCapability.Web.Webview.Core系统能力，起始版本为22。主要面向使用Cangjie开发Webview应用的开发者，提供了详细的参数说明和返回值类型，以便实现对网页权限的精细化控制。

### class_WebResourceRequest.md class_WebResourceRequest.md
本文档是Cangjie语言WebResourceRequest类的API参考文档，主要定义了Web组件中的资源请求对象。文档涵盖了获取请求头、请求方法、请求URL的函数，以及判断请求是否为主框架、服务端重定向或与手势相关的布尔函数。关键信息包括这些接口均属于SystemCapability.Web.Webview.Core系统能力，起始版本为22。该文档面向使用Cangjie进行Web应用开发的开发者，旨在提供拦截和分析Web资源请求所需的详细属性和方法。
