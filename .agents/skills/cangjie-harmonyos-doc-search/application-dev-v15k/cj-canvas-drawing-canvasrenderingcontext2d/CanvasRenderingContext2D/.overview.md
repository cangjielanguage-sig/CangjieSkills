## Detailed Description

### CanvasRenderingContext2D_2more.md CanvasRenderingContext2D_2more.md
This API documentation explains how to use the CanvasRenderingContext2D interface to perform 2D drawing operations on Canvas components within the Cangjie UIKit framework. The document covers the module import statement and provides a general description of drawing capabilities for objects like rectangles, text, and images. Crucial performance notes highlight that drawing instructions are queued and executed only during the render phase when the component is visible. Developers must avoid frequent calls on invisible components to prevent memory overflow. Additionally, dimensions exceeding 8000px force CPU rendering, significantly degrading performance. This guide targets Cangjie developers needing to implement custom graphics, requiring knowledge of the UIKit framework and rendering lifecycles.

Both components require SystemCapability.ArkUI.ArkUI.Full and are available starting from version 12. This documentation targets developers working with ArkUI 2D graphics who need to manage rendering quality or perform text layout operations.
