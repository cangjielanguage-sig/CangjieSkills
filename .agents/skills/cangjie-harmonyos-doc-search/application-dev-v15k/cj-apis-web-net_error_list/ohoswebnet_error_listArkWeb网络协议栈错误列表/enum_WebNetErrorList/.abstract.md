This directory contains comprehensive documentation for the `WebNetErrorList` enumeration, detailing error codes and status identifiers for web networking operations in the Cangjie language. It covers a wide range of failure scenarios including SSL/TLS protocol errors, certificate validation issues, HTTP/2 and QUIC faults, proxy authentication, DNS resolution, and caching problems. The documentation is intended for software developers and engineers working on networked applications or webview components who need to implement robust error handling and diagnostics.
