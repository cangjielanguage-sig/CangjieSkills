This directory contains API reference documentation for the `HdrStaticMetadata` class within the Cangjie programming language. It focuses on High Dynamic Range (HDR) static metadata, which is crucial for defining and interpreting display characteristics such as color primaries, white point coordinates, and luminance levels. The documentation covers the class constructor, public properties, and specific parameter tables, including units of measurement and valid ranges for normalized color coordinates. It is designed for software developers and engineers working on multimedia image core functionality who need to implement or manage HDR display and content lighting metrics in their applications.
