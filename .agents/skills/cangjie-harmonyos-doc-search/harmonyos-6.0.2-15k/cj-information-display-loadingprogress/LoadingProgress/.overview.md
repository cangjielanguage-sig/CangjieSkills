# LoadingProgress

This directory contains comprehensive documentation for the LoadingProgress component within the ArkUI framework, specifically designed for HarmonyOS application development using the Cangjie language. It covers essential aspects of implementing loading animations, including API references, component properties, and practical code examples. The content details how to initialize the component, customize its appearance, and manage its visibility state. Suitable for Cangjie developers, this resource provides the necessary tools to integrate dynamic loading indicators into user interfaces, ensuring smooth user experiences during data processing or transitions. It addresses both static displays and interactive state management scenarios.

### LoadingProgress_4more.md LoadingProgress_4more.md
This document provides API reference documentation for the LoadingProgress component within the ArkUI framework, designed to display loading animations. The content covers the component description, subcomponents, and the init() constructor method. Key information includes that animations automatically stop when the component is not visible, determined by specific visibility ratios. The component supports all common attributes except text styles and all common events, though developers are advised to set reasonable dimensions to prevent visual issues. This guide targets developers using the Cangjie language who need to implement loading indicators in their applications. Keywords: LoadingProgress, ArkUI, component, animation, API reference, Cangjie, visibility.

### 组件属性.md 组件属性.md
This document provides API reference documentation for configuring component properties in the ArkUI framework using the Cangjie language. It focuses on methods to customize the appearance and behavior of a loading progress component. The main sections cover the color function for setting the progress bar color, enableLoading for toggling animation visibility, and foregroundColor overloads for general foreground styling. Key information includes parameter definitions, default values, and version requirements, specifically noting that enableLoading hides only the animation content, not the component's layout space. This technical reference is intended for developers seeking to implement and style loading indicators in their applications.
