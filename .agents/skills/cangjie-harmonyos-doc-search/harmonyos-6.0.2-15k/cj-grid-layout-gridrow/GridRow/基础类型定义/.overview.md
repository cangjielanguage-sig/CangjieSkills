# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental type definitions essential for configuring responsive grid layouts within the Cangjie ArkUI framework. It details classes for managing breakpoints, grid row sizing options, and gutter configurations, alongside enums for layout direction and reference types. These definitions are critical for building adaptive user interfaces that dynamically adjust to various device screen sizes, ranging from mobile phones to large desktop displays. Suitable for UI developers and system architects working with ArkUI, this documentation provides the necessary structural components to implement flexible, responsive grid systems effectively.

## Detailed Description

### class_BreakPoints_2more.md class_BreakPoints_2more.md
This API reference documentation defines classes for configuring responsive grid layouts in the Cangjie ArkUI framework. It details the BreakPoints class, which constructs grid container breakpoints using a monotonic array of values and a reference type like WindowSize. Additionally, it covers the GridRowColumnOption struct, which sets column counts for six device width categories (xs, sm, md, lg, xl, xxl). Key information includes the mapping of breakpoint ranges to device types and default values. This guide targets UI developers building adaptive interfaces using ArkUI system capabilities.

### class_GridRowSizeOption.md class_GridRowSizeOption.md
This API reference document details the Cangjie class GridRowSizeOption, which configures grid gutter sizes for different device widths. The documentation covers the class definition, six public properties corresponding to device breakpoints (xs, sm, md, lg, xl, xxl), and the class constructor. Key information includes that all properties are of type Length with a default value of 0.vp, allowing developers to specify spacing for screens ranging from minimum to extra-large sizes. Intended for ArkUI developers using API version 12, this guide facilitates the creation of responsive grid layouts.

### class_GutterOption_3more.md class_GutterOption_3more.md
This document serves as API reference documentation for ArkUI grid layout configuration classes and enums in the Cangjie programming language. It covers the GutterOption class with its constructors for defining x and y-axis spacing, the BreakpointsReference enum for selecting window or container references, and the GridRowDirection enum for controlling element arrangement order. Key takeaways include the two initialization methods for GutterOption using Length or GridRowSizeOption, the distinction between WindowSize and ComponentSize references, and specific layout rules for GridRowDirection regarding span, offset, and automatic line wrapping. Targeted at developers using the ArkUI framework in Cangjie, this reference requires knowledge of grid layout systems and is essential for configuring responsive UI components.
