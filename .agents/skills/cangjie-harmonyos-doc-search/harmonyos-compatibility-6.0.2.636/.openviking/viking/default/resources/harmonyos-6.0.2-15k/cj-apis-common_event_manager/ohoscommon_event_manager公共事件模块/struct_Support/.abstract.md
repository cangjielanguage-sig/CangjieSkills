This directory contains API reference documentation for the `Support` struct within the Cangjie programming language. It primarily defines static constant strings used for subscribing to and handling system-wide common events. The content covers a broad range of hardware and system state changes, including Wi-Fi connectivity, Bluetooth states, power management (sleep/hibernate), user account lifecycle, and storage volume events. These resources are essential for developers building system-level applications that require real-time monitoring of device status and inter-process communication capabilities.
