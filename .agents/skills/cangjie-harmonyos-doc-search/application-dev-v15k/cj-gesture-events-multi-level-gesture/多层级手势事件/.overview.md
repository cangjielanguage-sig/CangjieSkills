# 多层级手势事件

This directory focuses on the mechanisms and management of multi-level gesture events within nested component structures, particularly within the Cangjie UI framework. It comprehensively covers the propagation rules, competition logic, and priority handling of touch and gesture events between parent and child elements. Key topics include default event behaviors, bubbling, interception, and custom control strategies for resolving gesture conflicts. This resource is suitable for UI developers and engineers working with complex interface interactions who need precise control over event handling hierarchies and input response logic to ensure smooth user experiences.

### 默认多层级手势事件.md 默认多层级手势事件.md
This technical guide explains the default behavior and propagation rules of touch and gesture events within multi-level component hierarchies. It covers Touch Events (onTouch) as the foundation of gestures and the rules governing Gesture and Event composition and priority. Key information includes that touch events are closed-loop and consistent, allowing simultaneous triggering in parent-child relationships but occlusion in siblings like Stack. For other gestures, only one gesture succeeds at a time by default, with child components taking priority over parents and the first recognized gesture triggering the callback. This is intended for UI developers building interactive interfaces who need to understand event bubbling, interception, and gesture conflict resolution.
