# cj-huks-signing-signature-verification

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language within the HarmonyOS ecosystem, specifically focusing on the critical domain of cryptographic security. It provides in-depth materials for implementing digital signature and verification functionalities, leveraging the robust capabilities of the Universal Keystore Kit (HUKS). The documentation encompasses the complete lifecycle of cryptographic operations, guiding developers through every step from secure key generation to key deletion. By supporting a wide spectrum of cryptographic algorithms—including widely used standards like ECC and RSA, as well as national standards like SM2—the directory ensures high data integrity and regulatory compliance. It is an essential reference for Cangjie developers who need to integrate hardware-backed cryptographic features and secure signing capabilities into their applications, ensuring that their software meets modern security requirements.
