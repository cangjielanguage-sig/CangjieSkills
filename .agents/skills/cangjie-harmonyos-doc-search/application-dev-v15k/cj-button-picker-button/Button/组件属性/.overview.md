# 组件属性

This directory contains API reference documentation for configuring the properties of Button components within the ArkUI framework using the Cangjie language. It covers a comprehensive range of styling and behavioral configurations, including visual emphasis, dimensions, text typography, adaptive font sizing, and interaction states. Developers will find detailed guides on functions like `buttonStyle`, `labelStyle`, `role`, and `shape`, enabling precise customization of button appearance and feedback. This documentation is suitable for software developers and UI engineers working with Cangjie and ArkUI who need to implement responsive and interactive button elements in their applications.
