# class_PubKey

This directory contains comprehensive API reference documentation for the `PubKey` class within the Cangjie CryptoArchitectureKit. It focuses on public key implementations designed for asymmetric cryptographic operations, including encryption and signature verification. The documentation covers essential functionalities such as retrieving specific key parameters, obtaining ASN.1 DER encoded data in various formats, and converting keys to PEM-encoded strings. It includes detailed information on function signatures, return types like `ResultSpec` and `DataBlob`, and error handling via `BusinessException`. This resource is suitable for developers working with cryptographic frameworks in Cangjie who require secure key management and encoding capabilities.
