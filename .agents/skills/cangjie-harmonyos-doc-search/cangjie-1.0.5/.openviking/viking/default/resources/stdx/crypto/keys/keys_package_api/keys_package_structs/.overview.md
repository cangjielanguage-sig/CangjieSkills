# keys_package_structs

本目录包含密钥包结构体的技术文档，主要涉及用于配置加密填充模式的API参考。文档详细阐述了在RSA加密和签名过程中至关重要的两个结构体：`OAEPOption`和`PSSOption`。内容不仅涵盖了这些结构体的定义和初始化方法，还深入说明了其参数配置，包括摘要算法的选择、可选标签的设置以及随机盐长度的限制与异常处理。该文档旨在为开发者提供精确的接口指导，帮助其正确实现安全加密功能。目标读者为具备基础密码学知识、特别是对非对称加密填充方案有理解的后端开发人员或安全工程师。

## 详细说明

### keys_package_structs.md keys_package_structs.md
本文档是密钥包的API参考文档，详细定义了用于配置加密填充模式的两个结构体。主要包含`OAEPOption`和`PSSOption`两个结构体的定义，分别用于OAEP和PSS填充模式，涵盖了它们的初始化方法及参数说明。关键信息包括`OAEPOption`需指定摘要算法和可选标签，`PSSOption`需指定随机盐长度且受长度限制，若长度非法将抛出`CryptoException`异常。面向需要实现RSA加密或签名的开发者，要求具备基础的密码学知识，特别是关于填充方案的理解。
