# cj-avcodec-support-formats

本目录包含一份处于Beta阶段的AVCodec组件支持格式参考文档，旨在全面明确当前版本的多媒体处理能力与技术边界。文档核心内容主要分为两大板块：一是媒体编解码能力，详细罗列了包括H.264、H.265在内的视频格式，以及AAC、MP3、Flac在内的音频格式的软硬解及编码支持情况；二是媒体数据封装与解析，界定了MP4、MKV、FLV等主流容器格式对应的码流类型及具体的封装限制（例如MP3采样率的具体要求）。该文档主要面向音视频开发人员，旨在帮助开发者在项目开发与调试过程中，快速查询和验证特定格式的兼容性，确保多媒体功能的稳定实现。
