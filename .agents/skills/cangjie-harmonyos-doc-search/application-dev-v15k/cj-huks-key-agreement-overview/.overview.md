# cj-huks-key-agreement-overview

This directory serves as a comprehensive technical reference for the key agreement functionalities provided by the HUKS (HarmonyOS Universal Keystore) framework. It focuses on the cryptographic principles that allow two parties to establish a shared secret key securely by exchanging public keys without transmitting private keys over the network. The documentation outlines specific algorithm support, detailing the availability of ECDH, DH, and X25519 algorithms starting from API level 15, with specific notes regarding the exclusion of lightweight devices. This guide is essential for developers and system architects aiming to implement robust secure communication protocols, ensuring they understand the available cryptographic capabilities and platform constraints within the HarmonyOS ecosystem. Keywords include HUKS, Key Agreement, ECDH, DH, X25519, API Level 15, Cryptography, and Asymmetric Keys.
