This directory contains API reference documentation for the `var_buttons` component within the ArkUI framework, specifically focusing on alert dialog initialization and button configuration in the Cangjie programming language. It covers constructors for creating multi-button dialogs, variable definitions for button options, and detailed parameters for styling and interaction behaviors. Key topics include `AlertDialogButtonOptions`, modal states, and background effects. This documentation is suitable for HarmonyOS developers and UI engineers looking to implement interactive, customizable alert popups in their applications using Cangjie.
