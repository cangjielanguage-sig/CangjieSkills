# Badge

This directory contains comprehensive documentation for the Badge component within the ArkUI framework, designed for HarmonyOS application development using the Cangjie programming language. It covers the complete implementation lifecycle, including API references, foundational type definitions, and practical code examples for creating and configuring notification markers. Key topics include `BadgeParams`, styling, positioning, and state-driven visibility. This resource is suitable for developers working on system version 12 or higher who need to integrate status indicators and information reminders into their user interfaces with precision.

## Detailed Description

### Badge_4more.md Badge_4more.md
This document provides API reference documentation for the Badge component, a container used for attaching information reminders to other components within the ArkUI framework. It covers subcomponent support, the component creation method init, and supported common attributes and events. Key information includes that the init function requires a BadgeParams object for numeric values and a child component. The component supports system and custom components, including rendering controls like if/else and ForEach. While it supports most common attributes, text styles are excluded. This technical reference targets developers building UIs with ArkUI using Cangjie syntax, specifically for version 12 and above.

### 示例代码.md 示例代码.md
This document provides Cangjie code examples demonstrating the implementation and configuration of the Badge UI component. It covers two primary scenarios: setting badge content and controlling visibility dynamically. The first example illustrates using BadgeParams to display numeric, string, or dot badges with various styles and positions. The second example demonstrates state-driven visibility, showing how a count of 0 hides the badge while 1 displays it. This guide targets developers using the Cangjie language for HarmonyOS application UI development, focusing on component properties and state management.
