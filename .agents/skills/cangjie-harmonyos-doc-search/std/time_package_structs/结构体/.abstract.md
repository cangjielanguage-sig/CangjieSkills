This directory serves as a comprehensive repository for API reference documentation regarding core data structures within the Cangjie programming language's time package. It focuses specifically on struct types designed for robust time handling and measurement. Key topics include the `DateTime` and `MonoTime` structs, detailing their constructors, properties, operator overloads, and system call support across different operating systems. This resource is suitable for software developers and engineers who require precise time manipulation, scheduling, timestamp management, or performance testing capabilities in their Cangjie applications.
