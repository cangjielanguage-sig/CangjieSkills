# HKDF

本目录包含在HarmonyOS生态系统中实现HKDF（基于HMAC的提取和扩展密钥派生函数）的文档与代码示例，主要使用仓颉（Cangjie）语言和HUKS（通用密钥库套件）。内容涵盖了密钥派生的完整生命周期，包括参数配置、会话管理、密钥生成与销毁以及错误处理机制。核心关键词包括HKDF、HUKS、AES、SHA256、密钥派生、仓颉编程。适用于需要在HarmonyOS应用中实现安全密钥派生功能的开发者。

## 详细说明

### HKDF_1.md HKDF_1.md
该文档旨在演示如何在Cangjie编程环境中利用HKDF算法进行密钥派生操作。文档涵盖了密钥别名定义、生成密钥参数集配置、初始化派生参数集以及完成派生参数集的设置。关键信息包括使用AES算法、SHA256摘要、密钥大小及HUKS存储标志的具体配置，并提供了错误处理和日志记录的辅助函数。这是一个面向开发者的代码教程，适用于熟悉HarmonyOS通用密钥库套件的用户，旨在指导其实现HKDF密钥派生功能。

### HKDF_2.md HKDF_2.md
本文档展示了如何通过HUKS API实现HKDF密钥派生的多阶段会话流程。涵盖了会话初始化、更新和结束的封装函数，以及密钥生成与删除操作，重点展示了异常处理机制和日志记录。核心在于通过testDerive函数串联了密钥生成、派生操作及清理的完整生命周期，并利用throwObject模式进行错误状态管理。适用于需要在HarmonyOS系统中使用HUKS服务进行安全密钥派生的开发者，属于代码示例或API参考文档。
