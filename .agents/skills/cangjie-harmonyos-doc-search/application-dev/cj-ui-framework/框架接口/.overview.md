# 框架接口

This directory contains API reference documentation for the ArkUI framework's internal interfaces and binding mechanisms within the Cangjie language environment. It primarily focuses on the `CustomView` and `RemoteView` base classes, which serve as foundations for UI components, and the `bind` function used for linking `@Builder` decorated functions to custom components. Key concepts include declarative UI definitions, observed properties, and dynamic UI construction for navigation elements. These documents are strictly intended for system framework developers or advanced ArkUI developers working in a Beta environment, as many classes are marked for internal use only.

## Detailed Description

### class_CustomView.md class_CustomView.md
This API reference document outlines the CustomView class, an abstract base class serving as a foundation for UI framework components in the Cangjie language. It details the class inheritance from RemoteView and documents four key member functions: getLocalStorage, build, aboutToBeDeleted, and getUIContext. Crucially, the documentation specifies that the class and most methods are strictly for internal framework use, warning application developers against their usage to prevent unexpected behavior. The build function is the primary exception, serving as the mandatory method for defining declarative UI descriptions in custom components. This reference targets system framework developers rather than general app developers.

### func_bindT1_T2_T3CustomVie_2more.md func_bindT1_T2_T3CustomVie_2more.md
This document serves as API reference material for the ArkUI framework, detailing specific binding mechanisms and base classes. It primarily documents the bind function, which links a Builder decorated function to a custom component object, facilitating the use of observed properties in UI elements like navigation titles and menu items. Additionally, it describes the abstract RemoteView class, a framework-internal base class that requires a build method for declarative UI definitions. Key takeaways include the specific parameters for the bind function and the strict warning that RemoteView is for internal framework use only. The target audience is ArkUI developers working with advanced custom components and navigation features.

### 框架接口_5more.md 框架接口_5more.md
This document serves as API reference for the ArkUI framework, specifically detailing the bind function used to link @Builder decorated functions with custom component objects. It covers three overloaded function signatures supporting zero, one, or two generic ObservedProperty parameters, along with their specific parameters and return types. Key takeaways include the function's role in enabling dynamic UI construction for navigation titles, tab bars, and menu items, requiring the kit.ArkUI module import. Intended for developers using the Cangjie language in a Beta environment, this guide assumes knowledge of custom components and the @Builder paradigm.
