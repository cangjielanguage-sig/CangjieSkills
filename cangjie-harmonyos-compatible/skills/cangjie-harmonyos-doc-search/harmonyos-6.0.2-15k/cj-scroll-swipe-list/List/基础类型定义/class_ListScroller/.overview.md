# class_ListScroller

This directory contains API reference documentation for the `ListScroller` class in the Cangjie language, designed for controlling scrolling behaviors within ArkUI List components. It covers essential functionalities such as managing swipe actions, retrieving item positions and sizes within groups, and programmatically scrolling to specific items. The documentation includes functions for identifying visible list content based on coordinates and handling navigation within `ListItemGroup` structures. Suitable for ArkUI developers, these resources require familiarity with Cangjie syntax and List component architecture to implement precise layout control and interaction logic.

### class_ListScroller_5more.md

### func_getVisibleListContentInfoFloat64_Float64.md
This API reference document details the getVisibleListContentInfo function, which retrieves child component index information based on specific coordinates within a List component. The content covers the function signature, system capabilities, input parameters for x and y coordinates in vp, and the VisibleListContentInfo return type. Key information includes the specific logic for determining return values depending on whether the coordinates intersect a ListItem, a ListItemGroup header or footer, or empty space, defining how index and area fields are populated. Intended for ArkUI developers, this document assists in programmatically identifying list elements for UI interaction and layout management.

### func_scrollToItemInGrou_5e14639b.md

This technical guide is intended for developers using the Cangjie language to implement precise navigation and scrolling behavior in grouped list interfaces.
