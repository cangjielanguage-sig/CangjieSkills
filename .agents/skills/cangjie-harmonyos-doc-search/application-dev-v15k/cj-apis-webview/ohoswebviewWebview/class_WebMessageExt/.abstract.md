This directory contains API reference documentation for the Cangjie class `WebMessageExt`, a core component for handling message events in WebView applications. It covers the data object structure used for sending and receiving messages via WebMessagePort, detailing constructors, getters, and setters for various data types like Array, ArrayBuffer, Boolean, Number, and String. Key features include strict type enforcement and error handling for type mismatches. This documentation is suitable for software developers working on WebView communication who need precise control over message data manipulation and validation.
