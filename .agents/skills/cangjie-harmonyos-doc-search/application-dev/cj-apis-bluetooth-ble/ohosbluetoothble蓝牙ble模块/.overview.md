# ohosbluetoothble蓝牙ble模块

This directory contains API reference documentation for the `ohos.bluetooth.ble` module in the Cangjie programming language, designed for HarmonyOS development. It covers Bluetooth Low Energy (BLE) operations including advertising, scanning, and GATT (Generic Attribute Profile) client and server interactions. Key components include configuration classes for broadcast packets, connection management, and data transmission. The documentation is intended for developers using the ConnectivityKit to implement BLE connectivity features, requiring knowledge of Cangjie syntax and Bluetooth protocols. It details system capabilities, permissions, and specific data structures necessary for building robust BLE applications.
