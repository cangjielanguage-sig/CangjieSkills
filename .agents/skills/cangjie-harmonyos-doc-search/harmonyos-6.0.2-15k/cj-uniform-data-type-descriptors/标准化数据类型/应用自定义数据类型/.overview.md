# 应用自定义数据类型

This directory provides comprehensive technical guidance for HarmonyOS developers on implementing custom data types using the Uniform Type Descriptor (UTD) framework. It addresses scenarios where standard data types are insufficient, enabling seamless cross-device and cross-application data interaction. The content covers both theoretical principles—such as UTD hierarchy validation, registration processes, and configuration constraints—and practical implementation steps. Developers will learn how to define proprietary formats, manage essential fields like TypeId, and ensure compliance with system requirements. This resource is essential for those looking to standardize data formats, extend existing types, or facilitate robust data sharing across the HarmonyOS ecosystem.

## Detailed Description

### 应用自定义数据类型_3more.md 应用自定义数据类型_3more.md
This technical guide explains how applications can declare, register, and share custom data types to bridge gaps where standard data types are insufficient. The document covers the working principles of the Uniform Type Descriptor (UTD), including hierarchy validation and installation processes, and details specific constraints for configuration fields. Key takeaways include that custom types must inherit from existing standard types to avoid circular dependencies. Essential fields like TypeId and BelongingToTypes have strict formatting and existence requirements, while file extensions and descriptions are optional. This reference material is intended for application developers working on cross-device or cross-app data interaction who need to define proprietary data formats.

### 开发步骤.md 开发步骤.md
This technical tutorial guides developers through defining custom Uniform Type Descriptor (UTD) standardized data types within HarmonyOS applications. It covers creating the utd.json5 configuration file, declaring custom types with specific attributes like TypeId and MIME types, and referencing or extending these types in other applications. Key takeaways include the necessity of placing the configuration file in the rawfile/arkdata/utd directory and the distinction between defining new types, referencing existing ones, and creating extensions using DevEco Studio templates. This guide targets HarmonyOS application developers who need to standardize proprietary file formats or share data type definitions across multiple apps.
