This directory contains API reference documentation for the `ActionSheetOptions` class within the Cangjie programming language and ArkUI framework. It focuses on the configuration and customization of list selection popups, modal dialogs, and action sheets. Key topics include setting properties like alignment, background blur, border styles, and handling dismissal callbacks. The documentation covers structural definitions, variable types, and system capabilities starting from API version 19. It is suitable for UI developers and software engineers looking to programmatically control the appearance, behavior, and layout of interactive UI components in their applications.
