# 订阅系统环境变量的变化

This directory provides comprehensive guides for HarmonyOS developers on how to subscribe to system environment variable changes using the Cangjie language and AbilityKit. It covers dynamic adaptation to settings like language, screen orientation, and memory levels. The content details implementation methods across different components, including ApplicationContext, AbilityStage, UIAbility, and ExtensionAbility. By utilizing callbacks such as `onConfigurationUpdate` and `EnvironmentCallback`, developers can ensure their applications respond intelligently to runtime configuration updates without restarting. These resources are essential for application developers seeking to enhance user experience through intelligent UI adaptation and resource management.

## Detailed Description

### 使用ApplicationContext订阅回调.md 使用ApplicationContext订阅回调.md
This tutorial guides developers on using the ApplicationContext class to subscribe to and unsubscribe from system environment variable changes in Cangjie applications. It covers registering callbacks via the on method to monitor changes like system language or memory levels, and deregistering them via the off method to release resources. The document provides complete Cangjie code examples demonstrating the implementation of EnvironmentCallback and the management of callbackId for resource cleanup. This guide is intended for application developers working with the HarmonyOS AbilityKit who need to dynamically respond to system configuration updates.

### 在AbilityStage组件容器中订阅回调_2more.md 在AbilityStage组件容器中订阅回调_2more.md
This guide explains how to subscribe to system environment variable changes within the AbilityStage and UIAbility components to enable dynamic UI adaptation. It details the implementation of the onConfigurationUpdate() callback method for both components. Key information includes that these callbacks are bound to the component's lifecycle and utilize the AbilityConfiguration object to retrieve updated settings like system language without restarting the application. The document provides Cangjie code examples demonstrating language change detection. This technical guide targets HarmonyOS developers using the Cangjie language who need to handle configuration updates in their applications.

### 在ExtensionAbility组件中订阅回调.md 在ExtensionAbility组件中订阅回调.md
This technical guide explains how to subscribe to system environment variable changes within the ExtensionAbility component using the onConfigurationUpdate callback method. It covers the usage of the onConfigurationUpdate method, the AbilityConfiguration object for retrieving updates, and the lifecycle relationship between the callback and the component. The document highlights that the callback exists only while the ExtensionAbility is active and provides a Cangjie code example demonstrating how to override this method in a PhotoEditorExtensionAbility to log configuration changes like language. This guide targets application developers using the AbilityKit framework who need to handle dynamic system configuration updates in their extension components.

### 订阅系统环境变量的变化.md 订阅系统环境变量的变化.md
This technical guide explains how to enable applications to dynamically detect and respond to system environment changes, such as language settings or screen orientation, to enhance user experience. The document details four implementation methods: using ApplicationContext, and subscribing within AbilityStage, UIAbility, and ExtensionAbility component containers. It defines system environment variables as runtime device settings triggered by the "Settings" or "Control Center" and references the AbilityConfiguration API for supported variables. Targeted at application developers, this guide facilitates intelligent UI adaptation and ensures apps react appropriately to system configuration updates.
