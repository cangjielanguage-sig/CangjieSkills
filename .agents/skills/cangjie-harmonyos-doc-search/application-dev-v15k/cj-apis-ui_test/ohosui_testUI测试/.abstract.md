This directory contains comprehensive API reference documentation for the HarmonyOS UI testing framework using the Cangjie programming language. It covers the `ohos.ui_test` module, enabling developers to simulate user interactions, manage window states, and automate UI testing workflows. Key components include initialization, component location, gesture simulation, and event observation. Designed for software developers and QA engineers, these resources support the creation of robust automated test scripts for system version 12, utilizing capabilities like `SystemCapability.Test.UiTest`.
