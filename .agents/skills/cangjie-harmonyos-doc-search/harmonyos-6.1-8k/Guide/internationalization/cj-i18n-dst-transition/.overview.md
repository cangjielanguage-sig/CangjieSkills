# cj-i18n-dst-transition

本目录包含仓颉（Cangjie）系统中关于夏令时（DST）跳变机制的规范文档。内容详细涵盖了夏令时的基本定义、系统层面的自动配置规则，以及应用程序如何通过标准接口同步时间的实现原理。文档的核心重点在于三大处理规则：如何计算夏令时当天可能出现的23小时或25小时时长差异，解决时间跳变导致的空缺与重复现象，以及推荐使用UTC或GMT标准时间进行数据存储与传输以避免信息丢失。该文档主要面向需要进行国际化开发的仓颉开发者，旨在提供处理时间跳变的最佳实践指导与代码示例。
