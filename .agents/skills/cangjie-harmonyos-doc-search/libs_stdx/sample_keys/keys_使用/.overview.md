# keys_使用

This directory serves as a comprehensive resource for developers working with the Cangjie programming language, specifically focusing on the implementation and management of cryptographic keys. It provides practical, code-based tutorials for handling asymmetric encryption algorithms, including the widely used RSA and ECDSA standards, as well as the SM2 algorithm commonly used in Chinese cryptography standards. The content covers the full lifecycle of key management, from generation and serialization (PEM format) to advanced operations like OAEP encryption, PKCS1 signing, and signature verification. These examples are essential for Cangjie developers aiming to secure their applications with robust data protection, integrity verification, and standard-compliant cryptographic practices using the `stdx.crypto.keys` library.

## Detailed Description

### RSA_密钥示例_2more.md RSA_密钥示例_2more.md
This document provides practical code examples for implementing RSA and ECDSA cryptographic operations using the Cangjie programming language. It covers two main topics: RSA key usage for OAEP encryption and decryption, and PKCS1 signing and verification using PEM files, followed by ECDSA key generation and signature validation. Key takeaways include the specific usage of padding modes like OAEP and PKCS1, integration with hash algorithms such as SHA512, and file I/O for key loading. This tutorial serves as a reference guide for Cangjie developers looking to integrate standard cryptographic security features like encryption and digital signatures into their applications.

### SM2_密钥示例.md SM2_密钥示例.md
This document provides a practical code example in the Cangjie language demonstrating the complete lifecycle of SM2 cryptographic keys. The main topics include generating SM2 key pairs, exporting and importing keys via PEM format, performing public key encryption and private key decryption, and implementing digital signatures with verification. Key takeaways involve using the stdx.crypto.keys library to handle SM2PrivateKey and SM2PublicKey objects, managing file I/O for key persistence, and validating cryptographic operations. This tutorial serves developers working with the Cangjie standard library who need to implement secure data transmission and integrity checks using the SM2 algorithm.
