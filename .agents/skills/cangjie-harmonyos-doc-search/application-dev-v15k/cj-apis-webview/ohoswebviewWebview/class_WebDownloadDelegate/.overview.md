# class_WebDownloadDelegate

This directory contains API reference documentation for the `WebDownloadDelegate` class in the Cangjie language, part of the ArkWeb framework. It covers the management of web download task notifications, including initialization, progress updates, completion, and failure handling. Key topics include the class constructor, callback functions like `onBeforeDownload`, `onDownloadUpdated`, `onDownloadFinish`, and `onDownloadFailed`, along with `WebDownloadItem` management. This documentation is suitable for HarmonyOS developers and application engineers working with web view components who need to implement robust file download functionality and error handling in their applications.
