## 详细描述

### 基础概念.md 基础概念.md
本文档阐述了应用框架中焦点管理的基础概念，旨在帮助开发者理解焦点的获取、传递及交互机制。主要内容包括焦点、焦点链与走焦的定义，焦点态的显示与激活规则，层级页面（如Dialog、Page）的焦点特性，以及根容器的默认焦点与传递逻辑。关键信息指出焦点链是根到组件的路径，层级页面具有视觉独立性和走焦范围限制，且焦点传递优先选择上次获焦子节点。这是一份面向UI开发者的概念指南，适用于需要实现键盘导航和无障碍交互的场景。

### 走焦算法.md 走焦算法.md
本文档旨在阐述焦点管理系统中容器组件的走焦算法机制，定义了焦点在按键操作下的转移逻辑。文档主要涵盖线性走焦、投影走焦和自定义走焦三种算法。线性走焦基于节点树挂载顺序，适用于Row等单方向布局；投影走焦基于投影重叠和中心点距离，适用于Wrap Flex布局；自定义走焦则由组件自行定义。关键信息包括各算法对TAB键、方向键及边界处理的具体判定规则。这是一份技术参考文档，面向UI开发人员，帮助其根据UX规格适配正确的焦点策略。关键词：焦点管理、走焦算法、线性走焦、投影走焦。

### 走焦规范.md 走焦规范.md
本文档规范了ArkUI框架下的焦点移动机制，指导开发者管理应用内的焦点行为。内容涵盖主动走焦（如按键、requestFocus、focusOnTouch）与被动走焦（如组件删除、属性变更、页面切换）。核心要点包括TAB键的Z字型循环遍历、方向键的十字型策略、API的跨层级限制，以及被动场景下优先转移至兄弟组件的规则。面向需要优化交互体验的ArkUI开发者。
