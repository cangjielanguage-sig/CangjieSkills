# 使用镜像能力

This directory focuses on the ArkUI framework's mirroring capability, essential for internationalization and bidirectional text support. It covers how to horizontally flip UI content to accommodate Right-to-Left (RTL) reading habits, such as Uyghur or Arabic, alongside standard Left-to-Right (LTR) layouts. Key topics include automatic mirroring triggers, manual Canvas rendering adjustments, and specific usage constraints for various components. This documentation is suitable for ArkUI developers and UI designers aiming to create applications that seamlessly adapt to different system languages and regional display requirements.

## Detailed Description

### 概述_2more.md
This document provides an overview of the ArkUI framework's mirroring capability, designed to accommodate different user reading habits by horizontally flipping display content on the X-axis. The text covers visual comparisons of mirroring effects, specific conditions for activation, and definitions of basic layout concepts. Key information includes that mirroring activates when the component's direction property is set to Direction.Rtl, or when set to Direction.Auto combined with a system language that reads right-to-left (RTL), such as Uyghur. It defines LTR as left-to-right and RTL as right-to-left. This guide targets ArkUI developers implementing internationalization features for applications requiring bidirectional text support.

### 自定义绘制Canvas组件.md
This technical guide addresses the mirroring capabilities of the Canvas component, specifically regarding text rendering in internationalization scenarios. It explains that while Canvas content does not automatically mirror with system language changes, text drawing via CanvasRenderingContext2D supports mirroring through specific direction attributes. The document outlines the priority of these attributes: Context direction takes precedence over Component direction, followed by System language. Key takeaways include the requirement for applications to manually redraw content upon locale changes and the limitation that only symbols, not alphanumeric characters, respond to mirroring. The guide includes a Cangjie code example demonstrating how to subscribe to locale change events to trigger updates. It is intended for developers seeking to implement bidirectional text support in custom Canvas components.
