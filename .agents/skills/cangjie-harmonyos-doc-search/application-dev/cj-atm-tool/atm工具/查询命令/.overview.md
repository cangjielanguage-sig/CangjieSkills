# 查询命令

This directory serves as a specialized repository for technical documentation regarding the `atm dump` command-line tool, which is essential for querying and managing system-level application data. It encompasses detailed guides on retrieving system application processes, checking current permission states, and auditing historical permission usage records. The content explains command syntax, various parameter flags for filtering specific data points like token IDs and bundle names, and how to interpret the resulting JSON output structures. Key functionalities include monitoring process attributes, defining permission usage types, and tracking access to sensitive system resources such as the camera. This documentation is primarily intended for system developers and administrators who need to debug applications, enforce security compliance, and maintain oversight of the operating system's permission management framework.

## Detailed Description

### 查询命令_1.md
This document serves as a technical reference for the atm dump command-line tool, designed to query system application processes and permission states. It details the command syntax and provides a comprehensive parameter table explaining required flags like -t for process information and -v for permission usage types, alongside optional filters such as token ID and bundle name. The document includes practical examples demonstrating how to retrieve specific application details and permission definitions in JSON format. Intended for developers and system administrators, this guide facilitates the debugging and monitoring of application permissions and process attributes within the operating system.

### 查询命令_2.md
This reference document provides command-line instructions for querying system permission usage records using the atm dump tool. It details the base command to retrieve all records and specific flags to filter results by application token ID or permission name. Key information includes the JSON output structure, which displays access counts, timestamps, and status for specific bundles. Intended for system developers or administrators, this guide facilitates auditing application behavior and tracking access to sensitive permissions like ohos.permission.CAMERA.
