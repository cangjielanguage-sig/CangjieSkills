# cj-common-components-richeditor

This directory serves as a comprehensive resource for implementing and customizing the RichEditor component using the Cangjie language within the ArkUI framework. It is designed to assist HarmonyOS developers and application engineers in building sophisticated text editing interfaces with granular control over user input and UI responsiveness. The content covers essential functionalities such as initializing the editor for mixed graphics and text, programmatically inserting text and image spans, and configuring custom selection menus. Additionally, it provides detailed guidance on event handling for content changes and user interactions, offering practical code examples for real-world application scenarios.
