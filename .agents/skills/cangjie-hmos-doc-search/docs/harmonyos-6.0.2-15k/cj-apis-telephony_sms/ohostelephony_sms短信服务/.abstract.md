This directory contains API reference documentation for the `ohos.telephony.sms` module within the HarmonyOS ecosystem, specifically tailored for the Cangjie programming language. It provides comprehensive resources for implementing Short Message Service (SMS) functionality, covering message creation, transmission, and status management. Key topics include defining message options, handling callbacks, enumerating result codes, and checking device capabilities. This documentation is suitable for developers building telephony applications who need to integrate SMS sending, receiving, and protocol handling using Cangjie syntax and HarmonyOS system capabilities.
