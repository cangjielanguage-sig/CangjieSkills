# cj-web-safe-area-insets

This directory serves as a specialized technical resource for managing safe area insets within web environments, specifically tailored for the ArkUI framework and the Cangjie programming language. It addresses the complex challenges developers face when adapting layouts for immersive modes, where system UI elements like status bars and navigation bars can easily obscure critical content. The content covers essential implementation strategies, including the configuration of the `expandSafeArea` attribute, the setup of `viewport-fit` meta tags, and the utilization of CSS `env()` functions for dynamic layout adjustment. This guide is indispensable for developers working with the ArkWeb kernel who need to ensure their applications render correctly on devices with irregular screens, such as those featuring notches, punch-hole cameras, or rounded corners, thereby guaranteeing a consistent and professional user interface.

## Detailed Description

### 网页中安全区域计算和避让适配/

This subdirectory focuses on the technical implementation of safe area calculations and avoidance adaptation for web pages within the ArkUI framework. It addresses a critical challenge in modern UI development: layout conflicts caused by immersive mode and system UI elements, such as status and navigation bars. When an application enters immersive mode, the system bars may disappear or become translucent, but the underlying hardware constraints (like notches) or the reappearance of bars can still interfere with touch targets and content visibility.

The resource provides a deep dive into key topics such as the `expandSafeArea` attribute, which allows developers to specify whether a component should extend into the system window areas. It also covers the `viewport-fit` meta tag, a crucial setting for controlling how the web viewport is laid out relative to the device's safe area. Additionally, the guide explains the use of CSS `env()` functions, which allow developers to reference safe area inset variables (like `safe-area-inset-top`) directly in their stylesheets for precise, pixel-perfect layout adjustments. This resource is particularly suitable for developers using the Cangjie language and ArkWeb kernel who need to ensure content visibility and seamless user experiences on devices with irregular screens or immersive layouts.
