# 扫描工具

This directory serves as a comprehensive resource for the `app_check_tool.jar`, a powerful utility specifically engineered to analyze HAP and App installation packages. The documentation provided herein covers a wide range of functionalities, including the detection of duplicate files, the identification of oversized files that may impact performance, and the statistical analysis of file type size distributions. It offers in-depth technical references regarding command-line parameters, the structure of JSON output reports, and necessary system constraints such as the Java 8 environment requirement. This collection is highly suitable for application developers and QA analysts who are focused on optimizing application architecture, troubleshooting package-related issues, and conducting thorough audits of storage distribution to maintain efficient application performance.

## Detailed Description

The following documents provide specific technical guidance for utilizing the scanning tool effectively.

### 简介_4more.md 简介_4more.md
This document provides a technical reference for the app_check_tool.jar, a utility designed to analyze HAP and App installation packages to help developers optimize structure and troubleshoot issues. Key sections include an introduction to the tool's capabilities, system constraints, and detailed usage examples for scanning duplicate files and identifying oversized files. The guide explains command-line parameters such as --stat-duplicate and --stat-file-size, alongside the structure of the resulting JSON output reports. It requires a Java 8 environment and read/write permissions. Intended for application developers, this documentation facilitates package analysis through duplicate detection and size threshold scanning.

### 统计各类型文件大小占比示例.md 统计各类型文件大小占比示例.md
This document serves as a technical reference for using the app_check_tool.jar to calculate the size proportion of different file types within application packages. It details the command-line usage, specifically the --stat-suffix parameter, and explains the resulting JSON output structure. Key sections include parameter definitions, a JSON response example, and field descriptions for task metadata and file statistics. The tool groups files by suffix (e.g., .so, .abc) to report total and individual sizes. This guide is intended for developers or analysts auditing HAP, HSP, or App packages to understand storage distribution.
