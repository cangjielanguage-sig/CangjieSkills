# 订阅系统环境变量的变化

This directory provides comprehensive technical guides for HarmonyOS developers using the Cangjie language to implement subscriptions for system environment variable changes. It covers how applications can dynamically detect and respond to system settings updates, such as language changes or screen orientation adjustments. The content details implementation methods across different components, including ApplicationContext, AbilityStage, UIAbility, and ExtensionAbility. By utilizing callbacks like `onConfigurationUpdate` and `EnvironmentCallback`, developers can ensure their applications adapt seamlessly to device configuration changes without restarting. This resource is suitable for developers seeking to enhance application reliability and user experience through dynamic configuration handling.

## Detailed Description

### 使用ApplicationContext订阅回调.md 使用ApplicationContext订阅回调.md
This technical tutorial explains how to use the ApplicationContext class in Cangjie to subscribe to system environment variable changes. The document details two primary processes: registering callbacks using the on method to dynamically respond to events like language or memory level updates, and unregistering them using the off method to free resources. Key takeaways include the implementation of the EnvironmentCallback interface and the importance of using the returned callback ID for cleanup. This guide is intended for HarmonyOS developers seeking to enhance application reliability and performance through effective resource management and dynamic configuration handling.

### 在AbilityStage组件容器中订阅回调_2more.md 在AbilityStage组件容器中订阅回调_2more.md
This guide explains how to subscribe to system environment variable changes, such as language updates, within HarmonyOS applications using the Cangjie language. It covers implementing the onConfigurationUpdate() callback method in both AbilityStage and UIAbility components. Developers utilize the AbilityConfiguration object to retrieve the latest configuration without restarting the component. The document provides Cangjie code examples demonstrating how to detect and log language changes, noting that callbacks follow the component's lifecycle. This tutorial targets application developers familiar with the AbilityStage and UIAbility lifecycles who need to implement dynamic UI adaptation based on system settings.

### 在ExtensionAbility组件中订阅回调.md 在ExtensionAbility组件中订阅回调.md
This technical guide explains how to subscribe to system environment variable changes within the ExtensionAbility component. It details the usage of the onConfigurationUpdate() callback method, the lifecycle behavior of the subscription, and provides a practical code example using PhotoEditorExtensionAbility. Key takeaways include that the callback receives an AbilityConfiguration object to access updated settings like language, and the subscription is bound to the component's lifecycle, being destroyed when the component is destroyed. Targeted at HarmonyOS developers using the Cangjie language, this document serves as a tutorial for handling dynamic system configuration updates in extension abilities.
