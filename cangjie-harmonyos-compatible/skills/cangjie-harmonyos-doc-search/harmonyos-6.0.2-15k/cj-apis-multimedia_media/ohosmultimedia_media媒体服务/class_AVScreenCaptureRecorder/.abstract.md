This directory contains API reference documentation for the `AVScreenCaptureRecorder` class within the Cangjie MediaKit. It provides comprehensive technical details for implementing screen recording functionality, covering initialization, event subscription, resource management, and recording control. Key topics include configuring recording parameters, handling state change callbacks, managing microphone input, and privacy settings. This documentation is suitable for software developers building multimedia applications in the Cangjie programming language who need to integrate robust screen capture features with proper error handling and system capability management.
