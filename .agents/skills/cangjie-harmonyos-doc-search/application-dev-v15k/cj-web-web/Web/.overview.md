# Web

This directory provides comprehensive documentation for the Web component in the Cangjie language, designed for HarmonyOS application development. It covers the integration of web content, including API references for component creation, event handling, property configuration, and fundamental data structures. Key topics include `WebviewController` usage, local resource loading, JavaScript interaction, security policies, and lifecycle management. This resource is suitable for Cangjie developers and UI engineers seeking to implement WebView functionality, manage web interactions, and customize display behaviors within their applications.

## Detailed Description

### Web_3more.md
This document serves as API reference documentation for the Web component in the Cangjie language, designed to provide web page display capabilities within applications. The content focuses on component creation, detailing two overloaded init functions: one for loading web pages via String URLs and another for accessing local resources using AppResource. Key information includes the mandatory use of a unique WebviewController for each instance, restrictions on dynamically changing the source address via state variables, and the lack of support for transition animations. This technical guide is intended for HarmonyOS developers using Cangjie who need to integrate web content or local HTML files into their user interfaces.

### 示例代码.md
This document serves as a practical code example demonstrating how to implement a WebView component using the Cangjie programming language for HarmonyOS development. The main topics include constructing a declarative UI layout with Column and Button components, managing state variables, and handling WebView controller interactions. Key information highlights the usage of the WebviewController for refreshing and loading URLs, as well as implementing lifecycle event callbacks like onPageBegin and onPageEnd for logging. This example is intended for developers seeking to understand basic UI structure and web content integration within Cangjie applications.

### 基础类型定义/
This directory contains API reference documentation for fundamental data structures and enumerations used in Cangjie WebView development. It covers classes for handling web events (like downloads, errors, and console logs), resource requests and responses, headers, and configuration enums for caching and mixed content. Key components include event parameter structures for JavaScript interactions and permission management. This documentation is suitable for Cangjie developers building web-based applications who need to implement detailed WebView logic, handle network interactions, and manage user interface events within the SystemCapability.Web.Webview.Core framework.

### 组件事件/
This directory contains API reference documentation for event handling within the Cangjie language and HarmonyOS ArkUI framework, specifically focusing on Web components. It covers a wide range of event callbacks including ad blocking, dialog management, page lifecycle tracking, download handling, and system permission requests. Key topics include `WebviewController` binding, JavaScript interaction, and security protocols for accessing hardware like cameras and microphones. This resource is designed for software developers seeking granular control over web interactions, resource loading, and user permissions in their applications.

### 组件属性/
This directory contains API reference documentation for configuring Web component properties within the Cangjie programming language, specifically targeting the ArkWeb framework. It covers a comprehensive range of settings including security policies, rendering behaviors, font configurations, media handling, and JavaScript interactions. Developers can find detailed instructions on managing database access, scrolling mechanics, layout modes, and user interface customizations. This documentation is suitable for application developers building WebView-based applications on HarmonyOS who require granular control over web content display and system integration.

### 通用属性通用事件/
This directory serves as a comprehensive technical reference for universal attributes and events within a UI framework. It systematically covers essential aspects of component configuration, ranging from layout constraints and visual styling to complex interaction handling and animation effects. The content details lifecycle management, focus control, and diverse input handling mechanisms for mouse, keyboard, and touch interfaces. Designed primarily for developers and UI engineers, this resource provides immediate access to globally applicable properties and event handlers. It enables users to effectively configure components, ensuring robust interactivity, visual consistency, and responsive behavior across application interfaces.
