# 组件属性

This directory serves as a technical resource for developers working with the Cangjie ArkUI framework, specifically focusing on the properties and configuration of the `SymbolGlyph` component. The documentation provides detailed API references for manipulating both static visual attributes—such as font size, color, and weight—and dynamic animation behaviors. It includes specific constraints, default values, and supported data types for various properties. This content is designed for HarmonyOS developers who possess a foundational understanding of ArkUI components and Cangjie syntax, enabling them to create rich, interactive user interfaces with customized symbols and effects.

## Detailed Description

### func_effectStrategySymbolE_7more.md func_effectStrategySymbolE_7more.md
This document serves as an API reference for configuring the appearance and behavior of the SymbolGlyph component within the Cangjie ArkUI framework. It details methods for setting animation strategies, colors, sizes, font weights, and rendering modes. Key information includes that the fontSize function specifically controls icon display size, while fontColor supports multiple data types including Color, UInt32, and AppResource arrays. Notably, the sys.symbol.ohos_lungs icon does not support weight adjustments. Default values are provided for size (16.fp) and rendering strategy (SINGLE). This guide targets developers using the Cangjie language to build user interfaces, requiring knowledge of ArkUI components and basic styling concepts.

### func_symbolEffectSymbolEff_2more.md func_symbolEffectSymbolEff_2more.md
This document provides API reference documentation for two overloaded symbolEffect functions in the Cangjie language, designed to configure animation behaviors for the SymbolGlyph component within the ArkUI framework. The content details two specific function signatures: one controlling animation playback via a boolean state, and another triggering animations based on integer value changes. Key information includes parameter definitions for SymbolEffect strategies, the isActive state flag, and the triggerValue mechanism, alongside system capability requirements and version availability. Intended for HarmonyOS developers, this reference requires knowledge of Cangjie syntax and ArkUI component development to implement dynamic symbol animations effectively.
