This directory serves as a comprehensive guide to the ArkUI framework utilizing the Cangjie declarative development paradigm. It covers the fundamental architecture, core features, and standard conventions necessary for building cross-device user interfaces. Key topics include state management, layout systems, component usage, and the application development lifecycle. Designed for application developers and UI engineers, this documentation provides the essential knowledge required to leverage the high-performance and simplified development capabilities of the Cangjie language for creating robust applications.
