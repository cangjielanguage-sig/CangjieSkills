This directory contains comprehensive API documentation for the `LogValue` interface within the Cangjie programming language, designed to facilitate data serialization for logging purposes. It covers the fundamental interface definition alongside its extensions for a wide range of standard types, including primitive values like `Bool` and `Int64`, as well as complex structures such as `Array`, `HashMap`, and `Duration`. The documents detail the `writeTo` method, which is essential for writing data to a `LogWriter` instance. This resource is primarily suitable for Cangjie developers who are implementing or extending logging capabilities for their applications and need to understand how to serialize both built-in and custom data types effectively. By leveraging these interfaces, developers can ensure their data structures are compatible with logging streams.
