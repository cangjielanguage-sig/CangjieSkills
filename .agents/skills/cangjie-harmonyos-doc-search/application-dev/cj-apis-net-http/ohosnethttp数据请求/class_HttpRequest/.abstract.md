This directory contains API reference documentation for the `HttpRequest` class in the Cangjie programming language, specifically designed for HarmonyOS development using NetworkKit. It covers essential HTTP operations including initiating asynchronous requests, managing streaming responses, handling request lifecycles, and subscribing to events. Key topics include `request`, `requestInStream`, `on`, `once`, `destroy`, and `off` methods, along with comprehensive error handling for `BusinessException` and system capabilities like NetStack. This documentation is suitable for Cangjie developers who need to implement robust network communication, manage data limits, and handle asynchronous callbacks effectively in their applications.
