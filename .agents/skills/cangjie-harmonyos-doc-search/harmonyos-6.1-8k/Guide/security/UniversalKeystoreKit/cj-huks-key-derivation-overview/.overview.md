# cj-huks-key-derivation-overview

本目录提供了关于OpenHarmony HUKS（通用密钥库系统）框架下密钥派生（KDF）功能的全面技术概览。文档深入探讨了密钥派生函数的核心定义，详细阐述了HUKS托管密钥在派生过程中的具体使用限制，并提供了HKDF和PBKDF2主流算法的详细规格参数。内容特别强调了派生操作必须基于HUKS托管的密钥体系，明确禁止直接使用用户口令，同时涵盖了API 15及以上版本支持的输入算法及派生结果密钥类型（包括AES、HMAC、SM4等）。该资料是OpenHarmony开发者在进行安全密钥管理、实现高安全性应用开发时的重要参考指南。

## Detailed Description

### cj-huks-key-derivation-overview.md

本文档旨在介绍HUKS框架下的密钥派生概念及支持的算法规格。主要内容包括密钥派生函数的定义、HUKS托管密钥的使用限制，以及HKDF和PBKDF2算法的详细规格表。关键信息指出，派生必须基于HUKS托管密钥，不支持直接使用用户口令，且使用现有别名会覆盖旧密钥。文档详细列出了API 15及以上版本支持的输入算法及派生结果密钥类型（如AES、HMAC、SM4）。这是一份面向OpenHarmony开发者的技术参考文档，适用于需要利用HUKS进行安全密钥管理的应用开发场景。关键词：HUKS、密钥派生、KDF、HKDF、PBKDF2、OpenHarmony、算法规格。
