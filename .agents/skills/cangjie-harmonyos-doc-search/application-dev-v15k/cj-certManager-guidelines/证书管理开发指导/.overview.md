# 证书管理开发指导

This directory serves as a comprehensive technical resource for developers focusing on certificate management within the HarmonyOS environment. It provides in-depth guidance on the implementation of application private credential management, utilizing tools such as the DeviceCertificateKit and the Cangjie language. The content covers essential security operations, including the installation, retrieval, and uninstallation of credentials, alongside complex cryptographic tasks like signing and verification. It details the integration with the Universal Keystore (HUKS) and supports algorithms such as RSA and ECC. Designed specifically for HarmonyOS application developers, this documentation assists in configuring necessary permissions, managing the credential lifecycle, and ensuring robust data security through SDK API version 12 or higher. It is an essential guide for building secure applications that require rigorous certificate handling and error management.

## Detailed Description

### 开发步骤.md 开发步骤.md
This document serves as a practical tutorial for developers on implementing application private credential management using the DeviceCertificateKit in the Cangjie language. The guide outlines three primary steps: configuring the required ACCESS_CERT_MANAGER permission in the module configuration, importing necessary modules, and executing a complete code workflow. Key technical details include the installation of private credentials, cryptographic signing and verification operations using CMSignatureSpec with PSS padding and SHA256 digest, and the subsequent removal of credentials. The content is designed for HarmonyOS application developers seeking to integrate secure certificate lifecycle management and error handling into their projects.

### 证书管理开发指导_3more.md 证书管理开发指导_3more.md
This development guide instructs developers on managing application certificates and private credentials using SDK API version 12 or higher. It details typical usage scenarios including installation, retrieval, uninstallation, and cryptographic signing or verification of data. The document outlines the supported algorithms, specifically RSA and ECC subsets provided by the Universal Keystore (HUKS). It lists key interfaces for the certificateManager module, covering credential lifecycle management and multi-step signature operations like init, update, and finish. This guide is intended for developers implementing secure data handling and credential storage within their applications.
