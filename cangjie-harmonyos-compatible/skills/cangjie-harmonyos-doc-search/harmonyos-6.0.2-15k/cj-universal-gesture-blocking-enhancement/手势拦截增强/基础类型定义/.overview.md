# 基础类型定义

This directory provides API reference documentation for fundamental type definitions in the Cangjie programming language, specifically within the ArkUI framework. It focuses on the core classes and interfaces required for gesture recognition, event handling, and component interaction management. Key topics include the `EventTargetInfo` class for component metadata, the base `GestureRecognizer` class for managing gesture states, and specialized implementations like `PanGestureRecognizer`. These resources are essential for Cangjie developers building interactive user interfaces who need to programmatically handle touch events, configure gesture recognizers, and manage component states effectively.

## Detailed Description

### class_EventTargetInfo.md class_EventTargetInfo.md
This document provides API reference documentation for the Cangjie `EventTargetInfo` class, which encapsulates information about components associated with gesture recognizers. The main sections cover the class definition and the `getId()` method, detailing its functionality to return the current component's identifier as a String. Key takeaways include the system capability requirements and the specific return type linking to component ID attributes. Intended for ArkUI developers, this reference assists in managing gesture interactions by providing access to component metadata.

### class_GestureRecognizer.md class_GestureRecognizer.md
This document serves as an API reference for the Cangjie `GestureRecognizer` class, detailing the properties and methods used to manage gesture recognition within the ArkUI framework. Main sections include the class constructor and various accessor methods. These cover functions to retrieve event target info, state, tag, type, and validity status, alongside methods to check and set the enabled state of the recognizer. Key information includes the ability to determine if a gesture is built-in or valid, and control whether it triggers application callbacks. All methods require SystemCapability.ArkUI.ArkUI.Full and are available from version 20.

### class_PanGestureRecognizer_3more.md class_PanGestureRecognizer_3more.md
This document serves as API reference documentation for the Cangjie programming language, specifically detailing gesture recognition components within the ArkUI framework. It covers the `PanGestureRecognizer` class for handling drag gestures, the `ScrollableTargetInfo` class for retrieving scrollable container status, and the `GestureRecognizerState` enum defining gesture lifecycle states. Key information includes methods like `getPanGestureOptions` for configuration, and `isBegin` or `isEnd` to check scroll positions, with specific behavior noted for Swiper components. The enum defines states such as Ready, Detecting, and Successful. This reference is intended for developers building user interfaces in Cangjie who need to implement and manage complex touch interactions and gesture logic.
