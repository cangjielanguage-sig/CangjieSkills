This directory contains API reference documentation for the `UIExtensionContentSession` class and related functions within the HarmonyOS AbilityKit framework, specifically for the Cangjie programming language. It covers essential lifecycle management tasks for UI extension components, including loading content, managing window privacy settings, implicitly starting abilities, and terminating sessions with result data. Key topics include `loadContent`, `setWindowPrivacyMode`, `startAbilityByType`, and `terminateSelf`. This documentation is suitable for HarmonyOS developers building UI extension components who need to handle interface rendering, security permissions, and session lifecycle events using Cangjie.
