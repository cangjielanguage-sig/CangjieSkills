# 窗口全屏布局方案

This directory provides comprehensive technical specifications and implementation guides for window fullscreen layouts within HarmonyOS applications. It focuses on how applications manage system avoidance areas, detailing the differences between immersive modes that hide system UI and extended layouts that allow content to flow behind system bars. Key technical concepts include `setWindowLayoutFullScreen`, dynamic avoidance area listeners, and UI padding adjustments. These resources are specifically designed for HarmonyOS developers and UI designers using Cangjie or ArkUI who aim to build distraction-free, responsive interfaces for media consumption or gaming.

## Detailed Description

### 应用扩展布局隐藏避让区.md 应用扩展布局隐藏避让区.md
This technical tutorial guides developers on implementing an immersive full-screen layout by hiding system avoidance areas for applications like games and movies. The document covers three main steps: setting the window layout to full screen using `setWindowLayoutFullScreen()`, hiding specific system bars via `setSpecificSystemBarEnabled()`, and building the UI without avoidance logic. Key takeaways include the specific Cangjie code snippets required to hide the status bar and navigation indicator while allowing them to be recalled by swiping up. This guide is intended for HarmonyOS developers using the Cangjie language to create distraction-free user interfaces.

### 窗口全屏布局方案.md 窗口全屏布局方案.md
This document defines the technical specifications for implementing window fullscreen layouts, specifically focusing on how applications handle system avoidance areas. The content is divided into two primary scenarios: application extended layout with fullscreen display that does not hide avoidance areas, and application extended layout that hides avoidance areas. Key information includes the distinction between immersive modes where system UI is hidden versus modes where content extends behind system bars without obscuring them. This guide is intended for developers and UI designers working on window management systems or application interfaces requiring fullscreen behavior.

### 应用扩展布局全屏显示不隐藏避让区/
This directory provides comprehensive technical guides for implementing immersive full-screen layouts in HarmonyOS applications where content extends into system bars without hiding them. It covers essential techniques for retrieving avoidance area dimensions, registering dynamic listeners for layout changes, and adjusting UI padding to prevent content overlap with status and navigation bars. Key topics include the use of `setWindowLayoutFullScreen`, `getWindowAvoidArea`, and ArkTS `@StorageProp` for state management. These resources are specifically suitable for HarmonyOS developers using Cangjie or ArkUI who need to create responsive, adaptive interfaces that handle complex scenarios like screen rotation, multi-window modes, and dynamic system bar visibility.
