This directory contains comprehensive API documentation for the Marquee component within the ArkUI framework, specifically designed for developers using the Cangjie language. It covers the implementation of scrolling single-line text, detailing component behavior, initialization, and performance constraints. Key topics include event handling for scroll lifecycles, text styling properties, and configuration parameters like play state and direction. This resource is suitable for HarmonyOS developers looking to integrate interactive text animations and manage UI component styling efficiently.
