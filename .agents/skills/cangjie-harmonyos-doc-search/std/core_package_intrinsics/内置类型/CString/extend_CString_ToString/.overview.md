# extend_CString_ToString

This directory contains API documentation for extending the Cangjie `CString` type to implement the `ToString` interface and adding essential string manipulation methods. It covers functions for resource management, lexicographical comparison, suffix/prefix validation, and memory-safe operations like `subCString` and `toString`. Key topics include C interoperability, unsafe memory operations, and null-safety checks. This documentation is suitable for Cangjie developers working with low-level string handling and interfacing with C libraries.

### extend_CString_ToString_4more.md extend_CString_ToString_4more.md
This API documentation details the extension of the Cangjie CString type to implement the ToString interface, adding essential string manipulation methods. The document covers three primary functions: asResource for resource management, compare for lexicographical comparison, and endsWith for suffix validation. Key features include automatic memory release via CStringResource, C-style comparison logic returning Int32, and null-safety checks returning false or throwing exceptions. Targeted at Cangjie developers performing C interoperability, requiring knowledge of unsafe memory operations and resource management.
