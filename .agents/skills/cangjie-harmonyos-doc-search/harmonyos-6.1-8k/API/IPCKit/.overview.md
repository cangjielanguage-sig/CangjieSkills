# IPCKit

IPCKit is a comprehensive documentation suite dedicated to Inter-Process Communication (IPC) and Remote Procedure Calls (RPC) within the HarmonyOS ecosystem, specifically tailored for developers using the Cangjie programming language. This directory aggregates essential resources, including detailed API definitions, implementation guides, and diagnostic references for the `ohos.rpc` module. It is designed to assist system application developers in understanding, building, and debugging robust cross-process communication capabilities. As the content covers Beta features, it is particularly suitable for developers who already possess a basic understanding of RPC concepts and wish to explore the specific implementations and error handling mechanisms provided by the Cangjie language in HarmonyOS.

## Detailed Description

### README_zh/
This directory contains the index documentation for the IPC Kit (Inter-Process Communication Service), specifically designed for developers utilizing the Cangjie language. The core of the documentation encompasses the API interface definitions for the `ohos.rpc` module and references for related RPC error codes, aiming to provide developers with a clear navigation entry point. Currently, all content represents Beta features, making it suitable for system application developers who possess a basic understanding of RPC concepts. Through this documentation, users can quickly grasp the cross-process communication capabilities available in the Cangjie language and consult specific interface details and error handling mechanisms.

### cj-apis-rpc/
This directory serves as a comprehensive resource for the Cangjie RPC APIs, specifically designed for the HarmonyOS operating system. It provides in-depth documentation on implementing Remote Procedure Calls (RPC) and Inter-Process Communication (IPC) using the Cangjie language. Developers can find detailed guides and references to facilitate the integration of communication services within their applications, ensuring they can effectively leverage the system's capabilities for distributed tasks and component interaction.

### cj-errorcode-rpc/
The `cj-errorcode-rpc` directory serves as a specialized repository for documentation regarding RPC (Remote Procedure Call) module error codes. Its primary purpose is to assist developers in the accurate diagnosis and resolution of system runtime faults. By providing a detailed list of error codes, this resource helps developers identify issues quickly and maintain the stability of their IPC implementations, acting as a critical tool for troubleshooting during the development and maintenance phases.
