This directory serves as the definitive source for API reference documentation concerning the `BlockCipher` interface within the Cangjie programming language. It is designed to provide a comprehensive specification of the standard contract that governs block encryption and decryption algorithms, ensuring interoperability and correctness across various cryptographic implementations. The documentation meticulously details the interface's mandatory properties, such as `algorithm` identification and `blockSize` parameters, which are crucial for proper cipher configuration. Additionally, it outlines the required method signatures for data transformation, specifically highlighting two distinct overloads for cryptographic operations: one optimized for ease of use by returning a new byte array, and another designed for high-performance scenarios by writing directly to a provided output buffer and returning the data length. This resource is indispensable for developers who are implementing low-level cryptographic primitives or integrating high-level security libraries, requiring a strong understanding of Cangjie syntax, array handling, and memory management. It is suitable for systems programmers and security engineers looking to build robust, standards-compliant encryption tools.
