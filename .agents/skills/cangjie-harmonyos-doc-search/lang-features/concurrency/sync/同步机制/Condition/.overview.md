# Condition

本目录包含仓颉语言中 Condition 接口的文档及代码示例，重点介绍线程同步机制。内容涵盖 Condition 变量与互斥锁的结合使用、wait/notify 机制、超时处理以及虚假唤醒的应对策略。同时提供了基于生产者-消费者模式的有界队列实现示例。适合需要利用共享变量进行多线程同步、处理并发控制逻辑的仓颉开发者阅读。

## 详细描述

### Condition_1.md

本文档介绍Cangjie语言中用于线程同步的Condition接口，它绑定互斥锁以实现线程阻塞与唤醒。涵盖接口定义、wait/notify机制、超时处理及正确与错误的使用示例（如有界队列）。关键点包括调用wait前必须持有锁、wait会自动释放并重获锁，以及需用循环处理虚假唤醒。适用于需要利用共享变量进行多线程同步的Cangjie开发者。

### Condition_2.md

本文档提供了一个使用 Mutex 和 Condition 变量实现线程安全 BoundedQueue（有界队列）的代码示例，用于管理生产者和消费者之间的并发。内容涵盖类结构、同步原语的初始化，以及处理循环缓冲区逻辑和线程等待/信号的阻塞 put 和 get 方法的实现。代码演示了如何通过互斥锁进行独占访问，并使用条件变量（notFull, notEmpty）高效阻塞线程直到队列状态改变，从而防止数据竞争、丢失或溢出。该参考示例适用于学习并发编程模式的开发者，特别是那些需要实现生产者-消费者逻辑或理解多线程环境中条件变量用法的用户。
