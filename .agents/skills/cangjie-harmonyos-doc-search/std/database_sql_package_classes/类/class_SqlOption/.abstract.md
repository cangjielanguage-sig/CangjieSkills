This directory contains comprehensive API reference documentation for the `SqlOption` class and associated static constants within the Cangjie programming language. It primarily addresses SQL database configuration, detailing standard string constants for connection parameters, operational settings, and security protocols. Key topics include SSL/TLS encryption modes, certificate management, cipher suites, and TLS version specifications. This documentation is designed for software developers and system architects who need to establish secure, robust database connections and fine-tune network security behaviors in their Cangjie applications.
