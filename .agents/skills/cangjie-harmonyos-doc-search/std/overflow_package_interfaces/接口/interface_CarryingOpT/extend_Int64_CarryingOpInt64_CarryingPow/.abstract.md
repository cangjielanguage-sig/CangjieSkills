This directory contains comprehensive API documentation for extending the Int64 type in the Cangjie programming language with specialized carrying arithmetic operations. It focuses on the implementation of the CarryingOp and CarryingPow interfaces, providing a suite of functions—including addition, subtraction, multiplication, division, and power—that handle integer overflow explicitly. Unlike standard arithmetic, these operations utilize a wrapping strategy and return a tuple containing both the calculation result and a boolean flag indicating whether truncation occurred. This resource is essential for Cangjie developers and systems programmers who require precise control over arithmetic behavior and need robust overflow detection mechanisms in low-level mathematical computations.
