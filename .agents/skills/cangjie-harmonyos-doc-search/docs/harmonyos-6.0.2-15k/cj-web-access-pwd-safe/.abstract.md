This directory contains the technical documentation and implementation guidelines for integrating the HarmonyOS system password vault with web-based login forms. It focuses on the ArkWeb component, providing developers with the necessary knowledge to enable secure credential management, including automatic password saving and filling functionalities. The content addresses specific user flows for various device types, such as mobile phones and 2-in-1 tablets, ensuring a consistent experience across the HarmonyOS ecosystem. Furthermore, it details the technical constraints and design patterns required for compatibility, such as adherence to Chromium-based form recognition algorithms. This resource is essential for HarmonyOS application developers and frontend engineers who want to reduce user friction during login processes while maintaining high security standards for H5 pages embedded in native apps.
