This directory serves as a comprehensive technical resource for developers working with the `argopt` package within the Cangjie programming language ecosystem. It focuses specifically on the structural definition of the `ParsedArguments` struct, which is the fundamental component for handling command-line argument parsing in Cangjie applications. The documentation provides a detailed breakdown of the data structure used to encapsulate parsing results, distinguishing between different types of inputs. It covers the `nonOptions` property, designed to store an array of string arguments that are not classified as options, and the `options` property, a read-only map utilized for storing key-value pairs. By defining these collection types—Array and ReadOnlyMap—the guide offers the necessary context for integrating robust command-line logic into software projects. This material is highly suitable for Cangjie developers, API designers, and systems programmers who require a thorough understanding of input handling mechanisms. It ensures that users have the knowledge required to effectively utilize the argopt library for managing command-line inputs, assuming a prerequisite familiarity with Cangjie syntax and standard data structures. Furthermore, this documentation acts as a vital reference point for maintaining code quality and ensuring correct implementation of parsing logic in complex software environments.
