This directory contains API reference documentation for the `Want` class in the Cangjie language, specifically designed for HarmonyOS application development. The documentation covers class definitions, constructors, and key properties such as bundle names, actions, URIs, and parameters. It is suitable for developers looking to configure component interactions, manage system capabilities, and handle data resources effectively within the HarmonyOS framework.
