# digest_package_api

The `digest_package_api` directory provides a comprehensive API reference for the digest package within the Cangjie programming language. It covers essential components for cryptographic operations, including a wide range of hashing and authentication algorithms (such as MD5, SHA family, and SM3), exception handling mechanisms, and core data structures. This documentation is designed for developers implementing security and encryption features, offering detailed guidance on algorithm types, error management, and structural definitions to ensure robust application development.

## Detailed Description

### [1] digest_package_classes
This directory serves as a comprehensive API reference for cryptographic digest classes within the Cangjie programming language. It covers a wide range of hashing and authentication algorithms, including the legacy MD5, the extensive SHA family (SHA-1, SHA-224, SHA-256, SHA-384, SHA-512), and the SM3 algorithm. It provides the necessary definitions and implementations for developers to perform secure data hashing operations.

### [2] digest_package_exceptions
This directory contains API reference documentation regarding exception handling within the digest package, primarily defining the `CryptoException` class used for handling digest and encryption/decryption errors. The documentation details the class's inheritance relationships, constructors, and its application scenarios in cryptographic operations. Core keywords include exception handling, encryption errors, CryptoException, and API reference. This document is mainly intended for programmers using the Cangjie language for security and encryption feature development, helping them catch and handle runtime encryption exceptions to ensure program robustness.

### [3] digest_package_structs
This directory contains API reference documentation for core structures within the digest package, primarily defining the `HashType` structure used to identify hash algorithm categories. The documentation comprehensively covers the static properties of HashType, listing various common digest algorithm types including MD5, SHA1, SHA224, SHA256, SHA384, SHA512, and the SM3 national standard. Furthermore, the document provides an in-depth analysis of the specific functionality of the `toString` method and the usage of equality comparison operators. This document is mainly targeted at developers using the Cangjie language for encryption digest development, aiming to provide specifications for algorithm type identification and comparison.
