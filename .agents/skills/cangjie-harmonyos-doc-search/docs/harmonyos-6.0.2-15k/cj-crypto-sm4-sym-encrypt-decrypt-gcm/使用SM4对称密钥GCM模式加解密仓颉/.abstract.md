This directory provides comprehensive technical tutorials for implementing SM4 symmetric encryption and decryption using GCM mode within the Cangjie programming environment. It covers the complete cryptographic workflow, from generating 128-bit SymKeys to managing Cipher instances with specific parameters like SM4_128|GCM|PKCS7. The guides emphasize critical steps such as handling GcmParamsSpec, processing data through update and doFinal methods, and managing the 16-byte authentication tag for verification. These resources are tailored for Cangjie developers looking to integrate robust cryptographic security using the CryptoArchitectureKit, requiring a foundational understanding of symmetric keys and padding modes.
