This directory contains API documentation for sorting functions within the Cangjie standard library. It covers various implementations of the `sort` and `unstableSort` functions designed for different collection types, including `Array`, `ArrayList`, and `List`. The documentation details sorting mechanisms using the `Comparable` interface, custom comparison functions, and key mapping. It also addresses parameters for stable sorting and descending order, alongside notes on deprecated functions. This resource is suitable for Cangjie developers looking to implement or understand sorting algorithms and collection manipulation in their applications.
