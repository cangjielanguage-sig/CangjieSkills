# 启动UIAbility的指定页面

This directory focuses on the technical implementation of launching specific pages within a UIAbility component in HarmonyOS development. It comprehensively covers the mechanisms for both cold starts, which involve initializing a new instance, and hot starts, which resume an existing instance. Key topics include utilizing the Want object to pass routing parameters, managing lifecycle callbacks such as onCreate, onWindowStageCreate, and onNewWant, and implementing navigation logic via the Router module. This resource is specifically suitable for developers using the Cangjie language and the Stage model who need to manage precise navigation flows between application components.

## Detailed Description

### 概述_2more.md
This document serves as a technical guide explaining how to launch specific pages within a UIAbility component. It covers the distinction between UIAbility cold starts, which require full initialization, and hot starts, which resume existing instances. The text details how a calling UIAbility can specify the target page by configuring custom parameters within the Want object. A Cangjie code example demonstrates adding a "router" parameter to the Want to navigate to a specific page like "FuncA". This information is intended for developers using the stage model who need to implement precise navigation flows between application components.

### 目标UIAbility冷启动.md
This technical guide explains how to handle parameter passing and page loading during the cold start of a target UIAbility in HarmonyOS development. It covers the lifecycle callbacks onCreate and onWindowStageCreate, demonstrating how to receive Want parameters and parse them to determine the target page URL. Key takeaways include extracting routing information from want.parameters and using windowStage.loadContent to render the specific page, illustrated by a Cangjie code example. Intended for application developers using the Cangjie language, this document serves as a practical reference for implementing navigation logic between UIAbility components.

### 目标UIAbility热启动.md
This guide explains how to handle the hot start scenario for a UIAbility component in HarmonyOS development. It details the lifecycle behavior where an existing instance triggers the onNewWant() callback instead of initialization methods like onCreate. The document provides a step-by-step tutorial with Cangjie code examples, demonstrating how to parse Want parameters and use the Router module to navigate to specific pages. Key takeaways include the necessity of implementing navigation logic within onNewWant() and the note that this callback is not used in multiton launch mode. This tutorial is intended for HarmonyOS developers using the Cangjie language to manage inter-application navigation and background-to-foreground transitions.
