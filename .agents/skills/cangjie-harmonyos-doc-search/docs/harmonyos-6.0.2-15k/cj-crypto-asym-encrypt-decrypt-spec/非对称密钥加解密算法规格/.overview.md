# 非对称密钥加解密算法规格

This directory contains technical documentation for asymmetric encryption and decryption algorithms within the Cangjie framework. It covers specifications for various algorithms, including SM2 and RSA, detailing encryption modes, padding schemes, and API compatibility. Key topics include algorithm parameter construction, digest algorithms, and ciphertext format conversion. This resource is suitable for Cangjie developers and security engineers looking to implement secure cryptographic operations, manage key configurations, and understand supported standards like GM/T 0009-2012.

## Detailed Description

### SM2.md SM2.md
This document serves as a technical reference for implementing the SM2 asymmetric encryption algorithm within the Cangjie framework, adhering to the GM/T 0009-2012 standard. It details the construction of string parameters for specifying algorithm specifications, such as "SM2_256|MD5", and lists supported digest algorithms including SM3 and SHA variants. Key information includes the composition of SM2 ciphertext (C1, C2, C3) and new features in API version 12 that allow retrieving digest parameters and converting ciphertext to ASN.1 format (C1C3C2). This guide is intended for Cangjie developers who need to perform cryptographic operations, specifically those handling SM2 encryption, decryption, and data format conversion.

### RSA/
This directory provides comprehensive technical documentation for implementing RSA asymmetric encryption within the Cangjie framework. It covers essential padding schemes such as NoPadding, PKCS1, and PKCS1_OAEP, detailing data length constraints, key type mappings, and specific parameter configurations. The resources also address the management of OAEP parameters, including message digests and mask generation functions. Designed for developers and security engineers, these guides assist in selecting appropriate encryption modes, managing API version 12+ compatibility, and ensuring secure cryptographic configurations.
