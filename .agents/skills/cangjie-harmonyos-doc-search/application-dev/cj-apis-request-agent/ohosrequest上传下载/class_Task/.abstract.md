This directory contains API reference documentation for the `Task` class in the Cangjie programming language, specifically designed for the `SystemCapability.Request.FileTransferAgent`. It covers the management of file upload and download operations, including task creation, lifecycle control (start, pause, resume, stop), and event subscription (progress, completion, headers). Key concepts include task IDs, configuration objects, and asynchronous event handling. This documentation is suitable for Cangjie developers building applications that require robust file transfer logic and programmatic control over network tasks.
