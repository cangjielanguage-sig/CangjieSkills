# 接口

本目录包含Cangjie语言x509包中关于密钥处理的API接口文档。主要涵盖了基础Key接口及其派生接口，包括DHParameters、PrivateKey和PublicKey。这些接口定义了密钥在DER和PEM格式之间的编码与解码操作，支持Diffie-Hellman参数处理及可选密码加密。文档详细说明了函数参数、返回值及异常处理，适用于使用Cangjie进行加密开发、X.509证书处理及密钥数据格式转换的程序员。

## 详细描述

### interface_DHParam_2more_d766ebb5.md
本文档是Cangjie语言的API参考文档，定义了密钥处理相关的接口。核心内容包括基础接口Key及其派生接口DHParameters。Key接口作为公钥和私钥的基类，提供DER和PEM格式的编解码功能。DHParameters接口继承自Key，专门用于Diffie-Hellman密钥参数的处理，支持从DER或PEM流解码及编码为PEM格式。文档详细说明了各函数的参数、返回值及X509Exception异常处理。该文档面向使用Cangjie进行加密开发的程序员，旨在规范密钥数据的格式转换操作。

### interface_PrivateKey.md
本文档是Cangjie语言中PrivateKey接口的API参考文档，主要定义了私钥在DER和PEM格式间的编码与解码操作。文档详细列出了静态方法（如decodeDer、decodeFromPem）和实例方法（如encodeToDer、encodeToPem），重点介绍了支持可选密码参数的加密与解密功能。关键信息包括方法参数、返回值类型（如DerBlob、PemEntry）以及可能抛出的X509Exception异常。该接口继承自Key，旨在为开发者提供处理X.509证书和加密私钥的标准工具。

### interface_PublicKey_5c255953.md
本文档定义了Cangjie语言x509包中PublicKey接口的API规范，主要用于公钥的编码与解码。文档涵盖了接口定义、从DER和PEM格式解码公钥的静态方法，以及将公钥编码为PEM格式的实例方法。核心功能包括decodeDer、decodeFromPem和encodeToPem，详细说明了参数类型、返回值及格式错误时抛出的X509Exception异常。该接口继承自Key父类型。这是一份面向Cangjie开发者的API参考文档，适用于涉及X.509证书处理及加密功能开发的人员。
