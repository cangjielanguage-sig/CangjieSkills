# 接口

This directory provides comprehensive API documentation for essential interfaces within the Cangjie programming language's testing framework. It covers the core components required for property-based and parameterized testing, specifically focusing on data generation, data shrinking, and formatted output. Key interfaces documented here include `DataProvider`, `DataStrategy`, `DataShrinker`, and `PrettyPrintable`, alongside their implementations for standard collections like Array and Range. This resource is designed for developers building or extending test capabilities in Cangjie, offering the necessary technical details to manage test data lifecycle and presentation effectively.

## Detailed Description

### interface_DataProvider_2more.md interface_DataProvider_2more.md
This API documentation defines the DataProvider and DataShrinker interfaces for the Cangjie programming language, serving as core components for the DataStrategy testing framework. The document details the DataProvider interface, which supplies test data via an Iterable return type, and includes implementations for Array and Range types. It also explains the DataShrinker interface, designed to reduce input values during testing to isolate failure causes. Key takeaways include the generic type constraints and the specific behaviors of the provide() and shrink() methods. Intended for developers working on property-based testing, this reference requires knowledge of Cangjie syntax and testing concepts.

### interface_DataStrategy.md interface_DataStrategy.md
This document serves as API reference documentation for the Cangjie DataStrategy interface, designed to define data generation strategies for parameterized testing. It details the interface's core components, including the provider function for data generation, shrinker for data reduction, and the isInfinite property. Additionally, it documents specific implementations of this interface for Array and Range types, outlining how they handle data provision and shrinking. Key information includes the generic type T for data specification and the Configuration parameter used in methods. This technical reference targets developers implementing or utilizing parameterized tests within the Cangjie unittest framework.

### interface_PrettyPrintable_2more.md interface_PrettyPrintable_2more.md
This API reference document defines interfaces for formatted printing and configuration key management within the Cangjie programming language's testing framework. It primarily covers the PrettyPrintable interface, which enables types to output content with color and indentation via a PrettyPrinter, and its implementations for Array and ArrayList. Additionally, it documents the KeyFor interface, used to define custom configuration keys for unit tests with a name property. Key takeaways include the requirement for generic type constraints in extensions and the usage of KeyFor with the @UnitestOption macro. This guide is intended for Cangjie developers implementing custom types or configuring unit test behaviors.
