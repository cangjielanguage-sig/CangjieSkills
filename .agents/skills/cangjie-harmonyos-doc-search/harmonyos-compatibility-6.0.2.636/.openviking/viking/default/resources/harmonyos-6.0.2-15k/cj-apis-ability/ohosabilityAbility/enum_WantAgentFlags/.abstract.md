This directory provides comprehensive API documentation for the `WantAgentFlags` enumeration within the Cangjie programming language environment. It focuses on defining configuration options that dictate the behavior and properties of WantAgent objects. Key topics include flags for managing object lifecycle (such as one-time execution), mutability controls (like updating or canceling presentations), and utility functions for string representation. The documentation is strictly tied to the `SystemCapability.Ability.AbilityRuntime.Core` system capability and targets API version 19 and above. It is primarily suitable for system developers and software engineers working on the ability runtime core who need precise control over WantAgent instantiation, behavior modification, and debugging. Understanding these flags is essential for ensuring that WantAgents behave correctly within the application's lifecycle, particularly regarding how they persist or update when triggered.
