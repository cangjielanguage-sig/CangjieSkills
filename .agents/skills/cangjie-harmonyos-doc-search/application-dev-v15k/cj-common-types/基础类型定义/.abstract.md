This directory contains API reference documentation for fundamental data types and structures used in the ArkUI framework with the Cangjie programming language. It covers a wide range of UI building blocks, including layout classes (Area, Padding, Margin), styling definitions (Color, Fonts, BorderRadiuses), and enumerations for alignment, animation, and interaction behaviors. These definitions are essential for constructing user interfaces, managing component geometry, and handling visual effects. Suitable for HarmonyOS developers and UI engineers using Cangjie to build applications, this documentation provides the necessary structural definitions for system capabilities starting from API version 12.
