This directory defines fundamental data structures and enumerations for image handling within the Cangjie ArkUI framework. It covers error handling classes, color transformation filters, and various image rendering modes. Key components include `CJImageError`, `ColorFilter`, and enums for dynamic range and interpolation. These definitions are essential for developers building HarmonyOS applications who need to manage image loading states, apply visual effects, and configure display properties. The documentation targets software engineers working with the ArkUI framework to ensure robust image processing and UI rendering.
