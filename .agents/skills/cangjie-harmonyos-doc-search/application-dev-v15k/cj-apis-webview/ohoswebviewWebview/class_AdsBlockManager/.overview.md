# class_AdsBlockManager

This directory contains API reference documentation for the `AdsBlockManager` class, designed for Cangjie applications utilizing the SystemCapability.Web.Webview.Core capability. It comprehensively covers the management of ad filtering configurations within Web components, specifically focusing on manipulating AllowedList and DisallowList domain suffixes. Developers can learn how to add, remove, and clear domain rules, as well as set persistent custom ad-blocking rules using EasyList syntax. The documentation highlights the distinction between persistent and non-persistent data storage for different configuration types. This resource is suitable for developers looking to customize web browsing experiences by implementing robust ad filtering logic in their apps.

## Detailed Description

### class_AdsBlockManager_5more.md class_AdsBlockManager_5more.md
This document provides API reference documentation for the AdsBlockManager class, which manages ad filtering configurations for Web components in Cangjie applications. It details static methods for manipulating the AllowedList and DisallowList, specifically adding and clearing domain suffixes to control where ad blocking is active. Key information includes the use of suffix matching for domain rules and the non-persistent nature of the DisallowList. The document targets developers utilizing the SystemCapability.Web.Webview.Core capability to customize web browsing experiences within their apps.

### static_func_removeAdsBlock_3more.md static_func_removeAdsBlock_3more.md
This API reference document details static functions for managing ad-blocking configurations within the Web component using the Cangjie language. It covers three main functions: removing domains from the AllowedList, removing domains from the DisallowedList, and setting custom ad-blocking rules via a file. Key information includes that list modifications are non-persistent and require re-setting after app restart, whereas custom rules set via setAdsBlockRules are persistent. All functions support EasyList syntax and throw parameter errors (code 401) for invalid inputs. This guide targets developers implementing ad filtering in web applications, requiring knowledge of file paths and domain management.
