# cj-universal-gesture-tapgesture

This directory serves as the central repository for documentation regarding the `cj-universal-gesture-tapgesture` module, a specialized library component for the Cangjie programming language. It is specifically designed to facilitate the development of rich, interactive user interfaces within the ArkUI framework by providing robust tools for gesture recognition. The documentation primarily focuses on the `TapGesture` component, which is essential for detecting and processing a wide variety of touch-based inputs, including single taps, double taps, and multi-finger gestures. It provides detailed guidance on configuring gesture parameters, such as the number of fingers and tap counts, as well as managing event responses through the `onAction` handler. Furthermore, it outlines critical technical constraints, such as the 300ms timeout for multi-tap recognition and the 60vp distance limit, which are necessary to ensure a consistent and intuitive user experience. This directory is an invaluable resource for software developers, UI engineers, and system architects working with Cangjie who need to implement precise, high-performance touch interactions in their applications.

## Detailed Description

### cj-universal-gesture-tapgesture.md
This document provides API reference documentation for the TapGesture component in the Cangjie language, designed to recognize single, double, and multi-finger tap events within the ArkUI framework. It details the component creation via the init function, specifying parameters for tap count and finger number, and the onAction event handler for successful recognition. Key parameters include count and fingers, with specific constraints like a 300ms timeout for multi-taps and a 60vp distance limit. The document includes a code example demonstrating priority and parallel gesture handling. This reference guide targets developers building UI applications using Cangjie and ArkUI who need to implement touch interactions.
