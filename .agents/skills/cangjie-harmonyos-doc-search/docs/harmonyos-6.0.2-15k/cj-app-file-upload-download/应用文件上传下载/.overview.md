# 应用文件上传下载

This directory provides a comprehensive technical guide for HarmonyOS developers focusing on the implementation of file transfer functionalities within applications. It covers the essential workflows for downloading network resources to local directories and uploading local application files to remote servers. Key technical areas include the integration of the `ohos.request` module for transfer tasks, `ohos.file_fs` for file system access, and the configuration of necessary permissions like `ohos.permission.INTERNET`. The documentation highlights specific constraints, such as the limitation of downloads to app directories and uploads to cache directories. Featuring detailed Cangjie code examples for task configuration, callback management, and proxy settings, this resource is tailored for developers seeking to build robust network file transfer features in their HarmonyOS projects.
