This directory provides a comprehensive guide to implementing data persistence using relational databases within the Cangjie framework on HarmonyOS. It focuses on the SQLite-based RdbStore component, designed to help developers manage complex data relationships efficiently. The content covers essential concepts such as predicates, result sets, and system constraints, alongside practical implementation steps for CRUD operations, version management, and database backup. It is specifically tailored for application developers utilizing the ArkData kit who need robust local storage solutions with SQL capabilities. By following these resources, developers can learn to initialize databases, handle data evolution, and optimize performance for large datasets.
