This directory contains comprehensive API reference documentation for the Cangjie `BatteryInfo` class, a crucial component of the PowerManager system capability. It is designed to assist developers in retrieving and monitoring a wide array of device battery metrics. The documentation covers read-only static properties that provide real-time access to data such as battery state of charge (SOC), temperature, charging status, health status, capacity levels, and current flow. Furthermore, it includes details on hardware-specific attributes like the plugged charger type, battery technology model, and voltage levels. This resource is suitable for Cangjie developers aiming to build system utilities or applications that require precise power management, battery health monitoring, and energy consumption tracking. By utilizing these APIs, developers can create responsive applications that adapt to the device's power state.
