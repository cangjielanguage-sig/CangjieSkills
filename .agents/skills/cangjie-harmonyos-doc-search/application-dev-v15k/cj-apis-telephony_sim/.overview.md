# cj-apis-telephony_sim

This directory serves as a comprehensive resource for the `cj-apis-telephony_sim` module, specifically tailored for the Cangjie programming language and the TelephonyKit framework. It provides essential API reference documentation focused on the robust management and querying of SIM card information within the system. The content covers a wide range of functionalities, including detailed data definitions, account management, and operational classes necessary for telecommunication applications. Developers will find critical information regarding enumerations for card types and states, the `IccAccountInfo` class for accessing card properties, and the `TelephonySim` class for executing core telephony functions. This documentation is indispensable for developers aiming to build applications that require deep integration with SIM status, operator details, and network configurations, ensuring compliance with system permissions and API version 19 standards. It is suitable for systems programmers and application developers working on Cangjie-based telephony solutions.

## Detailed Description

### ohostelephony_simSIM卡管理/
This directory provides comprehensive API reference documentation for the `ohos.telephony_sim` module, designed for the Cangjie programming language and TelephonyKit. It focuses on the management and querying of SIM card information, covering data definitions, account details, and operational classes.

Key components include enumerations for card types and states, the `IccAccountInfo` class for reading card properties, and the `TelephonySim` class for executing telephony functions. This documentation is essential for developers building applications that require access to SIM status, operator details, and network configurations, adhering to system permissions and API version 19 requirements.

Within this module, developers will find detailed descriptions of the data structures used to represent SIM card states and types. The `IccAccountInfo` class is particularly important for retrieving detailed account properties, while the `TelephonySim` class serves as the primary interface for executing telephony-related commands. The documentation emphasizes the importance of adhering to specific system permissions to access sensitive telephony data and outlines the requirements for API version 19. This ensures that applications are built with security and compatibility in mind, providing a reliable user experience for telephony features.
