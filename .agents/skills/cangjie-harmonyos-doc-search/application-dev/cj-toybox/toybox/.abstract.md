This directory contains comprehensive documentation for Toybox, a lightweight, consolidated Linux command-line utility collection designed to replace standard Linux commands within a single executable. It covers the tool's definition, Beta status, and specific usage prerequisites such as accessing the command line via hdc shell on a connected device or running within an application sandbox. The documentation also addresses troubleshooting common errors within the OpenHarmony environment, including permission issues and SELinux blocks. Furthermore, it provides a technical reference for system monitoring, process management, and network configuration. This resource is suitable for developers, system administrators, and embedded engineers working with OpenHarmony or Unix-like environments who need efficient command-line tools and debugging guides.
