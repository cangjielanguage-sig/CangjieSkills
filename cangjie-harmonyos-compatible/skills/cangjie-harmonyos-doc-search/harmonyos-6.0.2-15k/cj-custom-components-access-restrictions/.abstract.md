This directory serves as a comprehensive technical repository dedicated to elucidating the usage restrictions for access qualifiers on member properties within Cangjie custom components. It is an essential guide for navigating the complexities of state management, focusing specifically on the critical rules that dictate how decorators such as @State, @Prop, @Link, and @StorageLink interact with initialization protocols and access modifiers. The documentation provides a detailed overview of validation rules designed to prevent compiler errors, which is fundamental for ensuring proper data flow and synchronization between parent and child components. This resource is highly suitable for Cangjie developers and HarmonyOS application builders who are tasked with defining valid component interfaces, maintaining strict code integrity, and mastering the syntactic constraints of UI state management. By thoroughly understanding these restrictions, developers can avoid common pitfalls and ensure the development of a robust, error-free application architecture.
