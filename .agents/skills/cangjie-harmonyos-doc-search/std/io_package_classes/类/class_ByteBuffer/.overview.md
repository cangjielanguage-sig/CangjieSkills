# class_ByteBuffer

This directory contains comprehensive API reference documentation for the `ByteBuffer` class within the Cangjie standard library. It covers the implementation of IOStream and Seekable interfaces for efficient in-memory byte stream manipulation. Key topics include buffer initialization, capacity management, data reading and writing operations, and cursor positioning. The documentation details methods for handling byte arrays, managing buffer growth, and exception handling. It is suitable for Cangjie developers looking to perform low-level I/O operations, manage memory buffers, and manipulate byte data streams effectively in their applications.
