## Detailed Description

### crypto_package_overview.md crypto_package_overview.md
本文档概述了 stdx.crypto.crypto 包，主要介绍其提供的安全随机数生成和国密 SM4 对称加解密功能。文档包含功能介绍、OpenSSL 3 依赖安装指南（涵盖 Linux、Windows 和 macOS 系统配置及环境变量设置），以及 API 列表（涵盖类、结构体和异常类）。关键信息指出使用该包必须安装 OpenSSL 3 动态库，并详细说明了不同系统下的库文件路径及环境变量配置方法。核心组件包括 SecureRandom 类和 SM4 类，以及相关的工作模式和填充模式结构体。面向需要集成加密功能的开发人员，要求用户具备系统环境配置和外部库依赖管理的基础知识。
