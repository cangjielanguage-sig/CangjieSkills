# enum_ColorSpace

本目录包含关于图形色彩空间（ColorSpace）的API参考文档，主要面向使用Cangjie语言进行图形开发的开发人员。文档详细定义了系统支持的各种色彩空间常量（如DisplayP3、Srgb、Bt2020等），涵盖了RGB色域类型、转换函数（HLG、PQ、Linear）及编码范围（Full、Limit）等核心概念。此外，还提供了色彩空间枚举的比较运算符和字符串转换方法。这些内容属于SystemCapability.Graphic.Graphic2D.ColorManager.Core系统能力，适用于需要进行底层图形处理、色彩配置及颜色管理的场景。

### func_ColorSpace_3more_4b2acbd1.md func_ColorSpace_3more_4b2acbd1.md
本文档提供了Cangjie语言中ColorSpace枚举类型的API参考，详细说明了其比较运算符和字符串转换功能。主要涵盖三个函数：不等比较运算符`!=`、相等比较运算符`==`以及将枚举值转换为字符串的`toString()`方法。每个部分均包含语法声明、功能描述、参数说明及返回值定义。关键信息包括这些函数均属于图形2D颜色管理核心能力，起始版本为22。`!=`和`==`用于比较两个色域类型是否相等，`toString()`则返回对应的字符串表示。文档面向使用ArkGraphics2D工具包的Cangjie开发者，适用于需要进行色域类型比较或字符串转换的图形开发场景。
