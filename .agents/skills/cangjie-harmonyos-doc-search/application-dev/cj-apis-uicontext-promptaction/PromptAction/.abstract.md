This directory contains API reference documentation for the PromptAction module within the ArkUI framework, specifically designed for the Cangjie programming language. It comprehensively covers the implementation of interactive UI components such as dialog boxes, action menus, toast messages, and custom popups. The documentation details classes for configuring options, enumerations for display modes, and methods for managing system-level prompts. Intended for HarmonyOS developers using Cangjie, this resource provides the necessary technical specifications to create responsive user interfaces, handle asynchronous callbacks, and manage visual styling for feedback mechanisms starting from API version 22.
