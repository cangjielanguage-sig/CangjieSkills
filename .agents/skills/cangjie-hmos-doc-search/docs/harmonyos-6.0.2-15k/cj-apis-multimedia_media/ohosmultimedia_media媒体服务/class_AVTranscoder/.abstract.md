This directory contains API reference documentation for the `AVTranscoder` class in the Cangjie programming language, designed for managing video transcoding operations within the HarmonyOS MediaKit. It covers the complete lifecycle of transcoding tasks, including configuration, execution, state management (pause, resume, cancel), and resource release. The documentation details essential properties like file descriptors for input/output and provides comprehensive error handling and callback mechanisms for progress, completion, and error events. This resource is suitable for multimedia developers and software engineers building applications that require video processing capabilities on the HarmonyOS platform.
