This directory serves as the central repository for API reference documentation regarding the HarmonyOS Universal KeyStore (HUKS) system, specifically tailored for the Cangjie programming language. It provides a comprehensive suite of resources designed to facilitate the management of hardware-backed cryptographic keys. The content covers critical security operations including key generation, secure storage, import, export, and complex cryptographic tasks such as encryption, decryption, and digital signing. Furthermore, it details essential classes for configuring parameters like algorithms, padding modes, and digests, alongside data structures for options and results. This documentation is primarily intended for HarmonyOS developers and security engineers who are building secure applications requiring robust key management and cryptographic capabilities within the OpenHarmony ecosystem.
