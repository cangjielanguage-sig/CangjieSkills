### 使用SM4对称密钥GCM模式加解密仓颉

This directory provides comprehensive technical documentation for implementing SM4 symmetric encryption and decryption using the GCM (Galois/Counter Mode) within the Cangjie programming environment. It specifically addresses the SM4_128 algorithm with PKCS7 padding, detailing the complete lifecycle of cryptographic operations from key generation to data processing and authentication tag management. The guides cover essential APIs such as `createSymKeyGenerator`, `createCipher`, and `GcmParamsSpec`. These resources are tailored for Cangjie developers looking to secure their applications with robust encryption standards, requiring prior knowledge of the CryptoArchitectureKit and fundamental cryptographic concepts. By following these tutorials, developers can ensure data integrity and confidentiality in their software solutions.
