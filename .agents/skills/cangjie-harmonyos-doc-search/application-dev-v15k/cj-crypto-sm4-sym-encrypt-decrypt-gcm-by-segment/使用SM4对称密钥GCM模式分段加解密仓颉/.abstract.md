This directory focuses on implementing segmented encryption and decryption using the SM4 symmetric key algorithm in GCM mode within the Cangjie programming language. It covers the complete cryptographic workflow, including key generation, initialization vector (IV) handling, chunked data processing via the `update` method, and finalization with `doFinal`. Key topics include the `CryptoArchitectureKit` API, PKCS7 padding, and authentication tag management. This resource is suitable for Cangjie developers looking to integrate secure, efficient cryptographic operations into their applications.
