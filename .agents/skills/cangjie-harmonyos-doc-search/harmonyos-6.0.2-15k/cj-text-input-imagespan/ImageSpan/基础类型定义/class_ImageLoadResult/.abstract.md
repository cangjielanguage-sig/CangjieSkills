This directory contains API reference documentation for the `ImageLoadResult` class within the Cangjie language and ArkUI framework. It comprehensively covers the encapsulation of image loading metrics, status information, and dimensional data required for rendering. Key topics include the constructor signature, public properties for image and component dimensions, and the specific logic behind the `loadingStatus` property, which distinguishes between data loading and successful decoding states. This documentation is suitable for developers implementing image handling logic, managing layout calculations, or debugging rendering issues in ArkUI applications who need precise access to image data and status codes.
