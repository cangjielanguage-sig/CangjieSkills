This directory serves as a technical guide for developers using the Cangjie ArkUI framework, specifically focusing on the constraints and validation rules governing state management. It details the compatibility requirements between various access modifiers (such as `private` and `public`) and state management macros (including `@State`, `@Link`, `@StorageLink`, and others). By providing comparative code examples that highlight common compiler errors versus correct syntax, these documents help developers navigate access control restrictions. This resource is essential for Cangjie developers aiming to implement robust state management in their ArkUI applications while avoiding syntax pitfalls.
