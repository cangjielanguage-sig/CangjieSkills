## Detailed Description

### 设置参考边界.md 设置参考边界
This document serves as a reference guide explaining how to set reference boundaries for aligning a component's edges to an anchor point within a container. The content is divided into horizontal and vertical alignment sections. In the horizontal direction, users can align using left, middle, or right boundaries, though only left and middle settings are effective if all three are set. Vertically, alignment options include top, center, and bottom, with a similar constraint where only top and center apply when all three are defined. This information is crucial for developers and designers implementing relative layouts, ensuring precise component positioning. Keywords include reference boundary, anchor point, horizontal alignment, vertical alignment, and relative layout.

### 设置相对于锚点的对齐位置_2more.md 设置相对于锚点的对齐位置_2more
This guide explains how to configure component alignment relative to anchor points within a RelativeContainer using the ArkUI framework and Cangjie language. It covers horizontal and vertical alignment rules, specifically HorizontalAlign and VerticalAlign options, and details sub-component position offsetting using the offset property. The document highlights that alignment is set via alignRules, and while offset adjusts position, anchor alignment relies on the pre-offset position. A comprehensive code example demonstrates complex layout construction using these rules. This tutorial targets developers using ArkUI and Cangjie who need to create precise, relative layouts.

### 设置锚点/
This directory provides a comprehensive guide to configuring anchor points within the RelativeContainer component for ArkUI development. It explains the mechanisms for positioning child elements relative to parent containers and sibling elements, emphasizing the necessity of unique component IDs and specific alignment rules. The content includes both theoretical explanations and practical code examples in Cangjie and ArkTS, covering critical topics such as the default parent identifier, avoiding circular dependencies, and chaining elements for complex layouts. Suitable for UI developers and HarmonyOS application engineers, these resources are essential for mastering flexible, constraint-based layout design.
