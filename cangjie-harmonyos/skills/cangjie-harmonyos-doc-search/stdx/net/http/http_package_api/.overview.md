# http_package_api

This directory serves as the central API documentation hub for the Cangjie language's HTTP package. It encompasses a wide range of networking components, including core classes, enumerations, exception handling mechanisms, utility functions, interfaces, and data structures. The documentation is designed to assist developers in building robust HTTP clients, servers, and WebSocket applications. It provides detailed references for protocol negotiation, error management, and connection upgrades, making it an essential resource for engineers engaged in network programming within the Cangjie ecosystem.

## Detailed Description

### http_package_classes
This directory serves as the central repository for documentation regarding the core class definitions within the Cangjie language's HTTP package. It provides a comprehensive overview of essential networking components, including HTTP clients, servers, and other fundamental objects required for network communication.

### http_package_enums
This directory is the API reference documentation for core enumeration types in the Cangjie language HTTP package. It details the basic data structures needed for handling file transfers, HTTP protocol negotiation, and WebSocket communication in network programming. The documentation focuses on three core enumerations: `FileHandlerType` (for configuring file upload or download modes), `Protocol` (defining HTTP 1.0/1.1/2.0 versions), and `WebSocketFrameType` (describing text, binary, and control frames). These enumerations inherit from `Equatable` and `ToString` interfaces to facilitate consistent behavior across the package.

### http_package_exceptions
This directory contains definitions and documentation for exception handling in the Cangjie language HTTP package, aiming to provide comprehensive error management mechanisms for network programming. Content covers connection exceptions, timeout exceptions, HTTP status code exceptions, and WebSocket exceptions. The documentation details six core exception classes, including ConnectionException and HttpTimeoutException, all inheriting from the standard exception base class. This resource is suitable for engineers using the Cangjie language for HTTP network request development, serving as an API reference manual to help developers accurately capture and handle specific errors in network communication, improving program robustness.

### http_package_funcs
This directory is a collection of API reference documents for the Cangjie language HTTP package, focusing on convenient functions for defining and processing HTTP requests, responses, and protocol upgrades. The documentation details three core functions: `handleError` for replying with specific error codes, `notFound` for specifically handling 404 responses, and `upgrade` for supporting protocol upgrades and CONNECT requests. Notably, the `upgrade` function provides the ability to send response headers and return a `StreamingSocket` for underlying read/write operations. This document is primarily for developers using Cangjie for network programming, aiming to provide standard interfaces for handling HTTP contexts and connection management.
