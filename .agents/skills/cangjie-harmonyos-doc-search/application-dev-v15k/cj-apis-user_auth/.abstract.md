This directory provides comprehensive API reference documentation for the `cj-apis-user_auth` module, specifically tailored for the Cangjie programming language within the OpenHarmony (OHOS) ecosystem. It focuses on the critical domain of user identity verification and access management, offering developers the necessary tools to implement secure and robust authentication flows. The documentation covers a wide array of features, including biometric authentication methods such as Face and Fingerprint recognition, traditional PIN codes, and device unlocking mechanisms. Key components detailed in this module include authentication parameters, result handling, trust levels, and UI customization options. This resource is essential for developers building secure applications that require reliable credential state management and identity verification capabilities, leveraging the SystemCapability.UserIAM.UserAuth.Core capability to ensure high security standards.
