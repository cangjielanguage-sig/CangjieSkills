# cj-quick-start-first-cangjie-hybrid-module

This directory serves as a comprehensive quick start guide for HarmonyOS developers aiming to integrate the Cangjie programming language into existing ArkTS projects. It focuses on hybrid module development, enabling the incremental adoption of Cangjie features without the need to rewrite the entire application codebase. The content covers essential mixed-language programming scenarios, such as invoking Cangjie interfaces (both synchronous and asynchronous) directly from ArkTS, embedding Cangjie-based UI components, and managing cross-module navigation. Additionally, it addresses technical configuration details for HAP and HAR modules, supports SDK API versions 12 through 15, and explains interoperability mechanisms like `@Interop`. This resource is specifically tailored for developers using DevEco Studio who seek to enhance their applications with Cangjie capabilities efficiently and effectively, ensuring a smooth development experience.
