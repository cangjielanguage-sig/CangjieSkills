# cj-sensor-guidelines

This directory provides a comprehensive set of guidelines for developers integrating hardware sensors using the Cangjie programming language. It covers the entire spectrum of sensor development, ranging from high-level architectural concepts to specific implementation details. Key topics include understanding core sensor interfaces (`on`, `once`, `off`, `getSensorList`), handling application scenarios like orientation tracking and step counting, and managing technical constraints such as permissions and sampling periods. The resource features a practical tutorial focused on the accelerometer to illustrate the development lifecycle. It is tailored for application developers who need a reliable reference for embedding sensor capabilities into their Cangjie software projects.

## Detailed Description

### 传感器开发指导仓颉/

This directory serves as a comprehensive resource for developers working on sensor integration using the Cangjie programming language. It provides a structured approach to understanding and utilizing device hardware sensors, covering everything from high-level architectural concepts to granular implementation details. The content includes an exploration of application scenarios such as orientation tracking and step counting, alongside a detailed breakdown of core sensor interfaces like `on`, `once`, `off`, and `getSensorList`. Furthermore, it offers a practical, step-by-step tutorial for the development lifecycle, emphasizing the accelerometer as a case study. Key technical considerations such as permission verification, sampling period configuration, and the trade-off between sampling frequency and power consumption are addressed. This guide is primarily intended for application developers who require a reliable reference for embedding sensor capabilities into their software projects using Cangjie.
