This directory serves as a comprehensive technical reference for understanding and implementing Explicit and Implicit Want matching rules within the HarmonyOS/OpenHarmony ecosystem. It covers the fundamental principles used to launch target application components, detailing how specific parameters align with configuration files like `module.json5`. Key topics include the mandatory requirements for explicit matching (such as `bundleName` and `abilityName`) and the complex logic for implicit matching involving actions, entities, URIs, and types. This documentation is essential for application developers and system engineers aiming to implement precise component startup logic, ensure correct routing, and manage intent handling effectively across the system. By mastering these rules, developers can ensure their applications interact seamlessly with system capabilities and other applications, providing a robust user experience and avoiding common routing errors.
