# enum_Orientation

本目录包含Cangjie语言中WindowManager系统的Orientation枚举API参考文档及相关运算符定义。它详细涵盖了屏幕显示方向的多种状态，包括竖屏、横屏、倒置及基于传感器的自动旋转模式，并提供了方向实例的相等性比较功能。该模块适用于系统版本22及以上，主要面向需要精细控制屏幕旋转行为、处理窗口布局适配的UI开发人员，帮助开发者构建响应式用户界面。

## 详细描述

### enum_Orientation_14more_3c208c71.md enum_Orientation_14more_3c208c71.md
本文档是Cangjie语言中Orientation枚举的API参考文档，用于定义WindowManager系统的显示方向。文档详细列出了包括竖屏、横屏、倒置模式及多种自动旋转模式在内的枚举值，并定义了不等比较运算符。关键信息在于区分了固定方向与基于传感器的旋转，以及是否受系统自动旋转锁定控制。该枚举继承自Equatable，适用于版本22及以上系统。主要面向需要精细控制屏幕旋转行为的UI或窗口管理开发人员。

### operator_func_Orientati_2f9ff4b2.md operator_func_Orientati_2f9ff4b2.md
该文档定义了Orientation类型的相等比较运算符，用于判断两个方向实例是否相等。内容涵盖函数签名、功能描述、系统能力、起始版本、参数及返回值详情。该运算符接收另一个Orientation实例，返回布尔值结果，需WindowManager核心能力，起始版本为22。面向使用仓颉语言开发窗口管理功能的开发者，提供对象比较的API参考。
