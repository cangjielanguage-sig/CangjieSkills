### 数字格式化

数字格式化通过[NumberFormat](../../API_Reference/source_zh_cn/apis/LocalizationKit/cj-apis-intl.md#class-numberformat)的[format](../../API_Reference/source_zh_cn/apis/LocalizationKit/cj-apis-intl.md#func-formatfloat64-string)接口实现，具体开发步骤如下。

1. 导入模块。

   ```cangjie
   import kit.LocalizationKit.*
   ```

2. 创建NumberFormat对象。
   传入locale列表时，使用第一个有效的locale创建对象。不传入locale参数时，使用系统当前的locale创建对象。
   构造函数支持通过NumberOptions设置不同的数字格式化格式，具体请参见表1-表8。

   ```cangjie
   let numberFormat: NumberFormat = NumberFormat(locale: String, options！: ?NumberOptions = None)
   ```

3. 数字格式化，根据numberFormat的设置格式化number。

   ```cangjie
   let formattedNumber: String = numberFormat.format(number: Float64)
   ```

4. 获取数字格式化选项，查看对象的设置信息。

   ```cangjie
   let options: NumberOptions = numberFormat.resolvedOptions()
   ```

**数字格式化选项**

对于数字，通过[NumberOptions](../../API_Reference/source_zh_cn/apis/LocalizationKit/cj-apis-intl.md#struct-numberoptions)参数可以设置最小整数位数、最小小数位数、最大小数位数、最低有效位数、最大有效位数、是否分组显示、数字的格式化规格、紧凑型的显示格式、舍入模式、舍入优先级、舍入增量，以及数字的显示格式和数字系统。其中，数字的显示格式包括decimal(十进制)、percent(百分数)、currency(货币)、unit(单位)。

以123000.123为例，各属性参数取值和显示效果如下表所示。

**表1** 最小整数位数(minimumIntegerDigits)

| 取值 | 显示效果 |
| -------- | -------- |
| 6 | 123,000.123 |
| 7 | 0,123,000.123 |

**表2** 最小小数位数(minimumFractionDigits)

| 取值 | 显示效果 |
| -------- | -------- |
| 3 | 123,000.123 |
| 4 | 123,000.1230 |

**表3** 最大小数位数(maximumFractionDigits)

| 取值 | 显示效果 |
| -------- | -------- |
| 3 | 123,000.123 |
| 2 | 123,000.12 |

**表4** 最低有效位数(minimumSignificantDigits)

| 取值 | 显示效果 |
| -------- | -------- |
| 9 | 123,000.123 |
| 10 | 123,000.1230 |

**表5** 最大有效位数(maximumSignificantDigits)

| 取值 | 显示效果 |
| -------- | -------- |
| 9 | 123,000.123 |
| 8 | 123,000.12 |

**表6** 是否分组显示(useGrouping)

| 取值 | 显示效果 |
| -------- | -------- |
| true | 123,000.123 |
| false | 123000.123 |

**表7** 数字的格式化规格(notation)

| 取值 | 显示效果 |
| -------- | -------- |
| standard | 123,000.123 |
| scientific | 1.230001E5 |
| engineering | 123.000123E3 |
| compact | 123K |

**表8** 紧凑型的显示格式(compactDisplay)

| 取值 | 显示效果 |
| -------- | -------- |
| short | 123K |
| long | 123 thousand |

**开发实例**

<!-- run -->

```cangjie
// 导入模块
import kit.LocalizationKit.*

// 用科学计数法显示数字
let n1 = NumberOptions(notation: 'scientific', maximumSignificantDigits: 3)
let scientificFormat: NumberFormat = NumberFormat('zh-CN', options: n1)
var formattedNumber: String = scientificFormat.format(123400.0) // formattedNumber = '1.234E5'

// 用紧凑的格式显示数字
let n2 = NumberOptions(notation: 'compact', compactDisplay: 'short')
let compactFormat: NumberFormat = NumberFormat('zh-CN', options: n2)
formattedNumber = compactFormat.format(123400.0) // formattedNumber = '12.34万'

// 显示数字的符号
let n3 = NumberOptions(signDisplay: 'always')
let signFormat: NumberFormat = NumberFormat('zh-CN', options: n3)
formattedNumber = signFormat.format(123400.0) // formattedNumber = '123400'

// 显示百分数
let n4 = NumberOptions(style: 'percent')
let percentFormat: NumberFormat = NumberFormat('zh-CN', options: n4)
formattedNumber = percentFormat.format(0.25) // formattedNumber = '25%'
```
