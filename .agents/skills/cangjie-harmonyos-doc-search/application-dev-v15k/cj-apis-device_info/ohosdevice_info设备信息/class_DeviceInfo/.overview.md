# class_DeviceInfo

This directory contains comprehensive API reference documentation and implementation guides for the `DeviceInfo` class within the Cangjie programming language and HarmonyOS ecosystem. It focuses on providing static read-only properties to query terminal device information, covering hardware specifications, build metadata, operating system distribution details, and version identifiers. The content details data types, required system capabilities like `SystemCapability.Startup.SystemInfo`, and specific permissions needed for accessing sensitive data such as serial numbers. It is suitable for Cangjie and HarmonyOS developers who need to programmatically access device configuration details for system analysis, compatibility checks, or application diagnostics.
