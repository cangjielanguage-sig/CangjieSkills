### 操作符重载函数定义和使用_1.md 操作符重载函数定义和使用_1.md
本文档是仓颉编程语言中操作符重载函数定义与使用的技术指南。主要内容包括操作符重载的两种定义方式（类型内部定义与使用 extend 扩展）、一元和二元操作符的参数约定、索引操作符（[]）的取值与赋值重载规则，以及函数调用操作符（()）的重载机制。关键信息指出，二元操作符函数仅有一个参数，索引赋值重载必须包含名为 value 的参数且返回 Unit 类型，且 () 操作符重载函数不能通过 this 或 super 调用。该文档面向需要为结构体、类、枚举等自定义类型实现特定操作符行为的仓颉语言开发者。
