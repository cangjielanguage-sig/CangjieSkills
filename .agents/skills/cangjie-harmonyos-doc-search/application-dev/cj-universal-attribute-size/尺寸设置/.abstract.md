This directory contains essential API documentation for developers utilizing the ArkUI framework in conjunction with the Cangjie programming language. It focuses specifically on the configuration of component dimensions and layout properties, which are fundamental aspects of user interface design. The content covers a wide array of functions necessary for defining the physical space occupied by components, including width, height, and overall size, as well as the spacing around them through padding and margins. Furthermore, it addresses advanced layout behaviors such as layout weighting for proportional distribution, aspect ratio maintenance, and display priority for managing visibility hierarchies. All functions detailed here return a generic type T, facilitating fluent method chaining to streamline code structure. These resources are tailored for UI developers who require granular control over component positioning and sizing to create responsive and polished applications, with features supported starting from system version 22.
