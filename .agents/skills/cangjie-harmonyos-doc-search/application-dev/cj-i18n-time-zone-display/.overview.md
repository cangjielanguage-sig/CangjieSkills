# cj-i18n-time-zone-display

This directory serves as a specialized resource for Cangjie developers aiming to implement internationalization (i18n) features specifically for time zone displays. In a globalized application context, simply displaying a time zone identifier is often insufficient; users expect time zone names to appear in their native language and adhere to regional habits. This directory covers the methodology for achieving this, focusing on the distinction between displaying "Central Time Zone" in English versus "中部时区" in Chinese. It provides technical guidance on using the `LocalizationKit` module and the `getDisplayName` API. Key concepts covered include Localization, Time Zone handling, the Cangjie programming language, the `getDisplayName` function, and the broader scope of Internationalization via the `LocalizationKit`. This content is highly suitable for developers working on multilingual applications who need to ensure their time-related data is presented accurately and culturally appropriately to a diverse user base.
