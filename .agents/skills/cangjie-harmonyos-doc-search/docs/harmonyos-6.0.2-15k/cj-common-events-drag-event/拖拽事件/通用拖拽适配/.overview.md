# 通用拖拽适配

This directory provides comprehensive resources for implementing universal drag-and-drop functionality within the ArkUI Cangjie framework. It covers the complete lifecycle of drag interactions, from enabling drag attributes and resolving gesture conflicts to customizing visual feedback and handling drop events. Key technical topics include UDMF data management, PixelMap manipulation, and specific event callbacks like onDragStart, onDragEnd, and onDrop. The materials are designed for application developers and UI engineers who need to create intuitive, interactive interfaces by integrating complex drag-and-drop mechanics into components such as Images, Buttons, and Lists. The collection includes both theoretical guides and practical code examples.

## Detailed Description

The following files provide in-depth technical details and code examples to help you master drag-and-drop implementation.

### 通用拖拽适配_1.md 通用拖拽适配_1.md
This technical guide explains how to implement universal drag-and-drop functionality for components, using the Image component as a primary example within the ArkUI Cangjie framework. Key sections cover enabling drag via the draggable attribute and onDragStart callback, resolving gesture conflicts using parallelGesture, customizing the drag backplate image through the onPreDrag callback, and handling drag results with onDragEnd. The document provides Cangjie code snippets demonstrating data management via UDMF and PixelMap manipulation. It targets application developers seeking to integrate interactive drag features into their UI components.

### 通用拖拽适配_2.md 通用拖拽适配_2.md
This document serves as a code example demonstrating the implementation of universal drag-and-drop functionality within the ArkUI framework. It covers configuring a source Button to initiate drag events using onDragStart and a custom pixel map builder, alongside setting up a target List component with event handlers for onDragEnter, onDragMove, onDragLeave, and onDrop. Key information includes managing component visibility during the drag operation, utilizing DragItemInfo for custom visuals, and logging event coordinates for debugging. This tutorial is designed for developers working with ArkUI who need to integrate interactive drag-and-drop mechanics into their application interfaces.
