# 应用程序包概述

This directory provides a comprehensive guide to HarmonyOS application packages and module architecture. It covers the fundamental definitions of applications, the Stage model, and the distinctions between various module types like HAP, HAR, and HSP. Key topics include modular design, resource sharing strategies, multi-device adaptation, and dependency management. This documentation is suitable for HarmonyOS developers seeking to understand packaging units, optimize application structure, and select the correct module types for specific development scenarios.

## Detailed Description

### Module类型.md Module类型.md
This technical reference document categorizes HarmonyOS Modules based on usage scenarios to guide application structure. It covers two primary types: Ability-type Modules, which generate .hap files (HAP) for functionality, subdivided into entry (main) and feature (dynamic) modules; and Library-type Modules for code sharing, divided into Static Library (.har/HAR) and Shared Library (.hsp/HSP). Key takeaways include the distinction between HAR, which copies code at compile time and supports OHPM publishing, and HSP, which allows independent compilation and single runtime copies. The document also details Integrated HSP for cross-application usage. Targeted at HarmonyOS developers, this guide explains packaging units and resource sharing strategies.

### 应用程序包概述_3more.md 应用程序包概述_3more.md
This document provides a foundational overview of application packages and design mechanisms for developers using the Stage model. It covers the definitions of applications and packages, system management capabilities, and the multi-module design architecture. Key takeaways include the system's ability to shield chip platform differences and the benefits of modular development for independent compilation and maintenance. It also explains how modules facilitate multi-device adaptation through precise filtering based on device type support. This guide targets developers preparing to build applications, requiring an understanding of the Stage model context.

### 选择合适的包类型.md 选择合适的包类型.md
This guide assists HarmonyOS developers in selecting the appropriate package type among HAP, HAR, and HSP based on specific application requirements. It provides a functional comparison and a detailed specification matrix covering capabilities like UIAbility, pages, and dependencies. Key takeaways include that HAPs are independent installable units, HARs are static libraries suitable for SDKs but may cause code duplication, and HSPs are dynamic shared libraries that optimize package size for runtime reuse. The document also highlights critical constraints regarding page declarations and dependency rules. This reference material is intended for developers designing module architecture and managing dependencies.
