# 打包工具

This directory contains technical documentation and command-line guides for the HarmonyOS application packaging tool (`app_packing_tool.jar`). It covers various packaging scenarios including standard HAP and HSP generation, FastApp mode for market distribution, multi-project merging, and version normalization. Key topics include command syntax, parameter definitions, validation rules, and compression logic for release and debug builds. These resources are designed for developers and build engineers who need to manually package applications, manage complex module integrations, or ensure version consistency outside of the standard DevEco Studio build process.

### 版本归一指令versionNormalize_2more.md 版本归一指令versionNormalize_2more.md
This technical reference guide documents command-line instructions for normalizing version numbers and package names within application packages using the app_packing_tool.jar. It covers two primary modes: versionNormalize for synchronizing version codes and names across multiple HAP and HSP files, and packageNormalize for modifying bundle names and versions specifically for HSP files. Key information includes mandatory parameters such as input file lists, target version codes, and output directories. The versionNormalize command also generates a version_record.json to log original values. This guide targets developers and build engineers managing application packaging and versioning consistency.
