# extend_BigInt_RadixConvertibleBigInt

This directory contains API documentation for a Cangjie language extension that implements the `RadixConvertible` interface for the `BigInt` type. It focuses on the mechanisms required to perform conversions between string representations and large integer structures across various numerical bases, specifically ranging from binary (base 2) to base 36. The documentation covers both input parsing and output formatting functionalities. Key topics include the implementation details of static parsing functions, handling of optional signs and alphanumeric digits, and specific error management strategies for invalid inputs. This resource is essential for Cangjie developers working with arbitrary-precision arithmetic who need to process, validate, or display large numbers in non-decimal formats.

## Detailed Description

The following files provide the specific API references and implementation details for extending BigInt functionality in the Cangjie language.

### extend_BigInt_RadixConvert_3more.md extend_BigInt_RadixConvert_3more.md
This API documentation file details the Cangjie language extension that implements the RadixConvertible interface for the BigInt type. The main sections cover the static functions parse and tryParse, both designed to convert string representations of numbers into BigInt structures based on a specified radix. Key information includes support for bases ranging from 2 to 36, specific string formatting rules involving optional signs and alphanumeric digits, and error handling differences: parse throws an IllegalArgumentException while tryParse returns an optional type. This reference guide targets developers needing to perform base conversions for large integers, requiring knowledge of the BigInt structure and exception handling.

The content covers the function signature, parameter specifications for the radix, return types, potential exceptions, and a practical code example demonstrating binary conversion. Key takeaways include the valid radix range of 2 to 36 and the requirement to handle IllegalArgumentException for invalid inputs. This reference is intended for Cangjie developers working with arbitrary-precision arithmetic who need to format numeric data for display or storage.
