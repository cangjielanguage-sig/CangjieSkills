This directory contains the documentation for the `std.unittest.mock.mockmacro` package, a specialized collection of tools designed to support the unittest framework. It focuses specifically on the macros that act as the backbone for the mock framework, enabling developers to simulate object behaviors and verify code interactions without relying on external dependencies. The package provides a structured approach to testing by offering macros that facilitate the configuration of mock objects and the verification of method calls. Central to this package are the `Called` macro, which is essential for asserting that specific interactions took place, and the `On` macro, which allows for the dynamic definition of behaviors for mock and spy objects. This documentation is intended for developers and testers who require a deep understanding of the mock framework's internal API to write effective, isolated unit tests. It serves as a practical guide for those looking to implement advanced testing strategies such as behavior verification and stubbing. By leveraging the configuration API detailed in these documents, users can precisely control the execution flow of their tests, ensuring that all edge cases and dependencies are handled correctly.
