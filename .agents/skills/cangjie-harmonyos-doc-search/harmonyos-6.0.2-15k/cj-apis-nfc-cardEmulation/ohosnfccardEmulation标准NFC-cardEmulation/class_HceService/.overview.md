# class_HceService

This directory contains API documentation for the `HceService` class, designed to implement Host Card Emulation (HCE) functionality in Cangjie applications. It covers essential operations for managing NFC card emulation, including subscribing to APDU data, initializing the service, transmitting responses to readers, and terminating the service. Key topics include AID registration, lifecycle management, and asynchronous data handling. This resource is suitable for HarmonyOS developers building secure NFC applications that require communication with external reader devices using the Cangjie language.

### func_stopElementName.md func_stopElementName.md
This API reference document details the stop function used to terminate Host Card Emulation (HCE) services in Cangjie applications. The documentation outlines the function signature, required permissions, system capabilities, input parameters, and potential business exceptions with specific error codes. Key takeaways include that the function cancels APDU subscriptions, exits foreground priority, and releases dynamically registered AID lists. It is mandatory to call this interface within the onDestroy lifecycle method of the HCE page. The function requires the ohos.permission.NFC_CARD_EMULATION permission and a non-null ElementName parameter containing bundle and ability names. This guide targets HarmonyOS developers implementing NFC card emulation features who need to manage resource cleanup and service termination.
