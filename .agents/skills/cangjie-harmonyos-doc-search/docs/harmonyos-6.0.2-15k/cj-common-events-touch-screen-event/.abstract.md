This directory contains essential technical documentation for developers utilizing the Cangjie UI framework to build interactive applications for the HarmonyOS ecosystem. It provides an in-depth exploration of touch screen interaction handling, offering clear guidance on how to implement and manage event callbacks effectively. The content specifically differentiates between two primary types of interactions: Click Events (`onClick`), which are optimized for complete press-lift actions, and Touch Events (`onTouch`), which allow for granular monitoring of interaction phases such as Down, Move, Up, and Cancel. By detailing key APIs like `onClick` and `onTouch`, the guide enables developers to extract crucial event data, including precise touch coordinates, touch types, and the area of the target component. Additionally, the document includes practical Cangjie code examples that illustrate how to implement features like image toggling and real-time coordinate tracking. This resource is ideally suited for software developers and UI engineers who are looking to master event handling and create highly responsive, touch-driven user interfaces using the Cangjie language.
