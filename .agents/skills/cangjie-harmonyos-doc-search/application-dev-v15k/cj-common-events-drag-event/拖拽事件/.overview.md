# 拖拽事件

This directory provides a comprehensive guide to implementing drag-and-drop functionalities within the ArkUI framework and HarmonyOS ecosystem. It covers fundamental concepts, event mechanisms, data transfer via UDMF, and visual customization using backdrop images. The content addresses both mouse and touch interactions, gesture conflicts, and cross-language adaptation (ArkTS and Cangjie). It is suitable for UI developers and system engineers looking to build robust, interactive features with precise control over drag visuals and data flow.

## Detailed Description

### 拖拽事件_2more.md 拖拽事件_2more.md
This document defines the drag-and-drop event mechanism, explaining how data is transferred between components via mouse or touch gestures. It covers the introduction to drag-and-drop functionality and a detailed breakdown of basic concepts including drag operations, background customization, content encapsulation, source and target components, and drag point detection. Key takeaways include the use of UDMF UnifiedData for secure data handling and specific APIs like onDragStart and dragPreview for customizing the drag visual. The document clarifies the roles of the drag source (provider) and drag target (receiver). This is a conceptual guide intended for developers building UI interactions who need to understand the terminology and data flow of the drag-and-drop system.

### 拖拽背板图.md 拖拽背板图.md
This document explains the configuration and behavior of drag backdrop images within the ArkUI framework. It details how developers can customize the visual representation during dragging using onDragStart or dragpreview attributes with customBuilder or pixelmap, rather than relying on the default component screenshot. Key sections include supported visual styles like opacity and shadow, and specific constraints regarding system screenshots. Important takeaways are that system screenshots cannot capture content outside container bounds or apply transform effects like scale and rotate. This technical guide targets UI developers implementing drag-and-drop features who require precise control over the drag visual feedback.

### 拖拽流程/
This directory serves as a comprehensive technical resource for understanding and implementing drag-and-drop functionalities within the ArkUI framework. ### 通用拖拽适配/
This directory serves as a comprehensive technical resource for implementing universal drag-and-drop functionality within HarmonyOS applications. It addresses the specific challenges and methodologies for enabling drag capabilities across different programming languages and frameworks, specifically Cangjie and ArkTS. The content covers critical implementation details such as resolving gesture conflicts between system and custom interactions, customizing drag visuals using component snapshots and pixel maps, and managing data exchange via UDMF. Key technical topics include the use of `parallelGesture`, `DragItemInfo`, and event handling callbacks like `onDragStart` and `onDrop`. This resource is specifically designed for HarmonyOS developers who possess a foundational understanding of ArkUI, UIKit, or the Cangjie language and wish to enhance user interaction through advanced, cross-component drag-and-drop features. By following these guides, developers can create seamless and intuitive user experiences involving complex data transfer and visual feedback.
