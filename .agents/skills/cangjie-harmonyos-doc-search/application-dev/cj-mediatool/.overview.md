# cj-mediatool

The `cj-mediatool` directory serves as a centralized repository for the `mediatool`, a lightweight command-line utility specifically engineered for developers and technical users who require direct, programmatic control over media resources on a device. This directory provides comprehensive documentation for managing images and videos within the system Gallery, offering a robust alternative to standard user interface interactions. It covers critical operational capabilities such as exporting media files for external analysis or backup, deleting specific resources to manage storage efficiently, and resetting the media database to ensure system integrity and correct indexing. The content is particularly relevant for professionals working in development, quality assurance, or testing environments where precise manipulation of media URIs and database states is frequently required. To effectively utilize the tools and commands described here, users must possess a connected device with developer mode enabled, operating primarily through the `hdc shell` environment. This resource is vital for streamlining complex workflows related to media asset management and system debugging.

## Detailed Description

### mediatool工具/

This subdirectory contains the definitive documentation for the `mediatool`, a specialized command-line utility that acts as a bridge between developers and the device's internal media library. It is designed to facilitate the comprehensive management of media resources—specifically images and videos—that are displayed in the system Gallery. The documentation is structured to guide users through the tool's definition, clearly outlining what the utility does and how it integrates into the broader development ecosystem.

A significant portion of the content is dedicated to prerequisites and setup, ensuring that users understand the necessary environment configurations. This includes the requirement for a physically connected device and the enabling of developer mode to allow communication. The core of the documentation focuses on practical usage scenarios. It provides detailed instructions for performing essential tasks, such as exporting media files from the device to a local machine for safekeeping, deleting unwanted files to clean up the library, and resetting the media database to its default state to resolve corruption issues. Additionally, it covers the technical nuances of handling media URIs, which is crucial for developers working with file paths and content references. This documentation is an indispensable guide for technical users who prefer the efficiency and precision of the `hdc shell` over graphical interfaces.
