This directory contains a comprehensive set of code examples focused on cryptographic key management and secure data operations within the HarmonyOS Universal Keystore (HUKS) framework. It covers essential security protocols including ECDH key agreement, AES encryption (AES-192, AES-256-GCM), and secure key import workflows between devices. The examples demonstrate practical implementations using the Cangjie language, detailing utility functions for byte manipulation, session management, and key lifecycle operations. These resources are designed for developers working on OpenHarmony or HarmonyOS applications who need to implement robust security features, secure key storage, and encrypted data exchange mechanisms.
