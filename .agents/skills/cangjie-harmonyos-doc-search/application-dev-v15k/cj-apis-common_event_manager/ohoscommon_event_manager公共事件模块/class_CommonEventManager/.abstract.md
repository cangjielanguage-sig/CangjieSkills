This directory provides comprehensive API reference documentation for the `CommonEventManager` class within the Cangjie language ecosystem. It is designed to assist developers in managing common events and inter-process communication (IPC) effectively. The content covers the class structure, static methods for creating subscribers, publishing events, and unsubscribing from notifications. Key topics include parameter definitions, return values, system capabilities, and specific `BusinessException` error codes for troubleshooting. This documentation is intended for Cangjie developers utilizing the BasicServicesKit to implement robust event-driven architectures and system notification features.
