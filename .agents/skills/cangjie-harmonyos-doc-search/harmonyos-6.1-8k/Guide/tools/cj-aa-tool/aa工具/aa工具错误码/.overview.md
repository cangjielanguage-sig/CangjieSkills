本目录包含HarmonyOS应用开发中aa工具（Ability Assistant）相关的错误码参考文档。内容涵盖了应用启动、Ability拉起、组件连接及调试过程中的常见异常，如UIExtensionAbility不支持启动、隐式启动失败、权限校验失败、目标Ability不存在及进程终止错误等。文档详细描述了错误现象、可能原因及具体的排查步骤，旨在帮助开发者快速定位并解决使用`aa start`等命令时遇到的技术问题。主要面向HarmonyOS应用开发人员和测试人员。
