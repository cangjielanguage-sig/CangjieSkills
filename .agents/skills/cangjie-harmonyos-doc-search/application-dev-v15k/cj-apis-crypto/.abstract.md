This directory serves as a comprehensive API reference for the HarmonyOS Crypto Framework, specifically adapted for the Cangjie programming language. It provides developers with the necessary interfaces to implement robust security features within their applications. The content covers a broad spectrum of cryptographic operations, including symmetric and asymmetric encryption, digital signatures, complex key generation, message digests, and key agreement protocols. By supporting a diverse range of algorithms such as RSA, ECC, AES, SM2, and DSA, this framework ensures that developers can meet various security standards and requirements. This resource is primarily tailored for software developers and security engineers who are building applications in Cangjie and require advanced tools for data protection, secure key management, and the implementation of cryptographic protocols within the SystemCapability.Security.CryptoFramework environment.
