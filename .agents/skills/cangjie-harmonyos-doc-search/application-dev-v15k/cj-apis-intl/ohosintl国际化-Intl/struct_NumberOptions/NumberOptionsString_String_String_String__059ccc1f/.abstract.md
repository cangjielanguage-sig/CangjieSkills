This directory contains documentation for the `NumberOptions` class within the Cangjie programming language's LocalizationKit. It focuses on building configuration objects for number formatting, covering internationalization (i18n) and localization (l10n) features. The content includes API references for constructors and parameters, as well as practical code examples for various formatting scenarios like currency, scientific notation, and units. It is suitable for developers requiring precise control over numeric display, locale matching, and digit constraints in their applications.
