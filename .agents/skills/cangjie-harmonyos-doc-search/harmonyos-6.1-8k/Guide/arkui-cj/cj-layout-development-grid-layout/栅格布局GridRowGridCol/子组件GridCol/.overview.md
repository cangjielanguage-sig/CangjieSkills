# 子组件GridCol

本目录包含关于 ArkUI 框架中 GridCol 子组件的详细文档，重点介绍栅格布局的核心属性配置。内容涵盖了 span（列数）、offset（偏移量）和 order（排序）的使用方法，详细解析了固定值与响应式配置（GridColOptions）在不同屏幕尺寸（xs 至 xxl）下的应用逻辑。文档基于 Cangjie 语言编写，提供了丰富的代码示例，旨在帮助开发者掌握 ArkUI 栅格系统的布局控制技巧，适用于需要构建响应式界面的 UI 开发者。

## 详细描述

### offset_4aa45a02.md
1. 本文档旨在说明ArkUI栅格布局中GridCol组件的offset属性，用于定义子组件相对于前一个组件的偏移列数。
2. 文档主要涵盖两种类型的使用方式：当类型为Int32时，设置固定偏移量；当类型为GridColOptions时，支持xs、sm、md等六种设备尺寸的响应式偏移配置。
3. 通过Cangjie代码示例，文档详细展示了偏移量的计算逻辑及在不同屏幕下的布局效果，默认偏移为0。
4. 该文档适合使用ArkUI和Cangjie语言进行UI开发的开发者参考，关键词包括ArkUI、GridCol、offset、栅格布局和响应式设计。

### order.md
本文档详细说明了栅格布局中用于控制子组件排列次序的 `order` 属性。主要内容包括排序规则说明（如默认顺序、数值大小排序、混合设置时的优先级），以及两种数据类型的应用：`Int32` 类型用于全尺寸统一排序，`GridColOptions` 类型用于响应式布局下不同设备尺寸（xs至xxl）的独立排序设置。核心要点在于未设置 `order` 的子组件优先显示，已设置的按数值升序排列。文档通过 Cangjie 代码示例展示了静态排序与基于断点的动态响应式排序的具体实现方式。适用于使用 ArkUI 框架和 Cangjie 语言进行 UI 开发的开发者，旨在帮助其掌握栅格系统的布局控制技巧。

### 子组件GridCol_2more_65be4597.md
本文档介绍了ArkUI框架中GridCol子组件的用法，重点说明如何通过参数或属性设置栅格布局的列数、偏移量和序号。主要涵盖span、offset和order的配置方式，并详细解析了span属性在固定列数与响应式布局下的应用。关键信息指出span决定组件宽度，支持Int32通用设置及GridColOptions针对xs至xxl六种屏幕尺寸的差异化配置，并提供了Cangjie代码示例。该文档面向使用Cangjie语言的ArkUI开发者，适合需要构建响应式栅格界面的场景。
