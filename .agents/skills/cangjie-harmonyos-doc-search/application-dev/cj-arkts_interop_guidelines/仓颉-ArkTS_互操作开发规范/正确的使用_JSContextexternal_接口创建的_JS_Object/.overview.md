# 正确的使用_JSContextexternal_接口创建的_JS_Object

This directory serves as a comprehensive technical guide for HarmonyOS developers, focusing on the correct usage of the `JSContext.external` interface in Cangjie to create JavaScript objects compatible with ArkTS. It addresses critical aspects of object creation, including core rules for encapsulation, type safety, and the binding process between native Cangjie code and the JavaScript layer. The documentation highlights common pitfalls, such as type issues where `JSExternal` appears as `undefined`, and provides solutions using `attachCJObject`. Additionally, it covers backend implementation details for retrieving object IDs and data binding. This resource is essential for cross-platform developers proficient in Cangjie and ArkTS who are utilizing the `ohos.ark_interop` library for native-script interoperability.

## Detailed Description

### 正确的使用_JSContextexternal_接口创建的_JS_Object_1.md
This guide instructs HarmonyOS developers on the correct usage of the `JSContext.external` interface in Cangjie for creating JavaScript objects compatible with ArkTS. It covers the core rule, a "Wrong Example" demonstrating type issues where `JSExternal` appears as `undefined`, and a "Correct Example" showing proper encapsulation. Key takeaways include avoiding direct use of `JSExternal` as parameters; instead, developers must bind these objects to a `JSObject` using `attachCJObject` and attach methods to ensure type safety and maintainability. This technical guide targets developers working on Cangjie and ArkTS interop, requiring knowledge of both languages and the `ohos.ark_interop` library.

### 正确的使用_JSContextexternal_接口创建的_JS_Object_2.md
This technical guide demonstrates the correct implementation of the JSContext external interface to create and manipulate JavaScript objects from Cangjie code within a HarmonyOS environment. The document covers the Cangjie backend implementation for retrieving object IDs, the corresponding ArkTS interface declarations, and practical usage examples in ArkTS. Key information includes how to extract the this argument, access attached native data via getAttachInfo, and return values to the JavaScript layer, illustrating the data binding process between native and script layers. Targeted at cross-platform developers using Cangjie and ArkTS, this guide requires prerequisite knowledge of native-JavaScript interoperability and HarmonyOS development.
