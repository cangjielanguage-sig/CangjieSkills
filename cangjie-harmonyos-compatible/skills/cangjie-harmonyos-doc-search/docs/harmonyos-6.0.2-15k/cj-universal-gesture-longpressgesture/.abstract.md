This directory serves as a comprehensive resource for the LongPressGesture class within the Cangjie ArkUI framework, focusing on the implementation of long-press interactions in UI development. It provides detailed documentation on component initialization, allowing developers to configure parameters such as finger count, duration, and repeat behavior to suit specific interaction needs. The guide also covers essential event callbacks, including onAction, onActionCancel, and onActionEnd, ensuring precise control over gesture states. Additionally, it addresses technical nuances like the default 500ms duration threshold, conflict priority logic with drag gestures, and the 15px movement failure threshold. This documentation is tailored for Cangjie developers who require syntax definitions and practical code examples to effectively integrate gesture recognition into their applications. By understanding these elements, developers can create more responsive and intuitive user interfaces.
