# class_Session

This directory provides comprehensive API reference documentation for the Cangjie Session class, designed for managing connection sessions on SE Readers within the Secure Element framework. It covers essential functionalities such as session lifecycle management, channel establishment, and status retrieval. Key topics include ISO 7816-4 protocols, Answer To Reset (ATR) handling, and specific error management for `BusinessException` scenarios. The documentation outlines system capabilities and version requirements starting from version 19. This resource is intended for developers working with secure element hardware who require detailed interfaces to establish and maintain secure communication channels effectively.

### class_Session_6more.md class_Session_6more.md
This document serves as API reference documentation for the Cangjie Session class, which represents a connection session on an SE Reader within the Secure Element framework. It details key methods for managing session lifecycles, including closing sessions and channels, retrieving the Answer To Reset (ATR), and checking session status. The documentation specifies system capabilities, version requirements (starting from 19), and potential BusinessException errors such as capability not supported or illegal state exceptions. Intended for developers working with secure element hardware, this guide provides the necessary interfaces to establish and maintain secure communication channels.

### func_openBasicChannelArray_2more.md func_openBasicChannelArray_2more.md
This API reference document details the openBasicChannel functions in Cangjie for establishing basic communication channels with a Secure Element (SE) based on ISO 7816-4. The content covers two overloaded function signatures: one accepting an Applet ID (AID) array and another adding a P2 parameter for SELECT APDU commands. Key information includes parameter definitions, return values of a Channel instance, and system capability requirements starting from version 19. The document also enumerates specific error codes for handling exceptions such as parameter failures, security access denials, and communication IO errors. Intended for developers working with secure hardware, this guide requires understanding of SE protocols and exception management.

### func_openLogicalChannelArr_2more.md func_openLogicalChannelArr_2more.md
This API reference documentation details the overloaded openLogicalChannel functions in the Cangjie language for managing Secure Element (SE) sessions. It covers two function signatures: one accepting an Application Identifier (AID) array and another accepting both an AID array and a P2 parameter for APDU commands. Both functions return a Channel instance or None, adhering to the ISO 7816-4 protocol. The documentation specifies system capabilities, version requirements, and detailed error handling, including BusinessException codes for parameter failures, security errors, and IO issues. This guide targets developers implementing secure element communication who need to understand channel opening procedures and error management.
