This directory focuses on configuring outer outlines for UI components within the ArkUI framework using the Cangjie language. It contains both API references and practical code examples for setting properties like width, color, radius, and style, ensuring borders are drawn outside the component without affecting the internal layout. Key topics include uniform and side-specific configurations, constraints on percentage values, mandatory width settings, and radius calculation limits. This resource is suitable for UI developers and HarmonyOS application builders looking to programmatically style component edges and enhance visual interfaces with precise border control.
