# Badge

This directory contains comprehensive documentation for the ArkUI Badge component within the Cangjie framework. It covers the API reference, practical code examples, and fundamental type definitions required to implement and customize notification markers on UI elements. Key topics include numeric and text-based constructors, styling properties, positioning enums, and dynamic visibility control. This resource is suitable for UI developers and HarmonyOS application engineers looking to enhance user interfaces with visual indicators and status markers.

## Detailed Description

### Badge_5more.md Badge_5more.md
This document serves as API reference documentation for the ArkUI Badge component within the Cangjie framework, designed to attach information markers or reminders to other UI elements. The content details the module import, child component support, and two primary constructors: one for numeric counts with a maximum limit, and another for string-based text markers. Key parameters include BadgeStyle and BadgePosition for customization. The component supports a single child and accepts all universal attributes and events. This guide is intended for developers building user interfaces who require visual notification indicators.

### 示例代码.md 示例代码.md
This document provides practical Cangjie code examples for implementing the ArkUI Badge component. It covers two primary scenarios: setting badge content and controlling visibility. The first example demonstrates using the value and count properties to display text, numbers, or dot indicators, while illustrating various styling options like color, size, and position. The second example explains how to dynamically toggle badge visibility by manipulating the count value, specifically hiding the badge when the count is zero. This tutorial is designed for developers using the ArkUI framework to enhance user interfaces with notification markers.

### 基础类型定义/
This directory serves as a comprehensive resource for defining basic types within the ArkUI framework using the Cangjie programming language.
