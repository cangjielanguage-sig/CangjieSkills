# class_CameraManager

This directory contains API reference documentation for the CameraManager class within the Cangjie CameraKit framework for HarmonyOS. It covers the essential lifecycle and configuration methods required to manage camera hardware, including creating input/output streams, handling sessions, and querying device capabilities. Key topics include camera initialization, metadata and video output creation, torch (flashlight) control, and event callback management. This documentation is suitable for developers building multimedia applications who need to programmatically control camera features, handle permissions, and manage system-level hardware states using the Cangjie language.
