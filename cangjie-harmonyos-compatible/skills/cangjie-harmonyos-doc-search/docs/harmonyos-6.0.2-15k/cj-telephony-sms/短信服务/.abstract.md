This directory provides comprehensive technical documentation for integrating SMS (Short Message Service) functionality into HarmonyOS applications and web environments. It covers essential concepts such as SMS protocols, encoding types (7-bit, 8-bit, UCS-2), and system constraints. The guides detail various methods to launch the native SMS editing interface, utilizing URI schemes for web pages and the `startAbility` interface for in-app navigation. Key topics include PDU handling, SIM slot management, and specific permission requirements. This resource is suitable for developers seeking to implement seamless communication features, navigate system restrictions, and understand the underlying architecture of SMS services on the HarmonyOS platform.
