This directory provides comprehensive documentation for system applications designed to manage critical assets within specific user spaces, ensuring strict data isolation in complex multi-user environments. It details the necessary procedures for system apps to handle sensitive data securely, covering scenarios that require explicit user space specification. The content includes constraints related to the `INTERACT_ACROSS_LOCAL_ACCOUNTS` permission and offers a detailed reference table for basic asset management APIs. It is specifically tailored for developers building single-instance system applications using the Cangjie language who require robust mechanisms for adding, removing, updating, and querying assets across different user accounts while maintaining security and authentication flows. This guide ensures that developers understand the restrictions placed on these interfaces, which are exclusively available to system applications, thereby maintaining the integrity of user data separation.
