This directory provides essential API documentation for data parsing functions in the Cangjie programming language, focusing on enabling robust parameterized testing. It covers the implementation of functions that read and parse external data files—such as CSV, JSON, and TSV—into serializable objects. Key functionalities include customizing parsing logic with specific delimiters, handling headers, skipping data rows, and managing serialization requirements. This resource is designed for Cangjie developers and software testers who need to integrate external datasets into their testing frameworks to automate validation and ensure code reliability across various input scenarios.
