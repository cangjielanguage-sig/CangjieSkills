This directory serves as a comprehensive introduction and technical reference for the Media Kit, a system service designed for developing audio and video playback and recording functionalities. It covers core modules such as AVPlayer, AVRecorder, AVScreenCapture, SoundPool, AVMetadataExtractor, and AVImageGenerator. Key topics include media transcoding, screen recording workflows, metadata extraction, and thumbnail generation. The documentation details supported formats (MP4, MP3, H.264, AAC), interaction architectures via the Cangjie interface, and data flow through frameworks like Camera and Audio. It is targeted at application developers building media applications, requiring knowledge of streaming protocols and system framework interactions.
