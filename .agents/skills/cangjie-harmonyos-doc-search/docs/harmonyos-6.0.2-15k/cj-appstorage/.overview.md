# cj-appstorage

This directory serves as a comprehensive technical resource for AppStorage, a global UI state storage mechanism specifically designed for the Cangjie and ArkUI frameworks. It addresses the critical architectural need for application-level state management, clearly distinguishing it from page-level storage solutions to help developers design scalable applications. The documentation provides in-depth insights into data synchronization using decorators such as @StorageLink and @StorageProp, which are essential for building reactive user interfaces. Furthermore, it includes essential API references, strict constraint guidelines, and practical scenarios for handling complex data types effectively. This content is highly suitable for HarmonyOS developers and architects aiming to implement robust reactive state management, optimize UI performance, and gain a thorough understanding of data persistence boundaries and process isolation within their applications.

## Detailed Description

### AppStorage应用全局的UI状态存储/

This directory provides comprehensive documentation for AppStorage, a global UI state storage mechanism in the Cangjie and ArkUI frameworks. It covers the core concepts of application-level state management, distinguishing it from page-level storage, and details the usage of decorators like @StorageLink and @StorageProp for data synchronization. The content includes API references, constraint guidelines, and practical usage scenarios for complex data types. It is suitable for HarmonyOS developers and architects seeking to implement reactive state management, optimize UI performance, and understand the boundaries of data persistence and process isolation in their applications.

**Key topics covered include:**
- **Core Concepts:** Understanding the distinction between application-level and page-level state management.
- **Decorators:** Implementation details for @StorageLink and @StorageProp to ensure data synchronization.
- **API & Constraints:** A complete reference guide and usage constraints.
- **Complex Data Handling:** Scenarios and best practices for managing complex data types.
- **Architecture:** Insights into data persistence and process isolation for HarmonyOS applications.
