# 生命周期状态说明

This directory provides a comprehensive technical guide to the lifecycle states of UIAbility within the HarmonyOS development environment. It covers the complete application lifecycle, including initialization (Create), visibility changes (Foreground/Background), and termination (Destroy). Key concepts include essential callback functions like `onCreate`, `onForeground`, `onBackground`, and `onDestroy`, alongside best practices for resource management and data persistence using the Cangjie language. The documentation also details the `Want` mechanism for component communication and specific behaviors in singleton launch modes. This resource is suitable for application developers seeking to optimize app performance, manage system resources efficiently, and implement robust lifecycle logic in HarmonyOS applications using the AbilityKit framework.

## Detailed Description

### Create状态_2more.md
This technical guide explains the initial lifecycle states of UIAbility, specifically the Create and WindowStageCreate phases, within the HarmonyOS development context. It details the onCreate() callback for application initialization and the onWindowStageCreate() callback for UI loading and event subscription. Key information includes Cangjie code examples demonstrating variable definition, resource loading, and the use of loadContent() to set the main page. It also defines Want as an information carrier for component communication. Targeted at application developers, this document serves as a reference for managing application startup and window creation logic.

### Destroy状态.md
This document outlines the Destroy state in the UIAbility lifecycle, explaining when it triggers and how to handle it. It covers the `onDestroy()` callback, which executes when an instance is stopped via methods like `terminateSelf()` or closed by the user from the recent tasks list. Key takeaways include the necessity of releasing system resources and saving data within this callback. The text provides a Cangjie code example for implementation and notes specific behavior in developer mode. Intended for application developers, this guide serves as a reference for managing application lifecycle termination and resource cleanup.

### Foreground和Background状态.md
This technical guide explains the lifecycle management of UIAbility instances, specifically focusing on foreground and background state transitions. It details the onForeground and onBackground callbacks, providing Cangjie code examples for resource management. It also covers the onNewWant callback behavior for singleton launch modes. Key information includes using onForeground to acquire resources before UI visibility and onBackground to release resources or save state after UI invisibility. For singleton instances, startAbility triggers onNewWant instead of creation callbacks to update data. This guide targets developers using the Cangjie language and AbilityKit framework to optimize application performance and resource usage.
