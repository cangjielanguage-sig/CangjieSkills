# ohosappabilityui_ability

This directory provides API reference documentation for the `ohos.app.ability.ui_ability` module in the Cangjie programming language, part of the HarmonyOS AbilityKit framework. It covers core classes like `Ability`, `Context`, and `UIAbility`, focusing on lifecycle management, resource access, and system configuration. A significant portion addresses interoperability between Cangjie and ArkTS, specifically converting JSValue types to Context objects. This content is intended for HarmonyOS developers and system engineers using Cangjie to build applications with user interfaces, manage application lifecycles, and implement cross-language component communication.

## Detailed Description

### class_Ability_3more.md class_Ability_3more.md
This document serves as API reference documentation for the Cangjie programming language, detailing core classes within the AbilityKit framework. It covers the abstract sealed class Ability, the base for UIAbility and ExtensionAbility, alongside AbilityStageContext and ApplicationContext, both inheriting from Context. Key information includes system capabilities, version requirements (starting from 22), and specific properties like currentHapModuleInfo for accessing module information. Intended for application developers, this guide explains the hierarchical relationship between these contexts and their roles in managing system configurations, memory adjustments, and application-level resources.

### class_Context.md class_Context.md
This document serves as API reference documentation for the Cangjie Context class, which provides essential context support for abilities and applications, including resource access. It covers key properties like applicationInfo, area, filesDir, and resourceManager, defining their types and read-write capabilities. Additionally, it documents the toJSValue method for converting Cangjie objects to ArkTS JSValue for interoperability. The content is intended for developers using the AbilityKit who need to manage application resources and file partitions. It requires familiarity with Cangjie syntax and the application runtime environment.

### func_createContextFromJSVa_3more.md func_createContextFromJSVa_3more.md
This API reference documentation details functions and interfaces for converting between ArkTS JSValue types and Cangjie Context objects within the HarmonyOS Ability framework. It covers the createContextFromJSValue and createUIAbilityContextFromJSValue functions for type conversion, alongside the SystemObjectInteropTypeToJS interface and its toJSValue method for reverse conversion. Key takeaways include the requirement for a JSContext parameter, the system capability dependency on AbilityRuntime.Core, and the availability starting from version 22. Targeted at Cangjie developers implementing ArkTS interoperability, specifically those managing UIAbility and AbilityStage contexts.
