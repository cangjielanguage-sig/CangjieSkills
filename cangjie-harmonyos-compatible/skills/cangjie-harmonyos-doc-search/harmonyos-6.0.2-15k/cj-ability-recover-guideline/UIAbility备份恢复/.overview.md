# UIAbility备份恢复

This directory focuses on the UIAbility backup and restoration functionality within the HarmonyOS development environment. It is designed to assist developers in preserving application state and data during unexpected system terminations, thereby ensuring a smooth and continuous user experience. The documentation covers essential concepts such as lifecycle callbacks (onSaveState, onCreate), operational mechanisms, and specific constraints including data size limits and storage duration. Furthermore, it provides technical implementation guides using the Cangjie language and AbilityKit. This resource is highly suitable for HarmonyOS developers who need to manage application state continuity and handle lifecycle events effectively when background applications are reclaimed by the system.

## Detailed Description

### 场景介绍_3more.md
This document describes the UIAbility backup and restoration feature designed to preserve application state and data during unexpected system terminations. It details the scenario where background apps are killed, the operational mechanism involving lifecycle callbacks like onSaveState and onCreate, and specific constraints such as data size limits and storage duration. Key takeaways include that this process is automatic for system-killed apps but excludes normal closures or device restarts, with a 200KB data cap. This technical guide is intended for HarmonyOS developers implementing state recovery to ensure user experience continuity.

### 接口说明_2more.md
This document serves as a technical guide for implementing UIAbility backup and restore functionality using the Cangjie language and AbilityKit. It covers the setRestoreEnabled interface and provides step-by-step development instructions. Key takeaways include the requirement to call setRestoreEnabled during the initialization phase, specifically within onCreate before onForeground. The guide also demonstrates how to actively save state using onSaveState and restore data by parsing JSON parameters in onCreate. This resource is designed for developers seeking to manage application state continuity and lifecycle events effectively.
