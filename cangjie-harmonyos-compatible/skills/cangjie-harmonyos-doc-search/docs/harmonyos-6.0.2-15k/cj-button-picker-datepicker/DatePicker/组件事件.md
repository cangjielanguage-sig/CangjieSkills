## 组件事件

### func onDateChange((DatePickerResult) -> Unit)

```cangjie
public func onDateChange(callback: (DatePickerResult) -> Unit): This
```

**功能：** 选择日期时触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|([DatePickerResult](#class-datepickerresult))->Unit|是|-|返回选中的时间，年月日为选中的日期，时分取决于当前系统时间的时分，秒恒为00。|
