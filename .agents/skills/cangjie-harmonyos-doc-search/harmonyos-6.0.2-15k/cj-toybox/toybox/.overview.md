# toybox

This directory contains documentation for Toybox, a lightweight Linux command-line utility collection consolidated into a single executable. It covers the tool's definition, access methods via hdc shell or application sandbox, and troubleshooting common errors. The content also includes a comprehensive reference for system operations like process management and network configuration. Suitable for developers and system administrators working with Linux-based systems or Huawei devices, this resource provides essential guidelines for efficient command-line tool usage and debugging.

## Detailed Description

### toybox_2more.md toybox_2more.md
This document introduces toybox, a lightweight Linux command-line utility collection consolidated into a single executable, and outlines how to access it. The text covers the tool's definition and details two specific usage methods: accessing the tool via the hdc shell after connecting a device, or running it directly within an application sandbox environment. Key takeaways include understanding that toybox replaces multiple standard Linux commands with one binary and requires either a device connection with shell access or a sandboxed application context to function. This technical reference guide targets developers or system administrators working with Linux-based systems who need to utilize command-line tools efficiently.

### 常见问题.md 常见问题.md
This document serves as a troubleshooting guide for resolving common errors encountered when using the Toybox command-line tool. It addresses specific error scenarios including "Unknown command," permission issues like "Operation not permitted," standard Linux kernel errors, and discrepancies between shell and Toybox command implementations. Key takeaways include verifying command compilation status, checking file permissions and SELinux logs for access denials, interpreting standard Linux error codes, and using the "toybox [command]" prefix to override shell built-ins. Intended for developers or system administrators working with Huawei devices, this guide assumes prerequisite knowledge of Linux command-line operations and file permissions.
