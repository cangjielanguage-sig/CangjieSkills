### 函数/
This directory contains API documentation for file system utility functions in the Cangjie programming language. It is structured to assist developers in navigating the complexities of file I/O operations. The documentation covers essential operations such as path normalization, which ensures that file paths are correctly formatted regardless of the operating system, and file copying, which includes mechanisms to handle existing files safely.

Furthermore, it details existence checking, removal, and renaming processes, providing a complete toolkit for file management. The documents meticulously detail function signatures, parameters, return types, and exception handling for both `Path` and `String` inputs, offering flexibility in how developers choose to represent file locations. Key topics include recursive deletion for directory removal, overwrite controls to prevent accidental data loss, and symbolic link resolution to handle modern file system structures. This resource is suitable for Cangjie developers who need precise technical references to implement robust file management logic and handle file system errors effectively.
