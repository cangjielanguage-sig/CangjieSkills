This directory contains API reference documentation for event handling functions within the ArkUI List component, specifically using the Cangjie programming language. It covers a comprehensive range of interactive behaviors, including item deletion, complex drag-and-drop operations, and various scroll-related events such as start, stop, frame updates, and visibility changes. The documents detail function signatures, callback parameters, and system capability requirements. This resource is suitable for software developers and UI engineers building interactive list interfaces who need to implement custom logic for user interactions and dynamic content updates in ArkUI applications.
