# 媒体资源变更通知相关指导

This directory provides technical guidance for developers on monitoring and managing media resource changes using the MediaLibraryKit and photoAccessHelper in Cangjie. It covers registering listeners for specific URIs, implementing fuzzy listening, and unregistring callbacks. Key topics include asynchronous callback modes, permission management, and handling file modifications like renaming or deletion. Suitable for application developers building media-rich applications on HarmonyOS who need real-time synchronization with the user's photo library.
