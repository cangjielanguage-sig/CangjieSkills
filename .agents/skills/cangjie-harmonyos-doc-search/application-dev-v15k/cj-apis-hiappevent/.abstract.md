This directory provides API reference documentation for the `cj-apis-hiappevent` module, designed for the Cangjie programming language within the HarmonyOS environment. It focuses on the HiAppEvent module, which is essential for implementing application event tracking, logging, and analysis. The documentation covers a wide range of technical elements, including enums, structs for configuration and filtering, and classes for data handling. Key topics include event definitions, subscription management, data processors, and storage configuration. This resource is suitable for Cangjie developers and system integrators aiming to integrate performance monitoring, user behavior analysis, and fault diagnosis using the SystemCapability.HiviewDFX.HiAppEvent framework. By leveraging these APIs, developers can ensure application reliability and gain actionable insights into system operations.
