# cj-row-column-stack-stack

本目录提供了ArkUI框架下使用Cangjie语言开发的Stack堆叠容器组件的完整API参考文档。Stack组件是构建层叠布局UI的核心工具，允许子组件在空间上重叠排列。文档深入讲解了组件的初始化方式、`alignContent`对齐属性的使用细节，以及子组件的堆叠顺序（后入栈覆盖先入栈）。此外，还特别说明了该特定属性与通用`align`属性之间的互斥规则，帮助开发者避免布局冲突。该资料主要面向熟悉Cangjie语言语法并致力于ArkUI应用开发的工程师，适用于需要实现复杂层叠界面、悬浮按钮或背景叠加等场景的开发工作。

### cj-row-column-stack-stack.md cj-row-column-stack-stack.md

本文档是ArkUI框架中Cangjie语言的Stack堆叠容器组件API参考文档，旨在指导开发者实现子组件的层叠布局。文档涵盖了组件定义、模块导入、构造函数init（包含alignContent和child参数）、组件属性方法alignContent的详细说明，以及通用属性和事件的支持情况。关键信息指出Stack容器允许子组件按顺序入栈，后入栈的覆盖先入栈的，并强调了alignContent属性与通用align属性的冲突规则。文档还提供了示例代码演示子组件在底部对齐的显示效果。本文档面向具备Cangjie语言基础和ArkUI开发能力的应用开发者，适用于需要实现层叠UI界面的场景。
