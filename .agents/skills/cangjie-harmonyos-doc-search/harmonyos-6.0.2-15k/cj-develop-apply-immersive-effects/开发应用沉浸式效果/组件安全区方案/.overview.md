# 组件安全区方案

This directory provides a comprehensive technical guide on managing component safe areas within the HarmonyOS ArkUI framework. It focuses on achieving immersive display effects by extending UI components into system zones like status bars and navigation bars. Key topics include the `expandSafeArea` attribute, handling scrolling containers, bottom tab scenarios, and layout adaptation strategies. The documentation is tailored for application developers using the Cangjie or ArkTS languages who need to create adaptive, full-screen layouts while effectively managing system insets and visual consistency.

### 图文场景.md 图文场景.md
This document serves as a technical guide for implementing immersive display effects in HarmonyOS applications using the Cangjie language, specifically addressing scenarios where status bar and bottom navigation elements differ. The content focuses on the configuration of the expandSafeArea attribute to handle safe areas independently for top and bottom components. Key information includes the specific API usage: applying expandSafeArea with SafeAreaEdge.TOP for the top element and SafeAreaEdge.BOTTOM for the bottom element, rather than relying on simple background extension. The document provides a complete Cangjie code example demonstrating this logic within a Swiper and Column layout. This tutorial is intended for HarmonyOS developers using the declarative UI paradigm who need to manage complex layout immersions and safe area insets.

Key takeaways include that components must not use fixed dimensions, parents should not clip, and system components can utilize safeAreaPadding for clipping. ### 滚动类场景.md 滚动类场景.md
This technical guide explains how to implement immersive effects for scrolling containers in Cangjie applications, specifically addressing scenarios where child components do not support the expandSafeArea attribute. The document covers two primary implementation methods: applying the expandSafeArea property directly to the parent scroll container or using the clipContent property with ContentClipMode.SAFE_AREA to extend the clipping region. Key takeaways include the necessity of matching background colors between parent and child components to visually bridge the safe areas. This tutorial targets mobile application developers using the Cangjie language who need to handle layout adaptation for system avoidance zones like status bars and navigation bars.
