# 开发步骤

This directory serves as a comprehensive resource for developers working with cryptographic security in the Cangjie programming language, specifically focusing on the DeviceCertificateKit framework. It provides detailed development steps and code samples for managing X.509 certificates and Certificate Revocation Lists (CRLs). The guides cover critical operations such as importing data from PEM or DER formats, creating certificate collections, and performing complex queries using match parameters. Designed for software engineers and security developers, these documents require a basic understanding of Cangjie syntax and cryptographic principles to effectively implement certificate validation and management logic in their applications. By following these steps, developers can ensure robust security features are integrated into their systems.

## Detailed Description

The files below offer specific guidance on utilizing the framework's capabilities to handle cryptographic objects efficiently.

### 开发步骤_1.md
This document provides a step-by-step tutorial for managing X509 certificates and Certificate Revocation Lists (CRLs) using the DeviceCertificateKit in the Cangjie programming language. It covers importing the framework, creating certificate and CRL objects from data, establishing a CertCRLCollection, and querying specific items using match parameters. The guide includes Cangjie code examples demonstrating how to instantiate X509Cert and X509CRL from PEM or DER formats, handle business exceptions, and utilize selection methods. Targeted at developers implementing certificate validation and management logic, this guide requires prerequisite knowledge of Cangjie syntax and cryptographic concepts.

### 开发步骤_2.md
This document provides a code example demonstrating how to create and query a collection of X.509 certificates and Certificate Revocation Lists (CRLs). It covers creating certificate and CRL objects from PEM data, initializing a collection, and using match parameters to filter selection based on validity dates or specific certificates. Key takeaways include the usage of `createCertCRLCollection`, `selectCerts`, and `selectCRLs` functions, along with error handling patterns using `BusinessException`. This tutorial is intended for developers implementing security features who need to manage and verify digital certificates programmatically.
