This directory provides essential API reference documentation for the `DatagramSocket` interface within the Cangjie programming language's standard library. It focuses on packet-based network communication, specifically detailing the implementation of connectionless protocols like UDP. The documentation covers the structural definition of the socket interface, its inheritance hierarchy from Resource and ToString, and essential properties such as local and remote addresses. Furthermore, it provides in-depth technical specifications for blocking data transmission functions, including `receiveFrom` and `sendTo`, along with parameter types, return values, and exception handling strategies for socket errors and timeouts. This resource is indispensable for Cangjie developers and network engineers looking to implement robust, low-level networking solutions, manage socket lifecycles, and handle data flow with precision.
