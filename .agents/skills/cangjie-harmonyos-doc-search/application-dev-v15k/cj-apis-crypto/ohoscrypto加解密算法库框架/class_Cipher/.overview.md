# class_Cipher

This directory contains API reference documentation for the Cangjie Cipher class within the CryptoFramework. It covers the implementation of symmetric and asymmetric encryption and decryption operations. Key topics include the class overview, initialization methods, segmented data processing via `update`, finalizing operations with `doFinal`, and managing cipher specifications for algorithms like RSA and SM2. The documentation details parameters, return values, exceptions, and usage examples. It is suitable for Cangjie developers and software engineers implementing cryptographic security features and managing data processing flows in their applications.

## Detailed Description

### class_Cipher_3more.md class_Cipher_3more.md
This API reference document details the Cangjie Cipher class, which provides functionality for symmetric and asymmetric encryption and decryption operations. The documentation covers the class overview, the read-only algName property, and the init method used to initialize the cipher with a specific mode, key, and parameters. Key information includes the distinction between symmetric and asymmetric workflows, where init is mandatory, update is optional for symmetric algorithms but unsupported for RSA or SM2, and doFinal is required to complete the operation. It also lists parameters, exceptions, and provides a usage example. This guide is intended for Cangjie developers implementing cryptographic security features within the CryptoFramework.

### func_doFinalDataBlob.md func_doFinalDataBlob.md
This API documentation details the doFinal function for finalizing encryption and decryption operations within the Cangjie CryptoArchitectureKit. The document covers the function's signature, specific behaviors for symmetric and asymmetric algorithms, parameter descriptions, return values, and potential exceptions. Key information includes that doFinal processes remaining data, handles authentication tags for GCM and CCM modes, and resets the Cipher instance state, necessitating re-initialization for subsequent operations. This reference guide targets software developers implementing cryptographic operations in Cangjie who need to manage data processing flows and handle security exceptions.

### func_getCipherSpecCipherSp_2more.md func_getCipherSpecCipherSp_2more.md
This document serves as API reference documentation for managing cipher parameters within the Cangjie CryptoArchitectureKit. It details two primary functions: getCipherSpec for retrieving encryption parameters and setCipherSpec for configuring them, specifically supporting RSA and SM2 algorithms. Key information includes function signatures, parameter types like CipherSpecItem and Array<UInt8>, return values, and specific error codes for handling exceptions such as invalid parameters or memory errors. Targeted at developers implementing cryptographic operations, this guide requires knowledge of Cangjie syntax and cryptographic concepts like OAEP padding.

### func_updateDataBlob.md func_updateDataBlob.md
This API reference document details the `update` function for performing segmented encryption or decryption operations within the CryptoFramework. It covers the function signature, prerequisites, parameter descriptions, return values, and potential exceptions. The function requires a prior `init` call and supports large data via multiple calls. Crucially, it explains behavior differences between block modes (like ECB/CBC) and stream modes, advising developers to concatenate results from `update` and `doFinal`. It explicitly notes that RSA and SM2 asymmetric operations are unsupported. This guide targets software developers implementing cryptographic algorithms in Cangjie who need to handle data processing in chunks.
