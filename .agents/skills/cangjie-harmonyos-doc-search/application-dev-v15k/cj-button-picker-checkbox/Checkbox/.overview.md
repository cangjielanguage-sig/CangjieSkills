# Checkbox

This directory contains comprehensive documentation for the Checkbox component within the ArkUI framework, specifically designed for the Cangjie language. It covers the fundamental API reference, component properties, event handling, and practical code examples for implementing toggle controls. Key topics include component initialization, custom styling (shapes, colors, indicators), and state management using `onChange` events. This resource is suitable for HarmonyOS application developers and UI engineers who need to integrate or customize checkbox functionality in their user interfaces.

## Detailed Description

### Checkbox_4more.md Checkbox_4more.md
This document serves as API reference documentation for the Checkbox component within the ArkUI framework, detailing its usage for toggling options on or off. The primary section covers the component initialization method, specifically explaining parameters such as name, group for associating with CheckboxGroup, and indicatorBuilder for defining custom selected styles. Key information includes support for all universal attributes and events, system capability requirements starting from version 12, and the integration of the @Builder macro for custom UI descriptions. This technical reference is intended for developers using the Cangjie language to construct user interfaces.

### 示例代码.md 示例代码.md
This document provides Cangjie code examples demonstrating various styling and configuration options for the Checkbox UI component. It covers three specific scenarios: setting checkbox shapes like Circle and Rounded Square, customizing the check mark appearance using properties such as stroke color and size, and implementing custom text-based indicators via indicatorBuilder. Key takeaways include the usage of CheckBoxShape, the mark modifier, and event handling with onChange. This guide targets application developers using the Cangjie language for HarmonyOS development who need to implement or customize checkbox controls in their user interfaces.

### 组件事件_2more.md 组件事件_2more.md
This document provides API reference documentation for component events and configuration classes within the ArkUI framework using the Cangjie language. It details the onChange event handler, which triggers a callback with a boolean status upon selection changes, and the CheckBoxConfiguration class definition. Key information includes the class properties for name, selected state, and trigger functions, alongside their respective constructors and version requirements. This technical reference is intended for developers implementing checkbox interactions and state management in HarmonyOS applications.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring the properties of a CheckBox component within the ArkUI framework using the Cangjie language. It details specific methods including mark, select, selectedColor, shape, and unselectedColor. Each function entry provides the signature, system capability, start version, and a parameter table defining types, requirements, and default values. Key features include customizing the check mark's style, toggling selection state, and defining colors for selected and unselected states. The target audience is software developers utilizing the ArkUI framework who need to implement and style checkbox controls in their applications.
