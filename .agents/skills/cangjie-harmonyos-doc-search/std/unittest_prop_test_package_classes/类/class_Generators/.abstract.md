This directory provides essential API documentation for the `Generators` class and related static utilities in the Cangjie programming language. It serves as a guide for developers implementing property-based tests, offering detailed instructions on creating and manipulating custom value generators. Key topics include range-based generation, random array selection, lookup operations, and output transformation. The documentation explains how to leverage `RandomSource`, bounds, and closures to produce `Generator` objects that support generic types and constraints. Whether you need to combine arbitrary types or control selection logic, this resource equips developers with the knowledge to define flexible and robust data creation strategies for testing scenarios.
