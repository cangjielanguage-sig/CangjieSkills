This directory contains API reference documentation for the `UiWindow` class within the Cangjie language TestKit framework. It covers comprehensive window management capabilities for UI test automation, including retrieving properties (title, bounds, focus), manipulating window states (maximize, minimize, resize), and handling device-specific behaviors like split-screen mode. The documentation includes function signatures, return values, and exception handling for `BusinessException` errors. It is suitable for software developers and QA engineers using Cangjie to automate UI interactions across tablets and mobile devices.
