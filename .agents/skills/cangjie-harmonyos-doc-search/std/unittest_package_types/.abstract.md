This directory serves as a comprehensive API reference repository for a unit testing package, specifically focusing on the type definitions that underpin the framework's architecture. It primarily documents the `MeasurementUnitTable`, a critical type alias designed to handle the complexities of unit conversion within performance testing environments. By defining a structure that maps numerical boundaries—represented as Float64 values—to descriptive unit strings, this type allows developers to seamlessly normalize metrics, such as converting raw nanoseconds into human-readable seconds. This documentation is essential for software developers, QA engineers, and system architects who are integrating or extending the testing framework, providing them with the necessary understanding of how performance data is typed, processed, and displayed to ensure accurate and consistent reporting across different test scenarios.
