# 基于shell命令测试

This directory contains technical guides for performing automated testing on HarmonyOS devices using shell commands via the hdc tool. It covers essential operations like retrieving version information, simulating UI interactions (touch, swipe, input), and capturing device states (screenshots, layout dumps). The documentation details command syntax, JSON schemas for event recording, and prerequisites such as developer mode and APL levels. It is suitable for developers and QA engineers looking to implement command-line driven testing workflows.

## Detailed Description

### 基于shell命令测试_4more.md 基于shell命令测试_4more.md
This technical guide provides instructions for using shell commands via the hdc tool to perform automated testing tasks on HarmonyOS devices. The document covers a comprehensive command list table, usage examples for screenshots and layout dumping, and a detailed explanation of the user recording operation data structure. Key information includes commands like screenCap, dumpLayout, uiRecord, and uiInput, along with parameters for file paths and attribute filtering. It also defines the JSON schema for recorded touch events, detailing fields for coordinates, gesture types, and control hierarchy. Intended for developers requiring quick testing workflows, this guide assumes prior configuration of HDC environment variables.

### 注入UI模拟操作.md 注入UI模拟操作.md
This document serves as a technical reference for using the `hdc shell uitest uiInput` command to simulate various user interface interactions on a device. It details specific commands for touch gestures (click, doubleClick, longClick), motion actions (fling, swipe, drag, dircFling), text input, and hardware key events. Each command section defines required parameters (e.g., coordinates, text) and optional settings (e.g., velocity, step length), accompanied by practical shell execution examples. Intended for developers or QA engineers performing automated UI testing, this guide requires knowledge of command-line interfaces and coordinate systems.

### 获取版本信息_2more.md 获取版本信息_2more.md
This technical reference document provides commands for retrieving UITest version information and initiating the testing daemon. It covers two primary operations: checking the version using hdc shell uitest --version and starting the process with hdc shell uitest start-daemon. Key information includes critical prerequisites such as enabling developer mode on the device. The document specifies that only processes launched via the aa test command possess the capability to invoke UITest interfaces, unlike those started with aa start. Additionally, the test HAP requires an APL level of system_basic or normal. This guide targets developers and QA engineers setting up automated UI testing environments.
