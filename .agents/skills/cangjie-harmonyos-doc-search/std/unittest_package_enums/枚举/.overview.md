This directory serves as a comprehensive repository for API reference documentation regarding enumeration types within the Cangjie testing framework. It specifically details enumerations that govern garbage collection behavior, define precise time measurement units, and categorize CPU performance counters. These enums are critical components that grant developers granular control over memory management, timing operations, and system-level profiling during complex benchmarking and testing scenarios. By defining specific states and metrics, these enumerations facilitate the creation of robust performance analysis tools and highly accurate unit tests. This documentation is primarily suitable for Cangjie developers and QA engineers who require low-level access to hardware metrics and runtime configurations to optimize application performance and validate system behavior under various load conditions.

## Detailed Description

This section provides in-depth details for each enumeration file included in the directory.

### enum_ExplicitGcType_2more.md enum_ExplicitGcType_2more.md

This API reference document defines two enumeration types for the Cangjie testing framework: ExplicitGcType and TimeUnit. The ExplicitGcType enum configures explicit garbage collection behavior within the @Configure macro, offering options to disable GC or trigger heavy or light collection during performance tests. The TimeUnit enum specifies time measurement units like seconds, milliseconds, microseconds, and nanoseconds for use with the TimeNow constructor. Both enums inherit from the ToString interface to provide string representations. This documentation targets developers implementing benchmarks or unit tests who need precise control over memory management and time measurement.

### enum_PerfCounter.md enum_PerfCounter.md

This API reference document defines the PerfCounter enum, which specifies the CPU performance counters supported by the Perf constructor in the Cangjie language. The content categorizes counters into hardware metrics (like CPU cycles, cache references, and branch misses) and software metrics (like page faults, context switches, and CPU migrations). It also documents the inherited toString method for string conversion. Key information includes the mapping of these enum values to the Linux kernel perf_event_open system call types, enabling low-level performance monitoring. This documentation targets Cangjie developers implementing performance analysis tools who require knowledge of system-level profiling concepts.
