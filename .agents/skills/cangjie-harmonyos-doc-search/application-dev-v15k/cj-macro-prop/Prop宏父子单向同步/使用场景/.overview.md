# 使用场景

This directory contains technical guides and tutorials focused on state management and data synchronization scenarios within the Cangjie ArkUI framework. It covers various implementations of the @Prop decorator, ranging from simple data type synchronization to complex nested object management and array handling. Key topics include unidirectional data flow, the @Observed decorator, and change detection mechanisms. These resources are suitable for developers building HarmonyOS applications who need to understand how to effectively propagate state changes between parent and child components.

## Detailed Description

### Prop嵌套场景.md
This document serves as a technical guide for implementing nested object state management using the @Prop decorator in the Cangjie ArkUI framework. It illustrates the necessary data structure definitions, component hierarchy, and event handling required to propagate changes through multi-level objects. The key takeaway is that in nested scenarios, every class layer must be decorated with @Observed and received via @Prop to ensure the UI correctly perceives and updates upon data changes. This tutorial is intended for developers seeking to manage complex state dependencies within their application components.

### 从父组件中的State类对象属性到Prop简单类型的_2more.md
This tutorial demonstrates how to synchronize data from a parent component's @State decorated class objects to a child component's @Prop properties in ArkUI using the Cangjie language. It covers two primary scenarios: syncing a single class object property and syncing items within an @State array. Key takeaways include the necessity of using the @Observed decorator on classes and @Publish on specific properties to enable change detection. The document also introduces ObservedArrayList for managing arrays of observable objects, explaining how opaque proxy objects notify @Prop of internal updates. This guide is intended for ArkUI developers familiar with Cangjie who need to implement complex state management involving reference types.

### 父组件State到子组件Prop简单数据类型同步.md
This tutorial demonstrates one-way data synchronization from a parent component's @State variable to a child component's @Prop variable using simple data types in Cangjie. The document presents a code example involving a countdown game to illustrate initialization, re-rendering triggers, and unidirectional data flow. Key takeaways include that parent state changes automatically update child props, but modifications to the child's prop do not sync back to the parent and are overwritten upon subsequent parent updates. This guide is intended for developers learning component state management and data binding in the Cangjie UI framework.

### 父组件State数组项到子组件Prop简单数据类型同步.md
This tutorial illustrates the data synchronization mechanism between a parent component's @State array and a child component's @Prop variable in the Cangjie UI framework. It covers code implementation, local variable initialization, and the behavior of UI updates when the parent array is modified. Key takeaways include that @Prop creates a local copy of the array item, preventing child modifications from syncing back to the parent. Additionally, the document explains how replacing the entire parent array affects rendering, highlighting that direct bindings may not update, while ForEach reuses component instances based on diff algorithms, preserving local state for matching items. This guide is intended for developers building HarmonyOS applications using Cangjie.
