# cj-apis-element_name

This directory provides comprehensive API reference documentation for the `ElementName` class, a fundamental component within the Cangjie language's `ohos.element_name` module. It is designed to assist HarmonyOS developers in understanding the data structures required to uniquely identify application components across the operating system's distributed architecture. The documentation covers essential properties such as `deviceId`, `bundleName`, `abilityName`, and `moduleName`, offering clear guidance on how to configure these parameters. It details the class constructor, distinguishing between mandatory arguments like `bundleName` and `abilityName`, and optional named parameters such as `deviceId` and `moduleName`. Additionally, the document outlines necessary system capabilities and notes the module's current Beta status. This resource is crucial for developers looking to implement cross-device functionality or reference specific abilities within their HarmonyOS applications using the Cangjie programming language.
