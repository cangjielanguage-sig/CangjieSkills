This directory provides comprehensive documentation for managing network connections in the Cangjie development environment, specifically utilizing the NetworkKit. It covers essential topics such as domain name resolution, network state monitoring, capability querying, and connection migration. Key concepts include NetHandle objects, permission management (like `ohos.permission.INTERNET`), and handling network transitions between WiFi, cellular, and Ethernet. This resource is designed for Cangjie developers and application engineers seeking to build robust, network-aware applications with resilient connectivity and real-time status updates.
