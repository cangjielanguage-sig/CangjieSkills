# cj-uiability-launch-type

本目录主要介绍HarmonyOS应用开发中UIAbility组件的启动模式配置与管理。内容涵盖了单实例和多实例两种核心模式，详细解析了它们在实例创建、生命周期回调（如onNewWant）以及最近任务列表中的表现差异。通过本目录，开发者可以学习如何在module.json5文件中配置launchType字段，以根据业务需求精准控制UIAbility的生命周期和呈现状态。本文档适合HarmonyOS应用开发者阅读，旨在优化应用架构和用户体验。

## 详细说明

### cj-uiability-launch-type.md cj-uiability-launch-type.md
本文档旨在阐述UIAbility组件的启动模式及其配置方法。文档重点介绍了singleton（单实例）和multiton（多实例）两种模式，详细说明了它们在实例创建、生命周期回调（如onNewWant）及最近任务列表表现上的差异。关键信息包括singleton模式复用现有实例而multiton模式每次创建新实例，以及如何在module.json5文件中通过launchType字段进行配置。本文面向HarmonyOS应用开发者，旨在帮助其根据业务需求管理UIAbility实例的生命周期和呈现状态。
