# cj-apis-uicontext-router

This directory acts as a central hub for API documentation regarding the UIContext Router module, specifically engineered for the Cangjie programming language within the ArkUI framework. It comprehensively addresses the requirements of page navigation management, guiding developers through the processes of accessing URLs, navigating to specific pages, replacing the current page context, and returning to previous or specified pages. The documentation meticulously details the necessary setup, including how to obtain the Router object via `getRouter()` from UIContext and the required imports such as `kit.ArkUI.*`. Furthermore, it provides references for essential Router class methods like `pushUrl` and `back`, as well as state management classes like `RouterState` and `RouterMode`. This resource is ideally suited for application developers who are looking to implement robust routing logic, facilitate state transfer, and achieve precise navigation control in their UI applications.

## Detailed Description

### Router/
This directory provides comprehensive API documentation for the Router module within ArkUI applications, specifically designed for the Cangjie language. It covers the essential aspects of page navigation management, including accessing URLs, jumping to specific pages, replacing the current page, and returning to previous or specified pages. The documentation details the necessary setup, such as obtaining the Router object via `getRouter()` from UIContext and importing `kit.ArkUI.*`. It also includes references for the Router class methods like `pushUrl` and `back`, as well as state management classes like `RouterState` and `RouterMode`. This resource is suitable for application developers seeking to implement robust routing logic, state transfer, and navigation control in their UI applications.
