This directory contains API reference documentation for the `AVCastController` class in the Cangjie programming language. It focuses on managing audio-video casting sessions, enabling developers to control remote playback, handle events, and manage DRM media keys. The documentation covers essential functionalities such as retrieving playback state, subscribing to event listeners, sending control commands, and managing the controller lifecycle. It is designed for developers implementing multimedia casting features using the SystemCapability.Multimedia.AVSession.Core framework.
