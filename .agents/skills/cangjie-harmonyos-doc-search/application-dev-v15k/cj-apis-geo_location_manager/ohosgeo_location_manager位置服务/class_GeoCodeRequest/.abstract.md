This directory contains comprehensive API reference documentation for the `GeoCodeRequest` class within the Cangjie programming language. It focuses on defining the parameters and structure required for constructing geocoding requests, which are essential for converting textual addresses into geographic coordinates. Key technical aspects covered include the use of ISO 3166-1 alpha-2 country codes, support for the WGS84 coordinate system, and the configuration of geographic bounding boxes. The documentation details properties such as `maxItems`, `locale`, and coordinate boundaries, explaining how to filter results effectively. This resource is specifically designed for developers working on location services who need to implement precise geocoding functionality with robust filtering capabilities and localization support.
