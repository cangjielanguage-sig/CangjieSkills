This directory contains the API reference documentation for the Cangjie programming language's Timer class, located within the standard library's synchronization package. It covers the comprehensive functionality required to execute tasks at specific times or intervals, including one-shot and repeating schedules. Key topics include thread management, task lifecycle, exception handling, and catch-up strategies. The documentation details static initialization methods like `once`, `repeat`, and `after`, alongside instance control methods such as `cancel`. This resource is suitable for Cangjie developers implementing asynchronous logic, concurrent programming, and precise time-based operations in their applications.
