This directory provides comprehensive resources for implementing image encoding using the ImagePacker module in the Cangjie language. It details how to convert PixelMap images into various formats such as JPEG, WebP, PNG, and HEIF for efficient storage and transmission. The documentation covers essential concepts, API definitions, and practical implementation steps, including configuration of packing options and handling of data streams or files. Designed for Cangjie developers, these guides facilitate the integration of image processing capabilities into applications through template projects and specific code examples. The content addresses both theoretical definitions and hardware-dependent considerations to ensure robust application performance.
