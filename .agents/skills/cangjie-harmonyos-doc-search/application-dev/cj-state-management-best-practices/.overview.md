# cj-state-management-best-practices

This directory serves as a comprehensive resource for developers utilizing the Cangjie language within the ArkUI framework, specifically focusing on state management best practices. It provides an in-depth exploration of performance optimization techniques designed to significantly minimize unnecessary component re-renders and reduce overall execution overhead. The content covers critical technical areas, including controlling component associations for complex state objects, optimizing loop logic by minimizing state variable reads, and leveraging temporary variables for efficient data calculations. Additionally, it addresses the implementation of correct UI update mechanisms by avoiding dummy triggers. This guide is highly suitable for ArkUI developers seeking to enhance application quality and rendering efficiency through the mastery of efficient state variable usage and advanced optimization strategies. By following these guidelines, developers can ensure their applications remain responsive and efficient.

### 状态管理优秀实践/

This directory focuses on best practices for state management in ArkUI application development using the Cangjie language. Key topics include controlling component associations for complex state objects, optimizing loop logic by minimizing state variable reads, and using temporary variables for data calculations. This guide is suitable for ArkUI developers seeking to enhance application quality and rendering efficiency through efficient state variable usage.
