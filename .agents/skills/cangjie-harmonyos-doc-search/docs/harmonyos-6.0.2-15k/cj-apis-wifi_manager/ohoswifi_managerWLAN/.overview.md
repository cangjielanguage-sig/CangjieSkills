# ohoswifi_managerWLAN

This directory contains API reference documentation for the HarmonyOS WLAN module, specifically designed for the Cangjie programming language. It covers comprehensive WiFi management functionalities including Station (STA) mode, Peer-to-Peer (P2P) connections, network configuration, and event handling. Key components include data structures for IP information, device configurations, security types, and callback mechanisms for asynchronous events. This documentation is intended for software developers and system engineers building connectivity features in HarmonyOS applications, providing the necessary schemas and function signatures to implement robust WiFi networking, scanning, and state monitoring capabilities.

## Detailed Description

### class_WifiDeviceConfig/
This directory provides comprehensive API reference documentation for the `WifiDeviceConfig` class in the Cangjie programming language. It covers the configuration of WiFi station (STA) connections, including mandatory parameters like SSID and security types, as well as optional settings for BSSID, hidden networks, and advanced authentication protocols such as EAP and WAPI. The documents detail validation rules for key lengths, default values, and object serialization. This resource is suitable for developers working on network connectivity who need to implement robust WiFi configurations using the SystemCapability.Communication.WiFi.STA capability.

### class_WifiEapConfig/
This directory contains comprehensive API reference documentation for the `WifiEapConfig` class within the Cangjie language framework. It focuses specifically on the configuration parameters required for Extensible Authentication Protocol (EAP) in WiFi networks. The documentation covers essential aspects such as authentication methods (including PEAP and TLS), user identity credentials, password management, and detailed certificate handling. It also outlines system capability dependencies, specifically requiring WiFi STA support, and notes version compatibility starting from version 19. This resource is primarily designed for software developers and system engineers who are implementing secure WiFi connectivity features and need precise technical specifications for network security protocols and data structures.

### class_WifiLinkedInfo/
This directory contains API reference documentation for the `WifiLinkedInfo` class within the Cangjie programming language environment. It is designed to assist developers in accessing detailed information regarding the current WLAN connection status and network properties. The content covers a wide array of read-only properties, including SSID, BSSID, signal strength (RSSI), frequency, IP address, and link speeds, as well as specific WiFi capabilities and standards. This documentation is essential for developers implementing network connectivity features, specifically those requiring the SystemCapability.Communication.WiFi.STA capability. It serves as a guide for integrating WiFi Station features starting from API version 19, enabling the display and management of real-time WiFi metrics and configurations effectively.
