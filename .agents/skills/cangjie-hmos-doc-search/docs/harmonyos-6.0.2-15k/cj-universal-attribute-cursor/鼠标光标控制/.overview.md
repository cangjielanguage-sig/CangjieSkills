# 鼠标光标控制

This directory focuses on mouse cursor control within the Cangjie ArkUI framework for HarmonyOS development. It covers the `CursorControl` class, its methods for setting and restoring cursor styles, and the `PointerStyle` enum for defining specific cursor appearances. The content includes practical code examples demonstrating dynamic cursor manipulation based on user interactions like hovering and clicking. It is suitable for Cangjie developers and UI designers looking to enhance user experience through custom pointer behaviors and visual feedback in their applications.

### 鼠标光标控制_2more.md 鼠标光标控制_2more.md
This document serves as API reference documentation for managing mouse cursor display styles within the Cangjie ArkUI framework. It details the `CursorControl` class, specifically focusing on its static methods `setCursor` and `restoreDefault`. Key information includes that `setCursor` accepts a `PointerStyle` parameter to modify the cursor, while `restoreDefault` resets it to the standard arrow. Both functions require SystemCapability.ArkUI.ArkUI.Full and are available starting from version 19. This guide targets Cangjie developers implementing custom cursor behaviors in graphical user interfaces.
