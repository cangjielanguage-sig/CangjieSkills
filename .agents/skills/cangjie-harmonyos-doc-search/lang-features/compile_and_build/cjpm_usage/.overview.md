# cjpm_usage

This directory serves as a comprehensive guide for the Cangjie language's official project management tool, `cjpm`. It is designed to help developers understand the tool's role as a unified compilation entry point and a robust dependency management system. The content covers essential concepts such as automatic dependency resolution, custom build processes, and the practical use of command-line tools for project initialization and building. Additionally, it provides detailed instructions on configuring the `cjpm.toml` file to handle single-module projects and complex workspaces. This documentation is suitable for Cangjie language developers of all levels who wish to streamline their development workflow, manage dependencies effectively, and gain a deep understanding of build configuration options. It acts as a vital resource for ensuring project stability and build efficiency.

## Detailed Description

### cjpm_介绍/

This subdirectory acts as the central repository for documentation regarding `cjpm`, the official project management tool designed specifically for the Cangjie language. The content provided here is essential for understanding how `cjpm` functions as a unified compilation entry point and a sophisticated dependency management system. It delves into the core concepts that drive the tool, including the mechanisms behind automatic dependency management and the flexibility offered by custom build processes. By mastering these concepts, developers can significantly improve their workflow efficiency.

Beyond theoretical concepts, the documentation offers practical guidance on utilizing the command-line tool to execute critical operations such as project initialization (`init`) and building (`build`). It provides an in-depth analysis of the `cjpm.toml` configuration file, which is the heart of project setup. The text explains how to configure this file for various scenarios, distinguishing between single-module setups and more complex workspace configurations. It also covers the management of different dependency types and the adjustment of compilation options. These resources are curated for Cangjie language developers, aiming to help them quickly master project management and build configuration, making it an indispensable reference guide throughout the development lifecycle.
