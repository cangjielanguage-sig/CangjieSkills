This directory provides comprehensive API reference documentation for the `ohos.raw_file_descriptor` module within the Cangjie programming language ecosystem. It specifically addresses the data structures required to represent raw file descriptor information, which is crucial for low-level file handling in HarmonyOS development. The content covers essential aspects such as module import procedures, application context usage, and the specific definition of the `RawFileDescriptor` class. Key technical details include the class's public properties: `fd` (file descriptor), `offset` (start offset), and `length` (file size), all linked to the SystemCapability.Global.ResourceManager. This documentation is primarily intended for Cangjie developers involved in resource management who need to access raw file data contained within HAP packages using version 22 APIs. It serves as a critical resource for understanding how to interact with system-level file resources efficiently and correctly in the HarmonyOS environment, ensuring proper integration with the system's global resource manager capabilities.
