This directory contains comprehensive documentation for the TextPicker component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of sliding selectors for text content, including API references for constructors, event callbacks, type definitions, and property configurations. The content also provides practical code examples for styling and interaction. Suitable for HarmonyOS developers and UI engineers, this resource guides users in integrating and customizing text selection mechanisms in their applications using Cangjie syntax and ArkUI structures.
