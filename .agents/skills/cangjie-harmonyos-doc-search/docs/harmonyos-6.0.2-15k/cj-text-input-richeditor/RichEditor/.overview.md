# RichEditor

This directory contains comprehensive documentation and resources for the RichEditor component within the ArkUI framework, specifically designed for HarmonyOS application development using the Cangjie language. It covers the implementation of mixed graphics and text layouts, interactive editing capabilities, and detailed API references for component attributes, events, and fundamental data types. Developers will find specifications for text manipulation, image spans, paragraph styles, and event handling. This resource is suitable for software engineers and UI developers seeking to integrate advanced rich text editing features and customize user interactions in their applications.

## Detailed Description

### RichEditor_4more.md RichEditor_4more.md
This document serves as API reference documentation for the RichEditor component, designed to support mixed graphics and text layout alongside interactive editing. The primary sections cover component creation, specifically the init method which requires a RichEditorController parameter, and details regarding general attributes and events. Key information includes system capability requirements, version 12 compatibility, and specific attribute limitations such as restricted alignment options and unsupported borderImage properties. Intended for developers working within the ArkUI framework, this technical guide provides the necessary specifications to implement and configure rich text editing interfaces effectively.

### 示例代码.md 示例代码.md
This document provides a practical Cangjie code example demonstrating the implementation and configuration of the RichEditor component in a HarmonyOS application. It covers controller methods for caret management, adding text and image spans with specific styles, retrieving span data, updating paragraph styles, and implementing custom keyboards and selection menus. The code illustrates event handling for editor states like readiness, deletion, and selection, utilizing the RichEditorController to manipulate content programmatically. This example is intended for developers building UIs with the Cangjie language who need to integrate rich text editing capabilities.
