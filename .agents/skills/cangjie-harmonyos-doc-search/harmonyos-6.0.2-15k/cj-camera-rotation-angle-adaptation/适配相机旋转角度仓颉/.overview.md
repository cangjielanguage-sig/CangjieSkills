# 适配相机旋转角度仓颉

This directory focuses on adapting camera rotation angles using the Cangjie programming language within the HarmonyOS ecosystem. It covers essential techniques for handling video recording orientation, calculating device rotation via sensors, and synchronizing camera previews with display states. Key topics include `VideoOutput`, sensor data processing, `CameraManager`, and `PreviewOutput`. These resources are designed for application developers working on multimedia features who need to ensure correct image and video alignment across different device orientations.

## Detailed Description

### 录像.md 录像.md
This technical guide instructs developers on how to configure video rotation for recording sessions within a multimedia framework. It details the process of retrieving video rotation angles using the VideoOutput class and setting the metadata orientation. Key information includes calling the getVideoRotation function with the device degree parameter after the commitConfig method is executed, and writing the result to AVMetadata.videoOrientation. The document provides a Cangjie code example and references a broader development guide for remaining parameters. Intended for developers managing camera output streams, this guide requires prior session creation and knowledge of device orientation calculation.

### 计算设备旋转角度.md 计算设备旋转角度.md
This technical guide demonstrates how to calculate a device's rotation angle using sensor data in the Cangjie programming language. The document covers prerequisite permissions, sensor data retrieval via the once API, and mathematical calculation logic using atan2. Key information includes a fallback mechanism that prefers the Gravity sensor but defaults to the Accelerometer if unavailable, normalizing the result to a 0-360 degree range. Intended for application developers working with hardware sensors, this tutorial provides complete code examples for implementing orientation detection in HarmonyOS applications.

### 适配相机旋转角度仓颉_2more.md 适配相机旋转角度仓颉_2more.md
This development guide instructs developers on how to adapt camera rotation angles for various display states using the Cangjie language. It covers session creation, preview adaptation based on screen rotation, and photo or video adaptation based on device gravity. Key information includes using the CameraManager class to create sessions with specific SceneModes like NORMAL_PHOTO or NORMAL_VIDEO. The document highlights that preview rotation correlates with Display.rotation, whereas capture functions rely on device orientation. This tutorial targets application developers working with multimedia camera features who need to ensure correct image orientation across different device states.

### 预览/
This directory serves as a comprehensive technical resource for developers working on camera preview functionality, specifically focusing on the complexities of output rotation and display orientation synchronization. It provides essential guidance on using the CameraKit framework to manage how camera previews are rendered relative to the device's screen orientation. The documentation covers critical APIs such as `PreviewOutput.getPreviewRotation` and `PreviewOutput.setPreviewRotation`, alongside practical implementation strategies for handling dynamic rotation events. Additionally, it addresses configuration constraints like the `commitConfig` sequence and the `isDisplayLocked` parameter. This material is highly suitable for mobile application developers using Cangjie or ArkTS who need to ensure their camera apps provide a seamless and correctly oriented visual experience for users across different device states.
