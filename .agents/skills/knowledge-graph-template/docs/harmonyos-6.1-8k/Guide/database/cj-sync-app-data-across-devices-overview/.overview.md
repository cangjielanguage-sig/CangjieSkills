# cj-sync-app-data-across-devices-overview

本文档旨在全面概述同应用跨设备数据同步功能，为开发者在可信设备间实现高效的数据同步、修改与查询提供指导。内容深入涵盖了应用场景介绍、核心基本概念以及严格的访问控制机制。文档特别强调了技术选型的重要性，指导开发者根据数据生命周期在分布式数据对象与数据库（包括关系型和键值型）之间做出正确选择，并明确指出系统仅支持最终一致性而非强一致性。本文档非常适合分布式应用开发者阅读，旨在帮助其理解数据同步的技术细节及一致性约束。核心关键词包括分布式数据、数据同步、最终一致性、访问控制。

## Detailed Description

### cj-sync-app-data-across-devices-overview.md

本文档旨在概述同应用跨设备数据同步功能，指导开发者在可信设备间实现数据的同步、修改与查询。文档涵盖了场景介绍、基本概念及访问控制机制三大板块。关键信息包括根据数据生命周期选择分布式数据对象或数据库（关系型/键值型），以及明确系统仅支持最终一致性而非强一致性。本文档面向分布式应用开发者，提供了数据同步的技术选型和一致性约束说明。关键词涵盖分布式数据、数据同步、最终一致性、访问控制。
