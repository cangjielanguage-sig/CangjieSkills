This directory serves as a specialized technical resource for developers working within the Cangjie (cj) ecosystem, focusing specifically on the implementation of image decoding using the ImageKit framework. It provides a structured approach to handling diverse image data, centering on the `ImageSource` class to transform encoded files into usable PixelMaps for rendering or manipulation. The content covers the end-to-end process of decoding, identifying supported formats like JPEG, PNG, GIF, WebP, BMP, SVG, ICO, DNG, and HEIF. It also addresses critical performance aspects such as memory management and the handling of advanced decoding options like HDR. This guide is ideal for software engineers and application developers who require a robust understanding of image processing pipelines and format compatibility in their Cangjie-based projects.
