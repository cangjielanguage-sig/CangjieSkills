### interface_IReentrantMutex__3more.md interface_IReentrantMutex__3more.md

This API reference document defines interfaces for implementing reentrant and unique mutex locks in the Cangjie programming language. It details the deprecated IReentrantMutex, its recommended replacement Lock, and the extended UniqueLock interface. Key information includes the standard lock, tryLock, and unlock methods, where unlocking must match the lock count. UniqueLock extends Lock by adding a condition method for advanced synchronization patterns. A critical warning emphasizes that implementations must support nested locking to prevent deadlocks. This guide targets developers building synchronization primitives who require knowledge of thread blocking, reentrancy, and condition variables.
