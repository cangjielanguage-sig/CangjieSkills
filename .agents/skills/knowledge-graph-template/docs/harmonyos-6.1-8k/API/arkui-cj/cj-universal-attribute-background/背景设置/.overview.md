### func_backgroundImageSiz_1292d95e.md
本文档是ArkUI框架中backgroundImageSize函数的API参考，旨在指导开发者设置背景图片的宽度和高度。文档涵盖了函数签名、系统能力、起始版本、参数定义及返回值。关键信息显示，该函数通过width和height两个必填的命名参数（类型为?Length，初始值0.vp）来控制尺寸，并返回组件实例本身以支持链式调用。该文档面向使用仓颉语言进行ArkUI开发的工程师，适用于需要自定义背景图片尺寸的界面布局场景。关键词：ArkUI、仓颉、backgroundImageSize、API文档、组件样式。
