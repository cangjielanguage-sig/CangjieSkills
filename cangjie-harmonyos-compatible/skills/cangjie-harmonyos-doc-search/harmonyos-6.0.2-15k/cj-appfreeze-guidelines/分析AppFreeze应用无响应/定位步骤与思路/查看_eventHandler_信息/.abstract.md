This directory provides technical guides for analyzing `eventHandler` dump logs to diagnose system performance issues, specifically application freezes (appfreeze) and scheduling anomalies. It covers the interpretation of task execution times, VIP and High priority queues, and watchdog timer logs. Developers will learn how to calculate task duration, identify bottlenecks in event queues, and distinguish between application freezes and thread starvation. This resource is suitable for system developers and engineers debugging event handling, thread management, and performance optimization in ArkUI applications.
