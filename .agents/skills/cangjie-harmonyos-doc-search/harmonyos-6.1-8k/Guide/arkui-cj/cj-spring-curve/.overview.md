# cj-spring-curve

本目录主要聚焦于ArkUI框架下基于Cangjie（仓颉）语言的阻尼弹簧曲线技术文档。它深入探讨了弹簧曲线的物理运动规律，并详细阐述了四种核心接口的实现方式与应用场景。内容涵盖如何利用这些接口创建符合物理直觉、自然流畅的动画效果，特别是针对跟手交互与离手动画的无缝衔接。该文档适合正在使用Cangjie语言进行ArkUI应用开发的工程师，以及致力于提升应用交互质感与动效真实性的设计开发者阅读参考。

## 详细描述

### cj-spring-curve.md cj-spring-curve.md

本文档介绍了ArkUI中阻尼弹簧曲线的概念及其在Cangjie语言中的四种接口实现，旨在帮助开发者创建自然流畅、符合物理规律的动画效果。主要内容包括弹簧曲线的物理特性说明，以及springMotion、responsiveSpringMotion、interpolatingSpring和springCurve这四个核心接口的详细参数与适用场景。核心要点包括：springMotion和responsiveSpringMotion自动计算时长并继承速度，适合跟手与离手衔接；interpolatingSpring需指定归一化初速度；springCurve虽可指定时长但破坏物理规律，不建议使用。面向使用Cangjie语言的ArkUI开发者，适用于需要实现自然物理动效、跟手交互及避免动画突兀结束的应用开发场景。
