This directory contains API reference documentation for the `BaseScroller` class and associated scrolling functions within the Cangjie ArkUI framework. It covers the core sealed abstract base class used to manage scrolling functionality in components such as Scroll, List, Grid, and WaterFlow. Additionally, it details specific functions for programmatic navigation, including relative scrolling, edge positioning, pagination, and index-based scrolling. Key topics include inertial scrolling control, animation configuration, and performance considerations for large datasets. This documentation is suitable for ArkUI developers using the Cangjie language who need to implement custom scrolling behaviors, control scroll positions programmatically, or query component states.
