# cj-data-reliability-security-overview

This directory provides a comprehensive technical overview of data reliability and security features specifically designed for the HarmonyOS ecosystem. It focuses on the critical mechanisms required to protect application data against system failures and security breaches. The documentation covers a broad spectrum of topics, including functional scenarios, basic concepts, and operational constraints related to data management. Key areas of focus include database backup and recovery strategies, whole-file encryption utilizing the HUKS (HarmonyOS Universal Keystore System), and data classification protocols necessary for secure cross-device access. Furthermore, it details the implementation of E-class encrypted databases, which are vital for handling sensitive user information. This resource is primarily intended for HarmonyOS developers and system architects who are responsible for implementing secure data management, ensuring data integrity, and deploying effective recovery strategies in their applications to maintain user trust and system stability.

## Detailed Description

### cj-data-reliability-security-overview.md

This document provides an overview of data reliability and security features in HarmonyOS, outlining solutions for data protection against system failures. It covers functional scenarios, basic concepts, operational mechanisms, and constraints. Key topics include database backup and recovery, whole-file encryption using the HUKS system, data classification for cross-device access, and E-class encrypted databases for sensitive user information. Important takeaways are that backups are full-file and stored in the app sandbox, while encryption is automated by the system. Constraints include a maximum of five backups for key-value databases and annual key rotation. This guide is intended for HarmonyOS developers implementing secure data management and recovery strategies.
