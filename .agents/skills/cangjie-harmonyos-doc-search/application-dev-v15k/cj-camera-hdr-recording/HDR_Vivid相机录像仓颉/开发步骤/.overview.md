# 开发步骤

This directory provides a comprehensive technical guide for implementing video recording functionality, specifically focusing on HDR capabilities within the HarmonyOS ecosystem. It covers the entire development lifecycle using both the Cangjie and ArkTS programming languages. Key topics include importing necessary kits, configuring camera profiles, managing video stabilization, handling color spaces (SDR vs. HDR), and setting up the AVRecorder. The guide also details the critical steps for resource cleanup to prevent memory leaks. It is suitable for application developers looking to integrate advanced camera and multimedia features into their applications.

## Detailed Description

### 开发步骤_1.md 开发步骤_1.md
This technical guide outlines the development steps for implementing HDR video recording functionality using the Cangjie language. It covers importing required kits, retrieving preview and video profiles, checking and setting video stabilization, and configuring color spaces. Critical requirements include setting the output format to 10-bit CAMERA_FORMAT_YCRCB_P010, maintaining consistent aspect ratios between preview and video streams, and ensuring video stabilization is active. For color spaces, SDR requires BT709_LIMIT while HDR requires BT2020_HLG_LIMIT. This tutorial targets application developers working on camera features within the HarmonyOS ecosystem.

It details the logic for setting color spaces dynamically, specifically distinguishing between HDR (BT2020_HLG_LIMIT) and SDR (BT709_LIMIT) standards. Key takeaways include the specific workflow order: retrieving configurations, setting stabilization and color spaces before committing the session, and then proceeding with standard recording steps. This guide is intended for developers building camera applications who need to integrate advanced video features.
