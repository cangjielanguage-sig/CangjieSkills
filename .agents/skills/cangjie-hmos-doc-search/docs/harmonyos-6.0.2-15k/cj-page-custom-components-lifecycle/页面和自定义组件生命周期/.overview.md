# 页面和自定义组件生命周期

This directory provides a comprehensive technical guide on the lifecycle management of pages and custom components within the ArkUI framework. It covers the entire lifecycle from creation, rendering, and state management to destruction and deletion. Key topics include lifecycle callbacks (aboutToAppear, onPageShow), state variable synchronization, and memory optimization techniques. It is suitable for ArkUI and ArkTS developers seeking to master component behavior, optimize UI performance, and prevent memory leaks in their applications.

## Detailed Description

### 自定义组件的创建和渲染流程_2more.md
This technical guide details the lifecycle and rendering mechanism of custom components within the ArkUI framework. It covers the initial creation process, including member initialization and lifecycle callbacks like aboutToAppear and onDidBuild, as well as the re-rendering logic triggered by state changes. Key takeaways include that the framework creates instances, executes the build method, and maps state variables to UI components to enable efficient, minimal updates when data changes via events or storage. This document is intended for developers using ArkUI who need to understand component behavior and state management for UI optimization.

### 自定义组件监听页面声明周期.md
This document provides a code example demonstrating how to implement lifecycle monitoring for TabContent switching events within custom components using the Cangjie language. It covers defining callback classes that implement Callback1Argument to handle state changes like ON_SHOW and ON_HIDE. The tutorial details the process of registering observers using the on function in aboutToAppear and unregistering them with off in aboutToDisappear to manage memory effectively. Key takeaways include using ObserverType.OBSERVER_TAB_CONTENT_UPDATE to target specific Tabs components by ID. This guide is intended for ArkUI developers seeking to track page visibility and manage state across different component hierarchies.

### 页面和自定义组件生命周期.md
This technical guide details the lifecycle management for pages and custom components within the ArkUI framework. It distinguishes between `@Entry` decorated pages and `@Component` decorated custom units, outlining specific lifecycle interfaces for each. Key page callbacks include `onPageShow`, `onPageHide`, and `onBackPress`, while component callbacks cover `aboutToAppear`, `onDidBuild`, and `aboutToDisappear`. The document specifies execution timing and restrictions, such as avoiding state variable changes in `aboutToDisappear` to ensure stability. It targets developers needing to manage UI state and behavior during component creation, rendering, and destruction.

### 自定义组件的删除/
This directory provides a comprehensive technical overview of the deletion mechanisms and lifecycle management for custom components within the ArkUI framework. It covers critical internal processes, including the `aboutToDisappear` callback, the destruction sequence of backend and frontend nodes, and the unregistration of synchronized state variables such as `@Link` and `@Prop`. Furthermore, it details the execution order of lifecycles during various application states like page navigation, back presses, and app exit. This resource is specifically designed for ArkTS developers who need to master component state management, optimize memory usage, and prevent memory leaks in their applications. By understanding these concepts, developers can ensure robust application performance and stability while avoiding common pitfalls related to component destruction.
