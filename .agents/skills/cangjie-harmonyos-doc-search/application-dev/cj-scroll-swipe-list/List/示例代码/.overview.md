# 示例代码

This directory serves as a comprehensive practical resource for developers working with the ArkUI framework using the Cangjie programming language. It focuses specifically on the List component, offering detailed code examples that solve common UI challenges in modern application development. The content covers essential features such as tracking scroll positions to monitor user interaction, aligning items within complex multi-column grids, and implementing interactive edit modes that allow for dynamic data manipulation. By exploring properties like `onScrollIndex`, `alignListItem`, and `ObservedArrayList`, developers can learn to create responsive and user-friendly interfaces. This collection is particularly suitable for HarmonyOS developers looking to enhance the interactivity and visual structure of their applications through advanced list configurations and state management techniques. These examples are essential for mastering complex list behaviors.

### 示例1_添加滚动事件_2more.md 示例1_添加滚动事件_2more.md
This tutorial document provides Cangjie code examples for enhancing the ArkUI List component functionality. It covers two primary scenarios: implementing scroll event callbacks to track visible indices and configuring child element alignment in multi-column layouts. Key takeaways include using the onScrollIndex method to log first, last, and middle indices, and utilizing alignListItem with lanes to dynamically adjust item positioning. Intended for ArkUI developers, these examples demonstrate how to manage list interactions and visual structure effectively.

### 示例3_设置编辑模式_2more.md 示例3_设置编辑模式_2more.md

Example 3 illustrates how to toggle list item editability using a state variable, displaying a delete button that removes items from an ObservedArrayList. Example 4 demonstrates creating a horizontal list with center alignment, utilizing Scroller, chainAnimation, and edgeEffect properties.
