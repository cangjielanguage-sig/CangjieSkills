This directory contains API reference documentation for the HarmonyOS Request Agent module, specifically focusing on file upload and download operations using the Cangjie language. It covers the SystemCapability.Request.FileTransferAgent framework, providing comprehensive details on task configuration, lifecycle management, progress tracking, and error handling. Key components include classes for task and file management, enumerations for actions and states, and functions for querying and controlling transfer tasks. This documentation is suitable for Cangjie developers and software engineers building HarmonyOS or OpenHarmony applications that require robust, asynchronous file transfer capabilities with support for background execution and network constraints.
