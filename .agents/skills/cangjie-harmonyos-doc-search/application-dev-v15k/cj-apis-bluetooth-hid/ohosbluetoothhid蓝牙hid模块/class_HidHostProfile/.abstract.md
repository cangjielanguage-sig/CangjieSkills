This directory contains API reference documentation for the `HidHostProfile` class in the Cangjie language, specifically designed for managing Bluetooth Human Interface Device (HID) connections within the ConnectivityKit. It covers essential functionalities such as retrieving connected devices, checking connection states, and subscribing to or unsubscribing from connection state change events. The documentation includes details on required permissions, system capabilities, and error handling via `BusinessException`. This resource is suitable for software developers integrating Bluetooth HID features into HarmonyOS applications who are familiar with Cangjie syntax and event-driven programming.
