# 请求UI绘制帧率

This directory focuses on controlling UI rendering frame rates in HarmonyOS applications using the Cangjie language. It covers the utilization of the DisplaySync API to manage animation performance and optimize rendering efficiency. Key topics include setting expected frame rate ranges (e.g., 30 FPS, 60 FPS), managing lifecycle events, and implementing frame callbacks. This resource is suitable for Cangjie developers looking to create smooth animations or reduce power consumption by adjusting refresh rates dynamically. It provides both practical examples and architectural guidance for high-performance UI development.

### 完整示例.md 完整示例.md
This document provides a complete Cangjie code example demonstrating how to implement frame rate control using the DisplaySync API for UI animations. It covers defining callback classes for animation logic, creating DisplaySync instances with specific frame rates (30 FPS and 60 FPS), and managing their lifecycle within a UI component. This example is intended for developers using the Cangjie language and HarmonyOS UI framework who need to optimize rendering performance or create custom animations.
