The `core_package_structs` directory serves as the definitive API reference for the core data structures within the Cangjie programming language. It provides a comprehensive overview of the fundamental types that form the backbone of Cangjie development, ranging from basic collections like Arrays and Strings to specialized utilities such as Ranges, Durations, and Hashers. Beyond standard application development, this directory includes critical documentation for system-level programming, covering structures designed for C interoperability and low-level memory management. By detailing struct definitions, properties, methods, and operator overloads, it equips developers with the knowledge needed to understand type behaviors deeply. This resource is essential for Cangjie developers looking to implement custom algorithms, optimize performance, or execute Foreign Function Interface (FFI) operations with C code, making it suitable for both high-level application architects and systems programmers.
