This directory serves as a comprehensive roadmap for developers aiming to build HarmonyOS applications using the Cangjie language and the HarmonyOS SDK. It covers the full development lifecycle, starting with fundamental concepts such as application structure and Cangjie syntax, and progressing to advanced implementation using Kit-based capabilities. The content details essential domains including framework, system, media, and graphics, while also providing thorough instructions on using DevEco Studio. By organizing open capabilities through Kits like ArkUI and Network Kit, this resource helps developers understand the ecosystem's architecture. It is specifically designed for developers new to HarmonyOS who need a structured path from initial environment setup to advanced feature integration, acting as a vital prerequisite before diving into specific coding tasks.
