This directory acts as a definitive technical guide for the Cangjie convert package, focusing on the essential mechanisms of data conversion and string manipulation within the Cangjie programming ecosystem. It is designed to assist developers in understanding how to transform data types into strings and vice versa with high precision and control. The content covers the `Formattable` interface in detail and dissects the formatting syntax into four critical elements: flags, width, precision, and specifier. Readers will find specific instructions on managing output alignment, displaying numerical signs, and converting numbers to different bases such as binary, octal, and hexadecimal. It also addresses floating-point precision control for accurate decimal representation. This resource is best suited for Cangjie developers who have a foundational understanding of the language syntax and wish to leverage advanced formatting features in their applications to ensure data is presented exactly as required.
