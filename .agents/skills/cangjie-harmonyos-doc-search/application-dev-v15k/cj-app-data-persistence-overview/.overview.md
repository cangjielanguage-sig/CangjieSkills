# cj-app-data-persistence-overview

This directory provides a comprehensive technical overview of application data persistence mechanisms specifically designed for the HarmonyOS standard system. It acts as a strategic guide for developers, helping them evaluate and select the most appropriate storage solutions tailored to their application's unique requirements. The document covers the essential definition of data persistence and meticulously details three primary storage architectures: User Preferences, Key-Value (KV) Stores, and Relational Stores. It highlights critical distinctions, such as the high speed but low volume capacity of Preferences for configuration data, the non-relational, distributed nature of KV Stores ideal for version compatibility, and the complex data handling capabilities of Relational Stores using custom SQL. This resource is indispensable for HarmonyOS developers seeking to optimize data storage efficiency and ensure robust application performance across various use cases.
