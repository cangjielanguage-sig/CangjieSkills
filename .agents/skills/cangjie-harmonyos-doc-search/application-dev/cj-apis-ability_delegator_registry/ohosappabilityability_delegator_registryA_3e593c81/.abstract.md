This directory contains API reference documentation for the `ohos.app.ability.ability_delegator_registry` module in the Cangjie language, designed for the HarmonyOS testing framework. It covers classes and enums essential for managing test execution, monitoring application lifecycles (UIAbility and AbilityStage), and handling test arguments. Key components include the global registry, delegator arguments, lifecycle states, and shell command results. This documentation is suitable for developers and QA engineers using AbilityKit and TestKit to implement automated testing, runtime observation, and state management within HarmonyOS applications.
