# 完整示例

This directory provides a comprehensive collection of complete code examples designed to help developers master media playback using the AVPlayer framework in the Cangjie language for HarmonyOS. It covers a wide range of scenarios, including local file playback via URLs, file descriptors, and data sources, as well as live streaming implementations. The examples detail the setup of AVPlayer callbacks for state changes and error handling, illustrating how to manage the player lifecycle effectively. Key topics include AVPlayer initialization, StateChangeCallback usage, and UIAbility integration. These resources are specifically suitable for HarmonyOS developers who need to integrate robust audio and video playback features into their applications and require practical, ready-to-use code references.

## Detailed Description

### 完整示例_1.md
This document provides a complete Cangjie code example demonstrating how to implement audio playback with pause and resume functionality using the AVPlayer class. It covers setting up AVPlayer callbacks for state changes and errors, and illustrates three distinct methods for setting media sources: using a file system URL, using a file descriptor (fdSrc) from HAP resources, and using a data source (dataSrc) with seek support. Key takeaways include the initialization of the player context, handling state machine transitions, and the specific syntax for configuring different playback modes. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to integrate audio playback features into their applications.

### 完整示例_2.md
This document provides code examples demonstrating how to implement media playback using the AVPlayer framework, specifically focusing on local file playback via data sources and live streaming. The content covers two primary demo functions: avPlayerDataSrcNoSeekDemo for playing local sandbox files without seek capability, and avPlayerLiveDemo for streaming live content via URL. Key information includes the implementation of the StateChangeCallback class to manage the player lifecycle, handling states such as initialized, playing, and paused, and using AVDataSrcDescriptor for file access. This tutorial is intended for developers seeking to integrate audio and video playback functionality, requiring knowledge of file system operations and asynchronous state management.

### 完整示例_3.md
This document serves as a code reference for implementing AVPlayer callbacks and application lifecycle management in Cangjie. It covers three specific callback classes: one for reading file data without seeking, another for logging seek completion, and a third for handling errors by resetting the player. Additionally, it provides a MainAbility example demonstrating how to retrieve the AbilityContext during window stage creation. Key takeaways include the implementation of custom data sources and error handling logic. This guide targets developers building multimedia applications who need to integrate custom media playback logic and manage application context.
