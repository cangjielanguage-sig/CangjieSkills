This directory provides comprehensive documentation for the `hidumper` tool, a command-line utility essential for debugging and inspecting OpenHarmony and HarmonyOS system states. It covers a broad spectrum of functionalities, including retrieving system information, monitoring performance metrics like CPU and memory, and analyzing specific system services such as WindowManager and PowerManager. Additionally, it details advanced features like Inter-Process Communication (IPC) statistics and heap profiling for JavaScript and Cangjie. These guides are tailored for developers and system administrators aiming to diagnose issues, optimize resource usage, and maintain system stability.
