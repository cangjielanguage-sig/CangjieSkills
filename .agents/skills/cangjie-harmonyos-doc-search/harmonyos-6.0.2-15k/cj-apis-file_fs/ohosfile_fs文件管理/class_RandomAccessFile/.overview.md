# class_RandomAccessFile

This directory contains comprehensive API reference documentation for the `RandomAccessFile` class and its associated synchronous write functions within the Cangjie development environment. It focuses on providing developers with the tools necessary for performing random read and write operations on files, managing file descriptors, and controlling file pointers. The documentation details essential methods such as close, read, and setFilePointer, alongside specific system capability requirements. This resource is suitable for software developers and system engineers looking to implement robust file management and I/O features in their Cangjie applications, offering detailed parameter insights and practical usage examples.

### func_writeString_WriteOpti_2more.md func_writeString_WriteOpti_2more.md
This document provides API reference documentation for two overloaded synchronous write functions within the Cangjie language's file management system. It details the write(String, WriteOptions) and write(Array<Byte>, WriteOptions) methods, covering their parameters, return values, exceptions, and usage examples. Key information includes that both functions accept a data buffer and a WriteOptions object to configure write length, file offset, and encoding (UTF-8). They return the actual number of bytes written as an Int64. This reference guide targets software developers working with file I/O in Cangjie, specifically those needing granular control over data writing operations.
