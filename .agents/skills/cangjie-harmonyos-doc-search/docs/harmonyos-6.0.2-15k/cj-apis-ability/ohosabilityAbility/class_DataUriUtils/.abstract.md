This directory provides comprehensive API reference documentation for the `DataUriUtils` class, a core component of the Cangjie language designed for the HarmonyOS AbilityKit framework. It focuses on the manipulation of Uniform Resource Identifiers (URIs) by managing numeric identifiers embedded within URI paths. The documentation details essential static methods for attaching, deleting, retrieving, and updating these IDs. It includes specifications on parameters, return values, system capabilities, and error handling—specifically addressing parameter validation failures (error code 401). This resource is tailored for HarmonyOS application developers and Cangjie programmers who require robust tools for programmatically managing data URIs and resource identifiers during system runtime operations, ensuring precise control over data access and routing.
