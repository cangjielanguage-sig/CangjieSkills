This directory serves as a comprehensive resource for the `cj-universal-attribute-imageeffect` module within the Cangjie ArkUI framework. It is dedicated to providing developers with the necessary APIs and documentation to implement sophisticated visual effects and image manipulations in HarmonyOS applications. The content covers a wide array of functionalities, including color adjustments such as contrast, saturation, and hue rotation, as well as complex operations like blurring, blending, and geometric distortions. Furthermore, it delves into rendering performance optimizations, specifically off-screen rendering and shadow batching. This documentation is primarily suitable for HarmonyOS developers utilizing the Cangjie language who aim to significantly enhance the visual aesthetics and styling of their UI components.
