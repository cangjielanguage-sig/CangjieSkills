# 权限列表

This directory contains reference documentation for sensitive system permissions introduced in API version 12 for OpenHarmony and HarmonyOS. It covers specific authorization requirements, usage scopes, and restrictions for hardware access, file management, input monitoring, and system-level operations. Key topics include `system_grant` vs `user_grant` types, allowlist requirements, and device-specific constraints (e.g., 2in1 devices). This resource is suitable for application developers and enterprise engineers implementing advanced features like USB debugging, disk access, or floating windows while adhering to strict security protocols.

## Detailed Description

### ohospermissionACCESS_DDK_H_7more.md ohospermissionACCESS_DDK_H_7more.md
This reference document defines specific OpenHarmony system permissions introduced in version 12, detailing their usage scopes and authorization requirements. It covers seven permissions including ACCESS_DDK_HID, READ_PASTEBOARD, FILE_ACCESS_PERSIST, INTERCEPT_INPUT_EVENT, INPUT_MONITORING, SHORT_TERM_WRITE_IMAGEVIDEO, and READ_WRITE_USER_FILE. Key information includes allowed scenarios (often restricted to 2in1 devices or specific use cases like cloud desktops), authorization types (system_grant or user_grant), and version constraints. Notably, several permissions are exclusive to 2in1 devices or require allowlisting. This guide targets OpenHarmony application developers needing to implement hardware access, clipboard reading, file management, or input monitoring features.

### ohospermissionACCESS_DISK__9more.md ohospermissionACCESS_DISK__9more.md
This reference document defines sensitive HarmonyOS permissions available starting from API version 12. It details nine specific permissions covering disk hardware access, file preloading, proxy configuration, device management, anti-fraud data access, Bluetooth MAC persistence, and virtual screen management. Key information includes that all permissions utilize system_grant authorization and are strictly restricted to specific scenarios, such as financial apps, enterprise tools, UAD applications, or IoT connectivity, often requiring allowlist approval. This guide targets HarmonyOS developers seeking to implement specialized hardware or system-level features while adhering to strict usage constraints.

### ohospermissionREAD_WRITE_U_7more.md ohospermissionREAD_WRITE_U_7more.md
This document serves as a reference guide for seven sensitive HarmonyOS permissions introduced in API version 12. It details permissions for USB debugging, Wi-Fi peer MAC access, kernel memory protection modifications for cross-platform frameworks, and data sharing management for pasteboards and UDMF. Key takeaways include that all permissions use system_grant authorization and are strictly restricted to specific scenarios, often requiring allowlist approval and being limited to devices like 2in1s or tablets. The target audience is enterprise developers working on IDE tools, IoT connectivity, cross-platform frameworks, or high-performance gaming engines.

### ohospermissionSYSTEM_FLOAT_9more.md ohospermissionSYSTEM_FLOAT_9more.md
This document serves as a reference guide for specific OpenHarmony system permissions introduced in API version 12, detailing their usage scopes and authorization methods. It covers permissions for system floating windows, contact data, audio/video files, desktop directory access, and USB DDK interfaces. Key takeaways include the restriction of certain permissions like floating windows and USB DDK to 2in1 devices, the recommendation to use Pickers for general file access instead of requesting sensitive permissions, and the distinction between system_grant and user_grant authorization types. The target audience is application developers needing to implement sensitive features like backup, sync, or hardware integration on the OpenHarmony platform.
