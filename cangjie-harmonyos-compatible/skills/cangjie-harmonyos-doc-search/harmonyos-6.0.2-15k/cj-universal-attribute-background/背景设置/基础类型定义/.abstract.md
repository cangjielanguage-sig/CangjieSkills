This directory defines fundamental data types and configurations for background visual effects within the ArkUI framework using the Cangjie programming language. It covers essential structures for implementing blur effects, including style options, activation policies, and comprehensive background effect parameters. Key topics include depth-of-field blurring, component material styles, and dynamic visual state management based on window focus. This documentation is suitable for HarmonyOS developers and UI engineers looking to enhance application aesthetics through advanced visual rendering and styling capabilities.
