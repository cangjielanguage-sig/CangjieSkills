### 容器组件设置交叉轴对齐

可以通过Flex组件的alignItems参数设置子元素在交叉轴的对齐方式。

- ItemAlign.Auto：使用Flex容器中默认配置。

    <!-- run -->

    ```cangjie
    package ohos_app_cangjie_entry

    import kit.UIKit.*
    import ohos.state_macro_manage.*

    @Entry
    @Component
    class EntryView {
        func build() {
            Flex(FlexParams(alignItems: ItemAlign.Auto)) {
                Text('1').width(33.percent).height(30).backgroundColor(0xF5DEB3)
                Text('2').width(33.percent).height(40).backgroundColor(0xD2B48C)
                Text('3').width(33.percent).height(50).backgroundColor(0xF5DEB3)
            }.size(width: 90.percent, height: 80).padding(10).backgroundColor(0xAFEEEE)
        }
    }
    ```

    ![Flex13](figures/Flex13.png)
