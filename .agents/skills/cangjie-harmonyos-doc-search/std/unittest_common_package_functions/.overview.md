# unittest_common_package_functions

This directory provides essential API reference documentation for common functions within the unittest package, specifically targeting option management and validation mechanisms in the Cangjie language. It details critical functions including `registerOptionValidator` for implementing custom validation logic, `setOptionInfo` for establishing general option metadata, and `setOrUpdateOptionInfo` for managing specific type descriptions. The documentation emphasizes best practices, particularly the recommendation to utilize the `@UnittestOption` macro instead of direct function calls for standard validation scenarios. Furthermore, it illustrates how to programmatically define or override option descriptions and types. This resource is primarily intended for framework developers and advanced users who need to deeply customize test option behaviors, ensuring robust and flexible test configuration management within the Cangjie development environment.
