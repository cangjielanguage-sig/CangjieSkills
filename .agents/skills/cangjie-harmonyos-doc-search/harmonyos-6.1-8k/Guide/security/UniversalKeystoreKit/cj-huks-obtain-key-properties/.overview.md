# cj-huks-obtain-key-properties

本目录提供了在Cangjie语言环境下使用HUKS（通用密钥库）接口获取指定密钥属性信息的开发指南。文档详细介绍了开发流程，包括指定密钥别名、调用`getKeyItemProperties`接口以及解析返回的属性集合，并附带了完整的Cangjie代码示例。内容涵盖了密钥持久化存储的前提条件、密钥别名长度限制（最大128字节）及返回值类型等关键信息。该文档适用于使用UniversalKeystoreKit进行安全开发的程序员，特别是需要查询已生成或导入密钥属性的场景，目前处于Beta阶段。

## 详细说明

### cj-huks-obtain-key-properties.md cj-huks-obtain-key-properties.md
本文档旨在指导开发者如何在Cangjie环境中使用HUKS接口获取指定密钥的属性信息。主要内容包括开发步骤说明，涵盖指定密钥别名、调用getKeyItemProperties接口以及解析返回的属性集合，并提供了完整的Cangjie代码示例。关键信息指出操作前需确保密钥已持久化存储，密钥别名最大长度为128字节，options参数当前为预留，返回值为包含properties字段的Array<HuksParam>类型对象。该文档面向使用UniversalKeystoreKit进行安全开发的程序员，适用于需要查询已生成或导入密钥属性的场景，目前处于Beta阶段。
