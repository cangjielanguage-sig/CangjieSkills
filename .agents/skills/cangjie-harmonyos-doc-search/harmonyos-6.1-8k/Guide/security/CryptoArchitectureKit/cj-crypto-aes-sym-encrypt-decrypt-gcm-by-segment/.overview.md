# cj-crypto-aes-sym-encrypt-decrypt-gcm-by-segment

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language to implement AES symmetric encryption and decryption using GCM (Galois/Counter Mode) through segmented processing. It addresses the critical need for handling large data streams or files by breaking them into manageable chunks, ensuring efficient memory usage without sacrificing security. The guide covers the integration of the `CryptoArchitectureKit`, detailing the specific API workflows, parameter configurations, and the management of authentication tags required for authenticated encryption. This material is ideally suited for developers who possess a foundational understanding of cryptography and require practical, code-based guidance to implement secure data handling mechanisms in their Cangjie applications. By following this guide, developers can ensure their implementations are both performant and cryptographically sound.

## Detailed Description

### [1] 使用AES对称密钥GCM模式分段加解密/

This subdirectory provides an in-depth technical guide focused on the implementation of AES symmetric key encryption and decryption in GCM mode, specifically tailored for segmented data processing. The content is designed to assist developers in navigating the complexities of the `CryptoArchitectureKit`, offering a clear roadmap of the implementation flow from initialization to completion.

Key topics include the precise order of API calls and the detailed configuration of parameters required to establish a secure cryptographic context. The documentation places special emphasis on the nuances of processing data in segments, explaining how the `update` method functions iteratively to handle chunks of data without compromising security. This is particularly important for applications that cannot load entire datasets into memory at once. Furthermore, it highlights the indispensable role of the `doFinal` operation, which is crucial for finalizing the cryptographic transformation and generating the authentication tags that verify data integrity. Without correctly executing `doFinal`, the authentication tag cannot be retrieved, rendering decryption verification impossible.

By merging theoretical background with practical code examples written in the Cangjie language, this guide bridges the gap between abstract cryptographic concepts and real-world application. It is an invaluable resource for developers who need to process large volumes of data securely, ensuring they understand the specific behaviors and requirements of the GCM mode within the Cangjie environment.
