# cj-universal-attribute-touchtarget

本目录包含ArkUI框架中关于触摸目标属性的仓颉语言API参考文档。核心内容涵盖了如何使用`responseRegion`函数来灵活设置组件的触摸响应热区。该功能支持通过定义单个矩形或矩形数组来扩展或限制组件的可交互范围，从而在视觉布局之外独立定义按压测试区域。这对于优化小尺寸组件的触控体验或实现非规则形状的交互逻辑至关重要。文档适用于使用仓颉语言的ArkUI开发者，旨在帮助其实现更精细的交互控制与更流畅的用户体验。

## 详细说明

### cj-universal-attribute-touchtarget.md cj-universal-attribute-touchtarget.md
本文档是ArkUI框架的API参考文档，旨在指导开发者如何设置组件的触摸响应热区。文档主要包含模块导入说明及responseRegion函数的两个重载版本，分别支持设置单个矩形区域或矩形数组作为响应区域。关键信息指出，该功能允许在事件触发前自定义按压测试范围，从而优化触屏和鼠标交互体验。文档详细列出了参数类型、返回值及起始版本22。目标受众为使用仓颉语言的ArkUI开发者，适用于需要精确控制组件交互区域的场景。
