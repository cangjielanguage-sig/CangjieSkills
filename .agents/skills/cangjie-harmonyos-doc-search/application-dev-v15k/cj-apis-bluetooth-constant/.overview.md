# cj-apis-bluetooth-constant

This directory serves as the definitive API reference documentation for the `ohos.bluetooth.constant` module, specifically developed using the Cangjie programming language for the HarmonyOS operating system. It provides a comprehensive suite of enumerations and constants that are fundamental to executing Bluetooth operations effectively. The documentation covers critical areas such as device classification, utilizing MajorClass and MajorMinorClass, and managing connection states via ProfileConnectionState. Additionally, it includes essential profile identifiers (ProfileId) and profile UUIDs (ProfileUuids). These definitions empower developers to programmatically identify, categorize, and manage Bluetooth devices and their communication protocols with high precision. This resource is indispensable for software engineers and developers focused on implementing robust Bluetooth connectivity features. It requires the `SystemCapability.Communication.Bluetooth.Core` capability and is fully supported from API version 19 onwards, ensuring compatibility with modern HarmonyOS application development standards. By leveraging these tools, developers can ensure seamless interoperability between devices.

## Detailed Description

The following section details the specific subdirectory available within this repository, outlining its purpose and contents.

### ohosbluetoothconstant蓝牙constant模块/

This directory contains the API reference documentation for the `ohos.bluetooth.constant` module in the Cangjie programming language, designed for HarmonyOS development. It provides essential enumerations and constants for Bluetooth operations, including device classification (MajorClass, MajorMinorClass), connection states (ProfileConnectionState), profile identifiers (ProfileId), and profile UUIDs (ProfileUuids).

Key components covered in this module include:
*   **Device Classification:** Definitions for MajorClass and MajorMinorClass to categorize devices.
*   **Connection States:** ProfileConnectionState enumerations to manage device status.
*   **Profile Identifiers:** ProfileId and ProfileUuids for protocol identification.

These definitions enable developers to programmatically identify, categorize, and manage Bluetooth devices and communication protocols. The module requires the `SystemCapability.Communication.Bluetooth.Core` capability and is available from API version 19. It is suitable for software engineers implementing robust Bluetooth connectivity features in HarmonyOS applications.
