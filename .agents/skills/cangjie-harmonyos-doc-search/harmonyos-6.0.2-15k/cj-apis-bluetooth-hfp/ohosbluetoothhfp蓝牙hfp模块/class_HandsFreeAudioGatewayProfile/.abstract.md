This directory provides comprehensive API reference documentation for the `HandsFreeAudioGatewayProfile` class within the Cangjie language environment, tailored for HarmonyOS Bluetooth development. It focuses on the implementation and management of Bluetooth Hands-Free Audio Gateway (HFP AG) connections. The documentation covers essential functionalities such as profile instantiation, retrieving connected device lists, checking connection states, and managing event listeners for state changes. Key technical aspects include required permissions like `ohos.permission.ACCESS_BLUETOOTH`, system capabilities, and exception handling. This resource is ideal for developers utilizing the ConnectivityKit to build robust Bluetooth applications requiring HFP AG features.
