This directory contains comprehensive documentation for the HiLog logging system within the Cangjie programming language, specifically designed for HarmonyOS application development. It covers essential APIs, enumerations, and configuration guides required to implement structured logging, debug applications, and monitor runtime status. Key components include the `Hilog` and `HilogChannel` classes, log level definitions, and usage examples. This resource is suitable for Cangjie developers looking to integrate robust logging mechanisms, categorize system events, and ensure their applications adhere to system logging standards using the PerformanceAnalysisKit.
