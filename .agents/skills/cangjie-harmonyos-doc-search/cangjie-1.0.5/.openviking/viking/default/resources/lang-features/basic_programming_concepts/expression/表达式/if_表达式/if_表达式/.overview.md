# if_表达式

## 详细描述

### if_表达式_1.md
本文档详细介绍了仓颉编程语言中 `if` 表达式的语法结构、执行流程及类型推导规则。主要涵盖基本语法形式、条件类型（布尔值与 let pattern）、`else` 分支省略规则、多级 `else if` 判断以及 `if` 表达式的值与类型确定机制。核心要点包括条件必须是布尔类型（强类型检查）、支持多级条件判断，以及 `if` 表达式作为值的类型推导规则（上下文明确类型或取最小公共父类型）。该文档属于语言基础教程，面向仓颉语言初学者或开发者，旨在帮助其掌握条件控制流的使用。

### if_表达式_2.md
该文档旨在解释仓颉编程语言中 if 表达式的类型推导规则及求值行为。主要内容包括含 else 分支但未求值场景、不含 else 分支场景的类型规定，以及作为变量初值时的类型推导示例。核心要点指出，用于副作用或无 else 的 if 表达式类型为 Unit；用于赋值时，类型取各分支代码块的最小公共父类型。文档属于语言参考教程，面向仓颉语言开发者，帮助其理解表达式求值与类型系统的交互。
