# class_PriKey

This directory contains API reference documentation for the `PriKey` class within the Cangjie language's CryptoArchitectureKit. It focuses on managing private keys for cryptographic operations such as asymmetric encryption, signing, and key agreement. The documentation covers key structure, memory management, parameter retrieval, and encoding methods (DER and PEM). It is suitable for developers implementing security features who need to handle private key generation, secure erasure, and encoding standards like PKCS#8 and PKCS#1.

### class_PriKey_3more.md class_PriKey_3more.md

It details the class structure, which inherits from the Key interface, and documents two primary functions: clearMem() for securely erasing key data from memory and getAsyKeySpec() for retrieving specific key parameters. This guide targets developers implementing security features who need to handle asymmetric encryption, signing, and key agreement using the CryptoArchitectureKit.

### func_getEncodedDerString.md func_getEncodedDerString.md

The documentation covers the function signature, functionality, parameters, return values, and exception handling. Key information includes that the function currently supports only the "PKCS8" format for ECC private keys and distinguishes itself from Key.getEncoded by allowing format specification. It returns a DataBlob and may throw specific business exceptions for invalid parameters or crypto errors. This guide targets Cangjie developers working with cryptographic key generation and encoding within the CryptoArchitectureKit.
