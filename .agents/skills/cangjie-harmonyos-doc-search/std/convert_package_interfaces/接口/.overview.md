# 接口

This directory serves as a comprehensive API reference for core interfaces within the Cangjie programming language standard library. It focuses on type conversion and string manipulation capabilities, specifically covering the `Formattable`, `Parsable`, and `RadixConvertible` interfaces. These documents detail how to convert data types to strings, parse strings back into types, and handle numeric conversions across different radix systems. This resource is essential for Cangjie developers seeking to implement robust data formatting, parsing logic, and error handling for primitive numeric and character types in their applications.

## Detailed Description

### interface_Formattable
This directory contains API reference documentation for the `Formattable` interface in the Cangjie programming language. It covers the core interface definition and its extensions across various numeric data types, including signed and unsigned integers (Int8, Int16, Int32, Int64, UInt8, UInt16, UInt32, UInt64), floating-point numbers (Float16, Float32, Float64), and the Rune type. The documents detail the `format` function, which converts instances to formatted strings, and handle exceptions like `IllegalArgumentException`. This resource is suitable for Cangjie developers looking to implement or utilize string formatting capabilities for primitive types within their applications.

### interface_ParsableT
This directory contains comprehensive API documentation for the Cangjie language's `Parsable` interface and its specific implementations across various data types. It covers the standardization of string-to-type conversions for fundamental types, including Booleans, Integers (signed and unsigned, 8 to 64-bit), Floating-point numbers (16, 32, 64-bit), and Runes. The documentation details the `parse` and `tryParse` methods, highlighting the distinction between exception-based error handling and safe parsing using the `Option` type. This resource is suitable for Cangjie developers seeking robust mechanisms for parsing string literals into specific types, managing errors effectively, and understanding type conversion constraints within the standard library.

### interface_RadixConvertibleT
This directory contains API reference documentation for the Cangjie programming language's `RadixConvertible` interface and its implementations across standard integer types. It covers extensions for signed (Int8, Int16, Int32, Int64) and unsigned (UInt8, UInt16, UInt32, UInt64) integers, enabling conversions between string representations and numeric values across various numerical bases (radix 2 to 36). Key functionalities include parsing strings into integers using strict or safe methods (`parse`, `tryParse`) and formatting integers as strings (`toString`). This documentation is suitable for Cangjie developers who need precise control over numeric parsing, formatting, and error handling in different radix systems.
