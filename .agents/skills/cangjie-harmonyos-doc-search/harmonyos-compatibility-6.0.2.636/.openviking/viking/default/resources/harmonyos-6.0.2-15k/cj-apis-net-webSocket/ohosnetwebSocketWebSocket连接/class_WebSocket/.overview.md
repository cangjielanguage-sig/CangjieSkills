# class_WebSocket

This directory contains API reference documentation for the WebSocket class within the Cangjie language NetworkKit. It covers the essential functionalities required to establish, manage, and close WebSocket connections in HarmonyOS applications. Key topics include asynchronous connection establishment, event subscription (on/off), data transmission, and connection termination. The documentation details necessary permissions, error codes, and callback mechanisms. It is intended for developers working with network communication in HarmonyOS who need to implement real-time, bidirectional data exchange using the Cangjie programming language.
