# 签名验签仓颉

This directory provides comprehensive resources for implementing digital signature and verification functionalities using the Cangjie programming language within the HarmonyOS ecosystem. It centers on the Universal Keystore Kit (HUKS), covering the full lifecycle of cryptographic operations from key generation to deletion. The documentation supports a wide range of algorithms, including ECC, RSA, and national standards like SM2, ensuring data integrity and security. It is specifically designed for Cangjie developers who need to integrate hardware-backed cryptographic features and secure signing capabilities into their applications.

## Detailed Description

The following section provides detailed summaries of the documentation and code examples available in this directory.

### 开发步骤.md 开发步骤.md

This document serves as a step-by-step tutorial for developers implementing cryptographic operations using the Universal Keystore Kit. It covers four primary workflows: key generation, data signing, signature verification, and key deletion. The guide details specific API calls such as generateKeyItem, initSession, updateSession, and finishSession, explaining how to configure parameters like HuksOptions and manage session handles. It also references related concepts like key import and algorithm configuration. Intended for application developers, this document provides the essential procedures for managing the lifecycle of cryptographic keys and ensuring data integrity within the system.

### 签名验签仓颉.md 签名验签仓颉.md

This document serves as a practical development guide for implementing digital signature and verification functions using the Cangjie programming language. It outlines general development steps and provides specific code examples for four distinct cryptographic algorithm combinations: ECC256/SHA256, SM2/SM3, RSA/SHA256/PSS, and RSA/SHA256/PKCS1_V1_5. Key information includes references to a separate overview document for detailed specifications on supported algorithms and usage scenarios. The content is designed for developers seeking to integrate cryptographic signing capabilities into Cangjie applications, offering concrete implementation cases to facilitate secure development.
