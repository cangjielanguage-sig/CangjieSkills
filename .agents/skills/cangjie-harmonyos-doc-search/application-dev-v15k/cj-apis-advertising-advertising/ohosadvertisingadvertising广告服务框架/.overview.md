# ohosadvertisingadvertising广告服务框架

This directory contains the API reference documentation for the HarmonyOS Advertising Service Framework, specifically designed for the Cangjie programming language. It comprehensively covers the AdsKit module, providing essential classes and interfaces for configuring ad requests, managing ad loading, handling interaction events, and displaying advertisements. Key components include listeners for status updates, parameter configuration objects, and data structures for ad content. This documentation is suitable for HarmonyOS developers and software engineers looking to integrate robust advertising capabilities, such as Banner, Splash, and Native ads, into their applications while ensuring compliance and efficient performance.

## Quick Navigation

**What do you want to do?**

*   Configure ad requests and parameters → class_AdRequestParams.md, class_Parameter_2more.md, `class_AdOptions/`

## Detailed Description

### class_AdInteractionListene_2more.md class_AdInteractionListene_2more.md
This document defines listener classes for handling advertising events in Cangjie. It details the `AdInteractionListener` for monitoring status changes and `AdLoadListener` for managing single ad slot outcomes. Key information includes constructors and read-only callback properties like `onStatusChanged`, `onAdLoadSuccess`, and `onAdLoadFailure`, which accept lambda functions to handle asynchronous logic.

### class_AdRequestParams.md class_AdRequestParams.md
This reference defines the `AdRequestParams` class for configuring advertising requests. It details the constructor and properties such as `adId`, `adType`, `adCount`, and `dimensions`. The guide includes code examples for instantiating requests with custom parameters for various ad types like Splash, Banner, or Native ads.

### class_Advertisement.md class_Advertisement.md
This document serves as the API reference for the `Advertisement` class, defining the data structure for requested ad content. It details the constructor and read-only properties such as `adType`, `uniqueId`, `rewarded`, and `clicked`. All properties are immutable, encapsulating ad metadata, interaction states, and server verification parameters.

### class_MultiSlotsAdLoadListener.md class_MultiSlotsAdLoadListener.md
This document outlines the `MultiSlotsAdLoadListener` class for handling callbacks in multi-slot ad loading requests. It details the constructor and read-only properties `onAdLoadSuccess` and `onAdLoadFailure`, explaining the returned data structures like HashMaps linking slot IDs to ad arrays and error codes.

### class_Parameter_2more.md class_Parameter_2more.md
This reference covers the `Parameter` class and `ValueType` enum for storing key-value pairs in the AdsKit module. It explains the constructor supporting Int32, Bool, and String types, providing examples for instantiating objects and passing them to `AdRequestParams` for request configuration.

### ohosadvertisingadvertising_5more.md ohosadvertisingadvertising_5more.md
This document provides the API reference for the HarmonyOS Advertising Service Framework using Cangjie. It details the `kit.AdsKit` module, focusing on `getAdRequestBody` for retrieving ad data and `showAd` for presenting full-screen ads, including parameters, return values, and error codes.

### class_AdDisplayOptions/
This directory provides reference documentation for the `AdDisplayOptions` class in Cangjie. It covers functionalities for configuring ad display behaviors, including playback controls, user verification parameters, and custom attributes for ad rotation and refresh intervals.

### class_AdLoader/
This directory contains reference documentation for the `AdLoader` class designed to handle ad loading operations. It covers initialization using `StageContext`, core functions for requesting ads, and error handling details for single or multi-slot loading.

### class_AdOptions/
This directory provides reference documentation for the `AdOptions` class. It covers configuration aspects such as regulatory compliance settings (COPPA, content ratings), non-personalized advertising options, and custom attributes for fine-tuning ad behavior and traffic management.
