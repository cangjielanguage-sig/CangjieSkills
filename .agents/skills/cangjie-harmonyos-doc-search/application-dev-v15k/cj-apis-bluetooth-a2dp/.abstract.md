This directory serves as the central repository for API reference documentation regarding the HarmonyOS Bluetooth A2DP module, specifically tailored for the Cangjie programming language. It provides comprehensive coverage of the Advanced Audio Distribution Profile (A2DP) source functionality, which is essential for developers looking to implement robust wireless audio streaming solutions. The content encompasses the management of Bluetooth audio streaming, the intricacies of device connections, and the monitoring of playback states. Key technical components detailed herein include configuration classes for prominent audio codecs such as SBC, AAC, and L2HC, as well as enumerations for sample rates and channel modes. Additionally, the documentation highlights the `A2dpSourceProfile` class, which is instrumental in handling connection events and facilitating audio transmission. This resource is ideally suited for HarmonyOS developers utilizing the Cangjie language who require detailed guidance to integrate high-quality wireless audio features into their applications effectively.
