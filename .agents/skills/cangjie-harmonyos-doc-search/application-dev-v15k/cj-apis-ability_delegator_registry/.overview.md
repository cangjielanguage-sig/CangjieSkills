# cj-apis-ability_delegator_registry

This directory serves as a comprehensive resource for the HarmonyOS Cangjie framework, specifically targeting the `AbilityDelegatorRegistry` and its associated testing infrastructure. It provides in-depth documentation on the critical components required for establishing robust unit and automated testing environments within the ability runtime. Key topics covered include the encapsulation of arguments, the management of lifecycle states, and the detailed monitoring of UIAbility and AbilityStage components. Furthermore, the documentation outlines classes designed for tracking application states, executing shell commands, and orchestrating test execution flows. This collection is primarily intended for Cangjie developers and QA engineers who are tasked with constructing automated tests for HarmonyOS applications and require the ability to programmatically manipulate and observe the behaviors of various application components.
