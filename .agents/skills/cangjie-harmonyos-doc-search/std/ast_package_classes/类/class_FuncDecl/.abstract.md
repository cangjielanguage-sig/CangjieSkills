This directory contains comprehensive API documentation for the `FuncDecl` class and associated Abstract Syntax Tree (AST) manipulation utilities within the Cangjie programming language ecosystem. It covers the structural definition of function declaration nodes, including initialization, property management (such as parameters, return types, and syntax tokens), and validation mechanisms. Furthermore, it provides technical details on converting AST nodes to token sequences and traversing the syntax tree using the Visitor pattern. This documentation is specifically designed for compiler developers, language tool creators, and software engineers involved in building parsers or static analysis tools for Cangjie.
