This directory contains API reference documentation for core interfaces in the Cangjie programming language. It covers fundamental numeric abstractions, including generic arithmetic operations, floating-point behaviors, integer properties, and value limits. Key topics include the `Number`, `Integer`, `FloatingPoint`, and `MaxMinValue` interfaces, alongside a deprecated `MathExtension` reference. This documentation is suitable for Cangjie developers, software engineers, and system architects who need to understand type hierarchies, implement generic numeric constraints, or perform precise mathematical computations within the Cangjie ecosystem.
