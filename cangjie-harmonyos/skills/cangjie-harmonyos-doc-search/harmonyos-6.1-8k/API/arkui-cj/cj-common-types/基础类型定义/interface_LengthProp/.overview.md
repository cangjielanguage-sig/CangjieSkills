# interface_LengthProp

本目录包含仓颉语言中 `LengthProp` 接口及其扩展实现的 API 参考文档，主要用于 ArkUI 开发。文档详细介绍了 `Int64` 和 `Float64` 等基础类型如何扩展以支持多种长度单位（如 px、vp、fp、percent、lpx）及相关属性（value、unitType）。这些内容属于 SystemCapability.ArkUI.ArkUI.Full 系统能力，起始版本为 22。该目录适合使用仓颉语言进行 UI 布局开发的程序员，帮助他们理解如何便捷地将数值转换为不同单位的长度对象。

## Detailed Description

### extend_Int64_LengthProp_22bdabab.md
本文档是一份 API 参考文档，旨在说明仓颉语言中 `Int64` 类型如何扩展以实现 `LengthProp` 和 `Length` 接口。文档核心内容涵盖了扩展后的多个只读属性，包括以 px、vp、fp、percent 及 lpx 为单位的长度属性，以及表示数值的 `value` 属性和表示单位的 `unitType` 属性。关键信息在于这些属性均属于 SystemCapability.ArkUI.ArkUI.Full 系统能力，且起始版本为 22，允许开发者将整型数值便捷地转换为不同单位的长度对象。该文档主要面向使用仓颉语言进行 ArkUI 开发的程序员，帮助他们理解 Int64 在 UI 布局中的类型扩展用法。

### interface_LengthP_7more_8ca59f7d.md
本文档是 Cangjie 语言中 `LengthProp` 接口的 API 参考文档，用于定义长度属性的标准接口。文档主要包含 `LengthProp` 接口定义及其五种只读单位属性（px、vp、fp、percent、lpx），以及 `Float64` 类型对该接口的扩展实现。关键信息显示，`Float64` 扩展不仅实现了长度单位属性，还提供了 `value` 和 `unitType` 属性以获取具体数值和单位。该接口支持 ArkUI 全能力，起始版本为 22，主要面向使用 Cangjie 进行 ArkUI 开发的开发者，用于处理多单位长度数据。
