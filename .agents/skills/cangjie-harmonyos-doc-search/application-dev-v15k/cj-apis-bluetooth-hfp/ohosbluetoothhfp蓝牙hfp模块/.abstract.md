This directory provides comprehensive technical documentation for the HarmonyOS Bluetooth Hands-Free Profile (HFP) module, specifically implemented using the Cangjie language. It serves as a critical resource for developers aiming to integrate hands-free calling and audio gateway functionalities into their applications. The documentation covers the entire development workflow, including necessary imports, system permissions, and project configuration. It details the instantiation of the Hands-Free Audio Gateway Profile, connection management, and event handling for state changes. With a focus on system capabilities, return values, and business exceptions, this guide is intended for HarmonyOS developers and engineers working on connectivity kits who need to implement robust Bluetooth communication features and manage audio gateway interactions effectively.
