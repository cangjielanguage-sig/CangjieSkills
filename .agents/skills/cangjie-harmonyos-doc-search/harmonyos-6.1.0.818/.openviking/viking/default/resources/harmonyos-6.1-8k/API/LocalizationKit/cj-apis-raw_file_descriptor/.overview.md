# cj-apis-raw_file_descriptor

本目录包含仓颉语言中 `ohos.raw_file_descriptor` 模块的 API 参考文档。该文档详细阐述了如何在 HarmonyOS HAP 包中表示和访问原始文件描述符。核心内容涵盖 `RawFileDescriptor` 类的定义，包括文件描述符、起始偏移量和文件长度等关键属性，用于定位和读取原始资源。此功能目前处于 Beta 阶段，适用于使用仓颉语言进行 HarmonyOS 开发，并需要通过文件描述符底层访问文件资源的开发者。

### cj-apis-raw_file_descriptor.md cj-apis-raw_file_descriptor.md
