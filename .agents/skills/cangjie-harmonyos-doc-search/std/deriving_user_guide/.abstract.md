This directory serves as the definitive user guide for the `deriving_user_guide` module, specifically tailored for developers working with the Cangjie programming language. It focuses on the powerful `@Derive` macro, a tool designed to streamline the development process by automating the implementation of standard interfaces for classes and enums. By utilizing this guide, developers can learn how to significantly reduce boilerplate code, ensuring cleaner and more maintainable codebases. The documentation covers essential topics such as syntax rules, field collection mechanisms, and the handling of generic types and constraints. Furthermore, it delves into advanced customization options using specific attributes like `@DeriveInclude` and `@DeriveOrder`. This resource is ideal for Cangjie developers who want to efficiently implement common interfaces—such as `ToString`, `Hashable`, and `Equatable`—without sacrificing runtime performance or code clarity. Whether you are building complex data structures or simply looking to optimize your development workflow, this guide offers the necessary instructions and examples to master the Deriving feature.
