# 单一手势

This directory contains comprehensive documentation for implementing various single-touch and multi-touch gestures within the Cangjie UI framework. It covers essential interaction patterns including dragging, pinching, swiping, tapping, and long-pressing. The documents provide detailed API references, constructor parameters, and practical code examples demonstrating how to bind these gestures to UI components and handle event callbacks. Key topics include gesture configuration, state management for translation and scaling, and resolving gesture competition with scrollable containers. This resource is suitable for Cangjie developers seeking to enhance user interactivity and responsiveness in their applications.

### 拖动手势PanGesture.md 拖动手势PanGesture.md
This document serves as an API reference and a tutorial for implementing the PanGesture component in the Cangjie UI framework. It covers the constructor parameters including finger count, direction, and minimum distance, alongside a code example demonstrating how to bind the gesture to a Text component and update its position using event callbacks. Key takeaways include the default 5px trigger threshold and the importance of managing state variables for translation. The document also highlights critical considerations regarding gesture competition with scrollable parent components like List and Grid, advising on parameter adjustments to ensure responsiveness. This guide targets UI developers seeking to add interactive drag functionality to their applications.
