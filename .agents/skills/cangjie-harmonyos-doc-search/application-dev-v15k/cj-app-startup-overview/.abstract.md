This directory serves as a comprehensive technical resource designed to assist developers in transitioning from the deprecated explicit Want method to the modern, link-based application startup mechanism. It provides a detailed conceptual overview of how to launch specific applications securely and efficiently within the development environment. The content primarily focuses on the critical distinctions between Deep Linking and App Linking, emphasizing the substantial security advantages of the latter, such as the implementation of HTTPS schemes and rigorous domain verification processes. Additionally, the documentation covers the operational behavior of the `openLink` interface across a variety of different scenarios and conditions. This guide is essential for developers working on cross-app navigation and those utilizing `UIAbility` components who need to implement robust, secure, and efficient application startup flows using URL schemes. By mastering these concepts, developers can ensure their applications adhere to current best practices for security and usability.
