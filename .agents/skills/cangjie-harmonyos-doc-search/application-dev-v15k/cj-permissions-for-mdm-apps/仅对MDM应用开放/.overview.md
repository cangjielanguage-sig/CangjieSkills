# 仅对MDM应用开放

This directory provides technical documentation for OpenHarmony system permissions that are exclusively available to Mobile Device Management (MDM) applications and specific enterprise security tools. It covers a wide range of capabilities, including file scanning, device administration, network configuration, and system settings management. Key concepts include `FILE_GUARD_MANAGER`, `ENTERPRISE` permissions, and granular hardware control. These resources are designed for system developers and enterprise architects building robust device management solutions or file security applications, specifically targeting API version 12 and utilizing system_grant authorization. Understanding these permissions is crucial for ensuring compliance and functionality in enterprise environments.

## Detailed Description

### ohospermissionFILE_GUARD__15more.md ohospermissionFILE_GUARD__15more.md
This reference document defines specific OpenHarmony system permissions required for file management and enterprise device administration. It details the FILE_GUARD_MANAGER permission for file scanning and a comprehensive suite of ENTERPRISE permissions covering security, Bluetooth, WiFi, system settings, restrictions, and device operations like rebooting and locking. Key information includes that all listed permissions utilize system_grant authorization and are available starting from API version 12. Most are classified as system_basic level, with FILE_GUARD_MANAGER and ENTERPRISE_RECOVERY_KEY at the higher system_core level. This guide targets system developers creating enterprise device management applications or file security tools.
