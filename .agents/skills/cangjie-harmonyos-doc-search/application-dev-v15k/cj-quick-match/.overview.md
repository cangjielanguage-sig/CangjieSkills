# cj-quick-match

This directory provides a specialized technical guide for developers working within the ArkUI ecosystem, focusing specifically on the integration of system password auto-fill services. It details the necessary configurations for TextInput components to ensure seamless compatibility with native system password vaults. The content covers specific constraints related to InputType attributes, offering clear guidance on valid settings to ensure functionality. It includes step-by-step adaptation instructions for common authentication scenarios such as login and registration. Furthermore, the guide provides a Cangjie code example to demonstrate practical implementation in a real-world context. This resource is specifically suitable for developers building secure login interfaces who need to implement efficient password management and auto-fill features without compromising user experience or adhering to strict security standards.

### cj-quick-match.md cj-quick-match.md

This file serves as the definitive guide for the `cj-quick-match` directory, explaining the technical process of quickly integrating the system password auto-fill service into applications. It specifically leverages ArkUI TextInput components to achieve this functionality. The document details the strict constraints developers must adhere to regarding specific InputType attributes to ensure the system recognizes the fields correctly for auto-fill purposes. It provides comprehensive, step-by-step adaptation instructions designed for two primary user scenarios: login and registration.

Among the key takeaways, the guide emphasizes the critical importance of setting TextInput types to USER_NAME, Password, or NEW_PASSWORD. These specific configurations are necessary to successfully enable both auto-fill and password saving functions within the application. To aid developers in applying these concepts effectively, a Cangjie code example is provided for reference. This tutorial is specifically curated for developers who are building login interfaces and need to implement password vault features efficiently, ensuring a smooth user experience while maintaining high security standards. By following this guide, developers can ensure their applications meet modern user expectations for convenience and security.
