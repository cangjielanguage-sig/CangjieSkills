This directory contains comprehensive API reference documentation for the Cangjie `PrettyPrinter` class, a utility designed for generating formatted text output. It covers core functionality including indentation control, text alignment (left, center, right), color application, and line break management. The documentation details the class constructor, properties like `isTopLevel`, and various `append` methods, including support for closures to scope formatting effects. This resource is essential for Cangjie developers, particularly those working on unit testing or building tools that require structured, readable console output.
