# ohosmultimodalInputkeyEvent按键输入事件

This directory provides API reference documentation for handling key input events in the Cangjie language within the OpenHarmony environment. It covers essential components for multimodal input, including the `Action` enum for key states, the `Key` class for device-reported events, and the comprehensive `KeyEvent` class for managing keyboard interactions. Key topics include key codes, modifier states, pressed time, and system capabilities. Designed for developers implementing input handling logic, these resources support version 19+ systems and require the `SystemCapability.MultimodalInput.Input.Core` capability.

## Detailed Description

### enum_Action.md enum_Action.md
This API reference document defines the Action enum in the Cangjie language, which represents key event types for multimodal input handling. The documentation details the enum structure, listing specific values such as CANCEL, DOWN, and UP to describe key states. It also explains inherited comparison operators for equality checks and a toString method for string conversion. Key takeaways include the system capability requirement (SystemCapability.MultimodalInput.Input.Core) and the starting version (19). This resource is designed for developers implementing input event logic, providing the necessary definitions to handle and compare key actions within their applications.

### ohosmultimodalInputkeyEven_3more.md ohosmultimodalInputkeyEven_3more.md
This document provides API reference documentation for the Key class within the ohos.multimodalInput.keyEvent module, designed to handle device-reported key input events. The content details the class structure, specifically focusing on its three main properties: code (KeyCode), pressedTime (Int64), and deviceId (Int32), along with the class constructor. Key takeaways include that all properties are readable and writable, time is measured in microseconds, and the class requires SystemCapability.MultimodalInput.Input.Core. Targeted at developers using the Cangjie language, this reference aids in implementing input handling for version 19+ systems.

### class_KeyEvent/
This directory contains essential API reference documentation for the Cangjie programming language's `KeyEvent` class, specifically designed to manage and handle keyboard input events within applications. It provides a detailed breakdown of the class structure, including its inheritance from `InputEvent` and its dependency on the `SystemCapability.MultimodalInput.Input.Core` system capability. The documentation covers a wide array of properties, ranging from key actions and specific key codes to Unicode characters and arrays of currently pressed keys. Furthermore, it explains boolean flags for modifier keys like Ctrl, Alt, Shift, and Logo, as well as the state of lock keys such as Caps, Num, and Scroll. This resource is tailored for developers working on input handling logic who require precise definitions and version requirements (starting from version 19) to implement robust keyboard interactions.
