# 通过用户首选项实现数据持久化

This directory provides a comprehensive guide to implementing data persistence using User Preferences within the Cangjie language ecosystem. It focuses on managing lightweight, persistent Key-Value data suitable for application settings like font sizes and themes. The content covers the entire development lifecycle, from understanding the underlying mechanisms—such as memory caching and file persistence—to practical implementation steps involving CRUD operations, data flushing, and change subscriptions. It addresses specific constraints, including data size limits and concurrency safety. This resource is tailored for application developers utilizing the ArkData and AbilityKit frameworks who need efficient strategies for simple data storage and resource management.

## Detailed Description

### 场景介绍_4more.md
This technical guide introduces the User Preferences feature for managing lightweight, persistent Key-Value data in applications. It covers usage scenarios, operational mechanisms involving memory caching and file persistence, specific constraints like data size limits and concurrency safety, and a detailed API reference table. Key takeaways include that data is cached in memory for speed and requires the flush method for persistence. It is unsuitable for large datasets or multi-process environments, with specific limits on key length and encoding. This document targets application developers using the Cangjie language who need to store user settings like font size or theme preferences.

### 开发步骤/
This directory serves as a comprehensive resource for developers utilizing the Cangjie programming language, specifically focusing on the implementation of lightweight data storage mechanisms using the Preferences API. It details the complete development workflow, starting from importing necessary modules and obtaining Preferences instances within a UIAbility context to performing fundamental CRUD tasks such as writing, reading, and deleting key-value pairs. Furthermore, the documentation explores critical concepts for maintaining data integrity, including data persistence via the flush method, subscribing to data changes using custom callbacks, and managing the full lifecycle of preference files. These guides are meticulously designed for application developers working with the ArkData and AbilityKit frameworks who require efficient strategies for simple data persistence and effective storage resource management.
