# enum_KeyCode

This directory contains technical documentation for the `KeyCode` enumeration within a multimodal input system, specifically designed for the Cangjie programming language. It defines a comprehensive set of constants representing physical keys, including alphanumeric characters, function keys, media controls, navigation inputs, and gamepad buttons. The documentation details the specific system capabilities required (SystemCapability.MultimodalInput.Input.Core) and the minimum API version (19) for each keycode. It is intended for software developers and system engineers working on input event handling, user interface development, and hardware driver integration.
