This directory contains the official technical guidelines for the `cj-errormanager-guidelines`, designed specifically for application developers utilizing the Cangjie programming language in the HarmonyOS environment. The primary focus of this collection is to equip developers with the knowledge required to implement sophisticated error management and real-time monitoring within their applications. It addresses the critical need for handling runtime instability by leveraging the `errorManager` module. Key areas of instruction include managing uncaught exceptions that typically lead to crashes and detecting lifecycle timeouts that may freeze the main thread. The documentation provides detailed insights into specific API interfaces, guiding developers through the process of registering and unregistering observers. It distinguishes between the `ErrorObserver`, used for capturing granular exception details, and the `LoopObserver`, which is essential for monitoring message processing time on the main thread. By mastering these interfaces, developers can prevent their applications from exiting abruptly upon encountering errors, allowing for the necessary time to report logs to developer platforms for analysis. This resource is highly suitable for software engineers and developers who are focused on diagnosing complex runtime issues, significantly enhancing application stability, and integrating effective, production-grade error handling mechanisms into their HarmonyOS projects. By following these guidelines, developers ensure their applications remain resilient against unexpected failures, providing a better user experience and facilitating easier maintenance through comprehensive error logging and monitoring strategies.
