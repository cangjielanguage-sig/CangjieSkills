This directory provides a comprehensive guide for HarmonyOS developers on implementing App Linking to enable seamless inter-app navigation and deep linking. It covers the entire development lifecycle, including service introduction, configuration in AppGallery Connect (AGC) and DevEco Studio, domain verification, and code implementation for both calling and receiving applications. Key topics include the `openLink` interface, handling web fallbacks, and troubleshooting common errors. Suitable for client, cloud, and frontend developers looking to integrate secure HTTPS-based linking with Cangjie language support.
