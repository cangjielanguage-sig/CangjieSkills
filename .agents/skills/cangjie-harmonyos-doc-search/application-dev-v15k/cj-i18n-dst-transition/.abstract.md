This directory serves as a comprehensive technical resource for the Cangjie localization framework, specifically addressing the intricate challenges associated with Daylight Saving Time (DST) transitions. It provides an in-depth examination of the implementation strategies necessary to manage the non-uniform length of DST days, which can span either 23 or 25 hours. This variation creates unique technical hurdles, such as time gaps and overlaps, which are thoroughly explained within the documentation. The content covers essential system principles, including accurate hour calculation, correct local time display, and reliable data storage methods. A significant emphasis is placed on the recommendation to use UTC for data transmission to prevent anomalies. This guide is indispensable for developers and engineers working on internationalization (i18n) projects who need to integrate robust time management features. It includes practical Cangjie code examples utilizing LocalizationKit, enabling users to apply these concepts directly to ensure their applications function correctly across diverse global time zones.
