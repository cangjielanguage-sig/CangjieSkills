# 鼠标事件

This directory covers mouse interaction handling within the Cangjie UI framework (ArkUI). It includes documentation for configuring hover animations, handling specific mouse events like clicks and coordinates, and understanding the internal logic where mouse events are converted to touch events for unified handling. Key topics include `hoverEffect`, `onMouse`, and `onHover`. It is suitable for UI developers and application engineers building cross-device interfaces that require responsive mouse and touchpad support.

## Detailed Description

### hoverEffect.md hoverEffect.md
This API documentation explains the `hoverEffect` function used to configure mouse hover state animations for UI components in Cangjie. It covers the function signature, a detailed table of the `HoverEffect` enum values (Auto, Scale, Highlight, None), and a practical code example. Key takeaways include that these effects are fixed and non-customizable; Scale enlarges the component to 105%, Highlight darkens the background, and None disables the effect. Targeted at UI developers, this reference guide helps implement interactive visual feedback without custom animation parameters.

### onMouse.md onMouse.md
This document provides API reference documentation for the `onMouse` function in the Cangjie UI framework, enabling developers to handle mouse events on components. It covers the function signature, a description of the `MouseEvent` callback parameters (coordinates, buttons, actions), a note on button states, and a practical code example demonstrating event handling within a UI layout. Key takeaways include the ability to capture specific mouse actions and coordinates, support for event bubbling, and the structure of the `MouseEvent` object containing details like `MouseButton` and `MouseAction`. Intended for Cangjie developers building UI applications who need to implement custom mouse interaction logic.

### 鼠标事件_2more.md 鼠标事件_2more.md
This document serves as a technical reference for implementing mouse interactions in the ArkUI framework using the Cangjie language. It details supported events like `onHover` and `onMouse`, explaining the internal logic where left-click actions are converted to touch events for unified handling. The text provides a specific API breakdown for `onHover`, including its boolean parameter indicating mouse entry or exit and its default bubbling behavior. A practical code example illustrates how to dynamically alter a Button's style when the mouse enters or exits the component. This guide is intended for developers building cross-device applications that require responsive mouse and touchpad support.
