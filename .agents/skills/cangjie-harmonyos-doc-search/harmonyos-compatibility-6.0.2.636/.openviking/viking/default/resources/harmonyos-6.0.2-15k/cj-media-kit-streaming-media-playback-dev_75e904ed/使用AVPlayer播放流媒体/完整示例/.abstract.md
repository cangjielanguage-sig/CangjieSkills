This directory provides comprehensive code examples for implementing video playback using the AVPlayer class within the MediaKit framework. It covers essential functionalities such as streaming media playback (HLS VOD, HLS Live, DASH), lifecycle management, state change handling, and custom HTTP header configuration. Key topics include track selection, surface ID management, seek operations, buffering updates, and error recovery. These examples are designed for developers using ArkTS or Cangjie who need to integrate robust multimedia capabilities into their applications, serving as practical references for both basic playback logic and advanced network configurations. By exploring these files, developers will learn how to manage complex player states, handle rendering events, and ensure smooth media delivery across different streaming protocols.
