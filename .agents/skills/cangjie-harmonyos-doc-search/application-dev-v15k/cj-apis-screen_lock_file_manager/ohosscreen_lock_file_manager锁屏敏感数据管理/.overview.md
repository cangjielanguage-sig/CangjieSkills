# ohosscreen_lock_file_manager锁屏敏感数据管理

This directory contains documentation for the `ohos.screen_lock_file_manager` module, designed to manage sensitive data access permissions when a device screen is locked. It covers the security mechanism where sensitive data keys are destroyed upon locking and restored only after unlocking. The content includes API references for the `ScreenLockFileManager` class, status enums for access and release operations, and module configuration details. It is suitable for HarmonyOS developers using the Cangjie language who need to implement secure data protection features and handle permission states programmatically.

## Detailed Description

### class_ScreenLockFileManager.md
This API reference document details the ScreenLockFileManager class for managing sensitive data access permissions while the device screen is locked. It covers two primary static methods: acquireAccess for requesting permission and releaseAccess for revoking it, along with their return types (AccessStatus, ReleaseStatus) and potential BusinessException errors. Key takeaways include the synchronous nature of these calls, specific error codes for permission denial or system issues, and practical Cangjie code examples demonstrating implementation. Targeted at Cangjie developers, this documentation requires knowledge of system capabilities and exception handling to implement secure data protection features.

### enum_AccessStatus.md
This API reference document defines the Cangjie language enum AccessStatus, which represents the status of sensitive data access requests while the screen is locked. The documentation details two primary enum values, ACCESS_DENIED and ACCESS_GRANTED, alongside inherited comparison operators for equality checks and a toString method for string representation. Key information includes its inheritance from Equatable and ToString, and its association with the SystemCapability.Security.ScreenLockFileManager capability starting from version 19. This resource is intended for developers implementing security logic for lock screen file management who need to handle permission states programmatically.

### enum_ReleaseStatus.md
This API reference document defines the Cangjie language enum ReleaseStatus, which manages the release status of sensitive data access permissions under screen lock conditions. The documentation details the enum definition, its two primary values (RELEASE_DENIED and RELEASE_GRANTED), comparison operators (== and !=), and a string conversion method (toString). Key information includes that the enum inherits from Equatable and ToString, belongs to the SystemCapability.Security.ScreenLockFileManager capability, and is available starting from version 19. This document is intended for developers implementing security features related to screen lock file management who need to programmatically handle and compare permission states.
