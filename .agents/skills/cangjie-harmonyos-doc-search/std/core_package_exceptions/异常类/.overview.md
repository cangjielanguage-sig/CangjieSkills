# 异常类

This directory contains API documentation for the exception and error handling framework in the Cangjie programming language. It covers the base `Exception` and `Error` classes, along with numerous specific subclasses for handling runtime issues like arithmetic errors, memory violations, illegal arguments, and unsupported operations. Key topics include inheritance hierarchies, constructors, stack trace management, and error propagation. This documentation is suitable for Cangjie developers seeking to implement robust error handling, debug applications, and understand standard exception types within the core package.
