# cj-crypto-generate-message-digest

This directory contains a comprehensive development guide focused on the generation of SHA256 message digests using the Cangjie programming language within the CryptoArchitectureKit. It serves as an essential resource for developers aiming to implement secure cryptographic hashing in applications running on API version 12 and higher. The guide provides an in-depth analysis of two primary implementation strategies: single-pass data transmission, which is optimal for immediate processing of available data, and segmented data transmission, which is designed to handle large data streams efficiently. This flexibility is crucial for developers targeting lightweight wearable devices where memory and processing power are often constrained. The document clarifies that both transmission methods produce identical cryptographic results, ensuring data integrity regardless of the chosen approach. It features practical Cangjie code examples that walk through the usage of critical functions such as `createMd`, `update`, `digest`, and `getMdLength`. This material is intended for developers with a solid understanding of cryptographic operations and Cangjie syntax who need to ensure robust security features in their software projects.
