This directory contains the comprehensive API documentation for the UIContext module within the ArkUI framework, specifically tailored for the Cangjie programming language. It serves as a central resource for managing UI state, handling complex animations, and performing precise screen density unit conversions such as lpx, px, fp, and vp. Additionally, it covers essential dialog management functionalities including alerts and action sheets. This documentation is currently in Beta status and is designed for Cangjie developers and software engineers building responsive layouts and interactive components for HarmonyOS applications. It provides the necessary tools and references for developers requiring granular control over user interactions, ensuring a seamless and adaptive user experience across different devices.
