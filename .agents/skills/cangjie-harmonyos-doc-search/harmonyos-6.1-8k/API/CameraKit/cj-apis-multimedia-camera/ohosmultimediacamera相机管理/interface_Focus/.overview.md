# interface_Focus

本目录汇集了Cangjie语言CameraKit中关于相机对焦控制的核心API参考文档。内容主要涉及对焦接口的定义、对焦模式的设置、对焦点坐标的指定以及焦距值的查询。文档深入讲解了0-1坐标系的定义、方向转换逻辑、参数类型、必填项以及`BusinessException`异常处理机制。同时，提供了基于CameraKit的代码示例，演示如何在PhotoSession中调用相关接口。这些资料适用于具备基础编程能力的多媒体应用开发者，旨在帮助其实现精准、稳定的相机对焦控制功能。
