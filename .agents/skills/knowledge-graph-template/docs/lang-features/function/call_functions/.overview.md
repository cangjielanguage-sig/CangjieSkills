### call_functions.md call_functions.md

本文档介绍了仓颉编程语言中函数调用的语法规则及参数传递方式。主要涵盖非命名参数与命名参数的调用形式、命名参数传参顺序的灵活性，以及拥有默认值参数的处理机制。核心要点包括：实参类型需匹配参数类型；非命名参数直接传表达式，命名参数需使用“参数名: 表达式”格式；命名参数调用顺序可不同于定义顺序；未传值的命名参数将使用默认值，也可显式覆盖。适用于仓颉语言初学者或开发者，作为函数调用语法的参考指南。关键词：仓颉、函数调用、命名参数、默认值。
