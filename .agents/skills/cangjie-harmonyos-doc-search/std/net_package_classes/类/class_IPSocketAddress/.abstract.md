This directory provides comprehensive API reference documentation for the `IPSocketAddress` class within the Cangjie standard library's networking package. It details the implementation of immutable IP protocol socket addresses, which combine an IP address with a port number. The content covers class inheritance, constructors, properties, and various utility methods for parsing, comparing, and inspecting addresses. This documentation is intended for Cangjie developers and software engineers working on network programming tasks such as socket binding, connection management, and IP address validation.
