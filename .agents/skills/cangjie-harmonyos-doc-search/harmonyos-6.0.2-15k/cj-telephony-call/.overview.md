# cj-telephony-call

This directory serves as the definitive technical resource for developers implementing phone call functionality in third-party applications using the Cangjie programming language. It provides a comprehensive overview of the telephony development process, starting from scenario introductions and moving through complex implementation details. The guide covers essential basic concepts, including call state codes and system constraints, which are crucial for ensuring application stability and compliance with platform standards. It offers in-depth API descriptions for the call and observer modules, explaining how to effectively use `makeCall` to launch the system dialer and `hasVoiceCapability` to check for voice support. Furthermore, it details the implementation of optional state monitoring via `observer.on`, allowing applications to react dynamically to call status changes. With its step-by-step tutorial format and practical Cangjie code examples, this document is tailored for developers building telephony features on standard systems equipped with SIM cards, providing them with the necessary tools to create seamless communication experiences.
