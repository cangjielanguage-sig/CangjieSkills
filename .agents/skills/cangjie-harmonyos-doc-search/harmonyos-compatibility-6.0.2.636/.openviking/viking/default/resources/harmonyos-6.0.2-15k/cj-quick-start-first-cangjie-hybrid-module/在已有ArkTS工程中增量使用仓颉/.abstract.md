This directory serves as a comprehensive technical guide for HarmonyOS developers aiming to incrementally integrate the Cangjie programming language into existing ArkTS projects. It focuses on hybrid development workflows, enabling the seamless coexistence of ArkTS and Cangjie code within a single application architecture. Key topics include setting up the initial project structure, configuring module dependencies, calling Cangjie interfaces (both synchronous and asynchronous) from ArkTS, and embedding Cangjie UI components directly into ArkTS pages. This resource is ideal for developers looking to extend legacy ArkTS applications with high-performance Cangjie capabilities without rewriting the entire codebase, utilizing tools like DevEco Studio and Interop annotations.
