# 结构体

This directory serves as a comprehensive repository for API documentation regarding core data structures utilized within the Cangjie programming language's Abstract Syntax Tree (AST) package. It specifically focuses on the fundamental building blocks required for compiler construction, source code analysis, and tool development. The documentation covers essential structures such as `Position` for tracking code locations and `Token` for lexical analysis, detailing their properties, methods, and serialization capabilities. By implementing interfaces like `ToBytes`, these structures ensure efficient data handling. This resource is primarily designed for compiler developers, language engineers, and software architects seeking to understand or extend the Cangjie language infrastructure.

## Detailed Description

### struct_Position.md struct_Position.md

This document provides API reference documentation for the Cangjie Position struct, a data structure designed to represent source code location information including file ID, line number, and column number. The content details public properties, initialization methods for default or specific values, and utility functions such as dump for printing and isEmpty for validation. It also covers serialization via the toBytes method and equality comparison operators. Key takeaways include the struct's implementation of the ToBytes interface and its role within the AST package. This documentation is intended for developers working with compiler tools or source code analysis who require precise location tracking. Keywords: Cangjie, Position, struct, API, serialization, AST, source code location.

### struct_Token/

This directory provides comprehensive API documentation for the `Token` struct, a critical data structure within the Abstract Syntax Tree (AST) package designed for the Cangjie programming language. As the smallest lexical unit, the Token struct is essential for parsing source code and generating syntax trees. The documentation covers the struct's definition, including its core properties such as kind, position, and value, as well as its inheritance from the ToBytes interface for serialization. Additionally, it details operator overloads that enable developers to perform equality checks and merge token collections efficiently. This resource is specifically tailored for compiler developers, language engineers, and tool creators who require a deep understanding of lexical analysis and token manipulation to build robust Cangjie language tools and interpreters.
