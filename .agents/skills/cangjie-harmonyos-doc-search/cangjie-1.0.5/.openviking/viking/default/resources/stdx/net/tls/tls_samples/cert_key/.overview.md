# cert_key

本目录主要包含关于在仓颉编程语言中处理服务端证书和私钥的文档。内容重点在于如何读取和解析包含证书与私钥的单一PEM文件，并将其应用于TLS服务器的配置初始化。文档详细介绍了使用`Pem.decode`进行数据解析、通过标签过滤提取`X509Certificate`和`PrivateKey`对象，以及最终构建`TlsServerConfig`的完整流程。核心关键词包括仓颉、TLS、PEM解析、X509证书及私钥。这份资料适合需要在仓颉环境中配置HTTPS服务的开发者参考。

## 详细说明

### cert_key.md
这份文档演示了如何在仓颉编程语言中处理包含服务端证书和私钥的单一PEM文件。文档主要涵盖文件读取、PEM数据解析及TLS服务器配置初始化的代码示例。关键内容包括使用`Pem.decode`解析文本，通过标签过滤提取`X509Certificate`和`PrivateKey`，并最终构建`TlsServerConfig`对象。这是一份面向开发者的代码教程，旨在指导用户配置HTTPS服务，前提是用户需自行准备证书文件。关键词：仓颉、TLS、PEM解析、X509证书、私钥。
