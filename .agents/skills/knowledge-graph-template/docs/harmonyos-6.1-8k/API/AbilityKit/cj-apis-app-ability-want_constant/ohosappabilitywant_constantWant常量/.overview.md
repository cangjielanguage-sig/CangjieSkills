## 详细描述

### class_Flags.md
本文档是Cangjie语言中Flags类的API参考文档，定义了用于配置Want.flags字段的系统预置常量，主要涉及URI权限管理和原子化服务按需安装等功能。文档详细列出了五个静态常量，包括URI读写及持久化权限、原子化服务免安装拉起以及关闭匹配失败弹窗的标志位。关键信息包括各标志位的十六进制值及其具体功能，如临时或持久化授予URI数据权限、自动安装未安装的原子化服务，以及屏蔽隐式拉起失败时的默认提示弹窗。面向使用Cangjie进行应用开发的开发者，适用于需要控制应用跳转行为、数据访问权限及服务安装流程的场景。

### ohosappabilitywan_4more_6f97ec1f.md
本文档介绍了HarmonyOS仓颉开发中的want_constant模块，该模块提供了Want操作相关的系统预设枚举和常量。主要涵盖模块导入方法、所需权限列表（如分布式数据同步、隐私窗口等）以及API示例代码的使用说明。关键信息包括启动Ability时常用的Flag和Param参数，以及在仓颉模板工程中配置Context和运行示例的具体步骤。文档面向使用仓颉语言的HarmonyOS应用开发者，适用于需要处理Ability启动参数和系统权限配置的场景。

### class_Params/
本目录包含仓颉语言中 `Params` 类的 API 参考文档，主要定义了 HarmonyOS 开发中 `Want.parameters` 字段常用的系统预置关键字。内容涵盖 Ability 生命周期管理（如故障重启检测、跨任务栈返回行为）、原子化服务跨端分享配置以及跨端迁移行为控制（如页面栈迁移、源端应用退出）。适用于使用仓颉语言进行 HarmonyOS 应用开发且需要处理系统参数、跨端交互及 UIAbility 逻辑的开发者，要求 API 22 及以上版本。
