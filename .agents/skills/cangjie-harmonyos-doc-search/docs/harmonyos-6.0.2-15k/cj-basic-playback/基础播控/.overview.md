# 基础播控

This directory provides technical guides for implementing core playback control features in media applications using the AVSession framework. It covers essential functionalities such as displaying media metadata (covers, titles, subtitles), managing playback states (favorites, loop modes), and handling progress controls including seek functionality and special scenarios like VIP trials. Designed for application developers integrating media session capabilities, these documents ensure synchronization between the app and the system control center, offering a consistent user experience for audio and video playback interfaces.

## Detailed Description

### 副标题_7more.md 副标题_7more.md
This technical guide instructs developers on implementing and configuring playback control center features for media applications using the AVSessionKit framework. It covers displaying auxiliary information like subtitles, scrolling lyrics, and media source tags (e.g., AudioVivid). It details handling playback controls (play/pause, next/previous), managing button states for unsupported commands, and enabling navigation from the control card to the app's specific playback page. Key takeaways include using specific AVMetadata properties for text display and handling callbacks to synchronize playback state. The document emphasizes self-verification points for each feature to ensure correct display and functionality. This guide targets application developers integrating media session capabilities, requiring knowledge of the AVSession API.

### 媒体封面_2more.md 媒体封面_2more.md
This technical guide outlines specifications for displaying media covers and titles in the playback control center. It covers the implementation of AVMetadata properties, specifically mediaImage and title. Key sections detail resolution and aspect ratio requirements: music covers require a 1:1 ratio (recommended 800x800), while video supports 13:18 and 16:9 templates, with automatic cropping applied for mismatched dimensions. The document also explains title display behavior, noting that long strings scroll horizontally. Intended for application developers, it emphasizes using PixelMap for optimal performance and ensuring visual consistency in media playback interfaces.

### 收藏_3more.md 收藏_3more.md
This technical guide instructs developers on integrating advanced playback control features—favorites, loop modes, and fast forward/rewind—into media applications using the AVSession framework. The document details three distinct functionalities: syncing favorite states, managing loop mode switching (sequential, list, single, random), and implementing skip intervals for long-form content. Key takeaways include the necessity of maintaining state consistency between the app and the system control center. For loop modes, custom app modes must map to one of the four standard system modes. Skip intervals can be configured to 10s, 15s, or 30s. This guide is intended for media app developers, specifically those building music or audiobook platforms, who need to synchronize their internal playback logic with system-level controls.

### 进度与时间.md 进度与时间.md
This technical guide instructs developers on implementing and managing media playback progress within a control center environment. Main sections include progress display modes (draggable, auto-advancing, unavailable), progress control logic using AVPlaybackState, and handling special scenarios like VIP trials and advertisements. Key information highlights that developers should provide duration and register seek controls for draggable bars, while the system calculates progress automatically; apps only update state on specific events like play, pause, or seek. For VIP content, apps must handle relative timestamps and limit seeking to trial segments. This guide targets application developers integrating media session APIs who need to ensure consistent user experience for playback controls.
