This directory contains API reference documentation for the `PixelMap` class within the Cangjie language's ImageKit framework. It covers comprehensive functionalities for reading, writing, and managing image pixel data, including basic properties, resource management, and advanced image processing operations. Key topics include pixel format conversion, geometric transformations (scaling, rotating, flipping), color space management, and serialization for IPC. The documentation is designed for software developers and engineers building multimedia applications who require precise control over image manipulation, memory handling, and cross-process data transfer in the Cangjie environment.
