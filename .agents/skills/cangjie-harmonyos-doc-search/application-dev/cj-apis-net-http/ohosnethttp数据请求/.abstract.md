This directory provides comprehensive API reference documentation for the `ohos.net.http` module in the Cangjie programming language, designed to facilitate HTTP data requests in HarmonyOS applications. It covers the SystemCapability.Communication.NetStack, detailing essential classes for requests, responses, caching, and SSL management, alongside enumerations for protocols and methods. Developers will find resources for configuring network behaviors, handling multipart data, and monitoring performance. This documentation is essential for Cangjie developers implementing secure and efficient network communication, offering guidance on everything from basic request setup to advanced metrics tracking and resource management.
