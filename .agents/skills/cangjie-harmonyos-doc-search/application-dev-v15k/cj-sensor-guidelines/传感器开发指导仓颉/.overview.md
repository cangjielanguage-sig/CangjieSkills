# 传感器开发指导仓颉

This directory serves as a comprehensive resource for developers working on sensor integration using the Cangjie programming language. It provides a structured approach to understanding and utilizing device hardware sensors, covering everything from high-level architectural concepts to granular implementation details. The content includes an exploration of application scenarios such as orientation tracking and step counting, alongside a detailed breakdown of core sensor interfaces like `on`, `once`, `off`, and `getSensorList`. Furthermore, it offers a practical, step-by-step tutorial for the development lifecycle, emphasizing the accelerometer as a case study. Key technical considerations such as permission verification, sampling period configuration, and the trade-off between sampling frequency and power consumption are addressed. This guide is primarily intended for application developers who require a reliable reference for embedding sensor capabilities into their software projects using Cangjie.

## Detailed Description

### 场景介绍_2more.md 场景介绍_2more.md
This document serves as a high-level guide for the sensor module, outlining its application scenarios and core interfaces for accessing device hardware data. The content is divided into a scenario introduction, which highlights use cases like orientation tracking and step counting, and an interface summary table. Key information includes the four primary functions: on for continuous listening, once for single data retrieval, off to stop listening, and getSensorList to query available sensors. Intended for application developers, this document provides a quick reference to essential sensor APIs before directing users to detailed technical specifications.

### 开发步骤.md 开发步骤.md
This document serves as a step-by-step tutorial for developing sensor applications using the Cangjie language, utilizing the accelerometer as a primary example. It covers the complete development lifecycle including importing necessary modules, querying supported sensor parameters and sampling periods, verifying required permissions, and registering listeners via on() or once() interfaces. The guide also details how to cancel continuous monitoring using the off() method. Key information highlights the relationship between sampling frequency and power consumption. This technical guide is intended for application developers seeking to integrate sensor functionalities into their projects.
