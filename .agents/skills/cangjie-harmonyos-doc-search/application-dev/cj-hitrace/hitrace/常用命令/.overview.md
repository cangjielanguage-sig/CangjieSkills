# 常用命令

This directory serves as a comprehensive operational guide for the `hitrace` command-line tool, specifically tailored for the OpenHarmony development ecosystem. It provides essential documentation for system developers and performance analysts on how to effectively utilize the `hdc` shell to capture, manage, and export system performance traces. The content covers the complete workflow of trace analysis, ranging from basic operations like listing available trace tags and initiating recordings to advanced configurations such as buffer size adjustment, background snapshot recording, and data compression. By following these references, users can diagnose complex subsystem behaviors, monitor specific modules like graphics and power management, and prepare data for visualization in tools like Smartperf_Host to ensure optimal system performance.

## Detailed Description

### 常用命令_1.md 常用命令_1.md
This document provides a command reference for using the hitrace tool within the hdc shell to capture system performance traces. It details procedures for listing available trace tags, initiating and terminating trace recording, and configuring capture parameters like buffer size and duration. Key commands include hitrace -l for viewing tags, --trace_begin and --trace_finish for manual control, and combined options for automated capture with specific output paths. The guide is intended for developers debugging OpenHarmony subsystems, offering practical examples for tracking modules such as graphics, power, and applications.

### 常用命令_2.md 常用命令_2.md
This document serves as a practical reference guide for utilizing the hitrace command-line tool to capture, manage, and export system trace data. It details specific commands for dumping trace information to the console or files, operating snapshot mode for background recording, compressing output, and configuring trace clock sources. Key takeaways include the usage of flags like --trace_dump, --start_bgsrv, and -z, along with default file storage paths and integration with the Smartperf_Host visualization tool. This guide is intended for system developers and performance analysts seeking to diagnose system behavior and optimize performance through trace analysis.
