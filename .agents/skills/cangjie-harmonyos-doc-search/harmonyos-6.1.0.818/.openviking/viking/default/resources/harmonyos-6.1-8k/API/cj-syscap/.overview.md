# cj-syscap

This directory serves as a comprehensive technical resource dedicated to the understanding and implementation of OpenHarmony SystemCapability (SysCap). It addresses the critical relationship between underlying system capabilities and the application programming interfaces (APIs) exposed to developers, detailing the mechanisms that allow these capabilities to be distributed across diverse hardware environments. The content provides an in-depth analysis of how to manage capability differences between various devices, ensuring that applications can adapt to the specific hardware features available. Key topics include the distinction between supported capability sets (what the device provides) and required capability sets (what the application needs), the logic behind API filtering within DevEco Studio, and the compatibility verification processes that occur during application installation. This documentation is essential for OpenHarmony application developers and system solution providers who utilize DevEco Studio, providing the necessary guidance to guarantee application stability and compatibility across a wide range of device forms and system configurations.
