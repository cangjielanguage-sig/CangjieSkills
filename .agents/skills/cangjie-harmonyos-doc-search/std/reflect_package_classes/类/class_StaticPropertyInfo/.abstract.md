This directory provides comprehensive API reference documentation for the `StaticPropertyInfo` class within the Cangjie language's reflection package. It serves as a technical guide for developers who need to encapsulate and inspect metadata for static member properties. The documentation covers essential aspects such as accessing annotations, modifiers, names, and type information. It also details methods for retrieving and modifying static property values at runtime. This resource is suitable for developers utilizing runtime reflection to programmatically interact with static class members, offering insights into exception handling for abstract properties and the specific requirements for type safety and mutability when assigning values.
