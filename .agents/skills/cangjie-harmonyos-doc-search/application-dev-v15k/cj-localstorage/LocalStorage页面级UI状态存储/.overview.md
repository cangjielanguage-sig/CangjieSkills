# LocalStorage页面级UI状态存储

This directory provides comprehensive documentation and guides for managing page-level UI state using LocalStorage within the Cangjie framework. It covers core concepts like in-memory storage, lifecycle management, and state synchronization mechanisms. Key topics include the `@LocalStorageLink` and `@LocalStorageProp` decorators for data binding, usage constraints, and practical scenarios for state sharing across components and UIAbility instances. This resource is suitable for developers and architects working with HarmonyOS applications who need to implement reactive state management, ensure data persistence, and handle complex data types efficiently.

## Detailed Description

### LocalStorageLink.md LocalStorageLink.md
This API documentation defines the @LocalStorageLink decorator, which enables two-way synchronization between custom component state variables and LocalStorage. The document covers macro usage rules, variable passing restrictions, and observation behaviors for various data types including classes, arrays, and collections. Key takeaways include that the decorator requires a string key for bidirectional sync, ensuring local modifications update LocalStorage and trigger component re-renders. It supports complex types like Maps and Sets but prohibits initialization from parent nodes. This reference guide is intended for developers managing application state and data persistence within the UI framework.

### LocalStorageProp.md LocalStorageProp.md
This API documentation explains the @LocalStorageProp macro, which establishes one-way data synchronization between LocalStorage and custom component variables. The document details macro usage rules, variable passing constraints, and change observation behaviors for various data types including classes, arrays, and collections like Map and Set. Key takeaways include the requirement for a string key parameter, mandatory local initialization, and the fact that LocalStorage changes will always override local values. This reference guide targets developers using this UI framework who need to manage state persistence and data binding within their applications.

### LocalStorage页面级UI状态存储_2more.md LocalStorage页面级UI状态存储_2more.md
This guide explains LocalStorage, an in-memory storage mechanism for managing page-level UI state within the Cangjie framework. It covers the overview of LocalStorage, its lifecycle management, integration with component trees via the @Entry decorator, and the specific macros @LocalStorageProp and @LocalStorageLink for state synchronization. LocalStorage allows state sharing within a page or across pages in a UIAbility. It supports one-way and two-way data binding and is garbage collected when no longer referenced. Intended for developers with basic state management knowledge, this document serves as a technical guide for implementing efficient state storage.

### 限制条件.md 限制条件.md
This document outlines the specific constraints and usage rules for LocalStorage and its associated decorators in the Cangjie framework. The content covers parameter type requirements for decorators, unsupported variable types, immutability of attribute types after creation, and the scope of LocalStorage as page-level storage. Key takeaways include that @LocalStorageProp and @LocalStorageLink require string parameters, cannot decorate functions, and that attribute types are fixed once defined. It also clarifies that LocalStorage operates at the page level. This is a reference guide intended for developers using the Cangjie UI framework who need to implement state management correctly.
