This directory serves as a comprehensive technical resource for HarmonyOS developers aiming to integrate C++ code within Cangjie language modules. It focuses on achieving seamless interoperability between Cangjie and C++ within a single module, utilizing DevEco Studio as the primary development environment. The guide covers essential workflows such as project creation, adding C++ source files, declaring native functions using the `foreign` keyword, and configuring build dependencies in `cjpm.toml`. Additionally, it addresses critical operational requirements for deploying applications on real devices and emulators, including detailed instructions on signing and ABI filter configuration for x86 architectures. This documentation is ideal for developers seeking to leverage native C++ capabilities or validate their Cangjie applications across diverse execution environments.
