# WebSocket连接

This directory serves as a comprehensive technical resource for implementing WebSocket connections within HarmonyOS applications, specifically utilizing the Cangjie language and NetworkKit. It covers the full spectrum of WebSocket development, ranging from high-level API references and theoretical overviews to practical, step-by-step coding tutorials. Key topics include the WebSocket connection lifecycle, event handling for open, message, close, and error states, heartbeat mechanisms, and asynchronous event-driven architecture. The documentation details essential interfaces such as `createWebSocket`, `connect`, `send`, and `close`, alongside necessary permissions like `ohos.permission.INTERNET`. This resource is ideal for application developers and Cangjie programmers seeking to establish robust, real-time bidirectional communication between clients and servers efficiently.

## Detailed Description

### 场景介绍_2more.md 场景介绍_2more.md
This document provides a technical overview and API reference for implementing WebSocket connections in HarmonyOS applications. It covers the WebSocket connection lifecycle, event handling for open, message, close, and error states, and the heartbeat mechanism. The content details the webSocket module interfaces, including methods for creating, connecting, sending data, and closing connections, as well as subscribing to events. Key takeaways include the requirement for the ohos.permission.INTERNET permission and the specific usage of createWebSocket, connect, send, and close methods. This guide targets application developers seeking to establish real-time bidirectional communication between clients and servers.

### 开发步骤.md 开发步骤.md
This document serves as a technical tutorial guiding developers through the implementation of WebSocket communication using the Cangjie language and NetworkKit. It outlines a five-step development process: importing modules, creating a WebSocket object, subscribing to lifecycle events, establishing a connection, and disconnecting. The provided code example illustrates how to handle asynchronous events—specifically open, message, close, and error—using WebSocketAsyncCallback and WebSocketErrorCallback. Key takeaways include the usage of methods like send, connect, and close within an event-driven architecture. This guide targets Cangjie developers seeking to integrate real-time bidirectional communication into their applications.
