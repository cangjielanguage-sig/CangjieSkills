# MenuItem

本目录包含ArkUI框架下MenuItem组件的API参考文档，专为使用仓颉语言的开发者设计。内容涵盖了菜单项的创建与配置方法，包括支持二级菜单的构建、通用属性与事件的处理，以及字体样式、颜色和选中状态等UI细节的定制。该文档旨在帮助开发者构建具有丰富交互功能的菜单界面，适用于熟悉ArkUI框架并希望精细化控制菜单项外观与行为的开发人员。

## 详细说明

### MenuItem_5more_6c82ba60.md MenuItem_5more_6c82ba60.md
本文档是ArkUI框架中MenuItem组件的API参考文档，旨在指导开发者如何使用仓颉语言创建和配置具有二级菜单的菜单项。文档主要涵盖模块导入说明、组件创建方法（构造函数）以及通用属性与事件的支持情况。重点介绍了两种初始化方式：一种通过自定义UI构建器实现，另一种通过配置起始图标、内容文本、结束图标及标签信息（如快捷键）实现。文档指出该组件目前处于Beta阶段，支持全部通用属性和事件，并需结合@Builder宏使用。适用于熟悉ArkUI框架和仓颉语言的开发者，用于构建应用中的菜单交互界面。

### 组件事件_2more_5e95f46f.md 组件事件_2more_5e95f46f.md
本文档是ArkUI框架中组件事件API的参考文档，主要介绍了onChange回调函数的定义与用法。文档详细列出了该函数的签名、功能说明、系统能力要求及起始版本信息。核心内容指出，onChange仅在手动触发且组件选中状态改变时被调用，其参数为一个接收布尔值的回调函数。该文档面向使用仓颉语言进行ArkUI开发的开发者，旨在帮助其实现组件状态变化的监听与处理逻辑，相关示例代码需参考Menu组件文档。

### 组件属性/
本目录包含ArkUI框架下Cangjie语言的API参考文档，主要涉及菜单项的组件属性配置。内容涵盖了字体样式（大小、粗细、字族）、文本颜色、选中状态以及选中图标的显示逻辑。这些文档为ArkUI应用开发者提供了精细化的UI组件样式配置接口，适用于构建具有自定义外观的菜单交互界面。关键词包括ArkUI、Cangjie、菜单项、字体属性、图标配置。
