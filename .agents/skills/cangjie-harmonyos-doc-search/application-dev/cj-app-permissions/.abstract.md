This directory serves as the definitive guide for application permissions, designed to assist developers in navigating the complex landscape of authorization requirements. It functions as a central index, categorizing permissions into four distinct groups to simplify the application process: open permissions granted by the system, open permissions requiring user authorization, permissions specific to enterprise apps, and exclusive permissions for MDM (Mobile Device Management) apps. The documentation clearly delineates the boundaries of these categories, emphasizing that while open permissions are generally accessible, enterprise and MDM permissions are strictly regulated and available only through specific distribution types like enterprise_normal or enterprise_mdm. This resource is essential for developers aiming to ensure their applications comply with platform standards, providing the necessary clarity to select the correct permission type and application procedure based on the app's intended scope and distribution method.
