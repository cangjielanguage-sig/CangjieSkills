# 非对称密钥生成和转换规格

This directory provides technical specifications for generating and converting asymmetric keys within the Cangjie framework (API 12+). It covers major algorithms including RSA, DSA, ECC, Diffie-Hellman, SM2, Ed25519, and X25519. The documentation outlines methods for key generation using string parameters or specific key attributes, detailing constraints, supported key lengths, and parameter requirements. Designed for developers integrating cryptographic functions, these guides ensure secure implementation of digital signatures, key exchange, and encryption workflows.

## Detailed Description

### DH.md DH.md
This technical reference document outlines the implementation and usage of the Diffie-Hellman (DH) key exchange algorithm for secure key agreement. It covers three key generation methods: using string parameters (e.g., DH_modp2048), explicit key parameters (p, g, l, pk, sk), and prime/private key lengths. The document details supported well-known groups (modp, ffdhe), parameter definitions, and constraints for key lengths (512-10000 bits). It emphasizes that generating non-standard groups is resource-intensive and recommends using known groups for efficiency. Targeted at developers using API version 12+ who need to implement cryptographic key generation with forward security. Keywords: Diffie-Hellman, key exchange, API 12+, modp, ffdhe, cryptography.

### DSA.md DSA.md
This technical reference document outlines the implementation and usage of the Digital Signature Algorithm (DSA) for digital signatures and verification within a specific API framework. It covers DSA definitions, constraints regarding synchronous generation latency, and two key generation methods: using string parameters (e.g., DSA1024) and using specific key parameters (p, q, g, pk, sk). Key information includes supported key lengths (1024, 2048, 3072 bits), API version requirements, and a support matrix indicating which parameters are mandatory for generating public keys, private keys, or key pairs. It explicitly notes that DSA cannot be used for encryption and that generating private keys solely from private parameters is unsupported. This guide targets software developers integrating cryptographic functions, requiring knowledge of asymmetric cryptography concepts.

Key information includes a comprehensive list of supported curves (e.g., NID_secp224r1, BrainPool) and required attributes for public, private, and key pair generation, noting support for API version 12+. Targeted at developers integrating cryptographic functions, this guide requires prerequisite knowledge of asymmetric encryption concepts.

Keywords: ECC, Elliptic Curve Cryptography, Fp domain, key generation, asymmetric encryption, BrainPool, secp, API reference.

### RSA.md RSA.md
This technical reference document details the methods and specifications for generating RSA asymmetric keys within a specific API framework. It covers two primary generation approaches: using concatenated string parameters (key type and prime count) and using specific key parameters (modulus, public exponent, private exponent). Key information includes a support matrix for key sizes ranging from 512 to 8192 bits, noting that synchronous generation of larger keys is time-consuming. It also clarifies support limitations, such as the inability to generate random keys using only the modulus. This guide targets developers implementing cryptographic functions, requiring knowledge of RSA concepts and API version 12+. Keywords: RSA key generation, asymmetric cryptography, API 12+, key parameters, string parameters, modulus, prime count.

### SM2_3more.md SM2_3more.md
This technical reference document outlines key generation specifications for the SM2, Ed25519, and X25519 cryptographic algorithms. It details three main sections corresponding to each algorithm, explaining how to generate keys using either string parameters or specific key parameters. Key information includes SM2's support for Fp domain parameters and curve names like NID_sm2, requiring attributes such as p, a, b, and g. In contrast, Ed25519 and X25519 utilize 32-byte keys without public parameters. The document provides tables clarifying required attributes for public, private, and key pair generation. Targeted at developers implementing cryptographic functions, this guide assumes familiarity with asymmetric encryption concepts and is intended for use with API version 12+.
