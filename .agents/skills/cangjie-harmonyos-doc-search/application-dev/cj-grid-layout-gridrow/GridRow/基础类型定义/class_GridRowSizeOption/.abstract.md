This directory provides essential API reference documentation for the `GridRowSizeOption` class within the ArkUI framework, specifically curated for Cangjie developers. It focuses on the configuration of grid gutter sizes and the implementation of responsive layouts across a diverse range of device breakpoints, including xs, sm, md, lg, xl, and xxl. The documentation thoroughly covers the class structure, its six public properties, and two constructors, enabling developers to manage responsive design adjustments with nullable Length types. This resource is ideal for developers seeking precise control over component sizing and offsets in grid layouts. It requires the system capability ArkUI.Full and is available starting from version 22, serving as a foundational guide for building adaptive and robust user interfaces in the ArkUI ecosystem.
