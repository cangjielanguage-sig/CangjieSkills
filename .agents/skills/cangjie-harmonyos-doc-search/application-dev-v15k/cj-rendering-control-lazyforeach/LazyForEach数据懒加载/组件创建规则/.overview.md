# 组件创建规则

This directory provides a comprehensive technical guide on component creation rules within the LazyForEach mechanism for ArkUI development using the Cangjie language. It covers the fundamental specifications of the `itemGenerator` function, key-value generation strategies, and rendering behaviors across different lifecycle phases. Key topics include initial rendering logic, handling duplicate keys, and dynamic updates for non-initial rendering phases. This resource is essential for developers aiming to optimize list rendering performance, manage dynamic data loading, and ensure stable UI state synchronization in complex applications. It addresses common pitfalls like caching issues and provides strategies for efficient data observation.
