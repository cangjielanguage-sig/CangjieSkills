# 图形变换

This directory contains API reference documentation for graphic transformations within the ArkUI framework using the Cangjie programming language. It covers essential operations for manipulating UI components, including scaling, translating, and rotating elements in both 2D and 3D spaces. Key topics include transformation matrices, axis-specific adjustments, and coordinate system definitions. These resources are designed for developers working on application interfaces who need precise control over component geometry, layout positioning, and visual effects. The documentation details parameter types like Int32, Float32, and Length, ensuring comprehensive support for various transformation scenarios.
