# 菜单控制Menu

This directory focuses on menu control within the Cangjie and ArkUI frameworks, providing comprehensive guides for implementing interactive menus. It covers creating context menus triggered by right-click or long-press, building default and custom menu styles, and managing menu lifecycles and display modes (modal vs. non-modal). Key topics include the `bindMenu` and `bindContextMenu` interfaces, `@Builder` decorators, and event handling. These resources are suitable for UI developers looking to enhance application interactivity through robust menu systems.

## Detailed Description

### 创建支持右键或长按的菜单.md 创建支持右键或长按的菜单.md
This technical guide explains how to implement custom context menus triggered by right-click or long-press gestures using the bindContextMenu interface. The document covers menu content creation using the @Builder decorator, binding the menu to specific components, and configuring trigger types such as ResponseType.RightClick. Key information includes the fact that these menus render in an independent sub-window, enabling them to display outside the main application window boundaries. The guide provides a code example demonstrating the syntax for binding a custom menu builder to a button component. This resource is intended for UI developers working with the Cangjie framework who need to add interactive context menus to their applications.

### 创建默认样式的菜单.md 创建默认样式的菜单.md
This guide explains how to implement default and custom menus in Cangjie applications using the bindMenu interface. It covers creating simple default menus with Action and building complex custom menus using the @Builder decorator. Key information includes the structure of Menu, MenuItem, and MenuItemGroup, demonstrating resource binding, state management, and event handling like onChange. It also details how to bind sub-menus via the builder parameter. This tutorial is intended for Cangjie developers familiar with UI components and state management.

### 菜单控制Menu_2more.md 菜单控制Menu_2more.md
This document serves as a technical reference for implementing the Menu interface in the ArkUI framework, primarily used for right-click or click-triggered popups. It details the distinction between modal and non-modal display modes, explaining that using bindContextMenu with a preview image creates a modal state with an overlay, while bindMenu or bindContextMenu without a preview results in a non-modal state. Additionally, the document outlines the Menu lifecycle, providing a table of event callbacks such as aboutToAppear, onAppear, aboutToDisappear, and onDisappear to manage animation states. This guide is intended for developers seeking to control menu behavior and lifecycle events within their applications.
