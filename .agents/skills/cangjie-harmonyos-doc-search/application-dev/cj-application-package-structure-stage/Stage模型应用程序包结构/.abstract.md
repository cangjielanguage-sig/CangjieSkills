This directory provides comprehensive technical documentation on the application package structure for the HarmonyOS Stage model. It covers the project hierarchy during development, including configuration files like `app.json5` and `module.json5`, Cangjie source code, and resource management. Additionally, it details the structural transformation from the development phase to the final release state, explaining HAP generation, resource merging, and distribution packaging. Key topics include DevEco Studio project organization, build artifacts, and the distinction between App Packs and HAPs. This guide is suitable for HarmonyOS developers using the Cangjie language who need to understand project organization, build processes, and packaging logic.
