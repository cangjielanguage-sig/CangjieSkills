# 开发案例

This directory contains Cangjie code examples for cryptographic operations using the Universal Keystore Kit (HUKS) in HarmonyOS. It covers various encryption algorithms including AES (CBC, GCM), RSA (ECB with different paddings), and SM2. The examples demonstrate key lifecycle management (generation, encryption, decryption, deletion) and specific configurations like padding modes and digests. It is suitable for Cangjie developers and software engineers looking to implement secure data storage and cryptographic features within the HarmonyOS ecosystem.

## Detailed Description

### AESCBCPKCS7.md
This document provides a Cangjie code example demonstrating how to perform AES encryption and decryption using the CBC mode and PKCS7 padding via the Universal Keystore Kit. It covers key generation, data encryption, data decryption, and key deletion workflows. The code details the configuration of cryptographic properties, including algorithm selection, key size, padding mode, and initialization vector (IV) usage. Key takeaways include the specific HuksParam configurations for AES-128-CBC-PKCS7 and the session-based process involving initSession and finishSession. It highlights the importance of using a random IV in production environments. This tutorial targets Cangjie developers implementing secure data storage and requires prerequisite knowledge of cryptographic concepts and the Universal Keystore Kit API.

### RSAECBOAEPSHA256.md
This document provides a Cangjie code example demonstrating how to implement RSA encryption and decryption using the ECB mode, OAEP padding, and SHA-256 digest within the UniversalKeystoreKit framework. It covers helper functions for data conversion, configuration properties for key generation and cryptographic operations, and specific scenarios for key generation, encryption, decryption, and key deletion. The code utilizes a 2048-bit RSA key and follows a session-based workflow involving initSession and finishSession methods. It highlights specific Huks parameters like HUKS_PADDING_OAEP and HUKS_DIGEST_SHA256. This tutorial is intended for developers using the Cangjie language who need to integrate secure cryptographic operations into their applications.

### RSAECBPKCS1_V1_5.md
This document provides a Cangjie code example demonstrating RSA encryption and decryption using the ECB mode and PKCS1_V1_5 padding within the Universal Keystore Kit. It covers key generation, data encryption, data decryption, and key deletion. It includes helper functions for data conversion and configuration functions for setting cryptographic parameters like algorithm, key size, and padding. The code illustrates the full lifecycle of a cryptographic key, utilizing a 2048-bit RSA key. It highlights the use of `initSession` and `finishSession` for operations and specific tags for PKCS1_V1_5 padding and ECB block mode. This tutorial is intended for developers implementing security features in Cangjie applications who need to understand how to configure and execute RSA cryptographic operations.

### SM2.md
This document provides a practical Cangjie code example demonstrating how to implement SM2 cryptographic operations using the UniversalKeystoreKit. It covers the complete lifecycle of key management, including generating SM2 keys, encrypting plaintext, decrypting ciphertext, and deleting keys. Key sections detail the configuration of HuksParam properties for algorithm selection, key size, and digest methods, alongside the usage of API functions like generateKeyItem, initSession, and finishSession. This tutorial serves as a guide for developers seeking to integrate secure SM2 encryption and decryption functionalities into their applications using the HUKS framework.

### AESGCMNoPadding/
This directory serves as a technical resource for developers implementing AES-GCM (Galois/Counter Mode) encryption with NoPadding using the HarmonyOS Universal Keystore Kit (HUKS). It provides detailed code examples in Cangjie, demonstrating how to utilize hardware-backed key storage to secure sensitive data. The documentation covers the complete cryptographic workflow, starting from key generation and configuration of AES-128 properties, through to data encryption and decryption. It also emphasizes the correct handling of essential security parameters like Nonce, Additional Authenticated Data (AAD), and AE tags. Furthermore, it addresses key lifecycle management, specifically the secure deletion of keys. This guide is suitable for software engineers and security-focused developers working within the HarmonyOS ecosystem who need to ensure data confidentiality, integrity, and authenticity in their applications.
