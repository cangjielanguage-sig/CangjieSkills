# 组件创建规则

This directory provides comprehensive technical documentation regarding component creation rules within the LazyForEach framework mechanism, specifically designed for the Cangjie UI and ArkUI environments. It details the complete lifecycle of component generation, distinguishing between the initial first render and subsequent non-first render events. Key topics include the execution logic of the `itemGenerator` function, key generation strategies to ensure stability, and performance optimization techniques for dynamic data lists. This resource is essential for UI developers and engineers aiming to prevent caching errors, manage state synchronization, and implement efficient data-driven UI updates in complex applications.

## Detailed Description

### 组件创建规则.md 组件创建规则.md
This technical reference document defines the rules for component creation within the LazyForEach framework mechanism. It focuses on the execution of the itemGenerator function, which processes data source array items after key-value generation. The content is structured around two primary scenarios: the initial first render and subsequent non-first render events. Key takeaways include understanding how the itemGenerator functions differently depending on the rendering state to optimize performance. This guide is designed for developers working with dynamic data lists and requires prior knowledge of the LazyForEach lifecycle and key-value generation rules. Keywords: LazyForEach, itemGenerator, component creation, rendering rules, first render, non-first render, data source.

### 首次渲染.md 首次渲染.md
This technical guide explains the initial rendering process of the LazyForEach component in the Cangjie UI framework, specifically focusing on key generation rules. The document covers two primary scenarios: generating unique keys for correct rendering and the consequences of using identical keys. Key takeaways include that unique keys are essential for component stability, while duplicate keys lead to unpredictable behavior and caching errors during list scrolling. Targeted at UI developers, this guide provides code examples demonstrating correct and incorrect keyGenerator implementations to ensure proper list performance and visual consistency.

### 非首次渲染/
This directory focuses on managing dynamic UI updates and state synchronization for the `LazyForEach` component during non-initial rendering phases in the Cangjie and ArkUI frameworks. It covers essential techniques for modifying list data, including swapping items, updating single or multiple entries, and handling additions or deletions. Additionally, it addresses performance optimization strategies for updating sub-properties using decorators like `@Observed` and `@Link`. This resource is suitable for developers working with dynamic lists who need to implement efficient data-driven UI updates and maintain high rendering performance in complex applications.
