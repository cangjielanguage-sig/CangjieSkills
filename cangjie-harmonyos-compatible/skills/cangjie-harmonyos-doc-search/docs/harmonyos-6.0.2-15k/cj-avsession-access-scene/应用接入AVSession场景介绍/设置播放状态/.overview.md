# 设置播放状态

This directory serves as a comprehensive technical resource for configuring and managing media playback states within a system control center, utilizing the Cangjie language and the AVSessionKit framework. It addresses the core requirements for multimedia application development, such as synchronizing playback status, implementing progress bars, and managing metadata. The documentation delves into specific implementation details, including handling state attributes like position and speed, managing buffering, and dealing with special scenarios like trial listening and advertisements. By providing code examples and explaining system calculation logic, it guides developers on when to update the `AVPlaybackState` to ensure accurate UI representation. This content is specifically designed for application developers and engineers who are building media applications and need to integrate their custom playback logic with the system's native control center for a cohesive user experience.

## Detailed Description

### 进度条.md 进度条.md
This technical guide explains how to configure and manage media playback progress bars within a system control center using the Cangjie language and AVSessionKit. It covers setting media metadata and playback state via code examples, system calculation logic, and handling special scenarios like trial listening, non-trial content, and advertisements. The system automatically calculates progress, requiring apps to update AVPlaybackState only when state, position, or speed changes. Specific strategies are provided for handling trial durations and separating ad durations from main content. This is intended for application developers working on media playback features who need to integrate with the system's playback control center.

### 通用播放状态.md 通用播放状态.md
This document serves as a technical guide for developers to synchronize application playback status with the system using the AVSessionKit API. It covers the definition of playback state attributes, including state, position, speed, and loop mode, and provides a practical Cangjie code example demonstrating the implementation. The core takeaway is the usage of the setAVPlaybackState function to update the system control center, handling properties like PLAYBACK_STATE_PAUSE and error management. Intended for application developers working with multimedia sessions who need to display dynamic playback information in the system UI.
