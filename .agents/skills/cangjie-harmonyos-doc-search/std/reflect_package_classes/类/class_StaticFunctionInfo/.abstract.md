This directory contains API reference documentation for the `StaticFunctionInfo` class within the Cangjie programming language's reflection framework. It covers metadata retrieval for static member functions, including properties like name, parameters, and return types, as well as methods for dynamic invocation and annotation inspection. Key topics include reflection, introspection, dynamic method calls, and exception handling. This documentation is suitable for developers who need to programmatically inspect or execute static functions at runtime, requiring knowledge of generic types and standard interfaces like Equatable and Hashable.
