# 系统相册资源使用指导

This directory provides comprehensive technical guidance for developers working with system album resources in the OpenHarmony ecosystem using the Cangjie programming language. It covers the utilization of the `photoAccessHelper` module and `MediaLibraryKit` to access, manage, and manipulate specific media assets such as favorites, videos, screenshots, and screen recordings. The content includes practical code examples, prerequisite checks, and implementation workflows for integrating native gallery features. It is suitable for application developers seeking to build media-rich applications or implement photo management functionalities within the OpenHarmony environment.

### 系统相册资源使用指导.md
This guide instructs developers on how to utilize the photoAccessHelper module to access and manipulate specific system album resources. The document covers the scope of supported album types, including favorites, videos, screenshots, and screen recordings, while outlining necessary prerequisites. Key information includes the current Beta status of the feature, the requirement to initialize the PhotoAccessHelper object before execution, and the assumption that target resources are pre-existing in the database. This technical guide targets application developers working with system media assets, serving as a usage reference for implementing album-related functionalities.

### 收藏夹/
This directory provides a comprehensive technical guide for developers utilizing the Cangjie programming language to interact with the system Favorites album via MediaLibraryKit. It focuses on the programmatic management of user-favorited media content, detailing the necessary steps to access the system album and retrieve specific assets. Key topics include configuring `AlbumType.SYSTEM` and `AlbumSubtype.FAVORITE`, invoking the `getAlbums` interface, and handling data retrieval through `Album.getAssets`. The documentation includes practical Cangjie code examples covering context initialization, exception handling, and resource management. These resources are specifically designed for application developers building media features who require a deep understanding of the photoAccessHelper module to effectively integrate and manage favorites within their applications.

### 视频相册/
This directory serves as a comprehensive technical resource for HarmonyOS developers working with media management using the Cangjie programming language. It focuses specifically on the mechanisms required to interact with system video albums, covering the essential workflows for accessing, filtering, and retrieving video assets programmatically. The documentation details the practical application of MediaLibraryKit, photoAccessHelper, and DataSharePredicates to effectively manage media content. Whether you need to initialize UIAbility contexts, implement robust error handling, or understand the structural definitions of system video collections, these guides provide the necessary code examples and theoretical background. This content is ideal for developers building media-rich applications who require deep integration with the device's native gallery and video storage systems.
