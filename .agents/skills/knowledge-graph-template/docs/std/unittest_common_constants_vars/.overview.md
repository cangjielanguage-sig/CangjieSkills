# unittest_common_constants_vars

This directory acts as a centralized repository for the API reference regarding internal constants and variables utilized within the Cangjie unit testing framework. It specifically focuses on documenting the `optionsInfo` registry, which functions as a mapping mechanism for strings to option data structures, and the `unittestOptionsRegistryClosed` boolean flag. The documentation highlights the use of specific data types, including HashMap and Bool, providing clarity on the internal implementation details. Crucially, this content is designated for internal framework use only and is not intended for direct interaction by general users. It is primarily suitable for framework developers and maintainers who possess advanced knowledge of the Cangjie language and the internal architecture of the testing framework. As there are no subdirectories, all technical specifications are consolidated within the primary documentation file, making it a single source of truth for these low-level components.
