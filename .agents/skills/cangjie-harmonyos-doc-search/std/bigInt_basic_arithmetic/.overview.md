# bigInt_basic_arithmetic

This directory serves as a comprehensive educational resource focused on the implementation of high-precision arithmetic using the `BigInt` class within the Cangjie programming language. It addresses the critical need for handling integer values that exceed the storage capacity of standard primitive data types, providing developers with robust tools to perform accurate calculations on arbitrarily large numbers. The content thoroughly covers the complete workflow required to utilize these features, starting with the necessary syntax for importing the `std.math.numeric` module and progressing to object initialization via string parsing. It details the practical application of standard arithmetic operators—specifically addition, subtraction, multiplication, and division—and introduces the specialized `divAndMod` method for efficient simultaneous quotient and remainder extraction. This tutorial is primarily suitable for Cangjie developers, software engineers, and students who are building applications in domains such as financial computing, cryptography, or scientific research where numerical precision is paramount. By engaging with this material, users will acquire a solid understanding of the syntax, operational logic, and output formatting required to manipulate large integer values effectively within their Cangjie projects.
