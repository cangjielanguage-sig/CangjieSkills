# User-Agent开发指导

This directory provides comprehensive guidance on User-Agent (UA) string management within the OpenHarmony and HarmonyOS ecosystems. It covers the structural definition of UA strings, device identification techniques, and customization methods using the ArkWeb component and Cangjie language. Key topics include parsing device types, version detection, and modifying UA strings for debugging or specific request identification. This documentation is suitable for web developers needing to adapt content for HarmonyOS devices and application developers implementing custom web request logic.

## Detailed Description

### User-Agent开发指导_2more.md User-Agent开发指导_2more.md
This development guide explains the structure and significance of the User-Agent string within the OpenHarmony ecosystem to ensure proper web content rendering. It covers the definition of User-Agent, the default string structure, and a detailed breakdown of specific fields such as DeviceType, OSName, and ArkWeb version codes. Key takeaways include the specific format of the default string, how the presence of the "Mobile" field controls viewport meta tag behavior, and recommendations to use the "OpenHarmony" keyword for device identification. This guide is intended for web developers utilizing the ArkWeb component who need to customize content based on device characteristics.

### 常见问题.md 常见问题.md
This technical guide serves as a FAQ for developers on identifying and debugging HarmonyOS devices via User-Agent strings. The document details a three-step identification process: detecting the operating system, parsing the version number, and determining device types such as Phone, Tablet, or 2in1. It provides JavaScript code snippets using regular expressions for accurate detection. Additionally, it explains how to simulate these User-Agent strings using browser DevTools on non-HarmonyOS systems for frontend debugging. Targeted at web developers, this reference ensures precise device recognition and facilitates cross-platform testing workflows. Keywords: HarmonyOS, User-Agent, device identification, frontend debugging, JavaScript.

### 自定义User-Agent结构.md 自定义User-Agent结构.md
This technical guide explains how to retrieve, customize, and manage User-Agent strings within the ArkWeb component using the Cangjie language. It covers three primary API functions: getUserAgent, setCustomUserAgent, and getCustomUserAgent, providing code examples for each. Key recommendations include appending custom identifiers to the default User-Agent rather than overwriting it to preserve system information. The document emphasizes specific timing rules: setCustomUserAgent should be called within the onControllerAttached callback when a URL is pre-set to ensure consistency, avoiding the onLoadIntercept event. This guide targets HarmonyOS application developers using the ArkWeb kit who need to implement specific web request identification or debugging features.
