This directory contains API reference documentation for the `ohos.net.connection` module within the HarmonyOS Cangjie development environment. It covers comprehensive network connection management capabilities, including network state monitoring, address resolution, proxy configuration, and property retrieval. Key components include classes for network handles, capabilities, and connection properties, alongside functions for managing default networks and reporting connectivity status. This documentation is intended for HarmonyOS developers using the Cangjie language who need to implement robust network communication features, manage network transitions, and handle system-level networking tasks within the NetworkKit framework.
