This directory contains API reference documentation for the `Arbitrary` interface within the Cangjie programming language's `unittest_prop_test` package. It details implementations for generating random values across various data types, including numeric primitives, strings, and generic collections like Arrays and HashMaps. Each document explains the static `arbitrary` function required to produce `Generator` instances from a `RandomSource`. This resource is essential for developers performing property-based testing who need to understand how specific types conform to the `Arbitrary` interface to automate random data generation in their unit tests.
