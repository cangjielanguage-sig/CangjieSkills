# 设置应用子窗口

This directory serves as a comprehensive technical resource for HarmonyOS developers focusing on the implementation and configuration of application sub-windows using the Cangjie language. It provides a structured approach to window management, covering the full lifecycle from creation and property adjustment to display and destruction. The content highlights specific technical procedures, such as setting dimensions before displaying windows and integrating sub-windows with UI components like AppStorage. Furthermore, it offers critical guidance on the limitations of sub-windows in various display modes, such as split-screen or freeform windows, and suggests alternative solutions like the overlay attribute for better performance. This resource is ideal for developers and UI engineers who need to create dynamic, multi-window interfaces while adhering to platform constraints and optimizing user experience in HarmonyOS applications. It is essential reading for anyone building complex UIs.

## Detailed Description

### 开发步骤.md 开发步骤.md
This guide outlines the standard procedure for managing application sub-windows using the Cangjie language in HarmonyOS development. It covers four sequential steps: creating a sub-window via createSubWindow, configuring properties like size and position, displaying content with showWindow, and destroying the window using destroyWindow. The document emphasizes setting window dimensions before calling showWindow to control default sizing behavior. It provides two implementation examples: one within the onWindowStageCreate lifecycle method and another triggered by a UI button click using AppStorage. This tutorial targets HarmonyOS application developers familiar with Cangjie syntax and ArkUI components.

### 设置应用子窗口.md 设置应用子窗口.md
This guide instructs developers on creating and configuring application sub-windows, such as popups, for custom UI requirements. It primarily focuses on the limitations of sub-windows, specifically advising against their use in mobile scenarios, split-screen, or freeform modes where they are constrained by main window bounds or lack adaptive resizing. The document highlights that sub-windows may have restricted customization on certain platforms and recommends using the overlay attribute instead for better performance and flexibility. Intended for UI developers, this technical reference helps in choosing the right component for dynamic interface elements.
