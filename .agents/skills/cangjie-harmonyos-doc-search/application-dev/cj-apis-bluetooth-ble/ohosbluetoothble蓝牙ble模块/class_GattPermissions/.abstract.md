This directory contains API reference documentation for the `GattPermissions` class within the Cangjie language. It focuses on defining and managing access permissions for Bluetooth GATT characteristics and descriptors. The content covers the class definition, constructor parameters, and detailed descriptions of boolean properties governing read and write operations, including requirements for encryption, Man-in-the-Middle (MITM) protection, and data signing. This documentation is suitable for Bluetooth application developers using the Cangjie language who need to implement secure GATT server or client functionalities and configure specific security levels for data exchange.
