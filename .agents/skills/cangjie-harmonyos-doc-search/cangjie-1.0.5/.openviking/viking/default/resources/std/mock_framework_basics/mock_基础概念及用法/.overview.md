# mock_基础概念及用法

This directory serves as a comprehensive resource for understanding and applying mocking concepts within the Cangjie testing framework. It thoroughly covers the creation, configuration, and distinction between mock and spy objects, highlighting how spies delegate to original implementations while mocks enforce strict stubbing. The documentation extends to compilation requirements, dependency injection, and the Configuration API for advanced behaviors like parameter matching and call cardinality. Designed for Cangjie developers and QA professionals, this guide provides the essential knowledge needed to isolate units, simulate complex dependencies, and implement effective test doubles for robust software verification.

## Detailed Description

### 使用_spy_和_mock_对象_2more.md 使用_spy_和_mock_对象_2more.md
This technical guide explains the usage and configuration of spy and mock objects in the Cangjie testing framework. It covers the core distinction: spy objects invoke original implementations when unstubbed, while mock objects throw runtime errors. The document details how to override behavior using spies and outlines the compilation requirements for mocking dependencies, specifically the use of the --mock flag with cjc and automatic handling with cjpm. It highlights that interfaces are always mockable, whereas mocking classes requires specific compilation settings. Targeted at Cangjie developers, this guide provides essential knowledge for isolating units and simulating dependencies during testing.

### 创建_mock_对象.md 创建_mock_对象.md
This document provides a technical reference for creating mock and spy objects in the Cangjie programming language. It introduces the `mock` and `spy` constructor functions, explaining that `mock` generates a skeleton object with no default behavior, whereas `spy` wraps an existing instance to delegate member calls by default. The text clarifies that only classes and interfaces are supported for this type of mocking and references advanced usage for static declarations. This guide is intended for developers implementing unit tests who need to simulate or monitor object interactions. Key concepts include test doubles, dependency injection, and object encapsulation.

### 配置_API/
This directory contains comprehensive documentation for the Configuration API of a Cangjie mocking framework. It covers essential aspects of defining mock and spy behaviors, including parameter matching, operation definitions, and stub chaining. Developers will find guides on using the `@On` macro, setting return values, enforcing call cardinality, and handling complex sequential logic. This resource is suitable for software engineers and QA professionals looking to isolate dependencies and simulate component behavior during unit testing in the Cangjie language.
