# 权限列表

This directory serves as a comprehensive repository for OpenHarmony and HarmonyOS permission reference documents. It details the definitions, access levels, and authorization mechanisms for a wide array of system-level capabilities. Key topics include managing hardware interfaces like disk and Bluetooth, configuring network settings, accessing sensitive user data such as contacts and media, and customizing UI elements. The documentation primarily focuses on permissions introduced in API version 12, classified under the system_basic level. This resource is essential for system application developers and integrators seeking to implement secure, high-privilege features within their applications.

## Detailed Description

### ohospermissionMANAGE_PAST_15more.md ohospermissionMANAGE_PAST_15more.md
This reference document defines a set of system-level permissions introduced in OpenHarmony API version 12. The content covers permissions for managing clipboard and UDMF data sharing, accessing disk hardware, preloading files, configuring proxy scripts, and managing device restrictions. It also includes permissions for fraud detection tools, persisting Bluetooth addresses, controlling virtual screens, modifying APN settings, and accessing kernel-level memory interfaces. Key takeaways indicate that all listed permissions are classified as system_basic level, utilize system_grant authorization, and are available starting from version 12. This document targets system application developers and integrators requiring access to sensitive hardware, network, or security features.

### ohospermissionSYSTEM_FLOA_15more.md ohospermissionSYSTEM_FLOA_15more.md
This document serves as a technical reference for specific HarmonyOS permissions, detailing their definitions, access levels, and authorization requirements. It covers permissions for system float windows, contact and media data access (audio, image, video), clipboard reading, file persistence, input monitoring, Wi-Fi peer MAC addresses, and kernel memory protection for cross-platform frameworks. Key information indicates that most permissions are classified as system_basic level, requiring either system or user grant, and start from API version 12. Notable exceptions include a 30-minute limit for short-term media writing and specific restrictions for kernel permissions on tablet devices. This reference is intended for HarmonyOS application developers who need to request sensitive system capabilities or access user data.

### ohospermissionkernelSUPPOR_4more.md ohospermissionkernelSUPPOR_4more.md
This document serves as a technical reference for specific HarmonyOS permissions required to access advanced system features. It details four distinct permissions: `SUPPORT_PLUGIN`, `CUSTOM_SANDBOX`, `MANAGE_SCREEN_TIME_GUARD`, and `CUSTOMIZE_SAVE_BUTTON`. Each entry provides the permission description, level, authorization method, and starting API version. Key takeaways include that all listed permissions are system_basic level requiring system_grant authorization, covering capabilities like plugin installation, dynamic sandboxing, screen time control, and UI customization. This reference is intended for HarmonyOS developers who need to declare these permissions to implement specific system-level behaviors or UI modifications in their applications.
