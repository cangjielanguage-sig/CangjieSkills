This directory provides comprehensive documentation for the `CString` type within the Cangjie programming language, specifically focusing on C language interoperability and Foreign Function Interface (FFI) tasks. It covers the fundamental definition of C-style strings, their creation, and the critical memory management procedures required when bridging Cangjie with C libraries. Key topics include the `CString` constructor, the `LibC` struct's `mallocCString` function, and the necessity of manual memory release using the `LibC free` method. Additionally, it details extensions for the `ToString` interface, enabling safer string manipulation and lexicographical comparisons. This resource is essential for Cangjie developers who need to handle low-level string operations, manage unsafe memory manually, and ensure null-safety when interacting with native C code. The documentation ensures developers can effectively utilize FFI capabilities while maintaining system stability.
