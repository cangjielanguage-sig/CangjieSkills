This directory contains the API reference documentation for the HarmonyOS Bluetooth A2DP module, specifically designed for the Cangjie programming language. It covers essential components for implementing Bluetooth audio streaming, including encoder configuration (CodecInfo), playback state management, and A2DP source profile operations. The documentation details enums for sample rates, channel modes, and codec types, alongside classes for managing device connections and events. Suitable for developers working on Bluetooth Core capabilities (version 19+), this module provides the necessary tools to configure audio parameters, monitor playback status, and handle A2DP source interactions in HarmonyOS applications.
