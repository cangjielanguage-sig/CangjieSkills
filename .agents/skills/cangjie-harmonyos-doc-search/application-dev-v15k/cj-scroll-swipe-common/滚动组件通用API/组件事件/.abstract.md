This directory contains API reference documentation for scroll-related event callbacks within the Cangjie ArkUI framework. It focuses on the mechanisms for monitoring and controlling scroll behaviors in UI components. The documentation covers a range of events including scroll start, stop, offset changes, and boundary detection. Key topics include `onDidScroll`, `onWillScroll`, `onReachEnd`, and `onScrollStart`. These resources are essential for developers using the Cangjie language who need to implement interactive scrolling logic, handle edge effects, or manage controller interactions in their applications.
