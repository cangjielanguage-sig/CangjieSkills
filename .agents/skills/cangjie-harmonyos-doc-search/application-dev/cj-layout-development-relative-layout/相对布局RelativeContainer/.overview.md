### 组件尺寸.md 组件尺寸.md
This technical guide explains the priority rules for determining component dimensions within a RelativeContainer when explicit size settings conflict with relative layout alignment rules. It covers the hierarchy of size constraints, specific rendering failure conditions, and provides a practical Cangjie code example demonstrating complex alignment scenarios. Key information includes that explicit size attributes take precedence over alignment anchor dimensions. To ensure strict alignment with anchors, developers should rely solely on alignRules and avoid explicit size settings. Components may fail to render if constraints are unsolvable or anchor positions are contradictory. This guide targets ArkUI developers using the Cangjie language who need to master relative layout behaviors and constraint resolution.
