This directory provides a comprehensive collection of API reference documents designed for developers working with the CameraKit framework in the Cangjie language. The content focuses specifically on the `interface_Focus` module, which is critical for managing and controlling camera device focus operations. It covers a wide range of functionalities, from configuring focus modes and setting specific focus points to querying current focus states and retrieving focal lengths. The documentation explains complex logic such as the 0-1 coordinate system relative to device orientation and details necessary prerequisites like verifying mode support. Furthermore, it includes guidance on error handling for specific BusinessException codes, such as session configuration failures. This resource is primarily suitable for software developers and multimedia engineers who are building camera-integrated applications and need to implement precise, reliable focus management features to enhance user experience.
