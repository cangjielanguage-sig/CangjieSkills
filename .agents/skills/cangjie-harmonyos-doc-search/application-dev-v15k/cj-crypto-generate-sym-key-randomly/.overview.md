# cj-crypto-generate-sym-key-randomly

This directory serves as a comprehensive technical guide for Cangjie developers focused on implementing cryptographic security. It details the process of randomly generating symmetric keys using the CryptoArchitectureKit, specifically covering the AES-256 and SM4-128 algorithms. The content provides step-by-step instructions and Cangjie code examples, walking through the core workflow of creating a SymKeyGenerator, invoking generateSymKey, and retrieving binary data via getEncoded for storage or encryption. This resource is ideal for developers with a basic understanding of symmetric encryption who need practical guidance on using the CryptoArchitectureKit API to generate secure keys.

This technical guide explains how to randomly generate symmetric keys using the Cangjie programming language's CryptoArchitectureKit. It covers the generation of AES-256 and SM4-128 keys, providing step-by-step instructions and corresponding Cangjie code examples for each algorithm. This tutorial targets Cangjie developers implementing cryptographic security, requiring basic knowledge of symmetric encryption concepts and the CryptoArchitectureKit API.
