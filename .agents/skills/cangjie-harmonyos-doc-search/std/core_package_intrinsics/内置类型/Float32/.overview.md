# Float32

This directory provides comprehensive documentation for the Float32 data type, specifically tailored for the Cangjie programming language. It encompasses the fundamental definition of the 32-bit floating-point format, detailing its strict adherence to the IEEE 754 standard's binary32 single-precision specification. Beyond the core definition, the directory includes extensive API extensions that introduce mathematical constants, utility functions for boundary checks, bitwise manipulation capabilities, and standard interface implementations for comparison, hashing, and string conversion. This collection of reference materials is highly suitable for developers, engineers, and systems programmers working on low-level data structures, graphics programming, or any application requiring precise numerical definitions and high-performance floating-point operations.

### Float32.md Float32.md
This document serves as a reference definition for the Float32 data type, explaining its fundamental representation and compliance with industry standards. The content focuses on the Float32 data type, specifically detailing its 32-bit floating-point nature and its adherence to the IEEE 754 standard's binary32 single-precision format. The key takeaway is that Float32 is a standard numerical type used for representing decimal numbers with single precision, strictly following the IEEE 754 specification for binary32. This reference material is intended for developers or engineers working with low-level data structures, graphics programming, or systems requiring precise numerical definitions.

### extend_Float32.md extend_Float32.md
This API documentation extends the Cangjie Float32 type to support mathematical constants and utility functions. It covers static properties for accessing floating-point limits like Max, Min, Inf, NaN, MinDenormal, and MinNormal. Additionally, it documents static functions for finding maximum and minimum values across variable arguments, which return NaN if present. The file also describes instance methods such as isInf, isNaN, and isNormal for validating number states. This reference is intended for Cangjie developers who need to perform precise floating-point boundary checks and comparisons.

### extend_Float32_4more.md extend_Float32_4more.md
This API documentation file details extensions for the Float32 type in the Cangjie programming language, enabling bitwise conversions and interface implementations. The document covers four main extensions: basic bitwise manipulation, the Comparable interface for ordering, the Hashable interface for hashing, and the ToString interface for string conversion. Key functions include fromBits and toBits for direct bit-level conversion with UInt32, compare for ordering logic, hashCode for generating Int64 hash values, and toString which defaults to six decimal places. This reference guide targets Cangjie developers seeking to manipulate Float32 values at the bit level or integrate them into collections and string operations.
