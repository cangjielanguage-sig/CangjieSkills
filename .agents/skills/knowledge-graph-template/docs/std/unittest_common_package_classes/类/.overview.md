# 类

This directory provides API reference documentation for core classes in the Cangjie language, focusing on unit testing configuration and text formatting utilities. It covers the `Configuration` class for storing test data, `ConfigurationKey` for type-safe key management, `PrettyText` for intermediate output storage, and the `PrettyPrinter` utility for formatted console output. These resources are essential for Cangjie developers building testing frameworks or command-line tools that require structured data handling and aesthetic text presentation.

## Detailed Description

### class_Configuration.md class_Configuration.md
This API reference document details the Configuration class in the Cangjie language, which serves as a storage container for unittest configuration data generated by the @Configure macro. The documentation outlines the class structure, inheritance from ToString, and its similarity to HashMap with KeyFor typed keys. Key sections cover the constructor, data manipulation methods for getting, setting, and removing values using either KeyFor objects or string names, and a static merge function to combine configurations where child values override parent ones. Important takeaways include the use of generic types for type-safe retrieval and the handling of optional return values. This guide targets Cangjie developers working with unit testing frameworks who require programmatic control over test configurations.

### class_ConfigurationKey.md class_ConfigurationKey.md
This API reference document defines the ConfigurationKey class, an abstract sealed class in the Cangjie language used to represent configuration item keys. The documentation covers the class structure, including its inheritance from Equatable and Hashable interfaces. Key sections detail the public name property, equality operators for comparison, and the hashCode method. Additionally, it explains the static create extension function for instantiating keys with a specific name and type. This guide is intended for developers implementing or interacting with configuration management systems, providing the necessary interface details for key manipulation and comparison.

### class_PrettyText.md class_PrettyText.md
This API documentation defines the PrettyText class in the Cangjie language, designed for storing and managing printed output as an intermediate data structure. The document details the class definition, inheritance hierarchy, constructors, and instance methods like isEmpty, pprint, and toString, alongside a static factory method of. Key information includes that PrettyText implements PrettyPrinter, PrettyPrintable, and ToString interfaces, enabling it to both receive and generate formatted text. It supports initialization with an optional starting string and conversion from other printable types. This reference guide targets Cangjie developers working with unit testing or text formatting utilities who need to manipulate or buffer pretty-printed content.

### class_PrettyPrinter/
This directory provides comprehensive API reference documentation for the Cangjie `PrettyPrinter` class, a utility designed for sophisticated formatted console output. It covers a wide range of features including color management, text alignment (left, right, center), indentation control, and string appending mechanisms. The documentation highlights the class's ability to handle both raw strings and objects implementing the `PrettyPrintable` interface, with a focus on method chaining for fluent code construction. This resource is essential for Cangjie developers, particularly those building testing frameworks or command-line tools that require structured, readable, and aesthetically pleasing text output.
