This directory serves as a comprehensive repository for the `cj-apis-crypto` documentation, specifically focusing on the `ohoscrypto` cryptographic framework designed for the Cangjie programming language. It encompasses a wide array of security functionalities, including symmetric and asymmetric encryption, digital signatures, key derivation, and message digests. The documentation details support for industry-standard algorithms such as RSA, ECC, AES, and SHA, as well as specific standards like SM2 and key agreement protocols like Diffie-Hellman. This resource is primarily intended for software developers and security engineers who are building secure applications on the HarmonyOS/OpenHarmony platform and require detailed specifications for implementing robust security features within the `SystemCapability.Security.CryptoFramework`. It acts as a central hub for understanding the security capabilities available to Cangjie developers.
