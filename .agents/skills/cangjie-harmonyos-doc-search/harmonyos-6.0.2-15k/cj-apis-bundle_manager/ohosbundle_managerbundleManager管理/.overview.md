# ohosbundle_managerbundleManager管理

This directory provides API reference documentation for the Cangjie language implementation of the HarmonyOS BundleManager framework. It covers classes, structs, and enums for managing application bundles, querying component information, handling permissions, and configuring metadata. Key topics include default app management, routing tables, and module dependencies. It is suitable for Cangjie developers building applications for the HarmonyOS ecosystem who need to programmatically access and manipulate application configuration and lifecycle data.

## Detailed Description

### class_AbilityInfo/
API reference for the `AbilityInfo` class, covering properties defining an Ability's configuration, metadata, and runtime behavior. Includes read-only properties like bundleName, label, and launchType, essential for querying component attributes.

### class_BundleInfo/
Documentation for the `BundleInfo` class, detailing data structures for managing application bundle information. Covers read-only properties like version codes, installation times, and module details, supporting metadata queries and security verification.

### class_BundleManager/
Reference for the `BundleManager` class, covering methods for querying bundle info, retrieving metadata, and verifying URL accessibility. Includes parameter definitions and error codes for accessing configuration files.

### class_ExtensionAbilityInfo/
Documentation for the `ExtensionAbilityInfo` class, focusing on the structure of extension ability information. Covers metadata like bundle names, permissions, and skills, with version-specific features for clone applications.

### enum_BundleFlag/
Reference for the `BundleFlag` enumeration, detailing how to specify content scopes when retrieving bundle information. Covers flags for application data, HAP modules, abilities, and signatures.

### enum_ExtensionAbilityType/
Resource for `ExtensionAbilityType` enumeration, defining categories for system extension components like forms and input methods. Also covers the Work Scheduler for background task management.

### struct_ApplicationInfo/
Reference for the `ApplicationInfo` struct, detailing application metadata and configuration properties. Includes permissions, bundle types, localized resources, and system attributes like process info.

### struct_HapModuleInfo/
Documentation for the `HapModuleInfo` struct, encapsulating information about HAP modules. Covers module metadata, component details, dependencies, and configuration settings like router maps.
