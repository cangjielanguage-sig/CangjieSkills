This directory focuses on the implementation and usage of Toast components within HarmonyOS applications. It provides comprehensive guidelines for displaying temporary, non-intrusive user feedback, covering essential aspects such as API implementation chains involving UIContext and PromptAction, security constraints, and specific usage recommendations. Additionally, it explores technical comparisons between different display modes (Default vs. TopMost) in ArkUI using the Cangjie language, detailing sub-window creation, display hierarchy, and keyboard avoidance logic. Key topics include text density, display duration, positioning, and interaction limitations. This resource is suitable for HarmonyOS developers and UI designers seeking to implement lightweight status notifications and master the technical nuances of feedback mechanisms. By understanding these components, developers can ensure their applications provide clear, system-compliant user feedback without disrupting the overall workflow.
