This directory provides comprehensive API reference documentation for the `AddressFamily` struct within the Cangjie programming language. It is designed to assist developers in managing network socket addressing schemes effectively. The content covers essential protocol definitions such as IPv4, IPv6, Unix domain sockets, and Linux-specific Netlink. Additionally, it details operator overloads for equality comparisons and interface implementations. This documentation is suitable for software developers and network engineers working on network communication protocols who need to configure socket behavior, understand platform-specific variations, and perform comparisons on address family instances.
