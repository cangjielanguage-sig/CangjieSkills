The `cj-common-types` directory serves as the foundational type system library for the Cangjie language, specifically optimized for the ArkUI framework used in HarmonyOS development. It provides a standardized set of data structures critical for building modern user interfaces, covering geometric primitives, styling properties, and layout utilities. Additionally, it includes enumerations for UI components to ensure consistency. By supporting API versions 12 and 19, the library ensures compatibility across the platform's evolution. This resource is suitable for HarmonyOS developers who need type safety and responsive design patterns in their Cangjie projects, acting as the bedrock for UI construction.
