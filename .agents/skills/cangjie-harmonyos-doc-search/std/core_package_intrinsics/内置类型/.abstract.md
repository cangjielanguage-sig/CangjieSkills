This directory provides comprehensive documentation for the built-in types in the Cangjie programming language. It covers fundamental primitive types such as Bool and Unit, a wide range of numeric types including signed and unsigned integers (Int8 to Int64, UInt8 to UInt64) and floating-point numbers (Float16, Float32, Float64), as well as specialized types for system interoperability (CPointer, CString) and Unicode character representation (Rune). This resource is essential for Cangjie developers, systems programmers, and engineers working on low-level data structures, FFI tasks, or precise numerical computations.
