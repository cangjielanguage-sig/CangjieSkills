This directory serves as a comprehensive technical resource for developers implementing camera metadata handling using the Cangjie programming language. It focuses on the integration of descriptive image data, specifically targeting face detection functionalities within camera applications. The content covers the complete development lifecycle, including the definition of metadata, the creation of output streams, and the management of capture sessions. Key technical elements include the use of TAG/Key pairs for memory optimization and specific API calls like `createMetadataOutput` and `Session.start`. Additionally, the directory addresses the critical need for status monitoring, detailing how to register callbacks for data availability and handle business exceptions. These guides are intended for camera application developers who already have a solid understanding of camera preparation and permission application, providing the necessary tools to build responsive and data-rich camera features.
