# 开发音频通话功能

在音频通话场景下，音频输出（播放对端声音）和音频输入（录制本端声音）会同时进行，应用可以通过AudioRenderer来实现音频输出，通过AudioCapturer来实现音频输入。同时使用AudioRenderer和AudioCapturer即可实现音频通话功能。

在音频通话开始和结束时，应用可以自行检查当前的[音频场景模式](./cj-audio-call-overview.md#音频场景模式)和[铃声模式](./cj-audio-call-overview.md#铃声模式)，以便采取合适的音频管理及提示策略。

以下代码示范了同时使用AudioRenderer和AudioCapturer实现音频通话功能的基本过程，其中未包含音频通话数据的传输过程。在实际开发中，需要将网络传输来的对端通话数据解码播放，此处使用读取音频文件的数据代替。同时需要将本端录制的通话数据编码打包，通过网络发送给对端，此处使用将数据写入音频文件代替。
