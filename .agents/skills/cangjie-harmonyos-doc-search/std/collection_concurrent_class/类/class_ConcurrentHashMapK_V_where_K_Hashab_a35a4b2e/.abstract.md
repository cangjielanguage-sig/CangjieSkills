This directory provides comprehensive API reference documentation for the `ConcurrentHashMap` class in the Cangjie programming language. It covers a thread-safe hash table implementation designed for concurrent scenarios, requiring keys to be Hashable and Equatable. The documentation details class definitions, initialization constructors, atomic operations, and various manipulation methods such as add, remove, and replace. It also includes information on deprecated functions and recommended alternatives. This resource is intended for Cangjie developers looking to implement efficient, thread-safe data structures and manage concurrent data storage and retrieval logic.
