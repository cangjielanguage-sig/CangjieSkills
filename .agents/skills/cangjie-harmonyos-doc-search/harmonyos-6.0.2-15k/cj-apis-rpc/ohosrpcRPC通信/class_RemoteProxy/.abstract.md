This directory contains API reference documentation for the `RemoteProxy` class and related Inter-Process Communication (IPC) functions in the Cangjie language. It covers the implementation of the `IRemoteObject` proxy, detailing transaction codes, interface descriptors, and lifecycle management methods like death notification registration and unregistration. Key topics include synchronous and asynchronous message transmission, remote object status checks, and error handling. This documentation is suitable for system developers and engineers working on RPC and Binder architectures who need to manage IPC interactions, handle remote object states, and ensure robust communication protocols between processes.
