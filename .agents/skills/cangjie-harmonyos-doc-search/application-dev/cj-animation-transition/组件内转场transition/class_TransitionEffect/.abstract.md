This directory contains API reference documentation for the `TransitionEffect` class within the Cangjie language and ArkUI framework. It provides comprehensive details on defining, configuring, and combining transition animations for UI components, including entry and exit effects. The documentation covers static constants like OPACITY and SLIDE, as well as methods for rotation, scaling, and asymmetric transitions. It is suitable for software developers and UI engineers working within the HarmonyOS ecosystem who need to implement dynamic visual behaviors and custom animation parameters for their applications.
