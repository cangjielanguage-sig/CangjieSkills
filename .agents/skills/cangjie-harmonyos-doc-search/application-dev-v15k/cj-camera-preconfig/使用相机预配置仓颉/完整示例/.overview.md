# 完整示例

This directory contains comprehensive code examples designed to guide developers through the complete implementation of camera functionality within HarmonyOS applications. It covers the entire spectrum of camera operations, ranging from the initial setup of the CameraManager and the configuration of inputs and outputs to the detailed management of the photo capture lifecycle. Key topics include defining callback classes for robust error handling, creating and configuring PhotoSessions, managing preview and photo streams, and adjusting hardware-specific settings like flash, focus, and zoom ratios. Additionally, the examples emphasize the critical importance of resource management and hardware capability checks to ensure application stability. This collection is suitable for HarmonyOS developers working with Cangjie or ArkTS who require practical, end-to-end references for integrating complex camera features into their software projects.

### 完整示例_1.md 完整示例_1.md
This document provides a complete Cangjie code example demonstrating how to implement a camera shooting workflow using the CameraKit. It covers defining callback classes for status and error handling, initializing the CameraManager, and configuring camera inputs and outputs. Key steps include retrieving supported cameras, opening the camera input, creating a PhotoSession with preconfigurations, and adding preview and photo streams to the session. The example illustrates the sequence of operations required to set up a functional camera interface, including error monitoring and capability checks. This guide is intended for HarmonyOS developers using the Cangjie language who need a practical reference for integrating camera functionality into their applications.

### 完整示例_2.md 完整示例_2.md
This document provides a code example demonstrating the complete lifecycle of a photo capture session, from configuration to resource release. Main topics include session initialization, hardware capability checks for flash and focus modes, zoom ratio adjustment, and executing photo capture with specific quality settings. Key takeaways emphasize the importance of verifying hardware support before applying settings and ensuring proper resource cleanup—stopping the session and releasing inputs and outputs—only after the capture finishes. This technical reference is intended for developers integrating camera features, requiring knowledge of session-based camera APIs and asynchronous resource management. Keywords: camera session, photo capture, flash mode, focus mode, zoom ratio, resource management, ArkTS.
