This directory serves as a technical repository for the `ohos.ark_interop_helper` module, providing comprehensive API references that enable seamless interoperability between ArkTS and native Cangjie code within the HarmonyOS ArkUI framework. It is specifically designed to assist developers in managing complex data transformations and context handling required for high-performance applications. The documentation covers public auxiliary functions for converting data types—such as mapping native HashMap structures to JavaScript values—and managing application contexts across different models (FA and Stage). Key technical elements include the `mapToJSValue` function, `JSValue` to `napi_value` conversions, and context retrieval utilities. These resources are indispensable for HarmonyOS developers focused on native-bridge interactions, system capability integration, and optimizing the interface between the ArkTS runtime and native NAPI layers, particularly for systems running API version 12 and utilizing the SystemCapability.ArkUI.ArkUI.Napi capability. This documentation is crucial for ensuring type safety and data integrity during cross-language calls.
