# class_ImageSource

This directory contains API reference documentation for the Cangjie `ImageSource` class, a core component of the ImageKit framework designed for retrieving image information, decoding image data, and managing image metadata. It covers essential functionalities such as creating PixelMaps, handling animated images (GIFs), accessing EXIF properties, and supporting incremental data loading. The documentation is intended for Cangjie developers and multimedia engineers building applications that require robust image processing capabilities, including decoding, metadata manipulation, and dynamic image source management.
