This directory contains API documentation for creating and initializing video components within the ArkUI framework using the Cangjie programming language. It covers various constructor overloads that allow developers to configure video sources (AppResource or String), playback speeds (Float64 or PlaybackSpeed enum), preview images, and controllers. The documentation details supported video formats like mp4, mkv, and TS, and specifies necessary permissions for network access. This resource is suitable for HarmonyOS developers looking to implement robust video playback features in their applications.
