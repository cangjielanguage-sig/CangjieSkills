# class_Caller

This directory contains API reference documentation for the `Caller` class in the Cangjie language, specifically designed for HarmonyOS development. It covers inter-process communication (IPC) mechanisms, allowing client-side components to communicate with server components. Key topics include sending serialized Parcelable data, handling asynchronous responses, managing connection lifecycles, and monitoring remote state changes. The documentation details methods like `call`, `callWithResult`, `onRelease`, and `release`, along with associated error codes and exceptions. This resource is suitable for Cangjie developers and system architects working on cross-device applications and ability lifecycle management within the AbilityRuntime.AbilityCore and AbilityKit frameworks.
