# 资源分类

This section provides a comprehensive guide to organizing and managing application resources, specifically within the HarmonyOS development environment. It covers the structural hierarchy of resource directories, distinguishing between resource directories (base, qualifiers, rawfile, resfile) and resource group directories (element, media, profile). Key topics include localization strategies, device adaptation, strict naming conventions, and the handling of various file formats like JSON and media assets. This documentation is essential for developers and system integrators seeking to optimize application performance and ensure proper resource matching across different devices and languages.

### 资源分类.md 资源分类.md

It covers the distinction between resource directories (base, qualifiers, rawfile, resfile) and resource group directories (element, media, profile). Key information includes the use of qualifier directories for localization (e.g., en_US, zh_CN) and the specific handling of shared resources in the stage model's AppScope. Keywords: resource classification, directory structure, stage model, localization, qualifiers, resource groups.

### 资源组目录.md 资源组目录.md
This technical reference document defines the structure and usage of resource group directories, categorizing files into element, media, and profile types. The content details specific file formats and naming conventions for each category: element stores JSON files for data types like boolean, color, and string; media supports non-text files such as images and videos; and profile contains custom JSON configurations. Key takeaways include strict naming conventions for element files, supported media formats like JPEG and H.264 AVC, and provided JSON content examples for various data types. Intended for developers and system integrators, this guide ensures proper resource organization and management within the software framework.
