This directory contains API reference documentation for the Cangjie testing framework within HarmonyOS, specifically focusing on the `ohos.ability_delegator_registry` module. It covers essential classes and enums used for unit testing, including `AbilityDelegator`, `AbilityMonitor`, `AbilityDelegatorArgs`, and `AbilityLifecycleState`. The documentation details how to manage application lifecycles, monitor UIAbility and AbilityStage components, and access test parameters programmatically. It is suitable for developers building automated tests and validating runtime behaviors using the TestKit and AbilityKit frameworks.
