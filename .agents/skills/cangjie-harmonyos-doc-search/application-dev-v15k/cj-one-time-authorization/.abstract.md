This directory contains documentation for the "cj-one-time-authorization" feature, a privacy enhancement designed to provide users with granular control over sensitive application permissions. The core focus is on a system that automatically introduces an "Allow this time" option into standard authorization dialogs for specific high-risk scopes, such as clipboard access and location services. This mechanism allows applications to request necessary data for a single operation without forcing the user to grant permanent access. The documentation covers the scope of supported permissions and outlines critical usage restrictions, most notably the security measure that automatically revokes these temporary permissions after a ten-second interval. This guide is tailored for application developers who wish to implement privacy controls using standard request APIs, ensuring compliance and user trust without the burden of complex custom configuration. It serves as the definitive reference for integrating this privacy-centric capability into modern software ecosystems.
