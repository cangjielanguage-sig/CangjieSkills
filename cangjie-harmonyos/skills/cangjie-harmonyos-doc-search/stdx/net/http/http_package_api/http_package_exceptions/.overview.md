## 详细说明

### http_package_exceptions.md http_package_exceptions.md
本文档定义了HTTP包中用于错误处理的各类异常，涵盖连接、超时、状态码及WebSocket等场景。主要介绍了六个核心异常类：ConnectionException、CoroutinePoolRejectException、HttpException、HttpStatusException、HttpTimeoutException及WebSocketException。所有类均继承自Exception或IOException，并提供接收错误信息的构造函数，其中HttpStatusException额外包含UInt16类型的statusCode参数。该文档面向使用仓颉语言进行HTTP网络编程的开发者，作为API参考手册，旨在帮助开发者准确理解和捕获网络请求中的特定错误。
