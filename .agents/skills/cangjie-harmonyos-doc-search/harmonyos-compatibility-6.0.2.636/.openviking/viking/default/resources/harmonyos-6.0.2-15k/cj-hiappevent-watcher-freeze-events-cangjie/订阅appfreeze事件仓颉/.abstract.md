This directory provides a comprehensive technical guide for developers utilizing the Cangjie programming language to implement application freeze event subscriptions within the HarmonyOS ecosystem. It serves as a central resource for understanding how to monitor system-level performance issues effectively. The content covers essential API interfaces for managing event watchers, specifically focusing on adding and removing observers, and outlines a complete development workflow involving the HiAppEvent framework. Key topics include project initialization, event configuration, and log analysis for diagnosing Application Not Responding (ANR) errors and main thread blocking. This documentation is specifically designed for software engineers and QA professionals dedicated to maintaining high application stability and performance standards through advanced event tracking and root cause analysis.
