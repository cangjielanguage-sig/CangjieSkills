# 拉起系统应用

This directory provides comprehensive technical documentation for developers on how to launch and interact with system applications. It covers the essential strategies for invoking system-level capabilities, focusing on two main approaches: utilizing system Picker components for secure resource access (such as files, photos, and contacts) and calling specific interfaces to jump directly to applications like Settings or Phone. A significant emphasis is placed on permission management, highlighting how Pickers enable temporary access without requiring explicit user permissions. Additionally, it references specific APIs for telephony and media handling. This resource is ideal for application developers looking to integrate system features efficiently while adhering to security best practices and minimizing permission friction for users.

## Detailed Description

### 拉起系统应用_2more.md
This document serves as a technical guide for developers on how to launch system applications and utilize their capabilities. It details two primary methods: using system Picker components for resources like files, photos, and contacts, and invoking specific interfaces to jump directly to apps such as Settings and Phone. A key takeaway is that system Pickers allow developers to access user resources without applying for explicit permissions, as the system grants temporary access during user selection. The target audience is application developers seeking to integrate system-level functionalities while managing permissions efficiently. Keywords: launch system applications, Picker components, permission management, specific interfaces, developer guide.

### 支持跳转系统应用的能力清单.md
This reference document catalogs the system applications and specific interfaces that developers can invoke or jump to within the operating system. It details capabilities across five main categories: Settings, Telephony, Camera, File Management, and Media Library. Key information includes specific APIs for handling permission denials via requestPermissionOnSetting, initiating calls using makeCall, and accessing system resources through various Pickers like DocumentViewPicker, AudioViewPicker, and PhotoViewPicker. The document targets application developers who need to integrate system-level features such as permission management, dialing, and media file selection into their applications.
