This directory contains API reference documentation for the `HuksKeyAlg` class within the Cangjie language environment, specifically designed for the HarmonyOS Universal Keystore (HUKS) framework. It comprehensively defines static constants representing a wide array of cryptographic algorithms essential for secure data handling. These include asymmetric algorithms (RSA, ECC, SM2), symmetric algorithms (AES, DES, 3DES), and key derivation or hash functions (HMAC, HKDF, SM3). The documentation details specific integer values, required system capabilities (Core or Extension), and starting API version requirements for each constant. This resource is suitable for developers building secure applications who need to specify precise algorithm parameters when interacting with the HUKS service to ensure data integrity and confidentiality.
