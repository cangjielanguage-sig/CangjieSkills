This directory serves as a comprehensive technical repository focused on the mapping and matching rules for Explicit and Implicit Wants within the HarmonyOS/OpenHarmony ecosystem. It is an essential resource for application developers and system engineers who need to understand the underlying mechanisms used to launch target application components. The content covers the fundamental principles of how specific parameters align with configuration files like `module.json5`. It details the mandatory requirements for explicit matching, such as `bundleName` and `abilityName`, as well as the complex logic for implicit matching involving actions, entities, URIs, and types. By utilizing this directory, professionals can implement precise component startup logic, ensure correct routing, and manage intent handling effectively, thereby avoiding common routing errors and ensuring their applications interact seamlessly with system capabilities.
