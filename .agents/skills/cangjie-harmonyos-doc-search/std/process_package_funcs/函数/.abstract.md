This directory contains API reference documentation for process management functions in the Cangjie programming language. It covers essential operations for creating, executing, and managing external subprocesses, including handling command arguments, environment variables, and input/output redirection. The documentation details functions for executing commands with or without capturing output, finding existing processes, and launching new ones. It is suitable for developers who need to integrate system-level process control into their Cangjie applications, providing guidance on parameters, return values, exceptions, and resource management.
