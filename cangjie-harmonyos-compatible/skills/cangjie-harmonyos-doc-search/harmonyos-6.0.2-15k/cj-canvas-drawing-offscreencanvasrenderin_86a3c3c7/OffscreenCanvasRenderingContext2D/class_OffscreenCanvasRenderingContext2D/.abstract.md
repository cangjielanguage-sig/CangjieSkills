This directory contains API reference documentation for the `OffscreenCanvasRenderingContext2D` class in the Cangjie programming language, designed for the ArkUI framework. It covers a comprehensive suite of 2D drawing capabilities, including path creation (arcs, curves, rectangles), styling (fills, strokes, gradients, shadows), text rendering, image manipulation, and coordinate transformations. The documentation details function signatures, parameters, system capabilities, and code examples for off-screen drawing. It is intended for HarmonyOS developers using Cangjie to implement custom 2D graphics, animations, and visual effects within their applications.
