This directory serves as a technical resource for HarmonyOS developers utilizing the ArkUI framework and the Cangjie language to enhance user interfaces with inline iconography. It specifically addresses the integration and customization of the `SymbolSpan` component within `Text` components. The content covers a wide range of functionalities, including basic component creation, styling properties (such as font size, weight, and color), and advanced configuration of rendering and effect strategies. Key topics include the architectural necessity of embedding `SymbolSpan` within `Text`, the application of multi-layered rendering modes, and the implementation of dynamic animations like scaling and hierarchical effects. Additionally, it outlines specific constraints, such as the lack of support for common events. This guide is suitable for application developers looking to create visually rich text displays with embedded symbols.
