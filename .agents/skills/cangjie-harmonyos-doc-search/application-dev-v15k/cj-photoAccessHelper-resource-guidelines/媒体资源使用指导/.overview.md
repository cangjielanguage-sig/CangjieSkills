# 媒体资源使用指导

This directory provides comprehensive guidance for developers on managing media resources within applications using the MediaLibraryKit and photoAccessHelper interfaces. It covers essential operations such as querying, renaming, deleting, and retrieving thumbnails for images and videos. The documentation focuses on the Cangjie programming language and HarmonyOS development environment, detailing necessary permissions, initialization steps, and specific API usage like `deleteAssets` and `getThumbnail`. It is suitable for application developers who need to implement robust media access and management features in their apps.

The document outlines necessary prerequisites, including obtaining the photoAccessHelper instance and requesting specific read and write permissions. It details a four-step development process involving creating search predicates, fetching assets, and executing the deletion. ### 获取图片和视频缩略图.md 获取图片和视频缩略图.md
This technical tutorial guides developers on retrieving image and video thumbnails using the getThumbnail API for UI display. It covers prerequisites such as obtaining the photoAccessHelper instance, requesting READ_IMAGEVIDEO permissions, and importing necessary modules. The document details the step-by-step process to fetch a specific image's thumbnail, involving setting predicates, calling getAssets, and converting the result to a PixelMap via PhotoAsset.getThumbnail. A Cangjie code example demonstrates retrieving a 720x720 thumbnail. This guide is intended for application developers implementing media preview features in their apps.
