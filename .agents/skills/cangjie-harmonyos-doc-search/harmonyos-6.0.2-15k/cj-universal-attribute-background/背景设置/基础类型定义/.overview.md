# 基础类型定义

This directory defines fundamental data types and configurations for background visual effects within the ArkUI framework using the Cangjie programming language. It covers essential structures for implementing blur effects, including style options, activation policies, and comprehensive background effect parameters. Key topics include depth-of-field blurring, component material styles, and dynamic visual state management based on window focus. This documentation is suitable for HarmonyOS developers and UI engineers looking to enhance application aesthetics through advanced visual rendering and styling capabilities.

### class_BackgroundBlurStyleOptions.md class_BackgroundBlurStyleOptions.md
This API reference document defines the BackgroundBlurStyleOptions class for configuring background blur effects within the ArkUI framework. It details the class structure, which inherits from BlurStyleOptions, and covers its read-only properties: inactiveColor for fallback colors when a window loses focus, and policy for activation strategies. The document also explains the constructor parameters, such as color mode, adaptive color, and blur scale. Key takeaways include the ability to customize blur behavior based on window focus state. Intended for Cangjie developers, this documentation requires knowledge of ArkUI system capabilities and UI styling concepts.
