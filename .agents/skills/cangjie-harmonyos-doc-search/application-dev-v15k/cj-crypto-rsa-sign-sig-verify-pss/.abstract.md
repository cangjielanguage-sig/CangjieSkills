This directory serves as a specialized repository for implementing RSA digital signatures and verification using the Probabilistic Signature Scheme (PSS) within the Cangjie programming language. It focuses on the practical application of the CryptoArchitectureKit to ensure data integrity and authenticity in modern software systems. The content covers essential cryptographic workflows, including asymmetric key pair generation, parameter configuration (such as salt length and MGF1), and BigInt handling. It is designed for software developers and security professionals seeking robust, secure coding solutions for Cangjie-based applications requiring high-standard cryptographic operations. By leveraging these resources, users can effectively implement secure communication channels and data validation mechanisms, protecting against tampering and forgery.
