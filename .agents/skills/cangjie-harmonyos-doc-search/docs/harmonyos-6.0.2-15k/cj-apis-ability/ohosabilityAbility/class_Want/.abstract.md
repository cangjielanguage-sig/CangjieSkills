This directory serves as a comprehensive technical resource for the `Want` class within the Cangjie programming language, specifically designed for the HarmonyOS ecosystem. It provides essential API reference documentation that enables developers to precisely describe operation intentions between various application components. The content covers fundamental aspects such as class constructors, read-only properties (including `bundleName`, `abilityName`, `action`, `type`, `uri`, and `deviceId`), and the mechanisms for explicit ability launching and implicit intent matching using MIME types. Furthermore, it addresses advanced initialization parameters required for complex system interactions. This documentation is highly suitable for system developers, application engineers, and software architects who need to configure navigation requests, manage data parameters, and implement robust inter-component communication and system-level features in their applications.
