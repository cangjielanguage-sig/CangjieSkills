This directory contains API reference documentation for initializing and configuring UI Sheet components within the Cangjie and ArkUI development framework. It covers comprehensive configuration options for semi-modal and bottom-sheet interfaces, including visual styling, layout geometry, lifecycle events, and user interaction behaviors such as swipe gestures and dismissal logic. The documents detail specific parameters for background colors, blur effects, height constraints, and event callbacks. This resource is suitable for Cangjie developers and UI engineers seeking to implement complex, interactive sheet components with precise control over appearance and functionality in ArkUI applications.
