This directory contains API reference documentation for process management classes within the Cangjie programming language. It covers the creation, control, and monitoring of system processes, including the main process, child processes, and subprocesses. Key topics include process lifecycle management, environment variable handling, standard I/O stream redirection, and inter-process communication. The documentation also addresses deprecated APIs and legacy behaviors. It is suitable for Cangjie developers working on system programming, application automation, and operating system interaction who need robust tools for process control and data stream management.

## Detailed Description

### class_CurrentProcess_supdeprecatedsup
This directory contains API reference documentation for the Cangjie programming language, specifically focusing on the deprecated `CurrentProcess` class and essential environment variable management functions. It covers system-level interactions such as accessing command-line arguments, standard I/O streams, system directories, and process termination mechanisms. Additionally, it details functions for setting and removing environment variables, including specific platform behaviors like Windows handling and error management for invalid inputs. This documentation is suitable for Cangjie developers working on system programming, process control, and environment configuration who need to understand legacy or deprecated APIs and runtime environment manipulation. The content serves as a technical guide for interacting with the operating system environment, handling process lifecycles, and managing configuration data through environment variables. It highlights critical behaviors such as C language interop and exception handling for null characters.

### class_Process
This directory contains API reference documentation for the Cangjie programming language's Process class and related process management utilities. It covers essential operations for creating, managing, and monitoring system processes, including instance creation, information retrieval, lifecycle control, and termination. The documentation details key properties like process ID and start time, alongside functions for checking status and stopping execution. It also addresses deprecated static methods for subprocess execution and output capture. Intended for Cangjie developers, this guide requires knowledge of system processes and exception handling to effectively utilize these interfaces for system-level programming.

### class_SubProcess
This directory contains essential API reference documentation for the Cangjie language's `SubProcess` class and related functions, designed to assist developers in managing child process operations. It covers the inheritance hierarchy from the `Process` class and details the properties for accessing standard input, output, and error streams. A significant focus is placed on the deprecation of legacy stream properties in favor of new pipe-based attributes. The documentation also explains process lifecycle management, specifically the `wait` function for handling exit codes and timeouts, and the `waitOutput` function for retrieving execution results. Critical advice regarding stream redirection to prevent deadlocks and warnings about handling large output streams are included. This content is suitable for Cangjie developers involved in system programming, process control, and I/O stream management who need to handle subprocess execution and exception handling effectively.
