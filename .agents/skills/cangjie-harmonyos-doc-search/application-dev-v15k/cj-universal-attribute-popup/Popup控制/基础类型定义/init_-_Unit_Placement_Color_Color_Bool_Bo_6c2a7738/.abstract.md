This directory contains API reference documentation for the `init` constructor functions of the `CustomPopupOptions` class within the Cangjie ArkUI framework. It covers the creation and configuration of custom popup components, detailing parameters for visual styling, positioning, arrow visibility, and interaction behaviors. The documentation includes system capability requirements and version availability. This resource is suitable for HarmonyOS developers and UI engineers working with Cangjie who need to programmatically instantiate and customize popup interfaces with specific layout and event handling logic.
