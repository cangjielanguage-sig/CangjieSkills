This directory serves as a comprehensive technical resource for implementing cryptographic key agreement protocols using the Cangjie programming language within the HarmonyOS ecosystem. It specifically addresses the integration with the HarmonyOS Universal Keystore Service (HUKS) to facilitate secure key exchanges, such as X25519 and Diffie-Hellman. The content covers the complete development lifecycle, including key generation, public key export, agreement execution, and secure key deletion. It highlights critical configuration parameters like the HUKS_TAG_DERIVED_AGREED_KEY_STORAGE_FLAG and provides valid flag combination matrices. This collection is tailored for security developers and system architects working on OpenHarmony applications who require robust, hardware-backed key exchange mechanisms and precise cryptographic key management to ensure data security and privacy in their software solutions.
