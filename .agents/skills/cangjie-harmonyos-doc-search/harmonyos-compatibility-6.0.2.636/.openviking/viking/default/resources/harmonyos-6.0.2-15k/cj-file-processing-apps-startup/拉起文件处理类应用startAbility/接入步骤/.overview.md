# 接入步骤

This directory serves as a comprehensive technical resource for HarmonyOS developers working with the Cangjie language, specifically focusing on the implementation of cross-application file opening capabilities. It details the necessary integration steps for two distinct roles: the target application that receives and processes the file, and the caller application that initiates the file opening request. The documentation covers critical configuration tasks such as declaring permissions in `module.json5`, defining specific skills like `ohos.want.action.viewData`, and managing URI schemes. Furthermore, it explains runtime operations including extracting URIs from Want objects, converting file paths, and setting read/write authorization flags. These guides are essential for developers looking to enable seamless file sharing and intent handling within the HarmonyOS ecosystem, ensuring proper security and data access management.

## Detailed Description

### 目标方接入步骤.md 目标方接入步骤.md
This technical guide instructs developers on how to configure and implement file opening capabilities within an application. It covers two primary steps: declaring file access permissions in the module.json5 configuration and processing file URIs in the application code. Key information includes defining specific skills like ohos.want.action.viewData, setting the URI scheme to file, and specifying file types such as UTD or MIME. The code example demonstrates extracting the URI from the Want object and using FileFs.open for read-write operations. This guide targets HarmonyOS developers using the Cangjie language who need to handle file intents.

### 调用方接入步骤.md 调用方接入步骤.md
This technical tutorial guides developers through the integration steps for a caller application to open files using the Cangjie language. The content is structured into four sequential steps: importing required modules, retrieving and converting file paths to URIs, constructing request data via the Want object, and invoking the startAbility interface. Key implementation details include setting the Want action to "ohos.want.action.viewData", defining the file type, and configuring read/write URI permission flags to authorize the target application. Intended for Cangjie developers, this guide assumes familiarity with HarmonyOS application lifecycle and file sandbox concepts.
