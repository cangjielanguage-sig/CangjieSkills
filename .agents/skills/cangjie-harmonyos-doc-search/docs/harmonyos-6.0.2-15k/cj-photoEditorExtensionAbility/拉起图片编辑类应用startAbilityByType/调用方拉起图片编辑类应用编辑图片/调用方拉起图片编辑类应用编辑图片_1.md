## 调用方拉起图片编辑类应用编辑图片

开发者可以在Ability或者UIExtensionAbility的页面中通过接口startAbilityByType拉起图片编辑类应用扩展面板，系统将自动查找并在面板上展示基于[PhotoEditorExtensionAbility](../../API_Reference/source_zh_cn/apis/AbilityKit/cj-apis-ability.md#class-photoeditorextensionability)实现的图片编辑应用，由用户选择某个应用来完成图片编辑的功能，最终将编辑的结果返回给到调用方，具体步骤如下：

1. 导入模块。

    ```cangjie
    import kit.AbilityKit.{UIAbilityContext, Want, AbilityStartCallback, Flags}
    import kit.CoreFileKit.{FileFs, OpenMode, File, FileUri, PhotoSelectOptions, PhotoViewPicker, PhotoViewMIMETypes,
        PhotoSelectResult}
    ```

2. （可选）实现从图库中选取图片。

    ```cangjie
    let context = getContext()
    let photoResultCallback = {
        errorCode: Option<AsyncError>, data: Option<PhotoSelectResult> => match (errorCode) {
            case Some(e) => AppLog.error("photo select error: errcode is ${e.code}")
            case _ => match (data) {
                case Some(value) =>
                    // ...
                case _ => AppLog.error("photo select error: data is null")
            }
        }
    }

    var photoSelectOptions = PhotoSelectOptions()
    photoSelectOptions.MIMEType = PhotoViewMIMETypes.IMAGE_TYPE
    photoSelectOptions.maxSelectNumber = 1
    let photoPicker = PhotoViewPicker(context)
    photoPicker.select(photoResultCallback, option: photoSelectOptions)
    ```

3. 将图片拷贝到本地沙箱路径。

    ```cangjie
    let file = try {
        FileFs.open(
            uri,
            mode: OpenMode
                .READ_ONLY
                .mode
        )
    } catch (e: BusinessException) {
        AppLog.error("Open file failed: ${e.message}")
        return
    }
    try {
        let timeStamp = DateTime.now()
        // 将用户图片拷贝到应用沙箱路径
        FileFs.copyFile(file.fd, context.filesDirectory + "/original-${timeStamp}.jpg"
        )
        this.filePath = context.filesDirectory + "/original-${timeStamp}.jpg"
        this.originalImage = FileUri.getUriFromPath(this.filePath)
    } catch (e: BusinessException) {
        AppLog.error("readImage failed:${e.message}")
    } finally {
        FileFs.close(file.fd)
    }
    ```

4. 在startAbilityByType回调函数中，通过want.uri获取编辑后的图片uri，并做对应的处理。

    ```cangjie
    let context = getContext()
    let callBack = AbilityStartCallback(
        {
            code, name, message => AppLog.info("onError code ${code} name: ${name} message: ${message}")
        },
        onResult: {
            // 获取到回调结果中编辑后的图片uri并做对应的处理
            result => editedImage = readImageByUri(result.want.uri)
        }
    )
    ```

5. 将图片转换为图片uri，并调用startAbilityByType拉起图片编辑应用面板。示例中的context的获取方式请参见[获取UIAbility的上下文信息](cj-uiability-usage.md#获取uiability的上下文信息)。

    ```cangjie
    let uri = FileUri.getUriFromPath(this.filePath)

    let flag = Int64(Flags
        .FLAG_AUTH_READ_URI_PERMISSION
        .getValue())

    try {
        context.startAbilityByType("photoEditor",
            "{\"ability.params.stream\":[\"${uri}\"], \"ability.want.params.uriPermissionFlag\":${flag}}", callBack)
    } catch (e: BusinessException) {
        AppLog.error("startAbilityByType fail, err: ${e.message}")
    }
    ```
