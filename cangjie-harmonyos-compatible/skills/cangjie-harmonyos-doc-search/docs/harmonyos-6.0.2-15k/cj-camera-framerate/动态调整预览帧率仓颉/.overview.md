## Detailed Description

### 动态调整预览帧率仓颉_4more.md
This technical guide explains how to implement dynamic preview frame rate adjustment for camera applications using the Cangjie language. It covers constraints, the development workflow, session creation with specific modes, and code examples. Key takeaways include the requirement to create a session in NORMAL_PHOTO or NORMAL_VIDEO mode to enable frame rate control. The adjustment can occur before or after starting the preview and supports querying ranges, setting values, and retrieving current settings, though hardware capabilities ultimately determine supported ranges. Intended for application developers working on camera features, specifically for live streaming or video scenarios where power efficiency and frame rate control are critical.

### 完整流程.md
This document provides a complete code example demonstrating the workflow for configuring a camera session and adjusting frame rates in Cangjie. The main topics include CaptureSession creation, configuration management, adding inputs and outputs, and dynamic frame rate control. Key information illustrates the sequence of `beginConfig`, `addInput`, `addOutput`, and `commitConfig`, specifically highlighting how to query supported frame ranges and set frame rates both before and after calling `session.start()`. This guide is intended for developers using the Cangjie language for camera application development who need to manage session lifecycles and performance settings.

### 调整帧率.md
This document serves as a technical guide for developers on how to dynamically adjust camera frame rates using the CameraKit framework. The content outlines a three-step process involving the PreviewOutput class: querying supported frame rate ranges, setting specific minimum and maximum FPS values, and optionally retrieving the currently active frame rate. Key takeaways include the strict prerequisite that these operations must occur after the Session.commitConfig method is executed, though frame rate setting can happen before or after the preview starts. This guide targets application developers seeking to optimize camera performance and visual output quality.
