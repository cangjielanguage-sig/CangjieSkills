This directory contains documentation for the `FuzzDataProvider` class in the Cangjie programming language, a utility designed to facilitate fuzzing operations by converting raw byte streams into structured data types. It covers methods for consuming integers, strings, and booleans, as well as properties for tracking data state and offset. The documentation includes details on interoperability with native C code and exception handling. This resource is suitable for developers and security engineers working on fuzzing frameworks, binary data parsing, or serialization who need precise control over data type conversion from byte arrays.
