# ImageAnimator

This directory contains comprehensive documentation for the ImageAnimator component within the ArkUI framework, designed for implementing frame-by-frame image playback in HarmonyOS applications. It covers essential technical specifications, including API references, basic type definitions, practical code examples, event handling, and detailed component properties. Targeted at developers using the Cangjie language, these resources provide the necessary tools to integrate and control custom frame animations, manage image sequences, and handle animation lifecycle events effectively. This collection is ideal for UI engineers and system architects seeking to enhance user interface interactivity through dynamic visual effects.

### ImageAnimator_4more.md ImageAnimator_4more.md
This document provides API reference documentation for the ImageAnimator component, designed to implement frame-by-frame image playback within the ArkUI framework. Key information includes the capability to configure image lists and individual frame durations, full support for universal attributes and events, and specific system requirements starting from version 19. Intended for developers using the Cangjie language, this guide offers the essential technical specifications needed to integrate custom frame animations into user interfaces.

### 基础类型定义.md 基础类型定义.md
This API reference document defines the ImageFrameInfo class used for managing image frame properties within the ArkUI framework. The content details the class overview and two specific constructor methods: one accepting a String path and another accepting an AppResource object. Key parameters include the image source, playback duration in milliseconds, dimensions, and positioning coordinates, all with specific default values. Targeted at Cangjie developers implementing image animations or frame sequences in HarmonyOS applications, this document provides the necessary syntax and parameter descriptions for instantiating image frame objects.

### 组件事件.md 组件事件.md
This document serves as an API reference for animation event callbacks within the ArkUI framework using the Cangjie language. It details five specific functions: onCancel, onFinish, onPause, onRepeat, and onStart. Each function accepts a callback parameter to handle specific animation lifecycle events, such as starting, pausing, repeating, or returning to the initial state. All methods return the component instance to allow for chaining. This documentation is intended for developers implementing interactive animations in ArkUI applications, providing the necessary interfaces to respond to animation state changes effectively.
