# class_MessageOption

This directory provides comprehensive API reference documentation for the Cangjie `MessageOption` class, a critical component for configuring message transmission options in Inter-Process Communication (IPC) and Remote Procedure Call (RPC) environments. The documentation covers static constants that define flags for synchronous and asynchronous calls, file descriptor acceptance, and wait time parameters. It details the class constructor and various instance methods, including `getFlags`, `getWaitTime`, `isAsync`, and `setAsync`. Key takeaways include the ability to toggle between sync and async modes and manage RPC timeout settings. This technical reference is intended for Cangjie developers implementing inter-process communication who require precise control over message request behaviors and system capabilities.
