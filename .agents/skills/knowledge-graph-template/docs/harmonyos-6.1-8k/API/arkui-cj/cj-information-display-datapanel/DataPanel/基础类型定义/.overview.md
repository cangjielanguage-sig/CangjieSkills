# 基础类型定义

本目录包含ArkUI框架中用于UI样式定义的基础类型API参考文档，主要涉及颜色渐变和阴影效果配置。核心内容包括ColorStop（颜色断点）、LinearGradient（线性渐变）以及DataPanelShadowOptions（数据面板投影）等类的详细定义。这些类型使用仓颉（Cangjie）语言编写，适用于ArkUI应用开发。文档面向需要精细控制界面视觉效果的开发者，提供了实现渐变色填充和自定义阴影样式的具体接口与参数说明，系统要求版本为22及以上。

## 详细说明

### class_ColorStop_63897c16.md class_ColorStop_63897c16.md
本文档是Cangjie语言中ColorStop类的API参考文档，旨在定义用于描述渐进色颜色断点的类型。文档主要涵盖了类的属性定义（color和offset）以及构造函数的详细说明。关键信息指出，color属性指定颜色值，offset属性设定0到1之间的比例位置，系统会自动将超出范围的值截断。该类属于ArkUI系统能力，起始版本为22。文档主要面向使用Cangjie进行ArkUI应用开发的开发者，适用于需要实现UI渐变色效果的场景。

### class_DataPanelShadowOptions.md class_DataPanelShadowOptions.md
本文档是ArkUI框架中DataPanelShadowOptions类的API参考文档，旨在定义数据面板的投影样式配置。文档主要包含类定义、colors属性说明以及构造函数init的参数详解。关键信息指出该类继承自MultiShadowOptions，colors属性用于设置各数据段投影颜色，并明确了颜色数量与数据段数量不一致时的映射规则。构造函数支持配置投影模糊半径、颜色数组及X/Y轴偏移量。该文档面向使用仓颉语言进行ArkUI开发的开发者，适用于需要精细控制数据面板阴影效果的UI设计场景，要求系统版本为22及以上。

### class_LinearGradient_74a897fa.md class_LinearGradient_74a897fa.md
本文档是仓颉语言中LinearGradient类的API参考文档，旨在描述ArkUI框架下的线性渐变颜色。文档主要包含类定义及两个初始化构造函数：一个通过ColorStop数组定义多色渐变，另一个使用单一ResourceColor定义渐变。关键信息涵盖了系统能力、起始版本22以及构造函数的参数规范。该文档面向使用仓颉语言进行UI开发的开发者，提供了实现界面颜色渐变效果的具体接口说明。
