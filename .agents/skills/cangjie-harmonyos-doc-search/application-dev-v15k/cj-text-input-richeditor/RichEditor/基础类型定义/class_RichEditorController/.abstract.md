This directory provides comprehensive API reference documentation for the `RichEditorController` class within the ArkUI framework, tailored for developers using the Cangjie language. It covers the complete lifecycle of programmatic management for RichEditor components, ranging from initialization to complex content manipulation. Key functionalities include adding text and image spans, deleting specific content ranges, managing cursor positions, and applying granular style updates to both spans and paragraphs. This resource is essential for HarmonyOS application developers aiming to build sophisticated rich text editing interfaces in version 12 or later, offering detailed insights into method signatures, parameter handling, and exception management.
