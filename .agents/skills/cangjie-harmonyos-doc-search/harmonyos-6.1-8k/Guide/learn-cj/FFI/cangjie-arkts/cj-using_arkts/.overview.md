## 详细描述

### cj-using_arkts.md

本文档是一份面向仓颉开发者的开发指南，旨在指导如何在仓颉应用中调用ArkTS已有库以复用其生态。文档内容涵盖了ArkTS模块与页面的支持差异、库的分类（NAPI与三方库）及当前支持状态。核心要点在于明确仓颉支持增加ArkTS模块但不支持页面，目前仅支持调用NAPI模块，暂不支持三方库。具体的实现细节和代码示例需参考文档中提供的链接。本文档帮助开发者清晰理解跨语言调用的能力边界，确保项目集成的可行性。
