This directory contains essential API reference documentation for the Location class in the Cangjie programming language, specifically targeting developers building location-aware applications. It details the data structures used to encapsulate geographical and movement information, including coordinates, altitude, speed, and direction. The content specifies data types, units (meters, degrees), and the WGS84 coordinate system, alongside precision metrics like accuracy and altitudeAccuracy. Furthermore, it covers metadata fields and specific variables for timing and speed precision available from API version 22. This documentation is intended for software developers who need to access precise spatial and temporal data and requires knowledge of the SystemCapability.Location.Location.Core system interface.
