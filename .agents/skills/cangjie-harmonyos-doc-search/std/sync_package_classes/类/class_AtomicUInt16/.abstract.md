This directory contains API reference documentation for the `AtomicUInt16` class in the Cangjie programming language. It focuses on thread-safe atomic operations for the `UInt16` data type, essential for concurrent programming. Key topics include atomic arithmetic (add, subtract), bitwise operations (AND, OR, XOR), memory synchronization (load, store, swap), and compare-and-swap (CAS) mechanisms. The documentation highlights deprecated functions involving explicit memory ordering versus default ordering versions. It is suitable for systems programmers and developers building multi-threaded applications requiring low-level synchronization primitives to manage shared data safely.
