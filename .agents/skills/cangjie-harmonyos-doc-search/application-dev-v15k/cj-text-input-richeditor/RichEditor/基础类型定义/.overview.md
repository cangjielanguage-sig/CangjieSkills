# 基础类型定义

This directory contains fundamental type definitions and API references for the ArkUI framework using the Cangjie programming language. It primarily focuses on data structures, classes, and enumerations essential for building rich text editing interfaces, including text styling, image handling, clipboard events, and layout configurations. Key components include RichEditor controllers, span styles, and event handling classes. This documentation is suitable for HarmonyOS developers and software engineers who need to implement complex text manipulation, custom menus, and dynamic UI styling within their applications.

## Detailed Description

### class_RichEditorController/
This directory provides API reference documentation for the `RichEditorController` class, covering the lifecycle management of RichEditor components. It details functionalities for adding text and image spans, deleting content, managing cursor positions, and applying style updates, essential for building sophisticated rich text editing interfaces.

### class_RichEditorImageSpanResult/
This directory documents the `RichEditorImageSpanResult` class, which encapsulates image information returned by the backend. It covers properties like image dimensions, vertical alignment, and object fit, enabling developers to handle image spans and layout rendering precisely.

### class_RichEditorTextSpanResult/
This directory provides documentation for the `RichEditorTextSpanResult` class, focusing on the data structure for backend-returned text style information. It details properties for positioning, text content, and style attributes, including support for paragraph styles and preview text introduced in later API versions.

### class_RichEditorTextStyleResult/
This directory details the `RichEditorTextStyleResult` class for managing rich text styles. It covers font attributes, text decoration, and advanced styling like shadows and line height, providing a robust structure for handling complex text formatting.
