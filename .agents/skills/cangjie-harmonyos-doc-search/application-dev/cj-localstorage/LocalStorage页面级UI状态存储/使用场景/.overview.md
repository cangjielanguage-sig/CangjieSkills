# 使用场景

This directory contains tutorials and guides on using LocalStorage for state management in ArkUI applications developed with the Cangjie language. It covers various scenarios ranging from basic data binding and component communication to sharing state across UIAbility and views. Key topics include one-way and two-way data binding using decorators like `@LocalStorageProp` and `@LocalStorageLink`, handling complex data types, and modifying state from external logic. These resources are suitable for HarmonyOS developers looking to implement efficient state synchronization and data flow within their applications.

## Detailed Description

### LocalStorageProp和LocalStor_3more.md LocalStorageProp和LocalStor_3more.md
This technical tutorial demonstrates state management in ArkUI using Cangjie, focusing on LocalStorage synchronization mechanisms. It covers three primary scenarios: one-way data binding using @LocalStorageProp, two-way data binding using @LocalStorageLink, and state synchronization between sibling components. Key concepts include the distinction between unidirectional and bidirectional data flow, the usage of LocalStorage instances, and how decorators facilitate component communication. The document provides executable code examples to illustrate how changes in local variables or storage affect the UI and other components. It targets developers building applications with ArkUI who need to manage shared application state efficiently.

### 将LocalStorage实例从UIAbility共享到一个或多个视图.md 将LocalStorage实例从UIAbility共享到一个或多个视图.md
This tutorial guides HarmonyOS developers on sharing a LocalStorage instance from a UIAbility to multiple views using the Cangjie language. It covers creating the storage object in the MainAbility class and accessing it in different pages via the @Entry[storage] decorator. Key takeaways include using @LocalStorageLink for two-way data binding, ensuring state synchronization across views like EntryView and Page, and the best practice of setting default values during instance creation for safety and testing. This guide is intended for developers managing application state across different UI components. Keywords: LocalStorage, UIAbility, Cangjie, ArkUI, state management, @Entry, @LocalStorageLink.

### 应用逻辑使用LocalStorage_2more.md 应用逻辑使用LocalStorage_2more.md
This tutorial explains how to use LocalStorage for state management in Cangjie-based ArkUI applications. It covers two primary usage scenarios: manipulating storage within application logic using methods like setOrCreate and link, and binding storage to UI components using the @LocalStorageLink macro. Key takeaways include the creation of a shared storage instance, the implementation of bidirectional data synchronization between storage and UI variables, and the propagation of state changes across parent and child components. The guide is intended for developers familiar with Cangjie syntax and ArkUI component lifecycle.

### 自定义组件外改变状态变量.md 自定义组件外改变状态变量.md
This tutorial demonstrates how to modify state variables from outside a custom component using LocalStorage in the Cangjie language for ArkUI development. The document covers the initialization of LocalStorage, the creation of a Model class to handle state changes externally, and the implementation of the @LocalStorageLink decorator within the component. Key takeaways include understanding that calling setOrCreate on the shared storage object from an external class automatically updates the UI component due to the two-way binding mechanism. This guide is intended for HarmonyOS developers using Cangjie who need to manage application state across different scopes or objects.

### 装饰DateTime类型变量_3more.md 装饰DateTime类型变量_3more.md
This tutorial demonstrates how to use the @LocalStorageLink decorator with complex data types in ArkUI Cangjie development. It covers three specific scenarios: managing DateTime variables, Map collections, and Set collections. The examples illustrate how to modify these variables through button clicks and trigger view refreshes. For Map and Set, the code highlights the necessity of reassigning the modified collection to the state variable to ensure UI updates. This guide targets ArkUI developers using the Cangjie language who need to implement state management for non-primitive data types.
