# cj-crypto-sm4-sym-encrypt-decrypt-gcm

This directory is a comprehensive technical resource dedicated to the implementation of the SM4 symmetric encryption algorithm utilizing Galois/Counter Mode (GCM) within the Cangjie programming language ecosystem. It provides developers with the necessary tools and knowledge to leverage the CryptoArchitectureKit for securing sensitive data through robust cryptographic workflows. The scope of this directory encompasses critical security operations, including the generation of 128-bit keys, the initialization of encryption parameters, and the application of PKCS7 padding. Furthermore, it addresses the complexities of data integrity verification through the handling of authentication tags (authTag). Designed for software engineers and security architects, this material supports versatile data processing scenarios, ranging from single-pass operations to multi-pass streaming, ensuring high performance and security compliance in application development.

### [1] 使用SM4对称密钥GCM模式加解密/

This directory provides comprehensive resources for implementing encryption and decryption using the SM4 symmetric key algorithm in GCM (Galois/Counter Mode) with PKCS7 padding. It covers the complete cryptographic workflow within the CryptoArchitectureKit, detailing essential processes such as 128-bit key generation, parameter initialization, data processing, and the critical handling of authentication tags (authTag). The materials are specifically designed for developers working with the Cangjie programming language who need to integrate secure, high-performance cryptographic operations into their applications. The content supports both single-pass and multi-pass data processing scenarios, offering flexibility for various application requirements.
