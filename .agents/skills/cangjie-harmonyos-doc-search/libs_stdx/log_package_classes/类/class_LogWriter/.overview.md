# class_LogWriter

This directory provides comprehensive API reference documentation for the Cangjie `LogWriter` class and its associated utility functions. It focuses on the mechanisms required to serialize various data types into log output targets effectively. The content covers methods for structuring complex data containers, such as objects and arrays, as well as functions for writing primitive types, strings, and custom objects implementing the `LogValue` interface. Key topics include strict state management to prevent mismatched operations and the handling of specific data types like DateTime, Duration, and Exception. This documentation is specifically designed for Cangjie developers who are building or extending logging frameworks and need a deep understanding of serialization behavior, state constraints, and error handling within the logging system.
