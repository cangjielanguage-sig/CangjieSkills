# 内置类型

This directory provides comprehensive documentation for the built-in types in the Cangjie programming language. It covers fundamental primitive types such as Bool and Unit, a wide range of numeric types including signed and unsigned integers (Int8 to Int64, UInt8 to UInt64) and floating-point numbers (Float16, Float32, Float64), as well as specialized types for system interoperability (CPointer, CString) and Unicode character representation (Rune). This resource is essential for Cangjie developers, systems programmers, and engineers working on low-level data structures, FFI tasks, or precise numerical computations.

## Detailed Description

### Bool.md Bool.md
This API documentation defines the Bool type in the Cangjie language, detailing its core functionality and interface implementations. The document covers three main extensions: Equatable for equality checks, Hashable for hash value generation, and ToString for string representation. Key information includes the definition of true and false values, the hashCode() method returning Int64 (0 or 1), and the toString() method returning string literals. This reference guide targets Cangjie developers seeking to understand boolean type behaviors, standard library interfaces, and type conversion methods.

### Unit.md Unit.md
This API reference document defines the Unit type in the Cangjie language, representing expressions that produce side effects without meaningful return values. The text covers the type's single literal value, (), and its limited operations, specifically extensions for the Equatable, Hashable, and ToString interfaces. Key information includes that Unit supports equality checks, generates a fixed hash code of 0, and converts to the string representation "()". Intended for Cangjie developers, this documentation requires a basic understanding of type systems and interfaces.

### CPointerT/
The `CPointerT` directory serves as a comprehensive resource for the CPointer type in the Cangjie language, specifically engineered to facilitate seamless C language interoperability and low-level memory management. It thoroughly covers the type's definition, the CType constraint for generic parameters, and the critical rules governing memory operations. Key areas of focus include pointer arithmetic, memory read/write processes, and type casting, all of which mandate execution within an unsafe context to ensure safety. Furthermore, the documentation clarifies platform-dependent characteristics regarding size and alignment. This guide is indispensable for systems programmers and developers engaged in Foreign Function Interface (FFI) tasks who require granular control over memory manipulation and direct integration with C libraries.

### CString/
This directory provides comprehensive documentation for the `CString` type within the Cangjie programming language, specifically focusing on C language interoperability and Foreign Function Interface (FFI) tasks. It covers the fundamental definition of C-style strings, their creation, and the critical memory management procedures required when bridging Cangjie with C libraries. Key topics include the `CString` constructor, the `LibC` struct's `mallocCString` function, and the necessity of manual memory release using the `LibC free` method. Additionally, it details extensions for the `ToString` interface, enabling safer string manipulation and lexicographical comparisons. This resource is essential for Cangjie developers who need to handle low-level string operations, manage unsafe memory manually, and ensure null-safety when interacting with native C code. The documentation ensures developers can effectively utilize FFI capabilities while maintaining system stability.
