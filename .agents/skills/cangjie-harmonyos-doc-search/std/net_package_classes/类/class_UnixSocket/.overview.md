# class_UnixSocket

This directory contains API reference documentation for the `UnixSocket` class in the Cangjie programming language. It covers the implementation of client-side duplex stream-based communication using Unix domain sockets. Key topics include socket initialization, connection management, configuration options (buffer sizes, timeouts), data transmission (read/write), and socket state manipulation. The documentation highlights platform limitations (incompatible with Windows) and exception handling. It is suitable for Cangjie developers building network applications that require inter-process communication (IPC) on Unix-like systems, specifically those needing low-level socket control and stream data handling.

### class_UnixSocket_7more.md class_UnixSocket_7more.md
This API reference document details the UnixSocket class, a client for duplex stream-based host communication in the Cangjie language. It covers class constructors, properties for address management like localAddress and remoteAddress, socket configuration options including receiveBufferSize and sendBufferSize, and timeout settings for read and write operations. Key information includes that the class inherits from StreamingSocket, requires explicit connect and close calls, and is incompatible with Windows. The documentation outlines exceptions such as SocketException and IllegalArgumentException. This guide targets Cangjie developers implementing network communication, specifically those working with Unix domain sockets and socket configuration.
