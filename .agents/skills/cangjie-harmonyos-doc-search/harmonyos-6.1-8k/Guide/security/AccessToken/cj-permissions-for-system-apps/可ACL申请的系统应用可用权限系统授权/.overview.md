# 可ACL申请的系统应用可用权限系统授权

本目录汇集了OpenHarmony及HarmonyOS系统中可通过ACL（访问控制列表）申请的系统应用权限文档。内容涵盖API 12至20版本中定义的敏感权限，涉及设备管理、网络安全、隐私保护、媒体控制及硬件访问等核心领域。所有权限均为system_grant类型，需ACL使能，适用于system_basic及以上级别的系统应用开发者。本文档旨在为开发者提供权限申请规范与合规指导，确保应用安全访问底层系统能力。
