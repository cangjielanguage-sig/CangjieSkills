This directory provides comprehensive technical documentation on utilizing the `mailto` protocol to launch email applications within the HarmonyOS/OpenHarmony ecosystem. It covers the standard URI format, parameter configuration (subject, body, cc, bcc), and implementation details for both web (HTML) and native application (Cangjie language) environments. Additionally, it guides developers on how to configure their own applications to receive and process `mailto` links. This resource is suitable for developers looking to integrate email composition features or implement deep linking capabilities for email handling in their apps, specifically focusing on the interaction between the calling application and the email client via the `Want` object mechanism. It addresses both the client-side invocation and the server-side reception of these links, ensuring a complete understanding of the data flow.
