This directory functions as a comprehensive educational resource dedicated to the `FileInfo` class within the Cangjie programming language. It is structured as a practical code tutorial designed to assist developers in mastering the inspection and manipulation of file metadata through the `std.fs` module. The guide covers a broad spectrum of file operations, including the retrieval of essential attributes such as the parent directory path, various timestamps, and file size. Additionally, it provides detailed instructions on how to differentiate between file types, such as symbolic links, regular files, and directories. A core component of this tutorial is permission management, where users learn to check read, write, and execute statuses, as well as how to modify user permissions programmatically. By highlighting key methods like `isRegular`, `canRead`, and `setWritable` within a temporary file context, this document offers valuable, hands-on experience. It is specifically tailored for Cangjie developers who have a foundational knowledge of file systems and syntax and are looking to enhance their proficiency in system-level file handling. This ensures developers can build robust applications that handle files securely and efficiently.
