This directory contains documentation for the LocationButton component within the ArkUI framework, specifically designed for the Cangjie language. It covers the implementation of a security control that enables users to grant temporary precise location permissions through a single click, bypassing standard dialogs. The content includes API references, basic type definitions for styling and authorization results, and practical code examples for HarmonyOS applications. It is suitable for developers integrating secure location access features and customizing UI elements for location-based scenarios.
