This directory serves as a specialized resource hub for mastering runtime type introspection within the Cangjie programming language, specifically centering on the `TypeInfo` class. It provides a structured approach to understanding and implementing reflection capabilities, enabling developers to inspect and analyze type information dynamically during program execution. The content encompasses a wide range of topics, from the initial setup of importing required reflection libraries to the practical application of defining custom classes that are introspectable. It delves into the extraction of critical metadata, including type names, fully qualified names, and the enumeration of available methods. By leveraging the `TypeInfo.of()` method and accessing specific properties like `name`, `qualifiedName`, and `instanceFunctions.size`, developers can perform detailed inspections of object structures. This directory is highly suitable for Cangjie developers aiming to build robust, dynamic applications that require runtime type analysis, assuming they possess a solid grasp of Cangjie syntax and fundamental object-oriented programming concepts. It is an essential guide for those looking to move beyond static typing and implement advanced reflection features.
