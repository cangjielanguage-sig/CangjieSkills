This directory provides API reference documentation for the `HashSet` class in the Cangjie programming language. It details the implementation of the Set interface using a HashMap backend for storing unordered, unique elements. The content covers class definitions, properties, constructors, and various member functions including set arithmetic, capacity management, and element manipulation. It is designed for Cangjie developers who need to manage collections of unique items and requires an understanding of generic constraints such as `Hashable` and `Equatable`.
