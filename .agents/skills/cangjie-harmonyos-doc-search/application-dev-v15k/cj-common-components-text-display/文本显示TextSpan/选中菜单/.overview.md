# 选中菜单

This directory provides comprehensive documentation and tutorials focused on the implementation and customization of selection menus for text components within the ArkUI framework. It covers a range of technical topics, including enabling default selection behaviors, binding custom menus using `bindSelectionMenu`, and extending existing menu options via `editMenuOptions`. The content addresses development in both Cangjie and ArkTS, offering code examples for creating custom menu items with specific callbacks and controlling menu visibility. It is specifically designed for UI developers and HarmonyOS engineers who aim to build advanced text interaction features, such as custom copy or translation functions, to enhance the user experience in their applications.

## Detailed Description

### 选中菜单_1.md
This guide explains how to configure and customize selection menus for the Text component in ArkUI using the Cangjie language. It covers enabling default selection behavior, binding custom menus via bindSelectionMenu, and extending existing menus using editMenuOptions. Key information includes the requirement to set copyOption for selection, code examples for implementing custom menu items with callbacks, and methods to control menu visibility. This tutorial targets UI developers seeking to implement advanced text interaction features like custom copy or translation options within their applications.

### 选中菜单_2.md
This document serves as a code tutorial demonstrating how to customize the text selection menu within an ArkUI application. It details the implementation of the onCreateMenu method to filter standard system options and append custom menu items, alongside the onMenuItemClick method to manage event handling and interception logic. Key takeaways include the ability to block default actions like Copy or Select All by returning boolean values and the integration of resource references for icons and strings. This guide is intended for HarmonyOS developers with prior knowledge of ArkTS syntax and component lifecycle management who wish to implement advanced text interaction features.
