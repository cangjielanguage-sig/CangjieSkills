# extend_Int8_CheckedOpInt8

This directory contains essential API reference documentation for the Cangjie programming language, specifically focusing on the implementation of safe arithmetic operations for the `Int8` type. It provides a detailed breakdown of the `CheckedOp` interface, which is crucial for performing secure mathematical calculations. The content encompasses a broad spectrum of functions, including basic arithmetic such as addition, division, modulo, multiplication, negation, increment, and decrement, alongside bit manipulation tasks like shifting and subtraction. A defining characteristic of these operations is the utilization of the `Option` return strategy, which ensures that overflow scenarios and invalid shift amounts are handled gracefully by returning `None` rather than throwing runtime exceptions. This documentation is highly suitable for Cangjie developers who need to perform precise integer arithmetic and explicitly manage potential error conditions to ensure application stability.

### extend_Int8_CheckedOpInt8_8more.md
