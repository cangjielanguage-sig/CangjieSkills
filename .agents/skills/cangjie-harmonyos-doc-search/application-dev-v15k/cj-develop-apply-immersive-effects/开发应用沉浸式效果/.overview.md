# 开发应用沉浸式效果

This directory serves as a comprehensive resource for designing and implementing immersive application UI effects, specifically tailored for the HarmonyOS ecosystem. It addresses the technical challenges of minimizing the visual impact of system status and navigation bars to maximize screen real estate. The content covers core concepts such as avoidance areas and safe areas, while comparing distinct implementation strategies like Window Full-screen Layout and Component Safe Area. It is highly suitable for application developers and UI designers seeking to create adaptive, visually consistent interfaces that enhance user engagement through full-screen experiences.

## Detailed Description

### 概述.md 概述.md
This document provides an overview of designing and implementing immersive application UI effects to minimize the visual impact of system status and navigation bars. It defines key concepts like avoidance and safe areas, outlines design requirements for UI element avoidance and color matching, and compares two implementation strategies: Window Full-screen Layout and Component Safe Area. Key takeaways include the distinction between extending layout for interaction versus extending drawing for visual consistency only. This guide targets application developers and UI designers seeking to optimize user experience through immersive layouts.

### 窗口全屏布局方案/
This directory focuses on technical schemes and implementation guides for window fullscreen layouts within HarmonyOS applications. It comprehensively covers how to handle system avoidance areas, distinguishing between scenarios where system bars are hidden versus visible. Key topics include immersive layouts, window configuration APIs like `setWindowLayoutFullScreen`, and dynamic UI adjustment for status and navigation bars. Suitable for HarmonyOS developers and system architects using ArkUI, ArkTS, or Cangjie, this resource helps create adaptive interfaces that maximize screen real estate while managing system interactions effectively.

### 组件安全区方案/
This directory provides technical documentation for implementing Component Safe Area layouts in HarmonyOS applications using the Cangjie language and ArkUI framework. It focuses on managing the interaction between UI elements and system bars, such as the status bar and navigation bar, to prevent content occlusion and achieve immersive display effects. Key concepts include `expandSafeArea`, `SafeAreaType`, `safeAreaPadding`, and handling scrolling containers. It is suitable for HarmonyOS developers and UI engineers looking to optimize window layouts, maintain visual consistency, and create full-screen user experiences.
