This directory provides a comprehensive technical resource for implementing Bluetooth Low Energy (BLE) broadcasting and scanning functionalities using the ConnectivityKit framework. It is designed to assist developers in mastering device discovery, low-power communication, and state management within the HarmonyOS/OpenHarmony ecosystem. The content covers critical aspects such as controlling advertising states, managing scan filters, and parsing raw data packets using the Cangjie programming language. Whether you are looking for a high-level API overview or detailed step-by-step implementation guides for core scenarios, this documentation offers the necessary tools and knowledge. It is specifically tailored for software engineers and developers aiming to build efficient, resource-aware applications with robust BLE connectivity and communication capabilities.
