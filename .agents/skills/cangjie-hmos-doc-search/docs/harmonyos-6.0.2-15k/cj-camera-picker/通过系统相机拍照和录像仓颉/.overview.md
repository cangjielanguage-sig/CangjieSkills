# 通过系统相机拍照和录像仓颉

This directory provides comprehensive resources for implementing system camera functionality—specifically photo and video capture—within HarmonyOS applications using the Cangjie programming language. It covers the integration of the CameraKit API, focusing on the `CameraPicker` feature which enables media acquisition without requiring explicit camera permissions. Key technical areas include UI component construction using `RelativeContainer` and `Column`, file system management for temporary storage, and asynchronous result handling via custom callbacks. This content is designed for HarmonyOS developers seeking efficient, permission-free methods to integrate media capture into their user interfaces.

## Detailed Description

### 完整示例.md 完整示例.md
This document provides a complete Cangjie code example demonstrating how to implement a camera picker for photos and videos within a HarmonyOS application. The main topics include UI component construction using RelativeContainer and Column, file system operations for creating temporary storage, and integration with the CameraKit API. Key information involves defining a custom PickCallBack class to handle asynchronous results, configuring a PickerProfile with a specific save URI, and dynamically updating state variables to display the selected media. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to integrate media capture and selection functionality into their user interfaces.

The main sections cover importing necessary modules, configuring the PickerProfile to manage file storage locations, and invoking the picker interface with a callback to handle results. This tutorial targets application developers seeking a simple, permission-free method for media capture.
