This directory provides API reference documentation for the `AVTranscoder` class in the Cangjie programming language, designed for video transcoding within the HarmonyOS MediaKit framework. It covers class definitions, configuration, lifecycle management (start, pause, resume, cancel), resource cleanup, and event handling (progress, completion, errors). The documentation details file descriptor usage, system capabilities, and exception handling. It is intended for multimedia developers building applications requiring video processing capabilities, offering the necessary interfaces to manage transcoding workflows effectively.
