# cj-apis-cj_leakwatcher

This directory serves as the central repository for the `cj-apis-cj_leakwatcher` module, a vital component of the PerformanceAnalysisKit tailored for the HarmonyOS ecosystem. It focuses on providing robust tools and documentation for identifying and resolving memory leaks within Cangjie applications. The core functionality revolves around the `CJLeakWatcher` class, enabling developers to enable detection mechanisms, register specific objects for continuous monitoring, and export detailed heap snapshots for analysis. By facilitating workflows for garbage collection and object lifecycle management, this resource is indispensable for Cangjie developers and system engineers. It empowers users to diagnose complex memory issues, optimize runtime performance, and ensure the long-term stability and reliability of their applications through rigorous leak detection protocols.
