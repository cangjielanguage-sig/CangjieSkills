# cj-apis-values_bucket

本目录包含Cangjie语言中 `ohos.data.values_bucket` 模块的API参考文档，该模块是ArkData开发中处理数据库数据的关键组件。文档详细阐述了用于定义向数据库插入的键值对数据集的结构与用法。核心内容涵盖了 `VBValueType` 枚举，具体列出了整型、浮点型、字符串和布尔值等数据库支持的字段类型，并明确了各数据类型的系统能力及起始版本（API 22）。本文档主要面向使用Cangjie语言进行ArkData应用开发的开发者，旨在指导其正确构造和使用 `ValuesBucket` 作为数据传输载体，从而实现高效的数据持久化操作。
