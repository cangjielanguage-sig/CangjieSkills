This directory serves as a technical guide for developers working with the HarmonyOS ArkUI framework and Cangjie language, focusing specifically on the integration of the `SymbolSpan` component within `Text` elements. It provides a deep dive into the necessary steps for creating symbols, embedding them correctly, and customizing their visual properties, including size, color, and weight. The documentation also explores advanced features such as rendering strategies (monochrome, multicolor, hierarchical opacity) and effect strategies (scaling, animations). A key constraint highlighted is that `SymbolSpan` must be embedded inside a `Text` component to render and does not support common events. This collection is ideal for application developers aiming to implement dynamic, inline iconography with high visual fidelity and interactive effects in their applications.
