This directory focuses on encryption and decryption implementation within the HarmonyOS ecosystem, utilizing the Universal Keystore Kit (HUKS). It covers essential cryptographic algorithms such as AES, RSA, and SM2, providing both theoretical guides and practical code examples. The content is tailored for developers and security engineers looking to integrate secure data handling, key lifecycle management, and cryptographic operations into their applications using the Cangjie programming language. It serves as a comprehensive resource for mastering data protection mechanisms and adhering to security best practices.
