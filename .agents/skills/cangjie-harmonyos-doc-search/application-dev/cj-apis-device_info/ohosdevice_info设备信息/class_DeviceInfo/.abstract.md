This directory contains API reference documentation for the Cangjie `DeviceInfo` class, designed for querying terminal device information within the OpenHarmony environment. It covers a wide range of static properties, including device identifiers (ODID, UDID), hardware specifications (brand, model), and software metadata (OS versions, build time). All functionalities rely on the SystemCapability.Startup.SystemInfo capability starting from API version 22. This documentation is suitable for Cangjie application developers who need to access system hardware and software details to implement system-aware features or diagnostics.
