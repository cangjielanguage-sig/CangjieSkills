# 受限开放权限

本目录详细阐述了HarmonyOS及OpenHarmony生态中受限开放权限的申请机制与参考标准。核心内容包括Beta阶段普通应用通过ACL跨级别申请获取敏感权限的调试指南，以及涵盖剪贴板、硬件信息等核心功能的系统权限列表。文档旨在帮助开发者在调试阶段临时提升应用权限等级（APL），并提供了商用发布的合规路径。主要面向需要进行深度系统集成、调试敏感接口或开发系统级应用的高级工程师与开发者。

## 详细描述

### 受限开放权限_2more_7f2da91d.md 受限开放权限_2more_7f2da91d.md
本文档旨在说明在Beta阶段，普通应用如何通过跨级别申请获取受限开放权限。主要涵盖申请方式、通过访问控制列表（ACL）跨级别申请的流程，以及修改HarmonyAppProvision配置文件中APL等级的具体步骤。关键信息包括需将应用APL等级声明为system_basic及以上，修改配置文件中的apl字段。特别强调此方式仅限调试使用，商用版本需通过应用市场申请正式证书和Profile文件。面向需要调试受限权限的HarmonyOS应用开发者，要求具备应用打包和签名配置的基础知识。

### 权限列表/
本目录包含OpenHarmony和HarmonyOS系统的权限参考文档，详细定义了各类系统级敏感权限的功能、级别及授权方式。内容涵盖剪贴板访问、硬件信息获取、虚拟屏管控、沙箱配置及内核内存保护等核心权限。所有权限均为system_basic级别，主要面向需要深度系统集成、访问敏感硬件数据或实现高级管理功能的系统开发者及应用工程师。
