This directory contains API reference documentation for the `InstancePropertyInfo` class within the Cangjie programming language. It focuses on reflection capabilities, specifically designed for inspecting and manipulating instance member properties at runtime. Key topics include metadata retrieval (such as annotations, modifiers, and type information), dynamic property value access, and property state modification. The documentation covers methods for checking mutability, abstract status, and comparing property info objects. This resource is suitable for Cangjie developers who need to programmatically analyze program structure or dynamically interact with object properties using the reflection package.
