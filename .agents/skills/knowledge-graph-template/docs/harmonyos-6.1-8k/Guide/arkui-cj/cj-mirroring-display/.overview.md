# cj-mirroring-display

This directory serves as a comprehensive technical resource for developers working with the ArkUI framework, specifically focusing on the implementation of mirroring display capabilities to support Right-to-Left (RTL) user interfaces. It addresses the critical requirements of internationalization (i18n) for applications targeting regions with RTL languages such as Arabic and Hebrew. The documentation provides in-depth guidance on the `direction` property, automatic component adaptation, and the use of generalized directional attributes like `start` and `end`. This collection is essential for developers aiming to create culturally and linguistically appropriate layouts that seamlessly switch between Left-to-Right (LTR) and RTL modes without breaking the UI structure or compromising the user experience.

## Detailed Description

### 使用镜像能力/
This subdirectory contains a specialized collection of development documentation focused on the mirroring capabilities of the ArkUI framework. It is designed to guide developers through the complex process of implementing Right-to-Left (RTL) UI layout adaptations, which is a fundamental requirement for creating truly internationalized applications. The content covers a wide range of topics, starting with the basic concepts of mirroring capability and explaining the precise conditions under which these capabilities become active within the application environment.

Beyond the basics, the documentation provides a detailed analysis of the current adaptation status of various UI components. It helps developers understand which elements are automatically mirrored by the framework and which require manual intervention or specific configuration. It also highlights important usage constraints to prevent common layout errors during the mirroring process.

A key focus of the material is the practical application of the `direction` attribute to trigger mirroring. Developers will learn how to effectively switch the layout direction based on the user's locale. Furthermore, the docs instruct on the correct usage of generalized direction words—specifically `start` and `end`—when defining layouts and borders. This approach ensures that UI elements align correctly regardless of whether the layout is LTR or RTL, avoiding the hardcoding of directional values that often leads to layout bugs in mirrored environments. These resources are indispensable for ArkUI developers targeting international markets, especially those supporting Arabic, Hebrew, and other RTL languages, ensuring a polished and native-feeling user experience.
