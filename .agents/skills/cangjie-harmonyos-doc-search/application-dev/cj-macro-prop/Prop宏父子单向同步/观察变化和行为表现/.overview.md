# 观察变化和行为表现

This directory provides a comprehensive technical overview of observing data changes and behavioral performance within the Cangjie programming language's state management ecosystem. It specifically targets the `@Prop` decorator, elucidating its role in reactive UI development for ArkUI. The content covers critical aspects such as initialization processes, one-way data synchronization between parent and child components, and update mechanisms. It also addresses complex scenarios involving object and collection mutations, distinguishing between simple and deep observation requirements. This documentation is highly suitable for software developers and system architects seeking to master state management logic and ensure predictable application behavior.

## Detailed Description

### 框架行为.md 框架行为.md
This document outlines the initialization and update mechanisms for @Prop decorated variables within a parent-child component hierarchy. It covers the initial rendering process where data is passed from parent to child, and the update behavior characterized by one-way data flow. Key takeaways include that child @Prop updates do not sync back to the parent, while parent updates overwrite local child modifications. The document also notes that @Prop cannot refresh when the application is in the background, recommending @Link instead. This technical reference is intended for developers managing component state and lifecycle.

### 观察变化/
This directory serves as a specialized technical resource focused on the intricacies of observing data changes within the Cangjie programming language's state management system. It specifically addresses the functionality of the `@Prop` decorator, a critical component for building reactive user interfaces in ArkUI. The documentation covers a wide spectrum of scenarios, ranging from simple primitive type updates to complex object and collection mutations. It clarifies the boundaries of automatic observation, explaining when deep observation mechanisms like `@Observed` and `@Publish` are necessary. Furthermore, it defines the strict one-way data synchronization flow from parent components to child components. This material is highly suitable for software developers and system architects working with Cangjie who need to implement robust, efficient, and predictable state management logic in their applications.
