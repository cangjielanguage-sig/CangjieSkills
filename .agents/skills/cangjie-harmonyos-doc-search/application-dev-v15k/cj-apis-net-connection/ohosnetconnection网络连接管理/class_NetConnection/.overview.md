# class_NetConnection

This directory contains API reference documentation for the `NetConnection` class within the Cangjie language's NetworkKit. It focuses on network connection management, specifically how to subscribe to and monitor network state changes, capabilities, and availability. Key topics include the registration and unregistration processes, handling various network events like switching between WiFi and cellular data, and managing callbacks for network handles and properties. This documentation is suitable for HarmonyOS developers and system application builders who need to implement real-time network status monitoring and handle network transitions effectively.

## Detailed Description

### class_NetConnection_4more.md class_NetConnection_4more.md
This document serves as API reference documentation for the NetConnection class in the Cangjie language, focusing on network connection management. It covers the class definition and three primary subscription methods: onNetAvailable, onNetBlockStatusChange, and onNetCapabilitiesChange. Key information includes the requirement to call register before subscribing and the handling of network state transitions like switching from WiFi to cellular. The document explains callback parameters such as NetHandle and NetCapabilityInfo. Targeted at developers using the NetworkKit, this guide provides the necessary syntax and examples for monitoring network status and capabilities within system applications.

### func_onNetConnectionProper_3more.md func_onNetConnectionProper_3more.md

The main sections cover onNetConnectionPropertiesChange, onNetLost, and onNetUnavailable, providing syntax, parameter descriptions, and usage examples. Key information includes the mandatory requirement to call register before subscribing and unregister to stop notifications. These functions utilize callbacks to return network handles and connection properties. Intended for HarmonyOS developers using the NetworkKit, this documentation facilitates the implementation of real-time network status monitoring within applications.

### func_register_2more.md func_register_2more.md
This document serves as API reference documentation for managing network state subscriptions in the Cangjie programming language. It details two primary functions: register(), which subscribes to network state changes, and unregister(), which cancels this subscription. Key information includes required permissions like ohos.permission.GET_NETWORK_INFO, specific system capabilities, version 12 compatibility, and comprehensive error code tables for handling exceptions such as permission denial or service connection failures. Targeted at Cangjie developers using the NetworkKit, this guide provides the necessary syntax and error handling logic to implement network monitoring features in HarmonyOS applications.
