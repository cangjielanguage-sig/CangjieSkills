## 开发步骤及注意事项

详细的API说明请参见[AVRecorder API参考](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#class-avrecorder)。

1. 创建AVRecorder实例，实例创建完成进入idle状态。

   > **说明：**
   >
   > 需要在avRecorder完成赋值（即“avRecorder = recorder ”运行完成）后，再进行剩余操作。

   ```cangjie
   let avRecorder: AVRecorder = createAVRecorder()
   ```

2. 设置业务需要的监听事件，监听状态变化及错误上报。

   | 事件类型 | 说明 |
   | -------- | -------- |
   | stateChange | 必要事件，监听AVRecorder的state属性改变 |
   | error | 必要事件，监听AVRecorder的错误信息 |

   ```cangjie
    import ohos.base.BusinessException

    // 状态上报回调函数
    // 用户可以在此补充状态发生切换后想要进行的动作，回调函数的声明可以参考完整示例
    this.avRecorder.getOrThrow().on(AVRecorderCallbackType.AVRECORDER_STATE_CHANGE, StateChangeCallback())
    // 错误上报回调函数
    this.avRecorder.on(AVRecorderCallbackType.AVRECORDER_ERROR, ErrorCallBack())
    ```

3. 配置音频录制参数，调用prepare()接口，此时进入prepared状态。

    > **说明：**
    >
    > 配置参数需要注意：
    >
    > - 配置参数之前需要确保完成对应权限的申请，请参见[申请权限](#申请权限)。
    > - prepare接口的入参avConfig中仅设置音频相关的配置参数，如示例代码所示。
    > - 如果只需要录制音频，请不要设置视频相关配置参数；如果需要录制视频，请参见[视频录制开发指导](./cj-media-kit-video-recording.md)进行开发。直接设置视频相关参数会导致后续步骤报错。
    > - 需要使用支持的[录制规格](./cj-media-kit-intro.md#支持的格式)。
    > - 录制输出的url地址（即示例里avConfig中的url），形式为fd://xx (fd Int32)。需要基础文件操作接口（[Core File Kit的ohos.file.fs](../../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md)）实现应用文件访问能力，获取方式请参见[应用文件访问与管理](../../file-management/cj-app-file-access.md)。
    >
    > 获取AbilityContext下方示例中有所省略，详细获取方式请参见[完整示例](#完整示例)。

    ```cangjie
    import kit.MediaKit.*
    import kit.CoreFileKit.*
    import ohos.base.*

    var avProfile: AVRecorderProfile = AVRecorderProfile(
    ContainerFormatType.CFT_MPEG_4A, // 封装格式，当前支持MP4，M4A，MP3，WAV
    audioBitrate: 100000, // 音频比特率
    audioChannels: 2, // 音频声道数
    audioCodec: CodecMimeType.AUDIO_AAC, // 音频编码格式，当前支持ACC，MP3，G711MU
    audioSampleRate: 48000 // 音频采样率
    )

    // 通过MainAbility获取AbilityContext
    let context: UIAbilityContext
    var filePath: String = context.filesDirectory + "/example.mp3"
    var audioFile: File = FileFs.open(path, mode: READ_WRITE.mode | CREATE.mode)
    var fileFd: Int32 = this.audioFile.fd // 获取文件fd

    var avConfig: AVRecorderConfig = AVRecorderConfig(
    avProfile,
    "fd://" + fileFd.toString(), // 参考应用文件访问与管理中的开发示例获取创建的音频文件fd
    audioSourceType: AudioSourceType.AUDIO_SOURCE_TYPE_MIC, // 音频输入源，这里设置为麦克风
    )

    this.avRecorder.prepare(avConfig)
    ```

4. 开始录制，调用start()接口，此时进入started状态。

    ```cangjie
    // 开始录制
    avRecorder.start()
    ```

5. 暂停录制，调用pause()接口，此时进入paused状态。

    ```cangjie
    // 暂停录制
    avRecorder.pause()
    ```

6. 恢复录制，调用resume()接口，此时再次进入started状态。

    ```cangjie
    // 恢复录制
    avRecorder.resume()
    ```

7. 停止录制，调用stop()接口，此时进入stopped状态。

   ```cangjie
      // 停止录制
      avRecorder.stop()
      ```

8. 重置资源，调用reset()重新进入idle状态，允许重新配置录制参数。

    ```cangjie
    // 重置资源
    avRecorder.reset()
    ```

9. 销毁实例，调用release()进入released状态，退出录制。

    ```cangjie
    // 销毁实例
    avRecorder.release()
    ```
