This directory contains API reference documentation for the `On` class within the Cangjie UiTest framework. It provides comprehensive details on locating, filtering, and identifying UI controls for automated testing. The documentation covers various methods for setting attributes like text, ID, and state, as well as relative positioning and hierarchical searching. Designed for software developers and QA engineers using the Cangjie language, these resources facilitate precise widget identification and method chaining to construct robust test selectors using the SystemCapability.Test.UiTest capability.
