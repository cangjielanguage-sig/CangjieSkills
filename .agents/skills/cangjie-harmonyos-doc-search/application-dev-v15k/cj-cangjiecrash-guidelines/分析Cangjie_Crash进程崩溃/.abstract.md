This directory acts as a central knowledge base for analyzing and debugging process crashes in Cangjie applications. It offers a deep dive into crash log specifications, helping developers distinguish between system-level errors and logic-based exceptions. The material covers practical methods for log retrieval using DevEco Studio or hiAppEvent, alongside proven strategies for root cause analysis via stacktraces. Furthermore, it includes a rich collection of case studies focused on runtime issues like `OutOfMemoryError` and `StackOverflowError`. This resource is tailored for Cangjie developers and engineers who want to enhance application stability, master debugging tools, and implement effective error handling. By utilizing these guides, users can systematically diagnose uncaught exceptions, interpret complex log fields, and resolve stability challenges efficiently. The content bridges the gap between theoretical error types and practical debugging scenarios.
