This directory contains API reference documentation for the `AbilityConfiguration` class in the Cangjie programming language. It focuses on defining environmental configuration information for application abilities, covering initialization parameters and public properties such as language, color mode, screen direction, density, and display ID. The documentation is designed for Cangjie developers working on system capability integration and UI adaptation, specifically targeting version 19 and above. It provides essential details on managing application configuration states and handling system capability changes.
