# 示例

This directory provides a comprehensive collection of code examples and tutorials designed to demonstrate advanced animation techniques within the ArkUI framework. It specifically focuses on the implementation of complex component transitions and staggered animations using the `TransitionEffect` API. The content covers essential concepts such as combining opacity, scale, rotation, and translation properties, as well as managing animation parameters like curves and delays. It includes examples for both Cangjie and ArkTS environments, illustrating how to use `animateTo` closures and `ForEach` for sequential effects. These resources are highly suitable for developers seeking to create dynamic, responsive user interfaces with sophisticated entry and exit animations in HarmonyOS applications.

## Detailed Description

### 示例_1.md 示例_1.md
This document serves as a code tutorial demonstrating how to implement complex component transitions using TransitionEffect in the ArkUI framework with Cangjie. It details the process of creating stacked transition effects by combining properties like opacity, scale, rotation, and translation, while managing animation parameters such as curves. Key sections explain applying effects via the transition interface and triggering animations through conditional rendering or animateTo closures. The document highlights how animation parameters propagate through combined effects and suggests using delays for sequential multi-component animations. It targets developers looking to enhance user interface dynamics with custom entry and exit animations.

### 示例_2.md 示例_2.md
This document serves as a code example demonstrating the implementation of staggered entrance and exit animations for a Grid component using HarmonyOS ArkUI. The primary focus is on utilizing TransitionEffect to combine opacity and scale changes, alongside ForEach to generate items with sequential delays based on their index. Key takeaways include the configuration of AnimateParam for friction-based curves and the use of animateTo to trigger state changes. This example is designed for developers looking to enhance user interface interactivity with complex, cascading transition effects in ArkTS applications.
