This directory provides comprehensive API reference documentation for the deprecated `ConsoleReader` class and associated standard input utilities within the Cangjie programming language. It focuses on the mechanisms for reading, converting, and processing console input, including detailed explanations of EOF behavior, synchronous buffered operations, and specific methods such as `read()`, `readln()`, `readToEnd`, and `readUntil`. The documentation highlights critical considerations like UTF-8 truncation risks and exception handling strategies. It is specifically designed for Cangjie developers who are maintaining legacy systems or require a deep understanding of console input streams, assuming a solid foundation in basic I/O operations and data types like `Rune` and `String`. The content serves as a vital resource for understanding the transition to the `env` package and handling legacy input stream logic.
