## 详细说明

### cj-navigation-switching-stepperitem.md cj-navigation-switching-stepperitem.md
本文档是ArkUI框架中StepperItem组件的API参考文档，该组件作为Stepper导航组件的页面子组件使用。文档主要涵盖了模块导入、组件初始化方法、nextLabel和prevLabel等用于自定义按钮文本的属性函数，以及状态配置功能。关键信息指出StepperItem仅支持单个子组件，其宽高由父组件Stepper决定，且导航按钮具有默认文本（如“下一步”、“返回”）。该组件目前处于Beta阶段。文档面向使用仓颉语言进行UI开发的开发者，适用于构建分步导航流程的应用场景。
