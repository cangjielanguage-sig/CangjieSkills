This directory, `cj-certManager-guidelines`, functions as a pivotal technical resource for developers engaged in certificate management within the HarmonyOS ecosystem. It offers extensive guidance on implementing application private credential management, specifically leveraging the capabilities of the DeviceCertificateKit and the Cangjie programming language. The documentation thoroughly addresses essential security operations, encompassing the installation, retrieval, and uninstallation of credentials, as well as sophisticated cryptographic tasks like signing and verification. Furthermore, it provides detailed instructions on integrating with the Universal Keystore (HUKS) and supports widely used algorithms such as RSA and ECC. This content is meticulously designed for HarmonyOS application developers utilizing SDK API version 12 or higher. It assists in configuring necessary permissions, managing the credential lifecycle, and ensuring robust data security, making it an indispensable guide for creating secure applications that require rigorous certificate handling and comprehensive error management.
