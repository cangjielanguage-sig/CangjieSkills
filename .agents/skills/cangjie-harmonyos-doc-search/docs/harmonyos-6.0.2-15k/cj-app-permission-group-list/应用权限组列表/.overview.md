# 应用权限组列表

This directory serves as a comprehensive resource for developers working with application permissions and file access within the HarmonyOS operating system. It details the architecture of permission groups, explaining how related permissions—such as those for Location or Camera—are requested together in a single user dialog to improve the user experience. Furthermore, it provides specific technical guidance for file and folder access on 2-in-1 devices, covering media library permissions and the implementation of system Pickers for permission-free access. The documentation highlights critical distinctions between direct access requiring authorization and indirect access via user selection. This content is vital for developers seeking to configure permissions correctly, handle sensitive data like motion and health information, and ensure compliance with device-specific restrictions.
