This directory contains API reference documentation for the `SingleKVStore` class within the Cangjie language's ArkData framework. It covers the management of distributed key-value store databases, focusing on data persistence, transaction management, and synchronization. Key functionalities include data insertion, deletion, retrieval, backup, restore, and transaction control. The documentation is designed for developers working on HarmonyOS or OpenHarmony applications who need to implement robust local and distributed data storage solutions. It provides detailed method signatures, error handling for `BusinessException`, and practical code examples to assist in application development.
