# cj-bm-tool

The `cj-bm-tool` directory functions as a specialized repository for the Bundle Manager (bm) tool, specifically curated for the Cangjie and HarmonyOS development ecosystems. It provides an extensive collection of documentation focused on command-line interface (CLI) operations that are essential for managing the complete application lifecycle. The content covers a broad spectrum of tasks, ranging from basic installation and uninstallation to more complex operations like querying, debugging, and patching. Additionally, it addresses the management of specific package formats such as HAR and HAP, as well as the handling of shared libraries and overlays. This directory is an invaluable resource for developers, system administrators, and technical support personnel who need to execute precise deployment commands and resolve signature conflicts or installation issues directly through the shell environment.

## Detailed Description

### bm工具/

This directory houses a complete set of documentation for the Bundle Manager (bm) tool, a utility integral to the Cangjie and HarmonyOS development environments. The content is designed to guide users through the various command-line operations necessary to control the full application lifecycle. Key areas of instruction include the installation and uninstallation of applications, querying system and application data, debugging processes, and applying patches. The documentation also provides in-depth coverage of specialized topics, such as the proper handling of HAR and HAP packages, the management of shared libraries, and the configuration of overlays. Furthermore, it offers solutions for querying detailed application information and resolving technical challenges, specifically installation failures and signature conflicts. This resource is tailored for developers, system administrators, and technical support personnel who require a reliable reference for managing application deployment and troubleshooting issues via the shell. By centralizing this information, the directory ensures that users can quickly find the necessary commands to maintain system health and application performance.
