This directory contains technical documentation for HAR (Harmony Archive), a static shared package format used in HarmonyOS development for distributing Cangjie components, code, and resources. It covers the complete lifecycle of HAR packages, including creation, compilation, publishing, and consumption within DevEco Studio. Key topics include dependency management, resource conflict resolution, and integration with OHPM repositories. This resource is suitable for HarmonyOS developers and library maintainers looking to modularize their applications and share code efficiently across projects.
