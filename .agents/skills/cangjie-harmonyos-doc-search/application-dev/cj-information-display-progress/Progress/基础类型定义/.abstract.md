This directory contains fundamental type definitions for the ArkUI framework, specifically focusing on progress bar components within the Cangjie programming language environment. It covers essential interfaces, enumerations, and configuration classes that define the visual style, behavior, and state of progress indicators. Key elements include style options, progress status enums, and common interfaces for UI customization. This documentation is suitable for HarmonyOS developers and UI engineers who need to implement or customize progress bars in their applications using Cangjie.
