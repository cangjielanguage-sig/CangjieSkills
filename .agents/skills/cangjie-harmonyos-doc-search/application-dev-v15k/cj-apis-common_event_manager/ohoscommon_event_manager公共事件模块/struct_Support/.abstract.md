This directory contains API reference documentation for the `Support` struct and related system event constants within the Cangjie programming language environment. It primarily focuses on defining static constant string identifiers for various system-level common events, including Bluetooth states, Wi-Fi operations, storage volume changes, user lifecycle management, and device power states. The documentation provides specific event values, required subscriber permissions, and API version compatibility. It is suitable for application and system developers who need to subscribe to, handle, or broadcast system-level notifications and hardware state changes within the OpenHarmony ecosystem.
