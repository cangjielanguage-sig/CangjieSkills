This directory contains API reference documentation for the `GestureEvent` class within the ArkUI framework, specifically written for the Cangjie language. It covers the structural definition, properties, and initialization of gesture events used to handle user interactions like panning, pinching, rotating, and swiping. The documentation details metrics such as rotation angles, coordinate offsets, scaling ratios, and velocity components, distinguishing between touchscreens and pointing devices. It is suitable for developers implementing complex gesture recognition and event-driven interfaces in ArkUI applications.
