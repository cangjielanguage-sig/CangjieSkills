# 接入步骤

This directory provides comprehensive technical documentation for implementing file interaction capabilities within the HarmonyOS ecosystem using the Cangjie programming language. It specifically addresses the complete workflow required for one application to open files managed by another, covering both the receiving (target) and initiating (caller) sides of the interaction. Key technical concepts include `module.json5` configuration, URI scheme handling, `Want` object construction, and permission management. These guides are essential for developers building file viewers, editors, or any application requiring cross-app file sharing and data viewing functionalities. By following these steps, developers can ensure seamless interoperability between applications for handling local file resources.

## Detailed Description

### 目标方接入步骤.md 目标方接入步骤.md
This technical guide instructs developers on enabling applications to open local files within the HarmonyOS environment. The document details two primary steps: declaring file opening capabilities in the module.json5 configuration file and implementing the file handling logic in Cangjie code. Key configuration requirements include setting the action to "ohos.want.action.viewData", the URI scheme to "file", and the link feature to "FileOpen". The code section demonstrates extracting the file URI from the Want object and accessing the file using the FileIo API. This guide targets developers building file viewer or editor applications.

### 调用方接入步骤.md 调用方接入步骤.md
This technical tutorial guides developers through the integration steps for a caller application to open a file using the Cangjie language. The document outlines four main procedures: importing necessary modules like AbilityKit, retrieving the application file path and converting it to a URI, constructing a Want object with specific read/write permissions and the "viewData" action, and invoking the startAbility interface. Key takeaways include the configuration of URI permissions and the specific action required for file opening scenarios. This guide is intended for HarmonyOS developers implementing file sharing or viewing capabilities.
