# class_PhotoViewPicker

This directory provides in-depth API reference documentation for the `PhotoViewPicker` class in the Cangjie language, tailored for the HarmonyOS ecosystem. It details the technical implementation of selecting and saving images or videos via a system interface, covering critical components such as the class constructor, asynchronous callback patterns, and configuration options like `PhotoSaveOptions`. A key distinction highlighted is that saved files are stored in the File Manager rather than the system Gallery. The documentation includes practical code examples for instantiation and usage. This content is highly suitable for developers implementing file management features who possess a working knowledge of the AbilityKit framework and asynchronous programming paradigms.
