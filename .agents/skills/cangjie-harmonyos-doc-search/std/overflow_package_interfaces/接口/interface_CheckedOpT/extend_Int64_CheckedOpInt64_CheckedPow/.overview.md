# extend_Int64_CheckedOpInt64_CheckedPow

This directory contains API reference documentation for the Cangjie programming language, specifically focusing on extending the `Int64` type to support safe arithmetic operations. It covers the implementation of the `CheckedOp` and `CheckedPow` interfaces, detailing functions like `checkedAdd`, `checkedMul`, `checkedNeg`, and bitwise shifts. The core theme is safety through the `Option` return strategy, which returns `None` upon overflow instead of throwing exceptions or wrapping values. This resource is suitable for Cangjie developers who need to perform robust integer arithmetic and prevent undefined behavior caused by numerical overflows. The documentation is organized into files covering interface extensions and specific function references.
