# 开发步骤

This directory outlines the development steps for integrating device sensors into hybrid applications using the Cangjie language and HarmonyOS. It covers the full workflow from backend permission handling in native code to frontend data retrieval using standard Web APIs. Key topics include UIAbility context management, system permission requests for accelerometers and gyroscopes, and JavaScript implementation of the Generic Sensor API and legacy events. This guide is suitable for HarmonyOS developers and web engineers working on mobile-first or PWA projects that require hardware sensor access.

## Detailed Description

### 开发步骤_1.md
This tutorial guides developers on implementing sensor permission handling for Web components in Cangjie-based applications. It covers obtaining the UIAbility context, requesting specific system permissions like accelerometer and gyroscope, and configuring the Web component's onPermissionRequest callback to manage user authorization via an AlertDialog. Key takeaways include using the AbilityAccessCtrl manager for permission requests and handling grant or deny actions based on user interaction, while frontend code utilizes W3C standard JavaScript interfaces. Targeted at HarmonyOS developers with knowledge of Cangjie and ArkUI, this document serves as a practical guide for enabling sensor access in hybrid web applications.

### 开发步骤_2.md
This document provides an HTML and JavaScript example demonstrating how to access and retrieve data from various device motion and orientation sensors. It covers the Generic Sensor API, specifically the Accelerometer, Gyroscope, and AbsoluteOrientationSensor classes, alongside legacy window events like DeviceMotionEvent and DeviceOrientationEvent. Key information includes initializing sensors with a 60Hz frequency, managing event listeners for activation and errors, and logging real-time data such as acceleration, rotation rates, and quaternions. This technical guide is intended for web developers implementing sensor-based features in mobile applications, likely within a hybrid development environment.

### 开发步骤_3.md
This document serves as a code example or tutorial step demonstrating how to implement and manage device sensor event listeners, specifically focusing on device orientation and motion within a web application. The content covers JavaScript functions for removing event listeners and handling orientation data, alongside an HTML user interface containing buttons to trigger various sensor interactions such as accelerometer, gyroscope, and absolute orientation. Key takeaways include the specific syntax for the deviceorientationabsolute event, the structure of the event object containing alpha, beta, and gamma values, and the integration of these functions into a clickable UI for testing purposes. This is intended for web developers building mobile-first applications or progressive web apps (PWAs) that require access to hardware sensors, serving as a practical reference for implementation.
