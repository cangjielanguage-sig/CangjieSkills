# build

本目录汇集了仓颉项目管理工具中 `build` 命令的核心文档，旨在为开发者提供全面的构建指导。内容涵盖了构建命令的基础功能、高级配置选项（如增量编译、并发控制、调试模式及交叉编译）、依赖管理机制以及中间文件的处理逻辑。此外，还专门针对构建过程中常见的循环依赖问题提供了详细的故障排除指南。这些文档适合仓颉语言开发者及项目维护者阅读，能够帮助用户深入理解构建系统的工作原理，有效配置构建环境，并快速定位解决构建过程中的各类错误，从而提升开发效率。

## Detailed Description

### build_1.md
这份文档介绍了仓颉项目管理工具中 `build` 命令的功能与用法，旨在指导开发者构建项目。主要内容包括命令的各种配置选项，如增量编译、并发控制、调试模式、输出路径及交叉编译等，以及中间文件与可执行文件的存放位置。关键信息包括构建前会检查依赖，若发现循环依赖将中止构建，且通过 `cjpm.lock` 确保构建的可复制性。这是一份面向仓颉开发者的命令参考文档，帮助用户理解构建流程及常见错误处理。

### build_2.md
这份文档旨在指导开发者如何排查和解决代码构建中的循环依赖问题。主要内容包括基于报错信息分析导入路径、检查并删除冗余导入，以及在存在功能性依赖时通过重构导入顺序或拆分模块来打破闭环。关键信息在于通过单向依赖或模块拆解来解决问题，且该处理方式同样适用于涉及依赖解析的其他命令。这是一份面向开发者的故障排除指南，适用于遇到构建错误的场景。关键词：循环依赖、构建错误、重构、模块拆分。
