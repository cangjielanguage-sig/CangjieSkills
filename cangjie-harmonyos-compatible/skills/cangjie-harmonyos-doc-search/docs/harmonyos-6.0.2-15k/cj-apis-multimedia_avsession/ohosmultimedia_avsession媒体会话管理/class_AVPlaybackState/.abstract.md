This directory contains API reference documentation for the `AVPlaybackState` class within the Cangjie language's Multimedia AVSession Core system. It comprehensively covers the initialization, properties, and management of media playback contexts. Key topics include playback state, speed, volume, loop mode, video dimensions, and custom metadata handling via HashMap. These resources are designed for developers building multimedia applications who need to represent and control media playback status, starting from API version 19.
