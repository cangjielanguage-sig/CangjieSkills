# 示例2Grid嵌套滚动

This directory provides a comprehensive collection of code examples focused on implementing and managing nested scrolling behaviors in Grid components within HarmonyOS applications. It addresses complex scenarios where a parent List and a child Grid must coordinate their scroll interactions seamlessly. The directory includes two distinct approaches: one utilizing the Cangjie programming language to handle low-level event interception and scroll logic, and another using ArkTS to implement user interface enhancements such as a "Back to Top" button. Key technical concepts covered include nestedScroll options, onScrollFrameBegin callbacks, touch event handling, scroller management, and UI styling. These resources are specifically designed for HarmonyOS developers who need to create sophisticated, responsive layouts with smooth, coordinated scrolling and intuitive navigation controls.

## Detailed Description

### 示例2Grid嵌套滚动_1.md 示例2Grid嵌套滚动_1.md
This document provides a code example demonstrating how to implement nested scrolling between a parent List and a child Grid component in the Cangjie programming language. It covers the usage of nestedScroll options, onScrollFrameBegin callbacks, and touch event handling to coordinate scroll behavior. The key takeaway is the logic to intercept scroll events on the parent List once it reaches a specific offset and transfer them to the inner Grid using scrollBy, ensuring smooth interaction. This is intended for HarmonyOS developers using Cangjie who need to create complex layouts with coordinated scrolling containers.

### 示例2Grid嵌套滚动_2.md 示例2Grid嵌套滚动_2.md
This document serves as a code example demonstrating the implementation of a "Back to Top" button within a nested Grid scrolling scenario using ArkTS. The primary focus is on handling scroll events and UI component styling. Key sections include the definition of a circular button with shadow effects and the implementation of an onClick event listener. The code illustrates how to simultaneously reset the scroll positions of two distinct scrollers, scroller and gridScroller, to their origin coordinates. This example is intended for HarmonyOS developers seeking to enhance user experience by adding navigation controls to complex scrollable layouts. Keywords: ArkTS, Grid, Scroller, scrollTo, onClick, UI styling, nested scrolling.
