# learn-cj

The `learn-cj` directory is a specialized educational repository designed to support developers working with the Cangjie programming language. It focuses on providing essential resources for building applications within the HarmonyOS and OpenHarmony ecosystems. This directory covers a wide range of topics, from fundamental language syntax to advanced system-level integration techniques. Key areas include Foreign Function Interface (FFI) implementation for cross-language interoperability and structured learning paths for language mastery. It is suitable for software developers, system architects, and technical students who wish to leverage the Cangjie language for modern application development. Whether you are building native applications or integrating complex system components, this repository provides the necessary documentation and guidance to succeed in the HarmonyOS development environment.

## Detailed Description

### [1] FFI/
This directory focuses on Foreign Function Interface (FFI) documentation, specifically regarding the interoperability between the Cangjie programming language and ArkTS within the HarmonyOS/OpenHarmony ecosystem. It serves as a central hub for developers who need to enable seamless communication and data exchange between these two distinct languages. The documentation provided here is critical for complex application scenarios where performance optimization or the reuse of existing ArkTS codebases is necessary. By detailing the mechanisms of FFI, this section helps developers navigate the challenges of cross-language calling conventions, type conversions, and memory management, ensuring that applications built with Cangjie can effectively leverage the broader capabilities of the HarmonyOS platform.

### [2] README_zh/
This directory serves as the primary entry point for the `README_zh` project, acting as a comprehensive resource hub dedicated to the Cangjie programming language. It is designed to provide a structured and in-depth learning path that guides users from basic syntax to complex programming paradigms. As the main interface for the project, it aggregates essential information, tutorials, and guides that are vital for mastering the language. This resource is particularly valuable for new developers entering the ecosystem, as it organizes the learning process into manageable steps, ensuring a smooth transition into developing robust applications with Cangjie. It acts as the definitive starting point for anyone looking to explore the full potential of the language.
