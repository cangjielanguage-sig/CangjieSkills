This directory provides essential type definitions for the ArkUI framework, specifically tailored for the Cangjie programming language. It focuses on the core components required to construct and customize buttons within user interfaces. The content covers configuration classes that manage display properties—such as shape, size, and state effects—as well as enumerations defining functional roles, visual styles, and geometric types. By offering these foundational building blocks, the documentation enables developers to implement consistent and interactive UI elements. This resource is primarily suitable for ArkUI developers and UI engineers who need to fine-tune the appearance and behavior of buttons in their applications starting from version 19.
