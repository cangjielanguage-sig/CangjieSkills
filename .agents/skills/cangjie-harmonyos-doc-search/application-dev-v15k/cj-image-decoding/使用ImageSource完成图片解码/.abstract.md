This directory provides a comprehensive guide for developers on how to use the ImageSource component to decode images within applications. It covers the fundamental concepts of image decoding, converting various formats like JPEG, PNG, and WebP into PixelMap structures for display or processing. The content includes technical overviews, specific development steps using the Cangjie language, and practical examples for handling resource files. It is designed for application developers who need to implement image handling features and possess a basic understanding of the HarmonyOS system and Cangjie syntax.
