# enum_BundleFlag

This directory provides comprehensive API reference documentation for the Cangjie language, specifically focusing on the `BundleFlag` enumeration and its utility functions. It details how to specify content scopes when retrieving application bundle information, covering flags for default settings, application data, HAP modules, abilities, permissions, and signatures. Additionally, it includes technical references for accessing enumeration values programmatically. This resource is essential for system developers and software engineers utilizing the BundleManager framework who need precise control over data retrieval and enumeration management within their applications.

## Detailed Description

### enum_BundleFlag_13more.md enum_BundleFlag_13more.md
This API reference document defines the `BundleFlag` enumeration for the Cangjie language, which is used to specify the content scope when retrieving application bundle information. It details specific flags such as `GET_BUNDLE_INFO_DEFAULT`, `GET_BUNDLE_INFO_WITH_APPLICATION`, and `GET_BUNDLE_INFO_WITH_HAP_MODULE`, as well as flags for abilities, permissions, and signatures. The documentation highlights important dependency rules, noting that flags like `GET_BUNDLE_INFO_WITH_ABILITY` and `GET_BUNDLE_INFO_WITH_METADATA` must be combined with `GET_BUNDLE_INFO_WITH_HAP_MODULE` or other specific flags to function correctly. This document is intended for system developers working with the BundleManager framework who need granular control over bundle data retrieval.

### func_getValue.md func_getValue.md
This document serves as API reference documentation for the Cangjie function `getValue`, which retrieves the integer value of an enumeration. The content includes the function signature, a description of its functionality, system capabilities, and the starting version number. Key information highlights that the function returns an `Int32` type representing the enumeration's value and is associated with the `SystemCapability.BundleManager.BundleFramework.Core` capability available from version 12. This technical reference is intended for software developers using the Cangjie language who need to programmatically access enumeration values within the Bundle framework.
