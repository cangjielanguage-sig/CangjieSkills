This directory serves as a foundational resource for understanding state management within the Cangjie (CJ) framework, specifically targeting State Management V1 in declarative UI environments. It addresses the critical challenge of synchronizing data state with UI rendering, a core requirement for modern application development. The documentation explores a range of mechanisms, from component-level decorators like @State and @Link to application-wide solutions such as AppStorage. It clarifies the distinctions between unidirectional and bidirectional data flows and highlights the operational constraints of the main UI thread. Designed for developers utilizing the Cangjie framework, this guide is essential for mastering reactive programming principles, ensuring efficient data synchronization, and managing complex state hierarchies in scalable applications.
