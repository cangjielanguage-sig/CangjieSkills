This directory contains technical reference documentation for common error codes within the Package Management Subsystem. It covers a wide range of issues related to application lifecycle management, including installation, uninstallation, updates, and configuration validation. Key topics include bundle name resolution, HAP file parsing, permission verification, distributed services, and enterprise device management restrictions. These documents provide detailed error messages, root causes, and resolution steps. This resource is suitable for software developers, system integrators, and QA engineers using DevEco Studio or working with HarmonyOS bundle management to diagnose and resolve runtime or deployment errors.
