This directory contains API reference documentation for component properties within the Cangjie ArkUI framework, specifically focusing on image configuration and manipulation. It covers essential functions for customizing image rendering, such as setting placeholders, controlling tiling styles, managing decoding dimensions, and optimizing memory usage. Key topics include resource management, visual effects, layout adaptation for internationalization, and performance tuning for image display. This documentation is suitable for developers building ArkUI applications who need precise control over image behavior, ensuring efficient resource usage and high-quality visual presentation across different device configurations. The files provide detailed parameter definitions, default values, and system capability requirements to assist in the implementation of robust image handling features.
