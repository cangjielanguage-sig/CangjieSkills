# 页面跳转

This directory serves as a comprehensive resource for mastering page navigation within the Cangjie development environment. It focuses on the Router module, providing essential knowledge for implementing navigation logic, managing page lifecycles, and handling data transfer between different views. Key topics include understanding jump modes like pushUrl and replaceUrl, managing page instances (Standard and Single), and adhering to the 32-page stack limit. Additionally, it covers the technical specifics of parameter passing using string types and Option<String> retrieval. This documentation is specifically designed for Cangjie developers and UI engineers who are building robust applications and require efficient state management and navigation control. By following these guides, developers can ensure smooth user experiences and maintainable code structures.

## Detailed Description

The following files provide in-depth technical instructions and code examples for the topics outlined above.

### 页面跳转_1.md 页面跳转_1.md
This guide explains how to implement page navigation using the Router module in Cangjie development. It details two jump modes: pushUrl for retaining pages and replaceUrl for destroying them, alongside instance modes Standard and Single for managing page instances. The document highlights the 32-page stack limit and provides four practical code scenarios, such as login flows and detail views, to demonstrate correct usage. Targeted at developers, this tutorial offers essential patterns for managing application navigation and page stacks effectively.

### 页面跳转_2.md 页面跳转_2.md
This technical guide explains how to pass and retrieve parameters during page navigation using the Cangjie Router module. It covers two primary operations: sending data via the pushUrl method with a params attribute, and receiving data in the target page using the getParams method. The documentation specifies that the parameter passed is a string, and the retrieved value is of type Option<String>. Code examples demonstrate the implementation for both the source and destination pages. This is intended for Cangjie developers building UI applications who need to transfer state or data between views.
