This directory serves as a practical reference manual for Cangjie language developers aiming to leverage the POSIX library for system-level process management. It bridges the gap between high-level application development and low-level operating system interaction by offering concrete, executable code examples. The scope of the document includes critical operations such as modifying process priority with `nice`, which is essential for resource management; sending signals to processes or process groups using `kill` and `killpg` for control and communication; and utilizing `isatty` to determine if a file descriptor is associated with a terminal. The documentation also addresses cross-platform concerns, clearly marking these features as incompatible with the Windows operating system. This collection is best suited for developers who already have a grasp of Cangjie syntax and are looking to expand their capabilities into system programming, requiring a basic familiarity with POSIX standards to fully utilize the provided samples.
