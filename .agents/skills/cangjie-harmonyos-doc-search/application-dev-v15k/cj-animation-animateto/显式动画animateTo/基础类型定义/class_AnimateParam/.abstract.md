This directory serves as a comprehensive resource for the `AnimateParam` class, a fundamental component within the ArkUI framework designed for defining animation configuration parameters. It is specifically tailored for HarmonyOS developers who utilize the Cangjie language to build dynamic and responsive user interfaces. The documentation covers the complete API reference for the class, including detailed explanations of properties such as duration, curve, delay, iterations, and playMode. Furthermore, it provides in-depth technical guidance on the `init` constructor, outlining function signatures, system capabilities, and parameter tables. Developers will find critical warnings regarding playback modes and constraints on animation duration. This directory is suitable for anyone looking to implement sophisticated animation behaviors, control timing and speed, and manage repetition logic in their applications starting from API version 12.
