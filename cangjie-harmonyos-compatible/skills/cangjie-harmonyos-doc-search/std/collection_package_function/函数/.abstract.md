This directory contains API reference documentation for generic iterator and collection utility functions within the Cangjie programming language. It covers a comprehensive range of functional programming operations, including predicate checks, data transformations, aggregations, and conversions between different collection types like Arrays, ArrayLists, and HashMaps. The documentation details function signatures, parameters, return values, and generic constraints such as Hashable and Comparable. It is suitable for Cangjie developers seeking to efficiently manipulate iterable data structures, perform complex queries, and manage data flow using higher-order functions.
