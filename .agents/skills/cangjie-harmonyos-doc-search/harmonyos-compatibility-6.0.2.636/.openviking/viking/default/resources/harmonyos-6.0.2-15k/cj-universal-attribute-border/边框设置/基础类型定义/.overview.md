# 基础类型定义

This directory contains API reference documentation for fundamental Cangjie classes used in the ArkUI framework to define UI component borders and styling. It covers classes for specifying border colors, widths, and corner radii, with specific support for both standard layouts and internationalized (RTL) interfaces. Key concepts include `EdgeColors`, `EdgeWidths`, `LocalizedBorderRadiuses`, and localized edge properties. These documents are suitable for Cangjie developers and UI designers looking to implement precise, responsive, and localized styling for application components.

## Detailed Description

### class_EdgeColors.md class_EdgeColors.md
This API reference document defines the EdgeColors class, which is used to describe border colors for UI components across different directions. The documentation covers the class properties top, bottom, left, and right, all of type Option<ResourceColor>, and details the class constructor. Key information includes that these properties are readable and writable, defaulting to Option.None, and can be initialized via named parameters. Intended for Cangjie developers using the ArkUI framework, this guide provides the necessary syntax and parameters for styling component borders. Keywords: EdgeColors, ArkUI, Cangjie, ResourceColor, UI styling, border properties.

### class_EdgeWidths.md class_EdgeWidths.md
This API reference document details the Cangjie class EdgeWidths, designed to configure border widths for popup backplanes within the ArkUI framework. The documentation covers the class structure, specifically defining four public properties—top, right, bottom, and left—all of the Length type. Key information includes the constructor, which accepts optional named parameters with a default value of 0.vp, allowing flexible initialization. Intended for developers working with ArkUI system capabilities, this guide assists in customizing UI component borders using semantic keywords like EdgeWidths, Length, and ArkUI.

### class_LocalizedBorderRadiuses.md class_LocalizedBorderRadiuses.md
This API reference document defines the Cangjie class LocalizedBorderRadiuses, designed to describe border corner radii for UI components while supporting right-to-left (RTL) language layouts. The content details the class structure, specifically covering four public properties: bottomEnd, bottomStart, topEnd, and topStart. Each property is of type Option<Length> and adapts its position based on the display direction, swapping corners for RTL languages. The document also outlines the class constructor, which accepts these radii as named parameters with default values. Intended for ArkUI developers using Cangjie, this guide ensures proper visual adaptation for internationalized interfaces.

### class_LocalizedEdgeColors.md class_LocalizedEdgeColors.md
This API documentation defines the LocalizedEdgeColors class in Cangjie, used to specify border colors for the four sides of a UI component while supporting layout localization. The document details the class structure, including four public properties (top, bottom, start, end) of type Option<ResourceColor>, and the class constructor. Key information highlights that start and end properties automatically adapt to right-to-left language modes, ensuring correct visual rendering, while all properties are readable and writable. This reference guide targets UI developers using the ArkUI framework who need to implement internationalized border styling, requiring knowledge of Cangjie syntax and resource color types.

### class_LocalizedEdgeWidths.md class_LocalizedEdgeWidths.md
This API reference document defines the Cangjie class LocalizedEdgeWidths, designed to describe border widths for UI components with internationalization support. The documentation covers the class structure, specifically detailing the properties for top, bottom, start, and end edges, alongside the constructor method. Key information includes the use of the Option<Length> type for dimensions and the distinction between logical directions (start/end) and physical directions to handle right-to-left (RTL) layouts correctly. Intended for ArkUI developers, this reference assists in implementing responsive and localized component styling using named parameters.
