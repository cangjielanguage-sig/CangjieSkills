# ohosgeo_location_manager位置服务

本目录包含仓颉语言中用于HarmonyOS位置服务的API参考文档，涵盖了从模块导入、权限申请到具体定位请求和结果处理的完整流程。核心内容包括定位请求配置（优先级、场景）、定位结果数据结构以及定位源类型（GNSS、网络等）。该模块支持单次定位和连续定位，适用于需要集成高精度或低功耗位置功能的应用开发者。文档详细说明了系统能力要求及参数互斥逻辑，帮助开发者高效实现导航、轨迹追踪等场景。

## 详细说明

### class_SingleLocat_2more_5b4a564a.md class_SingleLocat_2more_5b4a564a.md
这份API参考文档定义了Cangjie语言中用于单次定位请求的SingleLocationRequest类及其优先级枚举LocatingPriority。文档涵盖了类的构造函数、定位优先级属性及超时时间参数的详细说明。核心信息包括两种定位策略的区别：精度优先策略结合GNSS和网络定位返回最佳结果，而速度优先策略则优先返回首个结果，两者均消耗较大资源。该文档面向需要集成系统定位核心能力的开发者，提供了完整的参数定义和系统能力要求。

### enum_LocationRequestPri_84b523c8.md enum_LocationRequestPri_84b523c8.md
本文档定义了仓颉语言中用于指定位置请求优先级的枚举类型 LocationRequestPriority。文档详细介绍了 Accuracy、FirstFix、LowPower 和 Unset 四个枚举值，分别对应精度优先、快速定位、低功耗和未设置策略。关键信息包括：Accuracy 依赖GNSS提供高精度但高功耗；FirstFix 结合GNSS和网络定位以快速获取位置；LowPower 仅使用网络定位以节省功耗。该文档属于API参考文档，面向需要配置定位策略的开发者，涉及系统核心定位能力。

### enum_LocationRequestScenario.md enum_LocationRequestScenario.md
本文档是Cangjie语言中LocationRequestScenario枚举的API参考文档，旨在定义位置请求中的不同定位场景类型。文档涵盖了Navigation、TrajectoryTracking、CarHailing、DailyLifeService及NoPower等主要枚举值，详细说明了各场景的适用范围（如导航、打车、日常服务）及所采用的定位技术（如GNSS或网络定位）。关键信息指出了高功耗场景与低功耗场景的区别，以及在特定场景下网络定位作为GNSS补充的回退机制。该文档面向需要集成位置服务的应用开发者，要求其具备基本的定位技术知识。

### enum_LocationSourceType_621bd458.md enum_LocationSourceType_621bd458.md
这是一份Cangjie语言的API参考文档，定义了用于标识定位结果来源的LocationSourceType枚举。文档详细介绍了Gnss、Network、Indoor和Rtk等主要枚举值，分别对应全球导航卫星系统、网络定位、室内高精度定位及室外高精度定位技术。该枚举属于SystemCapability.Location.Location.Core系统能力，起始版本为22，旨在帮助开发者区分定位数据的具体技术来源。文档主要面向使用Cangjie进行位置服务开发的开发人员，作为查询定位源类型的参考依据。

### ohosgeo_location__4more_0e15b9fd.md ohosgeo_location__4more_0e15b9fd.md
本文档是仓颉语言中 `ohos.geo_location_manager` 模块的 API 参考指南，旨在提供位置服务功能。主要涵盖模块导入、权限申请及示例代码的使用说明。该模块支持 GNSS 定位及网络定位（基站、WLAN、蓝牙），目前处于 Beta 阶段且仅支持 WGS-84 坐标系。使用时需开启设备“位置”开关。面向 HarmonyOS 仓颉开发者，需具备应用上下文配置及权限申请的基础知识。

本目录包含Cangjie语言中`CurrentLocationRequest`类的API参考文档，主要用于定义和初始化请求当前位置信息的参数配置。内容涵盖了类的核心属性（如精度要求、优先级、场景和超时时间）及其构造函数的详细说明。文档重点阐述了`scenario`与`priority`的互斥逻辑以及参数的有效性限制。该目录适合需要集成定位服务、配置定位请求参数的开发者阅读，要求具备Cangjie语法基础及位置权限相关知识。

### class_GeoLocationManager/
本目录包含关于Cangjie语言中GeoLocationManager类的API参考文档，主要面向HarmonyOS应用开发者。文档详细介绍了如何使用该类获取设备位置信息，包括getCurrentLocation方法的重载版本以及检查位置开关状态的isLocationEnabled方法。内容涵盖了必要的权限配置（如ohos.APPROXIMATELY_LOCATION）、返回值类型、BusinessException错误码处理以及完整的代码示例。这些资料旨在帮助开发者在应用中高效集成定位功能，处理异常。

### class_Location/
