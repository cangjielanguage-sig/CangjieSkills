# README_zh

本目录是Connectivity Kit（短距通信服务）的中文文档入口，旨在为开发者提供系统性的开发文档索引与功能概览。它主要涵盖了Connectivity Kit的基础介绍、核心术语表，以及详尽的蓝牙服务开发指南。内容涉及蓝牙技术概述、设备查找机制、连接管理及数据传输等关键子章节。文档特别指出该服务目前处于Beta特性阶段，并深入讲解了蓝牙低功耗（BLE）的开发全流程，包括设备发现、GATT连接建立及数据交互操作。本目录非常适合需要进行短距通信应用开发的工程师，尤其是专注于蓝牙功能集成与优化的技术人员参考使用。
