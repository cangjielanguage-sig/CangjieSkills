本目录主要介绍如何使用AES对称密钥的ECB模式进行数据的加密与解密操作。内容涵盖了从密钥生成、密码器创建到初始化及最终处理的完整流程，特别指定了AES128|ECB|PKCS7参数配置。文档面向CryptoArchitectureKit开发者及仓颉语言开发者，提供了Beta阶段的理论教程与具体的代码示例，帮助开发者在鸿蒙开发中实现基础数据加密。核心关键词包括AES、ECB、PKCS7、加解密、CryptoArchitectureKit及仓颉。
