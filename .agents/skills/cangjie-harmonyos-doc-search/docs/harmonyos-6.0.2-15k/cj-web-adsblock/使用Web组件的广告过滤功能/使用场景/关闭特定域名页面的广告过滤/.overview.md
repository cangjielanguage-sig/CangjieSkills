# 关闭特定域名页面的广告过滤

This directory provides comprehensive technical resources for developers looking to implement granular control over ad filtering in Web components. It focuses on the mechanisms required to disable ad blocking for specific domain pages using the `AdsBlockManager`. Key topics include the configuration of allowlists and disallowlists, the logic behind domain suffix matching, and the priority rules governing these lists (e.g., AllowList overriding DisallowedList). The documentation covers implementation in both the ArkWeb framework (using Cangjie) and HarmonyOS (using ArkTS), highlighting differences in persistence and setup requirements. It is suitable for application developers who need to manage complex ad filtering scenarios, such as exempting parent domains while blocking ads on subdomains, ensuring a tailored browsing experience within their applications.

## Detailed Description

### 关闭特定域名页面的广告过滤_1.md
This technical guide explains how to disable ad filtering for specific domain pages within a Web component using the AdsBlockManager. It covers the usage of the addAdsBlockDisallowedList interface, provides Cangjie code examples, and details the logic of domain suffix matching. Key takeaways include understanding the priority between the DisallowedList, which disables filtering, and the AllowList, which re-enables it with higher precedence. The document illustrates how to manage complex scenarios, such as disabling ads for a parent domain while keeping them active for specific subdomains. This guide is intended for application developers using the ArkWeb framework who require granular control over ad filtering behavior.

### 关闭特定域名页面的广告过滤_2.md
This document provides a code example demonstrating how to configure ad filtering allowlists and disallowlists for specific domains within a HarmonyOS Web component. The content covers the implementation of AdsBlockManager methods to manage domain exceptions alongside the standard Web controller setup. Key takeaways include the requirement that enableAdsBlock must be active for these settings to function and that the domain lists are not persistent, resetting after the application restarts. This guide is intended for HarmonyOS developers using ArkTS who need granular control over web content ad blocking.
