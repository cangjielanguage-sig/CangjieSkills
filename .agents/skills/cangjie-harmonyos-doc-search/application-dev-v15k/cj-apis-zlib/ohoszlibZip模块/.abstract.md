This directory provides API reference documentation for the `ohos.zlib` module in the HarmonyOS Cangjie environment. It covers the Zlib subsystem, focusing on data compression, decompression, and integrity verification. Key components include classes for stream management (ZStream, GZip, Zip), enumerations for configuration (levels, strategies, flush modes), and utility functions for file handling. The documentation details error handling, buffer management, and system capabilities. It is intended for Cangjie developers implementing data compression workflows, managing archives, or ensuring data integrity in HarmonyOS applications.
