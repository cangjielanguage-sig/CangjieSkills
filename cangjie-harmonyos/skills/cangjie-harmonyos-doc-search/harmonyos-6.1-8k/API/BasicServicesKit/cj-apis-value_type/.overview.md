# cj-apis-value_type

本目录提供了仓颉语言 `ohos.value_type` 模块的 API 参考文档，专门用于定义 HarmonyOS 系统中公共事件附加信息的类型取值。文档详细介绍了核心枚举 `CommonEventValueType`，该枚举广泛支持 Int32、String、Bool、Float64 以及文件描述符 FD 等多种基础数据类型，同时也包含这些类型的数组形式。此模块起始版本为 22，目前处于 Beta 阶段。文档内容涵盖模块导入方法、代码编写示例及 API 详细定义，非常适合需要处理公共事件数据结构的 HarmonyOS 仓颉开发者参考使用，要求使用者具备基础的工程配置与开发能力。

## 详细说明

### cj-apis-value_type.md cj-apis-value_type.md
本文档是仓颉语言 `ohos.value_type` 模块的 API 参考文档，用于定义公共事件附加信息的类型取值。文档主要包含模块导入说明、代码示例指南及核心枚举 `CommonEventValueType` 的详细定义。该枚举涵盖了 Int32、String、Bool、Float64、文件描述符 FD 等基础类型及其对应的数组类型，起始版本为 22。文档面向 HarmonyOS 仓颉开发者，需具备基本的工程配置能力，目前处于 Beta 阶段。
