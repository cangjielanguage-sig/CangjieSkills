## 创建组件

### init(Scroller, () -> Unit)

```cangjie
public init(scroller: Scroller, child: () -> Unit)
```

**功能：** 创建滚动条组件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|scroller|[Scroller](cj-scroll-swipe-scroll.md#class-scroller)|是|-|可滚动组件的控制器。用于与可滚动组件进行绑定。|
|child|()->Unit|是|-|声明容器内的子组件。|

### init(Scroller, ScrollBarDirection, () -> Unit)

```cangjie
public init(scroller: Scroller, direction: ScrollBarDirection, child: () -> Unit)
```

**功能：** 创建滚动条组件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|scroller|[Scroller](cj-scroll-swipe-scroll.md#class-scroller)|是|-|可滚动组件的控制器。用于与可滚动组件进行绑定。|
|direction|[ScrollBarDirection](./cj-common-types.md#enum-scrollbardirection)|是|-|滚动条的方向，控制可滚动组件对应方向的滚动。<br/>初始值：ScrollBarDirection.Vertical。|
|child|()->Unit|是|-|容器内的子组件。|
