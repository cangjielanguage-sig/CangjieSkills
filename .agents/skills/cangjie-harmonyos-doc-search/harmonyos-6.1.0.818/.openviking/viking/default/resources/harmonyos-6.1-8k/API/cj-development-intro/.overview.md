# cj-development-intro

This directory serves as a comprehensive introductory resource and knowledge base for developers utilizing the Cangjie language within the OpenHarmony ecosystem. It provides essential development guidelines and normative specifications designed to streamline the application creation process from start to finish. The content covers critical aspects such as integrating Cangjie API sample code into standard project templates, navigating complex API reference documentation, and interpreting version notes and system capabilities. Furthermore, it addresses the application model restrictions, specifically the Stage model, permission application mechanisms, and Context handling. This documentation is tailored for developers aiming to build robust applications, ensuring they adhere to documentation standards, invoke interfaces compliantly, and achieve efficient development workflows. By following these guidelines, developers can ensure their applications are secure, functional, and fully aligned with platform requirements.
