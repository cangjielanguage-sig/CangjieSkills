# ohosmultimodalInputkeyEvent按键输入事件

This directory provides essential API reference documentation for managing key input events within OpenHarmony applications developed using the Cangjie language. It focuses on the multimodal input subsystem, detailing the structures necessary to interpret and handle keyboard and button interactions. The content encompasses the `Action` enum for state definition, the `Key` class for raw device input, and the `KeyEvent` class for high-level event modeling. This resource is specifically designed for software developers and system engineers aiming to create responsive applications that require precise control over input mechanisms, including key codes, timestamps, and modifier states.

### ohosmultimodalInputkeyEven_3more.md ohosmultimodalInputkeyEven_3more.md
This document serves as API reference documentation for the Key class within the ohos.multimodalInput.keyEvent module, designed to handle device-reported key input events in the Cangjie language. The content details the class structure, specifically focusing on its constructor and three primary properties: code (KeyCode), pressedTime (Int64 in microseconds), and deviceId (Int32). Key takeaways include that all properties are readable and writable, the class inherits from InputEvent, and it requires system capability SystemCapability.MultimodalInput.Input.Core starting from version 19. This reference is intended for OpenHarmony application developers using the Cangjie language who need to process physical keyboard or button interactions.
