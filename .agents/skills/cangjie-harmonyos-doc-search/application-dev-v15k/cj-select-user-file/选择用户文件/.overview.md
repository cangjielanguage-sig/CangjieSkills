# 选择用户文件

This directory contains comprehensive technical documentation for HarmonyOS developers focusing on file selection mechanisms using the Cangjie language. It details the implementation of system FilePickers, including DocumentViewPicker and AudioViewPicker, to enable users to select and save files without requiring explicit application permissions. The guides cover essential workflows such as importing modules, configuring selection options, managing temporary URI permissions, and reading file data using FileFs. These resources are designed for developers building applications that require secure access to documents, images, and audio resources within the HarmonyOS ecosystem.

## Detailed Description

### 选择文档类文件.md 选择文档类文件.md
This tutorial guides developers through selecting document files using the DocumentViewPicker in the Cangjie language for HarmonyOS. It covers importing necessary modules, configuring selection options like file suffixes and maximum count, and invoking the picker interface to handle returned URIs. Key information includes the temporary read-only nature of URI permissions and the process of accessing file content. The document details using FileFs.open to obtain a file descriptor from the URI and FileFs.read to retrieve data. This guide is intended for application developers implementing file selection and reading capabilities within the HarmonyOS ecosystem.

### 选择用户文件_2more.md 选择用户文件_2more.md
This guide instructs developers on using the system pre-installed FilePicker to enable users to select and save files without requiring specific application permissions. It categorizes file selection into three main types: PhotoViewPicker, DocumentViewPicker, and AudioViewPicker. Key information includes the deprecation of the original PhotoViewPicker, directing developers to use PhotoAccessHelper for image selection and security controls for saving. DocumentViewPicker handles general files, while AudioViewPicker manages audio resources. This documentation serves as a technical reference for developers implementing file access capabilities in their applications.

### 选择音频类文件.md 选择音频类文件.md
This tutorial guides developers through selecting audio files using the AudioViewPicker in the Cangjie language. It covers importing necessary modules, creating selection options, invoking the picker interface, and accessing file data via file descriptors. Key takeaways include the creation of AudioSelectOptions, which defaults to all file types, and the critical note that returned URIs possess temporary read-only permissions that expire when the app exits the background. The document demonstrates using FileFs.open and FileFs.read to process the selected audio content. This guide targets application developers implementing file selection and media playback features within the HarmonyOS ecosystem.
