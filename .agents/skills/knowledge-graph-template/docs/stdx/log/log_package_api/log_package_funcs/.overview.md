## 详细说明

### log_package_funcs.md log_package_funcs.md

本文档是日志包中关于全局 Logger 管理的 API 参考文档。主要介绍了 `getGlobalLogger` 和 `setGlobalLogger` 两个核心函数，分别用于获取和设置全局 Logger 对象。关键要点包括：`getGlobalLogger` 可根据传入的属性数组返回 Logger 副本；`setGlobalLogger` 应在程序生命周期中仅调用一次，通常由日志提供者初始化，调用前的日志事件会被忽略。该文档面向使用该日志框架的开发者，需具备对 Logger 类和 Attr 类型的基本了解。
