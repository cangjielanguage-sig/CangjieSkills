# cj-apis-hidebug

This directory serves as the comprehensive API reference documentation for the `ohos.hidebug` module, specifically developed for the Cangjie programming language. As a critical component of the Performance Analysis Kit, it provides developers with the necessary interfaces to perform in-depth system and application performance profiling. The documentation covers a wide range of essential metrics, including detailed memory usage statistics (encompassing native, system, and heap memory), precise CPU utilization metrics, and advanced resource management functions. It outlines key components such as classes for memory information, thread usage analysis, and trace flags, alongside functions for retrieving system diagnostics and managing application resource limits. This resource is primarily tailored for system developers and performance engineers operating on the HarmonyOS platform (API version 19 and above), equipping them with the tools required for deep debugging and the optimization of complex application processes and system resources.
