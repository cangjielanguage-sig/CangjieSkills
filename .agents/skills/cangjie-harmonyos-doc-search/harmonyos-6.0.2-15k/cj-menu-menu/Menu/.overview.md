# Menu

This directory contains comprehensive API reference documentation for the ArkUI Menu component within the HarmonyOS ecosystem, specifically tailored for the Cangjie language. It covers the structural implementation of vertical menus, including sub-components like MenuItem and MenuItemGroup, as well as configuration options for submenu expansion modes and styling attributes. The documentation details binding methods, width calculations, and visual customization such as typography and borders. It is suitable for HarmonyOS developers and UI/UX engineers looking to implement interactive, multi-level menus and refine user interface behaviors in their applications.

## Detailed Description

### Menu_4more.md Menu_4more.md
This document serves as API reference documentation for the Menu component, which displays a vertical list of options. It details the component structure, including sub-components like MenuItem and MenuItemGroup, and the init constructor method. Key information emphasizes that the Menu cannot be used standalone and must be bound via bindMenu or bindContextMenu methods. The text also explains specific width calculation rules, covering default 2-grid sizing, adaptive content expansion, and fixed width constraints. Intended for developers using this UI framework, the guide ensures proper implementation of interactive menus with support for all universal attributes and events.

### 基础类型定义_2more.md 基础类型定义_2more.md
This document provides API reference documentation for the SubMenuExpandingMode enum within the ArkUI framework, specifically for the Cangjie language. It details three submenu expansion styles: SIDE_EXPAND (default side-by-side), EMBEDDED_EXPAND (nested), and STACK_EXPAND (floating overlay). Additionally, it documents a deprecated getValue method and includes a comprehensive code example demonstrating how to implement multi-level menus using MenuItem and bindMenu. The content targets HarmonyOS developers seeking to customize menu behaviors and layouts in their applications.
