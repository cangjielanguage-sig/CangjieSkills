# cj-animation-pagetransition

This directory contains resources and examples for implementing page transition animations using the Cangjie language within the ArkUI framework. It focuses on creating smooth, professional-grade navigation flows by utilizing custom entry and exit effects such as scaling, sliding, and opacity changes. The content covers essential APIs like `PageTransitionEnter` and `PageTransitionExit`, providing developers with the tools to enhance user experience in HarmonyOS applications. It is suitable for UI developers and application creators looking to master dynamic interface animations and route switching logic.

## Detailed Description

### 页面间转场pageTransition/
This directory focuses on implementing custom page transition animations within the ArkUI framework using the Cangjie language. It covers the essential APIs for configuring entry and exit effects, including scaling, sliding, and opacity changes during route switching. The content includes detailed references for classes like `PageTransitionEnter`, `PageTransitionExit`, and `PageTransitionOptions`, as well as enumerations for route types. It is suitable for UI developers and HarmonyOS application creators looking to enhance user experience with smooth, professional-grade navigation flows and dynamic interface animations.
