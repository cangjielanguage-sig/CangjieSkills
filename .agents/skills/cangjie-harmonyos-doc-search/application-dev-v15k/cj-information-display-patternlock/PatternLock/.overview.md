# PatternLock

This directory provides comprehensive documentation for the PatternLock component within the ArkUI framework, designed for implementing secure, gesture-based password verification interfaces. It covers API references for component creation, basic type definitions, event handling, and property configuration using the Cangjie programming language. The content includes practical code examples demonstrating state management, visual customization, and validation logic. Suitable for HarmonyOS developers and software engineers looking to integrate 9-grid pattern authentication into their applications, with support starting from API version 12.

## Detailed Description

### PatternLock_4more.md PatternLock_4more.md
This document provides API reference documentation for the PatternLock component, a 9-grid interface used for pattern-based password verification in ArkUI applications. The content focuses on component creation, detailing two initialization methods: a default constructor and an overload that accepts a PatternLockController for state reset functionality. Key information includes that the component supports all universal attributes and events, requires SystemCapability.ArkUI.ArkUI.Full, and is available starting from version 12. Written in Cangjie, this guide is intended for developers seeking to implement secure authentication interfaces using touch-based pattern inputs.

### 基础类型定义.md 基础类型定义.md
This document serves as an API reference for basic type definitions related to the PatternLock component in the Cangjie programming language. It covers the `PatternLockController` class for state management, the `CircleStyleOptions` class for visual styling of grid dots, and the `PatternLockChallengeResult` enumeration for validation outcomes. Key functionalities include resetting the component state via the controller, customizing ring color and radius, and setting password correctness status. Versioning indicates features evolved from version 12 to 19. This technical reference is intended for software developers using ArkUI to implement secure pattern lock interfaces.

### 示例代码.md 示例代码.md
This document provides a practical Cangjie code example demonstrating the implementation and configuration of a Pattern Lock (gesture password) user interface component. It covers UI layout construction using Column, PatternLock customization (colors, radius), and state management with @State and ObservedArray. The code implements a two-step password verification logic, checking for minimum length and matching inputs, while providing visual feedback through PatternLockChallengeResult and text messages. It also includes a reset mechanism. This example is intended for HarmonyOS developers using the Cangjie language and ArkUI framework to integrate security features into their applications.

### 组件事件.md 组件事件.md
This API reference document details event handling functions for a grid-based password input component within the ArkUI framework. It covers two primary functions: onDotConnect for tracking individual dot selections and onPatternComplete for handling the completion of the input sequence. Key information includes the specific indexing system where grid dots are numbered 0 through 8 row by row. onDotConnect returns a single index, while onPatternComplete returns an array of indices representing the full pattern. This documentation targets developers implementing pattern lock interfaces, requiring knowledge of the Cangjie programming language and ArkUI system capabilities.
