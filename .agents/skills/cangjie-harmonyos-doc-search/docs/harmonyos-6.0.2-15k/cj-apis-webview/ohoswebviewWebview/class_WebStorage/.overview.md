# class_WebStorage

This directory contains API reference documentation for the Cangjie `WebStorage` class, part of the ArkWeb framework. It focuses on managing Web SQL databases and HTML5 Web storage interfaces within HarmonyOS applications. The documentation covers essential functionalities such as clearing data for specific origins, retrieving storage quotas, and monitoring usage statistics. It is designed for Cangjie developers who need to programmatically control web data persistence, handle asynchronous callbacks, and manage storage resources effectively in their Web components.
