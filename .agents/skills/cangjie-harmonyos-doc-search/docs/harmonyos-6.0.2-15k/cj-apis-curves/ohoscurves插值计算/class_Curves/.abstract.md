This directory contains API reference documentation for the Curves class within the Cangjie ArkUI framework, focusing on animation interpolation. It covers various curve types including standard Bezier curves, custom interpolation logic, and physics-based spring animations. Key topics include cubic Bezier creation, spring dynamics (mass, stiffness, damping), and stepped transitions. These resources are designed for UI developers and engineers using Cangjie to implement smooth, responsive, and physics-driven animations in their applications. The documentation assumes familiarity with ArkUI concepts and Cangjie syntax.
