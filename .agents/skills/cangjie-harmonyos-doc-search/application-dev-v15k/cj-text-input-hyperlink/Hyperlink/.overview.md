# Hyperlink

This directory provides comprehensive technical documentation for the Hyperlink component within the Cangjie ArkUI framework. It serves as a complete resource for developers aiming to implement web navigation capabilities in their applications. The content covers essential aspects such as component functionality, permission requirements for internet access, and API references for initialization. Additionally, it details universal properties, event handling, and customization options for text and image sub-components. This documentation is specifically suitable for Cangjie application developers and UI engineers seeking to integrate interactive, external URL redirection features into their user interfaces effectively.

## Detailed Description

### Hyperlink_3more.md Hyperlink_3more.md
This document serves as a reference guide for the Hyperlink component, which enables navigation to external URLs when clicked within its defined area. It covers component functionality, permission requirements, and supported child components. Key takeaways include the restriction to system browser usage, the necessity of the ohos.permission.INTERNET permission for network access, and support for Image sub-components. This technical reference is intended for developers implementing web navigation features in their applications, providing essential constraints and usage rules for integration.

### 创建组件.md 创建组件.md
This document serves as API reference documentation for initializing Hyperlink components within the Cangjie ArkUI framework. It details six overloaded init constructors that allow developers to define the hyperlink's web address and display content using various combinations of String and AppResource types. Key takeaways include the flexibility to use either text content or a lambda-defined subcomponent, with the note that text is hidden when subcomponents are present. The documentation specifies system capabilities and version requirements ranging from API 16 to 19. Intended for application developers, this reference provides the necessary syntax to implement web navigation links effectively in user interfaces.

### 通用属性通用事件_3more.md 通用属性通用事件_3more.md
This API reference document outlines the specific attributes and usage of the Hyperlink component in the Cangjie ArkUI framework. It confirms support for all universal properties and events while detailing the specific color function, which allows developers to set the hyperlink text color using a ResourceColor parameter. The document includes a code example demonstrating how to implement hyperlinks with both text and image content. Targeted at Cangjie developers, this guide provides the necessary syntax and parameters for customizing hyperlink appearance and behavior in UI applications.
