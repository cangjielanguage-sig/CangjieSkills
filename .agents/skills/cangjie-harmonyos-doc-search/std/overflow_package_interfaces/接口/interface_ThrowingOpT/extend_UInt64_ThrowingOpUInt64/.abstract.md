This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically detailing the implementation of the `ThrowingOp` interface for the `UInt64` type. It encompasses a wide array of arithmetic and bitwise operations designed to utilize exception-throwing strategies for robust error management. The content covers critical functions such as addition, subtraction, multiplication, division, negation, and bit shifting. Specifically, it details how these functions throw `OverflowException` or `OvershiftException` to alert developers to critical issues. This documentation is highly suitable for Cangjie developers who require strict error handling mechanisms to ensure data integrity and prevent silent failures in high-precision numeric applications, offering a safer alternative to standard wrapping behaviors.
