# FFI

This directory focuses on Foreign Function Interface (FFI) documentation, specifically regarding the interoperability between the Cangjie programming language and ArkTS within the HarmonyOS/OpenHarmony ecosystem. It serves as a central hub for developers looking to integrate Cangjie into existing ArkTS projects or understand the language's role in the native application ecosystem. The content covers bidirectional calling mechanisms, data access, multi-threading scenarios, and development guidelines. It is suitable for application developers, system architects, and those interested in cross-language development on the OpenHarmony platform.
