# 结构体

This directory serves as a comprehensive API reference for fundamental data structures within the Cangjie programming language, specifically targeting the needs of compiler development and syntax analysis. It documents the `Position` and `Token` structs, which are critical for representing source code locations and lexical units, respectively. The content covers structural definitions, initialization constructors, instance methods for data manipulation, and serialization interfaces like `ToBytes`. Designed for compiler developers, language engineers, and software architects, these documents provide the necessary technical details to implement parsers, manage Abstract Syntax Trees (AST), and build robust tooling for the Cangjie ecosystem.

## Detailed Description

### struct_Position.md struct_Position.md
This document provides API reference documentation for the Cangjie Position struct, a data structure designed to represent source code location information. It covers member properties including file ID, line number, and column number, alongside constructors for initialization. Key sections detail instance methods for printing data, checking if the position is empty, and serializing the struct to a byte array via the ToBytes interface. Additionally, it documents equality operators for comparing instances. This reference is intended for developers working with compiler tools or Abstract Syntax Trees (AST) in the Cangjie programming language who require precise tracking of code positions.

### struct_Token/
This directory provides essential API documentation for the `Token` struct, which acts as the fundamental lexical unit used to construct Abstract Syntax Trees (AST) in the Cangjie programming language. It covers the complete structural definition of tokens, detailing their core properties such as kind, position, and value, alongside various constructors for initialization. The documentation also explains critical methods for adding position data, debugging via dump functions, and serialization through toBytes. Furthermore, it addresses the relationship between tokens and syntax tree nodes, including inheritance from the ToBytes interface. This technical reference is indispensable for compiler developers, language engineers, and software developers working on parsing or AST manipulation, offering the necessary insights to handle lexical units effectively within the Cangjie ecosystem.
