### class_FadingEdgeO_3more_1f5b913c.md class_FadingEdgeO_3more_1f5b913c.md
本文档是ArkUI框架下Cangjie语言的API参考文档，详细定义了三个用于配置滚动组件行为的选项类：FadingEdgeOptions、ScrollEdgeOptions和ScrollToIndexOptions。文档涵盖了每个类的属性定义，包括淡出边缘长度、滚动速度及滚动偏移量，并说明了其构造函数参数、默认值及系统能力要求。这些类自版本22起可用，旨在帮助开发者精细控制UI的边缘效果和滚动交互，主要面向使用Cangjie语言进行ArkUI应用开发的工程师。

### class_ScrollAnima_2more_f2e521db.md class_ScrollAnima_2more_f2e521db.md
本文档定义了Cangjie语言中用于配置滚动行为的两个类：ScrollAnimationOptions和NestedScrollOptions。主要涵盖滚动动画参数（如持续时间、曲线、越界滚动）和嵌套滚动模式（向前、向后）的属性定义及构造函数。ScrollAnimationOptions支持自定义动画时长、缓动曲线及越界滚动；NestedScrollOptions用于控制父子组件的嵌套滚动交互。两者均属于ArkUI全量系统能力，起始版本为22。面向使用Cangjie开发ArkUI界面的开发者，适用于需要精细控制滚动动画和嵌套滚动逻辑的场景。

### class_ScrollResul_3more_839451ca.md class_ScrollResul_3more_839451ca.md
这是一份Cangjie语言的API参考文档，定义了ArkUI框架中用于描述滚动和布局结果的三种数据结构。文档涵盖了ScrollResult（滚动剩余值）、OffsetResult（XY轴偏移量）和RectResult（矩形坐标及尺寸）类的属性定义与构造方法。核心内容包括各类的Float64类型属性及其读写能力，所有类均支持通过构造函数初始化。该文档适用于ArkUI应用开发者，提供了处理滚动操作和几何计算所需的数据模型规范。

### enum_ScrollAlign_2more_f17689dc.md enum_ScrollAlign_2more_f17689dc.md
这是一份Cangjie语言的API参考文档，详细定义了ArkUI框架中用于UI布局控制的两个枚举类型：ScrollAlign和ContentClipMode。文档主要涵盖ScrollAlign的列表项对齐模式（起始、居中、结束、自动）以及ContentClipMode的内容裁剪模式（仅内容、边界、安全区域）。两个枚举均继承自Equatable接口，并重载了相等与不相等操作符，支持版本为22。该文档面向使用Cangjie进行ArkUI应用开发的开发者，旨在提供精确控制组件滚动位置和内容显示范围的接口规范。

### type_OnWillScroll_5more_0c6da2ba.md type_OnWillScroll_5more_0c6da2ba.md
这份API参考文档定义了Cangjie语言中用于处理滚动事件的回调函数类型。文档详细列出了五种核心类型：OnWillScrollCallBack、OnScrollCallBack、ScrollOnScrollCallback、OnScrollFrameBeginCallback和OnScrollEdgeCallback，分别对应滚动前、滚动中、帧开始及边缘触发的场景。关键内容包括各回调的参数签名（如偏移量Float64、状态ScrollState）及返回值类型（如ScrollResult、Unit）。这些定义帮助开发者实现自定义滚动逻辑和交互行为，适用于构建复杂UI界面的开发人员。
