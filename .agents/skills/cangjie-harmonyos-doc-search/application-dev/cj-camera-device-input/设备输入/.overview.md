# 设备输入

This directory focuses on camera device input management within the Cangjie programming language ecosystem, specifically utilizing the CameraKit framework. It comprehensively covers the essential workflows required for initializing camera streams, managing system permissions, and configuring input capabilities. Key topics include retrieving supported scene modes, setting up output profiles for preview and photography, and handling device access protocols. The documentation provides a detailed look at the prerequisites and implementation steps required to control camera hardware effectively. This resource is designed for application developers and software engineers building multimedia features who need a foundational understanding of camera input control, stream configuration, and error handling mechanisms to create robust camera applications.

## Detailed Description

### 开发步骤.md 开发步骤.md
This document serves as a step-by-step tutorial for developers implementing camera functionality using the CameraKit in the Cangjie programming language. It covers the essential workflow starting with importing required interfaces and creating a camera input stream via the CameraManager class. The guide details how to retrieve supported scene modes and obtain output capabilities, such as preview and photo profiles, based on specific modes. Key takeaways include the necessity of completing camera management beforehand and the use of specific API methods like createCameraInput and getSupportedOutputCapability. This guide targets application developers building multimedia features, providing code examples for error handling and stream configuration.

### 设备输入.md 设备输入.md
This document serves as a development guide for camera applications, specifically focusing on device input control. The main topics cover the prerequisite steps for applying for necessary permissions and the implementation of core camera functionalities. Key information highlights that developers must first secure permissions before they can call and control camera devices to perform basic operations such as previewing, taking photos, and recording videos. This guide is intended for software developers building camera features who need a foundational understanding of device input handling and access protocols.
