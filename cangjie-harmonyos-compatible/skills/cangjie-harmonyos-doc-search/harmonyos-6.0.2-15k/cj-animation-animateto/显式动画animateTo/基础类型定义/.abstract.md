This directory serves as a comprehensive repository for fundamental type definitions and API references specifically designed for the Cangjie programming language within the ArkUI framework. It primarily focuses on core classes that are critical for system performance tuning and the precise control of animation effects in user interfaces. The documentation covers essential structures such as `ExpectedFrameRateRange` for managing frame rates and `AnimateParam` for defining animation behaviors. These resources are indispensable for ArkUI developers using Cangjie who aim to optimize rendering performance and implement sophisticated visual interactions. The content is tailored for those working with API version 12 and above, providing the necessary technical details to configure robust application behaviors effectively.
