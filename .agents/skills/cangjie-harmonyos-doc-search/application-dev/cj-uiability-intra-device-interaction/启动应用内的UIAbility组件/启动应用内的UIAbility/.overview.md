# 启动应用内的UIAbility

This directory serves as a technical resource for HarmonyOS developers focusing on the lifecycle management of UIAbility components within a single application using the Cangjie language. It details the procedures for initiating specific abilities via the `startAbility` method, parameter transmission using `Want` objects, and the proper termination of instances. The content explores the integration of the AbilityKit framework within the Stage model, offering insights into handling lifecycle callbacks like `onCreate` and managing business exceptions during termination. Additionally, it covers configuration settings in `module.json5` to control task visibility. This guide is essential for developers building multi-page or multi-ability applications requiring robust navigation and state management.

## Detailed Description

### 启动应用内的UIAbility_1.md
This technical guide explains how to start a specific UIAbility from another within the same HarmonyOS application using the Cangjie language. It details the process of initiating the startup via startAbility, receiving parameters in lifecycle callbacks like onCreate, and terminating the instance using terminateSelf. The core mechanism involves configuring a Want object with bundle and ability names to pass custom parameters between components. This tutorial targets HarmonyOS developers working with the AbilityKit framework and Cangjie programming language to manage multi-ability interactions.

### 启动应用内的UIAbility_2.md
This document provides a code example demonstrating how to terminate a UIAbility instance within an application using the Cangjie language. It covers accessing the UIAbility context, implementing the terminateSelf() method, and handling potential business exceptions. Key information includes a note that terminating an ability retains its snapshot in the recent tasks list by default. Developers can disable this by setting the removeMissionAfterTerminate field to true in the module.json5 configuration file. This guide targets HarmonyOS application developers using the Stage model who need to manage application lifecycle and task visibility.
