# 组件属性

This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It covers essential text styling capabilities, including font attributes (weight, size, color), date and time formatting options, and text shadow effects. The documents provide detailed parameters, default values, and syntax rules for customizing UI elements. This resource is suitable for HarmonyOS application developers who need to fine-tune the visual appearance of text and time displays in their applications using Cangjie syntax.
