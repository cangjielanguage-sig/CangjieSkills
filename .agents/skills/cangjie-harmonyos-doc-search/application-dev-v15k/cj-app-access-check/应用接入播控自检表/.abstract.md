This directory serves as a comprehensive technical resource designed to assist developers and QA engineers in the proper integration of AVSession and broadcast control features within their applications. It provides a structured framework for verifying compliance with platform standards, with a specific focus on audio playback scenarios. The content clearly distinguishes between mandatory requirements for background or lock-screen playback and optional integration for foreground-only applications. Key topics include detailed AVSession specifications, playback control states, and compliance checklists tailored for various media categories such as Music, Video, Live streaming, and VoIP. This documentation is essential for ensuring a seamless user experience, maintaining functional audio behavior across different system states, and meeting strict platform compliance standards prior to application launch.
