# cj-common-event-subscription

本目录包含了Cangjie应用开发中关于公共事件订阅的核心文档资料。它详细阐述了如何在Cangjie应用运行时动态订阅公共事件，从而实现对特定事件通知及其参数的接收。内容覆盖了从场景介绍、接口说明到具体开发步骤的全流程指导，重点讲解了`createSubscriber`和`subscribe`等核心API的使用方法。此外，文档还深入探讨了订阅者对象的生命周期管理，旨在帮助开发者有效防止内存泄漏。对于需要在应用运行期间响应系统级或应用级公共事件（例如电量变化、屏幕状态切换等）的Cangjie语言开发者而言，这是一份极具参考价值的教程，并附带了从模块导入到回调函数实现的完整代码示例。
