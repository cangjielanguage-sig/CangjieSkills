# class_DeviceInfo

This directory contains API documentation for the `DeviceInfo` class in the Cangjie programming language, specifically designed for querying terminal device information. It covers static, read-only properties related to device identity, build metadata, operating system distribution, and hardware specifications. Key topics include version identifiers, bootloader details, and unique device identifiers. This resource is suitable for software developers and system integrators working with HarmonyOS or Cangjie applications who need to access system attributes like build hashes, OS types, and hardware profiles for debugging or feature adaptation.

### class_DeviceInfo_21more.md class_DeviceInfo_21more.md
This document serves as an API reference for the DeviceInfo class in the Cangjie programming language, designed to query terminal device information. It details a comprehensive list of static, read-only properties categorized into device identity, build metadata, operating system distribution details, and hardware specifications. Key takeaways include that all properties are read-only, primarily returning String or Int64 types, and require the SystemCapability.Startup.SystemInfo capability, with support starting from API version 12. This reference is intended for software developers needing to access specific system attributes like bootloader version, build hash, or distribution OS type within their applications.
