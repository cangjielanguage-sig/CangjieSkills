# cj-hilog-guidelines

This directory provides comprehensive guidelines for utilizing the HiLog interface specifically designed for Cangjie applications. It functions as an essential manual for developers aiming to implement robust logging mechanisms to facilitate debugging and runtime analysis. The documentation thoroughly covers the API interfaces available for five different log levels, details critical parameter definitions such as domain and tag, and outlines important system constraints including the 4096-byte limit. Furthermore, it offers a practical development example that illustrates how to integrate logging within a button click event and visualize the output using DevEco Studio. This resource is primarily suitable for Cangjie application developers who need to track application execution and monitor logic flow efficiently. By following these guidelines, developers can ensure their applications are maintainable and easier to debug.

To bridge the gap between theory and practice, the document includes a comprehensive development example.
