This directory serves as a comprehensive guide for using the Image component in the Cangjie programming language within the HarmonyOS ArkUI framework. It covers fundamental image display techniques, including loading local and network resources, handling vector graphics (SVG), and managing image loading events like success and failure callbacks. Additionally, it explores advanced customization through property configuration such as scaling, interpolation, and color filters. This resource is suitable for application developers seeking to enhance UI visual quality and implement robust image handling logic in their Cangjie-based applications.
