This directory contains API reference documentation for the HarmonyOS Bluetooth A2DP module, specifically designed for the Cangjie programming language. It covers the implementation of Advanced Audio Distribution Profile (A2DP) source functionality, enabling developers to manage Bluetooth audio streaming, device connections, and playback states. Key components include configuration classes for audio codecs (SBC, AAC, L2HC), enumerations for sample rates and channel modes, and the main `A2dpSourceProfile` class for handling connection events and audio transmission. This documentation is suitable for HarmonyOS developers using Cangjie who need to integrate high-quality wireless audio features into their applications.
