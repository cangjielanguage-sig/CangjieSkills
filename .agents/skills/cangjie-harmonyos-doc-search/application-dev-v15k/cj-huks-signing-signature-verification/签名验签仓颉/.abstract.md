This directory provides a comprehensive guide and practical examples for implementing digital signing and signature verification using the Cangjie programming language and the Universal Keystore Kit. It covers the complete lifecycle of cryptographic operations, including key generation, signing, verification, and deletion. The content supports various algorithms such as ECC, RSA, and SM2, with a focus on session-based workflows and hardware-backed security. It is suitable for Cangjie developers and security engineers looking to integrate robust cryptographic features and national cryptographic standards into their applications.
