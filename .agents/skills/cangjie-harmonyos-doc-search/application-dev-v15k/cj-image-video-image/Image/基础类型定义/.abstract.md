This directory provides API reference documentation for fundamental data structures and enumerations within the ArkUI framework for the Cangjie programming language. It covers essential classes for image handling, including error reporting (`CJImageError`), successful loading states (`CJImageComplete`), and color transformations (`ColorFilter`). Additionally, it details key enumerations for controlling image rendering behaviors like dynamic range and interpolation. These definitions are vital for developers building HarmonyOS applications who need to manage image display, error states, and visual effects programmatically.
