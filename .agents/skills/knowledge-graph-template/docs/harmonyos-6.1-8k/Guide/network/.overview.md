# network

This directory hosts resources for the Network Kit module, designed for HarmonyOS developers. It encompasses documentation for HTTP data requests, network connection management, and network quality assessment. The materials include both general integration guides and specific technical resources for the Cangjie programming language. Key topics include multi-network priority strategies, state subscriptions, and DNS resolution. This directory is ideal for developers seeking to implement robust network communication, requiring knowledge of necessary permissions and compliance standards.

## Detailed Description

### README_zh
This directory is the documentation root directory for the Network Kit module, primarily containing Chinese explanation files for the module. As the primary entry point for developers to access network services, the documentation in this directory is currently in the Beta feature stage, meaning functionality may still be iterating. In terms of content, it not only provides an introduction to Network Kit but also focuses on how to access the network via HTTP data requests and how to utilize network connection management functions to maintain network status. The documentation builds a clear modular structure, guiding developers to read specific technical details through links. This directory and its content are highly suitable for developers who need to integrate network functions, perform data transmission, or manage state in their applications; it is recommended that readers possess basic network knowledge.

### cj-http-request
This directory serves as a comprehensive technical resource for developers working with HTTP data requests within HarmonyOS applications, specifically utilizing the Cangjie (仓颉) programming language. It provides a detailed development guide that spans foundational concepts to advanced implementation strategies, ensuring developers can effectively handle data transmission over the web.

### cj-net-connection-manager
This directory serves as a comprehensive technical resource dedicated to managing network connections within HarmonyOS applications using the Cangjie programming language. It focuses extensively on the NetworkKit framework, providing developers with the necessary tools and guidelines to maintain stable and efficient network connectivity.

### cj-net-mgmt-overview
This directory provides a comprehensive overview document regarding network management (Network Kit), aimed at guiding developers on integrating network services. The content covers key technical points such as HTTP data requests, network connection management (including multi-network priority strategies for WiFi and cellular networks), network quality assessment, state subscription, and DNS resolution. The documentation specifically emphasizes compliance requirements, detailing the `ohos.permission.GET_NETWORK_INFO` and `ohos.permission.INTERNET` permissions that must be declared before using network functions. This resource is suitable for all developers who need to implement stable and efficient network communication in their applications, providing a functional index to facilitate development.
