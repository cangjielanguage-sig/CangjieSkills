# 观察变化和行为表现

This directory focuses on the mechanisms of state observation and reactive rendering within a UI framework, specifically targeting the Cangjie language and ArkUI applications. It covers how state changes are detected across various data types, how these changes trigger component updates, and the framework's behavior in optimizing rendering performance. Key topics include reactive rendering, state management, the `@State` decorator, and the distinction between observable and standard variable changes. This content is suitable for developers building user interfaces who need to understand the underlying reactivity system to optimize application performance and manage state effectively.

### 框架行为.md 框架行为.md

Key topics include the detection of state variable changes, querying dependent components, executing update methods, and the optimization of rendering performance through selective updates. The core concept is that the framework ensures on-demand updates by only re-rendering components that depend on the modified state variables, while ignoring unrelated UI descriptions to optimize performance. Intended for developers building user interfaces, this reference material helps understand the underlying rendering logic to optimize application performance and manage state effectively. ### 观察变化.md 观察变化.md
This technical guide explains how the `@State` decorator observes data changes across different data types in the Cangjie language. It covers primitives, structs, classes, arrays, and other collections. Key takeaways include that primitives are fully observable, while structs prohibit internal property modification. Classes require `@Observed` and `@Publish` macros to detect internal changes. Standard arrays only detect whole replacement, whereas `ObservedArray` and `ObservedArrayList` enable item-level and structural change observation. Other collections like HashSet behave similarly to standard arrays. This reference material targets developers implementing state management in ArkUI applications.

The key information emphasizes that only observable modifications trigger UI refreshes, distinguishing them from standard variable changes. Intended for developers working with declarative UI frameworks, this section clarifies the reactivity system to ensure efficient state management and rendering performance. Keywords: state variables, UI refresh, framework observation, reactivity, behavior performance.
