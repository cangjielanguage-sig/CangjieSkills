# cj-apis-i18n

This directory serves as a comprehensive repository for API reference documentation related to the `ohos.i18n` module, specifically tailored for the Cangjie programming language within the HarmonyOS development environment. The primary focus is on internationalization (I18n), a critical aspect of modern software development that ensures applications can adapt to different languages and regions without engineering changes. The documentation covers essential topics such as retrieving system language preferences, managing various calendar types—including Gregorian and Buddhist—and performing complex date and time manipulations. It details key components like the System class, CalendarType enumeration, and Calendar class. This resource is specifically suitable for software developers and engineers aiming to build globalized HarmonyOS applications that require robust handling of locale-specific settings, time zones, and precise date arithmetic.

### [1] ohosi18n国际化-I18n/

This directory contains API reference documentation for the `ohos.i18n` module in the Cangjie programming language, focusing on internationalization (I18n) capabilities for HarmonyOS applications. It covers system language preferences, calendar types (Gregorian, Buddhist, etc.), and complex date/time manipulations. Key components include the System class, CalendarType enumeration, and the Calendar class. This documentation is suitable for software developers building globalized applications who need to handle locale-specific settings, time zones, and date arithmetic. The reference material provides the structural definitions and method signatures required to integrate these internationalization features seamlessly into Cangjie-based projects.
