This directory focuses on resolving issues related to missing stack backtraces within the cj-fuzz framework. It covers technical solutions for capturing native signals from C code crashes and provides detailed case studies on debugging uncaught exceptions in the Cangjie runtime. Key topics include LLVM ASan linking strategies, signal handling, and the interaction between Cangjie stack traces and native stack traces involving `libcangjie-runtime.so`. This resource is suitable for developers and debugging engineers working with fuzzing tools, native code integration, and runtime stability analysis who need to debug signal-based failures effectively. The documents provide both the theoretical linking strategy and practical execution flow analysis to aid in comprehensive debugging. By understanding these mechanisms, users can better diagnose the root causes of crashes in complex hybrid environments involving both high-level language runtimes and native C libraries.
