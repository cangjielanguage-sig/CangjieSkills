# class_AppStorage

This directory contains API documentation for the AppStorage class within the ArkUI framework, specifically designed for Cangjie developers. It focuses on application state management, providing mechanisms for creating, retrieving, updating, and deleting state properties. The documentation covers various static methods for establishing one-way and two-way data bindings, managing property lifecycles, and synchronizing state across components. It is suitable for developers looking to implement robust state management solutions in their applications using the Cangjie language and ArkUI version 12 or higher.

## Detailed Description

### class_AppStorage_5more.md class_AppStorage_5more.md
This API documentation defines the AppStorage class, a central storage type for managing application state data within the ArkUI framework. It covers static methods for data manipulation, including prop for creating one-way property bindings, get for retrieving values, and clear or delete for removing properties. Key takeaways include the requirement that properties can only be deleted if they have no active subscribers, such as those linked via @StorageLink. The document provides detailed parameter descriptions, return types, and usage examples. It is intended for Cangjie developers implementing state management in their applications.

Each function entry includes syntax, parameters, return types, system capabilities, and usage examples. Key concepts involve state synchronization and optional return types for bindings. This technical reference targets ArkUI developers using version 12 or higher who need to programmatically interact with AppStorage.
