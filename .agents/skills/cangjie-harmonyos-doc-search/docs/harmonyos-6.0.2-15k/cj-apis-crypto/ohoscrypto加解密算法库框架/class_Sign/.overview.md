# class_Sign

This directory contains API reference documentation for the Cangjie `Sign` class and related functions within the CryptoFramework and CryptoArchitectureKit. It covers digital signature operations, including class instantiation, initialization, parameter configuration via `setSignSpec`, and data processing using `sign` and `update` methods. The documentation details the three-step signing process, handling of large data chunks, and specific constraints like algorithm limitations. It is suitable for Cangjie developers and software engineers implementing cryptographic security features who need to perform digital signatures using private keys and fine-tune signature settings.

## Detailed Description

### class_Sign_4more.md
This document provides API reference documentation for the Cangjie Sign class, which handles digital signature operations within the CryptoFramework. It details the class functionality, the read-only algName property, and methods for retrieving specifications (getSignSpec) and initializing with a private key (initialize). Key information includes the three-step signing process requiring instantiation via createSign, followed by mandatory initialization, optional update for long data, and a final sign call. Notably, the class does not support re-initialization; new keys require new object instances. This guide targets Cangjie developers implementing cryptographic security features who need to perform digital signatures using private keys.

### func_setSignSpecSignSpecIt_2more.md
This document serves as API reference documentation for the Cangjie programming language, detailing the setSignSpec function used to configure cryptographic signature parameters. It covers two overloaded function signatures that accept either an Int32 or Array<UInt8> value to specify parameter details. Key sections include parameter definitions, system capabilities, exception handling with specific error codes, and practical code examples demonstrating usage with RSA keys. The document is intended for developers working with the CryptoArchitectureKit who need to fine-tune signature settings beyond standard initialization. Keywords: Cangjie, API, Cryptography, Signature, setSignSpec, CryptoArchitectureKit, Error Codes.

### func_signDataBlob_2more.md
This API reference document details the usage of digital signature functions within the Cangjie CryptoArchitectureKit. It covers the `sign` function for generating signatures and the `update` function for appending data chunks, including their syntax, parameters, return values, and specific error codes. Key takeaways include that `sign` accepts an optional DataBlob and returns the signature result, while `update` facilitates multi-part data processing to optimize memory usage for large datasets. Important constraints note that `update` cannot be used in OnlySign mode or with DSA NoHash algorithms. This guide targets software developers implementing cryptographic security features, requiring knowledge of the Cangjie programming language and asymmetric cryptography concepts.
