This directory contains API reference documentation for the `AtomicInt32` class in the Cangjie programming language, designed to facilitate thread-safe operations on 32-bit integers. It covers essential concurrency primitives such as atomic arithmetic, bitwise manipulations, compare-and-swap (CAS), and memory loading/storing. A significant focus is placed on the distinction between current implementations using default memory ordering and deprecated versions that required explicit memory order arguments. This resource is suitable for developers working on concurrent systems who require low-level synchronization primitives and atomic data types to ensure data integrity in multi-threaded environments.
