# 基础类型定义

This directory contains fundamental type definitions and API references for configuring semi-modal pages and panels within the Cangjie ArkUI framework. It covers essential classes such as BindOptions, SheetOptions, and SheetTitleOptions, alongside enumerations like SheetType, SheetMode, and SheetSize. These definitions enable developers to manage visual styling, lifecycle events, dismissal behaviors, and interaction modes for sheet interfaces. Suitable for Cangjie developers and UI designers, this documentation provides the necessary building blocks for creating customizable, responsive, and interactive modal components in ArkUI applications.

### class_SheetTitleOptions_5more.md class_SheetTitleOptions_5more.md

### enum_SheetType.md enum_SheetType.md
This document serves as API reference documentation for the Cangjie programming language, specifically defining the SheetType enum used to configure semi-modal sheet styles within the ArkUI framework. The content details three specific enumeration values: BOTTOM, CENTER, and POPUP, providing functional descriptions for each. Key takeaways include the specific behaviors of each sheet type, such as the POPUP type following touch input but disabling swipe-to-close functionality. All values are available from system version 12. This reference is intended for UI developers building applications using the ArkUI framework who need to implement different modal presentation styles.
