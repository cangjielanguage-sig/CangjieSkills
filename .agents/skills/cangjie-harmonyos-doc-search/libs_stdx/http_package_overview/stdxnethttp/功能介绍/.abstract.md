This directory provides comprehensive documentation for a robust network communication package supporting HTTP/1.1, HTTP/2, and WebSocket protocols. It covers essential setup requirements, specifically OpenSSL 3 integration, and details the implementation of HTTP clients and servers with TLS/ALPN support. Additionally, it explains WebSocket protocol upgrades, frame handling, and connection management across different HTTP versions. Targeted at developers building real-time communication systems or high-performance network applications, these guides ensure proper environment configuration and effective utilization of the library's features.
