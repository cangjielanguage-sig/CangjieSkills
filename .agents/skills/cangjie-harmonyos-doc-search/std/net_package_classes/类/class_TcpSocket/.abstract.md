This directory contains comprehensive API reference documentation for the `TcpSocket` class within the Cangjie programming language. It covers the implementation of TCP client connections, detailing class constructors, socket configuration properties, and operational methods for data transmission and connection management. Key topics include socket options (keepAlive, noDelay), timeouts, buffer sizes, and platform-specific behaviors for Windows and Linux/macOS. The documentation is intended for developers implementing network communication who need to manage low-level socket states, data reading/writing, and connection lifecycle in Cangjie.
