This directory contains the development guide for the Cangjie ASSET system, specifically focusing on Scenario 2: protecting sensitive data requiring user authentication. It covers the secure handling of critical financial assets, such as passwords and bank card numbers, which are locked until identity verification (e.g., biometrics or lock screen passwords) is confirmed. The documentation details comprehensive workflows for querying asset existence, managing assets through addition, deletion, or updates, and retrieving plaintext data securely. This resource is designed for developers building secure financial applications who need to implement robust data protection mechanisms within the Cangjie ecosystem. It provides the necessary context and implementation links to ensure that sensitive information remains inaccessible without proper user authorization, thereby enhancing the security posture of financial applications. By following this guide, developers can ensure compliance with security standards and protect user data effectively.
