# 组件属性

This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It primarily focuses on the customization of TabBar and Tabs components, covering aspects such as animation settings, background effects, layout modes, and navigation behaviors. Developers can find detailed instructions on adjusting visual aesthetics, interaction logic, and structural alignment. The content is suitable for UI developers and HarmonyOS application builders who need precise control over component styling and functionality to create polished user interfaces.

### func_scrollableBool_2more.md func_scrollableBool_2more.md
