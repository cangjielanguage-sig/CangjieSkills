# cj-canvas-drawing-imagebitmap

This directory contains the technical documentation for the `cj-canvas-drawing-imagebitmap` module, specifically detailing the `ImageBitmap` class within the Cangjie ArkUI framework. The content is centered around the storage and management of canvas-rendered pixel data. It provides a thorough explanation of the class structure, with particular attention given to the constructor `init`, which requires an image source path for initialization. Furthermore, it documents the read-only properties `width` and `height`, which allow developers to retrieve image dimensions in viewport units. The documentation also specifies important metadata, such as the Beta status, the mandatory import of `kit.ArkUI`, and support starting from version 22. This resource is intended for Cangjie developers who are actively working with canvas graphics and need to programmatically manage image bitmaps and their properties.
