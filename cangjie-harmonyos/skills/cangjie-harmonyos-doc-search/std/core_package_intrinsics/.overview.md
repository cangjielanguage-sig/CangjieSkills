# core_package_intrinsics

The `core_package_intrinsics` directory acts as the foundational reference for the Cangjie programming language's intrinsic capabilities and core type system. Unlike standard libraries, intrinsics are deeply integrated into the compiler and runtime, providing the essential building blocks upon which all other Cangjie code is built. This directory specifically documents the comprehensive API for built-in types, covering everything from basic primitives like `Bool` and `Unit` to complex numeric systems. It includes detailed specifications for signed and unsigned integers (Int8 to Int64, UInt8 to UInt64) and floating-point numbers (Float16, Float32, Float64). Furthermore, it provides critical documentation for low-level operations, including types designed for C interoperability like `CPointer` and `CString`, as well as the `Rune` type for Unicode handling. This resource is indispensable for Cangjie developers, systems programmers, and anyone involved in language interoperability or performance-critical application development.

## Detailed Description

### 内置类型/

This directory provides comprehensive API documentation for the built-in types in the Cangjie programming language. It serves as the primary reference for understanding the behavior, constraints, and capabilities of the language's primitive type system. The documentation covers fundamental types such as `Bool` for boolean logic and `Unit` for singleton or void-like return values. It extensively details a wide range of numeric types, ensuring developers have the tools for precision control, including signed and unsigned integers (Int8 to Int64, UInt8 to UInt64) and floating-point numbers (Float16, Float32, Float64). Beyond standard data types, this section is crucial for systems programming as it documents types designed for C interoperability, such as `CPointer` and `CString`, which allow direct memory manipulation and interaction with native system calls. Additionally, it documents the `Rune` type for Unicode character representation, ensuring proper international text support. This resource is essential for Cangjie developers seeking to understand type behaviors, interface implementations, and low-level memory manipulation capabilities.
