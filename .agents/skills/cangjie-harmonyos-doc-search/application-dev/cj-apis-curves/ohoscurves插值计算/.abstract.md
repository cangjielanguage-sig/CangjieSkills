This directory provides comprehensive API reference documentation for the `ohos.curves` module and related classes within the ArkUI framework, specifically designed for the Cangjie programming language. It focuses on interpolation calculations essential for creating smooth, non-linear animations and transitions in HarmonyOS applications. Key topics include cubic Bezier curves, spring dynamics, custom easing behaviors, and the ICurve interface implementation. This resource is suitable for HarmonyOS developers and UI engineers looking to implement physics-based motion or precise timing control in their user interfaces using Cangjie.
