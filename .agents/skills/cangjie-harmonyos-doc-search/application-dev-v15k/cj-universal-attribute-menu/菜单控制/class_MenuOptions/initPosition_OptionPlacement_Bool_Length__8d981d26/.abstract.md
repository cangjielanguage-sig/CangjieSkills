This directory provides API reference documentation for a Cangjie language constructor designed to instantiate `MenuOptions` objects. It covers a wide range of configuration parameters, including spatial positioning, visual styling, arrow indicators, background effects, and lifecycle event callbacks. The documentation explains default values, offset directions, boundary adjustments, and transition animations. It is intended for software developers and UI engineers working within the Cangjie framework who need to customize the behavior, appearance, and layout of menus, popups, and context windows.
