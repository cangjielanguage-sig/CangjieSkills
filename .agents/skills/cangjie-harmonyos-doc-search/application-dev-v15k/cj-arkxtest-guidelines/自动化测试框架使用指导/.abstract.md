This directory provides a comprehensive guide for the Cangjie Automated Testing Framework within the HarmonyOS/OpenHarmony ecosystem. It covers the architecture of the Cangjie Unit Test Framework and the UiTest framework, detailing their implementation principles and runtime environments. The content includes resources for writing and executing test scripts using the Cangjie language, performing UI automation via shell commands, and troubleshooting common execution errors. Designed for software developers and QA engineers, this documentation facilitates the setup of robust testing workflows, environment configuration, and effective debugging of UI automation scripts.
