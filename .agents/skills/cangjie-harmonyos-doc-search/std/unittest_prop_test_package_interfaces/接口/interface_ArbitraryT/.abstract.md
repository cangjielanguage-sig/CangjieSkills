This directory contains API documentation for the `Arbitrary` interface within the Cangjie property-based testing framework. It details how various data types implement this interface to enable automatic random value generation for testing. The content covers fundamental numeric types, strings, collections, and core data structures. Key concepts include the `RandomSource` parameter, `Generator` return types, and interface extensions. This documentation is suitable for software developers and QA engineers working with the `unittest_prop_test` package who need to generate random test data or implement custom property-based tests in Cangjie.
