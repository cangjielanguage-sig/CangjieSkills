This directory provides comprehensive API reference documentation for the `StartOptions` class within the Cangjie programming language. It is designed to assist developers in specifying window modes, startup parameters, and display configurations for target Abilities. The documentation covers essential public properties such as windowMode, displayId, and withAnimation, while also detailing version 19 enhancements including window geometry, processMode, and startupVisibility. Suitable for application developers and system engineers, this guide offers the necessary technical specifications to manage window behavior, process attributes, and launch settings effectively within the Ability runtime core.
