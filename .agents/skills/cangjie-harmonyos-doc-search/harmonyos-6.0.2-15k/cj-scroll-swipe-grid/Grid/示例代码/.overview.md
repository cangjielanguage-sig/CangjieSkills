# 示例代码

This directory contains a collection of practical code examples demonstrating advanced Grid component implementations in the Cangjie programming language for HarmonyOS development. It covers essential features such as scrollable grids with event handling, drag-and-drop reordering, adaptive column layouts, and nested scrolling scenarios. Additionally, it includes tutorials on visual customization like edge fading and height alignment. These examples are suitable for developers looking to master complex UI layouts and interactive behaviors using the ArkUI framework.

## Detailed Description

### 示例1可滚动Grid和滚动事件.md 示例1可滚动Grid和滚动事件.md
This document provides a practical code example demonstrating the implementation of a scrollable Grid component with comprehensive event handling in the Cangjie programming language. The content focuses on the `EntryView` class, specifically the `build` method where the `Grid` is configured. It covers property settings like `columnsTemplate`, `edgeEffect`, and `scrollBar`, alongside event callbacks such as `onScrollStart`, `onScrollStop`, and `onReachEnd`. The example illustrates how to bind a `Scroller` object for programmatic control (e.g., paging) and how to track scroll positions and indices using state variables and logging. This tutorial is intended for developers using the HarmonyOS/OpenHarmony Cangjie framework who need to implement complex list or grid layouts with interactive scrolling features.

### 示例3Grid拖拽场景.md 示例3Grid拖拽场景.md
This document serves as a practical tutorial for implementing drag-and-drop functionality within a Grid component using the Cangjie language. It details the necessary steps to enable editing, customize the drag visual, and handle data reordering. Key topics include setting the editMode property to true, utilizing the onItemDragStart callback to define the drag image, and implementing the onItemDrop callback to swap array elements based on start and insert indices. The provided code example demonstrates an ObservedArrayList data source and a custom changeIndex function to manage state updates. This guide is intended for developers building interactive UIs for HarmonyOS applications, specifically those looking to enhance user experience with sortable grid layouts.

### 示例4自适应Grid_2more.md 示例4自适应Grid_2more.md
This document provides code examples demonstrating advanced Grid component usage in Cangjie for HarmonyOS development. It covers two main scenarios: adaptive layout configuration and interactive gesture control. The first example illustrates how to use layoutDirection, maxCount, minCount, and cellLength to create a responsive grid without fixed templates. The second example demonstrates dynamic column adjustment by implementing a pinch gesture to modify the columnsTemplate and persisting the state using AppStorage. Key takeaways include understanding adaptive layout constraints and handling user gestures to update UI properties dynamically. This tutorial is intended for developers with prior knowledge of Cangjie syntax and ArkUI components who wish to build flexible and interactive grid interfaces.

### 示例6设置自适应列数.md 示例6设置自适应列数.md
This document serves as a practical code example demonstrating how to implement adaptive column layouts within a Grid component using the Cangjie language. It specifically illustrates the usage of the columnsTemplate property with three distinct keywords: auto-fill, auto-fit, and auto-stretch. The code highlights the behavioral differences between these modes, explaining how auto-fill calculates columns based on width, while auto-fit and auto-stretch distribute remaining space to columns and gaps respectively. This tutorial is designed for developers seeking to master responsive grid layouts in HarmonyOS application development.

### 示例7以当前行最高的GridItem的高度为其他GridItem的高度.md 示例7以当前行最高的GridItem的高度为其他GridItem的高度.md
This document provides a code example demonstrating how to synchronize the heights of GridItems within a row using the alignItems property. It covers the setup of a two-column Grid containing variable-height content and the implementation of the GridItemAlignment.STRETCH attribute. The key takeaway is that setting alignItems to STRETCH forces smaller GridItems to expand and match the height of the tallest GridItem in the current row, provided the items do not have a fixed height. This tutorial targets developers using the Cangjie language who need to create uniform grid layouts with dynamic content.

### 示例8设置边缘渐隐.md 示例8设置边缘渐隐.md
This document serves as a code tutorial demonstrating how to implement an edge fading visual effect within a Grid component using the Cangjie programming language. It covers the implementation of the fadingEdge property, specifically within a Grid layout that utilizes a Scroller and nested ForEach loops to generate content. The core takeaway is the syntax for enabling the effect: .fadingEdge(true, FadingEdgeOptions(fadingEdgeLength: 80.vp)). This allows developers to visually indicate scrollable content by fading the edges of the container. Targeted at HarmonyOS developers using Cangjie, this example is suitable for those looking to enhance UI feedback in scrollable list or grid views.

### 示例2Grid嵌套滚动/
This directory provides a comprehensive collection of code examples focused on implementing and managing nested scrolling behaviors in Grid components within HarmonyOS applications. It addresses complex scenarios where a parent List and a child Grid must coordinate their scroll interactions seamlessly. The directory includes two distinct approaches: one utilizing the Cangjie programming language to handle low-level event interception and scroll logic, and another using ArkTS to implement user interface enhancements such as a "Back to Top" button. Key technical concepts covered include nestedScroll options, onScrollFrameBegin callbacks, touch event handling, scroller management, and UI styling. These resources are specifically designed for HarmonyOS developers who need to create sophisticated, responsive layouts with smooth, coordinated scrolling and intuitive navigation controls.
