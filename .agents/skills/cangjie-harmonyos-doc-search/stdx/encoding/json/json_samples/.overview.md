# json_samples

This directory contains a comprehensive collection of code samples and tutorials focused on JSON handling within the Cangjie programming language. It covers essential topics such as parsing, serialization, and the manipulation of complex JSON data structures using the `stdx.encoding.json` library. The content ranges from basic string-to-object conversions to advanced handling of nested arrays and custom object serialization. It is suitable for Cangjie developers looking to master JSON data interaction, understand serialization interfaces, and efficiently manage data formats in their applications.

## Detailed Description

### json_array_sample
This directory focuses on the practical application of `JsonArray` within the Cangjie programming language, aiming to help developers master the core skills required to construct complex JSON data structures. The content comprehensively covers the complete workflow, from creating basic `JsonValue` objects and building `ArrayList` instances to handling nested `JsonObject` and `JsonArray` structures. The documentation provides an in-depth explanation of the data serialization process, with a specific emphasis on comparing the output differences between the `toString()` and `toJsonString()` methods. By providing concrete examples that handle null values, booleans, numbers, strings, and nested structures, this tutorial serves as a comprehensive guide for developers.

### json_value_sample
This directory primarily demonstrates how to efficiently implement the mutual conversion between `JsonValue` objects and `String` types in the Cangjie programming language. The content highlights the use of the `stdx.encoding.json` standard library extension for JSON data parsing and serialization operations. Specifically, it covers how to parse JSON-formatted strings into in-memory objects and how to convert those objects back into either compact or formatted string representations. The example details the specific usage and output differences of core methods such as `JsonValue.fromStr`, `toString`, and `toJsonString`, helping developers understand the nuances of different serialization approaches.

### to_json_sample
This directory showcases the implementation schemes for JSON data serialization and deserialization in the Cangjie language. By implementing the Serializable interface, it details the bidirectional conversion process between custom types (such as `Person` and `Location` classes) and JSON strings. Core topics include the construction of `DataModelStruct`, the data flow involved in `JsonValue.fromStr`, pattern matching processing, and techniques for handling nested objects and `Option` types. This document is highly suitable for Cangjie developers, particularly those who need to handle JSON data interaction scenarios in their projects.
