This directory contains API reference documentation for the `Calendar` class within the Cangjie programming language's LocalizationKit. It focuses on internationalization (I18n) capabilities, enabling developers to perform complex date and time manipulations, arithmetic operations, and locale-specific configurations. The documentation covers methods for retrieving calendar attributes, setting time zones, and managing date fields like year, month, and day. It is suitable for software developers building globalized applications who need precise control over calendar behavior, time zone handling, and date calculations in their Cangjie projects.
