# 拆包工具信息字段

This directory contains technical reference documentation for data structures used in HarmonyOS and OpenHarmony application unpacking tools. It covers the schema definitions for key components such as AppInfo, AbilityInfo, HapInfo, and various configuration structures like permissions, forms, and distribution filters. The documents detail the attributes, data types, and specific rules for both FA (Feature Ability) and Stage models. This resource is essential for software developers, system integrators, and tool engineers who need to parse application bundles, configure manifests, or understand the internal metadata of HAP packages.

## Detailed Description

### AbilityFormInfo结构体信息.md AbilityFormInfo结构体信息.md
This document serves as a technical reference defining the AbilityFormInfo structure used to configure application forms or cards. It covers identification, update mechanisms (refresh times), visual properties (dimensions, color modes), and provider configuration rules for FA and Stage models.

### AbilityInfo结构体信息.md AbilityInfo结构体信息.md
This document details the `AbilityInfo` schema for application component configuration. It includes fields for identification, resources, permissions, and advanced features like Picture-in-Picture mode, distinguishing between Stage and FA models.

### AppInfo结构体信息.md AppInfo结构体信息.md
This document describes the `AppInfo` structure for application configuration, covering identity, versioning, UI resources, and build settings. It includes definitions for bundle types like atomicService and Stage model specific fields.

### CommonEvent结构体信息_6more.md CommonEvent结构体信息_6more.md
This document outlines schemas for `CommonEvent`, `DependencyItem`, `ModuleAtomicService`, and others. It focuses on static subscriber configuration, device settings, and custom permissions within the Stage model framework.

### DefinePermission结构体信息_5more.md DefinePermission结构体信息_5more.md
This document defines structures for `DefinePermission`, `DefPermissionsGroups`, `FormInfo`, and others. It covers permission granting modes, distributed scene support, localized descriptions, and window design widths.

### Distro结构体信息_7more.md Distro结构体信息_7more.md
This document covers `Distro`, `MetaData`, `ReqPermission`, and `UsedScene` structures. It details module installation behaviors, metadata handling differences, and permission request scenarios for HarmonyOS/OpenHarmony.

### ExtensionAbilityInfo结构体信息_3more.md ExtensionAbilityInfo结构体信息_3more.md

### HapInfo结构体信息.md HapInfo结构体信息.md
This document defines the `HapInfo` class representing HAP metadata. It distinguishes between FA-specific and Stage-specific attributes, such as UI syntax, entry points, and extension abilities.

### IntentInfo结构体信息_7more.md IntentInfo结构体信息_7more.md
