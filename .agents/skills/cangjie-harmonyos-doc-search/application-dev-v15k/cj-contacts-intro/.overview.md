# cj-contacts-intro

This directory serves as a comprehensive introductory resource for the Contacts Kit on HarmonyOS, specifically tailored for developers utilizing the Cangjie programming language. It acts as a foundational guide designed to assist developers in integrating robust contact management features into their HarmonyOS applications. The content thoroughly covers the kit's core capabilities, clearly distinguishing between the universally accessible Picker interface and the restricted contact management functions (Create, Read, Update, Delete). Key technical topics include module imports, UIAbilityContext acquisition, API invocation, and the critical security permissions required for direct data manipulation, including the necessary steps for ACL application. This documentation is essential for HarmonyOS application developers who need to implement secure contact selection or management functionalities, ensuring they fully understand both the technical implementation details and the security implications of accessing user contact data.

## Detailed Description

### Contacts_Kit开发概述/

This directory provides a comprehensive development overview for the Contacts Kit on HarmonyOS, designed to assist developers in integrating robust contact management features into their applications. It serves as a critical resource for navigating the complexities of contact data handling within the HarmonyOS environment.

The documentation covers the kit's core capabilities, specifically distinguishing between the universally accessible Picker interface and the restricted contact management functions (CRUD). It clarifies the architectural differences between these two approaches, helping developers choose the right method for their specific use case.

Key areas covered include:
*   **Picker Interface:** Universal access for selecting contacts without complex permissions.
*   **CRUD Operations:** Restricted functions for creating, reading, updating, and deleting contact data directly.
*   **Cangjie Implementation:** Practical code examples for module imports, UIAbilityContext acquisition, and API invocation.
*   **Security & Permissions:** Detailed guidance on ACL applications and the specific permissions required for data manipulation.

It targets HarmonyOS application developers looking to implement contact selection or management, ensuring they understand the security implications and technical requirements for accessing user contact data.
