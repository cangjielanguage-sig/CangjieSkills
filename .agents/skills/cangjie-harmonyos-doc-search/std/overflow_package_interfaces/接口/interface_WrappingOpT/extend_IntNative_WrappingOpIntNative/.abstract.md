This directory provides comprehensive API documentation for the `WrappingOp` interface implementation specifically tailored for the `IntNative` type within the Cangjie programming language. It focuses on arithmetic and bitwise operations designed to handle integer overflow through a high-bit truncation strategy, ensuring results wrap around predictably rather than causing runtime errors. Key topics include standard arithmetic functions like addition, subtraction, multiplication, and division, alongside bitwise manipulations such as shifting. This resource is essential for Cangjie developers engaged in low-level systems programming or performance-critical tasks where deterministic overflow behavior is necessary.
