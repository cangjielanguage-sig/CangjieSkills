This directory focuses on component sizing and layout configuration within the Cangjie ArkUI framework. It provides comprehensive API references for setting dimensions (width, height), spacing (margin, padding), and layout constraints (constraintSize, layoutWeight). Developers can learn how to control component boundaries, manage overflow, and distribute space proportionally within parent containers like Row or Column. The documentation includes detailed parameter definitions, logic tables for constraint interactions, and practical code examples demonstrating visual layout mechanics. It is suitable for software developers and UI engineers building responsive HarmonyOS applications using the Cangjie language who need precise control over layout mechanics and component sizing behavior.
