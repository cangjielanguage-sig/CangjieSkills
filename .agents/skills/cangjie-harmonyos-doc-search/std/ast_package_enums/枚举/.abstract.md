This directory contains comprehensive documentation for the enumeration types that form the backbone of the Cangjie programming language's compiler infrastructure. It covers essential data structures used for diagnostic reporting, abstract syntax tree (AST) construction, and lexical analysis. The content details specific enums such as `DiagReportLevel` for error handling, `ImportKind` for module management, and the extensive `TokenKind` list for parsing syntax. These definitions are critical for understanding how the language represents source code internally, categorizes errors, and processes imports. This documentation is primarily intended for compiler developers, language tool implementers, and engineers working on static analysis tools or IDE integrations who require precise structural definitions and behavioral specifications of Cangjie's core language constructs.
