This directory contains essential documentation for the `cj-universal-attribute-touchtestcontrol` module, designed for ArkUI developers utilizing the Cangjie language. It focuses on the `hitTestBehavior` attribute, a critical tool for configuring touch test types and managing how user interactions are processed within the framework. The content provides a thorough API reference, including function definitions, system capabilities, and parameter details. It elucidates the lifecycle of touch events, from collection to distribution, with a specific focus on the `HitTestMode` enum. Furthermore, it addresses complex scenarios such as handling overlapping touch areas in Stack components by utilizing modes like Block and Transparent. This resource is particularly suitable for developers aiming to implement precise control over event dispatching and optimize touch interactions in their ArkUI applications.
