## Detailed Description

### cj-basic-syntax-overview.md cj-basic-syntax-overview.md
本文档通过具体示例介绍了仓颉语言的基本语法组成，旨在帮助开发者理解其核心概念和结构。主要涵盖宏修饰符、声明式UI描述、自定义组件、系统组件、属性与事件方法，以及@Builder等扩展语法范式。重点阐述了宏（如@Component、@State）的特殊含义、build()方法的声明式UI构建方式，以及组件通过链式调用配置属性和响应事件的机制。适用于ArkUI框架下的仓颉语言初学者，作为入门指南了解语言基础构成。
