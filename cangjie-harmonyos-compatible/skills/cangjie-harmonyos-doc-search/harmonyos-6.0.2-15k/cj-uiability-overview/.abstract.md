This directory offers a deep dive into the UIAbility component, a core element for Cangjie developers building modern applications. It explains UIAbility as a system scheduling unit responsible for managing user interfaces, emphasizing design philosophies that facilitate cross-device migration and multi-window interactions. The content explores critical architectural decisions, such as choosing between single-instance setups for optimal resource efficiency and multiple-instance configurations for superior multitasking performance. Additionally, it outlines the essential steps for component declaration and registration, including specific directives for `module.json5`. This resource is tailored for developers who need to effectively manage component lifecycles, control task visibility, and configure windows to create robust, responsive user experiences in the Cangjie ecosystem.
