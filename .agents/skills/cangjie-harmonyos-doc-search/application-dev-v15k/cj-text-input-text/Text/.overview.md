# Text

This directory provides comprehensive documentation for the Text component within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers essential aspects of text rendering, including component initialization, event handling, property configuration, and fundamental type definitions. The content ranges from basic API references to advanced code examples for styling and interaction. Designed for UI developers and software engineers building HarmonyOS applications, this resource offers the necessary tools to implement rich text interfaces, manage user interactions, and customize visual effects programmatically.

## Detailed Description

#### Text_4more.md Text_4more.md
This document provides API reference documentation for the Text component within the ArkUI framework, designed for the Cangjie programming language. It outlines how to display text segments and supports subcomponents like Span, ImageSpan, and SymbolSpan. The main sections cover three distinct initialization methods: using AppResource for localized text, using a String, or using a builder function for subcomponents. Key information includes the behavior where string content is overridden by Span subcomponents and that the component supports all universal attributes and events. This guide targets UI developers seeking to implement text rendering in their applications, requiring knowledge of ArkUI and Cangjie syntax.

#### 组件事件.md 组件事件.md
This document serves as an API reference for handling text-related component events within the ArkUI framework using the Cangjie language. It details two specific event handlers: onCopy, which triggers when text is copied to the clipboard, and onTextSelectionChange, which fires when text selection boundaries change. Key information includes the function signatures, required callback parameters such as the copied string or selection coordinates, and system requirements starting from version 19. This technical reference is intended for software developers implementing text interaction features in their applications.
