# 拉起方应用实现应用跳转

This directory serves as a comprehensive resource for developers working on the HarmonyOS platform, specifically focusing on the implementation of application jumps initiated by a calling application. It details the technical processes required to enable seamless navigation between different applications, leveraging the Cangjie programming language and the ArkUI framework. The content covers critical scenarios such as intercepting DeepLinks within Web components to trigger native app transitions and utilizing standard system APIs like `openLink` and `startAbility` for direct cross-application launching. This guide is highly suitable for HarmonyOS developers aiming to enhance their applications with robust web-to-native integration and implicit intent matching capabilities.

## Detailed Description

The following files provide in-depth technical instructions and code examples for the specific implementation methods mentioned above.

### 使用Web组件实现应用跳转.md 使用Web组件实现应用跳转.md
This technical guide demonstrates how to implement application navigation from a Web component using DeepLink interception. The document covers the Cangjie backend implementation utilizing the `onLoadIntercept` callback alongside the corresponding HTML frontend code. Key information includes the logic for intercepting specific URL requests, using `UIAbilityContext.openLink` to launch external applications, and returning true to prevent default webview loading. This tutorial targets HarmonyOS developers using the Cangjie language and ArkUI framework who need to integrate web-to-native navigation capabilities.

### 拉起方应用实现应用跳转_3more.md 拉起方应用实现应用跳转_3more.md
This technical guide explains how to implement application jumps from a calling application using specific HarmonyOS APIs. It covers two primary implementation methods: using the `openLink()` interface and the `startAbility()` interface. Key information includes configuring `OpenLinkOptions` with `appLinkingOnly` set to false for `openLink`, and utilizing implicit Want matching with a URI for `startAbility`. Both methods require obtaining the `UIAbilityContext`. The document provides Cangjie code examples for each approach. It is intended for HarmonyOS developers seeking to integrate cross-application navigation capabilities into their applications.
