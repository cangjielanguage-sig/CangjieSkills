# cj-telephony-sms

This directory serves as a comprehensive technical hub for the `cj-telephony-sms` module, specifically designed to facilitate the integration and management of SMS (Short Message Service) functionalities within the HarmonyOS operating system. It acts as a vital guide for developers aiming to embed sophisticated communication capabilities into their software, spanning both native mobile applications and web-based interfaces. The documentation delves into the technical intricacies of SMS, covering essential protocols, data encoding variations such as 7-bit, 8-bit, and UCS-2, and the system constraints that govern message transmission. Beyond basic messaging, it provides in-depth instructions on invoking the native SMS editing interface via URI schemes and the `startAbility` method. It also addresses advanced technical requirements, including PDU (Protocol Data Unit) handling, SIM slot management for dual-SIM devices, and the specific permissions needed to access telephony features securely. This resource is indispensable for developers who need to ensure their apps comply with system standards while delivering reliable and seamless user communication experiences.

## Detailed Description

### 短信服务/
This directory provides comprehensive technical documentation for integrating SMS (Short Message Service) functionality into HarmonyOS applications and web environments. It serves as a complete reference for developers needing to understand the full lifecycle of SMS implementation on the platform. The documentation covers essential concepts such as SMS protocols, encoding types (7-bit, 8-bit, UCS-2), and system constraints that developers must navigate to ensure compatibility across different devices and regions.

The guides detail various methods to launch the native SMS editing interface, providing clear instructions on utilizing URI schemes for web pages and the `startAbility` interface for in-app navigation. Key technical topics include PDU handling, which allows for the management of raw message data, and SIM slot management, which is critical for devices with multiple SIM cards. Additionally, the documentation outlines specific permission requirements necessary for the application to function correctly within the HarmonyOS security model. This resource is suitable for developers seeking to implement seamless communication features, navigate system restrictions, and understand the underlying architecture of SMS services on the HarmonyOS platform.
