This directory provides a comprehensive guide for implementing runtime user authorization in HarmonyOS applications using the Cangjie language. It covers essential procedures for declaring sensitive permissions, triggering dynamic authorization dialogs, and verifying access tokens. Key topics include using core APIs like `requestPermissionsFromUser` and `checkAccessToken`, handling system constraints, and ensuring compliance with privacy principles. This resource is specifically designed for application developers who need to securely integrate system capabilities such as location services or camera access while adhering to strict system security guidelines.
