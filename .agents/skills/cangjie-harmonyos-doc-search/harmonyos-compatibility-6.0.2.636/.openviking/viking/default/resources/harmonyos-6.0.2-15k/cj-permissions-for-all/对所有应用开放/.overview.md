# 对所有应用开放

This directory provides comprehensive documentation for permissions available to all applications within the HarmonyOS development environment. It encompasses the general workflow for applying for permissions, detailed lists of user-granted permissions involving sensitive data, and system-granted permissions for hardware and network access. Key topics include runtime permission requests, access control lists (ACL), protection levels, and security attributes. This resource is specifically designed for application developers who need to implement secure access to device features, ensuring compliance with privacy standards and optimizing the development process for permission handling. It serves as a central hub for understanding both user and system authorization mechanisms.

## Detailed Description

### user_grant用户授权权限列表.md user_grant用户授权权限列表.md
This reference document lists system permissions requiring user_grant authorization for application development. It details specific permissions such as Bluetooth, Camera, Location, Microphone, and Media access. Each entry defines the permission's function, level (normal), and ACL status. It highlights dependency rules, noting that precise location access requires prior approval for approximate location. Targeted at developers needing to implement privacy-sensitive features and request runtime permissions correctly.

### 对所有应用开放.md 对所有应用开放.md
This document serves as an introductory guide for developers regarding permissions available to all applications, aiming to optimize the permission application process. It primarily covers the prerequisite steps of understanding the general permission workflow before analyzing specific permission field descriptions. The key takeaway is the recommendation to master the basic application workflow first, which enables developers to accurately determine if their app qualifies for target permissions and thereby improves development efficiency. The target audience is application developers seeking to request permissions, who are expected to combine general workflow knowledge with specific field details.

### system_grant系统授权权限列表/
This directory serves as a comprehensive repository for HarmonyOS system_grant permission documentation. It provides detailed technical references for specific permissions required to access system features such as audio settings, hardware components (Bluetooth, NFC), and network operations. The content covers security attributes, protection levels (normal, system_basic, system_core), and ACL enablement status. This collection is essential for HarmonyOS developers seeking to correctly declare permissions in application manifests and understand the access control constraints necessary for secure app development.
