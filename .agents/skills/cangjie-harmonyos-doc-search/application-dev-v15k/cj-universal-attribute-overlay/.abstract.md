This directory contains API reference documentation for the Cangjie ArkUI framework, specifically focusing on the universal attribute overlay functionality. It details how to add mask text overlays to UI components, covering function signatures, parameters like title and alignment, and the ContentOffset class for coordinate adjustments. The documentation includes system capabilities, version 12 compatibility, and code examples for implementing floating text layers. This resource is suitable for Cangjie developers looking to enhance application interfaces with dynamic text overlays and precise positioning controls. It serves as a technical guide for mastering the overlay attribute within the Cangjie development environment, ensuring developers can effectively utilize these features in their projects to create rich, interactive user experiences.
