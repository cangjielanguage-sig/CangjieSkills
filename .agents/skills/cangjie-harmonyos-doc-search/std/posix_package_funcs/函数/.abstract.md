This directory contains API reference documentation for a comprehensive set of POSIX-style system functions in the Cangjie programming language. It covers low-level operations including file manipulation (access, read, write, open), process management (getpid, kill, nice), and system information retrieval. A critical aspect of this collection is that every function listed is explicitly marked as deprecated and scheduled for removal in future versions. This documentation is suitable for Cangjie developers maintaining legacy code, understanding low-level system interfaces, or migrating existing projects to newer, non-deprecated APIs.
