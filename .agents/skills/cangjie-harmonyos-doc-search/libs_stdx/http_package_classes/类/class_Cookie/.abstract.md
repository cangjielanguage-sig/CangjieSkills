This directory contains comprehensive API reference documentation for the `Cookie` class within the Cangjie HTTP package. It focuses on stateful session management via HTTP cookies, covering object initialization, attribute manipulation, and string serialization for server headers. The documentation adheres to RFC 6265 standards and details constructors, properties, and conversion functions. It is suitable for Cangjie developers and engineers building server-side logic or HTTP clients who need to implement compliant cookie handling, manage security settings, and generate valid Set-Cookie headers. The resources provided ensure precise implementation of protocol-specific exceptions and validation rules.
