This directory contains comprehensive API reference documentation for the Cangjie `Icons` class, a critical component designed to manage icon types for sidebar control buttons within ArkUI applications. The documentation covers a wide array of constructor overloads that handle various combinations of `String` and `AppResource` types for shown, hidden, and switching states. Key topics include initialization methods, mandatory versus optional parameter requirements, and system resource fallback mechanisms. This documentation is primarily suitable for ArkUI developers working with the Cangjie language who need to implement dynamic UI state changes and manage icon resources effectively in version 19 environments. It provides the necessary technical details to ensure robust icon handling, error management, and visual consistency in graphical user interfaces, ensuring that developers can handle resource loading failures gracefully and maintain a seamless user experience.
