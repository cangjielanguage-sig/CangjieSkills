This directory contains API reference documentation for configuring the List component within the ArkUI framework using the Cangjie language. It covers a comprehensive range of properties and methods designed to control list layout, scrolling behavior, visual effects, and performance optimization. Key topics include multi-column layouts, edge effects, sticky headers, scroll interactions, and animation configurations. These technical documents are intended for software developers and UI engineers seeking to implement dynamic, high-performance list interfaces in their applications using Cangjie syntax.
