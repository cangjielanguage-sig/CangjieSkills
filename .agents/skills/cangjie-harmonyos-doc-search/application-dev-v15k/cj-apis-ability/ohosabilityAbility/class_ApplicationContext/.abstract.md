This directory contains API reference documentation for the Cangjie language's `ApplicationContext` class, a core component for managing application-level context within the HarmonyOS ecosystem. It covers essential functionalities including application lifecycle management, event listener registration for system and ability state changes, and runtime configuration settings like language and font scaling. The documentation is intended for software developers building applications using the Cangjie framework who need to handle application data, process termination, reactive behaviors, and system-level UI adjustments programmatically.
