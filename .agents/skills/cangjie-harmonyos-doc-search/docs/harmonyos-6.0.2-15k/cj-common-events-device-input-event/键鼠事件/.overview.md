# 键鼠事件

This directory provides a comprehensive technical overview of input handling mechanisms, specifically focusing on keyboard and mouse events within the HarmonyOS and Cangjie development ecosystems. It establishes the foundational terminology for input events as signals from external peripherals and offers practical implementation guides for capturing and processing these interactions. The content ranges from basic definitions to advanced event propagation, focus management, and hover effects. Designed for application developers and UI engineers, this resource is essential for creating responsive, user-friendly interfaces that robustly handle user inputs across various devices.

This directory serves as a central hub for understanding and implementing keyboard input handling within HarmonyOS applications. It provides essential resources for developers looking to capture, process, and respond to user interactions triggered by physical or virtual keyboards. By covering both ArkUI (ArkTS) and Cangjie frameworks, it ensures broad compatibility for modern HarmonyOS development. This documentation is specifically suitable for application developers and system engineers who aim to build responsive, user-friendly interfaces with sophisticated input handling capabilities and robust event-driven logic.

#### 鼠标事件/
This directory covers mouse interaction handling within the Cangjie UI framework (ArkUI). It includes documentation for configuring hover animations, handling specific mouse events like clicks and coordinates, and understanding the internal logic where mouse events are converted to touch events for unified handling. Key topics include `hoverEffect`, `onMouse`, and `onHover`. It is suitable for UI developers and application engineers building cross-device interfaces that require responsive mouse and touchpad support.
