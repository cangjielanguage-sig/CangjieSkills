This directory provides comprehensive API reference documentation for the `var_confirm` component within the Cangjie programming language and the ArkUI framework. It focuses on the implementation, initialization, and configuration of alert dialogs, specifically those featuring confirmation buttons. The content covers essential constructors, button property customization (such as text, color, and callbacks), and advanced dialog styling including background blur, borders, and alignment. It is intended for software developers and UI engineers building interactive applications that require robust user confirmation mechanisms, warning popups, or modal interfaces.
