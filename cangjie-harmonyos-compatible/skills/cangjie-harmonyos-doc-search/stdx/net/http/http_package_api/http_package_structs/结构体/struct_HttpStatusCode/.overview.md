# struct_HttpStatusCode

本目录包含Cangjie语言中关于HTTP状态码的API参考文档，详细定义了用于网络通信的一系列静态常量。内容涵盖了从1xx信息响应到5xx服务器错误的标准状态码，包括200 OK、404 Not Found及500 Internal Server Error等关键定义。所有常量均为UInt16类型，基于RFC 9110标准，旨在帮助开发者在网络编程中准确标识和处理HTTP请求与响应状态。适用于使用Cangjie进行网络应用开发及需要实现HTTP协议解析的程序员。
