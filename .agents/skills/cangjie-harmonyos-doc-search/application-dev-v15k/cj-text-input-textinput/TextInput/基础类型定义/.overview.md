# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental types and classes essential to the ArkUI framework in the Cangjie programming language. It focuses on the core components required for robust text input handling, event management, and user interface configuration. Key topics include the `SubmitEvent` class for managing submission logic, the `TextInputController` for precise state manipulation, and the `InputType` enumeration for defining field behaviors. This documentation is specifically designed for developers constructing user interfaces who need to implement advanced text validation, cursor control, and keyboard interaction features.

### class_SubmitEvent_4more.md class_SubmitEvent_4more.md

It details the SubmitEvent class for handling submission events, alongside enumerations for CancelButtonStyle, EnterKeyType, and TextInputStyle. Key information includes the SubmitEvent class exposing a text property for input content, and enums defining visual and functional behaviors like keyboard action types (e.g., Go, Send) and input styles. This reference is targeted at developers implementing text input and submission logic within the ArkUI framework.

It covers the class initialization and methods for manipulating text input states, including cursor positioning, text selection, and content retrieval. Key functionalities include setting the caret position, retrieving text line counts and content rectangles, and controlling the editing mode. The documentation specifies system capabilities and version requirements for each interface. Intended for ArkUI developers, this reference requires familiarity with Cangjie syntax and UI component logic to effectively implement text control features in applications.

### enum_InputType.md enum_InputType.md
This API reference document defines the InputType enum in Cangjie, used to specify input field types within the ArkUI framework. It details ten enumeration values including Normal, Number, Email, Password, and PhoneNumber, alongside newer types like USER_NAME and URL. Each entry specifies allowed characters, UI behaviors such as password masking or auto-fill support, and system capability requirements. This guide targets ArkUI developers needing to configure text input validation and keyboard modes for user interfaces.
