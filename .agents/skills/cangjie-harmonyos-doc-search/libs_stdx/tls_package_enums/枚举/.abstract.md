This directory contains API reference documentation for enumeration types used in the Cangjie programming language, specifically focusing on network security and cryptographic protocols. It covers definitions for TLS configurations, certificate verification modes, and various cryptographic signature algorithms including RSA, ECDSA, and Edwards-curve schemes. These enumerations are essential for developers implementing secure network connections, managing data integrity, and configuring authentication settings within the Cangjie environment. The documentation provides structural definitions and interface implementations for equality checks and string conversions.
