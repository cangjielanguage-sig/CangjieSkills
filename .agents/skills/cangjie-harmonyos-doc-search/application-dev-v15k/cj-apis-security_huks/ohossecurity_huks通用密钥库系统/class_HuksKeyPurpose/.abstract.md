This directory contains technical documentation for the `HuksKeyPurpose` class, a critical component of the HarmonyOS Universal Keystore Service (HUKS) and OpenHarmony security framework. It focuses on defining constants that specify the intended usage of cryptographic keys, covering operations such as encryption, decryption, signing, verification, and key wrapping. The resources are specifically designed for developers using the Cangjie programming language to implement robust security features. By providing detailed API references, constant values, and system capability requirements, these documents assist in configuring key usage parameters effectively. This content is essential for software engineers working on secure key management and cryptographic operations within the OpenHarmony ecosystem.
