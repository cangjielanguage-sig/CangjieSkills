# deriving_package_overview

This directory contains the comprehensive documentation for the `std.deriving` package, a specialized tool designed to automate the generation of interface implementations for classes, structs, and enums. It thoroughly covers supported interfaces such as `ToString`, `Hashable`, `Equatable`, and `Comparable`, providing a complete API list of key macros. The content explains how the core `Derive` macro enables automatic expansion to streamline development, while auxiliary macros like `DeriveExclude`, `DeriveInclude`, and `DeriveOrder` offer fine-grained control over field inclusion, exclusion, and processing order. This resource is highly suitable for developers looking to reduce boilerplate code and enhance productivity by leveraging automatic derivation capabilities within the standard library ecosystem.
