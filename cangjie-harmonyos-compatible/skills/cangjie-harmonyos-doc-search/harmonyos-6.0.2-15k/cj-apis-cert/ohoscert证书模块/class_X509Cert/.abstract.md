This directory contains API reference documentation for the `X509Cert` class within the Cangjie programming language's DeviceCertificateKit. It provides comprehensive details on methods for parsing, validating, and managing X.509 digital certificates. The documentation covers retrieving certificate properties like validity periods, public keys, issuer and subject names, extensions, and signature algorithms. It includes syntax, parameters, return types, and error handling via `BusinessException`. This resource is suitable for developers implementing security capabilities, specifically those needing to integrate cryptographic certificate validation and data extraction into their Cangjie applications.
