This directory provides the API documentation for the `cj-apis-screen_lock_file_manager` module, a specialized toolkit designed for HarmonyOS developers focused on high-level data security. It offers detailed guidance on managing sensitive data access permissions, with a specific emphasis on the automated lifecycle of encryption keys. The module ensures that sensitive keys are destroyed immediately when the device screen is locked to prevent unauthorized data access and are securely restored when the screen is unlocked. The documentation covers the `ScreenLockFileManager` class, status enums for access requests, and module configuration requirements. It is an essential resource for developers using the Cangjie language who need to implement robust file access controls and manage permission states in locked-screen environments.
