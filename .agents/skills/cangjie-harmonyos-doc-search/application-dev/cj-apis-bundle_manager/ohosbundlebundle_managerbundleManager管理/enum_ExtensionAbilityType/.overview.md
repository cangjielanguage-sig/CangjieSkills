# enum_ExtensionAbilityType

This directory provides essential documentation for the `ExtensionAbilityType` enumeration within the Cangjie language framework, specifically designed for API version 22. It functions as a detailed reference guide for the various extension component types available in the system, enabling developers to implement sophisticated features that go beyond standard application boundaries. The documentation encompasses a broad spectrum of capabilities, including background task execution, inter-process data sharing, system UI customization, and hardware interaction. Furthermore, it explicitly defines system capability requirements and identifies specific extensions that are restricted to system applications only. This directory is an indispensable resource for Cangjie developers utilizing the BundleFramework who require precise technical specifications to implement robust, system-integrated extension abilities in their applications. By consulting these files, developers can ensure compliance with system permissions and leverage the full potential of the Cangjie ecosystem.

## Detailed Description

### Service_8more.md
This document serves as a reference guide defining various extension ability types available in the Cangjie language framework starting from version 22. It enumerates eight specific types: Service, Share, StaticSubscriber, Thumbnail, Unspecified, Wallpaper, Window, and WorkScheduler. Each entry details the specific functionality, such as background processing, file thumbnails, or UI composition, and notes system capability requirements. Several capabilities like Thumbnail and Wallpaper are restricted to system applications. This is intended for Cangjie developers needing to implement specific system-level or background features within the BundleFramework.

### enum_ExtensionAbilityType_15more.md
This document serves as an API reference for the ExtensionAbilityType enum in the Cangjie language, defining various extension component types available in the system. It details specific members including Accessibility, DataShare, Driver, InputMethod, and Print, explaining their individual functions such as data sharing, peripheral management, and document printing. Each entry specifies the required system capability and the starting API version 22. The documentation highlights that some capabilities like AdsService and Print are restricted to system applications. This reference is intended for developers utilizing the BundleFramework to implement specific extension abilities within their applications.
