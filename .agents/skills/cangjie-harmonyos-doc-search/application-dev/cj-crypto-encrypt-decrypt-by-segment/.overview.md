# cj-crypto-encrypt-decrypt-by-segment

This directory contains a specialized technical guide focused on optimizing cryptographic operations through segmented encryption and decryption. As data volumes grow, standard encryption methods can become bottlenecks; this resource addresses that challenge by outlining efficient strategies for processing data in chunks. The content covers the fundamental differences between symmetric and asymmetric encryption approaches, specifically how symmetric encryption leverages the update method for flexibility, while asymmetric encryption demands strict adherence to key specifications and length limits. Key technical concepts include handling segment sizes up to INT_MAX and managing constraints for RSA and SM2 algorithms. This documentation is tailored for developers using the CryptoArchitectureKit who require high-performance, secure data processing solutions.

### cj-crypto-encrypt-decrypt-by-segment.md cj-crypto-encrypt-decrypt-by-segment.md

This technical guide explains best practices for performing segmented encryption and decryption to improve efficiency when handling large data volumes. It details two primary approaches: symmetric encryption, which utilizes the update method for custom data chunks, and asymmetric encryption, which requires manual data splitting based on specific key specifications. Key takeaways include that symmetric operations support segment sizes up to INT_MAX, whereas asymmetric operations like RSA and SM2 do not support update and must adhere to strict length limits. Intended for developers using the CryptoArchitectureKit, this document provides essential guidance for optimizing cryptographic performance.
