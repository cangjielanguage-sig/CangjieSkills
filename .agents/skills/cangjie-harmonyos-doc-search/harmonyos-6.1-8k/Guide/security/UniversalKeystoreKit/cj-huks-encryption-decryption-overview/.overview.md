# cj-huks-encryption-decryption-overview

本目录提供了关于OpenHarmony通用密钥库（HUKS）加密与解密功能的全面概述文档。文档详细阐述了HUKS所支持的算法规格，涵盖了标准设备与轻量级设备的不同支持情况。核心内容包括AES、RSA、SM4、SM2、DES及3DES等主流算法的列表，以及对应的分组模式、填充模式和必选参数说明。此外，文档还明确区分了必选与可选规格，并标注了相关的API级别要求，建议开发者优先使用必选规格以确保系统的兼容性。该文档主要面向OpenHarmony应用开发者，旨在指导其正确利用HUKS进行安全、高效的数据加解密操作。
