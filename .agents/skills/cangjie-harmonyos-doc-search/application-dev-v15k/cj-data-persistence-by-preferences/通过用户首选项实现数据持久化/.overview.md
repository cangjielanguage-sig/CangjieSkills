# 通过用户首选项实现数据持久化

This directory provides a comprehensive technical guide to implementing data persistence using User Preferences within the HarmonyOS ecosystem, specifically utilizing the Cangjie programming language. It focuses on the management of lightweight, persistent Key-Value data suitable for application settings like font size or dark mode. The content covers the complete operational mechanism, including memory caching, file persistence, and the critical `flush` method. It addresses specific constraints such as data size limits, concurrency safety, and data type restrictions, while offering a detailed API reference. This resource is ideal for developers seeking efficient local storage solutions for simple data types without the overhead of a full database, providing both theoretical background and practical implementation steps.

## Detailed Description

### 场景介绍_4more.md
This technical guide introduces the User Preferences feature for managing lightweight, persistent Key-Value data in applications. It covers usage scenarios, operational mechanisms involving memory caching and file persistence, specific constraints like data size limits and concurrency safety, and a detailed API reference. Key takeaways include the necessity of the flush method for persistence, the unsuitability for large datasets or multi-process environments, and specific data type restrictions. Targeted at developers using the Cangjie language, this document provides essential interfaces like getPreferences, put, and delete for implementing user settings such as font size or dark mode.

### 开发步骤/
This directory contains essential development guides for implementing lightweight data storage using the Preferences API in the Cangjie programming language, tailored for the HarmonyOS ecosystem. It provides a step-by-step approach to managing application settings and simple persistent data efficiently. The content covers the complete data lifecycle, including importing modules, obtaining Preferences instances within a UIAbility, and performing key manipulation tasks such as writing, reading, and deleting key-value pairs. Furthermore, it details critical operations like ensuring data persistence using the flush method, subscribing to data changes via callbacks, and permanently removing preference files. These resources are highly suitable for HarmonyOS developers who need practical, code-focused tutorials to handle local data storage, exception handling, and cleanup operations effectively in their Cangjie applications.
