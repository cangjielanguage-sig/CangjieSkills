This directory serves as a comprehensive guide to the Cangjie declarative UI development paradigm within the ArkUI framework. It covers fundamental concepts including state management, component architecture, layout systems, and animation rendering. The documentation highlights the framework's high performance, cross-device capabilities, and efficient data-driven UI synchronization using decorators. It also outlines general conventions for units and error handling. This resource is suitable for application developers and UI engineers seeking to build robust, simplified, and high-performance user interfaces using the Cangjie programming language.
