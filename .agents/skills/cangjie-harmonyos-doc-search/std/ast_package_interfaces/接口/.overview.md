# 接口

This directory contains comprehensive API reference documentation for core interfaces within the Cangjie programming language, specifically focusing on data transformation and representation mechanisms. It covers essential interfaces such as `ToBytes`, which facilitates the serialization of complex types into byte sequences for efficient data storage and network transmission, and `ToTokens`, which handles the conversion of various data types into token objects necessary for Abstract Syntax Tree (AST) generation and parsing. Key concepts include serialization, tokenization, type conversion, and metaprogramming. This documentation is highly suitable for Cangjie developers who are implementing custom serialization logic, building compiler components, or developing advanced language processing tools that require precise control over how data is represented and manipulated within the system.

### interface_ToTokens/

This directory contains API reference documentation for the `ToTokens` interface within the Cangjie language framework. It details the implementation of tokenization logic for a wide range of data types, including signed and unsigned integers, floating-point numbers, strings, booleans, and collection types like Arrays and ArrayLists. These documents specify how primitive and structural types are converted into `Tokens` objects, primarily for Abstract Syntax Tree (AST) generation, parsing, and quote interpolation operations. This resource is suitable for developers working on compiler components, language processing tools, or metaprogramming features in Cangjie who need to understand type-to-token conversion mechanisms.
