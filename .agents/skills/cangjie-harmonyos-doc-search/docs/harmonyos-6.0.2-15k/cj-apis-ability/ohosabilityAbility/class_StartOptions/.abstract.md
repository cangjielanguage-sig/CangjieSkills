This directory provides comprehensive technical documentation for the `StartOptions` class in the Cangjie language, a critical component for the HarmonyOS Ability Runtime Core. It focuses on the mechanisms required to specify window modes and configuration parameters when launching an Ability. The documentation covers a wide array of properties, including window geometry, display ID, process mode, startup visibility, and animation settings. It also details the distinctions between API versions 12 and 19, such as the introduction of `processMode` and `startupVisibility`. Furthermore, it clarifies the read/write permissions of various properties. This resource is essential for developers who need precise control over application startup behavior, window layout management, and the definition of specific launch properties within their HarmonyOS applications.
