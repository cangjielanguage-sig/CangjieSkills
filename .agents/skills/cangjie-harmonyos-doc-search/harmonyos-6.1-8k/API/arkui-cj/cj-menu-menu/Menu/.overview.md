# Menu

本目录包含ArkUI框架中Menu组件的仓颉语言开发文档，涵盖了垂直列表菜单的API参考、多级菜单的构建示例以及组件外观属性的配置方法。内容涉及Menu组件的初始化、子组件（MenuItem/MenuItemGroup）的使用、布局约束、事件处理及样式定制。该文档适合使用仓颉语言进行鸿蒙应用开发的开发者，旨在指导实现复杂的菜单交互功能。

## 详细描述

### Menu_5more_28700f54.md Menu_5more_28700f54.md
本文档介绍了ArkUI中用于显示垂直列表菜单的Menu组件API，详细说明了其创建方式、子组件构成及布局约束。主要涵盖模块导入、子组件（MenuItem和MenuItemGroup）、组件初始化方法init以及通用属性和事件的支持情况。关键信息指出Menu组件需配合bindMenu或bindContextMenu使用，不可单独使用。文档详细阐述了菜单宽度的计算规则，包括默认2栅格宽度、自适应撑开及固定宽度设置，并指出设置边框时最小宽度为64vp。该文档面向使用仓颉语言开发ArkUI应用的开发者，属于API参考文档，旨在指导开发者正确实现和配置菜单功能。

### 示例代码.md 示例代码.md
本文档提供了一个仓颉代码示例，演示如何通过在MenuItem组件中使用builder参数来创建ArkUI多级菜单。文档涵盖了使用@Builder函数定义子菜单、配置包含图标和标签的菜单项，以及实现菜单组和选择状态。关键要点包括通过builder参数绑定子菜单的语法、处理资源引用，以及管理菜单项属性（如启用状态和选择事件）。本教程面向使用仓颉语言的鸿蒙开发者，适用于需要在应用中实现复杂菜单交互的场景。关键词：ArkUI, 仓颉, MenuItem, 多级菜单, @Builder, 鸿蒙开发。

### 组件属性.md 组件属性.md
本文档定义了Menu组件在Cangjie语言中的外观属性配置API，用于设置文本样式和边框圆角。主要涵盖`font`（字体尺寸、粗细、家族及样式）、`fontColor`（文本颜色）以及`radius`（边框圆角半径）四个核心函数接口。关键信息包括字体默认值为16.vp和HarmonyOS Sans，`radius`方法支持`BorderRadiuses`和`Length`两种类型重载，且当圆角半径之和超过菜单尺寸时会采用默认值。该文档属于API参考手册，面向使用HarmonyOS ArkUI框架和Cangjie语言进行UI开发的开发者。
