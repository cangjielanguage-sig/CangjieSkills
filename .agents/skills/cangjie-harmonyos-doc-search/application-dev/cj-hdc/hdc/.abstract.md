This directory contains comprehensive documentation for the HarmonyOS Device Connector (HDC), a command-line tool essential for debugging OpenHarmony and HarmonyOS devices. It covers the tool's architecture, installation, command syntax, file transfer, port forwarding, and application management. The resources also include troubleshooting guides for error codes, connectivity issues, and service process management. Suitable for software developers, QA engineers, and system administrators, this documentation provides the necessary instructions to establish a robust debugging environment and efficiently manage device interactions from Windows, Linux, or macOS systems.
