# digest_package_funcs

This directory provides the essential API reference documentation for generic digest functions within the Cangjie standard library's crypto package. It is designed to assist developers in performing secure hash computations across a variety of data sources, including byte arrays, input streams, and strings. The documentation highlights the use of generics constrained by the `Digest` interface to return `Array<Byte>` results. It also addresses specific function overloads and deprecations, ensuring developers are aware of the current best practices. This resource is essential for Cangjie developers implementing cryptographic hashing solutions, requiring a solid understanding of generics, interfaces, and IO stream handling to effectively utilize the provided code examples and technical specifications.

## Detailed Description

### digest_package_funcs.md digest_package_funcs.md

This document serves as the comprehensive API reference for generic digest functions within the Cangjie standard library's crypto package. It details the technical specifications required to perform hash computations using various data sources. The text covers three overloaded `digest` functions that accept `Array<Byte>`, `InputStream`, and `String` inputs respectively, with the `String` input variant explicitly marked as deprecated. All functions described are generic, constrained by the `Digest` interface, and consistently return an `Array<Byte>`. Additionally, the documentation includes practical Cangjie code examples that demonstrate how to implement these functions with custom digest classes. This reference is targeted at Cangjie developers implementing cryptographic hashing and requires prior knowledge of generics, interfaces, and IO streams.
