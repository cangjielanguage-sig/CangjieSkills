# class_JSArrayBuffer

This directory provides comprehensive API reference documentation for the `JSArrayBuffer` class within the Cangjie programming language, specifically tailored for the ArkUI NAPI framework. It focuses on the management and manipulation of generic raw binary data buffers. Key topics include the class definition, the read-only `byteLength` property, and methods for reading binary data into native Cangjie arrays or converting them into specific typed arrays such as Float32, Float64, Int16, Int32, and Int64. The documentation also highlights the distinction between returning native Cangjie arrays and JSValue objects to ensure seamless ArkTS interoperability. This resource is essential for HarmonyOS developers who need to bridge native Cangjie code with JavaScript environments to handle complex binary data operations efficiently.

### class_JSArrayBuffer_13more.md class_JSArrayBuffer_13more.md
