Designed for developers and security engineers, these materials provide the necessary specifications to ensure parameter compatibility, manage performance considerations, and securely configure cryptographic operations. ## Detailed Description

### RSA_3more.md RSA_3more.md
This technical reference document outlines the implementation of RSA asymmetric encryption modes within the Cangjie framework. It details three supported padding schemes: NoPadding, PKCS1, and PKCS1_OAEP, explaining their specific input data length constraints and parameter configurations. Key information includes a comparison table for RSA2048 input limits and a list of string parameters (e.g., "RSA2048|PKCS1") required for creating encryption instances. The document also highlights performance considerations for large key sizes. Intended for developers using Cangjie's cryptographic APIs, this guide provides the necessary specifications to correctly configure and utilize RSA encryption operations. ### 获取设置OAEP填充模式的参数.md 获取设置OAEP填充模式的参数.md
This API reference document outlines how to retrieve and configure parameters for the RSA PKCS1_OAEP padding mode, supported from API version 12. It details specific OAEP parameters including message digest (md), mask generation function (mgf), MGF1 digest (mgf1_md), and the encoding parameter string (pSource). The provided table clarifies access permissions, indicating that while md, mgf, and mgf1_md are read-only, the pSource parameter supports both retrieval and modification. This guide targets developers implementing RSA encryption who need to understand parameter availability and configurability within the cryptographic framework.

### 填充模式为PKCS1_OAEP/
This directory provides technical documentation for implementing RSA encryption and decryption using the PKCS1_OAEP padding mode. It covers the construction of configuration strings, compatibility matrices for various key sizes (RSA512 to RSA8192), and constraints regarding digest algorithms and Mask Generation Functions (MGF). The resources explain how to format parameters using the "Key|Padding|Digest|MaskDigest" syntax and handle key length attributes dynamically. This collection is suitable for developers and security engineers who need to ensure parameter compatibility, manage data size limits, and correctly configure cryptographic libraries for secure operations.
