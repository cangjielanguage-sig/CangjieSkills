This directory contains API reference documentation for configuring the properties of the Slider component within the Cangjie ArkUI framework. It covers a wide range of customization options, including visual styling of the block and track, interaction modes, and responsive behavior. Developers can find detailed parameters for setting colors, sizes, shapes, and valid sliding ranges. The documentation is essential for UI developers looking to create highly customized and interactive slider controls in their applications using the Cangjie language.
