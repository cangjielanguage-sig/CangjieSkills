# 开发音频通话功能

This directory provides a comprehensive guide for developers implementing audio call functionality in HarmonyOS applications. It covers the core components required for managing simultaneous audio input and output, specifically focusing on `AudioCapturer` for recording local voice and `AudioRenderer` for playing remote audio. Key topics include audio scene management, ringtone mode checks, and lifecycle management of audio streams. Suitable for application developers building VOIP or communication features, this resource offers practical examples in Cangjie and ArkTS to handle audio data flow, permissions, and state validation effectively.
