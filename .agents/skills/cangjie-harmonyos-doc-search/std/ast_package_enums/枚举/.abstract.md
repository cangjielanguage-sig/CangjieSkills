This directory serves as a centralized API reference for all enumeration types utilized within the Cangjie programming language's compiler infrastructure. It comprehensively documents critical data structures that define error reporting severities, import statement variations, and the exhaustive set of lexical tokens recognized by the parser. By covering components ranging from diagnostic levels to specific syntax tokens like keywords, operators, and punctuation, this collection provides the foundational type definitions necessary for understanding the language's grammar and internal logic. It is primarily suitable for compiler developers, language engineers, and contributors working on syntax analysis, tooling, or the Abstract Syntax Tree (AST) implementation. These enumerations ensure type safety and standardization across the compiler's codebase, facilitating robust parsing, accurate error reporting, and consistent handling of language constructs.
