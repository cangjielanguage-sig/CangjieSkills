# datetime_prop

This directory provides a detailed tutorial and code examples for Cangjie developers focusing on the retrieval and manipulation of date and time properties using the Cangjie standard library. It is an essential resource for understanding how to effectively handle temporal data within applications. The guide comprehensively covers the creation of DateTime objects using the `DateTime.of` method and details the extraction of various properties, including year, month, day, and time zone ID. It also explores advanced functionalities such as the calculation of ISO week data, day-of-year, and week-of-year, which are crucial for accurate date arithmetic. Additionally, the document addresses the complexities of time zone management through the use of `TimeZone.load` and highlights important warnings regarding platform-specific dependencies that may affect time zone data availability. This material is highly suitable for developers seeking to implement robust time-based features, ensuring they can manage, format, and calculate dates with precision and awareness of underlying platform constraints.
