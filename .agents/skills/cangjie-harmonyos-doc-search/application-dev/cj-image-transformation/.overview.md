# cj-image-transformation

This directory contains a comprehensive tutorial guide focused on image transformation techniques using the PixelMap class within the Cangjie programming language. It covers the complete development workflow, starting from the initial step of image decoding through to the acquisition and manipulation of PixelMap objects. Key topics include essential geometric operations such as cropping, scaling, translating, rotating, and flipping, as well as attribute adjustments like opacity. The content is specifically designed for developers working with the ImageKit framework, particularly those operating within the OpenHarmony ecosystem, who require robust tools to programmatically process and manipulate image data. The guide includes practical code snippets, detailed parameter explanations, and links to API references to facilitate implementation.
