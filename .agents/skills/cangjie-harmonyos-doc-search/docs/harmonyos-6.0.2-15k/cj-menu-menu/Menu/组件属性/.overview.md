# 组件属性

This directory serves as a centralized repository for API reference documentation focused on the properties of ArkUI Menu components, specifically implemented using the Cangjie language. It is designed to assist developers in mastering the customization of user interface elements within the HarmonyOS ecosystem. The documentation encompasses a variety of styling and functional attributes, ranging from typography adjustments—such as font size, weight, and color—to structural modifications like dividers and border radii. Furthermore, it includes configuration options for interaction behaviors, such as submenu expansion modes. This resource is particularly suitable for HarmonyOS developers and UI/UX engineers who are building or refining applications and require in-depth knowledge of the available parameters to achieve a specific visual design and user experience.

## Detailed Description

### func_fontLength_FontWeight_4more.md func_fontLength_FontWeight_4more.md

This API reference document details functions for styling text and dividers within ArkUI Menu components using the Cangjie language. It covers overloaded font functions for configuring size, weight, family, and style, a fontColor function for text color, and a menuItemDivider function for visual separators. Key information includes default settings like 16.vp font size and "HarmonyOS Sans" font family, with support for custom fonts and resource-based definitions. The divider function allows customization of stroke width, color, and margins. This guide is intended for HarmonyOS developers needing to customize the visual appearance of Menu components in their applications.

### func_menuItemGroupDividerD_4more.md func_menuItemGroupDividerD_4more.md

This document serves as API reference documentation for styling Menu components within the ArkUI framework using the Cangjie language. It details four specific functions: menuItemGroupDivider for configuring group dividers, two overloaded radius functions for setting border corner radii, and subMenuExpandingMode for defining submenu behavior. Key information includes parameters for divider stroke width and color, default radius values of 20.vp, and constraints on radius calculations relative to menu dimensions. This guide is intended for developers utilizing ArkUI to customize the visual appearance and interaction behavior of Menu components.
