# class_Sign

This directory contains API reference documentation for the Cangjie `Sign` class within the CryptoFramework. It focuses on digital signature operations, covering the core class definition, parameter configuration, and data signing methods. The documentation details the mandatory workflow of initialization, data updating, and signing, with specific support for RSA and handling large data chunks. It is suitable for Cangjie developers implementing cryptographic security who need to understand asymmetric key generation, signature algorithms, and fine-grained parameter control.

### class_Sign_4more.md class_Sign_4more.md
This document serves as API reference documentation for the Cangjie Sign class, designed to facilitate digital signature operations within the CryptoFramework. The content covers the class overview, the read-only algName property, and key methods such as getSignSpec for retrieving signature parameters and initialize for setting private keys. Key takeaways include the mandatory three-step workflow of initialize, update, and sign, with specific support for handling data in chunks and RSA algorithms. The documentation details parameters, return values, and potential error codes. It targets Cangjie developers implementing cryptographic security, requiring knowledge of asymmetric key generation and signature algorithms.

### func_signDataBlob_2more.md func_signDataBlob_2more.md
This document serves as API reference documentation for cryptographic signing operations within the Cangjie CryptoArchitectureKit. It details two primary functions: sign, which generates a digital signature from optional input data, and update, which appends data chunks to the signing context. Key information includes the necessity of initializing the signer before updating, recommendations to use update for large data to prevent memory issues, and specific restrictions where update is unsupported, such as DSA with NoHash. The content lists specific error codes for parameter validation and crypto operation failures. This documentation targets developers implementing secure digital signatures, requiring familiarity with asymmetric cryptography concepts and the Cangjie programming language.
