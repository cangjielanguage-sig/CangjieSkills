# 开发步骤

This directory acts as a vital resource for developers working within the Cangjie ecosystem, providing detailed instructions on implementing certificate chain validation using the DeviceCertificateKit framework. It is designed to assist developers in integrating security features by offering clear, step-by-step tutorials and practical code examples. The content delves into the nuances of data structure construction, specifically the `CertChainData` object, explaining requirements for byte-length-data and L-V formats. It also covers the execution of the PKIX algorithm, the handling of various encoding standards like PEM and DER, and the implementation of error handling for `BusinessException`. These documents are highly suitable for Cangjie developers and security architects aiming to build secure applications by verifying certificate authenticity and establishing reliable trust chains.

## Detailed Description

The following files contain specific code examples and structural definitions necessary for implementing the development steps outlined above.

### 开发步骤_1.md
This document provides a step-by-step tutorial for developers on how to implement certificate chain validation using the DeviceCertificateKit in the Cangjie programming language. It covers importing the framework, creating a validator object, constructing the CertChainData object with specific data structure requirements, and executing the validation process. Key information includes the detailed definition of the CertChainData structure, specifically the byte-length-data format required for the certificate array, and a practical Cangjie code example demonstrating the workflow. This guide targets Cangjie developers who need to integrate certificate trust chain verification into their applications.

### 开发步骤_2.md
This document provides a code example for implementing certificate chain validation using the PKIX algorithm. It covers defining a secondary CA certificate in PEM format and creating a validation function that instantiates a validator, configures certificate data, and executes the validation process. Key takeaways include the structure of CertChainData using L-V format, the requirement for PEM or DER encoding, and the implementation of error handling to catch BusinessException during validation. This technical guide targets developers integrating security features, specifically those needing to verify certificate authenticity within their applications.
