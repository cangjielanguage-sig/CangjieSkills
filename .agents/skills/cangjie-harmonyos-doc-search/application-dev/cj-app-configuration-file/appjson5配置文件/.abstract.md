This directory contains technical documentation for the `app.json5` configuration file format used in HarmonyOS/OpenHarmony application development. It covers the comprehensive structure of application manifests, including bundle identification, versioning, API compatibility, and runtime behavior settings. Key topics include environment variables, multi-instance modes, font scaling rules, and device compatibility. These resources are designed for application developers and configuration engineers who need to define project properties, manage build profiles, and control application capabilities using DevEco Studio.
