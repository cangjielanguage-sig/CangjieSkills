This directory contains the core documentation for Camera Kit, a robust service enabling developers to construct advanced camera applications. It covers essential features such as live preview, image capture, and precise hardware control. The documentation details the development model, explaining the workflows for input device management, session management, and output management. It highlights how sessions configure inputs and parameters like flash and exposure, and describes the data flow via Hardware Device Interfaces (HDI) and BufferQueue to surfaces. This resource is intended for developers building camera modules, serving as a conceptual precursor to specific development guides.
