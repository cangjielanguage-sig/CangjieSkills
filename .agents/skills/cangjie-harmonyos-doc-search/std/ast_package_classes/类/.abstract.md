This directory contains the API reference documentation for the Abstract Syntax Tree (AST) of the Cangjie programming language. It covers a comprehensive range of class definitions representing syntax nodes, including expressions, declarations, types, patterns, and utility structures. The documentation details class inheritance, properties, constructors, and methods for AST manipulation, traversal, and token conversion. It is intended for compiler developers, language tool engineers, and researchers working on parsing, static analysis, or code generation tools for the Cangjie language.
