This directory contains API reference documentation for the `Formattable` interface in the Cangjie programming language. It covers the core interface definition and its extensions across various numeric data types, including signed and unsigned integers (Int8, Int16, Int32, Int64, UInt8, UInt16, UInt32, UInt64), floating-point numbers (Float16, Float32, Float64), and the Rune type. The documents detail the `format` function, which converts instances to formatted strings, and handle exceptions like `IllegalArgumentException`. This resource is suitable for Cangjie developers looking to implement or utilize string formatting capabilities for primitive types within their applications.
