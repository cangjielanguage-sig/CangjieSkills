This directory contains essential API reference documentation for the `AnimatorOptions` class in the Cangjie language, designed to facilitate the configuration of animation behaviors within the ArkUI framework. It provides detailed technical specifications for defining animation dynamics, covering critical parameters such as duration, easing curves, delay, fill modes, direction, and iteration counts. The documentation also explains specific behaviors for advanced easing functions like cubic-bezier and interpolating-spring, alongside the immutable properties of the class. This resource is specifically intended for software developers and UI engineers building interactive applications on HarmonyOS who require a deep understanding of Cangjie syntax and ArkUI animation concepts to implement smooth, performant UI transitions.
