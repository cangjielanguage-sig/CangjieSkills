## Detailed Description

### cj-crypto-generate-message-digest.md cj-crypto-generate-message-digest.md

本文档是一份面向仓颉开发者的开发指南，旨在指导如何使用 CryptoArchitectureKit 计算 SHA256 消息摘要。文档详细介绍了两种数据传入模式：一次性传入和分段传入，并分别提供了完整的 Cangjie 代码示例。核心内容包括调用 `createMd` 创建实例、使用 `update` 接口更新数据、通过 `digest` 获取计算结果以及 `getMdLength` 获取摘要长度。该文档适用于需要处理不同数据量摘要计算的开发场景，帮助开发者根据实际需求灵活选择数据处理方式，确保在处理大文件或流式数据时依然能够保持高效的计算性能。
