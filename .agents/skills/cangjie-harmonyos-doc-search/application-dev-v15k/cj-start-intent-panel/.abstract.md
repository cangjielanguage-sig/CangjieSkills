This directory serves as a specialized technical resource for developers and system architects focusing on intent-based application launching mechanisms. It details the implementation of the `startAbilityByType` interface, a sophisticated feature that decouples application invocation from specific app IDs. Instead, it leverages business categories—such as navigation, finance, and mail—to present users with a vertical domain panel for app selection.
Key topics covered include:
*   **Vertical Domain Panels:** UI components for category-based app selection.
*   **Parameter Mapping:** Technical tables linking input types to system features.
*   **Protocol Support:** Implementation of `mailto` and file handling protocols.
The documentation includes critical technical assets, such as comprehensive mapping tables that link input parameters (type, sceneType) to specific target application configurations (linkFeature). This guide is essential for those building cross-app capabilities, ensuring seamless integration and a flexible user experience within the operating system's intent framework.
