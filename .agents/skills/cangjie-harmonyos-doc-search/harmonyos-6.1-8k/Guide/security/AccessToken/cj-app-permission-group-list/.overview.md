# cj-app-permission-group-list

This directory serves as a comprehensive reference guide for HarmonyOS application developers, focusing specifically on the management and configuration of application permission groups. It provides essential documentation regarding the complex landscape of system permissions, covering standard groups such as location, camera, and microphone, as well as specialized permissions required for advanced features like multi-device collaboration and communication media. The content details the permission application mechanism, distinguishing between system and normal applications, and outlines the protocols for accessing restricted permissions. By offering clear guidelines on sub-permissions and compliance standards, this resource enables developers to ensure their applications are secure, functional, and fully compliant with HarmonyOS ecosystem policies.

## Detailed Description

### 应用权限组列表/

This directory contains essential reference documentation for HarmonyOS application development, specifically focusing on permission groups. It is designed to assist developers in understanding and implementing the necessary security controls for their applications.

The content covers a broad spectrum of permission requirements, including specific permissions needed for enabling multi-device collaboration capabilities and communication media functions. It provides a detailed enumeration of the standard application permission groups supported by the system—such as location, camera, and microphone—along with their respective lists of sub-permissions. This granular breakdown helps developers understand exactly what access is requested when a specific permission group is utilized.

Furthermore, the documentation explains the permission application mechanism, highlighting the procedural differences between system applications and normal third-party applications. It offers specific guidance on how to apply for restricted permissions, which are often subject to stricter scrutiny. The primary goal of this directory is to help developers correctly configure and apply for permissions, ensuring that application functions are implemented in a compliant manner, maintaining user trust and system security.
