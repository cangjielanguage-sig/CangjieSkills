## Detailed Description

### 类/ (Classes)

This directory contains the core class API reference documentation for Web and URL handling in the Cangjie language. It provides a detailed breakdown of the object-oriented tools available for network interactions.

The documentation primarily covers three critical classes:
1.  **`UserInfo`**: A class dedicated to handling URL credentials, ensuring that authentication data is managed correctly within URL structures.
2.  **`Form`**: A utility class designed for managing HTTP form data and constructing query parameters, simplifying the process of data transmission.
3.  **`URL`**: The fundamental class for parsing and manipulating Uniform Resource Locators, allowing developers to deconstruct and rebuild web addresses programmatically.

Core concepts emphasized in this section include strict adherence to the RFC 3986 protocol, which ensures global interoperability, and the implementation of percent-encoding mechanisms to safely handle special characters. This documentation is suitable for backend developers who need to perform network programming, build robust web services, or process URL structures securely and efficiently.
