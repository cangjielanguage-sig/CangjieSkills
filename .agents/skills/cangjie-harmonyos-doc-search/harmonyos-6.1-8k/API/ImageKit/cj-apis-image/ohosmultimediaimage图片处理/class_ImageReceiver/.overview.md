## Detailed Description

### class_ImageReceiv_5more_68c0d1a3.md
这份文档是Cangjie语言中ImageReceiver类的API参考文档，旨在定义图像接收类的功能、属性及接口。主要内容包括类的只读属性（capacity、format、size）和获取Surface ID的方法（getReceivingSurfaceId）。关键点在于ImageReceiver作为消费者，其图像参数由生产者（如相机）决定，且使用完毕后必须主动释放内存以避免资源浪费。文档面向多媒体开发人员，提供了异常处理说明及代码示例，适用于需要处理图像流或相机预览的场景。

### func_onReceiveTyp_2more_c770a9f3.md
本文档是Cangjie语言中ImageReceiver组件的API参考文档，详细阐述了图片接收事件的回调注册与注销机制。主要涵盖`on`和`off`两个核心函数的说明，包括功能描述、系统能力、起始版本、参数定义及Cangjie代码示例。关键信息指出，`on`函数用于在接收图片时注册回调，`off`函数用于在释放buffer时移除回调，两者的事件类型均固定为ImageArrival。文档面向使用ImageKit进行多媒体图像开发的开发者，需具备Cangjie编程基础，旨在帮助开发者有效管理图像接收的生命周期。

### func_release_3more_6a33bbd2.md
这份文档是Cangjie语言中ImageReceiver类的API参考文档，主要介绍了实例释放与图片读取的三个核心方法。文档涵盖了release方法用于主动释放内存，以及readLatestImage和readNextImage方法用于获取图片数据。关键信息强调了图片占用内存较大，使用完毕后必须调用release方法释放资源，且读取操作需在回调触发后进行。文档包含功能描述、异常处理及代码示例。面向使用ImageKit进行多媒体应用开发的开发者，需具备Cangjie编程及异常处理基础知识。
