This directory contains essential API reference documentation for the `EnvironmentCallback` class in the Cangjie programming language, specifically designed for HarmonyOS application development. It covers the technical specifications required to handle system environment and memory changes dynamically. The documentation details the class constructor, system capabilities, version requirements, and parameters for key callbacks like `onConfigurationUpdated` and `onMemoryLevel`. It also includes practical code examples for instantiation and registration. This resource is suitable for Cangjie developers who need to manage app behavior dynamically based on system resource fluctuations and ensure UI adaptation through the ApplicationContext.
