# cj-application-package-structure-stage

This directory serves as an essential resource for developers working with the HarmonyOS Stage model, specifically focusing on the application package structure when using the Cangjie programming language. It provides a thorough explanation of the application's evolution from the development state to the compilation and release states. The guide covers the fundamental architecture of projects created in DevEco Studio, with a particular focus on the composition and purpose of the AppScope and Module directories. Key topics include the management of Cangjie source code files, the configuration of application resources, and the comprehensive build process. By defining critical terms such as AppScope, Module, HAP, HAR, App Pack, and build configuration, this document helps developers gain a deep understanding of the technical mechanics behind project initialization, packaging, and deployment. It is ideally suited for Cangjie developers seeking to streamline their workflow and ensure their applications are structured correctly for the HarmonyOS ecosystem.

## Detailed Description

### Stage模型应用程序包结构/
This directory offers an in-depth look at the HarmonyOS Stage model application package structure, meticulously documenting the transition of an application through the development, compilation, and release phases. It focuses heavily on the engineering structure within DevEco Studio, providing a clear breakdown of the AppScope and Module directories. The content explains how AppScope handles global configuration while Module manages specific functionality, and how Cangjie source code files are organized within this framework. Additionally, it covers resource configuration and the build process in detail. Key terminology such as AppScope, Module, HAP (HarmonyOS Ability Package), HAR (HarmonyOS Archive), App Pack, and build configuration are thoroughly explained to provide a complete understanding of the packaging mechanics. This guide is indispensable for developers using the Cangjie language, as it clarifies the complex procedures involved in project initialization, the technicalities of build packaging, and the requirements for deployment and listing. By following this structure, developers can ensure their HarmonyOS applications are built efficiently and correctly.
