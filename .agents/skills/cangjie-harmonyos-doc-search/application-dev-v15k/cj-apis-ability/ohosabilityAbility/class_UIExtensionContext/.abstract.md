This directory contains API reference documentation for the Cangjie language focusing on the `UIExtensionContext` class and related Ability lifecycle functions. It covers core functionalities such as launching abilities, managing UI extensions, handling atomic services, and terminating contexts. Key topics include `startAbility`, `openLink`, `reportDrawnCompleted`, and various termination methods. The documentation provides detailed error codes, parameter definitions, and asynchronous callback mechanisms. It is intended for HarmonyOS application developers working with the system runtime core to implement robust inter-process communication and UI component management.
