# Span

This directory provides comprehensive documentation for the Span component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the fundamental API reference for creating inline text segments, defining basic data types like text background styles and shadow effects, and configuring component properties. Additionally, it includes practical code examples demonstrating text styling techniques such as decorations, spacing, and visual effects. This resource is suitable for developers and UI engineers looking to implement and customize inline text content in HarmonyOS applications using Cangjie.

## Detailed Description

### Span_4more.md Span_4more.md
This document serves as API reference documentation for the Span component in the ArkUI framework using the Cangjie language. It defines Span as a child component of Text used specifically for displaying inline text content. The main sections cover component creation via two constructors, init(String) and init(AppResource), and detail support for universal attributes and events. Key information includes the note that Span has no child components and that while it supports click events, the target attribute is invalid due to the component's lack of size information. This guide targets developers seeking to implement and style inline text segments within ArkUI applications.

### 基础类型定义.md 基础类型定义.md
This document serves as API reference documentation defining basic data types for the ArkUI framework in the Cangjie programming language. It details the TextBackgroundStyle class, which configures text background color and rounded corners, and the ShadowType enum, which categorizes shadow effects into color or blur types. Key information includes the specific properties of TextBackgroundStyle such as color, radiusBorder, and radiusDimension, with a critical note that radiusDimension overrides radiusBorder if both are defined. Intended for developers building UI components, this reference requires knowledge of Cangjie syntax and ArkUI system capabilities.
