It covers essential type abstractions including collections, iteration, comparison operations, hashing, and C language interoperability. This documentation is suitable for Cangjie developers, systems engineers, and language learners seeking to implement custom types, understand type constraints, or utilize standard library features for data manipulation and system interaction.

### interface_CType_4more.md interface_CType_4more.md
This document serves as API reference documentation for core interfaces in the Cangjie programming language, focusing on type interoperability and comparison operations. The main sections cover the CType interface for C language interoperability, the Equal and Greater interfaces for comparison operators, and the Equatable interface which combines equality and inequality checks. Key information includes that CType is a sealed, built-in interface implicitly implemented by C-compatible types, while Equatable provides default implementations for standard types like Int64, String, and Array. This reference is intended for Cangjie developers seeking to understand type constraints and operator overloading for custom types or system interactions.

### interface_CollectionT.md interface_CollectionT.md

Key information includes that the interface mandates implementing types provide a way to retrieve the element count as an Int64, check for emptiness returning a Bool, and convert the collection into an Array. ### interface_ComparableT.md interface_ComparableT.md

This guide is intended for developers implementing custom types that require sorting or comparison logic, ensuring consistent behavior across the language's type system.
