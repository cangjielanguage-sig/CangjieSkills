This directory provides comprehensive API reference documentation for the `Iterator` class within the Cangjie programming language ecosystem. It encompasses the fundamental abstract class definition, which inherits from the `Iterable` interface, and details essential traversal mechanisms such as the `next` method. Beyond the basics, it explores advanced extensions based on generic type constraints, enabling operations like finding maximum/minimum values or checking for element presence. Furthermore, it covers a robust set of functional-style operations for data sequence manipulation, including intermediate and terminal operations. This resource is essential for Cangjie developers aiming to implement custom iterators, perform complex data transformations, or efficiently manage collection traversals in their applications.
