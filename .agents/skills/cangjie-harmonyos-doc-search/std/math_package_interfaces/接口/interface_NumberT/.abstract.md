This directory provides essential API reference documentation for the generic `Number` interface in the Cangjie programming language. It is designed to assist developers in understanding how arithmetic operations are standardized across different numeric types. The documentation covers the core interface definition, including operator overloads for addition, subtraction, multiplication, division, and negation, as well as specific implementations for a wide range of integer and floating-point types. Key concepts include generic numeric operations, type hierarchies, and the inheritance of functionality by built-in primitive data types. This resource is highly suitable for Cangjie developers who need to implement custom numeric types, utilize generic constraints for arithmetic calculations, or simply gain a deeper understanding of the language's type system and numeric capabilities.
