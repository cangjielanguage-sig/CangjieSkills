This directory contains API reference documentation for the `ListScroller` class in the Cangjie language, designed for controlling scrolling behaviors within ArkUI List components. It covers essential functionalities such as managing swipe actions, retrieving item positions and sizes within groups, and programmatically scrolling to specific items. The documentation includes functions for identifying visible list content based on coordinates and handling navigation within `ListItemGroup` structures. Suitable for ArkUI developers, these resources require familiarity with Cangjie syntax and List component architecture to implement precise layout control and interaction logic.
