This directory provides comprehensive documentation for the Float32 data type, specifically tailored for the Cangjie programming language. It encompasses the fundamental definition of the 32-bit floating-point format, detailing its strict adherence to the IEEE 754 standard's binary32 single-precision specification. Beyond the core definition, the directory includes extensive API extensions that introduce mathematical constants, utility functions for boundary checks, bitwise manipulation capabilities, and standard interface implementations for comparison, hashing, and string conversion. This collection of reference materials is highly suitable for developers, engineers, and systems programmers working on low-level data structures, graphics programming, or any application requiring precise numerical definitions and high-performance floating-point operations.
