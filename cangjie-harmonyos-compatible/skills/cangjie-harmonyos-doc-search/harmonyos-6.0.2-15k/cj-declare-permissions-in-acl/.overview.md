# cj-declare-permissions-in-acl

This directory provides a specialized technical guide for HarmonyOS developers focusing on the declaration of permissions within an Access Control List (ACL). It addresses the specific procedures required to apply for and utilize restricted permissions that are not typically granted to third-party applications by default. The documentation covers the end-to-end workflow, starting with the verification of usage scenarios and moving through the application process for a Profile file via AppGallery Connect (AGC). It also details the subsequent code declaration requirements necessary for implementation. Key topics include the critical need for accurate scenario descriptions to satisfy AGC review standards and the technical risks involved, such as installation failure if permissions are declared without a corresponding valid certificate. The guide distinguishes between the automated processes available in DevEco Studio for debugging and the mandatory manual application steps required for release. This resource is indispensable for developers building applications that demand sensitive access or system-level capabilities.
