This directory serves as a comprehensive technical resource for understanding and implementing the `@Provide` and `@Consume` macros within the Cangjie declarative UI framework. It specifically addresses the architectural challenges of state management by enabling efficient two-way data synchronization between ancestor and descendant components. The documentation covers essential topics such as core mechanisms, variable access rules, and usage constraints, alongside practical examples ranging from simple counters to complex collections. This content is highly suitable for developers building responsive HarmonyOS applications who seek to optimize performance through dependency injection, bypass intermediate component layers to avoid "prop drilling," and ensure automatic UI updates with minimal rendering overhead.
