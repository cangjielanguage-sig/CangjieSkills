# 消息认证码计算

This directory provides a comprehensive technical guide for calculating Message Authentication Codes (MAC), with a specific focus on Hash-based MAC (HMAC) algorithms. It is designed to help developers ensure data integrity and prevent tampering by utilizing shared keys and hash functions to generate fixed-length verification codes. The content covers core concepts, supported hash algorithms (such as SHA256, SM3, and MD5), and practical implementation steps. This resource is highly suitable for software developers and system architects working with the Cangjie programming language who need to integrate robust message authentication mechanisms into their applications. It addresses both theoretical specifications and practical coding scenarios, ensuring users can effectively secure data transmission and storage.

## Detailed Description

The following resources provide in-depth information regarding the implementation and theory of MAC calculations:

### 消息认证码计算_2more.md 消息认证码计算_2more.md
This document serves as a technical reference for calculating Message Authentication Codes (MAC), specifically focusing on Hash-based MAC (HMAC) algorithms to ensure data integrity and prevent tampering. It covers the fundamental concepts of MAC and HMAC, explaining how shared keys and hash functions generate fixed-length verification codes. Key information includes a detailed table of supported hash algorithms such as SHA1, SHA256, SHA512, SM3, and MD5, all requiring API version 12 or higher. This guide is intended for developers implementing security features who need to select specific algorithm specifications for message authentication.

### 开发步骤/
This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, specifically focusing on the implementation of HMAC (Hash-based Message Authentication Code) using the CryptoArchitectureKit. The content provides detailed development steps for calculating message authentication codes, addressing various data handling scenarios such as single-pass processing and segmented updates for streaming data. Core concepts covered include SHA256 hashing, symmetric key generation, and the usage of cryptographic APIs like `createMac`, `init`, `update`, and `doFinal`. These guides are highly suitable for software developers and system architects aiming to secure their applications with robust message authentication mechanisms, ensuring data integrity and authenticity in environments dealing with variable or large data volumes.
