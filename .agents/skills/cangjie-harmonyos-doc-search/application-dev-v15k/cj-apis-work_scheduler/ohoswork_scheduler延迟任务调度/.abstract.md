This directory provides API reference documentation for the `ohos.work_scheduler` module in the Cangjie programming language, focusing on the management of delayed tasks scheduled during system idle periods. It covers essential enumerations for system states (battery, storage, network), data types for parameters, and core functions for task lifecycle management (start, stop, query). Designed for HarmonyOS developers, these resources enable efficient background task execution, optimizing power and performance by leveraging system capabilities like `SystemCapability.ResourceSchedule.WorkScheduler`.
