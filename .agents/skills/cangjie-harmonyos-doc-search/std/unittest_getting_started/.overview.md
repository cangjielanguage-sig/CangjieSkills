# unittest_getting_started

This directory serves as a comprehensive quick start guide for implementing unit testing within the Cangjie programming language ecosystem. It covers essential workflows such as writing test functions using `@Test` and `@Expect` macros, compiling code with the `cjc` command, and managing test suites via the `cjpm` package manager. Key topics include the `--test` compilation flag, the `_test.cj` file naming convention for automatic detection, and interpreting standard test output. This resource is specifically designed for Cangjie developers looking to establish robust testing practices and validate their code efficiently. By following this guide, users will learn how to structure their test files correctly and execute them to ensure code reliability and correctness throughout the development lifecycle. It is an essential resource for anyone aiming to master the standard testing tools provided by the Cangjie environment, ensuring high-quality software delivery and minimizing bugs in production code through rigorous validation.
