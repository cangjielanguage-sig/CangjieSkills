# 场景示例

本目录主要展示了在ArkUI框架中使用Cangjie语言实现页面转场动画的代码示例。内容涵盖了通过`router.pushUrl`进行页面跳转时的转场效果定义，重点演示了如何利用`PageTransitionEnter`和`PageTransitionExit`接口配置进入与退出动画，包括滑动效果、位移及透明度变化。核心关键词包括ArkUI、页面转场、路由跳转、Cangjie、动画效果。这些示例适合具备基础ArkUI开发能力、希望深入理解页面栈操作与自定义转场动画结合应用的开发者参考学习。

## 详细描述

### 场景示例_1.md

本文档旨在通过Cangjie代码示例演示如何利用router.pushUrl实现ArkUI中的页面转场动画。文档主要包含EntryView和Page1两个代码示例，展示了页面进入与退出的转场效果定义。核心内容是使用PageTransitionEnter和PageTransitionExit接口，结合RouteType（Push/Pop）和SlideEffect，定义时长为1000ms的左右滑动动画。该文档适用于熟悉ArkUI框架和Cangjie语言的开发者，用于学习自定义页面路由转场效果。

### 场景示例_2.md

本文档演示了在ArkUI应用中实现自定义页面转场动画及路由跳转的代码示例。文档包含EntryView和Page1两个页面的完整实现，重点展示了如何使用pageTransition方法配置页面进入时的滑入效果和退出时的位移与透明度变化。同时，代码涵盖了通过Router进行pushUrl页面跳转和back返回的操作逻辑。该示例旨在帮助开发者理解页面栈操作与转场动画的结合应用，适用于具备基础ArkUI开发能力的用户。
