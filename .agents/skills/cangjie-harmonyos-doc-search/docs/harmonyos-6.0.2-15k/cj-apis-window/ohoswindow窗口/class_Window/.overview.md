# class_Window

This directory contains API reference documentation for the `Window` class in the Cangjie programming language, focusing on the WindowManager framework. It covers comprehensive window management capabilities, including lifecycle operations (creation, destruction), property configuration (layout, orientation, brightness), and event handling (listeners for size, focus, and system interactions). The documentation addresses specific device constraints, such as 2in1 device behaviors and multi-window modes. It is intended for application developers who need to implement responsive UIs, manage window states, and handle system-level window interactions within their Cangjie applications.
