# 基础类型定义

This directory contains API reference documentation for fundamental layout and alignment types in the ArkUI framework using the Cangjie language. It covers classes and enums for defining alignment rules, managing layout constraints, and configuring component positioning within relative containers. Key topics include `AlignRuleOption`, `Bias`, `HorizontalAnchor`, `VerticalAnchor`, and localized alignment parameters for internationalization (LTR/RTL). These resources are essential for ArkUI developers and system architects aiming to build responsive, direction-aware interfaces with precise control over component layout and spacing.

## Detailed Description

### class_AlignRuleOption.md class_AlignRuleOption.md
This API reference document details the AlignRuleOption class in the Cangjie language, used to define alignment rules for child components within relative containers in ArkUI. It covers the class constructor and seven public properties: left, right, middle, top, bottom, center, and bias. Key information includes the use of HorizontalAnchor, VerticalAnchor, and Bias types to control positioning and offset ratios, with all parameters being optional. Intended for ArkUI developers working with system version 12, this document provides the necessary parameters to manage component layout and positioning effectively.

### class_Bias_2more.md class_Bias_2more.md
This API reference documentation defines classes for managing component layout constraints and alignment within the ArkUI framework using the Cangjie language. It details the Bias class, which sets offset parameters as ratios relative to anchor distances, and the HorizontalAnchor class, which configures horizontal alignment targets. Key information includes the Bias properties for horizontal and vertical offsets, defaulting to 0.5, and the HorizontalAnchor requirements for a target component ID and alignment type. Both classes support SystemCapability.ArkUI.ArkUI.Full starting from version 12. This document is intended for UI developers implementing precise anchor-based positioning and alignment in their applications.

### class_LocalizedHorizontalA_4more.md class_LocalizedHorizontalA_4more.md
This API reference document defines Cangjie classes and enums for configuring component alignment and chain distribution within the ArkUI framework. It details the `LocalizedHorizontalAlignParam`, `LocalizedVerticalAlignParam`, and `VerticalAnchor` classes, alongside the `ChainStyle` enumeration. Key information includes properties for setting anchor component IDs and specific alignment directions, as well as chain styles like `SPREAD`, `PACKED`, and `SPREAD_INSIDE` for managing component spacing. Targeted at ArkUI developers, this documentation facilitates precise UI positioning and layout constraint implementation using the Cangjie language.

### class_LocalizedAlignRuleOptions/
This directory provides essential API reference documentation for the `LocalizedAlignRuleOptions` class within the Cangjie programming language and the ArkUI framework. It is designed to assist developers in defining alignment rules for child components inside relative containers, with a specific focus on localized layouts. The documentation covers how alignment properties automatically adjust to support both Left-to-Right (LTR) and Right-to-Left (RTL) text directions, ensuring internationalization compatibility. Key topics include horizontal and vertical alignment parameters—such as start, end, middle, top, bottom, and center—as well as the configuration of bias settings for ratio-based anchor offsets. This resource is highly suitable for UI developers and system architects seeking to implement responsive, direction-aware interfaces with precise positioning control.
