# cj-application-package-install-uninstall

本目录提供了关于应用程序包全生命周期管理的核心文档，重点涵盖了应用的安装、卸载及更新机制。文档详细区分了开发者视角与终端用户视角的操作流程，包括利用 `bm` 命令行工具进行调试安装卸载，以及通过应用市场进行的常规操作。同时，针对应用更新环节，文档明确了修改 `app.json5` 配置文件中 `versionCode` 的关键步骤，并指导如何使用 DevEco Studio 完成打包与发布。该资料主要面向应用开发者，旨在辅助其在开发调试阶段及应用上架部署阶段高效管理应用包。
