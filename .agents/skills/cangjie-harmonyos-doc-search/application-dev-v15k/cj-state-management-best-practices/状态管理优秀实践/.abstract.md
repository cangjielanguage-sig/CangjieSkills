This directory focuses on best practices for state management in ArkUI application development using the Cangjie language. It covers essential performance optimization techniques, including controlling the number of components associated with object-type state variables, utilizing temporary variables to minimize unnecessary UI updates, and avoiding anti-patterns like dummy state variables. These guides aim to help developers improve rendering efficiency and runtime performance. It is suitable for Cangjie and ArkUI developers looking to master state variable usage and optimize application responsiveness.
