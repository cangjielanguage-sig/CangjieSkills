## 创建组件

### init(() -> Unit)

```cangjie
public init(builder!: () -> Unit = { => })
```

**功能：** 构造一个有二级菜单的 item 菜单项。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|builder|()->Unit|否|{ => }| **命名参数。** 自定义UI描述。使用时结合[@Builder](../../../Dev_Guide/arkui-cj/paradigm/cj-macro-builder.md)和[bind](./cj-ui-framework.md#func-bindcustomview---viewbuilder-customview)方法使用。|

### init(String, String, String, String, Option\<() -> Unit>)

```cangjie
public init(startIcon!: String, content!: String, endIcon!: String, labelInfo!: String, builder!: Option<() -> Unit> = None)
```

**功能：** 构造一个有二级菜单的 item 菜单项。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|startIcon|String|是|-| **命名参数。** item中显示在左侧的图标信息路径。|
|content|String|是|-| **命名参数。** item的内容信息。|
|endIcon|String|是|-| **命名参数。** item中显示在右侧的图标信息路径。|
|labelInfo|String|是|-| **命名参数。** 定义结束标签信息，如快捷方式Ctrl+C等。|
|builder|Option\<()->Unit>|否|None| **命名参数。** 自定义UI描述。使用时结合[@Builder](../../../Dev_Guide/arkui-cj/paradigm/cj-macro-builder.md)和[bind](./cj-ui-framework.md#func-bindcustomview---viewbuilder-customview)方法使用。|
