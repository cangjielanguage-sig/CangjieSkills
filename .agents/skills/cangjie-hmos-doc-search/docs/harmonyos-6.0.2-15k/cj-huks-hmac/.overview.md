# cj-huks-hmac

This directory provides a comprehensive development guide focused on implementing HMAC (Hash-based Message Authentication Code) operations using the Cangjie programming language in conjunction with the Universal Keystore Kit (HUKS). It serves as an essential resource for developers aiming to secure their applications through robust message authentication mechanisms. The content thoroughly covers two critical workflows: the generation or import of HMAC keys and the execution of the HMAC calculation process. Detailed explanations of specific API calls, such as `generateKeyItem`, `initSession`, and `finishSession`, are provided, alongside necessary parameter configurations like algorithm type, key size, and digest method. Designed for Cangjie developers who possess a basic understanding of cryptographic concepts and the HUKS framework, this guide includes a complete code example to demonstrate how to initialize properties and handle session data effectively, ensuring a smooth implementation experience.
