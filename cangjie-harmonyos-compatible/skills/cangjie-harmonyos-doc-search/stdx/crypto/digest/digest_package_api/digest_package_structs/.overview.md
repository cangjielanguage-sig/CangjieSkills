# digest_package_structs

本目录包含了 digest 包中核心结构体的 API 参考文档，主要定义了用于标识哈希算法类别的 `HashType` 结构体。文档内容全面覆盖了 HashType 的静态属性，详细列举了包括 MD5、SHA1、SHA224、SHA256、SHA384、SHA512 以及国密 SM3 在内的多种常用摘要算法类型。此外，文档还深入解析了 `toString` 方法的具体功能以及相等性比较操作符的使用方法。该文档主要面向使用仓颉（Cangjie）语言进行加密摘要开发的开发者，旨在提供算法类型标识和比较的规范说明，帮助开发者在实际开发中准确识别和操作不同的哈希算法类型，是进行数据安全处理和加密应用开发的重要参考资料。

## 详细描述

### digest_package_structs.md

本文档是 digest 包中 HashType 结构体的 API 参考文档，旨在定义哈希算法的类别结构。文档涵盖了 HashType 的静态属性，包括 MD5、SHA1、SHA224、SHA256、SHA384、SHA512 和 SM3 等常用摘要算法类型。此外，还详细说明了 toString 方法及相等性比较操作符的功能与用法。该文档主要面向使用 Cangjie 语言进行加密摘要开发的开发者，提供了算法类型标识和比较的规范说明。
