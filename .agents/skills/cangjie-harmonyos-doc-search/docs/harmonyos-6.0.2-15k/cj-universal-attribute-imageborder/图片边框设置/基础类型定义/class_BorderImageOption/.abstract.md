This directory contains comprehensive API reference documentation for the `BorderImageOption` class within the Cangjie language, specifically tailored for the ArkUI framework. It serves as a technical guide for configuring image and gradient borders, covering essential properties such as source, slice, width, outset, repeat, and fill. The documentation explains how to manipulate image slicing for corner definitions, adjust border widths, and manage repetition modes like stretching. It is primarily suitable for HarmonyOS UI developers and ArkUI developers using Cangjie who require advanced styling capabilities for container components like Row, Column, and Flex. By utilizing these resources, developers can implement sophisticated visual effects and enhance the aesthetic appeal of their application interfaces. The documents also outline system capabilities and version requirements, ensuring compatibility with the development environment.
