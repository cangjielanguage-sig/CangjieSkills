This directory contains comprehensive documentation for the `ohos.font` module within the HarmonyOS ArkUI framework, specifically tailored for the Cangjie programming language. It covers the management of custom and system fonts, including registration, metadata retrieval, and system UI configuration. Key topics include the `Font` and `FontInfo` classes, fallback strategies, and font aliasing. This resource is suitable for HarmonyOS application developers and system engineers looking to implement custom typography, query system font settings, or configure advanced font rendering behaviors in their applications.
