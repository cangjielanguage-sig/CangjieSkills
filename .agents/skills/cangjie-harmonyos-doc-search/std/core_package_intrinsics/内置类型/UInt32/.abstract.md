This directory provides comprehensive API reference documentation for the UInt32 type within the Cangjie programming language. It details the 32-bit unsigned integer type, including its static properties such as Max and Min, and explores various interface implementations essential for type functionality. The documentation covers the Comparable interface for ordering, Countable for position-based arithmetic with overflow handling, Hashable for hash generation, and ToString for string conversion. This resource is designed for Cangjie developers seeking to implement integer operations, comparisons, hashing, and type formatting in their software projects.
