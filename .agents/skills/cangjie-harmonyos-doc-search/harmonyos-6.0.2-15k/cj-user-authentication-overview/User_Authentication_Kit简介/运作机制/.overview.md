# 运作机制

This directory provides a comprehensive technical overview of the operational mechanisms governing the Unified User Authentication Framework. It focuses on the architectural design, security protocols, and trust level classifications essential for building secure authentication systems. Key topics include the definition of Authentication Trust Levels (ATL) based on error rates (FRR, FAR, SAR), the issuance and structure of AuthTokens within a Trusted Execution Environment (TEE), and the integration with the Universal Keystore Service. The documentation addresses the critical balance between user convenience and high-level security, offering guidance for various scenarios ranging from low-risk personalization to high-security payments. This resource is specifically designed for developers, security architects, and system integrators who need to understand the underlying workflows, data structures, and security standards required to implement robust user authorization and key management solutions effectively.

## Detailed Description

The following documents provide in-depth technical specifications regarding the framework's security standards and operational workflows.

### 认证可信等级划分原则.md 认证可信等级划分原则.md
This reference document outlines the principles for classifying Authentication Trust Levels (ATL) based on three key metrics: FRR, FAR, and SAR. It details four distinct levels (ATL1 through ATL4), specifying threshold values for false rejection, false acceptance, and spoof acceptance rates. The content explains the trade-off between security and convenience, providing examples like secure PINs and 3D facial recognition for high-security scenarios like payments, versus voiceprints for lower-risk personalization. This guide serves as a technical specification for developers and security architects designing authentication systems.

### 运作机制_2more.md 运作机制_2more.md
This document outlines the operational mechanism and architecture of the Unified User Authentication Framework. It details the four core components: the unified API, framework layer, authentication controls, and various capabilities like face and fingerprint recognition. Key information includes the workflow where successful authentication triggers the issuance of an AuthToken within a Trusted Execution Environment (TEE). This token authorizes access to the Universal Keystore Service. The document also provides a technical breakdown of the AuthToken data structure, specifying plaintext fields, encrypted user credentials, and integrity tags. Intended for developers and system architects, this reference guide explains how to integrate and utilize the authentication framework for secure user authorization and key management.
