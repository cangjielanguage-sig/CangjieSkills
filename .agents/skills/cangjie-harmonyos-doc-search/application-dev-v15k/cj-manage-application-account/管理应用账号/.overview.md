# 管理应用账号

This directory provides comprehensive resources for managing application accounts using the Cangjie programming language. It covers the full lifecycle of account management, from creating accounts and querying lists to handling secure authorization tokens and credentials. Key topics include utilizing the App Account SDK and BasicServicesKit for data persistence, token access, and account removal. It is specifically designed for application developers who need to implement robust user authentication systems, secure session management, and local data storage within their applications.

## Detailed Description

### 存取账号的授权令牌_2more.md 存取账号的授权令牌_2more.md
This development guide explains how to manage account authorization tokens and delete application accounts using the Cangjie language. The document covers two primary operations: accessing authorization tokens by setting and retrieving them, and removing accounts when users log out. Key information includes code examples demonstrating the use of `setAuthToken`, `getAuthToken`, and `removeAccount` APIs from the BasicServicesKit, along with parameter definitions and error handling. It targets application developers implementing secure token handling and account lifecycle management within their applications.

### 管理应用账号_6more.md 管理应用账号_6more.md
This guide instructs application developers on managing local app account data using the App Account SDK in the Cangjie programming language. It covers development preparation, creating accounts, querying account lists, and managing credentials and custom data storage. Key takeaways include specific API usage for `createAccount`, `getAllAccounts`, `setCredential`, and `setCustomData`, along with important capability limitations regarding data deletion upon app uninstallation. This tutorial targets developers seeking to implement user authentication and data persistence features within their applications.
