This directory provides comprehensive API reference documentation for the HarmonyOS FormKit module, specifically focusing on the `FormBindingData` and `ProxyData` classes within the Cangjie programming language environment. It covers the essential mechanisms for creating and managing data bindings for form cards, including detailed explanations of proxy refreshes, subscription data management, and the handling of complex data types like JSON strings and image resources. Key topics include object instantiation via `createFormBindingData`, property definitions such as `key` and `subscriberId`, and robust error handling for business exceptions. This documentation is primarily suitable for developers building form applications who need to implement dynamic data updates, manage state synchronization, and leverage binding capabilities within the HarmonyOS ecosystem.
