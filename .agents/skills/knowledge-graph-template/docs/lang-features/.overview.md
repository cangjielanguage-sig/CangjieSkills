# lang-features

The `lang-features` directory acts as the central repository for comprehensive documentation on the Cangjie programming language. It encompasses the full spectrum of language capabilities, ranging from fundamental data types and basic programming concepts to advanced features like concurrency, metaprogramming, and foreign function interfaces. This resource is designed for developers of all skill levels, providing essential guides on syntax, compilation, deployment, and network programming. Whether you are writing your first script or building complex systems, this directory offers the technical specifications and practical insights needed to master the Cangjie ecosystem.

## Detailed Description

### Appendix/
This directory serves as a supplementary reference hub for the Cangjie programming language, containing essential technical specifications and guides. It covers a wide range of topics including package compatibility mechanisms, compiler configuration options, and other supplementary details necessary for advanced usage and language compliance.

### Basic_IO/
This directory serves as a comprehensive educational resource for understanding Input/Output (I/O) operations within the Cangjie programming language. It covers the fundamental architecture of I/O streams, including stream abstractions, standardized interfaces, and practical implementations for handling data input and output efficiently.

### FFI/
The FFI directory is a comprehensive technical resource dedicated to the Foreign Function Interface (FFI) capabilities of the Cangjie programming language. It specifically addresses the architectural and practical requirements for achieving robust interoperability between Cangjie code and libraries written in other languages, such as C.

### Macro/
This directory provides a comprehensive guide to the Macro system within the Cangjie programming language. It covers the full spectrum of metaprogramming, ranging from basic concepts and syntax definitions to advanced implementation details and practical use cases for code generation and transformation.

### Net/
The Net directory serves as a comprehensive resource for network programming within the Cangjie language environment. It covers a wide range of topics from fundamental transport layer protocols like TCP and UDP to high-level application layer protocols, enabling developers to build networked applications effectively.

### basic_data_type/
This directory provides a comprehensive guide to the fundamental data types in the Cangjie programming language. It covers essential building blocks such as numeric types (integers, floats), text processing (strings, characters), and logical structures (booleans), forming the basis for data manipulation.

### basic_programming_concepts/
This directory serves as a comprehensive foundational guide to the Cangjie programming language, focusing on the essential building blocks required to write effective and robust code. It covers core concepts such as program structure, identifiers, functions, and control flow mechanisms.

### class_and_interface/
This directory serves as a central hub for object-oriented programming (OOP) concepts within the Cangjie language. It covers the fundamental building blocks of classes, interfaces, and properties, alongside advanced type system features like subtyping, inheritance, and polymorphism.
