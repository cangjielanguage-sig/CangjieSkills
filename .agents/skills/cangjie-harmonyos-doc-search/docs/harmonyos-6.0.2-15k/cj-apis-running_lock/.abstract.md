This directory provides comprehensive API reference documentation for the `ohos.running_lock` module within the Cangjie programming environment. It focuses on power management functionalities, specifically designed to prevent system sleep and control screen states using RunningLocks. The content covers essential module functions, the `RunningLock` class for lock management, and the `RunningLockType` enumeration for defining specific lock types such as proximity control. This resource is suitable for HarmonyOS and Cangjie developers who need to manage device power states, keep the device awake during critical tasks, or implement sensor-based screen control features in their applications. By leveraging these APIs, developers can ensure smooth application performance without unexpected interruptions from the system's power-saving mechanisms, ultimately enhancing the reliability of background processes and user-facing activities.
