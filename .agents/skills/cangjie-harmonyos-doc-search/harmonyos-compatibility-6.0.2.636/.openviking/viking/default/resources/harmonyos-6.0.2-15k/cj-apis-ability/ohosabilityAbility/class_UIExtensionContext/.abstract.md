This directory contains API reference documentation for the Cangjie language focusing on the `UIExtensionContext` class and related ability management functions within the HarmonyOS AbilityRuntime framework. It covers essential operations for managing UI extensions, including launching abilities via `Want` objects or AppLinking, handling asynchronous results, tracking page load completion, and terminating UI extension contexts. Key topics include `openAtomicService`, `startAbility`, `startAbilityForResult`, and lifecycle termination methods. This documentation is intended for HarmonyOS application developers using Cangjie who need to implement complex component interactions, deep linking, and lifecycle management in their applications.
