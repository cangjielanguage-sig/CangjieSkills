# 接口

This directory provides API reference documentation for the Cangjie programming language, focusing on specialized arithmetic interfaces designed to handle integer overflow and power operations. It covers five distinct strategies—Carrying, Checked, Saturating, Throwing, and Wrapping—allowing developers to choose how mathematical operations behave at boundary limits. The content includes detailed specifications for power functions and general integer operations across various data types. This resource is suitable for Cangjie developers, systems programmers, and engineers who require precise control over numerical stability, error handling, and performance-critical computations.

### interface_CarryingPow.md interface_CarryingPow.md
This document provides API reference documentation for the Cangjie `CarryingPow` interface. It details the `carryingPow` function, which performs power operations using a wrapping strategy to handle arithmetic overflow. The function accepts a UInt64 exponent and returns a tuple consisting of a Bool flag indicating whether truncation occurred and the resulting Int64 value. This documentation targets Cangjie developers who need to perform exponentiation while explicitly detecting overflow conditions.

### interface_CheckedPow.md interface_CheckedPow.md
This API reference document defines the Cangjie `CheckedPow` interface, designed to provide a power operation that utilizes an Option return strategy. It describes the `checkedPow` function, which accepts a UInt64 exponent and returns `Option<Int64>`. The function returns `Option<Int64>.None` if the calculation exceeds the limit, rather than causing a runtime error. This document targets developers who need to implement safe arithmetic operations with explicit overflow handling.

This reference is intended for developers implementing mathematical logic that requires robust handling of boundary conditions.
