The `hitrace` directory provides comprehensive documentation for the HiTrace tool, a critical utility for tracking business process call chains and diagnosing cross-device or cross-process faults within the OpenHarmony ecosystem. It covers a wide array of functionalities, including command-line interfaces, trace capture configurations, snapshot mode operations, and performance analysis workflows. Key topics include using the `hdc` shell, managing trace buffer sizes, handling background services, and exporting data for visualization in Smartperf_Host. This resource is specifically suitable for system developers and performance analysts who need to debug complex system interactions, monitor specific subsystems like graphics and power management, and ensure optimal application performance through detailed trace analysis.
