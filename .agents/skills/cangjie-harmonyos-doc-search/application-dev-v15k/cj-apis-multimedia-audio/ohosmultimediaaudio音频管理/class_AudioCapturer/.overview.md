# class_AudioCapturer

This directory contains API reference documentation for the `AudioCapturer` class within the Cangjie programming language's AudioKit framework. It covers comprehensive interfaces for audio capture functionality, including stream management, device configuration, state monitoring, and event handling. Key topics include lifecycle control (start, stop, release), data reading, buffer management, and callbacks for state or device changes. This documentation is suitable for developers building multimedia audio applications who need to implement recording features, manage audio streams, and handle dynamic hardware events in a Cangjie environment.
