This directory serves as a comprehensive guide for implementing application recovery mechanisms to prevent data loss and enhance user experience during unexpected errors. It covers the fundamental principles of state restoration, the default system behavior upon crashes, and the specific technical implementation using the AbilityStage and onSaveState interfaces. Key topics include Application Recovery, State Restoration, Exception Handling, and the AbilityKit framework. This resource is suitable for application developers, particularly those working within the Cangjie language ecosystem, who aim to build resilient applications with robust error handling and seamless data persistence capabilities.
