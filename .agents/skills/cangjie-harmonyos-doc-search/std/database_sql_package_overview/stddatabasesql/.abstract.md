This directory contains the comprehensive documentation for the `stddatabasesql` package, a standard library component for the Cangjie programming language. It acts as a central resource for understanding and implementing database access using SQL/CLI interfaces. The content encompasses the fundamental architecture required for database operations, including driver management, connection handling, and transaction control. A significant focus is placed on the interoperability between SQL data structures and Cangjie type systems, offering detailed mapping tables and conversion rules. This documentation is tailored for Cangjie developers, software architects, and students who need to integrate persistent storage solutions into their applications or contribute to database driver development. Key areas of interest include API references, exception handling mechanisms, and state management enumerations.
