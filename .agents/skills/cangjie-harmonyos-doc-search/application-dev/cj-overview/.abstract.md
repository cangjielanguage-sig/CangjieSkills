This directory functions as a primary entry point for understanding the ArkUI framework's capabilities when used in conjunction with the Cangjie programming language. It offers a detailed introduction to the framework's underlying infrastructure, guiding developers through core architectural principles. Key topics covered include the structure of UI pages, the implementation of routing logic, and the definition of components, which are treated as the smallest indivisible units of user interface construction. A significant focus is placed on the Cangjie-based declarative development paradigm, illustrating how developers can use declarative syntax to streamline the management of components, create smooth animations, and handle application state effectively. This resource is specifically curated for developers who intend to utilize ArkUI's visual development tools combined with the unique features of the Cangjie language to create robust applications.
