# 接口介绍

This directory provides comprehensive technical documentation for the AssetStoreKit framework's API interfaces, specifically focusing on the management, update, and synchronization of critical assets. It covers the definition of asset parameters, attribute structures, security constraints, and data handling rules. Key topics include the `AssetParam` structure, security warnings regarding unencrypted custom data labels, and detailed specifications for storage types such as integrity-protected versus unprotected data. The documentation also highlights important updates regarding byte limits introduced in API 12. This resource is primarily suitable for software developers and engineers responsible for integrating secure asset storage and synchronization features into their applications.

## Detailed Description

### 接口介绍_1.md 接口介绍_1.md
This document serves as a technical reference for the API interface used to update key assets within the AssetStoreKit framework. It details the update function signature, specifically focusing on the AssetParam structure required for both querying and updating attributes. The text outlines the query parameter list and provides a crucial security warning regarding DATA_LABEL attributes, noting that these fields store unencrypted custom business information and must not contain personal data. This guide is intended for developers implementing asset synchronization who need to understand parameter definitions and data handling constraints.

### 接口介绍_2.md 接口介绍_2.md
This document serves as a technical reference defining the attribute parameters for managing critical assets within the AssetStoreKit framework. It details a comprehensive list of properties including unique indexing (ALIAS), access control settings (ACCESSIBILITY, AUTH_TYPE), persistence rules, and synchronization types. Key information includes specifications for custom data labels, distinguishing between integrity-protected (CRITICAL) and unprotected (NORMAL) storage, as well as local-only variants, with size limits updated to 2048 bytes since API 12. Intended for software developers integrating secure asset storage, this guide provides the necessary schema for the attributesToUpdate parameter list.

### 接口介绍_3.md 接口介绍_3.md
This document serves as a reference specification defining attribute parameters for an interface handling critical assets and associated data. It details the structure of the SECRET field, four standard DATA_LABEL_NORMAL fields, four local DATA_LABEL_NORMAL_LOCAL fields, and the REQUIRE_ATTR_ENCRYPTED boolean flag. Key information includes that all fields are optional, with SECRET holding plaintext assets up to 1024 bytes. Data labels allow custom business-defined content without integrity protection; standard labels sync across devices while local labels do not. A specific note highlights that label byte limits increased from 512 to 2048 starting with API12. This technical reference is intended for software developers integrating asset management features into applications using this specific API version.
