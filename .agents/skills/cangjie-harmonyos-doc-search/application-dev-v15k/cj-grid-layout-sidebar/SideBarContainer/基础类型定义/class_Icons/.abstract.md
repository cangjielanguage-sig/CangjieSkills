This directory provides technical documentation for the `Icons` class in the Cangjie language, a crucial component for developers building user interfaces in ArkUI applications. It specifically addresses the representation and management of icon types for sidebar control buttons. The documentation covers the creation and configuration of icon objects through multiple overloaded constructors, utilizing String and AppResource types to define shown, hidden, and switching states. It also outlines system capabilities, version requirements (starting from version 19), and resource error handling strategies. This resource is designed for software developers seeking to implement robust icon state management and handle application resources effectively within their UI components.
