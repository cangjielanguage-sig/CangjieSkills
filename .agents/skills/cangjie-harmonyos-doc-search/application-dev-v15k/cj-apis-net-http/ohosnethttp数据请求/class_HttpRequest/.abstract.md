This directory contains API reference documentation for the `HttpRequest` class within the Cangjie language and NetworkKit framework. It covers the lifecycle management of HTTP tasks, event subscription mechanisms for data and progress updates, and methods for initiating standard and streaming network requests. Key topics include request interruption, unsubscription functions, error handling, and asynchronous callbacks. This documentation is suitable for HarmonyOS and Cangjie developers looking to implement robust network communication, manage streaming data, and handle HTTP exceptions in their applications.
