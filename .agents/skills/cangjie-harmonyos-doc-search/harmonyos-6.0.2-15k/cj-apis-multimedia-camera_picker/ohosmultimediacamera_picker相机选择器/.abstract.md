This directory contains essential API reference documentation for the `ohos.multimedia.camera_picker` module, specifically tailored for the Cangjie programming language within the HarmonyOS development environment. It is designed to assist developers in invoking native system camera capabilities, facilitating seamless photo taking and video recording features within applications. The documentation thoroughly details the primary `pick` function used to launch the camera interface and the `PickerProfile` struct necessary for configuration settings. Key technical information includes parameters for media types, camera position, save URI, and maximum video duration, all of which necessitate a `UIAbilityContext` to execute properly. Furthermore, the documentation outlines system capabilities and version requirements. This resource is highly suitable for HarmonyOS developers who are looking to integrate standard, reliable camera functionality into their applications using the Cangjie programming language.
