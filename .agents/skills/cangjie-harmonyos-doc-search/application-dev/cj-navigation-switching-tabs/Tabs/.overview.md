# Tabs

This directory contains comprehensive documentation for the Tabs component within the ArkUI framework using the Cangjie language. It covers the fundamental implementation of tab-based navigation, including component initialization, property configuration, and event handling. Key topics include the Tabs container, TabContent restrictions, animation settings, and state management via TabsController. The resources also include advanced examples for custom linkages and lazy loading. This documentation is suitable for HarmonyOS developers and software engineers looking to build interactive, multi-view user interfaces with efficient navigation controls.

## Detailed Description

### Tabs_5more.md Tabs_5more.md
This document serves as API reference documentation for the Tabs container component in the ArkUI framework using the Cangjie language. It details the implementation of a container that switches content views through page tabs. Main sections include module imports, child component restrictions, and the component initialization constructor. Key information specifies that the component only supports TabContent, if/else, and ForEach as children, excluding custom components. The init function outlines parameters for bar position, controller, and current index, including specific behaviors regarding animation during tab switching. This guide is intended for developers seeking to implement tab-based navigation interfaces in Cangjie applications.

### 组件事件_2more.md 组件事件_2more.md
This document serves as an API reference for handling tab component events and control within the Cangjie language for ArkUI development. It details the onChange callback function, which triggers when a tab index changes, and the TabsController class used to manage tab state. Key information includes the onChange function accepting a callback with the new index and the TabsController providing a changeIndex method to programmatically switch tabs. The content targets HarmonyOS developers seeking to implement interactive tab switching logic and control mechanisms in their user interfaces.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring the properties of the Tabs component within the Cangjie ArkUI framework. It details six primary configuration functions: animationDuration, barHeight, barMode, barWidth, scrollable, and vertical. Key information includes parameter types such as Length and BarMode, default values, and specific behaviors for horizontal versus vertical layouts. All methods utilize a builder pattern, returning the component instance to allow chaining. The target audience is software developers using the Cangjie language to construct user interfaces, specifically requiring knowledge of ArkUI components and version 22 system capabilities.

### 示例代码/
