# 断言

This directory provides comprehensive documentation for implementing assertions within the Cangjie testing framework. It covers essential testing mechanisms including standard behavior verification, explicit failure handling, and exception validation. Key topics include the distinction between fail-fast (`@Assert`, `@Fail`) and continuation-based (`@Expect`, `@FailExpect`) strategies, as well as approximate equality comparisons via the `NearEqutable` interface. This resource is designed for Cangjie developers seeking to write robust unit tests with precise control over execution flow, error reporting, and floating-point arithmetic validation.

## Detailed Description

### 失败断言.md 失败断言.md
This document serves as a technical reference for implementing failure assertions within the Cangjie testing framework. It covers the `@Fail` and `@FailExpect` macros, explaining their distinct behaviors regarding test execution flow. Key takeaways include that `@Fail` employs a fast-fail mechanism, halting the test immediately and returning `Nothing`, while `@FailExpect` marks the test as failed but allows subsequent checks to run, returning `Unit`. Both macros accept a string parameter to describe the failure reason. The document includes a code example demonstrating usage in a validation function. This guide is intended for Cangjie developers writing unit tests who need to control test failure behavior and error reporting.

### 断言.md 断言.md
This document serves as a guide for using assertions within Cangjie unit tests to verify code behavior. It distinguishes between two assertion macros, @Expect and @Assert, demonstrating their execution flow through code examples. The critical distinction is that @Assert employs a fail-fast mechanism, halting execution upon the first failure, whereas @Expect continues to evaluate all checks to provide comprehensive feedback. It also details syntax for equality and boolean assertions. Targeted at Cangjie developers, this guide helps users select the appropriate assertion type based on whether they need immediate error detection or a full report of test failures.

Keywords: Cangjie, unit testing, assertions, @Assert, @Expect, fail-fast, Equatable

### 预期异常的断言.md 预期异常的断言.md
This document serves as a technical reference for implementing exception assertions and approximate equality comparisons within the Cangjie unit testing framework. It covers the usage, syntax, and return types of the `@AssertThrows` and `@ExpectThrows` macros, distinguishing their behavior when expected exceptions are not thrown. Additionally, it explains the `NearEqutable` interface for handling approximate comparisons, such as floating-point arithmetic, using delta parameters. Key takeaways include understanding the different return types for single versus multiple exception specifications and how to implement custom approximate equality logic. This guide is intended for developers writing robust unit tests in Cangjie who require precise control over exception validation and non-exact value matching.
