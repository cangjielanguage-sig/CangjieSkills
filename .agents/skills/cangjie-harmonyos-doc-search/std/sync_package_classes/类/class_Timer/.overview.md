# class_Timer

This directory contains API reference documentation for the Cangjie `Timer` class, a component of the `std.sync` package designed for scheduling tasks. It covers the creation, management, and cancellation of single and repeated executions. Key topics include static methods for scheduling (`after`, `once`, `repeat`, `repeatDuring`, `repeatTimes`), lifecycle control, and object comparison. The documentation details critical behaviors such as implicit thread spawning, garbage collection implications, and catchup strategies for handling delays. This resource is suitable for Cangjie developers implementing asynchronous operations, concurrency, and time-based logic.

### class_Timer.md class_Timer.md
This document provides API reference documentation for the Cangjie Timer class, which enables scheduling tasks for single or repeated execution at specific times or intervals. The content details the class definition, inheritance from Equatable and Hashable, and critical behavioral notes. Key information highlights that Timers implicitly spawn threads, bind tasks permanently upon initialization, and prevent garbage collection until tasks finish or are cancelled. It also warns that timing is not strictly precise and uncaught exceptions invalidate the timer. This resource is intended for Cangjie developers managing asynchronous operations and concurrency.
