# List

This directory provides comprehensive documentation for the ArkUI List component within the Cangjie framework. It covers the full lifecycle of list implementation, from component creation and configuration to handling complex events and managing scroll behaviors. Resources include API references for attributes and events, foundational type definitions, and practical code examples. Designed for UI developers and software engineers, this collection ensures the effective development of dynamic, high-performance, and interactive list interfaces in HarmonyOS applications.

### List_2more.md List_2more.md
This API reference document defines the List component, a container designed for displaying uniform-width list items such as images and text in a continuous, multi-line format. It covers supported child components, specifically ListItem and ListItemGroup, and rendering control mechanisms like if/else and ForEach. The document provides critical technical details on index calculation rules, explaining how conditional rendering, grouping, and visibility properties affect the sequential indexing of child nodes. Targeted at UI developers using this framework, it ensures accurate implementation of list layouts and data state management.

### 创建组件.md 创建组件.md
This API reference document details the constructors for creating a List container component within the Cangjie ArkUI framework. The content covers two initialization methods: a standard version and an extended version that includes a scroller controller. Key parameters include space for item spacing, initialIndex for the starting view position, and scrollerEx for scroll control. The documentation specifies constraints, such as invalid values for space and index, and restrictions on binding the scroller to multiple components. Intended for developers building UI applications, this guide provides the necessary syntax and parameter definitions to implement scrollable lists effectively.
