This directory provides the essential API reference documentation for generic digest functions within the Cangjie standard library's crypto package. It is designed to assist developers in performing secure hash computations across a variety of data sources, including byte arrays, input streams, and strings. The documentation highlights the use of generics constrained by the `Digest` interface to return `Array<Byte>` results. It also addresses specific function overloads and deprecations, ensuring developers are aware of the current best practices. This resource is essential for Cangjie developers implementing cryptographic hashing solutions, requiring a solid understanding of generics, interfaces, and IO stream handling to effectively utilize the provided code examples and technical specifications.
