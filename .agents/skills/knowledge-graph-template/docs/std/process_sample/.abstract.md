This directory provides a comprehensive practical code example demonstrating arbitrary process management operations within the Cangjie programming language. It primarily focuses on utilizing the `std.process` library to effectively interact with system processes. Key topics covered include launching a subprocess using the `launch` function, locating a specific process by its PID with `findProcess`, accessing detailed process metadata such as name and command, and forcefully terminating a process. The example highlights the complete workflow from process creation to destruction. It is important to note that these specific operations are not supported on the Windows platform. This guide is specifically suitable for Cangjie developers seeking to implement robust system-level process control within their applications.
