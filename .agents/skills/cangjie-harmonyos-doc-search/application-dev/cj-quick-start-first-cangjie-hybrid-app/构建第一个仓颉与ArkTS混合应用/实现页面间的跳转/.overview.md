# 实现页面间的跳转

This directory provides comprehensive technical guidance on implementing page navigation within HarmonyOS applications that utilize a hybrid architecture of ArkTS and Cangjie. It specifically addresses the interoperability challenges between ArkTS and Cangjie routers, which are not natively compatible. The content covers essential workflows such as navigating from an ArkTS page to a mixed page, handling complex return logic, and registering callback functions for cross-language communication. Key technical concepts include the `@Interop[ArkTS]` macro, `.d.ts` interface generation, and the `registerJSFunc` mechanism. These resources are tailored for developers working on cross-language integration who need to master routing and function invocation in mixed environments.

## Detailed Description

### 实现页面间的跳转_1.md
This tutorial guides developers on implementing page navigation between ArkTS and Cangjie mixed pages in HarmonyOS. It covers jumping from an ArkTS page to a mixed page using the router module and details the complex process of returning to the ArkTS page. Since Cangjie and ArkTS routers are not interoperable, the document explains how to use the @Interop[ArkTS] macro to register ArkTS routing functions for Cangjie to invoke. Key steps include writing Cangjie code for function registration and generating the necessary .d.ts interface file. This guide is intended for developers working with ArkTS and Cangjie interoperability.

### 实现页面间的跳转_2.md
This tutorial explains how to implement page navigation from a Cangjie component back to an ArkTS page in a hybrid application. It covers configuring project dependencies, registering an ArkTS callback function using registerJSFunc to handle the router.back logic, and embedding the Cangjie view via CJHybridComponent. The document details the Cangjie implementation where a button click triggers the registered function using globalJSFunction.get. Key takeaways include the mechanism for cross-language function registration and invocation. This guide targets developers integrating Cangjie and ArkTS, requiring knowledge of both languages and hybrid project structures.
