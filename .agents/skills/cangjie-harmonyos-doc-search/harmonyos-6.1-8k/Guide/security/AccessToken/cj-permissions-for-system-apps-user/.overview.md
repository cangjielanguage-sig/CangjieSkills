# cj-permissions-for-system-apps-user

本目录详细阐述了系统应用中涉及用户隐私且必须经过用户显式授权的敏感权限集合。内容重点覆盖了日历数据的读写访问、设备上已安装应用列表的获取、通话的接听与管理、通话记录的读写操作，以及短信和彩信的收发功能。这些权限均被定义为 system_basic 级别，要求应用通过 user_grant 模式进行动态授权，并支持 ACL（访问控制列表）机制以实现跨级别权限申请。该文档适用于 API 版本 12 及以上的开发环境，专门面向 APL（应用特权等级）为 system_basic 及以上的应用开发者，旨在协助开发者准确判断目标权限的申请资格，并规范其授权流程，确保应用在合规的前提下获取必要的系统能力。

## Detailed Description

### cj-permissions-for-system-apps-user.md

本文档列出了需要用户授权的系统应用可用权限。涵盖日历读写、已安装应用列表读取、通话接听与管理、通话记录读写以及短信和彩信的收发等敏感权限。所有权限均为 system_basic 级别，需通过 user_grant 方式授权，支持 ACL 跨级别申请，起始版本为 12。面向 APL 等级为 system_basic 及以上的应用开发者，旨在帮助其判断目标权限的申请资格及授权流程。
