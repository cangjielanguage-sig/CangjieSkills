This directory provides comprehensive documentation and examples for the Cangjie programming language's Deriving feature, specifically focusing on the `@Derive` macro. It covers automatic interface implementation for classes and enums, including syntax rules, field collection, and advanced customization using attributes like `@DeriveInclude` and `@DeriveOrder`. Additionally, it addresses handling generic types and constraints. The content is designed for Cangjie developers looking to reduce boilerplate code and automate the implementation of common interfaces such as `ToString`, `Hashable`, and `Equatable` while maintaining runtime performance.
