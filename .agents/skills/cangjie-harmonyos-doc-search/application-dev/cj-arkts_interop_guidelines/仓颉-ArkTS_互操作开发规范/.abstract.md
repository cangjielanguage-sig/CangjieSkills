This directory contains the development standards and technical guidelines for interoperability between the Cangjie language and ArkTS in HarmonyOS. It covers critical aspects such as threading models, memory management, exception handling, and object lifecycle management. Key topics include main thread restrictions, JSRuntime usage, cross-engine context safety, and preventing memory leaks. These documents are essential for HarmonyOS developers and system engineers working on native-script integration to ensure application stability and performance.
