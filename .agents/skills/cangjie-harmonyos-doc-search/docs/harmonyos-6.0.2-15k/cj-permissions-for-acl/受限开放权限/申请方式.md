## 申请方式

当前仅少量符合特殊场景的应用可在通过审批后，使用受限权限，其申请方式请参见：[申请使用受限权限](./cj-declare-permissions-in-acl.md)。

> **说明：**
>
> 如果应用涉及获取受限权限，在应用发布上架时，应用市场（AGC）将根据应用的使用场景审核是否可以使用对应的受限权限。如不符合，应用的上架申请将被驳回，审核方式请参见[发布HarmonyOS应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-harmonyos-releaseapp-0000001914554900#section8176625125714)。
