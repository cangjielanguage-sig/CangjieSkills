# cj-l10n-translation-scene

本目录包含关于本地化翻译场景的指导文档，核心目标是解决因语境缺失或理解偏差导致的翻译质量问题。文档深入探讨了如何为翻译团队提供精准的场景信息，重点涵盖了两种主要实现方式：一是在字符串资源文件中编写详尽的代码注释，涵盖上下文背景、词性界定、UI控件长度限制以及变量具体含义；二是提供直观的界面截图作为视觉参考。该指南强调了完整场景信息对于确保翻译准确性和专业性的决定性作用。内容主要面向开发人员、本地化工程师及项目负责人，适用于界面字符串资源交付翻译的具体工作流，是提升本地化效率与质量的必备最佳实践指南。

### cj-l10n-translation-scene.md cj-l10n-translation-scene.md

本文档是一份本地化最佳实践指南，旨在指导相关人员如何为翻译提供准确的场景信息，从而有效避免因语境差异导致的翻译偏差。文档内容主要涵盖了两种提供场景信息的具体方式：
1.  **资源文件注释**：详细说明了在字符串资源文件中应包含的注释内容，如上下文环境、词性说明、控件长度限制以及变量含义等。
2.  **视觉辅助**：强调了提供界面截图对于翻译人员理解布局和语境的重要性。

文档的核心要点在于强调完整场景信息对保证翻译质量的关键作用。该文档主要面向开发人员或本地化负责人，特别适用于界面字符串交付翻译的场景。
