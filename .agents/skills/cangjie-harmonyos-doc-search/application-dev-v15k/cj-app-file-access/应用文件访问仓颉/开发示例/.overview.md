# 开发示例

This directory serves as a comprehensive resource for developers working with the Cangjie programming language within the HarmonyOS ecosystem, specifically focusing on file system interactions and data persistence. It provides a collection of practical code examples and tutorials designed to guide developers through the complexities of file input and output (I/O) operations. The content covers a broad spectrum of tasks, ranging from basic file creation and data copying to advanced stream-based processing and file filtering. Key technical concepts explored include the utilization of the CoreFileKit and FileFs interfaces, the configuration of OpenMode flags, buffer management using Array<Byte>, and the implementation of ListFileOptions for filtering. These resources emphasize critical best practices such as closing streams to prevent resource leaks and correctly handling file offsets. The material is intended for application developers who possess a foundational understanding of the UIAbility context and are seeking to implement robust, efficient file management features in their applications.

## Detailed Description

The following documents provide in-depth technical details and code examples for the scenarios outlined above.

### 以流的形式读写文件_2more.md
This document provides Cangjie code examples for performing file operations using the CoreFileKit. It covers reading and writing files via stream interfaces and listing files with specific filtering options. Key takeaways include the implementation of buffered stream copying, the importance of closing streams to prevent resource leaks, and the configuration of ListFileOptions for filtering files by suffix, name, or size. Intended for application developers, this guide assumes knowledge of the UIAbility context and basic file system concepts.

### 开发示例_3more.md
This tutorial provides Cangjie code examples for performing file input and output operations within a HarmonyOS application context. The document covers two primary scenarios: creating a new file to write and read data, and copying content from a source file to a destination file. Key takeaways include the usage of the FileFs interface, OpenMode flags, and buffer management using Array<Byte>. It also emphasizes the importance of handling file offsets correctly during read/write operations. This guide is intended for developers who have already obtained the UIAbility context and application file paths.
