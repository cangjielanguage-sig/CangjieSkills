## Detailed Description

### class_HardLink.md
This document serves as API reference documentation for the HardLink class in the Cangjie programming language, detailing interfaces for managing file system hard links. The content covers the class definition and two overloaded static methods named create, which accept either Path objects or String arguments. Key information includes the functionality to create new hard links pointing to existing paths without overwriting existing files, along with specific parameter definitions and exception handling for invalid arguments or file system failures. This reference is intended for software developers implementing file system operations who need to understand the syntax, parameters, and error handling associated with hard link creation.

### class_SymbolicLink.md
This document serves as API reference documentation for the Cangjie language's SymbolicLink class, designed to handle filesystem symbolic links. The content covers two primary static functions: create and readFrom, both overloaded to support Path and String types. The create function establishes a new link to a target path, noting specific Windows behavior regarding non-existent targets. The readFrom function retrieves the target, with an option to recursively resolve the final path. Key details include parameter definitions, return values, and exceptions like IllegalArgumentException and FSException. This documentation targets Cangjie developers performing file system operations, requiring an understanding of path handling and error management.

### class_Directory/
This directory contains comprehensive API reference documentation for the `Directory` class within the Cangjie programming language's file system package. It covers essential operations for managing directories, including creating standard and temporary directories, checking if a directory is empty, reading directory contents, and performing non-recursive traversal. The documentation details static methods, function overloading for `Path` and `String` inputs, and exception handling for file system errors. It is suitable for software developers integrating file system management, directory creation, and content inspection into their Cangjie applications, providing the necessary syntax and parameter details for effective implementation.

### class_File/
This directory contains API reference documentation for the Cangjie programming language's `File` class and associated file system utilities. It covers comprehensive file I/O operations, including class definitions, inheritance structures, resource management, and static helper functions for reading, writing, and manipulating files. Key topics include file descriptors, stream handling, path operations, and exception handling for file system errors. This documentation is suitable for Cangjie developers and software engineers looking to implement low-level file system interactions, manage file resources, or perform data persistence operations within their applications.
