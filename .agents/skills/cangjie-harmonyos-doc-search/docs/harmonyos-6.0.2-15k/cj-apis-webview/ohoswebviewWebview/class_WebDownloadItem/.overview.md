# class_WebDownloadItem

This directory contains API reference documentation for the `WebDownloadItem` class in the Cangjie programming language, part of the HarmonyOS ArkWeb framework. It covers the management of web download tasks, including lifecycle control (start, pause, resume, cancel), status monitoring (progress, speed, state), and metadata retrieval (URL, MIME type, file path). The documentation includes methods for serialization and deserialization to handle task resumption. It is intended for HarmonyOS developers building web applications who need granular programmatic control over file downloads within web view components.

## Detailed Description

### class_WebDownloadItem_2more.md
API reference for `WebDownloadItem` and `deserialize`. Details class definition, system capabilities, and converting byte arrays back to objects for task resumption. Includes code examples for lifecycle events.

### func_cancel.md
API reference for `cancel()` to abort active downloads. Outlines signature, capabilities, and v19 compatibility, with examples of capturing `WebDownloadItem` and invoking cancel in UI handlers.

### func_getCurrentSpeed.md
API reference for `getCurrentSpeed` to retrieve download speed (Int64). Covers signature, capabilities, v19+ requirements, and usage within `WebDownloadDelegate` to monitor performance.

### func_getFullPath_2more.md
API reference for `getFullPath` (disk path) and `getGuid` (unique ID). Both return String, require `SystemCapability.Web.Webview.Core` (v19+), with usage examples in delegate callbacks.

### func_getLastErrorCode.md
API reference for `getLastErrorCode` to retrieve error codes on failure. Covers signature, capabilities, return type `WebDownloadErrorCode`, and usage in failure handlers for logging errors.

### func_getMethod.md
API reference for `getMethod` to retrieve the HTTP request method. Details signature, return value (String), and v19+ compatibility, with delegate implementation examples.

### func_getMimeType.md
API reference for `getMimeType` to retrieve file media type (String). Covers signature, capabilities, v19+ requirements, and usage in identifying content types before download.

### func_getPercentComplete.md
API reference for `getPercentComplete` to retrieve progress (Int64). Covers signature, capabilities, v19+ requirements, and usage in delegate callbacks for tracking completion.

### func_getReceivedBytes.md
API reference for `getReceivedBytes` to count bytes received. Details signature, capabilities, v19+ requirements, and usage in `onDownloadUpdated` for progress tracking.

### func_getState.md
API reference for `getState()` to retrieve operation status. Covers signature, capabilities, return type `WebDownloadState` (e.g., IN_PROGRESS), and usage in checking status within callbacks.

### func_getSuggestedFileName_2more.md
API reference for `getSuggestedFileName()` (default name) and `getTotalBytes()` (file size). Details signatures, return types, v19+ requirements, and usage in delegate callbacks.

### func_getUrl.md
API reference for `getUrl` to retrieve the request address. Covers signature, return value (String), capabilities, and v12+ requirements, with usage examples in logging.

### func_pause.md
API reference for `pause()` to pause active tasks. Covers signature, capabilities, v19+ requirements, and exception handling (e.g., error 17100019), with lifecycle code examples.

### func_resume.md
API reference for `resume()` to resume paused tasks. Details signature, capabilities, v19+ requirements, and exception handling (e.g., error 17100016), with UI context examples.

### func_serialize.md
API reference for `serialize()` to convert failed tasks to byte arrays. Covers signature, capabilities, v19+ requirements, and usage in `onDownloadFailed` for task persistence.

### func_startString.md
API reference for `start` to initiate downloads via a file path. Details signature, parameters, and the requirement to call within `onBeforeDownload` to transition from PENDING state.
