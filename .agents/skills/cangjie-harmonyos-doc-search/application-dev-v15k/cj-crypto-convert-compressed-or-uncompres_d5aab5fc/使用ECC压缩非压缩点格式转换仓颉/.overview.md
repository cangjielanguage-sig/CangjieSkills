# 使用ECC压缩非压缩点格式转换仓颉

This directory provides technical resources for developers working with Elliptic Curve Cryptography (ECC) in the Cangjie programming language. It focuses on the conversion between compressed and uncompressed point data formats using the CryptoArchitectureKit. The documentation covers essential operations such as generating point objects from byte arrays, retrieving encoded data, and creating public key objects from specific curve parameters like `NID_brainpoolP256r1`. These guides are suitable for Cangjie developers and cryptographic engineers looking to implement secure key generation and data transformation mechanisms.

## Detailed Description

### 使用ECC压缩非压缩点格式转换仓颉_2more.md
This technical guide explains how to convert between compressed and uncompressed ECC point data formats using the Cangjie programming language. It covers the general conversion capabilities and provides a specific tutorial on converting uncompressed point data to compressed format. Key information includes the use of `ECCKeyUtil.convertPoint` to generate point objects from byte arrays and `ECCKeyUtil.getEncodedPoint` to retrieve data in "COMPRESSED" or "UNCOMPRESSED" formats. The document includes a Cangjie code example demonstrating the process for the `NID_brainpoolP256r1` curve. This is intended for developers using the CryptoArchitectureKit who need to handle ECC key generation and data transformation.

### 指定压缩点数据获取密钥对象.md
This document serves as a technical tutorial demonstrating how to generate an ECC public key object from compressed point data using the CryptoArchitectureKit. The content outlines a sequential process involving data conversion via convertPoint, parameter specification for the 'NID_brainpoolP256r1' curve, and key generation using createAsyKeyGeneratorBySpec. Key takeaways include the construction of ECCPubKeySpec and methods to retrieve uncompressed point data and X coordinates. Intended for Cangjie developers, this guide requires familiarity with cryptographic concepts and API usage for implementing secure key management solutions.
