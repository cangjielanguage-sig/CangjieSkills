This directory contains API documentation and resources for the `ohos.matrix4` module within the HarmonyOS ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of 4x4 matrix transformations used for manipulating UI component geometry, including scaling, rotation, translation, and perspective projection. The content includes class definitions for matrices, points, and transformation options, alongside advanced manipulation functions and practical code examples. It is suitable for software developers and UI engineers looking to create complex 2D or 3D visual effects and dynamic layouts in HarmonyOS applications.
