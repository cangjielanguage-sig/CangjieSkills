This directory contains API reference documentation for the ArkUI framework, specifically focusing on the initialization and configuration of alert dialogs and popup components using the Cangjie language. It covers the constructor function signature, system capabilities, and extensive parameter lists for customizing content, layout, behavior, and visual styling. Key topics include modal behavior control, background effects, border styling, and transition animations. This documentation is suitable for software developers and UI designers building interactive user interfaces who need to implement configurable and aesthetically pleasing dialog windows in their applications.
