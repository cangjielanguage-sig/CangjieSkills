This directory contains API reference documentation for the Cangjie `PermissionRequestResult` class, a critical element for developers building applications on the HarmonyOS platform using the AbilityKit. The documentation focuses on the data structure used to encapsulate the results of system permission requests, providing a clear blueprint of the class's internal architecture. It thoroughly explains the three public properties: `permissions` (the list of requested permissions), `authResults` (the status codes indicating access status), and `dialogShownResults` (reflecting whether the system dialog was displayed). Additionally, the document provides a detailed breakdown of the integer values used within `authResults`, allowing developers to distinguish between successful grants, denials, and invalid request scenarios. This resource is tailored for HarmonyOS developers who need to manage application context and enforce secure user authorization protocols. Prerequisites include familiarity with the HarmonyOS application context and the AbilityKit framework.
