This directory contains API reference documentation for the `System` class within the Cangjie LocalizationKit. It focuses on internationalization (I18n) capabilities, enabling developers to retrieve and configure system localization settings. The documentation covers static methods for accessing language preferences, regional configurations, display names for countries and languages, and system formats like time and digits. It is suitable for Cangjie developers implementing localization features who need to handle text formatting, user preferences, and error management in their applications.
