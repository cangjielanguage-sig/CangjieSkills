# 创建列表List

This directory contains a comprehensive collection of development guides for creating and managing List components using the Cangjie language and ArkUI framework. It covers fundamental concepts like component structure and layout constraints, as well as advanced features including grouped lists, sticky headers, and scroll position control. Developers will also find tutorials on performance optimization, custom styling, and interactive elements such as swipe actions and pull-to-refresh. These resources are designed for UI developers and application engineers building efficient, scrollable interfaces for HarmonyOS applications.

### 响应列表项侧滑_3more.md 响应列表项侧滑_3more.md

It covers three main topics: implementing swipe-to-delete actions using the ListItem swipeAction property, adding notification badges using the Badge component, and handling pull-to-refresh and load-more functionalities via touch events. Key takeaways include code examples for binding custom delete buttons to swipe actions, configuring badge styles and positions, and monitoring touch gestures to trigger data updates. The document recommends using the Refresh component for standard refresh scenarios. This tutorial targets mobile application developers seeking to enhance user experience with standard UI patterns like deletion, notifications, and data loading.

### 布局与约束.md 布局与约束.md
This technical guide explains the layout mechanisms and size constraints of the List component within a UI framework. It covers the component hierarchy involving List, ListItemGroup, and ListItem, alongside layout capabilities for vertical and horizontal scrolling in single or multi-column configurations. Key information includes definitions of main and cross axes, and specific rules governing how List dimensions adapt based on parent and child component sizes. The document details scenarios where the List size adjusts to fit content or fills the parent container. It also recommends using List over Grid or WaterFlow for simple, equal-width layouts. Intended for UI developers, this guide assists in designing efficient, adaptive scrollable interfaces.

### 控制滚动位置_2more.md 控制滚动位置_2more.md

This tutorial targets application developers familiar with ArkUI components who need to implement advanced list interactions like "back to top" or alphabetical indexing.

### 概述.md 概述.md
This document provides an overview of the List component, defining it as a complex container capable of automatic scrolling for displaying large volumes of similar data types. Main topics include the component's use cases like contact lists, its structural composition using List, ListItemGroup, and ListItem, and various rendering control methods such as conditional rendering, loop rendering (ForEach), and lazy loading. Key information highlights that the List component supports vertical or horizontal linear arrangement of child components and allows mixing single views with iterative structures to build efficient, scrollable interfaces. Intended for UI developers, this guide serves as a conceptual foundation for implementing structured data displays in applications, linking to specific API references for further details.
