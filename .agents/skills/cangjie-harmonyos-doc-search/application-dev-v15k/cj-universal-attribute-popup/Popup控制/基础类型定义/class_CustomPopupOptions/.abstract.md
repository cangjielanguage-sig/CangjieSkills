This directory contains API reference documentation for the `CustomPopupOptions` class within the Cangjie ArkUI framework. It focuses on defining configuration parameters for custom popup windows, covering visual styling, positioning, interaction logic, and event handling. Key topics include arrow customization, focus behavior, spacing, animation effects, and lifecycle management. These resources are designed for developers using the Cangjie language to build ArkUI interfaces, providing the necessary details to implement and customize popup components effectively in their applications.
