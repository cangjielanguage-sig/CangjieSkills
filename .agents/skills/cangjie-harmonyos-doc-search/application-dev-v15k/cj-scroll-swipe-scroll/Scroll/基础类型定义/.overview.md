# 基础类型定义

This directory contains API reference documentation for fundamental scrolling types and classes in the Cangjie ArkUI framework. It covers essential components for controlling scrollable containers, including animation parameters, scroller controllers, and snap options. Key topics include scroll physics, edge effects, lifecycle binding, and pagination logic. This documentation is suitable for ArkUI developers and software engineers who need to implement precise scrolling behaviors, custom animations, and navigation logic in UI applications using Cangjie.

## Detailed Description

### class_ScrollAnimationOptions.md class_ScrollAnimationOptions.md
This document provides API reference documentation for the Cangjie class ScrollAnimationOptions, which defines parameters for customizing scroll animations. It covers the class properties including duration, curve, and canOverScroll, specifying their types and read-write capabilities. The documentation also details the constructor, which initializes these options with defaults like a 1000.0ms duration and Curve.Ease. A critical note specifies that canOverScroll only activates when the component's edge effect is set to EdgeEffect.Spring. Intended for ArkUI developers, this guide helps configure scroll physics and animation timing within the system capability framework starting from version 19.

### class_Scroller_3more.md class_Scroller_3more.md
This document provides API reference documentation for the Cangjie language, detailing the Scroller class used to control scrollable containers in ArkUI. It covers the Scroller controller, the OffsetResult struct for tracking scroll offsets, and the ScrollAlign enum for defining item alignment behaviors like START, CENTER, and AUTO. Key information includes the binding lifecycle, where the controller is functional only after the component's onAppear event, and supports containers like List and Grid. The document is intended for developers familiar with ArkUI component lifecycles who need to implement precise scrolling control in their applications.

### class_BaseScroller/
This directory contains API reference documentation for the BaseScroller class and related scrolling functions within the Cangjie ArkUI framework. It covers the core functionality required to programmatically control scrolling behaviors in UI components such as List, Grid, WaterFlow, and Scroll. Key topics include the BaseScroller class properties, methods for relative and absolute positioning, index-based navigation, and animation controls. This documentation is suitable for developers building UI applications in Cangjie who need to implement precise scroll manipulation, query component states, or handle fling and edge navigation logic.

### class_ScrollSnapOptions/
This directory contains comprehensive API documentation for the `ScrollSnapOptions` class used in the Cangjie language and ArkUI framework. It focuses on the configuration of scroll snapping behavior, enabling developers to define precise pagination and alignment rules for scrollable components. Key topics include setting alignment modes, defining pagination sizes using Length values, and controlling boundary behaviors such as snapping to the start or end. This documentation is essential for UI developers and software engineers aiming to create polished, user-friendly scrolling interfaces with controlled navigation logic.
