# 兼容性说明

This directory provides detailed API references and compatibility notes for process management classes within the system. It specifically addresses the transition from the deprecated `CurrentProcess` class to the modern `SubProcess` and `Process` classes. The documentation covers a wide range of functionalities, including environment variable manipulation, standard stream handling, and process lifecycle management (creation, execution, termination). A significant focus is placed on cross-platform compatibility, explicitly detailing support for Linux, Windows, and macOS, and noting platform-specific restrictions. This resource is essential for developers who need to integrate system-level process control into their applications while maintaining code portability and adhering to the latest API standards.

## Detailed Description

### class_CurrentProcess_supde_2more.md class_CurrentProcess_supde_2more.md
This document serves as an API reference for process management classes, specifically detailing the deprecated CurrentProcess class and the active SubProcess class. The content lists members such as environment variables, standard streams, and exit handling for CurrentProcess, alongside stream pipes and waiting functions for SubProcess. Key information includes the deprecation of CurrentProcess in favor of std.env and the replacement of specific stream properties with pipe variants in SubProcess. All listed members support Linux, Windows, and macOS platforms. This reference is intended for developers seeking to manage system processes, handle environment variables, or control child process execution within their applications.

### class_Process.md class_Process.md
This document provides an API reference overview for the Process class, listing its members and their compatibility across Linux, Windows, and macOS. The content is organized into a table categorizing properties and static methods, highlighting platform support and deprecation status for various functions like process creation, execution, and termination. Key takeaways include the widespread deprecation of legacy methods such as start and run, while core properties like pid and name remain active. Platform-specific limitations are explicitly noted, such as environment variables being supported only on Linux. Intended for developers seeking to manage system processes, this reference requires understanding of process management concepts and serves as a navigation hub for detailed implementation guides.
