## Detailed Description

### class_JsonWriter_9more_2a494ecc.md
这是一份仓颉语言中 JsonWriter 类的 API 参考文档，旨在说明如何将对象序列化为 JSON 并写入输出流。文档详细列出了类的构造函数、配置属性 writeConfig 以及构建 JSON 结构的核心方法，包括 startObject、endObject、startArray、endArray 和 flush。关键要点在于 JsonWriter 采用缓存机制，使用结束前必须调用 flush 确保数据写入，且需配合 JsonSerializable 接口使用。此外还介绍了写入原始字符串的 jsonValue 方法。该文档面向需要进行流式 JSON 编码的开发者。

### func_writeNameStr_3more_ea45a901.md
这份文档是Cangjie语言中JsonWriter类的API参考说明，详细阐述了用于流式写入JSON数据的三个关键函数。主要内容包括在对象结构中写入名称、写入JSON空值以及写入实现了JsonSerializable接口的泛型值。文档重点指出这些函数均返回当前JsonWriter引用以支持链式调用，并在状态非法时抛出IllegalStateException异常。此外，还说明了writeValue函数已为基础类型和集合类型扩展了序列化支持。该文档面向使用json.stream包进行数据编码的开发者，要求其具备基本的JSON结构理解。
