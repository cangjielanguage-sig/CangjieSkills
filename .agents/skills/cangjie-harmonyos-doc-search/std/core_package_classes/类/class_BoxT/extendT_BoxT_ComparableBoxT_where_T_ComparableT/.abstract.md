This directory serves as a comprehensive technical resource for Cangjie developers, containing API documentation that extends the generic `Box` class with full comparison capabilities. The primary focus is on implementing the `Comparable` interface and overloading relational operators, which are conditional on the encapsulated type `T` satisfying the `Comparable` constraint. The documentation thoroughly explains the `compare` function, the resulting `Ordering` enum, and the syntax for various operators including inequality and less-than comparisons. By providing these extensions, the directory enables developers to perform essential operations such as sorting and logical evaluation on boxed data types. This reference material is crucial for anyone working with generic types in Cangjie, ensuring that boxed objects can be compared seamlessly and efficiently while maintaining strict type safety and delegating logic to the underlying instances.
