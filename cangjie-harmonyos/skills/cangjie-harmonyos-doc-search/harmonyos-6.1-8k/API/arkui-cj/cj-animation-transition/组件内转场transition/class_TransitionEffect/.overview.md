## Detailed Description

### class_TransitionEffect.md class_TransitionEffect.md
本文档定义了ArkUI中的TransitionEffect类，用于以函数形式指定组件的转场效果类型。主要内容包括类属性（如IDENTITY、OPACITY、SLIDE）及详细说明，涵盖动画参数优先级、效果组合、默认行为及子树删除时的转场处理。关键信息包括动画参数的生效顺序、动画作用域内默认透明度转场的机制，以及使用IDENTITY禁用转场的方法。这是一份API参考文档，面向ArkUI开发者，需了解基础动画和组件生命周期概念。
