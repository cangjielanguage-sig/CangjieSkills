# cj-errorcode-universal

本目录提供了API调用过程中通用错误码的详细定义文档，旨在协助开发者快速定位并解决权限验证、参数传递及设备兼容性等方面的故障。文档内容覆盖了权限校验失败（如错误码201/202）、参数检查失败（如错误码401）以及设备能力不支持（如错误码801）等关键类别。通过列举具体的错误信息、潜在成因及建议的处理步骤，该文档深入解析了非系统应用违规调用系统API、必填参数缺失及系统能力（SysCap）受限等典型场景。本资源主要面向应用开发人员，是进行API调试和故障排查时不可或缺的参考指南。

### 详细描述

#### cj-errorcode-universal.md
本文档定义了API调用的通用错误码，旨在帮助开发者诊断权限、参数及设备兼容性问题。主要涵盖权限校验失败（201/202）、参数检查失败（401）及设备能力不支持（801）等类型。每个条目详细列出了错误信息、可能原因及处理步骤，重点解释了非系统应用调用系统API、参数缺失及SysCap限制等场景。该文档面向应用开发人员，作为API故障排查的参考指南。
