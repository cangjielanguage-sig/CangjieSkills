This directory provides API reference documentation for the `RdbPredicates` class in the Cangjie ArkData framework. It details how to define conditional expressions for relational database operations, covering methods for logical conjunctions, set matching, and grouping conditions. Key topics include string matching, numerical comparisons, query structuring, and distributed data handling. This resource is suitable for developers using the ArkData kit to build complex database queries in Cangjie, offering precise control over data filtering and retrieval.
