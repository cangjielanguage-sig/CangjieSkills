This directory contains API reference documentation for the `UIAbilityContext` class in the Cangjie programming language, specifically designed for HarmonyOS application development. It covers the context environment for UIAbility components, enabling developers to manage lifecycles, launch abilities, handle results, and interact with system services. Key topics include ability launching, termination, and dialog services. This documentation is suitable for Cangjie developers and system engineers using the AbilityKit to implement inter-component communication and manage application behaviors within the HarmonyOS ecosystem.
