This directory focuses on practical usage scenarios for the `@Link` decorator within the Cangjie UI framework, specifically designed for HarmonyOS application development. It provides comprehensive tutorials on implementing bidirectional data synchronization between parent and child components. The content covers a range of data types, including simple types, class objects, and arrays, while addressing advanced topics like state observation and side effects. Key concepts featured include two-way binding, `@Observed`, `@Publish`, `ObservedArrayList`, and `@Watch`. These resources are ideal for developers looking to master reactive state management and enhance component interaction logic in their Cangjie projects. The included files offer code examples ranging from basic synchronization to complex array management and local state updates.
