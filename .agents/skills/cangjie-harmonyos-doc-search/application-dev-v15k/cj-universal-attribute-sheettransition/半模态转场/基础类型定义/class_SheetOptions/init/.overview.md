# init

This directory contains API reference documentation for the `init` constructor function used to configure half-modal (semi-modal) sheet components within the Cangjie language and ArkUI framework. It covers a wide range of configuration options including visual styling, layout constraints, interaction behaviors, and lifecycle callbacks. Key topics include background colors, height detents, drag logic, and dismissal handlers. These resources are designed for developers building UI applications who need to implement or customize modal interfaces, specifically targeting version 12 or later of the framework.

## Detailed Description

### init_1.md init_1.md
This document serves as API reference documentation for the init constructor function in the Cangjie language, designed to configure optional attributes for a half-modal page. It details the function signature, system capabilities, and a comprehensive list of parameters covering visual styles, lifecycle callbacks, and layout configurations. Key parameters include backgroundColor, onAppear, height, detents, and shouldDismiss, enabling extensive customization of the sheet's appearance and interaction behavior. This resource is intended for developers building UI applications using ArkUI, specifically those implementing or customizing modal sheets in version 12 or later.

### init_2.md init_2.md
This document serves as an API reference for initializing and configuring a half-modal (semi-modal) sheet component, detailing its parameters and behaviors. It covers visual styling options like background colors and blur effects, layout sizing including height constraints and detents, and interaction settings such as drag bars and outside interactivity. Key information includes specific height limits based on screen orientation, swipe logic for detents, and lifecycle callbacks for appearance and dismissal events. It highlights critical distinctions between dismissal handlers like shouldDismiss and onWillDismiss. This reference is intended for developers implementing customizable modal interfaces, providing the necessary parameters to control animations, user interactions, and layout behaviors within the UI framework.

### init_3.md init_3.md
This document provides API reference details for configuring a half-modal component, focusing on event callbacks, styling, and display modes. Key sections include callbacks for dimension changes (height, width, detents), border and shadow styling, and layout behavior settings like mode and scroll size mode. Important takeaways note specific constraints for bottom sheets, such as the invalidity of bottom border settings and conditional height reporting based on user interaction. The document also specifies that the display mode cannot be dynamically changed. This technical reference is intended for developers implementing interactive sheet interfaces, requiring knowledge of UI component properties and event handling.
