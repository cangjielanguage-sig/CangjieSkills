This directory provides a comprehensive guide for OpenHarmony developers on building hybrid applications using the Cangjie and ArkTS languages. It covers the entire development lifecycle, from project setup and directory structure understanding to UI creation and deployment on real devices or emulators. Key topics include the "[Cangjie] Hybrid Ability" template, interoperability mechanisms, and cross-language page navigation. Suitable for developers with basic knowledge of ArkTS and Cangjie who want to master mixed-language development workflows in DevEco Studio.

## Detailed Description

### 仓颉与ArkTS混合工程目录结构.md 仓颉与ArkTS混合工程目录结构.md
This reference document outlines the standard directory structure for OpenHarmony projects integrating Cangjie and ArkTS languages. It details the project hierarchy, specifically focusing on the entry module, source code locations for both languages, and essential configuration files. Key takeaways include the separation of source code within the src directory, the role of cjpm.toml for Cangjie package management, and the use of HAR files for interoperability dependencies. It targets OpenHarmony developers seeking to understand project organization and build configurations for mixed-language development.

### 使用真机或模拟器运行应用.md 使用真机或模拟器运行应用.md
This tutorial guides developers on running OpenHarmony applications, specifically those written in the Cangjie language, on either physical devices or emulators using DevEco Studio. The document is divided into two main sections: configuring and running on a local real device, and setting up the emulator with specific architecture adjustments. Key information includes the necessity of enabling automatic signing for real devices and modifying the build-profile.json5 file to add x86_64 to abiFilters when using x86 emulators, as the default compilation architecture is arm64-v8a. This guide targets developers working on Cangjie and ArkTS hybrid applications who need to test their builds on different hardware environments.

### 构建第一个仓颉与ArkTS混合应用_2more.md 构建第一个仓颉与ArkTS混合应用_2more.md
This tutorial guides OpenHarmony developers through building their first hybrid application using the Cangjie and ArkTS languages. It covers the project creation process within DevEco Studio, specifically selecting the "[Cangjie] Hybrid Ability" template and configuring settings. Key information includes version requirements for DevEco Studio and the minimum Compatible SDK version of 5.0.1(13). The document distinguishes between hybrid and pure Cangjie templates. Intended for developers with basic knowledge of Cangjie, ArkTS, and UI frameworks, it aims to help users understand the directory structure and development workflow for mixed-language applications.

### 构建第一个页面纯ArkTS页面.md 构建第一个页面纯ArkTS页面.md
This tutorial guides developers through building a basic user interface page using pure ArkTS in a HarmonyOS project. It covers two primary steps: utilizing text components within layout containers and adding interactive button components. The document demonstrates layout strategies using RelativeContainer, Row, and Column components. It provides code examples for styling text and buttons, including properties like font size, weight, and alignment rules, to prepare for page navigation. Intended for beginners starting with ArkTS UI development who need to understand basic component structure and layout composition.

### 构建第二个页面ArkTS与仓颉混合页面.md 构建第二个页面ArkTS与仓颉混合页面.md
This tutorial instructs developers on building a hybrid page using ArkTS and Cangjie languages within a HarmonyOS project. The content details the process of creating a Cangjie component file, generating the corresponding ArkTS container page, and configuring the routing. Key takeaways include the understanding that Cangjie pages act as embedded components rather than standalone pages, requiring an ArkTS @Entry container utilizing the CJHybridComponent interface. The guide targets developers working on mixed-language UI development, providing code examples for both the Cangjie source and the ArkTS wrapper.

### 实现页面间的跳转/
This directory provides comprehensive technical guidance on implementing page navigation within HarmonyOS applications that utilize a hybrid architecture of ArkTS and Cangjie. It specifically addresses the interoperability challenges between ArkTS and Cangjie routers, which are not natively compatible. The content covers essential workflows such as navigating from an ArkTS page to a mixed page, handling complex return logic, and registering callback functions for cross-language communication. Key technical concepts include the `@Interop[ArkTS]` macro, `.d.ts` interface generation, and the `registerJSFunc` mechanism. These resources are tailored for developers working on cross-language integration who need to master routing and function invocation in mixed environments.
