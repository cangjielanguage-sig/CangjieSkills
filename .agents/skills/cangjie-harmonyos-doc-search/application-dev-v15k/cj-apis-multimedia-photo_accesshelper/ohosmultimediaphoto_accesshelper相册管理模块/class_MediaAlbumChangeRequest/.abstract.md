This directory contains API reference documentation for the Cangjie class `MediaAlbumChangeRequest`, part of the SystemCapability.FileManagement.PhotoAccessHelper.Core framework. It covers functionalities for managing photo album modifications, including initializing requests, adding or removing assets, retrieving album objects, and renaming albums. Key topics include system capabilities, version 19 compatibility, and exception handling with specific error codes. This documentation is intended for developers using the MediaLibraryKit to implement programmatic control over photo albums and assets within HarmonyOS applications.
