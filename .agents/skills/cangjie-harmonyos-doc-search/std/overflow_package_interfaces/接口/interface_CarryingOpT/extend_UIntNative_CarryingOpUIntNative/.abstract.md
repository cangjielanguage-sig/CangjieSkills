This directory contains comprehensive API documentation for the `CarryingOp` interface implementation regarding the `UIntNative` type within the Cangjie programming language. It is designed to assist developers in performing low-level unsigned integer arithmetic with a focus on safety and precision. The documentation details a variety of functions that utilize wrapping strategies for calculations, ensuring that operations behave predictably even at boundary limits. A key feature of these functions is their return type: a tuple containing both the operation result and a Boolean flag indicating if truncation or overflow occurred. This resource is particularly suitable for systems programmers and developers working on cryptographic algorithms or embedded systems where explicit overflow detection is critical for application stability and correctness.
