This repository serves as a comprehensive technical resource for developers aiming to implement Host Card Emulation (HCE) technology within HarmonyOS applications using the Cangjie programming language. It thoroughly covers the fundamental concepts of NFC card emulation, explaining how software can simulate smart cards without relying on secure element hardware. The documentation addresses critical implementation aspects, including AID registration, APDU command handling, and the specific APIs required for communication with external readers. Furthermore, it distinguishes between foreground and background execution modes, detailing the necessary permissions and lifecycle management. This resource is specifically designed for HarmonyOS developers who possess a working knowledge of Cangjie and NFC protocols, providing the essential instructions needed to build secure, contactless transaction applications such as mobile payments or access control systems.
