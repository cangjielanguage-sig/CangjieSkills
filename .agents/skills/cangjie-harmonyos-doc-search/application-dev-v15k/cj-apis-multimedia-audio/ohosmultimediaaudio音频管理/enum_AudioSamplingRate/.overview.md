# enum_AudioSamplingRate

This directory provides comprehensive API reference documentation for the `AudioSamplingRate` enumeration within the Cangjie programming language. It details the standard audio sampling rates supported by the multimedia audio core, covering values from 8000 Hz up to 192000 Hz. The documentation includes the enum's structural definition, its inheritance from `Equatable` and `ToString` interfaces, and specific operator implementations for value comparison. It specifies the necessary system capability (`SystemCapability.Multimedia.Audio.Core`) and availability starting from version 19. Furthermore, the document highlights that actual device support for these rates may vary. This resource is designed for software developers seeking to integrate precise audio functionality into their applications using this specific system framework.
