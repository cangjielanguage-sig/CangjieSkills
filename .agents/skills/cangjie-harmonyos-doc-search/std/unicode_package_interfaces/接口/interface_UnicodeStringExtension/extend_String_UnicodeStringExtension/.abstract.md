This directory contains API reference documentation for extending the Cangjie `String` type to implement the `UnicodeStringExtension` interface. It comprehensively covers advanced character set operations, including Unicode-compliant casing conversions (toLower, toTitle, toUpper), whitespace validation (isBlank), and various string trimming methods (trim, trimStart, trimEnd). The documents detail function signatures, locale-specific handling via `CasingOption`, and error handling for invalid UTF-8 encoding. Additionally, it highlights deprecated functions and their modern replacements. This resource is suitable for Cangjie developers seeking to manipulate text casing, sanitize inputs, and ensure proper Unicode compliance in their applications.
