This directory contains extensive API documentation for the implementation of the `CheckedOp` interface tailored to the `UIntNative` type in the Cangjie programming language. It serves as a vital technical reference for developers aiming to implement safe integer arithmetic and bitwise operations. The documentation focuses on robust error handling through an `Option` return strategy, where operations return `None` in the event of an overflow or invalid input rather than wrapping or throwing exceptions. The content covers a wide range of essential operations, including fundamental arithmetic functions such as addition, multiplication, division, and modulo, as well as increment, decrement, negation, and bit shifting. This resource is intended exclusively for Cangjie developers who need to perform precise mathematical computations while exercising precise control over error states and ensuring overall program safety and reliability.
