This directory serves as a comprehensive technical resource for managing audio playback streams within Cangjie applications. It provides in-depth guidance on monitoring and controlling audio states, covering both application-specific stream management using AudioRenderer and system-wide oversight via AudioStreamManager. The content explores essential techniques such as registering state change callbacks, querying stream properties like UID and state, and handling device updates to ensure responsive UI behavior. This documentation is specifically designed for application developers utilizing the AudioKit framework who need to implement dynamic audio features, monitor audio output effectively, or debug complex audio device connections.
