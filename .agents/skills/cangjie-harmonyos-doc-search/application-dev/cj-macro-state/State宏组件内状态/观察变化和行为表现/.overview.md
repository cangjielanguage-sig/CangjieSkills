# 观察变化和行为表现

This directory provides a comprehensive overview of state observation mechanisms and behavioral performance within a reactive UI framework. It details how the framework monitors data changes across different data types—ranging from primitive values to complex objects and collections—and translates these changes into UI updates. Key concepts include the @State decorator, on-demand rendering, and the specific observation rules of the Cangjie language. This material is essential for developers seeking to optimize application performance by understanding the underlying principles of state management and ensuring efficient, responsive UI rendering.

### 框架行为.md 框架行为.md

This document outlines the core reactive behavior of the framework regarding state management and rendering efficiency. This reference material targets developers seeking to understand the framework's internal rendering logic to optimize application performance. Keywords include state variables, component updates, re-rendering, and on-demand updates.

### 观察变化.md 观察变化.md

This technical guide explains how the @State decorator observes data changes across various data types in the Cangjie language. It details observation behaviors for primitive types, structs, classes, arrays, and other collections. Key takeaways include that primitives are fully observable, structs require whole assignment, and classes need @Observed and @Publish macros to detect internal changes. While standard arrays only detect whole reassignment, ObservedArrayList supports item-level modifications. This document serves as a reference for ArkUI developers implementing state management, requiring knowledge of Cangjie syntax and decorators.

### 观察变化和行为表现.md 观察变化和行为表现.md

This document serves as a conceptual guide explaining the relationship between state variable modifications and UI refreshes within a framework. It covers the criteria for observable changes that trigger updates and details the framework's behavior and rendering process when these changes are detected. Key information includes the distinction between general state changes and those perceptible to the framework, emphasizing that only observable modifications drive UI updates. This material is intended for developers using reactive UI frameworks who need to understand the underlying principles of state management and rendering efficiency. Keywords: state variables, UI refresh, framework observation, reactive behavior, state management.
