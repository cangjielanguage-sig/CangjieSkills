# cj-apis-promptaction

This directory serves as a comprehensive technical resource dedicated to the `ohos.prompt_action` module within the HarmonyOS Cangjie development ecosystem. It provides an in-depth look at creating and managing user interface popups, which are essential for interactive user feedback. The content covers a wide range of modal components, including simple text prompts (toasts), standard dialogs, action menus, and fully custom dialogs. It details the necessary configuration classes such as `ActionMenuOptions`, `ButtonInfo`, and `ShowDialogOptions`, alongside enumerations for styling and behavior control. Designed exclusively for pure Cangjie development scenarios, this documentation is an essential guide for HarmonyOS developers and UI engineers aiming to implement robust modal interfaces and enhance user interaction within the ArkUI framework.
