# cj-displaysync-animation

This directory serves as a comprehensive guide for managing animation frame rates within the ArkUI framework using the Cangjie programming language. It specifically addresses the implementation of the `ExpectedFrameRateRange` parameter inside `AnimateParam`, a crucial feature for optimizing rendering performance and achieving high-quality visual effects. The content covers essential techniques for defining minimum, maximum, and expected frame rates across different animation types. It is primarily designed for HarmonyOS application developers who need to fine-tune performance, enforce frame rate constraints, and strike a balance between visual smoothness and system resource consumption in their user interfaces.

## Detailed Description

### [1] 请求动画绘制帧率/

This subdirectory provides an in-depth exploration of techniques for requesting and controlling animation drawing frame rates within the ArkUI framework using the Cangjie language. Central to this guide is the implementation of the `ExpectedFrameRateRange` parameter within `AnimateParam`, which allows developers to optimize rendering performance and visual effects effectively.

The key topics covered include the granular configuration of minimum, maximum, and expected frame rates for both property animations and explicit animations. By understanding how to manipulate these parameters, developers can gain precise control over how their UI animations interact with the system's display refresh rate.

This resource is suitable for HarmonyOS application developers looking to fine-tune animation performance, manage frame rate constraints effectively, and balance visual smoothness with system resource usage in their UI components. By mastering these APIs, developers can ensure their applications run efficiently across different hardware capabilities while maintaining high-quality user experiences.
