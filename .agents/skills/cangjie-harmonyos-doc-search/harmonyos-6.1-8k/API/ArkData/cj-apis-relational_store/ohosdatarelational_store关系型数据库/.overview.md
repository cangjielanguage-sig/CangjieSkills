## Detailed Description

### class_Asset.md class_Asset.md
这份文档是Cangjie语言中Asset类的API参考，旨在定义用于记录资产附件（如文件、图片、视频）信息的类。文档涵盖了类的属性定义，包括名称、URI、路径、时间戳、大小及状态，并详细说明了构造函数的参数配置。关键信息指出该类属于关系型数据库核心能力，且暂不支持Datashare。主要面向使用Cangjie进行分布式数据管理的开发者，用于在应用沙箱中管理和存储资产元数据。

### enum_AssetStatus_2more_2d80015b.md enum_AssetStatus_2more_2d80015b.md
本文档是Cangjie语言的API参考文档，定义了AssetStatus和ChangeType两个枚举。AssetStatus描述资产附件状态（如正常、插入、更新、删除、异常、下载中），ChangeType区分数据变更与资产变更。两者均属于SystemCapability.DistributedDataManager.RelationalStore.Core系统能力，起始版本为22。文档旨在帮助开发者在分布式关系型数据库开发中追踪资产生命周期及识别变更类型。

### enum_ConflictReso_3more_16ca541e.md enum_ConflictReso_3more_16ca541e.md
本文档定义了Cangjie语言中关系型数据库操作相关的三个枚举类型，涵盖冲突解决、分布式类型及加密算法。主要内容包括ConflictResolution（处理SQL约束冲突的策略）、DistributedType（设备间或设备与云端间的分布式表类型）以及EncryptionAlgo（数据库加密算法）。关键信息包括OnConflictReplace在冲突时删除旧行的策略、DistributedCloud用于云端同步、以及支持AES-256-GCM和AES-256-CBC加密。所有接口均属于关系型数据管理系统能力。面向使用Cangjie关系型数据库API的开发者，用于在分布式应用中管理数据持久化、同步及安全性。

### enum_Field_3more_5c4ea848.md enum_Field_3more_5c4ea848.md
本文档是分布式数据管理系统的API参考文档，主要定义了用于云同步查询和数据库加密的三个枚举类型。文档涵盖了Field枚举（用于谓词查询的特殊字段，如游标、删除标志及共享权限）、HmacAlgo枚举（HMAC算法）和KdfAlgo枚举（PBKDF2算法）。关键信息包括各字段在数据同步、共享及清理状态中的具体含义，以及支持的安全哈希算法（SHA1/256/512）。该文档面向使用云同步客户端和关系型数据库核心功能的开发者，需具备数据安全与同步机制的相关知识。

### enum_Origin_4more_2c348cc9.md enum_Origin_4more_2c348cc9.md
本文档是Cangjie语言中分布式数据管理相关的API参考文档，主要定义了四个核心枚举类型。文档涵盖了数据来源、同步进度、数据库安全级别及订阅类型。Origin枚举区分本地、云端和远程数据；Progress描述端云同步状态；RelationalStoreSecurityLevel定义S1至S4四个安全等级，且仅支持由低向高设置；SubscribeType用于订阅云端或远程数据变更。这些内容面向使用关系型数据库和云同步功能的开发者，涉及SystemCapability.DistributedDataManager系统能力。

### enum_RelationalStoreValueType.md enum_RelationalStoreValueType.md
本文档定义了Cangjie语言中的RelationalStoreValueType枚举，用于表示关系型数据库中允许的数据字段类型。文档详细列出了基础类型（如整型Integer、浮点型Double、字符串StringValue、布尔值Boolean及空值Null）和复杂类型（如字节数组Uint8Array、附件AssetEnum及附件数组AssetsEnum）。该枚举属于SystemCapability.DistributedDataManager.RelationalStore.Core系统能力，起始版本为22，用于根据功能确定接口参数的具体类型。本文档属于API参考文档，面向需要在关系型数据库中处理多样化数据值的开发者，提供了数据类型定义的规范。

### enum_SyncMode_2more_6d79383f.md enum_SyncMode_2more_6d79383f.md
本文档是分布式数据管理相关的API参考文档，主要定义了SyncMode和Tokenizer两个枚举。SyncMode用于指定数据库同步模式，涵盖推送、拉取、云端优先、本地优先及基于时间的同步方式。Tokenizer用于全文搜索场景，包含无分词器、ICU分词器及自研分词器三种选项，其中自研分词器针对中英文进行了性能优化。文档详细说明了各枚举值的功能、系统能力及起始版本，旨在帮助开发人员在关系型数据库开发中实现数据同步与全文检索功能。
