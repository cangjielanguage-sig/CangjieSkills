This directory contains API reference documentation for the Cangjie Verify class within the CryptoFramework. It focuses on digital signature verification, covering the complete operational workflow from initialization using public keys to data updates and final verification. Key topics include algorithm configuration (RSA, SM2, DSA), parameter specification via `setVerifySpec`, and data recovery mechanisms. The documentation details error handling, multi-pass verification for large messages, and specific algorithm restrictions. It is suitable for Cangjie developers and security engineers implementing cryptographic security features and asymmetric encryption operations.
