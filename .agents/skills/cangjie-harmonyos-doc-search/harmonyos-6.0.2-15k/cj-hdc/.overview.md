# cj-hdc

The `cj-hdc` directory serves as a comprehensive technical repository dedicated to the HarmonyOS Device Connector (hdc). This directory is essential for understanding and utilizing the command-line tool that facilitates the debugging and management of HarmonyOS and OpenHarmony devices. It provides in-depth coverage of the tool's internal architecture, step-by-step guides for environment setup across different operating systems, and detailed instructions for a multitude of operations. Key functionalities documented include seamless file transfer, application installation and management, network port forwarding, and comprehensive log management. Additionally, the directory acts as a troubleshooting hub, offering solutions for error codes and device connectivity challenges. This documentation is primarily designed for developers, QA engineers, and system administrators who need to interact efficiently with HarmonyOS devices via the command line on Windows, Linux, or macOS platforms. By mastering the tools and techniques described here, professionals can significantly reduce debugging time and improve the reliability of their applications.

### hdc/
This directory contains comprehensive documentation for the HarmonyOS Device Connector (hdc), a command-line tool designed for debugging HarmonyOS and OpenHarmony devices across Windows, Linux, and macOS. It covers the tool's architecture, environment setup, and a wide array of functionalities including file transfer, app installation, port forwarding, and log management. Additionally, it provides essential troubleshooting resources for error codes, connectivity issues, and device management. This documentation is suitable for developers, QA engineers, and system administrators seeking to effectively interact with and debug HarmonyOS devices via the command line.
