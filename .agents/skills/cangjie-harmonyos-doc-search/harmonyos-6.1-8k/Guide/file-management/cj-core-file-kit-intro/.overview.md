# cj-core-file-kit-intro

This directory serves as an introduction to the OpenHarmony Core File Kit, providing essential knowledge for managing application and user files. It covers key concepts such as file classification models, sandbox isolation security, and cross-application file sharing mechanisms using URIs and File Descriptors (FD). Additionally, it delves into the underlying framework architecture principles. This resource is ideal for developers looking to build file management features, integrate file pickers, or gain a deep understanding of the OpenHarmony file system architecture. It offers a comprehensive guide ranging from foundational concepts to technical implementation details.

## Detailed Description

### Core_File_Kit简介/
This directory introduces OpenHarmony's Core File Kit (Basic File Service), aiming to help developers fully master the management mechanisms of application files and user files. The content covers file classification models, sandbox isolation security mechanisms, cross-application file sharing (URI/FD), and underlying framework architecture principles. It is suitable for developers who need to build file management functions, integrate file pickers, or deeply understand the OpenHarmony file system architecture, providing complete guidance from basic concepts to technical implementation.
