This directory contains advanced configuration guides for a Cangjie testing and benchmarking framework. It covers input regeneration strategies, detailed report generation, custom metrics, and parameter tuning to prevent compiler optimizations. Key topics include `BenchInputProvider`, `@Strategy` annotation, HTML/CSV reporting, and micro-benchmark precision. It is suitable for Cangjie developers and performance engineers seeking granular control over benchmarks, accurate performance simulation, and in-depth analysis beyond standard timing.
