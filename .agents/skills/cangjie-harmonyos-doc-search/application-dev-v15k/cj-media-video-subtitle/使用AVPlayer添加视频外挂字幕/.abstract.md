This directory provides a comprehensive guide for integrating external subtitles into video playback using the AVPlayer framework, specifically tailored for HarmonyOS developers using the Cangjie language. It covers the end-to-end process of managing subtitle sources, including setup via file descriptors or URLs, and controlling display through event callbacks. The documentation highlights essential constraints, such as the necessity of configuring subtitles prior to playback initiation. Key technical elements include resource setup, callback registration and unregistration, and error handling. This collection is ideal for application engineers seeking to enhance their multimedia applications with dynamic, external subtitle capabilities using methods like `addSubtitleFromFd` and `addSubtitleFromUrl`.
