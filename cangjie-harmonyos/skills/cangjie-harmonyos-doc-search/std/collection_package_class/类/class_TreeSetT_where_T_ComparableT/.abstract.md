This directory contains API reference documentation for the `TreeSet` class in the Cangjie programming language. It details an ordered collection implementation based on `TreeMap`, designed for storing unique, sorted elements where the type `T` implements the `Comparable` interface. The documentation covers class definitions, properties, constructors, and a wide range of member functions for manipulation, iteration, and set operations. It is suitable for Cangjie developers building applications requiring efficient sorted data structures, such as databases or caches, who need to understand generic types, iterators, and set algebra.
