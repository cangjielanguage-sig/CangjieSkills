# 结构体

This directory contains API reference documentation for core data structures used in the Cangjie programming language's Transport Layer Security (TLS) implementation. It covers essential structs such as `CipherSuite` for cryptographic algorithms, `TlsClientConfig` and `TlsServerConfig` for connection parameters, and `TlsSession` for session management. These documents provide detailed definitions, properties, and methods necessary for implementing secure network communication. Suitable for developers working on TLS clients and servers, this section requires familiarity with Cangjie syntax and cryptographic concepts like X509 certificates and protocol negotiation.

### struct_CipherSuite.md struct_CipherSuite.md
This document serves as API reference documentation for the CipherSuite struct within the Cangjie programming language, specifically designed to represent TLS cipher suites. The content outlines the struct's inheritance from ToString and Equatable interfaces and details its key members, including the static property allSupported for retrieving available suites, the toString method for naming, and equality operators for comparison. Key takeaways include the ability to list supported cryptographic algorithms and compare suite instances. This technical guide targets developers working on TLS implementations, requiring familiarity with Cangjie syntax and cryptographic concepts. Keywords: Cangjie, TLS, CipherSuite, API reference, struct, equality operators.

### struct_TlsClientConfig.md struct_TlsClientConfig.md
This API reference document details the TlsClientConfig struct used for configuring TLS client connections in the Cangjie programming language. It covers the struct definition, initialization, and various mutable properties including key logging, certificate verification, ALPN protocols, cipher suites for TLS 1.2 and 1.3, client certificates, SNI domain settings, TLS version ranges, security levels, and signature algorithms. Key information includes data types, default values, and potential exceptions like IllegalArgumentException for invalid characters or TlsException for version conflicts. The document references external RFCs and OpenSSL documentation for specific behaviors. This guide is intended for developers implementing secure network communication who need to customize TLS handshake parameters and security settings.

### struct_TlsSession.md struct_TlsSession.md
This document provides API reference documentation for the Cangjie TlsSession struct, which represents an established client TLS session designed for connection resumption. It covers the struct definition, its inheritance from Equatable, ToString, and Hashable interfaces, and specific member functions including hashCode, toString, and equality operators. Key information highlights that this struct is user-inaccessible for creation and encapsulates a session ID to bypass the TLS handshake process upon reconnection. This reference is intended for developers implementing TLS client functionality who need to manage session states and optimize connection performance.
