This directory contains the essential API reference documentation for the `cj-appendix-thread` module, designed specifically for managing thread execution in Cangjie-based OpenHarmony applications. It addresses the critical architectural distinction between UI and non-UI logic, providing developers with the necessary tools to explicitly schedule tasks to the UI thread. This capability is vital for preventing severe performance bottlenecks and potential security vulnerabilities that can arise from Cangjie's unique user-space threading model. The documentation comprehensively covers module import requirements, the `UIThread` instance, the `launch` function for task submission, and the `MainThreadContext` class definition. This resource is best suited for OpenHarmony developers utilizing the Cangjie language who require precise control over thread scheduling to ensure application stability, security, and a responsive user interface. Mastering these APIs is key to building robust applications in this environment.
