This directory contains API reference documentation for the Zip class and related functions within the Cangjie language's Zlib subsystem. It covers data compression and decompression capabilities, including stream-based operations, buffer management, and resource allocation. Key topics include functions like `compress`, `uncompress`, `deflate`, and `inflate`, along with initialization and termination routines for compression streams. The documentation details parameters, return values, and exception handling for various error codes. This resource is suitable for Cangjie developers implementing file or data compression features who need precise technical specifications and code examples for the SystemCapability.BundleManager.Zlib framework.
