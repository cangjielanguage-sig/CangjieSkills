This directory contains the API documentation for the `cj-apis-ark_interop_helper` module, a specialized library designed to facilitate interoperability between ArkTS and native code using the Cangjie language within the HarmonyOS ecosystem. It serves as a vital resource for developers who need to bridge the gap between the ArkUI framework and native NAPI logic, particularly for applications targeting API version 12. The documentation covers a wide range of helper functions that simplify complex tasks such as data mapping, type conversions, and context management. By providing detailed references for converting data structures like HashMaps to JSValue and managing Stage and FA contexts, this module enables developers to build more efficient and powerful applications. It is specifically suitable for HarmonyOS developers and system engineers who are leveraging SystemCapability.ArkUI.ArkUI.Napi and require robust tools for native integration.
