This directory acts as a comprehensive educational resource and glossary tailored for HarmonyOS developers, specifically focusing on the intricate terminology associated with application packages and the Stage model. It provides in-depth definitions and distinctions for critical package types, including the main application package (HAP), static shared packages (HAR), and dynamic shared packages (HSP). Additionally, it elucidates the roles of core components such as Module, ExtensionAbility, and UIAbility, which are pivotal to the architecture introduced in API version 9. The primary goal of this content is to equip developers with a clear understanding of application structure, component types, and packaging mechanisms. It is highly suitable for developers seeking to optimize their workflow through efficient resource sharing and modular design practices within the HarmonyOS ecosystem. By mastering these terms, developers can ensure they are utilizing the full capabilities of the Stage model.
