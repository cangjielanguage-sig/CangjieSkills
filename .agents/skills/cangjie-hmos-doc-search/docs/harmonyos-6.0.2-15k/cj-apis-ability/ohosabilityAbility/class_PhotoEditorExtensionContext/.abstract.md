This directory provides essential API reference documentation for the `PhotoEditorExtensionContext` class in the Cangjie language, designed specifically for developers creating photo editing extensions on the HarmonyOS platform. It details the class definition, which inherits from `ExtensionContext`, and focuses on the mechanisms required to support photo editing capabilities. The documentation covers critical methods for saving edited images, whether using `PixelMap` data or specific file URIs, and explains the resulting `AbilityResult` and error handling. Key topics include `saveEditedContentWithImage`, `saveEditedContentWithUri`, parameter configurations, and exception management. This resource is suitable for application developers and software engineers who need to implement persistent storage for edited images and manage complex system interactions within the Ability Kit framework.
