# ScrollBar

This directory provides comprehensive technical documentation for the ScrollBar component within the Cangjie ArkUI framework. It covers essential aspects of implementing scrollable user interfaces, including component initialization, layout constraints, styling options, and event handling. The content addresses critical behaviors such as main axis sizing, infinite dimension risks, and nested scrolling configurations. Designed for software developers and UI engineers, these resources guide users through creating custom scroll bars, managing Scroller bindings, and optimizing interactions for HarmonyOS applications starting from API version 12.

## Detailed Description

### ScrollBar_2more.md ScrollBar_2more.md
This document provides a technical reference for the ScrollBar component, designed to accompany scrollable elements such as List, Grid, Scroll, and WaterFlow. The content explains the component's basic usage, layout constraints regarding main axis sizing, and child component capabilities. Key information highlights a critical sizing behavior: if the main axis size is undefined, the component inherits the parent's maxSize, which can lead to infinite dimensions within scrollable containers. Therefore, explicit sizing is recommended. The document targets developers implementing UI layouts, specifically those managing scroll interactions and component hierarchies.

### 创建组件.md 创建组件.md
This document provides API reference documentation for initializing a ScrollBar component within the Cangjie ArkUI framework. It details four overloaded init constructors that allow developers to configure the scroll bar with varying levels of specificity regarding direction and visibility state. Key information includes the mandatory requirement of a Scroller controller for binding and a child lambda for defining sub-components. Optional parameters allow setting the ScrollBarDirection, which defaults to Vertical, and the BarState, which defaults to Auto. This reference is intended for software developers using the Cangjie language to build scrollable user interfaces, specifically targeting ArkUI system capabilities starting from version 12.

### 示例代码.md 示例代码.md
This document provides Cangjie code examples demonstrating how to implement and customize the ScrollBar component within a HarmonyOS UI application. It covers two primary scenarios: setting a child node for custom styling and omitting the child node for default system styling. The examples illustrate linking the ScrollBar to a Scroller object, configuring layout parameters like width and background color, and managing scroll direction. The first example uses a Text component to define the bar's appearance, while the second relies on default rendering. This tutorial is intended for developers using the Cangjie language to build user interfaces, specifically those needing to implement custom or standard scrolling behaviors.

### 通用属性通用事件_2more.md 通用属性通用事件_2more.md
This document serves as an API reference for ArkUI component properties, specifically detailing the configuration of nested scrolling behavior. It covers general properties and events support, and provides a detailed specification for the `enableNestedScroll` function. Key information includes the function's boolean parameter to control scrolling, the mechanism of offset propagation from inner to outer components, and specific constraints such as the incompatibility with WaterFlow's SLIDING_WINDOW mode. Additionally, it notes that PARALLEL mode requires custom logic in `onScrollFrameBegin`. This technical guide is intended for developers implementing complex scrolling interactions within the ArkUI framework.
