This directory contains API reference documentation for the `WifiDeviceConfig` class within the Cangjie programming language. It is designed to assist developers in managing WLAN configuration information for WiFi Station (STA) features. The documentation covers the class constructor, string representation methods, and detailed property definitions including SSID, security types, and encryption keys. It also addresses specific validation rules for different security protocols like WEP, SAE, and PSK, as well as handling EAP and WAPI configurations. This resource is suitable for software developers implementing network connectivity who require a deep understanding of Cangjie syntax and network security protocols under the SystemCapability.Communication.WiFi.STA framework.
