# AESGCMNoPadding

This directory provides comprehensive technical documentation and code tutorials for implementing AES-GCM (Galois/Counter Mode) encryption without padding using the Cangjie language and the HarmonyOS Universal Keystore Kit (HUKS). It covers the complete cryptographic lifecycle, detailing the processes of generating AES keys, encrypting plaintext, decrypting ciphertext, and securely deleting keys. Key technical concepts include HuksParam configuration, algorithm selection, and the management of GCM-specific parameters such as Nonce, Associated Data (AAD), and the AE Tag. This resource is specifically designed for developers operating within the HarmonyOS ecosystem who require robust solutions for secure data storage and transmission, as well as effective key lifecycle management.

## Detailed Description

### AESGCMNoPadding_1.md
This document serves as a code tutorial demonstrating AES/GCM/NoPadding encryption and decryption using the Cangjie language and the Universal Keystore Kit. It covers three main operational stages: generating an AES key, encrypting plaintext, and decrypting ciphertext. Key takeaways include the specific configuration of HuksParam for algorithm selection, key size, and GCM-specific parameters like Nonce, Associated Data (AAD), and the AE Tag. The example illustrates the complete lifecycle of a cryptographic session using initSession and finishSession. This guide targets developers implementing secure data storage and transmission within the HarmonyOS ecosystem.

### AESGCMNoPadding_2.md
This document serves as a technical reference demonstrating how to delete a cryptographic key within the Huawei Universal Keystore Service (HUKS) framework. The content focuses on the DeleteKey function, illustrating the use of the deleteKeyItem API with a specific key alias and empty options. Key takeaways include the necessity of using the aesKeyAlias defined during key generation and passing HuksOptions.NONE to complete the deletion process. This snippet is designed for developers managing key lifecycles in HarmonyOS applications, providing a clear example of secure key removal. It assumes prior knowledge of key generation and basic HUKS API usage.
