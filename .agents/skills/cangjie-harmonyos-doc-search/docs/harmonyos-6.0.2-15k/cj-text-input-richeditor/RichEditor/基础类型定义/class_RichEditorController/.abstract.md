This directory contains API reference documentation for the `RichEditorController` class in the Cangjie language, specifically designed to control RichEditor components within the ArkUI framework. It details the class initialization and various functional methods, including content manipulation, deletion, cursor management, and menu control. Key functions covered include `addImageSpan`, `addTextSpan`, `deleteSpans`, and `getCaretOffset`, enabling developers to programmatically insert content with specific options, manage text and image spans, and track cursor position. The documentation also covers span retrieval, style updates, and paragraph formatting. This resource is suitable for Cangjie developers working on ArkUI applications who need to implement rich text editing capabilities.
