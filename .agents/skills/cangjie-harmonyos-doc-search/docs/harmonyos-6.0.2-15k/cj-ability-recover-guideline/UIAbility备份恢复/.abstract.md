This directory focuses on the UIAbility backup and restoration functionality within the HarmonyOS development environment. It is designed to assist developers in preserving application state and data during unexpected system terminations, thereby ensuring a smooth and continuous user experience. The documentation covers essential concepts such as lifecycle callbacks (onSaveState, onCreate), operational mechanisms, and specific constraints including data size limits and storage duration. Furthermore, it provides technical implementation guides using the Cangjie language and AbilityKit. This resource is highly suitable for HarmonyOS developers who need to manage application state continuity and handle lifecycle events effectively when background applications are reclaimed by the system.
