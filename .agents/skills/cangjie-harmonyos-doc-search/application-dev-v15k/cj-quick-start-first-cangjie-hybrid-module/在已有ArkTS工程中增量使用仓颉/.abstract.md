This directory focuses on integrating the Cangjie programming language into existing HarmonyOS ArkTS projects incrementally. It covers mixed-language development scenarios, including calling Cangjie interfaces (sync/async) from ArkTS, embedding Cangjie UI components, and cross-module navigation. Key topics include module configuration (HAP/HAR), SDK API 12-15 support, and interoperability mechanisms like `@Interop`. It is designed for HarmonyOS developers using DevEco Studio who want to leverage Cangjie features without rewriting their entire codebase.
