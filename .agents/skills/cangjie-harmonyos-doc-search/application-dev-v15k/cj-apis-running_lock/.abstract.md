This directory serves as a comprehensive resource for the `cj-apis-running_lock` module, specifically tailored for the Cangjie programming language within the HarmonyOS ecosystem. It focuses on power management APIs, enabling developers to control device wakefulness and screen states effectively. The content covers the essential mechanisms for preventing system sleep, managing different types of running locks, and handling sensor-based screen control. It is an essential guide for Cangjie developers and system architects who need to maintain device activity during critical operations, such as navigation, background downloads, or media playback, while adhering to system power constraints and permission requirements. By utilizing these APIs, developers can ensure their applications function reliably without being interrupted by the system's aggressive power-saving mechanisms, thereby enhancing the overall stability and usability of system-level software.
