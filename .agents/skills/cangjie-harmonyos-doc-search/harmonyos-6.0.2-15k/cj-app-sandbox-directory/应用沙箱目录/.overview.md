# 应用沙箱目录

This directory focuses on the Application Sandbox Directory mechanism, a critical security feature in HarmonyOS designed to isolate application data and protect it from unauthorized access. It covers the composition of the sandbox, the distinction between virtual sandbox paths and real physical paths, and the mapping rules for different storage levels and encryption states. Key topics include file access permissions, path isolation, data persistence, and security boundaries. This documentation is suitable for HarmonyOS application developers who need to understand file system structures, manage data storage securely, and implement correct path resolution within the operating system environment.

## Detailed Description

### 应用沙箱目录_2more.md 应用沙箱目录_2more.md
This document serves as a technical guide explaining the Application Sandbox Directory mechanism, a security isolation feature designed to protect application data from unauthorized access. It covers the composition of the sandbox, which includes dedicated app files and essential read-only system files, while restricting access to user files via specific APIs and authorization. Key concepts include the distinction between "Application Sandbox Paths" (the virtual view seen by the app) and "Real Physical Paths" (the system view visible via hdc shell), emphasizing that they are not 1:1 mappings. The document targets application developers, providing essential knowledge on file access permissions, path isolation, and security boundaries within the operating system environment.

### 应用沙箱路径和真实物理路径的对应关系.md 应用沙箱路径和真实物理路径的对应关系.md
This reference document details the mapping between application sandbox paths and their corresponding real physical file system paths. It covers directories for application bundles, encrypted data at el1 and el2 levels, databases, and distributed files. Key information includes the distinction between standard applications and extensions running in independent sandboxes, defining variables such as USERID and EXTENSIONPATH. The document provides specific physical path structures for different storage levels. This guide is intended for developers needing to understand file system storage locations, data isolation, and path resolution mechanisms.

### 应用文件目录与应用文件路径/
This directory provides comprehensive technical documentation on HarmonyOS application file structures and path management. It covers the app sandbox hierarchy, encryption levels (EL1-EL5), and specific directory purposes such as persistent storage, caching, and distributed files. Key topics include Context API usage for path retrieval, security capabilities, and lifecycle behaviors like automatic cleanup. Suitable for HarmonyOS developers, this guide ensures correct implementation of data persistence, resource management, and security within the operating system environment. It distinguishes between global and HAP-level storage and advises on best practices for data encryption and file access. By following these guidelines, developers can effectively manage data lifecycles and ensure application compatibility across different HarmonyOS environments while maintaining high security standards.
