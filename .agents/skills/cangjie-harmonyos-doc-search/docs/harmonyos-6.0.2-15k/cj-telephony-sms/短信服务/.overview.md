# 短信服务

This directory provides comprehensive technical documentation for integrating SMS (Short Message Service) functionality into HarmonyOS applications and web environments. It covers essential concepts such as SMS protocols, encoding types (7-bit, 8-bit, UCS-2), and system constraints. The guides detail various methods to launch the native SMS editing interface, utilizing URI schemes for web pages and the `startAbility` interface for in-app navigation. Key topics include PDU handling, SIM slot management, and specific permission requirements. This resource is suitable for developers seeking to implement seamless communication features, navigate system restrictions, and understand the underlying architecture of SMS services on the HarmonyOS platform.

## Detailed Description

### sms方式跳转到短信编辑界面.md sms方式跳转到短信编辑界面.md
This technical guide explains how to use the SMS protocol scheme to launch the native SMS editing interface directly from web pages or HarmonyOS applications. It covers the standard URI format, detailing the required scheme, optional recipient numbers, and body parameters. The document provides specific implementation examples, including HTML hyperlinks for web usage and Cangjie code snippets for app development using the Want object to start the messaging ability. Key takeaways include the syntax `sms:number?body=content` and the method for passing context in Cangjie. This resource is intended for developers seeking to integrate seamless SMS sending functionality into their projects.

### 应用内跳转到短信编辑界面.md 应用内跳转到短信编辑界面.md
This technical tutorial guides developers on implementing a jump from a third-party application to the system SMS editing interface using the Cangjie language. The document explains that due to system permission restrictions, apps must use the startAbility interface to navigate to the messaging app. Key sections include the configuration of the Want object with specific parameters such as bundle name, ability name, and a JSON payload containing recipient details and message content. The code examples demonstrate how to pass these parameters and handle the result callback. This guide is intended for HarmonyOS developers building communication features who need to pre-fill SMS data without direct sending permissions.
