This directory contains API reference documentation for configuring the properties of the Indexer component within the ArkUI framework using the Cangjie language. It covers a wide range of customization options, including alignment styles, font settings, popup window appearance, and the visual state of selected items. Developers can find detailed parameters for adaptive folding, haptic feedback, and color schemes. The documentation is intended for HarmonyOS UI developers who need to programmatically style and control the behavior of index bars and their associated popups in their applications.
