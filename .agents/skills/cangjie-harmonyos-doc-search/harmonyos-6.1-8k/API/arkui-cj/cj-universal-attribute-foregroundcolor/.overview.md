### cj-universal-attribute-foregroundcolor.md cj-universal-attribute-foregroundcolor.md

这份API参考文档详细说明了ArkUI框架中Cangjie语言的组件前景色设置方法。文档核心包含`foregroundColor`函数的两种重载形式，分别接受`ColoringStrategy`和`ResourceColor`参数，用于设置颜色或智能取色策略。关键点在于该属性默认继承父组件，初始值为透明，且不支持属性动画。文档通过三个示例展示了基础颜色应用、背景反色策略及继承行为。主要面向使用Cangjie语言进行ArkUI应用开发的开发者，旨在帮助其掌握组件外观样式的配置。
