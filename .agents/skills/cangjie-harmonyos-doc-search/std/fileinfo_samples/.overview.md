# fileinfo_samples

This directory serves as a dedicated educational resource containing a practical code tutorial focused on the `FileInfo` class from the Cangjie standard library. It is designed to assist developers in mastering file system operations through real-world examples. The content covers a broad spectrum of essential tasks, including the creation of temporary files, the retrieval of parent directory metadata, and the logic necessary to check file types, such as distinguishing between regular files and directories. Furthermore, the tutorial highlights methods for inspecting and modifying file permissions, specifically addressing read, write, and execute access. It also includes references to commented-out examples for accessing timestamps and file size. This guide is primarily intended for Cangjie developers looking for a clear, functional reference to manipulate file metadata and manage user permissions effectively.
