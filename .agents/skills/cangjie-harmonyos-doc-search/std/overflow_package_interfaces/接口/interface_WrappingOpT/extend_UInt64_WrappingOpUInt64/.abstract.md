This directory contains API documentation for the Cangjie programming language, specifically focusing on the `WrappingOp` interface implementation for the `UInt64` type. It covers a comprehensive list of arithmetic and bitwise operations, including addition, subtraction, multiplication, division, modulo, negation, and bit shifting. The documentation highlights the use of a high-order truncation strategy to handle overflow, ensuring results wrap around rather than causing errors. Additionally, it details specific behaviors for shift operations, such as using the low 6 bits of the right operand for large shift amounts. This resource is suitable for Cangjie developers and software engineers requiring precise control over unsigned integer arithmetic behavior, particularly in performance-critical or low-level scenarios where overflow wrapping is desired.
