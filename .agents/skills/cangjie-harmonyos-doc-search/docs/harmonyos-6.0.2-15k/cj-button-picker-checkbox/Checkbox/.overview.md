# Checkbox

This directory contains comprehensive documentation for the Checkbox component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the component's initialization, configuration properties, event handling, and practical implementation examples. Key topics include customizing shapes, colors, checkmarks, and managing selection states via `onChange` events. The documentation is intended for developers building user interfaces on HarmonyOS who need to implement flexible form controls and interactive options. It provides both API references and code samples to facilitate the creation of standard or custom-styled checkboxes starting from API version 12.

## Detailed Description

### Checkbox_4more.md Checkbox_4more.md
This document serves as API reference documentation for the Checkbox component within the ArkUI framework, used for enabling or disabling options. The primary focus is on the component's initialization method, `init`, which defines parameters for the checkbox name, group association for coordination with CheckboxGroup, and a custom indicator builder for selected states. It notes that the component supports all universal attributes and events. Intended for developers using the Cangjie language, this guide details the syntax and parameters required to implement standard or custom-styled checkboxes in user interfaces starting from version 12.

### 示例代码.md 示例代码.md
This document provides practical code examples for configuring and customizing the Checkbox component within the Cangjie UI framework. It covers three distinct scenarios: setting checkbox shapes like Circle and Rounded Square, customizing the checkmark appearance using stroke properties, and implementing text-based indicators via indicatorBuilder. Key takeaways include the usage of properties such as selectedColor, shape, and mark, alongside event handling through onChange, demonstrating how to replace default graphics with custom UI elements. This guide targets application developers using the Cangjie language to build user interfaces, specifically those requiring flexible form controls and styling options.

### 组件事件_2more.md 组件事件_2more.md
This document serves as API reference material for ArkUI component events and configurations in the Cangjie programming language. It primarily covers the onChange event handler, which triggers a callback when a selection state changes, returning a boolean value. Additionally, it defines the CheckBoxConfiguration class, which encapsulates the state properties for a checkbox, including its name, selected status, and a trigger change function. The documentation outlines constructor parameters and property read-write capabilities. Targeted at developers, this guide provides the necessary specifications for implementing and managing checkbox interactions within HarmonyOS applications.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring the properties of a CheckBox component within the ArkUI framework using the Cangjie language. It details specific functions including mark, select, selectedColor, shape, and unselectedColor, providing syntax, parameters, and default values for each. Key takeaways include methods to control the checkbox's visual appearance, such as shape, colors, and internal icon styles, as well as its selection state. The documentation specifies system capabilities and version requirements for each function. This technical reference is intended for developers building UI applications who need to programmatically customize checkbox behaviors and styles.
