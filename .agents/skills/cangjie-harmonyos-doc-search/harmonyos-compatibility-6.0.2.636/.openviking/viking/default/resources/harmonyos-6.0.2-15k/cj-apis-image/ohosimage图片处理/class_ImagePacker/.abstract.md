This directory contains API reference documentation for the ImagePacker class and associated packing functions within the Cangjie ImageKit. It focuses on image compression and encoding into formats such as JPEG, WebP, and PNG. Key topics include resource management, the `packToData` and `packToFile` methods, and the use of `PackingOption` configurations for various image sources like ImageSource, PixelMap, and Picture. The documentation also covers error handling and system capabilities for image processing. It is suitable for software developers using the Cangjie language who need to implement image compression, file output, and data encoding features in their applications.
