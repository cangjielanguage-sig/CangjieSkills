### 关闭特定域名页面的广告过滤

在Web组件的广告过滤开关开启后，应用有时候会期望关闭一些特定页面的广告过滤功能，除了可以使用自定义的easylist规则，AdsBlockManager还提供了[addAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockdisallowedlistarraystring)接口完成此功能。

```cangjie
// index.cj
import ohos.state_macro_manage.*
import kit.ArkWeb.{WebviewController, AdsBlockManager}
import kit.UIKit.{Web, BusinessException, ButtonOptions, ButtonType, AsyncError, TextInputController, TextInput, Color}

@Entry
@Component
class EntryView {
    let webController = WebviewController()
    let mainUrl: String = 'https://www.example.com'
    let textIputController: TextInputController = TextInputController()
    @State
    var inputText: String = 'https://www.example.com'

    func build() {
        Column {
            Row {
                Column {
                    TextInput(text: inputText, placeholder: mainUrl, controller: textIputController).id("input_url").
                        height(40).margin(5).borderColor(Color.BLUE).onChange {
                        value => this.inputText = value
                    }.margin(10)
                    Button(ButtonOptions(shape: ButtonType.Capsule)) {
                        Text("Go")
                    }.onClick {
                        evt => webController.loadUrl(this.inputText);
                    }.margin(10)

                    Button(ButtonOptions(shape: ButtonType.Capsule)) {
                        Text("addAdsBlockDisallowedList")
                    }.onClick {
                        evt =>
                        let arrDomainSuffixes: Array<String> = ["example.com", "abcdefg.cn"]
                        AdsBlockManager.addAdsBlockDisallowedList(arrDomainSuffixes)
                    }.margin(10)
                }
            }
            Web(src: mainUrl, controller: webController).onControllerAttached {
                => try {
                    webController.enableAdsBlock(true)
                } catch (e: BusinessException) {
                    AppLog.error("ErrorCode: ${e.code},  Message: ${e.message}")
                }
            }
        }
    }
}
```

[addAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockdisallowedlistarraystring)接口将域名设置到AdsBlockManager的DisallowedList中，下次页面加载时会使用网页url和DisallowedList中的域名进行后缀匹配，匹配成功则不会对此页面进行广告过滤。此外，还提供了[addAdsBlockAllowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockallowedlistarraystring)接口配合DisallowedList进行域名设置，控制是否开启广告过滤。

AdsBlockManager中缓存有2组域名列表，分别为DisallowedList和AllowList，其中DisallowedList用于禁用网页的广告过滤，而AllowList用于重新开启被DisallowedList关闭的广告过滤开关，其中AllowList优先级更高。页面加载时会先使用网页url和AllowList进行匹配，匹配成功的网页广告过滤将保持开启，否则将会继续使用DisallowedList进行匹配，匹配成功将关闭网页的广告过滤。如果访问的网页不在AllowList和DisallowedList中，那么默认网页的广告过滤会保持开启状态。

例如，应用想要开启域名为'news.example.com'和'sport.example.com'的广告过滤，但需要关闭'example.com'的其他域名下网页的广告过滤，就可以先使用addAdsBlockDisallowedList()接口添加'example.com'域名到DisallowedList，再使用[addAdsBlockDisallowedList()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-addadsblockdisallowedlistarraystring)接口添加'news.example.com'和'sport.example.com'域名。
