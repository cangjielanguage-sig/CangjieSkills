# enum_Display

This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically targeting the `Display` enum and its related functionality. It serves as a technical guide for managing system display settings, covering critical aspects such as font scaling factors, screen brightness levels, auto-brightness status, and screen-off timeout configurations. Additionally, it documents utility functions for formatting these settings into string representations. Designed for application developers and system engineers, this directory facilitates the integration of display preference controls into Cangjie-based applications. It includes details on system capabilities, API versioning (starting from version 22), and code examples for retrieving values, ensuring developers have the necessary tools to implement robust display management features.
