# cj-api-business_exception

This directory provides API reference documentation for the Cangjie language module `ohos.business_exception`, specifically designed to handle common exceptions that occur during interface calls. It details the `BusinessException` class, which inherits from the base `Exception` class and includes features such as a read-only error code, a method to retrieve custom generic data, and a string conversion function. Additionally, the documentation defines the `AsyncCallback` type to support asynchronous error handling scenarios. Currently in Beta, this module targets Cangjie developers who are building applications and require robust error management mechanisms. Users should note that standard import syntax is required as Kit support is pending. This resource is essential for understanding how to implement and manage business logic errors effectively in Cangjie projects.
