### func selectIcon(?Bool)

```cangjie
public func selectIcon(value: ?Bool): This
```

**功能：** 设置当菜单项被选中时，是否显示被选中的图标。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 22

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|value|?Bool|是|-|菜单项被选中时，是否显示被选中的图标。初始值：false。|
