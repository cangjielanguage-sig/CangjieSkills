This directory contains API reference documentation for the `EnvironmentCallback` class in the Cangjie programming language, specifically designed for HarmonyOS application development. It covers mechanisms for handling system environment changes, including configuration updates (such as language or screen density) and memory level fluctuations. It is suitable for HarmonyOS developers who need to dynamically manage application behavior in response to system resource changes and ensure app stability under varying memory conditions.
