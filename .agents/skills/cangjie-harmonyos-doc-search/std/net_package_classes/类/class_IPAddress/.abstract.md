This directory contains API reference documentation for the `IPAddress` class in the Cangjie programming language's standard library (`std.net`). It covers the representation and manipulation of Internet Protocol addresses, including both IPv4 and IPv6. Key topics include class definition, property inspection, serialization, comparison, DNS resolution, and safe parsing methods. The documentation is designed for Cangjie developers building network applications who need to handle IP address objects, validate address types, and perform network protocol operations programmatically.
