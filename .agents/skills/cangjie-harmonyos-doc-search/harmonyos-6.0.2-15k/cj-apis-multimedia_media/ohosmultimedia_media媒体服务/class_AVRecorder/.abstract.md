This directory contains API reference documentation for the `AVRecorder` class within the Cangjie MediaKit, designed for managing audio and video recording in HarmonyOS applications. It covers the complete lifecycle of the recorder, including configuration, state management, error handling, and resource control. Key topics include audio capture parameters, video surface input, callback subscriptions, and rotation updates. This documentation is suitable for software developers and multimedia engineers implementing robust recording features using the Cangjie language, providing essential details on system capabilities, permissions, and exception handling.
