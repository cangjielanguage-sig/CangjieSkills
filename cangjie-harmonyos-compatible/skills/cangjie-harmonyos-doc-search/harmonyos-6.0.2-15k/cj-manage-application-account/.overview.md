# cj-manage-application-account

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie language to manage application accounts. It focuses on the App Account SDK and BasicServicesKit framework, covering the entire account lifecycle. Key topics include creating local accounts, querying account lists, and managing custom data and credentials securely. The documentation also details critical security workflows such as setting and retrieving authorization tokens and removing accounts upon user logout. Important APIs covered include `createAccount`, `getAllAccounts`, `setAuthToken`, `getAuthToken`, and `removeAccount`. This guide is intended for application developers aiming to implement robust user account persistence, secure authentication flows, and data management, ensuring high standards of data integrity and security throughout the user session. It is suitable for developers looking to integrate secure account management into their Cangjie-based applications.
