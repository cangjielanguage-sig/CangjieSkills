# 菜单控制

本目录主要介绍HarmonyOS ArkUI框架下的菜单控制功能，涵盖了弹出式菜单的API参考与实战示例。核心内容包括bindContextMenu和bindMenu的使用方法、触发机制（长按、点击、右键）、自定义构建器（CustomBuilder）的应用以及菜单的样式与动画配置。该文档适合具备仓颉语言基础的开发者，旨在帮助其掌握复杂的组件交互逻辑与高级UI效果实现。
