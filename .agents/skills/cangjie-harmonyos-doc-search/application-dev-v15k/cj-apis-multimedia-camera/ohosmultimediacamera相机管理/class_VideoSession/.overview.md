# class_VideoSession

This directory contains API reference documentation for the `VideoSession` class within the Cangjie CameraKit framework. Key topics include camera capabilities like Flash, AutoExposure, Focus, and Zoom, as well as methods for registering and unregistering callbacks for errors and state changes. The documentation provides Cangjie code examples and details system capabilities. It is intended for developers building camera applications who need to manage video recording sessions, handle asynchronous events, and configure camera parameters programmatically.

### func_offCameraCallbackType_2more.md func_offCameraCallbackType_2more.md
This API reference document details methods for managing camera event listeners in the Cangjie CameraKit, specifically for handling error, focus, and zoom events. It covers the `off` function for unregistering listeners and the `on` function for registering error callbacks, including syntax, parameters, and usage examples. Key information includes that `off` supports error, focus state, and smooth zoom events, while `on` is restricted to error events returning a `BusinessException`. Both functions require a valid session context and operate under SystemCapability.Multimedia.Camera.Core starting from version 19. This guide targets Cangjie developers implementing camera session management who need to handle asynchronous camera states and errors.
