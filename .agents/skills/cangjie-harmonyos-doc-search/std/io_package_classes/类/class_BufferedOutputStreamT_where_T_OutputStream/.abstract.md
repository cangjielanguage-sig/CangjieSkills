This directory contains API documentation for the Cangjie `BufferedOutputStream` class, a generic wrapper designed to enhance I/O performance by buffering data before writing to an underlying output stream. It covers class definitions, constructors with various buffer configurations, and extensions for resource management and seekable operations. Key topics include memory optimization, automatic cleanup via the Resource interface, random access capabilities, and low-level byte writing functions. This documentation is suitable for Cangjie developers looking to implement efficient, safe, and flexible data output operations in their applications.
