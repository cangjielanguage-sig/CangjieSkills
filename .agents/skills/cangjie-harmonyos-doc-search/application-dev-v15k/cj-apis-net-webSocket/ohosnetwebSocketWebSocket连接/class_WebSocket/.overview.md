# class_WebSocket

This directory contains API reference documentation for the WebSocket class within the Cangjie NetworkKit, designed for HarmonyOS application development. It covers the complete lifecycle of WebSocket communication, including establishing connections, sending and receiving data, managing event subscriptions, and closing connections. Key topics include asynchronous operations using AsyncCallback, permission requirements, and exception handling. This documentation is suitable for Cangjie developers and network engineers implementing real-time, bidirectional communication protocols in their applications.
