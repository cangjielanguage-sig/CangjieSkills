# hdc错误码

This directory serves as a comprehensive repository for troubleshooting guides related to HarmonyOS Device Connector (HDC) error codes. It specifically addresses common issues encountered during command-line interactions, such as invalid bundle names, unsupported interactive modes, and file transfer failures. The documentation provides detailed root cause analysis and step-by-step resolution strategies using standard HarmonyOS commands like `hdc`, `bm`, and `aa`. This resource is essential for HarmonyOS developers and QA engineers looking to quickly diagnose and fix CLI errors during the application development, debugging, and deployment lifecycle.

## Detailed Description

### E003001_命令行指定的包名非法.md E003001_命令行指定的包名非法.md
This troubleshooting guide addresses error code E003001, which occurs when an invalid bundle name is specified in the `hdc shell` command. The document outlines three primary causes: the application is not installed, not built in debug mode, or not currently running. It provides detailed resolution steps, including specific `hdc` and `bm` commands to verify installation status and debug configuration, as well as `aa` commands to launch the app. Key takeaways include the requirement for debug-signed applications and the necessity of mounting resource directories. Intended for HarmonyOS developers, this guide assists in diagnosing and resolving command-line execution failures during the development process.

### E003002_命令行指定的参数不支持交互模式_8more.md E003002_命令行指定的参数不支持交互模式_8more.md
This document serves as a troubleshooting reference for specific error codes encountered when using the HDC command-line tool for shell execution and file transfer. Additionally, it addresses E005101 through E005004 related to file operations, including invalid bundle names, illegal remote paths, and SDK or device version incompatibilities. Each entry provides the error message, description, potential causes, and resolution steps. This guide targets HarmonyOS developers and testers needing to diagnose and resolve command-line interface issues during application debugging or file management.
