# 自定义弹窗CustomDialog

本目录汇集了ArkUI框架中关于自定义弹窗功能的开发文档与示例代码，主要面向使用仓颉语言的开发者。内容涵盖了如何使用CustomDialogController创建和管理对话框、定义自定义UI组件以及详细的配置选项。核心知识点包括@CustomDialog装饰器的使用、弹窗的生命周期管理（如打开、关闭、销毁）以及样式与交互行为的精细配置。无论是初学者学习交互逻辑，还是进阶开发者进行UI定制，本目录都能提供有价值的参考。

## 详细描述

### 示例代码_0223c040.md
本文档旨在演示如何在仓颉语言中使用ArkUI框架创建并控制自定义对话框。主要内容包括定义带有取消和确认按钮的MyDialog类，以及在主视图EntryView中通过CustomDialogController管理对话框的显示与关闭。关键点在于利用@CustomDialog装饰器构建UI，通过CustomDialogController实例化对话框，并使用controller?.releaseSelf()方法实现点击按钮后的自我销毁逻辑。该文档面向仓颉语言及ArkUI的开发者，适合作为学习自定义弹窗组件交互逻辑的参考教程。

### 自定义弹窗CustomDialog_3more_5b415a62.md
本文档是ArkUI框架中自定义弹窗功能的API参考文档，旨在指导开发者使用CustomDialogController类创建和管理具有自定义样式的弹窗。文档主要内容包括模块导入、CustomDialogController类的构造函数及其配置选项，以及openDialog、closeDialog和releaseSelf等关键成员方法。核心信息指出该功能目前处于Beta阶段，支持灵活配置弹窗内容，并明确了SubWindow模式下的使用限制。本文档面向使用仓颉语言进行ArkUI应用开发的开发人员，需具备基础UI框架知识。

### class_CustomDialogControllerOptions/
本目录包含ArkUI框架中Cangjie语言的API参考文档，专注于`CustomDialogControllerOptions`类的定义与配置。内容涵盖了自定义弹窗的全方位设置，包括布局样式（尺寸、边框、圆角）、视觉效果（阴影、模糊、背景色）、交互行为（模态、自动取消、蒙层）以及动画和生命周期回调。该文档适合使用Cangjie开发ArkUI界面的开发者，旨在帮助他们通过精细的参数配置实现灵活且美观的自定义弹窗功能。
