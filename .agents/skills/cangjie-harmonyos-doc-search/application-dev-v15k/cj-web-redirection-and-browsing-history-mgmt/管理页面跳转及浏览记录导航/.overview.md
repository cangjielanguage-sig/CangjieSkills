# 管理页面跳转及浏览记录导航

This directory provides comprehensive technical guidance for managing page navigation and browsing history within HarmonyOS applications. It focuses specifically on the ArkWeb component and utilizes the Cangjie programming language for implementation. The content covers two critical areas: managing web history states, such as forward and backward navigation, and implementing complex transitions from web content to native pages or external applications. Key concepts include automatic history recording, network permission configuration, URL interception, and custom URL schemes. This documentation is essential for HarmonyOS developers who aim to create seamless, integrated navigation experiences between web content and the native application environment, ensuring smooth user interaction flows and robust application behavior.

## Detailed Description

### 历史记录导航.md
This document provides a detailed tutorial on managing the navigation stack within the ArkWeb component, a crucial aspect of user experience in hybrid applications. It explains how to implement forward and backward navigation for web history. The guide covers automatic history recording, network permission configuration in module.json5, and a Cangjie code example demonstrating button-triggered navigation. Key information includes the usage of `forward()`, `backward()`, `accessForward()`, and `accessBackward()` APIs. The document emphasizes checking history availability before navigation to prevent invalid operations. This tutorial is intended for application developers using the Cangjie language and ArkWeb framework to manage web browsing states.

### 页面跳转_2more.md
This document focuses on the interaction between web content and the native HarmonyOS system, enabling developers to leverage native capabilities directly from web views. It demonstrates how to implement page navigation from web content to native pages or external applications within HarmonyOS apps using the Web component. It covers two primary scenarios: in-app navigation using custom URL schemes and cross-application navigation, specifically launching the phone dialer. The core mechanism involves the onLoadIntercept() interface to intercept link clicks. Examples include using Router.pushUrl for internal navigation and TelephonyCall.makeCall for external calls, utilizing Cangjie code. This tutorial targets HarmonyOS developers using the Cangjie language who need to integrate web-to-native interaction flows.
