This directory serves as a comprehensive technical resource for analyzing Application Not Responding (ANR) and freeze logs within the HarmonyOS/OpenHarmony ecosystem. The content includes detailed guides on main thread blocking, stack trace analysis, and system resource monitoring. It is suitable for system developers, QA engineers, and software engineers focused on debugging application stability, performance bottlenecks, and responsiveness issues.

### 应用无响应日志分析_2more.md 应用无响应日志分析_2more.md
This technical guide provides a methodology for analyzing application freeze (appfreeze) logs within the HarmonyOS environment. It covers the interpretation of log header fields, specifically Reason, PID, and PACKAGE_NAME, and presents a sample log block illustrating a lifecycle timeout scenario. This technical reference guide explains how to analyze specific log scenarios related to application performance timeouts. It covers User Input Response Timeout (APP_INPUT_BLOCK) and Lifecycle Switch Timeout (LIFECYCLE_TIMEOUT), detailing their reasons, message formats, and log examples. Key takeaways include the observation that these timeouts often correlate with main thread appfreeze events. The document advises analysts to compare stack traces and BinderCatcher information from both specific and general logs to identify root causes, such as numerous small events blocking input. Intended for system developers or QA engineers debugging application responsiveness and lifecycle issues.
