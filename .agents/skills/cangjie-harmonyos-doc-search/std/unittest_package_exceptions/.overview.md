# unittest_package_exceptions

This directory contains the essential API reference documentation for the `unittest_package_exceptions` module, a critical component for developers working with the Cangjie unittest framework. It provides a detailed breakdown of specific exception classes thrown during testing operations, enabling precise error handling and debugging. The documentation covers four distinct classes: `AssertException` for handling standard assertion failures, `AssertIntermediateException` designed for power assertions, `UnittestException` which serves as the base error for the framework, and `UnittestCliOptionsFormatException` specifically for command-line parsing errors. Beyond simple definitions, the text explains inheritance hierarchies from the core Exception class, details constructors for custom messages, and outlines debugging properties such as `expression` and `originalException`. Understanding these exceptions is vital for creating robust test suites, as they allow developers to pinpoint exactly where and why a test has failed, whether due to logic errors, incorrect input, or framework misuse. This resource is specifically tailored for developers who need to catch specific errors, understand failure propagation, or implement custom error reporting logic within their test suites.
