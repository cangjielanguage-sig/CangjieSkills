This directory contains the API reference documentation for the `ColorMetrics` class within the Cangjie language, specifically designed for the ArkUI framework. It serves as a comprehensive guide for developers seeking to implement structured color manipulation in their applications. The documentation covers the definition of read-only properties for individual color components—red, green, blue, and alpha—as well as the resulting RGBA string. It details static factory methods for instantiating the class using HEX values, RGBA components, or resource color enums. Additionally, it explains advanced functionalities such as color overlay blending and conversion to 32-bit unsigned integers. This resource is intended for ArkUI developers working on HarmonyOS applications who need precise control over color resources and requires SystemCapability.ArkUI.ArkUI.Full, available starting from version 19.
