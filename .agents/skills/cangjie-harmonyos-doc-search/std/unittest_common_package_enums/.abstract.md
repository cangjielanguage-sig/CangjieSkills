This directory serves as the central repository for API reference documentation concerning enumeration types within the unittest common package of the Cangjie programming language. It is designed to provide developers with a clear understanding of the data structures that underpin the testing framework's capabilities. The content primarily focuses on two critical enumerations: the `Color` enum, which is essential for specifying standard output colors and includes implementations for equality operators, and the `OptionValidity` enum, which is vital for representing the results of configuration validation. These structures are indispensable for tasks such as formatting test output to improve readability and ensuring that command-line options are validated correctly. This documentation is suitable for software developers, QA engineers, and framework contributors who are utilizing the unittest framework and need to understand these data structures to effectively manage test output formatting and command-line option validation.
