# 开发步骤

This directory provides a structured technical guide for developers working with the Cangjie language to control device vibrations in HarmonyOS or OpenHarmony environments. It covers the complete implementation lifecycle using the SensorServiceKit, starting from the necessary VIBRATE permission applications to the execution of complex vibration patterns. The tutorials detail how to initiate motor vibrations using fixed durations, built-in preset effects, or custom configuration files, as well as how to terminate these vibrations based on specific modes. Key technical concepts include the `startVibration` and `stopVibration` APIs, UIAbilityContext for resource handling, and comprehensive exception management. This resource is specifically designed for application developers who need to integrate haptic feedback into their apps and are looking for practical, code-oriented examples and best practices in system resource management. By following these steps, developers can ensure their applications provide responsive and compliant haptic experiences.

## Detailed Description

### 开发步骤_1.md
This document serves as a technical tutorial guiding developers through controlling device vibration using the Cangjie language and SensorServiceKit. The content is structured into three main steps: applying for the VIBRATE permission, triggering motor vibrations via duration, preset effects, or custom configuration files, and stopping vibrations based on specific modes. Key takeaways include the usage of startVibration and stopVibration APIs, handling UIAbilityContext for custom file resources, and exception management. This guide is intended for application developers implementing haptic feedback in HarmonyOS or OpenHarmony environments, requiring knowledge of Cangjie syntax and system resource management.

### 开发步骤_2.md
This document provides code examples for stopping device vibration using the SensorServiceKit in the Cangjie programming language. It covers two distinct methods: stopping vibration based on a preset mode and stopping all vibration modes, including custom ones. Key information includes the usage of the `stopVibration` function with specific parameters like `VIBRATOR_STOP_MODE_PRESET` and `Option<VibratorStopMode>.None`, alongside standard error handling practices. This technical reference is intended for application developers implementing haptic feedback control, requiring knowledge of Cangjie syntax and exception handling.
