# 示例代码

This directory serves as a comprehensive technical resource for Cangjie developers engaged in HarmonyOS application development, specifically targeting the ArkUI framework. It provides detailed code examples that address complex window management tasks, such as modifying window touchability to restrict user interaction and monitoring keyboard height changes to ensure optimal UI responsiveness. The examples also delve into the lifecycle of modal sub-windows, demonstrating how to implement touch event callbacks to dismiss windows dynamically. Key technical concepts covered include the use of `setWindowTouchable`, `AppStorage` for state synchronization, and `WindowStage` for window configuration. These materials are ideal for developers who need to implement precise control over application windows and handle system-level UI events efficiently in their Cangjie projects. The directory includes specific guides on main window settings and sub-window callback functions.

## Detailed Description

Below are the detailed summaries for each file contained in this directory.

### 示例1获取主窗口设置不可触属性_2more.md
This document provides Cangjie code examples demonstrating window management capabilities in HarmonyOS application development. It covers two primary scenarios: setting the main window's touchability and monitoring keyboard height changes. Key takeaways include using `setWindowTouchable(false)` to disable user interaction and implementing event listeners with custom callbacks to track keyboard state changes via `AppStorage`. The content targets developers using the Cangjie language who need to implement specific window behaviors or UI event handling within the ArkUI framework.

### 示例3设置子窗口回调函数.md
This tutorial demonstrates how to create a modal sub-window and implement a callback function to close it when the modal area is clicked. The document covers MainAbility setup, AppStorage usage for sharing the WindowStage, and SubWindowOptions configuration. Key takeaways include setting the isModal property to true, registering a DialogTargetTouch event listener to trigger window destruction, and managing main window visual states like grayscale. Intended for Cangjie developers, this example illustrates the lifecycle of modal windows and event handling within the ArkUI framework.
