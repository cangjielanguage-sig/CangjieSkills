# cj-universal-event-hover

This directory contains the API reference documentation for the universal event hover functionality within the Cangjie ArkUI framework. It is specifically designed to assist developers in managing and responding to user interactions involving cursors or styluses moving over UI components. The content comprehensively covers the event definition, lists supported input devices such as mice and styluses, and provides specific implementation details for the `onHover` function. Key topics include the Boolean callback mechanism for detecting entry and exit states, which is available starting from version 12. This resource is highly suitable for Cangjie developers looking to implement interactive UI behaviors, proximity-based responses, and enhanced user feedback mechanisms in their applications. By utilizing these events, developers can create dynamic interfaces that react intuitively to user presence.

## Detailed Description

### cj-universal-event-hover.md cj-universal-event-hover.md
This API reference document details the hover event functionality within the Cangjie ArkUI framework, explaining how to handle cursor or stylus interactions over UI components. It serves as a comprehensive guide for developers to understand the underlying mechanics of event handling when a user's input device hovers over a specific interface element.

The document covers several critical aspects of the feature:
*   **Event Definition:** It provides a clear definition of what constitutes a hover event within the framework context.
*   **Supported Input Devices:** It explicitly lists supported hardware, including mice and styluses, ensuring developers know the scope of compatibility.
*   **Function Implementation:** It details the specific `onHover` function implementation.

The core takeaway is the `onHover` method, which accepts a Boolean callback where `true` indicates entry and `false` indicates exit. This functionality is available starting from version 12. This guide targets Cangjie developers seeking to implement interactive UI behaviors based on user input proximity.
