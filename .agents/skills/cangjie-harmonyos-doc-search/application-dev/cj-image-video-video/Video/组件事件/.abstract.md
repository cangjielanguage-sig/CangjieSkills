This directory provides essential API reference documentation for handling component events, specifically focusing on video playback controls within the ArkUI framework using the Cangjie language. It covers a comprehensive set of event callbacks designed to monitor and respond to player status changes. Key topics include error handling, playback lifecycle events (such as start, pause, finish, and seeking), and fullscreen mode transitions. The documentation details function signatures, parameter types like PreparedInfo and FullscreenInfo, and return values that support method chaining. This resource is intended for developers building video applications who need to implement robust event listeners and manage player behavior programmatically.
