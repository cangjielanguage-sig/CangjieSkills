# 播放音量管理

This directory serves as a comprehensive technical resource for managing playback volume in HarmonyOS applications developed with the Cangjie language. It provides a deep dive into the multi-layered volume architecture, clearly distinguishing between system, application, and audio stream volumes. The documentation explains the mathematical relationship between these layers—specifically how the final output is the product of all three—and offers practical implementation strategies. Key topics include monitoring system volume changes using the AudioVolumeManager API and programmatically adjusting stream volumes for AVPlayer and AudioRenderer components. Additionally, it highlights constraints such as the current lack of support for application volume modification. This guide is indispensable for HarmonyOS developers and multimedia engineers seeking to implement sophisticated audio control and ensure consistent user experiences across different audio scenarios.

### 播放音量管理_3more.md 播放音量管理_3more.md

This document outlines the playback volume management capabilities in HarmonyOS, detailing the hierarchy and interaction between system, application, and audio stream volumes. Main sections cover the definitions of these volume types, their mathematical relationship in determining final output, and specific implementation for system volume monitoring. Key information includes that final volume is a product of all three levels and that while system volume can be monitored via the AudioVolumeManager API using Cangjie code, application volume modification is currently unsupported. This technical guide targets HarmonyOS developers seeking to implement precise audio control within their applications.

### 音频流音量.md 音频流音量.md

This document serves as a technical guide for managing audio stream volume in Cangjie applications. It details the implementation of the setVolume() method across two main components: AVPlayer in MediaKit and AudioRenderer in AudioKit. Key takeaways include the valid volume range of 0.0 to 1.0 and the necessity of exception handling using BusinessException. The content provides specific code snippets for both interfaces to demonstrate successful invocation and error logging. This resource is intended for developers building multimedia features who need to programmatically adjust audio levels.
