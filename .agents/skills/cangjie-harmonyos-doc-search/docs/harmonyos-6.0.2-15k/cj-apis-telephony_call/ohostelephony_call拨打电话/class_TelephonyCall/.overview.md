# class_TelephonyCall

This directory contains API reference documentation for the `TelephonyCall` class within the Cangjie programming language, specifically designed for the TelephonyKit framework. It provides comprehensive resources for managing telephony operations, such as formatting phone numbers into standard or E.164 formats, retrieving current device call states, and launching the system dialer. The documentation covers static methods for checking voice capabilities, validating emergency numbers, and handling specific `BusinessException` error codes for invalid inputs or system failures. This content is essential for Cangjie developers building HarmonyOS applications who require robust telephony integration and need to understand system permissions and error handling mechanisms.

### static_func_makeCallString_2more.md static_func_makeCallString_2more.md
This API reference document details the makeCall static functions within the TelephonyKit for launching the system dialer interface. It covers two overloaded methods: a basic version accepting a phone number (API 12) and an extended version requiring a UIAbilityContext (API 19). Both functions display the specified number on the dialer screen and require the ohos.permission.START_ABILITIES_FROM_BACKGROUND permission for background use. The document specifies input parameters, system capabilities, and potential BusinessException error codes ranging from parameter errors to system failures. This guide targets Cangjie language developers implementing telephony features in HarmonyOS applications.
