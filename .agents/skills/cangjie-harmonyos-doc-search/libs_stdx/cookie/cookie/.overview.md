# cookie

This directory provides comprehensive documentation and practical code examples for handling HTTP cookies within the Cangjie programming language ecosystem. It addresses the dual aspects of web state management: the client-side perspective, focusing on receiving, storing, and resending cookies via a `CookieJar`, and the server-side perspective, detailing how to construct servers that issue `Set-Cookie` headers to clients. The tutorials leverage Cangjie's standard library extensions, covering essential networking concepts such as request lifecycles, response parsing, synchronization primitives, and socket communication. This resource is ideal for Cangjie developers aiming to build robust, stateful web applications or those seeking a deeper understanding of network programming and session persistence protocols. By exploring these examples, developers can master the mechanisms required to maintain user sessions and state across multiple HTTP requests.

## Detailed Description

The following files provide specific implementations and tutorials covering both the client and server sides of HTTP cookie interactions in Cangjie. These resources are designed to give developers a complete understanding of how state is maintained in stateless protocols.

### Client.md Client.md

This document serves as a practical tutorial demonstrating the usage of the HTTP Client in the Cangjie programming language, with a specific focus on cookie management. The code example illustrates the complete lifecycle of sending requests and handling responses, detailing how the client automatically parses Set-Cookie headers from a server and stores them in a CookieJar. Key takeaways include the automatic inclusion of valid cookies in subsequent requests and the logic for filtering out expired cookies based on maxAge. Intended for Cangjie developers, this guide helps implement session persistence and understand HTTP state management within the standard library extensions.

### Server.md Server.md

This document serves as a code tutorial demonstrating how to create an HTTP server in the Cangjie language that sets cookies. It covers the complete workflow including server construction using ServerBuilder, registering request handlers, and utilizing synchronization primitives. The example also includes a client simulation using TcpSocket to verify the HTTP response headers. Key takeaways involve understanding the Set-Cookie header implementation and raw socket communication. This guide is intended for developers learning Cangjie's standard library for network operations and HTTP server development.
