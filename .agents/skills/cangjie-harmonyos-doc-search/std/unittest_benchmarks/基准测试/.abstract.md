This directory provides a comprehensive guide to benchmarking within the Cangjie unit testing framework. It covers the fundamentals of performance testing, including the use of the `@Bench` macro, warmup phases, and noise reduction techniques. The content also addresses advanced topics such as achieving reliable results, understanding internal measurement algorithms, parametric benchmarking, and advanced configuration options like custom metrics and reporting. Designed for Cangjie developers and performance engineers, these resources help users accurately measure code execution time, optimize performance, and ensure reproducible results.
