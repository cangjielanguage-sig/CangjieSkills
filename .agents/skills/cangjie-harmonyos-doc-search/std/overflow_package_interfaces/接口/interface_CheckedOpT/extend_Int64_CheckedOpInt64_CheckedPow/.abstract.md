This directory provides comprehensive API documentation for the Cangjie programming language, specifically focusing on the implementation of safe arithmetic and bitwise operations for the `Int64` type. It details the `CheckedOp` and `CheckedPow` interfaces, which are essential for preventing runtime errors caused by integer overflows. The documentation covers a wide range of functions, including basic arithmetic like addition, division, and multiplication, as well as advanced operations such as negation, power calculation, and bitwise shifting. A core feature of these APIs is the use of the `Option` return strategy, which returns `None` upon overflow or invalid input, ensuring robust error handling. This resource is designed for Cangjie developers who need to implement reliable, safe mathematical logic in their software without relying on exception handling for overflow scenarios. By utilizing these checked operations, developers can ensure their applications handle edge cases gracefully, maintaining system stability and data integrity during complex computations. The documentation serves as a critical reference for building secure and resilient applications in the Cangjie ecosystem, providing the necessary details to integrate these safety mechanisms effectively.
