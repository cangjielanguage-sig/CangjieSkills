# 基础类型定义

This directory contains essential API reference documentation for fundamental data structures utilized within the Cangjie language and the ArkUI framework. It focuses on the core class definitions required to effectively manage user interactions and event targets in HarmonyOS applications. The content covers the structural details of click events, including properties for spatial coordinates, timestamps, and input sources, as well as the definition of event target areas. These types are crucial for developers who need to implement precise event handling logic and track user interactions with high accuracy. By defining read-write properties and specific data types, this documentation provides the foundation for building responsive and robust user interfaces. This resource is specifically tailored for application developers and UI engineers seeking to deepen their understanding of the underlying type system driving the ArkUI framework.

## Detailed Description

The following sections provide in-depth technical specifications for each class defined in this directory.

### class_ClickEvent.md class_ClickEvent.md
This document provides API reference documentation for the ClickEvent class in the Cangjie language, used within the ArkUI framework to define click event structures. It details the class constructor and public properties, which include spatial coordinates relative to the element, window, and display, as well as the event timestamp, input source type, and target element. Key takeaways include the read-write nature of all properties and the specific data types used for precise location tracking. Intended for application developers, this guide assists in implementing robust event handling and user interaction logic in HarmonyOS applications.

### class_EventTarget.md class_EventTarget.md
This document serves as API reference documentation for the EventTarget class within the Cangjie language and ArkUI framework. It details the class structure, focusing on the public property area and the class constructor. The class represents the display area of an element triggering an event, utilizing an Area type object to define the target region, which is readable and writable. Intended for UI developers, this guide provides necessary parameters and versioning information for managing event targets.
