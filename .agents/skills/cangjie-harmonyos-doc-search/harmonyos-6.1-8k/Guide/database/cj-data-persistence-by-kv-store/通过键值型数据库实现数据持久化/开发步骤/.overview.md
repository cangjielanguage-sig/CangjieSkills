# 开发步骤

本目录提供了使用仓颉语言进行键值型数据库开发的详细步骤指南。内容涵盖了从获取KVManager实例、创建SingleKVStore数据库，到执行数据的增删改查等基础操作，以及数据库生命周期的管理（如关闭和删除）。文档通过具体的代码示例演示了如何配置KVOptions、处理BusinessException异常以及使用Hilog记录日志。本指南适用于需要在HarmonyOS应用中实现本地数据持久化及资源管理的开发者。

## 详细说明

### 开发步骤_1.md 开发步骤_1.md
这份文档是一份针对仓颉语言开发者的键值型数据库使用教程。主要涵盖了获取KVManager实例、创建SingleKVStore数据库、以及执行数据的插入、查询和删除操作。文档通过Cangjie代码示例详细演示了配置KVOptions、处理BusinessException异常及使用put/get/delete方法管理数据，并说明了put方法对已存在键值的更新行为。该指南适用于需要在HarmonyOS应用中实现本地数据持久化的开发者。

### 开发步骤_2.md 开发步骤_2.md
本文档旨在指导开发者如何使用仓颉语言管理分布式键值数据库的生命周期，重点演示了关闭和删除数据库的操作。文档主要包含两个代码示例：一是通过closeKVStore方法关闭指定storeId的数据库，二是通过deleteKVStore方法删除数据库。关键信息在于展示了如何使用kvManager执行这些操作，并利用try-catch块捕获BusinessException进行异常处理，同时使用Hilog记录操作结果。这是一份面向应用开发者的技术教程片段，适用于需要释放或清理数据存储资源的场景。
