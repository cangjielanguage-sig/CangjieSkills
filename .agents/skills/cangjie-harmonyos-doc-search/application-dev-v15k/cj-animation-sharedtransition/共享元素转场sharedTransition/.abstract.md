This directory provides comprehensive documentation and examples for implementing shared element transitions within the ArkUI framework using the Cangjie language. It covers the core API for page routing animations, configuration options for transition effects, and practical code demonstrations. Key topics include the `sharedTransition` function, `SharedTransitionOptions` class, animation parameters like duration and curve, and the Exchange effect type. This resource is suitable for HarmonyOS developers looking to enhance user experience with smooth, custom navigation animations and motion paths.
