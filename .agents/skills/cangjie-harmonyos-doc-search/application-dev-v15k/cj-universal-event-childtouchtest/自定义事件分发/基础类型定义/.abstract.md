This directory provides essential API reference documentation for fundamental data structures utilized in touch event handling within the Cangjie ArkUI framework. It specifically defines classes and enumerations that manage touch test results, dispatch strategies, and coordinate geometry. Key components include the `TouchResult` class for overriding system hit testing, the `TouchTestStrategy` enum for controlling event propagation, and the `TouchTestInfo` class for encapsulating precise touch location data. This documentation is intended for HarmonyOS developers who require granular control over touch interactions, custom component behavior, and event flow management in their applications. By understanding these base types, developers can implement sophisticated gesture recognition and custom UI behaviors that go beyond standard system defaults.
