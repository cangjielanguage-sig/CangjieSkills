# 参数化基准测试

This directory serves as a comprehensive resource for implementing parametric benchmarking in the Cangjie programming language. It details the effective use of `@Bench` and `@Strategy` macros to optimize performance testing, highlighting how to avoid common pitfalls like memory bloat and garbage collection interference. The content also delves into data management strategies, explaining the default immutability of input data and how to configure setups for scenarios requiring data modification. Designed for developers and performance engineers with a background in unit testing, this guide ensures users can generate meaningful, consistent, and high-performance benchmark results while managing data states effectively and reducing code redundancy.

## Detailed Description

### 参数化基准测试_1.md 参数化基准测试_1.md
This tutorial explains how to implement parametric benchmarking effectively using the @Bench and @Strategy macros in the Cangjie programming language. It covers basic benchmark syntax, the pitfalls of naive data pre-allocation such as memory bloat and garbage collection interference, and the advanced use of data strategies. Key takeaways include that while @Bench supports direct data inputs, using @Strategy is superior for complex data types. It generates data on-demand, reduces code redundancy, prevents garbage collection impact on unrelated tests, and produces clearer benchmark reports with meaningful argument names. This guide targets developers familiar with unit testing who need to write accurate, high-performance benchmarks.
Keywords: Parametric benchmarking, @Bench, @Strategy, Cangjie, GC interference, performance testing, data generation.
