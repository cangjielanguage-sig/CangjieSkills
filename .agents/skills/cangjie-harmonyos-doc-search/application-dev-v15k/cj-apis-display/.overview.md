# cj-apis-display

This directory serves as a comprehensive technical resource, providing API reference documentation for the `ohos.display` module specifically tailored for the Cangjie programming language. It is designed to assist developers in mastering screen attribute management within the WindowManager system, a critical component for modern application development. The documentation extensively covers essential data structures and functions required to handle a wide variety of display scenarios, ranging from standard monitors to complex foldable devices and non-standard screen shapes like cutouts and waterfall screens. Key topics addressed include the retrieval of display physical resolution, the identification of fold crease regions, the configuration of HDR formats, and the setup of event listeners to track dynamic hardware changes. This documentation is highly suitable for HarmonyOS developers and UI engineers who need to ensure their applications can dynamically adapt layouts to different screen configurations, effectively manage display states, and implement robust responsive logic for the latest foldable hardware innovations.
