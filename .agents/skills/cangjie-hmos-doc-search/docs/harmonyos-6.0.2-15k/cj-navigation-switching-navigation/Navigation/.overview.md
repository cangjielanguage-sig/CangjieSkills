# Navigation

This directory contains comprehensive documentation for the Navigation component within the ArkUI framework, specifically tailored for the Cangjie language. It covers the implementation of root view containers for route navigation, managing home pages, and handling NavDestination subpages. Key topics include navigation stack management, event handling, property configuration, and UI customization for toolbars and menus. This resource is suitable for HarmonyOS developers and software engineers looking to build robust, responsive application interfaces using Cangjie.

### Navigation_4more.md Navigation_4more.md
This document provides API reference documentation for the Navigation component within the ArkUI framework using the Cangjie language. It describes Navigation as a root view container for route navigation, managing the display of home pages and NavDestination subpages. ### 组件事件.md 组件事件.md
This document serves as an API reference for handling event callbacks within the Navigation component of the ArkUI framework using the Cangjie language. It details three specific event handlers: onTitleModeChange, onNavBarStateChange, and onNavigationModeChange. Key information includes the function signatures and descriptions of the specific UI triggers, such as scrolling affecting the title bar, toggling navigation bar visibility, or switching between single and double-column layouts. All functions require a callback parameter and return the current instance. This technical reference is intended for software developers using the Cangjie language to build responsive navigation interfaces in HarmonyOS applications.
