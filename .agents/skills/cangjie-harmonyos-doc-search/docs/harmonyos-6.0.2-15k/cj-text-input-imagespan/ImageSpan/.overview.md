# ImageSpan

The ImageSpan directory provides comprehensive documentation for the ImageSpan component within the Cangjie ArkUI framework. It covers the integration of inline images into text elements, detailing initialization methods, component properties, event handling, and practical code examples. Key topics include image loading states, error management, visual styling (alignment, scaling, backgrounds), and fundamental type definitions. This resource is suitable for HarmonyOS developers using Cangjie who need to implement rich text layouts with embedded images, manage asynchronous loading, and customize visual presentation.

## Detailed Description

### ImageSpan_4more.md ImageSpan_4more.md
This API reference document details the ImageSpan component, a child element of the Text component designed for displaying inline images within the Cangjie ArkUI framework. The documentation covers component creation via three initialization methods accepting AppResource, PixelMap, or String data sources, alongside supported universal attributes and events. Key takeaways include support for various image formats like png and jpg, Base64 strings, and specific file paths. The component supports size, background, and border attributes but restricts events to clicks only. Intended for HarmonyOS developers using Cangjie, this guide requires knowledge of the Text component and resource management.

### 示例代码.md 示例代码.md
This document provides practical Cangjie code examples demonstrating the usage of the ImageSpan component within the HarmonyOS UIKit framework. It is structured into two main examples focusing on visual styling and layout control. The first example illustrates how to manipulate image alignment and scaling using the verticalAlign and objectFit properties within a mixed text context. The second example demonstrates applying background styles, such as color and rounded corners, via the textBackgroundStyle property. This technical guide is intended for Cangjie developers looking to implement rich text and image layouts in their applications.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling image loading events within the ArkUI framework using the Cangjie programming language. It details two primary event handler functions: onComplete and onError. The onComplete function triggers upon successful data loading and decoding, providing image dimensions via ImageLoadResult. Conversely, onError activates during loading exceptions, returning error details through CJImageError. Both functions utilize callback mechanisms to manage asynchronous operations. This guide is intended for software developers implementing image handling logic in ArkUI applications, requiring knowledge of Cangjie syntax and event-driven programming.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring component properties within the ArkUI framework using the Cangjie programming language. It details specific methods including alt, colorFilter, objectFit, textBackgroundStyle, and verticalAlign. The documentation outlines parameters, system capabilities, and version requirements for each function, explaining how to set placeholder images, apply color matrix filters, define scaling types, and style backgrounds with border radii. Targeted at developers utilizing ArkUI for UI development, this reference requires knowledge of Cangjie syntax and image processing concepts to effectively manipulate image display and alignment behaviors.
