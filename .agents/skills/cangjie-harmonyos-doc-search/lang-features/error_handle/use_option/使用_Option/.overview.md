# 使用_Option

本目录包含关于仓颉语言中 Option 类型的使用指南，旨在帮助开发者掌握错误处理和值解构的核心技巧。内容涵盖了模式匹配、空值合并操作符（??）、安全调用操作符（?）以及 getOrThrow 异常处理机制。核心关键词包括 Option、模式匹配、异常处理、NoneValueException。这些文档适合正在学习或使用仓颉语言进行开发的程序员，特别是需要高效处理空值和异常情况的用户。

## 详细描述

### 使用_Option_1.md
这份文档旨在指导开发者在仓颉语言中使用 Option 类型进行错误处理和值解构。文档详细介绍了四种核心处理方式：通过模式匹配提取值、利用空值合并操作符（??）提供默认值、使用问号操作符（?）实现安全调用及多层访问，以及调用 getOrThrow 函数在无值时抛出异常。文中包含丰富的代码示例，展示了这些操作符的具体语法和执行逻辑。这是一份面向仓颉语言开发者的实用指南，帮助其高效处理可能为空的值。

### 使用_Option_2.md
本文档旨在演示仓颉语言中 Option 类型的 getOrThrow 方法用法及异常处理机制。主要内容包括代码示例，展示了从 Some 变体取值、从 None 变体触发异常以及使用 try-catch 捕获 NoneValueException 的过程。核心要点是 getOrThrow 在 Option 为 None 时会抛出异常，开发者必须通过异常处理逻辑来管理这种情况。适用于正在学习仓颉 Option 类型及错误处理的开发者，属于基础教程或 API 使用指南。关键词：仓颉、Option、getOrThrow、NoneValueException、异常处理。
