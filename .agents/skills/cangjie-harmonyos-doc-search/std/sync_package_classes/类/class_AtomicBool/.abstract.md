This directory contains comprehensive API reference documentation for the `AtomicBool` class within the Cangjie programming language's synchronization package. It is dedicated to facilitating thread-safe operations on boolean values, which is essential for robust concurrent programming scenarios. The documentation thoroughly covers the class constructor, Compare-And-Swap (CAS) logic, load, store, and swap operations. A significant focus is placed on the evolution of the API, specifically distinguishing between current standard methods that utilize default memory ordering and older, deprecated versions that required explicit `MemoryOrder` parameters. This resource is highly suitable for Cangjie developers who need to implement precise boolean state synchronization and ensure strict memory consistency in multi-threaded applications.
