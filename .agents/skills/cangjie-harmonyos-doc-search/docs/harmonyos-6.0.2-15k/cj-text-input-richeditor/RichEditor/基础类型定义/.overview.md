# 基础类型定义

This directory provides API reference documentation for fundamental data types in the Cangjie language, specifically designed for the ArkUI framework. It focuses on rich text editing components, covering definitions for text and image spans, paragraph styles, clipboard events, and menu configurations. These types allow developers to programmatically manipulate content, handle user interactions, and customize visual appearances within rich editors. Suitable for HarmonyOS developers, this documentation serves as a structural guide for implementing advanced text processing and UI features.

## Quick Navigation
