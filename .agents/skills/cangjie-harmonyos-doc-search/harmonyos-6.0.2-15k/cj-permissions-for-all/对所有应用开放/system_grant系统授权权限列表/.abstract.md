This directory serves as a comprehensive repository for HarmonyOS system_grant permission documentation. It provides detailed technical references for specific permissions required to access system features such as audio settings, hardware components (Bluetooth, NFC), and network operations. The content covers security attributes, protection levels (normal, system_basic, system_core), and ACL enablement status. This collection is essential for HarmonyOS developers seeking to correctly declare permissions in application manifests and understand the access control constraints necessary for secure app development.
