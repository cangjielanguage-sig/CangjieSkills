This directory provides comprehensive API reference documentation for the `File` class and related concurrency functions within the Cangjie programming language. It is centered on the `SystemCapability.FileManagement.File.FileIO` framework, offering detailed guidance on file object management, property access, and synchronization mechanisms. The content covers essential read-only attributes such as file descriptors (`fd`), names, and paths, as well as instance methods for directory retrieval and non-blocking file locking. Additionally, it includes specifications for releasing locks via the `unlock` function. With a strong emphasis on error handling through `BusinessException` and defined error codes, this documentation is tailored for developers implementing secure and efficient file I/O operations, managing shared or exclusive access, and handling system-level exceptions in Cangjie applications.
