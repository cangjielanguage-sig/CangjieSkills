# class_AppStorage

This directory contains API documentation for the AppStorage class, a central storage mechanism for application state data within the Cangjie language and ArkUI framework. It covers essential functionalities for managing application state lifecycles, including one-way and two-way data binding, property retrieval, updates, and deletion. Key topics include static methods like `prop`, `link`, `set`, and `has`, which facilitate reactive programming and synchronization between app state and UI components. This documentation is suitable for ArkUI developers and software engineers looking to implement robust state management solutions in their applications.

### class_AppStorage_5more.md class_AppStorage_5more.md
This API documentation defines the AppStorage class, which serves as a central storage mechanism for application state data in the Cangjie language. The document details static methods including prop for one-way data binding, get for retrieving values, and clear or delete for removing properties. Key information highlights that deletion methods require no active subscribers, such as those using @StorageLink, to succeed. Additionally, the prop method creates a one-way binding where local changes do not sync back to the storage. This reference guide targets ArkUI developers needing to manage application state lifecycle and data binding.
