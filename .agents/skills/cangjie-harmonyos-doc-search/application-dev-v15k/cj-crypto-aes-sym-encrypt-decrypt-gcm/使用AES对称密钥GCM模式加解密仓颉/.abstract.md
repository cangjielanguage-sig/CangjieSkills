This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, focusing specifically on the implementation of AES symmetric encryption and decryption using the GCM (Galois/Counter Mode). It provides in-depth guidance on utilizing the CryptoArchitectureKit to secure data, detailing every step of the cryptographic process from initialization to finalization. The content covers essential concepts such as AES128 key generation, GCM block mode configuration, PKCS7 padding, and the management of authentication tags (AuthTags) for data integrity verification. Whether you are looking to encrypt sensitive information or decrypt received data securely, this collection of documents offers step-by-step tutorials and complete synchronous code examples. It is tailored for Cangjie developers who possess a basic understanding of cryptographic principles and need to integrate high-standard security features into their applications using the standard library's cryptographic capabilities.
