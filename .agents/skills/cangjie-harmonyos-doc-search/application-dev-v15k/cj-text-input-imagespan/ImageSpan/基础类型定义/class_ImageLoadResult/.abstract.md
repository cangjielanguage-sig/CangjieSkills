This directory contains essential API reference documentation for the `ImageLoadResult` class in the Cangjie language, specifically designed for use within the ArkUI framework. It serves as a comprehensive resource for developers looking to encapsulate and manage image loading metrics within their applications. The content covers the constructor's signature, system capabilities, and a detailed parameter table that defines critical properties such as dimensions and status codes. It provides clarity on the distinction between image and component sizes, explains the specific meaning of loading status values (0 for load success, 1 for decode success), and outlines the validity conditions for drawing offsets and content dimensions. This documentation is highly suitable for software developers building UI applications who need to precisely track image loading states and rendering geometry to optimize performance and user experience.
