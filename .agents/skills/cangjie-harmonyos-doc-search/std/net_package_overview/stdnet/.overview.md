# stdnet

The `stdnet` directory provides essential documentation for a robust network communication package tailored for the Cangjie language. It serves as a complete guide for developers looking to implement Socket servers, clients, and data transmission mechanisms. The content covers a wide range of networking concepts, including the specific implementations of UDP, TCP, and Unix Domain Sockets (UDS), as well as the structural hierarchy of socket classes. Additionally, it offers a deep dive into API references, error handling, and IP addressing strategies. This resource is ideal for software developers and system engineers aiming to build efficient, reliable networked applications who possess a foundational understanding of network protocols.

## Detailed Description

### 功能介绍.md 功能介绍.md
This document introduces the net package, designed for network communication by providing functionalities for Socket servers, clients, and data transmission. It covers the package's core capabilities, detailed definitions of three supported protocols (UDP, TCP, and UDS), and the class inheritance hierarchy for Socket types. Key takeaways include the specific use cases for each protocol: UDP for low-latency real-time apps, TCP for reliable transmission, and UDS for efficient local inter-process communication. The hierarchy diagram illustrates the structural relationship between streaming, datagram, and server sockets. This reference documentation targets developers using the Cangjie language who need to implement network functionality, requiring basic knowledge of network protocols.

### API_列表/
This directory serves as a comprehensive technical reference for a networking API, specifically focusing on socket communication and network protocol implementation. It provides detailed documentation for essential software components, including interfaces, classes, enumerations, data structures, and exception handling mechanisms. Key topics covered in this collection include IP addressing (supporting both IPv4 and IPv6), various socket types (TCP, UDP, and Unix Domain), transport layer protocols, and robust error management strategies. This documentation is primarily designed for software developers and system engineers who are tasked with implementing, configuring, or managing network connectivity in their applications. Users should possess a solid understanding of networking protocols and socket programming concepts to effectively utilize these resources. The directory acts as a central hub for understanding the structural and functional elements required to build reliable networked software.
