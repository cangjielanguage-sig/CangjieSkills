# 创建轮播Swiper

This directory focuses on implementing and customizing the Swiper component for sliding carousels in ArkUI applications using the Cangjie language. It covers essential configurations like layout constraints, loop playback, and auto-play, as well as advanced styling for navigation dots and arrows. Additionally, it includes guides on custom switching animations and programmatic page control. Suitable for UI developers and HarmonyOS developers looking to enhance user interfaces with interactive, dynamic carousel features.

## Detailed Description

### 创建轮播Swiper_4more.md
This document serves as a development guide for implementing the Swiper component to create sliding carousels in ArkUI applications. It covers three main topics: layout constraints, loop playback configuration, and automatic playback settings. Key information includes how Swiper determines its size based on explicit attributes or child components, the use of the loop property for continuous navigation, and the autoPlay and interval properties for timed transitions. The document targets UI developers looking to optimize home page displays with preloading mechanisms and interactive sliding features.

### 导航点样式.md
This guide explains how to configure and customize the styles of Swiper navigation indicators and arrows in the Cangjie language. It covers two primary topics: customizing navigation dots using the indicator property and configuring navigation arrows via the displayArrow property. Key information includes adjusting parameters such as position, size, color, and background for both elements. The document provides comparative code examples for default versus custom implementations, demonstrating specific properties like itemWidth, selectedColor, and ArrowStyle. Intended for UI developers using ArkUI who need to implement or modify Swiper component navigation controls.

### 自定义切换动画.md
This document provides a code example demonstrating how to implement custom switching animations for the Swiper component using the `customContentTransition` API in the Cangjie language. The content covers defining state variables for visual properties like opacity, scale, and translation, and implementing the transition callback to manipulate these properties frame-by-frame based on the page's position. Key takeaways include the logic for calculating property values for visible pages to create scaling and fading effects, while resetting attributes for pages outside the viewport. This tutorial targets HarmonyOS developers using Cangjie who require advanced, non-standard page transitions in their applications.

### 页面切换方式_3more.md
This technical guide explains advanced configuration options for the Swiper component in Cangjie development. It covers three main topics: programmatic page switching using a SwiperController, setting the carousel direction via the vertical property, and displaying multiple child components per page using the displayCount attribute. Key takeaways include specific controller methods like showNext, showPrevious, and changeIndex, alongside code examples demonstrating vertical versus horizontal layouts. The document targets HarmonyOS developers seeking to implement custom carousel behaviors, assuming prior knowledge of Cangjie syntax and the UIKit framework.
