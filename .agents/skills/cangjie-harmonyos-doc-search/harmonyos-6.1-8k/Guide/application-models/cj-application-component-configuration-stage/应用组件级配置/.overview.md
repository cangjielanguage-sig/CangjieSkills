# 应用组件级配置

本目录主要涵盖HarmonyOS应用开发中的基础配置项，包括应用图标与标签的设置、版本信息的声明以及应用包名的配置。内容涉及app.json5和module.json5配置文件的使用，旨在帮助开发者规范应用元数据、权限及设备支持。核心关键词包括图标配置、版本声明、包名、权限申请。适用于使用DevEco Studio进行HarmonyOS应用开发的初学者及进阶开发者，用于初始化和配置应用基础属性。

## 详细描述

### 图标和标签配置.md 图标和标签配置
本文档旨在说明HarmonyOS应用中图标和标签的配置方法及系统生成机制。主要涵盖了基于HAP内容和特定技能的生成机制、桌面与设置等应用场景、app与module级别的配置示例，以及系统对隐藏图标的管控规则。关键信息指出app.json5配置为必选且推荐，module.json5配置为可选；系统仅在特定action和entity存在时优先使用module配置；隐藏桌面图标仅限预置应用申请特权。面向使用DevEco Studio的HarmonyOS开发者，需具备基础应用配置文件知识。

### 应用版本声明配置_3more_470dfcfe.md 应用版本声明配置
本文档旨在说明如何在工程配置文件中声明应用版本、支持的设备类型及权限。主要涵盖在app.json5中配置versionCode和versionName以标识应用版本，在module.json5中通过deviceTypes定义模块支持的设备，以及使用requestPermissions声明访问受保护资源的权限信息。关键信息包括versionCode为用于版本比较的32位整数，deviceTypes决定模块运行环境，而权限配置需包含名称、原因及场景。这是一份面向开发者的配置参考指南，适用于应用元数据和系统权限的初始化设置。

### 应用组件级配置_2more_327b0954.md 应用组件级配置
本文档旨在指导开发者在开发应用时配置应用级的关键属性，特别是用于标识应用唯一性的包名。文档主要介绍了应用包名配置，详细说明了在工程AppScope目录下的app.json5配置文件中设置bundleName标签的方法。核心要点包括推荐采用反域名形式命名（如com.example.demo），并建议结构包含域名后缀、厂商名及应用名，以确保应用标识的唯一性。该文档面向处于Beta阶段的应用开发者，适用于需要初始化和配置应用基础信息的场景。
