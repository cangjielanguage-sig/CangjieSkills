# SymbolSpan

The SymbolSpan directory provides comprehensive documentation and resources for the SymbolSpan component within the Cangjie ArkUI framework. This component serves as a child element of the Text component, specifically designed to display and customize system-preset icon symbols. The content covers API references, implementation examples, and detailed property configurations such as rendering strategies, effect strategies, and font attributes. It is suitable for HarmonyOS application developers using the Cangjie language who need to integrate dynamic, scalable system icons into their user interfaces with precise control over visual appearance and interaction effects.

## Detailed Description

### SymbolSpan_4more.md
This API reference document details the SymbolSpan component, a child element of the Text component in the Cangjie ArkUI framework designed to display icon symbols. The documentation outlines the component creation process using the init method, which requires an AppResource parameter referencing system-preset symbols. Key takeaways include the component's ability to inherit attributes from its parent Text component and the restriction that it supports neither general attributes nor events. Additionally, it warns that using non-symbol resources will cause display errors. This guide is intended for developers building user interfaces with the Cangjie language who need to integrate system icons into text.
