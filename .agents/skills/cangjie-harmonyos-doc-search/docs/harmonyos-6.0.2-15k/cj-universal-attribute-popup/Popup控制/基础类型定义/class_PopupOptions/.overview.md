# class_PopupOptions

This directory contains API reference documentation for the `PopupOptions` class and related configuration variables within the ArkUI framework, specifically designed for the Cangjie language. It covers the comprehensive setup of popup windows, including layout positioning, visual styling, arrow properties, message content, and event handling. Developers will find details on constructors, default values, and advanced features like background blur and transition effects. This documentation is suitable for HarmonyOS developers looking to implement interactive popup dialogs, menus, or bubble components in their applications.

## Detailed Description

### class_PopupOptions.md class_PopupOptions.md
This document serves as an API reference for the PopupOptions class, which defines the configuration parameters for creating and customizing popup windows in the ArkUI framework. The content covers class properties including message content, button actions, layout positioning, visual styling, and event handling. It also details multiple constructors for initializing these options with varying degrees of customization. Key takeaways include the availability of default values for most properties, support for advanced features like background blur and transition effects, and specific system capabilities starting from version 12. This reference is intended for developers using the Cangjie language to build user interfaces on HarmonyOS, specifically those needing to implement interactive popup dialogs or menus.

This reference is intended for developers seeking to customize the layout and interaction logic of popup elements in their applications.

### var_messageOptions_11more.md var_messageOptions_11more.md
This document serves as an API reference for configuring popup component properties within the Cangjie ArkUI framework. Key information includes the deprecation of placementOnTop in favor of the placement enum, default styling values, and event handling mechanisms for state changes and dismissal interception. This reference is intended for developers using Cangjie to build and customize popup interfaces in ArkUI applications.

### var_showInSubWindow_4more.md var_showInSubWindow_4more.md
This document serves as API reference documentation for configuring popup window properties within the Cangjie ArkUI framework. It details four public variables: showInSubWindow for controlling display location, targetSpace for setting the gap to the target, transition for customizing show and exit animations, and width for defining popup dimensions. Key takeaways include that all variables are readable and writable, with specific defaults like false or 0.vp. The transition section provides crucial details on back key behavior and animation curve superposition. These features require SystemCapability.ArkUI.ArkUI.Full and are available starting from version 19. This guide is intended for Cangjie developers seeking to fine-tune popup UI behavior and visual effects.
