# direct_extension

本目录介绍了仓颉编程语言中的直接扩展机制，旨在指导开发者如何使用 `extend` 关键字为现有类型（包括泛型类型）添加新功能。内容涵盖了基础扩展语法、针对特定泛型实例的扩展、引入泛型形参的泛型扩展，以及通过 `where` 子句添加额外泛型约束的高级用法。核心概念包括类型扩展声明、泛型约束和条件性功能扩展。本文档适合具备仓颉基础语法的开发者阅读，帮助他们掌握类型扩展机制以增强代码复用性和灵活性。

## Detailed Description

### direct_extension.md direct_extension.md
本文档介绍了仓颉编程语言中直接扩展的语法与用法，旨在指导开发者如何使用 `extend` 关键字为现有类型（包括泛型类型）添加新功能。主要涵盖基础扩展语法、针对特定泛型实例的扩展、引入泛型形参的泛型扩展，以及在扩展中添加额外泛型约束的高级用法。核心要点包括使用 `extend` 关键字声明扩展、泛型类型实参必须符合约束、泛型形参必须被使用，以及通过 `where` 子句实现条件性功能扩展（如为 Pair 类型实现 equals）。本文属于语言教程，面向具备仓颉基础语法的开发者，帮助他们掌握类型扩展机制以增强代码复用性和灵活性。
