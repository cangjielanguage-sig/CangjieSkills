This directory provides a specialized development guide for Cangjie developers focusing on the internationalization (i18n) of language and region names within application interfaces. It addresses the critical need for software to adapt to the linguistic habits of its users, ensuring that interface lists—such as language or region selectors—are presented in a format that is familiar and readable. The content covers the technical implementation of converting standard language and country codes into localized strings using the `LocalizationKit`. It details the usage of `System.getDisplayLanguage` and `System.getDisplayCountry` APIs, explaining how to leverage specific locale identifiers to generate accurate translations. Furthermore, it discusses formatting options like sentence casing. This resource is suitable for developers building user-centric applications who require precise control over how geographic and linguistic data is displayed, ensuring a seamless experience for global users.
