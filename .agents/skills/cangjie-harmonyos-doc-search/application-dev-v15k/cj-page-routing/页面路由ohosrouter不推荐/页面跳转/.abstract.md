This directory focuses on page navigation mechanisms within Cangjie application development. It comprehensively covers the Router module, detailing jump modes (pushUrl, replaceUrl), instance management (Standard, Single), and data passing between pages. Key topics include the 32-page stack limit, lifecycle management, and parameter retrieval using `getParams`. The content includes practical code scenarios for use cases like detail views and login flows. This resource is suitable for developers working with the Cangjie language and UIKit framework who need to implement robust navigation logic, manage page transitions, and handle data transfer in their applications.
