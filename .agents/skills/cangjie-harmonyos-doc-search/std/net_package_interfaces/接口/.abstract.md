This directory contains API reference documentation for core network socket interfaces within the Cangjie programming language. It covers the essential components required for implementing network communication protocols, including server-side connection handling, stream-based data transmission, and packet-oriented messaging. Key topics include socket lifecycle management, blocking operations, address configuration, and exception handling. These resources are designed for Cangjie developers and network engineers seeking to build robust, low-level networking solutions, requiring a solid understanding of I/O streams and resource management principles.
