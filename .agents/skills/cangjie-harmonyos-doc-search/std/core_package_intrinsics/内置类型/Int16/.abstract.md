This directory contains comprehensive API reference documentation for the Int16 type within the Cangjie programming language. It covers the fundamental definition of the 16-bit signed integer, detailing its specific value range, static properties for maximum and minimum values, and extended functionalities. The documentation explains implementations of essential standard interfaces such as Comparable, Countable, Hashable, and ToString. It provides developers with the necessary methods for ordering comparisons, wrapping arithmetic, hash code generation, and string conversion. This resource is suitable for Cangjie developers who need to manipulate integer data, perform type conversions, or implement standard library interfaces in their applications.
