This directory contains comprehensive API reference documentation for the `JsonValue` class within the Cangjie language's `encoding_json` package. It serves as the fundamental data layer for handling JSON data, covering essential operations such as parsing strings into JSON objects, converting between data types, and serializing objects back into strings. Key topics include the `fromStr` method for parsing strings with various number formats (binary, octal, hexadecimal), instance methods for type casting (e.g., `asArray`, `asBool`, `asInt`), and serialization functions like `toJsonString`. The documentation is specifically suitable for Cangjie developers who need to parse, validate, transform, or serialize JSON data structures in their applications, with a strong emphasis on exception handling (`JsonException`) and type inspection mechanisms. This resource is essential for ensuring robust data interchange in Cangjie-based software projects.
