# class_ImageBitmap

This directory contains essential API reference documentation for the `ImageBitmap` class in the Cangjie language, developed for use within the ArkUI framework. It serves as a comprehensive guide for storing and manipulating canvas-rendered pixel data, offering detailed insights into various initialization strategies. The content covers constructors that accept local image paths or PixelMap objects, read-only properties for width and height, and support for standard formats like bmp, jpg, png, and svg. It also explains path resolution rules and dimension customization using Float64 or Int64. Additionally, the documentation addresses resource lifecycle management, including the use of the `close()` method and specific initialization overloads with `LengthMetricsUnit`. This resource is suitable for ArkUI developers seeking to master image resource handling and pixel manipulation using Cangjie syntax.
