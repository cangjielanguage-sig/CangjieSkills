This directory serves as a comprehensive API reference for fundamental type definitions within the ArkUI framework, specifically tailored for the Cangjie language. It covers essential classes and enums used to configure visual transformations and animations for UI components, including scaling, translation, rotation, and transition effects. By providing detailed specifications for properties like axis vectors, multipliers, and animation parameters, this documentation enables developers to implement dynamic and spatially complex user interfaces. It is suitable for UI developers and system architects working with ArkUI version 12+ who require precise control over component styling and lifecycle animations.
