# 完整示例

This directory provides a comprehensive collection of code examples designed to demonstrate audio playback implementation using the AudioRenderer API in the Cangjie language for the HarmonyOS framework. It covers the entire audio rendering lifecycle, from initial context management and stream configuration to state-based playback control and resource release. Key technical concepts include setting AudioStreamInfo, implementing data callbacks, managing renderer states (such as STATE_PREPARED and STATE_RUNNING), and handling audio interruptions. These examples are specifically tailored for developers seeking to build stable audio applications, offering practical solutions for concurrency, resource cleanup, and system event handling.

## Detailed Description

### 完整示例_1.md
This document provides a complete code example demonstrating how to render audio files using the AudioRenderer API in the Cangjie language. It covers context management in main_ability.cj and core audio logic in index.cj, including stream configuration, renderer initialization, and state-based playback control. Key information includes setting AudioStreamInfo and AudioRendererInfo, implementing data callbacks, and managing states like STATE_PREPARED and STATE_RUNNING to safely start and pause playback. This tutorial is intended for developers using the HarmonyOS/Cangjie framework who need to implement audio playback functionality in their applications.

### 完整示例_2.md
This document provides code examples for managing the lifecycle of an audio renderer, specifically focusing on stopping playback and releasing system resources. It covers the implementation of the stop and release functions, emphasizing the importance of checking renderer states like RUNNING, PAUSED, and RELEASED before executing operations to ensure stability. Additionally, it explains audio interruption scenarios where higher priority streams preempt the current output and references handling audio focus events. This technical guide is intended for developers implementing audio playback features who need to manage resource cleanup and concurrency.
