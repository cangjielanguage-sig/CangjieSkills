This directory provides a comprehensive guide for HarmonyOS developers on building applications that integrate the Cangjie programming language with ArkTS. It covers the complete development lifecycle, including project creation using the Hybrid Ability template, understanding the specific directory structure, and configuring the runtime environment for real devices or emulators. The tutorials detail how to construct pure ArkTS pages and hybrid pages that embed Cangjie components, as well as implementing complex page navigation logic across languages. Suitable for developers with basic knowledge of ArkTS and Cangjie looking to master mixed-language development in the HarmonyOS ecosystem.
