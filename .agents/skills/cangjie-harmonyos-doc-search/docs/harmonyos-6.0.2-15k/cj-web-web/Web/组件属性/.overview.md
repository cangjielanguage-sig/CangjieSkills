# 组件属性

This directory contains API reference documentation for configuring Webview component properties using the Cangjie language within the ArkWeb framework. It covers a comprehensive range of settings including security permissions, layout modes, font customization, JavaScript interaction, and media playback controls. Developers can find detailed parameters for managing web content rendering, storage access, and user interface behaviors. Suitable for application developers building hybrid applications on HarmonyOS who need granular control over Webview capabilities and system integration.

## Detailed Description

### func_allowWindowOpenMethod_5more.md
This document serves as API reference documentation for configuring Webview component behaviors using the Cangjie language. It details five distinct functions: allowWindowOpenMethod, blockNetwork, cacheMode, copyOptions, and darkMode. Key information includes the specific logic for allowWindowOpenMethod, which restricts JavaScript window opening based on user interaction timing and system properties, alongside settings for network access, caching, clipboard scope, and dark mode styling. Intended for application developers, this guide provides the necessary parameters and system capabilities to manage web content rendering and security within their applications.

### func_editMenuOptionsArrayT_5more.md

Key information includes the ability to override system menu callbacks, default configuration states, and specific interaction rules, such as editMenuOptions taking precedence over selectionMenuOptions. Intended for developers working with Webview core capabilities, this guide assumes familiarity with the Cangjie language to implement these advanced web component settings.

### func_geolocationAccessBool_6more.md

### func_javaScriptOnDocumentS_3more.md
This document provides API reference documentation for three specific Cangjie language functions used in WebView configuration and interaction. It details javaScriptOnDocumentStart for early script injection, javaScriptProxy for registering native objects with JavaScript, and keyboardAvoidMode for managing software keyboard behavior. Important notes include that javaScriptOnDocumentStart runs before DOM loading and executes in dictionary order, while javaScriptProxy requires cleanup to prevent memory leaks and supports both synchronous and asynchronous methods. The keyboard mode warns against usage in nested scrolling scenarios. This technical reference targets developers using the ArkWeb framework to build hybrid applications requiring deep JavaScript integration and UI layout control.

### func_layoutModeWebLayoutMo_3more.md

Key information includes critical constraints for adaptive layouts, such as size limits (7680px or 500kpx depending on render mode), the inability to switch layout modes dynamically, and specific rules regarding audio interruption and resumption intervals.
