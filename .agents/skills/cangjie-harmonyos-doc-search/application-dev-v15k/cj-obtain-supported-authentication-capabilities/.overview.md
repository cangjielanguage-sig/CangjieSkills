# cj-obtain-supported-authentication-capabilities

This directory contains a specialized technical tutorial designed for developers working with the Cangjie programming language to implement secure user authentication mechanisms. It focuses on the critical task of querying a device's hardware and software capabilities to determine supported authentication methods, such as facial recognition or password entry, using the UserAuthenticationKit. The guide provides in-depth instructions on utilizing the `getAvailableStatus` interface to verify support for specific authentication types and security trust levels, such as ATL1. Additionally, it covers the prerequisite steps for permission management, specifically the `ohos.permission.ACCESS_BIOMETRIC` permission. This resource is highly suitable for application developers who need to integrate biometric verification or password authentication into their apps, ensuring that the software gracefully handles devices with varying security capabilities and configurations, thereby optimizing both security and user experience.

## Detailed Description

### cj-obtain-supported-authentication-capabilities.md cj-obtain-supported-authentication-capabilities.md

This document provides a detailed tutorial for developers on how to query the authentication capabilities supported by a device using the UserAuthenticationKit in the Cangjie language. It focuses on the `getAvailableStatus` interface, which is the primary method for checking whether the device supports specific authentication combinations, such as `UserAuthType.FACE` combined with `AuthTrustLevel.ATL1`. The guide details the complete development workflow, beginning with the mandatory step of applying for the `ohos.permission.ACCESS_BIOMETRIC` permission in the application configuration. It then proceeds to demonstrate how to invoke the API with the correct parameters. Furthermore, the document includes a practical Cangjie code example that illustrates the implementation logic and necessary error handling, making it an invaluable reference for developers integrating biometric or password-based authentication systems. By following this guide, developers can ensure their applications correctly identify and utilize available security features, providing a robust user experience.
