# 实现页面间的跳转

本目录包含关于在HarmonyOS中实现ArkTS与仓颉页面间跳转的教程。内容涵盖了从ArkTS跳转至仓颉混合页面的实现方法，以及利用互操作宏和回调注册机制实现从仓颉返回ArkTS页面的完整流程。文档提供了详细的代码示例（如Index.ets和index.cj）及配置说明，重点讲解了跨语言互操作与路由注册机制。适合从事HarmonyOS混合语言开发、需要掌握页面路由管理的开发者阅读。

## 详细描述

### 实现页面间的跳转_1.md

本文档是一份HarmonyOS开发教程，指导实现ArkTS页面与仓颉混合页面间的跳转。文档涵盖两个核心场景：通过router.pushUrl实现ArkTS向混合页面的跳转；以及利用仓颉-ArkTS声明式互操作宏，解决路由不互通问题，将ArkTS路由函数注册给仓颉以实现返回。文档提供了Index.ets和index.cj代码示例，并说明了自动生成.d.ts接口文件的方法。本文面向混合语言开发者，重点在于掌握跨语言互操作与路由注册机制。

### 实现页面间的跳转_2.md

这份文档演示了如何在仓颉混合工程中实现从仓颉页面返回ArkTS页面的功能。文档涵盖了依赖配置、ArkTS侧注册路由回调函数以及仓颉侧调用该函数的完整流程。关键信息包括使用`registerJSFunc`在ArkTS侧暴露`router.back`逻辑，并在仓颉侧通过`globalJSFunction.get`触发回调，同时展示了`CJHybridComponent`的嵌入方式及生命周期管理。该教程面向需要掌握ArkTS与仓颉互操作及页面路由管理的开发者。
