# 触摸事件

This directory focuses on the comprehensive handling of touch interactions within the ArkUI framework using the Cangjie language. It covers the implementation of touch event callbacks, state management, and the extraction of detailed event properties such as coordinates, timestamps, and target dimensions. Additionally, it includes API references for fundamental data structures used in processing touch data. This content is suitable for HarmonyOS developers who need to build responsive user interfaces, manage raw touch data, and understand event propagation mechanics effectively.

## Detailed Description

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating how to implement and handle touch events within a UI component. The main topics include UI layout construction using Column and Button components, state management with the @State decorator, and the implementation of the onTouch event callback. Key information involves the extraction and logging of detailed touch event properties, such as event type, timestamp, touch point coordinates, and the target component's position and dimensions. The example illustrates how to update the UI state dynamically based on user interaction. This document serves as a practical guide for HarmonyOS developers using the Cangjie language, specifically those looking to understand touch event mechanics and coordinate systems in application development.

### 触摸事件_3more.md 触摸事件_3more.md
This document serves as an API reference for handling touch interactions within the ArkUI framework using the Cangjie language. It details the `onTouch` function, which triggers callbacks when users perform finger actions such as pressing, sliding, or lifting on a component. The documentation specifies that no permissions are required and outlines the function's system capabilities, starting from version 12. Key technical details include the callback parameter type `TouchEvent`. This guide is intended for developers seeking to implement interactive touch event handling in their UI components.

### 基础类型定义/
This directory provides essential API reference documentation for fundamental data structures used in handling touch interactions within the ArkUI framework, specifically designed for the Cangjie language. It comprehensively covers classes representing touch events and individual touch objects, detailing properties such as event types, coordinates, timestamps, and unique identifiers. Key concepts include event propagation, multi-touch support, and the distinction between different coordinate systems and refresh rates. This documentation is highly suitable for developers building responsive user interfaces who need to manage, interpret, and respond to raw touch data effectively in their applications.
