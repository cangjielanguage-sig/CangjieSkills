# cj-development-intro

This directory serves as a comprehensive introductory resource specifically designed for the OpenHarmony Cangjie SDK development environment. It acts as a central hub for developers to understand the foundational workflows and architectural patterns required for successful application creation. The content covers a wide range of critical topics, including the practical steps for compiling and running sample code using standard project templates, as well as the nuances of API documentation conventions such as version support and SystemCapability (SysCap). Additionally, it provides deep insights into managing system permissions and distinguishing between different application models. Key technical areas include Context object management and ensuring API compatibility via `canIUse`. This documentation is highly suitable for Cangjie developers and application engineers operating within the OpenHarmony ecosystem who need to ensure correct API usage, handle access control efficiently, and test code snippets effectively in a standardized environment.
