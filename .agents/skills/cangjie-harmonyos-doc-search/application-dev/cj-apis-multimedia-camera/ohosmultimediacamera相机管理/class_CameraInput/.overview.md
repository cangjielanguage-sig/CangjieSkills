# class_CameraInput

This directory provides comprehensive API reference documentation for the `CameraInput` class in the Cangjie programming language, specifically designed for the CameraKit framework. It details the essential operations required to manage camera device inputs within a session, including device initialization, connection termination, and event listener management. Key topics covered include the `open()`, `close()`, `on()`, and `off()` methods, alongside system capabilities, version 22 compatibility, and specific `BusinessException` error codes. This documentation is intended for multimedia application developers who need precise control over camera hardware lifecycles and robust error handling mechanisms.
