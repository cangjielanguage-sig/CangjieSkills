# 示例代码

This directory provides a comprehensive collection of code examples and tutorials designed to address complex UI interaction challenges in the Cangjie and ArkUI ecosystems. It primarily focuses on resolving gesture conflicts and implementing smooth nested scrolling mechanisms in layered layouts. Key topics include coordinating touch events between parent and child containers, intercepting gestures at boundaries, and utilizing specific framework APIs like `shouldBuiltInrecognizerParallelWith` and `onGestureRecognizerJudgeBegin`. These resources are essential for Cangjie and HarmonyOS developers aiming to build responsive applications with sophisticated navigation and touch handling requirements.

## Detailed Description

### 示例1嵌套滚动/

This directory contains code examples and tutorials demonstrating how to implement nested scrolling functionality across different UI frameworks, specifically Cangjie and ArkUI (ArkTS). It focuses on resolving gesture conflicts between parent and child scrollable components using techniques like `shouldBuiltInrecognizerParallelWith` and dynamic recognizer control. The examples illustrate logic where inner components handle gestures first, passing control to outer components at boundaries. Suitable for developers working on HarmonyOS/OpenHarmony applications or using the Cangjie language who need to manage complex touch interactions and smooth scrolling transitions in nested layouts.

### 示例2嵌套场景下拦截内部容器手势.md 示例2嵌套场景下拦截内部容器手势.md

This tutorial demonstrates how to manage gesture conflicts in nested Tabs components by allowing the outer container to intercept swipes when the inner container reaches its boundary. The document covers the implementation of nested Tabs, the use of the exposeInnerGesture parameter, and the onGestureRecognizerJudgeBegin callback. Key takeaways include tracking the inner Tabs index and returning GestureJudgeResult.REJECT for built-in pan gestures at boundaries to enable outer container navigation. Intended for Cangjie developers, this example provides a solution for complex UI layouts requiring coordinated gesture handling between parent and child containers.
