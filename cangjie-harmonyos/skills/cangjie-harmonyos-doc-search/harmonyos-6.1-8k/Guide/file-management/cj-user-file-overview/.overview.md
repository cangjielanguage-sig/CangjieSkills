# cj-user-file-overview

本目录包含关于终端设备上用户文件管理的核心概述文档。它详细阐述了用户文件的定义、存储位置（包括内置存储与外置存储）以及分类管理机制，涵盖了媒体文件、音频文件、文档文件及多用户共享文件的存储特征。文档还重点说明了应用访问用户文件所需的权限要求，以及不同类型文件在系统中的展示形式（如媒体文件以相册展示，文档文件以目录树展示）。该内容主要面向应用开发人员，旨在帮助其深入理解文件系统逻辑及权限管理，以便在开发过程中正确处理用户数据。核心关键词包括：用户文件、存储分类、权限管理、文件展示。

## 详细说明

### cj-user-file-overview.md cj-user-file-overview.md
本文档旨在概述终端设备上用户文件的定义、存储位置及分类管理机制。涵盖内置存储与外置存储两大类，详细说明了用户特有的媒体文件、音频文件、文档文件及多用户共享文件的存储特征与展示形式。关键信息指出应用对用户文件的访问需获取授权，且不同类型文件在系统中的呈现方式各异，如媒体文件以相册展示，文档文件以目录树展示。适用于应用开发人员，用于理解文件系统逻辑。关键词：用户文件, 内置存储, 外置存储, 媒体文件, 权限管理。
