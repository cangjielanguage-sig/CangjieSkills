This directory contains documentation for the SymbolGlyph component within the ArkUI framework, specifically for the Cangjie programming language. It covers API references, type definitions for symbol effects, and component properties for styling and animation. Key topics include system-preset symbol resources, rendering strategies, and dynamic visual effects like scaling and hierarchical animations. This resource is suitable for HarmonyOS developers and UI engineers looking to implement sophisticated iconography and animations in their applications starting from API version 19.
