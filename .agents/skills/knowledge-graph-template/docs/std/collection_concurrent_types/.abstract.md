This directory serves as a specialized documentation resource for the Cangjie programming language, specifically addressing the `collection_concurrent_types` module. It focuses on the API reference for deprecated type aliases found within the concurrent collection package. The content primarily covers the definitions, current status, and future removal plans for `BlockingQueue<E>` and `NonBlockingQueue<E>`, clarifying their relationship to `LinkedBlockingQueue<E>` and `ConcurrentLinkedQueue<E>`. By highlighting the deprecation warnings, this guide aims to assist developers in refactoring code to use direct class implementations, thereby preventing future compilation errors. This directory is essential for Cangjie developers, particularly those maintaining legacy systems or modernizing concurrent codebases, who need a solid grasp of generic types and concurrent programming patterns to ensure long-term code stability and compliance with the latest API standards.
