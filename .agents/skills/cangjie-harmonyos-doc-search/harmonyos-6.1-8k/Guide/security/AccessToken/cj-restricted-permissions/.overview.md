# cj-restricted-permissions

This directory serves as a comprehensive technical resource dedicated to the management and application of restricted open permissions within the HarmonyOS and OpenHarmony development ecosystems. It addresses the critical balance between maintaining robust system security and enabling advanced application functionality by detailing the specific protocols for accessing sensitive system capabilities. The content covers essential operational topics, including the Access Control List (ACL) cross-level application process designed for the Beta phase, practical debugging guides for sensitive interfaces, and comprehensive lists of system permissions involving hardware and clipboard access. Furthermore, it outlines the necessary procedural steps for transitioning from elevated debugging privileges to full commercial compliance. This repository is specifically curated for advanced engineers, system-level developers, and technical professionals engaged in deep system integration who require elevated privileges beyond standard application permissions.

## Detailed Description

### 受限开放权限/
This subdirectory provides an in-depth explanation of the application mechanisms and reference standards regarding restricted open permissions in the HarmonyOS and OpenHarmony ecosystems. It is designed to guide developers through the complexities of accessing sensitive features that are typically restricted to ensure system integrity. The core content includes a specialized debugging guide for general applications, explaining how to utilize ACL (Access Control List) cross-level applications to acquire sensitive permissions specifically during the Beta phase of development. Additionally, it offers a detailed catalog of system permissions that cover essential core functions, such as clipboard management and hardware information retrieval. The primary goal of this documentation is to assist developers in temporarily elevating their Application Permission Level (APL) for effective debugging while ensuring they clearly understand the strict compliance pathways required for eventual commercial release. This section is indispensable for advanced engineers and developers tasked with deep system integration, debugging sensitive interfaces, or building complex system-level applications.
