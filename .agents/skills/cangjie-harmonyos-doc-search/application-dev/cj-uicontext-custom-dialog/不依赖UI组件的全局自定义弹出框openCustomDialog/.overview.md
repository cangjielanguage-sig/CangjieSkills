# 不依赖UI组件的全局自定义弹出框openCustomDialog

This directory provides resources for implementing global custom dialogs in Cangjie HarmonyOS applications using the `openCustomDialog` API. It addresses the limitations of `CustomDialogController` by enabling dynamic creation and refreshing of dialog content. Key topics include parameter input methods (`CustomDialogOptions` and Lambda expressions), dialog lifecycle management, and ID-based control. This collection is ideal for ArkUI developers seeking to create flexible, decoupled popup interfaces using `getUIContext().getPromptAction()`.

## Detailed Description

### 不依赖UI组件的全局自定义弹出框openCustom_3more.md 不依赖UI组件的全局自定义弹出框openCustom_3more.md
This document serves as a technical guide for implementing global custom dialogs in Cangjie using the `openCustomDialog` API, designed to overcome the dynamic creation and refresh limitations of `CustomDialogController`. The content covers two parameter input methods—`CustomDialogOptions` for decoupled UI and Lambda expressions for callbacks—along with the dialog lifecycle sequence including `onWillAppear` and `onDidDisappear`. Key takeaways include the ability to dynamically update dialog content and manage dialog IDs for opening and closing instances. Targeted at ArkUI developers, this tutorial provides code examples for creating flexible, decoupled popup interfaces using the `getUIContext().getPromptAction()` methods.

### 完整示例.md 完整示例.md
This document provides a complete code example demonstrating how to implement and manage custom dialogs in a Cangjie HarmonyOS application. It covers the definition of the `EntryView` component, the use of `@Builder` methods for dialog content, and event handling logic. Key takeaways include using `getUIContext().getPromptAction().openCustomDialog` to display views and `closeCustomDialog` to dismiss them via a stored ID. This practical guide targets developers using the Cangjie language and ArkUI framework to create interactive UI components.
