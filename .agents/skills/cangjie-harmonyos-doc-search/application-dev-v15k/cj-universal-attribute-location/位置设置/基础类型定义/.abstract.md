This directory contains API reference documentation for fundamental layout and alignment types within the Cangjie ArkUI framework. It covers classes and structures essential for defining alignment rules, anchor points, bias offsets, and chain styles in relative containers. Key topics include `AlignRuleOption`, `Bias`, `HorizontalAnchor`, `VerticalAnchor`, and localized alignment parameters for internationalization. These definitions are crucial for developers building responsive and adaptive user interfaces in HarmonyOS applications, providing the necessary tools for precise component positioning and layout management.
