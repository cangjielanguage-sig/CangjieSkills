# 组件属性

This directory contains API reference documentation for configuring the properties of the Select component within the ArkUI framework using the Cangjie language. It covers a comprehensive range of customization options, including dropdown interface styling, menu alignment, background effects, option sizing, and typography. Developers can find detailed specifications for functions related to arrow positioning, control size, dividers, fonts, and selection behaviors. This documentation is suitable for UI developers and system engineers looking to programmatically customize the visual presentation and interaction logic of Select components to meet specific design requirements.

### func_optionHeightLength_5more.md func_optionHeightLength_5more.md
This document serves as an API reference for configuring the appearance and behavior of dropdown menus in the Cangjie ArkUI framework. It details four primary functions: optionHeight, optionWidth (overloaded), selected, and selectedOptionBgColor. Key information includes that optionHeight restricts menu height to a maximum of 80% of the screen, while optionWidth supports both specific lengths and modes, enforcing a minimum width of 56.vp. The selected function sets the initial index, defaulting to -1 if unset, and selectedOptionBgColor allows customization of the selection highlight. This reference targets developers using ArkUI who need to programmatically style dropdown components.
