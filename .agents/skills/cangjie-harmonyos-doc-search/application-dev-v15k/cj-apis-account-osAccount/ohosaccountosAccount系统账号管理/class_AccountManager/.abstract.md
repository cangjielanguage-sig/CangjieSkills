This directory contains API reference documentation for the `AccountManager` class and related functions in the Cangjie language, specifically designed for HarmonyOS system account management. It covers essential operations such as retrieving account IDs, checking account types, verifying constraints, and managing distributed virtual device IDs. The documentation includes method signatures, required system permissions (e.g., `ohos.permission.MANAGE_LOCAL_ACCOUNTS`), and error handling details. It is intended for system application developers who need to implement robust account management features using the BasicServicesKit, requiring a solid understanding of Cangjie syntax and HarmonyOS capabilities.
