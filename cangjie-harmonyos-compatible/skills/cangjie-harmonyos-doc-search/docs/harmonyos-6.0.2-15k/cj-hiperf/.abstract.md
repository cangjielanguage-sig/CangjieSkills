This directory serves as the documentation hub for `cj-hiperf`, a robust cross-platform command-line performance analysis tool tailored for developers operating within OpenHarmony and Linux-like environments. Designed to mirror the functionality of the Linux `perf` utility, it provides a comprehensive suite of features for capturing granular system and program performance data. The documentation encompasses a wide array of essential operations, including commands for recording samples, monitoring real-time statistics, generating detailed reports, and leveraging Python scripts to create visualized flame graphs. This resource is particularly suitable for performance analysts, software developers, and quality assurance testers who need to diagnose complex system issues, optimize application behavior, and profile performance bottlenecks through precise data collection and advanced visualization techniques.
