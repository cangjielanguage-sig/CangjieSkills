This directory provides API reference documentation for the `ohos.nfc.controller` module within the Cangjie programming language environment. It is designed to assist developers in managing NFC controller states and handling switch events in HarmonyOS applications. The documentation covers essential components such as callback type enumerations, state definitions, and functions for subscribing to or unsubscribing from state change events. Suitable for HarmonyOS developers utilizing the ConnectivityKit, this resource offers the necessary syntax and parameters to implement robust NFC control features and manage system capabilities effectively.
