This directory contains comprehensive API reference documentation for the `AVRecorder` class within the Cangjie MediaKit framework. It covers the complete lifecycle of audio and video media recording, including configuration, state management, error handling, and resource control. Key topics include audio capture metrics, video surface input, event subscriptions, and recording operations like start, pause, and stop. The documentation details system capabilities, required permissions, and specific `BusinessException` error codes. It is intended for Cangjie developers building multimedia applications who need to implement robust recording features in HarmonyOS environments.
