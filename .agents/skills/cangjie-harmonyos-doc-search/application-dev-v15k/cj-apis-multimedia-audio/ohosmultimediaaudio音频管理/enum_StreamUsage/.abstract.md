The documentation details specific enum values, their functional roles in applications (like VoIP or notifications), and essential operators for type comparison. It also includes utility functions for string representation. This resource is suitable for Cangjie developers who need to implement, identify, and manage various audio scenarios, ensuring compatibility with SystemCapability.Multimedia.Audio.Core and version 19.
