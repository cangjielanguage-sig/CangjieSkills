# 示例代码

This directory contains code examples demonstrating the implementation and customization of the Progress component within the Cangjie language for HarmonyOS development. It covers a wide range of functionalities, including setting different progress bar types like Linear, Ring, and Capsule, configuring visual properties such as stroke width and colors, and implementing smooth animation effects. These examples are designed to help developers understand how to enhance user interface interactions through state management and style options. This resource is suitable for developers familiar with Cangjie syntax and the HarmonyOS UIKit who are looking to integrate and customize progress indicators in their applications.

## Detailed Description

### 示例1设置进度条的类型.md 示例1设置进度条的类型.md
This document provides a code example demonstrating how to configure and display various progress bar types using the Cangjie language for HarmonyOS development. It covers the implementation of Linear, Eclipse, ScaleRing, Ring, and Capsule progress bars using the Progress component and its type attribute. The code illustrates setting values, colors, and specific style options like ScaleRingStyleOptions and RingStyleOptions to customize appearance, such as stroke width and scale count. This tutorial is intended for developers familiar with Cangjie syntax and UI kit basics who need to implement progress indicators in their applications.

### 示例2设置环形进度条属性_3more.md 示例2设置环形进度条属性_3more.md
This tutorial demonstrates how to configure visual and animation properties for Ring and Capsule progress bars using the Cangjie UI framework. The document is divided into three code examples illustrating specific styling techniques: setting ring visual attributes like stroke width and shadow, enabling ring animations such as loading status and scan effects, and customizing capsule styles including borders and text content. Key takeaways include the use of RingStyleOptions and CapsuleStyleOptions to modify component appearance and behavior. This guide is intended for Cangjie developers looking to implement customized progress indicators in HarmonyOS applications.

### 示例5设置进度平滑动效.md 示例5设置进度平滑动效.md
This document serves as a code example demonstrating how to configure smooth animation effects for a Progress component in a Cangjie-based application. The primary focus is on the `style` interface, specifically utilizing the `enableSmoothEffect` property within `RingStyleOptions` to toggle animation behavior. The code snippet illustrates a comparison between two Progress components, one with the effect enabled and one disabled, using a button to increment values and visualize the difference. Key takeaways include understanding state management with `@State` and applying style options to UI elements. This tutorial is designed for developers working with the Cangjie language and HarmonyOS UIKit who seek to enhance user interface interactions through animated progress indicators.
