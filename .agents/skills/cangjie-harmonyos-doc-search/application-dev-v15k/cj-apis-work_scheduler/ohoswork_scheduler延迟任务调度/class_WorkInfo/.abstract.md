This directory contains API reference documentation for the `WorkInfo` class in the Cangjie programming language, specifically designed for the WorkScheduler system. It covers the configuration of delayed tasks, including properties like work ID, bundle name, network type, battery status, and charging conditions. The documentation details initialization methods and public variables for managing task persistence, repetition cycles, and execution constraints. It is suitable for developers implementing background task scheduling and resource management in applications requiring precise control over system capabilities.
