This directory contains API reference documentation for the `CustomPopupOptions` class within the Cangjie language and ArkUI framework. It focuses on configuring parameters for custom popup windows, covering visual settings like background color, arrow dimensions, and behavioral aspects such as auto-cancel and placement. The documentation details constructor overloads, property definitions, and system capability requirements (starting from API version 12). It is intended for ArkUI developers who need to programmatically implement and customize popup interfaces, including sub-window display, transitions, and event handling.
