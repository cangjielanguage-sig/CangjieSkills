This directory provides comprehensive API documentation for the Router module within ArkUI applications, specifically designed for the Cangjie language. It covers the essential aspects of page navigation management, including accessing URLs, jumping to specific pages, replacing the current page, and returning to previous or specified pages. The documentation details the necessary setup, such as obtaining the Router object via `getRouter()` from UIContext and importing `kit.ArkUI.*`. It also includes references for the Router class methods like `pushUrl` and `back`, as well as state management classes like `RouterState` and `RouterMode`. This resource is suitable for application developers seeking to implement robust routing logic, state transfer, and navigation control in their UI applications.
