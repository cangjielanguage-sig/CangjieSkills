# class_UiWindow

This directory contains API reference documentation for the `UiWindow` class within the Cangjie UiTest framework. It provides comprehensive details on interacting with and manipulating UI windows during automated testing. The documentation covers essential methods for querying window properties (like bounds, title, and bundle name), managing window states (focus, active status, mode), and performing physical manipulations (moving, resizing, splitting). It is suitable for software developers and QA engineers using the Cangjie language and TestKit who need to programmatically control window behavior and handle potential `BusinessException` errors.
