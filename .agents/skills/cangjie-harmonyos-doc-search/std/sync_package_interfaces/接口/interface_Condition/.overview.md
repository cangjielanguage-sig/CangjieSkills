# interface_Condition

This directory provides comprehensive API reference documentation for the Cangjie `Condition` interface and its specific utility functions. It focuses on thread synchronization primitives that allow developers to manage shared variables and coordinate thread execution efficiently. The content covers essential mechanisms such as suspending threads, notifying waiting threads, and handling timeouts with mutex management. This documentation is intended for Cangjie developers and system programmers building multi-threaded applications who require robust tools for inter-thread communication and precise control over blocking conditions.

## Detailed Description

### func_waitUntil_-_Bool_Duration.md func_waitUntil_-_Bool_Duration.md
This document serves as API reference documentation for the Cangjie function `waitUntil`, designed to suspend the current thread until a specific condition becomes true or a timeout duration is exceeded. The text details the function's signature, parameters including the predicate and timeout, and return values. Key information explains that the thread releases its mutex while waiting and re-acquires it upon waking, returning true only if the predicate is met. It also lists exceptions for invalid arguments or synchronization states. Intended for developers implementing multi-threaded synchronization, this guide requires knowledge of mutexes and monitors.
