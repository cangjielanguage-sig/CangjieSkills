# 自定义文本样式

This directory provides a comprehensive guide to customizing text styles in ArkUI applications using the Cangjie language. It covers a wide range of text attributes, from basic layout adjustments like alignment, overflow handling, and line height, to advanced typography features such as baseline offset, character spacing, and adaptive font sizing. Additionally, it addresses text presentation controls like capitalization and user interaction settings such as clipboard options. The tutorials include executable code examples to help developers refine UI text appearance and layout behavior. This resource is suitable for developers building HarmonyOS applications who seek to enhance text presentation, readability, and user interaction capabilities within their interfaces.

## Detailed Description

### 自定义文本样式_1.md 自定义文本样式_1.md
This tutorial guide explains how to customize text styles in ArkUI applications using the Cangjie language. It covers four main styling aspects: text alignment, overflow handling, line height adjustment, and text decoration. The document provides executable code examples demonstrating specific properties like textAlign, textOverflow (which requires maxLines), lineHeight, and decoration to control visual presentation. Key takeaways include understanding how to manage text layout constraints and visual enhancements. It targets developers seeking to refine UI text appearance and readability within the ArkUI framework.

### 自定义文本样式_2.md 自定义文本样式_2.md
This document serves as a technical tutorial demonstrating how to implement advanced text styling properties using the Cangjie language in the ArkUI framework. It covers four specific text attributes: baseline offset, character spacing, adaptive font size constraints, and text case conversion. Key takeaways include the requirement that minFontSize and maxFontSize must be set simultaneously and combined with layout constraints like maxLines to enable adaptive sizing. Each section provides executable Cangjie code snippets alongside visual output references. This guide is intended for developers seeking to refine text presentation and layout behavior within their applications.

### 自定义文本样式_3.md 自定义文本样式_3.md
This document serves as a practical guide for implementing custom text styling properties in Cangjie UI development. It focuses on two specific text attributes: text capitalization and clipboard interaction. The main sections demonstrate the usage of the textCase property to switch between Normal, LowerCase, and UpperCase, and the copyOption property to control text copyability using CopyOptions.InApp. Key takeaways include the syntax for applying these modifiers to Text components within a layout. This tutorial is intended for developers building HarmonyOS applications who need to manipulate text presentation and user interaction capabilities.
