# 弹性布局Flex

This directory provides a comprehensive technical guide for implementing Flex layouts using the Cangjie language and the ArkUI framework. It covers fundamental concepts such as main and cross axes, layout directions, and wrapping behaviors, alongside advanced techniques for adaptive stretching and alignment. The content includes practical code examples and visual references to demonstrate how to structure responsive user interfaces effectively. Designed for HarmonyOS developers and UI engineers, this resource helps in mastering declarative UI mechanics to create polished, flexible applications that adapt to various screen sizes and content requirements.

### 自适应拉伸.md 自适应拉伸.md
This guide explains how to achieve adaptive layout in Flex containers by configuring child element properties. It covers three key attributes: flexBasis for setting base dimensions, flexGrow for distributing remaining space, and flexShrink for handling space shortages. The document provides Cangjie code examples demonstrating how flexBasis overrides width, how flexGrow allocates space based on ratios, and how flexShrink compresses elements proportionally. It targets ArkUI developers using the Cangjie language who need to create responsive user interfaces that adjust to varying parent container sizes.
