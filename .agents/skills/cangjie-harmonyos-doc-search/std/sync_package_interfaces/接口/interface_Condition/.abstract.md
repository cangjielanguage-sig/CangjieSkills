This directory provides comprehensive API reference documentation for the Cangjie `Condition` interface and its specific utility functions. It focuses on thread synchronization primitives that allow developers to manage shared variables and coordinate thread execution efficiently. The content covers essential mechanisms such as suspending threads, notifying waiting threads, and handling timeouts with mutex management. This documentation is intended for Cangjie developers and system programmers building multi-threaded applications who require robust tools for inter-thread communication and precise control over blocking conditions.
