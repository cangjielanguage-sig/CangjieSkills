This directory focuses on network connection management using the Cangjie language and HarmonyOS NetworkKit. It covers essential tasks such as DNS resolution, network state monitoring, capability querying, and handling network switches. Key topics include obtaining network handles, binding applications to specific networks, and managing permissions like `ohos.permission.INTERNET` and `ohos.permission.GET_NETWORK_INFO`. The resources are designed for developers building network-aware applications that require robust connectivity management across Wi-Fi, cellular, and Ethernet networks.
