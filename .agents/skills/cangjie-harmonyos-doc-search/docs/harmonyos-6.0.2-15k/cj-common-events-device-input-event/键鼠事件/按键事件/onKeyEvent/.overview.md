# onKeyEvent

This directory serves as a comprehensive resource for developers working with keyboard input events in HarmonyOS applications, specifically focusing on the `onKeyEvent` method. It encompasses documentation for both the Cangjie and ArkUI (ArkTS) frameworks, detailing how to capture and process user input on focused UI components. Key topics include understanding function signatures, utilizing callback parameters like `KeyType` and `keyCode`, and managing event flow through bubbling and propagation techniques. The directory also provides practical code snippets for detecting key presses and releases, as well as dynamically updating application state based on user interactions. This content is ideal for HarmonyOS developers who need to implement sophisticated keyboard handling, manage component focus, and ensure responsive event-driven behavior in their application interfaces.

## Detailed Description

### onKeyEvent_1.md onKeyEvent_1.md
This API documentation explains the onKeyEvent method in Cangjie for handling keyboard input events on focused UI components. It covers the function signature, KeyEvent callback parameters (like KeyType and keyCode), and practical code examples demonstrating event handling on nested components. Key takeaways include understanding event bubbling, where parent and child components both receive events, and using event.stopPropagation to prevent this behavior. The document also details the dual callback nature corresponding to key press and release actions. Targeted at Cangjie developers building HarmonyOS applications, this guide requires knowledge of basic UI component structure and focus management.

### onKeyEvent_2.md onKeyEvent_2.md
This document provides a code example demonstrating how to handle keyboard events using the onKeyEvent callback in ArkUI. The content focuses on implementing event logic to detect specific key types, such as Down and Up, and extracting event details like keyCode and keyText. Key takeaways include the syntax for binding the event handler and dynamically updating component state based on user input. This technical snippet is intended for HarmonyOS developers using ArkTS who require practical guidance on implementing keyboard interaction within their application interfaces.
