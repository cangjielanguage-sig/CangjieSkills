This documentation unit focuses on the `onMessageEventExt` function within the Cangjie and ArkWeb framework, facilitating communication between native applications and HTML5 web pages. It covers the API reference, system capabilities, and practical code examples for bi-directional data exchange using `WebMessagePort` and `WebMessageExt`. Key topics include message registration, data type handling (String, Number, ArrayBuffer, etc.), and exception management. This resource is suitable for developers building hybrid applications who need to implement robust native-to-web communication channels in HarmonyOS environments.
