# cj-crypto-sm4-sym-encrypt-decrypt-cbc

This directory serves as a specialized technical resource for implementing the SM4 symmetric encryption algorithm within the HarmonyOS development environment. It focuses specifically on the Cipher Block Chaining (CBC) mode combined with PKCS7 padding, utilizing the Cangjie programming language and the CryptoArchitectureKit. The content is designed to assist developers in mastering the complete cryptographic workflow, from the generation of secure 128-bit symmetric keys to the management of initialization vectors (IVs). It is particularly suitable for developers building secure applications that require robust data protection, compliance with Chinese cryptographic standards, and efficient handling of chunked data processing.

## Detailed Description

### 使用SM4对称密钥CBC模式加解密/

This subdirectory acts as a comprehensive guide for developers aiming to integrate SM4 symmetric encryption and decryption into their HarmonyOS applications using the Cangjie language. It provides detailed resources on utilizing the CryptoArchitectureKit to implement the CBC mode of operation, which is essential for ensuring data confidentiality.

The guide covers the full technical lifecycle of cryptographic operations. Key topics include:
*   **Key Generation:** Instructions for creating secure 128-bit symmetric keys required for the SM4 algorithm.
*   **Cipher Management:** Steps for instantiating and configuring cipher objects to perform encryption and decryption tasks.
*   **IV and Padding:** Best practices for managing Initialization Vectors (IVs) and applying PKCS7 padding to handle data blocks of varying sizes correctly.

Furthermore, the materials address advanced requirements such as supporting chunked data processing, allowing for the encryption of large data streams. By adhering to these guidelines, developers ensure their applications meet SM4 compliance standards while maintaining high performance and security.
