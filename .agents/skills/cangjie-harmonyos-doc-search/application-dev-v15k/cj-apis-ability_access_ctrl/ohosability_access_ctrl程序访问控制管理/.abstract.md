This directory provides comprehensive API reference documentation for the `ohos.ability_access_ctrl` module within the Cangjie language framework, focusing on program access control and permission management. It covers essential components such as the `AtManager` class for handling runtime permissions, enumerations for authorization states (`GrantStatus`), and result objects for permission requests. Key topics include verifying application permissions, requesting user authorization via system dialogs, and managing global hardware switches like cameras and microphones. This documentation is intended for HarmonyOS developers implementing security capabilities and user consent logic in their applications.
