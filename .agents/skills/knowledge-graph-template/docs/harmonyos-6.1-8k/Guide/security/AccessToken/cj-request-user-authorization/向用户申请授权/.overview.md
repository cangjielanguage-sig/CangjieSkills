# 向用户申请授权

本目录主要介绍在HarmonyOS应用开发中如何向用户动态申请敏感权限（user_grant）。内容涵盖了权限申请的完整流程，包括运行时权限校验、动态授权弹框触发、授权结果检查及异常处理。核心知识点涉及checkAccessToken()、requestPermissionsFromUser()等API的使用，以及仓颉语言在位置权限申请中的具体实现。本文档适合需要进行系统权限集成的应用开发者，帮助其遵循用户可知可控原则，正确实现隐私信息访问能力的授权管理。
