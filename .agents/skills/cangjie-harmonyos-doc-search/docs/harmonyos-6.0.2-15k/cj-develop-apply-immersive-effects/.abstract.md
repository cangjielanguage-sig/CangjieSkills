This directory serves as a comprehensive guide for developing and applying immersive effects within applications, specifically tailored for the HarmonyOS ecosystem. It addresses the technical challenges of minimizing visual disruption caused by system interface elements, such as status and navigation bars, to ensure a seamless user experience. The content covers essential concepts including avoidance areas, safe areas, and various immersive modes. Furthermore, it provides a comparative analysis of two primary implementation strategies: Window Full-screen Layout and Component Safe Area. This resource is ideal for application developers and UI designers utilizing ArkUI, Cangjie, or ArkTS who seek to create distraction-free, responsive, and full-screen layouts optimized for media consumption, gaming, and other visually intensive applications.
