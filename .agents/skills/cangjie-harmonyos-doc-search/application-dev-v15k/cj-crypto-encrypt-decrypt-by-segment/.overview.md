# cj-crypto-encrypt-decrypt-by-segment

This directory serves as a specialized technical resource dedicated to the advanced concepts of segmented encryption and decryption. It addresses the critical need for efficiency when handling large data volumes, offering developers a clear path to optimize cryptographic performance. The guide thoroughly explores the implementation nuances between symmetric and asymmetric encryption, highlighting the `update` method for symmetric processes and the necessity for manual data segmentation in asymmetric scenarios involving RSA and SM2. It provides vital information regarding chunk size limits—up to INT_MAX for symmetric—and strict key length adherence for asymmetric types. Furthermore, it clarifies that chunk size remains independent of specific encryption modes. This documentation is specifically tailored for developers utilizing the CryptoArchitectureKit who seek to build robust, high-performance applications capable of managing extensive datasets securely and efficiently.

## Detailed Description

The following section provides a comprehensive breakdown of the technical documentation available in this directory, detailing the specific implementation strategies for segmented cryptographic operations.

### cj-crypto-encrypt-decrypt-by-segment.md
This technical guide explains the principles and implementation of segmented encryption and decryption to improve efficiency when handling large data volumes. It covers symmetric encryption using the `update` method and asymmetric encryption which requires manual data splitting based on algorithm specifications like RSA and SM2. Key information includes that symmetric encryption allows developer-defined chunk sizes up to INT_MAX, while asymmetric encryption does not support `update` and requires strict adherence to key length limits. The document clarifies that chunk size is independent of encryption modes. This guide targets developers using the CryptoArchitectureKit who need to optimize performance for large datasets.
