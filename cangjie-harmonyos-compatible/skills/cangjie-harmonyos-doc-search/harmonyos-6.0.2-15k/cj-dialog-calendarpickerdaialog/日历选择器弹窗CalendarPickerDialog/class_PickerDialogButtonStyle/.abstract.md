This directory contains API reference documentation for the `PickerDialogButtonStyle` class within the Cangjie programming language and the ArkUI framework. It is dedicated to defining the styling configuration for buttons used specifically in picker dialogs. The documentation covers the comprehensive customization of button appearance and behavior, including text formatting, background styling, border radius, and interaction logic such as focus handling and response to the Enter key. By detailing both the class constructor and its read-only properties, this resource provides the necessary specifications for developers. It is suitable for UI developers and software engineers building ArkUI applications who require precise control over dialog interface aesthetics and user interaction flows.
