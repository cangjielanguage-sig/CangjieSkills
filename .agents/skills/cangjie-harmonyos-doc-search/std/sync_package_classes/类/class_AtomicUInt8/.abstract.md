This directory contains API reference documentation for the `AtomicUInt8` class in the Cangjie programming language. It focuses on atomic operations for unsigned 8-bit integers, essential for thread-safe concurrent programming. Key topics include constructors, compare-and-swap mechanisms, arithmetic operations (add, subtract), bitwise operations (AND, OR, XOR), and memory management (load, store, swap). The documentation highlights deprecated methods involving explicit memory ordering versus current default implementations. It is suitable for developers implementing low-level concurrency, synchronization mechanisms, and precise atomic state control.
