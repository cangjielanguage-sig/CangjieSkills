# HTTP数据请求

This directory focuses on HTTP data request capabilities within the NetworkKit framework, specifically for HarmonyOS and Cangjie development. It covers the full lifecycle of HTTP requests, including standard request implementation, streaming data handling, and security measures like Certificate Pinning. Key topics include module imports, `HttpRequest` object management, event subscription, and SSL configuration. It is suitable for application developers and system administrators looking to implement robust network communication, manage asynchronous data streams, and enhance application security against man-in-the-middle attacks.

## Detailed Description

### request接口开发步骤.md request接口开发步骤.md
This document serves as a technical tutorial guiding developers through the implementation of HTTP requests using the Cangjie language and the NetworkKit. It outlines a seven-step process covering the full request lifecycle, from importing modules and creating an HttpRequest object to subscribing to events, initiating requests, and finally destroying the object. The content includes a detailed code example demonstrating the configuration of HttpRequestOptions, such as setting request methods, headers, timeouts, and handling multipart data. Key takeaways emphasize the non-reusable nature of HttpRequest objects and the importance of resource cleanup. Intended for Cangjie application developers, this guide assumes familiarity with network concepts and SDK usage.

### 场景介绍_2more.md 场景介绍_2more.md
This document provides an overview of HTTP data request capabilities and the associated interfaces available in the http module. It covers the scenario description of initiating HTTP requests and a detailed interface table listing methods for request management and event subscription. Key information includes support for standard HTTP methods, the requirement for the ohos.permission.INTERNET permission, and functions like createHttp, request, and various on/off event listeners for headers, data streams, and progress tracking. This technical reference is intended for developers implementing network communication features who need to understand available APIs and permission prerequisites.

### requestInStream接口开发步骤/
This directory provides comprehensive technical tutorials for implementing the `requestInStream` interface, specifically designed to handle HTTP streaming requests efficiently. It covers the complete development lifecycle, ranging from object creation and event subscription to request initiation and resource cleanup. The content includes detailed code examples in both Cangjie and ArkTS/TypeScript, demonstrating how to configure request options, manage SSL certificates, handle timeouts, and implement asynchronous callbacks for error handling and response validation. This resource is essential for application developers utilizing NetworkKit who require robust solutions for processing streaming HTTP responses and managing network events in their applications.

### 证书锁定/
This directory focuses on Certificate Pinning (证书锁定) techniques, specifically designed for securing network communications within HarmonyOS applications. It provides comprehensive resources on how to restrict HTTPS connections to specific developer-defined certificates to effectively prevent man-in-the-middle attacks. The content covers the configuration of network security settings via JSON, including methods for pre-setting application-level certificates (crt/pem) and configuring public key hash values using SHA-256 algorithms. Additionally, it offers practical guidance on using OpenSSL for certificate extraction and hash calculation. This directory is suitable for HarmonyOS developers and system administrators seeking to implement custom trust stores and enhance application security protocols. It addresses critical security considerations, such as handling server certificate chain updates.
