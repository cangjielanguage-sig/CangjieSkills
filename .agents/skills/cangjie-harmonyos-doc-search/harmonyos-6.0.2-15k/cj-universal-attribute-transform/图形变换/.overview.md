# 图形变换

This directory contains API reference documentation for implementing graphic transformations within the ArkUI framework using the Cangjie programming language. It covers essential manipulation techniques including scaling, translation, and rotation, allowing developers to modify component geometry and layout positioning precisely. The content details specific functions for 2D and 3D transformations, handling of different data types (Int32, Float32, Length), and matrix operations. This resource is suitable for UI developers and system engineers looking to programmatically control component appearance and spatial relationships in ArkUI applications.

## Detailed Description

### func_scaleInt32_8more.md
This document serves as an API reference for component transformation functions within the ArkUI framework using the Cangjie language. It details methods for scaling components uniformly or along specific axes, including scale, scaleX, and scaleY, as well as translation and matrix transformation capabilities. Key information includes support for both Int32 and Float32 types for scaling factors, the ability to define 3D scaling ratios with custom center points, and the application of Matrix4Transit for complex transformations. Targeted at UI developers, this documentation provides the necessary parameters and system capabilities to precisely manipulate component geometry and layout positioning.

### func_translateLength_Lengt_6more.md
This API reference document details functions for setting component translation distances within the ArkUI framework using the Cangjie language. The main sections cover the `translate` function for 3D movement (x, y, z) and specific `translateX` and `translateY` overloads that accept Int64 or Length types. Key information includes parameter definitions, default values (0.vp), and an explanation of the coordinate system where the origin is the component's top-left corner. The document also highlights the visual scaling effect of Z-axis translation and provides a code example demonstrating implementation. Intended for UI developers, this guide requires knowledge of Cangjie syntax and ArkUI component structures. Keywords: ArkUI, Cangjie, translate, component transformation, API reference, coordinate system.

### 图形变换_9more.md
This document serves as an API reference for implementing graphic transformations, specifically rotation and scaling, within the ArkUI framework using the Cangjie language. It details multiple overloaded functions including a comprehensive rotate method for 3D axis-based rotation, specific rotateX and rotateY methods, a simplified rotate for Z-axis, and a scale function. Key information includes defining rotation axes via vector coordinates, setting transformation centers (anchors), and understanding the coordinate system behavior. All functions support system capability version 12 and return the component instance for method chaining. This technical documentation targets UI developers needing to manipulate component geometry programmatically.
