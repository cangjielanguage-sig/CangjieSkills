# ArkGraphics2D

ArkGraphics2D serves as the foundational 2D graphics service module for the HarmonyOS and OpenHarmony ecosystems, specifically optimized for the Cangjie programming language. This directory encompasses a wide array of resources focused on graphics rendering, image processing, and advanced color management. It provides developers with essential tools, including comprehensive API references, detailed error code definitions, and structural guides for implementation. Currently, many features are in the Beta stage, indicating active development and iteration. This documentation is primarily suitable for advanced developers and system engineers who require precise control over 2D graphics, color correction, and visual output stability in their applications.
