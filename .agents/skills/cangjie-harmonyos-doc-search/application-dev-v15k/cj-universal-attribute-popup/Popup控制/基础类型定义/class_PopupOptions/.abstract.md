This directory contains API reference documentation for the `PopupOptions` class and associated configuration variables within the ArkUI framework, specifically designed for the Cangjie language. It covers the comprehensive setup and customization of popup windows, detailing properties for layout positioning, visual styling, arrow indicators, transition effects, and event handling. Key topics include background blur, button actions, geometry constraints, and window management behaviors. This documentation is suitable for UI developers and system architects seeking to implement customizable popup dialogs, menus, or bubble components in their applications.
