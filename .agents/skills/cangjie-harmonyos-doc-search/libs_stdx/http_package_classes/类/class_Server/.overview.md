# class_Server

This directory contains API reference documentation for the Cangjie `Server` class, a core component designed for creating and managing HTTP services. It covers essential server functionalities including lifecycle management, request handling, TLS configuration, and protocol negotiation for HTTP/1.1 and HTTP/2. Developers will find detailed specifications for properties, methods, and hot updates for certificates. This documentation is suitable for backend developers and system engineers working with the Cangjie language who need to implement secure, high-performance web servers and manage runtime configurations effectively.

## Detailed Description

### class_Server_15more.md
This document provides API reference documentation for the Cangjie Server class, designed to facilitate HTTP service creation and management. It covers the class's core functionality, including starting and stopping services, registering request handlers, and managing TLS certificates and logging. The main section lists various properties for configuring server behavior, distinguishing between general settings like address and port, and protocol-specific parameters for HTTP/1.1 and HTTP/2. Key information includes configuration for request distribution, flow control, header limits, and timeouts. This guide targets Cangjie developers seeking to implement and fine-tune HTTP servers, requiring knowledge of network protocols and the Cangjie language syntax.

### func_updateCAArrayX509Cert_4more.md
This API reference document details functions for performing hot updates on CA and TLS certificates within a Cangjie HTTP server context. It covers four overloaded functions: updateCA and updateCert, each accepting either object arrays or file path strings as input parameters. The functions enable runtime certificate management without restarting the service. Key parameters include X509Certificate arrays, PrivateKey objects, and file paths. Common exceptions include IllegalArgumentException for invalid inputs and HttpException if TLS is not configured. This guide targets developers implementing secure communication in Cangjie applications who need dynamic certificate management capabilities.

### prop_protocolServiceFacto_11more.md
This document provides API reference documentation for a server configuration class in the Cangjie programming language. It details properties for accessing the protocol service factory, timeout settings, and transport layer configurations. Additionally, it outlines functions for server lifecycle management, including immediate and graceful shutdown methods, as well as callbacks for startup and shutdown events. Key takeaways involve understanding how to configure request timeouts, manage TLS settings, and register hooks for server binding and termination. This technical guide is intended for developers implementing or configuring HTTP servers who require precise control over service instances and operational behavior.

### func_serve
This directory contains comprehensive technical documentation for the `func_serve` module, a robust backend component designed to initiate and manage server-side processes for both HTTP/1.1 and HTTP/2 traffic. It provides in-depth specifications on request validation, response generation, connection management, and protocol negotiation via TLS ALPN. Key technical areas include strict RFC 9112 compliance enforcement, header processing rules, stream management, and flow control mechanisms. The documentation is specifically tailored for backend developers and system engineers who are implementing, configuring, or debugging the core HTTP server logic, ensuring high performance and strict adherence to web protocol standards. It serves as a critical reference for maintaining server stability, handling edge cases like 100-continue, and managing resource limits effectively.
