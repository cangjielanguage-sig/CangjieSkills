# interface_CountableT

This directory contains essential API documentation for the Cangjie programming language, focusing on the definition of the `Countable` interface and specific type extensions for time-based arithmetic. It covers the structural definition of the generic `Countable` interface, which maps instances to Int64 positions, and details extensions for Int64 and Float64 types to support multiplication with the `Duration` type. Key topics include interface methods such as `next` and `position`, operator overloading for scalar multiplication, and exception handling for arithmetic overflow scenarios. This documentation is highly suitable for Cangjie developers who are implementing countable types or working with precise time interval calculations and scaling operations.
