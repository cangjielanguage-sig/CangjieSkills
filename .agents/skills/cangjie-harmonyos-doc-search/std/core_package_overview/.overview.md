# core_package_overview

This directory serves as the primary entry point and comprehensive overview for the Cangjie language's standard library core package. The scope of this directory includes, but is not limited to, built-in primitive types such as integers and floats, fundamental I/O operations for system interaction, and standard interfaces like ToString and Hashable which are crucial for type interoperability. Because this core package is imported automatically, developers gain immediate access to vital classes like Array and String without needing to write explicit import statements. This documentation is specifically tailored for Cangjie developers who wish to gain a deeper understanding of the language's runtime, implement custom types that integrate seamlessly with the standard library, or execute low-level system operations. It acts as a critical resource for mastering exception handling, utilizing utility functions, and referencing the core APIs necessary for building robust and efficient applications.

## Detailed Description

### stdcore/
The `stdcore` directory serves as the central repository for the foundational documentation regarding the Cangjie language's standard library core package. It is designed to provide developers with essential programming capabilities right out of the box. Key areas covered in this section include the definition and usage of built-in types, such as integers and floating-point numbers, which are the building blocks of any application. Additionally, it details common I/O functions necessary for interacting with the system environment and standard interfaces like ToString and Hashable that facilitate object interoperability.

A significant feature of this package is that it is imported by default. This means developers have immediate access to core classes like Array and String without the need for explicit import statements, streamlining the development process. The documentation is particularly suitable for Cangjie developers who aim to understand the language's basic environment thoroughly. It provides the necessary guidance for those looking to implement custom types that adhere to language standards or perform low-level system operations. Furthermore, the section covers critical aspects of software robustness, including exception handling, various utility functions, and comprehensive API references, ensuring developers have all the tools needed for successful application development.
