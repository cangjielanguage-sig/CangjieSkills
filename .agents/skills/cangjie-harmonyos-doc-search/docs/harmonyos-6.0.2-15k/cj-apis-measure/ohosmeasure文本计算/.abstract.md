This directory provides comprehensive API reference documentation for the `ohos.measure` module within the HarmonyOS ArkUI framework, specifically tailored for the Cangjie programming language. It focuses on the essential tools required for calculating text layout dimensions, enabling developers to determine precise width and height values for dynamic UI rendering. The documentation covers core components such as the `Measure` class for performing calculations, the `Size` struct for representing dimensions, and the `MeasureOptions` class for configuring text attributes like font size and weight. This resource is ideal for Cangjie developers and UI engineers who need to implement responsive design logic and ensure accurate text measurement in their HarmonyOS applications.
