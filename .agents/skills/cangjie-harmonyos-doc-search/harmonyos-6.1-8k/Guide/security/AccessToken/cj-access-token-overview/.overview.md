# cj-access-token-overview

本目录提供了系统访问控制机制的全面概览，重点阐述了安全隔离与权限管理的核心原则。内容涵盖应用沙箱、应用权限、TokenID识别机制以及基于APL（Ability Privilege Level）等级的权限分层保护，旨在确保应用对系统数据和功能的合法访问。该文档作为参考指南，适合应用开发者阅读，帮助其深入理解系统安全架构、沙箱隔离原理以及权限申请的基本概念，从而有效保护通讯录、摄像头等敏感资源，抵御恶意攻击。

## 详细描述

### cj-access-token-overview.md cj-access-token-overview.md
本文档详细概述了系统的访问控制机制，其核心目标是通过严格的安全隔离和精细化的权限管理，确保应用能够合法、合规地访问系统数据和功能。文档主要涵盖了应用沙箱（Application Sandbox）和应用权限（Application Permissions）两大板块，深入介绍了TokenID识别机制以及基于APL（Ability Privilege Level）等级的权限分层保护策略。关键知识点包括：应用运行在受保护的沙箱环境中，并被分配唯一的ID；系统依据APL等级设置安全标签，通过权限管控机制严格保护通讯录、摄像头等敏感资源，从而有效抵御恶意攻击。本文档属于参考指南，主要面向应用开发者，旨在帮助开发者深入理解系统安全架构、沙箱隔离原理以及权限申请的基本概念。
