# 资源目录

This directory serves as a comprehensive technical reference for the architecture and management of application resource directories, specifically tailored for the HarmonyOS ecosystem. It details the structural hierarchy of resources, distinguishing between base directories and qualifier directories used for localization and device adaptation. The documentation covers critical aspects such as naming conventions, resource compilation into binary files, and the specific ordering rules for qualifiers like MCC, language, and orientation. Furthermore, it addresses the handling of non-compiled resources through rawfile and resfile directories, explaining access methods and sandbox path extraction. This guide is indispensable for software developers, system architects, and localization specialists who need to efficiently organize application assets, ensure compatibility across diverse devices, and implement robust internationalization strategies.

## Detailed Description

### 资源目录_1.md 资源目录_1.md
This reference guide outlines the structure and naming conventions for application resource directories, specifically focusing on base and qualifier directories. It covers the default base directory structure, the purpose and creation of qualifier directories for localization and device adaptation, and the strict naming rules for these qualifiers. Key information includes that resources are compiled into binary files referenced by type and name, and qualifier names must follow a specific order (MCC, language, orientation, etc.) using underscores or hyphens depending on the qualifier type. This guide is intended for software developers organizing project resources, requiring knowledge of file systems and internationalization concepts. Keywords: resource directory, qualifier, naming conventions, localization, base directory, binary compilation.

### 资源目录_2.md 资源目录_2.md
This technical reference document defines resource qualifiers and directory structures for application development, specifically within the HarmonyOS ecosystem. It details specific qualifier types including mobile network codes, language, script, region, orientation, device type, color mode, and screen density. It also explains the usage and access methods for rawfile and resfile directories. Key takeaways include that qualifiers follow international standards like ISO and ITU-T. Both rawfile and resfile support custom subdirectories and pack files without compilation or ID generation. Crucially, resfile resources are extracted to the application sandbox path for access via the Context API. This guide is intended for software developers needing to organize and access non-compiled application resources efficiently.
