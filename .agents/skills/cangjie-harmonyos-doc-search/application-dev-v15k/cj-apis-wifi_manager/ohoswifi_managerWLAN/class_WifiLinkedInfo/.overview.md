# class_WifiLinkedInfo

This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically focusing on the `WifiLinkedInfo` class. It serves as a technical resource for developers implementing WiFi Station (STA) functionality, offering detailed insights into the current state of a Wireless Local Area Network (WLAN) connection. The documentation covers a wide array of read-only properties, ranging from basic network identifiers like SSID and BSSID to complex signal metrics such as RSSI and frequency. Furthermore, it details connection specifics including IP addresses, link speeds, MAC address types, and hardware standards. By defining required system capabilities and data types, this guide assists developers in accessing network status to drive application logic or update user interfaces efficiently.

### class_WifiLinkedInfo_18more.md class_WifiLinkedInfo_18more.md
This document provides API reference documentation for the Cangjie class `WifiLinkedInfo`, which encapsulates detailed information about a current WLAN connection. It lists the class definition and describes numerous read-only properties including network identifiers like SSID and BSSID, signal metrics such as RSSI and frequency, and connection details like IP address, link speeds, and MAC address type. The document specifies data types for each property and notes system capabilities required. Intended for developers working with WiFi Station (STA) functionality, this reference helps in accessing network status for application logic or user interface updates. Key concepts include network bandwidth, security restrictions, and hardware standards.

### let_supportedWifiCategory_3more.md let_supportedWifiCategory_3more.md
This document provides API reference documentation for WiFi-related members in the Cangjie programming language. It details two read-only properties, `supportedWifiCategory` and `wifiStandard`, which expose the highest supported WiFi level and the current connection standard, respectively. Additionally, it documents the `toString()` function for retrieving a string representation of the class. Key information includes the data types `WifiCategory` and `WifiStandard`, the read-only nature of the properties, and the requirement for the system capability `SystemCapability.Communication.WiFi.STA` starting from version 19. This reference is intended for developers querying WiFi hardware capabilities and connection status within their applications.
