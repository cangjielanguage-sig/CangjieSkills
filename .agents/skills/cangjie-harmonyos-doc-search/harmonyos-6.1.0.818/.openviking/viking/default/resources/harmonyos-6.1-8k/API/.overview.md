# API

This directory serves as the central API reference documentation hub for the HarmonyOS and OpenHarmony ecosystems, specifically tailored for developers using the Cangjie (仓颉) programming language. It encompasses a wide range of system capabilities, including application frameworks, multimedia, graphics, connectivity, and hardware management. The content is designed to assist developers in integrating system services, managing data, and building robust applications. It is suitable for application developers, system engineers, and QA professionals seeking comprehensive technical guides and interface definitions for HarmonyOS development.

## Detailed Description

### [1] AbilityKit/
AbilityKit is a comprehensive framework service repository designed for HarmonyOS application developers using the Cangjie programming language. It provides extensive API references and documentation for core modules such as UIAbility, Want, and access control.

### [2] ArkData/
The ArkData directory serves as a comprehensive API reference and documentation hub for data management within the HarmonyOS ecosystem, specifically tailored for the Cangjie programming language. It covers core functionalities including distributed key-value data management.

### [3] ArkGraphics2D/
ArkGraphics2D serves as the foundational 2D graphics service module for the HarmonyOS and OpenHarmony ecosystems, specifically optimized for the Cangjie programming language. This directory encompasses a wide array of resources focused on graphics rendering and drawing capabilities.

### [4] ArkWeb/
ArkWeb is a specialized documentation module designed for the HarmonyOS Web component, catering specifically to developers utilizing the Cangjie programming language. It functions as a central repository for integrating web technologies into HarmonyOS applications.

### [5] BasicServicesKit/
This directory contains the Basic Services Kit for HarmonyOS and OpenHarmony development using the Cangjie programming language. It provides a comprehensive collection of system-level APIs and documentation covering device management, including battery and device info.

### [6] CameraKit/
CameraKit is a comprehensive documentation repository dedicated to the Cangjie (仓颉) programming language's camera services within the HarmonyOS and OpenHarmony ecosystems. It focuses on the `ohos.multimedia.camera` module, providing essential resources for camera functionality.

### [7] ConnectivityKit/
ConnectivityKit is a comprehensive software development kit designed for the Cangjie language within the HarmonyOS ecosystem. It provides extensive support for short-range communication services, including Bluetooth (A2DP, BLE, HFP) and WLAN management.
