This directory provides a comprehensive technical overview of audio call development, specifically focusing on the critical distinctions between VoIP and cellular communication modes. It covers essential implementation details such as audio scene management, ring modes, and the logic behind audio device switching. Key technical concepts include VoIP's dependency on network quality and cellular mode's restriction to system-level applications. Developers will learn how to manage `AudioScene` (e.g., `AUDIO_SCENE_VOICE_CHAT`) using `AudioManager` and handle `AudioRingMode` states (Silent, Vibrate, Normal) via `AudioVolumeGroupManager` to control volume and vibration. This resource is designed for application developers implementing call features who require a deep understanding of system audio behaviors and specific API usage to ensure a seamless user experience.
