This directory focuses on best practices for state management in ArkUI application development using the Cangjie language. It covers performance optimization techniques designed to minimize unnecessary component re-renders and reduce execution overhead. Key topics include controlling component associations for complex state objects, optimizing loop logic by minimizing state variable reads, and using temporary variables for data calculations. Additionally, it addresses correct UI update mechanisms by avoiding dummy triggers. This guide is suitable for ArkUI developers seeking to enhance application quality and rendering efficiency through efficient state variable usage.
