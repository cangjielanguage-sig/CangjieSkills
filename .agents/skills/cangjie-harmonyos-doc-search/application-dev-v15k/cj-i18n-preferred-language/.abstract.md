This directory contains essential documentation for Cangjie developers working on internationalization (i18n) and localization. It provides a detailed guide on how to configure an application's preferred language independently of the system language, a critical feature for creating user-centric applications. By utilizing the Cangjie LocalizationKit, developers can manage app-specific locales without altering the device's global settings. The documentation outlines a comprehensive four-step development process, guiding users through module imports, retrieving current language states, setting specific languages, and clearing preferences. It is particularly suitable for developers who need to implement dynamic language switching or allow users to override system defaults within the app. The guide highlights key technical behaviors, such as the use of `System.setAppPreferredLanguage` to modify the UI language and the specific conditions required to revert to the system default, including potential application restarts. This resource ensures developers have the necessary knowledge to build flexible, multi-language applications that respect user preferences while maintaining system stability.
