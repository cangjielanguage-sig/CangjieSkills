This directory serves as a comprehensive repository for the API reference documentation of the HarmonyOS Bluetooth A2DP module, specifically architected for the Cangjie programming language. It provides developers with the necessary resources to implement robust Bluetooth audio streaming functionalities within their applications. The content covers a wide array of essential components, ranging from detailed encoder configuration via CodecInfo to sophisticated playback state management and A2DP source profile operations. By including enums for sample rates, channel modes, and codec types, alongside classes for device connection and event handling, this module equips developers to manage audio parameters and monitor playback status effectively. It is particularly suitable for developers targeting Bluetooth Core capabilities (version 19+) who require precise control over A2DP source interactions in the HarmonyOS ecosystem. This documentation ensures that developers have access to the structural definitions and functional descriptions needed to build high-quality audio experiences on compatible devices. Whether you are building a media player or a specialized audio tool, this directory offers the foundational API definitions required for successful integration. The focus on the Cangjie language ensures that the syntax and type systems align perfectly with the HarmonyOS development environment.
