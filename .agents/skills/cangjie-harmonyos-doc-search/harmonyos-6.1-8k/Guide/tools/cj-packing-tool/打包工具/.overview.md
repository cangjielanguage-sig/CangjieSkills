# 打包工具

本目录包含HarmonyOS应用打包工具的详细技术文档，主要介绍如何使用`app_packing_tool.jar`及相关命令行工具进行应用构建。内容涵盖HSP与App包的基础打包、FastApp模式打包、多工程整合与补丁打包，以及版本归一化处理。文档详细说明了合法性校验规则、压缩策略、参数配置及运行环境要求。这些资料适用于需要掌握命令行构建流程、进行多模块协同开发或维护应用版本一致性的HarmonyOS开发者。

## 详细描述

### HSP打包指令_2more_f33af137.md
本文档旨在指导开发者使用app_packing_tool.jar工具进行HSP和App包的命令行打包。文档涵盖HSP打包指令与App打包指令两大核心板块，详细列出了各模式的参数说明、必选项及配置示例。关键信息包括App打包时的HAP合法性校验规则（如bundleName一致性）及压缩策略（release压缩，debug不压缩），并明确了从API 12起不再校验versionName。该技术参考文档面向HarmonyOS应用开发者，帮助其掌握构建共享包及上架应用包的流程。

### fastApp模式打包指令_a3341ab2.md
本文档旨在指导开发者使用打包工具JAR包将HAP和HSP文件打包生成用于上架应用市场的App包。文档涵盖了HAP合法性校验规则、打包压缩规则、具体的命令行调用示例以及详细的参数含义说明表。关键信息包括：打包时需确保HAP的bundleName、versionCode等配置一致且moduleName唯一；release模式会压缩而debug模式不压缩；关键参数包括--mode、--hap-path、--out-path等。该文档属于技术参考文档，面向需要进行应用集成的开发者。

### 多工程打包指令_3more_79bb8523.md
本文档是应用打包工具的参考指南，详细说明了如何使用命令行工具进行多工程整合及补丁打包。主要涵盖多工程打包、HQF紧急修复包打包和APPQF补丁集打包三个指令模块。重点阐述了多工程打包的合法性校验规则（如bundleName、versionCode一致性），并列出了各模式下的必选参数（如--mode, --out-path）及文件路径要求。适用于需要协同开发整合代码或进行应用紧急修复的开发者，关键词包括HAP、HSP、多工程打包、热修复。

### 打包工具_3more_1dceed77.md
本文档介绍了用于将编译产物打包成HAP、HSP等格式的打包工具，支持通过DevEco Studio或JAR命令行进行操作。主要涵盖工具概述、运行环境约束、仓颉语言限制说明、编译产物路径查找方法及HAP打包指令参数详解。关键信息指出工具需Java 8+环境，重点提供了Stage模型下的HAP打包命令示例及参数表，明确了必选项如`--mode`和`--out-path`，以及资源、库文件等可选项的配置。该文档面向需要使用命令行工具进行HarmonyOS应用打包的开发者，旨在指导其正确配置参数以生成安装包。

### 版本归一指令versionNorm_2more_0cbd9485.md
本文档是app_packing_tool.jar工具的参考指南，旨在指导用户统一HarmonyOS应用中HAP和HSP包的版本信息及包名。文档主要涵盖两个核心指令：versionNormalize用于将多个HAP/HSP的版本号和版本名称统一，并生成版本记录；packageNormalize用于修改HSP的包名和版本号。文档详细列出了这两个指令的必选参数规范，包括输入文件路径、目标版本值及输出目录。这些功能主要面向需要维护应用组件版本一致性的开发人员，提供了具体的命令行使用示例。
