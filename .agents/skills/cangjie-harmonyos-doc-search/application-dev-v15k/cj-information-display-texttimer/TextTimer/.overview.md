# TextTimer

This directory provides comprehensive documentation for the TextTimer component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of a UI component that displays time as text, manages countdowns, and handles timer states efficiently. Key topics include component initialization, event handling, controller usage, and text styling customization. The resources are tailored for HarmonyOS developers looking to integrate time-tracking features, manual controls, and visual effects into their applications using Cangjie syntax.

## Detailed Description

### TextTimer_4more.md TextTimer_4more.md
This document serves as API reference documentation for the TextTimer component within the ArkUI framework, specifically using the Cangjie language. It details a UI component that displays time as text and manages timer states, pausing automatically when the component is not visible. The main section covers the component creation via the init method, which accepts parameters for countdown mode, duration in milliseconds, and a controller object. Key information includes the 24-hour maximum duration limit and the support for all generic attributes and events. This guide is intended for developers building user interfaces who need to implement time-tracking features.

### 示例代码.md 示例代码.md
This document serves as a practical tutorial demonstrating the implementation and customization of the TextTimer component using the Cangjie programming language for HarmonyOS development. The content is divided into three distinct examples covering basic manual control, text shadow styling, and automatic execution upon component appearance. Key takeaways include using TextTimerController for start, pause, and reset operations, defining display formats, applying ShadowOptions arrays, and utilizing the onAppear lifecycle event. Targeted at HarmonyOS developers, these examples require prior knowledge of Cangjie syntax and the UIKit framework to effectively implement timer functionalities in applications.

### 组件事件_2more.md 组件事件_2more.md
This document provides API reference documentation for the TextTimer component in the Cangjie language, focusing on event handling and control mechanisms. The main sections cover the onTimer event function and the TextTimerController class definition. Key information includes the onTimer callback parameters, which return a Linux timestamp and elapsed time, and the controller's methods for starting, pausing, and resetting the timer. It specifies that events do not trigger when the application is in the background or the screen is locked. This guide is intended for HarmonyOS developers using ArkUI to implement and manage text-based timers.
