This directory provides a comprehensive technical guide for HarmonyOS developers focusing on the interoperability between ArkTS and the Cangjie programming language. It specifically addresses how to invoke Cangjie functions from a pure ArkTS project within the same engineering workspace. The content covers essential development steps such as annotating Cangjie code with @Interop, generating interface declarations, configuring build scripts, and handling synchronous versus asynchronous calls. Additionally, it includes instructions for deploying and testing applications on real devices or emulators. This resource is best suited for developers who possess a foundational understanding of both ArkTS and Cangjie and are looking to implement cross-module function calls in a mixed-language development environment. By following these guides, developers can effectively integrate Cangjie logic into their ArkTS modules, ensuring seamless interaction between the two languages within a single project structure.
