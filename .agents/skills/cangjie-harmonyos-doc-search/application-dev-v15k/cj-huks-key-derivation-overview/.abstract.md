This directory serves as the definitive reference for understanding and implementing key derivation functionality within the OpenHarmony HUKS (Harmony Universal KeyStore) framework. It provides an in-depth look at the Key Derivation Functions (KDF) supported by the system, offering developers the necessary guidelines to utilize these cryptographic primitives effectively. The documentation outlines the specific algorithms supported, namely HKDF and PBKDF2, and details their integration with secure hashing algorithms like SHA256, SHA384, and SHA512. Crucially, it defines the operational boundaries of these functions, such as the restriction that derivation can only be performed on keys already managed by HUKS (excluding direct password inputs) and the lack of support for lightweight device profiles. Furthermore, it specifies the resulting key types—AES, HMAC, and SM4—that can be generated for applications running on API level 15 and above. This guide is indispensable for developers and security architects focused on building secure applications, as it clarifies the algorithm compatibility and key management prerequisites essential for maintaining robust security standards within the HarmonyOS ecosystem. It is specifically suitable for backend developers and system integrators who require a deep understanding of cryptographic constraints to ensure their applications function correctly across different device types and security levels.
