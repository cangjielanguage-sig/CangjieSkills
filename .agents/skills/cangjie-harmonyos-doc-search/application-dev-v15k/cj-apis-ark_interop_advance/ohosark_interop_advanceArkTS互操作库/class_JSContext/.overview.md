# class_JSContext

This directory provides API reference documentation for the Cangjie `JSContext` class, essential for single-threaded interoperability with the ArkTS runtime in HarmonyOS. It encompasses the core class definition, object lifecycle management, and a wide array of functions for data type conversion between Cangjie and ArkTS. Key topics include creating ArrayBuffers, handling numeric arrays, defining fundamental types like strings and symbols, and managing asynchronous tasks or module loading. This resource is designed for Cangjie developers building ArkUI applications who require deep integration with the Napi system for memory management and cross-language communication.
