# cj-apis-power

This directory serves as the definitive source for API reference documentation regarding the `cj-apis-power` module, specifically designed for the Cangjie programming language in the HarmonyOS environment. It focuses on system power management capabilities, providing developers with the tools necessary to query and monitor device states accurately. The documentation thoroughly covers essential functions such as `getPowerMode`, `isActive`, and `isStandby`, which are crucial for applications that need to respond to changes in power availability. Additionally, it provides a detailed breakdown of the `DevicePowerMode` enumeration, explaining the distinctions between Normal, Performance, and Power Save modes. Beyond mere definitions, the guide includes practical module import instructions, usage examples for template projects, and comprehensive error handling details. It is an essential resource for Cangjie developers aiming to build robust HarmonyOS applications that require efficient power management and real-time monitoring of system behaviors. Whether you are optimizing for battery life or performance tuning, this documentation provides the necessary technical context.
