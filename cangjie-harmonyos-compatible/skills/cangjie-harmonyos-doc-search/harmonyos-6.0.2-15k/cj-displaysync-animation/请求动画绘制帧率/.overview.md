# 请求动画绘制帧率

This directory serves as a comprehensive technical resource for managing animation rendering performance within the Cangjie development environment. It specifically addresses the critical requirements for requesting and configuring specific drawing frame rates to ensure smooth visual effects and efficient system resource utilization. Key topics include the utilization of `ExpectedFrameRateRange` to define precise rendering parameters, distinguishing between property and explicit animation implementations, and leveraging `AnimateParam` for fine-tuned control. The documentation provides practical code examples illustrating how to set minimum, maximum, and expected frame rates (e.g., 30Hz or 60Hz) to balance performance and visual fidelity. This content is highly suitable for Cangjie developers and UI engineers aiming to optimize application responsiveness and achieve consistent animation behavior across different devices.
