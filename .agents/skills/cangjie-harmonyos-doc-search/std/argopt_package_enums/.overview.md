# argopt_package_enums

This directory hosts the API documentation for enumerations belonging to the `argopt` package, a core component for command-line argument parsing in the Cangjie programming language. It provides the foundational definitions required to structure and parse command-line inputs effectively. This documentation is highly suitable for systems programmers and developers building CLI tools in Cangjie who require precise control over argument behaviors, validation, and callback handling. By standardizing how arguments are defined, this package helps reduce boilerplate code and minimizes parsing errors. ### argopt_package_enums.md argopt_package_enums.md

This file acts as the definitive API documentation for the enumerations provided by the `argopt` package. It is specifically designed to assist developers working within the Cangjie programming language ecosystem to implement robust command-line interfaces. It serves as a structural skeleton for the package, ensuring that all argument handling follows a consistent type-safe pattern.

The documentation provides an in-depth look at the `ArgumentMode` enumeration. This enum is essential for defining the constraints on command-line parameters, specifying whether an argument expects no value, an optional value, or a required value. It also details the utility functions available for these modes, such as equality checks and string conversion capabilities, which are vital for validation and logging.

Additionally, the file covers the `ArgumentSpec` enumeration, which is used to outline the specific formats of command-line arguments. This includes support for short options (e.g., `-v`), long options (e.g., `--verbose`), and full options. A key feature described is the ability to associate these specifications with lambda callback functions, allowing for custom logic to be executed when specific arguments are parsed. This reference guide is indispensable for developers who need to define clear argument behaviors and specifications in their applications. By utilizing these enumerations, developers can ensure their command-line tools are user-friendly and strictly adhere to defined input protocols.
