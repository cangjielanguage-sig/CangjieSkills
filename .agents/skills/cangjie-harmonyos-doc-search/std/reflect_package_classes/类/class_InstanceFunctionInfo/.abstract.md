This directory contains API reference documentation for the `InstanceFunctionInfo` class within the Cangjie language's reflection framework. It provides comprehensive details on describing instance member function information, enabling runtime introspection and type analysis. The documentation covers class properties, dynamic invocation mechanisms for both standard and generic functions, and metadata retrieval utilities such as annotation checks. It is intended for Cangjie developers who need to perform dynamic execution, analyze code structure at runtime, or implement advanced reflection-based features in their applications.
