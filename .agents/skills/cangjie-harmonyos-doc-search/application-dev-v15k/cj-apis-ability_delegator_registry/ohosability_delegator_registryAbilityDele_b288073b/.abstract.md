This directory contains API reference documentation for the HarmonyOS Cangjie framework, specifically focusing on the `AbilityDelegatorRegistry` and related testing infrastructure. It covers essential components for unit testing and automated testing within the ability runtime, including argument encapsulation, lifecycle state management, and monitoring of UIAbility and AbilityStage components. The documentation details classes for tracking application states, executing shell commands, and managing test execution flows. It is suitable for Cangjie developers and QA engineers building automated tests for HarmonyOS applications who need to programmatically manipulate and observe application component behaviors.
