# socket_option

This directory contains essential documentation for configuring and extending socket options within the Cangjie programming language. It provides a detailed usage guide that covers the management of standard TCP socket properties, such as read timeout, no delay, and keep-alive settings, which are vital for optimizing network communication. Beyond standard configurations, the content explores advanced techniques for implementing custom attributes using the `extend` keyword. It also demonstrates how to perform low-level option manipulation through native functions like `getSocketOptionIntNative` and `setSocketOptionIntNative`. This resource is specifically designed for Cangjie developers who are already familiar with the `std.net` library and possess a basic understanding of socket programming concepts, offering them the tools needed to fine-tune network applications effectively. By mastering these options, developers can ensure their applications maintain robust and efficient network connections.
