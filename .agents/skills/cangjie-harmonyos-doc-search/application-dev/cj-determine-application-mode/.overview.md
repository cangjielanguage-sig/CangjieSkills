# cj-determine-application-mode

This directory contains essential documentation for developers working within a specific software ecosystem to determine the correct application mode for requesting permissions. It addresses the complexities of Application Permission Levels (APL), specifically focusing on normal and system_basic levels, and how they relate to different authorization types. The guide provides a detailed breakdown of workflows necessary for handling open versus restricted permissions, ensuring developers can correctly implement security measures. It explains the technical nuances of mapping permission types like system_grant and user_grant to specific operational steps, including declaration, ACL application, and user authorization. Furthermore, it offers practical instructions for modifying the HarmonyAppProvision configuration file to elevate APL for debugging. This document is a vital resource for developers responsible for maintaining permission compliance and managing access control, ensuring applications function correctly within the security constraints of the operating system.

## Detailed Description

### cj-determine-application-mode.md

This guide instructs developers on selecting the appropriate method to apply for permissions based on application permission levels (APL) and authorization types. It details workflows for normal and system_basic level applications, distinguishing between open and restricted permissions. Key information includes mapping permission types like system_grant and user_grant to specific operation paths involving declaration, ACL application, and user authorization. Additionally, it explains how to modify the HarmonyAppProvision configuration file to elevate APL for debugging. This technical reference is intended for developers managing permission compliance and access control within their applications.
