This directory serves as the definitive API reference documentation for the HarmonyOS BundleManager framework, specifically tailored for the Cangjie programming language. It provides an extensive technical overview of the mechanisms required to manage application bundles, encompassing standard abilities, extension abilities, system permissions, and metadata. The documentation details critical classes used for querying bundle information, enumerations that define component types and operational flags, and complex structures necessary for configuration details such as routing and dependency management. This resource is vital for developers and software engineers operating within the HarmonyOS ecosystem who require programmatic access to underlying system capabilities. It enables users to effectively manage application lifecycles, ensure proper permission handling, and configure component behaviors to create seamless and integrated user experiences.
