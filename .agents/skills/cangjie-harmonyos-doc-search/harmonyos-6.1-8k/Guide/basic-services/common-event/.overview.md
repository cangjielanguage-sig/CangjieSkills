# common-event

This directory contains documentation for the Common Event Service (CES), a mechanism designed for efficient inter-process communication (IPC) and event-driven development. It covers fundamental concepts, classifications, and operational mechanisms of CES, including system and custom events, as well as unordered, ordered, and sticky transmission modes. The content is specifically tailored for Cangjie language developers, offering comprehensive guides on subscribing to, publishing, and unsubscribing from events. It also addresses critical aspects such as resource lifecycle management and security permissions. This resource is essential for engineers building decoupled, cross-process applications that require real-time response to system or application-level state changes.

## Detailed Description

### README_zh/
This directory serves as the Chinese navigation center for the process and thread communication module. It aims to help developers utilize the common event mechanism for efficient Inter-Process Communication (IPC). The documentation comprehensively covers core topics such as basic knowledge of common events, dynamic subscription processes, unsubscription mechanisms, and event publishing methods. Since all listed features are currently Beta, this guide is particularly important for engineers wishing to try new features or develop cross-process interactions. It not only provides a clear functional index but also guides developers through the complete development loop from subscription to publishing via detailed links, serving as an important reference for building decoupled and efficient cross-process applications.

### cj-common-event-overview/
This directory contains overview documentation for the Common Event Service (CES), aiming to elucidate its basic concepts, classifications, and operational mechanisms. The content covers the distinction between system and custom events, as well as three sending modes: unordered, ordered, and sticky, helping developers implement subscription, publishing, and unsubscription functions between applications. The document also highlights security precautions, including permission control and package name restrictions. Core keywords include CES, common events, subscription/publishing, sticky events, and security permissions. This document is suitable for application developers requiring cross-process communication, providing comprehensive conceptual guidance.

### cj-common-event-publish/
This directory provides a development guide for publishing common events in the Cangjie language. The document details how to use `BasicServicesKit` to publish common events, covering scenario introductions, interface descriptions, and publishing events with or without information. Core content includes the use of the `publish` method, the configuration of `CommonEventPublishData` (such as unordered, ordered, or sticky events), and complete code examples. This document is suitable for Cangjie application developers and aims to help them master basic module imports and event handling mechanisms.

### cj-common-event-subscription/
This directory contains core documentation regarding common event subscription in Cangjie application development. It elaborates on how to dynamically subscribe to common events during Cangjie application runtime, thereby receiving specific event notifications and their parameters. The content covers full-process guidance from scenario introduction and interface description to specific development steps, focusing on the usage of core APIs like `createSubscriber` and `subscribe`.
