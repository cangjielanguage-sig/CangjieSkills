This directory provides comprehensive API reference documentation for the Cangjie Display class, a critical component for modeling screen instances within the WindowManager system. It covers a wide array of hardware attributes, ranging from device identification and physical dimensions to density metrics, refresh rates, and advanced capabilities like color spaces and HDR formats. Furthermore, it includes details on screen rotation, scaled density, display states, and methods for identifying non-usable regions such as notches. This documentation is specifically designed for developers working on window management features who need to query hardware display states and adapt application layouts to specific hardware configurations.
