## Detailed Description

### 使用AVPlayer添加视频外挂字幕/

This directory offers a comprehensive guide for developers looking to implement external subtitle functionality in video playback applications using the `AVPlayer` instance in the Cangjie language. It covers the complete development lifecycle, from setting subtitle resources via file descriptors or URLs to registering and managing subtitle update callbacks. The documentation highlights critical constraints, such as the necessity of setting subtitles prior to playback initiation.

In terms of technical implementation, the guide provides in-depth code examples for key methods. It explains how to use `addSubtitleFromFd` to load subtitles from local file systems using file descriptors, which is a common requirement for offline video players. Simultaneously, it covers `addSubtitleFromUrl` for scenarios where subtitles need to be fetched dynamically from remote servers. The documentation also details the handling of `AVPlayerCallbackType.subtitleUpdate` events, which are essential for synchronizing the UI with the media player's subtitle state.

This resource is ideal for application developers leveraging the MediaKit API to enhance user experience with multilingual or accessible video content. By following the patterns outlined here, developers can ensure their applications support a wide range of subtitle formats and sources, making their video content accessible to a global audience. The guide serves as a critical reference for mastering the nuances of media playback in the Cangjie ecosystem.
