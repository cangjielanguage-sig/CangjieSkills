# ohosmultimediacamera相机管理

本目录是HarmonyOS/OpenHarmony平台下仓颉语言的相机管理模块API参考文档。它涵盖了相机硬件的访问与控制，包括预览、拍照、录像等核心功能，以及闪光灯、对焦、曝光、变焦和防抖等高级配置。文档详细定义了相关的类、枚举和接口，适用于使用仓颉语言开发多媒体相机应用的开发者，旨在帮助其实现完整的相机功能与状态管理。
