This directory provides comprehensive documentation for the generic digest functions within the Cangjie `std.crypto.digest` package. It serves as a critical technical resource for developers aiming to implement cryptographic hash computations across diverse data structures. The content details the API specifications for three overloaded `digest` functions, specifically designed to handle `Array<Byte>`, `InputStream`, and `String` inputs. It thoroughly explains the generic constraints `T <: Digest`, the return type `Array<Byte>`, and highlights the deprecation of the String variant. Additionally, the documentation includes practical examples for custom `Digest` implementations. This directory is suitable for Cangjie developers, security engineers, and system architects who require precise syntax, parameter definitions, and usage scenarios to ensure secure and efficient data handling in their software projects.
