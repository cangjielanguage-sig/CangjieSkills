This directory provides comprehensive API reference documentation for extending the `IntNative` type within the Cangjie programming language. It specifically details the implementation of the `SaturatingOp` interface, which introduces a suite of arithmetic functions designed to handle overflow and underflow safely. Instead of wrapping around, these operations clamp results to the type's maximum or minimum values. This resource is crucial for Cangjie developers looking to implement robust error handling in numerical computations and prevent common integer wrapping bugs.
