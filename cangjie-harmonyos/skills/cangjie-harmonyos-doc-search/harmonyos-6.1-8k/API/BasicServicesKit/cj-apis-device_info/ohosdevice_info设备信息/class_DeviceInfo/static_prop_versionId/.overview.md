# static_prop_versionId

本目录包含Cangjie语言中静态属性 `versionId` 的相关文档，涵盖了API参考说明及代码示例。核心内容包括 `versionId` 的属性定义、数据类型、系统能力要求以及如何通过 `DeviceInfo` API 获取设备详细信息。该文档主要面向需要获取系统版本标识、硬件规格或构建元数据，以便进行日志记录、设备识别或系统配置的开发人员。

## 详细描述

### static_prop_versionId_1.md static_prop_versionId_1.md
本文档是Cangjie语言中静态属性 `versionId` 的API参考文档，旨在提供系统版本标识符的详细说明。文档主要涵盖了属性声明、功能描述、数据类型、读写权限、系统能力及起始版本等关键信息。核心内容指出 `versionId` 是一个只读字符串，由设备类型、制造商、品牌、操作系统全名、产品型号、SDK版本等多个字段拼接而成，用于唯一标识系统版本。该属性属于 `SystemCapability.Startup.SystemInfo` 系统能力，自API版本22起可用，主要面向需要获取设备详细版本信息进行日志记录或设备识别的开发人员。

### static_prop_versionId_2.md static_prop_versionId_2.md
本文档提供了使用 `DeviceInfo` API 检索和记录各种静态设备属性的代码示例。内容涵盖了访问广泛的系统信息，包括操作系统详细信息、硬件规格、构建元数据和分发操作系统属性。主要要点包括 `versionId`、`buildVersion`、`serial` 和 `abiList` 等属性的实践实现，以及使用 try-catch 块处理 `BusinessException` 的错误处理。该参考资料适用于寻求在应用程序中以编程方式访问设备规格和系统配置数据的软件开发人员。
