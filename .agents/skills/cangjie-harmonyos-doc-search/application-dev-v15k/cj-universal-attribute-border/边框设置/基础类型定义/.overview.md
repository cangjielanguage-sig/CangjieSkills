# 基础类型定义

This directory contains API reference documents for fundamental styling classes within the Cangjie ArkUI framework. It focuses on defining visual properties for UI component borders, including colors, widths, and corner radii. Key classes covered include EdgeColors, EdgeWidths, and their localized variants that support Right-to-Left (RTL) layouts. These definitions are essential for creating responsive and internationalized user interfaces. The documentation is suitable for ArkUI developers using the Cangjie language who need to customize the appearance and layout behavior of UI elements.

## Detailed Description

### class_EdgeColors.md class_EdgeColors.md
This API reference document details the EdgeColors class, which defines border colors for UI components in the Cangjie ArkUI framework. The documentation covers the class structure, four public properties (top, bottom, left, right), and the initialization method. Key information includes that all properties are of type Option<ResourceColor>, support read and write operations, and default to Option.None. The constructor uses named parameters to set specific side colors. Intended for UI developers, this class requires SystemCapability.ArkUI.ArkUI.Full and is available starting from version 19. Keywords: EdgeColors, Cangjie, ArkUI, ResourceColor, border styling.

### class_EdgeWidths.md class_EdgeWidths.md
This API reference document details the EdgeWidths class used to configure border widths for popup backplanes in the Cangjie language. The documentation covers the class definition, four public properties (top, right, bottom, left), and the constructor method. Key information includes that all properties are of type Length and are readable and writable. The constructor accepts named parameters for each side, defaulting to 0.vp, though at least one parameter is required upon instantiation. This guide is intended for ArkUI developers using system version 12 or higher who need to customize UI element borders.

### class_LocalizedBorderRadiuses.md class_LocalizedBorderRadiuses.md
This API reference document defines the LocalizedBorderRadiuses class in Cangjie for managing component border corner radii with layout direction awareness. It details four public properties—bottomEnd, bottomStart, topEnd, and topStart—along with the class constructor. Key information includes that all properties are of type Option<Length> and automatically adjust positions based on Right-to-Left (RTL) or Left-to-Right (LTR) display modes. The constructor supports named parameters with default values. This documentation targets ArkUI developers building internationalized interfaces using the Cangjie language.

### class_LocalizedEdgeColors.md class_LocalizedEdgeColors.md
This API reference document details the LocalizedEdgeColors class in Cangjie, used to define border colors for the four sides of a component. It covers the class structure, including properties for bottom, end, start, and top edges, alongside the constructor method for initialization. Key information includes the use of Option<ResourceColor> for all properties, read-write capabilities, and specific support for Right-to-Left (RTL) display modes via the start and end properties. Intended for ArkUI developers using Cangjie, this document assists in styling component borders with layout-aware color definitions.

### class_LocalizedEdgeWidths.md class_LocalizedEdgeWidths.md
This API reference document defines the Cangjie class LocalizedEdgeWidths, designed to specify border widths for UI components with internationalization support. The documentation details the class structure, four public properties (top, bottom, start, end), and the constructor. Key information includes that properties use the Option<Length> type, and the start and end properties dynamically adjust for right-to-left (RTL) text layouts. Instantiation requires passing at least one parameter. This guide is intended for ArkUI developers using Cangjie who need granular control over component borders in multilingual applications.
