This directory contains comprehensive API documentation for extending the Int64 type within the Cangjie programming language to support advanced carrying arithmetic operations. It specifically addresses the implementation of the `CarryingOp` and `CarryingPow` interfaces, which are designed to handle numerical computations where overflow detection is critical. The documentation covers a wide range of functions, including basic arithmetic like addition, subtraction, multiplication, and division, as well as bitwise operations and power calculations. All operations detailed here utilize a wrapping strategy, returning a tuple consisting of a boolean overflow flag and the resulting Int64 value. This resource is primarily suitable for Cangjie developers and systems programmers who require precise control over integer overflow behavior in performance-critical or low-level applications.
