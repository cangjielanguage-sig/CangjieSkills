## Detailed Description

### 类/
This directory contains API reference documentation for core classes within the Cangjie unittest framework. It primarily focuses on configuration management and text formatting utilities. Key components include classes for handling test configuration data (`Configuration`, `ConfigurationKey`) and tools for generating structured, readable console output (`PrettyText`, `PrettyPrinter`). These resources are designed for Cangjie developers who need to programmatically manage test settings or implement custom reporting and output formatting in their unit testing workflows.

The `Configuration` and `ConfigurationKey` classes are central to managing the behavior of test suites, allowing developers to define, retrieve, and modify test parameters dynamically. This decouples the test logic from hardcoded values, increasing flexibility. On the other hand, the `PrettyText` and `PrettyPrinter` classes address the need for clear communication of test results. They provide the necessary tools to format raw data into structured, human-readable text, which is crucial for debugging and reporting. By utilizing these resources, developers can build sophisticated testing utilities that are both configurable and user-friendly. This documentation effectively bridges the gap between raw test execution and polished, professional reporting, making it an essential reference for advanced framework usage.
