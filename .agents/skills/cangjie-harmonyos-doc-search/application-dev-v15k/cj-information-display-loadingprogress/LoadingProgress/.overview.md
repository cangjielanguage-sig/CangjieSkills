# LoadingProgress

This directory contains comprehensive documentation and resources for the LoadingProgress component within the ArkUI framework, specifically designed for HarmonyOS development using the Cangjie programming language. It covers the component's full API reference, including initialization methods, supported attributes, events, and specific property configurations like color and loading states. Additionally, it provides practical code examples ranging from basic static displays to interactive, state-driven implementations. This collection is suitable for software developers and UI engineers seeking to implement, customize, and manage loading indicators effectively in their HarmonyOS applications.

## Detailed Description

### LoadingProgress_4more.md LoadingProgress_4more.md
This document serves as API reference documentation for the LoadingProgress component, which is designed to display loading animations within the ArkUI framework. The content covers the component's description, subcomponents, initialization method, and supported attributes and events. Key information includes that the animation stops automatically when the component is invisible based on specific visibility thresholds. It supports the init() function starting from version 12 and accepts all common attributes except text styles, though developers are advised to set reasonable dimensions to ensure expected visual results. This guide targets software developers using the ArkUI framework who need to implement loading indicators in their applications.

### 示例代码.md 示例代码.md
This document provides practical code examples demonstrating the implementation and usage of the LoadingProgress component in the Cangjie programming language for HarmonyOS development. It covers two distinct examples: a basic static display and an interactive state-driven implementation. The first example illustrates simple styling and layout within a Column, while the second demonstrates state management using @State decorators to toggle the loading status and update UI text dynamically within a Button component. This guide targets HarmonyOS developers using the Cangjie language who need to implement loading indicators in their user interfaces.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring properties of a UI component, specifically a loading progress bar, within the ArkUI framework using the Cangjie language. It details four main functions: color, enableLoading, and two overloads of foregroundColor. Key information includes the specific parameters for setting colors and a critical distinction that enableLoading hides only the animation content while retaining component layout space, unlike Visibility.Hidden. The documentation specifies system capabilities and starting versions for each method. This reference is intended for developers building ArkUI interfaces who need to customize component appearance and control loading states programmatically.
