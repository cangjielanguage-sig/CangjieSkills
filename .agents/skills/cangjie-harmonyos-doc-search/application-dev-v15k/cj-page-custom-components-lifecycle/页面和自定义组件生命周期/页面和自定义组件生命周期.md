# 页面和自定义组件生命周期

在开始之前，需要先明确自定义组件和页面的关系：

- 自定义组件：@Component修饰的UI单元，可以组合多个系统组件实现UI的复用，可以调用组件的生命周期。

- 页面：即应用的UI页面。可以由一个或者多个自定义组件组成，@Entry修饰的自定义组件为页面的入口组件，即页面的根节点，一个页面有且仅能有一个@Entry。只有被@Entry修饰的组件才可以调用页面的生命周期。

页面生命周期，即被@Entry修饰的组件生命周期，提供以下生命周期接口：

- [onPageShow](../../../API_Reference/source_zh_cn/arkui-cj/cj-custom-component-lifecycle.md#func-onpageshow)：页面每次显示时触发一次，包括路由过程、应用进入前台等场景。

- [onPageHide](../../../API_Reference/source_zh_cn/arkui-cj/cj-custom-component-lifecycle.md#func-onpagehide)：页面每次隐藏时触发一次，包括路由过程、应用进入后台等场景。

- [onBackPress](../../../API_Reference/source_zh_cn/arkui-cj/cj-custom-component-lifecycle.md#func-onbackpress)：当用户点击返回按钮时触发。

组件生命周期，即一般用@Component修饰的自定义组件的生命周期，提供以下生命周期接口：

- [aboutToAppear](../../../API_Reference/source_zh_cn/arkui-cj/cj-custom-component-lifecycle.md#func-abouttoappear)：组件即将出现时回调该接口，具体时机为在创建自定义组件的新实例后，在执行其build()函数之前执行。

- [onDidBuild](../../../API_Reference/source_zh_cn/arkui-cj/cj-custom-component-lifecycle.md#func-ondidbuild)：组件build()函数执行完成之后回调该接口，开发者可以在这个阶段进行埋点数据上报等不影响实际UI的功能。不建议在onDidBuild函数中更改状态变量、使用animateTo等功能，这可能会导致不稳定的UI表现。

- [aboutToDisappear](../../../API_Reference/source_zh_cn/arkui-cj/cj-custom-component-lifecycle.md#func-abouttodisappear)：aboutToDisappear函数在自定义组件析构销毁之前执行。不允许在aboutToDisappear函数中改变状态变量，特别是@Link变量的修改可能会导致应用程序行为不稳定。
