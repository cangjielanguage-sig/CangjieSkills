# class_SubProcess

This directory provides a comprehensive overview of the `SubProcess` class and related utilities within the Cangjie language, specifically designed for managing child process operations and standard stream interactions. It serves as a critical resource for developers looking to implement robust process control, covering essential topics such as accessing standard input, output, and error streams via updated pipe properties. The documentation also details synchronization methods, including the `wait` function for retrieving exit statuses and the `waitOutput` function for capturing results. By addressing deprecations and limitations regarding stream sizes, this guide ensures developers can effectively handle inter-process communication and avoid common pitfalls like deadlocks. This content is ideal for Cangjie developers working on system-level programming who require a deep understanding of process lifecycle management and I/O handling.

## Detailed Description

### class_SubProcess_8more.md class_SubProcess_8more.md
This API reference document details the SubProcess class in the Cangjie language, designed to manage child process operations and standard stream interactions. The documentation outlines properties for accessing standard input, output, and error streams, specifically noting the deprecation of older properties in favor of stdInPipe, stdOutPipe, and stdErrPipe. It also describes the wait function, which blocks execution to retrieve the child process's exit status or signal number, supporting optional timeout parameters to handle potential deadlocks. Targeted at Cangjie developers, this reference requires understanding of I/O streams and process synchronization.

### func_waitOutput.md func_waitOutput.md
This API reference document details the waitOutput function in the Cangjie process package, which blocks execution to wait for a child process and retrieve its results. The content covers the function signature, functionality description, return value specifications, and potential exceptions. Key takeaways include that the function returns a tuple of the exit status, standard output, and standard error as byte arrays. Crucially, it warns that this method is unsuitable for large output streams and recommends using SubProcess stream attributes instead. The target audience is Cangjie developers managing subprocesses who need a simple way to capture output, provided they understand the limitations regarding stream size.
