# 接口

This directory serves as a comprehensive repository for API documentation regarding Cangjie language interfaces, specifically focusing on endianness handling and byte order manipulation. It encompasses detailed references for big-endian, little-endian, and byte-swapping operations across a wide spectrum of data types, including signed and unsigned integers, floating-point numbers, and boolean values. These interfaces are crucial for tasks involving binary data serialization, deserialization, and ensuring cross-platform compatibility. This documentation is primarily intended for Cangjie developers, system programmers, and engineers engaged in low-level data processing, network protocol implementation, or file I/O operations where precise control over byte order is mandatory.

## Quick Navigation

What do you want to do?

- Serialize or deserialize data using **Big-Endian** byte order? → `interface_BigEndianOrderT/`
- Serialize or deserialize data using **Little-Endian** byte order? → `interface_LittleEndianOrderT/`
- **Reverse** or swap the byte order of existing data? → `interface_SwapEndianOrderT/`

## Detailed Description

### interface_BigEndianOrderT/
This directory contains API documentation for the Cangjie language's `BigEndianOrder` interface and its type extensions. It covers the implementation of big-endian byte serialization and deserialization for various numeric and boolean types, including integers (Int8 to Int64), unsigned integers (UInt8 to UInt64), floating-point numbers (Float16, Float32, Float64), and Bool. The core functionality involves `readBigEndian` and `writeBigEndian` methods to convert between values and byte arrays. This resource is suitable for Cangjie developers working on low-level binary data manipulation, network protocols, or file I/O requiring specific endianness handling.

### interface_LittleEndianOrderT/
This directory contains API documentation for the Cangjie language's `LittleEndianOrder` interface and its implementations across various primitive data types. It covers extensions for signed and unsigned integers (Int8 to Int64, UInt8 to UInt64), floating-point numbers (Float16, Float32, Float64), and Boolean values. The documentation details methods for serializing data to and deserializing data from little-endian byte sequences using `Array<UInt8>` buffers. Key topics include binary data manipulation, low-level serialization, and endianness handling. This resource is suitable for Cangjie developers working on system programming, file I/O, or network protocols requiring precise byte order control.

### interface_SwapEndianOrderT/
This directory contains comprehensive API reference documentation for the `SwapEndianOrder` interface within the Cangjie programming language. It focuses on the mechanisms required to reverse the byte order (endianness) of various integer types, a critical operation for low-level data manipulation and network programming tasks. The documentation covers the generic interface definition alongside specific implementations for a wide range of signed and unsigned integers, including Int8, Int16, Int32, Int64, UInt8, UInt16, UInt32, and UInt64. It is specifically suitable for Cangjie developers who need to ensure data compatibility across different system architectures, providing detailed function signatures, return values, and practical code examples for efficient endianness conversion.
