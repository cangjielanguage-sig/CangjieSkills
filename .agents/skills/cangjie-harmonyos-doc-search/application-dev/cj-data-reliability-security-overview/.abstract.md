This directory acts as the central repository for documentation regarding data reliability and security features within the OpenHarmony operating system. It is designed to assist developers in understanding and implementing mechanisms that prevent data loss and protect sensitive information. The content extensively covers functional scenarios, basic concepts, operational mechanisms, and specific constraints associated with database backup, restore, encryption, and data classification. Key technical topics include full file backup capabilities that operate without requiring a database shutdown, automatic key management utilizing the HUKS (Hardware Unique Key Storage) system, and granular access controls for E-class encrypted databases. Furthermore, the documentation addresses important operational limits, such as the restriction of a maximum of five backups for key-value databases and the requirement for annual key rotation. This resource is specifically designed for application developers who need to implement robust data protection and recovery strategies to ensure high data integrity and security across diverse devices.
