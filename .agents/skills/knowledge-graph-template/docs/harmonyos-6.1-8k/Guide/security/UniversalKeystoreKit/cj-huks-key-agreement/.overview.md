# cj-huks-key-agreement

This directory provides a technical overview and implementation guide for key agreement protocols within the HarmonyOS and OpenHarmony ecosystems, utilizing the Cangjie (cj) language. It focuses on the HarmonyOS Universal KeyStore (HUKS) framework, demonstrating how to securely establish shared secrets between parties. The core content encompasses the full lifecycle of key agreement, starting from the generation of asymmetric key pairs and the export of public keys to the management of agreement sessions and the final derivation of symmetric keys. Specific attention is given to widely used algorithms such as X25519 and Diffie-Hellman (DH). This resource is essential for developers aiming to build secure communication applications, offering detailed parameter configuration rules and practical code examples to ensure the correct and efficient application of cryptographic standards in their projects.

## Detailed Description

### 密钥协商/
This directory primarily introduces the technical solution for implementing key agreement based on the Universal KeyStore (HUKS) framework on HarmonyOS and OpenHarmony platforms. The content covers the complete implementation flow for algorithms such as X25519 and Diffie-Hellman (DH), including asymmetric key generation, public key export, agreement session management, and key derivation. The documentation also involves code examples in the Cangjie language and parameter configuration rules. It is suitable for developers who need to build secure communication applications and master basic HUKS operations, aiming to guide them in implementing secure and efficient key exchange protocols.
