# 拉起快递类应用startAbilityByType

This directory provides comprehensive technical documentation for implementing inter-app communication specifically for express delivery services within the HarmonyOS ecosystem. It focuses on the `startAbilityByType` API, detailing how a host application can invoke an express delivery extension panel and how a target application should be configured to receive and process these requests. The documentation covers essential technical aspects such as JSON parameter construction, URI scheme configuration, and the Cangjie programming language implementation. It is designed for HarmonyOS developers who possess a working knowledge of AbilityKit and UIAbility contexts and are looking to integrate seamless express tracking query features into their applications. This guide ensures developers understand both the client-side invocation and the server-side handling required for a smooth user experience. By following these steps, developers can effectively bridge the gap between different applications to provide unified logistics services.

This technical tutorial targets HarmonyOS developers using Cangjie who need to implement deep linking or inter-app communication for specific features.
