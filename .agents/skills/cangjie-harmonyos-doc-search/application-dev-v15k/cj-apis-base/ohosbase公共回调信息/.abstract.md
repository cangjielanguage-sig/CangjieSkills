This directory provides essential API reference documentation for the `ohos.base` module, specifically tailored for the Cangjie programming language. It serves as a comprehensive technical guide for implementing common callback mechanisms, error handling, and logging within HarmonyOS applications. The content covers a wide range of abstract callback classes—such as CallbackObject and its variants—that support different argument counts and return types, enabling flexible event handling and asynchronous programming patterns. Additionally, it defines critical infrastructure for system logging (AppLog, BaseLog) and exception management (AsyncError, BusinessException). This documentation is intended for software developers and system architects utilizing the SystemCapability.Base framework to build robust, standardized applications requiring precise control over asynchronous flows and error reporting.
