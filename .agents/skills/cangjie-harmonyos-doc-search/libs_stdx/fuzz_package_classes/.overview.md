# fuzz_package_classes

The `fuzz_package_classes` directory functions as the central repository for API reference documentation regarding the core classes that constitute the Cangjie fuzzing framework. It is designed to offer an in-depth look at the structural components that are essential for the creation, configuration, and execution of automated fuzzing tests. The directory specifically highlights the `FuzzerBuilder`, which is the standard tool for instance construction, and the `Fuzzer` class, which is central to runtime management. Additionally, it provides detailed information on specialized data providers such as `FuzzDataProvider` and `DebugDataProvider`, which are instrumental in parsing raw byte streams and converting them into structured data suitable for testing. This documentation is an invaluable resource for software developers, QA engineers, and security professionals who demand precise control over data generation, target function definition, and the nuanced behavior of fuzzing operations within the Cangjie programming language ecosystem. By utilizing these references, users can effectively build robust testing environments that ensure software reliability and security.
