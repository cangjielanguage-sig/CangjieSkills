This directory contains essential API documentation for the Cangjie language, focusing on the implementation of the `WrappingOp` interface for the `UIntNative` type. It provides a detailed overview of a wide array of arithmetic and bitwise operations, such as addition, subtraction, multiplication, division, modulo, negation, increment, decrement, and bit shifting. The core theme of this documentation is the management of numeric overflow through high-bit truncation strategies. By ensuring that results wrap around instead of raising errors, these functions offer predictable behavior critical for system-level programming. This collection is specifically designed for Cangjie developers who need granular control over integer operations and require reliable overflow handling mechanisms in their applications.
