# cj-crypto-encrypt-decrypt-by-segment

This directory serves as a comprehensive technical resource focused on segmented encryption and decryption strategies, specifically designed to significantly enhance efficiency when processing large data volumes. It thoroughly distinguishes between symmetric and asymmetric cryptographic approaches, providing developers with the necessary knowledge to handle data chunks effectively and securely. Key topics include the utilization of the update method for symmetric encryption using AES and SM4, as well as the manual data splitting techniques required for asymmetric encryption involving RSA and SM2. The guide also clarifies the independence of segment size from various encryption modes. This resource is highly suitable for developers and security professionals working within the CryptoArchitectureKit environment who aim to optimize cryptographic performance and manage resource-intensive operations securely and effectively within their applications.
