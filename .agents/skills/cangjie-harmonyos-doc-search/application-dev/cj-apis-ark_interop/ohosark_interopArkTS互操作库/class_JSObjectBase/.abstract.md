This directory contains API reference documentation for the `JSObjectBase` class and related functions within the Cangjie and ArkTS interoperability framework. It covers essential operations for manipulating JavaScript objects, including binding Cangjie objects, invoking methods, and managing properties via getters, setters, and subscripts. Key topics include `JSValue`, `JSKeyable`, and `BusinessException` error handling. This documentation is suitable for developers working on cross-language applications who need to safely reference and interact with ArkTS objects from Cangjie code.
