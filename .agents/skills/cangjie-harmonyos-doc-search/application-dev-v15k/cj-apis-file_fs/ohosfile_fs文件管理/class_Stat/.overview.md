# class_Stat

This directory contains comprehensive API reference documentation for the Cangjie Stat class and its associated file type checking functions within the CoreFileKit. It covers the encapsulation of file metadata, including access times, ownership, inode numbers, and permission modes. Additionally, it details specific functions for identifying various file types such as block devices, character devices, directories, sockets, and symbolic links. This documentation is essential for Cangjie developers working on file I/O operations, system-level file management, and permission handling, providing the necessary tools to validate file types and access detailed file status information efficiently.

### class_Stat_10more.md class_Stat_10more.md
This document provides API reference documentation for the Cangjie Stat class, which encapsulates file metadata and status information. It details read-only properties such as access, modification, and change times, file size, ownership IDs, and inode numbers. A key section explains the mode property, decoding octal permission bits for user, group, and others. The document also notes that instances must be constructed via FileFs.stat() and introduces a location property for distinguishing local and cloud files. Targeting Cangjie developers, this reference requires understanding of file I/O operations and permission systems.

The content covers methods for identifying block devices, character devices, directories, named pipes (FIFOs), and regular files. Each function returns a Boolean value and is accessed via the FileFs.stat interface, with definitions explaining technical distinctions like cached block access versus uncached character access. Targeted at Cangjie developers, this documentation aids in implementing file type validation and system-level file management logic.

### func_isSocket_2more.md func_isSocket_2more.md

The main sections cover the isSocket() and isSymbolicLink() functions, outlining their syntax, functionality, system capabilities, and return values.
