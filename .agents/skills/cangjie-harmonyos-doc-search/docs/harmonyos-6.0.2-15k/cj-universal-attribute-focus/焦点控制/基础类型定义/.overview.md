# 基础类型定义

This directory provides essential API references for the Cangjie language within the ArkUI framework, focusing on fundamental UI types. It encompasses definitions for focus management (FocusControl, FocusPriority, FocusBoxStyle) and color manipulation (ColorMetrics). These resources enable developers to implement precise focus navigation logic, customize focus indicator styles, and handle complex color operations. Designed for Cangjie and ArkUI developers, this documentation supports the creation of interactive and visually refined HarmonyOS applications.

## Detailed Description

### class_FocusBoxStyle.md class_FocusBoxStyle.md
This API reference document details the FocusBoxStyle class used to define the visual appearance of system focus boxes in Cangjie applications. It covers the class constructor and three public properties: margin, strokeColor, and strokeWidth. Key information includes that the margin property sets the distance from the component edge, supporting positive or negative values but no percentages, while strokeWidth sets the width, restricting negative values and percentages. This guide is intended for Cangjie developers working with ArkUI system capabilities to customize focus indicators. Keywords: Cangjie, ArkUI, FocusBoxStyle, API, UI styling.

### class_FocusControl.md class_FocusControl.md
This document serves as API reference documentation for the Cangjie language's FocusControl class within the ArkUI framework. It details the class definition and specifically documents the static method requestFocus, which enables programmatic focus management. Key information includes the method's signature, which accepts a string parameter representing a component's key or ID, and returns a Boolean indicating success based on the component's existence and focusability. Targeted at developers building ArkUI applications, this reference requires knowledge of Cangjie syntax and UI component properties. Keywords: FocusControl, requestFocus, Cangjie, ArkUI, API reference, focus management.

### enum_FocusPriority.md enum_FocusPriority.md
This document serves as an API reference for the Cangjie programming language, specifically defining the FocusPriority enumeration used to manage component focus hierarchy within the ArkUI framework. It details three specific enum values: AUTO, PRIOR, and PREVIOUS, each accompanied by descriptions of their functionality and system capabilities. The key takeaway is the established priority hierarchy: AUTO is the default, PRIOR offers higher priority within a container, and PREVIOUS holds the highest priority by restoring focus to the last active node when a container regains focus. This technical reference is intended for UI developers working with Cangjie and ArkUI who need to implement custom focus navigation logic. Keywords: Cangjie, FocusPriority, ArkUI, enum, focus management, API reference.

### class_ColorMetrics/
This directory contains the API reference documentation for the `ColorMetrics` class within the Cangjie language, specifically designed for the ArkUI framework. It serves as a comprehensive guide for developers seeking to implement structured color manipulation in their applications. The documentation covers the definition of read-only properties for individual color components—red, green, blue, and alpha—as well as the resulting RGBA string. It details static factory methods for instantiating the class using HEX values, RGBA components, or resource color enums. Additionally, it explains advanced functionalities such as color overlay blending and conversion to 32-bit unsigned integers. This resource is intended for ArkUI developers working on HarmonyOS applications who need precise control over color resources and requires SystemCapability.ArkUI.ArkUI.Full, available starting from version 19.
