# using_cangjie

本目录旨在指导开发者如何在 ArkTS 应用开发中引入并使用仓颉（Cangjie）语言，重点讲解跨语言互操作的实现方法。文档详细阐述了仓颉模块的定义规范，并提供了在 DevEco Studio 开发环境中添加仓颉页面及模块的实操步骤。通过混合编程模式，开发者可以充分利用仓颉语言的高性能特性来优化应用表现。核心内容涉及 ArkTS 与仓颉的集成、模块加载机制以及性能提升策略。该指南特别适合使用 DevEco Studio 的 ArkTS 开发者阅读，帮助他们在现有项目中无缝融合仓颉语言，以应对对性能有较高要求的开发场景。
