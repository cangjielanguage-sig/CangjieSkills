# 组件事件

本目录包含ArkUI框架中Cangjie语言关于组件滚动事件的API参考文档。主要涵盖了滚动交互过程中的各类回调机制，包括滚动状态监听（如开始、停止、到达边缘）以及滚动前的拦截与处理逻辑。核心关键词包括ArkUI、Cangjie、滚动事件、onDidScroll、onWillScroll、回调函数。这些文档适合使用Cangjie语言进行ArkUI应用开发，需要精细控制滚动组件交互行为、处理边缘效果或实现自定义滚动逻辑的开发人员阅读。

## 详细描述

### func_onDidScrollO_5more_6518ae66.md
本文档是ArkUI框架中Cangjie语言的滚动事件回调API参考文档。主要涵盖了五个核心函数：onDidScroll（滑动监听）、onReachEnd（到达末尾）、onReachStart（到达起始）、onScrollStart（滚动开始）和onScrollStop（滚动停止）。关键信息包括这些函数如何监听滚动偏移量、状态变化及特定位置触发条件（如弹簧效果下的多次触发），它们均返回组件实例T，起始版本为22。文档面向使用ArkUI和Cangjie语言开发滚动组件交互的开发者，旨在提供处理滚动行为和边缘效果的详细接口说明。

### func_onWillScroll_2more_bb2d6433.md
本文档是Cangjie语言ArkUI框架的API参考文档，详细说明了滚动组件的`onWillScroll`事件回调函数。文档涵盖两个重载版本：一个返回`ScrollResult`以允许修改滚动偏移量，另一个返回`Unit`仅用于监听。核心内容包括回调参数（偏移量、状态、来源）、系统能力要求及版本信息。关键点指出该回调在滚动前触发，但在调用`scrollEdge`或无动画的`scrollToIndex`时不触发。该文档面向需要精细控制或监听滚动行为的UI开发人员。
