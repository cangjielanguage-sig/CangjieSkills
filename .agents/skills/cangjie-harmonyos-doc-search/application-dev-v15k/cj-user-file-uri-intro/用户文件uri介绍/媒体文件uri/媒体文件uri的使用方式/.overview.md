# 媒体文件uri的使用方式

This directory serves as a comprehensive resource for understanding the usage of media file URIs in HarmonyOS development. It addresses the critical aspects of accessing media resources in normal-level applications, contrasting the use of specific permissions like `READ_IMAGEVIDEO` with permission-free temporary authorization via `PhotoViewPicker`. The documentation provides in-depth insights into accessible metadata fields—such as URI, size, and dimensions—and offers practical implementation examples in both Cangjie and ArkTS. These examples cover image selection, querying the photo library using `DataSharePredicates`, and generating thumbnails. This collection is essential for HarmonyOS developers aiming to build media-rich applications that adhere to system privacy and permission protocols.

## Detailed Description

### 媒体文件uri的使用方式_1.md 媒体文件uri的使用方式_1.md
This technical guide explains how normal-level applications utilize media file URIs, detailing methods for accessing media resources with and without specific permissions. It covers using the photoAccessHelper module with the READ_IMAGEVIDEO permission and an alternative temporary authorization method via PhotoViewPicker. Key takeaways include a list of specific PhotoKeys accessible through temporary authorization, such as URI, size, dimensions, and timestamps, alongside a Cangjie code example for selecting images. Intended for HarmonyOS developers, this document assists in implementing media selection and access features while managing permission requirements.

### 媒体文件uri的使用方式_2.md 媒体文件uri的使用方式_2.md
This document provides a code example demonstrating how to retrieve detailed media asset information using a specific URI in HarmonyOS development. The primary focus is the uriGetAssets function, which utilizes PhotoAccessHelper and DataSharePredicates to query the photo library. It illustrates configuring fetch options to obtain metadata such as width, height, and title, and subsequently extracting the first PhotoAsset object to generate a thumbnail. Additionally, it includes a helper extension for converting MemberType values to strings. This tutorial snippet is designed for developers working with ArkTS who need to process and display media files selected via a URI.
