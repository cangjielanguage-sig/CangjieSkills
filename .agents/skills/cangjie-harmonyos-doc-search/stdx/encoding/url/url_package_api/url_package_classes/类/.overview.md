# 类

本目录包含仓颉语言中用于 Web 和 URL 处理的核心类 API 参考文档。主要涵盖了用于处理 URL 凭证的 `UserInfo` 类、管理 HTTP 表单数据与查询参数的 `Form` 类，以及用于解析和操作统一资源定位符的 `URL` 类。核心概念包括遵循 RFC 3986 协议、百分号编码机制及安全数据处理。该文档适合需要进行网络编程、构建 Web 服务或处理 URL 结构的后端开发者查阅。

## 快速导航

## 详细描述

### class_UserInfo.md class_UserInfo.md

本文档是 Cangjie 语言中 UserInfo 类的 API 参考文档，用于表示 URL 中的用户名和密码信息。文档详细列出了类的四种构造函数（支持不同参数组合）以及获取用户名、密码和字符串转换的方法。核心要点包括使用 Option<String> 类型处理可选密码，并引用 RFC 3986 警告不要在 URL 中明文存储敏感信息。该文档面向需要处理 URL 组件的开发者，提供了完整的接口定义和安全指导。

### class_Form/

本目录包含仓颉语言中 `Form` 类及相关编码函数的 API 参考文档，专注于 HTTP 请求表单数据与 URL 查询参数的高效处理。核心内容涵盖键值对形式的存储管理、支持单键多值的数据结构、URL 查询字符串的解析与构建，以及遵循 RFC 3986 协议的百分号编码机制。文档详细介绍了构造函数、数据增删改查（CRUD）方法、异常处理及返回值类型（如 `Option` 和 `ArrayList`）。该文档适合需要处理 Web 表单提交、管理 URL 参数或进行 HTTP 请求数据编码的后端开发者阅读。

### class_URL/

本目录包含仓颉语言中 `URL` 类的 API 参考文档，专注于统一资源定位符（URL）的解析、处理与操作。内容涵盖了 URL 类的基础定义、构造函数约束、属性获取（如协议、主机、路径、查询等）、路径合并、解析逻辑及字符串转换等核心功能。文档详细说明了遵循 RFC 3986 协议的解析规则、自动解码机制以及组件替换方法，并包含关于明文凭证的安全警告。适合需要在仓颉应用中进行网络编程、URL 结构分析或字符串序列化的开发者查阅。
