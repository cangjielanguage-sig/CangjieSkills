# 音频录制流管理

This directory provides comprehensive technical documentation for managing and monitoring audio recording streams within software applications. It focuses on the implementation of stream monitoring using APIs such as AudioStreamManager and AudioCapturer, specifically within the context of the Cangjie language and AudioKit framework. Key topics include tracking stream states, handling device change events, registering callbacks for real-time updates, and managing necessary permissions like Bluetooth access. The content is designed for application developers who require detailed guidance on implementing robust audio recording features, querying system-wide stream information, and responding to dynamic state changes in the audio subsystem. It serves as a practical resource for ensuring audio stability and responsiveness in complex application environments, covering both local application streams and global system audio management.

## Detailed Description

### 开发步骤及注意事项.md 开发步骤及注意事项.md
This document provides a step-by-step tutorial for managing audio stream monitoring using the AudioStreamManager API in the Cangjie language. It covers creating an instance, registering and unregistering callbacks for capturer change events, and retrieving current audio capturer information. The guide includes Cangjie code examples for implementing callbacks and highlights the necessity of declaring the ohos.permission.USE_BLUETOOTH permission to access full device details like names and addresses. It targets audio application developers who need to track audio recording stream states and device changes.

### 音频录制流管理_3more.md 音频录制流管理_3more.md
This technical guide instructs developers on managing and monitoring audio recording stream states within applications. It covers monitoring specific application streams via AudioCapturer and managing all system recording streams using AudioStreamManager. Key information includes methods to check the state property or register stateChange callbacks for individual streams. For global monitoring, the guide explains using getStreamManager(), on() for event listening, and getCurrentAudioCapturerInfoArray() for querying stream details like UID and status. Intended for application developers using the AudioKit API, specifically those implementing audio recording features who need to handle state changes and notifications.
