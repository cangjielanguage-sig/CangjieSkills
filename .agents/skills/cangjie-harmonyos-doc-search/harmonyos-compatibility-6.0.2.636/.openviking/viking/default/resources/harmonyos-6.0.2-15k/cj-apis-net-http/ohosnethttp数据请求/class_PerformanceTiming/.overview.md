# class_PerformanceTiming

This directory provides comprehensive documentation for the `PerformanceTiming` class, a specialized tool within the Cangjie language ecosystem designed for the NetworkKit framework. It focuses on the precise capture and analysis of HTTP request performance metrics, enabling developers to gain deep insights into network behavior. The content covers a wide range of critical network stages, including DNS resolution, TCP connection establishment, TLS handshake execution, redirect management, and response processing. By utilizing read-only properties of type Float64, the class allows for accurate measurement of time durations starting from the initial request. This documentation is essential for software engineers and system architects who need to diagnose network latency issues, optimize application throughput, and ensure robust communication capabilities. It also details the class inheritance from `ToString` and the specific system capabilities required for deployment. Implementation of this class requires the SystemCapability.Communication.NetStack capability to be present in the system environment.

### class_PerformanceTiming_12more.md class_PerformanceTiming_12more.md
This document serves as the definitive API reference for the `PerformanceTiming` class. It is designed to assist developers in capturing granular performance metrics related to HTTP requests, with all timing values expressed in milliseconds. The text provides a detailed list of read-only properties that correspond to distinct phases of the network communication process. These phases include the time required for DNS resolution, the duration of TCP and TLS connections, any time spent on redirects, and the final response processing time.

In addition to the timing properties, the documentation explains the `toString` method, which allows for the conversion of the timing object into a readable string format. It specifies that all metrics are stored as Float64 values to ensure high precision, measuring the time elapsed from the very start of the request. The class is defined as inheriting from `ToString`, and the document explicitly states that the `SystemCapability.Communication.NetStack` capability is a mandatory requirement for using this class. This resource is specifically targeted at developers utilizing the Cangjie language and NetworkKit to effectively monitor and analyze the efficiency of their network requests. By leveraging these metrics, developers can pinpoint inefficiencies in the network stack and improve the overall user experience of their applications.
