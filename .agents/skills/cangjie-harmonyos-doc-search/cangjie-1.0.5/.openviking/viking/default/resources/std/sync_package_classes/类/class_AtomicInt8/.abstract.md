This directory contains API reference documentation for the `AtomicInt8` class in the Cangjie programming language, focusing on thread-safe operations for 8-bit integers. It covers essential atomic functionalities such as constructors, compare-and-swap (CAS) mechanisms, arithmetic operations like addition and subtraction, bitwise manipulations, and swap operations. The documentation highlights the distinction between current implementations using default memory ordering and deprecated versions requiring explicit memory order parameters. This resource is suitable for developers implementing concurrent systems who require precise control over low-level integer synchronization and memory consistency.
