# 被拉起应用开发指导

This directory provides comprehensive guidance for HarmonyOS developers on implementing App Linking and deep linking functionalities. It covers the entire workflow from enabling services in the AppGallery Connect (AGC) console and configuring domain verification in DevEco Studio to handling incoming links and parsing parameters within the application code. Key topics include AGC configuration, `module.json5` setup, domain verification, and URI handling using the Cangjie language. This guide is suitable for developers looking to enable seamless transitions from web URLs to native app content.

## Detailed Description

### 在AGC控制台开通App_Linking服务_3more.md
This tutorial guides HarmonyOS developers through enabling and configuring the App Linking service within the AppGallery Connect (AGC) console to facilitate deep linking. The document covers three main steps: enabling the service in AGC, creating and hosting a verification JSON file on the developer's server, and associating the specific domain in the AGC console. Key information includes placing the applinking.json file in the .well-known directory for security validation and ensuring the domain configuration matches the project's APP ID. The system performs an intersection check to verify app ownership, refreshing every 24 hours. This guide targets HarmonyOS application developers who need to link web URLs directly to their native app content.

### 在DevEco_Studio中配置关联的网址域名.md
This guide explains how to configure associated domain names in DevEco Studio to enable domain verification and App Linking for HarmonyOS applications. It details the specific requirements for the module.json5 file, focusing on the skills configuration within abilities. Key information includes the necessity of including entity.system.browsable in entities, ohos.want.action.viewData in actions, and setting domainVerify to true. The uris section requires an https scheme and the target host. Crucially, a separate skill object must be created for link handling to avoid conflicts with the default entry skill. This technical tutorial is intended for HarmonyOS developers configuring deep links or App Linking capabilities.

### 处理传入的链接_2more.md
This technical guide instructs developers on handling incoming links in HarmonyOS applications using the Cangjie language. It details implementing logic within the UIAbility lifecycle callbacks, specifically onCreate or onNewWant, to parse URIs and extract query parameters from the Want object. Additionally, the document outlines a verification process requiring manual application signing, a critical prerequisite for App Linking, followed by testing the integration. The content targets developers implementing deep link navigation and parameter-based routing within their apps.
