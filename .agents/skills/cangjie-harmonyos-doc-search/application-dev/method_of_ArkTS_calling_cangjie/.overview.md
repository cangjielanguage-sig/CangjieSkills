# method_of_ArkTS_calling_cangjie

This directory serves as a comprehensive resource for developers working within the HarmonyOS ecosystem who need to facilitate communication between ArkTS and Cangjie programming languages. It focuses specifically on the mechanisms required to allow ArkTS applications to invoke Cangjie code, a critical capability for leveraging the performance and features of Cangjie within ArkTS-based user interfaces or logic. The content covers the complete development lifecycle, divided into Cangjie-side implementation and ArkTS-side usage. It highlights two distinct technical approaches: the use of declarative interop macros for static, type-safe declarations ideal for those new to the framework, and the interop library for dynamic type interfaces suited for advanced scenarios involving JavaScript and TypeScript interoperability. This guide is essential for software engineers and system architects aiming to build robust, cross-language applications that maximize the strengths of both ArkTS and Cangjie.
