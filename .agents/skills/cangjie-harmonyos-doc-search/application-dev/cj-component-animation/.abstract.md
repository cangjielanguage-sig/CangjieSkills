This directory contains a technical guide dedicated to the utilization and customization of component animations within the ArkUI framework, specifically implemented using the Cangjie programming language. It provides a detailed explanation of how to use default component animations to generate built-in visual effects for common user interactions, such as button clicks and list swipes. These default animations are highlighted as a key feature for enhancing user feedback and significantly reducing the workload required to implement standard UI behaviors. Furthermore, the guide covers the creation of custom animations for sub-items located within container components like Scroll. It instructs developers on how to achieve these custom effects by modifying affine properties during specific events, such as scroll events or gestures, through the application of attribute and transition animations. This tutorial is specifically targeted at ArkUI developers who are looking to enhance the interactivity and visual polish of their user interfaces.
