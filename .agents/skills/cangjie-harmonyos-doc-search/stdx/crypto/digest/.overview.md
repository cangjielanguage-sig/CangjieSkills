# digest

This directory serves as a comprehensive documentation and resource hub for the `stdx.crypto.digest` package within the Cangjie programming language ecosystem. It covers the implementation and usage of various cryptographic message digest algorithms, including industry standards like MD5, SHA series, and HMAC, as well as the SM3 national standard. The content is designed to guide developers through the theoretical aspects of these algorithms, the practical setup of required dependencies like OpenSSL 3, and their application in real-world scenarios. This resource is suitable for Cangjie developers, security engineers, and system integrators looking to implement secure hashing and data integrity verification in their applications.

## Detailed Description

### crypto_digest_package_overview

This directory provides a comprehensive technical overview of the `stdx.crypto.digest` package, focusing on common message digest algorithms such as MD5, the SHA series, HMAC, and the SM3 national standard. The documentation details the functional characteristics of these cryptographic algorithms and provides in-depth instructions for installing the OpenSSL 3 dependency library. It covers environment variable configuration, such as setting `LD_LIBRARY_PATH` and `PATH`, across Linux, Windows, and macOS. Additionally, it offers a complete API list, definitions for the `HashType` structure, and explanations for `CryptoException` handling, serving as a foundational guide for configuration and understanding.

### digest_package_api

The `digest_package_api` directory provides a comprehensive API reference for the digest package within the Cangjie programming language. It covers essential components for cryptographic operations, including a wide range of hashing and authentication algorithms. This section is structured to help developers quickly locate technical specifications, function parameters, and return types, ensuring accurate utilization of the library's cryptographic capabilities in software development.

### digest_samples

The `digest_samples` directory is a specialized educational repository tailored for developers working with the Cangjie programming language, focusing heavily on the critical domain of cryptographic digest algorithms. This directory acts as a vital resource for learning by example, offering practical code samples that demonstrate how to implement the various hashing and authentication features provided by the digest package effectively.
