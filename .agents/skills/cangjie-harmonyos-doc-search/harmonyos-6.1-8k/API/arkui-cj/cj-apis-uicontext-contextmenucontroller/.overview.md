# cj-apis-uicontext-contextmenucontroller

本目录提供了Cangjie语言中关于`ContextMenuController`的API参考文档，主要聚焦于ArkUI框架下上下文菜单的控制逻辑。文档详细介绍了该类的定义、模块导入方式以及核心`close()`方法的具体用法，帮助开发者实现菜单的动态关闭。内容涵盖了API的Beta阶段状态、通过`UIContext`获取实例的步骤，以及相关的系统能力和起始版本要求。该文档专为ArkUI应用开发者设计，旨在指导其在应用开发过程中有效管理上下文菜单的生命周期和交互行为。
