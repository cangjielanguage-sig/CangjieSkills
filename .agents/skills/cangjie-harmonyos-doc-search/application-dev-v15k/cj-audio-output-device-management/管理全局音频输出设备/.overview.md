# 管理全局音频输出设备

This directory provides comprehensive technical documentation for managing global audio output devices within the AudioKit framework using the Cangjie programming language. It covers essential development tasks such as instantiating audio routing managers, enumerating supported device types—including speakers and Bluetooth A2DP—and retrieving real-time device information. Furthermore, it addresses the complexities of monitoring device connection status changes via callbacks and identifying the active, highest-priority output device. These guides are specifically tailored for application developers who possess a foundational understanding of audio system architecture and require practical solutions for handling dynamic audio routing in multi-device environments. By following these tutorials, developers can implement robust audio management features that adapt to changing hardware configurations, handle exceptions, and respond to device role changes effectively.

## Detailed Description

### 管理全局音频输出设备_5more.md 管理全局音频输出设备_5more.md
This technical guide instructs developers on managing global audio output devices using the AudioRoutingManager interface within the AudioKit framework. It covers creating the manager instance, listing supported device types like speakers and Bluetooth A2DP, retrieving current device information, and monitoring device connection status changes via callbacks. Key takeaways include Cangjie code examples for implementation and a warning against using connection listeners for auto-pause logic. Targeted at application developers with knowledge of the Cangjie language and audio system architecture, this document serves as a practical tutorial for handling dynamic audio routing scenarios in multi-device environments.

### 获取最高优先级输出设备信息_2more.md 获取最高优先级输出设备信息_2more.md
This technical guide explains how to retrieve and monitor the highest priority audio output device in a Cangjie-based application using the AudioKit. It covers two main operations: retrieving the preferred output device using getPreferredOutputDeviceForRendererInfo and subscribing to device change events via a custom callback. The document defines the highest priority device as the active sound output destination. It provides code examples for creating AudioRendererInfo, handling exceptions, and registering or unregistering listeners for device role and type changes. Intended for application developers working with audio routing who need to manage dynamic audio output scenarios.
