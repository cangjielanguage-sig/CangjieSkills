# ImageSpan

The ImageSpan directory provides comprehensive documentation for the ImageSpan component within the ArkUI framework, specifically designed for the Cangjie language. It covers the integration of inline images into text flows, detailing initialization methods, component properties, event handling, and practical code examples for styling and alignment. Key topics include resource management, error handling, and visual customization like scaling and background styles. This resource is suitable for software developers and UI engineers building rich text interfaces on HarmonyOS who need to embed mixed media content directly into text components.

## Detailed Description

### ImageSpan_4more.md ImageSpan_4more.md
This document provides API reference documentation for the ImageSpan component in the ArkUI framework, specifically for the Cangjie language. It explains how to create inline images within a Text component using three initialization methods: AppResource, PixelMap, and String paths. Key sections cover constructor parameters supporting various formats like PNG, JPG, and Base64, as well as supported universal attributes such as size and background. The component exclusively supports click events. This guide targets developers building user interfaces who need to embed images directly into text flows, requiring familiarity with resource management and ArkUI component structures.

### 示例代码.md 示例代码.md
This document provides practical Cangjie code examples demonstrating the usage and styling of the ImageSpan component within HarmonyOS UI development. It covers two primary scenarios: alignment and scaling effects, and background styling. The first example illustrates properties like verticalAlign and objectFit to control image positioning relative to text. The second example details textBackgroundStyle for applying colors and border radius to image spans. This serves as a reference guide for developers using the Cangjie language to build rich text interfaces containing mixed media.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling image loading events within the ArkUI framework using the Cangjie language. It details two primary callback functions: `onComplete`, which triggers upon successful data loading and decoding to provide image dimensions via `ImageLoadResult`, and `onError`, which executes when exceptions occur to return error details via `CJImageError`. Both functions require specific callback parameters and are available starting from version 15. The documentation is intended for software developers integrating image handling capabilities into their applications, providing clear definitions of parameters, system capabilities, and functional behaviors to facilitate robust error handling and status monitoring.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring component properties within the Cangjie ArkUI framework. It details methods for image and text styling, specifically covering the alt, colorFilter, objectFit, textBackgroundStyle, and verticalAlign functions. Key information includes parameter definitions for setting placeholder images, applying RGBA color filter matrices, defining image scaling types, and customizing background styles with border radii. Each entry lists system capabilities and starting versions. This technical reference is intended for software developers using Cangjie to build user interfaces, requiring prior knowledge of UI components and graphical concepts.
