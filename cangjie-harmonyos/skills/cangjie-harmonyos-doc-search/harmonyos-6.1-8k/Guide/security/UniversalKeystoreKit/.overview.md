# UniversalKeystoreKit

UniversalKeystoreKit provides comprehensive documentation and guides for the Harmony Universal KeyStore (HUKS) within the OpenHarmony ecosystem. It focuses on secure key management, cryptographic operations, and lifecycle management using the Cangjie programming language and ArkTS. The content covers essential topics such as key generation, import, encryption, decryption, signing, and attestation. Designed for developers building secure applications, this kit ensures robust data protection through hardware-backed security environments and detailed algorithm specifications.

## Detailed Description

### [1] README_zh
This directory serves as the Chinese documentation entry for the Universal Keystore Kit (HUKS). It provides a comprehensive development guide for handling sensitive data and cryptographic operations in OpenHarmony, covering key generation, import, usage (encryption, signing, agreement, derivation), and lifecycle management (deletion, attestation).

### [2] cj-huks-check-key
A Cangjie language tutorial detailing how to use the HUKS interface to check if a specific key exists. It covers the complete development flow, including specifying key aliases, initializing attribute sets, and calling the `hasKeyItem` interface, with attention to alias length limits.

### [3] cj-huks-concepts
A foundational resource for developers using the Cangjie HUKS framework, focusing on core concepts necessary for secure cryptographic application development within the context of the Harmony Universal KeyStore.

### [4] cj-huks-delete-key
Focuses on secure key deletion practices in the Cangjie environment using HUKS. It provides a guide on determining key aliases, configuring attribute sets, and calling the `deleteKeyItem` interface to ensure sensitive data is thoroughly cleared.

### [5] cj-huks-encryption-decryption
A comprehensive resource for data encryption and decryption in Cangjie, covering the practical application of mainstream algorithms like AES and RSA within the HarmonyOS ecosystem.

### [6] cj-huks-encryption-decryption-overview
Provides a comprehensive overview of HUKS encryption and decryption capabilities, detailing supported algorithm specifications (AES, RSA, SM4, etc.) for standard and lightweight devices, including block modes, padding modes, and API level requirements.

### [7] cj-huks-export-key
Details how to export persistent asymmetric public keys in Cangjie using HUKS. It covers the development flow from alias setup to the `exportKeyItem` interface, explaining the returned X.509 standard DER format byte array.
