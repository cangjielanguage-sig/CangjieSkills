# 创建自定义组件

This directory focuses on creating custom components within the ArkUI framework using the Cangjie programming language. It covers the fundamental structure, syntax constraints, parameter regulations, and styling mechanisms for building reusable UI elements. Key topics include the `@Component` decorator, the `build()` function rules, state management, and component interaction. This resource is suitable for developers looking to encapsulate UI logic, ensure code compliance with ArkUI constraints, and enhance modularity in their applications.

## Detailed Description

### build函数.md build函数.md
This document outlines the strict syntax and structural rules for defining UI descriptions within the build() function in ArkUI using the Cangjie language. It covers root node requirements for @Entry and @Component decorators, variable declarations, logging usage, method invocation restrictions, control flow syntax, and state variable mutation. Key constraints include forbidding local variables, Hilog.info, local scopes, and match syntax. Only @Builder methods can be called for rendering, and state variables cannot be modified directly within the function. This reference guide targets ArkUI developers using Cangjie who need to ensure their UI code complies with framework constraints.

Keywords: ArkUI, Cangjie, build() function, UI description, constraints, @Entry, @Component, @Builder, state management

### 创建自定义组件_4more.md 创建自定义组件_4more.md
This guide explains how to create and use custom components within the ArkUI framework using the Cangjie programming language. It details the component structure, emphasizing the use of the @Component decorator, the mandatory build() function, and page entry points via @Entry. Key topics include component characteristics like reusability and data-driven updates, member variable constraints, and decorators for state management and component reuse. The document provides code examples demonstrating basic implementation and instantiation. It targets developers seeking to encapsulate UI and business logic for better code maintainability and modularity in ArkUI applications.

Keywords: ArkUI, Cangjie, Custom Components, @Component, build() function, UI development, @Entry, State management

### 自定义组件的参数规定.md 自定义组件的参数规定.md
This technical guide explains the parameter regulations for creating and initializing custom components within the Cangjie ArkUI framework. It covers two main scenarios: initializing member variables with basic data types like Int64 and Color, and passing function callbacks from parent to child components to handle events. Key takeaways include the syntax for instantiating components in the build method and using closures to enable child components to trigger parent logic. This tutorial is intended for developers using the Cangjie language to build ArkUI interfaces, focusing on component interaction and state management.

### 自定义组件通用样式.md 自定义组件通用样式.md
This technical guide explains how to apply common styles to custom components within the ArkUI framework using Cangjie syntax. The document covers the syntax for chain-style calling and provides a code example demonstrating a parent component styling a child component. The key takeaway is that ArkUI wraps custom components in an invisible container; styles are applied to this container rather than directly to the internal UI elements, such as the Button shown in the example. This is intended for ArkUI developers who need to understand the rendering behavior and style inheritance of custom components.

Keywords: ArkUI, Cangjie, custom components, chain-style calling, invisible container, rendering behavior
