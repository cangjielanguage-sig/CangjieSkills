## Detailed Description

### ohosrouter页面路由/

This directory provides API reference documentation for the `ohos.router` module and associated classes used in the ArkUI framework with the Cangjie language. It focuses on managing page navigation, URL-based access, and page state tracking. Key concepts include page jumping, stack management, and routing modes like Single and Standard. This documentation is essential for HarmonyOS developers building applications in Cangjie who need to implement complex navigation logic, handle page lifecycles, and manage parameters effectively.

The content delves deep into the mechanics of the `ohos.router` module, which acts as the backbone for user interface transitions in HarmonyOS apps. Developers will find detailed explanations on how to utilize page jumping to move between screens seamlessly, as well as how to manipulate the page stack to support "Back" navigation and multi-tasking workflows. The documentation also clarifies the nuances between different routing modes; for example, the "Single" mode ensures that only one instance of a page exists in the stack, which is useful for main screens, whereas "Standard" mode allows multiple instances, facilitating workflows that require repeated entry into the same page with different states.

Additionally, the reference material covers URL-based access, enabling developers to implement deep linking and navigate to specific parts of the application via external triggers. The section on page state tracking and lifecycle management is particularly important for maintaining data integrity during transitions, ensuring that user inputs are preserved or correctly discarded as the user navigates away. By mastering these APIs, developers can create intuitive, responsive, and stable navigation experiences that adhere to HarmonyOS design standards. Ultimately, this directory equips developers with the necessary tools to build sophisticated navigation flows that are essential for modern mobile applications.
