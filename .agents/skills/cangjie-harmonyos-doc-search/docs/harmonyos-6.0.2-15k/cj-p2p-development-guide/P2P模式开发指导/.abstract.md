This directory serves as a comprehensive technical resource for developers aiming to implement Wi-Fi Peer-to-Peer (P2P) functionality using the Cangjie language and the ConnectivityKit. It provides in-depth guidance on establishing direct TCP/IP connections between devices without relying on a traditional Access Point. The documentation covers critical concepts such as P2P mode definitions, device discovery mechanisms, and the management of P2P groups. It includes detailed API references and practical code examples for handling connection states and event callbacks. This guide is specifically designed for software developers and engineers who are building connectivity applications requiring robust peer-to-peer communication workflows, offering both theoretical background and actionable implementation steps to ensure successful integration of wireless P2P features into modern software systems.
