This directory serves as the primary entry point for the `stddatabasesql` package documentation within the Cangjie programming language ecosystem. It provides a comprehensive overview of the standard library component designed for database access using SQL/CLI interfaces. The content covers the fundamental architecture required for database operations, including driver management, connection handling, and transaction control. A significant emphasis is placed on the interoperability between SQL data structures and the Cangjie type system, featuring detailed mapping tables and conversion rules. This resource is tailored for Cangjie developers, software architects, and students who need to integrate persistent storage solutions into their applications or contribute to the development of database drivers. Key topics include API references, exception handling mechanisms, and state management enumerations.
