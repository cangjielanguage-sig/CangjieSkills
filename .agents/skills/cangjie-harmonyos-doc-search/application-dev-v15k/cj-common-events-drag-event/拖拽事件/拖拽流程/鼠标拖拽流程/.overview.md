# 鼠标拖拽流程

This directory provides a comprehensive technical guide for implementing mouse drag-and-drop functionality within the ArkUI framework. It covers the entire spectrum of the drag process, starting from the fundamental "drag and go" operational mode and specific trigger conditions to the complex management of event lifecycles and data transfer logic. Key topics include intra-application and cross-application support, callback event handling (such as onDragStart and onDrop), and the precise usage of DragEvent methods for state management. This documentation is specifically designed for software developers and system engineers who aim to build or customize interactive drag-and-drop features in their applications, offering both theoretical background and practical implementation details.

### 鼠标拖拽流程_3.md 鼠标拖拽流程_3.md
This technical reference document details the valid usage of DragEvent getter and setter methods throughout the drag-and-drop lifecycle. It covers two main areas: the availability of data retrieval methods like getVelocity and getWindowX/Y, and the execution timing for configuration methods like setResult and useCustomDropAnimation across specific callbacks such as onDragStart, onDrop, and onDragEnd. Key takeaways include that getResult is exclusive to onDragEnd, while getPreviewRect is only valid in onDrop. Crucially, setResult can be called in multiple stages, but only the value set in onDrop is passed as the final result to onDragEnd. This guide targets developers implementing drag-and-drop interactions in ArkUI applications who need precise control over event data and UI behavior.
