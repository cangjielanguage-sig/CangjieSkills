The documentation outlines essential functionality such as integer conversion, string representation, and validation logic, including exception handling for invalid inputs. Furthermore, it details operator overloads that enable developers to perform date arithmetic and equality comparisons. This resource is specifically designed for Cangjie developers and software engineers who require precise tools for manipulating, validating, or calculating weekday values in their applications. It serves as a central hub for understanding the data structure and behaviors associated with weekly time cycles.

## Detailed Description

The following files provide in-depth technical details regarding the implementation and usage of the DayOfWeek enum, covering both its static properties and dynamic behaviors.

### enum_DayOfWeek_12more.md
This document serves as API reference documentation for the DayOfWeek enum in the Cangjie programming language, detailing the representation of days within a week. It covers the enum definition inheriting from ToString and Equatable, lists all seven day instances (Sunday to Saturday), and documents static and instance methods like of, toInteger, and toString. Key functionality includes integer conversion where Sunday is 0 and Monday through Saturday are 1 to 6, with IllegalArgumentException handling for invalid inputs. The value() method is marked as deprecated in favor of toInteger(). This reference is intended for Cangjie developers working with date and time logic who need to manipulate or validate day-of-week data.

### operator_func_DayOfWeek_4more.md
This document serves as API reference documentation for operator overloads associated with the DayOfWeek enum in the Cangjie programming language. It details four specific operator functions: inequality (!=), addition (+), subtraction (-), and equality (==). Key takeaways include the ability to compare two DayOfWeek instances for equality and to perform date arithmetic by adding or subtracting an Int64 number of days to calculate future or past weekdays. The target audience is software developers utilizing the time package who need to manipulate or compare weekday values programmatically.
