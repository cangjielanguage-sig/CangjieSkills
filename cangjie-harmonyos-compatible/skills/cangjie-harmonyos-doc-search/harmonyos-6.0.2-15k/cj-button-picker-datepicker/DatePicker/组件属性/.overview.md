# 组件属性

This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework, specifically utilizing the Cangjie programming language. It focuses extensively on the visual customization of picker components, detailing how to manipulate text styles for various states such as selected, non-selected, and general text elements. Key topics include the configuration of font attributes like color, size, weight, and family, as well as specific features like lunar calendar toggling. The documentation distinguishes between string-based and resource-based parameter definitions, offering flexibility for developers. Furthermore, it explains method chaining capabilities and default value behaviors. This resource is essential for HarmonyOS developers and UI engineers seeking to implement precise, programmatic control over the aesthetic and functional aspects of selection interfaces in their applications.

## Detailed Description

### func_disappearTextStyleRes_4more.md func_disappearTextStyleRes_4more.md
This API reference document details Cangjie functions for configuring text styles and calendar display within ArkUI picker components. It covers the `disappearTextStyle` overloads for styling non-selected options, the `lunar` function for toggling lunar calendar display, and `selectedTextStyle` for customizing the active item's appearance. Key information includes parameter definitions for color, size, weight, and font family, with specific support for both String and AppResource types in the `disappearTextStyle` overloads. All functions return `This` to support method chaining. This documentation targets HarmonyOS developers using the ArkUI framework who require precise control over the visual presentation of selection interfaces.

### func_selectedTextStyleReso_3more.md func_selectedTextStyleReso_3more.md
This document serves as API reference documentation for Cangjie language functions used to configure text styles within the ArkUI framework. It details three specific function overloads: selectedTextStyle and two variants of textStyle, distinguishing between string-based and resource-based font family definitions. Key information includes parameter requirements, such as mandatory size and family arguments for resource-based overloads, default values like "HarmonyOS Sans", and the restriction that text size does not support percentages. The target audience is software developers utilizing ArkUI for UI development who need to programmatically customize text appearance, including color, weight, and font styles.
