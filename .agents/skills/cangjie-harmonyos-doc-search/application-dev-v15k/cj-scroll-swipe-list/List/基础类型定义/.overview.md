# 基础类型定义

This directory provides fundamental type definitions and API references for managing List components within the ArkUI framework using the Cangjie language. It covers essential data structures for tracking visible content, controlling scroll alignment behaviors, and managing list scrolling controllers. Key topics include the `VisibleListContentInfo` class, `ScrollSnapAlign` enum, and the `ListScroller` controller. It serves as a core resource for understanding the data models and controllers necessary for advanced list manipulation. This documentation is suitable for HarmonyOS developers who need to programmatically manipulate list states, handle scrolling interactions, and optimize layout rendering in their applications.

## Detailed Description

### class_VisibleListContentInfo.md class_VisibleListContentInfo.md
This API reference document defines the Cangjie class VisibleListContentInfo, which encapsulates detailed information about sub-components within the visible area of a List component. The documentation details the class structure, focusing on three public properties: index, itemGroupArea, and itemIndexInGroup, alongside the class constructor. Key information includes the data types for these properties, such as Int32 and ListItemGroupArea, and the constructor's parameter requirements, where index is mandatory. This resource is designed for ArkUI developers using the Cangjie language who need to programmatically access or track the state of visible list items and groups within their applications.

### enum_ScrollSnapAlign.md enum_ScrollSnapAlign.md
This API documentation defines the ScrollSnapAlign enum for controlling list item alignment upon scrolling completion in the Cangjie ArkUI framework. The document details four enum values: NONE, START, CENTER, and END, each describing specific alignment behaviors and system capabilities. Key information includes the limitation that accurate alignment is restricted to equal-height item scenarios, along with specific notes on edge behaviors for START and END modes where full item visibility takes precedence over strict alignment. This reference guide targets developers utilizing ArkUI to manage list scrolling interactions and visual positioning.

### class_ListScroller/
This directory contains comprehensive API reference documentation for the `ListScroller` class, a critical controller for managing scrolling behaviors within the ArkUI framework. Designed specifically for HarmonyOS developers using the Cangjie language, these documents cover the intricacies of binding controllers to List components and manipulating list states programmatically. Key topics include retrieving item geometry, handling swipe actions, and performing coordinate-based lookups to identify visible content. The documentation also details methods for navigating to specific items within groups, including important performance considerations regarding smooth scrolling animations. This resource is essential for developers building complex, interactive list interfaces requiring precise control over navigation and layout rendering.
