# cj-apis-metadata

本目录包含仓颉语言中 `ohos.metadata` 模块的 API 参考文档，专注于 HarmonyOS 应用开发中元数据的配置与读取机制。内容涵盖了模块、UIAbility 及 ExtensionAbility 的元数据定义，详细解析了 `Metadata` 类的核心属性（name、value、resource）及其使用方法。文档还提供了通过 `getBundleInfoForSelf` 接口获取元数据的具体指导，以及模块导入和运行环境的配置说明。该资源主要面向使用仓颉语言的 HarmonyOS 开发者，旨在帮助他们高效地管理和应用元数据信息。

## 详细说明

### cj-apis-metadata.md cj-apis-metadata.md
本文档是仓颉语言中 `ohos.metadata` 模块的 API 参考文档，旨在描述模块、UIAbility 及 ExtensionAbility 的元数据信息。文档详细介绍了 `Metadata` 类的结构，包括 name、value 和 resource 三个关键属性，并说明了如何通过 `getBundleInfoForSelf` 接口配合特定标志位获取元数据。此外，还涵盖了模块导入方式及示例代码的运行环境配置。该文档主要面向 HarmonyOS 仓颉开发者，用于指导应用元数据的配置与读取。
