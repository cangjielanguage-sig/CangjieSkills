This directory provides comprehensive tutorials on integrating Cangjie modules into ArkTS projects using the `import` syntax. It covers various scenarios including loading third-party libraries, static libraries, and local HAR packages, as well as handling complex dependencies where one library relies on another. Key topics include configuring `oh-package.json5`, defining TypeScript declarations in `.d.ts` files, and implementing interoperability functions using `JSContext` and `JSValue`. These guides are essential for HarmonyOS developers seeking to achieve cross-language interoperability between ArkTS and Cangjie, ensuring type safety and seamless function invocation.
