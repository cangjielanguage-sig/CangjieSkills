# class_AdOptions

This directory contains API reference documentation for the `AdOptions` class within the Cangjie AdsKit framework. It serves as a comprehensive guide for configuring advertising request instances, detailing the necessary parameters for initialization and property management. Key topics covered include the constructor signature, system capabilities, child protection tags for COPPA compliance, ad content classification ratings (such as W, PI, J, A), toggles for non-personalized ads, and custom attributes for ad duration and traffic settings. This documentation is specifically designed for developers integrating advertising capabilities into applications using the Cangjie programming language, providing the technical details required to ensure compliance and proper ad delivery.
