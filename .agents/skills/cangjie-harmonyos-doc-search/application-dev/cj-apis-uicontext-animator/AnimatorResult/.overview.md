# AnimatorResult

This directory contains API reference documentation for the ArkUI framework's animation components, specifically implemented in the Cangjie language. It covers the `AnimatorResult` class for managing animation states, the `AnimatorOptions` class for configuration, and enums for direction and fill modes. Key topics include animation lifecycle management, playback control, parameter configuration, and visual state persistence. This documentation is suitable for Cangjie developers and UI engineers who need to implement, control, and fine-tune complex animation behaviors within their applications.

### enum_AnimatorFill.md enum_AnimatorFill.md
This API documentation defines the AnimatorFill enum in the Cangjie language, which controls the visual state of animation targets before and after execution. The document enumerates four primary modes: None (no styles applied), Forwards (retains end state), Backwards (applies initial values during delay), and Both (combines previous rules). It also includes standard equality operators for comparing enum values. Key technical details include inheritance from Equatable and a system capability requirement of ArkUI.ArkUI.Full. Intended for ArkUI developers, this reference helps manage animation persistence and pre-execution behavior in user interfaces.
