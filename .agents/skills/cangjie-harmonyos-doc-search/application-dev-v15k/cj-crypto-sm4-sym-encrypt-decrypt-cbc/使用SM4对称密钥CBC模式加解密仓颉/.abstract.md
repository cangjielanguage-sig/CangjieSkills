This directory focuses on implementing SM4 symmetric encryption and decryption using CBC mode within the Cangjie programming language. It covers the essential cryptographic workflows, including key generation, initialization vector (IV) management, and data processing using the CryptoArchitectureKit. Key topics include SM4_128, CBC mode, PKCS7 padding, and the `Cipher` lifecycle methods such as `init`, `update`, and `doFinal`. The content is designed for Cangjie developers who need to secure application data through robust cryptographic standards, providing both theoretical guidance and practical code examples to ensure data integrity and security.
