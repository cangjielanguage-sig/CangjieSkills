# libs_stdx

The `libs_stdx` directory serves as a comprehensive repository for the Cangjie programming language's standard extension libraries. It encompasses a wide array of advanced functionalities designed to extend the core language capabilities, including Aspect-Oriented Programming (AOP), cryptographic operations (digests, encryption, X.509 certificates), network communication (HTTP, TLS, WebSocket), data serialization (JSON, CSV), compression (zlib), logging, and fuzzing testing frameworks. This collection is essential for Cangjie developers, backend engineers, and system architects seeking to build robust, secure, and high-performance applications by leveraging specialized, domain-specific tools and utilities.

## Detailed Description

### libs_overview
This directory provides a comprehensive overview of the Cangjie programming language's extension libraries, specifically focusing on the `stdx` ecosystem. It serves as a central hub for developers looking to access advanced functionalities beyond the standard library, such as cryptographic operations, network protocols, data compression, and Aspect-Oriented Programming (AOP). The content is tailored for Cangjie developers who need to integrate specialized modules, offering guidance on API usage, build environment configuration, and OS-specific linking for Linux, macOS, and Windows. It ensures users can effectively manage dependencies and compile projects requiring these external libraries, which are not distributed with the compiler by default.

### aspectCJ_package_overview
This directory serves as the central repository for the API overview and usage guide of the `stdx.aspectCJ` package, a specialized library designed to bring Aspect Oriented Programming (AOP) capabilities to the Cangjie language. It provides a comprehensive framework for developers to manage cross-cutting concerns efficiently. The documentation details the usage of three core annotation classes: `InsertAtEntry`, `InsertAtExit`, and `ReplaceFuncBody`. These annotations allow for the precise weaving of logic into function entry points, exit points, or the complete replacement of function bodies. Additionally, the guide outlines strict specifications concerning scope, parameter constraints, and global variable limitations. It also provides critical instructions on the mandatory two-step compilation process, which requires the `libcollect-aspects` and `libwave-aspects` plugins.

### base64_package_overview
This directory contains comprehensive documentation for the `stdx.encoding.base64` package, a specialized utility library designed to facilitate Base64 encoding and decoding operations. It serves as a technical reference guide for developers who need to serialize binary data into a text-safe format for secure transmission over protocols that strictly support text, such as email, JSON, or XML. The documentation covers the fundamental concepts of Base64 conversion, explaining how binary data is mapped to a set of 64 printable characters to ensure data integrity during transport. Furthermore, it details the specific API functions available for transforming byte arrays to Base64 strings and vice versa.

### crypto_package_overview
This directory contains the essential documentation for the `stdx.crypto.crypto` package, a robust library designed for secure random number generation and SM4 symmetric encryption. It provides a comprehensive installation guide that emphasizes the strict requirement for OpenSSL 3 across Linux, Windows, and macOS. The content covers critical environment variable configurations like `LD_LIBRARY_PATH` and `PATH` and details core API components such as the `SecureRandom` and `SM4` classes, alongside structs for `OperationMode` and `PaddingMode`. This resource is suitable for developers who need to implement cryptographic functions and must configure system libraries to prevent runtime exceptions.

### data_package_overview
This directory contains the API overview documentation for the `stdx.unittest.data` library, a specialized tool designed to facilitate input serialization for Cangjie unit tests. It provides comprehensive details on supporting JSON, CSV, and TSV formats, enabling developers to externalize test data for robust parameterized testing. The content covers essential functions like `csv`, `json`, and `tsv`, as well as strategy classes such as `CsvStrategy` and `JsonStrategy` for format implementation. This resource is suitable for Cangjie developers who possess knowledge of the language's standard testing capabilities and are seeking to optimize their test suites by integrating external data sources.

### fuzz_package_overview
This directory contains documentation for the `stdx.fuzz.fuzz` package, a robust coverage-feedback-based fuzzing engine specifically developed for the Cangjie programming language. It serves as a comprehensive guide covering fundamental fuzzing concepts, necessary system prerequisites including LLVM dependencies, and the detailed architecture of available API classes. Key components documented here include the `Fuzzer` and `FuzzerBuilder` classes for engine instantiation, and `FuzzDataProvider` for transforming byte streams into standard data types. The documentation explicitly outlines platform support for Linux and macOS while noting the exclusion of Windows, and defines the `ExhaustedException` for error handling.

### http_package_overview
This directory acts as the central repository for the `http_package_overview`, specifically housing the comprehensive documentation for the `stdxnethttp` package. This package is a versatile, high-performance network communication framework designed to facilitate the development of robust HTTP clients, servers, and WebSocket services. The documentation covers essential protocols including HTTP/1.1, HTTP/2, and WebSocket, alongside critical infrastructure requirements such as OpenSSL 3 integration and TLS/ALPN support. It is specifically curated for software developers and systems engineers who require deep architectural insights into interface contracts, data structures, and coroutine pool configurations.

### json_package_overview
This directory contains the essential API documentation for the `stdx.encoding.json` package, serving as a primary resource for developers working with data interchange in the stdx framework. It comprehensively covers the functionality required to process JSON data, with a specific focus on the conversion mechanisms between Strings, JsonValues, and DataModels. The content is grounded in the ECMA-404 standard, ensuring robust and standardized data handling across different systems. Key concepts include the `ToJson` interface, data encapsulation classes, and exception management. This documentation is specifically suitable for backend developers, system architects, and engineers seeking to implement reliable JSON encoding, decoding, and serialization logic within their software projects.

### log_package_overview
This directory serves as the central repository for the API overview documentation of the `stdx.log` package within the Cangjie programming language environment. It provides a detailed technical reference for a unified logging interface that abstracts away the complexities of actual implementation details. By offering a standardized approach, this package allows developers to handle logging operations efficiently without being tied to specific backend systems. The documentation encompasses a wide array of components, ranging from global management functions and abstract classes to specific structs and exception handling mechanisms. Key topics include the `Logger` class, `LogRecord` payloads, `LogWriter` serialization, `LogLevel` definitions, and `LogException` handling.

### serialization_package_overview
This directory provides a comprehensive API overview for the `stdx.serialization.serialization` package, a robust framework designed to facilitate the conversion of complex data structures into storable formats and their subsequent restoration. The documentation offers a functional introduction that clearly defines the core concepts of serialization and deserialization, followed by a detailed API list that includes essential functions, interfaces, classes, and exception handling mechanisms. Key takeaways from this package include the `Serializable` interface, which enables the creation of user-defined types, and the `DataModel` class hierarchy. This hierarchy acts as a crucial intermediate layer for managing specific data types such as `Bool`, `Int64`, and `String`.

### tls_package_overview
This directory serves as a comprehensive resource for the `stdxnettls` package, a specialized toolkit designed for establishing secure, encrypted network channels in modern applications. It covers the implementation of Transport Layer Security (TLS) protocols, specifically versions 1.2 and 1.3, leveraging the OpenSSL 3 library for robust cryptographic operations. The content ranges from low-level socket management to high-level session configuration, ensuring cross-platform compatibility across Linux, Windows, and macOS. This overview is suitable for software engineers and system architects seeking a reliable reference for secure communication protocols, certificate verification, and API navigation.

### url_package_overview
This directory serves as the central documentation hub for the `stdx.encoding.url` package, a specialized library designed to handle complex URL operations including parsing, encoding, decoding, and merging. It provides a deep dive into the standard URL structure, meticulously breaking down essential components such as scheme, host, path, and query parameters. Furthermore, it explains the UTF-8 based encoding process required for handling non-ASCII characters in modern web environments. The documentation outlines the complete package API, detailing key classes like URL, Form, and UserInfo, as well as the UrlSyntaxException for robust error handling.

### x509_package_overview
This directory serves as a comprehensive overview and documentation hub for a specialized cryptographic package focused on X.509 digital certificate management. It covers the full lifecycle of certificates, including parsing, serialization, verification, and chain management. The content provides detailed API references for components like `X509Certificate` and `X509CertificateRequest`, along with guides for cryptographic keys and encoding formats such as PEM and DER. It also addresses the mandatory OpenSSL 3 dependency with platform-specific setup instructions for Linux, Windows, and macOS. This resource is suitable for software engineers and security developers requiring precise control over digital certificates and cryptographic operations within their software projects.

### zlib_package_overview
This directory serves as the central documentation hub for the `stdx.compress.zlib` package, a specialized software library designed to facilitate high-performance data compression and decompression. The content provides a thorough functional overview and a complete API reference, making it an indispensable tool for developers working with data optimization. It explains the mechanics of the underlying deflate algorithm and details the specific formats supported by the library, namely deflate-raw and gzip, while clearly noting the exclusion of file packing features to focus purely on data stream manipulation. Key areas of focus include stream-based processing capabilities, which allow for the efficient transfer of data between streams and byte arrays, as well as the configuration of compression levels to suit different performance needs.
