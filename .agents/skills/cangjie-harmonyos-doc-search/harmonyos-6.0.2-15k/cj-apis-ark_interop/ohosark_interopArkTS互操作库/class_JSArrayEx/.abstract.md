This directory contains API reference documentation for the Cangjie class `JSArrayEx`, specifically designed for declarative interoperability with ArkTS Array types. It comprehensively covers class definitions, read-only properties like size, initialization methods, and a wide range of array manipulation functions including clone, concat, get, and isEmpty. Additionally, it details advanced features such as type conversion functions and operator overloading for element access. Key topics include ArkUI system capabilities, Napi-based cross-language interaction, and efficient data structure handling between Cangjie and ArkTS environments. This resource is essential for Cangjie developers working on ArkUI applications who need to manage complex data collections and perform seamless cross-language type conversions.
