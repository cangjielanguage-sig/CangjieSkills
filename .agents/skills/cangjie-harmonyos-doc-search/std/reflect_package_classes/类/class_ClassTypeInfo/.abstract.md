This directory contains API documentation for the `ClassTypeInfo` class in the Cangjie programming language, focusing on runtime type inspection and reflection capabilities. It covers essential functionalities for retrieving class metadata, including constructors, instance and static variables, and inheritance hierarchies. The documentation details methods for checking class semantics like abstract, open, or sealed status, as well as dynamic instance construction. Suitable for Cangjie developers implementing advanced reflection features, this reference provides code examples and exception handling details for interacting with class structures dynamically.
