This directory contains comprehensive API reference documentation for the `JsonReader` class within the Cangjie programming language ecosystem. It focuses specifically on the mechanisms required for deserializing JSON data streams into native Cangjie objects. The documentation covers essential aspects of stream processing, including initialization, token inspection, and structural navigation. It highlights error handling protocols, such as throwing `IllegalStateException` for invalid formats, and details specific behaviors like whitespace skipping and raw byte retrieval. This resource is primarily suitable for Cangjie developers and system architects who are implementing custom JSON parsing logic and require granular control over data stream consumption, validation, and extraction.
