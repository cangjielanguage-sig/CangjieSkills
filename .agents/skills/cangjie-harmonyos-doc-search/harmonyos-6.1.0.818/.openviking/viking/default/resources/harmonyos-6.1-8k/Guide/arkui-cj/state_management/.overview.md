# state_management

This directory provides a comprehensive guide to state management within the Cangjie (CJ) programming language and the ArkUI framework. It covers core mechanisms such as LocalStorage, AppStorage, and PersistentStorage, alongside essential macros like @State, @Prop, and @Link for data synchronization. Additionally, it addresses advanced topics including the MVVM architecture, environment parameter adaptation, and performance optimization best practices. This resource is suitable for developers seeking to implement robust, responsive, and efficient state handling in their applications.

## Detailed Description

### [1] cj-application-state-management-overview
This document outlines the framework's application-level state management capabilities, designed to help developers implement state data sharing across pages or the entire application. It covers four core mechanisms: LocalStorage for sharing within UIAbility, AppStorage as central storage, PersistentStorage for data persistence, and Environment for synchronizing device environment parameters. It highlights how AppStorage and PersistentStorage solve cross-page state sharing and persistence issues that decorators alone cannot handle. Suitable for developers needing complex state management or data persistence.

### [2] cj-appstorage
The `cj-appstorage` directory serves as a comprehensive technical resource dedicated to AppStorage, the centralized mechanism for global UI state storage in Cangjie applications. This documentation is essential for understanding how to manage application-wide state efficiently.

### [3] cj-environment
This directory contains Cangjie language development documentation for the Environment singleton object in the ArkUI framework. It details how to query device environment parameters (such as language, dark/light mode, layout direction) to adapt to different application scenarios. Core content includes the list of built-in Environment parameters, the mechanism for accessing environment variables via AppStorage, and specific code implementations for `envProp` and `@StorageProp`. Suitable for ArkUI developers with basic AppStorage knowledge, it helps achieve dynamic interface adjustments based on the system environment.

### [4] cj-localstorage
This directory serves as a comprehensive guide for the `cj-localstorage` module, focusing on the LocalStorage mechanism within the Cangjie (CJ) programming language. It is specifically designed to handle page-level UI state storage in ArkUI applications.

### [5] cj-macro-link
This directory serves as a comprehensive technical guide for the `@Link` macro within the ArkUI framework, specifically tailored for developers using the Cangjie programming language. It focuses on the critical mechanism of bidirectional data binding between parent and child components.

### [6] cj-macro-observed-and-publish
This directory serves as a comprehensive technical guide for the Cangjie programming language, specifically targeting the ArkUI framework's advanced state management features. It focuses on the implementation of the `@Observed` and `@Publish` macros, which are used for managing state in nested objects.
