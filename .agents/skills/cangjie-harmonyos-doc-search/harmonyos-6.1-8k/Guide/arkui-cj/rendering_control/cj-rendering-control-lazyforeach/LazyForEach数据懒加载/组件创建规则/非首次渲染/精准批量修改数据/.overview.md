# 精准批量修改数据

本目录包含关于如何在Cangjie语言中通过LazyForEach实现数据源精准批量修改的技术文档。内容涵盖了继承BasicDataSource、利用notifyDatasetChange方法以及DataOperation（如移动、交换、增加、删除）的具体实现与逻辑。重点在于优化列表数据变更时的渲染性能，详细解析了索引计算规则及操作限制。适合具备基础UI开发能力、需要高效管理动态数据列表的开发者参考。

## 详细描述

### 精准批量修改数据_1.md
这份文档旨在指导开发者如何在Cangjie语言中通过LazyForEach实现数据源的精准批量修改。文档包含两个核心代码示例，详细展示了如何继承BasicDataSource并利用notifyDatasetChange方法，配合DataOperation（如移动、交换、增加、删除）来高效更新列表UI。关键信息包括操作索引需基于修改前的原数组，以及onDatasetChange不能与其他数据操作接口混用的注意事项。本文档适合具备基础UI开发能力的开发者，用于优化列表数据变更时的渲染性能。

### 精准批量修改数据_2.md
这份文档旨在指导开发者如何通过精确的批量数据修改操作来优化列表数据更新。文档涵盖了数组修改前后的对比分析，详细说明了DataMoveOperation、DataExchangeOperation、DataAddOperation和DataDeleteOperation四种操作类型及其索引计算逻辑。核心要点包括LazyForEach机制下每个索引仅允许被操作一次，开发者可传入键值以提升性能，以及RELOAD操作具有最高优先级。这是一份面向UI框架开发者的技术参考文档，适用于需要高效管理动态数据列表的场景。
