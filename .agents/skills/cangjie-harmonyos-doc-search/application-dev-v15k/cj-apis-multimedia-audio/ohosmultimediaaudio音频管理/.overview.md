# ohosmultimediaaudio音频管理

This directory contains comprehensive API reference documentation for the HarmonyOS multimedia audio management module, specifically designed for the Cangjie programming language. It covers the AudioKit framework, detailing classes, enums, and functions necessary for audio capture, rendering, routing, volume control, and session management. Key topics include audio stream configuration, device handling, interruption management, and state monitoring. This documentation is suitable for software developers and multimedia engineers building audio applications on HarmonyOS who need to implement recording, playback, and advanced audio control features using Cangjie syntax and system capabilities.
