This directory serves as a specialized resource hub for Cangjie developers focusing on system-level debugging and performance optimization. It provides comprehensive guidelines for utilizing the HiDebug interface, a critical tool for acquiring real-time insights into application behavior. The content covers essential metrics such as memory statistics—including native heap and Proportional Set Size (PSS)—CPU usage patterns, and system resource limits. Designed specifically for developers operating within the DevEco Studio environment, this guide facilitates the integration of performance analysis kits into Cangjie applications. By following these guidelines, developers can effectively monitor process resources, identify bottlenecks, and ensure their applications run efficiently on the target system. This documentation is indispensable for those aiming to build robust, high-performance Cangjie software, offering both theoretical interface definitions and practical implementation steps to streamline the development workflow and enhance application stability.
