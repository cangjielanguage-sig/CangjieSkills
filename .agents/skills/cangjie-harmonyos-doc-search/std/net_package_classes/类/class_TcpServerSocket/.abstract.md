This directory contains API reference documentation for the `TcpServerSocket` class within the Cangjie programming language's network package. It covers the implementation of TCP servers, including initialization, connection listening, and socket configuration. Key topics include socket lifecycle management (bind, accept, close), low-level option manipulation (SO_KEEPALIVE, reuseAddress), and exception handling. This documentation is suitable for network application developers and systems programmers who need to build robust server-side applications or manage low-level TCP socket behaviors and system-specific options in Cangjie.
