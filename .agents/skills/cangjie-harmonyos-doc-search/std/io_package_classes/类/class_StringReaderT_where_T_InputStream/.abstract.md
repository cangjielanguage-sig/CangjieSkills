This directory contains comprehensive API reference documentation for the Cangjie `StringReader` class, specifically designed to read and convert data from `InputStream` objects into characters or strings. It covers the class initialization, core methods like `read` and `readToEnd`, internal buffering, and UTF-8 encoding support. Additionally, it details extensions for resource management and seekable stream navigation, alongside specific parsing functions. This resource is suitable for Cangjie developers implementing text processing, I/O operations, and stream parsing who require efficient data handling, error management, and random access capabilities.
