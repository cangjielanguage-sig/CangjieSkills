# 启动应用内的UIAbility

本目录详细介绍了在HarmonyOS应用中启动及管理同一应用内UIAbility的技术实现。核心内容包括如何通过Want对象启动目标Ability、在启动方与被调用方之间传递参数、以及正确销毁Ability实例。文档特别涵盖了使用Cangjie语言进行开发的代码示例，并涉及任务快照保留与移除的配置细节。这些内容对于需要实现复杂页面跳转、组件间通信及生命周期控制的HarmonyOS开发者极具参考价值。

## 详细说明

### 启动应用内的UIAbility_1.md 启动应用内的UIAbility_1.md
这份文档是一份技术教程，旨在指导开发者如何在同一应用内启动另一个UIAbility。文档主要涵盖了启动Ability、接收参数及销毁Ability三个核心环节。关键信息包括：在调用方通过构建包含bundleName、abilityName及parameters的Want对象，调用startAbility方法启动目标；在被调用方的onCreate或onNewWant回调中解析Want参数获取数据；以及使用terminateSelf方法结束Ability生命周期。文档提供了Cangjie语言代码示例，适用于需要实现应用内多Ability交互与数据传递的HarmonyOS开发者。

### 启动应用内的UIAbility_2.md 启动应用内的UIAbility_2.md
本文档旨在演示如何在Cangjie应用中通过代码停止UIAbility实例。主要内容包括使用UIAbilityContext调用terminateSelf()方法的代码示例，以及关于任务快照保留的配置说明。关键信息指出，调用该方法默认会保留最近任务列表中的快照，若需移除，需在module.json5配置文件中将removeMissionAfterTerminate字段设为true。文档面向HarmonyOS开发者，适合作为应用生命周期管理的参考教程。
