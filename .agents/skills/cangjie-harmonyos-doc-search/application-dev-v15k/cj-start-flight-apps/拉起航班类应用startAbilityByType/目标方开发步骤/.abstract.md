This directory serves as a comprehensive technical resource for developers tasked with building the target side of a flight query application within the HarmonyOS ecosystem. It meticulously covers the necessary steps to configure `module.json5` for feature declaration using `linkFeature` and URI attributes, as well as parsing incoming parameters inside `UIAbility` lifecycle methods. The documentation provides detailed parameter definitions for two primary scenarios: querying by flight number and by location, specifying required fields such as `flightNo` and `originLocation`. Furthermore, it includes code examples for page routing logic utilizing `localStorage` and `windowStage`. These guides are specifically designed for developers utilizing the Cangjie language and ArkUI frameworks to implement feature-based application invocation and efficient data handling.
