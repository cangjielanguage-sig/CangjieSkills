# 状态管理概述

This directory provides a comprehensive overview of state management mechanisms within the Cangjie declarative UI framework. It covers the fundamental principles of how state changes drive UI rendering, distinguishing between state variables and regular variables. Key topics include component-level decorators (@State, @Prop, @Link, @Provide/@Consume, @Observed/@Publish) and application-level management (AppStorage, LocalStorage), as well as data synchronization patterns (unidirectional vs. bidirectional). It also details initialization methods, the scope of state variables, and the handling of nested object observations. This resource is suitable for developers seeking to implement efficient data-UI linkage and state sharing, serving as a foundational guide for building dynamic, responsive interfaces.

### 状态管理概述_2more.md 状态管理概述_2more.md
This document provides an overview of state management mechanisms within the Cangjie declarative UI framework, explaining how state changes drive UI rendering. It covers the relationship between State and View, and defines basic concepts such as state variables, regular variables, data sources, and initialization methods like local and parent-based initialization.
