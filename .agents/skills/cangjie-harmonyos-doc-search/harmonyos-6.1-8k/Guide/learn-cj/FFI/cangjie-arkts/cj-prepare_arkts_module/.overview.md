# cj-prepare_arkts_module

本目录包含关于在仓颉应用中集成 ArkTS 模块的指导文档。它主要介绍了如何获取并映射 ArkTS 模块名称以实现跨语言互操作，重点涵盖了仓颉对 NAPI 模块的支持范围、模块名称映射规范（如处理 `@ohos` 前缀）以及工程配置说明。该文档面向需要在仓颉代码中调用 ArkTS NAPI 模块的 OpenHarmony 开发者，旨在帮助开发者理解模块映射规则并完成相关配置。核心关键词包括：仓颉、ArkTS、NAPI、互操作、模块映射。

## 详细说明

### cj-prepare_arkts_module.md cj-prepare_arkts_module.md
本文档旨在指导开发者在仓颉应用中获取并映射 ArkTS 模块名称，以实现跨语言互操作。主要涵盖仓颉对 ArkTS 模块的支持范围（仅限 NAPI 模块）、ArkTS 模块名与仓颉导入名称的映射规范，以及工程配置说明。核心要点是模块名映射规则：以 @ohos 开头的模块需去掉前缀，其他前缀需指定 prefix 参数。工程配置与普通仓颉项目一致，仅需在代码中加载 NAPI 模块。面向需要在仓颉中调用 ArkTS NAPI 模块的 OpenHarmony 开发者。关键词：仓颉、ArkTS、NAPI、互操作、模块映射。
