# 消息认证码计算

本目录主要介绍消息认证码（MAC）及基于哈希的消息认证码（HMAC）的计算方法与应用场景。内容涵盖了MAC和HMAC的基本概念、工作原理、支持的算法规格（如SHA256、SM3等）以及具体的开发实现步骤。通过利用共享密钥机制，确保数据在传输过程中的完整性与真实性，有效防止篡改。该文档适用于需要进行数据完整性校验的仓颉语言开发者及加密应用开发人员，提供了从理论算法选型到实践代码实现的全面参考。

本文档旨在介绍消息认证码（MAC）及基于哈希的消息认证码（HMAC）的计算方法与用途，用于验证消息完整性。文档涵盖了MAC和HMAC的基本概念、工作原理（利用共享密钥防止篡改）以及支持的算法规格。关键信息包括API版本12及以上支持的摘要算法列表，涵盖SHA1、SHA256、SM3及MD5等，生成的认证码长度固定。该文档适用于需要实现数据完整性校验的开发人员，作为算法选型的参考文档。
