This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework, specifically utilizing the Cangjie language. It covers essential functionalities for text and input components, ranging from text recognition and conflict resolution to menu customization and input styling. Key topics include `dataDetectorConfig`, `editMenuOptions`, `placeholder` settings, cursor styling, and custom keyboard layouts. These resources are designed for software developers and UI engineers who require detailed syntax, parameter descriptions, and behavioral notes to implement sophisticated text interactions and user interface features in their applications.
