# class_Album

This directory provides comprehensive API reference documentation for the Cangjie Album class, a core component of the MediaLibraryKit framework designed for HarmonyOS application development. It serves as a technical guide for managing entity albums within the PhotoAccessHelper system, covering the retrieval and manipulation of album metadata such as names, URIs, types, and media counts. The content differentiates between read-only and writable attributes and provides detailed instructions on using the `commitModify` function to update the database. Furthermore, it includes references for fetching image and video assets using specific fetch options, including necessary permissions and return values. This documentation is tailored for developers proficient in Cangjie syntax who need to build media applications, handle system permissions, and manage potential exceptions effectively.

### func_getAssetsFetchOptions.md
This document provides API reference details for the Cangjie function getAssets, which retrieves image and video files from an album based on specified fetch options. It covers the function signature, required permissions (ohos.permission.READ_IMAGEVIDEO), input parameters (FetchOptions), return values (FetchResult<PhotoAsset>), and potential exceptions with specific error codes. Key information includes the required system capability and availability starting from API version 19. A practical code example demonstrates fetching assets from a specific album. This reference guide targets developers building HarmonyOS applications using the MediaLibraryKit who need to access and manage photo assets programmatically.
