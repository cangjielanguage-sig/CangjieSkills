This directory provides comprehensive API reference documentation for the FormExtensionAbility module within the HarmonyOS ecosystem, specifically tailored for the Cangjie programming language. It covers the essential components required to develop and manage form widgets (cards), including lifecycle callbacks, context environments, and initialization processes. Key topics include widget creation, updates, visibility changes, and destruction, alongside specific system capabilities and version requirements. It also details critical usage restrictions, such as prohibitions on multimedia modules. This resource is suitable for HarmonyOS application developers using Cangjie who need to implement dynamic card functionality and manage form states efficiently while adhering to system restrictions and coding standards.
