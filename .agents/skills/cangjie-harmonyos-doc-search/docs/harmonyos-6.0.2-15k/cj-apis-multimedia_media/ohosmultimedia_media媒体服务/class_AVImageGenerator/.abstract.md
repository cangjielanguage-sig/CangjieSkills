This directory contains API reference documentation for the Cangjie `AVImageGenerator` class, a component of the MediaKit framework designed for multimedia application development. It primarily focuses on the functionality required to retrieve video thumbnails from media resources and manage the lifecycle of these media objects. Key topics covered include setting data sources using file descriptors, capturing specific video frames via timestamps, and properly releasing system resources to prevent memory leaks. The documentation details specific methods like `fetchFrameByTime` and `release`, along with their parameters, return values, and error handling. This content is intended for developers using the Cangjie language on HarmonyOS who need to integrate video thumbnail extraction into their applications.
