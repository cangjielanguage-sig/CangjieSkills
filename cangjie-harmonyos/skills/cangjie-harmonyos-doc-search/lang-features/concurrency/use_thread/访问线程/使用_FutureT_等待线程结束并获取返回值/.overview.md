# 使用_FutureT_等待线程结束并获取返回值

本目录详细介绍了在 Cangjie 语言中如何利用 Future 模板类来实现线程间的同步操作，并安全地获取子线程的执行结果。内容涵盖了 Future 类的核心 API，重点解析了 get()、get(timeout) 和 tryGet() 等成员函数的使用场景与差异。通过具体的代码示例，文档演示了如何阻塞主线程等待子线程结束，以及如何优雅地处理超时异常。此外，还解释了 Future 类型与 spawn 表达式返回类型的对应关系。该资料适合具备基础并发概念的 Cangjie 开发者，旨在提升多线程编程中的结果处理能力。关键词：Future, 线程同步, spawn, 阻塞等待, 超时处理。
