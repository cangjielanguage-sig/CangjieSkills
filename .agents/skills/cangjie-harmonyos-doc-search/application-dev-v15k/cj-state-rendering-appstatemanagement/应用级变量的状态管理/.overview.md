# 应用级变量的状态管理

This directory focuses on the mechanisms for managing application-level variable states within the HarmonyOS ArkUI framework using the Cangjie programming language. It covers essential concepts such as global UI state storage via AppStorage, page-level storage with LocalStorage, device environment queries, and persistent data storage. Key topics include state synchronization, data persistence across application restarts, and reactive programming patterns using decorators. This resource is suitable for HarmonyOS developers and software engineers looking to implement robust state management, data consistency, and adaptive UI features in their applications.

### AppStorage应用全局的UI状态存储/
This directory provides comprehensive documentation for AppStorage, the global UI state storage mechanism designed for the ArkUI framework and Cangjie programming language. It details the implementation of a singleton storage system created at application startup, which facilitates central state management accessible across the entire app, distinguishing it from page-level LocalStorage. The content covers the integration of AppStorage with PersistentStorage and Environment variables, highlighting its role in state sharing between multiple UIAbility instances. It also explains the necessity of using @StorageProp and @StorageLink decorators for UI synchronization. This resource is essential for HarmonyOS developers and software engineers aiming to master application-level state management, data persistence, and reactive programming in Cangjie-based projects, particularly for version 12 and above.

### Environment设备环境查询/
This directory contains technical documentation and practical examples for the ArkUI framework's Environment class, specifically implemented in the Cangjie language. It is designed to assist developers in querying and utilizing device environment parameters to create adaptive and responsive user interfaces. The documentation covers the singleton class structure, static methods for binding system variables to AppStorage, and the retrieval of available properties. Key topics include the immutability of environment properties, the necessity of initializing `envProp` during application startup, and the handling of enums like `ColorMode` and `LayoutDirection`. This resource is highly suitable for developers working on features such as multi-language support, dark mode adaptation, and dynamic layout adjustments based on system settings.

### LocalStorage页面级UI状态储存/
This directory provides comprehensive documentation and resources for managing page-level UI state using the LocalStorage mechanism within the Cangjie framework and HarmonyOS ArkUI. It covers the theoretical concepts of LocalStorage as an in-memory database, practical implementation details using decorators like @LocalStorageProp and @LocalStorageLink, and the complete API reference for the LocalStorage class. Designed for Cangjie and HarmonyOS developers, these materials explain how to achieve one-way and two-way data synchronization across component trees, handle state lifecycle, and manage storage manipulation effectively.

### PersistentStorage持久化存储UI状态/
This directory focuses on the PersistentStorage singleton object within the HarmonyOS ArkUI framework, specifically designed for persisting UI state across application restarts. It covers the technical relationship between PersistentStorage and AppStorage, API definitions for Cangjie developers, and practical code examples. Key topics include data persistence constraints, supported data types (Int64, Float64, String, Bool), and synchronous operation limitations. This resource is suitable for application developers and ArkUI engineers using the Cangjie language who need to manage lightweight state persistence and ensure data consistency between sessions.
