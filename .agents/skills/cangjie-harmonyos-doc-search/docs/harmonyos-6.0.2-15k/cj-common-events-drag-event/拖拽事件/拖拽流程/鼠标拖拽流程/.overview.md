# 鼠标拖拽流程

This directory provides a comprehensive guide to implementing mouse drag-and-drop functionality within the ArkUI framework. It covers the fundamental operational logic, including the "drag and go" trigger mode and support for both intra-application and cross-application data transfer. The documentation details the complete lifecycle of drag operations, specific callback events like onDragStart and onDrop, and the precise usage of DragEvent methods for managing UI feedback and data flow. It is suitable for ArkUI developers seeking to build or customize complex drag interactions and handle specific event behaviors in their applications.

### 鼠标拖拽流程_1.md 鼠标拖拽流程_1.md
This document outlines the mouse drag functionality within the ArkUI framework, explaining the operational logic and supported scopes. It covers the drag trigger mechanism, specifically the "drag and go" mode, and the support for both intra-application and cross-application dragging. Key information includes that the drag function triggers when the left mouse button is pressed and moved more than 1vp. Additionally, it notes that developers can utilize specific ArkUI callback events to perceive drag states and modify default system behaviors. This guide targets ArkUI developers looking to implement or customize drag-and-drop features in their applications.

### 鼠标拖拽流程_2.md 鼠标拖拽流程_2.md
This document serves as a technical reference for implementing drag-and-drop functionality using specific callback events in the ArkUI framework. It details the complete lifecycle of drag operations, covering events such as onDragStart, onDragEnter, onDragMove, onDragLeave, onDrop, onDragEnd, and onPreDrag. Key takeaways include using pixelmap for drag images in onDragStart, setting visual feedback during onDragMove, and defining final results like DRAG_SUCCESSFUL in onDrop. The onPreDrag event allows handling pre-drag animation states. This guide targets application developers needing to handle complex drag interactions and data transfer within their UI components.

### 鼠标拖拽流程_3.md 鼠标拖拽流程_3.md
This document serves as a technical reference for utilizing DragEvent methods during specific stages of the drag-and-drop lifecycle in ArkUI. It details the validity of get methods for retrieving event details like coordinates and velocity across callbacks such as onDragStart and onDrop. Additionally, it specifies the execution timing for set methods like setResult and useCustomDropAnimation to ensure system acceptance. Key takeaways include that coordinate data is unavailable in onDragEnd, and only setResult called in onDrop determines the final result passed to onDragEnd. This guide targets developers implementing drag-and-drop interactions who require precise API usage rules to manage UI and data flow effectively.
