This directory contains API reference documentation for a comprehensive set of deprecated POSIX-style system functions within the Cangjie programming language. It covers low-level operations including file manipulation (access, read, write, open), process management (getpid, kill, nice), and permission handling (chmod, chown). Since all functions are marked as deprecated and scheduled for removal, this resource is primarily suitable for Cangjie developers maintaining legacy code or understanding historical system interfaces before migrating to newer APIs.
