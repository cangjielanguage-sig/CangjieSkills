# class_Window

This directory contains API reference documentation for the `Window` class in the Cangjie programming language, specifically within the WindowManager module. It covers comprehensive window management capabilities, including lifecycle management (creation, destruction), property querying (status, orientation, color space), layout manipulation (resize, move, maximize), and event handling (callbacks for size, focus, and system interactions). The documentation also details specific behaviors for 2-in-1 devices, multi-window modes, and immersive layouts. Intended for application developers, these references provide syntax, parameters, error codes, and system capability requirements to build robust graphical user interfaces.
