This directory provides comprehensive API documentation for the `WrappingOp` interface implementation specifically tailored for the `IntNative` type within the Cangjie programming language. It focuses on a wide array of arithmetic and bitwise operations that manage integer overflow via high-order truncation, ensuring that results wrap around predictably instead of triggering exceptions. The documentation covers essential functions such as addition, subtraction, multiplication, division, modulo, negation, increment, decrement, and various bit shifts. This resource is highly suitable for Cangjie developers and system-level engineers who need deterministic integer behavior in performance-critical code paths where error handling overhead is unacceptable.
