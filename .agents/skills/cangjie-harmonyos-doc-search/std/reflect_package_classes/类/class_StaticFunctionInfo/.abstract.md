This directory contains API reference documentation for the `StaticFunctionInfo` class within the Cangjie programming language's reflection framework. It covers the structural definition of static member function metadata, including properties like name, parameters, and return types. Additionally, it details methods for dynamically invoking these static functions and retrieving annotations. Key topics include reflection, dynamic invocation, type safety, and metadata inspection. This documentation is suitable for Cangjie developers who need to programmatically inspect or execute static methods at runtime, particularly those building frameworks or tools that rely on runtime type information.
