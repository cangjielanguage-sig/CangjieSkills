This directory contains technical reference documentation for data structures used in HarmonyOS and OpenHarmony application unpacking tools. It covers the schema definitions for key components such as AppInfo, AbilityInfo, HapInfo, and various configuration structures like permissions, forms, and distribution filters. The documents detail the attributes, data types, and specific rules for both FA (Feature Ability) and Stage models. This resource is essential for software developers, system integrators, and tool engineers who need to parse application bundles, configure manifests, or understand the internal metadata of HAP packages.
