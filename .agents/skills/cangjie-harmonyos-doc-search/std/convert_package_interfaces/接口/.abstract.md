This directory serves as a comprehensive repository for API documentation regarding core interfaces within the Cangjie programming language. It primarily addresses the fundamental mechanisms of data transformation, specifically focusing on type-to-string formatting, string-to-type parsing, and numeric base conversions. The content covers essential interfaces such as `Formattable`, `Parsable`, and `RadixConvertible`, detailing their implementations across various primitive data types including integers, floating-point numbers, and Runes. This documentation is vital for Cangjie developers who need to implement robust data serialization, handle user input validation, or perform complex numeric manipulations within their applications.
