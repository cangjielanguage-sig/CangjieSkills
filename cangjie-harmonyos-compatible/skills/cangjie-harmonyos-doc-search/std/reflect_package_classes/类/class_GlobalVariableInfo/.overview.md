# class_GlobalVariableInfo

This directory contains essential API reference documentation for the `GlobalVariableInfo` class, a core component of the Cangjie programming language's reflection capabilities. It serves as a technical guide for developers seeking to perform runtime introspection and manipulation of global variables. The documentation covers a wide range of features, including properties for accessing variable names, types, and mutability status, as well as methods for safely retrieving and modifying values. It also includes details on annotation handling and utility functions for comparison and string representation. This resource is specifically tailored for developers utilizing the reflection package who possess a working knowledge of Cangjie and core interfaces like Equatable and Hashable.
