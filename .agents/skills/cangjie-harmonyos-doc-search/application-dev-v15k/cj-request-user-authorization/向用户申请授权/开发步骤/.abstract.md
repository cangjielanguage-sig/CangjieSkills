This directory provides a comprehensive guide for implementing runtime permission requests in HarmonyOS applications using the Cangjie language. It covers the complete workflow from declaring permissions in configuration files to handling user authorization results, with a specific focus on location access. The tutorials detail critical implementation steps such as checking authorization status, managing permission requests within the `onWindowStageCreate` lifecycle, and creating UI triggers. It is suitable for application developers looking to master privacy management and user authorization logic in the HarmonyOS ecosystem.
