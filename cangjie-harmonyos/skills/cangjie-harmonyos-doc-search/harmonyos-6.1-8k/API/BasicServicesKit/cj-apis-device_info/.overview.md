# cj-apis-device_info

This directory serves as a comprehensive resource for the `cj-apis-device_info` module, specifically focusing on the `ohos.device_info` interface tailored for HarmonyOS development using the Cangjie programming language. It covers the functionality required to query static device attributes, such as unique identifiers, hardware specifications, system build details, and version numbers. The documentation highlights that all properties are read-only and outlines the permission requirements for accessing sensitive data. This resource is ideal for HarmonyOS application developers looking to integrate device metadata for logic implementation, statistical analysis, or device adaptation, keeping in mind the module is currently in Beta.

## Detailed Description

### ohosdevice_info设备信息/

This subdirectory hosts the detailed documentation for the `ohos.device_info` module, a critical component for developers working within the HarmonyOS ecosystem using the Cangjie language. The module is engineered to facilitate the retrieval of static device properties, ensuring applications can access essential data points like device identifiers, hardware specifications, system build information, and various version numbers.

Key characteristics of this module include its read-only attribute design, which ensures data integrity by preventing modifications to device settings through this interface. Developers should note that accessing certain sensitive information types is gated behind specific permission requirements. As the module is currently in the Beta stage, it is primarily targeted at HarmonyOS application developers who require robust device metadata to drive application logic, perform data statistics, or ensure proper adaptation across different device configurations.
