## func borderWidth(?EdgeWidths)

```cangjie
func borderWidth(value: ?EdgeWidths): T
```

**功能：** 设置组件的边框宽度。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 22

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|value|?[EdgeWidths](./cj-common-types.md#class-edgewidths)|是|-|边缘宽度。|

**返回值：**

|类型|说明|
|:---|:---|
|T|返回调用此接口的组件实例本身。|
