## Detailed Description

### fs_package_exceptions.md fs_package_exceptions.md

This document serves as API reference documentation for the file system exception handling class within the Cangjie standard library. It details the FSException class, which inherits from IOException, and documents its two public constructors: a default initializer and one accepting a custom error message string. The key takeaway is that FSException is designed to handle file stream errors, allowing developers to instantiate exceptions either without specific details or with a descriptive message parameter for debugging. This reference is intended for Cangjie developers implementing file system operations who need to understand how to throw or catch file-related exceptions.
