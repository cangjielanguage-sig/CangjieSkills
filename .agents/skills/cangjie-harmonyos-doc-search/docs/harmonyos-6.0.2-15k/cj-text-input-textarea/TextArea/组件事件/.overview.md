# 组件事件

This directory contains API reference documentation for component events within the ArkUI framework, specifically utilizing the Cangjie language. It focuses on the event handling mechanisms for text input components, covering a wide range of interactions from basic content changes to complex edit state monitoring. Key topics include event callbacks for text modification, clipboard operations, cursor management, and the interception of insertion or deletion actions. This documentation is essential for developers who need to implement robust text input controls, validate user input in real-time, and manage the lifecycle of text editing within their ArkUI applications.

### func_onEditChangedBool_-_U_6more.md
This document provides API reference documentation for text input event handling functions in the Cangjie language within the ArkUI framework. It covers six main callback functions: `onEditChanged`, `onPaste`, `onSubmit`, `onTextSelectionChange`, `onWillDelete`, and `onWillInsert`. Key information includes monitoring edit states, capturing paste operations, handling Enter key submissions, tracking text selection, and intercepting text insertion or deletion before execution. Notably, the `onWillDelete` and `onWillInsert` functions allow developers to control text modification by returning boolean values. These features are intended for developers requiring granular control over text input behaviors and validation in their applications.
