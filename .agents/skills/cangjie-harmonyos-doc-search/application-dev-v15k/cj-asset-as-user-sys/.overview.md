# cj-asset-as-user-sys

This directory serves as a comprehensive technical resource for system developers operating within the Cangjie framework, specifically addressing the complexities of managing critical assets in a single-instance, multi-user environment. It provides detailed guidance on how system applications can designate specific user spaces to ensure robust data isolation and security. The documentation covers critical operational scenarios, such as managing active users and defining specific asset accessibility types, which are essential for maintaining system integrity. Additionally, it outlines the necessary system constraints, including the requirement for the `ohos.permission.INTERACT_ACROSS_LOCAL_ACCOUNTS` permission, and provides a thorough overview of the ASSET interfaces—add, remove, update, and query. This guide is indispensable for developers seeking to implement secure, user-specific asset management and enforce rigorous access control in their system-level applications.
