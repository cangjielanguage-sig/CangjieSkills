This directory provides comprehensive technical specifications for the encoding and structural formats of cryptographic key materials within the HUKS framework. It covers the standardized binary layouts for public keys, private keys, and key pairs across various algorithms such as RSA, ECC, and DSA. The documentation details X.509 DER encoding, memory offsets, and byte-level structures essential for key import and export operations. It is designed for software developers, cryptographers, and security engineers implementing low-level key management, serialization, and storage mechanisms in systems like Cangjie.
