# cj-universal-attribute-size

This directory serves as a comprehensive resource for the `cj-universal-attribute-size` module within the Cangjie ArkUI framework. It focuses on the universal attributes that govern component sizing and layout configuration. The documentation covers essential APIs for setting dimensions (width, height), managing spacing (margin, padding), and applying layout constraints (constraintSize, layoutWeight). It is designed to assist developers in controlling component boundaries, managing overflow scenarios, and distributing space proportionally within parent containers such as Row or Column. This resource is highly suitable for software developers and UI engineers building responsive HarmonyOS applications using the Cangjie language who need precise control over layout mechanics and component sizing behavior.
