This directory contains API reference documentation for the `TypeInfo` class in the Cangjie programming language, focusing on runtime reflection and type inspection. It covers the core interface for accessing type metadata, including annotations, properties, and functions. The documentation details how to retrieve static and instance members, check subtype relationships, and handle type names. It is suitable for Cangjie developers and system architects who need to perform meta-programming tasks or dynamic type analysis using the `std.reflect` package.
