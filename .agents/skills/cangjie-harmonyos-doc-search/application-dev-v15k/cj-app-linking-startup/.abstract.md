This directory serves as a comprehensive startup guide for implementing App Linking within the HarmonyOS ecosystem, specifically tailored for developers utilizing the Cangjie language. It addresses the critical need for secure inter-app navigation and deep linking capabilities. The content spans the complete development lifecycle, beginning with the initial configuration steps in AppGallery Connect (AGC) and moving through to the client-side implementation in DevEco Studio. Furthermore, it provides essential insights into domain verification, handling incoming link requests, and troubleshooting common integration or routing conflicts. This resource is highly suitable for developers responsible for creating either the calling (source) or target applications, ensuring seamless connectivity and user experience across different software components.
