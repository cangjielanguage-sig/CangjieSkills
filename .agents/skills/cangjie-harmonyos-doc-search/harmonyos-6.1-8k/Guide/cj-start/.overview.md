# cj-start

The `cj-start` directory serves as the comprehensive entry point for developers adopting the Cangjie programming language within the HarmonyOS and OpenHarmony ecosystems. It acts as a centralized hub for resources, covering everything from initial environment setup and Beta feature exploration to deep dives into architectural concepts. This directory is specifically tailored for beginners and experienced developers seeking to master the Stage model, application package lifecycle, and IDE configuration. By providing a structured learning path and essential navigation aids, it enables users to build a systematic understanding of Cangjie development efficiently.
