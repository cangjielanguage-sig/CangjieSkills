This directory provides API reference documentation for the HarmonyOS Universal KeyStore (HUKS) system implemented in the Cangjie programming language. It covers comprehensive resources for managing hardware-backed cryptographic keys, including key generation, storage, import, export, and secure operations like encryption, decryption, and signing. The documentation details essential classes for configuration parameters (algorithms, padding, digests), data structures for options and results, and functions for session management and key lifecycle. It is suitable for HarmonyOS developers and security engineers building secure applications that require robust key management and cryptographic capabilities within the OpenHarmony ecosystem.
