# AESGCMNoPadding

This directory provides a comprehensive collection of technical documentation and code examples dedicated to implementing AES-GCM (Galois/Counter Mode) encryption without padding using the HarmonyOS Universal Keystore Kit (HUKS) and the Cangjie programming language. It covers the complete lifecycle of cryptographic operations, including key generation, parameter configuration, and the specific handling of Nonce, Associated Data (AAD), and AE tags. The resources detail the session-based workflow required for secure data processing. This material is highly suitable for HarmonyOS developers, system architects, and security engineers seeking to integrate advanced encryption standards into their applications for secure data storage and transmission, ensuring compliance with modern security protocols.

## Detailed Description

### AESGCMNoPadding_1.md AESGCMNoPadding_1.md
This document provides a Cangjie code example demonstrating AES/GCM/NoPadding encryption and decryption using the Universal Keystore Kit (HUKS). Key topics include configuring properties for key generation, encryption, and decryption, specifically handling parameters like Nonce, Associated Data (AAD), and AE tags within the HUKS framework. The code illustrates the setup of HuksParam arrays for AES-128 keys, emphasizing the configuration of algorithm, padding, and block mode. It also details the extraction of the AE tag from ciphertext for the decryption process. Targeted at HarmonyOS developers using Cangjie, this tutorial serves as a practical guide for implementing secure cryptographic operations and key management.

### AESGCMNoPadding_2.md AESGCMNoPadding_2.md
This document provides code examples demonstrating how to perform AES-GCM encryption and decryption without padding using the HarmonyOS Universal KeyStore (HUKS) API. The content is divided into three main functions: encrypting plaintext, decrypting ciphertext, and deleting the key. Key takeaways include the session-based workflow utilizing initSession and finishSession, the use of a key alias for operations, and specific data handling during decryption to manage the authentication tag. This tutorial serves as a practical guide for developers implementing secure data storage and transmission in HarmonyOS applications.
