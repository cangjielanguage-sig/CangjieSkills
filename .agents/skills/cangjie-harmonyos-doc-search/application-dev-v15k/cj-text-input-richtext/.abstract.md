This directory serves as a comprehensive technical resource for the `cj-text-input-richtext` module, specifically focusing on the RichText component within the Cangjie framework and HarmonyOS ecosystem. It covers the essential functionality required to parse and display HTML strings effectively, bridging the gap between web content and native applications. The content includes detailed API references, component creation methods, and supported universal attributes, alongside critical performance considerations like memory usage in Lists. Designed for ArkUI developers, this documentation provides practical implementation examples and best practices for integrating web content, ensuring a balance between theoretical knowledge and efficient coding. It is particularly suitable for developers looking to enhance user interfaces with formatted text and web-like content rendering while maintaining high application performance.
