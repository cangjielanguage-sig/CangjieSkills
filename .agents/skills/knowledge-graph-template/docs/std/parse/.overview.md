# parse

This directory provides a technical overview and tutorial for parsing Cangjie source code into Abstract Syntax Tree (AST) objects, a critical step in the compilation and metaprogramming process. It explores the standard library's parsing capabilities, specifically focusing on the `std.ast.*` module. The documentation covers the essential workflows for converting text-based code into structured AST nodes, distinguishing between parsing isolated declarations—such as classes—and parsing complete source files that encompass packages, imports, and macro definitions. Furthermore, it addresses the practical aspects of AST manipulation, including token handling, pattern matching for specific node types like `ClassDecl`, and structural inspection using the `dump()` method. This resource is highly suitable for Cangjie developers, language tooling creators, and compiler engineers who possess a solid understanding of the language's syntax and wish to leverage ASTs for advanced code analysis, transformation, or building custom development tools. By mastering these parsing functions, developers can gain deeper insights into code structure and automate complex syntax-related tasks.
