This directory serves as a comprehensive reference for the deprecated data structures found within the Cangjie runtime package, specifically focusing on the retrieval of system and runtime statistics. It provides detailed documentation for three key structs: `MemoryInfo`, which was used for heap memory metrics; `ProcessorInfo`, designed for accessing processor counts; and `ThreadInfo`, utilized for gathering thread statistics. A central theme of this documentation is the deprecation of these structs in favor of a more modern, function-based API. Developers will find guidance on how static properties, such as `allocatedHeapSize` and `threadCount`, have been replaced by specific global functions like `getAllocatedHeapSize` and `getThreadCount`. This resource is essential for Cangjie developers who are maintaining legacy codebases or actively migrating applications to ensure compatibility with the latest runtime environment standards.
