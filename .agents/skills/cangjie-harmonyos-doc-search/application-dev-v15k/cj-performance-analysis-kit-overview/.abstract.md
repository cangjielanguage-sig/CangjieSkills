This directory hosts the overview documentation for the Performance Analysis Kit, a comprehensive suite of tools engineered to help developers observe application runtime states for behavior, fault, and security analysis. It extensively covers the kit's capability scope, including HiLog, HiTraceMeter, HiAppEvent, FaultLogger, and HiDebug, alongside key highlights such as APM construction and exception handling. The documentation is intended for developers with programming and OS knowledge, serving as an essential reference guide for integrating these tools into DevEco Studio workflows. By leveraging this kit, developers can facilitate custom APM SDK development, record distributed traces, and manage fault logs to diagnose and resolve issues like crashes and resource leaks, ultimately ensuring application stability and a superior user experience.
