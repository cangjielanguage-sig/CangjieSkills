# 完整示例

This directory provides a comprehensive collection of complete code examples designed to help developers implement audio recording functionality within HarmonyOS applications. It covers the entire development process, ranging from system-level permission declarations and context acquisition to the specific logic required for audio capture and data storage. The examples are presented in both Cangjie and ArkTS, offering flexibility depending on the chosen development language. Key topics include the AudioCapturer module, PCM data handling, and state management. This resource is ideal for HarmonyOS developers seeking practical, end-to-end solutions for integrating microphone capabilities and managing the audio capture lifecycle in their apps.

## Detailed Description

### 完整示例_1.md 完整示例_1.md
This document provides a complete code example demonstrating how to implement audio recording using the AudioCapturer module in the Cangjie language. It covers three essential steps: obtaining the UIAbilityContext, declaring microphone permissions in configuration files, and implementing the audio capture logic with data callbacks. The code details setting audio parameters like sample rate and channel configuration, handling file I/O to save PCM data, and managing the application context. This tutorial targets HarmonyOS developers using Cangjie who need to integrate microphone functionality into their applications.

### 完整示例_2.md 完整示例_2.md
This document provides a complete code example demonstrating how to implement audio capture functionality in a HarmonyOS application using ArkTS. Main sections include requesting microphone permissions via the AbilityAccessCtrl manager, initializing the AudioCapturer with read data callbacks, and managing the audio capture lifecycle through start, stop, and release methods. Key information highlights the strict state management required for the AudioCapturer, ensuring operations like start or stop only occur in valid states such as PREPARED or RUNNING. Intended for application developers, this guide serves as a practical reference for integrating audio recording features and handling runtime permissions. Keywords: HarmonyOS, ArkTS, AudioCapturer, Microphone Permission, Audio Capture.

### 完整示例_3.md 完整示例_3.md
This document provides a complete code example demonstrating the user interface implementation for controlling an audio capturer in a HarmonyOS application. The content focuses on the build function, utilizing declarative UI components like Row, Column, and Button to create a control panel. It outlines the standard lifecycle management for audio capturing, including requesting permissions, initializing the capturer, starting and stopping the recording, and releasing resources. This snippet targets application developers using ArkTS who need to implement audio recording functionality and manage the corresponding UI interactions.
