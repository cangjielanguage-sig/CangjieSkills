This directory provides comprehensive documentation and practical code examples for handling HTTP cookies within the Cangjie programming language ecosystem. It addresses the dual aspects of web state management: the client-side perspective, focusing on receiving, storing, and resending cookies via a `CookieJar`, and the server-side perspective, detailing how to construct servers that issue `Set-Cookie` headers to clients. The tutorials leverage Cangjie's standard library extensions, covering essential networking concepts such as request lifecycles, response parsing, synchronization primitives, and socket communication. This resource is ideal for Cangjie developers aiming to build robust, stateful web applications or those seeking a deeper understanding of network programming and session persistence protocols. By exploring these examples, developers can master the mechanisms required to maintain user sessions and state across multiple HTTP requests.
