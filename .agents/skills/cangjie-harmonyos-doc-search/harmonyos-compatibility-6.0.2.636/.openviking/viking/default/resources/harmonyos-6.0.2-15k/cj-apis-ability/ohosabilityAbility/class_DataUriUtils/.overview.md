# class_DataUriUtils

This directory provides comprehensive API reference documentation for the `DataUriUtils` class, a core component of the Cangjie language designed for the HarmonyOS AbilityKit framework. It focuses on the manipulation of Uniform Resource Identifiers (URIs) by managing numeric identifiers embedded within URI paths. The documentation details essential static methods for attaching, deleting, retrieving, and updating these IDs. It includes specifications on parameters, return values, system capabilities, and error handling—specifically addressing parameter validation failures (error code 401). This resource is tailored for HarmonyOS application developers and Cangjie programmers who require robust tools for programmatically managing data URIs and resource identifiers during system runtime operations, ensuring precise control over data access and routing.

## Detailed Description

### class_DataUriUtils_4more.md

This document serves as API reference documentation for the DataUriUtils class in the Cangjie language, designed to manipulate URIs by managing numeric identifiers. It covers three static methods: attachId, deleteId, and getId, detailing their parameters, return values, and system capabilities. Key information includes the requirement for String URIs and Int64 IDs, alongside error handling for parameter validation failures (error code 401). The document provides code examples demonstrating exception handling. Targeted at HarmonyOS application developers using the AbilityKit, this guide facilitates the programmatic management of data IDs within URI paths for system runtime operations.

### static_func_updateIdString_Int64.md

This document serves as API reference documentation for the Cangjie function updateId, designed to modify the ID segment within a given URI string. The content covers the function signature, system capabilities, version requirements, a detailed parameter table, return value specifications, and potential exceptions including error code 401 for parameter issues. Key takeaways include that the function accepts a String URI and an Int64 ID, returning the updated URI string, and throws a BusinessException if validation fails. This reference guide targets Cangjie developers working with URI manipulation within the AbilityKit framework, specifically those needing to programmatically update resource identifiers in URIs.
