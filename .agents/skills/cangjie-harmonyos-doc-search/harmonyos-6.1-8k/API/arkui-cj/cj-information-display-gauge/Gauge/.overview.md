# Gauge

本目录包含ArkUI框架中Gauge（数据量规）组件的完整开发文档，主要面向使用仓颉（Cangjie）语言的开发者。内容涵盖了组件的基础API参考、初始化配置（如数值范围校验）以及视觉样式的深度定制。通过这些文档，开发者可以快速掌握如何创建环形数据图表，并精细控制其外观与行为。适用于需要实现数据可视化、仪表盘界面或高度自定义量规图的应用场景。
