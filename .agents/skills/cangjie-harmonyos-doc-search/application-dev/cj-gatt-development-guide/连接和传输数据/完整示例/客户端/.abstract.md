This directory contains technical documentation and code examples for implementing Bluetooth Low Energy (BLE) GATT clients, primarily using ArkTS and Cangjie within the HarmonyOS ecosystem. It covers the complete client-side lifecycle, including connection management, service discovery, reading and writing characteristics, handling descriptors, and managing notifications. The content is designed for software developers building IoT or mobile applications that require robust Bluetooth connectivity, providing specific logic for state management, asynchronous callbacks, and resource cleanup.
