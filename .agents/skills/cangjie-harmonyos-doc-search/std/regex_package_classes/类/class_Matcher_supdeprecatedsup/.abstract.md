This directory contains API reference documentation for the deprecated Cangjie Matcher class and its associated regular expression functions. It covers legacy pattern matching capabilities, including scanning input sequences, finding matches, replacing text, and splitting strings. Key topics include the Matcher constructor, methods like `findAll`, `replace`, and `split`, as well as state management functions. The documentation highlights that this class is deprecated in favor of the Regex class. It is suitable for Cangjie developers maintaining legacy code or migrating existing applications to modern regex implementations.
