# 常见使用问题

本目录汇集了使用仓颉语言开发ArkUI应用时遇到的常见问题及解决方案。主要涵盖了List组件的滚动加载优化、LazyForEach的数据更新机制以及屏幕闪烁和渲染异常等UI交互问题的排查与修复。文档重点讲解了如何通过`notifyDatasetChange`、`DataAddOperation`以及`keyGenerator`的正确配置来提升性能和确保渲染正确性。这些内容适合正在使用仓颉进行ArkUI开发，特别是涉及动态列表数据处理和性能优化的开发者参考。

## 详细描述

### 在List内使用屏幕闪烁
本文档旨在解决在List组件滚动加载时使用onDataReloaded导致的屏幕闪烁问题。文档主要涵盖了问题复现的代码示例及优化方案，对比了使用notifyDataReload与notifyDatasetChange的区别。关键信息指出，在List的onScrollIndex中触发数据加载时，应避免全量刷新，改用notifyDatasetChange配合DataAddOperation进行增量更新，这不仅能消除闪烁还能提升加载性能。本文档属于开发最佳实践指南，适用于使用仓颉语言开发ArkUI应用，特别是涉及List和LazyForEach动态数据加载场景的开发者。关键词包括List、屏幕闪烁、LazyForEach、notifyDatasetChange、数据加载优化。

### 渲染结果非预期
本文档旨在解决LazyForEach在列表删除操作中出现的渲染非预期问题。文档分析了因索引未更新导致误删数据项的原因，并提供了修复方案。关键点在于删除数据后调用reloadData方法，并通过修改keyGenerator（如结合index生成key）强制重建后续子组件以更新索引。这是一份面向Cangjie开发者的故障排查指南，重点讲解了动态列表更新机制及key生成策略，帮助开发者确保列表交互的正确性。
