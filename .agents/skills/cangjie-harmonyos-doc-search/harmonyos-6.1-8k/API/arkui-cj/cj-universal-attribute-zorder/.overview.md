### cj-universal-attribute-zorder.md cj-universal-attribute-zorder.md

本文档是ArkUI框架中用于控制组件Z轴堆叠顺序的zIndex属性的权威参考。它详细介绍了模块导入方式、zIndex函数的完整定义、参数说明以及返回值类型。核心功能在于通过设置Int32类型的zIndex值来决定组件的显示层级，遵循“数值越大层级越高”的原则，默认值为0。为了帮助开发者更好地理解，文档特别提供了Stack容器中的代码示例，生动演示了如何利用zIndex调整重叠组件的覆盖关系。这是面向使用仓颉语言进行ArkUI应用开发者的必备API参考文档，旨在帮助开发者实现复杂且精细的界面布局控制，确保UI元素按预期顺序呈现。
