# cangjie-load-arkts

This directory contains essential documentation for developers utilizing the Cangjie programming language to build applications within the HarmonyOS ecosystem. It specifically addresses the technical challenges and solutions for interoperability between Cangjie and ArkTS, the primary language for UI development in HarmonyOS. The content covers the complete workflow of importing external modules, ranging from standard HAR and HSP packages to Native and System-level modules. By detailing the `requireArkModule` interface and its associated thread constraints, this guide helps developers create robust, modular applications that effectively bridge different programming languages. It is intended for experienced HarmonyOS developers who have a strong understanding of modular architecture, multi-threaded programming principles, and the specific nuances of cross-language memory management.

Additionally, the documentation emphasizes the critical importance of thread constraints. It explains how to safely manage cross-language calls across different threads to avoid concurrency issues and data races.

Finally, the document identifies the ideal audience for this technology: HarmonyOS developers engaged in complex, modular application development.
