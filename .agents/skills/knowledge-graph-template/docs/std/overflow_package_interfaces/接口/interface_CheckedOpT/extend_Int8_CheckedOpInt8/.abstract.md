This directory contains API reference documentation for the `CheckedOp` interface implementation specifically for the `Int8` type within the Cangjie programming language. It focuses on safe integer arithmetic operations, providing mechanisms to handle overflow scenarios gracefully without throwing runtime errors. The content covers a comprehensive range of arithmetic methods, including addition, subtraction, multiplication, division, negation, and bit manipulation. All these operations utilize `Option` return types to ensure robustness. This documentation is highly suitable for Cangjie developers who need to implement error-safe mathematical computations and bit logic in their applications, effectively preventing unexpected behavior during edge cases such as arithmetic overflow or invalid shift amounts. By utilizing these checked operations, developers can write more predictable and stable code.
