This directory contains API reference documentation for deprecated classes within the Cangjie programming language, specifically focusing on console input and output (I/O) operations. It covers the `Console`, `ConsoleReader`, and `ConsoleWriter` classes, detailing their interfaces for standard streams, synchronous buffered reading, and thread-safe writing. The content emphasizes deprecation notices and migration paths to the `env` package. This documentation is suitable for Cangjie developers maintaining legacy systems or requiring a deep understanding of historical console stream handling, data types like `Rune` and `String`, and exception strategies.
