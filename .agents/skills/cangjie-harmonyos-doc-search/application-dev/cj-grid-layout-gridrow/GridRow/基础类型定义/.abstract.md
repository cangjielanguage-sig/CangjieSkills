This directory defines fundamental data types and configurations for building responsive grid layouts within the ArkUI framework using the Cangjie programming language. It covers essential classes for managing breakpoints, grid row options, gutter spacing, and size options across various device screen sizes (xs to xxl). Additionally, it includes enumerations for layout references and directions. These definitions are crucial for developers aiming to create adaptive user interfaces that respond dynamically to different viewport dimensions. The documentation is suitable for Cangjie developers and UI engineers working on system capabilities requiring ArkUI.Full support.
