# hot_update_cert

本目录提供了关于在Cangjie服务器应用中实现TLS证书热更新功能的详细指南。它深入探讨了如何在不中断服务的情况下动态更换证书，重点涵盖了`MyServer`类的具体实现细节、`TlsServerConfig`的配置管理策略，以及利用属性设置器来动态更新证书链和私钥的技术手段。文档的核心机制在于确保证书配置的修改仅对新建连接生效，从而保证现有连接的稳定性，通过在`onAcceptedConnection`回调中引用当前配置对象来实现无缝切换。该资源非常适合那些需要维护高可用网络服务的Cangjie开发者阅读，要求读者具备基础的网络编程知识和对TLS安全协议的理解。

## 详细说明

### hot_update_cert.md hot_update_cert.md

本文档演示如何在Cangjie服务器应用中实现TLS证书的热更新功能。

涵盖了MyServer类的实现、TlsServerConfig的配置管理以及通过属性设置器动态更新证书链和私钥的方法。

核心要点在于修改证书配置仅对新建连接生效，现有连接不受影响，通过在onAcceptedConnection中引用当前配置对象实现无缝切换。

面向需要维护高可用网络服务的Cangjie开发者，要求具备基础的网络编程和TLS安全协议知识。
