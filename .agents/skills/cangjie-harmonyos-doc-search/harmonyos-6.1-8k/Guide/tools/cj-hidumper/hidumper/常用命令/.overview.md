# 常用命令

本目录汇集了OpenHarmony系统中hidumper调试工具的常用命令参考指南。文档内容涵盖了系统基础信息查询、核心服务状态监控（如窗口、渲染、电源）、性能数据统计（CPU、内存、网络、IPC）以及高级内存分析（JS堆内存、内存映射）。这些资料旨在帮助系统开发者和维护人员快速掌握命令行工具的使用，以便高效地进行系统状态监控、故障日志转储及性能调优。

### 常用命令_1.md 常用命令_1.md

### 常用命令_2.md 常用命令_2.md
本文档是一份系统调试工具hidumper的常用命令参考指南，旨在指导用户如何通过命令行获取系统各服务的运行状态和调试信息。文档主要涵盖了WindowManagerService（窗口信息）、RenderService（渲染性能、FPS及内存）、PowerManagerService（屏幕休眠控制）以及Faultlog（崩溃日志）四个核心模块。内容详细列出了各服务的参数选项、功能定义及具体执行示例，帮助开发者快速定位窗口管理、图形渲染、电源管理及系统崩溃等问题。

### 常用命令_3.md 常用命令_3.md
本文档是OpenHarmony系统中hidumper命令行工具的参考指南，旨在帮助用户查询系统性能和状态信息。主要内容包括获取网络流量、存储I/O、进程列表、CPU使用率、CPU频率及内存统计等命令的使用方法。文档详细列出了命令语法、实际操作样例及输出结果，并特别说明了进程信息命令在发布版本中的限制及版本区分方法。该文档适用于需要监控系统资源或进行应用调试的开发者和系统维护人员。

### 常用命令_4.md 常用命令_4.md
本文档作为技术参考指南，介绍了如何使用hidumper工具分析系统内存、导出诊断日志以及监控进程间通信（IPC）性能。文档涵盖了三个主要功能：获取特定或所有进程的详细内存使用统计，将命令输出压缩保存至指定目录，以及收集包含时间消耗和调用次数的IPC统计数据。关键信息包括内存检查的语法（--mem），自动生成的压缩文件路径，以及IPC统计的工作流程，该流程需要依次执行开始、查询和停止监控操作。本指南面向系统开发者和维护人员，要求具备Linux进程管理和系统调试的基础知识，以便有效解读Pss/Vss等内存指标和IPC接口性能数据。

### 常用命令_5.md 常用命令_5.md
