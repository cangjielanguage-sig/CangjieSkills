This directory provides comprehensive guidelines and technical recommendations for adapting custom application layouts to ensure full compatibility with the Password Vault feature. It addresses critical scenarios including login, registration, and password modification, specifically focusing on UI patterns that may restrict core functionalities like credential autofill. Key topics include identifying unsupported layouts such as split-screen inputs and verification code logins, as well as managing autofill states during authentication failures. This documentation is essential for application developers and UI designers who are building custom authentication flows and need to integrate seamless, secure password management services without compromising user experience or functionality. By following these guidelines, developers can avoid common pitfalls that lead to restricted functionality and ensure a smooth integration of password vault services.
