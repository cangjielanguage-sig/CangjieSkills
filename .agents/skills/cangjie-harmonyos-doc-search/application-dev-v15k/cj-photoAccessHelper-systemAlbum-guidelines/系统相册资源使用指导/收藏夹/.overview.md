# 收藏夹

This directory serves as a comprehensive technical resource for developers utilizing the Cangjie programming language in conjunction with the MediaLibraryKit. It focuses specifically on the mechanisms required to interact with the system's Favorites album, providing a deep dive into media access protocols. The content covers critical development steps, including initializing the photo access helper, configuring application permissions, and employing specific APIs to retrieve album objects and media assets. Through detailed step-by-step instructions and practical code examples, these guides enable developers to build features that read or manage user-favorited content effectively. This collection is highly suitable for HarmonyOS developers and application engineers seeking to integrate robust media library access and management capabilities into their software projects. The documentation ensures a smooth development experience by clarifying prerequisites and providing clear implementation paths.

## Detailed Description

### 收藏夹_2more.md
This technical tutorial explains how to access the system Favorites album using the MediaLibraryKit in the Cangjie programming language. The document defines the Favorites album functionality and details the process of retrieving the album object via the getAlbums API. Key sections include prerequisites such as obtaining the photoAccessHelper instance and applying for read permissions, followed by step-by-step development instructions. The text provides Cangjie code examples demonstrating how to set album type parameters to SYSTEM and FAVORITE to fetch the album. This guide targets application developers who need to programmatically interact with user-favorited media content.

### 获取收藏夹中的图片和视频.md
This tutorial guides developers on retrieving images and videos from the system favorites album using the MediaLibraryKit in Cangjie. It covers prerequisites such as obtaining the photoAccessHelper instance and applying for the READ_IMAGEVIDEO permission. The document details a step-by-step process to fetch the favorite album object, establish retrieval conditions, and access media assets using the getAssets and getFirstObject interfaces. Key takeaways include the provided code examples demonstrating how to handle FetchResult objects and manage resource closure. This guide is intended for HarmonyOS developers implementing media access features in their applications.
