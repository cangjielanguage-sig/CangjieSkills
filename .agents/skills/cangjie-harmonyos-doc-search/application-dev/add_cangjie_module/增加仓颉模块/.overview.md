# 增加仓颉模块

This directory provides comprehensive tutorials for integrating Cangjie modules into HarmonyOS ArkTS projects using DevEco Studio. It focuses on enabling interoperability between the ArkTS and Cangjie programming languages, covering various integration scenarios such as adding modules within the same project and incorporating static library modules. Key technical aspects include configuration file generation (cjpm.toml, oh-package.json5), dependency management, and the implementation of cross-language function calls. These resources are specifically tailored for HarmonyOS developers who wish to extend their applications by combining the robust features of ArkTS with the capabilities of the Cangjie language.

## Detailed Description

### 增加仓颉模块_2more.md 增加仓颉模块_2more.md
This tutorial guides developers on integrating Cangjie modules into ArkTS projects within DevEco Studio to enable interoperability. The primary section details adding a Cangjie module within the same module, covering file creation, configuration generation, and dependency management. Key information includes the automatic generation of cjpm.toml, the cangjie folder containing index.cj, and updates to oh-package.json5. Once configured, developers can import the shared library and call Cangjie functions directly in ArkTS code. This guide targets HarmonyOS developers using DevEco Studio who need to combine ArkTS and Cangjie languages in a single application.

### 添加仓颉静态库模块.md 添加仓颉静态库模块.md
This tutorial guides developers through integrating a Cangjie static library module into an ArkTS project to enable cross-language interoperability. The document details the step-by-step process of creating the module, writing Cangjie interop code, defining TypeScript declarations, and configuring package dependencies. Key steps include exposing functions via JSModule in Cangjie, creating corresponding .d.ts files, and linking them in oh-package.json5. It also provides an example of calling the Cangjie function within ArkTS code. A critical warning prohibits importing the interop module into other modules to prevent content loss. This guide targets HarmonyOS developers working with ArkTS and Cangjie languages.
