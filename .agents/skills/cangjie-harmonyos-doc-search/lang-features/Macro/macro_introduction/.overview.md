# macro_introduction

本目录深入介绍了仓颉编程语言中宏系统的核心概念与应用。宏作为一种强大的元编程工具，允许开发者像编写函数一样编写能够接收和生成代码的逻辑。本目录内容涵盖了宏的基本定义、声明方式、调用语法（使用 `@` 符号）、宏包的组织结构以及完整的编译流程。特别强调了宏必须定义在独立的 `macro package` 中，并详细讲解了如何导入 `std.ast.*`、使用 `Tokens` 类型处理输入流，以及利用 `quote` 表达式和插值语法 `$(...)` 来构造输出代码。本目录适合希望提升代码抽象能力、减少重复代码的仓颉语言开发者，通过具体的 `dprint` 示例，帮助读者快速建立对元编程的认知，为后续深入学习复杂的 `Tokens` 操作和 `quote` 表达式奠定坚实基础。
