# cj-photoAccessHelper-resource-guidelines

This directory acts as a central repository of technical guidelines for developers working with the Cangjie programming language, specifically those tasked with implementing media management capabilities in their applications. It provides a structured approach to using the `photoAccessHelper` interface and `MediaLibraryKit`, enabling the effective handling of image and video assets. The scope of the documentation includes critical lifecycle operations such as querying the media database, renaming files, deleting resources, and generating thumbnails. It is an essential resource for Cangjie developers, detailing the mandatory prerequisites like module instance initialization and permission application. By adhering to these guidelines, developers can ensure their applications securely access media files, manage metadata correctly, and integrate visual content into the UI with high performance and reliability.

## Detailed Description

### 媒体资源使用指导/
This directory contains comprehensive guides designed to assist developers in managing media resources—specifically images and videos—within applications developed using the Cangjie language. It focuses on the practical implementation of the MediaLibraryKit and the photoAccessHelper interface, which are the core tools for interacting with the system media library. The documentation thoroughly covers essential operations required for media manipulation, such as querying for specific assets based on criteria, renaming files to maintain organization, deleting obsolete resources, and retrieving thumbnails to enhance user interface responsiveness. Furthermore, the guide is tailored specifically for Cangjie developers, outlining critical prerequisites that must be addressed before any media operation can occur. These include obtaining the correct module instances and successfully applying for the necessary system permissions. Key topics also extend to asset manipulation strategies, metadata management for sorting and filtering, and the technical integration of media assets into the application's UI for optimal user experience. By mastering these concepts, developers can build applications that handle media content efficiently, respecting user privacy and system constraints while delivering rich visual functionality.
