This directory contains API reference documentation for cryptographic key classes in the Cangjie programming language. It covers the management, encoding, decoding, and usage of asymmetric keys, specifically focusing on ECDSA, RSA, and SM2 algorithms. The documentation details operations such as key generation, encryption, decryption, signing, and verification across both public and private key implementations. It is suitable for software developers and security engineers implementing robust cryptographic solutions, handling formats like PEM and DER, and managing exceptions via `CryptoException`.
