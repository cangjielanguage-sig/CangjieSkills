# interface_ParsableT

This directory contains API documentation for the Cangjie language's `Parsable` interface and its type-specific extensions. It covers the standardization of string-to-type conversions for primitive data types, including Booleans, Integers (signed and unsigned), Floating-point numbers, and Runes. The documentation details two primary parsing methods: `parse` for exception-based error handling and `tryParse` for safe, Option-based error handling. This resource is suitable for Cangjie developers seeking robust mechanisms for parsing string inputs into specific data types, handling conversion errors, and understanding type system constraints.
