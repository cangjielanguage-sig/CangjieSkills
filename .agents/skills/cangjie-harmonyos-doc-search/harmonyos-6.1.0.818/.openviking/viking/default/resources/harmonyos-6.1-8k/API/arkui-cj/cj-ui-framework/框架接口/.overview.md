# 框架接口

本目录包含ArkUI框架的核心接口文档，主要面向使用仓颉语言进行应用开发的开发者及框架维护人员。内容涵盖了UI组件的基础类定义（如CustomView和RemoteView）以及用于动态UI构建的绑定函数。重点介绍了声明式UI的构建机制、组件生命周期管理及@Builder函数的绑定方式。文档明确区分了框架内部接口与应用开发接口，旨在帮助开发者正确理解和使用ArkUI框架的基础能力，避免误用内部API导致不可预期行为。核心关键词包括ArkUI、CustomView、RemoteView、bind函数、声明式UI及仓颉语言。

## 详细说明

### class_CustomView_fb897c8c.md class_CustomView_fb897c8c.md
本文档是ArkUI框架中CustomView类的API参考文档，定义了UI框架使用的组件基础类。文档涵盖了类定义、继承自RemoteView的关系，以及build、getLocalStorage、aboutToBeDeleted和getUIContext等核心方法。关键信息在于该类及其大部分方法仅供框架内部使用，应用开发者不应调用，否则可能产生不可预期行为，但build函数是定义自定义组件声明式UI描述的必需函数。主要面向框架开发者，文档明确警告应用开发者勿用。关键词：CustomView、ArkUI、API参考、内部使用、声明式UI。

### func_bindT1_T2_T3_2more_f1e37999.md func_bindT1_T2_T3_2more_f1e37999.md
本文档是ArkUI框架的Cangjie语言API参考，主要介绍了`bind`泛型函数和`RemoteView`抽象类。`bind`函数用于将`@Builder`修饰的函数与自定义组件对象绑定，推荐用于导航标题、标签栏及菜单项的构建。`RemoteView`类作为UI框架组件的基础类，包含初始化和`build`方法，但明确标注仅供框架内部使用，应用开发者不应直接调用。文档面向熟悉ArkUI和自定义组件开发的开发者，提供了详细的参数说明和使用限制。
