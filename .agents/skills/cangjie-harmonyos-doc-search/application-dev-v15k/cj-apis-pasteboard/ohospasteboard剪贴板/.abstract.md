This directory contains API documentation for the HarmonyOS pasteboard (clipboard) module, specifically designed for the Cangjie programming language. It covers the essential components required to implement copy and paste functionality, including data records, system pasteboard management, and property definitions. Key topics include MIME type handling, data creation, and sharing scopes like cross-device transfer. Suitable for Cangjie developers using the BasicServicesKit, these references detail system capabilities and version requirements (starting from version 12) for building robust clipboard interactions in HarmonyOS applications.
