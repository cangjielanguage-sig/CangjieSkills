# class_Curves

This directory contains API reference documentation for the Curves class within the Cangjie ArkUI framework. It focuses on creating various animation interpolation curves to control motion timing and transitions. The content covers standard curves like cubic Bezier and step functions, as well as physics-based spring animations including interpolating, responsive, and standard spring motions. These tools are essential for developers looking to implement non-linear, realistic, or custom animation effects in their UI applications. The documentation is suitable for ArkUI developers using the Cangjie language who need to enhance user experience with dynamic animations.
