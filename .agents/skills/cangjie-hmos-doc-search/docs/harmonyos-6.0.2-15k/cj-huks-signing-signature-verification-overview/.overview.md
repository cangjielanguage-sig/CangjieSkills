# cj-huks-signing-signature-verification-overview

This directory serves as a comprehensive technical reference for the signing and signature verification operations within the HUKS (Hardware Universal KeyStore) framework. It is designed to guide developers in ensuring data integrity and non-repudiation across OpenHarmony applications. The documentation meticulously outlines algorithm specifications, distinguishing between the capabilities of standard devices and lite devices. It covers a wide array of cryptographic combinations, including RSA, ECC, ED25519, and SM2, with detailed explanations of their respective digest and padding modes. Additionally, the content addresses critical system constraints such as the requirement for API level 15+, specific limitations on PSS salt lengths, and the handling of NoDigest modes. By defining supported elliptic curves and other cryptographic primitives, this guide provides the necessary specifications for developers and security engineers to implement robust, hardware-backed security solutions effectively. This documentation is particularly relevant for those working on secure boot, data authentication, and secure communication protocols, assuming the reader has a foundational understanding of cryptographic concepts.
