# crypto_digest_package_overview

This directory hosts the essential documentation for the `stdx.crypto.digest` package, a robust software library dedicated to implementing widely-used message digest algorithms, including MD5, SHA, and SM3. It acts as a central resource for developers aiming to incorporate secure cryptographic hashing mechanisms into their projects. The content within provides a thorough overview of the package architecture and details the critical setup process, with a specific focus on the mandatory OpenSSL 3 dependency. It offers step-by-step guidance on environment variable configuration and library path setup across different operating systems such as Linux, Windows, and macOS. Furthermore, the documentation catalogs the available API components, such as algorithm-specific classes, the HashType struct, and the CryptoException class. This guide is intended for software developers who need to implement cryptographic functions and are comfortable handling system-level dependencies and complex environment configurations.
