# Column容器内子元素在垂直方向上的排列

本目录详细介绍了在 ArkUI 框架中使用 Cangjie 语言时，如何控制 Column 容器内子元素的垂直排列。重点讲解了 `justifyContent` 属性的使用，涵盖了 Start、Center、End、SpaceBetween、SpaceAround 和 SpaceEvenly 六种对齐模式。文档包含详细的 Cangjie 代码示例及效果图，旨在帮助开发者理解 FlexAlign 枚举值如何控制子元素在垂直轴上的分布、间距及对齐位置，从而实现精准的 UI 布局。适用于使用 ArkUI 和 Cangjie 语言进行应用开发的用户，特别是需要掌握布局属性实现的开发者。
