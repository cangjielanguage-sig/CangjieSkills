# class_AVMetadataExtractor

This directory contains API reference documentation for the Cangjie `AVMetadataExtractor` class, designed for the HarmonyOS ecosystem. It focuses on enabling developers to retrieve metadata from various media resources, such as streaming media and local files. The documentation covers essential properties for configuring data sources—specifically `dataSrc` and `fdSrc`—highlighting the constraint that only one can be active at a time. It also details methods for fetching album covers and general metadata, alongside resource management via the `release()` function. With information on system capabilities, return types, and error handling, this guide is suitable for multimedia application developers seeking to implement robust media metadata extraction and lifecycle management in their projects.
