# cj-errorcode-common_event_service

本目录专门收录了公共事件服务模块的错误码参考文档，旨在为开发者提供系统化的故障诊断指南。内容主要聚焦于事件发送与订阅流程中可能遇到的异常情况，涵盖了从1500001到1500009的一系列特定错误码。文档详细解析了包括Action参数为空、沙箱应用权限限制、事件发送频率过高、系统级公共事件权限不足、订阅者丢失以及IPC通信失败在内的多种常见问题场景。通过提供详细的错误信息、潜在原因分析及具体的处理步骤，本资料帮助开发者快速定位问题根源，重点关注权限校验、参数完整性检查及系统运行状态确认。该文档适合正在使用公共事件服务进行应用开发，且需要具备一定事件发布与订阅基础知识的开发人员查阅。
