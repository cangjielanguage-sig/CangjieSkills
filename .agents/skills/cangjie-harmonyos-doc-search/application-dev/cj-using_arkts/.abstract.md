This directory serves as a technical guide for Cangjie developers who wish to integrate and reuse the existing ArkTS library ecosystem within their applications. It addresses the growing need for cross-language compatibility, providing a clear overview of how Cangjie can interact with ArkTS components. The guide specifically covers the support mechanisms for ArkTS modules versus pages, offering a classification system that distinguishes between NAPI modules and third-party library types. Among the key takeaways, the document highlights that Cangjie currently supports adding ArkTS modules but does not support pages. Additionally, it clarifies that support is presently limited to NAPI modules, while third-party libraries are not supported. For those looking to implement these features, the guide references a linked document containing detailed implementation instructions. This resource is intended for Cangjie developers seeking to leverage ArkTS resources to expand their application's functionality and streamline their development workflow through effective module integration.
