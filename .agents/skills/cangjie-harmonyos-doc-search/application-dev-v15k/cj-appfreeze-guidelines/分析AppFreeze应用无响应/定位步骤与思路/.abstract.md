This directory provides a comprehensive technical guide for diagnosing and troubleshooting application unresponsiveness (appfreeze) and performance issues in HarmonyOS and Android environments. It covers the full workflow from log acquisition and basic information extraction to advanced analysis of Binder IPC, EventHandler mechanisms, and stack traces. Key topics include FaultLog retrieval, Hilog correlation, and interpreting timeout thresholds. Designed for developers, QA engineers, and system performance analysts, these resources equip users with the methodologies to pinpoint root causes of system freezes and thread blocking.
