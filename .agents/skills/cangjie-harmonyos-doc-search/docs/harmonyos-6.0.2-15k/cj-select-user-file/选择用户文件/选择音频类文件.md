## 选择音频类文件

1. 导入选择器模块和基础文件API模块。

    ```cangjie
    import kit.CoreFileKit.*
    import kit.BasicServicesKit.*
    import kit.AbilityKit.*
    import ohos.base.*
    ```

2. 创建音频类型文件选择选项实例。

    > **说明：**
    >
    > 目前AudioSelectOptions不支持参数配置，默认可以选择所有类型的用户文件。

    ```cangjie
    let audioSelectOptions = AudioSelectOptions()
    ```

3. 创建[音频选择器AudioViewPicker](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_picker.md#class-audioviewpicker)实例。调用[select()](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_picker.md#func-selectasynccallbackarraystring-audioselectoptions)接口拉起FilePicker应用界面进行文件选择。

    ```cangjie
    let uris = Box<String>("")
    // 见获取UIAbility的上下文信息章节
    let context = getContext()
    let audioViewPicker = AudioViewPicker(context)
    audioViewPicker.select({ err, ret =>
        if (let Some(v) <- err) {
        AppLog.error("Invoke audioViewPicker.select failed, code is ${v.code}")
        }
        if (let Some(v) <- ret) {
        // 文件选择成功后，返回被选中文档的uri结果集
        uris.value = v[0]
        }
    }, option: audioSelectOptions)
    ```

    > **注意：**
    >
    > 1.使用picker获取的[select()](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_picker.md#func-selectasynccallbackarraystring-audioselectoptions)返回的uri权限是临时只读权限,待退出应用后台后，获取的临时权限就会失效。
    > 2.开发者可以根据结果集中的uri做读取文件数据操作。建议定义一个全局变量保存uri。例如通过[基础文件API](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md)根据uri拿到音频资源的文件描述符(fd)，再配合媒体服务实现音频播放的开发，具体请参见[音频播放开发指导](../media/audio/cj-using-audiohaptic-for-playback.md)。

4. 待界面从FilePicker返回后，可以使用[基础文件API的file_fs.open](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md#static-func-openstring-int64)接口通过uri打开这个文件得到文件描述符(fd)。

    ```cangjie
    let uri = ''
    // 这里需要注意接口权限参数是OpenMode.READ_ONLY
    let file = FileFs.open(uri, mode: OpenMode.READ_ONLY.mode)
    AppLog.info('file fd: ${file.fd}')
    ```

5. 通过fd可以使用[基础文件API的file_fs.read](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md#static-func-readint32-arraybyte-readoptions)接口读取这个文件内的数据。

    ```cangjie
    let buffer = Array<Byte>(4096, repeat: 0)
    let readLen = FileFs.read(file.fd, buffer)
    AppLog.info('readSync data to file succeed and buffer size is: ${readLen}')
    // 读取完成后关闭fd
    FileFs.close(file)
    ```
