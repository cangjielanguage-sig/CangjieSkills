This directory focuses on advanced gesture interception and conflict resolution mechanisms within the ArkUI framework. It provides API references for customizing gesture judgment logic, managing parallel gesture processing, and controlling event responses dynamically. Key topics include `onGestureRecognizerJudgeBegin`, `shouldBuiltInRecognizerParallelWith`, and fundamental gesture types. This resource is suitable for developers building complex interactive user interfaces who need fine-grained control over touch events, nested scrolling, and component interaction behaviors in HarmonyOS applications.
