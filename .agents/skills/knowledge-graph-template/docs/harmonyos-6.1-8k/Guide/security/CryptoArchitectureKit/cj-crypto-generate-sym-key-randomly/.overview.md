本目录包含一份面向Cangjie开发者的技术教程，重点讲解如何利用CryptoArchitectureKit随机生成对称密钥。文档详细介绍了AES和SM4两种主流算法的密钥生成流程，涵盖了从创建SymKeyGenerator实例、调用generateSymKey方法到获取二进制数据的完整步骤。内容包含AES256和SM4_128的完整代码示例，适合需要实现加解密功能的开发者参考。关键词包括对称密钥、AES、SM4、Cangjie、随机生成、CryptoArchitectureKit。

## 详细说明

### cj-crypto-generate-sym-key-randomly.md cj-crypto-generate-sym-key-randomly.md
本文档是一份面向Cangjie开发者的技术教程，旨在指导如何使用CryptoArchitectureKit随机生成对称密钥。文档重点介绍了AES和SM4两种算法的密钥生成流程，包括创建SymKeyGenerator实例、调用generateSymKey生成密钥以及通过getEncoded获取二进制数据。文中提供了AES256和SM4_128的完整代码示例，展示了从初始化到输出密钥十六进制数据的步骤。目标读者为需要实现加解密功能的开发者，文档当前处于Beta阶段。关键词包括对称密钥、AES、SM4、Cangjie、随机生成、CryptoArchitectureKit。
