# enum_AVScreenCaptureStateCode

This directory contains comprehensive API reference documentation for the `AVScreenCaptureStateCode` enum within the Cangjie programming language environment. It focuses on defining and managing status codes for screen capture sessions, covering various operational states such as STARTED, CANCELED, STOPPED_BY_USER, and INTERRUPTED_BY_OTHER. Additionally, it addresses microphone-related states like MIC_MUTED_BY_USER and transitions involving privacy scenes. The documentation details the enum's inheritance from Equatable and ToString, specifies the required SystemCapability.Multimedia.Media.AVScreenCapture system capability, and notes availability starting from API version 19. This resource is specifically designed for multimedia application developers who need to effectively monitor, handle, and debug state changes, errors, and interruptions during screen capture operations. By utilizing these references, developers can ensure robust error handling and state management in their multimedia applications.
