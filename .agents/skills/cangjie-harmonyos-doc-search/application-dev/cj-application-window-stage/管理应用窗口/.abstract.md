This directory provides comprehensive technical guides for managing application windows in HarmonyOS using the Stage model and Cangjie language. It covers essential window management tasks, including configuring main windows, creating immersive experiences by hiding system bars, and implementing floating or sub-windows. Key topics include window lifecycle, property configuration, and UI integration. Suitable for HarmonyOS developers and UI engineers looking to build dynamic, multi-window interfaces and optimize user experiences through advanced window behaviors.
