# 焦点控制

This directory provides comprehensive API references and resources for managing component focus behavior within the Cangjie ArkUI framework. It covers essential focus control mechanisms, including navigation rules, priority settings, and default focus configurations. Developers can find documentation on functions like `focusScopePriority`, `focusable`, and `groupDefaultFocus`, alongside type definitions and practical code examples. This collection is suitable for UI developers and HarmonyOS engineers aiming to implement robust keyboard navigation, accessibility features, and complex interaction logic in their applications.

### func_focusScopePriorityStr_3more.md func_focusScopePriorityStr_3more.md
This document provides API reference documentation for managing component focus behavior in the Cangjie ArkUI framework. It covers three main functions: focusScopePriority for setting focus acquisition priority within specific containers, focusScopeId for defining focus groups and navigation boundaries, and tabIndex for customizing Tab key traversal sequences. Key information includes the logic for priority levels like PREVIOUS and AUTO, the specific navigation rules for focus groups such as arrow key restrictions, and the mutual exclusivity between tabIndex and focusScopeId. This resource is intended for UI developers implementing complex keyboard navigation, requiring an understanding of component hierarchy and focus event handling.

### func_groupDefaultFocusBool.md func_groupDefaultFocusBool.md
This API reference document details the groupDefaultFocus function in the Cangjie language, designed to configure a component as the default focus target when its parent container first receives focus. The documentation outlines the function signature, system capabilities, version requirements, and a detailed parameter table for the isGroupDefaultFocus boolean. Key takeaways include the requirement to use this function alongside tabIndex and that it only activates during the container's initial focus event. If multiple components are marked, the system defaults to the first one found via depth traversal. This guide targets ArkUI developers using Cangjie who need precise control over focus management and navigation flow.

### 焦点控制_5more.md 焦点控制_5more.md
This document serves as an API reference for managing focus control within the ArkUI framework using the Cangjie language.
