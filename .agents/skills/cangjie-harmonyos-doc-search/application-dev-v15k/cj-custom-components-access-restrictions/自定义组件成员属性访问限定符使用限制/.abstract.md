This documentation provides a comprehensive technical reference regarding the usage restrictions and initialization rules for access qualifiers—specifically private, public, and protected—applied to custom component member properties within the Cangjie framework. It covers the complex interactions between these access modifiers and state management decorators such as @State, @Prop, @Link, @StorageLink, and @Consume. By detailing specific constraints on external versus local initialization, this guide helps developers prevent compiler errors and ensure robust data binding. It is primarily suitable for component developers and system architects working on HarmonyOS UI applications who need to adhere to strict validation standards for stateful components.
