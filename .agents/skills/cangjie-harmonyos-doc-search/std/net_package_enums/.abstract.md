This directory serves as a comprehensive resource for the `net_package_enums` module, specifically focusing on the `SocketNet` enumeration within the Cangjie programming language's net package. It is designed to assist developers in understanding and implementing transport layer protocol types effectively. The documentation covers the structural definition of the enumeration, detailing its three primary variants: TCP, UDP, and UNIX protocols. Furthermore, it explains the integration of standard interfaces such as `ToString` and `Equatable`, which are essential for string representation and comparison operations. This directory is highly suitable for Cangjie developers, network engineers, and system programmers who are actively involved in developing network socket applications and require precise programmatic control over protocol differentiation and handling. The content ensures users have the necessary reference material to build robust networked applications, facilitating the creation of efficient and reliable communication channels across different network environments.
