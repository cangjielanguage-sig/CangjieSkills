This directory provides the API reference documentation for the `cj-apis-i18n` module, specifically focusing on the Cangjie LocalizationKit for HarmonyOS. It serves as a central resource for developers aiming to implement comprehensive internationalization (I18n) and localization features in their applications. The documentation covers a wide array of functionalities, including text normalization, entity recognition, phone number formatting, and holiday management. Additionally, it offers utilities for handling calendars, time zones, Unicode character analysis, and system locale settings. This content is essential for Cangjie developers and software engineers who need to build robust, culturally aware applications that support global users through advanced text processing and locale-specific adaptations.
