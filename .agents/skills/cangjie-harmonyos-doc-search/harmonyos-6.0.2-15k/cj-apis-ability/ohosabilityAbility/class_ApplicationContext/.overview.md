# class_ApplicationContext

This directory contains API reference documentation for the `ApplicationContext` class in the Cangjie programming language, designed for HarmonyOS application development. It covers essential application-level capabilities including data management, process control, lifecycle event listeners, and UI configuration settings like font scaling and language. Developers can find detailed specifications for functions handling system environment changes, ability lifecycle transitions, and application restarts. This resource is suitable for application developers seeking to programmatically manage app context, handle state transitions, and configure system-level behaviors within their HarmonyOS applications.
