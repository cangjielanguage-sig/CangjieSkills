# 使用场景

This directory contains tutorials and guides on using LocalStorage for state management in HarmonyOS applications developed with the Cangjie language. It covers various usage scenarios including data synchronization between components, sharing state across views via UIAbility, integrating storage with application logic, handling complex data types like DateTime and collections, and cross-language interoperability with ArkTS. These resources are suitable for Cangjie developers and HarmonyOS application architects looking to implement reactive state management, ensure data consistency, and manage shared application states efficiently.

## Detailed Description

### LocalStorageProp和LocalStor_3more.md LocalStorageProp和LocalStor_3more.md
This tutorial provides code examples for managing application state in Cangjie using LocalStorage. It covers three main scenarios: one-way data synchronization using @LocalStorageProp, two-way synchronization using @LocalStorageLink, and state sharing between sibling components. Key takeaways include understanding how to initialize LocalStorage, bind component variables, and ensure data consistency across the UI hierarchy. The document targets Cangjie developers working on HarmonyOS applications who need to implement reactive state management and data flow between components.

### 将LocalStorage实例从UIAbility共享到一个或多个视图.md 将LocalStorage实例从UIAbility共享到一个或多个视图.md
This tutorial explains how to share a LocalStorage instance across multiple views by initializing it within a UIAbility in the Cangjie language. It covers creating the LocalStorage instance in the MainAbility class and accessing it in separate view components like EntryView and Page. Key information includes using the `@Entry[storage]` decorator and `@LocalStorageLink` to bind variables, ensuring data synchronization across pages. The document recommends setting default values during initialization for error handling and testing. This guide targets application developers using the Cangjie language for HarmonyOS development who need state management across different views.

### 应用逻辑使用LocalStorage_2more.md 应用逻辑使用LocalStorage_2more.md
This tutorial demonstrates how to utilize LocalStorage for state management in Cangjie applications, covering both application logic and UI components. The document is divided into two main sections: basic usage in application logic and integration within the UI. The logic section covers methods like setOrCreate, get, and link, while the UI section explains the @LocalStorageLink and @Entry macros for data binding. Key takeaways include the implementation of two-way data synchronization between storage instances and UI components, ensuring state consistency across parent and child views. This guide targets Cangjie developers building HarmonyOS applications who need to manage shared application state efficiently.

### 自定义组件外改变状态变量_2more.md 自定义组件外改变状态变量_2more.md
This technical guide demonstrates how to modify state variables externally and share LocalStorage between ArkTS and Cangjie in hybrid UI development. It covers two main scenarios: managing state via a shared Model class in pure Cangjie and synchronizing state across language boundaries using ArkTS's LocalStorage. Key takeaways include using @LocalStorageLink for reactivity, registering LocalStorage.getShared in globalThis, and utilizing the "InterOp" flag in Cangjie macros for cross-language data binding. This document targets HarmonyOS developers building mixed-language applications who need to understand state management patterns and interoperability.

### 装饰DateTime类型变量_3more.md 装饰DateTime类型变量_3more.md
This document serves as a technical tutorial demonstrating how to use the @LocalStorageLink decorator with complex data types in the Cangjie programming language. It covers three main sections: decorating DateTime variables to update a DatePicker, and managing Map and Set collections to refresh list views via ForEach. Key takeaways include the syntax for binding these types to UI components and the specific pattern of modifying state variables to trigger view updates. The examples illustrate operations like adding, removing, and clearing data. This guide targets HarmonyOS developers using Cangjie who need to manage local storage state for non-primitive types.
