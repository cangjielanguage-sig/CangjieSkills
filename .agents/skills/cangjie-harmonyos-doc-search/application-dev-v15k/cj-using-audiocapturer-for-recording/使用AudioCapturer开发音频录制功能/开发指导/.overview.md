# 开发指导

This directory provides comprehensive development guidance for implementing audio recording functionality in HarmonyOS applications. It focuses on the AudioCapturer class, detailing the complete recording lifecycle, including instance creation, parameter configuration, state management, and resource release. The content covers essential topics such as handling state transitions, managing the `ohos.permission.MICROPHONE` permission, and writing captured data to PCM files. It includes practical code examples in both Cangjie and ArkTS. This guide is suitable for HarmonyOS developers looking to integrate robust audio capture features into their applications using the AudioKit framework.

## Detailed Description

### 开发指导.md 开发指导.md
This development guide instructs developers on implementing audio recording using the AudioCapturer class. It covers the complete recording lifecycle, including instance creation, parameter configuration, start and stop operations, and resource release. A key focus is the management of AudioCapturer state transitions, illustrated by a diagram, to prevent errors caused by inappropriate method calls. The document explains how to monitor these changes using the on(AudioCapturerCallbackType.STATE_CHANGE) method and the AudioState enum. Intended for developers, this tutorial is designed to be read alongside the API reference documentation to ensure correct implementation of audio capture functionality.

### 开发步骤及注意事项.md 开发步骤及注意事项.md
This document provides a step-by-step tutorial for implementing audio recording functionality using the AudioCapturer class in the Cangjie programming language. It covers five main stages: configuring audio parameters and creating the instance, subscribing to data read callbacks, starting and stopping the recording process, and releasing resources. Key information includes the mandatory requirement for the ohos.permission.MICROPHONE permission when using microphone audio sources and code examples for writing captured data to PCM files. Intended for HarmonyOS developers, this guide assumes familiarity with Cangjie syntax and the AudioKit framework.
