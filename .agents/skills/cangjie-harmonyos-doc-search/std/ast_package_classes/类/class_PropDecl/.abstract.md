This directory provides comprehensive API reference documentation for the Cangjie programming language, specifically targeting Abstract Syntax Tree (AST) manipulation and analysis. It details the `PropDecl` class, which serves as the structural representation for property definitions within the syntax tree, alongside the `traverse` function designed for systematic node navigation. The documentation covers critical aspects such as class inheritance hierarchies, initialization protocols, mutable syntax elements like type nodes and braces, and serialization methods. Furthermore, it explains visitor patterns for traversing tree structures, including early termination capabilities. This resource is specifically curated for compiler developers, tool builders, and software engineers involved in creating code analyzers or automated refactoring tools for the Cangjie ecosystem who require deep technical insights into AST operations.
