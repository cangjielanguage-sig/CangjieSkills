This directory focuses on the mechanisms of observing data changes and behavioral patterns within the Cangjie state management system for ArkUI. It comprehensively covers the `@Prop` decorator's initialization, update flows, and synchronization rules between parent and child components. Key topics include one-way data flow, deep observation of various data types (primitives, structs, classes), and constraints on collection reactivity like `HashSet`. This resource is suitable for developers looking to master reactive programming, manage component state efficiently, and ensure accurate UI updates in their applications by understanding the underlying framework behavior and observation rules.
