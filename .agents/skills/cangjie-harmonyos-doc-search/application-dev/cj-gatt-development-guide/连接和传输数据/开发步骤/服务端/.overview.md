# 服务端

This directory provides a comprehensive technical guide for implementing a Bluetooth Low Energy (BLE) GATT server using the Cangjie programming language and ConnectivityKit. It covers the complete server lifecycle, including initialization, service creation, connection management, and data exchange mechanisms. Key topics include defining GATT services and characteristics, handling client read/write requests, managing descriptors, and sending notifications or indications. Additionally, it details resource cleanup and server termination procedures. These documents are suitable for developers building Bluetooth applications who need to manage server-side GATT operations, asynchronous callbacks, and client interactions effectively.

## Detailed Description

### 服务端_1.md
This document provides a technical guide for implementing a Bluetooth Low Energy (BLE) GATT server using the Cangjie language and ConnectivityKit. It covers creating a server instance, adding services with specific UUIDs, and subscribing to connection state changes. It also introduces data transmission mechanisms like reading and writing characteristics. The guide includes code examples for defining descriptors, characteristics, and GATT services, as well as handling connection state callbacks and exception management. It targets developers building Bluetooth applications who need to manage server-side GATT operations and client interactions.

### 服务端_2.md
This document serves as a technical tutorial for implementing Bluetooth Low Energy (BLE) GATT server operations using the Cangjie programming language. It focuses on handling characteristic read and write requests from clients. The main sections detail importing necessary modules, defining callback classes for read and write events, and subscribing to these events via the on method. Key takeaways include using sendResponse to acknowledge read requests and checking the needRsp property to conditionally respond to write requests. The document also briefly introduces descriptor event handling. Intended for developers with knowledge of BLE protocols and Cangjie, this guide provides practical code examples for managing server-side data exchange and asynchronous callbacks.

### 服务端_3.md
This document serves as a technical guide for implementing Bluetooth Low Energy (BLE) GATT server functionalities using the Cangjie language. It covers handling descriptor read and write requests, detailing how to use the sendResponse API to reply to clients and manage the needRsp flag for write operations. Additionally, it explains sending characteristic change notifications or indications via the notifyCharacteristicChanged API, distinguishing between them using the confirm parameter. The content includes code examples for defining callbacks and subscribing to events. This guide targets developers building BLE server applications who need to manage client interactions and data updates.

### 服务端_4.md
This technical guide details how to implement BLE server notifications and manage server lifecycle termination in Cangjie. It covers enabling notifications or indications via specific descriptors and sending updates, followed by procedures for closing the server instance and releasing resources. Key takeaways include the requirement for the Client Characteristic Configuration descriptor UUID (0x2902) to support notifications, the use of `notifyCharacteristicChanged` for data transmission, and the necessity of calling `removeService` and `close` for proper cleanup. This tutorial targets developers building BLE applications who need to handle asynchronous data updates and resource management.
