# README_zh

本目录提供了Ability Kit（程序框架服务）的中文导航文档，核心聚焦于HarmonyOS Stage模型的应用开发框架与关键概念。文档内容全面覆盖了应用模型的基础概述、Stage模型下的开发实战指导，深入剖析了UIAbility组件的生命周期管理、启动模式设置以及Want信息传递机制。此外，还详细说明了应用间的跳转逻辑与配置文件的编写规范。本文档特别适合HarmonyOS应用开发者阅读，旨在帮助开发者构建清晰的程序框架认知，掌握组件间的交互方式。请注意，文档中涉及的大部分特性目前处于Beta阶段。

## 详细描述

### README_zh.md

本文档是Ability Kit（程序框架服务）的导航指南，主要介绍Stage模型应用开发框架及相关概念。涵盖应用模型概述、Stage模型开发指导（包括UIAbility组件生命周期与启动模式、Want信息传递机制）、应用间跳转及配置文件说明。重点阐述了UIAbility组件的基本用法与生命周期、显式与隐式Want的匹配规则，以及如何拉起文件处理类应用。文档中大部分内容属于Beta特性。适用于HarmonyOS应用开发者，旨在帮助其理解程序框架结构及组件交互方式。
