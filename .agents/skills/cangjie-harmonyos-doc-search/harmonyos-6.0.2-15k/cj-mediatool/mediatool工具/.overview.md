# mediatool工具

This directory contains documentation for the `mediatool`, a lightweight command-line utility designed for developers to manipulate media library resources within the system gallery. It covers the tool's introduction, usage scenarios, and detailed command-line reference. Key topics include exporting media files, deleting assets, resetting the media database, and querying resources using URIs. The documentation is intended for developers and technical users who need to manage image and video data programmatically via the hdc shell on connected devices.

### 命令行说明.md 命令行说明.md
This document serves as a technical reference guide for the mediatool command-line interface, detailing commands to manage media library resources. It covers three primary subcommands: recv for exporting source files to specific device paths, delete for permanently removing resources, and query for searching assets by display name. Key takeaways include the requirement for specific resource URIs, path restrictions to /data/local/tmp, and the exclusion of hidden albums. The recv and delete commands support an all argument for bulk operations, while query offers flags to return either file paths or URIs. This guide targets developers or system administrators needing to manipulate media assets programmatically via a shell environment.
