## 缓存与存储管理

在访问网站时，网络资源请求是相对比较耗时的。开发者可以通过Cache、Dom Storage等手段将资源保存到本地，以提升访问同一网站的速度。

### Cache

使用[cacheMode()](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-cachemodecachemode)配置页面资源的缓存模式，Web组件为开发者提供四种缓存模式，分别为：

- Default: 优先使用未过期的缓存，如果缓存不存在，则从网络获取。
- None: 加载资源使用cache，如果cache中无该资源则从网络中获取。
- Online: 加载资源不使用cache，全部从网络中获取。
- Only：只从cache中加载资源。

在下面的示例中，选用缓存设置为None模式。

```cangjie
// index.cj
import kit.ArkWeb.WebviewController
import kit.UIKit.{Web, CacheMode}

@Entry
@Component
class EntryView {
    let webController = WebviewController()

    func build() {
        Column {
            Web(src: 'www.example.com', controller: webController).cacheMode(CacheMode.None)
        }
    }
}
```

同时，为了获取最新资源，开发者可以通过[removeCache()](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-removecachebool)接口清除已经缓存的资源，示例代码如下：

```cangjie
// index.cj
import kit.ArkWeb.WebviewController
import kit.UIKit.{BusinessException, Web, CacheMode}

@Entry
@Component
class EntryView {
    let webController = WebviewController()

    func build() {
        Column {
            Button("removeCache").onClick {
                evt => try {
                    // 设置为true时同时清除rom和ram中的缓存，设置为false时只清除ram中的缓存
                    webController.removeCache(true)
                    AppLog.info("removeCache success")
                } catch (e: BusinessException) {
                    AppLog.error("removeCache ErrorCode: ${e.code},  Message: ${e.message}")
                }
            }
            Web(src: 'www.example.com', controller: webController).cacheMode(CacheMode.None)
        }
    }
}
```

### Dom Storage

Dom Storage包含了Session Storage和Local Storage两类。前者为临时数据，其存储与释放跟随会话生命周期；后者为可持久化数据，落盘在应用目录下。两者的数据均通过Key-Value的形式存储，通常在访问需要客户端存储的页面时使用。开发者可以通过Web组件的属性接口[domStorageAccess()](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-domstorageaccessbool)进行使能配置，示例如下：

```cangjie
// index.cj
import kit.ArkWeb.WebviewController
import kit.UIKit.Web

@Entry
@Component
class EntryView {
    let webController = WebviewController()

    func build() {
        Column {
            Web(src: 'www.example.com', controller: webController).domStorageAccess(true)
        }
    }
}
```
