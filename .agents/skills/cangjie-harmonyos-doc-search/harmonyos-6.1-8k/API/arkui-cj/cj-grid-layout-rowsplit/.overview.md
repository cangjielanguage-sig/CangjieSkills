# cj-grid-layout-rowsplit

本目录提供了ArkUI框架中RowSplit组件的API参考文档，专门针对使用仓颉（Cangjie）语言进行应用开发的工程师。该文档深入解析了RowSplit组件的功能，即如何将子组件进行横向排列并在其间插入纵向分割线。核心知识点涵盖了组件的初始化流程、子组件宽度与分割线位置的精确交互规则，以及如何利用`resizeable`属性来实现分割线的拖拽交互。文档还特别强调了在组件初始化后动态修改子组件宽度的具体限制。鉴于该组件目前处于Beta阶段，本资料非常适合那些致力于构建具有动态调整布局宽度功能的现代化界面的开发者参考。
