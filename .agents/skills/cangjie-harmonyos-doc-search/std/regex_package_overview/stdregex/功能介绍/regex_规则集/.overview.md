### regex_规则集_1.md regex_规则集_1.md

This is intended for software developers and engineers working with the Cangjie language who need to implement pattern matching or text processing.

### regex_规则集_3.md regex_规则集_3.md
This document serves as a technical reference guide for specific Regular Expression syntax rules and features. It details advanced constructs such as back-references, non-capturing groups, and positive or negative lookahead and lookbehind assertions. This guide is intended for developers or system administrators requiring precise pattern matching definitions for a specific regex engine.

### regex_规则集_4.md regex_规则集_4.md
This document outlines specific behavioral rules, limitations, and security warnings for the Regex implementation in the Cangjie language. It details quantifier handling, system capacity limits, unsupported nested quantifier syntax, and input constraints. Key information includes a maximum of 63 capture groups and a rule length limit of 65535. The text explicitly warns that null bytes in input strings can cause infinite loops and that unbounded repetition counts may trigger stack overflows or ReDoS attacks due to the lack of internal limits. This reference guide targets Cangjie developers who need to write efficient, safe regular expressions and understand system boundaries.
