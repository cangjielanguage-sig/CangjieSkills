This directory contains API reference documentation for the `AVSessionController` class in the Cangjie programming language. It focuses on managing and controlling audio-video sessions within multimedia applications. The content covers session properties, state retrieval, event listeners for metadata and playback changes, and command sending capabilities. Key topics include session lifecycle management, playback control, and event handling. It is suitable for multimedia application developers using the AVSession framework who need to implement robust media control features and handle dynamic session updates.
