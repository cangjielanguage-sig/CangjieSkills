# cj-custom-components-access-restrictions

This directory serves as a comprehensive technical resource for the Cangjie programming language, specifically focusing on the critical constraints governing access qualifiers—private, public, and protected—within custom component member properties. It addresses the nuanced interactions between these access modifiers and essential state management decorators, including @State, @Prop, @Link, @StorageLink, and @Consume. By clarifying the rules for external versus local initialization, this documentation assists developers in avoiding common compiler pitfalls and ensuring secure, efficient data binding. This resource is indispensable for component developers and system architects building complex HarmonyOS UI applications who require strict adherence to validation standards for stateful components. It ultimately ensures that architectural integrity and data encapsulation are maintained throughout the development lifecycle, providing a solid foundation for robust UI engineering.

### 自定义组件成员属性访问限定符使用限制/
