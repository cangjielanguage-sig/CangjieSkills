# 创建自定义组件

This directory focuses on creating custom components within the Cangjie UI framework (ArkUI). It covers the structural rules, syntax constraints, and parameter initialization required to build reusable UI elements. Key topics include the `build()` function specifications, the `@Component` decorator, and component communication mechanisms. This resource is suitable for HarmonyOS developers using the Cangjie language who want to encapsulate UI logic, improve code reusability, and ensure compliance with framework constraints.

## Detailed Description

### build函数.md build函数.md
This reference guide defines the strict syntax and structural rules for the build() function in Cangjie UI development. It specifies root node requirements for @Entry and @Component decorators, emphasizing uniqueness and container constraints. Key sections detail prohibited actions within UI descriptions, including declaring local variables, using local scopes, calling non-@Builder methods, employing match syntax, and modifying state variables. The document provides code examples illustrating correct and incorrect patterns. It targets Cangjie developers needing to ensure compliance with UI framework constraints to avoid compilation errors and runtime issues.

### 创建自定义组件_4more.md 创建自定义组件_4more.md
This guide explains how to create and structure custom components in ArkUI using the Cangjie programming language to enhance code reusability and maintainability. It covers component characteristics, basic usage examples, and structural definitions including the @Component macro, build() function, and decorators like @Entry and @Reusable. Key takeaways include that custom components are class-based, require a build() method for UI description, and have specific constraints such as a maximum of 128 member variables and private member access. This tutorial targets ArkUI developers using Cangjie who need to encapsulate UI and business logic.

### 自定义组件的参数规定.md 自定义组件的参数规定.md
This technical guide explains the regulations for initializing parameters when creating custom components within the Cangjie UI framework. The document covers two primary scenarios: initializing basic member variables like integers and colors using named parameters, and passing functions from parent components to child components to enable callbacks. Key information includes the syntax for component instantiation in the build method and the mechanism for defining function parameters within child components. Intended for HarmonyOS developers using Cangjie, this tutorial requires prior knowledge of basic UI component structure and state management.
