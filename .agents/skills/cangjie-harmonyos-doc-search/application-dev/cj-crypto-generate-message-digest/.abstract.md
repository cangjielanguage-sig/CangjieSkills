This directory provides a technical tutorial for Cangjie developers focusing on the implementation of SHA256 message digests using the CryptoArchitectureKit. It addresses the critical need for secure data hashing by detailing two primary input strategies: single-pass updates for standard use cases and segmented updates for processing large data volumes efficiently. The guide thoroughly explains the workflow involving essential functions such as `createMd`, `update`, `digest`, and `getMdLength`. By comparing code examples for both methods, it demonstrates that the final digest remains consistent regardless of data chunking. This resource is ideal for developers in the Beta phase who require robust solutions for cryptographic hashing, data integrity verification, and efficient memory management within the Cangjie ecosystem. Keywords: Cangjie, SHA256, CryptoArchitectureKit, message digest, update, digest, Beta, cryptographic hashing, data integrity.
