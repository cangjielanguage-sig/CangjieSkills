# package

This directory contains comprehensive documentation for the Cangjie programming language's package and module system. It covers essential concepts such as package declarations, naming conventions, and the structural relationship between source code and file systems. Additionally, it details the program entry point (`main` function), import mechanisms for code modularity, and visibility control for top-level declarations. This resource is designed for Cangjie developers seeking to organize code effectively, manage dependencies, and understand compilation and publishing standards.

## Detailed Description

### [1] package_overview/
This directory contains core overview documents for the package and module system of the Cangjie programming language, aiming to provide developers with comprehensive guidance on code organization, compilation, and publishing mechanisms. The documents explain in detail the role of the "package" as the smallest unit of compilation, including its namespace rules, independent output capability, and multi-source file management methods. It also expounds on the composition of the "module" as the smallest unit for third-party publishing, clarifying that a module is a collection of packages and specifying the specific parameter and return type requirements for the program entry (main function). This basic concept guide is very suitable for Cangjie language developers to read, helping readers deeply understand the overall project structure, build process, and code publishing standards.

### [2] entry/
This directory collects core documentation regarding program entry points in the Cangjie language, focusing on the complete definition specifications of the `main` function and its behavior within the compilation system. The content deeply explores the logic for locating entry functions, strict constraints on parameters and return values, access modifier restrictions, and common compilation errors with correction suggestions. Mastering these rules ensures programs are correctly identified and launched. This resource is primarily for Cangjie developers, especially those building executable applications or debugging startup processes.

### [3] package_name/
This directory collects core documentation regarding package name management in the Cangjie programming language. It delves into the syntax specifications of package declarations, their specific position requirements in source files, and the strict mapping relationship between source code directory structures and package names. The content covers default package naming mechanisms and details how to effectively avoid naming conflicts, particularly the naming constraints between sub-packages and parent packages. By reading this documentation, developers can master defining package names using legal identifiers and understand the role of dot separators in path mapping. This guide is an essential reference for Cangjie developers performing modular design, standardizing project code structure, and organizing large-scale software architectures.

### [4] import/
The `import` directory is a vital resource for developers working with the Cangjie programming language, focusing specifically on the mechanisms that enable code modularity and reuse. In modern software engineering, the ability to import and manage packages is crucial for building scalable applications. This section provides the necessary guidelines for utilizing these features effectively.
