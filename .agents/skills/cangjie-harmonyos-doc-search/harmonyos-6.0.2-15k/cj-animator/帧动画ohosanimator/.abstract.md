This directory provides comprehensive documentation and tutorials for implementing frame animations within HarmonyOS applications using the Cangjie language. It specifically explores the `ohos.animator` API, offering developers the tools to handle property adjustments on a per-frame basis. Key topics include the `AnimatorResult` object, `onFrame` callbacks, and lifecycle management methods like `onPageShow` and `onPageHide`. The resources cover practical implementations ranging from mathematical trajectory calculations to real-time UI updates. This content is ideal for developers seeking to build custom physics-based animations or require granular control over animation states beyond standard property animations.
