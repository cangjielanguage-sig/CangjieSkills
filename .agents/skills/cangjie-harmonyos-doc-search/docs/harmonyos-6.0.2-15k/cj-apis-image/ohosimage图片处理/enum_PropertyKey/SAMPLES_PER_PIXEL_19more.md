### SAMPLES_PER_PIXEL

```cangjie
SAMPLES_PER_PIXEL
```

**功能：** 每个像素的分量数。由于该标准适用于RGB和YCbCr图像，因此该标签的值设置为3。在JPEG压缩数据中，使用JPEG标记代替该标签。

**读写能力：** 可读写

**系统能力：** SystemCapability.Multimedia.Image.Core

**起始版本：** 19
