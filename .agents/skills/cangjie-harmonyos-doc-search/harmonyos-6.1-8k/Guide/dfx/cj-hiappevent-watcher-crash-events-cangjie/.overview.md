## Detailed Description

### 订阅崩溃事件/

This directory provides a detailed technical overview of how to implement crash event subscription and monitoring within applications built using the Cangjie language. The documentation is structured to guide developers through the process of handling two primary categories of crashes: `CjError`, which pertains to errors occurring within the Cangjie runtime, and `NativeCrash`, which addresses crashes at the native system level.

Key topics include comprehensive interface descriptions that define how developers interact with the event system. It outlines the specific methods required for adding and removing observers, allowing for dynamic control over event monitoring. The guide provides a complete set of development steps, ensuring that developers can effectively integrate these features into their projects.

Central to this functionality are the `addWatcher` and `removeWatcher` interfaces, which facilitate the management of event listeners. By utilizing these tools alongside the HiAppEvent system, developers can perform in-depth log analysis to understand the root causes of failures. As the documentation is currently in the Beta stage, it represents a cutting-edge resource for Cangjie developers focused on maximizing application stability, streamlining fault troubleshooting, and ensuring real-time monitoring capabilities in their software solutions. By following the guidelines provided, developers can significantly reduce downtime and improve the user experience through proactive error management.
