This directory contains the essential documentation for the `regex_package_enums` module, specifically focusing on the `RegexFlag` enumeration used within the Cangjie programming language's regex package. It acts as a definitive guide for developers who need to manipulate and configure the behavior of regular expression engines. The documentation covers the structural definition of the enumeration and provides in-depth explanations for its three primary variants: `IgnoreCase`, `MultiLine`, and `Unicode`. By detailing how these flags modify pattern matching—ranging from case sensitivity to multi-line mode and character encoding standards—this resource ensures developers can implement robust text processing solutions. It is intended for Cangjie developers seeking to optimize their regex operations for complex string manipulation tasks, providing the necessary context to choose the right configuration for every scenario.
