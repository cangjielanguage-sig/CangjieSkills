# crypto_package_overview

This directory contains the essential documentation for the `stdx.crypto.crypto` package, a robust library designed for secure random number generation and SM4 symmetric encryption. It provides a comprehensive installation guide that emphasizes the strict requirement for OpenSSL 3 across Linux, Windows, and macOS. The content covers critical environment variable configurations like `LD_LIBRARY_PATH` and `PATH` and details core API components such as the `SecureRandom` and `SM4` classes, alongside structs for `OperationMode` and `PaddingMode`. This resource is suitable for developers who need to implement cryptographic functions and must configure system libraries to prevent runtime exceptions. It requires familiarity with OS-specific package management and environment settings to ensure successful deployment and operation of the cryptographic tools.
