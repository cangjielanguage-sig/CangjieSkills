# 目标方开发步骤

This directory provides comprehensive technical guides for developing the target application in a flight query scenario using HarmonyOS, Cangjie, and ArkTS. It covers essential development steps including configuring the `module.json5` file with specific URI schemes and linkFeature attributes, parsing incoming parameters within UIAbility lifecycle methods, and implementing robust page routing logic. Key topics include deep linking, parameter extraction for flight numbers and locations, and navigation to specific content pages. These resources are specifically designed for developers implementing universal connectivity and deep link handling for flight services, offering practical code examples and configuration details to ensure seamless integration.

### 目标方开发步骤_1.md
This technical guide outlines the development steps for the target application in a flight query scenario using HarmonyOS and Cangjie. It covers configuring the module.json5 file with specific URI schemes and linkFeature attributes, such as QueryByFlightNo, and parsing incoming parameters within UIAbility lifecycle methods like onCreate and onNewWant. Key information includes detailed parameter definitions for two scenarios: querying by flight number and by location, including required fields like flightNo and originLocation. The document provides a complete Cangjie code example demonstrating parameter extraction and page loading. This guide is intended for developers implementing deep links or universal connectivity for flight services.

### 目标方开发步骤_2.md
This document serves as a technical reference for implementing page routing logic based on specific URIs within an application. It details the `loadPage` function, which handles navigation for flight number queries and location-based finance queries. Key information includes the use of conditional statements to check URIs, storing parameters like flight numbers, dates, and locations in `localStorage`, and loading specific content pages using `windowStage.loadContent`. The code demonstrates how to route users to `QueryByFlightNoPage`, `QueryByLocationPage`, or a default `EntryView`. This guide is intended for developers working on application navigation and data passing, specifically those using ArkTS or similar frameworks for cross-platform development.
