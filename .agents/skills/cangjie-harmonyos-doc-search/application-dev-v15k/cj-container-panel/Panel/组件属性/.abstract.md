This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework, specifically utilizing the Cangjie language. It focuses on the detailed setup and customization of UI elements, including sliding panels and interactive icons. Key areas covered include background masking, drag bar configuration, height definitions for various panel modes (Full, Half, Mini), and visibility controls. The documentation is essential for UI developers and software engineers seeking to customize component behavior, enforce layout constraints, and manage user interface states effectively in ArkUI-based applications. It serves as a technical guide for implementing complex UI interactions and adhering to framework-specific constraints.
