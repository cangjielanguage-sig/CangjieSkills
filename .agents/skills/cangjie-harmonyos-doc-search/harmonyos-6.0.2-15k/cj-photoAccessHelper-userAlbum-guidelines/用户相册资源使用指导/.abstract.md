This directory provides comprehensive technical guidance for HarmonyOS developers on managing user album resources using the Cangjie programming language. It covers essential operations including retrieving album lists, accessing images and videos, renaming albums, and adding or removing media assets. The documentation utilizes the MediaLibraryKit and photoAccessHelper modules, offering detailed code examples, permission handling, and API usage instructions. Suitable for developers building media-heavy applications, it ensures precise control over user content and system lifecycle management within the HarmonyOS ecosystem.
