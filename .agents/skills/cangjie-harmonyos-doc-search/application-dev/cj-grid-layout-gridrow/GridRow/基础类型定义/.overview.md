# 基础类型定义

This directory defines fundamental data types and configurations for building responsive grid layouts within the ArkUI framework using the Cangjie programming language. It covers essential classes for managing breakpoints, grid row options, gutter spacing, and size options across various device screen sizes (xs to xxl). Additionally, it includes enumerations for layout references and directions. These definitions are crucial for developers aiming to create adaptive user interfaces that respond dynamically to different viewport dimensions. The documentation is suitable for Cangjie developers and UI engineers working on system capabilities requiring ArkUI.Full support.

## Detailed Description

### class_BreakPoints.md class_BreakPoints.md
This API documentation defines the Cangjie BreakPoints class used to configure breakpoints for grid container components within the ArkUI framework. The document details the class structure, specifically covering the value property for setting breakpoint positions and the reference property for defining the switching reference, alongside the class constructor. Key information includes that the value property accepts a monotonically increasing array of Length types, defaulting to specific viewport values, while the reference defaults to WindowSize. This reference guide targets ArkUI developers implementing responsive layout capabilities.

### class_GridRowOptions.md class_GridRowOptions.md
This API reference document outlines the GridRowOptions class, which configures responsive grid column counts and offsets for different device breakpoints within the ArkUI framework. The main sections include the class definition, six nullable integer properties representing specific screen sizes (xs, sm, md, lg, xl, xxl), and two initialization methods. Key information highlights that properties are read-write and constructors allow setting values either individually per breakpoint or universally via a single parameter. Intended for Cangjie developers, this documentation facilitates the creation of adaptive user interfaces by defining layout behavior across varying screen widths.

### class_GutterOption.md class_GutterOption.md
This API documentation defines the GutterOption class, which specifies spacing for grid layout sub-components within the Cangjie ArkUI framework. The document details the class overview and two constructor overloads: one accepting optional Length types and another accepting GridRowSizeOption types. Key information includes that both constructors define horizontal (x) and vertical (y) spacing, with the Length version defaulting to 0.vp. This reference guide targets UI developers building responsive grid-based interfaces, providing the necessary parameters to control layout gaps effectively.

### enum_BreakpointsReference_2more.md enum_BreakpointsReference_2more.md
This document serves as API reference documentation for two enumerations used within the ArkUI framework for the Cangjie programming language. It details the BreakpointsReference enum, offering options like WindowSize and ComponentSize for setting responsive design references, and the GridRowDirection enum, which defines layout orientation via Row and RowReverse values. Both enums inherit from Equatable and include overloaded equality and inequality operators to compare enum values. All components require system capability SystemCapability.ArkUI.ArkUI.Full starting from version 22. The target audience is software developers utilizing the ArkUI framework to construct responsive and directional grid layouts in Cangjie applications.

### [5] class_GridRowSizeOption/
This directory provides essential API reference documentation for the `GridRowSizeOption` class within the ArkUI framework, specifically curated for Cangjie developers. It focuses on the configuration of grid gutter sizes and the implementation of responsive layouts across a diverse range of device breakpoints, including xs, sm, md, lg, xl, and xxl. The documentation thoroughly covers the class structure, its six public properties, and two constructors, enabling developers to manage responsive design adjustments with nullable Length types. This resource is ideal for developers seeking precise control over component sizing and offsets in grid layouts. It requires the system capability ArkUI.Full and is available starting from version 22, serving as a foundational guide for building adaptive and robust user interfaces in the ArkUI ecosystem.
