# cj-media-kit-intro

This directory acts as a technical guide for the Media Kit, a system service facilitating the development of audio and video playback and recording features. It provides an in-depth look at essential modules including AVPlayer, AVRecorder, AVScreenCapture, SoundPool, AVMetadataExtractor, and AVImageGenerator. The documentation explores critical processes such as media transcoding, screen recording workflows, metadata extraction, and thumbnail generation. Additionally, it outlines supported formats like MP4, MP3, H.264, and AAC, describes interaction architectures via the Cangjie interface, and maps data flow through frameworks like Camera and Audio. This resource is intended for application developers creating media apps who need a solid understanding of streaming protocols and system framework interactions.
