# cj-macro-prop

This directory serves as a specialized technical resource for the Cangjie ArkUI framework, specifically focusing on the `@Prop` decorator and its critical role in managing state between components. It provides an in-depth examination of one-way data synchronization, a fundamental pattern for maintaining predictable and efficient data flow in modern user interface development. The documentation covers essential technical aspects, including the protocols for variable initialization, the specific rules governing access, and the type constraints that developers must adhere to. Furthermore, it addresses the nuanced behavior where local changes to `@Prop` variables are preserved until a parent update overwrites them. The guide also extends into advanced territory, explaining how to manage complex data structures like nested objects and arrays by integrating the `@Observed` decorator. This content is highly suitable for HarmonyOS developers and software engineers who are looking to deepen their understanding of reactive programming, refine their state management strategies, and build robust, high-performance applications.

## Detailed Description

### Prop宏父子单向同步/

This subdirectory acts as a comprehensive technical guide dedicated to the `@Prop` macro within the Cangjie ArkUI ecosystem. Its primary focus is to elucidate the mechanisms behind one-way data synchronization from parent components to child components. The documentation thoroughly explores core concepts such as the initialization of variables, the strict rules regarding access, and the type constraints that ensure data integrity. A key feature of this guide is its explanation of the synchronization mechanism: it clarifies that while `@Prop` variables allow for local mutability within the child component, any updates originating from the parent component will overwrite these local changes, thereby enforcing a strict unidirectional state flow. Additionally, the content delves into more sophisticated scenarios, providing detailed instructions on how to handle nested objects and arrays effectively by utilizing the `@Observed` decorator. This makes the directory an essential reference for developers building HarmonyOS applications who need to master state management, implement precise data binding, and apply reactive programming patterns to optimize both component performance and overall application architecture.
