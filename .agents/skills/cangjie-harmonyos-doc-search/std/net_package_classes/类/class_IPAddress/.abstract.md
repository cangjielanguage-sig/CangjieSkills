This directory contains API reference documentation for the `IPAddress` class in the Cangjie standard library. It covers the representation and manipulation of Internet Protocol addresses, supporting both IPv4 and IPv6 formats. The documentation includes class definitions, property details, and methods for parsing, serialization, comparison, and validation. Key functionalities include DNS resolution, byte array conversion, and address type inspection (e.g., loopback, multicast). This resource is suitable for software developers and network engineers working with Cangjie who need to implement network programming logic, handle socket communications, or validate IP addresses programmatically.
