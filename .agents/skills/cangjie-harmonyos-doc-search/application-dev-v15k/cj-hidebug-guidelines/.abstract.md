This directory serves as a comprehensive resource for the `cj-hidebug-guidelines`, focusing on the integration and utilization of the HiDebug kit within the Cangjie programming language ecosystem. It provides in-depth documentation on accessing system-level debugging and performance analysis tools, specifically designed to help developers monitor critical application metrics effectively. The guide covers a wide array of essential features, including tracking memory statistics such as native heap size and PSS (Proportional Set Size), analyzing CPU usage patterns, and managing system resource limits. Additionally, it offers practical, step-by-step development examples to assist in implementing these monitoring features in real-world scenarios. This documentation is primarily intended for Cangjie developers who possess a working knowledge of the language and the DevEco Studio integrated development environment, enabling them to build high-performance applications with robust, integrated monitoring capabilities.
