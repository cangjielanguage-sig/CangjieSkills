# Rating

This directory provides comprehensive documentation and practical examples for the Rating component within the ArkUI framework using the Cangjie language. It covers essential aspects of implementing interactive star rating interfaces, including component initialization, property configuration, and event handling. Developers will find resources on customizing star styles, setting rating increments, and managing user interactions. Suitable for HarmonyOS application developers and UI designers, this collection facilitates the creation of both static displays and dynamic feedback controls, ensuring robust integration of rating functionalities into modern applications.

## Detailed Description

### Rating_4more.md Rating_4more.md
This document provides API reference documentation for the Rating component in the Cangjie language, designed for selecting ratings within a specified range. The content focuses on component initialization, detailing two constructors that accept either Float64 or Int64 for the rating value and an optional boolean indicator parameter. Key information includes that the rating value is clamped between 0 and the number of stars, and setting the indicator to true renders the component as a read-only display with specific default dimensions. The component supports all universal attributes and events. This reference guide targets ArkUI developers using Cangjie who need to implement interactive or static rating interfaces.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling change events on a Rating component within the ArkUI framework using the Cangjie language. It details two overloaded onChange functions, distinguishing between callbacks that accept a Float64 parameter representing the new rating and those that accept no parameters. Both functions return This to allow method chaining and are available from API version 12. The primary use case is capturing user interactions when the rating value is modified. This guide targets application developers implementing interactive rating bars in their UI, requiring knowledge of Cangjie syntax and ArkUI components.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring properties of a Rating component within the ArkUI framework using the Cangjie language. It details three primary functions: starStyle for visual customization, stars for setting the total count, and stepSize for defining rating increments. Key information includes support for asynchronous loading of local and network image URIs for different star states, with fallbacks to system defaults. The stars function defaults to 5, while stepSize accepts Float64 or Int64 values with a minimum of 0.1. This documentation targets UI developers seeking to implement and customize interactive rating controls in their applications.
