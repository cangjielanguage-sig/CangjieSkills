# 接口

This directory serves as a comprehensive repository for API documentation regarding interfaces within the Cangjie programming language, specifically focusing on extensions that significantly enhance Unicode capabilities. It covers essential utilities designed to extend the core `Rune` and `String` types, thereby enabling robust and efficient text processing. Key topics include detailed character classification, complex case conversion (upper, lower, title), string trimming, and locale-specific handling using `CasingOption`. The directory is organized into subdirectories that separate character-level logic from string-level logic, providing a clear structure for developers to locate specific functionalities. This documentation is indispensable for Cangjie developers who are building text processing engines, internationalization tools, or any application requiring precise character validation and transformation.

## Detailed Description

### interface_UnicodeRuneExtension/
This directory provides comprehensive API reference documentation for the `UnicodeRuneExtension` interface within the Cangjie programming language. It focuses on extending the `Rune` type to provide robust utilities for Unicode character handling. Key topics include character classification methods (such as identifying letters, numbers, and whitespace) and case conversion functions (including upper, lower, and title case). The documentation details function signatures, return types, and overloads that support locale-specific handling via `CasingOption`. This resource is essential for Cangjie developers building text processing engines, internationalization tools, or applications requiring precise character validation and transformation.

### interface_UnicodeStringExtension/
This directory contains API reference documentation for the `UnicodeStringExtension` interface in the Cangjie programming language. It focuses on extending the `String` type with advanced Unicode operations, including case conversion (toUpper, toLower, toTitle), whitespace trimming (trim, trimStart, trimEnd), and blank string detection. Key technical aspects involve handling `IllegalArgumentException` for invalid UTF-8 encoding and utilizing `CasingOption` for locale-specific rules. This documentation is suitable for Cangjie developers implementing internationalization, text sanitization, and precise string manipulation.
