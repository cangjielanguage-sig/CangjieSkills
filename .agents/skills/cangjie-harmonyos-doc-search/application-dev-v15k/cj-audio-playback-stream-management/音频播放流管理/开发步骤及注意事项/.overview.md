# 开发步骤及注意事项

This directory provides comprehensive technical guides and code examples for managing audio streams using the AudioStreamManager API within the Cangjie programming language. It covers the complete development lifecycle, including creating manager instances, subscribing to audio renderer change events via callbacks, and retrieving current audio renderer information. Key topics include implementing the AudioRendererChangeCallback interface, handling necessary permissions such as `ohos.permission.USE_BLUETOOTH` for accessing device details, and logging stream properties. These resources are specifically designed for application developers utilizing the AudioKit framework who need to handle audio state changes, monitor audio output, or debug audio device connections effectively.

## Detailed Description

### 开发步骤及注意事项_1.md
This document provides a step-by-step tutorial for managing audio streams using the AudioStreamManager API in the Cangjie programming language. Key sections cover creating an instance, subscribing to audio renderer change events via callbacks, unsubscribing, and retrieving current audio renderer information. Important takeaways include the implementation of the AudioRendererChangeCallback interface and the requirement for the ohos.permission.USE_BLUETOOTH permission to access specific device details like names and addresses. Targeted at application developers, this guide assumes familiarity with Cangjie syntax and the AudioKit framework for handling audio state changes and device management.

### 开发步骤及注意事项_2.md
This document provides a code example demonstrating how to retrieve and log detailed information about current audio renderers and their associated devices. The main topic covers audio stream management, specifically iterating through an array of renderer information to access stream properties and device descriptors. Key information includes the implementation of the getCurrentAudioRendererInfoArray function, which logs specific attributes such as stream ID, usage, flags, device type, role, name, address, sample rates, and channel counts. It also highlights error handling for business exceptions. This technical guide is intended for developers debugging audio output or implementing audio monitoring features, requiring knowledge of audio stream APIs and logging mechanisms. Keywords: audio renderer, stream management, device descriptors, logging, error handling, audioStreamManager.
