# cj-crypto-asym-encrypt-decrypt-spec

This directory serves as a comprehensive and authoritative repository for technical specifications and API references regarding asymmetric key encryption and decryption algorithms specifically designed for the Cangjie programming framework. It encompasses a wide array of critical cryptographic standards, with a particular focus on GM/T 0009-2012 (SM2) and various RSA implementations. The content provides in-depth details on encryption modes, padding schemes, and key configurations, ensuring developers have the necessary parameters for secure implementation. Furthermore, it addresses ciphertext components, parameter formats, and API version updates. This resource is primarily intended for software developers and security engineers who are tasked with implementing robust cryptographic operations, requiring a solid foundational understanding of asymmetric encryption concepts and modern security protocols to ensure data integrity and confidentiality.
