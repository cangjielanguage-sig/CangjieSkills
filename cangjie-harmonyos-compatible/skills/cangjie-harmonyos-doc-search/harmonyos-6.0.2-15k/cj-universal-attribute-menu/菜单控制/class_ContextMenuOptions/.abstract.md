This directory contains comprehensive API reference documentation for the `ContextMenuOptions` class in the Cangjie language, specifically designed for the ArkUI framework. It details the configuration of context menu parameters, covering essential aspects such as positioning, visual styling, animation behaviors, and lifecycle management. Key features include offset adjustments, placement logic, arrow display, background blur, and event callbacks like `onAppear`. This documentation is intended for UI developers and engineers building interactive interfaces who require granular control over context menu interactions, styles, and transitions, supporting system capabilities from API version 19 onwards.
