# ohosmultimediacamera相机管理

This directory contains comprehensive API reference documentation for the HarmonyOS Multimedia Camera Management module, designed for the Cangjie programming language. It covers the CameraKit framework, detailing classes, interfaces, enums, and structs necessary for camera hardware control, configuration, and session management. Key topics include camera input/output handling, focus and exposure settings, video stabilization, and metadata processing. This documentation is intended for software developers and multimedia engineers building camera-enabled applications on HarmonyOS, providing the technical specifications required to implement features like photo capture, video recording, and real-time preview.
