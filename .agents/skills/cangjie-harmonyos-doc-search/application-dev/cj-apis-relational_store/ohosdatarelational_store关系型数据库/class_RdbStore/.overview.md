# class_RdbStore

This directory contains API reference documentation for the `RdbStore` class in the Cangjie language, part of the ArkData kit for HarmonyOS application development. It covers the management of relational databases, including data manipulation (insert, update, delete, query), transaction control, backup and restore operations, and event subscription mechanisms. The documentation details function signatures, parameters, error codes, and usage examples for developers implementing data persistence. It is suitable for Cangjie developers working with relational data storage who need to handle database operations, ensure data consistency, and manage database lifecycles within their applications.
