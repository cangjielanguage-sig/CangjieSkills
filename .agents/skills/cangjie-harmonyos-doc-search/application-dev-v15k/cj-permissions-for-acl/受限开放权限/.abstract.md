This directory functions as a definitive guide for managing and applying restricted open permissions within the HarmonyOS and OpenHarmony development environments. It addresses the complex requirements developers face when seeking access to sensitive system capabilities that are otherwise protected. The content covers the complete lifecycle of permission management, beginning with the initial application process and eligibility criteria, moving through the App Gallery Connect (AGC) review, and concluding with the strict compliance audits required for app publication. It emphasizes the critical nature of matching usage scenarios to requested permissions to avoid rejection. Additionally, the directory provides detailed reference documentation for specific permissions introduced in API version 12, covering areas such as hardware access (HID, USB), file manipulation, data sharing, and advanced system features like virtual screens. It distinguishes between authorization types like system_grant and user_grant, outlining strict restrictions for enterprise and financial scenarios. This resource is essential for HarmonyOS developers and system engineers who need to securely implement high-risk functionalities while adhering to platform security standards.
