# struct_PhoneNumber

This directory contains API reference documentation for the `PhoneNumber` struct within the Cangjie ContactsData framework. It provides comprehensive details on the data structures used to represent contact phone numbers, including the specific properties and constructors required for instantiation. The documentation covers a wide array of static integer constants used to classify phone types, ranging from standard categories like Mobile and Home to specialized types such as Telex, TTY, and ISDN. It is suitable for application developers and system integrators who need to programmatically manage contact data, handle custom labels, and ensure correct data classification within their applications.
