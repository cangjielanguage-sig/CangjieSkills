This directory contains API reference documentation for the `ImagePacker` class in the Cangjie programming language, part of the ImageKit framework. It covers image compression, encoding, and file operations, supporting formats like JPEG and WebP. Key functionalities include packing image data from PixelMap or ImageSource objects into byte arrays or files, alongside essential memory management via the `release` method. The documentation details function signatures, parameters, return values, and specific `BusinessException` error codes. It is suitable for Cangjie developers working on multimedia applications who need to implement efficient image processing and resource management.
