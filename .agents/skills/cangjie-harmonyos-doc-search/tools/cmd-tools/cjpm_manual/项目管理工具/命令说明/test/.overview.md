## 详细描述

### test_1.md test_1.md
本文档介绍了仓颉包管理器中 `cjpm test` 命令的用法，用于编译并运行仓颉项目的单元测试。文档涵盖了命令功能描述、测试代码文件结构说明，以及单模块测试、单包测试和多包测试三种场景的具体示例。关键信息指出该命令默认执行当前模块测试而不包含依赖模块，编译产物存放于 `target/release/unittest_bin`，且执行前提是项目必须能成功构建。面向仓颉语言开发者，旨在指导其使用 `std.unittest` 库进行代码验证和测试结果分析。

### test_2.md test_2.md
该文档展示了 cjpm test 命令的执行输出日志，旨在说明测试结果的格式与状态。内容涵盖 test.koo 和 test 两个测试包的详情，包括测试套件、用例通过状态及耗时，并提供了项目整体测试的汇总统计。关键信息显示所有测试均通过，且文档末尾提示 test 命令具备多种可配置项。这是一份面向 cjpm 开发者的参考文档或教程片段，用于辅助理解测试输出及配置。

### test_3.md test_3.md
本文档是 cjpm test 命令的参考手册，详细说明了单元测试相关的命令行参数配置。主要涵盖编译控制（如并发数、增量编译）、测试筛选（如模块、过滤器、标签）、执行策略（如并行、超时）及输出报告（如覆盖率、XML格式）。关键信息包括通过 --filter 和 --include-tags 精准匹配测试用例，以及利用 --parallel 和 --coverage 优化测试性能与统计。文档面向使用 cjpm 构建工具的开发者，旨在提供全面的测试配置选项以支持灵活的测试流程管理。

### test_4.md test_4.md
本文档旨在提供 cjpm test 命令的参数使用示例，涵盖覆盖率生成、测试过滤及报告格式配置。主要内容包括使用 cjcov 生成 HTML 覆盖率报告、通过通配符过滤测试以及输出 XML 格式报告。关键点在于 cjpm test 会自动构建支持 Mock 的包，若需对二进制依赖进行 Mock，需预先使用 cjpm build --mock。这是一份面向开发者的参考文档，适用于配置测试流程和代码覆盖率分析的场景。关键词：cjpm test, 覆盖率, Mock, 测试配置。
