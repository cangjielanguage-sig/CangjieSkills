## 组件事件

### func onSelect((Bool) -> Unit)

```cangjie
public func onSelect(callback: (Bool) -> Unit): This
```

**功能：** ListItem元素被鼠标框选的状态改变时触发回调。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|(Bool)->Unit|是|-|ListItem元素被鼠标框选的状态改变时触发回调。进入鼠标框选范围即被选中为true， 移出鼠标框选范围即未被选中为false。|
