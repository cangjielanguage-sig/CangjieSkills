This directory provides comprehensive API documentation and implementation guides for the `ohos.telephony_call` module within the Cangjie programming environment, specifically designed for HarmonyOS development. It covers essential telephony features including making direct calls, launching the dialer interface, monitoring call states, and formatting phone numbers. Key components documented include the `TelephonyCall` class, `NumberFormatOptions`, `CallState`, and emergency number handling. This resource is suitable for HarmonyOS developers and system integrators looking to build robust call management applications using TelephonyKit.
