This directory provides a comprehensive collection of API reference documentation for the OpenHarmony vibrator module, specifically tailored for the Cangjie programming language. It serves as an essential resource for developers aiming to implement sophisticated haptic feedback and precise device motor control within the HarmonyOS ecosystem. The documentation covers a wide array of functionalities, including the creation of custom vibration profiles, the utilization of preset effects, and the management of duration-based vibrations. Key components detailed in this module include enumerations for defining usage scenarios and stop modes, as well as the core functions required to initiate and cease vibration operations. This resource is primarily suitable for Cangjie developers leveraging the SensorServiceKit to integrate advanced tactile features into their applications, provided they have secured the necessary `ohos.permission.VIBRATE` permissions.
