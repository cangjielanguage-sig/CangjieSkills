# cj-want-overview

本目录包含关于Cangjie语言开发中Want对象的概述文档。Want是HarmonyOS应用组件间信息传递的重要载体。文档详细介绍了Want的定义与用途，重点区分了显式Want和隐式Want两种类型，涵盖了通过指定组件名称启动应用内组件，以及通过系统匹配规则调用跨应用能力的场景。内容适用于使用Cangjie语言的HarmonyOS开发者，特别是涉及UIAbility启动及组件间数据交互的开发人员。

## 详细说明

### cj-want-overview.md cj-want-overview.md

本文档旨在介绍Cangjie开发中Want对象的定义、用途及其在应用组件间传递信息的作用。主要涵盖Want的定义与用法，详细区分了显式Want和隐式Want两种类型，并提供了Cangjie代码示例。显式Want通过指定bundleName和abilityName启动应用内组件；隐式Want则通过action、entities等参数由系统匹配目标组件，适用于跨应用能力调用，并说明了匹配失败、唯一匹配及多选匹配的三种情况。面向使用Cangjie语言的HarmonyOS开发者，适用于需要启动UIAbility及组件间数据传递的场景。
