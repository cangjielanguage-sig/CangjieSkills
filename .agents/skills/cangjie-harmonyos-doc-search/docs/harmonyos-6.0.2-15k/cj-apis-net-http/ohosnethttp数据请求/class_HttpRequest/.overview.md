### class_HttpRequest_8more.md class_HttpRequest_8more.md
This document provides API reference documentation for the HttpRequest class within the Cangjie NetworkKit, specifically focusing on request lifecycle management and event handling. It details methods for interrupting HTTP tasks and managing subscriptions for streaming response events. Key sections include the destroy function for stopping tasks, a series of off methods to cancel subscriptions for data reception, progress updates, and headers, and the onDataEnd method to subscribe to completion events. Important notes indicate that off methods clear all subscriptions and that the class requires the SystemCapability.Communication.NetStack capability. This technical reference is intended for Cangjie developers who need to control HTTP request behaviors and handle asynchronous network events in their applications.

### func_onDataReceiveArrayByt_5more.md func_onDataReceiveArrayByt_5more.md
This document provides API reference documentation for HTTP event subscription functions within the Cangjie NetworkKit module. It details five specific functions: `onDataReceive`, `onDataReceiveProgress`, `onDataSendProgress`, `onHeadersReceive`, and `onceHeadersReceive`. Key information includes that each function accepts a callback to handle events like streaming data chunks, transfer progress, or response headers. Notably, `onDataReceive` does not support upload streaming events, while `onceHeadersReceive` automatically unregisters after a single trigger. This guide targets developers using the Cangjie language to implement network communication features, requiring knowledge of HTTP protocols and asynchronous callback handling.
