# 基础类型定义

This directory provides fundamental type definitions for configuring Flex layouts in the ArkUI framework using the Cangjie language. It encompasses classes that define the structural and spatial properties of Flex containers, including alignment, direction, wrapping, and spacing between child components. Key types covered include `FlexParams`, `FlexSpaceOptions`, and `FlexOptions`, which allow developers to manipulate main and cross axes precisely. This documentation is intended for ArkUI developers and UI engineers who need to programmatically control flexible, responsive layouts and require a solid understanding of Flex layout mechanics.

## Detailed Description

### class_FlexParams.md class_FlexParams.md
This API reference document defines the FlexParams class, which configures the alignment and arrangement of child components within a Flex container in the Cangjie language. The documentation details the class constructor and five public properties: direction, wrap, justifyContent, alignItems, and alignContent. Key information includes how each property controls specific layout behaviors, such as main axis direction, line wrapping, and alignment along the main and cross axes, with alignContent specifically applying to multi-line layouts. Intended for ArkUI developers, this guide provides the necessary parameters to programmatically define Flex layout behaviors. Keywords: FlexParams, Flex layout, ArkUI, Cangjie, alignment, direction, wrap.

### class_FlexSpaceOptions.md class_FlexSpaceOptions.md
This API reference document details the FlexSpaceOptions class used to configure spacing between child components in a Flex container within the ArkUI framework. The documentation covers the class definition, two public properties (mainSpace and crossSpace), and the class constructor. Key information includes that both properties are of type Length, are read-write, and define spacing along the main and cross axes respectively. The constructor initializes these values using named parameters with a default of 0.px. This resource is intended for UI developers using the Cangjie language to build ArkUI interfaces, requiring prerequisite knowledge of Flex layouts and the Length data type.

### class_FlexOptions/
This directory contains comprehensive API reference documentation for the `FlexOptions` class utilized within the Cangjie language and the ArkUI framework. It serves as a technical guide for configuring layout properties specific to Flex containers, allowing developers to manipulate the alignment, direction, and spatial arrangement of child components. The documentation covers essential aspects such as the class constructor, public properties like `direction`, `wrap`, and `justifyContent`, and critical layout constraints regarding wrapping and spacing. This resource is specifically tailored for software developers and UI engineers working on ArkUI interfaces who require precise, programmatic control over flexible layouts and possess a foundational understanding of Flex layout concepts and Cangjie syntax. By detailing the interaction between main and cross axes, these documents provide the necessary specifications for building responsive and adaptive user interfaces.
