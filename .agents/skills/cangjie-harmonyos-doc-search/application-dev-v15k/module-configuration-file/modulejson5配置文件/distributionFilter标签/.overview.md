# distributionFilter标签

This directory provides comprehensive reference documentation for the `distributionFilter` tag, a vital tool for HarmonyOS developers aiming to implement precise HAP (HarmonyOS Ability Package) distribution strategies in cloud app delivery. It covers the complete configuration framework required to filter application delivery based on granular device specifications, including screen shape, window resolution, pixel density, and country code. The documentation addresses complex scenarios such as overlapping device types and ensures developers understand the strict rules for attribute consistency across Entry modules. It is specifically designed for developers managing multi-module applications who need to guarantee that the correct application package is dynamically delivered to the user's device based on hardware capabilities and regional settings. Additionally, it details the specific file placement requirements within the /resources/base/profile directory to ensure proper system recognition.
