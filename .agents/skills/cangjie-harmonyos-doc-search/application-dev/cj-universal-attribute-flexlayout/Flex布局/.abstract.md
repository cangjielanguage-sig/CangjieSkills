This directory provides essential API reference documentation for Flex layout properties within the ArkUI framework, specifically designed for developers using the Cangjie language. It covers critical layout functions including `alignSelf`, `flexBasis`, `flexGrow`, and `flexShrink`, detailing their parameters, return values, and system capabilities. The documentation explains how to manipulate component sizing, alignment, and space distribution within parent containers such as Flex, Column, Row, and GridRow. It addresses specific behaviors like overriding parent alignment and setting shrink ratios. This resource is ideal for ArkUI developers and UI engineers aiming to create responsive, adaptive, and precise user interfaces.
