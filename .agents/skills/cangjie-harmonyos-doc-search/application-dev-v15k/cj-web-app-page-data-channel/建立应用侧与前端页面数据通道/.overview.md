# 建立应用侧与前端页面数据通道

This directory provides a comprehensive technical guide focused on establishing a robust bidirectional data channel between a Cangjie application and a frontend web page. It specifically addresses the implementation of Message Ports within the ArkWeb component ecosystem, enabling seamless communication between native code and web environments. The content covers the entire workflow, from generating ports on the application side to handling events and data transmission in HTML/JavaScript. Key technical concepts include `createWebMessagePorts`, `onMessageEvent`, and `postMessage` for handling data types like String and ArrayBuffer. This resource is primarily suitable for developers engaged in hybrid application development who possess a foundational understanding of asynchronous event handling and web-native integration. By following these examples, developers can effectively bridge the gap between the native Cangjie environment and standard web technologies.
