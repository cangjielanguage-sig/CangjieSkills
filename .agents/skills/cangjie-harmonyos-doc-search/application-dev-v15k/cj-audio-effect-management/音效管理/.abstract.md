This directory provides comprehensive technical documentation for managing audio effects within the Cangjie development environment, specifically utilizing the AudioKit framework. It covers the entire lifecycle of audio effect control, ranging from querying global effect modes for specific stream usage scenarios to managing effects within individual playback instances. Key concepts include AudioStreamManager, AudioRenderer, StreamUsage, and AudioEffectMode (EFFECT_NONE, EFFECT_DEFAULT). These guides are designed for Cangjie developers and audio engineers who need to dynamically configure audio settings, handle exceptions, and ensure optimal sound quality for various playback contexts.
