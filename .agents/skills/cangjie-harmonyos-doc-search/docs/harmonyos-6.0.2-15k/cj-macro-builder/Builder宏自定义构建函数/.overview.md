## Detailed Description

### Builder宏自定义构建函数_2more.md Builder宏自定义构建函数_2more.md
This technical guide explains how to use the @Builder macro in Cangjie UI to create reusable custom build functions for UI elements. It details two implementation methods: private custom build functions defined within components and global custom build functions defined outside components. Key takeaways include that private functions act as special member functions accessing component state variables via this, while global functions are recommended for stateless UI reuse. Both types support parameters and can be called within build methods or other builders. Intended for Cangjie UI developers familiar with declarative UI syntax and custom components.

### 参数传递规则_2more.md 参数传递规则_2more.md
This technical guide outlines parameter passing rules for custom @Builder functions in the ArkUI/Cangjie framework. It distinguishes between pass-by-value and pass-by-reference mechanisms, detailing their impact on UI rendering and state management. Key takeaways include that pass-by-value is the default but does not trigger UI refreshes when state variables change, whereas pass-by-reference is required for dynamic UI updates. The document specifies that only single object literals are passed by reference and prohibits parameter modification within @Builder functions. Intended for UI developers, this reference ensures correct state synchronization and component behavior. Keywords: @Builder, pass-by-value, pass-by-reference, state variables, UI refresh, ArkUI, Cangjie.
