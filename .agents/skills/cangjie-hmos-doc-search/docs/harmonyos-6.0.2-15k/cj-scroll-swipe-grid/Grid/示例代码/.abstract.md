This directory contains a collection of practical code examples demonstrating advanced Grid component implementations in the Cangjie programming language for HarmonyOS development. It covers essential features such as scrollable grids with event handling, drag-and-drop reordering, adaptive column layouts, and nested scrolling scenarios. Additionally, it includes tutorials on visual customization like edge fading and height alignment. These examples are suitable for developers looking to master complex UI layouts and interactive behaviors using the ArkUI framework.
