This directory contains API reference documentation for the `ohos.telephony_observer` module in the Cangjie programming language. It focuses on the management of telephony communication subscriptions, enabling developers to monitor and react to various system states such as network status, signal information, call states, and SIM card changes. Key components include configuration classes, enumerations for lock reasons and event types, and the main observer class for handling asynchronous callbacks. This documentation is suitable for Cangjie developers integrating telephony monitoring features into their applications, requiring knowledge of system capabilities and event-driven architecture.
