# 接口

This directory serves as a comprehensive repository for API reference documentation regarding core interfaces in the Cangjie programming language, with a specific focus on JSON data manipulation. It encompasses the essential protocols required for both serializing native objects into JSON format and deserializing JSON streams back into Cangjie types. The documentation covers a wide range of data structures, including primitive types, complex collections, and specialized classes such as `DateTime` and `BigInt`. It is an essential resource for software developers and system architects who are building robust applications in Cangjie that require efficient data interchange, configuration management, or API integration through JSON.

## Detailed Description

### interface_JsonDeserializableT/

This directory provides the API reference documentation for the `JsonDeserializable` interface within the Cangjie language. It offers a detailed explanation of how various data types implement this interface to facilitate the parsing of JSON data streams. The content is extensive, covering extension definitions for basic types (integers, floating-point numbers, strings), standard collection types (ArrayList, HashMap, Array), and special types (BigInt, DateTime). Key areas of focus include the practical usage of the `fromJson` static method, the specific rules governing type conversions, and the exception handling mechanisms designed to manage errors such as numeric overflows. This documentation is highly suitable for developers working on Cangjie projects who need to implement reliable JSON data parsing and type conversion logic.

### interface_JsonSerializable/

This directory contains the API reference documentation for the `JsonSerializable` interface in the Cangjie language. It thoroughly covers the core definition of the interface and its extension implementations across a multitude of data types. The subject matter includes the JSON serialization mechanisms for basic numeric types (such as Int and Float), string types, collection types (such as Array, HashMap, and Option), as well as special types (like DateTime and BigInt). The documentation emphasizes the core functionality of the `toJson` method, which is used to write data to a `JsonWriter` to achieve efficient stream encoding. This guide is intended for developers who need to perform JSON data processing and serialization within their Cangjie applications, ensuring data can be easily exported or transmitted.
