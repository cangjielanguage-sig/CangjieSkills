This directory contains documentation and examples for implementing color gradients within the ArkUI framework using the Cangjie programming language. It covers essential API references for linear, sweep, and radial gradient functions, detailing parameters like color stops, angles, and center points. The content is designed to help developers enhance UI components with complex visual styling, including repeating modes and specific rendering behaviors. Suitable for developers working on ArkUI applications who need to apply advanced gradient effects to their user interfaces.
