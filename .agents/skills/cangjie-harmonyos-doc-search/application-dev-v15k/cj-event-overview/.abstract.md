This directory serves as a comprehensive technical reference and guide for developers aiming to master interaction event handling within the framework. It provides an in-depth analysis of the event system, clearly distinguishing between general events—such as those triggered by touch, keyboard, mouse, focus, and drag operations—and complex gesture events. Key topics include the event distribution mechanism, response chains, and the logic behind event priorities, which are essential for creating responsive user interfaces. Furthermore, it details the architecture of gestures, covering binding methods, single gesture units, and combined gestures formed by specific rules. This documentation is suitable for developers seeking to implement robust input handling, optimize component interaction logic, and understand the underlying flow of user inputs from hardware to application response. It is an essential guide for ensuring that applications react predictably and efficiently to user behavior, providing the necessary context for debugging and enhancing user experience.
