This directory provides a comprehensive guide on implementing inter-application navigation using Deep Linking technology within the HarmonyOS ecosystem. It covers the underlying principles of URI-based app launching, implicit Want matching, and the specific configuration required for both calling and target applications. Key topics include the `openLink` API, `module.json5` configuration, and lifecycle callbacks like `onNewWant`. This resource is suitable for HarmonyOS developers using the Cangjie programming language and ArkUI framework who need to enable seamless cross-app jumps and web-to-native transitions.
