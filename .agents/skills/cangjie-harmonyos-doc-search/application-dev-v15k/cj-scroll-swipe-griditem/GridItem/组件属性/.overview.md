# 组件属性

This directory contains API reference documentation for component properties within the ArkUI framework, specifically focusing on Grid and GridItem layout configurations using the Cangjie language. It covers essential functions for defining grid positioning, such as setting row and column start/end indices, as well as managing interactive states like selection behavior. Key topics include grid item spanning, coordinate system constraints, and the relationship between layout templates and item placement. This documentation is suitable for developers utilizing ArkUI system capabilities to build complex, responsive, and interactive grid-based user interfaces, providing the necessary parameters and logic for precise UI control.

## Detailed Description

### func_columnEndInt32.md
This document serves as API reference documentation for the columnEnd function in the ArkUI framework, detailing how to set the ending column index for a grid item. It covers the function signature, system capabilities, version requirements, and a detailed parameter table defining the columnEnd integer value. Key information includes the valid value range [0, total columns - 1] and the requirement to pair this with columnStart. The document provides specific logic for how grid items behave when columnTemplate and rowTemplate are configured, emphasizing that layout rules depend heavily on these template settings. Targeted at developers using the ArkUI framework to build grid layouts, this reference requires knowledge of Grid components and layout options.

### func_rowStartInt32_3more.md
This document serves as API reference documentation for layout positioning functions in the ArkUI framework using the Cangjie language. It covers three primary functions: rowStart, rowEnd, and columnStart, which are used to define the specific grid coordinates for elements. Key details include the required Int32 parameters for row and column indices, their valid value ranges, and recommendations to utilize Grid.layoutOptions for complex spanning scenarios. This guide targets developers implementing grid-based UI components who require precise control over element placement and layout structure.

### func_selectableBool_2more.md
This document provides API reference documentation for the Cangjie ArkUI framework, specifically detailing methods to control GridItem selection behavior. It covers two main functions: selectable, which determines if an item can be selected via mouse dragging, and selected, which sets the item's active selection state. Key takeaways include that selectable defaults to true and depends on the outer Grid container's configuration, while selected defaults to false. Both functions accept a boolean value and return the current instance for chaining. This reference is intended for developers using ArkUI system capabilities version 19 or higher to build interactive grid interfaces.
