# 触摸事件

This directory focuses on touch event handling within the HarmonyOS ArkUI framework using the Cangjie programming language. It covers the implementation of touch interactions, including event callbacks, state management with `@State`, and data retrieval such as coordinates and timestamps. The content includes practical code examples demonstrating UI layout construction with Column and Button components, as well as API references for the `onTouch` function supported from system version 12. Additionally, it provides definitions for core data structures like `TouchEvent` and `TouchObject`. It is suitable for HarmonyOS developers looking to build interactive and responsive user interfaces and understand the underlying event propagation logic.

## Detailed Description

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating how to implement and handle touch events within a HarmonyOS application UI. The primary topics include UI layout construction using Column and Button components, state management with @State, and the implementation of the onTouch event callback. Key takeaways involve capturing detailed touch event data such as event type, timestamp, touch point coordinates, and the target component's position and dimensions, which are then displayed in a Text view and logged. This example is intended for HarmonyOS developers using the Cangjie language to understand event handling and UI component interaction.

### 触摸事件_3more.md 触摸事件_3more.md
This document provides API reference documentation for handling touch events in the ArkUI framework using the Cangjie language. It details the `onTouch` function, which triggers callbacks when users perform finger actions such as pressing, sliding, or lifting on a component. The main sections include a general description, permission requirements (none), and the function signature. Key information highlights that the function requires a mandatory callback parameter of type `TouchEvent` and is supported from system version 12. This resource is intended for developers building interactive user interfaces who need to implement touch-based event handling logic.

### 基础类型定义/
This directory provides essential API reference documentation for fundamental data structures within the ArkUI framework, specifically designed for the Cangjie programming language. It focuses on the core classes required to handle user input and touch interactions effectively. The documentation covers the `TouchEvent` class, which encapsulates event data and propagation logic, and the `TouchObject` class, which defines the specific attributes of individual touch points, such as coordinates and identification. These resources are critical for developers aiming to build interactive and responsive UI applications, offering detailed insights into event handling mechanisms and coordinate systems.
