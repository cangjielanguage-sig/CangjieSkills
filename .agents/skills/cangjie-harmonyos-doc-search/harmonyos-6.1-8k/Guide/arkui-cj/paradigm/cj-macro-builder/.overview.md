# cj-macro-builder

This directory serves as a comprehensive technical guide for the `cj-macro-builder` project, focusing specifically on the advanced implementation and optimization of the `@Builder` macro within the Cangjie UI and ArkUI frameworks. It provides a structured approach to understanding how custom build functions are defined and utilized to create modular, reusable UI components. Key topics include the architectural differences between private and global functions, the technicalities of parameter passing (by value vs. by reference), and the implementation of dynamic UI refreshing through state variable access. This documentation is specifically curated for developers who have already mastered basic syntax and declarative UI concepts, offering the necessary depth to tackle complex interaction logic and achieve high-performance UI rendering in modern application development.

## Detailed Description

### [1] Builder宏自定义构建函数/
This directory provides an in-depth exploration of the `@Builder` macro, a pivotal feature in the Cangjie UI and ArkUI frameworks designed to enhance UI development efficiency. The content meticulously details the methods for defining custom build functions, clarifying the functional differences between private and global functions to help developers scope their code correctly. It further delves into the technicalities of parameter passing, providing clear guidelines on when to pass parameters by value versus by reference to optimize performance and behavior.

Beyond the basics, the guide covers advanced usage scenarios, with a strong focus on the UI reuse mechanism which promotes code modularity. It also explains how to effectively access state variables and implement dynamic UI refreshing, ensuring that applications remain responsive and interactive. This section is tailored for developers who already possess knowledge of basic syntax and declarative UI descriptions, aiming to elevate their skills in implementing lightweight UI component reuse and complex interaction logic.
