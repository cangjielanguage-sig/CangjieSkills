This directory provides resources for implementing global custom dialogs in Cangjie HarmonyOS applications using the `openCustomDialog` API. It addresses the limitations of `CustomDialogController` by enabling dynamic creation and refreshing of dialog content. Key topics include parameter input methods (`CustomDialogOptions` and Lambda expressions), dialog lifecycle management, and ID-based control. This collection is ideal for ArkUI developers seeking to create flexible, decoupled popup interfaces using `getUIContext().getPromptAction()`.
