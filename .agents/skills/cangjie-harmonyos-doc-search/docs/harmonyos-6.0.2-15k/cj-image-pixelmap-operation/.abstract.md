This directory is a dedicated resource for Cangjie developers focusing on the intricacies of image processing via the PixelMap class. It provides an in-depth tutorial on performing essential bitmap operations, which are crucial for developing features such as image beautification. The guide covers a wide range of topics, including how to retrieve image metadata, read and write pixel data for entire images or specific regions, and execute deep copies of PixelMaps. It also highlights critical technical considerations, such as the importance of pairing read and write methods to prevent format inconsistencies and ensuring pixel format compatibility during the cloning process. By including practical Cangjie code snippets for functions like `readPixelsToBuffer` and `writeBufferToPixels`, this document is tailored for developers who possess prior knowledge of image decoding and are looking to implement precise pixel-level editing and robust image manipulation in their software projects. This overview ensures developers have the necessary tools to handle complex image data structures efficiently.
