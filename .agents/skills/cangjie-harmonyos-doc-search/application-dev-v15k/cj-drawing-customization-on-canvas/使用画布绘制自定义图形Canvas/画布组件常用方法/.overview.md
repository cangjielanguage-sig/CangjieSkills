# 画布组件常用方法

This directory contains documentation and tutorials for the Canvas component in the Cangjie programming language, specifically within the ArkUI framework. It covers essential 2D drawing operations including shape rendering, text manipulation, image processing, and gradient effects. Key topics include `CanvasRenderingContext2D`, drawing primitives like rectangles and circles, pixel data manipulation, and creating linear or radial gradients. These resources are designed for developers using Cangjie to build UI applications requiring advanced graphics rendering capabilities.

## Detailed Description

### 画布组件常用方法_1.md
This document serves as a practical guide for utilizing common methods of the Canvas component in the Cangjie programming language. It focuses on the CanvasRenderingContext2D object, detailing how to manipulate drawing styles using properties like fillStyle and strokeStyle. The main sections cover drawing basic shapes, such as rectangles, circles, and ellipses using methods like rect and arc, and rendering text via fillText and strokeText. Key takeaways include the provided Cangjie code snippets that demonstrate step-by-step implementation of these graphics. This tutorial is intended for developers looking to integrate 2D drawing capabilities into their applications.

### 画布组件常用方法_2.md
This document provides code examples and explanations for common Canvas component methods in the Cangjie language, focusing on text rendering and image pixel manipulation. Main topics include text filling and stroking using fillText and strokeText, as well as image drawing and pixel data handling via drawImage, getImageData, and putImageData. Key takeaways demonstrate how to configure fonts, draw images onto an OffscreenCanvas, extract pixel data, and render it back to the main Canvas. Intended for developers building UI applications using the ArkUI framework and Cangjie programming language who need advanced graphics rendering capabilities.

### 画布组件常用方法_3.md
This document serves as a tutorial for implementing gradient effects within the Canvas component using the Cangjie language. It focuses on gradient-related methods, specifically createLinearGradient and createRadialGradient, and explains the usage of the CanvasGradient object. The key takeaway is the practical code example demonstrating how to create a radial gradient, define color stops with offsets and colors, and apply the fill style to a rectangle. This guide is intended for ArkUI developers who possess prerequisite knowledge of Cangjie syntax and basic canvas rendering concepts. Keywords: Canvas, Cangjie, ArkUI, Gradient, createRadialGradient, RenderingContext2D.
