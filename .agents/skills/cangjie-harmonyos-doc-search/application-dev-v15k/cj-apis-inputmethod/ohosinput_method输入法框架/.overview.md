# ohosinput_method输入法框架

This directory contains the API reference documentation for the HarmonyOS Input Method Framework (ohos.input_method) using the Cangjie programming language. It covers essential components for developing and managing input method editors (IMEs), including data structures for text attributes, keyboard configurations, and event handling. Key topics include input method properties, subtypes, window management, and system capabilities. The documentation is designed for developers building input method services or integrating text input controls into their applications, providing the necessary interfaces to control keyboard behavior, cursor movement, and text editing operations.
