## Detailed Description

### SysCap开发指导.md SysCap开发指导.md
This guide instructs developers on managing System Capabilities (SysCap) to ensure application compatibility across different devices. It covers adding custom SysCap configurations via JSON, distinguishing between single and cross-device development logic, and using the Cangjie canIUse API for runtime checks. Key information includes the SysCap lifecycle, from OS component assembly to PCID and RPCID encoding, and handling capability variations between devices. Targeting application developers using DevEco Studio, this document provides essential strategies for optimizing apps for diverse hardware configurations and ensuring proper API availability. Keywords: SysCap, System Capability, DevEco Studio, Cangjie, Cross-device development, PCID, RPCID, API compatibility.

### 概述.md 概述.md
This document provides an overview of System Capability (SysCap) concepts within the HarmonyOS ecosystem, explaining how system features relate to APIs and device compatibility. It covers SysCap definitions, the relationship between supported, required, and association capability sets, device classifications (typical vs. custom), and SDK integration with DevEco Studio. A core takeaway is the compatibility rule: an application can only be distributed to a device if its required capability set is a subset of the device's supported set. DevEco Studio filters API suggestions based on the selected device's capabilities. This technical reference guide targets HarmonyOS developers using DevEco Studio to ensure their applications are compatible with specific hardware configurations.
