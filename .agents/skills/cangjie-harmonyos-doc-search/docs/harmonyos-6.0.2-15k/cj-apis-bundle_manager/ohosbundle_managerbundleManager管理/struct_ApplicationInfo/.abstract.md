It details the structural definition of application metadata, configuration properties, and resource management. Key topics include application permissions, bundle types, localized resources (icons, labels), and system attributes like process info and release types. This resource is essential for Cangjie developers looking to query application attributes, manage resources, and ensure compatibility with system SDKs.
