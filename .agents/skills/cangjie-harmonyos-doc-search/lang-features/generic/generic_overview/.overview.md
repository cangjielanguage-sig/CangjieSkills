# generic_overview

### generic_overview.md generic_overview.md

本文档旨在介绍仓颉编程语言中泛型的基本概念，解释参数化类型的定义及其在类型和函数声明中的应用。文档涵盖了泛型的适用范围（如函数、类、接口等），并详细定义了类型形参、类型变元、类型实参和类型构造器等核心术语。核心要点在于泛型允许在声明时使用未知类型，并在使用时指定具体类型。通过 List<T> 示例，文档清晰展示了类型形参与实参的区别，以及如何通过类型构造器构建具体类型。本文属于基础概念参考文档，面向仓颉语言的开发者，帮助他们掌握泛型术语和语法结构。
