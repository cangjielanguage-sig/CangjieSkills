# Navigation

This directory provides comprehensive documentation for the ArkUI Navigation component using the Cangjie language. It covers the implementation of root view containers, routing management, and UI customization for multi-page applications. Key topics include the `NavPathStack` for state management, `NavDestination` for sub-pages, and configuration of title bars and toolbars. The content includes API references for constructors and properties, practical code examples for navigation flows, and definitions of fundamental data structures. It is suitable for HarmonyOS developers building complex user interfaces requiring robust page navigation logic and lifecycle management.

## Detailed Description

### Navigation_5more.md Navigation_5more.md
This document serves as API reference for the Navigation component within the ArkUI framework using the Cangjie language. It defines Navigation as a root view container for routing navigation, managing title bars, content areas, and toolbars. Key sections include the module import, subcomponent support, and two initialization methods: a basic constructor and one binding a NavPathStack for routing. Important notes address lifecycle behavior in nested scenarios and title bar visibility rules. The content targets developers implementing page navigation and routing logic, providing specific syntax details for constructors and parameters.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating the implementation of page routing and navigation using the ArkUI Navigation component in Cangjie. It covers the setup of a root Navigation container, a page mapping function for routing logic, and the creation of sub-pages using NavDestination. Key concepts include managing the NavPathStack for state, using @Provide and @Consume for dependency injection, and handling navigation actions like pushPath, pushPathByName, and pop. Intended for developers building multi-page applications, this example illustrates the standard flow from a home page to sub-pages and back navigation.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring component properties within the Cangjie ArkUI framework. It details three specific functions: hideTitleBar for controlling title bar visibility with optional animation, navDestination for creating navigation pages using a builder function, and title for setting page headers via custom builders or resource strings. Key information includes function signatures, parameter types, default values, and system capability requirements starting from version 22. This technical guide is intended for HarmonyOS developers seeking to implement navigation and title management in their applications.

### 基础类型定义/
This directory contains API reference documentation for fundamental data structures and enumerations used in navigation within the ArkUI framework, specifically for the Cangjie language. It covers essential classes for managing navigation stacks (`NavPathStack`), defining path information (`NavPathInfo`), and configuring navigation behaviors (`NavigationOptions`, `LaunchMode`). Additionally, it includes definitions for UI customization like title bar settings (`NavigationTitleOptions`) and pop operation results (`PopInfo`). These documents are intended for developers building user interfaces who need to implement complex page navigation logic, handle page lifecycles, and customize navigation transitions and styles in ArkUI applications.
