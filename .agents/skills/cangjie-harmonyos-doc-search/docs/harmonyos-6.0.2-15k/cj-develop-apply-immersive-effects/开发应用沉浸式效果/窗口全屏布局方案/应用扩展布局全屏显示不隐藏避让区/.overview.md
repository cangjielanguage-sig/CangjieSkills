# 应用扩展布局全屏显示不隐藏避让区

This directory provides comprehensive technical guides for implementing immersive full-screen layouts in HarmonyOS applications where content extends into system bars without hiding them. It covers essential techniques for retrieving avoidance area dimensions, registering dynamic listeners for layout changes, and adjusting UI padding to prevent content overlap with status and navigation bars. Key topics include the use of `setWindowLayoutFullScreen`, `getWindowAvoidArea`, and ArkTS `@StorageProp` for state management. These resources are specifically suitable for HarmonyOS developers using Cangjie or ArkUI who need to create responsive, adaptive interfaces that handle complex scenarios like screen rotation, multi-window modes, and dynamic system bar visibility. The guides ensure that applications remain visually immersive while maintaining usability by respecting system UI boundaries.
