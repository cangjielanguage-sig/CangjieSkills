# 密钥材料格式

This directory provides comprehensive technical specifications for the data formats used in cryptographic key materials within the HUKS system. It covers the structural definitions for public keys, private keys, and key pairs across various algorithms like RSA, ECC, and DSA. The documentation details byte-level layouts, X.509 DER encoding standards, and specific implementation examples using the Cangjie language. It is designed for developers and security engineers who need to implement secure key management, import/export processes, or low-level cryptographic storage mechanisms.

### 私钥材料格式.md 私钥材料格式.md
This technical reference document defines the structural format for encapsulating private key material within a cryptographic system. It explains that private key formats reuse the key pair material structure but modify the header by setting the public key length field to zero. The document details the composition formula, Private Key Material equals Key Pair Material Header plus Private Key Material Body, and provides a concrete RSA 2048 example using Cangjie code to demonstrate the byte-level layout of algorithm identifiers, key sizes, and modulus data. This guide is intended for developers and security engineers implementing low-level key serialization or storage mechanisms.
