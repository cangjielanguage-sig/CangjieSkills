This directory acts as the central hub for the API overview of the `std.crypto.digest` package, providing developers with the necessary documentation to utilize common cryptographic hash algorithm interfaces effectively. The content encompasses a thorough feature introduction that explicitly lists supported algorithms such as MD5, SHA, HMAC, and SM3, giving a clear picture of the cryptographic capabilities available. Furthermore, it presents a well-organized API list that categorizes functions and interfaces to streamline the development process. Among the key components discussed are the generic `digest` function, which is designed to support a variety of input types including `Array<Byte>`, `String`, and `InputStream`, and the `Digest` interface, which sets the standard for algorithm implementation. This reference guide is highly suitable for developers focused on implementing data hashing who need to understand the nuances of generic types and input streams.
