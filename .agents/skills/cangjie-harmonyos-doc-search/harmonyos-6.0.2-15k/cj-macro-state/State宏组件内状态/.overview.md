# State宏组件内状态

This directory focuses on the @State decorator within the Cangjie programming language for ArkUI development. It provides comprehensive documentation on managing internal state within components, covering fundamental definitions, usage scenarios, and specific constraints. Key topics include state variable rules, data type support, initialization mechanisms, and how state changes trigger UI refreshes. Additionally, it addresses reactivity mechanisms, observation behaviors, and common troubleshooting issues. This resource is suitable for Cangjie developers and HarmonyOS architects aiming to build reactive user interfaces, optimize rendering performance, and master state management best practices.

## Detailed Description

### State宏组件内状态_4more.md State宏组件内状态_4more.md
This reference document defines the @State macro, which enables variables to trigger UI refreshes within a component. It covers the overview of state variables, macro usage rules regarding supported data types, and variable transfer or access rules. Key takeaways include that @State variables are private, serve as data sources, and sync with child @Prop or @Link variables. While supporting basic types, observing changes in classes or arrays requires @Observed, @Publish, or specific array wrappers. Intended for developers with a basic understanding of the state management framework.

### 使用场景.md 使用场景.md
This technical guide illustrates the usage scenarios of the @State decorator in Cangjie for ArkUI development. It covers two primary use cases: decorating simple type variables and class object type variables. The document explains how state changes trigger targeted UI component updates and ensures state isolation between component instances. It also details the initialization mechanism, distinguishing between default values and externally passed parameters. Key takeaways include understanding the re-rendering logic and data flow. This guide targets Cangjie developers using state management to build reactive user interfaces.

### 限制条件.md 限制条件.md
This document serves as a reference guide outlining the specific usage constraints and limitations for the @State decorator in the Cangjie programming language. It details two main restrictions: the requirement for variable initialization and the lack of support for Function types. Key information includes that @State variables must be initialized to prevent compilation errors, and using @State on Function types is prohibited. This document is intended for Cangjie developers implementing state management who need to understand compile-time rules and syntax requirements.

### 常见问题/
This directory provides a comprehensive collection of technical guides designed to assist Cangjie UI and HarmonyOS developers in mastering state management and resolving common architectural issues. It focuses on critical best practices, such as the prohibition of state variable modifications within the build method to prevent infinite rendering loops and application freezes. Furthermore, it covers the intricacies of lifecycle management to avoid memory leaks, specifically regarding callback registration and unregistration. The guides also delve into the correct usage of arrow functions for state updates and the scoping rules of decorators like @State, @Observed, and @Publish.

### 观察变化和行为表现/
This directory focuses on the reactivity mechanisms within the ArkUI framework and the Cangjie language. It covers how state changes are observed, how these changes trigger component updates, and the specific behaviors of different data types (primitives, structs, classes, arrays) under decorators like @State and @Observed. Key concepts include on-demand rendering, dependency tracking, and state management rules. This content is suitable for developers looking to optimize UI performance and ensure data synchronization in their applications.
