# 通过系统相机拍照和录像仓颉

This directory serves as a comprehensive resource for developers working with the Cangjie programming language on the HarmonyOS platform, specifically focusing on camera integration. It details how to utilize the system's native CameraPicker to capture photos and videos efficiently. The content highlights the advantage of bypassing complex permission applications by leveraging system-provided interfaces. Key technical concepts include `PickerProfile` configuration, URI handling for file storage, and UI state management. This collection is ideal for mobile application developers who need a practical, code-driven guide to embedding media capture capabilities into their Cangjie-based projects without delving into low-level camera hardware controls.

## Detailed Description

### 完整示例.md
This document provides a complete code example demonstrating how to implement a camera picker for photos and videos in a Cangjie-based HarmonyOS application. The content covers defining a custom callback class, creating a UI layout with image and video display components, and managing file paths and URIs. Key takeaways include the usage of the pick function, PickerProfile configuration, and state management to dynamically update the UI with selected media. Intended for developers familiar with Cangjie syntax and HarmonyOS UI development, this example serves as a practical reference for integrating camera capabilities into mobile apps.

### 通过系统相机拍照和录像仓颉_2more.md
This development guide instructs developers on using the CameraPicker capability in the Cangjie language to capture photos and videos without applying for camera permissions. The document details the implementation process, including importing required modules like CameraKit and UIKit, configuring the PickerProfile to specify storage locations via the saveUri parameter, and invoking the pick interface with a callback to retrieve results. Key takeaways include the system-provided UI and the option to save media to the media library or an app sandbox file. This tutorial is intended for application developers looking for a simplified way to integrate camera features.
