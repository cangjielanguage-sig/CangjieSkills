This directory serves as a comprehensive technical resource for developers engaged in advanced metaprogramming within the Cangjie language ecosystem. It focuses specifically on the manipulation of Abstract Syntax Trees (ASTs), providing the necessary tools and knowledge to programmatically analyze, parse, and modify source code structures. The core content revolves around handling `ClassDecl` node types, demonstrating how to perform type casting, inject new member functions into existing classes, and utilize code generation functions like `quote` and `parseDecl`. By accessing the `body.decls` collection, developers can dynamically alter code behavior at the syntax level. This directory is ideal for compiler developers, language tool creators, and experienced Cangjie programmers who need to automate code refactoring, implement custom compiler passes, or build sophisticated development tools that require deep integration with the language's syntax tree. Through these examples, users will gain the confidence to implement complex syntax transformations and extend the capabilities of the Cangjie compiler toolchain.
