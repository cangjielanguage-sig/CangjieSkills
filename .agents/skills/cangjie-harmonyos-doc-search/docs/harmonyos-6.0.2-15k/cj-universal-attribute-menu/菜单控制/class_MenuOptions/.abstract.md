This directory serves as a comprehensive technical resource for the `MenuOptions` class within the Cangjie ArkUI framework, specifically designed to facilitate the configuration and implementation of popup menus. It encompasses the class structure, inheritance from `ContextMenuOptions`, and detailed API references for essential properties such as `title` and `showInSubWindow`. The documentation covers critical aspects including constructor initialization, offset adjustments, placement logic, and animation settings. By providing insights into spatial placement, arrow configuration, and background effects, this directory equips developers with the necessary tools to customize menu display behavior and visual effects. It is primarily suitable for developers and UI engineers utilizing the ArkUI framework who require precise control over context menu implementation and interaction rules in their applications.
