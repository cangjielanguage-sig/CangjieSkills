This directory provides essential documentation for the `ohoshi_tracemeter` performance tracking module, specifically designed for the Cangjie language in HarmonyOS development. It offers a deep dive into the APIs required for tracking process traces, measuring execution performance, and debugging complex applications. The content covers the HiTraceMeter class, detailing methods for marking task boundaries, distinguishing between parallel and serial execution, and monitoring variable values. Furthermore, it includes practical guides on module integration and configuration within Cangjie template projects. This resource is indispensable for HarmonyOS developers and system engineers who utilize the PerformanceAnalysisKit to ensure optimal application performance and conduct thorough system analysis using the hiTraceMeter tool.
