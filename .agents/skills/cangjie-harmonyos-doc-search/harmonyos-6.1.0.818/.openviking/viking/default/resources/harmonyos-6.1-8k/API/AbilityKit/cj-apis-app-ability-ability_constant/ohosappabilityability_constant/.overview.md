# ohosappabilityability_constant

本目录包含HarmonyOS应用Ability相关的常量与枚举类型API参考文档，主要面向使用仓颉（Cangjie）语言进行应用开发的开发者。文档涵盖了Ability生命周期中的关键状态定义，包括启动原因、内存级别、迁移结果、窗口模式以及退出原因等。这些常量属于SystemCapability.Ability.AbilityRuntime.Core系统能力，旨在帮助开发者处理应用恢复、内存压力管理、跨端迁移及窗口显示逻辑。适合需要精细控制Ability行为和响应系统运行时变化的开发人员查阅。

## 详细描述

### enum_LaunchReason_ba86ff5d.md enum_LaunchReason_ba86ff5d.md
本文档是Cangjie语言的API参考文档，定义了LaunchReason枚举，用于标识Ability的启动原因。文档涵盖了枚举定义及其成员，包括StartAbility、Call、Continuation、AppRecovery和Unknown。该枚举配合UIAbility的onCreate方法使用，允许开发者根据启动参数（如跨端迁移、故障恢复或常规启动）执行特定逻辑，属于系统能力SystemCapability.Ability.AbilityRuntime.Core。面向使用Cangjie开发应用的开发者，特别是需要处理Ability生命周期和不同启动场景的人员。关键词：LaunchReason、UIAbility、启动原因、Cangjie、API文档。

### enum_MemoryLevel.md enum_MemoryLevel.md
本文档是Cangjie语言中MemoryLevel枚举的API参考文档，旨在定义整机可用内存的级别。主要内容包括枚举定义、三个具体内存状态（Critical极低、Low低、Moderate适中）的功能描述，以及继承自Equatable和ToString的相等性判断操作符（==、!=）和字符串转换方法。关键信息指出该类型属于SystemCapability.Ability.AbilityRuntime.Core系统能力，起始版本为22。文档面向需要根据系统内存状态进行应用逻辑调整的开发者，提供了判断内存压力和进行类型比较的标准接口。

### enum_OnContinueRe_2more_818648b4.md enum_OnContinueRe_2more_818648b4.md
本文档是Cangjie语言的API参考文档，主要定义了Ability迁移结果和窗口创建模式相关的枚举类型。文档详细介绍了OnContinueResult枚举，包含Agree、Reject和Mismatch等状态，用于标识Ability迁移的决策结果。同时涵盖了WindowMode枚举，定义了全屏、左侧分屏及右侧分屏等窗口模式，该枚举需配合startAbility方法使用，且分屏功能仅限平板和折叠屏设备生效。所有接口均属于SystemCapability.Ability.AbilityRuntime.Core系统能力，起始版本为22。本文档面向需要处理应用迁移逻辑或定制窗口显示模式的开发者。

### ohosappabilityabi_6more_6b6b47c0.md ohosappabilityabi_6more_6b6b47c0.md
本文档是HarmonyOS仓颉语言的API参考文档，旨在定义Ability相关的常量枚举。主要内容包括LaunchParam类及其属性，以及LastExitReason枚举（涵盖正常退出、崩溃、冻屏等状态）。文档还列出了相关系统权限和示例代码的使用说明，帮助开发者根据启动或退出原因执行相应逻辑。该文档面向使用仓颉开发HarmonyOS应用的开发者，提供了Ability生命周期状态管理的核心定义。
