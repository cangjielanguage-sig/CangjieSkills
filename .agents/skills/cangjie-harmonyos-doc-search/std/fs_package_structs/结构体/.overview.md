This directory contains API reference documentation for core data structures within the Cangjie programming language's file system package. ## Detailed Description

### struct_FileDescriptor.md struct_FileDescriptor.md

This document serves as API reference documentation for the Cangjie programming language's FileDescriptor struct, designed to retrieve file handle information. It covers the struct definition, a detailed explanation of file handles across different operating systems, and the specific property fileHandle which returns an IntNative value. Key takeaways include the definition of a file handle as an OS-allocated data structure containing metadata and physical location details. The document clarifies that while handle representations vary by OS, the fileHandle property abstracts this by returning an IntNative type for file operations like reading and writing. This reference guide targets Cangjie developers working on low-level file I/O operations who need to understand how to access and utilize system-level file handles within their applications.

### struct_FileInfo/

It covers comprehensive file system operations including metadata inspection, permission management, and file attribute queries. Key topics include file type checking, size retrieval, timestamp access, and read/write/execute permissions across different operating systems like Windows and Linux. The documentation highlights platform-specific behaviors and potential race conditions. It is suitable for Cangjie developers who need precise programmatic control over file system entities and require detailed understanding of file attributes and access rights.

### struct_Path/

This directory provides comprehensive API reference documentation for the `Path` struct in the Cangjie `fs` package. It details the struct's definition, properties, operators, and utility methods designed for handling local file system paths across Windows and Unix operating systems. Key functionalities include path normalization, joining, component extraction (like filename and extension), and equality comparison. The documentation covers specific behaviors such as OS-specific separators, length limits, and exception handling for illegal paths. It is intended for Cangjie developers seeking precise definitions for path manipulation, validation, and cross-platform file system operations.
