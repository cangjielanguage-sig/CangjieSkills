## 详细描述

### 加密导入.md 加密导入.md
本文档介绍了HUKS的加密导入机制，旨在通过端到端加密通道安全地将密钥导入HUKS，防止传输过程中的泄露。涵盖了开发时序流程、涉及的HUKS能力调用（如密钥协商、加密）、数据封装格式（X.509及Length-Data格式）以及加密导入密钥材料的详细字节结构定义。核心要点包括支持ECDH和X25519协商算法，使用AES-GCM加密，且导入密钥材料需严格遵循特定的Length-Data封装格式，包含公钥、加密参数及密文等字段。适用于高安敏感业务场景下的开发者，需具备一定的密码学基础和HUKS开发经验。

### 密钥导入介绍及算法规格_2more_7204e946.md 密钥导入介绍及算法规格_2more_7204e946.md
本文档介绍了如何将外部生成的密钥导入HUKS进行安全管理，并详细说明了密钥导入的方式及相关规格。主要涵盖密钥导入的基本概念、明文导入与加密导入两种方式，并重点阐述了明文导入的适用场景及限制。密钥导入HUKS后，明文仅在安全环境访问。明文导入方式在传输过程中存在暴露风险，适用于非对称密钥公钥或轻量级设备，但不建议用于对称密钥或密钥对。轻量级设备仅支持明文导入。本文面向需要在HUKS中管理外部生成密钥的开发者，属于参考类文档，目前处于Beta阶段。

### 支持的算法_2more_26891762.md 支持的算法_2more_26891762.md
本文档规范了OpenHarmony HUKS服务支持的密钥导入算法及格式。主要涵盖标准设备与轻量级设备的算法规格，以及不同密钥类型的导入格式。关键信息包括AES、RSA、ECC、SM2等算法的密钥长度、API级别（15+）及必选性，强调RSA公钥指数需大于等于65537。文档还说明了对称密钥与非对称密钥的DER格式等导入要求。作为参考文档，旨在指导开发者根据必选规格确保全平台兼容性，正确实现密钥管理。
