This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on dropdown menus. It covers a comprehensive range of customization options, including background styling, text appearance, layout alignment, and dimensions. Developers can find detailed parameters for setting colors, fonts, spacing, and menu behavior. Suitable for UI developers using the Cangjie language, these documents provide the necessary technical specifications to create polished and functional user interfaces, ensuring components meet specific design and interaction requirements.
