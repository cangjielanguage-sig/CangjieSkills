This directory provides comprehensive tutorials on implementing custom pop-up dialogs within the ArkUI framework using the Cangjie language. It specifically addresses a feature currently marked as Beta and not recommended for production use. The content covers the fundamental implementation using the `@CustomDialog` decorator and `CustomDialogController`, as well as advanced styling and nested dialog management. Key concepts include distinguishing between modal and non-modal behaviors, understanding dialog persistence across page routes, and managing component lifecycles. This resource is designed for HarmonyOS developers seeking to implement complex user interactions, such as warnings or updates, while adhering to specific architectural constraints.
