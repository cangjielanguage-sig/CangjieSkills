# cj-power-shell

This directory serves as a comprehensive repository for the `cj-power-shell` tool documentation, a specialized utility designed to assist developers and system engineers in the intricate task of managing and debugging device power states. The content within this directory is focused on providing a robust reference for controlling various aspects of device hardware behavior, specifically screen activation and power management modes. It covers essential environment prerequisites required to run the tool effectively and provides a detailed command list that serves as a quick reference for users. The documentation elaborates on specific functions such as setting distinct power modes (including normal and performance profiles), waking up the device, suspending operations, and configuring screen timeout durations. It also provides critical information on command codes and parameters necessary for overriding system sleep settings. This guide is best suited for developers who require basic power debugging capabilities and assumes that the user already has access to the `hdc shell` environment. Keywords: power management, device debugging, screen activation, power modes, sleep settings, developer reference, command-line tools.
