# cj-support-for-aging-adaptation

This directory serves as a comprehensive technical resource dedicated to "Age-Friendly Adaptation" (适老化) within the Cangjie framework and HarmonyOS ecosystem. It addresses the essential requirements for making applications accessible and comfortable for elderly users, who often struggle with standard UI elements due to visual impairments or reduced motor skills. The content covers the implementation of system font scaling, the maintenance of layout stability during magnification, and the integration of system component features like "Care Mode." Developers will find in-depth information on JSON-based configuration methods, a wide range of scaling levels from 1x to 3.2x, and specific component behaviors such as long-press versus automatic scaling. This guide is suitable for developers and designers committed to creating inclusive digital products that cater to the senior demographic, ensuring that technology remains accessible to all age groups.

## Detailed Description

### 支持适老化/
This directory focuses on "Age-Friendly Adaptation" (适老化) for application development, specifically within the Cangjie framework and HarmonyOS ecosystem. It provides a structured approach to adapting applications for elderly users by addressing key accessibility challenges. The content covers how to support system font scaling to ensure text is legible, ensuring layout stability so that the user interface remains functional and aesthetically pleasing when elements are enlarged, and utilizing system component magnification features like "Care Mode" to improve usability. Key topics include detailed configuration methods using JSON, which allow for precise control over the interface, specific scaling levels ranging from 1x to 3.2x to accommodate varying degrees of visual assistance, and component-specific behaviors that distinguish between long-press interactions and automatic scaling. This resource is suitable for developers aiming to enhance accessibility and user experience for elderly demographics, providing the technical know-how to build more inclusive applications. By following these guidelines, developers can ensure their applications are not only compliant with accessibility standards but also genuinely user-friendly for older adults.
