# API_列表

This directory serves as a comprehensive API reference for a process management package, designed to assist developers in integrating system-level process control into their applications. It covers essential functionalities for creating, controlling, and interacting with system processes, including process execution, stream redirection, and lifecycle management. The documentation details key components such as the `Process` class hierarchy, execution functions, and exception handling. Additionally, it addresses cross-platform compatibility for Linux, Windows, and macOS, highlighting platform-specific restrictions. This resource is suitable for software developers and system integrators seeking to implement robust process management while maintaining code portability.

## Detailed Description

### 函数_4more.md 函数_4more.md
This document serves as an API reference index for a process management package, detailing functions and classes for creating, controlling, and interacting with system processes. The content is organized into four sections: Functions for process execution and lookup, Classes representing process instances, Enums for stream redirection, and Exception handling. Key components include the execute and launch functions for running child processes, the Process class hierarchy for instance management, and ProcessRedirect for standard stream configuration. This reference guide targets software developers seeking to integrate system-level process management and control into their applications.

### 兼容性说明/
This directory provides detailed API references and compatibility notes for process management classes within the system. It specifically addresses the transition from the deprecated `CurrentProcess` class to the modern `SubProcess` and `Process` classes. The documentation covers a wide range of functionalities, including environment variable manipulation, standard stream handling, and process lifecycle management (creation, execution, termination). A significant focus is placed on cross-platform compatibility, explicitly detailing support for Linux, Windows, and macOS, and noting platform-specific restrictions. This resource is essential for developers who need to integrate system-level process control into their applications while maintaining code portability and adhering to the latest API standards.
