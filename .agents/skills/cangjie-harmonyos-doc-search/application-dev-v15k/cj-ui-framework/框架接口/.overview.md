# 框架接口

This directory contains API reference documentation for the Cangjie language within the ArkUI framework, focusing on system-level interfaces and internal components. It covers Foreign Function Interface (FFI) containers for data types, base classes for UI rendering and state management, resource handling, and native interoperability structures. Key topics include component lifecycles, observer patterns, and vector data management. This documentation is primarily intended for framework developers, system engineers, and advanced users building or extending the ArkUI system, requiring deep knowledge of Cangjie syntax and UI architecture.
