This directory provides comprehensive API reference documentation for the Cangjie class `AlertDialogParamWithOptions` within the ArkUI framework. It focuses on extending standard alert dialog capabilities to support interfaces containing multiple buttons and complex configurations. Key topics include class initialization, button array management, layout orientation control (specifically vertical stacking for three or more buttons), and detailed visual styling properties. Additionally, it covers constructor signatures and popup window behaviors. This resource is essential for ArkUI developers and UI engineers seeking to implement interactive, multi-button modal dialogs with specific visual and behavioral requirements in their applications.
