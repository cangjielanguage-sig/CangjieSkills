# cmd-tools

The `cmd-tools` directory serves as a centralized repository for documentation regarding the Cangjie programming language's command-line utility suite. It encompasses a wide array of essential developer tools, including project management (CJPM), debugging (CJDB), static analysis (CJLint), code formatting (CJFMT), performance profiling (CJProf), and code coverage (CJCov). Additionally, it includes specialized manuals for intermediate representation deserialization (`chir-dis`) and stack trace recovery for obfuscated applications (`cjtrace-recover`). This comprehensive collection is designed for software developers, QA engineers, and DevOps professionals seeking to optimize their Cangjie development workflow, ensure code quality, and efficiently debug applications.

## Detailed Description

### chir_dis_manual
This directory contains the user manual for the CHIR deserialization tool `chir-dis` in the Cangjie programming language. This document details how to convert the CHIR serialized file output by the compiler into a readable text format, covering the tool's functional introduction, command-line parameter descriptions, and specific operation examples. Core content includes parsing input/output file formats, using command options (such as `-v` and `-h`), and how to execute `chir-dis` via the command line to process `.chir` files to generate `.chirtxt` text files. This document is mainly aimed at developers who need to deeply analyze the Cangjie compiler intermediate representation (CHIR), aiming to help users efficiently view and understand the compilation process.

### cjcov_manual
This directory serves as the definitive guide for the `cjcov` tool, a specialized code coverage statistics utility developed for the Cangjie programming language. It is an essential resource for software developers, QA engineers, and project managers who need to measure the effectiveness of their test suites and ensure code quality through detailed coverage reports.

### cjdb_manual
This directory serves as the comprehensive manual for `cjdb`, the dedicated command-line debugging tool for the Cangjie programming language. It provides essential resources and documentation for developers aiming to debug executables efficiently across various scenarios, offering insights into the tool's capabilities and usage patterns.

### cjfmt_manual
This directory serves as the central documentation hub for the CJFMT (Cangjie Format) tool, a specialized utility designed to automate code styling for the Cangjie programming language. It provides a comprehensive guide covering the tool's core functions, configuration options, and how to integrate it into a development workflow to maintain consistent code style.

### cjlint_manual
This directory serves as the comprehensive documentation repository for CJLint, the dedicated static analysis tool designed for the Cangjie programming language. It provides essential resources for developers to identify code vulnerabilities, enforce coding standards, and maintain high code hygiene through automated static checks.

### cjpm_manual
This directory serves as the comprehensive manual for the Cangjie Programming Language's official project management tool, CJPM. It covers the entire software development lifecycle, including project initialization, building, testing, and installation of packages, making it a fundamental guide for all Cangjie developers.
