This directory contains comprehensive API reference documentation for initializing and configuring ActionSheet and Dialog components within the ArkUI framework using the Cangjie language. It specifically addresses the `ActionSheetOptions` constructor, providing detailed insights into parameters for text resources, layout dimensions, visual styles, and event handling. The documentation outlines essential system capabilities, version requirements, and specific constraints for styling elements such as borders, shadows, and background blur effects. This resource is primarily suitable for software developers and UI engineers seeking to programmatically create, customize, and manage pop-up windows, modals, and action sheets in their applications.
