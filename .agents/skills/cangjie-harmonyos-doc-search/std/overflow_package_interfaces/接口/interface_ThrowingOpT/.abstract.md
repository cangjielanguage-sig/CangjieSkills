This directory provides comprehensive API documentation for the `ThrowingOp` interface in the Cangjie programming language. It focuses on arithmetic and bitwise operations that utilize exception-throwing strategies to handle errors like overflow and invalid shifts. The content covers the core interface definition and its implementations across various integer types, including `Int8`, `Int64`, `UInt32`, and `UIntNative`. By throwing specific exceptions such as `OverflowException` and `OvershiftException`, these tools ensure data integrity and prevent silent data corruption. This resource is essential for Cangjie developers building high-reliability systems requiring strict error handling and explicit validation in numerical computations.
