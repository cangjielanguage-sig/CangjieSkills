This directory provides comprehensive documentation for the `BackgroundEffectOptions` class, a fundamental component for configuring background visual effects within the ArkUI framework using the Cangjie programming language. It covers the complete API reference, detailing how to manipulate visual parameters such as blur radius, brightness, saturation, and adaptive color modes. The documentation explains specific technical behaviors, including valid value ranges for visual adjustments and the handling of inactive colors during window focus loss. It is specifically designed for software developers and UI engineers who need to programmatically define, customize, and implement sophisticated background blurring and styling effects in their applications to enhance user interface aesthetics and user experience.
