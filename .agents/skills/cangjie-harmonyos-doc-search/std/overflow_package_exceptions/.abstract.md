This directory serves as the central repository for API reference documentation concerning exception handling within the Cangjie overflow package. It is specifically designed to assist developers in understanding and implementing robust error management for bitwise shift operations. The content provides an in-depth look at the `OvershiftException` and `UndershiftException` classes, detailing their inheritance from the standard Exception class and their specific application scenarios—such as handling shifts that exceed bit width or are negative. Additionally, the documentation covers the initialization of these exceptions, offering guidance on both default usage and custom error messaging. This directory is highly suitable for Cangjie developers, systems programmers, and quality assurance engineers who are focused on building reliable, error-resilient software applications that require precise control over low-level data manipulations and bitwise calculations.
