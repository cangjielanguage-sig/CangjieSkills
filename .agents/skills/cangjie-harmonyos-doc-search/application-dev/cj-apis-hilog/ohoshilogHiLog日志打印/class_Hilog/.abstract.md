This directory contains API reference documentation for the Hilog class and its associated static functions within the Cangjie programming language. It focuses on the Performance Analysis Kit, providing developers with the tools to implement structured logging for applications and services. The documentation covers various log severity levels, including debug, error, fatal, info, and warn, along with specific constraints like domain identifiers (0x0-0xFFFF), tag length limits (31 bytes), and privacy formatting options using {public} or {private} tags. It is suitable for Cangjie developers and application engineers looking to integrate secure and efficient logging mechanisms into their software projects.
