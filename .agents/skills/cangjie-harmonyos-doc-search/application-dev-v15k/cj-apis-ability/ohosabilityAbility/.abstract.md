This directory provides comprehensive API reference documentation for the HarmonyOS Ability framework using the Cangjie programming language. It covers core components such as Ability lifecycle management, Context operations, Want/WantAgent mechanisms, and various ExtensionAbilities. Developers can find detailed specifications for classes, enums, and functions essential for building robust applications, handling inter-process communication, and managing system resources. This documentation is suitable for HarmonyOS application developers and system engineers seeking to implement UI logic, background services, and cross-device interactions within the Cangjie environment.
