# 使用运动和方向传感器监测设备状态

This directory provides comprehensive resources for monitoring device status using motion and orientation sensors within Web components. It covers the technical implementation of accessing sensor data—such as acceleration and angular velocity—via W3C standard interfaces. The content includes detailed explanations of supported sensors (Accelerometer, Gyroscope, Orientation), JavaScript interfaces, and the mandatory permission configurations required for system access. It addresses both the frontend web integration and backend native setup, ensuring a complete understanding of the data flow from hardware to application. This material is suitable for developers creating interactive applications like fitness trackers or motion-controlled games on HarmonyOS/OpenHarmony platforms who need to bridge native hardware capabilities with web technologies.

## Detailed Description

### 概述_2more.md 概述_2more.md
This document serves as a technical overview for accessing motion and orientation sensor data through W3C standard interfaces in Web components. It details supported sensors including Accelerometer, Gyroscope, and Orientation sensors, explaining their data outputs like acceleration and angular velocity. Key sections cover the specific JavaScript interfaces available and the mandatory permission configuration process. Developers must declare sensor permissions in the module.json5 file and implement the onPermissionRequest interface. This guide is intended for developers building interactive web applications, such as fitness tools or motion-controlled games, requiring hardware sensor integration.

### 开发步骤/
This directory provides a comprehensive development guide focused on integrating sensor capabilities into Cangjie applications that utilize Web components. It details the end-to-end process required to enable hardware sensors, such as accelerometers and gyroscopes, within a hybrid application environment. The content covers critical backend configurations, including permission handling using `AbilityAccessCtrl` and `UIAbilityContext`, as well as frontend implementation using standard W3C Generic Sensor APIs and legacy event listeners. By bridging native HarmonyOS/OpenHarmony system services with web technologies, this guide ensures developers can effectively access and manage device motion data. It is specifically designed for application and web developers looking to enhance their mobile or hybrid applications with advanced hardware interaction features.
