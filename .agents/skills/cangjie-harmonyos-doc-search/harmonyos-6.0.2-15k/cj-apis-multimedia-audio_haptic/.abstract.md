This directory serves as the central repository for API reference documentation regarding the HarmonyOS `ohos.multimedia.audio_haptic` module, with a specific focus on the Cangjie language implementation. It is dedicated to the concept of audio-haptic synergy, which is the technological process of binding audio tracks with haptic (vibration) feedback to produce a cohesive, multi-sensory user experience. The documentation outlines the necessary tools for developers to manage these complex interactions, including the `AudioHapticManager` for resource handling and the `AudioHapticPlayer` for execution. It also provides critical information on configuration settings, callback implementations, and latency management to ensure high-performance synchronization. This resource is primarily suitable for developers and systems engineers targeting HarmonyOS API version 19 and above who are involved in creating immersive applications—such as high-end mobile games, virtual reality environments, or accessibility tools—where precise control over sensory feedback is a key requirement for user engagement and experience quality.
