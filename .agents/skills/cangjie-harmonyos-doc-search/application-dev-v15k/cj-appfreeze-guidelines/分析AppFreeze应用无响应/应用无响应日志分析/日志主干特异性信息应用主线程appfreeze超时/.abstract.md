This directory provides a comprehensive technical guide for analyzing application main thread freeze (Appfreeze) logs, specifically within the HarmonyOS operating system environment. It focuses on interpreting specific log events such as THREAD_BLOCK_6S, understanding event queue statuses, and decoding stack traces to identify the root causes of application non-responsiveness. The documentation covers critical aspects like distinguishing between blocking tasks and general overload, analyzing Event Runner dumps, and correlating findings with system-wide metrics like CPU and memory usage. This resource is essential for system developers and software engineers tasked with debugging complex performance issues and ensuring application stability.
