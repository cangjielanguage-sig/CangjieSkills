This directory provides comprehensive API documentation for the Cangjie programming language, focusing on saturating arithmetic operations for unsigned integer types, with a primary emphasis on UInt8. It details the implementation of the `SaturatingOp` interface and specific utility functions designed to handle arithmetic edge cases safely. The documentation covers a wide range of operations, including addition, subtraction, multiplication, division, and bit shifting, explaining how they prevent wrapping errors by clamping results to type boundaries. This resource is essential for Cangjie developers who require robust, bounded arithmetic logic to ensure application stability and prevent undefined behavior during calculations.
