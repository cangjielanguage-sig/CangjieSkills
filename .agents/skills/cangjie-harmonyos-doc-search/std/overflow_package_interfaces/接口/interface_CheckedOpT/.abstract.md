This directory contains comprehensive documentation for the Cangjie programming language's `CheckedOp` interface, which defines safe arithmetic and bitwise operations designed to prevent integer overflow errors. It covers the generic interface definition alongside specific implementations for various integer types, including signed and unsigned variants (Int8, Int16, Int32, Int64, IntNative, and their unsigned counterparts). The core mechanism involves returning an `Option` type (`?T`) to gracefully handle errors by returning `None` instead of wrapping values or throwing exceptions. This resource is essential for Cangjie developers who require robust error handling and explicit management of numerical boundaries to ensure application stability and data integrity.
