# 组件属性

This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on secure controls. It covers a wide range of styling and layout attributes, including border aesthetics, text typography, dimension constraints, and icon positioning. Developers can find detailed function signatures, parameter types, and default values to customize the visual appearance and layout behavior of security components. This documentation is suitable for UI developers and system engineers using the Cangjie language who need to implement precise design specifications and ensure display integrity in secure user interfaces starting from ArkUI version 20.

### func_heightLength_3more.md
This API reference document details dimension configuration functions for secure controls within the Cangjie ArkUI framework. It covers three primary functions: height, size, and constraintSize, each utilizing the Length type for parameters. Key information includes that these functions default to content-adaptive sizing but enforce minimum dimensions to ensure display integrity. Notably, constraintSize holds higher priority than standard width and height settings, and text wrapping occurs automatically if width constraints are too restrictive. This documentation targets ArkUI developers using Cangjie who need precise control over component layout and sizing constraints.
