This directory serves as a specialized knowledge base for the `cj-cangjiecrash-guidelines`, dedicated to the comprehensive analysis and debugging of process crashes within Cangjie applications. It provides an in-depth examination of crash log specifications, enabling developers to effectively differentiate between system-level errors and logic-based exceptions. The content encompasses practical methodologies for log retrieval using tools like DevEco Studio or hiAppEvent, as well as proven strategies for root cause analysis through stacktraces. Additionally, it features a wide array of case studies addressing runtime issues such as `OutOfMemoryError` and `StackOverflowError`. This resource is specifically designed for Cangjie developers and stability engineers seeking to improve application reliability, master debugging tools, and implement robust error handling mechanisms. By leveraging these guidelines, users can systematically diagnose uncaught exceptions, interpret complex log data, and efficiently resolve stability challenges.
