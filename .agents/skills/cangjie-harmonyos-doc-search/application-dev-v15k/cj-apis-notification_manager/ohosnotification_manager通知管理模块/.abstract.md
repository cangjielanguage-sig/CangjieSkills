This directory contains API reference documentation for the HarmonyOS notification management module using the Cangjie programming language. It covers the construction, configuration, and lifecycle management of system notifications, including content types (text, picture, live view), notification channels (slots), and interactive elements like buttons and progress bars. Developers can find definitions for classes, enumerations, and functions required to implement rich notification features. This resource is suitable for HarmonyOS application developers seeking to integrate robust notification capabilities, manage user permissions, and handle distributed notification settings within their Cangjie-based projects.
