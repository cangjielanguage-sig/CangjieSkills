This directory provides a comprehensive technical guide for diagnosing and troubleshooting application unresponsiveness (appfreeze) issues within the OpenHarmony/HarmonyOS ecosystem. It covers the end-to-end workflow, from initial log collection using DevEco Studio or shell commands to advanced analysis of Binder IPC, EventHandler queues, and stack traces. Key topics include HiviewDFX fault detection logic, Hilog integration, and Trace analysis. These resources are designed for software developers, system engineers, and performance maintainers seeking to identify root causes of system freezes, thread blocking, and lifecycle timeouts.
