# exception_overview

本目录详细介绍了仓颉编程语言的异常处理机制，涵盖了异常的基本概念、分类及核心用法。重点阐述了系统内部错误与逻辑/IO异常的区别，包括它们的继承规则、构造函数、属性（如message）以及关键成员函数（如toString和printStackTrace）。此外，还说明了自定义异常的规范。该文档适合需要掌握错误处理机制或进行异常类开发的仓颉语言程序员阅读，旨在帮助开发者构建更健壮的应用程序。

## Detailed Description

### exception_overview.md exception_overview.md

本文档介绍了仓颉编程语言中的异常处理机制，定义了异常的概念及其分类。主要内容包括异常的基本概念、Error与Exception的区别、自定义异常的规则，以及这两类异常的构造函数、属性和成员函数说明。核心要点在于区分Error（系统内部错误，不可继承）和Exception（逻辑或IO错误，可继承），并详细列出了message属性、toString及printStackTrace等关键接口的使用方式。该文档属于语言参考指南，面向需要掌握错误处理机制或进行异常类开发的仓颉语言程序员。
