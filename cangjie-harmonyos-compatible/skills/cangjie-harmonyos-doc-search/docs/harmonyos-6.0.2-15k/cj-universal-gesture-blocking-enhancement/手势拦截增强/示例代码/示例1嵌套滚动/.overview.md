This directory contains code examples and tutorials demonstrating how to implement nested scrolling functionality, specifically focusing on resolving gesture conflicts between parent and child components. The examples illustrate how to ensure smooth interaction transitions when inner components reach their boundaries. This resource is suitable for developers working on the HarmonyOS platform who need to handle complex UI interactions and hierarchical scrollable structures.
