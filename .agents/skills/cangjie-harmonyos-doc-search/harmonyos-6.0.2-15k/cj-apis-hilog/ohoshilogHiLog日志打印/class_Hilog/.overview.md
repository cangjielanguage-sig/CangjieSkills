# class_Hilog

This directory serves as a central hub for API reference documentation regarding the Hilog class in the Cangjie language, specifically engineered to facilitate robust logging capabilities for applications and services. It thoroughly covers the SystemCapability.HiviewDFX.HiLog framework, providing detailed insights into static methods used for outputting logs at distinct severity levels, including debug, info, warn, error, and fatal. The documentation meticulously outlines required parameters such as domain identifiers, classification tags, and format strings, while also addressing logging control functions to verify log printability. This resource is primarily suitable for Cangjie developers and application engineers who aim to implement structured logging, manage log output efficiently, and ensure system stability through precise error tracking in their software projects starting from version 19.

## Detailed Description

### class_Hilog_5more.md
This document provides API reference documentation for the Hilog class in the Cangjie language, designed to facilitate logging for applications and services. It details static methods for outputting logs at specific severity levels: debug, info, error, and fatal. Key information includes the required parameters for each method: a domain identifier (0x0-0xFFFF), a tag for classification, and a format string. Intended for Cangjie developers, this guide helps implement structured logging within the SystemCapability.HiviewDFX.HiLog framework starting from version 19.
