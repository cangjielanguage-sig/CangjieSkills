This directory serves as a comprehensive technical guide for loading local pages within HarmonyOS applications, addressing specific development needs for both Cangjie and ArkTS developers. It thoroughly covers the intricacies of rendering local HTML content inside a Web component, including resource loading from `rawfile` directories and managing application sandbox paths. Furthermore, it details the application lifecycle management in ArkTS, specifically focusing on the `onWindowStageCreate` method to programmatically set the initial UI. Key concepts include `WebviewController`, `GlobalContext`, file access permissions, and `WindowStage` functionality. These documents are ideal for developers seeking to implement offline web rendering or control app initialization sequences effectively.
