# 基础类型定义

This directory contains the fundamental type definitions necessary for handling touch interactions in the Cangjie language within the ArkUI ecosystem. It covers the core classes and enumerations that allow developers to customize how touch events are dispatched and processed, as well as how geometric data for touch points is structured. Key topics include touch result strategies, event propagation control, and coordinate system mappings for touch points. These definitions are vital for developers aiming to build sophisticated UI interaction logic, providing the granular control needed to manage event flow and accurately interpret touch locations relative to windows, parent components, and specific UI elements. This documentation is best suited for Cangjie and ArkUI developers involved in low-level UI event handling and geometry calculations.

## Detailed Description

### class_TouchResult_2more.md class_TouchResult_2more.md
This API reference documentation defines the TouchResult class and TouchTestStrategy enum for the Cangjie language, enabling developers to customize touch event dispatching in ArkUI applications. The document details the TouchResult class constructors, which accept a strategy and optional component ID, and the TouchTestStrategy enum values including DEFAULT, FORWARD, and FORWARD_COMPETITION. Key information includes that the id parameter is mandatory when using FORWARD or FORWARD_COMPETITION strategies to target specific child nodes, otherwise default system behavior applies. This guide targets Cangjie developers working on UI interaction logic who require granular control over event propagation.

### class_TouchTestInfo.md class_TouchTestInfo.md
This API reference document defines the Cangjie class TouchTestInfo, which encapsulates coordinate, dimension, and identification data for touch points within ArkUI components. The documentation details the class structure, read-only properties for various coordinate systems (window, parent, component), component dimensions, and the initialization constructor. Key properties include windowX, parentX, x, rect, and id, all defined as Float32 or specific types like RectResult. The class requires all these values for object construction. This is intended for ArkUI developers needing to handle touch event geometry and component identification in Cangjie.
