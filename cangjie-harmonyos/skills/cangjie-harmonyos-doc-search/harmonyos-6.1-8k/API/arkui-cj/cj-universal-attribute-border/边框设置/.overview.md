# 边框设置

本目录包含ArkUI框架中关于组件边框设置的API参考文档，主要面向使用仓颉语言进行UI开发的开发者。文档涵盖了边框宽度、颜色、圆角半径及样式的配置方法，详细介绍了`border`、`borderWidth`、`borderColor`等核心函数的用法与参数规范。通过这些接口，开发者可以灵活定义组件的视觉边界，适用于需要精细控制UI组件样式的应用开发场景。

### func_borderWidthE_2more_8e626fe4.md func_borderWidthE_2more_8e626fe4.md
该文档是ArkUI框架中`borderWidth`函数的API参考文档，主要介绍如何设置组件的边框宽度。文档详细列出了两个重载函数：一个接受`EdgeWidths`类型以定义不同边缘的宽度，另一个接受`Length`类型以设置统一宽度。关键内容包括参数说明、返回值（返回组件实例本身以支持链式调用）、系统能力以及起始版本22。该文档面向使用仓颉语言进行UI开发的开发者，旨在提供组件样式配置的接口规范。
