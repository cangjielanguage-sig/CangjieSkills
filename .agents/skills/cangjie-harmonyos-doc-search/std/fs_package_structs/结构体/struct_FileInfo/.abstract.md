This directory contains API reference documentation for the `FileInfo` struct in the Cangjie programming language's file system package. It covers file metadata retrieval, attribute inspection, and permission management. Key topics include file size, timestamps, access rights (read/write/execute), and platform-specific behaviors on Windows and Linux/macOS. The documentation highlights critical considerations such as the lack of data caching in `FileInfo` and potential race conditions during file operations. This resource is suitable for Cangjie developers who need to programmatically inspect and manage file system attributes and permissions securely and efficiently.
