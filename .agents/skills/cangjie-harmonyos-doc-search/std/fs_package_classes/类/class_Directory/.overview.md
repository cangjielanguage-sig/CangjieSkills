# class_Directory

This directory contains comprehensive API reference documentation for the `Directory` class within the Cangjie programming language's file system package. It covers essential operations for managing directories, including creating standard and temporary directories, checking if a directory is empty, reading directory contents, and performing non-recursive traversal. The documentation details static methods, function overloading for `Path` and `String` inputs, and exception handling for file system errors. It is suitable for software developers integrating file system management, directory creation, and content inspection into their Cangjie applications, providing the necessary syntax and parameter details for effective implementation.

## Detailed Description

### class_Directory_5more.md
This document provides API reference documentation for the Directory class in the Cangjie programming language, designed for file system directory management. It covers the class's general capabilities and defines criteria for illegal paths, such as invalid characters or permission issues. The primary focus is on static methods for directory creation, specifically create and createTemp, which support both Path and String inputs. Key information includes the recursive parameter for nested directory creation, return types, and specific exceptions like FSException and IllegalArgumentException. Intended for developers, this guide facilitates the implementation of directory creation and temporary file handling within applications.

### static_func_isEmptyPath_4more.md
This document serves as API reference documentation for static file system utility functions in the Cangjie language. It details two primary operations: isEmpty, which determines if a directory is empty, and readFrom, which retrieves a list of child items within a directory. Both functions are overloaded to accept either a Path object or a String as input. Key information includes function signatures, parameter descriptions, return types (Bool and Array<FileInfo>), and specific exceptions such as FSException for file system errors and IllegalArgumentException for invalid inputs. The target audience is software developers integrating file system checks and directory traversal into their applications, requiring knowledge of Cangjie syntax and exception handling.

### static_func_walkPath_FileI_2more.md
This API documentation details the overloaded `walk` static functions used for non-recursive directory traversal in the Cangjie file system package. The content covers two function signatures accepting either a `Path` or `String` input, parameter definitions for the callback function, and potential exceptions. Key takeaways include that traversal stops if the callback returns `false`, the order is system-dependent, and errors are thrown for invalid paths or non-directory inputs. This reference guide targets Cangjie developers who need to inspect directory contents programmatically.
