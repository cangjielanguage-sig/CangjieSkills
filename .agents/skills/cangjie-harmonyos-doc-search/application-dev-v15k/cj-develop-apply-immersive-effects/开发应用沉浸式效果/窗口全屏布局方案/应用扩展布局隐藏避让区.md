### 应用扩展布局，隐藏避让区

此场景下导航条会自动隐藏，适用于游戏、电影等应用场景。可以通过从底部上滑唤出导航条。

![immerse-4](figures/immerse-4.png)

1. 调用[setWindowLayoutFullScreen()](../../API_Reference/source_zh_cn/arkui-cj/cj-apis-window.md#func-setwindowlayoutfullscreenbool)接口设置窗口全屏。

    ```cangjie
    // main_ability.cj
    class MainAbility <: UIAbility {
        // ...
        public override func onWindowStageCreate(windowStage: WindowStage): Unit {
            let windowClass: Window = windowStage.getMainWindow() // 获取应用主窗口
            let isLayoutFullScreen = true
            windowClass.setWindowLayoutFullScreen(isLayoutFullScreen)
            windowStage.loadContent("EntryView")
        }
    }
    ```

2. 调用[setSpecificSystemBarEnabled()](../../API_Reference/source_zh_cn/arkui-cj/cj-apis-window.md#func-setspecificsystembarenabledspecificsystembar-bool-bool)接口设置状态栏和导航条的具体显示/隐藏状态，此场景下将其设置为隐藏。

    ```cangjie
    // main_ability.cj
    // 设置状态栏隐藏
    windowClass.setSpecificSystemBarEnabled(SpecificSystemBar.status,false, true)
    // 设置导航条隐藏
    windowClass.setSpecificSystemBarEnabled(SpecificSystemBarnavigationIndicator, false, true)
    ```

                }.backgroundColor(Color.WHITE).padding(20).borderRadius(15).width(80.percent)

                Row() {
                    Text('Display Content 4').fontSize(30)
                }.backgroundColor(Color.WHITE).padding(20).borderRadius(15).width(80.percent)

                justifyContent(FlexAlign.SpaceBetween)
        }
    }
