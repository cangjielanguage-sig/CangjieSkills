# cj-common-components-text-input

本目录提供了基于ArkUI仓颉语言的TextInput和TextArea组件开发指南。文档内容全面覆盖了单行及多行文本输入框的创建流程、自定义样式配置（包括占位符、背景色等属性）以及文本选中菜单的实现细节。特别值得注意的是，文档深入解析了键盘避让机制，明确指出在横竖屏切换场景下，需在组件外层嵌套Scroll等滚动容器以确保功能正常。该指南主要面向使用仓颉语言进行应用开发的工程师，适用于构建评论系统、即时通讯聊天界面及各类数据录入表单等高频交互场景，旨在帮助开发者快速掌握组件核心能力并解决常见的布局遮挡问题。

## Detailed Description

### cj-common-components-text-input.md
本文档旨在指导开发者使用ArkUI仓颉语言的TextInput和TextArea组件。文档涵盖了创建单行及多行输入框、自定义样式（如占位符、背景色）以及文本选中菜单功能。重点介绍了键盘避让机制，指出需在组件外嵌套Scroll等滚动容器以在横竖屏切换时生效。这是一份面向开发者的组件使用指南，适用于构建评论、聊天及表单等交互场景。
