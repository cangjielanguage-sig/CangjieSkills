# 仓颉_GWP-Asan_内存安全检测

本目录汇集了仓颉编程语言中 GWP-Asan 内存安全检测功能的相关文档。内容主要涵盖该检测工具的配置指南以及具体的异常检测类型说明。通过环境变量配置，开发者可以在 Linux 和 HarmonyOS 平台上利用采样机制和 Canary 数据对比，检测仓颉与 C 语言互操作过程中的堆内存安全问题。文档详细介绍了工具的开启方式、采样频率设置、支持的检测范围（如堆内存写越界）及其局限性。这些资料适合需要进行底层调试、关注内存安全或使用 unsafe 操作的仓颉开发者参考。

## 详细描述

### 仓颉_GWP-Asan_内存安全检_5more_484425a5.md 仓颉_GWP-Asan_内存安全检_5more_484425a5.md
本文档是仓颉 GWP-Asan 内存安全检测功能的配置指南，旨在帮助开发者在仓颉与 C 语言互操作过程中检测堆内存安全问题。文档介绍了通过环境变量 cjEnableGwpAsan 开启功能、cjGwpAsanSampleRate 设置采样频率以及 cjGwpAsanHelp 输出帮助信息的方法，并说明了工具的约束限制。该工具基于采样机制，通过对比 Canary 数据检测部分写越界访问，支持 Linux 和 HarmonyOS，但无法检测读越界及所有写越界问题。适用于需要在 Linux 或 HarmonyOS 平台上调试仓颉程序内存安全问题的开发者。

### 异常检测类型.md 异常检测类型.md
这份文档介绍了仓颉编程语言中的异常检测类型，旨在帮助开发者识别内存安全问题。文档涵盖堆内存写越界（细分为向前越界和向后越界）及仓颉GC异常（未释放数组引用）。关键信息包括Head canary和Tail canary检测机制、错误报告格式，以及使用acquireArrayRawData时必须配套releaseArrayRawData的规范。该文档属于技术参考文档，面向使用unsafe操作和原生指针的仓颉开发者，需具备基础内存管理知识。
