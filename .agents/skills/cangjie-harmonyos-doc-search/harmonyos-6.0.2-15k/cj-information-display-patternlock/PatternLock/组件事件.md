## 组件事件

### func onDotConnect((Int64) -> Unit)

```cangjie
public func onDotConnect(callback: (Int64) -> Unit): This
```

**功能：** 密码输入选中宫格圆点时，触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|(Int64)->Unit|是|-|密码输入选中宫格圆点时触发该回调。 回调参数：选中宫格圆点顺序的数字，数字为选中宫格圆点的索引值（第一行圆点从左往右依次为0、1、2，第二行圆点依次为3、4、5，第三行圆点依次为6、7、8）。|

### func onPatternComplete((Array\<Int32>) -> Unit)

```cangjie
public func onPatternComplete(callback: (Array<Int32>) -> Unit): This
```

**功能：** 密码输入结束时，触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|(Array\<Int32>)->Unit|是|-|密码输入结束时触发该回调。回调参数：与选中宫格圆点顺序一致的数字数组，数字为选中宫格圆点的索引值（第一行圆点从左往右依次为0、1、2，第二行圆点依次为3、4、5，第三行圆点依次为6、7、8）。|
