This directory serves as the central repository for API reference documentation regarding type definitions within the x509 package, specifically designed for the Cangjie programming language ecosystem. It focuses extensively on data structure aliases, providing developers with the necessary technical context to understand how networking data is represented and manipulated internally. The core of this documentation covers the definition of "type IP," explaining the specific implementation choice of using `Array<Byte>` to represent IP addresses. This establishes a critical link between the logical concept of an IP address and its physical byte array representation, which is essential for low-level data processing. This material is highly suitable for software developers, system architects, and security engineers who are actively working with X.509 certificates or building robust network security protocols. Readers are expected to have prior familiarity with Cangjie syntax and fundamental networking concepts to fully benefit from this reference. Essential keywords for this section include x509, type alias, IP address, Array<Byte>, Cangjie, and API reference.
