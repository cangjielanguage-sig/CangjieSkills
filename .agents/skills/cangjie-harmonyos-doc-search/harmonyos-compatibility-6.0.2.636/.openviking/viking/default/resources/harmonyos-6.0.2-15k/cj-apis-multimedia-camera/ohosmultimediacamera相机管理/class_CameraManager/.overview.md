# class_CameraManager

This directory provides API reference documentation for the `CameraManager` class in the Cangjie CameraKit framework for HarmonyOS. It details the core functionalities required to manage camera hardware, including creating inputs, configuring outputs (photo, video, preview, metadata), and handling capture sessions. The documentation also covers querying device capabilities, managing torch (flash) modes, and registering event callbacks. Designed for multimedia application developers, these guides offer syntax, parameters, error handling, and code examples to effectively integrate camera features into Cangjie-based applications.
