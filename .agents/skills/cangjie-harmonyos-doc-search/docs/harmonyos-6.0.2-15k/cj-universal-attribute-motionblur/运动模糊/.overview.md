# 运动模糊

This directory provides comprehensive technical documentation and practical examples for implementing motion blur effects within the ArkUI framework using the Cangjie language. It covers the essential data structures required for configuration, specific API constraints, and real-world code implementation for property animations. Key topics include the `MotionBlurOptions` class, `MotionBlurAnchor` coordinates, and the `motionBlur` modifier function. The content is specifically tailored for HarmonyOS and UI developers who possess knowledge of the Cangjie language and aim to enhance visual performance and dynamic transitions in their applications starting from system version 19.

## Detailed Description

### 基础类型定义.md
This API documentation defines basic data structures for implementing motion blur effects within the ArkUI framework using the Cangjie language. The document details two primary classes: MotionBlurOptions, which configures blur parameters like radius and anchor points, and MotionBlurAnchor, which specifies coordinate values for the anchor. Key takeaways include that all properties are read-only Float64 types, the radius should ideally be under 1.0, and anchor coordinates must align with animation scaling anchors. Targeted at UI developers, this reference guide requires knowledge of ArkUI and Cangjie to effectively apply motion blur visual effects starting from system version 19.

### 示例代码属性动画状态下添加运动模糊效果.md
This document provides a Cangjie code example demonstrating how to implement a motion blur effect on an image component during property animations. The primary focus is on utilizing the motionBlur modifier alongside animationStart to create dynamic visual transitions. Key information includes configuring MotionBlurOptions with specific radius and anchor parameters, and managing state changes for image dimensions. The example illustrates how to trigger the blur effect during a size change animation and reset it upon completion. This tutorial is intended for HarmonyOS developers using the Cangjie language and ArkUI framework who wish to enhance user interface animations with motion blur effects.

### 运动模糊_2more.md
This API documentation describes the motionBlur function used to apply dynamic blur effects to components undergoing scaling or displacement changes in the ArkUI framework. The document outlines the function signature, system capabilities, and the required MotionBlurOptions parameter. Key takeaways include strict usage constraints: the blur radius must be initialized to 0, reset to 0 upon animation completion using AnimateParam.onFinish, and kept below 1. It also warns against using this property with specific transition types or changing the radius frequently. This reference guide is intended for developers using the Cangjie language to enhance visual animation performance.
