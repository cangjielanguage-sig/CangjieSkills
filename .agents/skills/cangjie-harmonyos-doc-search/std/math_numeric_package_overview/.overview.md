# math_numeric_package_overview

This directory serves as the comprehensive API overview for the `std.math.numeric` package within the Cangjie language ecosystem. It is designed to assist developers in extending standard numeric capabilities by implementing arbitrary-precision arithmetic via `BigInt` and `Decimal` structs. The content covers a wide array of mathematical functions, including absolute values, greatest common divisors, least common multiples, square roots, and rounding operations. Furthermore, it details the `OverflowStrategy` enumeration to manage type conversions safely. This documentation is ideal for software engineers, data scientists, and developers who need to perform high-precision calculations, handle extremely large integers, or implement complex mathematical logic with strict rounding rules in their professional applications. By utilizing this package, developers can ensure numerical stability and precision in complex computational tasks. The scope includes both structural definitions and functional implementations for advanced math.
