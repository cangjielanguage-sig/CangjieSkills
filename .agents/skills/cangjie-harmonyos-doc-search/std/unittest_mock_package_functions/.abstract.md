This directory contains essential API reference documentation for the core functions within the unittest mock package, specifically tailored for the Cangjie programming language. It serves as a guide for developers on how to create mock and spy objects to facilitate robust unit testing. The documentation details three primary functions: the basic mock generator, a mock generator that accepts specific stub modes, and a spy wrapper function. It clarifies that mock objects do not possess default implementations unless explicitly specified via the `@On` decorator, whereas spy objects wrap real instances to delegate calls by default. Furthermore, it explains how to utilize an array of StubMode to configure stubbing behavior. This guide is intended for developers writing unit tests who require knowledge of the `@On` decorator and stubbing concepts to effectively simulate or monitor object behavior.
