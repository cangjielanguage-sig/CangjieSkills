# class_BatteryInfo

This directory provides essential API reference documentation for the `BatteryInfo` class, a core component of the BasicServicesKit in the Cangjie programming language. It is designed to assist developers in retrieving comprehensive device battery status information. The content covers a wide range of static read-only properties, including state of charge (SOC), health indicators, temperature readings, current flow, voltage levels, and charging connection types. All interfaces are documented with specific data types and system capability requirements, targeting API version 19 and later. This directory is highly suitable for application developers and system engineers aiming to integrate advanced power management features, monitor hardware power states, or create battery-aware user experiences in their applications.

## Detailed Description

### class_BatteryInfo_8more.md class_BatteryInfo_8more.md
This document serves as API reference documentation for the BatteryInfo class in the Cangjie programming language, designed to retrieve device battery status. It details several static read-only properties, including batterySOC, chargingStatus, healthStatus, batteryTemperature, and nowCurrent, providing data types and system capability requirements. The document also includes a practical code example demonstrating how to access and log these metrics. Intended for application developers using the BasicServicesKit, this reference enables the integration of battery monitoring features, such as checking charge levels, voltage, and presence, into applications running on version 19 or later.

### static_prop_pluggedType_3more.md static_prop_pluggedType_3more.md
This document provides API reference documentation for static properties within a battery management module written in the Cangjie language. It details three read-only properties: pluggedType for identifying the charger connection type, technology for the battery's technical model, and voltage for the current battery voltage. All properties utilize the SystemCapability.PowerManager.BatteryManager.Core capability and are available starting from API version 19. Key information includes the specific return types like BatteryPluggedType, String, and Int32. This reference is intended for developers building system-aware applications who need to query hardware power states and battery specifications programmatically.
