This directory focuses on the HiLog logging system within the Cangjie development environment, providing essential resources for debugging and monitoring applications. It comprehensively covers the theoretical aspects of the logging API, including the five distinct log levels, parameter constraints like the 4096-byte limit, and best practices for consistency checks. Additionally, it offers practical implementation guidance through hands-on code examples involving UI interactions. The content is designed to help developers analyze application execution and logic effectively. It is suitable for Cangjie and ArkUI developers who need to integrate logging into their projects, understand system constraints, and utilize DevEco Studio for log filtering and analysis to ensure code stability. The directory includes both a technical API guide and a practical development example.
