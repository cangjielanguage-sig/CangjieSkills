# 类

This directory contains API reference documentation for core classes within the Cangjie HTTP framework. It covers essential components for building web clients and servers, including request/response handling, file transfers, WebSocket communication, and connection management. Key topics include HTTP/1.1 and HTTP/2 protocols, TLS configuration, and the builder pattern for object instantiation. This documentation is suitable for backend developers, software engineers, and system integrators working with the Cangjie programming language to implement robust network communication and web services.

## Detailed Description

### class_FileHandler.md class_FileHandler.md
This API documentation defines the FileHandler class, designed to manage HTTP file downloads and uploads within the Cangjie framework. It details the class constructor, which accepts a file path, handler type, and buffer size, alongside the handle method for request processing. Key specifications include enforcing GET requests for downloads and POST requests with multipart/form-data for uploads, along with specific HTTP status codes for errors. This guide targets developers implementing file transfer functionality in web applications.

### class_FuncHandler_2more.md class_FuncHandler_2more.md
This API reference details the FuncHandler and HttpContext classes for handling HTTP server requests in the Cangjie programming language. It covers the FuncHandler implementation, which wraps a function into a handler, and the HttpContext class, which provides server-side context including access to requests, responses, and connection state checks. This document is intended for backend developers using Cangjie to build web services who need to understand request processing and context management.

### class_HttpHeaders.md class_HttpHeaders.md
This document serves as API reference for the Cangjie HttpHeaders class, designed to represent and manipulate HTTP message headers and trailers. It covers the class structure, which inherits from Iterable, and details key methods for data management including add, set, get, and del. Key information includes that field-names are case-insensitive and stored in lowercase, while field-values must comply with RFC 9110 standards. This guide is intended for developers implementing HTTP communication.

### class_HttpResponse.md class_HttpResponse.md
This API documentation defines the HttpResponse class in Cangjie, providing interfaces for clients to read and manage server HTTP responses. It details properties for accessing response components like body, headers, status, and version, alongside methods for resource management. It also includes an extension section specifically for HTTP/2.0 features like server pushes. Key information highlights the non-concurrent nature of body reading and connection persistence rules.

### class_HttpResponsePusher_3more.md class_HttpResponsePusher_3more.md
This document provides API reference for three HTTP server utility classes: HttpResponsePusher for managing HTTP/2 server push operations, HttpResponseWriter for granular control over response body transmission, and NotFoundHandler for standard 404 error handling. It outlines methods for initiating resource pushes and streaming data chunks, with specific behaviors for HTTP/1.1 and HTTP/2 protocols. This targets backend developers implementing advanced HTTP features.

### class_OptionsHandler_3more.md class_OptionsHandler_3more.md
This document provides API reference for three specific classes used in HTTP handling: OptionsHandler for managing preflight requests, the abstract ProtocolService for connection lifecycle, and RedirectHandler for managing URL redirections. Key takeaways include the fixed response headers for OPTIONS requests, protocol service responsibilities, and validation logic for redirect status codes. This technical reference is intended for backend developers implementing HTTP servers or middleware.

### class_WebSocketFrame.md class_WebSocketFrame.md
This API documentation defines the WebSocketFrame class, the fundamental unit for reading data in the Cangjie WebSocket implementation. It details core properties like fin, frameType, and payload, explaining how they determine frame fragmentation. The document emphasizes that users must manually concatenate payloads for fragmented messages and handle interleaved control frames carefully. This guide targets developers who need to manage low-level WebSocket data transmission.

### class_Client/
This directory contains API reference documentation for the HTTP Client class in the Cangjie programming language. It covers the core functionality for sending HTTP/1.1 and HTTP/2 requests, managing connections, and handling protocol upgrades. Key topics include client configuration (timeouts, proxies, cookies), convenience methods for standard HTTP verbs, and low-level request sending. It is suitable for developers integrating network communication into Cangjie applications.

### class_ClientBuilder/
This directory contains API documentation for the `ClientBuilder` class, which acts as the exclusive constructor for HTTP Client instances. It covers the builder pattern implementation, including configuration of redirects, cookies, server push, and custom connectors. The documentation also details HTTP/2 protocol settings, network proxy configuration, and connection management features like timeouts and TLS. It is suitable for developers who need to instantiate and fine-tune HTTP clients.

### class_Cookie/
This directory contains comprehensive API reference documentation for the `Cookie` class within the Cangjie HTTP package. It focuses on stateful session management via HTTP cookies, covering object initialization, attribute manipulation, and string serialization for server headers. The documentation adheres to RFC 6265 standards and is suitable for developers building server-side logic or HTTP clients who need to implement compliant cookie handling.

### class_Server/
