This directory provides comprehensive API reference documentation for the Cangjie `Params` class and related static constants within the HarmonyOS development environment. It details system preset string constants used as keys for `Want.parameters`, which are crucial for configuring application behaviors at the system level. The documentation covers a wide range of functionalities, including ability lifecycle management, navigation control, fault detection, and cross-device migration behaviors. Key topics include UIAbility configuration, atomic service sharing, and application continuation logic. This resource is intended for HarmonyOS developers using the Cangjie language who need to implement specific extra parameters for application jumps, manage sharing scenarios, and customize migration logic across devices.
