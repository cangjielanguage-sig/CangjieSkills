This directory provides comprehensive API documentation for the `BufferedInputStream` class within the Cangjie standard library. It details a generic wrapper designed to enhance input stream performance through buffering. The content covers class initialization, including various constructor overloads for memory optimization, and extends functionality for resource management and seekable operations. Additionally, it documents essential reading functions and stream state management. This resource is intended for Cangjie developers seeking to implement efficient, safe, and high-performance I/O operations in their applications.
