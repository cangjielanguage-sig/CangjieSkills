This directory contains API reference documentation for the `AVMetadata` class in the Cangjie programming language, specifically designed for the AVSession framework. It covers the definition and management of media asset metadata, including constructors, properties, and variables for attributes like asset IDs, titles, artists, lyrics, and DRM schemes. The documentation details data handling rules, system capabilities, and version requirements. It is suitable for multimedia developers building media playback applications who need to structure and access media information accurately for system sessions.
