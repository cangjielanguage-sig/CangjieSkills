# 基础类型定义

This directory contains API reference documentation for fundamental data structures and enumerations used in navigation within the ArkUI framework, specifically for the Cangjie language. It covers essential classes for managing navigation stacks (`NavPathStack`), defining path information (`NavPathInfo`), and configuring navigation behaviors (`NavigationOptions`, `LaunchMode`). Additionally, it includes definitions for UI customization like title bar settings (`NavigationTitleOptions`) and pop operation results (`PopInfo`). These documents are intended for developers building user interfaces who need to implement complex page navigation logic, handle page lifecycles, and customize navigation transitions and styles in ArkUI applications.
