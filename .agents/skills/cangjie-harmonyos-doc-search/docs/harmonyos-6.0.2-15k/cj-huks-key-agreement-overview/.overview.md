# cj-huks-key-agreement-overview

This directory serves as a comprehensive technical resource dedicated to key agreement mechanisms within the HUKS (HarmonyOS Universal Keystore) framework. It provides an in-depth examination of the cryptographic protocols used to securely establish shared secrets between devices, focusing on the critical exchange of public keys while ensuring that private keys are strictly retained locally to guarantee confidentiality. The documentation thoroughly details the supported algorithms, specifically ECDH, DH, and X25519, and outlines essential implementation constraints such as the mandatory requirement for API level 15 or higher and the exclusion of lightweight device categories. This guide is indispensable for developers and security engineers aiming to construct secure communication channels in HarmonyOS applications, providing the necessary specifications to ensure compliance with modern cryptographic standards and system capabilities.
