# RSAECBOAEPSHA256

This directory provides a comprehensive collection of Cangjie code examples designed to demonstrate the implementation of RSA cryptographic operations within the HarmonyOS Universal Keystore (HUKS) framework. The primary focus is on utilizing RSA with ECB mode, OAEP padding, and SHA-256 digest to ensure robust data security. The documentation covers the entire cryptographic key lifecycle, including the generation of RSA 2048-bit keys, the encryption and decryption of data, and the secure deletion of key items. These resources are specifically tailored for developers using the Cangjie language who require practical guidance on integrating secure HUKS-based encryption and key management strategies into their HarmonyOS applications to protect sensitive information effectively.

### RSAECBOAEPSHA256_1.md RSAECBOAEPSHA256_1.md
This document provides a Cangjie code example demonstrating how to implement RSA encryption using the ECB mode, OAEP padding, and SHA-256 digest within the HarmonyOS Universal Keystore framework. The content covers helper functions for data conversion, configuration functions for defining cryptographic properties like algorithm and key size, and scenario functions for key generation and data encryption. Key takeaways include the specific parameter sets for RSA 2048-bit keys and the workflow involving generateKeyItem, initSession, and finishSession. This tutorial targets developers using the Cangjie language who need to integrate secure cryptographic operations, specifically HUKS-based encryption, into their applications.

### RSAECBOAEPSHA256_2.md RSAECBOAEPSHA256_2.md
This document provides code examples for performing RSA decryption and deleting keys using the HarmonyOS Universal Keystore Service (HUKS). It details the DecryptData function, which illustrates retrieving decryption properties, initializing a session with a specific key alias, and finalizing the session to obtain plaintext. Additionally, it covers the DeleteKey function, demonstrating how to securely remove a key item using its alias. Key concepts include session management via initSession and finishSession, and the use of HuksOptions for parameter configuration. This technical reference is intended for developers implementing cryptographic operations, specifically those managing RSA key lifecycles and data security.
