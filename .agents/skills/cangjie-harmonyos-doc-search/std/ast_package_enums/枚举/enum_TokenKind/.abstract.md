This directory contains comprehensive documentation for the `TokenKind` enumeration within the Cangjie programming language compiler. It details the lexical tokens used for parsing, including keywords, operators, punctuation, and various literal forms. The documentation is split across multiple files to cover the extensive list of syntax elements systematically. It serves as a critical reference for understanding the language's internal representation of source code. This resource is suitable for compiler developers, language tool implementers, and engineers working on abstract syntax trees (AST) or lexical analysis who need precise definitions of Cangjie's syntax rules and token types.
