## Detailed Description

### 使用SM4对称密钥GCM模式加解密/
This subdirectory provides an in-depth guide and complete code examples for performing data encryption and decryption using the SM4 symmetric key in GCM mode. It meticulously outlines the development process based on the CryptoArchitectureKit, enabling developers to integrate advanced cryptographic functions seamlessly. The guide covers essential steps such as generating secure SM4 keys, initializing the Cipher with the correct parameters, and handling data segmentation to optimize memory usage and performance for large files. Crucially, it addresses the extraction and verification of the authentication tag (authTag), which is vital for ensuring that encrypted data has not been tampered with. The documentation is specifically tailored for developers using the Cangjie language, aiming to deepen their understanding of the SM4_128/GCM/PKCS7 algorithm. It explains how PKCS7 padding is applied to block data and how GCM mode provides authenticated encryption, making it an indispensable resource for mastering secure development practices in the Cangjie environment.
