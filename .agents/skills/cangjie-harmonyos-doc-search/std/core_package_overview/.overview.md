# core_package_overview

This directory serves as the comprehensive documentation hub for the core package of the Cangjie language standard library. It details the foundational infrastructure automatically available to developers, eliminating the need for manual imports for basic functionalities. The documentation covers a wide array of essential topics, including built-in data types (integers, floating-point numbers), frequently used utility functions (such as `print` and `println`), and critical standard interfaces like `ToString` and `Hashable`. Additionally, it provides in-depth information on core classes, structs, and the exception handling hierarchy. This resource is specifically designed for Cangjie programmers and system architects who require a deep understanding of the language's basic building blocks. By mastering these structural components, users can construct robust, efficient applications and leverage the full power of the standard library from the very first line of code.

## Detailed Description

### stdcore/

The `stdcore` directory serves as the primary documentation hub for the core package of the Cangjie language standard library. It acts as the definitive guide for the language's foundational infrastructure, covering essential programming capabilities that are available to developers immediately upon starting a project. Key topics include built-in data types (such as integers and floating-point numbers), frequently used utility functions (like `print` and `println`), and critical standard interfaces (including `ToString` and `Hashable`). Furthermore, it documents core classes, structs, and the exception handling hierarchy. Because the core package is automatically imported by default, understanding its contents is mandatory for all Cangjie developers. This documentation is specifically tailored for programmers and system architects who need a deep understanding of the basic building blocks and structural components required to construct robust, efficient applications in the Cangjie environment. It ensures users can leverage the full power of the standard library from the very first line of code.
