# Context的典型使用场景

This directory serves as a comprehensive resource for developers working with the Context object in HarmonyOS applications. It covers essential scenarios such as retrieving application file paths, managing encrypted partitions for data security, accessing module contexts, and monitoring intra-process Ability lifecycle changes. The content includes practical guides and code examples in Cangjie and ArkTS, focusing on resource management, sandbox directories, and component interaction. It is suitable for application developers seeking to implement robust local storage, enhance data security, and ensure application stability through precise lifecycle monitoring.

## Detailed Description

### Context的典型使用场景.md Context的典型使用场景.md
This document serves as a practical guide for developers on how to utilize the Context object in typical application scenarios. It covers four main topics: retrieving application file paths, accessing and modifying encrypted partitions, obtaining Context for other modules within the same application, and subscribing to intra-process Ability lifecycle changes. The text highlights the Context's role in resource management, security, and component interaction. Intended for application developers, this guide assumes familiarity with the underlying framework and aims to provide specific implementation examples for common tasks. Keywords include Context, file path, encrypted partition, module, and Ability lifecycle.

### 获取加密分区_2more.md 获取加密分区_2more.md
This technical guide instructs Cangjie developers on accessing encrypted file partitions and managing module contexts to enhance data security. It details five encryption levels (EL1-EL5), explaining specific use cases ranging from device-level access for alarms (EL1) to high-security privacy data (EL5) and lock-screen file operations (EL3). The document provides code examples demonstrating how to retrieve the current encryption area via the `context.area` property and how to access other modules' contexts using the `createModuleContext` function. Targeted at application developers, this resource helps in selecting appropriate security measures based on data sensitivity and access requirements.

### 获取应用文件路径/
This directory provides comprehensive resources on retrieving and managing application file paths within the HarmonyOS ecosystem. It covers the theoretical distinctions between application-level and module-level contexts, such as `ApplicationContext` and `UIAbilityContext`, and their impact on data lifecycle. Furthermore, it offers practical coding tutorials in Cangjie for performing file input-output operations, including creating, writing, and reading files using `CoreFileKit`. Key topics include sandbox directories, data persistence, and context lifecycle management. This content is essential for developers seeking to implement robust local storage solutions and understand the underlying file system architecture in HarmonyOS applications.

### 订阅进程内Ability生命周期变化/
This directory provides comprehensive technical guidance on managing UIAbility lifecycle events within the same application process on the HarmonyOS platform. It details the mechanisms for subscribing to and unsubscribing from state changes—such as creation, window stage events, and foreground or background transitions—using the ApplicationContext. These capabilities are essential for gathering DFX statistics, including page dwell time, and for maintaining application health. The documentation includes practical code examples in both Cangjie and ArkTS, illustrating the implementation of `AbilityLifecycleCallback`, listener ID management, and proper resource cleanup. This resource is specifically designed for application developers utilizing the AbilityKit framework who require precise monitoring and control over their application's lifecycle behavior to ensure performance and stability.
