This directory serves as a comprehensive technical resource for addressing common queries and troubleshooting issues related to HarmonyOS application packages. It primarily focuses on the mechanisms for retrieving essential application metadata, specifically the `appIdentifier` and signature fingerprint information. The documentation covers a diverse range of techniques, including programmatic retrieval using the Cangjie API (via `BundleManager`), command-line operations using the `bm` tool, and certificate analysis using standard utilities like `keytool`. Furthermore, it clarifies the critical distinction between auto-signing and manual signing configurations and their impact on application identity stability. This content is specifically designed for HarmonyOS developers, QA engineers, and technical support personnel involved in application debugging, signature verification, and cross-device ecosystem integration.
