# aspectCJ_samples

This directory serves as a comprehensive educational resource and practical toolkit for developers interested in Aspect-Oriented Programming (AOP) within the Cangjie language ecosystem. It focuses on utilizing the `stdx.aspectCJ` library to achieve non-invasive code enhancement through detailed examples and development guides. The content covers essential AOP concepts, including entry instrumentation, exit instrumentation, and function body replacement, providing the necessary tools to separate cross-cutting concerns from business logic. It is specifically designed for Cangjie developers who wish to master AOP techniques, optimize code architecture, improve modularity, or implement low-level logic interception without modifying existing source code directly. Whether you are building complex enterprise systems or refining application structure, this collection offers the foundational knowledge required.

## Detailed Description

### aspectCJ_sample/
This subdirectory acts as a dedicated hub for practical examples and comprehensive development guides focused on Aspect-Oriented Programming (AOP) within the Cangjie language. It delves deeply into the practical application of the `stdx.aspectCJ` library, illustrating how developers can achieve non-invasive code enhancement—modifying behavior without altering the original source code structure. The primary focus is on the application scenarios of three pivotal annotations: `@InsertAtEntry` (entry instrumentation), which allows code execution before a method runs; `@InsertAtExit` (exit instrumentation) for post-execution logic; and `@ReplaceFuncBody`, which enables the complete substitution of a function's body.

In addition to providing complete, runnable code implementations, the documentation meticulously outlines the technical requirements for building these projects. It specifically details the two-step compilation process necessary for aspect collection and weaving within a Linux environment. This guide is invaluable for Cangjie developers seeking to master AOP technology, as it provides the tools needed to optimize code structure, separate cross-cutting concerns, and perform sophisticated interception of underlying logic.
