This directory provides comprehensive API documentation for the `PrimitiveTypeInfo` class, a core component of the Cangjie programming language's reflection package. It details how developers can describe and inspect type information for primitive data types, such as integers, floats, and booleans. The documentation covers class definitions, inheritance from `TypeInfo`, and specific methods for retrieving metadata, including handling exceptions for invalid types. It is designed for Cangjie developers who need to implement reflection features, programmatically inspect types, or manage runtime and static type information within their applications.
