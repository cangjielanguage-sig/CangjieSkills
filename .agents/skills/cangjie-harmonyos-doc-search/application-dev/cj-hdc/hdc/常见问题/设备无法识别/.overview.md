# 设备无法识别

This directory provides a comprehensive collection of troubleshooting guides aimed at resolving device recognition failures within the HarmonyOS/OpenHarmony development environment. It addresses critical issues where development tools cannot detect connected hardware, often manifested by empty command-line outputs. The documentation encompasses a wide array of technical solutions, ranging from basic physical connection diagnostics to advanced system-level configurations. Key topics include repairing Windows drivers via registry modifications, configuring Linux udev rules for proper USB access, resolving daemon process communication errors, and managing network port conflicts. These resources are specifically tailored for developers and technical users operating across Windows, Linux, and macOS platforms who require reliable device connectivity for application debugging and deployment.

## Detailed Description

### 设备无法识别_1.md
This troubleshooting guide addresses the issue where the `hdc list targets` command returns an empty result, indicating an unrecognized device. It covers four primary scenarios: physical connection issues, Windows driver corruption, daemon communication failures, and server connection failures. Key solutions include verifying USB hardware, reinstalling drivers using the WinUSB device option, resolving version mismatches, and managing port conflicts by killing conflicting processes or changing the `OHOS_HDC_SERVER_PORT` environment variable. The document provides specific instructions for Windows, Linux, and macOS, targeting developers debugging HarmonyOS/OpenHarmony devices.

### 设备无法识别_2.md
This troubleshooting guide provides solutions for resolving device recognition issues on Windows and Linux systems. The document is divided into two main sections: a Windows registry fix and a Linux permission configuration. Key information includes instructions for Windows users to navigate to a specific registry path and clear the UpperFilters value to fix USB driver issues. For Linux users, it details methods to grant non-root USB access for the hdc tool, using either temporary chmod commands or permanent udev rules. This guide targets developers and technical users needing to restore device connectivity.
