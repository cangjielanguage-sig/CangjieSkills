# 基础类型定义

This directory serves as a comprehensive API reference for fundamental type definitions within the ArkUI framework, specifically tailored for the Cangjie language. It covers essential classes and enums used to configure visual transformations and animations for UI components, including scaling, translation, rotation, and transition effects. By providing detailed specifications for properties like axis vectors, multipliers, and animation parameters, this documentation enables developers to implement dynamic and spatially complex user interfaces. It is suitable for UI developers and system architects working with ArkUI version 12+ who require precise control over component styling and lifecycle animations.

## Detailed Description

### class_ScaleOptions.md class_ScaleOptions.md
This API reference document defines the ScaleOptions class used to configure scaling transformations within the ArkUI framework using the Cangjie language. It details the class properties x, y, and z for scaling multipliers, alongside centerX and centerY for defining the transformation origin, as well as the class constructor. Key information includes that scaling properties accept Float32 values where values greater than 1 enlarge, values between 0 and 1 shrink, and negative values flip the axis, with center coordinates defaulting to 50 percent. This guide targets UI developers implementing component scaling effects in ArkUI applications.

### class_TranslateOptions_2more.md class_TranslateOptions_2more.md
This document serves as API reference documentation for the Cangjie language, specifically defining the TranslateOptions class and TransitionEdge enum within the ArkUI framework. The main sections cover the TranslateOptions class, which sets 3D translation parameters for x, y, and z axes using Length types, and the TransitionEdge enum, which identifies window edges like Top, Bottom, Start, and End. Key information includes default translation values of 0.0.vp and the directional logic for Start and End edges based on LTR or RTL modes. Intended for developers using ArkUI, this document supports the implementation of component transformations and window transitions starting from version 12.

### class_TransitionEffect/
This directory contains API reference documentation for the `TransitionEffect` class within the ArkUI framework, specifically designed for the Cangjie language. It covers the definition and combination of transition animations for component appearance and disappearance, including static constants like IDENTITY and OPACITY, as well as methods for move, rotate, scale, and translate effects. It is suitable for developers using ArkUI (version 12+) who need to implement sophisticated UI animations and manage component lifecycles in their applications.
