# cj-apis-bundle_manager

This directory serves as the definitive API reference documentation for the `ohos.bundle.bundle_manager` module, specifically tailored for the Cangjie programming language within the HarmonyOS ecosystem. It provides a comprehensive overview of the tools and interfaces required for effective application package management. The content covers critical functionalities such as querying application and module metadata, managing default applications, and configuring core components like Ability and ExtensionAbility. Additionally, it addresses essential system-level operations including permission control, window property settings, and the definitions for routing, signing, and dependencies. This resource is indispensable for Cangjie developers aiming to build robust, secure, and well-integrated HarmonyOS applications by leveraging the full capabilities of the BundleManager framework.

## Detailed Description

### ohosbundlebundle_managerbundleManager管理/

This directory contains the API reference documentation for the `ohos.bundle.bundle_manager` module, written in the Cangjie language. It is designed to support developers by covering the core functions of HarmonyOS application package management. The documentation provides detailed insights into querying application and module metadata, which is fundamental for understanding the structure and state of installed applications. It also includes guidance on managing default applications and configuring components such as Ability and ExtensionAbility, which are crucial for defining app behaviors and capabilities.

Furthermore, the directory covers permission control mechanisms and window property settings, ensuring applications can securely access system resources and present UI elements correctly. The documentation rigorously defines the classes and enumerations necessary for describing routing patterns, which are essential for navigation flow; digital signatures, which ensure application authenticity and security; dependency relationships, which manage how modules interact with one another; and display orientations, which control how content is presented on different screen types. By providing these resources, the directory aims to assist developers using the Cangjie language in deeply understanding and effectively utilizing the BundleManager framework. This facilitates efficient application information retrieval, precise module configuration, and seamless system interaction, ultimately streamlining the development process for HarmonyOS applications.
