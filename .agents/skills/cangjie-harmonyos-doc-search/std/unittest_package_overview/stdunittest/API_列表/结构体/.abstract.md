This directory contains documentation regarding data structures, specifically focusing on "structs" within the context of a unit testing and benchmarking framework. It covers API references for configuration keys, input data providers, performance measurement utilities, and timeout handling mechanisms. The content ranges from introductory concepts to detailed technical specifications for specific structs like `TimeNow`, `Perf`, and various configuration keys. It is suitable for C++ developers, QA engineers, and students looking to understand or extend the internal data handling and configuration options of the testing framework.
