# class_Verify

This directory contains API documentation for the `Verify` class within the Cangjie CryptoFramework, focusing on digital signature verification. It covers the complete workflow including initialization with public keys, data updates, and final verification. Key topics include RSA and SM2 algorithms, parameter configuration, and data recovery from signatures. The documentation is designed for developers implementing cryptographic security features, requiring knowledge of asymmetric encryption and Cangjie syntax.
