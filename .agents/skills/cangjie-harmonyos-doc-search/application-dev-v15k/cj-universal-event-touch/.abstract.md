This directory serves as a comprehensive resource for handling universal touch events within the HarmonyOS ArkUI framework, specifically implemented using the Cangjie programming language. It provides in-depth coverage of touch interaction implementation, ranging from basic event callbacks to complex state management using the `@State` decorator. Developers will find detailed guidance on retrieving essential touch data, including precise coordinates and timestamps, to enhance user experience. The repository includes practical code examples that demonstrate UI layout construction using fundamental components like Column and Button. Furthermore, it offers API references for the `onTouch` function introduced in system version 12 and defines core data structures such as `TouchEvent` and `TouchObject`. This material is highly suitable for HarmonyOS developers aiming to build interactive, responsive user interfaces and gain a thorough understanding of the underlying event propagation logic. By leveraging these resources, developers can ensure their applications respond intuitively to user gestures.
