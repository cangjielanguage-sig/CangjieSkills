## Detailed Description

### class_Ability_3more_bf041da7.md class_Ability_3more_bf041da7.md
本文档是仓颉语言的API参考文档，详细定义了Ability、AbilityStageContext和ApplicationContext三个核心类。主要内容包括Ability作为UIAbility和ExtensionAbility的抽象基类，提供系统配置更新和内存调整回调；AbilityStageContext提供AbilityStage的上下文环境及HapModuleInfo属性访问；ApplicationContext则提供应用级别的生命周期监听和进程管理能力。这些类均继承自Context，系统能力起始版本为22。文档面向HarmonyOS应用开发者，旨在帮助其理解应用运行时的上下文管理与基类功能。

### class_Context.md class_Context.md
这是一份仓颉语言的API参考文档，详细介绍了Context类的定义与用法。该类继承自BaseContext，旨在为Ability或Application提供上下文支持及资源访问能力。文档核心内容涵盖了四个关键属性：applicationInfo（应用信息）、area（文件加密分区）、filesDir（文件目录）和resourceManager（资源管理器），以及用于ArkTS互操作的toJSValue方法。每个条目均包含类型定义、读写权限及代码示例。该文档主要面向使用AbilityKit进行HarmonyOS应用开发的开发者，旨在帮助他们掌握如何通过Context对象管理应用运行时环境与资源。

### func_createContex_3more_bd80239c.md func_createContex_3more_bd80239c.md
本文档是仓颉语言的API参考文档，主要阐述了ArkTS互操作中Context对象与JSValue之间的类型转换机制。文档涵盖了createContextFromJSValue和createUIAbilityContextFromJSValue两个核心函数，用于将JSValue转换为Context或UIAbilityContext实例。同时介绍了SystemObjectInteropTypeToJS接口及其toJSValue方法，实现了仓颉系统对象向JSValue的转换。这些API属于系统能力SystemCapability.Ability.AbilityRuntime.Core，适用于需要在仓颉与ArkTS环境间进行上下文传递和互操作的开发者。

### ohosappabilityui__6more_10513f82.md ohosappabilityui__6more_10513f82.md
这份文档是HarmonyOS仓颉语言中ohos.app.ability.ui_ability模块的API参考文档，旨在提供UIAbility应用组件的核心API说明。文档涵盖了UIAbility生命周期管理、Context体系及ArkTS互操作能力，并列出了相关权限与导入方式。重点介绍了createAbilityStageContextFromJSValue和createApplicationContextFromJSValue函数，详细说明了其参数、返回值及如何将JSValue转换为Context类型。该文档面向使用仓颉语言进行HarmonyOS应用开发的开发者，帮助他们实现组件管理及跨语言交互。

### class_UIAbility/
本目录包含Cangjie语言中`UIAbility`类的API参考文档，专为鸿蒙应用开发设计。内容涵盖了UIAbility类的核心定义、生命周期管理（如创建、销毁、前后台切换）、窗口阶段事件以及Caller与Callee的通信机制。文档详细介绍了关键属性（如context、launchWant）和回调方法，旨在帮助开发者掌握UI组件的状态切换、资源管理及窗口交互逻辑。适用于使用Cangjie语言和AbilityKit框架进行应用开发的开发者。

### class_UIAbilityContext/
本目录包含Cangjie（仓颉）语言中UIAbilityContext类的API参考文档，主要面向HarmonyOS应用开发者。内容涵盖了UIAbility组件的上下文环境定义、生命周期管理及组件间交互。核心功能包括启动Ability（startAbility系列）、销毁Ability（terminateSelf系列）以及查询组件状态和请求模态弹框服务。文档详细描述了方法参数、返回值、系统能力要求及业务异常错误码，并提供了丰富的代码示例，旨在帮助开发者掌握AbilityKit框架下的组件启动、跳转与数据交互。
