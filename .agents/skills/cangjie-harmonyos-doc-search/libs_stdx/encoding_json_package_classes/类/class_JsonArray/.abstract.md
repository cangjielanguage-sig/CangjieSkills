This directory provides comprehensive API reference documentation for the `JsonArray` class within the Cangjie programming language. It is designed to assist developers in encapsulating, manipulating, and serializing array-type JSON data structures. The documentation covers class inheritance from `JsonValue`, various initialization constructors, and essential instance methods for data handling such as `add`, `get`, and `size`. Additionally, it details string conversion utilities and formatting options. This resource is ideal for Cangjie developers who require precise programmatic control over parsing, constructing, and interacting with JSON data.
