This directory provides comprehensive API reference documentation for the HarmonyOS App Account management module, specifically tailored for the Cangjie programming language. It covers essential functionalities such as account creation, authentication flows, token management, and credential verification. The documentation details various classes, enums, and options necessary for implementing secure account handling and distributed data synchronization. Targeted at application developers using Cangjie, these resources offer the structural definitions and interfaces required to integrate robust account management features into HarmonyOS applications, with support starting from API version 19.
