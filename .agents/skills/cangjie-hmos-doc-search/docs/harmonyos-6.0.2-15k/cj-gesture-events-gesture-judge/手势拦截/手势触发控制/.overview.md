# 手势触发控制

This directory focuses on the advanced mechanism of gesture trigger control within the HarmonyOS development ecosystem. It provides comprehensive resources for developers looking to implement custom logic for intercepting or allowing gestures, specifically after system thresholds have been satisfied. The content covers essential definitions of gesture interception, introduces critical APIs such as `onGestureJudgeBegin` and `onGestureRecognizerJudgeBegin`, and offers practical code examples in the Cangjie language. It is particularly suitable for HarmonyOS developers and UI engineers who require fine-grained control over gesture conflicts, event passing, and recognition logic in complex, multi-layered UI layouts using ArkUI.

## Detailed Description

### 手势触发控制_1.md
This technical guide explains the mechanism of gesture trigger control, allowing applications to intercept or allow gestures based on custom logic after system thresholds are met. The document covers the definition of gesture interception, introduces key APIs including onGestureJudgeBegin and the enhanced onGestureRecognizerJudgeBegin, and provides a practical code example using the Cangjie language. Key information includes a demonstration of handling overlapping components by checking gesture type and touch coordinates to decide whether to return GestureJudgeResult.CONTINUE or REJECT. It targets HarmonyOS developers who need fine-grained control over gesture conflicts in complex UI layouts.

### 手势触发控制_2.md
This code example demonstrates how to manage gesture conflicts and interception between overlapping UI components in ArkUI. The document presents a Stack layout containing an upper layer with a long-press gesture and a lower layer with a draggable image. Key information includes the implementation of `onGestureJudgeBegin`, which determines gesture ownership based on touch coordinates; it accepts long-press gestures only in the upper half and rejects others to allow the underlying drag gesture to trigger. This tutorial is intended for HarmonyOS developers seeking to implement complex gesture recognition and event passing logic.
