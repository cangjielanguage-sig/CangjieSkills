# cj-apis-security_huks

This directory contains the Cangjie language API reference documentation for the HarmonyOS Universal Key Store (HUKS). It focuses on the comprehensive management of cryptographic keys throughout their entire lifecycle, including generation, import, export, deletion, and encryption or decryption session management. The documentation details key attribute configurations such as algorithms, usage purposes, padding modes, and authentication types. It is designed for engineers developing security applications using the Cangjie language on HarmonyOS or OpenHarmony, enabling them to implement hardware-level key storage and granular access control. Core keywords include HUKS, Cangjie, key management, encryption algorithms, and security authentication.
