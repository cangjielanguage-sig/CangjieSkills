# 非首次渲染

This directory focuses on managing dynamic UI updates and state synchronization for the `LazyForEach` component during non-initial rendering phases in the Cangjie and ArkUI frameworks. It covers essential techniques for modifying list data, including swapping items, updating single or multiple entries, and handling additions or deletions. Additionally, it addresses performance optimization strategies for updating sub-properties using decorators like `@Observed` and `@Link`. This resource is suitable for developers working with dynamic lists who need to implement efficient data-driven UI updates and maintain high rendering performance in complex applications.

### 交换数据.md 交换数据.md
This tutorial demonstrates how to implement data swapping functionality within a LazyForEach list component using the Cangjie programming language. The document covers the implementation of a custom data source extending BasicDataSource and the logic for handling user interactions to trigger data movement. Key information includes the moveData method, which swaps data elements and calls notifyDataMove to signal the UI update, and the click handling logic that identifies two items to exchange. This guide is intended for developers working with dynamic list rendering in Cangjie who need to understand data-driven UI updates and component reordering.

### 改变单个数据.md 改变单个数据.md

Key takeaways include the data flow where modifying data triggers notifyDataChange, which subsequently calls the listener to rebuild the specific child component at the updated index. This guide is intended for developers working with dynamic lists in Cangjie UI frameworks, providing a practical example of handling item-level updates and UI synchronization.

### 改变多个数据.md 改变多个数据.md

The document covers the implementation of a custom data source extending BasicDataSource, including methods for data manipulation and reload notifications. Key takeaways include the process of calling modifyAllData followed by reloadData, which invokes notifyDataReload to rebuild child nodes. This guide is intended for developers managing dynamic list updates and state synchronization in UI development.
