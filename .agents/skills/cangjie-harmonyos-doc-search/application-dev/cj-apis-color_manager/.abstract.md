This directory provides essential API reference documentation for the `ohos.graphics.color_space_manager` module, specifically developed for the HarmonyOS ArkGraphics2D framework using the Cangjie language. It serves as a technical guide for the creation, management, and manipulation of color space objects, addressing complex requirements such as standard gamuts, custom primaries, and transfer functions. The documentation details critical components including the `ColorSpaceManager` class, `ColorSpacePrimaries` class, and `ColorSpace` enumeration. This resource is primarily suitable for graphics developers and engineers focused on 2D rendering and color management who need to implement precise, standardized color handling in their Cangjie applications.
