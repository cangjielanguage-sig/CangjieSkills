# cj-apis-common_event_publish_data

This directory serves as a comprehensive resource for the `ohos.common_event_publish_data` module within the HarmonyOS operating system, specifically designed for developers using the Cangjie (仓颉) programming language. It provides in-depth information on defining the content and attributes of common events, which are crucial for inter-process communication and application interaction. The documentation covers essential aspects such as module import methods, specific API usage instructions for Cangjie, and configuration requirements across various project files. Key topics include the management of event data structures, handling subscriber package names, configuring permissions, and utilizing event type flags like ordered and sticky events. As the module is currently in the Beta stage, it requires the import of `kit.BasicServicesKit`. This guide is best suited for HarmonyOS developers who possess a solid understanding of Cangjie project template structures and Context application context configurations, enabling them to effectively implement and manage event publishing in their applications.
