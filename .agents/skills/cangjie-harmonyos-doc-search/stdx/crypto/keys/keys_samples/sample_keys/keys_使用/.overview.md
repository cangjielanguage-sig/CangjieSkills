# keys_使用

本目录包含仓颉编程语言中关于密钥使用的示例代码与教程。主要涵盖了 RSA、ECDSA 以及国密 SM2 等非对称加密算法的实际应用场景。内容详细介绍了密钥对的生成、数据的加解密、数字签名与验签，以及 PEM 格式密钥文件的导入导出操作。通过 `stdx.crypto.keys` 等标准库的具体演示，帮助开发者快速掌握数据安全处理的核心技术。该文档适合需要在仓颉项目中集成加密功能、保障数据传输与存储安全的开发者参考。

## 详细描述

### RSA_密钥示例_2more_26d5f738.md RSA_密钥示例_2more_26d5f738.md
本文档旨在演示如何在仓颉编程语言中利用标准库实现 RSA 和 ECDSA 非对称加密操作。文档主要涵盖 RSA 密钥示例和 ECDSA 密钥示例两大板块。在 RSA 部分，重点展示了生成密钥对、使用 OAEP 填充模式进行加解密，以及从 PEM 文件加载密钥并使用 PKCS1 填充模式进行签名与验证的完整流程。ECDSA 部分则演示了基于 P224 曲线的密钥生成及签名验证。作为一份代码教程，它通过具体的 Cangjie 代码片段，向开发者展示了 stdx.crypto.keys 等模块的实际应用，适合需要集成加密功能的开发者参考。

### SM2_密钥示例_b8e30205.md SM2_密钥示例_b8e30205.md
本文档旨在演示如何在仓颉编程语言中生成SM2公私钥，并进行加密解密、签名验证及密钥的导入导出操作。主要涵盖SM2密钥对的生成、PEM格式文件的读写、公钥加密与私钥解密、以及私钥签名与公钥验证的完整流程。示例代码详细展示了利用`stdx.crypto.keys`等库实现密钥的持久化存储与恢复，验证了加密解密和签名验签功能的正确性。适用于需要在仓颉开发环境中集成国密SM2算法进行数据安全处理的开发者。
