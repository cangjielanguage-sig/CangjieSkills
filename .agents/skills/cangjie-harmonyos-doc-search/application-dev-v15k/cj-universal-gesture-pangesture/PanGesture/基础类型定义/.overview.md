# 基础类型定义

This directory contains fundamental type definitions for the ArkUI framework in the Cangjie language, specifically focusing on gesture recognition and interaction handling. It covers the core configuration options for pan gestures and the enumeration of possible drag directions. Key components include the `PanGestureOptions` class, which allows for the dynamic modification of gesture properties without triggering expensive UI refreshes, and the `PanDirection` enum, which provides a robust way to define movement constraints using cardinal and axis-based directions. These definitions are essential for developers building interactive user interfaces that require precise touch handling, efficient state management, and complex gesture logic. The content is suitable for application developers and UI engineers working on ArkUI applications.

## Detailed Description

This section provides in-depth information about the specific files contained within the "基础类型定义" directory, detailing the classes and enumerations available for gesture handling.

### class_PanGestureOptions.md
This API reference document outlines the PanGestureOptions class for the Cangjie language within the ArkUI framework. Its primary purpose is to enable dynamic modification of pan gesture recognizer properties without causing UI refreshes associated with state variables. The documentation details the class constructor, which accepts parameters for finger count, direction, and distance, alongside setter methods like setDirection and setFingers. Key information includes specific value constraints, such as the finger range of 1 to 10 and default distance handling. This guide targets developers building interactive UIs who require efficient gesture control.

### enum_PanDirection.md
This API reference document defines the PanDirection enum in the Cangjie language, used to specify drag gesture directions for the ArkUI framework. The documentation enumerates specific values for cardinal directions (Left, Right, Up, Down), axis-based movements (Horizontal, Vertical), and general states (None, All). It also details the Computed variant and overloaded bitwise operators (& and |) for combining direction logic. Key takeaways include the support for logical operations to define complex gesture constraints. Intended for application developers, this reference assists in implementing precise touch interaction handling in ArkUI applications starting from version 19.
