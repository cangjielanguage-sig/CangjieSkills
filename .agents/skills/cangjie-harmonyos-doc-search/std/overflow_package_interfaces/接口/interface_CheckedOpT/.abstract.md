This directory contains API reference documentation for the Cangjie programming language's `CheckedOp` interface and its implementations across various integer types. It focuses on safe arithmetic operations that explicitly handle integer overflow and invalid inputs by returning an `Option` type instead of throwing exceptions. The documentation covers generic interface definitions as well as specific extensions for signed and unsigned integers (Int8, Int16, Int32, Int64, IntNative, and their unsigned counterparts). This resource is suitable for Cangjie developers and system architects who require robust error handling and predictable behavior in numerical computations to ensure application stability and data integrity.
