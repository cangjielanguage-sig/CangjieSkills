This directory contains API reference documentation for synchronization interfaces in the Cangjie programming language. It covers essential concurrency control mechanisms, including mutex implementations, reentrant locks, and condition variables. Key topics include the deprecated `IReentrantMutex` interface, its replacement `Lock`, the extended `UniqueLock` interface, and thread synchronization via shared variables. This documentation is suitable for software engineers and developers building concurrent applications who need precise control over thread safety, locking mechanisms, and condition-based execution flows.
