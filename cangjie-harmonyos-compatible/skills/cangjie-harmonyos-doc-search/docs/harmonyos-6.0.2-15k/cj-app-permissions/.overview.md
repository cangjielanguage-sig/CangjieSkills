# cj-app-permissions

This directory contains documentation regarding application permissions and authorization requirements. It serves as a central index for developers to identify and apply for the correct permissions based on their app's scope. The content covers four main categories of permissions: open permissions with system authorization, open permissions requiring user authorization, permissions for enterprise apps, and exclusive permissions for MDM applications. It details grant mechanisms such as automatic installation grants or runtime pop-ups. This resource is suitable for application developers who need to determine the correct permission application process for their specific app type, particularly those working with enterprise or MDM distribution channels.

### cj-app-permissions.md cj-app-permissions.md
This document serves as a central index for developers to identify and apply for application permissions based on their specific scope and authorization requirements. It categorizes permissions into four distinct types: open permissions with system authorization, open permissions requiring user authorization, permissions for enterprise apps, and exclusive permissions for MDM applications. The guide clarifies that while open permissions are available to all apps, enterprise and MDM permissions are restricted to specific distribution types like enterprise_normal or enterprise_mdm, with varying grant mechanisms such as automatic installation grants or runtime pop-ups. This reference documentation targets application developers who need to determine the correct permission application process for their specific app type.
