This directory contains technical specifications and implementation guides for symmetric key encryption algorithms. It covers standards such as AES, 3DES, and SM4, detailing their supported encryption modes (e.g., ECB, CBC, GCM), padding schemes, and parameter syntax for API integration. The documents are designed for developers using the CryptoArchitectureKit (API version 12+), providing the necessary string parameter formats and configuration rules to correctly instantiate and utilize cryptographic functions. Key topics include block cipher configurations, key length handling, and specific mode behaviors.
