This directory contains comprehensive documentation for the ActionSheet component, a list selection popup within the ArkUI framework designed for the Cangjie language. It covers the core component implementation, configuration classes for buttons and selection items, and utilities for managing dialog dismissal and positioning. Key topics include UI customization, event handling, layout options, and API references starting from version 22. This documentation is suitable for software developers and UI engineers building interactive modal dialogs and bottom sheets in ArkUI applications who need to implement custom user interactions and selection interfaces.
