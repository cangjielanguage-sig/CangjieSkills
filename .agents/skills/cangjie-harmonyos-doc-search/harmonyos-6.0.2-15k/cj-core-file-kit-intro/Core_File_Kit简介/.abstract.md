This directory provides a comprehensive introduction to Core File Kit, a specialized service designed to enable developers to access and manage application and user files efficiently within the HarmonyOS ecosystem. It covers essential topics such as file classification models, sandbox isolation for security, and mechanisms for inter-app file sharing using URIs or FDs. Additionally, it details the underlying architecture of the Application and User File Access Frameworks, including components like FilePicker and FileManager. This documentation is suitable for developers seeking to implement robust file management, backup, restore, and cross-device access features while ensuring data consistency and portability.
