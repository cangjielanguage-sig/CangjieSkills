This directory serves as a comprehensive resource for the HarmonyOS HiAppEvent module, specifically tailored for the Cangjie programming language. It provides detailed API reference documentation designed to facilitate application event tracking, reporting, and observation. The content covers essential aspects such as event definitions, data types, configuration options, and subscription mechanisms. By utilizing these resources, developers can effectively monitor system faults, gather usage statistics, enhance security measures, and analyze user behavior. This documentation is primarily intended for Cangjie developers who are integrating performance analysis, debugging tools, and custom logging features into their applications within the HiviewDFX subsystem.
