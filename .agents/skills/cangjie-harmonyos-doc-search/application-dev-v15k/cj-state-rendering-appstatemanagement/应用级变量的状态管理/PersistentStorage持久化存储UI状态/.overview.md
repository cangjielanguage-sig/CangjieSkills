### PersistentStorage持久化存储UI状态_2more.md PersistentStorage持久化存储UI状态_2more.md
This technical guide explains the PersistentStorage singleton object for persisting UI state across application restarts. It covers the relationship between PersistentStorage and AppStorage, usage instructions, and specific constraints. Key takeaways include that developers must access data via AppStorage, not PersistentStorage directly, with supported types limited to Int64, Float64, String, and Bool. Crucially, it is a synchronous operation best suited for data under 2kb to avoid blocking the UI thread; large datasets require database APIs. Initialization must occur after the UI instance is ready. This guide targets application developers managing state persistence.
