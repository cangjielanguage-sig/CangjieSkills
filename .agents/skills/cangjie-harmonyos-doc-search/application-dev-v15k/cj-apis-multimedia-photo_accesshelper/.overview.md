# cj-apis-multimedia-photo_accesshelper

This directory contains the complete API reference documentation for the HarmonyOS PhotoAccessHelper system capability, specifically developed for the Cangjie programming language. It is designed to assist developers in utilizing the MediaLibraryKit framework to its fullest potential. The documentation covers a wide array of functionalities, including the management of photo albums, media assets, and user selection interfaces. Key topics include accessing and modifying photo metadata, handling change notifications, configuring media selection options, and managing file creation and retrieval processes. This resource is highly suitable for developers focused on building file management or gallery applications within the HarmonyOS ecosystem who need to interact with system photo libraries, manage complex permissions, and implement robust media processing features in their applications.
