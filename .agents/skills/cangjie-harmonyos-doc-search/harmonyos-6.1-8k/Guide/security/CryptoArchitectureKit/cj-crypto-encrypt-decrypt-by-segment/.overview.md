# cj-crypto-encrypt-decrypt-by-segment

本文档旨在为开发者提供关于大数据量分段加解密的详细技术指南，旨在解决处理海量数据时的效率瓶颈问题。内容全面涵盖了对称加解密与非对称加解密的实现机制，重点介绍了如何利用 `update` 接口进行对称加密的流式处理，以及针对 RSA 和 SM2 等非对称算法必须进行的严格数据拆分策略。文档深入探讨了自定义分段长度、密钥规格限制以及分段大小与加密模式无关等核心概念。该指南特别适合使用 CryptoArchitectureKit 框架的开发者，主要针对需要处理超过 2MB 大文件的场景，目前属于 Beta 阶段的技术参考文档。

## Detailed Description

### cj-crypto-encrypt-decrypt-by-segment.md

本文档是针对大数据量场景下的加解密效率优化指南，主要面向使用 CryptoArchitectureKit 的开发者。文档详细阐述了对称加解密与非对称加解密在分段处理上的本质区别：对称加密支持通过 `update` 接口进行多次调用，允许开发者自定义分段长度；而非对称加密（如 RSA 或 SM2）不支持 `update` 操作，必须严格遵循密钥规格对数据进行手动拆分。此外，文档明确指出分段大小与加密模式无关。该指南适用于处理超过 2M 数据的场景，目前处于 Beta 阶段，为开发者提供了处理大文件加密的实用技术路径。
