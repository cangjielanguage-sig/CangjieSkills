This directory provides comprehensive documentation for the `Rune` data type within the Cangjie programming language, focusing on Unicode character representation and manipulation. It covers the fundamental definition of the Rune type as a Unicode scalar value, its specific valid hexadecimal ranges, and the implementation of essential standard interfaces such as Comparable, Countable, Hashable, and ToString. Furthermore, it includes extensive API references for low-level UTF-8 encoding, decoding operations, and ASCII character classification utilities. This resource is suitable for Cangjie developers working on text processing, internationalization, and low-level data parsing who require robust tools for character data handling.
