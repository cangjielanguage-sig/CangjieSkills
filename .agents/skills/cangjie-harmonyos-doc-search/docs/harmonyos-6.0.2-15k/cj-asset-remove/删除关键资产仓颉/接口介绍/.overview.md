# 接口介绍

This directory provides essential technical documentation for the AssetStoreKit API, specifically targeting the management and configuration of critical assets within a secure environment. It covers the complete lifecycle of asset handling, including detailed interfaces for deleting key assets and defining complex attribute structures. The content explores critical parameters such as `AssetParam`, access control settings, persistence options, and data labeling strategies, while emphasizing security constraints like the prohibition of personal data in unencrypted `DATA_LABEL` fields. Furthermore, it documents API 12 updates, including increased data length limits. This resource is indispensable for developers and software engineers tasked with integrating robust asset management features, providing the necessary guidelines to ensure data integrity, security compliance, and proper synchronization control in their applications.

## Detailed Description

The following documents provide in-depth technical specifications and reference guides for the API interfaces mentioned above.

### 接口介绍_1.md 接口介绍_1.md
This document serves as a technical reference guide for the API interface used to delete key assets. It primarily details the `remove` function, specifically focusing on the `AssetParam` parameters required for the deletion process. A key section highlights a critical security warning regarding `DATA_LABEL` attributes, noting that these fields store custom business information without encryption and must not contain personal data. The content is intended for developers integrating asset management features, providing essential parameter definitions and data handling guidelines to ensure secure implementation.

### 接口介绍_2.md 接口介绍_2.md
This document serves as a reference guide defining the attribute structure and configuration options for critical assets within the AssetStoreKit API. It details specific data fields including access control settings like accessibility and authentication types, persistence options, and various data labels for storing custom information with or without integrity protection. Key takeaways include the distinction between critical and normal data labels, the expansion of data length limits to 2048 bytes since API 12, and options for local-only storage that prevents synchronization. Targeted at developers implementing secure asset management, this reference requires understanding of data types like UInt32 and Array<UInt8> and focuses on security and synchronization configurations.
