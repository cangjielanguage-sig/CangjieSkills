# cj-thread-model-stage

This directory serves as a definitive guide for understanding the threading architecture within the Cangjie development framework, specifically focusing on the Stage model. It provides an in-depth analysis of how concurrency is managed, distinguishing between the Main Thread—responsible for critical UI operations such as rendering, event dispatching, and lifecycle management—and Cangjie Threads, which handle background processing tasks. The documentation details the EventHub mechanism, which facilitates seamless intra-thread communication between UIAbility and UI components. Furthermore, it offers practical debugging tools, including shell commands, to help developers monitor thread behavior. This resource is essential for Cangjie developers who need to ensure application responsiveness, optimize component interactions, and gain a robust understanding of the framework's execution model. By mastering these concepts, developers can build more efficient and stable applications.

### cj-thread-model-stage.md

This file acts as the comprehensive technical guide for the directory, outlining the threading model for the Stage model in Cangjie development. It covers thread definitions, types (Main Thread vs. Cangjie Thread), and intra-thread communication using EventHub. Key information includes that the Main Thread handles UI rendering, event dispatching, and lifecycle management, while Cangjie threads handle other tasks. It highlights that UIAbility and UI components run on the main thread and communicate via EventHub. It also provides a shell command for debugging thread information. This guide targets developers needing to understand application concurrency and component interaction in the Cangjie framework. By reading this document, developers will gain the necessary knowledge to effectively manage threads and ensure smooth application performance.
