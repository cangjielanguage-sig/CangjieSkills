# mock_framework_getting_started

This directory provides a comprehensive tutorial focused on the mock framework within the Cangjie standard library's unit testing module. It is specifically designed to help developers isolate dependencies during the testing process, ensuring that code logic is verified independently of external systems. The guide covers all necessary setup requirements, detailing the required imports and the correct usage of build tools like cjpm or cjc. Additionally, it offers a practical, step-by-step example that illustrates the entire mock workflow. Key learning points include the creation of mock objects using the mock constructor, the configuration of specific behaviors via the @On macro to return values or throw exceptions, and the integration of these mocks into test cases. This resource is ideal for Cangjie developers aiming to write robust unit tests for components with complex or external dependencies.
