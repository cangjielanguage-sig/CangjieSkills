This directory contains API reference documentation for core input/output (IO) classes within the Cangjie standard library. It covers a range of utility classes designed for handling data streams, including sequential reading, multi-stream writing, and in-memory byte manipulation. Key topics include buffered input and output streams for performance enhancement, byte buffers for data management, and specialized readers and writers for string and text processing. This documentation is suitable for Cangjie developers seeking to implement efficient, safe, and high-performance I/O operations in their applications.
