This directory serves as a comprehensive reference for the common attributes and base configurations of security controls within the Cangjie ArkUI framework. It covers fundamental type definitions, shared property specifications, and detailed component styling options such as layout direction, borders, typography, and dimensions. Designed for application developers and UI engineers, these documents facilitate the consistent implementation and customization of secure user interfaces, ensuring visual integrity and standardized behavior across security components starting from API version 20. It provides the essential building blocks for creating robust and visually compliant security features, leveraging system capabilities like SystemCapability.ArkUI.ArkUI.Full for full integration.
