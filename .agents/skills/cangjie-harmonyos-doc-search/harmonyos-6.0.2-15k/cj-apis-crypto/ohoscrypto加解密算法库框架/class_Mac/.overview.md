# class_Mac

This directory contains comprehensive API reference documentation for the Mac class within the Cangjie programming language's CryptoArchitectureKit. It focuses on Message Authentication Code (MAC) encryption calculations, covering the complete lifecycle of cryptographic operations including initialization, data updates, and finalization. Key topics include the `algName` property, `init`, `doFinal`, `getMacLength`, and `update` methods, alongside robust error handling and system capabilities. This documentation is intended for Cangjie developers implementing cryptographic security features who require a technical understanding of the CryptoFramework, data integrity mechanisms, and exception management.

### class_Mac_5more.md class_Mac_5more.md
This document provides API reference documentation for the Mac class in the Cangjie programming language, designed to perform Message Authentication Code (MAC) encryption calculations. The content covers the read-only property algName and essential methods: init for initializing calculations with a SymKey, doFinal for retrieving the DataBlob result, and getMacLength for obtaining the byte length. Key information includes the requirement to construct instances via createMac and specific error codes for handling exceptions like invalid parameters or crypto operation errors. Intended for developers utilizing the SystemCapability.Security.CryptoFramework, this documentation assumes familiarity with cryptographic concepts and Cangjie syntax.
