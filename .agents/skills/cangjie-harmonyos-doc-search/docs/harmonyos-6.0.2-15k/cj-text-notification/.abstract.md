This directory contains a specialized development guide designed for software engineers utilizing the Cangjie programming language to build applications with robust notification capabilities. The core focus is on the NotificationKit framework, providing a deep dive into the mechanics of publishing text-based notifications. It thoroughly explains the categorization of notification content, specifically the technical differences and implementation details for basic text versus multiline text notifications. The guide outlines the `publish` interface, offering a clear roadmap for importing required modules and accurately constructing `NotificationRequest` objects. Critical technical constraints, such as the 200-byte size limit for text fields and mandatory field requirements, are highlighted to ensure compliance. Furthermore, it details the structural requirements for multiline content that supports expanded views. This resource is essential for application developers aiming to enhance user engagement through short messages or prompt notifications, ensuring they adhere to best practices within the Cangjie ecosystem.
