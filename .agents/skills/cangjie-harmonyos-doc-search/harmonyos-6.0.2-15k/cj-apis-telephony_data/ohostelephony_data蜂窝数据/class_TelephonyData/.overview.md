# class_TelephonyData

This directory provides comprehensive API reference documentation for the Cangjie TelephonyData class, specifically designed to query cellular network status and manage SIM card configurations. It covers a range of functionalities including retrieving data flow directions, connection states, identifying default SIM cards via ID or physical slot, and checking roaming status. Key topics include cellular data management, system permissions like `ohos.permission.GET_NETWORK_INFO`, and error handling for business exceptions. This documentation is intended for Cangjie developers working within the Telephony subsystem who need to access mobile data functionalities and monitor network settings in their applications.
