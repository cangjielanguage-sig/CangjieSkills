# Slider

This directory contains comprehensive documentation for the Slider component within the Cangjie ArkUI framework. It covers the implementation of interactive controls used for adjusting values such as volume or brightness. The content includes API references for initialization, enumeration definitions, event handling, property configuration, and practical code examples. Key topics include horizontal and vertical orientations, block styling, track customization, and interaction modes. This resource is suitable for developers and UI designers working with HarmonyOS applications who need to integrate functional and visually refined slider controls using the Cangjie programming language.

### Slider_4more.md Slider_4more.md

Additionally, it lists supported common attributes and events. Key information includes support for horizontal and vertical orientations and specific handling for invalid input ranges. This technical reference targets developers using the ArkUI framework who need to implement interactive slider controls in their applications.

### 基础类型定义.md 基础类型定义.md
This API reference document defines enumeration types for the Slider component within the ArkUI framework, specifically for the Cangjie programming language. The document details four primary enumerations: SliderBlockType, SliderInteraction, SliderStyle, and SliderChangeMode. Key information includes definitions for slider block shapes (default, image, custom), interaction modes (slide only, click enabled), visual styles (inset, outset), and event state values (begin, moving, end). Each enum value is accompanied by system capability requirements and version availability. This reference is intended for developers seeking to configure slider behavior and appearance in their user interfaces.

### 组件事件.md 组件事件.md
This document provides API reference documentation for the Slider component's onChange event handling within the Cangjie programming language and ArkUI framework. It details two overloaded function signatures: one accepting a callback with Float64 value and SliderChangeMode parameters, and another with a void callback. Key takeaways include the specific trigger conditions for event states such as Begin, End, Moving, and Click, with the clarification that dragging actions do not trigger the Click state. This technical reference is intended for developers implementing interactive slider behaviors in version 12 or later of the system.
