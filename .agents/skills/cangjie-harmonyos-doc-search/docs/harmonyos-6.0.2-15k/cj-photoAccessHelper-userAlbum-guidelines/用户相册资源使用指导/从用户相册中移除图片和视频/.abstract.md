This directory serves as a comprehensive technical resource for HarmonyOS developers working with the Cangjie language, specifically targeting the management of user media libraries. It provides an in-depth guide on how to programmatically remove images and videos from designated user albums, detailing the necessary permissions, API usage, and implementation steps involving MediaLibraryKit and PhotoAccessHelper. Beyond the core logic for media deletion, the directory also includes essential boilerplate code for application initialization. This covers the setup of the main ability, handling of lifecycle methods such as onCreate and onWindowStageCreate, and configuration of the UI context. This collection is ideal for developers building media-heavy applications who require precise control over user content and need a solid understanding of HarmonyOS application structure and media APIs.
