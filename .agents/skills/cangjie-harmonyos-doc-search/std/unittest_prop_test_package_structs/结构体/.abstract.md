This directory contains API documentation for various Cangjie language structs used primarily in unit testing and property-based testing frameworks. It covers wrappers for zero-argument functions (`Function0Wrapper`) and generic tuple wrappers ranging from two to five elements (`TupleWrapper2` through `TupleWrapper5`). Key features include encapsulation of data structures, implementation of standard interfaces like `ToString` and `Equatable`, and specialized extensions for random generation (`Arbitrary`) and value reduction (`Shrink`). This documentation is suitable for Cangjie developers, QA engineers, and anyone implementing automated testing utilities or complex data manipulation logic.
