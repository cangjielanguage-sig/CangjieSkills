This directory provides a specialized technical overview of HUKS (OpenHarmony Universal KeyStore) key attestation, a critical security component for OpenHarmony systems. It focuses on the mechanisms required to prove the legitimacy of asymmetric public keys by utilizing PKI certificate chains. The documentation covers the complete attestation workflow, offering a clear distinction between anonymous and non-anonymous attestation methods, which allows developers to balance privacy with accountability. It enumerates the supported cryptographic algorithms, including RSA, ECC, and SM2, ensuring compatibility with devices running API level 15 and above. Additionally, the guide highlights specific technical details such as the inclusion of key owner information within digital certificates and the identification of OID values for key origin verification. This resource is specifically tailored for OpenHarmony developers who need to implement robust, hardware-backed key validation to secure their applications against unauthorized access and ensure the integrity of hardware-based cryptographic operations.
