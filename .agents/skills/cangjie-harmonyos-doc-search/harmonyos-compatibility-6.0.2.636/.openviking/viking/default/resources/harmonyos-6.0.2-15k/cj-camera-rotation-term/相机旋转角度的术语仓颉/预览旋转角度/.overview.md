# 预览旋转角度

This directory provides technical documentation focused on the logic and mathematics behind calculating image rotation angles during camera preview on mobile platforms. It addresses the complexities of aligning the camera sensor output with the device's current display orientation. Key concepts include the relationship between lens installation angles, screen rotation compensation, and the specific behaviors of front versus rear cameras. The documentation details how to handle mirroring effects for front-facing lenses and interprets data from the `Display.rotation` API. It also breaks down eight specific scenarios involving different device orientations and charging port positions. This resource is designed for mobile application developers and system engineers building camera features who need a deep understanding of orientation transformation algorithms to ensure a correct user experience.

## Detailed Description

### 预览旋转角度_1.md
This technical reference document explains the underlying mechanism for calculating image rotation angles during camera preview. It details the relationship between the original image direction, camera lens angles, and screen display compensation. The key takeaway is the calculation formula: Image Rotation Angle equals the Lens Installation Angle plus the Screen Display Compensation Angle, with the latter being equal to the screen rotation angle. The document uses a mobile device example to illustrate this process. While intended for developers to understand the framework's logic, it explicitly recommends using a specific API interface for practical implementation.

### 预览旋转角度_2.md
This technical reference guide explains how to calculate the correct image preview rotation angle for mobile devices based on device orientation and camera type. Main sections cover eight distinct scenarios involving rear and front cameras across different device orientations, such as portrait and landscape modes with varying charging port directions. Key information includes the calculation formula where the preview rotation angle is the sum of the camera lens angle (90 degrees for rear, 270 degrees for front) and the screen rotation angle derived from the Display.rotation API, noting that front cameras produce mirrored images. The intended audience is mobile application developers implementing camera preview features who need to programmatically handle orientation transformations.
