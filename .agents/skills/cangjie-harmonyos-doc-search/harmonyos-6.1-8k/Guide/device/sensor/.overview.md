# sensor

This directory provides comprehensive documentation and resources for sensor development, primarily focusing on the HarmonyOS ecosystem and the Cangjie programming language. It covers the Sensor Service Kit, detailing sensor data acquisition, vibration control, and hardware integration protocols. The content spans from high-level architectural overviews and specific development guidelines to practical introductions for application developers. It is designed for engineers integrating sensor functionalities, those working on low-level hardware interactions, and developers utilizing Cangjie for system-level programming.

## Detailed Description

### README_zh
This directory serves as the main entry point for the Chinese documentation of the Sensor Service Kit. It aims to provide developers with comprehensive navigation and development support. Currently in the Beta stage, the documentation covers the complete process from basic concepts to specific practices. Core content includes an introduction to the Sensor Service Kit, an overview of sensor development, and detailed development guidance. Through a clear hierarchical structure, the documentation organizes the kit introduction with specific sensor development concepts and operational instructions, helping developers quickly master the overall architecture. This resource is particularly suitable for engineers who need to integrate sensor functions or perform underlying sensor development, serving as a core index for consulting detailed technical documents and following development standards.

### cj-sensor-guidelines
This directory serves as a specialized technical repository for developers focusing on sensor integration within the HarmonyOS operating system environment, with a specific emphasis on the Cangjie (仓颉) programming language. It provides a structured approach to development, offering guidelines and best practices for utilizing sensors effectively in this specific language context.

### cj-sensor-overview
This directory serves as a comprehensive guide to sensor development, offering a deep dive into the fundamental principles, operational mechanisms, and standard development protocols required for working with sensor hardware. It covers a wide array of sensors, providing the necessary theoretical background and operational standards for developers to understand how sensors function within the system.

### cj-sensorservice-kit-intro
This directory contains the development guide introduction for the Sensor Service Kit, aiming to provide application developers with comprehensive guidance on sensor data acquisition and vibration control. The document details the usage scenarios, functional features, and constraints of the two core modules: Sensor and Vibrator. Content covers how to develop various applications through sensor data subscription and how to use the vibration module to enhance user interaction experience. Additionally, it highlights relevant hardware dependencies, permission configuration requirements, and specifications for paired sensor interface calls. This document is suitable for all development scenarios requiring hardware sensor or vibration function integration and is essential reading for getting started with the Sensor Service Kit.
