This directory contains API reference documentation for event handling within the RichEditor component of the ArkUI framework, specifically using the Cangjie language. It covers a comprehensive range of functionalities including input method interception, text selection tracking, clipboard operations (copy, cut, paste), and lifecycle management. Key topics include `aboutToIMEInput`, `onSelect`, `onSubmit`, and various callback mechanisms for granular text control. This documentation is suitable for developers building rich text editing applications who need to implement custom logic for user interactions, input validation, and state monitoring.
