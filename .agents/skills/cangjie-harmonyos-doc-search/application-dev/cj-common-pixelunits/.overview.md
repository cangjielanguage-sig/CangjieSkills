# cj-common-pixelunits

This directory provides essential reference documentation for the Cangjie ArkUI framework, specifically focusing on the pixel units used for UI layout and design. It offers a deep dive into the four distinct units available: px, vp, fp, and lpx. The content is designed to help developers understand the nuances of density-independent design, highlighting vp as the standard unit, fp for font scalability, and lpx for viewport-relative dimensions. Beyond definitions, the directory includes API conversion methods via UIContext, detailing functions like vp2px and px2vp, and provides practical code examples to illustrate implementation. This resource is highly suitable for Cangjie developers who are building cross-device interfaces and need to master responsive sizing, unit conversion, and adaptive layout strategies to ensure consistent UI across different screen densities.
