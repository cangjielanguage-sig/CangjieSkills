# 气泡提示Popup

This directory provides a comprehensive guide to implementing and enhancing popup hints within the Cangjie ArkUI framework. It covers the fundamental implementation of popups using the Popup attribute, distinguishing between system-provided options and custom configurations. Key topics include managing modal behaviors, handling state changes, and adding interactive elements like buttons. Furthermore, it delves into advanced customization, such as creating custom layouts with @Builder decorators and applying dynamic entry and exit animations using TransitionEffect. This resource is suitable for Cangjie and HarmonyOS developers seeking to build interactive UI overlays, information alerts, and polished user experiences.

## Detailed Description

### 气泡提示Popup_4more.md 气泡提示Popup_4more.md
This document serves as a technical tutorial for implementing popup hints using the Popup attribute within the Cangjie ArkUI framework. It covers the distinction between system-provided PopupOptions and developer-defined CustomPopupOptions, explaining how to configure modal and non-modal behaviors using the mask property. The main sections detail creating text-only popups, handling state change events via onStateChange, and adding interactive buttons using primaryButton and secondaryButton properties. Key takeaways include the syntax for binding popups to components and managing their visibility state through boolean variables. This guide targets Cangjie developers seeking to implement interactive UI overlays for screen recording or information alerts.

### 气泡的动画.md 气泡的动画.md
This document serves as a code tutorial demonstrating how to configure entry and exit animations for popup components using the Cangjie language. The content focuses on utilizing the transition property within PopupOptions and CustomPopupOptions to control visual effects. Key takeaways include using TransitionEffect.asymmetric to combine opacity and translation for entry animations while keeping the exit static, and applying TransitionEffect.scale for uniform scaling effects. The example illustrates how to bind these animations to buttons and manage state changes. This guide is intended for UI developers working with the Cangjie framework who wish to enhance user experience through dynamic popup transitions. Keywords: Cangjie, Popup, Animation, TransitionEffect, UI, HarmonyOS.

### 自定义气泡_2more.md 自定义气泡_2more.md
This document serves as a tutorial for creating and styling custom popups in Cangjie-based HarmonyOS applications. It covers two main approaches: building custom content using CustomPopupOptions with @Builder decorators, and configuring standard popup styles via PopupOptions. Key takeaways include the ability to customize popup layout, background color, placement, mask overlay, and blur effects. The guide provides practical code examples demonstrating how to bind popups to components and manage state changes. It is intended for developers looking to implement interactive UI elements and improve user experience through flexible popup configurations.
