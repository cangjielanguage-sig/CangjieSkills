This directory serves as a comprehensive technical guide for developers utilizing the Cangjie programming language within the HarmonyOS ecosystem to implement application freeze event subscriptions. It acts as a central resource for understanding how to effectively monitor system-level performance issues, specifically focusing on the HiAppEvent framework. The content covers essential API interfaces for managing event watchers, including the critical functions of adding and removing observers. Furthermore, it outlines a complete development workflow that spans project initialization, event configuration, and log analysis. This documentation is vital for diagnosing complex issues such as Application Not Responding (ANR) errors and main thread blocking. It is specifically designed for software engineers and QA professionals dedicated to maintaining high application stability and performance standards through advanced event tracking and in-depth root cause analysis.
