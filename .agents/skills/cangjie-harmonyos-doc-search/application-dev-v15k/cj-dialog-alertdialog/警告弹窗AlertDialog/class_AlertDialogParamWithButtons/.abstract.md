This directory contains API reference documentation for the `AlertDialogParamWithButtons` class within the ArkUI framework, specifically designed for the Cangjie language. It covers the implementation of alert dialogs featuring two confirmation buttons, enabling developers to create modal interfaces with flexible user interactions. Key topics include class structure, inheritance, button configuration (primary and secondary), and customization options like alignment, background blur, and transitions. This documentation is intended for ArkUI developers and UI engineers looking to implement interactive dialog components with specific styling and event handling capabilities, starting from API version 12.
