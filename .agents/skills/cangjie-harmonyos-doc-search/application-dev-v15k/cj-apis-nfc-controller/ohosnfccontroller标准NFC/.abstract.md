This directory contains API reference documentation for the `ohos.nfc.controller` module in the Cangjie programming language, specifically designed for managing NFC states within HarmonyOS applications. It comprehensively covers the management of NFC controller states, including checking status, retrieving state enums, and handling state change callbacks. Key components include the `NfcControllerCallbackType` enum, `NfcState` definitions, and functions for registering and unregistering event listeners. This documentation is suitable for Cangjie developers implementing NFC functionality who need to monitor and control NFC hardware states, manage event listeners, and handle state transitions effectively within their applications.
