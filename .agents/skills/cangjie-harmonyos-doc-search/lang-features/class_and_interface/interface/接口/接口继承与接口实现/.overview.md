# 接口继承与接口实现

本目录深入探讨了仓颉编程语言中接口的核心机制，涵盖了接口继承、实现规则及多态性应用。内容详细说明了类型如何实现接口、成员匹配规则、默认实现机制以及多重继承的处理方式。核心关键词包括接口继承、接口实现、重写和默认实现。该文档适合仓颉语言开发者阅读，旨在帮助开发者掌握接口设计模式，正确处理多接口冲突与继承关系，从而编写出灵活且可维护的代码。

## 详细描述

### 接口实现的要求.md
这份文档详细阐述了仓颉编程语言中类型实现接口的规则与机制。主要内容包括接口实现的三种途径、成员匹配规则、默认实现机制及多重继承冲突处理。核心要点指出，实现类型需满足函数签名和属性类型的一致性，但允许 class 返回类型使用子类型；接口成员可提供默认实现，但在多接口冲突时必须由类型自行实现；此外，struct、enum 和 class 实现接口时 override 修饰符是可选的。这是一份面向仓颉开发者的语言参考指南，旨在帮助开发者正确理解和应用接口特性。

### 接口继承与接口实现.md
本文档旨在阐述仓颉编程语言中接口继承与实现的机制。主要内容包括使用 `&` 符号实现多个接口、接口间的多重继承规则，以及子接口对父接口成员的重写规范。关键点指出接口不能继承类，且若父接口成员含默认实现，子接口必须提供新的默认实现，此时 `override` 或 `redef` 修饰符为可选。该文档适合仓颉语言开发者阅读，帮助其掌握多态性及接口设计模式。
