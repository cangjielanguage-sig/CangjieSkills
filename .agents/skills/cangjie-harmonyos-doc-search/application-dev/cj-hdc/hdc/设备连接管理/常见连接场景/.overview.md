# 常见连接场景

This directory serves as a comprehensive resource for establishing and managing connections between HarmonyOS devices and development environments using the HDC tool. It addresses various connectivity scenarios, ranging from direct physical connections via USB to local network configurations using TCP, as well as complex remote setups between separate computers. The documentation provides detailed instructions on command syntax, hardware prerequisites, network parameter configuration, and troubleshooting steps. Designed for software developers and system administrators, these guides facilitate efficient device debugging, interaction setup, and remote management across different network topologies.

## Detailed Description

### USB连接场景_2more.md USB连接场景_2more.md
This technical guide outlines the procedures for connecting devices to a PC using the HDC tool via USB and TCP protocols. It covers two main scenarios: USB connection, detailing hardware requirements like direct ports and official cables, and TCP connection, which requires a shared network and warns against production use due to instability. The document provides step-by-step instructions for environment verification and executing commands such as `hdc list targets` and `hdc tconn`. Key takeaways include troubleshooting connection issues and ensuring proper driver installation. Intended for developers and system administrators, this guide facilitates device debugging and interaction setup.

### 远程连接场景.md 远程连接场景.md
This technical guide explains how to establish a remote connection between an HDC client and server running on separate PCs. It covers the command syntax using the -s parameter to specify network listening parameters like IP address and port. The document details parameter definitions, potential return values, and a step-by-step process for configuring the server to start network forwarding and enabling the client to execute commands remotely. Key takeaways include the specific commands for server setup and client connection, noting that the -s parameter overrides environment variables. This guide is intended for developers or system administrators managing HarmonyOS devices across different network environments.
