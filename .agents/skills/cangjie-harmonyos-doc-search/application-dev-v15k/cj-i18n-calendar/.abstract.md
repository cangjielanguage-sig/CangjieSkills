This directory contains the essential documentation for the `cj-i18n-calendar` module, a critical component for developers working with the Cangjie programming language and the LocalizationKit framework. The primary focus of this directory is to provide a comprehensive development guide for the `Calendar` class, enabling the precise configuration of calendars and time zones to meet internationalization (i18n) standards. The content covers a wide array of usage scenarios, ranging from standard Gregorian date handling to complex requirements for Chinese Lunar, Buddhist, Hebrew, Islamic, and Persian calendars. It addresses the technical needs of setting dates, defining week parameters, and performing robust date calculations such as addition, comparison, and weekend checks. This resource is specifically tailored for software developers and engineers who are tasked with implementing localization features in their applications. It serves as a practical manual for ensuring that software can accurately handle diverse regional date and time formats, thereby enhancing the user experience for a global audience. By following the instructions provided, developers can effectively manage temporal data across different cultural contexts.
