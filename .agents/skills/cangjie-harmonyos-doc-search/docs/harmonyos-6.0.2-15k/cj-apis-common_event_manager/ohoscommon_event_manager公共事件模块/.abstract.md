This directory contains API reference documentation for the `ohos.common_event_manager` module in the Cangjie programming language, designed for HarmonyOS application development. It covers the mechanisms for publishing, subscribing to, and managing common events, which facilitate inter-process communication (IPC) and system event monitoring. Key components include data structures for event payloads, subscriber configuration, and management classes for event lifecycles. This module is essential for developers building event-driven applications that need to react to system state changes or broadcast custom messages within the BasicServicesKit framework.
