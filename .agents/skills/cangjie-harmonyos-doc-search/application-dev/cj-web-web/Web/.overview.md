# Web

This directory contains comprehensive documentation for the Web component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers essential aspects of embedding web content, including component initialization, event handling, property configuration, and basic type definitions. Key topics include WebviewController usage, lifecycle management, resource interception, and UI customization. This resource is suitable for HarmonyOS developers and UI engineers looking to integrate WebView functionality, manage web interactions, and control rendering behaviors in their applications using SystemCapability.Web.Webview.Core.

## Detailed Description

### Web_4more.md Web_4more.md
This document provides API reference documentation for the Web component within the ArkUI framework, designed for the Cangjie programming language. It details the module import process and the component creation mechanism, specifically focusing on the init constructor that accepts a resource string and a WebviewController. Key takeaways include constraints on dynamic source updates via state variables and the necessity of binding unique controllers to multiple Web components on a single page. The document targets developers seeking to embed web display capabilities into their applications, noting system capabilities and version requirements.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating how to implement and control a WebView component within an ArkUI application using the Cangjie programming language. The code covers the setup of an EntryView class, initialization of a WebviewController, and the creation of a user interface containing buttons and a Web component. Key takeaways include methods for reloading and loading URLs, handling page lifecycle events like onPageBegin and onPageEnd, and using Hilog for debugging. This example is intended for HarmonyOS developers familiar with Cangjie syntax and ArkUI declarative UI paradigms who need to integrate web content into their apps.

### 组件事件.md 组件事件.md
This document provides API reference documentation for handling Web component events in the Cangjie programming language. It focuses on three specific callback functions designed to monitor and control the webpage loading lifecycle: onLoadIntercept, onPageBegin, and onPageEnd. Key information includes function signatures, parameter types, and system capabilities, specifically highlighting how onLoadIntercept allows developers to block URL access. The document is intended for developers building webview applications who require granular control over resource loading and page state transitions.

### 基础类型定义/
This directory contains API reference documentation for fundamental Cangjie language classes used in Web component development. It covers essential data structures for managing HTTP headers, handling web resource requests, and tracking page loading events. Key topics include the `Header` class, `WebResourceRequest`, and various event classes like `OnPermissionRequestEvent` and `OnLoadInterceptEvent`. These definitions are crucial for developers building WebView applications who need to intercept network traffic, manage user permissions, and monitor resource loading states within the SystemCapability.Web.Webview.Core framework.

### 组件属性/
This directory provides comprehensive API reference documentation for configuring component properties within the Cangjie language framework, with a specific focus on the WebView component. It covers a broad spectrum of configuration options, ranging from display modes (such as dark mode) and resource access permissions (including files, geolocation, and DOM storage) to JavaScript interaction proxies and user interface behaviors like scrolling and zooming. These documents are essential resources for developers building HarmonyOS applications who require precise control over web content rendering, security settings, and user interaction gestures.

### 通用属性通用事件/
This directory provides comprehensive technical documentation for universal attributes and events within the ArkUI framework. It serves as a central reference for developers working on UI component configuration, covering essential aspects such as layout dimensions, visual styling, interaction states, and component lifecycle management. Key topics include properties for width, height, and background color, as well as event handlers for touch, mouse, and keyboard interactions. This resource is specifically designed for software developers and UI engineers seeking to implement robust styling and interactive behaviors in their applications.
