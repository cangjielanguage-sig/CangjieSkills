# AccessToken

This directory provides comprehensive documentation on HarmonyOS and OpenHarmony access control mechanisms, focusing on access tokens, permission management, and security isolation. It covers core concepts such as APL (Ability Privilege Level), sandbox isolation, and ACL (Access Control List) configuration. The content guides developers through declaring permissions, handling user authorization (including one-time authorization), and managing specific permission types for system, enterprise, and MDM applications. It is suitable for application developers and security engineers seeking to implement compliant and secure access control in their software.

## Detailed Description

### [1] README_zh
This directory contains core Chinese documentation for program access control features, providing developers with a comprehensive guide to permission management and implementation. It explores access token mechanisms, application permission control processes, and how to correctly declare and apply for user authorization, covering complex scenarios like single-time authorization and restricted permissions. It details specific permissions required for system, enterprise, and MDM applications, distinguishing between system and user authorization.

### [2] cj-access-token-overview
This directory provides a comprehensive overview of the system access control mechanism, focusing on core principles of security isolation and permission management. Content covers application sandboxes, application permissions, TokenID identification mechanisms, and permission hierarchical protection based on APL (Ability Privilege Level) levels. It aims to ensure legal access by applications to system data and functions.

### [3] cj-app-permission-group-list
This directory serves as a comprehensive reference guide for HarmonyOS application developers, focusing specifically on the management and configuration of application permission groups. It provides essential documentation regarding the complex landscape of permission groups.

### [4] cj-app-permission-mgmt-overview
This directory provides a comprehensive overview of application permission management mechanisms, focusing on the core principles and concepts necessary for secure development. It covers the essential framework for compliantly applying for and utilizing permissions.

### [5] cj-app-permissions
This directory collects core documentation on application permission management, providing a complete reference guide for permission application and authorization. It analyzes four core permission categories: open permissions (including system automatic authorization and user dynamic authorization), enterprise application permissions, and MDM application-specific permissions. It focuses on authorization mechanisms applicable to different distribution types.
