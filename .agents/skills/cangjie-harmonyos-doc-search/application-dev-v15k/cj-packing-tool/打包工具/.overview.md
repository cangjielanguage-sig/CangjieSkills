# 打包工具

This directory contains technical reference guides for the HarmonyOS application packing tool (`app_packing_tool.jar`). It covers command-line instructions for packaging various distribution formats, including HAP, HSP, App, and HQF files. Key topics include standard and fastApp packaging modes, multi-project merging, hotfix patching (HQF), and version normalization across modules. These documents are essential for HarmonyOS developers and build engineers who need to automate build processes, manage complex application lifecycles, or ensure consistency across multiple HAP and HSP components.

## Detailed Description

### HSP打包指令_2more.md HSP打包指令_2more.md
This technical reference guide details the command-line usage of the app_packing_tool.jar for generating HSP and App packages in HarmonyOS development. It covers two primary modes: HSP packing, which enables file sharing between HAPs, and App packing, which aggregates HAPs and HSPs for market distribution. Key sections include parameter definitions for input/output paths, validation rules ensuring HAP consistency, and compression logic for release versus debug builds. The document provides specific syntax examples and mandatory versus optional arguments. It targets developers needing to automate or manually package application components using the Java-based tool.

### fastApp模式打包指令.md fastApp模式打包指令.md
This document serves as a technical reference guide for developers on how to use the app_packing_tool.jar to package HAP and HSP files into an App package suitable for market distribution using the fastApp mode. It covers the packaging command syntax, HAP legality validation rules regarding configuration consistency, compression rules for release versus debug modes, and a detailed parameter table defining mandatory and optional flags like input paths, output location, and signature details. Key takeaways include the strict requirement for matching bundle names and version codes across HAP modules, the unique module name constraint, and the specific handling of file paths for HAPs and HSPs within the command line interface. Intended for HarmonyOS developers or build engineers, this reference document assumes familiarity with command-line tools and application packaging concepts.

### 多工程打包指令_3more.md 多工程打包指令_3more.md
This technical reference guide provides command-line instructions for packaging HarmonyOS applications using the app_packing_tool.jar. It covers three distinct packaging modes: multi-project packaging for merging HAP, HSP, and App packages from separate development teams; HQF packaging for generating emergency fix patches; and APPQF packaging for bundling multiple HQF files for market distribution. Key takeaways include specific command syntaxes, required parameters like --mode and --out-path, and strict validation rules for multi-project builds, such as matching bundle names and API versions. The document targets developers and build engineers managing complex application lifecycles or urgent hotfix deployments.

### 版本归一指令versionNormalize_2more.md 版本归一指令versionNormalize_2more.md
This technical reference guide documents command-line instructions for normalizing versions and package names within HarmonyOS application packages using the app_packing_tool.jar. It details two primary modes: versionNormalize for synchronizing version codes and names across multiple HAP and HSP files, and packageNormalize for modifying bundle names and versions specifically for HSP files. Key information includes syntax examples and comprehensive parameter tables defining required inputs like file paths, version numbers, and output directories. The versionNormalize command notably generates a JSON record of original versions. Intended for developers or build engineers managing app packaging, this guide requires knowledge of HAP and HSP file structures and command-line interfaces.
