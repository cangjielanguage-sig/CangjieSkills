This directory provides comprehensive documentation on the `@BuilderParam` macro within the ArkUI framework and the Cangjie language environment. It details the mechanism for dynamically injecting specific UI descriptions or behaviors into custom component instances, effectively functioning as slot placeholders. The content covers essential concepts such as initialization via global or local `@Builder` functions, strict type consistency requirements, and specific usage limitations. Additionally, it addresses common compilation errors related to state management. This resource is designed for developers familiar with `@Builder` decorators who aim to achieve flexible component customization and dynamic UI composition in their ArkUI applications.
