# bigInt_basic_arithmetic

This directory serves as a dedicated educational resource for the Cangjie programming language, specifically focusing on the `BigInt` class. It provides a practical tutorial that demonstrates how to execute basic arithmetic operations on arbitrary-precision integers, a critical requirement for high-accuracy computing tasks where standard integer types are insufficient. The guide covers the complete workflow from initialization via string parsing to executing standard mathematical functions such as addition, subtraction, multiplication, and division. Additionally, it introduces the combined division and modulus functionality. Key learning points include mastering the syntax for BigInt instantiation and utilizing the `divAndMod` method to efficiently obtain both quotient and remainder in a single operation. This material is ideal for Cangjie developers who need robust examples of handling large integers using the standard library.
