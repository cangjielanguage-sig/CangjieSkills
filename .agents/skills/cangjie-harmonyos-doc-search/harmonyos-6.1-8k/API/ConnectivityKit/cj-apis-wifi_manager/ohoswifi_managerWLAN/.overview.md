# ohoswifi_managerWLAN

本目录包含HarmonyOS仓颉语言（Cangjie）的WLAN管理模块API参考文档。文档涵盖了WLAN站点（STA）功能、Wi-Fi点对点（P2P）连接、设备发现及事件回调等核心功能。主要内容包括扫描结果数据结构、P2P配置类、设备地址与安全类型枚举，以及网络状态管理函数。该文档适用于在HarmonyOS平台上进行网络连接开发的工程师，提供了实现Wi-Fi互通、热点扫描及P2P通信所需的完整接口规范。
