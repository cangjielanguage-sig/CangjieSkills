This directory contains API reference documentation for the `MediaAssetChangeRequest` class in the Cangjie language, part of the HarmonyOS MediaLibraryKit. It covers the management of media assets, including creating, modifying, and deleting photos and videos within the PhotoAccessHelper framework. Key topics include asset creation from sandbox files, resource appending, metadata editing, and handling camera photos. The documentation details system capabilities, required permissions, and error handling. It is suitable for application developers working on file management and media access features in HarmonyOS applications.
