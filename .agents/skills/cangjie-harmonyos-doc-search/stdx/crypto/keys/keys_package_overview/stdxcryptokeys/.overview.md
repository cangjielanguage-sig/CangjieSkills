# stdxcryptokeys

stdxcryptokeys 是一个专注于加密密钥管理的开发包，主要涵盖非对称加密算法（ECDSA、RSA、SM2）的私钥与公钥实现。该包深度依赖 OpenSSL 3.x.x 版本，提供了丰富的 API 用于配置加密参数、填充模式及签名方案。文档内容包含 API 参考列表及环境配置指南，旨在帮助开发人员快速集成加密功能并解决依赖库的安装问题。适合需要实现数据加密、数字签名及密钥管理的后端开发人员使用。

### API_列表_08063595.md API_列表_08063595.md
这份文档是一个API参考列表，旨在概述加密密钥包中的核心组件及其功能。文档主要包含类、枚举和结构体三个部分，涵盖了ECDSA、RSA及SM2算法的私钥与公钥类，以及用于配置加密参数的枚举和结构体。关键信息包括椭圆曲线选择、RSA填充模式设置，以及OAEP和PSS方案的详细定义。该文档面向需要实现加密或签名功能的开发人员，作为快速查阅和引用的指南。

### 功能介绍.md 功能介绍.md
本文档介绍了 keys 包的功能及其对 OpenSSL 3 依赖的安装配置指南。主要内容包括非对称加密算法（RSA、SM2、ECDSA）的功能概述，以及 Linux、Windows 和 macOS 三个操作系统的 OpenSSL 3 环境配置步骤。关键信息指出必须安装 OpenSSL 3.x.x 版本，并确保系统路径或环境变量（如 LD_LIBRARY_PATH、PATH）能正确找到对应的动态库文件，否则程序将抛出 CryptoException 异常。目标受众是使用该加密包的开发人员，需具备基本的系统环境配置知识。
