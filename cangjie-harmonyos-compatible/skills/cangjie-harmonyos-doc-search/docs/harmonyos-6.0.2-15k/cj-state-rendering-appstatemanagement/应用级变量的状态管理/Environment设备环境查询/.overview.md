This document serves as API reference documentation for the ArkUI framework's Environment class, enabling developers to query device environment parameters like language and color mode. It details the static methods envProp, which links system variables to AppStorage, and keys, which retrieves available variable names. Additionally, it defines the ColorMode and LayoutDirection enums for handling visual themes and text orientation. Key takeaways include that Environment is a singleton with immutable properties and that envProp must be called during application startup to ensure correct data binding. This guide targets ArkUI developers using the Cangjie language who need to adapt application behavior based on device settings.
