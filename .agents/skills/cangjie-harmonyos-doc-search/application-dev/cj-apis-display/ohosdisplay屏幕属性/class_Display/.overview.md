# class_Display

This directory contains essential API documentation for the Cangjie `Display` class and associated functions within the WindowManager framework. It focuses on providing developers with the tools necessary to query and interact with physical screen properties. The content covers a wide range of static attributes, such as screen dimensions, density metrics, orientation, and refresh rates, alongside specific functions for handling non-rectangular display areas like cutouts and notches. By detailing system capabilities, return types, and exception handling, this documentation serves as a critical resource for Cangjie developers and application engineers aiming to optimize user interfaces and ensure proper hardware interaction for diverse screen configurations.

## Detailed Description

### class_Display_15more.md class_Display_15more.md
This document provides API reference documentation for the Cangjie Display class, which defines static attributes for physical screens within the window manager system. It enumerates a comprehensive list of read-only properties, including dimensions (width, height), density metrics (densityDpi, xDpi), orientation, refresh rate, and state. Key information highlights that these properties do not automatically update and require specific system capabilities. The documentation is intended for Cangjie developers who need to query display configuration details for application layout or hardware interaction.

### func_getCutoutInfo.md func_getCutoutInfo.md
This API documentation defines the getCutoutInfo function in Cangjie, which retrieves the cutout or notch information for a display. The document outlines the function's signature, system capabilities, and return type CutoutInfo. It details potential BusinessException errors, such as invalid display or service abnormalities, providing specific error codes. A code example demonstrates how to invoke the method and handle exceptions. Targeting application developers, this reference is essential for managing window layouts and adapting user interfaces for screens with non-rectangular displays, specifically within the WindowManager framework.
