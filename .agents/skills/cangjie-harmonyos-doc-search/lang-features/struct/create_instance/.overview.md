## Detailed Description

### create_instance.md

本文档旨在介绍在仓颉编程语言中如何创建结构体实例，以及如何访问和修改其成员。主要涵盖通过构造函数实例化、访问公有成员、修改可变成员变量，以及结构体在赋值和传参时的值复制行为。关键点在于：修改成员需将实例和成员均定义为可变；结构体采用值语义，赋值或传参时会生成新实例，对副本的修改互不影响。适用于仓颉语言的初学者或开发者，帮助其理解结构体的基本操作和内存行为。
