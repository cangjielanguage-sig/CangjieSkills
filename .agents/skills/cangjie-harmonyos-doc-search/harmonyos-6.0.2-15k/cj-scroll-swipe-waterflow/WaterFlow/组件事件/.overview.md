# 组件事件

This directory contains API reference documentation for the WaterFlow component in the ArkUI framework, specifically using the Cangjie language. It covers essential classes, enums, and event handling functions required to implement and manage waterfall flow layouts. Key topics include layout direction, flow modes, section management, and scroll event callbacks. This documentation is suitable for developers building HarmonyOS applications who need to create dynamic, high-performance list interfaces with complex scrolling behaviors and data grouping.

## Detailed Description

### class_WaterFlowSections.md class_WaterFlowSections.md
This API reference document details the WaterFlowSections class, which manages grouped information for waterfall flow layouts in the ArkUI framework using the Cangjie language. The documentation covers the class constructor and methods for manipulating sections, including length, push, splice, update, and value. Key information explains how to add, remove, replace, and retrieve SectionOptions within a waterfall flow, with specific logic for handling indices and validation of item counts. This guide is intended for developers working on HarmonyOS ArkUI applications who need to dynamically manage waterfall stream data structures.

### enum_WaterFlowDirection.md enum_WaterFlowDirection.md
This document serves as API reference documentation for the WaterFlowDirection enum in the Cangjie language, defining the main axis direction for layout arrangements. It details the enum definition, system capabilities, and specific descriptions for four layout modes: Row, Column, RowReverse, and ColumnReverse. Key information includes the functional behavior of each mode, where Row and Column set the standard horizontal and vertical flows respectively, while their reverse counterparts invert the direction. This reference is intended for developers using the Cangjie language to build user interfaces, specifically those configuring layout directions in ArkUI applications starting from version 19.

### enum_WaterFlowLayoutMode.md enum_WaterFlowLayoutMode.md
This document serves as API reference documentation for the WaterFlowLayoutMode enum in the ArkUI framework, defining layout strategies for the WaterFlow component. It details two primary modes: ALWAYS_TOP_DOWN, the default mode where items depend on all previous layout information, and SLIDING_WINDOW, a performance-oriented mode that only considers the viewport. Key information highlights that SLIDING_WINDOW is recommended for frequent column changes but carries specific constraints, including no scrollbar support, limitations on scroller methods like scrollTo, and potential layout recalibration during jumps. This reference is intended for developers using the Cangjie language to optimize list rendering performance and handle complex scrolling behaviors in their applications.

### func_onReachEnd_-_Unit_4more.md func_onReachEnd_-_Unit_4more.md
This document serves as API reference documentation for event handling functions within the WaterFlow component of the ArkUI framework, specifically using the Cangjie language. It details four primary functions: onReachEnd, onReachStart, onScrollFrameBegin, and onScrollIndex. Key information includes function signatures, system capabilities, version requirements, and parameter definitions for callbacks that handle scroll boundaries, frame-based scroll offset adjustments, and index changes. The document is intended for developers implementing custom scroll logic or infinite loading in waterfall layouts. Important concepts involve scroll state management and specific event triggering conditions.
