This directory contains API reference documentation for deprecated classes related to console input and output (I/O) operations in the Cangjie programming language. It specifically covers the `Console`, `ConsoleReader`, and `ConsoleWriter` classes, providing detailed insights into their definitions, properties, and methods for handling standard streams. The documentation emphasizes deprecation notices and advises developers to migrate to the `env` package for future compatibility. This resource is primarily suitable for Cangjie developers who are maintaining legacy codebases or require a deep understanding of the specifications for these deprecated components.
