## Detailed Description

### `安全区域/`

This directory functions as a specialized documentation hub for managing Safe Areas and keyboard interactions within HarmonyOS applications. It is tailored for developers working with the ArkUI framework and the Cangjie language, providing the necessary technical guidance to handle complex layout scenarios.

The content covers fundamental concepts related to system UI elements, such as status bars and device cutouts, explaining how they impact the available screen real estate. It provides comprehensive API references for `expandSafeArea`, a universal attribute that allows developers to extend their application's content into these system zones, thereby achieving a truly immersive visual design.

Beyond static layout elements, the directory also addresses dynamic user interactions. It includes documentation for `setKeyboardAvoidMode`, which is essential for optimizing application layouts when the virtual keyboard appears. By detailing essential enumeration types and usage patterns, this resource equips UI developers and engineers with the knowledge to build responsive, adaptive interfaces that maintain usability and aesthetic integrity across all HarmonyOS devices.
