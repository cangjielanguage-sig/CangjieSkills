# cj-net-mgmt-overview

本目录提供了关于网络管理（Network Kit）的全面概览文档，旨在为开发者提供集成网络服务所需的指导。内容涵盖了HTTP数据请求、网络连接管理（包括WiFi与蜂窝网络的多网络优先级策略）、网络质量评估、状态订阅以及DNS解析等关键技术点。文档特别强调了合规性要求，详细说明了在使用网络功能前必须声明的`ohos.permission.GET_NETWORK_INFO`和`ohos.permission.INTERNET`权限。该资源适合所有需要在应用中实现稳定、高效网络通信的开发者，通过提供功能索引和详细文档链接，帮助开发者快速理解并应用网络能力。

## Detailed Description

### cj-net-mgmt-overview.md

本文档是Network Kit（网络服务）的概览指南，主要面向需要进行网络应用开发的开发者。它详细概述了网络服务的核心功能与权限约束，帮助开发者理解如何合规地使用网络能力。

主要内容包括：
1. **HTTP数据请求与网络连接管理**：涵盖WiFi、蜂窝等多网络环境下的优先级管理。
2. **高级网络功能**：包括网络质量评估、状态订阅及DNS解析。
3. **权限合规**：重点强调使用前必须声明`ohos.permission.GET_NETWORK_INFO`和`ohos.permission.INTERNET`权限。

文档还提供了相关功能的详细文档链接，作为功能索引和合规性要求的参考，是集成网络能力的必读文档。
