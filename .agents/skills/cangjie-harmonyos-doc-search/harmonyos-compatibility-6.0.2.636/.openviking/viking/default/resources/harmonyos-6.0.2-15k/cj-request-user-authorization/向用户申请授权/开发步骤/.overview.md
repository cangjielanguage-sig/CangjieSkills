# 开发步骤

This directory provides a comprehensive guide for implementing runtime permission requests in HarmonyOS applications using the Cangjie language. It covers the complete development lifecycle, from declaring permissions in configuration files to handling authorization results and UI integration. Key topics include location permission management, the `checkAccessToken` method, and the `requestPermissionsFromUser` API. The tutorials address critical timing constraints and lifecycle methods like `onWindowStageCreate`. This resource is suitable for HarmonyOS developers familiar with Cangjie syntax and the AbilityKit framework who need to integrate privacy permission flows into their applications.

## Detailed Description

### 开发步骤_1.md 开发步骤_1.md
This tutorial outlines the development steps for requesting location permissions in HarmonyOS applications using the Cangjie language. It covers three main stages: declaring required permissions in configuration, verifying current authorization status using the checkAccessToken method, and dynamically requesting permissions from users via requestPermissionsFromUser. Key takeaways include Cangjie code examples for checking access tokens and handling the relationship between precise and approximate location permissions. The document also highlights a critical timing requirement: dynamic permission requests must be invoked only after UI content loading finishes. This guide is intended for developers implementing runtime permission management.

### 开发步骤_2.md 开发步骤_2.md
This technical tutorial guides developers on implementing user permission requests in HarmonyOS applications using the Cangjie language. It covers two primary methods: requesting permissions within the onWindowStageCreate lifecycle method and requesting permissions directly from the UI layer. Key information includes the critical timing constraint that requestPermissionsFromUser must be called after onWindowStageCreate execution ends or within its callback to prevent failures in UIExtensionAbility. The document provides code examples for handling authorization results, managing callbacks, and storing the global context for UI-based requests. Intended for HarmonyOS application developers familiar with Cangjie syntax and the AbilityKit framework, this guide ensures proper runtime permission handling.
