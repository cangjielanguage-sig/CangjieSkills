This directory contains API reference documentation for the `GlobalVariableInfo` class within the Cangjie programming language's reflection package. It provides comprehensive details on metadata access and runtime manipulation capabilities for global variables. The documentation covers essential properties for accessing variable names, type information, and annotations, as well as methods for retrieving and modifying values. It also includes functionalities for checking mutability and reflection. This resource is designed for developers utilizing the reflection package to dynamically inspect and modify global variable states while maintaining type safety and handling mutability constraints. By leveraging these tools, developers can achieve greater flexibility in their applications through runtime introspection.
