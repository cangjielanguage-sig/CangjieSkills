# 在ArkTS模块中增量使用仓颉

This directory provides resources for HarmonyOS developers looking to integrate Cangjie language capabilities into existing ArkTS projects incrementally. It covers setting up hybrid development environments, embedding Cangjie UI components within ArkTS pages, and enabling cross-module function calls between pure ArkTS and Cangjie code. Key topics include Interop configurations, HybridComponent usage, and @Interop annotations. Suitable for developers using DevEco Studio who want to leverage Cangjie for high-performance business logic or UI elements while maintaining their current ArkTS architecture.

## Detailed Description

### 在ArkTS模块中增量使用仓颉_2more.md 在ArkTS模块中增量使用仓颉_2more.md
This tutorial guides developers on incrementally enabling Cangjie development within existing ArkTS HAP or HAR modules in HarmonyOS projects. It covers prerequisites regarding SDK versions (API 12-15), supported device types (phone, tablet), and necessary configuration adjustments in module.json5. The core instruction involves using the right-click menu to select "New -> Cangjie(Interop)," which automatically configures the project structure to support a Cangjie-ArkTS hybrid environment. Targeted at HarmonyOS developers using DevEco Studio, this document facilitates the integration of Cangjie code into ArkTS modules while noting current limitations regarding static library support.

### 在同模块内ArkTS页面嵌入仓颉组件.md 在同模块内ArkTS页面嵌入仓颉组件.md
This tutorial guides developers on embedding Cangjie UI components within ArkTS pages in the same module. It covers creating a Cangjie HybridComponent with stateful UI elements, integrating it into an ArkTS page using the CJHybridComponentV2 component, and invoking Cangjie native methods (callSync/callAsync) from ArkTS. The document provides code examples for both languages and instructions for running the application on a device or emulator. It targets HarmonyOS developers seeking to leverage Cangjie for business logic or UI within existing ArkTS applications.

### 在同一个工程内纯ArkTS工程跨模块调用仓颉函数/
This directory provides a comprehensive technical guide for HarmonyOS developers aiming to achieve interoperability between ArkTS and Cangjie within the same project. It details the process of invoking Cangjie functions from a pure ArkTS module, covering essential development steps such as using @Interop annotations, generating TypeScript definitions, and configuring build settings. The content addresses both synchronous and asynchronous execution patterns and explains how to integrate Cangjie shared libraries effectively. Designed for developers familiar with ArkTS who wish to incorporate Cangjie business logic, these resources facilitate the creation of high-performance hybrid applications by bridging the two languages seamlessly. The documentation ensures developers can successfully build, configure, and execute mixed-language projects in a unified workspace.
