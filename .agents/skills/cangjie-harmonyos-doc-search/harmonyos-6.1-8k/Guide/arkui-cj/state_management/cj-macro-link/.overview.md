# cj-macro-link

This directory serves as a comprehensive technical guide for the `@Link` macro within the ArkUI framework, specifically tailored for developers using the Cangjie programming language. It focuses on the critical mechanism of bidirectional data binding between parent and child components, which is essential for building reactive and interactive user interfaces. The documentation covers a wide array of technical details, including basic usage rules, variable passing protocols, supported data types, and the underlying change observation mechanisms. Additionally, it addresses common limitations and constraints developers may face during implementation. This resource is highly suitable for ArkUI developers who aim to achieve a deep understanding of component state management, reduce boilerplate code, and ensure efficient data interaction patterns in their application architecture.

## Detailed Description

### Link宏父子双向同步/

This subdirectory offers a detailed technical introduction to the `@Link` macro in the ArkUI framework, with a specific emphasis on implementing bidirectional data synchronization between parent and child components. The content is structured to guide developers through the core concepts required for effective state management. It begins by outlining the basic usage rules and the specific mechanisms involved in passing variables between components, ensuring that data flows seamlessly in both directions without manual intervention.

Furthermore, the documentation delves into the supported data types and the sophisticated change observation mechanisms that ensure the UI remains consistent with the underlying data state. It also highlights common restrictions and limitations that developers must navigate to avoid runtime errors and ensure application stability. To facilitate practical understanding, the directory includes code examples written in the Cangjie language. These examples demonstrate how to properly utilize the `@Link` decorator in conjunction with other essential decorators like `@State` and `@Observed`. This section is an essential reference for ArkUI developers seeking to master complex data interactions and build robust, reactive applications using the Cangjie language.
