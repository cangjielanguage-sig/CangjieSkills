# hdc错误码

本目录汇集了HarmonyOS设备连接器（HDC）工具在使用过程中遇到的常见错误代码及其解决方案。文档主要涵盖了命令行交互、参数校验以及文件传输操作中的异常情况，如包名非法、参数缺失及版本兼容性问题。通过详细的排查步骤和具体的命令行指导，帮助开发人员快速定位并解决开发调试中的阻碍。核心关键词包括HDC、错误代码、Shell命令、文件传输、调试。本目录适用于使用HDC工具进行HarmonyOS应用开发、调试及设备管理的开发人员。

## 详细说明

### E003001_命令行指定的包名非法.md E003001_命令行指定的包名非法.md

这份文档旨在解释并解决错误代码E003001，即在使用hdc shell命令时指定的包名非法的问题。文档详细分析了三种可能原因：应用未安装、应用非调试模式构建或应用未启动，并提供了相应的排查与处理步骤。关键内容包括使用bm dump命令检查安装和调试状态，使用mount命令检查挂载情况，以及通过aa命令启动应用。本文档主要面向使用HarmonyOS hdc工具进行应用调试的开发人员，提供了具体的命令行操作指导。
