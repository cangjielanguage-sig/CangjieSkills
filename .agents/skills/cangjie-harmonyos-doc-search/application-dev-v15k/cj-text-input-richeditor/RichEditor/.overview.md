# RichEditor

This directory provides comprehensive documentation and resources for the RichEditor component within the ArkUI framework, specifically designed for HarmonyOS application development using the Cangjie language. It covers essential aspects of building rich text editing interfaces, including mixed graphics and text layout, interactive text editing, and event handling. The content includes API references for component attributes, type definitions, event callbacks, and practical code examples for implementation. Suitable for software developers and UI engineers, this collection offers the necessary tools to create sophisticated text manipulation features, custom menus, and dynamic styling in modern applications.

## Detailed Description

### RichEditor_4more.md RichEditor_4more.md
This document serves as API reference documentation for the RichEditor component, designed to support mixed graphics and text layout alongside interactive text editing. The primary sections cover component creation using the init method and the supported general attributes and events. Key information includes the requirement of a mandatory RichEditorController parameter for initialization and specific attribute limitations, such as restricted alignment options and lack of support for borderImage. Intended for developers using the ArkUI framework, this guide details system capabilities starting from version 12, providing essential specifications for implementing rich text editing interfaces.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the implementation and configuration of the RichEditor component in a HarmonyOS application. It covers the main EntryView class structure, a custom keyboard builder, and various event handlers for content manipulation. Key operations include getting and setting caret offsets, adding text and image spans with specific styles, retrieving span data, and updating paragraph styles. The example also illustrates binding custom selection menus and handling lifecycle events like onReady and onSelect. This sample is intended for HarmonyOS developers using the Cangjie language who need to integrate rich text editing capabilities into their user interfaces.
