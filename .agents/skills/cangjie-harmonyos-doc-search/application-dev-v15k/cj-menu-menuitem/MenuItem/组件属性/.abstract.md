This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on menu items. It covers essential styling and state management features, including font customization (size, weight, color), label appearance, selection icon configuration, and selection state logic. The documentation details function signatures, parameters, default values, and system capabilities required for implementation. Suitable for HarmonyOS developers using the Cangjie language, these resources provide the technical specifications needed to build and customize user interface components effectively.
