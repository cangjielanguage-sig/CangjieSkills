# 菜单控制

This directory provides comprehensive API documentation and code examples for implementing menu controls in the Cangjie ArkUI framework. It covers the creation, configuration, and interaction of popup menus and context menus, including classes like `Action`, `MenuElement`, `MenuOptions`, and `ContextMenuOptions`. Developers can learn how to bind menus to components, customize animations, and handle user events. This resource is suitable for software developers and UI engineers building interactive user interfaces in HarmonyOS applications who need precise control over menu behavior and styling.

## Detailed Description

### class_Action.md class_Action.md
This document provides API reference documentation for the Cangjie Action class, which defines parameters for popup menu items. The content details the class constructor and its two read-only properties: value, a String representing the menu text, and action, a function type handling click events. Key takeaways include the requirement for named parameters during instantiation to set the text and callback logic. This resource is intended for developers building UI components in Cangjie who need to implement interactive menu behaviors. Keywords: Cangjie, Action class, API reference, popup menu, event callback, UI components.

### class_ContextMenuAnimationOptions.md class_ContextMenuAnimationOptions.md
This API reference document defines the Cangjie class ContextMenuAnimationOptions, which configures animation behaviors for context menus in ArkUI applications. The documentation details the class constructor and three public properties: scale, transition, and hoverScale. These properties control the start and end scaling ratios relative to the original preview image and define transition effects for menu display and exit. Key information includes specific constraints for the hoverScale property, such as its invalidity when transition is set or values are non-positive, and interaction rules where scale's start value is ignored if hoverScale is used. Intended for ArkUI developers, this guide requires knowledge of Cangjie syntax and UI layout principles to implement custom long-press preview animations effectively.

### class_MenuElement.md class_MenuElement.md
This document serves as API reference documentation for the Cangjie programming language, specifically detailing the MenuElement class used to configure menu items within the ArkUI framework. The file covers the class definition, system capabilities, and the constructor initialization method. It specifically outlines the parameters required to create a menu item, including text, click action, optional icon, and enabled state. Key takeaways include the requirement for a text value and an action callback, while the icon and enabled status are optional named parameters with default values. The class is available starting from version 19 and requires full ArkUI system capabilities. This reference is intended for developers building user interfaces in Cangjie who need to implement interactive menu components in their applications.
