This directory provides a comprehensive technical guide on implementing inter-application navigation using Deep Linking technology within the HarmonyOS ecosystem. It covers the fundamental principles of launching apps via URIs, implicit Want matching, and the specific configurations required for both calling and target applications. Key topics include URI parsing, `module.json5` configuration, and handling deep links in the UIAbility lifecycle. This resource is suitable for HarmonyOS developers, particularly those using the Cangjie language and ArkUI framework, who need to enable seamless cross-app launching and web-to-native transitions in their projects.
