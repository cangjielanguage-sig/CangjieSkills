This directory provides a comprehensive guide for developers working on application stability within the HarmonyOS environment, specifically focusing on the Cangjie programming language. It details the technical procedures required to implement crash event monitoring using the HiAppEvent module. The content covers the full lifecycle of crash handling, from initial code implementation and configuration of event watchers to the analysis of generated crash logs. Key technical concepts include AppEventFilter configuration, CjError stack unwinding, and the distinction between caught and uncaught exception reporting mechanisms. This resource is essential for Cangjie application developers and QA engineers utilizing DevEco Studio who require practical solutions for tracking, debugging, and resolving system-level crash events to ensure robust application performance.
