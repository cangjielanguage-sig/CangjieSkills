# class_Unicode

This directory contains API reference documentation for the Unicode class within the Cangjie LocalizationKit, specifically designed for comprehensive character analysis and classification. It covers a wide range of static methods used to validate text properties, including identifying digits, letters, ideographs, whitespace, and right-to-left orientation. Key topics include Unicode general categories, specific character property checks, and the necessary system capabilities for internationalization. This documentation is primarily suitable for Cangjie developers who are implementing text processing, input validation, or internationalization features and need to programmatically categorize or analyze characters within their applications. The resources provided here detail the syntax, parameters, and return values required to effectively utilize these character analysis tools.

### class_Unicode_7more.md
This document provides API reference documentation for the Unicode class within the Cangjie LocalizationKit, designed for character analysis and classification. It details several static methods, including getType, isDigit, isIdeograph, isLetter, isLowerCase, and isRTL. Key information includes that these methods accept a String input and return either a general category string or a boolean indicating specific character properties, such as digit status or right-to-left orientation. The class requires the SystemCapability.Global.I18n capability and is available starting from version 19. This reference guide targets Cangjie developers implementing internationalization features who need to programmatically validate or categorize text characters.

### static_func_isSpaceCharStr_3more.md

Key takeaways include that all functions accept a String input representing a character and return a Boolean indicating specific Unicode properties, such as whether the character is a space, uppercase letter, or general whitespace. Intended for Cangjie developers utilizing the LocalizationKit, this reference aids in implementing text processing and internationalization features.
