# cj-crypto-sm2-ciphertext-conversion

This directory provides a specialized technical guide focused on the intricacies of SM2 ciphertext conversion using the Cangjie CryptoArchitectureKit. It is designed to assist developers in navigating the complexities of cryptographic standards by detailing how to convert raw SM2 ciphertext parameters to and from the standard ASN.1 format (C1C3C2). The documentation covers essential workflows, including the generation of compliant ciphertexts from raw data and the reverse process of extracting specific parameters from existing ASN.1 structures. By utilizing the `SM2CipherTextSpec` structure and key functions like `genCipherTextBySpec` and `getCipherTextSpec`, developers can ensure their applications maintain strict compatibility with national cryptographic standards. This resource is particularly suitable for backend developers, security engineers, and system architects working within the Cangjie ecosystem who require reliable cryptographic data handling, standardization, and interoperability with national security systems.
