# 调试工具

## 详细描述

### FAQ.md
本文档旨在解决仓颉调试器 cjdb 使用中的常见问题。涵盖 Docker 权限配置、信号处理（SIGABRT/SIGSEGV）、异常捕获调试、macOS 平台限制及泛型命名规则。关键信息包括：Docker 需开启 SYS_PTRACE 权限；可通过命令管理信号捕获；调试 catch 块需手动打断点；macOS 表达式计算受限；泛型变元显示为 T0/T1 以兼容 ABI。面向仓颉开发者，适用于排查环境配置与调试逻辑问题。

### 可执行文件调试_2more_311ebc35.md
本文档旨在指导开发者使用 cjdb 调试器调试仓颉可执行文件。文档主要介绍了两种调试模式：启动调试器时加载程序或通过 file 命令加载，以及附加到正在运行的进程。关键信息包括必须使用 -g 编译的 debug 版本、泛型对象和 Enum 类型的显示特性，以及基于 lldb 构建所支持的原生功能。此外，还指出了在 C 语言互操作场景下可能存在的兼容性风险。目标受众为仓颉应用开发者，需具备基本的编译和调试知识。

### 调试工具_2more_db3e1a7b.md
本文档介绍仓颉语言的命令行调试工具 cjdb，旨在为开发者提供程序调试能力。内容涵盖 cjdb 基于 lldb 的技术背景、通过 SDK 获取工具的方法、Windows 平台使用示例及系统参数说明。关键信息包括工具在 SDK 中的路径、跨平台支持（Windows/Linux/macOS），以及调试器与编译器版本需保持一致的注意事项。文档面向仓颉开发者，属于工具配置指南，帮助用户快速部署调试环境。

### cjdb_命令/
本目录包含 `cjdb` 调试器的核心命令参考文档，旨在为开发人员提供全面的调试操作指南。内容涵盖了从基础的日志记录、平台管理，到进阶的线程状态查看、函数断点控制、变量监视与修改，以及观察点和表达式求值等关键功能。这些文档详细介绍了命令语法、使用场景及平台限制，特别适合使用仓颉语言进行程序开发、需要深入调试并发问题、控制执行流程或分析运行时数据的开发者。通过掌握这些命令，用户可以高效地定位和解决程序中的错误。
