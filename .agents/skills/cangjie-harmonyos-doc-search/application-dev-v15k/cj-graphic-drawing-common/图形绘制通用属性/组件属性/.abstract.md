This directory contains API reference documentation for configuring UI component properties within the Cangjie ArkUI framework. It covers essential visual styling aspects, including anti-aliasing, fill colors, opacity settings, component dimensions, and comprehensive stroke styling for borders. The documents provide detailed function parameters, data type constraints, default values, and clamping rules to ensure precise UI rendering. It is specifically designed for developers using the Cangjie language who require programmatic control over the appearance and layout of graphical components in ArkUI applications.
