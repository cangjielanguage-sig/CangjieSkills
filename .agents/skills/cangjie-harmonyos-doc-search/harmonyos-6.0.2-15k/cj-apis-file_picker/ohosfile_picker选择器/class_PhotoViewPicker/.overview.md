# class_PhotoViewPicker

This directory contains essential API reference documentation for the `PhotoViewPicker` class and the `select` function in the Cangjie programming language, specifically tailored for the HarmonyOS ecosystem. It provides developers with the technical specifications required to implement system-level media picking, allowing users to select, save, and manage images and videos within applications. The documentation covers critical aspects such as asynchronous callback handling, URI retrieval, and the configuration of selection options like media types and maximum selection counts. Furthermore, it clarifies storage behaviors, distinguishing between the Gallery and File Manager. This resource is primarily suitable for application developers and system integrators looking to enhance their apps with native media interaction capabilities.

## Detailed Description

### class_PhotoViewPicker_3more.md class_PhotoViewPicker_3more.md
This document serves as API reference documentation for the PhotoViewPicker class in the Cangjie language, designed to facilitate selecting and saving images or videos. It details the class constructor, which requires a UIAbilityContext instance, and the primary save method. This method uses an asynchronous callback to return an array of file URIs after a user interacts with the photo picker interface. Key information includes the specification of PhotoSaveOptions and the important distinction that saved files are stored in the File Manager rather than the Gallery. The document provides a practical code example for implementation. It targets developers building applications that require media file management and user interaction capabilities.
