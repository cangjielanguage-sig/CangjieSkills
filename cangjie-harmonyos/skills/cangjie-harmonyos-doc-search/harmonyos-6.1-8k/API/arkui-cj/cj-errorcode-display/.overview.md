# cj-errorcode-display

本目录专门用于存放屏幕显示模块的错误码定义文档，旨在为开发者提供故障诊断支持。文档详细列出了包括无效显示设备、无权限操作及系统服务异常在内的核心错误码，并深入探讨了虚拟屏管理、权限校验机制以及服务状态监测等关键领域。通过提供具体的错误原因分析和处理步骤，本资源帮助开发者快速定位并解决显示相关问题。该文档主要面向屏幕管理功能的开发人员，建议与通用错误码文档配合使用以获得最佳效果。

## 详细描述

### cj-errorcode-display.md
本文档定义了屏幕显示模块特有的错误码，旨在辅助开发者诊断显示故障。内容涵盖三个核心错误码：1400001（无效显示设备）、1400002（无权限操作）及1400003（系统服务异常），涉及虚拟屏管理、权限校验和服务状态。每个条目详细说明了错误原因及处理步骤，如检查虚拟屏状态、避免跨进程非法操作及服务异常时的重试方法。作为参考手册，本文档面向屏幕管理功能开发者，需配合通用错误码文档使用。
