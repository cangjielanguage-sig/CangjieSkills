# ohosrpcRPC通信

本目录主要介绍HarmonyOS系统中基于仓颉（Cangjie）语言的RPC（远程过程调用）与IPC（进程间通信）开发指南及API参考。内容涵盖了核心通信模块的配置与使用、数据序列化接口定义、消息序列处理机制以及匿名共享内存管理。核心关键词包括IPC、RPC、Binder驱动、软总线、Parcelable、Ashmem和MessageSequence。该文档适合从事HarmonyOS系统开发、需要实现跨进程数据传输或跨设备通信功能的仓颉语言开发者阅读，旨在帮助他们掌握高效的数据交互与共享机制。

## 详细描述

### interface_Parcelable.md interface_Parcelable.md
本文档是Cangjie语言中Parcelable接口的API参考文档，用于在进程间通信（IPC）期间实现对象的序列化与反序列化。文档详细介绍了marshalling（封送）和unmarshalling（解封）两个核心方法，包括其参数、返回值及功能说明。关键信息指出，该接口通过MessageSequence对象进行数据交互，并提供了具体的类实现示例，演示如何读写Int32和String类型数据。该文档面向需要进行IPC开发的Cangjie程序员，帮助他们理解如何自定义可序列化对象以支持跨进程数据传输。

### ohosrpcRPC通信_3more_316d05e8.md ohosrpcRPC通信_3more_316d05e8.md
本文档是ohos.rpc模块的API参考文档，旨在介绍仓颉语言环境下的进程间通信（IPC）和设备间通信（RPC）能力。文档主要涵盖模块导入方法、IPC（基于Binder驱动）与RPC（基于软总线驱动）的定义及使用说明。关键信息包括当前功能处于Beta阶段，以及如何在仓颉模板工程的index.cj或main_ability.cj文件中配置和运行示例代码。目标受众为HarmonyOS开发者，需具备仓颉工程配置及Context应用上下文的相关知识。

### class_Ashmem/
本目录包含Cangjie语言中Ashmem（匿名共享内存）类的API参考文档，专注于管理用于本设备内跨进程通信（IPC）的共享内存。内容涵盖了内存保护常量定义、共享内存的创建、映射、读写操作、保护设置及资源释放等核心功能。该文档旨在帮助系统开发者实现高效的数据共享，要求读者具备Cangjie编程基础及异常处理相关知识。

### class_MessageSequence/
本目录包含Cangjie语言中MessageSequence类的API参考文档，主要用于规范RPC或IPC过程中的数据序列化与传输。内容涵盖对象的创建与销毁、容量管理、以及基础类型、数组、文件描述符和Parcelable对象的读写操作。该文档集是构建HarmonyOS系统通信功能的重要参考资料，适合从事跨进程通信开发的工程师查阅，提供了处理IPC对象及数据序列化的标准接口。
