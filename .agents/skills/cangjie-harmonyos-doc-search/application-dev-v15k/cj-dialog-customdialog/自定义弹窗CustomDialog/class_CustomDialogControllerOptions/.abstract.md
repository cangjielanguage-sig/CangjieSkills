This directory contains API reference documentation for the `CustomDialogControllerOptions` class within the Cangjie ArkUI framework. It provides comprehensive details on configuring custom dialog components, covering layout settings, visual styles (borders, shadows, blur), and behavioral controls (modal state, animations, auto-cancel). The documentation includes the class definition, specific property variables, and initialization methods. It is suitable for UI developers and HarmonyOS designers seeking to implement highly customizable modal or non-modal dialogs with specific styling and interaction logic.
