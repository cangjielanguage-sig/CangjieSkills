# cj-apis-app-ability-start_options

本目录专门收录了HarmonyOS仓颉开发框架中`ohos.app.ability.start_options`模块的API参考文档。该文档的核心目的是指导开发者如何使用`StartOptions`类来配置`UIAbility`的启动选项。内容全面覆盖了模块的导入方式、运行时所需的权限、类属性（特别是`displayId`和`windowMode`）的详细定义以及构造函数的使用方法。关键知识点在于如何通过设置屏幕ID和窗口模式，来精确控制Ability在启动时的显示行为，这对于需要处理多窗口或特定屏幕布局的应用至关重要。本文档非常适合正在使用仓颉语言进行HarmonyOS应用开发的工程师，提供了详尽的参数说明和实用的代码示例，以辅助实现更加精细化和用户友好的界面启动控制。
