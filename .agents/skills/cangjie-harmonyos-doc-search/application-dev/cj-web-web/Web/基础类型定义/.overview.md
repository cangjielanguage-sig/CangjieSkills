# 基础类型定义

This directory contains API reference documentation for fundamental Cangjie language classes used in Web component development. It covers essential data structures for managing HTTP headers, handling web resource requests, and tracking page loading events. Key topics include the `Header` class, `WebResourceRequest`, and various event classes like `OnPermissionRequestEvent` and `OnLoadInterceptEvent`. These definitions are crucial for developers building WebView applications who need to intercept network traffic, manage user permissions, and monitor resource loading states within the SystemCapability.Web.Webview.Core framework.

## Detailed Description

### class_Header_4more.md class_Header_4more.md
This document serves as API reference documentation for Cangjie language classes related to Web component event handling and header management. It details the Header class for request/response data, and event classes OnLoadInterceptEvent, OnPageBeginEvent, and OnPageEndEvent for tracking web resource loading states. Key information includes nullable string properties for header keys and values, request data objects, and URL strings. All classes feature public constructors and read-write properties, requiring SystemCapability.Web.Webview.Core. This is intended for developers implementing WebView functionality who need to manage HTTP headers and intercept or monitor page loading events.

### class_OnPermissionRequestEvent.md class_OnPermissionRequestEvent.md
This API reference document defines the OnPermissionRequestEvent class in Cangjie, which structures parameters for handling permission requests within a Webview component. The documentation covers the class definition, the request property, and the constructor method. Key information includes the request variable, a PermissionRequest object used to grant or deny access, and the system capability requirements starting from version 22. Intended for developers working on Webview integration, this document provides the necessary interface to manage user permission interactions programmatically.

### class_PermissionRequest.md class_PermissionRequest.md
This document serves as API reference documentation for the Cangjie class PermissionRequest, designed to handle permission authorization within Web components. It covers the class definition and four primary member functions: deny, getAccessibleResource, getOrigin, and grant. Key information includes methods to retrieve the requesting web page origin and the list of requested resources, alongside functions to explicitly grant or deny access, specifically noting support for screen capture configurations. This technical reference targets developers utilizing the Webview Core system capability to manage web page permission interactions.

### class_WebResourceRequest.md class_WebResourceRequest.md
This document serves as API reference documentation for the Cangjie class WebResourceRequest, designed to handle web resource requests within the Webview Core system. It details the class definition and six public member functions, including getRequestHeader, getRequestMethod, getRequestUrl, isMainFrame, isRedirect, and isRequestGesture. Key information includes the ability to retrieve request metadata such as headers, URLs, and HTTP methods, while also determining request characteristics like whether it is a main frame, a server redirect, or triggered by a user gesture. All functions require SystemCapability.Web.Webview.Core and are available from version 22. This reference is intended for software developers building web applications using the Cangjie language who need to inspect or intercept web resource requests.
