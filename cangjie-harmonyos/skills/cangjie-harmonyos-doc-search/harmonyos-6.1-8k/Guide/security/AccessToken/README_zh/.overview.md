# README_zh

本目录包含程序访问控制特性的核心中文文档，旨在为开发者提供全面的权限管理导航与实施指南。文档深入探讨了访问令牌的运作机制、应用权限的管控全流程，以及如何正确声明和申请用户授权，涵盖了单次授权和受限权限等复杂场景。此外，它还详细列出了系统应用、企业应用及MDM应用所需的特定权限，并清晰界定了系统授权与用户授权的区别。该文档特别适合致力于构建安全、合规应用的开发者阅读，假设读者具备一定的软件开发基础，并主要聚焦于Beta阶段的特性。通过掌握访问控制列表（ACL）和权限申请流程，开发者可以有效地管理应用权限，确保系统安全。
