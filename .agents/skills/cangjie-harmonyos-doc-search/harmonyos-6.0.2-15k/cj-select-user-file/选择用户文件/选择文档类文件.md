## 选择文档类文件

1. 导入选择器模块和基础文件API模块。

    ```cangjie
    import kit.CoreFileKit.*
    import kit.AbilityKit.*
    import kit.BasicServicesKit.*
    import ohos.base.*
    ```

2. 创建文件类型、文件选择选项实例。

    ```cangjie
    let documentSelectOptions = DocumentSelectOptions(
        // 选择文档的最大数目（可选）。
        maxSelectNumber: 5,
        // 指定选择的文件或者目录路径（可选）。
        defaultFilePathUri: "file://docs/storage/Users/currentUser/test",
        // 选择文件的后缀类型['后缀类型描述|后缀类型']（可选，不传该参数，默认不过滤，即显示所有文件），若选择项存在多个后缀名，则每一个后缀名之间用英文逗号进行分隔（可选），后缀类型名不能超过100。此外2in1设备支持通过通配符方式['所有文件(*.*)|.*']，表示为显示所有文件，手机暂不支持该配置。
        fileSuffixFilters: ['图片(.png, .jpg)|.png,.jpg', '文档|.txt', '视频|.mp4', '.pdf'],
        // 选择是否对指定文件或目录授权，true为授权，当为true时，defaultFilePathUri为必选参数，拉起文管授权界面；false为非授权（默认为false），拉起常规文管界面（可选），仅支持2in1设备。
        authMode: false
    )
    ```

3. 创建[文件选择器DocumentViewPicker](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_picker.md#class-documentviewpicker)实例。调用[select()](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_picker.md#func-selectasynccallbackarraystring-documentselectoptions)接口拉起FilePicker应用界面进行文件选择。

    ```cangjie
    let uris = Box<Array<String>>([])
    // 见获取UIAbility的上下文信息章节
    let context = getContext()
    // 创建文件选择器实例
    let documentViewPicker = DocumentViewPicker(context);
    documentViewPicker.select({ err, ret =>
        if (let Some(v) <- err) {
            AppLog.error("Invoke documentViewPicker.select failed, code is ${v.code}")
        }
        if (let Some(v) <- ret) {
            // 文件选择成功后，返回被选中文档的uri结果集
            uris.value = v
        }
    }, option: documentSelectOptions)
    ```

    > **注意：**
    >
    > 1.使用picker获取的[select()](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_picker.md#func-selectasynccallbackarraystring-documentselectoptions)返回的uri权限是临时只读权限,待退出应用后台后，获取的临时权限就会失效。
    > 2.开发者可以根据结果集中uri做进一步的处理。建议定义一个全局变量保存uri。
    > 3.如有获取元数据需求，可以通过[基础文件API](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md)和[文件URI](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fileuri.md)根据uri获取部分文件属性信息，比如文件大小、访问时间、修改时间、文件名、文件路径等。

4. 待界面从FilePicker返回后，使用[基础文件API的file_fs.open](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md#static-func-openstring-int64)接口通过uri打开这个文件得到文件描述符(fd)。

    ```cangjie
    let uri = ''
    //这里需要注意接口权限参数是OpenMode.READ_ONLY。
    let file = FileFs.open(uri, mode: OpenMode.READ_ONLY.mode)
    AppLog.info('file fd: ${file.fd}')
    ```

5. 通过fd使用[file_fs.read](../../API_Reference/source_zh_cn/apis/CoreFileKit/cj-apis-file_fs.md#static-func-readint32-arraybyte-readoptions)接口读取这个文件内的数据。

    ```cangjie
    let buffer = Array<Byte>(4096, repeat: 0)
    let readLen = FileFs.read(file.fd, buffer)
    AppLog.info('readSync data to file succeed and buffer size is: ${readLen}')
    //读取完成后关闭fd。
    FileFs.close(file)
    ```
