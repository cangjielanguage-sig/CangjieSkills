# 使用场景

本目录详细展示了ArkUI中@Link装饰器的具体使用场景，重点讲解双向数据同步的实现机制与高级用法。内容涵盖了简单类型、类对象类型以及数组类型的状态管理，结合Cangjie（仓颉）语言代码示例，深入解析了@Link与@State、@Observed、@Publish及@Watch的配合使用。文档旨在帮助开发者理解父子组件间的数据流转逻辑，掌握复杂状态管理技巧，适合具备基础ArkUI开发经验，希望提升组件通信能力的开发者参考。

## 详细描述

### 数组类型的Link_2more_edb0dfd5.md

本文档旨在演示ArkUI中@Link装饰器在数组类型及双向同步场景下的高级用法。主要涵盖两个核心示例：一是使用ObservedArrayList修饰@Link变量，实现对数组元素增删改的感知与UI更新；二是结合@Watch监听器，在双向同步时修改本地@State变量，并阐明本地修改不会反向影响父组件。文档通过Cangjie代码实例，帮助开发者掌握复杂状态管理逻辑，适用于具备基础ArkUI开发经验的用户。关键词：@Link、ObservedArrayList、@Watch、双向同步、ArkUI、Cangjie。

### 简单类型和类对象类型的Link.md

1. 本文档旨在演示ArkUI中@Link装饰器在简单类型和类对象类型下的双向数据同步机制。
2. 主要内容包括父组件EntryView与子组件GreenButton、YellowButton的交互实现，展示了从父到子及从子到父的数据流转逻辑。
3. 关键信息指出@Link与@State配合实现双向绑定，类对象类型需配合@Observed和@Publish使用以实现属性变更的观察与同步。
4. 适合使用仓颉语言进行ArkUI开发的开发者，作为状态管理和组件通信的代码教程参考。
