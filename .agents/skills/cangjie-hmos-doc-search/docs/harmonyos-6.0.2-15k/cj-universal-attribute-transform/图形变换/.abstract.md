This directory contains API reference documentation for implementing graphic transformations within the ArkUI framework using the Cangjie programming language. It covers essential manipulation techniques including scaling, translation, and rotation, allowing developers to modify component geometry and layout positioning precisely. The content details specific functions for 2D and 3D transformations, handling of different data types (Int32, Float32, Length), and matrix operations. This resource is suitable for UI developers and system engineers looking to programmatically control component appearance and spatial relationships in ArkUI applications.
