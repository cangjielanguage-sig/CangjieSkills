# cj-cancel-authentication

This directory provides a comprehensive technical guide specifically designed for developers working with the unified user authentication framework. It focuses on the critical functionality of canceling an ongoing user authentication process, a necessary feature for managing user experience and application state. The documentation details the specific cancel interface within the UserAuthenticationKit, outlining a precise three-step development procedure that includes permission application, authentication initiation, and the invocation of the cancel method. It includes practical Cangjie code examples and explains essential prerequisites such as obtaining a UserAuthInstance and configuring AuthParam with specific trust levels. This resource is ideal for application developers who require robust control over authentication lifecycle events and need to implement interruption handling in their applications.

### cj-cancel-authentication.md cj-cancel-authentication.md
