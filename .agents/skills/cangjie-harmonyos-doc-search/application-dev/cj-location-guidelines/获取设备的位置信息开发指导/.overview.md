# 获取设备的位置信息开发指导

This directory provides comprehensive development guidance for acquiring device location information using the Cangjie language and LocationKit within the OpenHarmony ecosystem. It covers essential procedures such as permission application, module importing, location switch status checking, and single location requests. The content also includes references to practical code examples and distinguishes between real-time tracking and historical data retrieval scenarios. Key topics include WGS-84 coordinate systems, LocatingPriority settings, and exception handling. This resource is suitable for application developers and Cangjie language programmers looking to integrate location features like check-ins or service recommendations into their applications.

## Detailed Description

### 开发步骤.md 开发步骤.md
This document provides a step-by-step tutorial for developers to implement device location acquisition using the Cangjie language and LocationKit. The guide covers four main stages: applying for location permissions, importing the geoLocationManager module, checking the location switch status, and performing a single location request. Key information includes configuring the SingleLocationRequest object with specific LocatingPriority options for accuracy or speed, setting a recommended timeout of 10 seconds, and handling potential business exceptions. It notes that coordinates are returned in WGS-84 format. This resource is intended for application developers integrating location features such as check-ins or service recommendations.

### 示例代码.md 示例代码.md
This document serves as a reference index directing users to practical code examples within the OpenHarmony ecosystem. The primary takeaway is the external link to a GitCode repository containing Cangjie language samples for location services, indicating this file acts as a navigation hub rather than a standalone tutorial. The target audience includes OpenHarmony developers and Cangjie language programmers seeking implementation samples for device management and location tracking.

### 获取设备的位置信息开发指导_3more.md 获取设备的位置信息开发指导_3more.md
This development guide instructs developers on using location interfaces to obtain real-time or historical device location data and monitor location changes. The document covers a scenario overview that distinguishes between real-time tracking for sensitive applications and historical retrieval for power saving, followed by an interface description. Key information includes the use of the Location Kit module, specifically the getCurrentLocation and isLocationEnabled functions, with a note that only the WGS-84 coordinate system is supported. Targeted at application developers, this guide helps optimize location services for either accuracy or battery efficiency.
