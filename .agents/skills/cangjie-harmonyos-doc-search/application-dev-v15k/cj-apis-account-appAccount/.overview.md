# cj-apis-account-appAccount

This directory provides comprehensive API reference documentation for the HarmonyOS Application Account Management module, specifically tailored for the Cangjie programming language. It serves as a critical resource for developers aiming to implement secure account authentication, manage user credentials, and facilitate distributed data synchronization within their applications. The documentation covers essential functionalities such as account creation, credential verification, and the management of authentication tokens. It details key components like the `AppAccountManager` class and options for implicit account creation. This content is intended for HarmonyOS developers utilizing Cangjie who require robust tools to handle user identities and secure data access, relying on SystemCapability.Account.AppAccount starting from API version 19.

## Detailed Description

### [1] ohosaccountappAccount应用账号管理/
This directory contains API reference documentation for the HarmonyOS Application Account Management module (`ohos.account.appAccount`) specifically designed for the Cangjie programming language. It covers the core functionalities required for managing application accounts, including account creation, authentication, credential verification, and data synchronization. Key components include data structures for tokens, options for implicit account creation, and the central `AppAccountManager` class. This documentation is intended for HarmonyOS developers using Cangjie who need to implement secure account authentication, handle distributed data sync, and manage user credentials within their applications, relying on SystemCapability.Account.AppAccount starting from API version 19.
