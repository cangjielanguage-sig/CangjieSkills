# class_UnixServerSocket

This directory contains comprehensive API reference documentation for the `UnixServerSocket` class within the Cangjie programming language. It is dedicated to guiding developers through the implementation of host communication server-side services using Unix domain sockets. The content covers essential topics such as class initialization via file paths or socket addresses, configuration of properties like `backlogSize` and buffer sizes, and connection handling. This resource is suitable for Cangjie developers building network applications that require inter-process communication on Unix-like systems, noting that the class is incompatible with Windows platforms.

### class_UnixServerSocket_8more.md class_UnixServerSocket_8more.md
This document provides API reference documentation for the UnixServerSocket class in the Cangjie programming language, detailing how to implement host communication server-side services using Unix domain sockets. It covers class initialization via file paths or socket addresses, configuration properties like backlogSize, receiveBufferSize, and sendBufferSize, and the accept method for handling client connections. Key information includes the requirement to bind to a local address before listening and the limitation that this class is incompatible with Windows platforms. This technical reference targets Cangjie developers building network applications, specifically those requiring inter-process communication on Unix-like systems.
