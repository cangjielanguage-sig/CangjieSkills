# 组件属性

本目录包含ArkUI框架中关于组件属性配置的API参考文档，主要针对使用仓颉语言开发的字母索引条组件。内容涵盖了组件的对齐方式、颜色、字体、弹窗样式及选中状态等核心属性的设置方法。所有API均支持从API 22版本开始使用，旨在帮助开发者实现精细化的UI定制和交互体验优化。适合具备ArkUI开发基础并需要自定义组件外观的开发者阅读。

## 详细描述

### func_alignStyleIn_6more_83a53adf.md
本文档是ArkUI框架中字母索引条组件的API参考文档，旨在指导开发者使用仓颉语言配置组件样式。文档涵盖了六个主要配置函数：alignStyle、color、font、itemSize、popupBackground和popupColor。关键信息包括如何设置弹窗对齐方式、未选中项颜色、选中项字体样式、索引项区域大小以及弹窗的背景和文本颜色。所有函数均支持从API 22版本开始使用，并提供了详细的参数类型和默认值说明。该文档适合具备ArkUI开发基础的开发者阅读，用于实现精细化的UI定制。

### func_popupFontLen_5more_5f3e10d7.md
本文档提供了Cangjie语言中用于配置UI组件提示弹窗样式、位置及选中状态的API参考文档。主要涵盖了设置提示弹窗字体属性（大小、粗细、家族、样式）、弹窗相对位置坐标、选中项索引值以及选中项背景和文字颜色的函数。关键信息包括字体和位置的默认值（如24.vp、HarmonyOS Sans），所有函数均返回This以支持链式调用，且系统能力要求为ArkUI.Full，起始版本为22。面向使用Cangjie语言构建ArkUI界面的开发者，特别是需要自定义索引条或类似交互组件外观和行为的用户。

### func_selectedFont_2more_09e81d48.md
本文档是ArkUI开发中Cangjie语言的API参考文档，旨在说明如何配置选中项的文字样式及弹窗行为。文档主要包含selectedFont和usingPopup两个函数：前者用于设置字体大小、粗细、家族和样式，后者用于控制是否使用提示弹窗。关键信息涵盖了各参数的类型、默认值（如10.vp大小）及系统能力要求。这些函数均支持链式调用，面向需要精细定制UI组件外观和交互体验的ArkUI开发者，适用于构建具有特定视觉风格的应用界面。
