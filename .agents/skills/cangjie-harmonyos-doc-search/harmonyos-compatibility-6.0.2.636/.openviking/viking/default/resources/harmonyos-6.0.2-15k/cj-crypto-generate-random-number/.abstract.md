This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, specifically focusing on the generation of cryptographically secure random numbers. It utilizes the CryptoArchitectureKit to facilitate secure operations such as creating session keys and managing encryption processes. Key topics include the management of internal state, the application of random seeds, and the implementation of the CTR_DRBG algorithm. The guide provides a detailed walkthrough of the API workflow, from instance creation to data generation, leveraging OpenSSL's RAND_priv_bytes. This material is best suited for developers possessing a foundational understanding of encryption principles who wish to integrate robust random number generation into their Cangjie applications. The documentation ensures that users can effectively implement security standards required for modern cryptographic practices, covering everything from basic setup to advanced usage scenarios.
