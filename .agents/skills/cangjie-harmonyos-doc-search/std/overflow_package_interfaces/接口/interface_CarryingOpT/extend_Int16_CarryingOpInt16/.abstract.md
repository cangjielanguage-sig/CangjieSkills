This directory serves as a comprehensive repository for API reference documentation regarding the `CarryingOp` interface implementation specifically tailored for the `Int16` type within the Cangjie programming language. It functions as a critical technical guide for developers aiming to implement arithmetic operations equipped with robust overflow detection mechanisms. The content encompasses a wide array of functions, including carryingAdd, carryingMul, carryingSub, carryingDiv, carryingNeg, carryingShl, carryingShr, carryingInc, carryingDec, and carryingMod. Each function detailed herein utilizes a wrapping strategy and returns a tuple containing the calculation result paired with a Boolean flag to indicate overflow or truncation. This documentation is highly suitable for Cangjie developers who require precise, low-level control over integer arithmetic and need to ensure numerical stability and safety in their applications.
