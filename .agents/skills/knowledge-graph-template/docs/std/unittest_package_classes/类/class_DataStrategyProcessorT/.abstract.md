This directory contains API reference documentation for the `DataStrategyProcessor` class and its associated static initialization functions within the Cangjie programming language. It serves as the core infrastructure for property-based testing and data generation, covering the abstract base class definition, entry points for composing strategies, and advanced data manipulation extensions. Key topics include test case generation, shrinking logic, benchmarking, and strategy composition using methods like `map` and `flatMap`. This documentation is intended for developers implementing custom data strategies, utilizing the `@Strategy` macro, or working with the Cangjie unit testing framework to configure complex data processing flows.
