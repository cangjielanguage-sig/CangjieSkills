# cj-apis-contact

This directory serves as a comprehensive API reference repository for the `ohos.contact` module, specifically designed for developers utilizing the Cangjie programming language within the HarmonyOS ecosystem. It provides in-depth technical documentation for the ContactsKit framework, enabling the seamless integration of system-level contact data handling into applications. The content covers the entire lifecycle of contact management, including creating, querying, updating, and deleting contacts, as well as managing contact groups and user profiles. Furthermore, it details the necessary system permissions and complex data structures such as `ContactAttributes`, alongside specific attribute types like Email, Phone, and Address. By providing precise function signatures and structural definitions, this documentation empowers developers to build secure, contact-centric applications with robust data manipulation capabilities. It is an essential resource for software engineers aiming to leverage native HarmonyOS contact features efficiently and effectively.
