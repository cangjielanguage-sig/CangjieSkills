# 鼠标光标控制

This directory focuses on mouse cursor control within the HarmonyOS ArkUI framework using the Cangjie language. It covers the `CursorControl` class for manipulating cursor styles programmatically and the `PointerStyle` enumeration for defining specific visual appearances. Key topics include setting custom cursors, restoring defaults, and handling UI events like hover and click. This resource is suitable for application developers and UI/UX designers looking to enhance user interaction and feedback through dynamic cursor management in their applications.

### 鼠标光标控制_2more.md 鼠标光标控制_2more.md
This document serves as an API reference for the CursorControl class, designed to manage mouse cursor display styles within the ArkUI framework using the Cangjie language. It details the class definition and two primary static methods: setCursor for modifying the cursor appearance using a PointerStyle parameter, and restoreDefault for resetting it to the standard arrow. Key information includes system capabilities, version requirements starting from 19, and parameter descriptions. Targeted at application developers working on UI interactions, this guide enables the programmatic manipulation of cursor states to enhance user experience.

### enum_PointerStyle/
This directory provides comprehensive API documentation for the `PointerStyle` enumeration within the ArkUI framework, specifically tailored for the Cangjie programming language. It serves as a vital technical resource for defining and managing mouse cursor styles and interaction modes during application development. The content covers a wide array of visual indicators, including directional arrows, window resizing handles, hand gestures for dragging, and system status animations such as loading or processing states. By utilizing these constants, developers can ensure consistent and intuitive user feedback across different interface actions, significantly enhancing the overall user experience and accessibility of the software. This documentation is primarily suitable for software developers, UI/UX designers, and system engineers working on ArkUI-based applications who require detailed knowledge of cursor behaviors and system capabilities. All resources listed here require the SystemCapability.ArkUI.ArkUI.Full capability and are available starting from API version 19.
