# server

This directory serves as a comprehensive resource for developers working with the Cangjie programming language to build robust HTTP servers. It encompasses a wide range of topics, from basic server construction and request distribution to advanced network features. Key areas of focus include implementing HTTP/2 Server Push for performance optimization, utilizing chunked transfer encoding with trailers, and managing secure connections via TLS configuration and hot reloading. These guides are tailored for developers who possess a foundational understanding of network protocols and wish to leverage Cangjie's standard libraries to create secure, dynamic, and efficient web applications.

## Detailed Description

### response_中的_chunked_与_trai_3more.md
This document serves as a practical guide for implementing advanced HTTP server features using the Cangjie language. It covers three distinct topics: utilizing chunked transfer encoding with trailers for metadata, handling HTTP redirects via specific handlers, and performing hot reloading of TLS certificates. Key takeaways include using HttpResponseWriter for chunked data, registering RedirectHandler for status 308 redirects, and calling updateCert or updateCA to refresh security credentials without server downtime. This tutorial targets developers building secure, dynamic web servers who need to manage data streaming, routing, and certificate lifecycle.

### server_5more.md
This tutorial provides code examples for building HTTP servers in the Cangjie programming language using the stdx.net.http library. It covers creating a basic server, registering multiple handlers via a request distributor, implementing custom distributors and handler classes, and configuring advanced network options like TLS and transport buffers. Key concepts include ServerBuilder, HttpRequestHandler, and HttpRequestDistributor. The document targets Cangjie developers, requiring knowledge of HTTP protocols and file I/O, particularly for the TLS configuration section which needs user-provided certificates.

### server_push.md
This document provides a practical tutorial on implementing HTTP/2 Server Push using the Cangjie language, specifically demonstrating how to send and receive pushed resources. The content is divided into client and server examples, detailing the necessary TLS configurations, request handling, and the specific mechanisms for pushing data. Key takeaways include the requirement for ALPN protocols set to "h2" and the use of HttpResponsePusher on the server and response.getPush() on the client to handle the asynchronous resource transfer. Intended for developers with knowledge of Cangjie and network programming, this guide assumes users can provide their own TLS certificates and understand HTTP/2 concepts.
