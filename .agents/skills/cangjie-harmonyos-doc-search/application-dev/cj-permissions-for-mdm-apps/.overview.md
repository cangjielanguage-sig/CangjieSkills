# cj-permissions-for-mdm-apps

This directory serves as a specialized technical repository for developers and system integrators focusing on Mobile Device Management (MDM) solutions within the OpenHarmony and HarmonyOS ecosystems. It centralizes documentation regarding the exclusive permissions required for enterprise-grade applications to perform advanced device administration tasks that standard apps cannot execute. The content covers critical areas such as granular network control, application lifecycle management, rigorous security policy enforcement, and deep system settings modification. By detailing `system_grant` authorization levels, ACL (Access Control List) enablement, and specific requirements for API version 12, this guide provides the necessary framework for implementing secure and compliant device management features. It is an essential resource for enterprise developers, system architects, and security professionals aiming to build robust administrative controls for managed devices, ensuring that applications adhere to the strict security protocols of the operating system.

## Detailed Description

### 仅MDM应用可用权限/

This subdirectory acts as the definitive reference for understanding and implementing permissions that are strictly reserved for Mobile Device Management (MDM) and enterprise applications. Unlike standard application permissions, these authorizations grant system-level access necessary for comprehensive device administration. The documentation details the specific privileges required to manage network configurations, control application installation and removal, enforce security policies, and modify system settings programmatically. This level of access is critical for maintaining the integrity and security of enterprise device fleets.

Furthermore, the guide provides crucial technical specifications regarding the implementation of these permissions. It explains the nuances of `system_grant` authorization levels, which are automatically granted upon installation rather than requested from the user, and the process for ACL (Access Control List) enablement to access sensitive APIs. It also addresses the specific requirements introduced in API version 12, ensuring compatibility with the latest system updates and features. Finally, it outlines the manual configuration protocols necessary for signing applications correctly, ensuring that enterprise apps can legitimately utilize these powerful capabilities without triggering security blocks. This documentation is vital for developers who need to navigate the complex security landscape of managed devices and ensure their applications comply with OpenHarmony and HarmonyOS standards.
