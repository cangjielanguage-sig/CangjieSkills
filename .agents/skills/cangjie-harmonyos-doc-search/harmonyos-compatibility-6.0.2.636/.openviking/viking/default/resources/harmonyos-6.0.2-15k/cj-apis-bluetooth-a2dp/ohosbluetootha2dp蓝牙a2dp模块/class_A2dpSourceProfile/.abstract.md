This directory contains API reference documentation for the `A2dpSourceProfile` class in the Cangjie programming language, part of the HarmonyOS ConnectivityKit. It covers the management of Bluetooth A2DP source connections, including listing connected devices, querying connection states, retrieving playback status, and handling event subscriptions. Key topics include connection management, callback registration and deregistration, and comprehensive error handling. This documentation is suitable for HarmonyOS developers and system developers who are implementing Bluetooth audio source functionalities and need to manage device states and events within their applications.
