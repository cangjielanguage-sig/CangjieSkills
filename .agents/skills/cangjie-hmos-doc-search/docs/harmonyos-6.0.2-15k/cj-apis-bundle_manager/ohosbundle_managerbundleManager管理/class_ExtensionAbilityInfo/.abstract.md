This directory provides API reference documentation for the `ExtensionAbilityInfo` class in the Cangjie programming language, focusing on the structure and properties of extension ability information. It covers essential metadata such as bundle names, module names, permissions, and application info, alongside specific configuration properties like skills and write permissions. The documentation highlights version-specific features, including the `appIndex` for clone applications and the availability of certain properties starting from API version 12 or 19. This resource is designed for application developers utilizing the BundleManager framework to effectively retrieve and manage extension ability configurations.
