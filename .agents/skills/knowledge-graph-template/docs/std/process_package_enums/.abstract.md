This directory serves as a specialized API reference for the `process_package_enums` module within the Cangjie programming language ecosystem. It is specifically designed to assist developers in understanding and implementing process management features, with a primary focus on the `ProcessRedirect` enumeration. This enumeration is fundamental for configuring standard stream redirection—such as standard input, output, and error streams—when creating and managing child processes. The documentation provides a deep dive into four distinct enumeration variants: Inherit, Pipe, FromFile(File), and Discard. Each variant offers a unique method for handling process I/O, ranging from utilizing parent process streams to enabling complex inter-process communication via pipes or redirecting to specific file instances. This resource is highly suitable for Cangjie developers, systems programmers, and backend engineers who need to build robust applications that spawn external processes. By mastering these enums, developers can ensure precise control over data flow, error handling, and process isolation, which are critical for high-performance and reliable software systems. The guide ensures that users can select the appropriate redirection strategy for their specific use case, whether it involves logging output to a file, capturing data for processing, or silencing unnecessary noise.
