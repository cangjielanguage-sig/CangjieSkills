# class_SoundPool

This directory contains API reference documentation for the `SoundPool` class in the Cangjie programming language, designed for managing and playing audio resources in multimedia applications. Developers can also control audio properties including volume, rate, and priority. This documentation is suitable for multimedia developers using the HarmonyOS MediaKit and AudioKit frameworks who need to implement efficient sound effects and audio playback logic.
