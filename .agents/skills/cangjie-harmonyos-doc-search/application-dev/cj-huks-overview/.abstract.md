This directory provides a comprehensive overview of the Universal Keystore Kit (HUKS), a unified service framework designed for secure key management and cryptographic operations. It details the system's robust three-layer architecture, which includes the SDK, Service Layer, and Core Layer, with a strict emphasis on the Core Layer operating within a Trusted Execution Environment (TEE) to ensure maximum security. The content covers the entire key lifecycle, categorizing functions into generation, usage (such as encryption, signing, agreement, and derivation), deletion, and attestation. A critical security feature highlighted is the guarantee that key plaintexts never exit the secure environment. This documentation is specifically tailored for developers and OEMs who need to implement secure key storage and cryptographic capabilities in their systems. Keywords: HUKS, Keystore, Cryptography, Key Management, TEE, Security, Key Attestation.
