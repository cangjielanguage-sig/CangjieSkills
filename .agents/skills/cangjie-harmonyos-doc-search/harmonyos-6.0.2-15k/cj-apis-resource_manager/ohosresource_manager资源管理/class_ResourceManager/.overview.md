# class_ResourceManager

This directory contains API reference documentation for the Cangjie ResourceManager class within the HarmonyOS ecosystem. It covers comprehensive methods for accessing and managing application and system resources, including strings, booleans, colors, media, and raw files. Key topics include resource localization, cross-package access via AppResource, runtime resource overlays, and device capability adaptation. Designed for Cangjie developers using LocalizationKit and AbilityKit, these documents provide the necessary interfaces to dynamically load resources, handle internationalization, and manage application assets efficiently.
