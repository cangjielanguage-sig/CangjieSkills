# 基于设备分类和数据分级的访问控制

本目录主要介绍在分布式数据管理中，如何通过设备分类和数据分级来保障数据安全。涵盖了关系型数据库和键值型数据库的数据分级实现方法，以及跨设备同步时的访问控制机制。核心内容包括数据安全标签（S1-S4）、设备安全等级（SL1-SL5）的定义与匹配规则，以及使用仓颉语言进行数据库安全配置的具体代码示例。适用于需要进行数据安全管理和分布式应用开发的开发人员。

## 详细描述

### 使用关系型数据库实现数据分级
本文档旨在指导开发者如何使用仓颉语言创建具有特定安全等级（S1）的关系型数据库。主要包含获取应用上下文和配置数据库安全等级两个步骤，详细展示了相关代码实现。核心要点在于通过StoreConfig设置RelationalStoreSecurityLevel.S1参数，并调用getRdbStore接口来初始化数据库，涉及ArkData和AbilityKit等关键包。适用于使用仓颉语言进行应用开发的开发人员，需具备基础的数据库编程知识和对应用生命周期的理解。

### 使用键值型数据库实现数据分级
本文档是一份技术教程，旨在指导开发者使用键值型数据库实现数据分级。文档详细介绍了通过securityLevel参数设置数据库安全等级（如S1）的流程，包含获取上下文和创建数据库的Cangjie代码示例。重点阐述了安全等级升级的注意事项：该操作仅限单设备场景，需关闭数据库后重开，仅支持升级且不支持跨设备同步。本文适用于使用ArkData框架进行数据安全管理的开发人员，关键词包括键值型数据库、数据分级、KVOptions和Cangjie。

### 基于设备分类和数据分级的访问控制机制
本文档旨在阐述分布式数据管理中基于设备分类和数据分级的访问控制机制，保障数据跨设备同步安全。主要内容包括数据安全标签（S1-S4）与设备安全等级（SL1-SL5）的定义及对应的风险标准，以及跨设备同步的访问控制矩阵。关键信息在于数据仅能同步至安全等级不低于其数据标签的设备，文档还提供了查询设备安全等级的命令。本文面向分布式数据库开发人员，指导其在创建数据库时依据数据分类规范合理设置安全标签。
