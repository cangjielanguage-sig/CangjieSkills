This directory contains API reference documentation for the Cangjie `PhotoAccessHelper` class, which facilitates the access, management, and monitoring of image and video resources. It covers core functionalities such as retrieving media assets and albums, managing file modifications, and registering change listeners. Key topics include system permissions like `READ_IMAGEVIDEO` and `WRITE_IMAGEVIDEO`, `FetchOptions`, and exception handling. This documentation is suitable for Cangjie developers building file management features or media applications who need to interact with system photo libraries and handle resource lifecycles.
