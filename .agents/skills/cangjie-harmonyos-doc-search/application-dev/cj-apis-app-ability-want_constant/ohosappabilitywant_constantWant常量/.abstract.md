This directory contains API reference documentation for the `want_constant` module within the HarmonyOS Cangjie AbilityKit. It focuses on system-predefined constants and enumerations used to configure `Want` objects for application navigation, inter-component communication, and ability lifecycle management. Key topics include URI permissions, atomic service installation, parameter keys for system behaviors, and cross-device migration. This resource is suitable for HarmonyOS developers using the Cangjie language who need to implement specific startup behaviors, manage data access permissions, and configure application capabilities.
