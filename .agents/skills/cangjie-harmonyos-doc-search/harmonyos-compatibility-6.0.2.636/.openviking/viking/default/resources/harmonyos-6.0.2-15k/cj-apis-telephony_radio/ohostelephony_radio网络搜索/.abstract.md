This directory contains API reference documentation for the OpenHarmony telephony radio network search module, specifically designed for the Cangjie programming language. It covers essential data structures and enumerations for managing network registration, signal strength, radio technologies, and 5G NSA states. The content includes classes like NetworkState and SignalInformation, alongside enums for network selection and registration states. It is suitable for Cangjie developers building telephony applications who need to query device connectivity, interpret radio access technologies, and handle network status changes within the SystemCapability.Telephony.CoreService framework.
