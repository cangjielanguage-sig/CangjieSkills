# cj-apis-rpc-interop

This directory serves as the central repository for API documentation regarding the `cj-apis-rpc-interop` module, specifically designed to facilitate advanced interoperability between Cangjie IPC objects and ArkTS environments. It provides a comprehensive guide to the `ohos.rpc.interop` module, detailing essential functions and interfaces such as `fromJSValue` and `SystemObjectInteropTypeToJS`. The documentation focuses on enabling bidirectional conversion methods that allow service providers and proxies to interact seamlessly within ArkTS contexts, utilizing `JSContext` as the primary bridge for communication. This resource is indispensable for HarmonyOS developers and system architects who are tasked with implementing complex IPC scenarios requiring robust and efficient cross-language communication between Cangjie and ArkTS.

## Detailed Description

### cj-apis-rpc-interop.md

This API reference document details the interoperability capabilities between Cangjie IPC objects and ArkTS environments within the ohos.rpc.interop module. It covers the fromJSValue function for converting ArkTS JSValue to IRemoteObject, and the SystemObjectInteropTypeToJS interface implemented by RemoteObject and RemoteProxy classes. Key information includes bidirectional conversion methods allowing service providers and proxies to interact with ArkTS contexts, utilizing JSContext as the bridge. This guide targets HarmonyOS developers requiring cross-language communication between Cangjie and ArkTS in IPC scenarios.
