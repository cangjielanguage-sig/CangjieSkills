This directory serves as a comprehensive resource for the HarmonyOS Bluetooth Hands-Free Profile (HFP) module, specifically designed for developers using the Cangjie programming language. It encompasses the full scope of API reference documentation needed to implement Bluetooth call interfaces effectively. The content focuses heavily on the Hands-Free Audio Gateway (AG) profile, covering critical aspects such as module imports, system capabilities, and necessary permissions. Developers will find detailed guidance on profile instantiation, connection management, and state monitoring. This documentation is ideal for HarmonyOS developers leveraging the ConnectivityKit to create robust Bluetooth applications that require advanced HFP AG features, provided they have a working knowledge of Cangjie syntax and application context configuration.
