This directory provides technical documentation for implementing RSA encryption and decryption using the PKCS1_OAEP padding mode. It covers the construction of configuration strings, compatibility matrices for various key sizes (RSA512 to RSA8192), and constraints regarding digest algorithms and Mask Generation Functions (MGF). The resources explain how to format parameters using the "Key|Padding|Digest|MaskDigest" syntax and handle key length attributes dynamically. This collection is suitable for developers and security engineers who need to ensure parameter compatibility, manage data size limits, and correctly configure cryptographic libraries for secure operations.
