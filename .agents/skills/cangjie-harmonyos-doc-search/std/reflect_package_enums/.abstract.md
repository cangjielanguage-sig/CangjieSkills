This directory contains comprehensive API reference documentation for the enumeration types utilized within the Cangjie reflection package. It specifically focuses on the `ModifierInfo` enum, a fundamental component for representing and identifying code modifiers during runtime type inspection. The documentation thoroughly details the enum's specific values, including `Open`, `Mut`, `Static`, and `Abstract`, while providing important context regarding the exclusion of access control modifiers—explaining that reflection only exposes public types. Furthermore, it documents standard inherited methods such as `hashCode`, `toString`, and equality operators, which adhere to standard enum semantics. This resource is designed for developers and engineers working with the Cangjie language who require the ability to programmatically analyze class or function modifiers and perform deep introspection on code structures at runtime.
