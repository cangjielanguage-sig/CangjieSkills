This directory contains API reference documentation for fundamental layout classes and enumerations in the Cangjie language within the ArkUI framework. It covers definitions for barriers and guidelines used to create complex, responsive UI layouts. Key components include `BarrierStyle`, `GuideLineStyle`, `GuideLinePosition`, and localized barrier configurations supporting internationalization. These resources are essential for ArkUI developers who need to implement dynamic layout constraints, alignment rules, and adaptive interfaces in HarmonyOS applications.
