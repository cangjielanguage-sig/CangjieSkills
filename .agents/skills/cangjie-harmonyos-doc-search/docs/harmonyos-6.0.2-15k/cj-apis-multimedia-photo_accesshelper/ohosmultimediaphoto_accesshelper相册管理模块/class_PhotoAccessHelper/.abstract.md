This directory contains API reference documentation for the `PhotoAccessHelper` class in the Cangjie programming language, designed for HarmonyOS development. It covers the management of image and video resources, including retrieving assets, handling albums, monitoring changes, and managing user permissions. Key functionalities include fetching media with predicates, registering and unregistering change listeners, and triggering system dialogs for asset creation. This documentation is suitable for developers building file management or media-centric applications who need to interact with the system media library using the MediaLibraryKit.
