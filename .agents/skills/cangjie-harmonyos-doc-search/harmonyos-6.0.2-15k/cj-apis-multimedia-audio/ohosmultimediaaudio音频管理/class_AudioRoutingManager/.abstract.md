This directory contains API reference documentation for the `AudioRoutingManager` class within the Cangjie programming language and AudioKit framework. It covers the management of audio routing operations, including device discovery, selection, and monitoring of connection status changes. Key functionalities include retrieving available and preferred devices, setting communication device states, and registering callbacks for dynamic audio events. This documentation is suitable for developers working on multimedia applications in the HarmonyOS environment who need to handle complex audio device routing and system-level event handling.
