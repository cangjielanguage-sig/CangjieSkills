# 示例代码

This directory contains a comprehensive set of practical code examples designed to demonstrate how to implement custom page transition animations within the ArkUI framework using the Cangjie language. It covers essential techniques for configuring entry and exit effects, including scaling, opacity changes, and translation movements. The examples utilize `PageTransitionEnter` and `PageTransitionExit` to manipulate visual properties based on transition progress and route types. These resources are highly suitable for ArkUI developers seeking to enhance user experience through dynamic navigation effects and smooth visual transitions between application pages. By studying these examples, developers can learn to control animation parameters such as duration and curve types effectively to create polished interfaces.

## Detailed Description

### 示例代码1设置退入场动画.md 示例代码1设置退入场动画.md
This document serves as a code tutorial demonstrating how to configure custom page entry and exit animations in ArkUI using the Cangjie language. The content comprises two primary code examples, index.cj and page1.cj, which implement the pageTransition method to handle navigation effects. Key takeaways include the usage of PageTransitionEnter and PageTransitionExit to manipulate component properties like scale and opacity based on transition progress and route types. The example highlights specific animation parameters such as duration (1200ms) and curve types (Linear, Ease). This guide targets ArkUI developers looking to implement dynamic visual transitions between application pages.

### 示例代码2设置退入场平移效果.md 示例代码2设置退入场平移效果.md
This document provides a code example demonstrating how to configure page entry and exit translation effects using the Cangjie language in an ArkUI application. It covers two main source files, index.cj and page1.cj, which define the main entry view and a secondary page. The key takeaway is the implementation of the pageTransition method, utilizing PageTransitionEnter and PageTransitionExit with specific SlideEffect directions and durations to create smooth navigation animations. This tutorial targets developers using the ArkUI framework and Cangjie language who need to implement custom page transition animations in their applications.
