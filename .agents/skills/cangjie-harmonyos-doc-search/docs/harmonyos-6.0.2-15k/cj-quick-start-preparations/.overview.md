# cj-quick-start-preparations

This directory acts as the foundational resource hub for developers initiating Cangjie application development on the HarmonyOS platform. It is designed to bridge the gap between general programming knowledge and the specific requirements of the HarmonyOS ecosystem. The content focuses heavily on the preparatory phase, detailing the necessary software tools, specifically DevEco Studio, and the theoretical underpinnings of the operating system's architecture, such as the Stage application model and UI framework. Furthermore, it provides a roadmap for various development approaches, distinguishing between pure Cangjie projects and hybrid scenarios that involve integration with ArkTS. By outlining the available quick start tutorials, this directory helps developers identify the right learning path for their specific needs, whether they are building simple page navigation or complex applications utilizing third-party modules. This resource is ideal for novice developers, students, or anyone transitioning to the HarmonyOS ecosystem who needs a structured overview of the environment and core concepts prior to coding.

### cj-quick-start-preparations.md cj-quick-start-preparations.md

This document serves as the primary preparation guide for beginners starting Cangjie application development on HarmonyOS. It is structured to provide a holistic view of the initial development phase, ensuring no critical steps are missed. The text covers basic concepts including the UI framework and the Stage application model, which are crucial for understanding how applications are structured and run on the OS. Additionally, it outlines available quick start tutorials for both pure and hybrid development, giving users clear options based on their project requirements. The guide also details tool requirements like DevEco Studio, ensuring developers have the correct software installed and configured. Key takeaways include understanding that Cangjie apps utilize the Stage model for efficient development and accessing tutorials for building apps with page navigation, integrating with ArkTS, and calling third-party modules. This guide targets novice developers requiring an overview of the development environment and core concepts before building their first application.
