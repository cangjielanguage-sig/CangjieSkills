# 文本输入TextInputTextArea

This directory focuses on implementing text input components using the ArkUI framework and the Cangjie language. It covers the creation and configuration of single-line `TextInput` and multi-line `TextArea` components, including input types like passwords and emails. Additionally, it details event handling for user interactions such as content changes and submission, as well as advanced features like selection menus, auto-fill, and keyboard avoidance. This resource is suitable for UI developers building interactive forms, chat interfaces, or login pages who need to manage text entry and user input behaviors effectively.

## Detailed Description

### 文本输入TextInputTextArea_4more.md 文本输入TextInputTextArea_4more.md
This document provides a usage guide for implementing text input components, specifically TextInput and TextArea, within the ArkUI framework using the Cangjie language. It covers three main topics: creating single-line and multi-line input boxes, configuring specific input types such as passwords, emails, or numbers, and customizing visual styles like placeholders and background colors. Key takeaways include the distinction between TextInput for single entries and TextArea for auto-wrapping multi-line text, along with the use of the setType method for validation. The guide targets UI developers building interactive forms, chat interfaces, or login pages, requiring basic knowledge of Cangjie syntax and ArkUI component properties.

### 添加事件.md 添加事件.md
This document serves as a technical guide for implementing event handling on the TextInput component within the Cangjie development framework. It covers text input events like content changes, submission, selection tracking, and password visibility toggling, alongside lifecycle events for text insertion and deletion. The code example demonstrates binding specific callbacks such as onChange, onSubmit, and onSecurityStateChange, while noting that insertion and deletion callbacks only support system input methods. Targeted at developers using the Cangjie language for UI development, this reference material requires basic knowledge of component properties and event-driven programming.

### 选中菜单_3more.md 选中菜单_3more.md
This technical guide explains text input interaction features in the Cangjie UI framework, specifically focusing on selection menus, auto-fill, and keyboard avoidance. The document covers the selection menu for TextInput and TextArea, configuring auto-fill types via the contentType property, and implementing keyboard avoidance using scrollable containers. Key takeaways include the default availability of cut, copy, and translate options, the use of ContentType enums for specific inputs like email addresses, and the requirement to wrap components in Scroll, List, or Grid to ensure keyboard avoidance works during screen rotation. This guide targets UI developers using the Cangjie framework who need to implement advanced text input behaviors and layout adjustments.
