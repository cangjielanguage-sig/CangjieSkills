### ohosresource_manager资源管理/
This directory contains API reference documentation for the `ohos.resource_manager` module in the Cangjie programming language, designed for HarmonyOS application development. It covers the core classes and enumerations necessary for managing application resources, handling device configurations, and adapting to different screen densities and locales.

The documentation highlights several key components essential for modern app development:
*   **ResourceManager**: The central class for accessing application resources programmatically.
*   **AppResource**: Represents resource objects and facilitates their usage within the app logic.
*   **Configuration**: Allows the app to query and react to current device states, such as orientation and mode.

Furthermore, it details various enums for device types and display modes, providing granular control over UI behavior. This documentation is suitable for Cangjie developers who need to programmatically access resources, implement multi-language support, and ensure their applications adapt seamlessly to diverse device capabilities and user settings.
