This directory serves as a technical resource for Cangjie developers working within the HarmonyOS ecosystem, focusing on the selection and access of media library resources. It details the implementation of the system picker interface to select images and videos without requiring explicit user permissions, a critical feature for privacy and ease of use. Furthermore, it provides in-depth instructions on how to process the resulting URIs to read file data or retrieve media assets. Key technical areas include configuring `MPhotoSelectOptions`, managing `PhotoSelectResult`, utilizing the `FileFs` API for raw data access, and leveraging `MediaLibraryKit` for asset management. This guide is essential for developers building UIAbility components that require robust media file integration.
