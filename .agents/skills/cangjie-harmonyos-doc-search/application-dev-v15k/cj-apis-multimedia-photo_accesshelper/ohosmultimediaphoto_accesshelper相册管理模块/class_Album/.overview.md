# class_Album

This directory provides comprehensive API reference documentation for the `Album` class within the Cangjie language, specifically tailored for HarmonyOS developers building media-rich applications. It focuses on the system's file management framework, detailing how to manage photo albums effectively. Key functionalities include accessing album metadata (such as names, types, URIs, and content counts), modifying album properties, and persisting these changes to the database using specific write permissions. Additionally, it covers methods for retrieving media assets like images and videos using fetch options. This resource is essential for developers utilizing the MediaLibraryKit who require programmatic control over photo library data, ensuring they can handle permissions, error codes, and data fetching efficiently in their applications.

## Detailed Description

### class_Album_10more.md
This document serves as an API reference for the Album class in the Cangjie language, specifically for managing photo albums within the system's file management framework. It outlines properties for accessing album metadata, including albumName, albumType, albumUri, and content counts for images and videos. Additionally, it documents the commitModify() method, which is essential for persisting property changes to the database, requiring specific write permissions. Key takeaways include the read-only nature of most properties versus the mutable albumName, and the error handling associated with database updates. This guide is intended for developers building media applications who need to programmatically interact with and modify photo album data.

### func_getAssetsFetchOptions.md
This document serves as API reference documentation for the Cangjie function getAssets, which retrieves image and video files from a specific album. It details the function signature, required permissions like READ_IMAGEVIDEO, system capabilities, and supported versions. The content covers input parameters using FetchOptions, the return type FetchResult containing PhotoAsset objects, and potential BusinessException error codes. A practical code example demonstrates how to initialize the helper, set predicates, and fetch assets from an album. The target audience is HarmonyOS developers using the MediaLibraryKit who need to access and manage photo library data programmatically.
