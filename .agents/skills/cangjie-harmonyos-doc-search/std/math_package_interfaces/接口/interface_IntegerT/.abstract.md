This directory contains comprehensive API documentation for the `Integer` interface within the Cangjie programming language. It serves as a central reference for understanding the generic structure, inheritance hierarchy, and specific implementations of various integer types. The content covers the core interface definition, including essential methods, operator overloads for arithmetic and bitwise operations, and the static `isSigned` function. Furthermore, it details extensions for a wide range of numeric types, including signed types like Int8, Int16, Int32, Int64, and IntNative, as well as unsigned types such as UInt8, UInt16, UInt32, UInt64, and UIntNative. This documentation is primarily suitable for Cangjie developers who need to verify type properties, ensure interface compliance, and implement robust numeric operations in their applications.
