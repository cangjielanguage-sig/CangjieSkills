This directory contains a specialized technical guide focused on the generation of cryptographically secure random numbers, a fundamental requirement for modern security applications. It specifically targets developers working with the Cangjie programming language, utilizing the robust Cangjie CryptoArchitectureKit. The content covers the theoretical and practical aspects of creating secure random numbers, which are essential for tasks such as generating session keys and performing encryption operations. Key technical topics include the management of internal state, the importance of random seeds, and the implementation of the CTR_DRBG algorithm. The guide also highlights the integration with OpenSSL's `RAND_priv_bytes` interface to ensure high-grade security. By following this resource, developers can ensure their applications resist prediction attacks, a critical aspect of maintaining system integrity. It is designed for developers who possess a basic understanding of encryption concepts and are looking for a practical, step-by-step approach to implementing these features using specific API functions like `createRandom`, `setSeed`, and `generateRandom`.
