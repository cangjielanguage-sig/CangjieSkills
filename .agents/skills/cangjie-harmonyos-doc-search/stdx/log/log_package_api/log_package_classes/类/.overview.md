## 详细描述

### class_LogRecord_c1df5dd3.md class_LogRecord_c1df5dd3.md
这是一份Cangjie语言中LogRecord类的API参考文档，用于定义日志消息的负载结构。文档主要包含初始化构造函数，用于设置时间戳、级别、消息及属性键值对；详细列出了attrs、level、message和time等属性，用于访问和修改日志数据；以及clone方法用于对象复制。关键信息指出LogRecord由Logger自动创建并传递给日志提供者。该文档面向使用日志库的开发者，旨在帮助其理解日志记录的内部数据封装。关键词：LogRecord, Cangjie, 日志记录, API文档, 属性, 克隆。

### class_NoopLogger_437b3bd3.md class_NoopLogger_437b3bd3.md
本文档是 Cangjie 语言中 NoopLogger 类的 API 参考文档，主要介绍了一个 Logger 接口的无操作实现，用于丢弃所有日志。文档涵盖了类定义、构造函数 init、level 属性以及 close、isClosed、log 和 withAttrs 等核心方法。关键信息指出，NoopLogger 继承自 Logger，其 level 属性始终为 OFF 且不可更改，所有日志记录方法均为空实现。该文档面向需要静默日志处理或进行单元测试的开发者，提供了完整的接口规范和参数说明。

### class_LogWriter/
本目录包含仓颉语言中 `LogWriter` 抽象类及相关函数的 API 参考文档，主要涉及将对象序列化至日志输出目标的核心能力。内容涵盖了用于构建日志结构的 `start`/`end` 方法，以及写入 `Bool`、`Int64`、`Float64`、`String` 等多种数据类型的 `write` 方法。文档详细说明了 `LogWriter` 与 `LogValue` 接口的配合使用，以及在状态异常时抛出 `IllegalStateException` 的错误处理机制。核心关键词包括仓颉语言、日志序列化、API参考及抽象类。

### class_Logger/
本目录包含仓颉编程语言中 Logger 类的 API 参考文档，主要涵盖日志打印、管理及属性控制功能。核心内容包括 Logger 抽象类定义、继承自 Resource 的关系、日志级别控制（如 debug、info、error 等），以及支持懒加载的通用日志函数。此外，还介绍了用于创建包含特定属性 Logger 副本的方法。该文档适合需要实现结构化日志记录和分级管理的仓颉开发者查阅。
