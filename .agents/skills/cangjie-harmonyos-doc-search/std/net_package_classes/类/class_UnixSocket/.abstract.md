This directory contains API reference documentation for the `UnixSocket` class in the Cangjie programming language. It covers the implementation of client-side duplex stream-based communication using Unix domain sockets. Key topics include socket initialization, connection management, configuration options (buffer sizes, timeouts), data transmission (read/write), and socket state manipulation. The documentation highlights platform limitations (incompatible with Windows) and exception handling. It is suitable for Cangjie developers building network applications that require inter-process communication (IPC) on Unix-like systems, specifically those needing low-level socket control and stream data handling.
