# 安全单元访问开发指南

This directory serves as a comprehensive technical resource for developers seeking to integrate Secure Element (SE) functionality into HarmonyOS applications using the Cangjie programming language. It thoroughly covers the architecture of secure hardware, including eSE and NFC-enabled SIM cards, and outlines the critical APIs required for secure connectivity. The guide addresses key development tasks such as verifying device capabilities, managing sessions, opening logical channels, and transmitting APDU commands. It is specifically designed for mobile application developers and system engineers who need to implement robust security features like NFC card simulation, ensuring proper access control and resource management throughout the development lifecycle.

## Detailed Description

### 主要场景开发步骤.md 主要场景开发步骤.md
This document provides a step-by-step tutorial for developers on how to access and interact with a Secure Element (SE) within an application using the Cangjie programming language. It covers importing necessary modules, verifying device capabilities, and the specific implementation flow including service creation, reader selection, session management, logical channel opening, data transmission, and resource cleanup. The code example demonstrates filtering for a SIM reader, using an AID array to open a channel, and transmitting command data, emphasizing the importance of closing channels to release resources. This guide targets mobile application developers working on HarmonyOS or similar platforms who need to implement secure element communication features.

### 简介_3more.md 简介_3more.md
This document provides an introduction to Secure Elements (SE), defining types like eSE and NFC-enabled SIM cards. It covers usage scenarios where applications access SEs to simulate NFC cards, highlighting the requirement for access control permissions. Key information includes a summary of essential APIs for managing SE connections, such as createService, getReaders, openSession, and transmit for APDU communication. This technical guide is intended for developers implementing secure connectivity features, offering a foundational overview of SE architecture and interface usage.
