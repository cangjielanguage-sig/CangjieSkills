# class_HuksKeySize

This directory contains API reference documentation for the `HuksKeySize` class within the HarmonyOS Universal KeyStore (HUKS) framework. It focuses on defining static constants used to specify cryptographic key lengths for various algorithms such as RSA, ECC, AES, SM4, and 3DES. These constants, implemented as `HuksParamValue` types in the Cangjie language, allow developers to configure valid key parameters for secure operations. The documentation is intended for HarmonyOS developers working with API version 15 and above who need to ensure precise key size configuration for encryption and decryption tasks.

## Detailed Description

### class_HuksKeySize.md class_HuksKeySize.md
This API reference document defines the HuksKeySize class, which provides static constants for specifying cryptographic key lengths within the HarmonyOS Universal KeyStore framework. The content enumerates key size parameters for various algorithms, including RSA, ECC, AES, DH, SM2, SM4, DES, and 3DES. Key takeaways include that all constants are HuksParamValue types wrapping uint32 integers, representing specific bit lengths such as 2048 for RSA or 256 for AES. The class requires the SystemCapability.Security.Huks.Extension system capability and is available starting from version 15. This documentation targets developers using the Cangjie language who need to configure valid key parameters for secure cryptographic operations.
