# 组件级像素取整

This directory covers the component-level pixel rounding feature in the ArkUI framework for HarmonyOS development using the Cangjie language. It addresses visual anomalies like 1px gaps caused by sub-pixel rendering. Key topics include the `PixelRoundPolicy` class, the `pixelRound` function, and practical code examples for precise UI layout control. This resource is suitable for UI developers and engineers working on API version 19 and above who need to ensure high-fidelity rendering and alignment in their applications.

## Detailed Description

### 基础类型定义.md 基础类型定义.md
This API reference document defines the Cangjie class `PixelRoundPolicy`, used to specify pixel rounding directions for ArkUI components. The content covers the class definition, its four public properties (start, top, end, bottom), and the constructor details. Key information includes that each property accepts an optional `PixelRoundCalcPolicy` to control alignment for specific boundaries, with a default value of None. This documentation targets HarmonyOS developers using Cangjie who need precise control over component rendering and layout alignment, specifically for API version 19 and above.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating how to resolve 1px layout gaps caused by sub-pixel rendering using the `pixelRound` property. The main topics include ArkUI component layout, dynamic width adjustment, and the `PixelRoundPolicy` configuration. Key information highlights that non-integer pixel dimensions in parent components can create visual gaps, which are eliminated by applying `pixelRound` to both parent and child elements. The example features an interactive button to test width changes and compares visual results with and without the policy. This guide targets developers using the Cangjie language and ArkUI framework to ensure precise UI rendering.

### 组件级像素取整_2more.md 组件级像素取整_2more.md
This API documentation outlines the component-level pixel rounding feature for the ArkUI framework, designed to mitigate visual anomalies caused by floating-point rendering. The document details the `pixelRound` function, which accepts a `PixelRoundPolicy` parameter to specify alignment strategies for component boundaries. Key sections include the function signature, system capabilities, and a detailed explanation of the rounding logic: calculating top-left and bottom-right coordinates relative to the parent container, rounding them, and deriving the final component size from the difference.
