# 组件事件

This directory contains API reference documentation for scroll-related event callbacks within the Cangjie ArkUI framework. It focuses on the mechanisms for monitoring and controlling scroll behaviors in UI components. The documentation covers a range of events including scroll start, stop, offset changes, and boundary detection. Key topics include `onDidScroll`, `onWillScroll`, `onReachEnd`, and `onScrollStart`. These resources are essential for developers using the Cangjie language who need to implement interactive scrolling logic, handle edge effects, or manage controller interactions in their applications.

### func_onDidScrollscrollOffs_5more.md func_onDidScrollscrollOffs_5more.md

It covers five main functions: `onDidScroll`, `onReachEnd`, `onReachStart`, `onScrollStart`, and `onScrollStop`. Key information includes detailed parameter definitions, such as scroll offset and state, and specific trigger conditions for events like reaching boundaries or starting animations. Intended for developers building UI components, this guide requires knowledge of the Cangjie language and ArkUI system capabilities to effectively implement interactive scrolling logic.

### func_onWillScrollFloat64Sc_3more.md func_onWillScrollFloat64Sc_3more.md
This API reference document details the `onWillScroll` event callbacks for ArkUI scrollable components in the Cangjie language. It covers two primary function overloads—one returning Float64 to modify scroll offset and another returning Unit for observation—and a deprecated `onScroll` function. The callbacks trigger before scrolling, providing the calculated offset, ScrollState, and ScrollSource. Developers can override the offset via the return value. Crucially, these events do not fire during ScrollEdge or non-animated ScrollToIndex calls. This targets ArkUI developers needing to intercept or monitor scroll behaviors in version 19+.
