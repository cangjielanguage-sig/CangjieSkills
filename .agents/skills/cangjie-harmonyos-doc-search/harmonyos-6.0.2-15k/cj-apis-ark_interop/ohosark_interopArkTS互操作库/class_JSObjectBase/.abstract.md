This directory provides comprehensive API reference documentation for the `JSObjectBase` class and associated functions in the Cangjie language. It is designed to facilitate interoperability between Cangjie and ArkTS (JavaScript) environments within the HarmonyOS ArkUI framework. The content covers essential operations such as binding Cangjie objects to ArkTS references, invoking methods, and configuring property getters and setters. Additionally, it includes utilities for property inspection, value assignment, and instance checking. This documentation is suitable for developers working on ArkUI applications who utilize the Napi subsystem to bridge native Cangjie code with JavaScript objects, offering syntax details, parameters, and practical code examples.
