Suitable for HarmonyOS application developers, this documentation ensures robust implementation of image display, layout management, and interactive visual effects in user interfaces.

### Image_6more.md Image_6more.md

Intended for developers using the Cangjie language, this guide requires understanding of basic UI layout and resource handling.

### type_ImageCompleteCallback_2more.md type_ImageCompleteCallback_2more.md
This API reference document defines function type aliases for handling image loading events in the Cangjie programming language. The content covers two primary type definitions: ImageCompleteCallback and ImageErrorCallback. Key information includes the specific signatures for these callbacks, where the completion callback accepts an ImageLoadResult parameter and the error callback accepts an ImageError parameter, with both returning Unit. This documentation is intended for software developers implementing asynchronous image loading logic who need to define handlers for success and failure states.

### 组件事件.md 组件事件.md
This document serves as an API reference for handling image loading events within the ArkUI framework using the Cangjie programming language. It details three primary event handlers: onComplete, onError, and onFinish. Key information includes that onComplete returns image dimensions upon success, onError handles exceptions, and onFinish specifically triggers when non-infinite SVG animations conclude. All functions support nullable callbacks and belong to SystemCapability.ArkUI.ArkUI.Full starting from version 22. This guide targets software developers implementing image components who need to manage loading states and animation lifecycles in their applications.
