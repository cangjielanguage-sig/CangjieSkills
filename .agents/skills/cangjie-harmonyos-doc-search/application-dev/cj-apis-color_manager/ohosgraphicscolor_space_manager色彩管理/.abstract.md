This directory contains API reference documentation for the `ohos.graphics.color_space_manager` module in the Cangjie language, designed for the HarmonyOS ArkGraphics2D framework. It covers the creation, management, and manipulation of color space objects, including standard gamuts, custom primaries, and transfer functions. Key components include the `ColorSpaceManager` class, `ColorSpacePrimaries` class, and the `ColorSpace` enumeration. This documentation is suitable for graphics developers and engineers working on 2D rendering and color management who need to implement precise color standards in their Cangjie applications.
