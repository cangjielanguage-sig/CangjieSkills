# stdruntime

The `stdruntime` directory provides comprehensive documentation for the Cangjie programming language's runtime package, designed to facilitate interaction with the program's execution environment. It covers essential aspects of system programming, including memory management, automatic garbage collection (GC) control, and system resource monitoring. Developers will find resources for managing heap memory, triggering GC cycles, and retrieving statistics on threads and processors. This documentation is suitable for Cangjie developers and system programmers who need to optimize application performance, tune memory usage, and gain low-level control over runtime behavior. It serves as both an introductory guide and a technical reference for utilizing the runtime API effectively.

## Detailed Description

### API_列表.md API_列表.md
This document serves as a reference index for the runtime package API, listing available functions and structures for memory management, garbage collection, and system resource monitoring. It is divided into two main sections: a comprehensive list of functions and a list of structures. The functions section covers operations like heap dumping, GC control, and thread counting, while the structures section provides interfaces for memory, processor, and thread statistics. Key functions include `blackBox` for optimization control, `GC` for garbage collection, and various `get` methods for retrieving heap size and thread counts. Several functions and all listed structures are marked as deprecated, indicating an evolving API. Targeted at developers using the Cangjie runtime, this reference guide requires knowledge of system programming concepts and helps users manage application performance programmatically.

### 功能介绍.md 功能介绍.md
This document serves as an introduction to the runtime package within the Cangjie programming language, outlining its purpose for interacting with the program's execution environment. The content focuses on the package's capabilities in controlling, managing, and monitoring program execution. Key information highlights the integration with Cangjie's automatic garbage collection mechanism, specifically detailing functions for manually triggering GC, setting GC thresholds, and obtaining memory statistics for performance tuning. As a piece of reference documentation, it is intended for Cangjie developers seeking to optimize memory usage and manage runtime behavior. Keywords: Cangjie, runtime package, garbage collection, memory management, program execution, API reference.
