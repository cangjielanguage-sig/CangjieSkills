# Web组件的生命周期

This directory focuses on the lifecycle management of the Web component within the HarmonyOS ArkUI framework. It covers the sequence of events from component initialization and controller attachment to page loading, completion, and destruction. Key topics include lifecycle callback interfaces, state transitions, and event-driven architecture. Developers will learn how to handle specific operations like debugging configuration, JavaScript injection, and load interception at appropriate stages. This resource is suitable for application developers using Cangjie or ArkUI who need to integrate web content effectively and manage interactions between native code and web pages.

## Detailed Description

### Web组件网页加载的状态说明.md Web组件网页加载的状态说明.md
This document outlines the lifecycle events and loading states of the Web component, guiding developers on when to execute specific operations. It details the sequence from component creation (aboutToAppear) and controller attachment (onControllerAttached) to page loading interception (onLoadIntercept), start (onPageBegin), completion (onPageEnd), and disappearance (onDisAppear). Key takeaways include configuring debugging and cookies early, injecting JavaScript proxies after controller attachment, and executing scripts after page load. The text clarifies that onPageBegin and onPageEnd only trigger for the main frame, excluding iframes. This reference guide targets application developers using the ArkUI Web component who need to manage web interactions and initialization logic effectively.

### 概述.md 概述.md
This document serves as an overview for the Web component, detailing its functionality for loading local or online web pages and managing lifecycle states. The text highlights how developers utilize callback interfaces to monitor state changes for business processing, supported by a visual diagram illustrating the normal loading event sequence. Intended for developers integrating web content, this reference guide explains the event-driven architecture of the Web component.

### 示例.md 示例.md
This document provides a practical code example demonstrating how to integrate and control a Web component within a Cangjie-based HarmonyOS application. It covers the application-side Cangjie implementation using the ArkWeb kit and the corresponding frontend HTML file structure. The example illustrates initializing a WebviewController, enabling web debugging, loading a local rawfile resource, and handling critical lifecycle events such as load interception, page start and end, and component disappearance. It targets application developers familiar with Cangjie and ArkUI syntax who need to embed web content into native interfaces.
