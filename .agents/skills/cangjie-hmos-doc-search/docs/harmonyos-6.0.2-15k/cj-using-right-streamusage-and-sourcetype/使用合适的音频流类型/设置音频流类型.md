## 设置音频流类型

应用可采用多种方法实现音频播放或录音功能，常见的设置播放音频流类型的方法有：

- **[使用AudioRenderer开发音频播放功能](./cj-using-audiorenderer-for-playback.md)：**

    可以在调用[createAudioRenderer](../../cj-apis-multimedia-audio/.overview.md)以获取音频渲染器时，传入对应的[StreamUsage](../../cj-apis-multimedia-audio/.overview.md)。

    createAudioRenderer的参数options类型为AudioRendererOptions，包含AudioRendererInfo渲染器信息，使用AudioRendererInfo.usage可指定StreamUsage音频流类型。

- **[使用AVPlayer开发音频播放功能](../../cj-media-kit-using-avplayer-for-playback/.overview.md)：**

    可以通过设置AVPlayer的[audioRendererInfo](../../cj-apis-multimedia_media/.overview.md)属性来实现。该属性类型为AudioRendererInfo，使用AudioRendererInfo的[usage](../../cj-apis-multimedia-audio/.overview.md)属性可指定[StreamUsage](../../cj-apis-multimedia-audio/.overview.md)音频流类型。

    > **说明：**
    >
    > 在设置AVPlayer的audioRendererInfo属性时，只允许在initialized状态下设置。
    >
    > 如果应用未主动设置该属性，AVPlayer将进行默认处理。当媒体源包含视频时，usage的默认值为STREAM_USAGE_MOVIE；否则，usage的默认值为STREAM_USAGE_MUSIC。

- **[使用SoundPool开发音频播放功能](../../cj-media-kit-using-soundpool-for-playback/.overview.md)：**

    可以在调用[createSoundPool](../../cj-apis-multimedia_media/.overview.md)接口时，传入对应的[StreamUsage](../../cj-apis-multimedia-audio/.overview.md)指定音频流类型。

常见的设置录制音频流类型的方法有：

- **[使用AudioCapturer开发音频录制功能](./cj-using-audiocapturer-for-recording.md)：**

    可以在调用[createAudioCapturer](../../cj-apis-multimedia-audio/.overview.md)接口时，传入对应的[SourceType](../../cj-apis-multimedia-audio/.overview.md)。

    createAudioCapturer的参数options类型为AudioCapturerOptions，包含AudioCapturerInfo采集器信息，使用AudioCapturerInfo的source成员可指定SourceType音源类型。

- **[使用AVRecorder开发音频录制功能](../../cj-media-kit-using-avrecorder-for-recording/.overview.md)：**

    可以在调用AVRecorder的[prepare](../../cj-apis-multimedia_media/.overview.md)接口时，传入对应的[AudioSourceType](../../cj-apis-multimedia_media/.overview.md)。

    AVRecorder的prepare接口的参数config类型为AVRecorderConfig，使用AVRecorderConfig的audioSourceType成员可指定音源类型。
