# 订阅应用冻屏事件

本目录包含关于使用仓颉语言订阅和处理应用冻屏事件的开发文档。内容涵盖了如何导入PerformanceAnalysisKit模块、配置AppEventFilter与Watcher、实现onReceive回调处理APP_FREEZE事件，以及如何构造死循环触发冻屏进行测试。核心关键词包括HiAppEvent、addWatcher、removeWatcher、应用性能监控。这些文档适合需要监控应用无响应（ANR）场景及进行性能分析的仓颉语言开发者阅读。

### 开发步骤.md 开发步骤.md
这份文档是一份针对仓颉语言开发者的教程，旨在指导如何订阅和处理应用冻屏事件。文档详细介绍了五个主要步骤：导入PerformanceAnalysisKit模块；在onCreate函数中配置AppEventFilter和Watcher，实现onReceive回调处理APP_FREEZE事件；在onClick函数中构造死循环触发冻屏；运行应用并查看日志。关键信息包括使用HiAppEvent.addWatcher添加观察者，以及解析冻屏事件中的异常、内存和进程参数。该文档适合需要监控应用无响应场景的开发者阅读。
