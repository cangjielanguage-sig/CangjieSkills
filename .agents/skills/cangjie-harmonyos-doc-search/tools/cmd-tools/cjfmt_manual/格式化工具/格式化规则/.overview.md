# 格式化规则

本目录包含仓颉编程语言的代码格式化规范文档，旨在确保代码风格的统一性。内容涵盖了源文件结构顺序、缩进与大括号风格、关键字及操作符空格规则、修饰符排列优先级以及多行注释对齐规范。这些文档是仓颉开发者编写高质量代码、维护代码一致性以及配置格式化工具的重要参考指南。

## 详细描述

### 格式化规则_1.md
本文档旨在规范仓颉编程语言的代码格式，确保风格统一。主要涵盖源文件结构顺序、4空格缩进、K&R大括号风格、关键字及操作符的空格规则、减少冗余空行与分号，以及修饰符的排列优先级。文档通过正反例详细说明了格式化工具的处理逻辑，是仓颉开发者编写高质量代码及配置格式化工具的重要参考指南。

### 格式化规则_2.md
本文档定义了仓颉语言的代码格式化规则，主要涵盖成员变量修饰符排序及多行注释的对齐规范。主要内容包括成员变量修饰符的推荐排序优先级（如访问控制、static、redef），以及多行注释中星号对齐和空格处理的格式化行为。关键点在于明确了修饰符的层级顺序，并规定以星号开头的注释会自动对齐星号并删除多余空格，而非星号开头的注释则保持原样。该文档属于代码风格参考指南，面向使用仓颉语言的开发者，旨在统一代码风格并辅助格式化工具的配置。
