This directory serves as the definitive starting point for developers aiming to build camera applications using the Cangjie language on the HarmonyOS operating system. It comprehensively addresses the critical initial preparation phase, ensuring that applications are configured correctly to access sensitive hardware components. The guide details the specific system permissions required for camera functionality, including CAMERA, MICROPHONE, and MEDIA_LOCATION, and clarifies the mandatory user authorization process involving system pop-ups. Beyond basic setup, it provides a structured development roadmap that links initial configuration to advanced topics such as device input handling, session management, video preview, and media recording. A significant portion of the content is dedicated to security best practices, specifically advising developers to utilize media library Pickers for file reading and Security Controls for saving files, rather than requesting broad file access permissions. This resource is essential for application developers who need to securely integrate camera features and manage media files while adhering to HarmonyOS ecosystem standards.
