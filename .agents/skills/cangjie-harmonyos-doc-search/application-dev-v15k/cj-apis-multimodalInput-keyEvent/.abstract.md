This directory serves as a specialized repository for API reference documentation tailored for the Cangjie programming language within the OpenHarmony ecosystem. It focuses specifically on the intricacies of multimodal input, providing developers with the necessary tools to handle key input events effectively. The content encompasses critical components such as the `Action` enum, which defines key states; the `Key` class, representing device-reported events; and the `KeyEvent` class, which offers a comprehensive approach to managing keyboard interactions. By covering key codes, modifier states, pressed time, and system capabilities, this documentation ensures developers can build sophisticated input handling mechanisms. It is specifically designed for developers working on version 19+ systems and necessitates the `SystemCapability.MultimodalInput.Input.Core` capability for implementation.
