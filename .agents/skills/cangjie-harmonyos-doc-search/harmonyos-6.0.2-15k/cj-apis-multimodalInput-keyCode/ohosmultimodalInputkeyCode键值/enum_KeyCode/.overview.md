# enum_KeyCode

This directory contains comprehensive API documentation for the KeyCode enumeration, which maps physical hardware keys to programmatic constants within a multimodal input system. It covers a vast array of input types, including standard alphanumeric keys, multimedia controls, system functions, international language inputs (such as Japanese), and game controller buttons. All entries utilize the SystemCapability.MultimodalInput.Input.Core capability and are primarily available from API version 19. This resource is essential for software developers and system engineers working on input device drivers, user interface logic, or applications requiring precise keyboard and hardware event mapping in the Cangjie programming language environment.
