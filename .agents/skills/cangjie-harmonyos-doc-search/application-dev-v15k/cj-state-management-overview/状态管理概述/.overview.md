# 状态管理概述

This directory provides a comprehensive overview of state management mechanisms within the Cangjie declarative UI framework. It covers the fundamental principles of how state changes drive UI rendering, distinguishing between state variables and regular variables. Key topics include component-level decorators like @State, @Prop, and @Link, as well as application-level solutions such as AppStorage and LocalStorage. It also addresses data flow patterns (unidirectional vs. bidirectional) and nested object observation. This resource is suitable for developers building dynamic applications who need to understand data synchronization between components, pages, and global states to ensure efficient UI updates.

## Detailed Description

### 状态管理V1.md
This document provides an overview of State Management V1, guiding developers on using decorators to manage state synchronization and UI updates within applications. It categorizes decorators into component-level management (e.g., @State, @Prop, @Link, @Provide/@Consume, @Observed/@Publish) and application-level management (e.g., AppStorage, LocalStorage). Key information includes the distinction between unidirectional and bidirectional data transmission, the specific use cases for nested object observation via @Observed/@Publish, and the role of @Watch for monitoring changes. This reference guide targets developers building applications, specifically those needing to handle data flow between components, pages, and global application states.

### 状态管理概述_2more.md
This document provides an overview of state management mechanisms within the Cangjie declarative UI framework, explaining how state changes drive UI rendering. It covers the relationship between State and View, basic concepts including state variables, regular variables, and data sources, and parent-child component initialization via named parameters. Key takeaways include that variables must be decorated, such as with @State, to trigger UI updates, whereas regular variables do not cause refreshes. The text details how parent components initialize child state variables and notes that state management is restricted to the main UI thread. Intended for developers familiar with basic UI syntax and declarative descriptions, this guide serves as a foundational resource for building dynamic interfaces.
