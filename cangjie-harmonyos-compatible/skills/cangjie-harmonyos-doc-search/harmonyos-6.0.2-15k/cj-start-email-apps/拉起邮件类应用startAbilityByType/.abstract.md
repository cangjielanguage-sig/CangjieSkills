This directory provides comprehensive technical documentation for launching mail applications using the `startAbilityByType` interface within the Cangjie development environment. It covers the complete workflow from the initiating application to the target application. Key topics include constructing parameters for recipients, subjects, and attachments, handling URL encoding, setting URI permissions, and configuring `module.json5` for feature linking. Additionally, it details how to parse incoming parameters in `UIAbility` lifecycle methods. This resource is essential for HarmonyOS developers aiming to implement cross-application email capabilities or configure their apps to respond to external email requests.
