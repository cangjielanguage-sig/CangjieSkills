This directory contains API reference documentation for the HarmonyOS Telephony SMS service module, specifically designed for the Cangjie programming language. It covers the essential components required to implement SMS and MMS functionality, including message creation, sending, receiving, and status management. Key topics include message classes, content types, result enums, and callback interfaces. The documentation is intended for developers using TelephonyKit who need to integrate messaging capabilities into their applications, requiring knowledge of Cangjie and telephony protocols.
