# cj-crypto-sm2-ciphertext-conversion

This directory serves as a specialized technical repository dedicated to developers implementing the SM2 elliptic curve cryptography algorithm within the Cangjie programming ecosystem. It focuses specifically on the complex and critical task of converting SM2 ciphertext to and from the National Cryptography Standard ASN.1 format, widely identified as the C1C3C2 structure. The content provides in-depth guidance on two essential workflows: the generation of compliant ciphertext from specific input parameters and the reverse engineering of these parameters from pre-existing encrypted data. By utilizing the CryptoArchitectureKit, developers can effectively manage coordinates, ciphertext data, and hash data through the SM2CipherTextSpec object. This resource is indispensable for security architects and backend engineers aiming to ensure their applications adhere to strict national cryptographic standards while maintaining robust data security and seamless interoperability.

### cj-crypto-sm2-ciphertext-conversion.md

This document serves as a technical guide for developers on converting SM2 ciphertext to and from the National Cryptography Standard ASN.1 format (C1C3C2). It details two primary workflows: generating standard ASN.1 ciphertext from specific parameters using the SM2CipherTextSpec object and genCipherTextBySpec function, and extracting these parameters from existing ciphertext using getCipherTextSpec. The guide provides Cangjie code examples for both processes, illustrating how to handle coordinates, ciphertext data, and hash data. It targets developers needing to integrate or transform SM2 encryption data within the CryptoArchitectureKit.
