# 无障碍属性

This directory contains API references for configuring accessibility properties in the ArkUI framework using the Cangjie language. It covers functions for setting descriptions, grouping components, managing visibility levels, and handling virtual nodes for custom-drawn components. Key topics include screen reader support, assistive service integration, and accessibility text management. These documents are intended for developers building accessible user interfaces in ArkUI applications, specifically those needing to implement or refine accessibility features starting from version 19.

## Detailed Description

### func_accessibilityDescript_4more.md func_accessibilityDescript_4more.md
This document serves as an API reference for configuring accessibility properties in ArkUI using the Cangjie language. It details four specific functions: accessibilityDescription (supporting both String and AppResource inputs), accessibilityLevel, and accessibilityTextHint. Key information includes that accessibilityDescription provides detailed explanations of actions and consequences, read after the component's main text. The accessibilityLevel function controls component visibility to assistive services using values like "auto", "yes", "no", and "no-hide-descendants". accessibilityTextHint offers supplementary text for user guidance. This guide is intended for developers implementing accessibility features in ArkUI applications starting from version 19.

### func_accessibilityVirtualN_2more.md func_accessibilityVirtualN_2more.md
This API reference document details the Cangjie function accessibilityVirtualNode, designed to configure accessibility virtual child nodes for custom-drawn components. The content covers the function signature, system capabilities, version requirements, and a parameter table explaining the builder argument. Key information includes that the custom UI description passed to the builder is used for layout and assistive application retrieval but not for visual display. This guide is intended for ArkUI developers implementing accessibility features in self-drawn components, requiring knowledge of the @Builder macro and bind methods.

### 无障碍属性_4more.md 无障碍属性_4more.md
This document serves as an API reference for configuring accessibility properties within the ArkUI framework using the Cangjie language. It details three specific functions: accessibilityGroup for grouping components, and two overloads of accessibilityText for setting descriptive text via String or AppResource. Key behaviors include treating grouped components as a single selectable unit and prioritizing accessibility text over default text for screen readers. When grouping is enabled without explicit text, the system concatenates child text. This guide targets developers building accessible user interfaces who need to implement screen reader support and manage component focus.
