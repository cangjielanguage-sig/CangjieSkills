# cj-request-user-authorization

This directory focuses on the implementation of dynamic user authorization requests within HarmonyOS application development using the Cangjie language. It covers the complete workflow for requesting sensitive permissions classified as `user_grant`, ensuring applications adhere to privacy principles where user access is controllable and transparent. Key topics include runtime permission verification, triggering system authorization dialogs, handling authorization results, and managing exceptions. The content highlights essential APIs such as `checkAccessToken()` and `requestPermissionsFromUser()`. This resource is designed for application developers who need to integrate system-level permission management, specifically for accessing sensitive data like location services, ensuring compliance with user privacy standards.

## Detailed Description

### 向用户申请授权/
This directory primarily introduces how to dynamically request sensitive permissions (`user_grant`) from users during HarmonyOS application development. The content covers the complete process of permission application, including runtime permission verification, triggering dynamic authorization dialogs, checking authorization results, and handling exceptions. Core knowledge points involve the usage of APIs such as `checkAccessToken()` and `requestPermissionsFromUser()`, as well as the specific implementation of location permission requests using the Cangjie language. This document is suitable for application developers who need to perform system permission integration, helping them follow the principle of user knowledge and control to correctly implement authorization management for private information access capabilities.
