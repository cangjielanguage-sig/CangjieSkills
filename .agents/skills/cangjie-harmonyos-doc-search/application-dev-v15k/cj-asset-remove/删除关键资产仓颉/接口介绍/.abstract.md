This directory serves as a comprehensive technical resource for developers working with the AssetStoreKit framework, focusing specifically on the API interfaces required for managing critical assets. It provides detailed guidance on asset deletion operations, specifically the `remove` function and its associated `AssetParam` structure, alongside a comprehensive reference table for asset attributes. The documentation covers essential topics such as access control parameters, synchronization settings, persistence options, and custom data labels. It also highlights critical security warnings regarding unencrypted data storage and updates in API12. This content is intended for developers implementing secure asset storage who need to understand data handling constraints, protection levels, and effective configuration of asset properties to ensure application security and data integrity.
