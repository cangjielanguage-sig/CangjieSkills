# XComponent

The XComponent directory provides comprehensive documentation for the ArkUI framework's XComponent, a specialized component designed to embed a Surface for high-performance graphics drawing and media data writing. It covers essential API references, initialization parameters, attribute restrictions for SURFACE and TEXTURE types, and security features like screen capture prevention. Additionally, it includes definitions for fundamental data structures and controllers required for low-level rendering control. This resource is suitable for HarmonyOS developers using the Cangjie language who need to implement custom rendering, manage native interfaces like cameras, or handle secure media display in their applications.
