# cj-errorcode-i18n

This directory serves as the central documentation hub for the `cj-errorcode-i18n` module, specifically focusing on the internationalization error codes currently available in the Beta release. By isolating module-specific errors from universal system codes, this directory enables precise debugging. It is an essential resource for ensuring the correct implementation of parameter types and maintaining the stability of internationalization features during the Beta phase.
