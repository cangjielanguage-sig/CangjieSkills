# 日志主干通用信息

This directory provides reference guides for interpreting system and application logs, specifically focusing on performance issues like application freezes and Inter-Process Communication (IPC) delays. It covers key log fields, main thread task queues, Binder communication, CPU load, and memory usage statistics. Designed for system developers and engineers, these documents help diagnose responsiveness issues, analyze task accumulation, and interpret resource metrics within an OpenHarmony environment.

## Detailed Description

### 日志主干通用信息_1.md
This document serves as a reference guide for interpreting common fields found in application freeze (appfreeze) logs. It covers a table of key log fields including EVENTNAME, PID, and MSG, details on MSG field content regarding main thread task queues, and examples of stack traces and Binder communication logs. The document explains how to identify freeze causes, analyze task accumulation, and diagnose IPC communication delays using specific log markers like BinderCatcher. It also notes potential data loss under high system load. This technical reference is intended for system developers or engineers debugging application responsiveness issues.

### 日志主干通用信息_2.md
This document serves as a reference guide for interpreting system logs, specifically focusing on Inter-Process Communication (IPC) and system resource usage. It details four main sections: BinderCatcher logs for tracking transaction latency and async space, PeerBinder Stacktraces for diagnosing peer process freezes with thread details, CPU usage reports showing load averages and per-process consumption, and memory statistics detailing Pss, shared, and private memory allocations. Key information includes understanding transaction wait times, identifying blocking threads in libipc_core.z.so, and interpreting memory metrics. This guide targets system developers and debuggers troubleshooting performance issues or application freezes in an OpenHarmony environment.
