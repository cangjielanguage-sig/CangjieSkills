# cj-apis-app-ability

本目录包含仓颉语言中 `ohos.app.ability` 模块的 API 参考文档，重点介绍了作为所有 Context 类型父类的 `BaseContext` 基类。文档涵盖了模块导入方式、所需权限列表、示例代码使用说明，以及 `BaseContext` 类的详细定义，包括其 `stageModel` 属性。`BaseContext` 定义了基础能力，通过只读属性 `stageModel` 支持判断应用是否采用 Stage 模型。该模块目前处于 Beta 阶段，主要面向使用仓颉开发 HarmonyOS 应用的开发者，旨在帮助其深入理解上下文体系并有效访问应用上下文功能。
