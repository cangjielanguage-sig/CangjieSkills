# 使用AVImageGenerator提取视频指定时间图像

本目录主要介绍如何使用AVImageGenerator从视频资源中提取指定时间的缩略图。内容涵盖了从创建实例、配置文件描述符（fdSrc）、调用fetchFrameByTime获取PixelMap图像到资源释放的完整开发流程。文档详细说明了通过ResourceManager或应用沙箱路径设置资源的方法，并提供了基于仓颉语言和MediaKit的完整代码示例。适合需要实现视频帧提取功能的开发者参考。
