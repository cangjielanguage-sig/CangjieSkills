# 常用ArkUI基础信息显示能力

This directory serves as a technical repository for developers and QA engineers seeking to understand and debug the internal structures of HarmonyOS applications built with the ArkUI framework. It focuses on the critical capabilities of displaying and retrieving foundational runtime information, which is essential for diagnosing UI issues and verifying application logic. The documentation covers advanced techniques for accessing window management data, visualizing component tree hierarchies, and tracking navigation route stacks. By utilizing command-line tools such as `hidumper` and `hdc shell`, users can perform deep inspections of their applications' state. These guides are particularly suitable for professionals who need to troubleshoot rendering problems, analyze component attributes, or validate the navigation flow of complex applications without relying solely on IDE-based debugging tools.

## Detailed Description

### 常用ArkUI基础信息显示能力_4more.md 常用ArkUI基础信息显示能力_4more.md
This technical guide explains how to use the hidumper tool to retrieve window and component tree information within the ArkUI framework. It covers three main operations: retrieving full window information to identify Window IDs, dumping the complete component tree for a specific application, and inspecting details of a specific component node. Key information includes specific shell commands for each operation, methods for locating parameters like WinId and nodeID, and a mapping table of common window names to built-in system applications. Intended for developers or QA engineers debugging HarmonyOS applications, this reference guide requires basic knowledge of the command line interface and window management concepts. Keywords: ArkUI, hidumper, component tree, window management, debugging, HarmonyOS.

### 获取期望应用的Inspector树_2more.md 获取期望应用的Inspector树_2more.md
This technical guide explains how to retrieve the Inspector tree and route stack information for HarmonyOS applications using the hdc shell tool. It covers enabling the ArkUI debug switch, dumping the Inspector tree to view component attributes, and obtaining the navigation route stack hierarchy. Key information includes the prerequisite command to enable test mode and specific hidumper commands for WindowManagerService. The Inspector tree matches DevEco Studio's view, while the route stack command specifically targets applications using the Navigation component. This guide is intended for developers and testers debugging UI components and navigation logic in HarmonyOS applications.
