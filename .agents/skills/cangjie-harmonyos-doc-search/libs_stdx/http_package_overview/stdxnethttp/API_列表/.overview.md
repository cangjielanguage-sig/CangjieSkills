# API_列表

This directory serves as the central API reference for a versatile HTTP package designed for high-performance network applications. It comprehensively documents the essential building blocks required to create HTTP clients, servers, and WebSocket services. The content covers functional utilities, interface contracts, data structures, error handling mechanisms, and detailed class definitions. Key topics include protocol upgrades, coroutine pool configurations, and builder patterns for object construction. This documentation is primarily intended for software developers and engineers who need a deep understanding of the library's architecture to implement robust, scalable network communication solutions.

## Detailed Description

### 函数_2more.md
This document acts as a quick reference index for the core functions and interfaces within the HTTP package API. It is divided into two main sections: Functions and Interfaces. The Functions section details utilities for managing HTTP errors, generating 404 responses, and handling protocol upgrades for CONNECT requests. The Interfaces section defines contracts for client-side cookie management, request distribution by path, request handling logic, and service instance factories. This documentation is intended for software developers seeking to understand the available components for building HTTP clients and servers, providing a high-level overview of the package's structural capabilities.

### 枚举_3more.md
This document provides a reference index for core data types and error handling classes within the HTTP package API. It is organized into three primary categories: Enums, Structs, and Exception Classes. Key components include configuration structures for server coroutine pools and transport layers, protocol definitions for HTTP and WebSocket, and specific exception handling for timeouts, connection failures, and status errors. This guide targets developers integrating the library who need to understand available data structures and error management mechanisms for building robust network applications.

### 类.md
This document serves as a reference index listing the core classes available in the HTTP package, detailing their specific functionalities and links to detailed documentation. It covers client-side components like Client and HttpRequest, server-side components like Server and ProtocolService, utility handlers such as FileHandler and RedirectHandler, and WebSocket support. Key takeaways include the use of builder patterns for constructing Clients, Servers, and HTTP messages, alongside support for HTTP/1.1, HTTP/2, and WebSocket protocols. The document also highlights convenient handlers for common scenarios like 404 errors or OPTIONS requests. This reference guide targets developers using this HTTP library to build network applications, requiring knowledge of HTTP protocols and object-oriented programming concepts.
