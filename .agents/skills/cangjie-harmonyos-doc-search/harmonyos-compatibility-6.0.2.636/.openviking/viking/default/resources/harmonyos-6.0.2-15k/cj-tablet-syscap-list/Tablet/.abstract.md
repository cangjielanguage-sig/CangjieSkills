This directory contains technical documentation and reference lists defining SystemCapabilities (SysCap) for a specific tablet device profile within the HarmonyOS/OpenHarmony ecosystem. It covers a comprehensive range of subsystems including AI components, multimedia, graphics, security, and distributed data management. These documents provide granular feature identifiers used for system configuration, dependency management, and API compatibility verification. This resource is suitable for system developers, device engineers, and application developers who need to understand available hardware and software features or configure builds for tablet devices.
