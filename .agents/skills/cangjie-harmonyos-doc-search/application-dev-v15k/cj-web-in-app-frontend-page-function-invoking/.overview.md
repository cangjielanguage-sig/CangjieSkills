# cj-web-in-app-frontend-page-function-invoking

This directory contains a specialized technical tutorial designed for developers utilizing the Cangjie programming language in conjunction with the ArkWeb component. The primary focus is on establishing robust communication channels between native Cangjie applications and embedded frontend web environments. It thoroughly explains the mechanisms required to invoke JavaScript functions running within a web view from the native application layer. Key topics include the specific usage of `runJavaScript` and `runJavaScriptExt` methods, with a particular emphasis on their differences in parameter support, such as handling ArrayBuffer and AsyncCallback. The content is tailored for software engineers and developers who are building hybrid applications and require a deep understanding of how to bridge native logic with web-based interfaces to create responsive, feature-rich user experiences.

## Detailed Description

### cj-web-in-app-frontend-page-function-invoking.md

This document acts as a comprehensive guide for invoking frontend JavaScript functions from a Cangjie application using the ArkWeb component. It meticulously details the implementation of the `runJavaScript` and `runJavaScriptExt` methods, providing a clear comparison of their capabilities. The text highlights critical distinctions, particularly noting that `runJavaScriptExt` supports advanced parameters like ArrayBuffer and AsyncCallback, enabling more complex data transfer and asynchronous operations compared to the standard method. To facilitate practical understanding, the tutorial includes a concrete code example demonstrating how to trigger a frontend function to change text color upon a native button click. Key takeaways for the reader include mastering the specific method signatures required for these calls and learning how to handle execution results effectively via callbacks. This resource is essential for developers seeking to integrate and control web content seamlessly within native Cangjie applications.
