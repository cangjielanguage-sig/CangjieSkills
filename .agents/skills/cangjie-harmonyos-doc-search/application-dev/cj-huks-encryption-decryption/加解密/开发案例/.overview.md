# 开发案例

This directory serves as a comprehensive repository of practical development cases focused on cryptographic operations within the HarmonyOS ecosystem. It provides detailed code examples and implementation guides using the Cangjie programming language and the Universal Keystore Kit (HUKS). The content covers a wide range of encryption standards, including SM2, AES (CBC/PKCS7, GCM), and RSA (OAEP, PKCS1_V1_5), addressing key lifecycle management such as generation, encryption, decryption, and deletion. These resources are specifically designed for HarmonyOS developers and security engineers seeking to integrate robust data protection mechanisms and adhere to security best practices in their applications.

## Detailed Description

### SM2.md SM2.md
This document serves as a practical code example in Cangjie for implementing SM2 cryptographic operations using the Universal Keystore Kit. It details the complete lifecycle of key management, including functions for generating SM2 keys, encrypting plaintext, decrypting ciphertext, and deleting keys. Key takeaways include the specific configuration of HuksParam properties for SM2 algorithms, such as setting the key size to 256 bits and using the SM3 digest. The guide is intended for developers working within the HarmonyOS ecosystem who require secure data handling and cryptographic functionality.

### [2] AESCBCPKCS7/
This directory provides a comprehensive technical guide for implementing AES/CBC/PKCS7 encryption and decryption workflows using the Cangjie language on HarmonyOS. It focuses on the Universal Keystore Kit (HUKS), offering detailed code examples for managing the entire lifecycle of cryptographic keys. Key topics include generating 128-bit AES keys, configuring PKCS7 padding and CBC mode, handling Initialization Vectors (IV), and performing secure data operations. The documentation also covers essential maintenance tasks such as decrypting data and securely deleting keys from the keystore. This resource is specifically designed for HarmonyOS developers and security engineers seeking to implement standard, high-security data protection mechanisms within their applications using HUKS APIs like `generateKeyItem`, `initSession`, and `finishSession`. By following these examples, developers can ensure their applications adhere to security best practices while handling sensitive information.

### [3] AESGCMNoPadding/
This directory provides a comprehensive collection of technical documentation and code examples dedicated to implementing AES-GCM (Galois/Counter Mode) encryption without padding using the HarmonyOS Universal Keystore Kit (HUKS) and the Cangjie programming language. It covers the complete lifecycle of cryptographic operations, including key generation, parameter configuration, and the specific handling of Nonce, Associated Data (AAD), and AE tags. The resources detail the session-based workflow required for secure data processing. This material is highly suitable for HarmonyOS developers, system architects, and security engineers seeking to integrate advanced encryption standards into their applications for secure data storage and transmission, ensuring compliance with modern security protocols.

### [4] RSAECBOAEPSHA256/
This directory provides a comprehensive collection of Cangjie code examples designed to demonstrate the implementation of RSA cryptographic operations within the HarmonyOS Universal Keystore (HUKS) framework. The primary focus is on utilizing RSA with ECB mode, OAEP padding, and SHA-256 digest to ensure robust data security. The documentation covers the entire cryptographic key lifecycle, including the generation of RSA 2048-bit keys, the encryption and decryption of data, and the secure deletion of key items. These resources are specifically tailored for developers using the Cangjie language who require practical guidance on integrating secure HUKS-based encryption and key management strategies into their HarmonyOS applications to protect sensitive information effectively.

### [5] RSAECBPKCS1_V1_5/
This directory contains technical documentation and code examples for implementing RSA encryption and decryption using the ECB mode and PKCS1_V1_5 padding scheme within the HarmonyOS Universal Keystore (HUKS) framework. It covers the complete cryptographic lifecycle, including key generation, data encryption, decryption, and key deletion using the Cangjie language. The content is tailored for HarmonyOS developers who need to integrate secure cryptographic operations into their applications, providing specific parameter configurations and workflow guidance for utilizing HUKS APIs effectively.
