# ref_package_enums

This directory acts as the central API reference for the `ref_package_enums` module in the Cangjie programming language, specifically targeting the needs of developers working with advanced memory management features. It comprehensively documents the enumerations used to define garbage collection behaviors for weak references. The core component covered is the `CleanupPolicy` enum, which provides the critical logic for determining when objects are reclaimed by the garbage collector—either immediately upon becoming weakly reachable (EAGER) or only when the system faces memory constraints (DEFERRED). By detailing these variants and their impact on the `Equatable` interface, the documentation enables developers to fine-tune application performance and memory footprint. This guide is indispensable for Cangjie software engineers, systems programmers, and technical architects aiming to optimize resource utilization and ensure robust object lifecycle management in their applications.

### ref_package_enums.md ref_package_enums.md

This API reference document defines the CleanupPolicy enum within the Cangjie ref package, specifying garbage collection strategies for weak references. The documentation details the enum's two variants: EAGER, which instructs the GC to reclaim objects as soon as possible, and DEFERRED, which preserves objects until memory is insufficient. It also documents the equality and inequality operators inherited from the Equatable interface. Key takeaways include understanding how these policies impact object lifecycle management in WeakRef instances. This technical reference is intended for developers implementing memory management logic in Cangjie applications.
