# unittest_mock_mockmacro_package_macros

This directory contains the essential documentation for the `unittest_mock_mockmacro_package_macros`, a specialized package within the `unittest_mock` framework. It serves as a comprehensive reference guide for developers looking to leverage advanced macro features to improve their unit testing strategies. The primary focus is on the `@Called` and `@On` annotations, which provide syntactic sugar and powerful functionality for managing mock objects. The `@Called` macro facilitates the creation of verification statements, enabling developers to assert that specific interactions occurred with high precision. Meanwhile, the `@On` macro provides access to the configuration API, allowing users to define or redefine the behaviors of mock and spy object members dynamically. This documentation is intended for developers writing unit tests who require precise control over mock object setup and interaction verification. By mastering these tools, users can write cleaner, more readable, and more reliable tests. Key concepts include verification statements, configuration APIs, and spy object manipulation.
