# 接口介绍

This directory provides comprehensive technical documentation for the AssetStoreKit framework, specifically focusing on API interfaces used to synchronize and manage key assets. It covers essential topics such as the `add` function signature, `AssetParam` definitions, and data attribute configurations including mandatory fields like SECRET and ALIAS. The documentation also details custom data labels, encryption settings, conflict resolution strategies, and version-specific constraints like API12 changes. It is designed for developers integrating secure asset storage features, ensuring correct parameter implementation and adherence to data privacy standards.

## Detailed Description

### 接口介绍_1.md
This document serves as a technical reference for the API interface used to synchronize new key assets, specifically focusing on the `add` function. It outlines the function signature and details the `AssetParam` parameters required to define asset attributes. A critical security takeaway is the warning that attributes named "DATA_LABEL" are unencrypted and must not contain personal data. This guide is intended for developers integrating asset storage features, ensuring correct parameter implementation and adherence to data privacy standards.

### 接口介绍_2.md
This document serves as a reference guide defining the attributes and data types for managing critical assets within the AssetStoreKit framework. It details mandatory fields like SECRET and ALIAS, alongside optional configurations for access control, authentication, synchronization, and persistence. It also categorizes custom data labels into critical (integrity-protected), normal, and local-only types. Key takeaways include specific byte length constraints, version-specific changes regarding data label sizes in API12, and permission requirements for persistent storage. Targeted at developers integrating secure asset storage, this API reference requires understanding of data types like UInt32 and Array<UInt8>, as well as system permissions.

### 接口介绍_3.md
This document serves as a technical reference detailing specific parameters for managing key assets within the AssetStoreKit framework. It covers data definitions for local custom information, specifically DATA_LABEL_NORMAL_LOCAL_3 and DATA_LABEL_NORMAL_LOCAL_4, alongside conflict resolution strategies and encryption settings. Key information includes data types, byte limits ranging from 1-2048 bytes, and behavioral characteristics such as the lack of synchronization for local data and the handling of alias conflicts during asset creation. The content targets software developers integrating asset management features who need to understand data structure constraints, optional encryption requirements, and conflict handling logic.
