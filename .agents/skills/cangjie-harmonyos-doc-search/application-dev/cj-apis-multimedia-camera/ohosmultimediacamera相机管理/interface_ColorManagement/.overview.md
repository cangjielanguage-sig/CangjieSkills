# interface_ColorManagement

This directory provides comprehensive API reference documentation for the ColorManagement interface within the Cangjie CameraKit framework. It is dedicated to the management, configuration, and querying of camera color spaces, with a specific focus on supporting advanced display capabilities like P3 and HDR. The documentation outlines critical implementation details, such as function syntax, system prerequisites, and strict mapping rules between CameraFormat and ColorSpace to ensure visual fidelity. It also addresses error handling and session configuration flows to prevent performance issues. This resource is essential for multimedia developers and systems engineers aiming to integrate sophisticated color management into camera applications, ensuring optimal performance across various video and photo modes while avoiding common configuration errors.

## Detailed Description

### func_setColorSpaceColorSpace.md
This API reference document details the setColorSpace function for configuring camera color spaces in Cangjie applications. It covers function syntax, prerequisites, P3/HDR capabilities, and specific mapping tables for video and photo modes. Key information includes the requirement to query supported spaces first and call this method between addOutput and commitConfig to avoid performance issues. It defines strict pairings between CameraFormat and ColorSpace for SDR and HDR_VIVID video recording to prevent preview anomalies. The document also lists parameters, system capabilities, and specific error codes. Targeted at multimedia developers using CameraKit, it assumes knowledge of camera session configuration flows.

### interface_ColorManagement_2more.md
This document serves as API reference documentation for the ColorManagement interface in the Cangjie language, designed to manage color space settings within a camera system. It covers the interface definition, its inheritance from ColorManagementQuery, and detailed specifications for the getActiveColorSpace method, including its return values, potential exceptions, and usage examples. Key takeaways include the system capability requirement, the specific error code for unconfigured sessions, and the method's role in retrieving the current ColorSpace configuration. Targeted at developers working on multimedia camera applications, this guide requires knowledge of the Cangjie language and camera session management to implement color space retrieval effectively.
