# class_AudioHapticPlayer

This directory contains API reference documentation for the `AudioHapticPlayer` class in the Cangjie programming language, designed to facilitate coordinated audio and haptic playback within the HarmonyOS ecosystem. It covers essential functionalities such as querying mute status, managing event callbacks, handling audio interrupts, and controlling playback lifecycle (start, stop, release). Key topics include error handling via `BusinessException`, system capabilities, and resource management. This documentation is suitable for developers using the AudioKit to build immersive multimedia applications that require synchronized sensory feedback and robust audio focus management.
