# cj-macro-link

This directory serves as a comprehensive resource for the `cj-macro-link` project, focusing specifically on the `@Link` macro within the Cangjie UI and ArkUI development ecosystems. It addresses the critical need for implementing two-way data binding between parent and child components, a fundamental requirement for building reactive and interactive user interfaces. The content covers essential technical concepts such as state synchronization, variable transfer protocols, and observation mechanisms for various data types including primitives, classes, and arrays. It is specifically designed for developers who are already familiar with the `@State` decorator and need to manage reactive state more effectively, ensuring seamless bidirectional data flow across complex component hierarchies.

## Detailed Description

### Link宏父子双向同步/

This directory provides extensive documentation and practical tutorials on the `@Link` macro, which is essential for implementing two-way data binding in Cangjie UI and ArkUI development. It offers a deep dive into the core concepts required to maintain state consistency across component boundaries, specifically detailing how state synchronization and variable transfer protocols operate under the hood. The material thoroughly explains the observation mechanisms that apply to different data structures, distinguishing how primitives, classes, and arrays should be handled to ensure reactivity.

Beyond the basics, the content includes technical specifications and outlines specific usage constraints to help developers avoid common implementation errors. It also serves as a troubleshooting guide, offering solutions for frequent issues such as type mismatches between parent and child components. Furthermore, it explores practical, real-world scenarios involving the use of `ObservedArrayList` for dynamic data collections and the integration of the `@Watch` decorator for monitoring state changes. This makes the directory an invaluable reference for developers aiming to master reactive state management and build robust applications with efficient bidirectional data flow.
