# 使用场景

This directory focuses on practical usage scenarios for the `@Builder` decorator within the ArkUI Cangjie development framework. It provides in-depth technical guidance on implementing dynamic UI rendering, specifically addressing how to effectively pass global and local builder functions as parameters to other components. The content covers complex architectural patterns such as multi-layer nesting and the critical requirement of pass-by-reference for ensuring dynamic UI refreshes in deeply nested structures. Furthermore, it clarifies the relationship between build functions and state management macros like `@Observed` and `@Publish`. This resource is highly suitable for HarmonyOS developers who are familiar with Cangjie syntax and are seeking to optimize UI construction, encapsulation, and state synchronization in complex component hierarchies.

## Detailed Description

### 使用全局和局部的Builder传入customBui_2more.md 使用全局和局部的Builder传入customBui_2more.md
This technical guide explains advanced usage of the @Builder decorator in ArkUI Cangjie development. It covers passing global and local @Builder functions as customBuilder parameters to implement specific UI effects, such as in bindSheet. Additionally, it details multi-layer @Builder nesting, emphasizing that pass-by-reference is required for dynamic UI refresh in deeply nested scenarios. Key concepts include customBuilder types, @Observed classes, and state management. The document targets developers seeking to optimize UI construction and state synchronization in complex component hierarchies.

### 自定义组件内使用自定义构建函数_3more.md 自定义组件内使用自定义构建函数_3more.md
This tutorial demonstrates how to implement and utilize custom build functions (@Builder) in Cangjie for dynamic UI rendering. It covers three main scenarios: creating private @Builder methods within components using @State, defining global @Builder functions with parameter passing for complex objects, and clarifying that UI refresh is driven by state management macros like @Observed and @Publish rather than the @Builder itself. Key takeaways include understanding encapsulation, parameter passing, and the reactive data flow. This guide is intended for HarmonyOS developers familiar with Cangjie syntax and basic UI component lifecycles.
