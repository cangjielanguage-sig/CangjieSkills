This directory provides practical examples and technical guides for achieving interoperability between ArkTS and Cangjie within the HarmonyOS ecosystem. It covers essential topics such as manipulating ArkTS objects (both Sendable and ordinary) from Cangjie code, invoking ArkTS functions, and managing concurrency using AsyncLock mechanisms. Key concepts include cross-language communication, data sharing via `ark_interop`, thread safety, and context management during function calls. These resources are suitable for developers working on HarmonyOS applications who need to integrate Cangjie dynamic libraries with ArkTS, handle concurrent data access, or implement complex cross-language interactions.
