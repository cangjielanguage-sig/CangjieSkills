This directory serves as a specialized resource for Cangjie programming language developers aiming to master command-line argument parsing. It centers on the `std.argopt` library, providing a practical guide that bridges the gap between basic syntax knowledge and functional CLI application development. The content thoroughly explores two main parsing strategies: a callback-free approach that accumulates results in a result object, and a callback-driven approach that executes logic instantly when arguments are detected. Beyond parsing logic, the guide details the configuration of argument specifications using Short, Long, and Full specifiers. It also provides essential techniques for handling various value types—NoValue, RequiredValue, and OptionalValue—alongside managing non-option arguments. Furthermore, it includes critical error handling patterns using `ArgumentParseException`. This guide is perfectly suited for developers who already understand Cangjie syntax and standard library imports and are ready to build sophisticated command-line tools.
