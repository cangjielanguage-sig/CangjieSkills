This directory provides comprehensive technical documentation on the methods and techniques for utilizing media file URIs within HarmonyOS applications. It covers essential workflows for accessing media assets using the `photoAccessHelper` module, handling permissions such as `READ_IMAGEVIDEO`, and employing `PhotoViewPicker` for temporary authorization without explicit rights. Key topics include retrieving `PhotoAsset` objects, generating thumbnails, and extracting metadata like file size, dimensions, and timestamps. This resource is suitable for HarmonyOS developers working with Cangjie or ArkTS who need to implement robust image selection, URI handling, and media asset querying in their projects. It addresses scenarios ranging from basic access to complex metadata retrieval.
