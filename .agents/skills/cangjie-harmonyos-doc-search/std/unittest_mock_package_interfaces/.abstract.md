This directory serves as a specialized repository for the `unittest_mock_package_interfaces`, providing in-depth API reference documentation for the `ValueListener` interface within the Cangjie unittest mock package. Its primary purpose is to enable developers to monitor, capture, and process arguments passed to mock stubs with high precision. The content covers a wide array of functionalities, including key member functions like `addCallback` for defining custom operations, `allValues` and `lastValue` for retrieving captured data, and static methods `new` and `onEach` for interface instantiation. It also clarifies the interface's critical role in parameter matching when used in conjunction with `argThat` or `capture`. Illustrated with practical code examples demonstrating runtime assertions on captured objects, this resource is indispensable for developers writing unit tests who need to verify specific argument values and behaviors within mocked method calls to ensure application stability.
