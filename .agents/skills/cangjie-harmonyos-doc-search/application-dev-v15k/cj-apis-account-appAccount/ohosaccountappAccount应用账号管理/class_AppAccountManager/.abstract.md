This directory provides API reference documentation for the `AppAccountManager` class in the Cangjie programming language, part of the HarmonyOS BasicServicesKit. It covers comprehensive account management functionalities, including account creation, deletion, authentication token handling, data synchronization, and access control. Key topics involve credential management, event subscription, and authenticator configuration. This resource is intended for developers implementing secure account management, verifying permissions, and handling data sync within their Cangjie applications.
