This directory contains comprehensive documentation for the Checkbox component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the component's initialization, configuration properties, event handling, and practical implementation examples. Key topics include customizing shapes, colors, checkmarks, and managing selection states via `onChange` events. The documentation is intended for developers building user interfaces on HarmonyOS who need to implement flexible form controls and interactive options. It provides both API references and code samples to facilitate the creation of standard or custom-styled checkboxes starting from API version 12.
