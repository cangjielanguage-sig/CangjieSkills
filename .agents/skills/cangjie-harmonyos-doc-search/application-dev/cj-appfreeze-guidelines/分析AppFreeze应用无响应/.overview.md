### 应用无响应检测能力点.md 应用无响应检测能力点.md
This technical reference document outlines the detection mechanisms for application not responding (ANR) faults to assist developers in debugging. It details three specific fault types: main thread execution stall (THREAD_BLOCK_6S), user input response timeout (APP_INPUT_BLOCK), and Ability lifecycle switch timeout (LIFECYCLE_TIMEOUT). The text explains detection principles involving watchdog threads and liveness checks, distinguishing between warning and fault events based on specific time thresholds. It also provides a table of timeout durations for various lifecycle states like Load, Foreground, and Connect. This guide is intended for application developers seeking to understand the underlying causes of app freezes for better fault analysis and resolution.
