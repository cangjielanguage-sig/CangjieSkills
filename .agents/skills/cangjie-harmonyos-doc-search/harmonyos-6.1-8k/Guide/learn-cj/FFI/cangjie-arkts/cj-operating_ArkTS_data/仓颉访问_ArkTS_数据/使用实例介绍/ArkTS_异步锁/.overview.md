# ArkTS_异步锁

本目录主要介绍在ArkTS中如何利用异步锁解决多线程并发下的数据竞争问题。内容涵盖了结合Sendable对象在主线程与Worker线程间安全传递数据、使用AsyncLock保护共享资源，以及ArkTS与仓颉（Cangjie）动态库的互操作实现。核心知识点包括postMessageWithSharedSendable、lockAsync方法及Promise处理。适合需要进行高性能多线程并发开发且关注数据安全的HarmonyOS/OpenHarmony应用开发者参考。

## 详细描述

### ArkTS_异步锁_1.md
本文档旨在介绍如何在ArkTS中使用异步锁结合Sendable对象解决多并发实例间的数据竞争问题。文档涵盖了仓颉侧实现、TypeScript接口声明、主线程及Worker线程的代码示例。核心内容展示了如何定义包含AsyncLock的@Sendable类，并通过postMessageWithSharedSendable在主线程与Worker间安全传递对象，利用lockAsync方法保护共享数据，同时演示了仓颉与ArkTS的互操作。本文适合需要进行多线程并发开发且关注数据安全的HarmonyOS/OpenHarmony应用开发者阅读。

### ArkTS_异步锁_2.md
本文档演示了如何在 ArkTS 中使用 Worker 线程与仓颉动态库进行异步交互操作。涵盖了 Worker 线程的代码实现，包括导入仓颉动态库、监听主线程消息、执行异步任务及处理 Promise 结果，以及主线程启动 Worker 的逻辑。关键点包括导入与包名一致的仓颉动态库、利用 workerPort 进行线程间通信、在异步函数中调用仓颉接口并通过 Promise 处理返回结果。适用于需要掌握 ArkTS 多线程开发及仓颉互操作技术的 HarmonyOS 应用开发者。
