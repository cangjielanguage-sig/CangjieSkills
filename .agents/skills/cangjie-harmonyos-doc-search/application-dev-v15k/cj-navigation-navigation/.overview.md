# cj-navigation-navigation

This directory contains essential documentation for the Cangjie Navigation component, a core framework element designed to facilitate complex page routing and transition management in Cangjie applications. The content provides a deep dive into the architectural patterns required for building adaptive user interfaces, with a specific focus on multi-device deployment scenarios. It covers critical classes such as NavPathStack for stack manipulation and NavDestination for sub-page handling. Furthermore, it addresses advanced visual effects like shared element transitions using geometryTransition. Keywords associated with this directory include Navigation, NavPathStack, NavDestination, routing, Cangjie, shared element transition, geometryTransition, page stack, and multi-device deployment. This resource is highly suitable for Cangjie developers who need to implement robust, flexible navigation logic and ensure smooth visual continuity across different device form factors in their application development projects.

## Detailed Description

### cj-navigation-navigation.md

This comprehensive guide introduces the Navigation component, a vital tool for managing page routing and transitions in Cangjie applications. It provides a detailed overview of routing operations, with a specific focus on utilizing the NavPathStack class. Developers will find instructions on how to execute page jumps, manage returns, and handle the overall page stack efficiently. The guide also delves into sub-page management, explaining how to use NavDestination to create hierarchical page structures.

Beyond basic routing, the document addresses the implementation of transition animations to improve user engagement. It offers practical instructions for creating shared element transitions by employing geometryTransition within animateTo closures. Key takeaways include the strong recommendation to use NavPathStack for reliable stack management. This document is an essential resource for Cangjie developers aiming to build adaptive, multi-device applications that demand flexible navigation logic and seamless visual continuity between different pages and states.
