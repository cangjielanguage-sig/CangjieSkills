This directory provides a comprehensive technical guide for calculating Message Authentication Codes (MAC) and HMAC, essential mechanisms for verifying message integrity and authenticity in secure communications. It covers the theoretical foundations of MAC and HMAC, detailing how they utilize shared keys to prevent data tampering. The content includes a detailed list of supported hash algorithms, such as SHA1, SHA256, SHA512, SM3, and MD5, ensuring compatibility with API version 12 and above. Furthermore, it offers practical implementation guidance using the CryptoArchitectureKit in Cangjie, covering the full workflow from symmetric key generation to data processing. This resource is specifically designed for software developers and security architects seeking to integrate standardized cryptographic verification and robust message authentication capabilities into their applications.
