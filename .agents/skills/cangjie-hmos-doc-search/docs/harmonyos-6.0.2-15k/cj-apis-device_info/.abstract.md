This directory serves as a comprehensive resource for the `cj-apis-device_info` project, specifically focusing on the `ohos.device_info` module within the HarmonyOS ecosystem. It is tailored for developers using the Cangjie programming language to access read-only terminal device information. The directory covers essential topics such as querying device identifiers, retrieving build metadata, understanding operating system distribution, and accessing hardware specifications. This documentation is particularly suitable for HarmonyOS developers and system integrators who need to access system properties for debugging, analytics, or feature adaptation. It provides crucial guidance on permissions and context configurations, ensuring that users can successfully implement device info queries while adhering to the read-only nature of the module.
