# 栅格容器GridRow

This directory provides comprehensive technical documentation for the GridRow component within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers the essential aspects of building responsive grid systems, including how to configure total column counts, manage layout direction, and define spacing between child components. Additionally, it details the grid system's breakpoint rules for adapting layouts across different device widths, from xs to xxl. This resource is ideal for UI developers and software engineers seeking to implement adaptive, high-performance user interfaces that scale seamlessly across various screen sizes using ArkUI's grid capabilities.

## Detailed Description

### 布局的总列数.md 布局的总列数.md
This technical guide explains how to configure the total number of columns in the GridRow component for responsive layouts using the Cangjie language. It covers three main configuration methods: using the default 12-column setting, applying fixed custom integer values, and utilizing the GridRowColumnOption type for breakpoint-specific adjustments. Key takeaways include understanding how to define distinct column counts for six device sizes (xs, sm, md, lg, xl, xxl) and the inheritance logic for unspecified breakpoints, where smaller sizes default to 12 and larger sizes inherit the previous setting. This document serves as a reference for developers implementing adaptive grid systems in ArkUI applications.

### 排列方向_2more.md 排列方向_2more.md
This document serves as a technical guide for configuring the GridRow layout component in the Cangjie programming language. It focuses on two primary properties: arrangement direction and child component spacing. The first section explains the direction attribute, detailing how to set child component order from left to right (GridRowDirection.Row) or right to left (RowReverse). The second section covers the gutter attribute, illustrating how to define spacing using either a single Length value for uniform margins or a GutterOption object to specify distinct horizontal (x) and vertical (y) distances. The content includes code examples and visual demonstrations. This guide is intended for UI developers seeking to customize grid layouts and requires basic knowledge of the Cangjie syntax and grid system concepts.

### 栅格系统断点.md 栅格系统断点.md
This document defines the grid system breakpoint rules for responsive layout design based on device width. It covers default breakpoint definitions (xs, sm, md, lg), customization options supporting up to six types (xs to xxl), and configuration methods using the GridRow component. Key information includes defining breakpoints via monotonically increasing arrays in vp units and setting the reference to window size for dynamic layout adjustments. The document provides a Cangjie code example demonstrating how to apply different column spans across various breakpoints. This technical guide targets developers using the ArkUI framework to build adaptive user interfaces.
