This directory contains essential API reference documentation for the `AtomicBool` class in the Cangjie programming language, focusing on atomic operations for boolean values. It is a critical resource for developers building concurrent or multithreaded applications, providing the necessary low-level synchronization primitives to ensure thread safety. The documentation thoroughly covers the class constructor, Compare-And-Swap (CAS) operations, and atomic load/store functions. It also clarifies the distinction between current standard methods that use default memory ordering and deprecated versions that require explicit memory order parameters. This guide is specifically suitable for software engineers and systems programmers who need to manage shared boolean states safely and efficiently in a multi-threaded environment.
