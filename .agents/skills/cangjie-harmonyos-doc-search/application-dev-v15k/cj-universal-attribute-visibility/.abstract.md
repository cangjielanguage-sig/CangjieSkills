This directory serves as the central repository for the API reference documentation regarding the `cj-universal-attribute-visibility` module within the Cangjie ArkUI framework. It is specifically designed to provide developers with the necessary tools to control component display states through the visibility function. The documentation comprehensively outlines the function signature, required system capabilities, and detailed parameter definitions for the `Visibility` enum. It places a strong emphasis on the three distinct visibility modes: None (which hides the component without reserving layout space), Hidden (which hides the component while maintaining its space), and Visible (the default display state). This directory is an essential resource for Cangjie developers who need to precisely manage component rendering and layout behavior. By utilizing this guide, developers can effectively implement dynamic visibility controls to enhance the user experience and responsiveness of their applications.
