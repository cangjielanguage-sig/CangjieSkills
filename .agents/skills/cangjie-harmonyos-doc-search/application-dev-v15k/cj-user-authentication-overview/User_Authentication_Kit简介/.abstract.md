This directory provides an introduction to the User Authentication Kit, a system-level service designed to offer unified identity authentication capabilities. It covers the kit's definition, usage scenarios, and key features such as unified interfaces, trust level perception, and credential change detection. The documentation also outlines mandatory constraints for third-party applications, specifically regarding UI implementation and security policies. Additionally, it explores operational mechanisms like Authentication Trust Levels (ATL) and AuthToken generation within a Trusted Execution Environment (TEE). This resource is suitable for developers, security architects, and system integrators looking to integrate secure authentication methods like biometrics and passwords into their applications.
