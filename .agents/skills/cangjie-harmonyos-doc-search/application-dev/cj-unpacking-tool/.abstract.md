The `cj-unpacking-tool` directory contains a specialized utility designed for the OpenHarmony ecosystem, focusing on the decompression and parsing of application packages. It supports various formats, including HAP, HSP, and App files, providing developers with the means to extract configuration data and inspect package contents efficiently. The tool offers dual-mode functionality, supporting both command-line usage for quick tasks and Java API integration for seamless embedding into larger software projects. Additionally, it includes detailed schema definitions for critical internal data structures like `AppInfo` and `AbilityInfo`. This documentation is essential for developers building application markets, package management tools, or those debugging application bundles. Users should have a solid understanding of Java and HarmonyOS package structures to utilize this resource effectively.
