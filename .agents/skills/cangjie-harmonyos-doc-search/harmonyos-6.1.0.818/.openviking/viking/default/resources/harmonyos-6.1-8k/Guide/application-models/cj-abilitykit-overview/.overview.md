# cj-abilitykit-overview

本目录提供了 Ability Kit（程序框架服务）的全面概览，旨在阐述 HarmonyOS 应用模型框架的核心架构与运行机制。文档深入探讨了 Stage 模型、组件生命周期管理、上下文环境及访问控制等关键技术，并详细解析了多模块开发、跨设备流转以及组件与 UI 解耦等核心特性。通过介绍 Ability Kit 与 ArkUI 的紧密关系，本文档帮助开发者掌握如何构建高效、规范且支持多端协同的应用程序。该资料特别适合应用开发者阅读，旨在提升其对系统基础架构的理解，从而优化开发流程并改善最终用户体验。

### cj-abilitykit-overview.md cj-abilitykit-overview.md
本文档概述了 Ability Kit（程序框架服务），介绍了其作为应用模型框架提供的组件、运行机制及开发优势。文档主要涵盖使用场景（多模块开发、交互、跨设备流转）、能力范围（生命周期、上下文、访问控制）、核心特性（Stage 模型、组件与 UI 解耦、多设备支持）以及与 ArkUI 的关系。关键信息包括 Stage 模型支持组件级跨端迁移、面向对象的模块化开发，以及规范化的后台进程管理，旨在提升开发效率并优化用户体验。本文档面向应用开发者，旨在帮助其理解系统基础架构，以便构建复杂且支持跨设备流转的应用程序。关键词：Ability Kit, 应用模型, Stage 模型, 跨端迁移, UIAbility, 生命周期, 多模块开发。
