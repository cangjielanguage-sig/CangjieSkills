### [1] 枚举/

This directory serves as a specialized repository for enumeration types within the Cangjie programming language, specifically focusing on data structure handling and stream processing. It provides essential API documentation for developers working with these core types. In the context of modern software development, particularly when dealing with large-scale data, the ability to process JSON streams—rather than loading entire files into memory—is critical. The enumerations contained in this directory define the grammar and the various states that a parser can encounter during this stream processing. This includes definitions for object starts, array ends, and various value types, allowing the parser to make decisions on the fly. By isolating these definitions into a dedicated package, the Cangjie language promotes code reusability and modularity. Developers can rely on these enums to implement custom parsers or data handlers that are fully compliant with the language's standards. The documentation provided is not merely a list of values but a comprehensive guide to the API, explaining how these enums interact with the broader encoding and decoding libraries. This ensures that developers can integrate these types seamlessly into their projects, reducing the risk of type mismatches and logic errors during complex data manipulation tasks.
