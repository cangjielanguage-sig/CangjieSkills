This directory provides technical resources for developers working with Elliptic Curve Cryptography (ECC) in the Cangjie programming language. It focuses on the conversion between compressed and uncompressed point data formats using the CryptoArchitectureKit. The documentation covers essential operations such as generating point objects from byte arrays, retrieving encoded data, and creating public key objects from specific curve parameters like `NID_brainpoolP256r1`. These guides are suitable for Cangjie developers and cryptographic engineers looking to implement secure key generation and data transformation mechanisms.
