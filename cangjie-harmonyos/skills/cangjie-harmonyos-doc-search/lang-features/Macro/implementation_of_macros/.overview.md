# implementation_of_macros

This directory serves as a comprehensive technical resource for understanding the implementation of macro systems, with a specific focus on the Cangjie programming language. It provides a deep dive into the architecture of metaprogramming, covering essential topics such as macro definitions, core classifications (distinguishing between non-attribute and attribute macros), and the rules governing their invocation and nesting behaviors. The documentation explores advanced concepts like token validation, code generation strategies, and the manipulation of the Abstract Syntax Tree (AST) during macro expansion. This material is highly suitable for compiler engineers, language developers, and advanced programmers seeking to leverage compile-time code transformation to enhance efficiency and abstraction in their software projects.

## Detailed Description

### 宏的实现

This subdirectory provides an in-depth exploration of the implementation mechanisms and application specifications of the macro system within the Cangjie programming language. The content covers the basic definitions of macros, core classifications (distinguishing between non-attribute macros and attribute macros), invocation rules, and complex nesting behaviors. The documentation elaborates on Token legitimacy validation, ensuring that inputs meet syntactic requirements, and code generation techniques that allow for dynamic program creation.

Additionally, the text details the impact of macro expansion on the syntax tree (AST) and outlines specific limitation conditions that developers must observe. The primary goal of this section is to help developers fully grasp the core concepts of metaprogramming. It is particularly suitable for developers who wish to deeply understand the characteristics of the Cangjie macro system and perform compile-time code conversion and generation effectively.
