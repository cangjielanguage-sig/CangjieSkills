This directory contains the official documentation for the Cangjie Test Kit, an automated testing framework currently in Beta, designed specifically for the Cangjie language. It serves as a comprehensive guide for developers aiming to implement automated testing for their applications, covering both unit and UI testing scripts. The document details Unit Testing capabilities, including test definitions, assertions, setup/cleanup actions, and execution modes like stress testing. It also covers UI Testing capabilities, such as widget location, user interaction simulation, window manipulation, and system dialog monitoring. By allowing developers to verify functionality through automated scripts, the framework bridges the gap between unit tests and complex user action simulations, including hardware inputs. This resource is suitable for Cangjie language developers seeking to implement automated testing for their applications, ensuring robust software delivery and efficient quality assurance processes.
