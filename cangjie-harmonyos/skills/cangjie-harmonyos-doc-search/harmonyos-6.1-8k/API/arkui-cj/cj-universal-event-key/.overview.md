# cj-universal-event-key

本目录提供了ArkUI框架下Cangjie语言的通用按键事件API参考文档，旨在帮助开发者处理组件与键盘或遥控器之间的交互逻辑。文档核心内容涵盖了模块的导入方法、按键事件的具体定义以及`onKeyEvent`这一关键API函数的详细使用说明。它特别强调了该事件机制仅适用于当前获得焦点的组件（例如Button），并详细描述了`KeyEvent`回调参数及返回值类型。此外，文档还列出了相关的系统能力要求和起始版本信息。这份资料非常适合正在使用Cangjie语言构建ArkUI应用，且需要实现硬件按键输入响应功能的开发者查阅。核心关键词包括：ArkUI、Cangjie、按键事件、onKeyEvent、KeyEvent以及获焦组件。
