# cj-cangjiecrash-guidelines

This repository serves as a comprehensive technical resource for developers working within the Cangjie programming environment, focusing specifically on analyzing and resolving process crashes. It covers the full lifecycle of crash management, including understanding crash log specifications, distinguishing between `Error` and `Exception` types, and implementing effective problem location strategies. Key topics include retrieving logs via DevEco Studio or hiAppEvent, interpreting stack traces, and handling runtime errors like `OutOfMemoryError`. This guide is suitable for Cangjie developers aiming to enhance application stability, master advanced debugging workflows, and efficiently manage system-level resource exhaustion in production settings.
