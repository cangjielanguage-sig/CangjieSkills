This directory provides a comprehensive introduction to the Core File Kit within the HarmonyOS development environment, specifically designed to assist developers in mastering file access and management. It thoroughly covers the service's capabilities in handling both application and user files efficiently. Key topics include file classification models, sandbox isolation for ensuring security, and specific mechanisms for app sharing via URIs or File Descriptors (FDs). The content also details practical usage scenarios such as Create, Read, Update, Delete (CRUD) operations, data backup and restore, and cross-device synchronization. Furthermore, it delves into the architectural principles of file access frameworks, explaining the critical roles of FilePicker, ExtensionAbility, and various manager services. This resource is primarily suitable for HarmonyOS developers looking to implement robust file management, secure data sharing, and understand the underlying framework architecture.
