This directory serves as a technical repository for API reference documentation regarding the `ColorPicker` class and related image color analysis functions within the Cangjie programming language and ImageKit framework. It is designed to assist developers in extracting and analyzing dominant colors from image data and pixel maps. The content covers essential functionalities such as calculating average colors, determining the highest saturation colors, and ranking colors by their proportion within an image. Additionally, it includes utilities for verifying grayscale values. Complete with system capabilities, version requirements, and practical code examples, this documentation is ideal for developers in the Ark ecosystem focused on multimedia image processing and programmatic color property analysis.
