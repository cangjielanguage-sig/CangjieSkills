## 创建组件

### init(() -> Unit, ?Scroller, ?WaterFlowSections, WaterFlowLayoutMode)

```cangjie
public init(
    footer!: () -> Unit = { => },
    scroller!: ?Scroller = None,
    waterFlowSections!: ?WaterFlowSections = None,
    layoutMode!: WaterFlowLayoutMode = WaterFlowLayoutMode.ALWAYS_TOP_DOWN
)
```

**功能：** 创建一个WaterFlow容器。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|footer|()->Unit|否|{ => }| **命名参数。** 设置WaterFlow尾部组件。使用时结合[@Builder](../../../Dev_Guide/arkui-cj/paradigm/cj-macro-builder.md)和[bind](./cj-ui-framework.md#func-bindcustomview---viewbuilder-customview)方法使用。|
|scroller|?[Scroller](cj-scroll-swipe-scroll.md#class-scroller)|否|None| **命名参数。** 可滚动组件的控制器，与可滚动组件绑定。子组件与子组件之间间隙。<br/> **说明：**<br/> 不允许和其他滚动类组件，如：[List](./cj-scroll-swipe-list.md)、[Grid](./cj-scroll-swipe-grid.md)、[Scroll](./cj-scroll-swipe-scroll.md)和[WaterFlow](./cj-scroll-swipe-waterflow.md#waterflow)绑定同一个滚动控制对象。|
|waterFlowSections|?[WaterFlowSections](#class-waterflowsections)|否|None| **命名参数。** 设置FlowItem分组，实现同一个瀑布流组件内部各分组使用不同列数混合布局。<br/>**说明：**<br/>使用分组混合布局时会忽略columnsTemplate和rowsTemplate属性。<br/>使用分组混合布局时不支持单独设置footer，可以使用最后一个分组作为尾部组件。|
|layoutMode|[WaterFlowLayoutMode](#enum-waterflowlayoutmode)|否|ALWAYS_TOP_DOWN| **命名参数。** 设置WaterFlow的布局模式，根据使用场景选择更切合的模式。<br/>初始值：[ALWAYS_TOP_DOWN](#always_top_down)。|
