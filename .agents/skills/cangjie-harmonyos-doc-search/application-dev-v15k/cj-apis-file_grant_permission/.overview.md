# cj-apis-file_grant_permission

This directory serves as a comprehensive resource for the HarmonyOS `ohos.file_grant_permission` module, specifically adapted for the Cangjie programming language. It provides in-depth documentation on the critical mechanisms required for granting, persisting, revoking, and managing file access permissions associated with URIs. The content covers essential technical components such as enums defining operation modes and error codes, classes dedicated to policy management, and functions designed for activating or deactivating permissions. This documentation is primarily intended for HarmonyOS developers who are tasked with implementing secure folder authorization features within their applications. Users must possess the `ohos.permission.FILE_ACCESS_PERSIST` capability to utilize these APIs effectively. By offering detailed technical specifications, this directory ensures developers can handle file access rights securely and efficiently, maintaining the integrity of user data while enabling necessary application functionality.
