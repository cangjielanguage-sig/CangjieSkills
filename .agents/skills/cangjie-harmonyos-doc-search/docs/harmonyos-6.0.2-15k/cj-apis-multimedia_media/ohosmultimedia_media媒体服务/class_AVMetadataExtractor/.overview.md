# class_AVMetadataExtractor

This directory contains comprehensive API reference documentation for the Cangjie `AVMetadataExtractor` class, a core component of the MediaKit framework designed for retrieving metadata from various media resources. It covers essential functionalities such as setting data sources for both streaming media and local file descriptors, fetching album art as PixelMaps, and obtaining general media information. Additionally, it details resource management procedures to ensure efficient memory usage. This documentation is suitable for HarmonyOS developers and multimedia application engineers who need to programmatically access media file details, handle album covers, and manage system resources effectively within their Cangjie projects.

## Detailed Description

### class_AVMetadataExtractor_5more.md
This document provides API reference documentation for the Cangjie AVMetadataExtractor class, designed to retrieve metadata from media resources. It details properties for setting data sources, specifically dataSrc for streaming media and fdSrc for local file descriptors. Key sections include the fetchAlbumCover function for retrieving album art as PixelMap and fetchMetadata for obtaining general media information. The documentation specifies return types, potential BusinessException error codes, and provides code examples demonstrating initialization and usage. This technical reference targets developers building multimedia applications who need to programmatically access media file information or album covers.

### func_release.md
This document serves as API reference documentation for the Cangjie function release(), which is designed to free resources associated with the AVMetadataExtractor. The file details the function signature, system capabilities, and the minimum API version required. It explicitly lists potential exceptions, specifically the BusinessException with error code 5400102 indicating disallowed operations. A practical Cangjie code example demonstrates how to initialize the extractor with a file descriptor and safely call the release method within a try-catch block. This guide targets HarmonyOS developers utilizing the MediaKit to manage multimedia resource lifecycles effectively.
