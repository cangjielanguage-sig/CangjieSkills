# class_GlobalFunctionInfo

This directory contains API reference documentation for the `GlobalFunctionInfo` class within the Cangjie language reflection package. It covers the structural definition of global function metadata, including properties for annotations, parameters, and return types, as well as methods for dynamic function invocation and introspection. Key topics include reflection, generic function execution, runtime analysis, and exception handling. This documentation is suitable for developers working with runtime reflection who need to inspect or programmatically execute global functions in Cangjie.

### class_GlobalFunctionInfo_6more.md class_GlobalFunctionInfo_6more.md
This API reference document details the GlobalFunctionInfo class, which represents metadata for global functions in the Cangjie language. The content outlines the class definition, its inheritance from interfaces like Equatable and Hashable, and its core properties. ### func_applyArrayAny.md func_applyArrayAny.md
This API reference document details the `apply` function used to dynamically invoke global functions via reflection. The content covers the function signature, functionality description, input parameters, return values, and a comprehensive list of potential exceptions. Key information includes that the function accepts an `Array<Any>` of arguments which must strictly match the target function's parameter types and count. It returns an `Any` type result. Important exceptions include `InvocationTargetException` for generic functions, `IllegalArgumentException` for argument count mismatches, and `IllegalTypeException` for type incompatibilities. This documentation is intended for developers working with runtime reflection in the Cangjie programming language who need to execute functions dynamically.
