This directory contains API reference documentation for the `ohos.thermal` module in the Cangjie programming language, focusing on HarmonyOS thermal management capabilities. It provides detailed definitions for the `ThermalLevel` enum, which categorizes device thermal states, and outlines the core functions necessary for monitoring and responding to temperature changes. Key topics include thermal state definitions, system capability requirements, and event subscription mechanisms. This resource is suitable for system and application developers who need to implement thermal optimization strategies, ensuring applications dynamically adjust behavior to maintain device stability and performance under varying thermal conditions.
