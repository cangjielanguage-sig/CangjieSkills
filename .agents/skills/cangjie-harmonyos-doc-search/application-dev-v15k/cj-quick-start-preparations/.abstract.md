This directory serves as a comprehensive entry point for beginners initiating Cangjie application development on the HarmonyOS platform. It covers fundamental concepts such as the UI framework and the Stage application model, which abstracts essential app components for easier management. The content outlines four distinct learning paths, including pure Cangjie apps, hybrid Cangjie-ArkTS projects, incremental development, and cross-language module calls. Designed for developers new to the ecosystem, it requires the installation of the latest DevEco Studio. By following the tutorials, users will learn to build a simple application with page navigation to master the project structure and development workflow, ensuring a solid foundation for future projects. This guide is essential for anyone looking to modernize their development skills or integrate new language features into the HarmonyOS environment effectively.
