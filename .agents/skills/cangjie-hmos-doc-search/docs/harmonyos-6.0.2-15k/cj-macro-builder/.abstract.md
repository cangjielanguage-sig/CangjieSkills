This directory serves as a comprehensive technical resource for the `cj-macro-builder` project, specifically focusing on the implementation and optimization of the `@Builder` macro within the Cangjie UI framework. It is designed to assist developers in transitioning from basic UI coding to advanced, reusable component architecture. The content thoroughly explores the mechanics of declarative UI syntax, providing deep insights into how custom build functions can be structured to enhance modularity and reduce code redundancy. Key topics include the distinction between private and global implementation methods, the critical differences between pass-by-value and pass-by-reference parameters, and the integration of reactive state management using `@State` and `@Observed`. This documentation is essential for Cangjie UI developers and HarmonyOS application engineers who are looking to streamline their development workflow, ensure efficient UI refresh mechanisms, and build scalable, dynamic user interfaces with professional-grade code reusability.
