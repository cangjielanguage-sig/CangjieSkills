# 启动命令start

本目录主要介绍HarmonyOS开发中用于启动Stage模型组件的`aa start`命令。文档涵盖了UIAbility和ServiceExtensionAbility的显式与隐式启动方式，详细说明了命令语法、参数配置（如设备ID、URI、窗口属性）及错误处理。此外，还深入讲解了如何通过命令行传递数字、布尔值等参数，以及如何拉起浏览器跳转指定页面。内容包含Cangjie语言代码示例，适用于需要掌握命令行调试工具及组件启动流程的应用开发者。

## 详细描述

### 启动命令start_1.md
本文档详细介绍了用于启动Stage模型下UIAbility或ServiceExtensionAbility组件的`aa start`命令。内容涵盖显式与隐式启动的语法、参数列表（包括设备ID、URI、窗口属性等）、返回值及错误码。文档强调了目标组件需配置`exported`为true，并提供了隐式启动的配置与命令示例。这是一份面向开发者的命令行参考指南，适用于应用调试和组件启动测试。关键词：aa start, UIAbility, 隐式启动, 显式启动, Stage模型, 命令行工具, 调试。

### 启动命令start_2.md
本文档主要介绍如何使用 aa start 命令启动 UIAbility 并传递参数，以及如何通过命令拉起浏览器跳转指定页面。文档涵盖了通过命令行传递数字、布尔值、字符串及空字符串参数的方法，并提供了在 UIAbility 的 onCreate 方法中获取这些参数的 Cangjie 代码示例；同时展示了使用 -A 和 -U 参数启动浏览器访问指定 URL 的用法。关键信息包括 aa start 命令的具体参数格式（如 --pi, --pb, --ps），以及通过 want.parameters.get() 方法在代码中解析传入参数的实现逻辑。该文档适用于 HarmonyOS 应用开发者，特别是需要掌握命令行启动应用及处理启动参数的 Cangjie 语言使用者。
