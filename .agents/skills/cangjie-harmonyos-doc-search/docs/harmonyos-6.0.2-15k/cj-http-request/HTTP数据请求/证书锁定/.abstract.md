This directory focuses on Certificate Pinning, a vital security technique used to secure HTTPS connections by strictly limiting them to specific, developer-defined certificates or public keys. It addresses the need to prevent Man-in-the-Middle (MitM) attacks and ensures robust network communication protocols. The content covers the complete workflow, from understanding the hierarchical JSON configuration structure—encompassing global base-config and domain-specific rules—to the practical execution of pinning using OpenSSL commands for SHA256 hash generation. It highlights critical operational considerations, such as the necessity of app updates when server certificates change. This documentation is primarily intended for application developers and system administrators, particularly those operating within the HarmonyOS/OpenHarmony ecosystem, who are responsible for implementing and maintaining high-security standards in their applications.
