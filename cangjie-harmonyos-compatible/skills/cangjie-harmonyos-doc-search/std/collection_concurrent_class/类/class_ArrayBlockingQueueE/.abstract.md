This directory contains API reference documentation for the `ArrayBlockingQueue` class in the Cangjie programming language. It focuses on a thread-safe, array-based blocking queue with a fixed capacity, essential for managing concurrent data structures. The documentation covers class properties, constructors, and various member functions including blocking, non-blocking, and timed operations. It also highlights deprecated methods and provides code examples for multi-threaded environments. This resource is suitable for Cangjie developers looking to implement safe synchronization and manage queue interactions in concurrent applications.
