# 事件分发

本目录深入解析了ArkUI框架中事件分发的核心机制，涵盖了从触控事件产生到最终响应的完整流程。主要内容包括事件分发的概述、不同输入源（如手指、鼠标）的事件类型、触摸测试的判定逻辑以及事件响应链的收集与遍历规则。文档详细阐述了`hitTestBehavior`属性如何控制事件传递与阻塞，帮助开发者理解底层逻辑。适合ArkUI应用开发者阅读，旨在提升对触控交互和事件处理的理解与控制能力。
