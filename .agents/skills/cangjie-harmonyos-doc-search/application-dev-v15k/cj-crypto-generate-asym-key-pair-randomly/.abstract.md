This directory provides a specialized technical tutorial designed for developers utilizing the Cangjie programming language, with a specific focus on the CryptoArchitectureKit. The primary objective of this resource is to instruct users on the secure and random generation of asymmetric key pairs, which are vital for modern cryptographic operations such as encryption, decryption, and digital signing. The document delves into the practical implementation of two major industry-standard algorithms: RSA, widely recognized for secure data transmission, and SM2, a standard often employed in specific cryptographic ecosystems. It meticulously details the necessary parameter strings and the step-by-step workflow required to instantiate an `AsyKeyGenerator`. Furthermore, it explains how to invoke the `generateKeyPair` function to produce public and private keys, followed by the `getEncoded` method to serialize these keys into binary formats suitable for secure storage or network transmission. This guide is indispensable for Cangjie developers aiming to build secure, robust applications, offering clear, actionable code examples to bridge the gap between theoretical cryptography and practical software development. It addresses the nuances of algorithm selection and parameter configuration, making it suitable for both novice and experienced programmers.
