# chir_dis_manual

本目录包含仓颉编程语言中 CHIR 反序列化工具 `chir-dis` 的使用手册。该文档详细介绍了如何将编译器输出的 CHIR 序列化文件转换为可读的文本格式，涵盖了工具的功能简介、命令行参数说明及具体操作样例。核心内容包括输入输出文件格式解析、命令选项（如 `-v` 和 `-h`）的使用方法，以及如何通过命令行执行 `chir-dis` 处理 `.chir` 文件以生成 `.chirtxt` 文本文件。本文档主要面向需要深入分析仓颉编译器中间表示（CHIR）的开发者，旨在帮助用户高效地查看和理解编译器输出。
