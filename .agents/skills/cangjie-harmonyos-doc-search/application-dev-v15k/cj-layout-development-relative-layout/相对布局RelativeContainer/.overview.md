# 相对布局RelativeContainer

This directory focuses on the RelativeContainer component within the Cangjie UI and ArkUI frameworks. It covers the implementation of relative positioning to optimize complex interface layouts by reducing deep component nesting. Key topics include alignment rules, anchor configurations, dimension priority, component chains, and dependency management. The documentation provides practical code examples in Cangjie and ArkTS to help developers create responsive and efficient user interfaces. It is suitable for HarmonyOS developers and UI engineers looking to master relative positioning constraints and layout performance optimization.

## Detailed Description

### 多种组件的对齐布局.md
This document demonstrates how to implement relative alignment for various layout components using the RelativeContainer in the Cangjie UI framework. The content features a practical code example illustrating the placement of Row, Column, Flex, and Stack components within a parent container. The key takeaway is the usage of alignRules with AlignRuleOption, VerticalAnchor, and HorizontalAnchor to position elements relative to the container boundaries or specific sibling component IDs. This guide targets Cangjie developers seeking to create complex, responsive UI layouts through relative positioning constraints.

### 概述_2more.md
This document introduces the RelativeContainer component, designed to optimize performance in complex interface layouts by reducing deep component nesting. The content covers an overview of layout optimization challenges and defines basic concepts such as reference boundaries, anchors, and alignment modes. Key takeaways include understanding how RelativeContainer allows child elements to position themselves relative to siblings or the parent container, thereby minimizing overhead. It explains flexible alignment strategies like top, middle, bottom, left, center, and right. This guide targets developers seeking efficient layout solutions for complex UI scenarios.

### 组件尺寸.md
This document explains the priority rules for determining component dimensions when explicit size settings conflict with relative layout alignment rules within a RelativeContainer. It covers the conflict resolution between explicit size attributes and alignRules, conditions under which components fail to render, and provides a practical code example using Cangjie language to demonstrate complex relative positioning. Key takeaways include that explicit size settings have higher priority than alignment anchors. To ensure strict alignment, developers should avoid explicit size settings. Additionally, the document notes that components are not drawn if size is indeterminate or if anchor positions are logically inconsistent. This technical reference guide targets developers using the ArkUI framework with Cangjie, specifically those implementing complex layouts using RelativeContainer who need to understand rendering constraints and dimension calculation logic.

### 多个组件形成链/
This directory explores the concept of forming component chains within the ArkUI framework using RelativeContainer. It details the logic of linking components through anchor dependencies, configuring chain directions, and applying styles such as SPREAD and PACKED. The documentation covers overflow handling rules and bias attributes, providing practical examples in both Cangjie and ArkTS. It is designed for HarmonyOS developers aiming to master complex relative positioning and layout constraints to create cohesive and responsive user interfaces.

### 设置依赖关系/
This directory focuses on establishing and managing dependency relationships within the ArkUI framework, specifically for RelativeContainer layouts. It covers essential concepts such as configuring reference boundaries, setting alignment positions relative to anchor points, and defining anchor points themselves. Key topics include horizontal and vertical alignment rules, dependency constraints, and cycle prevention to ensure layout stability. The documentation provides practical code examples in Cangjie and ArkTS. It is suitable for HarmonyOS developers and UI engineers seeking to create precise, responsive, and complex user interfaces by mastering relative positioning and component dependencies.
