This directory contains API reference documentation for synchronization and concurrency classes in the Cangjie programming language. It covers a wide range of tools for managing multi-threaded execution, including locks like Mutex and ReadWriteLock, coordination primitives like Barriers and Semaphores, and atomic operations for various data types. Additionally, it includes documentation for task scheduling via the Timer class. While some legacy classes are deprecated, the collection provides essential resources for developers implementing thread-safe, high-performance concurrent systems.
