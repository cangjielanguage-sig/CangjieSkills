# SaveButton

This directory contains comprehensive documentation for the SaveButton component within the ArkUI framework, specifically designed for HarmonyOS developers using the Cangjie language. It covers the implementation of secure file saving features that grant temporary storage permissions without requiring user confirmation dialogs. The content includes API references for component creation, basic type definitions for styles and results, and practical code examples for UI integration. Suitable for developers looking to implement secure save controls, configure button behaviors, and handle authorization outcomes in their applications.

## Detailed Description

### SaveButton_5more.md SaveButton_5more.md
This document provides API reference documentation for the SaveButton component within the ArkUI framework, designed to grant temporary storage permissions without user confirmation dialogs. It details component creation methods, including default initialization and customizable constructors for icon, text, and button style, alongside the onClick event handling. Key information includes that the component requires at least an icon or text, supports static configuration only, and returns authorization results via the SaveButtonOnClickResult enum upon interaction. This guide targets developers using the Cangjie language to implement secure file saving features in ArkUI applications.

### 基础类型定义.md 基础类型定义.md
This document serves as API reference material defining basic enumeration types for the ArkUI Save Button component in the Cangjie language. It covers three primary enumerations: SaveIconStyle, which configures visual icon styles; SaveDescription, which sets text labels for various actions like saving or downloading; and SaveButtonOnClickResult, which indicates permission authorization outcomes. Key takeaways include specific enum values such as FullFilled, SaveToGallery, and Success, all supported from API version 20 with full system capabilities. This reference guide targets HarmonyOS developers needing to configure save button behaviors and handle authorization results.
