# cj-l10n-translation-scene

This directory contains a specialized guide focused on the critical process of providing translation context for software localization. It addresses the common challenge of linguistic deviations by emphasizing the importance of scene information. The content covers specific methodologies for conveying this context, including the use of annotations directly within string resource files and the inclusion of interface screenshots. Key concepts include documenting part of speech, defining key word meanings, specifying maximum text lengths, and outlining variable ranges in code comments. This resource is primarily suitable for developers and localization managers who are responsible for preparing user interface strings, ensuring that translators receive the necessary background to deliver accurate and high-quality translations. By following these guidelines, teams can significantly reduce the risk of misinterpretation and improve the overall efficiency of the localization workflow, ultimately leading to a better product for global users. The guide acts as a bridge between technical code and linguistic nuance.

### cj-l10n-translation-scene.md cj-l10n-translation-scene.md

This document serves as a vital guide for technical teams aiming to provide precise translation context, thereby ensuring accuracy and avoiding linguistic deviations. It begins by discussing the overarching importance of scene information, explaining why it is a prerequisite for high-quality localization. The guide then details two specific, actionable methods for providing this information: utilizing annotations within string resource files and providing clear interface screenshots.

Furthermore, the document highlights several key takeaways for developers. It stresses the necessity of documenting specific details in code comments, such as the context of the string, the part of speech, and the meanings of key words. Additionally, it covers technical constraints like maximum text length and variable ranges. This reference material is specifically intended for developers and localization managers who are preparing UI strings for translation. By equipping translators with this sufficient information, teams can ensure the production of accurate and contextually appropriate results, streamlining the entire localization process.
