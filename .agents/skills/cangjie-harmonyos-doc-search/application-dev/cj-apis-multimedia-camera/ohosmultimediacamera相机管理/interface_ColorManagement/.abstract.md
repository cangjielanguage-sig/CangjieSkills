This directory provides comprehensive API reference documentation for the ColorManagement interface within the Cangjie CameraKit framework. It is dedicated to the management, configuration, and querying of camera color spaces, with a specific focus on supporting advanced display capabilities like P3 and HDR. The documentation outlines critical implementation details, such as function syntax, system prerequisites, and strict mapping rules between CameraFormat and ColorSpace to ensure visual fidelity. It also addresses error handling and session configuration flows to prevent performance issues. This resource is essential for multimedia developers and systems engineers aiming to integrate sophisticated color management into camera applications, ensuring optimal performance across various video and photo modes while avoiding common configuration errors.
