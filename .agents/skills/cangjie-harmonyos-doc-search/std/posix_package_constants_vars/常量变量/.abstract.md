This directory contains API reference documentation for deprecated POSIX constants within the Cangjie programming language. It covers a wide range of system-level identifiers, including file system operation flags, file permission settings, file type identifiers, and signal handling constants. Each document details specific constant values, platform-specific variations (macOS, Windows), and associated functions, while explicitly marking them as deprecated for future removal. This resource is suitable for Cangjie developers maintaining legacy code, performing low-level I/O operations, or migrating applications away from deprecated POSIX interfaces.
