This directory provides comprehensive technical guidance for integrating express delivery capabilities into HarmonyOS applications using the `startAbilityByType` API. It covers the complete interaction workflow, addressing both the caller side and the target side of the process. Key topics include invoking the system-level express delivery extension panel, constructing JSON parameters (such as expressNo and sceneType), and handling callbacks to display app selection. Additionally, it details how to configure a HarmonyOS app to receive and process these feature-based requests via `module.json5` and URI schemes. This content is specifically suitable for HarmonyOS developers using the Cangjie language and the AbilityKit framework who need to implement cross-app tracking features or deep linking functionality.
