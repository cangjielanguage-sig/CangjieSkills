# 使用Display实现屏幕属性查询及状态监听

本目录主要介绍如何在HarmonyOS应用开发中使用Display接口进行屏幕属性的查询与状态监听。内容涵盖了获取屏幕分辨率、密度、刷新率等基础属性，以及如何处理挖孔屏等不可用区域。此外，还详细讲解了如何监听屏幕旋转和折叠设备的折叠状态变化。文档包含ArkUI及仓颉语言的代码示例，适用于需要根据屏幕硬件信息适配UI界面的HarmonyOS开发者。

### 使用Display实现屏幕属性查询_4more_fd458398.md

本文档是一份开发指南，旨在介绍如何使用Display接口查询屏幕属性及监听屏幕状态变化。主要涵盖场景介绍、常用接口说明以及获取Display对象的方法。核心内容包括查询屏幕分辨率、密度、刷新率等属性，监听屏幕旋转及折叠状态变化，并提供了获取默认Display对象的代码示例。适用于需要根据屏幕硬件信息适配UI界面的HarmonyOS应用开发者，需具备基础编程能力。关键词：Display, 屏幕属性, 状态监听, 折叠屏, ArkUI。

### 获取屏幕相关属性_2more_d3828863.md

本文档旨在指导开发者使用仓颉语言获取屏幕属性及监听折叠设备状态。文档主要分为两部分：一是通过Display对象获取屏幕ID、宽高、刷新率等基础信息，以及利用getCutoutInfo获取挖孔屏等不可用区域以优化UI布局；二是介绍如何判断设备是否可折叠，并通过注册回调函数监听折叠状态的变化（如展开、折叠、半折叠）。文档包含完整的代码示例，适用于HarmonyOS应用开发，要求开发者已掌握Display对象的获取方法。
