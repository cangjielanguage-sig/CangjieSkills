This directory defines the Uniform Type Descriptor (UTD) system, a standard for resolving data type ambiguity across formats like MIME types and file extensions. It organizes preset types into Basic Types, System-associated Types, and Application-defined Types to ensure seamless cross-application and cross-device data transmission. The content includes detailed mapping tables for UTD-IDs, file extensions, and MIME types across various platforms (OpenHarmony, MacOS, Android, etc.) and software ecosystems. It is suitable for developers, system architects, and integrators working on data interoperability, file type recognition, and cross-platform communication protocols.
