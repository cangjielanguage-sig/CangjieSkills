### cj-universal-event-touch.md cj-universal-event-touch.md

本文档是ArkUI框架中Cangjie语言的触摸事件API参考文档，旨在定义组件上手指触摸交互的处理方式。文档主要包含模块导入指令及`onTouch`函数的详细规范，涵盖功能描述、系统能力、起始版本、参数列表和返回值类型。核心信息指出`onTouch`函数通过接收`TouchEvent`类型的回调函数来响应手指的按下、滑动和抬起动作，并返回通用方法接口类型T。该文档面向使用Cangjie语言进行ArkUI应用开发的开发者，要求读者具备基础的事件监听和UI组件开发知识。
