# 导入所需API模块

本目录主要介绍如何使用仓颉语言在HarmonyOS平台上开发蓝牙低功耗（BLE）应用。内容涵盖了GATT客户端的完整生命周期，包括实例创建、连接管理、服务发现、特征值读写以及处理服务端数据变化通知与指示。核心涉及ConnectivityKit模块的使用及错误处理机制。适合具备一定蓝牙基础和仓颉编程能力的HarmonyOS应用开发人员参考。
