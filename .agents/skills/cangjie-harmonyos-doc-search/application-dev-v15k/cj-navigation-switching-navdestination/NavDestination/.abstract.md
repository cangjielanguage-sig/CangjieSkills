This directory contains comprehensive documentation for the NavDestination component, a root container for sub-pages within the Navigation framework using the Cangjie language. It covers API references, usage constraints, lifecycle behaviors, and configuration attributes. Key topics include component constructors, event handling, property customization, and fundamental type definitions. This resource is suitable for developers and software engineers using the ArkUI framework who need to implement complex page navigation, manage sub-page hierarchies, and control UI state transitions in HarmonyOS applications.
