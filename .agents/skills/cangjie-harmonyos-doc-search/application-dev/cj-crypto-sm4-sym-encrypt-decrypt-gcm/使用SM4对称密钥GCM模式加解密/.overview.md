# 使用SM4对称密钥GCM模式加解密

This directory provides comprehensive resources for implementing encryption and decryption using the SM4 symmetric key algorithm in GCM (Galois/Counter Mode) with PKCS7 padding. It covers the complete cryptographic workflow within the CryptoArchitectureKit, detailing essential processes such as 128-bit key generation, parameter initialization, data processing, and the critical handling of authentication tags (authTag). The materials are specifically designed for developers working with the Cangjie programming language who need to integrate secure, high-performance cryptographic operations into their applications. Key topics include SM4_128, GCM mode, symmetric key management, and secure data verification. The content supports both single-pass and multi-pass data processing scenarios, offering flexibility for various application requirements.
