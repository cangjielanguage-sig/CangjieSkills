# struct_String

This directory contains comprehensive API reference documentation for the `String` struct in the Cangjie programming language. It covers a wide range of string manipulation capabilities, including basic comparisons, searching, splitting, trimming, and case conversion. The documentation details operator overloads for indexing and concatenation, as well as static methods for high-performance UTF-8 handling. Key topics include UTF-8 byte arrays, rune iteration, memory constraints, and exception handling. This resource is suitable for Cangjie developers seeking detailed syntax, parameter definitions, and usage examples for implementing efficient string processing logic in their applications.
