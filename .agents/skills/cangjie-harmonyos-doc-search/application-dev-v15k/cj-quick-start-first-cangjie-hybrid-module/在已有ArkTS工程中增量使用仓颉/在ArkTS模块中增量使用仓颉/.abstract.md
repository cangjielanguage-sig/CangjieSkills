This directory provides a comprehensive guide for HarmonyOS developers on incrementally integrating the Cangjie programming language into existing ArkTS projects. It covers essential workflows such as enabling Cangjie support in HAP or HAR modules, embedding Cangjie components within ArkTS pages, and performing cross-module function calls. Key topics include SDK API 12-15 support, module configuration, UI integration, and interoperability mechanisms like `@Interop` annotations. This resource is ideal for developers using DevEco Studio who wish to leverage Cangjie's capabilities within their current ArkTS codebases without a complete rewrite.
