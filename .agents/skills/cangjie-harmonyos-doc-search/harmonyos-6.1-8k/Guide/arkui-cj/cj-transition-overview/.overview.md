# cj-transition-overview

本目录提供了关于转场动画的全面概述文档，旨在帮助开发者深入理解并高效实现组件的出现与消失效果。内容涵盖了转场动画的核心概念、设计目的及详细分类，具体包括出现/消失转场、模态转场、共享元素转场、页面转场动画（已不推荐）及旋转屏动画。文档重点阐述了转场动画与属性动画的本质区别，以及如何通过动画机制简化节点状态管理，避免在回调中手动删除节点的繁琐操作。该文档特别适合需要实现复杂界面切换、组件动态效果或希望优化UI状态管理逻辑的开发者阅读。

## 详细说明

### cj-transition-overview.md cj-transition-overview.md
本文档概述了转场动画的概念、目的及分类，旨在帮助开发者通过动画处理组件的出现与消失，从而简化节点状态管理。文档主要介绍了五种转场类型：出现/消失转场、模态转场、共享元素转场、页面转场动画（不推荐）及旋转屏动画。关键信息指出，转场动画区别于属性动画，能避免在回调中手动删除节点，且推荐使用模态转场替代页面转场。本文档适合需要实现界面切换或组件动态效果的开发者阅读。
