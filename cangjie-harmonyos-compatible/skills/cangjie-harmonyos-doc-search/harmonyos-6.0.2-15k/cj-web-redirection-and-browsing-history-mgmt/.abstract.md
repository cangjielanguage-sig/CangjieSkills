This directory focuses on web redirection and browsing history management within the context of HarmonyOS development using the Cangjie language. It provides technical guidance on integrating web content with native applications, specifically utilizing the ArkWeb component. Key topics include controlling web page history, managing page transitions triggered by web links, and handling URL schemes to bridge web and native logic. This resource is suitable for developers building hybrid applications who need to implement seamless navigation, network permission configuration, and cross-application routing features.
