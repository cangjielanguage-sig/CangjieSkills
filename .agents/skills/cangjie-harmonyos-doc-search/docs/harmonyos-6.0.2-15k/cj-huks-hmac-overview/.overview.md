# cj-huks-hmac-overview

This directory provides a specialized technical reference focused on HMAC (Hash-based Message Authentication Code) implementation within the HarmonyOS Universal Keystore (HUKS) framework. It is designed to assist developers and security engineers in understanding how to utilize HMAC for ensuring robust message integrity and authentication in their software projects. The content covers the theoretical underpinnings of HMAC concepts and transitions into practical implementation details necessary for real-world application. Key topics include a detailed breakdown of supported algorithms such as SHA256, SHA384, SHA512, and SM3, alongside specific technical constraints like key length ranges and the requirement for API level 15+. This resource is essential for those building secure HarmonyOS applications who need precise information on cryptographic compatibility and system limitations to ensure their code meets the highest security standards.
