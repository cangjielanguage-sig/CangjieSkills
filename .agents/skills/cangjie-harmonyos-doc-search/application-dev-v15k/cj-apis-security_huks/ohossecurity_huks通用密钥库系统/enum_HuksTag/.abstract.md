This directory contains API reference documentation for the `HuksTag` enumeration within the HarmonyOS Universal Keystore Service (HUKS), specifically implemented in the Cangjie language. It covers a comprehensive range of cryptographic tags used to define parameters for key generation, storage, encryption, decryption, and authentication. The documentation details system capabilities, API version requirements (starting from version 15), and the status of various tags, including active, deprecated, and reserved fields. It is suitable for HarmonyOS developers and security engineers working on secure key management, cryptographic operations, and hardware-backed keystore integration.
