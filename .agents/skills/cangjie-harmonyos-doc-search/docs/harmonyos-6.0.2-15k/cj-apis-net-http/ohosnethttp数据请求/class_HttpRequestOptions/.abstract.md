This directory contains API reference documentation for the `HttpRequestOptions` class in the Cangjie programming language, specifically designed for the SystemCapability.Communication.NetStack. It covers the configuration of HTTP requests, including optional parameters for security (SSL certificates), timeouts, DNS resolution, proxy settings, and data handling. The documentation details constructors, read-only properties for request methods, headers, and caching mechanisms. It is suitable for developers building robust networked applications who need fine-grained control over network communication behaviors, data serialization, and encoding requirements.
