# cj-macro-provide-and-consume

This directory serves as a technical resource for the Cangjie framework, specifically focusing on the `@Provide` and `@Consume` macros. It addresses the implementation of two-way data synchronization between ancestor and descendant components, a critical requirement for building scalable applications. The content covers core concepts, variable access rules, usage constraints, and practical scenarios ranging from simple counters to complex collections. It is designed for developers working with HarmonyOS and Cangjie's declarative UI who need efficient cross-level state management without the overhead of manual parameter passing, ensuring automatic UI updates and data consistency.

## Detailed Description

### Provide宏和Consume宏与后代组件双向同步/
This directory provides a comprehensive technical guide on implementing two-way data synchronization between ancestor and descendant components using the `@Provide` and `@Consume` macros in the Cangjie framework. It covers core concepts, variable access rules, usage constraints, and practical scenarios ranging from basic counters to complex collections. Designed for developers working with HarmonyOS and Cangjie's declarative UI, these resources facilitate efficient cross-level state management without manual parameter passing, ensuring automatic UI updates and data consistency across component hierarchies.
