# cj-declare-permissions

本目录提供了关于HarmonyOS应用权限声明的详细配置指南，核心内容聚焦于如何在应用的`module.json5`配置文件中准确申请和管理权限。文档深入解析了`requestPermissions`标签的配置细节，包括`name`、`reason`和`usedScene`等关键属性的使用方法。特别针对`user_grant`类型的权限，文档强调了`reason`字段的必填性、多语言资源适配规范以及文案长度的具体限制。此外，还涵盖了权限组在系统授权弹窗及设置界面中的展示逻辑。该文档主要面向HarmonyOS应用开发者，旨在帮助其完成应用权限的合规配置，确保应用顺利通过上架校验。

## 详细说明

### cj-declare-permissions.md cj-declare-permissions.md
本文档旨在指导开发者在HarmonyOS应用配置文件中正确声明所需权限。文档详细说明了在module.json5文件的requestPermissions标签中配置name、reason和usedScene等属性的方法，并提供了JSON配置样例。重点阐述了user_grant类型权限的reason字段必填要求、多语言适配规范及文案长度限制，同时解释了权限组在授权弹窗和设置界面中的展示逻辑。本文面向HarmonyOS应用开发者，属于配置指南类文档，帮助开发者完成应用权限的合规申请与上架校验。
