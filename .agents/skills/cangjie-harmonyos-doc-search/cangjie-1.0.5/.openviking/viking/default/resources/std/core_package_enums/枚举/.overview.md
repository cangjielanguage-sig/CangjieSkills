# 枚举

This directory serves as a centralized API reference for fundamental enumerations within the Cangjie programming language. It encompasses a variety of core data structures ranging from system-level utilities like `AnnotationKind` and `Endian` to essential functional programming components such as `Option` and `Ordering`. The documentation provides detailed definitions, valid usage contexts, and interface implementations for these types. It is specifically designed for Cangjie developers who need to implement custom annotations, handle platform-specific byte orders, manage safe null states, or perform type comparisons using the standard library's robust enumeration types.

## Detailed Description

### enum_AnnotationKind_2more.md enum_AnnotationKind_2more.md
This API reference document details the definitions and usage of two enumerations within the Cangjie core package: AnnotationKind and Endian. The first section covers AnnotationKind, listing valid targets for custom annotations such as types, parameters, functions, and variables. The second section describes the Endian enum, which represents platform byte order (Big or Little). Key information includes the specific declaration contexts supported by annotations and the Endian.Platform static property, which retrieves the runtime system's endianness. This technical documentation is intended for developers working with custom annotations or low-level data processing in Cangjie.

### enum_Ordering.md enum_Ordering.md
This document provides API reference documentation for the Cangjie Ordering enum, which represents comparison results. It covers the three primary variants: LT (less than), GT (greater than), and EQ (equal). Key sections detail the implementation of the Comparable, Hashable, and ToString interfaces. The document specifies the natural ordering hierarchy (GT > EQ > LT), distinct hash codes for each variant, and their string representations. This technical reference is designed for Cangjie developers who need to utilize comparison types within the standard library.

### enum_OptionT/
This directory provides comprehensive API documentation for the `Option` enum within the Cangjie programming language, designed to facilitate safe null handling and functional programming patterns. It details the encapsulation of values that may or may not exist, covering the core enum definition, constructors (`Some`, `None`), and syntactic sugar (`?Type`). The content includes functional methods for value extraction, transformation, and inspection, alongside interface implementations for `Hashable`, `ToString`, and `Equatable`. This resource is essential for Cangjie developers aiming to manage potential null states robustly, utilize optional values in hash-based collections, and implement safe type conversions without risking runtime exceptions.
