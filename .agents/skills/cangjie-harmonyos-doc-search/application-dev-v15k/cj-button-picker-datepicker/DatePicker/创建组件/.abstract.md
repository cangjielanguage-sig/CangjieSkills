This directory provides comprehensive API reference documentation for creating sliding date picker components using the Cangjie language within the HarmonyOS ArkUI framework. It focuses on the `initDateTime` constructors, detailing how to initialize date selection interfaces with specific parameters for start dates, end dates, and selected values. The documentation covers critical system capabilities, including date range validation (hard limits of 1900-2100), automatic edge case correction, and support for two-way data binding. These resources are essential for ArkUI developers (version 12 or higher) who need to implement robust, user-friendly date selection controls while adhering to strict system constraints and logic handling. By following these guides, developers can ensure their applications handle date inputs correctly across various scenarios.
