# 应用权限管控概述

This directory provides a comprehensive overview of the application permission control mechanism, essential for managing resource access and ensuring system security. It details the fundamental architecture, including identity mapping via TokenID, risk-based classifications through APL (Ability Privilege Level), and the Access Control List (ACL) for privilege escalation. Furthermore, it explores the operational principles of permission access, emphasizing minimization, strict declaration, and the distinction between system and user authorization types. By covering protection objects and dynamic user authorization for sensitive data, this guide serves as a critical resource for application developers and system architects aiming to build secure, compliant, and user-friendly applications that adhere to strict security protocols.

## Detailed Description

### 权限机制中的基本概念.md 权限机制中的基本概念.md
This reference document defines the fundamental concepts governing the system's permission mechanism to manage application resource access. It covers TokenID for unique identity mapping, APL (Ability Privilege Level) classifications for both applications and permissions, and the Access Control List (ACL) mechanism. Key takeaways include that TokenID handles multi-user and app cloning scenarios, while APL levels (normal, system_basic, system_core) restrict permission access based on risk levels. The ACL provides a pathway for lower-level apps to apply for higher-level permissions if enabled. This guide targets developers needing to understand permission hierarchy and authorization logic for application development.

### 简介_4more.md 简介_4more.md
This document introduces the system's permission access mechanism designed to protect system data and capabilities from misuse. It covers permission protection objects, usage principles like minimization and strict declaration, and the distinction between system_grant and user_grant authorization types. Key information includes the requirement for dynamic user authorization for sensitive permissions and the use of permission groups to optimize interaction. This guide targets application developers seeking to implement secure, compliant, and user-friendly permission requests.
