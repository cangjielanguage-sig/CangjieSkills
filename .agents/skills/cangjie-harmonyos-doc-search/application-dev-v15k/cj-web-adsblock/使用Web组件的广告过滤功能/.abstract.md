This directory focuses on the ad filtering capabilities of the ArkWeb component, providing a comprehensive guide for developers working with the Cangjie language. It covers the implementation of EasyList syntax rules for blocking network requests and hiding page elements, as well as the complete lifecycle of ad blocking management. Key topics include rule configuration, exception handling, statistics collection, and system constraints. This documentation is suitable for developers and system administrators looking to integrate robust, customizable ad-blocking features into their web applications while understanding the technical boundaries and operational logic of the ArkWeb framework.
