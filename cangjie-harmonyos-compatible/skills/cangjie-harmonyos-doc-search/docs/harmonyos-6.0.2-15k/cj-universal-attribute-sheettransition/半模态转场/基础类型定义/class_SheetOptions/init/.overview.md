# init

This directory contains API reference documentation for the `init` constructor function used to configure half-modal pages (sheets) in the Cangjie language. It covers a comprehensive range of configuration options, including visual styling, layout sizing, lifecycle management, and user interaction logic. Key topics include drag behavior, dismissal callbacks, and display modes. This documentation is suitable for developers building ArkUI applications who require granular control over the appearance and behavior of semi-modal interfaces, ensuring precise customization for interactive UI components.

## Detailed Description

### init_1.md
This document provides API reference documentation for the init constructor function in the Cangjie language, used to configure optional attributes for a half-modal page. The main content details the function signature, which includes a comprehensive list of optional parameters for styling (background, borders), lifecycle management (onAppear, onDisappear), layout (height, width, detents), and user interaction (dragBar, dismissal logic). Key information highlights that this feature is available starting from version 12 and belongs to the SystemCapability.ArkUI.ArkUI.Full capability. The document targets developers building ArkUI applications who require granular control over modal sheet behavior and appearance.

### init_2.md
This document serves as an API reference for configuring initialization parameters of a half-modal page component. It details properties for visual styling, layout sizing, and interaction control, alongside comprehensive lifecycle event callbacks. Key information includes complex rules for the height parameter based on screen orientation, the detents property for managing swipeable height steps with specific velocity thresholds, and the onWillDismiss callback for intercepting close actions. It also highlights constraints like prohibiting state variable modification during onWillDisappear. This reference is intended for developers implementing customizable semi-modal interfaces requiring precise control over appearance and behavior.

### init_3.md
This document provides API reference details for configuring a half-modal (sheet) component, focusing on event handling, styling, and display modes. It outlines callbacks for dismissal logic, dimension changes (height, width, type), and specific behaviors like rebound effects during swipe gestures. Styling parameters include border properties, width, and shadow, with specific notes on limitations for bottom popups. It also explains display hierarchy settings via SheetMode and content refresh timing via ScrollSizeMode. Intended for developers building interactive UIs, this reference requires understanding of component properties and event listeners to effectively customize the half-modal's appearance and interaction logic.
