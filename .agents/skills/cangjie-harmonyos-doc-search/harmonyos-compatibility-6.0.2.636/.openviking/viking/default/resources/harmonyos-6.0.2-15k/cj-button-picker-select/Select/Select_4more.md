# Select

提供下拉选择菜单，可以让用户在多个选项之间选择。

## 子组件

无

## 创建组件

### init(Array\<SelectOption>)

```cangjie
public init(values: Array<SelectOption>)
```

**功能：** 构造一个下拉选择菜单组件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|values|Array\<[SelectOption](#class-selectoption)>|是|-|设置下拉选项。|

## 通用属性/通用事件

通用属性：全部支持。

通用事件：全部支持。
