# cj-menu-contextmenu

This directory serves as a comprehensive API reference for the `ContextMenu` class, specifically designed for developers working within the ArkUI framework using the Cangjie programming language. The primary objective of this documentation is to elucidate the functionality required to programmatically close context menus within a defined page scope. It provides an in-depth look at the static `close` function, outlining its method signature, necessary system capabilities, and the specific framework version where it became available. Beyond technical specifications, the document includes practical, executable code examples that demonstrate how to effectively implement the `ContextMenu.close` method. These examples show how to dismiss menus that are bound to UI components via the `bindContextMenu` attribute, particularly within the context of event handlers such as `onDragStart`. This resource is indispensable for ArkUI developers, UI/UX designers, and software engineers who require granular control over component states and interactions to build responsive, user-friendly applications.
