# 使用AES对称密钥CCM模式加解密

本目录主要介绍如何使用AES对称密钥的CCM模式进行数据的加密与解密操作。内容涵盖了从密钥生成、Cipher实例创建到加解密流程的完整实现细节，特别强调了CCM模式不支持分段处理及认证标签验证的重要性。相关文档基于CryptoArchitectureKit开发，适用于仓颉语言开发者及需要实现高安全性数据加密的用户。
