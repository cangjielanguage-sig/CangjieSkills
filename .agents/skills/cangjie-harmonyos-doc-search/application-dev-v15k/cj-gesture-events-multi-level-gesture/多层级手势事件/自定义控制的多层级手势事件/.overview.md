# 自定义控制的多层级手势事件

This directory provides a comprehensive guide to managing complex touch interactions and gesture conflicts within the Cangjie UI framework. It focuses on multi-level component scenarios, detailing how to control event distribution, define custom response regions, and prioritize gesture handling between parent and child elements. Key topics include `hitTestBehavior` modes, various gesture binding methods like `.priorityGesture`, and the use of `responseRegion` for precise touch area definition. This resource is essential for UI developers seeking to implement sophisticated interaction logic and resolve input handling issues in nested layouts.

## Detailed Description

### hitTestBehavior对手势和事件的控制.md hitTestBehavior对手势和事件的控制.md
This technical guide explains how to use the `hitTestBehavior` property to control touch event and gesture distribution in complex multi-level UI components. The document details three specific modes: `HitTestMode.Block`, `HitTestMode.Transparent`, and `HitTestMode.None`, providing code examples and behavioral comparisons for each. Key takeaways include that Block consumes events and blocks children and siblings, Transparent allows siblings to receive events, and None ignores self-events to allow propagation. The guide recommends binding behaviors to single components for simple scenes and multiple components for complex scenarios. Intended for UI developers using the Cangjie framework, this resource helps resolve gesture conflicts and manage event dispatching effectively.

### 绑定手势方法对手势的控制.md 绑定手势方法对手势的控制.md
This technical guide explains how to manage gesture response priorities between parent and child components in multi-level scenarios. It covers three specific binding methods: standard `.gesture`, `.priorityGesture`, and `.parallelGesture`. Key takeaways include that standard binding gives priority to the child component, priority binding allows the parent to override the child, and parallel binding enables both to respond simultaneously. The document provides Cangjie code examples to illustrate these behaviors. It is intended for developers working on UI interactions who need to resolve gesture conflicts in nested component structures.

### 自定义控制的多层级手势事件_2more.md 自定义控制的多层级手势事件_2more.md
This technical guide explains how to customize multi-level gesture event competition and touch distribution in Cangjie development. It covers the usage of `responseRegion`, `responseRegionArray`, and `hitTestBehavior` properties, distinguishing their impact on touch event distribution versus gesture competition. Key takeaways include the ability to define response areas that differ from component layout bounds using single or multiple rectangles. Crucially, these properties affect both `onTouch` callbacks and gestures, whereas gesture binding properties only influence gesture competition. This document targets UI developers with prerequisite knowledge of Cangjie syntax and component layout who require precise control over event handling and response regions.
