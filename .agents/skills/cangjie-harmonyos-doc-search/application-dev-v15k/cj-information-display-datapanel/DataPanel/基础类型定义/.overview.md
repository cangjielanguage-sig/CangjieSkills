# 基础类型定义

This directory provides essential API references for basic type definitions within the Cangjie ArkUI framework, focusing on data visualization and UI styling components. It includes detailed documentation for shadow options, linear gradients, and data panel layout types. These resources are designed for developers working with HarmonyOS applications who need to implement sophisticated visual effects and configure data presentation styles. By understanding these fundamental types, developers can effectively customize the appearance and behavior of UI elements using the Cangjie language.

## Quick Navigation

**What do you want to learn or configure?**

## Detailed Description

### class_DataPanelShadowOptions.md class_DataPanelShadowOptions.md
This document provides API reference documentation for the Cangjie class DataPanelShadowOptions, which defines shadow styles for data panels within the ArkUI framework. The content details the class properties, including the blur radius, X and Y axis offsets, and an array of linear gradient colors for different data segments. It explains the initialization method and specific logic for handling color array lengths relative to data segments. Key information includes the system capability requirements and version 12 compatibility. This reference is intended for developers seeking to customize the visual appearance of data panels using Cangjie, requiring knowledge of basic UI styling and the Length type.

### class_LinearGradient_2more.md class_LinearGradient_2more.md
This document provides API reference details for the LinearGradient and ColorStop classes used to define linear color gradients in the Cangjie ArkUI framework. It covers the LinearGradient class properties and constructors, followed by the ColorStop class definition, including its color and offset attributes. Key information includes that LinearGradient supports initialization via an array of ColorStop objects or a single ResourceColor, while ColorStop defines specific gradient points using a color value and a normalized offset between 0 and 1. This reference is intended for UI developers using Cangjie to implement advanced styling and visual effects in HarmonyOS applications.

### enum_DataPanelType.md enum_DataPanelType.md
This document serves as an API reference for the DataPanelType enumeration within the Cangjie ArkUI framework, defining the visual layout styles for data panels. The content covers the enum definition and details its two specific members: LineType for linear displays and CircleType for ring-shaped displays. Key information includes the system capability requirements and the introduction of these types in API version 12. This reference is intended for UI developers using the Cangjie language to configure data visualization components. Keywords: Cangjie, ArkUI, DataPanelType, Enum, LineType, CircleType, API Reference.
