# net_socket

本目录提供了仓颉语言中网络编程的详细技术文档，核心聚焦于基于传输层协议的Socket编程功能。文档内容全面覆盖了网络通信的两大基石：TCP可靠传输与UDP不可靠传输编程模型。它不仅从理论层面讲解了服务端与客户端的创建、端口绑定、监听机制、连接建立及数据读写等关键流程，还深入探讨了无连接模式下的数据报收发机制。通过引入TcpServerSocket、TcpSocket和UdpSocket等核心类的实际代码示例，本指南为开发者提供了极具参考价值的实践指导。无论是初学者还是有经验的开发者，只要具备基础网络知识，都能通过本文档快速上手仓颉语言的网络通信开发。

## Detailed Description

### net_socket.md net_socket.md

该文件是本目录的核心文档，旨在系统性地介绍仓颉语言中基于传输层协议的Socket编程功能。文档内容主要分为两大板块：TCP可靠传输和UDP不可靠传输编程模型。在TCP部分，文档以详尽的篇幅讲解了服务端与客户端的交互逻辑，涵盖了从Socket创建、地址绑定、监听设置、连接建立到最终数据读写的完整流程。而在UDP部分，文档则侧重于阐述无连接模式下的数据报收发机制及其特点。为了增强实用性，文中通过具体的代码示例，生动展示了TcpServerSocket、TcpSocket和UdpSocket等核心类的API使用方法及交互逻辑。这是一份面向开发者的专业编程指南，特别适合那些已经具备基础网络知识，希望深入学习仓颉网络通信实现的用户阅读。
