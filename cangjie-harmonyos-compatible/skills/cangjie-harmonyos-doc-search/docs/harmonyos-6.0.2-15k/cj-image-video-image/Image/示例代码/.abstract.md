This directory contains Cangjie code examples designed for HarmonyOS UI development, focusing specifically on image manipulation and display techniques. It covers essential topics such as loading various image formats (PNG, GIF, SVG, JPG), implementing interactive events, applying color filters, and configuring advanced display properties like objectFit, objectRepeat, and rendering modes. The examples demonstrate state management with @State and performance optimization through decoding dimensions. These resources are suitable for Cangjie developers and UI engineers looking to enhance their applications with rich media handling, custom image styling, and dynamic visual effects.
