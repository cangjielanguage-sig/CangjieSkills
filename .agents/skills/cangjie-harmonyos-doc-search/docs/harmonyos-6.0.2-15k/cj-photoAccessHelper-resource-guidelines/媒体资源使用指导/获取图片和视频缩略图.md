## 获取图片和视频缩略图

通过接口[getThumbnail](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-getthumbnailsize)，传入缩略图尺寸，可以获取图片和视频缩略图。缩略图常用于UI界面展示。

**前提条件**

- 获取相册管理模块photoAccessHelper实例。
- [申请相册管理模块读权限](./cj-photoAccessHelper-preparation.md#申请相册管理模块功能相关权限)'ohos.permission.READ_IMAGEVIDEO'。
- 导入[dataSharePredicates](../../../API_Reference/source_zh_cn/apis/ArkData/cj-apis-data_share_predicates.md)模块。

### 获取某张图片的缩略图

当需要在相册展示图片和视频、编辑预览时，应用需要获取某张图片的缩略图。

参考以下示例，获取图片的文件描述符fd后，需要解码为统一的PixelMap，方便在应用中进行图片显示或图片处理，具体请参见[图片解码](../image/cj-image-decoding.md)。

下面以获取一张图片的缩略图为例，缩略图尺寸为720*720。

**开发步骤**

1. 建立检索条件，用于获取图片资源。
2. 调用[getAssets](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-getassetsfetchoptions-1)接口获取图片资源。
3. 调用[getFirstObject](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-getfirstobject)接口获取第一张图片。
4. 调用PhotoAsset.getThumbnail获取图片的缩略图的[PixelMap](../../../API_Reference/source_zh_cn/apis/ImageKit/cj-apis-image.md#class-pixelmap)。

```cangjie
import kit.MediaLibraryKit.*
import kit.ArkData.*
import kit.ImageKit.*
import ohos.base.BusinessException

let phAccessHelper = getPhotoAccessHelper(Global.context)

func example() {
    let predicates: DataSharePredicates = DataSharePredicates()
    let fetchOptions: FetchOptions = FetchOptions(
        fetchColumns: [],
        predicates: predicates
    )
    try {
        let fetchResult: FetchResult<PhotoAsset> = phAccessHelper.getAssets(fetchOptions)
        let photoAsset: PhotoAsset = fetchResult.getFirstObject()
        AppLog.info('getAssets photoAsset.displayName : ' + photoAsset.displayName)
        let size: Size = Size(width: 720, height: 720)
        let pixelMap: PixelMap = photoAsset.getThumbnail(size: size)
        let imageInfo: ImageInfo = pixelMap.getImageInfo()
        AppLog.info('getThumbnail successful, pixelMap ImageInfo size: ${size.width}, ${size.height}')
        fetchResult.close()
    } catch (e: BusinessException) {
        AppLog.error('getAssets failed with err: ' + e.toString())
    }
}
```
