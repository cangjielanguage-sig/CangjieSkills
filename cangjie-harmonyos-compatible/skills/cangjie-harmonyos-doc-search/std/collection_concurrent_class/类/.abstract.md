This directory contains API reference documentation for core concurrent classes within the Cangjie standard library. It focuses on thread-safe data structures essential for multi-threaded programming, including various implementations of maps and queues. The documentation covers class definitions, constructors, and methods for handling synchronization, atomic operations, and blocking behaviors. It is suitable for Cangjie developers building concurrent applications who need precise technical details to manage shared data safely and efficiently, avoiding data conflicts and deadlocks.
