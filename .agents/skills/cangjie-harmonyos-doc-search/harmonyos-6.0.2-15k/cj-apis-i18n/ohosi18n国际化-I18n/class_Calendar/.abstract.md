This directory contains API reference documentation for the `Calendar` class within the Cangjie LocalizationKit, specifically designed for internationalization (I18n) tasks. It covers comprehensive functionalities for date and time manipulation, including arithmetic operations, field comparisons, time zone configuration, and locale-specific formatting. Developers can find methods to retrieve specific date components, check weekend status, and manage calendar properties like week start days. The documentation is intended for software developers working on I18n features who need precise control over calendar logic and date validation in their Cangjie applications.
