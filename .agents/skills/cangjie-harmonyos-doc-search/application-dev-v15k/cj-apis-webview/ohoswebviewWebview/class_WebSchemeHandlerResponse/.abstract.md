This directory provides comprehensive API reference documentation for the `WebSchemeHandlerResponse` class within the Cangjie programming language, tailored for HarmonyOS developers. It focuses on the mechanisms for creating and managing custom responses for intercepted web requests in the Web component. The documentation encompasses class constructors, getter methods for response attributes, and setter functions for modifying response properties. Key areas include handling character encoding, HTTP headers, MIME types, status codes, and network errors. This resource is essential for developers working with ArkWeb and UIKit.Web modules to implement custom protocol handling and enhance WebView interactions.
