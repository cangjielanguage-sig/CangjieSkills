This directory provides comprehensive API reference documentation for the `AlertDialogParamWithOptions` class within the Cangjie programming language and the ArkUI framework. It is designed to assist developers in configuring alert dialogs that support multiple buttons, covering essential properties such as the buttons array and `buttonDirection`. The documentation details three public constructors that offer varying levels of control over layout and styling, including advanced visual features like background blur, border styling, and transitions. Available starting from API version 12, this content is specifically tailored for UI developers and HarmonyOS engineers seeking to implement customizable, multi-button alert popups with robust interaction behaviors in their applications.
