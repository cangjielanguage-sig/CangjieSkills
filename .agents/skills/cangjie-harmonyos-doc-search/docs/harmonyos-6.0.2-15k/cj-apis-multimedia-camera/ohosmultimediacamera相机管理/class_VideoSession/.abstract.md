This directory contains API reference documentation for the `VideoSession` class within the Cangjie language CameraKit framework. It covers standard video recording scenarios, detailing class structures, inheritance capabilities like Flash and Zoom, and methods for session management. Key topics include event listener registration (`on`/`off`), preconfiguration of camera settings (resolution and aspect ratio), and error handling. The documentation includes parameter definitions, system capabilities, and Cangjie code examples. It is suitable for developers building multimedia applications who need to programmatically control camera sessions, handle real-time events, and manage configurations.
