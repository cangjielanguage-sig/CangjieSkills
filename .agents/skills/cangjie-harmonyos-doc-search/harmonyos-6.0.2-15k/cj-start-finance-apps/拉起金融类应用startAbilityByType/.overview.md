### 拉起金融类应用startAbilityByType_3more.md

### 目标方开发步骤.md
This guide outlines the development steps for configuring a HarmonyOS application to act as a target for specific feature links, such as financial transfers or credit card repayments. It covers configuring module.json5 with linkFeature and URI attributes, and parsing incoming parameters within the UIAbility lifecycle methods. Developers must define supported features and match URI schemes to handle external requests. The document provides a Cangjie code example demonstrating how to extract want.uri and parameters like bankCardNo to dynamically load specific pages based on the invoked feature. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to implement deep-linking or cross-application feature invocation.
