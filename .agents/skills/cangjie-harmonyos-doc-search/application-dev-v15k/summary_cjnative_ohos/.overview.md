# summary_cjnative_ohos

This directory contains a comprehensive collection of documentation summaries for native application development on OpenHarmony and HarmonyOS using the Cangjie programming language. It covers the full development lifecycle, from getting started and project configuration to advanced UI implementation with ArkUI, system-level security, cryptography, and media handling. Key topics include the Stage model, state management, network connectivity, hardware interaction, and debugging tools. These resources are designed for developers seeking to build high-performance, secure native applications using Cangjie, providing both foundational guides and specific API references for system kits.
