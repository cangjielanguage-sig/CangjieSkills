This directory provides comprehensive resources for implementing encryption and decryption using the SM4 symmetric key algorithm in CBC mode with PKCS7 padding. It covers the complete technical workflow, including generating 128-bit symmetric keys, creating cipher instances, and managing initialization vectors. The materials are specifically tailored for developers utilizing the CryptoArchitectureKit within the HarmonyOS ecosystem. By following these guides, developers can effectively secure data handling, support chunked data processing, and ensure compliance with SM4 standards using the Cangjie programming language.
