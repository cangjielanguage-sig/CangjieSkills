# 使用场景

This section covers practical usage scenarios for state management in HarmonyOS applications using Cangjie. It focuses on AppStorage and LocalStorage, explaining how to implement two-way data synchronization between application logic and UI components. Key topics include managing complex data types like DateTime and collections, as well as best practices for event notifications to avoid performance overhead. It is suitable for Cangjie and HarmonyOS developers looking to optimize reactive state management, ensure data isolation, and build efficient, responsive user interfaces.

## Detailed Description

### 从应用逻辑使用AppStorage和LocalSto_2more.md 从应用逻辑使用AppStorage和LocalSto_2more.md
This technical guide explains how to utilize AppStorage and LocalStorage for state management in Cangjie applications. It covers two primary usage scenarios: accessing storage within application logic and integrating it with UI components. The document distinguishes AppStorage as a singleton with static APIs from LocalStorage, which requires instantiation. Key takeaways include the implementation of two-way data synchronization using the link API in logic and the @StorageLink and @LocalStorageLink decorators in UI views. Targeted at developers building HarmonyOS applications with Cangjie, this tutorial provides code examples demonstrating data isolation between storage types and reactive updates in the user interface.

### 装饰DateTime类型变量_3more.md 装饰DateTime类型变量_3more.md
This tutorial demonstrates how to use the @StorageLink decorator to manage state for complex data types like DateTime, Map, and Set in Cangjie applications. The document is divided into three sections, each providing a runnable code example for binding these specific types to AppStorage. Key takeaways include the syntax for initializing these variables and the pattern of modifying data to trigger view refreshes, particularly the requirement to reassign collection variables after modification to update the UI. Intended for Cangjie developers working on HarmonyOS, this guide explains reactive state management for non-primitive types, ensuring dynamic user interfaces.

### 不建议借助StorageLink的双向同步机制实现事件通知/
This directory provides comprehensive technical guidance and best practices for optimizing event notification mechanisms within HarmonyOS applications. It specifically addresses the anti-pattern of using `@StorageLink` and AppStorage's bidirectional synchronization for event handling, highlighting the significant performance overhead and unnecessary UI refreshes that result from state-based notifications. The content covers the theoretical drawbacks of this approach and offers a practical alternative using the `emit` interface for event subscription and callbacks. By decoupling components through the Emitter pattern, developers can achieve better performance and code readability. This resource is essential for HarmonyOS developers and architects aiming to refine state management strategies and build efficient, responsive applications using ArkTS.
