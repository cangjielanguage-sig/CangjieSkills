# 基础类型定义

This directory serves as a comprehensive resource for fundamental type definitions used in configuring list components within the ArkUI framework, specifically designed for the Cangjie language. It encompasses essential enumerations and parameter classes that dictate the visual presentation and structural configuration of list item groups. Key topics include the `ListItemGroupStyle` enum for defining group appearances and the `ListItemGroupParams` class for managing layout properties like headers, footers, and spacing. This documentation is highly suitable for Cangjie developers seeking to programmatically customize the behavior and aesthetics of list components, ensuring precise control over UI element grouping and styling in their applications.

## Detailed Description

### enum_ListItemGroupStyle.md enum_ListItemGroupStyle.md
This document serves as API reference documentation for the ListItemGroupStyle enumeration in the Cangjie language, used to define the visual style of list item groups within the ArkUI framework. The content details the enum definition and explains its two specific values: CARD, which applies a default card appearance, and NONE, which removes specific styling. Key information includes the system capability classification and the requirement of API version 19. This reference is intended for Cangjie developers building user interfaces with ArkUI who need to customize the visual presentation of list components. Keywords: Cangjie, ListItemGroupStyle, ArkUI, API reference, enum, List component, UI styling.

### class_ListItemGroupParams/
This directory provides comprehensive API reference documentation for the `ListItemGroupParams` class within the ArkUI framework, specifically tailored for the Cangjie language. It serves as a technical guide for developers building user interfaces, detailing the configuration parameters necessary for list item grouping components. The content covers essential class properties such as header, footer, space, and style, alongside multiple constructor overloads for object initialization.
