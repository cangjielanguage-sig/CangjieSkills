# Memoize_宏

本目录包含关于仓颉语言中 Memoize 宏的技术文档，旨在通过宏自动化实现算法的记忆化优化。内容涵盖了记忆化的基本概念、斐波那契数列的性能对比、宏展开代码的深度分析，以及基于 std.ast 的完整宏源码实现。核心要点在于利用 HashMap 缓存计算结果以避免重复计算，从而显著提升递归效率，并详细展示了如何通过 AST 操作生成代码。此外，还深入探讨了输入合法性检查及代码生成的具体步骤。这些文档适合熟悉仓颉语法的开发者学习宏编程及性能优化技巧。

## 详细描述

### Memoize_宏_1.md
1. 本文档介绍了仓颉语言中 Memoize 宏的实现与使用，旨在通过宏自动化实现算法的记忆化优化。
2. 涵盖了记忆化概念、斐波那契数列性能对比、宏展开代码分析及基于 std.ast 的完整宏源码。
3. 核心要点是利用 HashMap 缓存计算结果以避免重复计算，显著提升递归效率，并展示了如何通过 AST 操作生成代码。
4. 适合熟悉仓颉语法的开发者学习宏编程及性能优化技巧。

### Memoize_宏_2.md
本文档详细阐述了Memoize宏的实现逻辑，重点介绍了输入合法性检查及代码生成的具体步骤。主要内容包括属性与输入的合法性校验（如布尔字面量检查、单参数函数声明解析）、哈希表变量的生成以及利用quote模板构建返回代码的过程。关键点在于宏必须确保输入为单参数函数声明，并生成不易冲突的哈希表变量名，最终结合参数名、类型及返回类型通过模板生成最终代码。该文档属于技术实现参考，面向具备元编程基础的开发者，旨在指导如何构建具有缓存功能的宏。
