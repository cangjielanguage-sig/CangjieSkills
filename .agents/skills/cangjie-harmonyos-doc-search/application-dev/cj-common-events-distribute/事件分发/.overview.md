# 事件分发

This directory focuses on the event dispatching mechanism within the ArkUI framework. It covers the fundamental concepts of how user operations (touch and mouse) are processed, distributed to components, and how response chains are constructed. Key topics include touch testing, event classification (Touch vs. Mouse), and algorithms for collecting event response chains. This documentation is suitable for ArkUI developers who need to understand the underlying logic of user interaction handling, component hit testing, and event propagation to build responsive UI applications.

## Detailed Description

### 事件分发_2more.md 事件分发_2more.md
This document explains the mechanism of event dispatching within the ArkUI framework, detailing how user operations are processed and distributed to components. It covers the overview of event dispatching, the classification of touch events into Touch and Mouse categories, and the critical role of touch testing in determining event targets. Key takeaways include the distinction between Touch class events (finger, pen) and Mouse class events (joystick), and how touch testing governs the generation of event response chains and the triggering of component-bound events. Intended for developers working with ArkUI, this technical reference requires an understanding of UI components and user interaction handling. Keywords: ArkUI, event dispatching, touch testing, touch events, mouse events, event response chain.

### 事件响应链的收集.md 事件响应链的收集.md
This technical reference document explains the mechanism and algorithm for collecting event response chains in the ArkUI framework. It covers the definition of the event response chain, the specific post-order traversal algorithm prioritizing right subtrees, and provides Cangjie pseudo-code implementation. Key takeaways include a component tree example demonstrating the formation of the response chain 5-3-1 and an explanation of how the Default hitTestBehavior attribute blocks sibling nodes during collection. This guide targets ArkUI developers needing to understand touch event propagation and component interaction logic.

### 触摸测试.md 触摸测试.md
This technical guide explains the touch testing mechanism in ArkUI, defining how component response areas are determined and event response chains are constructed upon receiving touch or mouse events. Main sections cover the basic touch test flow involving tree traversal and bubbling, touch test control modes via hitTestBehavior, disabling controls, touch hot zone settings using responseRegion, and security component interactions. Key information details how specific modes like Block and Transparent affect event propagation, and how transparency or Z-order obscuring impacts event collection. Intended for ArkUI developers, this document provides the necessary logic to manage complex event handling and component interaction behaviors.
