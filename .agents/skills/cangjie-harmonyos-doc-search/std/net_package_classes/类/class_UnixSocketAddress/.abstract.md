This directory contains comprehensive API reference documentation for the `UnixSocketAddress` class within the Cangjie standard library. It focuses on the technical implementation of encapsulating Unix Domain Socket file system paths. The documentation covers class inheritance hierarchies, various constructors accepting `String` or `Array<Byte>`, and essential properties like `family` and `size`. Key topics include handling named, unnamed, and abstract addresses, managing path length limitations, and retrieving raw byte arrays compatible with the `sockaddr_un` structure. This resource is specifically suitable for Cangjie developers implementing low-level network communication who require precise specifications for managing socket addresses, converting them to strings, or comparing instances.
