# 通过关系型数据库实现数据持久化

This directory provides a comprehensive guide to implementing data persistence using relational databases, specifically leveraging SQLite within the HarmonyOS ArkData framework. It is designed to assist developers in managing complex data with strong relationships by covering core concepts such as predicates, result sets, and system constraints. The content ranges from theoretical introductions to practical implementation steps, including schema creation, CRUD operations, and database lifecycle management. Targeted at developers using the Cangjie language, this resource ensures efficient local storage solutions, performance optimization, and robust data handling in application development. It serves as an essential reference for mastering the RdbStore component.

## Detailed Description

### 场景介绍_5more.md 场景介绍_5more.md
This technical guide introduces the relational database component based on SQLite, designed for persisting complex data with strong relationships in application development. It covers usage scenarios, basic concepts like predicates and result sets, operational mechanisms, system constraints, and core API interfaces. Key takeaways include performance recommendations such as limiting single queries to 5000 rows, supported data types including Int64 and String, and specific constraints like a 2MB data limit per entry and WAL logging mode. The document details essential functions for database management such as getRdbStore, insert, update, and query. Intended for developers using the Cangjie language or ArkData framework, this guide provides the necessary reference for implementing efficient persistent storage solutions.

### 开发步骤/
This directory provides a comprehensive tutorial series for implementing relational database (RdbStore) functionality using the Cangjie language within the HarmonyOS ArkData framework. It covers the complete data lifecycle, starting from initial database configuration, schema creation, and version management strategies. It then progresses to essential CRUD operations—insertion, querying, updating, and deleting data using predicates—and concludes with advanced management tasks such as result set processing, data backup, restoration, and database deletion. Key concepts include RdbPredicates, SQL execution, and file management. This guide is specifically designed for application developers who need to build robust local data storage solutions, handle schema evolution, and ensure data persistence in their Cangjie-based applications.
