This directory provides a comprehensive guide to parameterized testing in the Cangjie programming language. It covers essential techniques for automating test input generation, ranging from basic value-driven testing and type parameterization to advanced coverage-guided random testing and custom data strategies. Key topics include the `@Types` macro, `@Strategy` macro, Data DSL, and fuzzing-based coverage guidance. Designed for Cangjie developers, these resources help improve test coverage, reduce code duplication, and ensure robust validation of polymorphic and complex code structures.
