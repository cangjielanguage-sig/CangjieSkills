This directory provides comprehensive API reference documentation for implementing Flex layouts within the ArkUI framework using the Cangjie language. It covers essential properties and functions required for controlling component sizing, scaling behavior, and alignment within parent containers such as Flex, Column, Row, and GridRow. Key topics include `flexBasis`, `flexGrow`, `flexShrink`, and `alignSelf`. This documentation is specifically suitable for Cangjie developers and UI engineers aiming to build responsive, adaptive interfaces by managing space allocation and cross-axis alignment programmatically. It serves as a technical guide for understanding the constraints and default values associated with these layout properties.
