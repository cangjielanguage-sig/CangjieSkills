This directory contains technical documentation and code examples for implementing bi-directional communication between native Cangjie/ArkTS applications and HTML5 web pages using the `onMessageEventExt` function and WebMessagePort API. It covers API references, native-side implementation, and H5-side logic for handling various data types like strings, numbers, and arrays. Key topics include message port initialization, event registration, and data serialization. This resource is suitable for developers building hybrid applications on HarmonyOS who need robust web-to-native communication mechanisms.
