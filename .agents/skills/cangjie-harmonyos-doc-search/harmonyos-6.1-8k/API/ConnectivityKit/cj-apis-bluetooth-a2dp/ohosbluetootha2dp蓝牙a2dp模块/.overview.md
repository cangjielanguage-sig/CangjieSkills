## 详细描述

### class_CodecInfo_c6e2c713.md class_CodecInfo_c6e2c713.md

### enum_CodecBitsPerSample.md enum_CodecBitsPerSample.md
本文档定义了用于蓝牙编码器采样点位数的CodecBitsPerSample枚举。包含16位、24位、32位及未知类型，提供判等、判不等和字符串转换等成员函数。属于蓝牙核心系统能力，为开发者提供配置和比较音频采样精度的标准接口。

### enum_CodecChannelMode.md enum_CodecChannelMode.md
本文档定义了蓝牙编码器声道模式枚举，包含单声道、双声道及未知声道。支持相等性判断和字符串表示，属于系统蓝牙核心能力。面向蓝牙底层开发程序员，提供处理音频声道模式的标准接口和类型定义。

### enum_CodecSampleRate.md enum_CodecSampleRate.md
本文档定义了用于蓝牙编码器采样率的枚举类型，列出了从44.1k到192k等多种采样率。继承Equatable和ToString父类型，提供判等与toString方法。旨在为开发者提供音频采样率的标准化定义与操作接口。

### enum_CodecType.md enum_CodecType.md
本文档定义了蓝牙编码器类型枚举CodecType，包含CodecTypeInvalid、Sbc、Aac、L2hc等成员值。详细说明了比较运算符和toString()方法，继承自Equatable和ToString。面向需要处理蓝牙音频编码格式的开发人员，提供类型判断和字符串转换的接口规范。

### enum_PlayingState_b1ec72d5.md enum_PlayingState_b1ec72d5.md
本文档定义了蓝牙A2DP播放状态枚举PlayingState，包含StateNotPlaying和StatePlaying两个核心状态。支持重载的相等性判断运算符和toString方法，属于SystemCapability.Communication.Bluetooth.Core系统能力。用于标识和比较蓝牙音频的播放状态。

### ohosbluetootha2dp_5more_a26213c1.md ohosbluetootha2dp_5more_a26213c1.md
本文档是HarmonyOS蓝牙A2DP模块的API参考文档，介绍了模块导入方式、所需权限及核心函数createA2dpSrcProfile的用法。该函数用于创建A2DP Source实例以管理本端作为音频源的播放状态。适用于需要实现蓝牙音频流传输功能的场景。

### class_A2dpSourceProfile/
本目录包含蓝牙A2DP源配置文件的API参考文档。涵盖A2dpSourceProfile类的定义及核心方法，如获取连接设备列表、连接状态、播放状态等。说明了所需权限、返回值类型及BusinessException异常处理机制，并介绍了如何订阅和取消订阅蓝牙Profile的连接状态变化事件。
