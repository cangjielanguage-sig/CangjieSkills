# ohosmultimediacamera相机管理

This directory provides API reference documentation for the HarmonyOS multimedia camera management module in the Cangjie language. It covers the CameraKit framework, enabling developers to implement camera functionalities like preview, photography, video recording, and metadata handling. Key components include device management, session configuration, output controls, and enums for settings like flash, focus, and exposure. Intended for software developers building multimedia applications on HarmonyOS, this documentation requires knowledge of Cangjie syntax and system capabilities starting from version 19.
