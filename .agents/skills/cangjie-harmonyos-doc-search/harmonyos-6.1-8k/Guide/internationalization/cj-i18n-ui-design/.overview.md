# cj-i18n-ui-design

本目录收录了国际化（i18n）用户界面设计的核心规范，旨在确立全球化应用的设计规则与一致性标准。文档涵盖界面空间预留与灵活布局策略，以及针对从右到左（RTL）语言的界面镜像设计。内容包含基于英文字符长度的空间预留比率表，以及UI布局、图标方向、触控操作逻辑及混合文本的镜像适配要求。该指南面向UI/UX设计师及开发人员，致力于解决多语言环境下的界面适配问题，提升应用的全球化质量与用户体验。
