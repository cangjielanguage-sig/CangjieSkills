This directory contains API reference documentation for a Cangjie constructor designed to initialize highly configurable UI components, specifically Popups or Bubbles within the ArkUI framework. It covers comprehensive parameters for visual styling, positioning, event handling, and interaction behaviors. Key topics include arrow configuration, background masking, shadow effects, and transition animations. The documentation is intended for Cangjie developers and software engineers working with ArkUI (version 22+) who need to implement interactive overlays, tooltips, or popups with specific layout and customization requirements. The files detail the function signature, system capabilities, and specific rules for rendering based on bubble size and available space.
