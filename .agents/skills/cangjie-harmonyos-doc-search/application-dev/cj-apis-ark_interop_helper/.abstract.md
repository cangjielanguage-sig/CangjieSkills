This directory contains the essential API reference documentation for the `ohos.ark_interop_helper` module, a critical toolkit designed for Cangjie development within the HarmonyOS ecosystem. The primary focus of this module is to provide robust utility functions that facilitate seamless data type conversion and interoperability between ArkTS and native environments. By covering critical operations such as bidirectional transformations for HashMap and JSValue, application mode detection, and specific type conversion utilities, it enables developers to bridge different runtime contexts effectively. Currently marked as Beta, this module is indispensable for developers who need to manage complex data mappings between JavaScript and native layers. It is specifically tailored for HarmonyOS developers utilizing the Cangjie language who require efficient mechanisms to bridge system components. However, users should note that while the module offers powerful interoperability features, Kit-based imports are not yet supported in this version, requiring developers to adhere to the current import constraints. This documentation ensures that developers have the necessary guidance to implement these features effectively.
