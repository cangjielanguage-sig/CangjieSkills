This directory provides a comprehensive guide and code examples for implementing segmented encryption and decryption using AES symmetric keys in GCM mode. It covers essential cryptographic operations such as key generation, Cipher instance creation, GCM parameter specification, and chunked data processing using the CryptoArchitectureKit. Key topics include handling initialization vectors (IV), authentication tags (authTag), and multi-part updates. Designed for developers working with the Cangjie programming language, these resources address the need to securely process large data volumes while maintaining high security standards.
