# cj-apis-screen_lock_file_manager

This directory provides the API documentation for the `cj-apis-screen_lock_file_manager` module, a specialized toolkit designed for HarmonyOS developers focused on high-level data security. It offers detailed guidance on managing sensitive data access permissions, with a specific emphasis on the automated lifecycle of encryption keys. The module ensures that sensitive keys are destroyed immediately when the device screen is locked to prevent unauthorized data access and are securely restored when the screen is unlocked. The documentation covers the `ScreenLockFileManager` class, status enums for access requests, and module configuration requirements. It is an essential resource for developers using the Cangjie language who need to implement robust file access controls and manage permission states in locked-screen environments.

### ohosscreen_lock_file_manager锁屏敏感数据管理/
This directory provides the complete API documentation for the `ohos.screen_lock_file_manager` module, which is integral to managing sensitive data access permissions on HarmonyOS devices. The documentation focuses on the secure handling of encryption key lifecycles, detailing the mechanisms for destroying keys when the screen is locked to ensure data security and restoring them upon unlocking to resume access. It includes comprehensive descriptions of the core `ScreenLockFileManager` class, which developers will use to interact with these security features. Additionally, the directory documents the status enums used to handle various access request states and provides necessary information on module configuration. This documentation is specifically intended for HarmonyOS developers utilizing the Cangjie language who need to implement secure file access controls and manage permission states effectively in scenarios where the device screen is locked.
