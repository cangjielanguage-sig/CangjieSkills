# 使用HiTraceMeter跟踪性能仓颉

This directory provides comprehensive resources for utilizing HiTraceMeter to track performance and implement distributed tracing within Cangjie applications. It covers the theoretical underpinnings of the tool, including its interaction with kernel ftrace buffers, and offers practical guidance on coding and verification. Key topics include asynchronous time-slice tracking APIs, unique task ID management, and command-line log capturing. This content is specifically designed for Cangjie developers working in DevEco Studio who aim to analyze system performance, monitor process trajectories, and optimize business logic execution.

### 简介_4more.md 简介_4more.md
This document introduces HiTraceMeter, a system performance marking tool designed to help developers track process trajectories and analyze system performance. It covers basic concepts like HiTraceMeter Tags, implementation principles involving kernel ftrace buffers, and detailed API interface descriptions. Key information includes the asynchronous time-slice tracking APIs startTrace and finishTrace, which require a unique taskId for correlation, and the traceByValue interface for tracking changing integer variables. The text clarifies that these synchronous APIs are used within the same thread. This technical reference is intended for developers, specifically those using the Cangjie language, to implement performance analysis in their applications.
