This directory serves as a comprehensive technical resource hub for the HarmonyOS application packaging tool, specifically focusing on the `app_packing_tool.jar`. It provides essential documentation and command-line guides tailored for developers and build engineers who require manual packaging capabilities or need to handle complex build scenarios outside the standard DevEco Studio environment. The content covers a wide array of packaging scenarios, including standard HAP and HSP generation, FastApp mode for market distribution, multi-project merging, and version normalization. Key topics include detailed command syntax, parameter definitions, validation rules, and compression logic for both release and debug builds. This collection is ideal for users seeking to automate build processes, manage complex module integrations, or ensure strict version consistency in their deployment pipelines.
