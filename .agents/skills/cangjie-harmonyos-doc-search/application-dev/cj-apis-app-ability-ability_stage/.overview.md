# cj-apis-app-ability-ability_stage

This directory contains the API reference documentation for the `ohos.app.ability.ability_stage` module, specifically implemented for the Cangjie language. It is designed to assist HarmonyOS developers in understanding and utilizing the `AbilityStage` runtime class, which serves as the entry point for HAP (HarmonyOS Ability Package) initialization. The content covers essential technical aspects, including how to import the module, the permissions required for execution, and the standard usage patterns within Cangjie template projects. By detailing the `AbilityStage` class, its context properties, and lifecycle callbacks, this documentation enables developers to manage application-level logic effectively. It is particularly suitable for those looking to perform operations such as resource preloading or global state management before the first Ability instance is created, ensuring a smooth and optimized application startup experience. Keywords include AbilityStage, Cangjie, API, lifecycle, onCreate, AbilityStageContext, and HarmonyOS.

## Detailed Description

### cj-apis-app-ability-ability_stage.md

This document provides a comprehensive API reference for the `ohos.app.ability.ability_stage` module within the Cangjie language framework. It focuses on the `AbilityStage` runtime class, which is a fundamental component for developers building applications on the HarmonyOS platform. The text outlines the necessary steps for integrating this module, including specific module imports and the permissions that must be configured to ensure the application runs correctly within Cangjie template projects.

Key sections of the documentation provide a deep dive into the `AbilityStage` class structure. It explains the class's context property, which is essential for accessing the application environment via `AbilityStageContext`. This context allows the application to interact with system services and resources. Furthermore, the document details the `onCreate()` lifecycle callback, a critical method that is triggered when the AbilityStage is first created. This section guides developers on how to use this callback to perform module initialization tasks, such as preloading resources or initializing global variables, ensuring these operations are completed before the first Ability instance is loaded. This guide is intended for developers with a solid grasp of application contexts and lifecycle management.
