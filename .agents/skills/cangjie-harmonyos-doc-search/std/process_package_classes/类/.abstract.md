This directory serves as a comprehensive resource for Cangjie programming language developers focusing on process management classes. It encompasses the `Process` class for system interaction, the `SubProcess` class for child process control, and the deprecated `CurrentProcess` class. Key topics include process lifecycle management, standard I/O stream handling, environment variable manipulation, and subprocess execution. This documentation is ideal for developers working on system-level programming, application integration, or maintaining legacy code that requires robust process control and inter-process communication capabilities.
