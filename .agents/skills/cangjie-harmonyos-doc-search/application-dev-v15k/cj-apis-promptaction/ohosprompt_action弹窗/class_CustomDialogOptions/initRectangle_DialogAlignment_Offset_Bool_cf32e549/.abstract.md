This directory contains technical documentation for the ArkUI framework, specifically focusing on the initialization and configuration of custom dialog components. It covers the `CustomDialogOptions` constructor, detailing parameters for layout positioning, visual styling, modal behavior, and lifecycle management. Key topics include border customization, mask transparency, transition animations, and keyboard avoidance features. The content is designed for UI developers and engineers working within the ArkUI ecosystem who need to implement sophisticated, customizable dialog windows with specific visual and behavioral characteristics.
