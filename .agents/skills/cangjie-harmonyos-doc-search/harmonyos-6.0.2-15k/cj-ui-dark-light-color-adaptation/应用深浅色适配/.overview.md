# 应用深浅色适配

This directory focuses on adapting applications to system dark and light display modes using the Cangjie framework. It covers strategies for synchronizing with system settings, programmatically overriding themes, and managing resources like colors and images. Key topics include the `setColorMode` API, resource qualifiers, and event listening for configuration changes. This documentation is suitable for developers and UI engineers aiming to optimize user experience through responsive theming and visual consistency across different system environments.

## Detailed Description

### 应用主动设置深浅色模式_2more.md
This guide explains how to programmatically control an application's color mode to override system defaults using the Cangjie language. It covers the setColorMode API, system default judgment rules based on resource directories, and how to ensure the app follows system settings. Key takeaways include that setColorMode takes priority over system settings, and if not set, the system checks for a dark resource directory to determine if components switch themes. Developers can use COLOR_MODE_NOT_SET to restore system-following behavior. This technical guide targets application developers using the Cangjie framework who need to manage UI theming and resource handling.

### 概述.md
This document serves as a technical overview for adapting applications to system dark and light display modes to optimize user experience. It categorizes adaptation strategies based on the relationship between application and system configurations. Key sections include Application Dark/Light Adaptation, detailing how to follow system settings, actively set modes, and apply system default judgment rules. The content explains the distinction between passive synchronization and active theme control. Intended for developers and UI engineers, this guide provides the foundational logic for implementing responsive theming. Keywords: dark mode, light mode, system adaptation, theme configuration, user experience.

### 应用跟随系统的深浅色模式/
This directory provides a specialized technical guide focused on the implementation of system-wide dark and light mode adaptation for applications developed using the Cangjie framework. It addresses the growing need for applications to dynamically adjust their visual appearance based on user system settings, thereby enhancing user comfort and experience. The documentation covers a wide array of implementation strategies, ranging from basic color adaptation using custom resource directories or system resource IDs to more complex image adaptation via resource qualifiers or SVG fill properties. Additionally, it includes specific instructions for configuring Web components to ensure they respect the current theme. The guide also delves into the programmatic aspects of theming, such as listening for mode switch events and handling configuration updates. Key technical concepts discussed include the `dark` resource qualifier, `AbilityStage` lifecycle methods, `AppStorage`, and `@Watch` decorators. This resource is primarily suitable for developers and UI engineers who are looking to build robust, responsive applications that offer a seamless visual experience across both light and dark system environments.
