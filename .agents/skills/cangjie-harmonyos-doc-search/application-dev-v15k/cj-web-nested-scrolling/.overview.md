# cj-web-nested-scrolling

This directory serves as a comprehensive technical guide for developers working within the ArkUI framework using the Cangjie programming language. It specifically addresses the complexities associated with implementing nested scrolling behaviors for Web components in HarmonyOS applications. The content provides in-depth explanations of how to coordinate scroll events between child Web views and parent scrollable containers, such as Lists, Grids, and Scroll components. By covering essential interfaces like the `nestedScroll` property and the `NestedScrollMode` enumeration—including modes like SELF_ONLY, SELF_FIRST, PARENT_FIRST, and PARALLEL—it equips developers with the tools needed to resolve scroll conflicts effectively. This resource is ideal for software engineers and UI/UX developers aiming to create sophisticated, multi-layered interfaces that integrate web content seamlessly into native layouts. By mastering these techniques, developers can ensure a fluid and responsive user experience, preventing common interaction issues in hybrid applications.

## Detailed Description

### Web组件嵌套滚动/
This directory focuses on the technical implementation of nested scrolling for Web components within the ArkUI framework. It provides comprehensive guidance on enabling coordinated scrolling behaviors between child Web components and parent scrollable containers. The documentation covers essential interfaces such as the `nestedScroll` property and the `NestedScrollMode` enumeration, detailing modes like SELF_ONLY, SELF_FIRST, PARENT_FIRST, and PARALLEL. It also explains scroll event propagation logic and lists supported containers like Grid, List, and Scroll. This resource is specifically designed for ArkUI and HarmonyOS developers using the Cangjie language who need to resolve scroll conflicts and manage complex interactions in applications featuring multiple scrollable areas and web content. By mastering these techniques, developers can ensure a smooth user experience when integrating web views into native scrollable layouts.
