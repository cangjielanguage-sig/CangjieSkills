# 加载本地页面

This directory serves as a technical guide for HarmonyOS developers aiming to load and display local HTML pages within their applications. It covers a range of implementation methods, focusing on the use of Web components in both Cangjie and ArkTS environments. Key topics include accessing resources from the `resources/rawfile` directory using `@rawfile` and `loadUrl`, as well as navigating application sandbox paths like `filesDir` via singleton contexts. The documentation also addresses essential configuration steps such as enabling `fileAccess` permissions, referencing local CSS stylesheets, and utilizing `WebviewController` for dynamic page manipulation. Furthermore, it provides insights into application lifecycle management, specifically the `onCreate` and `onWindowStageCreate` methods, and demonstrates how to use `GlobalContext` to bind paths for data synchronization between the Ability and UI layers. This resource is best suited for developers with a solid understanding of HarmonyOS architecture who need to implement robust local web content rendering.

## Detailed Description

### 加载本地页面_1.md
This technical guide demonstrates methods for loading local HTML pages within a Web component using the Cangjie language in HarmonyOS development. It covers two primary approaches: loading files from the resources/rawfile directory using @rawfile and loadUrl, and loading from application sandbox paths like filesDir via a singleton context. Key information includes referencing local CSS stylesheets, enabling fileAccess permissions for sandbox file access, and utilizing WebviewController for dynamic page changes. The document is intended for HarmonyOS developers seeking to implement local web content rendering, requiring knowledge of Cangjie syntax and application file path management.

### 加载本地页面_2.md
This document provides a code example demonstrating the lifecycle implementation for loading a local page in a HarmonyOS application. It focuses on the onCreate and onWindowStageCreate methods within an Ability component. Key information includes the use of GlobalContext to bind filesDir, facilitating data synchronization between the Ability and UI, and the loadContent call to render the EntryView. This technical reference is designed for developers using ArkTS who need to understand application initialization and page loading mechanisms. Keywords: ArkTS, HarmonyOS, Ability lifecycle, GlobalContext, WindowStage.
