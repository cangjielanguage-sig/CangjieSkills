### 添加文本内容_2more.md 添加文本内容_2more.md
This tutorial guide explains how to programmatically add text and image content to a RichEditor component using the Cangjie language. It covers two main sections: adding text via the addTextSpan interface to achieve mixed styles, and adding images via addImageSpan for visual enhancement. Key information includes that both methods update the cursor position to the right of the new content when the component is focused. The document provides practical Cangjie code examples demonstrating implementation with RichEditorController.

### 设置属性.md 设置属性.md
This document serves as a technical guide for implementing custom selection menus in text components using the ArkUI framework and Cangjie language. The primary topic is the bindSelectionMenu API, which allows developers to replace default text actions like copy and cut with custom functionalities such as translation or font styling. Key information includes a practical code example demonstrating the creation of a custom menu builder, binding it to a text span, and handling response types like long presses. The guide also advises using a Scroll component for lengthy menus to prevent keyboard obstruction.
