This directory contains API reference documentation for the `Router` class in the Cangjie language, specifically designed for managing page navigation within the ArkUI framework. It covers essential functionalities such as navigating between pages, managing the page stack, and retrieving page states or parameters. Key topics include static methods for pushing and replacing URLs, back navigation control, and stack inspection. This documentation is suitable for application developers building HarmonyOS applications who need to implement robust navigation logic, handle parameter passing via JSON strings, and manage page lifecycles effectively.
