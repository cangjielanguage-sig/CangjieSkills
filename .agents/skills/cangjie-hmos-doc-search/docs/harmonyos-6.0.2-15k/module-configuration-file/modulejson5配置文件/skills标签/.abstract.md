This directory provides comprehensive technical documentation for the `skills` tag used in HarmonyOS and OpenHarmony application development. It focuses on the configuration necessary to define the Want characteristics that UIAbility or ExtensionAbility components are capable of receiving. The content covers essential concepts such as implicit Want matching, inter-application jumps, data sharing, and deep linking. It details specific attributes including actions, entities, URIs, permissions, and domain verification settings. This resource is specifically designed for mobile application developers and system integrators who need to configure application manifests to enable robust system interactions and intent handling.
