This directory provides comprehensive API reference documentation for the HarmonyOS ContactsKit module using the Cangjie programming language. It covers the full lifecycle of contact management, including adding, deleting, querying, and updating contacts, as well as accessing specific data attributes like emails, phone numbers, and addresses. The documentation details necessary permissions, system capabilities, and error handling. It is designed for developers building contact-centric applications on HarmonyOS who need to implement robust data manipulation and retrieval features.
