This directory provides comprehensive API reference documentation for the Stack container component within the Cangjie ArkUI framework. It is centered around the creation and management of stacking containers, a crucial UI pattern where child components overlap sequentially to create depth or complex layouts. The documentation covers essential technical aspects, including the `init` and `Stack` constructors, which offer optional alignment parameters to customize the stacking behavior. Key sections explore component attributes, with a particular emphasis on `alignContent` for positioning children, and provide illustrative code examples to demonstrate layout behavior. Furthermore, the document highlights important API changes, specifically the deprecation of the `alignment` method in favor of `alignContent`. This guide is an indispensable resource for Cangjie developers looking to master the syntax and parameters required to implement effective, layered UI designs in their applications.
