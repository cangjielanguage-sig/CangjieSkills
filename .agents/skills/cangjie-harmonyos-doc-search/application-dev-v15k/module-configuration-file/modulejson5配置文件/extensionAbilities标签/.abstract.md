This directory contains comprehensive documentation for configuring the `extensionAbilities` tag in HarmonyOS and OpenHarmony application development. It covers the tag's structure, data types, mandatory attributes, and specific configuration rules for various extension types like forms, data sharing, and input methods. The guides detail process isolation, permissions, and security constraints, providing both theoretical definitions and practical JSON examples. This resource is suitable for software engineers, system architects, and application developers looking to precisely control extension capabilities, manage component interactions, and configure manifest files for specific device types and API versions.
