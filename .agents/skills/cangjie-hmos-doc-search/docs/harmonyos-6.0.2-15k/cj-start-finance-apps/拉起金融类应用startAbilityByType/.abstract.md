This directory provides comprehensive technical guidance for developers working within the HarmonyOS Cangjie environment to implement financial application interactions. It focuses on the `startAbilityByType` interface, enabling the launch of specific financial features such as transfers or credit card repayments. The documentation covers the complete workflow, from the client-side invocation using JSON payloads to the server-side configuration for handling external requests. Key topics include parameter specifications like `sceneType` and `bankCardNo`, URI handling, and `module.json5` configuration. This resource is essential for HarmonyOS developers aiming to integrate cross-application financial capabilities or implement deep-linking features.
