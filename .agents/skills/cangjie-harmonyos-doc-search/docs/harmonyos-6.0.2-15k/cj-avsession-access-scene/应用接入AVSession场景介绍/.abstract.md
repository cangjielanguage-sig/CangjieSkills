This directory provides a comprehensive technical guide for developers integrating the AVSession Kit into HarmonyOS applications. It covers essential scenarios for audio and video playback, including background task management, metadata configuration, playback state synchronization, and media control handling. The documentation details how to use the BackgroundTasks Kit for continuous playback, register system commands, and adapt to hardware key events. Designed for application developers using the Cangjie language, these resources ensure seamless interaction with the system's media playback center, notification center, and external devices like Bluetooth headsets.
