This directory provides comprehensive technical documentation on the "specified" startup mode for UIAbility components within the HarmonyOS ecosystem. It focuses on advanced instance management strategies where system behavior is dictated by unique keys passed via Want parameters. The documentation covers essential topics such as the operational principles of instance matching, lifecycle callbacks (onNewWant vs. onCreate), and configuration in module.json5. Additionally, it offers practical implementation examples using the Cangjie language, specifically targeting scenarios like document applications that require precise control over multi-instance logic. This resource is ideal for HarmonyOS developers seeking to optimize resource management and user experience in complex applications.
