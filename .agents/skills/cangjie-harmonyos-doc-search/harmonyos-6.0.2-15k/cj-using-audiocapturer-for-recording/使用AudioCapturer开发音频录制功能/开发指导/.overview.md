# 开发指导

This directory serves as a comprehensive resource for developers implementing audio recording functionality using the AudioCapturer class. It covers the complete development lifecycle, including parameter configuration, state management, event listening, and resource release. The content includes theoretical guides, step-by-step implementation instructions in the Cangjie language, and full code examples in both Cangjie and ArkTS. Key topics include AudioCapturer usage, PCM data handling, and microphone permissions. This guide is suitable for application developers and HarmonyOS engineers looking to integrate robust audio capture features into their applications.

## Detailed Description

### 开发指导.md
This development guide provides instructions for developers on how to use the AudioCapturer class to record audio data. It covers the complete recording workflow including instance creation, parameter configuration, start and stop operations, and resource release. Key sections explain the AudioCapturer state changes and event listening mechanisms. The document emphasizes the importance of state management, warning that calling methods in inappropriate states causes errors. It references a state change diagram and specific API callbacks like on(AudioCapturerCallbackType.STATE_CHANGE). Intended for developers implementing audio recording features, this tutorial serves as a practical guide best used alongside the API reference documentation. Keywords: AudioCapturer, audio recording, state management, development guide, API callback.

### 开发步骤及注意事项.md
This technical guide outlines the step-by-step process for implementing audio recording functionality using the AudioCapturer class in the Cangjie programming language. The document covers five main stages: configuring audio parameters and creating the instance, subscribing to data read callbacks, starting and stopping the recording, and releasing resources. Key information includes the mandatory requirement for microphone permission (ohos.permission.MICROPHONE) when using specific audio sources like the microphone. The guide provides practical Cangjie code examples for setting up stream info, handling callbacks to write PCM data to a file, and managing the capturer state. This tutorial is intended for application developers using the AudioKit framework to integrate audio capture features.

### 完整示例/
This directory provides a comprehensive collection of complete code examples designed to help developers implement audio recording functionality within HarmonyOS applications.
