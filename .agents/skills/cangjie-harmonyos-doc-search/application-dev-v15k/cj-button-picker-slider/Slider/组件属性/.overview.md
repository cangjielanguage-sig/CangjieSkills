# 组件属性

This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on the Slider component. It covers a wide range of customization options including block styling (borders, colors, shapes), track appearance, interaction modes, and responsive distances. Developers will find detailed parameters, default values, and version requirements for functions like `blockStyle`, `trackColor`, and `sliderInteractionMode`. This documentation is suitable for software developers and UI designers using the Cangjie language to build interactive and visually refined user interfaces.

## Detailed Description

### func_blockBorderColorResou_4more.md
This document provides API reference details for styling the block (thumb) of a Slider component in the Cangjie ArkUI framework. It covers four specific functions: blockBorderColor, blockBorderWidth, blockColor, and blockSize. Key information includes how these functions behave differently based on the SliderBlockType (DEFAULT, IMAGE, SHAPE) and SliderStyle. For example, image blocks ignore border settings, while shape blocks use borders for center lines. The documentation specifies parameters, default values, and version requirements. This reference is intended for developers using the Cangjie language to customize the visual appearance of slider components in their applications.

### func_blockStyleSliderBlock_5more.md
This document serves as API reference documentation for configuring slider block styles and behaviors in the ArkUI framework using the Cangjie language. It primarily details overloaded `blockStyle` functions that allow developers to customize slider appearance using images or custom shapes like Circle, Rect, and Path. Additionally, it covers the `minResponsiveDistance` function for defining interaction thresholds and lists deprecated functions for setting min and max labels. Key parameters include `SliderBlockType`, `AppResource`, and `ShapeAbstract`. This technical guide is intended for software developers seeking to implement and fine-tune slider components within their applications.

### func_minResponsiveDistance_7more.md
This document serves as API reference documentation for configuring the Slider component within the Cangjie ArkUI framework.
