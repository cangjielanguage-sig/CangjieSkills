# 布局子元素在主轴上的排列方式

This directory provides a comprehensive guide on controlling the alignment of child elements along the main axis within layout containers. It is suitable for UI developers and designers working with layout systems, specifically those using the Cangjie UI framework or HarmonyOS ArkUI, who need to master axis-based alignment to build structured and responsive user interfaces.
