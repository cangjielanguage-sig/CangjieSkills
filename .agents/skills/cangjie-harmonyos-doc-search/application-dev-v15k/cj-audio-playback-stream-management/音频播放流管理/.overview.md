# 音频播放流管理

This directory serves as a comprehensive technical resource for managing audio playback streams within Cangjie applications. It provides in-depth guidance on monitoring and controlling audio states, covering both application-specific stream management using AudioRenderer and system-wide oversight via AudioStreamManager. The content explores essential techniques such as registering state change callbacks, querying stream properties like UID and state, and handling device updates to ensure responsive UI behavior. This documentation is specifically designed for application developers utilizing the AudioKit framework who need to implement dynamic audio features, monitor audio output effectively, or debug complex audio device connections.

The following sections provide specific documentation and guides related to audio stream management:

### 音频播放流管理_3more.md 音频播放流管理_3more.md
This technical guide explains how to monitor and manage audio playback stream states in Cangjie applications to enable responsive UI updates. It covers two primary approaches: monitoring application-specific audio streams using AudioRenderer and managing system-wide audio streams using AudioStreamManager. Key information includes methods to directly check the state property or register stateChange callbacks for specific streams. For global monitoring, the guide details using on to listen for changes, off to stop listening, and getCurrentAudioRendererInfoArray to query stream details like UID and state. This document targets application developers using the AudioKit who need to handle audio state changes and device updates.
