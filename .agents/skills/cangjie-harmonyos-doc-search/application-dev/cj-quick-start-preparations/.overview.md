# cj-quick-start-preparations

This directory serves as an essential starting point and comprehensive guide for developers interested in OpenHarmony application development using the Cangjie language. It provides a foundational tutorial that bridges the gap for beginners by introducing the ArkUI framework, with a specific focus on the Cangjie declarative paradigm. The content highlights the critical transition to the Stage application model, the current standard for Cangjie APIs, while providing a clear contrast with legacy FA models and the ArkTS language. Key learning areas include the necessary environment setup using DevEco Studio and the Cangjie SDK, as well as practical, step-by-step guidance on building a simple application featuring page navigation. Additionally, it touches upon the complexities of mixed development scenarios involving ArkTS. This guide is specifically tailored for mobile system developers and individuals new to the OpenHarmony ecosystem who wish to master the basics of Cangjie programming and understand the architectural shifts in the platform.
