# 开发步骤及注意事项

This directory provides comprehensive technical guides and practical code examples for managing and monitoring audio streams using the AudioStreamManager API in the Cangjie language. It thoroughly covers essential development steps such as creating manager instances, subscribing to audio renderer change events via callbacks, and retrieving current audio renderer information. Key topics include handling stream state changes, monitoring device connections, and accessing specific device descriptors like sample rates and roles. Additionally, it highlights critical permissions, specifically `ohos.permission.USE_BLUETOOTH`, required for accessing actual Bluetooth device names and addresses. This documentation is primarily suitable for application developers working on multimedia features who need to implement robust audio monitoring, debug complex stream issues, or manage audio playback status and device connections effectively.

## Detailed Description

Below are the detailed contents of the files included in this directory:

### 开发步骤及注意事项_1.md
This technical guide outlines the development steps for managing and monitoring audio streams using the AudioStreamManager API in the Cangjie language. The document covers creating an instance, subscribing to audio renderer change events via callbacks, unsubscribing, and retrieving current audio renderer information. Key takeaways include code examples for handling stream state and device changes, along with a critical note that the ohos.permission.USE_BLUETOOTH permission is required to access actual Bluetooth device names and addresses. This tutorial targets application developers working on multimedia features who need to monitor audio playback status and device connections.

### 开发步骤及注意事项_2.md
This document provides a code example demonstrating how to retrieve and log detailed information about current audio renderers within a development workflow. The primary focus is on the implementation of the `getCurrentAudioRendererInfoArray` function, which interacts with an audio stream manager to fetch data. Key topics covered include iterating through renderer arrays, extracting stream properties such as ID and usage, and accessing device descriptors like type, role, and sample rates. The code also illustrates error handling for business exceptions. This technical guide is intended for developers debugging audio streams or implementing audio monitoring features, requiring knowledge of the specific audio management API and logging utilities. Keywords: audio renderer, stream management, device descriptors, logging, API implementation.
