# cjtrace_recover_manual

本目录包含仓颉语言异常堆栈信息还原工具 `cjtrace-recover` 的官方使用手册。该文档详细阐述了如何针对开启了外形混淆的仓颉应用，在运行时发生异常时将混淆后的堆栈信息还原为可读的原始代码信息。内容涵盖了工具的核心功能、详细的命令行参数说明（如 `-f` 指定堆栈文件和 `-m` 指定映射文件的使用）以及实际操作样例。通过利用符号映射文件，开发者可以轻松将混淆后的函数名和路径名还原为原始信息并输出。这份手册是仓颉开发者在生产环境调试和故障排查时的必备参考资料，能够显著提升问题定位效率，解决混淆代码难以调试的痛点。

## 详细描述

### cjtrace_recover_manual.md
本文件是目录下的核心文档，即仓颉语言异常堆栈信息还原工具 cjtrace-recover 的使用手册。文档旨在指导开发者还原经过外形混淆的运行时堆栈信息，主要包含功能简介、使用说明及使用样例三个部分。其中关键信息介绍了如何利用符号映射文件，通过命令行参数 -f 指定堆栈文件和 -m 指定映射文件，将被混淆的函数名和路径名还原为原始信息并输出至标准输出。该文档主要面向开启了外形混淆的仓颉应用开发者，用于在调试时定位和排查运行时问题。
