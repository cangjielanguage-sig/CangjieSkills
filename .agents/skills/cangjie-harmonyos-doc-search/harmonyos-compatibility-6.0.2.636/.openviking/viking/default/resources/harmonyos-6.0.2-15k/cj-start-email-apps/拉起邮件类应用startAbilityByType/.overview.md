# 拉起邮件类应用startAbilityByType

This directory provides comprehensive technical documentation for launching mail applications using the `startAbilityByType` interface within the Cangjie development environment. It covers the complete workflow from the initiating application to the target application. Key topics include constructing parameters for recipients, subjects, and attachments, handling URL encoding, setting URI permissions, and configuring `module.json5` for feature linking. Additionally, it details how to parse incoming parameters in `UIAbility` lifecycle methods. This resource is essential for HarmonyOS developers aiming to implement cross-application email capabilities or configure their apps to respond to external email requests.

## Detailed Description

### 拉起邮件类应用startAbilityByType_3more.md
This technical guide explains how to launch a mail application extension panel using the startAbilityByType interface in Cangjie. It details the parameter specifications for the "mail" type, including recipients, subject, body, and attachments, followed by a step-by-step development tutorial. Key takeaways include the mandatory URL encoding for string parameters and the requirement to set read permissions for attachments via uriPermissionFlag. The document provides a complete code example demonstrating parameter construction and context usage. Targeted at developers familiar with the AbilityKit and UIAbility context, this guide facilitates integrating email functionality into applications.

### 目标方开发步骤.md
This technical guide outlines the development steps for configuring an application as a target for specific system features, such as email composition. It covers two primary sections: declaring supported capabilities in the module.json5 file using the linkFeature attribute and parsing incoming parameters within the UIAbility lifecycle methods. Key information includes the specific parameter definitions (email, subject, body, etc.) passed via want.parameters and the requirement for URL decoding. The document provides a complete Cangjie code example demonstrating how to handle these parameters in onCreate and onNewWant. Intended for HarmonyOS developers, this guide ensures applications can correctly receive and process external invocation requests.
