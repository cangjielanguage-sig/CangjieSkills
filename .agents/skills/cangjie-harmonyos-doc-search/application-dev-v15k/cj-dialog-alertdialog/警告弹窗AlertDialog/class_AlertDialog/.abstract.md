This directory contains API reference documentation for the `AlertDialog` class within the Cangjie programming language and the ArkUI framework. It comprehensively covers the construction and display of modal alert pop-ups, focusing on class definitions and overloaded static `show` methods. Key topics include configuring dialogs using parameters like `AlertDialogParamWithConfirm` and `AlertDialogParamWithButtons`, as well as advanced shadow customization options introduced in API version 19. The documentation details the necessary system capabilities, specifically SystemCapability.ArkUI.ArkUI.Full. This technical resource is intended for software developers and application engineers looking to implement user notifications and modal alerts with specific styling in their Cangjie-based applications.
