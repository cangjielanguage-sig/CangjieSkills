This directory contains technical documentation and code examples for importing plaintext keys using the Cangjie programming language within the HarmonyOS Universal Keystore Service (HUKS) ecosystem. It covers the implementation of key import operations for algorithms like AES256, RSA2048, and X25519, utilizing the UniversalKeystoreKit. The content includes practical guides for defining key materials, configuring attributes, and verifying key existence. It is suitable for software developers and security engineers working on HarmonyOS applications who need to integrate secure cryptographic key management and storage functionalities.
