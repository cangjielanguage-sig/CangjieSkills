# concurrency

This directory contains comprehensive documentation for concurrency and multi-threading in the Cangjie programming language. It covers the core M:N thread model, thread creation, lifecycle management, synchronization, and termination. Key topics include the `spawn` keyword, `sleep` functions, and cooperative cancellation mechanisms. This resource is suitable for Cangjie developers ranging from beginners learning the basics of parallel execution to advanced engineers building high-concurrency applications or interacting with Foreign Function Interfaces (FFI).

## Detailed Description

### [1] concurrency_overview
This directory provides a comprehensive overview of the Cangjie programming language's concurrency mechanisms, focusing on the design philosophy and implementation details of its core thread model. The documentation delves into the essential differences between language threads and native threads, analyzing the M:N thread model's working principles—specifically how lightweight language threads are efficiently mapped to native threads for execution. Additionally, it covers preemptive scheduling strategies and blocking mechanism handling. This document is particularly suitable for Cangjie developers, especially those dedicated to developing high-concurrency applications or involving cross-language interactions (such as calling Foreign Function Interfaces), aiming to help them understand the concurrency model and avoid system throughput degradation caused by improper operations.

### [2] create_thread
This directory details the basics of multi-threaded programming in the Cangjie programming language, focusing on how to create and manage threads to achieve efficient concurrent execution. The documentation explains in depth the specific syntax and usage of using the `spawn` keyword combined with parameterless `lambda` expressions to start new threads, demonstrating through actual code how the main thread and child threads work in parallel. Furthermore, the content covers thread lifecycle characteristics (such as terminating with the main thread) and the application of the thread control function `sleep()`. Core keywords include: thread creation, concurrent programming, spawn, lambda expressions, Cangjie language. This material is very suitable for beginners of the Cangjie language, developers hoping to understand concurrency mechanisms, and those building multi-threaded applications.

### [3] sleep
This directory provides detailed API reference documentation for the `sleep` function in the Cangjie language standard library, focusing on time management mechanisms in thread concurrency control. The documentation deeply analyzes how to block the current thread via the `sleep` function, covering the function prototype, usage specifications for the `Duration` type parameter, and special behaviors when handling zero or negative duration inputs (i.e., yielding CPU resources without sleeping). Additionally, the document includes practical code examples demonstrating how to implement a one-second thread pause. This resource is primarily aimed at Cangjie language developers who need thread synchronization, execution rhythm control, or concurrent task processing, helping them accurately master programming techniques for thread sleeping and resource scheduling.
