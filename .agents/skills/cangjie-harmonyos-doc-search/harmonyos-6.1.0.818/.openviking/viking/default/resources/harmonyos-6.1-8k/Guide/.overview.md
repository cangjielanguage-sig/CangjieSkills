# Guide

This directory acts as a comprehensive navigation index for the platform's Beta features, specifically tailored for the OpenHarmony and HarmonyOS ecosystems. It serves as a centralized resource hub for application developers, providing systematic documentation entry points and resource integration. The content spans a wide range of technical areas, including the Cangjie programming language, ArkUI framework, system services, multimedia, graphics, and security. It is designed to assist developers in navigating specific technical documentation, finding API references, and understanding core development capabilities across various functional modules.

## Detailed Description

### README_zh
This directory is the core development guide navigation index for the platform's Beta features, aiming to provide systematic documentation entry points and resource integration for application developers. The content covers a wide range, from basic application development guides and introductory tutorials to advanced core development areas. Specific technology stacks include application frameworks (ArkUI, ArkData, Cangjie language), underlying system services (security, network, hardware interaction), multimedia processing, graphics rendering, and various application services. It also provides direct links to API references. All content is organized hierarchically by functional modules, clearly marking the Beta status of components.

### application-models
This directory contains comprehensive documentation for HarmonyOS application development, specifically focusing on the Stage model and the Cangjie programming language. It covers core concepts such as the Ability Kit framework, UIAbility components, lifecycle management, and application context, providing essential guidance for structuring applications effectively.

### application-test
This directory serves as a comprehensive repository for application testing resources, specifically designed for the Cangjie programming language and the OpenHarmony ecosystem. It provides essential documentation for the Test Kit service, covering testing frameworks, unit testing, and instrumentation to ensure application quality and stability.

### arkui-cj
This directory serves as a comprehensive resource hub for the ArkUI framework, specifically tailored for developers using the Cangjie (CJ) programming language within the HarmonyOS ecosystem. It covers a wide array of topics including declarative UI development, state management, and component composition, enabling the creation of responsive and cross-platform user interfaces.

### basic-services
This directory serves as a comprehensive documentation hub for the Basic Services Kit, focusing on essential system capabilities for HarmonyOS/OpenHarmony application development. It covers core functionalities such as inter-process communication (IPC), background task management, and data synchronization, forming the foundation for robust application behavior.
