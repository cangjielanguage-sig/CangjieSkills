### class_SystemDateTime.md class_SystemDateTime.md
This document serves as API reference documentation for the SystemDateTime class in the Cangjie programming language, detailing system time and timezone functionalities. It covers three primary static methods: getTime for retrieving Unix epoch time, getTimezone for obtaining the current system timezone, and getUptime for calculating time elapsed since system boot. Key information includes parameter definitions for time units, allowing selection between milliseconds and nanoseconds, and specific TimeType enums for uptime calculations. Targeted at Cangjie developers using the BasicServicesKit, this reference provides code examples and requires knowledge of exception handling to implement time-related features effectively.

### enum_TimeType.md enum_TimeType.md
This document serves as API reference documentation for the Cangjie TimeType enum, which defines types for retrieving system time. It covers the enum definition and details two specific variants: Active and Startup. Both variants measure time elapsed since system boot but differ in how they handle deep sleep periods. The Active type excludes deep sleep time, while the Startup type includes it. Both return values in milliseconds and require the SystemCapability.MiscServices.Time system capability, available starting from version 22. This reference is intended for Cangjie developers working with system time tracking who need to distinguish between active uptime and total elapsed time. Keywords: Cangjie, TimeType, enum, system time, API reference, deep sleep, uptime.
