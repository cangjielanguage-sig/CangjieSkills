# 支持适老化

This directory provides comprehensive technical resources for implementing "Age-Friendly Adaptation" (适老化) in HarmonyOS applications. It focuses on ensuring applications are accessible to elderly users by supporting system font scaling, maintaining layout stability, and utilizing specific system components for magnification. The content covers adaptation rules for scaling levels up to 3.2x, configuration methods in `app.json5`, and strategies to prevent UI overlap. Designed for developers using the Cangjie language and ArkUI framework, this collection includes detailed guides, component behavior specifications, and practical code examples to create responsive and accessible user interfaces.

## Detailed Description

### 支持适老化_3more.md
This technical guide instructs developers on adapting applications for elderly users by supporting system font scaling and ensuring layout stability. It covers adaptation rules, specific font scaling levels ranging from 1x to 3.2x, and configuration methods. Key information includes requirements to prevent layout overlap at 1.75x scaling, strategies like converting horizontal layouts to vertical ones, and the use of system components. The document details how to enable font following via app.json5 and configuration.json, set maximum scaling limits, and retrieve font parameters through lifecycle callbacks. This guide targets application developers using the Cangjie language and ArkUI framework to implement accessibility features.

### 适配适老化的系统组件及触发方式.md
This document outlines the implementation and behavior of age adaptation features for system components, enabling magnification for better accessibility. It covers adaptation rules, enabling methods via system settings, operational triggers like long-press, and integration with other gestures. Key information includes the requirement for specific configuration tags to enable scaling when system fonts exceed 1x, the distinction between long-press triggered popups and automatic scaling for components like PickerDialog, and a 2x magnification limit for popup content. The document serves as a technical guide for developers designing accessible applications for elderly users, listing specific components such as SideBarContainer and Navigation that support these features.

### 示例代码/
This directory contains practical code examples demonstrating age-friendly accessibility features within HarmonyOS applications developed using the Cangjie language. It specifically covers the implementation and configuration of `SideBarContainer` and `DatePickerDialog` components, highlighting how system font size changes trigger adaptive UI behaviors. Key topics include component styling, state management, event callbacks, and responsive design logic for accessibility. These examples are primarily suitable for HarmonyOS developers who possess prior knowledge of Cangjie syntax and the ArkUI framework structure and are looking to implement accessible, responsive user interfaces.
