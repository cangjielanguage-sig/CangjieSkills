# 使用合适的音频流类型

This directory provides comprehensive technical guidance for application developers on selecting and configuring audio stream types to ensure optimal audio behavior and user experience. It covers the definitions of playback (StreamUsage) and recording (SourceType) stream types, their significant impact on system behavior such as volume control and audio focus, and specific implementation methods using multimedia APIs like AudioRenderer and AVRecorder. Key topics include audio business logic mapping, device selection strategies, and enabling audio optimizations like noise cancellation. This resource is essential for developers aiming to correctly map business scenarios like VoIP or media playback to the correct technical parameters.

### 流类型对音频业务的影响.md 流类型对音频业务的影响.md
This technical guide explains how audio stream types impact system behavior and user experience. It details three main areas: volume control, audio focus adjustments, and input/output device selection. Key takeaways include the mapping of stream usage to independent volume types, how different streams interact (e.g., navigation ducking music or video stopping it), and default hardware routing for specific scenarios like VOIP or alarms. The document emphasizes that selecting the correct recording stream type is vital for enabling audio optimizations like noise cancellation. Intended for developers, this guide aids in configuring audio streams correctly for various business scenarios.

### 设置音频流类型.md 设置音频流类型.md
This technical guide outlines methods for configuring audio stream types during playback and recording in application development. Main sections cover playback implementations using AudioRenderer, AVPlayer, and SoundPool, followed by recording implementations using AudioCapturer and AVRecorder. Key information includes specifying StreamUsage via AudioRendererInfo for playback and SourceType or AudioSourceType for recording, highlighting specific API calls like createAudioRenderer and prepare, and noting AVPlayer default behaviors. The intended audience is developers seeking to manage audio stream configurations using multimedia APIs.
