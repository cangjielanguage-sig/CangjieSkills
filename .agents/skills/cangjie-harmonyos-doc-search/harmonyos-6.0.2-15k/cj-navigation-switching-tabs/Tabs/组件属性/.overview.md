# 组件属性

This directory contains API reference documentation for configuring the properties of the TabBar component within the ArkUI framework using the Cangjie language. It covers a wide range of customization options including animation settings, visual effects, layout dimensions, background styling, and interaction behaviors. Developers can find detailed parameters for functions controlling animation duration, background blur, bar positioning, and scrollability. This documentation is suitable for UI developers and system engineers building HarmonyOS applications who need precise control over the appearance and functionality of tabbed interfaces to enhance user experience.

## Detailed Description

### func_animationDurationFloa_5more.md
This API reference document details functions for configuring animation and visual effects of TabBar components within the ArkUI framework using the Cangjie language. The main sections cover animationDuration (supporting Float32 and Int32), animationMode, and barBackgroundBlurStyle (with and without options). Key information includes parameter definitions for transition duration in milliseconds, animation modes like CONTENT_FIRST, and background blur material settings. The document specifies system capabilities and starting versions for each function. It is intended for developers building tabbed interfaces who require precise control over transition animations and background aesthetics.

### func_barBackgroundColorRes_6more.md
This document provides API reference documentation for configuring the appearance and layout of the TabBar component in the Cangjie ArkUI framework. It details six specific functions: barBackgroundColor, barBackgroundEffect, barGridAlign, barHeight, and two overloads of barMode. Each section includes the function signature, description, system capability, starting version, and parameter tables. Key features include setting background colors and effects, defining height with specific default values based on orientation and style, and configuring layout modes (Fixed or Scrollable). Notably, barGridAlign is restricted to horizontal mode and excludes extra-large devices, while barMode supports scrollable options starting from version 19. This technical reference is intended for developers building UI applications using the Cangjie language and ArkUI framework, requiring knowledge of component styling and layout management.

### func_barOverlapBool_6more.md
This document serves as an API reference for configuring the appearance and behavior of the TabBar component within the ArkUI framework using the Cangjie language. It details six key functions: barOverlap, barPosition, barWidth, divider, edgeEffect, and fadingEdge, covering parameters like blur effects, positioning, dimensions, and scroll behaviors. Key information includes specific default values for width based on vertical orientation and style, the automatic blur style change when overlapping is enabled, and the default spring edge effect. Intended for UI developers, this reference requires knowledge of Cangjie syntax and ArkUI components to effectively customize tab navigation interfaces.

### func_scrollableBool_2more.md
This document provides API reference documentation for configuring tab navigation behaviors within the ArkUI framework using the Cangjie language. It covers two primary functions: scrollable and vertical, both designed to modify component properties via Boolean parameters. Key information includes that scrollable controls whether users can switch pages via swiping, defaulting to enabled, while vertical sets the tab orientation to vertical or horizontal, defaulting to horizontal. The text also warns developers to maintain consistent child component sizes to avoid animation jumps. This technical reference targets developers building HarmonyOS user interfaces who require precise control over tab interaction and layout orientation.
