# cj-crypto-sm4-sym-encrypt-decrypt-gcm

This directory serves as a specialized technical repository for Cangjie developers focusing on high-security data protection through the SM4 symmetric encryption algorithm. Specifically, it targets the implementation of the GCM (Galois/Counter Mode), which is widely regarded for providing both confidentiality and data integrity simultaneously. The resources within this directory guide users through the complex nuances of the CryptoArchitectureKit, detailing how to properly generate and manage 128-bit symmetric keys, handle specific padding schemes like PKCS7, and correctly process authentication tags to prevent tampering. It is an essential reference for developers building secure applications in the Cangjie ecosystem who need to ensure their cryptographic implementations are robust, efficient, and compliant with standard security practices.

### 使用SM4对称密钥GCM模式加解密仓颉

This subdirectory acts as a comprehensive educational hub for developers working within the Cangjie programming environment who wish to master SM4 symmetric encryption and decryption using GCM mode. The tutorials provided here offer a deep dive into the cryptographic workflow, ensuring that developers can effectively utilize the CryptoArchitectureKit to secure their applications against unauthorized access and data corruption.

The content covers the entire lifecycle of the encryption process in granular detail. It begins with the generation of 128-bit SymKeys, which are fundamental to the SM4 algorithm's security. From there, it guides users through the instantiation and management of Cipher objects, specifically configured with the parameters `SM4_128|GCM|PKCS7`. This specific combination ensures that data is not only encrypted but also properly padded to block boundaries and authenticated via the GCM mode.

Furthermore, the tutorials highlight critical technical steps that are often sources of implementation errors. This includes the correct handling of `GcmParamsSpec`, which defines the initialization vector (IV) and other GCM-specific parameters necessary for the algorithm's operation. It also details the procedural use of `update` and `doFinal` methods for processing data chunks efficiently, as well as the vital task of managing the 16-byte authentication tag. This tag is crucial for verifying the integrity and authenticity of the decrypted data, ensuring that any modification of the ciphertext is detected. Overall, this resource is tailored for Cangjie developers who possess a foundational understanding of symmetric keys and padding modes and are looking to apply this knowledge in a practical, secure manner.
