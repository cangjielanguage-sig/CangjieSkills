## 读取动态照片资源

对于一个动态照片对象，应用可以通过[requestContent](../../../API_Reference/source_zh_cn/apis/MediaLibraryKit/cj-apis-multimedia-photo_accesshelper.md#func-requestcontentstring-string)导出图片和视频到应用沙箱，或者读取图片或视频的ArrayBuffer内容。

```cangjie
import kit.MediaLibraryKit.*
import ohos.base.BusinessException

func example(movingPhoto: MovingPhoto) {
    try {
        let imageFileUri = 'file://com.example.temptest/data/storage/el2/base/haps/entry/files/request_moving_photo.jpg'
        let videoFileUri = 'file://com.example.temptest/data/storage/el2/base/haps/entry/files/request_moving_photo.mp4'
        movingPhoto.requestContent(imageFileUri, videoFileUri) // 将动态照片导出到应用沙箱。
        let imageData = movingPhoto.requestContent(ResourceType.IMAGE_RESOURCE) // 读取图片的ArrayBuffer内容。
        let videoData = movingPhoto.requestContent(ResourceType.VIDEO_RESOURCE) // 读取视频的ArrayBuffer内容。
    } catch (e: BusinessException) {
        AppLog.error("request moving photo failed with error: ${e.code}, ${e.message}")
    }
}
```
