# x509_使用

This directory contains technical documentation and tutorials focused on the implementation and handling of X.509 digital certificates within the Cangjie programming language. It covers essential cryptographic operations including the generation of certificates, creation of Certificate Signing Requests (CSRs), parsing of PEM-encoded files, and the verification of certificate chains. Key topics include defining certificate attributes, managing validity periods, and validating trust chains using the `stdx.crypto.x509` library. This resource is specifically designed for Cangjie developers who need to integrate robust security features, such as TLS/SSL components or digital signing, into their applications using the standard crypto library.

## Detailed Description

### 创建解析证书_2more.md 创建解析证书_2more.md
This document serves as a practical tutorial for Cangjie developers on how to generate and parse X.509 digital certificates and Certificate Signing Requests (CSRs) using the standard crypto library. The content is divided into two main sections: creating and parsing a standard X.509 certificate, and creating a CSR. Key takeaways include the process of defining certificate attributes like subject names, validity periods, and IP addresses, as well as decoding PEM files for keys and parent certificates. The examples illustrate accessing specific certificate fields such as the issuer, serial number, and DNS names. This guide is intended for developers implementing cryptographic security features in Cangjie applications.

### 读取解析证书_2more.md 读取解析证书_2more.md
This document provides Cangjie code examples for reading, parsing, and verifying X.509 certificates using the stdx.crypto.x509 library. It covers two primary workflows: parsing certificate fields like serial number, issuer, public key, and extensions, and verifying certificate validity through time checks, DNS matching, and chain of trust validation. Key takeaways include methods for decoding PEM files, accessing specific attributes such as DNS names and key usage, and configuring VerifyOption objects to test various trust scenarios involving root and intermediate certificates. This tutorial targets Cangjie developers implementing security features who need to handle digital certificates and cryptographic validation.
