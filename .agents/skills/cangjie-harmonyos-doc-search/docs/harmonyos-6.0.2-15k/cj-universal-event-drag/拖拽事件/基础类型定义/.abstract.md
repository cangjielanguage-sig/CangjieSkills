This directory defines the fundamental data structures and enumerations required for implementing drag-and-drop functionality within the Cangjie ArkUI framework. It covers essential classes like `DragInfo`, `DragItemInfo`, and `DragEvent`, alongside enumerations such as `DragBehavior`, `DragResult`, and `PreDragStatus`. These components manage data transfer, visual representation, interaction states, and event handling. Designed for Cangjie developers and HarmonyOS engineers, this documentation provides the necessary building blocks to create interactive UI components with robust drag-and-drop capabilities, requiring SystemCapability.ArkUI.ArkUI.Full (version 19 or later).
