This directory provides comprehensive technical documentation for the AbilityStage component container within HarmonyOS applications developed using the Cangjie language. It details the architecture of AbilityStage as a Module-level container responsible for HAP initialization, lifecycle management, and resource preloading. The content covers essential implementation steps, including class creation, registration, and module.json5 configuration, alongside specific lifecycle callbacks such as onCreate, onConfigurationUpdate, and onMemoryLevel. Furthermore, it addresses critical performance optimization strategies, focusing on memory management and handling low-memory system events to prevent application termination. This guide is specifically designed for developers utilizing the Cangjie language and AbilityKit framework who require a deep understanding of module-level logic to build robust, stable, and efficient HarmonyOS applications capable of handling complex system events and resource constraints.
