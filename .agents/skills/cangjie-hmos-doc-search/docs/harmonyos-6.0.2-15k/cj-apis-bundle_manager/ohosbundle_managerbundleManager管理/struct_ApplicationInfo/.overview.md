# struct_ApplicationInfo

This directory provides comprehensive API reference documentation for the `ApplicationInfo` struct in the Cangjie programming language, specifically within the BundleManager framework. It details the structural definition of application metadata, configuration properties, and resource management. Key topics include application permissions, bundle types, localized resources (icons, labels), and system attributes like process info and release types. The documentation highlights methods for retrieving bundle information, such as `getBundleInfoForSelf`, and notes specific API version requirements starting from version 12 or 19. This resource is essential for Cangjie developers looking to query application attributes, manage resources, and ensure compatibility with system SDKs.
