This directory provides a focused tutorial on iterator operations and pipeline expressions within the Cangjie programming language. It is designed to guide developers through the intricacies of functional programming patterns, specifically emphasizing the manipulation of data sequences. The content covers a range of essential operations, including filtering, stepping, skipping, and iterating over arrays. By leveraging the pipe operator (`|>`), users can chain these functions to create readable and efficient data processing pipelines. The tutorial highlights key functions such as `filter`, `step`, `skip`, `forEach`, `collectString`, and `contains`. This resource is ideal for Cangjie developers aiming to deepen their understanding of the standard library, improve their code efficiency, and master advanced collection manipulation techniques.
