This directory contains API reference documentation for core interfaces within the Cangjie unittest framework. It covers essential components for data-driven testing, including data generation strategies (DataProvider, DataStrategy), test case minimization (DataShrinker), and output formatting (PrettyPrintable, KeyFor). These documents define method signatures, properties, and implementations for standard types like Array and Range. This resource is suitable for developers implementing property-based testing, parameterized tests, or customizing test output configurations in Cangjie.
