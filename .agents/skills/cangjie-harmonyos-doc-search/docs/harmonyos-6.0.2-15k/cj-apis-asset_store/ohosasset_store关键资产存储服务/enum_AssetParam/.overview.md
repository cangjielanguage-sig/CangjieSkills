# enum_AssetParam

This directory provides comprehensive API reference documentation for the `SystemCapability.Security.Asset` module, specifically designed for the Cangjie programming language. It encompasses the definitions and specifications required for managing critical assets securely, focusing on enumerations, data attributes, and synchronization parameters. Key topics include the `AssetParam` enumeration for attribute types, custom data labels (normal and local), persistence flags, and query controls for pagination. Additionally, it covers synchronization types and timestamp management. These documents are essential for developers building secure applications who need to implement precise configurations for asset storage, access control, and data integrity, starting from system capability version 19.
