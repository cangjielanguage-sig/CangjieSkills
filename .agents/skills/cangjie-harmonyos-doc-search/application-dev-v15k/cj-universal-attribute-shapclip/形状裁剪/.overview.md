# 形状裁剪

This directory provides comprehensive documentation and resources for implementing shape clipping and masking effects within the ArkUI framework using the Cangjie language. It covers the fundamental APIs required to manipulate UI component visibility and layout boundaries through geometric shapes such as circles, rectangles, and paths. Key topics include boolean toggling for clipping, advanced masking with progress indicators, and the definition of shape classes. This collection is suitable for UI developers and system engineers working on HarmonyOS applications who need to create complex visual styles and custom drawing interfaces.

### 基础类型定义/
This directory contains API reference documentation for fundamental shape classes within the Cangjie ArkUI framework. It covers the base class `ShapeAbstract` and its derived implementations like `CircleShape`, `RectShape`, and `PathShape`, alongside utility classes such as `ProgressMask`. These definitions are essential for creating geometric shapes used in clipping, masking, and custom drawing interfaces. The documentation targets UI developers working with ArkUI system capabilities, specifically those implementing visual effects and geometric manipulations in applications running on version 12 or later.
