# cj-universal-gesture-pinchgesture

This directory provides the essential API reference documentation for the `PinchGesture` class, a specialized component designed to facilitate multi-finger pinch interactions within the Cangjie (CJ) framework for HarmonyOS. It is a vital resource for developers working with the ArkUI framework who aim to build highly interactive and responsive user interfaces. The documentation offers an in-depth look at the technical specifications required to implement scaling and zooming gestures, covering everything from component initialization to advanced event handling. Key topics include configuring parameters such as finger count (supporting 2 to 5 fingers) and minimum recognition distance, as well as managing the gesture lifecycle through callbacks for start, update, end, and cancellation events. By detailing default values and specific calculation rules—such as the priority given to the first set of fingers touching the screen—this guide ensures developers can create predictable and smooth touch experiences. This resource is ideally suited for HarmonyOS developers, mobile application engineers, and UI/UX designers seeking to integrate complex touch controls and robust state management into their applications.

### cj-universal-gesture-pinchgesture.md

This file serves as the primary technical resource for the PinchGesture class.
