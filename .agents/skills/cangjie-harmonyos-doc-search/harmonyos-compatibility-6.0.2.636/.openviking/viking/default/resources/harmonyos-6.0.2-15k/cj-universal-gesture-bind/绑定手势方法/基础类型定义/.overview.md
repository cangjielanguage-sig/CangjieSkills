# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental type definitions used in gesture handling within the ArkUI framework, specifically utilizing the Cangjie language. It encompasses essential data structures and classes required to build robust interactive interfaces, including base types for gesture recognition, event targets, finger information, and event propagation masks. Additionally, it details the `GestureEvent` class, which is crucial for processing complex user interactions like rotation, swiping, and pinching. These resources are designed for software developers and UI engineers who need to implement sophisticated touch and mouse gesture recognition, manage coordinate systems, and control event flow in their ArkUI applications. By understanding these base types, developers can effectively customize gesture logic and ensure smooth user experiences.

## Detailed Description

### class_GestureType_4more.md class_GestureType_4more.md
This document serves as API reference documentation for gesture-related classes and enums in the ArkUI framework using the Cangjie language, defining base types and data structures for handling touch interactions. It covers the `GestureType` base class with tagging capabilities, the `EventTarget` class for element areas, the `FingerInfo` class for touch coordinates, and the `GestureMask` enum for controlling event propagation between parent and child components. Key takeaways include the `tag` method for custom gesture identification, coordinate properties in `FingerInfo` (global vs. local), and the `IgnoreInternal` mask option to block child component gestures like scrolling. Intended for developers building ArkUI applications who need to implement or customize gesture recognition and event handling logic.

### class_GestureEvent/
This directory contains API reference documentation for the `GestureEvent` class within the Cangjie language and ArkUI framework. It covers the structural definition and properties of gesture events used to handle user interactions such as rotation, swiping, panning, and pinching. Key topics include event initialization, coordinate calculations, scaling ratios, and velocity metrics. This documentation is suitable for software developers and UI engineers building interactive applications who need to implement sophisticated touch and mouse gesture recognition using the SystemCapability.ArkUI.ArkUI.Full module.
