# sample_json_reader

This directory serves as a comprehensive educational resource for understanding JSON deserialization via the streaming API in the Cangjie programming language. It provides a practical, executable code example that guides developers through the creation of a custom class implementing the `JsonDeserializable` interface. Unlike DOM-based parsing, the streaming approach demonstrated here offers significant advantages in memory efficiency and performance, particularly when dealing with large data streams or continuous data feeds. The tutorial emphasizes manual parsing control using `JsonReader`, covering essential techniques for handling diverse data structures such as optional strings, booleans, floats, arrays, and hash maps. It also touches upon error handling and robustness in parsing. This content is particularly suitable for Cangjie developers looking to optimize data processing for large datasets, integrate with legacy systems that require specific parsing logic, or those seeking a deep, technical understanding of the `stdx.encoding.json.stream` library's internal mechanics and the serialization/deserialization lifecycle.

## Detailed Description

### sample_json_reader.md sample_json_reader.md

This document provides a detailed code example demonstrating how to perform JSON deserialization using the streaming API in the Cangjie programming language. It serves as an essential practical guide for developers who need to move beyond automatic parsing and implement custom deserialization logic with granular control over the reading process.

The content thoroughly covers the definition of a custom class that implements the `JsonDeserializable` interface. It explains the necessary boilerplate and structural logic required to successfully integrate user-defined types with the JSON parsing system. A significant portion of the document is dedicated to the implementation of the static `fromJson` method using `JsonReader`, providing deep insights into how the reader interacts with the data stream to extract values efficiently and safely.

Additionally, the document includes a main function that demonstrates the parsing process in a complete, runnable context. The example highlights the robust handling of various data types, including optional strings (handling nullability), booleans, floating-point numbers, arrays (lists), and hash maps (dictionaries), showing how to accurately map these JSON elements to native Cangjie types.

Finally, it illustrates the use of specific methods such as `startObject`, `readName`, `readValue`, and `endObject` for manual parsing control. These methods allow developers to navigate the JSON structure explicitly, enabling custom validation, data transformation, or error handling during the read phase. This tutorial targets Cangjie developers who need to parse JSON data manually or understand the underlying mechanics of the `stdx.encoding.json.stream` library.
