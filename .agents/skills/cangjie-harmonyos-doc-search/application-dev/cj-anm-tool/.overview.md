# cj-anm-tool

This directory contains documentation for the Advanced Notification Manager (anm) tool, a specialized command-line utility created for developers working within the OpenHarmony ecosystem. It serves as a comprehensive reference guide for debugging and testing notification functions, offering detailed insights into system-level notification behaviors. The documentation covers essential environment requirements, a complete command overview, and specific usage instructions for help, dump, and setting commands. Key capabilities include the ability to print active, recent, or distributed notifications and configure critical system parameters such as cache limits and enable switches. This resource is strictly intended for developers using the hdc tool on engineering (eng) versions who need to inspect notification states or modify system behaviors during the development lifecycle. By utilizing this guide, developers can effectively troubleshoot notification issues and ensure their applications interact correctly with the OpenHarmony notification subsystem.

### cj-anm-tool.md cj-anm-tool.md
This file serves as the definitive reference guide for the Advanced Notification Manager (anm) tool. It documents a robust command-line utility specifically engineered to assist developers in the complex tasks of debugging and testing notification functions on the OpenHarmony operating system. The content is structured to provide a clear understanding of the necessary environment requirements, a comprehensive command overview, and granular usage instructions for specific commands such as help, dump, and setting. Among its most critical features, the guide explains how to print active, recent, or distributed notifications, allowing for real-time inspection of the system's notification queue. Furthermore, it details how to configure system parameters, including cache limits and various enable switches, giving developers control over system behavior. It is important to note that this tool requires the hdc tool for execution and is designed to run exclusively on eng versions of the software. This documentation is targeted at developers who need to deeply inspect notification states or modify system notification behaviors during the development process. It provides the necessary technical depth to understand the internal workings of the notification manager, making it an essential resource for troubleshooting and system optimization.
