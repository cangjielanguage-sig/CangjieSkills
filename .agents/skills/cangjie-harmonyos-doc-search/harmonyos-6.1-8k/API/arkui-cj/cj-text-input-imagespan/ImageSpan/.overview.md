# ImageSpan

本目录汇集了ArkUI框架中ImageSpan组件的核心开发文档，专注于指导开发者使用仓颉语言在Text组件中实现行内图片嵌入功能。文档内容全面覆盖了组件的API参考、构造方法（支持ResourceStr和PixelMap）、通用属性限制以及colorFilter、objectFit、verticalAlign等关键属性的使用。同时，详细介绍了图片加载完成与异常的回调事件机制。该组件目前处于Beta阶段，非常适合致力于构建图文混排界面的ArkUI应用开发者查阅。

## 详细说明

### ImageSpan_7more_0769d0d5.md ImageSpan_7more_0769d0d5.md
本文档是ArkUI框架中ImageSpan组件的API参考手册，旨在指导开发者使用仓颉语言在Text组件中嵌入行内图片。文档详细介绍了组件的导入方式、基于ResourceStr或PixelMap的多种构造方法，以及通用属性与事件的限制。重点阐述了colorFilter（颜色滤镜）、objectFit（图片填充）和verticalAlign（垂直对齐）等核心组件属性。此外，还包含图片加载完成与异常情况的回调事件说明。该组件目前处于Beta阶段，主要面向需要实现图文混排效果的ArkUI应用开发者。

### 示例代码.md 示例代码.md
本文档通过具体的Cangjie代码示例，演示了ArkUI框架中ImageSpan组件的实际应用方法。内容分为两部分：第一部分展示了如何利用verticalAlign和objectFit属性调整ImageSpan在文本中的对齐方式及缩放效果；第二部分演示了通过colorFilter属性为图像添加颜色滤镜，并结合@State实现动态交互。这些示例涵盖了图文混排及图像处理的关键技术点，适合正在学习或使用ArkUI进行应用开发的开发者参考。
