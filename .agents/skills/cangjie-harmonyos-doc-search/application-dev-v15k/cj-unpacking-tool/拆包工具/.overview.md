# 拆包工具

This directory provides comprehensive documentation for the HarmonyOS Unpacking Tool, a utility designed to decompress and analyze HAP, HSP, App, and APPQF packages. It covers both command-line usage and Java API integration for extracting configuration metadata and debugging application structures. The content includes interface references, command instructions, and detailed data structure schemas for various package components. Suitable for HarmonyOS developers, application market engineers, and system integrators who need to programmatically parse package contents or inspect internal metadata during development and debugging.

## Detailed Description

### 包解析接口.md 包解析接口.md
This document serves as an API reference for the package parsing interface, designed to extract configuration information from HAP, HSP, and App packages for application markets. The content details the UncompressEntrance class, specifically four Java interface methods categorized by parsing App packages or HAP packages. Key takeaways include the support for both file paths and input streams, the use of ParseAppMode enumeration (ALL, HAP_LIST, HAP_INFO) to control parsing depth, and the return of UncompressResult objects containing extracted data. This technical documentation targets developers working on application market platforms who need to programmatically analyze package contents and metadata.

### 拆包工具_2more.md 拆包工具_2more.md
This document serves as a technical guide for the HarmonyOS Unpacking Tool, a debugging utility designed to decompress and analyze HAP, HSP, and App files. It details the tool's dual functionality, supporting both command-line operations and Java API parsing, and identifies its location within the HarmonyOS SDK. Key takeaways include a specific constraint for Cangjie developers, noting that HSP packages are currently unsupported in Cangjie programs, and a system requirement for Java 8 or higher. This reference is intended for HarmonyOS developers seeking to inspect package structures during the development and debugging process.

### 拆包指令说明.md 拆包指令说明.md
This reference guide provides command-line instructions for using the app_unpacking_tool.jar to decompress various application package formats. It covers five distinct modes: unpacking HAP, App, HSP, and APPQF packages, as well as extracting specific rpcid files from HAP packages. Each section details the required syntax, mandatory parameters like file paths and output directories, and optional flags such as --force for overwriting existing files. Targeted at developers, this guide requires knowledge of Java command-line execution to inspect or analyze application components.

### 拆包工具信息字段/
This directory contains technical reference documentation for data structures used in HarmonyOS and OpenHarmony application unpacking tools. It covers the schema definitions for key components such as AppInfo, AbilityInfo, HapInfo, and various configuration structures like permissions, forms, and distribution filters. The documents detail the attributes, data types, and specific rules for both FA (Feature Ability) and Stage models. This resource is essential for software developers, system integrators, and tool engineers who need to parse application bundles, configure manifests, or understand the internal metadata of HAP packages.
