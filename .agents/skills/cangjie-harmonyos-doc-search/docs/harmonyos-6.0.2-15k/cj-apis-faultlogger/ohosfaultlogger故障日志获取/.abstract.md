This directory provides comprehensive API reference documentation for the `ohos.faultlogger` module within the HarmonyOS ecosystem, specifically utilizing the Cangjie programming language. It focuses on the mechanisms for retrieving, categorizing, and analyzing system fault logs to aid in application stability and diagnostics. The documentation covers essential data structures like `FaultLogInfo`, enumerations for fault categorization such as `FaultType`, and the core `FaultLogger` class used for querying log data. This resource is tailored for developers and system integrators working with the PerformanceAnalysisKit who require programmatic access to system-level crash and freeze reports for debugging and performance optimization.
