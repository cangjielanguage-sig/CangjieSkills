This directory contains API reference documentation for the `GeolocationPermissions` class within the Cangjie language environment, specifically designed for HarmonyOS developers using the ArkWeb framework. It covers the management of geolocation access for Web components, detailing static methods to allow, delete, and retrieve permission states. Key topics include system permissions, incognito mode handling, and error code management. This resource is suitable for developers needing to programmatically control location permissions in webview applications, ensuring privacy and compliance with user settings.
