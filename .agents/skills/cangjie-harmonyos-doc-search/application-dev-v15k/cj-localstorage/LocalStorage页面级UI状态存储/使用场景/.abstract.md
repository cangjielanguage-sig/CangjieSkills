This directory contains tutorials and guides on using LocalStorage for state management in HarmonyOS applications developed with the Cangjie language. It covers various usage scenarios including data synchronization between components, sharing state across views via UIAbility, integrating storage with application logic, handling complex data types like DateTime and collections, and cross-language interoperability with ArkTS. These resources are suitable for Cangjie developers and HarmonyOS application architects looking to implement reactive state management, ensure data consistency, and manage shared application states efficiently.
