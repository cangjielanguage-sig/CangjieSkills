This directory contains API reference documentation for styling text spans and components within the Cangjie ArkUI framework. It comprehensively covers text styling capabilities, ranging from font configuration (size, weight, family) and layout adjustments (baseline offset, line height) to advanced visual effects (shadows, backgrounds). The documentation provides detailed function signatures, parameter types, default values, and specific system capability requirements. It is suitable for software developers using the Cangjie language to design and customize user interfaces, offering precise technical guidance on text appearance, behavior, and resource management.
