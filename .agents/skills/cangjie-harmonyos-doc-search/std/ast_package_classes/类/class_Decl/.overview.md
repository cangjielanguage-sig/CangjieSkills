# class_Decl

This directory provides comprehensive API reference documentation for the Cangjie Abstract Syntax Tree (AST), focusing specifically on declaration structures and node manipulation utilities. It details the `Decl` class, the foundational parent for all declaration nodes, alongside essential methods for visualizing, traversing, and inspecting syntax tree elements. Key topics include handling generic parameters, modifiers, annotations, and implementing the Visitor pattern for tree walking. This documentation is primarily designed for compiler developers and language tool engineers who require deep programmatic access to Cangjie language structures for analysis or transformation tasks.

### class_Decl_13more.md

This API reference document defines the `Decl` class, which serves as the base parent class for all declaration nodes within the Cangjie Abstract Syntax Tree. It inherits from the `Node` class and establishes the fundamental structure for declarations.

**Key Components:**
*   **Protected Variables:** Used for maintaining internal state.
*   **Public Properties:** Provide access to identifiers, keywords, modifiers, annotations, and generic parameters.
*   **Supported Types:** The class supports various declaration types, including classes and functions.
*   **Advanced Features:** It handles generic constraints and type parameters effectively.

This document is intended for compiler developers or tool builders working with the Cangjie AST who need to manipulate or inspect declaration structures.

### func_dumpUInt16_5more.md

This document provides API reference documentation for methods operating on Abstract Syntax Tree (AST) nodes within the Cangjie language framework. It focuses on utility functions that allow developers to interact with and analyze the tree structure.

**Primary Functions Covered:**
*   **dump:** Visualizes the node structure with indentation for debugging.
*   **getAttrs / hasAttr:** Retrieves and checks for specific node attributes.
*   **toTokens:** Handles type conversion operations.
*   **traverse:** Walks the node hierarchy using a Visitor pattern, with support for early termination.

Key information includes the specific string formatting for tree output and the ability to terminate traversals early. This technical reference targets compiler developers and language tool engineers who need to inspect, modify, or analyze syntax trees programmatically.
