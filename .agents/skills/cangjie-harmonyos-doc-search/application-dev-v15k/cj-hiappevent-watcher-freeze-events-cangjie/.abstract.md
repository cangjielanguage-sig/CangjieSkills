This directory functions as a comprehensive technical resource focused on the subscription and monitoring of application freeze events within the HarmonyOS ecosystem, utilizing the Cangjie programming language. It provides an extensive overview of the essential API interfaces required for effective event subscription, with a particular emphasis on the `addWatcher` and `removeWatcher` methods. The content covers the full development lifecycle for performance monitoring, integrating the PerformanceAnalysisKit and HiAppEvent framework. Additionally, it explores cross-language interaction patterns involving Cangjie and ArkTS. This documentation is primarily intended for HarmonyOS developers, performance engineers, and QA professionals who are seeking to implement precise event tracking systems, diagnose complex runtime issues, and ensure application stability through detailed log analysis and system-level data interpretation, ultimately improving user experience by mitigating app freezes.
