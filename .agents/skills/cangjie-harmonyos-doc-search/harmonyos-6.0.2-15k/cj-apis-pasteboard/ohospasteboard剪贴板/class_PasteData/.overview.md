# class_PasteData

This directory provides comprehensive API reference documentation for the Cangjie `PasteData` class, a core component for handling clipboard content in HarmonyOS applications. It details the structure of pasteboard data objects, including data records and properties, and covers a wide range of operations such as adding, retrieving, modifying, and removing various data types like text, HTML, PixelMap, and byte arrays. Designed for Cangjie developers utilizing the BasicServicesKit, these resources facilitate the implementation of complex pasteboard features under the SystemCapability.MiscServices.Pasteboard capability.

### class_PasteData_5more.md class_PasteData_5more.md
This document provides API reference documentation for the Cangjie PasteData class, which represents clipboard content objects containing data records and properties. The main sections cover the class definition and four overloaded addRecord functions designed to append data entries. Key information includes that these methods support various data types—PasteDataRecord, String, PixelMap, and byte arrays—and automatically update MIME types in the PasteDataProperty. Developers must initialize the object using createData() before calling these methods. Intended for Cangjie developers, this guide facilitates handling text, images, and binary data within the SystemCapability.MiscServices.Pasteboard system capability.
