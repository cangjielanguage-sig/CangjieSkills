# cj-huks-key-generation-overview

This directory provides a comprehensive technical reference for generating keys using the OpenHarmony HUKS (Hardware Unified Key Storage) service. It covers fundamental concepts such as cryptographically secure random generation and secure storage, ensuring keys remain inaccessible outside the HUKS environment. The documentation details supported algorithms—including AES, RSA, ECC, SM2, and SM4—along with their specific key lengths and API level requirements for both standard and lightweight devices. It emphasizes that keys are designed for single purposes to enhance security. This resource is suitable for application developers working on OpenHarmony systems who need to implement secure cryptographic operations and manage key lifecycles effectively.
