This directory provides technical guides for the `ohos.router` module in HarmonyOS, specifically designated as a legacy or non-recommended approach. It covers essential routing operations such as page jumping, returning, and implementing confirmation dialogs within the Cangjie and ArkUI frameworks. Key topics include URL-based navigation, data transfer, page stack management, and lifecycle handling. Although functional, the documentation emphasizes that the Navigation component is now the standard. This collection is intended for developers maintaining legacy code or seeking to understand historical routing implementations before migrating to the new framework.
