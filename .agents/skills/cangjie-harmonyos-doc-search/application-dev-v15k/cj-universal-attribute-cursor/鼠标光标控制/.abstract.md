This directory focuses on mouse cursor control within the HarmonyOS ArkUI framework using the Cangjie language. It covers the `CursorControl` class for manipulating cursor styles programmatically and the `PointerStyle` enumeration for defining specific visual appearances. Key topics include setting custom cursors, restoring defaults, and handling UI events like hover and click. This resource is suitable for application developers and UI/UX designers looking to enhance user interaction and feedback through dynamic cursor management in their applications.
