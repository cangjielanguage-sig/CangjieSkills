This directory contains essential API reference documentation for the `AudioViewPicker` class in the Cangjie language, designed to facilitate audio file management within HarmonyOS applications. It provides detailed technical specifications for selecting and saving audio files, including class constructors, asynchronous methods, and option configurations. Developers will find information on utilizing `UIAbilityContext`, handling `AudioSaveOptions`, and managing file URIs through callback mechanisms. The documentation is intended for application developers who need to implement audio storage and selection features, assuming prior knowledge of Cangjie syntax and the HarmonyOS development environment.
