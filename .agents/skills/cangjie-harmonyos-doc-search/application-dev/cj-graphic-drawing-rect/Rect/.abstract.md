This directory contains comprehensive documentation for the Rect component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the API reference for creating and configuring rectangle drawing tools, including initialization parameters, supported attributes, and event handling. The content also provides practical code examples demonstrating styling techniques such as fill, stroke, and rounded corners. Suitable for UI developers and HarmonyOS application builders, this resource facilitates the implementation of 2D shapes and declarative UI design in Cangjie applications.
