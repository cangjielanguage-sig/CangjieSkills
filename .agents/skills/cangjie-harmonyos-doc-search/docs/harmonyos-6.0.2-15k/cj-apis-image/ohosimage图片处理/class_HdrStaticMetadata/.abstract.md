This directory contains essential API reference documentation for the `HdrStaticMetadata` class within the Cangjie language framework. It focuses on High Dynamic Range (HDR) static metadata, which is critical for defining color characteristics and luminance levels in modern image processing. The documentation covers the class constructor, properties for display primaries, white points, and various luminance metrics such as max content light level. It is intended for multimedia developers working with the `SystemCapability.Multimedia.Image.Core` framework to implement advanced HDR features. Users should have a solid understanding of image processing concepts and Cangjie syntax to utilize these resources effectively.
