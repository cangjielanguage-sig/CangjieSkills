This directory provides comprehensive API documentation for the `ohos.file_picker` module in the Cangjie language, designed for HarmonyOS application development. It covers the implementation of system-level file pickers for selecting and saving photos, audio, and documents. Key components include configuration options like `DocumentSelectOptions`, `PhotoSaveOptions`, and picker classes such as `PhotoViewPicker` and `AudioViewPicker`. The documentation details asynchronous methods, URI handling, and file filtering capabilities. It is suitable for Cangjie developers integrating file management and user interaction features into their applications using the SystemCapability.FileManagement.UserFileService.
