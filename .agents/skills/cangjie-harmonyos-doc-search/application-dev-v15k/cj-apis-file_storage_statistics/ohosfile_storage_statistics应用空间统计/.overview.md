# ohosfile_storage_statistics应用空间统计

This directory provides comprehensive API references for the `ohos.file_storage_statistics` module within the HarmonyOS ecosystem, specifically tailored for developers using the Cangjie language. It focuses on the mechanisms required to query and manage storage space statistics effectively. The content covers the definition of storage data structures and the functions necessary to retrieve critical metrics such as total internal storage capacity, available free space, and granular application-specific usage (including installation, cache, and data file sizes). Leveraging the `SystemCapability.FileManagement.StorageService.SpatialStatistics` capability, these resources are essential for developers aiming to build storage-aware applications, optimize performance, and handle storage-related errors. This documentation is suitable for Cangjie developers and system engineers who need to implement robust storage monitoring and management features in their HarmonyOS applications.

## Detailed Description

### class_BundleStats.md class_BundleStats.md
This document serves as an API reference for the Cangjie class BundleStats, designed to represent application storage space statistics. It covers the class definition and details three public properties: appSize, cacheSize, and dataSize. Key information includes that all properties are Int64 types measured in Bytes, representing installation files, cache files, and other file storage sizes respectively. All fields are readable and writable. The class is part of the SystemCapability.FileManagement.StorageService.SpatialStatistics system capability, available starting from version 20. This documentation targets Cangjie developers who need to monitor or manage file storage usage within their applications.

### ohosfile_storage_statistic_6more.md ohosfile_storage_statistic_6more.md
This document serves as API reference for the ohos.file_storage_statistics module, enabling developers to query storage statistics in HarmonyOS applications using the Cangjie language. It details three primary functions: getCurrentBundleStats for retrieving app-specific data sizes, getFreeSize for available internal storage, and getTotalSize for total internal storage capacity. Key takeaways include specific return types like BundleStats and Int64, system capabilities, version requirements (API 20), and potential error codes such as IPC errors. The content targets HarmonyOS developers working with Cangjie who need to monitor storage usage or manage application data.
