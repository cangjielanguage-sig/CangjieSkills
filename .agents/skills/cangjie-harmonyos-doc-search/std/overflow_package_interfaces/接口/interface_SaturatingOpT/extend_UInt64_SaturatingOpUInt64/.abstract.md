This directory provides comprehensive API reference documentation for extending the `UInt64` type with saturating operations within the Cangjie programming language. It focuses on the implementation of the `SaturatingOp` interface and specific utility functions designed to handle arithmetic and bitwise manipulations safely. The documentation covers a wide range of operations, including addition, subtraction, multiplication, division, modulo, negation, increment, decrement, and bit shifting. A core concept explored here is saturation behavior, where results are clamped to the type's maximum or minimum limits upon overflow or underflow, thereby preventing undefined behavior. This resource is essential for Cangjie developers who require precise control over numeric boundaries and robust error handling in low-level or performance-critical programming tasks.
