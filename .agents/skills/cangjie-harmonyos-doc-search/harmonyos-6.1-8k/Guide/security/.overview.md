# security

This directory serves as a central repository for system security documentation within the HarmonyOS and OpenHarmony ecosystems. It covers critical security domains including access control mechanisms, cryptographic frameworks, and key management services. Key topics include Access Tokens, APL (Ability Privilege Level), the CryptoArchitectureKit for the Cangjie programming language, and the Harmony Universal KeyStore (HUKS). This documentation is suitable for developers and system integrators looking to implement robust security features, manage permissions, or integrate encryption and key lifecycle management into their applications. It provides the necessary guidelines to ensure applications adhere to strict security standards and protect user data effectively.

## Detailed Description

### [1] AccessToken/
This directory provides comprehensive documentation on HarmonyOS and OpenHarmony access control mechanisms, focusing on access tokens, permission management, and security isolation. It covers core concepts such as APL (Ability Privilege Level), sandbox environments, and the specific permission models used to secure applications. It is essential for understanding how the system enforces boundaries between different applications and protects sensitive resources.

### [2] CryptoArchitectureKit/
The CryptoArchitectureKit is a comprehensive cryptographic framework designed for the Cangjie programming language, providing developers with essential tools for encryption, decryption, and data security. It covers a wide range of algorithms including symmetric and asymmetric encryption, hashing, and message authentication codes. This kit serves as the foundational building block for ensuring data confidentiality and integrity across applications developed in the Cangjie environment.

### [3] README_zh/
This directory contains the Chinese navigation index documentation for the system security module, primarily introducing security features currently in the Beta stage. The documentation covers core areas such as program access control, the Crypto Architecture Kit providing encryption and decryption algorithm framework services, and the Universal Keystore Kit responsible for key management. As the main entry point for system security functions, this document aims to help developers quickly understand and integrate these security services. It is suitable for developers or system integrators who need to integrate access control, encryption and decryption algorithms, and key management services.

### [4] UniversalKeystoreKit/
UniversalKeystoreKit provides comprehensive documentation and guides for the Harmony Universal KeyStore (HUKS) within the OpenHarmony ecosystem. It focuses on secure key management, cryptographic operations, and lifecycle management using the Cangjie programming language. This section details how to generate, store, and use keys securely, ensuring that sensitive cryptographic material is protected throughout its existence, from creation to destruction.
