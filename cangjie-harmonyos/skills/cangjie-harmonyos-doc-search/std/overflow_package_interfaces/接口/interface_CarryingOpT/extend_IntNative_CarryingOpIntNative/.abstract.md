This directory provides essential API documentation for the `CarryingOp` interface as implemented for the `IntNative` type in the Cangjie programming language. It is dedicated to detailing arithmetic operations that employ a wrapping strategy to manage integer overflow effectively. The scope of this documentation includes fundamental functions such as addition, subtraction, multiplication, division, and modulo, as well as bitwise operations like shifting and negation. Crucially, all documented functions return a tuple containing a Boolean overflow flag and the computed result, allowing for precise error detection. This collection is specifically curated for Cangjie developers who need to implement safe arithmetic logic, particularly in performance-critical or low-level systems programming contexts where detecting truncation is vital for maintaining data integrity and preventing silent failures.
