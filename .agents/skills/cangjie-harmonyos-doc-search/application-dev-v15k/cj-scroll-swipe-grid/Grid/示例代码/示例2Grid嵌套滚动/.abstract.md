This directory provides a comprehensive collection of code examples focused on solving the complex challenges of nested scrolling within the HarmonyOS development environment. Specifically, it demonstrates how to effectively coordinate scroll events between a parent List component and a child Grid component using the Cangjie programming language and ArkUI framework. The examples cover critical technical aspects such as scroll event distribution, offset transfer logic using `onScrollFrameBegin`, and UI state management features like a "Back to Top" button. These resources are highly suitable for developers building complex user interfaces that require smooth, intuitive scrolling behaviors across multiple layers of content, ensuring a seamless and professional user experience.
