This directory contains the definitive overview documentation for the Cangjie Test Kit, a sophisticated automated testing framework meticulously designed for developers utilizing the Cangjie programming language. It serves as the primary resource for understanding how to effectively perform both unit and UI testing within this ecosystem. The document comprehensively details the framework's two main pillars: Unit Testing, which encompasses test definitions, flexible assertions, lifecycle management, and various execution modes; and UI Testing, which extends these capabilities to include widget location, user interaction simulation, window manipulation, and system dialog monitoring. Key features highlighted include stress testing modes and the simulation of diverse input devices. This guide is essential for Cangjie developers seeking a high-level grasp of the framework's architecture and capabilities, providing clear direction to specific usage guidelines for practical implementation.
