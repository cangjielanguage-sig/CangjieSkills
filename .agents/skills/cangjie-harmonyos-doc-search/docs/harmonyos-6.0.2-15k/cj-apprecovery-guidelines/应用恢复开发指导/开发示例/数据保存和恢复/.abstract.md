This directory serves as a technical resource for implementing robust data saving and recovery mechanisms within the Cangjie application ecosystem. It specifically addresses the AbilityKit framework, providing developers with the knowledge to handle application state resilience during crashes or unexpected terminations. The documentation covers two primary approaches: active recovery using `appRecovery` features and `ErrorObserver` callbacks, and passive recovery via the `onSaveState` interface. Key concepts include managing `Want` parameters, identifying specific launch reasons such as `APP_RECOVERY`, and detecting restart markers like `ABILITY_RECOVERY_RESTART`. This guide is tailored for application developers who need to ensure data persistence and seamless user experience restoration in their Cangjie-based projects.
