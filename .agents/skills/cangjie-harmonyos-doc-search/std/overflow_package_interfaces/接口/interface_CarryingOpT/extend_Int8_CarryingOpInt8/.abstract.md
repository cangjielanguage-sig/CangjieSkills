This directory provides comprehensive API documentation for the `CarryingOp` interface implementation specifically tailored for the `Int8` type within the Cangjie programming language. It covers a wide array of arithmetic operations, including addition, subtraction, multiplication, division, modulo, increment, decrement, negation, and bitwise shifts. A core feature of these functions is the wrapping strategy, which ensures that operations return a tuple containing both the computed result and a Boolean flag to signal overflow or truncation. This documentation is crucial for developers engaged in low-level integer arithmetic or performance-critical applications where explicit overflow detection and precise control over numerical behavior are mandatory. By utilizing these APIs, developers can prevent silent data corruption and handle edge cases in numerical computations effectively, ensuring robust system behavior.
