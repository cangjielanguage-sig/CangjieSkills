# cj-arkts_interoperability_lib

本目录包含仓颉与ArkTS互操作库的开发指南文档，旨在指导开发者实现ArkTS调用仓颉模块。该方案作为声明式互操作宏的备选，重点涵盖了在ArkTS工程中创建仓颉模块、编写互操作函数（涉及JSContext、JSCallInfo和JSValue类型转换）、通过JSModule.registerModule注册函数以及编写TypeScript声明等核心内容。文档详细阐述了手动注册和类型转换的实现细节，并强调了命名规则以防止符号覆盖。适合需要进行混合编程的HarmonyOS开发者参考。

## Detailed Description

### cj-arkts_interoperability_lib.md cj-arkts_interoperability_lib.md

这份文档是一份开发指南，旨在指导开发者如何使用仓颉-ArkTS互操作库实现ArkTS调用仓颉模块，作为声明式互操作宏的备选方案。主要内容包括在ArkTS工程中创建仓颉模块、编写互操作函数（涉及JSContext、JSCallInfo和JSValue类型转换）、通过JSModule.registerModule注册函数、编写TypeScript声明以及在ArkTS侧导入动态库进行调用。文档还强调了同一模块中注册函数和接口的命名规则，以防止符号覆盖。该指南面向需要混合编程的HarmonyOS开发者，重点在于手动注册和类型转换的实现细节。
