This directory contains API reference documentation for the `JsonObject` class within the Cangjie programming language's `encoding_json` package. It details the class structure used to encapsulate JSON object data, covering inheritance from `JsonValue`, various constructors, and essential methods for data manipulation. Key topics include managing key-value pairs via `put` and `get`, validation with `containsKey`, and serialization capabilities. This documentation is designed for developers seeking to programmatically handle, modify, and serialize JSON data structures efficiently in Cangjie.
