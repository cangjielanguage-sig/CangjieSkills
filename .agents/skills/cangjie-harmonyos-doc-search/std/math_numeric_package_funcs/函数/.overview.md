### func_trailingZerosBigInt.md func_trailingZerosBigInt.md
This document serves as API reference documentation for the trailingZeros function within the Cangjie standard library's math.numeric package. It details the function signature, functionality description, input parameters, return type, and a practical code example with expected output. The key information is that the function calculates the number of consecutive zero bits starting from the least significant bit of a BigInt value, returning an Int64 count. The example demonstrates that the hexadecimal value 0xC000_0000 results in 30 trailing zeros. This reference is intended for Cangjie developers performing low-level bit manipulation or mathematical operations requiring BigInt analysis.
