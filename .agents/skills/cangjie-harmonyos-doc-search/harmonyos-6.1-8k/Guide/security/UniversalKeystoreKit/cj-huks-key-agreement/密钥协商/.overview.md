# 密钥协商

本目录主要介绍在HarmonyOS及OpenHarmony平台下，基于通用密钥库（HUKS）框架实现密钥协商的技术方案。内容涵盖X25519和Diffie-Hellman (DH)等算法的完整实现流程，包括非对称密钥生成、公钥导出、协商会话管理及密钥派生。文档还涉及仓颉语言的代码示例及参数配置规则。适用于需要构建安全通信应用、掌握HUKS基础操作的开发者，旨在指导其实现安全高效的密钥交换协议。

本文档是一份面向开发者的教程，详细指导如何在HUKS框架下实现密钥协商功能，并以X25519算法为例进行全流程解析。文档涵盖了生成非对称密钥对、导出公钥、执行密钥协商以及删除密钥这四个核心步骤。重点讲解了如何利用`HUKS_TAG_DERIVED_AGREED_KEY_STORAGE_FLAG`参数来控制协商密钥的存储策略，即选择由HUKS系统管理密钥还是将密钥返回给调用方，并提供了相应的参数组合规则。阅读本文档需要开发者具备HUKS的基础操作知识。
