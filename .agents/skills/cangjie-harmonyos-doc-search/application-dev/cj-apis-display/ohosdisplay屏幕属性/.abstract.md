This directory provides API reference documentation for the `ohos.display` module in the Cangjie programming language, focusing on screen properties and display configurations within the HarmonyOS WindowManager framework. It covers a wide range of functionalities including querying display attributes, managing foldable device states (fold status, crease regions, display modes), handling screen orientations, and listening for display events. The documentation is essential for developers building adaptive user interfaces and window management systems that need to support diverse hardware configurations such as waterfall screens and foldable devices.
