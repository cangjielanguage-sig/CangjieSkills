# 调试步骤

This directory serves as a comprehensive technical resource for HarmonyOS developers, particularly those working with the Cangjie language, who need to debug web components within their applications. It provides a structured workflow for enabling and utilizing Chrome DevTools to inspect web pages running in the ArkWeb environment. The content covers the entire setup process, beginning with the programmatic enabling of the debugging switch and the declaration of required system permissions. It further details the necessary hardware configurations, such as enabling USB debugging, and the network setup required to bridge the device with the development machine. Key technical elements include the use of `WebviewController.setWebDebuggingAccess`, `hdc` command-line tools, and domain socket forwarding. By following these guides, developers can establish a reliable connection for real-time debugging and performance analysis. This documentation is essential for any developer aiming to troubleshoot or optimize web-based functionalities in HarmonyOS apps.

## Detailed Description

The following documents provide in-depth technical instructions for each stage of the debugging setup process.

### 应用代码开启Web调试开关_2more.md 应用代码开启Web调试开关_2more.md
This technical guide instructs developers on enabling Web debugging capabilities within an application to allow DevTools to detect web pages. The document covers enabling the debugging switch via Cangjie code, declaring necessary internet permissions in module.json5, and establishing a device connection using hdc commands. Key takeaways include calling WebviewController.setWebDebuggingAccess(true) and configuring the device for USB debugging through developer options. Targeted at HarmonyOS developers using the Cangjie language, this tutorial ensures the proper setup for web component inspection and debugging.

### 端口转发_4more.md 端口转发_4more.md
This technical tutorial guides developers on enabling Chrome DevTools debugging for ArkWeb applications by establishing port forwarding. The document details the process of querying the device's domain socket, forwarding it to the local TCP port 9222 using hdc commands, and configuring Chrome to discover network targets. Key information includes the necessity of matching the dynamic application process ID in the forwarding command and troubleshooting steps if the socket is not found. Intended for developers debugging web components, this guide ensures seamless connection between the device's domain socket and the Chrome browser for effective web page inspection and debugging.
