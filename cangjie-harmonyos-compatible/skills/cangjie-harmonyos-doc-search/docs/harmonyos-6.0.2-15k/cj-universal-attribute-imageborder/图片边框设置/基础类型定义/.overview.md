# 基础类型定义

This directory defines fundamental data types and configuration structures for the ArkUI framework within the Cangjie language. It covers essential styling components such as linear gradients, image border repetition modes, and border image options. These definitions are crucial for developers looking to implement advanced visual effects, including gradient backgrounds and complex border styling for UI components. The documentation is tailored for HarmonyOS and ArkUI developers who require precise control over UI rendering, layout aesthetics, and type safety in their applications.

## Detailed Description

### class_LinearGradientOption.md class_LinearGradientOption.md
This document serves as API reference documentation for the LinearGradientOption class in the Cangjie language, used to define linear gradient styles within the ArkUI framework. It details the class constructor and its four public properties: angle, direction, colors, and repeating. Key information includes default values, data types, and specific behaviors, such as the angle parameter overriding the direction setting and the ability to define color stops at percentage locations. Targeted at ArkUI developers, this reference requires knowledge of Cangjie syntax and UI development to implement gradient visualizations effectively.

### enum_RepeatMode.md enum_RepeatMode.md
This document provides API reference documentation for the RepeatMode enum in the Cangjie language, used to configure how sliced images repeat along borders in the ArkUI framework. The content enumerates four distinct modes: SPACE, STRETCH, REPEAT, and ROUND. Key information includes specific rendering behaviors for each mode, such as tiling with whitespace gaps, stretching to fill, repeating with clipping, or compressing to fit integer tiles. This technical reference targets UI developers working with system version 19 or higher who need precise control over image border styling and layout rendering.

### interface_BorderImageOptio_2more.md interface_BorderImageOptio_2more.md
This document serves as an API reference defining two specific sealed interfaces used within the ArkUI framework for border image configurations. It details the BorderImageOptionSourceType interface for defining image sources and the LengthEdgeWidthsType interface for specifying border edge widths. Key information includes that BorderImageOptionSourceType accepts String, AppResource, or LinearGradientOption, while LengthEdgeWidthsType accepts LengthType or EdgeWidths. Both interfaces are available starting from system version 19 and require the SystemCapability.ArkUI.ArkUI.Full capability. This reference is intended for Cangjie developers implementing UI components who need to understand valid type unions for border styling.

### class_BorderImageOption/
This directory contains comprehensive API reference documentation for the `BorderImageOption` class within the Cangjie language, specifically tailored for the ArkUI framework. It serves as a technical guide for configuring image and gradient borders, covering essential properties such as source, slice, width, outset, repeat, and fill. The documentation explains how to manipulate image slicing for corner definitions, adjust border widths, and manage repetition modes like stretching. It is primarily suitable for HarmonyOS UI developers and ArkUI developers using Cangjie who require advanced styling capabilities for container components like Row, Column, and Flex. By utilizing these resources, developers can implement sophisticated visual effects and enhance the aesthetic appeal of their application interfaces. The documents also outline system capabilities and version requirements, ensuring compatibility with the development environment.
