# collection_iterable_collections

本目录深入探讨了仓颉语言中 `Iterable` 接口的设计理念及其在集合遍历中的实际应用。文档详细解析了 `Iterable` 与 `Iterator` 接口的核心定义，揭示了 `for-in` 循环与 `while` 循环在底层的等价转换关系，并列举了支持遍历的标准集合类型。通过理解 `for-in` 语法本质上是调用 `iterator()` 并通过 `next()` 方法获取 `Option` 类型元素的语法糖，开发者可以掌握遍历机制的本质。该目录内容非常适合正在学习仓颉语言基础语法的开发者，特别是那些希望深入理解语言底层机制或为自定义数据结构实现遍历功能的用户。
