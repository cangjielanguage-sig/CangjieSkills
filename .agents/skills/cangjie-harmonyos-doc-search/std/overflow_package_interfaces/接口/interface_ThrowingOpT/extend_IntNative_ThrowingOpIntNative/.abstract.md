This directory serves as a specialized technical resource for the Cangjie language, providing comprehensive API documentation for the `ThrowingOp` interface as implemented for the `IntNative` type. The content focuses on arithmetic and bitwise operations that prioritize safety and predictability by employing a throwing exception strategy. Instead of relying on silent wrapping, these functions explicitly throw exceptions such as `OverflowException` or `OvershiftException` when errors occur. Key topics covered include safe integer arithmetic, rigorous error handling, and specific operational functions like addition, multiplication, negation, and bit shifting. This documentation is essential for Cangjie developers who need to maintain high data integrity and require explicit control over error conditions in their mathematical and logical operations, ensuring robust application behavior and preventing undefined states.
