# 绑定半模态页面bindSheet

This directory focuses on the implementation and interaction design of half-modal pages (bindSheet) within the ArkUI framework using the Cangjie language. It covers essential concepts ranging from basic definitions and lifecycle management to advanced interaction patterns like nested scrolling and dismissal controls. The content is tailored for HarmonyOS and UI developers looking to create non-full-screen modal interfaces that maintain parent view visibility. Key topics include gesture priority, secondary confirmation dialogs, and device adaptation strategies.

## Detailed Description

### 二次确认能力_2more.md
This technical guide explains how to implement secondary confirmation and control dismissal behaviors for half-modal interfaces using the Cangjie language. It covers implementing the `onWillDismiss` callback to trigger confirmation dialogs via `AlertDialog`, filtering dismissal reasons to allow specific actions like slide-down only, and managing spring-back behaviors using `onWillSpringBackWhenDismiss`. Key takeaways include the requirement to explicitly call `dismiss()` to close the modal and `springBack()` to enable the bounce effect, as default behaviors are overridden. This guide targets UI developers seeking granular control over modal lifecycle and user interaction flows.

### 使用嵌套滚动交互.md
This document serves as a technical guide for implementing nested scrolling interactions within semi-modal panels using the Cangjie language. It details the priority logic for gestures, distinguishing between expanding or closing the panel and scrolling internal content based on the content's current position. The text explains the default nested scroll mode and provides specific instructions for configuring scrollable containers like Lists. Key takeaways include the necessity of applying the .nestedScroll modifier with NestedScrollOptions(PARENT_FIRST, SELF_FIRST) to ensure smooth interaction. The document targets HarmonyOS developers seeking to integrate complex scroll behaviors into bottom sheet interfaces.

### 绑定半模态页面bindSheet_3more.md
This document serves as a technical guide for developers on implementing the bindSheet attribute to create semi-modal pages in ArkUI. It defines bindSheet as a non-full-screen modal interaction that retains parent view visibility, ideal for simple tasks like information panels or sharing. Key sections cover usage constraints, device adaptation via the preferType property, and the specific lifecycle sequence: onWillAppear, onAppear, onWillDisappear, and onDisappear. The guide advises against using specific dismissal interfaces without custom behaviors and suggests alternative transitions for complex workflows. Targeted at application developers, this resource provides essential definitions, API references, and best practices for effective UI interaction design.
