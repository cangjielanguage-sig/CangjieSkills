# 应用权限管控概述

This directory provides a comprehensive overview of the application permission control mechanism within the operating system, focusing on security and privacy. It covers fundamental concepts such as identity management (TokenID), privilege levels (APL), and the Access Control List (ACL). Additionally, it outlines the principles of secure resource access, distinguishing between system_grant and user_grant authorizations. Key topics include permission hierarchies, data protection, and privacy compliance. This documentation is suitable for application developers and system architects seeking to implement secure access control, understand permission classification, and ensure user privacy in their applications.

## Detailed Description

### 权限机制中的基本概念.md 权限机制中的基本概念.md
This document defines the fundamental concepts governing the system's permission mechanism, specifically focusing on identity management and privilege levels. It covers TokenID for unique application identification, APL (Ability Privilege Level) classifications for both applications and permissions, and the Access Control List (ACL) mechanism for cross-level permission requests. Key points include the three-tier APL structure (normal, system_basic, system_core), the restriction preventing normal apps from accessing core resources, and the use of ACL to allow exceptions for specific high-level permissions when enabled. This reference guide targets developers needing to understand permission hierarchies and how to implement secure access control within the operating system environment.

### 简介_4more.md 简介_4more.md
This document serves as an introductory guide to the system's permission access mechanism, outlining how applications can securely access resources and capabilities. It details the protection of data and functions, establishes usage principles such as minimization and strict declaration, and distinguishes between system_grant and user_grant authorization types. Key takeaways include the requirement for dynamic user authorization for sensitive permissions and the use of permission groups to streamline the user experience. Intended for application developers, this guide ensures compliance with privacy standards and optimizes user trust.
