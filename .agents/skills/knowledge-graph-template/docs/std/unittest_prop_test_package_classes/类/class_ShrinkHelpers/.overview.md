# class_ShrinkHelpers

This directory provides comprehensive API reference documentation for the Cangjie `ShrinkHelpers` class, a specialized utility designed to facilitate property-based testing through shrinking iterators for tuples. It details the implementation of overloaded static methods, specifically `shrinkTuple`, which supports tuples containing anywhere from two to five elements. By accepting a target tuple alongside individual iterables for each component, these methods return a combined iterable of shrunk tuples, allowing developers to systematically reduce complex inputs to simpler failing cases. Beyond tuple shrinking, the directory also documents utility functions like `mix`, which combines arrays of iterables into unified iterators. The documentation clearly defines parameters and return types for generic types T0 through T3. This content is essential for Cangjie developers involved in functional programming or building automated testing frameworks who need to manipulate complex data streams and optimize test case reduction.
