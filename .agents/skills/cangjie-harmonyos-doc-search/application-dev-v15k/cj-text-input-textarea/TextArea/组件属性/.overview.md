# 组件属性

This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework, specifically focusing on text input and TextArea components. It covers a wide range of functionalities including custom keyboards, text styling (fonts, spacing, alignment), input behavior (preview, auto-fill, filters), and visual feedback (counters, selection). The documentation is intended for HarmonyOS developers and software engineers using the Cangjie language who need to customize user interfaces and implement complex text interaction logic. Key topics include font adaptation, layout constraints, and input validation.
