# 消息认证码计算

This directory focuses on the technical implementation of Message Authentication Codes (MAC) and Hash-based MAC (HMAC) to ensure data integrity and authenticity. It covers essential concepts such as shared key usage, tamper detection, and supported hash algorithms like SHA1, SHA256, SM3, and MD5. The content is designed for developers and security engineers working with the CryptoArchitectureKit in the Cangjie programming language. It provides specifications and practical guidance for integrating secure message verification mechanisms into software applications, ensuring compliance with security standards.

### 消息认证码计算_2more.md 消息认证码计算_2more.md

This document serves as a technical reference for calculating Message Authentication Codes (MAC) and Hash-based MAC (HMAC) to ensure message integrity and authenticity. It covers the definitions of MAC and HMAC, explaining how they utilize shared keys to detect information tampering and forgery. A key section details the supported hash algorithms, including SHA1, SHA256, SM3, and MD5, all available in API version 12 and above. The document highlights that HMAC generates fixed-length codes by combining a specified hash algorithm with a shared secret key. Intended for developers and security engineers, this guide provides the necessary specifications for implementing secure message verification in software applications.
