# 相机旋转角度的术语仓颉

This directory focuses on the technical definitions and calculation methods for camera rotation angles in mobile development. It covers the complex relationship between device orientation, gravity sensors, lens installation angles, and screen display directions. Key topics include specific mathematical formulas for image rotation on front and rear cameras, utilizing sensor data, and managing preview alignment mechanisms. This resource is suitable for application developers and engineers working on camera applications who need to ensure correct image orientation and handle device rotation logic programmatically.

## Detailed Description

### 拍照录像角度.md
This technical guide explains how to determine image rotation angles for photography and video recording based on device orientation. It details the mathematical relationship between image rotation, lens installation angle, and gravity direction for both rear and front cameras. Key takeaways include specific formulas where rear camera rotation adds gravity direction to the lens angle, while front camera rotation subtracts it. The document instructs developers to listen to the SensorId.GRAVITY event to retrieve x, y, and z axis data for calculating device rotation. Intended for application developers, this guide ensures correct image orientation handling in camera applications.

### 相机旋转角度的术语仓颉_5more.md
This reference document defines key terminology related to camera rotation angles to help developers understand the framework's adaptation mechanisms. It covers four main concepts: device natural direction, screen display direction, screen rotation angle, and camera lens installation angle. Key takeaways include the definition of screen rotation as the clockwise angle from the natural direction, retrievable via the Display.rotation API. It also explains that rear camera sensors typically have a 90-degree installation angle, while front cameras have 270 degrees, due to sensor orientation and mirroring. This guide is intended for developers working on camera applications who need to handle image orientation and device rotation logic.

### 预览旋转角度/
This directory provides a comprehensive technical overview of the mechanisms required to calculate and adjust image rotation angles during camera preview on mobile devices. It details the critical relationship between hardware-specific factors, such as the lens installation angle, and software variables like screen display compensation. Key topics include the `Display.rotation` API, the specific angular differences between front and rear cameras, and the management of image mirroring. This resource is essential for mobile developers and engineers who need to programmatically handle orientation changes, ensuring that the camera preview aligns correctly with the user's physical perspective regardless of device rotation.
