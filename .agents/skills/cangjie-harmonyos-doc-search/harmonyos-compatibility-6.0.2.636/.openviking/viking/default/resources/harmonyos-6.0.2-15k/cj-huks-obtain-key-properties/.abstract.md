This directory contains essential documentation for software developers working within the OpenHarmony ecosystem who are utilizing the Cangjie programming language. The content specifically addresses the interaction with the Hardware Universal Key Store (HUKS), focusing on the retrieval of properties associated with cryptographic keys that are already stored in the system. By providing a detailed walkthrough of the `getKeyItemProperties` interface, this resource helps developers understand how to query key attributes effectively. It covers the necessary development environment setup, the specific API calls required, and the handling of return results. This guide is particularly suitable for backend or security-focused developers who need to audit or manage persistent keys in their applications. It explicitly excludes lightweight devices, targeting standard OpenHarmony deployments. Key concepts include HUKS integration, Cangjie syntax, key property management, and the Universal Keystore Kit.
