# stdconvert

The `stdconvert` directory provides essential documentation and reference materials for the standard conversion library in the Cangjie programming language ecosystem. It covers the fundamental mechanisms required for transforming data between strings and various types. Key topics include the `Formattable` interface, parsing logic, and radix conversion capabilities. This resource is designed for developers who need to implement precise data formatting, handle complex string parsing, or customize output presentation in their Cangjie applications. It serves as both a quick reference guide and a deep-dive tutorial for mastering type conversion logic.

## Detailed Description

### API_列表.md API_列表.md
This document serves as a reference index listing the core interfaces within a specific API package, focusing on data conversion capabilities. The main section presents a table of three key interfaces: Formattable, Parsable, and RadixConvertible. Key information includes the specific functions of these interfaces: Formattable defines how to convert instances to formatted strings, while Parsable and RadixConvertible handle parsing strings into specific types, with the latter supporting radix conversion. This reference guide is intended for developers seeking to understand or implement type conversion and formatting logic, providing quick access to detailed definitions for these essential components.
