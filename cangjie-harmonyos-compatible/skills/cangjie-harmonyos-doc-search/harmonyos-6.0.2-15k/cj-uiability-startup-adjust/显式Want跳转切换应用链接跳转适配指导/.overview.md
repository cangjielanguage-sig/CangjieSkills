# 显式Want跳转切换应用链接跳转适配指导

This directory provides comprehensive technical guidance for HarmonyOS developers on adapting application navigation mechanisms from explicit Want jumps to App Linking. It details the necessary configurations for `module.json5`, the implementation of the `openLink` interface, and the handling of return results via UIAbility. Key topics include implicit matching rules, domain verification processes, and the utilization of the `OpenLinkOptions` parameter to distinguish between AppLinking and DeepLinking behaviors. These resources are specifically designed for developers utilizing the Cangjie language who require robust solutions for cross-application navigation and data exchange while adhering to API 18 standards. This documentation ensures developers can effectively manage application switching and link handling in a secure and standardized manner.

## Detailed Description

The following documents provide in-depth technical instructions and code examples for implementing and migrating link-based navigation in HarmonyOS applications.

### 启动其他应用的UIAbility并获取返回结果.md 启动其他应用的UIAbility并获取返回结果.md
This technical guide explains how to launch another application's UIAbility using a link and handle the return result. It covers configuring the target application's module.json5 file with specific skills, actions, entities, and URIs, and implementing the caller logic using the openLink interface. Key information includes implicit matching via ohos.want.action.viewData, domain verification settings, and the OpenLinkOptions parameter which controls whether to strictly use AppLinking or fallback to DeepLinking. The document provides a Cangjie code example demonstrating the callback mechanism for AbilityResult. This is intended for HarmonyOS developers needing to implement cross-application navigation and data exchange.
