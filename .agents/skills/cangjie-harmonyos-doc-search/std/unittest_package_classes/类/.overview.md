# 类

This directory provides API reference documentation for the Cangjie language's unit testing framework. It details classes for structuring tests, managing assertions, running benchmarks, and generating reports. Key topics include `TestSuite`, `Benchmark`, data strategies, and reporters like `XmlReporter` and `CsvReporter`. Designed for developers and QA engineers, these documents cover the inheritance hierarchies, method signatures, and functional behaviors necessary to build robust testing infrastructure and property-based testing systems in Cangjie.

## Detailed Description

### class_AssertionCtx.md class_AssertionCtx.md
This API reference details the AssertionCtx class in the Cangjie language, designed to manage state and facilitate the creation of user-defined assertions within a unit testing framework. The content is organized into properties and methods, covering access to argument strings, caller identifiers, and error status. Key functions include `arg` for retrieving parameter values, `fail` for throwing exceptions upon failure, and `failExpect` for logging errors while continuing execution. Additionally, it mentions an internal method `setArgsAliases`.

### class_BenchReport_4more.md class_BenchReport_4more.md
This API documentation defines classes for handling performance test reporting and data processing within the Cangjie unittest framework. It details the BenchReport class for performance results, CartesianProductProcessor for generating test data combinations, and output handlers like ConsoleReporter and TextReporter. Key information includes that BenchReport extends Report to manage benchmark execution results, while CartesianProductProcessor creates tuples from two data strategies. Additionally, ConsoleReporter outputs colored results to the console, whereas TextReporter directs output to a PrettyPrinter instance.

### class_Benchmark.md class_Benchmark.md
This API documentation defines the Benchmark class in Cangjie, designed for creating and executing individual performance test cases. The document outlines the class properties, specifically the name property, and the run method which returns a BenchReport. Key sections include static factory methods for instantiation: `create` for standard tests and `createParameterized` for tests driven by data strategies. These methods allow customization through Configuration and Measurement parameters.

### class_CsvReporter_2more.md class_CsvReporter_2more.md
This API documentation defines two classes, CsvReporter and CsvRawReporter, designed to export performance benchmark results to CSV files in the Cangjie language. The document details the class definitions, their inheritance from the Reporter interface, and their respective constructors. Key information includes that CsvReporter outputs standard performance test results, while CsvRawReporter specifically exports raw measurement values. Both classes require a Path parameter in their constructors to specify the output directory.
