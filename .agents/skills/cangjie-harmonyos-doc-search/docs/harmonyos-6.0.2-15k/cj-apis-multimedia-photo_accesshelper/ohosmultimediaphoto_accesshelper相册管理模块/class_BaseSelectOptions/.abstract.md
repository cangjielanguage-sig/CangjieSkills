This directory contains comprehensive API reference documentation for the `BaseSelectOptions` class within the Cangjie programming language ecosystem. It is specifically designed to assist developers in configuring media selection behaviors for the PhotoAccessHelper system and gallery interfaces. The documentation covers essential aspects such as constructor signatures, system capabilities, and specific version requirements (notably API level 19 and above). Key configuration options detailed here include setting MIME type filters, defining maximum selection counts (ranging from 50 to 500), and toggling feature flags for camera integration, search functionality, and preview modes. This resource is highly suitable for application developers working on file management systems, photo galleries, or any application requiring robust media selection capabilities, providing the technical specifications needed to customize user interactions with image and video assets.
