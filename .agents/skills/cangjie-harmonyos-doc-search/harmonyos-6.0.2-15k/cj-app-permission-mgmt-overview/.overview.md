# cj-app-permission-mgmt-overview

This directory provides a comprehensive overview of the application permission control mechanism within the operating system, focusing on security and privacy. It covers fundamental concepts such as identity management (TokenID), privilege levels (APL), and the Access Control List (ACL). Additionally, it outlines the principles of secure resource access, distinguishing between system_grant and user_grant authorizations. Key topics include permission hierarchies, data protection, and privacy compliance. This documentation is suitable for application developers and system architects seeking to implement secure access control, understand permission classification, and ensure user privacy in their applications. By exploring these materials, users will gain a deep understanding of how to manage permissions effectively, ensuring that applications adhere to strict security standards while respecting user data privacy.
