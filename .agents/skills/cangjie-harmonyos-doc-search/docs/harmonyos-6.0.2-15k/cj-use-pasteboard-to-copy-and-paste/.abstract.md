This directory contains a comprehensive technical guide intended for developers who are implementing copy and paste functionality using the system clipboard in the Cangjie language. It serves as a critical resource for understanding how to effectively utilize the BasicServicesKit to manage clipboard operations within modern applications. The document covers a broad spectrum of essential topics, beginning with scenario introductions that set the context for usage. It provides detailed information on constraint limitations, specifically highlighting the 128MB size limit for data and the privacy permissions that must be granted for secure access. Furthermore, the guide explains the usage of basic data types, such as text and HTML, ensuring developers can handle common formats effectively. It identifies the primary interfaces, `setData` and `getData`, as the core methods for interaction, while also offering specific notes on handling more complex URI data via file management APIs. To facilitate practical understanding, the document includes a code example demonstrating text manipulation. This guide is suitable for application developers looking to integrate robust clipboard capabilities into their projects, ensuring they can build user-friendly applications with efficient data transfer features.
