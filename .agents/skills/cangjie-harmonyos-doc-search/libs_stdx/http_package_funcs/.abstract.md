This directory contains API reference documentation for utility functions within an HTTP package specifically designed for the Cangjie programming language. It focuses on essential server-side operations, including handling request responses, managing specific error codes, and facilitating protocol upgrades such as CONNECT requests. The documentation covers functions for sending specific error responses, managing 404 "Not Found" states, and establishing low-level socket connections for raw data transmission. It is primarily suitable for backend developers implementing HTTP servers who require convenient error handling mechanisms or need direct socket access for advanced protocol implementations. By providing these utilities, the package aims to streamline the development of robust network applications, allowing developers to focus on business logic rather than low-level protocol details. The reference guide ensures that users understand the behavior of functions like `upgrade`, including how it handles headers and potential exceptions, while also offering structural descriptions of the code organization.
