# HTTP数据请求

This directory focuses on HTTP data request implementation within the HarmonyOS and Cangjie development ecosystem. It covers essential network communication topics, including standard API references, step-by-step interface development, streaming data handling, and security mechanisms like Certificate Pinning. Key concepts include the `http` module, `createHttp`, `requestInStream`, SSL configuration, and network security hardening. This resource is suitable for developers working with ArkTS, Cangjie, or HarmonyOS frameworks who need to integrate robust, secure, and efficient network capabilities into their applications.

## Detailed Description

### HTTP数据请求_3more.md HTTP数据请求_3more.md
This document serves as an API reference guide for implementing HTTP data requests in application development. It covers the scenario introduction and detailed interface descriptions provided by the http module. Key information includes the requirement for the ohos.permission.INTERNET permission and a comprehensive list of functions such as createHttp, request, requestInStream, and event subscription methods for headers, data streams, and progress tracking. Intended for developers, this guide explains how to initiate network requests using standard methods like GET and POST.

### request接口开发步骤.md request接口开发步骤.md
This document provides a step-by-step tutorial for developing HTTP request interfaces using the Cangjie NetworkKit. It covers the complete lifecycle of an HTTP request, including object creation, event subscription, request initiation, response parsing, and resource cleanup. Key information includes the usage of createHttp(), request(), and destroy() methods, alongside a detailed Cangjie code example demonstrating configuration options like request methods, headers, timeouts, and SSL certificates. Intended for Cangjie developers, this guide serves as a practical reference for implementing network communication in applications.

### requestInStream接口开发步骤/
This directory serves as a comprehensive resource for developers looking to implement the `requestInStream` interface, focusing on efficient HTTP streaming data handling. It covers the entire development lifecycle, including module imports, object instantiation, event subscription, and resource management. Key topics include the usage of NetworkKit, asynchronous callback mechanisms, and advanced configuration options such as SSL certificates, proxy settings, and multipart form data. Whether working with Cangjie or ArkTS/HarmonyOS, developers will find practical code examples and detailed explanations for building secure, high-performance network clients. This collection is essential for mastering streaming requests and ensuring robust communication in modern applications.

### 证书锁定/
This directory focuses on Certificate Pinning (证书锁定), a critical security mechanism designed to protect mobile applications from Man-in-the-Middle (MitM) attacks by strictly restricting HTTPS connections to specific, trusted certificates. It covers the technical implementation of network security configurations using JSON, specifically tailored for the HarmonyOS framework. Key topics include defining trust anchors, configuring domain rules, and utilizing SHA256 hash algorithms for public key pinning. Additionally, it addresses the operational risks associated with certificate updates. This resource is essential for mobile developers and system administrators aiming to harden application network security and enforce strict trust policies to ensure data integrity.
