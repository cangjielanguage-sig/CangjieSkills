This directory provides technical documentation for the `FuncDecl` class and related Abstract Syntax Tree (AST) manipulation functions within the Cangjie programming language ecosystem. It covers the architecture of function definition nodes, including initialization constructors, mutable properties for managing function components like bodies and parameters, and syntax validation methods. Additionally, it details utility functions for converting AST nodes to tokens and traversing the syntax tree using the Visitor pattern. This documentation is primarily intended for compiler developers, language tool builders, and software engineers implementing custom analysis or transformation tools who require a detailed understanding of Cangjie AST structures and node manipulation techniques.
