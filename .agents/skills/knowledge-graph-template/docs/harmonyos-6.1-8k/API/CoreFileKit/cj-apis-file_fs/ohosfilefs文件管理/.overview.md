# ohosfilefs文件管理

本目录包含仓颉语言中 `ohos.file.fs` 模块的 API 参考文档，专注于 HarmonyOS 应用开发中的文件系统操作。内容涵盖文件读写、目录管理、流式处理、随机访问及文件属性查询等核心功能。文档详细定义了各类配置选项（如打开模式、读写选项）及核心类（如 File、FileIo、Stream）。适用于需要进行底层文件 I/O 操作、数据持久化及文件资源管理的 HarmonyOS 开发者。

### class_OpenMode.md class_OpenMode.md
定义文件打开接口 flags 参数的常量。涵盖读写权限（READ_ONLY）、文件创建与截断（CREATE、TRUNC）、追加写入（APPEND）及非阻塞等特殊模式。

### class_Options_dac03266.md class_Options_dac03266.md
定义文件读取的可选配置 `Options` 类。包含 `encoding` 属性，支持 `readLines` 接口，默认编码为 utf-8。

### class_RandomAcces_3more_3c355512.md class_RandomAcces_3more_3c355512.md

### class_ReadOptions_2more_ff040b9c.md class_ReadOptions_2more_ff040b9c.md
定义 `ReadOptions` 和 `ReadTextOptions` 类，用于配置文件读取参数。支持设置读取偏移量、长度及编码（utf-8），分别用于 `read` 和 `readText` 接口。

### class_WriteOption_4more_2e6ff755.md class_WriteOption_4more_2e6ff755.md
定义文件操作相关的配置类与枚举。包含 `WriteOptions`（设置写入长度、偏移量、编码）及用于校验位置、权限和指针偏移基准的枚举类型。

### ohosfilefs文件管理_4more_dcddc11d.md ohosfilefs文件管理_4more_dcddc11d.md
提供 `ohos.file.fs` 模块的基础 API 参考。涵盖模块导入、应用沙箱路径获取及 `ConflictFiles` 类定义，支持文件目录管理及流式读写。

### class_File/
包含 `File` 类及相关函数的 API 参考。涵盖文件对象属性（描述符、路径）、核心方法（获取父目录、文件加锁）及解锁功能，包含异常处理说明。

### class_FileIo/
包含 `FileIo` 类的 API 参考。涵盖文件系统操作的核心功能，如文件创建、读写、复制、移动、删除、权限检查及目录管理的静态方法。

### class_Filter/
包含 `Filter` 类的 API 参考，用于配置 `listFile` 接口的文件过滤规则。涵盖构造函数及 `suffix`、`displayName`、`fileSizeOver` 等属性及匹配逻辑。

### class_RandomAccessFile/
包含 `RandomAccessFile` 类的 API 参考，指导实现文件的随机读写操作。涵盖核心属性、读取数据、设置文件指针位置及写入数据的方法。

### class_Stat/
包含 `Stat` 类及相关函数的 API 参考。涵盖文件元数据（大小、权限、时间戳）的封装访问，以及识别特定文件类型（如块设备、目录）的布尔函数。

### class_Stream/
包含 `Stream` 类的 API 参考，专注于文件流操作。涵盖从流读取数据到字节数组、将数据写入文件，以及通过 `close()` 和 `flush()` 管理流生命周期的功能。
