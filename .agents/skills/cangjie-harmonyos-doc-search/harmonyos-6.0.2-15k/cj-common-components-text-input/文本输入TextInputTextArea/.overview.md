# 文本输入TextInputTextArea

This directory provides comprehensive documentation for implementing text input functionality using the TextInput and TextArea components within the ArkUI framework and the Cangjie language. It covers the full lifecycle of text input development, from basic component creation and styling to complex event handling and user experience enhancements. Key topics include configuring input types like passwords and emails, managing input events, implementing selection menus, and handling keyboard avoidance. This resource is suitable for developers aiming to build interactive user interfaces such as login pages, search bars, or chat applications.

## Detailed Description

### 文本输入TextInputTextArea_4more.md
This document serves as a usage guide for the TextInput and TextArea components within the ArkUI framework, detailing how to implement text input functionality for user interactions. The main sections cover creating single-line and multi-line input boxes, configuring specific input types such as Normal, Password, and Email via the setType method, and applying custom styles like placeholder text and background colors. Key takeaways include the distinction between TextInput and TextArea regarding line limits and the variety of supported input modes. This guide targets developers using the Cangjie language to build functional pages like login forms or chat interfaces.

### 添加事件.md
This document provides a practical code example for binding event callbacks to a TextInput component using the Cangjie language. It details specific input handling events including onChange for content updates, onSubmit for enter key actions, and onTextSelectionChange for cursor tracking. Additionally, it covers password visibility state synchronization and text editing lifecycle events like onWillInsert and onDidDelete. Important notes highlight that insertion and deletion callbacks are restricted to system input methods. This reference guide is intended for developers seeking to implement robust user input interactions and data processing in their applications.

### 选中菜单_3more.md
This guide explains text input interaction features in Cangjie development, specifically focusing on selection menus, auto-fill, and keyboard avoidance. It covers the text selection menu for TextInput and TextArea, configuring auto-fill types via the contentType property, and implementing keyboard avoidance using scrollable containers. Key information includes that selecting text triggers a menu with Cut, Copy, and Translate, auto-fill supports types like email addresses, and keyboard avoidance requires wrapping components in Scroll, List, or Grid to function correctly during screen rotations. This is intended for Cangjie developers looking to enhance user experience in text input scenarios.
