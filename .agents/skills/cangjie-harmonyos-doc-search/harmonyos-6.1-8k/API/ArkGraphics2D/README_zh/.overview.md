# README_zh

本目录是ArkGraphics2D（方舟2D图形服务）的中文索引文档，旨在为使用仓颉语言进行HarmonyOS或OpenHarmony应用开发的开发者提供核心导航。文档重点涵盖了色彩管理模块的仓颉语言API接口以及相关的错误代码定义，所有相关特性目前均处于Beta阶段，意味着功能仍在持续迭代中。作为连接开发者与底层图形服务的桥梁，该文档提供了通往具体API参考和错误码说明的直达链接，特别适合那些专注于2D图形渲染、图像处理及色彩校正的高级用户查阅和使用，帮助开发者快速定位所需的开发资源。
