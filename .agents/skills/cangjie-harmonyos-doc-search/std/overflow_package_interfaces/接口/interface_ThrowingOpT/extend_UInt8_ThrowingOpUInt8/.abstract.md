This directory contains API reference documentation for the Cangjie language, specifically focusing on the `ThrowingOp` interface implementation for the `UInt8` type. It covers a range of arithmetic and bitwise operations that utilize exception-handling strategies to manage errors such as overflow and overshift. Key topics include functions like `throwingAdd`, `throwingNeg`, `throwingShl`, and `throwingSub`, which are designed to throw specific exceptions rather than wrapping around. This documentation is suitable for Cangjie developers who require safe, checked numeric operations where errors must be explicitly caught to ensure data integrity and robust error handling in low-level programming tasks. By utilizing these APIs, developers can prevent undefined behavior in critical calculations.
