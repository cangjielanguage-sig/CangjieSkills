# stdast

The `stdast` directory serves as the central documentation hub for the Cangjie Abstract Syntax Tree (AST) package, providing critical insights into syntax parsing and macro expansion management. It thoroughly explains the process of converting source code tokens into AST nodes and introduces the "Macro With Context" functionality, which is essential for handling complex nested macro scenarios. The directory also houses a complete API reference that covers serialization, tokenization, error handling, and various compiler operations. This documentation is tailored for software developers, compiler engineers, and students who wish to deepen their understanding of language design, metaprogramming, and the creation of language extensions in the Cangjie ecosystem.

## Detailed Description

### 功能介绍.md 功能介绍.md
This document serves as a feature introduction for the Cangjie ast package, detailing its capabilities in parsing source code and managing macro expansion contexts. It covers two primary areas: the syntax parser that converts tokens into Abstract Syntax Tree (AST) nodes, and the "Macro With Context" functionality designed for handling nested macro scenarios. Key takeaways include specific functions for context checking, such as assertParentContext for validation and insideParentContext for boolean checks, alongside setItem for storing data, with strict usage constraints requiring direct calls. This reference guide targets developers working with Cangjie macros and AST manipulation who need to understand parsing mechanisms and context validation within nested macro environments.
