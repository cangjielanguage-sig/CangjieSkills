This directory contains comprehensive API documentation and code examples for the `ohos.prompt_action` module in the HarmonyOS Cangjie environment. It covers the implementation of various UI popups, including text prompts (toasts), standard dialogs, action menus, and custom dialogs. Key topics include configuration classes like `ActionMenuOptions`, `ButtonInfo`, and `ShowDialogOptions`, as well as enumerations for styling and behavior. The documentation is strictly for pure Cangjie development scenarios and is intended for HarmonyOS developers and UI engineers seeking to implement interactive user feedback mechanisms and modal interfaces within the ArkUI framework.
