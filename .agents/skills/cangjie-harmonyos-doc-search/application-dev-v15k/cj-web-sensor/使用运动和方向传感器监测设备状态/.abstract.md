This directory provides a comprehensive guide on monitoring device status using motion and orientation sensors within the HarmonyOS environment. It details the implementation of W3C standard interfaces, such as Accelerometer and Gyroscope, to capture data like acceleration and angular velocity. The content covers essential configuration steps, including mandatory permission declarations in `module.json5` and the setup of the `onPermissionRequest` interface. Additionally, it explores the integration of native code with web components using the Cangjie language. This resource is ideal for developers creating interactive web applications, fitness tracking tools, or motion-controlled games that rely on precise hardware sensor data.
