This directory focuses on the classification, management, and access of resources within the HarmonyOS/Cangjie development environment. It covers the distinction between application and system resources, directory creation conventions, resource matching rules for different device states, and the syntax for accessing these resources programmatically. Key topics include localization, device adaptation, resource qualifiers, and the `cj_res_entry` mapping mechanism. It is suitable for developers and system integrators looking to optimize application performance and ensure visual consistency across various devices and configurations.
