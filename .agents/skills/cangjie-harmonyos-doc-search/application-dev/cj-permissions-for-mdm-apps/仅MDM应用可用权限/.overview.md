# 仅MDM应用可用权限

This directory provides comprehensive reference documentation for permissions exclusively available to Mobile Device Management (MDM) and enterprise applications within the OpenHarmony and HarmonyOS environments. It details system-level authorizations required for advanced device administration, including network control, application management, security policies, and system settings modifications. Key topics include system_grant authorization levels, ACL enablement, API version 12 requirements, and specific manual configuration protocols for signing. This resource is essential for system developers and enterprise integrators aiming to implement robust administrative controls and security policies on managed devices.

## Detailed Description

### ohospermissionENTERPRISE_A_9more.md
This reference document defines specific OpenHarmony permissions required for enterprise device management capabilities. It details permissions for managing device admin apps, recovery keys, delegated policies, and various device restrictions such as APN, telephony, Kiosk mode, and wallpaper settings. Key information includes permission levels ranging from system_basic to system_core, system_grant authorization, and API version requirements spanning from version 12 to 20. Most recent permissions specifically target Phone and Tablet devices. This document is intended for system developers and enterprise application integrators who need to configure security policies and administrative controls within the OpenHarmony operating system.

### ohospermissionENTERPRISE__17more.md
This document serves as a reference list for OpenHarmony permissions specifically designed for enterprise device management capabilities. It details seventeen distinct permissions, categorized by function such as certificate management, system settings, network control (Wi-Fi/Bluetooth), application management, and device operations like rebooting or locking. Key information indicates that all permissions require system authorization and ACL enablement, with most classified as system_basic level, though installation permissions are system_core. These features are available starting from API version 12. This reference targets system developers and enterprise application creators who need to implement device administration policies and security controls on OpenHarmony devices.

### 仅MDM应用可用权限_16more.md
This reference document outlines specific permissions exclusively available to Mobile Device Management (MDM) applications on HarmonyOS. It details 15 enterprise-level permissions, including device info retrieval, network management, app installation policies, factory resets, and system time settings. Key information indicates that all permissions are system-granted, primarily at the system_basic level, and require API version 12. Crucially, these permissions do not support automatic signing and require manual configuration during debugging and release. This guide targets HarmonyOS developers building device management solutions who need to implement administrative controls over enterprise devices.
