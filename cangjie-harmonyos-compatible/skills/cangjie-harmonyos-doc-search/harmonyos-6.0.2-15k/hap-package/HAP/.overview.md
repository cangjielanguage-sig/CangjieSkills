# HAP

This directory serves as a comprehensive technical resource for understanding and managing the Harmony Ability Package (HAP), the fundamental unit for HarmonyOS application installation, execution, and distribution. It thoroughly covers the architectural definition of HAPs, distinguishing between entry and feature types, and outlines best practices for single versus multi-HAP configurations to optimize resource loading. Furthermore, the directory provides practical guidance on the application lifecycle, including detailed procedures for debugging, installing, and updating packages using DevEco Studio and command-line tools like hdc and bm. Key topics include bundle naming conventions, signing certificate consistency, HAR references, and deployment commands. This content is specifically tailored for HarmonyOS developers, particularly those utilizing the Cangjie language, who need to efficiently structure, package, and debug their applications within the HarmonyOS ecosystem. It addresses specific constraints regarding configuration and signing, ensuring developers adhere to strict requirements for consistent bundle names across modules.

## Detailed Description

The following files provide in-depth technical specifications and operational guides for HAP management:

### HAP_5more.md HAP_5more.md
This technical guide defines the Harmony Ability Package (HAP), the fundamental unit for HarmonyOS application installation and execution. It covers HAP types (entry and feature), usage scenarios (single vs. multi-HAP), specific constraints regarding configuration and signing, and a step-by-step creation tutorial using DevEco Studio. Key takeaways include the recommendation for single HAP structures to optimize resource loading, strict requirements for consistent bundle names and signing certificates across modules, and support for HAR references. Targeted at HarmonyOS developers using the Cangjie language, this document serves as a reference for structuring and packaging applications efficiently.

### 调试.md 调试.md
This technical guide outlines procedures for debugging HarmonyOS applications using HAP packages generated by DevEco Studio. It covers two primary debugging methods: utilizing the DevEco Studio IDE and employing the command-line hdc tool. The hdc section details installation and uninstallation processes using both direct hdc commands and the bm tool via hdc shell. The document provides specific command examples for installing, updating, and uninstalling HAPs on Windows and device environments, referencing tools like hdc and bm. Targeted at HarmonyOS developers, this guide assumes familiarity with the development environment and command-line interfaces for application deployment and debugging.
