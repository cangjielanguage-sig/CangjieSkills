This directory serves as a comprehensive resource for the `cj-apis-telephony_call` module, specifically tailored for the Cangjie programming language environment. It focuses on the `ohos.telephony_call` module and the `TelephonyKit` framework, providing essential documentation for developers working within the HarmonyOS ecosystem. The content covers a wide range of telephony operations, including initiating calls, monitoring call states, formatting phone numbers, and managing emergency calls. Key data structures such as `NumberFormatOptions` and `CallState` are detailed alongside practical implementation examples. This documentation is ideal for Cangjie developers who need to integrate robust telephony features, manage system permissions, and handle call-related exceptions effectively in their applications.
