This directory serves as a comprehensive guide to state management within the Cangjie declarative UI framework. It explores the core principles of how state changes drive UI rendering, distinguishing between state variables and regular variables. The content covers essential component-level decorators like @State, @Prop, and @Link, alongside application-level solutions such as AppStorage and LocalStorage. It also addresses data synchronization patterns, initialization methods, and nested object observation. This resource is designed for developers seeking to implement efficient data-UI linkage and build dynamic, responsive interfaces in Cangjie applications.
