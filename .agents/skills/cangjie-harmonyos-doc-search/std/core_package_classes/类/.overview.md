### class_ArrayIteratorT.md class_ArrayIteratorT.md
This document provides API reference documentation for the ArrayIterator class in the Cangjie programming language, designed to facilitate sequential traversal of array elements. Key sections explain the next() function, which returns elements wrapped in an Option type, returning None when the iteration concludes. A practical code example demonstrates how to manually iterate through an array using a while-loop and handle the Option return value. This guide targets Cangjie developers seeking to understand or implement array iteration patterns, requiring familiarity with generics, arrays, and the Option enum.

### class_FutureT.md class_FutureT.md
This document provides API reference documentation for the Future class in the Cangjie programming language, detailing how to manage asynchronous thread tasks spawned via the spawn expression. It covers the thread property and key methods including cancel, get, get(timeout), and tryGet. Key takeaways include understanding that cancel sends a cooperative request rather than forcing a stop, get blocks the current thread until completion or timeout, and tryGet allows non-blocking result retrieval returning an Option type. This reference is intended for Cangjie developers implementing concurrent programming who need to control thread execution and retrieve computation results.

### class_Thread.md class_Thread.md
This document serves as API reference documentation for the Cangjie programming language's Thread class, detailing thread management and exception handling capabilities. This reference is intended for developers working with concurrency in Cangjie who need to control thread execution and manage error states.

### class_ThreadLocalT.md class_ThreadLocalT.md
This document serves as API reference documentation for the Cangjie programming language's ThreadLocal class, which manages thread-local variables. It covers the class definition, the get() method for retrieving values, and the set() method for modifying values. The core concept is that each thread maintains an independent copy of the variable, ensuring isolation from other threads. The get() method returns the value or None, while set() accepts a nullable value to update or delete the variable's content. This guide targets Cangjie developers implementing concurrent programming who need to manage thread-specific data safely.
