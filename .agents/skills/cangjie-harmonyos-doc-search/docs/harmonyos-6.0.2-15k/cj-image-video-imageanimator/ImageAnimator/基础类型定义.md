## 基础类型定义

### class ImageFrameInfo

```cangjie
public class ImageFrameInfo {
    public init(
        src!: String,
        duration!: Int32 = 0,
        width!: Length = 0.vp,
        height!: Length = 0.vp,
        top!: Length = 0.vp,
        left!: Length = 0.vp
    )
    public init(
        src!: AppResource,
        duration!: Int32 = 0,
        width!: Length = 0.vp,
        height!: Length = 0.vp,
        top!: Length = 0.vp,
        left!: Length = 0.vp
    )
}
```

**功能：** 图片帧信息，包含图片路径、图片大小、图片位置和图片播放时长信息。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

#### init(String, Int32, Length, Length, Length, Length)

```cangjie
public init(
    src!: String,
    duration!: Int32 = 0,
    width!: Length = 0.vp,
    height!: Length = 0.vp,
    top!: Length = 0.vp,
    left!: Length = 0.vp
)
```

**功能：** 构造一个ImageFrameInfo类型的对象。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|src|String|是|-| **命名参数。** 图片路径，图片格式为jpg、jpeg、svg、png、bmp、webp、ico和heif。|
|duration|Int32|否|0| **命名参数。** 每一帧图片的播放时长，单位毫秒。|
|width|[Length](./cj-common-types.md#interface-length)|否|0.vp| **命名参数。** 图片宽度。|
|height|[Length](./cj-common-types.md#interface-length)|否|0.vp| **命名参数。** 图片高度。|
|top|[Length](./cj-common-types.md#interface-length)|否|0.vp| **命名参数。** 图片相对于组件左上角的纵向坐标。|
|left|[Length](./cj-common-types.md#interface-length)|否|0.vp| **命名参数。** 图片相对于组件左上角的横向坐标。|
