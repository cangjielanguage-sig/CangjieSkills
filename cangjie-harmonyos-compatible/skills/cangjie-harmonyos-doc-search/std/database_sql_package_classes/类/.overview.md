# 类

This directory contains API reference documentation for core database classes in the Cangjie programming language. It covers database driver management, connection pooling, and a wide array of SQL data type wrappers. A significant portion of the documents detail deprecated classes that map SQL types to native Cangjie types, providing guidance for developers maintaining legacy code. Additionally, it includes configuration options for secure database connections. This documentation is intended for software developers and system architects who need to manage database drivers, optimize connection performance, and handle data type conversions in Cangjie applications.

## Detailed Description

### class_DriverManager.md class_DriverManager.md
This API reference details the DriverManager class, which manages database driver instances at runtime. It covers four primary static methods: register, deregister, getDriver, and drivers. Key information includes that all methods are thread-safe, register throws a SqlException for duplicate names, and getDriver returns an Option type. It explains how to map driver names to instances and retrieve sorted lists of available drivers, intended for developers integrating database functionality who need to handle driver lifecycle and concurrency safely.

### class_PooledDatasource.md class_PooledDatasource.md

It details the constructor, mutable properties for pool configuration (maxSize, connectionTimeout, idleTimeout), and operational methods like connect(), close(), and setOption(). Key information includes inheritance from Datasource and specific behaviors for managing connection lifecycles, health checks, and resource limits. This is intended for developers building database applications requiring efficient connection management and performance optimization.
