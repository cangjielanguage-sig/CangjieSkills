# 组件属性

This directory serves as a comprehensive resource for API reference documentation regarding component properties within the ArkUI framework, specifically designed for the Cangjie programming language. It focuses extensively on the styling and configuration of menu items, providing developers with the necessary functions to manipulate typography, such as font size, weight, style, and family, as well as text color settings for both content and labels. Furthermore, it covers the management of selection states and the visual representation of selected items through icons. These guides are intended for UI developers and system engineers seeking to programmatically enhance the visual presentation and interactivity of their applications, ensuring compatibility with system version 22 or later.

## Detailed Description

The following files provide specific API details and parameter configurations for the component properties discussed above.

### func_contentFontLength_Fon_5more.md func_contentFontLength_Fon_5more.md
This document serves as API reference documentation for styling menu items within the ArkUI framework using the Cangjie language. It details five primary functions: contentFont and labelFont for defining font styles including size, weight, family, and style; contentFontColor and labelFontColor for setting text colors; and selected for managing the selection state. Key takeaways include the use of optional parameters with specific defaults like "HarmonyOS Sans" and 16.vp, as well as method chaining support via the return type This. These APIs are available starting from system version 22. The intended audience is UI developers seeking to programmatically customize the visual presentation and interaction states of menu components.

### func_selectIconBool_2more.md func_selectIconBool_2more.md
This API reference document details the selectIcon function used to configure the display of icons for selected menu items in ArkUI applications. The content covers two function overloads: one accepting a boolean value to toggle visibility and another accepting a resource string to specify a custom icon. Key information includes parameter definitions, default values (false for boolean, empty string for resource), system capabilities, and the requirement of version 22 or later. This guide targets Cangjie developers implementing UI components who need to customize the visual feedback of selected states.
