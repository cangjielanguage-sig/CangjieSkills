# cj-apis-bundle_manager

This directory serves as the definitive resource for API reference documentation related to the HarmonyOS BundleManager framework, specifically curated for developers using the Cangjie programming language. It acts as a comprehensive technical guide for managing the entire lifecycle and configuration of applications within the HarmonyOS environment. The content provided herein is critical for understanding how to programmatically interact with the operating system's core services effectively. It covers a wide range of essential development tasks, including the management of application bundles, the querying of detailed component information, the handling of system-level permissions, and the configuration of application metadata. By providing access to detailed definitions for classes, structs, and enums, this documentation enables developers to build robust applications that can seamlessly integrate with the system. It is specifically designed for Cangjie developers who require precise control over application behaviors, such as setting default applications, managing routing tables, and handling complex module dependencies. This directory ensures that developers have the necessary tools to create stable, efficient, and secure software for the HarmonyOS ecosystem.
