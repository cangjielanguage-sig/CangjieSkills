# class_PrimitiveTypeInfo

This directory contains comprehensive API reference documentation for the `PrimitiveTypeInfo` class within the Cangjie programming language's reflection framework. It focuses on the mechanisms used to describe and inspect primitive data types, such as integers, floats, and booleans, at runtime. The documentation covers the class structure, its inheritance hierarchy from `TypeInfo`, and various static methods for retrieving type metadata. Key topics include handling qualified type names, managing exceptions like `InfoNotFoundException`, and distinguishing between static and runtime types. This resource is essential for Cangjie developers looking to implement dynamic type inspection, reflection-based utilities, or generic programming patterns that require detailed type information.
