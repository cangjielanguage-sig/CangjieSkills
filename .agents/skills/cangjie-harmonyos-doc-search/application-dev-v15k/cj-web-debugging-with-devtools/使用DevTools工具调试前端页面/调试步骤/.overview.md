# 调试步骤

This directory provides a comprehensive technical guide for debugging HarmonyOS applications, specifically focusing on web components (ArkWeb) developed using the Cangjie language. It covers the essential workflow required to enable remote inspection via Chrome DevTools, starting from the initial application configuration to the final network setup. Key topics include invoking the `setWebDebuggingAccess` API, managing the `ohos.permission.INTERNET` permission, and establishing USB debugging connections. The guides also detail the use of `hdc` command-line tools for shell access and port forwarding, which are critical for bridging the device with the development environment. These resources are designed for HarmonyOS developers who need to troubleshoot web functionality and are comfortable with system-level configurations and command-line operations.

## Detailed Description

### 应用代码开启Web调试开关_2more.md 应用代码开启Web调试开关_2more.md
This technical guide instructs developers on enabling web debugging for HarmonyOS applications using the Cangjie language. The document covers two primary steps: configuring the application code and connecting the device. Key actions include calling the setWebDebuggingAccess API, declaring the ohos.permission.INTERNET permission in module.json5, and enabling USB debugging on the device. It also details using hdc commands to verify the connection and access the shell. This tutorial is essential for developers preparing to debug web components within their apps using DevTools.

### 端口转发_4more.md 端口转发_4more.md
This technical guide instructs developers on establishing port forwarding to enable Chrome DevTools debugging for ArkWeb applications. The document details querying the device's domain socket, forwarding it to a local TCP port using hdc commands, and configuring Chrome browser settings to discover targets. Key takeaways include identifying the specific process ID for the domain socket and forwarding it to local port 9222, noting that the process ID is dynamic and requires re-forwarding if the application restarts. This tutorial targets HarmonyOS developers needing to debug web components who are familiar with command-line tools and Chrome DevTools.
