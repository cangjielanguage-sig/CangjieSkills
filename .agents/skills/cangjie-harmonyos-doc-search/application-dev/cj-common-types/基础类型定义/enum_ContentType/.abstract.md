This directory contains API reference documentation for the `ContentType` enum within the Cangjie language, specifically tailored for the ArkUI framework. It comprehensively covers the definition and implementation of specific data types that enable contextual autofill capabilities, ranging from contact details like phone numbers and email addresses to sensitive information such as bank cards and credentials. The documentation outlines system capabilities, version requirements (starting from API version 22), and operator overloads necessary for comparing content types. This resource is essential for ArkUI developers and software engineers aiming to optimize user experience by implementing robust form input, automatic saving, and intelligent autofill features in their Cangjie-based applications.
