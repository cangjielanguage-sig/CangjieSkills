# 处理音频焦点变化

This directory provides comprehensive technical guidance for developers on managing audio focus changes within applications. It covers the system's audio focus strategy, which automatically handles stream conflicts, and details how to use the InterruptEvent API to respond to these changes. Key topics include monitoring audio focus events across different development methods like AVPlayer, AudioRenderer, and AudioCapturer, as well as understanding critical parameters such as InterruptForceType and InterruptHint. This resource is suitable for audio application developers who need to ensure state consistency and a seamless user experience when integrating audio playback or recording features.

### 使用不同方式开发时如何监听音频焦点事件.md 使用不同方式开发时如何监听音频焦点事件.md
This guide explains how to monitor and handle audio focus events across different audio development methods. It covers implementation for AVPlayer, AudioRenderer, and AudioCapturer, detailing the specific on callback interfaces required to listen for InterruptEvent. Key information includes analyzing two critical parameters within the event: InterruptForceType, which distinguishes between system-forced and app-controlled actions, and InterruptHint, which indicates specific state changes like resume, pause, stop, or ducking. Intended for audio application developers, this document ensures proper handling of interruptions to maintain system consistency and user experience.
