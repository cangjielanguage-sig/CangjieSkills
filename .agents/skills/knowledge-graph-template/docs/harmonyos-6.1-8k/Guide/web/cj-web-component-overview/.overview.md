# cj-web-component-overview

本目录提供了关于ArkWeb组件的全面概览文档，旨在帮助开发者深入理解该组件的技术细节与应用价值。文档内容涵盖了ArkWeb组件的基本定义、适用场景、核心功能能力以及相关的使用约束。它详细阐述了在应用集成、浏览器构建及小程序开发等不同场景下的应用方式，并深入解析了基于Chromium M114内核的页面加载机制、生命周期管理、交互逻辑、安全策略及维测能力。核心知识点包括JS交互支持、无痕模式、广告拦截及同层渲染技术。该文档主要面向需要在应用中嵌入Web内容，或计划开发浏览器及小程序的专业开发者。

## Detailed Description

### cj-web-component-overview.md
本文档介绍ArkWeb组件，概述其定义、场景、能力及约束。涵盖应用集成、浏览器及小程序场景，详述页面加载、生命周期、交互、安全及维测能力。核心信息包括基于Chromium M114内核，支持JS交互、无痕模式、广告拦截及同层渲染。适用于需嵌入Web内容或构建浏览器/小程序的开发者。
