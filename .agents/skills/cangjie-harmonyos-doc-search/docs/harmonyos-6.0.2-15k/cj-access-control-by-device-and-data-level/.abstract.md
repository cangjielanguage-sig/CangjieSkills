This directory serves as a comprehensive technical resource for developers working within the ArkData framework, specifically focusing on the implementation of granular access control mechanisms using the Cangjie programming language. The core subject matter revolves around a dual-layered security approach: classifying devices and grading data. It details the specific security level standards, ranging from S1 to S4 for data sensitivity and SL1 to SL5 for device trust levels. The content provides practical, step-by-step tutorials for applying these classifications to different storage backends, including both relational and key-value databases. Furthermore, it addresses complex scenarios such as cross-device synchronization rules and data protection policies to prevent unauthorized data leakage. This resource is primarily designed for Cangjie developers and system architects who are building distributed applications and require robust security measures to ensure that sensitive data is synchronized exclusively with compliant, authorized devices.
