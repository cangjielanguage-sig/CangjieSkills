This directory serves as a comprehensive and practical guide for developers who are new to the Cangjie unit testing framework or looking to formalize their testing practices. It provides a step-by-step tutorial that covers the essential aspects of creating, compiling, and managing unit tests within the Cangjie ecosystem. The content focuses heavily on the practical application of the `@Test` and `@Expect` macros, which are fundamental for defining test logic and assertions. It also offers a deep dive into the build process, specifically detailing how to use the `cjc` compiler with the `--test` flag to generate test executables. For developers working on complex systems, the guide explains how to leverage the `cjpm` package manager to handle dependencies and organize test suites effectively. Additionally, it establishes important coding standards, such as the `_test.cj` file naming convention, and provides clear instructions on how to analyze and interpret test results to ensure code correctness. This resource is ideally suited for Cangjie developers who are committed to improving code quality and reliability through rigorous automated testing, making it an indispensable tool for modern Cangjie development and ensuring long-term project maintainability.
