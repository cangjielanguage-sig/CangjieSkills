This directory contains API reference documentation for the HarmonyOS `ohos.bluetooth.connection` module, specifically designed for the Cangjie programming language. It covers comprehensive Bluetooth connectivity features, including device discovery, pairing management, state monitoring, and battery information retrieval. Key components include enums for transport types and bond states, classes for device parameters, and functions for handling asynchronous callbacks and connection operations. This resource is suitable for software developers and system engineers building Bluetooth-enabled applications on HarmonyOS, providing the necessary definitions and code examples to implement robust wireless communication protocols.
