## 详细描述

### basic.md
本文档旨在介绍仓颉编程语言的核心特性，帮助开发者了解其设计理念与应用价值。主要涵盖多后端支持、简明语法、多范式编程、类型与内存安全、高效并发、生态兼容、领域扩展、UI开发及内置库功能。仓颉是兼顾开发效率与运行性能的通用语言，支持CJNative和CJVM后端，具备静态强类型、自动内存管理、轻量化线程及元编程等特性。适用于全场景应用开发者，作为语言入门概览。
