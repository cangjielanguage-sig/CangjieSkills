# cj-app-permissions

This directory provides a comprehensive reference for developers regarding the complex landscape of application permissions and authorization protocols. It serves as a critical resource for identifying the correct permissions required based on an application's scope and intended distribution method. The content thoroughly categorizes permissions into four distinct groups: open permissions with system authorization, open permissions requiring user authorization, permissions specifically for enterprise apps, and those exclusive to MDM (Mobile Device Management) applications. Additionally, it clarifies the technical differences in authorization methods, ranging from automatic grants during installation to dynamic runtime requests via user popups. This documentation is specifically designed for application developers who need to determine the precise permission application process to ensure compliance and functionality for their specific app type.
