# class_Directory

This directory provides comprehensive API reference documentation for the `Directory` class in the Cangjie programming language, specifically designed for file system directory management. It details essential functionalities such as creating directories (including recursive and temporary generation), defining illegal path constraints, and handling various exceptions like `FSException` and `IllegalArgumentException`. Furthermore, it covers static methods for inspecting directory states, retrieving content arrays, and performing non-recursive traversals using callbacks. This documentation is intended for Cangjie developers seeking to implement robust directory manipulation, validation, and enumeration logic within their applications.

### static_func_isEmptyPath_4more.md
This API reference document details static functions for directory inspection and content retrieval within a file system package. It covers overloaded versions of isEmpty and readFrom functions, accepting either Path or String arguments. Key information includes that isEmpty returns a boolean indicating if a directory is empty, while readFrom returns an array of FileInfo objects representing directory contents. Both functions throw FSException for system errors or IllegalArgumentException for invalid inputs. This guide targets Cangjie developers needing to validate directory states or enumerate files.

### static_func_walkPath_FileI_2more.md
This API reference document details the overloaded `walk` static functions for non-recursive directory traversal in the Cangjie file system package. It covers two function signatures accepting either a `Path` or `String` object, parameter definitions, and exception handling. The functions execute a callback `(FileInfo)->Bool` for each directory entry, stopping if the callback returns `false`. Exceptions are thrown for invalid paths, non-directory inputs, or access failures. This documentation is intended for Cangjie developers implementing file system operations who need to iterate over directory contents.
