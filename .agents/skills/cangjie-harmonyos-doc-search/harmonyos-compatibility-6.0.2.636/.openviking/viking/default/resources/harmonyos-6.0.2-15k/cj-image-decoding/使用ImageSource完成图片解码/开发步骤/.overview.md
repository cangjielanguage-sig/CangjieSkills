# 开发步骤

This directory provides a comprehensive set of development guides focused on image decoding and processing using the Cangjie language and the ImageKit framework. It details the essential steps required to integrate image handling capabilities into applications, starting from the initial setup and module imports to the actual decoding of image data. The documentation covers critical aspects such as acquiring image data via sandbox paths or resource managers, creating ImageSource instances, and configuring decoding options for various formats including HDR. These resources are specifically tailored for application developers who possess a working knowledge of Cangjie syntax and application context handling, aiming to facilitate efficient image loading and manipulation within their software projects.

## Detailed Description

The following documents outline the specific procedures and code examples for the development process.

### 开发步骤_1.md
This document serves as a development guide for implementing image decoding using the Cangjie language and ImageKit. It outlines a three-step process: importing the Image module, acquiring image data through various methods like sandbox paths, file descriptors, or resource managers, and creating an ImageSource instance. Key takeaways include specific code snippets for handling file I/O and resource management using modules like CoreFileKit and LocalizationKit. The guide targets application developers who need to load and process images within their apps, requiring knowledge of the Cangjie syntax and application context handling.

### 开发步骤_2.md
This technical tutorial guides developers through creating ImageSource objects and decoding them into PixelMap images using the Cangjie language. The content covers methods to instantiate ImageSource from buffers or file descriptors, configuring DecodingOptions for standard and HDR formats, and performing resource cleanup. Key takeaways include using ResourceManager for media content, enabling HDR decoding via DecodingDynamicRange.AUTO, and manually releasing PixelMap and ImageSource objects to manage memory. Intended for Cangjie developers, this guide assumes familiarity with UIAbilityContext and basic image processing concepts.
