# 性能分析工具

本目录主要介绍仓颉语言的性能分析工具 cjprof，旨在帮助开发者对应用程序进行性能调优和问题排查。内容涵盖 CPU 热点函数采样、性能数据导出、统计报告与火焰图生成，以及堆内存的导出与分析。核心关键词包括 cjprof、性能分析、CPU 采样、内存泄漏排查。该文档适用于需要在 Linux 环境下进行仓颉应用性能优化的开发者及运维人员。
