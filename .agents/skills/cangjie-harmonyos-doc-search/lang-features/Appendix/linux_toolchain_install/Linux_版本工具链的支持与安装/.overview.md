## 详细描述

### Linux_版本工具链的支持与安装_2more_bc5f0045.md Linux_版本工具链的支持与安装_2more_bc5f0045.md
本文档是一份安装指南，旨在指导用户在 Linux 系统上安装仓颉工具链及其依赖项。文档主要列出了经过完整功能测试的 Linux 发行版，包括 Ubuntu 18.04/20.04、UnionTech OS Server 20 和 Kylin Linux Advanced Server V10，并针对每个版本提供了具体的依赖安装命令。关键信息指出，所有系统均需安装 binutils、C/C++ 开发库及 GCC，且必须额外安装 OpenSSL 3，若默认源无法提供需参考编译文档。本文档面向需要在特定 Linux 环境下配置仓颉开发环境的开发人员，关键词包括仓颉、工具链、Linux 安装、依赖管理和 OpenSSL。

### 编译安装依赖工具.md 编译安装依赖工具.md
本文档是一份操作指南，旨在指导用户通过源码编译安装 OpenSSL 3，以满足仓颉工具链的依赖需求。文档主要涵盖了 OpenSSL 3 的下载、解压、配置、编译、测试及安装步骤，以及后续的环境变量配置方法。关键信息包括建议使用 3.0.7 或更高版本，重点强调了使用 `--prefix` 防止覆盖系统 OpenSSL，并详细说明了如何设置 `LIBRARY_PATH` 和 `LD_LIBRARY_PATH` 以使工具链找到自定义安装的库。目标受众为仓颉语言开发者，特别是系统包管理器未提供 OpenSSL 3 的用户。
