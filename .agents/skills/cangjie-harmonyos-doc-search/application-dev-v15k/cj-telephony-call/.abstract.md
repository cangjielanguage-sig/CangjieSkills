This directory provides a technical overview and implementation guide for developers working with the Cangjie TelephonyKit to integrate phone call functionality into third-party applications. It serves as a comprehensive resource for understanding how to interact with the system's telephony services, specifically focusing on voice calling capabilities. The content covers critical aspects such as verifying device support using the `hasVoiceCapability` API, initiating calls through the `makeCall` interface to launch the system dialer, and monitoring call lifecycle events via the observer module. Developers will find detailed explanations of call states like IDLE and RINGING, along with necessary prerequisites such as SIM card availability and standard system compliance. The guide includes step-by-step tutorials and Cangjie code examples to facilitate easy integration. This documentation is primarily suitable for application developers and software engineers looking to add reliable, system-integrated communication features to their Cangjie-based projects, ensuring a seamless user experience for voice interactions.
