# cj-universal-event-click

本目录提供了关于 ArkUI 框架中通用点击事件处理的 API 参考文档，专门针对使用仓颉语言进行开发的场景。文档内容涵盖了模块导入指令、`onClick` 函数的详细定义及其参数说明。核心知识点包括如何使用可选的 `ClickEvent` 回调函数来定义点击后的行为，以及利用返回的通用接口类型 `T` 实现链式调用。此外，文档还明确了相关的系统能力要求和起始版本信息。该文档主要面向 ArkUI 应用开发者，旨在帮助他们掌握组件点击事件的处理机制，从而实现丰富且流畅的用户交互功能。
