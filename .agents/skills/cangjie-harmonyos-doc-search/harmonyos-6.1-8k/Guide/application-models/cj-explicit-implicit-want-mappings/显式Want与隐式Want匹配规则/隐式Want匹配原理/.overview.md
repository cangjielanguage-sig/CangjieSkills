# 隐式Want匹配原理

本目录深入解析了鸿蒙系统中隐式Want的匹配机制，详细阐述了Want参数与目标应用组件Skills配置之间的核心匹配规则。内容涵盖了Action、Entities、URI、Type及linkFeature的匹配逻辑、优先级顺序以及不同输入场景下的判定条件。通过这些文档，开发者可以掌握系统如何根据调用参数筛选目标组件，理解最左匹配原则及组合匹配策略。适用于需要掌握鸿蒙应用组件隐式调用、Skills配置及AbilityKit框架的开发者。

### want参数的uri和type匹配规则.md want参数的uri和type匹配规则.md
