# 常用命令

This directory contains a comprehensive set of reference guides for the `hidumper` command-line tool used in OpenHarmony systems. It covers a wide range of functionalities, from basic system information retrieval and service debugging to advanced performance monitoring and memory analysis. Key topics include inspecting system abilities, analyzing network and CPU statistics, managing window and graphics services, and performing deep dives into process memory and JavaScript heap dumps. These documents are essential resources for system developers, QA engineers, and administrators who need to diagnose issues, monitor system health, or optimize performance on OpenHarmony devices.

## Detailed Description

### 常用命令_1.md 常用命令_1.md
This document serves as a command-line reference guide for the hidumper tool, used for debugging and monitoring OpenHarmony systems. It details commands to view help, list system information clusters, and enumerate system abilities. Key sections cover retrieving detailed information for specific clusters like "base" and "system" using the -c flag, and accessing data for specific system abilities using the -s flag. The guide provides usage examples and output samples for each command. It is intended for developers and system administrators needing to inspect system state, process information, and service capabilities.

### 常用命令_2.md 常用命令_2.md
This document serves as a technical reference guide for using the hidumper command-line tool to inspect and debug system services. It covers commands for WindowManagerService (window info), RenderService (graphics, FPS, memory), PowerManagerService (screen timeout), and Faultlog (crash history). Key takeaways include specific syntax for dumping window data, monitoring surface frame rates, managing screen auto-sleep settings, and retrieving system crash logs. Intended for system developers or QA engineers with knowledge of command-line interfaces for debugging and performance monitoring.

### 常用命令_3.md 常用命令_3.md
This document serves as a technical reference guide for the hidumper command-line tool in OpenHarmony, detailing specific system diagnostic commands. It covers retrieving network traffic, storage I/O statistics, process and thread lists, CPU usage rates, CPU frequency, and memory information. Each section provides command syntax and sample output. Crucially, it notes that process information export is restricted to debug applications in release versions, offering methods to distinguish build types. Targeted at developers and system administrators, this guide facilitates system monitoring and debugging. Keywords: hidumper, OpenHarmony, system diagnostics, network, storage, CPU, memory, debugging.

### 常用命令_4.md 常用命令_4.md
This reference guide documents advanced usage of the hidumper command-line tool for system diagnostics. It covers three primary functions: analyzing process memory usage, exporting logs to compressed zip files, and monitoring Inter-Process Communication (IPC) statistics. Key information includes detailed explanations of memory metrics like Pss, Vss, and Heap, as well as methods to track IPC time costs and call counts for specific or all processes. The document provides syntax examples and output interpretations for commands like --mem, --zip, and --ipc. Intended for system developers or engineers, this guide assists in debugging performance issues and resource management on the target operating system.

### 常用命令_5.md 常用命令_5.md
This reference document details the usage of memory analysis commands for the hidumper tool. It focuses on two specific functions: exporting detailed process memory statistics using --mem-smaps and managing JavaScript heap snapshots and garbage collection using --mem-jsheap. Key takeaways include the restriction of these commands to debug versions of the system, with the JS heap command offering options to trigger GC, dump snapshots, or list leaked objects. The output files are typically stored in specific system log directories. This guide is intended for developers and system engineers performing low-level memory debugging and diagnostics.

### 常用命令_6.md 常用命令_6.md
This document serves as a practical reference guide for using the hidumper tool to perform JavaScript heap memory analysis and leak detection. The content illustrates specific shell commands for dumping heap snapshots, triggering garbage collection, and identifying leaking objects for a target process ID. Key takeaways include the syntax for flags like --mem-jsheap, --gc, and --leakobj, as well as how to verify the generated output files. This technical guide is designed for developers or system engineers debugging memory issues who possess prerequisite knowledge of command-line interfaces and process management. Keywords: hidumper, memory analysis, JS heap, garbage collection, debugging, shell commands.
