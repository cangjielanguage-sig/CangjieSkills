# class_PopupOptions

This directory contains API reference documentation for the `PopupOptions` class and associated configuration variables within the ArkUI framework, specifically designed for the Cangjie language. It covers the comprehensive setup and customization of popup windows, detailing properties for layout positioning, visual styling, arrow indicators, transition effects, and event handling. Key topics include background blur, button actions, geometry constraints, and window management behaviors. This documentation is suitable for UI developers and system architects seeking to implement customizable popup dialogs, menus, or bubble components in their applications.

## Detailed Description

### class_PopupOptions.md class_PopupOptions.md
This document serves as an API reference for the PopupOptions class, which defines configuration parameters for creating popup windows in the ArkUI framework. It details class properties such as message content, button actions, layout positioning, styling attributes like color and shadow, and event callbacks. The document also outlines multiple constructors for initializing these options with varying degrees of customization. Key information includes support for background blur, arrow indicators, and transition effects, categorized under SystemCapability.ArkUI.ArkUI.Full starting from version 12. This reference is intended for developers using the Cangjie language to build user interfaces, specifically those needing to implement customizable popup dialogs or menus within their applications.
