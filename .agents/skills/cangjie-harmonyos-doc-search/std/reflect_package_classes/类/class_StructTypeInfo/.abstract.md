This directory contains API documentation for the `StructTypeInfo` class within the Cangjie language's `std.reflect` package. It provides comprehensive details on reflection capabilities for struct types, enabling developers to inspect and manipulate type metadata at runtime. Key topics include retrieving constructors, accessing instance and static variables, and dynamic instance construction. The documentation also covers critical implementation notes regarding manual boxing and unboxing for variable modification. This resource is essential for Cangjie developers who need to perform runtime type inspection, programmatically access struct members, or handle generic types and exceptions during reflection operations.
