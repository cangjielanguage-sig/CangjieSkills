This directory serves as a central repository for documentation regarding application configuration files, with a specific focus on the HarmonyOS and OpenHarmony development ecosystems. It provides in-depth guidance on utilizing the `app.json5` file format, which acts as the primary manifest for defining application metadata and behavior. The scope of this documentation includes critical setup areas such as bundle identification, version control, API compatibility specifications, and resource management strategies. Additionally, it explores more nuanced configuration options like font scaling adjustments, the implementation of layered icons, environment variable definitions, and settings for multi-app modes. Through the use of detailed attribute tables, illustrative JSON examples, and structural code skeletons, this directory equips developers with the necessary tools to establish application identity and manage runtime behaviors effectively. This resource is particularly suitable for application developers and DevEco Studio users who require precise control over app properties and seamless system integration during the build process.
