# 开发步骤

This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, specifically focusing on the implementation of HMAC (Hash-based Message Authentication Code) using the CryptoArchitectureKit. The content provides detailed development steps for calculating message authentication codes, addressing various data handling scenarios such as single-pass processing and segmented updates for streaming data. Core concepts covered include SHA256 hashing, symmetric key generation, and the usage of cryptographic APIs like `createMac`, `init`, `update`, and `doFinal`. These guides are highly suitable for software developers and system architects aiming to secure their applications with robust message authentication mechanisms, ensuring data integrity and authenticity in environments dealing with variable or large data volumes.
