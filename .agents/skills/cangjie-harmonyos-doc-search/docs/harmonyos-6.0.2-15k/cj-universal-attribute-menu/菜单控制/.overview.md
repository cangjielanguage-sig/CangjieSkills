# 菜单控制

This directory provides comprehensive API documentation and examples for implementing menu control systems within the Cangjie and ArkUI frameworks. It covers the definition of menu items, configuration of context menus, animation options, and binding methods for interactive UI components. Key topics include the `Action` and `MenuElement` classes, `bindMenu` and `bindContextMenu` functions, and specific options for styling and positioning. Designed for developers and UI engineers building interactive interfaces on HarmonyOS, these resources support system capabilities from API version 12 onwards, offering tools for creating standard and custom popup menus with advanced visual effects.

## Detailed Description

### class_Action.md class_Action.md
This document serves as API reference documentation for the Action class in the Cangjie language, specifically designed to define parameters for popup menu items. It covers the class definition, its read-only properties value and action, and the constructor details. The documentation outlines the data types, functionality, and initialization parameters required to create an Action instance. Key takeaways include that value holds the menu text as a String, while action is a callback function triggered on click. Both properties are immutable and must be provided as named arguments during object creation. Targeted at developers using the Cangjie framework version 12 or higher to build user interfaces with interactive menus, this reference requires knowledge of Cangjie syntax and event handling.

### class_ContextMenuAnimationOptions.md class_ContextMenuAnimationOptions.md
This document provides API reference documentation for the Cangjie class ContextMenuAnimationOptions, which configures animation parameters for context menus, specifically controlling scaling and transition effects during long-press previews. The main sections include the class constructor and detailed descriptions of its properties: scale, transition, and hoverScale. Key information highlights that scale sets general animation ratios, hoverScale manages floating component scaling in custom scenarios, and transition defines display effects. The documentation specifies constraints, such as invalid values for hoverScale and interaction rules between properties. Intended for ArkUI developers, this guide requires understanding of UI animation concepts to effectively customize menu behaviors in version 19 and later.

### class_MenuElement.md class_MenuElement.md
This document serves as an API reference for the MenuElement class in the Cangjie language, designed to configure menu items within the ArkUI framework. The documentation details the class structure and focuses primarily on its constructor, init, which initializes a menu element with text, a click action callback, and optional properties for icons and interaction states. Key information includes the specific parameter definitions, noting that icon and enabled are named parameters with default values. Intended for developers building ArkUI applications, this guide requires familiarity with Cangjie syntax and system capabilities to effectively implement interactive menu components.

### func_bindMenu_-_Unit.md func_bindMenu_-_Unit.md
This document provides API reference documentation for the bindMenu function in the Cangjie language, designed to attach interactive popup menus to UI components. The content details the function signature, system capabilities, and version requirements, specifically focusing on the mandatory builder parameter which accepts a custom UI description using the @Builder macro. Key information includes the function's return type of This for method chaining and its support for icon-text arrangements or custom layouts. Intended for ArkUI developers, this guide assists in implementing context menus that trigger upon component interaction, starting from system version 12.

### 菜单控制_5more.md 菜单控制_5more.md
This API documentation details how to bind popup menus to UI components using the Cangjie language. It covers two primary functions: bindContextMenu for custom menus triggered by long-press or right-click, and bindMenu for click-triggered menus supporting icons and text. Key sections include function signatures, parameter descriptions for builders and response types, and specific constraints regarding multi-level menus and drag-and-drop interactions. The document highlights system capabilities and version requirements. It is intended for developers implementing interactive menu behaviors in ArkUI applications, providing the necessary parameters and configuration options for menu control.
