# enum_PhotoKeys

本目录包含Cangjie语言中`PhotoKeys`枚举类型的API参考文档，主要用于定义和管理照片及视频文件的关键信息字段。内容涵盖了文件大小、缩略图尺寸、时间戳、媒体特征（如宽高）以及文件地址（Uri）等核心属性。该模块属于PhotoAccessHelper核心能力，起始版本为22。文档面向使用Cangjie开发HarmonyOS文件管理应用的开发者，提供了详细的字段定义、谓词查询规则及使用限制，帮助开发者高效处理媒体元数据。
