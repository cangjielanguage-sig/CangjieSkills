This directory contains API reference documentation for the `ohos.distributed_kv_store` module in the Cangjie programming language, part of the HarmonyOS ArkData framework. It comprehensively covers the implementation of distributed key-value databases, enabling efficient data synchronization and management across multiple devices. Key components include classes for store management (`KVManager`, `SingleKVStore`), data querying (`Query`), configuration (`KVOptions`, `Schema`), and change notifications (`ChangeNotification`). This documentation is suitable for Cangjie developers and software engineers building distributed applications that require secure, efficient, and synchronized data storage solutions.
