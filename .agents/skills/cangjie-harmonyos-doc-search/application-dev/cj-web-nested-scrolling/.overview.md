# cj-web-nested-scrolling

This directory serves as a specialized technical resource for implementing nested scrolling mechanisms tailored for Web components within the ArkUI framework, utilizing the Cangjie programming language. It addresses the complex challenges associated with embedding web content into native HarmonyOS applications, focusing on the creation of a unified and fluid user experience across multi-layered interfaces. The documentation thoroughly covers essential application scenarios, the configuration of the `nestedScroll` property interface, and specific scrolling behavior rules for supported containers such as List and Grid. It is primarily designed for ArkUI developers and system engineers who need to master the coordination of touch events and scrolling hierarchies between Web components and their parent containers using the `NestedScrollMode` enum.

## Detailed Description

### Web组件嵌套滚动/

This directory provides a comprehensive guide on implementing nested scrolling for Web components within ArkUI scrollable containers. It addresses the technical challenges of creating a unified user experience when embedding web content into native applications. The content covers application scenarios, the `nestedScroll` property interface, specific scrolling behavior rules, and supported containers such as List and Grid. Key concepts include the `NestedScrollMode` enum (SelfOnly, SelfFirst, ParentFirst, Parallel) which dictates the interaction hierarchy between the Web component and its parent. It is specifically designed for ArkUI developers using the Cangjie language who need to manage complex, multi-layered scrolling interfaces in HarmonyOS applications. By defining clear rules for how scroll events are propagated—whether the web view consumes the event, passes it to the parent, or handles them in parallel—this guide ensures that developers can build responsive and intuitive interfaces where native and web elements coexist seamlessly.
