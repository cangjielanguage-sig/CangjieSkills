This directory contains API reference documentation for the Cangjie Event class, designed to model calendar schedule objects within the SystemCapability.Applications.CalendarData capability. It covers the essential components for implementing calendar data management, including the class constructor, public properties like event type, timestamps, location, attendees, and recurrence rules. The documentation details requirements such as 13-digit timestamps and support for all-day or lunar events. This resource is intended for application developers familiar with Cangjie syntax who need to integrate robust calendar functionality into their applications.
