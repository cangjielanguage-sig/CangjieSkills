# cj-apis-uicontext-contextmenucontroller

This directory contains API reference documentation for the `ContextMenuController` class within the Cangjie ArkUI framework, focusing on programmatic menu control. It covers the class definition, import requirements, and the specific close method used to dismiss context menus. Key information includes the Beta status of the API and the prerequisite of obtaining an instance via `UIContext.getContextMenuController`. The documentation is intended for developers building ArkUI applications who require the ability to manually close context menus. This resource is essential for understanding the lifecycle and management of UI context elements, ensuring developers can implement robust user interaction patterns. Keywords: Cangjie, ArkUI, ContextMenuController, API reference, UIContext, close method, Beta.
