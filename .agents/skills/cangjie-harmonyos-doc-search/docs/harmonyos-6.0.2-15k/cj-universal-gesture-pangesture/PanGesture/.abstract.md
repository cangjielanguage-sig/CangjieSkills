This directory contains comprehensive documentation and resources for the PanGesture component within the Cangjie language and HarmonyOS ArkUI framework. It covers the implementation of sliding gesture events triggered by specific movement distances, including API references, practical code examples, and core type definitions. Key topics include gesture configuration, event handling callbacks, state management, and dynamic property updates. This resource is suitable for developers and software engineers building interactive user interfaces who require precise control over gesture recognition, touch interactions, and event logic in their applications.
