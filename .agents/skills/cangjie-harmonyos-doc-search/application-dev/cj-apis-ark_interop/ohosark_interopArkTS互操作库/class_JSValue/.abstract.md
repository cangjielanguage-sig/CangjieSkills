This directory contains API reference documentation for the `JSValue` class in the Cangjie programming language, designed for interoperability with the ArkTS runtime. It covers the unified type system used to interact with JavaScript values, detailing strict lifecycle management, type conversions, and data manipulation methods. Key topics include type checking functions, property access, and error handling for cross-language communication. This documentation is suitable for Cangjie developers working on HarmonyOS applications who need to safely pass data between Cangjie and ArkTS environments, manage object lifecycles, and handle type casting with precision.
