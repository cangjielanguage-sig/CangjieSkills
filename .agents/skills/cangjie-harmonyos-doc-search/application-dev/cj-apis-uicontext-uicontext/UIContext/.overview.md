# UIContext

The UIContext directory serves as a comprehensive resource for the UIContext module within the ArkUI framework, specifically designed for the Cangjie programming language. It details the module's purpose, import statements, and its current Beta status. The content covers a wide range of UI context management functionalities, including animation controls, screen density unit conversions (lpx, px, fp, vp), and dialog management such as alerts and action sheets. This documentation is primarily intended for Cangjie developers and software engineers who are building responsive layouts and interactive components for HarmonyOS applications. It provides the necessary API references and utility functions for developers requiring precise control over UI state, measurements, and user interactions.
