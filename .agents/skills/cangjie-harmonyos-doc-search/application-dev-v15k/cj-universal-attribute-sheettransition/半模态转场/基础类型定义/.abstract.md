This directory defines the fundamental types and configurations for semi-modal pages (Sheets) within the Cangjie ArkUI framework. It covers essential classes for binding options, title settings, and general sheet properties, alongside enumerations for display styles. Key topics include lifecycle callbacks, visual customization, drag behaviors, and animation controls. These definitions are crucial for developers building interactive UI components that require precise control over modal presentation, dismissal logic, and layout sizing. It is suitable for UI developers and system architects working with the Cangjie language to create sophisticated application interfaces.
