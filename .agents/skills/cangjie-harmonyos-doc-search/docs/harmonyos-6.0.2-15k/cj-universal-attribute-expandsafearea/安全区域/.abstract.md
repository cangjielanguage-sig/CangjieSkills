This directory provides comprehensive documentation for managing Safe Areas and keyboard interactions in HarmonyOS applications using the ArkUI framework and Cangjie language. It covers fundamental concepts, API references for `expandSafeArea` and `setKeyboardAvoidMode`, and essential enumeration types. Developers can learn how to handle system UI elements like status bars and cutouts, as well as optimize layouts for virtual keyboards. This resource is suitable for UI developers and engineers building immersive, responsive interfaces on HarmonyOS.
