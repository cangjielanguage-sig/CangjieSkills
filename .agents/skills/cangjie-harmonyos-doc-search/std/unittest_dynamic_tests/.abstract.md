This directory provides a specialized guide for developers working within the Cangjie framework who need to implement advanced dynamic testing strategies. Unlike standard static testing, this resource focuses on scenarios where test data is generated or discovered at runtime rather than compile time. It introduces the `@TestBuilder` annotation as the primary mechanism for handling these dynamic requirements, guiding users through the construction of flexible test suites using `TestSuite` and `UnitTestCase` classes. The content clearly distinguishes these dynamic approaches from traditional static `@Test` cases, highlighting the benefits of programmatic test execution via the `runTests()` method. Additionally, it addresses the critical need for diverse result dissemination by explaining how to utilize various `Reporter` classes to export test outcomes to console, text, XML, or CSV formats. This documentation is particularly suitable for software engineers and QA professionals who require a highly adaptable testing infrastructure capable of integrating with external data sources and complex configuration environments. By mastering these dynamic testing techniques, users can significantly enhance the flexibility and coverage of their testing workflows within the Cangjie ecosystem.
