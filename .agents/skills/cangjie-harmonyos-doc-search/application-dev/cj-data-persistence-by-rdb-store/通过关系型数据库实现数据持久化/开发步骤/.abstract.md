This directory provides a comprehensive tutorial series for implementing data persistence using relational databases in the Cangjie programming language. It covers the full development lifecycle, from initializing the RdbStore and configuring database properties to performing essential data manipulation operations like inserting, updating, and querying records. Additionally, it addresses advanced maintenance tasks such as database backup, restoration, and deletion. Designed for application developers familiar with Cangjie and ArkUI, these guides offer practical code examples for managing local data storage effectively within UIAbility components.
