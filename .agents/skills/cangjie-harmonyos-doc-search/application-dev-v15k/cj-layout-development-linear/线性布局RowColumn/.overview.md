# 线性布局RowColumn

This directory focuses on linear layouts using Row and Column containers within the ArkUI framework and Cangjie language. It covers fundamental layout concepts, including main and cross axes, spacing, and adaptive strategies for different screen sizes. Key topics include handling content overflow through scrolling, adaptive stretching using the Blank component, and scaling with layoutWeight. Additionally, it provides detailed guides on aligning child elements along both main and cross axes. This resource is suitable for UI developers and HarmonyOS engineers seeking to master responsive design and precise element positioning in Cangjie-based applications.
