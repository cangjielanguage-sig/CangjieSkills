# cj-common-components-custom-dialog

This directory serves as a technical repository for implementing custom pop-up dialogs within the HarmonyOS ecosystem, specifically utilizing the ArkUI framework and the Cangjie language. It focuses on the `@CustomDialog` and `CustomDialogController` implementation pattern, explicitly marking it as a legacy approach not recommended for new development. The content covers a wide range of topics including dialog creation, user interaction handling, modal versus non-modal behaviors, and complex styling techniques such as borders and shadows. Additionally, it explores advanced architectural patterns like nesting dialogs and managing component lifecycles to prevent runtime errors. This resource is primarily suitable for Cangjie developers and UI engineers who are tasked with maintaining legacy codebases or require a deep understanding of specific overlay mechanics, while being advised to adopt the Navigation component for modern page-level scenarios.

### 基础自定义弹出框CustomDialog不推荐/

This directory provides technical tutorials focused on implementing custom pop-up dialogs using the ArkUI framework and the Cangjie language within the HarmonyOS ecosystem. It explicitly addresses a specific implementation pattern using `@CustomDialog` and `CustomDialogController` while noting that this approach is currently not recommended for new development. The content covers essential aspects such as dialog creation, user interaction handling, modal versus non-modal behaviors, and complex styling including borders and shadows. Furthermore, it delves into advanced architectural patterns like nesting dialogs and managing component lifecycles to prevent errors. This resource is suitable for Cangjie developers and UI engineers who need to maintain legacy code or understand specific overlay mechanics, with a strong recommendation to utilize the Navigation component for page-level scenarios instead. Understanding these patterns is vital for ensuring the stability of existing applications while navigating the transition to newer architectural standards.
