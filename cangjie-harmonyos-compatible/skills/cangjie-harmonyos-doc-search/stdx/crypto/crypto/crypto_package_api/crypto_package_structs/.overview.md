# crypto_package_structs

This directory serves as a specialized technical resource for the Cangjie programming language, focusing specifically on the core data structures required for symmetric encryption operations. It provides a detailed API reference for essential components that dictate how encryption algorithms behave, particularly the `OperationMode` and `PaddingMode` structures. The content covers a wide array of cryptographic standards, including popular encryption modes like ECB, CBC, and GCM, as well as necessary padding schemes such as PKCS7. By documenting the specific properties and member functions of these structures, this package enables developers to fine-tune their security implementations. It is an invaluable tool for Cangjie developers who need to integrate secure symmetric encryption into their applications, ensuring they have the correct structural definitions to configure parameters accurately and effectively.

## Detailed Description

### 结构体/

This directory contains the fundamental API reference documentation for core structures used in symmetric encryption within the Cangjie language environment. It is structured to assist developers in understanding the building blocks required to implement secure cryptographic workflows.

The documentation centers on two primary structural definitions. First, the `OperationMode` structure is comprehensively detailed, explaining how to define the working modes of encryption algorithms. This includes in-depth coverage of common modes such as ECB (Electronic Codebook), CBC (Cipher Block Chaining), and GCM (Galois/Counter Mode), which are pivotal for determining the security and efficiency of data encryption.

Second, the `PaddingMode` structure is explored to define padding strategies, with specific attention given to methods like PKCS7 which ensure data blocks meet algorithm size requirements. The documentation goes beyond simple definitions by including detailed descriptions of the attributes and member functions associated with these structures. By outlining these technical specifics, the guide helps developers understand how to interact with the structures programmatically. This level of detail makes the content highly suitable for developers who are actively implementing or invoking symmetric encryption functions in Cangjie projects, providing them with the knowledge needed to correctly configure encryption parameters and manage data integrity throughout the development lifecycle.
