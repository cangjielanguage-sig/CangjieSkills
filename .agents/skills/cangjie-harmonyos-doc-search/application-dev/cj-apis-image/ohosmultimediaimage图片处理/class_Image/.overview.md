# class_Image

This directory provides essential API reference documentation for the Cangjie Image class within the ImageKit framework, focusing on the retrieval and management of image content. It details critical read-only properties such as clipRect, format, and size, alongside methods for accessing image buffers. A primary emphasis is placed on memory management, specifically the immutability of image properties and the mandatory manual invocation of the release method to free memory. This documentation is tailored for developers working on multimedia applications in Cangjie, particularly those handling image streams from ImageReceiver who require precise control over resource lifecycles and data access.

### class_Image_5more.md class_Image_5more.md
This document provides API reference documentation for the Cangjie Image class, designed to retrieve and manage image content. Key takeaways include the immutability of image properties, the specific behavior of the size attribute for YUV versus JPEG data, and the critical requirement to manually call the release method to free memory. ### func_release.md func_release.md
This document serves as API reference documentation for the Cangjie language's release function, detailing how to manage image resources effectively. It covers the function signature, specific functionality, system capabilities, and version requirements, alongside a practical code example demonstrating error handling and resource cleanup. Key takeaways emphasize the necessity of actively calling this method to free memory, as images occupy significant space, and ensuring resources are released before acquiring new images. The target audience includes developers working with multimedia image processing who possess prerequisite knowledge of Cangjie syntax and the ImageKit framework.
