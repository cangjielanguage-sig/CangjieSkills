This directory provides comprehensive documentation for the ArkUI Stepper component, a navigation tool essential for displaying progress across multiple task steps in HarmonyOS applications. It covers the component's API reference, practical implementation examples using the Cangjie language, and detailed event handling mechanisms. Key topics include module imports, constructor parameters, state management for step indices, and lifecycle callbacks such as onChange and onFinish. This resource is suitable for HarmonyOS developers and system architects looking to build robust multi-step workflows and step-by-step navigation interfaces using the ArkUI framework and Cangjie language.
