# stdruntime

The `stdruntime` directory provides essential documentation for the Cangjie programming language's standard runtime package. It serves as a central resource for understanding how to interact with and control the program's execution environment effectively. The content primarily focuses on advanced memory management techniques, including the interaction with Cangjie's automatic garbage collection system, as well as manual controls for heap optimization. Additionally, it covers performance profiling, thread monitoring, and CPU statistics. This documentation is specifically designed for Cangjie developers and system engineers who require deep system-level access to debug applications, manage resource consumption, and optimize runtime performance for production environments.

## Detailed Description

### API_列表.md API_列表.md
This document serves as a comprehensive API reference index for runtime management, specifically targeting memory control, thread monitoring, and performance profiling within the Cangjie runtime environment. The content is organized into two primary sections: Functions and Structs. The Functions section details utilities for garbage collection execution, heap memory statistics, thread counting, and CPU profiling, including specific tools like blackBox for compiler optimization. The Structs section lists deprecated interfaces for accessing memory, processor, and thread statistics. Key information includes the availability of real-time metrics for heap usage and GC performance, alongside deprecation warnings for legacy structures. This documentation is intended for developers and system engineers seeking to optimize application performance or debug runtime behavior.

### 功能介绍.md 功能介绍.md
This document provides an overview of the runtime package in the Cangjie programming language, detailing its role in interacting with the program's execution environment. The content covers the package's general capabilities for controlling and monitoring execution, with a specific focus on memory management. Key information includes the explanation of Cangjie's automatic garbage collection mechanism and how the runtime package supplements it with manual controls, such as triggering collection, setting thresholds, and retrieving memory statistics. This serves as introductory reference material for Cangjie developers who need to manage system resources and optimize performance. Keywords: Cangjie, runtime package, garbage collection, memory management, execution control.
