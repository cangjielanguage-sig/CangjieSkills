## Detailed Description

### cj-menu-menuitemgroup.md

本文档是ArkUI框架中MenuItemGroup组件的API参考文档，旨在指导开发者如何创建和管理菜单项分组。文档主要涵盖模块导入、子组件包含关系以及两种初始化构造函数的详细说明，分别支持通过CustomBuilder或ResourceStr设置分组的头部和尾部信息。关键信息指出该组件目前处于Beta阶段，使用CustomBuilder类型参数时需配合bind函数管理。文档面向使用仓颉语言进行UI开发的开发者，提供了完整的通用属性和事件支持说明，并引用了Menu组件的示例代码供参考，帮助开发者快速上手并正确应用该组件。
