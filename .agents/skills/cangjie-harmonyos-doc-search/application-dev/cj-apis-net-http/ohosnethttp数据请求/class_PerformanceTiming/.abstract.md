This directory provides comprehensive API reference documentation for the Cangjie `PerformanceTiming` class and its associated variables, specifically designed to capture and analyze network request performance metrics with high precision. It covers granular timing data for various critical stages of the request lifecycle, including DNS resolution, TCP connection establishment, TLS negotiation, server redirects, and response parsing, all measured in milliseconds. The documentation details properties and variables of type Float64 that support read and write access, measuring duration from the initial request or callback. This resource is suitable for developers implementing or analyzing network communication features who require precise timing data to optimize performance, utilizing the SystemCapability.Communication.NetStack capability available from version 22.
