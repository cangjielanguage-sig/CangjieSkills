# 传感器开发指导仓颉

This directory serves as a comprehensive technical guide for sensor development using the Cangjie programming language. It provides essential resources for accessing device hardware data, covering a wide range of scenarios from monitoring device orientation to tracking user steps via pedometer sensors. The documentation details the core API interfaces, including methods for continuous data listening, single data retrieval, and listener unregistration. Furthermore, it addresses practical implementation aspects such as querying available sensors, configuring application permissions, and managing sampling periods to optimize power consumption. This content is specifically tailored for application developers and system integrators looking to leverage the SensorServiceKit to build robust, sensor-aware applications. It bridges the gap between high-level use case requirements and low-level technical implementation.

## Detailed Description

### 场景介绍_2more.md 场景介绍_2more.md
This document serves as a conceptual guide for using the sensor module to access device hardware data. It outlines common usage scenarios, such as monitoring device orientation or tracking user steps via pedometer sensors. The text details the primary API interfaces, distinguishing between continuous data listening via the on method, single data retrieval with once, and unregistration using off. It also includes the getSensorList function for querying available sensors. Intended for application developers, this document acts as a bridge between use case requirements and the detailed technical API reference, providing a quick lookup for essential sensor management functions.

### 开发步骤.md 开发步骤.md
This document provides a step-by-step tutorial for developing sensor applications using the Cangjie language, utilizing the accelerometer as a primary example. It covers essential procedures including importing necessary modules, querying device sensor parameters, and configuring required permissions. Key sections detail how to register listeners for continuous or single-event data reporting using the on() and once() interfaces, as well as how to unregister them. The guide highlights critical concepts such as sampling period constraints and their impact on power consumption. It is intended for developers using the SensorServiceKit to implement sensor functionality.
