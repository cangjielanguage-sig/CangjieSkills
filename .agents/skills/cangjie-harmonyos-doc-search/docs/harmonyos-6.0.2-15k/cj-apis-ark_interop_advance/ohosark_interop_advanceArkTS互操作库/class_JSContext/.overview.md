# class_JSContext

This directory contains API reference documentation for the `JSContext` class and associated functions in the Cangjie programming language, specifically designed for interoperability with ArkTS on HarmonyOS. It covers the creation and management of JavaScript values, including arrays, buffers, objects, and primitive types, as well as threading and module management. Key topics include memory management, data type conversion, and lifecycle handling within the ArkTS runtime. This documentation is suitable for Cangjie developers working on cross-language integration, native module development, and low-level Napi operations requiring system capabilities like ArkUI.ArkUI.Napi.
