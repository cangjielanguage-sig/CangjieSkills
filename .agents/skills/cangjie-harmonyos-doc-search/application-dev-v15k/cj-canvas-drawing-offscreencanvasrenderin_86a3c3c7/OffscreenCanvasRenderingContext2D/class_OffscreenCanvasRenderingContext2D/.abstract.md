This directory contains API reference documentation for the `OffscreenCanvasRenderingContext2D` class in the Cangjie programming language, designed for HarmonyOS ArkUI development. It covers offscreen 2D drawing capabilities, including path creation, shape rendering, text styling, image manipulation, and coordinate transformations. Key topics include canvas gradients, patterns, pixel data handling, and state management. This resource is essential for developers building high-performance 2D graphics applications who need to programmatically render complex visual elements off the main screen.
