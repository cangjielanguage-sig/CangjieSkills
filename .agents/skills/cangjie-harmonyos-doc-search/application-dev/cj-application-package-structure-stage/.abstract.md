This directory serves as a comprehensive technical guide for the application package structure within the HarmonyOS Stage model, specifically designed for developers utilizing the Cangjie language. It thoroughly covers the project hierarchy during the development phase, including essential configuration files such as `app.json5` and `module.json5`, Cangjie source code organization, and resource management strategies. Furthermore, it details the structural transformation from the development environment to the final release state, explaining complex processes like HAP generation, resource merging, and distribution packaging. This documentation is ideal for HarmonyOS developers seeking to understand DevEco Studio project organization, build artifacts, and the critical distinctions between App Packs and HAPs.
