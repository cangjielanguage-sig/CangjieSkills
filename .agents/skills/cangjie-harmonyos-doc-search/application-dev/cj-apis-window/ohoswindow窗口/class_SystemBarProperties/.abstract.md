This directory provides comprehensive API reference documentation for the `SystemBarProperties` class in the Cangjie programming language. It focuses on the configuration and customization of system bar attributes, specifically targeting the status bar and navigation bar. The content covers a wide range of visual properties, including background colors, content colors, light icon modes, and animation toggles. Designed for application developers utilizing the WindowManager system capability, this documentation enables manual control over system bar appearance starting from API version 22. By detailing the class constructor and its public properties, these resources help developers integrate system bar styling seamlessly into their applications, ensuring a consistent and user-friendly interface experience.
