This directory contains technical documentation for the Float64 data type within the Cangjie programming language context. It covers the fundamental definition of the 64-bit floating-point number based on the IEEE 754 standard, along with extended API functionalities. Key topics include mathematical constants, boundary limits, bitwise operations, and interface implementations like Comparable and Hashable. This documentation is suitable for developers and engineers who need precise definitions, mathematical utilities, and low-level bit manipulation capabilities for double-precision floating-point arithmetic in their applications.
