# 手电筒使用

This directory provides comprehensive technical documentation for implementing and managing flashlight (torch) functionality within applications developed using the Cangjie language and the CameraKit framework. It covers the complete development lifecycle for torch features, ranging from initial capability verification and mode configuration to real-time status monitoring. Key topics include API integration methods, specific behavioral constraints regarding camera compatibility, and event-driven status updates. This resource is specifically designed for software developers and application engineers who possess a working knowledge of the CameraKit API and Cangjie syntax, enabling them to successfully integrate continuous lighting and robust status tracking into their camera-based applications.

## Detailed Description

### 手电筒使用_2more.md 手电筒使用_2more.md
This document serves as a comprehensive development guide for implementing the flashlight (torch) feature using the Cangjie language and CameraKit. It outlines specific behavioral constraints that developers must account for, such as the incompatibility of the torch with rear camera flash-off modes and the automatic deactivation of the torch during camera switching processes. The main section provides a detailed, step-by-step tutorial covering essential API imports, capability verification via `isTorchSupported` and `isTorchModeSupported`, and mode configuration using `setTorchMode` and `getTorchMode`. Key takeaways include the absolute necessity of implementing status listeners to accurately retrieve torch states. Intended for software developers, this guide requires familiarity with the CameraKit API and Cangjie syntax to successfully integrate continuous lighting functionality into applications.

### 状态监听.md 状态监听.md
This document guides developers through the process of monitoring torch status changes within a camera application using the CameraKit framework. It covers the technical implementation of the `TorchStatusChange` event registration, the `TorchStatusInfo` callback interface, and specific status states such as open, closed, or unavailable. The provided Cangjie code example demonstrates how to implement `TorchStatusChangeCallBack` to effectively handle status updates, logging critical properties such as availability, active state, and light level. This technical guide targets application developers who are familiar with the Cangjie language and camera management APIs and who need to implement real-time flashlight status tracking to ensure a responsive user experience.
