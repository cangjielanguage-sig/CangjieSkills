This directory contains API reference documentation for the `StaticVariableInfo` class within the Cangjie programming language's reflection package. It provides comprehensive details on metadata and reflection capabilities specifically designed for static member variables. The documentation covers essential properties for accessing variable attributes such as name, type information, annotations, and modifiers, as well as methods for runtime interaction including value retrieval and modification. It is intended for developers utilizing reflection to dynamically inspect and manipulate static class members. Users should have a solid understanding of Cangjie syntax and exception handling mechanisms to effectively utilize these tools. The content highlights key functionalities like `getValue`, `setValue`, and `isMutable`, providing a complete guide for runtime introspection and dynamic class member management.
