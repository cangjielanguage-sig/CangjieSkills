This directory contains API reference documentation for the Cangjie programming language's Process class and related process management utilities. It covers essential operations for creating, managing, and monitoring system processes, including instance creation, information retrieval, lifecycle control, and termination. The documentation details key properties like process ID and start time, alongside functions for checking status and stopping execution. It also addresses deprecated static methods for subprocess execution and output capture. Intended for Cangjie developers, this guide requires knowledge of system processes and exception handling to effectively utilize these interfaces for system-level programming.
