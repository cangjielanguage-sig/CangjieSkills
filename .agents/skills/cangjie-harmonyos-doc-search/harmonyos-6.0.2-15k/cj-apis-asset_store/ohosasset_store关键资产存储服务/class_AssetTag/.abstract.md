This directory provides API reference documentation for the `AssetTag` class in the Cangjie language, focusing on constant identifiers used as keys for asset attributes. It covers static `UInt32` constants organized into categories such as security, authentication, data labeling, and query operations. Key topics include distinguishing between critical and normal data labels, managing access control, and handling synchronization settings. These definitions are part of the `SystemCapability.Security.Asset` capability starting from version 19. This documentation is intended for developers implementing secure asset management systems who need to specify attribute types, values, and security policies for key assets.
