# 日志打印示例

This directory serves as a comprehensive resource for implementing logging mechanisms in the Cangjie programming language. It provides practical examples and tutorials covering two primary scenarios: library development and application development. The content details the setup of global loggers using modules like `stdx.log` and `stdx.logger`, configuration of log levels, and the use of structured logging with key-value pairs. Furthermore, it addresses advanced requirements such as sensitive data masking for security, performance optimization through lazy evaluation, and context injection. These materials are highly suitable for Cangjie developers, software engineers, and system architects who aim to build robust, secure, and efficient logging systems that facilitate debugging and compliance in production environments. By mastering these patterns, developers can ensure their applications maintain high performance while providing necessary observability without exposing sensitive user data.

## Detailed Description

### 库开发场景记录日志.md 库开发场景记录日志.md
This document serves as a practical tutorial demonstrating how to implement logging in Cangjie library development. It covers the setup of a global logger using stdx.log and stdx.logger modules, including configuration of log levels and output targets. Key information includes the usage of getGlobalLogger for class-level logging, the SimpleLogger for standard output, and the formatting of log messages with structured key-value pairs. The example illustrates a PGConnection class logging a trace event. This guide is intended for Cangjie developers seeking to integrate diagnostic logging into their libraries or applications.

Keywords: Cangjie, logging, stdx.log, global logger, structured logging, library development, trace level.

### 应用程序开发场景日志打印/
This directory focuses on logging mechanisms within application development scenarios, specifically utilizing the Cangjie programming language. It covers the practical implementation of custom logging frameworks designed to enhance security and performance. Key topics include sensitive data masking (such as passwords) to prevent information leakage, structured logging with key-value pairs for better parsing, log level management, and performance optimization via lazy evaluation techniques. The content demonstrates how to handle output streams, serialize complex data types, and inject context into logs. These resources are highly suitable for software developers and system architects seeking to build robust, secure, and efficient logging systems that facilitate debugging and compliance in production environments. By mastering these patterns, developers can ensure their applications maintain high performance while providing necessary observability without exposing sensitive user data.
