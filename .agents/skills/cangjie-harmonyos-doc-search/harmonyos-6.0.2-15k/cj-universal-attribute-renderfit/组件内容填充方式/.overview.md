The documentation details the function signature, system capabilities, and the RenderFit enum parameter. Key information includes the default initial value RenderFit.TOP_LEFT and specific behaviors for XComponent types: TEXTURE and SURFACE types default to RenderFit.RESIZE_FILL, while SURFACE types with opaque black backgrounds strictly require RESIZE_FILL. This guide targets developers using the Cangjie language to implement dynamic UI animations and rendering logic.
