This directory contains API reference documentation for the `Tags` class in the Cangjie programming language, specifically designed for the HarmonyOS ecosystem. It defines a comprehensive set of bit-flag constants used to identify system modules and usage scenarios within the HiProfiler and HiDebug frameworks. The documentation covers a wide array of subsystems, ranging from Ability Manager and ArkUI to Distributed Hardware and Media. These resources are essential for developers and system engineers working on performance profiling, debugging, and system event categorization, requiring the SystemCapability.HiviewDFX.HiProfiler.HiDebug capability starting from API version 19.
