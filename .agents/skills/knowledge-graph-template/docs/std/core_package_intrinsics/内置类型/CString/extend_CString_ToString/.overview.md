# extend_CString_ToString

This directory contains API documentation for extending the `CString` type in the Cangjie programming language. It focuses on implementing the `ToString` interface and adding utility methods for C-style string manipulation. Key topics include resource management (`asResource`), lexicographical comparison (`compare`), substring extraction (`subCString`), and type conversion (`toString`). The documentation covers essential functions for checking prefixes/suffixes, calculating size, and handling null pointers within `unsafe` blocks. It is suitable for Cangjie developers working on low-level string operations, C interoperability, and manual memory management.

### extend_CString_ToString_4more.md extend_CString_ToString_4more.md
This API documentation file details the extension of the CString type in the Cangjie language to implement the ToString interface and add utility methods. It covers three primary functions: asResource for resource management, compare for lexicographical comparison, and endsWith for suffix checking. Key information includes the asResource method enabling automatic memory release via try-with-resource syntax, the compare function mimicking C's strcmp behavior, and endsWith handling null pointers by returning false. This reference is intended for Cangjie developers working with C-style strings and manual memory management, requiring knowledge of unsafe operations and C interop.
