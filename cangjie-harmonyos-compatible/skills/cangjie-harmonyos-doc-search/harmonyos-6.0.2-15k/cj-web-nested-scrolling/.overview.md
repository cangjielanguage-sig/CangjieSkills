# cj-web-nested-scrolling

This directory serves as a specialized technical guide for implementing nested scrolling functionality tailored for Web components within the ArkUI framework. It addresses the complexities of synchronizing scroll events between child Web views and parent scrollable containers, a common requirement in modern hybrid application development. The content provides a deep dive into the `nestedScroll` property interface, the `NestedScrollMode` enumeration, and the logic governing event propagation. It also examines input event compatibility and the specific container types supported by the framework. This resource is indispensable for HarmonyOS developers working with Cangjie or ArkTS who aim to create sophisticated, multi-layered interfaces that integrate Web content seamlessly without sacrificing native scroll performance or user experience.

## Detailed Description

### Web组件嵌套滚动/
This directory focuses on the implementation and configuration of nested scrolling for Web components within ArkUI scrollable containers. It provides comprehensive resources for enabling coordinated scrolling between child Web views and parent containers. The content covers the `nestedScroll` property interface, the `NestedScrollMode` enumeration, event propagation logic, supported container types, and input event compatibility.

Central to this guide are the four scrolling modes: **SELF_ONLY**, **SELF_FIRST**, **PARENT_FIRST**, and **PARALLEL**. The documentation details how each mode affects the distribution of scroll gestures. For instance, it explains the mechanism for passing unconsumed scroll offsets to the nearest parent container based on axis direction, which is vital for handling edge cases where a child view reaches its scroll limit. By understanding these propagation rules and compatibility requirements, developers can prevent conflicts between native and Web-based scrolling systems. This collection is suitable for HarmonyOS developers using Cangjie or ArkTS who need to integrate Web components into complex, multi-layered scrolling interfaces.
