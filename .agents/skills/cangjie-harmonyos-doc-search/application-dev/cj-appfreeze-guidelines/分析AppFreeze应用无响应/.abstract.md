This directory focuses on analyzing Application Not Responding (AppFreeze) events within the OpenHarmony/HarmonyOS ecosystem, specifically under the Stage model. It covers detection mechanisms, fault types like main thread stalls and lifecycle timeouts, and system recovery processes. The content includes guides for log collection, stack trace analysis, and debugging workflows using tools like DevEco Studio. It is suitable for developers, system engineers, and QA professionals looking to diagnose and resolve application stability issues, understand watchdog logic, and optimize performance.
