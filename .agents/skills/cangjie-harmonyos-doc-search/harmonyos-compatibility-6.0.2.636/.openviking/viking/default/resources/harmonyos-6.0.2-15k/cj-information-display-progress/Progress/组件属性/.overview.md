# 组件属性

This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It specifically focuses on the Progress component, providing comprehensive details on methods for customizing visual appearance, colors, and values. Key topics covered include setting foreground colors using solid ResourceColor or gradient Array<ColorStop> inputs, defining visual styles for various bar types such as Linear, Capsule, Ring, and Eclipse, and managing progress values with automatic clamping. This documentation is suitable for software developers and engineers building HarmonyOS applications who need to programmatically control UI component behavior, dimensions, and styling.

## Detailed Description

### func_colorResourceColor_7more.md
This document serves as API reference material for configuring the appearance of a Progress component using the Cangjie language. It details overloaded functions for setting foreground colors, supporting both solid ResourceColor and gradient Array<ColorStop> inputs. Additionally, it covers various style methods tailored to specific progress bar types, including Ring, Eclipse, and ScaleRing, alongside a general style configuration. Key information includes parameter definitions, default values for different shapes, and version compatibility notes starting from API 12. This guide is intended for developers working within the ArkUI framework who need to programmatically customize progress bar dimensions, colors, and specific geometric styles.

### func_styleLinearStyleOptio_3more.md
This document serves as API reference material for configuring progress bar components within the ArkUI framework using the Cangjie language. It details three specific methods: `style` for LinearStyleOptions, `style` for CapsuleStyleOptions, and `value` for Float64. Key information includes that the `style` functions define visual appearances (Linear or Capsule), while the `value` function sets the current progress, automatically clamping values between 0 and the total. All functions return `This` to support method chaining. This documentation targets software developers working on HarmonyOS applications who need to programmatically control progress bar behavior and styling.
