# 透明度变化的旋转屏动画

This directory provides comprehensive technical guides on implementing opacity-based animations during screen rotation for HarmonyOS applications. It covers the implementation details for both the Cangjie framework and ArkTS, focusing on how to manage UI component transitions smoothly when device orientation changes. Key concepts include `TransitionEffect.OPACITY`, window size change callbacks, `@StorageLink` for reactive state management, and necessary configuration in `module.json5`. These resources are designed for developers seeking to create polished, responsive user interfaces that handle orientation changes with professional fade-in and fade-out effects, ensuring a seamless visual experience for the end-user.

## Detailed Description

### 透明度变化的旋转屏动画_1.md 透明度变化的旋转屏动画_1.md
This document serves as a development guide explaining how to implement automatic opacity transitions for UI components during screen rotation in the Cangjie framework. It details the mechanism where the system applies TransitionEffect.OPACITY to components added or removed during rotation events to ensure smooth appearance and disappearance. The content includes code examples demonstrating how to use @StorageLink for reactive UI updates and how to register a windowsSizeChange callback in the ability lifecycle to update orientation state. Key takeaways include the automatic application of default transitions and the option for manual configuration. This guide is intended for HarmonyOS developers seeking to enhance user experience during device orientation changes.

### 透明度变化的旋转屏动画_2.md 透明度变化的旋转屏动画_2.md
This document serves as a technical guide for implementing a rotation screen animation featuring opacity transitions in HarmonyOS applications. It covers the code implementation for window management and display orientation tracking, as well as the necessary configuration in the module.json5 file to enable auto-rotation. Key takeaways include setting the orientation attribute to "auto_rotation" and using window callbacks to manage size changes. The animation logic combines window resizing transitions with view switching effects, applying fade-out to disappearing views and fade-in to new views. This guide targets developers familiar with ArkTS and application configuration who need to create smooth, visually appealing rotation transitions.
