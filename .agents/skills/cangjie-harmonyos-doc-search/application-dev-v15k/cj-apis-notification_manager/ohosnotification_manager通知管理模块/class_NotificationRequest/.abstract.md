This directory contains API reference documentation for the `NotificationRequest` class in the Cangjie programming language. It covers the structure and configuration of system notification requests, including constructors, properties for deduplication, badge management, and display settings. Key topics include `NotificationContent`, `appMessageId`, `deliveryTime`, and various notification flags. The documentation details data types, system capabilities, and version requirements. It is suitable for software developers using Cangjie to implement or manage system notifications who need precise definitions of object structures and notification handling logic.
