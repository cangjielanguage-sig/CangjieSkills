This directory provides a comprehensive guide to HarmonyOS application packages and module architecture. It covers the fundamental definitions of applications, the Stage model, and the distinctions between various module types like HAP, HAR, and HSP. Key topics include modular design, resource sharing strategies, multi-device adaptation, and dependency management. This documentation is suitable for HarmonyOS developers seeking to understand packaging units, optimize application structure, and select the correct module types for specific development scenarios.
