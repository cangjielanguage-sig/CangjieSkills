## Detailed Description

### class_Stream_4more.md class_Stream_4more.md
This document provides API reference documentation for the Stream class in the Cangjie programming language, designed for file stream management. It covers the class definition and three primary synchronous methods: close, flush, and read. Key information includes the requirement to instantiate Stream via FileFs.createStream or FileFs.fdopenStream before usage. The read method accepts a byte array buffer and ReadOptions for length and offset configuration, returning the actual bytes read. All methods support SystemCapability.FileManagement.File.FileIO starting from version 12. This reference targets Cangjie developers implementing file input/output operations who need to handle file streams, buffers, and potential business exceptions.

### func_writeString_WriteOpti_2more.md func_writeString_WriteOpti_2more.md
This API reference document details the overloaded write functions used to write string or byte array data into file streams within the Cangjie development environment. The content covers two primary function signatures, parameter definitions including the WriteOptions struct, return values, exception handling, and practical code examples for both data types. Key information includes that both functions return the number of bytes written as Int64 and support optional parameters for write length, offset, and encoding (UTF-8). They require a file stream object and throw BusinessException on failure. This guide targets software developers implementing file input/output operations, specifically those needing to handle text or binary data writing with configurable options.
