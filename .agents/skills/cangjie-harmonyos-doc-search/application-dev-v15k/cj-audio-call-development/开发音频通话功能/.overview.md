This directory provides a comprehensive technical guide for developing audio call functionality within the HarmonyOS ecosystem. It covers the essential workflow of managing simultaneous audio input and output, utilizing components like AudioRenderer and AudioCapturer. Key topics include audio stream configuration, lifecycle management, and handling voice communication scenarios. The documentation is tailored for developers building communication or VOIP applications, offering foundational knowledge on audio data flow and component integration using languages such as ArkTS or Cangjie.

### 使用AudioCapturer录制本端的通话声音/
This directory provides a specialized technical guide for developers focused on capturing local voice call audio using the AudioCapturer module within the HarmonyOS environment, specifically utilizing the Cangjie programming language. It comprehensively covers the setup process, including obtaining the UIAbility context and configuring audio streams with the critical `SOURCE_TYPE_VOICE_COMMUNICATION` parameter. The documentation highlights essential requirements such as microphone permissions and the implementation of callbacks for processing audio data. Additionally, it addresses the complexities of the AudioCapturer lifecycle, offering code examples for start, stop, and release operations with strict state validation. This resource is designed for application developers with existing knowledge of Cangjie syntax and HarmonyOS basics who need to implement reliable, state-aware audio recording logic in their applications.

### 使用AudioRenderer播放对端的通话声音/
This directory provides comprehensive technical guidance on utilizing the AudioRenderer component to play remote call audio within HarmonyOS applications. It covers the complete workflow from retrieving the UIAbility context to implementing audio output logic. Key technical aspects include configuring `audioRendererInfo` parameters—specifically setting stream usage to `STREAM_USAGE_VOICE_COMMUNICATION` and content type to speech—as well as managing the AudioRenderer lifecycle. The content addresses state validation, error handling, and data reading from files. This resource is ideal for HarmonyOS developers building VOIP applications or implementing complex audio playback features using ArkTS or Cangjie.
