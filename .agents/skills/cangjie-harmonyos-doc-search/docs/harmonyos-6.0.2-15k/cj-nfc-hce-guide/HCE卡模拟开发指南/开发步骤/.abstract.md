This directory contains essential technical documentation for implementing Host Card Emulation (HCE) functionality within HarmonyOS applications using the Cangjie programming language. It provides a comprehensive walkthrough of the development steps required to simulate smart cards for contactless interactions, such as payments or secure access. The content covers the entire implementation spectrum, starting with configuration in `module.json5` for permissions and actions, importing necessary modules, and checking device capabilities for NFC and HCE support. It details how to manage the HCE service lifecycle, specifically distinguishing between foreground execution—where priority is managed via `EntryAbility`—and background execution. Key technical processes include subscribing to APDU commands, processing data through callbacks, and transmitting appropriate responses. These guides are tailored for HarmonyOS developers who have a working knowledge of Cangjie and understand NFC protocols, enabling them to build robust, contactless transaction applications.
