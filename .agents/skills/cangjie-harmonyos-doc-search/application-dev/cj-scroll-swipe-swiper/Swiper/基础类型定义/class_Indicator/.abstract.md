This directory contains comprehensive API reference documentation for the Cangjie Indicator class within the ArkUI framework. It focuses on the configuration and management of navigation points for the Swiper component. The content covers essential topics such as static factory methods for creating various indicator types (DigitIndicator, DotIndicator), instance methods for positioning (bottom, left, right, end), and specific functions for layout control (start, top). Key concepts include adaptive layout behaviors, interaction height defaults, and priority rules for positioning attributes. This documentation is specifically suitable for ArkUI developers using the Cangjie language who need to implement and customize carousel indicator layouts with precise control over placement and behavior. By referencing these files, developers can effectively manage the visual presentation and interaction logic of navigation indicators in their applications.
