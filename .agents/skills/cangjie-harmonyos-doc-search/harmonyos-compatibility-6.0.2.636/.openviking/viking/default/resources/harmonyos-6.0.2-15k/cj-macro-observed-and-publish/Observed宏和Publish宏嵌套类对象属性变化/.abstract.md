This directory provides a comprehensive technical guide on using the `@Observed` and `@Publish` macros in the Cangjie programming language to manage state within nested class objects and arrays. It addresses the complexities of two-way data binding and reactive UI updates that go beyond simple state management. The content covers implementation specifications, behavioral mechanics, common troubleshooting issues, and specific usage constraints. It is designed for Cangjie developers and ArkUI framework users who need to build responsive user interfaces with complex data models and deep object hierarchies.
