This directory serves as a comprehensive technical reference for the specification of symmetric key generation and conversion processes. It focuses on the precise definitions required to implement cryptographic operations securely. The content covers a range of standard algorithms, including AES, 3DES, SM4, and HMAC, providing detailed insights into their respective key lengths, security attributes, and necessary parameter string formats. A core aspect of this specification is the use of concatenated strings—such as AES256 or HMAC|SHA256—to accurately define key specifications during the creation of generators. Furthermore, it addresses the nuances of HMAC key generation, specifically regarding digest-aligned keys versus arbitrary lengths. This documentation is primarily designed for software developers and system architects utilizing API version 12 or higher who require a reliable guide for implementing robust cryptographic key generation mechanisms within their software solutions.
