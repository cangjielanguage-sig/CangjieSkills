# 完整示例

This directory serves as a comprehensive repository for complete code examples and technical documentation focused on Bluetooth Low Energy (BLE) development. Specifically, it targets the HarmonyOS and OpenHarmony ecosystems, providing full-stack implementations for both GATT Client and GATT Server roles. The content covers essential workflows such as device discovery, connection establishment, service configuration, and data interaction using modern languages like ArkTS and Cangjie. It is an ideal resource for software developers, IoT engineers, and system architects seeking to implement robust, production-ready Bluetooth communication protocols in their applications, ensuring they understand both ends of the communication channel.

## Detailed Description

### 客户端/

This directory provides an extensive collection of technical documentation and practical code examples dedicated to building Bluetooth Low Energy (BLE) GATT clients. The primary focus is on the HarmonyOS ecosystem, utilizing languages such as ArkTS and Cangjie. The examples guide developers through the entire client-side lifecycle, starting from connection management and service discovery to more complex operations like reading and writing characteristics, handling descriptors, and managing notifications. By providing specific logic for state management and asynchronous callbacks, this content ensures that developers can create responsive and stable IoT or mobile applications that maintain robust Bluetooth connectivity and handle resource cleanup efficiently.

### 服务端/

This directory offers a complete set of technical documentation and code examples for implementing Bluetooth Low Energy (BLE) GATT Server functionality. It covers the full lifecycle of a BLE server, guiding developers through the initial setup, service and characteristic configuration, and the handling of read/write requests from connected clients. The content also addresses connection state management and proper resource cleanup to ensure system stability. Examples are provided in multiple languages relevant to the OpenHarmony ecosystem, including Cangjie and ArkTS, with potential references to Kotlin or Swift. This makes the directory suitable for software developers and system engineers aiming to build reliable, server-side Bluetooth applications for HarmonyOS or compatible platforms.
