# cj-apis-bluetooth-socket

This directory provides essential API reference documentation for the HarmonyOS Bluetooth Socket module, explicitly designed for the Cangjie programming language ecosystem. It focuses on the practical implementation of the Serial Port Profile (SPP), a standard protocol for Bluetooth communication that allows devices to simulate serial cable connections. The content encompasses a wide range of functionalities, including the management of server and client sockets, the transmission of data streams, and the handling of various socket events. Key components detailed within include configuration classes such as `SppOptions`, enumerations defining different link types, and core functions for managing the connection lifecycle like `sppConnect`, `sppListen`, and `sppAccept`. This resource is ideal for developers leveraging the ConnectivityKit to create sophisticated, Bluetooth-enabled applications, provided they have a working knowledge of Cangjie syntax and general Bluetooth networking concepts.
