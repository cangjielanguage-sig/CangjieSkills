# deriving_user_guide

This directory serves as a comprehensive resource and user guide for the Cangjie programming language, specifically focusing on the powerful `@Derive` attribute and its extensive capabilities. It provides detailed guides and practical examples on how to automatically implement common interfaces, significantly reducing boilerplate code for developers. Key topics include field collection rules, customizing output order, and handling generic types with constraints. The content covers essential attributes like `@DeriveExclude`, `@DeriveInclude`, and `@DeriveOrder` to fine-tune code generation. This guide is highly suitable for Cangjie developers seeking to enhance type safety and streamline the implementation of standard behaviors such as `ToString`, `Hashable`, and `Equatable` through efficient macro-based automation. By mastering these tools, developers can write cleaner, more maintainable code while leveraging the compiler to handle repetitive implementation tasks.
