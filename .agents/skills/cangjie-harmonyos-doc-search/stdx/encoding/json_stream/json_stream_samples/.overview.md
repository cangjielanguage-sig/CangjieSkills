# json_stream_samples

This directory contains a comprehensive collection of code samples demonstrating JSON stream processing within the Cangjie programming language. It covers the full lifecycle of JSON handling, including reading (deserialization), writing (serialization), and configuration for output formatting. The examples focus on efficient, manual parsing and generation techniques using core interfaces like `JsonDeserializable` and `JsonSerializable`. These resources are ideal for Cangjie developers seeking to implement robust JSON data handling, optimize performance with streaming, or customize output readability in their applications.

## Detailed Description

### [1] sample_json_reader
This directory provides a complete example of JSON stream deserialization in the Cangjie programming language. It details how to perform fine-grained manual parsing of JSON data by implementing the `JsonDeserializable` interface and combining it with the `JsonReader` tool. This approach allows for precise control over the parsing process, which is essential for handling complex or non-standard JSON structures efficiently. The content covers the conversion process from basic strings to complex objects, focusing on demonstrating how to use core methods such as `peek`, `startObject`, `readName`, and `readValue` to handle various data structures including `Option`, `Bool`, `Array`, and `HashMap`. This resource is highly suitable for Cangjie developers looking for efficient JSON processing solutions, serving as a practical guide for implementing custom deserialization logic.

### [2] sample_json_writeconfig
This directory primarily demonstrates how to utilize `WriteConfig` in the Cangjie programming language to beautify JSON output formats. The content covers the construction of `JsonWriter`, the setting of `WriteConfig.pretty` configuration, and the implementation of the `JsonSerializable` interface. It explains the step-by-step process of configuring the writer to ensure the output is human-friendly. By setting `writer.writeConfig` to `WriteConfig.pretty`, developers can generate readable JSON strings with proper indentation and line breaks, which is crucial for logging and debugging. This documentation is suitable for Cangjie developers who need to handle JSON serialization and are concerned with output readability. Core keywords include Cangjie, JSON serialization, and pretty printing.

### [3] sample_json_writer
This directory provides a complete example of JSON stream processing in the Cangjie language, focusing on demonstrating how to efficiently serialize custom objects into JSON format. The document details the standard process for implementing the `JsonSerializable` interface and provides an in-depth explanation of how to use methods provided by `JsonWriter`, such as `startObject`, `writeName`, and `writeValue`, to finely construct JSON data structures. Furthermore, it covers technical details regarding low-level output through `ByteBuffer`, offering insights into performance optimization for data writing. This is a practical tutorial aimed at Cangjie developers, designed to help those with basic syntax and IO operation knowledge master JSON writing techniques.
