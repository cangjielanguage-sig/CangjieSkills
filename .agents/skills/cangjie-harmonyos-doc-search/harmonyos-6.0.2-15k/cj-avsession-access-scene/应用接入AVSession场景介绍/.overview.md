# 应用接入AVSession场景介绍

This directory provides a comprehensive technical guide for developers integrating the AVSession Kit into HarmonyOS applications. It covers essential scenarios for audio and video playback, including background task management, metadata configuration, playback state synchronization, and media control handling. The documentation details how to use the BackgroundTasks Kit for continuous playback, register system commands, and adapt to hardware key events. Designed for application developers using the Cangjie language, these resources ensure seamless interaction with the system's media playback center, notification center, and external devices like Bluetooth headsets.

## Detailed Description

### 创建后台任务.md 创建后台任务.md
This document serves as a technical guide for developers on creating background tasks to prevent application suspension during specific operations like media playback. It focuses on utilizing the BackgroundTasks Kit to apply for long-running tasks. The key takeaway is that media playback scenarios specifically require applying for the AUDIO_PLAYBACK BackgroundMode to ensure continuous operation. Intended for application developers working on background functionality, this document assumes familiarity with system APIs and task management concepts. Keywords include BackgroundTasks Kit, long-running tasks, AUDIO_PLAYBACK, suspension, and media playback.

### 应用接入AVSession场景介绍_4more.md 应用接入AVSession场景介绍_4more.md
This technical guide outlines the scenarios and integration steps for AVSession Kit, enabling audio/video applications to manage media sessions and system playback controls. It details mandatory usage for long-form media and VOIP to avoid system constraints, and optional usage for games. The document covers the integration workflow, including creating sessions, setting metadata and playback states, and registering commands. It explains how different session types (Audio, Video, Voice Call) dictate the playback center's UI and provides a Cangjie code example for session creation. This guide is intended for developers implementing media playback and background task management.

### 设置元数据.md 设置元数据.md
This technical guide explains how to configure and update media metadata for audio sessions using the AVSessionKit in the Cangjie programming language. It covers three specific areas: general metadata (title, artist, album), synchronized lyrics (LRC format), and media resource gold tags (AudioVivid identifiers). The core functionality relies on the `setAVMetadata` method to populate the system's playback control center. Code examples demonstrate initializing `AVMetadata` objects and setting specific properties like `lyric` and `displayTags`. This tutorial targets application developers building audio features who need to integrate with system-level playback controls and display rich media information.

### 适配媒体通知.md 适配媒体通知.md
This document outlines the system behavior for media control notifications, serving as a technical guide for developers. It explains that the system automatically sends and manages media notifications in the notification center and lock screen once an application properly integrates with the media playback center. The key takeaway is that developers do not need to implement direct notification sending; the system controls the display and lifecycle of these playback cards. This information is crucial for developers building media apps to understand the automatic interface updates. Keywords: media notifications, media playback center, system lifecycle, lock screen, notification center, app integration.

### 注册控制命令/
This directory provides technical guides for implementing media control commands using the AVSessionKit framework in HarmonyOS. It covers essential playback functionalities such as registering system commands, handling loop modes, managing fast forward and rewind operations, and implementing progress seeking. The documents include Cangjie code examples to demonstrate how to synchronize application states with the system control center and handle user interactions effectively. This resource is intended for developers building multimedia applications who need to integrate standard media controls and ensure seamless state management.

### 设置播放状态/
This directory serves as a comprehensive technical resource for configuring and managing media playback states within a system control center, utilizing the Cangjie language and the AVSessionKit framework. It addresses the core requirements for multimedia application development, such as synchronizing playback status, implementing progress bars, and managing metadata. The documentation delves into specific implementation details, including handling state attributes like position and speed, managing buffering, and dealing with special scenarios like trial listening and advertisements. By providing code examples and explaining system calculation logic, it guides developers on when to update the `AVPlaybackState` to ensure accurate UI representation. This content is specifically designed for application developers and engineers who are building media applications and need to integrate their custom playback logic with the system's native control center for a cohesive user experience.

### 适配蓝牙按键与有线按键事件/
This directory provides comprehensive technical documentation on adapting applications to handle media key events originating from both Bluetooth and wired input devices. It centers on the utilization of the AVSession framework within the Cangjie development environment. The content covers two primary implementation approaches: the recommended method using AVSession control commands for automatic event conversion, and the alternative method involving manual KeyEvent handling. Key technical aspects include defining callback classes, initializing audio sessions, and the critical requirement of setting AVMetadata to ensure event reception. This guide is specifically designed for application developers who need to integrate robust media control features, ensuring their apps respond correctly to external hardware controls like play, pause, and stop buttons. By following these guides, developers can ensure seamless synchronization between their application's playback state and user interactions via physical media keys, ultimately enhancing the user experience for media playback applications.
