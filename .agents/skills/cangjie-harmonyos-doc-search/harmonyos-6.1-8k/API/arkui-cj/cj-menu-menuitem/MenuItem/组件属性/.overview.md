### func_contentFontL_5more_e9cf304f.md
这是一份ArkUI框架下的Cangjie语言API参考文档，旨在定义菜单项的字体样式、颜色及选中状态。文档涵盖了五个主要函数：contentFont和labelFont用于配置内容与标签的字体属性（如尺寸、粗细、字族），contentFontColor和labelFontColor用于设置文本颜色，selected用于控制选中状态。关键信息包括参数的具体类型（如Length、ResourceColor）、默认值（如16.vp、HarmonyOS Sans）及系统能力要求。该文档面向ArkUI应用开发者，提供了精细化的UI组件样式配置接口，适用于构建具有自定义外观的菜单交互界面。

### func_selectIconBo_2more_e9ded07d.md
这是一份Cangjie语言的API参考文档，旨在定义菜单项选中状态的图标显示逻辑。文档主要包含两个重载函数部分，分别接受?Bool和?ResourceStr类型的参数。关键信息指出，前者用于控制是否显示图标（默认false），后者用于指定具体的图标资源（默认空字符串），两者均属于ArkUI.Full系统能力。该文档面向使用ArkUI框架的开发者，提供了自定义菜单UI样式的具体接口说明。关键词：API文档、Cangjie、ArkUI、selectIcon、菜单项、UI组件、函数重载。
