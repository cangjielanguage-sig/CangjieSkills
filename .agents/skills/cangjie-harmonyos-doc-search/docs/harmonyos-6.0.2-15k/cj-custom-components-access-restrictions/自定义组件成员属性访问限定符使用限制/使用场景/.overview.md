# 使用场景

This directory provides technical documentation and coding references for specific usage scenarios within the Cangjie programming language, primarily focusing on state management in UI component development. It details the strict validation rules governing access modifiers—such as private and public—when used in conjunction with state management macros like @State, @Prop, @Link, and @StorageLink. The content explains how incorrect modifier usage leads to compiler errors and offers corrected code examples to demonstrate proper implementation. These resources are essential for Cangjie developers building HarmonyOS applications, ensuring they correctly handle component state synchronization and adhere to syntactic constraints to avoid compilation failures. By understanding these rules, developers can effectively manage data flow between parent and child components while maintaining code integrity.

## Detailed Description

### 使用场景_1.md
This document serves as a coding reference guide for the Cangjie language, specifically detailing validation rules regarding access modifiers and state management macros. It covers three main scenarios: the incompatibility of the private modifier with macros like @State, @Prop, @Provide, @BuilderParam, and @Link, and the incompatibility of the public modifier with @StorageLink, @StorageProp, @LocalStorageLink, @LocalStorageProp, and @Consume. Key takeaways are that these specific combinations trigger compiler errors, requiring developers to omit explicit access modifiers for these state variables. The target audience is Cangjie developers working on UI components who need to adhere to these syntactic constraints to ensure successful compilation.

### 使用场景_2.md
This document illustrates the correct usage of the @Link decorator in Cangjie component state management by contrasting incorrect and correct code implementations. It features an Anti-example demonstrating a compilation error caused by using the private modifier, and a Positive Example showing the corrected code. The key takeaway is that variables decorated with @Link in a child component cannot be private, as they require external access from the parent component to synchronize state. This guide targets Cangjie developers working with HarmonyOS UI components who need to understand state synchronization rules and access modifiers. Keywords: Cangjie, @Link, state management, access modifier, private, HarmonyOS, component, parent-child.
