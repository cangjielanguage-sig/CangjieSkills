This directory provides comprehensive API reference documentation for the `HapModuleInfo` struct within the Cangjie programming language and the HarmonyOS BundleManager framework. It details the structure used to encapsulate information about Harmony Ability Package (HAP) modules. The documentation covers a wide range of read-only properties, including module metadata (such as name, icon, and label), component details (abilities and extension abilities), runtime dependencies, and specific configuration settings like router maps and native library paths. It also outlines version requirements and retrieval methods. This resource is essential for application developers who need to programmatically access, query, and manage HAP module configurations and system-level resources to build robust applications.
