This directory provides comprehensive API reference documentation for the `AVCastControlCommandType` enum within the Cangjie programming language's multimedia framework. It is designed to assist developers in managing audio-video casting commands by defining specific values for playback controls (such as play, pause, stop), navigation (seek, next, previous), and various settings (volume, speed, loop mode, mute). The documentation covers the enum's inheritance from `Equatable`, `Hashable`, and `ToString`, alongside utility functions for object identification. This resource is suitable for developers implementing casting control logic, specifically those working with the `SystemCapability.Multimedia.AVSession.AVCast` capability starting from API version 19. It serves as a technical guide for ensuring proper implementation of casting features in multimedia applications.
