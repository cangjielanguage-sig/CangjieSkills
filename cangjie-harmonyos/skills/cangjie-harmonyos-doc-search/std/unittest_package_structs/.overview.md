## Detailed Description

### 结构体/

This directory contains API documentation for Cangjie language structs used primarily within the unittest and benchmarking frameworks. It covers input management providers like `BatchInputProvider` and `ImmutableInputProvider`, performance measurement tools such as `CpuCycles` and `TimeNow`, and a comprehensive set of configuration key structs for customizing test execution. These resources are essential for developers implementing custom benchmarks, managing test data, or configuring unit test parameters like coverage guidance, timeouts, and reporting formats. The documentation provides structural definitions and usage guidance for optimizing performance testing accuracy and framework configuration. By leveraging these documented structs, users can ensure their testing setups are both robust and tailored to specific performance metrics, ultimately leading to more reliable and maintainable code within the Cangjie ecosystem.
