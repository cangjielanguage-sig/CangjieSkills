# Contacts_Kit开发概述

This directory provides a comprehensive development overview for the Contacts Kit on HarmonyOS, designed to assist developers in integrating robust contact management features into their applications. It covers the kit's core capabilities, specifically distinguishing between the universally accessible Picker interface and the restricted contact management functions (CRUD). The documentation includes practical Cangjie code examples for importing modules, obtaining UIAbilityContext, and invoking APIs. It targets HarmonyOS application developers looking to implement contact selection or management, highlighting the specific permissions required for direct data manipulation and the necessary steps for ACL application. The guides ensure developers understand the security implications and technical requirements for accessing user contact data.

The content includes Cangjie code examples demonstrating how to acquire the UIAbility context, request user authorization via AbilityAccessCtrl, and execute contact operations such as adding and deleting entries.
