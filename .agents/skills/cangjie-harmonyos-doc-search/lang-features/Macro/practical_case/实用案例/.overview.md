## 详细描述

### 一个_dprint_宏的扩展_02a74cc0.md 一个_dprint_宏的扩展_02a74cc0.md
本文档是一篇 Cangjie 语言宏编程教程，旨在演示如何扩展 dprint 宏以支持多个逗号分隔的表达式。文档重点介绍了使用 parseExprFragment 配合 while 循环解析输入 Token 流的逻辑，包括索引跟踪、逗号验证及代码生成。通过提供实现代码、使用案例及输出结果，帮助开发者理解宏的执行过程。本文适合具备 Cangjie 基础并希望掌握元编程技术的开发者阅读。关键词：Cangjie, 宏, parseExprFragment, 元编程。

### 一个简单的_DSL.md 一个简单的_DSL.md
这份文档是一个教程，旨在演示如何使用仓颉语言的宏实现一个简单的领域特定语言（DSL），模仿 LINQ 查询语法。文档主要涵盖目标语法定义、宏的解析与校验逻辑、代码生成过程及使用示例。关键信息展示了宏如何通过解析 Tokens（如 from, in, where, select）将 DSL 语句转换为标准的 for 循环和条件判断。文档通过筛选奇数并输出平方的案例，说明了宏在语法扩展和元编程中的应用。这适合希望了解宏机制和 DSL 设计的开发者阅读。

### 快速幂的计算.md 快速幂的计算.md
这份文档是一份教程，旨在演示如何使用仓颉语言的宏功能进行编译期求值，以优化快速幂计算。文档对比了传统的运行时循环实现与手动展开的优化代码，重点讲解了自定义宏 `@power` 的实现，包括解析属性、使用 `quote` 生成代码及测试用例。关键信息在于宏通过编译期逻辑生成无循环、无条件判断的高效乘法代码，从而提升性能。本文适合希望掌握仓颉元编程和编译期优化技术的开发者阅读。

### Memoize_宏/
本目录包含关于仓颉语言中 Memoize 宏的技术文档，旨在通过宏自动化实现算法的记忆化优化。内容涵盖了记忆化的基本概念、斐波那契数列的性能对比、宏展开代码的深度分析，以及基于 std.ast 的完整宏源码实现。核心要点在于利用 HashMap 缓存计算结果以避免重复计算，从而显著提升递归效率，并详细展示了如何通过 AST 操作生成代码。此外，还深入探讨了输入合法性检查及代码生成的具体步骤。这些文档适合熟悉仓颉语法的开发者学习宏编程及性能优化技巧。
