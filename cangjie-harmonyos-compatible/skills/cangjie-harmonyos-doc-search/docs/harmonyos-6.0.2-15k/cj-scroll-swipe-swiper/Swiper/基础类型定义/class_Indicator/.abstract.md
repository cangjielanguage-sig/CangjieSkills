This directory provides comprehensive API reference documentation for the Cangjie Indicator class within the ArkUI framework. It is designed to assist developers in configuring the positioning, style, and layout behavior of navigation dots used within Swiper components. The documentation covers essential topics such as static factory methods for creating DigitIndicator and DotIndicator objects, instance methods for precise placement (including bottom, end, left, and right), and handling layout behaviors like RTL/LTR support and property priority rules. This resource is specifically suitable for ArkUI developers using the Cangjie language who require detailed customization of Swiper navigation indicators for cross-platform user interfaces.
