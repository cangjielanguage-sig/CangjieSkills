# enum_Orientation

This directory contains essential API reference documentation for the `Orientation` enumeration within the WindowManager module, specifically designed for developers using the Cangjie language. It provides a detailed breakdown of constants and types used to control screen rotation and display direction. The content covers a broad spectrum of orientation behaviors, including static portrait and landscape modes, dynamic sensor-based auto-rotation, and restricted axis variants. Additionally, it documents specific user rotation modes that allow applications to temporarily force a specific orientation before reverting to system defaults. This documentation is suitable for software developers and UI engineers who need to implement robust window management logic, handle sensor dependencies, and manage display behaviors responsive to system control center settings and hardware capabilities.

## Detailed Description

### USER_ROTATION_PORTRAIT_5more.md USER_ROTATION_PORTRAIT_5more.md
This API reference document defines enumeration constants for controlling screen rotation modes within the WindowManager module. The content details five specific orientation modes: standard and inverted portrait, standard and inverted landscape, and a mode to follow the desktop. Key information indicates that user rotation modes temporarily force a specific orientation before reverting to sensor-based auto-rotation, contingent upon system control center settings and hardware capabilities. All constants are available starting from version 19. This documentation is intended for software developers using the Cangjie language to manage window display behaviors and orientation logic in their applications.

### enum_Orientation_14more.md enum_Orientation_14more.md
This API reference document defines the Orientation enum in Cangjie, specifying window display direction types for the WindowManager system. It details 17 enum values, including static modes like PORTRAIT and LANDSCAPE, dynamic sensor-based modes like AUTO_ROTATION, and restricted variants. Key information includes specific behaviors for each mode, such as sensor following, control center dependencies, and axis restrictions. For example, AUTO_ROTATION_LANDSCAPE allows only horizontal rotation. This document is intended for developers working on window management interfaces who need to programmatically control screen orientation behavior.
