# 结构体

本目录包含Cangjie语言Crypto包中与X.509证书、密钥及PEM格式处理相关的核心结构体API参考文档。内容涵盖了证书数据封装（如DerBlob、X509CertificateInfo）、密钥用途定义（KeyUsage、ExtKeyUsage）、PEM编解码（Pem、PemEntry）以及证书验证配置（VerifyOption）等关键数据结构。这些文档详细说明了各结构体的属性、构造函数及操作方法，旨在为开发者提供处理数字证书、签名请求及加密通信的基础数据支持。适合使用Cangjie语言进行安全开发、证书管理或密码学应用构建的程序员参考。

## 详细说明

### struct_DerBlob.md struct_DerBlob.md
本文档是Cangjie语言Crypto包中DerBlob结构体的API参考文档，旨在说明如何封装和操作二进制证书流数据。文档详细介绍了结构体的定义、属性（body和size）、构造函数以及哈希和比较操作符（==, !=）。DerBlob实现了Equatable和Hashable协议，核心功能是将二进制数据解析为X509Certificate、X509CertificateRequest或密钥对象。该文档面向需要进行X.509证书和密钥处理的开发人员，提供了基础数据结构的操作指南。

### struct_ExtKeyUsage_5f0496bb.md struct_ExtKeyUsage_5f0496bb.md
本文档提供了Cangjie语言中ExtKeyUsage结构体的API参考文档，用于定义数字证书的扩展密钥用法。文档详细列出了该结构体的静态常量（如ServerAuth、ClientAuth、CodeSigning等）、构造函数以及将用途转换为字符串的方法。关键信息包括定义了SSL验证、电子邮件保护、代码签名等七种具体用途的UInt16常量值，并指出同一密钥可具备多种用途。该文档面向使用Cangjie语言进行加密或证书管理开发的程序员，属于技术参考手册。

### struct_KeyUsage.md struct_KeyUsage.md
本文档是Cangjie语言中KeyUsage结构体的API参考文档，旨在定义数字证书扩展字段中公钥的用法。主要内容包括DigitalSignature、KeyEncipherment、CertSign等九个静态常量，分别对应数字签名、密钥加密、证书签名等具体操作，以及用于组合这些用途的构造函数init和toString方法。关键信息在于同一个密钥可通过按位或操作支持多种用途，且特定标志（如EncipherOnly）需配合KeyAgreement使用。该文档面向处理数字证书和加密功能的开发人员，提供了配置密钥用法扩展的详细规范。

### struct_Pem.md struct_Pem.md
本文档提供了 Cangjie 语言中 Pem 结构体的 API 参考文档，用于处理 PEM 格式数据，将其表示为条目序列。文档涵盖了结构体定义、size 属性以及构造函数、静态 decode 方法、encode 方法、isEmpty、iterator 和 toString 等成员函数。该结构体实现了 Collection 和 ToString 接口，支持将 PEM 字符串解码为 PemEntry 对象序列或将序列编码回字符串，并在数据为空或解码失败时抛出 X509Exception。面向使用 x509 包进行加密操作的开发者，需具备 Cangjie 语言基础及 PEM 格式相关知识。

### struct_SerialNumb_2more_034acb09.md struct_SerialNumb_2more_034acb09.md
本文档是Cangjie语言中X.509数字证书相关结构体的API参考文档，旨在定义用于证书标识和验证的数据结构。文档主要包含SerialNumber和Signature两个结构体部分。关键信息包括SerialNumber支持1-20字节长度的随机生成及十六进制转换，且遵循RFC 5280规范；Signature则封装二进制签名数据用于身份验证，两者均实现了相等性判断和哈希计算。该文档面向使用Cangjie进行安全开发或证书处理的开发者，提供了详细的接口规范、参数限制及异常处理说明。

### struct_VerifyOption_c469e9a1.md struct_VerifyOption_c469e9a1.md
这份文档定义了Cangjie语言中的VerifyOption结构体，旨在为X.509证书验证函数提供配置选项。文档主要涵盖了该结构体的定义及其四个公共属性：dnsName、intermediates、roots和time。关键信息包括roots默认使用系统根证书，dnsName仅在设置时进行校验，time默认为当前时间，这些属性共同控制证书验证的行为。这是一份API参考文档，面向需要在Cangjie项目中实现安全通信和证书链验证逻辑的开发者。

### struct_X509CertificateRequestInfo.md struct_X509CertificateRequestInfo.md
本文档提供了Cangjie语言中X509CertificateRequestInfo结构体的API参考，该结构体用于封装X.509证书签名请求所需的信息。文档涵盖了结构体定义、成员变量（包括主体名称、DNS域名、电子邮件地址和IP地址）以及构造函数的详细说明。关键信息包括各字段的数据类型、构造函数的默认参数设置，以及在输入无效IP地址时会抛出X509Exception异常的机制。该文档面向使用X509包处理证书请求的开发者，需要具备Cangjie语言基础及X.509标准的背景知识。

### struct_PemEntry/
本目录包含Cangjie语言中`PemEntry`结构体的API参考文档，专注于PEM（Privacy-Enhanced Mail）格式数据的表示与处理。内容涵盖了结构体的定义、构造函数、核心方法（如编码、头部检索）以及符合RFC 7468和RFC 1421标准的静态常量。该模块旨在帮助开发者处理X.509证书、私钥及各类加密参数。适合需要使用Cangjie进行密码学开发、证书管理或Base64编码数据处理的程序员参考。

### struct_X509CertificateInfo/
本目录包含 Cangjie 语言中 X509CertificateInfo 结构体的相关文档，主要涉及 X.509 数字证书的数据结构定义与初始化方法。内容涵盖了证书的详细属性字段（如序列号、有效期、主体信息、DNS、IP地址及密钥用法等）以及构造函数的具体参数配置和异常处理机制。这些文档旨在为开发者提供完整的 API 参考，帮助他们理解证书数据结构并进行正确的对象初始化。主要面向使用 Cangjie 语言进行加密通信、网络安全开发或需要处理数字证书的程序员。
