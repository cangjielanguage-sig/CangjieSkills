# CheckboxGroup

This directory contains documentation for the CheckboxGroup component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the API reference, event handling, property configuration, and practical implementation examples for managing collective checkbox states. Key topics include the `init` method for grouping, `onChange` events, and styling properties like `mark` and `selectedColor`. This resource is suitable for application developers and UI engineers building interactive selection controls in HarmonyOS applications who need to implement "Select All" functionality or custom checkbox styling.

## Detailed Description

### CheckboxGroup_4more.md CheckboxGroup_4more.md
This document provides API reference documentation for the CheckboxGroup component within the ArkUI framework, detailing how to manage the collective state of multiple checkboxes. It covers the component's description, sub-components, and the specific initialization method init(String). Key information includes that the init function accepts a group string parameter to link checkboxes, enabling select-all control. Crucially, it specifies that only the first CheckboxGroup with a specific name is effective and warns about manual state management when used with cached components like Lists. The component supports all generic attributes and events starting from version 12. This technical reference targets developers building UIs in the Cangjie language who need to implement grouped checkbox controls.

### 示例代码.md 示例代码.md
This document serves as a practical code tutorial for implementing checkbox groups using the Cangjie programming language within a HarmonyOS UI framework. It covers two primary scenarios: establishing a "Select All" functionality and customizing the visual appearance of the checkmark. The first example details how to link a CheckboxGroup with individual Checkboxes via a group identifier to manage selection states and handle change events. The second example extends this by demonstrating how to configure the mark property to alter stroke color, size, and width. These examples are intended for application developers seeking to implement interactive selection controls with specific styling requirements.

### 组件事件_2more.md 组件事件_2more.md
This document serves as API reference documentation for the CheckboxGroup component's onChange event within the Cangjie ArkUI framework. It details the callback function signature triggered by selection changes and defines the associated data structures. Key sections include the CheckboxGroupResult class, which encapsulates the selection status and a list of selected names, and the SelectStatus enum defining All, Part, or None states. This guide is essential for developers implementing interactive checkbox groups, providing the necessary type definitions and system capability requirements for version 12.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring properties of the CheckboxGroup component within the ArkUI framework using the Cangjie language. It details five key functions: checkboxShape, mark, selectAll, selectedColor, and unselectedColor. Key information includes parameter definitions, default values, and system capabilities. Notably, the documentation explains that child checkboxes inherit the group's shape unless explicitly overridden, and individual selection settings take precedence over the group's selectAll status. This technical reference is intended for software developers seeking to customize the appearance and behavior of checkbox groups in their applications.
