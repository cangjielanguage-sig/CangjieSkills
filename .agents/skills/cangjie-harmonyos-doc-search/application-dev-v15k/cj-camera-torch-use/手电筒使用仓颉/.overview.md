# 手电筒使用仓颉

This directory provides comprehensive technical documentation for developers implementing flashlight functionality using the Cangjie programming language and CameraKit framework. It covers the complete development lifecycle, from initial hardware capability checks and mode verification to real-time status monitoring and event handling. Key technical concepts include `isTorchSupported`, `setTorchMode`, and `TorchStatusChange` callbacks. The guides address specific usage scenarios, such as managing flashlight behavior during front and rear camera switching and handling constraints when the rear flash is disabled. These resources are specifically tailored for Cangjie developers and mobile application engineers seeking to integrate robust hardware controls and state management into their camera applications.

## Detailed Description

### 手电筒使用仓颉_2more.md 手电筒使用仓颉_2more.md
This document serves as a development guide for implementing flashlight functionality using the Cangjie programming language and CameraKit. It details usage scenarios, such as flashlight behavior when switching between front and rear cameras, and provides a step-by-step tutorial for coding. The main sections cover importing necessary interfaces, checking device hardware support via isTorchSupported, verifying specific modes with isTorchModeSupported, and controlling the torch state using setTorchMode. Key takeaways include understanding the constraints when the rear camera flash is off and the necessity of registering state listeners. This guide is intended for Cangjie developers integrating hardware controls into mobile camera applications.

### 状态监听.md 状态监听.md
This document serves as a technical guide for monitoring flashlight status changes within a camera application using the Cangjie language. It details the process of registering the TorchStatusChange event and implementing a callback to handle state updates. Key information includes the use of the TorchStatusInfo parameter, which provides data on availability, active status, and light level. The document provides a code example demonstrating how to define a TorchStatusChangeCallBack class and register it with the CameraManager. Intended for application developers, this guide requires knowledge of camera APIs and event handling to effectively track flashlight states such as open, close, and availability.
