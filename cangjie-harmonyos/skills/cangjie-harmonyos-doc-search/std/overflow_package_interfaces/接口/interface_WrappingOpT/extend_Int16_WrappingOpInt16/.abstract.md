This directory contains comprehensive API documentation for the `WrappingOp` interface implementation and specific arithmetic functions tailored for the `Int16` type in the Cangjie programming language. It covers a wide range of operations, including addition, subtraction, multiplication, division, modulo, increment, decrement, negation, and bitwise shifts. The primary focus is on handling integer overflow through high-order truncation strategies, ensuring results always fit within the `Int16` type without raising runtime errors. This resource is suitable for Cangjie developers, particularly those engaged in systems programming or low-level arithmetic who require precise control over integer behavior.
