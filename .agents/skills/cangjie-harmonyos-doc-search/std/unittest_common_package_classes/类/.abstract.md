This directory contains API reference documentation for core classes within the Cangjie unittest framework. It primarily focuses on configuration management and text formatting utilities. Key components include classes for handling test configuration data (`Configuration`, `ConfigurationKey`) and tools for generating structured, readable console output (`PrettyText`, `PrettyPrinter`). These resources are designed for Cangjie developers who need to programmatically manage test settings or implement custom reporting and output formatting in their unit testing workflows.
