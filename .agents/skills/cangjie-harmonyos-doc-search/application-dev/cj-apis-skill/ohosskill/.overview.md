# ohosskill

This directory provides comprehensive API reference documentation for the `ohos.skill` module within the HarmonyOS framework, specifically tailored for the Cangjie programming language. It focuses on the core classes required for system-level skill management and URI routing. The documentation covers the `Skill` class for handling skill tag objects and the `SkillUri` class for defining URI structures, including advanced matching features like path regex and MIME types. Designed for HarmonyOS developers, these resources assist in implementing inter-app jumping, data matching, and bundle information management. Keywords include API reference, Cangjie, Skill class, URI routing, BundleManager, and HarmonyOS development.

## Detailed Description

### class_SkillUri.md
This API reference document defines the Cangjie class SkillUri, which describes and identifies URI information within the system. It details the class structure and specifications for ten read-only properties, covering standard URI components like scheme, host, port, and path, alongside advanced matching features such as pathRegex and pathStartWith. Key information includes dependency rules where properties like host and path only activate if preceding components exist, as well as data type identification using MIME and UniformDataType standards. The document also addresses file handling limits and inter-app jumping capabilities. Intended for developers working with the BundleManager framework, this reference assists in implementing URI routing, data matching, and application linking features.

### ohosskill_4more.md
This document provides API reference documentation for the ohos.skill module in the Cangjie programming language, detailing the Skill class used for handling skill tag objects within the HarmonyOS framework. It covers module imports, usage instructions for example code, and a comprehensive breakdown of the Skill class properties including actions, entities, uris, and domainVerify. Key information indicates that the Skill object is retrieved via getBundleInfoForSelf and requires specific bundle flags, with all properties being read-only. This targets HarmonyOS developers using the Cangjie language who need to manage bundle information and skill matching logic.
