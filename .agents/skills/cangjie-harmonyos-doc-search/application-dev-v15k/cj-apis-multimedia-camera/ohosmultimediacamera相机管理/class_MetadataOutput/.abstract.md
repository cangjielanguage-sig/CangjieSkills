This directory contains API reference documentation for the `MetadataOutput` class within the CameraKit framework, specifically designed for the Cangjie programming language. It covers the management of metadata streams, including event listener registration, unsubscription, and lifecycle control. Key topics include handling detected metadata objects, error callbacks, and resource management methods like start, stop, and release. This documentation is suitable for developers building camera applications who need to integrate metadata detection features and manage camera output streams efficiently.
