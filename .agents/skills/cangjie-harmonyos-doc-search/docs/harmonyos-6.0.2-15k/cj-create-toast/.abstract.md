This directory serves as a comprehensive technical resource for Cangjie developers utilizing the ArkUI framework, specifically focusing on the implementation and management of Toast notifications via the PromptAction class. The documentation provides an in-depth analysis of the architectural and design considerations necessary to create effective, non-intrusive user feedback mechanisms. It thoroughly explores the distinctions between DEFAULT and TOP_MOST display modes, clarifying how TOP_MOST establishes a sub-window with a higher hierarchy and distinct keyboard avoidance behaviors compared to the in-app DEFAULT mode. Furthermore, the guide emphasizes the importance of adhering to system positioning standards and advises against the inclusion of long text or interactive elements within notifications. By integrating practical code examples with detailed usage recommendations, this guide equips developers with the knowledge required to optimize user interaction flows and ensure strict compliance with ArkUI best practices. It is an essential reference for ensuring application stability and user satisfaction, particularly when dealing with complex UI layouts.
