# concurrency_overview

本目录提供了关于仓颉编程语言并发编程机制的全面概述，重点阐述了其核心线程模型的设计理念与实现细节。文档深入探讨了语言线程与原生线程的本质区别，详细解析了M:N线程模型的工作原理，即如何将轻量级的语言线程高效映射到原生线程上执行。此外，内容还涵盖了线程的抢占式调度策略以及阻塞机制的处理方式。该文档特别适合仓颉语言开发者阅读，尤其是那些致力于开发高并发应用或涉及跨语言交互（如调用Foreign Function Interface）的开发人员，旨在帮助他们理解并发模型，避免因不当操作导致系统吞吐量下降。

## 详细说明

### concurrency_overview.md concurrency_overview.md

本文档旨在介绍仓颉编程语言的并发编程机制及其核心线程模型。文档涵盖了语言线程与native线程的区别、M:N线程模型的实现原理，以及线程调度与阻塞机制。关键信息指出，仓颉采用M:N模型，将轻量级的语言线程映射到native线程上执行，支持抢占式调度。开发者通常只需关注语言线程，但在跨语言编程时必须避免调用阻塞式foreign函数，因为这会阻塞底层native线程并降低吞吐量。本文面向仓颉语言开发者，特别是涉及并发及跨语言交互的开发人员。
