This directory serves as a comprehensive API reference for core interfaces within the Cangjie programming language standard library. It focuses on type conversion and string manipulation capabilities, specifically covering the `Formattable`, `Parsable`, and `RadixConvertible` interfaces. These documents detail how to convert data types to strings, parse strings back into types, and handle numeric conversions across different radix systems. This resource is essential for Cangjie developers seeking to implement robust data formatting, parsing logic, and error handling for primitive numeric and character types in their applications.
