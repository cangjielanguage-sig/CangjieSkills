This directory provides API reference documentation for the `ohoscommon_event_manager` module within the HarmonyOS ecosystem, specifically designed for the Cangjie programming language. It covers the essential components for managing common events, including publishing, subscribing, and handling system-level notifications. Key topics include event data structures, subscriber configuration, and system event constants. This documentation is suitable for Cangjie developers and system engineers building event-driven applications or implementing inter-process communication (IPC) using the BasicServicesKit.
