This directory provides comprehensive API documentation for the `JSType` struct in the Cangjie programming language, specifically designed for the ArkUI framework. It serves as a reference for handling ArkTS data types within the SystemCapability.ArkUI.ArkUI.Napi environment. The documentation details the enumeration of standard JavaScript types—such as Undefined, Null, Number, Boolean, and Object—and includes utility methods for type comparison and string representation. It is designed for Cangjie developers who need to implement robust type checking and identification mechanisms when interacting with JavaScript values via Napi. The resources provided cover operator overloads and struct definitions available starting from version 12.
