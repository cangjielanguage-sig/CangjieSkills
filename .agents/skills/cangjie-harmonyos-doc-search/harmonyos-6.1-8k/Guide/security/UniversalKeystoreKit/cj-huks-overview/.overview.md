# cj-huks-overview

本目录包含通用密钥库套件（HUKS）的概览文档，旨在为应用提供统一的密钥管理及安全操作能力。HUKS 是系统中至关重要的安全基础设施，内容涵盖了其分层架构（SDK、服务层、核心层）以及密钥全生命周期的核心功能，包括密钥生成、使用（如加解密、签名、密钥协商、派生）、删除和证明。该套件严格确保密钥明文仅在可信执行环境（TEE）等安全环境中被访问，核心层依赖硬件支持，开源版本则提供模拟实现。本文档主要面向需要安全密钥存储和密码学运算能力的开发者，作为深入理解 HUKS 架构设计与功能特性的概念性指南。
