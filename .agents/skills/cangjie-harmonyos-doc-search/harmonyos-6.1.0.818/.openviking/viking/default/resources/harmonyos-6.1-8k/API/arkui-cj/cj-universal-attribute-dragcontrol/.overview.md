# cj-universal-attribute-dragcontrol

本目录包含了ArkUI框架中关于拖拽控制属性的详细API参考文档，专为使用仓颉语言进行应用开发的工程师设计。文档的核心重点在于`dragPreview`函数，这是一个关键的API，允许开发者通过传入组件ID来精确控制拖拽过程中显示的预览图像。内容不仅涵盖了该函数的参数类型定义、返回值说明以及调用所需的系统能力，还深入探讨了技术实现的细节。例如，文档详细阐述了当组件ID无效或组件处于隐藏状态时的回退截图机制，确保了交互的鲁棒性。同时，它也明确指出了截图结果不包含亮度调整、阴影渲染等特定视觉效果的局限性。这份资料对于任何希望在ArkUI应用中实现精细化、自定义组件拖拽交互功能的开发者来说，都是不可或缺的参考资源。

## 详细说明

### cj-universal-attribute-dragcontrol.md cj-universal-attribute-dragcontrol.md

这是一份ArkUI框架中拖拽控制属性的API参考文档，旨在指导开发者使用仓颉语言设置组件的拖拽预览图。文档主要介绍了`dragPreview`函数，详细说明了其参数类型、返回值及系统能力要求。关键信息包括通过传入组件ID将其截图设为预览图，以及在ID无效或组件隐藏时的回退截图逻辑，同时指出了截图不包含亮度、阴影等视觉效果。该文档适用于需要实现或自定义组件拖拽交互功能的ArkUI应用开发者。
