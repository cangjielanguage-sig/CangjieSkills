This directory focuses on cryptographic key agreement protocols within the HarmonyOS Universal KeyStore (HUKS) framework. It comprehensively covers the implementation of secure key exchange mechanisms, specifically utilizing algorithms like X25519 and Diffie-Hellman (DH). Key topics include asymmetric key generation, public key export, session management (init, update, finish), and the handling of derived keys via specific HUKS tags. The content provides both theoretical guidance and practical code examples in Cangjie and ArkTS. It is suitable for HarmonyOS developers and security engineers seeking to integrate robust, hardware-backed key exchange and management solutions into their applications.
