The `cj-bm-tool` directory functions as a specialized repository for the Bundle Manager (bm) tool, specifically curated for the Cangjie and HarmonyOS development ecosystems. It provides an extensive collection of documentation focused on command-line interface (CLI) operations that are essential for managing the complete application lifecycle. The content covers a broad spectrum of tasks, ranging from basic installation and uninstallation to more complex operations like querying, debugging, and patching. Additionally, it addresses the management of specific package formats such as HAR and HAP, as well as the handling of shared libraries and overlays. This directory is an invaluable resource for developers, system administrators, and technical support personnel who need to execute precise deployment commands and resolve signature conflicts or installation issues directly through the shell environment.
