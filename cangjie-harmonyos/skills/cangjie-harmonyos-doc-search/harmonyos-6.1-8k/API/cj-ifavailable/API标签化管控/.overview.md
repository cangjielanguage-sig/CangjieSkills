## 详细描述

### API标签化管控_4more_71799e64.md API标签化管控_4more_71799e64.md
本文档介绍了仓颉语言中用于实现API标签化管控的@IfAvailable宏表达式及其使用方法。文档涵盖了宏的语法结构、运行时语义，以及针对API版本和系统能力的Level与Syscap检查规则。关键信息包括：@IfAvailable需配合APILevel注解，根据条件执行不同Lambda；Level检查限制高版本API调用，Syscap检查依据设备能力交集与并集进行编译校验。该指南面向仓颉开发者，帮助其在DevEco Studio工程中实现精细化的API使用限制。

### IfAvailable_使用示例.md IfAvailable_使用示例.md
本文档提供了仓颉语言中 `@IfAvailable` 注解的使用示例，旨在演示如何基于 API 等级和系统能力进行条件编译与运行时控制。文档主要涵盖两个核心场景：利用 `level` 参数管理不同 API 版本的函数调用，以及利用 `syscap` 参数处理设备特定的系统能力。关键要点在于理解该注解如何在编译期限制作用域内的 API 调用权限，并在运行期根据设备实际支持情况执行相应分支，从而确保代码兼容性。该文档面向使用 DevEco Studio 和仓颉语言的鸿蒙开发者，适用于需要处理多版本 API 适配及差异化系统能力调用的开发场景。
