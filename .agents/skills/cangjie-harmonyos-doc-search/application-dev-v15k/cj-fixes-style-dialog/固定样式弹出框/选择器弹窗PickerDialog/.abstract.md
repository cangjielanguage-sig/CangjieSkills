This directory provides comprehensive documentation for implementing PickerDialog components within Cangjie applications. It focuses on the technical aspects of integrating date selection interfaces, covering essential features such as lunar calendar switching, time display, and state management. The content guides developers through configuring date ranges, customizing text styles, and managing dialog lifecycles. It also details how to handle critical event callbacks like onDateAccept and onDateChange to ensure user choices are persisted. This resource is specifically designed for application developers utilizing the Cangjie language and UIKit framework who require robust, interactive popup dialogs for date selection in their user interfaces.
