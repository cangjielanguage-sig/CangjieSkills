This directory contains API reference documentation for the `AVMetadata` class within the Cangjie programming language and the AVSession framework. It covers the initialization, constructors, and properties required to manage audio-visual metadata for multimedia applications. Key topics include media asset identification, artist and album details, duration handling, image support via PixelMap or URL, and DRM configuration. The documentation is intended for software developers integrating multimedia session management, providing the necessary tools to define and manipulate media attributes effectively.
