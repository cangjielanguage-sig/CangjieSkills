# 资源分类与访问

This section provides comprehensive technical guidance on managing, classifying, and accessing resources within HarmonyOS and Cangjie development environments. It covers the creation of resource directories, the distinction between application and system resources, and the logic behind resource matching for different device configurations. Additionally, it details how to programmatically access these resources using the Cangjie framework. Key topics include resource qualifiers, localization, translatable attributes, and adaptive UI styling. This documentation is suitable for HarmonyOS and Cangjie developers seeking to optimize asset organization and ensure consistent application behavior across diverse devices.

### 资源分类与访问.md 资源分类与访问.md
This document serves as a guide explaining the classification and usage of resources within application development, specifically distinguishing between custom application resources and pre-defined system resources. It covers the definition of application resources, which allow developers to manage custom values like colors and fonts across different devices, and system resources, which provide adaptive pre-set definitions based on configurations like device type or color mode. The key takeaway is understanding that while application resources require manual management for different configurations, system resources offer built-in adaptability through layered parameters, simplifying the handling of varying device environments. Targeted at application developers, this guide helps in efficiently managing UI elements and ensuring consistent visual presentation across diverse hardware and software configurations.

### 资源匹配_2more.md 资源匹配_2more.md
This document serves as a technical guide explaining the system logic for matching application resources based on specific device states. It details the priority hierarchy for qualifier directories, ranging from mobile country codes to screen density, and defines the fallback behavior to the base directory. Key takeaways include the strict matching requirement for specific qualifiers and the exclusion of rawfile from this process. Additionally, it outlines restrictions such as avoiding Cangjie language reserved keywords in resource names and the lack of support for transparent colors in JSON definitions. This guide is intended for application developers managing resource localization and device adaptation.

### 资源访问.md 资源访问.md
This document serves as a technical guide explaining how to access and reference application and system resources within the Cangjie development framework. It covers two main areas: accessing application resources (including strings, media, and rawfiles) and utilizing system resources for consistent UI styling. Key concepts include the `@r(app.type.name)` syntax for app resources, `@rawfile("filename")` for raw files, and `@r(sys.type.resource_id)` for system resources. It details handling string placeholders and raw file descriptors, providing Cangjie code examples for implementation. Targeted at Cangjie developers, this reference documentation requires knowledge of resource file structures like JSON and the `cj_res_entry` module.
