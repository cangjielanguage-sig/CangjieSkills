# cj-audio-playback-overview

This directory serves as a centralized resource for understanding audio capabilities within the Cangjie programming environment. It provides a comprehensive development guide designed to assist developers in selecting and implementing the correct audio playback APIs based on specific project needs. The content thoroughly covers four distinct audio methods: AudioRenderer for high-fidelity PCM output, AudioHaptic for synchronized vibration experiences, AVPlayer for handling standard media formats, and SoundPool for low-latency sound effects. Beyond just listing APIs, the document outlines specific use cases, clearly distinguishing between requirements like game sound effects and media streaming, while also noting current system limitations such as the lack of support for background or screen-off playback. This resource is essential for Cangjie developers aiming to optimize development efficiency and ensure high-quality user experiences by precisely matching technical requirements with the appropriate audio tools.

## Detailed Description

### cj-audio-playback-overview.md cj-audio-playback-overview.md

This document acts as a crucial development guide for Cangjie developers, focusing on the strategic selection of appropriate audio playback APIs. It provides a detailed breakdown of four primary methods available in the ecosystem to address different audio engineering challenges.

First, it discusses **AudioRenderer**, which is intended for professional PCM output scenarios requiring granular control. Second, it covers **AudioHaptic**, a specialized API designed for creating synchronized vibration effects alongside audio to enhance immersion. Third, it examines **AVPlayer**, the robust go-to solution for playing standard media formats in typical playback scenarios. Finally, it details **SoundPool**, which is optimized for low-latency sound effects, making it ideal for gaming applications where timing is critical.

The guide highlights key takeaways regarding specific use cases—differentiating between complex media streaming and immediate sound effects—and explicitly states a current limitation: background or screen-off playback is not supported. By mapping technical requirements to these tools, the document aims to significantly optimize development efficiency and decision-making for Cangjie programmers during the architectural planning phase.
