These enums ensure type safety and consistency across the application logic. Additionally, the documentation details the `BatteryInfo` class, which acts as the main entry point for retrieving this data. By utilizing these resources, Cangjie developers and system engineers can effectively implement power management features, track energy consumption patterns, and ensure their applications respond dynamically to the device's power state.
