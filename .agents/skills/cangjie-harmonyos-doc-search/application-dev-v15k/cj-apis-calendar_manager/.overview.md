# cj-apis-calendar_manager

This directory serves as the central repository for API reference documentation regarding the Cangjie programming language's CalendarKit module. It specifically focuses on schedule management capabilities provided by the SystemCapability.Applications.CalendarData framework. The content is tailored for application developers and software engineers who aim to build or enhance applications with robust calendar functionalities. It covers the essential building blocks of calendar systems, including data structures, enumerations, and classes needed for creating, querying, and managing calendar events, accounts, and configurations. Key topics addressed in this documentation include event filtering, location handling, recurrence rules, and permission management. To effectively utilize this resource, users are expected to have a solid understanding of Cangjie syntax and be working within an environment supporting system capabilities starting from API version 20.
