# 仓颉调用模块内cpp文件

This directory serves as a technical resource for developers utilizing the Cangjie programming language within the HarmonyOS development environment, specifically addressing the integration of C++ modules and the deployment of applications. It provides step-by-step instructions on bridging high-level Cangjie code with low-level C++ implementations using the Foreign Function Interface (FFI), ensuring efficient performance and code reuse. Additionally, it covers the critical configuration steps required to run applications on various target platforms, including local physical devices and software emulators. Key topics include the `foreign` keyword, `cjpm.toml` library linking, `extern "C"` usage, and modifying `build-profile.json5` for architecture compatibility. This content is tailored for Cangjie developers seeking to extend their application capabilities through native code and validate their work across different testing environments using DevEco Studio.

## Detailed Description

### 仓颉调用模块内cpp文件_2more.md
This tutorial guides developers on integrating C++ code within a Cangjie module using DevEco Studio. It covers creating a Cangjie Empty Ability project, generating a C++ file, and implementing native functions. The document details how to declare these functions in Cangjie using the `foreign` keyword for Foreign Function Interface (FFI) and how to configure the `cjpm.toml` file to link the native libraries correctly. Key takeaways include the necessity of `extern "C"` in C++ and the specific `ffi.c` dependency configuration. This guide is intended for Cangjie developers seeking to leverage existing C++ code or optimize performance through native calls.

### 使用真机或模拟器运行应用.md
This guide instructs developers on running HarmonyOS applications developed with the Cangjie language using either local real devices or the DevEco Studio emulator. The document covers two main workflows: connecting a real device and configuring automatic signing through a Huawei account, and setting up a Phone emulator. A critical technical detail is the requirement to modify the build-profile.json5 file to include x86_64 in abiFilters for both Cangjie and C++ options, enabling compatibility with x86 emulators which otherwise default to arm64-v8a. This tutorial serves developers using DevEco Studio who need to configure build architectures and device signatures for application testing.
