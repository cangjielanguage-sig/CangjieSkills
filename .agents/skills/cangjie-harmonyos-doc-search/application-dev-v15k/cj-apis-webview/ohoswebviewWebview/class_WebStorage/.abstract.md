This directory contains API reference documentation for the `WebStorage` class in the Cangjie programming language, specifically designed for the ArkWeb framework. It covers the management of Web SQL and HTML5 storage interfaces, including methods for deleting data, retrieving storage quotas, and monitoring usage. Key functionalities include clearing storage based on origin strings, handling incognito modes, and asynchronous data retrieval. This documentation is suitable for application developers and HarmonyOS engineers who need to programmatically manage web data storage within WebView components.
