This directory serves as a comprehensive technical resource for analyzing Application Not Responding (ANR) and freeze logs within the HarmonyOS/OpenHarmony ecosystem. It covers methodologies for diagnosing appfreeze events, interpreting log headers, and analyzing specific timeout scenarios like user input response and lifecycle switches. The content includes detailed guides on main thread blocking, stack trace analysis, and system resource monitoring. It is suitable for system developers, QA engineers, and software engineers focused on debugging application stability, performance bottlenecks, and responsiveness issues.
