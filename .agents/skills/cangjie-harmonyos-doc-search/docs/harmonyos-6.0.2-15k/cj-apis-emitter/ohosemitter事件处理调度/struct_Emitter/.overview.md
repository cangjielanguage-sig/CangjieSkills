# struct_Emitter

This directory contains API reference documentation for the `Emitter` struct in the Cangjie language, specifically within the BasicServicesKit framework. It covers event-driven communication mechanisms, including sending events, managing subscriptions, and handling listener counts. Key topics include static methods for event emission, subscription management (`on`, `off`, `once`), and error handling for invalid inputs. The documentation is designed for Cangjie developers implementing event-driven logic, providing detailed parameter descriptions, return values, and code examples to facilitate robust application development using the Notification framework.

## Detailed Description

### static_func_getListenerCou_4more.md
This API reference document details static functions for managing event subscriptions and listener counts within the Emitter system. It covers the getListenerCount(String) method to retrieve subscription numbers and three overloaded off functions to remove subscriptions using String or UInt32 event IDs. Key information includes that all functions require a non-empty event ID and throw a BusinessException (error 401) for invalid inputs. The off methods allow removing all listeners or specific callbacks. This guide targets Cangjie developers implementing event-driven logic who need to monitor or terminate event handling.

### static_func_offString_Even_3more.md
This API reference document details event subscription and unsubscription methods for the Cangjie Emitter module. It covers three static functions: off for canceling subscriptions, and two on overloads for continuous subscription using InnerEvent or String identifiers. Key information includes parameter requirements like non-empty event IDs and EventCallback objects, system capabilities, and error handling for invalid inputs. The document provides code examples for each function. It is intended for Cangjie developers implementing event-driven logic within the Notification framework.

### static_func_onceInnerEvent_2more.md
This API reference document details the `once` function for one-time event subscriptions within the Emitter module. It covers two overloaded static methods accepting either an `InnerEvent` object or a `String` eventId, alongside an `EventCallback`. Key information includes the automatic unsubscription behavior after the callback executes, parameter requirements, and specific error codes like 401 for invalid event IDs. The document provides Cangjie code examples demonstrating implementation. Targeted at developers using SystemCapability.Notification.Emitter, this guide is essential for implementing event-driven logic that requires handlers to run only once.
