# class_Form

本目录包含仓颉语言中 `Form` 类及相关编码函数的 API 参考文档，专注于 HTTP 请求表单数据与 URL 查询参数的高效处理。核心内容涵盖键值对形式的存储管理、支持单键多值的数据结构、URL 查询字符串的解析与构建，以及遵循 RFC 3986 协议的百分号编码机制。文档详细介绍了构造函数、数据增删改查（CRUD）方法、异常处理及返回值类型（如 `Option` 和 `ArrayList`）。该文档适合需要处理 Web 表单提交、管理 URL 参数或进行 HTTP 请求数据编码的后端开发者阅读。

## Detailed Description

### class_Form_10more_f4483b1e.md

这是一份 Cangjie 语言中 Form 类的 API 参考文档，旨在说明如何以键值对形式存储和管理 HTTP 请求表单信息。文档涵盖了类的构造函数（包括从 URL 查询字符串解析）、数据增删改查方法（add、get、getAll、set、remove）以及克隆和判空功能。关键信息包括支持一个键对应多个值、处理 URL 编码异常、以及使用 Option 和 ArrayList 类型返回查询结果。该文档面向需要处理 URL 查询参数或表单数据的开发者，提供了详细的接口定义和参数说明。

### func_toEncodeString_50a8b049.md

本文档主要介绍了用于对表单键值对进行百分号编码的 `toEncodeString` 函数。内容涵盖了函数签名、功能描述、编码规则说明（包括未保留字符定义及空格处理）以及返回值类型。关键信息指出该函数遵循 RFC 3986 协议，未保留字符（字母、数字及特定符号）不编码，空格转换为加号，最终返回编码后的字符串。这是一份仓颉语言的 API 参考文档，面向需要处理表单数据编码的开发者。
