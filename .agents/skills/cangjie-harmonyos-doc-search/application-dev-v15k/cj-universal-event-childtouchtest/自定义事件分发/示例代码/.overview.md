# 示例代码

This directory provides a comprehensive collection of example code tailored for developers utilizing the Cangjie language and the ArkUI framework. It focuses on the critical aspect of touch event dispatch strategies, offering detailed guidance on managing and resolving gesture conflicts between overlapping UI components, specifically Lists and Buttons. The content covers the practical application of the `touchTestInfo` function and the `onChildTouchTest` modifier to customize event distribution behaviors. By examining different strategies such as FORWARD_COMPETITION, FORWARD, and DEFAULT, developers can gain a deeper understanding of how to balance scrolling capabilities with click responsiveness. These resources are ideal for UI developers and HarmonyOS engineers seeking to implement sophisticated touch event handling and ensure smooth, intuitive user interactions in their applications.

## Detailed Description

### 示例1设置事件派发策略为FORWARD_COMPETITION.md 示例1设置事件派发策略为FORWARD_COMPETITION.md
This tutorial demonstrates how to configure the event dispatch strategy to FORWARD_COMPETITION in a Cangjie application to manage touch conflicts between a List and a Button. The document covers the implementation of the touchTestInfo function, the usage of TouchTestStrategy.FORWARD_COMPETITION, and the application of the onChildTouchTest modifier. Key information includes that setting this strategy for the "MyList" ID allows the List to scroll when interacting with blank areas below it, while ensuring the Button remains clickable and responsive to its onClick event. This guide is intended for UI developers using the Cangjie language and ArkUI framework who need to handle complex touch event distribution and gesture conflicts.

### 示例2设置事件派发策略为FORWARD_2more.md 示例2设置事件派发策略为FORWARD_2more.md
This document provides code examples demonstrating how to configure touch event dispatch strategies using the onChildTouchTest method in Cangjie UI development. It covers two scenarios: setting the strategy to FORWARD (Example 2) and DEFAULT (Example 3), comparing their effects on a List and a Button component. The key takeaway is that the FORWARD strategy enables List scrolling while blocking Button clicks, whereas the DEFAULT strategy prevents List scrolling but allows Button interaction, illustrating how to manage touch event conflicts. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to customize touch event handling and component interaction logic.
