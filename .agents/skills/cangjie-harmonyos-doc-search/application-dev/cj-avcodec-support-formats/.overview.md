# cj-avcodec-support-formats

This directory hosts the documentation for `cj-avcodec-support-formats`, acting as the definitive guide for the media formats supported by the AVCodec module. Given that the module is in a Beta phase, this document is vital for tracking the current feature set and technical boundaries. It offers a granular analysis of video and audio encoding and decoding pipelines, explicitly highlighting the differences between hardware and software decoding for video streams. The scope extends to media data parsing (demuxing) and encapsulation (muxing), ensuring developers understand how to handle container formats like MP4, MKV, and FLV, including the integration of subtitle tracks. The text enumerates supported codecs such as H.264, H.265, AAC, and MP3, while also defining critical operational constraints like sample rates and channel counts. This guide is tailored for developers and engineers tasked with integrating robust media playback or recording systems who must validate codec and container compatibility to prevent runtime errors.
