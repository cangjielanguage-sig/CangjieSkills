# ohosappabilityerror_manager错误管理模块

本模块是HarmonyOS仓颉开发框架中的错误管理组件，专注于Ability运行时的异常处理。它提供了ErrorManager类及相关枚举，允许开发者注册和注销错误观察者，以监控应用崩溃和冻结等严重错误。核心功能包括错误事件监听、取消监听及事件类型定义。该模块适用于使用仓颉语言开发HarmonyOS应用的开发者，旨在帮助其有效捕获和处理运行时异常，提升应用稳定性。

## 详细描述

### class_ErrorManager.md
这是一份Cangjie语言的API参考文档，主要介绍ErrorManager类，用于提供Ability错误管理能力，包括错误事件的监听与取消监听。文档核心涵盖两个静态方法：on方法用于注册错误观察者并返回观察者ID，off方法则用于根据ID取消监听。内容详细列出了参数、返回值、可能抛出的BusinessException异常及对应错误码，并附带了完整的代码示例。该文档面向使用Cangjie开发HarmonyOS应用的开发者，旨在帮助他们有效处理应用运行时的异常和错误。关键词：ErrorManager, Ability, 错误监听, Cangjie, API文档, 异常处理。

### enum_ErrorManagerEvent_2221ad6a.md
本文档定义了仓颉语言中的 ErrorManagerEvent 枚举，用于指定错误管理事件类型。文档涵盖了枚举的整体定义及其 Error 变体，并提供了系统能力和起始版本等元数据。关键信息包括该枚举属于 SystemCapability.Ability.AbilityRuntime.Core 系统能力，起始版本为 22，其中 Error 变体专门用于表示错误事件。该文档面向使用仓颉语言进行应用开发的开发者，特别是涉及 Ability 运行时错误处理的场景。
