# 使用Web组件加载页面

This directory provides comprehensive technical guidance for HarmonyOS developers on integrating web content using the Web component. It covers essential scenarios including loading network pages, rendering local HTML files from `rawfile` or sandbox paths, and displaying HTML rich text data directly. Key technical points include configuring internet permissions, utilizing `WebviewController`, and implementing `loadUrl()` or `loadData()` interfaces. The content is specifically designed for ArkUI and ArkWeb developers using the Cangjie language who are building hybrid applications requiring seamless interaction between native code and web assets.

## Detailed Description

### 使用Web组件加载页面_2more.md 使用Web组件加载页面_2more.md
This technical guide instructs developers on using the Web component to load pages within applications. It covers three primary scenarios: loading network pages, local pages, and HTML rich text data. Key takeaways include the necessity of configuring internet permissions in module.json5 and the restriction that the src attribute cannot be dynamically changed via state variables. Instead, developers must use the loadUrl() interface to update the displayed URL. The document provides a Cangjie code example demonstrating the WebviewController and loadUrl implementation. Targeted at ArkUI developers, this guide serves as a practical tutorial for integrating web content.

### 加载HTML格式的文本数据.md 加载HTML格式的文本数据.md
This document serves as a technical guide for developers on how to load HTML text data directly into a Web component without fetching a full web page. It covers two primary methods: utilizing the loadData() interface and employing the Data URL scheme. Key takeaways include the specific parameters for loadData, such as the HTML string, MIME type, and encoding, as well as the syntax for Data URLs. The guide also notes that for large HTML files, the baseUrl parameter should be set to "data". The content is intended for application developers using the ArkWeb framework and Cangjie language who need to display dynamic HTML fragments or local content.

### 加载本地页面/
This directory serves as a technical resource for HarmonyOS developers aiming to implement local web page rendering within their applications. It explores the necessary procedures for loading HTML content from both the application's `rawfile` resources and secure sandbox paths. The documentation covers the use of the Cangjie language for Web component integration, including dynamic URL loading and local CSS styling. Additionally, it provides essential insights into the ArkTS-based `MainAbility` lifecycle, demonstrating how to utilize `GlobalContext` to bind file directories and synchronize data between the Ability and UI components. This guide is suitable for developers building hybrid applications that require seamless interaction between native code and local web assets.
