# 开发步骤

This directory provides a comprehensive tutorial series for implementing relational database (RdbStore) functionality using the Cangjie language within the HarmonyOS ArkData framework. It covers the complete data lifecycle, starting from initial database configuration, schema creation, and version management strategies. It then progresses to essential CRUD operations—insertion, querying, updating, and deleting data using predicates—and concludes with advanced management tasks such as result set processing, data backup, restoration, and database deletion. Key concepts include RdbPredicates, SQL execution, and file management. This guide is specifically designed for application developers who need to build robust local data storage solutions, handle schema evolution, and ensure data persistence in their Cangjie-based applications.

## Detailed Description

### 开发步骤_1.md
This tutorial guides developers through implementing data persistence using a relational database (RdbStore) in the Cangjie language. It covers database configuration, initialization, schema creation, and version management strategies for upgrades and downgrades. Key information includes a code example demonstrating how to define StoreConfig, check database versions, and execute SQL commands like CREATE TABLE and ALTER TABLE within the onWindowStageCreate lifecycle method. The document also references procedures for handling database exceptions. This guide is intended for application developers building features requiring local data storage and schema evolution.

### 开发步骤_2.md
This document provides a technical tutorial for performing CRUD operations on a relational database using the Cangjie language. Main sections cover data insertion, modification and deletion using predicates, and querying data with result sets, alongside notes on database context and file management. Key takeaways include the use of RdbPredicates for filtering, automatic data persistence, and the generation of temporary files like -wal and -shm in the app sandbox. The guide targets application developers managing local data storage, requiring knowledge of Cangjie syntax and relational database concepts.

### 开发步骤_3.md
This tutorial section guides developers through advanced data management operations for relational databases in Cangjie, specifically focusing on result processing, backup, restoration, and deletion. Main topics covered include iterating through query results using a ResultSet, performing manual database backups, restoring data from backups, and deleting the database store. Key information highlights the importance of calling the close method on ResultSets to release memory and provides code examples for backup, restore, and deleteRdbStore functions with error handling. This guide is intended for developers using the Cangjie language and HarmonyOS ArkData framework to implement complete data lifecycle management in their applications.
