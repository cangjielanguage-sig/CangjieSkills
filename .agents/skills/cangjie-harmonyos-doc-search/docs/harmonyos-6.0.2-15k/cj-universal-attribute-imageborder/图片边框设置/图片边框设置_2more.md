# 图片边框设置

设置组件的图片边框样式。

## func borderImage(BorderImageOption)

```cangjie
public func borderImage(value: BorderImageOption): This
```

**功能：** 设置组件的图片边框。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|value|[BorderImageOption](#class-borderimageoption)|是|-|图片边框或者渐变色边框设置接口。|
