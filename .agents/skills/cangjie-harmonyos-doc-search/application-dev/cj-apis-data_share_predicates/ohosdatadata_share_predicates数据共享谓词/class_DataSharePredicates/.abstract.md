This directory contains API reference documentation for the `DataSharePredicates` class in the Cangjie programming language, part of the ArkData kit. It covers the construction and manipulation of data query predicates used for sharing data across different implementations, supporting both relational and key-value databases. Key functionalities include logical conjunctions, value matching, result limiting, and sorting. The documentation is intended for developers working within the distributed data management system who need to implement complex database filtering, pagination, and sorting logic. Note that the class is not thread-safe and may throw `BusinessException` for internal errors.
