# Connectivity_Kit开发概述

This directory serves as a comprehensive technical resource for the Connectivity Kit, specifically designed to assist developers in seamlessly integrating robust wireless communication capabilities into their applications. It covers a wide range of essential technologies, including Bluetooth, Wi-Fi (WLAN), and Near Field Communication (NFC). The documentation details specific modules such as BLE, A2DP, various WLAN operational modes (STA, P2P, AP), and NFC card emulation. It is highly suitable for application developers seeking to implement basic communication services, manage connection lifecycles, and significantly enhance user experience through wireless protocols, provided they possess a foundational understanding of these technologies and relevant API references. The content ensures developers can effectively utilize the available tools to create connected experiences.
