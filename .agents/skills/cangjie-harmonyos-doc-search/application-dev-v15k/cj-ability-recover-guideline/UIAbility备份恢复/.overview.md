# UIAbility备份恢复

This directory provides comprehensive documentation on the UIAbility backup and recovery feature within the HarmonyOS development framework. It covers essential mechanisms designed to prevent data loss when applications are terminated by the system in the background, thereby ensuring a continuous and seamless user experience. Key topics include the operational mechanisms involving lifecycle callbacks such as `onSaveState` and `onCreate`, specific constraints like data retention limits, and detailed implementation steps using the Cangjie framework and AbilityKit. This guide is suitable for application developers looking to implement robust state management and recovery capabilities in their applications to handle unexpected system terminations gracefully.

## Detailed Description

### 场景介绍_3more.md
This document introduces the UIAbility backup and recovery feature designed to prevent data loss when applications are terminated by the system in the background. It covers the scenario description, operational mechanism involving lifecycle callbacks like onSaveState and onCreate, and specific constraints. Key information includes that backup triggers automatically after onBackground, restores page stack and Want data upon restart, and supports multi-instances. Constraints include a 7-day data retention period, a 200KB size limit, and exclusion of device restarts and UIExtensionAbility. This guide targets application developers seeking to implement state persistence for a continuous user experience.

### 接口说明_2more.md
This document serves as a technical guide for implementing UIAbility backup and restore functionality within the Cangjie development framework. It covers the setRestoreEnabled interface specification and provides step-by-step development instructions for enabling restoration and managing state persistence. Key information includes the requirement to call setRestoreEnabled(true) during the onCreate lifecycle phase, prior to onForeground, and the implementation of onSaveState to return OnSaveResult.ALL_AGREE. The content demonstrates how to parse JSON parameters for data recovery. This guide is intended for application developers using the AbilityKit who need to ensure their applications can persist and recover state effectively.
