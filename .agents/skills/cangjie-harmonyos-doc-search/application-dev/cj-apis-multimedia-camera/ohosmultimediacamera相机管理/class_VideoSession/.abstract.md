This directory contains API reference documentation for the `VideoSession` class within the Cangjie language CameraKit. It covers the implementation of standard video recording modes, including capabilities like flash, exposure, focus, zoom, and stabilization. The documentation details methods for querying hardware support (`canPreconfig`), preconfiguring sessions (`preconfig`), and managing event listeners for errors, focus states, and smooth zoom operations (`on`/`off`). It is intended for developers building HarmonyOS camera applications who need to handle video session configuration and event monitoring.
