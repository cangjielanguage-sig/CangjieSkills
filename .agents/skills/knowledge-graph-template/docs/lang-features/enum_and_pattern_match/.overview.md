# enum_and_pattern_match

This directory provides a comprehensive technical guide to enumeration types and pattern matching within the Cangjie programming language. It covers the definition and usage of enums, the `match` expression for control flow, and the `Option` type for null safety. Additionally, it explores advanced pattern matching concepts, including refutability, irrefutable patterns, and various pattern types like tuples and bindings. This resource is suitable for Cangjie developers and learners aiming to master complex data structures, control flow logic, and type-safe programming techniques.

## Detailed Description

### [1] enum/
This directory serves as a comprehensive technical resource dedicated to enumeration types within the Cangjie programming language. It provides a structured approach to learning how to define enums, covering the syntax required for both simple and complex scenarios.

### [2] match/
This directory serves as a comprehensive technical guide dedicated to the `match` expression functionality within the Cangjie programming language. It acts as a central resource for developers aiming to master complex control flow structures and leverage pattern matching effectively.

### [3] option_type/
This directory contains core documentation for the `Option` type in the Cangjie programming language, detailing how to handle values that may or may not exist. The content covers the definition of `Option` as a generic enum (including `Some` and `None` constructors), the shorthand syntax `?Ty`, automatic wrapping mechanisms during context type inference, and methods for explicitly specifying the type of `None`. This document is suitable for Cangjie learners and developers, aiming to help master null safety handling and generic applications. It is recommended to read this in conjunction with error handling documentation.

### [4] other/
This directory contains documentation on advanced applications of pattern matching in the Cangjie programming language, focusing on scenarios other than `match` expressions. It details the specific applications of wildcard patterns, binding patterns, and irrefutable tuple and enum patterns in variable definitions, `for in` loops, and conditional expressions. The document emphasizes the principle that "irrefutable" patterns—those guaranteed to match—must be used in variable definitions and `for in` expressions. Suitable for developers already familiar with basic Cangjie syntax, it aims to help master more flexible deconstruction and binding techniques. Keywords: Cangjie, pattern matching, irrefutable patterns, variable definition.

### [5] pattern_overview/
This directory serves as a comprehensive guide to the pattern matching mechanisms within the Cangjie programming language. It covers a wide array of pattern types, including tuple, type, enum, constant, wildcard, and binding patterns. Through practical examples, it explains how these patterns interact with the language's type system.

The directory details the distinction between "refutable patterns" and "irrefutable patterns," covering the specific matching characteristics of constant, wildcard, binding, tuple, type, and enum patterns.
