This directory provides comprehensive API reference documentation for the `UserAuthInstance` class within the Cangjie language User Authentication Kit. It is designed to assist developers in executing user identity authentication, specifically focusing on biometric operations. The content covers essential methods for managing authentication lifecycles, including halting processes, unsubscribing from events, and initiating authentication flows. Key technical aspects include required permissions like `ohos.permission.ACCESS_BIOMETRIC`, system capabilities, and specific error codes for exception handling. This documentation is intended for application developers working with system version 19 who possess a foundational understanding of the UserIAM framework.
