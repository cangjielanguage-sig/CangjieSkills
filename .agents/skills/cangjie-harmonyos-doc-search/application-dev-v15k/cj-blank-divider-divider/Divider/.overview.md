# Divider

This directory provides comprehensive documentation for the Divider component within the ArkUI framework, specifically tailored for developers utilizing the Cangjie programming language. It encompasses the complete API reference, including component initialization, supported versions (starting from API 12), and universal attributes. Furthermore, it addresses specific configuration methods like `lineCap` and `strokeWidth`, alongside hardware rendering recommendations to prevent visual artifacts. The content details how to configure visual properties such as stroke width, color, and line cap, while also offering practical code examples for implementing both horizontal and vertical dividers in UI layouts. This resource is essential for UI developers and software engineers seeking to create distinct visual separations between content blocks, ensuring clean and structured application interfaces.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring the properties of a Divider component within the ArkUI framework using the Cangjie language. It details four primary methods: color, lineCap, strokeWidth, and vertical, which define the visual appearance and orientation of the divider line. Key specifications include default values such as a semi-transparent dark color, Butt-style endpoints, and a 1.vp width. The documentation highlights that the strokeWidth property has lower priority than the generic height attribute and recommends using 2 pixels to prevent rendering issues on specific hardware. This technical reference is intended for UI developers building applications with ArkUI, requiring familiarity with Cangjie syntax and layout concepts.
