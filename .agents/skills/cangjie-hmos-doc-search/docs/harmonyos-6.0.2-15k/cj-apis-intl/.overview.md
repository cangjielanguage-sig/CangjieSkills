# cj-apis-intl

The `cj-apis-intl` directory serves as a comprehensive technical repository for the Cangjie LocalizationKit, specifically focusing on the `ohos.intl` module designed for HarmonyOS internationalization (I18n). It provides essential API reference documentation and structural definitions for developers aiming to build global applications. The content covers critical localization features, including the formatting of dates, numbers, and relative times, as well as complex logic for locale-specific string comparison and pluralization rules. This directory is highly suitable for Cangjie developers and software engineers working on localization features who need to implement culturally aware text sorting, accurate time display, and region-specific numeric formatting. By leveraging the resources within this directory, developers can effectively configure initialization methods and apply usage examples to ensure their software resonates with users across diverse linguistic and cultural landscapes.

## Detailed Description

The following section details the primary subdirectory available within this repository, outlining its specific focus on internationalization APIs.

### ohosintl国际化-Intl/

This directory contains API reference documentation for the `ohos.intl` module within the Cangjie LocalizationKit, designed for HarmonyOS internationalization (I18n). It covers essential classes and structs for formatting dates, numbers, and relative times, as well as handling locale-specific string comparison and pluralization rules. The documentation provides initialization methods, configuration options, and usage examples for developers building global applications. It is suitable for Cangjie developers and engineers working on localization features who need to implement culturally aware text sorting, time display, and numeric formatting. By utilizing these resources, developers can ensure their applications correctly interpret and display data according to the cultural conventions of end-users worldwide, which is a critical requirement for modern software distribution in international markets.
