# 开发步骤

This directory provides comprehensive development guides for implementing internationalization (i18n) features using the LocalizationKit in the Cangjie programming language. It covers essential tasks such as unit conversions, number formatting, and currency display. The documentation includes detailed function signatures, configuration options like `NumberOptions`, and practical code examples for handling localized data presentation. It is suitable for Cangjie developers looking to integrate robust localization capabilities into their applications, ensuring accurate and culturally appropriate formatting for global users.

## Detailed Description

### 度量衡转换.md 度量衡转换.md
This document provides a guide for performing unit conversions and formatting based on specific regions and styles using the LocalizationKit. It covers module import, the I18NUtil.unitConvert function signature, a table of formatting styles (long, short, narrow), and a practical development example. The core function takes source and target units, a numerical value, a locale string, and an optional style parameter to return a formatted string. It targets Cangjie developers implementing internationalization features who need to handle measurement localization.

### 数字格式化.md 数字格式化.md
This document serves as a technical guide for implementing number formatting in the Cangjie programming language using the LocalizationKit. It details the usage of the NumberFormat class, covering the complete workflow from module import and object creation to formatting numbers and retrieving options. Key sections explain the NumberOptions struct, providing tables that demonstrate how parameters like minimum digits, grouping, notation, and compact display affect output. The guide includes practical code examples for scientific notation, compact formats, and percentages. It is intended for developers seeking to localize numerical data presentation with specific formatting rules.

### 货币和单位格式化.md 货币和单位格式化.md
This technical guide explains how to implement currency and unit formatting using the LocalizationKit in the Cangjie programming language. It details configuration options for currency signs and display styles, as well as unit display formats and usage scenarios, supported by illustrative tables. The document demonstrates how to use the NumberOptions struct to define styles like 'currency' or 'unit' and provides practical code examples showing the NumberFormat class methods for converting numerical values into localized strings. It targets software developers seeking to localize numerical data, requiring basic knowledge of the Cangjie syntax and internationalization concepts.
