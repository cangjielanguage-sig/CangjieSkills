# hdc

This directory contains comprehensive documentation for the HarmonyOS Device Connector (hdc), a versatile command-line tool designed for debugging and managing HarmonyOS and OpenHarmony devices. It covers essential topics such as environment setup, command references, file transfer, port forwarding, and application lifecycle management. The documentation also includes troubleshooting guides for error codes and common connectivity issues. Suitable for developers, QA engineers, and system administrators, these resources facilitate efficient device interaction, debugging, and automation across Windows, Linux, and macOS platforms.

## Detailed Description

### hdc_2more.md
This document serves as a technical guide for the HarmonyOS Device Connector (hdc), detailing its client-server-daemon architecture, environment setup via DevEco Studio, and configuration options like system paths and custom ports. Essential for developers setting up efficient device debugging across Windows, Linux, and macOS.

### hdc命令列表.md
Reference guide outlining global parameters and executable commands for the HDC tool. Covers device connection, app management, file transfer, and debugging, noting parameter placement rules and deprecated commands. Intended for developers and QA engineers for efficient device interaction.

### hdc调试日志.md
Guide on configuring and collecting hdc debugging logs, covering server-side management and device-side retrieval. Details runtime log levels (0-6), storage paths across OS platforms, and commands for capturing device logs using `hilog`. Assists developers in diagnosing connection issues.

### 基本使用方法.md
Quick start guide for the HDC tool, covering prerequisites like USB debugging, querying devices, and executing shell commands. Includes help access and troubleshooting for common issues like process exceptions. Ensures OpenHarmony developers can effectively manage device connections.

### 安全相关命令_2more.md
Reference for security and versioning commands, covering key pair generation via `keygen` and version queries using `-v` and `checkserver`. Provides syntax, parameters, and return value explanations to facilitate secure connection setup and troubleshooting.

### 执行交互命令_2more.md
Documentation for shell execution and app management, detailing `hdc shell` for interactive sessions and lifecycle commands like `install` and `uninstall`. Explains flags for app replacement and data preservation, aiding developers in debugging and deployment.

### 文件传输.md
Instructions for transferring files between host and device using hdc. Covers sending and receiving files, preserving timestamps, syncing updates, and managing permissions, including specific parameters for debuggable app data directories.

### 服务进程管理.md
Reference for managing the hdc service lifecycle, covering start, stop, bypass checks, and foreground mode. Explains the `-r` restart parameter, log level hierarchy, and the single-instance system restriction for effective process control.

### 端口转发.md
Guide for managing port forwarding between host and device using hdc. Details listing, setting up forward/reverse forwarding, and removing tasks. Specifies protocols, syntax, and error handling for network tunneling and debugging.

### 设备操作.md
Guide for device operations via hdc, including `hilog` retrieval, `jpid` listing, `track-jpid` monitoring, and rebooting. Provides syntax and parameters for debugging and system control, targeted at developers managing HarmonyOS devices.

### hdc错误码/
Repository for troubleshooting hdc error codes related to shell execution, app debugging, and file transfers. Provides root cause analysis and solutions for issues like invalid bundle names and version compatibility, essential for resolving workflow obstacles.

### 常见问题/
Knowledge base for common technical obstacles like tool execution failures and unrecognized devices. Covers solutions ranging from environment configuration to system-level debugging across Linux, macOS, and Windows, ensuring stable development workflows.

### 设备连接管理/
Focuses on managing device connections using hdc, covering querying lists, switching USB/wireless modes, and handling multi-device environments. Provides command-line solutions for connectivity management and network configuration in HarmonyOS development.
