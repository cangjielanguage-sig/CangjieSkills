This directory provides a comprehensive technical guide on using the `@Observed` and `@Publish` macros in the Cangjie language for ArkUI development. It focuses on managing state observation and property changes within nested custom classes and arrays. The content covers deep observation mechanisms, variable initialization, UI update triggers, and specific constraints like inheritance and constructor restrictions. It is suitable for Cangjie developers who need to implement reactive user interfaces and handle complex data models beyond basic state management.
