This directory outlines the essential development steps for primary Bluetooth Low Energy (BLE) scenarios within the HarmonyOS ecosystem. It focuses on the practical implementation of GATT (Generic Attribute Profile) protocols, comprehensively covering both server-side service management and client-side data interaction. Key topics include BLE server initialization, service addition, client notifications, connection establishment, and read/write operations. The documentation provides detailed code examples in both Cangjie and ArkTS to facilitate understanding. It is specifically suitable for software developers and engineers aiming to build robust connectivity features, manage GATT server logic, or implement client communication in HarmonyOS applications, ensuring a thorough grasp of asynchronous callback handling and UUID management.
