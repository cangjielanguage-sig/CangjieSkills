This directory serves as a comprehensive technical resource for the Contacts Kit development overview on HarmonyOS, aimed at empowering developers to integrate sophisticated contact management capabilities into their applications. It thoroughly details the kit's scope, clearly distinguishing between the open Contact Picker feature—which facilitates contact selection without requiring user permissions—and the restricted Contact Management functions that demand specific authorization. The documentation includes extensive step-by-step tutorials utilizing the Cangjie language, guiding developers through essential workflows such as importing necessary modules, retrieving the UIAbilityContext, and invoking the selectContacts interface. This guide is suitable for HarmonyOS developers seeking to implement either basic contact selection or advanced management features, providing the necessary insights to handle permission requirements and API interactions effectively.
