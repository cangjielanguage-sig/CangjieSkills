# 基础类型定义

This directory contains API reference documentation for fundamental data structures and enumerations used in Cangjie WebView development. It covers classes for handling web events (like downloads, errors, and console logs), resource requests and responses, headers, and configuration enums for caching and mixed content. Key components include event parameter structures for JavaScript interactions and permission management. This documentation is suitable for Cangjie developers building web-based applications who need to implement detailed WebView logic, handle network interactions, and manage user interface events within the SystemCapability.Web.Webview.Core framework.

## Detailed Description

### class_AdsBlockedDetails.md class_AdsBlockedDetails.md
This document serves as API reference documentation for the Cangjie class `AdsBlockedDetails`, defining the parameter structure for ad interception events. It details the class constructor and two read-only properties: `url`, representing the page where filtering occurred, and `adsBlocked`, an array of resource URLs or DOM paths that may contain duplicates. Key information includes the system capability `SystemCapability.Web.Webview.Core` and the requirement for mandatory parameters during object initialization. This documentation is intended for developers working on WebView functionality who need to handle and analyze ad-blocking data within their applications.

### class_ConsoleMessage_3more.md class_ConsoleMessage_3more.md
This API reference document defines three classes for managing Web component events in the Cangjie language. It covers `ConsoleMessage` for retrieving console logs, `PermissionRequest` for handling web resource authorization, and `WebResourceError` for managing resource loading failures. Key methods include retrieving log levels, granting or denying permissions (requiring specific system capabilities like microphone access), and fetching error codes. All classes belong to the `SystemCapability.Web.Webview.Core` system capability starting from version 19. The target audience is developers building webview applications who need to handle console output, user permissions, and network errors programmatically.
