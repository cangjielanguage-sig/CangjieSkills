# ohoscert_manager证书管理模块

This directory contains API reference documentation for the OpenHarmony Certificate Manager module, designed for the Cangjie programming language. It covers the complete lifecycle of security certificates and credentials, including installation, retrieval, signing, and verification. Key components include data structures for certificate metadata, enumerations for cryptographic algorithms (digests, padding), and error handling codes. The module requires specific system capabilities and permissions like `ohos.permission.ACCESS_CERT_MANAGER`. It is suitable for HarmonyOS developers implementing secure cryptographic operations, managing user trusted certificates, and handling digital signatures within their applications.

## Detailed Description

### class_CertAbstract_3more.md class_CertAbstract_3more.md
This API reference document defines data structures for managing security certificates and credentials within the Cangjie framework. It details three main classes: CertAbstract for summary information, CertInfo for detailed certificate data, and Credential for comprehensive credential details. Key information includes read-only properties such as aliases, binary data, validity dates, fingerprints, and counts of contained keys or certificates. All classes belong to the SystemCapability.Security.CertificateManager capability starting from version 19.

### class_CredentialAbstract.md class_CredentialAbstract.md
This document serves as API reference documentation for the Cangjie programming language, specifically defining the CredentialAbstract class used to represent brief credential information within the security certificate management system. The content covers the class definition and details three read-only properties: alias, credentialType, and keyUri, all of which are String types. This class provides a structured way to access credential identifiers and types.

### class_ErrorCode.md class_ErrorCode.md
This API reference document defines the ErrorCode class for handling certificate management errors in the Cangjie language. It details a collection of public static integer constants representing specific failure states, such as permission issues, invalid parameters, and certificate format errors. Key information includes the specific integer values for each error, ranging from general system errors like "NOT_SYSTEM_APP" to specific certificate issues like "MAX_CERT_COUNT_REACHED".

### enum_CmKeyDigest.md enum_CmKeyDigest.md
This API reference document defines the CmKeyDigest enum in the Cangjie language, specifying digest algorithms used for signing and verification. The content details the enum structure, listing specific values such as MD5, SHA1, SHA256, and a NONE option for pre-digested data. It also documents inherited operators for equality comparison and string conversion methods, targeting developers working on security features.

### enum_CmKeyPadding_2more.md enum_CmKeyPadding_2more.md
This API reference document defines enumerations for cryptographic operations within the SystemCapability.Security.CertificateManager module. It details the CmKeyPadding enum for specifying signature padding modes (None, PSS, PKCS1_V1.5) and the CmKeyPurpose enum for defining key usage (Sign, Verify). Both enums implement Equatable and ToString interfaces, providing standard equality operators and string conversion functionality.

### func_abortCMHandle_2more.md func_abortCMHandle_2more.md

The document covers function definitions, required permissions, system capabilities, parameters, exception handling with specific error codes, and practical code examples. The abort function terminates operations using a CMHandle, while finish completes verification by accepting a handle and signature data.
