# cj-dialog-base-overview

本目录提供了关于ArkUI框架中弹出框组件的全面概述文档，旨在帮助开发者深入理解模态窗口的机制与应用。内容涵盖了模态窗口的定义、详细分类以及多样化的应用场景，重点介绍了自定义弹出框（如CustomDialog、openCustomDialog）和固定样式弹出框（如AlertDialog、ActionSheet、showDialog、showActionMenu）的使用方法与核心区别。文档通过详细的对照表，帮助开发者根据需求选择支持动态更新和复杂布局的自定义组件，或适用于简单警告、列表选择及异步结果处理的固定组件。本文档主要面向ArkUI应用开发者，提供了选择合适组件的指导，以优化应用交互体验。关键词：ArkUI, 弹出框, 模态窗口, CustomDialog, AlertDialog。

## 详细说明

### cj-dialog-base-overview.md cj-dialog-base-overview.md

本文档详细概述了ArkUI框架中的弹出框组件体系，旨在帮助开发者全面理解模态窗口的定义、分类及实际应用场景。文档内容主要分为两大核心部分：自定义弹出框（包括CustomDialog和openCustomDialog）与固定样式弹出框（包括AlertDialog、ActionSheet、showDialog及showActionMenu）。文中不仅提供了这两类组件的详细特性说明，还包含了一份实用的使用场景对照表。关键信息指出，弹出框作为模态窗口，强制要求用户完成交互后才能关闭。其中，自定义类型支持动态更新和复杂布局，适合高度定制化的需求；而固定类型则更适用于简单的警告提示、列表选择及异步结果处理。本文档是ArkUI应用开发者选择合适组件、构建高效交互界面的重要参考资料。
