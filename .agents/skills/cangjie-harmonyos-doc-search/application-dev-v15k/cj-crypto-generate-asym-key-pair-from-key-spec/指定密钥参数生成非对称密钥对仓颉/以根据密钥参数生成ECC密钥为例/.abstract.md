This directory provides comprehensive Cangjie code examples focused on generating Elliptic Curve Cryptography (ECC) keys based on specific parameters. It details the process of defining common ECC specifications, constructing `ECCCommonParamsSpec` structures with field types and curve coefficients, and utilizing the `CryptoArchitectureKit`. The tutorials cover essential operations such as logging BigInt values, retrieving detailed key attributes, and extracting specific parameters like generator points and private key values. This resource is ideal for developers implementing custom cryptographic operations who need a practical guide to key generation workflows and parameter inspection within the Cangjie environment.
