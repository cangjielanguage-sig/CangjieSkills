This directory contains API reference documentation for the Cangjie language, focusing on the implementation and configuration of alert dialog components within the ArkUI framework. It covers essential constructors like `init()`, variable definitions for confirmation buttons, and various styling options for modal windows. Key topics include `AlertDialogButtonOptions`, event handling, system capabilities, and parameter initialization. This documentation is suitable for HarmonyOS application developers and UI designers using Cangjie who need to create, customize, and integrate interactive user confirmation dialogs and modal interfaces into their applications.
