This directory provides essential API reference documentation for the Cangjie programming language, specifically targeting the deprecated `CurrentProcess` class and related environment variable utilities. It encompasses the management of the currently running process, detailing how to access command-line arguments, navigate system directories, handle standard I/O streams, and implement process termination or exit callbacks. Additionally, the directory includes references for manipulating environment variables via `setEnv` and `removeEnv` functions. This content is tailored for Cangjie developers seeking technical guidance on interacting with the runtime environment, controlling execution flow, and configuring process environments, while noting the deprecated nature of the primary class. ### class_Process/
This directory contains API reference documentation for the Cangjie Process class, focusing on system process management and interaction. It covers functionalities such as retrieving process details (pid, name, command), managing process lifecycles (checking status, termination), and executing subprocesses. The documentation includes details on properties, static functions, and deprecated methods like `run`, `start`, and `runOutput`, guiding developers toward modern alternatives. It addresses platform-specific limitations, exception handling, and IO redirection. This resource is suitable for Cangjie developers who need to integrate system-level process control into their applications or maintain legacy code involving subprocess execution.

### class_SubProcess/
This directory provides a comprehensive overview of the `SubProcess` class and related utilities within the Cangjie language, specifically designed for managing child process operations and standard stream interactions. It serves as a critical resource for developers looking to implement robust process control, covering essential topics such as accessing standard input, output, and error streams via updated pipe properties. The documentation also details synchronization methods, including the `wait` function for retrieving exit statuses and the `waitOutput` function for capturing results. By addressing deprecations and limitations regarding stream sizes, this guide ensures developers can effectively handle inter-process communication and avoid common pitfalls like deadlocks. This content is ideal for Cangjie developers working on system-level programming who require a deep understanding of process lifecycle management and I/O handling.
