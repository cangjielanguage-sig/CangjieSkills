This directory contains technical API reference documentation for the Cangjie View class and associated instance ID management functions within the ArkUI framework. It comprehensively covers the foundational base class responsible for UI rendering mechanics, including methods for creating, recycling, and managing view lifecycles. Additionally, it details specific functions for synchronizing instance IDs. These documents are strictly intended for system developers and framework engineers working on ArkUI system internals, as the content is designated for internal framework use rather than general application development. Understanding these components requires knowledge of UI rendering mechanics and component management. This documentation is essential for maintaining the integrity of the UI framework's rendering pipeline.
