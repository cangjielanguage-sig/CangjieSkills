This directory contains API reference documentation for the BaseScroller class and related scrolling functions within the Cangjie ArkUI framework. It covers the core functionality required to programmatically control scrolling behaviors in UI components such as List, Grid, WaterFlow, and Scroll. Key topics include the BaseScroller class properties, methods for relative and absolute positioning, index-based navigation, and animation controls. This documentation is suitable for developers building UI applications in Cangjie who need to implement precise scroll manipulation, query component states, or handle fling and edge navigation logic.
