This directory focuses on implementing foreground blur effects for UI components within the HarmonyOS ArkUI framework using the Cangjie programming language. It covers the practical application of the `foregroundBlurStyle` modifier, comprehensive API references for configuration options, and fundamental data structures for visual effects. Key topics include material design styles, adaptive color modes, blur radius settings, and system capability requirements. This resource is suitable for Cangjie developers and UI designers looking to enhance application aesthetics with advanced visual styling, dynamic blur effects, and sophisticated component appearance manipulation.
