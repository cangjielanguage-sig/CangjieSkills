# 结构体

This directory serves as a comprehensive repository for API reference documentation regarding core data structures within the Cangjie programming language's time package. It focuses specifically on struct types designed for robust time handling and measurement. The content covers essential functionalities such as representing specific points in time, performing date arithmetic, managing time zone conversions, and measuring elapsed time with high precision. Key topics include the `DateTime` and `MonoTime` structs, detailing their constructors, properties, operator overloads, and system call support across different operating systems. This resource is suitable for software developers and engineers who require precise time manipulation, scheduling, timestamp management, or performance testing capabilities in their Cangjie applications.

## Detailed Description

### struct_DateTime/
This directory contains API reference documentation for the `DateTime` struct within the Cangjie programming language's time package. It covers comprehensive functionality for representing specific points in time, including date arithmetic, time zone conversions, formatting, parsing, and comparison operations. The documentation details constructors, properties, operator overloads, and exception handling for time calculations. It is suitable for software developers and engineers who need to implement precise time handling, scheduling, or timestamp manipulation in Cangjie applications.

### struct_MonoTime/
This directory contains comprehensive API reference documentation for the `MonoTime` struct within the Cangjie programming language's time package. It focuses on a monotonic time type specifically designed for measuring elapsed time with high precision. The documentation covers the struct definition, system call support across Linux, Windows, and macOS, and various operator overloads for arithmetic and comparison operations. Key topics include time measurement, timestamp manipulation, and chronological logic. This resource is suitable for Cangjie developers who need to implement precise time calculations, performance testing, or time-ordered queues in their applications, ensuring accurate and reliable time tracking.
