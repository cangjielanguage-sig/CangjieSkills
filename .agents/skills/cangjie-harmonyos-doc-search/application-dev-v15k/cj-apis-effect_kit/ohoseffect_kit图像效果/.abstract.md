This directory contains API reference documentation for the `ohos.effect_kit` module within the HarmonyOS ecosystem, specifically tailored for the Cangjie programming language. It covers comprehensive image processing capabilities, including creating filters, extracting colors, and applying various visual effects. Key topics include the `createEffect` function, `Color` class, `ColorPicker`, and `Filter` class functionalities. This documentation is suitable for developers and software engineers working with the ImageKit and ArkGraphics2D libraries to build dynamic image manipulation and analysis features in their applications.
