# cj-navigation-navigation

本目录提供了Cangjie框架中Navigation组件的全面指南，专注于实现高效的页面路由、参数传递及跳转栈管理。文档深入探讨了NavPathStack的核心路由操作、NavDestination子页面的生命周期管理，以及复杂的页面转场效果，特别是共享元素转场的实现。核心知识点包括如何利用NavPathStack维护页面栈，以及结合geometryTransition和animateTo API打造流畅的视觉体验。该文档专为Cangjie/ArkUI开发者设计，通过丰富的代码示例，指导开发者构建具备自适应能力和丝滑转场效果的应用导航结构。
