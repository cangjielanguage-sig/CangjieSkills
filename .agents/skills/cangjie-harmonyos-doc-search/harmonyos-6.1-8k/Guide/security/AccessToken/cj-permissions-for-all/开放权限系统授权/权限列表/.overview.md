# 权限列表

本目录包含HarmonyOS系统权限的API参考文档，主要面向应用开发者。文档详细列出了API 12版本中引入的各类权限定义，涵盖蓝牙、网络、传感器、硬件控制、安全检测、数据存储、车机引擎及窗口管理等核心功能。所有权限均为normal级别，采用system_grant授权方式。这些资料旨在帮助开发者在配置文件中正确声明和使用系统能力，确保应用合规运行。
