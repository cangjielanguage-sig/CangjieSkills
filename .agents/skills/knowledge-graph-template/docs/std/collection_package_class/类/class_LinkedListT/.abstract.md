This directory contains comprehensive API reference documentation for the generic `LinkedList` class within the Cangjie standard library. It details a doubly linked list data structure supporting dynamic sequences, bidirectional traversal, and efficient node-based manipulation. The documentation covers core class properties, constructors, various insertion and removal methods, iterator utilities, and interface extensions for equality and string conversion. It is designed for Cangjie developers seeking to manage collections, understand time complexities, and handle structural modifications or data serialization in their applications.
