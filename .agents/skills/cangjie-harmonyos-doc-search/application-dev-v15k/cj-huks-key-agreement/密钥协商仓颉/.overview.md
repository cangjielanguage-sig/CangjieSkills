# 密钥协商仓颉

This directory serves as a comprehensive technical resource for implementing cryptographic key agreement protocols using the Cangjie programming language within the HarmonyOS ecosystem. It specifically addresses the integration with the HarmonyOS Universal Keystore Service (HUKS) to facilitate secure key exchanges, such as X25519 and Diffie-Hellman. The content covers the complete development lifecycle, including key generation, public key export, agreement execution, and secure key deletion. It highlights critical configuration parameters like the HUKS_TAG_DERIVED_AGREED_KEY_STORAGE_FLAG and provides valid flag combination matrices. This collection is tailored for security developers and system architects working on OpenHarmony applications who require robust, hardware-backed key exchange mechanisms and precise cryptographic key management to ensure data security and privacy in their software solutions.

## Detailed Description

### 密钥协商仓颉_2more.md 密钥协商仓颉_2more.md
This technical guide explains how to implement X25519 key agreement within the HUKS framework using the Cangjie language. It details the development workflow, covering generating asymmetric keys, exporting public keys, performing the agreement, and deleting keys. A key takeaway is the configuration of the HUKS_TAG_DERIVED_AGREED_KEY_STORAGE_FLAG parameter, which determines whether the negotiated key is managed strictly by HUKS or exported to the application. The document provides a matrix of valid flag combinations between key generation and agreement phases. Intended for security developers, this guide ensures secure key exchange and lifecycle management in HarmonyOS applications.

### 示例/
This directory contains practical code examples for the HarmonyOS Universal Keystore Service (HUKS) and Universal Keystore Kit, written in the Cangjie programming language. It focuses on cryptographic operations, specifically asymmetric key agreement algorithms like X25519 and Diffie-Hellman (DH). The examples cover essential workflows such as key generation, session management (init, update, finish), key export, and lifecycle management including deletion. These resources are suitable for developers working within the OpenHarmony ecosystem who need to implement secure key exchange mechanisms and manage cryptographic keys effectively in their applications.
