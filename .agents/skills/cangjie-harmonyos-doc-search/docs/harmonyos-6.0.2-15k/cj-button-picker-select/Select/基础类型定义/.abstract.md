This directory provides essential API reference documentation for fundamental data structures and enumerations utilized within the ArkUI framework, specifically written for the Cangjie programming language. It encompasses configuration classes for UI components such as dividers and dropdown menus, alongside enumerations defining menu alignment strategies. Key topics include the `DividerOptions` class for styling, the `SelectOption` class for menu item configuration, and the `MenuAlignType` enum for layout control. These definitions are critical for developers aiming to customize the appearance and behavior of user interface elements in HarmonyOS applications. This documentation is primarily intended for application developers and UI engineers working with ArkUI version 12 or later who require precise control over component properties and layout logic.
