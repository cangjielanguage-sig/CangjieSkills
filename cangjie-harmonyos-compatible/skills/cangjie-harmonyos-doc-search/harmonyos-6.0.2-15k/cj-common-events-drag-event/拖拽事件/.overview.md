# 拖拽事件

This directory provides comprehensive technical documentation for implementing drag-and-drop functionalities within the ArkUI framework. It covers the complete drag-and-drop lifecycle, including event mechanisms, data transfer via UDMF, and visual customization like backdrop images. The content distinguishes between gesture-based and mouse-driven operations, addressing advanced scenarios such as cross-application data transfer and UI feedback management. It is suitable for developers and UI engineers looking to integrate interactive data movement, copying, or deletion features into their applications using ArkUI or the Cangjie framework.

## Detailed Description

### 拖拽事件_2more.md 拖拽事件_2more.md
This document defines the drag-and-drop event mechanism, explaining how data is transferred between components via mouse or touch gestures. The text covers basic concepts such as the drag operation lifecycle, drag background customization, and the distinct roles of drag sources and targets. Key information includes the use of the UDMF UnifiedData API for secure data encapsulation and specific attributes like onDragStart and dragPreview for visual customization. It also explains how the drag point determines hit testing. This technical reference is intended for developers implementing interactive UI features requiring data movement, copying, or deletion.

### 拖拽背板图.md 拖拽背板图.md
This document explains the configuration and behavior of drag backdrop images within the ArkUI framework, detailing how to customize the visual representation during drag operations. It covers configuration methods using onDragStart and dragpreview attributes, default system screenshot behavior, supported visual styles like opacity and shadow, and specific constraints regarding content overflow and graphical transformations. Key information includes the ability to set custom images via customBuilder or pixelmap, with the system defaulting to a component screenshot if unset. Crucially, system screenshots cannot capture content outside container bounds or apply scale and rotate transformations. This guide targets UI developers implementing drag-and-drop features who need to understand visual limitations and customization options.
