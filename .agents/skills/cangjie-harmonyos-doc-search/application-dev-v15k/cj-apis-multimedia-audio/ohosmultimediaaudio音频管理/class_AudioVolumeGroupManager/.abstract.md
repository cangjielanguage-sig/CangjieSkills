This directory contains API reference documentation for the `AudioVolumeGroupManager` class in the Cangjie programming language, part of the AudioKit framework. It covers comprehensive audio volume management capabilities, including retrieving device amplitude, volume limits, system volume in decibels, and mute states. Additionally, it details methods for subscribing to and unsubscribing from audio events like microphone state and ring mode changes. The documentation includes function signatures, parameter descriptions, return values, and error handling. It is suitable for software developers and multimedia engineers building applications requiring precise audio control and system state monitoring.
