This directory provides comprehensive API reference documentation for the UInt16 type within the Cangjie programming language. It details the 16-bit unsigned integer type, defining its specific range and core functionalities. The documentation covers essential extensions such as mathematical constants (Max, Min), the Comparable interface for size comparisons, the Countable interface for positional arithmetic, and the Hashable interface for hash generation. Furthermore, it includes specific extensions for string conversion via the ToString interface. This resource is designed for Cangjie developers who need a deep understanding of type behaviors, interface implementations, and method signatures for effectively utilizing unsigned 16-bit integers in their applications.
