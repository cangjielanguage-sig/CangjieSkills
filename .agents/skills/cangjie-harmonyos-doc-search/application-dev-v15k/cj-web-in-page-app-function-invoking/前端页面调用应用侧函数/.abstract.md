This directory focuses on the technical implementation of enabling frontend web pages to invoke application-side native functions within the HarmonyOS ecosystem. It covers essential techniques for hybrid app development, specifically detailing how to use Web components to bridge JavaScript and native code. The content includes registration methods, memory management, and security configurations using both the Cangjie language and ArkTS. It is suitable for HarmonyOS developers looking to facilitate secure and efficient communication between web content and native application logic using ArkUI and ArkWeb frameworks.
