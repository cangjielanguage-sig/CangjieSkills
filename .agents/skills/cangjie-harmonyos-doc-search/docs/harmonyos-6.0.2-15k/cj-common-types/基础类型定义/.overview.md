# 基础类型定义

This directory provides API reference documentation for fundamental data structures in the Cangjie language within the ArkUI framework. It covers geometric definitions, styling properties, layout utilities, and enumerations for UI components. Designed for HarmonyOS developers, these definitions enable the construction of responsive and visually consistent interfaces, targeting API versions 12 and 19.

## Detailed Description

### class_Area.md class_Area
Defines geometric properties (width, height, position) of UI elements in Float64 units, distinguishing between parent-relative and global screen coordinates.

### class_BorderRadiuses.md class_BorderRadiuses
Defines border corner radii using Length properties for all four corners, defaulting to 0.vp.

### class_DividerStyleOptions.md class_DividerStyleOptions
Configuration object for styling divider lines, defining read-only properties for stroke width, color, and margins.

### class_EdgeColor.md class_EdgeColor
Defines border colors for the top, right, bottom, and left sides, defaulting to Color.BLACK.

### class_EdgeStyles.md class_EdgeStyles
Defines border styles (e.g., Solid) for the four sides of a UI component.

### class_Fonts.md class_Fonts
Defines text styling properties including size, weight, family, and style, with specific defaults like "HarmonyOS Sans".

### class_LocalizedPadding.md class_LocalizedPadding
Describes padding dimensions supporting RTL/LTR layout directions using start and end properties.

### class_Margin_3more.md class_Margin_3more
Layout utilities for component spacing (Margin) and coordinate shifts (MenuOffset, Offset).

### class_Padding_4more.md class_Padding_4more
Defines inner spacing (Padding), coordinate management (Position), and interaction enums (AccessibilityHoverType).

### class_RectResult.md class_RectResult
Data structure for storing component position and dimensions (Float64), used for retrieving layout information.

### class_Rectangle.md class_Rectangle
Specifies region positions and touch hot zones using Length type, defaulting to full size and origin.

### enum_Alignment_4more.md enum_Alignment_4more
Enums for layout positioning (Alignment), animation playback states (AnimationStatus), screen orientation (AppRotation), and UI placement (ArrowPointPosition).

### enum_Axis_4more.md enum_Axis_4more
Enums for layout orientation (Axis), constraint barriers (BarrierDirection), scrollbar visibility (BarState), and blend modes (BlendApplyType).

### enum_BlurStyleActivePolicy_6more.md enum_BlurStyleActivePolicy_6more

### enum_CanvasFillRule_4more.md enum_CanvasFillRule_4more

### enum_CompositeOperation.md enum_CompositeOperation
Defines graphical content compositing modes (e.g., SourceOver, DestinationOver) for blending new and existing content.

### enum_ControlSize_2more.md enum_ControlSize_2more
Enums for component dimensions (SMALL, NORMAL) and text copying modes (None, InApp, LocalDevice).

### enum_Curve.md enum_Curve

### enum_DialogAlignment_4more.md enum_DialogAlignment_4more

### enum_EdgeEffect_5more.md enum_EdgeEffect_5more

### enum_FontWeight.md enum_FontWeight
