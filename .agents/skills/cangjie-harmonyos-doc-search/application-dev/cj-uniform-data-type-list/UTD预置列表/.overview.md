# UTD预置列表

This directory defines the Uniform Type Descriptor (UTD) system, a standard for resolving data type ambiguity across formats like MIME types and file extensions. It organizes preset types into Basic Types, System-associated Types, and Application-defined Types to ensure seamless cross-application and cross-device data transmission. The content includes detailed mapping tables for UTD-IDs, file extensions, and MIME types across various platforms (OpenHarmony, MacOS, Android, etc.) and software ecosystems. It is suitable for developers, system architects, and integrators working on data interoperability, file type recognition, and cross-platform communication protocols.

## Detailed Description

### UTD预置列表.md UTD预置列表.md
This document defines the Uniform Type Descriptor (UTD) system, which standardizes data type descriptions to resolve ambiguity across different formats like MIME types and file extensions, facilitating seamless cross-application and cross-device data transmission. The content is organized into three main categories of preset types: Basic Types, System-associated Types, and Application-defined Types. UTD unifies various type descriptors to prevent recognition failures during data transfer, providing presets categorized by universality and usage scenarios to simplify business integration. This reference guide targets developers and system architects working on data interoperability, requiring an understanding of data formats and cross-platform communication protocols.

### 系统关联类型.md 系统关联类型.md
This document serves as a reference list defining system-associated data types that facilitate cross-application interaction within specific operating systems or platforms. It covers a detailed table of predefined types categorized by platform, including OpenHarmony, MacOS, Debian, Android, RedHat, and HarmonyOS, mapping UTD-IDs to belonging types, file extensions, MIME types, and descriptions. Key takeaways include the identification scheme using UTD-IDs (e.g., openharmony.hap, macos.dmg) and the classification hierarchy, highlighting specific formats like HAP, HAR, APK, and RPM. This reference guide targets developers and system integrators working with file type associations, data transfer, or application packaging across heterogeneous systems, particularly within the OpenHarmony ecosystem.

The content covers a wide range of formats, including Microsoft Office, OpenDocument, Adobe products, AutoCAD, and multimedia files.
