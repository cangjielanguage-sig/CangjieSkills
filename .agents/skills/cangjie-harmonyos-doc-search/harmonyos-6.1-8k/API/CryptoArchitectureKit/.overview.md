# CryptoArchitectureKit

The CryptoArchitectureKit serves as a comprehensive cryptographic framework service designed specifically for developers using the Cangjie language within the OpenHarmony ecosystem. It provides a unified interface for cryptographic algorithms, abstracting underlying implementation details to facilitate secure application development. This kit covers essential components such as API definitions, detailed error code references, and structural guides for handling encryption and decryption operations. Currently in the Beta stage, it focuses on API structure and exception handling. It is suitable for Cangjie language developers looking to integrate robust security features, debug cryptographic issues, and understand the `ohos.security.crypto_framework` module.

## Detailed Description

### README_zh/
This directory contains the index documentation for the Crypto Architecture Kit (encryption and decryption algorithm framework service), designed specifically for Cangjie language developers. Acting as the navigation center for the cryptographic library, it primarily covers Cangjie API interface definitions and error code lists, while linking to detailed descriptions of the `ohos.security.crypto_framework` module. Currently, this service is in the Beta stage, focusing on showcasing the framework's API structure and exception handling mechanisms. This document is suitable for users developing applications in the Cangjie language, serving as an entry point for consulting encryption and decryption interface definitions and obtaining debugging information.

### cj-apis-crypto/
This directory contains the API reference documentation for the OpenHarmony Cangjie language cryptographic framework. It is designed to provide a unified interface for cryptographic algorithms, abstracting the underlying implementation details to facilitate development and usage. It serves as the primary resource for understanding the specific functions, classes, and interfaces available within the crypto framework, enabling developers to effectively implement security features in their applications.

### cj-errorcode-crypto/
This directory specifically houses the error code reference manual for the crypto framework. Its core purpose is to provide developers with a complete guide for accurately identifying and efficiently handling various exceptions that may occur in the encryption and decryption modules. The documentation comprehensively covers three key areas: memory errors (e.g., 17620001), runtime errors (e.g., 17620002), and algorithm operation errors (e.g., 17630001). Through detailed error message analysis, analysis of potential causes (including scenarios like insufficient system memory or third-party library interaction failures), and specific troubleshooting steps, this material aims to help developers with basic system debugging capabilities quickly locate the root causes of technical faults during development, thereby significantly improving problem-solving efficiency.
