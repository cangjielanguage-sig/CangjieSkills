# 网页中安全区域计算和避让适配

This directory focuses on the technical implementation of safe area calculations and avoidance adaptation for web pages within the ArkUI framework. It addresses the critical challenge of layout conflicts caused by immersive mode and system UI elements, such as status and navigation bars. Key topics include the `expandSafeArea` attribute, `viewport-fit` meta tags, and CSS `env()` functions for precise layout adjustment. This resource is suitable for developers using the Cangjie language and ArkWeb kernel who need to ensure content visibility and seamless user experiences on devices with irregular screens or immersive layouts.

## Detailed Description

### 实现场景.md 实现场景.md
This technical guide explains how to implement immersive display effects for Web components within the ArkUI framework. It covers enabling immersive mode via the expandSafeArea attribute, configuring viewport behavior using the viewport-fit meta tag, and managing element layout to avoid system UI overlaps using CSS env() functions. Key takeaways include the requirement for viewport-fit=cover to enable safe area adaptation and the use of safe-area-inset-* variables with fallback values and math functions like calc() to prevent content obstruction by status or navigation bars. Targeted at developers using the Cangjie language and ArkUI, this document provides code examples for creating seamless web experiences in mobile applications.

Keywords: ArkUI, Web component, immersive mode, expandSafeArea, viewport-fit, safe-area-inset, CSS env, Cangjie, layout adaptation.

### 网页中安全区域计算和避让适配_2more.md 网页中安全区域计算和避让适配_2more.md
This document outlines the mechanism for calculating safe areas and implementing avoidance adaptation in web pages to resolve layout conflicts with system UI elements during immersive mode. It defines safe areas versus non-safe areas like status bars and navigation bars, illustrating the overlap issue that occurs when immersive effects are enabled. The text explains how the ArkWeb kernel utilizes W3C CSS standards to monitor and calculate the intersection between the Web component and system areas, determining the specific distances needed for element avoidance. This technical guide targets web developers seeking to ensure proper display on devices with irregular screens or immersive layouts.
