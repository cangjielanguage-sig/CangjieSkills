This directory serves as a comprehensive technical resource dedicated to the ArkWeb multi-process architecture within the Cangjie application ecosystem. It provides in-depth guidance on managing web rendering processes, a critical aspect for ensuring high system performance, robust stability, and enhanced security. The content thoroughly details the specific responsibilities of five key processes: Application, Foundation, Web Incubation, Web Rendering, and Web GPU. Furthermore, it elucidates the default strategies employed for rendering process sharing across various device types, distinguishing between mobile and 2in1 devices. This documentation is specifically designed for Cangjie developers who require advanced knowledge of process management APIs, such as setRenderProcessMode and terminateRenderProcess, to effectively optimize their web components.
