# cj-photoAccessHelper-userAlbum-guidelines

This directory serves as a comprehensive technical resource specifically curated for HarmonyOS developers who are focusing on media management using the Cangjie programming language and the MediaLibraryKit framework. It provides detailed, step-by-step guidelines on interacting with user albums, covering a wide range of essential operations. These include retrieving album lists, accessing images and videos, renaming albums, adding media, and removing assets. Key technical concepts discussed in depth include permission handling, the utilization of `photoAccessHelper`, and the implementation of `MediaAlbumChangeRequest`. This documentation is primarily designed for developers building media-centric applications who require robust programmatic control over the device's media library to ensure seamless user experiences and efficient data handling. The content ensures that developers understand the necessary APIs and workflows to manipulate media assets securely and effectively within the HarmonyOS ecosystem. By mastering these guidelines, developers can create powerful applications that fully leverage the device's multimedia capabilities while maintaining strict adherence to system protocols. This documentation is an essential reference for ensuring that media manipulation features are implemented correctly and performantly in a HarmonyOS environment.
