This directory provides comprehensive API reference documentation for the `ohos.resource_manager` module in the Cangjie programming language, designed for HarmonyOS application development. It covers essential components for managing application resources, including device configuration, capabilities, and resource retrieval mechanisms. Key topics include the `Configuration` and `DeviceCapability` classes, enumerations for value types and screen settings, and the core `ResourceManager` class for handling localization and media. This documentation is suitable for HarmonyOS developers and system integrators who need to programmatically access and manage dynamic resources, implement internationalization, and adapt to different device hardware using the Cangjie language.
