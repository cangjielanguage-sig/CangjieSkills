This directory provides comprehensive API reference documentation for the `StringWriter` generic class and its associated output functions within the Cangjie programming language. It details the class structure, which utilizes a 4096-byte internal buffer and is currently limited to UTF-8 encoding. The content covers methods for writing various primitive data types, including integers, floats, and booleans, to an `OutputStream`. Additionally, it documents extensions for resource management and stream seeking. This documentation is essential for Cangjie developers implementing I/O operations, buffered writing, and console output who require specific syntax and interface implementation details.
