# 事件分发

This directory provides comprehensive documentation on the event dispatch mechanisms within the ArkUI framework. It covers the fundamental concepts of event handling, including the classification of touch and mouse events, and details the critical Touch Test process used to determine event response chains. Key topics include the algorithms for collecting response chains, traversal orders, and how component properties like `hitTestBehavior` influence event propagation. This resource is designed for ArkUI developers and UI engineers who need to understand the underlying logic of user interactions, customize gesture recognition, or manage component response behaviors effectively.

## Detailed Description

### 事件响应链的收集.md 事件响应链的收集.md
This technical reference document explains the mechanism and algorithm for collecting event response chains in the ArkUI framework. It covers the specific traversal order, defined as a right subtree priority post-order traversal, and provides Cangjie pseudocode for implementation. The document illustrates the process with a component tree example, highlighting that the collection follows a reverse iteration order. Key takeaways include understanding how the `hitTestBehavior` property, specifically when set to Default, blocks sibling nodes during chain collection, resulting in a specific sequence like 5, 3, 1. This guide targets ArkUI developers and UI engineers who need to understand touch event propagation, response logic, and component interaction behaviors.

### 概述.md 概述.md
This document provides a conceptual overview of event dispatch mechanisms within the ArkUI framework. It covers the definition of event dispatch, the classification of touch events into Touch and Mouse categories, and the specific input sources and triggerable events for each. The core takeaway is that the Touch Test is the critical process determining the event response chain and final component distribution, regardless of the input source type. This reference material targets ArkUI developers seeking to understand the underlying logic of user interaction handling. Keywords: ArkUI, event dispatch, touch test, touch events, mouse events, user interaction.

### 触摸测试.md 触摸测试.md
This technical guide defines the ArkUI touch testing process, which determines component response areas and constructs event response chains based on input coordinates. It details the basic traversal flow, touch test control modes, disable control, touch hot zone settings, and security component interactions. The document explains how properties like hitTestBehavior (Default, None, Block, Transparent) influence sibling and parent-child event propagation, and how enabled or responseRegion settings impact event collection. Intended for ArkUI developers seeking to customize event handling and gesture recognition logic.

Keywords: ArkUI, Touch Test, hitTestBehavior, Event Response Chain, Component Tree, Touch Hot Zone, Gesture Recognition
