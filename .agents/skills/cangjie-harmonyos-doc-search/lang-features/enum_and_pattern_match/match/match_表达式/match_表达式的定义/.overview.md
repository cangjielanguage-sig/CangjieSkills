# match_表达式的定义

本目录详细介绍了仓颉编程语言中 match 表达式的定义、语法结构及执行逻辑。内容涵盖了含匹配值与无匹配值的 match 表达式、case 分支的模式匹配规则、匹配的穷尽性要求以及 where 关键字的使用。文档重点讲解了如何通过通配符保证覆盖所有取值，以及如何区分基于模式和基于布尔值的匹配机制。核心关键词包括：match 表达式、模式匹配、穷尽性检查、where 守卫、控制流。适合希望深入理解仓颉语言控制流与条件逻辑的开发者阅读。

## 详细描述

### match_表达式的定义_1.md
本文档详细介绍了仓颉编程语言中含匹配值的 match 表达式的定义、语法结构及执行逻辑。主要内容包括 match 表达式的基本构成、case 分支的模式匹配规则、匹配的穷尽性要求以及如何处理非穷尽枚举。文档重点强调了必须覆盖所有可能取值，通常使用通配符 _ 来保证，并介绍了使用 where 关键字添加模式守卫以进行额外条件判断。作为语言参考文档，旨在帮助开发者掌握仓颉的控制流与模式匹配机制。

### match_表达式的定义_2.md
本文档旨在解释仓颉编程语言中 match 表达式的定义与用法，重点涵盖了带守卫的标准模式匹配和无匹配值的 match 表达式。文档通过代码示例详细介绍了如何使用 where 守卫处理枚举类型，并阐述了 case 分支包含布尔表达式而非模式的特殊语法。关键信息指出，无匹配值的 match 表达式会按顺序判断条件，直到遇到值为 true 的分支并执行相应代码。本教程面向仓颉语言开发者，旨在帮助其掌握控制流和条件逻辑，特别是区分基于模式和基于布尔值的匹配机制。
