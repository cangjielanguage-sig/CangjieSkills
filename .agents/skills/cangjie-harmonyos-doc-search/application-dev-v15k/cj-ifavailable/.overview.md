# cj-ifavailable

This directory serves as a comprehensive resource for the `cj-ifavailable` project, specifically designed to facilitate API tagging and management within the Cangjie programming language ecosystem. It provides in-depth guidance on utilizing the `@IfAvailable` macro expression, a critical tool for developers aiming to handle API versioning and System Capabilities (syscap) with precision. The content covers essential concepts such as compile-time scope restrictions, runtime execution logic, and strategies for maintaining code compatibility across various SDK versions and device configurations. This documentation is highly suitable for Cangjie developers working in DevEco Studio who require fine-grained control over API availability. By leveraging these resources, developers can effectively prevent deployment errors and ensure their applications operate seamlessly across diverse hardware environments and system capabilities.
