# cj-component-startup-rules

This directory serves as a comprehensive technical resource for understanding and implementing the startup rules governing application components within the HarmonyOS ecosystem. It specifically focuses on the UIAbility component within the Stage model, detailing the necessary protocols to enhance both user experience and system security. The content covers critical aspects such as general restrictions, same-device startup behaviors, and the complexities of distributed cross-device scenarios. Developers will find detailed information on essential permissions like `START_ABILITIES_FROM_BACKGROUND` and `DISTRIBUTED_DATASYNC`, as well as configuration requirements for the `exported` field. These guidelines are strictly applicable for systems running API 18 and above. This documentation is primarily intended for HarmonyOS developers and system architects who are responsible for building secure, compliant applications that interact seamlessly across different devices and contexts while adhering to the latest system constraints and avoiding common security pitfalls.

## Detailed Description

The following file provides the complete set of rules and guidelines developers must follow to ensure their application components function correctly within the HarmonyOS security framework.

### cj-component-startup-rules.md cj-component-startup-rules.md
This document defines the startup rules for application components, specifically UIAbility, in the Stage model to enhance user experience and security. It covers general restrictions, same-device startup scenarios, and distributed cross-device startup scenarios. Key rules include verifying the exported field for cross-app calls, requiring the START_ABILITIES_FROM_BACKGROUND permission for background launches (with exceptions for 2in1 devices), and needing DISTRIBUTED_DATASYNC for cross-device calls. These rules apply from API 18. This guide targets HarmonyOS developers needing to implement component startup logic while adhering to system security constraints.
