This directory provides comprehensive API reference documentation for the `CanvasPattern` class, a specialized component within the Cangjie UIKit designed for high-fidelity 2D graphics rendering. It focuses on the technical implementation of image fill templates, allowing developers to define how images repeat across a canvas surface. The documentation thoroughly covers the class definition, the initialization constructor required to instantiate patterns, and the `setTransform` method, which is vital for applying matrix transformations to adjust the pattern's coordinate space. Additionally, it specifies system capability requirements, confirming support for features starting from version 19. This resource is indispensable for ArkUI developers and graphics engineers who aim to implement sophisticated visual effects and precise pattern manipulations in their application interfaces, ensuring they utilize the latest graphical capabilities available in the system.
