# cj-common-events-touch-screen-event

This directory provides a comprehensive technical guide for developers utilizing the Cangjie UI framework to effectively manage touch screen interactions. It focuses on the critical aspects of event handling, specifically distinguishing between Click Events and Touch Events. The content explains how to use the `onClick` function for standard press-and-lift actions and the `onTouch` function for tracking detailed finger movements such as Down, Move, Up, and Cancel. Furthermore, it addresses advanced features like multi-touch support and the extraction of specific event data, including coordinates, touch IDs, and component dimensions. Designed for application developers, this documentation offers practical Cangjie code examples to illustrate how to implement interactive features like toggling image visibility. It serves as a vital reference for building responsive and dynamic user interfaces within the UIKit environment.

## Detailed Description

### cj-common-events-touch-screen-event.md cj-common-events-touch-screen-event.md
This technical guide explains how to handle touch screen interactions in the Cangjie UI framework, specifically focusing on click and touch event callbacks. The document covers two primary event types: Click Events, triggered by a complete press and lift action using the onClick function, and Touch Events, which track granular actions like Down, Move, Up, and Cancel via the onTouch function. Key information includes the support for multi-touch interactions and access to detailed event data such as coordinates, touch IDs, and component dimensions. The guide provides Cangjie code examples demonstrating how to toggle image visibility and display touch details. Intended for application developers, this documentation serves as a practical reference for implementing interactive UI components using the UIKit.
