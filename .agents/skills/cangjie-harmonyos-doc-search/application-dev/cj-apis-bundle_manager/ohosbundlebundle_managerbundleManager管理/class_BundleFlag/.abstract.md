This directory provides comprehensive API reference documentation for the Cangjie `BundleFlag` class, a core component within the BundleManager framework. It focuses on the bitmask flags that developers use to specify exactly which types of information are retrieved during bundle queries. The documentation details various static constants, outlining their hexadecimal values and the specific data subsets they include or exclude, ranging from application info and abilities to metadata and permissions. It also clarifies critical dependency rules, such as the requirement to combine ability-related flags with HAP module flags. This resource is essential for Cangjie developers and system engineers aiming to construct precise data retrieval requests, ensuring compatibility with system capabilities defined for API version 22.
