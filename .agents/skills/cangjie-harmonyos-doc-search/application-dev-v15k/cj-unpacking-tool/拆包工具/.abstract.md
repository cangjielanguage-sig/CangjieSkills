This directory provides comprehensive documentation for the HarmonyOS Unpacking Tool, a utility designed to decompress and analyze HAP, HSP, App, and APPQF packages. It covers both command-line usage and Java API integration for extracting configuration metadata and debugging application structures. The content includes interface references, command instructions, and detailed data structure schemas for various package components. Suitable for HarmonyOS developers, application market engineers, and system integrators who need to programmatically parse package contents or inspect internal metadata during development and debugging.
