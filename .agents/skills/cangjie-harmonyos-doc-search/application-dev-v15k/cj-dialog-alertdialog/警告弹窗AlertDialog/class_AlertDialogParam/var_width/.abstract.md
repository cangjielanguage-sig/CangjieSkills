This directory contains API reference documentation for the Cangjie ArkUI framework, focusing on dialog and alert component configuration. It covers the initialization of alert dialogs, setting dialog backboard width, and extensive customization options for layout, appearance, and interaction. Key topics include the `init` function, `width` properties, background styling, and modal behavior. This resource is suitable for software developers and UI engineers using the Cangjie language to build and customize user interface components within the ArkUI ecosystem, specifically targeting API version 19 and above.
