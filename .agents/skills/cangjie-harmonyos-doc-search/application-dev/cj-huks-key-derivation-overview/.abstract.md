This directory provides a comprehensive technical reference for OpenHarmony HUKS (Hardware User Key Store) key derivation mechanisms. It covers supported Key Derivation Functions (KDF), specifically HKDF and PBKDF2, along with their usage constraints and algorithm specifications. The documentation details how derived keys are managed within the Trusted Execution Environment (TEE) and outlines rules for key aliasing and overwriting. It is intended for developers implementing cryptographic security features who need to ensure platform compatibility and adhere to mandatory specifications for secure key management. The content highlights the distinction between HUKS-managed keys and direct passwords, emphasizing the security benefits of TEE integration. By following these guidelines, developers can effectively implement secure key derivation strategies that align with OpenHarmony standards, ensuring robust protection for sensitive data and cryptographic operations.
