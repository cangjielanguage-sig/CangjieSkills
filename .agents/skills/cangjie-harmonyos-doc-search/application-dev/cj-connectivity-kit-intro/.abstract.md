This directory serves as the definitive introductory guide for the Connectivity Kit, a comprehensive framework designed to provide applications with essential wireless communication services. It is centered on enhancing the user experience by enabling robust connectivity features. The content provides an in-depth look at specific Bluetooth modules, distinguishing between BLE for low-power communication and A2DP for high-quality audio transmission. Furthermore, it details various WLAN modes, including STA, P2P, and AP configurations. Key aspects of the documentation include the definitions of these technologies, the critical requirement for applications to actively manage connections, and the mandatory process of obtaining explicit user authorization to access hardware capabilities. This resource is specifically tailored for developers who need foundational concepts, clear technical definitions, and direct links to relevant API references for successfully integrating wireless features into their applications.
