# argopt_package_struct

This directory serves as a comprehensive technical resource for the `argopt` package in the Cangjie programming language, specifically focusing on the structural definitions used to manage command-line argument parsing results. It provides an in-depth look at the `ParsedArguments` struct, which is the fundamental object developers utilize to encapsulate and retrieve data processed from the command line. The documentation clearly distinguishes between two types of inputs: positional arguments (stored as an Array) and flag-based options (stored as a ReadOnlyMap). By defining these properties, the directory enables developers to effectively separate and access different types of user inputs. The scope of this directory is strictly limited to the structural definition of the parsed arguments, providing the necessary API details without covering the parsing algorithms themselves. This content is tailored for Cangjie developers, systems programmers, and software engineers who are implementing command-line interfaces (CLIs) and need a reliable reference for accessing parsed data. It assumes the reader has a basic familiarity with Cangjie syntax and its standard collection libraries.

## Detailed Description

### argopt_package_struct.md argopt_package_struct.md

This file is the central documentation for the package's data model. It provides API reference documentation for the ParsedArguments struct in the Cangjie argopt package, designed to store argument parsing results. The main sections detail the struct's definition and its two public properties: nonOptions and options. Key information includes that nonOptions is an Array holding arguments without flags, while options is a ReadOnlyMap storing key-value pairs for parsed flags. This reference is intended for Cangjie developers implementing command-line interfaces who need to access parsed data. It assumes familiarity with Cangjie syntax and standard collection types.
