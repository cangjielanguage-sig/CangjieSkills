This directory functions as a vital technical resource designed to guide developers through the complex process of determining the correct method for applying application permissions. It thoroughly addresses the nuances of permission levels and authorization types, offering a structured approach to decision-making that involves APL level matching. The guide clearly distinguishes between system_grant and user_grant authorizations, providing detailed instructions for the latter, which include declaration, object association, and the triggering of dynamic authorization dialogs. Furthermore, it covers the implementation of ACL for restricted permissions. To assist with quick reference, the document includes a summary table mapping open and restricted permissions to their respective operational paths. This guide is specifically tailored for application developers who are responsible for ensuring that their software implements permissions correctly and adheres to strict compliance and security standards.
