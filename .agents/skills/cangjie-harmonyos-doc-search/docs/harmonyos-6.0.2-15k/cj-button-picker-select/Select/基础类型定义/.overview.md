# 基础类型定义

This directory provides essential API reference documentation for fundamental data structures and enumerations utilized within the ArkUI framework, specifically written for the Cangjie programming language. It encompasses configuration classes for UI components such as dividers and dropdown menus, alongside enumerations defining menu alignment strategies. Key topics include the `DividerOptions` class for styling, the `SelectOption` class for menu item configuration, and the `MenuAlignType` enum for layout control. These definitions are critical for developers aiming to customize the appearance and behavior of user interface elements in HarmonyOS applications. This documentation is primarily intended for application developers and UI engineers working with ArkUI version 12 or later who require precise control over component properties and layout logic.

## Detailed Description

The following files provide the specific technical details for each type definition found in this directory.

### class_DividerOptions.md class_DividerOptions.md
This API reference document defines the DividerOptions class in the Cangjie language, used to configure parameters for divider components in ArkUI. The content details read-only properties for stroke width, start and end margins, and color, specifying acceptable units like vp and px. It explains the primary constructor for initializing these values with specific constraints, such as maximum width limits. Intended for HarmonyOS developers, this documentation requires knowledge of ArkUI system capabilities and serves as a guide for styling UI elements like TextPicker dividers.

### class_SelectOption.md class_SelectOption.md
This document provides API reference documentation for the Cangjie SelectOption class, designed to configure parameters for dropdown menu components within the ArkUI framework. It covers the class definition, two public properties for option content and icon, and four constructor overloads supporting String or AppResource types. Key takeaways include the read-write nature of properties and the requirement for named icon parameters. Intended for application developers using ArkUI version 12 or later, this guide assists in implementing selectable list items with localized resources or static strings.

### enum_MenuAlignType.md enum_MenuAlignType.md
This document serves as API reference documentation for the Cangjie programming language, defining the MenuAlignType enumeration used to specify menu alignment strategies within the ArkUI framework. The content details three primary enum variants: START, CENTER, and END. Each variant is explained with specific functionality, noting that START and END align based on language direction, while CENTER provides standard centering. Key metadata includes system capabilities and the requirement of API version 12. This reference is intended for developers building user interfaces who need to programmatically control menu positioning. Keywords include Cangjie, ArkUI, enum, alignment, and API reference.
