This directory contains comprehensive API documentation for component properties within the ArkUI framework, specifically tailored for the Cangjie programming language. It focuses on the intricacies of grid layout manipulation, providing developers with the necessary tools to control column offsets, element ordering, and spanning behaviors. The documentation covers overloaded functions that accept various parameter types, such as Int32 and GridColColumnOption, to facilitate flexible UI design. Key concepts include responsive layout strategies, conditional rendering based on span values, and method chaining for efficient code structure. This resource is essential for UI developers and software engineers aiming to build sophisticated, grid-based user interfaces in ArkUI applications using Cangjie. It ensures precise control over how components are positioned and displayed within a grid system.
