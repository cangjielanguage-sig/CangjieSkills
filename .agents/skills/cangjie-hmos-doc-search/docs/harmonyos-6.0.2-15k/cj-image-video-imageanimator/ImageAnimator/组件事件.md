## 组件事件

### func onCancel(() -> Unit)

```cangjie
public func onCancel(callback: () -> Unit): This
```

**功能：** 动画返回最初状态时触发该事件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|callback|()->Unit|是|-|回调函数，动画返回最初状态时触发。|
