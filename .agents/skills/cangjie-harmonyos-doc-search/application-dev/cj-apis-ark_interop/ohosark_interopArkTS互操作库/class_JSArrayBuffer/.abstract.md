This directory contains API reference documentation for the `JSArrayBuffer` class in the Cangjie programming language, specifically designed for handling generic raw binary data buffers in JavaScript interoperability scenarios. It covers the core class structure, properties like `byteLength`, and a comprehensive suite of methods for converting binary data into various typed arrays (e.g., Float32, Int16, UInt8) compatible with ArkTS. The documentation includes details on return types, error handling (BusinessException), and thread safety within a JSContext. It is suitable for HarmonyOS developers and cross-language engineers working with Cangjie to manage data exchange between Cangjie and JavaScript environments.
