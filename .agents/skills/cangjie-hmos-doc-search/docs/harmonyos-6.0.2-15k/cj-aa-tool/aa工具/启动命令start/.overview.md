# 启动命令start

This directory serves as an essential technical resource for developers working within the HarmonyOS environment, specifically focusing on the `aa start` command used to initiate Stage model application components. It provides a thorough examination of launching UIAbility and ServiceExtensionAbility elements via the command line, distinguishing between explicit and implicit startup methods. Key topics include the configuration of URI schemes, the transmission of various parameter types (integer, boolean, string), and the retrieval of these parameters within Cangjie code. The documentation also addresses critical operational aspects such as error code troubleshooting, return value interpretation, and window positioning constraints unique to 2in1 devices. This guide is ideally suited for software developers and QA engineers seeking to streamline application lifecycle management, conduct automated testing, or debug complex application behaviors using shell commands.

## Detailed Description

### 启动命令start_1.md

This reference document details the aa start command used to launch Stage model application components, specifically UIAbility or ServiceExtensionAbility, via the command line. It covers syntax for both explicit and implicit ability starts, providing a comprehensive list of parameters such as device ID, bundle name, window positioning options, and debug flags. Key information includes return values, a detailed table of error codes for troubleshooting, and specific constraints for window positioning on 2in1 devices. This guide is intended for developers and testers who need to manage application lifecycles, pass startup parameters, or debug applications using the shell.

### 启动命令start_2.md

This technical guide explains how to use the aa start command for implicit Ability startup in HarmonyOS development. It details configuring the target application's module.json5 with URI schemes and skills, then demonstrates command-line syntax for launching apps via URIs. Key sections cover passing parameters (integer, boolean, string) using flags like --pi and --ps, retrieving these parameters in Cangjie code within the onCreate method, and launching a browser with a specific action. The document serves as a reference for developers needing to test or trigger specific application flows via the command line interface.
