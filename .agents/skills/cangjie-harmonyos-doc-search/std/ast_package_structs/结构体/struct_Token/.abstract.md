This directory provides comprehensive API documentation for the `Token` struct, a critical data structure within the Abstract Syntax Tree (AST) package designed for the Cangjie programming language. As the smallest lexical unit, the Token struct is essential for parsing source code and generating syntax trees. The documentation covers the struct's definition, including its core properties such as kind, position, and value, as well as its inheritance from the ToBytes interface for serialization. Additionally, it details operator overloads that enable developers to perform equality checks and merge token collections efficiently. This resource is specifically tailored for compiler developers, language engineers, and tool creators who require a deep understanding of lexical analysis and token manipulation to build robust Cangjie language tools and interpreters.
