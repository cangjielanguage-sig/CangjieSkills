This directory serves as a comprehensive technical resource for the `ohos.device_info` module, specifically tailored for HarmonyOS developers utilizing the Cangjie programming language. It provides detailed API references and implementation guides for querying read-only terminal device information, encompassing hardware specifications, build metadata, and operating system distribution details. The documentation thoroughly covers essential aspects including module imports, required system capabilities like `SystemCapability.Startup.SystemInfo`, and specific permissions such as `ohos.permission.sec.ACCESS_UDID` for accessing sensitive data like serial numbers. It is designed for developers who need to programmatically access device configuration for system analysis, compatibility checks, or application diagnostics, ensuring they understand how to execute code within template projects without modifying device settings. The content clarifies that while developers can read extensive device data, configuration changes are not supported through this interface.
