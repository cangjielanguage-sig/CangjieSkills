This directory provides comprehensive API reference documentation for the `ApplicationInfo` struct in the Cangjie language, designed for the Bundle Manager framework. It details the structural definition of application configuration, focusing on read-only properties that expose critical metadata. Key areas covered include application resources (icons, labels), security attributes (permissions, UIDs), and runtime settings (debug flags, distribution types). The documentation specifies data types like `AppResource`, `String`, and `Int32`, while noting API version requirements starting from version 12. This resource is essential for Cangjie developers and system engineers who need to programmatically retrieve application bundle information, manage localization resources, or verify system compatibility and status.
