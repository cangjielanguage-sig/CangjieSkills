# cj-telephony-sms

This directory serves as a comprehensive technical repository for developers implementing SMS (Short Message Service) functionalities within HarmonyOS applications using the Cangjie programming language. It provides in-depth documentation on the integration of telephony services, covering core concepts, system constraints, and the specific API interfaces required for SMS management. The content guides developers through essential tasks such as message creation, SIM slot configuration, and service center management. Furthermore, it details the procedures for launching the SMS editing interface using URI protocols or in-app jumps, alongside the necessary steps for handling permissions and constructing Want objects. This resource is specifically designed for mobile developers who need to facilitate seamless communication between third-party applications and the system messaging interface, ensuring robust and compliant feature implementation.

## Detailed Description

### 短信服务/
This directory provides comprehensive technical documentation for integrating SMS services within HarmonyOS applications. It covers core concepts, system constraints, and API interfaces for SMS management, including message creation and SIM slot configuration. Key topics include launching the SMS editing interface via URI protocols or in-app jumps using the Cangjie language, handling permissions, and constructing Want objects. Suitable for mobile developers, these guides facilitate the implementation of features like sending messages, managing service centers, and navigating between third-party apps and the system messaging interface.
