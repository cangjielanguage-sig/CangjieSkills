# cj-apis-app-ability-dialog_request

本目录包含仓颉开发环境中 `ohos.app.ability.dialog_request` 模块的 API 参考文档，专注于提供处理系统模态弹框的能力。该文档详细阐述了模块导入方法、所需权限声明、仓颉工程配置步骤，以及 `RequestResult` 类和 `ResultCode` 枚举的具体定义。核心内容涉及模态弹框作为拦截底层事件的系统弹框机制，以及包含结果码和 Want 信息的请求结果结构。该文档主要面向需要实现模态弹框交互的鸿蒙应用开发者，要求读者具备仓颉语言基础及 AbilityKit 相关知识。
