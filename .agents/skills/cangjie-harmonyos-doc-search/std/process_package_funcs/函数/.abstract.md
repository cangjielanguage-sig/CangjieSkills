This directory contains comprehensive API reference documentation for process management functions within the Cangjie programming language. It focuses on the creation, execution, and control of subprocesses, offering detailed specifications for command execution, output capturing, and process lifecycle management. Key technical areas include environment variable configuration, working directory manipulation, I/O stream redirection, and timeout settings. These resources are specifically designed for Cangjie developers seeking to implement robust system-level operations, handle external command execution, or manage process resources efficiently in their applications.
