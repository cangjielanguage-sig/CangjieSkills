# 常用命令

This directory contains a comprehensive collection of technical reference guides for the `hilog` command-line tool, essential for system logging and debugging in HarmonyOS or OpenHarmony environments. It covers a wide range of operations including viewing and setting log levels, filtering logs by tags or processes, managing log persistence, configuring display formats, and controlling process flow. These documents provide practical command examples and syntax details for developers and system administrators who need to monitor system behavior, debug applications, or maintain log infrastructure efficiently.

## Detailed Description

### 查看和设置日志级别.md
This document serves as a technical reference guide for managing system log levels using the hilog command-line tool. It details the procedures for querying the current global log level and setting levels for global scopes, specific domain IDs, or tags. Key information includes the syntax for log severity options (Debug, Info, Warning, Error, Fatal) and the use of the --persist flag to maintain settings after a reboot. The document provides practical shell command examples to illustrate successful execution. Intended for developers and system administrators, this guide assists in controlling log verbosity during application debugging and system maintenance.

### 查看帮助命令_8more.md
This document serves as a command reference guide for the hilog logging utility, detailing various operational commands for log management and analysis. It covers viewing help information, performing non-blocking log reads, querying and modifying log buffer sizes, clearing buffers, toggling kernel log storage, and managing log statistics. Key commands include hilog -x for non-blocking reads, hilog -G for resizing buffers, and hilog -s for generating detailed statistical reports on log frequency and volume, with definitions for metrics like MAX_FREQ and MAX_TP. Intended for system developers or administrators needing to monitor, configure, and debug system logging behavior.

### 查看指定TAG日志_3more.md
This technical reference guide provides command-line instructions for filtering and viewing system logs using the hilog tool. It covers three specific operations: filtering logs by a specified tag using the -T option, retrieving the first n lines of the log buffer with -a, and fetching the last n lines using -z. Each section includes a shell command syntax and a practical output example demonstrating the log format and content. The document targets developers or system administrators debugging HarmonyOS or OpenHarmony systems who need to monitor specific system events or buffer states.

### 查看指定进程日志_3more.md
This technical reference guide explains advanced usage of the hilog command-line tool for system logging and debugging. It covers three primary functions: filtering logs by specific Process ID (PID), searching logs using regular expressions, and managing log persistence tasks to disk storage. Key information includes detailed commands for querying, starting, and stopping disk write tasks, along with configuration parameters for file size limits, file counts, and compression methods like zlib or zstd. Intended for system developers or administrators, this document provides the necessary syntax to monitor specific processes and control log file rotation effectively.

### 设置日志显示格式.md
This document serves as a technical reference guide for configuring the timestamp display format within the hilog logging system. It details the command syntax for the -v option, listing available parameters such as time, color, epoch, and nsec. The content includes practical shell examples that demonstrate the visual difference between standard time formatting and high-precision nanosecond output. Key takeaways include understanding how to switch between different time granularities for debugging purposes. This guide is intended for developers or system engineers using the hilog command-line tool to analyze system logs.

### 进程流控开关_5more.md
This document serves as a technical reference guide for the hilog command-line tool, focusing on log management and flow control mechanisms. It details commands to toggle flow control for processes and domains, as well as methods to filter logs based on severity levels, types, and specific domain IDs. Key sections include practical shell usage examples for enabling or disabling flow control and querying specific log data. The document is intended for developers or system administrators who require precise log monitoring and debugging capabilities within the operating system environment.
