This directory contains critical reference documentation designed for developers working with the HiAppEvent watcher interface, specifically focusing on the intricate data structures and attributes of system crash events. It provides a detailed breakdown of the params object, dissecting it into essential sub-attributes such as general event information, specific exception details, signal data, thread stacks, and frame-level specifics. The documentation is vital for distinguishing between different crash types, specifically CjError and NativeCrash, and provides necessary paths to external log files for deeper forensic analysis. Furthermore, it includes a crucial warning regarding log file storage management to prevent exceeding the 5MB limit, ensuring system stability. This resource is best suited for software engineers and developers who require a deep understanding of application stability, crash reporting mechanisms, and debugging workflows within the HiAppEvent framework.
