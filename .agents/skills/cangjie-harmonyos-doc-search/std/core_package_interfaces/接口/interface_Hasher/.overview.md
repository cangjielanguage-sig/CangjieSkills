# interface_Hasher

This directory contains essential API reference documentation for the `interface_Hasher` module in the Cangjie programming language. It is designed to assist developers in understanding and implementing combined hash computations. The documentation covers the structural definition of the `Hasher` interface and provides specific details on method overloads for inputting data. Key topics include state management via `reset` and `finish` methods, as well as the ability to process diverse data types such as integers, floats, strings, and booleans. This resource is suitable for software engineers working on data integrity, algorithm implementation, or any system requiring robust hashing capabilities within the Cangjie framework.

## Detailed Description

### func_writeUInt16_4more.md

This document offers a detailed API reference for a series of overloaded `write` functions specifically designed to handle unsigned integer inputs in the Cangjie language. It outlines four distinct function variants that accommodate `UInt8`, `UInt16`, `UInt32`, and `UInt64` data types. The documentation specifies that these functions are mutable, return `Unit`, and accept a single parameter representing the value to be hashed. It serves as a crucial technical resource for developers who need to feed integer data of varying sizes into a hash combination operation, ensuring precise integration into the broader hashing workflow.

### interface_Hasher_13more.md

Serving as the primary API reference for the Cangjie `Hasher` interface, this document outlines the specifications for handling combined hash computations. It describes the interface's core structure, including the `finish` method for retrieving the resulting `Int64` hash and the `reset` method for clearing the internal state. Furthermore, it details multiple overloaded `write` functions capable of sequentially processing a wide array of primitive types, including integers, floating-point numbers, strings, and booleans. This reference is intended for developers who require a deep understanding of the interface's contract to implement or utilize hashing algorithms effectively within the Cangjie environment.
