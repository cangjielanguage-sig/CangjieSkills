This directory provides comprehensive API reference documentation and code examples for the Swiper component within the ArkUI framework using the Cangjie language. It covers the implementation of sliding carousel view containers, including initialization, event handling, attribute configuration, and navigation control. Key topics include lazy loading constraints, indicator styling, playback control, and animation settings. This resource is suitable for UI developers and system architects looking to build interactive, visually appealing carousel interfaces with precise control over navigation and user interaction in their applications.
