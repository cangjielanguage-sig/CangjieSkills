# 基础类型定义

This directory contains fundamental type definitions and API references for the ArkUI framework using the Cangjie language, specifically focusing on Swiper components and their associated indicators. It covers essential classes for styling navigation controls (arrows, dots, digits), managing component behavior (controllers, display modes), and handling custom animations and transitions. Key topics include visual property configuration, event handling, and layout logic. This documentation is suitable for UI developers and system engineers working on HarmonyOS applications who need to implement or customize Swiper functionality, navigation indicators, and page transition effects in their interfaces.

## Detailed Description

### class_ArrowStyle.md class_ArrowStyle.md
This document serves as an API reference for the Cangjie `ArrowStyle` class, which configures visual properties for left and right navigation arrows within the ArkUI framework. It details the class definition, public properties including arrow and background dimensions, colors, and visibility settings, alongside the constructor initialization parameters. Key information includes the specific logic where arrow size defaults to three-quarters of the background size when the background is enabled. Intended for UI developers, this reference facilitates the customization of navigation controls, such as positioning arrows relative to sidebars or indicators.

### class_DigitIndicator.md class_DigitIndicator.md

Key information includes default styling values, such as a selected font size of 14 and specific hex color codes, alongside constraints like a maximum font scale of 2. Intended for UI developers, this guide provides the necessary parameters to customize the appearance of digital pagination dots in application interfaces.

### class_FontOptions.md class_FontOptions.md
This API reference document details the `FontOptions` class used to configure the font style for digital navigation dots within the Swiper component in the Cangjie language. The documentation covers the class definition, properties for font size and weight, and the constructor initialization method. Key takeaways include that the size property is of type Length but does not support percentage values, while weight uses the FontWeight enum. The constructor provides default values of 14.vp for size and Normal for weight. This guide targets developers building ArkUI interfaces who need to customize the appearance of Swiper indicators.

### class_SwiperAnimationEvent_2more.md class_SwiperAnimationEvent_2more.md
This API reference document defines two Cangjie classes, `SwiperAnimationEvent` and `SwiperAutoFill`, used for configuring and handling Swiper component behaviors in the ArkUI framework. The documentation details the properties and constructors for `SwiperAnimationEvent`, which tracks animation offsets and velocity, and `SwiperAutoFill`, which manages adaptive sizing parameters. Key takeaways include the specific data types for properties like `currentOffset`, `targetOffset`, `velocity`, and `minSize`, all available from system version 19. This is intended for UI developers working with the Cangjie language to implement custom Swiper animations and responsive layouts.

### class_SwiperContentAnimatedTransition.md class_SwiperContentAnimatedTransition.md
This document serves as API reference documentation for the Cangjie class `SwiperContentAnimatedTransition`, designed to configure custom transition animations for Swiper components. The content details the class constructor and two primary public properties: `timeout` and `transition`. Key information includes that the `timeout` property sets a maximum duration in milliseconds for the custom animation; if the developer does not call `finishTransition` within this period, the system automatically terminates the animation. The `transition` property accepts a lambda function containing the specific animation logic. This guide targets ArkUI developers using the Cangjie language who require granular control over page switching effects and rendering tree management within Swiper containers.

### class_SwiperController.md class_SwiperController.md
This document provides API reference documentation for the `SwiperController` class in the Cangjie language, used to control Swiper container components within the ArkUI framework. It covers the class initialization and key methods for navigation and animation management, including `changeIndex` for jumping to specific pages, `finishAnimation` for stopping playback with optional callbacks, and `showNext` or `showPrevious` for sequential page turning. Intended for developers building UIs with ArkUI, this guide requires understanding of component binding and system capabilities.

### enum_SwiperDisplayMode.md enum_SwiperDisplayMode.md
This document provides API reference documentation for the Cangjie `SwiperDisplayMode` enum, which defines the sizing behavior of the Swiper component along its main axis. The content details two enumeration values: `STRETCH`, where the page width matches the Swiper's width, and `AUTO_LINEAR`, a deprecated mode that bases width on the leftmost child component. Key takeaways include the deprecation of `AUTO_LINEAR` in favor of the `Scroller.scrollto` method and the specific version requirements (starting from version 19). This reference guide targets developers building UIs with the ArkUI framework who need precise control over Swiper layout dimensions.
