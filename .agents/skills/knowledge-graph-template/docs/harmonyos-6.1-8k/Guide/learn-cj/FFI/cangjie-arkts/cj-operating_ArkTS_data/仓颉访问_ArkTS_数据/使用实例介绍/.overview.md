# 使用实例介绍

本目录主要介绍仓颉语言与 ArkTS 之间的互操作实例，涵盖了对象操作、函数调用及并发通信等核心场景。内容详细讲解了如何在仓颉中操作 ArkTS 的普通对象与 Sendable 对象，以及如何调用 ArkTS 函数，并深入探讨了多线程环境下的异步锁机制。核心关键词包括互操作、Sendable 对象、函数回调、异步锁、并发通信。本文档适合需要进行 HarmonyOS/OpenHarmony 跨语言开发的开发者参考，帮助其实现高效、安全的混合编程。

## 详细描述

### 操作_ArkTS_的_sendable_对象_19cc733c.md 操作_ArkTS_的_sendable_对象_19cc733c.md
本文档旨在指导开发者如何在仓颉语言中操作 ArkTS 的 sendable 对象，以实现并发通信中的引用传递。主要内容包括在 ArkTS 中定义 @Sendable 类，在仓颉侧编写互操作函数读取对象属性，配置 Index.d.ts 接口声明，以及在 ArkTS 侧构建对象并调用仓颉接口。核心要点是仓颉侧操作 sendable 对象与普通对象一致。文档通过实例演示了如何将 ArkTS 的 sendable 对象传递给仓颉进行数值计算，并返回结果。适用于需要实现 ArkTS 与仓颉语言互操作，特别是涉及大量对象并发通信场景的开发者。

### 操作_ArkTS_的普通对象.md 操作_ArkTS_的普通对象.md
这份文档旨在指导开发者在仓颉语言中操作ArkTS普通对象，实现跨语言互操作。文档通过代码示例展示了互操作函数的实现、TypeScript声明及调用流程，重点讲解了如何读取、赋值及创建对象属性。关键信息包括使用`JSObject[key]`操作属性、属性的可配置性、操作失败的特殊场景（如sealed对象），以及如何枚举属性、创建新对象和访问全局对象。本文适合熟悉仓颉和ArkTS的开发者参考。

### 调用_ArkTS_函数.md 调用_ArkTS_函数.md
本文档旨在指导开发者在仓颉代码中调用ArkTS函数。文档主要分为普通函数调用和带this指针的函数调用两部分，详细展示了ArkTS回调函数的传递与执行流程。关键信息包括如何将ArkTS函数转换为仓颉可调用的对象，以及使用`thisArg`参数显式指定this上下文以正确调用对象方法。该文档属于互操作教程，适用于熟悉ArkTS和仓颉基础语法的HarmonyOS开发者，帮助其实现跨语言函数回调与交互。

### ArkTS_异步锁/
本目录主要介绍在ArkTS中如何利用异步锁解决多线程并发下的数据竞争问题。内容涵盖了结合Sendable对象在主线程与Worker线程间安全传递数据、使用AsyncLock保护共享资源，以及ArkTS与仓颉（Cangjie）动态库的互操作实现。核心知识点包括postMessageWithSharedSendable、lockAsync方法及Promise处理。适合需要进行高性能多线程并发开发且关注数据安全的HarmonyOS/OpenHarmony应用开发者参考。
