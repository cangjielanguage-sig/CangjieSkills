# process_package_enums

This directory serves as a comprehensive documentation hub for the `process_package_enums` module within the Cangjie programming language. It focuses specifically on the `ProcessRedirect` enumeration, a fundamental component for defining how standard streams—such as standard input, standard output, and standard error—are redirected during the creation of child processes. The content covers a wide range of redirection strategies, including inheriting streams from the parent process, utilizing pipes for inter-process communication, redirecting I/O to specific files, or discarding streams entirely to suppress output. This documentation is highly suitable for systems programmers and application developers who are implementing complex process management logic and require precise, programmatic control over data flow and input/output handling in their software projects.

## Detailed Description

### process_package_enums.md process_package_enums.md

This API reference document provides a detailed technical breakdown of the `ProcessRedirect` enum in the Cangjie language. It is a vital resource for developers who need to define how standard streams are redirected when spawning child processes. The document comprehensively covers four distinct enumeration variants:

*   **Inherit**: Used to pass the parent's streams directly to the child process.
*   **Pipe**: Establishes a connection for data exchange between the parent and child.
*   **FromFile(File)**: Redirects the stream to a specific file on the system.
*   **Discard**: Completely ignores or discards the stream output.

In addition to defining these behaviors, the document clarifies the read/write permissions associated with stream properties in each mode. This guide is specifically tailored for developers implementing process management systems who require granular control over input and output flow to ensure their applications function correctly and securely. By understanding these enums, developers can effectively manage process lifecycles and communication channels.
