# PromptAction

本目录包含ArkUI框架中PromptAction模块的API参考文档，主要面向使用仓颉语言进行应用开发的开发者。内容涵盖了即时反馈组件（如Toast消息）、对话框（标准、自定义及基础配置）、操作菜单以及相关的UI交互选项类。文档详细介绍了如何通过UIContext获取PromptAction实例，并提供了各类弹窗、菜单项按钮、边框颜色及显示模式的配置接口。这些资源适用于需要实现复杂用户界面交互、自定义弹窗样式及处理用户输入反馈的开发场景。
