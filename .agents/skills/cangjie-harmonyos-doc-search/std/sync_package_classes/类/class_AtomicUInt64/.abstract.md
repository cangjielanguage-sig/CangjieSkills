This directory contains API reference documentation for the `AtomicUInt64` class in the Cangjie programming language. It covers atomic operations for 64-bit unsigned integers, including arithmetic, bitwise, and memory access functions. Key topics include thread-safe synchronization, compare-and-swap (CAS), fetch-and-modify operations, and memory ordering deprecations. The documentation is intended for systems programmers and developers implementing low-level concurrency primitives who require efficient, thread-safe manipulation of shared data.
