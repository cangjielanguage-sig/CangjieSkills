# 加速Web页面的访问

This directory focuses on optimizing Web page performance within the ArkWeb framework using the Cangjie language. It covers essential techniques such as DNS pre-resolution, socket pre-connection, resource pre-loading, and prefetching POST requests to significantly reduce latency. The guides provide practical Cangjie code examples for implementing these optimizations during specific Web component lifecycle events like `onAppear` and `onPageEnd`. It is suitable for application developers looking to enhance the responsiveness and loading speed of their Web-based interfaces through advanced network management and caching strategies. By leveraging these methods, developers can ensure a smoother user experience with minimized wait times and efficient resource utilization.

## Detailed Description

### 加速Web页面的访问_3more.md 加速Web页面的访问_3more.md
This technical guide instructs developers on optimizing Web page performance using pre-connection and pre-loading capabilities within the ArkWeb framework. It details two primary methods: using `prepareForPageLoad` for DNS pre-resolution and socket pre-connection, and `prefetchPage` for downloading page resources in advance without executing JavaScript. The document provides Cangjie code examples demonstrating how to implement these methods during specific Web component lifecycle events, such as `onAppear` and `onPageEnd`. It is intended for developers seeking to reduce latency and improve the responsiveness of Web-based applications by managing network connections and resource fetching more efficiently.

### 预获取post请求.md 预获取post请求.md
This technical guide explains how to optimize web performance by prefetching POST requests in ArkWeb components using the Cangjie language. It covers the usage of `prefetchResource()` for prediction and `clearPrefetchedResource()` for cache management, providing two distinct code examples. The document details parameters like `RequestInfo`, `cacheKey`, and `cacheValidTime`, demonstrating how to prefetch during `onAppear` for immediate needs or `onPageEnd` for future navigation. It targets application developers seeking to reduce loading latency in web-based interfaces by anticipating user actions and caching necessary data ahead of time.
