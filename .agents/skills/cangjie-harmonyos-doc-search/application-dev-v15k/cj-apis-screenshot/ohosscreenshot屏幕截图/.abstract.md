This directory contains comprehensive documentation for the `ohos.screenshot` module within the HarmonyOS Cangjie language ecosystem. It focuses on screen capture functionalities, detailing how to retrieve full-screen images on tablets and selective capture data on 2-in-1 devices. The content includes API references for core classes like `PickInfo` and `Rect`, configuration options, required system permissions, and error handling. It is designed for developers implementing window management features or integrating screen capture capabilities into applications using ArkUI and ImageKit.
