It is suitable for software developers, compiler engineers, and students interested in language design, syntax tree manipulation, and building language extensions.

## Detailed Description

### 接口.md 接口.md
This document serves as a reference index defining core interfaces within an AST package, specifically focusing on type conversion and serialization capabilities. The content is organized as a table listing two primary interfaces: ToBytes and ToTokens, both linking to detailed API documentation. The ToBytes interface provides serialization functionality for types, while ToTokens enables the conversion of instances to Tokens, which is explicitly noted as a mandatory requirement for supporting quote interpolation operations. This API documentation is intended for developers working with the AST package who need to implement or understand data serialization and tokenization mechanisms, particularly for metaprogramming features like quote interpolation.

### 枚举_3more.md 枚举_3more.md
This document serves as a reference guide for core data types and error handling within the AST package API. It is organized into three main sections: Enums, Structs, and Exception Classes. The content details enumerations for diagnostic levels, import types, and lexical tokens, alongside structures for position tracking and token definitions. Additionally, it defines specific exception classes for handling errors in general AST operations, macro contexts, and parsing processes. This resource is intended for developers working with the compiler's internal structures who require a comprehensive understanding of the library's type system and error handling mechanisms.
