# cj-crypto-generate-message-digest-overview

This directory serves as a vital technical reference for developers working with the CJ crypto API, focusing specifically on the generation and specification of message digests. It provides a thorough introduction to hash functions that convert variable-length inputs into fixed-length, deterministic outputs, a cornerstone of modern cryptographic security. The content covers essential algorithm characteristics, including determinism and fixed output size, and offers a detailed comparison of supported methods. Key algorithms documented include SHA1, SHA224, SHA256, SHA384, SHA512, MD5, and SM3, with specific attention paid to their byte lengths and compatibility with API version 12 and above. This guide is specifically curated for software engineers and system architects who need to implement secure data processing, offering the necessary technical parameters to choose the correct hashing algorithms for their specific security requirements.
