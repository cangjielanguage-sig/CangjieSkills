This directory provides a comprehensive technical reference for implementing encryption and decryption operations using the HarmonyOS Universal Keystore Service (HUKS). It covers supported algorithm specifications tailored for both standard and lightweight devices, detailing specific combinations of algorithms, block modes, and padding modes such as AES/GCM, RSA/OAEP, and SM4. The documentation highlights mandatory parameters like IV, Nonce, and TAG required from API level 15. This resource is suitable for developers building secure HarmonyOS applications who need to understand cryptographic algorithm compatibility and precise parameter requirements for secure data handling. It serves as a crucial guide for ensuring data security and compliance within the HarmonyOS ecosystem, helping developers navigate the complexities of hardware-backed key management and cryptographic operations across different device types.
