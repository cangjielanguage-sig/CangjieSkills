# 交叉轴对齐方式

This directory focuses on the mechanisms of cross-axis alignment within layout systems, specifically utilizing the ArkUI framework and the Cangjie programming language. It covers the fundamental rules governing how parent containers and child elements interact regarding positioning, including the priority hierarchy where child settings override parent configurations. Key topics include `alignItems`, `alignSelf`, and `alignContent` for multi-line layouts. This documentation is designed for HarmonyOS developers and UI designers seeking to master precise control over component positioning, resolve alignment conflicts, and implement complex layout behaviors in their applications.

## Detailed Description

### 交叉轴对齐方式.md 交叉轴对齐方式.md
This document defines the rules governing cross-axis alignment within a layout system, specifically addressing the interaction between container and child element settings. It covers the configuration options available for both parent containers and individual child elements regarding cross-axis positioning. The primary takeaway is the priority hierarchy: alignment settings defined on child elements take precedence over those set on the parent container. This reference material is intended for developers or UI designers working with layout engines who need to understand how to control element positioning and resolve alignment conflicts. Keywords: cross-axis, alignment, priority, layout, container, child element.

### 子元素设置交叉轴对齐.md 子元素设置交叉轴对齐.md
This technical guide explains how to override the cross-axis alignment of individual child elements within a Flex layout container using the alignSelf attribute in the ArkUI framework. The document covers the definition of the alignSelf property, its relationship to the parent container's alignItems configuration, and provides a practical Cangjie code example demonstrating various alignment scenarios like Start, Baseline, and default behavior. The primary takeaway is that setting alignSelf on a child element takes precedence over the parent Flex container's alignItems setting, allowing for granular control over layout positioning. This tutorial is intended for developers using the Cangjie language and ArkUI framework who need to customize UI component layouts beyond standard container settings.

Keywords: ArkUI, Flex layout, alignSelf, alignItems, cross-axis alignment, Cangjie, UI development.

### 容器组件设置交叉轴对齐.md 容器组件设置交叉轴对齐.md
This technical guide explains how to configure cross-axis alignment for child elements within a Flex container using the Cangjie programming language. The document details six specific alignment options available through the alignItems parameter: Auto, Start, Center, End, Stretch, and Baseline. Each alignment mode is demonstrated with runnable Cangjie code snippets and corresponding visual figures, illustrating how text elements are positioned or stretched relative to the container's cross-axis. It targets HarmonyOS developers seeking to master UI layout and component styling, providing practical examples for implementing precise alignment behaviors in application interfaces.

### 内容对齐/
This directory provides comprehensive technical documentation on configuring content alignment within Flex layouts using the Cangjie programming language and the ArkUI framework. It specifically addresses the `alignContent` parameter, which is essential for controlling the distribution of child element rows along the cross-axis in multi-line (wrapped) containers. The documentation covers a wide range of alignment strategies, including FlexAlign.Start, Center, End, SpaceBetween, SpaceAround, and SpaceEvenly. Through detailed code snippets and visual output references, developers can learn how to manipulate layout spacing precisely. This resource is highly suitable for software developers and UI designers working on HarmonyOS applications who need to master complex layout behaviors and ensure consistent visual presentation across different screen sizes.
