This directory focuses on `cj-appstorage`, a global UI state storage mechanism designed for the Cangjie and ArkUI frameworks. It provides comprehensive resources for managing application-wide state, ensuring data synchronization across components and abilities. Key topics include the singleton lifecycle, unique key access, two-way data binding, and the usage of decorators like `@StorageProp` and `@StorageLink`. It also covers integration with `PersistentStorage` for data persistence. This documentation is suitable for developers working in pure Cangjie or ArkTS environments who need to implement robust state management, optimize performance, and ensure correct data flow in their applications. By utilizing these resources, developers can effectively handle cross-ability data sharing and build responsive, high-performance user interfaces.
