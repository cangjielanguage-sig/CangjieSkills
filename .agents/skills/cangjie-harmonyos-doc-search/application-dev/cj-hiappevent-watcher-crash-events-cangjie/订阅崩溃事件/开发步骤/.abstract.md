This directory serves as a comprehensive technical resource for developers focusing on application stability and performance monitoring within the Cangjie ecosystem. It provides a detailed, step-by-step tutorial on implementing crash event subscriptions using the PerformanceAnalysisKit, covering essential tasks such as importing dependencies, configuring AppEventFilter and Watcher components, and manually triggering crashes for testing. Furthermore, it offers a deep dive into the log output format generated by the HiAppEvent framework, illustrating exactly how crash data is structured for effective analysis. The content addresses specific technical behaviors, such as stack unwinding differences between CjError and NativeCrash, and the precise timing of crash reports. It is specifically designed for Cangjie developers and system engineers utilizing DevEco Studio who need to debug application failures, interpret complex crash logs, and optimize error handling mechanisms in HarmonyOS or OpenHarmony environments.
