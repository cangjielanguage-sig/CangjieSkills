# 宏

This directory contains comprehensive reference documentation for testing macros in the Cangjie programming language. It covers essential unit testing components, including lifecycle management, assertion mechanisms, performance benchmarking, and configuration options. Developers can find guides on defining test cases, handling exceptions, implementing custom assertions, and managing parallel execution. The documentation also details advanced features like power assertions, data generation strategies, and test templates. Suitable for Cangjie developers and QA engineers, these resources provide the syntax and functional definitions needed to structure robust test suites, validate code behavior, and analyze execution efficiency effectively.

## Detailed Description

### AfterAll_宏_6more.md AfterAll_宏_6more.md
This reference guide details testing framework macros for managing test lifecycles and performing assertions. It covers lifecycle hooks (@BeforeAll, @AfterAll, @BeforeEach, @AfterEach) and verification macros (@Assert, @AssertThrows). Key points include execution order (suite vs. test level) and assertion capabilities like equality checks, boolean validation, and delta comparisons. It provides syntax and definitions for developers to structure test execution and validate code behavior.

### Bench_宏.md Bench_宏.md
This guide covers the `@Bench` macro for performance benchmarking and statistical analysis in Cangjie. It details metrics like median, mean, and confidence intervals, plus integration with parameterized DSL. The macro executes functions in batches to generate statistical distributions and supports parameterized inputs for distinct performance cases. It includes code examples and output table formats for developers analyzing execution efficiency.

### Configure_宏.md Configure_宏.md
This guide explains the `@Configure` macro for setting test parameters in Cangjie. It covers syntax, general parameters (randomSeed), and benchmarking options (batchSize, warmup). It details configuration inheritance from classes to functions and precedence rules where function-level settings override class-level ones. It is intended for developers customizing test execution and performance analysis.

### CustomAssertion_宏.md CustomAssertion_宏.md
This documentation explains the `@CustomAssertion` macro for defining custom assertion functions. It outlines requirements like top-level functions and accepting `AssertionCtx` as the first parameter. Key topics include return values, nested assertions for error reporting, and generic type parameters. It notes that custom assertions generate tree-structured output for better readability during failures, helping developers extend standard capabilities.

### Expect_宏_6more.md Expect_宏_6more.md
This guide details macros for assertion, performance, and parallel execution in Cangjie. It covers `@Expect` (comparisons), `@ExpectThrows` (exceptions), `@Fail`/`@FailExpect` (failures), `@Measure` (benchmarking), and `@Parallel` (concurrency). Key points include execution stopping behavior, delta for approximate equality, and parallel testing requirements like independent cases. It targets developers writing unit tests or benchmarks.

### PowerAssert_宏_4more.md PowerAssert_宏_4more.md
This guide covers advanced testing macros: `@PowerAssert` (detailed evaluation), `@Skip` (conditional exclusion), `@Strategy` (data generation), and `@Tag` (metadata/filtering). It explains `@PowerAssert`'s sub-expression display, `@Tag` propagation rules, and `@Strategy`'s return type requirements. It helps developers and QA engineers enhance readability, manage execution, and organize test suites.

### TestCase_宏.md TestCase_宏.md
This API reference covers the `@TestCase` macro for designating unit test cases. It explains requirements like the `Unit` return type and details parameterized testing via DSL. Supported sources include arrays, ranges, random generation, and file inputs (JSON/CSV), plus custom strategies via `DataStrategy`. It clarifies execution behavior regarding lifecycle hooks and random types for developers creating data-driven tests.

### TestTemplate_宏_4more.md TestTemplate_宏_4more.md
This documentation details macros for enhancing test functionality: `@TestTemplate`, `@Timeout`, `@Types`, and `@UnittestOption`. It covers templates, execution timeouts, generic parameterization, and custom configuration options. Key points include `@Types` usage requirements, Duration types for timeouts, and strict type checking with `@UnittestOption`. It targets developers implementing advanced features like parameterized tests and custom configurations.

### Test_宏_2more.md Test_宏_2more.md
This guide outlines unit testing macros, primarily `@Test`, which transforms functions or classes into test cases by introducing the `unittest.TestCases` base class. Requirements include a no-argument constructor and no inheritance. It explains exposed `ctx` and `name` fields for context management and introduces `@TestBuilder` for dynamic test suites. It targets developers structuring and executing unit tests.
