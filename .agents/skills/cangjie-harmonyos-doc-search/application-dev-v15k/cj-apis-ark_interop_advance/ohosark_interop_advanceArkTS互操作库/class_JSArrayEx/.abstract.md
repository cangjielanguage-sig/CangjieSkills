This directory provides comprehensive API reference documentation for the Cangjie class `JSArrayEx` and its associated utility functions. It focuses on facilitating declarative interoperability with ArkTS Array types, enabling developers to seamlessly manage array data structures within ArkUI and Napi environments. Key topics include generic type support, deep copying mechanisms, element manipulation via subscripts, and data conversion between Cangjie native formats and JavaScript/ArkTS values. The documentation details specific functionalities such as cloning, concatenation, and element access, alongside internal framework tools like `fromJSValue`. This resource is specifically suitable for Cangjie developers working on cross-platform applications who require efficient array operations and type conversions using system capabilities starting from version 15. By utilizing these references, developers can ensure robust data handling and seamless integration between Cangjie logic and ArkTS runtime environments.
