# 基础概念与规范

This directory provides a comprehensive guide to focus management in UI applications, specifically designed for non-pointing input scenarios such as remote controls and keyboards. It covers essential definitions like Focus Chains, Root Containers, and Hierarchical Pages, as well as the algorithms driving focus movement. Additionally, it details the specifications for active and passive navigation behaviors, including keyboard traversal and programmatic requests. This resource is ideal for UI developers and system architects seeking to implement robust navigation logic and custom focus behaviors in component-based frameworks.

## Detailed Description

### 基础概念.md 基础概念.md
This document outlines the fundamental concepts of focus management for UI applications, specifically targeting non-pointing input scenarios like remote controls or keyboards. It details the definitions of Focus, Focus Chains, and Focus Movement, alongside the visual behavior of Focus States and activation rules. Key sections explain Hierarchical Pages—containers like Dialogs and Popups that isolate focus—and Root Containers, which manage the initial focus distribution within a page. The text clarifies how focus is trapped within specific components and how it propagates to child elements. This reference guide is intended for developers building interactive interfaces for diverse devices, providing the necessary logic to implement robust navigation systems and custom focus behaviors.

### 走焦算法.md 走焦算法.md
This technical reference document defines the algorithms governing focus movement between UI components using keyboard inputs like TAB and arrow keys. It details three specific strategies: Linear (default, tree-order based), Projection (geometry-based for wrapped layouts), and Custom (component-defined). Key takeaways include that Linear navigation relies on node mounting order regardless of visual layout, while Projection determines the next target based on projection overlap and center point distance. The document outlines specific rules for handling boundaries and directional requests for each algorithm. This guide targets UI developers and system architects implementing focus management in component-based frameworks.

### 走焦规范.md 走焦规范.md
This document defines the specifications and behaviors for focus navigation within a UI framework, categorizing mechanisms into active and passive types. It covers Active Focus Navigation, detailing keyboard inputs (TAB, arrow keys), programmatic requests (requestFocus), and touch interactions (focusOnTouch). It also explains Passive Focus Navigation, which handles automatic focus transfers during component deletion, property changes, and page switching. Key takeaways include the Z-shape traversal logic for TAB keys, distance-priority algorithms for directional navigation, and the hierarchy of focus recovery when components are removed. This technical reference guide is intended for UI developers and system engineers implementing focus management, requiring knowledge of component hierarchies and event handling.
