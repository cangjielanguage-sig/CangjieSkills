# 显示图片Image

This directory provides a comprehensive collection of tutorials focused on the Image component within the Cangjie programming language for HarmonyOS development. It covers the complete lifecycle of image handling, from basic rendering of local, network, and vector graphics (SVG) resources to managing loading events and extracting metadata. Furthermore, it addresses advanced customization techniques, including scaling behavior, quality interpolation, and color filtering. These resources are essential for application developers using the ArkUI framework who aim to create visually polished and high-performance user interfaces with robust image display capabilities.

## Detailed Description

### 事件调用.md 事件调用.md
This tutorial demonstrates how to handle image loading events in the Cangjie programming language for HarmonyOS development. The document focuses on utilizing the `onComplete` and `onError` callbacks within the Image component. Key takeaways include extracting specific image metadata such as width, height, and component dimensions upon successful loading, as well as implementing error handling for failed loads. The provided code example illustrates binding these events to update state variables and display results dynamically. This guide is intended for application developers with prerequisite knowledge of Cangjie syntax and the HarmonyOS UIKit framework.

### 显示图片Image_3more.md 显示图片Image_3more.md
This guide instructs developers on using the Image component to display various image formats within applications. It details the component interface, loading resources (local, network, Resource, media library), and displaying vector graphics (SVG). Key points include the `Image(src)` API, the requirement for internet permissions for network images, the use of `@r` for app resources, and the ability to modify SVG colors via `fillColor`. It also explains path handling for SVGs referencing bitmaps. Targeted at application developers using the Cangjie language and ArkUI framework, this document serves as a practical tutorial for implementing image rendering.

### 添加属性/
This directory contains technical tutorials focused on enhancing and configuring the Image component within the Cangjie framework and ArkUI. It covers essential image manipulation techniques including scaling behavior control via `objectFit`, quality enhancement through interpolation, and advanced rendering modes like color filters and decoding dimensions. These guides provide practical code examples to help developers optimize visual performance and layout. Suitable for HarmonyOS developers using the Cangjie language who need to customize image display properties, prevent blurriness, and implement specific visual effects in their user interfaces.
