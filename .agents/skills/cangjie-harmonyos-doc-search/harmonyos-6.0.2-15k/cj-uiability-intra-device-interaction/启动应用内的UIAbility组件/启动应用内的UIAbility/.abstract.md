This directory provides comprehensive technical guidance for managing UIAbility lifecycles within the same HarmonyOS application using the Cangjie language. It covers essential operations such as initiating specific UIAbility components via the `startAbility()` method, configuring Want objects with parameters like bundleName and abilityName, and passing custom data between components. Additionally, it details how to terminate UIAbility instances and manage application processes using methods like `terminateSelf()` and `killAllProcesses()`. This resource is suitable for HarmonyOS developers working with the Stage model who need to implement multi-Ability navigation, handle parameter passing via JSON, and control application visibility and lifecycle events effectively.
