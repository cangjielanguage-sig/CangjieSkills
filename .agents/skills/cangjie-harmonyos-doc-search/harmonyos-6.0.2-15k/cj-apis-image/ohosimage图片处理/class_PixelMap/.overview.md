# class_PixelMap

This directory contains API reference documentation for the `PixelMap` class within the Cangjie ImageKit framework, focusing on reading, writing, and managing image pixel data. It covers image transformations (scaling, rotating, flipping), pixel format conversion, color space management, and memory operations. Key topics include resource management, metadata retrieval, and serialization for IPC. Intended for software developers using Cangjie (version 12+), this documentation supports the implementation of advanced multimedia image processing features, including HDR to SDR conversion and cross-thread Worker usage.
