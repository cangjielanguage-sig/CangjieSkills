## 录像

完成[会话创建](#创建会话)后，开发者可根据实际需求，配置输出流。录像的旋转角度与重力方向（即设备旋转角度）相关。

1. 调用[VideoOutput](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-videooutput)类中的[getVideoRotation](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-getvideorotationint32)可以获取到录像的旋转角度。

    该接口需要在session调用[commitConfig](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-commitconfig)完成配流后调用。

    deviceDegree：设备旋转角度。获取方式请见[计算设备旋转角度](#计算设备旋转角度)。

    ```cangjie
    func getVideoRotation(videoOutput: VideoOutput, deviceDegree: Int32): ImageRotation {
        let videoRotation: ImageRotation = videoOutput.getVideoRotation(deviceDegree)
        AppLog.info("Video rotation is: ${videoRotation}")
        return videoRotation
    }
    ```

2. 将录像的旋转角度写入[AVMetadata](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#class-avmetadata).videoOrientation。
3. 其余参数的配置及启动录像，请参见[录像开发指导](./cj-camera-recording.md)。
