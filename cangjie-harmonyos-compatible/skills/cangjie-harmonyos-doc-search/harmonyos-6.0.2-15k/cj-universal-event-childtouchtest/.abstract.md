This directory provides a specialized technical overview for developers utilizing the Cangjie language within the ArkUI framework, specifically focusing on the advanced capabilities of universal event handling. It centers on the `onChildTouchTest` mechanism, a powerful tool that enables developers to override standard touch behaviors and implement custom logic for how events are distributed across the UI hierarchy. The content covers critical aspects such as managing event conflicts, handling geometric data for precise touch point detection, and defining touch result strategies. Furthermore, it explains event propagation control and coordinate system mappings, which are essential for creating responsive and conflict-free interfaces. This resource is primarily intended for advanced Cangjie and ArkUI developers who require granular control over event flows to build sophisticated, high-performance user interfaces with complex interaction logic.
