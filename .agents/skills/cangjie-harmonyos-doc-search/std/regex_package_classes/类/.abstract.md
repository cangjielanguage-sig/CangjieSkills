This directory provides comprehensive API reference documentation for classes associated with regular expression processing within the Cangjie programming language. It encompasses both active and deprecated components, offering insights into the `Regex` class for modern pattern matching, as well as legacy classes like `Matcher` and `RegexOption`. Key functionalities covered include compiling expressions, performing matches, replacing text, splitting strings, and managing capture groups. Additionally, it addresses specific behaviors such as lazy evaluation and configuration modes. This documentation is essential for Cangjie developers seeking to implement robust text processing, maintain legacy systems, or transition from deprecated regex implementations to current standards.
