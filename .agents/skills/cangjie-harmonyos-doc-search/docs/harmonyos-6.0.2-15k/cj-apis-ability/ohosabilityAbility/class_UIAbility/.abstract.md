This directory contains comprehensive API reference documentation for the `UIAbility` class within the Cangjie AbilityKit framework. It covers the definition of UI application components, extending `BaseAbility`, and details essential properties like `callee`, `context`, and launch parameters. The documentation extensively explores lifecycle management, including initialization, state transitions, window management, and inter-ability communication using `Caller` and `Callee`. It is designed for HarmonyOS application developers using the Cangjie programming language who need to manage UI component lifecycles, handle system interactions, and implement multi-device continuity features effectively.
