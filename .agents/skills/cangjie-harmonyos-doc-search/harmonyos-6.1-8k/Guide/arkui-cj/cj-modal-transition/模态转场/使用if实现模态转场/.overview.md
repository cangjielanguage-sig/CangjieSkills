# 使用if实现模态转场

本目录介绍了如何在ArkUI中使用条件渲染（if范式）来实现模态转场效果。它涵盖了通过状态管理动态控制组件的显示与隐藏，并结合animateTo和TransitionEffect实现平滑的动画过渡。内容包含Cangjie和ArkTS两种语言的代码示例，展示了从基础逻辑到UI构建及动画配置的完整流程。适合需要实现自定义模态弹窗和转场动画的HarmonyOS开发者。
