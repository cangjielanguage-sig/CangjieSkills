This directory functions as a comprehensive technical resource dedicated to the calculation and implementation of Message Authentication Codes (MAC) and HMAC within the Cangjie development environment. It addresses the fundamental requirements for verifying message integrity and authenticity in secure communications systems, emphasizing the use of shared keys to effectively mitigate data tampering risks. The content encompasses the theoretical underpinnings of these cryptographic mechanisms and provides an extensive list of supported hash algorithms, including SHA1, SHA256, SHA512, SM3, and MD5, ensuring full compatibility with API version 12 and higher. Furthermore, it delivers practical implementation strategies utilizing the CryptoArchitectureKit, guiding developers through the complete workflow from symmetric key generation to data processing. This documentation is specifically curated for software developers and security architects aiming to embed standardized cryptographic verification and resilient message authentication features into their software applications.
