This directory provides comprehensive API documentation for the `TupleWrapper3` struct, a key component of the Cangjie programming language's "more" package. It focuses on a generic wrapper designed to encapsulate and manipulate three-element tuples efficiently within various application contexts. The documentation covers core functionality, including struct definitions, constructors, and standard interface implementations such as `ToString`, `Equatable`, and `IndexAccess`. Furthermore, it details specialized extensions for property-based testing, specifically the `Arbitrary` and `Shrink` interfaces, which are essential for generating random test cases and reducing them to minimal failing examples. This resource is highly suitable for Cangjie developers working with complex tuple data structures and those implementing advanced testing frameworks requiring robust random data generation and shrinking capabilities.
