# enum_DayOfWeek

This directory contains comprehensive API reference documentation for the `DayOfWeek` enum within the Cangjie language's time package. It covers the fundamental definition of the seven days of the week, ranging from Sunday to Saturday, and includes detailed methods for conversion between integers and strings. Furthermore, it provides essential information on operator overloading functions, enabling arithmetic and comparison operations such as addition, subtraction, and equality checks. This documentation is specifically suitable for Cangjie developers who need to implement robust date logic, calculate future or past days, or compare day values effectively in their software applications.

### enum_DayOfWeek_12more.md enum_DayOfWeek_12more.md
This document serves as API reference documentation for the DayOfWeek enum in the Cangjie language, detailing the representation of days of the week. It covers the enum definition listing seven days (Sunday to Saturday), static factory methods for integer conversion, and instance methods for string representation and integer retrieval. Key features include the `of` function for creating instances from integers (0-6), `toInteger` for reverse conversion, and `toString` for string output. It also notes the deprecation of the `value` method in favor of `toInteger`. Targeted at Cangjie developers working with time or date logic, this reference requires basic knowledge of the language's type system and exception handling.

Key takeaways include that arithmetic operators accept Int64 values to calculate future or past days, returning a new DayOfWeek instance, while comparison operators return Boolean values indicating if two instances represent the same day. The target audience is software developers utilizing the Cangjie language for time-related calculations who need to manipulate or compare day-of-week values.
