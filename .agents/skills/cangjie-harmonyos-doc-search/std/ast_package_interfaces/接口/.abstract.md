This directory serves as a comprehensive repository for API reference documentation regarding core interfaces within the Cangjie programming language. It primarily focuses on standard protocols designed for type conversion and data transformation. The content covers essential interfaces such as `ToBytes`, which handles object serialization into byte sequences, and `ToTokens`, which facilitates the conversion of data types into token objects for metaprogramming purposes. These interfaces are fundamental for enabling interoperability between custom data types and system-level operations like storage, transmission, and compile-time code generation. This documentation is highly suitable for Cangjie developers, language engineers, and system architects who are building robust applications, compiler tools, or advanced metaprogramming features and require a deep technical understanding of how to implement and utilize these standard interfaces effectively.
