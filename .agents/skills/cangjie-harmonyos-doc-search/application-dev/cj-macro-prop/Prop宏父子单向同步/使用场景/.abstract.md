This directory contains usage scenarios and tutorials for state management in ArkUI using the Cangjie language. It focuses on data synchronization mechanisms between parent and child components, specifically utilizing decorators like @State, @Prop, @Observed, and @Publish. The content covers simple data types, nested objects, and array collections, illustrating how state changes propagate or remain local. It is suitable for ArkUI developers looking to master component interaction, state synchronization logic, and complex data structure handling within their applications.
