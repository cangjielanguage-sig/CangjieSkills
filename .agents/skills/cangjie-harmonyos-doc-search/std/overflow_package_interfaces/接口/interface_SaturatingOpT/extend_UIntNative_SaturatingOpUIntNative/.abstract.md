These include standard operations like addition, subtraction, multiplication, and division, as well as bit manipulation and negation. The core functionality ensures that results clamp to the type's maximum or minimum values during overflow or underflow, preventing the undefined behavior associated with wrapping arithmetic. This documentation is essential for Cangjie developers who need to perform bounded, predictable integer calculations in safety-critical or performance-sensitive applications.
