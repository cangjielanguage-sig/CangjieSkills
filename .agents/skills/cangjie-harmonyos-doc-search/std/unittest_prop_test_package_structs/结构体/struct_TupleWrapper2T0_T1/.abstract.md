This directory provides comprehensive documentation for the Cangjie `TupleWrapper2<T0, T1>` struct, a generic utility designed to encapsulate two-element tuples. It covers the fundamental struct definition, including its constructor and the `apply` method for executing closures on the tuple. The documentation also details extensions for standard interfaces like `ToString`, `Equatable`, and `IndexAccess`, enabling string representation, equality checks, and indexed element retrieval. Furthermore, it includes specialized extensions for property-based testing, specifically the `Arbitrary` and `Shrink` interfaces for random generation and value reduction. This content is intended for Cangjie developers and QA engineers working with data structures or implementing automated testing frameworks.
