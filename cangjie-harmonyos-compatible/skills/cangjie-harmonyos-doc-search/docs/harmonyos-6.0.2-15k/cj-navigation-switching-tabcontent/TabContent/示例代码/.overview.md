# 示例代码

This directory provides a comprehensive collection of code examples and tutorials focused on implementing and customizing tab components using the Cangjie language and HarmonyOS UI framework. It covers a wide range of functionalities, including custom tab switching linkage, vertical side tabs, text height adaptation, bottom tab properties, and dynamic styling for text and icons. Additionally, it offers comparative examples of different tab bar styles and configurations for underline indicators. These resources are suitable for developers seeking to master complex UI navigation patterns and enhance user interface feedback in HarmonyOS applications.

## Detailed Description

### 示例1自定义页签切换联动.md 示例1自定义页签切换联动.md
This document provides a code example demonstrating how to implement custom linkage between a tab bar and tab content in a Cangjie application. The main sections include the `EntryView` component definition, a custom `tabBuilder` function for styling tab items, and the configuration of the `Tabs` container. Key information highlights the use of the `onAnimationStart` callback to update the visual state of the custom tab bar and the `onChange` callback to synchronize the content index during switching. This tutorial is intended for developers using the Cangjie UI framework to build interactive tab interfaces with custom visual feedback.

### 示例2自定义侧边页签.md 示例2自定义侧边页签.md
This document provides a code tutorial demonstrating how to implement custom vertical side tabs using the Cangjie language and HarmonyOS UI Kit. The main content includes a complete code example featuring an EntryView class, a custom tabBuilder function, and the build method configuring the Tabs component. Key information highlights setting the vertical property and BarPosition.Start to position tabs on the side, using @Builder for custom tab content, and managing state variables like selectedIndex to handle UI updates during tab switching. This tutorial targets developers familiar with Cangjie and declarative UI paradigms who need to implement sidebar navigation in their applications.

### 示例5设置子页签文本自适应高度属性.md 示例5设置子页签文本自适应高度属性.md
This document provides a code example demonstrating how to configure text height adaptation for sub-tab labels using the heightAdaptivePolicy property in a Cangjie UI application. The example illustrates four distinct text handling scenarios within a vertical Tabs component: single-line truncation with ellipses, font size reduction before clipping, font reduction combined with line wrapping, and multi-line wrapping. Key technical details include the configuration of SubTabBarStyle, LabelStyle, TextOverflow, and specific adaptive policies like MAX_LINES_FIRST and MIN_FONT_SIZE_FIRST. This tutorial is intended for UI developers using the Cangjie language who need to manage text overflow and layout constraints in tab interfaces.

### 示例6设置底部页签基本属性.md 示例6设置底部页签基本属性.md
This document provides a Cangjie code example demonstrating how to configure and dynamically modify basic properties of bottom tab bars in a HarmonyOS application. It covers the implementation of BottomTabBarStyle properties including padding, verticalAlign, layoutMode, and symmetricExtensible. The example utilizes state variables and interactive buttons to show real-time updates to the tab bar's appearance, such as adjusting padding, switching between vertical and horizontal layouts, and changing alignment. This tutorial is intended for HarmonyOS developers using the Cangjie language who need to customize tab bar behaviors and layouts.

### 示例7设置子页签底部页签文本颜色.md 示例7设置子页签底部页签文本颜色.md
This document provides a Cangjie code example demonstrating how to customize text and icon colors for sub-tabs and bottom tabs. It covers the implementation of SubTabBarStyle and BottomTabBarStyle within the Tabs component. The example illustrates using LabelStyle to define unselectedColor and selectedColor for text, and TabBarIconStyle for icon colors in bottom tabs. This tutorial targets developers using the Cangjie UI framework who need to implement dynamic tab styling to enhance user interface feedback.

### 示例4设置子页签下划线基本属性/
This directory contains code examples focused on configuring and animating the underline indicator for sub-tabs in HarmonyOS applications. It covers setting basic visual properties like color, height, width, border radius, and spacing using languages such as Cangjie and ArkTS. The examples demonstrate how to use `SubTabBarStyle`, `IndicatorStyle`, and the `animateTo` function to create static and dynamic UI effects. These tutorials are suitable for developers working on HarmonyOS UI development who need to customize tab navigation components and implement smooth property animations.
