This directory contains technical documentation and code examples related to the `setCharacteristicChangeNotification` function, a critical component for managing Bluetooth Low Energy (BLE) GATT client connections. The resources provided cover the complete lifecycle of enabling or disabling notifications for server-side characteristic value changes, including API specifications, system capability requirements, and asynchronous callback handling. Developers will find detailed information on prerequisites such as the `getServices` call and the necessity of the Client Characteristic Configuration descriptor. Additionally, the documentation outlines required permissions like `ohos.permission.ACCESS_BLUETOOTH` and specific error codes. This content is specifically designed for software developers and system engineers utilizing the ConnectivityKit in Cangjie or ArkTS environments to build robust BLE communication features.
