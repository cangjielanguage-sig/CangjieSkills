This directory contains comprehensive guidelines and reference matrices designed to determine integration requirements for various application types, with a specific focus on AVSession and playback control features. It covers the distinction between mandatory and conditional integration items, feature priorities, and compliance standards across media categories such as Music, Video, Live streaming, and VoIP. The documents provide detailed checklists for playback information, control states, and navigation behaviors. Suitable for developers, QA engineers, compliance auditors, and system integrators, these guidelines ensure that media applications meet specific platform standards and deliver optimized user experiences.
