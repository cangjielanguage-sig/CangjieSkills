# cj-anm-tool

本目录包含 Advanced Notification Manager (anm) 工具的说明文档。该工具旨在为开发者提供通知打印、参数设置及调试测试能力。文档详细介绍了环境要求、命令列表，并重点说明了 help、dump 和 setting 三个核心命令的用法。内容涵盖仅支持 eng 版本的限制、通过 hdc shell 执行的方式，以及如何配置缓存数量和使能开关。这份指南适合需要调试通知功能的开发者使用。

## 详细描述

### cj-anm-tool.md cj-anm-tool.md
本文档介绍了Advanced Notification Manager（anm）工具，旨在为开发者提供通知打印、参数设置及调试测试能力。文档涵盖了环境要求、命令列表，并详细说明了help、dump和setting三个核心命令的用法与参数。关键信息包括该工具仅支持eng版本，需通过hdc shell执行；dump命令可打印活跃或分布式通知，setting命令可配置缓存数量和使能开关。这是一份面向开发者的命令行参考指南，适用于需要调试通知功能的场景。
