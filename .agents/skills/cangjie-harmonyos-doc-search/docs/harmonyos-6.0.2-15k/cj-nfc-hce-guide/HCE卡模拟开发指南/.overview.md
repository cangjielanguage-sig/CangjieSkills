# HCE卡模拟开发指南

This directory serves as a comprehensive technical guide for developers aiming to implement Host Card Emulation (HCE) technology within HarmonyOS applications using the Cangjie programming language. It thoroughly covers the fundamental concepts of NFC card emulation, explaining how software can simulate smart cards without relying on secure element hardware. The documentation addresses critical implementation aspects, including AID registration, APDU command handling, and the specific APIs required for communication with external readers. Furthermore, it distinguishes between foreground and background execution modes, detailing the necessary permissions and lifecycle management. This resource is specifically designed for HarmonyOS developers who possess a working knowledge of Cangjie and NFC protocols, providing the essential instructions needed to build secure, contactless transaction applications such as mobile payments or access control systems.

## Detailed Description

The following sections provide in-depth technical details regarding the theory and practical implementation of HCE features.

### 简介_3more.md 简介_3more.md
This document provides an introduction to Host Card Emulation (HCE) technology, explaining how applications simulate NFC cards without secure element chips. It covers basic definitions of NFC and HCE, usage scenarios including foreground and background card swiping, and interface descriptions. Key takeaways include the requirement for an unlocked screen, AID registration, and the use of specific APIs like start, stop, on, and transmit to manage communication with readers. Targeted at developers using the Cangjie framework, this guide outlines the necessary permissions and constraints for implementing NFC card emulation features.

### 开发步骤/
This directory contains essential technical documentation for implementing Host Card Emulation (HCE) functionality within HarmonyOS applications using the Cangjie programming language. It provides a comprehensive walkthrough of the development steps required to simulate smart cards for contactless interactions, such as payments or secure access. The content covers the entire implementation spectrum, starting with configuration in `module.json5` for permissions and actions, importing necessary modules, and checking device capabilities for NFC and HCE support. It details how to manage the HCE service lifecycle, specifically distinguishing between foreground execution—where priority is managed via `EntryAbility`—and background execution. Key technical processes include subscribing to APDU commands, processing data through callbacks, and transmitting appropriate responses. These guides are tailored for HarmonyOS developers who have a working knowledge of Cangjie and understand NFC protocols, enabling them to build robust, contactless transaction applications.
