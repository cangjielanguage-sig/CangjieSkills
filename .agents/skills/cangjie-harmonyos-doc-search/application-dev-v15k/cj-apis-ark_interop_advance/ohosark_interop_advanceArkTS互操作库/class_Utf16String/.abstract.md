This directory contains comprehensive API reference documentation for the `Utf16String` class in the Cangjie programming language. It focuses on high-performance string storage in UTF-16 format, specifically optimized for ArkTS interoperability and ArkUI application development. The documentation covers class definitions, properties, constructors, operator overloads, and various string manipulation methods including searching, splitting, and memory management. It is suitable for software developers working on HarmonyOS applications who require efficient Napi interactions and complex string operations using Cangjie syntax.
