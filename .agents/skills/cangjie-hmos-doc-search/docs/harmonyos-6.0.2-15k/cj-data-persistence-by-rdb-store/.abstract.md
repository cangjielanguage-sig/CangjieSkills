This directory serves as a comprehensive technical resource for implementing data persistence using relational databases within the Cangjie framework on HarmonyOS. It focuses on the SQLite-based RdbStore component, enabling developers to efficiently manage complex data relationships and ensure data integrity. Key topics include predicates, result sets, system constraints, CRUD operations, version management, and database backup. This guide is specifically designed for application developers utilizing the ArkData kit who require robust local storage solutions with SQL capabilities to handle large datasets and manage data evolution effectively.
