# API_列表

This directory serves as a comprehensive technical reference for the `API_列表`, specifically focusing on deprecated POSIX system calls and low-level programming interfaces. It provides detailed documentation for functions and constants essential for file manipulation, process control, and permission management. The content is primarily written in Chinese and addresses cross-platform compatibility issues across Linux, macOS, and Windows. It is an invaluable resource for software engineers, system programmers, and students who are maintaining legacy codebases, performing system-level programming, or migrating applications from older C-style interfaces to modern frameworks. By documenting obsolete APIs, it aids in understanding historical system behaviors and ensuring smooth transitions in software evolution projects. This collection is crucial for anyone needing to reference or implement low-level logic in a legacy environment, ensuring that developers have access to necessary specifications for older systems.

## Detailed Description

### 函数/
This directory contains documentation regarding programming functions, primarily focusing on deprecated POSIX system calls and file operations. It covers a wide range of low-level tasks including file manipulation, permission management, process control, and system information retrieval. The content is written in Chinese and serves as a reference for legacy code maintenance or migration projects. It is suitable for developers and students working with system-level programming who need to understand obsolete APIs, platform compatibility (Linux, macOS, Windows), and function signatures for C-style interfaces.

### 常量/
This directory contains documentation for various programming constants, primarily focusing on deprecated POSIX API definitions. It covers immutable values used in file system operations, input/output handling, permission settings, and signal management. The content serves as a reference for developers maintaining legacy code or understanding low-level system interactions across Linux, Windows, and macOS platforms. Key topics include file flags, access modes, and process signals. This resource is suitable for software engineers and system programmers who need detailed specifications on specific constant behaviors and their cross-platform compatibility.
