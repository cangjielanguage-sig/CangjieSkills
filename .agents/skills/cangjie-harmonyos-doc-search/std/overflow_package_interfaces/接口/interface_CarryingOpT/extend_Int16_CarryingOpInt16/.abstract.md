This directory serves as a comprehensive API reference for the `CarryingOp` interface implementation tailored for the `Int16` type within the Cangjie programming language. It provides detailed documentation for arithmetic operations designed to handle integer overflow through a wrapping strategy. The content covers a wide range of functions, including addition, subtraction, multiplication, division, and bitwise shifts, all of which return a tuple containing a Boolean overflow flag and the result. This resource is essential for developers and systems programmers who require granular control over arithmetic behavior and explicit overflow detection in their software projects.
