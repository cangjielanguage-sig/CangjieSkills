This directory provides comprehensive API reference documentation for the `ShowToastOptions` class, specifically designed for the Cangjie language and ArkUI framework. It covers the configuration of text toast message displays, including detailed specifications for constructors and fourteen read-only properties such as message content, duration, alignment, background color, and shadow options. The documentation outlines system capabilities, type definitions (e.g., Color, Offset, BlurStyle), and API version compatibility starting from version 19. It is intended for developers and UI engineers seeking to customize toast notification appearance and behavior within their applications using specific UI types.
