### 通用规则.md 通用规则.md
This document establishes general conventions for parameter units and error handling within the ArkUI framework. It covers two primary topics: default measurement units for length parameters and the protocol for handling invalid input values. Key takeaways include that length parameters default to virtual pixels (vp) for Int32, Int64, and Float64 types. Regarding exceptions, invalid parameters revert to defined defaults if they exist; otherwise, the specific attribute or interface fails to activate. This reference guide targets developers using the ArkUI framework who need to understand system behaviors regarding input validation and unit measurement to ensure correct UI implementation.
