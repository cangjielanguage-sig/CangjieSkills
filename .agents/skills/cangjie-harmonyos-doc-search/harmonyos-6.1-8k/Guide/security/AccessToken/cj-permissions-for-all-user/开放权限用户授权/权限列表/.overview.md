# 权限列表

本目录包含HarmonyOS API 12相关的权限参考文档，涵盖了蓝牙、相机、位置、健康数据等敏感权限的定义与授权方式，以及平板设备上公共目录（如下载、文档目录）的访问权限。文档详细说明了权限级别（如normal）、授权模式（user_grant）及配置要求，特别是后台位置权限的特殊申请流程。这些资料旨在帮助应用开发者正确配置module.json5，遵循隐私规范，从而合法合规地申请和使用系统权限。

## 详细描述

### ohospermissionAC_14more_9887850d.md ohospermissionAC_14more_9887850d.md
本文档是HarmonyOS API 12的权限参考文档，旨在定义蓝牙、相机、位置及健康数据等敏感权限的用途与授权方式。文档涵盖了ACCESS_BLUETOOTH、LOCATION_IN_BACKGROUND等权限条目，重点说明了后台位置权限需先申请前台权限并引导用户手动授予的特殊流程。关键信息指出所有权限均为normal级别，需通过user_grant方式授权，且精确位置依赖模糊位置。该文档面向应用开发者，帮助其正确配置module.json5并遵循隐私规范申请系统权限。

### ohospermissionREA_2more_86012edc.md ohospermissionREA_2more_86012edc.md
本文档定义了两个用于在平板设备上访问公共目录的HarmonyOS权限。主要涵盖了READ_WRITE_DOWNLOAD_DIRECTORY（访问下载目录）和READ_WRITE_DOCUMENTS_DIRECTORY（访问文档目录）两个权限条目。关键信息包括这两个权限均为normal级别，需用户授权，仅支持平板设备，且起始版本为API 12。该文档面向HarmonyOS应用开发者，用于指导应用在特定版本和设备上获取文件读写权限。
