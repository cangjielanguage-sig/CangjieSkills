This directory provides API reference documentation for the `LocalStorage` class in the Cangjie ArkUI framework. Key functionalities include retrieving values, checking existence, creating one-way or two-way bindings, and managing property lifecycles. This documentation is intended for ArkUI developers using Cangjie who need to implement robust state management, data persistence, and synchronization between UI components and the storage layer.

### class_LocalStorage_5more.md class_LocalStorage_5more.md
This API reference document details the LocalStorage class, which provides page-level UI state storage for the ArkUI framework in Cangjie. It covers the class constructor, the prop function for retrieving one-way bindings, and management functions clear and delete for removing properties. Key information includes that properties can only be deleted if they have no active subscribers, such as those bound via @LocalStorageLink or @LocalStorageProp. The prop method returns a one-way binding that does not sync changes back to storage. This guide targets ArkUI developers needing to manage application state and component lifecycle.
