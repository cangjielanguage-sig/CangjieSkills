This directory contains a collection of practical code examples demonstrating image handling capabilities within the ArkUI framework using the Cangjie language. It covers fundamental operations such as loading various image formats (PNG, GIF, SVG, JPG), managing interactive events, and applying advanced visual effects like fill modes, color customization, and rendering adjustments. These examples are designed to help HarmonyOS developers master the Image component, optimize display performance, and enhance user interface interactions through state management and property configuration.
