# ArkData

The ArkData directory serves as a comprehensive API reference and documentation hub for data management within the HarmonyOS ecosystem, specifically tailored for the Cangjie programming language. It covers core functionalities including distributed key-value stores, relational databases, user preferences, data sharing predicates, and value buckets. Additionally, it provides detailed error code references for debugging and exception handling. This resource is primarily designed for developers using Cangjie to build robust applications requiring data persistence, synchronization, and query capabilities. All features listed are currently in Beta.

## Detailed Description

### [1] README_zh/
This directory contains the API reference index documentation for the ArkData module in the Cangjie language. It serves as a navigation guide for HarmonyOS application developers, covering core APIs such as data sharing predicates, distributed key-value databases, user preferences, relational databases, and datasets, along with related error code definitions. All listed features are currently Beta. This document is suitable for developers using the Cangjie language to quickly locate interfaces related to data storage, querying, and distributed data synchronization, as well as exception handling information.

### [2] cj-apis-data_share_predicates/
This directory serves as a comprehensive guide for the `data_share_predicates` module, part of the ArkData suite tailored for the Cangjie programming language. It is dedicated to the construction and management of filter conditions essential for DataShare operations.

### [3] cj-apis-distributed_kv_store/
This directory provides the essential API reference documentation for the HarmonyOS Distributed Key-Value (KV) Store, specifically developed for the Cangjie programming language. It serves as a critical resource for developers looking to implement robust distributed data storage solutions.

### [4] cj-apis-preferences/
This directory serves as a comprehensive technical resource for the `cj-apis-preferences` module, providing essential API reference documentation for developers working within the HarmonyOS ecosystem using the Cangjie programming language. The core focus is on managing user preferences and lightweight data persistence.

### [5] cj-apis-relational_store/
This directory serves as a comprehensive API reference for the Relational Database (RDB) features in HarmonyOS, specifically designed for the Cangjie programming language. It encompasses the full spectrum of database functionalities, ranging from initialization to complex data manipulation.

### [6] cj-apis-values_bucket/
This directory contains the API reference documentation for the `ohos.data.values_bucket` module in the Cangjie language, a key component for handling database data in ArkData development. The documentation details the structure and usage of key-value pair datasets defined for database insertion. Core content covers the `VBValueType` enumeration, listing supported field types such as integer, float, string, and boolean, while specifying system capabilities and starting versions (API 22). It is aimed at developers using Cangjie for ArkData application development to guide the correct construction and use of `ValuesBucket`.
