# Web

This directory provides comprehensive documentation for the Web component in the Cangjie language, designed for HarmonyOS developers using the ArkWeb framework. It covers the integration of web content into native applications, detailing API references for component creation, controller usage, and event handling. Key topics include WebView configuration, resource management, security settings, and interaction between native and web layers. This resource is suitable for developers building hybrid applications or embedding web pages, offering essential tools for managing web view lifecycles, properties, and user interactions effectively.

## Detailed Description

### Web_3more.md Web_3more.md
This document serves as API reference documentation for the Web component in the Cangjie language, designed to provide web page display capabilities within applications. It details the component creation process through two overloaded init functions: one accepting a String URL and another accepting an AppResource for local files. Key information includes constraints such as the lack of support for transition animations, the necessity of binding unique WebviewController instances to multiple components, and the restriction that String src parameters cannot be dynamically updated via state variables. Additionally, it specifies protocols for accessing local resources like @rawfile or file://. This technical reference targets HarmonyOS developers utilizing the ArkWeb framework to integrate web content.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating how to integrate and control a WebView component within a Cangjie application. The content covers UI layout construction using Column and Button components, state management with the @State decorator, and WebView controller usage. Key takeaways include the implementation of button click handlers for refreshing and loading URLs, as well as logging page lifecycle events like onPageBegin and onPageEnd. This reference example targets Cangjie developers building HarmonyOS applications who need to embed web content into their native interfaces. Keywords: Cangjie, WebView, HarmonyOS, UI component, event handling, WebviewController.

### 基础类型定义/
This directory contains API reference documentation for fundamental data structures and enumerations used in Cangjie WebView development. It covers classes for handling web events (alerts, downloads, errors), resource management (requests, responses, headers), and configuration enums (cache modes, mixed content). These definitions are essential for developers building robust webview applications, enabling precise control over web content interaction, security settings, and user interface behaviors. Targeted at application developers utilizing the SystemCapability.Web.Webview.Core module, this documentation provides the necessary type definitions to implement advanced web features and manage system capabilities effectively.

### 组件事件/
This directory provides comprehensive API documentation for handling events within the ArkWeb Webview component using the Cangjie programming language. It covers a wide range of functionalities, including lifecycle management, resource loading, JavaScript dialog interception, ad blocking, and hardware permission requests for camera and microphone access. Designed for HarmonyOS application developers, these resources offer detailed guidance on managing web interactions, configuring security settings, and integrating native capabilities with web content to build robust hybrid applications.

### 组件属性/
This directory contains API reference documentation for configuring Webview component properties using the Cangjie language within the ArkWeb framework. It covers a comprehensive range of settings including security permissions, layout modes, font customization, JavaScript interaction, and media playback controls. Developers can find detailed parameters for managing web content rendering, storage access, and user interface behaviors. Suitable for application developers building hybrid applications on HarmonyOS who need granular control over Webview capabilities and system integration.

### 通用属性通用事件/

This resource is suitable for developers looking to quickly locate specific properties to define component appearance or implement interactive behaviors and state tracking in their UI applications. It acts as a central index for styling and functional logic, providing direct links to detailed definitions for efficient development workflows. By categorizing properties and events, it enables rapid application of styling and functional logic to components, making it an essential tool for building responsive and interactive user interfaces.
