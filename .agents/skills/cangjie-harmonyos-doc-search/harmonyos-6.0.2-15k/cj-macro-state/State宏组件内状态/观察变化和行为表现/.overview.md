# 观察变化和行为表现

This directory focuses on the reactivity mechanisms within the ArkUI framework and the Cangjie language. It covers how state changes are observed, how these changes trigger component updates, and the specific behaviors of different data types (primitives, structs, classes, arrays) under decorators like @State and @Observed. Key concepts include on-demand rendering, dependency tracking, and state management rules. This content is suitable for developers looking to optimize UI performance and ensure data synchronization in their applications.

## Detailed Description

### 框架行为.md 框架行为.md
This document explains the core reactive behavior and rendering mechanism of the framework, specifically how state changes trigger component updates. The content covers the lifecycle of a state change: querying dependencies, executing updates, and optimizing rendering by skipping unrelated components. The key concept is "on-demand updating." When a state variable changes, only components directly dependent on that variable are queried and re-rendered. Unrelated UI descriptions remain static, ensuring performance efficiency. This serves as a conceptual reference guide for developers using the framework to understand performance optimization and state management. It assumes basic knowledge of component-based architecture. Keywords: framework behavior, state variables, component updates, on-demand rendering, reactive programming.

### 观察变化.md 观察变化.md
This technical guide details the change observation behavior of the @State decorator across different data types in the Cangjie language. It covers primitives, structs, classes, arrays, and other collections. Key takeaways include that primitives are fully observable, while structs only support whole assignment. Classes require @Observed and @Publish macros to detect internal changes. Standard arrays only observe full replacement, whereas ObservedArray and ObservedArrayList enable item-level change detection. This reference material is intended for developers managing state in ArkUI applications, providing essential rules for ensuring UI reactivity and data synchronization.
