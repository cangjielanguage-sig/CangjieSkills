# cj-power-shell

本目录包含 `cj-power-shell` 工具的参考指南，专门设计用于协助开发者高效调试设备的电源状态。文档内容全面，涵盖了环境配置的先决条件以及核心操作命令，重点深入讲解了如何设置不同的电源模式（包括正常、省电、性能及超级省电四种模式）、控制屏幕的亮灭状态以及精确管理自动熄屏时间。该资源主要面向使用 `hdc shell` 进行系统级交互的开发者，通过提供具体的命令语法与实际操作示例，帮助用户快速掌握电源管理技巧，优化设备功耗表现，确保应用在不同电源策略下的稳定性与性能。

## 详细说明

### cj-power-shell.md cj-power-shell.md

本文档是 power-shell 工具的权威参考指南，旨在帮助开发者深入调试设备的电源状态。文档内容涵盖了环境搭建要求及核心命令的使用方法，重点介绍了如何设置电源模式、控制亮屏与熄屏操作，以及管理自动熄屏时间。关键内容包括 `setmode` 命令所支持的四种模式（正常、省电、性能、超级省电）的具体应用场景，以及 `timeout` 命令用于覆盖或恢复系统休眠时间的详细参数用法。该文档特别适合使用 `hdc shell` 的开发者，提供了清晰的命令语法与丰富的操作示例，以便于在实际开发中快速定位和解决电源相关问题，提升调试效率。
