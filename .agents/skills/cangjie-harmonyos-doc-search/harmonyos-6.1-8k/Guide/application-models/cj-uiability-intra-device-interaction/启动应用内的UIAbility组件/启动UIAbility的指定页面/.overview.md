# 启动UIAbility的指定页面

本文档集旨在指导HarmonyOS开发者如何在启动UIAbility时直接跳转至指定页面。内容涵盖了UIAbility的冷启动与热启动场景，详细讲解了如何利用Want参数传递自定义参数（如"router"）来实现页面路由控制。文档包含基于仓颉（Cangjie）语言的代码示例，展示了从参数配置、生命周期回调处理到页面加载的完整流程。适用于具备AbilityKit和ArkUI基础知识的开发者，帮助其掌握多Ability交互及页面跳转的核心技术。

## 详细描述

### 概述_2more_f8d98b54.md
本文档旨在指导开发者如何在启动UIAbility时指定显示的特定页面。文档涵盖了UIAbility冷启动与热启动的定义，以及调用方如何通过Want参数配置启动页面。核心要点是利用Want中的parameters字段传递自定义参数（如"router"）来实现页面跳转，文档提供了Cangjie代码示例展示具体实现。这是一份技术指南，适用于HarmonyOS应用开发者，需具备AbilityKit和ArkUI基础知识。

### 目标UIAbility冷启动_fa021c8a.md
本文档旨在指导开发者如何在目标UIAbility冷启动时接收调用方参数并加载指定页面。文档详细说明了在onCreate生命周期回调中接收Want参数，以及在onWindowStageCreate回调中解析参数获取页面URL，并通过windowStage.loadContent方法加载页面的流程。文中提供了基于仓颉（Cangjie）语言的代码示例，展示了FuncAbilityA类的具体实现。该文档适合熟悉HarmonyOS应用开发及UIAbility生命周期的开发者阅读，重点涉及UIAbility、冷启动、Want参数传递及页面路由加载等关键技术点。

### 目标UIAbility热启动.md
本文档旨在指导开发者处理目标UIAbility的热启动场景，即在实例已存在时再次启动的逻辑。文档主要介绍了onNewWant()生命周期回调的使用及通过Router进行页面跳转的开发步骤。核心要点在于，热启动仅触发onNewWant()而非初始化方法，开发者需在此解析Want参数并调用Router.pushUrl跳转至指定页面。文档还指出multiton启动模式下不会触发该回调。本文适用于使用仓颉语言进行应用开发的开发者，特别是涉及多Ability交互的场景。
