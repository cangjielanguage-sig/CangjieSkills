# cj-crypto-sm4-sym-encrypt-decrypt-gcm-by-segment

This directory provides a comprehensive guide and implementation examples for performing segmented encryption and decryption using the SM4 symmetric algorithm within the GCM (Galois/Counter Mode) standard. It specifically addresses the complexities of processing data in chunks, which is essential for handling large files or streaming data efficiently without loading entire datasets into memory. The content is built upon the CryptoArchitectureKit, offering a practical reference for developers working in the Cangjie ecosystem. It covers critical security aspects such as key generation, parameter configuration, and the management of authentication tags (authTag) to ensure both data confidentiality and integrity. This resource is highly suitable for backend engineers, security architects, and developers looking to integrate robust, high-performance cryptographic operations into their Cangjie applications.

## Detailed Description

### [1] 使用SM4对称密钥GCM模式分段加解密/

This subdirectory serves as a comprehensive technical repository containing documentation and practical code samples focused on the segmented application of the SM4 symmetric key algorithm in GCM mode. The primary objective of this content is to demonstrate the complete lifecycle of data encryption and decryption, specifically tailored for scenarios where data must be processed in segments rather than as a monolithic block. This approach is crucial for optimizing memory usage and improving performance when dealing with large files or continuous data streams.

Key technical areas covered include the secure generation of SM4 symmetric keys and the precise configuration of GCM mode parameters, which are vital for the cipher's security. The documentation provides detailed insights into the mechanics of segmented data processing, illustrating how to utilize `update` and `doFinal` operations to feed data into the cipher incrementally. Furthermore, it addresses the critical handling of the authentication tag (authTag), a component essential for verifying data integrity and authenticity in GCM mode. By leveraging the CryptoArchitectureKit, this guide offers a specialized resource for developers operating within the Cangjie development environment who require efficient, standards-compliant, and secure cryptographic implementations.
