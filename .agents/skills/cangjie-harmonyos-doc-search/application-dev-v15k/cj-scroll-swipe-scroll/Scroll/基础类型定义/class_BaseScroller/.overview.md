# class_BaseScroller

This directory contains API reference documentation for the BaseScroller class and related scrolling functions within the Cangjie ArkUI framework. It covers the core functionality required to programmatically control scrolling behaviors in UI components such as List, Grid, WaterFlow, and Scroll. Key topics include the BaseScroller class properties, methods for relative and absolute positioning, index-based navigation, and animation controls. This documentation is suitable for developers building UI applications in Cangjie who need to implement precise scroll manipulation, query component states, or handle fling and edge navigation logic.

### class_BaseScroller_8more.md class_BaseScroller_8more.md
This document serves as API reference documentation for the BaseScroller class in the Cangjie language, detailing the base functionality for scrolling components within the ArkUI framework. The content covers the class initialization and key methods including currentOffset, fling (overloaded for Float64 and Int64), getItemIndex, getItemRect, and isAtEnd. ### func_scrollByLength_Length_7more.md func_scrollByLength_Length_7more.md
This document serves as an API reference for scrolling control functions within the Cangjie ArkUI framework, detailing methods to manipulate scroll positions programmatically. The content covers five primary functions: scrollBy for relative movement, scrollTo for absolute positioning, scrollEdge for edge navigation with optional velocity, and scrollPage for pagination with animation control. Key takeaways include that scrollBy and scrollTo do not support percentage values, scrollEdge allows specifying speed in vp/s, and all functions utilize named parameters starting from API version 12. This technical reference targets UI developers using Cangjie to implement precise scrolling behaviors in Scroll, List, Grid, and WaterFlow components.

### func_scrollToIndexInt32_Bo_2more.md func_scrollToIndexInt32_Bo_2more.md
This document provides API reference documentation for the scrollToIndex function in the Cangjie language, designed to control scrolling behavior within container components. It covers two overloaded function signatures that allow developers to scroll to a specific index in List, Grid, or WaterFlow components. Key parameters include the target index, a smooth animation toggle, alignment settings, and an optional extra offset. The documentation highlights a critical performance warning: enabling smooth animation triggers layout calculations for all traversed items, potentially causing issues with large datasets. Intended for ArkUI developers, this reference requires knowledge of Cangjie syntax and UI component structures to effectively implement scroll navigation.

### func_scrollToLength_Length_3more.md func_scrollToLength_Length_3more.md
This document serves as API reference documentation for the scrollTo function in the Cangjie language, detailing three overloaded methods to programmatically scroll containers to specific coordinates with varying animation controls.
