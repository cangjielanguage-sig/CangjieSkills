This directory provides comprehensive API reference documentation for the `ohos.skill` module within the HarmonyOS framework, specifically tailored for the Cangjie programming language. It focuses on the core classes required for system-level skill management and URI routing. The documentation covers the `Skill` class for handling skill tag objects and the `SkillUri` class for defining URI structures, including advanced matching features like path regex and MIME types. Designed for HarmonyOS developers, these resources assist in implementing inter-app jumping, data matching, and bundle information management.
