### 仓颉线程_d5c8b76f.md 仓颉线程_d5c8b76f.md
本文档是cjdb调试器中关于仓颉线程功能的参考指南，旨在指导用户如何查看线程状态和堆栈信息。文档主要涵盖两个核心命令：`cjthread list`用于列出当前进程中的所有线程及其ID、状态和顶层帧；`cjthread backtrace`用于显示指定线程的详细调用栈。关键点在于明确指出当前版本支持查看线程信息但暂不支持线程切换，并提供了具体的命令使用示例和参数说明。目标受众为使用cjdb进行仓颉程序调试的开发人员，适用于需要分析多线程执行上下文和调试并发问题的场景。
