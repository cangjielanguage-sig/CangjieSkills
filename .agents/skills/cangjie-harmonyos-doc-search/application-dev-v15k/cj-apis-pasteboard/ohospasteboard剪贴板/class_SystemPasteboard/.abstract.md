This directory provides comprehensive API reference documentation for the `SystemPasteboard` class within the Cangjie language environment, specifically designed for managing system clipboard operations. It details the complete lifecycle of clipboard interaction, including initializing the pasteboard, reading data, checking for data existence, verifying specific MIME types, and identifying data sources. The documentation highlights critical methods such as `getData` and `setData`, outlining necessary permissions, exception handling, and version requirements. This resource is essential for Cangjie developers integrating clipboard functionality into their applications using the BasicServicesKit and SystemCapability.MiscServices.Pasteboard.
