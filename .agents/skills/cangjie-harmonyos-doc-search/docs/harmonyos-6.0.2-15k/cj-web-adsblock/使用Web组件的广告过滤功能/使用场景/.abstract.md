This directory outlines various usage scenarios for implementing and managing ad filtering within applications using the ArkWeb framework and HarmonyOS. It covers essential functionalities such as enabling ad blocking with custom rules, collecting statistics on blocked ads, and managing granular control over specific domains through allowlists and disallowlists. Key topics include the `AdsBlockManager` API, event handling via `onAdsBlocked`, and domain matching logic. These resources are designed for application developers seeking to integrate robust ad-blocking capabilities, customize filtering rules, and optimize user experience by exempting specific websites from filtering.
