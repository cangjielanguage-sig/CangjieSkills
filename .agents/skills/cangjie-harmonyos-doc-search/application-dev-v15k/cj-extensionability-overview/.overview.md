# cj-extensionability-overview

This directory provides a comprehensive technical overview of ExtensionAbility components within the Stage model development framework. It focuses on system-managed application components tailored for specific scenarios, including embedded user interfaces and data sharing mechanisms. The content covers essential aspects such as component types (EmbeddedUIExtensionAbility and ShareExtensionAbility), lifecycle management, sandboxing configurations, and process isolation models. It highlights that these components are invoked by system services rather than directly by applications to ensure strict control. This resource is ideal for developers seeking to master component architecture, understand data sharing modes, and navigate system constraints for creating advanced, secure applications. By detailing the interaction between system services and application components, it offers crucial insights for building robust, extensible software solutions.

## Detailed Description

### cj-extensionability-overview.md

This document serves as a technical overview of ExtensionAbility components, which are system-managed application components designed for specific scenarios like embedded UIs and sharing. It details the supported types, specifically EmbeddedUIExtensionAbility and ShareExtensionAbility, outlining their functionality, permissions for third-party implementation and access, and sandboxing configurations. Key takeaways include that these components cannot be started directly by applications but are instead pulled up by corresponding system services to ensure lifecycle control. Additionally, the document explains the process model where same-type components run in a single independent process separate from UIAbility components. This guide is intended for developers using the Stage model to understand component architecture, data sharing modes, and system constraints.
