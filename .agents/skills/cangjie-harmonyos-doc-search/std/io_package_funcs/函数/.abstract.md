This directory serves as a comprehensive collection of API reference documentation for utility functions within the Cangjie standard library, specifically focusing on input/output (IO) stream operations. It provides detailed technical information for critical data handling tasks, including copying data between streams, reading stream content into strings, and retrieving remaining data as byte arrays. The documentation highlights important distinctions between safe operations that validate UTF-8 encoding and unsafe variants optimized for performance. It is designed for Cangjie developers seeking to implement robust and efficient data processing, stream reading, and error handling within their software projects.
