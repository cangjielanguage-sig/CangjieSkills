# 预览

This directory serves as a comprehensive technical resource for developers working on camera preview functionality, specifically focusing on the complexities of output rotation and display orientation synchronization. It provides essential guidance on using the CameraKit framework to manage how camera previews are rendered relative to the device's screen orientation. The documentation covers critical APIs such as `PreviewOutput.getPreviewRotation` and `PreviewOutput.setPreviewRotation`, alongside practical implementation strategies for handling dynamic rotation events. Additionally, it addresses configuration constraints like the `commitConfig` sequence and the `isDisplayLocked` parameter. This material is highly suitable for mobile application developers using Cangjie or ArkTS who need to ensure their camera apps provide a seamless and correctly oriented visual experience for users across different device states.

## Detailed Description

### 预览_1.md 预览_1.md
This technical guide instructs developers on configuring camera preview output rotation within a session using the CameraKit framework. The document details two primary steps: retrieving the preview rotation angle based on device display orientation and applying this rotation to the preview output. Key information includes the usage of `PreviewOutput.getPreviewRotation` and `PreviewOutput.setPreviewRotation` APIs, emphasizing that these must be called after `commitConfig`. It explains the `isDisplayLocked` parameter, which determines if rotation follows window changes or remains fixed based on the camera lens angle. Targeted at developers building camera applications in Cangjie, the guide provides practical code snippets for implementation.

### 预览_2.md 预览_2.md
This document provides a code example demonstrating how to synchronize camera preview rotation with the device's display orientation. It covers the previewRotation function, initial setup of rotation values, and the implementation of a callback listener to handle dynamic rotation changes during capture status updates. The code retrieves the default display rotation, converts it to degrees, and applies it to the preview output. It utilizes a listener mechanism to automatically adjust the preview rotation whenever the capture status changes, ensuring the preview remains correctly oriented relative to the screen. This technical reference is intended for mobile application developers working on camera functionality, specifically those needing to handle orientation changes dynamically. Keywords: camera preview, rotation synchronization, display orientation, event listener, mobile development, ArkTS.
