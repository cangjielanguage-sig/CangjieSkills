# ohossensor传感器

本目录包含仓颉语言中ohos.sensor模块的API参考文档，专注于HarmonyOS/OpenHarmony系统的传感器开发。内容涵盖传感器数据响应类（如加速度计、陀螺仪、心率等）、配置选项类、枚举类型（如SensorId、IntervalOption）及核心订阅函数。文档详细定义了各类属性、数据类型、单位及系统能力要求，旨在为开发者提供处理原始传感器数据的标准规范。适用于需要集成设备传感器功能的仓颉语言开发者。
