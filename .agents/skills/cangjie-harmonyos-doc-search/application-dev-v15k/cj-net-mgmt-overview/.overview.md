# cj-net-mgmt-overview

This directory serves as a comprehensive entry point for understanding the Network Kit, designed to facilitate robust network communication and management within applications. It provides a detailed high-level overview of the kit's core functionalities, covering essential operations such as HTTP data requests and real-time WebSocket connections. Beyond basic connectivity, the content delves into advanced network connection management features, including sophisticated multi-network priority handling, automated network quality assessment, and efficient DNS resolution processes. Crucially, the documentation outlines strict implementation constraints, emphasizing the absolute necessity of declaring specific permissions—namely `ohos.permission.INTERNET` and `ohos.permission.GET_NETWORK_INFO`—prior to development. This resource is specifically curated for application developers seeking a foundational starting point for integrating network services. It effectively bridges the gap between general concepts and practical implementation by linking to detailed guides for specific protocols and ensuring adherence to security compliance standards. By utilizing this overview, developers can ensure they have the necessary permissions and understanding of network quality metrics to build responsive and reliable applications.
