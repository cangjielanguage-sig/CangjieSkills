# func_serve

本目录包含 `serve()` 函数的 API 参考文档，主要涵盖服务端进程的启动与运行机制。内容深入解析了 HTTP/1.1 和 HTTP/2 协议的请求校验、响应处理、头部字段合规性检查及连接管理。核心知识点包括 RFC 9112 标准遵循、TLS ALPN 协商、流量控制策略、错误码处理机制以及 `100-continue` 机制。该文档适合后端开发人员阅读，旨在帮助开发者掌握服务器内部处理逻辑、规范配置及性能优化，确保通信的稳定性与安全性。

## 快速导航

- 想要了解如何启动服务端、处理 HTTP/1.1 请求及 TLS 配置 → func_serve_1.md
- 想要深入了解 HTTP/2 协议机制、流量控制、优先级及异常处理 → func_serve_2.md

## 详细描述

### func_serve_1.md
本文档是 `serve()` 函数的 API 参考文档，主要说明如何启动服务端进程。内容涵盖 HTTP/1 请求与响应的详细检查与处理逻辑，包括请求行验证、头部字段合规性检查（如 Host、Content-Length）、连接管理及响应头的自动配置。文档还介绍了通过 TLS ALPN 协商启用 HTTP/2 服务的方法。关键要点包括对 RFC 9112 标准的遵循、特定错误码（如 400、413）的触发条件以及 `100-continue` 机制的处理。该文档适合后端开发人员阅读，旨在帮助开发者深入理解服务器的内部处理机制及规范要求。

### func_serve_2.md
本文档详细阐述了HTTP/2服务器的请求校验、响应处理及流量控制机制。主要涵盖请求头与伪头的合规性检查、响应头的自动修正、基于窗口的流控策略以及基于TLS ALPN的协议选择规则。重点说明了不合规头部导致的流关闭行为、流量窗口的阻塞控制、请求优先级处理以及异常时的响应策略。这是一份技术参考文档，适合后端开发人员理解服务器内部行为，确保HTTP/2通信的稳定与正确配置。
