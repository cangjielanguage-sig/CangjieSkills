This directory contains API reference documentation for the `MeasureOptions` class within the Cangjie language, specifically designed for the ArkUI framework. It focuses on defining text attributes required for measurement and layout calculations, such as font size, weight, family, and alignment. The documentation covers the class structure and its constructor, detailing parameters for text content, styling, and constraints. It is intended for HarmonyOS developers using Cangjie who need to configure text measurement parameters for precise UI rendering and layout logic.
