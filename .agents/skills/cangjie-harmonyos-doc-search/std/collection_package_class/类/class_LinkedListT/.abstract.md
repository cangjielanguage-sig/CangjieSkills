This directory contains API reference documentation for the generic `LinkedList` class within the Cangjie standard library. It details a doubly linked list data structure that supports bidirectional traversal, dynamic resizing, and efficient insertion and deletion operations. The documentation covers class definitions, properties, constructors, and various manipulation methods including adding, removing, and converting elements. It is suitable for Cangjie developers seeking to implement dynamic collections or requiring precise syntax and behavioral details for linked list operations in their applications.
