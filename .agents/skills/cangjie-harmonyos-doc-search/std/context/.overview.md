# context

This directory serves as a technical guide for managing context and establishing robust communication channels between nested macros in the Cangjie programming language. It thoroughly covers parent-child context validation using `assertParentContext` and explains message passing mechanisms via `setItem` and `getChildMessages`. The content includes illustrative examples: one demonstrating a compilation error triggered by calling a macro outside its required parent context, and another showing how an inner macro sends key-value pairs to an outer macro for retrieval and processing during compilation. This guide is specifically designed for Cangjie developers who are already comfortable with basic macro syntax and need to implement complex macro interactions, context checks, and compile-time communication strategies in their projects.
