This directory provides comprehensive API documentation for essential interfaces within the Cangjie programming language's testing framework. It covers the core components required for property-based and parameterized testing, specifically focusing on data generation, data shrinking, and formatted output. Key interfaces documented here include `DataProvider`, `DataStrategy`, `DataShrinker`, and `PrettyPrintable`, alongside their implementations for standard collections like Array and Range. This resource is designed for developers building or extending test capabilities in Cangjie, offering the necessary technical details to manage test data lifecycle and presentation effectively.
