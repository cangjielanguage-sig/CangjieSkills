This directory focuses on the implementation and customization of selection menus for text components within the HarmonyOS ArkUI development environment. It provides comprehensive guidance on enabling default selection behaviors, binding fully custom menus, and extending standard menus with additional options. The content covers specific technical implementations using both the Cangjie language and ArkTS, detailing the use of `TextController`, `bindSelectionMenu`, `editMenuOptions`, and event handling callbacks like `onCreateMenu` and `onMenuItemClick`. This resource is designed for HarmonyOS application developers who need to create sophisticated text interaction experiences, manage user selections, and implement custom editing behaviors in their mobile applications. By following these guides, developers can learn how to intercept standard actions, append custom items, and control the UI presentation of text selection menus effectively.
