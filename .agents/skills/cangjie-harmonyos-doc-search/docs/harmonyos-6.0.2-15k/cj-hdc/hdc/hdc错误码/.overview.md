# hdc错误码

This directory serves as a specialized repository for troubleshooting documentation regarding error codes generated by the HarmonyOS Device Connector (hdc) command-line tool. It addresses a range of technical issues, including invalid bundle names specified in shell commands, unsupported interactive modes, invalid command options, missing parameters, and remote path restrictions during file transfers. The documentation provides in-depth error descriptions, analyzes root causes such as application installation status, debug signing requirements, and version incompatibilities, and outlines precise resolution strategies involving verification commands like `bm dump` and `mount`. This collection is essential for developers and QA engineers working within the HarmonyOS ecosystem who require immediate solutions to command-line execution failures to maintain development workflow efficiency.

## Detailed Description

### E003001_命令行指定的包名非法.md E003001_命令行指定的包名非法.md
This troubleshooting guide explains error code E003001, which occurs when an invalid bundle name is specified in the `hdc shell` command. The document details the error description, three potential causes (not installed, not debuggable, not started), and specific resolution steps for each scenario. Key information includes verification commands using `bm dump` and `mount` to check installation, debug status, and resource mounting. It emphasizes that only debug-signed applications support this functionality and offers commands to install or launch the app using `aa start`. This guide targets developers debugging HarmonyOS applications who need to resolve command-line execution failures.
