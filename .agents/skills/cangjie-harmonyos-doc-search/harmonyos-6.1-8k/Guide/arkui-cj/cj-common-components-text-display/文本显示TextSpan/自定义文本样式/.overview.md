# 自定义文本样式

本目录主要介绍在ArkUI框架下使用仓颉语言进行Text组件的自定义样式开发。内容涵盖了文本对齐、超长处理、行高设置、装饰线样式、基线偏移、字体自适应缩放及大小写控制等核心功能。通过详细的代码示例与效果图，帮助ArkUI应用开发者掌握文本布局控制与高级样式配置技巧，适用于希望提升UI表现力的开发人员。

## 详细描述

### 自定义文本样式_1.md
本文档介绍如何在ArkUI中使用仓颉语言自定义文本样式。主要涵盖文本对齐、超长处理、行高设置、装饰线样式及基线偏移五个部分。文档详细讲解了textAlign、textOverflow、lineHeight、decoration和baselineOffset等关键属性的使用方法，并提供了完整的代码示例和效果图，展示了具体的样式实现逻辑。该文档面向ArkUI应用开发者，旨在帮助其掌握Text组件的样式定制与布局控制技巧。

### 自定义文本样式_2.md
本文档是一份针对ArkUI开发者的代码示例教程，旨在演示如何使用Cangjie语言自定义文本样式。文档主要涵盖三个核心功能：通过baselineOffset属性调整文本基线偏移；利用minFontSize与maxFontSize实现字体大小的自适应缩放，并指出需配合maxLines或布局约束生效；以及使用textCase属性控制文本的大小写显示。文中提供了完整的代码片段和渲染效果，帮助开发者快速掌握文本组件的高级样式配置技巧。
