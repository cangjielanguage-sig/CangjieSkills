This directory serves as a comprehensive technical resource for HarmonyOS developers focusing on the management and implementation of restricted permissions through the Access Control List (ACL). It details the end-to-end workflow required to legally and technically integrate sensitive capabilities into applications that go beyond standard privilege levels. Key topics include validating usage scenarios against strict platform policies, navigating the AppGallery Connect (AGC) interface to request a Profile file, and the precise code-side configurations needed to activate these permissions. The guide highlights the critical dependency on obtaining a permission certificate from AGC before any configuration attempts, ensuring that applications do not fail during installation due to missing authorization. Furthermore, it clarifies the procedural differences between debugging environments using auto-signing and production builds requiring manual release signing. This documentation is essential for developers whose applications require access to sensitive user data or system capabilities, ensuring compliance with strict auditing standards and the necessity for precise scenario documentation.
