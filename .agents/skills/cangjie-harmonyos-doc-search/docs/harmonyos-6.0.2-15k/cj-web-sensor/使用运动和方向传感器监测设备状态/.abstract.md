This directory provides comprehensive resources for monitoring device status using motion and orientation sensors within Web components. It covers the technical implementation of accessing sensor data—such as acceleration and angular velocity—via W3C standard interfaces. The content includes detailed explanations of supported sensors (Accelerometer, Gyroscope, Orientation), JavaScript interfaces, and the mandatory permission configurations required for system access. It addresses both the frontend web integration and backend native setup, ensuring a complete understanding of the data flow from hardware to application. This material is suitable for developers creating interactive applications like fitness trackers or motion-controlled games on HarmonyOS/OpenHarmony platforms who need to bridge native hardware capabilities with web technologies.
