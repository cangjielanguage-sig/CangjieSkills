## 详细说明

### sleep.md
本文档是仓颉语言中 `sleep` 函数的 API 参考文档，旨在说明如何阻塞当前线程使其睡眠指定时长。文档主要涵盖函数原型定义、参数类型说明、关于零或负时长的特殊行为注意事项以及代码示例。关键信息指出，该函数接受 Duration 类型参数，若参数小于等于零，线程仅让出资源而不进入睡眠。文档通过示例展示了如何让线程暂停一秒。这主要面向需要控制线程执行节奏的仓颉语言开发者。
