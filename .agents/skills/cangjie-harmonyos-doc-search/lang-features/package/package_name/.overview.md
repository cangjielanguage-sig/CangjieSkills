## Detailed Description

### package_name.md

本文档旨在阐述仓颉编程语言中包声明的语法规则、位置要求及目录映射关系。主要涵盖了包声明的基本语法、文件首行位置限制、源码目录与包名的对应规则、默认包名机制以及命名冲突的避免。关键信息指出包声明必须使用合法标识符且位于文件非空非注释首行，包名需反映相对于src目录的路径并用点号分隔，且子包名不得与父包顶层声明同名。这是一份面向仓颉语言开发者的参考指南，适用于需要规范项目代码结构和模块组织的场景。
