# 传感器开发指导

本目录提供了关于鸿蒙系统传感器开发的全面指导，涵盖了从基础概念到具体代码实现的完整流程。内容包括传感器模块的核心API使用（如监听、注销）、周期传感器与瞬时传感器的区别，以及基于仓颉语言的开发步骤。文档旨在帮助开发者实现设备朝向感知、步数统计等功能，适用于OpenHarmony应用开发者及需要集成传感器功能的工程人员。

## 详细描述

### 传感器开发指导_3more_122ceb30.md
本文档旨在指导开发者如何使用sensor模块获取设备传感器数据，以实现如感知设备朝向或统计步数等功能。文档主要包含场景介绍和接口说明两个部分，详细阐述了应用场景及核心API的使用方法。重点介绍了四个核心接口：on用于持续监听数据变化，once用于获取单次数据，off用于注销监听，以及getSensorList用于获取设备传感器列表。文档目前处于Beta阶段。适用于需要集成传感器功能的开发者，提供了详细的API参考链接，帮助理解回调参数及响应类型。

### 备注_2more_3e38839d.md
本文档旨在阐述传感器开发的基本原则，并重点区分周期传感器与瞬时传感器两种数据采集模式。主要涵盖传感器开发概述、周期传感器与瞬时传感器的定义及典型示例列表，以及示例代码的获取链接。核心信息指出传感器按采集方式分为两类：按固定间隔上报数据的周期传感器（如重力、气压）和受特定事件触发的瞬时传感器（如计步、接近检测），开发流程可参考加速度传感器。面向OpenHarmony应用开发者，适用于需要集成或管理不同类型传感器功能的开发场景。

### 开发步骤.md
本文档是一份针对仓颉语言传感器开发的教程，以加速度传感器为例。主要涵盖模块导入、查询传感器列表及参数、权限配置、注册监听（on持续监听和once单次监听）以及取消监听。重点解释了采样周期范围对功耗的影响，以及周期传感器与瞬时传感器的开发差异，并展示了自定义回调类的实现。适用于鸿蒙系统下进行传感器应用开发的开发者。关键词：传感器开发、仓颉、加速度传感器、采样周期、监听注册。
