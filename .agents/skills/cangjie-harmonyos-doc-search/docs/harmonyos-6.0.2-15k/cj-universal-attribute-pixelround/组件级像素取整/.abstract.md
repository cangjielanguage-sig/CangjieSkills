This directory covers the component-level pixel rounding feature in the ArkUI framework for HarmonyOS development using the Cangjie language. It addresses visual anomalies like 1px gaps caused by sub-pixel rendering. Key topics include the `PixelRoundPolicy` class, the `pixelRound` function, and practical code examples for precise UI layout control. This resource is suitable for UI developers and engineers working on API version 19 and above who need to ensure high-fidelity rendering and alignment in their applications.
