# cj-quick-start-first-cangjie-hybrid-app

This directory serves as a comprehensive guide for building the first hybrid application using the Cangjie (CJ) programming language and ArkTS. It covers the entire development lifecycle, including project creation, directory structure analysis, configuration for real devices or emulators, and the development of both pure ArkTS pages and hybrid pages. Key topics include mixed development, DevEco Studio usage, `CJHybridComponent`, interoperability, and page routing. This resource is ideal for developers who possess basic OpenHarmony knowledge and wish to master the techniques of integrating Cangjie with ArkTS.
