This directory provides API reference documentation for the `PhotoOutput` class in the Cangjie CameraKit framework. It focuses on managing photo capture outputs within camera sessions, covering standard capture, moving photos, mirroring, and rotation. The documentation details methods for event handling, resource management, and configuration settings like video codecs. It includes error handling via `BusinessException` and Cangjie code examples. This resource is suitable for developers building multimedia applications who need to implement and control camera photo capabilities, manage application contexts, and handle lifecycle events.
