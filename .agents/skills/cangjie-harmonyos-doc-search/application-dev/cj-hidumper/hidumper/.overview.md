# hidumper

This directory serves as a central repository for documentation regarding HiDumper, a powerful command-line utility used within the OpenHarmony ecosystem. It provides extensive resources aimed at assisting developers and QA engineers in retrieving critical system information for debugging and performance analysis. The documentation covers environment setup, command syntax, and specific usage scenarios for monitoring system capabilities, network statistics, CPU load, and memory usage. Additionally, it details advanced procedures like JavaScript heap snapshots and memory leak detection. These guides are essential for professionals seeking to diagnose complex issues, optimize system performance, and ensure the stability of OpenHarmony applications and services.

## Detailed Description

The following sections provide in-depth information about the specific files and subdirectories available in this folder.

### hidumper_3more.md hidumper_3more.md
This document serves as a reference guide for HiDumper, a command-line tool designed to help developers and testers retrieve system information for debugging and problem analysis. It covers environment prerequisites, specifically the need for the hdc tool and device connection, followed by a comprehensive command-line reference table detailing various options for accessing system clusters, capabilities, and specific metrics like network, storage, CPU, memory, and IPC. Key takeaways include the ability to filter data by process ID (pid), export logs to zip files, and perform advanced memory analysis such as JS heap snapshots and leak detection. The tool supports granular control over system abilities and crash history retrieval. Targeted at developers and testers, this reference documentation requires prior knowledge of the hdc command-line environment and a connected device to execute the commands effectively.
