This directory contains API reference documentation for the HarmonyOS WLAN module, specifically designed for the Cangjie programming language. It covers comprehensive WiFi management functionalities including Station (STA) mode, Peer-to-Peer (P2P) connections, network configuration, and event handling. Key components include classes for device info and IP configuration, enums for security types and standards, and functions for scanning, connecting, and monitoring WiFi states. This documentation is suitable for software developers and system integrators building network connectivity features in HarmonyOS applications, requiring knowledge of Cangjie syntax and WiFi protocols.
