# SymbolGlyph

This directory contains documentation for the SymbolGlyph component within the ArkUI framework, specifically for the Cangjie programming language. It covers API references, type definitions for symbol effects, and component properties for styling and animation. Key topics include system-preset symbol resources, rendering strategies, and dynamic visual effects like scaling and hierarchical animations. This resource is suitable for HarmonyOS developers and UI engineers looking to implement sophisticated iconography and animations in their applications starting from API version 19.

### SymbolGlyph_4more.md SymbolGlyph_4more.md
This document provides API reference documentation for the SymbolGlyph component, designed to display icon symbols within the ArkUI framework. It details the component's creation methods, including a default constructor and an initialization method accepting an AppResource parameter. Key takeaways include the restriction that SymbolGlyph only supports system-preset symbol resources, such as sys.symbol.ohos_wifi, and that referencing non-symbol resources causes display errors. The document also clarifies that while the component supports universal attributes and events, it excludes text-specific attributes. Intended for developers using the Cangjie language, this guide helps implement system icons in applications starting from API version 19.
