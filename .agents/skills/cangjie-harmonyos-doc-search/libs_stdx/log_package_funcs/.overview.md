### log_package_funcs.md log_package_funcs.md

This document serves as API reference documentation for global logger management functions within a Cangjie logging package. It details two primary functions: `getGlobalLogger` for retrieving logger instances and `setGlobalLogger` for configuring the global logger. Key information includes that `getGlobalLogger` returns a shared instance or a copy with specific attributes, while `setGlobalLogger` initializes the global logger, noting it should be called only once per lifecycle and typically by the implementation provider. This guide targets Cangjie developers integrating logging functionality who need to understand logger initialization and retrieval.
