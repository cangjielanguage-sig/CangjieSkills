# class_ListScroller

This directory contains comprehensive API reference documentation for the `ListScroller` class, a critical controller for managing scrolling behaviors within the ArkUI framework. Designed specifically for HarmonyOS developers using the Cangjie language, these documents cover the intricacies of binding controllers to List components and manipulating list states programmatically. Key topics include retrieving item geometry, handling swipe actions, and performing coordinate-based lookups to identify visible content. The documentation also details methods for navigating to specific items within groups, including important performance considerations regarding smooth scrolling animations. This resource is essential for developers building complex, interactive list interfaces requiring precise control over navigation and layout rendering.
