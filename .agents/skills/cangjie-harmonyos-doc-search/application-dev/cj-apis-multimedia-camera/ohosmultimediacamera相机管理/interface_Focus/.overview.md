# interface_Focus

This directory contains comprehensive API reference documentation for the Cangjie Camera Kit, specifically focusing on the `interface_Focus` module. It provides essential resources for developers looking to manage and control camera focusing operations within multimedia applications. The content covers the core `Focus` interface definition, which inherits from `FocusQuery`, alongside specific functions for setting focus modes and points. Key topics include manual and auto-focus configuration, normalized coordinate systems for focus points, and coordinate transformation logic for various device orientations. Additionally, it details error handling for unconfigured sessions and system capabilities. This documentation is intended for developers with a solid understanding of Cangjie syntax and camera session management who are building advanced camera features using the Multimedia Camera Core capability.
