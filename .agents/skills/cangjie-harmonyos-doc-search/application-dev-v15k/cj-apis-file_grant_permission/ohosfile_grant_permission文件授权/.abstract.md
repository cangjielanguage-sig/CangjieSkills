This directory contains API reference documentation for the HarmonyOS `ohos.file_grant_permission` module, specifically designed for the Cangjie language. It covers the mechanisms for granting, persisting, revoking, and managing file access permissions for URIs. Key components include enums for operation modes and error codes, classes for policy management, and functions for activating or deactivating permissions. The documentation targets HarmonyOS developers implementing folder authorization features, requiring the `ohos.permission.FILE_ACCESS_PERSIST` capability. It provides essential technical details for handling file access rights securely within applications.
