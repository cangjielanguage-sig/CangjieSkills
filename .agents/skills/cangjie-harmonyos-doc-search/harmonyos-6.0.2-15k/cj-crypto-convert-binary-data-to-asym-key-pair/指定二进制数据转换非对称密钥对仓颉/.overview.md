# 指定二进制数据转换非对称密钥对仓颉

This directory provides technical documentation for converting binary data into asymmetric key pairs using the Cangjie language and the CryptoArchitectureKit. It covers specific implementations for ECC, SM2, and RSA algorithms, guiding developers on how to transform raw or encoded binary data (such as PKCS#8 or X.509) into usable `KeyPair` objects. Key topics include the use of `AsyKeyGenerator`, `DataBlob`, and the `convertKey` method. These resources are designed for developers who need to import, restore, or manage cryptographic key materials within the Cangjie ecosystem.
