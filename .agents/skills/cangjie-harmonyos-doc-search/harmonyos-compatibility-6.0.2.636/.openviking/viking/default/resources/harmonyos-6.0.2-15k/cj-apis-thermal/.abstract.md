This directory serves as a comprehensive resource for API documentation regarding the `ohos.thermal` module within the Cangjie development environment, specifically tailored for HarmonyOS developers. It provides in-depth technical details on device thermal management, enabling applications to effectively monitor real-time temperature changes and dynamically optimize system performance. The content covers essential components such as the `ThermalLevel` enum for categorizing thermal states, alongside core functions for retrieving thermal levels and managing event subscriptions. This resource is highly suitable for software engineers and system architects aiming to implement robust thermal-aware features, allowing them to intelligently adjust system resources, reduce background processing loads, and safeguard critical data based on the device's thermal severity to ensure stable operation and a superior user experience.
