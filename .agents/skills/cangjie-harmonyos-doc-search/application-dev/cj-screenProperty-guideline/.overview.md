# cj-screenProperty-guideline

This directory provides a comprehensive technical guideline for developers utilizing the Cangjie programming language within the HarmonyOS ecosystem. It focuses on the implementation of screen attribute queries and status monitoring using the Display module. The documentation covers essential techniques for retrieving screen properties such as resolution, density, and cutout information, alongside methods for listening to real-time status changes. Special emphasis is placed on adaptive UI development for diverse hardware, including foldable devices. By leveraging APIs like `getDefaultDisplaySync` and foldable status listeners, developers can create responsive applications. This material is ideal for those seeking to optimize user experiences across varying device configurations and states, ensuring applications remain functional and visually consistent regardless of the hardware form factor.
