This directory provides comprehensive documentation for the `ohos.rpc` module in the Cangjie language, designed to facilitate Inter-Process Communication (IPC) and Remote Procedure Calls (RPC) within the OpenHarmony ecosystem. It covers essential components such as data serialization via `Parcelable` and `MessageSequence`, as well as shared memory management using `Ashmem`. The resources include API references, configuration guides, and code examples. This documentation is suitable for Cangjie developers building applications that require efficient data exchange between processes, whether on the same device or across distributed systems.
