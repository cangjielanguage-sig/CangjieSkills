This directory provides comprehensive documentation for error codes within the Access Control module. It covers a range of specific exceptions, including invalid parameters, token validation failures, permission issues, and global switch configurations. The documents are structured to provide error messages, root cause analysis, and recommended handling steps. By referencing these guides, users can quickly identify whether an error requires immediate action or simply indicates a system state confirmation.
