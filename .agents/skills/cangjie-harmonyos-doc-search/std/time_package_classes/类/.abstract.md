This directory serves as a comprehensive repository for API reference documentation regarding core classes within the Cangjie programming language's time package. It provides detailed technical specifications for handling complex temporal data, focusing specifically on the `DateTimeFormat` class for parsing and generating standardized time strings, and the `TimeZone` class for managing global time zone conversions and system settings. Key topics include RFC standard formats (RFC1123, RFC3339), IANA time zone data integration, handling deprecated API members, and managing exceptions for invalid inputs. This documentation is essential for Cangjie developers who require precise control over time representation, formatting logic, and localization features in their software projects.
