This directory provides comprehensive API reference documentation for the Cangjie `StringWriter` class and its associated I/O functions. It focuses on the mechanisms for converting strings and primitive data types into encoded bytes for writing to output streams. Key topics include the class constructor, internal buffer management (flush), and extensive overloads for `write` and `writeln` methods supporting various numeric, string, and generic types. Additionally, it covers interface implementations for Resource and Seekable capabilities. This documentation is suitable for Cangjie developers working on data serialization, stream management, and output operations who require detailed syntax and parameter information.
