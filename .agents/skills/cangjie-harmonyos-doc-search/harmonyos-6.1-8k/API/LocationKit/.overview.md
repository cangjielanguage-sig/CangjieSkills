# LocationKit

LocationKit serves as the central repository for HarmonyOS geolocation services, specifically tailored for the Cangjie (仓颉) programming language. It encompasses the `ohos.geo_location_manager` module, providing essential tools for location management, geofencing, and hardware scanning. This directory is designed for developers building applications in the Cangjie environment, offering comprehensive resources ranging from API references to detailed error diagnostics. It facilitates the integration of maps and positioning features while addressing the specific needs of the Beta stage development lifecycle, ensuring engineers have the necessary stability notes and technical guidance.

## Detailed Description

### [1] README_zh
This directory contains the core index documentation for the Cangjie language Location Service (Location Kit) Beta features. This document acts as a navigation hub for developers, detailing how to access and use Location Service API interfaces and error code descriptions within the Cangjie language environment. The content primarily revolves around the `ohos.geo_location_manager` module, covering interface definitions, usage methods, and exception handling mechanisms for location management functions. As the current functionality is in the Beta stage, this document specifically emphasizes interface stability notes. This resource is primarily intended for engineers using the Cangjie language for HarmonyOS application development, aiming to help them quickly locate and understand technical details related to location services, making it an important resource for integrating maps and positioning functions.

### [2] cj-apis-geo_location_manager
This directory serves as a comprehensive repository for API reference documentation regarding the Cangjie language implementation of HarmonyOS location services. It is designed to assist developers in seamlessly integrating geolocation capabilities into their applications.

### [3] cj-errorcode-geo_location_manager
This directory specifically collects error code reference documentation for the location service module, aiming to provide developers with a complete set of diagnostic tools to quickly identify and resolve various anomalies occurring in positioning functions. The documentation content is extensive, covering not only basic issues such as unavailable location services and positioning acquisition failures but also delving into complex scenarios like regional information queries, geofencing operations, and WiFi and Bluetooth scanning startup failures. By providing detailed error information, descriptions, potential causes (e.g., weak signals, hardware limitations, or parameter configuration errors), and specific handling steps, this resource effectively assists application developers integrating location services in handling runtime errors, thereby significantly improving the application's positioning accuracy and user experience. This document is an important part of the API reference manual.
