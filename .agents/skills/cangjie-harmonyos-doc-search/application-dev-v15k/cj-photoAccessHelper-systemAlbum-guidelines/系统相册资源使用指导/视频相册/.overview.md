# 视频相册

This directory contains technical documentation designed for HarmonyOS developers using the Cangjie programming language. It focuses on the MediaLibraryKit, providing a comprehensive guide to accessing and managing the system video album. The content covers essential development steps, including obtaining the `photoAccessHelper` instance, requesting the `READ_IMAGEVIDEO` permission, and setting retrieval predicates. Developers will find step-by-step tutorials and practical Cangjie code examples that demonstrate how to fetch album objects, retrieve video assets using interfaces like `getAssets` and `getFirstObject`, and manage resources within a UIAbility context. This resource is ideal for developers looking to integrate system gallery functionalities and media library access features into their applications efficiently.
