# cj-hiappevent-watcher-freeze-events

本目录提供了关于HiAppEvent系统中应用冻屏（appfreeze）事件的详细技术文档。它主要定义了用于监控和诊断应用冻屏问题的数据结构及其属性，涵盖了从通用事件信息到具体的异常详情、线程调用栈、内存统计以及日志文件路径的全方位内容。文档深入拆解了exception、thread、frame和memory等嵌套结构，并提供了进程标识符、故障ID、消息队列及关键内存指标（RSS、PSS）的说明。此外，文档还特别强调了外部日志管理的注意事项，提醒开发者及时删除日志以防止超过5MB的存储限制。该资料主要面向需要利用HiAppEvent API进行应用性能分析和故障排查的开发人员。

## 详细说明

### cj-hiappevent-watcher-freeze-events.md cj-hiappevent-watcher-freeze-events.md
本文档定义了HiAppEvent提供的系统appfreeze事件的数据结构和属性，用于监控应用冻屏。文档详细说明了params属性，涵盖通用事件信息、异常详情、线程调用栈、内存统计及日志文件路径，并拆解了exception、thread、frame和memory等嵌套结构。关键信息包括进程标识符、故障ID、消息队列及内存指标（RSS、PSS），并特别警告需及时删除外部日志以避免超过5MB存储限制。该参考指南面向使用HiAppEvent API诊断和排查应用冻屏问题的开发者。
