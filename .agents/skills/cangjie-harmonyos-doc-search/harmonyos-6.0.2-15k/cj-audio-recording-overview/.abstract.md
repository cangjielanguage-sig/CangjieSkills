This directory provides a comprehensive development overview for selecting the appropriate audio recording APIs within the system. It covers four primary methods: AudioCapturer (Cangjie, PCM), OpenSL ES (Native, cross-platform), OHAudio (Native, low-latency), and AVRecorder (Cangjie, m4a output). The guide details development prerequisites, including necessary permissions like `ohos.permission.MICROPHONE` and foreground requirements. It is designed for media application developers using Cangjie or Native APIs who need to implement audio input functionality, helping them distinguish between raw PCM data handling and integrated file generation solutions.
