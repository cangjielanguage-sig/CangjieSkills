This directory provides comprehensive technical documentation regarding component creation rules within the LazyForEach framework mechanism, specifically designed for the Cangjie UI and ArkUI environments. It details the complete lifecycle of component generation, distinguishing between the initial first render and subsequent non-first render events. Key topics include the execution logic of the `itemGenerator` function, key generation strategies to ensure stability, and performance optimization techniques for dynamic data lists. This resource is essential for UI developers and engineers aiming to prevent caching errors, manage state synchronization, and implement efficient data-driven UI updates in complex applications.
