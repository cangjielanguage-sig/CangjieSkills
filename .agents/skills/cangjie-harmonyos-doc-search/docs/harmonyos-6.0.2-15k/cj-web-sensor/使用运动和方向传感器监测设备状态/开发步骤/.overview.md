# 开发步骤

This directory provides a comprehensive development guide focused on integrating sensor capabilities into Cangjie applications that utilize Web components. It details the end-to-end process required to enable hardware sensors, such as accelerometers and gyroscopes, within a hybrid application environment. The content covers critical backend configurations, including permission handling using `AbilityAccessCtrl` and `UIAbilityContext`, as well as frontend implementation using standard W3C Generic Sensor APIs and legacy event listeners. By bridging native HarmonyOS/OpenHarmony system services with web technologies, this guide ensures developers can effectively access and manage device motion data. It is specifically designed for application and web developers looking to enhance their mobile or hybrid applications with advanced hardware interaction features.

## Detailed Description

### 开发步骤_1.md
This document serves as a development tutorial guiding developers on implementing sensor permission handling for Web components in Cangjie applications. It covers two main steps: configuring the application-side code to request permissions and setting up the frontend to use W3C sensor interfaces. Key information includes using the onPermissionRequest interface, obtaining the UIAbilityContext, and specifically requesting accelerometer and gyroscope permissions via AbilityAccessCtrl. The guide targets application developers working with HarmonyOS/OpenHarmony who need to bridge native sensor permissions with web-based functionality.

### 开发步骤_2.md
This document provides a practical code example for accessing device motion and orientation sensors within a web application. It covers the implementation of the Generic Sensor API for Accelerometer, Gyroscope, and AbsoluteOrientationSensor, alongside legacy event listeners for DeviceMotion and DeviceOrientation. Key takeaways include setting sensor frequency, handling activation and error events, and processing sensor data like acceleration, rotation, and quaternions. Intended for web developers, this tutorial snippet serves as a reference for integrating hardware sensor capabilities into hybrid or mobile web applications.

### 开发步骤_3.md
This document serves as a code example within a web development tutorial, demonstrating how to access and manage mobile device sensors. The content includes JavaScript functions for handling device orientation events, specifically removing listeners and logging sensor data like alpha, beta, and gamma values. It also presents an HTML user interface with buttons to trigger various sensor APIs, including the accelerometer, gyroscope, and absolute orientation sensors. Key takeaways involve understanding the implementation of the DeviceOrientationEvent API for motion tracking. This material is intended for developers seeking to integrate hardware sensor capabilities into web applications.
