This directory contains comprehensive API reference documentation for the `FetchResult` class in the Cangjie language, specifically designed for the MediaLibraryKit and PhotoAccessHelper systems. It covers the complete lifecycle of file retrieval result sets, including resource management, bulk data retrieval, and precise navigation methods. Key topics include closing result sets, fetching all objects, counting files, and accessing specific assets by position or sequential order. This documentation is suitable for developers working on file management systems who need to programmatically access, iterate through, and manage photo assets using the Cangjie language and application contexts.
