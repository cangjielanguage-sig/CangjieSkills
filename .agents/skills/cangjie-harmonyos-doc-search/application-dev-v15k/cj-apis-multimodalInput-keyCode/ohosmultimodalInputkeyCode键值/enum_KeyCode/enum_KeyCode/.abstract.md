This directory contains documentation for the `KeyCode` enumeration, a critical component for handling user input in software systems. It defines standardized constants representing physical keyboard keys, media controls, and specialized hardware inputs. The content covers standard alphanumeric keys, function keys, navigation controls, and extended mappings for game controllers and system utilities. It is suitable for software developers and system engineers implementing input logic, user interfaces, or low-level device drivers. Keywords include KeyCode, enumeration, input handling, API reference, Cangjie, and hardware constants.
