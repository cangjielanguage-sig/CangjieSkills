# paradigm

This directory serves as a comprehensive educational resource for the Cangjie programming language, specifically focusing on its application within the ArkUI framework. It covers fundamental syntax, declarative UI paradigms, and advanced component architecture. Key topics include macro modifiers like `@Component`, `@State`, `@Builder`, and `@Reusable`, alongside lifecycle management and access restrictions. Designed for beginners and experienced developers alike, this collection provides the necessary guidelines to master UI construction, state management, and performance optimization in Cangjie-based application development.

## Detailed Description

### cj-basic-syntax-overview
This directory provides an overview of the basic syntax of the Cangjie language, highlighting core concepts for application development under the ArkUI framework. Content covers macro modifiers, declarative UI descriptions, custom and system components, property event methods, and @Builder extension syntax. The document explains the meaning of macros like @Component and @State through specific examples, as well as the mechanism of the build() method and chain calls. Suitable for Cangjie beginners and ArkUI developers, it aims to help quickly master the basic composition of the language and UI construction paradigms.

### cj-create-custom-components
This directory is a specialized educational resource focused on the development of custom components using the Cangjie programming language within the ArkUI framework. It provides a deep dive into the architectural standards required for building robust components.

### cj-custom-components-access-restrictions
This directory focuses on the specific usage restrictions and initialization rules for member property access qualifiers within ArkUI custom components using the Cangjie programming language. It provides comprehensive guidelines on how state management should be handled to ensure component integrity.

### cj-declarative-ui-description
This directory specifically collects core documentation on the Cangjie programming language's declarative UI description system. The documentation introduces in simple terms how to use Cangjie's features to efficiently combine and extend UI components in a declarative manner. Content covers comprehensive knowledge from basic component construction (including parameterized and non-parameterized construction) to complex property configuration (such as chain calls for setting styles), to the implementation of interaction logic (using arrow functions to configure events), and nested layout of child components (trailing closures). Additionally, it elaborates on parameter passing mechanisms, property enumeration usage, event scope management, and specific implementation methods for multi-level nested containers. This material is an essential basic tutorial for Cangjie developers developing ArkUI applications, helping developers quickly understand and master declarative UI development.

### cj-macro-builder
This directory serves as a comprehensive technical guide for the `cj-macro-builder` project, focusing specifically on the advanced implementation and optimization of the `@Builder` macro within the Cangjie UI and ArkUI frameworks. It provides a structured approach to leveraging this macro for efficient UI development.
