## Detailed Description

### ohosability_access_ctrl程序访问控制管理/
This directory hosts the API reference documentation for the `ohos.ability_access_ctrl` module, a critical component for HarmonyOS application security built using the Cangjie language. It comprehensively covers the entire spectrum of program access control management, providing developers with the necessary tools and guidelines to implement robust authentication, authorization, and permission verification systems. The documentation thoroughly details the `AtManager` class, which serves as the primary interface for handling access tokens, ensuring that applications can securely manage and verify permissions. Additionally, it includes various enumerations that define grant statuses and hardware switches, allowing for precise control over system capabilities and hardware interactions. Result classes for permission requests are also extensively documented to assist developers in managing the outcomes of security checks effectively. These resources are specifically intended for Cangjie developers, facilitating the creation of secure applications that feature reliable runtime permission checks, intuitive user consent dialogs, and effective global switch management, all operating seamlessly within the `SystemCapability.Security.AccessToken` framework.
