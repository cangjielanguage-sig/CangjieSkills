This directory contains technical documentation and code examples for implementing dynamic preview frame rate adjustment in camera applications using the Cangjie language. It covers the CameraKit framework, session configuration workflows, and specific methods for querying and setting frame rates to optimize performance and power efficiency. Key topics include `CaptureSession` management, `PreviewOutput` configuration, and constraints related to hardware capabilities. This resource is suitable for application developers working on live streaming, video recording, or camera features requiring precise performance control in the Cangjie ecosystem.
