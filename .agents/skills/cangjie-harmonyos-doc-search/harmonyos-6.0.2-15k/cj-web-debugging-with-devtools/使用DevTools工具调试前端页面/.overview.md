# 使用DevTools工具调试前端页面

This directory provides a comprehensive technical resource for debugging front-end pages within HarmonyOS Web components using DevTools. It covers the complete workflow from enabling debugging APIs and configuring permissions to establishing remote connections between a computer and mobile devices. Key topics include the `setWebDebuggingAccess` method, `hdc` tool usage, port forwarding automation scripts, and troubleshooting common connection issues. This collection is essential for front-end developers and engineers working on HarmonyOS applications who need to inspect, debug, and resolve issues in web views efficiently.

## Detailed Description

### 使用DevTools工具调试前端页面.md 使用DevTools工具调试前端页面.md
This document serves as a technical guide explaining how to enable and use DevTools for debugging front-end pages within Web components on mobile devices. It covers the integration of DevTools, the specific API method setWebDebuggingAccess, and the workflow for remote debugging from a computer to a mobile device. The primary takeaway is that developers must explicitly enable debugging access via the API and ensure the device runs version 4.1.0 or higher to utilize this functionality. This guide targets front-end developers working with Web components who need to debug mobile applications remotely.

### 便捷脚本.md 便捷脚本.md
This document provides automation scripts to simplify port forwarding configuration for debugging HarmonyOS applications using the hdc tool. It is divided into two platform-specific sections: a Windows batch script and a Linux/Mac shell script. The Windows script dynamically identifies available ports, maps them to application process IDs, and automatically opens the browser inspection page. The Linux script clears existing forwarding rules before establishing new connections for webview debugging sockets. This guide targets developers seeking to streamline the setup process for inspecting web components on HarmonyOS devices without manual configuration.

### 常见问题与解决方法.md 常见问题与解决方法.md
This document serves as a troubleshooting guide for resolving common issues encountered when using the hdc tool and DevTools for web application debugging. It addresses device discovery failures, authorization errors, missing domain sockets, port forwarding issues, and Chrome browser connection problems. Key solutions include enabling USB debugging, authorizing the computer, ensuring the Web debugging switch is on, verifying TCP port 9222 availability, and matching port configurations in Chrome. Targeted at developers debugging HarmonyOS web components, it requires basic knowledge of command-line tools and browser debugging.

### 调试步骤/
This directory serves as a comprehensive technical resource for developers working on HarmonyOS applications, specifically focusing on the critical steps required to debug web components effectively. It covers the complete lifecycle of the debugging setup, starting from the initial application code configuration where developers must enable specific interfaces like `setWebDebuggingAccess` and declare necessary permissions such as `INTERNET`. The content also extends to the physical and network connection between the development machine and the target device, utilizing command-line tools like `hdc` and browser-based tools like Chrome DevTools. By following these guides, developers can master the art of remote debugging, handle dynamic process IDs, and ensure their web views are fully accessible for inspection. This collection is essential for any developer aiming to streamline their debugging workflow and resolve issues efficiently within the HarmonyOS ecosystem.
