# cj-custom-components-access-restrictions

This directory focuses on the specific usage restrictions and initialization rules for member property access qualifiers within ArkUI custom components using the Cangjie programming language. It provides comprehensive guidelines on how state management variables—such as `@State`, `@Link`, and `@StorageLink`—interact with access modifiers like `private` and `public`. The documentation aims to clarify compilation verification logic to prevent syntax errors and ensure proper encapsulation. This resource is best suited for Cangjie developers who already possess a foundational understanding of component state management and wish to deepen their knowledge of access control and initialization constraints.

## Detailed Description

### 自定义组件成员属性访问限定符使用限制

This section provides a comprehensive guide to the constraints and initialization protocols governing member property access qualifiers within the Cangjie language's ArkUI framework. As custom components form the backbone of modern UI development, understanding the boundary between standard object-oriented access control and declarative state management is crucial.

The documentation details the specific initialization permissions required for state management variables, including `@State`, `@Link`, and `@StorageLink`. It clarifies how standard access qualifiers—such as `private` and `public`—interact with state management macros. For instance, it explains whether a state variable marked as private can be linked externally or if specific public visibility is mandated for certain decorators.

By providing detailed rule explanations and accompanying code examples, this resource helps developers navigate the compilation verification logic. It aims to prevent common syntax errors that arise from incorrect modifier usage, ensuring robust component design. This material is highly recommended for Cangjie developers who already have a foundational grasp of component state management and are looking to enforce stricter access control or debug initialization issues in their applications.
