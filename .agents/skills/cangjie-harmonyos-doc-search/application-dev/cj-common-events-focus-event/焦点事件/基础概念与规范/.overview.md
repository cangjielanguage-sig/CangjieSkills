# 基础概念与规范

This directory provides a comprehensive guide to focus management within the application framework, detailing the core principles, algorithms, and specifications required to implement robust keyboard navigation. It covers essential topics such as Focus Chains, hierarchical page handling, and Root Containers, alongside the specific algorithms—Linear and Projection—that govern focus movement between components. Additionally, it defines the standards for Active and Passive focus navigation, including API usage and system recovery mechanisms. This documentation is suitable for UI developers and system architects seeking to customize interaction logic or ensure accessibility compliance in their applications.

## Detailed Description

### 基础概念.md 基础概念.md
This document defines the fundamental concepts of focus management within the application framework, explaining how keyboard navigation and interaction work. Main topics include Focus, Focus Chains, and Focus Movement; Focus State display and activation rules; Hierarchical Pages (like Page, Dialog); and Root Containers. Key information highlights that focus moves transparently but can be tracked via events, focus states only appear when active via TAB key, and hierarchical pages preempt focus while restricting movement internally. Root containers handle default focus and passing focus to child nodes. This guide targets UI developers needing to implement or customize keyboard navigation and focus behavior in their applications.

### 走焦算法.md 走焦算法.md
This technical reference document defines the algorithms governing focus navigation within UI containers, detailing how focus moves between child components via keyboard inputs. It covers three primary strategies: Linear, Projection, and Custom focus algorithms. The Linear algorithm relies on node tree mounting order for single-direction layouts like Row and Column, ignoring visual position. The Projection algorithm determines targets based on geometric overlap and center distance, specifically for wrapped Flex components with varying sizes. Custom algorithms allow component-specific logic. Key takeaways include the distinct behaviors for TAB, Shift+TAB, and arrow keys within each strategy, particularly how Projection navigation simulates wrapping. This guide targets UI developers and system architects implementing focus management systems, requiring an understanding of component trees and layout logic.

### 走焦规范.md 走焦规范.md
This document defines the specifications and behaviors for focus navigation within the ArkUI framework. It categorizes navigation into Active Focus Navigation, driven by user inputs or developer APIs, and Passive Focus Navigation, triggered automatically by system events. Key topics include keyboard traversal logic (Z-order for TAB, cross-shaped for arrows), programmatic focus control via requestFocus and focusOnTouch, and automatic focus recovery mechanisms during component deletion or property changes. The document outlines specific algorithms for container components and constraints like cross-page limitations. This technical reference guide targets UI developers and system engineers implementing accessibility and interaction logic in ArkUI applications.
