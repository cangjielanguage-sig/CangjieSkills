# 基础类型定义

This directory provides comprehensive API reference documentation for fundamental data structures and configuration classes used within the ArkUI framework, specifically tailored for the Cangjie programming language. It covers essential type definitions required for constructing and styling user interface components, such as dividers, dropdown menus, and alignment enumerations. Key topics include the `DividerOptions` class for visual separators, the `SelectOption` class for menu items, and the `MenuAlignType` enum for layout positioning. This documentation is intended for developers and system engineers working with Cangjie who need precise control over component properties, resource handling, and system capabilities starting from version 12 or 19.

## Detailed Description

### class_DividerOptions.md class_DividerOptions.md
This document provides API reference documentation for the Cangjie class DividerOptions, designed to configure parameters for divider components in the ArkUI framework. It covers the class definition, read-only properties for stroke width, margins, and color, and the initialization constructor. Key information includes specific constraints on value ranges and units (vp or px), with default values provided for parameters like color and stroke width. Intended for developers using the Cangjie language, this guide requires knowledge of ArkUI development and system capabilities starting from version 19.

### class_SelectOption.md class_SelectOption.md
This document serves as API reference documentation for the Cangjie SelectOption class, designed to configure parameters for dropdown menu components within the ArkUI framework. The content details the class structure, focusing on two primary properties: value for option content and icon for the option image. It outlines four constructor overloads that allow these properties to be initialized using either String or AppResource types, with the icon parameter being mandatory. Key takeaways include the flexibility in resource handling and the requirement for system capability ArkUI.Full. This guide is intended for developers using Cangjie to build user interfaces, specifically those needing to implement selectable dropdown lists with localized or static resources.

### enum_MenuAlignType.md enum_MenuAlignType.md
This document serves as an API reference for the Cangjie programming language, specifically defining the MenuAlignType enumeration used to specify menu alignment configurations. The content details the enum structure and provides specific documentation for its three member values: START, CENTER, and END. Key information includes the functional description of each alignment type, where START and END respect language direction, while CENTER provides standard centering. All members share the system capability ArkUI.ArkUI.Full and are available starting from version 12. This reference is intended for UI developers working with the ArkUI framework in Cangjie who need to control menu positioning.
