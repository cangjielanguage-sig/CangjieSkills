# interface_CountableT

This directory contains API documentation for the Cangjie programming language, focusing on the `Countable` interface and specific arithmetic type extensions. It covers the definition of the `Countable` interface, which allows types to be enumerated by position, detailing methods such as `next` for retrieving instances and `position` for obtaining indices. Additionally, it documents extensions for numeric types like `Int64` and `Float64` to support multiplication with `Duration` objects, including syntax, parameters, and exception handling for overflow scenarios. This documentation is essential for Cangjie developers implementing custom countable types or performing complex time-based arithmetic operations.
