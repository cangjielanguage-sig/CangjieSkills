This directory contains comprehensive API reference documentation for image component properties within the Cangjie ArkUI framework. It covers a wide array of image manipulation and display configurations, ranging from basic placeholder settings and memory optimization to complex drag interactions and rendering modes. Key topics include image decoding strategies, SVG handling, object fitting, dynamic range adjustments, and clipboard interactions. This documentation is specifically suitable for software developers and UI engineers using the Cangjie language who are building high-performance applications and require precise control over image resources, visual effects, and user interaction behaviors.
