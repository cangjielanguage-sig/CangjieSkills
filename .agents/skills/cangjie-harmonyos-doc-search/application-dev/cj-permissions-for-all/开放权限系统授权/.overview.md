# 开放权限系统授权

This directory provides a comprehensive guide to HarmonyOS open permissions that utilize system authorization (`system_grant`). It details permissions automatically granted by the system upon installation, specifically those classified as "normal" level. Key topics include permission definitions, application methods, and the technical distinction that these permissions do not involve ACL enablement fields. The content is essential for application developers who need to identify which permissions are pre-authorized and how to declare them correctly in configuration files. By covering access to device capabilities like connectivity, sensors, and system controls, this resource ensures compliant access to system services without user interaction during runtime, streamlining the development process for standard app features.

## Detailed Description

### 开放权限系统授权_2more.md 开放权限系统授权_2more.md
This reference document lists open permissions that utilize system authorization (system_grant), available to all applications. It covers the definition of these permissions and the application method, directing users to the permission declaration guide. Key information includes that system_grant permissions are automatically granted by the system during app installation, and that permissions with a "normal" level do not involve ACL enablement fields. The document is intended for application developers seeking to understand which permissions are automatically authorized and how to properly request them.

### 权限列表/
This directory serves as a comprehensive repository for HarmonyOS system permission references, specifically focusing on API version 12. It provides detailed lists of permissions required for accessing a wide array of device capabilities, ranging from basic connectivity options like Bluetooth and Wi-Fi to advanced hardware interactions involving sensors and NFC. Additionally, it covers critical system controls such as wallpaper management and background processes, as well as specialized areas like security detection, dynamic code execution, and cloud synchronization. A key characteristic of these permissions is that they are all classified as normal level and utilize system_grant authorization. This collection is primarily designed for HarmonyOS application developers who need to accurately declare permissions in their configuration files to ensure compliant and functional access to specific device features and system services.
