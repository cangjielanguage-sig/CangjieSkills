# cj-actions-entities

本目录包含关于应用配置文件中 `actions` 和 `entities` 定义的文档。内容主要涵盖了调用方执行的通用操作（如启动入口、查看数据）以及目标组件的类别信息（如默认类别、浏览器类别）。这些属性通常需要在被调用方配置文件的 `skills` 字段中进行声明。该文档适用于需要进行应用模块配置的开发人员，特别是在使用 `startAbility` 拉起应用等开发场景中。请注意，该内容目前处于 Beta 阶段，暂不推荐使用。核心关键词包括：skills、配置文件、组件类别、通用操作。

## 详细说明

### cj-actions-entities.md cj-actions-entities.md

本文档旨在介绍应用配置文件中常见的action和entities定义及其用法，但需注意该内容处于Beta阶段且不推荐使用。文档主要分为两个部分：action部分定义了调用方执行的通用操作，如启动入口、选择资源或查看数据；entities部分描述了目标组件的类别信息，如默认类别、主屏幕入口或浏览器类别。核心要点指出这些属性需在被调用方配置文件的skills字段中声明，并详细列举了ACTION_HOME、ACTION_VIEW_DATA及ENTITY_BROWSABLE等具体常量的含义。面向需要进行应用模块配置的开发人员，适用于startAbility拉起应用等开发场景。关键词：skills、配置文件、组件类别、通用操作。
