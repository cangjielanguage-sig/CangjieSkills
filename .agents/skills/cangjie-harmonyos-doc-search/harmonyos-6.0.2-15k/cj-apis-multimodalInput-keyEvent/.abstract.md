This directory serves as a comprehensive repository for API reference documentation related to key input events in OpenHarmony applications built with the Cangjie language. It is centered on the multimodal input subsystem, offering the necessary structural definitions to interpret and manage keyboard and button interactions effectively. The documentation covers critical components such as the `Action` enum for defining states, the `Key` class for handling raw device input, and the `KeyEvent` class for high-level event modeling. This content is tailored for software developers and system engineers who need to implement precise input control, including handling key codes, timestamps, and modifier states to create responsive and intuitive user experiences. It is an essential resource for ensuring that applications can accurately process and react to user inputs in a complex multimodal environment.
