# 开发步骤

This directory serves as a specialized resource for HarmonyOS developers aiming to enhance application stability through advanced event monitoring. It details the process of subscribing to system-level application freeze events using the Cangjie language, leveraging the powerful HiAppEvent framework. The documentation covers a complete workflow, including project initialization, configuration of event watchers and filters, and the creation of trigger mechanisms using ArkTS. Additionally, it provides reference materials for interpreting the resulting logs to identify root causes of performance issues. This guide is essential for software engineers and QA professionals working within the HarmonyOS environment who need to diagnose ANRs, monitor main thread blocks, and analyze resource usage metrics to maintain high application performance standards.

## Detailed Description

### 开发步骤_1.md 开发步骤_1.md
This tutorial guides developers through implementing a subscription to system app freeze events using the Cangjie language within a HarmonyOS application. The document outlines a five-step process: setting up the Cangjie project with necessary imports, configuring the event watcher and filter, creating a trigger mechanism in ArkTS, running the application, and verifying the output logs. Key information includes using HiAppEvent, AppEventFilter, and Watcher to monitor system events, specifically capturing parameters like hilog from the event data. This guide targets HarmonyOS developers familiar with Cangjie and ArkTS who need to monitor application performance and handle system-level event callbacks.

### 开发步骤_2.md 开发步骤_2.md
This document presents an example output log of an APP_FREEZE event captured by the HiAppEvent framework, serving as a reference for debugging application stability issues. The content details event metadata, system context including bundle name and process ID, and specific exception details such as a 6-second main thread block. Key information includes resource usage statistics like memory availability, handler sizes, and references to external log files for deeper analysis. This technical log is intended for developers or QA engineers working within a HarmonyOS environment to identify root causes of application freezes through structured event parameters.
