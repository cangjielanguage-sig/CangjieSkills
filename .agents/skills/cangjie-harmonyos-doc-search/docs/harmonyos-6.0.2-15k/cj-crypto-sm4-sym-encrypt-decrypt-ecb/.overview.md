# cj-crypto-sm4-sym-encrypt-decrypt-ecb

This directory serves as a specialized technical resource for developers working with the Cangjie programming language, focusing specifically on the implementation of the SM4 symmetric encryption algorithm in ECB (Electronic Codebook) mode. It addresses the critical technical requirements for securing data through the generation of 128-bit symmetric keys and the application of PKCS7 padding to ensure block alignment. The guide explains how to effectively leverage the CryptoArchitectureKit to instantiate Cipher objects using the specific 'SM4_128|ECB|PKCS7' algorithm string, while also highlighting the unique operational characteristics of ECB mode, particularly its lack of requirement for an initialization vector. Targeted primarily at HarmonyOS developers and security professionals, this collection of documentation and code examples ensures the successful integration of high-standard cryptographic practices into modern application development workflows.

## Detailed Description

### 使用SM4对称密钥ECB模式加解密仓颉/

This directory provides a comprehensive technical guide on implementing SM4 symmetric encryption and decryption using the ECB mode within the Cangjie programming framework. It thoroughly covers the cryptographic workflow, including the generation of 128-bit symmetric keys, the instantiation of Cipher objects, and the execution of data transformation using PKCS7 padding. Key technical topics include the utilization of the CryptoArchitectureKit, the specific algorithm string 'SM4_128|ECB|PKCS7', and the operational characteristics of ECB mode, specifically its lack of requirement for initialization parameters. This resource is highly suitable for HarmonyOS developers and security engineers who are looking to integrate standardized, robust data protection mechanisms into their Cangjie applications, providing both theoretical procedural steps and practical implementation details to ensure secure data handling.
