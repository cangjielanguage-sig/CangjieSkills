The `stdregex` directory contains the core documentation and API reference for the standard regular expression library in the Cangjie programming environment. It provides comprehensive resources for text processing, including pattern matching, string manipulation, and data validation. This package covers essential components like the Regex class, MatchData, and Position, while also addressing advanced features such as lookarounds and security considerations like ReDoS prevention. It is suitable for software developers, system administrators, and engineers seeking to integrate powerful text analysis tools into their applications or needing a reliable reference for writing efficient regex patterns in Cangjie.
