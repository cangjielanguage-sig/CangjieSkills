This directory contains API reference documentation for fundamental type definitions related to symbol effects within the ArkUI framework, specifically using the Cangjie programming language. It covers various symbol effect classes—such as `AppearSymbolEffect`, `ReplaceSymbolEffect`, and `ScaleSymbolEffect`—as well as enumerations like `SymbolEffectStrategy` and `SymbolRenderingStrategy`. These definitions are essential for developers building dynamic UI animations in HarmonyOS applications, providing the necessary syntax, parameters, and configuration options to customize visual behaviors including scaling, direction, color rendering, and automatic animation strategies.
