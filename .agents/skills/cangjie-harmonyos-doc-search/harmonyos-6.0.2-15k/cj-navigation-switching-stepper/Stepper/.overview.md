# Stepper

This directory contains documentation for the Stepper component within the ArkUI framework, specifically designed for the Cangjie programming language in HarmonyOS development. It covers the component's API reference, practical implementation examples, and event handling mechanisms for multi-step task navigation. Key topics include component structure, state management, and lifecycle events like `onFinish` and `onSkip`. This resource is suitable for application developers and UI engineers looking to implement step-by-step navigation flows and manage user interactions effectively in their applications.

## Detailed Description

### Stepper_4more.md
This document provides API reference documentation for the Stepper component within the ArkUI framework, designed to display progress for multi-step tasks. It details the component's structure, specifying that it can only contain StepperItem child components. The main sections cover two constructor methods: one requiring a UInt32 index and content lambda, and another requiring only content. Key information includes full support for universal attributes and events, system capability requirements, and a minimum API version of 12. Intended for developers using the Cangjie language, this guide helps implement step-by-step navigation interfaces in application development.

### 示例代码.md
This document provides a practical code example demonstrating the implementation and usage of the Stepper component in the Cangjie programming language for HarmonyOS development. It covers the structure of the Stepper and StepperItem components, state management using @State, and dynamic status changes including Normal, Skip, Disabled, and Waiting. The code illustrates how to configure navigation labels, handle user interactions via buttons, and respond to lifecycle events such as onFinish, onSkip, and onChange. This tutorial is intended for application developers seeking to implement step-by-step navigation flows in their UI using the Cangjie framework.

### 组件事件.md
This document serves as an API reference for event handling within the Stepper component of the ArkUI framework using the Cangjie language. It details five specific event functions: onChange, onFinish, onNext, onPrevious, and onSkip. Key information includes the specific trigger conditions for each event, such as clicking navigation labels or reaching the final step, and the callback parameters that provide current and target step indices. This documentation is intended for developers implementing step-by-step navigation interfaces who need to manage state transitions and user interactions effectively.
