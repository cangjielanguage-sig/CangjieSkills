This directory provides comprehensive API reference documentation for the `ohos.eventhub` module within the Cangjie programming language, designed for the HarmonyOS AbilityKit framework. It covers the architecture for event-driven programming, including classes for managing events with zero to five parameters, callback interfaces, and the central `EventHub` system. Key topics include event emission, subscription, unsubscription, and parameter validation. This documentation is intended for HarmonyOS developers and software engineers implementing robust, type-safe communication logic in applications requiring the `SystemCapability.Ability.AbilityRuntime.Core` capability.
