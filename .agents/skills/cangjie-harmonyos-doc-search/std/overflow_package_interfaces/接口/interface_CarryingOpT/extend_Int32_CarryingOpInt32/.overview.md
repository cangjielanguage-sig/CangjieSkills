# extend_Int32_CarryingOpInt32

This directory serves as a technical reference for the `CarryingOp` interface implementation regarding the `Int32` data type in the Cangjie programming language. It encompasses a wide array of arithmetic and bitwise operations that are designed to manage integer overflow using a wrapping strategy. The content is divided into specific documentation files covering functions like `carryingAdd`, `carryingMul`, `carryingSub`, `carryingDiv`, `carryingMod`, `carryingInc`, `carryingDec`, `carryingNeg`, `carryingShl`, and `carryingShr`. A core feature of these operations is their return type: a tuple containing both the result and a Boolean flag indicating if truncation took place. This documentation is specifically curated for Cangjie developers who are engaged in low-level system programming, algorithm implementation, or any scenario where explicit overflow detection and bit manipulation are critical for application stability and correctness.
