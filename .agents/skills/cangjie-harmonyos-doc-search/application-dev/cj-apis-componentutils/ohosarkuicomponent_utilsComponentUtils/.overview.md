# ohosarkuicomponent_utilsComponentUtils

This directory contains API reference documentation for the `ohos.arkui.component_utils` module in the Cangjie programming language, specifically designed for the HarmonyOS ArkUI framework. It covers utility classes and data structures used to query and manipulate UI component geometric properties, including size, position, and transformations like translation, scaling, and rotation. Key components include `ComponentUtils` for retrieving component metrics and various result classes (`ComponentInfo`, `Offset`, `RotateResult`, etc.) that encapsulate layout data. This documentation is suitable for HarmonyOS developers using Cangjie who need to programmatically access and analyze UI component layout states and transformation matrices for advanced interface manipulation.
