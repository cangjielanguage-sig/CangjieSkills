This directory provides a specialized collection of API reference documentation tailored for the HarmonyOS Unified Data Management Framework (UDMF) using the Cangjie programming language. It is centered around the concept of standardized data channels, which are pivotal for enabling smooth and efficient cross-application data sharing within the HarmonyOS operating system environment. The documentation covers a wide array of essential components, including core classes like UnifiedData and UnifiedRecord, and specific data types such as Text, Image, and Video. By offering detailed specifications for data manipulation functions—including insert, delete, query, and update—this directory serves as a critical guide for HarmonyOS developers. It is intended for those seeking to implement sophisticated distributed data management features, ensuring that data exchange is both efficient and standardized across the application ecosystem, ultimately reducing integration friction and enhancing interoperability.
