# SensorServiceKit

SensorServiceKit is a specialized documentation and resource kit designed for sensor development within the HarmonyOS and OpenHarmony ecosystems, specifically tailored for the Cangjie programming language. It provides a centralized repository for API references, interface documentation, and system error code definitions. This kit is suitable for developers and engineers who are integrating or debugging sensor functionalities in their applications. It covers essential aspects such as sensor calling methods, hardware compatibility checks, and exception handling strategies. Currently, all features are in the Beta stage, serving as a vital reference for improving development efficiency and ensuring robust sensor integration.

## Detailed Description

### README_zh
This directory serves as the Cangjie language index documentation for the Sensor Service Kit. It is designed to provide developers with a primary entry point for API interfaces and error codes. The content primarily covers Cangjie API interface documentation and a comprehensive list of sensor error codes, noting that all features are currently in Beta versions. The documentation links to detailed descriptions of the `ohos.sensor` module, including sensor invocation methods and error code definitions. It is targeted at programmers using the Cangjie language for HarmonyOS development, particularly those needing to integrate or debug sensor functions. Through this document, developers can quickly locate sensor-related interface descriptions and exception handling solutions, thereby significantly improving development efficiency.

### cj-apis-sensor
This directory contains the complete API reference documentation for the `ohos.sensor` module, specifically designed for the Cangjie programming language. It focuses on sensor development within the HarmonyOS and OpenHarmony ecosystems, providing a standard and comprehensive reference for developers. This section is crucial for understanding the specific functions, parameters, and capabilities available when interacting with hardware sensors using Cangjie.

### cj-errorcode-sensor
This directory is specifically dedicated to storing error code definition documents for the sensor module, aiming to provide developers with a systematic guide for fault diagnosis and handling. The content focuses on specific exceptions that may occur during sensor runtime, detailing key error codes such as sensor service exceptions and unsupported device hardware. By reading this document, developers can understand the specific meaning of errors, potential causes, and recommended resolution steps, such as using timed retry mechanisms for HDI service failures or checking hardware compatibility via specific interfaces. It is primarily intended for engineers developing applications using sensor APIs; readers are advised to possess basic knowledge of HDI services and sensor interfaces to better understand and apply these error codes.
