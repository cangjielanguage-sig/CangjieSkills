This directory contains technical resources focused on runtime reflection and dynamic member manipulation within the Cangjie programming language. It provides a detailed exploration of how developers can programmatically access class structures, inspect `TypeInfo` objects, and interact with `instanceVariables` and `instanceFunctions` during execution. The material covers critical operations such as dynamically reading and modifying property values using `getValue` and `setValue`, as well as verifying function return types at runtime. Through practical examples, such as the `Rectangular` class, it demonstrates the real-world impact of dynamic modifications on method execution. This resource is specifically designed for Cangjie developers who possess a foundational understanding of the language syntax and are looking to implement advanced runtime type inspection or dynamic behavior in their software solutions.
