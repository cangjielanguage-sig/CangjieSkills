This directory provides comprehensive API reference documentation for the Cangjie Stat class and associated file type inspection utilities. It focuses on encapsulating detailed file metadata, such as access, modification, and status change timestamps, alongside file size, ownership IDs, and permission modes. The content also covers methods for programmatically identifying various file types, including block devices, character devices, directories, named pipes, sockets, and symbolic links. Designed for developers proficient in Cangjie and file I/O concepts, this guide assists in implementing robust file system operations using the CoreFileKit and FileFs.stat.
