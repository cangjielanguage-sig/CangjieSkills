# basic_programming_concepts

This directory serves as a comprehensive foundational guide to the Cangjie programming language, focusing on the essential building blocks required to write effective and robust code. It covers core concepts such as program structure, identifiers, functions, and expressions. Designed specifically for beginners and those new to the Cangjie ecosystem, the content provides a thorough overview of syntax rules, naming conventions, and architectural organization. By mastering these basics, learners will establish a solid framework for tackling advanced programming tasks. The resources included offer detailed explanations, technical specifications, and practical examples to ensure a smooth learning curve for developers.

## Detailed Description

### [1] program_structure
The `program_structure` directory serves as a vital educational resource for anyone looking to master the Cangjie programming language. It provides a thorough overview of the language's basic architecture, focusing on how programs are structured and organized.

### [2] identifier
This directory aggregates reference materials regarding the definition and usage of "identifiers," a core element in the grammar of the Cangjie programming language. It explains in detail the strict rule set to be followed when naming variables, functions, classes, etc., specifically regarding the permissibility of characters based on the Unicode 15.0.0 standard and XID_Start/XID_Continue properties. It also covers the notation for "raw identifiers" used to employ names that conflict with reserved words (keywords), and technical details regarding Normalization Form C (NFC).

### [3] function
This directory primarily introduces the definition and usage specifications of functions in the Cangjie programming language. The content covers the basic syntactic structure of functions, the application of the `func` keyword, naming rules, parameter list formats, and the declaration of return value types. Through a specific `add` function example, it analyzes in detail the syntax of separating parameters and return values with a colon. This document is suitable for beginners of the Cangjie language, aiming to help learners master the core concepts of function definition and lay a solid foundation for further in-depth study of language features.

### [4] expression
This directory serves as a comprehensive and detailed resource dedicated to the expression system within the Cangjie programming language. It is designed to guide learners through the complexities of the language, covering everything from basic expressions to more advanced topics.
