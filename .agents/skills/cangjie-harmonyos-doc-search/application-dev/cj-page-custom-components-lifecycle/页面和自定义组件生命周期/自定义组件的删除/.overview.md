# 自定义组件的删除

This directory serves as a technical resource for understanding the deletion mechanisms and lifecycle management of custom components within the ArkUI framework, specifically developed using the Cangjie language. It provides in-depth coverage of critical processes such as the `aboutToDisappear` lifecycle callback, the unregistration of state variables including @Link and @Prop, and the backend node destruction process. Additionally, it explores the complex execution order of component deletion in relation to various page navigation events, such as `router.pushUrl` and `router.replaceUrl`. This content is highly suitable for ArkUI developers and system architects who aim to optimize application performance, manage memory efficiently, and ensure robust resource cleanup during component transitions and routing operations.

## Detailed Description

### 自定义组件的删除_1.md
This technical guide explains the deletion mechanism and lifecycle behavior of custom components within the ArkUI framework using the Cangjie language. The document details the deletion process triggered by conditional rendering changes, the specific role of the aboutToDisappear lifecycle, and the unregistration of state variables like @Link and @Prop. Key information includes the backend node destruction process, frontend node garbage collection, and a strict warning against using asynchronous operations in aboutToDisappear to prevent memory leaks. A practical code example demonstrates these lifecycle transitions. This guide targets ArkUI developers using Cangjie who need to manage component lifecycle and memory efficiently.

### 自定义组件的删除_2.md
This technical guide details the lifecycle execution order of custom components, specifically focusing on component deletion and page navigation events. It covers page-level versus component-level lifecycles, initialization flows, and the specific behavior triggered by router methods, back presses, and app state changes. Key takeaways include the distinction that only @Entry components handle page lifecycles, and the specific destruction sequences for router.pushUrl versus router.replaceUrl. Targeted at developers, this guide helps in managing state and resource cleanup during component transitions.
