# 元数据仓颉

This directory serves as a specialized technical repository for developers implementing camera metadata handling using the Cangjie (仓颉) programming language. It provides a comprehensive overview of accessing and managing descriptive image data, with a specific emphasis on face detection coordinates. The included guides cover the complete development lifecycle, ranging from importing necessary interfaces and creating metadata output streams to starting and stopping sessions that listen for data callbacks. Furthermore, the documentation details critical status monitoring mechanisms and error handling strategies required for maintaining robust application behavior. These resources are specifically tailored for camera application developers who possess a foundational understanding of camera permissions and API usage, enabling them to effectively configure sessions and integrate advanced metadata processing capabilities into their software solutions.

## Detailed Description

### 元数据仓颉_2more.md 元数据仓颉_2more.md
This document is a development guide for implementing camera metadata handling using the Cangjie language. It defines metadata as descriptive image data, such as face detection coordinates, and provides a step-by-step tutorial for accessing this information. The main sections cover importing interfaces, creating metadata output streams, starting the session to listen for data callbacks, and stopping the output. Key takeaways include using CameraOutputCapability to check supported types and the metadataObjectsAvailable callback for data retrieval. Intended for camera application developers, this guide requires prerequisite knowledge of camera permissions and API usage to configure sessions and manage metadata streams effectively.

### 状态监听.md 状态监听.md
This technical guide explains how to implement status monitoring for camera applications using the Cangjie language, focusing on metadata and output stream states. The document details two primary monitoring mechanisms: registering a callback for MetadataObjectsAvailable to capture face detection data and setting up an error handler for CameraError events. Key takeaways include that current metadata support is restricted to face detection, providing rectangular region coordinates. The guide provides specific code examples for MetadataObjectsAvailableCallBack and ErrorCallBack implementations. It targets developers building camera features who need to manage real-time data reception and error handling within their applications.
