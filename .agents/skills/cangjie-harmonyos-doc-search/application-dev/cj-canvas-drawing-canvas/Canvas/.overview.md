# Canvas

This directory provides comprehensive documentation and resources for the ArkUI Canvas component, specifically tailored for the Cangjie programming language. It encompasses the core Canvas API, essential data type definitions for rendering contexts, and practical implementation examples. Key technical areas include component initialization, event handling (onReady), 2D drawing commands, gradient management, and text measurement. This collection is designed for software developers and UI engineers building HarmonyOS applications who require detailed guidance to create custom 2D graphics, manage rendering settings, and integrate visual elements programmatically.

### 基础类型定义.md 基础类型定义.md
This document provides API reference documentation for fundamental data types used in ArkUI rendering contexts within the Cangjie programming language. The content covers three primary classes: RenderingContextSettings for configuring rendering properties like antialiasing, TextMetrics for capturing text dimensions including width and height, and CanvasGradient for managing color gradients through the addColorStop method. Key information includes specific data types such as Float64 and ?Bool, system capabilities, and version requirements starting from version 22. This technical reference is designed for software developers and UI engineers working with the ArkUI framework who require precise control over canvas rendering, text measurement, and graphical styling.
