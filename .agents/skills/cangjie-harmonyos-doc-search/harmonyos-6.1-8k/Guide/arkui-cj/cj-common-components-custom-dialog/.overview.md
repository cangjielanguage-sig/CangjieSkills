# cj-common-components-custom-dialog

This directory serves as a comprehensive resource for developers working with the Cangjie programming language within the ArkUI framework, specifically focusing on the creation and management of custom dialog components. It addresses the technical requirements for building interactive user interface elements such as popups, advertisements, and system warnings. The content covers essential architectural aspects including the application of the `@CustomDialog` macro, configuration of display modes (modal and non-modal), and the intricacies of user interaction handling. While the documentation notes that certain features are currently in a Beta stage or marked as deprecated, it remains a valuable reference for understanding the structural implementation and lifecycle management of these UI components. It is best suited for Cangjie developers seeking to enhance application interactivity through custom dialog solutions.

## Detailed Description

### 基础自定义弹出框CustomDialog不推荐/

This subdirectory hosts a detailed tutorial dedicated to the implementation of basic custom popups using the Cangjie language in the ArkUI environment. Despite the feature being labeled as deprecated and currently existing in a Beta phase, the documentation offers an in-depth look at the underlying mechanics of dialog creation.

Key topics include the practical use of the `@CustomDialog` macro, which is central to defining these components. The guide walks developers through the necessary steps to configure dialogs for different behavioral modes, specifically distinguishing between modal (blocking) and non-modal (non-blocking) interactions. Furthermore, it provides instructions on styling the dialogs to fit specific application themes and handling user inputs effectively.

Advanced concepts such as the implementation of nested popups—where one dialog triggers another—and the management of the dialog lifecycle are also covered. This section is particularly relevant for Cangjie developers tasked with building complex, interactive UI components like promotional ads or critical warning alerts, providing the necessary technical groundwork to manage state and behavior effectively.
