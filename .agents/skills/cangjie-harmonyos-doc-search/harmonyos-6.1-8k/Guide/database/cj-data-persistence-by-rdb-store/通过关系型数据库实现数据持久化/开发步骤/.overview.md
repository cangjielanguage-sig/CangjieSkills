# 开发步骤

本目录包含仓颉语言中关系型数据库开发的完整指南，涵盖了从数据库初始化、数据增删改查到备份恢复及删除的全生命周期管理。文档详细介绍了RdbStore实例的获取、表结构创建、谓词查询、事务处理及错误日志记录等关键技术点。适用于需要进行本地数据持久化及维护的仓颉应用开发者，帮助其掌握数据库操作的核心流程与最佳实践。

## 快速导航

你想做什么？

*   初始化数据库并插入基础数据 → 开发步骤_1.md
*   执行数据查询、更新、删除或备份恢复 → 开发步骤_2.md
*   删除数据库文件并处理异常日志 → 开发步骤_3.md

## 详细描述

### 开发步骤_1.md 开发步骤_1.md
本文档指导开发者如何在仓颉语言中使用关系型数据库实现数据持久化，重点介绍获取RdbStore实例及插入数据的开发步骤。主要涵盖导入依赖包、配置StoreConfig、在UIAbility中创建表结构以及调用insert接口插入数据等环节。关键信息包括数据库与上下文Context的绑定关系、临时文件（-wal, -shm）的处理机制，以及使用HashMap和RelationalStoreValueType进行数据类型映射的方法。面向需要进行关系型数据库开发的仓颉应用开发者，适用于应用初始化及基础数据写入场景。

### 开发步骤_2.md 开发步骤_2.md
本文档介绍了在仓颉语言中进行关系型数据库数据操作与维护的具体开发步骤。主要涵盖使用谓词修改和删除数据、查询并遍历结果集、手动备份数据库、从备份恢复数据以及删除数据库文件。重点介绍了利用RdbPredicates构建条件执行update、delete和query操作，强调查询后需调用close释放内存，并说明了数据插入即持久化及手动备份恢复的实现方式。这是一份面向仓颉开发者的技术教程，适用于需要实现本地数据持久化、查询及维护的应用开发场景。

### 开发步骤_3.md 开发步骤_3.md
本文档演示了如何使用仓颉语言以编程方式删除关系型数据库存储，特别关注错误处理和日志记录。内容涵盖在 try-catch 块中执行 deleteRdbStore 函数、配置安全级别为 S3 的存储，以及针对成功和错误场景实现日志记录。代码重点介绍了使用 StoreConfig 指定数据库名称和安全级别，同时通过 BusinessException 处理确保通过记录错误代码和消息来提供强大的错误报告。目标受众是遵循仓颉数据库管理分步开发指南的开发人员，需要具备基本语法和关系型数据库概念的基础知识。
