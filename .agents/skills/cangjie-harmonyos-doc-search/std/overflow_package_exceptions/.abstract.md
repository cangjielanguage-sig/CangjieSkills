This directory serves as the central API reference for the `overflow_package_exceptions` module in the Cangjie programming language. It is dedicated to defining and explaining the specific exception classes required for handling errors that occur during bitwise shift operations. The content primarily focuses on two critical classes: `OvershiftException` and `UndershiftException`. It explains their structural relationship to the base `Exception` class and provides clear guidelines on the runtime conditions that necessitate throwing these exceptions, such as when a shift amount is negative or exceeds the defined bit width of the operand. Additionally, the documentation outlines the constructors available for instantiating these exceptions, allowing for both default and custom error messaging. This package is suitable for Cangjie developers, compiler engineers, and anyone involved in writing systems-level code where precise error handling and bitwise operation safety are paramount.
