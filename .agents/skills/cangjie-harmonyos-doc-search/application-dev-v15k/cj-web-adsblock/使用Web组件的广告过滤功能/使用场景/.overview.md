# 使用场景

This directory provides comprehensive usage scenarios for implementing and managing ad filtering within applications built on the ArkWeb framework using the Cangjie language. It covers the complete lifecycle of ad blocking functionality, starting with enabling the feature and applying custom easylist rules via the AdsBlockManager. Additionally, it details methods for collecting filtering statistics with performance-optimized callbacks and managing granular domain exceptions through allowlists and disallowlists. This documentation is specifically tailored for application developers who need to integrate robust, customizable ad blocking capabilities into their Web components while maintaining control over specific website behaviors.

## Detailed Description

### 开启广告过滤.md 开启广告过滤.md

This technical guide explains how to implement ad filtering in applications using the ArkWeb framework and Cangjie language. It covers API usage for setting custom easylist rules via AdsBlockManager and enabling the feature via the Web component, followed by a detailed code example demonstrating file selection and rule application. Key takeaways include understanding the replace parameter to manage conflicts between custom and built-in rules, and noting that configurations are application-level, global, and persistent. This document targets application developers seeking to integrate ad blocking capabilities into their web views.

### 收集广告过滤的信息.md 收集广告过滤的信息.md

This technical guide explains how to collect and track ad filtering statistics in a Web component using the Cangjie language. It details the implementation of the onAdsBlocked callback interface, providing a code example that demonstrates how to receive AdsBlockedDetails and update state variables. Key takeaways include the notification logic designed to minimize performance impact: the first notification triggers on page load completion, with subsequent reports throttled to one-second intervals. This document is intended for application developers utilizing ArkUI Web components who need to monitor ad blocking behavior and aggregate data.

### 关闭特定域名页面的广告过滤/

This directory provides comprehensive technical guidance on managing ad filtering behaviors for specific domains within Web components. It focuses on the mechanisms to selectively disable ad blocking for certain websites while maintaining it for others, utilizing the `AdsBlockManager`. Key technical concepts include the implementation of allowlists and disallowlists, domain suffix matching logic, and the priority hierarchy where AllowList overrides DisallowedList. The documentation includes practical code examples in both Cangjie and ArkTS, illustrating how to handle exceptions like blocking a parent domain but allowing specific subdomains. This resource is specifically designed for developers working with ArkWeb components who require granular, programmatic control over ad blocking configurations in their applications.
