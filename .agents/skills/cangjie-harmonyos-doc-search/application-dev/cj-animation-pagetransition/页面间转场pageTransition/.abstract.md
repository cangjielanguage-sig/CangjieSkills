This directory provides comprehensive documentation and resources for implementing custom page transition animations within the ArkUI framework using the Cangjie language. It covers essential APIs such as `CommonTransition`, `PageTransitionEnter`, `PageTransitionExit`, and related enumerations like `RouteType` and `SlideEffect`. The content guides developers through configuring visual effects like sliding, scaling, and opacity changes during navigation. It is suitable for ArkUI developers looking to enhance user experience with dynamic and smooth navigation effects in their applications.
