# sample_json_writeconfig

本目录主要展示了如何在仓颉编程语言中利用 `WriteConfig` 来美化 JSON 输出格式。内容涵盖了 `JsonWriter` 的构造、`WriteConfig.pretty` 配置的设置以及 `JsonSerializable` 接口的实现。通过将 `writer.writeConfig` 设置为 `WriteConfig.pretty`，开发者可以生成带有缩进和换行的易读 JSON 字符串。该文档适合需要处理 JSON 序列化并关注输出可读性的仓颉开发者。核心关键词包括仓颉、JSON序列化、WriteConfig、JsonWriter 和格式化输出。
