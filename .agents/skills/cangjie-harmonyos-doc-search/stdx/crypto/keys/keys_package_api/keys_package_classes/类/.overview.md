# 类

本目录包含 Cangjie 语言中各类加密密钥的 API 参考文档，涵盖了 ECDSA、RSA 及国密 SM2 算法的公钥与私钥操作。核心内容涉及密钥的生成、编解码（DER/PEM）、数据加解密以及数字签名与验证。这些文档为开发者提供了处理椭圆曲线、非对称加密及国密安全协议的完整接口，适用于需要在 Cangjie 应用中实现高安全性数据保护、身份认证及安全通信的开发人员。

## 详细描述

### class_ECDSAPublicKey.md class_ECDSAPublicKey.md
本文档是 Cangjie 语言中 ECDSAPublicKey 类的 API 参考文档，旨在定义 ECDSA 公钥的操作接口。主要内容包括类构造函数、静态解码方法（支持 DER 和 PEM 格式）、实例编码方法、字符串转换以及签名验证功能。关键信息指出，该类继承自 PublicKey，允许从私钥生成公钥，支持多种格式的编解码，并能验证数据摘要与签名的有效性，操作失败将抛出 CryptoException。文档面向需要处理 ECDSA 密钥及实现签名验证逻辑的开发人员。

### class_SM2PublicKey.md class_SM2PublicKey.md
本文档是 Cangjie 语言中 SM2PublicKey 类的 API 参考文档，主要定义了 SM2 公钥的生成、编解码及加解密操作。文档涵盖了从私钥初始化公钥、PEM 与 DER 格式的相互转换、数据加密以及签名验证等核心功能。关键信息包括该类继承自 PublicKey，加密输出遵循 ASN.1 规则，且所有方法在失败时均抛出 CryptoException。该文档面向需要实现国密 SM2 算法安全功能的开发者，提供了详细的参数说明和返回值定义。

### class_ECDSAPrivateKey/
本目录包含 Cangjie 语言中 ECDSAPrivateKey 类的 API 参考文档，旨在为开发者提供关于椭圆曲线数字签名算法（ECDSA）私钥的全面操作指南。内容涵盖了私钥的生成、基于指定曲线的初始化、以及 DER 和 PEM 格式的编码与解码（支持加密）。文档详细介绍了如何使用私钥进行数据摘要签名，并说明了相关的异常处理机制（CryptoException）。核心关键词包括 ECDSA、私钥管理、DER 编码、PEM 格式、数字签名及 Cangjie 加密开发。这些文档适合需要在 Cangjie 环境中进行底层加密开发的用户。

### class_RSAPrivateKey/
本目录包含 Cangjie 语言中 `RSAPrivateKey` 类的 API 参考文档，专注于 RSA 私钥的生成、管理及操作。内容涵盖了密钥的初始化构造、从 DER 和 PEM 格式解码、数据解密以及数字签名等核心功能。文档详细说明了密钥长度限制、填充模式（PKCS1、OAEP、PSS）及加密私钥支持。适用于需要在安全场景下实现 RSA 签名、解密及密钥格式转换的开发人员。

### class_RSAPublicKey/
本目录包含 Cangjie 语言中 RSAPublicKey 类及其相关验证功能的 API 参考文档。内容主要涵盖 RSA 公钥的生成、从私钥初始化、PEM 与 DER 格式的编解码转换，以及支持 PKCS1 和 OAEP 填充模式的数据加密操作。此外，还详细介绍了用于验证数字签名的 verify 函数，支持 PSS 填充模式。核心关键词包括 RSA、公钥、加密、签名验证、OAEP、PSS、CryptoException。这些文档适合需要在 Cangjie 应用中实现高安全性数据加密和签名验证的开发人员。

### class_SM2PrivateKey/
本目录包含 Cangjie 语言中 SM2PrivateKey 类的 API 参考文档，主要涵盖 SM2 私钥的生成、编解码、加密及签名功能。核心功能包括支持 DER 和 PEM 格式的转换、基于 AES-256-CBC 的密码保护机制、SM2 解密操作以及结合 SM3 算法的数字签名。该文档适用于使用国密算法进行安全通信和身份认证的开发者，提供了详细的异常处理和参数说明，帮助用户在 Cangjie 环境中高效实现 X.509 证书处理及数据加密解密。
