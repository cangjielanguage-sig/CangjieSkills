This directory provides a technical overview and implementation guide for requesting runtime user authorization for sensitive permissions in HarmonyOS applications. It is designed to help developers navigate the complexities of privacy management, detailing how to programmatically trigger authorization dialogs, verify permission status using access tokens, and handle user decisions appropriately. The content emphasizes critical constraints such as dialog visibility, request frequency limits, and the correct timing within the `onWindowStageCreate` lifecycle. It is an essential resource for application developers using the Cangjie language and AbilityKit framework who need to securely request and manage system capabilities while ensuring a smooth user experience.
