# enum_AVScreenCaptureStateCode

This directory contains API reference documentation for the `AVScreenCaptureStateCode` enum in the Cangjie programming language. It defines status codes for screen capture operations, covering lifecycle events like start, stop, cancellation, and interruptions. The documentation includes enum definitions and utility functions for comparison and string conversion. It is associated with the `SystemCapability.Multimedia.Media.AVScreenCapture` capability and is available from API version 19.
