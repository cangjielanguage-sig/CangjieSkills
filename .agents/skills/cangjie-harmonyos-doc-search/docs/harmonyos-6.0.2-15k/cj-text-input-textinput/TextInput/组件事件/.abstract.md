This directory provides comprehensive API reference documentation for component events within the ArkUI framework, specifically tailored for the Cangjie language. It focuses on the intricate event handling mechanisms required for text input components. The documentation covers a wide array of callbacks, including text content changes, scrolling behavior, clipboard operations (copy, cut, paste), and the interception of text insertion or deletion actions. Key topics include parameter definitions for tracking cursor positions, scroll offsets, and edit states, as well as specific system constraints like input method limitations. This resource is essential for developers aiming to implement robust, interactive text components with fine-grained control over user input and system interactions.
