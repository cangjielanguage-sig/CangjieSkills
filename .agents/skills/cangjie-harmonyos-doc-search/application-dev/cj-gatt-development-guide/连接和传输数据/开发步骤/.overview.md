# 开发步骤

This directory outlines the essential development steps for implementing Bluetooth functionality, specifically focusing on Bluetooth Low Energy (BLE) using the Cangjie programming language and ConnectivityKit. It covers the complete lifecycle from initial configuration, such as permission application, to importing necessary API modules. The content guides developers through both client-side operations (connection, service discovery) and server-side implementation (service creation, data exchange). Designed for Cangjie developers, these resources provide the technical foundation needed to build robust Bluetooth applications, ensuring proper security configuration and effective GATT protocol management.

## Detailed Description

### 申请蓝牙权限.md
This document serves as a specific configuration guide for enabling Bluetooth functionality by identifying the required system permission. The content focuses on the ohos.permission.ACCESS_BLUETOOTH permission constant and directs developers to external documentation for the detailed procedures of declaring permissions and requesting user authorization. Key information includes the specific permission name and references to security configuration steps. Intended for application developers, this reference material ensures users understand the necessary security prerequisites before implementing Bluetooth features. Keywords include Bluetooth, permissions, ohos.permission.ACCESS_BLUETOOTH, configuration, and user authorization.

### 导入所需API模块/
This directory provides technical tutorials and code examples for Cangjie developers implementing Bluetooth Low Energy (BLE) GATT client functionality. It covers the complete workflow of BLE operations, including module imports, connection management, service discovery, and data exchange via reading and writing characteristics and descriptors. Key topics include handling asynchronous callbacks, managing connection states, and enabling notifications or indications for real-time updates. The content is suitable for developers looking to integrate robust BLE communication into their applications using the ConnectivityKit, with a focus on error handling and specific API implementations.

### 服务端/
This directory provides a comprehensive technical guide for implementing a Bluetooth Low Energy (BLE) GATT server using the Cangjie programming language and ConnectivityKit. It covers the complete server lifecycle, including initialization, service creation, connection management, and data exchange mechanisms. Key topics include defining GATT services and characteristics, handling client read/write requests, managing descriptors, and sending notifications or indications. Additionally, it details resource cleanup and server termination procedures. These documents are suitable for developers building Bluetooth applications who need to manage server-side GATT operations, asynchronous callbacks, and client interactions effectively.
