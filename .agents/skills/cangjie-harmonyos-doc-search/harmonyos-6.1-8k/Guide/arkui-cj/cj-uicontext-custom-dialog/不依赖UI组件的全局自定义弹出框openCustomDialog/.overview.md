# 不依赖UI组件的全局自定义弹出框openCustomDialog

本目录主要介绍在HarmonyOS开发中，使用Cangjie语言通过`openCustomDialog` API实现不依赖UI组件的全局自定义弹出框。内容涵盖了如何解决传统`CustomDialogController`无法动态创建和刷新的问题，详细讲解了`CustomDialogOptions`配置、生命周期回调、ID管理以及UI解耦方案。此外，还提供了完整的代码示例，演示如何通过`UIContext`和`PromptAction`管理弹窗。适合具备ArkUI和Cangjie基础的开发者学习，旨在提供更灵活的弹窗封装与管理能力。

这份文档提供了一个完整的Cangjie语言代码示例，旨在演示如何在HarmonyOS应用中通过UIContext的PromptAction来管理自定义对话框。文档涵盖了EntryView组件的定义、使用@Builder装饰器构建对话框内容，以及在build方法中通过按钮事件触发openCustomDialog和closeCustomDialog的实现细节。关键点在于展示了如何利用bind函数绑定构建器，并使用CustomDialogOptions进行配置。该示例适合具备Cangjie基础的开发者，用于学习UI交互和弹窗控制逻辑。
