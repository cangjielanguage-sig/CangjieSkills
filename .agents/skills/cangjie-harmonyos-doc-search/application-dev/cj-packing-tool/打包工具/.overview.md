# 打包工具

This directory provides comprehensive technical documentation for the HarmonyOS application packaging tool (`app_packing_tool.jar`). It covers command-line instructions for generating HAP, HSP, and App packages, supporting various modes such as standard packaging, FastApp, and multi-project merging. Additionally, it includes guides for creating hotfixes (HQF) and normalizing version numbers across modules. These resources are essential for developers and build engineers seeking to automate deployment, manage complex module dependencies, and ensure consistency in application builds outside of the IDE environment.

### HSP打包指令_2more.md HSP打包指令_2more.md
This technical reference guide outlines command-line instructions for packaging HSP and App files using the app_packing_tool.jar utility. It details two primary modes: HSP packing for enabling file sharing across HAPs, and App packaging for market distribution. Key sections include parameter tables defining required and optional arguments, such as input paths and output destinations. The document emphasizes critical validation rules for HAP consistency, including bundleName and version matching, and specifies compression behaviors for release versus debug builds. Intended for developers, this guide facilitates the automated generation of deployment-ready software packages.

### fastApp模式打包指令.md fastApp模式打包指令.md

Key sections include HAP legality validation rules, compression logic for release versus debug modes, the command-line syntax example, and a comprehensive table defining all available parameters. Critical takeaways include strict requirements for HAP configuration consistency, unique module names, and mandatory parameters like --mode, --pack-info-path, and --out-path. Intended for developers preparing applications for release, this document assumes familiarity with HarmonyOS package structures and command-line interfaces.

### 多工程打包指令_3more.md 多工程打包指令_3more.md

Targeted at developers managing complex builds or urgent fixes, this document assumes familiarity with HarmonyOS package structures and command-line interfaces.

### 版本归一指令versionNormalize_2more.md 版本归一指令versionNormalize_2more.md

It details two primary commands: versionNormalize for synchronizing version codes and names across multiple HAP and HSP files, and packageNormalize for modifying bundle names and versions specifically for HSP files. The document targets developers and build engineers seeking to maintain consistency across application modules during the packaging and update process.
