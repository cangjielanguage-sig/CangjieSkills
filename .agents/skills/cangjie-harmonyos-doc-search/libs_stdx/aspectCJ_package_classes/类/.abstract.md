This directory serves as a comprehensive API reference for classes specifically designed to facilitate Aspect-Oriented Programming (AOP) within the Cangjie language ecosystem. It focuses on the core mechanisms of method weaving, enabling developers to inject behavior into existing code structures dynamically. The documentation covers essential classes for intercepting method execution at entry or exit points, as well as completely replacing method implementations. Key concepts include constructor parameters, recursion handling for inheritance hierarchies, and function type string specifications. These resources are tailored for software engineers and developers utilizing the aspectCJ package who require precise technical details to implement cross-cutting concerns, logging, or runtime behavior modification efficiently.
