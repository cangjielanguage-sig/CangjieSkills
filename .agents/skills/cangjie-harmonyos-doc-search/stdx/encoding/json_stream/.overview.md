# json_stream

This directory serves as a comprehensive resource for the `json.stream` package within the Cangjie programming language ecosystem. It focuses on the serialization and deserialization of Cangjie objects to and from JSON data streams, providing essential tools for efficient data handling. The content covers core components such as `JsonWriter` and `JsonReader`, supports a wide range of data types including collections and custom interfaces, and offers practical code examples. This documentation is suitable for Cangjie developers seeking to implement robust JSON processing in their applications.

## Detailed Description

### json_stream_package_api

The `json_stream_package_api` directory serves as the central documentation hub for the `json.stream` package within the Cangjie programming language ecosystem. It provides comprehensive resources covering the fundamental components required for JSON stream processing. This section is essential for developers who need detailed technical specifications and API definitions to integrate JSON capabilities into their Cangjie projects effectively.

### json_stream_package_overview

This directory provides a detailed overview of the `stdx.encoding.json.stream` package, designed to help developers master the serialization and deserialization techniques between Cangjie objects and JSON data streams. The documentation covers the functional introduction of core APIs, focusing on the usage of `JsonWriter` and `JsonReader`. Additionally, it details the range of supported data types, including basic types, collection types (such as Array, HashMap), special types (such as Option, BigInt), and the `JsonSerializable` interface for customized processing.

### json_stream_samples

This directory contains a comprehensive collection of code samples demonstrating JSON stream processing within the Cangjie programming language. It covers the full lifecycle of JSON handling, including reading (deserialization), writing (serialization), and various practical scenarios. These samples serve as a practical guide for developers to understand how to apply the theoretical concepts and API references in real-world coding situations.
