This directory provides a comprehensive introduction to HiAppEvent, a sophisticated system-level event tracking mechanism designed to empower developers with the ability to meticulously record application faults, statistics, and user behavior. The documentation covers the essential basic concepts regarding tracking and provides detailed specifications for event design, including clear definitions for event domains, names, and parameters. Central to this guide is the explanation of the four supported event types: behavior, fault, statistic, and security. These types are instrumental in facilitating the in-depth analysis of application performance and the understanding of user habits. This resource is specifically tailored for application developers and analysts, offering the necessary standards and guidelines for implementing logging systems that support robust business analysis and operational monitoring. By following these specifications, users can ensure their data collection is standardized and effective for downstream processing.
