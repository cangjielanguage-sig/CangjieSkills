# 状态管理概述

This directory provides a comprehensive overview of state management mechanisms within declarative UI frameworks, specifically focusing on the Cangjie framework and State Management V1. It details the synchronization between data state and UI rendering, covering essential concepts such as state variables, decorators, and data flow patterns. Key topics include component-level management using decorators like @State and @Link, as well as application-level solutions like AppStorage. The content also distinguishes between unidirectional and bidirectional data transmission and explains the constraints of the main UI thread. This resource is suitable for developers seeking to understand reactive programming principles, implement robust data synchronization, and manage complex state hierarchies efficiently in their applications.

## Detailed Description

### 状态管理V1.md 状态管理V1.md
This document serves as an overview guide for State Management V1, detailing how developers use decorators to manage data flow and UI synchronization. It categorizes decorators into component-level management (@State, @Prop, @Link, @Provide/@Consume, @Observed/@Publish) and application-level management (AppStorage, LocalStorage). Key takeaways include the distinction between unidirectional and bidirectional data transmission, the specific use cases for nested object observation, and the role of AppStorage as a global state hub. Additionally, it mentions the @Watch decorator for monitoring changes. This reference guide targets developers building applications that require reactive state updates across different component hierarchies and global scopes.

### 状态管理概述_2more.md 状态管理概述_2more.md
This document provides an overview of state management mechanisms within the Cangjie declarative UI framework, explaining how state changes drive UI rendering. It covers the relationship between State and View, basic concepts including state variables, regular variables, and data sources, and initialization methods like parent-to-child parameter passing. Key takeaways include that only variables decorated with state decorators trigger UI updates, and state management is restricted to the main UI thread. Intended for developers familiar with basic UI paradigms and declarative syntax, this guide serves as a foundational resource for building dynamic interfaces.
