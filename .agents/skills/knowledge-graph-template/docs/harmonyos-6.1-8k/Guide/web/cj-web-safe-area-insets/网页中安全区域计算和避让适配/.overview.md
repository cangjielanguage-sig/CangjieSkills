## 详细说明

### 实现场景.md 实现场景
本文档是一份技术指南，旨在指导开发者实现Web组件的沉浸式效果及安全区域适配。文档主要涵盖三个核心部分：通过Cangjie代码使用expandSafeArea属性开启沉浸式、设置HTML meta标签viewport-fit=cover以允许网页覆盖全屏，以及利用CSS env()函数和safe-area-inset-*变量对网页元素进行避让处理。关键信息指出env()必须配合viewport-fit=cover使用，并支持与calc()等函数组合计算。该文档面向需要处理全屏Web布局及系统UI避让的开发者，提供了具体的代码实现与CSS适配方案。
