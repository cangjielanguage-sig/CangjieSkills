# cj-send-file-to-app-sandbox

本目录包含一份专门针对 HarmonyOS 开发者的技术指南，核心内容是讲解如何利用 hdc 工具向应用沙箱环境推送文件，从而辅助开发与调试工作。由于 HarmonyOS 应用运行在严格的沙箱隔离机制中，直接操作物理路径往往受限，因此理解路径映射至关重要。本文档详细介绍了应用沙箱路径与真实物理路径之间的对应关系，并提供了具体的命令行操作示例，涵盖使用 hdc 进行文件传输以及通过 chown 命令调整文件归属权限。此外，文档还深入探讨了如何使用 nsenter 命令进入应用沙箱的命名空间，帮助开发者从沙箱内部视角直观地排查文件目录及权限问题。该指南非常适合需要频繁进行文件注入、数据模拟或调试文件访问权限的 HarmonyOS 应用开发者。
