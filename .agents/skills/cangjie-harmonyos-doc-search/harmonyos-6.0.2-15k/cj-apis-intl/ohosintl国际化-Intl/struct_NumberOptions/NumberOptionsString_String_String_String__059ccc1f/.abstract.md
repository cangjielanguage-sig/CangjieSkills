This directory contains technical documentation for the `NumberOptions` class within the Cangjie programming language's LocalizationKit. It focuses on configuring number formatting for internationalization (I18n), covering aspects such as currency display, unit specifications, and precision control. The resources include API references, parameter definitions, and practical code examples. Suitable for developers working on localized applications, these documents explain how to customize numeric data presentation across different regions using specific locales like 'zh-CN' and 'en-GB'.
