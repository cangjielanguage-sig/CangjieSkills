## 详细描述

### definePermissions标签.md definePermissions标签.md
本文档详细说明了用于在系统资源HAP中定义权限的definePermissions标签的配置规范。主要内容包括标签的使用范围（仅限系统资源）、属性说明表（涵盖名称、授予模式、限制级别等七个属性）以及JSON配置示例。核心要点包括权限授予模式（自动授予或用户动态授权）、权限级别（核心、基础或普通）以及是否支持证书申请和分布式场景。文档明确指出该标签不支持应用自定义权限。这是一份面向系统开发者的参考文档，适用于配置OpenHarmony系统资源权限定义。

### deviceTypes标签_2more_c01d406e.md deviceTypes标签_2more_c01d406e.md
本文档旨在说明OpenHarmony应用开发中deviceTypes标签和pages标签的配置规范与用途。主要涵盖deviceTypes支持的设备类型枚举（如平板、PC/2in1），以及pages标签引用的页面路由配置文件结构，包含src路径列表和window窗口属性。关键信息包括module.json中的设备类型配置示例，main_pages.json中src数组定义页面路由，以及window对象中designWidth和autoDesignWidth对页面设计基准宽度的控制。面向OpenHarmony应用开发者，适用于应用模块配置和页面路由规划场景。

### fileContextMenu标签.md fileContextMenu标签.md
这份文档是HarmonyOS应用开发的技术参考，旨在指导开发者通过fileContextMenu标签为PC/2in1设备配置文件管理器的右键菜单。文档详细说明了在module.json5和profile资源文件中的配置方法，解析了fileContextMenu和menuContext对象的属性定义，如abilityName、menuKind及文件类型过滤规则。此外，还阐述了菜单触发后的响应机制及传递的want参数。该文档面向需要实现文件交互扩展功能的HarmonyOS开发者，提供了完整的配置规范和行为说明。

### hnpPackages标签_76076e09.md hnpPackages标签_76076e09.md
本文档旨在定义hnpPackages标签的用途及配置规范，用于标识应用包含的Native软件包信息。文档详细列出了该标签的属性说明表，并提供了JSON格式的配置示例。核心内容包括两个不可缺省的属性：package（标识软件包名称）和type（标识软件包类型，支持public公有或private私有）。这是一份技术参考文档，主要面向应用开发人员，用于指导模块配置文件的编写。关键词：hnpPackages, Native软件包, 配置标签, 属性说明, JSON配置, 应用开发。

### metadata标签.md metadata标签.md
本文档详细说明了HAP配置文件中metadata标签的定义、属性及其使用场景。主要内容包括标签属性说明表（涵盖name、value、resource三个子标签）、两种具体应用场景（配置主窗口大小位置及移除启动页）以及完整的JSON配置示例。关键信息指出metadata为数组类型，子标签均为字符串且可缺省。文档重点介绍了通过特定name值（如ohos.ability.window.height）控制窗口属性，以及通过enable.remove.starting.window控制启动页显示。该文档面向HarmonyOS应用开发者，适用于需要自定义模块或Ability元数据、配置窗口行为的应用开发场景。

### modulejson5配置文件_2more_c5b2fe7a.md modulejson5配置文件_2more_c5b2fe7a.md
本文档旨在通过一个完整的示例展示module.json5配置文件的结构与用法。文档涵盖了模块的基本属性、安装配置、Ability组件定义、权限申请以及元数据和HNP包等高级配置。关键信息在于展示了如何通过JSON5格式详细定义模块的入口点、UI资源、运行时权限及环境变量。作为一份处于Beta阶段的参考文档，它主要面向HarmonyOS/OpenHarmony应用开发者，用于指导HAP模块的配置。

### shortcuts标签.md shortcuts标签.md
本文档旨在说明HarmonyOS应用中shortcuts标签的配置方法，用于定义应用的快捷方式信息。主要涵盖shortcuts标签的属性定义（如shortcutId、label、icon、wants）、wants子标签的详细说明，以及如何在module.json5中通过metadata关联配置文件。关键信息包括shortcutId不支持资源索引、wants用于指定目标组件及参数，以及必须通过两步配置（JSON文件与module.json5引用）使快捷方式生效。这是一份面向HarmonyOS应用开发者的技术参考文档，适用于需要实现应用快捷启动功能的场景。

### skills标签.md skills标签.md
本文档是HarmonyOS应用开发的配置参考，详细说明了skills标签的用途及属性配置，用于定义UIAbility或ExtensionAbility组件接收隐式Want的能力。文档主要涵盖skills标签的五大属性（actions、entities、uris、permissions、domainVerify）以及uris子标签的详细参数（如scheme、host、path、type等）。关键信息包括：建议单个skill仅配置一个action或entity，API 18起scheme和host匹配不区分大小写，以及路径匹配的三种模式。文档附带JSON配置示例，旨在帮助开发者正确配置组件的过滤规则，适用于处理隐式调用和数据分享等场景的开发人员。

### startWindow标签.md startWindow标签.md
这份文档是关于startWindow标签的配置参考，旨在指导开发者如何通过profile文件配置UIAbility组件的启动页面。文档详细列出了startWindow标签下的六个属性，包括应用图标、插画、品牌标识、背景颜色、背景图片及其适应方式，并提供了JSON配置示例。关键信息指出该标签自API 18起支持，且配置后将覆盖原有的startWindowIcon和startWindowBackground字段。主要面向HarmonyOS应用开发者，用于定制应用启动时的视觉体验。

### testRunner标签_4more_05e2e176.md testRunner标签_4more_05e2e176.md
本文档详细说明了模块配置中testRunner、dependencies、proxyData和appEnvironments标签的属性定义与用法。内容涵盖测试框架配置、运行时共享库依赖声明、数据代理列表配置及环境变量设置。关键点包括各标签的必填属性、数据代理的URI格式规范、读写权限限制及环境变量长度限制。作为配置参考手册，本文档面向应用开发人员，指导其正确配置模块的测试、依赖、数据共享及环境参数。
