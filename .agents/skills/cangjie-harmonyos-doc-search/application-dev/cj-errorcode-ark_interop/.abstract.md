This directory functions as a specialized technical repository for the ArkTS Interop library, specifically tailored for developers integrating the Cangjie language with ArkTS. It provides a structured reference guide that addresses eight distinct error codes arising during cross-language operations. The scope of this documentation covers critical runtime issues such as illegal indices, unhandled runtime exceptions, violations of object lifecycle protocols, thread validation errors, type mismatches, and failures in module imports. By offering in-depth analyses of potential causes and precise resolution steps—including API usage verification like `JSContext.isBindThread()`—this resource is essential for developers who need to effectively debug interoperability issues and ensure the robustness of their applications.
