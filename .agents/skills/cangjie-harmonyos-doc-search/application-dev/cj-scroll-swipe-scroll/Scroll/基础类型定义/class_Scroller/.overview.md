# class_Scroller

This directory contains API documentation for the `Scroller` class within the ArkUI framework, implemented using the Cangjie language. It covers the controller interface for scrollable container components, detailing methods for programmatic scrolling, state management, and animation control. Key topics include basic scrolling operations (scrollTo, scrollBy), edge navigation, inertial fling, index-based navigation, and state queries like current offset and item positioning. This documentation is intended for software developers building UI applications who need to implement or manipulate complex scrolling behaviors in their interfaces.

## Detailed Description

### class_Scroller_8more.md
This API reference document details the Scroller class, which serves as a controller for scrollable container components within the ArkUI framework using the Cangjie language. The documentation covers the class constructor and several functional methods including scrollTo, scrollBy, and scrollEdge. Key functions allow scrolling to specific coordinates with or without animation options, scrolling by relative offsets, and moving to container edges. Methods support overloads for different animation configurations like ScrollAnimationOptions or boolean flags. This technical reference is intended for software developers building UI applications who need to implement or control scrolling behavior programmatically. Keywords: Scroller, ArkUI, Cangjie, scrollTo, scrollBy, scrollEdge, API reference, UI components.
