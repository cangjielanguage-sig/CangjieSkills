This directory contains comprehensive documentation for the `WebNetErrorList` enumeration within the Cangjie programming language. It defines a standardized set of error codes for handling web networking operations, covering a vast spectrum of issues including SSL/TLS handshakes, HTTP/2 and QUIC protocol failures, DNS resolution problems, and caching mechanisms. The documentation is essential for software developers and system engineers who need to debug network connectivity issues or implement robust error handling in webview and network applications. All entries are introduced starting from version 19.
