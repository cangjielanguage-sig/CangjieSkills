# cj-acm-tool

This directory serves as a comprehensive repository for the `cj-acm-tool`, specifically focusing on the ACM (Account Management Tool) documentation. It provides a detailed guide for managing the lifecycle and permission constraints of local accounts via a command-line interface. The content covers critical operations such as account creation, deletion, querying, switching, and logout, alongside the configuration of constraint conditions. Core functionalities are executed using the `acm` command set within an `hdc shell` environment, with most administrative tasks requiring root privileges. This resource is tailored for developers and system administrators who need to debug account features or configure system permissions. It offers detailed parameter explanations and practical usage examples to facilitate efficient system management and security configuration, ensuring that users can handle complex account scenarios with ease.

## Detailed Description

### acm工具/

This subdirectory contains the essential reference documentation for the ACM (Account Management Tool). It is designed to assist users in managing the full lifecycle and permission constraints of local accounts directly through a command-line interface. The documentation provides in-depth instructions on a wide array of operations, including the creation, deletion, querying, switching, and logout of accounts. Furthermore, it guides users through the process of setting specific constraint conditions to control account behavior and access levels.

The core workflow involves accessing the target environment using `hdc shell` and executing the `acm` command set to perform these tasks. Given the nature of the operations—which often involve system-level changes—most commands require root privileges to execute successfully. This documentation is particularly suitable for developers and system administrators who are responsible for debugging account functions or configuring system-level permissions. It includes complete parameter descriptions and illustrative usage examples to ensure users can effectively utilize the tool for their specific needs. By following this guide, technical personnel can ensure robust account management and maintain strict system security protocols.
