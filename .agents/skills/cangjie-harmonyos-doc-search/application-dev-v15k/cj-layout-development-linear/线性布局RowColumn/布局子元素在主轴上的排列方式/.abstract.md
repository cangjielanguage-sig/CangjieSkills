This directory serves as a comprehensive resource for configuring the alignment of child elements along the main axis in layout containers. It covers the `justifyContent` property, detailing how to control space distribution and element positioning using various alignment strategies. The content is designed for developers and UI designers working with frameworks like Cangjie UI and HarmonyOS, providing both theoretical explanations and practical code examples. Whether you need to arrange items vertically or horizontally, this guide helps achieve precise, responsive layouts.
