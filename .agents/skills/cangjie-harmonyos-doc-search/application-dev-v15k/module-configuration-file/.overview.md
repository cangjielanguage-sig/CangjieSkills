# module-configuration-file

This directory serves as a comprehensive technical resource for configuring HarmonyOS Ability Packages (HAP), with a primary focus on the `module.json5` configuration file. It provides detailed documentation covering essential development aspects such as module properties, permissions, device compatibility, UI components, and runtime behaviors. The content addresses critical areas including ability definitions, extension capabilities, metadata handling, and distribution filtering. These resources are specifically designed for application developers, system integrators, and software engineers who need to structure application manifests effectively, manage application lifecycles, and implement complex features like shortcuts, context menus, and native package integration within the HarmonyOS and OpenHarmony ecosystems. By utilizing these documents, developers can ensure their applications are correctly configured for optimal performance and compatibility across various devices.

### module-configuration-file.md module-configuration-file.md
This reference document details the configuration of the metadata tag within the module.json5 file for HarmonyOS Ability Packages (HAP). It explains the tag's structure, providing a detailed table of its sub-attributes: name, value, and resource. Key information includes the specific syntax for the resource attribute, which uses $profile:filename to reference files in the /resources/base/profile directory. The document also provides a JSON5 example demonstrating how to implement metadata within modules, abilities, and extensionAbilities. This guide is intended for developers seeking to define custom metadata and resource references during application configuration.
