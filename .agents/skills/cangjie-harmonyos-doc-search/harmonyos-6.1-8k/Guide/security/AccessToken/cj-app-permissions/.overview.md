# cj-app-permissions

本目录汇集了关于应用权限管理的核心文档，旨在为开发者提供一套完整的权限申请与授权参考指南。文档内容深入剖析了四大核心权限类别：开放权限（包括系统自动授权与用户动态授权）、企业类应用权限以及MDM应用专用权限。重点阐述了不同分发类型（如 enterprise_normal、enterprise_mdm）下应用所适用的权限集合及其特定的授权机制。该资源主要面向应用开发者，旨在帮助其快速检索权限信息，并制定正确的权限申请策略，以确保应用功能的合规实现。

## Detailed Description

### cj-app-permissions.md
本文档作为应用权限的索引参考，旨在指导开发者根据权限的开放范围及授权方式选择正确的申请途径。文档涵盖了四大核心类别：开放权限（系统自动授权）、开放权限（用户动态授权）、企业类应用权限及MDM应用专用权限。关键要点在于明确区分了不同分发类型（如enterprise_normal、enterprise_mdm）的应用所适用的权限集合及授权机制。本文档主要面向应用开发者，用于快速检索并确定特定权限的申请策略。
