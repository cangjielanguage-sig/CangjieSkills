# 配置文件标签

本目录包含关于应用配置文件标签的详细说明文档，重点聚焦于 `module.json5` 文件的结构与定义。内容涵盖了配置标签的用途、属性含义、数据类型及约束条件，包括模块基础标识、进程管理、依赖库及权限声明等核心配置项。这些文档属于参考手册类型，旨在帮助开发人员正确编写和优化模块配置。适合具备基础配置知识的 HarmonyOS/OpenHarmony 应用开发者查阅。

## 详细描述

### 配置文件标签_1.md
本文档旨在详细说明module.json5配置文件中包含的各类标签及其定义。主要内容通过表格形式（表1）列出了配置文件标签的详细说明，涵盖了标签的具体用途和结构。关键信息在于提供了完整的配置项参考，帮助用户理解如何正确使用这些标签进行模块配置。该文档属于参考手册类型，主要面向需要编写或修改module.json5配置文件的开发人员，要求具备基础的配置文件读写知识。

### 配置文件标签_2.md
本文档详细定义了应用配置文件中Module标签的各类属性及其含义。涵盖模块基础标识、入口配置、进程管理、部署设置、功能组件、依赖库及权限声明等核心配置项。重点说明了模块类型（如entry、har）、安装与免安装特性、多进程隔离模式及Native库处理方式，并明确了各属性的数据类型、缺省值及约束条件。属于参考类文档，面向HarmonyOS/OpenHarmony应用开发者，用于指导模块级配置文件的编写与优化。
