# 应用程序包常见问题

This directory serves as a comprehensive technical resource for addressing common queries and troubleshooting issues related to HarmonyOS application packages. It primarily focuses on the mechanisms for retrieving essential application metadata, specifically the `appIdentifier` and signature fingerprint information. The documentation covers a diverse range of techniques, including programmatic retrieval using the Cangjie API (via `BundleManager`), command-line operations using the `bm` tool, and certificate analysis using standard utilities like `keytool`. Furthermore, it clarifies the critical distinction between auto-signing and manual signing configurations and their impact on application identity stability. This content is specifically designed for HarmonyOS developers, QA engineers, and technical support personnel involved in application debugging, signature verification, and cross-device ecosystem integration.

## Detailed Description

### 如何获取应用信息中appIdentifier.md
This technical guide explains how to retrieve the appIdentifier from application information using two distinct methods. The document covers programmatic retrieval via the Cangjie API and command-line retrieval using the bm tool. Key takeaways include using BundleManager.getBundleInfoForSelf with specific flags to access signatureInfo, or executing bm dump -n combined with grep in a shell environment. Intended for HarmonyOS developers, this guide requires knowledge of Cangjie coding and basic shell commands for debugging or verification.

### 如何获取签名信息中的指纹信息_2more.md
This technical guide explains methods to retrieve application fingerprint information and defines the concept of appIdentifier within the HarmonyOS development context. It details four retrieval methods: using the bundleManager.getBundleInfoForSelf API with Cangjie code, the bm command-line tool, extracting from .cer files, and using keytool. Additionally, it clarifies that appIdentifier is a unique identifier in the Profile file. The document distinguishes between auto-signing, which generates a random appIdentifier, and manual signing via AppGallery Connect, which provides a stable appIdentifier derived from the APP ID. It recommends manual signing for scenarios requiring consistent identifiers like cross-device debugging. This guide targets HarmonyOS developers needing to verify signatures or manage application identity.
