This directory serves as a comprehensive technical guide for developers and QA engineers using the HiDumper tool to retrieve system information and debug applications in the HarmonyOS/OpenHarmony ecosystem. It covers environment setup, command-line options, and performance monitoring (CPU, memory, network). A key focus is the specific support for Cangjie (仓颉) applications, including heap snapshots and garbage collection. Additionally, it details ArkUI debugging techniques for window hierarchies and component trees. This resource is essential for system diagnostics, performance profiling, and troubleshooting UI logic.
