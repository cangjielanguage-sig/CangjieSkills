# Router切换Navigation

This directory provides comprehensive technical guides for migrating from the legacy Router component to the modern Navigation component in HarmonyOS applications using the Cangjie ArkUI framework. It covers architectural differences, lifecycle management, routing operations, and advanced features like cross-package navigation and shared element transitions. Key topics include NavPathStack management, imperative vs. declarative routing, and stack-based page handling. These resources are designed for Cangjie developers seeking to modernize their app navigation logic, improve animation performance, and implement flexible, cross-platform UI structures.

## Detailed Description

### Router切换Navigation_2more.md Router切换Navigation_2more.md
This guide assists developers in migrating from Router to Navigation in HarmonyOS, highlighting Navigation's superior animations and cross-platform capabilities. It focuses on structural differences, contrasting Router's @Entry components with Navigation's split architecture of Navigation containers and NavDestination subpages. Key takeaways include the shift from imperative Router calls to stack-based management using NavPathStack and @Builder mapping. The document provides Cangjie code examples demonstrating page transitions and stack operations. It targets developers seeking to modernize their navigation logic for better flexibility and multi-end deployment.

### 生命周期_5more.md 生命周期_5more.md
This technical guide details lifecycle management and routing capabilities for Router and Navigation components within the Cangjie ArkUI framework. It covers lifecycle callbacks, transition animations, shared element transitions, cross-package routing, and route interception mechanisms. Key information includes a comparison of Router methods like aboutToAppear versus Navigation's NavDestination events, implementation of custom transitions using pageTransition and geometryTransition, and code examples for cross-package navigation via NavPathStack. The document serves as a reference for developers managing page states and navigation flows, highlighting that Navigation offers more advanced features like native cross-package support, whereas Router requires custom encapsulation for interception.

### 路由操作.md 路由操作.md
This technical guide explains routing mechanisms in Cangjie applications, comparing global Router operations with Navigation component management. It covers global Router methods, Navigation's NavPathStack usage, and strategies for accessing the stack in child pages. Key information includes APIs for page navigation (push, pop, replace, clear) and stack management (size, parameters). It highlights three methods to pass NavPathStack to children: @Provide/@Consume, onReady callbacks, and AppStorage, noting coupling concerns. Targeted at Cangjie developers building UIs with the Navigation component, this document serves as a reference for implementing flexible page navigation.
