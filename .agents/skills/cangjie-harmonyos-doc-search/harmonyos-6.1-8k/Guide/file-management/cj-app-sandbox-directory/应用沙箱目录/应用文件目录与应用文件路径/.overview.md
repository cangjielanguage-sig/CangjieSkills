# 应用文件目录与应用文件路径

本目录包含关于 OpenHarmony 应用文件目录结构、路径获取及数据存储规范的文档。内容涵盖应用沙箱机制、五种加密级别（EL1-EL5）的安全特性，以及安装包、数据库、缓存、分布式文件等八种具体路径的用途与生命周期管理。文档重点介绍了如何通过 Context API 安全获取路径，避免硬编码，并区分了应用级与 HAP 级目录。适合需要管理持久化数据、实现跨设备协同或优化存储安全的 OpenHarmony 应用开发者参考。

## 详细描述

### 应用文件目录与应用文件路径_1.md

本文档定义了OpenHarmony应用沙箱内应用文件目录的结构及路径获取方法。文档详细介绍了目录层级结构，重点阐述了五种加密级别（EL1-EL5）的安全特性及适用场景，并区分了通过ApplicationContext和AbilityContext获取的应用级与HAP级目录。核心要点包括禁止硬编码路径、推荐使用Context API获取路径，以及EL2作为默认加密方式、EL1用于开机前访问等安全策略。该指南面向需要管理持久化数据存储和文件安全的OpenHarmony开发者。

### 应用文件目录与应用文件路径_2.md

本文档详细定义了应用各类文件目录的Context属性、类型及用途，阐明了数据存储规范与生命周期。主要涵盖安装包、基础持久化、数据库、分布式文件、通用文件、缓存、首选项及临时目录等八种路径。关键信息包括各目录随应用卸载清理的特性，缓存与临时文件可被系统自动回收，以及分布式文件支持跨设备访问。文档强调了资源访问需使用特定接口，并区分了持久化与临时数据的存储场景。该参考手册面向应用开发人员，旨在指导其正确选择存储路径以实现数据持久化、缓存管理及多设备协同。
