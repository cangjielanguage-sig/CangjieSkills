This directory acts as a centralized technical hub for the `hitrace` command-line utility, which is indispensable for performing deep performance analysis within the HarmonyOS and OpenHarmony operating environments. It offers extensive reference documentation aimed at helping users proficiently capture, manage, and export system trace data through the command line interface. The guides thoroughly explain essential procedures such as enumerating trace tags, controlling recording sessions, and fine-tuning capture parameters like buffer size and time limits. Beyond basic tracing, the content delves into sophisticated functionalities including snapshot mode for background tasks, output compression, and clock synchronization settings. This collection is ideally suited for system developers, QA engineers, and performance specialists who need granular diagnostic capabilities to monitor system health and enhance application efficiency.
