## Web组件网页加载的状态说明

- [aboutToAppear](../../API_Reference/source_zh_cn/arkui-cj/cj-custom-component-lifecycle.md#func-abouttoappear)函数：在创建自定义组件的新实例后，在执行其build函数前执行。一般建议在此设置WebDebug调试模式[setWebDebuggingAccess](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-setwebdebuggingaccessbool)、设置Cookie([configCookie](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#static-func-configcookiestring-string-bool))等。
- [onControllerAttached](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-oncontrollerattached---unit)事件：当Controller成功绑定到Web组件时触发该回调，且禁止在该事件回调前调用Web组件相关的接口，否则会抛出js-error异常。推荐在此事件中注入JS对象[registerJavaScriptProxy](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-registerjavascriptproxyarraystring---string-string-arraystring)、设置自定义用户代理[setCustomUserAgent](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-setcustomuseragentstring)，可以在回调中使用[loadUrl](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-loadurlstring)，[getWebId](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-getwebid)等操作网页不相关的接口。但因该回调调用时网页还未加载，因此无法在回调中使用有关操作网页的接口，例如[zoomIn](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-zoomin)、[zoomOut](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-zoomout)等。
- [onLoadIntercept](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-onloadinterceptwebresourcerequest---bool)事件：当Web组件加载url之前触发该回调，用于判断是否阻止此次访问。默认允许加载。
- [onPageBegin](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-onpagebeginonpageevent---unit)事件：网页开始加载时触发该回调，且只在主frame（表示一个HTML元素，用于展示HTML页面的HTML元素）触发。如果是iframe或者frameset（用于包含frame的HTML标签）的内容加载时则不会触发此回调。多frame页面有可能同时开始加载，即使主frame已经加载结束，子frame也有可能才开始或者继续加载中。同一页面导航（片段、历史状态等）或者在提交前失败、被取消的导航等也不会触发该回调。
- [onPageEnd](../../API_Reference/source_zh_cn/arkui-cj/cj-web-web.md#func-onpageendonpageevent---unit)事件：网页加载完成时触发该回调，且只在主frame触发。多frame页面有可能同时开始加载，即使主frame已经加载结束，子frame也有可能才开始或者继续加载中。同一页面导航（片段、历史状态等）或者在提交前失败、被取消的导航等也不会触发该回调。推荐在此回调中执行JavaScript脚本[loadUrl](../../API_Reference/source_zh_cn/apis/ArkWeb/cj-apis-webview.md#func-loadurlstring)等。需要注意的是收到该回调并不能保证Web绘制的下一帧将反映此时DOM的状态。
- [onDisAppear](../../API_Reference/source_zh_cn/arkui-cj/cj-universal-attribute-menu.md#var-ondisappear)事件：组件卸载消失时触发此回调。该事件为通用事件，指组件从组件树上卸载时触发的事件。
