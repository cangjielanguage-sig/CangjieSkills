This directory contains API reference documentation for extending the `Rune` type in the Cangjie programming language. It focuses on low-level character manipulation, specifically covering UTF-8 encoding and decoding operations, ASCII character classification, and case conversion utilities. Key topics include converting byte arrays to characters, locating character boundaries, and validating character types using specific hexadecimal ranges. This documentation is suitable for Cangjie developers working on text processing engines, internationalization support, or any application requiring precise byte-level character operations and validation.
