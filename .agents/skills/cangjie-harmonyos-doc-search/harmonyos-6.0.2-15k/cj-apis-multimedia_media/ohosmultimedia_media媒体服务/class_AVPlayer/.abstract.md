This directory contains API reference documentation for the `AVPlayer` class within the Cangjie MediaKit framework. It covers comprehensive media playback management, including audio and video track selection, playback controls, event handling, and property configuration. Developers can find details on lifecycle management, streaming media support, and resource handling. The documentation is intended for software engineers and multimedia developers building applications in the Cangjie language who need granular control over media playback, state transitions, and event monitoring.
