# HKDF

This directory provides technical resources and code examples for implementing HKDF (HMAC-based Key Derivation Function) operations using the Universal Keystore Kit (HUKS) in the Cangjie programming language and HarmonyOS. It covers the complete lifecycle of cryptographic key derivation, including defining parameter sets, session management, initialization, data updates, and finalization. Key topics include configuring HUKS parameters for AES-128 source keys, handling errors, and managing wrapper functions for secure operations. This content is designed for developers building secure applications on HarmonyOS who require practical guidance on integrating robust key derivation logic and managing cryptographic sessions within the HUKS framework.
