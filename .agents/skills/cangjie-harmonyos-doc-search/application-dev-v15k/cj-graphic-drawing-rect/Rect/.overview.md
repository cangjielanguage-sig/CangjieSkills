# Rect

This directory contains documentation and examples for the `Rect` component within the ArkUI framework using the Cangjie language. It covers the API reference for creating rectangles, configuring attributes like dimensions and border radii, and practical code examples for styling shapes. Key topics include component constructors, universal attributes, rounded corners, and declarative UI implementation. This resource is suitable for UI developers and programmers working on HarmonyOS or OpenHarmony applications who need to implement and customize geometric shapes in their user interfaces.

## Detailed Description

### Rect_4more.md Rect_4more.md
This document serves as API reference documentation for the Rect component, used for drawing rectangles within the ArkUI framework using the Cangjie language. It details component creation through two constructors: one requiring named width and height parameters of type Length, and a parameterless version that defaults to zero size. Key information includes parameter constraints where dimensions must be non-negative, default units in vp, and system capability requirements starting from version 12. The document also outlines support for universal attributes, specific graphic drawing attributes, and all universal events. This technical reference is intended for UI developers seeking to implement rectangular shapes in their applications.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating how to create and customize rectangular shapes within a user interface using the UIKit framework. It covers the implementation of the Rect component, showing variations such as filled rectangles, stroked outlines, and different methods for applying rounded corners to specific or all vertices. Key takeaways include the syntax for setting dimensions, colors, and corner radii using properties like radius, radiusWidth, or arrays for individual corners. The code is structured within an EntryView component using a declarative UI approach. Intended for developers learning the Cangjie language or building UIs for HarmonyOS/OpenHarmony, this example serves as a practical reference for styling geometric shapes.

### 组件属性.md 组件属性.md
This API reference document details methods for configuring border corner radii within the ArkUI framework using the Cangjie language. It covers overloaded radius functions accepting single lengths, arrays, or tuples, alongside specific radiusHeight and radiusWidth methods. Key information includes that all functions require non-negative values with a default unit of vp and an initial value of 0, reverting to defaults on error. These features are available starting from API version 12. This guide targets UI developers needing to programmatically style component corners with varying degrees of precision.
