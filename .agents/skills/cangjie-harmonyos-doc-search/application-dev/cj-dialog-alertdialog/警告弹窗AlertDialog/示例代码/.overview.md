# 示例代码

This directory serves as a comprehensive resource for HarmonyOS developers, providing practical code examples written in the Cangjie language and utilizing the ArkUI framework. The primary focus of this collection is the implementation and customization of AlertDialogs, a crucial component for user interaction. It covers a range of scenarios, from standard multi-button configurations to advanced subwindow popups. By exploring these examples, developers will learn how to manipulate dialog properties such as alignment, offset, and background color, as well as manage event handling for user interactions. The content specifically details the use of classes like `AlertDialogParamWithConfirm` and `AlertDialogParamWithOptions`. These examples are best suited for developers who possess a basic understanding of Cangjie syntax and are looking to enhance their application's UI capabilities. By mastering these dialog implementations, developers can significantly improve the user experience and interactivity of their HarmonyOS applications.

## Detailed Description

### 示例1弹出多个按钮的弹窗.md
This document serves as a code example demonstrating how to implement alert dialogs with varying button configurations using the Cangjie language and ArkUI framework. The content covers three specific scenarios: a single-button dialog, a two-button dialog, and a three-button dialog, utilizing `AlertDialogParamWithConfirm`, `AlertDialogParamWithButtons`, and `AlertDialogParamWithOptions` respectively. Key takeaways include setting dialog properties like alignment, offset, and background color, as well as handling user interactions through callbacks for button clicks and dismissal events. Intended for HarmonyOS developers, this example requires basic knowledge of Cangjie syntax and ArkUI component structure.

### 示例2可在主窗外弹出的弹窗.md
This document provides a Cangjie code example demonstrating how to implement an AlertDialog that appears outside the main window in a subwindow. The content covers ArkUI component usage, specifically the configuration of `AlertDialogParamWithOptions`. Key information includes setting `showInSubWindow: true` to enable the popup behavior, along with parameters for alignment, offset, button direction, and event handling for dismissal and button clicks. This tutorial is intended for HarmonyOS developers using the Cangjie language who require knowledge of creating dialogs in subwindows.
