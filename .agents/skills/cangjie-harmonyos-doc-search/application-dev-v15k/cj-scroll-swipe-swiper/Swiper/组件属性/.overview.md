# 组件属性

This directory contains API reference documentation for the Swiper component properties within the ArkUI framework, specifically designed for the Cangjie language. It covers a comprehensive range of configuration options including autoplay behavior, display modes, animation curves, navigation indicators, and layout adjustments like margins and spacing. The documentation details function signatures, parameters, and system capabilities to help developers implement and customize carousel interfaces. It is suitable for software developers and UI engineers building interactive applications using HarmonyOS ArkUI.

## Detailed Description

### func_autoPlayBool_6more.md
API reference for Swiper component in Cangjie/ArkUI. Details autoPlay, cachedCount, curve, disableSwipe, and displayArrow overloads. Covers parameter definitions, defaults, pre-loading logic, animation curves, and arrow hover effects. Specifies system capabilities and versions. Intended for developers implementing carousel behaviors.

### func_displayCountInt32_2more.md
API reference for displayCount in ArkUI, configuring visible child elements. Covers Int32 and swipeByGroup overloads. Explains main axis stretching, 50% drag thresholds, and placeholders for incomplete groups. Details layout interactions with margins and loop mode exceptions. For Cangjie developers building precise Swiper interfaces.

### func_displayCountSwiperAut_3more.md
API reference for Swiper layout and animation in Cangjie. Covers displayCount (auto-calculation), displayMode (layout arrangement), and duration (transition length). Notes placeholder logic and duration dependency on animation curves (spring curves ignore duration). For ArkUI developers implementing complex carousels.

### func_displayCountSwiperAutoFill_Bool.md
Details displayCount using SwiperAutoFill type. Covers signatures, capabilities, and layout/loop modes. Includes auto-calculation based on minimum size, group swiping, drag thresholds, and margin/loop edge cases. Explains placeholder filling and loop conditions. For HarmonyOS ArkUI developers needing advanced layout control.

### func_effectModeEdgeEffect_6more.md
API reference for Swiper configuration in Cangjie. Covers effectMode (edge scrolling), index (page selection), and indicator overloads (bool, dot, digit). Notes API 12 requirements, index bounds, and loop mode behaviors. For UI developers building interactive page-switching interfaces.

### func_indicatorStyleLength_Length_Length_L_305beefd.md
Documentation for deprecated indicatorStyle function in Cangjie. Configures dot visuals and positioning (left, top, right, bottom). Details adaptive behaviors, priority rules, dot size, colors, and masking. Notes deprecation and recommends the indicator function. For developers maintaining legacy code.

### func_intervalUInt32_4more.md
API reference for Swiper behavior/layout in Cangjie ArkUI. Covers interval (autoplay), itemSpace (spacing), loop (cyclic playback), and nestedScroll. Defines defaults (3000ms), unit restrictions, and behaviors with negative values or LazyForEach. For developers needing precise Swiper control.

### func_nextMarginLength_Bool_3more.md
API reference for margins and direction in ArkUI Swiper. Covers nextMargin, prevMargin, and vertical. Notes that margins reveal adjacent items only in STRETCH mode or with integer display counts. Explains ignoreBlank boolean for non-loop spacing. For Cangjie/ArkUI UI developers.
