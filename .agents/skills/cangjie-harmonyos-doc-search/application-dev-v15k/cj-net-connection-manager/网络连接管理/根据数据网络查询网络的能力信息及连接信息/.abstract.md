This directory provides comprehensive technical documentation for querying network capabilities and connection properties within the HarmonyOS environment, specifically utilizing the Cangjie programming language. It details the complete workflow required for network state management, starting from permission declarations (such as `ohos.permission.GET_NETWORK_INFO`) to the practical implementation of NetworkKit APIs. Key functionalities covered include obtaining network handles via `getDefaultNet` or `getAllNets`, identifying network types like Cellular and Wi-Fi, and extracting specific features such as MMS or Internet access. Additionally, it explains how to retrieve link and routing details using `getConnectionProperties`. These resources are essential for developers aiming to build robust, network-aware applications that require real-time monitoring and dynamic adaptation to changing network conditions. By following these guides, developers can effectively manage network states and ensure optimal application performance across different connectivity scenarios.
