This directory provides comprehensive documentation and practical examples regarding the `@Watch` macro within the ArkUI framework, specifically tailored for the Cangjie language. It focuses on the mechanisms for monitoring state variable changes, covering essential aspects such as syntax, triggering conditions based on strict equality, and execution timing. The content also addresses specific limitations, including the requirement for valid callback methods and the necessity to decorate state variables like @State. Beyond basic reference material, the directory includes advanced tutorials on handling complex data structures and managing UI updates in custom components. It is highly suitable for HarmonyOS developers who possess a foundational knowledge of state management and component lifecycles and are looking to master reactive programming patterns and optimize application performance.
