# 组件属性

This directory contains API reference documentation for component properties within the Cangjie ArkUI framework, specifically focusing on Grid and GridItem layout configurations and interaction behaviors. It covers essential functions for defining grid item positioning, including row and column start/end indices, spanning rules, and selection states. The documents provide detailed parameter descriptions, valid value ranges, and layout logic to ensure precise rendering. This resource is suitable for ArkUI developers using the Cangjie language who require granular control over Grid layouts, item placement strategies, and user interaction handling in their applications.

## Detailed Description

### func_columnEndInt32.md
This API reference document explains the columnEnd function used to define the ending column position of elements within ArkUI Grid layouts. It covers the function signature, system capabilities, and the required columnEnd parameter, including its valid range and relationship with columnStart. Key information includes detailed layout rules explaining how columnEnd interacts with columnTemplate and rowTemplate settings, noting that specific spanning scenarios should utilize Grid.layoutOptions. The document is intended for developers using the Cangjie language for ArkUI development who need precise control over Grid item placement and spanning.

### func_rowStartInt32_3more.md
This document serves as an API reference for Cangjie ArkUI functions used to define grid item positioning. It details three specific methods: rowStart, rowEnd, and columnStart, each accepting an Int32 parameter to set the respective start or end indices. Key takeaways include the requirement to pair start and end functions, valid value ranges based on total grid dimensions, and recommendations to use Grid's layoutOptions for complex scenarios. This documentation targets ArkUI developers implementing Grid layouts who need precise control over item placement and spanning.

### func_selectableBool_2more.md
This document provides API reference documentation for managing the selection behavior of GridItem components within the Cangjie ArkUI framework. It covers two primary functions: selectable(Bool) and selected(Bool). The selectable function controls whether a GridItem can be selected via mouse box-selection, contingent on the outer Grid container's settings, while the selected function directly sets the item's selection state. Both functions accept a boolean parameter and return the component instance. This guide is intended for developers implementing interactive grid interfaces, requiring knowledge of basic ArkUI component structures and event handling. Keywords: Cangjie, ArkUI, GridItem, selection, API reference, mouse interaction.
