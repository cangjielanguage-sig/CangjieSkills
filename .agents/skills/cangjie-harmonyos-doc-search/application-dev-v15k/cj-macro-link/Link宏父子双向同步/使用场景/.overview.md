# 使用场景

This directory focuses on practical usage scenarios for the `@Link` decorator within the Cangjie UI framework, specifically designed for HarmonyOS application development. It provides comprehensive tutorials on implementing bidirectional data synchronization between parent and child components. The content covers a range of data types, including simple types, class objects, and arrays, while addressing advanced topics like state observation and side effects. Key concepts featured include two-way binding, `@Observed`, `@Publish`, `ObservedArrayList`, and `@Watch`. These resources are ideal for developers looking to master reactive state management and enhance component interaction logic in their Cangjie projects. The included files offer code examples ranging from basic synchronization to complex array management and local state updates.

## Detailed Description

### 数组类型的Link_2more.md 数组类型的Link_2more.md

This tutorial provides code examples for advanced @Link decorator usage in Cangjie UI development. It covers two primary scenarios: managing array types and handling side effects during synchronization. The first section demonstrates using ObservedArrayList to ensure child components detect array modifications like additions and replacements. The second section explains how to combine @Link with @Watch to update local @State variables when linked data changes, distinguishing between local updates and parent-child propagation. Key concepts include two-way data binding, state observation, and component interaction. This guide is intended for developers seeking to implement complex reactive state management in HarmonyOS applications. Keywords: @Link, ObservedArrayList, @Watch, two-way binding, Cangjie, state management.

### 简单类型和类对象类型的Link.md 简单类型和类对象类型的Link.md

This tutorial demonstrates bidirectional data synchronization using the @Link decorator with both simple types and class object types in Cangjie. The document provides a code example featuring a parent component with @State variables and child components using @Link. Key takeaways include understanding how changes in child components propagate back to the parent and how parent updates refresh child views. It specifically highlights that class objects require @Observed and @Publish decorators for property changes to be tracked. This guide is designed for developers learning state management and component interaction in the Cangjie UI framework.
