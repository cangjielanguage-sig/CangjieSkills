This directory contains API reference documentation for the `AbilityDelegator` class in the Cangjie language, specifically designed for HarmonyOS application testing and lifecycle management. It covers the creation and management of monitors for UIAbility and AbilityStage components, alongside methods to control application states, execute shell commands, and manage test execution flows. Key topics include lifecycle tracking, ability synchronization, and test utilities. This documentation is suitable for HarmonyOS developers utilizing the TestKit and AbilityKit frameworks to implement automated testing and validate application runtime behavior.
