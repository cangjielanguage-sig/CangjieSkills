# Stepper

This directory contains documentation for the Stepper component within the ArkUI framework, designed for developers using the Cangjie language. It covers the implementation of navigation tools used to display progress across multiple task steps. Key topics include component initialization, child component restrictions (StepperItem), state management, and event handling for navigation logic. This resource is suitable for software developers building structured, multi-step user interfaces for HarmonyOS applications, providing both API references and practical code examples.

## Detailed Description

### Stepper_4more.md Stepper_4more.md
This API reference document details the Stepper component, a navigation tool used to display progress across multiple task steps. The content covers child component restrictions, specifically the mandatory use of StepperItem, and outlines two constructor methods for initialization. Key information includes parameters for setting the current step index and content, alongside full support for common attributes and events. Designed for developers using the Cangjie language within the ArkUI framework, this documentation facilitates the creation of structured, multi-step user interfaces starting from version 12.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating the implementation and usage of the Stepper navigation component within the Cangjie programming framework for HarmonyOS development. The content covers the structural setup of the Stepper and StepperItem components, state management for tracking the current index and item statuses, and event handling for navigation logic. Key takeaways include how to dynamically change item states such as Normal, Skip, Disabled, and Waiting, and how to configure labels and callbacks for finishing or skipping steps. Intended for Cangjie developers, this tutorial serves as a reference for building multi-step user interfaces with interactive state transitions.

### 组件事件.md 组件事件.md
This document serves as an API reference for event handling within a Stepper component in the ArkUI framework, specifically using the Cangjie language. It details five specific event functions: onChange, onFinish, onNext, onPrevious, and onSkip, which manage step navigation logic. Key information includes trigger conditions, such as clicking navigation labels or specific ItemState values, and callback parameters that provide current and target step indices. This technical reference is intended for software developers implementing step-by-step navigation interfaces in ArkUI applications.
