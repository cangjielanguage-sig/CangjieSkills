# Net

The Net directory serves as a comprehensive resource for network programming within the Cangjie language environment. It covers a wide range of topics from fundamental transport layer protocols like TCP and UDP to high-level application layer protocols such as HTTP and WebSocket. The documentation details the architecture, protocol stacks, and specific implementation classes like `ServerBuilder` and `TcpSocket`. It also highlights unique features like the "pseudo-blocking" model for high concurrency. This collection is suitable for developers ranging from beginners learning socket programming to experienced engineers building complex networked applications in Cangjie.

## Detailed Description

### [1] net_overview
This directory provides a comprehensive overview of Cangjie language network programming, helping developers understand its basic architecture, supported protocol stacks, and core programming features. The documentation delves into the complete abstraction and implementation details from the transport layer (including UDP, TCP, and Unix Domain Socket) to the application layer (covering multiple HTTP versions and WebSocket upgrade mechanisms). It specifically emphasizes the network functions provided by the `std.socket` package and Cangjie's unique "pseudo-blocking" model—where network operations appear blocking but only block Cangjie lightweight threads, not underlying system threads, ensuring high concurrency performance. This resource is ideal for those needing to master the Cangjie network communication model.

### [2] net_socket
This directory provides detailed technical documentation for network programming in the Cangjie language, focusing on Socket programming functionality based on transport layer protocols. The content comprehensively covers the two cornerstones of network communication: the TCP reliable transmission and UDP unreliable transmission programming models. It not only explains key processes such as server and client creation, port binding, listening mechanisms, connection establishment, and data reading/writing from a theoretical level but also explores datagram sending and receiving mechanisms in connectionless mode. By providing practical code examples using core classes like `TcpServerSocket`, `TcpSocket`, and `UdpSocket`, this guide offers valuable practical guidance for developers. It is suitable for both beginners and experienced developers with basic network knowledge.

### [3] net_http
This directory focuses on the HTTP network programming development guide within the Cangjie language environment. It covers not only the basic theory of the HTTP protocol, such as the request-response model, the difference between GET and POST methods, and supported protocol versions, but also deeply explains the actual construction process of clients and servers. The document highlights the dependency relationships of the `stdx` module and provides complete code examples through core classes like `ServerBuilder` and `ClientBuilder`, helping developers achieve efficient data interaction. Core keywords include HTTP protocol, Cangjie language, network programming, ServerBuilder, ClientBuilder, and request-response mechanism. This resource is particularly suitable for those who have mastered basic Cangjie syntax and wish to advance their skills.

### [4] net_websocket
The `net_websocket` directory serves as a specialized technical resource for developers working with the WebSocket protocol within the Cangjie programming language environment. It provides in-depth documentation and structural guides focused on establishing connections and managing real-time communication.
