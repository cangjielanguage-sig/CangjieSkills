This directory focuses on component positioning and layout configuration within the Cangjie ArkUI framework. It covers essential APIs for setting coordinates, alignment rules, layout direction, and anchor points. Key topics include absolute positioning, relative offsets, chain modes, and Right-to-Left (RTL) support for internationalization. It also provides foundational type definitions and practical code examples. This resource is suitable for UI developers and system architects using the Cangjie language to build responsive, localized, and precisely positioned user interfaces in HarmonyOS applications.
