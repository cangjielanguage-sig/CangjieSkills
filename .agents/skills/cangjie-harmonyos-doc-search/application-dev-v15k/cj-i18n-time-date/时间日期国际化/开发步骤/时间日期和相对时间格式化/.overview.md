# 时间日期和相对时间格式化

This directory provides comprehensive technical documentation for formatting dates, times, and relative time ranges using the DateTimeFormat class within the Cangjie LocalizationKit. It covers the complete development lifecycle, from importing modules to retrieving configurations, with a strong focus on internationalization (i18n) and localization (l10n). Key topics include style options (full, long, short), locale-specific behaviors for zh-CN and en, and advanced customization such as alternative numbering systems and date range formatting. This resource is essential for Cangjie developers seeking to implement precise, culturally aware time display logic in their applications.

### 时间日期和相对时间格式化_1.md
This document serves as a technical guide for formatting dates, times, and relative time ranges using the DateTimeFormat class within the Cangjie LocalizationKit. It outlines a four-step development process: importing the module, creating formatter objects with specific locales and DateTimeOptions, performing formatting operations, and retrieving configuration details. Key sections include detailed reference tables illustrating how different style options such as full, long, and short affect the display of dates, times, years, and weekdays across zh-CN and en locales. The content is designed for Cangjie developers seeking to implement precise internationalization and localization features in their applications.
