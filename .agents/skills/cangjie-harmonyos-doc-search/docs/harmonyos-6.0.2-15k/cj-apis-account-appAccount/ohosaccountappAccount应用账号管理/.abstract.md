This directory contains comprehensive API reference documentation for the HarmonyOS App Account management module, specifically designed for the Cangjie programming language. It covers essential functionalities including account creation, authentication flows, token management, and credential verification. The documentation details various classes, enums, and options required to implement secure account handling and distributed data synchronization. Targeted at application developers using Cangjie, these resources provide the structural definitions and interfaces needed to integrate robust account management features into HarmonyOS applications, starting from API version 19.
