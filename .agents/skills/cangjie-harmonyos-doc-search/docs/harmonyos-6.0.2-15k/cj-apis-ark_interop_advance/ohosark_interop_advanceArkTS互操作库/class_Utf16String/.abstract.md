This directory contains API reference documentation for the `Utf16String` class in the Cangjie programming language. It focuses on storing and manipulating strings in UTF-16 format to optimize performance during ArkTS interoperability within the ArkUI framework. The content covers class properties, operator overloads, memory management, and string manipulation methods like splitting, searching, and conversion. It is suitable for developers working on HarmonyOS applications who need efficient cross-language string operations and memory management in the Napi environment.
