This directory serves as the central hub for API documentation regarding the `cj-apis-preferences` module, meticulously designed for developers leveraging the Cangjie programming language within the HarmonyOS ecosystem. It provides an in-depth look at the `ohos.data.preferences` module, which is the standard solution for implementing lightweight Key-Value (KV) data persistence. The documentation guides developers through the complexities of managing application settings, user preferences, and local data storage with high efficiency. Key topics include detailed configuration options, an exploration of storage types such as XML and GSKV, the management of data change events, and the full lifecycle of preference instances. This resource is indispensable for HarmonyOS developers who need to ensure reliable data storage, apply data constraints, and monitor data changes dynamically in their Cangjie-based applications.
