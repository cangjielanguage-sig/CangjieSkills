# interface_IntegerT

This directory contains API reference documentation for the `Integer` interface in the Cangjie programming language. It details the standardization of integer operations, including arithmetic, bitwise manipulations (AND, OR, XOR), and type properties like signedness. The documentation covers the core interface definition alongside specific implementations for various integer types, such as Int8, Int16, Int32, Int64, IntNative, and their unsigned counterparts (UInt8, UInt16, UInt32, UInt64, UIntNative). It is suitable for Cangjie developers looking to understand type behaviors, operator overloading, and interface inheritance within the core numeric package.
