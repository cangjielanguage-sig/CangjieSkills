### 约束与限制_2.md
This document outlines the constraints, logic, and persistence behaviors of the ad-blocking feature within the Web component framework. It covers the WebviewController instance controls, the global AdsBlockManager singleton, rule persistence, allowlist and disallowlist priority logic, and network request behaviors. Key takeaways include that custom rules set via setAdsBlockRules persist across cold starts, whereas allowlist and disallowlist modifications do not. The allowlist takes priority over the disallowlist, and if enabled without specific lists, ad filtering applies to all websites by default. Disabling the feature prevents requests for default configuration files. This reference guide targets developers integrating ad-blocking capabilities into Web applications, requiring knowledge of the ArkWeb API and component lifecycle management.

Key information includes the explanation that the system does not require exact domain matches; instead, a configured domain like "xxyy.com" will automatically match any subdomain, such as "wwsstt.xxyy.com". This technical reference guide is designed for developers and system administrators configuring network security policies or domain restrictions.
