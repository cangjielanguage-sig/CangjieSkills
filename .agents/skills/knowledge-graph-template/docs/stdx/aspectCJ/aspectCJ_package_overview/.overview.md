### aspectCJ_package_overview.md
这份文档是仓颉语言 stdx.aspectCJ 包的 API 参考指南，介绍面向切面编程（AOP）功能。主要涵盖功能介绍、核心注解类（InsertAtEntry、InsertAtExit、ReplaceFuncBody）及详细规格。关键信息指出，该包需配合 libcollect-aspects 和 libwave-aspects 编译插件，实现函数入口插桩、退出插桩及函数体替换。文档详细规定了标注范围、全局变量及形参约束。目标受众是需要在仓颉项目中实现 AOP 的开发者。关键词：仓颉、AOP、注解、插桩、编译插件。
