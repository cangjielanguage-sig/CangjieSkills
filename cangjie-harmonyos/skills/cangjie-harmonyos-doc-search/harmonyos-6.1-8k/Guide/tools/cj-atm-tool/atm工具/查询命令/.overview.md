# 查询命令

本目录包含关于 `atm dump` 命令的参考指南，主要用于查询系统应用进程信息、权限状态及权限使用记录。文档详细介绍了命令语法、参数说明（如 TokenID、包名筛选）以及 JSON 格式的输出结构。内容涵盖权限授予调试、进程属性查询及安全审计场景，适合系统开发者、测试人员及维护人员使用，旨在帮助用户深入理解应用权限行为。

## 快速导航

- 你想查询应用进程信息或当前权限状态？
  → 查看 查询命令_1.md 了解 `atm dump` 基础用法及参数
- 你想查询权限的历史使用记录或进行安全审计？
  → 查看 查询命令_2.md 了解 `atm dump -r` 记录查询

## 详细描述

### 查询命令_1.md
本文档是 `atm dump` 命令的参考指南，用于查询系统应用进程信息及权限状态。主要内容包括命令语法、参数说明表（涵盖 -t、-v 等必选参数及 -i、-b 等可选参数）及具体使用示例。关键信息在于支持通过 token ID、包名或进程名筛选应用详情，并能查询权限使用类型，输出为 JSON 格式。面向系统开发者或测试人员，适用于调试权限授予和进程属性，需具备命令行基础。

### 查询命令_2.md
本文档是一份命令行参考指南，旨在指导用户使用 `atm dump -r` 命令查询系统内的权限使用记录。文档详细列出了四种查询场景：查询全量记录、按应用 TokenID 筛选、按权限名筛选以及组合条件查询。内容重点展示了命令的 JSON 输出结构，包含访问次数、拒绝次数及时间戳等关键审计字段。该文档适用于开发人员或系统维护人员，用于调试应用权限行为或进行系统级的安全审计。
