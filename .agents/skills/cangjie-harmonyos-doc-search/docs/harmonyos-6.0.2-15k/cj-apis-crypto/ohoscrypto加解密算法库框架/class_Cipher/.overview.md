# class_Cipher

This directory contains API reference documentation for the `Cipher` class within the Cangjie programming language's CryptoArchitectureKit. It covers cryptographic operations including encryption and decryption for both symmetric (e.g., AES) and asymmetric (e.g., RSA, SM2) algorithms. Key topics include cipher initialization, segmented data processing via `update`, finalizing operations with `doFinal`, and managing cipher specifications. The documentation details workflows, parameters, return values, and error handling. It is suitable for software developers and security engineers implementing cryptographic features in Cangjie who need to manage data processing flows and configure security parameters.

### func_doFinalDataBlob.md func_doFinalDataBlob.md
This API documentation details the doFinal function, which finalizes encryption or decryption operations for both symmetric and asymmetric cryptographic algorithms within the CryptoArchitectureKit. The document covers the function's signature, specific behaviors for symmetric (AES) and asymmetric (RSA, SM2) operations, parameter definitions, return values, and potential exceptions. Key takeaways include that doFinal processes remaining data, resets the Cipher instance state requiring re-initialization for new operations, and handles authentication tags (authTag) specifically for GCM and CCM modes. It also warns against accessing empty results. This reference guide targets software developers implementing cryptographic security features who need to manage data processing flows and error handling.

### func_getCipherSpecCipherSp_2more.md func_getCipherSpecCipherSp_2more.md

It details two primary functions: getCipherSpec for retrieving parameter values and setCipherSpec for assigning specific byte array values to parameters. Key information includes that getCipherSpec supports RSA and SM2 algorithms returning a ResultSpec, while setCipherSpec currently supports only RSA. Both functions handle potential BusinessException errors with specific codes for invalid parameters or memory issues. This reference guide targets Cangjie developers implementing cryptographic operations who need to configure or query cipher specifications beyond basic initialization.

### func_updateDataBlob.md func_updateDataBlob.md
This API documentation details the `update` function for segmented encryption and decryption operations within the CryptoArchitectureKit. The file covers the function signature, functionality description, system capabilities, parameters, return values, exceptions, and a code example. Crucial takeaways include the prerequisite of initializing the Cipher instance, the behavior of block modes like ECB and CBC where output depends on buffer accumulation, and the restriction that asymmetric algorithms (RSA, SM2) do not support updates. Developers must handle potential empty array results and concatenate data correctly. This reference guide targets Cangjie developers implementing cryptographic operations, requiring knowledge of symmetric encryption and data handling.
