This directory serves as a comprehensive educational resource for developers working with the Cangjie programming language, specifically focusing on the sorting of collection types. It provides an in-depth examination of the `std.sort` package, guiding users through the practical process of manipulating both native Arrays and ArrayLists. The document is carefully structured to cover a wide variety of essential sorting operations, ranging from fundamental ascending sorts to more advanced and customizable techniques. It explains in detail how to implement custom comparators using the `by` parameter, how to achieve descending order using `lessThan`, and how to perform stable sorts that rely on key functions. Furthermore, the tutorial includes a practical, real-world example using a custom `Student` class to illustrate the sorting of complex objects based on specific attributes. This resource is ideally suited for Cangjie developers who need practical, code-centric examples to master collection manipulation and implement efficient sorting algorithms in their projects. By following this guide, developers can gain a solid understanding of how to effectively organize and manage data within their applications, ensuring their code is both efficient and readable. It is an essential starting point for anyone looking to refine their data handling skills.
