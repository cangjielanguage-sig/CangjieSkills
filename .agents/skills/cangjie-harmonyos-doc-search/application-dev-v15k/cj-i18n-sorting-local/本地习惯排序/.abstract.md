This directory focuses on implementing sorting logic that adapts to user habits and local conventions, particularly within application settings and internationalization contexts. It covers requirements for context-aware sorting, such as displaying language lists according to user preferences. The content also includes technical guides for developers using the Cangjie language and LocalizationKit framework to handle locale-aware string operations, including Pinyin and Stroke sorting. It is suitable for developers, UI/UX designers, and localization engineers aiming to build robust multi-language applications. The documentation bridges the gap between user experience requirements and technical implementation, ensuring that sorting behaviors align with linguistic expectations across different regions.
