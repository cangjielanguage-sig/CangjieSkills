# 使用相机预配置（仓颉）

相机预配置（Preconfig），对常用的场景和分辨率进行了预配置集成，可简化开发相机应用流程，提高应用的开发效率。

开发者在开发相机应用时，在获取到[CameraDevice](../../cj-apis-multimedia-camera/.overview.md)之后，如果遵循通用流程开发，步骤较为繁琐。需要先调用[CameraManager](../../cj-apis-multimedia-camera/.overview.md)的[getSupportedOutputCapability](../../cj-apis-multimedia-camera/.overview.md)来查询当前相机在指定模式下所支持的各类输出的配置信息，拿到[CameraOutputCapability](../../cj-apis-multimedia-camera/.overview.md)之后，应用开发者还需要对里面的各类数据进行解析，筛选，找到自己需要的配置数据[Profile](../../cj-apis-multimedia-camera/.overview.md)以及[VideoProfile](../../cj-apis-multimedia-camera/.overview.md)。最后使用对应的Profile以及VideoProfile创建对应的[PreviewOutput](../../cj-apis-multimedia-camera/.overview.md)、[PhotoOutput](../../cj-apis-multimedia-camera/.overview.md)以及[VideoOutput](../../cj-apis-multimedia-camera/.overview.md)。

为了解决上述问题，优化应用开发流程，系统针对拍照（[PhotoSession](../../cj-apis-multimedia-camera/.overview.md)）、录像（[VideoSession](../../cj-apis-multimedia-camera/.overview.md)）两类场景，提供了[preconfig](../../cj-apis-multimedia-camera/.overview.md)接口帮助开发者快速完成相机参数配置。推荐仅需要自定义拍照界面的无需开发专业相机应用的开发者，使用相机预配置功能快速开发应用。
