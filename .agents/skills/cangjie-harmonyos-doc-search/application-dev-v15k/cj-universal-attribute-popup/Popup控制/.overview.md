# Popup控制

This directory focuses on the implementation and management of popup windows within the ArkUI framework using the Cangjie language. It covers essential APIs for binding popups to UI components, configuring visual styles, and handling interaction states. Key topics include `bindPopup` functions, `PopupOptions`, `CustomPopupOptions`, and event handling mechanisms like `onStateChange`. Additionally, it addresses specific constraints such as visibility rules during page construction. This resource is designed for developers and UI engineers building HarmonyOS applications who need to integrate interactive dialog boxes, custom popups, and robust state management into their user interfaces.

## Detailed Description

### Popup控制_3more.md Popup控制_3more.md
This API reference documentation explains how to bind popup windows to UI components using the Cangjie language within the ArkUI framework. It details two overloaded bindPopup functions that accept either CustomPopupOptions or PopupOptions to configure content and interaction. Crucially, the show parameter controls visibility but cannot be set to true during page construction to avoid layout errors. The document clarifies that popup state is managed via onStateChange rather than component lifecycle. Intended for developers building UIs, it provides necessary parameters, system capabilities, and version requirements for implementing interactive popups.

### 示例代码.md 示例代码.md
This document provides a practical Cangjie code example demonstrating the implementation of popup components in a HarmonyOS application. It covers the usage of `PopupOptions` for standard dialogs and `CustomPopupOptions` for custom content, detailing state management with `@State` decorators and event callbacks like `onStateChange` and `onWillDismiss`. Key takeaways include configuring popup properties such as placement, arrow styles, background blur, and handling dismissal reasons like `TOUCH_OUTSIDE`. Intended for Cangjie developers, this example serves as a reference for integrating interactive popup UI elements into application views.

### 基础类型定义/
This directory provides API reference documentation for fundamental type definitions within the Cangjie ArkUI framework. It primarily covers classes and structures used for configuring interactive UI components, such as dialog buttons, popup windows, and state management events. Key topics include the `Action` class for button parameters, `DismissPopupAction` for popup behavior, and various `PopupOptions` for customizing visual styles, positioning, and lifecycle events. These resources are essential for software developers and UI engineers building HarmonyOS applications who need to implement robust user interfaces with precise control over popups, dialogs, and event handling logic.
