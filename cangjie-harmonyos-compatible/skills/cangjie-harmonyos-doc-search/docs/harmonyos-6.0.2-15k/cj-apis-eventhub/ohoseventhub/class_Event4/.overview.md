# class_Event4

This directory provides comprehensive API reference documentation for the Cangjie `Event4` class and its associated subscription functionality within the AbilityKit framework. It specifically addresses event handling scenarios that require four parameters, offering detailed insights into class definitions, inheritance structures, and event management methods. The documentation covers essential operations such as triggering events via the `emit` method, removing subscriptions using `off` methods, and registering callbacks through the `on` function. Key technical aspects include generic type parameters A1 through A4 and dependencies on the `AbilityRuntime.Core` system capability. This resource is designed for Cangjie developers and system architects who need to implement robust, multi-argument event-driven logic in their applications using the EventHub context.
