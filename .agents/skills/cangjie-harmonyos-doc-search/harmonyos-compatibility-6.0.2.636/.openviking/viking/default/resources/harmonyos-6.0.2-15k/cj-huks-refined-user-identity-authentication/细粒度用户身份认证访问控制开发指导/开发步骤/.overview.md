# 开发步骤

This directory contains technical tutorials for implementing secure cryptographic operations using the Cangjie language within the HarmonyOS ecosystem. It focuses on the Universal Keystore Kit (HUKS) and User IAM for biometric authentication. The guides cover generating SM4 keys with fingerprint access control, initializing encryption sessions, and performing authenticated decryption. It is suitable for software developers building secure applications that require hardware-backed key storage and biometric verification.

## Quick Navigation

## Detailed Description

### 开发步骤_1.md
This technical tutorial guides developers through generating a secure SM4 key with fingerprint access control and performing encryption using the Universal Keystore Kit in Cangjie. The document is divided into two main steps: generating a key with specific properties and initializing an encryption session. It details configuring key attributes like algorithm, key size, and user authentication types. Crucially, it specifies that while the key requires fingerprint authentication for decryption, the encryption process does not require user identity verification. This guide targets software developers implementing secure cryptographic operations, specifically those needing biometric authentication for sensitive data access in HarmonyOS applications.

### 开发步骤_2.md
This technical tutorial demonstrates how to implement secure cryptographic operations in Cangjie, specifically focusing on finishing encryption sessions and performing authenticated decryption using HUKS and User IAM. The content covers session finalization functions, SM4 encryption testing, and a detailed workflow for SM4 decryption requiring fingerprint authentication. Key information includes initializing a session to retrieve a challenge, configuring decryption properties like SM4-CBC, and integrating User IAM to obtain an authentication token before accessing the key. This guide targets Cangjie developers implementing secure key access control and biometric authentication in HarmonyOS applications.

### 开发步骤_3.md
This document provides code examples demonstrating how to complete a secure decryption session using HUKS and UserIAM authentication. It covers the implementation of the finishSession function, the public wrapper publicFinishFunc, and test cases for initializing a cipher session with biometric challenges and finalizing the operation with an authentication token. Key information includes the workflow of initializing a session to retrieve a challenge, performing UserIAM fingerprint authentication, and calling the finish function with the resulting authToken to decrypt data. Error handling and logging are included. This is a technical tutorial or code reference for developers building secure applications on HarmonyOS/OpenHarmony, specifically those integrating hardware-backed key storage and biometric authentication.
