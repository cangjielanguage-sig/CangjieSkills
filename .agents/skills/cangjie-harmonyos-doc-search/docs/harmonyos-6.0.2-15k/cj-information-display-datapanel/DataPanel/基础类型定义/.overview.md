# 基础类型定义

This directory contains API reference documentation for fundamental data types and enumerations used within the ArkUI framework and the Cangjie programming language. It covers essential definitions for data panel styles, shadow configurations, and linear gradients. Key components include the `DataPanelType` enum for panel shapes, the `DataPanelShadowOptions` class for visual effects, and the `LinearGradient` and `ColorStop` classes for color management. These definitions are critical for developers and UI designers aiming to implement and customize data visualization components and graphical effects in their applications.

## Detailed Description

### class_DataPanelShadowOptions.md class_DataPanelShadowOptions.md
This document provides API reference documentation for the Cangjie class `DataPanelShadowOptions`, which defines shadow styles for data panels within the ArkUI framework. The content details the class structure, focusing on four public properties: radius, offsetX, offsetY, and colors. It explains that colors are defined as an array of LinearGradient objects mapped to data segments, with specific rules for handling mismatched array lengths. The document also outlines the constructor method, which initializes these properties as named parameters. Key information includes the system capability requirements and the starting version 12. This reference guide is intended for developers seeking to customize the visual appearance of data panels by configuring shadow effects, requiring knowledge of Cangjie syntax and ArkUI components.

### class_LinearGradient_2more.md class_LinearGradient_2more.md
This document serves as API reference documentation for the Cangjie language, detailing the `LinearGradient` and `ColorStop` classes used in ArkUI development. It covers the properties and constructors for defining linear gradients, including the management of color stop arrays and single resource colors. Key information includes the `ColorStop` class, which defines specific color values and their proportional offsets (clamped between 0 and 1). The document outlines system capabilities and version requirements. Intended for UI developers, this reference enables the creation of complex color transitions and gradients in graphical interfaces.

### enum_DataPanelType.md enum_DataPanelType.md
This document serves as an API reference for the `DataPanelType` enum in the Cangjie programming language, specifically used within the ArkUI framework. It details the enumeration definition and describes its two available values: `LineType`, representing a linear data panel, and `CircleType`, representing a circular or ring-shaped data panel. Key information includes the system capability requirement `SystemCapability.ArkUI.ArkUI.Full` and the introduction of this feature in API version 12. This documentation is intended for software developers and UI designers working with Cangjie to implement data visualization components, providing the necessary definitions to select the appropriate panel style for their application interfaces.
