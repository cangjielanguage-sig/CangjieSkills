# 签名验签

本目录专注于数字签名与验签功能的开发指南，基于鸿蒙通用密钥库套件（HUKS）及仓颉语言。内容涵盖密钥生命周期管理、多种算法（如RSA、SM2、ECC）的签名验签流程，以及具体的代码实现案例。核心关键词包括HUKS、数字签名、SM2、RSA、仓颉。适用于需要在鸿蒙系统中实现数据完整性验证和安全加密通信的开发者。

## 详细描述

### 开发步骤.md
本文档概述了使用通用密钥库套件进行加密操作的标准开发流程，重点涵盖密钥生命周期管理和数据完整性操作。主要包含四个阶段：生成密钥（或导入）、签名、验签以及删除密钥。关键步骤包括使用 generateKeyItem 创建密钥，通过 initSession 和 finishSession 执行签名，验签过程则增加了 updateSession。文档强调了配置包含算法参数和数据的 HuksOptions，并引用了 deleteKeyItem 等API进行清理。这是一份面向开发者的操作指南，适用于需要在应用中实现安全加密功能的场景，要求读者具备API调用和会话管理的基础知识。

### 签名验签_1419ee18.md
本文档旨在指导开发者完成签名和验签功能的开发。文档提供了四种开发示例，涵盖SM2/SM3、RSA/SHA256/PSS及RSA/SHA256/PKCS1_V1_5等算法，并链接至算法规格概览。当前内容处于Beta阶段，重点在于提供具体的代码示例以辅助开发，详细场景及算法规格需参考关联文档。面向需要进行加密通信或数据完整性验证的开发者，属于技术实现指南。

### 开发案例/
本目录汇集了基于仓颉语言和鸿蒙通用密钥库套件（HUKS）的加密开发案例，重点展示了数字签名的实现方法。内容涵盖了ECC、RSA（支持PKCS1_V1_5和PSS填充）以及国密SM2等多种主流算法，详细讲解了从密钥生成、参数配置、签名验签到密钥删除的完整生命周期管理。文档包含具体的代码示例和HUKS接口调用流程，适合具备基础密码学知识并致力于鸿蒙系统安全开发的仓颉语言开发者参考。
