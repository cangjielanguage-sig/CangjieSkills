This directory serves as a specialized technical repository for the Cangjie ArkUI framework, focusing specifically on the usage restrictions and initialization rules governing access qualifiers for custom component member properties. It provides an in-depth analysis of the compatibility matrix between standard access modifiers—such as `private` and `public`—and complex state management decorators like `@State`, `@Link`, `@Prop`, `@StorageLink`, and `@Consume`. The documentation highlights critical validation rules, external initialization constraints, and methods for preventing compiler errors. This resource is indispensable for Cangjie developers and component architects who need to master the nuances of state encapsulation, ensure data flow integrity, and avoid common syntax pitfalls during the development of robust applications. By clarifying the boundaries of property access, it ensures that applications adhere to strict architectural standards.
