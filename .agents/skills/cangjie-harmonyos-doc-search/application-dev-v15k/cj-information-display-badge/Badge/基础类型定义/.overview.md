# 基础类型定义

This directory contains API reference documentation for fundamental types used in configuring Badge components within the ArkUI framework using the Cangjie language. It covers the `BadgeParams` class for configuration, the `BadgeStyle` class for styling, and the `BadgePosition` enum for layout positioning. These definitions are essential for developers looking to implement notification badges or status indicators in their user interfaces. The documentation targets Cangjie developers working with system capabilities starting from version 12, providing the necessary specifications to build robust UI elements.

## Detailed Description

### class_BadgeParams.md class_BadgeParams.md
This API reference document defines the BadgeParams class used to configure parameters for creating Badge components in the Cangjie language. It details two primary constructors: one for numeric message counts and another for text-based content. Both constructors require a BadgeStyle object for appearance and allow optional positioning via BadgePosition, defaulting to RightTop. Key parameters include count, value, and maxCount, which limits numeric display to 99 by default. This documentation targets Cangjie developers working with ArkUI system capabilities starting from version 12, providing the necessary specifications to implement notification badges or status indicators in user interfaces.

### class_BadgeStyle.md class_BadgeStyle.md
This document provides API reference documentation for the BadgeStyle class in the Cangjie language, designed to configure style parameters for Badge components in the ArkUI framework. It details the class structure, public properties, and initialization method. Key sections cover properties for text styling like color, fontSize, and fontWeight, as well as badge-specific attributes such as badgeColor, badgeSize, and border settings including borderColor and borderWidth. The constructor allows creating instances with default values for all parameters. All properties are readable and writable. Intended for developers building UIs with ArkUI, this reference requires familiarity with Cangjie syntax and resource types. It supports system capabilities starting from version 12.

### enum_BadgePosition.md enum_BadgePosition.md
This document serves as an API reference for the BadgePosition enum in the Cangjie programming language, defining the display positions for badge dots within the ArkUI framework. The content covers the enum definition and detailed descriptions of its three specific values: Left, Right, and RightTop. Key information includes the specific alignment for each value, such as vertical centering for Left and Right, and the top-right corner placement for RightTop, all supported since version 12. This reference is intended for UI developers using Cangjie to control badge placement in their applications. Keywords: BadgePosition, Cangjie, ArkUI, Enum, UI Layout.
