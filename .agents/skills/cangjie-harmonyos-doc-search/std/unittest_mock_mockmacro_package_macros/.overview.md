### unittest_mock_mockmacro_package_macros.md

This document serves as a comprehensive technical reference guide for macros within the `unittest_mock` framework. It specifically details the usage of two primary annotations: `@Called` and `@On`.

The content is logically divided into two main sections. The first section describes the `@Called` macro, which is designed to create verification statements that allow developers to check interactions and ensure methods were called as expected during the testing lifecycle. The second section covers the `@On` macro, which utilizes the configuration API to define or redefine behaviors for mock and spy objects, allowing for precise control over test scenarios.

Key takeaways include understanding how to verify method calls and configure mock object behaviors effectively.
