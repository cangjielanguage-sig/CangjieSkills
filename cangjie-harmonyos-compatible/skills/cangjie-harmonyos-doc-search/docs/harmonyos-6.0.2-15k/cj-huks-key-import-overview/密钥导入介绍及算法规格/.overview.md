# 密钥导入介绍及算法规格

This directory provides comprehensive technical documentation for the HUKS (HarmonyOS Universal Keystore Service) system, specifically focusing on key import mechanisms and supported cryptographic algorithm specifications. It details secure end-to-end key transfer processes, compares plaintext versus encrypted import workflows, and outlines specific data packaging formats. The content covers essential algorithms such as ECDH, X25519, AES-GCM, RSA, and ECC, alongside security considerations for both standard and lightweight devices. This documentation is designed for security developers, system integrators, and engineers implementing secure key lifecycle management within the HarmonyOS ecosystem.

## Detailed Description

### 加密导入.md 加密导入.md
This technical guide details the encrypted import mechanism for HUKS, enabling secure end-to-end key transfer for high-security applications. It covers the development workflow, supported algorithms (ECDH, X25519, AES-GCM), and specific data packaging formats. Key information includes the step-by-step process of generating key pairs for agreement, encrypting the target key, and importing the ciphertext. The document specifies X.509 format for public keys and a strict Length-Data structure for the import material, detailing the byte-level composition including encryption parameters like AAD, Nonce, and TAG. Intended for security developers implementing sensitive key management, this guide requires prerequisite knowledge of cryptography and HUKS APIs.

### 密钥导入介绍及算法规格_2more.md 密钥导入介绍及算法规格_2more.md
This technical guide explains how to import externally generated keys into the HUKS system for secure lifecycle management. It covers two primary import methods: plaintext and encrypted import, with a specific focus on plaintext import details. The document outlines that plaintext import exposes key material during the process, making it suitable for lightweight devices or low-security scenarios. It recommends this method primarily for asymmetric public keys, advising against it for symmetric keys or key pairs. The content targets developers integrating HUKS, specifically those working with resource-constrained devices.

### 支持的算法_2more.md 支持的算法_2more.md
This reference document specifies the cryptographic algorithms and key import formats supported by the HUKS system for API level 15 and above. It categorizes specifications into standard device algorithms, including AES, RSA, ECC, and SM2, and lightweight device algorithms like DES and 3DES, noting that lightweight support depends on OEM implementation. Additionally, it defines import formats, such as raw byte data for symmetric keys and X.509 DER encoding for public keys. This technical guide is intended for developers and system integrators managing secure key storage and importation.
