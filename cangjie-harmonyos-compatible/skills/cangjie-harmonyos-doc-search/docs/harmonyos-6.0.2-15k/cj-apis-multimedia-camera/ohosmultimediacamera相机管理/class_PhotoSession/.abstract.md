This directory contains API reference documentation for the `PhotoSession` class within the Cangjie CameraKit framework. It focuses on managing normal photo mode operations, including session initialization, event listener management, and preconfiguration of camera settings like resolution and aspect ratio. Key topics include the `on` and `off` methods for handling callbacks, `preconfig` for setting up session parameters, and error handling via `BusinessException`. This documentation is suitable for developers using the Cangjie language to implement robust camera functionality, requiring knowledge of system capabilities, asynchronous state updates, and callback management.
