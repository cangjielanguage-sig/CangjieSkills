# 断言

This directory provides comprehensive documentation for assertion mechanisms within the Cangjie testing framework. It covers essential validation tools, including standard assertion macros for equality and boolean checks, manual failure triggers, and exception validation. Additionally, it explains how to perform approximate equality comparisons for floating-point numbers. These resources are tailored for developers writing unit tests in Cangjie who need to ensure code correctness, manage test execution flow, and handle complex error scenarios effectively.

## Detailed Description

### 失败断言.md 失败断言.md
This document serves as a technical reference for implementing failure assertions within a testing framework, specifically detailing macros to force test case failures. The content distinguishes between two primary macros: `@Fail`, which employs a fast-fail mechanism to halt execution immediately, and `@FailExpect`, which records a failure but allows subsequent checks to proceed. Key information includes that both macros accept a string parameter for failure descriptions, but differ in return types (Nothing for `@Fail`, Unit for `@FailExpect`). A practical Cangjie code example demonstrates usage and resulting error output. Targeted at developers writing unit tests, this guide requires basic knowledge of the Cangjie programming language and testing syntax.

### 断言.md 断言.md
This document serves as a guide for using assertion macros within the Cangjie testing framework to validate code behavior. It covers the two primary assertion types, `@Expect` and `@Assert`, demonstrating their execution flow through code examples and output comparisons. The critical distinction is that `@Assert` employs a fail-fast mechanism, halting execution upon the first failure, whereas `@Expect` continues to run all checks to report multiple errors. It also details syntax for equality and boolean assertions. This tutorial targets developers writing unit tests who need to decide between immediate failure termination or comprehensive error reporting based on their testing scenario.

### 预期异常的断言.md 预期异常的断言.md
This reference guide details exception assertion macros and approximate equality comparisons within the Cangjie unit testing framework. It explains the usage, syntax, and return types of `@AssertThrows` and `@ExpectThrows`, distinguishing their behaviors when expected exceptions are not thrown. Furthermore, it covers the `NearEqutable` interface and `delta` parameter for performing approximate comparisons on floating-point numbers and custom types. Key concepts include exception type lists, common supertype returns, and relative delta structures. This document targets Cangjie developers who need to validate exception handling and perform non-exact value assertions in their test cases.
