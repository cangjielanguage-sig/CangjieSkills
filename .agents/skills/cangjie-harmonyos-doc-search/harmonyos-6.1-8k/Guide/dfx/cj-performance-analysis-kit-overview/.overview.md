# cj-performance-analysis-kit-overview

本目录包含 Performance Analysis Kit（性能分析服务）的概述文档，旨在为开发者提供全面的应用事件、日志和跟踪分析工具。文档详细介绍了 HiLog、HiTrace 和 HiAppEvent 等核心组件，帮助开发者观测应用运行时状态，进行行为、故障及安全分析。内容涵盖使用场景、能力范围、亮点特征以及针对 Cangjie Crash、AppFreeze 等故障的通用定位方法。本文档适合具备编程语言和操作系统基础知识的开发者，用于应用调试、问题定位及构建 APM 系统。

## Detailed Description

### cj-performance-analysis-kit-overview.md cj-performance-analysis-kit-overview.md
本文档旨在介绍 Performance Analysis Kit（性能分析服务），该套件提供应用事件、日志和跟踪分析工具，帮助开发者观测应用运行时状态，用于行为、故障及安全分析。文档主要涵盖了使用场景、能力范围、亮点特征以及故障分析方法。核心组件包括 HiLog流水日志、HiTrace跟踪和HiAppEvent应用事件。关键信息包括该套件支持便捷构建APM系统，具备强悍的异常处理机制和全面的基础维测能力，并详细说明了Cangjie Crash、AppFreeze等故障的通用定位方法。本文档面向具备编程语言和操作系统基础知识的开发者，作为概述指南，帮助其进行应用调试、问题定位及线上监控。
