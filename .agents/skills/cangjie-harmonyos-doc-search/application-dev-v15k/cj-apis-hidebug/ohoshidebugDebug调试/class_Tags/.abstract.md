This directory contains API reference documentation for the `Tags` class in the Cangjie language, specifically designed for system profiling and debugging within the HiProfiler framework. It defines a comprehensive set of static `UInt64` bit-flag constants used to identify and trace various system modules, including Ability Manager, ArkUI, Bluetooth, Distributed Hardware, and Graphics. These tags are essential for performance analysis and event categorization in the OHOS environment. This documentation is suitable for system developers and performance engineers working with API version 19 and above who need to instrument code or analyze specific usage scenarios using the HiDebug module.
