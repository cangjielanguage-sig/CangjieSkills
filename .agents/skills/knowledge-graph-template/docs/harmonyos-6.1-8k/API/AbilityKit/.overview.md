# AbilityKit

AbilityKit is a comprehensive framework service repository designed for HarmonyOS application developers using the Cangjie programming language. It provides extensive API references and documentation for core modules such as UIAbility, Want, access control, and package management. The kit covers essential functionalities including application lifecycle management, permission handling, error recovery, and context configuration. Currently in Beta, it serves as an authoritative guide for developers to understand system behaviors, implement complex interactions, and troubleshoot errors within the HarmonyOS ecosystem.

## Detailed Description

### [1] README_zh
This directory serves as the Cangjie language API reference index for the Ability Kit (Program Framework Service). It aims to provide documentation navigation for core module interfaces and error codes for HarmonyOS application developers. The content comprehensively covers key modules such as UIAbility, Want, access control, package management, and application recovery, detailing common error codes for meta-abilities, package management, and access control subsystems. All content is currently a Beta feature, involving core concepts like application lifecycle management, permission request handling, and failure recovery. This document is particularly suitable for developers using the Cangjie language for HarmonyOS application development as an authoritative reference guide.

### [2] cj-apis-ability-ability_result
This directory contains API reference documentation for the Cangjie language, focusing on the detailed definition and usage guide of the `AbilityResult` class. This class is specifically designed to handle result codes and data payloads returned after a UIAbility component is launched and exited. The documentation comprehensively covers module import methods, required permission lists, specific usage instructions, and class properties (such as `resultCode` and `want`) along with constructor configurations. It is primarily面向 developers using Cangjie to develop HarmonyOS applications, especially for complex interaction scenarios requiring Ability calls and result handling.

### [3] cj-apis-ability_access_ctrl
This directory provides API reference documentation for HarmonyOS application access control management specifically designed for the Cangjie programming language. It covers essential components such as permission grant status enumerations, access control mechanisms, and security-related interfaces, enabling developers to manage application permissions securely.

### [4] cj-apis-app-ability
This directory contains API reference documentation for the `ohos.app.ability` module in the Cangjie language, highlighting the `BaseContext` class, which serves as the parent class for all Context types. The documentation covers module import methods, required permission lists, example code usage, and the detailed definition of the `BaseContext` class, including its `stageModel` property. `BaseContext` defines basic capabilities and supports determining if the application uses the Stage model through the read-only `stageModel` property. This module is currently in Beta and targets developers using Cangjie for HarmonyOS development.
