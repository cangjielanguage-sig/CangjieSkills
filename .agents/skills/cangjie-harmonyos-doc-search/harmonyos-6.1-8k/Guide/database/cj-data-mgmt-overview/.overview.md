# cj-data-mgmt-overview

本目录包含ArkData（方舟数据管理）的概览指南，旨在全面介绍OpenHarmony平台上的数据存储、管理与同步能力。文档深入探讨了从基础的数据持久化到复杂的分布式数据交互的全过程。内容涵盖了用户首选项、键值型数据库、关系型数据库、跨应用数据管理及统一数据管理框架（UDMF）等关键组件的技术细节。此外，文档重点解析了应用沙盒内的数据存储安全机制，以及通过DatamgrService实现跨设备同步和跨应用共享的底层原理。该资源非常适合致力于构建高性能、高可靠性数据应用的OpenHarmony开发者阅读。核心关键词包括：ArkData、数据存储、分布式同步、DataShare及UDMF。
