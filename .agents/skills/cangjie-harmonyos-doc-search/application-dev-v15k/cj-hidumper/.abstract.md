This directory contains the documentation for `cj-hidumper`, a project focused on HiDumper, a unified command-line tool essential for the HarmonyOS and OpenHarmony ecosystems. It is designed to assist developers and testers in acquiring comprehensive system information necessary for deep analysis and debugging. The documentation covers a wide range of functionalities, including retrieving system capabilities, capturing crash logs, monitoring network traffic, and analyzing storage I/O. It also delves into performance monitoring, offering insights into CPU usage, memory statistics, and Inter-Process Communication (IPC) data. Advanced topics like JavaScript heap analysis and garbage collection are also covered. This resource is ideal for system developers, QA engineers, and administrators who need to diagnose system states, troubleshoot application crashes, and optimize performance using the hdc environment.
