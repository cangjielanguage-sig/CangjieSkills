This directory serves as a technical repository for developers and QA engineers seeking to understand and debug the internal structures of HarmonyOS applications built with the ArkUI framework. It focuses on the critical capabilities of displaying and retrieving foundational runtime information, which is essential for diagnosing UI issues and verifying application logic. The documentation covers advanced techniques for accessing window management data, visualizing component tree hierarchies, and tracking navigation route stacks. By utilizing command-line tools such as `hidumper` and `hdc shell`, users can perform deep inspections of their applications' state. These guides are particularly suitable for professionals who need to troubleshoot rendering problems, analyze component attributes, or validate the navigation flow of complex applications without relying solely on IDE-based debugging tools.
