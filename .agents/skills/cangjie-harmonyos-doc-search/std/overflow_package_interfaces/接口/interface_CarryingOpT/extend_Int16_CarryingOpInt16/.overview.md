# extend_Int16_CarryingOpInt16

This directory serves as a comprehensive API reference for the `CarryingOp` interface implementation tailored for the `Int16` type within the Cangjie programming language. It provides detailed documentation for arithmetic operations designed to handle integer overflow through a wrapping strategy. This resource is essential for developers and systems programmers who require granular control over arithmetic behavior and explicit overflow detection in their software projects.
