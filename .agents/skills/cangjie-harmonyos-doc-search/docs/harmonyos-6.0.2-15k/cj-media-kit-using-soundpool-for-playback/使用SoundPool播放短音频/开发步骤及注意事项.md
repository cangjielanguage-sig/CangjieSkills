## 开发步骤及注意事项

1. 调用createSoundPool方法创建SoundPool实例。

    ```cangjie
    import kit.MediaKit.*
    import kit.AudioKit.*
    import ohos.base.*

    var soundPool: ?SoundPool = None
    // audioRenderInfo中的参数usage取值为STREAM_USAGE_UNKNOWN，STREAM_USAGE_MUSIC，STREAM_USAGE_MOVIE，
    // STREAM_USAGE_AUDIOBOOK时，SoundPool播放短音时为混音模式，不会打断其他音频播放。
    var audioRendererInfo: AudioRendererInfo = AudioRendererInfo(
        StreamUsage.STREAM_USAGE_MUSIC,
        0
    )

    soundPool = media.createSoundPool(5, audioRendererInfo)
    ```

2. 调用on(LoadCompleted)方法，用于监听“资源加载完成”。

    ```cangjie
    // 回调实现方式参考完整示例
    soundPool.on(SoundPoolEvent.LoadCompleted, SoundPoolEventCallback())
    ```

3. 调用on(PlayFinished)方法，用于监听“播放完成”。

    当仅单独注册PlayFinished事件回调时，当音频播放完成的时候，都会触发注册的回调。

    ```cangjie
    // 回调实现方式参考完整示例
    soundPool.on(SoundPoolEvent.PlayFinished, FinishPlayCallback())
    ```

4. 调用on(EventError)方法，设置错误类型监听。

    ```cangjie
    // 回调实现方式参考完整示例
    soundPool.on(SoundPoolEvent.EventError, ErrCallback())
    ```

5. 调用load方法进行音频资源加载。

    可以传入uri或fd加载资源，此处使用传入uri的方式为例，更多方法请参见[API文档](../../../API_Reference/source_zh_cn/apis/MediaKit/cj-apis-multimedia_media.md#func-loadstring)。

    当系统加载完毕音频资源文件时，会通过loadComplete回调，通知用户资源加载完成，请在收到回调之后，再进行后续的play操作。

    ```cangjie
    import ohos.base.*
    import kit.CoreFileKit.*

    var soundID: Int32 = 0
    var uri: String
    func load() {
        // '/test_01.mp3' 作为样例，使用时需要传入文件对应路径。
        var file = FileFs.open("/test_01.mp3", fs.OpenMode.READ_ONLY)
        uri = "fd://" + (file.fd).toString()
        soundID = soundPool.load(uri)
    }
    ```

6. 配置播放参数PlayParameters，并在收到loadComplete回调通知之后，调用play方法播放音频。多次调用play播放同一个soundID，只会播放一次。

    ```cangjie
    var streamID: Int32 = 0
    var playParameters: PlayParameters = PlayParameters(
        loop: 0, // 循环0次
        rate: AudioRendererRate.RENDER_RATE_DOUBLE, // 2倍速
        leftVolume: 0.5f32, // range = 0.0-1.0
        rightVolume: 0.5f32, // range = 0.0-1.0
        priority: 0, // 最低优先级
    )
    streamId = soundPool.play(soundID, playParameters)
    ```

7. 调用setLoop方法设置循环次数。

    ```cangjie
    // 先调用play方法获取到对应资源的streamID
    soundPool.setLoop(streamID, 1)
    ```

8. 调用setPriority方法设置优先级。

    ```cangjie
    // 先调用play方法获取到对应资源的streamID
    soundPool.setPriority(streamID, 1)
    ```

9. 调用setVolume方法设置音量。

    ```cangjie
    // 先调用play方法获取到对应资源的streamID
    soundPool.setVolume(streamID, 0.5f32, 0.5f32)
    ```

10. 调用stop方法终止指定流的播放。

    ```cangjie
    // 先调用play方法获取到对应的streamID
    soundPool.stop(streamID)
    ```

11. 调用unload方法卸载音频资源。

    ```cangjie
    // 先调用load方法获取到对应资源的soundID
    soundPool.unload(soundID)
    ```

12. 调用off(LoadCompleted)方法注销加载完成监听。

    ```cangjie
    soundPool.off(SoundPoolEvent.LoadCompleted)
    ```

13. 调用off(PlayFinished)方法注销播放完成监听。

    ```cangjie
    soundPool.off(SoundPoolEvent.PlayFinished)
    ```

14. 调用off(EventError)方法注销错误错误类型监听。

    ```cangjie
    soundPool.off(SoundPoolEvent.EventError)
    ```

15. 调用release方法释放SoundPool实例。

    ```cangjie
    soundPool.release()
    ```
