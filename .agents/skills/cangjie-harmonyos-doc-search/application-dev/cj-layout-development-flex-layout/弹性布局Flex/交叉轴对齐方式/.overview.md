# 交叉轴对齐方式

This directory focuses on cross-axis alignment techniques within the ArkUI framework using the Cangjie programming language. It covers how to manage the positioning of child elements in Flex containers, ranging from general container-level settings to specific overrides for individual components. Key topics include the `alignItems` parameter, `alignSelf` attribute, and multi-line layout strategies via `alignContent`. This resource is suitable for HarmonyOS developers and UI engineers seeking to master declarative UI layout mechanics and optimize the visual structure of their applications.

## Detailed Description

### 交叉轴对齐方式_2more.md 交叉轴对齐方式_2more.md
This technical reference guide explains how to configure cross-axis alignment for child elements within a Flex container using the ArkUI framework and Cangjie language. The document details the `alignItems` parameter, covering six specific alignment modes: Auto, Start, Center, End, Stretch, and Baseline. Key information includes Cangjie code snippets and visual references for each mode, illustrating how items behave differently. It also notes that child element alignment settings take precedence over container settings. This guide is intended for UI developers using ArkUI who need precise control over layout positioning and component behavior.

### 子元素设置交叉轴对齐.md 子元素设置交叉轴对齐.md
This document demonstrates how to override the cross-axis alignment of individual child elements within a Flex container using the alignSelf attribute in ArkUI. It covers the interaction between the parent container's alignItems configuration and the child's specific alignment settings. The key takeaway is that alignSelf takes precedence over the parent's alignItems, allowing developers to customize the position of specific components, such as aligning to the start or baseline, while others follow the container's rule. This tutorial is intended for developers using the ArkUI framework and Cangjie programming language to build flexible user interfaces.

### 内容对齐/
This directory provides comprehensive technical documentation on content alignment strategies within the ArkUI framework, specifically tailored for developers using the Cangjie programming language. It focuses on the intricacies of configuring child element rows in multi-line Flex layouts, primarily through the use of the `alignContent` parameter. The content covers a wide range of alignment options, including FlexAlign.Start, Center, End, SpaceBetween, SpaceAround, and SpaceEvenly. By providing Cangjie code snippets and visual comparisons, these resources guide developers in managing layout spacing and cross-axis alignment when `FlexWrap.Wrap` is enabled. This collection is highly suitable for HarmonyOS developers and UI engineers seeking to master declarative UI layout mechanics and optimize the visual structure of their applications.
