The `cj-acm-tool` directory functions as a centralized documentation hub for the Account Manager (ACM) command-line utility. It is specifically tailored for developers and system administrators who require precise control over local account management within a shell environment. This resource covers the complete account lifecycle, including creation, deletion, switching, and deactivation, while also detailing the configuration of account constraints. It is an essential guide for professionals managing diverse account types such as admin or guest, ensuring they can enforce system-level policies effectively. Users should possess a working knowledge of system permissions and the hdc tool to utilize this documentation fully.
