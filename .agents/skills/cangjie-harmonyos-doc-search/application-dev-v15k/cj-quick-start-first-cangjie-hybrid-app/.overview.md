# cj-quick-start-first-cangjie-hybrid-app

This directory serves as a comprehensive guide for developers aiming to build their first HarmonyOS application that integrates the Cangjie language with ArkTS. It covers the complete development lifecycle, starting from project creation using the Hybrid Ability template to understanding the intricacies of a mixed-language directory structure. The content provides detailed instructions on building both pure ArkTS pages and hybrid UI pages, ensuring a smooth user experience. Additionally, it addresses the practical aspects of deploying applications on real devices or emulators and solves the complexities associated with cross-language page navigation. This resource is specifically suitable for developers who possess basic knowledge of HarmonyOS, ArkTS, and Cangjie, focusing heavily on interoperability, project configuration, and routing between different language environments.
