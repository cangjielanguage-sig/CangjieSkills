This directory contains API reference documentation for the `A2dpSourceProfile` class in the Cangjie programming language, specifically designed for managing Bluetooth A2DP source functionality within the ConnectivityKit. It covers essential operations such as retrieving connected devices, checking connection states, managing playback status, and handling connection state event subscriptions. Key topics include asynchronous operations, error handling, and specific permissions like `ohos.permission.ACCESS_BLUETOOTH`. This documentation is suitable for software developers working on HarmonyOS applications who need to implement robust Bluetooth audio source features and manage device connectivity events programmatically.
