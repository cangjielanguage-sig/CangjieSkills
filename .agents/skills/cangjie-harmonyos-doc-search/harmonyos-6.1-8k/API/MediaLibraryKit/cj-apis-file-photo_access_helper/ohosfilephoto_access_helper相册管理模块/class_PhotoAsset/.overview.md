# class_PhotoAsset

本目录包含仓颉语言中 `PhotoAsset` 类的 API 参考文档，主要用于 HarmonyOS 应用开发中的媒体文件管理。该类封装了图片和视频资源的属性访问与操作方法，涵盖元数据读取、缩略图获取及属性修改等功能。核心关键词包括：PhotoAsset、媒体库、元数据、缩略图、仓颉语言。文档面向使用 MediaLibraryKit 和 PhotoAccessHelper 的开发者，提供了详细的权限要求、异常处理及代码示例，帮助开发者高效管理应用内的媒体资产。

## Detailed Description

### class_PhotoAsset_5more_5bbf510e.md class_PhotoAsset_5more_5bbf510e.md
这份文档是Cangjie语言中PhotoAsset类的API参考文档，旨在提供封装文件属性的方法。主要内容包括三个只读属性：displayName（显示文件名）、photoType（媒体文件类型）和uri（资源地址），以及commitModify()方法（用于修改文件元数据）。关键信息涉及commitModify所需的ohos.permission.WRITE_IMAGEVIDEO权限、可能抛出的BusinessException异常及错误码。文档还提供了获取资源、修改标题并提交更改的代码示例。该文档面向HarmonyOS应用开发者，特别是使用PhotoAccessHelper进行媒体文件管理的开发人员。

### func_getString_2more_d7a58430.md func_getString_2more_d7a58430.md
这是一份Cangjie语言的API参考文档，旨在说明PhotoAsset类中获取属性和缩略图的方法。文档主要涵盖两个函数：`get`用于根据成员名称获取PhotoAsset参数值，需注意非基础属性需在fetchColumns中指定；`getThumbnail`用于获取指定尺寸的PixelMap缩略图，并要求READ_IMAGEVIDEO权限。文档详细列出了参数、返回值、异常错误码及对应的Cangjie代码示例。该文档面向使用MediaLibraryKit进行媒体资源开发的HarmonyOS应用开发者，提供了具体的实现指导和错误处理参考。

### func_setString_String_3d66757b.md func_setString_String_3d66757b.md
本文档介绍了用于设置PhotoAsset成员参数（主要是标题）的API函数`set`。文档涵盖了函数签名、系统能力、参数定义、异常处理及代码示例。关键信息指出目前仅支持修改`PhotoKeys.TITLE`，标题有严格限制（长度1-255、无扩展名、无非法字符），且会针对无效参数抛出`BusinessException`。该文档面向使用仓颉语言进行HarmonyOS应用开发的开发者，特别是涉及媒体库资产管理的场景。
