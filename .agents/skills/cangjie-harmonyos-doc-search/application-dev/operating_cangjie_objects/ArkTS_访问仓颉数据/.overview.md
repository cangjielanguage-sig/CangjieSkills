# ArkTS_访问仓颉数据

This directory contains technical guides and tutorials focused on interoperability between ArkTS and Cangjie within the HarmonyOS ecosystem. It covers methods for operating Cangjie objects in ArkTS, specifically detailing Custom Functions, JSClass, and JSExternal approaches. Key topics include SharedObject definitions, JSModule registration, TypeScript declarations, and performance optimization techniques like `attachCJObject`. These resources are designed for HarmonyOS developers who need to integrate Cangjie backend logic with ArkTS frontend code, ensuring efficient data access and secure cross-language object manipulation.

## Detailed Description

### ArkTS_访问仓颉数据_2more.md ArkTS_访问仓颉数据_2more.md
This technical guide details interoperability methods for operating Cangjie objects within ArkTS, specifically focusing on Custom Functions, JSExternal, and JSClass. The document provides a step-by-step tutorial for the Custom Functions approach, demonstrating how to define a SharedObject in Cangjie, register functions using JSModule, and declare interfaces in Index.d.ts. Key takeaways include the usage of context.external for object references and a warning that JSExternal objects manifest as undefined in ArkTS, posing runtime safety risks. Targeted at HarmonyOS developers, this guide requires knowledge of both ArkTS and Cangjie syntax.

### JSClass.md JSClass.md
This guide explains how to use JSClass to optimize performance and reduce memory overhead during Cangjie-ArkTS interop. It details defining a Cangjie class with a static constructor and methods, registering the class via JSModule, creating corresponding TypeScript declarations, and instantiating the class in ArkTS. Key takeaways include using attachCJObject to bind Cangjie instances to JS objects and getAttachInfo for retrieval, which is more efficient than attaching methods directly. This tutorial targets developers seeking high-performance object creation and manipulation in cross-language environments.

### JSExternal.md JSExternal.md
This tutorial demonstrates how to use the JSExternal object in Cangjie to bind data to a JSObject, hiding internal data to enhance interface security during ArkTS-Cangjie interop. The document covers defining Cangjie functions using SharedObject, declaring TypeScript interfaces, and invoking these functions in ArkTS. Key information includes creating a JSObject, attaching a Cangjie object via attachCJObject, and retrieving it using getAttachInfo within callback functions to manipulate properties. This guide targets HarmonyOS developers working on cross-language interoperability between Cangjie and ArkTS.
