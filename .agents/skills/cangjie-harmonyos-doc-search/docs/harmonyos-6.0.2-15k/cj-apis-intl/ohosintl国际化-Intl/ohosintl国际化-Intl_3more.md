# ohos.intl（国际化-Intl）

本模块提供基础的应用国际化能力，包括时间日期格式化、数字格式化、排序等，相关接口在ECMA 402标准中定义。
I18N模块提供其他非ECMA 402定义的国际化接口，与本模块共同使用可提供完整地国际化支持能力。

## 导入模块

```cangjie
import kit.LocalizationKit.*
```
