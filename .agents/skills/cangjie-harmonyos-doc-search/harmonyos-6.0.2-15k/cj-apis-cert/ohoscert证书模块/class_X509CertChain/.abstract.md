This directory contains comprehensive API reference documentation for the X509CertChain class and its associated validation functions within the Cangjie programming language environment. It is primarily focused on the representation, manipulation, and verification of X509 certificate chain objects. The documentation details essential member functions for retrieving certificate lists, calculating hash codes, and string conversion, as well as the critical validation logic required to verify certificate integrity. Key technical concepts covered include the DeviceCertificateKit, SystemCapability.Security.Cert, and specific error handling mechanisms via BusinessException. This resource is intended for security developers and system architects who need to implement robust certificate management and validation protocols, providing the necessary code examples and error code references to ensure secure application development.
