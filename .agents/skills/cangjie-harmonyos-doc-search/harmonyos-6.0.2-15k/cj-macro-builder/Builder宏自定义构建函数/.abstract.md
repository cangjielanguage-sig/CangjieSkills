This directory provides a comprehensive guide to using the @Builder macro in the Cangjie UI framework for creating reusable custom build functions. It covers implementation methods (private vs. global), parameter passing rules (pass-by-value vs. pass-by-reference), and practical usage scenarios involving dynamic UI construction and state management. Key concepts include @Builder, @State, @Observed, and UI refresh mechanisms. This resource is suitable for Cangjie UI developers and HarmonyOS application engineers looking to optimize component reusability and master declarative UI syntax.
