# 使用DevTools工具调试前端页面

This directory provides a comprehensive guide for debugging front-end pages in HarmonyOS applications using DevTools. It covers the essential workflow for enabling remote debugging between a PC and mobile devices, focusing on Web components (ArkWeb) and the Cangjie language. Key topics include the `setWebDebuggingAccess` API, `hdc` command-line tools, port forwarding automation, and troubleshooting common connection issues. This resource is designed for HarmonyOS developers and engineers who need to inspect and debug web applications on mobile devices using Chrome DevTools.

## Detailed Description

### [调试步骤/]
This directory provides a comprehensive technical guide for debugging HarmonyOS applications, specifically focusing on web components (ArkWeb) developed using the Cangjie language. It covers the essential workflow required to enable remote inspection via Chrome DevTools, starting from the initial application configuration to the final network setup. Key topics include invoking the `setWebDebuggingAccess` API, managing the `ohos.permission.INTERNET` permission, and establishing USB debugging connections. The guides also detail the use of `hdc` command-line tools for shell access and port forwarding, which are critical for bridging the device with the development environment. These resources are designed for HarmonyOS developers who need to troubleshoot web functionality and are comfortable with system-level configurations and command-line operations.

### 使用DevTools工具调试前端页面.md 使用DevTools工具调试前端页面.md
This technical guide explains how to enable and use DevTools for debugging front-end pages within Web components. The document covers the integration of DevTools, the specific API method setWebDebuggingAccess, and the setup for remote debugging between a PC and a mobile device. Key information includes the requirement to use the setWebDebuggingAccess interface to activate debugging capabilities and the prerequisite that the target mobile device must run system version 4.1.0 or higher. This guide is intended for front-end developers and engineers needing to debug web applications on mobile devices using a computer. Keywords: DevTools, Web components, debugging, setWebDebuggingAccess, mobile device, front-end.

### 便捷脚本.md 便捷脚本.md
This document provides automation scripts to simplify port forwarding configuration for debugging webviews on HarmonyOS devices using the hdc tool. It is divided into two main sections covering Windows batch scripts and Linux/Mac shell scripts. The Windows script intelligently identifies existing ports, maps new connections for devtools sockets, and automatically opens the browser inspection page. Conversely, the Linux script clears all existing forwarding rules before establishing new ones starting from port 9222. This guide targets developers seeking to streamline their debugging workflow, requiring basic command-line knowledge and an active debugging session.

### 常见问题与解决方法.md 常见问题与解决方法.md
This document serves as a troubleshooting guide for resolving common issues encountered when using the hdc tool and Chrome DevTools for debugging HarmonyOS applications. It covers key topics such as device discovery failures, unauthorized access errors, missing DevTools domain sockets, and port forwarding problems. Key takeaways include verifying USB debugging settings, authorizing the computer, ensuring web debug switches are active, and matching TCP port configurations between hdc and Chrome. The guide targets HarmonyOS developers debugging web components, requiring familiarity with command-line tools and browser debugging interfaces.
