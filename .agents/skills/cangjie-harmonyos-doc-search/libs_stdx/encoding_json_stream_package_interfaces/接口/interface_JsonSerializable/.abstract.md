This directory contains API documentation for the Cangjie language's `JsonSerializable` interface, which enables the serialization of various data types into JSON data streams. It covers the base interface definition and numerous extensions for fundamental types, including integers, floating-point numbers, strings, and generic collections like `Array` and `HashMap`. The documentation details the `toJson` function implementation for each type, specifying constraints for generic parameters. This resource is suitable for Cangjie developers implementing JSON encoding logic who need to understand how specific types are converted and written to output streams using `JsonWriter`.
