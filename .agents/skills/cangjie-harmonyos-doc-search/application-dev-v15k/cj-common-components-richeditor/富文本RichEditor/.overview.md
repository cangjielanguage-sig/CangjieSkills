# 富文本RichEditor

This directory provides a comprehensive guide to implementing and managing the RichEditor component within the ArkUI framework using the Cangjie programming language. It covers essential functionalities such as component initialization, programmatic content insertion (text and images), custom selection menu configuration, and advanced event handling. Key topics include `RichEditorOptions`, `addTextSpan`, `bindSelectionMenu`, and lifecycle callbacks. This resource is suitable for HarmonyOS application developers looking to build interactive input interfaces like comment sections, code editors, or document editors requiring mixed graphics and text editing capabilities.

### 添加文本内容_2more.md 添加文本内容_2more.md
This technical guide explains how to programmatically add text and image content to the RichEditor component in the ArkUI framework using the Cangjie language. The document covers two main topics: using addTextSpan to create mixed-style text and addImageSpan to insert visual elements like icons or data charts. Key information includes the specific API usage, parameter options for image sizing, and cursor behavior, which updates to the right of new content upon insertion. Intended for application developers, this tutorial assumes familiarity with ArkUI components and provides executable code snippets for implementing rich text features.

### 设置属性.md 设置属性.md
This technical guide explains how to implement and configure custom selection menus for text components using the bindSelectionMenu API. The document covers replacing default system menus with custom options, handling menu appearance and disappearance callbacks, and managing menu layout. Key information includes a Cangjie code example demonstrating the creation of a Menu with MenuItemGroup, binding it via TextSpanType and TextResponseType, and using TextController to close the menu. It also advises using a Scroll component for long menus to prevent keyboard obstruction. This guide is intended for HarmonyOS application developers using the ArkUI framework and Cangjie programming language who need to enhance text interaction features.

### 添加事件/
This directory provides comprehensive guidance on implementing event handling and callbacks for the ArkUI RichEditor component using the Cangjie language. It covers critical interaction scenarios including tracking content changes, managing Input Method Editor (IME) inputs, intercepting clipboard paste operations, and handling component lifecycle events. Developers will find practical examples for utilizing callbacks like `onDidChange`, `onPaste`, `onReady`, and `onSelect` to enable features such as real-time data synchronization, smart input assistance, custom content formatting, and dynamic UI responses. This resource is specifically designed for HarmonyOS application developers aiming to build sophisticated and responsive rich text editing experiences.
