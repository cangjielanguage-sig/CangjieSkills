# 预览

This directory serves as a comprehensive technical resource for developers implementing camera preview functionality, with a specific focus on rotation management and synchronization. It provides detailed guides and practical code examples demonstrating how to align the camera preview stream with the device's display orientation using the CameraKit API. Key concepts covered include calculating rotation angles, handling the `isDisplayLocked` parameter, and registering event listeners for dynamic updates. The materials are specifically tailored for software engineers utilizing the Cangjie language, ArkUI framework, or ArkTS to build responsive camera applications that adapt seamlessly to screen orientation changes.

## Detailed Description

The following files provide in-depth technical guidance and implementation details for managing camera preview rotations within the specified development environment.

### 预览_1.md 预览_1.md
This technical guide instructs developers on configuring preview stream rotation for camera applications using the CameraKit API. It details the process of retrieving the device's display rotation and applying it to the preview output. Key sections explain the usage of `getPreviewRotation` to calculate angles based on screen orientation and `setPreviewRotation` to apply them, specifically highlighting the `isDisplayLocked` parameter to control rotation behavior relative to window changes. The guide emphasizes that these operations must occur after the session calls `commitConfig`. Intended for developers using the Cangjie language and ArkUI framework, it provides code examples to handle camera orientation effectively.

### 预览_2.md 预览_2.md
This document provides a code implementation for synchronizing camera preview rotation with device display orientation. The content focuses on the `previewRotation` function, which handles the initialization and dynamic adjustment of the preview angle. Key operations include retrieving the default display rotation, calculating the corresponding preview rotation, and setting it on the `PreviewOutput` object. Additionally, it demonstrates registering a callback listener for capture status changes to automatically update the rotation when the device orientation shifts. This technical reference is intended for software developers working on camera applications, specifically those using the ArkTS or similar framework. Prerequisites include familiarity with event listeners and camera output APIs. Keywords: camera preview, rotation synchronization, display orientation, event listener, ArkTS, callback function.
