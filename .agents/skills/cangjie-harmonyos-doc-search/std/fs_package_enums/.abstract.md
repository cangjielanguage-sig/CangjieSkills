This directory provides comprehensive API reference documentation for enumerations within the file system package, with a primary focus on the `OpenMode` enum. It is designed to assist developers in understanding the nuances of file access modes, including Read, Write, Append, and ReadWrite. The documentation covers critical aspects such as file creation rules, truncation policies, and exception handling for missing files, which are vital for preventing data loss and ensuring application stability. Targeted at developers using the Cangjie programming language, this resource offers precise control over file input/output operations. It also details inherited interfaces like ToString and Equatable, ensuring developers have all necessary information to implement robust file handling logic in their applications.
