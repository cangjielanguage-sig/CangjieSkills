# 自定义弹窗CustomDialog

This directory focuses on the implementation and management of custom dialog boxes (CustomDialog) within the HarmonyOS ArkUI framework using the Cangjie programming language. It covers the complete lifecycle of dialog creation, from defining UI components with the `@CustomDialog` decorator to managing their display state via `CustomDialogController`. Key topics include component structure, event handling for user interactions, and detailed configuration options for visual styling and behavior. This resource is suitable for Cangjie developers and system architects seeking to build interactive, responsive, and polished modal interfaces in their applications.
