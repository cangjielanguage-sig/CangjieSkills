# add_cangjie_module

This directory serves as a comprehensive technical guide for HarmonyOS developers who wish to integrate Cangjie programming language modules into ArkTS projects using DevEco Studio. It addresses the critical need for interoperability between ArkTS and Cangjie, providing detailed instructions for various integration scenarios. The content covers essential workflows such as adding modules within the same project structure and incorporating static library modules. Key technical areas include the generation and management of configuration files like `cjpm.toml` and `oh-package.json5`, handling complex dependencies, and implementing cross-language function calls. This resource is ideal for developers looking to leverage the combined strengths of ArkTS and Cangjie to build more robust, high-performance HarmonyOS applications, ensuring a seamless development experience.

## Detailed Description

### 增加仓颉模块/
This directory provides comprehensive tutorials for integrating Cangjie modules into HarmonyOS ArkTS projects using DevEco Studio. It focuses on enabling interoperability between the ArkTS and Cangjie programming languages, covering various integration scenarios such as adding modules within the same project and incorporating static library modules.

The tutorials provide in-depth guidance on the technical requirements for successful integration. Key technical aspects include configuration file generation (specifically `cjpm.toml` and `oh-package.json5`), dependency management, and the implementation of cross-language function calls. These resources are specifically tailored for HarmonyOS developers who wish to extend their applications by combining the robust features of ArkTS with the capabilities of the Cangjie language, facilitating a versatile and powerful development environment.
