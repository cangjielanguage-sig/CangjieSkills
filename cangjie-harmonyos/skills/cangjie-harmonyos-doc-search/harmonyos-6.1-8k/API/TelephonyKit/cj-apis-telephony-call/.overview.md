# cj-apis-telephony-call

This directory serves as a comprehensive repository for API reference documentation regarding the HarmonyOS telephony call management module, specifically implemented using the Cangjie programming language. It is designed to assist developers in seamlessly integrating robust communication capabilities into their HarmonyOS applications. The content covers a wide array of essential telephony features, including initiating phone calls, navigating to the system dialer interface, monitoring real-time call status, and standardizing phone number formats. By detailing configuration classes for emergency numbers and formatting options, as well as enumerations for call states and the core `Call` class, this module provides a complete toolkit. Currently in the Beta stage, it is an essential resource for developers aiming to build sophisticated communication solutions on the HarmonyOS platform, ensuring they have the necessary tools to handle voice interactions effectively.
