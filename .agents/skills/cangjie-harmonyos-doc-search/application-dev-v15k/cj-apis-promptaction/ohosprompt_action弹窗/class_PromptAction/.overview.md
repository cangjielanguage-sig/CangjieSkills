# class_PromptAction

This directory contains API reference documentation for the `PromptAction` class within the ArkUI framework, specifically designed for the Cangjie language. It covers the creation and management of various user interface popups, including text prompts (toasts), interactive dialogs, action menus, and custom dialogs. The documentation details static methods for displaying these elements, handling asynchronous callbacks, and managing dialog lifecycles across different API versions. This resource is suitable for application developers working on HarmonyOS applications who need to implement user notifications and interactive modalities.

### class_PromptAction_5more.md class_PromptAction_5more.md

It covers static methods for displaying text prompts via showToast and interactive dialogs via showDialog, including overloaded versions accepting options objects introduced in version 19. Key information includes parameters for message content, duration limits, positioning offsets, and asynchronous callback handling for dialog button interactions. This guide targets application developers seeking to implement user notification and interaction modalities in HarmonyOS applications.
