This directory provides comprehensive API reference documentation for the `ohos.measure` module within the ArkUI framework, specifically tailored for the Cangjie language. It covers essential tools for programmatically calculating text layout dimensions, including width and height, to ensure precise UI rendering and layout management. Key components include the `Measure` class, `Size` struct, and `MeasureOptions` configuration. This resource is suitable for HarmonyOS developers and UI engineers who need to handle text measurement, font configuration, and layout constraints in their applications to achieve pixel-perfect designs.
