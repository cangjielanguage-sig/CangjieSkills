This directory contains API reference documentation for the HarmonyOS multimedia image processing module, specifically designed for the Cangjie programming language. It provides comprehensive resources for developers working with image data streams, covering essential functionalities such as image decoding, encoding, PixelMap manipulation, and metadata management. The documentation focuses on the SystemCapability.Multimedia.Image framework, offering interfaces for efficient image transformation and resource handling. It is suitable for software developers and engineers building multimedia applications who need to implement robust image processing features within the HarmonyOS ecosystem.
