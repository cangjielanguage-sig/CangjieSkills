# cj-permissions-for-system-apps-user

This directory functions as a critical technical resource for developers responsible for creating system-level applications, with a specific focus on the complex framework of sensitive permissions that mandate explicit user authorization. The documentation provides a thorough catalog of permissions required for accessing high-privacy user data, including detailed sections on calendar data access, telephony call management, and the handling of SMS or MMS messages. It outlines the strict security prerequisites for these permissions, emphasizing the necessity of the `system_basic` Ability Privilege Level (APL) and the implementation of the `user_grant` authorization mode to ensure user privacy is respected. Furthermore, the guide explains the nuances of ACL cross-level application support and establishes the baseline compatibility for these features starting from API version 12. This resource is indispensable for system app developers who need to navigate the platform's security model, ensuring their applications can securely and compliantly access sensitive device functions and user data.

## Detailed Description

### cj-permissions-for-system-apps-user.md cj-permissions-for-system-apps-user.md

This reference document serves as a comprehensive catalog for sensitive permissions available to system applications that require explicit user authorization. It covers specific permissions for accessing calendar data, managing calls, and handling SMS or MMS messages. The document provides key technical details regarding these permissions, indicating that all listed permissions require the `system_basic` APL (Ability Privilege Level), utilize the `user_grant` authorization mode, and support ACL cross-level application. Furthermore, these permissions are available starting from API version 12. This guide targets developers building system-level applications who need to request access to sensitive user data or device functions.
