This directory contains essential API reference documentation for the `AlertDialogButtonOptions` class, utilized within the Cangjie language and the ArkUI framework. It comprehensively covers the configuration and structural definition of buttons inside alert dialogs. Key topics include detailed explanations of class properties such as `action`, `backgroundColor`, `defaultFocus`, `enabled`, `fontColor`, `primary`, `style`, and `value`. The documentation also addresses event handling via callbacks, focus management rules, and specific API version requirements, such as the availability of the `primary` property starting from version 19. This resource is specifically tailored for developers who need to implement, customize, and manage interactive dialog buttons in their applications, ensuring proper behavior and styling.
