This directory provides a comprehensive technical overview of custom touch event distribution mechanisms within the ArkUI framework, specifically utilizing the Cangjie language. It addresses the complexities of handling touch interactions where parent components must influence child node touch testing prior to the actual dispatching of events. This capability is crucial for resolving gesture conflicts and managing event propagation with high precision in complex user interfaces. The documentation delves into essential technical components such as the `onChildTouchTest` function, various `TouchResult` classes, and specific dispatch strategies including `FORWARD_COMPETITION`. This resource is primarily intended for HarmonyOS developers and UI engineers who aim to construct sophisticated touch interfaces, manage behaviors of overlapping components like Lists and Buttons, and customize event flows to exceed standard system limitations.
