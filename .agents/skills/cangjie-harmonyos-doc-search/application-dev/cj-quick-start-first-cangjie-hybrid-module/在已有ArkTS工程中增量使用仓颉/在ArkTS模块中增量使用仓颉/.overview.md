# 在ArkTS模块中增量使用仓颉

This directory provides comprehensive guides for developers looking to incrementally integrate the Cangjie programming language into existing ArkTS projects within the OpenHarmony and HarmonyOS ecosystems. It covers essential interoperability techniques, including enabling Cangjie support in ArkTS modules, cross-module function calls, and embedding Cangjie UI components directly into ArkTS pages. These resources are designed for developers seeking to leverage Cangjie's capabilities while maintaining their current ArkTS codebase, facilitating a smooth transition to hybrid development models.

## Detailed Description

### 在ArkTS模块中增量使用仓颉_2more.md 在ArkTS模块中增量使用仓颉_2more.md
This tutorial guides developers on incrementally enabling Cangjie development within an existing ArkTS module in OpenHarmony projects. It covers the prerequisite note regarding HAR static shared packages and details the "one-click enablement" process via the IDE's right-click menu. Key information includes the resulting directory structure, highlighting the creation of the cangjie source folder and type definitions, which transforms the module into a Cangjie-ArkTS hybrid. This guide is intended for OpenHarmony developers seeking to integrate Cangjie code into ArkTS applications using the interop feature.

### 在同一个工程内纯ArkTS工程跨模块调用仓颉函数.md 在同一个工程内纯ArkTS工程跨模块调用仓颉函数.md
This tutorial guides developers on calling Cangjie functions from a pure ArkTS module within the same project. It details the process of writing Cangjie code with @Interop annotations for synchronous and asynchronous interfaces, automatically generating TypeScript declaration files (.d.ts), and configuring dependencies. The document demonstrates how to import the shared library in ArkTS and invoke the exposed functions via buttons. Key concepts include cross-module interoperability, package naming conventions, and Promise handling for async calls. This guide is intended for HarmonyOS developers building hybrid applications using both ArkTS and Cangjie languages.

### 在同模块内ArkTS页面嵌入仓颉组件.md 在同模块内ArkTS页面嵌入仓颉组件.md
This tutorial guides developers on embedding Cangjie UI components within ArkTS pages located in the same module. It covers creating a Cangjie HybridComponent file, implementing the Cangjie page logic, and integrating it into an ArkTS page using the CJHybridComponent wrapper. Key information includes the required directory structure, code examples for both cangjie_page.cj and MyModulePage.ets, and methods for invoking Cangjie functions like callSync and callAsync from ArkTS. Intended for HarmonyOS developers, this guide facilitates cross-language UI development by demonstrating how to seamlessly mix ArkTS and Cangjie components within a single application module.
