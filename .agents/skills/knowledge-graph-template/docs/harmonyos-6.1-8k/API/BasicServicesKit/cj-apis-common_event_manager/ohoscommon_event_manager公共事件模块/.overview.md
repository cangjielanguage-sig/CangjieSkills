# ohoscommon_event_manager公共事件模块

本模块是HarmonyOS系统中用于公共事件管理的仓颉语言API参考文档。它涵盖了公共事件的发布、订阅及退订功能，支持开发者实现应用间及系统级的事件驱动通信。核心内容包括CommonEventManager类的使用、系统公共事件常量定义以及Context配置要求。该模块目前处于Beta阶段，适用于需要处理系统通知、监听硬件状态变化（如Wi-Fi、蓝牙、电池）或进行应用间数据交互的HarmonyOS应用开发者，提供了基于BasicServicesKit的基础事件通信能力。

本文档是ohos.common_event_manager公共事件模块的API参考文档，旨在指导开发者使用仓颉语言实现公共事件的发布、订阅及退订功能。文档主要涵盖模块导入说明、示例代码运行指南及Context配置要求。关键信息指出该模块目前处于Beta阶段，并详细说明了在仓颉模板工程中执行示例代码的具体步骤。文档面向HarmonyOS应用开发者，提供了事件驱动开发的基础能力支持。

### class_CommonEventManager/
本目录包含Cangjie语言中`CommonEventManager`类的API参考文档，专注于HarmonyOS系统中的公共事件管理能力。文档涵盖了创建订阅者、发布事件以及订阅/取消订阅事件的核心功能，详细说明了参数、返回值、异步回调机制及异常处理（如BusinessException）。主要面向使用BasicServicesKit进行系统通知和事件监听功能开发的开发者，帮助他们实现系统级的事件通信。

### class_Support/
本目录包含仓颉语言中 `Support` 类的 API 参考文档，主要定义了系统公共事件的静态常量。内容涵盖 Wi-Fi、蓝牙、NFC、电池、用户管理、USB 及车载系统（IVI）等多种系统状态变更事件的字符串标识。所有常量均属于 `SystemCapability.Notification.CommonEvent` 系统能力，起始版本为 22。该文档适用于需要订阅系统广播、监听硬件状态变化或处理应用生命周期事件的开发者，提供了详细的事件名称、功能描述及支持状态。
