This directory contains API reference documentation for the `Cipher` class within the Cangjie programming language's CryptoArchitectureKit. It covers cryptographic operations including encryption and decryption for both symmetric (e.g., AES) and asymmetric (e.g., RSA, SM2) algorithms. Key topics include cipher initialization, segmented data processing via `update`, finalizing operations with `doFinal`, and managing cipher specifications. The documentation details workflows, parameters, return values, and error handling. It is suitable for software developers and security engineers implementing cryptographic features in Cangjie who need to manage data processing flows and configure security parameters.
