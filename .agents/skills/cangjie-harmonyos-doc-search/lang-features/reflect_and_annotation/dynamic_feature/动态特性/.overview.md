# 动态特性

本目录主要介绍仓颉语言的动态特性，核心聚焦于反射机制及其应用。内容涵盖了反射的基本概念、优缺点，以及如何通过核心类型 `TypeInfo` 获取类型信息和访问类成员。文档详细讲解了运行时类型与静态类型的区别、完全限定名查找规则，以及通过反射访问和修改公共成员变量的方法。这些资料适合希望利用反射提高程序灵活性、扩展性或需要进行动态对象操作的仓颉语言开发者参考。

### 动态特性_3more_fad06e47.md
本文档旨在介绍仓颉语言的动态特性，重点阐述反射机制及其核心类型 TypeInfo 的使用方法。主要涵盖反射的基本概念与优缺点，详细讲解了通过 TypeInfo.of 获取实例类型信息，以及通过 TypeInfo.get 依据名称查找类型信息的两种主要方式。关键信息包括区分运行时类型与静态类型的获取，理解完全限定名查找规则，以及注意未实例化泛型类型无法通过名称获取的限制。本文档适合需要利用反射提高程序灵活性和扩展性的仓颉语言开发者参考。

### 如何使用反射访问成员.md
这份文档是一份关于仓颉语言反射机制的教程，旨在指导开发者如何通过 TypeInfo 访问类的成员。主要内容包括访问和修改静态及实例成员变量、检查与更新属性（包括可变性检查）、以及通过反射调用函数。文档强调了反射仅能访问 public 修饰的成员，并提供了完整的代码示例演示 getValue、setValue 和 apply 等方法的使用。适合需要动态操作对象或检查类型信息的仓颉开发者阅读。
