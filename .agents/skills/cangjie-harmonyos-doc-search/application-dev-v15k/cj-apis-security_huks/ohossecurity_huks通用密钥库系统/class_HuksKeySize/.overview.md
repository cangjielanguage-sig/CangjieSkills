# class_HuksKeySize

This directory contains API reference documentation for the `HuksKeySize` class and related static constants within the HarmonyOS Universal Keystore (HUKS) framework. It provides definitions for cryptographic key lengths across various algorithms, including RSA, ECC, AES, SM4, 3DES, and DH. These resources are essential for Cangjie developers implementing security features, as they define the specific bit sizes required for key generation and cryptographic operations. The documentation details system capabilities, data types (HuksParamValue), and API version availability (starting from version 15).
