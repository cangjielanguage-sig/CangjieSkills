# 开放权限系统授权

本目录全面介绍了HarmonyOS系统中面向所有应用开放的系统授权权限列表及其核心授权机制。文档内容深入浅出，涵盖了权限的严格定义、system_grant授权方式的运作原理以及具体的申请指引。核心要点明确指出，当应用申请此类权限后，系统将在应用安装阶段自动授予，无需用户进行手动确认，极大地简化了用户体验。同时，文档特别说明normal级别的权限不涉及ACL使能字段。此外，目录还整合了API 12版本中各类核心功能（如蓝牙、网络、传感器、硬件控制、安全检测、数据存储、车机引擎及窗口管理等）的权限API参考。该文档主要面向应用开发者，旨在指导其在配置文件中正确声明和使用系统能力，确保应用在合规的前提下高效运行。
