# 色彩

本目录主要介绍在ArkUI框架中使用仓颉语言实现UI组件的色彩渐变效果。内容涵盖了线性渐变、径向渐变和角度渐变三种核心API，通过详细的代码示例展示了如何配置渐变角度、颜色断点、中心点及重复模式。该文档适合具备仓颉语言基础的开发者参考，旨在帮助提升UI界面的视觉表现力和美观度。
