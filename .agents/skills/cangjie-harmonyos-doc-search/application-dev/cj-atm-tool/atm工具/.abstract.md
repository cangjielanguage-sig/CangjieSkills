This directory contains comprehensive documentation for the Access Token Manager (atm) tool, a specialized utility designed for querying application process permissions and managing access control information within the system. It covers essential topics such as environment setup using the hdc shell, command lists for `help` and `dump` functions, and methods to inspect access control data based on specific identifiers like token IDs, package names, and process names. Additionally, it includes detailed guides on retrieving system application processes, checking current permission states, and auditing historical permission usage records. The content is tailored for developers and system administrators who need to debug applications, enforce security compliance, and maintain oversight of the operating system's permission management framework.
