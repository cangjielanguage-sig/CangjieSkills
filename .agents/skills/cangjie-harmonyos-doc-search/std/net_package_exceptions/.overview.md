## Detailed Description

### net_package_exceptions.md

This document serves as the API reference documentation for exception handling classes within the Cangjie net package. It is designed to assist developers in navigating the complexities of network error management by providing detailed specifications for key exception types. The document details two primary classes: `SocketException`, which is utilized for general socket errors, and `SocketTimeoutException`, which is specifically designed for timeout scenarios.

Key information includes a thorough explanation of their inheritance hierarchy, where `SocketException` extends `IOException` and `SocketTimeoutException` extends `Exception`. Additionally, the document specifies the available constructors for both classes. Each class offers two constructors: a default initializer for standard error creation and one that accepts a custom error message string for more granular error reporting. This reference is intended for Cangjie developers implementing network operations who need to effectively manage and handle socket-related errors and connection timeouts, ensuring application stability during network interactions.

**Key aspects covered in this file include:**
*   **Class Definitions:** Clear descriptions of `SocketException` and `SocketTimeoutException`.
*   **Inheritance Structure:** Details on how these classes extend base exception types.
*   **Constructor Options:** Information on default and custom message initialization.
