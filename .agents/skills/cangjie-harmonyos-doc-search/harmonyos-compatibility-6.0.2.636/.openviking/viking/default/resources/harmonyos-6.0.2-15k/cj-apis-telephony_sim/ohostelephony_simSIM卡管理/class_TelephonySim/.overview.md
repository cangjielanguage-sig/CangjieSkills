# class_TelephonySim

This directory contains API reference documentation for the `TelephonySim` class in the Cangjie programming language, specifically designed for HarmonyOS telephony services. It covers comprehensive SIM card management functionalities, including retrieving account information, checking card status, and accessing operator metadata. Key topics include static methods for querying ISO country codes, operator names, SIM state, and activation status. The documentation details required permissions like `GET_TELEPHONY_STATE`, system capabilities, and error handling via `BusinessException`. It is intended for application developers integrating telephony features into their apps using TelephonyKit, providing the necessary interfaces to interact with core telephony services starting from API version 19.
