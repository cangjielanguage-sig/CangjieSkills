## 详细描述

### target.md target.md
本文档介绍了在仓颉构建系统中如何使用 `target` 字段为不同后端和平台配置隔离的编译选项。内容涵盖配置语法、通过 `cjc -v` 获取目标名称的方法，以及编译选项、依赖管理和链接器透传等具体配置项，并详细说明了针对 `debug` 和 `release` 模式的特定配置方式。关键点在于 `compile-option`、`bin-dependencies` 等配置项既适用于本地编译也支持交叉编译。这是一份面向开发者的配置参考指南，旨在帮助用户实现跨平台或多环境的构建定制。

### target_相关字段合并规则.md target_相关字段合并规则.md
这份文档详细阐述了 cjpm.toml 配置文件中 target 字段与公共配置项的合并规则。文档定义了配置的优先级顺序，即特定编译模式配置优先于目标平台配置，后者又优先于公共配置。重点介绍了编译选项、链接选项的拼接规则，以及源码依赖和二进制依赖的合并与冲突处理机制。这是一份技术参考文档，旨在帮助开发者理解多平台及多编译模式下的配置继承与覆盖逻辑，适用于使用 cjpm 进行项目构建和依赖管理的开发人员。关键词：cjpm、target配置、合并规则、优先级、依赖管理。

### targettarget-namedebugreleasebin-dependencies.md targettarget-namedebugreleasebin-dependencies.md
本文档介绍了仓颉构建配置中 `target.target-name[.debug/release].bin-dependencies` 字段的用法，用于导入已编译的库产物。主要内容包括通过 `path-option` 按目录自动导入和通过 `package-option` 显式映射文件两种方式，并指出后者优先级更高。文档还详细说明了库文件命名规范、源码调用示例以及依赖缺失时回退到 `root` 包的机制。作为配置参考指南，它面向需要处理二进制依赖的仓颉开发者，关键词涵盖仓颉、二进制依赖、cjpm及库导入规则。
