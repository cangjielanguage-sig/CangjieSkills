This directory focuses on the structure, acquisition, and utilization of Uniform Resource Identifiers (URIs) for media files within the HarmonyOS ecosystem. It covers technical specifications for image, video, and audio URIs, detailing component breakdowns and API interfaces like `PhotoViewPicker` and `PhotoAccessHelper`. Key topics include URI formats, asset querying, permission handling, and metadata extraction. This documentation is suitable for HarmonyOS developers using ArkTS or Cangjie who need to implement robust media file access, selection, and management in their applications.
