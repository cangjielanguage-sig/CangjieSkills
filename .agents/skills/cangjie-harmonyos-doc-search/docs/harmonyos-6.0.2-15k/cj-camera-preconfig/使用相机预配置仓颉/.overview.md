# 使用相机预配置仓颉

This directory provides a comprehensive guide and resources for using the Camera Preconfiguration feature within the Cangjie programming language and CameraKit framework. It covers the conceptual understanding of preconfig interfaces, step-by-step development tutorials, and detailed resolution specifications. Designed to streamline camera application development, it eliminates the need for manual capability parsing by offering simplified parameter setups for PhotoSession and VideoSession. This resource is suitable for HarmonyOS developers seeking to implement custom camera interfaces with standard configurations without the complexity of professional-grade API management.

## Detailed Description

### 使用相机预配置仓颉.md 使用相机预配置仓颉.md
This guide explains how to use the Camera Preconfiguration feature in Cangjie to streamline camera application development. It details the standard cumbersome configuration process and introduces the preconfig interface for PhotoSession and VideoSession to simplify parameter setup. Key takeaways include the elimination of manual capability parsing and the distinction between preconfig, system camera usage, and full API development. The document targets developers seeking custom camera interfaces without the complexity of professional-grade settings, offering a middle ground between ease of use and flexibility. Keywords: Cangjie, CameraKit, Preconfig, PhotoSession, VideoSession.

### 开发步骤.md 开发步骤.md
This document provides a step-by-step tutorial for developing camera applications using the CameraKit in the Cangjie programming language. It covers importing necessary interfaces, creating input and output streams, configuring sessions, and utilizing preconfig capabilities. Key steps include initializing PreviewOutput and PhotoOutput, setting up a PhotoSession with specific SceneModes, checking Preconfig support for performance optimization, and binding inputs and outputs through configuration methods. The guide targets developers familiar with Cangjie and UI components like XComponent who need to implement photo or video capture functionality.

### 规格说明.md 规格说明.md
This document defines the resolution specifications for camera preconfigurations within the CameraKit system. It details four PreconfigType options (720P, 1080P, 4K, HIGH_QUALITY) and three PreconfigRatio options (1:1, 4:3, 16:9). The content provides specific resolution tables for preview, photo capture, and video recording outputs across normal photo and video modes. It emphasizes that PRECONFIG_HIGH_QUALITY and video-mode photos follow the sensor's maximum capability. Crucially, developers must call canPreconfig to verify device compatibility before applying settings. This reference guide targets developers configuring camera output parameters.

### 完整示例/
This directory contains a comprehensive collection of code examples designed to demonstrate the complete implementation of camera shooting functionality using the Cangjie language and CameraKit framework. It covers the entire development lifecycle, starting from defining callback classes for status and error handling to initializing the CameraManager and configuring PhotoSessions. The content details critical steps such as creating camera inputs and outputs, checking supported hardware modes, applying preconfigurations like 1080P resolution, and linking preview and photo streams. Additionally, it addresses advanced topics including flash and focus mode verification, zoom ratio adjustment, and the execution of photo capture commands. These examples are intended for HarmonyOS developers who possess prior knowledge of UIAbility contexts and require a practical, step-by-step guide to integrate robust camera capabilities into their mobile applications while ensuring proper resource management and lifecycle control.
