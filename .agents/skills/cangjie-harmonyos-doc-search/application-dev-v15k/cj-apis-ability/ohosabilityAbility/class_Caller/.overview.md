# class_Caller

This directory contains API reference documentation for the Cangjie `Caller` class within the HarmonyOS AbilityKit framework. It focuses on Inter-Process Communication (IPC) mechanisms, enabling client interfaces to communicate with generic component servers. The documentation covers essential methods for sending serialized data, managing asynchronous callbacks, handling remote state changes, and releasing communication resources. Key topics include Parcelable data, MessageSequence, and lifecycle management. This resource is suitable for Cangjie and HarmonyOS developers who need to implement robust cross-component communication and connection management in their applications.
