# class_Processor

This directory contains comprehensive API reference documentation for the `Processor` class within the Cangjie programming language, specifically designed for the HiAppEvent system. It provides detailed guidance on configuring and managing application event reporting, covering essential properties such as `name`, `appId`, `debugMode`, and `routeInfo`. The documentation thoroughly explains reporting mechanisms like `batchReport` and `periodReport`, alongside specific constraints for property values, including string length limits and valid numeric ranges for thresholds. Furthermore, it addresses user data management through `userIds` and `userProperties` variables. This resource is suitable for developers seeking to customize data processing behaviors, implement robust event transmission logic, and enforce strict data access controls within their applications.
