# HAR

This directory contains technical documentation for the Harmony Archive (HAR) format within the HarmonyOS ecosystem. It covers the complete lifecycle of HAR packages, which are static shared packages used for distributing Cangjie components, code, and resources. Key topics include the definition and constraints of HARs, how to develop and export elements, how to consume them in applications, and the compilation and publishing processes. This documentation is suitable for HarmonyOS developers using DevEco Studio and the Cangjie programming language who need to modularize code or share libraries.

## Detailed Description

### HAR_4more.md HAR_4more.md
This technical guide defines HAR (Harmony Archive), a static shared package designed for distributing Cangjie components, code, and resources across HarmonyOS modules and projects. It details usage scenarios such as in-app sharing and publishing as SDKs to OHPM repositories. The document outlines critical constraints, including the inability to run standalone, prohibitions against circular and transitive dependencies, and specific packaging rules for binary HARs. It also explains automatic permission merging and SDK version requirements. Intended for HarmonyOS developers, this guide provides essential knowledge for creating and managing shared libraries using DevEco Studio.

### 使用.md 使用.md
This technical guide instructs developers on how to configure dependencies and utilize elements from a HAR (Harmony Archive) within HarmonyOS applications using the Cangjie programming language. The document covers three primary usage scenarios: referencing Cangjie components, importing classes and methods, and accessing resources such as strings and images. Key takeaways include the prerequisite of configuring HAR dependencies and the specific syntax for integration, using `import` statements for code logic and the `@r` identifier for resources. The content targets HarmonyOS developers seeking to modularize their code or integrate third-party libraries, providing practical code examples for implementation in the Cangjie environment.

### 开发.md 开发.md
This technical guide instructs developers on exporting Cangjie components, classes, methods, and resources from a HAR (Harmony Archive) for reuse. It details using the `public` modifier to expose code and explains the compilation behavior where HARs merge into the host application. Key sections include exporting UI components, exporting logic classes, and handling resource conflicts. The document specifies resource priority rules: AppScope overrides HAP modules, which override HAR modules based on dependency order. It is intended for HarmonyOS developers working with the Cangjie language and Stage model.

### 编译_2more.md 编译_2more.md
This document provides a high-level overview of compiling and publishing HAR packages within the HarmonyOS development environment. It focuses on the lifecycle of a HAR file from build to distribution. The main sections cover Compilation, explaining that HARs function as second-party or third-party libraries for other applications, and Publishing, which redirects users to official documentation for detailed release procedures. Key takeaways include understanding the role of HARs as shared resources and the necessity of following external guides for the actual publishing process. This guide is intended for HarmonyOS developers seeking to package and share their code modules efficiently.
