This directory provides technical documentation for digital signature and verification algorithms within a cryptographic API framework. It covers fundamental principles, algorithm specifications, and configuration details for various schemes including DSA, SM2, Ed25519, ECDSA, and RSA. Key topics include data integrity, sender authentication, parameter formatting (e.g., "KeyType|Digest"), supported curves, padding schemes, and API version requirements. This resource is suitable for software developers, security engineers, and cryptographers looking to implement secure data transmission and identity verification features in their applications.
