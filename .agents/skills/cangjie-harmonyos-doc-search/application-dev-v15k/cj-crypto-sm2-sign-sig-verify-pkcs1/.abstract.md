This directory serves as a comprehensive technical resource for developers working with the Cangjie programming language, specifically focusing on the implementation of the SM2 cryptographic algorithm for digital signatures and verification. It addresses the critical security requirements of data integrity and authentication by detailing the use of the SM2 curve combined with the SM3 hash algorithm, often utilized within a PKCS1 framework. The content is tailored for software engineers and security professionals who are building secure applications and need to integrate robust signing mechanisms. By leveraging the CryptoArchitectureKit, users can follow a structured approach to handle cryptographic operations, from the initial generation of public and private key pairs to the final validation of digital signatures. This guide ensures that developers have the necessary knowledge to implement compliant and secure cryptographic workflows in their Cangjie projects, covering both the theoretical algorithm specifications and practical synchronous code execution.
