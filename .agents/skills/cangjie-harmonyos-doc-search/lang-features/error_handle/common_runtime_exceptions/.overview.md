# common_runtime_exceptions

本目录是仓颉语言开发文档体系中的重要组成部分，专门用于介绍和管理语言内置的常见运行时异常。它为开发人员提供了一套标准化的错误处理参考，涵盖了并发修改、非法参数、负数数组大小、空值及算术溢出等五类核心异常场景。通过本目录，开发者可以深入理解不同异常类的具体定义及其在代码执行过程中的触发条件，例如在Map数据结构中访问不存在的键或进行超出范围的算术运算时系统如何响应。该文档不仅适合初学者了解基本的错误类型，也适合资深开发者在进行系统调试和异常捕获设计时作为快速查阅的工具，有助于提升代码的健壮性和可维护性。
