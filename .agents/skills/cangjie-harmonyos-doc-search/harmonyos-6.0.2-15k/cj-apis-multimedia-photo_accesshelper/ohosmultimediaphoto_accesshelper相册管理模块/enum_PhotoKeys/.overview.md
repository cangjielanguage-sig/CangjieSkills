# enum_PhotoKeys

This directory provides comprehensive API reference documentation for the `PhotoKeys` enum utilized in the Cangjie programming language. It focuses on the file management system's ability to handle photo and video metadata, offering detailed definitions of keys for accessing file identifiers, dimensions, timestamps, and media-specific attributes like burst keys. Beyond the enum structure, the documentation covers operator overloading for equality comparisons, inequality operators, and string representation conversions. This resource is designed for developers and system architects who are implementing applications requiring precise photo library access, metadata querying, and media manipulation features. It ensures users understand how to effectively leverage the SystemCapability.FileManagement.PhotoAccessHelper.Core capability to manage file properties and handle sorting constraints within their software projects. By defining inheritance from ToString and Equatable, the documentation supports developers in building robust, type-safe file management logic.
