This directory provides comprehensive API reference documentation for the `JSObjectBase` class within the HarmonyOS ArkUI framework, specifically tailored for Cangjie developers. It focuses on the essential mechanisms for safely referencing, manipulating, and bridging Cangjie objects with ArkTS (JavaScript) environments. Key topics include object lifecycle management, method invocation, property definition, and runtime inspection using the Napi framework. This documentation is ideal for developers building cross-language interoperability in HarmonyOS applications who need to effectively manage object interactions and data exchange between Cangjie and JavaScript contexts.
