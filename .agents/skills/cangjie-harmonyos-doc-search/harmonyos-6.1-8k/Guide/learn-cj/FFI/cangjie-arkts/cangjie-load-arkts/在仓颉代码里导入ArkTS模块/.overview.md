# 在仓颉代码里导入ArkTS模块

本文档主要介绍如何在仓颉（Cangjie）语言中通过ArkTS互操作库加载和调用ArkTS模块。核心内容涵盖`requireArkModule`接口的使用场景、函数定义、调用限制以及线程约束。文档详细阐述了加载HAR、HSP、Native及系统模块的机制，帮助开发者实现仓颉与ArkTS或原生代码的跨语言集成。适用于需要进行模块化开发和跨语言调用的HarmonyOS开发者，需具备多线程及模块系统基础知识。

## 详细描述

### 场景介绍_3more_5d5b5726.md
本文档介绍了ArkTS互操作库中`requireArkModule`接口的使用场景、函数定义及调用限制，指导开发者加载ArkTS模块。主要涵盖场景介绍、函数说明及使用限制，详细阐述了接口功能、参数及线程约束。核心信息包括接口签名`public func requireArkModule(src: String): JSValue`。重点限制包括：仅限ArkTS绑定线程调用、禁止在全局初始化或模块导出时使用，且部分系统模块不支持Worker线程。注意当前版本在特定回调中调用会失败。面向使用ArkTS互操作功能的开发者，适用于跨语言调用场景，需具备多线程及模块系统基础知识。

### 支持场景/
本目录主要介绍在 HarmonyOS 开发中，使用仓颉语言加载和调用不同类型模块的支持场景。内容涵盖了 HAR、HSP、Native 模块以及系统模块的加载机制，包括配置文件的设置、动态导入 API 的使用以及模块间的互操作性。文档旨在帮助开发者理解如何通过 `requireArkModule` 实现仓颉与 ArkTS 或原生代码的集成，适用于需要进行模块化开发和跨语言调用的 HarmonyOS 开发者。
