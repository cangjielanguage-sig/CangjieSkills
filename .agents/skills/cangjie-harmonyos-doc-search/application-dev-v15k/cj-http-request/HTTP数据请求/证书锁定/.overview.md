# 证书锁定

This directory focuses on Certificate Pinning (证书锁定) techniques, specifically designed for securing network communications within HarmonyOS applications. It provides comprehensive resources on how to restrict HTTPS connections to specific developer-defined certificates to effectively prevent man-in-the-middle attacks. The content covers the configuration of network security settings via JSON, including methods for pre-setting application-level certificates (crt/pem) and configuring public key hash values using SHA-256 algorithms. Additionally, it offers practical guidance on using OpenSSL for certificate extraction and hash calculation. This directory is suitable for HarmonyOS developers and system administrators seeking to implement custom trust stores and enhance application security protocols. It addresses critical security considerations, such as handling server certificate chain updates.

### 证书锁定_3more.md 证书锁定_3more.md
This technical guide explains how to implement certificate pinning in HarmonyOS applications to secure HTTPS connections by restricting them to specific developer-defined certificates. The document covers configuration via network_config.json, pre-setting application-level certificates (crt/pem), and pre-setting certificate public key hashes. It also includes instructions for retrieving domain certificates using OpenSSL. Key information highlights that developers can pin certificates by embedding files or specifying public key hashes, but a critical warning notes that server certificate chain updates will cause connection failures unless the app is updated. The guide provides specific OpenSSL commands for certificate extraction and hash calculation. This is intended for HarmonyOS developers with knowledge of network security and command-line tools, focusing on enhancing app security against man-in-the-middle attacks.
