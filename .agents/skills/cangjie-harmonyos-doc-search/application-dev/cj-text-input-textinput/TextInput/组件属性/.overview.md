# 组件属性

This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework. It primarily focuses on text input and text styling attributes, covering visual customization, keyboard interaction, and input validation. Key topics include font settings (color, size, weight), caret configuration, text alignment, and input constraints like length limits and filters. These resources are designed for software developers and UI engineers using the Cangjie language to build ArkUI applications, providing the necessary technical details to implement precise control over component behavior and appearance.

### func_styleTextInputStyle_2more.md func_styleTextInputStyle_2more.md
This document serves as API reference documentation for styling text input components within the Cangjie ArkUI framework. It details two specific functions: style for defining the text input style and textAlign for configuring horizontal text alignment. Key information includes that both functions accept optional enum parameters and return This to support method chaining. The style function defaults to TextInputStyle.Default, while textAlign defaults to TextAlign.Start. These features are available starting from system version 22. This reference is intended for UI developers building applications using the Cangjie language who need to customize the appearance and layout of text input fields.
