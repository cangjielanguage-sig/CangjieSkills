# Media_Kit简介

This directory serves as a comprehensive introduction and technical reference for the Media Kit, a system service designed for developing audio and video playback and recording functionalities. It covers core modules such as AVPlayer, AVRecorder, AVScreenCapture, SoundPool, AVMetadataExtractor, and AVImageGenerator. Key topics include media transcoding, screen recording workflows, metadata extraction, and thumbnail generation. The documentation details supported formats (MP4, MP3, H.264, AAC), interaction architectures via the Cangjie interface, and data flow through frameworks like Camera and Audio. It is targeted at application developers building media applications, requiring knowledge of streaming protocols and system framework interactions.

## Detailed Description

### AVRecorder.md AVRecorder.md
This technical reference document outlines the AVRecorder module, designed to capture, encode, and save audio and video streams for application developers. The content covers the module's interaction architecture with external frameworks like Camera and Audio, detailed data flow steps, and a comprehensive list of supported formats. Key information explains the recording process via the Cangjie interface, detailing how SurfaceID facilitates video data transfer and how audio is captured via HDI. It specifies supported sources like mic and surface, encodings including HEVC and AAC, and output containers such as MP4 and MP3. Targeted at developers building media recording applications, this guide requires knowledge of the Cangjie interface and system framework interactions.

### AVScreenCapture_3more.md AVScreenCapture_3more.md

Targeted at developers integrating screen recording and media analysis capabilities, the document provides supported format tables and interaction diagrams to facilitate implementation.

### SoundPool.md SoundPool.md
This technical reference document outlines the SoundPool component, designed to facilitate short audio playback by handling media transcoding and signal output without requiring manual data parsing from the application. The content covers the interaction architecture involving the application, Player Framework, and Audio Framework, alongside specifications for supported audio protocols and container formats. Key takeaways include the requirement for file descriptors over file paths for local playback and support for formats like MP3, AAC, OGG, and WAV. The document targets application developers integrating audio features, specifically those using the Cangjie interface layer, advising against custom stream creation to maintain compatibility.

### AVPlayer/
The AVPlayer directory provides essential technical documentation for the AVPlayer component, a system designed to handle media resource transcoding and playback for applications. It covers the complete architecture and data flow for both Audio and Video workflows, explaining how the Player Framework routes data to the Audio Framework and Graphic Framework via respective HDIs. Key technical concepts include the separation of software and hardware decoding, the use of XComponent for video surfaces, and the abstraction provided by the Cangjie interface layer. Furthermore, it serves as a reference for supported media specifications, including protocols, audio/video codecs, and subtitle formats. It is particularly relevant for ensuring compatibility across different media types and optimizing performance through hardware acceleration. This documentation is tailored for application developers seeking to implement robust media playback features without managing the complexities of low-level parsing or decoding.
