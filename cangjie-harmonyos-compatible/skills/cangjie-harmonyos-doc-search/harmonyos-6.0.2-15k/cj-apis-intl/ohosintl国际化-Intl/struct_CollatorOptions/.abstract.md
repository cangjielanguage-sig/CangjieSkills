This directory contains comprehensive documentation for the `CollatorOptions` struct within the Cangjie programming language's LocalizationKit. It focuses on the configuration mechanisms necessary for customizing string sorting and comparison behaviors across different languages and regions. The documentation covers essential aspects such as locale matching strategies, sensitivity levels, punctuation handling, and specific collation rules like Pinyin or stroke-based sorting. It is specifically designed for developers and engineers involved in internationalization (I18n) who require precise control over how text is ordered and compared in their applications. By defining these options, developers can ensure that sorting logic adheres to local linguistic habits and user expectations.
