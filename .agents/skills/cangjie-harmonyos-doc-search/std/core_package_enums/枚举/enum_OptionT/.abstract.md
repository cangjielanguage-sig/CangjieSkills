The documentation covers the core enum definition, constructors (`Some`, `None`), and syntactic sugar like `?Type`. Furthermore, it details essential member functions for data transformation, interface implementations for hashing and string conversion, and utilities for instance inspection. This guide is tailored for Cangjie developers seeking to build robust, type-safe applications.
