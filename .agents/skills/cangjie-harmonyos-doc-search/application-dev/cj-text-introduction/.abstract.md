This directory serves as a comprehensive introductory guide specifically designed for developers working on the system's user interface. It focuses on the critical process of selecting and utilizing the appropriate text components for various development needs. The content covers the general definitions of text elements and provides a detailed comparative table of three primary component categories: Text, Text Input, and Rich Editor. Key distinctions include using Text and Span for static content, TextInput or TextArea for pure text entry, and RichEditor for complex inputs involving images or icons. Intended for UI developers, this guide is essential for optimizing interaction convenience and information display by matching specific application scenarios with the correct text components. It acts as a foundational resource to ensure consistency and efficiency across the platform's user interface implementations.
