# 动画衔接

This directory provides comprehensive documentation on animation transition and continuity mechanisms within the ArkUI framework, specifically designed for developers utilizing the Cangjie language. It covers the essential techniques required to ensure smooth and responsive UI interactions, focusing on complex scenarios such as interrupting ongoing animations and maintaining velocity continuity between user gestures and subsequent system animations. The content explores the automatic linkage mechanism that handles interpolation when property values change, as well as the implementation of physics-based curves like `springMotion` for natural motion. This resource is ideal for ArkUI developers seeking to master the creation of fluid, high-performance user interfaces that seamlessly bridge real-time user input with automated visual responses.

## Detailed Description

### 动画衔接.md 动画衔接.md
This guide explains the animation transition capabilities in ArkUI, ensuring smooth UI responses to real-time user interactions. It covers scenarios like interrupting ongoing animations and inheriting velocity from gestures to prevent visual stutters. The document details the automatic linkage mechanism where the system seamlessly transitions between running and new animations when property values change. Key information includes that developers only need to update property values within animateTo or using the animation interface, while the system handles the interpolation. A Cangjie code example demonstrates continuous scaling transitions during rapid clicks. This is intended for ArkUI developers seeking to implement fluid, responsive animations.

### 手势与动画的衔接.md 手势与动画的衔接.md
This guide explains how to seamlessly transition from gesture-driven movement to post-gesture animation in ArkUI applications. It covers the concept of velocity continuity, emphasizing that the animation speed after a user releases a touch must match the speed at the moment of release to prevent visual jarring. The document highlights the use of the springMotion curve, which automatically inherits the gesture's velocity. It includes a Cangjie code example demonstrating a draggable circle that snaps back to its original position. This tutorial is intended for ArkUI developers using the Cangjie language to create smooth, physics-based interactive UIs.
