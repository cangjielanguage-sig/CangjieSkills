This directory serves as a comprehensive resource for developers working with the ArkUI framework and the Cangjie programming language, specifically focusing on font management and typography. It provides detailed documentation on the APIs required to manipulate and control font behaviors within applications. The content covers critical functionalities such as registering custom typefaces, accessing the system's font registry, and querying detailed metadata about available fonts. By utilizing these resources, developers can ensure their applications support diverse typography requirements and maintain visual consistency. This documentation is primarily intended for HarmonyOS application developers who are looking to implement custom text rendering, improve accessibility through font choices, or simply inspect the font capabilities of the underlying system. The directory structure is designed to facilitate quick access to the `Font` and `FontInfo` classes, which are central to these operations.
