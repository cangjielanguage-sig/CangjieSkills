This directory provides comprehensive API reference documentation for the `ohos.system_date_time` module within the OpenHarmony ecosystem, specifically designed for the Cangjie programming language. It covers essential functionalities for managing system time, configuring timezones, and handling time-related enumerations. Key topics include retrieving current time, calculating elapsed time since the Unix epoch, and distinguishing between active time and total system uptime (including deep sleep). This documentation is suitable for Cangjie developers (version 12+) utilizing the BasicServicesKit who require precise time management and exception handling capabilities in their applications.
