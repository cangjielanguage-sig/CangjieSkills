This directory contains the API reference documentation for the `MenuItemGroup` component within the ArkUI framework, specifically tailored for the Cangjie language. It is designed to assist developers in implementing structured, grouped displays for menu items, thereby improving the organization and hierarchy of user interfaces. The documentation thoroughly covers essential implementation details, including required module imports, child component prerequisites, and initialization strategies. It specifically contrasts two methods: using `CustomBuilder` for creating custom, flexible layouts versus using `ResourceStr` for standard text-based headers and footers. Furthermore, the document provides detailed parameter definitions for headers, footers, and child content, as well as system capabilities and version requirements. This resource is ideal for UI developers working with ArkUI and Cangjie syntax who need to manage complex menu structures, noting that the component is currently in a Beta stage and supports universal attributes and events.
