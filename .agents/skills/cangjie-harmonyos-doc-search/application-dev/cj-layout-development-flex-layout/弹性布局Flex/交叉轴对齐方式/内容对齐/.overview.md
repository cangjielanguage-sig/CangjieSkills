# 内容对齐

This directory provides comprehensive technical documentation on content alignment strategies within the ArkUI framework, specifically tailored for developers using the Cangjie programming language. It focuses on the intricacies of configuring child element rows in multi-line Flex layouts, primarily through the use of the `alignContent` parameter. The content covers a wide range of alignment options, including FlexAlign.Start, Center, End, SpaceBetween, SpaceAround, and SpaceEvenly. By providing Cangjie code snippets and visual comparisons, these resources guide developers in managing layout spacing and cross-axis alignment when `FlexWrap.Wrap` is enabled. This collection is highly suitable for HarmonyOS developers and UI engineers seeking to master declarative UI layout mechanics and optimize the visual structure of their applications.

## Detailed Description

The following documents provide specific technical references and tutorials for implementing alignment in ArkUI using the Cangjie language.

### 内容对齐_1.md
This technical reference document explains how to configure the alignment of child element rows within a multi-line Flex layout using the alignContent parameter in ArkUI. It details five specific alignment options: FlexAlign.Start, Center, End, SpaceBetween, and SpaceAround. Each option is illustrated with Cangjie code snippets demonstrating how rows distribute along the cross-axis, specifically when FlexWrap.Wrap is enabled. This guide targets ArkUI developers using the Cangjie language who need to manage layout spacing and alignment in multi-line flex containers.

### 内容对齐_2.md
This document serves as a technical tutorial demonstrating cross-axis alignment configurations within the ArkUI Flex layout using the Cangjie language. It specifically focuses on the alignContent property, providing code examples and visual comparisons for FlexAlign.SpaceAround and FlexAlign.SpaceEvenly when FlexWrap.Wrap is enabled. Key takeaways include understanding how these properties distribute spacing between rows and the container edges. The content targets HarmonyOS developers seeking to master declarative UI layout mechanics and requires basic knowledge of the Cangjie syntax and ArkUI components.
