This directory contains API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It covers a wide range of styling and layout functionalities, including border settings, text appearance, sizing constraints, and icon positioning. These documents provide detailed function signatures, parameter types, and default values to help developers customize the visual presentation and layout behavior of secure controls. Suitable for UI developers and software engineers working with Cangjie to build precise and responsive user interfaces.
