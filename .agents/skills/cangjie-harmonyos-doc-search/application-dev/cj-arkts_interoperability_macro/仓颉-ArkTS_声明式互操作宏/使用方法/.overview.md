# 使用方法

This directory serves as a comprehensive resource hub for developers working on cross-language integration within the HarmonyOS and OpenHarmony development environments. It specifically addresses the technical requirements for achieving interoperability between the Cangjie language and ArkTS. The content covers essential procedures such as importing Cangjie dynamic libraries like `libohos_app_cangjie_entry.so` into ArkTS code, applying the `@Interop` macro for function annotation, and generating TypeScript declaration files (.d.ts) directly within DevEco Studio. Key themes include library naming conventions, symbol conflict prevention, and API definition generation. Designed for HarmonyOS developers and software engineers, these guides assume prior knowledge of module implementation and basic syntax, providing the necessary instructions to successfully integrate Cangjie logic into ArkTS applications and streamline the development process.

Targeted at HarmonyOS developers working with cross-language interoperability between ArkTS and Cangjie, this tutorial assumes prior knowledge of module implementation and basic ArkTS syntax.

### 使用方法_2more.md 使用方法_2more.md
