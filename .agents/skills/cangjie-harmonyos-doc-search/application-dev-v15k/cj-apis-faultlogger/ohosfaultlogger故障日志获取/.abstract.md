This directory provides comprehensive API reference documentation for the `ohos.faultlogger` module within the OpenHarmony Cangjie framework. It focuses on the mechanisms required to capture, categorize, and query system fault logs, enabling robust application diagnostics. The documentation covers essential data structures like `FaultLogInfo`, enumerations for fault types such as crashes and freezes, and the methods to retrieve this data. Designed for developers and system engineers, these resources facilitate the integration of fault logging capabilities into applications using the HiviewDFX framework, ensuring effective error tracking and system stability analysis.
