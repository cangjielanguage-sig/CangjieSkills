This directory provides comprehensive API reference documentation for the `CapsuleStyleOptions` class, a key component for styling within the HarmonyOS ArkUI framework using the Cangjie language. It focuses on the configuration of Capsule components, detailing how to manipulate text appearance, border dimensions, and advanced visual effects. Key topics include setting inner border colors and widths, defining custom text, and toggling specific animations like smooth progress and scanning lights. The documentation also explains how custom content overrides percentage displays. This resource is essential for HarmonyOS developers and UI designers who require precise control over the visual properties and behavior of capsule elements in their ArkUI applications. It serves as a technical guide for those looking to implement sophisticated UI styling and component behavior programmatically.
