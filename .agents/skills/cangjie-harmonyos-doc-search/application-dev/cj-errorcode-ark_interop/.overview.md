# cj-errorcode-ark_interop

This directory functions as a specialized technical repository for the ArkTS Interop library, specifically tailored for developers integrating the Cangjie language with ArkTS. It provides a structured reference guide that addresses eight distinct error codes arising during cross-language operations. The scope of this documentation covers critical runtime issues such as illegal indices, unhandled runtime exceptions, violations of object lifecycle protocols, thread validation errors, type mismatches, and failures in module imports. By offering in-depth analyses of potential causes and precise resolution steps—including API usage verification like `JSContext.isBindThread()`—this resource is essential for developers who need to effectively debug interoperability issues and ensure the robustness of their applications.

## Detailed Description

### cj-errorcode-ark_interop.md cj-errorcode-ark_interop.md
This document serves as a comprehensive reference guide for specific error codes encountered within the ArkTS Interop library during Cangjie and ArkTS integration. It is an essential tool for maintaining system stability, detailing eight distinct error codes that cover a wide array of potential runtime issues. These include illegal indices, general runtime exceptions, object lifecycle violations, thread validation errors, type mismatches, and module import failures.

The content is organized to facilitate rapid debugging and problem resolution. For each of the eight error codes, the document provides:
*   **The Error Message:** The exact string or code displayed to the user.
*   **Detailed Description:** An explanation of what the error means in the context of the Interop library.
*   **Potential Causes:** A list of common programming mistakes or configuration issues that trigger the error.
*   **Specific Handling Steps:** Clear instructions on how to fix the issue, such as checking thread binding with `JSContext.isBindThread()` or verifying the correctness of module paths.

This resource is primarily intended for developers working on cross-language interoperability who need to debug runtime errors and ensure correct API usage.
