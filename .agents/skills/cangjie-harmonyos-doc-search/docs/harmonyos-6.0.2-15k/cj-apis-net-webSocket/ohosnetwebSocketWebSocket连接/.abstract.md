This directory provides comprehensive API reference documentation and practical examples for implementing WebSocket connections in HarmonyOS using the Cangjie programming language. It covers the entire WebSocket lifecycle, from establishing connections and configuring security options to handling asynchronous events and managing data transmission. Key components include classes for request options, proxy settings, client certificates, and enums for event types and data formats. This documentation is specifically designed for developers utilizing the SystemCapability.Communication.NetStack to build real-time, bidirectional network communication features in their HarmonyOS applications.
