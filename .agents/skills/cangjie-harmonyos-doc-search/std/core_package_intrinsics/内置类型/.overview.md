# 内置类型

This directory provides comprehensive API documentation for the built-in types in the Cangjie programming language. It covers fundamental types such as Bool and Unit, a wide range of numeric types including signed and unsigned integers (Int8 to Int64, UInt8 to UInt64) and floating-point numbers (Float16, Float32, Float64), as well as types designed for C interoperability like CPointer and CString. Additionally, it documents the Rune type for Unicode character representation. This resource is essential for Cangjie developers seeking to understand type behaviors, interface implementations, and low-level memory manipulation capabilities.

## Detailed Description

### Bool.md Bool.md
This API documentation defines the Bool type in the Cangjie language, detailing its core functionality and interface implementations. The document covers three main extensions: Equatable for equality checks, Hashable for hash code generation, and ToString for string representation. Key information includes the specific return values for methods like hashCode(), which returns 0 for false and 1 for true, and toString(), which converts boolean values to their string equivalents. This reference guide targets Cangjie developers seeking to understand boolean type behaviors, standard interface compliance, and method signatures for data manipulation and comparison.

### Unit.md Unit.md
This API reference document defines the Unit type in the Cangjie programming language, representing expressions focused on side effects rather than return values. The text covers the type's single literal value `()` and its extensions for the Equatable, Hashable, and ToString interfaces. Key information includes that Unit supports limited operations like equality checks, has a fixed hash code of 0, and converts to the string "()". Common examples include print functions and assignment expressions. This technical reference is intended for Cangjie developers seeking to understand type system behaviors and intrinsic types.
