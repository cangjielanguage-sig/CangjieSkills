This directory functions as a specialized knowledge base for HarmonyOS developers, focusing on the intricacies of application package information and signature management. It addresses critical technical challenges, such as how to accurately retrieve the `appIdentifier` and fingerprint data, which are vital for application security and runtime logic. The content covers a range of methodologies, from utilizing the Cangjie programming language APIs to executing shell commands via the `bm` tool. Furthermore, it explains the nuances of signing modes—specifically comparing auto-signing versus manual signing via AppGallery Connect—and their implications for identifier stability. This resource is highly suitable for developers, security engineers, and QA professionals who require precise access to application metadata for debugging, verification, or ensuring consistency across multi-user development environments.
