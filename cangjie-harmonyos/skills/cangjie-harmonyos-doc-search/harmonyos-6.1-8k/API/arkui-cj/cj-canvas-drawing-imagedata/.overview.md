# cj-canvas-drawing-imagedata

本目录提供了ArkUI框架下`ImageData`类的API参考文档，专门针对使用仓颉（Cangjie）语言进行开发的用户。该文档的核心内容是介绍如何存储和管理Canvas渲染所需的像素数据。它详细阐述了`ImageData`类的结构，包括其只读属性（宽度、高度、数据数组）以及构造函数的具体用法。此外，文档还明确了像素数据的操作限制，例如宽高的最大值（16384px）和数据数组的计算规则。这份资料非常适合那些需要在应用中直接处理图像像素、实现自定义绘图效果或进行底层图形数据操作的开发者阅读和参考。

## 详细说明

### cj-canvas-drawing-imagedata.md cj-canvas-drawing-imagedata.md
本文档是ArkUI框架中ImageData类的API参考，用于存储Canvas渲染的像素数据。内容涵盖类定义、导入模块、只读属性（宽、高、数据数组）及两个构造函数。关键信息包括宽高最大不超过16384px，数据数组长度需等于4倍宽高乘积，且支持单位配置。面向使用仓颉语言的开发者，适用于直接操作Canvas像素数据的场景。
