This directory contains comprehensive documentation for the `QualifiedType` class within the Cangjie language's Abstract Syntax Tree (AST) infrastructure. It focuses on representing user-defined member types accessed via dot notation (e.g., `T.a`), including robust support for generics. The documentation covers the complete class structure, initialization methods, property definitions, and essential AST manipulation techniques such as token conversion and recursive traversal. It is specifically designed for developers working on compilers, static analysis tools, or language processing tasks involving the Cangjie language, providing the necessary API references to programmatically construct and manage type nodes.
