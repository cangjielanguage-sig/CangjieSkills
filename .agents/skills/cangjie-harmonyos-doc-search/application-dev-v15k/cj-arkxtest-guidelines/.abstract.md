This directory serves as a comprehensive resource hub for the Cangjie Automated Testing Framework, specifically tailored for the HarmonyOS and OpenHarmony ecosystems. It provides in-depth documentation covering the architectural design, implementation principles, and runtime environments of both the Cangjie Unit Test Framework and the UiTest framework. The guidelines included here are essential for developers and QA engineers looking to master the writing and execution of test scripts using the Cangjie language. Additionally, it offers practical insights into performing UI automation via shell commands and resolving common execution errors. This collection is suitable for software developers and QA engineers aiming to establish robust testing workflows, configure development environments accurately, and enhance the reliability of their applications through effective debugging of UI automation scripts.
