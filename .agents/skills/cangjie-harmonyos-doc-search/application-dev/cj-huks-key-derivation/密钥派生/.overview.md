# 密钥派生

This directory provides comprehensive resources on cryptographic key derivation, primarily focusing on the HarmonyOS Universal Keystore Kit (HUKS) framework. It covers the theoretical foundations of key derivation using algorithms like HKDF256 and PBKDF2, alongside practical implementation guides for the Cangjie programming language. The content details the complete key lifecycle, including generation, derivation, and deletion, emphasizing secure storage and session management. Suitable for developers and security engineers, these documents and case studies offer the necessary technical guidance to implement robust, hardware-backed security protocols and ensure compliance with cryptographic standards in a modern development environment.

## Detailed Description

### 密钥派生.md 密钥派生.md
This document serves as a conceptual guide for implementing key derivation, specifically using the HKDF256 algorithm as a primary example. It outlines the fundamental process of deriving keys and references external documentation for detailed scenario descriptions and supported algorithm specifications. Key takeaways include the current Beta status of the feature and the reliance on the HKDF256 standard. The content is intended for developers or security engineers working with cryptographic systems who require guidance on key management and derivation protocols.

### 开发步骤.md 开发步骤.md
This technical guide outlines the development steps for managing cryptographic keys using the HUKS framework. It covers three main stages: key generation, key derivation, and key deletion. Key information includes configuring the `HUKS_TAG_DERIVED_AGREED_KEY_STORAGE_FLAG` to determine if derived keys are managed by HUKS or exported to the application. The document details the specific API sequence for derivation: `initSession`, `updateSession`, and `finishSession`. Intended for developers, this guide provides a step-by-step process for secure key lifecycle management, ensuring keys remain within a secure environment or are handled externally based on business requirements.
