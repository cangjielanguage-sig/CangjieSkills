### module-configuration-file.md module-configuration-file.md
This technical reference document details the configuration of the metadata tag within the module.json5 file for HarmonyOS Ability Packages (HAP). It covers the tag's definition, a detailed attribute table specifying name, value, and resource properties, and practical JSON5 examples. Key information includes that metadata stores custom information as an array, where the resource attribute uses the $profile:filename syntax to reference files in the /resources/base/profile directory. The examples demonstrate implementation within module, abilities, and extensionAbilities objects. This guide targets application developers needing to define custom metadata or resource references in their project configuration.
