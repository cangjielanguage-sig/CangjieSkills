## Detailed Description

### cj-universal-attribute-bindcontentcover.md
这是一份关于ArkUI全屏模态转场属性的API参考文档，旨在指导开发者使用bindContentCover方法为组件绑定全屏模态页面。文档详细说明了该函数的参数定义，包括控制显示状态的isShow、自定义内容的builder以及配置转场效果的options。关键信息指出该功能目前处于Beta阶段，支持无动画、上下切换及透明渐变等过渡方式，但不支持横竖屏切换和路由跳转。文档面向使用仓颉语言进行UI开发的程序员，提供了完整的接口说明和系统能力要求。
