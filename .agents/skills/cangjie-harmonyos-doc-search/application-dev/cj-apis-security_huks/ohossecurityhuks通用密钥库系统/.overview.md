# ohossecurityhuks通用密钥库系统

This directory provides API reference documentation for the OpenHarmony Universal KeyStore System (HUKS) specifically designed for the Cangjie programming language. It encompasses a wide range of cryptographic functionalities, including key generation, storage, import, export, and session management. The documentation details essential classes for defining algorithms, key sizes, padding modes, and access control, alongside functions for managing key lifecycles and secure operations. Targeted at HarmonyOS developers and security engineers, this resource offers the technical specifications required to implement hardware-backed key management and robust cryptographic features in OpenHarmony applications.
