This directory contains API reference documentation for the Cangjie `MessageSequence` class, a core component of the IPCKit designed for data serialization and deserialization in Inter-Process Communication (IPC) and Remote Procedure Calls (RPC). It covers methods for managing file descriptors, reading and writing various data types (integers, floats, strings, arrays), and handling memory buffers. The documentation is essential for Cangjie developers implementing efficient data transmission and resource management in IPC processes, providing detailed error codes and usage examples for robust application development.
