This directory contains comprehensive API documentation for the Cangjie programming language's `Statement` interface, which is essential for managing pre-executed SQL statements and database connections. It covers core database operations such as querying, updating, parameter binding, and option setting, while also addressing error handling for `SqlException`. Additionally, it provides critical information regarding deprecated functions and migration paths for legacy code. Key topics include the inheritance from the `Resource` type and the management of parameterized queries. This documentation is intended for software developers and database engineers working within the Cangjie environment who need to implement, maintain, or migrate database interaction logic. The directory includes references for both the main interface definition and specific deprecated utility functions to ensure smooth code transitions.
