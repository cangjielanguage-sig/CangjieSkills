# Canvas

本目录包含ArkUI框架下Canvas组件的API参考文档及示例，专为使用仓颉语言进行HarmonyOS应用开发的用户设计。内容涵盖了Canvas组件的初始化、事件处理、基础类型定义（如渲染设置、文本尺寸、渐变）以及具体的2D绘图代码示例。它旨在帮助开发者掌握在ArkUI中实现自定义2D图形绘制的能力，适用于需要构建高性能图形界面的开发者。

### 基础类型定义.md 基础类型定义.md
本文档是ArkUI框架下Cangjie语言的API参考文档，主要定义了Canvas渲染相关的基础类型。文档涵盖了三个核心类：用于配置渲染上下文属性（如抗锯齿）的RenderingContextSettings，包含只读宽高属性的TextMetrics文本尺寸类，以及用于创建渐变效果的CanvasGradient类。关键信息包括addColorStop方法用于定义渐变断点，所有组件均属于SystemCapability.ArkUI.ArkUI Full系统能力，起始版本为22。该文档面向使用Cangjie语言进行2D图形绘制的开发者，提供了构建渲染上下文和处理文本、渐变效果所需的数据结构定义。
