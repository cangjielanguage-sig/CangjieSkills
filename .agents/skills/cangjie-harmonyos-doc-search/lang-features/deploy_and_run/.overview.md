# deploy_and_run

The `deploy_and_run` directory serves as a comprehensive operational guide for the execution and distribution phases of the Cangjie programming language. It focuses on enabling developers to successfully run compiled executables across diverse operating environments, including Linux, macOS, and Windows. Key topics covered include direct binary execution, utilizing the `cjpm` package manager for project management, and the critical deployment of runtime libraries. This documentation is essential for developers and DevOps engineers who have completed the compilation stage and require precise instructions for testing, deploying, or distributing Cangjie applications in production or isolated settings.

## Quick Navigation

- **What do you want to do?**
    - Run a compiled program using binaries or cjpm? → Go to `run/`
    - Deploy the runtime environment for distribution? → Go to `runtime_deploy/`

## Detailed Description

### run/

This directory provides a guide for running Cangjie language executable programs, designed to help developers successfully execute programs in different environments. The content covers specific operational steps on Linux, macOS, and Windows systems, primarily divided into two modes: direct execution and running using `cjpm`. The documentation details the necessary runtime library deployment before running, how to locate compilation artifact paths, and the complete toolchain installation and specific command execution required when using `cjpm`. This guide is suitable for Cangjie developers who have completed compilation and are ready to test or deploy programs, providing a full-process operation reference from direct binary execution to project-level running management.

### runtime_deploy/

This directory is specifically dedicated to providing deployment documentation for the Cangjie runtime environment, aiming to solve the problem of running Cangjie executable programs in environments without a compiler. The content covers independent deployment processes on mainstream operating systems such as Linux, macOS, and Windows, including SDK downloads for different architectures, file extraction, and configuration methods for key environment variables (such as PATH, LD_LIBRARY_PATH, and DYLD_LIBRARY_PATH). The documentation emphasizes the importance of dynamic library path configuration, noting that programs that are not fully statically linked must have these variables set correctly to run. This resource is suitable for developers and operations personnel who need to distribute and run Cangjie applications in production or isolated environments.
