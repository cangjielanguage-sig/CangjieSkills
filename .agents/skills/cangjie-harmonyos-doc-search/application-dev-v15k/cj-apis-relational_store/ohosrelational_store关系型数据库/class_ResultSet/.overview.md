# class_ResultSet

This directory contains API reference documentation for the `ResultSet` class in the Cangjie language, designed for the HarmonyOS ArkData framework. It covers the functionality required to access, navigate, and manipulate data returned from relational database queries (RdbStore). Key topics include cursor navigation, data type retrieval (Strings, Integers, Blobs, Assets), and metadata management. This documentation is suitable for developers working with SQLite databases in Cangjie who need to efficiently iterate through query results, handle various data types, and manage database exceptions.
