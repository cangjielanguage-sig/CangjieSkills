# LocationButton

This directory provides comprehensive documentation for the LocationButton component within the ArkUI framework, specifically tailored for HarmonyOS developers using the Cangjie language. It focuses on a specialized UI element designed to request temporary precise location permissions without displaying a system popup dialog, thereby enhancing user experience. The documentation covers the complete API reference, including constructors and event callbacks, enumerations for visual styles and authorization results, and practical code examples for UI integration. This resource is essential for developers seeking to implement secure, customizable, and user-friendly location access controls in their applications while adhering to system capability requirements.

## Detailed Description

### LocationButton_5more.md LocationButton_5more.md
This document serves as API reference for the LocationButton component within the ArkUI framework, designed to grant temporary precise location permissions without requiring a system popup dialog. It covers component creation methods, including a default constructor and a customizable version accepting icon, text, and button type parameters. Key information includes the requirement to provide at least an icon or text, the static nature of these styles, and the onClick event callback which returns authorization results. Intended for Cangjie developers, this guide assists in implementing secure, user-friendly location access controls in applications.

### 基础类型定义.md 基础类型定义.md
This API reference document defines basic enumeration types for configuring location buttons within the ArkUI framework using the Cangjie language. It details three primary enumerations: LocationIconStyle for visual styles, LocationDescription for text labels, and LocationButtonOnClickResult for permission authorization outcomes. Key values include FullFilled and Lines for icons, various text options like CurrentLocation and ShareLocation, and Success or TemporaryAuthorizationFailed for click results. All definitions require SystemCapability.ArkUI.ArkUI.Full starting from version 20. This reference is intended for developers implementing location-based UI components in HarmonyOS applications.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating the implementation and customization of the LocationButton component in a Cangjie-based HarmonyOS application. It covers event handling for click results, UI layout construction using Row and Column, and various property configurations for the LocationButton. The code illustrates how to modify button attributes such as icon style, text description, background color, font size, and dimensions to create different location-related UI elements. This example is intended for HarmonyOS developers using the Cangjie language who need to integrate location request buttons into their user interfaces.
