# class_PerformanceTiming

本目录包含仓颉语言中 `PerformanceTiming` 类及相关变量的 API 参考文档，专注于网络性能监控与分析。内容涵盖了从 DNS 解析、TCP/TLS 连接到重定向、响应处理等各个阶段的耗时指标，以及请求总处理时间的记录。这些 API 基于 NetStack 系统能力，旨在帮助开发者精确测量网络请求性能，进行耗时分析与优化。适用于需要进行网络性能调优和监控的仓颉语言开发者。

## Detailed Description

### class_Performanc_10more_92939c6b.md class_Performanc_10more_92939c6b.md
本文档是 Cangjie 语言中 `PerformanceTiming` 类的 API 参考文档，用于记录以毫秒为单位的网络性能指标。文档详细列出了该类的多个属性，涵盖 DNS 解析、TCP/TLS 连接、重定向耗时以及响应头和响应体解析时间。此外，还包括首字节发送与接收时间及请求总完成时间。所有属性均为 Float64 类型，支持读写操作。该文档面向使用 NetStack 系统能力的开发者，旨在帮助其分析和优化网络请求性能。

### var_totalTiming_9c4cecb6.md var_totalTiming_9c4cecb6.md
本文档定义了用于记录网络请求处理耗时的 API 变量 `totalTiming`。涵盖了变量声明、功能描述、数据类型、读写权限、系统能力及起始版本信息。该变量为 Float64 类型，可读写，用于计算从请求回调到应用程序的耗时，属于通信网络栈系统能力，起始版本为 22。面向使用仓颉语言进行网络开发的开发者，用于性能监控和耗时分析。
