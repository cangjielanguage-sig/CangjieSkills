This directory contains API reference documentation for the `ohos.running_lock` module within the Cangjie programming environment. It focuses on power management, specifically preventing system sleep and controlling screen states using RunningLocks. The documentation covers the main module functions, the `RunningLock` class for lock management, and the `RunningLockType` enumeration for defining lock types like proximity control. It is suitable for HarmonyOS and Cangjie developers who need to manage device power states, keep the device awake during critical tasks, or implement sensor-based screen control features in their applications.
