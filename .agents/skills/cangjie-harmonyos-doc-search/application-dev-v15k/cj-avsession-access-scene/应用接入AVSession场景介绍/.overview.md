# 应用接入AVSession场景介绍

This directory provides a comprehensive technical guide for developers integrating the AVSession Kit into HarmonyOS applications. It covers essential scenarios for audio and video playback, including background task management, metadata configuration, playback state synchronization, and media control adaptation. Key topics include utilizing BackgroundTasks Kit for continuous playback, registering control commands, and handling hardware key events. This documentation is suitable for application developers using the Cangjie language who need to implement robust media features, ensure system-level UI integration, and manage the application lifecycle effectively during media operations.

## Detailed Description

### 创建后台任务.md 创建后台任务.md
This document serves as a technical guide for developers on implementing background tasks to prevent application suspension during operations like background playback. The content focuses on utilizing the BackgroundTasks Kit to apply for long-running tasks. Key information includes the specific requirement to use the AUDIO_PLAYBACK BackgroundMode for media playback scenarios to ensure the app avoids entering the Suspend state. This guide is intended for application developers seeking to maintain continuous execution in the background, specifically for media applications, and assumes familiarity with basic application lifecycle management.

### 应用接入AVSession场景介绍_4more.md 应用接入AVSession场景介绍_4more.md
This technical guide outlines the scenarios and integration process for AVSession Kit in audio and video applications. It covers mandatory scenarios like long audio and VOIP, the integration workflow, and specific session types such as Audio and Video. Key information includes the necessity of creating sessions, setting metadata, and registering commands to enable playback controls in the system's control center. The document explains that background playback requires BackgroundTasks Kit and provides code examples for session creation. This guide targets developers building media apps who need to manage playback states and system UI controls effectively.

### 设置元数据.md 设置元数据.md
This technical guide instructs developers on configuring session metadata for audio applications using the Cangjie language and AVSessionKit. It covers three main topics: general metadata display, synchronized lyrics integration, and media resource gold tags. Key information includes using the setAVMetadata method to populate AVMetadata objects with details like titles, artists, LRC lyrics, and audio source identifiers such as AudioVivid. This enables the system's playback control center to visualize and synchronize media information. The document targets application developers building audio features who require integration with system-level playback controls.

### 适配媒体通知.md 适配媒体通知.md
This document outlines the mechanism for adapting media notifications within the system. It clarifies that applications do not directly send media control notifications; instead, the system automatically generates them when the app correctly integrates with the media playback center and enters a playing state. The text highlights that the system manages the entire lifecycle of these notifications, including their display in the notification center and on the lock screen. This guide is intended for developers implementing media playback features, ensuring they understand the system's role in managing media control interfaces. Keywords: media notification, media playback center, system lifecycle, lock screen, notification center.

### 注册控制命令/
This directory provides technical guides for implementing media control commands in applications using the AVSessionKit framework and the Cangjie language. It covers essential playback features such as loop modes, fast forward, rewind, favorites, and progress seeking. The documentation details how to register specific commands, handle callbacks, and synchronize application states with the system's playback center. It is intended for HarmonyOS developers building media or telephony applications who need to integrate system-level media controls and ensure seamless user interaction with the playback interface.

### 设置播放状态/
This directory provides comprehensive technical guidance for developers on how to configure and manage media playback states within the system's control center using the AVSessionKit framework. It covers essential tasks such as updating playback status, managing progress bars, handling metadata, and addressing complex scenarios like trial listening and advertisements. Key topics include the `setAVPlaybackState` API, buffering logic, position tracking, and speed control. This documentation is specifically designed for application developers using the Cangjie language who need to synchronize their app's media player with the system UI and ensure accurate state reporting. By following these guides, developers can ensure a seamless media experience for users interacting with system-level controls.

### 适配蓝牙按键与有线按键事件/
This directory provides a comprehensive technical guide for developers on how to adapt Bluetooth and wired media key events within applications using the AVSession framework. It covers essential implementation strategies for handling media control commands, detailing the differences between abstract command registration and raw key event processing. Key topics include AVSession setup, AVMetadata configuration, and the specific callback mechanisms required for KeyEvent handling. The documentation emphasizes the critical necessity of setting metadata to ensure the system correctly routes events to the application. This content is specifically suitable for application developers seeking to integrate seamless media playback controls that function consistently regardless of whether the input source is Bluetooth or wired hardware, ensuring a unified user experience.
