This directory provides essential API reference documentation for the `NativeMediaPlayerBridge` class and related surface manipulation functions in the Cangjie programming language. It is centered around the technical implementation of bridging the ArkWeb kernel with custom, application-created media players, thereby enabling web components to exert control over native media playback. The documentation covers a wide array of functionalities, including detailed playback management (such as play, pause, and seek operations), complex state handling (suspend, resume, and release), and configuration options (volume, playback rate, and fullscreen modes). Additionally, it addresses the geometric manipulation of rendering surfaces. This resource is highly suitable for advanced developers and systems engineers working on ArkWeb applications who need to implement robust custom media player integrations, manage player lifecycles, and programmatically adjust surface positioning relative to web components.
