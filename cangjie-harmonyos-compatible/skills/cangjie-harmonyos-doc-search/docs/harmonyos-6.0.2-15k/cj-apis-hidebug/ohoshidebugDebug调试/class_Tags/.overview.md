# class_Tags

This directory contains API reference documentation for the `Tags` class in the Cangjie programming language, specifically designed for the HarmonyOS ecosystem. It defines a comprehensive set of bit-flag constants used to identify system modules and usage scenarios within the HiProfiler and HiDebug frameworks. The documentation covers a wide array of subsystems, ranging from Ability Manager and ArkUI to Distributed Hardware and Media. These resources are essential for developers and system engineers working on performance profiling, debugging, and system event categorization, requiring the SystemCapability.HiviewDFX.HiProfiler.HiDebug capability starting from API version 19.

## Detailed Description

The following files provide specific constant definitions and API references for the Tags class, categorized by the system modules they represent.

### class_Tags_10more.md class_Tags_10more.md
This document serves as API reference documentation for the Tags class in the Cangjie programming language, defining bit-flag constants used for identifying system modules and usage scenarios. The content details a comprehensive list of public static UInt64 constants, each representing a specific subsystem such as Ability Manager, ArkUI, Bluetooth, Distributed Hardware, and Media. Key information includes the specific bit-shifted values for each tag, their functional descriptions, and the required system capability SystemCapability.HiviewDFX.HiProfiler.HiDebug. Intended for developers working with system profiling or debugging tools starting from API version 19, this class facilitates precise categorization and filtering of system events.

### static_const_DISTRIBUTED__16more.md static_const_DISTRIBUTED__16more.md
This document serves as a reference for Cangjie language constant definitions used to tag various system modules within the HiProfiler and HiDebug frameworks. It lists 16 public static constants, including tags for distributed systems (Data, Hardware, Scheduler), core subsystems (Graphics, HDF, NET, FFRT), and media components (Image, Media). Each constant is a UInt64 bit flag (1 << n) associated with the SystemCapability.HiviewDFX.HiProfiler.HiDebug capability, starting from API version 19. This reference is intended for system developers and engineers working on performance profiling or debugging in the HarmonyOS ecosystem.

### static_const_NOTIFICATION_7more.md static_const_NOTIFICATION_7more.md

Key information includes that all constants map to the SystemCapability.HiviewDFX.HiProfiler.HiDebug capability and are available starting from API version 19.
