## 开发步骤

1. 导入[证书算法库框架模块](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md)。

    ```cangjie
    import kit.DeviceCertificateKit.*
    ```

2. [cert.createCertChainValidator](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md#func-createcertchainvalidatorstring)创建证书链校验器对象。

3. 基于已有的证书数据，创建证书链数据对象[CertChainData](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md#class-certchaindata)。

   证书算法库框架提供了证书链校验器对象可用于校验证书链，以验证信任链根源，但待校验的证书链数据对象应符合如下的数据结构定义。

   | 名称 | 类型 | 可读 | 可写 | 说明 |
   | -------- | -------- | -------- | -------- | -------- |
   | data | Array\<UInt8> | 是 | 是 | 证书数据，按照长度(2字节)-数据的形式传入。如08ABCDEFGH07ABCDEFG：第一本证书前2个字节表示证书的长度为8字节，后面附加8字节的证书数据；第二本证书前2个字节表示证书的长度为7字节，后面附加7字节的证书数据。 |
   | count | UInt32 | 是 | 是 | 传入的数据中，包含的证书数量。 |
   | encodingFormat | UInt32 | 是 | 是 | 指明证书编码格式。 |

4. 调用[CertChainValidator.validate](../../../API_Reference/source_zh_cn/apis/DeviceCertificateKit/cj-apis-cert.md#func-validatecertchaindata)校验证书链数据。
