# 组件属性

This directory contains API reference documentation for the ArkUI framework using the Cangjie language, focusing specifically on component properties for text and UI elements. It covers a wide range of functionalities including text styling, layout configuration, data detection, and interaction behaviors. Key topics include typography control, adaptive text layout, selection handling, and visual effects like shadows and decorations. The documentation is intended for software developers and UI engineers using Cangjie to build applications, providing detailed function signatures, parameters, and version requirements to implement precise and interactive user interfaces.
