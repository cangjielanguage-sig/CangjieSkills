# Web组件嵌套滚动

This directory provides a comprehensive guide on implementing nested scrolling for Web components within ArkUI scrollable containers. It addresses the technical challenges of creating a unified user experience when embedding web content into native applications. The content covers application scenarios, the `nestedScroll` property interface, specific scrolling behavior rules, and supported containers such as List and Grid. Key concepts include the `NestedScrollMode` enum (SelfOnly, SelfFirst, ParentFirst, Parallel) which dictates the interaction hierarchy between the Web component and its parent. It is specifically designed for ArkUI developers using the Cangjie language who need to manage complex, multi-layered scrolling interfaces in HarmonyOS applications.

## Detailed Description

The following files provide the theoretical background and practical implementation details for achieving nested scrolling in Web components.

### Web组件嵌套滚动_1.md
This technical guide explains how to implement nested scrolling for Web components within ArkUI scrollable containers to create a unified user experience. The document covers application scenarios, the nestedScroll property interface, scrolling behavior rules, supported containers like List and Grid, and input events. Key information includes the NestedScrollMode enum (SelfOnly, SelfFirst, ParentFirst, Parallel) which controls the interaction hierarchy between the Web component and its parent. It clarifies that unconsumed scroll offsets are passed to the nearest parent, and diagonal gestures resolve to the dominant axis. This guide targets ArkUI developers using Cangjie who need to integrate web content into complex, multi-layered scrolling interfaces.

### Web组件嵌套滚动_2.md
This document serves as a practical code example demonstrating the implementation of nested scrolling for Web components within a parent Scroll container using ArkUI. The primary focus is on the nestedScroll property, specifically configuring scrollForward and scrollBackward attributes. Key sections include a user interface with buttons to dynamically switch between four scrolling modes: SelfOnly, SelfFirst, ParentFirst, and Parallel. The code illustrates how these modes affect the interaction between the parent container and the embedded Web content. This example is designed for developers seeking to understand and implement complex scrolling coordination in HarmonyOS applications.
