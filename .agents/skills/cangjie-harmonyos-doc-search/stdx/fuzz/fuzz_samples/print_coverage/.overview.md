# print_coverage

本目录主要包含仓颉模糊测试工具中关于覆盖率打印特性的说明文档。该目录旨在指导开发者如何通过特定的启动参数来统计和分析函数测试的覆盖情况。内容涵盖了功能的基本概述、详细的编译配置要求（例如必须链接仓颉自带的 libfuzzer 库以及启用特定的 sanitizer 覆盖率选项），并提供了 C 语言与仓颉语言的输出示例对比。此功能作为实验性特性，不会干扰正常的 fuzz 过程，非常适合需要深入分析测试覆盖度的仓颉语言开发人员。核心关键词包括：仓颉、fuzzer、覆盖率、libfuzzer、sanitizer。

## 详细说明

### print_coverage.md print_coverage.md
本文档介绍了仓颉 fuzzer 的实验性特性，即通过启动参数打印覆盖率信息以统计函数测试情况。主要涵盖功能概述、编译配置要求（包括链接特定 libfuzzer 及启用特定编译选项），以及 C 语言和仓颉语言的输出示例对比。关键信息包括使用 `-print_coverage=1` 参数，必须链接仓颉自带的 libfuzzer 并启用特定的 sanitizer 覆盖率选项。文档指出该功能不影响 fuzz 过程，且仓颉语言输出目前暂不支持显示文件名和行号。适用于使用仓颉语言进行模糊测试的开发人员，旨在帮助其分析测试覆盖情况。关键词：仓颉、fuzzer、覆盖率、libfuzzer、sanitizer。
