This directory contains API reference documentation for the `BaseProfile` interface within the Cangjie language environment, specifically designed for managing Bluetooth profile connections in HarmonyOS applications. It covers essential functionalities including retrieving connected devices, checking connection states, and handling connection state change events through subscription and unsubscription mechanisms. Key topics include the `on` and `off` functions for event management, A2DP profiles, and security features like random MAC addresses. This documentation is suitable for developers using the ConnectivityKit who need to implement robust Bluetooth connectivity features and manage asynchronous event handling in their applications.
