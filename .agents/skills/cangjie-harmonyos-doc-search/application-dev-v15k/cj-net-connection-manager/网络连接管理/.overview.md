# 网络连接管理

This directory provides comprehensive documentation for managing network connections in the Cangjie development environment, specifically utilizing the NetworkKit. It covers essential topics such as domain name resolution, network state monitoring, capability querying, and connection migration. Key concepts include NetHandle objects, permission management (like `ohos.permission.INTERNET`), and handling network transitions between WiFi, cellular, and Ethernet. This resource is designed for Cangjie developers and application engineers seeking to build robust, network-aware applications with resilient connectivity and real-time status updates.

## Detailed Description

### 使用对应网络解析域名获取所有IP.md 使用对应网络解析域名获取所有IP.md
This technical guide explains how to resolve a domain name to retrieve all associated IP addresses using the default network in a Cangjie development environment. The document covers three essential steps: declaring the ohos.permission.INTERNET permission, importing the connection module from kit.NetworkKit, and invoking the getAddressesByName API. Key takeaways include understanding the normal permission level requirements and the specific syntax for calling the resolution function, which returns an array of NetAddress objects. This guide targets application developers implementing network resolution features who need to understand permission management and NetworkKit API usage.

### 接口说明.md 接口说明.md
This document serves as a concise API reference for the Cangjie NetworkKit, specifically focusing on network connection management interfaces. It categorizes functions into retrieving network handles, binding applications to specific networks, querying network capabilities and properties, resolving domain names, and subscribing to network state events. Key takeaways include methods for obtaining default or app-bound networks via NetHandle objects and monitoring availability or capability changes through callbacks. This technical reference is designed for Cangjie developers who need to implement robust network connectivity and status monitoring within their applications.

### 接收指定网络的状态变化通知.md 接收指定网络的状态变化通知.md
This document provides a step-by-step tutorial for developers on how to monitor and receive status change notifications for a specific network using the Cangjie language. It covers essential steps including declaring the required GET_NETWORK_INFO permission, importing the NetworkKit, and creating a NetConnection object with specific network capabilities and timeouts. Key information details the usage of methods like createNetConnection, register, and unregister, alongside event callbacks such as onNetAvailable and onNetUnavailable to handle network state changes. The guide includes a code example demonstrating the setup for a cellular network connection. This resource is intended for application developers building network-aware applications who need to manage network state listeners dynamically.

### 监控默认网络变化并主动重建网络连接_2more.md 监控默认网络变化并主动重建网络连接_2more.md
This technical guide explains how to monitor default network changes and proactively migrate application connections to new networks using the NetworkKit in Cangjie. It covers scenarios triggering network switches, such as weak WiFi signals, and details two main operations: monitoring network availability via the onNetAvailable callback and retrieving all connected networks using the getAllNets method. Key information includes the requirement to declare the ohos.permission.GET_NETWORK_INFO permission before accessing network lists. This guide targets Cangjie developers seeking to ensure application connectivity resilience during network transitions.

### 简介_4more.md 简介_4more.md
This document serves as an introductory guide for Network Connection Management, outlining capabilities like multi-network priority management, quality assessment, and DNS resolution. It defines core concepts such as network producers, consumers, detection, and optimization, while specifying Cangjie as the required development language. The text details typical scenarios including status change notifications, network information queries, and domain resolution. Intended for Cangjie developers, this overview provides the necessary context and definitions to implement robust network handling in applications, ensuring efficient switching and data usage across WiFi, cellular, and Ethernet connections.

### 根据数据网络查询网络的能力信息及连接信息/
This directory provides comprehensive technical documentation for querying network capabilities and connection properties within the HarmonyOS environment, specifically utilizing the Cangjie programming language. It details the complete workflow required for network state management, starting from permission declarations (such as `ohos.permission.GET_NETWORK_INFO`) to the practical implementation of NetworkKit APIs. Key functionalities covered include obtaining network handles via `getDefaultNet` or `getAllNets`, identifying network types like Cellular and Wi-Fi, and extracting specific features such as MMS or Internet access. Additionally, it explains how to retrieve link and routing details using `getConnectionProperties`. These resources are essential for developers aiming to build robust, network-aware applications that require real-time monitoring and dynamic adaptation to changing network conditions. By following these guides, developers can effectively manage network states and ensure optimal application performance across different connectivity scenarios.
