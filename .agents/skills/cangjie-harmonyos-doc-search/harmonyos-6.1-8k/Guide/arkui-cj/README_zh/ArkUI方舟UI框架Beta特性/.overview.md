## 详细描述

### ArkUI方舟UI框架Beta特性_1.md
本文档旨在介绍ArkUI方舟UI框架在Beta阶段发布的最新特性和功能更新。主要涵盖框架的新增组件、API变更、性能优化以及实验性功能的详细说明。关键信息包括Beta版本的具体改进点、兼容性说明以及开发者需要注意的变更事项，帮助用户快速掌握新能力。文档面向HarmonyOS应用开发者，适用于希望提前体验和测试ArkUI新特性的技术人群，建议具备基础的ArkUI开发知识。

### ArkUI方舟UI框架Beta特性_2.md
本文档是ArkUI框架Beta特性的综合指南，重点介绍基于仓颉语言的声明式UI开发范式。内容涵盖基本语法、自定义组件、状态管理（如@State、@Link等宏）、渲染控制、导航路由、各类布局、文本媒体、表单弹窗、交互事件及动画。核心要点在于利用宏实现状态同步与生命周期管理，以及构建响应式UI的最佳实践。面向使用仓颉语言的HarmonyOS开发者，本教程旨在指导用户掌握从基础组件到复杂交互的完整UI开发流程。

### ArkUI方舟UI框架Beta特性_3.md
本文档是ArkUI方舟UI框架Beta特性的导航索引，旨在指导开发者使用高级UI开发能力。主要涵盖动画系统（包括共享元素转场、动画曲线、模糊与阴影特效）、自定义绘制（Canvas）、混合开发、镜像能力、深浅色主题适配以及窗口和屏幕管理。所有列出的功能均处于Beta阶段，重点介绍了弹簧曲线、旋转屏动画等具体实现及系统级集成。该文档面向寻求实验性功能和高级交互体验的开发者，提供了构建动态界面和系统资源管理的参考指南。
