This directory provides a comprehensive technical guide for HarmonyOS application developers utilizing the Cangjie programming language, with a specific focus on enhancing application stability and user experience. It details the procedures for retrieving and handling abnormal application exit reasons, which is crucial for debugging and preventing future crashes. The documentation covers the necessary constraints and provides an in-depth look at the LaunchParam interface, accompanied by step-by-step development instructions. Developers will learn how to access vital diagnostic data, such as `lastExitReason` and `lastExitMessage`, directly within the `onCreate` lifecycle of `UIAbility` or `UIExtensionAbility`. Furthermore, the guide addresses the management of specific failure scenarios, including application freezes and resource control (RSS) issues. This resource is ideal for developers who need to implement robust crash analysis and recovery logic to ensure their applications perform reliably under all conditions.
