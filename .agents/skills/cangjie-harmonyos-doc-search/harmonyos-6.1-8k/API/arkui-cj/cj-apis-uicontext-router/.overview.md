# cj-apis-uicontext-router

This directory serves as a comprehensive resource for API reference documentation regarding the Router module within the ArkUI framework and the Cangjie programming language. It is specifically designed to address the implementation and management of in-application page navigation, which is a critical aspect of mobile app development. The documentation covers essential operations such as page jumping, replacement, and returning via URLs. Key topics include the Router class methods (e.g., `pushUrl`, `back`), mechanisms for passing parameters between pages, and the management of page stack states using the `RouterState` class and `RouterMode` enum. This content is tailored for developers utilizing ArkUI and Cangjie to build HarmonyOS applications, providing the necessary guidance to implement robust page routing logic and efficient data transmission.

## Detailed Description

### Router/

This subdirectory hosts the API reference documentation for the Router module, a core component of the ArkUI framework and Cangjie language ecosystem. Its primary focus is on the implementation and management of in-app page navigation, which is fundamental for creating a seamless user experience in HarmonyOS applications.

The documentation provides detailed insights into various navigation operations, including how to perform page jumps, replace current pages, and return to previous pages using URLs. It offers an in-depth look at the `Router` class, specifically its methods such as `pushUrl` and `back`, which are essential for controlling the navigation flow. Furthermore, it explains the mechanisms for parameter passing, ensuring data can be effectively transferred between different pages during navigation.

Additionally, the content covers the `RouterState` class and the `RouterMode` enum. These components are crucial for developers who need to manage the state of the page stack and define routing behaviors, such as distinguishing between Standard and Single modes. By providing these technical details, the documentation aims to assist developers in correctly implementing page routing logic and data transmission, ensuring their applications are both functional and user-friendly.
