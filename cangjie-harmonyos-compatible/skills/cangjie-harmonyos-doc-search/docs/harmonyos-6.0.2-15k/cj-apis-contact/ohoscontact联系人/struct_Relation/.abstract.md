This directory provides comprehensive API reference documentation for the `Relation` struct within the Cangjie programming language. It is specifically designed to facilitate the management of contact relationship types as part of the system's contacts data capability. The content covers the struct definition, a wide array of static constants representing specific relationship categories such as family, friends, and professional roles, and detailed constructor parameters including relationName, labelName, and labelId. Additionally, it explains the properties for custom labels and the necessary system capability requirements. This documentation is suitable for developers building applications that handle contact data, requiring a solid understanding of the Cangjie language and the contacts system framework.
