This directory contains API reference documentation for the `WebCookieManager` class in the Cangjie language, part of the ArkWeb framework. It covers comprehensive cookie management functionalities, including clearing cookies, configuring cookie strings, checking existence, fetching values, and managing permissions for both standard and third-party cookies. Key features include support for incognito mode, error handling, and system capability requirements. This documentation is suitable for Cangjie developers and application engineers working with WebView components who need to implement robust web data persistence, privacy controls, and session management within their applications.
