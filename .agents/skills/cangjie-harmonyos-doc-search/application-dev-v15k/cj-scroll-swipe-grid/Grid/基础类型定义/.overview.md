# 基础类型定义

This directory provides essential API reference documentation for fundamental data structures and classes used within the ArkUI framework's Grid components in the Cangjie language. It covers the core definitions required to configure complex grid layouts, manage scrollbar attributes programmatically, and handle sliding offsets and alignment directions. Key topics include custom item sizing, irregular grid arrangements, scrollbar geometry calculations, and axis definitions. These resources are tailored for developers seeking granular control over UI rendering and interaction behaviors in ArkUI applications.

## Detailed Description

### class_GridLayoutOptions.md class_GridLayoutOptions.md
This document serves as API reference documentation for the `GridLayoutOptions` class in the Cangjie language, designed to configure layout behaviors for Grid components in the ArkUI framework. The content focuses on the class constructor, detailing parameters for defining standard item sizes, identifying irregular item indexes, and setting callbacks for custom sizing and positioning. Key takeaways include the restriction that `regularSize` must be (1, 1), and the distinction between using `onGetIrregularSizeByIndex` for single-direction templates versus `onGetRectByIndex` for dual-direction templates to control item spans and coordinates. This guide is intended for developers implementing complex grid layouts with non-uniform item arrangements.

### struct_ComputedBarAttribute.md struct_ComputedBarAttribute.md
This document serves as API reference documentation for the `ComputedBarAttribute` struct in the Cangjie language, defining properties for scrollbar position and length within a Grid component. It details the struct definition, its read-only properties `totalOffset` and `totalLength`, and the constructor required to instantiate the object. Key information includes that both properties are of type `Float64`, measured in pixels, representing the Grid's total content length and its offset relative to the display area. The struct is available starting from API version 19. This reference is intended for developers building ArkUI applications who need to programmatically manage or calculate scrollbar attributes for Grid components.

### struct_OffsetOption_3more.md struct_OffsetOption_3more.md
This document provides API reference documentation for Cangjie language structures and enums within the ArkUI framework. It details the `OffsetOption` struct for handling sliding amounts, the `GridDirection` enum for defining main axis layout directions (Row, Column, etc.), and the `GridItemAlignment` enum for managing item alignment. Key information includes the read-only `offsetRemain` property measured in vp and specific behavioral constraints for the `STRETCH` alignment, which requires scrollable grids and regular item sizing. Intended for UI developers, this reference assumes familiarity with Cangjie syntax and grid layout concepts to effectively implement and customize Grid component behaviors.
