# class_DotIndicator

This directory contains comprehensive API reference documentation for the `DotIndicator` class within the Cangjie language and ArkUI framework. It focuses on the implementation and configuration of dot-style navigation indicators specifically designed for Swiper components. The documentation covers a wide range of functionalities, including basic class construction, dimension settings, color customization, and handling overflow scenarios. It provides essential details on default values, scaling effects, and constraints such as the lack of percentage support. This resource is highly suitable for UI developers and software engineers seeking to fine-tune the visual presentation and interactive behavior of navigation elements in their ArkUI applications.

## Detailed Description

### class_DotIndicator_7more.md
This document provides API reference documentation for the DotIndicator class in the Cangjie language, designed to configure dot-style navigation indicators for Swiper components within the ArkUI framework. It details the class constructor and several configuration methods such as color, itemWidth, itemHeight, mask, and maxDisplayCount. Key information includes default dimension values of 6vp, a 1.33x scaling effect on press, and specific constraints like the lack of percentage support for dimensions. The documentation also explains overflow behavior when navigation points exceed the maximum display count, noting that interaction is disabled in this mode. This reference is intended for developers building UIs who need precise control over Swiper navigation aesthetics and behavior.

### func_selectedColorResource_3more.md
This API reference document details methods for customizing the appearance of the selected state in Swiper component dot indicators within the ArkUI framework. It covers three specific functions: selectedColor, selectedItemHeight, and selectedItemWidth, each defining parameters, types, and default values. Key information includes the ability to set the indicator color, height, and width, with specific default values like 6vp for height and 12vp for width. Notably, dimension properties do not support percentage values. This guide is intended for UI developers using the Cangjie language to style Swiper navigation elements.
