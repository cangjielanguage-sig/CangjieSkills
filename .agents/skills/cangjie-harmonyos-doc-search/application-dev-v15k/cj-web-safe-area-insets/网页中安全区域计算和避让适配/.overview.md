# 网页中安全区域计算和避让适配

This directory provides a comprehensive technical guide on calculating and adapting safe areas within web components to ensure optimal UI display in immersive mode. It addresses the complex challenges posed by non-rectangular displays and system regions, such as status bars and navigation bars, by leveraging W3C CSS standards and specific ArkWeb APIs. Key topics include the `expandSafeArea` API, the `viewport-fit` meta tag, and `safe-area-inset` variables for precise layout adjustment. This content is specifically suitable for ArkWeb developers utilizing Cangjie, HTML, and CSS who need to prevent content overlap and achieve full-screen immersive layouts effectively. By following these guides, developers can ensure their applications dynamically adjust to various screen shapes and system UI constraints, providing a seamless user experience across different devices and screen configurations.

## Detailed Description

### 实现场景.md 实现场景.md
This technical guide instructs developers on implementing immersive effects for Web components to extend content into system safe areas. It covers enabling immersive mode via the expandSafeArea API, configuring viewport behavior using the viewport-fit meta tag, and applying CSS env() functions for element avoidance. Key concepts include using viewport-fit=cover to allow full-screen coverage and safe-area-inset-* variables within CSS to calculate padding and prevent overlap with status or navigation bars. Targeted at ArkWeb developers using Cangjie and HTML/CSS, this guide ensures proper UI adaptation for non-rectangular displays or immersive layouts.

### 概述.md 概述.md
This document provides an overview of safe area concepts and adaptation mechanisms for Web components operating in immersive mode. It covers the definition of safe areas versus non-safe system regions like status bars and navigation bars, highlighting potential overlap issues. The text explains how the ArkWeb kernel utilizes W3C CSS standards to dynamically calculate safe area insets, enabling developers to adapt layouts for irregular screens. Key takeaways include the automatic monitoring of component positions and the calculation of required avoidance distances. This guide targets web developers seeking to ensure proper UI display and prevent element overlap in immersive environments.
