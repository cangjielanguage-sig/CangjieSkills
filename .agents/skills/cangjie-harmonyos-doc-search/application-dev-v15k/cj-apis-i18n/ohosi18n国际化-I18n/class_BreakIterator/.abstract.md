This directory contains API reference documentation for the `BreakIterator` class within the Cangjie programming language's LocalizationKit. It focuses on text boundary analysis and segmentation, which are critical components for internationalization (I18n) features. The documentation details member functions used for navigating and manipulating text boundaries, including methods like `current`, `first`, `following`, and `last`. It is specifically designed for software developers implementing text processing logic who need to programmatically handle line breaks and text segments in Cangjie applications.
