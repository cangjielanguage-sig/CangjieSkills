This directory contains documentation related to "Classes," primarily focusing on the Cangjie programming language's SQL database package. It includes API references for database management classes like DriverManager and PooledDatasource, as well as detailed mappings for deprecated SQL data type wrappers. The content covers both standard and nullable type conversions between SQL and Cangjie native types. Additionally, there is a placeholder file for general class concepts. This resource is suitable for Cangjie developers, software engineers, and students working with database connectivity or maintaining legacy code involving SQL type mappings.
