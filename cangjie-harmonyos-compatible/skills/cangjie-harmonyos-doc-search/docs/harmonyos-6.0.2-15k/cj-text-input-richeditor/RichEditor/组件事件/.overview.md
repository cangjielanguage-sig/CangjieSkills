# 组件事件

This directory provides comprehensive API reference documentation for event handling functions within the ArkUI RichEditor component, utilizing the Cangjie language. It covers the full spectrum of text manipulation events, ranging from input interception and deletion management to selection changes and clipboard operations. Key functionalities include handling IME (Input Method Editor) interactions, overriding default system behaviors for copy and cut actions, and receiving notifications for content changes. This resource is designed for software developers who require precise control over user interactions and state management when constructing rich text editing interfaces in ArkUI applications.

## Detailed Description

### func_aboutToIMEInputRichEd_7more.md
This document serves as API reference documentation for event handling functions within the ArkUI RichEditor component using the Cangjie language. It details seven specific functions: aboutToIMEInput, aboutToDelete, onDeleteComplete, onDidChange, onIMEInputComplete, onPaste, and onReady. Key information includes how these functions manage the text manipulation lifecycle, allowing developers to intercept and control input and deletion events via boolean callbacks, implement custom paste logic, and receive notifications upon initialization or content changes. The target audience is software developers utilizing ArkUI system capabilities to build rich text editing interfaces.

### func_onDidIMEInputTextR_bc82f009.md
This API reference document details the onDidIMEInput function used to handle events triggered after an Input Method Editor (IME) completes text input. The content covers the function signature, system capabilities, version requirements, and a parameter table defining the callback. Key information includes that the function accepts a required callback parameter of type (TextRange) -> Unit, where TextRange specifies the range of the input content. The function returns This to support method chaining. This documentation targets ArkUI developers needing to manage text input behaviors in applications running on API version 20 or higher.

### func_onSelectRichEditorSel_6more.md
This document serves as API reference documentation for event handling functions within a RichEditor component in the ArkUI framework using the Cangjie language. It details six specific functions: onSelect, onSelectionChange, onSubmit, onEditingChange, onCopy, and onCut. Key information includes function signatures, system capabilities, version requirements, and parameter definitions for managing text selection, cursor changes, keyboard submission, and clipboard operations. The document explains how to override default system behaviors for copy and cut actions. The target audience is software developers implementing rich text editing interfaces who need to handle user interactions and state changes programmatically.
