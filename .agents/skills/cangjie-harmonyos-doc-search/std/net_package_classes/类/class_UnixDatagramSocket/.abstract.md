This directory contains API reference documentation for the `UnixDatagramSocket` class in the Cangjie programming language. It covers the implementation of host communication using Unix Domain Sockets (UDS), focusing on datagram-oriented messaging. Key topics include socket initialization, lifecycle management (binding, connecting, closing), data transmission (send/receive), and configuration options. The documentation highlights platform-specific behaviors, such as file system interactions and Windows incompatibility. It is suitable for Cangjie developers and network programmers building low-level inter-process communication (IPC) systems who need precise control over socket behavior and exception handling.
