# 按键事件

This directory provides comprehensive documentation for handling key input events within the ArkUI framework using the Cangjie language. It covers the fundamental definitions of the `KeyEvent` class, the implementation of the `onKeyEvent` callback for capturing hardware input, and practical code examples for real-world application. Key topics include event propagation control, device identification, and focus management for UI components. This resource is specifically designed for software developers building HarmonyOS applications who require robust logic for processing keyboard and remote control interactions.

## Detailed Description

### 基础类型定义.md 基础类型定义.md
This API reference document defines the KeyEvent class for handling key input events within the ArkUI framework using the Cangjie language. It details the class structure, listing properties such as isStopPropagation, keyText, keyType, keyCode, keySource, metaKey, deviceId, and timestamp, along with their types and read-write capabilities. Additionally, it documents the class constructor which initializes these properties. Key information includes the ability to control event propagation and identify specific input devices and timestamps. This documentation targets software developers working on ArkUI applications who need to implement keyboard or input device event handling logic.

### 按键事件_3more.md 按键事件_3more.md
This document serves as an API reference for handling key events triggered by keyboards or remote controls within the ArkUI framework. It covers the definition of key events, permission requirements, and details the `onKeyEvent` function signature. Key information includes that these events apply to focusable components like Button, while non-focusable ones like Text require specific settings. The `onKeyEvent` method accepts a callback parameter of type `KeyEvent` and is available starting from version 12. This guide targets developers implementing interactive UI components who need to capture user input via hardware keys. Keywords: ArkUI, KeyEvent, onKeyEvent, focusable, callback, API reference.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating how to handle key events within a Cangjie-based HarmonyOS application. The main topic is UI event handling, specifically capturing keyboard input. The code defines an EntryView component containing a Button that utilizes the onKeyEvent callback. When triggered, this callback extracts event details such as keyType, keyCode, keyText, deviceId, metaKey, and timestamp. These details are then bound to a state variable to update the UI display and logged via AppLog. This serves as a reference for developers implementing keyboard interactions, requiring knowledge of the Cangjie language and UIKit framework.
