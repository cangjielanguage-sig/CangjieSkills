# 定位步骤与思路

This directory provides a comprehensive technical guide for diagnosing and troubleshooting application unresponsiveness (appfreeze) and performance issues in HarmonyOS and Android environments. It covers the full workflow from log acquisition and basic information extraction to advanced analysis of Binder IPC, EventHandler mechanisms, and stack traces. Key topics include FaultLog retrieval, Hilog correlation, and interpreting timeout thresholds. Designed for developers, QA engineers, and system performance analysts, these resources equip users with the methodologies to pinpoint root causes of system freezes and thread blocking.

## Detailed Description

### 定位步骤与思路_2more.md 定位步骤与思路_2more.md
This technical guide outlines the methodology for diagnosing application unresponsiveness issues. It covers the general workflow of log acquisition and analysis, specifically detailing how to retrieve fault logs managed by the FaultLog module. Key information includes two primary retrieval methods: using DevEco Studio for automatic archiving or utilizing the hiAppEvent interface for subscription-based monitoring. The document emphasizes combining basic log information with hilog and trace data to pinpoint specific failure locations. This guide targets developers troubleshooting HarmonyOS applications, requiring familiarity with development tools and log analysis.

### 查看_binder_信息.md 查看_binder_信息.md
This technical troubleshooting guide explains how to analyze Android Binder IPC logs to diagnose application freeze (appfreeze) root causes. It details the capture timing for different fault types and covers four main analysis areas: tracing binder call chains to identify blocking peers, diagnosing IPC_FULL states where thread exhaustion or buffer limits cause blocking, evaluating wait times to distinguish root causes from frequent short calls, and handling transient stack discrepancies. Key concepts include interpreting ready thread counts, free_async_space consumption, and understanding capture delays. Intended for Android system engineers or performance analysts familiar with IPC mechanisms and stack traces, this document helps pinpoint issues like lock contention or high async load.

### 确认基本信息.md 确认基本信息.md
This technical reference guide explains how to extract and interpret basic information from HarmonyOS appfreeze logs to diagnose application stability issues. Main sections include identifying process details like PID and foreground status, determining fault timestamps, and referencing a comprehensive table of detection durations for various fault types such as THREAD_BLOCK and LIFECYCLE_TIMEOUT. Key takeaways include specific timeout thresholds, such as 6 seconds for thread blocks, and the cumulative counting mechanism for background applications, which requires five consecutive 3-second blocks before reporting a 6-second error. Intended for developers and QA engineers troubleshooting app freezes, this guide requires familiarity with log analysis and HarmonyOS system architecture.

### 结合_hilog_2more.md 结合_hilog_2more.md
This technical guide instructs developers on analyzing application freezes (appfreeze) by correlating Hilog logs and Trace data. It details DFX log types like fault reporting and stack traces, outlines steps to pinpoint freeze timing based on log output patterns, and explains Trace analysis for main thread congestion or function timeouts. Key takeaways include identifying freeze origins by checking for log silence or excessive output, and diagnosing performance bottlenecks like dense animation loops or specific interface delays. Intended for system engineers troubleshooting app stability and performance issues, this document requires familiarity with debugging tools and system logs.

### 查看_eventHandler_信息/
This directory serves as a technical resource for developers and performance engineers focused on analyzing EventHandler dump logs to diagnose application freezes and system responsiveness issues. It provides in-depth instructions on examining current running statuses, history event queues, and specific priority queue configurations. Key topics include methods for calculating task duration using timestamps, understanding the functional roles of VIP and High priority queues, and identifying scheduling starvation. The documentation covers specific mechanisms such as ArkUI input transmission chains and periodic watchdog tasks, making it suitable for those troubleshooting thread scheduling and event handling bottlenecks.

### 查看_stack_信息/
This directory contains technical guides and stack trace analysis documents focused on debugging application issues within the HarmonyOS/OpenHarmony environment. It covers diagnosing application freezes (appfreeze), analyzing IPC communication failures, troubleshooting SQLite database operations, and resolving resource loading errors. The content provides specific examples of stack traces, explaining how to interpret Pid/Tid, identify mutex locks, and distinguish between frozen and busy threads. These resources are suitable for system developers, debuggers, and engineers proficient in C++, NAPI, and decompiling tools who need to diagnose runtime performance issues or crashes.
