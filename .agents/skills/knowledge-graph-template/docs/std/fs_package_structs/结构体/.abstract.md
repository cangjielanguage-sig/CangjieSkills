This directory contains API reference documentation for core data structures within the Cangjie programming language's file system package. It focuses on essential structs used for low-level file I/O operations, file metadata inspection, and cross-platform path manipulation. Key topics include file handle management, attribute queries, permission handling, and path normalization across Windows and Unix systems. This documentation is suitable for Cangjie developers who require precise programmatic control over file system entities and need to understand the underlying mechanics of file operations and path handling in their applications.
