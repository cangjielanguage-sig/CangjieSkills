## 接口说明

以下是UTD常用接口说明，对于预置数据类型和应用自定义数据类型同样适用，更多接口和详细说明，请参见[ohos.uniformTypeDescriptor (标准化数据定义与描述)](../../API_Reference/source_zh_cn/apis/ArkData/cj-apis-uniformTypeDescriptor.md)。

| 接口名称                                                     | 描述                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| UniformDataType                                              | 标准化数据类型的枚举定义。此处不再展开列举各枚举。 |
| belongsTo(utype: String): Bool                             | 判断当前标准化数据类型是否归属于指定的标准化数据类型。       |
| isLowerLevelType(utype: String): Bool                      | 判断当前标准化数据类型是否是指定标准化数据类型的低层级类型。 |
| isHigherLevelType(utype: String): Bool                     | 判断当前标准化数据类型是否是指定标准化数据类型的高层级类型。 |
| getUniformDataTypeByFilenameExtension(filenameExtension: String, belongsTo!: String = ""): String | 根据给定的文件后缀名和所归属的标准化数据类型查询标准化数据类型ID。若有多个符合条件的标准化数据类型ID，则返回第一个。 |
| getUniformDataTypeByMIMEType(mimeType: String, belongsTo!: String = ""): String | 根据给定的MIME类型和所归属的标准化数据类型查询标准化数据类型ID。若有多个符合条件的标准化数据类型ID，则返回第一个。 |
