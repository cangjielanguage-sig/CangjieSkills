# cj-notification-badge

This directory provides a comprehensive development guide focused on the implementation and management of notification badges for application icons. It serves as a technical resource for displaying unread message counts, covering essential interface specifications and logic rules such as clearing badges when counts reach zero or displaying "99+" for large numbers. The guide provides detailed step-by-step coding procedures, highlighting the usage of the `setBadgeNumber()` function for manual count adjustments and the `NotificationRequest` field for automatic badge increments upon notification arrival. It includes practical Cangjie code examples for importing necessary modules and handling updates. This documentation is specifically tailored for application developers who possess a working knowledge of the NotificationKit module and seek to enhance user experience through effective notification handling.
