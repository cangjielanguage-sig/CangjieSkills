# pattern_refutability

本目录专门针对仓颉编程语言中的模式可反驳性进行了系统性的定义与解释。在仓颉的类型系统中，理解模式是否可能匹配失败对于保证程序逻辑的正确性至关重要。本目录详细阐述了“可反驳模式”与“不可反驳模式”的区别，并涵盖了常量、通配符、绑定、元组、类型及枚举等多种模式的具体匹配特性。特别是针对元组和枚举模式，文档深入剖析了其在特定条件下才满足不可反驳性的复杂规则。这是一份面向仓颉开发者的核心语言参考指南，旨在帮助开发者深入掌握模式匹配的底层逻辑，从而在编写分支判断、变量绑定等代码时，能够利用编译器的检查机制，编写出更加健壮、安全且符合语言规范的代码。

## Detailed Description

### pattern_refutability.md

本文档旨在定义和解释仓颉编程语言中模式的可反驳性，区分了可能匹配失败的“可反驳模式”与总是匹配成功的“不可反驳模式”。文档涵盖了常量、通配符、绑定、元组、类型及枚举模式，详细说明了各类模式的匹配特性，特别是元组和枚举模式在特定条件下才为不可反驳模式的规则。这是一份语言参考指南，面向需要深入理解模式匹配逻辑的仓颉开发者，旨在帮助其编写更健壮的代码。
