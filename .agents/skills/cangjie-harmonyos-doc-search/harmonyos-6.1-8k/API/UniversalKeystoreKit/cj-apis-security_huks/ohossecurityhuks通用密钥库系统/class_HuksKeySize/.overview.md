# class_HuksKeySize

本目录包含关于HarmonyOS通用密钥库（HUKS）中`HuksKeySize`类的文档，主要面向使用Cangjie语言进行开发的用户。该目录详细定义了用于存储各种加密算法密钥长度常量的类结构，涵盖了RSA、ECC、AES、CURVE25519、DH、SM2及SM4等主流算法。所有常量均为UInt32类型，属于SystemCapability.Security.Huks.Core系统能力，起始版本为22。这些文档旨在为开发者提供标准化的密钥配置参数，确保在密钥生成和加密操作中正确指定密钥长度，适用于需要实现高安全性加密功能的HarmonyOS应用开发者。

## 详细描述

### class_HuksKeySiz_10more_0649a392.md
本文档定义了Cangjie语言中的HuksKeySize类，用于存储HUKS系统中各种加密算法的密钥长度常量。文档涵盖了RSA、ECC、AES、CURVE25519、DH、SM2及SM4等算法的密钥尺寸定义，详细列出了如HUKS_AES_KEY_SIZE_128等常量的具体比特长度和类型。所有常量均为UInt32类型，属于SystemCapability.Security.Huks.Core系统能力，起始版本为22，为配置加密密钥提供标准化数值。该文档面向使用Cangjie语言开发HarmonyOS应用安全功能的开发者，用于在加密操作中指定密钥长度。

### static_const_HUK_10more_c3f6e44d.md
该文档是一份API参考文档，定义了鸿蒙通用密钥库（HUKS）中用于指定不同加密算法密钥长度的静态常量。主要涵盖了ECC、RSA、SM2和SM4算法的多种密钥尺寸规格，如384位、2048位等。所有常量均为UInt32类型，属于SystemCapability.Security.Huks.Core系统能力，起始版本为22。这些定义旨在为使用Cangjie语言进行安全开发的开发者提供标准化的参数，确保在密钥生成或加密操作中正确配置密钥长度。
