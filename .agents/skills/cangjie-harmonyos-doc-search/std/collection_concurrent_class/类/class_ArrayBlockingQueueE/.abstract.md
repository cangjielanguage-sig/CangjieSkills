This directory contains API reference documentation for the `ArrayBlockingQueue` class in the Cangjie programming language. It focuses on a thread-safe, array-based blocking queue with a fixed capacity, essential for concurrent data handling. The documentation covers class initialization, properties, and various element manipulation methods, including blocking, non-blocking, and timed operations. It also highlights deprecated methods and their modern replacements. This resource is suitable for Cangjie developers implementing concurrent data structures who need precise control over bounded queue operations, thread synchronization, and capacity management.
