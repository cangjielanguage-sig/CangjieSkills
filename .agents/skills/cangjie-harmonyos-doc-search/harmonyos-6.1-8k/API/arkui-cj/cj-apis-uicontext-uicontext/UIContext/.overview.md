# UIContext

UIContext 目录提供了 ArkUI 框架下关于 UI 上下文管理的核心模块文档。该模块旨在为开发者提供 UI 状态管理、动画控制、单位转换及交互式对话框等功能支持。内容涵盖模块导入方式、API 接口说明以及仓颉语言下的具体实现细节。适用于使用 ArkUI 框架和仓颉语言进行 HarmonyOS 应用开发的开发者，帮助他们实现屏幕适配、动态效果及界面交互逻辑。
