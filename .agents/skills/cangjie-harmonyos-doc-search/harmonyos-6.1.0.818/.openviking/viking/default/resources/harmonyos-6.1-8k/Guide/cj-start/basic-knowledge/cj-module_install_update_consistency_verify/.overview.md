# cj-module_install_update_consistency_verify

本目录详细阐述了多模块应用在安装与更新过程中的签名证书及配置文件一致性校验规则，核心目标是确保应用的安全性与合法性。文档内容涵盖了签名证书一致性校验和配置文件一致性校验两大关键领域，深入解析了 appId、bundleName、versionCode 等关键字段在初始安装及不同版本更新场景下的具体验证逻辑。作为一份重要的技术参考文档，它主要面向应用开发者和打包人员，旨在帮助相关人员深入理解系统对应用合法性的验证机制，特别是在处理多模块协同开发时必须遵守的配置约束与版本管理要求，从而有效避免因配置不一致导致的安装失败或安全风险。
