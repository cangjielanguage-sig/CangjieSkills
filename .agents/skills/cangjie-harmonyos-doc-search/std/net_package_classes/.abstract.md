The `net_package_classes` directory serves as the definitive API reference documentation for the Cangjie standard library's networking classes. It provides a structured overview of the components essential for modern network programming, focusing heavily on the implementation and management of network protocols. The directory covers critical areas such as IP address management for both IPv4 and IPv6 standards, various socket operations (including TCP, UDP, and Raw sockets), and Unix Domain Sockets utilized for inter-process communication. Within this directory, developers will find detailed documentation regarding class definitions, properties, methods, and exception handling mechanisms. This resource is primarily intended for Cangjie developers and software engineers who are looking to implement robust network protocols, effectively manage socket connections, and ensure precise address validation in their application development workflows.
