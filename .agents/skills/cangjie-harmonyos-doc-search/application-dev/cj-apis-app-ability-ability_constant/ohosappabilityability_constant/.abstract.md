This directory contains API reference documentation for the `ohos.app.ability.ability_constant` module within the HarmonyOS Cangjie SDK. It focuses on constants and enumerations that define the lifecycle states, memory levels, launch reasons, and window modes for Ability components. Key topics include ability migration, crash recovery, and system resource management. This documentation is suitable for HarmonyOS application developers using the Cangjie language who need to handle application lifecycle events, optimize performance based on memory status, or implement cross-device continuation features.
