# generic_class

本目录深入探讨了仓颉编程语言中泛型类的核心概念与实际应用。文档详细阐述了泛型类的声明语法、类型参数的使用方法，以及如何通过Hashable和Equatable等接口施加约束。特别强调了静态成员在泛型环境下的行为差异，解释了为何在静态成员的声明和初始化中不能引用类型参数。这份资料适合具备仓颉语言基础的开发者，旨在通过规范化的讲解，帮助读者深入理解泛型编程的边界与最佳实践，从而编写出更安全、高效的代码。

## Detailed Description

### generic_class.md

本文档旨在介绍仓颉编程语言中泛型类的定义、使用及相关约束。主要涵盖了泛型类的声明语法、类型参数约束（如Hashable与Equatable），以及静态成员在泛型类中的特殊限制。核心要点指出，由于静态成员内存共享，其声明和初始化表达式中严禁引用类型参数或包含未实例化的泛型类型。这是一份面向开发者的语言特性教程，适合已了解基础语法的用户阅读，帮助其掌握泛型编程规范。关键词：泛型类、类型参数、泛型约束、静态成员、仓颉语言。
