This directory provides comprehensive documentation on the supported scenarios for module loading and interoperability within the HarmonyOS Cangjie development environment. It focuses on the technical mechanisms required to integrate Cangjie code with various module types, including HAR, HSP, Native, System, and HAP modules. Key topics cover dynamic loading strategies, configuration specifications in `oh-package.json5` and `build-profile.json5`, and the practical application of the `requireArkModule` function. This resource is essential for HarmonyOS developers aiming to achieve seamless cross-language communication between Cangjie and ArkTS, manage complex dependencies, and optimize module interactions in their applications. The directory includes specific guides on general loading scenarios and detailed technical instructions for handling HAR, HSP, and Native modules.
