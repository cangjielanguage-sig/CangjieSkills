# 类

本目录包含 Cangjie 语言 JSON 库的核心类定义文档，详细介绍了用于构建和操作 JSON 数据的各种类结构。内容涵盖了从基础的布尔值、数值、字符串到复杂的数组和对象类型，以及核心的 `JsonValue` 基类。这些文档提供了完整的 API 参考，包括构造函数、类型识别、数据获取及序列化方法。核心关键词包括 Cangjie、JSON、API、encoding_json、序列化、数据类型。该目录适合需要在 Cangjie 项目中进行 JSON 数据解析、编码、转换及处理的开发者查阅。
