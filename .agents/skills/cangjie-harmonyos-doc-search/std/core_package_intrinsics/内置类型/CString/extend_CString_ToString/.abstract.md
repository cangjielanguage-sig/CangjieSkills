This directory contains API documentation for extending the Cangjie `CString` type to implement the `ToString` interface and adding essential string manipulation methods. It covers functions for resource management, lexicographical comparison, suffix/prefix validation, and memory-safe operations like `subCString` and `toString`. Key topics include C interoperability, unsafe memory operations, and null-safety checks. This documentation is suitable for Cangjie developers working with low-level string handling and interfacing with C libraries.
