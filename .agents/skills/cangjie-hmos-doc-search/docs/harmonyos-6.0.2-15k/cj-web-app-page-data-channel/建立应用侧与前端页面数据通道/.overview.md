# 建立应用侧与前端页面数据通道

This directory serves as a comprehensive technical resource for developers working within the HarmonyOS ecosystem, specifically focusing on the integration of native application logic with web-based frontend components. It provides a complete walkthrough for establishing a robust, bidirectional data channel using Message Ports. The content covers the entire implementation pipeline, starting from the native side using the Cangjie language and ArkWeb components, through to the frontend implementation using HTML and JavaScript. Key technical concepts include port creation, event registration, data serialization (handling strings and ArrayBuffers), and message passing mechanisms. This guide is essential for HarmonyOS developers aiming to build high-performance hybrid applications that require seamless and efficient communication between the native runtime and web content, ensuring a cohesive and responsive user experience.

## Detailed Description

#### 建立应用侧与前端页面数据通道_1.md 建立应用侧与前端页面数据通道_1.md
This document provides a tutorial on establishing a bidirectional data channel between the application side and a frontend web page using message ports. It details the application-side implementation using Cangjie code, demonstrating the creation of message ports, event registration, and message transmission. Key steps include creating ports via `createWebMessagePorts()`, registering a callback on one port, and transferring the other port to the HTML side using `postMessage()`. The code example illustrates handling string and array buffer message types. This guide targets HarmonyOS developers using the Cangjie language and ArkWeb components who need to integrate web content with native application logic.

#### 建立应用侧与前端页面数据通道_2.md 建立应用侧与前端页面数据通道_2.md
This document provides an HTML and JavaScript example demonstrating how to establish a bidirectional data channel between a WebView frontend and a native Cangjie application using Message Ports. Topics covered include port initialization via the `__init_port__` event, handling incoming messages from the native side, and sending data back to the application. Key takeaways involve saving the transferred port object, parsing string or ArrayBuffer data types, and using `postMessage` for communication. This tutorial is intended for developers implementing hybrid application features requiring efficient native-web interaction.
