# ast_package_funcs

This directory serves as a comprehensive resource for the `ast_package_funcs` module within the Cangjie programming language ecosystem. It focuses on providing API reference documentation for utility functions essential for metaprogramming, macro expansion, and Abstract Syntax Tree (AST) manipulation. The content covers critical functionalities such as lexical analysis, token comparison, parsing tokens into AST nodes (including declarations, expressions, patterns, and types), diagnostic reporting, and inter-macro communication. This documentation is specifically designed for developers working on compiler tools, creating custom macros, or performing source code analysis, offering the necessary interfaces to validate contexts, handle errors, and programmatically construct or inspect code structures. By leveraging these APIs, developers can achieve fine-grained control over the compilation process, enabling the creation of robust, domain-specific language extensions and sophisticated code analysis tools that integrate seamlessly with the Cangjie environment.
