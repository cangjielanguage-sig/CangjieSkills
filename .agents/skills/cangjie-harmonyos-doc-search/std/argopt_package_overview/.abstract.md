This directory contains the comprehensive API overview documentation for the `std.argopt` package, a specialized library designed for parsing command-line argument strings into structured names and values. It thoroughly covers the functional definitions of various argument types, distinguishing between short options, long options, short-prefixed long options, and non-options, while also explaining special delimiter rules. The documentation details the primary `parseArguments` function, the deprecated `ArgOpt` class, enums for `ArgumentMode` and `ArgumentSpec`, the `ParsedArguments` struct, and exception handling mechanisms. This resource is suitable for developers implementing command-line interfaces who need a deep understanding of argument specifications and parsing logic to build robust applications. By providing a clear breakdown of the API, it ensures that developers can effectively integrate argument parsing into their software projects. It serves as the foundational reference for understanding the package's architecture and operational behavior.
