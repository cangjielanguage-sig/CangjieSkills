# 基础类型定义

This directory contains API reference documentation for fundamental styling classes within the Cangjie ArkUI framework. It covers definitions for background board styles, visual indicators, tab bar icons, and specific navigation components like bottom and sub-tab bars. Key topics include layout configurations, resource handling, and visual property customization such as colors, borders, and text overflow. This documentation is suitable for UI developers and system architects using the Cangjie language to build and style user interfaces, providing the necessary structural definitions to implement precise and adaptive component styling.

## Detailed Description

### class_BoardStyle.md class_BoardStyle.md
This document provides API reference documentation for the Cangjie BoardStyle class, used to define background board styles in the ArkUI framework. It covers the class definition, the read-only borderRadius property, and the constructor method. Key information includes that borderRadius specifies the corner radius in viewport units, defaults to 8.0.vp, does not support percentages, and accepts values from zero to infinity. Intended for developers building user interfaces, this document explains how to instantiate and configure board styling objects using the Length type.

### class_IndicatorStyle.md class_IndicatorStyle.md
This API reference document details the IndicatorStyle class in the Cangjie language, designed to configure the visual appearance of underline indicators within the ArkUI framework. The content outlines the class structure, read-only properties including color, height, width, borderRadius, and marginTop, and the constructor with default parameters. Key information specifies that length properties do not support percentages and that a width of 0.0.vp automatically matches the text width. Intended for UI developers, this documentation requires familiarity with ArkUI components and Cangjie syntax to effectively customize interface elements.

### class_TabBarIconStyle_3more.md class_TabBarIconStyle_3more.md
This API reference document defines styling and layout configurations for TabBar components within the Cangjie ArkUI framework. It details the TabBarIconStyle class for managing icon colors, alongside the LayoutMode and SelectedMode enums for content arrangement and selection visuals. Key information includes the TabBarIconStyle constructor, which accepts ResourceColor parameters for selected and unselected states—applicable only to SVG sources—and the specific behaviors of AUTO, VERTICAL, and HORIZONTAL layouts. Intended for Cangjie developers, this documentation requires familiarity with ArkUI system capabilities and resource types to effectively customize tab bar interfaces.
