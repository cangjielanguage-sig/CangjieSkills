# cj-audio-call-overview

This directory contains essential technical documentation for developers working on audio call implementations. It provides a comprehensive overview that clearly distinguishes between VoIP and cellular communication modes, highlighting critical architectural differences such as VoIP's reliance on IP networks versus the system-restricted nature of cellular calls. The content covers vital development tasks including the configuration of audio scene modes, the implementation of various ring modes (Silent, Vibrate, Normal), and the complex logic required for audio device switching. By utilizing specific APIs like `AudioManager` and `AudioVolumeGroupManager`, developers can manage audio states effectively and ensure proper hardware interaction. This resource is specifically suitable for application developers who need to integrate complex audio call features and must understand the underlying system audio behaviors to ensure a seamless, professional user experience across different devices and scenarios.

## Detailed Description

### cj-audio-call-overview.md cj-audio-call-overview.md
This document serves as a foundational guide for audio call development, offering a detailed technical comparison between VoIP and cellular communication modes. It emphasizes that VoIP calls operate over IP networks and are generally available to third-party developers, whereas cellular calls are privileged operations restricted to system applications. The guide provides specific instructions on managing audio scenes, particularly the `AUDIO_SCENE_VOICE_CHAT` mode, which developers must configure using the `AudioManager` to ensure optimal voice quality. Furthermore, it outlines the necessary logic for audio device switching, enabling the application to handle transitions between different audio outputs correctly. The document also delves into the management of ring modes, categorizing them into Silent, Vibrate, and Normal states. It instructs developers on the use of `AudioVolumeGroupManager` to programmatically adjust volume settings and control vibration feedback. This comprehensive overview is designed for application developers who need to master system audio behaviors and API usage to successfully implement robust audio call features in their applications. By following these guidelines, developers can ensure their applications adhere to system standards and provide a consistent user experience during voice interactions, avoiding common pitfalls related to audio routing and state management.
