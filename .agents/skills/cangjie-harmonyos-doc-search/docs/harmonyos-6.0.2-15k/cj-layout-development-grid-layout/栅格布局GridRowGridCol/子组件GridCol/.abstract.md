This directory contains API documentation for the `GridCol` sub-component within the Cangjie UI framework (ArkUI). It focuses on grid layout management, specifically controlling column behavior through attributes like span, offset, and order. The documentation covers responsive design strategies using breakpoints (xs to xxl) and fixed values, enabling developers to create adaptive interfaces. It is suitable for UI developers using the Cangjie programming language who need to implement flexible and responsive grid systems in their applications.
