This document serves as a technical guide for developers on the creation and verification of certificate chain validator objects. It covers the fundamental concept of a certificate chain, illustrating the hierarchical relationship between root, intermediate, and end-entity certificates using a specific GlobalSign example. Key information includes the explanation of how a self-signed root certificate issues an intermediate certificate, which subsequently signs the third-level certificate. The document highlights that developers can reference these structural examples to construct certificate chain data from existing certificates. Intended for software engineers implementing security features, this guide provides the necessary context for understanding certificate hierarchies before implementation.
