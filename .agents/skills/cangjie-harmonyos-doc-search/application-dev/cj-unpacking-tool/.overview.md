# cj-unpacking-tool

The `cj-unpacking-tool` directory contains a specialized utility designed for the OpenHarmony ecosystem, focusing on the decompression and parsing of application packages. It supports various formats, including HAP, HSP, and App files, providing developers with the means to extract configuration data and inspect package contents efficiently. The tool offers dual-mode functionality, supporting both command-line usage for quick tasks and Java API integration for seamless embedding into larger software projects. Additionally, it includes detailed schema definitions for critical internal data structures like `AppInfo` and `AbilityInfo`. This documentation is essential for developers building application markets, package management tools, or those debugging application bundles. Users should have a solid understanding of Java and HarmonyOS package structures to utilize this resource effectively.

## Detailed Description

### 拆包工具/

This directory provides comprehensive documentation for the OpenHarmony Unpacking Tool, a utility designed for decompressing and parsing application packages such as HAP, HSP, and App files. The documentation is structured to assist developers in two main ways: through command-line usage for direct interaction and via Java API integration for embedding the tool's functionality into custom applications.

Key topics covered include the extraction of configuration data and the inspection of package contents. Additionally, the documentation offers schema definitions for internal data structures like `AppInfo` and `AbilityInfo`, which are crucial for understanding the metadata of OpenHarmony applications. This resource is highly suitable for developers building application markets, package management tools, or those needing to debug application bundles. However, it requires a prerequisite knowledge of Java and HarmonyOS package structures to be used effectively.

**Key capabilities documented include:**
*   **Package Parsing:** Handling HAP, HSP, and App file formats.
*   **Data Extraction:** Retrieving configuration data and inspecting contents.
*   **Integration:** Guidance on using the Java API within other projects.
*   **Schema Reference:** Definitions for `AppInfo` and `AbilityInfo`.
