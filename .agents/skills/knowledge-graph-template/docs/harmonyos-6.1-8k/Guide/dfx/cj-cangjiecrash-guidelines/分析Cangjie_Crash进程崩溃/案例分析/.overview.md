# 案例分析

本目录包含仓颉语言中异常处理的案例分析，涵盖了Error类和Exception类两大核心内容。文档详细讲解了内存溢出、栈溢出等系统级错误的排查方法，以及开发者如何自定义异常、使用try-catch机制捕获和处理标准库异常。通过Crash日志解读和堆栈分析，帮助开发者定位故障根因。适合仓颉语言开发者及需要提升程序健壮性的技术人员阅读。

## 详细描述

### Error_类案例分析.md Error_类案例分析.md
本文档旨在分析仓颉语言中由系统内部错误或资源耗尽引发的Error类异常，重点讲解OutOfMemoryError和StackOverflowError。文档涵盖异常定义、内存不足异常案例源码、Crash日志解读及根因分析方法。关键信息指出调用栈对内存错误的参考意义有限，建议结合DevEco Studio Profiler工具分析内存开销、代码逻辑及cjHeapSize配置。这是一份面向仓颉开发者的故障排查指南，适用于解决运行时崩溃和资源耗尽问题。

### Exception_类案例分析/
本目录包含关于仓颉语言中 Exception 类异常处理的案例分析文档。内容涵盖了开发者如何自主抛出异常、定义自定义异常、使用 try-catch 机制捕获标准库异常，以及如何通过堆栈日志定位和修复因未处理异常导致的 Crash 问题。核心关键词包括异常处理、堆栈分析、故障排查、NoneValueException。适合仓颉语言开发者及需要提升程序健壮性的技术人员阅读。
