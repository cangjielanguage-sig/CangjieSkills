This directory serves as a dedicated educational resource designed to help developers master the HashMap data structure within the Cangjie programming language. It provides a detailed, step-by-step practical tutorial that focuses heavily on the implementation of three core functionalities essential for effective data management: adding new entries to the collection, retrieving specific values based on unique keys, and checking for the existence of keys within the map. The guide highlights critical programming concepts such as properly initializing a `HashMap<String, Int64>`, safely managing the `Option` return type using `getOrThrow`, and accurately interpreting boolean results from existence checks. This material is highly suitable for Cangjie beginners who are looking to understand collection types, as well as experienced developers requiring a concise, executable reference guide for standard map operations and data structure manipulation.
