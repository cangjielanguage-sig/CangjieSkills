# cj-bm-tool

This directory serves as a comprehensive technical repository for the `cj-bm-tool`, specifically focusing on the Bundle Manager (bm) command-line utility within the HarmonyOS operating system environment. It provides in-depth documentation regarding the complete application lifecycle management, including the installation and uninstallation of HAP (HarmonyOS Ability Package) files, querying detailed application information, and managing shared library dependencies. Furthermore, it addresses advanced technical requirements such as Ahead-Of-Time (AOT) compilation processes. The documentation also serves as a critical troubleshooting resource, offering solutions for common error codes associated with deployment failures, signature verification issues, and system configuration problems. This collection is primarily intended for Cangjie developers, system administrators, and QA engineers who require robust command-line tools to debug, maintain, and deploy applications effectively.

## Detailed Description

### bm工具/
This directory contains technical documentation for the Bundle Manager (bm) tool, a command-line utility designed for managing application lifecycles on HarmonyOS. It covers essential operations such as installing and uninstalling HAP packages, querying application information, managing shared library dependencies, and handling AOT compilation. Additionally, it includes a comprehensive collection of troubleshooting guides for common error codes related to deployment, signature verification, and configuration. This resource is suitable for Cangjie developers, system administrators, and QA engineers who need to debug, maintain, or deploy applications efficiently via the command line.
