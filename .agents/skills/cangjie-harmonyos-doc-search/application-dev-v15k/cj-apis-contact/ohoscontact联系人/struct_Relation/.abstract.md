This directory provides comprehensive API reference documentation for the `Relation` struct within the Cangjie language's `ContactsData` system capability. It is designed to assist developers in defining and managing various contact relationship types effectively. The content covers essential components such as the struct's constructor, properties like `labelId`, and a wide array of static constants representing specific relationships ranging from family members to professional roles. Additionally, it explains the mapping of these relationships to unique Int32 identifiers, support for custom labels, and the handling of invalid label IDs. This documentation is suitable for developers working on contact applications who are familiar with Cangjie syntax and system capabilities starting from version 19.
