This directory contains comprehensive API reference documentation for core interfaces in the Cangjie programming language. It covers fundamental type system components including interoperability with C (CType), collection management (Collection, Iterable), comparison operations (Comparable, Equatable), hashing (Hashable, Hasher), and utility functions (ToString, Resource). Additionally, it details the root type hierarchy (Any) and specialized interfaces for counting and concurrency. This documentation is essential for Cangjie developers seeking to understand type constraints, implement custom data structures, manage object lifecycles, or utilize standard library features for generic programming and operator overloading.
