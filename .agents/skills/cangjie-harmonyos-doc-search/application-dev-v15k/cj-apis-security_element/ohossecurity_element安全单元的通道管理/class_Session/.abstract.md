This directory contains API reference documentation for the Cangjie `Session` class and related channel management functions used in Secure Element (SE) communication. It covers the lifecycle management of sessions with SE readers, including methods to open basic and logical channels according to the ISO 7816-4 protocol. Key topics include session handling, channel opening, error code management, and system capability requirements. This documentation is suitable for developers implementing secure element access, managing SE connections, and handling communication exceptions within the Cangjie framework.
