# cj-apis-color_manager

This directory serves as a comprehensive resource for the OpenHarmony graphics color management module, specifically tailored for the Cangjie programming language. ## Detailed Description

### [1] ohosgraphicscolor_space_manager色彩管理/

This directory provides the complete API reference documentation for the OpenHarmony graphics color management module, specifically developed using the Cangjie language. It serves as a technical guide for the ArkGraphics2D color management core capabilities, focusing on the definition, management, and creation logic of various color spaces. The content addresses the handling of standard color gamuts widely used in the industry, such as Srgb and DisplayP3, while also offering comprehensive support for developers needing to implement custom color gamuts for specialized hardware or artistic requirements.

The documentation details the usage of several critical components necessary for advanced graphics programming. The `ColorSpaceManager` class is highlighted as the primary interface for managing these color spaces effectively within an application's lifecycle. Additionally, the `ColorSpacePrimaries` class is explained in the context of defining the fundamental chromaticity coordinates that determine the range of colors, while the `ColorSpace` enumeration provides a structured way to reference different color standards. Developers will also find instructions on how to query specific technical parameters, including Gamma values for tone mapping curves, white point values for color temperature calibration, and the exact coordinates of the red, green, and blue primaries. This module is indispensable for developers working on graphics rendering engines, performing system-level color correction, or developing applications that require advanced image processing features to ensure color accuracy and consistency across different devices.
