# cj-apis-file_storage_statistics

This directory serves as a comprehensive technical resource for the `cj-apis-file_storage_statistics` module, specifically designed for the HarmonyOS ecosystem using the Cangjie programming language. It focuses on providing detailed API references and structural definitions necessary for developers to query, monitor, and manage device storage space effectively. The content covers critical aspects such as retrieving total internal storage capacity, checking available free space, and analyzing granular application-specific usage, including installation packages, cache sizes, and data file volumes. By leveraging the `SystemCapability.FileManagement.StorageService.SpatialStatistics` capability, this documentation enables the creation of storage-aware applications that can dynamically respond to storage conditions. It is highly suitable for Cangjie developers and system engineers aiming to optimize application performance, prevent storage-related crashes, and implement robust storage management features within their HarmonyOS projects. The documentation ensures that developers have the necessary tools to handle storage-related errors and maintain system stability efficiently.
