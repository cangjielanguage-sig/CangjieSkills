# 开发步骤

This directory serves as a technical resource for Cangjie developers aiming to implement and understand crash event subscription within HarmonyOS applications using the HiAppEvent module. It covers the end-to-end development process, including importing necessary dependencies, configuring Watchers with AppEventFilters, and simulating crash scenarios via UI triggers. The documentation explains critical behaviors such as the callback mechanisms for crash data, the differences in stack unwinding between CjError and NativeCrash, and the reporting timing for caught versus uncaught exceptions. Furthermore, it provides examples of raw log outputs to aid in debugging APP_CRASH events. This guide is essential for developers using DevEco Studio who need to monitor application stability, interpret crash logs, and handle system-level exceptions effectively to ensure a robust user experience.

## Detailed Description

### 开发步骤_1.md

This tutorial guides developers through implementing crash event subscription in a Cangjie application using the HiAppEvent module. It covers importing dependencies, configuring a Watcher with an AppEventFilter in the onCreate function, and creating a UI button to trigger a crash scenario. Key information includes the callback mechanism for processing crash data, distinguishing between CjError and NativeCrash stack unwinding processes. It explains that uncaught crashes report on the next app launch, while caught crashes report before exit. Targeted at Cangjie developers using DevEco Studio, this guide ensures proper monitoring and handling of system crash events.

### 开发步骤_2.md

This document provides a raw log output demonstrating the capture of an application crash event using the HiAppEvent framework. It details the specific parameters captured during an APP_CRASH event, including system metadata, process identifiers, and exception details. The log shows a CjError crash for com.example.myapplication, containing the exception stack, timestamp, PID, UID, and paths to external log files. This is intended for developers debugging application stability issues or learning how to implement event monitoring in HarmonyOS.
