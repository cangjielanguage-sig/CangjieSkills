This directory contains API reference documentation for the Cangjie AVPlayer class, a core component of the MediaKit designed for managing and playing multimedia resources. It covers a comprehensive range of functionalities including playback control, track management, event handling, property configuration, and resource management. Developers can find details on audio/video streaming, subtitle support, and adaptive bitrate control. The documentation is intended for software engineers and developers building multimedia applications in the Cangjie language who need precise control over media playback states, system capabilities, and error handling.
