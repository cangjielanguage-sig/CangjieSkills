This directory provides comprehensive API reference documentation for the `AudioHapticManager` class, a core component of the Cangjie AudioHaptic Kit. It is designed to assist developers in implementing sophisticated audio-haptic coordination features within multimedia applications. The documentation covers the complete lifecycle of audio and vibration management, from initializing the manager instance and registering resource URIs to configuring playback settings like latency and stream types. It includes detailed specifications on system capabilities, parameter constraints, return values, and error codes (such as parameter errors and permission denials). Specifically, it addresses the prerequisite `ohos.permission.VIBRATE` permission and methods for resource management. This resource is essential for developers aiming to create immersive, synchronized sensory experiences in their applications.
