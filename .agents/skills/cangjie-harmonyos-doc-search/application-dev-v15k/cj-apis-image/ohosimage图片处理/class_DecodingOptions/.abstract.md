This directory contains API reference documentation for the `DecodingOptions` class within the Cangjie programming language. It focuses on configuration settings for image decoding processes, specifically targeting the ImageSource system capability. Key topics covered include defining output dimensions, pixel formats, color spaces, dynamic ranges (HDR/SDR), and rotation settings. The documentation details class definitions, constructors, and specific properties such as `desiredSize`, `editable`, and `sampleSize`. This resource is suitable for software developers and multimedia application engineers working with image processing in Cangjie who need precise control over how images are decoded and rendered.
