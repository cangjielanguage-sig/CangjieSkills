# class_HuksKeyAlg

本目录包含 `HuksKeyAlg` 类的 API 参考文档，主要用于定义 HarmonyOS 通用密钥库（HUKS）系统中的密钥算法类型。内容涵盖了 RSA、ECC、AES、HMAC 以及国密算法（SM2、SM3、SM4）等多种加密、哈希和密钥交换算法的常量定义。所有常量均为 UInt32 类型，属于 `SystemCapability.Security.Huks.Core` 系统能力，起始版本为 22。该文档适用于使用仓颉语言进行 HarmonyOS 安全开发的开发者，旨在提供指定加密算法所需的枚举值和常量参考。
