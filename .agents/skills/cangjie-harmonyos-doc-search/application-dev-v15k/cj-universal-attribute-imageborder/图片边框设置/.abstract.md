This directory provides comprehensive documentation and resources for configuring image borders within the ArkUI framework using the Cangjie programming language. It covers the `borderImage` API, fundamental data type definitions for gradients and border options, and practical code examples for dynamic styling. Key topics include linear gradients, border repetition modes, and interactive UI controls. This content is suitable for Cangjie developers and UI designers working on HarmonyOS applications who need to implement advanced visual effects and complex border rendering starting from API version 19.
