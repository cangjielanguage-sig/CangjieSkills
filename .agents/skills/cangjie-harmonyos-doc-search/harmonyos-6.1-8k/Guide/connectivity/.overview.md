# connectivity

This directory contains documentation for the Connectivity Kit, focusing on short-range communication services within the HarmonyOS and OpenHarmony ecosystems. It covers essential technologies such as Bluetooth (including BLE and A2DP) and WLAN (STA, P2P, AP modes). The content is designed for developers using the Cangjie programming language, providing guides on device discovery, connection management, and data transmission. As the service is currently in Beta, the documentation emphasizes connection state management and user authorization requirements. It serves as a comprehensive resource for engineers integrating and optimizing communication capabilities in their applications.

## Detailed Description

### README_zh/
This directory acts as the Chinese documentation entry point for the Connectivity Kit (short-range communication service), designed to provide developers with a systematic index of development documentation and a functional overview. It primarily covers the basic introduction to Connectivity Kit, a core glossary, and detailed Bluetooth service development guides. The content involves key sub-chapters such as Bluetooth technology overview, device discovery mechanisms, connection management, and data transmission. The document specifically notes that the service is currently in a Beta feature stage and provides an in-depth explanation of the full Bluetooth Low Energy (BLE) development process, including device discovery, GATT connection establishment, and data interaction operations. This directory is highly suitable for engineers developing short-range communication applications, particularly those focused on the integration and optimization of Bluetooth functions.

### bluetooth/
This directory serves as a centralized repository for technical documentation and development guides focused on Bluetooth technologies within the HarmonyOS and OpenHarmony ecosystems. It specifically targets developers using the Cangjie programming language.

### cj-connectivity-kit-intro/
This directory contains the introductory documentation for the Connectivity Kit, aiming to provide guidance for developers building application services using basic communication capabilities such as Bluetooth and WLAN. The documentation details the core concepts and functional features of Bluetooth technology (including BLE and A2DP modules) and WLAN technology (including STA, P2P, and AP modes). As the service is currently in the Beta stage, the documentation emphasizes that applications need to actively manage connection states and must obtain explicit user authorization when utilizing device capabilities. This guide is very suitable for beginners wishing to quickly get started with connection function development, while also providing links to API references and detailed development guides, making it an important starting point for developing related applications.

### cj-terminology/
The `cj-terminology` directory functions as a specialized glossary and reference hub for the Connectivity Kit, specifically curated for professionals involved in Bluetooth technology development. It provides rigorous definitions and explanations of critical terms.
