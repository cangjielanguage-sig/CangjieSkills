This directory contains API reference documentation for the `ohos.ability.interop` module, focusing on interoperability between Cangjie and ArkTS in HarmonyOS applications. This documentation is intended for HarmonyOS developers working with API level 19 and above who need to integrate ArkTS components with native Cangjie code.
