This directory serves as a comprehensive repository for API reference documentation regarding the HarmonyOS Accessibility module, specifically tailored for the Cangjie programming language. It encompasses a wide array of technical specifications essential for developing barrier-free applications, including detailed definitions for accessibility service management, event handling mechanisms, gesture simulation, and caption styling. The content covers critical components such as ability states, event types, capabilities, and action enumerations. Designed for developers targeting system version 19, this documentation provides the necessary tools and guidelines to create assistive technologies that support users with visual, auditory, or motor impairments, ensuring a more inclusive user experience.
