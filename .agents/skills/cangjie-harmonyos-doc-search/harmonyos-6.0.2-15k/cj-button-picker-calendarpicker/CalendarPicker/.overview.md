# CalendarPicker

This directory contains documentation and resources for the CalendarPicker component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of a dropdown calendar popup for date selection, including API references, basic type definitions, and practical code examples. Key topics include component initialization, configuration attributes like edgeAlign and textStyle, event handling, and state management. This content is suitable for HarmonyOS developers and Cangjie programmers looking to integrate customizable date selection functionality into their applications.

Intended for developers using the ArkUI framework, this guide provides the necessary syntax and parameters to implement and customize date pickers within their applications.

### 基础类型定义.md 基础类型定义.md
This API reference document defines basic types for configuring calendar picker components in the Cangjie language within the ArkUI framework. It details the CalendarOptions class for setting parameters like selection radius and date, and the CalendarAlign enum for defining alignment modes. Key properties include hintRadius for background styling and selected for the current date, while the enum supports START, CENTER, and END alignment. Targeted at developers using HarmonyOS ArkUI, this documentation requires knowledge of Cangjie syntax and UI component configuration.
