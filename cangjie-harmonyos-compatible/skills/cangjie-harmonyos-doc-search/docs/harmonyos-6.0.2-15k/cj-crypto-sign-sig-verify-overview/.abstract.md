This directory serves as a comprehensive overview for the `cj-crypto` library, specifically focusing on the critical domains of digital signature generation and verification. It is an essential resource for understanding how to maintain data integrity and verify sender identity in modern software applications. The documentation covers a broad spectrum of cryptographic algorithms, detailing the nuances of DSA, SM2, Ed25519, ECDSA, and RSA. Beyond just listing algorithms, it provides vital information on parameter construction, supported key types, and digest combinations, all tailored for API version 12+. This guide is specifically curated for developers and security engineers who need to ensure their implementations are secure, compliant, and correctly instantiated within the cryptographic framework, ultimately protecting systems against fraud and unauthorized access.
