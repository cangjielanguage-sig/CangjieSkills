# cj-macro-reusable

This directory serves as a comprehensive technical resource for the `cj-macro-reusable` project, specifically focusing on the implementation and optimization of the `@Reusable` macro within the Cangjie ArkUI framework. Whether you are optimizing existing code or building new interfaces from scratch, this guide provides the necessary tools to succeed.
