# 自定义注解

本目录详细介绍了仓颉语言中自定义注解的定义、使用规则及其与反射机制的配合。内容涵盖了注解类的声明约束（例如必须提供 const init）、使用语法、不可重复性、不可继承性，以及如何通过 target 参数限定注解的适用范围。核心关键词包括自定义注解、反射、元数据、AnnotationKind、const init。本文档主要面向需要利用反射获取元数据以支持复杂逻辑的开发者，帮助他们深入理解注解系统的运作机制。

## Detailed Description

### 自定义注解_1.md

本文档介绍了仓颉语言中自定义注解的定义、使用规则及其与反射机制的配合。主要涵盖注解类的声明约束（如必须提供 const init）、使用语法、不可重复性、不可继承性，以及通过 target 参数限定注解适用范围。关键信息指出，自定义注解通过 @Annotation 修饰类创建，参数需为常量表达式，且支持通过 AnnotationKind 限制应用于类型、函数或变量等特定位置。本文档面向需要利用反射获取元数据以支持复杂逻辑的开发者。
