This directory provides comprehensive documentation for the `expandSafeArea` universal attribute within the ArkUI framework, specifically tailored for the Cangjie programming language. It is designed to assist developers in implementing immersive layouts by allowing UI components to extend their rendering into system-defined safe areas, such as status bars and navigation bars. The content thoroughly covers the function signature, parameters for defining expansion types and edges, and essential usage constraints, including specific limitations related to fixed dimensions and scroll containers. Furthermore, it addresses potential side effects like system event interception in extended regions. This resource is best suited for ArkUI developers who possess a solid understanding of basic UI layout principles and system window management and are seeking technical guidance to achieve edge-to-edge display integration.
