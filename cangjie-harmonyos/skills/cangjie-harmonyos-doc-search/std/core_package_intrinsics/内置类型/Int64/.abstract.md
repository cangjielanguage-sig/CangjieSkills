This directory provides comprehensive API reference documentation for the Int64 type within the Cangjie programming language. It focuses on the definition, range, and extended functionalities of 64-bit signed integers. Key topics include static properties for maximum and minimum values, interface implementations for comparisons and arithmetic, and type conversion mechanisms. The documentation covers essential methods such as compare, next, position, and toString. This resource is designed for Cangjie developers who need to implement mathematical operations, handle data comparisons, or perform string conversions on Int64 values in their software projects.
