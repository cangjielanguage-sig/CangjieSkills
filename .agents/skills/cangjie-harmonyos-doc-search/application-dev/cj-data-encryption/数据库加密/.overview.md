# 数据库加密

This directory serves as a technical repository for database encryption implementations within the HarmonyOS development environment, specifically tailored for the Cangjie language and ArkData framework. It addresses the critical need for data security by detailing how to encrypt both relational and Key-Value (KV) databases effectively. The content covers the complete lifecycle of setting up encryption, from retrieving application contexts to configuring specific security parameters like the `encrypt` attribute and security levels. It emphasizes that encryption must be established at the moment of database creation. Designed for HarmonyOS developers and application engineers, these guides provide the necessary code snippets and architectural knowledge to secure sensitive user data against unauthorized access, ensuring compliance with modern security standards.

## Detailed Description

### 关系型数据库加密.md 关系型数据库加密.md
This technical tutorial guides developers on implementing encryption for relational databases using the Cangjie language. The document is divided into two main sections: retrieving the application context and configuring database encryption settings. Key takeaways include the necessity of importing specific ArkData kits and setting the encrypt attribute to true within the StoreConfig object, while also defining a security level. The content provides specific code snippets demonstrating how to initialize the database with these security parameters. Intended for HarmonyOS developers, this guide assumes prior knowledge of Cangjie syntax and basic database management concepts.

### 数据库加密_3more.md 数据库加密_3more.md
This guide explains how to implement database encryption to enhance data security and integrity for application storage. It covers the encryption scenario overview and specific implementation steps for Key-Value databases. Key information includes that encryption is configured at database creation and cannot be changed later. For Key-Value stores, developers must set the encrypt parameter to true within the KVOptions configuration. The document provides Cangjie code examples for context retrieval and store creation. This is intended for application developers using the ArkData framework and Cangjie programming language who need to secure sensitive data.
