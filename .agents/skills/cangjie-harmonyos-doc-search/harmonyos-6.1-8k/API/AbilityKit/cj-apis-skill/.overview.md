# cj-apis-skill

This directory serves as a comprehensive repository for the API reference documentation of the `ohos.skill` module, specifically authored in the Cangjie programming language. It is dedicated to elucidating the mechanisms of Skills and URI handling, which are pivotal for HarmonyOS application development. The documentation rigorously defines the `SkillUri` and `Skill` classes, which are essential for describing URI protocols, path matching rules, and validating application attributes like actions, entities, and domain names. By supporting MIME types and UniformDataType specifications, these APIs enable core functionalities such as inter-application jumps, data sharing, and intent matching. This resource is tailored for developers who possess a foundational understanding of Cangjie syntax and are working within the HarmonyOS system framework, including components like BundleManager and Ability.

## Detailed Description

### ohosskill/

This subdirectory contains the complete API reference documentation for the `ohos.skill` module, written in the Cangjie language. It covers the essential Skill and URI handling mechanisms required for HarmonyOS application development.

Key aspects of the documentation include:
- **Class Definitions**: Detailed descriptions of the `SkillUri` class and the `Skill` class.
- **URI Handling**: Explanation of URI protocols and path matching rules.
- **Application Attributes**: Validation rules for actions, entities, and domain names.
- **Data Standards**: Support for MIME types and UniformDataType specifications.

These components are fundamental for developers looking to implement inter-application jumps, facilitate data sharing, and manage intent matching. The content assumes the reader has a basic knowledge of Cangjie syntax and familiarity with the HarmonyOS system framework, such as BundleManager and Ability.
