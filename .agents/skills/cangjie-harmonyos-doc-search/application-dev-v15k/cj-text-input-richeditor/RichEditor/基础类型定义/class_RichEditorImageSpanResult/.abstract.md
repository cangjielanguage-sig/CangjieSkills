This directory provides comprehensive API reference documentation for the `RichEditorImageSpanResult` class, a fundamental component in the Cangjie programming language designed for the ArkUI framework. It serves as a critical resource for developers tasked with encapsulating and managing image information returned by backend systems within rich text editing environments. The documentation thoroughly explores the class architecture, detailing essential properties such as image dimensions, vertical alignment modes, object fit settings, and image styling attributes. It also specifies read-write access for key fields like `valuePixelMap`, `spanPosition`, and `offsetInSpan`, which are vital for tracking image content and text ranges. Covering API versions 12 through 19, this guide ensures developers have the necessary information to implement robust image handling features. It is specifically suitable for software engineers and UI developers building advanced rich text interfaces who require deep integration of image spans and precise control over layout and rendering.
