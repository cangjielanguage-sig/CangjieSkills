# 开放权限用户授权

This directory provides comprehensive guidance on managing open permissions that require explicit user authorization within the HarmonyOS ecosystem. It details the `user_grant` mechanism, emphasizing the necessity of declaring permissions in the installation package and obtaining dynamic user consent at runtime. The content covers a wide range of sensitive system capabilities, including hardware access (Bluetooth, Camera), data retrieval (Calendar, Health), and specific file system permissions for 2-in-1 devices. Designed for application developers, this documentation ensures compliance with API version 12 standards and facilitates the secure implementation of features requiring sensitive data access.
