# cj-apis-rpc

This directory serves as a comprehensive documentation hub for the `cj-apis-rpc` project, specifically focusing on the `ohos.rpc` module as implemented in the Cangjie programming language. It is designed to facilitate Inter-Process Communication (IPC) and Remote Procedure Calls (RPC), which are foundational to the OpenHarmony ecosystem's architecture. The documentation covers essential components required for building distributed applications, including data serialization strategies using `Parcelable` and `MessageSequence`, as well as efficient shared memory management via `Ashmem`. By providing API references, configuration guides, and practical code examples, this resource is tailored for Cangjie developers and software engineers who need to implement reliable, high-performance data exchange mechanisms between processes, whether running locally on a single device or across a distributed network environment.
