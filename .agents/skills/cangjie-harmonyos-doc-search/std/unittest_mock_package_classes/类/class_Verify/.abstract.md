This directory contains API documentation for the `Verify` class within the Cangjie unit testing mock framework. It covers the mechanisms for defining and validating mock object behaviors, focusing on execution frequency, argument validation, and call order. Key components include static methods for ordered and unordered verification, the `@Called` macro, and exception handling for failed verifications. This documentation is suitable for developers writing unit tests who need to ensure stub functions are executed as expected, providing tools for precise behavioral testing and interaction validation.
