# 组件内转场transition

This directory provides comprehensive documentation for implementing component internal transitions within the ArkUI framework using the Cangjie language. It covers essential configuration classes for scaling, translation, and rotation transformations, alongside the core `TransitionEffect` API for defining entry and exit animations. The content includes detailed API references for options classes, enums for edge definitions, and practical code examples demonstrating bidirectional and asymmetric transitions. Designed for ArkUI developers and UI engineers, these resources facilitate the creation of smooth, state-driven visual changes and dynamic user interface behaviors in HarmonyOS applications.

## Detailed Description

### class_ScaleOptions.md class_ScaleOptions.md
This API reference document outlines the ScaleOptions class for configuring component scaling transformations within the ArkUI framework using the Cangjie language. It covers public properties x, y, and z for defining axis-specific scale ratios, and centerX, centerY for setting the transformation anchor point. Key information includes how values greater than 1 enlarge components, values between 0 and 1 shrink them, and negative values flip the direction. The constructor allows initializing these parameters with specific defaults like 1.0 for scale and 50 percent for the center. Intended for ArkUI developers, this guide provides the necessary parameters to manipulate component size and perspective.

### class_TranslateOptions.md class_TranslateOptions.md
This document provides API reference documentation for the TranslateOptions class in the Cangjie language, designed to define translation parameters for ArkUI components. The content details the class structure, focusing on the public properties x, y, and z, which represent translation distances along the respective axes, and the class constructor. Key takeaways include that these properties are optional Length types supporting vp units with infinite range, defaulting to zero. This guide targets ArkUI developers using Cangjie who need to implement 2D or 3D position transformations in their user interfaces.

### enum_TransitionEdge.md enum_TransitionEdge.md
This API reference document defines the TransitionEdge enum for specifying window edges within the ArkUI framework using the Cangjie language. It covers enum members such as Top, Bottom, Start, and End, along with operator overloads for equality and inequality checks. Key information includes the layout-direction dependency of Start and End values, which adapt to LTR or RTL contexts. The enum inherits from Equatable and is available from system version 22. This documentation targets developers implementing window transitions or edge-based positioning, providing the necessary definitions for handling directional logic in user interfaces.
