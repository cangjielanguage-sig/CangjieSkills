# digest_package_interfaces

This directory provides the definitive API reference documentation for the Digest interface within the Cangjie programming language, serving as the standard contract for implementing cryptographic hash algorithms. It comprehensively details the essential properties required for any digest implementation, including algorithm identification, blockSize, and size. Additionally, the document covers the core methods necessary for hash computation: write for updating the digest context with data buffers, finish for retrieving the final hash value, and reset for clearing the internal state for reuse. This resource is specifically tailored for developers who are either building custom hash algorithms or integrating existing ones into their applications. To utilize this guide effectively, readers should possess a strong familiarity with Cangjie syntax and core data types such as Array<Byte> and Int64. It ensures consistency across different implementations.
