# 示例代码

This directory serves as a comprehensive resource for developers working with the Cangjie language within the HarmonyOS ecosystem, specifically focusing on the ArkUI framework. It provides practical, executable code examples designed to teach the implementation of sophisticated page transition animations. The content covers essential techniques for customizing navigation behaviors, including modifying component properties like scale, opacity, and position during route transitions. By exploring these examples, developers can learn to create fluid, responsive user interfaces that adapt to different layout modes, such as RTL. This collection is ideal for application developers and UI engineers aiming to elevate the visual quality and user experience of their HarmonyOS applications through dynamic animation effects. The examples demonstrate the use of lifecycle methods like onTransition to handle complex visual states effectively.

## Detailed Description

### 示例代码1设置退入场动画.md
This document provides a practical code example demonstrating how to configure custom page entry and exit animations using the Cangjie language for HarmonyOS development. The content covers two main code files, index.cj and page1.cj, which implement the onTransition method to handle navigation effects. Key takeaways include using PageTransitionEnter and PageTransitionExit to modify component properties like scale and opacity based on route types (Push/Pop) and animation progress. This tutorial is intended for application developers seeking to enhance user experience with smooth, custom page transitions in their UI components.

### 示例代码2设置退入场平移效果.md
This document provides a code example demonstrating how to configure page transition slide effects using the Cangjie language. The content covers the implementation of PageTransitionEnter and PageTransitionExit methods within the onTransition lifecycle function. Key takeaways include the use of SlideEffect.START and SlideEffect.END to define translation directions for entering and exiting pages, specifically in the context of RTL layout modes. The example features two pages, EntryView and Page1, utilizing Router.push for navigation. This tutorial is designed for developers working with the Cangjie ArkUI framework who need to implement custom page navigation animations and transitions.
