# 基础类型定义

This directory contains API reference documentation for fundamental data structures and enumerations used in Cangjie WebView development. It covers classes for handling web events (alerts, downloads, errors), resource management (requests, responses, headers), and configuration enums (cache modes, mixed content). These definitions are essential for developers building robust webview applications, enabling precise control over web content interaction, security settings, and user interface behaviors. Targeted at application developers utilizing the SystemCapability.Web.Webview.Core module, this documentation provides the necessary type definitions to implement advanced web features and manage system capabilities effectively.

## Detailed Description

### class_AdsBlockedDetails.md class_AdsBlockedDetails.md
This document provides API reference for the `AdsBlockedDetails` class, which defines the parameter structure for ad blocking events within a WebView. It details the class constructor and its read-only properties: `url` (the page where filtering occurred) and `adsBlocked` (an array of resource URLs or DOM paths). It is intended for developers handling web ad filtering logic.

### class_ConsoleMessage_3more.md class_ConsoleMessage_3more.md
This document details three classes: `ConsoleMessage`, `PermissionRequest`, and `WebResourceError`. It outlines methods for retrieving console logs, handling permission requests (granting or denying access), and managing resource loading errors. Key functions include `getMessage`, `grant`, and `getErrorCode`, operating under the SystemCapability.Web.Webview.Core capability.

### class_ExpandedMenuItemOptions.md class_ExpandedMenuItemOptions.md
This reference details the `ExpandedMenuItemOptions` class, designed to define parameters for custom menu extension items within a WebView. It covers properties for display content, optional icons, and callback actions, including two constructor overloads for standard strings and AppResource types. It targets developers building custom context menus.

### class_Header_3more.md class_Header_3more.md
This document details the `Header` class for managing request/response headers, and the `OnAlertEvent` and `OnBeforeUnloadEvent` classes for handling web dialog events. It specifies read-write properties for headers and read-only structures for events containing URL, message, and `WebResult` parameters to handle user actions during alerts or page exits.

### class_OnConfirmEvent_2more.md class_OnConfirmEvent_2more.md
This document defines data structures for JavaScript interactions, specifically the `OnConfirmEvent` class for managing confirm dialog callbacks and the `OnConsoleEvent` class for receiving console messages. It includes read-only properties like URL, message content, and result objects to facilitate communication between the web page and the host application.

### class_OnDownloadStartEvent.md class_OnDownloadStartEvent.md
This document defines the `OnDownloadStartEvent` class, which notifies the application when a file download begins. It details the constructor and five read-only properties: `url`, `userAgent`, `contentDisposition`, `mimetype`, and `contentLength`, representing server response headers or download metadata.

### class_OnErrorReceiveEvent_3more.md class_OnErrorReceiveEvent_3more.md
This document defines event classes for handling web component states and errors: `OnErrorReceiveEvent` for resource loading errors, `OnHttpErrorReceiveEvent` for HTTP-specific errors, and `OnPageEvent` for page loading events. It details constructors and properties providing context during callbacks, such as `WebResourceRequest` and `WebResourceError`.

### class_OnPermissionRequestE_2more.md class_OnPermissionRequestE_2more.md
This documentation defines `OnPermissionRequestEvent` and `OnPromptEvent` for the Cangjie Webview component. It details their constructors and read-only properties used to handle web interactions, encapsulating permission requests and managing parameters triggered by JavaScript `prompt()` calls, including URL, message, value, and result handling.

### class_ScriptItem_2more.md class_ScriptItem_2more.md
This document defines data structures for Web component interactions, primarily covering the `ScriptItem` class for injecting JavaScript scripts at document start and the `WebEvent` class for managing popup dialog callbacks. It includes syntax for `scriptRules` to control script execution origins and properties for handling user interaction events.

### class_WebResourceRequest.md class_WebResourceRequest.md
This document serves as API reference for the `WebResourceRequest` class, which describes resource request objects. It details six public member functions to retrieve request details (URL, headers, method) and check request properties (main frame status, redirection, gesture association), requiring SystemCapability.Web.Webview.Core.

### class_WebResourceResponse_2more.md class_WebResourceResponse_2more.md
This document provides API reference for `WebResourceResponse` and `WebResult`. It details `WebResourceResponse` for managing resource response data (status codes, encoding, headers, body) and `WebResult` for handling user dialog interactions like canceling requests, confirming SSL certificates, and submitting prompt inputs.

### enum_CacheMode_5more.md enum_CacheMode_5more.md
This document defines five enumeration types for configuring WebView behaviors: `CacheMode` for resource loading, `MessageLevel` for logging severity, `OverScrollMode` for scrolling effects, `WebKeyboardAvoidMode` for keyboard interaction, and `WebLayoutMode` for page layout adaptation. It details specific behaviors for each enum value.

### enum_MixMode.md enum_MixMode.md
This API documentation defines the `MixMode` enum, which configures the loading behavior of mixed HTTP and HTTPS content. It details three members (All, None, Compatible) and their security behaviors, including the default setting (None) which blocks mixed content. It is intended for managing web content security in ArkUI applications.
