This directory contains a technical tutorial focused on the extraction and manipulation of date and time properties using the Cangjie programming language. It specifically demonstrates how to utilize the `std.time` standard library to create `DateTime` objects and access a wide range of specific attributes. These include basic calendar data like year, month, and day, as well as more complex temporal details such as time components, timezone offsets, and ISO week data. The content is designed for Cangjie developers who possess a basic understanding of the language syntax and are seeking practical, executable examples for handling temporal data in their applications. Key topics covered include `DateTime.of`, `TimeZone.load`, and various property retrieval methods. This resource is essential for anyone needing to implement robust time-handling logic in Cangjie, ensuring accurate data representation and manipulation within the `std.time` framework.
