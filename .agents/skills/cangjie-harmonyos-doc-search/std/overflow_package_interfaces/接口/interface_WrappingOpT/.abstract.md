This directory contains API documentation for the Cangjie programming language's `WrappingOp` interface and its implementations across various integer types. It focuses on arithmetic operations using a high-order truncation strategy to handle integer overflow, ensuring results wrap around predictably without raising runtime errors. The content covers signed and unsigned integers (Int8, Int16, Int32, Int64, IntNative, and their unsigned counterparts), detailing functions like addition, subtraction, multiplication, division, and bitwise shifts. This resource is suitable for Cangjie developers and systems programmers who require precise, deterministic control over low-level integer behavior and modular arithmetic in performance-critical applications.
