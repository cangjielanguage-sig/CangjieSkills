# class_Path2D

This directory provides comprehensive API reference documentation for the Path2D class within the Cangjie language, specifically designed for the ArkUI framework. It covers the creation, manipulation, and rendering of 2D path objects used for custom drawing on a Canvas. Key topics include initializing paths from SVG data, applying geometric transformations like scaling and translation, and drawing various primitives such as lines, arcs, and curves. The documentation details specific methods for path construction and closure, utilizing virtual pixels (vp) for coordinate units. This resource is essential for developers building graphical user interfaces who need to implement custom 2D graphics and vector path operations in their ArkUI applications.

## Detailed Description

### class_Path2D_8more.md class_Path2D_8more.md
This document provides API reference documentation for the Path2D class in the Cangjie language, designed for creating and manipulating 2D path objects within the ArkUI framework. It details constructors for initializing empty or SVG-based paths, and methods for path manipulation including adding sub-paths, applying transformations like scale and translate, and drawing primitives such as lines and arcs. Key information includes support for Canvas stroke and fill operations, coordinate units in vp, and system capability requirements. This reference is intended for developers building graphical user interfaces in ArkUI who need to perform custom 2D drawing on a Canvas.

### func_arcToFloat64_Float64__4more.md func_arcToFloat64_Float64__4more.md
This document provides API reference documentation for path-drawing functions in the ArkUI framework using the Cangjie language. It covers four specific methods: arcTo, quadraticCurveTo, bezierCurveTo, and ellipse, detailing their syntax, functionality, and required parameters. Key takeaways include the use of Float64 for all coordinate and radius inputs, default units in virtual pixels (vp), and specific capabilities like rotation and clockwise control for ellipses. All functions are supported from system version 22. This guide targets developers implementing complex 2D graphics and shapes within ArkUI applications.

### func_rectFloat64_Float64_F_2more.md func_rectFloat64_Float64_F_2more.md
This document serves as API reference documentation for Cangjie developers working with the ArkUI framework, detailing functions for creating and closing path shapes. It covers the `rect` function, which creates a rectangular path using x, y coordinates, width, and height, all specified in vp units. Additionally, it describes the `closePath` function, which closes the current path by drawing a line from the current point back to the start. Both functions return Unit and require SystemCapability.ArkUI.ArkUI.Full starting from version 22. This guide is intended for developers implementing 2D graphics and path manipulation in their applications.
