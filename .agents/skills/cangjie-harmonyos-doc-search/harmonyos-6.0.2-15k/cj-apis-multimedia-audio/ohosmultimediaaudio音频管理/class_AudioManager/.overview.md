# class_AudioManager

This directory contains comprehensive API reference documentation for the Cangjie AudioManager class, a critical component designed to manage audio volume and devices within HarmonyOS applications. It covers a wide array of functionalities, including retrieving audio scene modes, accessing routing controls, managing sessions, and obtaining specific manager instances for streams and volume. The documentation provides detailed syntax, system capabilities, return values, and exception handling, with a specific focus on `BusinessException` errors and error code 6800301. This resource is intended for software engineers and developers utilizing the AudioKit who need to implement robust multimedia audio features and control mechanisms in their software projects. It serves as a technical guide for integrating complex audio management capabilities efficiently.
