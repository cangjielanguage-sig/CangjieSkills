This directory contains comprehensive API documentation for the `DateTimeFormat` class within the Cangjie LocalizationKit, specifically designed to handle the internationalization (I18n) of date and time data. It covers the essential functionality required to format single `DateTime` objects and date-time ranges according to specific locale conventions. The documentation details initialization methods for various locale settings, the use of `DateTimeOptions` for style customization (such as "full" or "medium"), and methods for retrieving resolved configuration options. Intended for software developers working on global applications, these resources require the SystemCapability.Global.I18n capability and provide practical code examples to facilitate the implementation of localized time displays.
