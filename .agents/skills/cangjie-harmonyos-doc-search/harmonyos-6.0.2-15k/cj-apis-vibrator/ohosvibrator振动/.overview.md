# ohosvibrator振动

This directory contains API reference documentation for the OpenHarmony vibrator module, specifically designed for the Cangjie programming language. It covers the implementation of haptic feedback and device motor control, including classes for custom vibration profiles, preset effects, and duration-based vibrations. Key components include enums for usage scenarios and stop modes, alongside functions to start and stop vibrations. The documentation is intended for Cangjie developers using the SensorServiceKit to integrate advanced haptic features into HarmonyOS applications, requiring the `ohos.permission.VIBRATE` permission.

### class_HapticFileDescriptor.md class_HapticFileDescriptor.md

It covers class structure, properties (file descriptor, offset, length), and constructor initialization. It details requirements for valid file resources via FileFs or ResourceManager APIs, default parameter behaviors, and system capability specifications for developers triggering vibration sequences from file data.

### class_VibrateAttribute_2more.md class_VibrateAttribute_2more.md

Key sections include property definitions, constructors, inheritance relationships (`VibrateFromFile` extending `VibrateEffect`), and error handling for unsupported devices, targeting SensorServiceKit developers.

### class_VibratePreset.md class_VibratePreset.md

It notes inheritance from `VibrateEffect`, the required `presetType` value, and configuration of repetition and intensity levels (0-100) for specific haptic feedback patterns.

### class_VibrateTime_2more.md class_VibrateTime_2more.md
API reference for Cangjie components managing haptic feedback. It covers `VibrateTime` for fixed-duration effects and the `EffectId` enum for predefined patterns like clock timers. ### enum_HapticFeedback.md enum_HapticFeedback.md

It covers values like `EFFECT_SOFT`, `EFFECT_HARD`, and `EFFECT_SHARP`, characterized by distinct frequency and intensity levels. It includes standard methods for string representation and equality, requiring `SystemCapability.Sensors.MiscDevice` from version 19.

It notes inheritance from `ToString` and `Equatable`, association with `SystemCapability.Sensors.MiscDevice`, and availability from version 19.
