# 接入步骤

This directory serves as a comprehensive technical resource for developers aiming to implement file opening capabilities in HarmonyOS applications using the Cangjie language. It details the end-to-end integration process, addressing the specific requirements for both the target application (responsible for receiving and processing file requests) and the caller application (responsible for initiating the file open action). Key topics include declaring file access permissions in `module.json5`, processing file URIs within the `onCreate` lifecycle, constructing `Want` objects, and invoking the `startAbility` interface. The guides also provide critical instructions on converting sandbox paths to URIs, setting the `ohos.want.action.viewData` action, and configuring read/write permission flags to ensure secure file sharing. These documents are essential for HarmonyOS developers working with UIAbility and file access mechanisms who need to enable robust cross-application file sharing and viewing functionalities.

## Detailed Description

### 目标方接入步骤.md 目标方接入步骤.md
This technical guide instructs developers on how to configure and implement file opening capabilities within an application. It covers two primary steps: declaring file access permissions in the module.json5 configuration and processing file URIs in the application code. Key takeaways include defining specific skills with the ohos.want.action.viewData action, file scheme, and FileOpen link feature. The implementation involves extracting the URI from the Want parameter in the onCreate lifecycle method and using FileFs.open for file operations. This tutorial targets HarmonyOS application developers using the Cangjie language who need to handle external file requests.

### 调用方接入步骤.md 调用方接入步骤.md
This document provides a step-by-step tutorial for developers on how to implement the caller integration to open files using the Cangjie language. It covers importing necessary modules, retrieving application file paths, constructing request data via the Want object, and invoking the startAbility interface. Key takeaways include converting sandbox paths to URIs, setting the action to "ohos.want.action.viewData", and configuring read/write permission flags for file sharing. The guide targets HarmonyOS application developers working with UIAbility and file access mechanisms.
