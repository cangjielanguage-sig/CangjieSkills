This directory contains API reference documentation for the `ActionSheetOptions` class within the Cangjie ArkUI framework. It covers the configuration of ActionSheet popup windows, detailing class structures, constructors, and properties for layout, styling, and behavior. Key topics include button configurations, visual attributes like borders and shadows, and initialization parameters. This documentation is intended for software developers and UI engineers using Cangjie to build and customize modal dialogs and action sheets in their applications, starting from API version 22.
