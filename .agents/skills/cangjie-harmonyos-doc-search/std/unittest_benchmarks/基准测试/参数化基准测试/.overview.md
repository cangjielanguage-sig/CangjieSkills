# 参数化基准测试

This directory serves as a technical guide for implementing parametric benchmarking in the Cangjie language. It covers the essential use of `@Bench` and `@Strategy` macros, offering insights into basic syntax and advanced data generation strategies. The documentation highlights common pitfalls associated with naive data initialization, such as memory allocation issues and garbage collection interference, providing solutions to ensure accurate performance measurement. Additionally, it explains the framework's default behavior regarding input data immutability, ensuring that every function call receives an identical data version for consistency. Key concepts include parametric benchmarking, immutable input, and data state management. This guide is suitable for developers and performance engineers familiar with unit testing who need to write accurate, high-performance benchmarks and manage data states effectively.

## Detailed Description

### 参数化基准测试_1.md
This tutorial explains how to implement parametric benchmarking effectively using the `@Bench` and `@Strategy` macros in the Cangjie language. It covers basic benchmark syntax, the pitfalls of naive data initialization regarding memory allocation and GC interference, and the advanced usage of the `@Strategy` macro for data generation. Key takeaways include that while `@Bench` supports direct data inputs, using `@Strategy` is superior for complex data types. It generates data on-demand, reduces code redundancy, prevents memory pollution across tests, and provides clearer reporting labels. This guide targets developers familiar with unit testing who need to write accurate, high-performance benchmarks.

### 参数化基准测试_2.md
This documentation section explains the default behavior of input data handling within a parametric benchmarking framework, specifically focusing on data immutability. The text covers the assumption that input data remains unchanged to ensure every function call receives an identical data version, thereby maintaining test consistency. It highlights that while immutability is the standard, the framework also supports benchmarks that require modifying input data, directing users to the "Setup before each call" subsection for details. This technical guide is intended for developers or performance engineers configuring benchmark tests who need to understand data state management. Key concepts include parametric benchmarking, immutable input, and function call consistency.
