# cj-obtain-enrolled-state-capabilities

This directory provides a specialized technical resource for developers utilizing the UserAuthenticationKit within the Cangjie programming ecosystem. It focuses specifically on the mechanism for querying the enrollment status of various user authentication credentials, including biometric modalities such as face recognition and fingerprint scanning, as well as knowledge-based factors like PIN codes. The guide details the usage of the `getEnrolledState` interface, explaining how to pass `UserAuthType` parameters to retrieve specific credential metadata such as enrollment counts and digest values. Furthermore, it addresses critical security prerequisites, particularly the configuration of the `ohos.permission.ACCESS_BIOMETRIC` permission, and outlines robust error handling strategies using `BusinessException`. This documentation is essential for application developers aiming to build secure, responsive applications that dynamically adapt based on the user's available authentication hardware and enrolled credentials. The guide ensures that developers can effectively manage authentication flows and provide a seamless user experience.

## Detailed Description

### cj-obtain-enrolled-state-capabilities.md cj-obtain-enrolled-state-capabilities.md

This document serves as a comprehensive development guide for querying the enrollment status of user authentication credentials, such as face, fingerprint, or PIN, within the UserAuthenticationKit. It covers the `getEnrolledState` interface, which accepts a `UserAuthType` parameter to return credential details like count and digest. The content outlines necessary prerequisites, specifically the `ohos.permission.ACCESS_BIOMETRIC` permission, and provides a step-by-step implementation using the Cangjie programming language. Key takeaways include handling the `BusinessException` for error management. This tutorial is intended for application developers who need to detect and react to changes in user biometric or password credentials. By mastering this interface, developers can enhance user experience by dynamically showing or hiding authentication options based on device capabilities and user enrollment status. The guide serves as a critical reference for ensuring application security and usability.
