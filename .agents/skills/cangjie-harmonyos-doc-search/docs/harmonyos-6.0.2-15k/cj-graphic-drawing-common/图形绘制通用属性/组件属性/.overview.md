# 组件属性

This directory provides comprehensive API references for configuring visual properties and dimensions of UI components within the Cangjie ArkUI framework. It covers a wide range of styling capabilities, including anti-aliasing, fill colors, opacity management, and detailed stroke definitions such as dash patterns and line joins. The documentation explains function overloads supporting data types like Float64, Int64, and AppResource, with specific attention to value clamping and default behaviors. Designed for system version 12, this resource is essential for developers looking to programmatically control graphical rendering, component sizing, and border aesthetics in their applications.
