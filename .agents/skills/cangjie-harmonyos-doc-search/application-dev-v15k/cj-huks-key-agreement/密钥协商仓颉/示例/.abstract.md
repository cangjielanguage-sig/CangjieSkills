This directory contains practical code examples for the HarmonyOS Universal Keystore Service (HUKS) and Universal Keystore Kit, written in the Cangjie programming language. It focuses on cryptographic operations, specifically asymmetric key agreement algorithms like X25519 and Diffie-Hellman (DH). The examples cover essential workflows such as key generation, session management (init, update, finish), key export, and lifecycle management including deletion. These resources are suitable for developers working within the OpenHarmony ecosystem who need to implement secure key exchange mechanisms and manage cryptographic keys effectively in their applications.
