### 使用画布绘制自定义图形Canvas_2more.md 使用画布绘制自定义图形Canvas_2more.md
This document serves as a technical guide for developers on using the Canvas component to draw custom graphics in the Cangjie programming language. It covers two primary drawing methods: standard rendering using the CanvasRenderingContext2D object and off-screen drawing using the OffscreenCanvas object to optimize performance. Key takeaways include configuring RenderingContextSettings for antialiasing, utilizing the onReady callback for drawing operations, and employing transferToImageBitmap and transferFromImageBitmap methods for efficient off-screen rendering. All interface parameters use vp units. Intended for application developers building UIs with Cangjie, this tutorial requires basic knowledge of the UIKit framework and component lifecycle.

### 初始化画布组件_2more.md 初始化画布组件_2more.md
This technical tutorial guides developers on initializing and drawing with the Canvas component using the Cangjie language in HarmonyOS development. It covers the onReady lifecycle event for initialization and resizing, configuration of rendering context settings, and two distinct drawing approaches: direct API calls and using Path2D objects. The document emphasizes that onReady is required to access the canvas dimensions and rendering contexts like CanvasRenderingContext2D. It demonstrates how to enable antialiasing and provides code examples for drawing shapes like rectangles, lines, and arcs. This guide targets HarmonyOS application developers with prerequisite knowledge of Cangjie syntax and UI component structures.

Intended for HarmonyOS application developers, this tutorial serves as a guide for implementing custom rendering logic and visual elements within a user interface.
