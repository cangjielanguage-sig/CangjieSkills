# RSA

This directory provides comprehensive technical documentation for implementing RSA encryption within the Cangjie framework. It covers essential topics such as supported padding modes (NoPadding, PKCS1, PKCS1_OAEP), data length constraints, and API specifications for key sizes ranging from RSA512 to RSA8192. Additionally, it details the configuration of OAEP parameters and specific implementation syntax. This resource is designed for developers, security engineers, and cryptographers who require precise guidance on asymmetric cryptography configuration, parameter management, and ensuring system compatibility.

### RSA_3more.md RSA_3more.md
This technical reference document details RSA encryption implementation within the Cangjie framework, specifically focusing on padding modes and data length constraints. The text covers three supported modes: NoPadding, PKCS1, and PKCS1_OAEP, explaining their specific input/output length requirements and configuration parameters. It provides API specification tables listing the string parameters required to initialize encryption instances for various key sizes, ranging from RSA512 to RSA8192. Key takeaways include the formula for maximum input data length per mode and a performance warning for large keys. This guide targets developers integrating asymmetric cryptography who need to configure specific RSA algorithms and padding modes.

### 获取设置OAEP填充模式的参数.md 获取设置OAEP填充模式的参数.md
This document serves as an API reference detailing the retrieval and configuration of parameters for the RSA PKCS1_OAEP padding mode, supported from API version 12. It covers specific OAEP parameters including message digest (md), mask generation function (mgf), MGF1 digest (mgf1_md), and the encoding parameter string (pSource). The content provides a table mapping these parameters to their enum values and indicates their read/write capabilities. Notably, while md, mgf, and mgf1_md are read-only, the pSource parameter supports both getting and setting. This guide targets developers implementing cryptographic operations who need to understand parameter accessibility for OAEP padding.
