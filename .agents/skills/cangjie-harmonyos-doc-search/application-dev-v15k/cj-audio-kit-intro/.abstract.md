This directory serves as a comprehensive introduction to Audio Kit, a robust service engineered to deliver scenario-based audio playback and recording interfaces. It focuses on high-definition capture and immersive playback experiences, covering the complete system architecture from the Application layer down to the Kernel. Key topics include low latency playback, sound effect modes, and audio-vibration synchronization. The documentation introduces audio streams as independent data processing units, detailing supported PCM formats and configuration attributes. It is specifically tailored for application developers who need a solid grasp of acoustics—such as sampling and quantization—to effectively configure audio streams and manage hardware capabilities, strictly separating audio logic from UI or graphics. This resource is essential for those looking to build professional-grade audio applications that demand precise control over hardware resources and data flow.
