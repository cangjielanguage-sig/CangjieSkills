This directory contains API reference documentation for the `AutoExposure` interface within the CameraKit framework, specifically designed for the Cangjie programming language. It covers the management of device automatic exposure operations, including retrieving and setting exposure modes, metering points, and exposure bias values (EV). Key topics include system capabilities, version requirements, coordinate system logic for metering, and error handling for session configurations. This documentation is suitable for software developers and multimedia application engineers who need to integrate precise camera exposure controls into their Cangjie-based projects.
