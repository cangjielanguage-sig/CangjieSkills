# convert_使用示例

This directory provides a comprehensive collection of practical code examples and tutorials designed for the Cangjie programming language. It focuses heavily on two critical aspects of data handling: string manipulation for presentation and type conversion for data processing. The content covers the `format` method for controlling string output, including alignment and width, and the `convert` module for parsing strings into strongly typed values like Integers, Floats, and Booleans. By exploring parsing mechanisms, error handling, and return types, this resource serves as an essential guide for Cangjie developers. It is particularly suitable for programmers looking to implement robust data validation, manage user input, or format output effectively in their applications.

## Detailed Description

### format_使用示例.md
This document serves as a practical tutorial demonstrating the usage of the `format` method in the Cangjie programming language for string manipulation. It is divided into three main sections covering the formatting of integers, floating-point numbers, and characters (Runes). The examples illustrate how to control output alignment (left and right) and field width using specific format strings like "-10" or "+10". It also shows how to handle numeric literals with underscores. The target audience is Cangjie developers seeking to understand data type conversion and string presentation.

### convert_使用示例/
This directory serves as a comprehensive resource for Cangjie developers, providing practical code examples focused on the `convert` module within the standard library. It specifically addresses string-to-type conversion functionalities, illustrating how to transform string inputs into strongly typed values. The content covers a broad spectrum of data types, including Boolean, Rune, Char, various signed and unsigned Integers (Int8 to Int64, UInt8 to UInt64), and Floating-point numbers (Float16 to Float64). By demonstrating both parsing and try-parsing mechanisms, these examples help developers understand syntax nuances, handle potential parsing errors, and manage return types like Option. This collection is ideal for programmers looking to implement robust data validation and type transformation in their Cangjie applications, offering a quick reference for common conversion tasks and edge case handling.
