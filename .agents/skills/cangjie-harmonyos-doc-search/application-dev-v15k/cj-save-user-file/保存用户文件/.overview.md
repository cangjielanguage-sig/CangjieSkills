# 保存用户文件

This directory provides comprehensive technical documentation for implementing file saving functionalities within HarmonyOS applications using the Cangjie language. It addresses various scenarios, including direct file downloads to the system's Download directory, saving general documents via the FilePicker interface, and handling specific media types like audio files. Key concepts covered include DocumentViewPicker, AudioViewPicker, URI handling, persistent and temporary permissions, and file system operations using FileFs. These guides are essential for developers seeking to manage file persistence, ensure system isolation compliance, and provide robust user file management features in their applications.

## Detailed Description

### DOWNLOAD模式保存文件.md DOWNLOAD模式保存文件.md
This technical guide explains how to implement file saving using the DOWNLOAD mode within the DocumentViewPicker component. It covers mode characteristics, required module imports, configuration of DocumentSaveOptions, and the implementation of the save callback. Key information includes that DOWNLOAD mode automatically creates a directory under Download/包名/, bypasses the file selection interface, and returns a URI with persistent permissions for file creation. The code example demonstrates writing data to a file using FileFs. This tutorial targets developers using the Cangjie language who need to save files directly to the device's download directory without user interaction.

### 保存用户文件_3more.md 保存用户文件_3more.md
This guide explains how to use the FilePicker capability to save user files locally in HarmonyOS applications. It covers permission requirements, system isolation from the gallery, saving media files (referencing Media Library Kit), and a detailed tutorial for saving document files. Key information includes that files saved via Picker have temporary permissions and are isolated from the system gallery. The document saving process involves configuring DocumentSaveOptions, invoking DocumentViewPicker.save(), and using FileFs APIs to write content via the returned URI. This is intended for application developers using the Cangjie language who need to implement file download or save-as functionality.

### 保存音频类文件.md 保存音频类文件.md
This tutorial guides developers through saving audio files using the AudioViewPicker in a HarmonyOS environment with the Cangjie language. The document covers module imports, configuring save options, invoking the picker interface, and subsequent file manipulation. Key steps include creating an AudioViewPicker instance, handling the returned URI via a callback, and using FileFs APIs to open, write, and close the file descriptor. It emphasizes avoiding direct URI manipulation in callbacks and suggests using global variables for storage. This guide is intended for HarmonyOS application developers familiar with Cangjie and file system operations.
