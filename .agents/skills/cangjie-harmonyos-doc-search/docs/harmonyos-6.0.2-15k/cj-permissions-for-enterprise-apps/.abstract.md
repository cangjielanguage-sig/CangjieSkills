This directory functions as a vital technical resource for enterprise developers, providing a detailed reference regarding the specific permissions required for enterprise applications. It encompasses a wide array of functionalities, including standard enterprise apps and Mobile Device Management (MDM) solutions, with a focus on critical areas like file control, network management, account interaction, and system monitoring. The content specifically addresses permissions classified at the system_basic level utilizing system_grant authorization, which are predominantly introduced starting from API version 12. Furthermore, it outlines specific restrictions for certain features, such as firewall management on 2-in-1 devices. This guide is indispensable for developers who must accurately declare sensitive capabilities within their Profile files to ensure compliant access to advanced system functions, thereby ensuring their applications operate correctly within the secure enterprise ecosystem.
