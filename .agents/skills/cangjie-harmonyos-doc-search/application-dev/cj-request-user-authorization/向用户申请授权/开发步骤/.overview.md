# 开发步骤

This directory provides a comprehensive guide for implementing runtime permission requests in HarmonyOS applications using the Cangjie language. It covers the complete development lifecycle, from declaring permissions in configuration files to handling authorization results via UI components. Key topics include location permissions (`ohos.permission.LOCATION`), lifecycle management (`onWindowStageCreate`), and user interaction logic. This resource is suitable for Cangjie developers looking to integrate secure location access and manage system permissions effectively within their applications. The tutorials progress from basic setup to advanced UI interaction and result handling.

## Detailed Description

### 开发步骤_1.md 开发步骤_1.md
This tutorial guides developers through the process of requesting location permissions in a HarmonyOS application using the Cangjie language. It covers three primary steps: declaring permissions in the configuration file, verifying current authorization status via the checkAccessToken method, and dynamically requesting user authorization using requestPermissionsFromUser. Key information includes specific permission names like ohos.permission.LOCATION, logic for handling precise versus approximate location grants, and the correct timing for calling request methods within the onWindowStageCreate lifecycle. The document is intended for application developers implementing runtime permission requests.

### 开发步骤_2.md 开发步骤_2.md
This tutorial provides Cangjie code examples for implementing user permission requests in HarmonyOS applications. It covers two primary methods: requesting permissions during the onWindowStageCreate lifecycle and triggering requests via UI components. Key information includes using AbilityAccessCtrl to request location permissions, managing UIAbilityContext globally for UI access, and handling authorization results through callbacks to verify if permissions are granted or denied. The document targets Cangjie developers who need to implement runtime permission handling, specifically for location access, within their application logic.

### 开发步骤_3.md 开发步骤_3.md
This document is a tutorial segment guiding developers through implementing runtime permission requests in a HarmonyOS application using the Cangjie language. It covers two main areas: constructing a user interface with a button to trigger permission requests and handling the subsequent authorization results. Key information includes code snippets for the button's onClick event and logic for managing user responses, specifically guiding users to system Settings if permissions are denied. The content targets developers building secure applications, focusing on the interaction between UI components and system permission APIs like requestPermissionsFromUser.
