# 使用Display实现屏幕属性查询及状态监听

This directory serves as a comprehensive resource for developers utilizing the Cangjie programming language within the HarmonyOS ecosystem. It focuses on the implementation of screen attribute queries and status monitoring using the Display module. The documentation covers essential techniques for retrieving screen properties such as resolution, density, and cutout information, alongside methods for listening to real-time status changes. Special emphasis is placed on adaptive UI development for diverse hardware, including foldable devices. By leveraging APIs like `getDefaultDisplaySync` and foldable status listeners, developers can create responsive applications. This material is ideal for those seeking to optimize user experiences across varying device configurations and states.

### 使用Display实现屏幕属性查询及状态监听_5more.md 使用Display实现屏幕属性查询及状态监听_5more.md
This technical guide explains how to use the Display module to query screen attributes and monitor status changes for adaptive UI development. It covers scenario introductions, interface descriptions, obtaining Display objects, and retrieving specific screen properties like resolution and cutout information. Key APIs include `getDefaultDisplaySync`, `getAllDisplays`, and foldable status listeners. The document provides Cangjie code examples for fetching display instances and accessing attributes such as width, height, and refresh rate. Targeted at developers building applications for various devices, including foldables, it requires knowledge of the Cangjie language and basic screen concepts.

### 监听折叠设备状态变化.md 监听折叠设备状态变化.md
This technical guide explains how to detect and monitor the foldable status of devices using the Cangjie programming language. The document covers two main functionalities: querying device foldability via the isFoldable interface and managing event listeners for fold status changes using on and off methods. Key information includes practical code examples demonstrating error handling, callback implementation for specific states like FoldStatusExpanded or FoldStatusFolded, and procedures for registering or unregistering listeners. Intended for HarmonyOS developers, this reference material assists in adapting application layouts or behaviors dynamically for foldable hardware.
