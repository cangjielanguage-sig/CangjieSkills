This directory serves as a comprehensive technical repository dedicated to the specifications for asymmetric encryption and decryption algorithms within the Cangjie programming ecosystem. It provides in-depth documentation for prominent cryptographic standards, specifically SM2 and RSA, covering essential implementation details such as encryption modes, padding schemes, and API compatibility layers. The content delves into critical areas like algorithm parameter construction, digest algorithm integration, and ciphertext format conversion. Designed primarily for Cangjie developers and security engineers, this resource is essential for those aiming to implement robust cryptographic operations, manage complex key configurations, and ensure strict compliance with industry standards like GM/T 0009-2012. By utilizing these specifications, users can effectively integrate high-level security features into their applications.
