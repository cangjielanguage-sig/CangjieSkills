# 类

## 详细说明

### class_HMAC.md class_HMAC.md
该文档是Cangjie语言中HMAC类的API参考文档，旨在提供基于哈希的消息认证码算法实现。文档涵盖了类定义、支持的哈希算法（如MD5、SHA系列及SM3）、构造函数、属性及核心方法。关键信息包括用于更新数据的write、生成摘要的finish、重置状态的reset以及防止时序攻击的静态比较函数equal，并详细说明了参数、返回值及CryptoException异常处理。该文档面向需要在Cangjie项目中实现数据安全认证的开发者。

### class_MD5.md class_MD5.md
这是一份仓颉语言中MD5类的API参考文档，旨在提供MD5摘要算法的实现接口。文档主要涵盖了类的属性（如算法名称、块大小、摘要长度）以及核心方法（初始化、写入数据、完成计算、重置上下文）。关键信息包括finish方法会改变上下文，需调用reset才能再次计算，且涉及CryptoException异常处理。该文档面向使用加密功能的开发者，提供了详细的参数说明和返回值定义。

### class_SHA1.md class_SHA1.md
这是一份API参考文档，详细介绍了Cangjie语言中SHA1类的实现接口，用于提供SHA1摘要算法功能。文档主要涵盖类定义、属性（algorithm、blockSize、size）以及核心方法（init、finish、reset、write）。关键信息指出finish方法调用后上下文会改变，必须通过reset重置才能再次计算，否则会抛出CryptoException异常。该文档面向需要在Cangjie项目中实现数据加密和摘要计算的开发者，属于加密库的参考手册。

### class_SHA224.md class_SHA224.md
