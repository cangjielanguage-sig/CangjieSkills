This directory provides comprehensive documentation for the `StoreConfig` class within the Cangjie language, specifically designed for managing relational database configurations in distributed data management systems. It covers critical configuration aspects such as database naming conventions, security levels, encryption status, custom directory paths, application group IDs, and automatic data cleanup settings. The documentation highlights specific technical constraints, including the 128-byte limit on custom directory sizes and the specific directory structure required for database creation. Additionally, it explains the nuanced behavior of cloud-deleted data synchronization. This resource is primarily suitable for developers and engineers working on local storage solutions and cloud data synchronization who need to configure relational stores securely, manage sandbox paths, and handle data lifecycle events efficiently.
