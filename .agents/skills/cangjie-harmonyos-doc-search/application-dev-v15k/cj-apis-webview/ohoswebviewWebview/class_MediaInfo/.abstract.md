This directory provides comprehensive API reference documentation for the `MediaInfo` class in the Cangjie language, specifically designed for developers integrating native media player functionalities within webview environments. It covers the encapsulation of webpage media information to enable native playback takeover, detailing the class constructor, mandatory initialization parameters, and read-only properties. Key topics include configuring media sources, surface rendering information, HTTP headers, and HTML5 tag attributes such as muted and preload. This documentation is essential for software engineers utilizing the Webview Core system capability to manage interactions between web components and custom native players, ensuring robust media playback control and configuration.
