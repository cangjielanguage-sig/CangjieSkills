This directory serves as a comprehensive technical resource for developers working within the OpenHarmony environment, specifically focusing on the Hardware Universal KeyStore (HUKS). It provides a detailed overview of encryption and decryption capabilities, offering a clear breakdown of supported cryptographic algorithms such as AES, RSA, SM4, SM2, DES, and 3DES. A key feature of this documentation is its categorization of specifications based on device types—standard and lightweight—ensuring that developers can tailor their security implementations to the specific hardware constraints of their target devices. The content delves into critical technical details, including block modes, padding schemes, and the specific API levels required for various operations. Furthermore, it highlights mandatory parameters like IV, Nonce, and TAG necessary for secure modes such as CBC and GCM. This reference is essential for application developers aiming to integrate high-grade security features, as it clarifies the distinction between mandatory and optional algorithm specifications to ensure full compatibility and robust functionality.
