# 示例代码

This directory serves as a practical resource hub containing Cangjie code examples dedicated to the implementation and customization of AlertDialogs in HarmonyOS applications. The content spans from fundamental dialog setups featuring varying button configurations to advanced behaviors like rendering popups outside the main window context. Core technical topics include the utilization of `AlertDialogParamWithConfirm` and `AlertDialogParamWithOptions`, implementation of event callbacks, and application of custom visual styles. These examples are ideally suited for Cangjie developers working within the UIKit framework who require precise control over dialog interactions, need to handle complex dismissal events, or wish to enhance the visual aesthetics of their application's modal components.

## Detailed Description

### 示例1弹出多个按钮的弹窗.md
This document provides a Cangjie code example demonstrating how to implement AlertDialogs with varying numbers of buttons in a HarmonyOS application. It covers three specific scenarios: a single-button dialog, a two-button dialog, and a three-button dialog. The code illustrates the use of distinct parameter structures like AlertDialogParamWithConfirm and AlertDialogParamWithOptions to configure titles, subtitles, button styles, and event callbacks such as onClick and onWillDismiss. This tutorial is intended for Cangjie developers seeking to implement interactive dialog components within the UIKit framework.

### 示例2可在主窗外弹出的弹窗_2more.md
This document provides Cangjie code examples demonstrating advanced AlertDialog configurations for HarmonyOS applications. It covers two specific scenarios: displaying a dialog outside the main window and customizing the dialog's visual style. Key information includes using `AlertDialogParamWithOptions` with the `showInSubWindow: true` parameter to enable popups outside the main window context, and utilizing `AlertDialogParamWithConfirm` to apply styling properties such as dimensions, corner radius, borders, and shadow effects. The document serves as a practical guide for developers looking to implement complex dialog behaviors and custom UI designs using the UIKit framework.
