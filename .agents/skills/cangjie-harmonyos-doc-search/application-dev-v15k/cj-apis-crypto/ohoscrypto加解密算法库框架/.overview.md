This directory provides the API reference for the HarmonyOS Crypto Framework (ohoscrypto) in the Cangjie language. It covers a wide range of cryptographic operations including symmetric and asymmetric encryption, digital signatures, key generation, message digests, and key agreement. The framework supports algorithms such as RSA, ECC, AES, SM2, and DSA, enabling developers to implement robust security features. It is intended for software developers and security engineers building Cangjie applications who require comprehensive tools for data protection, key management, and cryptographic protocol implementation within the SystemCapability.Security.CryptoFramework.
