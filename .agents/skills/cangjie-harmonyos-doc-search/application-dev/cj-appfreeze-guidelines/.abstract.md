This directory provides comprehensive guidelines for analyzing and resolving Application Not Responding (AppFreeze) issues within the OpenHarmony and HarmonyOS ecosystems, specifically focusing on the Stage model. It covers essential topics such as detection mechanisms, common fault types like main thread stalls and lifecycle timeouts, and system recovery processes. The content includes practical guides for log collection, stack trace analysis, and debugging workflows using DevEco Studio. It is suitable for developers, system engineers, and QA professionals seeking to diagnose application stability issues, understand watchdog logic, and optimize overall performance.
