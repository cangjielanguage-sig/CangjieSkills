This directory serves as a comprehensive technical resource dedicated to the implementation of drag-and-drop functionality within the Cangjie ArkUI framework. It is designed to assist developers in understanding and utilizing universal event handling mechanisms to create dynamic user interfaces. The repository covers a broad spectrum of essential APIs, including `onDragStart`, `onDrop`, and `onDragEnter`, providing the necessary tools to manage complex user interactions. Additionally, it details configuration attributes and fundamental data structures like `DragInfo` and `DragEvent`, which are crucial for maintaining state and data integrity during drag operations. The documentation also addresses version compatibility, explicitly outlining the differences between API 12 and API 19. This resource is highly suitable for Cangjie developers and HarmonyOS engineers who are looking to build interactive UI components with robust drag-and-drop capabilities, offering both theoretical insights and practical implementation guidance.
