# class_IPPrefix

This directory contains API reference documentation for the `IPPrefix` class in the Cangjie standard library's net package. It focuses on representing IP address prefixes and subnets, defined by a start address and length. The documentation covers essential functionalities including parsing strings into IPPrefix objects, calculating network properties like broadcast addresses and masks, and performing comparisons or range checks. It is designed for software developers and network engineers working on network applications who need robust tools for subnet calculations, IP validation, and protocol implementation in Cangjie.
