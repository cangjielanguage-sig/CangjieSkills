This directory provides comprehensive API documentation for the `Matchers` class, a fundamental component of the Cangjie unit testing framework dedicated to advanced mocking and stubbing capabilities. It serves as a guide for developers to generate argument matchers that control mock object behavior with high precision. The content covers essential functionalities such as accepting arbitrary values, filtering arguments through custom predicates, and capturing argument values for later verification. Key concepts include the distinction between mock and spy behaviors, the use of the `@On` macro for conditional stubbing, and the nuances of structural versus reference equality. This documentation is specifically tailored for developers implementing unit tests who require granular control over argument matching to ensure their test logic is both robust and reliable.
