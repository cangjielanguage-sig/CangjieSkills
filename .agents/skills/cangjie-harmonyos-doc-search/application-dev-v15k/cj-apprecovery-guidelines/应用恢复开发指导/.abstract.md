This directory provides comprehensive guidance on the Application Recovery feature, designed to mitigate data loss from unexpected application behaviors like unhandled exceptions. It covers the technical implementation involving the AbilityStage component, state restoration mechanisms, and data persistence strategies. Key topics include fault listening, auto-restart capabilities, and managing application crashes or freezes. This guide is suitable for application developers and system engineers seeking to enhance app stability, ensure continuous user experiences, and integrate robust error handling and state management capabilities using the Cangjie language and AbilityKit framework.
