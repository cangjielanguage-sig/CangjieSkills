This directory contains essential API reference documentation for the `Call` class within the Cangjie programming language's TelephonyKit module. It is designed to assist developers in implementing comprehensive telephony call management features. The content covers a wide range of functionalities, including standardizing phone number formats for display and international compliance (E.164), retrieving real-time call states, checking for active voice calls, and initiating new calls via the system dialer. Detailed information regarding method parameters, return types, and specific `BusinessException` error codes is provided alongside Cangjie code examples. This resource is ideal for developers who require a deep understanding of TelephonyKit system capabilities to build robust communication applications.
