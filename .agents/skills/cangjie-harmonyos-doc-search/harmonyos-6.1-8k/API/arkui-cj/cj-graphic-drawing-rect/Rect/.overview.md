## Detailed Description

### Rect_5more_c81e995d.md
本文档是ArkUI框架中Rect矩形绘制组件的API参考文档，面向使用仓颉语言进行UI开发的开发者。文档主要涵盖了模块导入方式、组件初始化构造函数以及支持的通用属性和事件。关键信息指出该组件目前处于Beta阶段，通过init方法可设置可选的宽度和高度参数，支持图形绘制通用属性，参数默认值为0且单位为vp。该文档旨在帮助开发者在应用中快速实现矩形图形的绘制与配置。

### 示例代码_fdde88cf.md
本文档旨在通过Cangjie语言演示如何在HarmonyOS应用中使用Rect组件绘制不同样式的矩形。文档主要涵盖了基础矩形绘制、描边设置、填充颜色以及多种圆角设置方式，包括统一圆角、独立宽高圆角及四角独立圆角。关键信息展示了通过链式调用设置宽度、高度、填充、描边及半径属性的具体方法，并配合嵌套Column布局展示最终效果。该示例适用于正在学习Cangjie语言ArkUI框架开发的开发者，帮助他们掌握图形绘制的常用技巧。

### 组件属性.md
本文档是ArkUI框架中用于设置组件圆角属性的API参考文档，基于仓颉语言编写。文档主要涵盖了radiusWidth、radiusHeight以及三种不同参数重载形式的radius函数，详细说明了如何设置圆角的宽度、高度及四个角的独立半径。关键信息包括所有函数均支持Length类型参数，异常值会按初始值0.vp处理，且起始版本为22。该文档面向使用仓颉语言开发ArkUI界面的开发者，旨在提供精细控制UI组件圆角样式的接口说明。
