This directory contains API reference documentation for the `ohos.cert_manager` module within the Cangjie framework, designed for HarmonyOS application development. It covers the complete lifecycle of certificate management, including installation, retrieval, and cryptographic operations like signing and verification. Key components include data structures for certificate details, enumerations for cryptographic algorithms (digest, padding, purpose), and functions for handling credentials and error codes. This documentation is suitable for developers implementing security features, managing user trust stores, and performing secure cryptographic operations in their applications.
