# DataPanel

The DataPanel directory provides comprehensive API documentation and resources for the DataPanel component within the ArkUI framework, specifically designed for the Cangjie language. It covers data visualization features, including component initialization, property configuration, and visual styling like gradients and shadows. This collection is suitable for software developers and UI engineers working on HarmonyOS applications who need to implement sophisticated data displays. Key topics include circular and linear panel types, animation control, and track customization.

## Detailed Description

### DataPanel_4more.md DataPanel_4more.md
This document provides API reference documentation for the DataPanel component, which visualizes data proportions using charts. The main sections cover the component description and the initialization method init. Key information includes the function parameters: an array of values (limited to 9 items), a maximum value for scaling, and a panel type. It specifies that negative values are reset to zero and the panel type is static after creation. The component supports all universal attributes and events. This guide targets developers using the ArkUI framework (version 12 or higher) to implement data visualization features.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring properties of a data panel component within the ArkUI framework using the Cangjie language. It details five key functions: closeEffect, strokeWidth, trackBackgroundColor, trackShadow, and valueColors. These methods allow developers to control visual behaviors such as rotation animations, shadow effects, ring thickness, background colors, and segment gradients. Specific constraints are noted, such as strokeWidth being invalid for LineType and the interaction between closeEffect and trackShadow. This technical reference is intended for software developers using ArkUI system capabilities, specifically those customizing data visualization components.
