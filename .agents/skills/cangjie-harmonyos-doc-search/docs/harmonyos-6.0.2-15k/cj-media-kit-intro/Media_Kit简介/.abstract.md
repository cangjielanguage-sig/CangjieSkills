Media Kit is a comprehensive framework designed for developing audio and video playback and recording functionalities. It covers modules like AVPlayer, AVRecorder, AVScreenCapture, SoundPool, AVMetadataExtractor, and AVImageGenerator. Key features include a lightweight engine, HDR video support, low-latency audio, and robust encoding capabilities. The documentation details system architecture, data flow, supported formats (MP4, M4A, H264, H265), and integration with hardware interfaces. Suitable for application developers using Cangjie, JS, or Native interfaces, this kit provides the necessary specifications to implement multimedia features, from local playback to network streaming and screen recording.
