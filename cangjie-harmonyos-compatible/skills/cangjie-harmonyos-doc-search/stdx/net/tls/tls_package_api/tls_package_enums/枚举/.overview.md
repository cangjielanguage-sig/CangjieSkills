# 枚举

## 详细描述

### enum_CertificateV_2more_8f45fafa.md enum_CertificateV_2more_8f45fafa.md
本文档是仓颉语言中关于TLS安全配置的API参考文档，主要定义了证书验证模式和签名算法类型。文档详细介绍了 `CertificateVerifyMode` 枚举的三种模式：使用自定义CA、默认系统CA验证以及仅用于开发测试的信任所有模式。同时，文档涵盖了 `SignatureAlgorithm` 枚举，区分了适用于TLS 1.2的签名哈希算法组合和TLS 1.3的签名方案，并说明了其字符串转换及比较运算符的功能。这些内容旨在帮助开发者在网络通信中正确配置证书校验策略和加密算法，适用于具备基础网络安全知识的开发人员。

### enum_SignatureSchemeType.md enum_SignatureSchemeType.md
本文档是Cangjie语言中SignatureSchemeType枚举的API参考文档，旨在定义用于网络通信安全的加密算法类型。文档详细列出了RSA、ECDSA、ED25519及ED448等多种签名方案变体，并说明了该枚举实现了ToString和Equatable接口。主要内容包括各枚举实例的具体功能描述、字符串转换方法以及相等性比较操作符。这些定义对于实现身份验证和数据完整性至关重要。目标受众为使用Cangjie进行安全通信开发的程序员，需具备基础密码学概念。

### enum_SignatureTyp_3more_071f0d6c.md enum_SignatureTyp_3more_071f0d6c.md
本文档是Cangjie语言TLS包的API参考文档，旨在定义与TLS协议相关的核心枚举类型。主要包含三个部分：SignatureType定义了DSA、ECDSA和RSA等签名算法类型，支持字符串转换和相等性比较；TlsClientIdentificationMode规定了服务端对客户端证书的认证模式，涵盖禁用、可选和必须三种状态，分别对应单向或双向认证；TlsVersion则标识TLS 1.2、1.3及未知版本。文档详细列出了各枚举值的功能、方法参数及返回值，适合具备基础网络编程知识的开发者用于构建安全通信应用。
