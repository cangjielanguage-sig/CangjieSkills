This directory provides comprehensive technical guidance for HarmonyOS developers regarding the critical transition from explicit Want mechanisms to App Linking for inter-application navigation. It specifically addresses the deprecation of explicit Want starting from API 18, offering detailed instructions on configuring `module.json5` for domain verification and implementing the `openLink` interface using Cangjie or ArkTS. The documentation covers essential topics such as handling return results from launched UIAbilities, ensuring security compliance, and managing fallback mechanisms. This resource is essential for developers seeking to modernize their app's navigation logic and ensure secure, compliant cross-application communication within the HarmonyOS ecosystem. By following these guides, developers can effectively replace legacy methods with standardized, secure linking protocols.
