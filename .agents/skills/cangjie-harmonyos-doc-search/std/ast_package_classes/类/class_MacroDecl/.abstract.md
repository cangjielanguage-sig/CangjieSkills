This directory contains technical documentation for the `MacroDecl` class and associated traversal utilities within the Cangjie language's Abstract Syntax Tree (AST). It focuses on the structural definition of macro declaration nodes, detailing their inheritance hierarchy, mutable properties like tokens and block structures, and methods for serialization back into tokens. Furthermore, it covers the visitor pattern implementation for traversing syntax trees, allowing for programmatic inspection and manipulation of code structures. Key concepts include AST node construction, token handling, and tree traversal algorithms. This resource is specifically designed for compiler developers, language engineers, and software developers involved in building or maintaining the Cangjie compiler infrastructure.
