This directory contains API reference documentation for the `ohos.file_fs.interop` module, designed to facilitate interoperability between Cangjie file objects and ArkTS JavaScript values within the HarmonyOS ecosystem. It covers core classes such as `File`, `Stream`, and `RandomAccessFile`, detailing their definitions and methods for bidirectional type conversion. Key topics include the `JSSystemObjectInteropType` interface and ownership transfer mechanisms during object conversion. This documentation is suitable for HarmonyOS developers working on file management and cross-language integration who need to bridge Cangjie and ArkTS environments.
