This directory contains the API reference documentation for the HarmonyOS advertising service framework (AdsKit) specifically designed for the Cangjie programming language. It covers the core components required to integrate advertising into applications, including ad loading, display configuration, request parameters, and event listeners. The documentation details classes for managing ad slots, handling callbacks, and configuring ad options for compliance and user experience. It is suitable for software developers and engineers working within the HarmonyOS ecosystem who need to implement monetization features using Cangjie syntax and asynchronous event handling patterns.
