This directory contains API reference documentation for the `On` class within the Cangjie UiTest framework. It focuses on locating and matching target UI widgets for automated testing. The documentation covers the class constructor, various property-matching methods (such as clickable, enabled, and text), relative positioning functions, and hierarchical component matching. Designed for software developers and QA engineers, these resources provide Cangjie code examples and detailed parameter descriptions to facilitate the creation of robust UI test scripts using the TestKit.
