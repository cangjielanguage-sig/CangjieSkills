# 签名验签仓颉

This directory provides a comprehensive guide and practical examples for implementing digital signing and signature verification using the Cangjie programming language and the Universal Keystore Kit. It covers the complete lifecycle of cryptographic operations, including key generation, signing, verification, and deletion. The content supports various algorithms such as ECC, RSA, and SM2, with a focus on session-based workflows and hardware-backed security. It is suitable for Cangjie developers and security engineers looking to integrate robust cryptographic features and national cryptographic standards into their applications.

## Detailed Description

### 开发步骤.md 开发步骤.md
This document serves as a step-by-step development guide for implementing cryptographic operations using the Universal Keystore Kit. It covers four primary workflows: generating or importing keys, signing data, verifying signatures, and deleting keys. Key sections detail the specific API calls required for each process, such as generateKeyItem, initSession, updateSession, and finishSession, along with parameter configurations like HuksOptions. The guide emphasizes the session-based approach for signing and verification. It is intended for developers seeking to integrate secure key management and cryptographic functions into their applications, providing a clear procedural reference for the complete lifecycle of key usage.

### 签名验签仓颉.md 签名验签仓颉.md
This document serves as a practical guide for developers to implement digital signing and signature verification using the Cangjie programming language. It covers development steps and specific development cases for four cryptographic algorithms: ECC256/SHA256, SM2/SM3, RSA/SHA256/PSS, and RSA/SHA256/PKCS1_V1_5. The guide provides concrete examples and references a separate overview document for detailed specifications on supported algorithms and scenarios. It targets Cangjie developers seeking to integrate cryptographic security features into their applications.
