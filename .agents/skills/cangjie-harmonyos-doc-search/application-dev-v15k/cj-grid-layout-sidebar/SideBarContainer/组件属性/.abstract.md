This directory provides comprehensive API reference documentation for configuring component properties within the ArkUI framework using the Cangjie language. It primarily focuses on the `SideBarContainer` component, offering detailed instructions on layout management, interaction behavior, and visual appearance. Key topics covered include auto-hiding logic, width constraints, control button styling, divider configuration, and sidebar positioning. The documentation also highlights property priorities, default values, and version compatibility. This resource is essential for developers building responsive user interfaces who require precise control over sidebar mechanics, resizing behavior, and method chaining to create polished and functional applications.
