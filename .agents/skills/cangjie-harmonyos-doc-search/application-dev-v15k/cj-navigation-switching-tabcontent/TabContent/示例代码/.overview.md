# 示例代码

This directory contains a collection of code examples and tutorials focused on implementing and customizing the Tabs component in Cangjie and HarmonyOS applications. It covers a wide range of tab bar configurations, including custom side tabs, bottom tabs, and sub-tabs, as well as styling properties like text adaptation, colors, and underlines. The examples demonstrate state management, event handling, and visual feedback mechanisms. Suitable for developers using the Cangjie language or ArkUI framework, these resources provide practical guidance for creating interactive and responsive navigation interfaces.

## Detailed Description

### 示例1自定义页签切换联动.md 示例1自定义页签切换联动.md
This tutorial demonstrates how to implement custom linkage between a tab bar and content views in a Cangjie application. The document focuses on utilizing the Tabs component with a custom tabBuilder to create interactive tab interfaces. Key information includes the use of onAnimationStart to trigger visual state changes in the custom tab bar immediately, and onChange to synchronize the content index. The code example illustrates managing state variables like selectedIndex to dynamically update icon and text colors. Intended for developers with knowledge of Cangjie and HarmonyOS UI development, this guide provides a practical reference for enhancing user interaction in tab-based layouts.

### 示例2自定义侧边页签.md 示例2自定义侧边页签.md
This document provides a code example demonstrating how to implement a vertical side tab bar with custom styling in the Cangjie programming language. It covers the usage of the Tabs component configured with BarPosition.Start and vertical(true), a custom tabBuilder function for tab content, and state management logic using onChange and onAnimationStart to handle selection highlighting. Key takeaways include setting specific dimensions for the side bar, using state variables to toggle icon and text colors dynamically, and synchronizing the displayed content with the selected tab index. This tutorial is intended for developers using the HarmonyOS Cangjie UI framework who need to create custom navigation layouts, specifically vertical side tabs.

### 示例5设置子页签文本自适应高度属性.md 示例5设置子页签文本自适应高度属性.md
This document provides a code example demonstrating how to configure text height adaptation for sub-tab labels using the heightAdaptivePolicy property in the Cangjie UI framework. The code illustrates four distinct scenarios within a Tabs component: single-line truncation with ellipsis, font size reduction before clipping, font reduction combined with line wrapping, and multi-line wrapping. The core implementation relies on the LabelStyle class, specifically configuring TextHeightAdaptivePolicy (either MAX_LINES_FIRST or MIN_FONT_SIZE_FIRST) alongside overflow and maxLines parameters to control text rendering behavior. This tutorial is intended for developers using the Cangjie language to build HarmonyOS applications who need to manage text layout in vertical tab bars.

### 示例6设置底部页签基本属性.md 示例6设置底部页签基本属性.md
This document serves as a code tutorial demonstrating how to configure and dynamically modify the basic properties of bottom tab bars in a Cangjie application. It covers the implementation of BottomTabBarStyle within a Tabs component, specifically focusing on attributes like padding, vertical alignment, layout mode, and symmetric extensibility. The example provides interactive buttons to adjust these properties at runtime, illustrating how state variables control the visual presentation of tab content, including text length and icon positioning. Targeted at developers using the Cangjie language and HarmonyOS UIKit, this guide helps in creating responsive and customizable bottom navigation interfaces.

### 示例7设置子页签底部页签文本颜色.md 示例7设置子页签底部页签文本颜色.md
This tutorial demonstrates how to customize text and icon colors for sub-tabs and bottom tabs in a Cangjie application. The document presents a single code example divided into two sections: one illustrating sub-tab styling and the other showing bottom tab styling. Key takeaways include using the LabelStyle component with unselectedColor and selectedColor properties to modify text appearance, and TabBarIconStyle for icon colors within SubTabBarStyle and BottomTabBarStyle. This guide is intended for Cangjie developers seeking to implement dynamic visual feedback in tab-based navigation interfaces.

### 示例3子页签底部页签侧边页签样式对比/
This directory provides comprehensive code tutorials focused on the implementation and visual comparison of three distinct tab bar styles: SubTab, BottomTab, and SideTab. It covers the technical configuration of `TabContent`, `BarPosition`, and specific styles like `SubTabBarStyle` and `BottomTabBarStyle` within modern UI frameworks such as Cangjie UI and ArkTS. Key topics include managing lifecycle callbacks (`onWillShow`, `onWillHide`), defining layout properties (vertical orientation, `BarMode.Fixed`), and handling user interaction events. These resources are suitable for developers looking to create complex, responsive navigation interfaces, offering practical examples of how to structure varied navigation layouts using declarative UI syntax to optimize user experience and application flow across different development environments.

### 示例4设置子页签下划线基本属性/
This directory contains code examples demonstrating how to configure and animate the underline indicator for sub-tabs in HarmonyOS applications. It covers both static property customization and dynamic animations using ArkTS and Cangjie languages. Key topics include setting visual attributes like color, width, height, border radius, and spacing, as well as implementing smooth transitions using the `animateTo` function. These examples are suitable for developers working with the ArkUI framework who want to enhance user interface design through detailed tab navigation styling and interactive visual effects.
