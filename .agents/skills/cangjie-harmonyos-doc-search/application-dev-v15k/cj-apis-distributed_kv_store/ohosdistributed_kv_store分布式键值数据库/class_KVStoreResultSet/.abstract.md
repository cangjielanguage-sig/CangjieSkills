This directory contains API reference documentation for the `KVStoreResultSet` class within the Cangjie programming language and ArkData framework. It covers the management of database query results, including retrieving key-value pairs, counting rows, and navigating cursor positions. Key topics include result set iteration, boundary checks, and position tracking. This documentation is suitable for developers working on HarmonyOS distributed data management who need to programmatically access and manipulate data returned from SingleKVStore or DeviceKVStore queries.
