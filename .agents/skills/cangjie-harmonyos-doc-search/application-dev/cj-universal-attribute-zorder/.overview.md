# cj-universal-attribute-zorder

This directory provides comprehensive documentation for the Cangjie ArkUI framework, specifically focusing on the Z-order attribute. This attribute is a fundamental tool for developers, enabling precise control over the stacking order and visual hierarchy of user interface components. The content explains how to manipulate the layering of elements to manage depth and handle overlapping scenarios effectively. By detailing the `zIndex` function, its parameters, and its behavior, this documentation helps developers solve common layout challenges. It is highly suitable for Cangjie developers, UI/UX designers, and engineers working on application interfaces where controlling component layering, visibility, and z-axis positioning within layout containers like Stacks is essential for creating a polished and functional user experience.

## Detailed Description

### cj-universal-attribute-zorder.md

This API reference document serves as the definitive guide for controlling the stacking order of components within the Cangjie ArkUI framework using the Z-order attribute. It is designed to assist developers in implementing complex UI layouts where the vertical arrangement of elements is critical for user interaction and visual design. The document begins by outlining the necessary module imports required to access the functionality within a project. It then provides a thorough breakdown of the `zIndex` function signature, including detailed parameter descriptions and return values to facilitate accurate implementation in code.

A significant portion of the document is dedicated to a practical code example that demonstrates how to handle overlapping components in a real-world scenario. The key takeaway emphasized is that the `zIndex` function accepts an optional Int32 value to determine the display level of a component. The guide clarifies the logic that higher numerical values correspond to higher display levels, allowing those components to visually cover others with lower values. It also specifies that the default stacking value is 0 if no argument is provided.

**Key Takeaways:**
*   **Functionality:** The `zIndex` function is the primary method for adjusting layering.
*   **Data Type:** It utilizes an optional Int32 value for configuration.
*   **Hierarchy:** Higher values result in the component appearing on top.
*   **Default State:** Components default to a Z-order of 0 if not specified.

This documentation is specifically tailored for Cangjie developers who are actively building UIs and need to manage component layering and visibility, particularly when working with Stack layouts where elements naturally occupy the same coordinate space.
