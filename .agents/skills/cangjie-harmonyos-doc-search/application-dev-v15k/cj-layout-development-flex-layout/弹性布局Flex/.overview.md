# 弹性布局Flex

This directory provides a comprehensive guide to Flex layout implementation using the Cangjie language and ArkUI framework. It covers fundamental concepts like main and cross axes, layout directions, wrapping behavior, and adaptive stretching properties. The content includes practical code examples for aligning elements, managing overflow, and creating responsive interfaces. It is suitable for HarmonyOS developers and UI designers seeking to master flexible box layouts for efficient application design.

## Detailed Description

### 场景示例.md 场景示例.md
This document provides a practical code example demonstrating how to implement a specific Flex layout scenario using the Cangjie language and ArkUI framework. The content focuses on configuring the Flex component to achieve horizontal arrangement, space-between justification, and vertical centering of child elements. Key information includes the use of FlexParams with parameters like FlexDirection.Row, FlexAlign.SpaceBetween, and ItemAlign.Center to distribute three text elements evenly within a container. This tutorial is designed for developers using Cangjie who require guidance on UI layout implementation and styling.

### 布局换行.md 布局换行.md
This technical guide explains the wrap property within Flex layouts, detailing how child elements behave when they exceed the container's main axis size. It covers three specific modes: FlexWrap.NoWrap (default compression), FlexWrap.Wrap (standard wrapping), and FlexWrap.WrapReverse (reverse wrapping). The document provides Cangjie code snippets and visual references for each mode, illustrating how the cross-axis direction determines the arrangement of new lines in multi-line layouts. Targeted at HarmonyOS developers using the Cangjie language, this reference helps users control layout overflow and element positioning effectively.

### 概述_3more.md 概述_3more.md
This document serves as a conceptual guide and tutorial for implementing Flex layout within the Cangjie UI framework to efficiently arrange and align child elements. It covers an overview of Flex layout usage, definitions of main and cross axes, and detailed explanations of layout directions controlled by the direction parameter. The text defines core concepts like main and cross axes and provides Cangjie code examples for four direction modes: Row, RowReverse, Column, and ColumnReverse, illustrating how to control element flow. Targeted at HarmonyOS developers using Cangjie, this guide requires basic knowledge of UI component structure and aims to facilitate the construction of navigation bars and page frameworks.

### 自适应拉伸.md 自适应拉伸.md
This guide explains how to achieve adaptive layouts in Flex containers by configuring child element properties in Cangjie. It covers three key attributes: flexBasis for setting base dimensions, flexGrow for distributing remaining space, and flexShrink for defining compression ratios when space is insufficient. The document provides Cangjie code examples and mathematical breakdowns for how space is allocated based on these property values, demonstrating how flexBasis overrides width and how ratios affect sizing. This is intended for developers building UI layouts using the ArkUI framework and Cangjie language who need to manage responsive component sizing.

### 主轴对齐方式/
This directory focuses on the technical implementation of main axis alignment within Flex layouts, a crucial aspect of modern UI design. It comprehensively covers the `justifyContent` parameter, detailing how to control the distribution of space among child elements along the primary axis. Key topics include edge alignment modes like Start, Center, and End, as well as space distribution algorithms such as SpaceBetween, SpaceAround, and SpaceEvenly. The resources provide executable code examples in both Cangjie and ArkTS, making them highly suitable for developers working on cross-platform UIs, specifically those utilizing the HarmonyOS ecosystem or the Cangjie language. Whether you are building responsive interfaces or studying layout mechanics, these documents offer essential syntax and logic to achieve precise layout control.

### 交叉轴对齐方式/
This directory provides a comprehensive technical guide on configuring cross-axis alignment within layout systems, specifically focusing on the ArkUI framework and the Cangjie programming language. It covers the fundamental rules governing parent containers and child elements, detailing how properties like `alignItems`, `alignSelf`, and `alignContent` control positioning. The content explains the priority hierarchy where child settings override container defaults and explores various alignment modes such as Start, Center, Stretch, and Baseline. It is suitable for HarmonyOS developers and UI designers seeking granular control over Flex layouts to build responsive interfaces.
