# 自定义组件的生命周期

This directory provides comprehensive documentation on the lifecycle management of custom components within the ArkUI framework using the Cangjie language. It covers essential API references for lifecycle callbacks such as `aboutToAppear`, `onPageShow`, and `onBackPress`, as well as advanced component reuse mechanisms involving the `@Reusable` decorator and `ReuseParams` class. Additionally, it includes practical code examples demonstrating state management and performance optimization. This resource is designed for ArkUI developers seeking to master component behavior, handle page transitions effectively, and optimize application performance through efficient recycling strategies.

## Detailed Description

### class_ReuseParams.md class_ReuseParams.md
This API reference document details the ReuseParams class, which manages construction parameters for reusable components within the ArkUI framework using the Cangjie language. It covers the class definition, properties like size, initialization methods, and utility functions for parameter retrieval (get), existence checking (contains), and modification (add). Key takeaways include that constructors and the add method are typically not called directly by developers, and the aboutToRecycle lifecycle callback is triggered before a component enters the reuse cache. This guide targets ArkUI developers working with component lifecycle management and optimization in version 12.

### 自定义组件的生命周期_9more.md 自定义组件的生命周期_9more.md

It details specific functions including aboutToAppear, aboutToDisappear, aboutToReuse, onBackPress, onDidBuild, onPageShow, and onPageHide.
