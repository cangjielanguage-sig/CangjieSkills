This directory provides comprehensive API reference documentation for the `DataUriUtils` class within the Cangjie language environment, specifically tailored for HarmonyOS application development. It focuses on the manipulation of URIs by handling numeric IDs, which is essential for managing data paths within the ability runtime. The documentation covers core functionalities such as appending, deleting, retrieving, and updating IDs. It includes detailed syntax, parameters, return values, and exception handling, specifically addressing `BusinessException` error code 401. This resource is intended for Cangjie developers utilizing the AbilityKit who require precise URI management in their applications.
