This directory contains comprehensive API reference documentation for the `HttpRequest` class within the Cangjie programming language's standard library. It serves as a technical guide for developers looking to implement or understand HTTP communication mechanisms. The documentation covers the essential properties and methods required to construct, send, and parse HTTP requests effectively. Key topics include request configuration (headers, body, method), timeout management, protocol versioning, and serialization. It addresses specific behaviors such as the non-concurrent nature of body streams and form data parsing logic. This resource is suitable for software engineers and backend developers working with HTTP protocols who need to manipulate request objects for robust client-server interactions. By detailing attributes like `isPersistent` and `readTimeout`, it provides the necessary tools for fine-tuning network performance and reliability.
