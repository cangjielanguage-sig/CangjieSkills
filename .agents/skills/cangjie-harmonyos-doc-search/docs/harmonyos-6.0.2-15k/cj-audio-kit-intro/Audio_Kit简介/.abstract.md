This directory provides a technical introduction to Audio Kit, a service designed for building high-definition audio capture and immersive playback capabilities. It covers the system architecture, key features like low-latency playback and audio-vibration synchronization, and the configuration of audio streams within the HarmonyOS environment. Core topics include audio stream parameters, PCM formats, and implementation strategies for concurrency and volume management. This documentation is suitable for application developers and audio engineers looking to utilize the Audio Kit API to create high-performance, audio-centric applications.
