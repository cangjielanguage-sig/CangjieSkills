# class_AnimatorResult

This directory provides comprehensive API reference documentation for the `AnimatorResult` class in the Cangjie programming language, specifically designed for the ArkUI framework. It serves as a vital resource for developers looking to define animation initialization parameters, manage event callbacks, and control the entire lifecycle of animations. The documentation covers critical aspects such as handling lifecycle events like `onCancel` and `onFinish`, executing playback commands like `play`, `pause`, and `reverse`, and setting frame rate ranges. Additionally, it details version-specific deprecations regarding property naming and error handling for internal exceptions. This content is highly suitable for ArkUI developers using Cangjie who require granular control over animation logic, state management, and performance optimization in their application interfaces.

## Detailed Description

### class_AnimatorResult_10more.md
This document provides API reference documentation for the Cangjie AnimatorResult class, used for defining animation initialization and handling event callbacks within the ArkUI framework. The main sections detail the class constructor and several mutable properties for animation lifecycle events, specifically onCancel, onFinish, onFrame, and onRepeat. Key information includes the deprecation of lowercase property names in favor of capitalized versions starting from API version 19. All properties are readable and writable, accepting function types, and may throw a BusinessException for internal errors. This guide targets ArkUI developers using Cangjie who need to implement animation logic and manage state changes during playback.

### func_cancel_7more.md
This document serves as an API reference for controlling animation lifecycles in the Cangjie programming language within the ArkUI framework. It details seven key functions: cancel, finish, pause, play, reset, reverse, and setExpectedFrameRateRange. These methods allow developers to start, stop, pause, or modify animations. Most functions require SystemCapability.ArkUI.ArkUI.Full and may throw a BusinessException with error code 100001. The reverse function is incompatible with interpolating-spring curves, while setExpectedFrameRateRange enforces specific min/max constraints. This reference is intended for Cangjie developers building ArkUI applications who need granular control over animation behavior and performance.
