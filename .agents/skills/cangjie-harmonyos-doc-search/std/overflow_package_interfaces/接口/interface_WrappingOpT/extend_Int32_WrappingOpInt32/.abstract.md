This directory provides API reference documentation for the Cangjie programming language, focusing on the `Int32` type's implementation of the `WrappingOp` interface. It details a wide range of arithmetic and bitwise functions, including addition, subtraction, multiplication, division, modulo, negation, and shifting. A core feature of these operations is the use of a high-order truncation strategy, which ensures that results wrap around upon overflow rather than throwing errors. This behavior is essential for scenarios where predictable arithmetic overflow is required. The documentation is specifically tailored for Cangjie developers and systems programmers working on performance-critical or system-level tasks who need precise control over low-level integer operations. The files within this directory break down the general interface implementation and specific function references.
