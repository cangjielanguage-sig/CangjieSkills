# BasicServicesKit

This directory contains the Basic Services Kit for HarmonyOS and OpenHarmony development using the Cangjie programming language. It provides a comprehensive collection of system-level APIs and documentation covering device management (battery, device info), data processing (file upload/download), inter-process communication (common events), and system utilities (settings, time). The kit includes detailed API references, structural definitions, and error code documentation to assist developers in building robust applications. It is suitable for developers working with the Cangjie language who need to integrate core system services and handle system-level exceptions.

## Detailed Description

### [1] README_zh/
This directory serves as the core API index for the Cangjie language Basic Services Kit. It provides a system-level navigation entry covering device management (such as battery monitoring and device info), data file processing (including upload and download), inter-process communication (such as common event mechanisms), and system tools (such as system settings and time management). It also lists error codes for various services to help with exception handling. Most features referenced are currently in the Beta stage, primarily under the `ohos` namespace.

### [2] cj-apis-battery_info/
This directory serves as a comprehensive repository for API documentation related to battery information management within the OpenHarmony ecosystem, specifically tailored for the Cangjie programming language. It encompasses a wide array of interfaces for monitoring and managing battery status.

### [3] cj-apis-common_event_data/
This directory contains the API reference documentation for the `ohos.common_event_data` module in the Cangjie language, designed to define data structures for HarmonyOS common events. It details module imports, project configuration, and the core `CommonEventData` class properties, including event name, package name, and various data types. This module is currently in Beta.

### [4] cj-apis-common_event_manager/
This directory contains the Cangjie (CJ) language API reference documentation for the HarmonyOS Common Event Manager. It provides a comprehensive resource for developers aiming to implement event-driven communication patterns within the HarmonyOS operating system.

### [5] cj-apis-common_event_publish_data/
This directory serves as a comprehensive resource for the `ohos.common_event_publish_data` module within the HarmonyOS operating system, specifically designed for developers using the Cangjie programming language. It provides in-depth information on publishing common events.

### [6] cj-apis-common_event_subscribe_info/
This directory serves as the central repository for API reference documentation regarding the `ohoscommon_event_subscribe_info` module within the HarmonyOS Cangjie development framework. It assists developers in understanding subscription information structures.

### [7] cj-apis-common_event_subscriber/
This directory provides the complete API reference documentation for the `ohos.common_event_subscriber` module in the Cangjie language, specifically defining interface specifications for common event subscribers in the HarmonyOS system. It covers module imports, environment configuration, and usage examples for the `CommonEventSubscriber` class. The module is currently in Beta (starting version 22).

### [8] cj-apis-device_info/
This directory serves as a comprehensive resource for the `cj-apis-device_info` module, focusing on the `ohos.device_info` interface tailored for HarmonyOS dev
