## Detailed Description

### Prop宏父子单向同步_3more.md Prop宏父子单向同步_3more.md
This technical guide explains the @Prop decorator for establishing one-way data synchronization between parent and child components. It covers the synchronization mechanism and specific usage restrictions. Key information includes that @Prop allows local variable mutation but does not sync changes back to the parent; parent updates overwrite local values. It must be declared with var, initialized by the parent, and match the source type. Targeted at developers familiar with @State, this API documentation aids in implementing state management within child components.

### 变量的传递访问规则说明.md 变量的传递访问规则说明.md
This document serves as a technical reference guide detailing the data passing and access rules for variables decorated with the @Prop decorator. The content is structured into a table covering three primary topics: initialization from parent components, usage for initializing child components, and external access permissions. Key takeaways include that @Prop variables must be initialized by the parent upon instance creation and cannot be initialized internally; they support various parent source types like @State and @Link, but only state variables trigger UI refreshes. Additionally, @Prop variables are strictly private to the component, prohibiting external access.

Key information highlights that @Prop facilitates one-way data synchronization from parent to child components, requires specific decorators like @Observed for tracking internal changes in classes or arrays, and advises limiting nesting depth to avoid performance issues.
