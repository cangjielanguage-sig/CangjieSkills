# 示例代码

本目录包含使用仓颉语言在鸿蒙ArkUI框架下开发AlertDialog（警告对话框）的示例代码。内容涵盖了从基础的多按钮弹窗配置到高级的子窗口弹出功能，详细展示了不同参数配置下的实现方式。核心关键词包括AlertDialog、仓颉语言、ArkUI、模态对话框、showInSubWindow。这些示例适合正在学习仓颉语言或进行鸿蒙应用开发的开发者，旨在帮助其掌握弹窗组件的属性设置、事件回调及高级交互逻辑。

## 详细描述

### 示例1弹出多个按钮的弹窗.md
本文档旨在演示如何在鸿蒙ArkUI中使用仓颉语言创建包含多个按钮的警告对话框。文档详细展示了单按钮、双按钮和三按钮弹窗的实现，分别对应AlertDialogParamWithConfirm、AlertDialogParamWithButtons和AlertDialogParamWithOptions三种参数配置。关键信息包括弹窗的属性设置（如标题、对齐方式）以及按钮点击和关闭事件的回调处理。该示例适合正在学习仓颉语言ArkUI开发的开发者，用于掌握弹窗组件的具体用法。

### 示例2可在主窗外弹出的弹窗_3b6958c4.md
本文档旨在演示如何在鸿蒙ArkUI框架中使用仓颉语言实现一个可在主窗口外弹出的AlertDialog。文档主要展示了AlertDialogParamWithOptions组件的配置方法，重点讲解了如何通过设置showInSubWindow参数为true来实现子窗口弹出效果。关键信息包括对话框的标题、消息、按钮布局、偏移量设置以及onWillDismiss生命周期回调的处理逻辑。该示例适合具备仓颉语言基础和ArkUI组件开发经验的开发者参考，用于学习模态对话框的高级交互实现。
