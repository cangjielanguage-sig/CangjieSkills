This directory contains comprehensive API documentation for the `ShowToastOptions` constructor within the Cangjie language and ArkUI framework. It serves as a technical guide for developers aiming to generate configuration objects that control the behavior and visual presentation of toast notifications. The documentation covers a wide array of customizable properties, including message content, display duration, screen positioning, and advanced styling options like background colors and blur effects. Additionally, it outlines system constraints, such as duration clamping and mutual exclusivity of certain style properties. This resource is essential for software engineers and UI developers seeking to implement robust, user-friendly notification popups that adhere to ArkUI standards and best practices.
