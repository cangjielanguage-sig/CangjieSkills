This directory provides essential API references and type definitions for text handling components within the ArkUI framework, specifically designed for the Cangjie language. It encompasses configuration classes that define text selection behaviors and input field constraints, as well as controller classes that offer programmatic manipulation of TextArea components. Key concepts include menu policies for selection, input validation types like EMAIL and NUMBER, and methods for cursor management and text retrieval. This documentation is intended for ArkUI developers who require granular control over text input interfaces, enabling the implementation of robust user interactions and precise input validation in their applications.
