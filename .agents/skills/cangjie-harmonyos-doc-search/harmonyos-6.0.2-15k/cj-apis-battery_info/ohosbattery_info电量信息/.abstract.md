This directory contains API reference documentation for the `ohos.battery_info` module in the Cangjie programming language, designed for HarmonyOS power management. It covers interfaces for querying battery metrics, charging states, health status, and common event keys. Key components include enums for capacity levels, charge states, health states, and plugged types, alongside the main `BatteryInfo` class for real-time data retrieval. This resource is suitable for Cangjie developers and system engineers implementing battery monitoring, power management features, and energy consumption tracking in their applications.
