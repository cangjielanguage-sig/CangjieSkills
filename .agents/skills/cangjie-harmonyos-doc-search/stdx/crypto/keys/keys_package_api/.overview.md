# keys_package_api

The `keys_package_api` directory serves as the central API documentation hub for cryptographic key management within the Cangjie programming language. It provides comprehensive references for implementing and manipulating asymmetric encryption keys, supporting standard algorithms like RSA and ECDSA. This package covers essential components including key classes, enumeration types for algorithm configurations, and structures for padding options. It is designed for backend developers and security engineers who require precise technical specifications to integrate secure cryptographic operations into their applications.

## Detailed Description

### keys_package_classes/
This directory serves as a comprehensive API reference for cryptographic key management within the Cangjie programming language. It focuses on the implementation and manipulation of asymmetric encryption keys, specifically supporting standard algorithms.

### keys_package_enums/
This directory is specifically used to store API reference documentation for key package-related enumeration types. Its core goal is to define and standardize the various configuration options required for cryptographic algorithm implementations. The documentation content primarily focuses on two core components: the `Curve` enumeration used for ECDSA (Elliptic Curve Digital Signature Algorithm) key generation, which details eight mainstream elliptic curves including the NIST P-series and Brainpool BP-series and elaborates on their respective security characteristics; and the `PadOption` enumeration used for RSA encryption operations, covering multiple padding modes such as OAEP, PSS, and PKCS1, while explicitly advising developers to prioritize secure options.

### keys_package_structs/
This directory contains technical documentation for key package structures, primarily involving API references for configuring encryption padding modes. The documentation details two structures that are crucial during RSA encryption and signature processes: `OAEPOption` and `PSSOption`. The content not only covers the definitions and initialization methods of these structures but also explains parameter configuration in depth, including the selection of digest algorithms, the setting of optional labels, and the limits and exception handling of random salt lengths. This document aims to provide developers with precise interface guidance to help them correctly implement secure encryption functions. The target audience includes backend developers or security engineers possessing basic cryptography knowledge, particularly those with an understanding of asymmetric encryption padding schemes.
