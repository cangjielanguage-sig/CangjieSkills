# class_MediaAssetChangeRequest

本目录包含仓颉语言中 `MediaAssetChangeRequest` 类的 API 参考文档，属于 HarmonyOS MediaLibraryKit 的一部分。文档涵盖了在应用沙箱内创建、修改和删除媒体资产（图片、视频）的核心功能。主要内容包括初始化变更请求、通过 ArrayBuffer 添加资源、管理相机照片、设置标题以及删除资产。文档详细说明了系统能力、所需权限（如 `WRITE_IMAGEVIDEO`）及异常处理机制。该文档面向使用仓颉语言构建 HarmonyOS 媒体管理应用的开发者，提供了与 PhotoAccessHelper 和文件系统交互的必要方法。

## Detailed Description

### class_MediaAssetC_3more_86a2e521.md
本文档是Cangjie语言中MediaAssetChangeRequest类的API参考文档，旨在定义媒体资产变更请求的创建与初始化方式。文档主要涵盖类的基本定义、用于初始化现有资产变更的构造函数init，以及用于创建新资产请求的静态方法createAssetRequest。关键信息包括参数类型（如PhotoAsset、UIAbilityContext）、CreateOptions配置选项、返回值说明及BusinessException异常处理机制。该文档面向使用MediaLibraryKit进行媒体文件管理的开发者，要求读者具备Cangjie编程基础及文件管理相关系统能力的了解。

### func_addResourceR_2more_6bde9a1a.md
本文档是Cangjie语言的API参考文档，旨在说明MediaAssetChangeRequest类中用于媒体资源管理的两个核心函数。文档主要涵盖addResource函数，用于通过ArrayBuffer数据添加图片或视频资源，并特别指出动态照片可调用两次；以及discardCameraPhoto函数，用于删除相机拍摄的照片。内容详细列出了参数定义、系统能力要求、BusinessException异常处理及完整的代码示例。该文档面向使用PhotoAccessHelper进行文件操作和媒体库开发的开发者，提供了具体的错误码参考和实现逻辑。

### func_getAsset_2more_6d16377a.md
本文档是Cangjie语言的API参考文档，详细介绍了媒体资产管理中`getAsset`和`getWriteCacheHandler`两个函数的用法。文档涵盖了函数定义、系统能力、返回值、异常处理及代码示例。关键信息包括：`getAsset`用于获取当前变更请求中的资产对象，而`getWriteCacheHandler`用于获取临时文件写句柄以写入数据，后者需要特定权限。文档还列出了相关的错误码和异常情况。目标受众是使用MediaLibraryKit进行照片资产管理和文件操作的开发者。

### func_saveCameraPh_2more_9e99ac43.md
本文档是Cangjie语言的API参考文档，介绍了MediaAssetChangeRequest类中的saveCameraPhoto和setTitle方法。文档详细说明了这两个函数的功能、系统能力、异常错误码及参数规格，特别是setTitle对文件名长度和非法字符的限制。通过提供的代码示例，展示了如何利用PhotoAccessHelper获取资源并应用更改。该文档面向HarmonyOS开发者，旨在指导其实现相机照片保存及媒体资产标题修改功能。

### static_func_creat_2more_30bc9d23.md
本文档是HarmonyOS MediaLibraryKit中MediaAssetChangeRequest类的API参考文档，主要介绍了创建视频资产变更请求和删除媒体资产的静态方法。文档详细阐述了createVideoAssetRequest和deleteAssets两个核心函数，涵盖了函数签名、参数说明（如UIAbilityContext和fileUri）、返回值、所需权限（如WRITE_IMAGEVIDEO）、系统错误码及Cangjie代码示例。关键要点包括文件必须位于应用沙箱内、删除操作限制300个元素以及异常处理机制。该文档面向使用Cangjie语言进行HarmonyOS应用开发的开发者，旨在指导其实现媒体库的增删操作。

### static_func_createImage_f9225996.md
本文档是MediaLibraryKit中静态函数createImageAssetRequest的API参考，用于根据应用沙箱内的文件URI创建图片资产变更请求。文档详细说明了函数签名、系统能力、输入参数（UIAbilityContext和fileUri）、返回值MediaAssetChangeRequest及可能抛出的BusinessException异常。关键点在于fileUri必须位于应用沙箱，生成的请求需配合applyChanges使用。该功能起始版本为22，面向使用仓颉语言开发鸿蒙应用并需管理图片资源的开发者。

### static_func_delet_2more_122f0ec8.md
