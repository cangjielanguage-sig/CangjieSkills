### extensionAbilities标签_3.md extensionAbilities标签_3.md
本文档是关于应用配置文件中extensionAbilities标签的参考文档，旨在详细说明MainProcess、dataGroupIds和process等关键配置项的定义与用法。文档涵盖了这些标签的数据类型、缺省值及特定约束条件，重点阐述了数据共享机制与进程管理规则。关键信息包括：dataGroupIds需匹配签名证书配置以实现数据目录共享，且仅在独立沙箱目录下生效；process标签仅适用于type为embeddedUI的组件，自API 14起支持，用于在2in1设备上控制进程运行。该文档主要面向需要进行应用模块配置、数据隔离及进程管理的开发者，提供了具体的参数规范和生效条件说明。
