# PerformanceAnalysisKit

The PerformanceAnalysisKit is a comprehensive documentation suite designed for developers using the Cangjie programming language within the HarmonyOS/OpenHarmony ecosystem. It focuses on application performance monitoring, debugging, and event tracking. This kit covers essential modules such as HiLog for logging, HiAppEvent for event tracking, HiTraceMeter for process tracing, and Hidebug for CPU usage analysis. It is suitable for application developers and system engineers who need to implement monitoring features, analyze system performance, or troubleshoot errors using specific error codes and API references.

## Detailed Description

### [1] README_zh
This directory serves as the index document center for the Cangjie programming language performance analysis service (Beta feature). It aims to provide developers with a comprehensive reference for API interfaces and error codes. The documentation focuses on key monitoring and debugging functions in application development, including core APIs for application event marking, HiLog logging, and performance marking. Additionally, it details error code definitions related to application event marking and Hidebug CpuUsage. This directory is suitable for all developers using the Cangjie language, particularly for performance analysis, log recording, and troubleshooting, helping to improve development efficiency.

### [2] cj-apis-hi_tracemeter
This directory serves as a central repository for documentation related to the `cj-apis-hi_tracemeter` module, specifically tailored for the HarmonyOS Cangjie development environment. It addresses the critical need for process trace tracking and provides the necessary interfaces for developers to monitor and trace process execution effectively.

### [3] cj-apis-hiappevent
This directory serves as a comprehensive repository for the HarmonyOS HiAppEvent module API documentation, specifically tailored for the Cangjie programming language. It focuses on the critical aspects of application event tracking, monitoring, and observation, enabling developers to capture and manage application events efficiently.

### [4] cj-apis-hilog
This directory serves as a comprehensive resource for the HiLog logging module tailored for the Cangjie programming language within the HarmonyOS/OpenHarmony development environment. It provides essential documentation for developers aiming to implement robust logging mechanisms in their applications.

### [5] cj-errorcode-hiappevent
This directory serves as a comprehensive repository for error code documentation related to the HiAppEvent module, a critical component for application event tracking and logging. It provides a structured approach to identifying and rectifying faults that may occur during event handling.

### [6] cj-errorcode-hidebug-cpuusage
This directory specifically collects error code reference documents for the Hidebug CpuUsage module, focusing on specific exceptions that may occur during the module's Beta phase. The core content covers a detailed analysis of error code 11400104, delving into the "CpuUsage statistics anomaly" phenomenon. It analyzes potential causes, particularly fault logic related to the hiview service process startup status. This material is intended for application developers and system maintenance engineers to assist in quickly locating and resolving technical issues related to CPU usage statistics.
