This directory contains API documentation for the Cangjie `JSHashMapEx` class, a specialized data structure designed for seamless interoperability with ArkTS Map types. It covers the class definition, generic constraints requiring keys to be JSKeyable, and various methods for data manipulation, conversion, and inspection. Key topics include constructors, static conversion methods, and instance operations like insertion, deletion, and retrieval. This documentation is suitable for Cangjie developers working on HarmonyOS applications who need to manage key-value data across language boundaries, ensuring thread safety and proper type handling.
