# PersistentStorage持久化存储UI状态

This directory provides comprehensive technical documentation on PersistentStorage, a singleton object designed to persist specific AppStorage properties to disk, ensuring UI state retention across application restarts. It covers the synchronization mechanism between PersistentStorage and AppStorage, detailing how data is written and retrieved. Key topics include supported data types (simple types and JSON-serializable objects), strict limitations (prohibition of nested objects, 2kb size limit), and initialization sequences. The documentation also explores usage scenarios within Cangjie applications, emphasizing the critical importance of calling PersistentStorage before AppStorage to prevent data loss. It is intended for HarmonyOS developers and application developers familiar with AppStorage who need to implement robust state management and data persistence efficiently while adhering to performance best practices.
