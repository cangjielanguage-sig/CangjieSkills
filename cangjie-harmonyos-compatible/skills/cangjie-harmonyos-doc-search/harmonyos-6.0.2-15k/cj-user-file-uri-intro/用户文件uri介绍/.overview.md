# 用户文件uri介绍

This directory provides a complete technical overview of User File Uniform Resource Identifiers (URIs) within the HarmonyOS ecosystem, serving as a critical guide for developers handling file operations. It thoroughly covers the structural definitions, categorization, and acquisition methods for both Document and Media file URIs. Key topics include detailed URI field definitions, the implementation of picker interfaces such as `DocumentViewPicker`, `AudioViewPicker`, and `PhotoViewPicker`, and specific permission handling requirements for normal-level applications using the `fs` module. Additionally, it addresses security best practices, such as warnings against parsing URI fragments. This documentation is specifically designed for HarmonyOS developers utilizing ArkTS or Cangjie who require a deep understanding of file URI structures to implement secure, efficient, and error-free file management, querying, and metadata extraction in their applications.
