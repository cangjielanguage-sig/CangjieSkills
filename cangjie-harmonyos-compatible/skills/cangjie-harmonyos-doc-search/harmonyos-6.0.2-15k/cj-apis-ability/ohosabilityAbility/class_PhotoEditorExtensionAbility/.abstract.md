This directory provides comprehensive API reference documentation for the `PhotoEditorExtensionAbility` class, specifically designed for the Cangjie programming language. It serves as a technical resource for developers implementing photo editing extension pages within HarmonyOS applications. The content covers essential aspects such as class definitions, inheritance from `ExtensionAbility`, and the management of lifecycle methods including `onCreate`, `onForeground`, and `onDestroy`. Furthermore, it details content editing callbacks for handling image loading and UI sessions. This documentation is highly suitable for HarmonyOS developers aiming to build robust photo editing features, offering code examples and system capability requirements starting from API version 19 to ensure proper integration and resource management.
