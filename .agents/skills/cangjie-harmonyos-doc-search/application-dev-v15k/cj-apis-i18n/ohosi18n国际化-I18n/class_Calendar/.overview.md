# class_Calendar

This directory contains API reference documentation for the Calendar class within the Cangjie programming language's LocalizationKit. It covers comprehensive functionalities for date manipulation, time zone management, and internationalization (I18n) logic. Key topics include retrieving and setting date fields, calculating day differences, checking weekends, and configuring locale-specific calendar rules like week start days. The documentation is designed for developers working on HarmonyOS applications who need to implement robust date and time handling, arithmetic, and formatting across different locales using Cangjie syntax.
