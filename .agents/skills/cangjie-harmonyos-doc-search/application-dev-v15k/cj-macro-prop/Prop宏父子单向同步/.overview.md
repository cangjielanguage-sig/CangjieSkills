It covers core concepts such as variable initialization, access rules, type constraints, and synchronization mechanisms. ### Prop宏父子单向同步_3more.md Prop宏父子单向同步_3more.md
This technical guide explains the usage and behavior of the @Prop decorator for managing one-way data synchronization between parent and child components. The document covers an overview of the synchronization mechanism and specific limitations regarding variable declaration and initialization. Key takeaways include that @Prop variables are mutable locally but do not sync changes back to the parent, and any parent update overwrites local modifications. It also details strict constraints such as the prohibition of local initialization and the requirement for type consistency with the parent's state variables. Intended for developers familiar with @State, this documentation serves as a reference for implementing unidirectional state flow in component architecture.

### 变量的传递访问规则说明.md 变量的传递访问规则说明.md
This document serves as a technical reference guide detailing the initialization, passing, and access rules for variables decorated with the @Prop decorator. The content is structured into a table covering three primary topics: initialization from parent components, usage for initializing child components, and external access permissions. Key information includes that @Prop variables must be initialized by the parent upon instance creation and cannot be initialized internally. They support various parent source types such as @State and @Link, but only state variables trigger UI refreshes. Additionally, @Prop variables are strictly private to the component and cannot be accessed externally or modified with access modifiers. This guide is intended for developers managing component state and data flow within the framework.
