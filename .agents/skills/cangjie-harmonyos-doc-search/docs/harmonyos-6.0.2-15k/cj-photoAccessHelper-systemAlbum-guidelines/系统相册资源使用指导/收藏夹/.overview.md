# 收藏夹

This directory serves as a comprehensive technical resource for developers working within the HarmonyOS ecosystem, specifically utilizing the Cangjie programming language. It focuses on the MediaLibraryKit and provides in-depth guidance on interacting with the system's Favorites album. The documentation covers critical aspects of media access, including the necessary prerequisites such as obtaining the photoAccessHelper instance and securing READ_IMAGEVIDEO permissions. It details the technical procedures for retrieving the Favorites album object and fetching specific media assets like images and videos. These guides are intended for software engineers and application developers who need to implement features that access or manage user-favorited content, offering practical code examples and step-by-step instructions to facilitate seamless integration with the system media library.

## Detailed Description

The following documents provide specific technical implementations and tutorials for managing favorites.

### 收藏夹_2more.md 收藏夹_2more.md
This technical guide explains how to programmatically access the system Favorites album using the MediaLibraryKit in the Cangjie language. The document defines the Favorites album functionality and details the process of retrieving the album object. Key sections include prerequisites such as obtaining the photoAccessHelper instance and applying for the READ_IMAGEVIDEO permission. The core instruction demonstrates using the getAlbums interface with specific parameters, AlbumType.SYSTEM and AlbumSubtype.FAVORITE. It provides practical Cangjie code examples showing the implementation steps, error handling, and context initialization. This guide is intended for developers building media applications who need to interact with user-favorited image or video content.

### 获取收藏夹中的图片和视频.md 获取收藏夹中的图片和视频.md
This document provides a tutorial for developers on retrieving images and videos from the system favorites album using the MediaLibraryKit in the Cangjie programming language. It covers prerequisites such as obtaining the photoAccessHelper instance and applying for read permissions. The guide outlines a step-by-step process to fetch the favorite album object, establish search conditions using FetchOptions, and retrieve assets via the getAssets interface. Key code examples demonstrate using getFirstObject to access specific media items. Intended for HarmonyOS developers, this guide requires basic understanding of the photo access module and permission handling.
