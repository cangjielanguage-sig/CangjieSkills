# class_AdDisplayOptions

This directory contains comprehensive API reference documentation for the `AdDisplayOptions` class within the Cangjie programming language, specifically designed for the AdsKit framework. A solid understanding of Cangjie syntax and the AdsKit environment is recommended for effective implementation of these advertising features.
