# interface_BaseProfile

This directory contains API reference documentation for the `BaseProfile` interface within the HarmonyOS ConnectivityKit, specifically designed for the Cangjie programming language. It covers the fundamental functionalities required for Bluetooth profile management, including methods to retrieve connected device lists, check connection states, and handle event subscriptions. Key topics include asynchronous callbacks for connection state changes, permission management (specifically `ohos.permission.ACCESS_BLUETOOTH`), and error handling via business exceptions. This documentation is intended for software developers integrating Bluetooth connectivity features into HarmonyOS applications who need to manage profile lifecycles and event listeners effectively.
