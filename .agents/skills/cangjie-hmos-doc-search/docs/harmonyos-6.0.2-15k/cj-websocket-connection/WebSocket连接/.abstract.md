This directory serves as a comprehensive technical resource for implementing WebSocket connections within HarmonyOS applications, specifically utilizing the Cangjie language and NetworkKit. It covers the full spectrum of WebSocket development, ranging from high-level API references and theoretical overviews to practical, step-by-step coding tutorials. Key topics include the WebSocket connection lifecycle, event handling for open, message, close, and error states, heartbeat mechanisms, and asynchronous event-driven architecture. The documentation details essential interfaces such as `createWebSocket`, `connect`, `send`, and `close`, alongside necessary permissions like `ohos.permission.INTERNET`. This resource is ideal for application developers and Cangjie programmers seeking to establish robust, real-time bidirectional communication between clients and servers efficiently.
