This directory contains API reference documentation for the `GattClientDevice` class in the Cangjie language, part of the ConnectivityKit. It focuses on Bluetooth Low Energy (BLE) client operations, enabling developers to manage connections, read/write characteristics and descriptors, and handle asynchronous events. Key functionalities include device connection management, service discovery, MTU configuration, and event subscription for state or value changes. This documentation is suitable for software developers and application engineers building BLE-enabled applications who need detailed function signatures, error codes, and Cangjie code examples to implement robust connectivity features.
