This directory functions as a specialized technical resource hub designed to assist developers in integrating web pages seamlessly with the HarmonyOS system password vault. Its primary focus is on enabling secure credential saving and auto-filling capabilities by leveraging the ArkWeb component. The documentation encompasses a broad spectrum of technical requirements, including distinct user scenarios for mobile phones and 2-in-1 devices, comprehensive workflows for password management, and vital constraints regarding form submission triggers and Native app instance lifecycle management. Additionally, it offers in-depth specifications for designing password login forms that ensure compatibility with ArkWeb and Chromium-based auto-fill algorithms. This guide is indispensable for HarmonyOS developers, front-end engineers, and security professionals aiming to create robust, user-friendly, and secure authentication interfaces that fully leverage system-level password management tools to enhance the overall user experience.
