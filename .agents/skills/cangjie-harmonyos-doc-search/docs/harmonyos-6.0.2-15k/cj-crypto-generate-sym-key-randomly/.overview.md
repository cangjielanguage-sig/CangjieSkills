# cj-crypto-generate-sym-key-randomly

This directory serves as a specialized resource hub for developers utilizing the Cangjie programming language, specifically targeting the domain of cryptographic security. The primary focus of this collection is the random generation of symmetric keys, a fundamental requirement for secure data encryption and decryption processes. The content provides an in-depth look at generating keys for two widely used algorithms: AES-256, the global standard for high-security encryption, and SM4-128, a standard commonly used in specific regulatory environments. By leveraging the CryptoArchitectureKit, developers are guided through a structured three-step methodology. This involves the technical instantiation of a SymKeyGenerator using precise algorithm strings, the invocation of the generateSymKey function to instantiate the key object, and the subsequent extraction of the key material via the getEncoded method. This ensures that the keys are not only generated securely but are also formatted correctly for storage or transmission across networks. The tutorial is designed to bridge the gap between theoretical cryptographic concepts and practical application, making it highly suitable for Cangjie developers, backend engineers, and security professionals who are tasked with building robust security features. It addresses the specific API calls, parameter requirements, and coding patterns necessary to successfully implement these cryptographic primitives within the Cangjie ecosystem.

### cj-crypto-generate-sym-key-randomly.md cj-crypto-generate-sym-key-randomly.md
This document serves as a tutorial for developers on how to randomly generate symmetric keys using the Cangjie programming language. It specifically covers the generation of AES-256 and SM4-128 keys using the CryptoArchitectureKit. The guide details the three-step process: creating a SymKeyGenerator with a specified algorithm string, invoking generateSymKey to produce the key object, and calling getEncoded to obtain the binary data for storage or transmission. Code examples are provided for both algorithms to demonstrate practical implementation. This resource is intended for Cangjie developers implementing cryptographic security features who need to understand the specific API calls and parameters required for key generation.
