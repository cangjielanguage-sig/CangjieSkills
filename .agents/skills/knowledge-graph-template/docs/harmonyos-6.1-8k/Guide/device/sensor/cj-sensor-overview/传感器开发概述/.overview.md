## 详细描述

### 传感器开发概述_2more_818f4a32.md
本文档旨在概述传感器开发的基本概念，指导开发者如何通过Sensor接口访问底层硬件并订阅数据。文档主要介绍了系统传感器的定义及其在指南针、运动健康等应用中的场景，并详细列举了加速度、陀螺仪、计步器、环境光、心率等多种传感器类型。关键信息包括各传感器的测量维度、单位及具体用途，如检测运动状态或调节屏幕亮度。这是一份面向应用开发者的概述性文档，适用于需要利用硬件传感器进行算法开发和应用构建的场景。关键词：传感器、Sensor接口、加速度计、陀螺仪、心率检测。

### 运作机制_2more_4986e93e.md
本文档旨在阐述传感器子系统的运作机制及其开发约束与限制。主要涵盖传感器架构的四个模块（Sensor API、Sensor Framework、Sensor Service和HDF层）的功能职责，以及传感器数据获取所需的权限管理规则。关键信息包括各层级间的数据交互与通信方式，不同传感器（如加速度计、陀螺仪、心率计）对应的敏感权限级别，以及订阅与取消订阅接口必须成对调用的开发规范。面向需要集成传感器功能的系统开发者或应用开发者，帮助其理解底层架构及合规使用传感器数据。
