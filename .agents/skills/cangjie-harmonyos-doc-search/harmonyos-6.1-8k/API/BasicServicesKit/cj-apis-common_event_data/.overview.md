# cj-apis-common_event_data

本目录包含仓颉语言中 `ohos.common_event_data` 模块的 API 参考文档，旨在定义鸿蒙系统公共事件的数据结构。文档详细介绍了模块导入方式、仓颉工程配置说明以及核心类 `CommonEventData` 的属性定义，涵盖事件名称、包名、整型数据、字符串数据及附加参数等关键信息。该类封装了订阅者接收的数据，其字段值与发布者通过 `CommonEventPublishData` 传递的数据保持一致。该模块目前处于 Beta 阶段，具备系统通知能力。本文档适合具备基本工程配置和 Context 上下文知识的仓颉语言鸿蒙应用开发者，用于实现事件订阅与发布机制。

### cj-apis-common_event_data.md cj-apis-common_event_data.md
本文档是仓颉语言中 ohos.common_event_data 模块的 API 参考文档，旨在定义公共事件的数据结构。文档涵盖了模块导入方式、仓颉工程使用说明以及核心类 CommonEventData 的详细属性定义，包括事件名称、包名、整型数据、字符串数据及附加参数。关键信息指出，该类封装了订阅者接收的数据，其字段值与发布者通过 CommonEventPublishData 传递的数据一致。该模块目前处于 Beta 阶段，具备系统通知能力。文档面向使用仓颉语言开发鸿蒙应用的开发者，需具备基本的工程配置和 Context 上下文知识。
