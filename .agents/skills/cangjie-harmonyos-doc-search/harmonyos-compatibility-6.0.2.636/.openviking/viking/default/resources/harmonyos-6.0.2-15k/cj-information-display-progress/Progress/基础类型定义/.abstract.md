This directory contains API reference documentation for basic type definitions related to the Progress component within the HarmonyOS ArkUI framework using the Cangjie language. It covers a comprehensive range of style options classes (such as Linear, Ring, Eclipse, ScaleRing, and Capsule), configuration classes for progress values, and enumerations for status and style types. These definitions allow developers to fine-tune visual appearance, animation behaviors (like smooth and scan effects), and state management for progress indicators. It is suitable for software developers and UI designers working with ArkUI who require precise control over component styling and behavior.
