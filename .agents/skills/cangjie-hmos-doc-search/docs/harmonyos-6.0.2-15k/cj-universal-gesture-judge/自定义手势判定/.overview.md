# 自定义手势判定

This directory focuses on customizing gesture recognition logic within the ArkUI framework using the Cangjie language. It covers the implementation of the `onGestureJudgeBegin` callback to resolve gesture conflicts, reject specific gestures, and distinguish between events like LongPress and Drag based on touch regions. Key topics include `GestureJudgeResult`, `GestureInfo`, and event handling structures. It is suitable for HarmonyOS application developers who need granular control over UI interactions and complex touch event processing.

## Detailed Description

### 示例代码1_2more.md
This document serves as a code tutorial for Cangjie developers, demonstrating how to customize gesture recognition and resolve conflicts using the onGestureJudgeBegin callback. The content is divided into two primary examples: the first illustrates how to selectively reject specific gestures like Pan while logging others, and the second details region-based judgment to distinguish between LongPress and Drag events based on touch coordinates within a Stack. Key takeaways include the usage of GestureJudgeResult (REJECT/CONTINUE) and accessing GestureInfo properties. This guide is intended for developers building complex UI interactions in HarmonyOS applications.

### 自定义手势判定_2more.md
This API documentation provides developers with the ability to implement custom gesture judgment logic for UI components in the Cangjie language. The document details the `onGestureJudgeBegin` function, including its signature, system capabilities, and parameter definitions. Key information includes that this function binds a callback triggered when a gesture is accepted, allowing developers to return a `GestureJudgeResult` based on `GestureInfo` and `BaseGestureEvent` inputs. It is intended for application developers using the ArkUI framework who require granular control over gesture recognition and response behaviors.
