This directory provides comprehensive API reference documentation for configuring component properties within the Cangjie ArkUI framework, with a specific focus on image components. It covers essential functionalities such as setting image sources, managing display attributes, optimizing memory usage, and handling user interactions. Key topics include placeholder configuration, color transformations, drag-and-drop capabilities, object fitting, and loading strategies. Designed for software developers and UI engineers, these documents offer detailed parameters, system capabilities, and constraints to facilitate the creation of high-performance, visually consistent user interfaces using the Cangjie language.
