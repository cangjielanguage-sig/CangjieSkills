### interface_IReentrantMutex__3more.md interface_IReentrantMutex__3more.md

This document serves as API reference documentation for synchronization interfaces in the Cangjie language, specifically focusing on mutex implementations. It details the deprecated IReentrantMutex interface, its replacement Lock, and the extended UniqueLock interface. Key sections cover methods for locking, attempting locks, and unlocking, with UniqueLock adding support for condition variables. Important takeaways include the deprecation of IReentrantMutex in favor of Lock and the critical requirement for implementers to ensure underlying support for nested locking to prevent deadlocks. This guide targets developers building concurrent systems who need to implement or utilize thread-safe locking mechanisms.
