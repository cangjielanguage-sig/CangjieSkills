## Detailed Description

### Provide宏和Consume宏与后代组件双向同步_3more.md Provide宏和Consume宏与后代组件双向同步_3more.md
This technical reference guide explains the `@Provide` and `@Consume` macros for implementing two-way data synchronization between ancestor and descendant components in the Cangjie framework. The document covers an overview of cross-level state management features and detailed specifications for both macros, including parameters, synchronization types, and supported variable types. Key takeaways include that `@Provide` decorates ancestor variables to make them available to descendants, while `@Consume` binds to them via matching names or aliases. The system supports one-to-many relationships and selects the nearest ancestor if multiple providers exist. Intended for developers familiar with Cangjie's declarative UI and custom components, this guide facilitates efficient state management without manual parameter passing.

### 变量的传递访问规则说明.md 变量的传递访问规则说明.md
This document acts as a technical reference guide detailing the variable passing and access rules for the @Provide and @Consume decorators. It is structured into two main sections, each presenting a table of rules for one decorator. Key information includes that @Provide allows initialization from various parent variable types but does not sync with the parent; instead, it creates a two-way data binding with @Consume in descendant components. Conversely, @Consume is initialized by matching the name or alias of an ancestor's @Provide variable. Both decorators enforce private visibility within their components. This guide is intended for developers managing state across component hierarchies, requiring knowledge of state variables and component lifecycles. Keywords: state management, data binding, component communication, ArkTS, HarmonyOS.

### 限制条件.md 限制条件.md
This reference guide defines the constraints and usage rules for the @Provide and @Consume decorators in the Cangjie language. It covers key type requirements, initialization restrictions, duplicate key resolution, and error handling for missing providers. Key takeaways include that keys must be string literals, @Consume variables cannot be locally initialized, and duplicate keys bind to the nearest provider in the component tree. Type consistency is mandatory to prevent runtime errors. This document targets Cangjie developers implementing state management across component hierarchies.
