# extend_Rune_UnicodeRuneExtension

This directory provides comprehensive API reference documentation for extending the Cangjie language's `Rune` type to implement the `UnicodeRuneExtension` interface. The documentation details member functions for identifying character properties—such as determining if a character is a letter, number, or whitespace—and functions for transforming character case, including support for locale-specific options. By adhering to specific Unicode definitions, these resources enable precise text manipulation.
