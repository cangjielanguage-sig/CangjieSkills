# media

This directory serves as the central hub for multimedia development documentation within the OpenHarmony and HarmonyOS ecosystems, specifically tailored for the Cangjie programming language environment. It encompasses four core Beta-stage modules: Camera Kit, Image Kit, Media Kit, and Media Library Kit. The content covers the full spectrum of media handling, ranging from low-level processing and camera operations to upper-layer file management. It is designed for developers seeking to integrate comprehensive multimedia capabilities into their applications, providing a complete functional chain from processing to management. This resource helps developers quickly locate specific service documentation and understand relevant Beta features to enhance their development workflow.
