# 组件事件

This directory provides API reference documentation for the ArkUI WaterFlow component using the Cangjie language. It encompasses classes for managing waterfall flow sections, enums for defining layout directions and modes, and functions for handling scroll events. Developers will find resources for configuring layout strategies like ALWAYS_TOP_DOWN and SLIDING_WINDOW, managing section data, and implementing callbacks for scroll boundaries and index tracking. This documentation is intended for HarmonyOS developers building dynamic, high-performance user interfaces.

## Detailed Description

### class_WaterFlowSections.md
This API reference document details the WaterFlowSections class, which manages grouping information for waterfall flow layouts within the ArkUI framework using the Cangjie language. The documentation outlines the class constructor and essential methods for manipulating section data, including length, push, splice, update, and value. Key functionality involves adding sections to the end, modifying configurations at specific indices, and complex splicing operations to remove or replace groups. Methods return UInt32 for counts or Boolean for success status, often validating that itemsCount is a positive integer. This technical guide targets developers building dynamic waterfall flow user interfaces for HarmonyOS applications.

### enum_WaterFlowDirection.md
This document provides API reference documentation for the WaterFlowDirection enum in the Cangjie language, used to define the main axis direction of layouts within the ArkUI framework. The content outlines the enum's structure and details its four specific members: Row, Column, RowReverse, and ColumnReverse. Key information includes the functional description of each member, specifying whether the layout follows a standard or reversed horizontal and vertical flow. This reference is intended for software developers utilizing ArkUI system capabilities to configure user interface layouts, specifically requiring knowledge of layout axes and directional flow concepts.

### enum_WaterFlowLayoutMode.md
This document provides API reference documentation for the WaterFlowLayoutMode enum in the Cangjie language, defining layout strategies for the WaterFlow component. It covers two primary modes: ALWAYS_TOP_DOWN, the default mode that calculates layout based on all preceding items, and SLIDING_WINDOW, which optimizes performance by only considering the viewport. Key information highlights that SLIDING_WINDOW is ideal for scenarios with frequent column switching but carries specific limitations, including lack of scrollbar support, restricted scrolling API usage, and potential layout inconsistencies after long jumps. This guide targets HarmonyOS developers seeking to optimize rendering performance in ArkUI applications.

### func_onReachEnd_-_Unit_4more.md
This document serves as API reference documentation for event handling functions within the ArkUI WaterFlow component, specifically focusing on scroll and position events. It details four key functions: onReachEnd, onReachStart, onScrollFrameBegin, and onScrollIndex. Each entry provides the Cangjie function signature, system capabilities, and parameter definitions. Key information includes how to trigger callbacks when the list reaches boundaries, how to modify scroll offsets during frame updates, and how to track changes in visible item indices. The document is intended for developers building user interfaces with the ArkUI framework who need to implement custom scroll logic, infinite scrolling, or index tracking in waterfall layouts.

### class_SectionOptions/
This directory contains API reference documentation for the `SectionOptions` class in the Cangjie language, specifically designed for the ArkUI framework. It focuses on configuring FlowItem grouping within waterfall flow layouts. The documentation covers class structures, initialization methods, and properties such as item counts, cross-axis counts, spacing, and dynamic sizing callbacks. It is intended for developers building complex UI interfaces who need to customize layout efficiency and appearance in ArkUI applications, starting from API version 19.
