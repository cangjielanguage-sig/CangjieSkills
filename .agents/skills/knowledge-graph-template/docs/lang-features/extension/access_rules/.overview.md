# access_rules

This directory serves as the definitive resource for understanding the access control and modifier rules that apply to the extension mechanism within the Cangjie programming language. As extensions are a powerful feature for adding functionality to existing types, strict rules are necessary to maintain code safety and modularity. This directory covers a wide array of technical specifications, including the restrictions placed on modifiers, the enforcement of the orphan rule to prevent conflicting implementations, and the granular control over member access permissions. It also explains shadowing restrictions and how visibility is managed for generic extensions. Beyond the syntax, the documentation explores the architectural aspects of extensions, specifically their import and export mechanisms and the logic governing cross-package calls. Essential keywords for this section include extensions, access control, modifiers, orphan rules, and import/export. This material is specifically designed for developers who require a deep dive into the functional boundaries of Cangjie extensions and those looking to implement robust module encapsulation in their software projects.
