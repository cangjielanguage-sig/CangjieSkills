This directory contains API reference documentation for the `Curves` class and related static functions in the Cangjie language, specifically designed for the ArkUI framework. It covers the creation of various interpolation curves used to define animation timing and transitions, ranging from standard Bezier curves to physics-based spring motions and discrete step curves. Key topics include cubic Bezier construction, custom interpolation logic, spring dynamics (mass, stiffness, damping), and responsive motion for touch interactions. This documentation is suitable for HarmonyOS developers using Cangjie who need to implement realistic, non-linear, or physics-driven animation effects in their user interfaces.
