This directory contains API documentation for the Cangjie language's `BigEndianOrder` interface and its type extensions. It covers the implementation of big-endian byte serialization and deserialization for various numeric and boolean types, including integers (Int8 to Int64), unsigned integers (UInt8 to UInt64), floating-point numbers (Float16, Float32, Float64), and Bool. The core functionality involves `readBigEndian` and `writeBigEndian` methods to convert between values and byte arrays. This resource is suitable for Cangjie developers working on low-level binary data manipulation, network protocols, or file I/O requiring specific endianness handling.
