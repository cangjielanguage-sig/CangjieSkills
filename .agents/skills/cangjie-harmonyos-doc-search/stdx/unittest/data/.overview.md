# data

This directory contains documentation and resources for the `stdx.unittest.data` library within the Cangjie programming language ecosystem. It focuses on data handling, serialization, and data-driven testing mechanisms. The content covers how to utilize external data files—such as JSON, CSV, and TSV—to facilitate parameterized unit tests. It is designed for developers looking to improve test efficiency and coverage by integrating external data sources into their testing workflows. Key topics include serialization formats, data providers, and API references for data manipulation.

This resource is ideal for developers working in the Cangjie ecosystem who wish to implement data-driven testing using external data files.
