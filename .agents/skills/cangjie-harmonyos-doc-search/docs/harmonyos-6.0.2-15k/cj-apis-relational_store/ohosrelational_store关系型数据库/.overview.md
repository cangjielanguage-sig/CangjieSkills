This directory contains API reference documentation for the `ohos.relational_store` module in the Cangjie programming language, designed for HarmonyOS and OpenHarmony application development. Key topics include database lifecycle management (creation, deletion), data type definitions, query predicates, and configuration settings. The documentation is suitable for Cangjie developers implementing robust data persistence, handling end-cloud synchronization, and managing relational database operations within the ArkData framework.
