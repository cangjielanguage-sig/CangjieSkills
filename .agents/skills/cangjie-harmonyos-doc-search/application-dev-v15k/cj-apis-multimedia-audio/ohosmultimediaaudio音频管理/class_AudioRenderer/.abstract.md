This directory contains API reference documentation for the `AudioRenderer` class in the Cangjie programming language, part of the AudioKit framework for HarmonyOS. It covers comprehensive audio rendering operations, including stream management, volume control, device handling, and state monitoring. Key topics include buffer management, audio effects, playback speed, and event callbacks. The documentation is designed for software developers and multimedia engineers who need to implement robust audio playback features, requiring familiarity with Cangjie syntax and audio stream processing.
