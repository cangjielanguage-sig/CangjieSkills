This directory contains API reference documentation for the `ohos.battery_info` module in the Cangjie programming language, designed for HarmonyOS development. It covers comprehensive battery management features, including querying battery status, monitoring charge levels, health states, and charging types. The documentation includes enums for various battery states and a core class for retrieving real-time metrics like voltage, temperature, and capacity. It is suitable for developers and system engineers building power-aware applications or integrating advanced power management features into their HarmonyOS projects using the BasicServicesKit.
