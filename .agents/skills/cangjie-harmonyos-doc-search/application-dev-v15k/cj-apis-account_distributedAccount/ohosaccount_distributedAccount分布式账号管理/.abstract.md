This directory provides comprehensive API reference documentation for managing distributed accounts using the Cangjie programming language within the OpenHarmony ecosystem. It covers the essential module interfaces, data structures, and enumerations required to handle distributed account synchronization, state management, and lifecycle events. Key components include the `DistributedAccountAbility` for querying and updating account states, the `DistributedInfo` class for data encapsulation, and specific enums for tracking login statuses and events. This documentation is suitable for system application developers and HarmonyOS developers aiming to implement robust distributed account features and ensure seamless account synchronization across devices.
