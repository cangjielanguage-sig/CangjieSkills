This directory serves as a comprehensive technical guide for managing application resource directories and structures within the development environment. It provides detailed explanations on how to organize resources using base and qualifier directories to support localization and device-specific configurations. Key topics include strict naming conventions, resource compilation processes, and the handling of raw files versus compiled resources. It is specifically designed for developers and system architects who need to ensure their application resources are correctly matched, compiled, and deployed across a wide variety of devices, regions, and screen densities. By following these guidelines, users can optimize resource management and ensure compatibility. The documentation also references international standards such as ISO 639 and ITU-T E.212 to ensure global compliance. Included files cover directory structures, naming rules, and specific qualifier definitions.
