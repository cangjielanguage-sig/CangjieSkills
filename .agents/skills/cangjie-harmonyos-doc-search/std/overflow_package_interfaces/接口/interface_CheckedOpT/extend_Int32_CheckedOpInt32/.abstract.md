This directory contains comprehensive API documentation for the Cangjie programming language, specifically focusing on the `CheckedOp` interface implementation for the `Int32` type. It covers a wide range of safe arithmetic and bitwise operations designed to prevent runtime exceptions by handling potential overflows explicitly. The core functionality includes operations like addition, subtraction, multiplication, division, negation, and bit shifting, all utilizing an `Option` return strategy to manage errors gracefully. By returning `Option<Int32>.None` instead of wrapping values or throwing errors, these functions ensure predictable behavior in critical calculations. This resource is suitable for Cangjie developers who require robust error handling and application stability when performing integer arithmetic, particularly in scenarios where data integrity is paramount.
