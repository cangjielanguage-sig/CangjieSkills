# cj-connectivity-kit-intro

本目录包含Connectivity Kit的入门介绍文档，旨在为开发者提供利用蓝牙和WLAN等基础通信能力构建应用服务的指导。文档详细涵盖了蓝牙技术（包括BLE和A2DP模块）以及WLAN技术（包括STA、P2P和AP模式）的核心概念与功能特点。由于该服务目前处于Beta阶段，文档特别强调了应用需要主动管理连接状态，并且在使用设备能力时必须获得用户的明确授权。这份指南非常适合希望快速上手连接功能开发的初学者，同时也提供了通往API参考和详细开发指南的链接，是开发相关应用的重要起点。

## Detailed Description

### cj-connectivity-kit-intro.md

这份文档是Connectivity Kit的简介，旨在帮助开发者利用蓝牙和WLAN等基础通信能力设计贴近生活的应用服务。主要内容包括蓝牙（BLE、A2DP模块）和WLAN（STA、P2P、AP模式）的技术简介及功能特点。文档指出该服务处于Beta阶段，应用需主动管理连接状态，且使用设备能力必须获得用户授权。这是一份面向开发者的入门指南，提供了相关API参考和开发指南的链接。
