# camera

This directory contains comprehensive documentation for the Camera Kit (CameraKit) API, specifically tailored for the Cangjie programming language environment. It covers the complete lifecycle of camera application development, ranging from initial setup and permission management to advanced features like device input, session management, and torch control. The resources are designed for mobile application developers looking to integrate robust camera functionalities, including preview, photo capture, and video recording. Key topics include hardware interaction via HDI, BufferQueue data mechanisms, and the distinction between mandatory and basic capabilities within the Beta framework.

## Detailed Description

### README_zh
This directory contains the overall overview document for the Camera Kit (Camera Service) Beta version, designed to provide a systematic development guide for mobile app developers needing to integrate camera functions. As a core index, the document details the documentation structure, core functional modules, and development process. Content covers the complete path from development preparation and environment setup to specific feature implementation, highlighting mandatory capabilities (including camera management, device input, session management) and basic capabilities (such as flashlight usage). The document distinguishes between different capability levels to help developers choose based on application needs. Since all listed features are currently in the Beta testing stage, this document is essential for developers to understand the latest API features and obtain technical references.

### cj-camera-device-input
This directory serves as a comprehensive technical resource for developers focusing on camera device input and control, specifically leveraging the CameraKit API. It provides an in-depth look at building multimedia camera applications, covering the entire scope of input handling and device interaction.

### cj-camera-device-management
This directory provides a foundational guide for camera application development, specifically designed for the Cangjie programming language environment utilizing the CameraKit framework. It addresses the critical challenges of hardware interaction, focusing on the management and control of camera devices.

### cj-camera-overview
This directory contains the overview document for the Camera Kit, aiming to introduce its basic concepts, functions, and development model. The document elaborates on camera application development scenarios, workflows, and the relationships between input device management, session management, and output management. Core content includes implementing preview, photo capture, video recording, and controlling parameters like flash and exposure through interfaces. It also deeply analyzes the underlying mechanism of data transmission via HDI and BufferQueue. Suitable for developers needing to develop camera applications or related modules, this serves as a general guide. Keywords: Camera Kit, Camera Development, Session Management, HDI, BufferQueue.

This directory aims to provide a preparation guide for developers using the Cangjie language for camera application development.
