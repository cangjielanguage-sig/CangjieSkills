# cj-crypto-aes-sym-encrypt-decrypt-ccm

This directory serves as a comprehensive technical resource for developers working within the Cangjie programming ecosystem, specifically focusing on the implementation of AES symmetric encryption and decryption using the CCM (Counter with CBC-MAC) mode. It provides a structured approach to utilizing the `CryptoArchitectureKit`, enabling developers to achieve robust authenticated encryption which ensures both data confidentiality and integrity. The directory covers the full spectrum of the cryptographic workflow, starting from the initial generation of symmetric keys and the instantiation of cipher objects, through to the detailed configuration of parameters and the final processing of data. It also highlights critical operational constraints, such as the inability to perform segmented updates in CCM mode and the specific requirement for a 12-byte authentication tag. This repository is ideally suited for Cangjie developers who have a foundational understanding of cryptographic concepts and are looking for practical, in-depth guidance on implementing secure data handling mechanisms in their applications.

## Detailed Description

### 使用AES对称密钥CCM模式加解密仓颉/
This subdirectory offers an extensive collection of technical tutorials aimed at mastering the implementation of AES symmetric encryption and decryption using CCM mode in the Cangjie programming environment. The tutorials are designed to guide developers through the complete lifecycle of cryptographic operations. They begin by establishing the necessary groundwork, covering the generation of AES128 keys and the creation of cipher instances. The content then moves into the specifics of initialization, providing detailed instructions on how to properly configure the cipher using `CcmParamsSpec`. Following initialization, the tutorials explain the data processing phase, clarifying the usage of `update` and `doFinal` methods to handle the encryption and decryption streams. Furthermore, the directory delves into the extraction and verification of authentication tags, a crucial step for ensuring the authenticity of the transmitted data. Key technical points are emphasized throughout, including the specific restriction that CCM mode does not support segmented operations—necessitating careful data management—and the strict requirement for a 12-byte authentication tag for successful verification. These resources are meticulously tailored for Cangjie developers utilizing the `CryptoArchitectureKit`, assuming the audience possesses a degree of familiarity with cryptographic concepts and API references to effectively leverage the provided code examples and structural skeletons.
