# 气泡提示Popup

This directory provides comprehensive resources for implementing and configuring Popup components using the ArkUI Cangjie framework in HarmonyOS development. It covers a wide range of functionalities, from basic text-only tips and interactive alerts to advanced custom styling and animation effects. Developers will learn how to manage state changes, distinguish between system and custom options, and control modal behaviors. The content is specifically tailored for developers proficient in the Cangjie language who aim to enhance UI interaction with dynamic bubble tips, screen recording notifications, and information alerts.

## Detailed Description

### 气泡提示Popup_4more.md 气泡提示Popup_4more.md
This tutorial guide explains how to implement and configure Popup attributes in the ArkUI Cangjie framework for displaying bubble tips and alerts on components. Main sections cover text-only popups, handling state change events via onStateChange, and creating interactive popups with primary and secondary buttons. Key information includes the distinction between system PopupOptions and custom CustomPopupOptions, modal versus non-modal behavior using the mask property, and code examples demonstrating binding popups to components and managing visibility through state variables. The content targets developers using the Cangjie language to build HarmonyOS applications, specifically those needing UI interaction components like screen recording tips or information alerts.

### 气泡的动画.md 气泡的动画.md
This document serves as a code tutorial demonstrating how to configure entry and exit animations for popups in Cangjie development. It focuses on utilizing the transition property within PopupOptions and CustomPopupOptions to control visual effects. The main sections illustrate two distinct examples: one using PopupOptions with an asymmetric transition combining opacity and translation, and another using CustomPopupOptions with a symmetric scaling animation. Key information includes the implementation of TransitionEffect.asymmetric for different show and hide behaviors, combining multiple animation types, and setting animation parameters like duration and curve. The document targets HarmonyOS developers familiar with the Cangjie language, UI components, and state management, providing a practical reference for enhancing user interface interactions.

### 自定义气泡_2more.md 自定义气泡_2more.md
This document serves as a technical guide for developers on implementing and styling custom popups using the Cangjie UI framework. It covers two primary topics: creating custom popup content via CustomPopupOptions and @Builder decorators, and configuring popup styles using PopupOptions. Key information includes how to control placement, background color, mask effects, and blur styles. The document provides executable code examples demonstrating how to bind popups to buttons and handle state changes. Intended for application developers, this tutorial requires prior knowledge of Cangjie syntax and UI component lifecycle management.
