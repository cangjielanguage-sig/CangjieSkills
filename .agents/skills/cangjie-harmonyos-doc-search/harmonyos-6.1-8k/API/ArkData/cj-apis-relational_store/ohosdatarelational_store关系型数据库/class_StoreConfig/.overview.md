# class_StoreConfig

本目录包含Cangjie语言中StoreConfig类的API参考文档，主要用于定义和管理关系数据库及向量数据库的配置参数。内容涵盖数据库初始化的核心属性，包括名称、安全级别、加密设置、自定义路径、插件库及语义索引等。文档详细介绍了路径大小限制、端云协同场景下的脏数据自动清理策略以及数据库异常时的自动重建机制。这些资料适合需要配置RdbStore实例、实现数据存储与同步功能的应用开发人员，以及从事分布式数据管理的开发者阅读。
