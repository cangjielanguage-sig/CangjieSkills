# 常用命令

This directory provides comprehensive documentation for the `hidumper` tool, a command-line utility essential for debugging and inspecting OpenHarmony and HarmonyOS system states. It covers a broad spectrum of functionalities, including retrieving system information, monitoring performance metrics like CPU and memory, and analyzing specific system services such as WindowManager and PowerManager. Additionally, it details advanced features like Inter-Process Communication (IPC) statistics and heap profiling for JavaScript and Cangjie. These guides are tailored for developers and system administrators aiming to diagnose issues, optimize resource usage, and maintain system stability.

The document targets developers and system administrators who need to diagnose system states, monitor resources, or analyze service behaviors using command-line interfaces.

### 常用命令_2.md 常用命令_2.md
This document serves as a technical reference guide for using the hidumper command-line tool to diagnose and monitor OpenHarmony system services. It details specific commands for WindowManagerService to dump window information, RenderService to analyze FPS, memory, and surface data, and PowerManagerService to control screen timeout settings. Additionally, it covers retrieving crash history via the Faultlog module. The guide provides syntax options, parameter descriptions, and example outputs for effective system debugging. It targets developers and system administrators seeking to analyze system performance, manage display states, and troubleshoot application crashes.

### 常用命令_3.md 常用命令_3.md
This document serves as a technical reference guide for the `hidumper` tool, detailing commands 10 through 15 for retrieving system performance metrics. It covers network traffic, storage I/O, process lists, CPU usage, CPU frequency, and memory information. Each section provides command syntax, usage examples, and sample output. ### 常用命令_4.md 常用命令_4.md
This reference document provides usage instructions for the hidumper command-line tool, focusing on system diagnostics. It covers three primary areas: memory analysis, output compression, and Inter-Process Communication (IPC) statistics. Key information includes commands to retrieve detailed memory metrics like Pss, Vss, and Rss for specific PIDs, monitor memory changes over time, and generate simplified reports. Additionally, it explains saving logs to zip files and tracking IPC data flow using start, stat, and stop flags. Intended for system developers or engineers debugging performance issues, this guide assumes familiarity with Linux process management concepts.

### 常用命令_5.md 常用命令_5.md
This reference guide documents specific `hidumper` commands for monitoring IPC statistics and exporting detailed memory usage information. The content is divided into two main sections: IPC load statistics and memory smaps analysis. The IPC section explains how to start, view, and stop statistics for specific process IDs or all processes, detailing output formats for global, process, and interface data. The memory section describes the `--mem-smaps` command, noting it is restricted to debug versions and supports a verbose flag for detailed process memory statistics. This document serves as a technical reference for developers and system engineers debugging system performance and resource utilization.

### 常用命令_6.md 常用命令_6.md
This document serves as a command reference guide for the hidumper system diagnostic tool, primarily focusing on memory analysis capabilities. It lists general usage options for system information, processes, and network statistics, while providing detailed instructions for JavaScript heap (--mem-jsheap) and Cangjie heap (--mem-cjheap) profiling. Key information includes syntax for triggering garbage collection, exporting heap snapshots, and detecting memory leaks, along with output file locations and version compatibility restrictions. This guide is intended for developers and system administrators debugging memory performance and reliability issues on HarmonyOS.
