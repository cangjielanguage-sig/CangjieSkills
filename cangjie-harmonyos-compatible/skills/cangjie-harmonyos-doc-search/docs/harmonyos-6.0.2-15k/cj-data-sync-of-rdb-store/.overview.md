# cj-data-sync-of-rdb-store

This directory serves as a comprehensive technical resource dedicated to the implementation of cross-device data synchronization for relational databases within the HarmonyOS ecosystem. It addresses the critical architectural challenges involved in maintaining strict data consistency across multiple devices, offering detailed insights into distributed table configurations, synchronization modes (specifically push and pull mechanisms), and the handling of change notifications. The documentation further outlines essential database constraints and limits that developers must consider to ensure stability. By introducing vital APIs such as `setDistributedTables` and `sync`, it provides the necessary tools for effective implementation. This guide is specifically tailored for application developers utilizing the Cangjie language who aim to build robust, distributed data capabilities into their applications, thereby ensuring a seamless, unified, and consistent user experience across a diverse range of hardware devices and network conditions.

### 关系型数据库跨设备数据同步/
