# cj-universal-attribute-zorder

This directory provides comprehensive API reference documentation for the `zIndex` attribute within the Cangjie ArkUI framework. It is specifically designed to assist developers in understanding and implementing the stacking order of UI components to manage visual hierarchy and overlap effectively. The documentation covers the core mechanics of layering, where components with higher values obscure those with lower ones, and includes practical examples for both static layering and dynamic updates using state variables. This resource is particularly suitable for HarmonyOS developers working with the Cangjie language who require precise control over component visibility and layout behavior. By utilizing this guide, developers can ensure that their UI elements render in the correct order, thereby improving user experience and interface stability in complex applications.

### cj-universal-attribute-zorder.md cj-universal-attribute-zorder.md
This document serves as API reference documentation for the zIndex attribute in the Cangjie ArkUI framework, detailing how to manage the stacking order of UI components. It includes the function definition for zIndex(Int32), a parameter table explaining the layer hierarchy logic, and two executable code examples. The core concept is that components with higher zIndex values cover those with lower ones, starting from a default of 0. The examples illustrate both static layering and dynamic updates using state variables, highlighting stable sorting behavior. This guide is intended for HarmonyOS developers using Cangjie who need to handle component overlap and visibility within layout containers.
