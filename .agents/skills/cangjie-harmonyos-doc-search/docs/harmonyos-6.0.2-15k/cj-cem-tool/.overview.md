# cj-cem-tool

The `cj-cem-tool` directory provides the technical reference guide for the Common Event Manager (cem) tool, a command-line utility designed for developers to debug and test public events. It enables users to print system information and simulate event publications. The documentation covers environment prerequisites, specifically the hdc shell, and details three primary commands: help, publish, and dump. Key takeaways include parameters for publishing events—such as event names, codes, and data—and restrictions on the dump command, which is exclusive to engineering (eng) versions. This guide is suitable for developers needing command-line utilities to inspect event subscribers and simulate event dispatching within their development environment. It provides the necessary instructions to validate event logic and ensure proper communication between system components during the development lifecycle. By utilizing this tool, developers can effectively troubleshoot event handling issues and verify that events are being dispatched correctly to all relevant subscribers.
