This directory contains comprehensive API reference documentation for the Cangjie `ConfigureMock` class, a fundamental utility designed to facilitate the configuration of mock objects within modern testing frameworks. It provides detailed technical specifications for static methods and functions essential for intercepting and stubbing various types of class members, including property getters, setters, and standard member functions. The documentation covers critical implementation details such as argument matchers, stub call expressions, reference tokens, and the specific selector objects returned for configuration. This resource is specifically tailored for Cangjie developers and QA engineers who require precise control over object behavior during unit testing, enabling the simulation of complex scenarios and the isolation of dependencies to ensure code reliability and correctness. By mastering these tools, developers can effectively control execution flows and verify interactions within their test suites, ultimately leading to more robust and maintainable software.
