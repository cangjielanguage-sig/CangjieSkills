# unittest_diff_package_interfaces

This directory serves as a critical infrastructure component for the Cangjie programming language, specifically designed to support robust unit testing through standardized interface definitions. It acts as the backbone for assertion handling, ensuring that when tests fail, the output is formatted correctly for easy debugging. The directory focuses heavily on the `AssertPrintable` interface, which dictates how various data types—ranging from floating-point numbers (Float16, Float32, Float64) to complex types like Option and String—are converted into readable strings during evaluation. This is vital for the functionality of core testing macros such as `@Assert` and `@Expect`. The package is highly suitable for Cangjie developers who are building custom testing tools or need to extend the default assertion capabilities. By utilizing these interfaces, developers can ensure that their test reports provide granular, actionable insights, significantly improving the efficiency of the debugging process and the overall reliability of the software.
