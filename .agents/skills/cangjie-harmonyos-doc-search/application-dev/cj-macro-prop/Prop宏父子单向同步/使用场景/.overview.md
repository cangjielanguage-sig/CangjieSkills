# 使用场景

This directory contains usage scenarios and tutorials for state management in ArkUI using the Cangjie language. It focuses on data synchronization mechanisms between parent and child components, specifically utilizing decorators like @State, @Prop, @Observed, and @Publish. The content covers simple data types, nested objects, and array collections, illustrating how state changes propagate or remain local. It is suitable for ArkUI developers looking to master component interaction, state synchronization logic, and complex data structure handling within their applications.

## Detailed Description

### Prop嵌套场景.md Prop嵌套场景.md
This document provides a code example demonstrating how to handle nested object state management using @Prop and @Observed decorators in ArkUI. The content covers nested class definitions, the usage of @Observed and @Publish, and state synchronization between parent and child components. Key takeaways include the requirement that every layer of a nested class hierarchy must be decorated with @Observed, and nested objects must be received via @Prop to ensure state changes are detected and propagated. The example illustrates modifying properties of both a parent object and a nested child object. This guide is intended for ArkUI developers using the Cangjie language who need to manage complex, nested state structures in their applications.

This tutorial demonstrates state synchronization in ArkUI using Cangjie, specifically passing @Observed class objects from parent @State to child @Prop variables. It covers two scenarios: synchronizing a single class object and synchronizing items within an ObservedArrayList. Key takeaways include the mechanism where @Observed wraps instances in proxies to detect changes, ensuring modifications in child components update the parent state. This guide targets ArkUI developers seeking to implement complex state management with reference types and collections.

### 父组件State到子组件Prop简单数据类型同步.md 父组件State到子组件Prop简单数据类型同步.md
This tutorial demonstrates one-way data synchronization from a parent component's @State variable to a child component's @Prop variable using the ArkUI framework in Cangjie. The document covers the implementation of a countdown example, illustrating initialization, rendering triggers, and state modification behaviors. Key takeaways include that parent state changes automatically update the child and overwrite local child modifications, while changes to the child's @Prop variable remain local and do not sync back to the parent. This guide is intended for developers learning state management and component interaction in ArkUI applications.
