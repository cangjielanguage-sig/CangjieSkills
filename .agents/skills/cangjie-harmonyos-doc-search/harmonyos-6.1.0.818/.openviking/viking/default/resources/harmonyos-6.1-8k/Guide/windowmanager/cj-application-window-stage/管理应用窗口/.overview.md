# 管理应用窗口

本目录主要介绍HarmonyOS应用中窗口管理的相关技术与实现方法，涵盖Stage模型下的主窗口设置、沉浸式体验、悬浮窗及子窗口的管理。内容重点包括窗口属性的配置、系统栏的控制、权限申请以及窗口生命周期的管理，并提供了基于Cangjie语言的代码示例。本文档适合HarmonyOS应用开发者，特别是需要自定义窗口行为、实现全屏布局或多窗口交互场景的开发人员阅读。

## 详细描述

### 体验窗口沉浸式能力.md 体验窗口沉浸式能力
本文档旨在指导开发者利用窗口沉浸式能力隐藏系统栏，以优化视频、游戏等场景的全屏体验。文档介绍了API 10的默认配置及开发步骤，包括获取主窗口、通过setWindowLayoutFullScreen或setWindowSystemBarEnabled实现沉浸效果、以及加载内容。关键点在于区分窗口级与页面级配置，并提供了Cangjie代码示例。这是一份面向HarmonyOS开发者的技术指南，适用于需要实现全屏布局的应用开发。

### 管理应用窗口_4more_78e2c7f6.md 管理应用窗口_4more_78e2c7f6
本文档介绍Stage模型下应用窗口的管理方法，涵盖属性设置、沉浸式体验及悬浮窗功能。内容包括基本概念、典型场景及WindowStage和Window类的API说明。核心要点指出沉浸式能力仅适用于全屏主窗口，悬浮窗需申请权限。关键API涉及窗口创建、内容加载、全屏布局、系统栏控制及销毁。面向使用Stage模型的开发者，适用于自定义窗口行为和界面开发的场景。

### 设置应用主窗口_c9facda4.md 设置应用主窗口_c9facda4
本文档是一份开发指南，旨在指导开发者在Stage模型下使用Cangjie语言设置应用主窗口。文档主要涵盖通过UIAbility的onWindowStageCreate回调获取WindowStage，进而操作主窗口的流程。核心内容包括获取主窗口、设置窗口属性（如是否可触）以及加载目标页面的三个开发步骤，并提供了详细的Cangjie代码示例。关键信息涉及getMainWindow、setWindowTouchable和loadContent接口的使用，以及module.json5配置文件的补充说明。本文面向具备Stage模型基础的HarmonyOS应用开发者。

### 设置悬浮窗_0f6a3989.md 设置悬浮窗_0f6a3989
本文档旨在指导开发者如何在应用中创建、配置及管理悬浮窗，实现始终在前台显示的窗口功能。主要涵盖悬浮窗的定义、开发前提条件（权限申请）、四个核心开发步骤（创建、属性设置、显示、销毁）以及Cangjie语言代码示例。关键信息包括必须申请ohos.permission.SYSTEM_FLOAT_WINDOW权限，使用createWindow接口创建WindowType.TypeFloat类型窗口，并通过moveWindowTo、resize、showWindow及destroyWindow等接口进行全生命周期管理。面向HarmonyOS应用开发者，特别是需要实现悬浮窗功能的Cangjie语言使用者。

### 设置应用子窗口/
本目录主要介绍在HarmonyOS应用中如何创建和管理子窗口。内容涵盖了子窗口的开发步骤、属性设置、显示与销毁，以及在不同场景下的使用限制和最佳实践建议。重点讲解了使用仓颉语言进行开发的流程，并对比了子窗口与控件overlay能力的优劣。适合熟悉ArkUI和AbilityKit框架的HarmonyOS应用开发者阅读，旨在帮助开发者掌握子窗口的实现方案及正确选择窗口模式。
