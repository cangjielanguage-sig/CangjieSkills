This directory provides API reference documentation for the `ohos.file_fs.interop` module, a critical component designed to facilitate interoperability between Cangjie file objects and ArkTS JavaScript values within the HarmonyOS ecosystem. It comprehensively covers core classes such as `File`, `Stream`, and `RandomAccessFile`, detailing their definitions and methods to enable seamless bidirectional type conversion. Key topics include the `JSSystemObjectInteropType` interface and ownership transfer mechanisms during object conversion, ensuring safe and efficient data handling. This documentation is suitable for HarmonyOS developers working on file management and cross-language integration who need to bridge Cangjie and ArkTS environments effectively.
