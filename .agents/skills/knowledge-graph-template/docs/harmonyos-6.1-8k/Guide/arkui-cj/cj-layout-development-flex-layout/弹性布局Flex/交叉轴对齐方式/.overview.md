# 交叉轴对齐方式

本目录主要介绍ArkUI框架中Flex布局的交叉轴对齐机制。内容涵盖了容器级别的`alignItems`属性、子元素级别的`alignSelf`属性，以及多行布局中的`alignContent`属性。通过基于仓颉语言的代码示例，详细讲解了Start、Center、End、Stretch等多种对齐模式及其应用场景。本文档适合ArkUI应用开发者阅读，旨在帮助开发者掌握Flex布局细节，实现精细化的UI排版控制。
