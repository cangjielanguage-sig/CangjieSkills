# DatePicker

This directory contains comprehensive documentation for the DatePicker component within the ArkUI framework using the Cangjie language. It covers the component's API reference, including initialization parameters, event handling, and style configuration. Key topics include setting date ranges, switching between Gregorian and Lunar calendars, and customizing text styles for different states. The documentation also provides practical code examples demonstrating state management and user interaction. This resource is suitable for HarmonyOS developers and software engineers looking to implement and customize sliding date selectors in their applications.

## Detailed Description

### DatePicker_5more.md DatePicker_5more.md
This document provides API reference documentation for the DatePicker component in the ArkUI framework using the Cangjie language. It details the module import process and the component's constructor, `init`, which accepts optional `start`, `end`, and `selected` DateTime parameters to configure the date range and default selection. Key information includes default values ranging from 1970 to 2100 and support for all universal attributes and events. Intended for developers, this guide facilitates the implementation of sliding date selectors in user interfaces.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the implementation of a DatePicker component with Gregorian and Lunar calendar switching capabilities within an ArkUI application. The code covers state management using @State, UI layout with Column and Button, and configuration of the DatePicker including text styles and event handling. Key takeaways include using the lunar property to toggle calendar types and the onDateChange callback to capture user input, logging the result via Hilog. This example targets developers familiar with Cangjie and ArkUI who need practical guidance on implementing date selection features.

### 组件事件_2more.md 组件事件_2more.md
This document serves as an API reference for handling date selection events and results within the ArkUI framework using the Cangjie language. It primarily details the onDateChange function, which triggers a callback when a date is selected, and the DatePickerResult class, which encapsulates the selection data. Key information includes that the callback returns a DateTime object where seconds default to 00 and time relies on the system, while the result class uses a 0-11 range for months. This documentation is intended for developers implementing date picker components in HarmonyOS applications, providing necessary type definitions and event handling logic.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring text styles and calendar display modes for a Picker component in the Cangjie programming language. It details four specific functions: disappearTextStyle, lunar, selectedTextStyle, and textStyle, each providing syntax, descriptions, and parameter tables. Key information includes the ability to customize font attributes like color, size, and weight for different item states (selected, general, and transition) using the PickerTextStyle type, as well as toggling lunar calendar display. All functions accept optional parameters and return the component instance for chaining. This technical reference is intended for HarmonyOS developers using ArkUI who need to customize the visual appearance and behavior of selection pickers.
