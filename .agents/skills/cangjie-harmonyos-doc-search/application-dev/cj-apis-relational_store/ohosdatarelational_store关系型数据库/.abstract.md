This directory provides API reference documentation for the HarmonyOS Relational Store module in the Cangjie programming language. It covers the management of local SQLite-based databases, distributed data synchronization, and secure storage operations. Key topics include database creation and configuration, encryption, query predicates, result sets, and asset management for files and images. The documentation is suitable for HarmonyOS developers using the ArkData kit to implement persistent local data storage, handle multi-device synchronization, and ensure data security in their applications.
