This directory provides a foundational overview of Audio Kit, a robust service engineered to deliver scenario-based audio playback and recording interfaces with a focus on high-definition capture and immersive playback experiences. The content encompasses the complete system architecture, detailing the interaction between the Application layer, FFI, Native Framework, SystemAbility, HAL, and the Kernel. Key topics include low latency playback, sound effect modes, and audio-vibration synchronization. Additionally, it introduces the concept of audio streams, defining them as independent data processing units, and outlines supported PCM formats and configuration attributes. This documentation is tailored for application developers who require a solid grasp of acoustics—such as sampling and quantization—to effectively configure audio streams and manage hardware capabilities, strictly focusing on audio logic separate from UI or graphics.
