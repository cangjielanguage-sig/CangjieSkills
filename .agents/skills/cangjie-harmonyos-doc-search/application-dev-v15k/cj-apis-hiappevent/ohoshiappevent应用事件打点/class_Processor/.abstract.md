This directory contains comprehensive documentation for the Cangjie Processor class, a fundamental data handler object within the HiAppEvent system capability introduced in API version 12. It provides essential resources for developers working with event reporting, covering the complete lifecycle of the Processor from initialization to configuration. Key topics include defining read-only properties such as name, appId, and routeInfo, as well as setting up complex reporting triggers like onStartReport, onBackgroundReport, periodReport, and batchReport. The documentation also delves into data filtering strategies using userIds, userProperties, and eventConfigs, alongside specific validation rules for string lengths and numeric ranges. It includes references for the class definition as well as the specific constructor method required to instantiate these objects. This content is specifically tailored for Cangjie developers who need to implement, configure, and manage robust application event monitoring and data transmission mechanisms in their software projects.
