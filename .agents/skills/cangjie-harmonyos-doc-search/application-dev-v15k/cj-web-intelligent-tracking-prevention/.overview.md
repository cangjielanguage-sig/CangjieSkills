# cj-web-intelligent-tracking-prevention

This directory serves as a comprehensive technical resource for developers working within the ArkWeb framework on the HarmonyOS ecosystem, specifically focusing on advanced privacy and security features. It details the implementation of Intelligent Tracking Prevention (ITP), a critical mechanism designed to block third-party tracking cookies and protect user data. The content covers the complete lifecycle of managing ITP, including enabling or disabling the feature, querying its current operational status, and handling domain bypass lists. Written specifically for the Cangjie programming environment, it highlights essential APIs such as `enableIntelligentTrackingPrevention` and the `WebviewController` class. This guide is ideal for application developers who need to integrate robust privacy controls into their web views while ensuring that specific, trusted domains remain accessible and functional through global configuration settings.

## Detailed Description

### 使用智能防跟踪功能/

This directory provides a comprehensive guide on implementing and managing Intelligent Tracking Prevention (ITP) within the ArkWeb framework for HarmonyOS applications. It covers essential operations such as enabling or disabling the feature, checking its status, and configuring domain bypass lists using the Cangjie language. Key topics include the usage of APIs like `enableIntelligentTrackingPrevention` and methods to modify bypass lists, with a specific focus on how bypass lists apply globally to the application. This documentation is suitable for application developers looking to enhance user privacy by blocking third-party tracking cookies while maintaining control over specific domain exceptions through `WebviewController`.
