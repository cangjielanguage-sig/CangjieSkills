This directory provides comprehensive API reference documentation for the Int32 type within the Cangjie programming language. It details the fundamental definition of the 32-bit signed integer, its specific numerical range, and a wide array of extended functionalities designed to enhance type utility. The documentation covers essential mathematical constants such as Max and Min, alongside implementations for core interfaces including Comparable, Countable, and Hashable. Furthermore, it explains utility functions for ordering, overflow handling, and type conversion to String. This resource is designed for Cangjie developers who need to perform integer arithmetic, implement comparison logic, or format numerical data for output and string manipulation, ensuring robust type handling in their applications.
