This directory serves as a comprehensive resource for the `std.overflow` package, a library specifically engineered to address integer arithmetic overflow through multiple defined strategies. It details four core handling mechanisms: Checked, Saturating, Throwing, and Wrapping. The documentation outlines API interfaces that support standard operations and power calculations, giving developers the flexibility to return Options, clamp values, throw exceptions, or truncate bits when overflow is detected. Additionally, it defines exception classes for invalid shift operations. This guide is essential for developers who need granular control over integer behavior to prevent bugs and ensure application stability.
