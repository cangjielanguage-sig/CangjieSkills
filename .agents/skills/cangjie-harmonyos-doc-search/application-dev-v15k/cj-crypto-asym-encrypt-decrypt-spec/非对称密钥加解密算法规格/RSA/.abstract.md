This directory provides comprehensive technical documentation for implementing RSA encryption within the Cangjie framework. It covers essential topics such as supported padding modes (NoPadding, PKCS1, PKCS1_OAEP), data length constraints, and API specifications for key sizes ranging from RSA512 to RSA8192. Additionally, it details the configuration of OAEP parameters and specific implementation syntax. This resource is designed for developers, security engineers, and cryptographers who require precise guidance on asymmetric cryptography configuration, parameter management, and ensuring system compatibility.
