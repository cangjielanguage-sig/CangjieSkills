# 媒体文件uri

This directory focuses on the structure, acquisition, and utilization of Uniform Resource Identifiers (URIs) for media files within the HarmonyOS ecosystem. It covers technical specifications for image, video, and audio URIs, detailing component breakdowns and API interfaces like `PhotoViewPicker` and `PhotoAccessHelper`. Key topics include URI formats, asset querying, permission handling, and metadata extraction. This documentation is suitable for HarmonyOS developers using ArkTS or Cangjie who need to implement robust media file access, selection, and management in their applications.

### 媒体文件uri介绍_2more.md 媒体文件uri介绍_2more.md
This technical reference document defines the URI structure and acquisition methods for media files. It details the specific URI formats for images, videos, and audio, providing a breakdown of each component, such as file type indicators and database IDs. Key information includes the warning that the `<id>` field is a processed value distinct from the database `file_id` and should not be used for queries. The document also outlines how to obtain these URIs using specific API interfaces like `PhotoViewPicker`, `getAssets`, and `createAsset`. Intended for developers, this guide serves as a resource for correctly interpreting and utilizing media file identifiers within the `PhotoAccessHelper` module.
