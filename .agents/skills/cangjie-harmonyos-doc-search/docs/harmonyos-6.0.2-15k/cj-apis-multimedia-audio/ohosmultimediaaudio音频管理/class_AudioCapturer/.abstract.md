This directory contains API reference documentation for the `AudioCapturer` class in the Cangjie programming language, part of the AudioKit framework. It covers comprehensive interfaces for audio capture functionality, including lifecycle management, stream configuration, device monitoring, and event handling. Developers can find details on synchronous methods for retrieving stream information, buffer sizes, and timestamps, as well as asynchronous mechanisms for registering callbacks on state changes, data reading, and audio interruptions. This documentation is suitable for software developers building multimedia audio applications who need to manage recording streams, handle audio focus, and monitor device states in system version 19.
