# 基础类型定义

This directory contains API reference documentation for fundamental type definitions used within the ArkUI framework and Cangjie language. It primarily focuses on components and configurations related to the Swiper control, including navigation indicators (arrows, digits, dots), animation controllers, transition proxies, and display modes. These definitions allow developers to customize the appearance, behavior, and layout of carousel and slider interfaces. Suitable for ArkUI developers and UI engineers using Cangjie, this documentation provides the necessary structural details to implement dynamic, responsive, and visually polished user interface components.

## Detailed Description

### class_ArrowStyle.md class_ArrowStyle.md
This API reference details the ArrowStyle class used to configure the appearance and behavior of left and right arrows in ArkUI components. It covers the class definition, public properties for styling (color, size, background), and constructor initialization parameters. Key properties include showBackground, isSidebarMiddle, and dimension settings. The constructor provides defaults, such as a transparent background and specific sizing logic. This guide targets Cangjie developers building UIs who need to customize navigation arrow controls.

### class_DigitIndicator.md class_DigitIndicator.md
This document details the DigitIndicator class, which configures numeric navigation styles for Swiper components within the ArkUI framework. It outlines the class constructor and methods for customizing typography, specifically digitFont, fontColor, selectedDigitFont, and selectedFontColor. Key information includes default values for font size, weight, and hex colors for both selected and unselected states, alongside a maximum font scale limit of 2. Intended for developers using the Cangjie language.

### class_FontOptions.md class_FontOptions.md
This reference details the FontOptions class used to configure font styles for digital navigation dots within the Swiper component in the Cangjie language. It covers the class definition, two public properties (size and weight), and the class constructor. Key information includes that the size property sets the font length with a default of 14.vp but does not support percentage values, while weight controls thickness with a default of Normal. Targets ArkUI developers using Cangjie.

### class_SwiperAnimationEvent_2more.md class_SwiperAnimationEvent_2more.md
This document serves as an API reference for Cangjie developers working with the ArkUI Swiper component, specifically detailing two auxiliary classes. It covers the SwiperAnimationEvent class, which encapsulates animation state data including current offset, target offset, and fling velocity, and the SwiperAutoFill class, which defines adaptive layout properties like minimum element width. Key information includes the specific data types for properties and constructor overloads for initialization.

### class_SwiperContentAnimatedTransition.md class_SwiperContentAnimatedTransition.md
This reference defines the Cangjie class SwiperContentAnimatedTransition, which configures custom switching animations for the Swiper component within the ArkUI framework. It details the class constructor and two public properties: timeout and transition. Key information includes that the timeout property sets a maximum duration in milliseconds for the custom animation; if the finishTransition method is not called before this limit, the system automatically ends the animation. The transition property accepts a lambda function containing the specific animation logic.

### class_SwiperContentTran_d2b80c79.md class_SwiperContentTran_d2b80c79.md
This reference details the SwiperContentTransitionProxy class used for managing custom transition animations within the Swiper component in the Cangjie language. It covers read-only properties such as selectedIndex, index, position, and mainAxisLength, alongside the finishTransition method. Key information includes how the proxy object provides real-time page metrics during transitions and allows developers to signal animation completion. Intended for ArkUI developers implementing custom Swiper animations.

### class_SwiperController.md class_SwiperController.md
This document provides API reference documentation for the SwiperController class in the Cangjie language, which enables programmatic control of Swiper container components. It covers the class initialization and key methods for navigation, including changeIndex to jump to specific pages with or without animation, finishAnimation to stop playback with optional callbacks, and showNext or showPrevious for sequential page turning. Key information includes system capabilities and version requirements starting from API 12.

### enum_SwiperDisplayMode.md enum_SwiperDisplayMode.md
This document provides API reference documentation for the Cangjie SwiperDisplayMode enum, which controls the sizing behavior of the Swiper component along its main axis. The content details the enum's system capabilities and defines its two specific modes: STRETCH and AUTO_LINEAR. Key takeaways include that STRETCH matches the page width to the Swiper's width, whereas AUTO_LINEAR uses the leftmost child's width. Importantly, AUTO_LINEAR is marked as deprecated starting from version 19.

### class_DotIndicator/
This directory contains comprehensive API reference documentation for the `DotIndicator` class within the Cangjie language and ArkUI framework. The documentation covers a wide range of functionalities, including basic class construction, dimension settings, color customization, and handling overflow scenarios. It provides essential details on default values, scaling effects, and constraints such as the lack of percentage support.

### class_Indicator/
This directory provides comprehensive API reference documentation for the Cangjie Indicator class within the ArkUI framework. It is designed to assist developers in configuring the positioning, style, and layout behavior of navigation dots used within Swiper components. The documentation covers essential topics such as static factory methods for creating DigitIndicator and DotIndicator objects, instance methods for precise placement (including bottom, end, left, and right), and handling layout behaviors like RTL/LTR support and property priority rules.
