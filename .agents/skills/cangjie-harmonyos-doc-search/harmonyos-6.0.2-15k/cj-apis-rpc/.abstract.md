This directory serves as a comprehensive resource for the `cj-apis-rpc` module, specifically focusing on the Cangjie language implementation of Remote Procedure Call (RPC) and Inter-Process Communication (IPC) mechanisms. It covers essential components required for building robust communication between processes, including remote object management, data serialization, shared memory usage, and error handling. Key topics include `IRemoteObject`, `MessageSequence`, `Parcelable`, and `Ashmem`. This documentation is designed for Cangjie developers and system engineers working on HarmonyOS applications who need to implement secure and efficient data exchange across different processes or devices.
