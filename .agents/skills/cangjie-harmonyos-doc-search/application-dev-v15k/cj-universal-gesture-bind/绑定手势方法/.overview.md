# 绑定手势方法

This directory provides comprehensive documentation on binding gesture methods to UI components in the ArkUI framework using the Cangjie language. It covers core concepts such as responding to gesture events, implementing priority and parallel gesture handling, and defining foundational types for gesture recognition. Key topics include TapGesture implementation, event masking, and managing interaction conflicts between parent and child components. This resource is suitable for UI developers and software engineers seeking to enhance application interactivity through robust touch control mechanisms.

### 示例.md 示例.md
This document provides a Cangjie code example demonstrating the difference between priority and parallel gesture handling in UI components. It covers the implementation of TapGesture, priorityGesture, and parallelGesture within a Column layout. The key takeaway is that priorityGesture with GestureMask.IgnoreInternal blocks child component gestures, whereas parallelGesture allows both parent and child gestures to trigger simultaneously. This tutorial snippet is intended for HarmonyOS developers using the Cangjie language to manage complex user interactions and event conflicts.

### 绑定手势识别.md 绑定手势识别.md
This API reference document details how to bind gesture recognition to components within the ArkUI framework using the Cangjie language. It covers three primary binding methods: standard gesture, parallelGesture for simultaneous triggering with child components, and priorityGesture for parent-component precedence. Each method includes overloads accepting a GestureMask parameter to control event response. Key information includes the non-bubbling nature of gesture events, how parallelGesture simulates bubbling, and specific exceptions for long-press gestures regarding priority. This guide targets UI developers implementing interactive touch controls, requiring knowledge of component attributes and event handling.
