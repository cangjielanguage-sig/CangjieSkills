# cj-crypto-generate-random-number

本目录提供了在仓颉编程语言中生成符合密码学安全要求的安全随机数的API指南。文档涵盖了随机数的基本概念（如内部状态、随机种子）、CTR_DRBG算法规格以及具体的开发步骤。核心内容包括如何使用OpenSSL接口，通过`createRandom`创建实例、`setSeed`设置种子以及`generateRandom`生成指定长度的数据。该指南适用于需要生成临时会话密钥等安全数据的开发者，读者需具备基础的加解密知识。

## 详细说明

### cj-crypto-generate-random-number.md cj-crypto-generate-random-number.md

本文档是一份面向开发者的API指南，旨在指导如何在Cangjie中生成符合密码学安全要求的安全随机数。文档主要涵盖随机数的基本概念（如内部状态、随机种子）、支持的CTR_DRBG算法规格及开发步骤。核心信息包括使用OpenSSL接口生成随机数，通过createRandom创建实例、setSeed设置种子及generateRandom生成指定长度数据。文档提供了同步代码示例，适用于临时会话密钥生成等场景。目标读者需具备加解密基础知识。
