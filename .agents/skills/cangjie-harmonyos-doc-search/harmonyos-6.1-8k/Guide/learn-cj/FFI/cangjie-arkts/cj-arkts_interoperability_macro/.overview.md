# cj-arkts_interoperability_macro

This directory provides a technical overview and implementation guide for the declarative interoperability macro mechanism connecting the Cangjie and ArkTS programming languages. It is designed to assist developers in understanding and utilizing a system that automates the complex process of cross-language communication. The documentation covers essential topics such as the operational principles of macros, precise type mapping rules, and strategies for effective project integration. By automatically generating ArkTS declaration files and the necessary interoperability layer code, this mechanism ensures a near-native calling experience that drastically simplifies the development workflow. This resource is highly suitable for developers and system architects engaged in mixed programming, offering the tools needed to achieve seamless interoperability and efficient data exchange between Cangjie and ArkTS environments.

### 仓颉-ArkTS_声明式互操作宏/

This subdirectory focuses on the declarative interoperability macro mechanism, a critical component for enabling interaction between Cangjie and ArkTS. It serves as a comprehensive guide that explains the macro system's working principles, ensuring developers understand how to bridge the two languages effectively. The content details the specific rules for type mapping, which is fundamental for maintaining data integrity across language boundaries. Additionally, it provides step-by-step instructions on project integration methods and defines standardized usage scenarios to ensure consistency.

A key feature of this mechanism is its ability to automatically generate ArkTS declaration files and the interoperability layer code. This automation removes the need for manual boilerplate code, providing a near-native calling experience that enhances both developer productivity and application performance. The documentation highlights core keywords such as Cangjie, ArkTS, interoperability macros, type mapping, and cross-language calls. It is an essential reference for developers who need to perform mixed programming, offering the insights required to build robust, interoperable applications that leverage the strengths of both Cangjie and ArkTS.
