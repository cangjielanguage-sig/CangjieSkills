This directory contains comprehensive API reference documentation for the `WebviewController` class in the Cangjie programming language, designed for HarmonyOS application development. It covers a wide range of functionalities including web page navigation, history management, security settings (like ad blocking and safe browsing), JavaScript interaction, and resource handling. Targeted at developers using the ArkWeb and UIKit.Web frameworks, these documents provide detailed function signatures, parameters, error codes, and practical code examples to facilitate the integration of advanced web capabilities into native applications.
