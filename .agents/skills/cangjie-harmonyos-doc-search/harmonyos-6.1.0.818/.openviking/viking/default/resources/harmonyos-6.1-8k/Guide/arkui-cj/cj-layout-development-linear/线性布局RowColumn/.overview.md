### 线性布局RowColumn_4more_53098c0f.md 线性布局RowColumn_4more_53098c0f.md
本文档旨在介绍使用仓颉语言进行ArkUI开发时线性布局的基础概念及用法。文档主要涵盖Row和Column容器的概述、布局轴线（主轴和交叉轴）的定义，以及如何使用space属性管理子元素间距。关键信息包括Column垂直排列、Row水平排列子元素，以及利用space属性实现子元素间的等间距排列。该指南面向使用仓颉语言构建UI的开发者，通过代码示例和图示帮助学习基础布局结构。关键词：线性布局、Row、Column、主轴、交叉轴、space属性、仓颉。

### 自适应延伸.md 自适应延伸.md
本文档介绍了ArkUI应用中实现自适应延伸的方法，解决内容超出屏幕显示的问题。主要涵盖两种实现方式：在List中添加滚动条，以及使用Scroll组件包裹Column或Row实现垂直或水平滚动。文档提供了Cangjie代码示例，展示如何配置滚动方向、滚动条状态及样式。面向使用Cangjie的ArkUI开发者，适用于线性布局内容溢出的场景。

### 自适应拉伸_2more_5e017bc4.md 自适应拉伸_2more_5e017bc4.md
本文档旨在介绍在ArkUI框架中使用Cangjie语言实现线性布局下的自适应拉伸与缩放方法。文档主要涵盖“自适应拉伸”和“自适应缩放”两部分。前者讲解利用Blank组件和百分比宽高填充空间；后者介绍通过layoutWeight属性分配权重及使用百分比宽度实现子元素按比例调整尺寸。文档提供了横竖屏切换下的代码示例及效果图，展示了界面随设备尺寸变化的动态效果。本文适合具备ArkUI基础的开发者，旨在指导其构建响应式用户界面。

### 布局子元素在主轴上的排列方式/
本目录主要介绍在UI布局系统中如何控制子元素在主轴上的排列方式。核心内容围绕 `justifyContent` 属性展开，涵盖了从起始端、结束端到空间均匀分割等多种对齐策略。文档特别针对 ArkUI 框架下的 Column 和 Row 容器进行了详细说明，并提供了 Cangjie 语言的代码示例。这适合需要掌握 Flex 布局对齐技巧、进行精准 UI 界面调整的开发人员参考。

### 布局子元素在交叉轴上的对齐方式/
本目录主要介绍在ArkUI框架中，如何使用仓颉语言控制布局容器内子元素在交叉轴上的对齐方式。内容涵盖了Row容器的垂直对齐和Column容器的水平对齐，详细讲解了`alignItems`和`alignSelf`属性的使用方法及优先级。通过完整的代码示例和UI效果图，帮助开发者掌握基础布局控制技巧。适合HarmonyOS应用开发的初学者及UI工程师参考学习。
