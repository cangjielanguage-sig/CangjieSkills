# console_sample

This directory serves as a comprehensive educational resource designed to introduce developers to the fundamental concepts of console input and output (I/O) within the Cangjie programming language. It focuses on the practical implementation of standard I/O streams, which are essential for creating interactive command-line applications. The content covers critical procedures such as importing the standard console library, utilizing `Console.stdOut` to display user prompts, and employing `Console.stdIn` to capture and process user responses. Special attention is given to error handling and result management, specifically through the use of `getOrThrow` to ensure robust input retrieval. This tutorial is perfectly suited for beginners in Cangjie who are looking to establish a solid foundation in user interaction patterns and understand the underlying mechanics of reading from and writing to the system console. By mastering these basic operations, developers can effectively build more complex, data-driven applications that rely on direct user feedback.
