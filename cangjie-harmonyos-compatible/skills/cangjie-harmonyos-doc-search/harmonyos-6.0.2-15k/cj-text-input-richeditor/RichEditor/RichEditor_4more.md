# RichEditor

支持图文混排和文本交互式编辑的组件。

## 子组件

无

## 创建组件

### init(RichEditorController)

```cangjie
public init(controller: RichEditorController)
```

**功能：** 创建RichEditor组件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|controller|[RichEditorController](#class-richeditorcontroller)|是|-|富文本控制器。|

## 通用属性/通用事件

通用属性：全部支持。

> **说明：**
>
> - align属性只支持上方、中间和下方位置的对齐方式。
> - 不支持borderImage属性。

通用事件：全部支持。
