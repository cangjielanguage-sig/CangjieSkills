This directory contains the API reference documentation for the `ColumnSplit` component within the ArkUI framework. It focuses on the technical implementation of arranging child components vertically using horizontal dividers. The documentation covers essential aspects such as component initialization, constraints applied to child components, support for universal attributes, and specific properties like `divider` and `resizeable`. It clarifies the behavior of divider positions, which are calculated initially and remain static unless manually dragged, while also noting limitations regarding dynamic resizing. This resource is suitable for developers using the Cangjie language to build user interfaces, providing the necessary syntax definitions and code examples to create flexible, resizable layouts.
