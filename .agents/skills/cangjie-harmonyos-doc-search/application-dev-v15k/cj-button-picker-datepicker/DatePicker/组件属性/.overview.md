# 组件属性

This directory provides comprehensive API reference documentation for defining and manipulating component properties within the ArkUI framework, specifically tailored for the Cangjie programming language. It focuses extensively on text styling mechanisms, allowing developers to fine-tune the appearance of UI elements, particularly picker components. Key topics include setting text attributes for selected items, configuring styles for non-focused (disappearing) options, and managing font resources. Additionally, the documentation covers specific functional behaviors such as toggling lunar calendar displays. These guides are indispensable for Cangjie developers and UI engineers aiming to create highly customized, visually consistent, and functionally rich user interfaces, offering granular control over typography and component rendering logic to meet specific design requirements and system capabilities.

## Detailed Description

The following files provide specific API details for implementing these configurations.

### func_disappearTextStyleRes_4more.md func_disappearTextStyleRes_4more.md
This document serves as API reference documentation for configuring text styles and calendar display within a Cangjie-based UI component, likely a picker. It details four specific functions: two overloads of disappearTextStyle, lunar, and selectedTextStyle. Key information includes that disappearTextStyle sets the style for the top and bottom options, while selectedTextStyle configures the currently selected item. Both accept parameters for color, size, weight, font family, and style, with specific defaults provided. The lunar function enables or disables lunar calendar display. These APIs require SystemCapability.ArkUI.ArkUI.Full and are available starting from version 12. The target audience is Cangjie developers utilizing ArkUI to customize picker component behaviors and aesthetics.

### func_selectedTextStyleReso_3more.md func_selectedTextStyleReso_3more.md
This document serves as API reference documentation for Cangjie language functions designed to configure text styles within the ArkUI framework. It details three specific function overloads: selectedTextStyle and two variants of textStyle, covering parameters such as color, size, weight, font family, and style. Key information includes parameter definitions, default values like specific hex codes and font weights, and distinctions between AppResource and String types for font families. The intended audience is ArkUI developers using Cangjie who need to customize the appearance of text in selected or standard UI components.
