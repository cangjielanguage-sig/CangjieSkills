## 设备发现开发指导

### 场景概述

开发者可以调用DeviceManager设备发现相关API，获取周边可用的设备。

### 接口说明

startDiscovering(discoverParam: HashMap\<String, ValueType>, filterOptions!: ?HashMap\<String, ValueType> = None): Unit

发现周边设备。详细信息请参见：[startDiscovering](../../API_Reference/source_zh_cn/apis/DistributedServiceKit/cj-apis-distributed_device_manager.md#func-startdiscoveringhashmapstring-valuetype-hashmapstring-valuetype)。

### 开发步骤

1. 申请分布式数据同步权限。

2. 导入DistributedServiceKit模块，所有与设备管理相关的功能API，都是通过该模块提供的。

    ```cangjie
    import kit.DistributedServiceKit.*
    ```

3. 导入BusinessException模块，用于获取DistributedServiceKit模块相关API抛出的错误码。

    ```cangjie
    import ohos.base.*
    ```

4. 创建设备管理实例，设备管理实例是分布式设备管理方法的调用入口，并注册发现设备的回调。

    ```cangjie
    class Callback1ArgumentImpl<A> <: Callback1Argument<A> {
        Callback1ArgumentImpl(let callback: (A) -> Unit) {}

        public func invoke(arg: A): Unit {
            callback(arg)
        }
    }

    let discoverSuccess = Callback1ArgumentImpl<String> {
        deviceName: String => AppLog.info("discoverSuccess on: ${deviceName}")
    }

    let discoverFailure = Callback1ArgumentImpl<String> {
        deviceName: String => AppLog.info("discoverFailure on: ${deviceName}")
    }

    try {
        let dmInstance = createDeviceManager('ohos.samples.cjHelloWorld')
        dmInstance.on(DISCOVER_SUCCESS, discoverSuccess)
        dmInstance.on(DISCOVER_FAILURE, discoverFailure)
    } catch (e: BusinessException) {
        AppLog.error("createDeviceManager ErrorCode: ${e.code}, ErrorMessage: ${e.message}")
    }
    ```

5. 发现周边设备。发现状态持续两分钟，超过两分钟，会停止发现，最大发现数量99个。wifi场景要求同局域网。

    ```cangjie
    let discoverParam: HashMap<String, ValueType> = HashMap<String, ValueType>([("discoverTargetType", Integer(1))])
    let filterOptions: HashMap<String, ValueType> = HashMap<String, ValueType>([("availableStatus", Integer(0))])

    try {
        let dmInstance = createDeviceManager('ohos.samples.cjHelloWorld')
        dmInstance.startDiscovering(discoverParam, filterOptions: filterOptions)
    } catch (e: BusinessException) {
        AppLog.error("startDiscovering errCode: ${e.code},errMessage: ${e.message}")
    }
    ```
