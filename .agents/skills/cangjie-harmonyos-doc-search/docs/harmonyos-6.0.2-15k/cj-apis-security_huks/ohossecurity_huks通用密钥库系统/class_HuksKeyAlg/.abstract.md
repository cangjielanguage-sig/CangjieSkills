This directory provides comprehensive documentation for the `HuksKeyAlg` class, a core component of the Huawei Universal Keystore (HUKS) system designed for the Cangjie programming language. It covers the definition and usage of static constants representing a wide range of cryptographic algorithms, including industry standards like RSA, ECC, AES, and HMAC, as well as the SM series (SM2, SM3, SM4) and legacy options. The documentation details integer mappings, system capability requirements, and API versioning constraints. This resource is essential for HarmonyOS developers and security engineers who need to specify precise algorithm types when configuring HUKS parameters for secure key management and cryptographic operations in their applications.
