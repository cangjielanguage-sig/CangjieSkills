This directory focuses on the critical technical aspects of calculating safe areas and implementing avoidance adaptations for web components in HarmonyOS development. It provides a deep dive into the mechanisms required to handle immersive modes, ensuring that web content remains visible and unobstructed by system UI elements such as status bars and navigation bars. The documentation covers the distinction between safe and non-safe areas, the use of the ArkWeb kernel for position monitoring, and specific implementation strategies using CSS environment variables and meta tags. This resource is specifically designed for web developers and UI/UX engineers who need to optimize layouts for devices with non-rectangular screens or those utilizing full-screen immersive effects, ensuring a seamless user experience free from layout conflicts.
