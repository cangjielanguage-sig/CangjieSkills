# 设置播放状态

This directory provides comprehensive technical guidance for developers on how to configure and manage media playback states within the system's control center using the AVSessionKit framework. It covers essential tasks such as updating playback status, managing progress bars, handling metadata, and addressing complex scenarios like trial listening and advertisements. Key topics include the `setAVPlaybackState` API, buffering logic, position tracking, and speed control. This documentation is specifically designed for application developers using the Cangjie language who need to synchronize their app's media player with the system UI and ensure accurate state reporting. By following these guides, developers can ensure a seamless media experience for users interacting with system-level controls.

## Detailed Description

The following files provide specific instructions and code examples for implementing these features.

### 进度条.md 进度条.md

This technical guide explains how to configure and manage media playback progress within the system's control center using the AVSessionKit. It covers setting media metadata (duration), defining playback state (position, speed, buffering), and handling special scenarios like trial listening, non-trial content, and advertisements. The system automatically calculates progress, requiring apps to update AVPlaybackState only when state, position, or speed change. Specific logic is provided for handling trial durations (relative vs. absolute timestamps) and separating ad duration from main content. This guide targets application developers working with media playback in the Cangjie language who need to integrate with system-level media controls.

### 通用播放状态.md 通用播放状态.md

This document guides developers on how to update and display the current media playback status within the system's playback control center using the AVSessionKit. It details the `setAVPlaybackState` API and lists key state attributes such as playback state, position, speed, and loop mode. The document provides a Cangjie code example demonstrating how to initialize an `AVPlaybackState` object, configure properties like pause status and favorites, and handle potential errors during the update process. This tutorial is intended for application developers using the Cangjie language who need to synchronize their app's media player status with the system UI.
