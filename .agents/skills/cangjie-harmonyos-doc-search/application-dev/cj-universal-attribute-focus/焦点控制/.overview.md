# 焦点控制

This directory provides comprehensive API reference documentation for focus control mechanisms within the ArkUI framework, specifically utilizing the Cangjie programming language. It covers the essential tools required to manage and manipulate user interface focus, enabling developers to create intuitive and accessible navigation experiences. Key topics include the `FocusControl` class for programmatic focus requests, as well as various attributes for configuring component focusability, default focus states, and custom navigation sequences using Tab or arrow keys. The documentation is primarily intended for ArkUI developers and UI engineers who need to implement robust focus logic, handle custom components, and ensure seamless user interaction in their applications starting from version 22.

## Detailed Description

The following files provide in-depth technical specifications and usage guidelines for the focus control features available in the ArkUI framework.

### class_FocusControl.md

This document serves as API reference documentation for the FocusControl class in the Cangjie language, designed to manage focus behavior within the ArkUI framework. It details the class definition and its primary static method, requestFocus. Key information includes the method's functionality to programmatically transfer focus to a target component using its bound key or id string. The method returns a boolean indicating success, dependent on the target's existence and focusability. Intended for ArkUI developers, this reference guide assists in implementing custom focus navigation and control logic in applications starting from version 22.

### 焦点控制_7more.md

This document serves as an API reference for managing focus control within the ArkUI framework using the Cangjie programming language. It details how to configure custom component focus behaviors, including focusability, default focus states, and navigation order via Tab or arrow keys. The main sections cover the module import and specific functions such as defaultFocus, focusable, focusOnTouch, groupDefaultFocus, and tabIndex, each with parameter descriptions and return values. Key takeaways include understanding that custom components rely on child components for focus and that tabIndex customizes navigation sequences. This technical guide is intended for developers implementing UI navigation logic.
