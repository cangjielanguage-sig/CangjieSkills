This directory contains API reference documentation for the `GattClientDevice` class in the Cangjie language, focusing on client-side Bluetooth Low Energy (BLE) operations. It covers essential GATT client functionalities including device connection management, service discovery, characteristic and descriptor reading/writing, and event subscription for notifications and MTU changes. The documentation is designed for software developers using the ConnectivityKit to implement BLE connectivity, providing detailed function signatures, system capabilities, error codes, and practical code examples for handling asynchronous operations and business exceptions.
