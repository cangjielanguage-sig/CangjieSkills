This directory serves as the central repository for documentation regarding the `cj-universal-attribute-hovereffect` module within the Cangjie ArkUI framework. It is dedicated to the implementation and configuration of mouse hover visual effects, a fundamental feature for creating responsive and intuitive user interfaces. The documentation provides an in-depth look at the `hoverEffect` function, detailing its signature, required system capabilities, and the `HoverEffect` enum which defines specific visual behaviors such as Auto, Highlight, and None. By including comprehensive parameter definitions and a complete, executable code example that demonstrates how to log hover states across different components, this guide acts as a practical manual. It is specifically designed for Cangjie developers who are looking to elevate the user experience of their applications by adding dynamic, interactive feedback mechanisms through precise mouse interaction handling.
