This directory provides comprehensive documentation on ArkUI's mirroring capabilities, a critical feature currently in Beta for adapting user interfaces to Right-to-Left (RTL) reading habits. It serves as a technical guide for developers implementing internationalization (i18n) and localization (l10n) by detailing how layouts automatically flip horizontally to accommodate different languages. The content covers the core concepts of LTR and RTL, the specific conditions required to trigger mirroring (such as setting the direction property), and the constraints developers must navigate. It highlights which components are pre-adapted and which require manual intervention, such as replacing absolute positioning terms with relative ones. This resource is specifically tailored for ArkUI developers aiming to create seamless, bidirectional user experiences for global markets, ensuring that applications function correctly across diverse linguistic environments.
