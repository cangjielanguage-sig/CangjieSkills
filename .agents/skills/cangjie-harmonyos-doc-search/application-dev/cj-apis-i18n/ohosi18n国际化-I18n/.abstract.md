This directory contains API reference documentation for the `ohos.i18n` module in the Cangjie programming language, focusing on internationalization (I18n) capabilities for HarmonyOS applications. It covers system language preferences, calendar types (Gregorian, Buddhist, etc.), and complex date/time manipulations. Key components include the System class, CalendarType enumeration, and the Calendar class. This documentation is suitable for software developers building globalized applications who need to handle locale-specific settings, time zones, and date arithmetic.
