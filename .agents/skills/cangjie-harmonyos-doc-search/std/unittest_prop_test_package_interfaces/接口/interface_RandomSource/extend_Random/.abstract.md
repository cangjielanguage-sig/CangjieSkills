This directory contains API reference documentation for extending the `Random` type in the Cangjie programming language. It comprehensively covers the implementation of the `RandomSource` interface and provides a wide array of functions for generating pseudo-random numbers. The documentation details methods for various numeric types, including signed and unsigned integers (Int8 to Int64, UInt8 to UInt64), floating-point numbers (Float16 to Float64), Booleans, and Runes. It includes functionality for bounded ranges, Gaussian distributions, and full-range value generation. This resource is suitable for Cangjie developers looking to implement robust randomization logic, handle specific numeric constraints, or utilize statistical distributions in their applications.
