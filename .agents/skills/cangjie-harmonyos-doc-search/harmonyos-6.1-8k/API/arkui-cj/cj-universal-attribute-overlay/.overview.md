# cj-universal-attribute-overlay

本目录包含ArkUI框架中`overlay`通用属性API的文档，专为仓颉语言开发者设计。它详细介绍了如何在UI组件上添加文本遮罩浮层，涵盖函数定义、参数（文本内容、对齐方式、偏移量）详解、返回值说明及代码示例。文档还指出了`align`与`offset`效果的叠加机制，并注明该功能目前处于Beta阶段。适合需要在应用界面中实现文本覆盖或提示效果的开发者参考。

## 详细说明

### cj-universal-attribute-overlay.md cj-universal-attribute-overlay.md
本文档介绍了ArkUI框架中用于在组件上添加遮罩文本浮层的overlay通用属性API。文档涵盖了函数定义、参数详解（包括文本内容、对齐方式及偏移量）、返回值说明及代码示例。核心信息指出align与offset效果叠加，且该功能目前处于Beta阶段。面向使用仓颉语言的开发者，旨在帮助其在UI组件上实现文本覆盖或提示效果。
