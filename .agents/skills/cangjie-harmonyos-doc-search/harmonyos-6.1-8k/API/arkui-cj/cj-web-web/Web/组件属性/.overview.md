# 组件属性

本目录包含Cangjie语言中Web组件及Webview组件的属性配置API参考文档。内容涵盖了深色模式设置、DOM存储与文件系统权限管理、JavaScript对象注入、混合内容加载、滚动行为控制以及手势缩放等功能。这些文档旨在为HarmonyOS Web应用开发者提供精细化的组件配置能力，支持链式调用与默认参数设置，适用于需要深度定制Web视图交互与显示特性的开发场景。

## 详细描述

### func_darkModeWebD_6more_4f6e560c.md
这份文档是Cangjie语言Webview组件的API参考，详细定义了六个用于配置Web行为和权限的函数。主要内容包括设置深色模式、DOM存储访问、文件系统访问、强制深色模式、地理位置权限及图片加载控制。这些函数均返回This以支持链式调用，起始版本为22。关键点在于darkMode需配合forceDarkAccess实现强制深色效果，且各权限均有明确的默认值。文档面向Web应用开发人员，旨在提供精细化的Web组件配置能力。

### func_javaScriptPr_5more_560ea7ec.md
本文档是Cangjie语言Web组件的API参考文档，详细说明了五个用于配置Web视图行为的函数。主要内容包括：注入JavaScript对象以实现应用侧与网页交互、设置HTTP与HTTPS混合内容加载模式、配置双向嵌套滚动、控制网络图片资源访问权限以及管理纵向滚动条的显示。关键信息指出这些函数均采用命名参数并具备默认值，支持链式调用。文档面向使用Cangjie开发HarmonyOS Web应用的开发者，旨在帮助他们精细控制WebView的交互与显示特性。

### func_zoomAccessBool_66438091.md
本文档是zoomAccess函数的API参考文档，旨在设置Webview组件是否支持手势缩放。文档主要包含函数定义、系统能力声明、起始版本及参数说明。关键信息指出，该函数接收一个必填的可空布尔参数zoomAccess，true表示支持缩放，false表示不支持，默认初始值为false。此功能属于SystemCapability.Web.Webview.Core，适用于版本22及以上的系统。目标受众为Webview开发者，用于精细控制视图的交互行为。
