This directory contains API reference documentation for the `JsonDeserializable` interface in the Cangjie programming language. It details how various data types implement the `fromJson` method to parse JSON streams into native objects. The content covers core interface definitions, numeric types (integers, floats, Decimal), collections (ArrayList, HashMap, Array), and utility types (String, Option, DateTime). It is suitable for Cangjie developers integrating JSON parsing capabilities, focusing on stream-based reading, generic constraints, and error handling like overflow exceptions.
