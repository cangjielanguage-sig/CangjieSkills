# 媒体会话提供方

This directory provides a technical overview and implementation guide for creating media session providers on the HarmonyOS platform. It is designed to assist developers in integrating audio and video applications with the system's media framework, enabling the display of media information and the handling of playback commands. Key technical areas covered include the management of `AVMetadata` for media attributes, `AVPlaybackState` for status updates, and the overall session lifecycle. This documentation is essential for developers working with the Cangjie programming language who need to ensure their media apps interact correctly with system control centers and support robust controller interactions.
