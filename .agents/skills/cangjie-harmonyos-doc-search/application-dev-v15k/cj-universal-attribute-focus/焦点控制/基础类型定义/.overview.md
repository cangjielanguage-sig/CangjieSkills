This directory contains fundamental type definitions and API references for the Cangjie language within the ArkUI framework. It covers essential components for managing focus states, including focus box styling, programmatic focus control, and priority enumeration. Additionally, it includes detailed documentation for color metrics, enabling precise color manipulation and representation. These resources are designed for HarmonyOS developers and UI engineers who need to implement robust focus management and dynamic theming in their applications.

## Detailed Description

### class_FocusBoxStyle.md class_FocusBoxStyle.md
This API reference document defines the Cangjie class FocusBoxStyle, which configures the visual appearance of system focus boxes within the ArkUI framework. It details the class constructor and three public properties: margin, strokeColor, and strokeWidth. The properties define the focus box's distance from the component edge, color, and width respectively. Specific constraints are noted, such as the lack of support for percentages in margin and strokeWidth, and the prohibition of negative values for strokeWidth. This guide targets ArkUI developers using Cangjie who need to customize focus indicators, requiring knowledge of basic UI types like Length and ColorMetrics.

### class_FocusControl.md class_FocusControl.md
This document provides API reference documentation for the FocusControl class in the Cangjie language, designed to manage component focus within the ArkUI framework. The content details the static method requestFocus, which enables developers to programmatically transfer focus to a specific component using a string identifier bound via key or id. Key information includes the method's signature, the required String parameter, and the Bool return value indicating success based on the target's existence and focusability. Intended for application developers, this reference assists in implementing custom focus control logic in system version 12 or later.

### enum_FocusPriority.md enum_FocusPriority.md
This document serves as an API reference for the Cangjie language's FocusPriority enum, which defines focus acquisition priorities within UI components. The content details the enum definition and provides specific descriptions for its three values: AUTO, PRIOR, and PREVIOUS, including their system capabilities and version requirements. Key information includes the priority hierarchy: AUTO is the default, PRIOR grants higher priority for initial focus, and PREVIOUS holds the highest priority by restoring focus to the last active node when a container regains focus. This reference is intended for UI developers using the ArkUI framework in Cangjie to manage user interface navigation and focus states effectively. Keywords: FocusPriority, Cangjie, ArkUI, enum, focus management, UI components.

### class_ColorMetrics/
This directory provides comprehensive API reference documentation for the `ColorMetrics` class, specifically designed for the Cangjie language within the ArkUI framework. It focuses on color mixing, representation, and manipulation for user interface development. The content covers read-only properties for color components (red, green, blue, alpha), string representations, and various static factory methods for instantiation. Key functionalities include creating instances from HEX values, RGBA components, or color enums, as well as advanced operations like color blending and resource loading. This documentation is intended for software developers and engineers working on HarmonyOS applications who require precise control over color metrics and styling using SystemCapability.ArkUI.ArkUI.Full. By utilizing these tools, developers can ensure consistent and dynamic theming across their applications, handling both static color definitions and runtime color adjustments efficiently. The guide is essential for mastering color management in modern UI development.
