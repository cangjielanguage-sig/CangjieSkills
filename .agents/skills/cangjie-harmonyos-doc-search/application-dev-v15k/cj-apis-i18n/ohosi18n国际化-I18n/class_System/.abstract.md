This directory contains API reference documentation for the `System` class within the Cangjie programming language's LocalizationKit. It focuses on internationalization (I18n) features, enabling developers to retrieve and configure system-level language, region, and locale settings. The documentation covers static methods for accessing preferred languages, display countries, time formats, and system capabilities. It is designed for software developers implementing localization in global applications, providing method signatures, parameters, return values, and error handling details to ensure correct usage of system internationalization features.
