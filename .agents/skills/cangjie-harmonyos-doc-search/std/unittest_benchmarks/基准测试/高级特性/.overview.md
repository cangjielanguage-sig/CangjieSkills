# 高级特性

This directory contains advanced configuration guides for a Cangjie testing and benchmarking framework. It covers input regeneration strategies, detailed report generation, custom metrics, and parameter tuning to prevent compiler optimizations. Key topics include `BenchInputProvider`, `@Strategy` annotation, HTML/CSV reporting, and micro-benchmark precision. It is suitable for Cangjie developers and performance engineers seeking granular control over benchmarks, accurate performance simulation, and in-depth analysis beyond standard timing.

## Detailed Description

### 每次调用前的设置.md 每次调用前的设置.md
This guide explains how to configure input data regeneration for accurate benchmarking of state-modifying functions in a Cangjie testing framework. It covers the `BenchInputProvider` interface and the `@Strategy` annotation, detailing four specific implementations: `ImmutableInputProvider`, `GenerateEachInputProvider`, `BatchSizeOneInputProvider`, and `BatchInputProvider`. Key takeaways include the recommendation to use `GenerateEachInputProvider` for stable generation, the precision limitations of `BatchSizeOneInputProvider` for fast operations, and the potential GC overhead of `BatchInputProvider`. This technical reference targets developers seeking to optimize benchmark accuracy by managing input state and execution time measurement.

### 高级特性_3more.md 高级特性_3more.md
This technical guide outlines advanced configuration options for a benchmarking framework to facilitate in-depth performance analysis and result verification. It covers two main topics: generating detailed reports and implementing custom test sources. Key information includes using the `--report-format=html` option to create visualized reports with charts (requiring Gnuplot) or exporting raw data to CSV for statistical analysis. Additionally, it explains how to use the `@Measure` annotation and `Measurement` interface to track specific metrics like CPU cycles and hardware performance counters instead of just time. This document targets developers and performance engineers using the Cangjie language who require granular diagnostics beyond standard timing benchmarks.

### 高级配置参数_2more.md 高级配置参数_2more.md
This document serves as a technical guide for configuring advanced benchmarking parameters and preventing compiler optimizations in the Cangjie programming language. It details specific configuration options like batchSize, minBatches, warmup, minDuration, and explicitGC, alongside a DSL syntax for parameter iteration. Additionally, it addresses strategies to avoid unnecessary compiler optimizations to ensure realistic performance testing. Key takeaways include using the @Configure macro for settings, employing config.<parameter> in <strategy> for value iteration, and utilizing strategies to hide literal values or store return values globally to prevent code elimination. This guide targets Cangjie developers seeking precise control over micro-benchmarks and accurate performance simulation.
