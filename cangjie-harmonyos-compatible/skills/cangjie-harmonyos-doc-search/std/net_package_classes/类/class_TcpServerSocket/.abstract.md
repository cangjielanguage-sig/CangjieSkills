This directory contains API reference documentation for the `TcpServerSocket` class in the Cangjie programming language. It covers the implementation of TCP server functionality, including class initialization, socket configuration, connection management, and low-level option handling. Key topics include socket properties like backlog size and address reuse, binding and listening logic, and methods for accepting client connections. The documentation is designed for software developers and network engineers familiar with network programming concepts who need to configure, manage, and troubleshoot TCP connections in Cangjie applications.
