# static_prop_versionId

This directory provides comprehensive documentation and practical code examples for the `versionId` static property in the Cangjie language and HarmonyOS environments. It focuses on retrieving a device's comprehensive version identifier, which is a read-only string combining attributes such as device type, brand, OS name, and build type. The resources include API reference details regarding syntax, data types, and required system capabilities, as well as implementation examples for logging device metadata and managing runtime exceptions. This collection is designed for Cangjie and HarmonyOS developers building OpenHarmony system applications who require precise device identification and system information access for diagnostics or conditional logic.

## Detailed Description

### static_prop_versionId_1.md
This document serves as API reference documentation for the static property versionId within the Cangjie language environment, detailing how to retrieve a device's comprehensive version identifier. The content covers the property's syntax, functionality, data type, read-only access capability, required system capability, and the API version it was introduced in. It also provides a usage example with necessary imports. Key information indicates that versionId is a read-only String concatenating attributes like device type, brand, OS name, and build type. It requires the SystemCapability.Startup.SystemInfo permission and is available from API version 22. This reference is intended for Cangjie developers working on OpenHarmony system applications who need to access detailed system information for logging, device identification, or conditional logic based on specific build configurations.
