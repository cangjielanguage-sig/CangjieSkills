# 基于Cangjie编写和执行测试

This directory serves as a comprehensive resource for developers aiming to implement automated testing using the Cangjie language within the OpenHarmony and HarmonyOS development environment. It systematically guides users through the entire testing process, beginning with the prerequisite setup of DevEco Studio. The documentation covers the creation of robust test scripts, including unit tests with assertions and UI tests utilizing the UiTest API for component interaction. Additionally, it provides detailed instructions on executing these tests via both the DevEco Studio graphical interface and the command line using the `aa test` command. Key topics include environment configuration, script writing, test execution strategies, and log analysis. This guide is specifically designed for developers and QA engineers familiar with OpenHarmony who wish to ensure application quality through structured testing.

## Detailed Description

### 执行测试脚本.md 执行测试脚本.md
This technical guide explains how to execute test scripts for OpenHarmony applications using either DevEco Studio or the command line interface. The document covers two primary execution methods: a graphical approach within the IDE and a command-line approach using the aa test command. Key information includes the requirement for hardware connection, specific command parameters for bundle and module names, and configuration options for test runners. It highlights that execution is currently limited to the TestClass granularity rather than individual TestCases. Additionally, it provides examples of command usage and explains how to interpret XML log outputs for test results. This guide is intended for developers familiar with the hdc environment and OpenHarmony testing frameworks.

### 搭建环境.md 搭建环境.md
This document serves as a preliminary guide for setting up the development environment, specifically focusing on obtaining and configuring DevEco Studio. The content directs users to the official Huawei developer website to download the necessary software and perform relevant configuration actions. The key information provided is the direct link to the download page, indicating that detailed setup instructions are hosted externally rather than within the file itself. This brief reference document is intended for developers initiating a project that requires DevEco Studio, likely for HarmonyOS application development, acting as a starting point for environment preparation.

### 新建和编写测试脚本.md 新建和编写测试脚本.md
This tutorial guides developers on creating and writing test scripts for HarmonyOS applications using the Cangjie language in DevEco Studio. It covers creating scripts in the ohosTest directory, writing unit test scripts with assertions, and writing UI test scripts using the UiTest API. Key information includes the necessity of dependency imports and assertions in unit tests, and the use of Driver for UI interactions like finding components, clicking, and verifying text changes. The document targets HarmonyOS developers seeking to implement automated testing for their applications.
