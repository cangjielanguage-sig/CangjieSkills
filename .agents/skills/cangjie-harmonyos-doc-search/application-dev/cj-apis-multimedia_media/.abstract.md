This directory provides API reference documentation for the `ohos.multimedia.media` module in the Cangjie language, specifically focusing on media services within the HarmonyOS ecosystem. It covers the essential components required for video thumbnail generation and image frame extraction, including data source descriptors, pixel map parameters, and query options. The documentation details the `AVImageGenerator` class and related utilities for handling media resources efficiently. It is suitable for multimedia developers and software engineers working with Cangjie who need to integrate video preview capabilities and manage system media resources in their applications.
