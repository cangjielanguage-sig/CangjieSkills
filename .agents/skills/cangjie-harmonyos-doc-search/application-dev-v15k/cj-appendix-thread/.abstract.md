This directory provides a comprehensive technical guide dedicated to thread control management within the Cangjie programming language, specifically tailored for HarmonyOS application development. It addresses the architectural necessity of separating UI and non-UI logic to ensure application responsiveness and stability. The content covers the development paradigm for custom thread scheduling, thread creation using the `spawn` keyword, and the `launch` function API. It explains how to bind Cangjie user threads to the OS UI thread using the `Main` object to prevent performance issues. This resource is essential for Cangjie developers looking to master concurrency, manage UI state updates, and optimize application performance through proper thread handling. It assumes the reader has a foundational understanding of concurrency concepts and UI state management.
