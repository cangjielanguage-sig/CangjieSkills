### enum SheetType

```cangjie
public enum SheetType {
    | BOTTOM
    | CENTER
    | POPUP
}
```

**功能：** 设置半模态弹窗的样式。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

#### CENTER

```cangjie
CENTER
```

**功能：** 居中弹窗。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full


**起始版本：** 12
