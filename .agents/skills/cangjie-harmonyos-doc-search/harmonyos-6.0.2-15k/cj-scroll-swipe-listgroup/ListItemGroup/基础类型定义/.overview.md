# 基础类型定义

This directory serves as a foundational resource for defining basic types within the ArkUI framework using the Cangjie programming language. It specifically focuses on the structural configuration and styling of list item groups, providing essential enumerations and parameter classes. Key topics include the `ListItemGroupStyle` enum for visual presentation and the `ListItemGroupParams` class for detailed component configuration, covering aspects such as headers, footers, and item spacing. This documentation is primarily suitable for HarmonyOS developers and UI engineers who are utilizing Cangjie to build complex, structured user interfaces and require precise control over list component behaviors.

## Detailed Description

### enum_ListItemGroupStyle.md enum_ListItemGroupStyle.md
This document provides API reference documentation for the ListItemGroupStyle enum in the Cangjie language, used to define the visual style of List components in the ArkUI framework. It covers the enum definition and detailed descriptions for its two specific values: CARD and NONE. Key takeaways include that CARD applies a default card style while NONE removes styling, both supported under SystemCapability.ArkUI.ArkUI.Full starting from version 19. This reference is intended for developers building user interfaces who need to configure list group appearances. Keywords: ListItemGroupStyle, ArkUI, Cangjie, List component, enum, API reference.

### class_ListItemGroupParams/
This directory serves as a comprehensive repository for API reference documentation regarding the `ListItemGroupParams` class, utilized within the ArkUI framework and implemented using the Cangjie language. It focuses on defining configuration parameters for list item grouping components, detailing class properties like header, footer, space, and style. The content encompasses multiple constructor overloads for object initialization, highlighting requirements such as the `@Builder` decorator for header and footer components and the read-write nature of the style property. Furthermore, it explains the specific behavior of the space property regarding item spacing. This documentation is intended for HarmonyOS developers who possess knowledge of Cangjie syntax and ArkUI UI development paradigms, providing them with the necessary technical details to implement effective list grouping in their applications.
