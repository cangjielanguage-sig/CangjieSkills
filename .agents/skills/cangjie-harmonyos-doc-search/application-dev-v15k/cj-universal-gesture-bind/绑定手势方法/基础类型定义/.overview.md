# 基础类型定义

This directory serves as the foundational reference for type definitions used in gesture handling within the ArkUI framework, specifically implemented using the Cangjie language. It encompasses the essential building blocks required to construct and manage user interactions, ranging from basic touch coordinate tracking to complex gesture masking rules. Key components include the `GestureType` base class, `EventTarget` for display area management, and specific enums for controlling event propagation. By defining the core properties and behaviors of touch inputs, this module provides the necessary infrastructure for developers to build responsive and interactive user interfaces. It is highly suitable for UI developers, system architects, and engineers working on the underlying logic of gesture recognition systems who need a deep understanding of data structures, type constraints, and the initialization of gesture-related objects.

## Detailed Description

### class_GestureType_4more.md class_GestureType_4more.md

This document provides API reference documentation for gesture-related classes and enums within the ArkUI framework using the Cangjie language. It covers the base class GestureType, the EventTarget class for display areas, the FingerInfo class for touch coordinates, and the GestureMask enum for event response settings. Key information includes the tag method for custom gesture identification, read-only properties for finger coordinates (global and local), and the IgnoreInternal mask to block child component gestures. This technical reference is intended for UI developers implementing custom gesture recognition and handling in ArkUI applications.

### class_GestureEvent/

This directory contains API reference documentation for the `GestureEvent` class within the ArkUI framework, specifically written for the Cangjie language. It covers the structural definition, properties, and initialization of gesture events used to handle user interactions like panning, pinching, rotating, and swiping. The documentation details metrics such as rotation angles, coordinate offsets, scaling ratios, and velocity components, distinguishing between touchscreens and pointing devices. It is suitable for developers implementing complex gesture recognition and event-driven interfaces in ArkUI applications.
