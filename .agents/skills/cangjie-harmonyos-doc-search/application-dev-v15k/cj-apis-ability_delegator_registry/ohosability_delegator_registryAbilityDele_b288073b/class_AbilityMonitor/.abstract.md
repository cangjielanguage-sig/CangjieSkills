This directory contains API reference documentation for the `AbilityMonitor` class within the Cangjie programming language, specifically designed for HarmonyOS development. It covers the instantiation and usage of objects that monitor UIAbility lifecycle events, including creation, destruction, and state transitions. Key topics include constructor parameters, system capabilities, and callback functions for granular observation of ability state changes. This documentation is suitable for developers utilizing the `AbilityRuntime.Core` capability who need to manage or test application runtime behaviors and UIAbility interactions.
