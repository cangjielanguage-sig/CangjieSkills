# extend_BigInt_RadixConvertibleBigInt

This directory provides essential API documentation for extending the `BigInt` type in the Cangjie programming language to support comprehensive radix (base) conversion functionalities. It details the implementation of the `RadixConvertible` interface, enabling developers to parse numeric strings from various bases (2-36) into `BigInt` objects, as well as convert `BigInt` values back to string representations in desired bases. The documentation covers critical methods such as `parse`, `tryParse`, and `toString`, explaining their parameters, return values, and exception handling for invalid inputs or out-of-range radices. It also addresses support for optional signs and alphanumeric characters. This resource is tailored for Cangjie developers engaged in arbitrary-precision arithmetic who need to handle non-decimal numeric data efficiently and accurately.

### extend_BigInt_RadixConvert_3more.md extend_BigInt_RadixConvert_3more.md

This API documentation details the extension of the BigInt type to implement the RadixConvertible interface, enabling string-to-integer conversion across various bases. The document covers the extension declaration and two primary static methods: parse and tryParse. Both functions accept a string and a radix (Int64) between 2 and 36. The parse function returns a BigInt or throws an IllegalArgumentException for invalid input, whereas tryParse returns an optional BigInt or None upon failure. String formats support optional signs and alphanumeric digits valid for the specified radix. This reference guide targets Cangjie developers working with arbitrary-precision arithmetic who need to parse numeric strings from non-decimal bases.
