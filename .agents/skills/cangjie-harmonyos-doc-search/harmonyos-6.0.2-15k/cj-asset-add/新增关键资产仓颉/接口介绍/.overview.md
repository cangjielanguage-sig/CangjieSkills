# 接口介绍

This directory provides comprehensive technical documentation for API interfaces related to key asset management and synchronization. It covers the AssetStoreKit interface, parameter definitions for asset creation (AssetParam), and data security constraints. Key topics include synchronization logic, encryption requirements, conflict resolution strategies, and data label specifications (e.g., DATA_LABEL). These documents are essential for developers implementing secure asset storage, handling custom business data, and managing system updates like API12 extensions. The guides ensure proper integration of asset management features while adhering to security protocols and data integrity standards.

## Detailed Description

### 接口介绍_1.md
This document serves as a technical guide for the API interface used to synchronize new key assets. It covers the add function reference and details the AssetParam parameters required for asset creation. A critical security warning specifies that attributes named DATA_LABEL store unencrypted custom business data and must not contain personal information. This guide targets developers implementing asset synchronization who need to understand parameter structures and data security constraints. Keywords: API, AssetParam, key assets, synchronization, data encryption, DATA_LABEL.

### 接口介绍_2.md
This document serves as a technical reference defining the attribute parameters for the AssetStoreKit interface. It outlines mandatory fields such as SECRET and ALIAS, alongside optional configurations for access control, authentication types, synchronization, and data persistence. Key information includes specific data type constraints, byte length limits for various labels, and API12 updates extending label capacities to 2048 bytes. It also notes permission requirements for persistent data storage. Intended for developers integrating secure asset management, this guide provides the necessary specifications for configuring asset properties and custom data labels with or without integrity protection.

### 接口介绍_3.md
This document fragment serves as a technical reference defining specific parameters for managing key assets within an API structure. It details data fields such as local asset information labels, conflict resolution strategies, and encryption requirements. Key information includes the specifications for DATA_LABEL_NORMAL_LOCAL fields, which hold custom, non-synchronized data up to 2048 bytes, and the CONFLICT_RESOLUTION parameter for handling duplicate aliases. It also outlines the REQUIRE_ATTR_ENCRYPTED boolean for securing custom attributes. Intended for software developers, this documentation provides the necessary data type definitions and behavioral constraints for implementing asset storage and conflict handling logic effectively. Keywords: API reference, asset management, data structure, conflict resolution, encryption, UInt8, UInt32, AssetStoreKit.
