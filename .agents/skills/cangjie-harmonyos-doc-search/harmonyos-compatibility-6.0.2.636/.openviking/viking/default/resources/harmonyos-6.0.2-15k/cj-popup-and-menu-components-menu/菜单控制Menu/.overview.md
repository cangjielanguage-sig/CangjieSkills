# 菜单控制Menu

This directory focuses on menu control implementation within the Cangjie language and ArkUI framework. It covers creating custom context menus triggered by right-click or long-press actions, implementing default and custom menu styles using `bindMenu`, and managing menu lifecycles and display modes. Key topics include the `bindContextMenu` interface, `@Builder` decorator, modal behaviors, and event handling. This resource is suitable for UI developers and engineers looking to build interactive application interfaces with robust menu systems.

## Detailed Description

### 创建支持右键或长按的菜单.md 创建支持右键或长按的菜单.md
This document serves as a technical guide explaining how to implement custom context menus triggered by right-click or long-press actions using the `bindContextMenu` interface in the Cangjie language. The text covers the configuration of menu triggers, the use of the `@Builder` decorator for menu content, and the specific syntax for binding the menu to components like Buttons. Key takeaways include the ability to display menus in independent sub-windows outside the main application and the specific code pattern for setting the `responseType` parameter to define the interaction method. This tutorial is intended for developers using the Cangjie framework who need to implement interactive UI elements, specifically context menus, within their applications.

### 创建默认样式的菜单.md 创建默认样式的菜单.md
This tutorial instructs developers on implementing menus in the Cangjie language, covering both default and custom styles. The document details using the `bindMenu` interface to attach menus to components, starting with simple Action items. It progresses to advanced customization using the `@Builder` decorator to construct complex layouts, including `MenuItem`, `MenuItemGroup`, and nested sub-menus. Key takeaways include handling menu events, configuring icons, and managing state. This guide is intended for UI developers building interactive applications using the Cangjie framework.

### 菜单控制Menu_2more.md 菜单控制Menu_2more.md
This document serves as a technical reference for implementing the Menu interface within the ArkUI framework, focusing on its usage, display modes, and lifecycle management. The main topics cover the application of menus for right-click or click popups, distinguishing between modal and non-modal behaviors based on the use of `bindContextMenu` or `bindMenu`. Key information includes the specific conditions that trigger a modal mask layer and a detailed table of lifecycle callbacks such as `aboutToAppear`, `onAppear`, `aboutToDisappear`, and `onDisappear`. Intended for developers building user interfaces, this guide provides essential knowledge for controlling menu visibility and handling state transitions during entry and exit animations.
