This directory provides essential API references for the Cangjie language within the ArkUI framework, focusing on fundamental UI types. It encompasses definitions for focus management (FocusControl, FocusPriority, FocusBoxStyle) and color manipulation (ColorMetrics). These resources enable developers to implement precise focus navigation logic, customize focus indicator styles, and handle complex color operations. Designed for Cangjie and ArkUI developers, this documentation supports the creation of interactive and visually refined HarmonyOS applications.
