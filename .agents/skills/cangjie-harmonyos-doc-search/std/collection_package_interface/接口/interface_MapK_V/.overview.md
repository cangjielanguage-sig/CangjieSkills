This file focuses on specific mechanisms for updating data within a map. This document serves as API reference documentation for modifying key-value pairs within a Map collection in the Cangjie programming language. It covers two specific functions: the `replace` function and the overloaded `[]` operator. Both sections detail functionality, parameters, and return values. The `replace` function updates a value only if the key exists, returning the old value or None. Conversely, the `[]` operator acts as an upsert mechanism, overwriting existing values or adding new key-value pairs, and returns Unit. This guide targets Cangjie developers working with Map collections who need to understand the specific behaviors of value modification and insertion operations.
