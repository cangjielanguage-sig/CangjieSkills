This directory serves as a comprehensive resource for the `cj-apis-hiappevent` module, focusing on the HarmonyOS HiAppEvent functionality adapted for the Cangjie programming language. It provides detailed API references essential for implementing application event tracking, logging, subscription, and analysis. The content is deeply integrated with the Performance Analysis Kit, offering developers the tools needed for robust performance analysis, fault monitoring, and user behavior tracking. By defining data structures for event configuration, enumerations for event types, and classes for event packages and processors, this documentation is indispensable for HarmonyOS developers and system integrators seeking to optimize application performance and reliability through precise event management.
