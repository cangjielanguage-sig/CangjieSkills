## Detailed Description

### 查看_eventHandler_信息_1.md
This technical guide instructs developers on analyzing eventHandler dump logs to diagnose application freezes. It covers three main sections: current running status, history event queue information, and VIP priority event queue information. Key takeaways include methods for calculating task duration using timestamps like trigger time and complete time. The guide explains how to determine if the currently running task caused the freeze or if the issue lies in historical tasks within the queue. This resource is intended for developers troubleshooting system responsiveness and thread scheduling issues.

### 查看_eventHandler_信息_2.md
This technical reference document explains the log formats and functional roles of VIP and High priority event queues within the EventHandler system. It covers VIP priority event queue information, detailing user input transmission chains like ArkUI and MMI, and High priority event queue information, focusing on periodic watchdog tasks. The document clarifies that VIP queues handle system-managed user input events requiring immediate response, while High priority queues contain watchdog tasks sent every 3 seconds. It advises comparing these against warning or block events during analysis. This guide is intended for system developers or performance engineers analyzing event handling and system responsiveness.

### 查看_eventHandler_信息_3.md
This document provides a diagnostic analysis of event handler logs to identify system scheduling issues or application freezes. It covers log examples of high-priority event queues and a comparative analysis of queue lengths. The text highlights that a growing queue with a stagnant first task suggests either an application freeze or starvation caused by higher-priority tasks. This technical guide is intended for system developers or debuggers analyzing watchdog timer events and thread scheduling.
