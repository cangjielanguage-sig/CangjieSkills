This directory contains essential API reference documentation for the `NavigationTitleOptions` class within the ArkUI framework, tailored for developers using the Cangjie language. It covers the comprehensive styling and layout configurations available for navigation title bars, including properties for background color, blur effects, bar styles, and padding. The documentation highlights the nullable nature of these properties and their impact on visual elements, as well as specific usage constraints regarding padding in different UI contexts. Furthermore, it provides details on the constructor required to instantiate these options, specifying parameters for resources and layout adjustments. This directory is suitable for HarmonyOS developers and UI designers seeking to programmatically control and customize the aesthetic and functional aspects of navigation interfaces in their applications.
