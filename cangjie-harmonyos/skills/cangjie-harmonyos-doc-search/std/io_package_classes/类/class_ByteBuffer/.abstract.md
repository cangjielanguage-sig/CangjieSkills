This directory contains API reference documentation for the Cangjie `ByteBuffer` class, which manages in-memory byte stream read and write operations. It covers class structure, initialization, capacity management, and various methods for data manipulation like reading, writing, seeking, and cloning. Key topics include IOStream inheritance, Seekable interface, and exception handling. This resource is suitable for Cangjie developers implementing data buffering, stream manipulation, and low-level I/O operations.
