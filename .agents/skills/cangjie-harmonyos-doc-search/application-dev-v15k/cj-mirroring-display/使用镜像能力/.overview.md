# 使用镜像能力

This directory provides comprehensive documentation on the ArkUI framework's mirroring capability, which flips display content on the X-axis to accommodate Right-to-Left (RTL) reading habits. It covers core concepts like LTR and RTL layouts, activation conditions, and specific implementation details for components like Canvas. Additionally, it outlines usage constraints and limitations for various UI elements. This resource is essential for ArkUI developers and UI engineers working on internationalization (i18n) and bidirectional layout adaptation within the HarmonyOS ecosystem.

## Detailed Description

### 概述_2more.md 概述_2more.md
This document provides an overview of the ArkUI framework's mirroring capability, designed to accommodate different reading habits by flipping display content on the X-axis. The text covers the visual effects of mirroring, the specific conditions required for activation, and fundamental definitions of LTR and RTL layouts. Key takeaways include that mirroring activates when the component's direction property is set to Direction.Rtl or Direction.Auto combined with a right-to-left system language like Uyghur. Intended for ArkUI developers, this guide serves as a reference for implementing internationalization and layout adaptation.

### 自定义绘制Canvas组件.md 自定义绘制Canvas组件.md
This document explains the mirroring behavior of the Canvas component and how to implement text mirroring in response to system language changes. It covers the lack of automatic mirroring for coordinates and content, the specific support for text mirroring via CanvasRenderingContext2D, and the priority rules for the direction attribute. Key takeaways include that manual redrawing is required after language changes and that only symbols, not alphanumeric characters, respond to direction changes. A Cangjie code example demonstrates subscribing to locale events to trigger redraws. This guide targets developers working on internationalization within the HarmonyOS framework who need to handle Right-to-Left layouts in custom Canvas drawings.

### 使用约束/
This directory contains technical documentation regarding usage constraints within the ArkUI framework. It primarily focuses on display mirroring adaptation, component-specific limitations, and implementation boundaries for various UI elements. The content covers default behaviors for mirroring, lists of restricted basic components, and detailed constraints for layout containers and attributes. It is suitable for software developers and UI engineers who need to ensure application compatibility, avoid runtime errors, and implement proper bidirectional support for internationalization or specific display modes.
