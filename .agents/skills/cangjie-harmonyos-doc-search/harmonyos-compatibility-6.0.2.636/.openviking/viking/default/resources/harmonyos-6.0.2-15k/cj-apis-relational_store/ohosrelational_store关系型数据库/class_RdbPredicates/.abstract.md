This directory contains API reference documentation for the `RdbPredicates` class within the Cangjie language's ArkData kit. It focuses on constructing condition expressions and predicates for relational database operations in HarmonyOS or OpenHarmony systems. The documentation covers a wide array of methods for filtering, sorting, and aggregating data, ranging from basic comparisons to complex logical groupings and distributed queries. It is suitable for software developers and database administrators implementing data query logic, providing the necessary tools to build precise and efficient database predicates while handling concurrency and system capabilities.
