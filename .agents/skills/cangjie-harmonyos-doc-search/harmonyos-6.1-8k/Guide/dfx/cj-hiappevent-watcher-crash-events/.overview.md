# cj-hiappevent-watcher-crash-events

本目录包含关于HiAppEvent系统崩溃事件订阅功能的文档，旨在帮助开发者获取和分析应用崩溃信息。内容涵盖了崩溃事件的数据结构定义，详细说明了`params`主属性及其嵌套的`exception`、`signal`、`thread`和`frame`等关键字段，包括崩溃类型、进程信息、异常堆栈及线程调用栈。此外，文档还重点介绍了通过`external_log`路径分析CPPCRASH和CjERROR日志文件的方法，并提醒开发者注意5MB日志空间限制及及时清理。该文档适合需要进行故障诊断和性能分析的开发者参考。

## Detailed Description

### cj-hiappevent-watcher-crash-events.md
本文档介绍了HiAppEvent系统崩溃事件的订阅功能及数据结构定义，旨在帮助开发者获取和分析应用崩溃信息。文档详细说明了`params`主属性及其嵌套的`exception`、`signal`、`thread`和`frame`等字段，涵盖崩溃类型、进程信息、异常堆栈及线程调用栈。重点强调了通过`external_log`路径分析CPPCRASH和CjERROR日志文件，并提醒开发者注意5MB日志空间限制及及时清理。该文档面向需要进行故障诊断的开发者，属于技术参考文档。
