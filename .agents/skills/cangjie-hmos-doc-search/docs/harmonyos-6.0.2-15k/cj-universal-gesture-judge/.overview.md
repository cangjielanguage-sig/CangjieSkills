# cj-universal-gesture-judge

This directory serves as a comprehensive technical resource dedicated to the advanced implementation of gesture recognition and judgment within the HarmonyOS operating system environment. Specifically, it targets developers utilizing the ArkUI framework in conjunction with the Cangjie programming language. The content addresses the critical need for "universal" gesture judgment—a system capable of intelligently managing and arbitrating between multiple simultaneous or competing touch inputs. In modern mobile application development, default gesture handling often falls short when dealing with complex user interfaces that require overlapping interaction zones or custom behaviors. This directory provides the necessary architectural patterns and code structures to overcome these limitations. By leveraging the type safety and modern syntax of the Cangjie language, developers can write more reliable gesture handling code. This material is highly suitable for HarmonyOS application developers who require granular control over UI interactions and need to implement robust, conflict-free touch event processing in their applications.

### 自定义手势判定/

This directory focuses on customizing gesture recognition logic within the ArkUI framework using the Cangjie language. It covers the implementation of the `onGestureJudgeBegin` callback to resolve gesture conflicts, reject specific gestures, and distinguish between events like LongPress and Drag based on touch regions. Key topics include `GestureJudgeResult`, `GestureInfo`, and event handling structures. It is suitable for HarmonyOS application developers who need granular control over UI interactions and complex touch event processing.
