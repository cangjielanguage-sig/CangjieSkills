# 像素单位

This directory focuses on pixel unit definitions and conversion mechanisms within the Cangjie ArkUI framework. It comprehensively covers essential concepts such as physical pixels (px), virtual pixels (vp), font pixels (fp), and layout pixels (lpx), alongside the specific APIs required for transforming between these units. Key topics include density-independent design principles, responsive layout calculations, and handling system font scaling. This resource is highly suitable for Cangjie developers and UI designers who need to ensure consistent, precise, and adaptive interface rendering across a wide variety of screen densities and device configurations.
