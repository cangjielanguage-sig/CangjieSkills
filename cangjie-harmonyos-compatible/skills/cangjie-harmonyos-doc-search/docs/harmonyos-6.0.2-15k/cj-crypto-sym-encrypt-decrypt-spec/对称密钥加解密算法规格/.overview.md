# 对称密钥加解密算法规格

This directory contains technical specifications and implementation guides for symmetric key encryption algorithms. It covers standards such as AES, 3DES, and SM4, detailing their supported encryption modes (e.g., ECB, CBC, GCM), padding schemes, and parameter syntax for API integration. The documents are designed for developers using the CryptoArchitectureKit (API version 12+), providing the necessary string parameter formats and configuration rules to correctly instantiate and utilize cryptographic functions. Key topics include block cipher configurations, key length handling, and specific mode behaviors.

## Detailed Description

### 3DES.md 3DES.md
This document serves as a technical reference for implementing 3DES encryption and decryption within a specific cryptographic library. It covers the algorithm's definition, supported encryption modes (ECB, CBC, OFB, CFB), and padding requirements for 64-bit blocks. Key information includes the specific string parameter syntax for creating instances, combining symmetric key type, block mode, and padding (e.g., "3DES192|ECB|PKCS7"). It clarifies that PKCS5 and PKCS7 both pad to 8 bytes and supports omitting key length in parameters. Targeted at developers using API version 12+, this guide requires an understanding of symmetric cryptography concepts to correctly configure encryption specifications.

Keywords: 3DES, encryption modes, padding, string parameters, symmetric key, API reference.

### SM4_2more.md SM4_2more.md
This document provides a technical reference for implementing SM4 symmetric encryption, detailing supported modes, padding schemes, and parameter formatting. It covers seven encryption modes including ECB, CBC, and GCM, explains padding mechanisms like NoPadding and PKCS7, and defines the syntax for string-based parameter specification. Key takeaways include the requirement for padding in ECB and CBC modes, the specific string format "SM4_128|Mode|Padding" for instance creation, and the distinction that stream-based modes like CTR and GCM function as NoPadding regardless of settings. Intended for developers using the CryptoArchitectureKit API, this guide assumes knowledge of cryptographic concepts and focuses on version 12+ API specifications.

Keywords: SM4, symmetric encryption, block cipher, padding modes, ECB, CBC, GCM, CryptoArchitectureKit, API reference.
