# class_WebMessagePort

This directory contains documentation for the `WebMessagePort` class in the Cangjie programming language, focusing on message communication between native applications and HTML5 content within a Webview environment. It covers API references for managing ports, sending messages, and handling events, including support for standard and extended message types. Key topics include port initialization, event registration, and data serialization. This resource is suitable for developers working with HarmonyOS, ArkWeb, and hybrid applications who need to implement robust bidirectional communication between native and web components.

## Detailed Description

### class_WebMessagePort_4more.md
This document provides API reference documentation for the WebMessagePort class in the Cangjie programming language, facilitating message communication between applications and HTML content. It details the read-only property isExtentionType and essential methods including close() for terminating ports and onMessageEvent() for registering message reception callbacks. Key takeaways involve system capabilities, version 19 requirements, parameter definitions, and exception handling for message events, supported by practical code examples. Targeting developers working with Webview capabilities, this guide requires knowledge of Cangjie syntax and web component integration.

### func_postMessageEventWebMe_2more.md
This API documentation details Cangjie functions for sending messages from native code to the HTML5 side within a Webview environment. It covers postMessageEvent for standard WebMessage types and postMessageEventExt for extended WebMessageExt types, including syntax, parameters, system capabilities, and exception handling. Key information highlights that both functions require prior registration of message event listeners to succeed and may throw a BusinessException on failure. The document provides a practical code example demonstrating port creation and message transmission. Targeted at developers using the ArkWeb kit, this guide facilitates bidirectional communication between native and web components.
