# 使用画布绘制自定义图形Canvas

本目录主要介绍在ArkUI框架中使用Canvas组件进行2D自定义图形绘制的方法。内容涵盖Canvas组件的基本初始化、CanvasRenderingContext2D对象的使用、Path2D路径构建以及常用绘图API（如形状、文本、渐变）。文档主要使用Cangjie（仓颉）语言提供代码示例，旨在帮助HarmonyOS应用开发者掌握核心绘图技巧，实现丰富的2D图形界面。
