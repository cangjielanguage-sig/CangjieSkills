This directory contains API reference documentation for core interfaces within the Cangjie programming language, specifically focusing on the `unittest_prop_test` package for property-based testing. It covers essential abstractions for random data generation, value shrinking, and indexed access. Key components include the `Generator`, `Arbitrary`, `RandomSource`, and `Shrink` interfaces, along with support for various numeric types and collections. This documentation is suitable for Cangjie developers, testing framework engineers, and software architects looking to implement or utilize automated testing utilities and randomization logic in their applications.

### interface_GeneratorT_2more.md interface_GeneratorT_2more.md
This document serves as API reference documentation for two specific interfaces in the Cangjie programming language: Generator and IndexAccess. The content is divided into two main sections, each detailing an interface definition, its functionality, and specific method signatures including next() and getElementAsAny(). Key takeaways include that the Generator interface produces values of type T through its next method, while the IndexAccess interface provides a utility to retrieve tuple elements as Any type using an Int64 index, returning None if the index is invalid. This reference guide targets Cangjie developers who need to implement or utilize these interfaces for value generation and indexed data access.

### interface_ArbitraryRangeT/
This directory contains API reference documentation for the `ArbitraryRange` interface in the Cangjie programming language. The documentation covers interface definitions and extensions for signed and unsigned integers (Int8, Int16, Int32, Int64, IntNative, UInt8, UInt16, UInt32, UInt64, UIntNative) and floating-point numbers (Float16, Float32, Float64). Key components include static methods for boundary retrieval and the `arbitraryRange` function for creating Generators. This resource is suitable for developers implementing property-based testing frameworks or needing constrained random data generation for unit tests.

### interface_RandomSource/
This directory contains API reference documentation for the `RandomSource` interface in the Cangjie programming language. It covers the generation of pseudo-random numbers for various data types, including signed and unsigned integers, floating-point numbers, booleans, and Gaussian distributions. The documentation details methods for both full-range generation and range-bounded generation (using `next` and `suggest` prefixes). It is suitable for Cangjie developers implementing testing frameworks, random data generators, or applications requiring statistical distributions and precise randomization logic.

### interface_ShrinkT/
This directory contains API documentation for the `Shrink` interface in the Cangjie programming language, focusing on implementations that enable value reduction strategies for property-based testing. It covers the core interface definition and extensions for a wide range of data types, including collections like HashMap and Array, as well as primitive types such as integers, floats, and strings. These documents detail how the `shrink()` function generates iterables of smaller values to facilitate debugging and failure analysis. This resource is suitable for Cangjie developers working on testing frameworks or data manipulation libraries who need to understand how specific types support shrinking operations.
