# 键鼠事件

This directory serves as a comprehensive resource for understanding and managing input events generated by external peripherals, specifically keyboards and mice. It covers fundamental concepts of input handling within the ArkUI Cangjie framework, detailing how to capture, process, and respond to user interactions. Key topics include event bubbling, callback mechanisms, coordinate tracking, and focus management. Designed for developers and UI engineers, this documentation (currently in Beta) provides the technical guidance needed to build responsive and interactive user interfaces that support complex input logic and multi-modal input sources.

### [2] 按键事件/
This directory acts as a centralized technical hub for managing keyboard interactions within the ArkUI Cangjie framework. It provides an in-depth exploration of the `onKeyEvent` function, equipping developers with the knowledge required to handle peripheral keyboard inputs for focused components with precision. The directory delves into critical technical concepts, such as the architecture of the `KeyEvent` parameter, the mechanics of event bubbling, and the dual-callback behavior associated with key presses (Down and Up). Beyond basic handling, it offers advanced strategies for event interception, allowing for granular control over application flow. This resource is specifically curated for ArkUI developers and UI engineers who are tasked with creating responsive and interactive user interfaces. It is an essential guide for professionals needing to understand complex focus mechanisms and implement logic to prevent default event propagation, ensuring a seamless and intuitive user experience across different devices.

### [3] 鼠标事件/
This directory provides comprehensive documentation on handling mouse events within the Cangjie ArkUI framework. It is designed to help developers understand and implement interactive features by detailing the specific APIs used to capture mouse inputs. The content covers the `onMouse` and `onHover` event interfaces, explaining how to track coordinates, manage button states, and handle event bubbling. Additionally, it addresses the logic for converting left-clicks to touch events and distinguishing between different input sources. This resource is essential for ArkUI developers using the Cangjie language who aim to build responsive UI components that support both mouse and touchpad interactions effectively.
