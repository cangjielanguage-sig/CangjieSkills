# cj-arkxtest-guidelines

This directory serves as a comprehensive resource hub for the Cangjie Automated Testing Framework, specifically tailored for the HarmonyOS and OpenHarmony ecosystems. It provides in-depth documentation covering the architectural design, implementation principles, and runtime environments of both the Cangjie Unit Test Framework and the UiTest framework. The guidelines included here are essential for developers and QA engineers looking to master the writing and execution of test scripts using the Cangjie language. Additionally, it offers practical insights into performing UI automation via shell commands and resolving common execution errors. This collection is suitable for software developers and QA engineers aiming to establish robust testing workflows, configure development environments accurately, and enhance the reliability of their applications through effective debugging of UI automation scripts.

## Detailed Description

### 自动化测试框架使用指导/
This directory provides a comprehensive guide for the Cangjie Automated Testing Framework within the HarmonyOS/OpenHarmony ecosystem. It covers the architecture of the Cangjie Unit Test Framework and the UiTest framework, detailing their implementation principles and runtime environments. The content includes resources for writing and executing test scripts using the Cangjie language, performing UI automation via shell commands, and troubleshooting common execution errors. Designed for software developers and QA engineers, this documentation facilitates the setup of robust testing workflows, environment configuration, and effective debugging of UI automation scripts.

**Key Features:**
- **Comprehensive Framework Guide:** Detailed coverage of the Cangjie Automated Testing Framework architecture.
- **Dual Framework Support:** In-depth look at both the Cangjie Unit Test Framework and the UiTest framework.
- **Practical Implementation:** Resources for writing and executing test scripts in the Cangjie language.
- **Automation & Debugging:** Instructions for UI automation via shell commands and troubleshooting common errors.
- **Target Audience:** Specifically designed for software developers and QA engineers to facilitate robust testing workflows and environment configuration.
