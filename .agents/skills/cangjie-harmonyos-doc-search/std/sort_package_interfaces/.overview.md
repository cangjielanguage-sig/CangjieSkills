# sort_package_interfaces

The `sort_package_interfaces` directory serves as a comprehensive repository for documentation regarding deprecated sorting interfaces within the Cangjie programming language ecosystem. It specifically addresses legacy sorting mechanisms, focusing on the `SortExtension` and `SortByExtension` interfaces and their specific implementations for the `Array` type. The documentation covers essential technical concepts such as auxiliary sorting functionality, the implementation of custom comparators, and the nuances of sort stability. This resource is primarily designed for Cangjie developers who are responsible for maintaining legacy codebases or are currently in the process of migrating existing systems to modern sorting APIs. Users should note that these components are marked as obsolete and are scheduled for removal in future versions, making this documentation critical for understanding historical implementations during the transition period. It is highly recommended to cross-reference these documents with the latest API guides to ensure a smooth transition.
