# 基础类型定义

This directory provides fundamental type definitions and API references for implementing scrolling behaviors and edge effects within the Cangjie ArkUI framework. It covers configuration options for animations and fading edges, data structures for scroll results and geometry, enumerations for alignment and clipping, and callback types for event handling. Additionally, it includes documentation for the `Scroller` controller class. Designed for software developers using Cangjie, these resources are essential for building interactive, high-performance user interfaces with precise control over scroll mechanics and visual feedback.

## Detailed Description

### class_FadingEdgeOptions_3more.md class_FadingEdgeOptions_3more.md
This document serves as an API reference for configuration classes used in ArkUI scrolling and edge effects within the Cangjie programming language. It details three specific classes: FadingEdgeOptions for customizing fade length, ScrollEdgeOptions for setting scroll velocity, and ScrollToIndexOptions for defining extra offsets during index-based scrolling. Key takeaways include the specific properties for each class, such as fadingEdgeLength, velocity, and extraOffset, along with their default values and nullable types. Intended for ArkUI developers, this documentation helps fine-tune user interface interactions and visual effects in scrollable components.

### class_ScrollAnimationOptio_2more.md class_ScrollAnimationOptio_2more.md
This document serves as an API reference for configuring scroll behaviors within the Cangjie ArkUI framework. It details two primary classes: ScrollAnimationOptions and NestedScrollOptions. The ScrollAnimationOptions class allows customization of animation parameters including duration, curve, and overscroll capabilities. The NestedScrollOptions class defines scrolling behavior for parent-child hierarchies, specifically controlling forward and backward scroll modes. Key takeaways include the specific default values for animation properties and the requirement for scroll direction parameters in nested options. This technical documentation is intended for developers implementing custom scroll interactions in ArkUI applications, requiring knowledge of Cangjie syntax and UI components.

### class_ScrollResult_3more.md class_ScrollResult_3more.md
This document provides API reference documentation for three data classes used to handle scroll and geometry results in the Cangjie ArkUI framework. It details the ScrollResult class for remaining scroll values, OffsetResult for horizontal and vertical offsets, and RectResult for rectangular dimensions. Key information includes public properties of type Float64 (or nullable Float64 for RectResult) and specific constructors to initialize these values. All classes support read-write access and belong to SystemCapability.ArkUI.ArkUI.Full starting from version 22. This reference is intended for developers using the Cangjie language to implement or manage UI scrolling and layout behaviors.

### enum_ScrollAlign_2more.md enum_ScrollAlign_2more.md
This document serves as an API reference for two enumerations in the Cangjie language used within the ArkUI framework. It details the ScrollAlign enum, which defines list item alignment modes like Start, Center, End, and Auto, and the ContentClipMode enum, which specifies clipping strategies such as ContentOnly, Boundary, and SafeArea. Both enums inherit from Equatable and include standard equality and inequality operators, with all members available starting from version 22. Targeted at developers building user interfaces, this reference provides the necessary definitions for controlling layout alignment and content clipping behavior.

### type_OnWillScrollCallBack_5more.md type_OnWillScrollCallBack_5more.md
This API reference document defines five Cangjie function types used for handling various scroll event callbacks in a UI framework. The main sections cover type definitions for OnWillScrollCallBack, OnScrollCallBack, ScrollOnScrollCallback, OnScrollFrameBeginCallback, and OnScrollEdgeCallback. Key information includes the specific input parameters, such as Float64 offset, ScrollState, and ScrollSource, and return types like ScrollResult or Unit, which are essential for implementing scroll logic, edge detection, and frame control. This documentation targets software developers using the Cangjie language to build interactive scrolling interfaces.

### class_Scroller/
This directory contains API documentation for the `Scroller` class within the ArkUI framework, implemented using the Cangjie language. It covers the controller interface for scrollable container components, detailing methods for programmatic scrolling, state management, and animation control. Key topics include basic scrolling operations (scrollTo, scrollBy), edge navigation, inertial fling, index-based navigation, and state queries like current offset and item positioning. This documentation is intended for software developers building UI applications who need to implement or manipulate complex scrolling behaviors in their interfaces.
