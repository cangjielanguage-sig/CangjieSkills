### SM2.md SM2.md
This document serves as API reference documentation for the SM2 asymmetric encryption algorithm within the Cangjie framework. It details the specification for encryption and decryption based on the GM/T 0009-2012 standard, explaining the ciphertext components C1, C2, and C3. Key sections cover the string parameter format for defining key types and digest algorithms, such as "SM2_256|SM3". Additionally, it outlines features introduced in API version 12, including retrieving digest algorithm parameters and converting ciphertext to the ASN.1 C1C3C2 format. Developers using Cangjie for cryptographic operations are the primary audience, requiring knowledge of asymmetric encryption concepts.
