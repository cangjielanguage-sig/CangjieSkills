This directory contains documentation for the `Processor` class within the Cangjie programming language, specifically designed for the HiAppEvent system capability. It serves as a data handler for reporting application events, offering comprehensive configuration options for developers. Key topics include the class constructor, read-only properties, reporting triggers (such as batch thresholds and periodic timers), and filtering mechanisms for user IDs and event configurations. This documentation is intended for developers using API version 12 or higher who need to implement application event monitoring, data processing, and reporting behavior in their Cangjie-based applications.
