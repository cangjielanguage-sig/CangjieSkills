# HAR

This directory contains technical documentation for HAR (Harmony Archive), a static shared package format used in HarmonyOS development. It covers the creation, development, compilation, and usage of HAR packages for sharing Cangjie components, code, and resources across modules. Key topics include exporting interfaces, managing dependencies, resolving resource conflicts, and publishing libraries. This resource is suitable for HarmonyOS developers, particularly those using the Cangjie language, who need to modularize code, distribute SDKs, or integrate shared libraries into their applications.

## Detailed Description

### HAR_4more.md HAR_4more.md
This technical guide defines HAR (Harmony Archive), a static shared package designed for sharing Cangjie components, code, and resources across HarmonyOS modules and projects. The document outlines usage scenarios for internal and external SDK distribution via OHPM repositories, details creation methods using DevEco Studio, and lists critical constraints. Key takeaways include that HARs cannot run standalone, do not support transitive or circular dependencies, and automatically merge permissions during compilation. It also specifies requirements for binary HARs regarding SDK versions and packaging structures. This guide is intended for HarmonyOS developers seeking to modularize code or publish libraries.

### 开发.md 开发.md
This guide explains how to export Cangjie components, interfaces, and resources from a HAR package for reuse in other HarmonyOS applications or modules. It details exporting UI components, classes, and methods using the public modifier, alongside rules for resource management. Key information includes the fact that HARs are compiled into the host application and run under its identity, requiring specific API calls for version differentiation. The document also outlines resource conflict resolution priority, where AppScope overrides HAP modules, which in turn override dependent HARs based on dependency order. This technical guide targets HarmonyOS developers using the Cangjie language to create modular libraries.

### 编译_2more.md 编译_2more.md
This document serves as a brief guide on compiling and publishing HAR (Harmony Archive) files within the HarmonyOS development environment. It covers two main topics: Compilation and Publishing. The text explains that HAR files can function as second-party or third-party libraries for use by other applications, while the publishing section directs readers to a specific external Huawei developer guide for detailed instructions. The target audience includes HarmonyOS developers looking to modularize and share their code. Key concepts include HAR files, library types, and the publishing workflow.
