This directory serves as a comprehensive and specialized repository for the Cangjie language's benchmarking and unit testing framework, with a primary focus on performance evaluation and testing methodologies. It provides extensive documentation designed to guide developers through the intricacies of constructing precise performance tests using the `@Bench` macro. The scope of the content covers fundamental testing strategies, internal measurement algorithms, and advanced features such as parametric benchmarking and custom measurement sources. By addressing critical concepts including statistical analysis, overhead elimination, and compiler optimization, this resource is meticulously designed to equip Cangjie developers and performance engineers with the necessary tools to ensure code efficiency, validate performance improvements, and gain deep, granular insights into system behavior under various conditions. It acts as a definitive guide for anyone looking to master performance testing in the Cangjie ecosystem, ensuring that users can not only write tests but also interpret the complex data generated by them to make informed engineering decisions.
