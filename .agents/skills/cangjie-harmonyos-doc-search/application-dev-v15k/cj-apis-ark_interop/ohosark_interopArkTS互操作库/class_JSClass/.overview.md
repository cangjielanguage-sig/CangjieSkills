# class_JSClass

This directory provides comprehensive API reference documentation for the `JSClass` component within the Cangjie language, specifically designed to facilitate safe interoperability with ArkTS class constructors in the ArkUI framework. It covers the core class definition, inheritance from `JSHeapObject`, and methods for dynamic class manipulation such as adding accessors, methods, and properties. Additionally, the documentation details object instantiation using various argument types, including arrays. This resource is essential for developers working with the Napi subsystem (version 12+) who need to programmatically extend or instantiate ArkTS classes using Cangjie syntax, ensuring seamless integration between Cangjie and JavaScript environments.
