This directory provides a technical overview of the `@Watch` macro used for monitoring state variable changes within the ArkUI framework, specifically utilizing the Cangjie language. It serves as an essential guide for developers aiming to implement reactive programming patterns in their applications. The documentation covers core concepts including the macro's syntax, execution behavior, and specific constraints such as strict equality checks and synchronous execution triggers. It also highlights critical best practices, such as avoiding infinite loops and asynchronous operations within callbacks. This resource is intended for developers with a foundational knowledge of state management who wish to deepen their understanding of ArkUI's reactive mechanisms and build robust, interactive user interfaces.
