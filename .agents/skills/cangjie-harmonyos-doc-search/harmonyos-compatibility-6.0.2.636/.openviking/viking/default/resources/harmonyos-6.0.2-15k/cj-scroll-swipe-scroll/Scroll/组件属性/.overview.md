# 组件属性

This directory provides API reference documentation for configuring component properties within the Cangjie ArkUI framework. It focuses on the extensive customization of scrollable components, ranging from basic directional settings to complex physical interactions and visual adjustments. Core topics covered include setting scroll directions, managing edge effects, adjusting friction coefficients, and defining scrollbar properties such as color and width. Additionally, it addresses advanced behaviors like nested scrolling and initial offsets. These documents are essential for UI developers seeking to optimize user experience through precise control over component physics and layout. A solid understanding of ArkUI components and the Cangjie language is recommended for users of this documentation.

### func_scrollableScrollDirection.md func_scrollableScrollDirection.md
This document provides API reference documentation for the scrollable function in the ArkUI framework, designed to set the scrolling direction of a component. The main sections include the function signature, system capabilities, version compatibility, and a detailed parameter table. This technical reference is intended for developers using the Cangjie language to implement and customize scrolling behaviors in user interfaces.
