This directory provides a comprehensive overview and structural guide for the Cangjie programming language's standard library (std). It is designed to help developers understand the library's core characteristics—convenience, versatility, and quality—while offering practical guidance on package management and import syntax. The documentation clarifies the distinction between packages as compilation units and modules as publishing units, detailing various import methods such as importing specific items or using wildcards. Additionally, it serves as a gateway to a modular reference index covering diverse domains such as core APIs, file systems, networking, cryptography, and concurrency. This resource is essential for Cangjie developers looking to master library architecture, locate specific functional modules, or efficiently integrate standard library resources into their applications.
