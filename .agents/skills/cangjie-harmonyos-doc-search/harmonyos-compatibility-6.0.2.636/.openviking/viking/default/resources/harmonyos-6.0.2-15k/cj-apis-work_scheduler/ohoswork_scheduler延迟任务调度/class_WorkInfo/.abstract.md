This directory contains API reference documentation for the `WorkInfo` class in the Cangjie programming language, specifically designed for the Work Scheduler system. It covers the definition and configuration of delayed tasks, detailing properties like task identification, network requirements, battery status, and execution conditions. The documentation includes constructors for initializing task objects and variables for setting constraints such as deep idle states and persistence. Suitable for developers building background task management applications, these resources help configure precise triggers for work execution based on device status, starting from API version 12.
