# 使用foregroundBlurStyle为组件添加内容模糊效果

This directory provides comprehensive guidance on adding content blur effects to UI components using the `foregroundBlurStyle` attribute. It covers the implementation of various blur intensities, such as THIN, REGULAR, and THICK, alongside their background-specific variants to create modern frosted glass aesthetics. The documentation explains how to configure `ForegroundBlurStyleOptions` to adjust parameters like colorMode, adaptiveColor, and scale for precise visual control. This collection is ideal for HarmonyOS developers using either the Cangjie language or ArkUI (ArkTS) who are looking to implement sophisticated material design blur effects and improve the visual depth of their application interfaces.
