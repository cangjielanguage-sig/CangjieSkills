# 设置依赖关系

This directory focuses on establishing and managing dependency relationships within the ArkUI framework, specifically for RelativeContainer layouts. It covers essential concepts such as configuring reference boundaries, setting alignment positions relative to anchor points, and defining anchor points themselves. Key topics include horizontal and vertical alignment rules, dependency constraints, and cycle prevention to ensure layout stability. The documentation provides practical code examples in Cangjie and ArkTS. It is suitable for HarmonyOS developers and UI engineers seeking to create precise, responsive, and complex user interfaces by mastering relative positioning and component dependencies.

## Detailed Description

### 设置参考边界.md 设置参考边界.md
This technical reference document explains how to configure reference boundaries for aligning child components to anchor points within a container. The content covers alignment rules for both horizontal and vertical directions, detailing options for left, middle, right, top, center, and bottom boundaries. Key information includes specific behavioral constraints: when setting three boundaries simultaneously, the right boundary is ignored in horizontal alignment, and the bottom boundary is ignored in vertical alignment. This guide is intended for developers or UI designers utilizing this layout system who require precise control over component positioning and layout constraints. Keywords: reference boundaries, alignment, anchor point, horizontal, vertical, layout constraints.

### 设置相对于锚点的对齐位置_2more.md 设置相对于锚点的对齐位置_2more.md
This guide explains how to configure component alignment relative to anchor points within the ArkUI framework. It covers the alignRules property for setting horizontal and vertical alignment positions, such as Start, Center, and End, and discusses adjusting child component positions using offset or bias. The text clarifies that alignment positions are calculated before offset adjustments when a component serves as an anchor, and provides a Cangjie code example demonstrating a complex RelativeContainer layout. This technical guide is intended for UI developers using the Cangjie language who need to implement precise relative positioning in their applications.
