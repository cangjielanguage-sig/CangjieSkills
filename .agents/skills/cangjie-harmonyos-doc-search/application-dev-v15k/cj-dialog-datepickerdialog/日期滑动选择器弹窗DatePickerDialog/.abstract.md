This directory focuses on the `DatePickerDialog` component within the ArkUI framework, designed for creating sliding date selector popups in applications. It covers the API reference for the static show function, basic type definitions for configuration options (such as `DatePickerDialogOptions` and button styles), and practical Cangjie code examples. Key topics include lunar calendar integration, visual customization, and lifecycle management. This resource is suitable for HarmonyOS developers and UI architects using the Cangjie language who need to implement robust date selection interfaces compatible with API version 19 and above.
