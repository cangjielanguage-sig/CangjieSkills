This directory serves as a technical resource for developers working with the Cangjie ArkUI framework, specifically focusing on the event handling mechanisms of text input components. It provides in-depth API reference documentation that covers a wide spectrum of user interaction events. Key topics include monitoring content changes, handling clipboard operations (copy, cut, paste), and managing scrolling behaviors. Additionally, the documentation explores advanced features such as intercepting text modifications before they are committed to the UI, tracking cursor and selection states, and handling search submissions. The guides include detailed function signatures, parameter descriptions, and specific system capability requirements, noting support for API versions 12 and 19. This content is essential for developers aiming to create highly interactive and responsive user interfaces, offering the tools needed to implement precise event listeners and control the logic behind text editing and input validation.
