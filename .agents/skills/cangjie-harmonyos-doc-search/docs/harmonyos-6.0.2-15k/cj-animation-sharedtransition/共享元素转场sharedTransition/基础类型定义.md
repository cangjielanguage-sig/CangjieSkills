## 基础类型定义

### SharedTransitionOptions

```cangjie
public class SharedTransitionOptions {
    public SharedTransitionOptions(
        public var duration!: Int32 = 1000,
        public var curve!: Curve = Curve.Linear,
        public var delay!: Int32 = 0,
        public var motionPath!: MotionPathOptions = MotionPathOptions(),
        public var zIndex!: Int32 = 0,
        public var `type`!: SharedTransitionEffectType = SharedTransitionEffectType.SharedEffectExchange
    )
}
```

**功能：** 共享元素转场动画参数类型。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

#### SharedTransitionOptions(Int32, Curve, Int32, MotionPathOptions, Int32, SharedTransitionEffectType)

```cangjie
public SharedTransitionOptions(
    public var duration!: Int32 = 1000,
    public var curve!: Curve = Curve.Linear,
    public var delay!: Int32 = 0,
    public var motionPath!: MotionPathOptions = MotionPathOptions(),
    public var zIndex!: Int32 = 0,
    public var `type`!: SharedTransitionEffectType = SharedTransitionEffectType.SharedEffectExchange
   )
```

**功能：** 创建一个SharedTransitionOptions类型的对象。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|duration|Int32|否|1000| **命名参数。** 描述共享元素转场动效播放时长。<br/>单位：毫秒。<br/>取值范围：[0, +∞)。|
|curve|[Curve](./cj-common-types.md#enum-curve)|否|Curve.Linear | **命名参数。** 动画曲线。|
|delay|Int32|否|0| **命名参数。** 延迟播放时间。<br/>单位：毫秒。|
|motionPath|[MotionPathOptions](./cj-animation-motionpath.md#class-motionpathoptions)|是|-| **命名参数。** 运动路径信息。|
|zIndex|Int32|否|0| **命名参数。** 设置Z轴。<br>取值范围：(-∞, +∞)。|
|type|[SharedTransitionEffectType](./cj-common-types.md#enum-sharedtransitioneffecttype)|否|SharedTransitionEffectType.Exchange|动画类型。|
