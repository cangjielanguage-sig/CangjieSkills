# 类

This directory contains API reference documentation for synchronization and concurrency classes in the Cangjie programming language. It covers a wide range of tools for managing multi-threaded execution, including locks like Mutex and ReadWriteLock, coordination primitives like Barriers and Semaphores, and atomic operations for various data types. Additionally, it includes documentation for task scheduling via the Timer class. While some legacy classes are deprecated, the collection provides essential resources for developers implementing thread-safe, high-performance concurrent systems.

## Detailed Description

### class_Barrier.md class_Barrier.md
API reference for the Barrier class, coordinating multi-threaded execution by blocking threads until a specified count is reached. Details initialization, wait methods, timeout handling, and exceptions for invalid counts. Targets developers implementing concurrent systems requiring precise thread flow control.

### class_Monitor_supdeprecatedsup.md class_Monitor_supdeprecatedsup.md
Details the deprecated Monitor class for thread synchronization via shared variables. Covers signal-based blocking, wait/notify mechanisms, and recommends the Condition interface instead. Intended for developers understanding legacy synchronization mechanisms.

### class_Mutex.md class_Mutex.md
API reference for the Mutex class, implementing a reentrant mutual exclusion lock. Covers locking/unlocking, condition variable creation, and blocking behavior for managing critical sections. Essential for developers managing concurrent access to shared resources.

### class_ReadWriteLock.md class_ReadWriteLock.md
Documents the ReadWriteLock class for reentrant read-write synchronization. Explains write mutual exclusion, read concurrency, lock downgrading, and fairness modes for optimizing performance in multi-threaded applications.

### class_ReentrantMutex_supde_2more.md class_ReentrantMutex_supde_2more.md
Reference for deprecated ReentrantMutex and ReentrantReadMutex classes. Details locking mechanisms and recommends migrating to the Mutex class for future implementations.

### class_ReentrantReadWriteMutex_supdeprecatedsup.md class_ReentrantReadWriteMutex_supdeprecatedsup.md
API documentation for the deprecated ReentrantReadWriteMutex class. Covers reentrancy rules, fairness strategies, and advises migration to ReadWriteLock for advanced multi-threaded control.

### class_ReentrantWriteMut_babfcb58.md class_ReentrantWriteMut_babfcb58.md
