# ref_package_classes

This directory contains essential API reference documentation for the Cangjie programming language's `ref` package, specifically focusing on classes designed for advanced memory management. It provides detailed technical specifications for managing weak references, primarily centering on the `WeakRef` class and its sealed abstract parent, `WeakRefBase`. The documentation explains how developers can utilize these classes to allow the Garbage Collector to reclaim objects based on specific `CleanupPolicy` settings, even when those objects are technically reachable. This resource is highly suitable for systems programmers and developers working on performance-critical applications who require granular control over object lifecycles and memory reclamation strategies within the Cangjie runtime environment. Key topics include garbage collection, memory management, and API reference details.
