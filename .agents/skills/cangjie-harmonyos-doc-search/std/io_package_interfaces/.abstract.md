This directory serves as a comprehensive resource for the API reference documentation regarding input and output stream interfaces within the Cangjie programming language. It is designed to provide developers with the necessary definitions and specifications to handle data flow effectively in their applications. The content covers the fundamental abstractions required for stream manipulation, specifically focusing on reading, writing, and seeking operations. By defining core interfaces such as `InputStream`, `OutputStream`, `IOStream`, and `Seekable`, this directory outlines the essential contracts and method signatures for IO operations. It is highly suitable for software developers and system engineers who are either implementing custom IO backends or utilizing existing stream functionalities in Cangjie. A basic understanding of Cangjie syntax and data types is recommended to fully leverage these interfaces. This documentation is essential for ensuring compatibility and standard behavior across different IO implementations. Keywords: Cangjie, IO, Stream, Interface, API, Read, Write, Seek.
