# hilogtool

The `hilogtool` directory provides comprehensive documentation for a specialized utility used to parse and analyze HarmonyOS log files. It addresses the specific challenge of decoding encoded binary gz log files located in the device's `/data/log/hilog` directory, which are unreadable upon direct export. The documentation covers essential usage scenarios, tool acquisition from the HarmonyOS SDK, environment configuration for Windows and MacOS, and detailed command-line syntax. Additionally, it includes practical examples, automation scripts, and troubleshooting guides for common parsing errors. This resource is tailored for developers, system integrators, and testers who require offline debugging capabilities and need to convert binary log formats into readable plaintext for analysis.

## Detailed Description

### 使用场景.md 使用场景.md
This document serves as a usage guide explaining the specific scenario requiring the hilogtool for log analysis. It details that hilog logs are stored as encoded binary gz files in the device's `/data/log/hilog` directory, making them unreadable after direct export. Consequently, developers must use the hilogtool to parse these files into readable plaintext. The text also clarifies that this limitation applies only to exported hilog files, noting that kmsg logs and online hilog command outputs remain unaffected. This guide targets developers and system integrators who need to access and debug device logs offline.

### 使用指导.md 使用指导.md
This document serves as a usage guide for the hilogtool, a utility designed to parse HarmonyOS log files. It details the tool acquisition process from the HarmonyOS SDK and provides step-by-step instructions for configuring environment variables on both Windows and MacOS operating systems. The core section explains the command-line syntax, specifically the parse command, and lists essential parameters such as input paths, output directories, and the required data dictionary file. Key takeaways include the necessity of the data dictionary for successful parsing and version requirements for custom log filenames. This guide targets developers and technical users responsible for log analysis and debugging in the HarmonyOS environment.

### 常用解析命令示例_5more.md 常用解析命令示例_5more.md
This technical guide provides instructions and examples for using the hilogtool to parse binary hilog files into readable plaintext.
