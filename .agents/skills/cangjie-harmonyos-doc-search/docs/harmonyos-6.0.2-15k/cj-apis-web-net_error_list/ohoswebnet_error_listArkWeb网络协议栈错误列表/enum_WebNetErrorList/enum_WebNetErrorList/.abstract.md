This directory contains technical documentation for the `WebNetErrorList` enumeration, a standardized set of error codes designed for robust error handling in web networking contexts. It covers a wide range of network protocol stack failures, including general connectivity issues, SSL/TLS handshake errors, HTTP/2 and QUIC protocol specifics, caching mechanisms, and DNS resolution problems. The documentation is primarily intended for software developers and system engineers working with the WebNet framework or webview components who need precise error definitions for debugging and implementing resilient application logic. Keywords include API reference, enumeration, error codes, SSL/TLS, HTTP/2, and network debugging.
