This directory provides API documentation for the `ohos.ark_interop_advance` library, facilitating interoperability between the Cangjie programming language and ArkTS/TypeScript within the HarmonyOS ecosystem. It covers core functionalities such as runtime management, data type conversions (JSValue, JSString, JSArray), function calls, asynchronous operations (JSPromise), and module registration. Key components include JSRuntime, JSContext, and SharedObject for memory management. This resource is essential for Cangjie developers and system integrators building ArkUI applications who require robust, low-level bridging capabilities and efficient cross-language data handling using Napi.
