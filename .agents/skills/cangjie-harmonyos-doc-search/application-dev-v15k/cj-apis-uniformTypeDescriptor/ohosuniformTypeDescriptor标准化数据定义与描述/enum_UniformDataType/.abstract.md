This directory contains API reference documentation for the `UniformDataType` enumeration within the Cangjie programming language and the Unified Data Management Framework (UDMF). It defines standardized constants for classifying a wide array of data formats, including audio, video, images, text, archives, and OpenHarmony-specific system packages. The documentation details hierarchical relationships, parent categories, and version 19 introduction requirements. It is suitable for developers working on data interoperability, file handling, and distributed data management in the OpenHarmony ecosystem who need precise type identification logic.
