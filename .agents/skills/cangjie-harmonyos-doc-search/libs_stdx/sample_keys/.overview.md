# sample_keys

The `sample_keys` directory is a curated collection of code examples and tutorials designed specifically for developers working with the Cangjie programming language. It focuses on the critical aspects of cryptographic key implementation and management, utilizing the `stdx.crypto.keys` library. The directory covers a wide range of asymmetric encryption algorithms, including the industry-standard RSA and ECDSA, as well as the SM2 algorithm, which is a mandatory requirement for many Chinese cryptography standards. The content is structured to guide developers through the complete lifecycle of key management. This includes initial key generation, serialization into PEM format for storage and transport, and advanced cryptographic operations such as OAEP encryption, PKCS1 signing, and signature verification. This resource is ideal for Cangjie developers who are aiming to secure their applications with robust data protection mechanisms, ensure data integrity through verification, and maintain compliance with established cryptographic standards.

## Detailed Description

### keys_使用/

This directory serves as a comprehensive resource for developers working with the Cangjie programming language, specifically focusing on the implementation and management of cryptographic keys. It provides practical, code-based tutorials for handling asymmetric encryption algorithms, including the widely used RSA and ECDSA standards, as well as the SM2 algorithm commonly used in Chinese cryptography standards. The content covers the full lifecycle of key management, from generation and serialization (PEM format) to advanced operations like OAEP encryption, PKCS1 signing, and signature verification. These examples are essential for Cangjie developers aiming to secure their applications with robust data protection, integrity verification, and standard-compliant cryptographic practices using the `stdx.crypto.keys` library.

**Key Topics Covered:**
- **Supported Algorithms:** RSA, ECDSA, SM2.
- **Key Operations:** Generation, Serialization (PEM format).
- **Cryptographic Functions:** OAEP encryption, PKCS1 signing, Signature verification.
- **Target Library:** `stdx.crypto.keys`.
