This directory serves as the definitive technical guide for the `cj-universal-event-mouse` module, a key component of the Cangjie ArkUI framework. It is specifically curated for developers who need to incorporate mouse interaction capabilities into their application interfaces. The directory focuses on the `onMouse` function, which is essential for detecting and responding to user actions performed with a mouse, such as clicking or hovering over UI elements. The provided documentation offers a deep dive into the API, covering all necessary aspects including module imports, function signatures, and the detailed parameters of the `MouseEvent` callback. It also explains the return values that facilitate event handling logic. Furthermore, the directory provides critical context regarding the feature's current state, highlighting that it is in Beta, supports only external mice, and utilizes a default event pass-through mechanism. This resource is indispensable for developers targeting ArkUI version 22 or higher, ensuring they have the knowledge required to build interactive, mouse-responsive applications while navigating the framework's specific technical constraints.
