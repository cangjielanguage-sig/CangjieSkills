# ohoscrypto加解密算法库框架

This directory contains the API reference documentation for the `ohoscrypto` cryptographic framework, designed for the Cangjie programming language. It provides a comprehensive suite of tools for implementing security features, including symmetric and asymmetric encryption, digital signatures, key derivation, and message digests. The framework supports standard algorithms such as RSA, ECC, AES, SM2, and SHA, alongside key agreement protocols like Diffie-Hellman. It is intended for software developers and security engineers building secure applications on the HarmonyOS/OpenHarmony platform, offering detailed specifications for classes, interfaces, and utility functions within the `SystemCapability.Security.CryptoFramework`.

## Detailed Description

### class_AsyKeyGenerator/
This directory contains API reference documentation for the `AsyKeyGenerator` class, focusing on generating and converting asymmetric cryptographic keys (e.g., RSA, ECC256) in the Cangjie language. It covers creating random key pairs, converting binary data blobs, and importing keys from PEM strings.

### class_AsyKeyGeneratorBySpec/
This directory provides documentation for the `AsyKeyGeneratorBySpec` class, detailing how to generate asymmetric keys based on specific parameters. It includes methods for generating key pairs and extracting keys, with support for algorithms like DSA.

### class_Cipher/
This directory documents the `Cipher` class for encryption and decryption operations (symmetric and asymmetric). It covers initialization, segmented data processing (`update`), finalization (`doFinal`), and parameter management.

### class_ECCKeyUtil/
This directory provides documentation for the `ECCKeyUtil` class, handling Elliptic Curve Cryptography operations. It includes generating common parameter specifications and converting point data according to RFC5480.

### class_Mac/
This directory covers the `Mac` class for Message Authentication Code calculations. It details the lifecycle of MAC operations, including initialization, updates, and finalization.

### class_PriKey/
This directory documents the `PriKey` class for managing private keys used in asymmetric encryption, signing, and key agreement. It covers memory management, parameter retrieval, and encoding (DER/PEM).

### class_PubKey/
This directory provides API reference for the `PubKey` class, managing public keys for asymmetric operations. It details key retrieval, encoding formats (X.509, PKCS#1), and usage in verification and encryption.

### class_SM2CryptoUtil/
This directory documents the `SM2CryptoUtil` class for SM2 cryptographic operations, specifically handling ASN.1 formatted ciphertext generation and parameter extraction.

### class_Sign/
This directory covers the `Sign` class for digital signature operations. It details instantiation, initialization, parameter configuration, and data processing methods.

### class_Verify/
This directory provides documentation for the `Verify` class, focusing on digital signature verification workflows, including initialization, updates, and data recovery.

### enum_AsyKeySpecItem/
This directory serves as a repository for the `AsyKeySpecItem` enum, defining constants for key parameters across various asymmetric algorithms (ECC, RSA, DSA, etc.).
