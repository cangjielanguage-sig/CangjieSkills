# UTD预置列表

本目录提供了统一类型描述符（UTD）预置列表的完整技术规范，旨在通过标准化数据类型描述解决跨应用和跨设备传输时的类型模糊问题。内容涵盖UTD定义、基础类型、系统关联类型及应用定义类型，统一了MIME Type和文件扩展名等描述方式。该文档集目前处于Beta阶段，主要面向需要进行数据传输、类型适配及系统集成的开发人员，帮助降低适配难度并实现高效的数据交互。

### 系统关联类型.md 系统关联类型.md
本文档是一份技术参考文档，旨在定义和列举与特定操作系统深度关联的系统关联类型。文档核心内容为一个详细的类型列表，涵盖了OpenHarmony、MacOS、Android及Linux发行版等多种平台的预定义数据类型。关键信息包括各类文件的UTD-ID标识（如openharmony.hap、com.android.apk）、所属类型、文件后缀名及MIME类型，这些定义支持系统内的跨应用交互。该文档主要面向开发人员和系统集成工程师，用于理解系统如何识别和处理特定平台的数据格式。

### 基础类型/
本目录定义了系统中用于跨应用和跨平台数据交互的基础类型。内容涵盖基础类型定义、UTD-ID命名规范、各类文件格式（如图像、视频、音频、文档、代码等）的详细分类、文件扩展名及MIME类型映射。该文档集为开发人员和系统集成者提供了标准化的数据字典，用于文件识别、数据验证及内容管理系统的构建。

### 应用定义类型/
本目录包含应用定义类型的规范文档及各类文件格式的参考列表。内容涵盖应用定义类型的概念、UTD-ID标识符规范、数据交互机制，以及Microsoft Office、Adobe、OpenDocument、WPS、媒体格式等多种文件类型的详细映射定义。这些文档主要面向系统开发人员和架构师，用于理解自定义类型的注册机制，以及在系统中准确识别、配置和处理各类特定文件格式。
