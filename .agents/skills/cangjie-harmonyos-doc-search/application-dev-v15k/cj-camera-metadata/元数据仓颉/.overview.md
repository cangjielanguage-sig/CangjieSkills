# 元数据仓颉

This directory serves as a comprehensive technical resource for developers implementing camera metadata handling using the Cangjie programming language. It focuses on the integration of descriptive image data, specifically targeting face detection functionalities within camera applications. The content covers the complete development lifecycle, including the definition of metadata, the creation of output streams, and the management of capture sessions. Key technical elements include the use of TAG/Key pairs for memory optimization and specific API calls like `createMetadataOutput` and `Session.start`. Additionally, the directory addresses the critical need for status monitoring, detailing how to register callbacks for data availability and handle business exceptions. These guides are intended for camera application developers who already have a solid understanding of camera preparation and permission application, providing the necessary tools to build responsive and data-rich camera features.

## Detailed Description

### 元数据仓颉_2more.md 元数据仓颉_2more.md
This document is a development guide for implementing camera metadata handling using the Cangjie programming language. It covers the definition of metadata as descriptive image data and outlines a four-step development process: importing interfaces, creating metadata output streams, starting sessions to listen for data callbacks, and stopping output. Key information includes using TAG/Key pairs to reduce memory usage and specific API calls like createMetadataOutput and Session.start to retrieve data such as face detection coordinates. Intended for camera application developers, this guide requires prior knowledge of camera preparation and permission application.

### 状态监听.md 状态监听.md
This technical guide explains how to implement status monitoring for camera applications using the Cangjie language, focusing on metadata and output stream states. The document details two primary monitoring mechanisms: registering a callback for MetadataObjectsAvailable to retrieve face detection data, specifically rectangular coordinates, and setting up an error callback to handle BusinessException codes. Key takeaways include the limitation that metadata currently only supports face detection and the provided code examples for callback implementation. Intended for camera application developers, this guide serves as a reference for managing real-time data events and error handling within the camera framework.
