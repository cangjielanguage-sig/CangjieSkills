# class_X509Cert

This directory contains API reference documentation for the `X509Cert` class within the Cangjie programming language's DeviceCertificateKit. It includes syntax, parameters, return types, and error handling via `BusinessException`. This resource is suitable for developers implementing security capabilities, specifically those needing to integrate cryptographic certificate validation and data extraction into their Cangjie applications.
