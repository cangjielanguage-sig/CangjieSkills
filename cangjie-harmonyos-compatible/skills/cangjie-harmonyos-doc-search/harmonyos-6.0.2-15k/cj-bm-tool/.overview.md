# cj-bm-tool

The `cj-bm-tool` directory serves as a comprehensive technical repository dedicated to the Bundle Manager (bm) tool, a pivotal command-line utility within the HarmonyOS and OpenHarmony development environments. This directory provides extensive documentation covering the full lifecycle of application package management, including installation, uninstallation, updates, and information querying. It extends into complex technical territories such as dependency analysis, Ahead-Of-Time (AOT) compilation, and resource overlay management. Furthermore, the directory serves as a critical troubleshooting resource, offering detailed guides for resolving error codes. This documentation is specifically curated for developers, QA engineers, and system administrators who require reliable references for debugging, deploying, and maintaining applications through the hdc shell or DevEco Studio interfaces.

## Detailed Description

### bm工具/
This directory contains documentation for the Bundle Manager (bm) tool, a command-line utility essential for managing application packages in the HarmonyOS/OpenHar ecosystem. It covers core operations like installation, uninstallation, updates, and querying application information, as well as advanced features such as dependency analysis, AOT compilation, and resource overlay management. Additionally, it includes a comprehensive troubleshooting guide for error codes. This resource is suitable for developers, QA engineers, and system administrators who need to debug, deploy, or maintain applications using the hdc shell or DevEco Studio.
