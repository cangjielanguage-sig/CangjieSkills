This directory provides essential API reference documentation for the `MatchExpr` class and its associated functions within the Cangjie Abstract Syntax Tree (AST) package. It focuses on the structural definition and manipulation of pattern matching expressions, a critical component for language parsing and compilation. The content covers class initialization, mutable properties like keywords and delimiters, and methods for node conversion and tree traversal. Key topics include AST nodes, match cases, selectors, and visitor patterns. Additionally, it details error handling mechanisms such as ASTException for invalid token assignments. This documentation is specifically suitable for developers working on compiler construction, language processing tools, or anyone needing to programmatically analyze, transform, or generate Cangjie syntax trees. It provides the necessary API references to handle both selector-based and selector-less match expressions effectively.
