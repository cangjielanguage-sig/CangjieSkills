This directory serves as a comprehensive technical resource for the `cj-hiappevent-watcher-crash-events` module, specifically curated for HarmonyOS developers working with the Cangjie programming language. It provides an in-depth look at the data structures and attributes defining system crash events as exposed through the HiAppEvent interface. The documentation thoroughly covers the `params` object, detailing essential metadata such as crash types, process IDs, and bundle information, as well as complex nested structures for exceptions, signals, threads, and stack frames. Furthermore, it highlights critical operational constraints, including the distinction between CjError and NativeCrash types, the utilization of external log paths for forensic analysis, and the strict 5MB storage limit that requires manual log management to prevent system write failures. This guide is indispensable for software engineers and system architects focused on implementing robust crash monitoring and conducting precise post-mortem debugging to maintain high application stability.
