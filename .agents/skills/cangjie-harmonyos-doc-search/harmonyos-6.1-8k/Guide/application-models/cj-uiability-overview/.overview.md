# cj-uiability-overview

本目录专注于Cangjie编程语言中UIAbility组件的核心概念与实现指南。UIAbility是包含UI界面的应用组件，也是系统调度的基本单元。文档深入探讨了其设计理念、组件划分原则以及如何根据任务视图需求确定组件数量。内容详细覆盖了从module.json5声明配置到Cangjie代码注册的完整流程，并特别强调了UIAbility在跨端迁移与多端协同场景下的关键作用。通过掌握关键配置属性，开发者可以高效构建具备复杂交互能力的应用。本资料主要面向Cangjie应用开发者，旨在帮助其深入理解组件生命周期与配置细节，从而开发出支持多端协同的高质量应用。
