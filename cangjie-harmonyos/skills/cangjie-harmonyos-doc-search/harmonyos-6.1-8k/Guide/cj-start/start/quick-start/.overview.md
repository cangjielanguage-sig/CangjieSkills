# quick-start

This directory serves as a comprehensive entry point for developers looking to utilize the Cangjie programming language within the OpenHarmony ecosystem. It covers essential topics ranging from initial environment configuration and SDK setup to the creation of a first application. The content includes detailed guidance on the ArkUI framework, Stage application models, and interoperability with ArkTS. Designed for developers with basic configuration knowledge, these resources facilitate a smooth transition into building applications using Cangjie, highlighting both Beta features and standard development workflows. It is the ideal starting point for anyone aiming to master core development skills on this platform.

## Detailed Description

### README_zh
This directory contains the quick-start index documentation for the Cangjie language on the OpenHarmony platform, designed to guide developers in quickly getting started and mastering core development skills. The documentation primarily covers two core parts: development preparation and building the first OpenHarmony application, with these features currently being Beta. It details every step of environment setup and the full process of creating an application using the Cangjie language, ensuring developers can smoothly begin their work. This document is particularly suitable for developers who possess basic development configuration knowledge and wish to try application development using the Cangjie language on the OpenHarmony platform. Through this document, users can systematically understand the Cangjie language development environment configuration and basic application construction process.

### cj-quick-start-first-cangjie-app
This directory serves as a comprehensive quick-start guide designed for developers eager to explore the Cangjie programming language within the OpenHarmony ecosystem. It provides a structured pathway for creating a first application, covering essential development steps and configurations required to get started.

### cj-quick-start-preparations
This directory aims to provide a comprehensive preparation guide for beginners using the Cangjie language for OpenHarmony application development. The content deeply covers a comparison of the three development paradigms of the ArkUI framework, basic concepts of the Stage application model, and an explanation of interoperability between Cangjie and ArkTS. It highlights that the Cangjie declarative development paradigm is suitable for complex scenarios and explicitly notes that this paradigm only supports the Stage model (starting from API 22). Furthermore, it provides detailed configuration guidelines for the DevEco Studio integrated development environment and the Cangjie SDK. This material is very suitable for mobile system application developers who wish to quickly understand the project directory structure, understand the development process, and set up the environment. By reading this document, developers can effectively prepare for their development tasks.
