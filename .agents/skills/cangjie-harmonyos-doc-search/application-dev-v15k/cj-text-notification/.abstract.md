This directory serves as a comprehensive technical resource for developers utilizing the Cangjie language, specifically targeting the implementation of text-based notifications through the NotificationKit framework. The content provides an in-depth exploration of the `publish` interface, guiding users through the complexities of content classification, which encompasses both basic text and multiline text formats. It offers detailed, step-by-step development instructions that cover essential tasks such as module imports and the precise construction of `NotificationRequest` objects. Furthermore, the guide highlights critical constraints including mandatory fields for titles and text, a strict 200-byte size limit, and the specific architectural requirements for multiline notifications that support expanded views. This material is highly suitable for Cangjie developers who possess a solid understanding of object construction and API integration and are seeking to effectively deploy short message and prompt notifications in their applications. The scope is limited to text notifications, excluding rich media or interactive button types, ensuring a focused learning path for standard notification requirements.
