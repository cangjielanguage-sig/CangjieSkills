This directory serves as a comprehensive resource for API reference definitions regarding type aliases within the unittest package. It specifically focuses on the `MeasurementUnitTable`, a critical component designed to facilitate unit conversion for performance test results. By utilizing an array of Float64 and String pairs, this type alias enables the normalization of data through boundary-value pairs. This mechanism is essential for developers who need to automatically scale measurements—such as converting time from nanoseconds to seconds—based on specific thresholds. The documentation is tailored for developers and engineers involved in implementing or analyzing performance tests in the Cangjie programming language, providing them with the necessary tools for precise control over result formatting and unit scaling. It ensures that users can effectively manage and interpret performance metrics with high accuracy.
