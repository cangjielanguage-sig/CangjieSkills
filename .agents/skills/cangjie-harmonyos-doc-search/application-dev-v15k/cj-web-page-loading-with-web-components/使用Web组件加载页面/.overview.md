# 使用Web组件加载页面

This directory provides comprehensive technical guidance on utilizing the Web component to load and display various types of page content within HarmonyOS applications. It covers essential scenarios including loading network pages, rendering HTML text data, and displaying local HTML files. Key topics include configuring network permissions, using interfaces like `loadUrl` and `loadData`, managing local resource access via `rawfile` and sandbox paths, and understanding the nuances of state variables versus direct interface calls. This resource is designed for application developers using the Cangjie language and ArkUI framework who need to integrate web content into their apps.

## Detailed Description

### 使用Web组件加载页面_2more.md 使用Web组件加载页面_2more.md
This technical guide explains how to utilize the Web component to load various types of page content, specifically focusing on network pages. It covers prerequisites like configuring network permissions in module.json5 and details the process of loading network pages, including setting default URLs and dynamically changing them. A critical takeaway is that the src attribute cannot be updated via state variables; instead, developers must use the loadUrl() interface to navigate to new URLs. The document provides a Cangjie code example demonstrating this navigation logic. This guide targets application developers using the Cangjie language and ArkUI framework who need to integrate web content into their applications.

### 加载HTML格式的文本数据.md 加载HTML格式的文本数据.md
This technical guide explains how to load HTML text data within a Web component using the Cangjie language. It covers two primary approaches: utilizing the loadData() interface and employing the Data URL scheme. Key information includes that loadData() is ideal for displaying page fragments without full page loads, requiring parameters for HTML content, MIME type, and encoding. Alternatively, developers can embed HTML strings directly into the src attribute using the data:text/html prefix. Targeted at application developers working with ArkWeb components, this document provides code examples for rendering dynamic HTML content efficiently.

### 加载本地页面/
This directory serves as a technical guide for HarmonyOS developers aiming to load and display local HTML pages within their applications. It covers a range of implementation methods, focusing on the use of Web components in both Cangjie and ArkTS environments. Key topics include accessing resources from the `resources/rawfile` directory using `@rawfile` and `loadUrl`, as well as navigating application sandbox paths like `filesDir` via singleton contexts. The documentation also addresses essential configuration steps such as enabling `fileAccess` permissions, referencing local CSS stylesheets, and utilizing `WebviewController` for dynamic page manipulation. Furthermore, it provides insights into application lifecycle management, specifically the `onCreate` and `onWindowStageCreate` methods, and demonstrates how to use `GlobalContext` to bind paths for data synchronization between the Ability and UI layers. This resource is best suited for developers with a solid understanding of HarmonyOS architecture who need to implement robust local web content rendering.
