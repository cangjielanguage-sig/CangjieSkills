This directory contains API reference documentation for configuring UI component properties within the ArkUI framework using the Cangjie language. Developers will find detailed parameter definitions and usage guidelines for functions like `dataDetectorConfig`, `editMenuOptions`, and `customKeyboard`. This resource is suitable for developers building advanced text editing interfaces and interactive UI components in HarmonyOS applications who need precise control over user input and text handling behaviors.
