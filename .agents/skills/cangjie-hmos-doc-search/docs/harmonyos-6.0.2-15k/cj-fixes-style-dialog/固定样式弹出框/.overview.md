# 固定样式弹出框

This directory provides a comprehensive collection of technical guides and tutorials for implementing fixed-style popup components in the Cangjie programming language within the ArkUI framework. It covers various UI elements including list selection popups (ActionSheet), action menus, standard dialogs, alert dialogs, and picker dialogs for date selection. Key topics include component configuration, styling customization, animation effects, and event handling. These resources are designed for Cangjie developers looking to enhance user interaction in HarmonyOS applications through robust, predefined dialog interfaces.

## Detailed Description

### 列表选择弹窗ActionSheet.md 列表选择弹窗ActionSheet.md
This document serves as a tutorial demonstrating how to implement and customize a list selection popup (ActionSheet) in the Cangjie programming language. It covers the component's definition, the ActionSheet.show interface, and configuration parameters for styling and behavior. Key takeaways include the code structure for defining list items via SheetInfo, setting confirmation buttons, and applying advanced visual styles such as corner radius, borders, and asymmetric transition animations. Intended for developers using the ArkUI framework, this guide assumes familiarity with Cangjie syntax and basic UI component lifecycle management.

### 固定样式弹出框_4more.md 固定样式弹出框_4more.md
This document provides a technical guide for implementing fixed-style popup boxes in the Cangjie development environment, designed to simplify UI creation by using predefined layouts. It covers usage constraints, specifically the requirement to obtain a PromptAction object before calling methods. The main sections detail the implementation of Action Menus (showActionMenu) and Dialogs (showDialog), both of which asynchronously return the index of the selected button. Key takeaways include the ability to set isModal to false for non-modal behavior. Targeted at Cangjie developers, the guide includes code examples demonstrating how to configure titles, messages, and button callbacks.

### 警告弹窗AlertDialog.md 警告弹窗AlertDialog.md
This document provides a guide on implementing AlertDialogs in Cangjie to prompt users for critical decisions or permissions. It covers usage guidelines, the `show` interface, and a code example demonstrating button configuration and transition effects. Key takeaways include avoiding non-actionable alerts and using `AlertDialogParamWithButtons` to customize styles, animations, and button actions like 'cancel' and 'ok'. Targeted at Cangjie developers needing to add interactive dialog components to their applications.

### 选择器弹窗PickerDialog/
This directory serves as a comprehensive resource for implementing PickerDialog components using the Cangjie development framework in HarmonyOS applications. It specifically addresses the creation of interactive date selection popups, covering essential features such as defining date ranges, enabling lunar calendar toggles, and customizing text styles. Additionally, it explores advanced topics like dialog lifecycle management, event handling, and UI customization for buttons. These guides are intended for Cangjie developers seeking to enhance user experience through robust, interactive selection interfaces. The included code examples demonstrate practical integration of these components into real-world applications.
