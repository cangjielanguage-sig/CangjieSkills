# basic_data_type

This directory provides a comprehensive guide to the fundamental data types in the Cangjie programming language. It covers essential building blocks such as numeric types (integers, floats), text processing (strings, characters), and logical structures (booleans, arrays, tuples). Additionally, it documents special types like Unit, Nothing, and Range, which are crucial for control flow and type safety. This resource is designed for developers ranging from beginners learning the basics to advanced users needing a quick reference on type definitions, operators, and conversion rules within the Cangjie ecosystem.
