This directory contains essential API reference documentation for the Cangjie `TypeDescriptor` class, a fundamental component used within the UDMF (Unified Data Management Framework). It is dedicated to the description of standardized data types and the management of their hierarchical relationships. The documentation covers critical aspects such as querying type metadata, validating type inheritance logic, and understanding system capability requirements. Key topics include read-only properties like typeId and mimeTypes, alongside methods for type comparison. This resource is specifically tailored for developers and engineers working with the Distributed Data Manager who need to ensure data consistency, validate type structures, and implement robust data handling logic in their applications.
