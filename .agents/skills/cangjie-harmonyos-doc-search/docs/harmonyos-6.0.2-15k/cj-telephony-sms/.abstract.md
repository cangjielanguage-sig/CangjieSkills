This directory serves as a comprehensive technical hub for the `cj-telephony-sms` module, specifically designed to facilitate the integration and management of SMS (Short Message Service) functionalities within the HarmonyOS operating system. It acts as a vital guide for developers aiming to embed sophisticated communication capabilities into their software, spanning both native mobile applications and web-based interfaces. The documentation delves into the technical intricacies of SMS, covering essential protocols, data encoding variations such as 7-bit, 8-bit, and UCS-2, and the system constraints that govern message transmission. Beyond basic messaging, it provides in-depth instructions on invoking the native SMS editing interface via URI schemes and the `startAbility` method. It also addresses advanced technical requirements, including PDU (Protocol Data Unit) handling, SIM slot management for dual-SIM devices, and the specific permissions needed to access telephony features securely. This resource is indispensable for developers who need to ensure their apps comply with system standards while delivering reliable and seamless user communication experiences.
