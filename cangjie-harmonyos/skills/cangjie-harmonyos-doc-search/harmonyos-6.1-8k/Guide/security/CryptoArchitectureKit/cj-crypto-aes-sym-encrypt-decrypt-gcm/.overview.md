This directory provides a comprehensive technical overview and implementation guide for AES symmetric encryption and decryption using the GCM (Galois/Counter Mode) standard, specifically designed for the Cangjie programming language. The content encompasses the full spectrum of the encryption workflow, starting from the secure generation of symmetric keys and the initialization of Cipher instances, through to the complex processes of data encryption and decryption. Special emphasis is placed on the unique features of GCM mode, including the management of authentication tags (authTag) to ensure data integrity and the implementation of data segmentation techniques for handling large files efficiently. This directory is highly suitable for software engineers and security-focused developers looking to secure data transmission and storage within the Cangjie ecosystem.

## Detailed Description

### 使用AES对称密钥GCM模式加解密/

This subdirectory acts as a specialized technical guide for developers working with the Cangjie language, focusing specifically on the implementation of AES symmetric encryption and decryption within the GCM (Galois/Counter Mode) architecture. The content provided herein is structured to assist developers in mastering the CryptoArchitectureKit, offering a blend of theoretical documentation and executable code examples.

The primary focus is on the end-to-end cryptographic workflow. It begins with the foundational steps of key generation, ensuring that developers understand how to create secure symmetric keys required for the encryption process. Following this, the guide details the instantiation of Cipher objects, which are the primary tools for performing the actual cryptographic transformations.

A significant portion of the documentation is dedicated to the intricacies of the GCM mode. Unlike standard encryption modes, GCM provides authenticated encryption, and this guide emphasizes the correct handling of the `authTag`. This component is vital for ensuring that the encrypted data has not been tampered with, providing both confidentiality and integrity.

Additionally, the subdirectory addresses practical engineering challenges, such as the encryption of large datasets. It introduces concepts of data segmentation, allowing for the efficient processing of files that are too large to fit into memory or to be encrypted in a single block. By covering these advanced topics, the directory serves as an essential resource for developers building systems that demand high security and performance for data transmission and storage.
