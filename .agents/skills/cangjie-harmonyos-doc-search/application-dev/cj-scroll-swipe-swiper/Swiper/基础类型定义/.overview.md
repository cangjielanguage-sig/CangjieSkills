# 基础类型定义

This directory contains API reference documentation for fundamental classes used in the ArkUI framework with the Cangjie language, specifically focusing on Swiper component navigation and control. It covers the definition and styling of indicators (dots and digits) and the controller logic for managing Swiper behavior. Key concepts include `DigitIndicator`, `DotIndicator`, `Indicator`, and `SwiperController`. This documentation is suitable for UI developers and system architects using the Cangjie language to build interactive user interfaces with precise control over carousel navigation and animation.

## Detailed Description

### class_DigitIndicator.md class_DigitIndicator.md
This API reference document details the DigitIndicator class, which defines the styling for digital navigation points within Swiper components in the ArkUI framework. The documentation covers the class constructor and configuration methods for font styles and colors, specifically distinguishing between normal and selected states. Key information includes the class inheritance from Indicator and the ability to customize digit fonts and colors using Font and ResourceColor types. It also notes that displayed child nodes exclude placeholders during group paging. This guide targets developers using the Cangjie language to build user interfaces, requiring prior knowledge of ArkUI components and styling properties.

### class_SwiperController.md class_SwiperController.md
This document provides API reference documentation for the SwiperController class in the Cangjie language, which acts as a controller for Swiper container components. It covers the class initialization and essential methods for manipulating component behavior, specifically finishing animations with optional callbacks and navigating to the next or previous page. Key takeaways include the ability to programmatically control page transitions with animation effects tied to the Swiper's duration property. Intended for ArkUI developers, this guide requires knowledge of the ArkUI framework and is applicable from system version 22.

### class_DotIndicator/
This directory provides detailed API reference documentation for the `DotIndicator` class, specifically designed for the Cangjie language and ArkUI framework. It serves as a technical guide for configuring dot navigation indicators within Swiper components, covering essential aspects such as layout, styling, and interaction behaviors. The content includes instructions on setting dot dimensions, colors, and masks, as well as managing overflow scenarios where dot counts exceed the maximum display capacity. Furthermore, it offers specific methods for customizing the appearance of the selected indicator. This documentation is highly suitable for UI developers and system architects aiming to create polished, interactive navigation elements in their ArkUI-based applications, ensuring a seamless user experience for content sliders and galleries.

### class_Indicator/
This directory contains comprehensive API reference documentation for the Cangjie Indicator class within the ArkUI framework. It focuses on the configuration and management of navigation points for the Swiper component. The content covers essential topics such as static factory methods for creating various indicator types (DigitIndicator, DotIndicator), instance methods for positioning (bottom, left, right, end), and specific functions for layout control (start, top). Key concepts include adaptive layout behaviors, interaction height defaults, and priority rules for positioning attributes. This documentation is specifically suitable for ArkUI developers using the Cangjie language who need to implement and customize carousel indicator layouts with precise control over placement and behavior. By referencing these files, developers can effectively manage the visual presentation and interaction logic of navigation indicators in their applications.
