# cj-sensorservice-kit-intro

本目录包含 Sensor Service Kit 的开发指南介绍，旨在为应用开发者提供关于传感器数据获取及振感控制的全面指导。文档详细阐述了 Sensor 和 Vibrator 两大核心模块的使用场景、功能特性及约束限制。内容涵盖如何通过传感器数据订阅开发各类应用，以及利用振动模块提升用户交互体验。此外，还重点说明了相关的硬件依赖、权限配置要求以及传感器接口成对调用的规范。该文档适用于所有需要集成硬件传感器或振动功能的开发场景，是入门 Sensor Service Kit 的必读资料。
