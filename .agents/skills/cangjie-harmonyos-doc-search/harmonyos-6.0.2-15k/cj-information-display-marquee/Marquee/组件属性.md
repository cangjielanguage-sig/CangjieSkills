## 组件属性

### func allowScale(Bool)

```cangjie
public func allowScale(value: Bool): This
```

**功能：** 设置是否允许文本缩放。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|value|Bool|是|-|是否允许文本缩放。<br>初始值：false。<br>**说明:**<br>仅当fontSize为fp为单位时生效。|

### func marqueeUpdateStrategy(MarqueeUpdateStrategy)

```cangjie
public func marqueeUpdateStrategy(content: MarqueeUpdateStrategy): This
```

**功能：** 跑马灯组件属性更新后，跑马灯的滚动策略。

> **说明：**
>
> 当跑马灯为播放状态，且文本内容宽度超过跑马灯组件宽度时，该属性生效。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 19

**参数：**

|参数名|类型|必填|默认值|说明|
|:---|:---|:---|:---|:---|
|content|[MarqueeUpdateStrategy](./cj-common-types.md#enum-marqueeupdatestrategy)|是|-|跑马灯组件属性更新后，跑马灯的滚动策略。<br>初始值：MarqueeUpdateStrategy.DEFAULT。|
