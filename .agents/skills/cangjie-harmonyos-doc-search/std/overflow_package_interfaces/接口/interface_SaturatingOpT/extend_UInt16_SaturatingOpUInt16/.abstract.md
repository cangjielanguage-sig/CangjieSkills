This directory contains comprehensive API documentation for extending the `UInt16` type with saturating operations within the Cangjie programming language. It focuses on the implementation of the `SaturatingOp` interface, which provides a robust suite of safe arithmetic and bitwise functions. Key topics include addition, subtraction, multiplication, division, modulo, negation, increment, decrement, and bit shifting. The core functionality relies on a saturation strategy that clamps results to the type's maximum or minimum values to prevent wrap-around errors during overflow or underflow. This resource is essential for Cangjie developers who require precise, boundary-checked mathematical operations on 16-bit unsigned integers to ensure system stability and data integrity in performance-critical or safety-critical applications.
