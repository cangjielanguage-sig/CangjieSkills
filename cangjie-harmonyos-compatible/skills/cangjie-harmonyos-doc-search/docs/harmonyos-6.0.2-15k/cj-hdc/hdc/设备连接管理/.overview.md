# 设备连接管理

This directory serves as a comprehensive technical resource for managing device connections within the HarmonyOS development ecosystem. It focuses extensively on the HarmonyOS Device Connector (hdc) tool, providing essential references for establishing and maintaining communication channels between hosts and devices. The documentation covers critical operations such as switching between USB and wireless debugging modes, querying device lists, and managing commands in multi-device environments. Furthermore, it addresses common connectivity scenarios, including local USB, TCP, and remote debugging across different networks. This content is specifically designed for developers and testers who possess command-line interface knowledge and need to configure, monitor, or troubleshoot device connections efficiently.

## Detailed Description

### usb调试和无线调试切换.md usb调试和无线调试切换.md
This technical reference guide documents commands for switching between USB and wireless debugging modes using the hdc tool. It details the `tmode` command for managing network channels and the `tconn` command for establishing TCP connections. Key takeaways include the deprecation of `tmode usb`, the requirement for devices and PCs to be on the same network, and the critical warning that switching modes restarts the device daemon and interrupts existing connections. Targeted at developers and testers, this guide requires knowledge of command-line interfaces and network debugging.

### 查询设备列表_3more.md 查询设备列表_3more.md
This reference guide explains how to manage connected devices using the HarmonyOS Device Connector (hdc) tool. It covers querying device lists, targeting specific devices in multi-device environments, and waiting for device connections. Key commands include `hdc list targets [-v]` to view identifiers and `hdc -t [connect-key] [command]` to execute commands on specific devices. The `connect-key` is defined as a unique serial number or IP:port. The document details return values and potential error messages. This technical documentation is intended for developers or testers managing HarmonyOS devices who need to handle single or multiple device connections via command line.
