# cj-crypto-convert-string-data-to-asym-key-pair

This directory contains a specialized technical guide designed for Cangjie developers who need to handle cryptographic keys programmatically. It focuses on the critical task of converting PEM-formatted string data—often retrieved from configuration files or network transmissions—into functional asymmetric key pairs using the Cangjie programming language. The guide specifically targets RSA keys and provides detailed insights into the supported specifications for public keys (X.509, PKCS#1) and private keys (PKCS#8, PKCS#1). By leveraging the CryptoArchitectureKit, developers will learn how to manipulate key data structures effectively. This resource is suitable for backend engineers, security-focused developers, and anyone working on secure data exchange or authentication systems within the Cangjie environment who requires a deep understanding of key parsing and format conversion. It simplifies the complex process of handling raw string data, ensuring that developers can securely integrate cryptographic keys into their software architecture.

### cj-crypto-convert-string-data-to-asym-key-pair.md cj-crypto-convert-string-data-to-asym-key-pair.md

This technical guide provides an in-depth explanation of how to convert PEM-formatted string data into asymmetric key pairs using the Cangjie programming language, with a primary focus on RSA keys. The document begins by clearly defining the supported specifications, helping developers distinguish between the appropriate formats for public keys (X.509, PKCS#1) and private keys (PKCS#8, PKCS#1).

The main section of the guide breaks down the technical workflow into a step-by-step process. It details how to properly create an `AsyKeyGenerator` instance, which serves as the foundation for key operations. It then explains the use of the `convertPemKey` function, which is essential for parsing string data and generating a usable `KeyPair` object. Additionally, the guide covers the `getEncodedPem` method, which facilitates the conversion of key objects back into different PEM string formats.

To ensure practical applicability, the document includes a comprehensive code example. This example demonstrates a real-world scenario where PKCS1 strings are converted into PKCS8 and X509 formats. This guide is an essential resource for Cangjie developers utilizing the CryptoArchitectureKit, providing the knowledge required to implement secure and flexible cryptographic key management in their applications. By following these instructions, developers can ensure their applications handle sensitive key material correctly and efficiently.
