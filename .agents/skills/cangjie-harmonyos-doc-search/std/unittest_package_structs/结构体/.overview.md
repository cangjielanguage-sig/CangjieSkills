# 结构体

This directory contains API documentation for various Cangjie language structs used primarily within the unittest and benchmarking frameworks. It covers input providers for performance testing, measurement mechanisms (CPU cycles, time, perf counters), and type-safe configuration keys for test execution settings. Key components include structs for managing test data, handling coverage-guided parameters, and configuring output and timeouts. This documentation is suitable for Cangjie developers who need to implement custom benchmarks, configure test environments, or understand the underlying structures of the testing framework.

## Detailed Description

### struct_BatchInputProviderT_2more.md struct_BatchInputProviderT_2more.md
This file defines `BatchInputProvider` and `BatchSizeOneInputProvider`, which serve as input providers for benchmarking tests. Both structs inherit from `BenchInputProvider` and offer constructors and methods like `get` and `reset`. `BatchInputProvider` pre-generates inputs in a buffer, while `BatchSizeOneInputProvider` generates inputs per execution to handle unstable generation times. Crucially, the execution time of the `get` function is excluded from benchmark measurements.

### struct_CpuCycles_2more.md struct_CpuCycles_2more.md
This documentation details `CpuCycles` for performance measurement and `GenerateEachInputProvider` for benchmark data generation. `CpuCycles` implements the `Measurement` interface to count CPU cycles on x86 platforms using the `rdtscp` instruction. `GenerateEachInputProvider` creates fresh inputs for each run. Input generation time is included in measurements but subtracted as framework overhead.

### struct_ImmutableInputProvi_4more.md struct_ImmutableInputProvi_4more.md
This document covers the `ImmutableInputProvider` struct, the default mechanism for supplying immutable data to benchmarks by copying input for every call. It also documents configuration key structs—`KeyBaseline`, `KeyBaselinePath`, and `KeyBatchSize`—used to define and retrieve settings within a `Configuration` object.

### struct_KeyBench_5more.md struct_KeyBench_5more.md
This reference defines five Cangjie structs used as type-safe keys for configuration settings: `KeyBench`, `KeyCaptureOutput`, `KeyCoverageGuided`, `KeyCoverageGuidedBaselineScore`, and `KeyCoverageGuidedInitialSeeds`. All inherit from `KeyFor` and map to types like `Bool` or `Int64`, facilitating the setup of benchmarking and coverage-guided testing parameters.

### struct_KeyCoverageGuidedMa_5more.md struct_KeyCoverageGuidedMa_5more.md
This file provides API reference for five structs used as configuration keys for coverage-guided testing parameters, including `MaxCandidates`, `NewCoverageBonus`, `NewCoverageScore`, and execution modes like `DeathAware` and `DryRun`. Each struct inherits from `KeyFor` and includes a static property for accessing the key instance.

### struct_KeyExcludeTags_6more.md struct_KeyExcludeTags_6more.md
This document details six structs used as configuration keys: `KeyExcludeTags`, `KeyExplicitGC`, `KeyFilter`, `KeyFromTopLevel`, `KeyGenerationSteps`, and `KeyHelp`. Inheriting from `KeyFor`, these function as keys for the `Configuration` class to manage settings like test filtering, garbage collection, and help display.

### struct_KeyIncludeTags_6more.md struct_KeyIncludeTags_6more.md
This document defines six structs used as type-safe keys for accessing configuration options: `KeyIncludeTags`, `KeyInternalTestrunnerInputPath`, `KeyMeasurement`, `KeyMeasurementInfo`, `KeyMinBatches`, and `KeyMinDuration`. These inherit from `KeyFor` and are utilized to manage settings like tags, input paths, and duration limits.

### struct_KeyNoCaptureOutput_6more.md struct_KeyNoCaptureOutput_6more.md
This reference defines six structs for configuring unit test settings: `KeyNoCaptureOutput`, `KeyNoColor`, `KeyOptimizeMocksForBench`, `KeyParallel`, `KeyRandomSeed`, and `KeyReductionSteps`. All inherit from `KeyFor` to function within the `Configuration` class, providing static properties for key instances.

### struct_KeyReportFormat_6more.md struct_KeyReportFormat_6more.md
This documentation details six structs used as type-safe keys within the `Configuration` system: `KeyReportFormat`, `KeyReportPath`, `KeyShowAllOutput`, `KeyShowTags`, `KeySkip`, and `KeyTimeout`. These allow developers to access settings like report paths, output visibility, and test timeouts.

### struct_KeyTimeoutEach_5more.md struct_KeyTimeoutEach_5more.md
This file details five structs: `KeyTimeoutEach`, `KeyTimeoutHandler`, `KeyVerbose`, `KeyWarmup`, and `MeasurementInfo`. The first four act as type-safe keys for the `Configuration` class to set parameters like timeouts and verbosity. `MeasurementInfo` defines how performance metrics are displayed and converted in reports.

### struct_Perf_3more.md struct_Perf_3more.md
This document details three structures: `Perf`, `RelativeDelta`, and `TestCaseInfo`. `Perf` enables hardware and software CPU counter measurement on Linux using `perf_event_open`. `RelativeDelta` provides approximate floating-point equality checks, and `TestCaseInfo` encapsulates metadata for the currently executing test.

### struct_TimeNow.md struct_TimeNow.md
This documentation defines the `TimeNow` struct, which implements the `Measurement` interface to measure function execution duration. It details constructors for time units, properties for conversion, and the core `measure` function, supporting various units from nanoseconds to seconds for statistical analysis.
