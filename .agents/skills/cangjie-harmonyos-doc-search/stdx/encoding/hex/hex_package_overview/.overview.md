# hex_package_overview

本目录包含 `stdx.encoding.hex` 包的概览文档，专注于字符串的 Hex（十六进制）编码与解码技术。文档详细阐述了 Hex 编码的标准定义（即使用 0-9 和 A-F 字符表示二进制数据）及其底层工作原理。内容涵盖了核心 API 接口的列表与说明，特别强调了 `fromHexString`（解码）和 `toHexString`（编码）这两个关键函数的使用方法。该资源主要面向需要在应用程序中处理数据序列化、网络传输或调试信息的开发者，是一份实用的 API 参考指南。

## Detailed Description

### hex_package_overview.md
本文档概述了 `stdx.encoding.hex` 包，旨在介绍其提供的字符串 Hex 编码及解码功能。主要包含功能介绍部分，解释了 Hex 编码的定义及原理，以及 API 列表部分，列出了核心函数接口。关键信息包括 Hex 编码使用 0-9 和 A-F 字符表示数据的定义。文档重点介绍了两个核心函数：用于解码的 `fromHexString` 和用于将字节数组转换为 Hex 字符串的 `toHexString`。该文档属于 API 参考文档，面向需要在应用程序中进行 Hex 数据转换的开发者。
