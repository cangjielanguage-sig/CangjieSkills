This directory contains comprehensive API reference documentation for the `ohos.file_fs` module in the Cangjie programming language, designed for HarmonyOS and OpenHarmony development. It covers a wide range of file management capabilities, including file I/O operations, directory manipulation, file system monitoring, and metadata access. Key components include classes for file handling, stream management, and random access, alongside structs for configuration and error handling. This documentation is intended for Cangjie developers and system engineers who need to implement robust file storage, data transfer, and resource management features within their applications, utilizing the SystemCapability.FileManagement.File.FileIO capability.
