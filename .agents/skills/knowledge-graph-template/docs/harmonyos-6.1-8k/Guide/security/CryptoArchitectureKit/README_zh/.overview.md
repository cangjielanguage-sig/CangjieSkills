# README_zh

本目录是Crypto Architecture Kit（加解密算法框架服务）的中文导航索引，旨在为开发者提供全面的加密服务文档入口。它详细涵盖了密钥生成与转换、多种加解密算法（包括AES、3DES、SM4等模式及分段处理）、消息摘要（如SHA256、MD5）、消息认证码（MAC）以及安全随机数生成等核心功能。所有功能目前均处于Beta阶段，文档结构清晰，包含功能介绍、规格说明及具体的开发指导。该目录非常适合需要集成加解密算法和安全功能的开发人员，作为查阅API文档和开发教程的权威目录指南。
