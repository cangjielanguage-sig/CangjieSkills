This directory provides a specialized development guide for the Unified User Authentication Framework, specifically addressing the implementation of a mechanism to switch from system biometric authentication to custom business authentication. It comprehensively covers the necessary switching logic, a detailed compatibility table for supported authentication types, and a practical Cangjie code example. The guide details the configuration of `WidgetParam` with `navigationButtonText` to display a navigation button. It explains how to handle the result code `12500011` to launch custom interfaces. This resource is suitable for application developers using the Cangjie language who need to implement fallback authentication flows, such as switching to a payment password after biometric failure. It ensures developers can create seamless user experiences when primary authentication methods are unavailable.
