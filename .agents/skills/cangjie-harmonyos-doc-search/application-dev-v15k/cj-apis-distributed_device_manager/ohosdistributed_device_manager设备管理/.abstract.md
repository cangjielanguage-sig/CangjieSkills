This directory provides API reference documentation for the `ohos.distributed_device_manager` module, specifically designed for the Cangjie programming language within HarmonyOS distributed hardware scenarios. It encompasses the essential components required to manage distributed devices, including the main `DeviceManager` class, data structures for device information, and enumerations for tracking device states and event types. Key functionalities covered include device discovery, authentication, status monitoring, and information retrieval. This documentation is suitable for application developers building distributed features who need to implement device connectivity, query device states, and manage hardware interactions across a network using SystemCapability.DistributedHardware.DeviceManager starting from version 19.
