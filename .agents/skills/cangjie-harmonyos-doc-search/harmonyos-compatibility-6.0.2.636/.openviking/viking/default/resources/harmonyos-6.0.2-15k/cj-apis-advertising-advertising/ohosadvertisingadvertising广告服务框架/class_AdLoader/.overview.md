# class_AdLoader

This directory contains essential API reference documentation for the `AdLoader` class, a core component of the Cangjie AdsKit framework designed to facilitate seamless ad loading in HarmonyOS applications. It serves as a comprehensive guide for software developers and engineers aiming to implement robust advertising capabilities using the Cangjie programming language. The content covers the complete lifecycle of ad requests, ranging from the initialization of the class using `StageContext` to the execution of ad loading functions. It details both single ad loading and advanced multi-slot loading scenarios, providing developers with the flexibility to manage various ad strategies. Key technical topics include the configuration of `AdRequestParams` and `AdOptions`, the setup of listeners for handling ad load events, and the management of errors through `BusinessException`. Furthermore, the documentation includes practical Cangjie code examples to assist with implementation. This directory is suitable for developers who possess a prerequisite understanding of Cangjie syntax and application context management and are looking to effectively monetize their applications within the HarmonyOS ecosystem.
