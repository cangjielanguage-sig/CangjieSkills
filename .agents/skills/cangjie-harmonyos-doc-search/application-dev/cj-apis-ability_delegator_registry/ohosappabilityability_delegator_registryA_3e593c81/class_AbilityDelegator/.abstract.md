This directory contains API reference documentation for the `AbilityDelegator` class in the Cangjie language, specifically designed for HarmonyOS application development. It focuses on managing and monitoring the lifecycle states of UIAbility and AbilityStage components. The documentation covers essential methods for adding and removing monitors, triggering lifecycle transitions, executing shell commands, and handling test synchronization. Key topics include automated testing, runtime observation, and error handling. This resource is suitable for application developers and QA engineers utilizing the HarmonyOS AbilityKit and TestKit frameworks to implement robust testing scenarios and control application behavior during runtime.
