# User-Agent开发指导

This directory provides comprehensive guidance on User-Agent (UA) string management within the OpenHarmony and HarmonyOS ecosystems. It covers the default UA structure, field definitions like DeviceType and OSName, and methods for customizing UA strings in the ArkWeb component. Additionally, it addresses common questions regarding device identification and debugging simulation using JavaScript. This documentation is suitable for web developers, system integrators, and frontend developers aiming to ensure proper web content rendering, accurate device detection, and cross-platform compatibility for applications built on OpenHarmony.

## Detailed Description

### User-Agent开发指导_2more.md User-Agent开发指导_2more.md
This development guide explains the structure and usage of User-Agent (UA) strings within the OpenHarmony ecosystem to ensure proper web content rendering and device identification. The document covers the definition and importance of UA, details the default UA string structure, and provides a comprehensive breakdown of specific fields such as DeviceType, OSName, and ArkWeb version codes. Key information includes the specific syntax for the default UA, how the presence of the "Mobile" field controls viewport meta tag behavior, and recommendations to use the "OpenHarmony" keyword for accurate device identification. This guide is intended for web developers and system integrators utilizing the ArkWeb component who need to customize content based on device characteristics.

### 常见问题.md 常见问题.md
This technical guide serves as a FAQ for developers to identify and simulate HarmonyOS devices via User-Agent strings. It covers device identification and debugging simulation, detailing how to detect the operating system, version numbers, and device types like Phone, Tablet, and 2in1. The document provides JavaScript regular expression examples for detection and explains using browser DevTools to rewrite User-Agents for testing. Targeted at frontend developers with basic JavaScript knowledge, this guide facilitates cross-platform compatibility strategies. Keywords: HarmonyOS, User-Agent, device detection, frontend debugging, JavaScript.

### 自定义User-Agent结构.md 自定义User-Agent结构.md
This guide explains how to manage and customize User-Agent strings for the ArkWeb component. It covers retrieving the default User-Agent, setting a custom User-Agent, and retrieving the custom value. The document emphasizes that `setCustomUserAgent` overwrites system defaults, recommending developers append custom identifiers to the default string. It specifies that User-Agent configuration should occur in the `onControllerAttached` callback to ensure consistency, avoiding `onLoadIntercept`. This is intended for application developers using the ArkWeb kit who need to modify browser identification strings for web content loading.
