This directory contains API reference documentation for the `ohos.hi_tracechain` module in the Cangjie language, designed for HarmonyOS distributed tracing. It covers the core classes and enums required to implement call chain tracking, performance analysis, and debugging across devices, threads, and processes. Key components include the `HiTraceChain` class, `HiTraceId` structure, and various enums for flags and tracepoint types. This documentation is suitable for HarmonyOS developers using the PerformanceAnalysisKit who need to monitor system performance, instrument business processes, and manage trace lifecycles in distributed systems starting from API version 12.
