This directory contains the API reference documentation for the HarmonyOS Unified Data Channel module, part of the Unified Data Management Framework (UDMF). It focuses on standardized data sharing and management using the Cangjie language. The content covers core data structures like UnifiedData and UnifiedRecord, specific data types such as Image, Video, and Text, and operational functions for data manipulation. It is designed for developers building distributed data applications who need to implement cross-application data interactions, manage metadata, and handle various data formats efficiently within the HarmonyOS ecosystem.
