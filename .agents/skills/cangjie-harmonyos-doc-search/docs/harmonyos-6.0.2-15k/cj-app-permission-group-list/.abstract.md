This directory serves as a comprehensive technical resource for developers working on the HarmonyOS operating system, specifically focusing on the intricacies of application permission management and file access control. It details the architecture of permission groups, explaining how related permissions—such as Location or Camera—are requested together in a single user dialog to improve the user experience. Furthermore, it provides specific technical guidance for file and folder access on 2-in-1 devices, covering media library permissions and the implementation of system Pickers for permission-free access. The documentation highlights critical distinctions between direct access requiring authorization and indirect access via user selection. This content is vital for developers seeking to configure permissions correctly, handle sensitive data like motion and health information, and ensure compliance with device-specific restrictions.
