This directory provides API documentation for a specific extension of the generic Array type within the Cangjie programming language. It applies to arrays where the element type `T` satisfies the Equatable constraint, enabling advanced comparison and manipulation capabilities. The documentation covers a comprehensive set of tools, including search functions like `indexOf` and `lastIndexOf`, boundary modification methods such as `removePrefix` and `trim`, and operator overloads for equality checks. It is designed for Cangjie developers seeking to perform precise element lookups, structural modifications, and equality comparisons on arrays of equatable items.
