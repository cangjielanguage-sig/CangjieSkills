This directory contains Cangjie code examples for cryptographic operations using the Universal Keystore Kit (HUKS). It covers digital signing and verification using various algorithms like ECC, RSA, and SM2. Key topics include key generation, lifecycle management, and specific parameter configurations for different hashing and padding modes (SHA-256, PKCS1_V1_5, PSS, SM3). These examples are suitable for Cangjie developers working on HarmonyOS who need to integrate secure, hardware-backed cryptographic features and national cryptographic standards into their applications.
