# cj-start-express-apps

This directory serves as a comprehensive technical resource tailored for HarmonyOS developers working with the Cangjie programming language. It focuses specifically on the integration of express delivery capabilities into mobile applications through the use of the `startAbilityByType` API. The content is designed to bridge the gap between different applications, enabling seamless cross-app functionality for logistics and tracking services. It covers essential concepts such as invoking system-level panels, parameter construction, and configuration management. By following the guidance provided, developers can ensure their applications correctly interpret and respond to delivery-related requests. This guide is highly suitable for developers utilizing the AbilityKit framework who need to implement advanced features like deep linking, feature-based app selection, and cross-app tracking within the HarmonyOS ecosystem.

## Detailed Description

### 拉起快递类应用startAbilityByType/

This directory provides comprehensive technical guidance for integrating express delivery capabilities into HarmonyOS applications using the `startAbilityByType` API. It is structured to support developers through every stage of the integration process, ensuring that both the initiating application and the target application communicate effectively.

The documentation covers the complete interaction workflow, addressing both the caller side and the target side of the process. Key topics include the method for invoking the system-level express delivery extension panel, a critical component for user interaction. It provides in-depth instructions on constructing JSON parameters, such as `expressNo` and `sceneType`, which are necessary for defining the context of the delivery request. Furthermore, it covers the technicalities of handling callbacks to display the app selection interface to the user.

In addition to the caller-side logic, the directory details how to configure a HarmonyOS app to receive and process these feature-based requests. This includes specific guidance on editing `module.json5` and implementing URI schemes to handle incoming intents. This content is specifically suitable for HarmonyOS developers using the Cangjie language and the AbilityKit framework who need to implement cross-app tracking features or deep linking functionality, providing a solid foundation for building interconnected service applications.
