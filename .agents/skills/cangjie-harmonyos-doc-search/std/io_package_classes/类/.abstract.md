This directory provides API documentation for essential I/O classes in the Cangjie standard library, focusing on stream management, data buffering, and text processing. It includes utilities for chaining streams, optimizing read/write operations via buffering, and handling in-memory byte buffers. Additionally, it covers classes for converting between streams and strings, supporting various encodings and data types. These resources are suitable for Cangjie developers seeking to build efficient, robust applications with advanced input/output capabilities and resource management.
