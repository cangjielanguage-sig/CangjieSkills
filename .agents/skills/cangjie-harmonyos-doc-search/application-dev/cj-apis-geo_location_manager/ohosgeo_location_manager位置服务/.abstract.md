This directory provides comprehensive API documentation for the `ohos.geo_location_manager` module in the Cangjie programming language, designed for HarmonyOS location services. It covers core functionalities including GNSS and network positioning, request configurations, and data structures for location information. Key topics include location request priorities, scenarios, source types, and specific classes like `GeoLocationManager` and `Location`. This documentation is suitable for developers integrating location features, managing permissions, and optimizing power consumption in Cangjie applications.
