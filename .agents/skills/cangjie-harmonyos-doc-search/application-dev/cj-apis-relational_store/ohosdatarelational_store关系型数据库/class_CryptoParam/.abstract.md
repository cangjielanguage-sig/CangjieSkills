This directory contains essential API reference documentation for the `CryptoParam` class in the Cangjie programming language, specifically designed for configuring database encryption parameters. It covers the class constructor and six critical properties: `encryptionKey`, `iterationCount`, `encryptionAlgo`, `hmacAlgo`, `kdfAlgo`, and `cryptoPageSize`. The documentation highlights important constraints, such as the requirement for page sizes to be a power of 2, and explains default algorithm settings. It also clarifies that an empty key triggers automatic key generation by the database, provided the store's encryption option is enabled. This content is tailored for developers utilizing the RelationalStore Core system capability who need to implement secure database storage using specific encryption and key derivation algorithms.
