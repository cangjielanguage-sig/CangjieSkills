This directory contains fundamental type definitions for the ArkUI framework in the Cangjie language, specifically focusing on gesture recognition and interaction handling. It covers the core configuration options for pan gestures and the enumeration of possible drag directions. Key components include the `PanGestureOptions` class, which allows for the dynamic modification of gesture properties without triggering expensive UI refreshes, and the `PanDirection` enum, which provides a robust way to define movement constraints using cardinal and axis-based directions. These definitions are essential for developers building interactive user interfaces that require precise touch handling, efficient state management, and complex gesture logic. The content is suitable for application developers and UI engineers working on ArkUI applications.
