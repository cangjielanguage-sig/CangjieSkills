# README_zh

本目录是通用密钥库套件（HUKS）的中文文档入口，专为需要在OpenHarmony系统中处理敏感数据和加密操作的开发者设计。它提供了关于密钥管理服务的全面开发指南，涵盖了从密钥的生成、导入（包括明文和加密方式）到实际使用（如加解密、签名验签、密钥协商、派生及HMAC计算）的全过程。此外，文档还详细介绍了密钥的生命周期管理，包括删除、安全证明、属性查询及导出等功能。通过阅读本文档，开发者可以了解HUKS的算法规格、功能特性及具体的开发流程，从而在应用中构建安全可靠的密钥存储体系。请注意，当前文档描述的功能特性均处于Beta阶段。
