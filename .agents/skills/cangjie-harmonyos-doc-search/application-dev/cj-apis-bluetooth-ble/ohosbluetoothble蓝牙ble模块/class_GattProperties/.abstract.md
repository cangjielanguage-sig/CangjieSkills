This directory serves as a comprehensive resource for the `GattProperties` class within the Cangjie language framework, specifically designed for developers working with Bluetooth Low Energy (BLE) technology. It provides detailed API documentation on how to configure attributes for GATT characteristic values, covering essential boolean properties like read, write, writeNoResponse, notify, and indicate. The content explains how these properties control access permissions and specific communication behaviors, such as whether a write operation requires a response or if notifications need confirmation. Furthermore, it outlines the system capabilities required, specifically SystemCapability.Communication.Bluetooth.Core starting from version 22. This documentation is ideal for software developers and Bluetooth engineers who need to implement precise control over data transmission and access in their BLE applications using the Cangjie language.
