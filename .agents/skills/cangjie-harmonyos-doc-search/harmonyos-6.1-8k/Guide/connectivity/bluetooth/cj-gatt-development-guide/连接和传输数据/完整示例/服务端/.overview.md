# 服务端

本目录汇集了蓝牙低功耗（BLE）GATT服务端开发的核心文档与代码示例。内容涵盖服务端初始化、特征值与描述符的读写请求处理、连接状态管理、数据通知机制以及服务注销流程。文档主要使用仓颉语言和ArkTS编写，详细展示了`GattServerManager`的构建、回调逻辑封装及标准GATT配置的实现。适合鸿蒙系统下的蓝牙应用开发者，特别是需要实现BLE外设功能或进行服务端业务逻辑开发的工程师参考。

## 详细说明

### 服务端_1.md
本文档提供了使用仓颉语言实现BLE GATT服务端的代码示例，重点展示了GattServerManager类的结构、服务初始化及回调函数的定义。涵盖了必要的库导入、UUID常量定义、描述符与特征值的初始化方法、连接状态变化回调、读写请求回调以及服务注册逻辑。关键信息包括如何构建BleDescriptor和BleCharacteristic对象，如何处理标准Client Characteristic Configuration描述符以支持通知，以及在registerServer方法中如何响应特征值读取请求。面向使用仓颉语言开发蓝牙应用的鸿蒙开发者，作为服务端实现的参考代码或教程片段。

### 服务端_2.md
本文档提供了实现BLE GATT服务端的代码示例，重点在于处理特征值和描述符的读写请求及服务注册。主要涵盖了特征值读写、描述符读写的事件回调逻辑，以及GattService的构建和gattServer实例的初始化流程。关键信息包括使用sendResponse响应客户端、在写入时更新本地缓冲区，以及订阅连接状态和数据交互事件。文档面向HarmonyOS蓝牙应用开发者，展示了从创建服务实例到处理具体业务交互的步骤，适用于实现低功耗蓝牙服务端功能的场景。

### 服务端_3.md
本文档介绍蓝牙低功耗（BLE）服务端在特征值变化时的通知机制及服务注销流程。主要涵盖特征值变化通知、服务注销及回调处理类。核心内容包括`sendCharacterChange`函数，用于根据描述符配置发送通知或确认；以及`unRegisterServer`函数，用于移除服务、取消订阅回调并关闭服务器。文档还定义了连接状态、读写请求的回调封装。这属于API参考文档，面向具备基础蓝牙协议和ArkTS编程能力的开发人员，旨在指导实现BLE服务端的数据交互与资源释放。

### 服务端_4.md
本文档作为技术参考或代码片段，展示了在蓝牙GATT服务端环境中处理描述符写入请求的回调实现。主要关注`DescriptorWriteRequestCb`类，该类扩展了回调接口以管理写入操作。关键部分包括类定义、构造函数初始化以及处理潜在业务异常和请求对象的invoke方法。此外，还展示了`GattServerManager`的实例化。代码演示了如何封装用于处理异步BLE事件的函数。该材料面向从事蓝牙连接工作的软件开发人员，特别是实现GATT配置文件服务端逻辑的人员。前提条件包括熟悉BLE概念和所使用的特定编程语言语法。
