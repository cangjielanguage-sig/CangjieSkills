This directory provides a comprehensive technical overview and API reference for the `PinchGesture` class, specifically developed for the Cangjie language within the ArkUI framework. It focuses on the intricate details of handling multi-finger pinch interactions, a fundamental gesture pattern for touch-enabled devices. The documentation thoroughly covers the component initialization process, offering guidance on setting critical parameters such as finger count (supporting a range of 2 to 5 fingers) and defining the minimum recognition distance required to trigger the gesture accurately. Beyond initialization, it details the event-driven architecture, explaining how to utilize callbacks for the entire gesture lifecycle—including start, update, end, and cancel actions—using `GestureEvent` data structures. This guide is an invaluable resource for HarmonyOS developers aiming to implement sophisticated touch-based scaling and zooming features, ensuring their applications offer a fluid and responsive user experience.
