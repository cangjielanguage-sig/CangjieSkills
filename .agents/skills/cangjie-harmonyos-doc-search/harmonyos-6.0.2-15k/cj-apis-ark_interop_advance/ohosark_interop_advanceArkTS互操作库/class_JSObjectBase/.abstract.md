This directory contains API reference documentation for the `JSObjectBase` class and related functions within the Cangjie programming language environment. It focuses on bridging Cangjie and ArkTS (JavaScript) interactions, specifically for ArkUI and Napi development. The content covers object referencing, method invocation, property manipulation (getters/setters), and instance checking. It is suitable for HarmonyOS developers working on native interoperation who need to safely manipulate JavaScript objects from Cangjie code.
