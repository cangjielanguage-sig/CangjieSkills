This directory contains documentation for the `HuksTag` class, a core component of the HarmonyOS Universal Keystore (HUKS) framework. It defines the enumeration of tags used to specify key attributes, cryptographic algorithms, operational parameters, and security access controls. The content covers constant definitions, data type structures, and API parameter configurations essential for secure hardware-backed key management. It is suitable for system developers, security engineers, and application developers working with OpenHarmony or HarmonyOS, particularly those implementing cryptography using the Cangjie language or native APIs.
