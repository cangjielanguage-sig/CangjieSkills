# cj-i18n-preferred-language

This directory serves as a comprehensive resource for Cangjie developers aiming to implement robust internationalization (i18n) features within their applications. It specifically addresses the technical requirement to set an application's preferred language independently of the device's system language, a critical capability for supporting multilingual users effectively. The documentation covers the utilization of the LocalizationKit framework, detailing how to manage language settings programmatically using APIs like `System.setAppPreferredLanguage`. By following this guide, developers can ensure that their application's interface resources dynamically align with the user's selected locale. This content is highly suitable for software engineers working on global applications where user language preferences may differ from the operating system's default settings, offering a tailored and accessible experience.

## Detailed Description

### cj-i18n-preferred-language.md cj-i18n-preferred-language.md

This document provides a detailed instructional guide for Cangjie developers on how to configure an application's preferred language separate from the system-wide language setting. It is designed to assist developers in supporting multilingual users by allowing the app to operate in a specific locale regardless of the device settings. The guide begins by outlining the core purpose of this feature and transitions into a practical, step-by-step tutorial utilizing the LocalizationKit framework.

Key technical steps covered in the document include:
*   **Module Importation:** Instructions on importing the necessary modules to access internationalization features.
*   **Retrieving Preferences:** How to use `System.getAppPreferredLanguage` to check the current language setting.
*   **Modifying Preferences:** How to implement `System.setAppPreferredLanguage` to change the language.

The guide explains how to set a specific language that impacts only the application environment, as well as how to clear these custom settings to revert to the default system language. This tutorial is essential for ensuring that application interface resources correctly match the selected internationalization locale, thereby enhancing the user experience for diverse audiences and ensuring compliance with localization standards. It empowers developers to build flexible, user-centric applications that respect individual language choices.
