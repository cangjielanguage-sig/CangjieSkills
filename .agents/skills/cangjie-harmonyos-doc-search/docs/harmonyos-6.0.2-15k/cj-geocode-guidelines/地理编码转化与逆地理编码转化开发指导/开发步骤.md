## 开发步骤

> **说明：**
> 地理编码与逆地理编码功能需要访问后端服务，请确保设备联网，以进行信息获取。

1. 导入geoLocationManager模块，所有与地理编码转化及逆地理编码转化能力相关的功能API，都是通过该模块提供的。

    ```cangjie
    import kit.LocationKit.*
    ```

2. 查询地理编码与逆地理编码服务是否可用。

    调用isGeoServiceAvailable查询地理编码与逆地理编码服务是否可用。如果服务可用，则继续执行步骤3；如果服务不可用，说明该设备不具备地理编码与逆地理编码能力，请勿使用相关接口。

    <!-- run -->

    ```cangjie
    import kit.LocationKit.*
    import ohos.base.*

    try {
        let isAvailable = GeoLocationManager.isGeocoderAvailable()
    } catch (err: BusinessException) {
        AppLog.error("errCode: ${err.code}, message: ${err.message}")
    }
    ```

3. 获取转化结果。
    - 调用getAddressesFromLocation，把坐标转化为地理位置信息。应用可以获得与此坐标匹配的[GeoAddress](../../API_Reference/source_zh_cn/apis/LocationKit/cj-apis-geo_location_manager.md#class-geoaddress)（地理编码地址信息）列表，应用可以根据实际使用需求，读取相应的参数数据。

        <!-- run -->

        ```cangjie
        import kit.LocationKit.*
        import ohos.base.*

        let reverseGeocodeRequest: ReverseGeoCodeRequest = ReverseGeoCodeRequest(31.12, 121.11, maxItems: 1)
        try {
            let data = GeoLocationManager.getAddressesFromLocation(reverseGeocodeRequest)
            AppLog.info("getAddressesFromLocation data size: ${data.size}")
        } catch (err: BusinessException) {
            AppLog.error("errCode: ${err.code}, message: ${err.message}")
        }
        ```

    - 调用getAddressesFromLocationName把位置描述转化为坐标。

        <!-- run -->

        ```cangjie
        import kit.LocationKit.*
        import ohos.base.*

        let geocodeRequest: GeoCodeRequest = GeoCodeRequest("上海市浦东新区xx路xx号", maxItems: 1)
        try {
            let data = GeoLocationManager.getAddressesFromLocationName(geocodeRequest)
            AppLog.info("getAddressesFromLocationName data size: ${data.size}")
        } catch (err: BusinessException) {
            AppLog.error("errCode: ${err.code}, message: ${err.message}")
        }
        ```

    应用可以获得与位置描述相匹配的[GeoAddress](../../API_Reference/source_zh_cn/apis/LocationKit/cj-apis-geo_location_manager.md#class-geoaddress)（地理编码地址信息）列表，其中包含对应的坐标数据。

    如果需要查询的位置描述可能出现多地重名的请求，可以设置[GeoCodeRequest](../../API_Reference/source_zh_cn/apis/LocationKit/cj-apis-geo_location_manager.md#class-geocoderequest)，通过设置一个经纬度范围，以高效地获取期望的准确结果。
