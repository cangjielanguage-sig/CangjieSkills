# 页面和自定义组件生命周期

This directory focuses on the lifecycle management of pages and custom components within the ArkUI framework, covering both ArkTS and Cangjie contexts. It details the creation, rendering, state management, and destruction processes, including specific callbacks like `aboutToAppear`, `onPageShow`, and `aboutToDisappear`. It also addresses advanced topics such as monitoring page visibility changes in nested components and handling component deletion mechanisms. This resource is suitable for HarmonyOS developers seeking to optimize application performance, manage resources effectively, and ensure stable UI behavior through proper lifecycle handling.

## Detailed Description

### 自定义组件的创建和渲染流程_2more.md 自定义组件的创建和渲染流程_2more.md
This technical guide details the lifecycle and rendering mechanism of custom components within the ArkUI framework. It covers the initial creation process, member variable initialization, lifecycle callbacks like aboutToAppear and onDidBuild, and the re-rendering logic triggered by state changes. Key takeaways include that the framework creates instances and executes the build method to render UI while establishing a mapping between state variables and components. Re-rendering utilizes this mapping to perform minimal updates when state variables change via events or storage updates. This document serves as a reference for developers building ArkUI applications who need to understand component behavior and state management optimization. Keywords: ArkUI, custom components, lifecycle, state management, re-rendering, aboutToAppear.

### 自定义组件监听页面声明周期.md 自定义组件监听页面声明周期.md
This tutorial demonstrates how to implement lifecycle monitoring for TabContent switching events within custom components using the Cangjie language. It covers defining callback classes inheriting from Callback1Argument, registering observers via the on function, and managing lifecycle states like ON_SHOW and ON_HIDE. The code illustrates the ObserverType.OBSERVER_TAB_CONTENT_UPDATE usage, showing how to bind specific Tabs components by ID and handle event data logging within aboutToAppear and aboutToDisappear methods. This guide is intended for HarmonyOS developers using Cangjie and ArkUI who need to track page visibility changes in nested components.

### 页面和自定义组件生命周期.md 页面和自定义组件生命周期.md
This technical guide details the lifecycle management for pages and custom components in the ArkUI framework. It distinguishes between @Component decorated UI units and @Entry decorated page roots, explaining their specific callback interfaces. Key sections cover page lifecycle methods like onPageShow and onBackPress, alongside component lifecycle stages such as aboutToAppear, onDidBuild, and aboutToDisappear. The document provides critical usage constraints, advising against state variable modifications in onDidBuild and aboutToDisappear to prevent UI instability. Intended for ArkUI developers, this reference ensures proper handling of component initialization, rendering, and destruction.

### 自定义组件的删除/
This directory provides a comprehensive technical overview of the deletion and destruction mechanisms for custom components within the ArkUI framework. It covers the entire lifecycle process, from the initial trigger of component removal to the final garbage collection. Key topics include the `aboutToDisappear` callback, the unbinding of state variables like `@Link` and `@Prop`, and the specific execution order of lifecycle events during conditional rendering, page navigation, and application state changes. The documentation distinguishes between different programming contexts (Cangjie and ArkTS) and navigation methods (`pushUrl` vs. `replaceUrl`). It is essential for developers aiming to master resource management, prevent memory leaks, and ensure smooth state transitions in their applications.
