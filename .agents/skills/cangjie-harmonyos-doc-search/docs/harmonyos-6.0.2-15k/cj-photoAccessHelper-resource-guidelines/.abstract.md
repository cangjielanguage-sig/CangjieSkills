This directory acts as a central repository of technical guidelines for developers working with the Cangjie programming language, specifically those tasked with implementing media management capabilities in their applications. It provides a structured approach to using the `photoAccessHelper` interface and `MediaLibraryKit`, enabling the effective handling of image and video assets. The scope of the documentation includes critical lifecycle operations such as querying the media database, renaming files, deleting resources, and generating thumbnails. It is an essential resource for Cangjie developers, detailing the mandatory prerequisites like module instance initialization and permission application. By adhering to these guidelines, developers can ensure their applications securely access media files, manage metadata correctly, and integrate visual content into the UI with high performance and reliability.
