# ohosappabilitycontext_constant

This directory provides comprehensive API documentation for the `ohos.app.ability.context_constant` module within the HarmonyOS Cangjie SDK. It is designed to assist developers in defining and managing application context constants, with a primary focus on data security through file encryption partition levels. The documentation details the `AreaMode` enumeration, which categorizes encryption zones from device-level to application-level, ensuring data protection across different device states such as boot, lock screen, and unlock. Additionally, it covers process modes post-UIAbility startup and outlines necessary system permissions like `DISTRIBUTED_DATASYNC`. This resource is essential for Cangjie developers aiming to implement robust security configurations and manage context-specific behaviors in their applications, currently available in a Beta environment.

## Detailed Description

### enum_AreaMode.md
This API documentation defines the Cangjie AreaMode enum, which specifies file encryption partition levels to ensure data security across various application scenarios. The document details five distinct encryption levels (El1 through El5), outlining specific accessibility and read/write permissions based on device states like boot, lock screen, and unlock. It also covers standard operators for equality comparison and string conversion. Key takeaways include the distinction between device-level (El1), user-level (El2-El4), and application-level (El5) encryption zones. Intended for developers utilizing the SystemCapability.Ability.AbilityRuntime.Core capability, this reference guide helps in selecting appropriate security measures for protecting user data.

### ohosappabilitycontext_cons_4more.md
This document serves as API reference for the ohos.app.ability.context_constant module within the HarmonyOS Cangjie SDK. It defines Context-related enumerations, specifically covering file encryption partition levels and process modes following UIAbility startup. The content outlines the necessary import statements, lists required permissions such as DISTRIBUTED_DATASYNC and PRIVACY_WINDOW, and provides instructions for executing example code in Cangjie template projects. Currently in Beta, this guide targets developers using the Cangjie language who need to implement context configurations and manage specific system permissions in their applications.
