# class_Image

本目录包含Cangjie语言ImageKit框架中Image类的API参考文档，主要涵盖图像类的定义、属性、方法及资源管理。文档详细介绍了`clipRect`、`format`、`size`等只读属性，以及获取组件缓存的`getComponent`方法。特别强调了图像实例的不可变性及其内存占用较大的特性，要求开发者在使用完毕后必须调用`release`方法释放资源。此外，还涉及YUV预览流和JPEG拍照流数据中`size`属性的差异。该文档适用于从事多媒体图像处理、相机流数据应用开发的Cangjie程序员。
