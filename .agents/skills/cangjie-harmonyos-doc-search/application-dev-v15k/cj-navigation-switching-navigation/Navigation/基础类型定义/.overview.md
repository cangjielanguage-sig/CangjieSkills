# 基础类型定义

This directory contains API reference documentation for fundamental data structures and configuration classes used in the HarmonyOS ArkUI framework, specifically written in the Cangjie language. It covers essential components for navigation systems, including routing path information, toolbar configurations, title options, and menu items. Key topics include NavPathInfo, NavigationOptions, and various enums defining UI states and behaviors. This documentation is suitable for HarmonyOS developers and UI engineers who need to implement and customize navigation logic, page transitions, and interface layouts within their applications using Cangjie.

## Detailed Description

### class_NavPathInfo.md class_NavPathInfo.md
This document provides API reference documentation for the Cangjie class `NavPathInfo`, which is used to store routing page information for `NavDestination` components. It covers the class definition, public properties including `name`, `param`, and `onPop`, and two constructor overloads. Key information includes the management of page names and parameters, alongside a callback mechanism triggered during page pop events. Intended for developers working with ArkUI navigation, this reference targets version 20.

### class_NavigationCommonTitl_5more.md class_NavigationCommonTitl_5more.md
This document serves as API reference documentation for Cangjie language classes and enums within the ArkUI Navigation framework. It details the `NavigationCommonTitle` class for configuring main and sub titles, alongside several enums: `NavigationMode` for layout styles, `ToolbarItemStatus` for item states, `NavBarPosition` for split view alignment, and `LaunchMode` for routing stack operations. Key takeaways include the 600.vp threshold for Auto mode and specific routing behaviors like `MoveToTopSingleTon`.

### class_NavigationMenuItem.md class_NavigationMenuItem.md
This API reference document outlines the `NavigationMenuItem` class, which represents menu options in a Navigation component for the Cangjie language. It covers the class structure, detailing properties such as `value` for text, `icon` for resource paths, `isEnable` for state control, and `action` for event callbacks. It explains two constructor overloads that accept either standard Strings or `AppResource` objects for localization support, assisting developers in implementing interactive navigation menus.

### class_NavigationOptions.md class_NavigationOptions.md
This document serves as an API reference for the Cangjie class `NavigationOptions`, which defines configuration settings for launching navigation components. It details the class properties `launchMode` and `animated`, along with the class constructor. Key information includes that `launchMode` controls page stack operations using the `LaunchMode` enum, while `animated` determines if transition animations are enabled. Both properties are read-only and initialized via the constructor, which defaults to standard mode and animations enabled.

### class_NavigationToolbarOptions.md class_NavigationToolbarOptions.md
This API reference document defines the `NavigationToolbarOptions` class used to configure the appearance and layout of a Navigation toolbar within the Cangjie ArkUI framework. It details the class's public properties, specifically `backgroundColor`, `backgroundBlurStyle`, and `barStyle`, explaining their types, read-write capabilities, and default behaviors. Key takeaways include that all properties are optional, allowing developers to customize visual effects like background blur or rely on system defaults.

### class_PopInfo.md class_PopInfo.md
This API reference document defines the `PopInfo` class, which serves as a data carrier for callback information when a page returns in the ArkUI framework. It covers the class structure, specifically detailing the properties `info` and `result`, along with the initialization constructor. Key information includes that the `info` property automatically captures system-generated `NavPathInfo` for the current page, while the `result` property allows developers to define custom return strings.

### class_ToolBarItem.md class_ToolBarItem.md
This document serves as an API reference for the `ToolBarItem` class in the Cangjie language, designed to configure toolbar options within the ArkUI framework. It details the class's properties, including display text, icon paths, event callbacks, and status states, alongside two constructor overloads supporting both `String` and `AppResource` types. Key takeaways include the ability to define normal and active states for icons and the requirement of a value parameter during initialization.

### enum_NavigationTitleMode_2more.md enum_NavigationTitleMode_2more.md
This document serves as API reference documentation for Cangjie developers using the ArkUI framework, defining enums for navigation title behaviors and layout styles. It covers the `NavigationTitleMode` enum, detailing three modes: Free, Full, and Mini, including specific height values and animation constraints. It also describes the `BarStyle` enum, which controls the spatial relationship between the title bar and content area via Standard or Stack layouts.

### class_NavPathStack/
This directory contains API reference documentation for the `NavPathStack` class within the HarmonyOS ArkUI framework, written in the Cangjie language. It covers the comprehensive management of navigation routing stacks, including class initialization, stack manipulation (push, pop, remove, replace), and query functions. Key topics include handling page transitions, passing data between pages, managing nested navigation, and configuring launch modes for complex page navigation logic.
