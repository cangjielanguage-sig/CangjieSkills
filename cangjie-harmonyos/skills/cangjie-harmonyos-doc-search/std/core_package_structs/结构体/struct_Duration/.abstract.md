This directory contains API reference documentation for the `Duration` struct in the Cangjie programming language. It covers the representation and manipulation of time intervals with nanosecond precision. The documentation details arithmetic operators, comparison logic, unit conversion methods, and static constants for time units. It is suitable for Cangjie developers who need to perform precise time-based calculations, handle time spans, or format duration data in their applications. Key topics include operator overloading, exception handling for overflow, and interface implementations like `Comparable` and `Hashable`.
