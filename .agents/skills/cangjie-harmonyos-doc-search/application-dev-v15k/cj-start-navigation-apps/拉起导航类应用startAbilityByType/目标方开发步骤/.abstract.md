This directory serves as a comprehensive resource for HarmonyOS developers tasked with configuring an application to function as a target service provider for map functionalities. It thoroughly covers the necessary development steps, including the configuration of the `module.json5` file to declare specific features such as Navigation, RoutePlan, and PlaceSearch via the `linkFeature` attribute. Furthermore, it details the technical implementation required to parse incoming parameters within the `UIAbility` lifecycle, offering specific parameter tables for different scenarios and Cangjie code examples. This guide is essential for developers who need to enable their applications to seamlessly receive, process, and respond to external map service requests.
