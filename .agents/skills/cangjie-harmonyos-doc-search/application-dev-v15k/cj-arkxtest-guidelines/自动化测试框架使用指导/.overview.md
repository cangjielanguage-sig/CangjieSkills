# 自动化测试框架使用指导

This directory provides a comprehensive guide for the Cangjie Automated Testing Framework within the HarmonyOS/OpenHarmony ecosystem. It covers the architecture of the Cangjie Unit Test Framework and the UiTest framework, detailing their implementation principles and runtime environments. The content includes resources for writing and executing test scripts using the Cangjie language, performing UI automation via shell commands, and troubleshooting common execution errors. Designed for software developers and QA engineers, this documentation facilitates the setup of robust testing workflows, environment configuration, and effective debugging of UI automation scripts.

## Detailed Description

### 常见问题.md 常见问题.md
This troubleshooting guide addresses common errors encountered during UI test case execution. It covers three specific failure scenarios: window retrieval failures, API concurrency restrictions, and widget object invalidation due to UI changes. Key solutions include enabling the ArkUI test mode via specific shell commands, avoiding multi-thread or multi-process calls to UITest APIs, and re-running tests when UI states shift unexpectedly. This reference is intended for software developers and QA engineers debugging UI automation scripts, providing specific error messages, root causes, and remediation steps.

### 概述_2more.md 概述_2more.md
This document serves as a technical guide for the Cangjie Automated Testing Framework, outlining its architecture and usage within the HarmonyOS environment. It details two core components: the Cangjie HarmonyOS Unit Test Framework, which adapts the standard library via TestRunner for case execution and reporting, and the UiTest framework, which provides APIs for UI automation and auxiliary shell commands. Key sections explain implementation principles, including the workflow for test registration, execution, and result aggregation. The text highlights that UiTest relies on the unit test framework as its runtime base. This guide targets developers needing to understand the framework's structure to prepare environments and write automated test scripts.

### 基于Cangjie编写和执行测试/
This directory serves as a comprehensive resource for developers working with the Cangjie language in the OpenHarmony ecosystem, focusing specifically on the complete testing lifecycle. It guides users through the initial setup of the HarmonyOS development environment using DevEco Studio, proceeds to the creation of robust unit and UI test scripts, and concludes with methods for executing these tests via both graphical interfaces and command-line tools. Key topics include environment configuration, the use of assertions, the UiTest framework, and the interpretation of XML test results. This documentation is tailored for HarmonyOS application developers and QA engineers seeking to establish a reliable automated testing workflow.

### 基于shell命令测试/
This directory contains technical documentation for performing automated UI testing and debugging on HarmonyOS/OpenHarmony systems using shell commands. It covers the `uitest` tool, enabling users to execute operations such as screen capturing, layout dumping, and complex UI simulations directly from the command line. Key topics include gesture recording, input simulation (clicks, swipes, text), and environment configuration. These resources are designed for developers and QA engineers seeking efficient workflows for rapid testing and interface validation, assuming prior setup of HDC environment variables and appropriate system permissions.
