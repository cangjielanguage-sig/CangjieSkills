# class_TelephonySim

This directory contains API reference documentation for the TelephonySim class and related static functions within the TelephonyKit in the Cangjie programming language. It covers comprehensive SIM card management capabilities, including retrieving account information, operator details, ISO country codes, and SIM state verification. The documentation details function signatures, required permissions (such as GET_TELEPHONY_STATE), system capabilities, and exception handling. It is suitable for Cangjie developers integrating telephony services who need to query SIM status, configurations, and metadata while adhering to system data access restrictions.
