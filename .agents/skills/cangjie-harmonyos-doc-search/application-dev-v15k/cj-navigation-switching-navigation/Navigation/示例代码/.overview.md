# 示例代码

This directory contains practical code examples and tutorials designed for developers building HarmonyOS applications using the Cangjie language. It focuses specifically on the implementation and management of the Navigation component, a crucial element for mobile app architecture. The content covers two main areas: the structural configuration of navigation interfaces—including title bars, menus, and toolbars—and the programmatic management of page routing stacks. Key concepts include NavPathStack methods, page mapping, decorators like @Entry and @Component, and stack manipulation operations such as push, pop, and move. These examples are best suited for developers who already have a basic understanding of Cangjie and wish to master complex UI navigation and state management within the HarmonyOS ecosystem.

## Detailed Description

### 示例2使用路由栈方法.md 示例2使用路由栈方法.md
This document provides a practical code example demonstrating the usage of the `NavPathStack` class methods within a HarmonyOS application built with Cangjie. It covers the setup of a Navigation component, a page mapping function, and two destination pages. The core focus is on `PageOne`, which implements buttons to test various stack operations including `pushPathByName`, `popToName`, `popToIndex`, `moveToTop`, `moveIndexToTop`, parameter retrieval, and clearing the stack. This tutorial is intended for developers familiar with Cangjie and HarmonyOS UI development who need to understand page navigation and stack management.

### 示例代码_2more.md 示例代码_2more.md
This document serves as a code tutorial demonstrating the implementation of a Navigation page layout using the Cangjie language. The primary focus is on configuring the Navigation component, including the title bar, menu bar, content area, and toolbar. Key takeaways include the usage of decorators like `@Entry` and `@Component`, custom builders for UI elements, and specific properties such as `titleMode` and `toolbarConfiguration`. The example highlights that effects should be verified on real devices rather than simulators. This guide is intended for developers seeking practical examples of structuring complex navigation interfaces in Cangjie applications.
