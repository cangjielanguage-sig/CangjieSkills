This directory contains API reference documentation for standard utility functions in the Cangjie programming language. It covers a wide range of operations including console input/output (print/println), standard error logging (eprint), memory management (raw pointers, alignment), and data manipulation (min/max, Option handling). The documentation provides syntax definitions, parameter descriptions, and verified code examples for various data types, from integers and floats to generic types. It is suitable for Cangjie developers seeking precise control over system-level operations, FFI integration, and standard I/O streams.
