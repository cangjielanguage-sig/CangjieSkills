This directory focuses on API tagging and management within the Cangjie programming language ecosystem. It primarily covers the `@IfAvailable` macro expression, which allows developers to handle API versioning and System Capabilities (syscap) gracefully. Key topics include compile-time scope restrictions, runtime execution logic, and ensuring code compatibility across different SDK versions and device configurations. This documentation is suitable for Cangjie developers using DevEco Studio who need to implement fine-grained control over API availability and prevent errors when deploying to diverse hardware environments. By utilizing these guides, developers can ensure their applications function correctly across varying system capabilities and API levels.
