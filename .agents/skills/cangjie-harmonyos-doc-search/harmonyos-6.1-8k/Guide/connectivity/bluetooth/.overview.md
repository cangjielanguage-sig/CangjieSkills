# bluetooth

This directory serves as a centralized repository for technical documentation and development guides focused on Bluetooth technologies within the HarmonyOS and OpenHarmony ecosystems. It specifically targets developers using the Cangjie programming language, offering resources that range from high-level architectural overviews to deep-dive implementation guides. The content covers fundamental physical principles, the distinctions between Classic Bluetooth (BR/EDR) and Low Energy (BLE), and specific protocol handling like GATT. Designed to support the growing Internet of Things (IoT) landscape, these guides are ideal for embedded systems engineers, IoT developers, and software architects seeking to build robust, low-power connectivity solutions for wearables and smart devices.

## Detailed Description

### [1] cj-ble-development-guide/
This directory serves as a comprehensive technical resource for developers working with Bluetooth Low Energy (BLE) technologies using the Cangjie language on HarmonyOS and OpenHarmony platforms. As the Internet of Things (IoT) continues to expand, the guide provides essential knowledge for creating efficient, low-power connectivity solutions. It addresses the specific needs of developers looking to leverage the Cangjie language for modern BLE application development.

### [2] cj-bluetooth-overview/
This directory focuses on providing a comprehensive technical overview of Bluetooth service development, aiming to help developers deeply understand the core mechanisms of Bluetooth technology. The content covers the basic physical principles of Bluetooth, including communication based on 2.4GHz radio waves and frequency-hopping spread spectrum technology. The document highlights a comparison between the two main branches of Bluetooth technology: Classic Bluetooth (BR/EDR) and Bluetooth Low Energy (BLE). It elaborates on the mature protocol advantages of Classic Bluetooth in high-speed data transmission and audio streaming, as well as the widespread application of BLE in ultra-low power operation, wearable device connections, and Internet of Things (IoT) scenarios. Core keywords cover Bluetooth development, BR/EDR, BLE, audio transmission, IoT, and wearable devices. This resource is particularly suitable for embedded developers or mobile developers.

### [3] cj-gatt-development-guide/
This directory serves as a comprehensive technical resource for developers working on Bluetooth Low Energy (BLE) applications within the HarmonyOS ecosystem. It specifically focuses on the Generic Attribute Profile (GATT) protocol, providing a deep dive into its structure and implementation. This guide is crucial for developers who need to handle complex data exchange and service definitions in their BLE applications.
