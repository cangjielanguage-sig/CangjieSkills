### 枚举_3more_8e4cb414.md

### 类.md
该文档作为HTTP包的类索引，列出了核心类名及其功能描述，帮助开发者快速了解API组件。主要涵盖客户端与服务器构建、HTTP请求与响应处理、上下文管理、多种便捷处理器以及WebSocket通信支持。关键信息包括Client和Server通过对应的Builder构建实例，ProtocolService负责连接与报文解析，同时提供了FuncHandler、RedirectHandler等便捷工具类及WebSocket相关接口。文档面向使用该HTTP库进行网络编程的开发者，适用于构建HTTP/1.1、HTTP/2服务或WebSocket应用。
