This directory contains API reference documentation for the `HttpRequestOptions` class in the Cangjie programming language, specifically designed for the NetStack system capability. It covers the comprehensive configuration and customization of HTTP requests, including SSL certificates, DNS settings, timeouts, proxy management, and data transmission protocols. The documentation details read-only properties, constructor definitions, and specific behaviors for request bodies and headers. It is suitable for Cangjie developers seeking to implement secure, robust, and customizable network communication solutions in their applications.
