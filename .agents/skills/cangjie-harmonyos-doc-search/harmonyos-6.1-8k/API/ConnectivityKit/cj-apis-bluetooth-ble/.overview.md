# cj-apis-bluetooth-ble

This directory contains the API reference documentation for Bluetooth Low Energy (BLE) functionality specifically designed for the Cangjie programming language within the HarmonyOS ecosystem. It covers essential BLE operations including scanning for devices, configuring advertising data, and managing GATT (Generic Attribute Profile) client and server interactions. Key components include scan filters, service construction classes, and connection lifecycle management. This documentation is intended for developers using Cangjie to build low-power wireless communication applications on HarmonyOS, providing the necessary tools to implement robust Bluetooth connectivity.
