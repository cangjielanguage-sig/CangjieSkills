This directory contains API reference documentation for the `ohos.intl` module within the Cangjie LocalizationKit, designed for HarmonyOS internationalization (I18n). It covers essential classes and structs for formatting dates, numbers, and relative times, as well as handling locale-specific string comparison and pluralization rules. The documentation provides initialization methods, configuration options, and usage examples for developers building global applications. It is suitable for Cangjie developers and engineers working on localization features who need to implement culturally aware text sorting, time display, and numeric formatting.
