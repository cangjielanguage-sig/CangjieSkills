This directory contains essential API reference documentation for the `BaseDialogOptions` constructor in the Cangjie language, aimed at developers configuring dialog component properties within a UI framework. The documentation thoroughly covers layout definitions, including mask rectangles, alignment, and offsets, as well as visual settings like mask colors and transition animations. It also details interaction behaviors such as modal settings, auto-cancel features, and keyboard avoidance modes. Additionally, it explains lifecycle event callbacks for managing state changes. This resource is suitable for Cangjie developers and UI engineers looking to customize dialog appearance, positioning, and event handling in their applications.
