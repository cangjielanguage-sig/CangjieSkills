This directory provides comprehensive API reference documentation for the `Tokens` class within the Cangjie programming language ecosystem. It focuses on the encapsulation and management of Token object sequences, primarily for Abstract Syntax Tree (AST) construction and lexical analysis. Key topics include class inheritance from standard interfaces, initialization constructors, and properties for accessing internal data. The documentation is essential for developers requiring efficient token manipulation, serialization, and iteration capabilities using Cangjie collection types such as ArrayList and Array.
