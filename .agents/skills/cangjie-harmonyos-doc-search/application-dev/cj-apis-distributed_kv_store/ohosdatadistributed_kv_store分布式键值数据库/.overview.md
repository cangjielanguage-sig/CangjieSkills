# ohosdatadistributed_kv_store分布式键值数据库

This directory provides API reference documentation for the distributed key-value database module in the Cangjie language, designed for the HarmonyOS ArkData framework. It covers the core functionalities required to implement distributed data management, including database creation, configuration, querying, and synchronization across devices. Key topics include schema definitions, security levels, data types, and system constraints. This documentation is suitable for developers building applications that need robust local storage and cross-device data collaboration capabilities.

### enum_KVSecurityLevel.md enum_KVSecurityLevel.md
This API reference document defines the KVSecurityLevel enum used to specify security levels for KV databases in the Cangjie language. It details four security levels—S1 (Low), S2 (Medium), S3 (High), and S4 (Critical)—describing the potential impact of data breaches for each. Key information includes that security levels support upgrades only, not downgrades, and cross-device synchronization is unsupported during these changes. Developers must close and reopen the database to apply a new level. This guide targets developers using the SystemCapability.DistributedDataManager.KVStore.Core module to classify and protect sensitive data effectively.
