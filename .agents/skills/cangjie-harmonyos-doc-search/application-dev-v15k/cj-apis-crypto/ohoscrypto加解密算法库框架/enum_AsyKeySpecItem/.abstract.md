This directory contains API reference documentation for the `AsyKeySpecItem` enum within the Cangjie CryptoFramework. It defines constants representing specific key parameters for various asymmetric cryptographic algorithms, including ECC, RSA, DSA, ED25519, and X25519. The documentation covers essential key components such as coordinates, moduli, exponents, and curve coefficients. It is intended for security developers and engineers implementing cryptographic operations who need to programmatically identify and manipulate key specification items. All components require the `SystemCapability.Security.CryptoFramework` permission and are available starting from API version 19.
