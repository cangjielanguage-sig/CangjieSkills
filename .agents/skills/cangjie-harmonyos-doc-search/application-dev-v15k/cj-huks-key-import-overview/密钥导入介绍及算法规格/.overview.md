# 密钥导入介绍及算法规格

This directory provides comprehensive technical documentation for importing keys into the HarmonyOS Universal KeyStore (HUKS). It covers the mechanisms for both plaintext and encrypted key import, detailing the cryptographic algorithms (AES, RSA, ECC, ECDH, X25519) and data formats (X.509, Length-Data) required for secure key management. The content distinguishes between standard and lightweight device specifications, outlining security constraints and API level dependencies. It is suitable for security developers and OEMs implementing secure key transfer and storage solutions on HarmonyOS devices.

## Detailed Description

### 加密导入.md
This technical guide details the encrypted import mechanism for HUKS, enabling secure key transfer for high-sensitivity applications. It covers the development workflow, sequence diagram, specific API steps including key generation, encryption, and import, and the binary data format structure. The process uses ECDH or X25519 for key agreement and AES-GCM for encryption. Key materials must follow specific formats like X.509 for public keys and a strict Length-Data structure for the encrypted payload. This is intended for security developers implementing secure key management in HarmonyOS.

### 密钥导入介绍及算法规格_2more.md
This technical guide outlines the process and specifications for importing externally generated keys into the HUKS framework for secure management. It details two primary import methods: plaintext and encrypted import, with a specific focus on the characteristics and limitations of plaintext import. Key takeaways include that plaintext import exposes key material in non-secure environments, making it suitable only for public keys or lightweight devices lacking hardware support for encrypted import. The document targets developers working on HarmonyOS security implementations, providing essential constraints for different device classes.

### 支持的算法_2more.md
This reference document outlines the cryptographic algorithms and key import specifications supported by the HUKS system. It details specifications for standard and lightweight devices, listing supported algorithms like AES, RSA, and ECC alongside their key lengths and API level requirements. Additionally, it explains the required formats for importing symmetric and asymmetric keys, such as X.509 DER for public keys. Key takeaways include the distinction between device specifications and the dependency of lightweight features on OEM implementation. This guide targets developers and OEMs working with security features on devices running API level 15 or higher.
