The `core_package_intrinsics` directory acts as the foundational reference for the Cangjie programming language's intrinsic capabilities and core type system. Unlike standard libraries, intrinsics are deeply integrated into the compiler and runtime, providing the essential building blocks upon which all other Cangjie code is built. This directory specifically documents the comprehensive API for built-in types, covering everything from basic primitives like `Bool` and `Unit` to complex numeric systems. It includes detailed specifications for signed and unsigned integers (Int8 to Int64, UInt8 to UInt64) and floating-point numbers (Float16, Float32, Float64). Furthermore, it provides critical documentation for low-level operations, including types designed for C interoperability like `CPointer` and `CString`, as well as the `Rune` type for Unicode handling. This resource is indispensable for Cangjie developers, systems programmers, and anyone involved in language interoperability or performance-critical application development.
