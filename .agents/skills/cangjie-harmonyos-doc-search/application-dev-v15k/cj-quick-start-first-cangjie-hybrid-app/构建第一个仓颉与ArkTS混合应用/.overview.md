# 构建第一个仓颉与ArkTS混合应用

This directory provides a comprehensive guide for developers building their first HarmonyOS application that integrates the Cangjie language with ArkTS. It covers the complete development lifecycle, including project creation using the Hybrid Ability template, understanding the mixed-language directory structure, and building both pure ArkTS and hybrid UI pages. Additionally, it addresses deployment on real devices or emulators and the complexities of cross-language page navigation. Suitable for developers with basic knowledge of HarmonyOS, ArkTS, and Cangjie, this resource focuses on interoperability, project configuration, and routing between different language environments.

## Detailed Description

### 仓颉与ArkTS混合工程目录结构.md 仓颉与ArkTS混合工程目录结构.md
This reference document outlines the standard directory structure for HarmonyOS projects integrating Cangjie and ArkTS languages. It details the project tree hierarchy and explains the function of key configuration files and source directories. Key sections include the entry module, which separates Cangjie source code in src/main/cangjie from ArkTS code in src/main/ets, and the AppScope for global settings. Important takeaways involve the role of cjpm.toml for Cangjie package management, module.json5 for module configuration, and the har folder for interoperability dependencies. This guide is intended for developers managing mixed-language HarmonyOS applications.

### 使用真机或模拟器运行应用.md 使用真机或模拟器运行应用.md
This tutorial guides developers on running HarmonyOS applications built with the Cangjie language on either local physical devices or emulators within DevEco Studio. The document is divided into two main sections: using a local real device and using the emulator. Key information includes the requirement to configure automatic signing with a Huawei account for real devices and the necessity of modifying the build-profile.json5 file to include x86_64 in abiFilters when running on x86 emulators, as the default architecture is arm64-v8a. This guide is intended for developers creating Cangjie and ArkTS hybrid applications who need to deploy and test their projects.

### 构建第一个仓颉与ArkTS混合应用_2more.md 构建第一个仓颉与ArkTS混合应用_2more.md
This tutorial guides HarmonyOS developers through building their first hybrid application using Cangjie and ArkTS languages to understand project structure and workflows. The document details the project creation process within DevEco Studio, specifically focusing on selecting the "[Cangjie] Hybrid Ability" template and configuring project settings. Key takeaways include distinguishing between hybrid and pure Cangjie templates and generating sample code for a simple page navigation app. Intended for developers with basic knowledge of Cangjie, ArkTS, and UI frameworks, this guide serves as a practical introduction to mixed development practices.

### 构建第一个页面纯ArkTS页面.md 构建第一个页面纯ArkTS页面.md
This tutorial guides developers through building a basic user interface page using pure ArkTS in HarmonyOS. The document covers two main steps: utilizing text components for content display and adding button components to enable user interaction and navigation. Key information includes practical code examples for the Index.ets file, demonstrating how to structure layouts using RelativeContainer, Row, and Column components to align elements effectively. It highlights styling properties for text and buttons to create a functional interface. Intended for beginners starting HarmonyOS development, this guide provides the foundational knowledge necessary for composing UI layouts and handling basic component interactions.

### 构建第二个页面ArkTS与仓颉混合页面.md 构建第二个页面ArkTS与仓颉混合页面.md
This tutorial guides developers on building a hybrid page combining ArkTS and Cangjie languages. It covers creating a Cangjie component using the HybridComponentEntry decorator, embedding it within an ArkTS container page via the CJHybridComponentV2 interface, and verifying the route configuration in main_pages.json. Key takeaways include understanding that Cangjie pages function as components requiring an ArkTS host and the specific file generation process. This guide is intended for HarmonyOS developers familiar with ArkTS who are integrating Cangjie code.

### 实现页面间的跳转/
This directory provides a comprehensive technical overview of implementing page navigation within HarmonyOS applications that utilize a hybrid architecture combining ArkTS and Cangjie. It addresses the specific challenges developers face when routing between these two distinct language environments, which do not share a direct router connection. The documentation covers critical scenarios including standard forward navigation using the native router module and the complex interoperability required for backward navigation. Key topics include the utilization of `router.pushUrl`, the application of Cangjie-ArkTS interop macros for function registration, and the management of cross-language callbacks. This guide is specifically tailored for developers working on mixed-language applications who need to bridge routing capabilities and ensure seamless user flow between ArkTS and Cangjie components.
