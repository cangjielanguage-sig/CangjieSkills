# 配置文件标签

This directory contains technical documentation regarding configuration file tags used in application development, specifically focusing on the `module.json5` structure within HarmonyOS and OpenHarmony environments. It covers essential definitions for module properties, component behaviors, deployment settings, and packaging options. Key topics include module identification, permission management, process isolation, and HAP file attributes. These reference guides are designed for software developers and system architects who need to accurately configure application modules, manage dependencies, and ensure proper functionality across different device types. Prerequisite knowledge of JSON5 syntax is recommended.

## Detailed Description

### 配置文件标签_1.md
This document serves as a reference guide detailing the specific tags and structure used within the module.json5 configuration file. The content focuses on a comprehensive table (Table 1) that lists and explains the various configuration tags available for defining module properties. Key information includes the definitions and descriptions of each tag, enabling developers to correctly configure application modules and define their behaviors. Intended for software developers and system architects working with this specific framework, this reference material requires prerequisite knowledge of JSON5 syntax and application configuration concepts.

### 配置文件标签_2.md
This document serves as a technical reference guide for configuring Module-level attributes within application development, specifically for HarmonyOS or OpenHarmony systems. It provides a detailed table of properties including module identification, entry points, deployment settings, and component definitions. Key information covers data types, optionality, and constraints for tags such as name, type, deviceTypes, abilities, and requestPermissions. It also explains advanced features like process isolation modes and installation-free characteristics. This resource is intended for developers who need to accurately structure their application modules to ensure proper functionality, installation, and permission management across different device types.

### 配置文件标签_3.md
This document serves as a technical reference for specific configuration tags used in HarmonyOS HAP (Harmony Ability Package) files. It details attributes such as build hash generation for OTA upgrades, native library compression and isolation, file context menus for PC devices, URL query schemes, and application environment variables. Key information includes the logic for preventing .so file conflicts via libIsolation and the API version 17 requirements for UIAbility redirection using delegator fields. Most tags are optional with specific default values. This reference is intended for HarmonyOS developers configuring module-level behaviors, packaging options, and startup logic within their application projects.
