This directory provides comprehensive API reference documentation for the `TransitionEffect` class within the ArkUI framework, tailored for developers using the Cangjie language. It focuses on defining and managing transition effect types for component appearance and disappearance. The content covers class structures, static constants, and methods for combining effects, alongside specific animation parameters like move, rotate, and scale. It addresses complex scenarios such as animation precedence hierarchies, subtree deletion, and asymmetric transitions. This resource is essential for UI developers seeking to implement dynamic, polished entry and exit animations in their applications.
