This directory contains the essential API reference documentation for the `cj-apis-metadata` project, specifically focusing on the `ohos.metadata` module within the Cangjie programming language framework. It is a technical resource dedicated to explaining the mechanisms for handling metadata associated with application modules and abilities in the HarmonyOS ecosystem. The documentation covers the structural definition of the `Metadata` class, the required import statements, and step-by-step usage instructions tailored for Cangjie template projects. Key concepts include the management of metadata properties such as name, value, and resource descriptors. This directory is highly suitable for HarmonyOS developers who are actively using the Cangjie language and need to understand how to retrieve and manipulate metadata via `getBundleInfoForSelf` using specific bundle flags. It assumes the reader has a working knowledge of application context and bundle management.
