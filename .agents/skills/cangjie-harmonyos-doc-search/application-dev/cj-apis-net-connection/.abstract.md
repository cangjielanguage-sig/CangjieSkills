This directory serves as a comprehensive technical resource for the `cj-apis-net-connection` module, focusing on network connectivity management within the HarmonyOS ecosystem. It is specifically tailored for developers utilizing the Cangjie programming language, providing detailed API references for the `ohos.net.connection` module. The content covers a wide array of essential networking tasks, including real-time connection monitoring, dynamic property configuration, DNS resolution processes, and proxy management. By offering classes for network handles, capabilities, and connection events, this documentation enables developers to query network states and manage application-specific bindings effectively. It is an indispensable guide for Cangjie developers aiming to create robust, network-aware applications that can seamlessly handle network transitions and maintain high connectivity standards in diverse HarmonyOS environments.
