This directory contains essential API reference documentation for the Cangjie language's `SubProcess` class and related functions, designed to assist developers in managing child process operations. It covers the inheritance hierarchy from the `Process` class and details the properties for accessing standard input, output, and error streams. A significant focus is placed on the deprecation of legacy stream properties in favor of new pipe-based attributes. The documentation also explains process lifecycle management, specifically the `wait` function for handling exit codes and timeouts, and the `waitOutput` function for retrieving execution results. Critical advice regarding stream redirection to prevent deadlocks and warnings about handling large output streams are included. This content is suitable for Cangjie developers involved in system programming, process control, and I/O stream management who need to handle subprocess execution and exception handling effectively.
