# class_Fuzzer

This directory contains API reference documentation for the `Fuzzer` class within the Cangjie language fuzzing framework. It covers the creation, configuration, and execution of automated fuzzing tools, including constructor overloads, runtime argument management, and target function definition. Key features include support for `Array<UInt8>` or `FuzzDataProvider` inputs, debug data toggling, and fake coverage management to sustain processes. This documentation is suitable for Cangjie developers and security engineers looking to implement robust automated testing and security analysis with precise control over fuzzing behavior and feedback mechanisms.
