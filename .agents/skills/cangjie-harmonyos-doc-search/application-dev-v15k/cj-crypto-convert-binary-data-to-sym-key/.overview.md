# cj-crypto-convert-binary-data-to-sym-key

This directory serves as a specialized technical resource for Cangjie developers working with the CryptoArchitectureKit. It focuses on the precise mechanism required to transform external binary data into symmetric key objects (SymKey), a common requirement for integrating with existing cryptographic systems. The guide provides in-depth coverage for two specific algorithms: 3DES (192-bit) and HMAC. Through detailed step-by-step instructions and practical Cangjie code examples, users will master the core workflow, which involves encapsulating binary data into a DataBlob, initializing a SymKeyGenerator via `createSymKeyGenerator`, performing the conversion using `convertKey`, and retrieving the final key with `getEncoded`. This documentation is particularly suitable for developers tasked with importing legacy key material to facilitate secure operations such as encryption and signing within their Cangjie applications.

### cj-crypto-convert-binary-data-to-sym-key.md

This technical guide explains how to convert external binary data into symmetric key objects (SymKey) within the Cangjie programming language's CryptoArchitectureKit. It details the process for two specific algorithms: 3DES (192-bit) and HMAC, providing step-by-step instructions and Cangjie code examples for each. The core workflow involves encapsulating binary data into a DataBlob, creating a SymKeyGenerator using `createSymKeyGenerator`, converting the data via `convertKey`, and retrieving the result with `getEncoded`. This tutorial targets Cangjie developers who need to import existing key material for cryptographic operations like encryption or signing. It serves as an essential reference for ensuring correct key management and utilization in secure software development.
