This directory contains API reference documentation for the HarmonyOS accessibility module (ohos.accessibility) specifically designed for the Cangjie programming language. It covers a comprehensive range of barrier-free features including accessibility application metadata, gesture recognition, caption styling, event handling, and window management. The documentation details classes, enums, and functions necessary for implementing services like screen readers, touch guides, and closed captioning. It is intended for system developers and application engineers working on accessibility features who require technical specifications for system capabilities starting from API version 19.
