This directory provides comprehensive guidelines for declaring and managing application permissions in HarmonyOS. It details the technical configuration required within the `module.json5` file, including tag structures and attributes like `name`, `reason`, and `usedScene`. Additionally, it offers style standards for drafting user-facing permission request reasons to ensure compliance and clarity. Key concepts include `user_grant` permissions, multilingual support, and app store validation prerequisites. This resource is designed for HarmonyOS developers seeking to implement robust permission management and ensure their applications meet platform authorization requirements.
