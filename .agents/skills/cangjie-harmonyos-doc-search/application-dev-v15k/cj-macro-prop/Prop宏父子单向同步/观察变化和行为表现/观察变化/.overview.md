# 观察变化

This directory provides a comprehensive technical overview of change observation mechanisms within the Cangjie programming language and ArkUI state management. It details how specific decorators, such as `@Prop`, interact with various data structures—including primitive types, structs, classes, arrays, and collections—to detect and synchronize changes. The documentation highlights critical distinctions between value and reference observation, particularly regarding internal mutations versus whole assignments. It also addresses specific behaviors of collections like HashSet and ObservedArray, clarifying exactly when updates trigger UI refreshes. This resource is designed for Cangjie and ArkUI developers seeking to master reactive programming patterns, optimize component state updates, and understand the nuanced limitations of observable data structures in their applications. Mastering these concepts is crucial for building responsive and efficient user interfaces.

## Detailed Description

The following files provide in-depth technical guidance on specific aspects of the observation system.

### 观察变化_1.md
This technical guide details the change observation mechanisms of the @Prop decorator in Cangjie state management. It covers behavior for primitive types, structs, classes, arrays, and collections, alongside synchronization rules with @State. Key takeaways include that @Prop detects value changes in primitives and whole assignments in structs, while classes require @Observed and @Publish for internal updates. Standard arrays only detect whole replacement, whereas ObservedArray tracks item modifications. The document explains one-way synchronization from parent @State variables without modifying the source. Intended for ArkUI developers, this reference ensures proper implementation of reactive data binding and component state updates.

### 观察变化_2.md
This document serves as a technical guide illustrating the behavior of observing changes within a HashSet in the Cangjie programming language. It specifically addresses the initialization of a HashSet containing Int64 values and demonstrates the usage of the add method. The key information highlights a critical limitation: internal modifications to the HashSet, such as adding elements, cannot be perceived by the observation mechanism. This implies that state observation relies on reference changes rather than internal content mutation. The target audience includes Cangjie developers working with reactive state management or observable data structures who need to understand the nuances of tracking collection updates.

Keywords: Cangjie, HashSet, observation, state management, reactive programming, collection mutation.
