# application-test

This directory serves as a comprehensive repository for application testing resources, specifically designed for the Cangjie programming language and the OpenHarmony ecosystem. It provides essential documentation for the Test Kit service, covering everything from high-level service overviews to detailed automated testing framework guidelines. Key topics include unit testing, UI testing, and the `cj-arkxtest` framework implementation. This collection is ideal for developers and quality assurance engineers seeking to standardize their testing workflows, enhance code quality, and leverage automated tools for efficient application validation within the Cangjie environment.

As a feature description for the Beta phase, it covers the complete process from service overview to specific testing framework operations, helping users understand how to use this tool for standardized application testing. This directory is particularly suitable for developers who need to perform application development and testing. ### cj-arkxtest-guidelines/
This directory serves as a comprehensive resource for the `cj-arkxtest` framework, specifically tailored for the Cangjie programming language within the OpenHarmony ecosystem. It provides essential guidelines for implementing automated testing, covering the necessary protocols and standards developers need to follow to ensure effective testing practices.

### cj-test-kit-overview/
This directory contains the overview documentation for the Cangjie language Test Kit automated testing framework, aiming to provide developers with a comprehensive unit testing and UI testing solution. The documentation details the core capabilities of unit testing, including case definition, assertion interfaces, preset cleanup actions, and multiple execution modes. It also covers key functions of UI testing, such as control finding, UI and window operation simulation, Shell command simulation, and popup monitoring. This document emphasizes the framework's support for automated script writing and the convenient viewing of test results. It is suitable for Cangjie language developers to read and use for guiding their functional verification and the setup of automated testing processes.
