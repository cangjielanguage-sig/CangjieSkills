### 快捷键使用注意事项.md 快捷键使用注意事项.md
本文档旨在阐述ArkUI框架中快捷键的使用规则、响应逻辑及限制条件，帮助开发者正确实现自定义键盘交互。主要涵盖快捷键处理逻辑（如组件状态、焦点、冲突解决）、禁止绑定的系统快捷键列表以及系统预置按键事件的优先级说明。关键点包括快捷键优先于OnKeyEvent、隐藏组件仍可响应而禁用组件不可、重复快捷键仅首个节点生效，且系统保留键（如Alt+F4）不可覆盖。这是一份面向ArkUI应用开发者的参考文档，读者需具备组件事件处理和窗口焦点管理的基础知识。
