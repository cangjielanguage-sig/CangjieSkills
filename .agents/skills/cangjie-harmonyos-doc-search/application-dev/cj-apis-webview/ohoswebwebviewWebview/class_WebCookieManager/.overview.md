# class_WebCookieManager

This directory contains API reference documentation for the `WebCookieManager` class in the Cangjie language, part of the ArkWeb framework. It covers comprehensive cookie management functionalities, including clearing cookies, configuring cookie strings, checking existence, fetching values, and managing permissions for both standard and third-party cookies. Key features include support for incognito mode, error handling, and system capability requirements. This documentation is suitable for Cangjie developers and application engineers working with WebView components who need to implement robust web data persistence, privacy controls, and session management within their applications.

## Detailed Description

### class_WebCookieManager_3more.md class_WebCookieManager_3more.md
This document provides API reference documentation for the Cangjie language's WebCookieManager class, designed to control cookie behavior within Web components. It covers the class definition and two primary static methods: clearAllCookies, which removes all cookies with an optional incognito mode parameter, and clearSessionCookie, which specifically targets session cookies. Key information includes system capability requirements, version details (starting from version 22), and code examples demonstrating usage with error handling. The documentation highlights that a single WebCookieManager instance is shared across all Web components in an application. This reference is intended for Cangjie developers utilizing the ArkWeb kit to manage web data persistence and privacy.

### static_func_configCookieString_String_Bool.md static_func_configCookieString_String_Bool.md

The content details the function signature, system capabilities, and parameters including URL, value, and an optional incognito mode flag. Key information highlights that the value must follow the Set-Cookie HTTP header format, cookies are saved periodically to disk, and specific error codes are thrown for invalid inputs. The document includes a code example demonstrating usage and exception handling, targeting developers implementing webview cookie management.

### static_func_isCookieAllowe_4more.md static_func_isCookieAllowe_4more.md
This API reference document outlines static methods within the WebCookieManager class for managing cookie permissions in a Cangjie-based web environment.
