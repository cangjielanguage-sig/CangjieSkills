# 非首次渲染

This directory focuses on advanced rendering techniques for dynamic lists in the ArkUI framework using the Cangjie programming language. It specifically addresses "non-initial rendering" scenarios, covering how to efficiently update, swap, add, delete, and modify data within a LazyForEach component without causing unnecessary full reloads. Key topics include data source management, notification mechanisms like `notifyDataChange`, and performance optimization using `@Observed` and `@ObjectLink`. This resource is suitable for developers building complex, responsive user interfaces who need to master granular UI updates and data synchronization in Cangjie applications.

## Detailed Description

### 交换数据.md 交换数据.md
This tutorial demonstrates how to implement data swapping functionality within a list using the Cangjie programming language and ArkUI framework. The document covers the implementation of a custom MyDataSource extending BasicDataSource and the usage of LazyForEach for dynamic rendering. Key takeaways include the moveData method which swaps data elements and triggers notifyDataMove to notify the UI, allowing LazyForEach to efficiently swap child components without full reloading. The example illustrates a click-based interaction where selecting two items exchanges their positions. This guide is intended for developers with prior knowledge of Cangjie syntax and ArkUI components who need to handle complex list data manipulations.

### 改变单个数据.md 改变单个数据.md
This tutorial demonstrates how to implement and trigger updates for a single data item within a LazyForEach component using the Cangjie framework. The content covers the implementation of a custom MyDataSource class extending BasicDataSource, focusing on data manipulation methods like push, delete, move, and change. Key takeaways include the specific workflow where clicking a list item calls the changeData method, which updates the data array and invokes notifyDataChange to signal the LazyForEach to rebuild the corresponding child component. This guide is intended for Cangjie developers building dynamic user interfaces who need to understand the data notification mechanism for efficient UI updates.

### 改变多个数据.md 改变多个数据.md
This tutorial illustrates how to modify multiple data items and trigger a reload in a LazyForEach component using the Cangjie language. It covers the implementation of a custom BasicDataSource, methods for data manipulation like modifyAllData, and the interaction between data changes and UI updates. Key takeaways include understanding that calling notifyDataReload forces LazyForEach to rebuild nodes by comparing keys, utilizing caching for matches and recreating for differences. This guide is intended for developers working with dynamic lists in Cangjie-based UI frameworks.

### 改变数据子属性.md 改变数据子属性.md
This technical guide explains how to efficiently update sub-properties of data items within a LazyForEach list to improve rendering performance. It covers the performance limitations of standard LazyForEach refreshing and introduces the @Observed and @ObjectLink deep observation mechanism. The document provides a Cangjie code example demonstrating how to implement a data source and child component so that only the specific UI element updates when a property changes, avoiding the costly reconstruction of the entire ListItem. This resource is intended for developers building complex list interfaces who need to optimize UI refresh rates and minimize unnecessary component rebuilding.

### 非首次渲染_3more.md 非首次渲染_3more.md
This technical guide explains how to manage dynamic updates for the LazyForEach component during non-initial rendering cycles using the Cangjie language. The document covers two primary scenarios: adding data and deleting data from a custom data source. Key takeaways include the necessity of calling specific notification methods, such as notifyDataAdd and notifyDataDelete, within the data source logic. These methods trigger listener interfaces that instruct LazyForEach to create or destroy child components at specific indices. Intended for ArkUI developers, this tutorial provides code examples demonstrating how to synchronize data changes with UI updates efficiently.

### 精准批量修改数据/
This directory focuses on techniques for performing precise batch data modifications within the ArkUI framework using the Cangjie language. It covers the implementation of granular updates for LazyForEach components, utilizing specific operation classes like DataMoveOperation, DataExchangeOperation, and others to map array changes efficiently. Key topics include manual data manipulation, direct array assignment, and the `notifyDatasetChange` method to optimize list rendering performance. This resource is suitable for UI developers and engineers looking to enhance application responsiveness and handle complex data updates without full UI reconstruction.
