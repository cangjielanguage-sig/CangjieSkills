This directory contains API reference documentation for the `MetadataOutput` class within the Cangjie CameraKit framework. It focuses on managing metadata streams, including registering and unregistering listeners for detected metadata objects and error handling. Key topics include lifecycle management methods like start, stop, and release, as well as specific callback constraints. This documentation is intended for developers building camera applications who need to handle metadata events and manage camera output resources using the Cangjie programming language.
