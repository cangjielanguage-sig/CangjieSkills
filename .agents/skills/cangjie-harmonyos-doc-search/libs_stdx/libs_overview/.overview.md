# libs_overview

This directory provides a comprehensive overview of the Cangjie programming language's extension libraries, specifically focusing on the `stdx` ecosystem. It serves as a central hub for developers looking to access advanced functionalities beyond the standard library, such as cryptographic operations, network protocols, data compression, and Aspect-Oriented Programming (AOP). The content is tailored for Cangjie developers who need to integrate specialized modules, offering guidance on API usage, build environment configuration, and OS-specific linking for Linux, macOS, and Windows. It ensures users can effectively manage dependencies and compile projects requiring these external libraries, which are not distributed with the compiler by default. This documentation is crucial for anyone looking to extend the capabilities of their Cangjie applications with robust, domain-specific tools, providing the necessary bridge between the core language and specialized system-level functionalities.

## Detailed Description

The following section details the contents of the primary subdirectory within this overview. It contains the essential documentation required to leverage the full power of the Cangjie language's external libraries.

### 仓颉编程语言扩展库_API/

This directory serves as the central repository for the API documentation and technical usage guidelines of the Cangjie programming language's extension library, known as stdx. It provides a structured overview of domain-specific packages designed to complement the standard library, covering advanced functionalities such as Aspect-Oriented Programming (AOP), cryptographic operations, data compression, network protocols, and unit testing. Additionally, it offers critical instructions for developers on how to configure build environments, manage dependencies, and handle OS-specific linking for Linux, macOS, and Windows. This resource is essential for Cangjie developers who need to integrate specialized libraries like `crypto`, `net`, and `encoding` into their software projects, ensuring they understand both the available APIs and the compilation requirements necessary to utilize these external modules effectively. Since these libraries are not distributed with the compiler, this documentation is vital for guiding users through the separate download and integration process.
