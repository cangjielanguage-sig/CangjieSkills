# RSAECBPKCS1_V1_5

本目录详细介绍了在仓颉编程语言环境下，如何利用HarmonyOS通用密钥库（HUKS）实现基于RSA算法的安全通信。具体涵盖了ECB模式配合PKCS1_V1_5填充标准的完整实现路径，包括密钥对的生成、参数配置、数据加密与解密的核心逻辑，以及密钥资源的销毁管理。核心关键词涵盖HUKS、RSA加密、PKCS1_V1_5、仓颉语言、密钥生命周期管理。该资料特别适合致力于HarmonyOS应用安全开发的仓颉语言使用者，旨在帮助开发者快速掌握HUKS API的调用方法，构建安全可靠的数据保护机制。

## 详细说明

### RSAECBPKCS1_V1_5_1.md RSAECBPKCS1_V1_5_1.md

本文档旨在演示如何在仓颉语言中使用HUKS通用密钥库进行RSA/ECB/PKCS1_V1_5模式的加密操作。文档主要包含密钥属性配置、密钥生成及数据加密的代码示例。关键信息包括定义了生成、加密和解密的参数集（如2048位密钥、PKCS1_V1_5填充），并展示了通过generateKeyItem、initSession和finishSession完成密钥生成与加密流程的完整步骤。该文档适用于需要在HarmonyOS应用开发中集成HUKS加密服务的仓颉开发者，提供了具体的API调用参考。

### RSAECBPKCS1_V1_5_2.md RSAECBPKCS1_V1_5_2.md

本文档旨在演示如何使用HUKS框架实现RSA解密及密钥删除操作，重点展示PKCS1_V1_5填充模式下的具体实现流程。文档主要包含两个代码场景：模拟解密场景（DecryptData函数）和模拟删除密钥场景（DeleteKey函数）。关键信息包括通过initSession和finishSession完成基于密钥别名的分段解密，以及利用deleteKeyItem清理密钥资源，强调了HuksOptions参数的配置与使用。该文档适用于HarmonyOS或OpenHarmony开发者，要求具备基础的安全编程知识，用于指导密钥生命周期管理及数据解密功能的开发。
