This directory serves as a comprehensive repository for technical specifications regarding symmetric key encryption and decryption algorithms. It primarily focuses on the implementation details of widely used cryptographic standards, specifically 3DES, SM4, and AES. The content covers essential operational aspects such as supported modes of operation (including ECB, CBC, and GCM), standard padding schemes (PKCS5 and PKCS7), and the precise syntax for parameter configuration. Furthermore, the documents offer critical guidance on technical constraints like key lengths, block sizes, and specific API requirements, notably for API version 12 and above. This resource is specifically tailored for developers and system architects who are integrating cryptographic functions using the CryptoArchitectureKit or similar libraries, providing them with the necessary knowledge to understand algorithm configurations and string parameter formats for securely instantiating cryptographic instances.
