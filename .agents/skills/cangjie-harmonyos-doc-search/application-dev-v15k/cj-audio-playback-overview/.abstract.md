This directory serves as a centralized resource for understanding audio capabilities within the Cangjie programming environment. It provides a comprehensive development guide designed to assist developers in selecting and implementing the correct audio playback APIs based on specific project needs. The content thoroughly covers four distinct audio methods: AudioRenderer for high-fidelity PCM output, AudioHaptic for synchronized vibration experiences, AVPlayer for handling standard media formats, and SoundPool for low-latency sound effects. Beyond just listing APIs, the document outlines specific use cases, clearly distinguishing between requirements like game sound effects and media streaming, while also noting current system limitations such as the lack of support for background or screen-off playback. This resource is essential for Cangjie developers aiming to optimize development efficiency and ensure high-quality user experiences by precisely matching technical requirements with the appropriate audio tools.
