# 组件属性

本目录包含ArkUI框架中使用仓颉（Cangjie）语言开发的文本输入组件属性API参考文档。内容涵盖了文本输入的全方位配置，包括基础样式定制（如字体、颜色、对齐方式）、交互行为控制（如光标、键盘类型、焦点管理）以及输入限制规则（如长度限制、过滤规则）。所有API均支持链式调用，起始版本为API 22。这些文档适用于需要精细化管理UI组件外观与逻辑的ArkUI应用开发者，旨在帮助构建高效、美观的用户输入界面。

### func_styleTextInp_2more_370932ad.md func_styleTextInp_2more_370932ad.md
本文档提供了ArkUI框架中使用Cangjie语言设置文本输入组件样式的API参考。主要包含两个函数接口：`style`用于定义文本输入样式，`textAlign`用于设置文本的水平对齐方式。关键信息包括这两个函数均返回`This`以支持链式调用。`style`函数接受`TextInputStyle`枚举参数，默认值为Default；`textAlign`函数接受`TextAlign`枚举参数，默认值为Start。两者均系统能力为ArkUI.Full，起始版本为22。面向使用Cangjie语言开发ArkUI应用的开发者，旨在帮助其自定义文本输入框的外观和布局。
