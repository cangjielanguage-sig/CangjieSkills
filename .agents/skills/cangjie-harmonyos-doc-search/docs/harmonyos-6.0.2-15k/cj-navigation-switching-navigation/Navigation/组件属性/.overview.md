# 组件属性

This directory contains API reference documentation for configuring properties of the Navigation component within the ArkUI framework using the Cangjie language. It covers a wide range of functionalities including menu and toolbar configuration, title customization, layout positioning, safe area handling, and state recovery mechanisms. These documents provide detailed parameter definitions, usage constraints, and system capability requirements for developers building robust navigation interfaces. Suitable for software engineers and UI developers utilizing Cangjie to implement complex navigation behaviors and styling in their applications.

### func_menusArrayltNavigatio_4more.md
This document provides API reference documentation for configuring navigation menus, title modes, and toolbars within the ArkUI framework using the Cangjie language. It details four primary functions: `menus` (supporting both array and builder inputs), `titleMode`, and `toolbarConfiguration`. Key information includes specific display limits, such as a maximum of 3 menu icons in portrait mode and 5 toolbar icons, with overflow items automatically moved to a "More" menu. Additionally, it highlights restrictions on modifying icon sizes and effects via `SymbolGlyphModifier`. This technical reference is intended for developers implementing navigation UI components, requiring knowledge of Cangjie syntax and ArkUI system capabilities.

### func_minContentWidthLength_3more.md
This document serves as API reference material for configuring Navigation components in the ArkUI framework using the Cangjie language. Key information includes parameter definitions, default values like 360.vp, and specific usage constraints such as the requirement for full-screen Navigation to apply status bar styles. The documentation highlights interactions between navigation layout ranges and system event interception. Intended for ArkUI developers, this guide requires knowledge of Cangjie syntax and UI layout principles to effectively manage navigation behavior and system UI integration.

### func_recoverableBool_3more.md
This document serves as API reference documentation for the Cangjie ArkUI Navigation component, detailing three specific configuration functions. Key information includes the requirement to set a Navigation ID for recovery functionality and the caveat that non-serializable data is lost during restoration. This guide is intended for developers utilizing ArkUI to implement robust navigation state management and refined UI interactions.

This guide targets software developers using the Cangjie language to construct user interfaces, specifically those implementing navigation components and requiring system capability integration.
