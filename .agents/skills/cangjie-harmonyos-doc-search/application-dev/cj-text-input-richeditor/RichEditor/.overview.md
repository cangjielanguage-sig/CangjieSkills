# RichEditor

This directory contains comprehensive documentation for the ArkUI RichEditor component, designed for HarmonyOS developers using the Cangjie language. It covers the implementation of mixed graphics and text interactive editing, including API references, component properties, event handling, and practical code examples. Key topics include text styling, image insertion, custom keyboards, and selection management. These resources are suitable for developers building complex user interfaces requiring advanced text manipulation and input method customization in version 22+ system environments.

## Detailed Description

### RichEditor_5more.md RichEditor_5more.md
This document provides API reference documentation for the RichEditor component within the ArkUI framework, designed for developers implementing mixed graphics and text interactive editing. It details the module import process, component initialization via the RichEditorController, and supported general attributes and events. Key information includes the mandatory controller parameter, full support for general properties with specific exceptions regarding alignment and border images, and the component's current Beta status. This guide is intended for Cangjie language developers building complex user interfaces.

### 示例代码.md 示例代码.md
This document provides a Cangjie code example demonstrating the implementation and configuration of the ArkUI RichEditor component for HarmonyOS applications. The content covers the main EntryView class structure, a custom keyboard builder using ForEach, and the build method defining the UI layout. Key information includes utilizing RichEditorController for text and image manipulation, such as adding text spans, inserting images, and updating paragraph styles. It also illustrates binding custom keyboards, handling selection menus, and managing lifecycle events like onReady and onSelect. This example targets developers seeking practical guidance on advanced text editing features in Cangjie.

### 组件属性.md 组件属性.md
This document serves as an API reference for configuring component properties within the ArkUI framework using the Cangjie language. It details three primary functions: bindSelectionMenu, copyOptions, and customKeyboard. Key information includes how bindSelectionMenu enables custom selection menus with specific content and response types, while copyOptions manages text copy and paste capabilities, triggering selection menus on long press. Additionally, customKeyboard allows developers to replace the system input method with a custom UI component that overlays the interface and intercepts gestures. The target audience is ArkUI developers seeking to implement advanced text editing and input interactions.
