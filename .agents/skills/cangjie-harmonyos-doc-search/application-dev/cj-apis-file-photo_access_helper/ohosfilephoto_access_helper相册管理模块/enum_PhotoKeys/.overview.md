# enum_PhotoKeys

This directory provides comprehensive API reference documentation for the `PhotoKeys` enum within the Cangjie programming language. It is designed to assist developers in accessing and retrieving metadata for photo and video files. The content covers a wide range of file attributes, including physical dimensions, file sizes, timestamps, and display names, while also detailing system capabilities and version-specific requirements. This documentation is essential for developers building media applications or system-level file management tools that require precise querying of file attributes using data predicates and understanding of operator overloads.

### Size_8more.md Size_8more.md
This document provides API reference documentation for the Cangjie language, detailing the PhotoKeys enum used to access photo file metadata. It defines specific keys for file attributes such as Size, ThumbnailSize, Title, Uri, and Width, along with operator overloads for equality comparison and a toString method. Key information includes the system capability requirement SystemCapability.FileManagement.PhotoAccessHelper.Core and specific usage notes for the Uri field during queries. Intended for developers working with file management features on system version 22, this reference requires familiarity with Cangjie syntax and data predicates.

### enum_PhotoKeys_17more.md enum_PhotoKeys_17more.md
This document serves as an API reference for the PhotoKeys enum in the Cangjie language, defining keys used to retrieve metadata for photo and video files. It details specific enum members such as BurstKey, CoverPosition, DateAdded, DisplayName, and LcdSize, explaining their functionality, units, and constraints. Key information includes that the enum inherits from ToString, supports the SystemCapability.FileManagement.PhotoAccessHelper.Core capability starting from version 22, and notes that millisecond timestamp fields do not support sorting. This reference is intended for developers building applications that require access to detailed media file attributes and system-level file management features.
