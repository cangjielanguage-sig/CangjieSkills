This directory serves as a comprehensive educational resource focused on the Mock framework basics, specifically designed for the Cangjie programming language ecosystem. It provides a deep dive into essential testing concepts, clearly explaining the nuances between spy and mock objects, the procedures for their instantiation, and the critical compilation configurations required to enable mocking, such as the `--mock=on` flag. Beyond the basics, it explores the Configuration API, offering guidance on defining stub signatures, implementing parameter matchers, and setting up advanced behaviors. This documentation is ideally suited for Cangjie developers and QA engineers who are dedicated to isolating units of code, effectively simulating dependencies, and conducting rigorous, precise unit testing to enhance software quality and maintainability.
