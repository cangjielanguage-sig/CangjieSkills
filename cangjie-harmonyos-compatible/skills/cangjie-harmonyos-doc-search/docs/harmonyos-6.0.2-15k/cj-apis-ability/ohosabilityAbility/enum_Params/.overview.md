# enum_Params

This directory contains comprehensive API reference documentation for the `Params` enum within the HarmonyOS Ability framework, specifically designed for developers using the Cangjie programming language. It provides detailed specifications for parameter keys utilized in Want operations, covering essential aspects such as display modes, subpackage management, cross-device migration, and inter-component communication. The documentation includes definitions for system capability keys, utility functions for enum manipulation, and specific constants for navigation and metadata handling. By detailing the inheritance from interfaces like Equatable and ToString, this resource is suitable for HarmonyOS application developers seeking to configure ability runtime behaviors, manage page stacks, and implement robust inter-process communication mechanisms. The files included cover both specific key definitions and broader utility functions for the Params enum.
