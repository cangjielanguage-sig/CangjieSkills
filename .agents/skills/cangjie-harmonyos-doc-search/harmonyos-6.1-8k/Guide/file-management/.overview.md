# file-management

This directory provides comprehensive documentation for file management within the HarmonyOS and OpenHarmony ecosystems, specifically tailored for developers using the Cangjie programming language. It covers the Core File Kit, detailing application sandbox isolation, file access interfaces, and inter-app file sharing mechanisms. Key topics include understanding the app file system structure, managing user files, and debugging file operations using the hdc tool. This resource is suitable for developers seeking to implement secure data storage, handle file permissions, and facilitate cross-application data exchange in their applications.

## Detailed Description

### [1] README_zh
This directory contains the Chinese navigation index document for the Core File Kit, aiming to provide developers with a structured overview of file management services. The content primarily covers two core areas: application file management (including sandbox directory mechanisms, Cangjie language access interfaces, and file sharing functions) and user file management. All features are currently Beta and undergoing continuous iteration. This document is suitable for developers handling application and user file management, particularly those using the Cangjie language, helping them understand application sandbox concepts, file access methods, and inter-app file sharing mechanisms.

### [2] cj-app-file-access
This directory serves as a comprehensive technical resource for developers working on HarmonyOS and OpenHarmony applications, specifically focusing on file access and management using the Cangjie programming language. It details the utilization of relevant interfaces and methods to handle file operations effectively within the development environment.

### [3] cj-app-file-overview
This directory contains core documentation regarding the application file system, aiming to comprehensively expound on the definition of application files, their storage structure, and their close relationship with the application sandbox environment. The content covers the hierarchical structure of application file directories, components of the application sandbox directory, and strict file access permissions and storage specifications. The core point is to explain how application data is stored in exclusive directories, how the sandbox limits the app's visibility, why system files are read-only, and the restriction mechanism where apps can only write to specific subdirectories. This is a conceptual guide ideal for developers needing to understand the app file system architecture and master data isolation and security storage specifications.

### [4] cj-app-sandbox-directory
This directory serves as a comprehensive guide to the OpenHarmony application sandbox, focusing on the critical isolation mechanisms and security protection principles that govern app behavior. It provides in-depth coverage of file access specifications, ensuring developers understand the boundaries and security constraints of the application environment.
