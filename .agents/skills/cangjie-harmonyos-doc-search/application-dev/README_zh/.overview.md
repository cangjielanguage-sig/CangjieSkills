# README_zh

This directory serves as a central hub for documentation related to the HarmonyOS development ecosystem, specifically focusing on the ArkUI framework and the Cangjie programming language. It provides access to resources for managing application windows, exploring Beta features of the ArkUI framework, and comprehensive guides for learning Cangjie. The content is tailored for software developers and system architects who are implementing window handling capabilities, evaluating experimental UI components, or mastering the Cangjie language for cross-platform development. Key topics include window stages, declarative UI, concurrency, and interoperability.

### ArkUI方舟UI框架Beta特性/
This directory contains comprehensive documentation for the Beta features of the ArkUI (Fangzhou UI) framework. It covers experimental functionalities, new declarative UI components, APIs, and integration guidelines designed for the testing phase. The content includes references for the Cangjie programming language, layout systems, navigation tools, animations, and error handling. It is suitable for software developers, system architects, and HarmonyOS developers looking to evaluate, implement, or explore upcoming capabilities within the ArkUI ecosystem.

### 学习仓颉语言/
This directory contains a comprehensive series of guides and tutorials for learning the Cangjie programming language, designed primarily for HarmonyOS ecosystem development. It covers a wide spectrum of topics ranging from introductory concepts and basic syntax to advanced object-oriented programming, concurrency, and interoperability with ArkTS and C. The resources are structured logically to help developers progress from foundational knowledge to mastering complex system features like metaprogramming and network programming. Suitable for software developers and programmers at all levels who wish to adopt or master the Cangjie language.
