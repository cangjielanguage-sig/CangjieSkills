# 层叠布局Stack

This directory provides comprehensive documentation on the Stack layout component within the Cangjie UI framework (ArkUI). It covers essential techniques for creating overlapping interfaces, managing component stacking order via Z-index, and configuring alignment modes. Key topics include layering sibling components, handling display hierarchy, and practical implementation scenarios such as card stacks or floating navigation bars. Included files offer both high-level overviews and specific guides on Z-order control. This resource is specifically designed for Cangjie developers and UI designers seeking to master complex, multi-layered interface layouts and enhance visual depth in HarmonyOS applications.

## Detailed Description

### Z序控制_2more.md
This guide explains how to manage the display hierarchy of sibling components within a Stack container using the zIndex attribute in Cangjie UI development. It covers the basic concept of Z-order, demonstrates default stacking behavior versus zIndex modification through code comparisons, and provides a practical scenario example for building complex layouts. Key takeaways include that higher zIndex values result in higher display levels, allowing smaller or earlier defined components to overlay larger ones. The document illustrates how to combine Stack with Flex layouts to create interfaces like app grids with floating navigation bars. This tutorial targets Cangjie developers looking to master layout layering and component stacking in HarmonyOS applications.

### 概述_3more.md
This document provides an overview and implementation guide for the StackLayout component within the ArkUI Cangjie framework. It covers the definition and use cases of the Stack container, a development layout example with code, and alignment configuration using the alignContent parameter. Key takeaways include that the layout allows child elements to overlap sequentially, with the last element covering the previous one, and supports nine alignment modes for positioning. This guide targets UI developers using the Cangjie language who need to create overlapping interface effects like advertisements or card stacks.
