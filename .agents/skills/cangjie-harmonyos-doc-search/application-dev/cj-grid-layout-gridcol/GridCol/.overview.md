# GridCol

This directory contains documentation for the GridCol component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the implementation of responsive grid layouts that must be nested within a GridRow container. Key topics include component constructors, attribute configuration (span, offset, order), and the GridColOptions class for handling device breakpoints. This resource is suitable for UI developers and software engineers looking to build flexible, adaptive user interfaces using Cangjie and ArkUI.

This API reference document defines the GridColOptions class used for configuring responsive grid column layouts in ArkUI applications using the Cangjie language. It details the class properties xs, sm, md, lg, xl, and xxl, alongside two constructor methods for initialization. Key information includes that these properties allow developers to specify column spans or offsets for different device breakpoints, with all fields being optional nullable integers. The constructors support setting individual breakpoint values or a universal value. This document is intended for UI developers implementing responsive design systems, requiring knowledge of the Cangjie language and ArkUI framework.

### 组件属性.md 组件属性.md
This document provides API reference documentation for grid layout properties within the Cangjie ArkUI framework. It details methods for configuring grid child components, specifically gridColOffset, order, and span. Each function supports overloads accepting either an optional Int32 or a GridColOptions object to handle responsive layout needs. Key information includes that gridColOffset adjusts positioning relative to previous items, order determines the visual sorting sequence, and span controls the number of occupied columns, with a span of 0 excluding the element from rendering. Intended for software developers, this reference requires familiarity with ArkUI grid systems and Cangjie programming to implement flexible user interfaces.
