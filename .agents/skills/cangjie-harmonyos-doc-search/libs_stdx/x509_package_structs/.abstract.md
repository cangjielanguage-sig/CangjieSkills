This directory serves as a comprehensive repository for API reference documentation regarding core data structures within the Cangjie Crypto and X.509 packages. It focuses on the fundamental building blocks required for implementing robust cryptographic operations, specifically handling X.509 certificates and related security artifacts. Key topics include binary encoding formats like DER and PEM, certificate extensions such as KeyUsage and ExtKeyUsage, and essential management structures like SerialNumber and VerifyOption. This documentation is primarily designed for Cangjie developers and security engineers who are developing low-level cryptographic libraries, SSL/TLS protocols, or identity management systems. It provides the necessary definitions to parse, validate, and generate secure data, ensuring that users can effectively manage digital identities and establish secure communication channels within their applications.
