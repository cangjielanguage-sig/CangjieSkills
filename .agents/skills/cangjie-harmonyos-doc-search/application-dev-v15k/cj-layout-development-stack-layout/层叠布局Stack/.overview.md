# 层叠布局Stack

This directory focuses on the Stack layout mechanism within the ArkUI framework using the Cangjie language. It covers the fundamental concepts of overlapping components, alignment strategies, and Z-order management to create layered interfaces. Key topics include the StackLayout component definition, the nine alignment modes available via alignContent, and zIndex manipulation for controlling display hierarchy. This resource is suitable for UI developers and HarmonyOS application builders looking to implement complex, multi-layered designs such as card stacks, navigation overlays, and advertisement displays.

### Z序控制_2more.md Z序控制_2more.md
This tutorial explains how to manage component display hierarchy within Stack containers using the zIndex property in Cangjie UI development. It covers the basic concept of Z-order, demonstrates default stacking behavior versus zIndex manipulation through code examples, and provides a practical scenario for building layered interfaces. Key takeaways include that higher zIndex values place components on top, overriding the default size-based stacking order where larger elements hide smaller ones. The document illustrates how to overlay UI elements like navigation bars over content grids. This guide targets Cangjie developers building HarmonyOS applications who need to implement complex, layered layouts.

Keywords: Z-order, zIndex, Stack container, Cangjie, UI layout, layering, HarmonyOS, component hierarchy.
