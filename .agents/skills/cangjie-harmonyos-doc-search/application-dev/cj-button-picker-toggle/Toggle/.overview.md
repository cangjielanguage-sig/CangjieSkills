# Toggle

This directory serves as a comprehensive technical resource for the ArkUI Toggle component, specifically tailored for the Cangjie programming language. It encompasses both detailed API reference documentation and practical implementation guides. The content thoroughly covers the creation, configuration, and styling of various toggle elements, including Switch, Checkbox, and Button types. Developers will find extensive information on component attributes such as selectedColor and switchPointColor, as well as event handling mechanisms like onChange callbacks. Additionally, the directory includes code examples demonstrating layout integration using Column and Flex structures. This material is primarily intended for application developers who are actively building user interfaces within the ArkUI framework and possess a foundational understanding of Cangjie syntax and UI development principles.

## Detailed Description

### Toggle_7more.md Toggle_7more.md
This document provides API reference documentation for the ArkUI Toggle component, designed for the Cangjie programming language. It details the creation and configuration of toggle switches, checkboxes, and status buttons. Main sections include module imports, initialization constructors, component-specific attributes like selectedColor and switchPointColor, and event handling through onChange callbacks. Key information highlights that only Button-type toggles support subcomponents and that the component allows extensive customization of active state colors. This technical guide targets application developers building user interfaces, who are expected to have prior knowledge of the ArkUI framework and Cangjie syntax.

### 示例代码.md 示例代码.md
This document provides a practical code example demonstrating how to configure and style the Toggle component within the ArkUI framework using the Cangjie language. The main topic covers implementing three distinct toggle types: Switch, Checkbox, and Button. Key information includes setting specific properties such as selected color, switch point color, and size, alongside implementing event handling through the onChange callback to log status changes. The example utilizes Column and Flex layouts to organize the components visually. This tutorial is intended for developers with prior knowledge of Cangjie and ArkUI who are looking to implement interactive toggle controls in their applications.
