# 音效管理

This directory provides comprehensive technical documentation for managing audio sound effects using the AudioKit framework in the Cangjie language. It covers two primary aspects: querying global audio effect modes associated with specific `StreamUsage` scenarios and managing effects for individual audio playback instances. Key concepts include `AudioStreamManager`, `AudioRenderer`, `AudioEffectMode`, and stream usage types. This content is designed for multimedia application developers who need to programmatically control audio playback effects, configure scene-specific audio modes, or query system capabilities for scenarios such as music playback.

## Detailed Description

### 全局查询音效模式.md 全局查询音效模式.md
This technical guide explains how to query global audio effect modes associated with specific StreamUsage scenarios. It covers obtaining the AudioStreamManager instance and querying audio effect information for specific usage types like music. Key takeaways include the prerequisite step of creating an AudioStreamManager via getStreamManager() and using getAudioEffectInfoArray() to retrieve effect data, with Cangjie code examples provided for implementation. Intended for audio application developers, this document helps ensure apps select appropriate audio modes for scenarios such as music playback.

### 播放实例音效管理.md 播放实例音效管理.md
This document serves as a technical guide for managing audio effect modes within an audio playback stream using the AudioKit framework in the Cangjie language. It covers creating an AudioRenderer instance, querying the current audio effect mode using getAudioEffectMode, and setting the mode using setAudioEffectMode. The document defines two primary modes: EFFECT_NONE to disable effects and EFFECT_DEFAULT to automatically load scene-specific effects based on the stream usage type. Code examples demonstrate configuration, error handling, and implementation steps. This tutorial targets application developers working with multimedia audio who need to programmatically control audio playback effects. Keywords: AudioKit, AudioRenderer, AudioEffectMode, StreamUsage, Cangjie, audio playback.

### 音效管理.md 音效管理.md
This document serves as a technical reference for managing audio sound effects, focusing on two core functionalities: playback instance management and global sound effect queries. The first section covers querying and setting effect modes for active audio playback streams, while the second section explains how to retrieve supported effect modes for specific usage scenarios defined by the StreamUsage enumeration. Key takeaways include the distinction between manipulating active streams and querying system capabilities. This guide targets developers working with the AudioKit API who need to implement or configure audio effects based on different stream usage contexts.
