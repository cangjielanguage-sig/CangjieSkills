This directory provides comprehensive API reference documentation for the `CurrentLocationRequest` class within the Cangjie language framework, specifically designed for HarmonyOS location services. It serves as a technical guide for defining parameters required to request current location information, covering the class structure, its public properties, and the constructor initialization logic. Developers will find detailed explanations of configuration parameters such as priority, scenario, maxAccuracy, and timeoutMs. The documentation also clarifies critical implementation details, including the dependency of maxAccuracy on location permissions, the precedence of scenario over priority, and recommended values for distinct use cases like navigation or daily life services. This resource is tailored for developers building location-aware applications who need a deep understanding of the SystemCapability.Location.Location.Core capabilities to effectively manage location requests and handle system permissions.
