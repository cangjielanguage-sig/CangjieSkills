This directory provides comprehensive API reference documentation for the Cangjie programming language's Context class within the HarmonyOS development environment. It focuses on context capabilities essential for abilities and applications, detailing how to access application information, manage resources, and interact with file system directories such as cache, database, and temporary storage. The documentation also covers the EventHub object for event handling and specific context management functions. Key topics include system capability requirements, version availability (starting from API 19), and error handling. This resource is designed for HarmonyOS developers using Cangjie to manage application runtime environments and system resources effectively.
