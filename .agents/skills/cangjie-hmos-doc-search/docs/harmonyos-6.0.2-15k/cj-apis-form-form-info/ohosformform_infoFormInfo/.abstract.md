This directory contains API reference documentation for the Cangjie programming language, specifically focusing on the `FormInfo` module within the HarmonyOS `SystemCapability.Ability.Form` framework. It covers data structures, enumerations, and classes essential for managing form (card) metadata, including dimensions, shapes, types, states, and filtering logic. Key components include the `FormInfo` class, `FormInfoFilter`, and various enums defining form attributes. This documentation is suitable for HarmonyOS developers using Cangjie who need to programmatically configure, filter, and manage widget properties and lifecycle states in their applications.
