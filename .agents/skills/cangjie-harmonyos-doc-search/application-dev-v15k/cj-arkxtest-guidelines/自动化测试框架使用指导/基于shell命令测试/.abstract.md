This directory contains technical documentation for performing automated UI testing and debugging on HarmonyOS/OpenHarmony systems using shell commands. It covers the `uitest` tool, enabling users to execute operations such as screen capturing, layout dumping, and complex UI simulations directly from the command line. Key topics include gesture recording, input simulation (clicks, swipes, text), and environment configuration. These resources are designed for developers and QA engineers seeking efficient workflows for rapid testing and interface validation, assuming prior setup of HDC environment variables and appropriate system permissions.
