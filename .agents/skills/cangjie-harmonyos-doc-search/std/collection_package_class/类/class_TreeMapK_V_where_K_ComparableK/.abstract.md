This directory provides comprehensive API reference documentation for the Cangjie programming language's `TreeMap<K, V>` class, specifically where keys implement the `Comparable` interface. It details a balanced binary search tree implementation of the `OrderedMap` interface, covering class definitions, inheritance hierarchies, and functional methods for ordered key-value storage. Key topics include constructors, data manipulation, iteration, and interface extensions for equality and string conversion. This resource is designed for Cangjie developers building efficient data structures for applications such as databases or caching systems.
