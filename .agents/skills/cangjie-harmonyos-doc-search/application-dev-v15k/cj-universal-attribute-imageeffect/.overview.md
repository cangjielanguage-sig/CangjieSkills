# cj-universal-attribute-imageeffect

The `cj-universal-attribute-imageeffect` directory serves as a comprehensive technical hub for the Cangjie ArkUI framework, specifically dedicated to the `ImageEffect` universal attribute. It provides extensive API reference documentation and implementation guides essential for applying sophisticated visual effects to UI components. The content covers a broad spectrum of image manipulation capabilities, ranging from basic color adjustments—such as contrast, saturation, and hue—to complex filters like blur, sepia, and grayscale. Furthermore, it delves into advanced rendering techniques, including spherical effects and pixel stretching, alongside critical performance optimization strategies like off-screen rendering and shadow batching. This documentation is specifically curated for HarmonyOS developers and UI designers who require precise parameters and type definitions to programmatically enhance component aesthetics and ensure high rendering efficiency in their Cangjie applications.
