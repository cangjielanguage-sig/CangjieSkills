# class_AVMetadata

This directory contains comprehensive API reference documentation for the `AVMetadata` class within the Cangjie programming language framework. It focuses on defining and managing audio and video metadata fields, covering both descriptive attributes like title, artist, and album, as well as technical specifications such as duration, sample rate, HDR type, and video dimensions. The documentation highlights system capabilities for metadata extraction and recording, noting version compatibility starting from API version 19. It distinguishes between read-only fields and those usable as input parameters for recording. This resource is suitable for multimedia developers looking to access, manipulate, or record media resources and properties in their Cangjie-based applications.
