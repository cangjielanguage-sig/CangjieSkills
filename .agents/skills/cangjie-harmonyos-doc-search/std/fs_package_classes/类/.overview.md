This directory contains API reference documentation for core file system classes in the Cangjie programming language. It covers essential components for managing file system entities, including hard links, symbolic links, directories, and standard files. The documentation details class definitions, static methods, instance properties, and exception handling for operations like creation, traversal, reading, and writing. It is suitable for Cangjie developers and software engineers who need to implement robust file I/O operations, manage system resources, or handle path manipulations within their applications.

## Detailed Description

### class_HardLink.md class_HardLink.md
This document serves as API reference for the HardLink class in the Cangjie language, detailing interfaces for managing file system hard links. It covers the class definition and two overloaded static methods named create, which accept either Path or String types. The create function establishes a new hard link pointing to an existing file without overwriting if the target exists. It specifies parameters for the new and existing paths and documents potential exceptions, including IllegalArgumentException for invalid inputs and FSException for operation failures. This reference guide targets software developers implementing file system operations who need to understand function signatures, parameter requirements, and error handling.

### class_SymbolicLink.md class_SymbolicLink.md
This document serves as API reference documentation for the Cangjie language's SymbolicLink class, which provides interfaces for handling file system symbolic links. It details static methods for creating links and reading link targets, both supporting Path and String inputs. Key information includes the create function's specific behavior on Windows regarding non-existent targets and the readFrom function's ability to recursively resolve the final target. Both methods throw IllegalArgumentException or FSException upon failure. This guide is intended for Cangjie developers performing file system operations who need to programmatically manage symbolic links.

### class_Directory/
This directory provides comprehensive API reference documentation for the `Directory` class in the Cangjie programming language, specifically designed for file system directory management. It details essential functionalities such as creating directories (including recursive and temporary generation), defining illegal path constraints, and handling various exceptions like `FSException` and `IllegalArgumentException`. Furthermore, it covers static methods for inspecting directory states, retrieving content arrays, and performing non-recursive traversals using callbacks. This documentation is intended for Cangjie developers seeking to implement robust directory manipulation, validation, and enumeration logic within their applications.

### class_File/
This directory contains comprehensive API reference documentation for the `File` class within the Cangjie programming language's `fs` package. It covers file manipulation, stream I/O, and static utility functions for creating, reading, writing, and managing files. Key topics include class inheritance, properties, constructors, instance methods for seeking and resizing, and static helpers for temporary files and bulk operations. Designed for developers building file system utilities or implementing I/O operations, this documentation assumes familiarity with Cangjie syntax and provides detailed specifications for handling file paths, resource management, and exception handling.
