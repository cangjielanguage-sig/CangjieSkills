# 基础类型定义

This directory provides API reference documentation for fundamental data structures and classes in the Cangjie language, specifically designed for the ArkUI framework. It covers essential UI components including shadow configurations, text controllers, font styling, and menu item definitions. Additionally, it details enumerations for text interaction, data detection, and selection states. These definitions are critical for developers building HarmonyOS applications who need to implement visual effects, manage text behaviors, and customize user interface elements programmatically. The documentation targets software developers working with API versions 12 and above.

## Detailed Description

### class_ShadowOptions.md
This API reference document details the ShadowOptions class in the Cangjie language, designed to configure shadow properties for UI elements within the ArkUI framework. The documentation covers the class definition, public properties such as radius, shadowType, offsetX, offsetY, color, and fill, along with the class constructor. Key information includes the data types for each property, their read/write capabilities, and specific version availability starting from API 12. The constructor allows developers to initialize shadow effects with parameters for blur radius, offsets, and color, using pixel units. This guide is intended for developers implementing visual styling and shadow effects in ArkUI applications.

### class_TextController.md
This document provides API reference documentation for the TextController class in the Cangjie language, designed to control Text components within the ArkUI framework. It covers the class definition, the public constructor for object instantiation, and the specific function closeSelectionMenu(). Key information includes the ability to programmatically dismiss custom or system default selection menus. The documentation specifies system capabilities and indicates support starting from version 19. Intended for HarmonyOS developers, this reference guide assists in managing text interaction behaviors programmatically in user interfaces.

### class_TextFont.md
This document provides API reference documentation for the TextFont class in the Cangjie language, designed to configure text styles within the ArkUI framework. It details two constructor overloads that allow developers to initialize text properties using either a string or an AppResource for the font family. Key sections cover parameters for font size, weight, and style, all of which are named arguments with specific default values. The documentation highlights that the family parameter is mandatory when using AppResource. Intended for software developers building ArkUI applications, this guide requires knowledge of Cangjie syntax and resource management to effectively implement text styling.

### class_TextMenuItem.md
This document provides API reference documentation for the Cangjie class TextMenuItem, used to define text menu items in the ArkUI framework. It covers the class definition, public properties including content, icon, and ID, and three constructor overloads that support both String and AppResource types. Key information highlights that the icon property does not support network images and that all parameters are named. Intended for Cangjie developers, this guide assists in creating menu objects with system capability requirements starting from version 19.

### class_TextMenuItemId.md
This API reference document defines the Cangjie class TextMenuItemId, which serves as an identifier for text menu items within the ArkUI framework. The documentation details static properties for standard actions like COPY, CUT, PASTE, and advanced features such as AI_WRITER. It also explains factory methods for creating custom IDs from resources or strings, alongside an equals method for comparison. Key takeaways include the read-only nature of predefined IDs and the requirement for specific system capabilities. This guide targets developers using Cangjie to implement or customize text selection menus in their applications.

### enum_TextSpanType_4more.md
This API reference document defines four enumeration types used for text handling and interaction within the ArkUI framework. It details TextSpanType for content classification, TextResponseType for menu triggers, TextDataDetectorType for entity recognition, and TextSelectable for selection and focus states. Key information includes distinguishing between text, image, and mixed spans; defining triggers like long-press or right-click; identifying entities such as URLs or phone numbers; and controlling selectability and focus behavior. Intended for developers building UI components in Cangjie, this documentation provides the necessary definitions to implement advanced text input, selection menus, and data detection features starting from API version 19.
