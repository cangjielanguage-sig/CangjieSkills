# 基础类型定义

This directory contains API reference documentation for fundamental data structures used in the ArkUI framework with the Cangjie programming language. It covers classes essential for defining visual styles, specifically focusing on gradient rendering and shadow configurations. Key components include color stops for gradients, linear gradient definitions, and shadow options for data panels. These documents are intended for UI developers and system architects working within the ArkUI ecosystem who need to implement complex graphical effects, manage color resources, and customize component appearances programmatically.

## Detailed Description

### class_ColorStop.md class_ColorStop.md
This document serves as API reference documentation for the Cangjie ColorStop class, which defines color stops used in gradient rendering. The content covers the class definition, properties including color and offset, and the initialization constructor. Key takeaways include that color accepts a ResourceColor type, while offset is a Length type clamped between 0 and 1 to represent the gradient position. This reference is intended for UI developers working with the ArkUI framework to implement gradient effects.

### class_DataPanelShadowOptions.md class_DataPanelShadowOptions.md
This document serves as API reference documentation for the DataPanelShadowOptions class in the Cangjie language, designed to configure shadow styles for DataPanel components within the ArkUI framework. It details the class inheritance from MultiShadowOptions, the colors property for defining segment-specific gradients, and the constructor parameters including radius, offsets, and color arrays. Key information includes the ability to set shadow blur radius, X/Y offsets, and linear gradient colors, with specific logic for handling mismatched color array lengths relative to data segments. This technical reference targets ArkUI developers using Cangjie who need to customize visual effects for data panels.

### class_LinearGradient.md class_LinearGradient.md
This API reference document details the LinearGradient class in the Cangjie programming language, designed for defining linear gradient colors within the ArkUI framework. The documentation covers the class definition and two initialization methods: one accepting an array of ColorStop objects for multi-color gradients, and another accepting a single ResourceColor. Key takeaways include the system capability requirement and the distinction between complex gradient definitions using color stops and simple single-color gradients. This is intended for UI developers using Cangjie to style graphical interfaces, requiring knowledge of basic ArkUI concepts and resource management. Keywords: LinearGradient, Cangjie, ArkUI, ColorStop, API reference.
