# 开发步骤

This directory provides a structured set of tutorials for developers implementing location services using the LocationKit module in the Cangjie language. It covers the essential development steps required to integrate location capabilities into applications, ranging from basic single-point acquisition to complex continuous tracking. The documentation details critical technical procedures such as permission management, module importing, and device status checks. It also explores configuration options for balancing accuracy and power consumption, including specific parameters like `LocatingPriority` and `locationScenario`. These guides are designed for application developers seeking to enable features such as user check-ins, location-based service recommendations, real-time navigation, and fitness tracking within their software projects.

## Detailed Description

### 开发步骤_1.md
This tutorial guides developers through implementing basic location acquisition using the LocationKit module in the Cangjie language. The content covers a four-step process: requesting permissions, importing modules, checking the location switch status, and acquiring device coordinates. It details two primary methods: `getLastLocation` for low-power cached data and `getCurrentLocation` for real-time positioning. Key technical points include configuring `SingleLocationRequest` with parameters like `LocatingPriority` for accuracy or speed, and setting a recommended timeout of 10 seconds. The document notes that output coordinates are in WGS-84 format. This guide targets application developers integrating features like check-ins or service recommendations.

### 开发步骤_2.md
This document provides a technical guide for implementing continuous location tracking in applications, specifically for scenarios like navigation and fitness tracking. It details the instantiation of the `ContinuousLocationRequest` object, configuration of the `locationScenario` and `interval` parameters, and the usage of `GeoLocationManager` methods. The guide emphasizes setting the correct scenario, such as `NAVIGATION`, for optimal performance and includes a Cangjie code example demonstrating how to start and stop location updates to manage device power consumption effectively. This tutorial is intended for application developers using the LocationKit API who need to integrate real-time positioning features.
