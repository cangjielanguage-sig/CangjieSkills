This directory provides comprehensive guides for developers looking to incrementally integrate the Cangjie programming language into existing ArkTS projects within the OpenHarmony and HarmonyOS ecosystems. It covers essential interoperability techniques, including enabling Cangjie support in ArkTS modules, cross-module function calls, and embedding Cangjie UI components directly into ArkTS pages. These resources are designed for developers seeking to leverage Cangjie's capabilities while maintaining their current ArkTS codebase, facilitating a smooth transition to hybrid development models.
