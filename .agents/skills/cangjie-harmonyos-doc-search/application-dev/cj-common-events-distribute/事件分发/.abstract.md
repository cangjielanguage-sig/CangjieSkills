This directory focuses on the event dispatching mechanism within the ArkUI framework. It covers the fundamental concepts of how user operations (touch and mouse) are processed, distributed to components, and how response chains are constructed. Key topics include touch testing, event classification (Touch vs. Mouse), and algorithms for collecting event response chains. This documentation is suitable for ArkUI developers who need to understand the underlying logic of user interaction handling, component hit testing, and event propagation to build responsive UI applications.
