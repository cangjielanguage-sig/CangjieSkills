# struct_Path

This directory provides comprehensive API reference documentation for the `Path` struct in the Cangjie `fs` package. It details the struct's definition, properties, operators, and utility methods designed for handling local file system paths across Windows and Unix operating systems. Key functionalities include path normalization, joining, component extraction (like filename and extension), and equality comparison. The documentation covers specific behaviors such as OS-specific separators, length limits, and exception handling for illegal paths. It is intended for Cangjie developers seeking precise definitions for path manipulation, validation, and cross-platform file system operations.

### prop_fileName_2more.md prop_fileName_2more.md
This document provides API reference documentation for two properties of the Path struct within the Cangjie file system package. It details the fileName property, which retrieves the full filename including extension, and fileNameWithoutExtension, which returns the filename excluding the extension based on the last dot. Key information includes return types of String, specific behavior on Windows systems regarding volume names, and examples illustrating path splitting logic. Both properties throw an IllegalArgumentException if the path is empty or contains a string terminator. This reference guide targets developers using the Cangjie language to programmatically manipulate and analyze file paths.
