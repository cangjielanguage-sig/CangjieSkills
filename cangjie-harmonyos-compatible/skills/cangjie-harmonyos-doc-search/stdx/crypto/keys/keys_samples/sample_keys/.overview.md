# sample_keys

This directory serves as a comprehensive educational resource and code repository focused on cryptographic key management within the Cangjie programming language. It provides in-depth coverage of asymmetric encryption algorithms, specifically highlighting industry standards like RSA and ECDSA, as well as the SM2 national cryptographic standard. The material is designed to guide developers through complex security operations, including the generation of public-private key pairs, secure data encryption and decryption, and the implementation of digital signatures for identity verification. Additionally, it addresses the practical handling of key storage and exchange using PEM formats. By utilizing the `stdx.crypto.keys` standard library, the examples demonstrate best practices for implementing security protocols. This collection is highly suitable for backend developers, security engineers, and system architects who are building Cangjie applications and require robust mechanisms to protect sensitive data during transmission and at rest.

## Detailed Description

### keys_使用/
This subdirectory functions as a comprehensive tutorial hub for the Cangjie programming language, focusing specifically on the practical implementation and usage of cryptographic keys. It bridges the gap between theoretical cryptography and application development by covering real-world scenarios involving asymmetric encryption algorithms. The content includes detailed guidance on widely used standards such as RSA and ECDSA, alongside the SM2 (ShangMi 2) standard, which is essential for specific regulatory compliance. The tutorials provide step-by-step instructions on fundamental security tasks: generating cryptographically secure key pairs, performing data encryption and decryption to ensure confidentiality, and executing digital signing and verification processes to guarantee data integrity and non-repudiation. Furthermore, it offers practical insights into managing key lifecycles through the import and export of PEM format key files, which facilitates seamless integration with various security infrastructures. By leveraging the `stdx.crypto.keys` standard library, these examples serve as an essential reference for developers aiming to master core data security technologies. This documentation is particularly valuable for developers tasked with integrating sophisticated encryption capabilities into Cangjie projects to secure data transmission channels and storage systems effectively against unauthorized access and tampering.
