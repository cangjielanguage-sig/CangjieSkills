This directory provides a comprehensive overview of HarmonyOS application packages, specifically focusing on the Stage model architecture. It covers fundamental definitions of applications and packages, emphasizing system management strategies and cross-platform compatibility requirements. The content explores the multi-module design mechanism, highlighting how modular development supports loose coupling and adaptation for various devices. Key distinctions between different package types, such as HAP and HAR, are clarified to aid in architectural decision-making. This documentation is suitable for HarmonyOS developers and system architects seeking to understand package structures, compilation characteristics, and dependency management before initiating application development.
