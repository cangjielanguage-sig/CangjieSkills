# class_InterfaceTypeInfo

This directory contains essential API reference documentation for the `InterfaceTypeInfo` class and related functions within the Cangjie standard library. It focuses on providing reflection capabilities specifically designed for interface types, allowing developers to perform runtime type inspection and dynamic type handling. The documentation covers the class structure, highlighting the `sealedSubtypes` property used for retrieving subtype collections, and static retrieval methods such as `get` and `of`. It also includes details on specific exceptions like `InfoNotFoundException` and `IllegalTypeException`. Furthermore, it documents the `isSealed` function for checking interface semantics. This resource is intended for Cangjie developers who need to enforce interface constraints and utilize advanced reflection features in their applications.
