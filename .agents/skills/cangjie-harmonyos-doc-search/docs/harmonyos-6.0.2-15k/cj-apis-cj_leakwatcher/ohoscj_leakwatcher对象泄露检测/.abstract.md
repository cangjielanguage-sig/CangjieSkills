This directory provides comprehensive documentation for the `ohos.cj_leakwatcher` module, a critical tool within the PerformanceAnalysisKit for identifying memory leaks in Cangjie applications on HarmonyOS. It details the `CJLeakWatcher` class, offering insights into enabling detection, registering objects for monitoring, and exporting heap snapshots. The documentation covers essential workflows for triggering garbage collection and managing object lifecycles. It is intended for Cangjie developers and system engineers who need to diagnose memory issues, optimize performance, and ensure application stability through rigorous leak detection and analysis.
