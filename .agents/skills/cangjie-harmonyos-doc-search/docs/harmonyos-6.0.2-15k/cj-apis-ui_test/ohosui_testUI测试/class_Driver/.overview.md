# class_Driver

This directory provides API reference documentation for the `Driver` class, the main entry point for the UiTest framework in the Cangjie language. It covers UI automation tasks including initialization, component assertion, coordinate-based interaction, gesture simulation, and system control. Functionalities range from basic clicks and text input to multi-touch gestures and display management. This documentation targets developers and QA engineers using the TestKit to automate UI interactions for HarmonyOS applications, providing detailed syntax, parameters, and error handling guidance.
