# 基础类型定义

This directory contains API reference documentation for fundamental data structures and classes used in ArkUI development with the Cangjie language. It covers the SearchController for managing search component states, enums for configuring input types and button styles, and structs for handling cursor positioning and geometric data. Key topics include text manipulation, input validation, and UI geometry. This documentation is suitable for HarmonyOS developers who need granular control over search interfaces and text input behaviors in their applications.

## Detailed Description

### class_SearchController.md class_SearchController.md
This document provides API reference documentation for the SearchController class in the Cangjie language, used to control the Search component within the ArkUI framework. It covers the class initialization and methods for manipulating text input states, including setting cursor positions, retrieving text metrics like line count and content area, and managing text selection highlights. Key functionalities include caretPosition, setTextSelection, and stopEditing, with several advanced features introduced in API version 19. This guide is intended for developers building ArkUI interfaces who require granular control over search component behaviors and text editing properties.

### enum_SearchType_2more.md enum_SearchType_2more.md
This document serves as API reference documentation for two Cangjie enums used in ArkUI development to configure input field behaviors and button visibility. It details the SearchType enum, which specifies input modes like email, phone number, and URL, and the CancelButtonStyle enum, which controls the display behavior of text clearing buttons. Key takeaways include specific character constraints for each input type, such as the single '@' rule for emails, and visibility states for cancel buttons including constant, invisible, or input-based. All features require SystemCapability.ArkUI.ArkUI.Full starting from version 19. Targeted at HarmonyOS developers using the Cangjie language, this reference assists in defining user input validation and UI interaction patterns for text components.

### struct_CJCaretOffset_2more.md struct_CJCaretOffset_2more.md
This API reference document defines two data structures, CJCaretOffset and CJRectResult, for the Cangjie language within the ArkUI framework. The documentation details the properties and constructors for CJCaretOffset, which tracks cursor index and coordinates relative to an input box, and CJRectResult, which defines rectangular dimensions and position. Key information includes that all properties are Float64 types with read-write capabilities. Intended for developers managing text input cursor positioning or UI element geometry, this reference provides the necessary structural definitions to handle spatial data and cursor states effectively in version 19 of the system.
