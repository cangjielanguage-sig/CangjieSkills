# crypto_samples

This directory provides a collection of sample code and documentation focused on cryptographic operations within the Cangjie programming language. It covers key security concepts including the SM4 encryption algorithm for data protection and the generation of secure random numbers using the `SecureRandom` class. The examples illustrate the practical use of the `stdx.crypto` module, guiding developers through configuration, initialization, and execution of security functions. These resources are ideal for Cangjie developers seeking to implement robust encryption and secure randomization in their applications.

## Detailed Description

### sample_crypto/

This directory contains a sample document demonstrating how to implement data encryption and decryption using the SM4 algorithm in the Cangjie programming language. The documentation details the application of the `stdx.crypto` module, covering the complete workflow from importing the encryption library, configuring CBC mode, and initializing keys to performing encryption and decryption operations. Additionally, it showcases techniques for converting between byte arrays and strings to ensure complete data restoration. This resource is particularly suitable for Cangjie developers, providing clear code examples and best practices for the practical application of the SM4 class.

### sample_secure_random/

This directory primarily demonstrates how to use the `SecureRandom` class in the Cangjie programming language to generate highly secure random boolean values. The documentation details the complete code implementation process, starting from importing necessary encryption modules, creating a `SecureRandom` instance, and calling the `nextBool` method within a loop structure to obtain random results. Core knowledge points cover the creation of random number objects, the use of encryption modules, and the verification of the unpredictability of random results. This tutorial is especially suitable for beginners and advanced Cangjie developers, particularly those needing to implement secure random number generation in scenarios such as encryption, simulation, or game development, aiming to help developers quickly master the relevant APIs.
