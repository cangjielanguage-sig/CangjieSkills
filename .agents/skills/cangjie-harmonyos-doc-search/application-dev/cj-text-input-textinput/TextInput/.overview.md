# TextInput

This directory provides comprehensive API reference documentation for the TextInput component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the core component implementation, controller classes for programmatic manipulation, event handling mechanisms, and detailed property configurations for styling and validation. Suitable for software developers and UI engineers building HarmonyOS applications, these resources offer the technical details needed to implement single-line text input functionality, manage cursor behavior, handle user interactions, and customize visual appearance.

## Detailed Description

### TextInput_5more.md TextInput_5more.md
This document serves as API reference documentation for the TextInput component within the ArkUI framework, designed for the Cangjie programming language. It outlines the usage of a single-line text input box currently in Beta, covering module imports and component creation. The primary focus is the `init` method, which accepts optional parameters for placeholder text, current text value, and a controller object. The document specifies system capabilities and version requirements, noting that the component supports all universal attributes and events. This technical reference is intended for developers implementing basic text input functionality in their applications.

### 基础类型定义_2more.md 基础类型定义_2more.md
This document serves as an API reference for the TextInputController class in the Cangjie language, designed to control TextInput components within the ArkUI framework. It details the class constructor and key methods including caretPosition for cursor placement, setTextSelection for text range selection, and stopEditing to exit edit mode. All functions require SystemCapability.ArkUI.ArkUI.Full and start from version 22. The document includes a practical code example demonstrating controller binding, state management, and event handling. This guide is intended for ArkUI developers using Cangjie who need to programmatically manipulate text input behaviors in their applications.

### 组件事件.md 组件事件.md
This document serves as an API reference for event handling functions within a Cangjie-based UI component, specifically focusing on text input interactions. It details six primary event handlers: onChange, onCopy, onCut, onEditChange, onPaste, and onSubmit. Key information includes that each function accepts a nullable callback parameter returning Unit and supports fluent chaining by returning This. The callbacks provide specific data types like String for content changes or EnterKeyType for submission actions. All functions require SystemCapability.ArkUI.ArkUI.Full and are available from version 22. This guide targets software developers using the Cangjie language to build HarmonyOS ArkUI applications who need to implement interactive text editing features.

### 组件属性/
This directory contains API reference documentation for configuring component properties within the Cangjie ArkUI framework. It primarily focuses on text input and text styling attributes, covering visual customization, keyboard interaction, and input validation. Key topics include font settings (color, size, weight), caret configuration, text alignment, and input constraints like length limits and filters. These resources are designed for software developers and UI engineers using the Cangjie language to build ArkUI applications, providing the necessary technical details to implement precise control over component behavior and appearance.
