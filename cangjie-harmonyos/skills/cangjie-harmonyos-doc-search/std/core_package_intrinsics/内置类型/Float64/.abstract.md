This directory contains comprehensive documentation for the Float64 data type within the Cangjie programming language ecosystem. It covers the fundamental technical definition of the 64-bit floating-point number, its compliance with the IEEE 754 standard, and various API extensions. Key topics include double-precision binary64 format, mathematical constants, utility operations, bit manipulation, and interface implementations like Comparable and Hashable. This documentation is suitable for software developers, systems engineers, and Cangjie programmers who need precise numerical computing capabilities, edge-case handling, and low-level bit operations in their applications.
