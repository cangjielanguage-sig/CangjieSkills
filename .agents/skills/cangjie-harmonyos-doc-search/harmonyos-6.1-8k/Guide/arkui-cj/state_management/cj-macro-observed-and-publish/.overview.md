# cj-macro-observed-and-publish

This directory serves as a comprehensive technical guide for the Cangjie programming language, specifically targeting the ArkUI framework's advanced state management features. It focuses on the implementation of the `@Observed` and `@Publish` macros, which are indispensable tools for creating reactive user interfaces. The core subject matter revolves around the challenges of observing and synchronizing state changes in complex data structures, particularly nested class objects and arrays. These structures often present difficulties in standard reactive systems due to their deep hierarchy. The documentation covers essential ground, including macro definitions, detailed specifications, variable passing protocols, and the underlying runtime behaviors. It also addresses specific restrictions and limitations that developers may encounter. By leveraging this information, developers can achieve robust two-way data binding and ensure that their UIs update correctly in response to data changes. This resource is tailored for Cangjie developers who possess a basic understanding of ArkUI and are seeking to solve complex data synchronization challenges in their applications.
