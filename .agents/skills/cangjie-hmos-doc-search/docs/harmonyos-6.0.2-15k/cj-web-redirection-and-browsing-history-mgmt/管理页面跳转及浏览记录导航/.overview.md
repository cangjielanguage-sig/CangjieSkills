# 管理页面跳转及浏览记录导航

This directory provides a comprehensive technical overview of navigation management for HarmonyOS applications built with the Cangjie language. It focuses on the ArkWeb component, detailing how to control web page history and implement sophisticated page transitions triggered by web links. The documentation covers essential topics such as configuring network permissions, utilizing navigation APIs for forward and backward movement, and intercepting URL schemes to bridge web content with native application logic. By addressing scenarios like in-app routing and cross-application launches, this guide is designed for developers creating hybrid applications that require seamless integration between web views and native system functionalities.

## Detailed Description

### 历史记录导航.md 历史记录导航.md
This guide explains how to implement forward and backward navigation within the ArkWeb component for managing web page history. It covers automatic history recording, network permission configuration in module.json5, and the usage of navigation APIs like forward(), backward(), accessForward(), and accessBackward(). Key takeaways include the necessity of declaring internet permissions and checking history availability before navigation to prevent invalid operations. The document targets application developers using the Cangjie language and ArkWeb framework to build web-view enabled applications.

### 页面跳转_2more.md 页面跳转_2more.md
This technical guide demonstrates how to implement page navigation triggered by web links within a HarmonyOS application using the Cangjie language. It covers two primary scenarios: in-app navigation to native pages and cross-application navigation to external apps like the dialer. The core mechanism involves the Web component's onLoadIntercept() interface to intercept specific URL schemes (e.g., native:// for internal routing and tel:// for phone calls) and execute corresponding native logic like Router.pushUrl() or TelephonyCall.makeCall(). Targeted at developers building hybrid web-native applications, this document requires knowledge of Cangjie syntax, ArkUI components, and basic HTML.
