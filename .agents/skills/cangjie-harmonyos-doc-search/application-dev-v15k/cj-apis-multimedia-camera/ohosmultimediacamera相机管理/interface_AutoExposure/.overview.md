# interface_AutoExposure

This directory provides comprehensive API reference documentation for the AutoExposure interface within the CameraKit framework, specifically tailored for the Cangjie programming language. It encompasses the management of device automatic exposure operations, covering critical functionalities such as adjusting exposure compensation (EV), defining auto-exposure strategies, and configuring metering points. The documentation includes detailed specifications on parameter constraints, supported ranges, error handling, and system capabilities. It is primarily suitable for software developers and multimedia engineers who require precise, programmatic control over camera hardware behavior and are integrating advanced exposure features into their applications.
