# onKeyEvent

This directory provides comprehensive documentation and practical examples for the `onKeyEvent` function, a critical tool for handling keyboard input events in Cangjie and ArkUI environments. It covers the technical implementation of event handling, including detailed function signatures, callback parameters such as `KeyEvent`, `KeyType`, and `keyCode`, and the complex mechanics of event bubbling. Additionally, it offers practical guidance on preventing event propagation and monitoring user input in real-time. This resource is specifically designed for Cangjie and HarmonyOS developers who need to manage component focus and create highly interactive, keyboard-responsive user interfaces. By understanding these concepts, developers can effectively control how their applications respond to user keyboard interactions, ensuring a smooth and intuitive user experience.

## Detailed Description

### onKeyEvent_1.md
This API documentation explains how to handle keyboard input events for focused components using the onKeyEvent function in the Cangjie language. It details the function signature, callback parameters like KeyEvent, KeyType, and keyCode, and provides a practical code example demonstrating event handling on a Button and parent Column. Key takeaways include understanding event bubbling, where both child and parent components receive events, and how to prevent this using event.stopPropagation(). The document also clarifies that each key press triggers Down and Up callbacks. This guide targets Cangjie developers building UIs who need to manage keyboard interactions and focus events.

### onKeyEvent_2.md
The document provides a practical code example for handling keyboard input events within an ArkUI application. It focuses on the onKeyEvent callback attached to a layout component, demonstrating how to detect specific key actions such as Down and Up. The key takeaway is the extraction and display of event properties, including keyCode and keyText, to update the UI in real-time. Accompanied by a visual GIF, this guide serves developers looking to implement interactive event handling and user input monitoring in their HarmonyOS projects.
