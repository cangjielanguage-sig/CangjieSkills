# 类

本目录包含仓颉语言中与 X.509 数字证书处理相关的核心类 API 参考文档。内容涵盖了证书身份定义、证书管理及证书签名请求（CSR）的处理。主要涉及 X509Name、X509Certificate 和 X509CertificateRequest 等类，提供了证书解析、验证、编解码及签名请求生成等功能。该模块适用于从事公钥基础设施（PKI）、加密通信及网络安全开发的程序员，旨在提供完整的证书生命周期管理接口。

## 快速导航

**您想要做什么？**

*   定义或获取证书的可辨识名称（DN） → class_X509Name.md X509Name
*   处理、验证或解析 X.509 数字证书 → class_X509Certificate/
*   创建或解析证书签名请求（CSR） → class_X509CertificateRequest/

## 详细描述

### class_X509Name.md class_X509Name.md
本文档是Cangjie语言中X509Name类的API参考文档，旨在定义数字证书中用于验证身份的可辨识名称（DN）。文档详细介绍了类的构造函数、属性列表及toString方法。构造函数支持设置国家、省份、组织、通用名称等可选字段，属性用于获取这些字段值，初始化失败可能抛出X509Exception。该类继承自ToString，用于生成证书实体名称字符串。目标受众为使用X.509证书处理功能的开发人员，需具备基本的加密编程知识。关键词：X509Name、可辨识名称、数字证书、Cangjie、API文档。

### class_X509Certificate/
本目录包含仓颉语言中 X509Certificate 类的 API 参考文档，专注于处理 X.509 数字证书。内容涵盖了证书的核心属性定义（如颁发者、公钥）、证书验证逻辑（有效期、域名、链验证）以及证书的创建、编解码（DER/PEM）和系统根证书获取。该模块适用于从事公钥基础设施（PKI）和安全通信开发的程序员，提供了完整的证书管理与加密通信接口。

### class_X509CertificateRequest/
本目录包含 X509CertificateRequest 类的 API 参考文档，专注于定义和处理数字证书签名请求 (CSR)。内容涵盖了类的初始化（支持 RSA、ECDSA、DSA）、DER 和 PEM 格式的编解码方法，以及获取证书请求详情（如公钥、签名算法、使用者主体信息）的属性。该模块适用于从事加密通信、PKI 基础设施开发的技术人员，提供了完整的参数定义、异常处理机制及数据格式转换功能，是处理证书请求数据的核心参考。
