This directory contains the API reference documentation for the Cangjie programming language's Timer class, located within the standard library's synchronization package. The documentation details static initialization methods like `once`, `repeat`, and `after`, alongside instance control methods such as `cancel`. This resource is suitable for Cangjie developers implementing asynchronous logic, concurrent programming, and precise time-based operations in their applications.

### class_Timer.md class_Timer.md
This document provides API reference for the Cangjie Timer class, designed to execute tasks at specific times or intervals. The content covers the class definition, inheritance from Equatable and Hashable, and detailed behavioral constraints. Key information highlights that Timers implicitly spawn threads, bind to a single immutable task during initialization, and prevent garbage collection until the task finishes or is cancelled. The documentation also notes that timing is not guaranteed to be precise and uncaught exceptions will invalidate the timer. Intended for Cangjie developers, this guide explains the lifecycle differences between one-shot and repeating timers, emphasizing thread management and exception handling in concurrent programming.
