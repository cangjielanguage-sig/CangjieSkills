# Core_File_Kit简介

This directory serves as a comprehensive introduction to the Core File Kit within the HarmonyOS development environment. It is designed to help developers understand the service's capabilities in accessing and managing both application and user files efficiently. The content covers essential topics such as file classification models, sandbox isolation for security, and mechanisms for app sharing via URIs or FDs. Additionally, it details usage scenarios including CRUD operations, backup and restore, and cross-device synchronization. Beyond basic features, the directory delves into the architectural principles of file access frameworks, explaining the roles of FilePicker, ExtensionAbility, and various manager services. This resource is primarily suitable for HarmonyOS developers looking to implement robust file management, secure data sharing, and understand the underlying framework architecture.

### 框架原理_2more.md 框架原理_2more.md
This document outlines the architectural principles of HarmonyOS file access frameworks, explaining how applications and users interact with file systems. It covers the Application File Access Framework, which relies on basic interfaces, and the User File Access Framework, which utilizes the ExtensionAbility mechanism. Key information includes the roles of FilePicker for permission-free file selection, File Access Helper APIs, and specific services like UserFileManager and ExternalFileManager for managing internal and external storage. The text also highlights the dependency on Ability Kit. This conceptual guide targets HarmonyOS developers needing to understand file management architecture and implement file access features.

Keywords: HarmonyOS, File Access Framework, ExtensionAbility, FilePicker, UserFileManager, Ability Kit.
