# cj-appendix-hybrid

This directory serves as a technical resource for HarmonyOS developers aiming to implement hybrid development by combining Cangjie and ArkTS. It focuses on the practical application of embedding Cangjie UI components into ArkTS pages using the `CJHybridComponentV2` component. The content covers essential aspects such as the background of mixed-language scenarios, project configuration, and the specific lifecycle and routing differences compared to pure Cangjie development. By providing setup instructions and code examples, this guide assists developers in integrating Cangjie logic into existing ArkTS applications, while also noting current limitations regarding cross-language state synchronization and full page lifecycle support.
