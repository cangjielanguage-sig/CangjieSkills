This directory contains technical documentation and reference guides for implementing RSA encryption and decryption using the PKCS1_OAEP padding mode. It covers essential topics such as parameter string construction, supported algorithm combinations, key size constraints, and compatibility rules for various digest and Mask Generation Function (MGF1) algorithms. The resources are designed to help developers and security engineers configure cryptographic libraries correctly, ensuring data size limits are respected and valid security configurations are applied. Keywords include RSA, PKCS1_OAEP, MGF1, digest algorithms, and encryption parameters.
