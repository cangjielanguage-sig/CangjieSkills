This directory serves as a centralized resource for HarmonyOS application developers, providing detailed reference documentation regarding system permission groups and specific requirements for multi-device collaboration. It encompasses a broad spectrum of functionalities, ranging from hardware access like Camera and Microphone to connectivity features such as Bluetooth, NearLink, and distributed data synchronization. The content explains the architectural logic behind permission grouping, where related permissions are requested together to optimize the user experience, and provides a comprehensive index of permissions necessary for communication and data sharing. This documentation is essential for developers aiming to implement robust features while adhering to system security protocols, ensuring that all necessary access rights are correctly declared and managed within their applications.
