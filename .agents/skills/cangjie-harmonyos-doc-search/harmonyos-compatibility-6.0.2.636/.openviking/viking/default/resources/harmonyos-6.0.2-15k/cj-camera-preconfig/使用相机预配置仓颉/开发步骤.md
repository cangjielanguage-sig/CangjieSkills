## 开发步骤

详细的API说明请参见[Camera API参考](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md)。

1. 导入相关接口。

    ```cangjie
    import kit.CameraKit.*
    import kit.BasicServicesKit.*
    ```

2. 创建输出流Output。

    此处以创建预览流和拍照流为例。

    创建预览输出流时，涉及参数surfaceId。XComponent组件为预览流提供Surface（获取surfaceId请参见[getXcomponentSurfaceId](../../../API_Reference/source_zh_cn/arkui-cj/cj-rendering-drawing-xcomponent.md#func-getxcomponentsurfaceid)方法），而XComponent的能力由UI提供，相关介绍请参见[XComponent组件参考](../../../Dev_Guide/arkui-cj/cj-common-components-xcomponent.md)。

    ```cangjie
    // 创建预览输出流
    let previewOutput: PreviewOutput = cameraManager.createPreviewOutput(surfaceId)
    // 创建拍照输出流
    let photoOutput: PhotoOutput = cameraManager.createPhotoOutput()
    ```

3. 调用[CameraManager](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-cameramanager)方法，创建输入流Input。

    ```cangjie
    let cameraInput = cameraManager.createCameraInput(cameraArray[0])
    // 打开相机
    cameraInput.open()
    ```

4. 调用[createSession](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-createsessionscenemode)创建会话（Session）。

    > **说明：**
    >
    > SceneMode需要指定为NORMAL_PHOTO或NORMAL_VIDEO，对应拍照场景[PhotoSession](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-photosession)和录像场景[VideoSession](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#class-videosession)。

    ```cangjie
    //创建会话
    let photoSession: PhotoSession = (cameraManager.createSession(SceneMode.NORMAL_PHOTO) as PhotoSession).getOrThrow()
    ```

5. 调用[canPreconfig](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-canpreconfigpreconfigtype-preconfigratio)检查对应的PreconfigType和PreconfigRatio的组合在当前设备上是否支持。确认支持后，调用[preconfig](../../../API_Reference/source_zh_cn/apis/CameraKit/cj-apis-multimedia-camera.md#func-preconfigpreconfigtype-preconfigratio)启用Preconfig配置。

    ```cangjie
    // 查询Preconfig能力
    let isPreconfigSupport = photoSession.canPreconfig(PreconfigType.PRECONFIG_1080P)
    if (!isPreconfigSupport) {
        AppLog.error('PhotoSession canPreconfig check fail.')
        return;
    }

    // 配置Preconfig
    photoSession.preconfig(PreconfigType.PRECONFIG_1080P)
    ```

6. Session添加Input和Output。

    > **说明：**
    >
    > Session调用preconfig接口成功之后，Session内部会将预置数据准备好，如果向Session中进行添加未配置Profile的Output，Session则会对相应的Output进行配置对应Profile。如果向Session中添加已配置Profile的Output，则Session的预配置数据不生效。

    ```cangjie
    // 开始配置会话
    photoSession.beginConfig()

    // 向会话中添加相机输入流
    photoSession.addInput(cameraInput)

    // 向会话中添加预览输出流
    photoSession.addOutput(previewOutput)

    // 向会话中添加拍照输出流
    photoSession.addOutput(photoOutput)

    // 提交会话配置
    photoSession.commitConfig()
    ```

7. 启动Session。

    ```cangjie
    // 启动会话
    photoSession.start()
    ```
