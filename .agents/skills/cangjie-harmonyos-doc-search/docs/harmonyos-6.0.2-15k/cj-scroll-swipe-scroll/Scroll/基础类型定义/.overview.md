# 基础类型定义

This directory provides essential API reference documentation for fundamental scrolling types and configurations within the Cangjie ArkUI framework. It covers core classes such as `ScrollAnimationOptions` for customizing scroll physics, `Scroller` for controlling scrollable containers, and `BaseScroller` as the abstract base for scroll management. Additionally, it includes `ScrollSnapOptions` for implementing precise pagination and snapping effects. These resources are designed for HarmonyOS and ArkUI developers using the Cangjie language who need to implement advanced scrolling behaviors, control scroll positions programmatically, and optimize user interface interactions with specific animation and alignment rules.

## Detailed Description

### class_ScrollAnimationOptions.md class_ScrollAnimationOptions.md
This document provides API reference documentation for the Cangjie class ScrollAnimationOptions, designed to configure custom scroll animation parameters within the ArkUI framework. The content details the class structure, specifically covering three public properties: duration for animation length, curve for the easing function, and canOverScroll for boundary behavior. It also documents the class constructor and its default parameter values. Key information includes that enabling canOverScroll requires the component's edge effect to be set to Spring to trigger the rebound animation. This technical guide targets developers utilizing ArkUI who need precise control over scroll physics and visual effects.
