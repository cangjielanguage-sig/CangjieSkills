This directory contains API reference documentation for the `UnixSocketAddress` class within the Cangjie standard library. It covers the implementation of Unix Domain Socket addressing, including class properties, constructors for handling file system paths, and methods for address manipulation and comparison. Key topics include socket address encapsulation, byte-level data structures, and operator overloading for equality checks. This documentation is suitable for Cangjie developers working on network communication who need precise control over socket addressing, path validation, and data conversion.
