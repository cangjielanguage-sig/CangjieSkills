This directory contains a comprehensive set of code examples demonstrating cryptographic operations and key management within the HarmonyOS ecosystem, specifically utilizing the Universal Keystore (HUKS) framework and the Cangjie programming language. It covers essential security workflows including AES encryption, Elliptic Curve Diffie-Hellman (ECDH) key agreement, key wrapping, and secure key import between devices. The examples range from basic parameter configuration and initialization vector (IV) setup to complex session-based encryption and lifecycle management. These resources are designed for developers seeking to implement secure data handling, key storage, and cryptographic protocols in their HarmonyOS applications.
