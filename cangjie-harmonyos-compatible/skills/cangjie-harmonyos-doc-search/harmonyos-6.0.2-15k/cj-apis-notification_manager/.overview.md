# cj-apis-notification_manager

This directory serves as the central repository for the `ohos.notification_manager` API documentation, meticulously crafted for the Cangjie programming language and HarmonyOS ecosystem. It offers a robust technical guide for software engineers and system developers aiming to implement comprehensive notification solutions. The content spans the full lifecycle of system notifications, including their creation, detailed configuration, and persistent management. Key areas of focus include the implementation of diverse content types such as text, static images, and dynamic live views, as well as the architectural setup of notification channels and slots. Furthermore, the documentation provides critical insights into interaction controls, permission handling, and the utilization of distributed capabilities. This resource is essential for developers seeking to ensure their applications maintain effective and compliant communication channels with users through advanced notification features.

### ohosnotification_manager通知管理模块/
This module provides comprehensive API reference documentation for the `ohos.notification_manager` in the Cangjie programming language, designed for HarmonyOS application development. It covers the creation, configuration, and management of system notifications, including various content types like text, pictures, and live views, as well as notification channels (slots) and interaction controls. Developers can find detailed specifications for classes, enumerations, and functions to handle notification lifecycles, permissions, and distributed capabilities. This resource is suitable for software engineers and system developers implementing robust notification features in their applications.
