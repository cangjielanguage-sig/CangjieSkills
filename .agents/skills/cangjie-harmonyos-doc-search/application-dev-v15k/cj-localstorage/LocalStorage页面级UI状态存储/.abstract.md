This directory provides comprehensive documentation and guides for managing page-level UI state using LocalStorage within the Cangjie framework. It covers core concepts like in-memory storage, lifecycle management, and state synchronization mechanisms. Key topics include the `@LocalStorageLink` and `@LocalStorageProp` decorators for data binding, usage constraints, and practical scenarios for state sharing across components and UIAbility instances. This resource is suitable for developers and architects working with HarmonyOS applications who need to implement reactive state management, ensure data persistence, and handle complex data types efficiently.
