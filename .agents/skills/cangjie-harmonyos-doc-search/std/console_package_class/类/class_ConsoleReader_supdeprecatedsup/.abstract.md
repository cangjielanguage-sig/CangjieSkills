This directory provides comprehensive API reference documentation for the deprecated `ConsoleReader` class and associated standard input functions within the Cangjie programming language. It details the mechanisms for synchronous data reading from standard input, covering class definitions, inheritance from `InputStream`, and specific method behaviors such as `read()`, `readln()`, and `readToEnd`. The documentation highlights critical technical aspects including internal buffering, EOF handling, and potential UTF-8 encoding truncation risks. It is designed for Cangjie developers who need to maintain legacy console input operations or understand the specifications before migrating to the new `env` package.
