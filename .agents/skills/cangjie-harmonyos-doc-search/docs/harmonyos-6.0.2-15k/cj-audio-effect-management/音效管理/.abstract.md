This directory provides comprehensive technical documentation for managing audio sound effects using the AudioKit framework in the Cangjie language. It covers two primary aspects: querying global audio effect modes associated with specific `StreamUsage` scenarios and managing effects for individual audio playback instances. Key concepts include `AudioStreamManager`, `AudioRenderer`, `AudioEffectMode`, and stream usage types. This content is designed for multimedia application developers who need to programmatically control audio playback effects, configure scene-specific audio modes, or query system capabilities for scenarios such as music playback.
