This directory contains API reference documentation for the `CanvasRenderingContext2D` class in the Cangjie language, designed for the ArkUI framework. It provides a comprehensive guide to the 2D drawing context, covering initialization, property configuration, path manipulation, transformations, gradients, and pixel-level operations. Key topics include drawing shapes, rendering text, managing canvas state, and handling image data. Suitable for HarmonyOS developers using Cangjie to build custom graphical user interfaces and 2D graphics applications, this documentation requires knowledge of ArkUI and is applicable from system version 22 onwards.
