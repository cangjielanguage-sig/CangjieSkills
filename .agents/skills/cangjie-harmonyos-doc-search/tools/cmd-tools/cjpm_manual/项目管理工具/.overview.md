### 使用示例.md 使用示例
本文档演示了如何使用 cjpm 工具管理仓颉项目，涵盖初始化、构建、测试及清理流程。主要内容包括 init 和 build 命令的使用（创建主模块与依赖模块、配置依赖），以及 test 和 clean 命令的操作（执行单元测试、清理中间文件），并附带源代码和配置文件示例。文档重点展示了包含主模块和静态库依赖的目录结构，说明了通过 cjpm.toml 配置依赖的方法及生成文件的路径。这是一份面向仓颉开发者的入门教程，旨在帮助用户掌握项目组织与构建命令。

### 功能简介_2more_13793f33.md 功能简介

### 配置和缓存文件夹_3more_e6d58bd9.md 配置和缓存文件夹
本文档介绍了仓颉包管理工具cjpm的配置规范、源码包识别规则及命令扩展机制。主要涵盖通过CJPM_CONFIG环境变量设置存储路径，定义有效源码包需满足目录及其父级均包含代码文件的要求，以及利用cjpm-xxx可执行文件扩展命令的方法。关键点在于父目录无代码会导致子包被忽略，且内置命令优先级高于扩展。文档面向仓颉开发者，旨在指导项目配置与工具扩展。关键词：cjpm、环境变量、源码包规范、命令扩展。

### 命令说明/
本目录汇集了仓颉包管理器（cjpm）的核心命令参考文档，涵盖了从项目初始化、构建、测试到安装卸载的完整开发生命周期。内容详细介绍了 `init`、`build`、`test`、`run`、`clean`、`install` 等关键命令的用法、参数配置及高级功能（如依赖管理、覆盖率分析、性能基准测试）。这些文档适合仓颉语言开发者及项目维护者阅读，旨在帮助用户熟练掌握命令行工具，提升开发效率并解决构建与运行过程中的常见问题。

### 模块配置文件说明/
