This directory contains API reference documentation for the `HapModuleInfo` class in the Cangjie programming language, specifically designed for the HarmonyOS BundleManager framework. It covers the structure and properties of Harmony Ability Package (HAP) module information, including metadata, dependencies, device types, and configuration settings like routing tables and preloading lists. The documentation highlights that these properties are read-only and accessible via the `getBundleInfoForSelf` method starting from API version 22. This resource is intended for system and application developers who need to programmatically query and manage module configurations within HarmonyOS applications.
