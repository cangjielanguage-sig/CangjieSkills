# 使用场景

This directory provides a comprehensive collection of practical guides and tutorials focused on advanced state management techniques within the ArkUI framework using the Cangjie language. It specifically addresses the implementation of bidirectional state synchronization across component hierarchies using `@Provide` and `@Consume` decorators. The content covers essential usage scenarios ranging from basic state sharing between ancestor and descendant components to the management of complex data structures like Maps and Sets (HashSet). By demonstrating how data modifications trigger automatic UI updates, these resources ensure developers can build reactive and efficient applications. This directory is highly suitable for HarmonyOS developers, software engineers, and technical architects seeking to deepen their understanding of cross-component data flow and reactive state management patterns in the Cangjie ecosystem.

## Detailed Description

### 使用场景_2more.md
This document serves as a practical guide for implementing bidirectional state synchronization in ArkUI using the Cangjie language's @Provide and @Consume decorators. It features two primary usage scenarios: basic state sharing between an ancestor and descendant components, and advanced state management involving Map type variables. Key takeaways include how modifications to consumed variables in child components automatically update the provided state in ancestors, and how to handle complex data structures like HashMaps with operations such as adding, clearing, and replacing items. This tutorial is intended for developers seeking to master cross-component data flow in ArkUI applications.

### 装饰Set类型变量.md
This tutorial demonstrates how to decorate and manage state for Set type variables, specifically HashSet, using ArkUI's state management decorators in the Cangjie language. The document covers the implementation of `@Provide` and `@Consume` decorators to share data between parent and child components. Key information includes practical examples showing that modifying the HashSet—such as initializing, adding elements, clearing, or removing items—triggers automatic view refreshes. This ensures the UI stays synchronized with the data state. The content is intended for HarmonyOS developers using Cangjie who need to implement reactive state management for collection types in their applications.
