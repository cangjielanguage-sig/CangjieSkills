This directory provides comprehensive API reference documentation for the `FormParam` enum and its associated utility function within the Cangjie language environment. It is specifically designed to support card (widget) functionality in HarmonyOS applications by defining standardized parameter keys. The documentation covers essential attributes such as dimensions, permissions, bundle names, and rendering modes. Included are the enum definition, specific member keys like IdentityKey and DimensionKey, equality operators, and a method to retrieve string values from these enumerations. This resource is suitable for software developers building form-based applications using the HarmonyOS ability framework who need to access, manipulate, and map form configuration data effectively. It ensures standardized access to system capabilities starting from version 20.
