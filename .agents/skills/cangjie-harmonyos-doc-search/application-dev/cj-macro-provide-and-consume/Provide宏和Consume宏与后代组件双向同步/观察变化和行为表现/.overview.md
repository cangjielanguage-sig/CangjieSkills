# 观察变化和行为表现

This directory provides a comprehensive technical overview of state observation mechanisms and behavioral patterns within the ArkUI framework using the Cangjie language. It addresses the critical aspects of reactive programming, including how data changes are detected across various types such as basic values, collections, and complex objects. Furthermore, it examines the internal logic of state management decorators, specifically focusing on the synchronization and dependency injection patterns of `@Provide` and `@Consume`. This material is highly suitable for ArkUI developers, software engineers, and system architects who aim to deepen their understanding of data flow, component lifecycle interactions, and the implementation of efficient state synchronization in modern application development.

## Detailed Description

The following documents provide in-depth technical details regarding the specific behaviors and observation rules defined in this directory.

### 框架行为.md 框架行为.md
This technical reference document details the internal behavior and data synchronization mechanisms of the @Provide and @Consume decorators within the framework. It covers three specific phases: initial rendering logic, data propagation when @Provide changes, and data synchronization when @Consume changes. Key takeaways include the Map-based data passing mechanism where @Consume registers itself to @Provide, ensuring dependency tracking. The document highlights the bidirectional data flow: @Provide updates trigger cascading refreshes in child components, while @Consume modifications sync back to the parent provider. This guide is intended for developers requiring a deep understanding of state management, component lifecycle interactions, and dependency injection patterns.

### 观察变化.md 观察变化.md
This technical guide details the state observation capabilities for various data types within the ArkUI framework using the Cangjie language. It covers observation rules for basic types, collections (Array, HashMap, HashSet), complex objects (DateTime), and function types. Key takeaways include that basic types observe value changes, while collections and DateTime observe specific method calls like addDays or set. Code examples demonstrate state synchronization between parent and child components using @Provide and @Consume decorators. The target audience is ArkUI developers needing to implement reactive state management in their applications.
