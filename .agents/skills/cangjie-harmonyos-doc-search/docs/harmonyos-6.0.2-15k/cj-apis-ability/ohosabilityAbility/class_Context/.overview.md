# class_Context

This directory provides API reference documentation for the Context class and associated context management functions in the Cangjie language, specifically designed for the HarmonyOS ecosystem. It covers essential runtime capabilities for abilities and applications, including event hub objects, read-only properties, and file directory access such as cache, database, and temp folders. Key topics include resource management interfaces, module-specific context retrieval, global application context access, and shared directory management via Group IDs. This documentation is suitable for Cangjie and HarmonyOS developers who need to manage application runtime environments, interact with system-level file partitions, and handle context-related operations within the SystemCapability.Ability.AbilityRuntime.Core framework.

### class_Context_14more.md class_Context_14more.md
This API reference document details the Context class in the Cangjie language, which provides essential context capabilities for abilities and applications. The documentation outlines the class structure, focusing on an event hub object and various read-only properties introduced in version 19. Key sections include properties for accessing file directories like cache, database, and temp folders, alongside application information and resource management interfaces. The class enables developers to interact with system-level file partitions and manage resources without direct path manipulation. Intended for Cangjie developers, this reference assists in managing application runtime environments and event handling within the HarmonyOS ecosystem, requiring knowledge of the SystemCapability.Ability.AbilityRuntime.Core framework.

### func_createModuleContextSt_3more.md func_createModuleContextSt_3more.md
This document serves as API reference documentation for Cangjie developers, detailing specific context management functions within the AbilityKit framework. It covers three primary functions: createModuleContext for retrieving module-specific contexts, getApplicationContext for obtaining the global application context, and getGroupDir for accessing shared directories via Group IDs. Each entry includes syntax, system capabilities, parameters, return values, and potential exceptions like parameter errors or missing contexts. Notably, createModuleContext is restricted to the current application, and getGroupDir supports el2 encryption levels. Targeted at HarmonyOS application developers, this guide provides code examples to implement context retrieval and directory management within UIAbility classes.
