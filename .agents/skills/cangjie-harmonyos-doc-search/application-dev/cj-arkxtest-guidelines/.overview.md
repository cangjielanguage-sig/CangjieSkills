# cj-arkxtest-guidelines

This directory serves as a comprehensive resource and knowledge base for the Cangjie automated testing framework, specifically tailored for the OpenHarmony and HarmonyOS ecosystems. It covers essential testing methodologies, including Unit Tests and UI Tests, alongside command-line strategies using shell commands and the hdc tool. The content guides developers through environment setup in DevEco Studio, script creation, test execution workflows, and troubleshooting. Suitable for developers and QA engineers, this collection ensures application quality through structured testing, log analysis, and component interaction automation. It acts as a central hub for mastering testing capabilities in the Cangjie language environment, providing the necessary documentation to streamline the quality assurance process for modern application development. By following these guidelines, users can effectively validate application behavior, ensure stability across different devices, and maintain high standards of code quality throughout the development lifecycle.
