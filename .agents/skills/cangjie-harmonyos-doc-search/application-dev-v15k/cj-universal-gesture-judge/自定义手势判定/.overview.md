# 自定义手势判定

This directory focuses on custom gesture judgment and conflict resolution within the HarmonyOS ArkUI and Cangjie frameworks. It covers how to implement granular control over gesture recognition using callbacks like `onGestureJudgeBegin`, manage multi-touch interactions, and resolve conflicts between gestures such as Pan, LongPress, and Drag. It also includes foundational API references for data structures and event classes. This resource is suitable for application developers and UI engineers who need to build complex interactive interfaces with precise gesture handling logic.

## Detailed Description

### 示例代码1_2more.md
This document serves as a code tutorial for implementing custom gesture judgment and conflict resolution in Cangjie applications. It features two main examples: the first demonstrates using onGestureJudgeBegin to log gesture details and selectively reject Pan gestures while allowing others; the second illustrates how to resolve conflicts between LongPress and Drag gestures by checking touch coordinates within a Stack layout. Key concepts include GestureJudgeResult.REJECT and GestureJudgeResult.CONTINUE for controlling gesture flow. This guide targets developers working with the HarmonyOS Cangjie UI framework who need to manage complex multi-touch interactions and gesture priorities.

### 自定义手势判定_2more.md
This API documentation provides developers with the capability to implement custom gesture judgment for UI components. The document details the onGestureJudgeBegin function, including its signature, system capabilities, and parameter definitions. Key takeaways include the function's role in binding a callback that determines gesture response based on GestureInfo and BaseGestureEvent, returning a GestureJudgeResult. Intended for application developers using the ArkUI framework who require granular control over gesture recognition logic starting from version 19.

### 基础类型定义/
This directory provides comprehensive API reference documentation for fundamental data structures and event classes within the ArkUI framework, specifically designed for the Cangjie language. It covers the core definitions required for handling input device interactions and UI gestures. Key topics include the BaseEvent class for system events, BaseGestureEvent for finger tracking, and specific gesture types like pinch, rotation, and swipe. Additionally, it details structures for gesture judgment and categorization. This documentation is essential for developers building interactive applications who need to implement custom event handling and gesture recognition logic.
