This directory contains API reference documentation for configuring the Swiper component within the Cangjie ArkUI framework. It covers a comprehensive range of properties essential for building interactive carousel and slider interfaces, including playback control, layout arrangement, animation settings, and navigation indicators. Developers can find detailed specifications for functions like `autoPlay`, `displayCount`, `loop`, and `indicator`. This documentation is suitable for UI developers and system engineers using the Cangjie language who need precise control over component behavior, layout logic, and user interaction in their applications.
