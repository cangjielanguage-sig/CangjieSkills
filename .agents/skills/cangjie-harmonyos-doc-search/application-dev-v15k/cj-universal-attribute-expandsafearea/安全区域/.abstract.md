This directory provides comprehensive documentation for managing Safe Areas within the Cangjie ArkUI framework. It covers the fundamental concepts of safe areas, API references for extending component layouts into system regions (like status bars and notches), and handling virtual keyboard interactions. Key topics include the `expandSafeArea` function, `setKeyboardAvoidMode`, and basic type definitions such as `SafeAreaType` and `SafeAreaEdge`. The content also includes practical code examples demonstrating immersive layouts. This resource is suitable for HarmonyOS developers using the Cangjie language who need to optimize UI layouts for various screen configurations and system obstructions.
