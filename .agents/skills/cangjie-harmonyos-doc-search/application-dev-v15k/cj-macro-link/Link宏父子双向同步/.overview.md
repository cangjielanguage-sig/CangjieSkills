This directory provides comprehensive technical documentation and guides for the `@Link` macro, focusing on implementing bidirectional data synchronization between parent and child components in Cangjie and ArkUI frameworks. It covers core concepts such as two-way binding, state management, and change observation mechanisms. The content includes reference documentation, usage constraints, troubleshooting guides for type mismatches, and practical scenarios involving classes and arrays. It is suitable for developers working with HarmonyOS application development who need to master reactive state management and component interaction logic.

It details the macro's usage rules, including supported data types like basic types, classes requiring @Observed, and specific array types for internal change observation. The document outlines variable transfer rules, emphasizing that @Link variables must be initialized by the parent and cannot be locally initialized. Intended for developers familiar with @State, this guide serves as a technical reference for implementing bidirectional state management in component architectures.

Key takeaways include that classes require @Observed and @Publish for internal change detection, while arrays need ObservedArray for item-level monitoring. ### 限制条件.md 限制条件.md
This reference document outlines the specific constraints and usage rules for the @Link macro in Cangjie UI component development. It covers declaration requirements, initialization restrictions, type consistency with parent data sources, and prohibited usage scenarios. Key takeaways include that @Link variables must be declared with var, cannot be locally initialized, must match the parent's state variable type exactly, and cannot be used in @Entry components or with Function types. This guide targets Cangjie developers building custom components who need to manage state synchronization between parent and child components.
