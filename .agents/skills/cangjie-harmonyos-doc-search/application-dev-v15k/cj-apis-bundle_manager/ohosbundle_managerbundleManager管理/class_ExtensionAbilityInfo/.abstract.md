This directory contains comprehensive API documentation for the `ExtensionAbilityInfo` class within the Cangjie language's BundleManager framework. It covers the structural definition of ExtensionAbility components, detailing a wide array of read-only properties such as bundle name, module name, type, permissions, resource IDs, and metadata. The documentation includes specific versioning details, system capability requirements, and references to retrieval methods like `getBundleInfoForSelf`. Additionally, it provides insights into specific properties like skills and write permissions. This resource is designed for Cangjie developers who need to access, interpret, or configure extension ability configurations and manage access controls in their applications.
