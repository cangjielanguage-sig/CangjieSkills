# 数据保存和恢复

This directory serves as a technical resource for implementing robust data saving and recovery mechanisms within the Cangjie application ecosystem. It specifically addresses the AbilityKit framework, providing developers with the knowledge to handle application state resilience during crashes or unexpected terminations. The documentation covers two primary approaches: active recovery using `appRecovery` features and `ErrorObserver` callbacks, and passive recovery via the `onSaveState` interface. Key concepts include managing `Want` parameters, identifying specific launch reasons such as `APP_RECOVERY`, and detecting restart markers like `ABILITY_RECOVERY_RESTART`. This guide is tailored for application developers who need to ensure data persistence and seamless user experience restoration in their Cangjie-based projects.

## Detailed Description

### 数据保存和恢复_3more.md
This technical guide explains how to implement active data saving and recovery using the appRecovery feature in Cangjie applications. It covers the complete workflow including importing necessary libraries, registering an ErrorObserver callback to handle errors, and implementing the onSaveState method to persist data. The document details how to retrieve saved data during the onCreate phase by checking the APP_RECOVERY launch reason and accessing Want parameters. It also includes instructions for unregistering the observer. Targeted at application developers, this tutorial provides code examples for managing application state resilience and crash recovery within the AbilityKit framework.

### 被动保存和恢复_2more.md
This technical guide explains how to implement passive state saving and recovery mechanisms for applications using the Cangjie language. It covers the implementation of the onSaveState interface for data persistence and the onCreate interface for data restoration based on launch reasons, as well as identifying restart recovery markers for failed Abilities. Key information includes using wantParams to save data, checking LaunchReason.APP_RECOVERY to restore it, and detecting the ABILITY_RECOVERY_RESTART marker to handle post-failure restarts. This guide targets application developers working with the AbilityKit framework who need to ensure app resilience and data persistence during unexpected terminations.
