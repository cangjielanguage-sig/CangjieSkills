# 企业类应用可用权限

本目录包含HarmonyOS及OpenHarmony系统中企业类应用（包括MDM应用和普通企业应用）可申请的敏感权限参考文档。内容涵盖安全审计、进程管理、eSIM设置、文件管控、Wi-Fi配置及企业网络管理等核心功能权限。文档详细说明了权限级别（如system_basic）、授权方式（system_grant）以及API版本（API 12-18）对权限开放范围的变更。主要面向在企业定制设备上开发应用的开发者，指导其正确声明和使用涉及系统核心功能的权限。
