# 接口

This directory contains API reference documentation for the core interfaces within the Cangjie programming language's SQL package. It covers essential components for database interaction, including connection management, query execution, transaction control, and result handling. Key topics include the `Connection`, `QueryResult`, `Transaction`, and `Statement` interfaces, alongside definitions for data types and metadata. This documentation is suitable for software developers and database engineers who are implementing or consuming database drivers in the Cangjie environment, providing the necessary specifications to build robust database applications.

## Detailed Description

### interface_ColumnInfo.md interface_ColumnInfo.md
This document serves as API reference documentation for the ColumnInfo interface in the Cangjie programming language, designed to represent metadata for columns returned by database Select or Query statements. The content details the interface structure and provides specifications for six properties: displaySize, length, name, nullable, scale, and typeName. Key information includes specific behaviors for the length property across numeric, character, and binary data types, as well as how typeName maps database types to Cangjie definitions. This reference is intended for software developers building or using database drivers who need to programmatically interpret result set metadata.

### interface_Connection.md interface_Connection.md
This document provides API reference documentation for the Connection interface in the Cangjie database SQL package, defining the standard contract for managing database connections. It details the interface structure, which inherits from the Resource parent type, and outlines its core components: the state property of type ConnectionState, and methods for creating transactions, retrieving metadata as a string map, and preparing SQL statements. Key information includes that prepareStatement supports ? placeholders and throws SqlException on errors, while createTransaction throws exceptions if parallel transactions are unsupported. This reference is intended for Cangjie developers implementing or interacting with database drivers, requiring knowledge of SQL and interface inheritance.

### interface_Datasource_2more.md interface_Datasource_2more.md
This document provides API reference documentation for the Datasource and Driver interfaces within the Cangjie SQL package. It details the Datasource interface, which inherits from Resource and defines methods for establishing connections and setting options, alongside the Driver interface, which outlines driver properties and initialization logic. Key information includes the connect and setOption functions for Datasource, and the name, preferredPooling, and open members for Driver. The preferredPooling property specifically advises on connection management strategies. This technical reference targets developers implementing or interacting with database drivers in Cangjie.

### interface_QueryResult.md interface_QueryResult.md
This API documentation defines the Cangjie QueryResult interface, which represents the result set generated by SQL Select statements. The document outlines the interface's inheritance from the Resource type and details its core members, including the columnInfos property for metadata and methods like next, get, and getOrNull for data navigation and retrieval. Key takeaways include the requirement to call next to advance the cursor and the distinction between standard value retrieval and handling SQL NULLs. This reference guide targets developers implementing or consuming database drivers in the Cangjie language.

### interface_SqlDbType_supdep_2more.md interface_SqlDbType_supdep_2more.md
This API reference document defines the deprecated Cangjie interfaces SqlDbType and SqlNullableDbType used for implementing SQL data types. The text details the SqlDbType interface as the parent class for all SQL types, specifying requirements for the name property, single-parameter constructors, and public value properties. It also describes SqlNullableDbType, which extends SqlDbType to support null values via Option.None. Key takeaways include the strict implementation rules for type constructors and the critical warning that both interfaces are deprecated and will be removed in future versions. This documentation is intended for Cangjie developers extending database functionality, serving as a technical reference for defining custom SQL data types despite the pending deprecation.

### interface_Transaction.md interface_Transaction.md
This API reference document defines the Transaction interface in the Cangjie language, specifying the core behaviors and properties required for managing database transactions. The documentation details mutable properties for transaction configuration, including access mode, deferrable mode, and isolation level, alongside essential methods for transaction lifecycle management such as begin, commit, and rollback. It also covers savepoint operations like save and release. Key information includes that all methods return Unit and may throw SqlException for server errors or invalid states. This document is intended for developers implementing or utilizing database drivers who need to understand transaction control, savepoint logic, and exception handling within the Cangjie SQL package.

### interface_UpdateResult.md interface_UpdateResult.md
This document serves as API reference documentation for the Cangjie UpdateResult interface, which defines the structure for results generated by database Insert, Update, and Delete operations. The content details the interface definition and specifies two primary properties: lastInsertId and rowCount, both of type Int64. Key information includes that lastInsertId returns the auto-generated row ID from an Insert statement, defaulting to 0 if unsupported, while rowCount indicates the total number of rows affected by the executed statement. This reference is intended for Cangjie developers implementing or interacting with database drivers who need to handle query execution results programmatically.

### interface_Statement/
This directory contains comprehensive API documentation for the Cangjie programming language's `Statement` interface, which is essential for managing pre-executed SQL statements and database connections. It covers core database operations such as querying, updating, parameter binding, and option setting, while also addressing error handling for `SqlException`. Additionally, it provides critical information regarding deprecated functions and migration paths for legacy code. Key topics include the inheritance from the `Resource` type and the management of parameterized queries. This documentation is intended for software developers and database engineers working within the Cangjie environment who need to implement, maintain, or migrate database interaction logic. The directory includes references for both the main interface definition and specific deprecated utility functions to ensure smooth code transitions.
