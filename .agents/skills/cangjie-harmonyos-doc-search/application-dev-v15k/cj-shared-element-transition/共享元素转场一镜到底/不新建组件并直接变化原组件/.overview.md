# 不新建组件并直接变化原组件

This directory focuses on advanced UI animation techniques within the ArkUI and ArkTS frameworks, specifically emphasizing the strategy of modifying existing component properties directly rather than creating new component instances to achieve smooth transitions. It covers the implementation of "one-shot" transition effects, state-driven layout changes, and asymmetric transitions using core functions like `animateTo` and `TransitionEffect`. The content is ideal for HarmonyOS developers and UI engineers looking to optimize performance and enhance user experience in expandable lists, cards, and interactive elements without restructuring the component tree.

## Detailed Description

### 不新建组件并直接变化原组件_1.md
This technical tutorial guides developers on implementing seamless "one-shot" transition effects in ArkUI by modifying existing components rather than creating new containers. It covers the methodology of combining component transitions with attribute animations to handle scenarios where sibling components appear or disappear during an expansion. The document outlines a two-step process involving state variable management and transition binding, illustrated by a Cangjie code example of an expandable card list. Key concepts include using animateTo, TransitionEffect, and state variables to control opacity and translation. This guide targets UI developers seeking to enhance user experience with smooth, continuous animations without complex component tree restructuring.

### 不新建组件并直接变化原组件_2.md
This document demonstrates how to implement an expandable UI component in ArkTS by directly modifying the original component's properties without creating new instances. The code illustrates state-driven layout changes using the animateTo function to smoothly transition height, avatar size, and image dimensions. It highlights the use of conditional rendering with if statements and TransitionEffect to manage the appearance and disappearance of a comment section. Key concepts include dynamic property calculation and asymmetric transitions for polished UI interactions. This technical example targets HarmonyOS developers seeking to create interactive, animated list items or cards within their applications.
