## 详细描述

### log_package_exceptions.md
本文档是Cangjie语言日志包的API参考文档，旨在定义用于处理日志相关异常的LogException类。文档详细说明了该类的继承关系（继承自Exception）、两个构造函数（无参及带参）以及获取类名的重写方法getClassName。核心要点包括支持通过自定义异常信息创建实例，以及通过重写方法获取类名的具体实现。该文档面向需要实现或处理日志错误的开发者，提供了标准的异常处理机制。关键词：Cangjie、LogException、异常处理、API文档、构造函数。
