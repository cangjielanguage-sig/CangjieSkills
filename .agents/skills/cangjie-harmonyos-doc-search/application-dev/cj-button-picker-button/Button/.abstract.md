This directory contains comprehensive API documentation and code examples for the Button component within the ArkUI framework, specifically designed for the Cangjie programming language. It covers the component's lifecycle, including initialization, property configuration, and event handling, alongside fundamental type definitions and practical implementation guides. Key topics include button styles, constructors, state effects, and common attributes. This resource is suitable for HarmonyOS developers and system architects using Cangjie who need to build interactive and visually polished user interfaces with system capabilities starting from version 22.
