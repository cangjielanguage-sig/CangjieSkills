# 预览旋转角度

This directory provides a comprehensive technical overview of the mechanisms required to calculate and adjust image rotation angles during camera preview on mobile devices. It details the critical relationship between hardware-specific factors, such as the lens installation angle, and software variables like screen display compensation. Key topics include the `Display.rotation` API, the specific angular differences between front and rear cameras, and the management of image mirroring. This resource is essential for mobile developers and engineers who need to programmatically handle orientation changes, ensuring that the camera preview aligns correctly with the user's physical perspective regardless of device rotation.

### 预览旋转角度_2.md 预览旋转角度_2.md
This technical reference guide explains how to calculate the correct image preview rotation angles for mobile devices based on device orientation and camera type. It covers scenarios for rear and front cameras across four distinct device orientations, mapping physical positions like charging port direction to the Display.rotation API values. The key takeaway is the calculation formula where the image preview rotation angle equals the sum of the camera lens angle (90 degrees for rear, 270 degrees for front) and the screen rotation angle. This document is intended for mobile application developers implementing camera preview features who need to programmatically handle orientation changes and image mirroring.
