# 测试猜测字符功能

This directory focuses on fuzzing testing for a character guessing feature within the Cangjie programming language. It provides comprehensive resources for setting up, compiling, and executing fuzz tests designed to trigger specific exceptions. Key topics include libFuzzer integration, complex linker configurations, and crash analysis. The content is particularly suitable for Cangjie developers and security analysts who aim to improve code robustness and identify crash-inducing inputs through automated testing techniques. By following these guides, users can learn how to leverage coverage feedback and mutation strategies to uncover vulnerabilities in their applications. The documentation covers both the theoretical setup and practical execution logs, offering a complete view of the fuzzing lifecycle from compilation to crash discovery.
