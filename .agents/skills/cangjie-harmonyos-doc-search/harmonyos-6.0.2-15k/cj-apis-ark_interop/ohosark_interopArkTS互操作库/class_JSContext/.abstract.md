This directory contains API reference documentation for the `JSContext` class in the Cangjie programming language, designed for single-threaded ArkTS interoperation within the HarmonyOS ArkUI framework. It covers essential properties, lifecycle management, and methods for creating and manipulating JavaScript data types like Arrays, ArrayBuffers, Objects, and Strings from Cangjie code. Key topics include Napi capabilities, memory management, and module loading. This documentation is suitable for developers integrating Cangjie with ArkTS, requiring knowledge of system capabilities and version 12 features.
