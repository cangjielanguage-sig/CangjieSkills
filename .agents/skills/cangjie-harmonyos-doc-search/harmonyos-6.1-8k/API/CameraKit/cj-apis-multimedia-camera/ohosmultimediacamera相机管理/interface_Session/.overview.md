本目录包含Cangjie语言中Camera Kit相机会话（Session）相关的API参考文档。内容涵盖了Session接口的定义、配置流程管理（如启动配置、提交配置）、输入输出流的添加与移除，以及会话生命周期的控制（启动与停止）。核心关键词包括Session接口、beginConfig、commitConfig、addInput、addOutput、removeOutput、start、stop以及BusinessException异常处理。这些文档适用于使用Cangjie语言进行HarmonyOS多媒体相机应用开发的开发者，旨在指导其正确配置和管理相机会话资源，实现拍照和录像功能。
